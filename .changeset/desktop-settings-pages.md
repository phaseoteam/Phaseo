Desktop settings: new Chat, Diffs, Threads, Browser, Source control, Worktrees and Maintenance pages. Follow-ups can steer by default, and quitting asks first while chats are working. Markdown is styled as you type in every message box and in the other places you write Markdown (pull request and diff comments, review summaries, issue drafts, Factory, scheduled tasks and instructions), and Settings → Chat turns it off everywhere. Diffs get a shared layout and whitespace default and blue-and-orange colours. Chats can resume or snooze until usage limits reset, continue after restarts (now on by default) and compact when idle, with editable snooze times and response streaming modes. Agent health and update checks can be tuned. Links, including pull request and issue links, open where Settings → Browser says; the search engine can be chosen, agent browser tools can be turned off per project, and browsers get separate profiles. Worktrees get a location, branch naming and submodule checkout, and a failed submodule checkout is shown in the chat's Git section. Commit, pull request, title and review guide instructions, a model for git text, and pull request templates are supported. Old recordings and logs can be cleaned up, and About links to the Android app, the licences and the privacy policy.
