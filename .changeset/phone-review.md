A paired phone can review a thread's changes on its computer: uncommitted work, the branch, or one turn, file by file with numbered lines, and a comment on a range of lines goes into the thread's message. The computer's Settings → Phone has switches per phone for reading code (on), making changes and terminals (off), and a change applies at once.
