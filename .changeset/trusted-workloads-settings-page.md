Settings → Trusted workloads lets workspace owners and admins create, edit, turn off and delete trust policies for Vercel deployments and GitHub Actions jobs, with copyable token snippets. The page and its sidebar entry appear only for workspaces in the gateway_workload_identity Statsig gate. Workload identity keys no longer appear on the Keys page or count toward the API key limit.
