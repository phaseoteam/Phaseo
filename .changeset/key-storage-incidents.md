Key storage incidents: when a platform where customers store API keys reports a breach, Phaseo staff can revoke or pause, in one step, every key recorded as stored there and created before a cut-off, across all workspaces. Each affected workspace's owners and admins get an email naming the platform and the number of keys, and the Key security page shows what happened and what to do next.
