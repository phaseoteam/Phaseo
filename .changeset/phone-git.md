A paired phone with Make changes on can commit (with Write message), push, pull, and switch or create branches on its computer, start a thread in a new worktree from a base branch, and list, read, review, comment on, merge, close and reopen pull requests through the computer's GitHub sign-in. Each runs the window's own command, and the window says what the phone did. Make changes needs Read code, and stays off until it's turned on for that phone in Settings → Phone.
