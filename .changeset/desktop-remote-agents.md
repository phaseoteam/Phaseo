Let AI apps that support MCP connectors drive Phaseo Desktop's chats from anywhere. Add `https://mcp.phaseo.app/mcp?access=desktop` as a connector, make a one-time link in Settings → Outside agents → Apps through Phaseo (read only, or can start chats), and send it to the app. Requests reach the desktop over Phaseo Connect, end to end encrypted, and run with the same tools and limits as an outside agent on the computer.
