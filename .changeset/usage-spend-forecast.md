Forecast this month on the usage overview. Every KPI card gains a this-month line: Spend, Requests and Tokens show where the month is heading, and the rate cards show the month so far. Each line uses the exact daily rollup. Also, "Usage by model" gains a This month view with cumulative spend, the projection and last month's total, all from the exact daily rollup. Spend, request and token deltas are now neutral, with green and red kept for metrics where the direction is good or bad. Chart cursors and the sparkline hover dot use valid theme colours.
