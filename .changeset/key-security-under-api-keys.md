Key Security now sits under API Keys in the settings sidebar, next to the key list. On the page, filters sit directly above the key table with their counts, and a "Showing X of Y keys" line says which filter is on. Every column of the table sorts, and there are new Created and Status columns: Status shows whether a key is active, paused, idle, never used or safe to remove, and Risks shows the settings that make a leak worse, each with the same icon as its filter. "Where keys are stored" lists the top 5 platforms with a "Show all" button. Storage location logos are drawn in each platform's brand colour.
