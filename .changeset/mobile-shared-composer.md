Chats and Code threads share one composer. It sits on one line beside its controls until the text wraps, then grows above them to four lines; the model shows its logo, and its name and effort once there's room. With nothing typed, send turns into stop while answers run. In chats, messages sent while answers run wait in a queue that sends each one when the answers before it finish; queued messages can be edited or removed, and a stopped or failed answer pauses the queue until you resume it. Typing `/` offers model, compare, settings and usage. In Code threads, send steers the running turn, and a long press queues the message on the computer instead; approvals and questions show as cards over the composer, and New thread uses the same composer.
