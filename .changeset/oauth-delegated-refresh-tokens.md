Apps that use "Sign in with Phaseo" now get a refresh token with their access token. The access token still lasts 7 days; the refresh token lasts 90 days from its last use and changes on every refresh. Refreshing gives the app's existing key a new secret, so the old access token stops working at once, and the key keeps its limits, history and place under Settings → Keys. Approving the same app again renews that key the same way instead of adding a second one, as long as the key isn't revoked, and never turns a paused key back on; after a sign-out or any other revocation, signing in issues a new key with fresh limits and spending. A refresh never adds scopes, and losing a scope the key needs ends refreshes for good; losing `gateway:access` also revokes the app's credit-spending keys, so their access tokens stop at once. Using a refresh token twice ends the sign-in. A refresh token from before the app was approved again is just refused, so it can't end the renewed sign-in. Revoking the app or its key, turning the key off, or leaving the workspace ends refreshes, and revoking an app's access now also revokes its keys, paused ones included. Revoking a refresh token at `/oauth/revoke` ends the key and every refresh token from that sign-in in one step.
