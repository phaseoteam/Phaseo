Ship the Phaseo plugin for Claude Code alongside Codex and ChatGPT. It bundles the Phaseo MCP, the Phaseo Docs MCP and all 14 public skills, with marketplaces for both hosts. Three new public skills cover migrating from eight platforms, choosing models and monitoring usage. Every public skill now has a third-person description with clear boundaries, Codex metadata (`agents/openai.yaml`) and evals, and CI validates the skills, their example model IDs and request bodies, and the plugin manifests.
