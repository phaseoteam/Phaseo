API keys can record where they are stored (Railway, Vercel, GitHub, 1Password and 35 other places, each with its logo), optionally when the key is created or later on its page. If one of those places reports a breach, the keys stored there can be found and revoked. Revoked keys can no longer be turned back on from the dashboard, the API or the database; rotate them instead.
