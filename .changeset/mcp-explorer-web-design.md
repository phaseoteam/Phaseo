The model explorer now looks like the website's models page: organisation logo tiles, "Organisation: Model" names with the Phaseo ID, price, provider and context chips, coloured input and output modality badges, and release dates. Modality, sort and the Gateway filter are visible tabs and chips instead of dropdowns, a model opens in place of the list instead of a floating panel, and the shortlist bar only appears once you've picked a model. Colours, corners and the font follow the host's theme.
