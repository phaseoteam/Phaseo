# @phaseo/slack-agent

## 0.1.0

### Minor Changes

- [#3135](https://github.com/phaseoteam/Phaseo/pull/3135) [`891f5f1`](https://github.com/phaseoteam/Phaseo/commit/891f5f10d2d752a84a047f18c3627a2c6a8895fd) Thanks [@DanielButler1](https://github.com/DanielButler1)! - The Slack agent now answers. Each turn runs as a Cloudflare Workflow. It streams the answer into the Slack thread through the gateway, with the installation's managed key, model and instructions, and adds a footer with the model and the turn's cost. Every request asks for providers that don't keep or train on data, and is labelled `app=slack-agent`. Retried steps update the same Slack message instead of posting again, and a failed Slack write is retried on its own without running the model again; a retried answer counts every attempt's cost against the per-turn limit and in the footer. Stop and Cancel end a turn between steps. Out-of-credits, spending-limit and unavailable-model errors become plain replies. Linked workspace members can ask about the workspace's spend, credit balance, key usage and models in direct messages, or in channels the admins allow. Two new database functions add the spend up per day, week or month and per API key.

- [#3134](https://github.com/phaseoteam/Phaseo/pull/3134) [`ccf8394`](https://github.com/phaseoteam/Phaseo/commit/ccf83948d9a0627a81cbe6c0b40e7a08ffc13d5d) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Add the Slack agent's Cloudflare Worker (`apps/slack`). It verifies and acknowledges Slack events and button clicks for the hosted app and for a company's own app, ignores bots, and dedupes Slack's retries. A meter per installation decides who gets an answer under the installation's limits and counts each month's people and answers for billing. A coordinator per Slack thread runs one turn at a time and deletes its working memory after 7 days. Unlinked people get a Connect account button when the installation requires linked accounts. Removing the app inside Slack uninstalls it in Phaseo: its gateway key is deleted, its guardrail removed and the change recorded in the audit log. Turns are acknowledged but not answered yet. The Slack secrets format now comes from one shared module used by web-api and the Worker.

### Patch Changes

- [#3176](https://github.com/phaseoteam/Phaseo/pull/3176) [`043d3eb`](https://github.com/phaseoteam/Phaseo/commit/043d3ebaf1d16c8fcff3dbe3911fbc1842eb4bfa) Thanks [@DanielButler1](https://github.com/DanielButler1)! - The Slack agent no longer takes other bots' and apps' messages in a thread for its own. Only its installation's bot user, or its own Slack app, is "You" in the prompt; other bots and apps are shown as "Another app", with their name when Slack gives one. When Slack answers a thread read with 429, the installation's meter keeps the `Retry-After`, and every thread in that installation skips its read and works from its working memory until it has passed, instead of asking Slack again.

- [#3171](https://github.com/phaseoteam/Phaseo/pull/3171) [`a62fb90`](https://github.com/phaseoteam/Phaseo/commit/a62fb9084bc9a5ee1138c61ce088ce7ad6c3c108) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Add the Slack agent's app manifest (`apps/slack/manifest.json`), with a test that keeps its bot scopes, bot events and request URLs in step with web-api and the Worker. Add the Slack agent guide in nine languages: installing from Settings → Slack, who can use it and linking accounts, usage questions, limits, pricing, data handling, emails to owners and admins, using your own Slack app with the same manifest, uninstalling and troubleshooting. The docs search includes the new page.

- [#3174](https://github.com/phaseoteam/Phaseo/pull/3174) [`de31255`](https://github.com/phaseoteam/Phaseo/commit/de31255405ccf753c419ba9e415ca76d30526f68) Thanks [@DanielButler1](https://github.com/DanielButler1)! - The Slack agent now reads the newest part of a long thread instead of its first 15 messages. Each answer makes one `conversations.replies` read that ends at the message being answered and starts from the newest messages the thread already knows (in a channel, from the last 30 minutes at most). It always keeps the thread's first message, says when a busy thread held more than Slack returned, and merges the read with its own earlier replies. The agent no longer asks Slack for `files:read` or `search:read.public`, which nothing used; installs keep them until they're reinstalled. When anyone can use the agent, someone who isn't linked and asks about usage where usage data is allowed now gets the private Connect your Phaseo account button, at most once per person in each thread, and still gets an answer. The Slack agent guide covers all three in nine languages.

- [#3144](https://github.com/phaseoteam/Phaseo/pull/3144) [`0ad409a`](https://github.com/phaseoteam/Phaseo/commit/0ad409a10a8c8a49b0394f06ee885cbf2678e64a) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Email workspace owners and admins when the Slack agent turns people away because the plan is full, the monthly people limit or spending cap is reached, or a charge is unpaid. At most one email per reason a month, with no Slack names or message text.
