[API प्रदाता](https://phaseo.app/api-providers) पर कोई प्रदाता खोलें और देखें कि वह Phaseo के ज़रिए कौन से मॉडल देता है और वह कितना तेज़ रहा है, या [प्रदाताओं की तुलना](https://phaseo.app/api-providers/compare) साथ-साथ करें। API प्रदाता मॉडल को एक API के पीछे होस्ट करता है; जिस [संगठन](./organisations.mdx) ने मॉडल बनाया, वह अक्सर कोई दूसरी कंपनी होती है।

| | संगठन | API प्रदाता |
| --- | --- | --- |
| **क्या करता है** | मॉडल बनाता और प्रशिक्षित करता है | मॉडल API होस्ट करता और उपलब्ध कराता है |
| **फ़ोकस** | रिसर्च और मॉडल की गुणवत्ता | विश्वसनीयता, ऐक्सेस, क्षेत्र और मूल्य |
| **मॉडल** | आमतौर पर अपने ही मॉडल परिवार | अक्सर कई संगठनों के मॉडल |

कई कंपनियाँ दोनों होती हैं।

## प्रदाता पेज क्या दिखाता है

| सेक्शन | यह आपको क्या बताता है |
| --- | --- |
| **प्रदर्शन** | पिछले सात दिनों में Gateway ट्रैफ़िक पर हर घंटे की लेटेंसी और थ्रूपुट। |
| **टोकन उपयोग** | समय के साथ Phaseo ने प्रदाता को कितने टोकन भेजे। |
| **शीर्ष मॉडल** और **शीर्ष ऐप** | इस प्रदाता पर सबसे ज़्यादा ट्रैफ़िक वाले मॉडल और सार्वजनिक ऐप। |
| **मॉडल** | प्रदाता के दिए हर मॉडल की सूची, टेक्स्ट, इमेज, ऑडियो, वीडियो, एम्बेडिंग और मॉडरेशन मॉडल के टैब के साथ। |

फिर हर मॉडल का पेज उस मॉडल के लिए प्रदाता का मूल्य, कॉन्टेक्स्ट लंबाई, स्थिति और डेटा नीति दिखाता है; स्टेटस आइकन [प्रदाता स्थितियां](../guides/provider-statuses) में समझाए गए हैं।

## Gateway प्रदाताओं का उपयोग कैसे करता है

जब किसी मॉडल के कई प्रदाता होते हैं, तो Gateway हर अनुरोध के लिए एक चुनता है और विफल होने पर दूसरे पर फ़ॉलबैक करता है। आप एक ही अनुरोध फ़ॉर्मैट भेजते हैं और आपको एक ही बिल और एक ही उपयोग लॉग मिलता है, चाहे कोई भी प्रदाता अनुरोध पूरा करे। इसके बजाय अपने प्रदाता खाते में बिल करवाने के लिए प्रदाता कुंजी जोड़ें ([BYOK](../guides/routing-and-fallbacks#byok-considerations))।

[रूटिंग और फ़ॉलबैक](../guides/routing-and-fallbacks) दिखाता है कि प्रदाताओं को रैंक, पिन या बाहर कैसे करें।

## प्रदाता चुनें

| अगर आपके लिए ज़रूरी है | जाँचें |
| --- | --- |
| कोई खास मॉडल | मॉडल पेज का **प्रदाता** सेक्शन, या `GET /v1/models/{author}/{slug}/endpoints` |
| आपके क्षेत्र में लेटेंसी | प्रदाता का **प्रदर्शन** सेक्शन और मॉडल पेज पर उसके क्षेत्र |
| आपके वॉल्यूम पर लागत | मॉडल का **मूल्य निर्धारण** सेक्शन और [मूल्य कैलकुलेटर](https://phaseo.app/tools/pricing-calculator) |
| टूल, स्ट्रीमिंग या संरचित आउटपुट | मॉडल पेज या endpoints API पर रूट के समर्थित पैरामीटर |
| डेटा प्रबंधन और अनुपालन | मॉडल पेज पर रूट की डेटा नीति और प्रोसेसिंग स्थान |

[मूल्य और प्रदर्शन](./pricing-performance.mdx) बताता है कि लागत और गति के आँकड़े कैसे पढ़ें।
