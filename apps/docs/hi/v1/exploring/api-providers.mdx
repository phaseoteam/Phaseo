API प्रदाता वे प्लेटफ़ॉर्म हैं जो मॉडल API को होस्ट और उपलब्ध कराते हैं।

मॉडल संगठन मॉडल को ट्रेन करते हैं। प्रोवाइडर प्रोडक्शन एंडपॉइंट, प्रमाणीकरण, उपयोग नियंत्रण और संचालन टूल के माध्यम से ये मॉडल उपलब्ध कराते हैं।

## API प्रदाता आम तौर पर क्या संभालता है

- प्रमाणीकरण और कुंजी प्रबंधन
- अनुरोध रूटिंग और उपलब्धता प्रबंधन
- उपयोग की गणना और बिलिंग
- API और SDK का उपयोग अनुभव
- क्षेत्रीय होस्टिंग और अनुपालन नियंत्रण

## प्रोवाइडर और संगठन

| पहलू | संगठन | API प्रदाता |
| --- | --- | --- |
| मुख्य भूमिका | मॉडल बनाना और ट्रेन करना | मॉडल API को होस्ट और उपलब्ध कराना |
| ध्यान | शोध और मॉडल गुणवत्ता | विश्वसनीयता, पहुंच और संचालन |
| वितरण | आमतौर पर अपना मॉडल परिवार | कई संगठनों के मॉडल उपलब्ध करा सकता है |

उत्पाद के आधार पर कई कंपनियां दोनों भूमिकाएं निभाती हैं।

## Phaseo के प्रदाता पृष्ठ पर क्या देख सकते हैं

| सेक्शन | जानकारी |
| --- | --- |
| अवलोकन | प्रोवाइडर की पहचान, दस्तावेज़ लिंक और समर्थित क्षमताएं |
| मॉडल | उपलब्ध मॉडल और उनके वेरिएंट |
| कीमत | प्रोवाइडर की कीमतों और मीटर का सामान्यीकरण |
| सीमाएं | उपलब्ध होने पर अनुरोध और थ्रूपुट सीमाएं |
| सुविधाएं | स्ट्रीमिंग, टूल, संरचित आउटपुट और मोडैलिटी समर्थन |

## प्रोवाइडर लेयर के रूप में Phaseo Gateway

Phaseo Gateway कई बैकएंड पर एक समान पहुंच देता है।

फ़ायदे:

- प्रोवाइडर के बीच अनुरोध और प्रतिक्रिया का एक समान प्रारूप
- प्रोवाइडर के अनुसार रूटिंग और फ़ॉलबैक
- कई प्रोवाइडर वाले इंटीग्रेशन के लिए एक समान SDK उपयोग
- उपयोग और लागत की केंद्रीकृत ऑब्ज़र्वेबिलिटी
- प्रोवाइडर की अपनी कुंजियों के लिए वैकल्पिक BYOK समर्थन

## प्रोवाइडर चुनें

प्रोवाइडर का मूल्यांकन करते समय इन बातों पर ध्यान दें:

- आपके उपयोग के लिए मॉडल की उपलब्धता
- लक्षित क्षेत्र में विश्वसनीयता और विलंबता
- अनुमानित ट्रैफ़िक के अनुसार लागत
- टूल, स्ट्रीमिंग और संरचित आउटपुट की सुविधा
- अनुपालन और डेटा प्रबंधन की आवश्यकताएं

## मूल्यांकन के उदाहरण प्रश्न

- मेरी ज़रूरत के मॉडल परिवार कौन-से प्रोवाइडर उपलब्ध कराते हैं?
- मेरे क्षेत्र में किस प्रोवाइडर की विलंबता बेहतर है?
- मेरे टोकन वॉल्यूम के लिए सबसे कम लागत वाला विकल्प कौन-सा है?
- मुझे जिन endpoint सुविधाओं की ज़रूरत है, उन्हें कौन-सा प्रोवाइडर सपोर्ट करता है?
