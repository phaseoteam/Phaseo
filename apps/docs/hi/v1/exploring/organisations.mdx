[संगठन](https://phaseo.app/organisations) पर कोई संगठन खोलें और उसके जारी किए हर मॉडल को देखें, साथ ही यह कि वे मॉडल Gateway पर कैसा प्रदर्शन करते हैं। Phaseo पर हर मॉडल एक संगठन का होता है: वह कंपनी या लैब जो उसे विकसित करती और उसका रखरखाव करती है।

## संगठन पेज क्या दिखाता है

पेज में दो टैब हैं।

| टैब | सेक्शन | यह आपको क्या बताता है |
| --- | --- | --- |
| **अवलोकन** | परिचय | नाम, विवरण और देश। |
| | प्रदर्शन | संगठन के मॉडलों में हाल की Gateway लेटेंसी और थ्रूपुट। |
| | नवीनतम मॉडल | हाल की रिलीज़, उपलब्धता, कॉन्टेक्स्ट, मूल्य और उपयोग के साथ। |
| | वेब पर | संगठन की वेबसाइट, GitHub, Hugging Face और सोशल अकाउंट के लिंक। |
| **मॉडल** | | संगठन के जारी किए सभी मॉडल, आर्काइव और डेप्रिकेटेड मॉडल समेत। |

## संगठन और API प्रदाता

संगठन मॉडल बनाता है; [API प्रदाता](./api-providers.mdx) उसे उपलब्ध कराता है। एक मॉडल के अक्सर कई प्रदाता होते हैं।

| | संगठन | API प्रदाता |
| --- | --- | --- |
| **क्या करता है** | मॉडल को प्रशिक्षित करता और उसका रखरखाव करता है। | मॉडल को एक API के पीछे होस्ट करता है। |
| **उदाहरण** | Anthropic ने Claude मॉडल बनाए। | Anthropic, Amazon Bedrock और Google Vertex, सभी Claude मॉडल उपलब्ध कराते हैं। |

कुछ संगठन, जैसे OpenAI और Google, अपने मॉडलों के प्रदाता भी हैं।

## सुधार की रिपोर्ट करें

संगठन पेज और किसी आधिकारिक स्रोत के साथ एक GitHub issue खोलें। मेंटेनर स्वीकृत बदलाव डेटाबेस में लागू करते हैं। [संगठन अपडेट रिपोर्ट करें](../contributing/editing-an-organisation.mdx) देखें।
