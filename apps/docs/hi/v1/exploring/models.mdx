टेक्स्ट, इमेज, ऑडियो, वीडियो, एम्बेडिंग और दूसरे मॉडल ढूँढने के लिए [मॉडल](https://phaseo.app/models) सूची खोलें, फिर किसी मॉडल को खोलकर उसके प्रदाता, मूल्य, प्रदर्शन और बेंचमार्क स्कोर देखें।

![Phaseo पर एक मॉडल पेज](/images/gemini-3-page.png)

## कैटलॉग मॉडल और कॉल किए जा सकने वाले मॉडल

कैटलॉग Gateway से बड़ा है। मॉडल सूची डिफ़ॉल्ट रूप से सिर्फ़ वे मॉडल दिखाती है जो **Gateway पर सक्रिय** हैं। बाकी देखने के लिए **Gateway स्थिति** फ़िल्टर को **जल्द आ रहा है** या **निष्क्रिय** पर बदलें।

| शब्द | अर्थ |
| --- | --- |
| कैटलॉग मॉडल | Phaseo मॉडल का मेटाडेटा ट्रैक करता है। हो सकता है कि उसका कोई रूट न हो जिसे आप कॉल कर सकें। |
| रूट करने योग्य मॉडल | Phaseo Gateway पर अभी कम से कम एक प्रदाता रूट सक्रिय है। |
| बाहरी मैपिंग | Phaseo किसी प्रदाता ऑफ़र को सूचीबद्ध करता है जिसे Gateway नहीं चलाता। |

`GET /v1/models` सिर्फ़ रूट करने योग्य मॉडल लौटाता है। बाकी शामिल करने के लिए `availability=all` जोड़ें।

## सूची को फ़िल्टर और सॉर्ट करें

| नियंत्रण | विकल्प |
| --- | --- |
| Gateway स्थिति | Gateway पर सक्रिय (डिफ़ॉल्ट), जल्द आ रहा है, निष्क्रिय |
| एंडपॉइंट | मॉडल जिन API एंडपॉइंट को सपोर्ट करता है, जैसे टेक्स्ट जनरेशन या एम्बेडिंग |
| इनपुट और आउटपुट मोडैलिटी | टेक्स्ट, इमेज, ऑडियो, वीडियो और अन्य |
| फ़ीचर | क्षमताएँ, जैसे टूल कॉलिंग या रीज़निंग |
| वर्ष | रिलीज़ वर्ष |
| सॉर्ट | सबसे नया, सबसे लोकप्रिय (7 दिन के टोकन), मूल्य, कॉन्टेक्स्ट लंबाई, थ्रूपुट, लेटेंसी |

किसी एक लैब के सभी मॉडल देखने के लिए उसका [संगठन पेज](./organisations.mdx) खोलें।

## मॉडल पेज क्या दिखाता है

| सेक्शन | यह आपको क्या बताता है |
| --- | --- |
| **प्रदाता** | हर प्रदाता रूट, उसकी स्थिति, कॉन्टेक्स्ट लंबाई, मूल्य, अपटाइम और डेटा नीति के साथ। आइकन [प्रदाता स्थितियां](../guides/provider-statuses) में समझाए गए हैं। |
| **प्रदर्शन** | Gateway ट्रैफ़िक पर मापी गई लेटेंसी और थ्रूपुट, जब पर्याप्त डेटा हो। |
| **मूल्य निर्धारण** | USD में हर मीटर: इनपुट, आउटपुट, कैश्ड इनपुट और मीडिया यूनिट। |
| **बेंचमार्क** | हर बेंचमार्क पर स्कोर, स्रोतों के साथ। |
| **गतिविधि** | समय के साथ Gateway टोकन उपयोग। |
| **ऐप्लिकेशन** | मॉडल का उपयोग करने वाले सार्वजनिक ऐप। |
| **अपटाइम** | हाल के दिनों में रूट की उपलब्धता। |
| **सत्यापन** | इमेज और वीडियो मॉडल के लिए कंटेंट-प्रोवेनेंस जाँच। |
| **इस मॉडल के बारे में** | रिलीज़ तिथियाँ, लाइसेंस, लिंक और मॉडल परिवार। |
| **सदस्यताएँ** | प्रदाता की सदस्यता योजनाएँ जिनमें यह मॉडल शामिल है। |
| **सामान्य प्रश्न** | मॉडल के बारे में आम सवाल। |

कोई सेक्शन तभी दिखता है जब उसके लिए डेटा हो। सक्रिय रूट वाले मॉडल एक क्विकस्टार्ट भी दिखाते हैं, जिसमें भेजने के लिए मॉडल ID होती है।

## मॉडलों की तुलना करें

[तुलना करें](https://phaseo.app/compare) मॉडलों को मूल्य, बेंचमार्क स्कोर, कॉन्टेक्स्ट और फ़ीचर पर साथ-साथ रखता है। [मूल्य और प्रदर्शन](./pricing-performance.mdx) बताता है कि लागत और गति के आँकड़े कैसे पढ़ें।

## सुधार की रिपोर्ट करें

मॉडल पेज और किसी आधिकारिक स्रोत के साथ एक GitHub issue खोलें। मेंटेनर स्वीकृत अपडेट डेटाबेस में लागू करते हैं। [मॉडल अपडेट रिपोर्ट करें](../contributing/editing-a-model.mdx) देखें।
