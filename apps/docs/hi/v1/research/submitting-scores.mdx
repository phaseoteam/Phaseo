GitHub इश्यू से बेंचमार्क परिणाम जमा करें। रखरखावकर्ता प्रमाण जाँचकर स्वीकृत स्कोर डेटाबेस संपादक से प्रकाशित करते हैं।

## प्रमाण तैयार करें

ये शामिल करें:

- मॉडल ID, प्रदाता और उपलब्ध होने पर Phaseo पेज।
- बेंचमार्क नाम, संस्करण, डेटा विभाजन, स्कोर और इकाइयाँ।
- मूल्यांकन की तारीख, प्रॉम्प्ट प्रारूप, परीक्षण ढाँचा और संबंधित हार्डवेयर या सैंपलिंग सेटिंग।
- सार्वजनिक शोधपत्र, परिणाम पेज, डेटासेट या दोहराए जा सकने वाला मूल्यांकन लॉग।
- परिणाम प्रदाता का बताया हुआ है या स्वतंत्र रूप से मापा गया है।

## इश्यू जमा करें

नए परिणाम या बेंचमार्क के लिए [नया बेंचमार्क डेटा माँगें](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml)। मौजूदा स्कोर सुधारने के लिए [गलत जानकारी बताएँ](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) और वर्तमान व प्रस्तावित मान शामिल करें।

सार्वजनिक रिपोर्ट में क्रेडेंशियल, निजी प्रॉम्प्ट या ग्राहक डेटा शामिल न करें।

## प्रकाशन की स्थिति देखें

डेटाबेस अपडेट से पहले रखरखावकर्ता इश्यू में स्पष्टीकरण माँग सकते हैं। दैनिक JSON स्नैपशॉट प्रकाशित डेटा दिखाते हैं; संग्रहित बेंचमार्क JSON बदलने से स्कोर प्रकाशित नहीं होता।

जमा करने की तैयारी में मदद के लिए [समुदाय Discord](https://discord.gg/aQyywCvgZ5) इस्तेमाल करें।
