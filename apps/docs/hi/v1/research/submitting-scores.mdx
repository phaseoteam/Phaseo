हम प्रदाताओं, शोधकर्ताओं और अनुभवी उपयोगकर्ताओं के योगदान का स्वागत करते हैं। सबमिशन जल्दी संसाधित हो, इसके लिए नीचे दिया गया तरीका अपनाएँ।

---

## 1. डेटा तैयार करें

- जाँचें कि बेंचमार्क `/data/benchmarks` में मौजूद है। यदि नहीं, तो उसे प्रस्तावित करने के लिए issue बनाएँ।
- कच्चे परिणाम एकत्र करें, जिनमें prompt का प्रारूप, मूल्यांकन harness और हार्डवेयर विवरण शामिल हों।
- उपलब्ध होने पर सार्वजनिक संदर्भ (ब्लॉग पोस्ट, शोधपत्र या dataset repository) दें।

> ✅ **सुझाव**
> पुनरुत्पादन योग्य script या notebook साझा करने से सत्यापन काफी तेज़ होता है।

---

## 2. रिपॉज़िटरी fork करें

1. [github.com/phaseoteam/data](https://github.com/phaseoteam/data) को fork करें।
2. नई branch बनाएँ (उदाहरण के लिए `add-claude-3.5-sonnet-mmlu`)।
3. संबंधित benchmark JSON में अपने स्कोर और मेटाडेटा अपडेट करें।

---

## 3. सत्यापन चलाएँ

संरचना और मान-सीमाएँ सही हैं या नहीं, यह जाँचने के लिए रिपॉज़िटरी के टूल उपयोग करें:

```bash
pnpm install
pnpm run validate:benchmarks
```

Pull request भेजने से पहले रिपोर्ट की गई समस्याएँ ठीक करें।

---

## 4. Pull request खोलें

अपने PR विवरण में ये बातें शामिल करें:

- बेंचमार्क का नाम और split (उदाहरण: `GSM8K test`)।
- मॉडल ID और प्रदाता।
- संदर्भ या मूल्यांकन लॉग के लिंक।
- स्कोर कैसे प्राप्त हुआ, इसका सारांश।

मेंटेनर सबमिशन की समीक्षा करेंगे, ज़रूरत पड़ने पर स्पष्टीकरण माँगेंगे और मंज़ूरी के बाद merge करेंगे。

---

## 5. प्रकाशन पर नज़र रखें

Merge के बाद स्कोर अगले निर्धारित डेटा सिंक में दिखाई देगा। प्रगति Discord के #data-updates चैनल या सार्वजनिक changelog में देख सकते हैं।
