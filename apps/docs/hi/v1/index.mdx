`https://api.phaseo.app/v1` पर एक ही API से कई प्रदाताओं के मॉडल कॉल करें, तय करें कि हर अनुरोध कैसे रूट हो, और हर अनुरोध का उपयोग और लागत देखें। यह अनुरोध `phaseo/free` का उपयोग करता है, इसलिए यह क्रेडिट जोड़ने से पहले भी काम करता है:

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "phaseo/free", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // reads PHASEO_API_KEY

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # reads PHASEO_API_KEY

response = client.responses.create({"model": "phaseo/free", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

अभी तक API कुंजी नहीं है? [डैशबोर्ड में एक बनाएँ](https://phaseo.app/settings/keys), फिर [क्विकस्टार्ट](./quickstart.mdx) देखें।

## मॉडल चुनें

[मॉडल देखें](https://phaseo.app/models) या [उनकी तुलना करें](https://phaseo.app/compare)। कैटलॉग में वे मॉडल भी दिखते हैं जिन्हें आप अभी कॉल नहीं कर सकते, इसलिए इंटीग्रेट करने से पहले जाँच लें कि मॉडल **Gateway पर सक्रिय** है, या `GET /v1/models` से कॉल किए जा सकने वाले मॉडल की सूची लें। मॉडल, प्रदाता और बिलिंग के लिए [Phaseo कैसे काम करता है](./developers/introduction.mdx) देखें।
