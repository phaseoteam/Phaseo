Phaseo से कई प्रदाताओं के मॉडल एक API से कॉल करें, रूटिंग नियंत्रित करें और उपयोग व लागत देखें।

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "phaseo/free", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // reads PHASEO_API_KEY

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # reads PHASEO_API_KEY

response = client.responses.create({"model": "phaseo/free", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

अभी तक API कुंजी नहीं है? [डैशबोर्ड में एक बनाएँ](https://phaseo.app/hi/settings/keys), फिर [क्विकस्टार्ट](./quickstart.mdx) देखें।

## मॉडल चुनें

[मॉडल देखें](https://phaseo.app/models) या [तुलना करें](https://phaseo.app/compare)। कैटलॉग में बिना रूट वाले मॉडल भी हो सकते हैं; जोड़ने से पहले Gateway उपलब्धता जाँचें। मॉडल, प्रदाता और बिलिंग के लिए [Phaseo कैसे काम करता है](./developers/introduction.mdx) देखें।
