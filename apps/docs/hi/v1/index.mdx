अगर आपको पता है कि क्या बनाना है, लेकिन यह तय नहीं है कि Phaseo के किस दस्तावेज़ से शुरू करें, तो इस पेज का उपयोग करें।

Phaseo मॉडल एक्सेस, प्रोवाइडर रूटिंग, कीमत, उपयोग ट्रैकिंग और एसिंक्रोनस AI वर्कफ़्लो के लिए एक ही API देता है।

अगर आप Phaseo पर नए हैं, तो पहले एक अनुरोध सफलतापूर्वक भेजें। अगर आपके पास पहले से AI इंटीग्रेशन है, तो अपने ऐप के लिए उपयुक्त माइग्रेशन या SDK गाइड खोलें।

## पहला अनुरोध सफलतापूर्वक भेजें

नई इंटीग्रेशन के लिए यह तरीका अपनाएँ:

1. डैशबोर्ड में API कुंजी बनाएँ।
2. किसी मौजूदा टेक्स्ट मॉडल को अनुरोध भेजें।
3. जवाब से जनरेट किया गया टेक्स्ट पढ़ें।
4. अगले कदम के अनुसार SDK, रूटिंग या प्रोडक्शन गाइड पढ़ें।

## पहला अनुरोध

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-sol",
    "input": "Reply with: docs ready",
    "temperature": 0
  }'
```

```typescript TypeScript SDK
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-5.6-sol",
  input: "Reply with: docs ready",
  temperature: 0,
});

console.log(response.output_text);
```

```python Python SDK
from phaseo import Phaseo

client = Phaseo(api_key="YOUR_API_KEY")

response = client.generate_response(
    {
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with: docs ready",
        "temperature": 0,
    }
)

print(response.get("output_text"))
```
</CodeGroup>

अगर यह काम करता है, तो पहली अनुरोध प्रक्रिया पूरी करने के लिए [क्विकस्टार्ट](./quickstart.mdx) पढ़ें।
