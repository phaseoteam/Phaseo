जब आपके ऐप को एक बार के जनरेशन से अधिक चाहिए, तब Phaseo Agent SDK का उपयोग करें:

- कई चरणों वाले टूल लूप
- स्थानीय रनटाइम टूल
- Gateway से जुड़े मॉडल टर्न
- ऐप द्वारा नियंत्रित, फिर से शुरू किया जा सकने वाला रन स्टेट
- सटीक कॉल के लिए अनुमोदन, मानव भागीदारी वाले टूल, मैन्युअल टूल और फिर से शुरू होने वाला निष्पादन
- रनटाइम सत्यापन, प्रगति बताने वाले टूल और सुधार योग्य टूल त्रुटियां
- दोबारा चलाए जा सकने वाले इवेंट कंज़्यूमर के साथ स्ट्रीम किया गया मॉडल आउटपुट
- डायनामिक टर्न कॉन्फ़िगरेशन, जोड़ी जा सकने वाली रुकने की शर्तें और सामान्यीकृत उपयोग/लागत
- मॉडल पुनःप्रयास, टूल समय-सीमाएँ, सीमित टूल समवर्तिता और लाइफ़साइकल इवेंट
- स्थानीय Phaseo Devtools कैप्चर
- मुख्य क्लाइंट SDK वाली ही भाषाओं में एकसमान अनुरोध रूटिंग

## समर्थित भाषाएं

Agent SDK की वर्तमान भाषाएं Phaseo क्विकस्टार्ट में दिए गए मुख्य क्लाइंट SDK के भाषा सेट से मेल खाती हैं:

- [TypeScript](../typescript/agent-sdk.mdx)
- [Python](../python/agent-sdk.mdx)
- [Go](../go/agent-sdk.mdx)
- [C#](../csharp/agent-sdk.mdx)
- [PHP](../php/agent-sdk.mdx)
- [Ruby](../ruby/agent-sdk.mdx)
- [Rust](../rust/agent-sdk.mdx)

## सामान्य मॉडल

हर Agent SDK एक ही रनटाइम मॉडल रखता है:

- एक एजेंट परिभाषित करें
- शून्य या अधिक स्थानीय टूल परिभाषित करें
- Gateway से जुड़ा मॉडल क्लाइंट बनाएं
- `responses` API पर सीमित लूप चलाएं
- लाइफ़साइकल इवेंट या Devtools ट्रेस देखें
- लौटे हुए रन को सहेजें और मानव निर्णय के बाद फिर से शुरू करें

TypeScript संदर्भ API डिज़ाइन है। Python, Go, C#, PHP और Ruby अपनी भाषा के मूल कॉलबैक, समवर्तिता, टाइमआउट और रद्दीकरण की बुनियादी सुविधाओं से भाषाओं के बीच का व्यापक अनुबंध उपलब्ध कराते हैं। Rust एक समर्थित सिंक्रोनस रनटाइम है, जिसमें स्थानीय और बाहरी टूल, सटीक ID वाले अनुमोदन, मानवीय समीक्षा, मॉडल पुनःप्रयास, सीरियलाइज़ किया जा सकने वाला रन स्टेट, जीवनचक्र कॉलबैक और उपयोग का एकत्रीकरण शामिल हैं। Java और C++ पर काम अभी जारी है।

<Note>
  Rust Agent SDK [`phaseo-agent`](https://crates.io/crates/phaseo-agent) के रूप में प्रकाशित है। इसमें अभी स्ट्रीमिंग, एसिंक्रोनस निष्पादन, समवर्ती स्थानीय टूल, रनटाइम स्कीमा सत्यापन या Devtools कैप्चर शामिल नहीं हैं।
</Note>

## भाषाओं के बीच क्षमता अनुबंध

| क्षमता | TypeScript | Python | Go | C# | PHP | Ruby | Rust |
| --- | --- | --- | --- | --- | --- | --- | --- |
| चलाए जा सकने वाले टूल और सुधारी जा सकने वाली टूल त्रुटियां | हाँ | हाँ | हाँ | हाँ | हाँ | हाँ | सिंक्रोनस |
| सटीक ID वाले अनुमोदन, HITL और मैन्युअल आउटपुट | हाँ | हाँ | हाँ | हाँ | हाँ | हाँ | हाँ |
| टूल की शुरुआती प्रगति | Async generator | Iterator या कॉलबैक | कॉलबैक | कॉलबैक | कॉलबैक | कॉलबैक | अभी नहीं |
| मॉडल स्ट्रीमिंग और दोबारा चलाए जा सकने वाले कंज़्यूमर | Async iterable | Iterator | Channel | Async enumerable | Iterable | Enumerator | अभी नहीं |
| जोड़ी जा सकने वाली रुकने की शर्तें | हाँ | हाँ | हाँ | हाँ | हाँ | हाँ | चरण सीमा |
| डायनामिक टर्न और बदला जा सकने वाला संदर्भ | हाँ | हाँ | हाँ | हाँ | हाँ | हाँ | प्रत्येक रन का मॉडल, चरण सीमा और संदर्भ |
| ऐप द्वारा सहेजा गया रन स्टेट | हाँ | हाँ | हाँ | हाँ | हाँ | हाँ | सीरियलाइज़ किया जा सकने वाला `RunResult` |
| सामान्यीकृत उपयोग और लागत | हाँ | हाँ | हाँ | हाँ | हाँ | हाँ | टोकन; कस्टम क्लाइंट की लागत केवल `0.1` में |

PHP और Ruby प्रदाता के स्ट्रीम इवेंट अपने सामान्य सिंक्रोनस इटरेशन API के ज़रिए उपलब्ध कराते हैं। इनके लिए होस्ट किया गया रनटाइम या पृष्ठभूमि में चलने वाली Phaseo सेवा आवश्यक नहीं है।

## क्लाइंट SDK, Agent SDK और API

| उपयोग | चुनें | इसकी ज़िम्मेदारी |
| --- | --- | --- |
| एक API अनुरोध या सभी एंडपॉइंट का पूरा कवरेज | क्लाइंट SDK | जनरेट किए गए API प्रकार और ट्रांसपोर्ट |
| टूल का उपयोग करने वाला, कई चरणों वाला ऐप्लिकेशन लॉजिक | Agent SDK | स्थानीय लूप, टूल, चेकपॉइंट, समीक्षा, इवेंट और Devtools |
| कस्टम ट्रांसपोर्ट या असमर्थित भाषा | सीधा API | HTTP अनुरोध और प्रतिक्रिया संभालना |

Agent SDK के Gateway एडाप्टर मॉडल टर्न संबंधित क्लाइंट SDK को सौंपते हैं। जिन भाषाओं में `requestOptions` या उसके समकक्ष हुक है, वे Responses API के अतिरिक्त फ़ील्ड आगे भेज सकती हैं, जबकि `model`, `input`, `instructions` और स्थानीय फ़ंक्शन टूल पर नियंत्रण Agent SDK का ही रहता है। Rust `0.1` एडाप्टर अभी अतिरिक्त अनुरोध-विकल्प हुक के बिना सामान्यीकृत एजेंट फ़ील्ड भेजता है।
