जब किसी Rust ऐप्लिकेशन को सीमित मॉडल लूप, स्थानीय टूल, अनुमोदन या फिर से शुरू की जा सकने वाली मानवीय समीक्षा की ज़रूरत हो, तो प्रकाशित [`phaseo-agent`](https://crates.io/crates/phaseo-agent) crate का उपयोग करें।

Rust Agent SDK, `phaseo` क्लाइंट पर आधारित है और Phaseo Responses API के ज़रिए मॉडल टर्न चलाता है।

## समर्थित क्षमताएँ

| क्षमता | Rust सपोर्ट |
| --- | --- |
| स्थानीय निष्पादन योग्य टूल | हाँ; मॉडल कॉल के क्रम में सिंक्रोनस रूप से चलाए जाते हैं |
| बाहरी टूल आउटपुट | हाँ; `Tool::external(...)` और `ContinueOptions` के ज़रिए |
| टूल अनुमोदन | हाँ; टूल-कॉल की सटीक ID के आधार पर |
| मानवीय समीक्षा | हाँ; सीरियलाइज़ किए जा सकने वाले रुके हुए रन स्टेट के साथ |
| मॉडल रीट्राई | हाँ; निश्चित प्रतीक्षा-अंतराल के साथ |
| लाइफ़साइकल इवेंट | हाँ; कॉलबैक-आधारित रन मेथड के ज़रिए |
| उपयोग का एकत्रीकरण | इनपुट, आउटपुट, कैश्ड और कुल टोकन; कस्टम मॉडल क्लाइंट भरता है तो लागत भी |
| रन सीमाएँ | मॉडल स्टेप की अधिकतम संख्या |
| Gateway अडैप्टर | `GatewayAgentClient` के ज़रिए Responses API |
| स्ट्रीमिंग | अभी समर्थित नहीं |
| असिंक्रोनस निष्पादन और रद्द करना | अभी समर्थित नहीं |
| समवर्ती स्थानीय टूल | अभी समर्थित नहीं |
| रनटाइम स्कीमा सत्यापन | JSON Schema मॉडल को भेजा जाता है; स्थानीय इनपुट और आउटपुट `serde_json::Value` होते हैं |
| Devtools कैप्चर | अभी समर्थित नहीं |

<Note>
Rust एक समर्थित सिंक्रोनस रनटाइम है, TypeScript स्ट्रीमिंग रनटाइम का हर सुविधा वाला पोर्ट नहीं। इस सेक्शन के पेज केवल `phaseo-agent 0.1` में उपलब्ध API बताते हैं।
</Note>

## रनटाइम मॉडल

1. मौजूदा संदेश और टूल परिभाषाएँ `ModelClient` को भेजता है
2. उपलब्ध स्थानीय टूल चलाता है
3. ज़रूरत पड़ने पर अनुमोदन, बाहरी आउटपुट या मानवीय समीक्षा के लिए रुकता है
4. परिणाम जोड़कर पूरा होने या स्टेप सीमा तक पहुँचने तक जारी रहता है

SDK, Phaseo द्वारा होस्ट की गई सेवा में रन संग्रहीत नहीं करता। यदि प्रोसेस रीस्टार्ट होने के बाद भी रन जारी रहना चाहिए, तो अपने ऐप्लिकेशन में `RunResult` सहेजें।

Gateway अडैप्टर `0.1` अभी Gateway के `cost_nanos` या `cost_cents` को `UsageSummary.cost` में मैप नहीं करता। खर्च की रिपोर्टिंग के लिए Agent SDK की लागत फ़ील्ड के बजाय Gateway रिस्पॉन्स या जनरेशन रिकॉर्ड का उपयोग करें।
