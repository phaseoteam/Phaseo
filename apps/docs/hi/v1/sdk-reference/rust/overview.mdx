Rust ऐप्लिकेशन से Phaseo Gateway पर अनुरोध भेजने के लिए प्रकाशित [`phaseo`](https://crates.io/crates/phaseo) crate का उपयोग करें।

उच्च-स्तरीय क्लाइंट ये सुविधाएँ देता है:

- `Phaseo::responses(...)` से Responses API अनुरोध
- `Phaseo::chat_completions(...)` से Chat Completions अनुरोध
- `Phaseo::post(...)` से अन्य JSON एंडपॉइंट
- `Phaseo::model_endpoint_capabilities(...)` से लाइव मॉडल रूट खोज
- `Phaseo::check_model_parameters(...)` से पैरामीटर समर्थन रिपोर्ट
- `Phaseo::from_env()` से पर्यावरण-आधारित कॉन्फ़िगरेशन
- कस्टम HTTPS एंडपॉइंट और loopback विकास सर्वर
- संरचित स्थिति, JSON बॉडी, अनुरोध ID और त्रुटि विवरण

पैरामीटर रिपोर्ट हर अनुरोधित पैरामीटर को `supported`, `partial`, `unsupported` या `unknown` चिह्नित करती है, घोषित मानों और सीमाओं की जाँच करती है और पूरे पैरामीटर सेट को स्वीकार करने वाले रूट लौटाती है।

```rust
use phaseo::Phaseo;
use serde_json::json;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Phaseo::from_env()?;
    let response = client.responses(&json!({
        "model": "openai/gpt-6-astra",
        "input": "Reply with exactly: Rust SDK works"
    }))?;

    println!("{}", response.body);
    Ok(())
}
```

<Note>
  संस्करण `0.1` समर्थित और प्रकाशित है, लेकिन `1.0` से पहले Rust API बदल सकती है। प्रोडक्शन में संगत minor version पिन करें।
</Note>

## मौजूदा दायरा

Ergonomic client synchronous है और `serde_json::Value` request bodies स्वीकार करता है। Generated low-level modules `phaseo::gen` में उपलब्ध हैं; convenience re-exports `phaseo::client`, `phaseo::models` और `phaseo::operations` में हैं।

Rust client में अभी async transport या high-level streaming helper नहीं है। ये helpers आने से पहले app को streaming चाहिए, तो raw HTTP API उपयोग करें।
