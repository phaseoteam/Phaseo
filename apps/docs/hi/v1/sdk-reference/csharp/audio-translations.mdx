**Method**: `client.CreateTranslation(...)`

### उदाहरण
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.CreateTranslation(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-4o-transcribe",
    ["audio_b64"] = "base64-audio"
});
```

### मुख्य पैरामीटर
- `model` (ज़रूरी): translation-सक्षम model ID।
- `file` (ज़रूरी): translate करने के लिए audio data।
- `prompt`: translation को दिशा देने वाला optional context।
- `temperature` (0–2): sampling randomness।
- `response_format`: `json`, `text`, `srt`, `verbose_json` आदि।

### लौटाया गया मान
`AudioTranscriptionResponse`
