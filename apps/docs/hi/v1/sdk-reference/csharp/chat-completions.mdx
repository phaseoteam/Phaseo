**Method**: `client.GenerateText(...)` या `client.CreateChatCompletion(...)`

### उदाहरण
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.GenerateText(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-5-nano",
    ["messages"] = new[]
    {
        new Dictionary<string, object>
        {
            ["role"] = "user",
            ["content"] = "Write a limerick about lighthouses."
        }
    }
});
```

### मुख्य parameters
- `model` (आवश्यक): लक्ष्य मॉडल ID।
- `messages` (आवश्यक): `system|user|assistant|tool` भूमिकाओं वाले क्रमबद्ध संदेश; सामग्री पाठ या हिस्सों में हो सकती है।
- नमूना चयन: `temperature` (0–2), `top_p` (0–1), `top_k` (>=1), `seed` (वैकल्पिक पूर्णांक)।
- लंबाई/दंड: `max_output_tokens` (पूर्णांक), `presence_penalty` और `frequency_penalty` (-2 से 2), `stop` (string|string[])।
- टूल: `tools` (परिभाषाएँ), `tool_choice` (auto/none/विशिष्ट टूल), `max_tool_calls` (पूर्णांक), `parallel_tool_calls` (बूलियन)।
- लॉग प्रायिकताएँ: `logprobs` (बूलियन), `top_logprobs` (0–20)।
- आउटपुट: `response_format` (json/text), `meta` (पास-थ्रू ऑब्जेक्ट), `stream` (बूलियन), `service_tier`।
- Gateway के अतिरिक्त विकल्प: `usage` (उपयोग आँकड़े माँगने के लिए बूलियन), `meta` (मेटा ब्लॉक शामिल करने के लिए बूलियन)।
