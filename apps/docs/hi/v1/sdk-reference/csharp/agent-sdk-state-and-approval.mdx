सामान्य checkpoint के लिए `AgentDefinition.HumanReview` उपयोग करें। approval-gated और manual tools सटीक call IDs को `Run.Pause.PendingToolCalls` में रखते हैं।

`Agent.ContinueRun(...)` से जारी रखें और ये दें:

- `Approvals` या `Rejections` में `ToolDecision` रिकॉर्ड
- आपके ऐप द्वारा किए गए काम के लिए `ToolOutput` रिकॉर्ड
- सामान्य समीक्षा विराम के लिए `HumanInput`
- पिछला `RunResult` या `IStateAccessor` के साथ `RunId`

निर्णय call ID से मिलाए जाते हैं, इसलिए एक ही tool की साथ हुई calls अलग रहती हैं।

requests या process restarts के बाद भी रन बनाए रखने के लिए `IStateAccessor.Load(...)` और `Save(...)` लागू करें। Phaseo Agent SDK रन state होस्ट नहीं करता।
