`Agent.Stream(...)` वही state machine चलाता है जो `Run(...)` चलाता है और `AgentStreamResult` लौटाता है:

```csharp
var stream = agent.Stream(new RunOptions { Input = input, Client = client });

await foreach (var delta in stream.TextStream())
{
    Console.Write(delta);
}

var completed = await stream.GetResult();
```

मॉडल, टूल, स्टेप और रन इवेंट पाने के लिए `FullStream()` उपयोग करें। अलग-अलग consumer कैप्चर की गई async sequence को स्वतंत्र रूप से दोबारा चला सकते हैं। सक्रिय रन रोकने के लिए `Cancel()` कॉल करें; cancel मॉडल अनुरोधों और स्थानीय टूल तक पहुँचता है।
