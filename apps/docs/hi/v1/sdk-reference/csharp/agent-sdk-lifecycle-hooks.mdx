---

Pass `RunOptions.OnEvent` प्रोडक्ट टाइमलाइन, ऑडिट लॉग या टेलीमेट्री पाइपलाइन अपडेट करने के लिए।

इवेंट परिवारों में रन का शुरू होना/फिर शुरू होना/समाप्ति स्थिति, मॉडल अनुरोध, स्टेप चेकपॉइंट, टूल निष्पादन और प्रगति, मानव हस्तक्षेप की प्रतीक्षा, रद्दीकरण और विफलताएँ शामिल हैं।

कॉलबैक तेज़ रखें। धीमे स्टोरेज या नेटवर्क काम को एजेंट लूप के बाहर कतार में भेजें।

```csharp
OnEvent = value => logger.LogInformation(
    "{EventType} {RunId}", value.Type, value.RunId
);
```
