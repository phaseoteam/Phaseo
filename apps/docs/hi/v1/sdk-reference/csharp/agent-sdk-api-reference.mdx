| API | उद्देश्य |
| --- | --- |
| `AgentSdk.CreateAgent(...)` | एजेंट परिभाषित करें |
| `AgentSdk.DefineTool(...)` | लोकल या मैनुअल टूल परिभाषित करें |
| `AgentSdk.CreateGatewayAgentClient(...)` | मॉडल टर्न को Phaseo से जोड़ें |
| `Agent.Run(...)` | अंतिम या रुकी हुई स्थिति तक चलाएँ |
| `Agent.Stream(...)` | दोबारा चलाई जा सकने वाली एसिंक्रोनस स्ट्रीम के साथ चलाएँ |
| `Agent.ContinueRun(...)` | सहेजी गई या रुकी हुई स्थिति से आगे जारी रखें |
| `AgentStreamResult.GetResult()` | पूरे हुए रन की प्रतीक्षा करें |
| `AgentStreamResult.TextStream()` | टेक्स्ट डेल्टा पढ़ें |
| `AgentStreamResult.FullStream()` | जीवनचक्र के सभी इवेंट पढ़ें |
| `AgentStreamResult.Cancel()` | सक्रिय रन रद्द करें |

महत्वपूर्ण रिकॉर्ड और इंटरफ़ेस में `AgentDefinition`, `RunOptions`, `RunResult`, `RunRecord`, `RunStep`, `Tool`, `ToolDecision`, `ToolOutput`, `RuntimeContext`, `IStateAccessor`, `ModelRetryConfig` और `ToolExecutionConfig` शामिल हैं।
