description: "डेवलपमेंट और डिबगिंग के लिए .NET Agent SDK रन को स्थानीय रूप से कैप्चर करें।"
---

स्थानीय JSONL कैप्चर चालू करने के लिए `AgentSdk.CreateAgentDevtools(...)` और इसे पास करें `RunOptions`.

कैप्चर की गई एंट्री में रन की स्थिति और अवधि, मॉडल/प्रोवाइडर का विवरण, अनुरोध ID, संदेश, स्टेप, टूल गतिविधि, उपयोग, लागत और संरचित त्रुटियाँ शामिल हैं।

<Warning>
एजेंट इनपुट, संदर्भ और टूल के नतीजों में संवेदनशील डेटा हो सकता है। DevTools आउटपुट को सोर्स कंट्रोल या प्रोडक्शन इमेज में न रखें।
</Warning>
