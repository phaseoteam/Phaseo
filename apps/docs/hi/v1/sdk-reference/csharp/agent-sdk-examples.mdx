| पैटर्न | संयोजन |
| --- | --- |
| टिकट की छँटाई | प्रीसेट रूटिंग, लुकअप टूल और संरचित अंतिम आउटपुट |
| कोड समीक्षा | रिपॉज़िटरी टूल, प्रगति और बदलाव से पहले अनुमति |
| रिसर्च ब्रीफ़ | प्रबंधित सर्च, स्ट्रीमिंग टेक्स्ट और लागत सीमाएँ |
| ऑपरेशन रनबुक | स्टेटस टूल, एस्केलेशन और टिकाऊ निरंतरता |

एक एजेंट और एक या दो नियतात्मक टूल से शुरुआत करें, और साइड इफेक्ट वाले काम के लिए स्पष्ट अनुमति रखें।
