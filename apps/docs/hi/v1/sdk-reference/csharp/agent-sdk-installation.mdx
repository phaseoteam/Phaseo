Agent SDK NuGet पर [`Phaseo.AgentSdk`](https://www.nuget.org/packages/Phaseo.AgentSdk) के रूप में प्रकाशित है।

## आवश्यकताएँ

- .NET 8 या नया
- Phaseo API कुंजी

## इंस्टॉलेशन

```bash
dotnet add package Phaseo.AgentSdk
```

मुख्य `Phaseo.Sdk` पैकेज निर्भरता के रूप में अपने-आप इंस्टॉल होता है।

## एन्वायरनमेंट

उदाहरण चलाने से पहले अपनी Gateway API कुंजी सेट करें:

```bash
set PHASEO_API_KEY=phaseo_v1_sk_...
```
