---

जब आगे का .NET कोड संरचित मानों की अपेक्षा करे, तो अंतिम आउटपुट की जाँच करें। जाँच में विफलता को अनुबंध त्रुटि मानें, अस्थायी ट्रांसपोर्ट विफलता नहीं। Validation failure को contract error मानें, transient transport failure नहीं।

`ModelRetryConfig` से bounded retries configure करें:

```csharp
ModelRetry = new ModelRetryConfig
{
    MaxRetries = 2,
    Backoff = TimeSpan.FromMilliseconds(250),
}
```

पूरे हुए चरण में मॉडल प्रयासों की अंतिम संख्या सुरक्षित रहती है। स्थानीय टूल विफलताएँ अलग संभाली जाती हैं और उन्हें मॉडल अनुरोध के रूप में दोबारा नहीं चलाया जाता। Local tool failures अलग संभाले जाते हैं और model requests के रूप में retry नहीं होते।

`GatewayAgentClientOptions` में संरचित प्रतिक्रिया, रूटिंग, प्रदाता, तर्क-विचार, टूल चयन, प्रॉम्प्ट कैश और अतिरिक्त अनुरोध विकल्प शामिल हैं।
