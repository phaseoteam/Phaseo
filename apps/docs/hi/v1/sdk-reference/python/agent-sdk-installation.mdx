Agent SDK PyPI पर [`phaseo-agent-sdk`](https://pypi.org/project/phaseo-agent-sdk/) के रूप में उपलब्ध है।

## आवश्यकताएँ

- Python 3.10 या नया
- Phaseo API कुंजी

## इंस्टॉलेशन

अपनी पसंद के Python पैकेज मैनेजर से Agent SDK इंस्टॉल करें:

<CodeGroup>

    ```bash title="pip"
    pip install phaseo-agent-sdk
    ```

    ```bash title="uv"
    uv add phaseo-agent-sdk
    ```

</CodeGroup>

मुख्य `phaseo` क्लाइंट डिपेंडेंसी के रूप में अपने-आप इंस्टॉल होता है।

## एनवायरनमेंट

उदाहरण चलाने से पहले अपनी Gateway API कुंजी सेट करें:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
