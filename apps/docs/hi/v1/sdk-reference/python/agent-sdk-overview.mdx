Python Agent SDK, Phaseo Gateway के लिए पूरा लोकल एजेंट रनटाइम है। इसमें रीट्राई, समानांतर टूल, टाइमआउट, मानव समीक्षा, फिर से शुरू होने वाली स्थिति, लाइफ़साइकल इवेंट और DevTools कैप्चर शामिल हैं।

इसे तब इस्तेमाल करें जब आपको चाहिए:

- हल्का और सीमित टूल लूप
- Gateway के `responses` एंडपॉइंट के अनुरोध
- पर्सिस्टेंस और ऑर्केस्ट्रेशन पर ऐप का नियंत्रण

## इसमें क्या मिलता है

- `create_agent(...)`
- `define_tool(...)`
- `create_gateway_agent_client(...)`
- Gateway के `responses` एंडपॉइंट के अनुरोध
