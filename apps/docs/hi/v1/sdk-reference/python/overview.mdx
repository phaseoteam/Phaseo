PyPI से प्रकाशित [~phaseo~](https://pypi.org/project/phaseo/) पैकेज इंस्टॉल करें।

Phaseo Python SDK फ़िलहाल Phaseo Gateway API के लिए सिंक्रोनस क्लाइंट देता है।

## सुविधाएँ

-   OpenAPI स्पेसिफ़िकेशन से जनरेट किए गए टाइप्ड अनुरोध मॉडल।
-   चैट, responses, messages, इमेज, ऑडियो, एम्बेडिंग, मॉडरेशन, फ़ाइल, बैच, जनरेशन और async वीडियो जॉब के लिए अंतर्निहित हेल्पर।
-   टेक्स्ट, responses और messages के लिए streaming हेल्पर (~stream_*~ iterators)।
- कंट्रोल-प्लेन हेल्पर से मॉडल, एंडपॉइंट और संगठन देखे जा सकते हैं; कीमतें खोजी और गणना की जा सकती हैं; API कुंजी और वर्कस्पेस का जीवनचक्र प्रबंधित किया जा सकता है; और मौजूदा कुंजी, स्वास्थ्य स्थिति, प्रदाता, क्रेडिट, गतिविधि तथा विश्लेषण की जाँच की जा सकती है।

## त्वरित उदाहरण

```python
from phaseo import Phaseo

client = Phaseo(api_key="your-api-key")

response = client.generate_response(
    {
        "model": "openai/gpt-5-nano",
        "input": "Reply with: python sdk works",
    }
)

print(response.get("id"))
```

## "इसमें क्या शामिल है"

-   `Phaseo` क्लाइंट
-   `chat.completions.create(...)` and `responses.create(...)` संगतता हेल्पर
-   रिसोर्स हेल्पर, जैसे `client.batches`, `client.videos`, `client.files`, and `client.async_jobs`
-   बैच और वीडियो लाइफ़साइकल स्ट्रीम के लिए async-job WebSocket URL हेल्पर
-   मॉडल लाइफ़साइकल हेल्पर, जैसे `get_model_deprecation_info(...)` and `validate_model(...)`
-   टेक्स्ट, responses और messages के लिए streaming iterators
-   ~phaseo.models~ में जनरेट किए गए अनुरोध/प्रतिक्रिया मॉडल
