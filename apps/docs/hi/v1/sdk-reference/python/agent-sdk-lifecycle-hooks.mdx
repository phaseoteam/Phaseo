प्रोडक्ट टाइमलाइन, ऑडिट रिकॉर्ड या मौजूदा टेलीमेट्री सिस्टम अपडेट करने के लिए `on_event` पास करें:

```python
def on_event(event):
    logger.info("%s %s", event.type, event.run_id)
```

इवेंट में रन स्थिति, मॉडल कॉल, स्टेप, चेकपॉइंट, टूल निष्पादन और प्रगति, मानव प्रतीक्षा, रद्दीकरण और विफलताएँ शामिल हैं। कॉलबैक तेज़ रखें और धीमा काम बाहरी कतार में भेजें।
