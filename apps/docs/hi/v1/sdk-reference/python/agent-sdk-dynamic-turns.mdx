मॉडल, fallback मॉडल, instructions, temperature, अधिकतम output tokens, top-p और tools fixed values या हर टर्न पर evaluate होने वाले callbacks हो सकते हैं।

जब कोई टूल आगे काम आने वाली जानकारी पाए, तो `runtime.set_context(value)` उपयोग करें। केवल तुरंत अगले model request पर लागू override के लिए `next_turn_params` उपयोग करें।

अगले टर्न के override paused state के साथ सहेजे जाते हैं, इसलिए approval checkpoint routing या sampling के निर्णय को नहीं हटाता।

जब `AgentStateAccessor` उपयोग करें, तो context को serializable रखें।
