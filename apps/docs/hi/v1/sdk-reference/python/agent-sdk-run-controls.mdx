जब downstream Python code को structured data चाहिए, तो final output validation उपयोग करें। Validation callback deterministic होने चाहिए और अंतिम मान ऐप के contract पर खरा न उतरने पर error दें।

`AgentModelRetryConfig` से सीमित retry सेट करें:

```python
retry = AgentModelRetryConfig(max_retries=2, backoff_ms=250)
```

पूरा हुआ step अंतिम model-attempt count रखता है। Tool errors की अपनी policy होती है; उन्हें model request की तरह retry नहीं किया जाता।

गेटवे क्लाइंट संरचित आउटपुट, रूटिंग, प्रदाता, तर्क-विचार, प्रबंधित टूल, प्लगइन, प्रॉम्प्ट कैश और अतिरिक्त अनुरोध विकल्प स्वीकार करता है।
