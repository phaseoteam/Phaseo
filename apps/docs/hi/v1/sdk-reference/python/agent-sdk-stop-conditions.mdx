`stop_when` के ज़रिए स्टॉप हेल्पर जोड़ें:

```python
stop_when = [
    step_count_is(12),
    max_tokens_used(40_000),
    max_cost(2),
    max_duration(60_000),
]
```

अन्य हेल्पर में `has_tool_call(...)` और `finish_reason_is(...)` शामिल हैं। लागत या टोकन सीमा के साथ भी स्टेप या अवधि की सीमा रखें, क्योंकि वे रिपोर्ट किए गए उपयोग पर निर्भर करते हैं।
