title: "फ़ाइलें"
description: "Python SDK से `/files` कॉल करें।"
---

**मेथड**: `client.upload_file()`, `client.list_files()`, `client.get_file()`, `client.get_file_content()`।

```python
uploaded = client.upload_file(
    purpose="batch",
    file="data:application/json;base64,eyJ0ZXN0Ijp0cnVlfQ==",
)
file_obj = client.get_file(uploaded["id"])
file_bytes = client.get_file_content(uploaded["id"])

print(uploaded)
print(file_obj)
print(file_bytes[:20])
```

<Note>
  SDK में `list_files()` उपलब्ध है, लेकिन `GET /files` अभी `file_list_not_supported_with_shared_gateway_key` लौटाता है
  shared gateway key के साथ। अपलोड की गई फ़ाइलों के ID सहेजें और उन्हें सीधे प्राप्त करें।
</Note>
