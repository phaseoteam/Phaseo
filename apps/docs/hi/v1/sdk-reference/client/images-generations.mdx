`POST /v1/images/generations` भेजने के लिए SDK का इमेज मेथड मॉडल और प्रॉम्प्ट के साथ कॉल करें। हर बनी हुई इमेज `data` में `url` या `b64_json` एंट्री के रूप में लौटती है।

<CodeGroup>

```typescript TypeScript
const image = await client.generateImage({
  model: "openai/gpt-image-1",
  prompt: "A lighthouse at golden hour",
  size: "1024x1024",
  n: 1,
});
```

```python Python
image = client.generate_image({

    "size": "1024x1024",
    "n": 1,

```

| भाषा | मेथड | नोट |
| --- | --- | --- |
| TypeScript | `client.generateImage(request)` | `client.streamImage()` वही अनुरोध `stream: true` के साथ भेजता है और आंशिक-इमेज इवेंट देता है। |
| Python | `client.generate_image(request)` | `client.images.generate(request)` भी यही करता है। इमेज स्ट्रीमिंग का कोई हेल्पर नहीं है। |
| Go | `client.CreateImage(ctx, req)` | `map[string]interface{}` लौटाता है। |
| C# | `client.GenerateImage(request)`, उपनाम `CreateImage` | `Dictionary<string, object>?` लौटाता है। |
| PHP | `$client->generateImage($request)`, उपनाम `createImage()` | एक array लौटाता है। |
| Ruby | `client.generate_image(...)`, उपनाम `create_image` | एक Hash लौटाता है। |
| Java | `client.createImage(request)` | `Map` या Jackson `JsonNode` लेता है; `JsonNode` लौटाता है। |
| Rust | कोई इमेज हेल्पर नहीं | `client.post("/images/generations", &request)` JSON बॉडी भेजता है और `PhaseoResponse` लौटाता है। |

## पैरामीटर

हर SDK में फ़ील्ड के नाम JSON बॉडी के फ़ील्ड ही हैं।

| फ़ील्ड | नोट |
| --- | --- |
| `model`, `prompt` | ज़रूरी। GPT Image प्रॉम्प्ट 32,000 अक्षरों तक हो सकते हैं। |
| `n` | इमेज की संख्या, `1` से `10`। |
| `size` | उदाहरण के लिए `1024x1024`, `1024x1792` या `1792x1024`; समर्थित साइज़ मॉडल पर निर्भर करते हैं। |
| `aspect_ratio`, `width`, `height` | `size` के मॉडल-निर्भर विकल्प। |
| `quality` | मॉडल-निर्भर: `dall-e-3` पर `standard` या `hd`; GPT Image मॉडलों पर `auto`, `low`, `medium` या `high`। |
| `output_format`, `output_compression` | `png`, `jpeg` या `webp`; कंप्रेशन (`0` से `100`) के लिए `jpeg` या `webp` चाहिए। |
| `background` | `transparent`, `opaque` या `auto`। ट्रांसपेरेंट के लिए `png` या `webp` चाहिए। |
| `response_format` | `url` या `b64_json`। GPT Image मॉडल इस फ़ील्ड को अस्वीकार करते हैं। |
| `style` | मॉडल-निर्भर, जैसे `dall-e-3` पर `vivid` या `natural`। GPT Image मॉडल इस फ़ील्ड को अस्वीकार करते हैं। |
| `stream`, `partial_images` | TypeScript में `streamImage()` से `3` तक आंशिक इमेज स्ट्रीम करें। |
| `user` | दुरुपयोग ट्रैक करने के लिए एंड-यूज़र टैग। |

पूरा स्कीमा [Image generations API संदर्भ](../../api-reference/endpoint/images-generations) में है।

## प्रतिक्रिया

`ImagesGenerationResponse`:

```json
{
  "data": [
    {
      "url": "https://example.com/generated_image.png"
    }
  ]
}
```

जो मॉडल इमेज बाइट लौटाते हैं, वे उन्हें `url` की जगह `b64_json` में रखते हैं।
