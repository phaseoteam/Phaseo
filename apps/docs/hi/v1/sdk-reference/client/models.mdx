वैकल्पिक फ़िल्टर के साथ `GET /v1/models` से मॉडल कैटलॉग पढ़ने के लिए SDK का list मेथड कॉल करें।

<CodeGroup>

```typescript TypeScript
const models = await client.getModels({
  provider: ["anthropic"],
  provider_status: ["beta", "not_ready"],
  provider_availability_reason: ["preview_only", "provider_not_ready"],
  capability_status: ["coming_soon", "internal_testing"],
  availability: "all",
});
```

```python Python
models = client.get_models({
    "provider": ["anthropic"],
    "provider_status": ["beta", "not_ready"],
    "provider_availability_reason": ["preview_only", "provider_not_ready"],
    "capability_status": ["coming_soon", "internal_testing"],
    "availability": "all",
})
```

```go Go
client, err := phaseo.NewFromEnv()
if err != nil {
  panic(err)
}

  "capability_status":            "coming_soon,internal_testing",
  "availability":                 "all",
  "limit":                        "10",
})

  panic(err)
}

```

| Python | `client.get_models(filters)` या `client.models.list(filters)` | List |
| Go | `map[string]string` के साथ `client.GetModels(ctx, query)` | कॉमा से अलग की गई स्ट्रिंग |
| C# | `Dictionary<string, string>` के साथ `client.ListModels(query)` | कॉमा से अलग की गई स्ट्रिंग |
| PHP | `$client->listModels($params)` | कॉमा से अलग की गई स्ट्रिंग |
| Ruby | `client.list_models(...)` | कॉमा से अलग की गई स्ट्रिंग |
| Java | `Map<String, String>` के साथ `client.listModels(query)` | कॉमा से अलग की गई स्ट्रिंग |
| Rust | कोई हेल्पर नहीं; `client.request("GET", "/models?<filters>", None, &RequestOptions::default())` कॉल करें | query string में कॉमा से अलग की गई स्ट्रिंग |

## सूची फ़िल्टर करें

सभी फ़िल्टर वैकल्पिक हैं और हर SDK में उनके नाम एक जैसे हैं: ये क्वेरी पैरामीटर हैं।

| फ़िल्टर | किस आधार पर फ़िल्टर करता है |
| --- | --- |
| `provider`, `organisation` | प्रदाता या मॉडल का संगठन |
| `endpoints`, `input_types`, `output_types`, `params` | समर्थित एंडपॉइंट, मोडैलिटी और अनुरोध पैरामीटर |
| `status`, `provider_status`, `provider_routing_status`, `model_routing_status`, `capability_status`, `provider_availability_status`, `provider_availability_reason` | लाइफ़साइकल और रूटिंग की स्थिति |
| `availability` | जिन मॉडलों को रूट नहीं किया जा सकता, उन्हें शामिल करने के लिए `all` सेट करें |
| `limit`, `offset` | पेजिंग |

डिफ़ॉल्ट रूप से सूची में सिर्फ़ रूट किए जा सकने वाले मॉडल होते हैं। बाकी को शामिल करने के लिए `availability` को `all` पर सेट करें, फिर सूची को सीमित करें:

- `provider_availability_reason` रोलआउट की स्थितियाँ चुनता है, जैसे `preview_only`, `provider_not_ready`, `gated`, `access_limited`, `region_limited`, `project_limited`, `paused` या `soft_blocked`।
- `capability_status` उन एंडपॉइंट मैपिंग को चुनता है जो अभी रूट नहीं की जा सकतीं, जैसे `coming_soon` या `internal_testing`।

## एक मॉडल जाँचें

`checkParameters` और इसके समकक्ष लाइव प्रदाता-रूट मेटाडेटा पढ़ते हैं, हर पैरामीटर को `supported`, `partial`, `unsupported` या `unknown` चिह्नित करते हैं, घोषित वैल्यू और रेंज जाँचते हैं, और वे प्रदाता रूट लौटाते हैं जो पूरा सेट स्वीकार करते हैं। `preflight` पूरी अनुरोध बॉडी के लिए यही करता है और मॉडल की लाइफ़साइकल जाँच जोड़ता है, साथ में एक समग्र `ok` देता है।

| भाषा | क्षमताएँ | पैरामीटर जाँचें | Preflight | लाइफ़साइकल |
| --- | --- | --- | --- | --- |
| TypeScript | `models.capabilities(modelId)` | `models.checkParameters(modelId, values, { endpoint, provider })` | `models.preflight(request, { endpoint, provider })` | `models.validate(modelId)` `{ ok, info, reason }` लौटाता है; `models.getDeprecationInfo(modelId)` |
| Python | `models.capabilities(model_id)` | `models.check_parameters(model_id, values, endpoint=..., provider=...)` | `models.preflight(request, endpoint=..., provider=...)` | `models.validate(model_id)`, `models.get_deprecation_info(model_id)` |
| Go (अगली रिलीज़) | `GetModelEndpointCapabilities` | `CheckModelParameters` | `PreflightRequest` | `ValidateModel`, `GetModelDeprecationInfo` (प्रकाशित) |
| C# (अगली रिलीज़) | `GetModelEndpointCapabilities(modelId)` | `CheckModelParameters(modelId, values)` | `PreflightRequest` | `ValidateModel`, `GetModelDeprecationInfo` (प्रकाशित) |
| PHP (अगली रिलीज़) | `getModelEndpointCapabilities` | `checkModelParameters(...)` | `preflightRequest` | `validateModel`, `getModelDeprecationInfo` (प्रकाशित) |
| Ruby (अगली रिलीज़) | `model_endpoint_capabilities` | `check_model_parameters(model_id, values)` | `preflight_request` | `validate_model`, `get_model_deprecation_info` (प्रकाशित) |
| Java (सोर्स बिल्ड) | `getModelEndpointCapabilities(modelId, query)` | `checkModelParameters(modelId, values, options)` | `preflightRequest(request, options)` | `validateModel`, `getModelDeprecationInfo` |
| Rust (`0.2.0` में नहीं) | `Phaseo::model_endpoint_capabilities(...)` | `Phaseo::check_model_parameters(...)` | कोई नहीं | कोई नहीं |

"अगली रिलीज़" का मतलब है कि मेथड SDK के सोर्स में है, लेकिन प्रकाशित पैकेज में नहीं; देखें [हर पैकेज में क्या शामिल है, जाँचें](./overview#check-what-each-package-ships)। deprecation-info मेथड मॉडल की स्थिति (`active`, `deprecated` या `retired`), deprecation और retirement की तारीख़ें, और बदले जाने वाले मॉडल की ID लौटाते हैं।
