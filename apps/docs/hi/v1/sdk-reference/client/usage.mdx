नीचे का हर सेक्शन हर एंडपॉइंट का एक छोटा उदाहरण है। अगर किसी सेक्शन में कोई भाषा नहीं है, तो उसके SDK में उस एंडपॉइंट का कोई रैपर नहीं है; [मेथड तालिका](./overview#find-the-method-for-each-endpoint) विकल्प दिखाती है। इस सेक्शन के एंडपॉइंट पेज हर पैरामीटर की सूची देते हैं।

## ऑडियो

ट्रांसक्रिप्शन और अनुवाद multipart अपलोड लेते हैं। TypeScript `FormData` बॉडी को multipart के रूप में भेजता है। Python, Go, C#, PHP और Ruby के मेथड JSON भेजते हैं, इसलिए ट्रांसक्रिप्शन सिर्फ़ तब काम करता है जब URL किसी ऐसे मॉडल को दिया जाए जो `file_url` स्वीकार करता है, और अनुवाद के लिए multipart अपलोड चाहिए। उन SDK से ऑडियो फ़ाइल अपलोड करने के लिए देखें [STT (स्पीच से टेक्स्ट)](./audio-transcriptions#upload-an-audio-file) और [अनुवाद](./audio-translations)।

<CodeGroup>

```typescript TypeScript
import { readFile } from "node:fs/promises";

const speech = await client.generateSpeech({
  model: "openai/gpt-4o-mini-tts",
  input: "Hello world",
});

// ट्रांसक्रिप्शन और अनुवाद multipart अपलोड लेते हैं।
const form = new FormData();
form.append("model", "openai/gpt-4o-transcribe");
form.append("file", new Blob([await readFile("call.mp3")], { type: "audio/mpeg" }), "call.mp3");
const transcript = await client.generateTranscription(form as unknown as Record<string, unknown>);
```

```python Python
speech = client.generate_speech(
    {"model": "openai/gpt-4o-mini-tts", "input": "Hello world"}

# generate_transcription JSON भेजता है, इसलिए file_url स्वीकार करने वाले मॉडल को URL दें।
transcription = client.generate_transcription(
    {"model": "mistral/voxtral-mini-transcribe-2", "file_url": "https://example.com/call.mp3"}
)
```

```go Go

```

```csharp C#
    ["model"] = "openai/gpt-4o-mini-tts",
    ["input"] = "Hello from .NET",
});
```

```php PHP
    'model' => 'openai/gpt-4o-mini-tts',
```

## त्रुटियाँ संभालें

<CodeGroup>

```typescript TypeScript
import { PhaseoHttpError } from "@phaseo/sdk";

try {
  await client.generateText({ model: "invalid", messages: [{ role: "user", content: "Hi" }] });
} catch (error) {
  if (error instanceof PhaseoHttpError) {
    console.error(error.status, error.code, error.requestId, error.traceUrl);
  } else {
    throw error;
  }
}
```

```python Python
from phaseo import PhaseoHTTPError

try:
    client.generate_text({"model": "invalid", "messages": [{"role": "user", "content": "Hi"}]})
except PhaseoHTTPError as error:
    print(error.status, error.code, error.request_id, error.trace_url)
```

```java Java
import app.phaseo.gen.Client;
import app.phaseo.sdk.Phaseo;
import java.time.Duration;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"))
    .setTimeout(Duration.ofSeconds(30))
    .setMaxRetries(2);

try {
    var result = client.requestWithResponse("GET", "/models",
        Map.of("limit", "5"), null, null, null);
    System.out.println(result.requestId());
    System.out.println(result.data);
} catch (Client.ApiException error) {
    System.err.println(error.getStatusCode());
    System.err.println(error.getRequestId());
    System.err.println(error.getResponseBody());
}
```

```rust Rust
let request = serde_json::json!({
    "model": "openai/gpt-6-astra",
    "input": "Handle this request"
});

match client.responses(&request) {
    Ok(response) => println!("{}", response.body),
    Err(error) => {
        eprintln!("message: {}", error.message);
        eprintln!("status: {:?}", error.status);
        eprintln!("body: {:?}", error.body);
    }
}
```

</CodeGroup>

जब Gateway ने त्रुटि लौटाई हो, तो `PhaseoError` (Rust) में एक HTTP स्टेटस और पार्स की गई JSON बॉडी होती है; ट्रांसपोर्ट और कॉन्फ़िगरेशन विफलताओं में कोई स्टेटस नहीं होता। [परिचय](./overview#request-controls-and-errors) हर SDK के त्रुटि फ़ील्ड की सूची देता है।
