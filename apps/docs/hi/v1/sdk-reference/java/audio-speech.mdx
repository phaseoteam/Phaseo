icon: "music"
title: "TTS (टेक्स्ट से वाणी)"
description: "Java SDK से `/audio/speech` कॉल करें।"
---

**मेथड**: `client.rawClient().requestBytes(...)`

```java
import app.phaseo.sdk.Phaseo;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

String body = """
{
  "model": "openai/gpt-4o-mini-tts",
  "input": "Hello from Java",
  "voice": "alloy",
  "response_format": "mp3"
}
""";

byte[] audio = client.rawClient().requestBytes("POST", "/audio/speech", null, null, body);
java.nio.file.Files.write(java.nio.file.Path.of("speech.mp3"), audio);
```
