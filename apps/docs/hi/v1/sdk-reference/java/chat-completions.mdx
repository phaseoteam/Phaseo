**मेथड**: `client.createChatCompletion(...)`

```java
import app.phaseo.sdk.Phaseo;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

String body = """
{
  "model": "openai/gpt-5-nano",
  "messages": [
    { "role": "user", "content": "Write a one-line haiku." }
  ]
}
""";

Object response = client.createChatCompletion(new com.fasterxml.jackson.databind.ObjectMapper().readTree(body));
System.out.println(String.valueOf(response));
```

## स्ट्रीमिंग

`streamResponse` और `rawClient().requestLines` SSE लाइनें आते ही लौटाते हैं। try-with-resources से स्ट्रीम बंद करें और अपने ऐप में इवेंट नाम, डेटा लाइनें और पूर्ण होने के संकेत संभालें।

```java
import app.phaseo.sdk.Phaseo;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.List;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));
var payload = Map.of(
    "model", "openai/gpt-6-astra",
    "messages", List.of(Map.of("role", "user", "content", "Hello")),
    "stream", true
);
try (var lines = client.rawClient().requestLines(
    "POST", "/chat/completions", null, null,
    new ObjectMapper().writeValueAsString(payload)
)) {
    lines.forEach(System.out::println);
}
```
