description: "विकास और डीबगिंग के लिए Java Agent SDK रन को स्थानीय रूप से कैप्चर करें।"
---

`AgentSdk.createAgentDevtools(...)` से स्थानीय रन कैप्चर चालू करें:

```java
var devtools = AgentSdk.createAgentDevtools(".phaseo-devtools");
```

यह मान `RunOptions` के ज़रिए दें। कैप्चर की गई JSONL प्रविष्टियों में रन की स्थिति और अवधि, मॉडल व प्रदाता का विवरण, अनुरोध ID, संदेश, चरण, टूल गतिविधि, उपयोग, लागत और संरचित त्रुटियाँ शामिल होती हैं।

<Warning>
एजेंट के इनपुट, संदेश, कॉन्टेक्स्ट और टूल परिणामों में संवेदनशील डेटा हो सकता है। DevTools डायरेक्टरी को सोर्स कंट्रोल और प्रोडक्शन इमेज से बाहर रखें।
</Warning>
