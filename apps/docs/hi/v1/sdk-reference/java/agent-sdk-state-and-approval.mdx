सामान्य चेकपॉइंट के लिए `AgentDefinition.humanReview` से `HumanReviewRequest` लौटाएँ। टूल अनुमोदन और मैन्युअल काम के सटीक कॉल ID रोके गए परिणाम में रखे जाते हैं।

`Agent.continueRun(...)` के साथ जारी रखें और ये दें:

- अनुमोदन या अस्वीकृति में `ToolDecision` प्रविष्टियाँ
- मैन्युअल टूल के लिए `ToolOutput` प्रविष्टियाँ
- सामान्य समीक्षा विराम के लिए मानवीय इनपुट
- सीरियलाइज़ किया गया `RunResult`, या `StateAccessor` पर आधारित रन ID

SDK, होस्ट की गई Agent SDK स्थिति पर निर्भर नहीं है। यदि रन को अनुरोधों या सेवा के पुनरारंभ के बाद भी बने रहना है, तो `StateAccessor` लागू करें।
