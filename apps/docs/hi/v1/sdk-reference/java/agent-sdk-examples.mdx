इनमें से किसी एक पैटर्न से शुरुआत करें:

| पैटर्न | संयोजन |
| --- | --- |
| सहायता अनुरोध की छँटाई | प्रबंधित प्रीसेट, खोज उपकरण, संरचित अंतिम आउटपुट |
| कोड समीक्षा | फ़ाइल या पैच उपकरण, प्रगति घटनाएँ, संपादन से पहले अनुमोदन |
| अनुसंधान संक्षेप | प्रबंधित वेब उपकरण, लागत और चरणों की सीमाएँ, स्ट्रीम किया गया पाठ |
| संचालन पुस्तिका | स्थिति उपकरण, मैन्युअल एस्केलेशन, टिकाऊ निरंतरता |

पहला implementation सीमित रखें: एक agent, एक या दो deterministic tools और side effects के लिए स्पष्ट approval।
