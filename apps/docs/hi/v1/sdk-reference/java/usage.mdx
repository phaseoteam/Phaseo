## सेटअप

```java
import app.phaseo.sdk.Phaseo;

String apiKey = System.getenv("PHASEO_API_KEY");
Phaseo client = new Phaseo(apiKey);
```

## पैटर्न

आम wrapper calls इस तरह दिखते हैं:

```java
Object response = client.createChatCompletion("""
{
  "model": "openai/gpt-5-nano",
  "messages": [
    { "role": "user", "content": "Say hello from Java" }
  ]
}
""");
```

अधिकांश JSON एंडपॉइंट पर रैपर मेथड पार्स किए गए JSON नोड लौटाते हैं; फ़ाइल और वीडियो सामग्री के हेल्पर बाइट ऐरे लौटाते हैं।

## सुझाव

- Gateway के आम कामों के लिए पहले `app.phaseo.sdk.Phaseo` उपयोग करें।
- जब wrapper में अभी शामिल न किया गया low-level operation चाहिए, तभी `app.phaseo.gen.Client` और `app.phaseo.gen.Operations` का उपयोग करें।
- Wrapper method names के लिए इस section में endpoint-specific examples से शुरुआत करें।
