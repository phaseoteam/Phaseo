```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

JSON अनुरोधों के लिए `createResponse`, `createChatCompletion`, `createEmbedding` और `listModels` इस्तेमाल करें। `Map` या `JsonNode` दें; JSON स्ट्रिंग को क्लाइंट मेथड में देने से पहले पार्स करें।

## रीट्राई और त्रुटियाँ

डिफ़ॉल्ट रूप से रीट्राई बंद हैं। `setMaxRetries` सुरक्षित GET/HEAD अनुरोध दोहराता है; लिखने वाले और स्ट्रीमिंग अनुरोध दोबारा नहीं भेजे जाते। HTTP त्रुटियों में `Client.ApiException` से स्टेटस, बॉडी, हेडर और अनुरोध ID मिलते हैं।

```java
import app.phaseo.gen.Client;
import app.phaseo.sdk.Phaseo;
import java.time.Duration;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"))
    .setTimeout(Duration.ofSeconds(30))
    .setMaxRetries(2);

try {
    var result = client.requestWithResponse("GET", "/models",
        Map.of("limit", "5"), null, null, null);
    System.out.println(result.requestId());
    System.out.println(result.data);
} catch (Client.ApiException error) {
    System.err.println(error.getStatusCode());
    System.err.println(error.getRequestId());
    System.err.println(error.getResponseBody());
}
```

## स्ट्रीमिंग

`streamResponse` और `rawClient().requestLines` SSE लाइनें आते ही लौटाते हैं। try-with-resources से स्ट्रीम बंद करें और अपने ऐप में इवेंट नाम, डेटा लाइनें और पूर्ण होने के संकेत संभालें।

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));
try (var lines = client.streamResponse(Map.of(
    "model", "openai/gpt-6-astra", "input", "Hello"
))) {
    lines.forEach(System.out::println);
}
```
