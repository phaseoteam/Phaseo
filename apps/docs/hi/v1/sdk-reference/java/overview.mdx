Java SDK से टेक्स्ट, एम्बेडिंग और मॉडल सूची के अनुरोध भेजें।

<Note>वर्तमान सोर्स में रीट्राई नियंत्रण और रिस्पॉन्स मेटाडेटा हैं, जो Maven Central के पुराने 3.0.0 आर्टिफ़ैक्ट में नहीं हैं। वर्तमान SDK के लिए नीचे दिए गए रिविज़न को बिल्ड करें। [इंस्टॉलेशन](./installation)</Note>

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

## समर्थित अनुरोध

JSON अनुरोधों के लिए `createResponse`, `createChatCompletion`, `createEmbedding` और `listModels` इस्तेमाल करें। `Map` या `JsonNode` दें; JSON स्ट्रिंग को क्लाइंट मेथड में देने से पहले पार्स करें।

## स्ट्रीमिंग

`streamResponse` और `rawClient().requestLines` SSE लाइनें आते ही लौटाते हैं। try-with-resources से स्ट्रीम बंद करें और अपने ऐप में इवेंट नाम, डेटा लाइनें और पूर्ण होने के संकेत संभालें।

<Note>`createSpeech` मेथड JSON की अपेक्षा करता है और बाइनरी ऑडियो डिकोड नहीं कर सकता। ऑडियो आउटपुट के लिए `rawClient().requestBytes` इस्तेमाल करें।</Note>
