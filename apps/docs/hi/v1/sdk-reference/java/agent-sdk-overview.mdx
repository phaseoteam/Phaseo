<Note type="warning">
  Java Client SDK और Agent SDK अभी विकासाधीन हैं और Maven Central से उपलब्ध नहीं हैं।
</Note>

Java Agent SDK, Java Client SDK पर बना स्रोत-आधारित रनटाइम है। इसका मुख्य अनुबंध TypeScript Agent SDK जैसा है:

- सीमित, कई चरणों वाला टूल लूप
- हर टूल के लिए समय-सीमा वाले समवर्ती टूल
- मॉडल के पुनःप्रयास और बैकऑफ़
- मानवीय समीक्षा के लिए विराम और फिर से शुरू किए जा सकने वाले रन रिकॉर्ड
- जीवनचक्र इवेंट और Phaseo DevTools का JSONL कैप्चर
- Java Client SDK पर आधारित Gateway अडैप्टर

रन आपके ऐप के भीतर रहते हैं। Phaseo मॉडल अनुरोधों को संभालता है; आपकी सेवा डेटा को स्थायी रूप से सहेजने, कतारों, प्राधिकरण और समीक्षा इंटरफ़ेस को संभालती है।
