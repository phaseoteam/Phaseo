वर्तमान सोर्स में रीट्राई नियंत्रण और रिस्पॉन्स मेटाडेटा हैं, जो Maven Central के पुराने 3.0.0 आर्टिफ़ैक्ट में नहीं हैं। वर्तमान SDK के लिए नीचे दिए गए रिविज़न को बिल्ड करें।

## आवश्यकताएँ

- Java 17+
- Maven 3.8+
- Git

## सोर्स से बिल्ड करें

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
git checkout 1ff1119f41ceb3ac2c85ed605f6e1c4beca6e011
mvn -f packages/sdk/sdk-java/pom.xml -DskipTests install
```

Maven स्थानीय रिपॉज़िटरी में Jackson डिपेंडेंसी सहित `app.phaseo:phaseo-sdk:3.0.0` इंस्टॉल करता है।

## डिपेंडेंसी जोड़ें

```xml
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-sdk</artifactId>
  <version>3.0.0</version>
</dependency>
```

<Note>[Maven Central आर्टिफ़ैक्ट](https://repo.maven.apache.org/maven2/app/phaseo/phaseo-sdk/3.0.0/) पुरानी API देता है। इसमें वर्तमान रीट्राई, मेटाडेटा या पैरामीटर जाँच API नहीं हैं।</Note>
