एजेंट को प्रोडक्ट टाइमलाइन, ऑडिट लॉग या telemetry pipeline से जोड़ने के लिए `RunOptions` में event consumer दें:

```java
event -> logger.info("{} {}", event.type(), event.runId())
```

इवेंट के समूह:

- रन का शुरू होना, फिर से शुरू होना, मानवीय इनपुट की प्रतीक्षा, पूरा होना, रद्द होना और विफल होना
- स्टेप का शुरू होना, checkpoint, पूरा होना, रद्द होना और विफल होना
- मॉडल अनुरोध, पूरा होना और विफल होना
- टूल का शुरू होना, शुरुआती प्रगति, पूरा होना और विफल होना

callback को तेज़ रखें। धीमे स्टोरेज या नेटवर्क काम को रनटाइम लूप के बाहर queue में भेजें।
