---

**Method**: `$client->listModels(...)`

### उदाहरण
```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo($apiKey);

$models = $client->listModels([
    'provider' => 'anthropic',
    'provider_status' => 'beta,not_ready',
    'provider_availability_reason' => 'preview_only,provider_not_ready',
    'capability_status' => 'coming_soon,internal_testing',
    'availability' => 'all',
    'limit' => 5,
]);
echo "Found " . count($models['models'] ?? []) . " models\n";
```

### पैरामीटर
- वैकल्पिक फ़िल्टर: `provider`, `provider_status`, `provider_routing_status`, `model_routing_status`, `capability_status`, `provider_availability_status`, `provider_availability_reason`, `status`, `organisation`, `endpoints[]`, `input_types[]`, `output_types[]`, `params[]`, `availability`, `limit`, `offset`।
- `provider_availability_reason`, `availability=all` के साथ `preview_only`, `provider_not_ready`, `gated`, `access_limited`, `region_limited`, `project_limited`, `paused` या `soft_blocked` जैसी rollout states देखने में उपयोगी है।
- `capability_status`, `availability=all` के साथ `coming_soon` या `internal_testing` जैसी non-routable endpoint mappings देखने में उपयोगी है।
