`Agent::stream(...)` एक `AgentStreamResult` लौटाता है:

```php
$stream = $agent->stream($input, $client);

foreach ($stream->textStream() as $delta) {
    echo $delta;
}

$completed = $stream->result;
```

अन्य projection के लिए `reasoningStream()`, `itemStream()` या `fullStream()` उपयोग करें। provider के synchronous stream से इवेंट पढ़ लेने के बाद भी हर iterable को दोबारा चलाया जा सकता है।

PHP item वैल्यू सामान्य array और object ही रहती हैं; वे TypeScript का discriminated item union नहीं हैं।
