---

टूल टाइमलाइन, अनुमोदन इंटरफ़ेस और रन इंस्पेक्टर बनाते समय DevTools कैप्चर चालू करें।

```php
$result = $agent->run(
    input: $prompt,
    client: $client,
    devtools: AgentSdk::createAgentDevtools(".phaseo-devtools")
);
```

हर रन और कंटिन्यूएशन एक संरचित JSONL रिकॉर्ड लिखता है, जिसमें स्थिति, उपयोग, मॉडल प्रयास, टूल कॉल, विराम, अनुरोध मेटाडेटा और त्रुटियाँ शामिल होती हैं।

स्थानीय कैप्चर विकास में सहायता के लिए है, प्रोडक्शन ऑडिट स्टोर नहीं। संवेदनशील सामग्री सहेजने से पहले अपने ऐप्लिकेशन के अनुसार गोपनीय अंश छिपाने, पहुँच नियंत्रण, एन्क्रिप्शन और डेटा प्रतिधारण के नियम लागू करें।
