**तरीका**: `$client->generateImageEdit(...)` या `$client->createImageEdit(...)`

### उदाहरण

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo(getenv('PHASEO_API_KEY'));
$response = $client->generateImageEdit([
    'model' => 'openai/gpt-image-1',
    'prompt' => 'Make it sunset',
    'image' => 'data:image/png;base64,...',
    'mask' => 'data:image/png;base64,...'
]);
echo $response['data'][0]['url'] ?? '';
```

### मुख्य पैरामीटर

-   `model` (ज़रूरी): image-edit सक्षम model ID।
-   `image` (ज़रूरी): source image का Base64 data URL या URL।
-   `prompt`: edit के लिए वैकल्पिक नया निर्देश।
-   `mask`: वैकल्पिक mask (पारदर्शी हिस्सों का संपादन होता है)।
-   `n` (1–10): संपादित variants की संख्या।
-   `size`: जैसे `1024x1024`, `1024x1792` या `1792x1024`।
-   `response_format`: `url` या `b64_json`।
-   `user`: अंतिम उपयोगकर्ता के लिए वैकल्पिक टैग।
