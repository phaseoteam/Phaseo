सामान्य checkpoint के लिए `AgentDefinition::$humanReview` उपयोग करें। approval-gated और manual tools सटीक call IDs को `$result->run->pause->pendingToolCalls` में रखते हैं।

`Agent::continueRun(...)` से जारी रखें और यह दें:

- approval या rejection के लिए `ToolDecision` वैल्यू
- मैन्युअल काम के लिए `ToolOutput` वैल्यू
- सामान्य समीक्षा विराम के लिए मानवीय input

जब ऐप को storage से रन दोबारा लोड करना हो, तब `StateAccessor` के साथ `continueRunById(...)` उपयोग करें। निर्णय tool name के बजाय call ID से मिलाए जाते हैं।
