Agent SDK इस नाम से प्रकाशित है [`phaseo/agent-sdk`](https://packagist.org/packages/phaseo/agent-sdk) Packagist पर।

## आवश्यकताएँ

- PHP 8.1 या नया
- Composer
- Phaseo API कुंजी

## इंस्टॉलेशन

```bash
composer require phaseo/agent-sdk
```

मुख्य `phaseo/sdk` पैकेज डिपेंडेंसी के रूप में अपने आप इंस्टॉल होता है।

## एनवायरनमेंट

उदाहरण चलाने से पहले अपनी Gateway API कुंजी सेट करें:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
