**Method**: `$client->generateImage(...)`

### उदाहरण

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo(getenv('PHASEO_API_KEY'));
$response = $client->generateImage([
    'model' => 'openai/gpt-image-1',
    'prompt' => 'A lighthouse at golden hour',
    'size' => '1024x1024',
    'n' => 1,
    'response_format' => 'url'
]);
echo $response['data'][0]['url'] ?? '';
```

### मुख्य पैरामीटर

- `model` (ज़रूरी): image-capable model ID (जैसे `openai/gpt-image-1`)।
- `prompt` (ज़रूरी): text prompt।
- `n` (1–10): जनरेट की जाने वाली images की संख्या।
- `size`: जैसे `1024x1024`, `1024x1792`, `1792x1024`।
- `quality`: `standard` या `hd` (model पर निर्भर)।
- `style`: जैसे `vivid` या `natural` (model पर निर्भर)।
- `response_format`: `url` या `b64_json`।
- `user`: सुरक्षा और दुरुपयोग की निगरानी के लिए अंतिम उपयोगकर्ता का वैकल्पिक टैग।
