---

स्ट्रीम परिणाम टेक्स्ट और संरचित इवेंट के लिए ऐसे कंज़्यूमर देता है जिन्हें दोबारा चलाया जा सकता है।

```php
$stream = $agent->stream(input: $prompt, client: $client);

foreach ($stream->itemStream() as $item) {
    renderItem($item);
}

$result = $stream->getResult();
```

अगर UI को प्रदाता आइटम के साथ रीज़निंग डेल्टा, टूल की प्रगति, अनुमोदन चेकपॉइंट या लाइफ़साइकल बदलाव भी चाहिए, तो पूरी इवेंट स्ट्रीम इस्तेमाल करें।

<Note>
PHP में आइटम मान सामान्य ऐरे या ऑब्जेक्ट होते हैं, टाइप किए गए आइटम का बंद यूनियन नहीं। आपका UI जिन फ़ील्ड का उपयोग करता है, उन्हें सत्यापित करें और नए प्रदाता इवेंट के लिए अज्ञात आइटम का फ़ॉलबैक बनाए रखें।
</Note>

PHP प्रदाता स्ट्रीम को सिंक्रोनस रूप से पढ़ता है और एकत्रित अनुक्रम को दोबारा चलाने योग्य बनाता है। यह अनुरोध वर्कर और CLI प्रोग्राम के लिए उपयुक्त है, लेकिन अपने आप में कोई बैकग्राउंड पुश चैनल नहीं है।
