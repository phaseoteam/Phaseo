## अनुमोदन के साथ डिप्लॉयमेंट

```php
$deploy = new Tool(
    id: "deploy",
    description: "Deploy the selected release",
    requireApproval: true,
    execute: fn (array $input, $runtime) => $deployments->deploy($input)
);
```

Run के `waiting_for_human` में पहुँचने पर उसे सहेजें, फिर pending call ID से जुड़ा निर्णय देकर जारी रखें।

## टेक्स्ट स्ट्रीम करें

```php
$stream = $agent->stream(input: $prompt, client: $client);
foreach ($stream->textStream() as $delta) { echo $delta; }
$result = $stream->getResult();
```

## स्वायत्त काम सीमित करें

Step, token, cost और duration limits मिलाएँ, ताकि उपयोगी काम मिलता रहने पर भी agent application budget से आगे न जाए।
