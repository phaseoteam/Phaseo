`generateImage` में `phaseo.imageModel(modelId)` पास करें। अनुरोध Gateway के `/v1/images/generations` एंडपॉइंट पर जाते हैं।

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateImage } from "ai";

const result = await generateImage({
  model: phaseo.imageModel("openai/gpt-image-1"),
  prompt: "A minimalist poster of a lighthouse at dawn.",
  size: "1024x1024",
});

console.log(result.images[0].mediaType);
console.log(result.images[0].uint8Array.length);
console.log(result.providerMetadata);
```

## नतीजा पढ़ें

Gateway जो इमेज URLs के रूप में लौटाता है, वे AI SDK के file आकार में बदल दी जाती हैं, इसलिए प्रदाता ने चाहे जो लौटाया हो, हर इमेज पर `uint8Array` और `mediaType` पढ़ें।

- उपलब्ध `size` मान मॉडल पर निर्भर करते हैं।
- किसी इमेज को बाद में दोबारा बनाने के लिए prompt, मॉडल और पैरामीटर को इमेज के metadata के साथ सहेजें।
