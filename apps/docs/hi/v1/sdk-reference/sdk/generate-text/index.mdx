एक पूरी प्रतिक्रिया पाने के लिए `phaseo(modelId)` के साथ `generateText` कॉल करें।

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a concise summary of Phaseo Gateway.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

## चैट इतिहास भेजें

एक टर्न के लिए `prompt` का उपयोग करें, और जब कई टर्न या system role चाहिए, तब `messages` का।

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "system", content: "You are a terse assistant." },
    { role: "user", content: "Give me three bullet points on retrieval augmentation." },
  ],
});

console.log(result.text);
console.log(result.providerMetadata);
```

## मॉडल पर डिफ़ॉल्ट सेट करें

सेटिंग को `phaseo()` के दूसरे argument के रूप में पास करें। ये इस मॉडल instance का उपयोग करने वाली हर कॉल पर लागू होती हैं।

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra", {
    maxTokens: 300,
  }),
  prompt: "Draft a release note for an API update.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

मॉडल IDs `provider/model` रूप में होते हैं। उन्हें अद्यतन रखने के लिए `/v1/models` से पढ़ें; [मॉडल खोज](/hi/v1/sdk-reference/sdk/get-models) देखें।
