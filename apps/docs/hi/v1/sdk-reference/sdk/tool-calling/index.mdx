AI SDK के `tool()` helper से टूल परिभाषित करें, उन्हें `generateText` में पास करें, और `stopWhen` सेट करें ताकि टूल चलने के बाद मॉडल जवाब दे सके।

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, stepCountIs, tool } from "ai";
import { z } from "zod";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "What is 17 + 25? Use the calculator tool.",
  tools: {
    calculator: tool({
      description: "Perform basic arithmetic",
      inputSchema: z.object({
        operation: z.enum(["add", "subtract", "multiply", "divide"]),
        a: z.number(),
        b: z.number(),
      }),
      execute: async ({ operation, a, b }) => {
        if (operation === "add") return a + b;
        if (operation === "subtract") return a - b;
        if (operation === "multiply") return a * b;
        return a / b;
      },
    }),
  },
  stopWhen: stepCountIs(2),
});

console.log(result.text);
```

डिफ़ॉल्ट रूप से `generateText` एक स्टेप के बाद रुक जाता है। अगर वह स्टेप टूल कॉल है, तो `result.text` खाली होता है और टूल का नतीजा `result.toolResults` में होता है। `stepCountIs(2)` मॉडल को नतीजे के साथ जवाब देने के लिए दूसरा स्टेप देता है।

## सुरक्षित टूल लिखें

- विवरण सटीक और input schemas सख़्त रखें; arguments मॉडल भरता है।
- arguments को अविश्वसनीय इनपुट मानें। किसी भी side effect से पहले `execute` के अंदर उनकी जाँच करें।
- जो downstream APIs अस्थायी रूप से विफल होते हैं, उनके लिए `execute` के अंदर रीट्राई और backoff जोड़ें।
