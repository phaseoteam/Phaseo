`@phaseo/ai-sdk-provider` इंस्टॉल करें और `generateText`, `streamText` या Vercel AI SDK 7 के किसी भी दूसरे function में `model` के रूप में `phaseo(modelId)` पास करें। टेक्स्ट अनुरोध Gateway के `/v1/chat/completions` एंडपॉइंट पर जाते हैं।

## इंस्टॉल करें

<CodeGroup>

```bash title="npm"
npm install @phaseo/ai-sdk-provider
```

```bash title="pnpm"
pnpm add @phaseo/ai-sdk-provider
```

```bash title="yarn"
yarn add @phaseo/ai-sdk-provider
```

```bash title="bun"
bun add @phaseo/ai-sdk-provider
```

</CodeGroup>

बिना संस्करण वाला पैकेज npm का `latest` tag इंस्टॉल करता है, जो AI SDK 7 वाली लाइन है। यह `ai@^7` को peer dependency के रूप में घोषित करता है, इसलिए जो package managers peers अपने आप इंस्टॉल करते हैं, वे इसे आपके लिए जोड़ देते हैं।

अपने सर्वर environment में `PHASEO_API_KEY` सेट करें, फिर अपना पहला अनुरोध भेजें। अगर `PHASEO_API_KEY` सेट नहीं है, तो डिफ़ॉल्ट `phaseo` export त्रुटि फेंकता है।

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Reply with: AI SDK works",
});

console.log(result.text);
console.log(result.providerMetadata);
```

[Models एंडपॉइंट](../../api-reference/endpoint/models.mdx) से कोई मौजूदा मॉडल id लें।

## टेक्स्ट स्ट्रीम करें

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Stream a short greeting.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## प्रदाता instance कॉन्फ़िगर करें

`apiKey`, `baseURL`, `headers` या कस्टम `fetch` सेट करने के लिए `createPhaseo()` कॉल करें। Phaseo अनुरोध विवरण में अपने ऐप्लिकेशन की पहचान दिखाने के लिए इसका उपयोग करें:

```typescript
import { createPhaseo } from "@phaseo/ai-sdk-provider";

const phaseo = createPhaseo({
  apiKey: process.env.PHASEO_API_KEY,
  headers: {
    "x-title": "My App",
    "http-referer": "https://example.com",
  },
});
```

`PHASEO_BASE_URL` वैकल्पिक है और इसका डिफ़ॉल्ट `https://api.phaseo.app/v1` है।

## मॉडल का प्रकार चुनें

| प्रदाता method | AI SDK function |
| --- | --- |
| `phaseo(modelId)` या `phaseo.languageModel(modelId)` | `generateText`, `streamText` |
| `phaseo.embeddingModel(modelId)` (alias `textEmbeddingModel`) | `embed`, `embedMany` |
| `phaseo.imageModel(modelId)` | `generateImage` |
| `phaseo.transcriptionModel(modelId)` | `transcribe` |
| `phaseo.speechModel(modelId)` | `generateSpeech` |
| `phaseo.rerankingModel(modelId)` | `rerank` |

`rerankingModel` को छोड़कर हर method दूसरे argument के रूप में वैकल्पिक प्रति-मॉडल सेटिंग स्वीकार करता है: `temperature`, `topP`, `topK`, `maxTokens`, `frequencyPenalty`, `presencePenalty`, `seed`, `user`, `headers` और `fetch`।

## समर्थित AI SDK 7 सुविधाएँ

- टेक्स्ट जनरेशन और स्ट्रीमिंग
- रीज़निंग आउटपुट और सेटिंग
- function टूल और स्ट्रीम किए गए टूल इनपुट
- JSON और JSON Schema आउटपुट
- टेक्स्ट और इमेज फ़ाइल इनपुट
- URL उद्धरण स्रोत
- एम्बेडिंग और इमेज जनरेशन
- रीरैंकिंग
- ट्रांसक्रिप्शन और स्पीच जनरेशन
- प्रदाता metadata, उपयोग, abort signals और raw stream chunks

कोई कॉल क्या कर सकती है, यह अब भी मॉडल और प्रदाता पर निर्भर करता है। यह प्रदाता managed file references, skills या प्रदाता द्वारा चलाए जाने वाले टूल (उनकी परिभाषाएँ, नतीजे या अनुमोदन प्रतिक्रियाएँ) घोषित नहीं करता। जिन function टूल को आपका ऐप्लिकेशन चलाता है, वे AI SDK के सामान्य निष्पादन और अनुमोदन flow का उपयोग करते हैं।

## AI SDK का पुराना संस्करण इस्तेमाल करें

| AI SDK | इंस्टॉल |
| --- | --- |
| 7 | `@phaseo/ai-sdk-provider` (`latest`) |
| 6 | `@phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `@phaseo/ai-sdk-provider@ai-sdk-v5` |

अगर peers का अपने आप इंस्टॉल होना बंद है, तो मेल खाने वाला `ai` major (`ai@^7`, `ai@^6` या `ai@^5`) ख़ुद इंस्टॉल करें।
