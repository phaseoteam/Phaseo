स्पीच से टेक्स्ट के लिए `transcribe` में `phaseo.transcriptionModel(modelId)` पास करें, और टेक्स्ट से स्पीच के लिए `generateSpeech` में `phaseo.speechModel(modelId)` पास करें। प्रदाता ऑडियो को multipart form के रूप में `/v1/audio/transcriptions` पर अपलोड करता है और स्पीच अनुरोध `/v1/audio/speech` पर भेजता है।

```ts
import { readFileSync, writeFileSync } from "node:fs";
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateSpeech, transcribe } from "ai";

const transcription = await transcribe({
  model: phaseo.transcriptionModel("openai/whisper-1"),
  audio: readFileSync("./audio.mp3"),
});

console.log(transcription.text);
console.log(transcription.providerMetadata);

const speech = await generateSpeech({
  model: phaseo.speechModel("openai/gpt-4o-mini-tts"),
  text: "Hello from Phaseo audio.",
  voice: "alloy",
  outputFormat: "mp3",
});

writeFileSync("./speech.mp3", Buffer.from(speech.audio.uint8Array));
console.log(speech.providerMetadata);
```

`audio` एक `Buffer`, `Uint8Array`, `ArrayBuffer`, base64 string या `URL` लेता है। AI SDK 7 पुराने `experimental_transcribe` और `experimental_generateSpeech` नाम अब भी aliases के रूप में export करता है।

## लंबे या विफल हो रहे ऑडियो को संभालें

- समर्थित इनपुट और आउटपुट फ़ॉर्मैट मॉडल पर निर्भर करते हैं।
- लंबी फ़ाइलों के लिए timeouts बढ़ाएँ, और अपलोड को मॉडल की आकार सीमा के भीतर रखें (ज़्यादातर मॉडल के लिए 25 MB)।
- अस्थायी `429` और `5xx` प्रतिक्रियाओं पर backoff के साथ रीट्राई करें।
