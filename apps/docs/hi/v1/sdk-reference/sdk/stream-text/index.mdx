Partial tokens आते ही पाने के लिए `streamText` का उपयोग करें।

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## संदेशों के साथ स्ट्रीमिंग

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## प्रोडक्शन के सुझाव

- Long responses और interactive UI के लिए streaming को प्राथमिकता दें।
- छोड़ी गई streams के लिए runtime में cancellation और timeout संभालें।
- पुराने aliases से बचने के लिए `/v1/models` से model IDs up-to-date रखें।
