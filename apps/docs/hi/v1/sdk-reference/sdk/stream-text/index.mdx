आते ही टेक्स्ट पाने के लिए `phaseo(modelId)` के साथ `streamText` कॉल करें और `textStream` पढ़ें। `streamText` तुरंत लौट आता है; स्ट्रीम ख़त्म होने के बाद `providerMetadata` पढ़ें।

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## चैट इतिहास से स्ट्रीम करें

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## छोड़ी गई स्ट्रीम रोकें

`streamText` में `abortSignal` पास करें और जब उपयोगकर्ता चला जाए या timeout बीत जाए, तब उसे abort करें, ताकि अनुरोध चलता न रहे:

```ts
const controller = new AbortController();
setTimeout(() => controller.abort(), 60_000);

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a long report.",
  abortSignal: controller.signal,
});
```

मॉडल IDs को hard-code करने के बजाय `/v1/models` से पढ़ें; [मॉडल खोज](/hi/v1/sdk-reference/sdk/get-models) देखें।
