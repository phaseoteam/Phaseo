प्रोडक्ट इंटरफ़ेस अपडेट करने, ऑडिट रिकॉर्ड लिखने या एजेंट की गतिविधि को अपनी मौजूदा टेलीमेट्री से जोड़ने के लिए `onEvent` का उपयोग करें।

## रन के इवेंट सुनें

```typescript
const result = await agent.run({
  input,
  client,
  onEvent(event) {
    console.log(event.type, event.runId);
  },
});
```

इवेंट हैंडलर छोटे रखें। जिस धीमे नेटवर्क या स्टोरेज वाले काम से रन में देरी नहीं होनी चाहिए, उसे अपने ऐप्लिकेशन की कतार में भेजें।

## इवेंट के प्रकार

| समूह | इवेंट |
| --- | --- |
| रन | `run.started`, `run.resumed`, `run.waiting_for_human`, `run.cancelled`, `run.completed`, `run.failed` |
| चरण | `step.started`, `step.completed`, `step.failed`, `step.cancelled` |
| मॉडल | `model.requested`, `model.completed`, `model.failed` |
| टूल | `tool.started`, `tool.preliminary_result`, `tool.completed`, `tool.failed` |
| स्थिति | `checkpoint.saved` |

पूरे हुए चरण का चेकपॉइंट सहेजे जाने के बाद `step.completed` भेजा जाता है। इससे डेटा सहेजने वाले या टेलीमेट्री कंज़्यूमर इसे एक स्थिर सीमा मान सकते हैं।

## प्रोडक्ट इंटरफ़ेस के लिए इवेंट चुनें

- लाइव उत्तर टेक्स्ट के लिए [स्ट्रीमिंग](./agent-sdk-streaming.mdx) से मिलने वाले मॉडल डेल्टा का उपयोग करें।
- टूल कॉल कार्ड और प्रगति संकेतकों के लिए टूल इवेंट का उपयोग करें।
- अनुमोदन या इनपुट नियंत्रण दिखाने के लिए `run.waiting_for_human` का उपयोग करें।
- लोडिंग स्थितियाँ बंद करने और परिणाम दर्ज करने के लिए रन के अंतिम इवेंट का उपयोग करें।
