**Method**: `client.getGeneration()`।

### उदाहरण
```typescript
const record = await client.getGeneration("G-01ABC...");
```

### पैरामीटर
- `id` (string, required): पिछली call से मिला request ID।

### रिटर्न मान
Generation record (JSON)

Gateway ने पूरी request details सहेजी हों, तो returned record में `replay_supported` और `replay_request` होंगे। नियंत्रित rerun के लिए `replay_request` को original endpoint पर भेजें।

Timing fields पूरे gateway में एक ही semantics का पालन करते हैं:

- `latency_ms`: पहला token या output byte/frame आने तक का समय, यदि track किया गया हो
- `generation_ms`: latency के बाद generation time, यदि track किया गया हो
