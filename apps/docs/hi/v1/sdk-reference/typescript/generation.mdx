**मेथड**: `client.getGeneration()`।

### उदाहरण
```typescript
const record = await client.getGeneration("G-01ABC...");
```

### पैरामीटर
- `id` (string, आवश्यक): पिछली कॉल से लौटाया गया अनुरोध ID।

### रिटर्न मान
जनरेशन रिकॉर्ड (JSON)

अगर Gateway ने अनुरोध का पूरा विवरण सहेजा है, तो लौटाए गए रिकॉर्ड में `replay_supported` और `replay_request` शामिल होते हैं, जिसे नियंत्रित रूप से दोबारा चलाने के लिए मूल एंडपॉइंट पर वापस भेजा जा सकता है।

समय से जुड़े फ़ील्ड पूरे Gateway में एक जैसे अर्थ का पालन करते हैं:

- `latency_ms`: पहले टोकन या आउटपुट के पहले बाइट/फ़्रेम तक का समय, यदि ट्रैक किया गया हो
- `generation_ms`: लेटेंसी के बाद का जनरेशन समय, यदि ट्रैक किया गया हो
