**Method**: `client.generateModeration()`।

### उदाहरण
```typescript
const moderation = await client.generateModeration({
  model: "openai/omni-moderation-latest",
  input: "Text to classify",
});
```

### मुख्य parameters
- `model` (आवश्यक): मॉडरेशन मॉडल ID (जैसे, `openai/omni-moderation-latest`)।
- `input` (आवश्यक): स्ट्रिंग या सामग्री आइटमों की सूची (पाठ या `image_url`)।
- वैकल्पिक: `categories`/`severity` फ़िल्टर (यदि समर्थित हों) और `user` टैग।
