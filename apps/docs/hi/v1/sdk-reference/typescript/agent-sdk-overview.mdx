जब आपके ऐप को एक बार के generation से अधिक की आवश्यकता हो, तब TypeScript Agent SDK का उपयोग करें:

- कई चरणों वाले local tool loops
- फिर से शुरू की जा सकने वाली run state
- Gateway के ज़रिए मॉडल टर्न
- मान्य संरचित आउटपुट, स्ट्रीम की गई प्रगति और प्लगइन-जागरूक रूटिंग

यह `@phaseo/sdk` पर आधारित है और अलग-अलग Agent SDK भाषाओं द्वारा साझा किया जाने वाला रनटाइम अनुबंध तय करता है।

## रनटाइम की क्षमताएँ

| क्षमता | SDK सहायता |
| --- | --- |
| चलने योग्य और समवर्ती टूल | अंतर्निर्मित; नियतात्मक परिणाम क्रम और हर टूल के लिए समय-सीमा के साथ |
| रनटाइम सत्यापन | `parse`, `safeParse` या सत्यापन फ़ंक्शन से इनपुट, आउटपुट, इवेंट और अंतिम एजेंट स्कीमा जाँचें |
| मानवीय अनुमोदन | हर टूल या कॉल के लिए अनुमोदन; रन फिर शुरू करते समय सटीक call ID के आधार पर स्वीकृत या अस्वीकृत करें |
| मानवीय समीक्षा वाले टूल | `onToolCalled` से रोकें और `onResponseReceived` से रूपांतरित करें |
| मैन्युअल टूल | `execute: false` और बाहर से दिए गए `toolOutputs` |
| प्रगति उत्पन्न करने वाले टूल | असिंक्रोनस जनरेटर टूल और `tool.preliminary_result` इवेंट |
| टूल त्रुटि से उबरना | रन को विफल करें या मॉडल को संरचित टूल त्रुटि लौटाएँ |
| स्ट्रीमिंग | मॉडल डेल्टा और दोबारा चलाए जा सकने वाले टेक्स्ट, तर्क, आइटम, टूल तथा सभी-इवेंट उपभोक्ता |
| रन रोकने के नियंत्रण | कदम, अवधि, टोकन, लागत, टूल कॉल, समाप्ति कारण और कस्टम शर्तें |
| गतिशील चरण | गतिशील मॉडल, निर्देश, सैंपलिंग मान, टूल सेट, संदर्भ में बदलाव और `nextTurnParams` |
| स्थायी रूप से जारी रखना | सीरियलाइज़ किए जा सकने वाले रन परिणाम या ऐप द्वारा प्रबंधित `state` लोड/सहेजने का एक्सेसर |
| निगरानी | सामान्यीकृत उपयोग और लागत, चेतावनियाँ, समाप्ति कारण, चरण परिणाम, जीवनचक्र घटनाएँ और स्थानीय DevTools |

## आपको क्या मिलता है

- `createAgent()`
- `defineTool()`
- `createGatewayAgentClient()`
- `run()`, `stream()`, `continueRun()` और `continueStream()`
- चलाए जा सकने वाले, मैन्युअल, अनुमोदन-नियंत्रित और मानव-हस्तक्षेप वाले टूल
- रनटाइम इनपुट/आउटपुट स्कीमा, जनरेटर की प्रगति, संयोज्य स्टॉप शर्तें और उपयोग/लागत सारांश
- वैकल्पिक ऐप-प्रबंधित स्थिति एक्सेसर और डेवलपर टूल के लिए जीवनचक्र इवेंट
