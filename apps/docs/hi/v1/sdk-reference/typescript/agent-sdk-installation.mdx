Agent SDK npm पर [`@phaseo/agent-sdk`](https://www.npmjs.com/package/@phaseo/agent-sdk) के रूप में प्रकाशित है।

## आवश्यकताएँ

- npm, pnpm, Yarn या Bun इस्तेमाल करने वाला TypeScript या JavaScript प्रोजेक्ट
- Phaseo API कुंजी

## इंस्टॉलेशन

अपने पसंदीदा पैकेज मैनेजर से Agent SDK इंस्टॉल करें:

<CodeGroup>

    ```bash title="npm"
    npm install @phaseo/agent-sdk
    ```

    ```bash title="pnpm"
    pnpm add @phaseo/agent-sdk
    ```

    ```bash title="yarn"
    yarn add @phaseo/agent-sdk
    ```

    ```bash title="bun"
    bun add @phaseo/agent-sdk
    ```

</CodeGroup>

मुख्य पैकेज `@phaseo/sdk` डिपेंडेंसी के रूप में अपने-आप इंस्टॉल होता है।

## एनवायरनमेंट

उदाहरण चलाने से पहले अपनी Gateway API कुंजी सेट करें:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
