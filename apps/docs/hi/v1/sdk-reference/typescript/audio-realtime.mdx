<Note>
रीयलटाइम वॉइस बीटा में है और इसकी पहुँच हर वर्कस्पेस के लिए अलग से दी जाती है।
</Note>

**मेथड**: `client.realtime.connect()` सत्र बनाता है (`POST /v1/audio/realtime/sessions`), रिले का WebSocket खोलता है और रिले के `relay.connected` भेजते ही पूरा होता है। यह आपकी API कुंजी भेजता है, इसलिए इसे केवल अपने सर्वर पर कॉल करें। Node.js 22 या उसके बाद के संस्करणों में ग्लोबल `WebSocket` होता है; पुराने रनटाइम पर `ws` पैकेज इंस्टॉल करें या अपना कंस्ट्रक्टर `webSocket` के रूप में पास करें।

ब्राउज़र में चलने वाली कॉल के लिए, अपने सर्वर पर सत्र बनाएँ और ब्राउज़र में `connectRealtimeSession()` से सॉकेट खोलें। यह आपके सर्वर द्वारा बनाया गया सत्र लेता है, जिसमें उसका `client_secret` भी शामिल है, जो केवल उसी एक सत्र के लिए काम करता है, और इसे कभी API कुंजी की ज़रूरत नहीं होती। [ब्राउज़र कॉल](#browser-calls) दोनों हिस्से दिखाता है।

रिले प्रोटोकॉल, चेतावनियाँ और कारण कोड [रीयलटाइम वॉइस सत्र](/hi/v1/guides/realtime-voice) में बताए गए हैं।

### उदाहरण

```typescript
import { Phaseo, RealtimeSessionClosedError } from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY });

const session = await client.realtime.connect({
  model: "openai/gpt-realtime-2",
  voice: "marin",
  instructions: "Answer in one sentence.",
});

session.onWarning((warning) => console.warn(warning.code, warning.message));
session.on("response.output_audio.delta", (event) => play(event.delta as string));

// PCM16 microphone audio: 24 kHz for OpenAI and xAI, 16 kHz for Google.
session.sendAudio(pcm16Chunk);

try {
  const ended = await session.end({ reason: "caller hung up" });
  console.log(ended.reason, ended.duration_seconds, ended.cost.total_usd, ended.billing_status);
} catch (error) {
  if (error instanceof RealtimeSessionClosedError) {
    // The call is still billed. Fetch the final cost later with error.finalBill.path.
    console.error(error.message);
  } else {
    throw error;
  }
}
```

इसके बजाय हर इवेंट पढ़ने के लिए, सत्र पर इटरेट करें। सॉकेट बंद होने पर इटरेशन रुक जाता है।

```typescript
for await (const event of session) {
  if (event.type === "session.ended") console.log("bill", event.cost);
}
```

### ब्राउज़र कॉल

Phaseo API कुंजी को कभी भी ब्राउज़र कोड में न रखें। अपने सर्वर पर `client.realtime.createSession()` से सत्र बनाएँ, जो `connect()` जैसे ही `model`, `voice`, `instructions`, `provider` और `metadata` विकल्प लेता है, और प्रतिक्रिया अपने पेज को लौटाएँ:

```typescript
// Server route, for example POST /api/voice-session
const info = await client.realtime.createSession({ model: "openai/gpt-realtime-2", voice: "marin" });
return Response.json(info);
```

ब्राउज़र में `connectRealtimeSession()` से सत्र में शामिल हों। यह सत्र के `client_secret` से रिले खोलता है और `connect()` जैसा ही सत्र ऑब्जेक्ट लौटाता है:

```typescript
import { connectRealtimeSession } from "@phaseo/sdk";

const info = await fetch("/api/voice-session", { method: "POST" }).then((response) => response.json());
const session = await connectRealtimeSession(info);
session.sendAudio(pcm16Chunk);
```

`connectRealtimeSession(info, options)` `connect()` की तरह `webSocket` और `connectTimeoutMs` स्वीकार करता है, और अगर आप क्षेत्रीय एंडपॉइंट इस्तेमाल करते हैं तो `baseUrl` (डिफ़ॉल्ट `https://api.phaseo.app/v1`) भी।

### कनेक्ट विकल्प

- `model` (आवश्यक): एक रीयलटाइम मॉडल ID, उदाहरण के लिए `openai/gpt-realtime-2`।
- `voice`, `instructions`, `provider`, `metadata`: सत्र बनाने के अनुरोध को पास किए जाते हैं।
- `webSocket`: ग्लोबल कंस्ट्रक्टर की जगह इस्तेमाल करने के लिए एक WebSocket कंस्ट्रक्टर।
- `connectTimeoutMs`: `relay.connected` का कितनी देर इंतज़ार करना है। डिफ़ॉल्ट 30 सेकंड।

### सत्र

| सदस्य | विवरण |
| --- | --- |
| `id`, `info` | सत्र ID और सत्र बनाने की प्रतिक्रिया, `client_secret` के बिना। |
| `sendAudio(pcm16)` | PCM16 ऑडियो का `Uint8Array` या `ArrayBuffer` `client.audio` के रूप में भेजता है। SDK इसे base64 में एन्कोड करता है। |
| `send(event)` | प्रदाता-विशिष्ट संदेशों के लिए कोई भी इवेंट JSON के रूप में भेजता है। |
| `on(type, listener)` | एक इवेंट प्रकार की, या `"*"` से हर इवेंट की सदस्यता लेता है। सदस्यता हटाने वाला फ़ंक्शन लौटाता है। प्रदाता के इवेंट बिना बदले आते हैं। |
| `onWarning(listener)`, `onEnded(listener)` | `session.warning` और `session.ended` के लिए टाइप किए गए हेल्पर। |
| `[Symbol.asyncIterator]` | इटरेशन शुरू होने से लेकर सॉकेट बंद होने तक हर इवेंट देता है। |
| `end({ reason?, cancelResponse?, timeoutMs? })` | `session.end` भेजता है और `session.ended` के साथ पूरा होता है: `reason`, `initiated_by`, `duration_seconds`, `usage`, `cost`, `billing_status` और, अगर निपटान नहीं हुआ है, तो `final_bill`। डिफ़ॉल्ट टाइमआउट 60 सेकंड। |
| `ended` | कॉल चाहे किसी भी तरह खत्म हो, `session.ended` के लिए एक प्रॉमिस, जिसमें प्रदाता या गेटवे द्वारा शुरू की गई समाप्तियाँ भी शामिल हैं। |
| `close()` | बिल का इंतज़ार किए बिना सॉकेट बंद करता है। कॉल का बिल फिर भी बनता है। |

### त्रुटियाँ

अगर `session.ended` के बिना सॉकेट बंद हो जाता है या `end()` का टाइमआउट हो जाता है, तो `end()` और `ended` `RealtimeSessionClosedError` के साथ अस्वीकार होते हैं। इसमें `sessionId`, `closeCode`, `closeReason` और `finalBill` होते हैं; आखिरी वाला वह अनुरोध है जो निपटान के बाद अंतिम लागत लौटाता है: `GET /v1/generations?id=realtime%3A<session_id>`। `realtimeFinalBill(sessionId)` यही अनुरोध बनाता है।

अगर रिले कनेक्ट होने से पहले सत्र समाप्त कर देता है या `relay.connected` समय पर नहीं आता, तो `connect()` अस्वीकार हो जाता है।
