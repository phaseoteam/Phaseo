**तरीका**: `client.generateText()` (पार्स किए गए हिस्सों को स्ट्रीम करने के लिए `client.streamChat()`).

### उदाहरण
```typescript
const chat = await client.generateText({
  model: "openai/gpt-4o-mini",
  messages: [
    { role: "system", content: "You are helpful." },
    { role: "user", content: "Write a limerick about lighthouses." },
  ],
  temperature: 0.5,
});
```

### स्ट्रीमिंग
```typescript
for await (const chunk of client.streamChat({
  model: "openai/gpt-4o-mini",
  messages: [{ role: "user", content: "Stream a story" }],
})) {
  if (chunk.text) process.stdout.write(chunk.text);
}
```

### मुख्य पैरामीटर
- `model` (required): लक्ष्य मॉडल ID।
- `messages` (required): `system|user|assistant|tool` भूमिकाओं वाले क्रमबद्ध संदेश; कंटेंट स्ट्रिंग या हिस्सों में हो सकता है।
- सैंपलिंग: `temperature` (0–2), `top_p` (0–1), `top_k` (>=1), `seed` (int, optional).
- लंबाई/पेनल्टी: `max_output_tokens` (int), `presence_penalty` and `frequency_penalty` (-2 to 2), `stop` (string|string[]).
- टूल: `tools` (परिभाषाएँ), `tool_choice` (`auto`/`none`/विशिष्ट टूल), `max_tool_calls` (पूर्णांक), `parallel_tool_calls` (बूलियन)।
- लॉग प्रायिकताएँ: `logprobs` (बूलियन), `top_logprobs` (0–20)।
- आउटपुट: `response_format` (json/text), `metadata` (पास-थ्रू ऑब्जेक्ट), `stream` (बूलियन), `service_tier`।
- गेटवे के अतिरिक्त विकल्प: `usage` (उपयोग माँगने के लिए बूलियन), `meta` (मेटाडेटा ब्लॉक शामिल करने के लिए बूलियन)।
