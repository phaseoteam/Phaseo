आप जो प्रोडक्ट बना रहे हैं, उससे मेल खाने वाला सबसे छोटा उदाहरण चुनें। हर पैटर्न में डेटा सहेजने का काम और यूज़र इंटरफ़ेस आपके ऐप्लिकेशन में ही रहते हैं, जबकि मॉडल टर्न के लिए Phaseo इस्तेमाल होता है।

## पैकेज में शामिल उदाहरण

| उदाहरण | उपयोग |
| --- | --- |
| `research-brief-agent.ts` | प्रबंधित सर्च से शोध करना और टाइप्ड अंतिम सारांश तैयार करना |
| `support-triage-agent.ts` | प्रबंधित प्रीसेट से सहायता संबंधी काम को रूट और वर्गीकृत करना |
| `coding-review-agent.ts` | लोकल रनटाइम टूल से कोड की समीक्षा करना |
| `parallel-tool-agent.ts` | स्वतंत्र लोकल टूल को एक साथ चलाना |
