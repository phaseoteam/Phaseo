अपने product के अनुरूप सबसे छोटा example चुनें। हर pattern में persistence और user interface आपकी application में रहते हैं, जबकि model turns के लिए Phaseo उपयोग होता है।

## पैकेज में शामिल उदाहरण

| उदाहरण | उपयोग |
| --- | --- |
| `research-brief-agent.ts` | Managed search से research और typed final brief तैयार करना |
| `support-triage-agent.ts` | Managed preset से support requests route और classify करना |
| `coding-review-agent.ts` | Local runtime tools से code review करना |
| `parallel-tool-agent.ts` | Independent local tools को parallel चलाना |
