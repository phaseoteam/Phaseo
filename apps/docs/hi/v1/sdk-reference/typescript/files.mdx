**मेथड**: `client.uploadFile()`, `client.listFiles()`, `client.getFile()`, `client.getFileContent()`।

### उदाहरण
```typescript
const uploaded = await client.uploadFile({ purpose: "batch", file: new Blob(["{}"]) });
const file = await client.getFile(uploaded.id);
const content = await client.getFileContent(uploaded.id);
```

<Note>
`client.listFiles()` मौजूद है, लेकिन साझा Gateway कुंजी इस्तेमाल करने पर `GET /files` अभी `file_list_not_supported_with_shared_gateway_key`
लौटाता है। `uploaded.id` मान सहेजें और फ़ाइलें सीधे प्राप्त करें।
</Note>

### मुख्य पैरामीटर
- `file` (अपलोड के लिए आवश्यक): Blob/File/base64/string।
- `purpose` (अपलोड के लिए आवश्यक): उदाहरण के लिए `batch`।

### रिटर्न मान
`FileObject` (अपलोड करने और प्राप्त करने पर)

```json
{
  "id": "file-123",
  "object": "file",
  "filename": "data.json",
  "purpose": "batch",
  "status": "processed",
  "created_at": 1677610602,
  "bytes": 123
}
```

या `FileListResponse` (सूची के लिए, जब मूल प्रदाता कुंजी फ़ाइलों की सूची बनाने का समर्थन करती हो)

```json
{
  "data": [
    {
      "id": "file-123",
      "object": "file",
      "filename": "data.json",
      "purpose": "batch",
      "status": "processed",
      "created_at": 1677610602,
      "bytes": 123
    }
  ]
}
```
