**Methods**: `client.uploadFile()`, `client.listFiles()`, `client.getFile()`, `client.getFileContent()`।

### उदाहरण
```typescript
const uploaded = await client.uploadFile({ purpose: "batch", file: new Blob(["{}"]) });
const file = await client.getFile(uploaded.id);
const content = await client.getFileContent(uploaded.id);
```

<Note>
`client.listFiles()` मौजूद है, लेकिन `GET /files` अभी `file_list_not_supported_with_shared_gateway_key` लौटाता है
shared gateway key का उपयोग करने पर। `uploaded.id` value सहेजें और files सीधे retrieve करें।
</Note>

### मुख्य parameters
- `file` (upload के लिए required): Blob/File/base64/string।
- `purpose` (upload के लिए required): उदाहरण के लिए `batch`।

### रिटर्न मान
`FileObject` (upload/get)

```json
{
  "id": "file-123",
  "object": "file",
  "filename": "data.json",
  "purpose": "batch",
  "status": "processed",
  "created_at": 1677610602,
  "bytes": 123
}
```

या `FileListResponse` (जब underlying provider key file listing support करे)

```json
{
  "data": [
    {
      "id": "file-123",
      "object": "file",
      "filename": "data.json",
      "purpose": "batch",
      "status": "processed",
      "created_at": 1677610602,
      "bytes": 123
    }
  ]
}
```
