<Note type="warning">C++ SDK पर अभी काम चल रहा है और इसे अभी तक किसी पैकेज रजिस्ट्री पर प्रकाशित नहीं किया गया है।</Note>

## लोकल उपयोग

SDK सिर्फ़-हेडर वाला C++17 है। `packages/sdk/sdk-cpp` को अपने CMake बिल्ड में जोड़ें और इंटरफ़ेस टारगेट लिंक करें, या `packages/sdk/sdk-cpp/src` को अपने include पाथ में रखें:

```cmake
add_subdirectory(path/to/Phaseo/packages/sdk/sdk-cpp)
target_link_libraries(your_app PRIVATE phaseo::sdk)
```

फिर `phaseo.hpp` शामिल करें, जो `src/gen` में जनरेट किया गया क्लाइंट ले आता है।
