<Note type="warning">C++ SDK पर काम जारी है और इसे अभी तक किसी पैकेज रजिस्ट्री में प्रकाशित नहीं किया गया है।</Note>

## स्थानीय उपयोग

- जनरेट किए गए हेडर यहां उपयोग करें: `packages/sdk/sdk-cpp/src/gen`.
- इस फ़ोल्डर को अपने बिल्ड सिस्टम के include path में जोड़ें।
- अभी क्लाइंट केवल हेडर-आधारित है।
