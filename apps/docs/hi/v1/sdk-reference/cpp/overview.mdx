<Note type="warning">
  C++ SDK पर काम जारी है और यह अभी पैकेज मैनेजर के माध्यम से उपलब्ध नहीं है। स्रोत हेडर का उपयोग केवल मूल्यांकन के लिए करें।
</Note>

- स्थिति: काम जारी है (अभी प्रकाशित नहीं)।
- स्रोत यहां है: `packages/sdk/sdk-cpp`.
- जनरेट किए गए हेडर यहां हैं: `packages/sdk/sdk-cpp/src/gen`.
