<Note type="warning">
  C++ SDK पर अभी काम चल रहा है और यह अभी किसी पैकेज मैनेजर से उपलब्ध नहीं है। सोर्स हेडर सिर्फ़ मूल्यांकन के लिए इस्तेमाल करें।
</Note>

C++ SDK `packages/sdk/sdk-cpp` में सिर्फ़-हेडर वाले C++17 सोर्स का एक सेट है; यह प्रकाशित नहीं है, और जब तक यह शुरू से अंत तक काम नहीं करता, SDK रिलीज़ से बाहर रहता है।

| फ़ाइल | सामग्री |
| --- | --- |
| `src/gen/client.hpp`, `src/gen/operations.hpp`, `src/gen/models.hpp`, `src/gen/model_ids.hpp` | जनरेट किया गया क्लाइंट |
| `src/phaseo.hpp` | लाइव मॉडल क्षमताओं के लिए `GetModelEndpointCapabilities(...)` और पैरामीटर सपोर्ट रिपोर्ट के लिए `CheckParameterSupport(...)` |
| `src/workflows.hpp` | पेजिंग और जॉब-पोलिंग हेल्पर |

प्रीव्यू ट्रांसपोर्ट कच्चा JSON लौटाता है, इसलिए जाँचने से पहले प्रतिक्रिया को `ModelEndpointCapabilities` में डीसीरियलाइज़ करें। इसे आज़माने के लिए [इंस्टॉलेशन](./installation) देखें। C++ के लिए कोई Agent SDK नहीं है।
