## सेटअप

```go
import (
  "context"
  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

client := phaseo.New("<API_KEY>", "https://api.phaseo.app/v1")
ctx := context.Background()
```

## चैट कंप्लीशन

```go
chatReq := phaseo.ChatCompletionsRequest{
  Model: "openai/gpt-5-nano",
  Messages: []map[string]interface{}{
    {"role": "user", "content": "Hello"},
  },
}
chatResp, err := client.GenerateText(ctx, chatReq)
```

## Responses

```go
input := map[string]interface{}{
  "role": "user",
  "content": []map[string]interface{}{
    {"type": "input_text", "text": "Reply with: go sdk works"},
  },
}
resp, err := client.GenerateResponse(ctx, phaseo.ResponsesRequest{
  Model: "openai/gpt-5-nano",
  Input: &input,
})
```

## एम्बेडिंग

```go
embedding, err := client.GenerateEmbedding(ctx, map[string]interface{}{
  "model": "openai/text-embedding-3-large",
  "input": "Sample text",
})
```

## मॉडरेशन

```go
moderation, err := client.GenerateModeration(ctx, map[string]interface{}{
  "model": "openai/omni-moderation-latest",
  "input": "Some text to check",
})
```

## इमेज और ऑडियो

```go
image, err := client.CreateImage(ctx, map[string]interface{}{
  "model": "openai/gpt-image-1",
  "prompt": "A lighthouse at golden hour",
})

speech, err := client.CreateSpeech(ctx, map[string]interface{}{
  "model": "openai/gpt-4o-mini-tts",
  "input": "Hello from Go",
})
```

## मॉडल

```go
models, err := client.GetModels(ctx, map[string]string{"limit": "10"})
```

## मौजूदा सीमाएँ

Go रैपर अब चैट, Responses, इमेज, ऑडियो, एम्बेडिंग, मॉडरेशन, मॉडल, प्रदाता, बैच, फ़ाइल, जनरेशन लुकअप, स्वास्थ्य जाँच और वीडियो हेल्पर को कवर करता है। जिन एंडपॉइंट को अभी हाथ से लिखे रैपर में शामिल नहीं किया गया है, उनके लिए निचले स्तर के जनरेट किए गए ऑपरेशन उपलब्ध रहते हैं, लेकिन सामान्य अनुरोध टाइप रैपर पैकेज से दोबारा एक्सपोर्ट किए जाते हैं।
