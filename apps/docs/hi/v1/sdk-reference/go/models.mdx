Wrapper method का उपयोग करें:

- `client.GetModels(ctx, query)`

```go
import (
  "context"
  "fmt"
  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v2"
)

client := phaseo.New(apiKey, "https://api.phaseo.app/v1")
models, err := client.GetModels(context.Background(), map[string]string{
  "provider": "anthropic",
  "provider_status": "beta,not_ready",
  "provider_availability_reason": "preview_only,provider_not_ready",
  "capability_status": "coming_soon,internal_testing",
  "availability": "all",
  "limit": "10",
})
if err != nil {
  panic(err)
}

fmt.Println(models)
```

समर्थित query keys में `provider`, `provider_status`, `provider_routing_status`, `model_routing_status`, `capability_status`, `provider_availability_status`, `provider_availability_reason`, `status`, `organisation`, `endpoints`, `input_types`, `output_types`, `params`, `availability`, `limit` और `offset` शामिल हैं।

`preview_only`, `provider_not_ready`, `gated`, `access_limited`, `region_limited`, `project_limited`, `paused` या `soft_blocked` जैसे rollout states पाने के लिए `availability=all` के साथ `provider_availability_reason` उपयोग करें। `coming_soon` या `internal_testing` जैसी non-routable endpoint mappings पाने के लिए `availability=all` के साथ `capability_status` उपयोग करें।
