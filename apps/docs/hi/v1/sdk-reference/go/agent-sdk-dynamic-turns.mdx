डायनामिक टर्न कॉलबैक, एजेंट को दोबारा बनाए बिना रूटिंग को रन की स्थिति के अनुसार बदलने देते हैं। वे हर मॉडल अनुरोध से पहले चलते हैं और उन्हें मौजूदा टर्न का संदर्भ मिलता है।

```go
agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
  ID: "support-agent",
  DynamicModel: func(turn phaseoagent.TurnContext) string {
    if turn.Run.StepCount > 3 { return "openai/gpt-5.4" }
    return "openai/gpt-5.4-nano"
  },
  DynamicInstructions: func(turn phaseoagent.TurnContext) string {
    return fmt.Sprintf("Resolve the request. Current context: %v", turn.Context)
  },
})
```

आप डायनामिक टूल और हर टर्न के लिए `Temperature`, `MaxOutputTokens` व `TopP` मान भी कॉन्फ़िगर कर सकते हैं।

## टूल से अगले टर्न को प्रभावित करें

ठीक अगले मॉडल अनुरोध को बदलने के लिए टूल पर `NextTurn` सेट करें। ये ओवरराइड रोकी गई स्थिति में सहेजे जाते हैं, इसलिए अनुमोदन चेकपॉइंट के बाद भी बने रहते हैं और अगले टर्न के बाद समाप्त हो जाते हैं।

जिस नीति की हर टर्न पर दोबारा गणना होनी चाहिए, उसके लिए डायनामिक कॉलबैक उपयोग करें। रिपॉज़िटरी की जाँच के बाद मॉडल बदलने जैसे टूल-विशिष्ट हैंडऑफ़ के लिए `NextTurn` उपयोग करें।
