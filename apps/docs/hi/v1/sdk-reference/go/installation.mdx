SDK [`sdk-go/v2`](https://pkg.go.dev/github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3) के रूप में प्रकाशित है।

## आवश्यकताएँ

- Go 1.23 या नया

## इंस्टॉल करें

```bash
go get github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3@latest
```

v2 मॉड्यूल पाथ इंपोर्ट करें:

```go
import phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
```
