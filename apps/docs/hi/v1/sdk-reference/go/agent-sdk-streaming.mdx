`Agent.Stream(...)` दोबारा चलाया जा सकने वाला `StreamResult` लौटाता है:

```go
stream := agent.Stream(ctx, phaseoagent.RunOptions{Input: input, Client: client})

for delta := range stream.Text() {
  fmt.Print(delta)
}

completed, err := stream.Result()
```

लाइफ़साइकल और प्रदाता इवेंट के लिए `Events()` इस्तेमाल करें। स्ट्रीम कॉन्टेक्स्ट और सक्रिय मॉडल अनुरोध रद्द करने के लिए `Cancel()` कॉल करें।

Go अभी TypeScript जैसा मूल टाइप्ड आइटम कंज़्यूमर नहीं देता; संरचित प्रोडक्ट टाइमलाइन के लिए इवेंट अनुक्रम और पूरे हुए रन के रिकॉर्ड का उपयोग करें।
