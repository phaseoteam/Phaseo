Agent SDK इस नाम से प्रकाशित है [`agent-sdk-go`](https://pkg.go.dev/github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go) Go मॉड्यूल के ज़रिए।

## आवश्यकताएँ

- Go 1.24 या नया
- Phaseo API कुंजी

## इंस्टॉलेशन

```bash
go get github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go@latest
```

मुख्य `sdk-go/v2` मॉड्यूल डिपेंडेंसी के रूप में अपने आप इंस्टॉल होता है।

## एनवायरनमेंट

उदाहरण चलाने से पहले अपनी Gateway API कुंजी सेट करें:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
