---

**मेथड**: `client.generate_speech(...)` या `client.create_speech(...)`।

### उदाहरण
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
audio = client.generate_speech(
  model: 'openai/gpt-4o-mini-tts',
  input: 'Hello world',
  voice: 'alloy',
  format: 'mp3'
)
```

### मुख्य पैरामीटर
- `model` (ज़रूरी): TTS-सक्षम मॉडल ID।
- `input` (ज़रूरी): संश्लेषित किया जाने वाला टेक्स्ट।
- `voice`: आवाज़ प्रीसेट (मॉडल पर निर्भर, जैसे `alloy`)।
- `format`: `mp3`, `wav`, `flac` आदि।
- `speed`: प्लेबैक गति का गुणक (आमतौर पर 0.25–4)。
