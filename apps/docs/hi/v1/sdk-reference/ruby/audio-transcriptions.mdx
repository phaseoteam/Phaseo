description: "Ruby SDK के साथ /audio/transcriptions call करें।"
---

**Methods**: `client.generate_transcription(...)` या `client.create_transcription(...)`।

### उदाहरण
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
transcript = client.generate_transcription(
  model: 'openai/gpt-4o-transcribe',
  audio_b64: 'base64_audio_data',
  language: 'en'
)
```

### मुख्य पैरामीटर
- `model` (ज़रूरी): transcription-सक्षम model ID।
- `audio_url` या `audio_b64` (ज़रूरी): audio data (URL या base64)।
- `language`: भाषा code का hint (जैसे `en`)।
- `prompt`: accuracy बढ़ाने के लिए optional context।
- `temperature` (0–2): sampling randomness।
- `response_format`: `json`, `text`, `srt`, `verbose_json` आदि।

### लौटाया गया मान
`AudioTranscriptionResponse`
