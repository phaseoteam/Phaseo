**मेथड**: `client.generate_moderation(...)`, `client.create_moderation(...)`.

### उदाहरण
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))

moderation = client.create_moderation(
  "model" => "openai/omni-moderation-latest",
  "input" => "Text to classify"
)
```

### मुख्य पैरामीटर
- `model` ज़रूरी: मॉडरेशन मॉडल ID (जैसे `openai/omni-moderation-latest`).
- `input` ज़रूरी: टेक्स्ट या image_url जैसे कंटेंट आइटम की स्ट्रिंग या ऐरे।
- वैकल्पिक: `categories`/`severity` फ़िल्टर (समर्थित होने पर), `user` टैग।

### रिटर्न
`ModerationResponse`
