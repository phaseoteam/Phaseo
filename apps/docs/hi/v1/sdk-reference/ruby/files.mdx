**Methods**: `upload_file`, `list_files`, `retrieve_file`, `retrieve_file_content`।

### उदाहरण
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch('PHASEO_API_KEY'))

uploaded = client.upload_file(
  'purpose' => 'batch',
  'file' => 'data:application/json;base64,eyJ0ZXN0Ijp0cnVlfQ=='
)

file = client.retrieve_file('file_123')
content = client.retrieve_file_content('file_123')
```

<Note>
`list_files` SDK के ज़रिए उपलब्ध है, लेकिन shared gateway key पर `GET /files` अभी `file_list_not_supported_with_shared_gateway_key` लौटाता है
Uploaded file IDs सहेजें और उन्हें सीधे retrieve करें।
</Note>
