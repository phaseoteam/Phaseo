SDK को [`phaseo_sdk`](https://rubygems.org/gems/phaseo_sdk) पर RubyGems.

## आवश्यकताएं

- Ruby 3.1 या नया

## इंस्टॉल करें

```bash
gem install phaseo_sdk
```

या इसे अपने `Gemfile` में जोड़ें:

```ruby
gem "phaseo_sdk"
```
