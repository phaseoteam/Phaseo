Agent SDK RubyGems पर [`phaseo_agent_sdk`](https://rubygems.org/gems/phaseo_agent_sdk) के रूप में प्रकाशित है।

## आवश्यकताएँ

- Ruby 3.2 या नया
- RubyGems या Bundler
- Phaseo API key

## इंस्टॉलेशन

```bash
gem install phaseo_agent_sdk
```

या इसे अपने `Gemfile` में जोड़ें:

```ruby
gem "phaseo_agent_sdk"
```

मुख्य `phaseo_sdk` gem निर्भरता के रूप में अपने-आप इंस्टॉल होता है।

## एनवायरनमेंट

उदाहरण चलाने से पहले gateway API key सेट करें:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
