**मेथड**: `client.get_generation(...)`

### उदाहरण

```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))

record = client.get_generation('G-01ABC...')
```

### पैरामीटर

- `id` (string, आवश्यक): पिछली कॉल से मिला अनुरोध ID।

### रिटर्न

जनरेशन रिकॉर्ड (JSON)

यदि गेटवे ने अनुरोध के सभी विवरण सहेजे थे, तो लौटाए गए रिकॉर्ड में `replay_supported` और `replay_request` भी शामिल होते हैं। इनसे कैप्चर किए गए payload को मूल endpoint पर दोबारा भेजकर नियंत्रित री-रन किया जा सकता है।

समय फ़ील्ड गेटवे की साझा परिभाषा का पालन करते हैं:

- `latency_ms`: रिकॉर्ड किए जाने पर, पहले token या पहले आउटपुट byte/frame तक का समय
- `generation_ms`: रिकॉर्ड किए जाने पर, latency के बाद का जनरेशन समय
