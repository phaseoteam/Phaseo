Ruby Agent SDK, Phaseo Gateway के लिए एक पूर्ण स्थानीय एजेंट रनटाइम है। इसमें पुनः प्रयास, समानांतर टूल, समय-सीमा, मानव समीक्षा, फिर से शुरू की जा सकने वाली स्थिति, जीवनचक्र घटनाएँ और DevTools कैप्चर शामिल हैं।

इसे तब उपयोग करें जब आपको चाहिए:

- हल्का और सीमित tool loop
- gateway-आधारित `responses` requests
- persistence और orchestration पर ऐप का अपना नियंत्रण

## शामिल सुविधाएँ

- `PhaseoAgentSdk.create_agent(...)`
- `PhaseoAgentSdk.define_tool(...)`
- `PhaseoAgentSdk.create_gateway_agent_client(...)`
- Phaseo `responses` API पर सीमित tool loop
