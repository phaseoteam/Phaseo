स्ट्रीम परिणाम टेक्स्ट और प्रदाता आइटम के लिए ऐसे कंज़्यूमर देता है जिन्हें दोबारा चलाया जा सकता है।

```ruby
stream = agent.stream(input: prompt, client: client)

stream.item_stream.each do |item|
  render_item(item)
end

result = stream.result
```

अगर इंटरफ़ेस को रीज़निंग डेल्टा, टूल की प्रगति, अनुमोदन चेकपॉइंट या लाइफ़साइकल इवेंट भी चाहिए, तो `full_stream` इस्तेमाल करें।

<Note>
Ruby में आइटम मान सामान्य हैश होते हैं, टाइप किए गए आइटम का बंद यूनियन नहीं। आपका UI जिन फ़ील्ड का उपयोग करता है, उन्हें सत्यापित करें और भविष्य के प्रदाता इवेंट के लिए अज्ञात आइटम का फ़ॉलबैक रखें।
</Note>

Ruby प्रदाता स्ट्रीम को सिंक्रोनस रूप से पढ़ता है और एकत्रित अनुक्रम को दोबारा चलाने योग्य बनाता है। यह अपने आप कोई बैकग्राउंड पुश सेवा नहीं बनाता।
