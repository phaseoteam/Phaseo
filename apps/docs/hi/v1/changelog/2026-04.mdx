### SDK रिलीज़

- SDK `2.0.2` इन भाषाओं के लिए जारी किया गया: [TypeScript](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fsdk%402.0.2), [Python](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fpy-sdk%402.0.2), [Go](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fgo-sdk%402.0.2), [C#](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fcsharp-sdk%402.0.2), [Java](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fjava-sdk%402.0.2), [PHP](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fphp-sdk%402.0.2) और [Ruby](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fruby-sdk%402.0.2).
- इस रिलीज़ में रनटाइम अनुरोधों के मॉडल ID को जनरेट किए गए कॉल करने योग्य हेल्पर कॉन्स्टैंट से अलग किया गया, ताकि नए मॉडल अगली SDK रिलीज़ से पहले ही इस्तेमाल किए जा सकें।
- जनरेट किए गए हेल्पर अब गेटवे पर मौजूदा कॉल करने योग्य मॉडल स्नैपशॉट को ट्रैक करते हैं, जिससे केवल कैटलॉग अपडेट के कारण SDK में होने वाले अनावश्यक बदलाव कम होते हैं।
