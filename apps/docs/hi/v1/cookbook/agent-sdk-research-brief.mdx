एक TypeScript एजेंट बनाएँ जो जवाब देने से पहले Phaseo के ज़रिए वेब पर खोजे, और स्रोतों के साथ शोध ब्रीफ़ सख्त JSON के रूप में लौटाए। अंत में आपके पास एक स्क्रिप्ट होगी जो आपके दिए किसी भी विषय के लिए सत्यापित `{ topic, summary, sources }` ऑब्जेक्ट प्रिंट करती है।

यह स्क्रिप्ट एक बार के शोध के लिए प्रोडक्शन के लिए तैयार है। खोज के नतीजे अविश्वसनीय वेब सामग्री हैं: नीचे की स्कीमा जाँच गलत रूप वाले आउटपुट को रोकती है, लेकिन उन पर अमल करने से पहले स्रोतों की समीक्षा करें। पैकेज किया गया संस्करण `packages/sdk/agent-sdk-ts/examples/research-brief-agent.ts` में है।

```ts research-agent.ts
import { z } from "zod";
import { createAgent, createGatewayAgentClient } from "@phaseo/agent-sdk";

// इतना छोटा कि एक लॉग लाइन में पढ़ा जा सके।
const ResearchBrief = z
  .object({
    topic: z.string(),
    summary: z.string().min(1),
    sources: z.array(z.object({ title: z.string(), url: z.string().url() }).strict()).min(1),
  })
  .strict();
type ResearchBrief = z.infer<typeof ResearchBrief>;

const researchBriefAgent = createAgent<string, ResearchBrief>({
  id: "research-brief-agent",
  model: "openai/gpt-6-astra",
  instructions:
    "Research the user's topic with web search and return a concise JSON brief with cited sources.",
  maxSteps: 4,
  parseOutput: (text) => JSON.parse(text),
  outputSchema: ResearchBrief,
});

const client = createGatewayAgentClient({
  clientOptions: { apiKey: process.env.PHASEO_API_KEY! },
  // वह JSON Schema जो Gateway मॉडल से माँगता है।
  responseFormat: {
    type: "json_schema",
    name: "research_brief",
    schema: {
      type: "object",
      properties: {
        topic: { type: "string" },
        summary: { type: "string" },
        sources: {
          type: "array",
          items: {
            type: "object",
            properties: { title: { type: "string" }, url: { type: "string" } },
            required: ["title", "url"],
            additionalProperties: false,
          },
          minItems: 1,
        },
      },
      required: ["topic", "summary", "sources"],
      additionalProperties: false,
    },
  },
  // लगभग-सही JSON की मरम्मत करें।
  plugins: [{ id: "response-healing" }],
  // खोज Phaseo चलाता है; क्वेरी मॉडल लिखता है।
  gatewayTools: [{ type: "phaseo:web_search", parameters: { max_results: 5 } }],
  // जवाब देने से पहले हमेशा खोजें।
  toolChoice: "phaseo:web_search",
  webSearchOptions: { search_context_size: "high" },
});

const result = await researchBriefAgent.run({
  input: "Summarize the latest browser automation support patterns for coding agents.",
  client,
  onEvent(event) {
    console.log(event.type, event.runId);
  },
});

console.log(result.output);
```

| क्लाइंट विकल्प | क्या करता है |
| --- | --- |
| `responseFormat` | आउटपुट स्कीमा को स्पष्ट रखता है |
| `plugins` | लगभग-सही JSON के लिए [response healing](./response-healing-for-structured-json) |
| `gatewayTools` | `phaseo:web_search` जोड़ता है; [वेब खोज गाइड](../guides/server-tools/web-search) में इसके पैरामीटर हैं |
| `toolChoice` | ऐसे वर्कफ़्लो के लिए खोज ज़रूरी बनाता है जिसे हमेशा खुद को स्रोतों पर आधारित करना है |
| `webSearchOptions` | उन इंजनों के लिए खोज सेटिंग जो अपने नतीजों का आकार तय करते हैं |

## जाँचें कि यह काम किया

स्क्रिप्ट कम से कम एक स्रोत URL वाला ब्रीफ़ प्रिंट करती है। फिर **सेटिंग → उपयोग → लॉग्स** में अनुरोध खोलें और जाँचें:

- **वेब खोज की निगरानी** में प्रबंधित खोजें, नतीजे और उद्धरण दिखते हैं।
- प्लगइन रिकॉर्ड `response-healing` को `applied` सिर्फ़ तब दिखाता है जब JSON की मरम्मत की ज़रूरत पड़ी हो।
- प्रतिक्रिया स्कीमा से मेल खाती थी; मेल न खाने पर रन `AgentSchemaValidationError` के साथ विफल हो जाता।

जिन मामलों में कोई खोज नहीं चली, उनके लिए [वेब खोज डीबग करें](./web-search-debugging) देखें।

## कब कुछ और इस्तेमाल करें

यह तरीका एक बार के ऐसे शोध के लिए सही है जहाँ मॉडल को खुद को स्रोतों पर आधारित करना हो और कॉल करने वालों को टाइप किया हुआ JSON चाहिए। जब आपको URL पहले से पता हों, तो [`phaseo:web_fetch`](./tool-grounding-with-web-fetch) इस्तेमाल करें; जब काम को वेब से ज़्यादा आपके अपने डेटा की ज़रूरत हो, तो [स्थानीय-टूल एजेंट](./agent-sdk-durable-loop); और जब अनुबंध इतना ढीला हो कि स्कीमा जितना बचाता है उससे ज़्यादा काम जोड़ता है, तो सादा टेक्स्ट आउटपुट।
