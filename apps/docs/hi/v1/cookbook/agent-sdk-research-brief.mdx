जब किसी एजेंट वर्कफ़्लो को यह करना हो, तब यह तरीका अपनाएँ:

- TypeScript Agent SDK से चलना
- प्रबंधित वेब खोज पर निर्भर रहना
- सख्त संरचित JSON लौटाना
- लगभग सही लेकिन गलत फ़ॉर्मैट वाले JSON को नियतात्मक तरीके से रिकवर करना

## 2. एक सीमित आउटपुट अनुबंध तय करें

शोध का पहला आउटपुट इतना छोटा रखें कि ऑपरेटर उसे लॉग में आसानी से जाँच सकें।

```ts
type ResearchBrief = {
  topic: string;
  summary: string;
  sources: Array<{
    title: string;
    url: string;
  }>;
};
```

## 3. एजेंट बनाएँ

`parseOutput` इस्तेमाल करें ताकि रनटाइम कच्चे टेक्स्ट के बजाय प्रकारयुक्त डेटा लौटाए।

```ts
import { createAgent } from "@phaseo/agent-sdk";

export const researchBriefAgent = createAgent<string, ResearchBrief>({
  id: "research-brief-agent",
  model: "phaseo/free",
  instructions:
    "Research the user's topic with web search when needed and return a concise JSON brief with cited sources.",
  parseOutput(text) {
    return JSON.parse(text) as ResearchBrief;
  },
});
```

## 4. Gateway से जुड़े एडाप्टर को एक बार कॉन्फ़िगर करें

यह सबसे महत्वपूर्ण हिस्सा है:

- `responseFormat` आउटपुट स्कीमा स्पष्ट रखता है
- `plugins` लगभग सही JSON के लिए प्रतिक्रिया सुधार चालू करता है
- `gatewayTools` मॉडल को प्रबंधित वेब खोज उपलब्ध कराता है
- जब वर्कफ़्लो को हमेशा स्रोतों पर आधारित रहना हो, तो `toolChoice` खोज टूल को अनिवार्य करता है

```ts
import {
  createGatewayAgentClient,
} from "@phaseo/agent-sdk";

const client = createGatewayAgentClient({
  clientOptions: {
    apiKey: process.env.PHASEO_API_KEY!,
  },
  responseFormat: {
    type: "json_schema",
    name: "research_brief",
    schema: {
      type: "object",
      properties: {
        topic: { type: "string" },
        summary: { type: "string" },
        sources: {
          type: "array",
          items: {
            type: "object",
            properties: {
              title: { type: "string" },
              url: { type: "string" },
            },
            required: ["title", "url"],
            additionalProperties: false,
          },
          minItems: 1,
        },
      },
      required: ["topic", "summary", "sources"],
      additionalProperties: false,
    },
  },
  plugins: [{ id: "response-healing" }],
  gatewayTools: [
    { type: "phaseo:web_search", parameters: { max_results: 5 } },
  ],
  toolChoice: "phaseo:web_search",
  webSearchOptions: { search_context_size: "high" },
});
```

## 5. वर्कफ़्लो चलाएँ

```ts
const result = await researchBriefAgent.run({
  input: "Summarize the latest browser automation support patterns for coding agents.",
  client,
  onEvent(event) {
    console.log(event.type, event.runId);
  },
});

console.log(result.output);
```

## 6. लॉग में क्या जाँचें

एक सफल रन के बाद अनुरोध विवरण खोलें और पुष्टि करें:

- `requested native web search tools` या प्रबंधित खोज गतिविधि मौजूद है
- खोज परिणाम और उद्धरण सहेजे गए हैं
- प्लगइन निष्पादन में `response-healing` तभी दिखता है जब रिकवरी की ज़रूरत पड़ी हो
- अंतिम आउटपुट आपके माँगे गए JSON स्कीमा से मेल खाता है

## 7. यह तरीका कब इस्तेमाल करें

यह तरीका तब अपनाएँ जब:

- वर्कफ़्लो मुख्य रूप से एक बार का शोध हो, न कि स्थानीय टूल का गहरा लूप
- जवाब देने से पहले मॉडल को स्रोत देखने चाहिए
- आगे के कॉलर को गद्य के बजाय प्रकारयुक्त JSON चाहिए

यह तरीका तब न अपनाएँ जब:

- वर्कफ़्लो को सटीक URL पहले से पता हों और `phaseo:web_fetch` पर्याप्त हो
- एजेंट को अपस्ट्रीम प्रदाता के नेटिव टूल से ज़्यादा समृद्ध स्थानीय टूल चाहिए
- आउटपुट अनुबंध इतना ढीला हो कि सख्त JSON से मिलने वाले लाभ से ज़्यादा काम बढ़े
