जब किसी Python वर्कफ़्लो को इनकी ज़रूरत हो, तो यह रेसिपी उपयोग करें:

- एक स्थानीय लुकअप टूल
- एक सीमित एजेंट लूप
- एक सख्त JSON आउटपुट संरचना

## 1. SDK तैयार करें

<Note type="warning">Python Agent SDK पैकेज अभी PyPI पर उपलब्ध नहीं है। [सोर्स से इंस्टॉल करने के निर्देश](../sdk-reference/python/agent-sdk-installation.mdx) देखें।</Note>

## 2. स्थानीय टूल तय करें

```python
from phaseo_agent import AgentTool, define_tool

lookup_policy = define_tool(
    AgentTool(
        id="lookup-policy",
        description="Look up one internal policy by slug.",
        parameters={
            "type": "object",
            "properties": {
                "slug": {"type": "string"},
            },
            "required": ["slug"],
            "additionalProperties": False,
        },
        execute=lambda input, ctx: {
            "slug": input["slug"],
            "summary": "Presets centralize routing, prompts, and caching defaults.",
        },
    )
)
```

## 3. एजेंट बनाएँ

```python
from phaseo_agent import create_agent

agent = create_agent(
    {
        "id": "policy-extractor",
        "model": "openai/gpt-5.4-nano",
        "instructions": "Use tools when needed and return concise JSON.",
        "tools": [lookup_policy],
        "parse_output": lambda text: text,
    }
)
```

## 4. Gateway-आधारित क्लाइंट के ज़रिए एजेंट चलाएँ

```python
from phaseo_agent import create_gateway_agent_client

result = agent.run(
    input="Look up presets and return JSON with keys summary and recommendation.",
    client=create_gateway_agent_client(),
)

print(result.output)
```

## 5. यह रेसिपी कब उपयुक्त है

- ऑर्केस्ट्रेशन की ज़िम्मेदारी एक Python वर्कर के पास हो
- टूल स्थानीय और नियतात्मक हों
- पहले कोई बड़ी ऑर्केस्ट्रेशन परत बनाए बिना आपको सख्त आउटपुट चाहिए
