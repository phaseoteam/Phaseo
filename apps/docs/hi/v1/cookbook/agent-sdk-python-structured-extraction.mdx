एक Python एजेंट चलाएँ जो एक स्थानीय टूल से कुछ खोजे और अपना जवाब सख्त JSON के रूप में लौटाए। अंत में आपके पास एक स्क्रिप्ट होगी जिसका `result.output` खुला टेक्स्ट नहीं, बल्कि `summary` और `recommendation` वाला सत्यापित `PolicySummary` ऑब्जेक्ट होता है।

टूल तय नमूना डेटा लौटाता है, इसलिए यह स्क्रिप्ट उदाहरण के लिए है; इसे अपने lookup से बदलें। यह ऐसे Python worker के लिए सही है जो अपना ऑर्केस्ट्रेशन खुद संभालता है और जिसके पास छोटा, निर्धारक टूल सेट है।


<Step title="एजेंट लिखें">

```python extract.py
import json
import os

from pydantic import BaseModel, ConfigDict

from phaseo_agent import AgentTool, create_agent, create_gateway_agent_client, define_tool

POLICY_SLUGS = {"presets", "routing", "guardrails"}


class PolicySummary(BaseModel):
    model_config = ConfigDict(extra="forbid")
    summary: str
    recommendation: str


def check_lookup_input(value):
    # मॉडल के बनाए आर्ग्युमेंट: जो ज्ञात slug नहीं है, उसे अस्वीकार करें।
    if not isinstance(value, dict) or set(value) != {"slug"} or value["slug"] not in POLICY_SLUGS:
        raise ValueError(f"slug must be one of {sorted(POLICY_SLUGS)}")
    return value


lookup_policy = define_tool(
    AgentTool(
        id="lookup-policy",
        description="Look up one internal policy by slug.",
        parameters={
            "type": "object",
            "properties": {"slug": {"type": "string", "enum": sorted(POLICY_SLUGS)}},
            "required": ["slug"],
            "additionalProperties": False,
        },
        input_schema=check_lookup_input,
        execute=lambda input, ctx: {
            "slug": input["slug"],
            "summary": "Presets centralize routing, prompts, and caching defaults.",
        },
    )
)

agent = create_agent(
    {
        "id": "policy-extractor",
        "model": "openai/gpt-6-astra",
        "instructions": "Use tools when needed and return JSON with summary and recommendation.",
        "tools": [lookup_policy],
        "max_steps": 4,
        "parse_output": json.loads,
        "output_schema": PolicySummary,
    }
)

# Python क्लाइंट PHASEO_API_KEY खुद नहीं पढ़ता: इसे पास करें।
client = create_gateway_agent_client(
    client_options={"api_key": os.environ["PHASEO_API_KEY"]},
    response_format={
        "type": "json_schema",
        "name": "policy_summary",
        "schema": {
            "type": "object",
            "properties": {
                "summary": {"type": "string"},
                "recommendation": {"type": "string"},
            },
            "required": ["summary", "recommendation"],
            "additionalProperties": False,
        },
    },
    plugins=[{"id": "response-healing"}],
)

result = agent.run(input="Look up our presets policy and recommend when to use it.", client=client)

print(result.run.status)
print(result.output)
```

| हिस्सा | क्या करता है |
| --- | --- |
| `parameters` | टूल के आर्ग्युमेंट के लिए वह JSON Schema जो मॉडल देखता है |
| `input_schema` | `execute` चलने से पहले आर्ग्युमेंट जाँचता है; गलत कॉल रन को विफल कर देती है |
| `response_format` | हर टर्न पर Gateway से यही JSON Schema माँगता है |
| `parse_output` और `output_schema` | अंतिम टेक्स्ट को पार्स करके `PolicySummary` में सत्यापित करते हैं |

## जाँचें कि यह काम किया

- स्क्रिप्ट `completed` प्रिंट करती है, फिर दोनों फ़ील्ड भरा हुआ `PolicySummary`।
- **सेटिंग → उपयोग → लॉग्स** में पहले मॉडल टर्न में `{"slug": "presets"}` के साथ `lookup-policy` कॉल दिखती है।
- (Pydantic) मॉडल से मेल न खाने वाला आउटपुट आधा भरा ऑब्जेक्ट लौटाने के बजाय `Invalid agent output` के साथ विफल होता है।

टूल के बिना एक बार के संरचित आउटपुट के लिए [Python SDK को सीधे](./sdk-python-presets-and-json) कॉल करें। [Python Agent SDK संदर्भ](../sdk-reference/agent/usage) में स्थिति, अनुमोदन और स्ट्रीमिंग की जानकारी है।
