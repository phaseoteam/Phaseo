जब आप कोडिंग एजेंट को अस्पष्ट इंटीग्रेशन योजना के बजाय छोटा, काम करने वाला ऐप बनाने वाला ठोस प्रॉम्प्ट देना चाहें, तब इस पेज का उपयोग करें।

<Tip>
इन प्रॉम्प्ट को परिणाम पर केंद्रित और कार्यान्वयन-विशिष्ट बनाया गया है, ताकि Cursor, Claude Code, Codex और ऐसे अन्य टूल में बेहतर काम करें।
</Tip>

## इन प्रॉम्प्ट का उपयोग कैसे करें

<Steps>
  <Step title="इंटीग्रेशन का तरीका चुनें">
    ऐसा प्रॉम्प्ट चुनें जो ऐप द्वारा Phaseo को कॉल करने के तरीके से मेल खाता हो:

    - रॉ HTTP
    - एक आधिकारिक SDK
    - Vercel AI SDK
    - Agent SDK
  </Step>
  <Step title="स्क्वायर ब्रैकेट वाले वेरिएबल बदलें">
    कोडिंग एजेंट में प्रॉम्प्ट पेस्ट करने से पहले `[ऐप का विचार]`, `[फ़्रेमवर्क]`, `[मॉडल]` और `[LANGUAGE]` जैसी वैल्यू भरें।
  </Step>
  <Step title="सिर्फ़ कोड नहीं, सत्यापन भी माँगें">
    प्रॉम्प्ट में सत्यापन वाली पंक्तियाँ रखें। इससे एजेंट को बताना होगा कि उसने वास्तव में क्या चलाया, क्या मान लिया और अभी क्या मैन्युअल सेटअप चाहिए।
  </Step>
</Steps>

## प्रॉम्प्ट को बेहतर कैसे बनाएँ

- `[ऐप का विचार]` में व्यापक उत्पाद विवरण के बजाय उपयोगकर्ता का एक सीमित कार्य लिखें।
- `[मॉडल]` को एजेंट द्वारा उपयोग की जाने वाली सटीक मॉडल ID से बदलें।
- बताएँ कि आउटपुट मुक्त टेक्स्ट, सख्त JSON, चैट या एक जनरेटेड एसेट होना चाहिए।
- पता हो तो UI फ़्रेमवर्क और डिप्लॉयमेंट लक्ष्य बताएँ।
- एक या दो ज़रूरी पाबंदियाँ जोड़ें, जैसे `केवल EU प्रदाता`, `स्ट्रीमिंग उपयोग करें` या `सभी सीक्रेट सर्वर पर रखें`।
