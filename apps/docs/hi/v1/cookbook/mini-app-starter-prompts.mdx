इनमें से कोई एक प्रॉम्प्ट Cursor, Claude Code, Codex या किसी मिलते-जुलते कोडिंग एजेंट में पेस्ट करें, और वह एक छोटा काम करता Phaseo ऐप बनाता है, फिर बताता है कि उसने क्या चलाया और क्या नहीं जाँच सका। हर प्रॉम्प्ट इंटीग्रेशन सरफ़ेस, सुरक्षा नियम और आप जो जाँच चाहते हैं, उन्हें स्पष्ट करता है।

इनसे बनने वाले ऐप शुरुआती बिंदु हैं: डिप्लॉय करने से पहले कोड की समीक्षा करें, खासकर सीक्रेट संभालने और टूल वैलिडेशन की।

## प्रॉम्प्ट का उपयोग करें

<Steps>
  <Step title="इंटीग्रेशन सरफ़ेस चुनें">
    | प्रॉम्प्ट | Phaseo को कॉल करता है |
    | --- | --- |
    | सीधा HTTP | `https://api.phaseo.app/v1` पर `fetch` |
    | TypeScript SDK | `@phaseo/sdk` |
    | Python SDK | `phaseo` |
    | Vercel AI SDK | `@phaseo/ai-sdk-provider` |
    | Agent SDK | `@phaseo/agent-sdk`, `phaseo-agent-sdk`, या आपकी भाषा का Agent SDK |
  </Step>
  <Step title="ब्रैकेट वाले वेरिएबल बदलें">
    प्रॉम्प्ट को अपने कोडिंग एजेंट में पेस्ट करने से पहले `[APP IDEA]`, `[FRAMEWORK]`, `[MODEL]` और `[LANGUAGE]` जैसे मान भरें।
  </Step>
  <Step title="सिर्फ़ कोड नहीं, जाँच भी माँगें">
    प्रॉम्प्ट में जाँच वाली पंक्तियाँ रहने दें। वे एजेंट को यह बताने के लिए मजबूर करती हैं कि उसने असल में क्या चलाया, क्या माना, और किसके लिए अभी भी मैन्युअल सेटअप चाहिए।
  </Step>
</Steps>

## प्रॉम्प्ट को बेहतर कैसे बनाएँ

- `[APP IDEA]` को किसी व्यापक प्रोडक्ट पिच के बजाय उपयोगकर्ता के एक सीमित काम से बदलें।
- `[MODEL]` को उस सटीक मॉडल ID से बदलें जिसे आप एजेंट से इस्तेमाल करवाना चाहते हैं।
- बताएँ कि आउटपुट खुला टेक्स्ट, सख्त JSON, चैट, या एक जनरेट किया गया एसेट होना चाहिए।
- अगर आपको पता हो, तो UI फ़्रेमवर्क और डिप्लॉयमेंट लक्ष्य बताएँ।
- एक या दो ज़रूरी शर्तें जोड़ें, जैसे `EU-only providers`, `use streaming`, या `keep all secrets server-side`।

[TypeScript और Python SDK](../sdk-reference/client/overview) और [Agent SDK](../sdk-reference/agent/overview) के संदर्भ बताते हैं कि हर पैकेज क्या देता है, ताकि आप एजेंट के कोड को उनसे मिलाकर जाँच सकें।
