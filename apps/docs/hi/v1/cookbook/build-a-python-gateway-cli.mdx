**लक्ष्य:** छोटे Python कमांड-लाइन ऐप्लिकेशन से Phaseo के कंट्रोल और जनरेशन रूट चलाना।

## नमूना प्रोजेक्ट

- GitHub: [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart)
- रिपॉज़िटरी का स्थानीय पाथ: `examples/gateway-python-quickstart`

## यह ऐप क्या करता है

- इन जैसे कंट्रोल रूट का समर्थन करता है:
  - `GET /v1/health`
  - `GET /v1/models`
  - `GET /v1/providers`
- इन जैसे जनरेशन रूट का समर्थन करता है:
  - `POST /v1/responses`
  - `POST /v1/chat/completions`
  - `POST /v1/embeddings`
  - और कई अन्य एंडपॉइंट

## यह नमूना क्यों उपयोगी है

इससे आपको मिलता है:

- बिना थर्ड-पार्टी निर्भरताओं के Python-आधारित संदर्भ
- स्पष्ट अनुरोध पेलोड और रिस्पॉन्स हैंडलिंग
- workers, स्क्रिप्ट और आंतरिक टूल के लिए व्यावहारिक पैटर्न

## आवश्यकताएँ

- Python 3
- Phaseo API कुंजी

## नमूना चलाएँ

```bash
cd examples/gateway-python-quickstart
cp .env.example .env.local
```

यह सेट करें:

- `PHASEO_API_KEY`

फिर चलाएँ:

```bash
python quickstart.py smoke
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

## अपना काम जाँचें

- स्मोक मोड पुष्टि करता है कि API तक पहुँचा जा सकता है।
- Responses कमांड `integration_ok` प्रिंट करता है।
- `--help` बिना अनुरोध भेजे उपलब्ध कमांड दिखाता है।
- टर्मिनल में प्रमाणीकरण और API की त्रुटियाँ साफ़ दिखाई देती हैं।

## कोड में क्या देखें

- वातावरण कैसे लोड किया जाता है
- CLI कमांड कैसे भेजता है
- अलग-अलग अनुरोध पेलोड कैसे बनाए जाते हैं
- एसिंक्रोनस वीडियो और म्यूज़िक रूट को एकल-उत्तर वाले टेक्स्ट रूट से अलग कैसे संभाला जाता है

## नमूने को अपने लिए ढालें

- अपने सेवा में काम न आने वाले एंडपॉइंट हटाएँ
- हर जगह हेडर दोहराने के बजाय एक साझा अनुरोध हेल्पर रखें
- आगे चलकर उच्च-स्तरीय क्लाइंट चाहिए तो Python SDK पर जाएँ
