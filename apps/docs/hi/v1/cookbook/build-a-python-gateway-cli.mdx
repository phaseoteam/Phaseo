सिर्फ़ स्टैंडर्ड लाइब्रेरी वाली Python CLI चलाएँ जो एक बार में एक कमांड से Phaseo एंडपॉइंट कॉल करती है। अंत में आपके पास health, models, Responses और Chat Completions के लिए काम करता हुआ `python quickstart.py <command>` होगा, साथ ही एम्बेडिंग, मॉडरेशन, इमेज, OCR, वीडियो और म्यूज़िक की कमांड भी, जिन्हें आप किसी वर्कर या बैकएंड में कॉपी कर सकते हैं।

यह CLI उदाहरण के लिए है: यह अनुरोधों के ढाँचे का संदर्भ है, कोई पैकेज्ड टूल नहीं। मीडिया कमांड के कई डिफ़ॉल्ट मॉडल ID अब उपलब्ध नहीं हैं, इसलिए उनके लिए `--model` दें ([मीडिया कमांड के लिए मॉडल चुनें](#pick-models-for-the-media-commands) देखें)।

किसी कोडिंग एजेंट से ऐसी ही CLI शुरू से बनवाने के लिए, यह प्रॉम्प्ट पेस्ट करें:

## CLI क्या करती है

सैंपल [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) है: एक फ़ाइल, `quickstart.py`, जो सिर्फ़ `urllib`, `json` और `argparse` का उपयोग करती है।

| कमांड | कॉल |
| --- | --- |
| `smoke` | `GET /v1/health`, `GET /v1/models`, `GET /v1/providers`, और एक `POST /v1/responses` |
| `health`, `models`, `providers` | संबंधित `GET` रूट |
| `responses --prompt` | `POST /v1/responses` |
| `chat --prompt` | `POST /v1/chat/completions` |
| `embeddings --text` | `POST /v1/embeddings` |
| `moderations --text` | `POST /v1/moderations` |
| `image --prompt` | `POST /v1/images/generations` |
| `ocr --image-url` | `POST /v1/ocr` |
| `video-create`, `video-status`, `video-cancel`, `video-download-url` | `POST /v1/videos`, `GET /v1/videos/{video_id}`, `POST /v1/videos/{video_id}/cancel`, `POST /v1/videos/{video_id}/download_url` |
| `music-create`, `music-status` | `POST /v1/music/generate`, `GET /v1/music/generate/{music_id}` |

हर अनुरोध `429`, `5xx` और नेटवर्क त्रुटियों पर दो बार दोबारा कोशिश करता है, पहले 1 s और फिर 2 s रुककर, और 45 सेकंड बाद टाइम आउट हो जाता है। जब कॉल `2xx` नहीं होती, तो हर कमांड `1` के साथ बाहर निकलती है, इसलिए आप इसे स्क्रिप्ट में इस्तेमाल कर सकते हैं।

## इसे चलाएँ

आपको Python 3 और एक Phaseo API कुंजी चाहिए।

<Steps>
<Step title=".env.local बनाएँ">

स्क्रिप्ट उसी फ़ोल्डर से `.env.local` पढ़ती है जिसमें आप उसे चलाते हैं। सैंपल में `.env.example` नहीं है, इसलिए फ़ाइल खुद बनाएँ:

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# Optional
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My Python CLI
PHASEO_HTTP_REFERER=https://myapp.example
```

आपके शेल में पहले से सेट वेरिएबल फ़ाइल के मानों पर भारी पड़ते हैं। `PHASEO_MODEL` के बिना, टेक्स्ट कमांड `openai/gpt-5.6-sol` का उपयोग करती हैं।

</Step>
<Step title="स्मोक जाँच चलाएँ">

```bash
cd examples/gateway-python-quickstart
python quickstart.py smoke
```

`smoke` एक छोटा Responses अनुरोध भी भेजता है, इसलिए इसमें कुछ क्रेडिट खर्च होते हैं।

</Step>
<Step title="एक अनुरोध भेजें">

```bash
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

</Step>
</Steps>

## जाँचें कि यह काम कर गया

- `smoke` हर ब्लॉक के लिए `HTTP 200` प्रिंट करता है और `0` के साथ बाहर निकलता है।
- `responses` कमांड के आउटपुट में `integration_ok` होता है।
- `--help` कोई अनुरोध किए बिना कमांड सूचीबद्ध करता है।
- कुंजी के बिना, स्क्रिप्ट `Missing PHASEO_API_KEY` प्रिंट करती है और `1` के साथ बाहर निकलती है।
- अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखते हैं।

## मीडिया कमांड के लिए मॉडल चुनें

`quickstart.py` के ये डिफ़ॉल्ट रिटायर हो चुके हैं या इनका कोई सक्रिय प्रदाता नहीं है। `--model` से कोई मौजूदा मॉडल दें, और उसे [मॉडल पेज](https://phaseo.app/models) या `python quickstart.py models` से चुनें:

| कमांड | सैंपल में डिफ़ॉल्ट | स्थिति |
| --- | --- | --- |
| `moderations` | `openai/omni-moderation-latest` | कैटलॉग ID नहीं है; `openai/omni-moderation` का उपयोग करें |
| `ocr` | `mistral/mistral-ocr` | रिटायर; `mistral/ocr-4.1` आज़माएँ |
| `video-create` | `openai/sora-2` | रिटायर |
| `music-create` | `suno/suno-v4` | कोई सक्रिय प्रदाता नहीं |

`embeddings` (`google/gemini-embedding-2`) और `image` (`openai/gpt-image-2`) के डिफ़ॉल्ट उपलब्ध हैं। वीडियो और म्यूज़िक जॉब एसिंक्रोनस होते हैं: लौटाया गया ID सहेजें और स्टेटस कमांड से पोल करें; जॉब का लाइफ़साइकल [एसिंक वीडियो और बैच](../guides/async-video-and-batch) में बताया गया है।

फ़ाइल को सिर्फ़ उन कमांड तक छोटा करें जिनकी आपकी सेवा को ज़रूरत है, एक साझा `gateway_request()` हेल्पर रखें, और टाइप किए गए अनुरोध चाहिए हों तो [Python SDK](../sdk-reference/client/overview) पर जाएँ।
