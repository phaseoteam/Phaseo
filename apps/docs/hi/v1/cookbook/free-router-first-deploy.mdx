किसी सशुल्क मॉडल को अभी चुने बिना अपनी पहली Phaseo इंटीग्रेशन शुरू करने के लिए इस गाइड का उपयोग करें।

खुद कोई मुफ़्त मॉडल चुनने के बजाय अनुरोध `phaseo/free` पर भेजें। Phaseo उस अनुरोध को संभालने वाला उपलब्ध मुफ़्त मॉडल चुनेगा।

## इसका उपयोग कब करें

- आप सशुल्क मॉडल चुनने से पहले काम करता हुआ प्रोटोटाइप चाहते हैं।
- आपको उम्मीद है कि सबसे अच्छा मुफ़्त विकल्प समय के साथ बदलता रहेगा।
- आप ऐप्लिकेशन कोड में एक स्थिर मॉडल ID चाहते हैं, जबकि Phaseo पर्दे के पीछे मुफ़्त प्रदाताओं में होने वाले बदलाव सँभालता है।

## अनुरोध का उदाहरण

```bash cURL
  -d '{

    "temperature": 0.2
  }'
```


```go Go SDK
package main

import (
  "context"
  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New("YOUR_API_KEY", "https://api.phaseo.app/v1")

  response, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
    Model: "phaseo/free",
    Input: map[string]interface{}{
      "role": "user",
      "content": []map[string]string{
        {
          "type": "input_text",
          "text": "Summarize why provider-aware free routing helps prototypes.",
        },
      },
    },
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(response)
}
```

## अंदर क्या होता है

1. आपका अनुरोध साझा `phaseo/free` एलियास पर जाता है।
2. Phaseo जांचता है कि कौन-से मुफ़्त मॉडल उस अनुरोध को संभाल सकते हैं।
3. एक उपलब्ध मुफ़्त मॉडल चुना जाता है और प्रतिक्रिया के लिए उसी का उपयोग होता है।
4. अनुरोध के विवरण में फिर भी वही सटीक मॉडल दिखता है जो चला था, ताकि आप बाद में इसकी जांच या डीबग कर सकें।

## पहले अनुरोध के बाद

- **Gateway -> उपयोग** में अनुरोध के विवरण खोलें और पुष्टि करें कि कौन-सा मॉडल इस्तेमाल हुआ।
- अगर वर्कस्पेस नीति अनुरोध रोकती है, तो अनुरोध के विवरण देखकर पता करें कि किस सेटिंग ने इसे रोका।
- अगर कोई मुफ़्त मॉडल ज़रूरी सुविधा नहीं देता, तो वही अनुरोध फिर से भेजने के बजाय `phaseo/free` से किसी खास सशुल्क मॉडल पर जाएं।

## प्रोडक्शन संबंधी बातें

- `phaseo/free` का इस्तेमाल प्रोटोटाइप, डेमो और कम जोखिम वाले ट्रैफ़िक के लिए करें।
- अगर आपको पूर्वानुमेय लेटेंसी, आउटपुट शैली या प्रदाता का चुनाव चाहिए, तो सबसे अच्छा विकल्प पता चलने पर किसी खास मॉडल पर जाएं।
- अगर अलग-अलग सेवाओं में प्रॉम्प्ट का व्यवहार एक जैसा रखना है, तो इस गाइड के साथ [प्रीसेट](../guides/presets.mdx) इस्तेमाल करें।
