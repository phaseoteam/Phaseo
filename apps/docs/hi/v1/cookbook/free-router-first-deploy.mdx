`"model": "phaseo/free"` भेजें और Phaseo आपका अनुरोध किसी ऐसे उपलब्ध फ़्री मॉडल पर चलाता है जो उसे सपोर्ट करता हो, बिना क्रेडिट के। अंत में आपकी पसंद की भाषा में आपके पास एक काम करता अनुरोध होगा और आप जानेंगे कि किस मॉडल ने जवाब दिया।

यह प्रोटोटाइप, डेमो और कम जोखिम वाले ट्रैफ़िक के लिए प्रोडक्शन-तैयार अनुरोध ढाँचा है। फ़्री मॉडल लेटेंसी, आउटपुट शैली या किसी तय प्रदाता का वादा नहीं करते।

```bash cURL
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```

```go Go
package main

import (
  "context"
  "fmt"
  "os"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New(os.Getenv("PHASEO_API_KEY"), "https://api.phaseo.app/v1")

  temperature := 0.2
  response, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
    Model:       "phaseo/free",
    Input:       "Summarize why provider-aware free routing helps prototypes.",
    Temperature: &temperature,
  })
  if err != nil {
    panic(err)
  }

  fmt.Printf("%+v\n", response)
}
```

<Step title="जाँचें कि किस मॉडल ने जवाब दिया">

**सेटिंग्स → उपयोग → लॉग्स** खोलें और अनुरोध चुनें। विवरण में वह सटीक मॉडल और प्रदाता दिखता है जिसने उसे चलाया, और अगर वर्कस्पेस नीति ने उसे रोका हो तो वह सेटिंग भी जिसने उसे रोका।

## फ़्री मॉडल कैसे चुना जाता है

1. आपका अनुरोध साझा `phaseo/free` उपनाम पर जाता है।
2. Phaseo वे फ़्री मॉडल रखता है जो इस अनुरोध को संभाल सकते हैं (एंडपॉइंट, पैरामीटर, टूल)।
3. यह अनुरोध उनमें से किसी एक को भेजता है।

फ़्री मॉडल डिफ़ॉल्ट रूप से हर उपयोगकर्ता के लिए हर UTC दिन 1,500 अनुरोधों का एक साझा कोटा इस्तेमाल करते हैं। उसके बाद, 00:00 UTC तक अनुरोध `phaseo_free_model_limit_exceeded` कोड के साथ `429` लौटाते हैं; [Gateway सीमाएँ](../api-reference/limits#gateway-limits) देखें।

## फ़्री राउटर से आगे बढ़ें

अगर कोई भी फ़्री मॉडल आपकी ज़रूरत की सुविधा, जैसे टूल या JSON Schema, सपोर्ट नहीं करता, तो वही अनुरोध दोबारा भेजने के बजाय किसी खास पेड मॉडल पर जाएँ। जब आपको अनुमानित लेटेंसी, आउटपुट शैली या प्रदाता का चुनाव चाहिए, तो किसी तय मॉडल पर जाएँ, और साझा सेटिंग्स एक [प्रीसेट](../guides/presets) में रखें ताकि हर सेवा एक जैसा अनुरोध भेजे। [रूटिंग और फ़ॉलबैक](../guides/routing-and-fallbacks) बताता है कि पेड अनुरोध प्रदाता कैसे चुनते हैं, और [API त्रुटियाँ](../api-reference/errors) त्रुटि कोड सूचीबद्ध करता है।
