## सैंपल प्रोजेक्ट

- GitHub: [examples/gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart)
- रिपॉज़िटरी में स्थानीय पथ: `examples/gateway-node-quickstart`

## यह ऐप क्या करता है

- कॉल करता है `GET /v1/health`
- कॉल करता है `GET /v1/models`
- जैसे generation routes का परीक्षण करता है `POST /v1/responses`
- smoke tests, scripts और backend checks के लिए raw HTTP उदाहरण देता है

## यह सैंपल कब सही है

इन स्थितियों में यहां से शुरू करें:

- आप raw API calls सीधे डीबग करना चाहते हैं
- आप अभी SDK abstractions नहीं चाहते
- आप web UI के बजाय script, worker या CLI बना रहे हैं

## ज़रूरी चीज़ें

- built-in `fetch` support
- Phaseo API key

## सैंपल चलाएं

```bash
cd examples/gateway-node-quickstart
cp .env.example .env.local
```

यह सेट करें:

- `PHASEO_API_KEY`

फिर इनमें से कोई एक चलाएं:

```bash
npm run smoke
```

या:

```bash
npm run start
```

## काम की जांच करें

- Smoke mode API की पहुंच की पुष्टि करता है।
- मॉडल खोज में कम-से-कम एक मॉडल लौटता है।
- पूरा रन एक सफल generation response प्रिंट करता है।
- Authentication और non-200 responses पर टर्मिनल में स्पष्ट errors दिखती हैं।

## कोड में किन बातों को देखें

- script कैसे लोड करता है `.env.local`
- authorization header कैसे जोड़ा जाता है
- हर अनुरोध स्पष्ट रूप से कैसे बनाया जाता है
- non-200 responses को दबाने के बजाय कैसे दिखाया जाता है

## इसे अपने मुताबिक कैसे बनाएं

- script में केवल वही routes रखें जिनकी service को ज़रूरत है
- कई scripts में साझा request code को एक helper में रखें
- raw HTTP code दोहराने लगे तो बाद में TypeScript SDK पर जाएं
