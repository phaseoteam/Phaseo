बिना किसी डिपेंडेंसी वाली Node.js स्क्रिप्ट चलाएँ जो सादे `fetch` से Phaseo को कॉल करती है, ताकि आप हर अनुरोध और प्रतिक्रिया देख सकें। अंत में आपके पास एक स्मोक टेस्ट होगा जिसे आप डिप्लॉय से पहले चला सकते हैं: यह जाँचता है कि API पहुँच में है, मॉडल सूचीबद्ध करता है, और Responses, Chat Completions और Embeddings को एक-एक अनुरोध भेजता है।

यह स्क्रिप्ट उदाहरण के लिए है: यह हर HTTP स्टेटस प्रिंट करती है, लेकिन हमेशा `0` के साथ बाहर निकलती है। इसलिए CI में इस पर भरोसा करने से पहले [इसे डिप्लॉय जाँच के रूप में इस्तेमाल करें](#use-it-as-a-deploy-check) में बताई गई एग्ज़िट-कोड जाँच जोड़ें।

किसी कोडिंग एजेंट से यही स्क्रिप्ट शुरू से बनवाने के लिए, यह प्रॉम्प्ट पेस्ट करें:

## स्क्रिप्ट क्या कॉल करती है

सैंपल [examples/gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) है: एक फ़ाइल, `index.mjs`, जिसमें कोई डिपेंडेंसी नहीं है।

| मोड | कॉल | क्रेडिट खर्च होते हैं |
| --- | --- | --- |
| `npm run smoke` | `GET /v1/health`, `GET /v1/models` | नहीं |
| `npm run start` | ऊपर के दोनों, फिर `POST /v1/responses`, `POST /v1/chat/completions`, `POST /v1/embeddings` | हाँ |

टेक्स्ट कॉल `PHASEO_MODEL` (डिफ़ॉल्ट `openai/gpt-5.6-sol`) को `Return exactly: integration_ok` भेजती हैं। एम्बेडिंग कॉल `google/gemini-embedding-2` का उपयोग करती है।

## इसे चलाएँ

आपको Node.js 18 या नया (बिल्ट-इन `fetch` के लिए) और एक Phaseo API कुंजी चाहिए।

<Steps>
<Step title=".env.local बनाएँ">

स्क्रिप्ट उसी फ़ोल्डर से `.env.local` लोड करती है जिसमें आप उसे चलाते हैं, बिना किसी पैकेज के। सैंपल में `.env.example` नहीं है, इसलिए फ़ाइल खुद बनाएँ:

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# Optional
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My smoke test
PHASEO_HTTP_REFERER=https://myapp.example
```

आपके शेल में पहले से सेट वेरिएबल फ़ाइल के मानों पर भारी पड़ते हैं।

</Step>
<Step title="स्मोक मोड चलाएँ">

```bash
cd examples/gateway-node-quickstart
npm run smoke
```

</Step>
<Step title="पूरा मोड चलाएँ">

```bash
npm run start
```

</Step>
</Steps>

## जाँचें कि यह काम कर गया

हर कॉल इस तरह का एक ब्लॉक प्रिंट करती है:

```text
=== Health ===
HTTP 200
{ ... }
```

- `Health` और `Models` में `HTTP 200` दिखता है, और `Models` कम से कम एक मॉडल सूचीबद्ध करता है।
- पूरे रन में, Responses और Chat Completions ब्लॉक में `integration_ok` होता है।
- गलत कुंजी होने पर, जनरेशन ब्लॉक चुपचाप दबाए जाने के बजाय `HTTP 401` और त्रुटि का बॉडी दिखाते हैं।
- अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखते हैं।

## इसे डिप्लॉय जाँच के रूप में इस्तेमाल करें

`request()` `{ status, ok, payload }` लौटाता है, लेकिन `ok` को कुछ भी नहीं जाँचता। `print()` की शुरुआत में एक पंक्ति जोड़ें ताकि कोई भी कॉल विफल होने पर स्क्रिप्ट `1` के साथ बाहर निकले:

```js index.mjs
function print(title, result) {
  if (!result.ok) process.exitCode = 1;
  console.log(`\n=== ${title} ===`);
  // ...rest unchanged
}
```

स्क्रिप्ट को सिर्फ़ उन रूट तक छोटा करें जिन्हें आपकी सेवा इस्तेमाल करती है, और अगर आप पेलोड हाथ से नहीं बनाना चाहते तो [TypeScript SDK](../sdk-reference/client/overview) पर जाएँ।
