यह गाइड उन टीमों के लिए है जो Gateway SDK के आधार पर आंतरिक टूल, CLI या कोडिंग-एजेंट वर्कफ़्लो बनाती हैं।

<Visibility for="humans">
<Note>
अगर हर skill को शुरू से लिखने के बजाय दोबारा इस्तेमाल किया जा सकने वाला शुरुआती सेटअप चाहिए, तो [phaseoteam/skills](https://github.com/phaseoteam/skills) से Phaseo की सार्वजनिक skills इंस्टॉल करें:

```bash
npx skills add phaseoteam/skills --agent codex --skill '*'
```

इसके बाद, प्रोजेक्ट-विशिष्ट निर्देश अपनी स्थानीय `SKILL.md` फ़ाइल में रखें।
</Note>
</Visibility>

<Visibility for="agents">
<Note>
दोबारा इस्तेमाल की जा सकने वाली Phaseo skills [phaseoteam/skills](https://github.com/phaseoteam/skills) में हैं। पहले इन्हें इस कमांड से इंस्टॉल करें:

```bash
npx skills add phaseoteam/skills --agent codex --skill '*'
```

फिर, प्रोजेक्ट-विशिष्ट निर्देश repository की `SKILL.md` फ़ाइल में जोड़ें।
</Note>
</Visibility>

मुख्य विचार सरल है:

- SDK सेटअप repository में रखें
- ऐसी `SKILL.md` फ़ाइल जोड़ें जो एजेंट को बताए कि प्रोजेक्ट अनुरोध कैसे भेजने की अपेक्षा करता है
- सेटअप के दौरान एजेंट को उस फ़ाइल की ओर निर्देशित करें, ताकि अनुरोधों का तरीका एक जैसा रहे

## 1. SDK इंस्टॉल करें

अगर आप TypeScript या JavaScript उपयोग कर रहे हैं:

<CodeGroup>

```bash npm
npm install @phaseo/sdk
```

```bash pnpm
pnpm add @phaseo/sdk
```

```bash yarn
yarn add @phaseo/sdk
```

```bash bun
bun add @phaseo/sdk
```

</CodeGroup>

अगर आप Python उपयोग कर रहे हैं:

```bash
pip install phaseo
```

## 2. प्रोजेक्ट की स्थानीय skill फ़ाइल जोड़ें

Repository के root में या आपकी टीम द्वारा इस्तेमाल किए जाने वाले agent skill स्थान पर `SKILL.md` बनाएँ।

```md
# Phaseo Gateway

- Use `https://api.phaseo.app/v1` as the gateway base URL.
- Read the API key from `PHASEO_API_KEY`.
- Prefer the Responses API for new text integrations.
- Use preset slugs when the repository defines shared request defaults.
- Log request ids and model ids for debugging.
- For async video jobs, store the returned id and poll status until terminal.
```

## 3. पहली इंटीग्रेशन छोटी रखें

कोडिंग एजेंट के लिए बड़े wrappers की तुलना में छोटे request helpers को दोबारा इस्तेमाल करना आसान होता है।

```ts
import Phaseo from "@phaseo/sdk";

export const gateway = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY!,
});
```

इसके बाद, हर surface के लिए एक स्पष्ट call path रखें:

- टेक्स्ट जनरेशन
- एसिंक्रोनस वीडियो
- embeddings
- इमेज जनरेशन

## 4. Skill में क्या दर्ज होना चाहिए

आपकी `SKILL.md` को उन सवालों के जवाब देने चाहिए जिनमें एजेंट का सबसे अधिक समय जाता है:

- किस endpoint family को प्राथमिकता देनी है
- क्रेडेंशियल किस environment variable में हैं
- कौन से model ID या preset slug स्वीकृत हैं
- request ID को कैसे लॉग करना है
- async jobs को कैसे ट्रैक करना है

## 5. Repository के लिए सुझाया गया पैटर्न

- SDK helpers के लिए एक साझा module
- integration code के पास या repository root में `SKILL.md`
- हर मुख्य endpoint के लिए एक छोटा उदाहरण
- request logging और error handling पर एक नोट

इससे लोगों और कोडिंग एजेंटों, दोनों को एक ही संचालन प्रवेश-बिंदु मिलता है।
