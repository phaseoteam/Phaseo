यह गाइड उन टीमों के लिए है जो Gateway SDK के आधार पर आंतरिक टूल, CLI या कोडिंग-एजेंट वर्कफ़्लो बनाती हैं।

<Visibility for="humans">
<Note>
अगर हर स्किल को शुरू से लिखने के बजाय दोबारा इस्तेमाल किया जा सकने वाला शुरुआती सेटअप चाहिए, तो [`phaseoteam/skills`](https://github.com/phaseoteam/skills) से Phaseo की सार्वजनिक स्किल इंस्टॉल करें:

```bash
npx skills add phaseoteam/skills --agent codex --skill '*'
```

इसके बाद, प्रोजेक्ट-विशिष्ट निर्देश अपनी स्थानीय `SKILL.md` फ़ाइल में रखें।
</Note>
</Visibility>

<Visibility for="agents">
<Note>
दोबारा इस्तेमाल की जा सकने वाली Phaseo स्किल [`phaseoteam/skills`](https://github.com/phaseoteam/skills) में हैं। पहले इन्हें इस कमांड से इंस्टॉल करें:

```bash
npx skills add phaseoteam/skills --agent codex --skill '*'
```

फिर, प्रोजेक्ट-विशिष्ट निर्देश रिपॉज़िटरी की `SKILL.md` फ़ाइल में जोड़ें।
</Note>
</Visibility>

मुख्य विचार सरल है:

- SDK सेटअप रिपॉज़िटरी में रखें
- ऐसी `SKILL.md` फ़ाइल जोड़ें जो एजेंट को बताए कि प्रोजेक्ट अनुरोध कैसे भेजने की अपेक्षा करता है
- सेटअप के दौरान एजेंट को उस फ़ाइल की ओर निर्देशित करें, ताकि अनुरोधों का तरीका एक जैसा रहे

## 1. SDK इंस्टॉल करें

अगर आप TypeScript या JavaScript उपयोग कर रहे हैं:

<CodeGroup>

```bash npm
npm install @phaseo/sdk
```

```bash pnpm
pnpm add @phaseo/sdk
```

```bash yarn
yarn add @phaseo/sdk
```

```bash bun
bun add @phaseo/sdk
```

</CodeGroup>

अगर आप Python उपयोग कर रहे हैं:

```bash
pip install phaseo
```

## 2. प्रोजेक्ट की स्थानीय स्किल फ़ाइल जोड़ें

रिपॉज़िटरी के रूट में, या आपकी टीम जिस एजेंट स्किल स्थान का उपयोग करती है वहाँ, `SKILL.md` बनाएँ।

```md
# Phaseo Gateway

- Use `https://api.phaseo.app/v1` as the gateway base URL.
- Read the API key from `PHASEO_API_KEY`.
- Prefer the Responses API for new text integrations.
- Use preset slugs when the repository defines shared request defaults.
- Log request ids and model ids for debugging.
- For async video jobs, store the returned id and poll status until terminal.
```

## 3. पहली इंटीग्रेशन छोटी रखें

कोडिंग एजेंट के लिए बड़े रैपर की तुलना में छोटे अनुरोध हेल्पर को दोबारा इस्तेमाल करना आसान होता है।

```ts
import Phaseo from "@phaseo/sdk";

export const gateway = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY!,
});
```

इसके बाद, हर उपयोग-क्षेत्र के लिए कॉल का एक स्पष्ट रास्ता रखें:

- टेक्स्ट जनरेशन
- एसिंक्रोनस वीडियो
- एम्बेडिंग
- इमेज जनरेशन

## 4. स्किल में क्या दर्ज होना चाहिए

आपकी `SKILL.md` को उन सवालों के जवाब देने चाहिए जिनमें एजेंट का सबसे अधिक समय जाता है:

- किस एंडपॉइंट परिवार को प्राथमिकता देनी है
- क्रेडेंशियल किस एनवायरनमेंट वैरिएबल में हैं
- कौन-से मॉडल ID या प्रीसेट स्लग स्वीकृत हैं
- अनुरोध ID को कैसे लॉग करना है
- एसिंक्रोनस जॉब को कैसे ट्रैक करना है

## 5. रिपॉज़िटरी के लिए सुझाया गया पैटर्न

- SDK हेल्पर के लिए एक साझा मॉड्यूल
- इंटीग्रेशन कोड के पास या रिपॉज़िटरी रूट में `SKILL.md`
- हर मुख्य एंडपॉइंट के लिए एक छोटा उदाहरण
- अनुरोध लॉगिंग और त्रुटि प्रबंधन पर एक नोट

इससे लोगों और कोडिंग एजेंटों, दोनों को एक ही संचालन प्रवेश-बिंदु मिलता है।
