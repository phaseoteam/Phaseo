---

किसी एक अनुरोध में `provider` ऑब्जेक्ट जोड़कर बदलें कि कौन से प्रदाता उसे संभालें, वर्कस्पेस डिफ़ॉल्ट या प्रीसेट को छुए बिना। अंत में आप एक पसंदीदा क्रम तय कर सकेंगे, अनुरोध को अनुमति-सूची के अंदर रख सकेंगे, या किसी एक प्रदाता को छोड़ सकेंगे, और प्रतिक्रिया में देख सकेंगे कि किस प्रदाता ने जवाब दिया।

ये अनुरोध ढाँचे प्रोडक्शन के लिए तैयार हैं। प्रदाता स्लग असली उदाहरण हैं; अपने मॉडल को सर्व करने वाले प्रदाताओं के लिए मॉडल का पेज देखें।

| फ़ील्ड | क्या करता है | उदाहरण |
| --- | --- | --- |
| `order` | पहले इन प्रदाताओं को आज़माता है, फिर पात्र पूल के बाकी प्रदाताओं को | `["anthropic-us", "anthropic"]` |
| `only` | अनुरोध को इसी सूची के अंदर रखता है | `["openai", "openai-eu"]` |
| `ignore` | इस अनुरोध के लिए इन प्रदाताओं को हटाता है | `["novita"]` |
| `sort` | बचे हुए प्रदाताओं को `price`, `latency` या `throughput` के हिसाब से रैंक करता है | `"price"` |

ठीक एक प्रदाता इस्तेमाल करने और प्रदाताओं के बीच फ़ॉलबैक बंद करने के लिए, उसे मॉडल ID के आगे लगाएँ: [एक प्रदाता पिन करें](../guides/routing-and-fallbacks#pin-one-provider) देखें।

## प्रदाताओं को तय क्रम में आज़माएँ

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "input": "Write a concise launch summary.",
    "provider": {
      "order": ["anthropic-us", "anthropic"]
    },
    "meta": true
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "anthropic/claude-sonnet-5.5",
  input: "Write a concise launch summary.",
  provider: {
    order: ["anthropic-us", "anthropic"],
  },
  meta: true,
});

console.log(response.meta?.routing); // { selected_provider: "anthropic-us", ... }
```

```python Python
import os

from phaseo import Phaseo

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])

response = client.generate_response(
    {
        "model": "anthropic/claude-sonnet-5.5",
        "input": "Write a concise launch summary.",
        "provider": {
            "order": ["anthropic-us", "anthropic"],
        },
        "meta": True,
    }
)

print(response["meta"]["routing"]["selected_provider"])
```
</CodeGroup>

`meta: true` प्रतिक्रिया में `meta.routing.selected_provider` जोड़ता है, ताकि आप लॉग खोले बिना नतीजा जाँच सकें।

## अनुरोध को अनुमति-सूची के अंदर रखें

`only` भेजें, और चाहें तो उस सूची के अंदर रैंक करने के लिए `sort` भी:

```json
{
  "model": "openai/gpt-5.6-luna",
  "input": "Extract the action items.",
  "provider": {
    "only": ["openai", "openai-eu"],
    "sort": "price"
  }
}
```

अगर सूची का कोई भी प्रदाता मॉडल सर्व नहीं करता, तो अनुरोध सूची से बाहर जाने के बजाय विफल हो जाता है।

## एक प्रदाता छोड़ें

जब कोई प्रदाता ठीक से काम न कर रहा हो, या जब आप कोई दूसरा रास्ता टेस्ट कर रहे हों, तब `ignore` भेजें:

```json
{
  "model": "meta/llama-4-maverick",
  "input": "Summarize the transcript.",
  "provider": {
    "ignore": ["novita"]
  }
}
```

## इन्हें मिलाएँ

पूल के लिए `only`, उसके अंदर पसंद के लिए `order`, और बाकी के लिए `sort` इस्तेमाल करें। यह अनुरोध को Google Vertex पर रखता है, पहले EU क्षेत्र आज़माता है, फिर लेटेंसी के हिसाब से रैंक करता है:

```json
{
  "model": "anthropic/claude-sonnet-5.5",
  "input": "Summarize the incident in one sentence.",
  "provider": {
    "only": ["google-vertex", "google-vertex-eu"],
    "order": ["google-vertex-eu"],
    "sort": "latency"
  }
}
```

## जाँचें कि अनुरोध कहाँ गया

**सेटिंग्स → उपयोग → लॉग्स** में अनुरोध खोलें और **Routing observability** फैलाएँ। इसमें वे प्रदाता दिखते हैं जिन्हें रैंकिंग से पहले बाहर किया गया और उसकी वजह, और स्कोर के साथ रैंक किए गए उम्मीदवार; [रूटिंग फ़ैसला समझें](../guides/routing-and-fallbacks#explain-a-routing-decision) हर फ़ील्ड बताता है।

अनुरोध-स्तर के नियम उन ओवरराइड के लिए इस्तेमाल करें जो अस्थायी हों, किसी एक कॉलर के लिए हों, या किसी एक उपयोगकर्ता फ़्लो से जुड़े हों। जब वही नियम कई सेवाओं में दिखने लगें, तो उन्हें एक [प्रीसेट](../guides/presets) में ले जाएँ, जहाँ वे यह भी सीमित करते हैं कि फ़ॉलबैक किन प्रदाताओं का उपयोग कर सकता है। रैंकिंग की तुलना के लिए, [प्रदाताओं को क्रमित करें](./sort-providers-by-price-latency-or-throughput) देखें।
