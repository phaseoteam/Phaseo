जब किसी वर्कफ़्लो में मॉडल द्वारा जानकारी निकालने, सारांश बनाने या वर्गीकृत करने से पहले एक पेज प्राप्त करके उसे सीमित टेक्स्ट में बदलना हो, तब यह रेसिपी अपनाएँ।

## 1. एक पेज को आधार बनाने के लिए `phaseo:web_fetch` उपयोग करें

`phaseo:web_fetch` Gateway द्वारा प्रबंधित सर्वर टूल है।

इसका उपयोग तब करें जब आपको चाहिए:

- Gateway द्वारा सीधे प्राप्त किया गया एक URL
- टूल लूप को लौटाया गया सीमित टेक्स्ट
- अनुरोध स्तर पर उपयोग ट्रैकिंग
- अनुरोध लॉग में प्राप्त पेज की जानकारी

URL पहले से मालूम हो, तो व्यापक खोज की तुलना में यह बेहतर विकल्प है।

## 2. अनुरोध स्पष्ट रखें

सामान्य तरीका:

1. मॉडल से `phaseo:web_fetch` कॉल करने को कहें
2. Gateway को पेज प्राप्त और सामान्यीकृत करने दें
3. लौटाए गए टेक्स्ट के आधार पर मॉडल को जानकारी निकालने दें

पेज प्राप्त होने के बाद किए जाने वाले काम को प्रॉम्प्ट में स्पष्ट करें:

- फ़ील्ड निकालें
- एक सेक्शन का सारांश बनाएँ
- दस्तावेज़ को वर्गीकृत करें
- किसी दावे की पुष्टि करें

## 3. प्राप्त टेक्स्ट का आकार सोच-समझकर सीमित करें

काम के लिए डिफ़ॉल्ट सीमा बहुत बड़ी या छोटी हो, तो `max_chars` सेट करें।

सुझाया गया तरीका:

- शीर्षक या सारांश निकालने के लिए छोटी सीमा
- संरचित फ़ील्ड निकालने के लिए बड़ी सीमा

पेज बहुत बड़ा हो, तो प्राप्ति सीमा हटाने के बजाय जानकारी निकालने का दायरा छोटा करें।

## 4. केवल अंतिम उत्तर नहीं, लॉग भी जाँचें

अनुरोध के विवरण में यह दिखना चाहिए:

- प्राप्त URL
- रीडायरेक्ट के बाद का अंतिम URL
- उपलब्ध होने पर पेज का शीर्षक
- HTTP स्थिति
- कंटेंट का प्रकार
- लौटाए गए वर्णों की संख्या
- ट्रंकेशन संकेतक

यह दृश्य देखकर पुष्टि करें कि मॉडल ने अपेक्षित पेज को आधार बनाया।

## 5. टूल की सीमाएँ जानें

`phaseo:web_fetch` जानबूझकर सीमित रखा गया है।

यह इनके लिए उपयोगी है:

- HTML पेज
- सादा टेक्स्ट
- सरल JSON या XML प्रतिक्रियाएँ

यह इनके लिए सही टूल नहीं है:

- बाइनरी फ़ाइलें
- बड़े पैमाने पर क्रॉल करना
- केवल JavaScript से रेंडर होने वाले पेज की जाँच

ब्राउज़र में रेंडर हुए पेज को जाँचने के लिए केवल प्राप्त टेक्स्ट पर निर्भर रहने के बजाय ब्राउज़र वर्कफ़्लो इस्तेमाल करें।

## 6. सुझाया गया परिनियोजन तरीका

1. एक प्रीसेट या एक एंडपॉइंट पाथ से शुरू करें
2. प्राप्ति मेटाडेटा और ट्रंकेशन के लिए अनुरोध लॉग देखें
3. प्राप्त सामग्री बहुत व्यापक हो तो प्रॉम्प्ट का दायरा घटाएँ
4. आधारित निष्कर्षण प्रक्रिया स्थिर होने के बाद ही दायरा बढ़ाएँ
