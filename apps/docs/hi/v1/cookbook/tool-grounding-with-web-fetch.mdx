मॉडल को `phaseo:web_fetch` और एक ऐसा URL दें जिसे आप पहले से जानते हैं, और Phaseo पेज फ़ेच करता है, उसे एक आकार सीमा तक छोटा करता है और मॉडल के एक्सट्रैक्ट, सारांश या वर्गीकरण करने से पहले टेक्स्ट वापस देता है। अंत में आपके पास एक ऐसा अनुरोध होगा जो एक पेज पढ़ता है और उससे फ़ील्ड लौटाता है, और आप लॉग में पुष्टि कर सकेंगे कि उसने असल में कौन सा पेज पढ़ा।

दिखाई गई डोमेन सीमा के साथ यह अनुरोध प्रोडक्शन के लिए तैयार है। फ़ेच किए गए पेज अविश्वसनीय इनपुट हैं: मॉडल को उनमें निर्देश दिख सकते हैं, इसलिए वह जो लौटाए उसे वैलिडेट करें। जब आपको URL पता न हो, तो इसके बजाय [वेब सर्च](../guides/server-tools/web-search) का उपयोग करें।

## आधार वाला अनुरोध भेजें

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
    "tools": [
      {
        "type": "phaseo:web_fetch",
        "parameters": {
          "allowed_domains": ["phaseo.app"],
          "max_chars": 8000,
          "max_uses": 1
        }
      }
    ],
    "tool_choice": "phaseo:web_fetch"
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-6-astra",
  input:
    "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
  tools: [
    {
      type: "phaseo:web_fetch",
      parameters: {
        allowed_domains: ["phaseo.app"],
        max_chars: 8000,
        max_uses: 1,
      },
    },
  ],
  tool_choice: "phaseo:web_fetch",
});

console.log(JSON.stringify(response.output, null, 2));
console.log(response.usage?.server_tool_use);
```
</CodeGroup>

प्रॉम्प्ट में फ़ेच के बाद का काम स्पष्ट रखें: ये फ़ील्ड एक्सट्रैक्ट करें, इस सेक्शन का सारांश दें, दस्तावेज़ का वर्गीकरण करें, या किसी एक दावे की जाँच करें।

| पैरामीटर | डिफ़ॉल्ट | उपयोग |
| --- | --- | --- |
| `allowed_domains` | कोई नहीं | सिर्फ़ इन डोमेन से फ़ेच करें। मॉडल सूची को छोटा कर सकता है, कभी बड़ा नहीं। |
| `max_chars` | `12000` | लौटाए गए पेज टेक्स्ट के अक्षर, `100000` तक। शीर्षक या सारांश के लिए कम, फ़ील्ड एक्सट्रैक्शन के लिए ज़्यादा। |
| `max_uses` | `10` | हर अनुरोध में फ़ेच कॉल, `100` तक। |

[वेब फ़ेच गाइड](../guides/server-tools/web-fetch#parameters) बाकी पैरामीटर सूचीबद्ध करती है, जिनमें `blocked_domains` और इंजन शामिल हैं।

## जाँचें कि इसने क्या पढ़ा

टूल का नतीजा, जिसे अनुरोध लॉग दिखाता है, ठीक-ठीक बताता है कि मॉडल ने किस पेज को आधार बनाया:

```json
{
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "truncated": false,
  "returned_chars": 8000
}
```

यह भरोसा करने से पहले कि मॉडल ने पूरा पेज देखा, रीडायरेक्ट के बाद का `final_url` और `truncated` जाँचें। हर फ़ेच `usage.server_tool_use.web_fetch_requests` में 1 जोड़ता है।

## सीमाएँ जानें

डिफ़ॉल्ट `direct` इंजन के साथ, Phaseo पेज खुद फ़ेच करता है और HTML को सादे टेक्स्ट में बदल देता है। यह `localhost` और निजी पतों को मना करता है, ज़्यादा से ज़्यादा 5 रीडायरेक्ट फ़ॉलो करता है, और हर रीडायरेक्ट को आपकी डोमेन सूचियों से जाँचता है; उनसे बाहर का रीडायरेक्ट मॉडल को `redirect_blocked_by_domain_policy` लौटाता है।

वेब फ़ेच HTML पेज, सादे टेक्स्ट, और छोटी JSON या XML प्रतिक्रियाओं के लिए ठीक है। यह बाइनरी फ़ाइलों, कई पेज क्रॉल करने, या यह जाँचने के लिए नहीं है कि कोई पेज JavaScript के साथ कैसे रेंडर होता है; इसके लिए ब्राउज़र वर्कफ़्लो का उपयोग करें। अगर पेज बहुत बड़ा है, तो `max_chars` बढ़ाने के बजाय एक्सट्रैक्शन का काम छोटा करें।

एक प्रीसेट या एंडपॉइंट से शुरू करें, लॉग में फ़ेच विवरण और ट्रंकेशन पढ़ें, और उपयोग बढ़ाने से पहले, अगर फ़ेच किया गया टेक्स्ट बहुत व्यापक है तो प्रॉम्प्ट को सख्त करें।
