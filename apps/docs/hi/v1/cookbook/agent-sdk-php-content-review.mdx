एक PHP एजेंट चलाएँ जो स्थानीय टूल से CMS ड्राफ़्ट लोड करे और संपादकीय बदलाव सुझाए, उसी ऐप या एडमिन बैकएंड के अंदर जो पहले से सामग्री का मालिक है। अंत में आपके पास एक स्क्रिप्ट होगी जो होमपेज ड्राफ़्ट के लिए हेडलाइन का सुझाव प्रिंट करती है।

टूल तय नमूना डेटा लौटाता है, इसलिए यह स्क्रिप्ट उदाहरण के लिए है; इसे अपने CMS lookup से बदलें। यह ऐसे PHP ऐप के लिए सही है जहाँ एक या दो स्थानीय टूल काफ़ी हैं।

## इसे बनाएँ

<Steps>
<Step title="इंस्टॉल करें">

```bash
composer require phaseo/agent-sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

`phaseo/agent-sdk` अपने साथ `phaseo/sdk` इंस्टॉल करता है और इसके लिए PHP 8.1 या नया चाहिए। [PHP Agent SDK इंस्टॉलेशन](../sdk-reference/agent/installation) देखें।

</Step>
<Step title="एजेंट लिखें">

```php review.php
<?php
require 'vendor/autoload.php';

use Phaseo\AgentSdk\AgentDefinition;
use Phaseo\AgentSdk\AgentSdk;
use Phaseo\AgentSdk\Tool;

const ALLOWED_SLUGS = ['homepage', 'pricing', 'about'];

$loadDraft = AgentSdk::defineTool(new Tool(
    id: 'load-draft',
    description: 'Load one CMS draft by slug.',
    parameters: [
        'type' => 'object',
        'properties' => [
            'slug' => ['type' => 'string', 'enum' => ALLOWED_SLUGS],
        ],
        'required' => ['slug'],
        'additionalProperties' => false,
    ],
    // आर्ग्युमेंट मॉडल से आते हैं: सिर्फ़ ज्ञात slug ही execute तक पहुँचते हैं।
    inputSchema: static function (mixed $input): array {
        if (!is_array($input) || !in_array($input['slug'] ?? null, ALLOWED_SLUGS, true)) {
            throw new InvalidArgumentException('slug must be one of ' . implode(', ', ALLOWED_SLUGS));
        }
        return $input;
    },
    execute: static fn (array $input, $context) => [
        'slug' => $input['slug'],
        'headline' => 'Phaseo makes gateway routing visible.',
    ],
));

$agent = AgentSdk::createAgent(new AgentDefinition(
    id: 'content-review-agent',
    model: 'openai/gpt-6-astra',
    instructions: 'Use tools when helpful and return concise editorial feedback.',
    tools: [$loadDraft],
    maxSteps: 4,
));

// PHASEO_API_KEY को एनवायरनमेंट से पढ़ता है।
$result = $agent->run(
    input: 'Review the homepage draft and suggest one headline improvement.',
    client: AgentSdk::createGatewayAgentClient(),
);

echo $result->run->status . PHP_EOL;
echo $result->output . PHP_EOL;
```

</Step>
<Step title="इसे चलाएँ">

```bash
php review.php
```

</Step>
</Steps>

## जाँचें कि यह काम किया

- स्क्रिप्ट `completed` प्रिंट करती है, फिर हेडलाइन का एक सुझाव।
- **सेटिंग → उपयोग → लॉग्स** में पहले मॉडल टर्न में `{"slug": "homepage"}` के साथ `load-draft` कॉल दिखती है।
- `PHASEO_API_KEY` के बिना `createGatewayAgentClient()` यह त्रुटि देता है: `PHASEO_API_KEY is required`।

## प्रोडक्शन से पहले

टूल को सिर्फ़ पढ़ने वाला रखें। अगर आप ऐसा टूल जोड़ते हैं जो सामग्री प्रकाशित या संपादित करे, तो उस पर `requireApproval: true` सेट करें ताकि रन किसी संपादक के लिए रुक जाए। फ़ीडबैक को ऐसे JSON के रूप में पाने के लिए जिसे आपका CMS संग्रहीत कर सके, एक स्कीमा माँगें और लगभग-सही आउटपुट को [response healing](./response-healing-for-structured-json) से ठीक करें। [PHP Agent SDK संदर्भ](../sdk-reference/agent/usage) में स्थिति, अनुमोदन और स्ट्रीमिंग की जानकारी है।
