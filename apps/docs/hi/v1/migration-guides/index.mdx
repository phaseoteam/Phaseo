आप जो बदल रहे हैं, उसके लिए गाइड चुनें: वह प्लेटफ़ॉर्म जिसे आपका ऐप कॉल करता है (नीचे), या वह मॉडल जिसे वह उपयोग करता है ([मॉडल माइग्रेशन](../model-migrations))। अगर आप दोनों बदल रहे हैं, तो पहले प्लेटफ़ॉर्म बदलें और नया पथ सत्यापित होने तक मॉडल वही रखें।

अपने हिसाब से बनी चेकलिस्ट के लिए [Migration Assistant](https://phaseo.app/migrate) उपयोग करें।

<span id="platform-migrations"></span>
## प्लेटफ़ॉर्म माइग्रेशन

हर प्लेटफ़ॉर्म गाइड एक ही क्रम में चलती है: बेस URL और कुंजी बदलें, मॉडल ID मैप करें, प्लेटफ़ॉर्म की सुविधाएं मैप करें, फिर टेस्ट करें और रोलआउट करें, जबकि रोलबैक सिर्फ़ बेस URL और कुंजी बदलने तक सीमित रहे।

| आप कॉल करते हैं | कोड में संकेत | गाइड |
| --- | --- | --- |
| सीधे OpenAI | `api.openai.com`, `OPENAI_API_KEY`, `AzureOpenAI` | [OpenAI SDK](./from-openai) |
| सीधे Anthropic | `api.anthropic.com`, `ANTHROPIC_API_KEY`, `@anthropic-ai/sdk` | [Anthropic SDK](./from-anthropic) |
| OpenRouter | `openrouter.ai`, `OPENROUTER_API_KEY`, `sk-or-v1` कुंजियां | [OpenRouter](./from-openrouter) |
| Vercel AI Gateway | `ai-gateway.vercel.sh`, `@ai-sdk/gateway`, AI SDK कॉल में सादे स्ट्रिंग मॉडल | [Vercel AI Gateway](./from-vercel) |
| LLM Gateway | `api.llmgateway.io`, `LLM_GATEWAY_API_KEY` | [LLM Gateway](./from-llmgateway) |
| कोई LiteLLM प्रॉक्सी | `model_list` वाली `config.yaml`, `LITELLM_*` वेरिएबल, पोर्ट 4000 | [LiteLLM](./from-litellm) |
| Cloudflare AI Gateway | `gateway.ai.cloudflare.com`, `cf-aig-*` हेडर | [Cloudflare AI Gateway](./from-cloudflare) |
| Helicone | `*.helicone.ai`, `Helicone-Auth` | [Helicone](./from-helicone) |

रोलआउट की योजना बनाने और जांचने के लिए [माइग्रेशन सुविधा चेकलिस्ट](./feature-parity-matrix) उपयोग करें।

## मॉडल माइग्रेशन

जब इंटीग्रेशन वही रहे लेकिन मॉडल बदले, तब [मॉडल माइग्रेशन गाइड](../model-migrations) उपयोग करें। हर गाइड अनुरोध पैरामीटर में बदलाव, प्रॉम्प्ट और रीज़निंग व्यवहार में बदलाव, संरचित आउटपुट और टूल कॉलिंग के अंतर, और फ़ॉलबैक के साथ रोलआउट का तरीका बताती है।

किसी भी तरह के माइग्रेशन में, आउटपुट गुणवत्ता की तुलना से पहले अनुरोध पैरामीटर और एंडपॉइंट व्यवहार जांचें, और लाइव ट्रैफ़िक बदलने से पहले प्रोडक्शन जैसे मूल्यांकन चलाएं।
