## मॉडल माइग्रेशन

अनुकूलित शुरुआती चेकलिस्ट के लिए [माइग्रेशन सहायक](https://phaseo.app/migrate) इस्तेमाल करें।

जब integration लगभग वैसा ही रहे, लेकिन इस्तेमाल होने वाला model बदले, तब इन गाइड का उपयोग करें।

इनमें शामिल हैं:

- request parameters में बदलाव
- prompts और reasoning के व्यवहार में अंतर
- structured output और tool-calling में अंतर
- rollout, fallback और rollback की रणनीति

## इन गाइड का उपयोग कैसे करें

1. तय करें कि platform, model या दोनों बदल रहे हैं।
2. माइग्रेशन के सबसे जोखिम वाले हिस्से वाली गाइड से शुरू करें।
3. output quality की तुलना से पहले request parameters और endpoint behavior जाँचें।
4. live traffic बदलने से पहले production-जैसे evaluations चलाएँ।
