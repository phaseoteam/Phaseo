Anthropic SDK और Messages कॉल वैसे ही रखें। क्लाइंट को `https://api.phaseo.app` पर पॉइंट करें, अपनी Phaseo कुंजी `authToken` के रूप में दें, और हर मॉडल को उसकी Phaseo ID दें।

| सेटिंग | Anthropic | Phaseo |
| --- | --- | --- |
| बेस URL | SDK डिफ़ॉल्ट (`https://api.anthropic.com`) | `https://api.phaseo.app` (SDK `/v1/messages` जोड़ता है) |
| API कुंजी | `ANTHROPIC_API_KEY`, `x-api-key` के रूप में भेजी जाती है | `PHASEO_API_KEY`, `authToken` / `auth_token` के रूप में, `Authorization: Bearer` से भेजी जाती है |
| मॉडल | `claude-sonnet-5-5` | `anthropic/claude-sonnet-5.5`, या `GET /v1/models` की कोई भी ID |
| Messages कॉल | `messages.create` | अपरिवर्तित |

## क्लाइंट बदलें

[Phaseo CLI](../guides/integrations/phaseo-cli) में `phaseo keys create` से या [API कुंजियाँ](https://phaseo.app/settings/keys) में कुंजी बनाएं, और उसे ऐप को `PHASEO_API_KEY` के रूप में उपलब्ध कराएं।

<CodeGroup>
```typescript TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  apiKey: null,
  authToken: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app",
});

const response = await client.messages.create({
  model: "anthropic/claude-sonnet-5.5",
  max_tokens: 256,
  messages: [{ role: "user", content: "Reply with: migration ready" }],
});
```

```python Python
import os
import anthropic

client = anthropic.Anthropic(
    auth_token=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app",
)

response = client.messages.create(
    model="anthropic/claude-sonnet-5.5",
    max_tokens=256,
    messages=[{"role": "user", "content": "Reply with: migration ready"}],
)
```

```bash cURL
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 256,
    "messages": [{"role": "user", "content": "Reply with: migration ready"}]
  }'
```
</CodeGroup>

यह कदम सबसे ज़्यादा इन तीन बातों से टूटता है:

- **रूट होस्ट उपयोग करें।** `baseURL: "https://api.phaseo.app/v1"` से `/v1/v1/messages` बनता है। उसी रिपॉज़िटरी के OpenAI-संगत क्लाइंट फिर भी `/v1` उपयोग करते हैं।
- **कुंजी bearer टोकन के रूप में भेजें।** गेटवे सिर्फ़ `Authorization: Bearer` पढ़ता है; `x-api-key` हेडर पर `401` `missing_or_invalid_authorization_header` मिलता है। `authToken` हर SDK संस्करण पर Bearer भेजता है। `apiKey` ऐसा सिर्फ़ `@anthropic-ai/sdk` 1.0 और `anthropic` 2.0 से आगे करता है।
- **`ANTHROPIC_API_KEY` हटाएं** उन एनवायरनमेंट से जो अब Phaseo को कॉल करते हैं। `apiKey: null` पुराने TypeScript SDK को इसे पढ़ने से रोकता है, और 0.98 से पहले के Python SDK `auth_token` सेट होने पर भी इसे पढ़ते हैं।

एनवायरनमेंट वेरिएबल से कॉन्फ़िगर होने वाले टूल, जैसे Claude Code, `ANTHROPIC_BASE_URL=https://api.phaseo.app`, Phaseo कुंजी पर सेट `ANTHROPIC_AUTH_TOKEN`, और खाली `ANTHROPIC_API_KEY` उपयोग करते हैं।

## मॉडल ID मैप करें

हर प्रोडक्शन मॉडल को `GET /v1/models?format=openai` के `data[].id` से जांचें। Phaseo ID संस्करण में बिंदु उपयोग करती हैं: `claude-sonnet-5-5` बन जाता है `anthropic/claude-sonnet-5.5`। अगर मॉडल भी बदल रहा है, तो उसकी [मॉडल माइग्रेशन गाइड](../model-migrations) पढ़ें।

## क्या अलग तरह से काम करता है

| Anthropic सुविधा | Phaseo पर |
| --- | --- |
| `anthropic-version` हेडर | कोई भी मान स्वीकार है; Phaseo Claude को अपने संस्करण से कॉल करता है। |
| `anthropic-beta` हेडर | आगे नहीं भेजे जाते। Phaseo अपनी समर्थित सुविधाओं के लिए ज़रूरी बीटा खुद जोड़ता है; `mcp_servers` जैसे सिर्फ़-बीटा बॉडी फ़ील्ड `400` लौटाते हैं। |
| `temperature`, `top_p`, `top_k` | जहां मॉडल या रूट इन्हें नहीं लेता, वहां हटा दिए जाते हैं और `X-Phaseo-Dropped-Params` में सूचीबद्ध होते हैं। |
| `speed: "fast"` | `400` लौटाता है। `service_tier: "fast"` उपयोग करें। |
| मूल वेब खोज और वेब फ़ेच टूल | जहां प्रदाता इन्हें चलाता है वहां स्वीकार होते हैं, या Phaseo का `phaseo:web_search` सर्वर टूल उपयोग करें। |
| `cache_control` | शीर्ष स्तर पर या प्रति ब्लॉक समर्थित। देखें [प्रॉम्प्ट कैशिंग](../guides/prompt-caching)। |
| `metadata.user_id` | अंतिम-उपयोगकर्ता ID के रूप में उपयोग नहीं होता। अंतिम-उपयोगकर्ता दर सीमा नीतियों के लिए `user` या `X-Phaseo-User-Id` हेडर भेजें। |
| Message Batches (`/v1/messages/batches`) | ऐसा कोई पथ नहीं है। `/v1/batches` अलग आकार में `/v1/messages` पंक्तियां स्वीकार करता है। |
| टोकन गिनती (`/v1/messages/count_tokens`) | कोई समकक्ष नहीं। इसे Anthropic पर रखें या क्लाइंट की तरफ़ अनुमान लगाएं। |
| Files API (`client.beta.files`) | कोई समकक्ष नहीं। दस्तावेज़ इनलाइन भेजें। |
| `AnthropicBedrock`, `AnthropicVertex` क्लाइंट | सादे `Anthropic` क्लाइंट से बदलें; क्लाउड प्रमाणीकरण और क्षेत्र सेटिंग लागू नहीं होतीं। |

## टेस्ट करें और रोलआउट करें

ऐप जिन सटीक मॉडल ID को उपयोग करता है, उनके साथ सिस्टम प्रॉम्प्ट, स्ट्रीमिंग, टूल उपयोग, थिंकिंग और संरचित आउटपुट टेस्ट करें। फिर दोनों कॉन्फ़िगरेशन पर प्रतिनिधि प्रॉम्प्ट सेट की तुलना आउटपुट आकार, लेटेंसी, टोकन उपयोग, त्रुटियों और लागत के लिए करें। ट्रैफ़िक बदलने से पहले:

- Phaseo कुंजी हर डिप्लॉयमेंट एनवायरनमेंट में सेट है;
- हर प्रोडक्शन मॉडल ID `GET /v1/models?format=openai` में है;
- स्टेजिंग में स्ट्रीमिंग और टूल-उपयोग फ़्लो पास होते हैं;
- हर `anthropic-beta` हेडर और सिर्फ़-बीटा फ़ील्ड हटा दिया गया है या बदल दिया गया है;
- रोलबैक अब भी सिर्फ़ बेस URL और कुंजी का बदलाव है।
