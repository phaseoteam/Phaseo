- API कुंजी की खर्च सीमा वाली `429` त्रुटियाँ `$0.0117 of $0.01` जैसी डॉलर राशि दिखाती हैं, और मासिक सीमाओं में `Retry-After` हेडर बना रहता है ([#3296](https://github.com/phaseoteam/Phaseo/pull/3296))।

- **सेटिंग्स -> रेट लिमिट** किसी नीति को API कुंजी, सदस्य, विभाग, गार्डरेल या एंड-यूज़र डिफ़ॉल्ट को सौंपता है और पिछले 24 घंटों में रोके गए अनुरोध दिखाता है ([#3150](https://github.com/phaseoteam/Phaseo/pull/3150))।

- कुंजी सुरक्षा अब **सेटिंग्स -> API कुंजियाँ -> कुंजी सुरक्षा** में है, और कुंजियों की तालिका में **Status** कॉलम और क्रमबद्ध होने वाले कॉलम जुड़े हैं ([#3184](https://github.com/phaseoteam/Phaseo/pull/3184))।
- Broadcast अब Amazon S3 और S3-संगत स्टोरेज, Cloudflare R2, Google Cloud Storage, ClickHouse, BigQuery और Snowflake पर ट्रेस भेज सकता है; देखें [Broadcast](./guides/broadcast.mdx) ([#3181](https://github.com/phaseoteam/Phaseo/pull/3181), [#3182](https://github.com/phaseoteam/Phaseo/pull/3182), [#3185](https://github.com/phaseoteam/Phaseo/pull/3185))।
- नई गाइड: [Broadcast](./guides/broadcast.mdx) हर गंतव्य प्रकार की सेटिंग्स बताती है ([#3190](https://github.com/phaseoteam/Phaseo/pull/3190))।
- तुलना पेज में 30 दिनों का **Activity** चार्ट जुड़ा है, जो Phaseo के ज़रिए हर मॉडल के टोकन और अनुरोध दिखाता है ([#3147](https://github.com/phaseoteam/Phaseo/pull/3147))।
- तुलना पेज दिखाता है कि क्षमता सूचकांकों में हर मॉडल किस रैंक पर है ([#3148](https://github.com/phaseoteam/Phaseo/pull/3148))।
- दो मॉडलों की तुलना के अपने पेज हैं, जिनमें सारांश और FAQ है, जैसे `/compare/anthropic_claude-opus-5.5-vs-openai_gpt-6-astra` ([#3162](https://github.com/phaseoteam/Phaseo/pull/3162))।
