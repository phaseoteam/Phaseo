Phaseo Desktop बातचीत, कोडिंग एजेंट और प्रोजेक्ट टूल को एक ऐप में लाता है। निजी चैट से शुरू करें, फिर जब किसी एजेंट से फ़ाइलों पर काम करवाना हो तो प्रोजेक्ट जोड़ें।

<Note>
ये गाइड डेस्कटॉप प्रीव्यू के बारे में हैं। उपलब्ध सुविधाएँ आपके बिल्ड और कनेक्ट किए गए एजेंट पर निर्भर करती हैं।
</Note>

## ऐप खोलें

अगर आपके पास पहले से प्रीव्यू बिल्ड है, तो Phaseo खोलें। सोर्स से चलाने के लिए Git, Node.js 24 और pnpm 10.33 इंस्टॉल करें, फिर चलाएँ:

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
pnpm install
pnpm --filter @phaseo/desktop dev
```

डेवलपमेंट कमांड ज़रूरी पैकेज बिल्ड करती है और डेस्कटॉप विंडो खोलती है। इस्तेमाल करते समय टर्मिनल चालू रखें।

## खाता कनेक्ट करें

**Settings → Accounts** खोलें। Phaseo में साइन इन करें, API खाता जोड़ें, या इस कंप्यूटर पर पहले से साइन इन किए हुए कोडिंग एजेंट का इस्तेमाल करें। **Settings → Agents** आपकी मशीन पर उपलब्ध एजेंट दिखाता है।

आपका खाता तय करता है कि आप कौन से मॉडल इस्तेमाल कर सकते हैं और उपयोग का बिल कैसे बनेगा। कनेक्ट की गई सदस्यता पर उसके प्रदाता की उपयोग सीमाएँ लागू रहती हैं; Phaseo के ज़रिए भेजे गए अनुरोध आपका Phaseo खाता इस्तेमाल करते हैं।

## चैट शुरू करें

1. **Chat** और **New chat** चुनें।
2. संदेश बॉक्स के पास मॉडल पिकर खोलें। एजेंट और मॉडल चुनें, फिर जहाँ समर्थित हो वहाँ रीजनिंग या गति बदलें।
3. संदेश लिखकर भेजें। प्रोजेक्ट की ज़रूरत नहीं है।

अगर मॉडल नहीं दिखते, तो **Accounts** में अपना साइन-इन और **Agents** में एजेंट की उपलब्धता जाँचें।

## अपनी पसंद के अनुसार बदलें

**Settings → Appearance** से थीम, फ़ॉन्ट और पैनल ऐनिमेशन की अवधि नियंत्रित होती है: 0–600 ms, डिफ़ॉल्ट 200 ms। प्रीव्यू देखने के लिए छोटे वर्कस्पेस पर क्लिक करें। अवधि शून्य होने, **Animations** बंद होने या सिस्टम की कम गति वाली प्राथमिकता चालू होने पर पैनल तुरंत दिखते हैं।

चैट और कमांड खोजने के लिए `Ctrl+K` (macOS पर `Cmd+K`) इस्तेमाल करें। **Settings → Keyboard shortcuts** आपके मौजूदा शॉर्टकट दिखाता है।
