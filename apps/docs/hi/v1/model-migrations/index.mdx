# मॉडल माइग्रेशन

एक ही platform पर रहते हुए model upgrade करने के लिए इन गाइड का उपयोग करें।

ये उन बदलावों पर ध्यान देती हैं जो मौजूदा integrations को अक्सर सबसे पहले प्रभावित करते हैं:

- request parameters में बदलाव
- prompts और reasoning के व्यवहार में बदलाव
- structured output और tool-calling में regressions
- rollout, fallback और rollback की रणनीति

## इस section का उपयोग कैसे करें

1. जिस model family पर जा रहे हैं, उसकी सटीक गाइड से शुरुआत करें।
2. output quality जाँचने से पहले request parameters अपडेट करें।
3. production-जैसे prompts के साथ prompt और schema evaluations दोबारा चलाएँ।
4. fallback और rollback के स्पष्ट नियम बनाकर traffic धीरे-धीरे बदलें।

अगर आप सिर्फ़ model नहीं, बल्कि provider, SDK या gateway बदल रहे हैं, तो [Migration Guides](../migration-guides/index.mdx) section देखें।
