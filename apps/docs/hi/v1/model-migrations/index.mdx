# मॉडल माइग्रेशन

जब आप उसी प्लेटफ़ॉर्म पर रहते हुए केवल मॉडल अपग्रेड कर रहे हों, तब इन गाइड का इस्तेमाल करें।

ये पेज उन बदलावों पर ध्यान देते हैं जिनसे असली इंटीग्रेशन अक्सर सबसे पहले टूटते हैं:

- अनुरोध पैरामीटर में बदलाव
- प्रॉम्प्ट और रीज़निंग के व्यवहार में बदलाव
- संरचित आउटपुट और टूल कॉलिंग में रिग्रेशन
- रोलआउट, फ़ॉलबैक और रोलबैक की रणनीति

## इस सेक्शन का इस्तेमाल कैसे करें

1. आप जिस मॉडल परिवार को अपग्रेड कर रहे हैं, उसकी सटीक गाइड से शुरुआत करें।
2. आउटपुट की गुणवत्ता जाँचने से पहले अनुरोध का स्वरूप अपडेट करें।
3. प्रोडक्शन जैसे प्रॉम्प्ट पर प्रॉम्प्ट और स्कीमा मूल्यांकन दोबारा चलाएँ।
4. स्पष्ट फ़ॉलबैक और रोलबैक नियमों के साथ ट्रैफ़िक धीरे-धीरे बदलें।

अगर आप केवल मॉडल नहीं, बल्कि प्रदाता, SDK या गेटवे बदल रहे हैं, तो इसके बजाय [माइग्रेशन गाइड](../migration-guides/index.mdx) सेक्शन देखें।
