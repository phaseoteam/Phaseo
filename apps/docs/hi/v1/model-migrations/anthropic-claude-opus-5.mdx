# Anthropic Claude Opus 5

प्रोडक्शन में `anthropic/claude-opus-5` को सुरक्षित रूप से अपनाने के लिए इस गाइड का उपयोग करें।

Claude Opus 5 जटिल तर्क, लंबे एजेंट-आधारित कोडिंग कार्यों और उच्च स्वायत्तता वाले वर्कफ़्लो के लिए मौजूदा Opus मॉडल है। इसकी कीमत Opus 4.8 के समान है; इसमें 1M टोकन की संदर्भ विंडो और अधिकतम 128K आउटपुट टोकन हैं।

## माइग्रेशन की त्वरित शुरुआत

1. बाकी अनुरोध बदले बिना मॉडल ID को `anthropic/claude-opus-5` करें।
2. प्रोडक्शन प्रॉम्प्ट, टूल और संरचित आउटपुट के मूल्यांकन फिर से चलाएँ।
3. लंबे संदर्भ और अधिक तर्क-क्षमता वाले कार्यभार के लिए विलंबता, टोकन उपयोग और कार्य लागत की नई आधाररेखा बनाएँ।
4. डिफ़ॉल्ट रूट बदलने से पहले Claude Opus 4.8 को fallback रखते हुए इस मॉडल को धीरे-धीरे canary करें।

```json
{
  "model": "anthropic/claude-opus-5",
  "messages": [
    {
      "role": "user",
      "content": "Review this implementation plan and identify the highest-risk assumptions."
    }
  ]
}
```

## नया क्या है

- Phaseo मॉडल ID `anthropic/claude-opus-5` है।
- संदर्भ विंडो 1M टोकन की है।
- अधिकतम आउटपुट 128K टोकन है।
- यह लंबे तर्क, कोडिंग और स्वायत्त टूल वर्कफ़्लो के लिए बनाया गया है।
- कीमत Claude Opus 4.8 के समान बनी हुई है।

## क्या जाँचें

### प्रॉम्प्ट और आउटपुट

- सबसे लंबे सिस्टम प्रॉम्प्ट में निर्देशों का पालन।
- संरचित आउटपुट और स्कीमा की सफलता दर।
- उत्तर की लंबाई और रुकने का व्यवहार।
- Claude Opus 4.8 के लिए विशेष रूप से समायोजित प्रॉम्प्ट में आई गिरावट।

### टूल और एजेंट

- टूल चयन और आर्ग्युमेंट की गुणवत्ता।
- टूल त्रुटियों या आंशिक परिणामों के बाद सुधार।
- लंबे कार्यों के पूरा होने की दर।
- उच्च स्वायत्तता वाले वर्कफ़्लो में अनुमति और अनुमोदन की सीमाएँ।

### संचालन

- उपलब्ध हर तर्क-प्रयास स्तर पर विलंबता और टोकन उपयोग।
- लंबे दस्तावेज़ों और एजेंट ट्रेस में संदर्भ-विंडो का उपयोग।
- सफलतापूर्वक पूरे हुए कार्य की लागत।
- मुख्य रूट का समय समाप्त होने या विफल होने पर fallback व्यवहार।

## सुरक्षित rollout

1. मूल्यांकन के दौरान Claude Opus 4.8 को वैकल्पिक मॉडल के रूप में उपलब्ध रखें।
2. उपयोगकर्ता अनुरोधों का जवाब नए मॉडल से देने से पहले प्रतिनिधि प्रोडक्शन ट्रैफ़िक की छाया-जाँच करें।
3. सभी Opus रूट एक साथ बदलने के बजाय हर कार्यभार पर सीमित ट्रैफ़िक से आज़माएँ।
4. गुणवत्ता, विलंबता, लागत और टूल-सुरक्षा जाँच लक्ष्य पूरा करें तभी रोलआउट बढ़ाएँ।
