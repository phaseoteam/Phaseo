मॉडल को `anthropic/claude-opus-4.7` में बदलें, सैंपलिंग पैरामीटर और थिंकिंग बजट हटाएं, और गहराई effort लेवल से तय करें। जो अनुरोध अब भी Opus 4.6 के फ़ील्ड भेजते हैं, वे Phaseo पर विफल नहीं होते; गेटवे उन्हें नीचे दिखाए अनुसार दोबारा लिखता है।

| Opus 4.6 अनुरोध | Phaseo Opus 4.7 को क्या भेजता है |
| --- | --- |
| `temperature`, `top_p`, `top_k` | छोड़ दिए जाते हैं। गैर-डिफ़ॉल्ट मानों पर Anthropic `400` लौटाता। |
| `thinking: {"type": "enabled", "budget_tokens": …}` | `thinking: {"type": "adaptive", "display": "summarized"}`; बजट आगे नहीं भेजा जाता। |
| `reasoning.effort` | `output_config.effort`, `xhigh` सहित। |
| `reasoning.effort: "none"` या `reasoning.enabled: false` | `thinking: {"type": "disabled"}`। |
| कोई रीज़निंग सेटिंग नहीं | कोई `thinking` फ़ील्ड नहीं, इसलिए Opus 4.7 थिंक नहीं करता। |

Opus 4.7 थिंकिंग कंटेंट तब तक छिपाता है जब तक आप ऑप्ट-इन न करें; Phaseo जब भी थिंकिंग चालू करता है, सारांशित डिस्प्ले मांगता है। इसका टोकनाइज़र एक ही टेक्स्ट के लिए Opus 4.6 से ज़्यादा टोकन बना सकता है।

## अनुरोध अपडेट करें

1. मॉडल ID को `anthropic/claude-opus-4.7` पर सेट करें।
2. `temperature`, `top_p` और `top_k` हटाएं, और इसके बजाय निर्देशों से ट्यून करें।
3. थिंकिंग बजट की जगह एडैप्टिव थिंकिंग और effort लेवल दें:

```json
{
  "model": "anthropic/claude-opus-4.7",
  "messages": [{ "role": "user", "content": "Refactor this module and explain the risks." }],
  "reasoning": { "effort": "xhigh" }
}
```

`high` से शुरू करें और सबसे कठिन कोडिंग और एजेंटिक रूट के लिए `xhigh` उपयोग करें। `/v1/messages` पर इसके बजाय `output_config.effort` के साथ `thinking: {"type": "adaptive"}` भेजें।

4. टोकनाइज़र बदल गया है, इसलिए `max_tokens` और `max_output_tokens`, टाइमआउट बजट और लागत अलर्ट की जांच करें।

## क्या टेस्ट करें

- आपके प्रोडक्शन प्रॉम्प्ट पर स्कीमा पास दर;
- लंबे चलने वाले टूल वर्कफ़्लो: टूल कॉल की संख्या, पूर्णता दर और लेटेंसी;
- `high` बनाम `xhigh` पर गुणवत्ता;
- आपकी सबसे ज़्यादा मात्रा वाली प्रॉम्प्ट श्रेणियों पर टोकन लागत।

## रोलआउट करें

1. ट्रैफ़िक बदलने से पहले अनुरोध-आकार के बदलाव डिप्लॉय करें।
2. अपने प्रोडक्शन मूल्यांकन सूट पर Opus 4.7 को शैडो करें।
3. Opus 4.6 को `models` में फ़ॉलबैक रखकर कैनरी चलाएं।
4. गुणवत्ता, लेटेंसी और लागत में बदलाव लक्ष्य के भीतर होने पर प्रमोट करें।
