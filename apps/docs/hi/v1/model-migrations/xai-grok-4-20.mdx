# SpaceXAI Grok 4.20

Phaseo Gateway के ज़रिए Grok 4.20 को सुरक्षित रूप से अपनाने के लिए यह गाइड इस्तेमाल करें।

हमारे कैटलॉग का मुख्य रूट:

- `spacex-ai/grok-4-20-2026-02-17`

प्रदाता के मॉडल ID से उपलब्ध वैकल्पिक मल्टी-एजेंट रूट:

- `spacex-ai/grok-4.20-multi-agent-beta-0309`

## माइग्रेशन क्विकस्टार्ट

ज़्यादातर इंटीग्रेशन में मॉडल ID अपडेट करने और अपना सामान्य सत्यापन सेट फिर से चलाने के अलावा कोई माइग्रेशन काम ज़रूरी नहीं है।

मौजूदा अनुरोध और प्रतिक्रिया पैटर्न वैसे ही रह सकते हैं।

## नया क्या है

बेस Grok 4.20 रूट के लिए Phaseo Gateway में ऐसा कोई व्यवहार परिवर्तन नहीं है जिसके लिए आपको माइग्रेट करना पड़े।

एकमात्र व्यावहारिक बदलाव यह है कि मल्टी-एजेंट वैरिएंट को कैसे ट्यून करें।

Phaseo Gateway में:

- बेस Grok 4.20 की रीज़निंग को पहले की तरह `reasoning.enabled` से चालू या बंद किया जा सकता है।
- मल्टी-एजेंट Grok 4.20 को `reasoning.effort` से ट्यून करें।
- `low`, `medium`, `high` और `extra high` इस्तेमाल करें।
- SpaceXAI के दिशानिर्देशों के अनुसार `low` और `medium` में 4 एजेंट होते हैं, जबकि `high` और `extra high` बड़े मल्टी-एजेंट कॉन्फ़िगरेशन इस्तेमाल करते हैं।

हम Gateway अनुरोधों में `agent_count` का सीधे इस्तेमाल नहीं करते।

### तर्क टॉगल के साथ Grok 4.20 का मूल संस्करण

बेस मॉडल इस्तेमाल करें और `reasoning.enabled` सीधे सेट करें:

```json
{
  "model": "spacex-ai/grok-4-20-2026-02-17",
  "input": "Explain this architecture",
  "reasoning": {
    "enabled": true
  }
}
```

### प्रयास नियंत्रण के साथ मल्टी-एजेंट Grok 4.20

मल्टी-एजेंट मॉडल इस्तेमाल करें और `reasoning.effort` से गहराई नियंत्रित करें:

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta-0309",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": {
    "effort": "medium"
  }
}
```

रीज़निंग प्रयास के स्तर:

- `low`
- `medium`
- `high`
- `extra high`
