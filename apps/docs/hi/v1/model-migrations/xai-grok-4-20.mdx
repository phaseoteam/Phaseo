# SpaceXAI Grok 4.20

Phaseo Gateway के ज़रिए Grok 4.20 को सुरक्षित रूप से अपनाने के लिए यह गाइड इस्तेमाल करें।

Catalog का मुख्य route:

- `spacex-ai/grok-4-20-2026-02-17`

Provider model ID से उपलब्ध वैकल्पिक multi-agent route:

- `spacex-ai/grok-4.20-multi-agent-beta-0309`

## माइग्रेशन quickstart

ज़्यादातर integrations में model ID अपडेट करके सामान्य validation फिर चलाना ही काफ़ी है।

मौजूदा request और response patterns वैसे ही रह सकते हैं।

## नया क्या है

बेस Grok 4.20 route के लिए Phaseo Gateway में व्यवहार बदलने की ज़रूरत नहीं है।

व्यावहारिक बदलाव multi-agent variant को tune करने का तरीका है।

Phaseo Gateway में:

- बेस Grok 4.20 के reasoning को सामान्य रूप से `reasoning.enabled` से toggle किया जा सकता है।
- multi-agent Grok 4.20 को `reasoning.effort` से tune करें।
- `low`, `medium`, `high` और `extra high` इस्तेमाल करें।
- SpaceXAI guidance के अनुसार `low` और `medium` में 4 agents होते हैं; `high` और `extra high` बड़े multi-agent configurations इस्तेमाल करते हैं।

Gateway requests में `agent_count` सीधे इस्तेमाल नहीं होता।

### तर्क टॉगल के साथ Grok 4.20 का मूल संस्करण

बेस model इस्तेमाल करें और `reasoning.enabled` सीधे सेट करें:

```json
{
  "model": "spacex-ai/grok-4-20-2026-02-17",
  "input": "Explain this architecture",
  "reasoning": {
    "enabled": true
  }
}
```

### प्रयास नियंत्रण के साथ मल्टी-एजेंट Grok 4.20

Multi-agent model इस्तेमाल करें और `reasoning.effort` से depth नियंत्रित करें:

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta-0309",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": {
    "effort": "medium"
  }
}
```

Reasoning effort levels:

- `low`
- `medium`
- `high`
- `extra high`
