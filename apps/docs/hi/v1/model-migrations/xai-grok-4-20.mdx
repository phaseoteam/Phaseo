मॉडल ID बदलें और अपना सत्यापन सेट दोबारा चलाएं; अनुरोध और प्रतिक्रिया आकार वही रहते हैं। एकमात्र नया नियंत्रण यह है कि मल्टी-एजेंट संस्करण कितनी गहराई से काम करता है।

| मॉडल | Phaseo मॉडल ID | रीज़निंग नियंत्रण |
| --- | --- | --- |
| Grok 4.20 | `spacex-ai/grok-4.20` | `reasoning.enabled`: चालू या बंद |
| Grok 4.20 Multi-Agent (बीटा) | `spacex-ai/grok-4.20-multi-agent-beta` | `reasoning.effort`: `low`, `medium` या `high` |

## Grok 4.20 पर रीज़निंग चालू-बंद करें

मॉडल का रीज़निंग संस्करण उपयोग करने के लिए `reasoning.enabled: true` सेट करें। इसके बिना, या `false` के साथ, Phaseo नॉन-रीज़निंग संस्करण कॉल करता है।

```json
{
  "model": "spacex-ai/grok-4.20",
  "input": "Explain this architecture",
  "reasoning": { "enabled": true }
}
```

## मल्टी-एजेंट मॉडल पर गहराई सेट करें

गहराई `reasoning.effort` से नियंत्रित करें। गेटवे अनुरोध xAI का `agent_count` नहीं लेते; xAI के अनुसार, `low` और `medium` 4 एजेंट चलाते हैं और `high` एक बड़ा कॉन्फ़िगरेशन चलाता है।

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": { "effort": "medium" }
}
```
