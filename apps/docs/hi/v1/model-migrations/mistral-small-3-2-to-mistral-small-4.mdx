# Mistral Small 4

Phaseo Gateway के ज़रिए Mistral Small 4 को सुरक्षित रूप से अपनाने के लिए यह गाइड इस्तेमाल करें:

- `mistral/mistral-small-4-2026-03-16`

## नया क्या है

- Mistral Small 4 में `reasoning_effort` के ज़रिए रीज़निंग मोड नियंत्रित किया जाता है।
- Gateway इस मॉडल रूट के लिए अपस्ट्रीम को केवल दो मान भेजता है:
  - `none` (रीज़निंग बंद)
  - `high` (रीज़निंग चालू)
- Gateway, Mistral के थिंकिंग ब्लॉक को वापस मानक प्रतिक्रिया फ़ील्ड में मानकीकृत करता है:
  - `message.content` में असिस्टेंट का दिखाई देने वाला टेक्स्ट
  - `message.reasoning_content` और `message.reasoning_details` में रीज़निंग टेक्स्ट

## माइग्रेशन क्विकस्टार्ट

इस रूट पर रीज़निंग डिफ़ॉल्ट रूप से बंद है।

Gateway के मैपिंग नियम:

- रीज़निंग नियंत्रण न देने पर Gateway `reasoning_effort: "none"` भेजता है।
- `reasoning.enabled: true` देने पर Gateway `reasoning_effort: "high"` भेजता है।
- `reasoning.effort: "none"` देने पर Gateway `reasoning_effort: "none"` भेजता है।
- `reasoning.effort` का कोई दूसरा मान देने पर Gateway `reasoning_effort: "high"` भेजता है।

अनुशंसित उपयोग:

- हल्के काम के लिए `reasoning.effort: "none"`।
- गहन रीज़निंग के लिए `reasoning.effort: "high"`।

उदाहरण:

```json
{
  "model": "mistral/mistral-small-4-2026-03-16",
  "messages": [
    { "role": "user", "content": "Why is fast inference important?" }
  ],
  "reasoning": {
    "effort": "high"
  }
}
```

## जवाब संभालने संबंधी नोट

Mistral असिस्टेंट सामग्री के मिश्रित ब्लॉक लौटा सकता है (जैसे `thinking` और `text`)। Gateway उन्हें एक स्थिर संरचना में बदलता है, ताकि आप इन्हें उपयोग कर सकें:

- उपयोगकर्ता को दिखने वाला अंतिम उत्तर: `choices[0].message.content`।
- रीज़निंग टेक्स्ट: `choices[0].message.reasoning_content`।

इससे OpenAI-शैली के चैट कंप्लीशन फ़ील्ड की अपेक्षा रखने वाला डाउनस्ट्रीम व्यवहार बना रहता है।

## रिलीज़ जाँच-सूची

1. मॉडल ID को `mistral/mistral-small-4-2026-03-16` पर अपडेट करें।
2. रीज़निंग नियंत्रणों को केवल `none` और `high` के साथ सत्यापित करें।
3. उच्च प्रयास वाले रूट पर आउटपुट गुणवत्ता और स्कीमा परीक्षण फिर से चलाएँ।
4. पूरी तरह बदलने से पहले `none` और `high` की लेटेंसी और लागत की तुलना करें।
