मॉडल को `mistral/mistral-small-4` में बदलें और हर रूट के लिए तय करें कि रीज़निंग चालू रहे या नहीं। Mistral Small 4 में दो रीज़निंग मोड हैं, बंद और high, और Phaseo हर effort मान को इनमें से एक पर मैप करता है।

```json
{
  "model": "mistral/mistral-small-4",
  "messages": [
    { "role": "user", "content": "Why is fast inference important?" }
  ],
  "reasoning": { "effort": "high" }
}
```

## रीज़निंग चालू या बंद करें

जब तक अनुरोध न मांगे, रीज़निंग बंद रहती है। Mistral के अपने API पर, Phaseo `reasoning_effort` इस तरह भेजता है:

| अनुरोध | Mistral को भेजा जाता है |
| --- | --- |
| कोई रीज़निंग सेटिंग नहीं | `reasoning_effort: "none"` |
| `reasoning.effort: "none"` या `reasoning.enabled: false` | `reasoning_effort: "none"` |
| कोई भी दूसरा `reasoning.effort`, या `reasoning.enabled: true` | `reasoning_effort: "high"` |

अनुरोध में फ़्लैट `reasoning_effort` को `reasoning.effort` पर प्राथमिकता मिलती है। हल्के रूट के लिए `none` और गहरी रीज़निंग के लिए `high` उपयोग करें; `low` और `medium` बिल्कुल `high` की तरह व्यवहार करते हैं।

## उत्तर और रीज़निंग पढ़ें

Mistral मिश्रित कंटेंट ब्लॉक लौटा सकता है, जैसे `thinking` के बाद `text`। Phaseo उन्हें OpenAI-शैली के फ़ील्ड में बांट देता है, ताकि Chat Completions पढ़ने वाला डाउनस्ट्रीम कोड काम करता रहे:

- उत्तर `choices[0].message.content` में होता है;
- रीज़निंग टेक्स्ट `choices[0].message.reasoning_content` और `reasoning_details` में होता है।

## रोलआउट करें

1. मॉडल ID को Mistral Small 3.2 से `mistral/mistral-small-4` में बदलें।
2. रीज़निंग को सिर्फ़ `none` और `high` के साथ टेस्ट करें।
3. `high` उपयोग करने वाले रूट पर आउटपुट गुणवत्ता और स्कीमा टेस्ट दोबारा चलाएं।
4. पूरे कटओवर से पहले `none` और `high` के लिए लेटेंसी और लागत की तुलना करें।
