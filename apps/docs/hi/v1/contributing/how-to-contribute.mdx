**Phaseo** में योगदान देना आसान और पारदर्शी है तथा सभी के लिए खुला है।
यह मार्गदर्शिका पूरी प्रक्रिया बताती है—चाहे आप मॉडल प्रविष्टि संपादित करें, बेंचमार्क डेटा अपडेट करें, दस्तावेज़ सुधारें या नए विचार दें।

---

## शुरू करने से पहले

आपको कुछ बुनियादी टूल इंस्टॉल करने होंगे:

| टूल | उपयोग | इंस्टॉलेशन |
| ------------------ | ---------------------------------------------- | -------------------------------------------------- |
| **Git**            | बदलावों को क्लोन और पुश करने के लिए वर्ज़न कंट्रोल।     | [Git इंस्टॉल करें](https://git-scm.com/downloads)       |
| **Node.js (v20+)** | Phaseo साइट को स्थानीय रूप से चलाता है (Next.js)।      | [Node.js डाउनलोड करें](https://nodejs.org/en/download) |
| **pnpm**           | इस प्रोजेक्ट में इस्तेमाल होने वाला पैकेज मैनेजर।          | `npm install -g pnpm`                              |
| **GitHub खाता** | फ़ोर्क, इश्यू और पुल रिक्वेस्ट के लिए ज़रूरी है। | [यहाँ साइन अप करें](https://github.com/signup)          |

यदि आप केवल **डेटा** या **Markdown दस्तावेज़** संपादित करना चाहते हैं, तो स्थानीय वातावरण सेट किए बिना GitHub पर सीधे बदलाव कर सकते हैं।

---

## 1. रिपॉज़िटरी फ़ोर्क करें

[Phaseo GitHub रिपॉज़िटरी](https://github.com/phaseoteam/Phaseo) पर जाएँ और ऊपर दाईं ओर **Fork** पर क्लिक करें।
इससे प्रोजेक्ट की आपकी अपनी प्रति बनती है, जिसे आप स्वतंत्र रूप से संपादित कर सकते हैं।

---

## 2. अपना फ़ोर्क क्लोन करें

```bash
git clone https://github.com/yourusername/Phaseo.git
cd Phaseo
```

इससे आपका फ़ोर्क स्थानीय कंप्यूटर पर डाउनलोड हो जाता है।

---

## 3. नई ब्रांच बनाएँ

हर बदलाव के लिए नई ब्रांच बनाना अच्छा अभ्यास है:

```bash
git checkout -b update-benchmark-data
```

बदलाव बताने वाला स्पष्ट ब्रांच नाम रखें, ताकि समीक्षा आसान हो।

उदाहरण:

-   `fix-{model-name}`
-   `add-new-organisation`
-   `improve-docs`
-   `update-pricing-for-{model-name}`

---

## 4. बदलाव करें

आप क्या संपादित करना चाहते हैं, उसके अनुसार:

| क्षेत्र | फ़ाइलें | विवरण |
| --------------------- | --------------------------------------------- | ----------------------------------------------------- |
| **मॉडल डेटा**        | `/packages/data/catalog/src/data/models/**/model.json`     | मॉडल का मेटाडेटा, कीमत या बेंचमार्क जोड़ें या अपडेट करें। |
| **संगठन डेटा** | `/packages/data/catalog/src/data/organisations/*.json`     | कंपनियों या शोध समूहों की जानकारी अपडेट करें।    |
| **बेंचमार्क डेटा**    | `/packages/data/catalog/src/data/benchmarks/**/*.json`     | नए मूल्यांकन परिणाम या सुधार सबमिट करें।         |
| **दस्तावेज़**     | `/apps/docs/v1/**/*.mdx`                      | गाइड, रेफ़रेंस और दस्तावेज़ पेज बेहतर बनाएँ या विस्तार करें। |
| **गेटवे**           | `/apps/api/*`                                 | API गेटवे में बदलाव करें।                      |

डेटा संपादित करते समय [रिपॉज़िटरी संरचना](./repo-structure.mdx) में बताए गए स्कीमा और फ़ील्ड फ़ॉर्मैट का पालन करें।

---

## 5. बदलावों का पूर्वावलोकन करें (वैकल्पिक)

यदि आप अपने बदलावों का स्थानीय पूर्वावलोकन करना चाहें:

```bash
pnpm install
pnpm dev
```

वेब बदलावों के लिए [http://localhost:3100](http://localhost:3100) और दस्तावेज़ बदलावों के लिए [http://localhost:3101](http://localhost:3101) खोलें। वेब ऐप डेटाबेस से डेटा लेता है, इसलिए डेटा बदलाव PR बनने के बाद ही देखे जा सकते हैं।

---

## 6. बदलाव कमिट करें

बदलावों से संतुष्ट होने पर अपना काम कमिट करें:

```bash
git add .
git commit -m "Updated benchmark data for Claude 3.5 Sonnet"
```

कमिट संदेश में बदलाव स्पष्ट रूप से बताएँ, ताकि समीक्षक आपके योगदान को समझ सकें।

---

## 7. ब्रांच पुश करें

```bash
git push origin update-benchmark-data
```

---

## 8. पुल रिक्वेस्ट (PR) खोलें

1. GitHub पर अपने फ़ोर्क पर जाएँ।
2. PR बनाने का संदेश दिखेगा—**Compare & Pull Request** पर क्लिक करें।
3. अपने बदलावों से जुड़ी जानकारी PR टेम्पलेट में भरें।
4. PR सबमिट करें।

PR की समीक्षा और मंज़ूरी के बाद इसे Phaseo की मुख्य रिपॉज़िटरी में मर्ज कर दिया जाएगा।

## योगदान संबंधी सुझाव

-   PR को **छोटा और केंद्रित** रखें—हर PR में एक तार्किक बदलाव करें।
-   जहाँ संभव हो [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) का पालन करें। `fix:`, `add:` या `chore:` जैसे **स्पष्ट कमिट प्रीफ़िक्स** इस्तेमाल करें।
-   यदि बदलाव डेटा की सटीकता को प्रभावित करता है, तो **स्रोत या संदर्भ** शामिल करें।
-   बड़े या अनिश्चित विचारों पर कोड लिखने से पहले **GitHub Discussion** या Discord में चर्चा करें।
-   हमेशा सम्मानजनक रहें और हमारी [आचार संहिता](../community/code-of-conduct.mdx) का पालन करें।

## उदाहरण कार्यप्रवाह सारांश

```bash
# 1. Fork and clone

git clone https://github.com/yourusername/Phaseo.git
cd Phaseo

# 2. Create branch
git checkout -b add-openai-new-model

# 3. Make changes
# e.g., update packages/data/catalog/src/data/models/openai/new-model/model.json

# 4. Commit and push
git add .
git commit -m "Add new OpenAI model entry"
git push origin add-new-openai-model

# 5. Create a Pull Request on GitHub
```
