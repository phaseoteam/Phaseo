Phaseo एक pnpm और Turborepo मोनोरेपो है। अपने कोड या दस्तावेज़ बदलाव का फ़ोल्डर नीचे खोजें। कैटलॉग रिकॉर्ड रिपॉज़िटरी में नहीं हैं; किसी रिकॉर्ड को बदलने के लिए [issue खोलें](./overview.mdx)।

## ऐप्लिकेशन

| पाथ | उद्देश्य |
| --- | --- |
| `apps/web` | Next.js 16 वेबसाइट, डैशबोर्ड और आंतरिक कैटलॉग संपादक। |
| `apps/web-api` | सार्वजनिक कैटलॉग रीड, और प्रमाणित अकाउंट व एडमिन API। |
| `apps/api` | Cloudflare Workers पर Gateway रूटिंग और प्रदाता निष्पादन। |
| `apps/docs` | Mintlify दस्तावेज़; MDX पेज `v1` में हैं, नेविगेशन `docs.json` में। |
| `apps/mcp` | मॉडल खोज, कीमतों और उपयोग के लिए Phaseo MCP सर्वर। |
| `apps/desktop` | Phaseo Desktop ऐप। |
| `apps/mobile` | Phaseo मोबाइल ऐप (Expo, पहले Android)। |
| `apps/slack` | Phaseo Slack एजेंट के पीछे का Worker। |

## पैकेज और टूलिंग

| पाथ | उद्देश्य |
| --- | --- |
| `packages/sdk` | TypeScript, Python, Go, C#, PHP, Ruby, Java, Rust और C++ SDK, साथ में Agent SDK (`agent-sdk-*`)। |
| `packages/cli/phaseo` | `@phaseo/cli` कमांड-लाइन टूल। |
| `packages/integrations` | Vercel AI SDK प्रदाता और Terraform प्रदाता। |
| `packages/shared` | ऐप्स के बीच साझा कोड, जैसे UI, खर्च नियम और रूटिंग सेटिंग। |
| `supabase/schemas` | घोषणात्मक डेटाबेस परिभाषाएँ। |
| `supabase/migrations` | आगे की ओर चलने वाले SQL माइग्रेशन, जो स्कीमा और अनुमति बदलाव डिप्लॉय करते हैं। |
| `scripts` | सत्यापन, SDK जनरेशन और ऑटोमेशन यूटिलिटी। |
| `.github/workflows` | CI, डिप्लॉयमेंट और कैटलॉग सिंक्रनाइज़ेशन। |
| `.changeset` | वर्ज़न वाले पैकेजों के लिए रिलीज़ मेटाडेटा। |

## कैटलॉग डेटा

मॉडल, प्रदाता, संगठन, कीमतें, बेंचमार्क और कैटलॉग सेटिंग का एकमात्र स्रोत डेटाबेस है। रिपॉज़िटरी में कोई कैटलॉग JSON नहीं है। एडमिन [Internal data](https://phaseo.app/internal/data) में रिकॉर्ड प्रबंधित करते हैं; सार्वजनिक योगदान GitHub issues के रूप में आते हैं।

स्कीमा और ऐप्लिकेशन बदलाव अब भी माइग्रेशन और pull requests से होकर जाते हैं। जनरेट की गई SDK फ़ाइलें हाथ से नहीं, उनकी जनरेशन कमांड से अपडेट करें।

## कैटलॉग ऑटोमेशन

प्रदाता सिंक प्रस्तावित कीमतों को [Provider updates](https://phaseo.app/internal/data/imports) में समीक्षा के लिए कतार में रखता है। बेंचमार्क और मॉडल लाइफ़साइकल जॉब डेटाबेस को पढ़ते और उसमें लिखते हैं।

सिर्फ़ कैटलॉग रिकॉर्ड से Gateway रूटिंग चालू नहीं होती। रूट और कीमत के बदलावों के लिए एडमिन समीक्षा ज़रूरी है।

बदलाव शुरू करने के लिए [कोड या दस्तावेज़ में योगदान दें](./how-to-contribute.mdx) देखें।
