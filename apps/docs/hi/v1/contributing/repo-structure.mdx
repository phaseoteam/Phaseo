Phaseo में योगदान देने से पहले **रिपॉज़िटरी की संरचना** समझना ज़रूरी है।
प्रोजेक्ट डेटा, दस्तावेज़ और ऐप लॉजिक को अलग रखता है, ताकि ज़रूरी चीज़ें आसानी से मिलें और संरचना स्पष्ट रूप से बढ़ सके।

---

## अवलोकन

रिपॉज़िटरी की रूट डायरेक्टरी इस तरह दिखती है:

```bash
Phaseo/
+-- apps/
¦   +-- web/ # The main Phaseo Next.js website (contains data)
¦   +-- api/ # The Phaseo Gateway API (Hono/Cloudflare Workers)
¦   +-- docs/ # The Mintlify-powered documentation site
¦
+-- packages/ # SDKs and shared tooling
¦   +-- sdk-ts/
¦   +-- sdk-py/
¦   +-- sdk-go/
¦   +-- sdk-csharp/
¦   +-- sdk-php/
¦   +-- sdk-ruby/
¦   +-- sdk-java/
¦   +-- sdk-rust/
¦   +-- sdk-cpp/
¦   +-- ai-sdk-phaseo/
¦
+-- scripts/ # Automation scripts and utilities
+-- .changeset/ # Release metadata
+-- turbo.json # Turborepo configuration
+-- package.json # Global scripts and dependencies
+-- README.md # Root readme file
```

---

## डेटा फ़ोल्डर

Phaseo संरचित डेटा को `/packages/data/catalog/src/data` डायरेक्टरी में **JSON फ़ाइलों** में रखता है।
ये फ़ाइलें मॉडल, बेंचमार्क और कीमतों के लिए सही जानकारी का स्रोत हैं।

### `/packages/data/catalog/src/data/models`

हर मॉडल के लिए एक JSON फ़ाइल होती है।
हर फ़ाइल में मॉडल का मेटाडेटा, कीमत, बेंचमार्क और क्षमताएँ होती हैं।

उदाहरण:
`/packages/data/catalog/src/data/models/openai/gpt-5-2025-08-07/model.json`

---

### `/packages/data/catalog/src/data/organisations`

मॉडल के पीछे की कंपनियों या शोध समूहों का विवरण देता है।
हर JSON फ़ाइल में नाम, विवरण, स्थापना तिथि, वेबसाइट और देश शामिल हैं।

उदाहरण:
`/packages/data/catalog/src/data/organisations/openai.json`

---

### `/packages/data/catalog/src/data/benchmarks`

इसमें बेंचमार्क मेटाडेटा और विभिन्न मॉडलों के एकत्रित परिणाम होते हैं।
हर बेंचमार्क में ID, नाम, विवरण, श्रेणी और मेट्रिक्स होते हैं।

उदाहरण:
`/packages/data/catalog/src/data/benchmarks/mmlu.json`

---

### `/packages/data/catalog/src/data/api_providers`

सभी समर्थित API प्रदाताओं और उनके मॉडलों की सूची देता है।
यह मॉडल और संगठनों, दोनों से जुड़ता है।

उदाहरण:
`/packages/data/catalog/src/data/api_providers/openai.json`

---

### `/packages/data/catalog/src/data/pricing`

रुझानों के विश्लेषण के लिए समय के साथ कीमतों का इतिहास रखता है।
फ़ाइलों पर टाइमस्टैम्प होते हैं और उन्हें अक्सर प्रदाता के अनुसार समूहित किया जाता है।

---

## दस्तावेज़ फ़ोल्डर

दस्तावेज़ **MDX** में लिखे गए हैं और `/apps/docs/v1/` में मौजूद हैं।
हर फ़ोल्डर Mintlify कॉन्फ़िगरेशन के एक समूह से सीधे जुड़ा है।

| फ़ोल्डर | उद्देश्य |
| ----------------------------- | ------------------------------------------------------- |
| `/apps/docs/v1/exploring`     | डेटा की अवधारणाओं (मॉडल, बेंचमार्क, प्रदाता) की व्याख्या करता है। |
| `/apps/docs/v1/contributing`  | योगदानकर्ताओं के लिए चरण-दर-चरण गाइड।                   |
| `/apps/docs/v1/developers`    | इंटीग्रेशन और API उपयोग के गाइड।                       |
| `/apps/docs/v1/api-reference` | हर एंडपॉइंट के लिए विस्तृत रेफ़रेंस।                  |
| `/apps/docs/v1/community`     | सहायता, FAQ और समुदाय के पेज।                      |

---

## ऐप्लिकेशन फ़ोल्डर

| पथ | विवरण |
| ------------ | ------------------------------------------------------------------------------------------------- |
| `/apps/web`  | Next.js 15 और TailwindCSS से बना मुख्य Phaseo वेबसाइट। यह आधिकारिक डेटा `packages/data/catalog/src/data` से पढ़ता है। |
| `/apps/api`  | API Gateway—रूटिंग, कैशिंग और मॉडल प्रॉक्सी लॉजिक।                                         |
| `/apps/docs` | यह Mintlify दस्तावेज़ प्रोजेक्ट, जिसे आप अभी पढ़ रहे हैं।                                           |

हर ऐप स्वतंत्र रूप से चलता है, लेकिन `/packages` के ज़रिए टाइप और कॉन्फ़िगरेशन साझा करता है।

---

## SDK पैकेज

`/packages` डायरेक्टरी में Phaseo API के साथ काम करने के लिए विभिन्न प्रोग्रामिंग भाषाओं के SDK हैं।

| SDK | विवरण |
| ------------ | ------------------------------------------------ |
| `sdk-ts`     | Node.js और वेब ऐप्लिकेशन के लिए TypeScript SDK। |
| `sdk-py`     | Python SDK।                                      |
| `sdk-go`     | Go SDK।                                          |
| `sdk-csharp` | C# SDK।                                          |
| `sdk-php`    | PHP SDK।                                         |
| `sdk-ruby`   | Ruby SDK।                                        |
| `sdk-java`   | Java SDK।                                        |
| `sdk-rust`   | Rust SDK।                                        |
| `sdk-cpp`    | C++ SDK।                                         |
| `ai-sdk-phaseo` | Vercel AI SDK प्रदाता।                      |

## ऑटोमेशन और स्क्रिप्ट

Phaseo डेटा को अपडेट रखने के लिए ऑटोमेशन का उपयोग करता है:

-   **इंपोर्टर**: Hugging Face या प्रदाता API जैसे स्रोतों से नया डेटा लाते हैं।
-   **वॉचर**: GitHub Actions के ज़रिए तय समय पर चलते हैं, ताकि अपडेट पहचानकर कमिट किए जा सकें।
-   **यूटिलिटी**: सत्यापन, स्कीमा जाँच और JSON फ़ॉर्मैटिंग संभालती हैं।

इन्हें `/scripts/` में देख सकते हैं।

---

## कहाँ से शुरू करें

यदि आप योगदान दे रहे हैं:

-   **डेटा:** `/packages/data/catalog/src/data/` में JSON फ़ाइलें देखें।
-   **दस्तावेज़:** `/apps/docs/v1/` में MDX फ़ाइलें देखें।
-   **कोड:** `/apps/web` या `/apps/api` देखें।
-   **ऑटोमेशन:** `/scripts/` में बदलाव करें या उसकी जाँच करें।
-   **SDK:** `/packages/` में भाषा-विशिष्ट SDK देखें।
