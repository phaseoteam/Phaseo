Phaseo pnpm और Turborepo मोनोरेपो है। कोड या दस्तावेज़ बदलाव की फ़ाइलें खोजने के लिए यह संदर्भ इस्तेमाल करें। कैटलॉग रिकॉर्ड बदलाव के लिए [issue खोलें](./overview.mdx)।

## ऐप्लिकेशन और पैकेज

| पथ | उद्देश्य |
| --- | --- |
| `apps/web` | Next.js 16 वेबसाइट, डैशबोर्ड और आंतरिक कैटलॉग एडिटर। |
| `apps/web-api` | सार्वजनिक कैटलॉग पढ़ना और प्रमाणीकरण वाले खाता व एडमिन API। |
| `apps/api` | Cloudflare Workers पर गेटवे रूटिंग और प्रदाता निष्पादन। |
| `apps/docs` | Mintlify दस्तावेज़; MDX पेज `v1` में, नेविगेशन `docs.json` में। |
| `packages/data/catalog` | कैटलॉग स्कीमा, संगतता फ़िक्स्चर और जनरेट किए सार्वजनिक स्नैपशॉट। |
| `packages/sdk` | TypeScript, Python, Go, C#, PHP, Ruby, Java, Rust और C++ SDK। |
| `supabase/migrations` | डेटाबेस स्कीमा और अनुमति माइग्रेशन। |
| `scripts` | सत्यापन, SDK जनरेशन और ऑटोमेशन उपकरण। |
| `.github/workflows` | CI, डिप्लॉयमेंट, कैटलॉग समन्वयन और स्नैपशॉट शेड्यूल। |
| `.changeset` | संस्करण वाले पैकेज का रिलीज़ मेटाडेटा। |

## कैटलॉग डेटा

डेटाबेस मॉडल, प्रदाता, संगठन, कीमत, बेंचमार्क और सहायक कैटलॉग सेटिंग्स का प्रामाणिक स्रोत है। एडमिन [आंतरिक डेटा](https://phaseo.app/internal/data) से रिकॉर्ड प्रबंधित करते हैं। सार्वजनिक योगदान GitHub issue के जरिए समीक्षा किए जाते हैं।

- `packages/data/catalog/generated/database-v2` में दैनिक सार्वजनिक स्नैपशॉट और OpenAPI तथा SDK टूल द्वारा इस्तेमाल जनरेट किया मॉडल enum इंडेक्स है।
- `packages/data/catalog/src/data` में संग्रहीत संगतता फ़िक्स्चर हैं।
- किसी भी डायरेक्टरी का संपादन लाइव कैटलॉग रिकॉर्ड नहीं बदलता। पुराना JSON से डेटाबेस आयातक बंद हो चुका है।

स्कीमा और ऐप्लिकेशन बदलाव अभी भी माइग्रेशन और पुल अनुरोध इस्तेमाल करते हैं। जनरेट किए स्नैपशॉट और SDK आर्टिफ़ैक्ट उनके जनरेशन कमांड से अपडेट होने चाहिए।

## कैटलॉग ऑटोमेशन

प्रदाता समन्वयन प्रस्तावित कीमतों को [प्रदाता अपडेट](https://phaseo.app/internal/data/imports) में समीक्षा की कतार में रखता है। बेंचमार्क और मॉडल जीवनचक्र जॉब डेटाबेस इस्तेमाल करते हैं। दैनिक सार्वजनिक निर्यात समीक्षा योग्य स्नैपशॉट पुल अनुरोध बनाते हैं।

केवल कैटलॉग में रिकॉर्ड होना गेटवे रूटिंग अपने आप सक्षम नहीं करता। रूट और कीमत बदलाव को संबंधित एडमिन समीक्षा चाहिए।
