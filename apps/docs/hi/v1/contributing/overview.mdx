Phaseo एक **ओपन और समुदाय-संचालित प्रोजेक्ट** है, जिसका उद्देश्य AI मॉडल, बेंचमार्क और प्रदाताओं की अधिकतम जानकारी सभी के लिए निःशुल्क उपलब्ध कराना है।

आपका योगदान प्लेटफ़ॉर्म को सटीक, पारदर्शी और अद्यतन रखने में मदद करता है।  
टाइपो ठीक करना हो, नया बेंचमार्क डेटा जोड़ना हो या दस्तावेज़ सुधारना—हर योगदान मायने रखता है।

---

## योगदान क्यों करें?

AI तेज़ी से विकसित हो रहा है—हर दिन नए मॉडल, अपडेट और कीमतों में बदलाव होते हैं।  
योगदान देकर आप मदद करते हैं:

-   मॉडल, संगठनों और बेंचमार्क के डेटा को वर्तमान और भरोसेमंद रखना
-   प्रदाताओं के बीच AI तुलना की सटीकता बढ़ाना
-   शोध निष्कर्ष, समुदाय की खोजें या छूटा हुआ मेटाडेटा साझा करना
-   AI पारदर्शिता के खुले इकोसिस्टम को मज़बूत करना
-   डेटाबेस को निःशुल्क उपलब्ध और समुदाय के स्वामित्व में बनाए रखना

आपका नाम भी इस पृष्ठ पर दिखाई देगा: [योगदानकर्ता पृष्ठ](https://phaseo.app/contribute), आपके योगदान के सम्मान में।

## योगदान प्रक्रिया का अवलोकन

1. [Phaseo GitHub रिपॉज़िटरी](https://github.com/phaseoteam/Phaseo) का **फ़ोर्क** बनाएँ।
2. बदलावों के लिए **ब्रांच बनाएँ** (जैसे `fix-model-data` या `add-new-benchmark`)।
3. [रिपॉज़िटरी संरचना](./repo-structure.mdx) में बताई गई व्यवस्था के अनुसार **JSON या Markdown फ़ाइलें संपादित करें**।
4. ज़रूरत पड़ने पर **बदलावों को स्थानीय रूप से जाँचें** (जैसे Next.js फ़्रंटएंड में देखकर)।
5. बदलावों को **कमिट करके पुश करें**।
6. **पुल रिक्वेस्ट (PR) खोलें** और बताएँ कि क्या बदला है और क्यों।

समीक्षा और मंज़ूरी के बाद आपका योगदान मर्ज होकर Phaseo के लाइव डेटाबेस में दिखाई देगा।

## योगदान के प्रकार

| प्रकार                   | उदाहरण                                                 | कठिनाई |
| ---------------------- | ------------------------------------------------------- | ---------- |
| **डेटा सुधार**           | मॉडल नाम, प्रदाता या बेंचमार्क मान ठीक करना। | आसान       |
| **नई प्रविष्टि**          | नया मॉडल, बेंचमार्क या संगठन जोड़ना।         | मध्यम   |
| **संरचनात्मक बदलाव**  | डेटाबेस या स्कीमा लेआउट में बदलाव करना।                    | उन्नत   |
| **सुविधा जोड़ना**   | UI कंपोनेंट या Next.js लॉजिक जोड़ना।                  | उन्नत   |
| **दस्तावेज़ संपादन** | Markdown फ़ाइलें या गाइड सुधारना।                     | आसान       |

आप कोई भी बदलाव करना चाहें, हर आकार और जटिलता के योगदान का स्वागत है।

## दिशानिर्देश और मानक

डेटा की गुणवत्ता और एकरूपता सुनिश्चित करने के लिए सभी योगदानों को इन मानकों का पालन करना चाहिए:

-   **सटीक स्रोत:** केवल सत्यापित या आधिकारिक रूप से प्रकाशित डेटा शामिल करें।
-   **एकसमान फ़ॉर्मैटिंग:** सही केसिंग, इंडेंटेशन और स्कीमा कुंजियों का उपयोग करें।
-   **संस्करणित बदलाव:** चेंजलॉग या कमिट संदेशों में बदलाव का स्पष्ट वर्णन करें।
-   **संदर्भ:** PR विवरण में डेटा स्रोतों के लिंक शामिल करें।
-   **सम्मानजनक संवाद:** हमारे [आचार संहिता](../community/code-of-conduct.mdx).

## योगदान प्रक्रिया का उदाहरण

```bash
# 1. Fork and clone the repo
git clone https://github.com/yourusername/Phaseo.git

# 2. Create a new branch
git checkout -b add-openai-new-model

# 3. Make your edits
# e.g. edit packages/data/catalog/src/data/models/openai/new-model/model.json

# 4. Stage, commit, and push
git add .
git commit -m "Added new OpenAI model with updated benchmark data"
git push origin add-openai-new-model

# 5. Open a Pull Request on GitHub
# Describe your changes and link any sources
```

-   सवाल या सुझाव के लिए **GitHub Discussion** खोलें।
-   समीक्षा मार्गदर्शन के लिए अपने PR में मेंटेनर को टैग करें।
