मॉडल का डेटा `packages/data/catalog/src/data/models` के अंतर्गत JSON फ़ाइलों में होता है। हर मॉडल का अपना फ़ोल्डर और `model.json` फ़ाइल होती है।

## 1. मॉडल ढूँढ़ें

प्रदाता और मॉडल के नाम से मॉडल डायरेक्टरी ढूँढ़ें। उदाहरण:

`packages/data/catalog/src/data/models/openai/gpt-5-2025-08-07/model.json`

## 2. बदलाव करें

आम बदलावों में शामिल हैं:

- विवरण और लिंक
- क्षमताएँ और समर्थित एंडपॉइंट
- कीमत या उपलब्धता संबंधी जानकारी
- बेंचमार्क संदर्भ

मानों को आस-पास की फ़ाइलों में मौजूद स्कीमा के अनुरूप रखें।

## 3. डेटा की जाँच करें

PR खोलने से पहले डेटा सत्यापन स्क्रिप्ट चलाएँ:

```bash
pnpm validate:data
```

## 4. PR खोलें

बदलावों का संक्षिप्त सारांश और उपयोग किए गए स्रोत शामिल करें।
