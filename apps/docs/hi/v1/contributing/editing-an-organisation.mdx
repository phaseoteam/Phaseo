संगठन की छूटी हुई या पुरानी जानकारी GitHub इश्यू के माध्यम से बताएँ। मेंटेनर प्रमाणों की समीक्षा करके स्वीकृत बदलाव डेटाबेस संपादक में लागू करते हैं।

## सुधार की सूचना दें

1. संगठन के Phaseo पेज का URL या ID कॉपी करें।
2. प्रभावित फ़ील्ड और प्रस्तावित मान के साथ [गलत जानकारी की सूचना दें](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml)।
3. आधिकारिक वेबसाइट, घोषणा या अन्य सत्यापन योग्य स्रोत का लिंक दें।

आम सुधारों में नाम, विवरण, वेबसाइट, स्थान और मॉडल या API प्रदाताओं से संबंध शामिल हैं।

## छूटे हुए संगठन का अनुरोध करें

संगठन का नाम, आधिकारिक वेबसाइट और संबंधित मॉडल या प्रदाता लिंक देते हुए [डेटा अनुरोध खोलें](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml)।

## जमा करने के बाद

समीक्षा और प्रकाशन की स्थिति इश्यू में देखें। कैटलॉग रिकॉर्ड बदलने के लिए JSON संपादन या पुल रिक्वेस्ट की आवश्यकता नहीं है। दैनिक JSON फ़ाइलें निर्यात हैं; उन्हें लाइव डेटाबेस में आयात नहीं किया जाता।

प्रशासक [आंतरिक कैटलॉग संपादक](https://phaseo.app/internal/data) से संगठनों का प्रबंधन करते हैं, जिसके लिए प्रशासक पहुँच आवश्यक है।
