संगठन की छूटी हुई या पुरानी जानकारी GitHub issue के ज़रिए बताएँ। मेंटेनर प्रमाणों की समीक्षा करते हैं और स्वीकृत बदलाव डेटाबेस संपादक में लागू करते हैं।

## सुधार की रिपोर्ट करें

1. संगठन के Phaseo पेज का URL या ID कॉपी करें।
2. प्रभावित फ़ील्ड और प्रस्तावित मान के साथ [गलत जानकारी की रिपोर्ट करें](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml)।
3. आधिकारिक वेबसाइट, घोषणा या किसी दूसरे सत्यापन योग्य स्रोत का लिंक दें।

आम सुधारों में नाम, विवरण, वेबसाइट, स्थान, और मॉडलों या API प्रदाताओं से संबंध शामिल हैं।

## छूटे हुए संगठन का अनुरोध करें

संगठन के नाम, आधिकारिक वेबसाइट और संबंधित मॉडल या प्रदाता लिंक के साथ [डेटा अनुरोध खोलें](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml)।

## सबमिट करने के बाद

समीक्षा और प्रकाशन की स्थिति issue में देखें। कैटलॉग रिकॉर्ड बदलने के लिए pull request की ज़रूरत नहीं है: कैटलॉग रिकॉर्ड का एकमात्र स्रोत डेटाबेस है, और रिपॉज़िटरी में कोई कैटलॉग JSON नहीं है।

एडमिन [आंतरिक कैटलॉग संपादक](https://phaseo.app/internal/data) से संगठनों को प्रबंधित करते हैं, जिसके लिए एडमिन एक्सेस चाहिए।
