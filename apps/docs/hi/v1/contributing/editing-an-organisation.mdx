संगठन का डेटा `packages/data/catalog/src/data/organisations` के अंतर्गत JSON फ़ाइलों में होता है।

## 1. संगठन ढूँढ़ें

हर संगठन एक JSON फ़ाइल में दर्ज होता है। उदाहरण:

`packages/data/catalog/src/data/organisations/openai.json`

## 2. बदलाव करें

आम बदलावों में शामिल हैं:

- नाम, विवरण और वेबसाइट
- देश कोड या मेटाडेटा फ़ील्ड
- मॉडल या प्रदाताओं के संबंध लिंक

फ़ॉर्मैटिंग और फ़ील्ड क्रम को आस-पास की फ़ाइलों के अनुरूप रखें।

## 3. डेटा की जाँच करें

PR खोलने से पहले डेटा सत्यापन स्क्रिप्ट चलाएँ:

```bash
pnpm validate:data
```

## 4. PR खोलें

तथ्यात्मक बदलावों के लिए स्रोत या संदर्भ दें।
