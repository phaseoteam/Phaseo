डैशबोर्ड, API या इन दस्तावेज़ों में मिले किसी शब्द को यहाँ खोजें। हर पंक्ति एक वाक्य में अर्थ देती है, उस पेज का लिंक देती है जो शब्द को पूरी तरह समझाता है, और बताती है कि यह कहाँ लागू होता है: API, डैशबोर्ड, CLI, SDK, MCP, चैट या Slack।

## खाते और पहुँच

| शब्द | अर्थ | कहाँ लागू होता है |
| --- | --- | --- |
| [एडमिन](./developers/management-api-keys.mdx) | वर्कस्पेस की एक भूमिका जो बजट, खर्च नियम, गार्डरेल और ट्रस्ट नीतियों जैसी सिर्फ़-एडमिन सेटिंग्स प्रबंधित करती है, और ऑडिट लॉग पढ़ती है। | API, डैशबोर्ड, CLI, MCP |
| [सदस्य](./developers/management-api-keys.mdx) | वर्कस्पेस की एक भूमिका जो वर्कस्पेस का उपयोग करती है और उसके खर्च नियम देख सकती है, लेकिन सिर्फ़ मालिक और एडमिन वाली सेटिंग्स नहीं बदल सकती। | API, डैशबोर्ड, CLI, MCP |
| [मालिक](./developers/management-api-keys.mdx) | वर्कस्पेस की एक भूमिका जो एडमिन जैसी ही सिर्फ़-एडमिन सेटिंग्स प्रबंधित करती है और मॉडल अप्रचलन अलर्ट जैसे मालिक ईमेल पाती है। | API, डैशबोर्ड, CLI, MCP |
| [वर्कस्पेस](./guides/workspaces.mdx) | एक कंटेनर जो अपनी API कुंजियाँ, रूटिंग सेटिंग्स, प्रीसेट, गार्डरेल और एडमिन पहुँच दूसरे वर्कस्पेस से अलग रखता है। | API, डैशबोर्ड, CLI |

## कुंजियाँ और प्रमाणीकरण

| शब्द | अर्थ | कहाँ लागू होता है |

| [BYOK](./guides/routing-and-fallbacks.mdx#byok-considerations) | अपनी कुंजी लाएँ: Phaseo आपकी प्रदाता API कुंजी से अनुरोध रूट करता है, और मॉडल उपयोग का बिल प्रदाता बनाता है। | API, डैशबोर्ड |
| [BYOK फ़ॉलबैक](./guides/routing-and-fallbacks.mdx#byok-considerations) | वर्कस्पेस की एक सेटिंग जो तय करती है कि विफल BYOK अनुरोध Phaseo क्रेडिट पर दोबारा कोशिश कर सकता है या नहीं। | API, डैशबोर्ड |
| [क्षमता](./developers/management-api-keys.mdx#choose-an-access-level) | मैनेजमेंट कुंजी या OAuth साइन-इन पर एक अनुमति, जैसे `keys:write`, जो तय करती है कि वह कौन से प्रशासन API कॉल कर सकती है। | API, डैशबोर्ड, CLI, MCP |
| [मैनेजमेंट कुंजी](./developers/management-api-keys.mdx) | कुंजियों, प्रीसेट और गार्डरेल जैसे प्रशासन API के लिए `phaseo_v1_mk_` से शुरू होने वाला सीक्रेट; यह इनफ़रेंस अनुरोध नहीं भेज सकती। | API, डैशबोर्ड |
| [OAuth ऐप](./guides/integrations/phaseo-cli.mdx#oauth-apps) | एक ऐप जो लोगों को Phaseo OAuth से साइन इन कराता है और उनके स्वीकृत स्कोप और वर्कस्पेस के भीतर उनकी ओर से काम करता है। | API, डैशबोर्ड, CLI, MCP |
| [भरोसेमंद वर्कलोड](./developers/trusted-workloads.mdx) | एक डिप्लॉयमेंट या CI जॉब जो API कुंजी के बजाय अपने प्लेटफ़ॉर्म का अल्पकालिक OIDC टोकन भेजता है, और किसी ट्रस्ट नीति से मेल खाता है। | API, डैशबोर्ड |

## मॉडल और प्रदाता

| शब्द | अर्थ | कहाँ लागू होता है |
| --- | --- | --- |
| [कॉन्टेक्स्ट लंबाई](./exploring/models.mdx#what-a-model-page-shows) | किसी मॉडल के लिए प्रदाता रूट जितने कॉन्टेक्स्ट आकार का समर्थन करता है, जो मॉडल पेज पर हर प्रदाता के लिए दिखाया जाता है। | API, डैशबोर्ड |
| [अप्रचलित (मॉडल)](./guides/model-retirement.mdx#how-a-model-is-retired) | लैब या प्रदाता ने मॉडल की सेवानिवृत्ति की घोषणा कर दी है, और उसके अनुरोध अब भी सामान्य रूप से पूरे होते हैं। | API, डैशबोर्ड |
| [मॉडल ID](./api-reference/parameters.mdx#parameter-model) | वह ID जिसे आप `model` के रूप में भेजते हैं, जैसे `openai/gpt-6-astra`, जो हर मॉडल पेज के क्विकस्टार्ट में दिखाई जाती है। | API, डैशबोर्ड, CLI, SDK, MCP |
| [निजी मॉडल](./guides/private-models.mdx) | आपके वर्कस्पेस में जोड़ा गया एक समर्पित या सेल्फ़-होस्टेड OpenAI-संगत डिप्लॉयमेंट, जिसे सिर्फ़ आपका वर्कस्पेस देख या कॉल कर सकता है। | API, डैशबोर्ड |
| [प्रदाता](./developers/introduction.mdx#models-and-providers) | एक कंपनी जो मॉडल होस्ट करती है और उसकी उपलब्धता, समर्थित पैरामीटर, कीमत और प्रदर्शन तय करती है। | API, डैशबोर्ड, SDK, MCP |
| [प्रदाता स्थिति आइकन](./guides/provider-statuses.mdx#status-icon) | वह स्थिति जिसे Phaseo किसी प्रदाता रूट के लिए खुद सेट करता है: `Active`, `Lower priority` (सिर्फ़ बैकअप) या `Disabled`। | डैशबोर्ड |
| [प्रदाता-योग्य मॉडल ID](./guides/provider-qualified-models.mdx) | प्रदाता उपसर्ग वाली मॉडल ID, जैसे `baseten:thinking-machines/inkling-small`, जो बिना फ़ॉलबैक के उसी प्रदाता पर चलती है। | API, SDK |
| [क्वांटाइज़ेशन](./guides/quantization.mdx) | मॉडल के वेट को `FP8` या `INT4` जैसे छोटे संख्या प्रकार में रखना, जिससे गुणवत्ता में कुछ कमी के साथ तेज़ सेवा मिलती है। | API, डैशबोर्ड, SDK |
| [सेवानिवृत्त (मॉडल)](./guides/model-retirement.mdx#how-a-model-is-retired) | सेवानिवृत्ति की तारीख बीत चुकी है; जब तक कोई प्रदाता मॉडल उपलब्ध कराता है, अनुरोध काम करते हैं, फिर `410 model_retired` के साथ विफल होते हैं। | API, डैशबोर्ड |
| [रूट करने योग्य मॉडल](./exploring/models.mdx#catalog-models-and-callable-models) | ऐसा मॉडल जिसका कम से कम एक प्रदाता रूट अभी Gateway पर सक्रिय है; `GET /v1/models` डिफ़ॉल्ट रूप से सिर्फ़ इन्हीं को सूचीबद्ध करता है। | API, डैशबोर्ड, MCP |

| [Gateway](./developers/introduction.mdx) | `https://api.phaseo.app/v1` पर Phaseo API, जो हर अनुरोध को मॉडल होस्ट करने वाले किसी प्रदाता तक रूट करता है। | API, SDK |
| [जनरेशन ID](./api-reference/endpoint/generation.mdx) | `x-request-id` और त्रुटि बॉडी में लौटाई गई `G-` अनुरोध ID; इसे लॉग, खोज और सहायता के लिए इस्तेमाल करें। | API, डैशबोर्ड, SDK |
| [प्रॉम्प्ट कैशिंग](./guides/prompt-caching.mdx) | प्रॉम्प्ट की शुरुआत एक जैसी रखना ताकि प्रदाता उसे कैश से पढ़े और कैश-रीड दर पर बिल बनाए। | API, SDK |
| [रीज़निंग प्रयास](./api-reference/parameters.mdx#parameter-reasoning) | जवाब देने से पहले कोई रीज़निंग मॉडल कितना सोचता है, जिसे `reasoning.effort` या `reasoning_effort` से `none` से `max` तक सेट किया जाता है। | API, SDK |
| [रीज़निंग टोकन](./guides/context-and-token-budgeting.mdx#what-counts-towards-a-request) | वे टोकन जो कोई रीज़निंग मॉडल जवाब देने से पहले खर्च करता है; ये आउटपुट में गिने जाते हैं और आउटपुट सीमा का हिस्सा लेते हैं। | API, SDK |
| [सेवा स्तर](./guides/service-tiers.mdx) | टेक्स्ट अनुरोध के लिए गति और कीमत का एक स्तर (`standard`, `fast`, `ultrafast` या `flex`), जिसे सिर्फ़ वही प्रदाता पूरा करते हैं जो इसे देते हैं। | API, SDK |
| [सत्र ID](./guides/routing-and-fallbacks.mdx#keep-a-conversation-on-one-provider) | एक `session_id` जिसे आप किसी बातचीत के अनुरोधों को एक प्रदाता पर रखने के लिए भेजते हैं, अधिकतम 24 घंटे की गतिविधि तक। | API, डैशबोर्ड, SDK |
| [स्ट्रीमिंग](./guides/streaming.mdx) | `stream: true` सेट करना ताकि मॉडल के लिखते समय Gateway आउटपुट को सर्वर-सेंट इवेंट के रूप में भेजे। | API, SDK |
| [टोकन](./guides/context-and-token-budgeting.mdx) | वे इकाइयाँ जिन्हें मॉडल इनपुट के रूप में पढ़ता है और आउटपुट के रूप में लिखता है; हर टोकन विलंब और लागत बढ़ाता है। | API, डैशबोर्ड, SDK |
| [उपयोग ऑब्जेक्ट](./guides/prompt-caching.mdx#usage-and-pricing-fields) | प्रतिक्रिया में `usage` फ़ील्ड, जो अनुरोध के इनपुट, आउटपुट और कैश टोकन की गिनती बताता है। | API, SDK |
