हर अनुरोध पर `X-App-Id` हेडर भेजें, ताकि ऐप एनालिटिक्स और अनुरोध ऑडिट में उसका उपयोग एक ऐप्लिकेशन के तहत समूहबद्ध हो। हर उस प्रोडक्ट, एनवायरनमेंट या ग्राहक-सामने वाले अनुभव के लिए अलग ID इस्तेमाल करें जिसकी आप अलग रिपोर्ट चाहते हैं। एट्रिब्यूशन इन्फ़रेंस प्रतिक्रिया को कभी नहीं बदलता।

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-App-Id: acme-support" \
  -H "X-App-Name: Acme Support" \
  -H "HTTP-Referer: https://acme.example/support" \
  -H "X-App-Categories: chat,productivity" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Summarize this ticket."
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const phaseo = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY,
  app: {
    id: "acme-support",
    name: "Acme Support",
    url: "https://acme.example/support",
    categories: ["chat", "productivity"],
  },
});

const response = await phaseo.generateResponse({
  model: "openai/gpt-6-astra",
  input: "Summarize this ticket.",
});
```
</CodeGroup>

TypeScript SDK का `app` विकल्प हर अनुरोध पर यही हेडर भेजता है। Phaseo आपके लिए एट्रिब्यूशन कभी सेट नहीं करता।

## हेडर

| हेडर | उद्देश्य |
| --- | --- |
| `X-App-Id` | आपके ऐप्लिकेशन द्वारा चुना गया स्थिर पहचानकर्ता। |
| `X-App-Name` | ऐप और उपयोग व्यू में दिखने वाला पढ़ने योग्य नाम। |
| `HTTP-Referer` | ऐप से जुड़ा सार्वजनिक पेज या डिप्लॉयमेंट URL। |
| `X-App-Categories` | अधिकतम तीन श्रेणियों की कॉमा से अलग की गई सूची। |
| `X-Title` | पढ़ने योग्य ऐप नाम के लिए संगतता उपनाम। |

अगर आप `HTTP-Referer` URL भेजते हैं तो Phaseo ऐप को उसी से पहचानता है, वरना `X-App-Id` से। दोनों को स्थिर रखें: नया URL या ID एनालिटिक्स में एक नया ऐप शुरू कर देता है।

`HTTP-Referer` का ब्राउज़र के अपने-आप भेजे गए `Referer` हेडर से मेल खाना ज़रूरी नहीं है। जब आप एक तय ऐप URL चाहते हों, तो सर्वर-साइड इंटीग्रेशन में इसे स्पष्ट रूप से सेट करें।

## श्रेणियाँ

`chat`, `developer-tools`, `research`, `productivity`, `education`, `commerce`, `media`, `finance` और `other` में से अधिकतम तीन चुनें।

मान केस-इनसेंसिटिव होते हैं। Phaseo अज्ञात मानों को अनदेखा करता है, डुप्लिकेट हटाता है, और पहली तीन मान्य श्रेणियाँ रखता है। बाद के अनुरोधों में भेजी गई श्रेणियाँ ऐप के लिए पहले से सेव श्रेणियों में जुड़ जाती हैं; वे डैशबोर्ड में चुनी गई श्रेणियों को कभी नहीं हटातीं।

ऐप्लिकेशन कोड के बजाय श्रेणियों को केंद्रीय रूप से प्रबंधित करने के लिए उन्हें **सेटिंग्स → ऐप्स** में संपादित करें।

## एट्रिब्यूशन को साझा करने के लिए सुरक्षित रखें

- एट्रिब्यूशन हेडर में ग्राहक ID, ईमेल पते या दूसरा व्यक्तिगत डेटा न डालें।
- URL और नाम को सार्वजनिक मानें: वे साझा या सार्वजनिक ऐप व्यू में दिख सकते हैं।
