यह पेज quantization और inference parameters पर पूरी guide series का शुरुआती बिंदु है।

अगर आप model variants चुन रहे हैं (जैसे `BF16` बनाम `FP8`) या request settings (`temperature`, `top_p`, token budgets) tune कर रहे हैं, तो यहाँ से शुरू करके जुड़े guides पढ़ें।

## क्वांटाइज़ेशन क्या है?

Quantization में model weights और activations को कम precision वाले numbers से दिखाया जाता है, जिससे memory usage घटता है और inference तेज़ होता है।

सामान्यतः:

- अधिक precision: बेहतर quality/stability, लेकिन अधिक लागत।
- कम precision: बेहतर throughput और कम लागत, लेकिन quality risk अधिक।
