[fx](https://fx.sh) Vercel Labs का एक ओपन-सोर्स कोडिंग एजेंट है। यह नामित कस्टम कनेक्शन के ज़रिए किसी भी OpenAI-संगत Chat Completions एंडपॉइंट को कॉल कर सकता है, इसलिए Phaseo इसके मॉडल गेटवे के रूप में काम करता है। fx macOS और Linux पर चलता है।

## 1) fx कॉन्फ़िगर करें

कनेक्शन जोड़ने, संगत Phaseo मॉडल सिंक करने और Phaseo को fx का सक्रिय प्रदाता बनाने के लिए Phaseo CLI इस्तेमाल करें:

```bash
phaseo login
phaseo fx --model openai/gpt-5.6-terra
```

इंटरैक्टिव टर्मिनल में fx न होने पर Phaseo आधिकारिक इंस्टॉलर कमांड दिखाता है और चलाने से पहले अनुमति माँगता है। इसके बाद कमांड:

- `~/.fx/settings.json` में `phaseo` कनेक्शन जोड़ता है और आपकी दूसरी सेटिंग्स व कनेक्शन सुरक्षित रखता है;
- उनकी कॉन्टेक्स्ट और आउटपुट सीमाओं के साथ अधिकतम 256 संगत Phaseo मॉडल सिंक करता है, जो fx द्वारा स्वीकार की जाने वाली अधिकतम संख्या है;
- `phaseo` को सक्रिय fx प्रदाता बनाता है और पिछला प्रदाता दर्ज करता है ताकि हटाने पर उसे बहाल किया जा सके;
- एक `Phaseo CLI: fx API Key` बनाता है, जो 90 दिनों बाद समाप्त हो जाती है और जिसकी मासिक खर्च सीमा $100 है, और उसे केवल मालिक द्वारा पढ़ी जा सकने वाली फ़ाइल `~/.config/phaseo/integrations/fx.env` में सहेजता है। समाप्त हो चुकी कुंजी बदलने के लिए `phaseo fx` फिर से चलाएँ।

केवल चुने गए मॉडल को कॉन्फ़िगर करने के लिए `--catalog default` इस्तेमाल करें, या फ़ाइल बदलावों का पूर्वावलोकन करने के लिए `--dry-run` इस्तेमाल करें।

## 2) अपने शेल में कुंजी लोड करें

fx कस्टम कनेक्शन की कुंजियाँ केवल एनवायरनमेंट वेरिएबल से पढ़ता है, अपनी सेटिंग्स फ़ाइल से कभी नहीं। यह पंक्ति एक बार `~/.zshrc` या `~/.bashrc` में जोड़ें, फिर नया टर्मिनल खोलें:

```bash
[ -f "$HOME/.config/phaseo/integrations/fx.env" ] && . "$HOME/.config/phaseo/integrations/fx.env"
```

फ़ाइल मौजूद होने पर यह पंक्ति `PHASEO_FX_API_KEY` सेट करती है, और एकीकरण हटाने के बाद कुछ नहीं करती।

## 3) fx शुरू करें

```bash
fx
```

`/model` से मॉडल बदलें, या किसी एक रन के लिए `FX_MODEL=<id> fx` के साथ कोई भी Phaseo मॉडल ID चुनें। `fx provider <name>` से किसी दूसरे प्रदाता पर वापस जाएँ।

## मैन्युअल कॉन्फ़िगरेशन

`~/.fx/settings.json` में कनेक्शन जोड़ें। fx प्रोजेक्ट की `.fx.json` में कस्टम कनेक्शन स्वीकार नहीं करता।

```json
{
  "provider": "phaseo",
  "providers": {
    "phaseo": {
      "protocol": "openai-chat-completions",
      "base_url": "https://api.phaseo.app/v1",
      "auth": { "type": "bearer", "env": "PHASEO_API_KEY" },
      "model_metadata": {
        "openai/gpt-5.6-terra": { "context_window": 400000, "max_output_tokens": 128000 }
      }
    }
  },
  "models": { "phaseo": "openai/gpt-5.6-terra" }
}
```

फिर `PHASEO_API_KEY` एक्सपोर्ट करें और `fx` चलाएँ। `context_window` के बिना fx तय नहीं कर पाता कि बातचीत को कब कॉम्पैक्ट करना है, इसलिए जिन मॉडल का आप उपयोग करते हैं, उनकी सीमाएँ घोषित करें। ऊपर दी गई सीमाएँ केवल उदाहरण हैं; वास्तविक मान [मॉडल एंडपॉइंट](../../api-reference/endpoint/models.mdx) से लें।

## हटाएँ

```bash
phaseo integrations remove fx
```

यह `phaseo` कनेक्शन और मॉडल हटाता है, Phaseo अब भी सक्रिय होने पर आपका पिछला fx प्रदाता बहाल करता है, कुंजी फ़ाइल मिटाता है और कुंजी रद्द कर देता है।

## जाँच

- सक्रिय प्रदाता, एंडपॉइंट और मॉडल की पुष्टि के लिए `fx status --json` चलाएँ।
- फ़ाइल संपादन वाले काम से पहले `fx ask "Summarize README.md"` जैसा एक छोटा प्रॉम्प्ट चलाएँ।
- अगर fx किसी क्रेडेंशियल के न होने की रिपोर्ट करता है, तो नया टर्मिनल खोलें या जाँचें कि शेल प्रोफ़ाइल वाली पंक्ति मौजूद है।
- केवल AI Gateway वाली fx सुविधाएँ, जैसे गेटवे वेब सर्च और क्रेडिट जाँच, कस्टम कनेक्शन के ज़रिए उपलब्ध नहीं हैं।
