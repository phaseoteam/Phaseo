Vercel Labs के ओपन-सोर्स कोडिंग एजेंट [fx](https://fx.sh) में Phaseo को कस्टम कनेक्शन के रूप में जोड़ने के लिए `phaseo fx` चलाएँ, या कनेक्शन ख़ुद `~/.fx/settings.json` में जोड़ें। fx Phaseo के Chat Completions एंडपॉइंट को कॉल करता है और macOS और Linux पर चलता है।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo fx --model openai/gpt-5.6-terra
```

अगर fx इंस्टॉल नहीं है, तो CLI आधिकारिक इंस्टॉलर कमांड दिखाता है और उसे चलाने से पहले पूछता है। इसके बाद सेटअप:

- `~/.fx/settings.json` में एक `phaseo` कनेक्शन जोड़ता है, और आपकी बाकी सेटिंग्स और कनेक्शन बनाए रखता है;
- अधिकतम 256 संगत Phaseo मॉडल, उनकी कॉन्टेक्स्ट और आउटपुट सीमाओं के साथ, सिंक करता है; fx इससे ज़्यादा स्वीकार नहीं करता;
- `phaseo` को सक्रिय fx प्रदाता बनाता है और पिछले प्रदाता को दर्ज करता है ताकि हटाने पर उसे बहाल किया जा सके;
- एक `Phaseo CLI: fx API Key` बनाता है जो 90 दिनों में समाप्त होती है और जिसकी मासिक खर्च सीमा $100 है, और उसे सिर्फ़ मालिक के लिए पढ़ने योग्य फ़ाइल `~/.config/phaseo/integrations/fx.env` में रखता है। समाप्त कुंजी बदलने के लिए `phaseo fx` दोबारा चलाएँ।

सिर्फ़ चुना गया मॉडल जोड़ने के लिए `--catalog default`, या बदलावों का पूर्वावलोकन देखने के लिए `--dry-run` इस्तेमाल करें।

fx कस्टम कनेक्शन की कुंजियाँ सिर्फ़ एनवायरनमेंट वेरिएबल से पढ़ता है, कभी अपनी सेटिंग्स फ़ाइल से नहीं। यह लाइन एक बार `~/.zshrc` या `~/.bashrc` में जोड़ें, फिर नया टर्मिनल खोलें:

```bash
[ -f "$HOME/.config/phaseo/integrations/fx.env" ] && . "$HOME/.config/phaseo/integrations/fx.env"
```

फ़ाइल मौजूद होने पर यह लाइन `PHASEO_FX_API_KEY` सेट करती है, और इंटीग्रेशन हटाने के बाद कुछ नहीं करती। फिर fx शुरू करें:

```bash
fx
```

`/model` से मॉडल बदलें, या एक रन के लिए `FX_MODEL=<id> fx` के साथ कोई भी Phaseo मॉडल ID इस्तेमाल करें। किसी दूसरे प्रदाता पर वापस जाने के लिए `fx provider <name>` इस्तेमाल करें।

## fx को मैन्युअल रूप से कॉन्फ़िगर करें

कनेक्शन `~/.fx/settings.json` में जोड़ें। fx किसी प्रोजेक्ट की `.fx.json` में कस्टम कनेक्शन स्वीकार नहीं करता।

```json ~/.fx/settings.json
{
  "provider": "phaseo",
  "providers": {
    "phaseo": {
      "protocol": "openai-chat-completions",
      "base_url": "https://api.phaseo.app/v1",
      "auth": { "type": "bearer", "env": "PHASEO_API_KEY" },
      "model_metadata": {
        "openai/gpt-5.6-terra": { "context_window": 400000, "max_output_tokens": 128000 }
      }
    }
  },
  "models": { "phaseo": "openai/gpt-5.6-terra" }
}
```

`PHASEO_API_KEY` एक्सपोर्ट करें और `fx` चलाएँ। आप जो भी मॉडल इस्तेमाल करते हैं, हर एक की सीमाएँ घोषित करें: `context_window` के बिना fx यह नहीं बता सकता कि बातचीत को कब कॉम्पैक्ट करना है। ऊपर दी गई सीमाएँ उदाहरण हैं; असली मान [Models एंडपॉइंट](../../api-reference/endpoint/models.mdx) से लें।

## जाँचें कि यह काम करता है

1. सक्रिय प्रदाता, एंडपॉइंट और मॉडल की पुष्टि के लिए `fx status --json` चलाएँ।
2. फ़ाइलें संपादित करने वाले काम से पहले एक छोटा प्रॉम्प्ट चलाएँ, जैसे `fx ask "Summarize README.md"`।
3. पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

अगर fx क्रेडेंशियल गायब होने की सूचना देता है, तो नया टर्मिनल खोलें या जाँचें कि शेल-प्रोफ़ाइल वाली लाइन मौजूद है।

## Phaseo हटाएँ

```bash
phaseo integrations remove fx
```

यह `phaseo` कनेक्शन और मॉडल हटाता है, अगर Phaseo अब भी सक्रिय है तो आपका पिछला fx प्रदाता बहाल करता है, कुंजी फ़ाइल मिटाता है, और कुंजी रद्द करता है।

## ज्ञात सीमाएँ

fx की जो सुविधाएँ सिर्फ़ उसके बिल्ट-इन होस्टेड प्रदाता के साथ काम करती हैं, जैसे उसका वेब सर्च और क्रेडिट जाँच, वे कस्टम कनेक्शन के ज़रिए उपलब्ध नहीं हैं।
