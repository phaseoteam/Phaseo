हर संगत Phaseo मॉडल वाला Phaseo प्रदाता OpenCode में जोड़ने के लिए `phaseo opencode` चलाएँ, या `opencode.json` में ख़ुद एक `phaseo` प्रदाता जोड़ें।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo opencode --model openai/gpt-5.6-terra
```

अगर OpenCode इंस्टॉल नहीं है, तो CLI आधिकारिक इंस्टॉल कमांड दिखाता है और उसे चलाने से पहले पूछता है। इसके बाद सेटअप:

- Chat Completions के साथ काम करने वाले हर सक्रिय Phaseo टेक्स्ट मॉडल के साथ एक ग्लोबल `phaseo` प्रदाता जोड़ता है। अगर आपकी ग्लोबल `opencode.jsonc` है तो यह उसे अपडेट करता है, नहीं तो `~/.config/opencode/opencode.json` को, और आपकी बाकी सेटिंग्स नहीं छूता;
- एक `Phaseo CLI: OpenCode API Key` बनाता है जो 90 दिनों में समाप्त होती है और जिसकी मासिक खर्च सीमा $100 है, और उसे OpenCode के क्रेडेंशियल स्टोर में रखता है। CLI अपनी कॉपी OS क्रेडेंशियल स्टोर में रखता है। समाप्त कुंजी बदलने के लिए `phaseo opencode` दोबारा चलाएँ।

सिर्फ़ चुना गया मॉडल जोड़ने के लिए `--catalog default`, या बदलावों का पूर्वावलोकन देखने के लिए `--dry-run` इस्तेमाल करें।

## OpenCode को मैन्युअल रूप से कॉन्फ़िगर करें

प्रदाता को अपने प्रोजेक्ट की `opencode.json` में, या अपने ग्लोबल OpenCode कॉन्फ़िग में जोड़ें:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-6-astra",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-6-astra": { "name": "GPT-6 Astra" },
        "openai/gpt-5.4-mini": { "name": "GPT-5.4 Mini" },
        "anthropic/claude-sonnet-5.5": { "name": "Claude Sonnet 5.5" }
      }
    }
  }
}
```

`PHASEO_API_KEY` एक्सपोर्ट करें, और OpenCode में कौन से Phaseo मॉडल दिखें यह चुनने के लिए `models` में एंट्री जोड़ें या हटाएँ।

## जाँचें कि यह काम करता है

OpenCode रीस्टार्ट करें, `/models` से एक Phaseo मॉडल चुनें, और फ़ाइलें संपादित करने वाला काम शुरू करने से पहले एक छोटा प्रॉम्प्ट भेजें। पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## Phaseo हटाएँ

```bash
phaseo integrations remove opencode
```

यह सिर्फ़ Phaseo प्रदाता और उसका सेव किया गया क्रेडेंशियल हटाता है, फिर कुंजी रद्द करता है।

## आम समस्याएँ ठीक करें

| समस्या | समाधान |

| ऑथेंटिकेशन विफल होता है | `phaseo opencode` दोबारा चलाएँ और `opencode auth list` जाँचें। |
