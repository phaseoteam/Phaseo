OpenCode कस्टम OpenAI-संगत प्रदाता के ज़रिए Phaseo को कॉल कर सकता है। जब आप चाहते हैं कि OpenCode में मॉडल चयन, उपयोग और रूटिंग एक ही Phaseo API कुंजी से हों, तब यह सेटअप इस्तेमाल करें।

## 1) OpenCode कॉन्फ़िगर करें

OpenCode को उसकी आधिकारिक रिलीज़ से इंस्टॉल करें, फिर Phaseo CLI से एक ग्लोबल प्रदाता जोड़ें, सभी संगत Phaseo मॉडल सिंक करें और OpenCode के क्रेडेंशियल स्टोर में एक समर्पित कुंजी सहेजें:

```bash
phaseo opencode --model openai/gpt-5.6-terra
```

यह कमांड कभी समाप्त न होने वाली `Phaseo CLI: OpenCode API Key` बनाता है, OpenCode की असंबंधित सेटिंग्स और क्रेडेंशियल को सुरक्षित रखता है और `--dry-run` का समर्थन करता है। मौजूदा ग्लोबल `opencode.jsonc` होने पर यह उसे अपडेट करता है; अन्यथा `~/.config/opencode/opencode.json` इस्तेमाल करता है।

केवल चुने गए मॉडल को कॉन्फ़िगर करने के लिए `--catalog default` इस्तेमाल करें।

CLI, OS के क्रेडेंशियल स्टोर में अपनी एक प्रति भी रखता है और `phaseo integrations remove opencode` चलाने पर कुंजी रद्द कर देता है।

## मैन्युअल कॉन्फ़िगरेशन

अपने प्रोजेक्ट में `opencode.json` बनाएँ या अपडेट करें, या OpenCode का ग्लोबल कॉन्फ़िगरेशन अपडेट करें:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-5.5",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-5.5": {
          "name": "GPT-5.5"
        },
        "openai/gpt-5.4-mini": {
          "name": "GPT-5.4 Mini"
        },
        "anthropic/claude-sonnet-4.5": {
          "name": "Claude Sonnet 4.5"
        }
      }
    }
  }
}
```

OpenCode में आप जिन Phaseo मॉडल ID का उपयोग करना चाहते हैं, उनसे मेल कराने के लिए `models` ऑब्जेक्ट में मॉडल जोड़ें या हटाएँ।

## 2) OpenCode शुरू करें

कॉन्फ़िगरेशन बदलने के बाद OpenCode रीस्टार्ट करें, फिर `/models` से Phaseo मॉडल चुनें।

बाद में केवल Phaseo प्रदाता हटाने के लिए यह चलाएँ:

```bash
phaseo integrations remove opencode
```

## जाँच

- फ़ाइल संपादन वाले वर्कफ़्लो इस्तेमाल करने से पहले एक छोटा प्रॉम्प्ट चलाएँ।
- अगर कोई मॉडल अस्वीकार होता है, तो [मॉडल एंडपॉइंट](../../api-reference/endpoint/models.mdx) से सटीक ID की पुष्टि करें।
- अगर प्रमाणीकरण विफल होता है, तो `phaseo opencode` दोबारा चलाएँ और `opencode auth list` जाँचें।
