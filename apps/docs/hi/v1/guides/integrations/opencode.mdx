OpenCode कस्टम OpenAI-संगत provider के ज़रिए Phaseo को call कर सकता है। जब आप OpenCode के model selection, usage और routing को एक Phaseo API key से चलाना चाहें, तो यह सेटअप उपयोग करें।

## 1) OpenCode कॉन्फ़िगर करें

OpenCode को उसके आधिकारिक release से install करें। फिर Phaseo CLI से global provider जोड़ें, सभी संगत Phaseo models sync करें और OpenCode के credential store में dedicated key सहेजें:

```bash
phaseo opencode --model openai/gpt-5.6-terra
```

यह command बिना expiry वाली `Phaseo CLI: OpenCode API Key` बनाता है, OpenCode की असंबंधित settings और credentials को सुरक्षित रखता है और `--dry-run` support करता है। मौजूदा global `opencode.jsonc` हो तो उसे update करता है; अन्यथा `~/.config/opencode/opencode.json` उपयोग करता है।

केवल चुने गए model को configure करने के लिए `--catalog default` उपयोग करें।

CLI OS credential store में अपनी एक copy भी रखता है। `phaseo integrations remove opencode` चलाने पर key revoke हो जाती है।

## मैन्युअल कॉन्फ़िगरेशन

अपने project या OpenCode की global config में `opencode.json` बनाएँ या update करें:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-5.5",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-5.5": {
          "name": "GPT-5.5"
        },
        "openai/gpt-5.4-mini": {
          "name": "GPT-5.4 Mini"
        },
        "anthropic/claude-sonnet-4.5": {
          "name": "Claude Sonnet 4.5"
        }
      }
    }
  }
}
```

OpenCode में जिन Phaseo model IDs का उपयोग करना है, उनसे मेल कराने के लिए `models` object में models जोड़ें या हटाएँ।

## 2) OpenCode शुरू करें

Config edit करने के बाद OpenCode restart करें, फिर `/models` से Phaseo model चुनें।

बाद में केवल Phaseo provider हटाने के लिए यह चलाएँ:

```bash
phaseo integrations remove opencode
```

## जाँच

- File-editing workflows उपयोग करने से पहले एक छोटा prompt चलाएँ।
- Model reject हो तो [Models endpoint](../../api-reference/endpoint/models.mdx) में exact ID जाँचें।
- Authentication विफल हो तो `phaseo opencode` फिर चलाएँ और `opencode auth list` जाँचें।
