Claude Code के अनुरोध Phaseo से भेजने के लिए `phaseo claude-code` चलाएँ, या तीन एनवायरनमेंट वैरिएबल खुद सेट करें। Claude Code Anthropic-शैली का `/v1/messages` कॉल करता है, जिसे Phaseo [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx) के रूप में संभालता है, इसलिए आपके प्रॉम्प्ट नहीं बदलते।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo claude-code
claude
```

अगर Claude Code इंस्टॉल नहीं है, तो CLI आधिकारिक इंस्टॉल कमांड दिखाता है और उसे चलाने से पहले पूछता है। फिर सेटअप:

- एक `Phaseo CLI: Claude Code API Key` बनाता है, जो 90 दिन बाद एक्सपायर होती है और जिसकी $100 मासिक खर्च सीमा है, और उसे OS क्रेडेंशियल स्टोर में रखता है;
- `~/.claude/settings.json` में `ANTHROPIC_BASE_URL` और एक `apiKeyHelper` सेट करता है। हेल्पर CLI से कुंजी लाता है और पुरानी कुंजी एक्सपायर होने पर नई बनाता है, इसलिए Claude Code सेटिंग में कोई सादी कुंजी नहीं लिखी जाती।

अगर `settings.json` में पहले से कोई अलग `ANTHROPIC_BASE_URL`, कोई अलग `apiKeyHelper`, या खाली न होने वाली `ANTHROPIC_API_KEY` या `ANTHROPIC_AUTH_TOKEN` है, तो सेटअप बिना कुछ बदले रुक जाता है। Claude Code के लिए `--model` सपोर्ट नहीं है; इसके बजाय `ANTHROPIC_MODEL` सेट करें (नीचे देखें)।

## Claude Code को हाथ से कॉन्फ़िगर करें

इन्हें उस शेल में सेट करें जहाँ से आप Claude Code शुरू करते हैं:

<CodeGroup>

```bash bash
export ANTHROPIC_BASE_URL="https://api.phaseo.app"
export ANTHROPIC_AUTH_TOKEN="your_phaseo_api_key"
export ANTHROPIC_API_KEY=""
```

```powershell PowerShell
$env:ANTHROPIC_BASE_URL = "https://api.phaseo.app"
$env:ANTHROPIC_AUTH_TOKEN = "your_phaseo_api_key"
$env:ANTHROPIC_API_KEY = ""
```

</CodeGroup>

Claude Code `ANTHROPIC_AUTH_TOKEN` को `Authorization` हेडर के रूप में भेजता है, जिसे Phaseo स्वीकार करता है। कोई डिफ़ॉल्ट मॉडल तय करने के लिए, `ANTHROPIC_MODEL` को [Models](../../api-reference/endpoint/models.mdx) के किसी Phaseo मॉडल ID पर सेट करें।

## जाँचें कि यह काम करता है

`claude` चलाएँ, एक छोटा प्रॉम्प्ट भेजें, और पक्का करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## Phaseo हटाएँ

```bash
phaseo integrations remove claude-code
```

यह `settings.json` से वह बेस URL, कुंजी हेल्पर और खाली क्रेडेंशियल वैरिएबल हटाता है जो Phaseo ने जोड़े थे, फिर कुंजी रद्द करता है। हाथ से किए गए सेटअप के लिए, तीनों एनवायरनमेंट वैरिएबल unset करें।

## ज्ञात सीमाएँ

- किसी टीम को इस पर ले जाने से पहले, अपने वर्कफ़्लो के साथ स्ट्रीम किए गए टूल लूप टेस्ट करें।
- अगर आप चाहते हैं कि Claude Code किसी सत्र के दौरान Phaseo दस्तावेज़ पढ़े, तो [Docs MCP](./docs-mcp.mdx) सर्वर जोड़ें।
