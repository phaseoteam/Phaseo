`@phaseo/ai-sdk-provider` इंस्टॉल करें और किसी भी AI SDK कॉल में मॉडल के रूप में `phaseo("<model id>")` पास करें। प्रदाता एनवायरनमेंट से `PHASEO_API_KEY` पढ़ता है।

## इंस्टॉल करें

```bash
npm install @phaseo/ai-sdk-provider
```

बिना वर्ज़न वाला पैकेज npm के `latest` टैग का पालन करता है, जो AI SDK 7 वाली लाइन है, और `ai@^7` को peer dependency के रूप में घोषित करता है, जिसे npm आपके लिए इंस्टॉल कर देता है। पुराने AI SDK के लिए, मेल खाने वाला टैग इंस्टॉल करें:

| AI SDK | प्रदाता कॉन्ट्रैक्ट | इंस्टॉल |
| --- | --- | --- |
| 7 (मौजूदा) | `ProviderV4` (प्रदाता 2.x) | `npm install @phaseo/ai-sdk-provider` |
| 6 | `ProviderV3` (प्रदाता 1.x, रखरखाव) | `npm install @phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `ProviderV2` | `npm install @phaseo/ai-sdk-provider@ai-sdk-v5` |

अगर आपका पैकेज मैनेजर peer dependencies इंस्टॉल नहीं करता, तो मेल खाने वाला `ai` मेजर वर्ज़न (`ai@^7`, `ai@^6` या `ai@^5`) भी इंस्टॉल करें।

जब AI SDK 8 स्थिर हो जाएगा, तो Phaseo npm पर प्रदाता 1.x को deprecated चिह्नित करेगा। मौजूदा रिलीज़ नहीं हटाई जाएँगी, और सपोर्ट खत्म होने की कोई भी घोषणा अलग से की जाएगी।

## टेक्स्ट जनरेट करें

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Summarize this in one sentence.",
});

console.log(result.text);
```

यही कोड तीनों लाइनों पर काम करता है। [Models एंडपॉइंट](../../api-reference/endpoint/models.mdx) के मॉडल ID इस्तेमाल करें; हर क्षमता फिर भी मॉडल और अपस्ट्रीम प्रदाता पर निर्भर करती है।

## हर लाइन क्या सपोर्ट करती है

| सुविधा | AI SDK 7 (प्रदाता 2.x) | AI SDK 5 |
| --- | --- | --- |
| टेक्स्ट जनरेशन और स्ट्रीमिंग | हाँ | हाँ |
| फ़ंक्शन टूल और टूल-नतीजे के राउंड ट्रिप | हाँ, स्ट्रीम किए गए टूल इनपुट समेत | हाँ |
| JSON और JSON Schema संरचित आउटपुट | हाँ | हाँ |
| एम्बेडिंग और इमेज जनरेशन | हाँ | हाँ |
| ट्रांसक्रिप्शन और स्पीच | हाँ | हाँ |
| रीरैंकिंग | हाँ | नहीं |
| प्रदाता से स्वतंत्र रीज़निंग सेटिंग और आउटपुट | हाँ | |
| टेक्स्ट और इमेज फ़ाइल इनपुट (V7 टैग किया गया फ़ाइल डेटा) | हाँ | |
| URL उद्धरण स्रोत | हाँ | |
| प्रदाता मेटाडेटा, उपयोग, अनुरोध हेडर, abort सिग्नल, कच्चे स्ट्रीम चंक | हाँ | |

AI SDK 7 वाला कॉलम वह है जो प्रदाता 2.x लागू करता है और AI SDK 7 के नेटिव v4 कॉन्ट्रैक्ट के ख़िलाफ़ टेस्ट करता है। रीरैंकिंग AI SDK 6 वाली लाइन पर भी उपलब्ध है।

## दस्तावेज़ रीरैंक करें

`phaseo.rerankingModel(modelId)` के साथ AI SDK का `rerank()` हेल्पर इस्तेमाल करें:

```ts
import { rerank } from "ai";
import { phaseo } from "@phaseo/ai-sdk-provider";

const result = await rerank({
	model: phaseo.rerankingModel("voyage/rerank-2"),
	query: "Which document is about TypeScript?",
	documents: [
		"TypeScript adds static types to JavaScript.",
		"Rust is a systems programming language.",
	],
	topN: 1,
});
```

## ज्ञात सीमाएँ

- प्रदाता `ProviderV4` की वे सुविधाएँ नहीं बताता जिनके लिए ऐसे Phaseo API चाहिए जो अभी मौजूद नहीं हैं: प्रबंधित फ़ाइल अपलोड और रेफ़रेंस, स्किल, और प्रदाता द्वारा चलाए जाने वाले टूल की परिभाषाएँ, नतीजे या मंज़ूरी प्रतिक्रियाएँ।
- जो फ़ंक्शन टूल आपका ऐप चलाता है, वे अब भी AI SDK का सामान्य निष्पादन और मंज़ूरी फ़्लो इस्तेमाल करते हैं।
- प्रदाता-विशिष्ट या कस्टम प्रॉम्प्ट हिस्से जो सपोर्ट नहीं होते, चुपचाप हटाए जाने के बजाय साफ़ एरर के साथ विफल होते हैं।
