Zed की `settings.json` में Phaseo प्रदाता जोड़ने के लिए `phaseo zed` चलाएँ, फिर कुंजी Zed में पेस्ट करें, जो प्रदाता कुंजियाँ सिस्टम कीचेन में रखता है। CLI छोड़ना हो तो प्रदाता ख़ुद Zed की सेटिंग्स में जोड़ें।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo zed --model openai/gpt-5.6-terra
```

CLI एक `Phaseo CLI: Zed API Key` (90 दिन में समाप्ति, $100 मासिक खर्च सीमा) बनाता है और Zed की `settings.json` में `phaseo` नाम का एक `openai_compatible` प्रदाता जोड़ता है, जिसका API URL `https://api.phaseo.app/v1` है और जिसमें चुना गया मॉडल होता है। असंबंधित सेटिंग्स नहीं छुई जातीं। `--model` के बिना यह `anthropic/claude-sonnet-4.6` इस्तेमाल करता है। अगर Zed में पहले से `phaseo` नाम का प्रदाता है, तो सेटअप रुक जाता है।

## Zed में कुंजी जोड़ें

1. कमांड पैलेट खोलें और **agent: open settings** चलाएँ।
2. **AI** के अंदर **LLM Providers → Configure** चुनें।

![LLM Providers हाइलाइट की हुई Zed AI सेटिंग्स](/images/integrations/zed-agent-settings.png)

3. अगर Phaseo दिखता है, तो उसे खोलें और `phaseo integrations credential zed` का आउटपुट पेस्ट करें।

CLI के बिना प्रदाता जोड़ने के लिए, इसकी जगह **Add Provider → OpenAI** चुनें और नीचे दिए गए मान दर्ज करें।

![Add Provider वाला Zed LLM Providers पेज](/images/integrations/zed-llm-providers.png)

| फ़ील्ड | मान |
| --- | --- |
| Provider Name | `Phaseo` |
| API URL | `https://api.phaseo.app/v1` |
| API Key | `phaseo integrations credential zed` का आउटपुट, या कोई भी Phaseo API कुंजी |
| Model Name | एक Phaseo मॉडल ID |

![OpenAI-संगत प्रदाता जोड़ने का Zed फ़ॉर्म](/images/integrations/zed-add-compatible-provider.png)

**Save Provider** चुनने से पहले API URL, मॉडल और कुंजी भरें।

## जाँचें कि यह काम करता है

एक नया Agent थ्रेड खोलें, Phaseo मॉडल चुनें, और एक छोटा अनुरोध भेजें। पुष्टि करें कि वह **सेटिंग्स → उपयोग → लॉग्स** में दिखता है। अगर Zed अमान्य कुंजी की सूचना देता है, तो `phaseo integrations credential zed` दोबारा चलाएँ और Zed में कुंजी बदलें।

## Phaseo हटाएँ

```bash
phaseo integrations remove zed
```

यह `settings.json` से Phaseo प्रदाता हटाता है और कुंजी रद्द करता है। अगर Zed अब भी पुरानी कीचेन एंट्री दिखाता है, तो **LLM Providers** से भी Phaseo हटाएँ।
