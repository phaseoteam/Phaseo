Phaseo CLI से प्रदाता और मॉडल Zed में जोड़ें, फिर कुंजी Zed के कीचेन में सहेजें। CLI इस्तेमाल न करना चाहें, तो वही प्रदाता मान हाथ से भरें।

## Phaseo CLI से सेटअप करें

```bash
phaseo login
phaseo zed --model openai/gpt-5.6-terra
```

CLI असंबंधित सेटिंग बदले बिना प्रदाता ID `phaseo`, API URL `https://api.phaseo.app/v1` और चुने गए मॉडल को Zed के `settings.json` में जोड़ता है।

## Zed में सेटअप पूरा करें

Zed प्रदाता कुंजियाँ सिस्टम कीचेन में रखता है, इसलिए UI में बस यही एक चरण बचता है।

1. कमांड पैलेट खोलें और **agent: open settings** चलाएँ।
2. **AI** के अंतर्गत **LLM Providers → Configure** चुनें।

![Zed की AI सेटिंग्स, जिनमें LLM Providers हाइलाइट है](/images/integrations/zed-agent-settings.png)

3. अगर Phaseo पहले से दिख रहा हो, तो उसे खोलें और उसकी समर्पित कुंजी पेस्ट करें। नहीं तो **Add Provider → OpenAI** चुनें।

![Add Provider के साथ Zed का LLM Providers पेज](/images/integrations/zed-llm-providers.png)

4. अगर हाथ से सेटअप करना हो, तो ये मान दर्ज करें:

| फ़ील्ड | मान |
| --- | --- |
| Provider Name | `Phaseo` |
| API URL | `https://api.phaseo.app/v1` |
| API Key | `phaseo integrations credential zed` का आउटपुट |
| Model Name | चुने गए Phaseo मॉडल का ID |

![OpenAI-संगत प्रदाता जोड़ने के लिए Zed का फ़ॉर्म](/images/integrations/zed-add-compatible-provider.png)

बेस URL, मॉडल ID और कुंजी पूरी तरह भरने से पहले **Save Provider** न चुनें।

## पुष्टि करें

नया Agent थ्रेड खोलें, Phaseo मॉडल चुनें और एक छोटा अनुरोध भेजें। अगर Zed अमान्य कुंजी की त्रुटि दिखाए, तो `phaseo integrations credential zed` दोबारा चलाएँ और Zed में सहेजी गई कुंजी बदलें।

## हटाएँ

```bash
phaseo integrations remove zed
```

CLI `settings.json` से Phaseo प्रदाता हटाता है और उसकी समर्पित कुंजी रद्द करता है। अगर Zed में अब भी पुरानी कीचेन एंट्री दिखे, तो **LLM Providers** से भी Phaseo हटाएँ।
