[Phaseo AI SDK प्रदाता](./ai-sdk.mdx) से एक मॉडल अपने [eve](https://eve.dev) एजेंट को दें, और हर मॉडल कॉल आपकी रूटिंग, कुंजियों, बजट और लॉग के साथ Phaseo से होकर जाती है। eve कोई भी AI SDK लैंग्वेज मॉडल स्वीकार करता है।

## इंस्टॉल करें

eve AI SDK 7 इस्तेमाल करता है, इसलिए `@phaseo/ai-sdk-provider` 2.0.1 या बाद का वर्ज़न इंस्टॉल करें:

```bash
npm install @phaseo/ai-sdk-provider
```

`eve dev` के लिए `.env.local` में, और हर डिप्लॉयमेंट के सर्वर एनवायरनमेंट में `PHASEO_API_KEY` सेट करें। eve का `/login` कनेक्शन सिर्फ़ आपकी मशीन पर काम करता है।

## eve एजेंट को Phaseo पर ले जाएँ

```ts agent/agent.ts
import { defineAgent } from "eve";
import { phaseo } from "@phaseo/ai-sdk-provider";

export default defineAgent({
	model: phaseo("openai/gpt-6-astra"),
	modelContextWindowTokens: 922_000,
	reasoning: "low",
});
```

`phaseo("openai/gpt-6-astra")` जैसा मॉडल ऑब्जेक्ट दें; सादा मॉडल ID स्ट्रिंग Phaseo को नहीं भेजी जाती। `modelContextWindowTokens` को [Models एंडपॉइंट](../../api-reference/endpoint/models.mdx) से मिले मॉडल के `limits.input_tokens` पर सेट करें। eve किसी मॉडल ऑब्जेक्ट की कॉन्टेक्स्ट विंडो ख़ुद नहीं देख सकता, और यह संख्या इस्तेमाल करके तय करता है कि बातचीत को कब कॉम्पैक्ट करना है।

एजेंट को एक बार चलाएँ और पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## हर टर्न के लिए मॉडल चुनें

`defineDynamic` हर मॉडल कॉल से पहले चलता है। एक सिलेक्शन ऑब्जेक्ट लौटाएँ ताकि हर मॉडल अपनी कॉन्टेक्स्ट विंडो बनाए रखे:

```ts agent/agent.ts
import { defineAgent } from "eve";
import { defineDynamic } from "eve/models";
import { phaseo } from "@phaseo/ai-sdk-provider";

export default defineAgent({
	model: defineDynamic((ctx) =>
		ctx.session.auth.initiator?.attributes.plan === "enterprise"
			? { model: phaseo("openai/gpt-6-sol"), modelContextWindowTokens: 1_050_000 }
			: { model: phaseo("openai/gpt-6-luna"), modelContextWindowTokens: 1_050_000 },
	),
});
```

## ज्ञात सीमाएँ

- टूल, स्ट्रीमिंग, रीज़निंग, कॉम्पैक्शन और प्रॉम्प्ट कैशिंग Phaseo के ज़रिए काम करते हैं। प्रॉम्प्ट कैश रीड eve के उपयोग इवेंट और Phaseo लॉग में दिखते हैं।
- मॉडल ऑब्जेक्ट के लिए eve हर रन की लागत ख़ाली छोड़ देता है। लागत Phaseo के **उपयोग** पेज या **लॉग्स** में देखें।
