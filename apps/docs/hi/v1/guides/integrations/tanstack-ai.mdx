यदि आपको React, Solid, Preact, Vue, Svelte या सर्वर-साइड TypeScript में प्रकार-सुरक्षित चैट प्रवाह चाहिए, तो TanStack AI का उपयोग करें।

## इंस्टॉल करें

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## अडैप्टर कॉन्फ़िगर करें

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-5-nano", "anthropic/claude-sonnet-4.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-5-nano"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## नोट्स

- जिन Phaseo मॉडल ID का आप उपयोग करना चाहते हैं, उन्हें `models` ऐरे में घोषित करें।
- OpenAI-संगत अडैप्टर डिफ़ॉल्ट रूप से Chat Completions का उपयोग करता है। केवल Responses API में उपलब्ध सुविधाओं के लिए सीधे API कॉल करें।
- अगर आपके वर्कफ़्लो में कोई मॉडल टूल या इमेज का समर्थन नहीं करता, तो TanStack AI में सीमित क्षमताएँ घोषित करें ताकि TypeScript असमर्थित कॉल पहले ही पकड़ सके।
