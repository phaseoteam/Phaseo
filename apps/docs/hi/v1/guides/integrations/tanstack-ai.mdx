अपनी Phaseo कुंजी, `baseURL: "https://api.phaseo.app/v1"` और जिन Phaseo मॉडल ID का आप इस्तेमाल करते हैं, उनके साथ TanStack AI का `openaiCompatible` एडैप्टर बनाएँ। यह React, Solid, Preact, Vue, Svelte या सर्वर-साइड TypeScript में टाइप-सुरक्षित चैट के लिए काम करता है।

## इंस्टॉल करें

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## एडैप्टर को Phaseo पर ले जाएँ

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-6-astra", "anthropic/claude-sonnet-5.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-6-astra"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

जिस भी Phaseo मॉडल ID का इस्तेमाल करने की आपकी योजना है, उसे `models` में घोषित करें। ID [मॉडल](../../api-reference/endpoint/models.mdx) में जाँचें।

## ज्ञात सीमाएँ

- एडैप्टर Chat Completions इस्तेमाल करता है। सिर्फ़-Responses सुविधाओं के लिए Phaseo को सीधे कॉल करें या [OpenAI SDK](./openai-sdk.mdx) इस्तेमाल करें।
- अगर कोई मॉडल [टूल](../tool-calling.mdx) या इमेज सपोर्ट नहीं करता, तो TanStack AI में सीमित क्षमताएँ घोषित करें ताकि TypeScript असमर्थित कॉल पकड़ ले।
