अगर आप पहले से LiteLLM के प्रॉक्सी, बजट या लोकल राउटर पर निर्भर हैं, लेकिन उसके पीछे Phaseo की मॉडल कवरेज, एनालिटिक्स और सर्वर टूल चाहते हैं, तो LiteLLM इस्तेमाल करें।

## Python से सीधे कॉल करें

```bash
pip install litellm
```

```python
import os
from litellm import completion

response = completion(
    model="openai/openai/gpt-5-nano",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(response.choices[0].message.content)
```

OpenAI-संगत एंडपॉइंट के लिए LiteLLM आम तौर पर `openai/` प्रदाता प्रीफ़िक्स इस्तेमाल करता है। Phaseo मॉडल ID `openai/gpt-5-nano` ही रहता है, इसलिए LiteLLM मॉडल स्ट्रिंग `openai/openai/gpt-5-nano` जैसी दिख सकती है।

## प्रॉक्सी कॉन्फ़िगरेशन

अगर आप नहीं चाहते कि ऐप्लिकेशन कोड में LiteLLM प्रदाता प्रीफ़िक्स शामिल हो, तो मॉडल उपनाम इस्तेमाल करें:

```yaml
model_list:
  - model_name: phaseo-gpt-5-nano
    litellm_params:
      model: openai/openai/gpt-5-nano
      api_key: os.environ/PHASEO_API_KEY
      api_base: https://api.phaseo.app/v1
```

फिर LiteLLM प्रॉक्सी को `model: "phaseo-gpt-5-nano"` के साथ कॉल करें।

## नोट

- प्रोडक्शन में मॉडल के नाम पढ़ने में आसान रहें, इसके लिए LiteLLM उपनामों को प्राथमिकता दें।
- अगर आप Phaseo सर्वर टूल इस्तेमाल करते हैं, तो LiteLLM का सटीक रूट जाँचें, क्योंकि कुछ प्रॉक्सी परतें अज्ञात टूल टाइप को नॉर्मलाइज़ कर देती हैं या हटा देती हैं।
- मूल्य निर्धारण के लिए तय करें कि आपके रिकॉर्ड का आधिकारिक स्रोत LiteLLM होगा, Phaseo होगा या दोनों।
