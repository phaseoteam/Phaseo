Phaseo के ज़रिए Muse Code सत्र शुरू करने के लिए `phaseo muse` चलाएँ। Muse Code के साथ Phaseo इस्तेमाल करने का यही एकमात्र समर्थित तरीका है।

## Phaseo CLI के ज़रिए Muse Code चलाएँ

```bash
phaseo login
phaseo muse --model meta/muse-spark-1.3
```

रनर एक समर्पित कुंजी बनाता है, Muse सेटिंग्स एक अस्थायी `XDG_CONFIG_HOME` के अंदर लिखता है, `muse` लॉन्च करता है, और Muse Code बंद होने पर सेटिंग्स मिटा देता है। Muse Code के अपने फ़्लैग `--` के बाद लिखें।

| फ़्लैग | असर |
| --- | --- |
| `--model <id>` | इस्तेमाल होने वाला मॉडल। डिफ़ॉल्ट `openai/gpt-5.6-terra` है। |
| `--catalog all` | सिर्फ़ चुने गए मॉडल की जगह हर सक्रिय Phaseo टेक्स्ट मॉडल दिखाता है। |
| `--dry-run --json` | कुंजी बनाए या Muse Code शुरू किए बिना लॉन्च की योजना दिखाता है। |
| `--skip-install` | इंस्टॉल जाँच छोड़ देता है। |

`phaseo run muse ...` इसी कमांड का लंबा रूप है।

macOS और Linux पर पहला इंटरैक्टिव रन Meta के इंस्टॉलर से Muse Code इंस्टॉल करने का विकल्प देता है। Windows पर Muse Code ख़ुद इंस्टॉल करें, `muse --version` जाँचें, और `--skip-install` इस्तेमाल करें।

## मैन्युअल सेटअप क्यों नहीं है

Muse Code, Meta के अपने [Model API](https://ai.meta.com/llama) और साइन-इन के इर्द-गिर्द बना है। Meta इसे किसी दूसरे OpenAI-संगत एंडपॉइंट पर ले जाने के लिए कोई स्थिर सेटिंग दस्तावेज़ित नहीं करता, इसलिए रनर इस्तेमाल करें। रनर की अस्थायी सेटिंग्स अपनी सामान्य Muse प्रोफ़ाइल में कॉपी न करें; वे एक आंतरिक विवरण हैं और रनर बंद होने पर मिट जाती हैं।

अपने कोड से Phaseo मॉडल कॉल करने के लिए, `https://api.phaseo.app/v1` और एक Phaseo API कुंजी के साथ [OpenAI SDK](./openai-sdk.mdx) इस्तेमाल करें।

## जाँचें कि यह काम करता है

एक छोटा प्रॉम्प्ट भेजें और पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## आम समस्याएँ ठीक करें

### Muse Code इंस्टॉल नहीं है

Muse Code ख़ुद इंस्टॉल करें, `muse --version` जाँचें, और `--skip-install` के साथ दोबारा चलाएँ।

### मॉडल सूची में नहीं है

`--catalog all` इस्तेमाल करें, या `--model` के साथ मॉडल ID दें। Phaseo को मॉडल डिस्कवरी की ज़रूरत नहीं है।
