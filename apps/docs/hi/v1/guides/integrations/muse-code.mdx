Phaseo CLI एक समर्पित गेटवे कुंजी और अस्थायी प्रदाता सेटिंग्स से Muse Code शुरू कर सकता है।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo muse --model meta/muse-spark-1.3 --
```

सभी सक्रिय Phaseo टेक्स्ट/चैट मॉडल उपलब्ध कराने के लिए `--catalog all` इस्तेमाल करें, या कुंजी बनाए या Muse Code शुरू किए बिना लॉन्च योजना देखने के लिए `--dry-run --json` इस्तेमाल करें:

```bash
phaseo muse --catalog all --dry-run --json
```

स्पष्ट कमांड रूप के लिए `phaseo run muse ...` इस्तेमाल करें। Muse Code के फ़्लैग `--` के बाद रखें, ताकि Phaseo पहले अपने फ़्लैग पढ़ सके।

Unix जैसे सिस्टम पर पहली इंटरैक्टिव रन Meta के इंस्टॉलर से Muse Code इंस्टॉल करने का विकल्प देती है। Windows पर Muse Code अलग से इंस्टॉल करें, `muse --version` जाँचें और `--skip-install` इस्तेमाल करें।

## मैन्युअल कॉन्फ़िगरेशन

Muse Code का सार्वजनिक सेटअप Meta की अपनी Model API और प्रमाणीकरण प्रक्रिया पर आधारित है। Meta फिलहाल इस एंडपॉइंट को किसी तृतीय-पक्ष OpenAI-संगत गेटवे से बदलने के लिए स्थिर, स्थायी सेटिंग का दस्तावेज़ नहीं देता। इसलिए Muse Code को Phaseo से रूट करने का समर्थित तरीका Phaseo CLI रनर है।

किसी दूसरे क्लाइंट से Phaseo मॉडल मैन्युअल रूप से इस्तेमाल करने के लिए `https://api.phaseo.app/v1` और Phaseo API कुंजी के साथ [OpenAI-संगत एकीकरण](./openai-sdk) इस्तेमाल करें। रनर की अस्थायी Muse सेटिंग्स को अपने सामान्य Muse प्रोफ़ाइल में कॉपी न करें; ये फ़ाइलें कार्यान्वयन का हिस्सा हैं और रनर बंद होने पर हटा दी जाती हैं।

## सत्यापित करें

शुरू किए गए वातावरण से छोटा प्रॉम्प्ट भेजें और पुष्टि करें कि अनुरोध Phaseo गतिविधि में दिखाई देता है। रनर अस्थायी `XDG_CONFIG_HOME` में `settings.json` लिखता है और Muse Code बंद होने पर उसे हटा देता है।

## समस्या निवारण

### Muse Code इंस्टॉल नहीं है

Muse Code अलग से इंस्टॉल करें, `muse --version` जाँचें और `--skip-install` के साथ फिर चलाएँ।

### मॉडल सूची में नहीं है

`--catalog all` इस्तेमाल करें या `--model` से मॉडल आईडी दें। Phaseo गेटवे के लिए मॉडल खोज आवश्यक नहीं है।
