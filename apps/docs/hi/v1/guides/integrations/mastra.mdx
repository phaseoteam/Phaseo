अपनी Phaseo कुंजी और `baseURL: "https://api.phaseo.app/v1"` के साथ एक AI SDK OpenAI प्रदाता बनाएँ, और उसके मॉडल Mastra एजेंट और वर्कफ़्लो को दें।

## इंस्टॉल करें

```bash
npm install @mastra/core @ai-sdk/openai ai
```

## Mastra एजेंट को Phaseo पर ले जाएँ

```ts
import { Agent } from "@mastra/core/agent";
import { createOpenAI } from "@ai-sdk/openai";

const phaseo = createOpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
	compatibility: "compatible",
});

export const agent = new Agent({
	name: "support-agent",
	instructions: "Answer in two short paragraphs.",
	model: phaseo("openai/gpt-6-astra"),
});
```

सिर्फ़ base URL इस्तेमाल करें, `/chat/completions` या `/responses` के बिना। एजेंट को एक छोटे प्रॉम्प्ट के साथ एक बार चलाएँ और पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## ज्ञात सीमाएँ

- Mastra एजेंट कैसे व्यवहार करते हैं, यह AI SDK प्रदाता पर निर्भर है। प्रोडक्शन से पहले [टूल कॉलिंग](../tool-calling.mdx) और स्ट्रीमिंग की जाँच करें।
- कुछ ख़ास प्रदाताओं को प्राथमिकता देने के लिए, अनुरोध पर या किसी [प्रीसेट](../presets.mdx) में Phaseo रूटिंग कंट्रोल सेट करें।
