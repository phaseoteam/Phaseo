Phaseo API कुंजियों को बिना डाउनटाइम के रोटेट करें: [प्रबंधन कुंजी](../../developers/management-api-keys.mdx) से एक नई कुंजी बनाएँ, अपने ऐप को उस पर स्विच करें, फिर पुरानी कुंजी मिटा दें। यह पेज वे मान देता है जो Infisical कनेक्शन इस रोटेशन के लिए इस्तेमाल करता है।

<Warning>
Phaseo अभी Infisical में चुनने योग्य App Connection नहीं है। कनेक्टर, टेस्ट और UI एंट्री को अभी Infisical में स्वीकार किया जाना बाकी है। तब तक, नीचे दिए गए अनुरोध अपने ख़ुद के रोटेशन जॉब से इस्तेमाल करें।
</Warning>

## रोटेशन कैसे काम करता है

```mermaid
flowchart LR
  mk["प्रबंधन कुंजी"] -->|"POST /v1/keys"| newkey["नई API कुंजी"]
  newkey -->|"सीक्रेट में सेव करें"| app["ऐप नई कुंजी इस्तेमाल करता है"]
  app -->|"DELETE /v1/keys/{id}"| old["पुरानी कुंजी रद्द"]
```

Phaseo किसी API कुंजी का मान सिर्फ़ एक बार दिखाता है, जब वह बनाई जाती है। पुरानी और नई दोनों कुंजियाँ तब तक काम करती हैं जब तक आप पुरानी को मिटा नहीं देते, इसलिए सीक्रेट अपडेट होने के दौरान आपका ऐप स्विच कर सकता है।

## सीमित दायरे वाली प्रबंधन कुंजी बनाएँ

**सेटिंग्स → प्रबंधन कुंजियाँ** में इन क्षमताओं वाली कुंजी बनाएँ:

| क्षमता | किसलिए |
| --- | --- |
| `keys:read` | कनेक्शन जाँचने और प्रबंधित कुंजियों की सूची देखने के लिए। |
| `keys:write` | नई कुंजियाँ बनाने के लिए। |
| `keys:delete` | पुरानी कुंजियाँ रद्द करने के लिए। |

`phaseo_v1_mk_...` मान Infisical में सेव करें। प्रबंधन कुंजियाँ आपके खाते को नियंत्रित करती हैं और इनफ़रेंस के लिए इस्तेमाल नहीं हो सकतीं।

## कनेक्शन विवरण

| फ़ील्ड | मान |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| ऑथेंटिकेशन | `Authorization: Bearer <PHASEO_MANAGEMENT_KEY>` |
| कनेक्शन जाँचें | `GET /keys` |
| API कुंजियों की सूची | `GET /keys` |
| API कुंजी बनाएँ | [`POST /keys`](../../api-reference/endpoint/keys-create.mdx) |
| API कुंजी रद्द करें | [`DELETE /keys/{id}`](../../api-reference/endpoint/keys-delete.mdx) |

## नई कुंजी बनाएँ

```bash
curl https://api.phaseo.app/v1/keys \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "infisical-production",
    "limit": 100,
    "limit_reset": "monthly",
    "include_byok_in_limit": false
  }'
```

प्रतिक्रिया में नई कुंजी एक बार `data.key` में, और उसकी ID `data.id` में होती है।

| फ़ील्ड | मान |
| --- | --- |
| `limit` | US डॉलर में खर्च सीमा। |
| `limit_reset` | `daily`, `weekly` या `monthly`। |
| `include_byok_in_limit` | सिर्फ़ संगतता के लिए स्वीकार किया जाता है। BYOK उपयोग इस सीमा में कभी नहीं गिना जाता। |

## पुरानी कुंजी रद्द करें

```bash
curl -X DELETE https://api.phaseo.app/v1/keys/$PREVIOUS_KEY_ID \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY"
```

मिटाने को दोहराना सुरक्षित है: पहले से मिटाई गई कुंजी को मिटाने पर `{"deleted": true}` के साथ `200` मिलता है, इसलिए दोबारा चलाया गया रोटेशन सुरक्षित है।
