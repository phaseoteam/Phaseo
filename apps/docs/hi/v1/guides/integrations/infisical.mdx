Infisical सीमित दायरे वाली Phaseo प्रबंधन API कुंजी से प्रमाणीकरण करके Phaseo Gateway API कुंजियाँ रोटेट कर सकता है। Phaseo दो-चरण, बिना डाउनटाइम वाले रोटेशन के लिए ज़रूरी कुंजी जीवनचक्र पहले से उपलब्ध कराता है।

<Warning>
Infisical में Phaseo अभी चुनने योग्य App Connection नहीं है। यह पेज समर्थित Phaseo अनुबंध और वह कॉन्फ़िगरेशन बताता है जिसका इस्तेमाल Infisical कनेक्शन उपलब्ध होने पर करना है।
</Warning>

## कुंजी बदलने की प्रक्रिया कैसे काम करती है

1. Infisical, प्रबंधन API कुंजी से Phaseo में प्रमाणीकरण करता है।
2. Infisical `POST /v1/keys` से एक प्रतिस्थापन Gateway API कुंजी बनाता है।
3. Infisical लौटाई गई सादा टेक्स्ट कुंजी को कॉन्फ़िगर किए गए सीक्रेट में सहेजता है।
4. ऐप्लिकेशन प्रतिस्थापन कुंजी का इस्तेमाल शुरू करता है।
5. Infisical `DELETE /v1/keys/{id}` से पिछली कुंजी रद्द करता है।

Phaseo किसी Gateway API कुंजी का सादा टेक्स्ट मान केवल उसे बनाते समय लौटाता है। सीक्रेट अपडेट होने के दौरान पुरानी और प्रतिस्थापन कुंजियाँ कुछ समय तक साथ-साथ मान्य रह सकती हैं।

## सीमित दायरे वाली प्रबंधन API कुंजी बनाएँ

**डैशबोर्ड → सेटिंग्स → प्रबंधन कुंजियाँ** में इन क्षमताओं वाली कुंजी बनाएँ:

- कनेक्शन सत्यापित करने और प्रबंधित कुंजियाँ देखने के लिए `keys:read`
- प्रतिस्थापन कुंजियाँ बनाने के लिए `keys:write`
- पिछली कुंजियाँ रद्द करने के लिए `keys:delete`

बनने वाले `phaseo_v1_mk_...` सीक्रेट को Infisical में सहेजें। प्रबंधन API कुंजियाँ कंट्रोल-प्लेन क्रेडेंशियल हैं और इनका इस्तेमाल इन्फ़रेंस के लिए नहीं किया जा सकता।

## कनेक्शन विवरण

| फ़ील्ड | मान |
| --- | --- |
| बेस URL | `https://api.phaseo.app/v1` |
| प्रमाणीकरण | `Authorization: Bearer <PHASEO_MANAGEMENT_KEY>` |
| सत्यापन | `GET /keys` |
| Gateway कुंजियों की सूची | `GET /keys` |
| Gateway कुंजी बनाएँ | `POST /keys` |
| Gateway कुंजी रद्द करें | `DELETE /keys/{id}` |

## रोटेशन के लिए नई कुंजी बनाएँ

```bash
curl https://api.phaseo.app/v1/keys \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "infisical-production",
    "limit": 100,
    "limit_reset": "monthly",
    "include_byok_in_limit": false
  }'
```

प्रतिक्रिया में नई Gateway कुंजी केवल एक बार `data.key` में मिलती है, साथ ही उसका स्थायी पहचानकर्ता `data.id` में होता है।

## पिछली कुंजी रद्द करें

```bash
curl -X DELETE https://api.phaseo.app/v1/keys/$PREVIOUS_KEY_ID \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY"
```

कुंजी हटाना इडेम्पोटेंट है, यानी इसे दोहराने से परिणाम नहीं बदलता। पहले से हटाई गई कुंजी के लिए भी सफल "हटाई गई" स्थिति लौटती है, इसलिए रोटेशन का पुनः प्रयास सुरक्षित रहता है।

## सीमाएँ और BYOK

Phaseo संगतता के लिए `limit`, `limit_reset` और `include_byok_in_limit` फ़ील्ड स्वीकार करता है। समर्थित रीसेट अवधियाँ दैनिक, साप्ताहिक और मासिक हैं। `include_byok_in_limit` अभी केवल संगतता के लिए है; Phaseo इस कुंजी-सीमा फ़ील्ड से BYOK उपयोग को बाहर रखता है।

## साझेदार स्थिति

Infisical का मूल कनेक्शन तभी उपलब्ध होगा जब Infisical, Phaseo App Connection और Phaseo API Key Rotation के कार्यान्वयन को स्वीकार करे। Phaseo के प्रबंधन और कुंजी-जीवनचक्र API उपलब्ध हैं; Infisical कनेक्टर, परीक्षण, UI प्रविष्टि और दस्तावेज़ अभी बाकी हैं।
