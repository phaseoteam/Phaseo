अलग सत्र के लिए Phaseo CLI रनर चुनें, या CLI से समर्पित कुंजी बनाकर मौजूदा Kilo Code इंस्टॉलेशन हाथ से सेट करें।

## Phaseo CLI से Kilo Code चलाएँ

Kilo Code CLI के लिए Phaseo को एक सत्र का प्रदाता कॉन्फ़िगरेशन बनाने दें:

```bash
phaseo login
phaseo kilo --model openai/gpt-5.6-terra --
```

सभी सक्रिय Phaseo टेक्स्ट/चैट मॉडल उपलब्ध कराने के लिए `--catalog all`, या इंस्टॉल और लॉन्च योजना देखने के लिए `--dry-run --json` इस्तेमाल करें। स्पष्ट कमांड रूप के लिए `phaseo run kilo ...` इस्तेमाल करें। रनर अस्थायी `KILO_CONFIG` फ़ाइल इस्तेमाल करता है, इसलिए मौजूदा Kilo Code या VS Code सेटअप नहीं बदलता।

## Phaseo CLI से क्रेडेंशियल बनाएँ

```bash
phaseo login
phaseo setup kilo-code --model anthropic/claude-sonnet-4.6
```

## Kilo Code को हाथ से सेट करें

1. VS Code में Kilo Code खोलें।
2. सेटिंग्स आइकन चुनें, **Providers** खोलें, फिर **Add custom provider** चुनें।
3. ये मान दर्ज करें:

| Kilo Code फ़ील्ड | मान |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.phaseo.app/v1` |
| API key | इस कमांड का आउटपुट `phaseo integrations credential kilo-code` |

4. अगर कोई मॉडल अपने-आप न मिले, तो ID `anthropic/claude-sonnet-4.6` मैन्युअल रूप से जोड़ें।
5. **Submit** चुनें, फिर Phaseo मॉडल चुनें।

Kilo चयन को `phaseo/anthropic/claude-sonnet-4.6` के रूप में दिखाता है: `phaseo` स्थानीय प्रदाता ID है, जबकि शेष हिस्सा मॉडल ID के रूप में Phaseo को भेजा जाता है।

## जाँचें

Kilo Code से `PHASEO_KILO_OK` जवाब देने को कहें, फिर पुष्टि करें कि अनुरोध Phaseo की गतिविधि में दिखाई देता है।

## हटाएँ

Kilo Code में कस्टम प्रदाता हटाएँ, फिर यह चलाएँ:

```bash
phaseo integrations remove kilo-code
```

CLI एक्सटेंशन का निजी स्टोरेज साफ़ नहीं कर सकती, लेकिन हटाने पर कुंजी निरस्त हो जाती है।

## समस्या निवारण

### कोई मॉडल नहीं मिलता

मॉडल मैन्युअल रूप से जोड़ें। `/models` के ज़रिए मॉडल खोजना ज़रूरी नहीं है।

### प्रमाणीकरण विफल होता है

सहेजे गए मान को `phaseo integrations credential kilo-code` के आउटपुट से बदलें और Base URL ठीक वैसा ही रखें जैसा दिखाया गया है।

### मॉडल का नाम अलग दिखता है

Kilo में `phaseo/<Phaseo model ID>` चुनें, लेकिन मॉडल ID फ़ील्ड के अंदर `phaseo/` न जोड़ें।
