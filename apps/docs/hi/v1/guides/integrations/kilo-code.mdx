Phaseo के ज़रिए Kilo Code CLI सत्र शुरू करने के लिए `phaseo kilo` चलाएँ, या `phaseo kilo-code` से कुंजी बनाएँ और Kilo Code एक्सटेंशन में कस्टम प्रदाता जोड़ें।

## Phaseo के ज़रिए Kilo Code CLI चलाएँ

```bash
phaseo login
phaseo kilo --model openai/gpt-5.6-terra
```

रनर एक अस्थायी `KILO_CONFIG` फ़ाइल लिखता है, `kilo` लॉन्च करता है, और Kilo बंद होने पर फ़ाइल मिटा देता है, इसलिए आपका मौजूदा Kilo Code या VS Code सेटअप नहीं बदलता। अगर Kilo इंस्टॉल नहीं है, तो इंटरैक्टिव रन उसे इंस्टॉल करने का विकल्प देता है। Kilo के अपने फ़्लैग `--` के बाद लिखें।

| फ़्लैग | असर |
| --- | --- |
| `--model <id>` | इस्तेमाल होने वाला मॉडल। डिफ़ॉल्ट `openai/gpt-5.6-terra` है। |
| `--catalog all` | सिर्फ़ चुने गए मॉडल की जगह, Kilo में हर सक्रिय Phaseo टेक्स्ट मॉडल दिखाता है। |
| `--dry-run --json` | कुंजी बनाए या Kilo शुरू किए बिना इंस्टॉल और लॉन्च की योजना दिखाता है। |
| `--skip-install` | इंस्टॉल जाँच छोड़ देता है। |

`phaseo run kilo ...` इसी कमांड का लंबा रूप है।

## Kilo Code एक्सटेंशन कॉन्फ़िगर करें

एक्सटेंशन के लिए कुंजी बनाएँ:

```bash
phaseo login
phaseo kilo-code --model anthropic/claude-sonnet-5.5
```

फिर VS Code में:

1. Kilo Code खोलें, सेटिंग्स आइकन चुनें, **Providers** खोलें, फिर **Add custom provider** चुनें।
2. ये मान दर्ज करें:

| Kilo Code फ़ील्ड | मान |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.phaseo.app/v1` |
| API key | `phaseo integrations credential kilo-code` का आउटपुट |

3. अगर कोई मॉडल नहीं मिलता, तो ID `anthropic/claude-sonnet-5.5` ख़ुद जोड़ें।
4. **Submit** चुनें, फिर Phaseo मॉडल चुनें।

Kilo चुने गए मॉडल को `phaseo/anthropic/claude-sonnet-5.5` के रूप में दिखाता है। `phaseo` लोकल प्रदाता ID है; बाकी हिस्सा वह मॉडल ID है जो Phaseo को भेजा जाता है। पूरे फ़ॉर्म के लिए Kilo के [कस्टम मॉडल](https://kilo.ai/docs/code-with-ai/agents/custom-models) दस्तावेज़ देखें।

## जाँचें कि यह काम करता है

Kilo Code से `PHASEO_KILO_OK` के साथ जवाब देने को कहें, फिर पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## Phaseo हटाएँ

Kilo Code में कस्टम प्रदाता मिटाएँ, फिर यह चलाएँ:

```bash
phaseo integrations remove kilo-code
```

इससे कुंजी रद्द हो जाती है। CLI एक्सटेंशन का स्टोरेज साफ़ नहीं कर सकता।

## आम समस्याएँ ठीक करें

### कोई मॉडल नहीं मिलता

मॉडल ख़ुद जोड़ें। Kilo को `/models` के ज़रिए डिस्कवरी की ज़रूरत नहीं है।

### ऑथेंटिकेशन विफल होता है

सेव की गई कुंजी को `phaseo integrations credential kilo-code` के आउटपुट से बदलें, और Base URL ठीक वैसा ही रखें जैसा दिखाया गया है।

### मॉडल का नाम अलग दिखता है

Kilo में `phaseo/<Phaseo model ID>` चुनें, लेकिन मॉडल ID फ़ील्ड में `phaseo/` न जोड़ें।
