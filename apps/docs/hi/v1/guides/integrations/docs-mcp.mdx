अपने कोडिंग एजेंट में `https://phaseo.app/docs/mcp` को MCP सर्वर के रूप में जोड़ें, ताकि वह Phaseo के सवालों के जवाब अपने ट्रेनिंग डेटा की जगह लाइव दस्तावेज़ों से दे। सर्वर सिर्फ़ पढ़ने के लिए है: एजेंट दस्तावेज़ खोज सकते हैं, पूरे पेज पढ़ सकते हैं, और होस्ट किया गया [skill.md](https://phaseo.app/docs/skill.md) क्षमता सारांश पढ़ सकते हैं।

## Codex

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
codex mcp list
```

## Claude Code

सर्वर को मौजूदा प्रोजेक्ट में जोड़ें, या उसे हर प्रोजेक्ट में उपलब्ध कराने के लिए `--scope user` जोड़ें:

```bash
claude mcp add --transport http phaseo-docs https://phaseo.app/docs/mcp
claude mcp add --transport http --scope user phaseo-docs https://phaseo.app/docs/mcp
claude mcp list
```

## Cursor

इसे किसी भी दस्तावेज़ पेज के कॉन्टेक्स्चुअल मेन्यू से इंस्टॉल करें, या Cursor के MCP कॉन्फ़िग में जोड़ें:

```json
{
  "mcpServers": {
    "phaseoDocs": {
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## VS Code

इसे किसी भी दस्तावेज़ पेज के कॉन्टेक्स्चुअल मेन्यू से इंस्टॉल करें, या VS Code के MCP कॉन्फ़िग में जोड़ें:

```json
{
  "servers": {
    "phaseoDocs": {
      "type": "http",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## OpenCode

इसे `opencode.json` में जोड़ें:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "phaseoDocs": {
      "type": "remote",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## जाँचें कि यह काम करता है

एजेंट से कुछ ऐसा पूछें जिसका जवाब सिर्फ़ दस्तावेज़ दे सकें, और जाँचें कि वह Phaseo दस्तावेज़ सर्वर को कॉल करता है:

- `Look up the Responses request format in the Phaseo docs and give me a minimal example.`
- `Use the Phaseo docs MCP server to check how provider.sort works before you change this request.`
- `Find the guardrails docs in Phaseo and summarize the parts that affect provider routing.`

एजेंट इसका इस्तेमाल अनुरोध के आकार जाँचने, यह देखने कि कोई मॉडल या प्रदाता कौन से एंडपॉइंट सपोर्ट करता है, और रूटिंग, प्रीसेट, गार्डरेल और async जॉब कैसे व्यवहार करते हैं, यह समझने के लिए करते हैं। दस्तावेज़ सर्वर Phaseo को आपका मॉडल गेटवे नहीं बनाता; उसके लिए [कोडिंग एजेंट](./coding-assistants.mdx) देखें।
