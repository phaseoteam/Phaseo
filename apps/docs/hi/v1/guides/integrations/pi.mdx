हर संगत Phaseo मॉडल के साथ Pi में Phaseo प्रदाता एक्सटेंशन जोड़ने के लिए `phaseo pi` चलाएँ।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo pi
```

अगर Pi इंस्टॉल नहीं है, तो CLI आधिकारिक इंस्टॉल कमांड दिखाता है और उसे चलाने से पहले पूछता है। इसके बाद सेटअप एक `Phaseo CLI: Pi API Key` (90 दिन में समाप्ति, $100 मासिक खर्च सीमा) बनाता है और `~/.pi/agent/extensions/phaseo.ts` में एक प्रदाता एक्सटेंशन लिखता है। एक्सटेंशन Chat Completions के साथ काम करने वाले हर सक्रिय Phaseo टेक्स्ट मॉडल की सूची रखता है।

| फ़्लैग | असर |
| --- | --- |
| `--model <id>` | शुरुआती मॉडल सेट करता है। डिफ़ॉल्ट `anthropic/claude-sonnet-4.6` है। |
| `--catalog default` | सिर्फ़ चुना गया मॉडल जोड़ता है। |
| `--dry-run` | फ़ाइल बदलाव किए बिना उन्हें दिखाता है। |

एक्सटेंशन Pi के कमांड-आधारित कुंजी सिंटैक्स से अनुरोध के समय कुंजी लेता है, इसलिए फ़ाइल में कोई सादा-टेक्स्ट कुंजी नहीं लिखी जाती:

```text
!phaseo integrations credential pi
```

## जाँचें कि यह काम करता है

```bash
pi
```

`/model` खोलें, `phaseo` प्रदाता चुनें, और एक छोटा प्रॉम्प्ट भेजें। पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## Phaseo हटाएँ

```bash
phaseo integrations remove pi
```

यह सिर्फ़ Phaseo एक्सटेंशन हटाता है और कुंजी रद्द करता है।
