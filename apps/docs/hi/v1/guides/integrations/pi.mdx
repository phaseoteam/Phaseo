## Phaseo CLI से सेटअप करें

इन उत्पादन-तैयार कमांडों के लिए Phaseo खाते की ज़रूरत है। CLI में लॉग इन और सेटअप करते समय गेटवे का अलग क्रेडेंशियल बनाया जाता है।

```bash
phaseo login
phaseo pi
```

पहले Pi की आधिकारिक रिलीज़ इंस्टॉल करें। सेटअप `~/.pi/agent/extensions/phaseo.ts` में एक प्रबंधित प्रदाता एक्सटेंशन लिखता है। यह एक्सटेंशन Chat Completions के साथ संगत सभी सक्रिय Phaseo टेक्स्ट मॉडल उपलब्ध कराता है और हर अनुरोध के समय Phaseo CLI से अपनी समर्पित API कुंजी प्राप्त करता है।

शुरुआती मॉडल चुनें, या ज़रूरत पड़ने पर केवल एक मॉडल कॉन्फ़िगर करें:

```bash
phaseo pi --model anthropic/claude-sonnet-4.6
phaseo pi --catalog default
```

फ़ाइलों में होने वाले बदलावों का पूर्वावलोकन देखने के लिए `--dry-run` उपयोग करें।

## शुरू करें और जाँचें

```bash
pi
```

`/model` खोलें, `phaseo` प्रदाता चुनें और एक छोटा प्रॉम्प्ट भेजें। केवल प्रबंधित एक्सटेंशन को हटाने और उसकी समर्पित कुंजी निरस्त करने के लिए यह चलाएँ:

```bash
phaseo integrations remove pi
```

## क्रेडेंशियल को मैन्युअल रूप से ऐक्सेस करें

जनरेट किया गया एक्सटेंशन, Pi के कमांड-आधारित कुंजी सिंटैक्स का उपयोग करता है:

```text
!phaseo integrations credential pi
```

एक्सटेंशन में कोई भी कुंजी सादे टेक्स्ट में नहीं लिखी जाती।
