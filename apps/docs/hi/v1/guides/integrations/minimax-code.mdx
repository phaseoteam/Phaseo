Phaseo के ज़रिए MiniMax Code (`mcode`) सत्र शुरू करने के लिए `phaseo minimax` चलाएँ, या उसे हर सत्र में रखने के लिए `mcode provider add` से Phaseo जोड़ें।

## Phaseo CLI के ज़रिए MiniMax Code चलाएँ

```bash
phaseo login
phaseo minimax --model openai/gpt-5.6-terra
```

रनर एक समर्पित कुंजी बनाता है, `MINIMAX_DATA_DIR` को एक अस्थायी डायरेक्टरी पर सेट करता है, वहाँ `mcode provider add` से Phaseo प्रदाता जोड़ता है, `mcode` लॉन्च करता है, और `mcode` बंद होने पर डायरेक्टरी मिटा देता है। आपका सामान्य `~/.minimax` कॉन्फ़िगरेशन नहीं बदलता, और कुंजी सिर्फ़ प्रदाता सेटअप प्रोसेस को दी जाती है। MiniMax Code के अपने फ़्लैग `--` के बाद लिखें।

| फ़्लैग | असर |
| --- | --- |
| `--model <id>` | इस्तेमाल होने वाला मॉडल। डिफ़ॉल्ट `openai/gpt-5.6-terra` है। |
| `--catalog all` | Chat Completions के साथ काम करने वाला हर सक्रिय Phaseo टेक्स्ट मॉडल रजिस्टर करता है। |
| `--dry-run --json` | कुंजी बनाए बिना इंस्टॉल और लॉन्च की योजना दिखाता है। |
| `--skip-install` | इंस्टॉल जाँच छोड़ देता है। |

`phaseo run minimax ...` इसी कमांड का लंबा रूप है।

अगर `mcode` इंस्टॉल नहीं है, तो पहला इंटरैक्टिव रन उसे MiniMax के आधिकारिक इंस्टॉलर (Windows पर PowerShell इंस्टॉलर) से इंस्टॉल करने का विकल्प देता है। अगर आप MiniMax Code ख़ुद संभालते हैं, तो उसे इंस्टॉल करें, `mcode --version` जाँचें, और `--skip-install` के साथ दोबारा चलाएँ।

## MiniMax Code को मैन्युअल रूप से कॉन्फ़िगर करें

Phaseo प्रदाता को स्थायी रखने के लिए, उसे MiniMax Code की अपनी कमांड से जोड़ें:

```bash
export MCODE_PROVIDER_API_KEY="your_phaseo_api_key"
mcode provider add \
  --name "Phaseo" \
  --base-url "https://api.phaseo.app/v1" \
  --api-format openai-completions \
  --model "openai/gpt-5.6-terra" \
  --use
```

MiniMax Code प्रदाता को अपनी डेटा डायरेक्टरी में सेव करता है।

## जाँचें कि यह काम करता है

एक छोटा प्रॉम्प्ट भेजें और पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## आम समस्याएँ ठीक करें

### MiniMax Code इंस्टॉल नहीं है

आधिकारिक इंस्टॉलर को मंज़ूरी देने के लिए कमांड इंटरैक्टिव टर्मिनल में चलाएँ, या MiniMax Code ख़ुद इंस्टॉल करें और `--skip-install` के साथ दोबारा चलाएँ।

### प्रदाता या मॉडल सूची में नहीं है

`phaseo minimax --catalog all` इस्तेमाल करें, या `--model` के साथ मॉडल ID दें।

### आपको इंटरैक्टिव CLI की जगह ACP चाहिए

`phaseo minimax` इंटरैक्टिव CLI चलाता है। MiniMax Code `mcode acp` के साथ ACP प्रोसेस के रूप में भी चलता है; जब आपका एडिटर या होस्ट सीधे ACP इस्तेमाल करता है, तो MiniMax Code का ACP कॉन्फ़िगरेशन इस्तेमाल करें।
