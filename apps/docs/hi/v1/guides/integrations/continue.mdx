Phaseo CLI से IDE एक्सटेंशन और `cn` कमांड-लाइन इंटरफ़ेस के लिए साझा स्थानीय Continue कॉन्फ़िगरेशन बनाएँ, या वही मॉडल और सीक्रेट मान मौजूदा Continue कॉन्फ़िगरेशन में हाथ से जोड़ें।

## Phaseo CLI से सेटअप करें

```bash
phaseo login
phaseo continue --model anthropic/claude-sonnet-4.6
```

`~/.continue/config.yaml` और `~/.continue/.env` इस्तेमाल में न हों, तो सेटअप दोनों फ़ाइलें बनाता है:

```yaml
name: Phaseo
version: 1.0.0
schema: v1
models:
  - name: Phaseo
    provider: openai
    model: anthropic/claude-sonnet-4.6
    apiBase: https://api.phaseo.app/v1
    apiKey: ${{ secrets.PHASEO_API_KEY }}
    useResponsesApi: false
    roles: [chat, edit, apply]
```

कुंजी `~/.continue/.env` में `PHASEO_API_KEY` नाम से रखी जाती है। `useResponsesApi: false` अनुरोधों को Phaseo के Chat Completions पथ पर रखता है।

<Warning>
Continue की ग्लोबल `.env` फ़ाइल सादे टेक्स्ट में होती है। इसे कभी कमिट न करें। IDE एक्सटेंशन सामान्य शेल एनवायरनमेंट वैरिएबल इनहेरिट नहीं करते, इसलिए CLI, Continue के दस्तावेज़ों में बताई गई सीक्रेट फ़ाइल उपयोग करती है।
</Warning>

अगर किसी भी फ़ाइल में पहले से उपयोगकर्ता का कॉन्फ़िगरेशन है, तो सेटअप उसे ओवरराइट किए बिना रुक जाता है। मॉडल प्रविष्टि को मिलाएँ और मौजूदा `.env` में `PHASEO_API_KEY=<dedicated key>` जोड़ें। कुंजी `phaseo integrations credential continue` से प्राप्त करें।

## जाँचें

VS Code या JetBrains में विंडो रीलोड करें, Continue खोलें, **Phaseo** चुनें और उससे `PHASEO_CONTINUE_OK` जवाब देने को कहें।

Continue CLI के लिए `cn` चलाएँ। अगर कोई दूसरा सहेजा गया कॉन्फ़िगरेशन सक्रिय है, तो `/config` उपयोग करें, फिर वही टेस्ट प्रॉम्प्ट भेजें। पुष्टि करें कि अनुरोध Phaseo की गतिविधि में दिखता है।

## हटाएँ

```bash
phaseo integrations remove continue
```

हटाने पर कुंजी निरस्त हो जाती है, और दोनों फ़ाइलें तभी हटाई जाती हैं जब उनमें अब भी Phaseo CLI का स्वामित्व चिह्न मौजूद हो। मैन्युअल रूप से मिलाई गई प्रविष्टियाँ नहीं बदली जातीं।

## समस्या निवारण

### Phaseo दिखाई नहीं देता

IDE रीलोड करें और जाँचें कि `config.yaml` में आवश्यक शीर्ष-स्तरीय फ़ील्ड `name`, `version` और `schema` मौजूद हैं।

### Continue कहता है कि गोपनीय कुंजी मौजूद नहीं है

पुष्टि करें कि `~/.continue/.env` में `phaseo integrations credential continue` से मिली कुंजी मौजूद है, फिर IDE रीस्टार्ट करें।

### Continue Responses API को कॉल करता है

Phaseo मॉडल प्रविष्टि में `useResponsesApi: false` रखें।
