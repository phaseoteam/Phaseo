अगर आपके LlamaIndex ऐप को जनरेशन या एम्बेडिंग Phaseo के ज़रिए रूट करनी है, तो यह गाइड इस्तेमाल करें।

## इंस्टॉल करें

```bash
pip install llama-index llama-index-llms-openai-like llama-index-embeddings-openai-like
```

## OpenAI-संगत LLM कॉन्फ़िगर करें

```python
import os
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="openai/gpt-5-nano",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    is_chat_model=True,
)

response = llm.complete("Write one sentence about retrieval quality.")
print(response)
```

## इंडेक्स में उपयोग करें

```python
from llama_index.core import Settings

Settings.llm = llm
```

इसके बाद सामान्य तरीके से अपना इंडेक्स बनाएँ या उस पर क्वेरी करें।

## नोट्स

- तृतीय-पक्ष OpenAI-संगत API के लिए `OpenAILike` इस्तेमाल करें।
- जनरेशन और एम्बेडिंग मॉडल ID स्पष्ट रूप से दें। यह न मानें कि LlamaIndex के डिफ़ॉल्ट Phaseo की ओर इशारा करते हैं।
- अगर आप Phaseo एम्बेडिंग इस्तेमाल करते हैं, तो एम्बेडिंग मॉडल को Phaseo मॉडल ID और उसी बेस URL के साथ सेट करें।
