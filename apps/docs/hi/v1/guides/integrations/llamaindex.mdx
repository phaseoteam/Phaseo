अपनी Phaseo कुंजी और `api_base="https://api.phaseo.app/v1"` के साथ एक `OpenAILike` LLM बनाएँ, फिर उसे LlamaIndex का डिफ़ॉल्ट सेट करें ताकि आपके RAG वर्कफ़्लो में जनरेशन Phaseo के ज़रिए हो।

## इंस्टॉल करें

```bash
pip install llama-index llama-index-llms-openai-like llama-index-embeddings-openai-like
```

## LlamaIndex को Phaseo पर ले जाएँ

```python
import os
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    is_chat_model=True,
)

response = llm.complete("Write one sentence about retrieval quality.")
print(response)
```

एक वाक्य प्रिंट होने का मतलब है कि सेटअप काम करता है। `OpenAILike` तीसरे पक्ष के OpenAI-संगत API के लिए LlamaIndex की क्लास है।

## इंडेक्स में इस्तेमाल करें

```python
from llama_index.core import Settings

Settings.llm = llm
```

फिर अपना इंडेक्स हमेशा की तरह बनाएँ या क्वेरी करें।

## ज्ञात सीमाएँ

- LlamaIndex के डिफ़ॉल्ट Phaseo की ओर इशारा नहीं करते। जनरेशन और एम्बेडिंग मॉडल स्पष्ट रूप से सेट करें।
- Phaseo [एम्बेडिंग](../../api-reference/endpoint/embeddings.mdx) के लिए, एम्बेडिंग मॉडल को Phaseo मॉडल ID और उसी base URL के साथ कॉन्फ़िगर करें।
