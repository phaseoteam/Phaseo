Phaseo अनुरोधों को दो तरीकों से ट्रेस करें: [प्रसारण](../broadcast.mdx) चालू करें ताकि Phaseo बिना किसी कोड बदलाव के हर अनुरोध का ट्रेस Langfuse, LangSmith या किसी भी OpenTelemetry टूल को भेजे, या अपनी ट्रेसिंग लाइब्रेरी अपने ऐप में रखें और उसके मॉडल क्लाइंट को Phaseo पर ले जाएँ।

| | प्रसारण | आपके ऐप में ट्रेसिंग |
| --- | --- | --- |
| ट्रेस कहाँ से आते हैं | Phaseo से, हर अनुरोध के लिए | आपके ऐप के मॉडल क्लाइंट से |
| कोड बदलाव | कोई नहीं; **सेटिंग्स → प्रसारण** में सेट अप करें | क्लाइंट को रैप करें, फिर उसका base URL बदलें |
| ट्रेस में क्या होता है | मॉडल, प्रदाता, हर प्रदाता प्रयास, टोकन, लागत, समय, और (वैकल्पिक रूप से) प्रॉम्प्ट और आउटपुट | आपकी लाइब्रेरी जो भी रिकॉर्ड करती है, साथ में आपके ऐप का अपना संदर्भ |

## OpenAI SDK के साथ Langfuse

Langfuse का OpenAI रैपर रखें और रैप किए गए क्लाइंट को Phaseo का base URL दें:

```bash
pip install langfuse openai
```

```python
import os
from langfuse.openai import openai

client = openai.OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Reply with only: ok",
)
```

## LangChain के साथ LangSmith

[LangChain](./langchain.mdx) वाला `ChatOpenAI` सेटअप इस्तेमाल करें और LangChain के सामान्य एनवायरनमेंट वेरिएबल से LangSmith चालू करें:

```bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your_langsmith_key"
export PHASEO_API_KEY="your_phaseo_key"
```

## OpenTelemetry

अगर आपका फ़्रेमवर्क पहले से OpenTelemetry स्पैन भेजता है, तो आपको किसी ख़ास एक्सपोर्टर की ज़रूरत नहीं है। यह अनुरोध संदर्भ अपने स्पैन में ख़ुद जोड़ें:

- मॉडल ID;
- एंडपॉइंट, जैसे `responses` या `chat.completions`;
- Phaseo अनुरोध ID, प्रतिक्रिया मेटाडेटा या [लॉग](../../api-reference/endpoint/activity.mdx) से;
- अनुरोध पूरा करने वाला प्रदाता, जब प्रतिक्रिया मेटाडेटा चालू हो।

Phaseo API कुंजियों को कभी स्पैन एट्रिब्यूट के रूप में रिकॉर्ड न करें।
