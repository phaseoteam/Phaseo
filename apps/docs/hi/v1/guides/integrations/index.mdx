ज़्यादातर integrations में OpenAI या Anthropic-संगत client को Phaseo पर point करके Phaseo API key उपयोग की जाती है। जिस tool का उपयोग करते हैं, उसकी guide से शुरू करें।

## आधार URL

| Client style | Base URL |
| --- | --- |
| OpenAI-संगत clients | `https://api.phaseo.app/v1` |
| Anthropic-संगत clients | `https://api.phaseo.app` |

[Models endpoint](../../api-reference/endpoint/models.mdx) से model IDs लें। नए OpenAI-style apps के लिए [Responses](../../api-reference/endpoint/responses.mdx) बेहतर है। पुरानी libraries के लिए आम तौर पर [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) सबसे सुरक्षित विकल्प है।

## सुझाए गए defaults

- `PHASEO_API_KEY` एक बार set करके उसे client की expected environment variable से map करें।
- Model ID को जस का तस रखें, जैसे `openai/gpt-5-nano`।
- OpenAI-संगत libraries के लिए `https://api.phaseo.app/v1` उपयोग करें, जब तक tool root host साफ़ तौर पर न माँगे।
- Anthropic-संगत SDKs और `/v1/messages` जोड़ने वाले tools के लिए `https://api.phaseo.app` उपयोग करें।
- Agent traffic ले जाने से पहले staging में streaming और tool calling जाँचें।
