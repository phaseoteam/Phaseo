किसी OpenAI-संगत या Anthropic-संगत क्लाइंट को Phaseo के base URL पर ले जाएँ, उसे एक Phaseo API कुंजी दें, और `openai/gpt-6-astra` जैसे Phaseo मॉडल ID बिना बदलाव के इस्तेमाल करें। हर गाइड पहले टूल सेट अप करती है, फिर दिखाती है कि कैसे जाँचें कि वह काम करता है और क्या काम नहीं करता।

| क्लाइंट शैली | Base URL | कुंजी कहाँ जाती है |
| --- | --- | --- |
| OpenAI-संगत | `https://api.phaseo.app/v1` | API कुंजी फ़ील्ड में, `Authorization: Bearer` के रूप में भेजी जाती है |
| Anthropic-संगत (`/v1/messages` ख़ुद जोड़ता है) | `https://api.phaseo.app` | ऑथ टोकन फ़ील्ड में, `Authorization: Bearer` के रूप में भेजी जाती है |

मॉडल ID [Models एंडपॉइंट](../../api-reference/endpoint/models.mdx) से लें। नए OpenAI-शैली ऐप के लिए [Responses](../../api-reference/endpoint/responses.mdx) इस्तेमाल करें; पुरानी लाइब्रेरी [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) पर सबसे सुरक्षित रहती हैं। `PHASEO_API_KEY` एक बार सेट करें और उसे उस वेरिएबल से मैप करें जिसकी टूल को ज़रूरत है, और एजेंट ट्रैफ़िक ले जाने से पहले स्ट्रीमिंग और टूल कॉलिंग की जाँच करें।
