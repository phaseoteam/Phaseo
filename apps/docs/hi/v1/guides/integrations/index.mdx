ज़्यादातर इंटीग्रेशन में किसी OpenAI-संगत या Anthropic-संगत क्लाइंट को Phaseo पर निर्देशित किया जाता है और Phaseo API कुंजी इस्तेमाल की जाती है। आप जो टूल पहले से इस्तेमाल करते हैं, उसकी गाइड से शुरुआत करें।

## बेस URL

| क्लाइंट का प्रकार | बेस URL |
| --- | --- |
| OpenAI-संगत क्लाइंट | `https://api.phaseo.app/v1` |
| Anthropic-संगत क्लाइंट | `https://api.phaseo.app` |

मॉडल ID [मॉडल एंडपॉइंट](../../api-reference/endpoint/models.mdx) से लें। नए OpenAI-शैली वाले ऐप्स के लिए [Responses](../../api-reference/endpoint/responses.mdx) को प्राथमिकता दें। पुरानी लाइब्रेरी के लिए आम तौर पर [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) सबसे सुरक्षित विकल्प है।

## उपयोगी डिफ़ॉल्ट

- `PHASEO_API_KEY` एक बार सेट करें और उसे उस एनवायरनमेंट वैरिएबल से मैप करें जिसकी क्लाइंट अपेक्षा करता है।
- मॉडल ID को बिना बदले रखें, जैसे `openai/gpt-5-nano`।
- OpenAI-संगत लाइब्रेरी के लिए `https://api.phaseo.app/v1` इस्तेमाल करें, जब तक टूल स्पष्ट रूप से रूट होस्ट न माँगे।
- Anthropic-संगत SDK और `/v1/messages` जोड़ने वाले टूल के लिए `https://api.phaseo.app` इस्तेमाल करें।
- एजेंट ट्रैफ़िक को Phaseo पर लाने से पहले स्टेजिंग में स्ट्रीमिंग और टूल कॉलिंग जाँचें।
