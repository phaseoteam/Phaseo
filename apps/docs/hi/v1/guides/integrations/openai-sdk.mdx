आधिकारिक OpenAI SDK को Phaseo पर ले जाने के लिए तीन चीज़ें बदलें: API कुंजी, base URL (`https://api.phaseo.app/v1`) और मॉडल ID।

## इंस्टॉल करें

<CodeGroup>

```bash TypeScript
npm install openai
```

```bash Python
pip install openai
```

</CodeGroup>

## क्लाइंट को Phaseo पर ले जाएँ

<CodeGroup>

```ts TypeScript
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Write one sentence about reliable model routing.",
});

console.log(response.output_text);
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Write one sentence about reliable model routing.",
)

print(response.output_text)
```

</CodeGroup>

एक वाक्य प्रिंट होने का मतलब है कि कुंजी और base URL काम करते हैं। अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में भी दिखता है।

## Chat Completions इस्तेमाल करें

Chat Completions को कॉल करने वाला कोड उसी क्लाइंट के साथ काम करता है:

```ts
const completion = await client.chat.completions.create({
	model: "openai/gpt-6-astra",
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## ज्ञात सीमाएँ

- प्रदाता प्रीफ़िक्स वाले Phaseo मॉडल ID इस्तेमाल करें: `openai/`, `anthropic/`, `google/` वगैरह। पूरे अनुरोध आकार के लिए [Responses](../../api-reference/endpoint/responses.mdx) और [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) देखें।
- [सर्वर टूल](../server-tools/index.mdx) Phaseo टूल नाम इस्तेमाल करते हैं, जैसे `phaseo:web_search`।
- Anthropic-शैली `/v1/messages` क्लाइंट के लिए [Anthropic SDK](./anthropic-sdk.mdx) गाइड देखें।
