अगर आपका ऐप्लिकेशन पहले से Effect इस्तेमाल करता है और आप Phaseo को किसी Effect सेवा या वर्कफ़्लो के पीछे रखना चाहते हैं, तो यह गाइड इस्तेमाल करें।

## स्थिति

Phaseo OpenAI-संगत HTTP एंडपॉइंट उपलब्ध कराता है। Effect के अपने प्रदाता पैकेज तब उपयोगी हैं जब वे आपकी ज़रूरत वाले प्रदाता का सीधे समर्थन करते हों; अगर इंस्टॉल किया गया Effect OpenAI पैकेज बेस URL का विकल्प नहीं देता, तो Effect के HTTP क्लाइंट के ज़रिए Phaseo को कॉल करें या [OpenAI SDK](./openai-sdk.mdx) को अपनी Effect लेयर में लपेटें।

## इंस्टॉल करें

```bash
npm install effect @effect/platform
```

## Effect HTTP से Phaseo को कॉल करें

```ts
import { FetchHttpClient, HttpClient, HttpClientRequest } from "@effect/platform";
import { Config, Effect, Redacted } from "effect";

const generate = Effect.gen(function* () {
	const apiKey = yield* Config.redacted("PHASEO_API_KEY");
	const client = yield* HttpClient.HttpClient;

	const request = HttpClientRequest.post(
		"https://api.phaseo.app/v1/chat/completions",
	).pipe(
		HttpClientRequest.bearerToken(Redacted.value(apiKey)),
		HttpClientRequest.jsonBody({
			model: "openai/gpt-5-nano",
			messages: [{ role: "user", content: "Reply with only: ok" }],
		}),
	);

	return yield* client.execute(request).pipe(
		Effect.flatMap((response) => response.json),
	);
});

const runnable = generate.pipe(Effect.provide(FetchHttpClient.layer));
```

## OpenAI SDK को Effect सेवा में लपेटें

अगर आप कहीं और आधिकारिक OpenAI SDK पहले से इस्तेमाल करते हैं, तो Phaseo कॉन्फ़िगरेशन को एक ही लेयर में रखें:

```ts
import OpenAI from "openai";
import { Config, Effect } from "effect";

const makeClient = Effect.gen(function* () {
	const apiKey = yield* Config.string("PHASEO_API_KEY");

	return new OpenAI({
		apiKey,
		baseURL: "https://api.phaseo.app/v1",
	});
});
```

## नोट्स

- OpenAI-संगत कॉल के लिए `https://api.phaseo.app/v1` इस्तेमाल करें।
- मॉडल ID को Phaseo फ़ॉर्मैट में रखें, जैसे `openai/gpt-5-nano`।
- जब आप अपने बाकी ऐप्लिकेशन में प्रदाता-शैली का एक साझा एब्स्ट्रैक्शन चाहते हों, तब कस्टम Effect लेयर इस्तेमाल करें।
- प्रोडक्शन रोलआउट से पहले अपने Effect पैकेज के सटीक संस्करणों के साथ स्ट्रीमिंग और टूल कॉल की जाँच करें।
