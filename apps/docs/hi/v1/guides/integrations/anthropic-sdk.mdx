जब आपका ऐप, एजेंट या कोडिंग टूल Claude-शैली के `/v1/messages` अनुरोधों की अपेक्षा करे, तब Anthropic-संगत API इस्तेमाल करें।

## TypeScript

```bash
npm install @anthropic-ai/sdk
```

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app",
});

const message = await client.messages.create({
	model: "anthropic/claude-sonnet-4.5",
	max_tokens: 512,
	messages: [{ role: "user", content: "Reply with only: ok" }],
});

console.log(message.content);
```

## Python

```bash
pip install anthropic
```

```python
import os
from anthropic import Anthropic

client = Anthropic(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app",
)

message = client.messages.create(
    model="anthropic/claude-sonnet-4.5",
    max_tokens=512,
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(message.content)
```

## नोट्स

- रूट होस्ट `https://api.phaseo.app` इस्तेमाल करें; Anthropic क्लाइंट अपने-आप `/v1/messages` जोड़ते हैं।
- एंडपॉइंट की जानकारी के लिए [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx) देखें।
- जहाँ Phaseo समर्थन करता है, वहाँ Anthropic के नेटिव टूल स्वरूप काम कर सकते हैं, लेकिन कई प्रदाताओं पर चलने वाले सर्वर टूल के लिए Phaseo के टूल नाम इस्तेमाल करें।
- अगर कोई वर्कफ़्लो स्ट्रीम किए गए टूल लूप पर निर्भर है, तो प्रोडक्शन रोलआउट से पहले उसे जाँचें, क्योंकि Anthropic-संगत क्लाइंट टूल इवेंट के क्रम को लेकर ज़्यादा सख्त होते हैं।
