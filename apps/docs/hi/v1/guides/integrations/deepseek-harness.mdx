DeepSeek Harness के मॉडल पिकर में Phaseo जोड़ने के लिए `phaseo deepseek-harness` चलाएँ, या Harness UI या `settings.yaml` में कस्टम प्रदाता जोड़ें। Harness OpenAI-संगत Chat Completions अनुरोध सीधे Phaseo को भेजता है, इसलिए किसी एडैप्टर की ज़रूरत नहीं है।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo deepseek-harness
```

अगर Harness इंस्टॉल नहीं है, तो CLI आधिकारिक इंस्टॉल कमांड दिखाता है और उसे चलाने से पहले पूछता है। इसके बाद सेटअप:

- प्रदाता, base URL, प्रोटोकॉल, मॉडल कैटलॉग और डिफ़ॉल्ट मॉडल को `$DSH_HOME/cordis.patch.yml` (`DSH_HOME` का डिफ़ॉल्ट `~/.dsh` है) में एक चिह्नित ब्लॉक के अंदर लिखता है, ताकि बाद में वह सिर्फ़ अपनी सेटिंग्स अपडेट कर सके या हटा सके;
- Chat Completions के साथ काम करने वाला हर सक्रिय Phaseo टेक्स्ट मॉडल जोड़ता है। सिर्फ़ डिफ़ॉल्ट मॉडल जोड़ने के लिए `--catalog default` इस्तेमाल करें;
- एक `Phaseo CLI: DeepSeek Harness API Key` बनाता है जो 90 दिनों में समाप्त होती है और जिसकी मासिक खर्च सीमा $100 है, और उसे Harness की सुरक्षित `$DSH_HOME/.credentials.yaml` में लिखता है। समाप्त कुंजी बदलने के लिए `phaseo deepseek-harness` दोबारा चलाएँ।

डिफ़ॉल्ट मॉडल `anthropic/claude-sonnet-4.6` है। कोई दूसरा चुनने के लिए:

```bash
phaseo deepseek-harness --model YOUR_PHASEO_MODEL_ID
```

## Harness UI में Phaseo जोड़ें

1. **Settings > Models** खोलें और **Add a custom provider** चुनें।
2. ये मान दर्ज करें:

| फ़ील्ड | मान |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Base URL | `https://api.phaseo.app/v1` |
| API protocol | `OpenAI Completions` |
| API key | एक Phaseo API कुंजी |

3. **Model catalog** के अंदर **Fetch available models** चुनें।
4. टूल सपोर्ट वाला कोई Chat Completions मॉडल चुनें, जैसे `anthropic/claude-sonnet-5.5`, और प्रदाता सेव करें।
5. कंपोज़र में Phaseo मॉडल चुनें और नया सत्र शुरू करें।

सेव किए गए सत्र और क्रेडेंशियल रेफ़रेंस प्रदाता ID बनाए रखते हैं, इसलिए `phaseo` को स्थायी मानें। डिस्प्ले नाम, URL, कुंजी और मॉडल सूची आप बाद में बदल सकते हैं।

## settings.yaml में Phaseo कॉन्फ़िगर करें

आप यही प्रदाता `$DSH_HOME/settings.yaml` में भी सेट अप कर सकते हैं। कुंजी इस फ़ाइल से बाहर रखें: `apiKeyEnv` उस वेरिएबल का नाम बताता है जिससे Harness कुंजी पढ़ता है।

```yaml $DSH_HOME/settings.yaml
llm-pi-ai:
  providers:
    phaseo:
      displayName: Phaseo
      apiKeyEnv: PHASEO_API_KEY
      api: openai-completions
      baseURL: https://api.phaseo.app/v1
      models:
        - id: YOUR_PHASEO_MODEL_ID
```

Harness लॉन्च करने वाले एनवायरनमेंट में `PHASEO_API_KEY` सेट करें, या कुंजी Models पेज पर सेव करें। `YOUR_PHASEO_MODEL_ID` को Phaseo के सटीक ID से बदलें; कोडिंग एजेंट के लिए `anthropic/claude-sonnet-5.5` से शुरू करें। `models` सूची एक सेव किया गया कैटलॉग है, लाइव क्वेरी नहीं, इसलिए जब Harness में और Phaseo मॉडल चाहिए हों तो इसे अपडेट करें।

## जाँचें कि यह काम करता है

पहले कुंजी और मॉडल डिस्कवरी जाँचें:

```bash
curl https://api.phaseo.app/v1/models \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

फिर नए Harness सत्र में कोई Phaseo मॉडल चुनें और `Reply with exactly: Phaseo is connected.` भेजें। जवाब मिलना Harness से Phaseo होते हुए मॉडल प्रदाता तक पूरे रास्ते की पुष्टि करता है। अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में भी दिखता है। लाइव अनुरोधों का बिल सामान्य उपयोग की तरह बनता है।

## Phaseo हटाएँ

```bash
phaseo integrations remove deepseek-harness
```

यह सिर्फ़ Phaseo का कॉन्फ़िगरेशन हटाता है और कुंजी रद्द करता है।

## आम समस्याएँ ठीक करें

| समस्या | समाधान |
| --- | --- |
| मॉडल फ़ेच करने पर `401` मिलता है | जाँचें कि कुंजी मौजूदा है और base URL में `/v1` शामिल है। |
| मॉडल पिकर में मॉडल नहीं दिखता | कैटलॉग फिर से फ़ेच करें, या `settings.yaml` में `models` के अंदर सटीक मॉडल ID जोड़ें। |
| Harness `MISSING_CREDENTIAL` रिपोर्ट करता है | कुंजी Models पेज पर सेव करें, या `PHASEO_API_KEY` को Harness प्रोसेस के लिए उपलब्ध कराएँ। |
| अनुरोध गलत एंडपॉइंट पर जाते हैं | `OpenAI Completions` (`openai-completions`) चुनें। यह प्रदाता Phaseo का `/v1/chat/completions` इस्तेमाल करता है। |
| रीज़निंग चालू होने पर कोई मॉडल फ़ंक्शन टूल अस्वीकार करता है | ऐसा मॉडल चुनें जो Chat Completions पर टूल सपोर्ट करे। जिन मॉडल को टूल के साथ रीज़निंग के लिए Responses API चाहिए, वे इस प्रोटोकॉल के साथ काम नहीं करते। |
| कोई सत्र अपना पुराना मॉडल बनाए रखता है | नया सत्र शुरू करें। जिन सत्रों ने अनुरोध भेजा है, उनमें Harness प्रदाता और मॉडल सेव कर लेता है। |
