अपनी Phaseo कुंजी और `base_url="https://api.phaseo.app/v1"` के साथ एक `ChatOpenAI` मॉडल बनाएँ, और LangChain चेन, एजेंट और LangGraph वर्कफ़्लो Phaseo के ज़रिए मॉडल कॉल करते हैं।

## इंस्टॉल करें

```bash
pip install -U langchain langchain-openai
```

## ChatOpenAI को Phaseo पर ले जाएँ

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

एक वाक्य प्रिंट होने का मतलब है कि सेटअप काम करता है।

## LangGraph में इस्तेमाल करें

वही `llm` अपने ग्राफ़ नोड या एजेंट बिल्डर को दें:

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## ज्ञात सीमाएँ

- यह तरीका [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) इस्तेमाल करता है, इसलिए सिर्फ़ `/v1/chat/completions` पर उपलब्ध Phaseo सुविधाएँ काम करती हैं, जिनमें [टूल कॉलिंग](../tool-calling.mdx) और [रूटिंग और फ़ॉलबैक](../routing-and-fallbacks.mdx) शामिल हैं।
- `phaseo:apply_patch` जैसे सिर्फ़-Responses सर्वर टूल के लिए Phaseo को सीधे कॉल करें या [OpenAI SDK](./openai-sdk.mdx) इस्तेमाल करें।
- LangSmith से ट्रेसिंग के लिए [ऑब्ज़र्वेबिलिटी](./observability.mdx) देखें।
