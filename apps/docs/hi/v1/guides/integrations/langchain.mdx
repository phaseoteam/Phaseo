अगर आप LangChain chains, agents या LangGraph वर्कफ़्लो से Phaseo के ज़रिए मॉडल कॉल करना चाहते हैं, तो इस गाइड का उपयोग करें।

## इंस्टॉल करें

```bash
pip install -U langchain langchain-openai
```

## ChatOpenAI कॉन्फ़िगर करें

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-5-nano",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

## LangGraph के साथ उपयोग करें

उसी `llm` को अपने graph nodes या agent builder में पास करें:

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## नोट्स

- LangChain का OpenAI-संगत पथ Chat Completions को लक्ष्य करता है। `/v1/chat/completions` पर उपलब्ध Phaseo सुविधाओं का उपयोग करें।
- `phaseo:apply_patch` जैसे केवल Responses वाले server tools के लिए सीधे Phaseo कॉल करें या OpenAI SDK गाइड देखें।
- ट्रेसिंग के लिए इस सेटअप को [ऑब्ज़र्वेबिलिटी](./observability.mdx) के साथ जोड़ें।
