Phaseo CLI से समर्पित कुंजी बनाएँ और Roo Code की प्रदाता प्रोफ़ाइल हाथ से सेट करें। Roo Code क्रेडेंशियल VS Code के सीक्रेट स्टोरेज में रखता है, इसलिए अंतिम प्रविष्टि एक्सटेंशन के इंटरफ़ेस में होती है।

## Phaseo CLI से सेटअप करें

```bash
phaseo login
phaseo roo-code --model anthropic/claude-sonnet-4.6
```

## Roo Code को हाथ से सेट करें

1. VS Code में Roo Code खोलें।
2. **Settings** खोलें, फिर **Providers** पर जाएँ।
3. प्रदाता कॉन्फ़िगरेशन प्रोफ़ाइल बनाएँ और **OpenAI Compatible** चुनें।
4. ये मान दर्ज करें:

| Roo Code फ़ील्ड | मान |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | `phaseo integrations credential roo-code` का आउटपुट |
| Model | `anthropic/claude-sonnet-4.6` या सेटअप में दिखाया गया मॉडल |

5. प्रोफ़ाइल सहेजें और उसे सक्रिय करें।

अलग-अलग रिलीज़ में फ़ील्ड लेबल थोड़े बदल सकते हैं, लेकिन प्रोफ़ाइल में एंडपॉइंट, कुंजी और सटीक मॉडल ID होना ज़रूरी है।

## जाँचें

Roo Code से `PHASEO_ROO_OK` जवाब देने को कहें, फिर पुष्टि करें कि अनुरोध Phaseo गतिविधि में दिखता है।

## हटाएँ

Phaseo प्रोफ़ाइल हटाएँ या दूसरी प्रोफ़ाइल चुनें, फिर यह चलाएँ:

```bash
phaseo integrations remove roo-code
```

CLI, VS Code के निजी एक्सटेंशन स्टोरेज से मान नहीं हटा सकता, लेकिन हटाने की प्रक्रिया कुंजी को रद्द कर देती है।

## समस्या निवारण

### प्रमाणीकरण विफल

`phaseo integrations credential roo-code` से कुंजी फिर से प्राप्त करें। सुनिश्चित करें कि Base URL के अंत में `/v1` हो।

### Roo Code को मॉडल नहीं मिलता

प्रदाता प्रीफ़िक्स सहित सटीक Phaseo मॉडल ID हाथ से दर्ज करें।

### चैट काम करता है, लेकिन टूल विफल होते हैं

टूल कॉलिंग का समर्थन करने वाले मॉडल पर स्विच करें।
