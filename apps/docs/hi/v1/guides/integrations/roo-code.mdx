कुंजी बनाने के लिए `phaseo roo-code` चलाएँ, फिर Roo Code में **OpenAI Compatible** प्रोफ़ाइल जोड़ें। Roo Code कुंजियाँ VS Code के सीक्रेट स्टोरेज में रखता है, इसलिए यह आख़िरी चरण उसी के UI में होता है।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo roo-code --model anthropic/claude-sonnet-5.5
```

CLI एक `Phaseo CLI: Roo Code API Key` बनाता है जो 90 दिनों में समाप्त होती है और जिसकी मासिक खर्च सीमा $100 है, फिर अगले चरण के मान प्रिंट करता है।

## Roo Code कॉन्फ़िगर करें

1. VS Code में Roo Code खोलें, फिर **Settings → Providers**।
2. एक प्रदाता कॉन्फ़िगरेशन प्रोफ़ाइल बनाएँ और **OpenAI Compatible** चुनें।
3. ये मान दर्ज करें:

| Roo Code फ़ील्ड | मान |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | `phaseo integrations credential roo-code` का आउटपुट, या कोई भी Phaseo API कुंजी |
| Model | `anthropic/claude-sonnet-5.5`, या सेटअप द्वारा दिखाया गया मॉडल |

4. प्रोफ़ाइल सेव करें और उसे सक्रिय करें।

फ़ील्ड के लेबल रिलीज़ के बीच थोड़े बदलते हैं; अगर आपके अलग हैं तो Roo Code के [मॉडल प्रदाता](https://docs.roocode.com/providers/) दस्तावेज़ देखें।

## जाँचें कि यह काम करता है

Roo Code से `PHASEO_ROO_OK` के साथ जवाब देने को कहें, फिर पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## Phaseo हटाएँ

Phaseo प्रोफ़ाइल मिटाएँ या प्रोफ़ाइल बदलें, फिर यह चलाएँ:

```bash
phaseo integrations remove roo-code
```

इससे कुंजी रद्द हो जाती है। CLI VS Code का एक्सटेंशन स्टोरेज साफ़ नहीं कर सकता।

## आम समस्याएँ ठीक करें

### ऑथेंटिकेशन विफल होता है

`phaseo integrations credential roo-code` से कुंजी फिर से कॉपी करें, और जाँचें कि Base URL `/v1` पर ख़त्म होता है।

### Roo Code मॉडल नहीं ढूँढ पाता

प्रदाता प्रीफ़िक्स सहित सटीक Phaseo मॉडल ID टाइप करें।

### चैट काम करती है, लेकिन टूल विफल होते हैं

टूल-कॉलिंग सपोर्ट वाले मॉडल पर स्विच करें।
