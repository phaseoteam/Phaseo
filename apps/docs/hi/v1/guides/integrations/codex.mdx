Codex `config.toml` के ज़रिए कस्टम मॉडल प्रदाताओं का समर्थन करता है, इसलिए आप वही CLI, ऐप या IDE वर्कफ़्लो बनाए रखते हुए Codex के अनुरोध Phaseo के माध्यम से रूट कर सकते हैं।

यदि आप यह भी चाहते हैं कि Codex काम करते समय Phaseo के मौजूदा दस्तावेज़ पढ़े, तो [Docs MCP](./docs-mcp.mdx) सर्वर भी जोड़ें।

## Phaseo CLI से सेटअप

```bash
phaseo login
phaseo codex --model openai/gpt-5.6-terra
```

पहले Codex को उसकी आधिकारिक रिलीज़ से इंस्टॉल करें। सेटअप एक बिना समाप्ति वाली `Phaseo CLI: Codex API Key` बनाता है, उसे OS के क्रेडेंशियल स्टोर में रखता है और एक समर्पित Phaseo प्रोफ़ाइल लिखता है। Codex यह कुंजी CLI हेल्पर के ज़रिए लेता है, इसलिए `config.toml` में सादे टेक्स्ट में कोई कुंजी नहीं लिखी जाती।

Codex को इस तरह शुरू करें:

```bash
codex --profile phaseo
```

वही Phaseo CLI प्रक्रिया अलग अस्थायी प्रदाता कॉन्फ़िगरेशन से [Cline](./cline), [Kilo Code](./kilo-code), [oh-my-pi](./oh-my-pi), [Muse Code](./muse-code) और [MiniMax Code](./minimax-code) भी लॉन्च करती है।

## मैन्युअल कॉन्फ़िगरेशन

`~/.codex/config.toml` में अपना उपयोगकर्ता कॉन्फ़िगरेशन बनाएँ या अपडेट करें। किसी भरोसेमंद प्रोजेक्ट के लिए आप यही सेटिंग्स रिपॉज़िटरी के भीतर `.codex/config.toml` में भी रख सकते हैं।

```toml
model = "openai/gpt-5.5"
model_provider = "phaseo"

[model_providers.phaseo]
name = "Phaseo"
base_url = "https://api.phaseo.app/v1"
env_key = "PHASEO_API_KEY"
wire_api = "responses"
```

कस्टम प्रदाताओं के लिए Codex फ़िलहाल Responses वायर प्रोटोकॉल का उपयोग करता है। `wire_api = "responses"` बनाए रखें, या इसे छोड़कर डिफ़ॉल्ट का उपयोग करें।

Codex App और IDE एक्सटेंशन कॉन्फ़िगरेशन की समान परतें साझा करते हैं। IDE एक्सटेंशन में `Codex Settings > Open config.toml` से कॉन्फ़िगरेशन खोलें।

## सत्यापन

- शुरू करने से पहले [मॉडल सूची](../../api-reference/endpoint/models.mdx) में पुष्टि करें कि आपकी मॉडल ID मौजूद है।
- Codex-शैली के डिफ़ॉल्ट प्रवाह के लिए [Responses](../../api-reference/endpoint/responses.mdx) का उपयोग करें।

## समस्या निवारण

- `401 Unauthorized`: `phaseo whoami` चलाएँ, फिर `phaseo codex` दोबारा चलाएँ।
- `model_not_found`: [मॉडल सूची](../../api-reference/endpoint/models.mdx) से मौजूदा ID लें और `model` अपडेट करें।
- प्रदाता-विशिष्ट समस्याएँ: फ़ेलओवर व्यवहार के लिए [रूटिंग और फ़ॉलबैक](../routing-and-fallbacks.mdx) देखें।
