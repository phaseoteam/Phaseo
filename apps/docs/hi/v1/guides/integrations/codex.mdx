Codex में Phaseo प्रोफ़ाइल जोड़ने के लिए `phaseo codex` चलाएँ, या `config.toml` में ख़ुद `phaseo` प्रदाता जोड़ें। यही कॉन्फ़िग Codex CLI, Codex App और Codex IDE एक्सटेंशन में काम करता है।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo codex --model openai/gpt-5.6-terra
codex --profile phaseo
```

अगर Codex इंस्टॉल नहीं है, तो CLI आधिकारिक इंस्टॉल कमांड दिखाता है और उसे चलाने से पहले पूछता है। इसके बाद सेटअप एक `Phaseo CLI: Codex API Key` बनाता है जो 90 दिनों में समाप्त होती है और जिसकी मासिक खर्च सीमा $100 है, उसे OS क्रेडेंशियल स्टोर में रखता है, और प्रोफ़ाइल `~/.codex/phaseo.config.toml` (या `CODEX_HOME` के अंदर) में लिखता है। Codex कुंजी CLI से लेता है, जो पुरानी कुंजी समाप्त होने पर नई बना देता है, इसलिए कॉन्फ़िग में कोई सादा-टेक्स्ट कुंजी नहीं लिखी जाती। `--model` के बिना प्रोफ़ाइल `openai/gpt-5.6-terra` इस्तेमाल करती है।

## Codex को मैन्युअल रूप से कॉन्फ़िगर करें

इसे `~/.codex/config.toml` में, या किसी भरोसेमंद प्रोजेक्ट की `.codex/config.toml` में जोड़ें:

```toml
model = "openai/gpt-6-astra"
model_provider = "phaseo"

[model_providers.phaseo]
name = "Phaseo"
base_url = "https://api.phaseo.app/v1"
env_key = "PHASEO_API_KEY"
wire_api = "responses"
```

फिर `PHASEO_API_KEY` एक्सपोर्ट करें और Codex शुरू करें। Codex के कस्टम प्रदाता Responses वायर प्रोटोकॉल इस्तेमाल करते हैं, जो डिफ़ॉल्ट है, इसलिए आप `wire_api` छोड़ भी सकते हैं। IDE एक्सटेंशन में फ़ाइल **Codex Settings → Open config.toml** से खोलें।

## जाँचें कि यह काम करता है

एक छोटा प्रॉम्प्ट भेजें और पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है। Codex [Responses](../../api-reference/endpoint/responses.mdx) को कॉल करता है, इसलिए मॉडल को वह एंडपॉइंट सपोर्ट करना चाहिए।

## Phaseo हटाएँ

```bash
phaseo integrations remove codex
```

अगर `phaseo.config.toml` Phaseo ने बनाई थी, तो यह उसे मिटा देता है और कुंजी रद्द कर देता है। मैन्युअल सेटअप में `config.toml` से `phaseo` प्रदाता हटा दें।

## आम समस्याएँ ठीक करें

| त्रुटि | समाधान |
| --- | --- |
| `401 Unauthorized` | `phaseo whoami` चलाएँ, फिर `phaseo codex` दोबारा चलाएँ। |
| `model_not_found` | [मॉडल](../../api-reference/endpoint/models.mdx) से मौजूदा ID लें और `model` अपडेट करें। |
| कोई प्रदाता विफल होता है | फ़ेलओवर के लिए [रूटिंग और फ़ॉलबैक](../routing-and-fallbacks.mdx) देखें। |

## Phaseo स्किल और दस्तावेज़ जोड़ें

काम करते समय Codex को Phaseo के लाइव दस्तावेज़ पढ़ने देने के लिए [Docs MCP](./docs-mcp.mdx) सर्वर जोड़ें। Codex के लिए सार्वजनिक [Phaseo स्किल](https://phaseo.app/docs/.well-known/agent-skills/index.json) इंस्टॉल करने के लिए:

```bash
npx skills add https://phaseo.app/docs --agent codex --skill '*'
```

यही CLI वर्कफ़्लो [Cline](./cline.mdx), [Kilo Code](./kilo-code.mdx), [oh-my-pi](./oh-my-pi.mdx), [Muse Code](./muse-code.mdx) और [MiniMax Code](./minimax-code.mdx) को अस्थायी सेटिंग्स के साथ लॉन्च करता है।
