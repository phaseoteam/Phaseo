Replit से Phaseo इस्तेमाल करने के लिए आधिकारिक OpenAI SDK या Phaseo का अपना AI SDK प्रदाता इस्तेमाल करें। API कुंजी को सोर्स कोड के बजाय Replit Secrets में रखें।

## गोपनीय कुंजी जोड़ें

अपने Replit वर्कस्पेस में **Tools → Secrets** खोलें और यह जोड़ें:

```text
PHASEO_API_KEY=phaseo_v1_sk_...
```

यह गोपनीय कुंजी आपके ऐप्लिकेशन को एनवायरनमेंट वैरिएबल के रूप में उपलब्ध होगी।

## OpenAI SDK के साथ TypeScript

```bash
npm install openai
```

```ts
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-5-nano",
	input: "Reply with only: ok",
});

console.log(response.output_text);
```

## AI SDK के साथ TypeScript

```bash
npm install @phaseo/ai-sdk-provider
```

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const { text } = await generateText({
	model: phaseo("openai/gpt-5-nano"),
	prompt: "Reply with only: ok",
});

console.log(text);
```

## डिप्लॉयमेंट

डेवलपमेंट वर्कस्पेस के साथ-साथ डिप्लॉयमेंट की गोपनीय कुंजियों में भी `PHASEO_API_KEY` जोड़ें। पुष्टि करें कि डिप्लॉयमेंट एनवायरनमेंट वैरिएबल या अनुरोध हेडर लॉग में प्रिंट न करे।
