`https://api.phaseo.app/v1` पर इशारा करने वाले `OpenAIProvider` के साथ एक `OpenAIChatModel` बनाएँ, और PydanticAI एजेंट Phaseo मॉडल पर चलते हैं।

## इंस्टॉल करें

```bash
pip install "pydantic-ai-slim[openai]"
```

## PydanticAI को Phaseo पर ले जाएँ

```python
import os
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-6-astra",
    provider=OpenAIProvider(
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)

agent = Agent(model, system_prompt="Answer concisely.")
result = agent.run_sync("Reply with only: ok")
print(result.output)
```

`ok` प्रिंट होने का मतलब है कि सेटअप काम करता है।

## ज्ञात सीमाएँ

- यह तरीका OpenAI-शैली Chat Completions इस्तेमाल करता है। `phaseo:apply_patch` जैसी सिर्फ़-Responses सुविधाओं के लिए Phaseo के Responses एंडपॉइंट को सीधे कॉल करें।
- [संरचित आउटपुट](../structured-outputs.mdx) स्कीमा इतने छोटे रखें कि वे मॉडल की कॉन्टेक्स्ट विंडो में आ जाएँ। सीमाएँ [मॉडल](../../api-reference/endpoint/models.mdx) में जाँचें।
