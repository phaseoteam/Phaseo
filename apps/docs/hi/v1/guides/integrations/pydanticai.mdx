टाइप्ड आउटपुट, सत्यापन और संक्षिप्त OpenAI-संगत मॉडल सेटअप वाले Python एजेंट बनाने के लिए PydanticAI इस्तेमाल करें।

## इंस्टॉल करें

```bash
pip install "pydantic-ai-slim[openai]"
```

## मॉडल कॉन्फ़िगर करें

```python
import os
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-5-nano",
    provider=OpenAIProvider(
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)

agent = Agent(model, system_prompt="Answer concisely.")
result = agent.run_sync("Reply with only: ok")
print(result.output)
```

## नोट्स

- PydanticAI का OpenAI-संगत तरीका OpenAI-शैली का चैट व्यवहार इस्तेमाल करता है।
- `phaseo:apply_patch` जैसी केवल Responses में उपलब्ध सुविधाओं के लिए Phaseo Responses API को सीधे कॉल करें।
- संरचित आउटपुट स्कीमा इतने छोटे रखें कि वे चुने गए मॉडल की कॉन्टेक्स्ट विंडो में समा सकें।
