`phaseo login` चलाएँ, फिर किसी कोडिंग एजेंट को उसकी अपनी API कुंजी के साथ Phaseo पर ले जाने के लिए `phaseo <agent>` चलाएँ। CLI छोड़ना हो तो एजेंट की सेटिंग्स में [मैन्युअल प्रदाता मान](#enter-the-provider-values-yourself) दर्ज करें।

```bash
phaseo login
phaseo codex
```

## अपने एजेंट के लिए कमांड ढूँढें

CLI हर एजेंट को इन तीन में से किसी एक तरीके से सेट अप करता है:

- **कॉन्फ़िगर किया गया**: CLI एजेंट की कॉन्फ़िग फ़ाइल लिखता है। एजेंट शुरू करें और कोई Phaseo मॉडल चुनें।
- **सिर्फ़ कुंजी**: एजेंट कुंजियाँ अपने ऐप स्टोरेज में रखता है, इसलिए CLI कुंजी बनाता है और भरने वाले फ़ील्ड दिखाता है।
- **सत्र**: CLI एजेंट को अस्थायी सेटिंग्स के साथ लॉन्च करता है, जो उसके बंद होने पर मिट जाती हैं। आपका सामान्य कॉन्फ़िग नहीं छुआ जाता।

| Pi | `phaseo pi` | कॉन्फ़िगर किया गया | [Pi](./pi.mdx) |

## CLI क्या बनाता है

हर एजेंट को उसके नाम वाली अपनी API कुंजी मिलती है (उदाहरण के लिए `Phaseo CLI: Codex API Key`), जिसकी मासिक खर्च सीमा $100 है और जो 90 दिनों में समाप्त होती है। हर नई कुंजी आप CLI द्वारा खोले गए डैशबोर्ड पेज पर स्वीकृत करते हैं, फिर CLI उसे एक बार ले लेता है; देखें [ब्राउज़र में कुंजी स्वीकृत करें](./phaseo-cli.mdx#approve-the-key-in-your-browser)। समाप्त कुंजी बदलने के लिए सेटअप कमांड दोबारा चलाएँ, और सीमा डैशबोर्ड में **सेटिंग्स → API कुंजियां** में बदलें।

अगर Claude Code, Codex, OpenCode, fx, DeepSeek Harness, Pi, Prime Agent, OpenClaw या Hermes Agent इंस्टॉल नहीं है, तो CLI आधिकारिक इंस्टॉल कमांड दिखाता है और उसे चलाने से पहले पूछता है। इंटरैक्टिव टर्मिनल के बाहर यह इंस्टॉल कमांड प्रिंट करके रुक जाता है। OpenCode, fx, DeepSeek Harness, Pi, Prime Agent और OpenClaw को Chat Completions के साथ काम करने वाला हर सक्रिय Phaseo टेक्स्ट मॉडल भी मिलता है।

| फ़्लैग या कमांड | असर |
| --- | --- |
| `--model <id>` | डिफ़ॉल्ट मॉडल सेट करता है। Claude Code के लिए समर्थित नहीं। |
| `--catalog default` | पूरे कैटलॉग की जगह सिर्फ़ चुना गया मॉडल जोड़ता है। |
| `--skip-install` | इंस्टॉल जाँच छोड़ देता है, उस एजेंट के लिए जिसे आप ख़ुद संभालते हैं। |
| `--dry-run` | फ़ाइल बदलाव किए बिना उन्हें दिखाता है। |
| `--key <key>` | नई कुंजी मांगने के बजाय डैशबोर्ड में बनाई गई कुंजी का उपयोग करता है। `--key-stdin` उसे स्टैंडर्ड इनपुट से पढ़ता है। |
| `phaseo integrations credential <agent>` | उस एजेंट की कुंजी प्रिंट करता है, उन एजेंट के लिए जिनमें आप उसे पेस्ट करते हैं। |
| `phaseo integrations remove <agent>` | Phaseo द्वारा लिखा गया कॉन्फ़िगरेशन मिटाता है और कुंजी रद्द करता है। आपकी बाकी सेटिंग्स बनी रहती हैं। |

## प्रदाता मान ख़ुद दर्ज करें

OpenAI-संगत प्रदाता वाले किसी भी एजेंट में ये मान इस्तेमाल करें। फ़ील्ड के नाम टूल के हिसाब से अलग होते हैं।

| सेटिंग | मान |
| --- | --- |
| प्रदाता प्रकार | OpenAI Compatible |
| Base URL | `https://api.phaseo.app/v1` |
| API कुंजी | एक Phaseo API कुंजी |
| मॉडल | एक Phaseo मॉडल ID, जैसे `openai/gpt-6-astra` |

Anthropic Messages API इस्तेमाल करने वाले एजेंट के लिए:

| सेटिंग | मान |
| --- | --- |
| Base URL | `https://api.phaseo.app` (क्लाइंट `/v1/messages` जोड़ता है) |
| ऑथ टोकन | एक Phaseo API कुंजी |
| मॉडल | एक Phaseo मॉडल ID, जैसे `anthropic/claude-sonnet-5.5` |

कुछ एजेंट `/` वाले मॉडल ID अस्वीकार करते हैं। अगर आपका एजेंट ऐसा करता है और उपनाम (alias) सपोर्ट करता है, तो एक लोकल उपनाम बनाएँ जो Phaseo मॉडल ID से जुड़ा हो।

## जिन एजेंट की अपनी गाइड नहीं है

### VS Code

अगर आपके बिल्ड में OpenAI-संगत प्रदाता शामिल है, तो VS Code अपने Language Models एडिटर में मॉडल जोड़ सकता है।

1. Command Palette खोलें और `Chat: Manage Language Models` चलाएँ।
2. `OpenAI Compatible` या `OAI Compatible` चुनें।
3. अपनी Phaseo API कुंजी दर्ज करें और एंडपॉइंट `https://api.phaseo.app/v1` पर सेट करें।
4. एक Phaseo मॉडल ID जोड़ें, जैसे `openai/gpt-6-astra`, और उसे चैट मॉडल पिकर में चुनें।

अगर आपके बिल्ड में OpenAI-संगत प्रदाता नहीं है, तो कस्टम प्रदाता सपोर्ट करने वाला एक्सटेंशन इस्तेमाल करें: [Continue](./continue.mdx), [Cline](./cline.mdx), [Roo Code](./roo-code.mdx) या [Kilo Code](./kilo-code.mdx)।

### Claude Desktop

Claude Desktop कस्टम मॉडल प्रदाता इस्तेमाल नहीं कर सकता। उसे Phaseo दस्तावेज़ देने के लिए [Docs MCP](./docs-mcp.mdx) जोड़ें, और जब Phaseo को मॉडल गेटवे के रूप में चाहिए तो [Claude Code](./claude-code.mdx) इस्तेमाल करें।

### Deep Agents CLI और अन्य LangChain टूल

[LangChain](./langchain.mdx) से base URL और कुंजी इस्तेमाल करें। अगर टूल OpenAI एनवायरनमेंट वेरिएबल पढ़ता है, तो इन्हें सेट करें और उसके मॉडल फ़ील्ड में Phaseo मॉडल ID दें:

```bash
export OPENAI_API_KEY="your_phaseo_api_key"
export OPENAI_BASE_URL="https://api.phaseo.app/v1"
```

## ज्ञात सीमाएँ

- सर्वर टूल सिर्फ़ वहीं काम करते हैं जहाँ एजेंट उन्हें भेजता है: `phaseo:apply_patch` सिर्फ़ [Responses](../../api-reference/endpoint/responses.mdx) पर उपलब्ध है। जो पुराने एजेंट Responses इवेंट या [सर्वर टूल](../server-tools/index.mdx) नहीं संभालते, उनके लिए [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) ज़्यादा सुरक्षित है।
- किसी एजेंट को फ़ाइलें संपादित करने देने से पहले एक छोटा चैट अनुरोध भेजें, और एजेंट के काम के लिए टूल-कॉलिंग सपोर्ट वाला मॉडल चुनें।
- अगर आप चाहते हैं कि एजेंट सत्र के दौरान Phaseo दस्तावेज़ पढ़े, तो [Docs MCP](./docs-mcp.mdx) जोड़ें।
