इस गाइड से कोडिंग एजेंट को Phaseo से जोड़ें। प्रबंधित क्रेडेंशियल और कॉन्फ़िगरेशन के लिए Phaseo CLI चुनें, या एजेंट के अंदर सेटअप रखने के लिए मैन्युअल प्रदाता मान इस्तेमाल करें।

## सेटअप चुनें

| आप चाहते हैं… | इस्तेमाल करें |
| --- | --- |
| अलग अस्थायी सेटिंग के साथ Cline, Kilo Code, oh-my-pi, Muse Code या MiniMax Code चलाना | `phaseo cline`, `phaseo kilo`, `phaseo omp`, `phaseo muse`, या `phaseo minimax` |
| इंस्टॉल एजेंट को सेट करना और उसकी सेटिंग रखना | `phaseo <integration>` |
| Phaseo CLI के बिना एजेंट सेट करना | विशिष्ट गाइड में मैन्युअल प्रदाता चरण अपनाएँ |

## Phaseo CLI से सेटअप करें

एक बार साइन इन करें, फिर अपना कोडिंग हार्नेस कॉन्फ़िगर करें:

```bash
phaseo login
phaseo codex
```

यह कमांड जाँचता है कि हार्नेस इंस्टॉल है या नहीं। इंटरैक्टिव टर्मिनल में हार्नेस न होने पर Phaseo समर्थित इंस्टॉल कमांड दिखाता है और चलाने से पहले अनुमति माँगता है। इसके बाद Phaseo हार्नेस के लिए समर्पित कुंजी बनाकर उसका कॉन्फ़िगरेशन लिखता है। नॉन-इंटरैक्टिव रन बिना निगरानी सिस्टम में बदलाव किए उपयोगी इंस्टॉलेशन निर्देश दिखाते हैं। OpenCode, DeepSeek Harness, Pi, Prime Agent और OpenClaw को Chat Completions के अनुकूल सभी सक्रिय टेक्स्ट मॉडल भी मिलते हैं। दायरा सीमित करने के लिए `--skip-install`, `--catalog default` या `--dry-run` उपयोग करें।

हर स्थायी एकीकरण के लिए उत्पाद-नाम वाला कमांड इस्तेमाल करें:

```bash
phaseo codex
```

Supported integration names are `codex`, `claude-code`, `opencode`, `deepseek-harness`, `pi`, `openclaw`, `hermes`, `aider`, `cline`, `roo-code`, `kilo-code`, `continue`, `cursor`, and `zed`. अलग CLI रनर `cline`, `kilo`, `omp`, `muse` और `minimax` हैं।

CLI हर असिस्टेंट के नाम वाली अलग, बिना समाप्ति की API key बनाती है। नई इंस्टॉलेशन पर यह Aider और Continue को अपने आप कॉन्फ़िगर करती है और Zed की provider/model सेटिंग भी लिखती है। जो असिस्टेंट सीक्रेट सिर्फ़ एडिटर UI में रखते हैं, उनके लिए यह बाकी फ़ील्ड दिखाती है, संबंधित गाइड लिंक करती है और केवल उसी असिस्टेंट की key कॉपी करने देती है:

```bash
phaseo integrations credential codex
```

सेटअप से पहले फ़ाइल बदलावों का पूर्वावलोकन करें और बाद में साफ़ तरीके से डिस्कनेक्ट करें:

```bash
phaseo codex --dry-run
phaseo integrations remove codex
```

हटाने पर Phaseo की कॉन्फ़िगरेशन मिटती है और उस असिस्टेंट की key रद्द होती है। असंबंधित सेटिंग नहीं हटतीं。

## मैन्युअल प्रदाता सेटिंग

जब तक टूल किसी अन्य फ़ील्ड नाम की माँग न करे, इन मानों का उपयोग करें:

| सेटिंग | मान |
| --- | --- |
| प्रदाता प्रकार | OpenAI Compatible |
| Base URL | `https://api.phaseo.app/v1` |
| API key | आपकी Phaseo API key |
| मॉडल | जैसे `openai/gpt-5-nano` एक Phaseo मॉडल ID |

Anthropic-संगत टूल के लिए यह उपयोग करें:

| सेटिंग | मान |
| --- | --- |
| Base URL | `https://api.phaseo.app` |
| प्रमाणीकरण टोकन | आपकी Phaseo API key |
| मॉडल | Phaseo मॉडल ID, जैसे `anthropic/claude-sonnet-4.5` |

## Cursor

Cursor, OpenAI API key सेटिंग के ज़रिए कस्टम OpenAI-संगत endpoint सपोर्ट करता है।

1. Cursor Settings खोलें।
2. `Models` पर जाएँ।
3. `OpenAI API Key` प्रविष्टि सक्षम करें या जोड़ें।
4. अपनी Phaseo API key पेस्ट करें।
5. `Override OpenAI Base URL` सक्षम करें।
6. Base URL को `https://api.phaseo.app/v1` पर सेट करें।
7. Phaseo मॉडल ID, जैसे `openai/gpt-5-nano` का उपयोग करके कस्टम मॉडल जोड़ें।
8. मॉडल सक्षम करें और Cursor मॉडल पिकर में इसकी जाँच करें।

Cursor द्वारा `/` वाली मॉडल ID अस्वीकार करने पर, UI में उपलब्ध निकटतम स्थानीय alias बनाएँ और यदि client alias सपोर्ट करता हो, तो अपनी config में उसे Phaseo मॉडल की ओर रूट करें।

## VS Code

यदि आपके VS Code या Insiders बिल्ड में OpenAI-संगत प्रदाता उपलब्ध है, तो VS Code के Language Models एडिटर में मॉडल जोड़ सकते हैं।

1. Command Palette खोलें।
2. `Chat: Manage Language Models` चलाएँ।
3. `OpenAI Compatible` या `OAI Compatible` चुनें।
4. अपनी Phaseo API key दर्ज करें।
5. endpoint या base URL को `https://api.phaseo.app/v1` पर सेट करें।
6. Phaseo मॉडल ID जोड़ें, जैसे `openai/gpt-5-nano`।
7. चैट मॉडल पिकर से नया मॉडल चुनें।

यदि आपके VS Code बिल्ड में OpenAI-संगत प्रदाता नहीं दिखता, तो Continue, Cline, Roo Code या Kilo Code जैसे कस्टम प्रदाता सपोर्ट करने वाले एक्सटेंशन का उपयोग करें।

## Continue

Continue, कस्टम API base के साथ अपने OpenAI प्रदाता से Phaseo उपयोग कर सकता है।

```yaml
name: Phaseo
version: 0.0.1
schema: v1

models:
  - name: Phaseo GPT-5 Nano
    provider: openai
    model: openai/gpt-5-nano
    apiKey: ${{ secrets.PHASEO_API_KEY }}
    apiBase: https://api.phaseo.app/v1
    roles:
      - chat
      - edit
      - apply
```

यदि Continue डिफ़ॉल्ट रूप से Responses चुनता है, लेकिन आपके वर्कफ़्लो को Chat Completions संगतता चाहिए, तो `useResponsesApi: false` सेट करें।

## Cline, Roo Code और Kilo Code

इन टूल में प्रदाता की मिलती-जुलती सेटिंग हैं।

1. एक्सटेंशन सेटिंग खोलें।
2. प्रदाता के रूप में `OpenAI Compatible` चुनें।
3. Base URL को `https://api.phaseo.app/v1` पर सेट करें।
4. अपनी Phaseo API key पेस्ट करें।
5. Phaseo मॉडल ID दर्ज करें।
6. फ़ाइल-संपादन टूल इस्तेमाल करने से पहले सेव करें और एक छोटा चैट अनुरोध चलाएँ।

## Aider

OpenAI-संगत environment variables सेट करें और शुरू करते समय मॉडल दें:

```bash
export OPENAI_API_BASE="https://api.phaseo.app/v1"
export OPENAI_API_KEY="your_phaseo_api_key"
aider --model openai/openai/gpt-5-nano
```

Aider में OpenAI-संगत कस्टम मॉडल के आगे अक्सर `openai/` प्रीफ़िक्स चाहिए। Phaseo मॉडल ID में प्रदाता प्रीफ़िक्स पहले से होते हैं, इसलिए Aider की पूरी मॉडल स्ट्रिंग `openai/openai/gpt-5-nano` जैसी दिख सकती है।

## Pi, Prime Agent, OpenClaw और Hermes Agent

`phaseo pi` एक समर्पित प्रदाता एक्सटेंशन जोड़ता है, जो रनटाइम में Phaseo CLI से key लेता है। `phaseo prime-agent` कमांड-आधारित प्रदाता को `~/.prime/agent/models.json` में लिखता है। दोनों को संगत Phaseo मॉडल कैटलॉग मिलता है। `phaseo openclaw` संगत मॉडल कैटलॉग और exec-आधारित SecretRef रजिस्टर करता है, लेकिन API key को `openclaw.json` में नहीं रखता।

Hermes इंस्टॉल न होने पर `phaseo hermes` आधिकारिक Nous Research इंस्टॉलर चलाने का विकल्प देता है, फिर इंस्टॉल किए गए एजेंट को कॉन्फ़िगर करता है। यह Hermes की पिछली मॉडल सेटिंग सहेजता है, Phaseo को कस्टम endpoint बनाता है और समर्पित key को `~/.hermes/.env` में `OPENAI_API_KEY` के रूप में रखने के लिए Hermes का आधिकारिक `hermes config set` कमांड उपयोग करता है। Hermes प्रदाता क्रेडेंशियल के लिए जानबूझकर इस plaintext फ़ाइल का उपयोग करता है; इसे किसी अन्य API-key फ़ाइल की तरह सुरक्षित रखें। हटाने पर पुरानी मॉडल सेटिंग बहाल होती है, `OPENAI_API_KEY` और Phaseo recovery state हटते हैं और key रद्द होती है।

## MiniMax Code

`mcode` CLI के लिए [MiniMax Code गाइड](./minimax-code.mdx) देखें। `phaseo minimax` Phaseo के OpenAI-संगत एंडपॉइंट से अस्थायी MiniMax प्रदाता बनाता है, CLI चलाता है और सत्र समाप्त होने पर अस्थायी डेटा निर्देशिका हटाता है। संपादक या होस्ट सीधे ACP इस्तेमाल करे तो MiniMax Code `mcode acp` से ACP भी स्वीकार करता है।
## Zed

`phaseo zed` चलाएँ, फिर Zed सेटिंग में OpenAI-संगत प्रदाता जोड़ने के लिए दिखाए गए चरणों का पालन करें। बनाई गई key केवल Zed के क्रेडेंशियल फ़ील्ड में उपयोग करें।

## Codex

Codex CLI, Codex App और Codex IDE एक्सटेंशन के लिए [Codex की विशेष गाइड](./codex.mdx) देखें। संक्षेप में:

```toml
model = "openai/gpt-5.5"
model_provider = "phaseo"

[model_providers.phaseo]
name = "Phaseo"
base_url = "https://api.phaseo.app/v1"
env_key = "PHASEO_API_KEY"
wire_api = "responses"
```

Codex कस्टम प्रदाता Responses wire protocol का उपयोग करते हैं।

## OpenCode

यदि OpenCode से कस्टम OpenAI-संगत प्रदाता के ज़रिए Phaseo कॉल करना चाहते हैं, तो [OpenCode की विशेष गाइड](./opencode.mdx) देखें।

## Claude Code

[Claude Code की विशेष गाइड](./claude-code.mdx) देखें। Claude Code Anthropic-संगत गेटवे environment variables का उपयोग करता है:

```bash
export ANTHROPIC_BASE_URL="https://api.phaseo.app"
export ANTHROPIC_AUTH_TOKEN="your_phaseo_api_key"
export ANTHROPIC_API_KEY=""
```

फिर उसी shell से Claude Code शुरू करें:

```bash
claude
```

## Claude Desktop

Claude Desktop MCP सर्वर सपोर्ट करता है, लेकिन Cursor, Codex या Claude Code जैसे कोडिंग असिस्टेंट की तरह कस्टम मॉडल-प्रदाता सेटअप नहीं देता। Claude Desktop में Phaseo दस्तावेज़ का संदर्भ जोड़ने के लिए [Docs MCP](./docs-mcp.mdx) उपयोग करें। Phaseo को मॉडल गेटवे बनाना हो तो Claude Code उपयोग करें।

## Deep Agents CLI और LangChain टूल

[LangChain](./langchain.mdx) जैसी base URL और API key सेटिंग उपयोग करें। यदि टूल OpenAI environment variables पढ़ता है, तो इन्हें सेट करें:

```bash
export OPENAI_API_KEY="your_phaseo_api_key"
export OPENAI_BASE_URL="https://api.phaseo.app/v1"
```

फिर टूल के मॉडल फ़ील्ड में Phaseo मॉडल ID दें।

## नोट

- मॉडल ID में स्लैश को कोडिंग असिस्टेंट अलग-अलग तरह से संभालते हैं। UI द्वारा `openai/gpt-5-nano` अस्वीकार करने पर, यदि टूल alias सपोर्ट करता है तो स्थानीय alias बनाएँ।
- फ़ाइल-संपादन वर्कफ़्लो सावधानी से जाँचें। `phaseo:apply_patch` केवल Responses पर काम करता है।
- सेशन के दौरान असिस्टेंट को Phaseo दस्तावेज़ पढ़ने देना हो तो [Docs MCP](./docs-mcp.mdx) जोड़ें।
- पुराने कोडिंग टूल में Chat Completions को प्राथमिकता दें, जब तक कि टूल Responses events और server tools का स्पष्ट समर्थन न करे।
