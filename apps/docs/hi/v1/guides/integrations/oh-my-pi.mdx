Phaseo के ज़रिए oh-my-pi सत्र शुरू करने के लिए `phaseo omp` चलाएँ, या हर सत्र में Phaseo रखने के लिए `~/.omp/agent/models.yml` में एक `phaseo` प्रदाता जोड़ें।

## Phaseo CLI के ज़रिए oh-my-pi चलाएँ

```bash
phaseo login
phaseo omp --model openai/gpt-5.6-terra
```

रनर एक समर्पित कुंजी बनाता है, एक अस्थायी `PI_CODING_AGENT_DIR` के अंदर `models.yml` लिखता है, `omp` को `--model phaseo/<model>` के साथ लॉन्च करता है, और oh-my-pi बंद होने पर डायरेक्टरी मिटा देता है। अगर `omp` इंस्टॉल नहीं है, तो पहला इंटरैक्टिव रन उसे इंस्टॉल करने का विकल्प देता है। oh-my-pi के अपने फ़्लैग `--` के बाद लिखें।

| फ़्लैग | असर |
| --- | --- |
| `--model <id>` | इस्तेमाल होने वाला मॉडल। डिफ़ॉल्ट `openai/gpt-5.6-terra` है। |
| `--catalog all` | सिर्फ़ चुने गए मॉडल की जगह हर सक्रिय Phaseo टेक्स्ट मॉडल दिखाता है। |
| `--dry-run --json` | कुंजी बनाए या oh-my-pi शुरू किए बिना इंस्टॉल और लॉन्च की योजना दिखाता है। |
| `--skip-install` | इंस्टॉल जाँच छोड़ देता है। |

`phaseo run omp ...` इसी कमांड का लंबा रूप है।

## oh-my-pi को मैन्युअल रूप से कॉन्फ़िगर करें

डैशबोर्ड में **सेटिंग → API कुंजियाँ** से एक कुंजी बनाएँ, उसे उस शेल में एक्सपोर्ट करें जो oh-my-pi शुरू करता है, और कॉन्फ़िग डायरेक्टरी बनाएँ:

```bash
export PHASEO_OMP_API_KEY="<your Phaseo API key>"
mkdir -p ~/.omp/agent
```

प्रदाता जोड़ें:

```yaml ~/.omp/agent/models.yml
providers:
  phaseo:
    baseUrl: https://api.phaseo.app/v1
    api: openai-completions
    apiKey: PHASEO_OMP_API_KEY
    authHeader: true
    models:
      - id: openai/gpt-5.6-terra
        name: GPT-5.6 Terra via Phaseo
        contextWindow: 32768
        maxTokens: 8192
```

`apiKey` एनवायरनमेंट वेरिएबल का नाम बताता है, इसलिए कुंजी `models.yml` से बाहर रहती है। ज़रूरत के अनुसार `models` के अंदर और एंट्री जोड़ें; ऊपर दी गई सीमाएँ उदाहरण हैं। oh-my-pi को प्रदाता-सहित मॉडल ID के साथ शुरू करें:

```bash
omp --model phaseo/openai/gpt-5.6-terra
```

बाकी फ़ील्ड के लिए oh-my-pi के [प्रदाता कॉन्फ़िगरेशन](https://github.com/can1357/oh-my-pi/blob/main/docs/providers.md) दस्तावेज़ देखें।

## जाँचें कि यह काम करता है

एक छोटा प्रॉम्प्ट भेजें और पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## आम समस्याएँ ठीक करें

### oh-my-pi इंस्टॉल नहीं है

इंस्टॉल को मंज़ूरी देने के लिए कमांड इंटरैक्टिव टर्मिनल में चलाएँ, या oh-my-pi ख़ुद इंस्टॉल करें और `--skip-install` के साथ दोबारा चलाएँ।

### मॉडल सूची में नहीं है

`--catalog all` इस्तेमाल करें, या `--model` के साथ मॉडल ID दें। Phaseo को मॉडल डिस्कवरी की ज़रूरत नहीं है।
