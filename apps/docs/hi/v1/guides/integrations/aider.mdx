Phaseo की ओर इशारा करने वाला Aider कॉन्फ़िग लिखने के लिए `phaseo aider` चलाएँ, या अपनी मौजूदा `.aider.conf.yml` में तीन लाइनें जोड़ें।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo aider --model anthropic/claude-sonnet-5.5
```

अगर `~/.aider.conf.yml` मौजूद नहीं है, तो सेटअप एक `Phaseo CLI: Aider API Key` (90 दिन में एक्सपायर, $100 मासिक खर्च सीमा) बनाता है और यह फ़ाइल लिखता है। `--model` के बिना, यह `anthropic/claude-sonnet-4.6` इस्तेमाल करता है।

```yaml ~/.aider.conf.yml
# Managed by Phaseo CLI
model: openai/anthropic/claude-sonnet-5.5
openai-api-base: https://api.phaseo.app/v1
openai-api-key: "<dedicated Phaseo key>"
```

किसी कस्टम मॉडल को अपने OpenAI-संगत अडैप्टर से भेजने के लिए Aider को `openai/` प्रीफ़िक्स चाहिए। Phaseo को भेजा गया मॉडल फिर भी `anthropic/claude-sonnet-5.5` ही होता है।

<Warning>
कुंजी सादे टेक्स्ट में रखी जाती है, क्योंकि `.aider.conf.yml` Aider की दस्तावेज़ में बताई गई कुंजी जगहों में से एक है। फ़ाइल को सिर्फ़ अपने यूज़र खाते के पढ़ने लायक रखें, और इसे कभी commit न करें।
</Warning>

## Aider को हाथ से कॉन्फ़िगर करें

अगर आपके पास पहले से Aider कॉन्फ़िग है, तो CLI उसे बदले बिना रुक जाता है। ऊपर की तीन सेटिंग उस कॉन्फ़िग में कॉपी करें जिसे आप Aider से लोड करवाना चाहते हैं, और `openai-api-key` के लिए `phaseo integrations credential aider` या कोई भी Phaseo API कुंजी इस्तेमाल करें। Aider `.aider.conf.yml` आपकी होम डायरेक्टरी, रिपॉज़िटरी रूट और मौजूदा डायरेक्टरी से पढ़ता है, और बाद वाली फ़ाइलें प्राथमिकता पाती हैं। Aider के [YAML कॉन्फ़िगरेशन](https://aider.chat/docs/config/aider_conf.html) और [OpenAI-संगत API](https://aider.chat/docs/llms/openai-compat.html) दस्तावेज़ देखें।

## जाँचें कि यह काम करता है

कोई रिपॉज़िटरी खोलें और Aider शुरू करें:

```bash
aider
```

जाँचें कि स्टार्टअप आउटपुट में `openai/anthropic/claude-sonnet-5.5` लिखा है, उससे `PHASEO_AIDER_OK` के साथ जवाब देने को कहें, और पक्का करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

अनजान मॉडल की चेतावनी अनुरोधों को नहीं रोकती। Aider मॉडल मेटाडेटा तभी जोड़ें जब आपको टोकन-सीमा या लागत के सटीक अनुमान चाहिए।

## Phaseo हटाएँ

```bash
phaseo integrations remove aider
```

यह कुंजी रद्द करता है और `~/.aider.conf.yml` को तभी मिटाता है जब फ़ाइल अब भी Phaseo CLI मार्कर से शुरू होती हो। अगर आपने सेटिंग अपनी फ़ाइल में मिलाई हैं, तो तीनों लाइनें खुद हटाएँ।

## आम समस्याएँ ठीक करें

### Aider कोई दूसरा एंडपॉइंट या मॉडल इस्तेमाल करता है

रिपॉज़िटरी रूट या मौजूदा डायरेक्टरी में मौजूद `.aider.conf.yml` आपकी होम डायरेक्टरी वाली फ़ाइल को ओवरराइड करती है। एनवायरनमेंट वैरिएबल और कमांड-लाइन विकल्प इन सबको ओवरराइड करते हैं।

### ऑथेंटिकेशन विफल होता है

`openai-api-key` की तुलना `phaseo integrations credential aider` के आउटपुट से करें, और `openai-api-base` को ठीक `https://api.phaseo.app/v1` रखें।

### मॉडल पहचाना नहीं जा सकता

Aider का `openai/` प्रीफ़िक्स रखें। Phaseo मॉडल `openai/gpt-6-astra` Aider में `openai/openai/gpt-6-astra` बन जाता है।
