हर संगत Phaseo मॉडल वाला Phaseo प्रदाता Prime Agent में जोड़ने के लिए `phaseo prime-agent` चलाएँ। Prime Agent macOS और Linux पर चलता है; Windows पर इसे WSL के अंदर इंस्टॉल करें और सेटअप वहीं चलाएँ।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo prime-agent
```

अगर Prime Agent इंस्टॉल नहीं है, तो CLI आधिकारिक इंस्टॉलर कमांड दिखाता है और उसे चलाने से पहले पूछता है। इसके बाद सेटअप एक `Phaseo CLI: Prime Agent API Key` (90 दिन में समाप्ति, $100 मासिक खर्च सीमा) बनाता है और `~/.prime/agent/models.json` में एक `phaseo` प्रदाता लिखता है। प्रदाता Chat Completions के साथ काम करने वाले हर सक्रिय Phaseo टेक्स्ट मॉडल की सूची रखता है।

| फ़्लैग | असर |
| --- | --- |
| `--model <id>` | शुरुआती मॉडल सेट करता है। डिफ़ॉल्ट `anthropic/claude-sonnet-4.6` है। |
| `--catalog default` | सिर्फ़ चुना गया मॉडल जोड़ता है। |
| `--dry-run` | फ़ाइल बदलाव किए बिना उन्हें दिखाता है। |

प्रदाता Prime Agent के कमांड-आधारित कुंजी फ़ॉर्मेट से अनुरोध के समय कुंजी लेता है, इसलिए फ़ाइल में कोई सादा-टेक्स्ट कुंजी नहीं लिखी जाती:

```text
!phaseo integrations credential prime-agent
```

## जाँचें कि यह काम करता है

```bash
prime-agent
```

`/model` खोलें, `phaseo` प्रदाता चुनें, और एक छोटा प्रॉम्प्ट भेजें। पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## Phaseo हटाएँ

```bash
phaseo integrations remove prime-agent
```

यह सिर्फ़ Phaseo प्रदाता हटाता है और कुंजी रद्द करता है।
