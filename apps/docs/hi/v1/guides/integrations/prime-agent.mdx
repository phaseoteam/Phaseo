## Phaseo CLI से सेटअप करें

प्रोडक्शन के लिए तैयार इन कमांड के लिए Phaseo खाते की ज़रूरत है; साइन-इन और सेटअप के दौरान CLI गेटवे के लिए एक अलग क्रेडेंशियल बनाता है।

```bash
phaseo login
phaseo prime-agent
```

पहले Prime Agent को उसकी आधिकारिक रिलीज़ से इंस्टॉल करें। सेटअप `~/.prime/agent/models.json` में प्रबंधित `phaseo` प्रदाता लिखता है। यह प्रदाता Chat Completions के साथ संगत सभी सक्रिय Phaseo टेक्स्ट मॉडल उपलब्ध कराता है और अनुरोध के समय Phaseo CLI से अपनी समर्पित API कुंजी प्राप्त करता है।

Prime Agent अभी macOS और Linux पर समर्थित है। Windows पर, WSL के अंदर एक्ज़ीक्यूटेबल इंस्टॉल करने के बाद वहीं सेटअप चलाएँ।

शुरुआती कैटलॉग एंट्री चुनें या ज़रूरत हो तो केवल एक मॉडल कॉन्फ़िगर करें:

```bash
phaseo prime-agent --model anthropic/claude-sonnet-4.6
phaseo prime-agent --catalog default
```

## शुरू करें और जाँचें

```bash
prime-agent
```

`/model` खोलें, `phaseo` प्रदाता चुनें और एक छोटा प्रॉम्प्ट भेजें। जनरेट किया गया प्रदाता Prime Agent के समर्थित कमांड-आधारित कुंजी फ़ॉर्मैट का उपयोग करता है:

```text
!phaseo integrations credential prime-agent
```

केवल Phaseo के स्वामित्व वाले प्रदाता को हटाने और उसकी समर्पित कुंजी रद्द करने के लिए यह चलाएँ:

```bash
phaseo integrations remove prime-agent
```
