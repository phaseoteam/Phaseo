कुंजी बनाने के लिए `phaseo cursor` चलाएँ, फिर Cursor की OpenAI API कुंजी और **Override OpenAI Base URL** सेटिंग्स चालू करें। इससे Cursor के चैट मॉडल Phaseo के ज़रिए रूट होते हैं; जो सुविधाएँ Cursor के अपने मॉडल इस्तेमाल करती हैं, जैसे टैब कम्प्लीशन, वे Cursor के इंफ्रास्ट्रक्चर का इस्तेमाल जारी रख सकती हैं।

## Phaseo CLI से सेट अप करें

```bash
phaseo login
phaseo cursor --model openai/gpt-5.6-terra
```

CLI एक `Phaseo CLI: Cursor API Key` बनाता है जो 90 दिनों में समाप्त होती है और जिसकी मासिक खर्च सीमा $100 है, और नीचे दी गई सेटिंग्स प्रिंट करता है। कुंजी समाप्त होने के बाद नई कुंजी के लिए `phaseo cursor` दोबारा चलाएँ। CLI Cursor के क्रेडेंशियल स्टोर में बदलाव नहीं करता।

## Cursor कॉन्फ़िगर करें

1. **Cursor Settings → Models** खोलें।
2. **OpenAI API Key** सेक्शन ढूँढें और उसे चालू करें।
3. `phaseo integrations credential cursor` से मिली कुंजी, या कोई भी Phaseo API कुंजी पेस्ट करें।
4. **Override OpenAI Base URL** चालू करें और आख़िर में स्लैश के बिना `https://api.phaseo.app/v1` दर्ज करें।
5. जो Phaseo मॉडल चाहिए उसे जोड़ें या चालू करें।

| Cursor फ़ील्ड | मान |
| --- | --- |
| OpenAI API Key | `phaseo integrations credential cursor` का आउटपुट |
| Override OpenAI Base URL | `https://api.phaseo.app/v1` |
| Model | ऐसा Phaseo मॉडल ID जिसे Cursor स्वीकार करे |

Cursor की कुंजी और Base URL सेटिंग्स ग्लोबल हैं, हर प्रदाता के लिए अलग नहीं: चालू की गई कुंजी और Base URL तय करते हैं कि हर OpenAI-परिवार अनुरोध कहाँ जाता है, और मॉडल का नाम जैसा है वैसा आगे भेजा जाता है। कुछ रिलीज़ **Verify** बटन के बिना कुंजी सेव कर लेती हैं; ऐसे में नई चैट से जाँच करें। Cursor के [API कुंजी दस्तावेज़](https://docs.cursor.com/settings/api-keys) देखें।

## जाँचें कि यह काम करता है

1. कुंजी और Base URL ओवरराइड चालू रखें।
2. Cursor के मॉडल पिकर में मॉडल चुनें और नई चैट शुरू करें।
3. उससे `PHASEO_CURSOR_OK` के साथ जवाब देने को कहें।
4. पुष्टि करें कि अनुरोध **सेटिंग्स → उपयोग → लॉग्स** में दिखता है।

## Phaseo हटाएँ

**Cursor Settings → Models** में OpenAI API कुंजी और Base URL ओवरराइड बंद करें, फिर कुंजी रद्द करें:

```bash
phaseo integrations remove cursor
```

CLI Cursor का क्रेडेंशियल स्टोरेज साफ़ नहीं कर सकता। अगर कुंजी अब भी कॉन्फ़िगर दिखती है, तो उसे Cursor की Models सेटिंग्स में मिटा दें।

## आम समस्याएँ ठीक करें

### Cursor-होस्टेड मॉडल काम करना बंद कर देते हैं

Cursor Base URL ओवरराइड हर OpenAI-परिवार मॉडल पर लागू करता है। Cursor-होस्टेड मॉडल पर वापस जाने से पहले **Override OpenAI Base URL** बंद करें।

### मॉडल अस्वीकार हो जाता है

Cursor ऐसे ID अस्वीकार कर सकता है जो उसके बिल्ट-इन कैटलॉग से टकराते हैं या उसकी OpenAI-परिवार रूटिंग में फ़िट नहीं होते, और कुछ रिलीज़ प्रदाता प्रीफ़िक्स वाले ID अस्वीकार करती हैं। कोई दूसरा Phaseo मॉडल आज़माएँ जिसे Cursor OpenAI-परिवार कस्टम मॉडल के रूप में स्वीकार करे।

### ऑथेंटिकेशन विफल होता है

`phaseo integrations credential cursor` दोबारा चलाएँ, Cursor में कुंजी बदलें, और जाँचें कि Base URL ठीक `https://api.phaseo.app/v1` है।
