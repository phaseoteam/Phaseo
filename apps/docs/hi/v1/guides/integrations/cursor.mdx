इस गाइड से समर्थित Cursor चैट मॉडल को Phaseo से रूट करें। Phaseo CLI से समर्पित कुंजी बनाएँ और निरस्त करें, फिर Cursor में सेटअप पूरा करें; या अपनी Phaseo कुंजी देकर वही मैन्युअल सेटिंग्स अपनाएँ।

## Phaseo CLI से सेटअप करें

```bash
phaseo login
phaseo cursor --model openai/gpt-5.6-terra
```

Setup बिना expiry वाली `Phaseo CLI: Cursor API Key` बनाकर नीचे की settings दिखाती है। यह Cursor के private credential store को नहीं बदलती।

## Cursor कॉन्फ़िगर करें

1. **Cursor Settings** खोलें।
2. **Models** चुनें।
3. **OpenAI API Key** section ढूँढकर उसे चालू करें।
4. Dedicated key copy करें:

```bash
phaseo integrations credential cursor
```

5. Cursor के OpenAI API key field में key paste करें।
6. **Override OpenAI Base URL** चालू करें।
7. आखिर में slash के बिना `https://api.phaseo.app/v1` दर्ज करें।
8. जिस Phaseo model का उपयोग करना है उसे जोड़ें या चालू करें।

| Cursor field | मान |
| --- | --- |
| OpenAI API Key | `phaseo integrations credential cursor` का आउटपुट |
| Override OpenAI Base URL | `https://api.phaseo.app/v1` |
| Model | Cursor के Model फ़ील्ड द्वारा समर्थित Phaseo मॉडल ID |

Cursor के कस्टम-प्रदाता नियंत्रण अभी हर प्रदाता के लिए अलग होने के बजाय सभी पर लागू होते हैं। मॉडल का नाम कॉन्फ़िगर किए गए एंडपॉइंट को भेजा जाता है, जबकि सक्षम API कुंजी और Base URL अनुरोध का गंतव्य तय करते हैं।

<Warning>
Cursor अभी OpenAI Base URL override को व्यापक रूप से लागू करता है। Phaseo चालू होने पर Cursor-hosted models विफल हों, तो उन पर वापस जाने से पहले override बंद करें। Built-in model names से टकराने वाले या OpenAI-family routing में फिट न होने वाले custom IDs भी Cursor अस्वीकार कर सकता है।
</Warning>

## जाँचें

1. Phaseo key और Base URL override चालू रखें।
2. Cursor के model picker में configured model चुनें।
3. नया chat शुरू करें और `PHASEO_CURSOR_OK` जवाब देने को कहें।
4. Phaseo activity या logs में request दिखने की पुष्टि करें।

Cursor का मानक चैट पथ मुख्य संगतता लक्ष्य है। टैब पूरा करने जैसी सुविधाएँ, जो Cursor-विशिष्ट मॉडलों का उपयोग करती हैं, Cursor के अपने इन्फ़्रास्ट्रक्चर पर निर्भर हो सकती हैं।

## हटाएँ

पहले **Cursor Settings → Models** में OpenAI API कुंजी और Base URL ओवरराइड बंद करें। फिर Phaseo की समर्पित कुंजी रद्द करें:

```bash
phaseo integrations remove cursor
```

हटाने पर Cursor का secure credential storage अपने-आप साफ़ नहीं होता। Key configured दिखे तो Cursor की Models settings से हटाएँ।

## समस्या निवारण

### Cursor पर होस्ट किए गए मॉडल काम करना बंद कर देते हैं

Cursor-hosted model चुनने से पहले **Override OpenAI Base URL** बंद करें। Cursor अभी हर model के लिए custom Base URL अलग नहीं रखता।

### मॉडल अस्वीकार होता है

Cursor द्वारा OpenAI-family custom model के रूप में स्वीकार किया जाने वाला Phaseo model आज़माएँ। Built-in catalog से टकराने वाले IDs अस्वीकार हो सकते हैं, और कुछ releases provider prefix वाले IDs नहीं लेते।

### सत्यापन बटन नहीं दिखता

कुछ Cursor versions अलग Verify action के बिना key save करते हैं। Key और Base URL दर्ज करें, फिर नए chat में जाँचें।

### प्रमाणीकरण विफल होता है

`phaseo integrations credential cursor` फिर चलाएँ, Cursor में सहेजी value बदलें और सुनिश्चित करें कि Base URL ठीक `https://api.phaseo.app/v1` हो।
