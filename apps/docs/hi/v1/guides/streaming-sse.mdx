सभी streaming endpoints SSE-style frames उपयोग करते हैं:

`data: <json-or-sentinel>`

## आम frame sequence

1. एक या अधिक progress/delta frames।
2. Final status और usage वाला completion frame।
3. `data: [DONE]` sentinel।

## JavaScript पार्सर का उदाहरण

```typescript
for await (const line of client.streamText({
  model: "openai/gpt-5-nano",
  messages: [{ role: "user", content: "Say hello." }],
  stream: true,
})) {
  if (!line.startsWith("data:")) continue;
  const payload = line.slice(5).trim();
  if (payload === "[DONE]") break;
  console.log(payload);
}
```

## Python पार्सर का उदाहरण

```python
for line in client.stream_response({
    "model": "openai/gpt-5-nano",
    "input": "Say hello.",
    "stream": True,
}):
    if not line.startswith("data:"):
        continue
    payload = line[5:].strip()
    if payload == "[DONE]":
        break
    print(payload)
```

## एंडपॉइंट प्रारूप के बारे में

- `/v1/chat/completions`: `choices[].delta` शैली के खंडित इवेंट।
- `/v1/responses`: Responses-शैली के आउटपुट आइटम/डेल्टा इवेंट।
- `/v1/messages`: Anthropic-शैली के इवेंट (`message_start`, `content_block_delta`, `message_stop`)।
