## पहला integration

Phaseo के साथ पहला integration कर रहे हैं, तो ये steps क्रम से अपनाएँ:

1. [त्वरित शुरुआत](../quickstart.mdx): एक सफल request भेजें।
2. [प्रमाणीकरण](../developers/authentication.mdx): keys सुरक्षित रूप से store और भेजें।
3. [उदाहरण](./examples.mdx): request patterns को अपनी app में copy करें।

<Note>
Credits जमा किए बिना `:free` models call कर सकते हैं। Paid models के लिए wallet में उपलब्ध balance ज़रूरी है।
</Note>
