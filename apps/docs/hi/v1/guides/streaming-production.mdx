Prototype से production पर जाते समय इन patterns का उपयोग करें।

## विश्वसनीयता जाँच-सूची

- Client-side timeout और cancellation controls सेट करें।
- `429` और `5xx` को exponential backoff के साथ handle करें।
- Disconnected streams को retry योग्य मानें।
- Correctness अहम हो, तो partial text केवल completion के बाद persist करें।

## Browser/Node में रद्द करने का उदाहरण

```typescript
const controller = new AbortController();
const timeout = setTimeout(() => controller.abort(), 30_000);

try {
  const response = await fetch("https://api.phaseo.app/v1/chat/completions", {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "openai/gpt-5-nano",
      messages: [{ role: "user", content: "Stream a short summary." }],
      stream: true,
    }),
    signal: controller.signal,
  });
  // Parse SSE frames from response.body here.
} finally {
  clearTimeout(timeout);
}
```

## UI संबंधी मार्गदर्शन

- Token deltas को धीरे-धीरे render करें।
- `[DONE]` आने पर स्पष्ट “generation ended” state दिखाएँ।
- Replay/debugging के लिए request ID और model ID logs में रखें।

## स्ट्रीमिंग कब न करें

- मौजूदा request validation में tool-calling flows (`stream + tools` अस्वीकार होता है)।
- ऐसे workflows जिन्हें user-visible output से पहले पूरी validation चाहिए।
