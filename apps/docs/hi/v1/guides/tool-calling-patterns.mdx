टूल कॉलिंग को नियतात्मक और डीबग करने योग्य रखने के लिए ये पैटर्न अपनाएँ।

## पैटर्न 1: Chat Completions चक्र

1. उपयोगकर्ता का संदेश और टूल परिभाषाएँ भेजें।
2. अगर `finish_reason` का मान `tool_calls` हो, तो हर टूल कॉल निष्पादित करें।
3. टूल आउटपुट को `role: "tool"` संदेशों के रूप में वापस भेजें।
4. असिस्टेंट का अंतिम उत्तर पढ़ें।

### अनुरोध (आगे की कड़ी)

```json
{
  "model": "openai/gpt-5-nano",
  "messages": [
    { "role": "user", "content": "What is the weather in Seattle?" },
    {
      "role": "assistant",
      "content": null,
      "tool_calls": [
        {
          "id": "call_123",
          "type": "function",
          "function": {
            "name": "get_weather",
            "arguments": "{\"city\":\"Seattle\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_123",
      "content": "72F and sunny"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    }
  ]
}
```

## पैटर्न 2: Responses चक्र

`/v1/responses` में मॉडल के टूल कॉल `function_call` प्रकार के आउटपुट आइटम के रूप में दिखते हैं।
फिर `function_call_output` इनपुट आइटम के साथ अनुवर्ती अनुरोध भेजें।

### अनुरोध (अनुवर्ती)

```json
{
  "model": "openai/gpt-5-nano",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [{ "type": "input_text", "text": "What's the weather in Seattle?" }]
    },
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Seattle\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "72F and sunny"
    }
  ]
}
```

## एंडपॉइंट चुनें

- अगर आप पहले से OpenAI-शैली के संदेश चक्र इस्तेमाल करते हैं, तो `/v1/chat/completions` को प्राथमिकता दें।
- अगर आपका ऐप Responses API पर मानकीकृत है, तो `/v1/responses` को प्राथमिकता दें।
- अगर आपका ऐप Anthropic-नेटिव है, तो `/v1/messages` इस्तेमाल करें।
