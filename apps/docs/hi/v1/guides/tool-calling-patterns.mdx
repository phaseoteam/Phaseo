description: "Chat Completions और Responses एंडपॉइंट के लिए भरोसेमंद टूल-कॉलिंग लूप।"
---

मॉडल के किसी टूल को कॉल करने के बाद, एक अगला अनुरोध भेजें जिसमें बातचीत, मॉडल की कॉल और आपके टूल का नतीजा दोहराया गया हो। फिर मॉडल अपना जवाब लिखता है, या कोई दूसरा टूल कॉल करता है और आप यही दोहराते हैं। वह एंडपॉइंट इस्तेमाल करें जिसका मैसेज फ़ॉर्मेट आपका ऐप पहले से इस्तेमाल करता है: OpenAI-शैली के मैसेज लूप के लिए `/v1/chat/completions`, Responses API के लिए `/v1/responses`, और Anthropic-नेटिव ऐप्स के लिए `/v1/messages`।

<Tabs>
<Tab title="Chat Completions">

जब `finish_reason` `tool_calls` हो, तो हर कॉल चलाएँ, फिर assistant मैसेज बिना बदले भेजें और उसके बाद हर कॉल के लिए एक `role: "tool"` मैसेज, जो `tool_call_id` से मेल खाता हो। `tools` फिर से भेजें।

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "What is the weather in Seattle?" },
    {
      "role": "assistant",
      "content": null,
      "tool_calls": [
        {
          "id": "call_123",
          "type": "function",
          "function": {
            "name": "get_weather",
            "arguments": "{\"city\":\"Seattle\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_123",
      "content": "72F and sunny"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    }
  ]
}
```

</Tab>
<Tab title="Responses">

कॉल `function_call` प्रकार के आउटपुट आइटम के रूप में आती हैं। कॉल आइटम को इनपुट के रूप में वापस भेजें, उसके बाद उसी `call_id` वाला एक `function_call_output` आइटम।

```json
{
  "model": "openai/gpt-6-astra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [{ "type": "input_text", "text": "What's the weather in Seattle?" }]
    },
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Seattle\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "72F and sunny"
    }
  ]
}
```

</Tab>
</Tabs>

कोई कॉल चलाने से पहले उसके आर्ग्युमेंट सत्यापित करें; [टूल कॉलिंग की सुरक्षा](./tool-calling-safety) देखें।
