हर टूल कॉल को अविश्वसनीय इनपुट मानें: कुछ भी चलने से पहले टूल का नाम एक अनुमति-सूची से जाँचें और आर्ग्युमेंट सत्यापित करें।

```typescript
import { z } from "zod";

const WeatherArgs = z.object({
  city: z.string().min(1),
});

function executeToolCall(name: string, rawArgs: string) {
  if (name !== "get_weather") {
    throw new Error(`Unsupported tool: ${name}`);
  }

  const parsed = WeatherArgs.parse(JSON.parse(rawArgs));
  return getWeather(parsed.city);
}
```

## जाँच-सूची

- **schema छोटे और साफ़ रखें।** कम और टाइप वाले फ़ील्ड मॉडल को कुछ अनपेक्षित भेजने की कम गुंजाइश देते हैं।
- **पार्स किए गए आर्ग्युमेंट सत्यापित करें**, निष्पादन से पहले, ऊपर की तरह।
- **अनजान टूल नाम अस्वीकार करें**, यह अंदाज़ा लगाने के बजाय कि मॉडल का क्या मतलब था।
- **टाइमआउट और दोबारा कोशिश जोड़ें**, उन कॉल में जो बाहरी सिस्टम तक पहुँचती हैं।
- **लॉग करें**: कॉल ID, टूल का नाम, और कोई भी सत्यापन विफलता।

## जब सत्यापन विफल हो

टूल न चलाएँ। अगले टर्न में टूल के नतीजे के रूप में एक छोटा, नियंत्रित एरर भेजें, और मॉडल से सुधरे हुए आर्ग्युमेंट के साथ दोबारा कोशिश करने को कहें।

## स्ट्रीमिंग

`stream: true` के साथ, आर्ग्युमेंट टुकड़ों में आते हैं। किसी कॉल को पार्स, सत्यापित या चलाने से पहले उसके हर आर्ग्युमेंट डेल्टा को इकट्ठा करें। टूल कॉल स्ट्रीम होती हैं या नहीं, यह मॉडल और प्रदाता पर निर्भर करता है। [स्ट्रीमिंग](./streaming.mdx) देखें।
