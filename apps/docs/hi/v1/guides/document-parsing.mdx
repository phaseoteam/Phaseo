जब आपको साधारण OCR से अधिक चाहिए, तब Parse एंडपॉइंट इस्तेमाल करें। यह पेजों का क्रम बनाए रखता है और Markdown या फिर टेक्स्ट, इमेज और टेबल के संरचित ब्लॉक लौटा सकता है।

<Warning>
  Cohere का सार्वजनिक Parse API अभी केवल इमेज URL और base64 इमेज डेटा URI स्वीकार करता है। भेजने से पहले PDF पेजों को इमेज में बदलें। हर इमेज 20 MB, 50 मेगापिक्सल या डिकोड होने के बाद 200 MB से बड़ी नहीं होनी चाहिए।
</Warning>

## Markdown में पार्स करें

Markdown पढ़ने का क्रम बनाए रखता है, टेबल को HTML के रूप में इनलाइन करता है और पहचानी गई इमेज को पेज के मेटाडेटा से जोड़ता है।

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/parse \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cohere/parse-v5.0",
    "document": {
      "type": "image_url",
      "image_url": "https://example.com/invoice.png"
    },
    "output_format": "markdown"
  }'
```

```ts TypeScript
const response = await fetch("https://api.phaseo.app/v1/parse", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "cohere/parse-v5.0",
    document: {
      type: "image_url",
      image_url: "https://example.com/invoice.png",
    },
    output_format: "markdown",
  }),
});

const parsed = await response.json();
console.log(parsed.pages[0].markdown.content);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/parse",
    headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
    json={
        "model": "cohere/parse-v5.0",
        "document": {
            "type": "image_url",
            "image_url": "https://example.com/invoice.png",
        },
        "output_format": "markdown",
    },
)
response.raise_for_status()
print(response.json()["pages"][0]["markdown"]["content"])
```
</CodeGroup>

## संरचित ब्लॉक लौटाएँ

क्रमबद्ध टेक्स्ट, इमेज और टेबल क्षेत्र पाने के लिए `output_format` को `blocks` पर सेट करें। उपलब्ध होने पर इमेज और टेबल ब्लॉक में पिक्सेल और सामान्यीकृत बाउंडिंग बॉक्स शामिल होते हैं।

Parse का उपयोग प्रति पेज मापा जाता है। जब प्रदाता बिल किए गए पेजों की संख्या बताता है, तब प्रतिक्रिया में Cohere का मेटाडेटा और सामान्यीकृत `usage.input_pages` मान शामिल होता है। Cohere अभी मूल्यांकन के लिए दर-सीमित API एक्सेस मुफ़्त देता है और उसने प्रोडक्शन उपयोग के लिए Parse API की दर प्रकाशित नहीं की है।
