दस्तावेज़ की इमेज `POST /v1/parse` पर भेजें और उसका टेक्स्ट पढ़ने के क्रम में वापस पाएँ, Markdown के रूप में या संरचित टेक्स्ट, इमेज और टेबल ब्लॉक के रूप में। जब आपको सिर्फ़ सादा टेक्स्ट चाहिए, तो [OCR](../api-reference/endpoint/ocr.mdx) इस्तेमाल करें।

<Warning>
  Parse हर अनुरोध में एक इमेज स्वीकार करता है, `http(s)` URL या base64 `data:image/...` URI के रूप में। PDF स्वीकार नहीं किए जाते: पहले हर पेज को इमेज में बदलें। Cohere हर इमेज को 20 MB, 50 मेगापिक्सेल और डिकोड होने पर 200 MB तक सीमित करता है।
</Warning>

## Markdown में पार्स करें

Markdown डिफ़ॉल्ट `output_format` है। यह पढ़ने का क्रम बनाए रखता है, टेबल को HTML के रूप में इनलाइन रखता है, और पहचानी गई इमेज को पेज के मेटाडेटा से जोड़ता है।

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/parse \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cohere/parse-v5.0",
    "document": {
      "type": "image_url",
      "image_url": "https://example.com/invoice.png"
    },
    "output_format": "markdown"
  }'
```

```ts TypeScript
const response = await fetch("https://api.phaseo.app/v1/parse", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "cohere/parse-v5.0",
    document: {
      type: "image_url",
      image_url: "https://example.com/invoice.png",
    },
    output_format: "markdown",
  }),
});

const parsed = await response.json();
console.log(parsed.pages[0].markdown.content);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/parse",
    headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
    json={
        "model": "cohere/parse-v5.0",
        "document": {
            "type": "image_url",
            "image_url": "https://example.com/invoice.png",
        },
        "output_format": "markdown",
    },
)
response.raise_for_status()
print(response.json()["pages"][0]["markdown"]["content"])
```
</CodeGroup>

## संरचित ब्लॉक लौटाएँ

क्रमबद्ध टेक्स्ट, इमेज और टेबल क्षेत्र पाने के लिए `output_format` को `blocks` पर सेट करें। जहाँ उपलब्ध हो, इमेज और टेबल ब्लॉक में पिक्सेल और सामान्यीकृत बाउंडिंग बॉक्स शामिल होते हैं।

## Parse का बिल कैसे बनता है

Parse उपयोग प्रति पेज मापा जाता है। प्रतिक्रिया में Cohere का मेटाडेटा होता है, और जब प्रदाता बिल किए गए पेज बताता है तो एक सामान्यीकृत `usage.input_pages` मान भी। Cohere फ़िलहाल मुफ़्त, रेट-लिमिटेड मूल्यांकन API ऐक्सेस देता है और उसने प्रोडक्शन Parse API की दर प्रकाशित नहीं की है।
