जब prompt मौजूदा तारीख, सप्ताह के दिन, समय या timezone पर निर्भर हो, तब `phaseo:datetime` उपयोग करें।

Tool को कब call करना है, यह model तय करता है। Phaseo resolved timezones और मौजूदा timestamps model को लौटाता है; फिर model अंतिम जवाब लिखता है।

## त्वरित शुरुआत

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "messages": [
      { "role": "user", "content": "What day of the week is it in Tokyo?" }
    ],
    "tools": [
      {
        "type": "phaseo:datetime",
        "parameters": {
          "timezones": ["Asia/Tokyo", "UTC"]
        }
      }
    ]
  }'
```

## कॉन्फ़िगरेशन

```json
{
  "type": "phaseo:datetime",
  "parameters": {
    "timezones": ["Europe/London", "UTC"]
  }
}
```

| पैरामीटर | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `timezones` | string[] | `["UTC"]` | एक टूल कॉल में लौटाने के लिए अधिकतम 5 IANA समय-क्षेत्र नाम, जैसे `["Europe/London", "UTC"]`। |

## टूल का परिणाम

टूल के परिणाम में हर अनुरोधित समय-क्षेत्र के लिए एक प्रविष्टि होती है।

```json
{
  "timezones": [
    {
      "timezone": "Europe/London",
      "datetime": "2026-07-03T10:00:00.123+01:00"
    },
    {
      "timezone": "UTC",
      "datetime": "2026-07-03T09:00:00.123+00:00"
    }
  ]
}
```

## उपयोग

Datetime calls इस संख्या को बढ़ाती हैं:

```json
{
  "usage": {
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```
