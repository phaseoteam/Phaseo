`phaseo:datetime` जोड़ें ताकि जब कोई प्रॉम्प्ट मौजूदा दिनांक और समय पर निर्भर हो, जैसे "टोक्यो में आज कौन सा दिन है?", तो मॉडल उसे देख सके। मॉडल तय करता है कि इसे कब कॉल करना है; Phaseo आपके बताए हर टाइमज़ोन में समय लौटाता है।

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What day of the week is it in Tokyo?" }
    ],
    "tools": [
      {
        "type": "phaseo:datetime",
        "parameters": { "timezones": ["Asia/Tokyo", "UTC"] }
      }
    ]
  }'
```

## पैरामीटर

| पैरामीटर | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `timezones` | string[] | `["UTC"]` | अधिकतम 5 IANA टाइमज़ोन नाम, जैसे `["Europe/London", "UTC"]`। |

5 से ज़्यादा टाइमज़ोन, या ऐसा नाम जो मान्य IANA टाइमज़ोन नहीं है, मॉडल चलने से पहले ही अनुरोध अस्वीकार करवा देता है। पुराना प्रकार नाम `gateway:datetime` अब भी स्वीकार किया जाता है।

## टूल क्या लौटाता है

हर टाइमज़ोन के लिए एक एंट्री:

```json
{
  "timezones": [
    { "timezone": "Europe/London", "datetime": "2026-07-03T10:00:00.123+01:00" },
    { "timezone": "UTC", "datetime": "2026-07-03T09:00:00.123+00:00" }
  ]
}
```

## उपयोग और कीमत

हर कॉल `usage.server_tool_use.datetime_requests` में 1 जोड़ती है। दिनांक-समय टूल का अपना कोई कीमत मीटर नहीं है।
