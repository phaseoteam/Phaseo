`phaseo:web_fetch` जोड़ें, ताकि मॉडल किसी ज्ञात URL को पढ़ सके, जैसे कोई दस्तावेज़ पेज, लेख या चेंजलॉग। मॉडल `url` देता है; Phaseo पेज फ़ेच करता है और उसका टेक्स्ट एक आकार सीमा तक काटकर लौटाता है, और मॉडल उत्तर देने से पहले और पेज भी फ़ेच कर सकता है।

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Summarize https://phaseo.app/docs/v1/guides/tool-calling" }
    ],
    "tools": [
      { "type": "phaseo:web_fetch" }
    ]
  }'
```

<span id="parameters"></span>
## पैरामीटर

```json
{
  "type": "phaseo:web_fetch",
  "parameters": {
    "engine": "direct",
    "max_chars": 12000,
    "allowed_domains": ["phaseo.app"],
    "blocked_domains": ["internal.example.com"]
  }
}
```

| पैरामीटर | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `engine` | string | `direct` | `auto`, `native`, `direct`, `exa`, `parallel`, `firecrawl` या `deepseek`। देखें [इंजन चुनें](#choose-an-engine)। |
| `max_chars` | integer | `12000` | मॉडल को लौटाए जाने वाले पेज टेक्स्ट के अक्षर, अधिकतम `100000`। |
| `max_content_tokens` | integer | कोई नहीं | `max_chars` न देने पर उसकी जगह उपयोग होता है। `native` के लिए भी आकार सीमा यही है। |
| `max_uses` | integer | `10` | प्रति अनुरोध फ़ेच कॉल, अधिकतम `100`। |
| `allowed_domains` | string[] | कोई नहीं | सिर्फ़ इन डोमेन से फ़ेच करें। मॉडल किसी कॉल में यह सूची छोटी कर सकता है, बड़ी नहीं। |
| `blocked_domains` | string[] | कोई नहीं | इन डोमेन से कभी फ़ेच न करें। उपनाम: `excluded_domains`। |

## मॉडल क्या भेजता है

हर कॉल में एक `url` होता है। मॉडल `engine`, `max_chars`, `max_content_tokens` और डोमेन सूचियां भी भेज सकता है।

<span id="choose-an-engine"></span>
## इंजन चुनें

| इंजन | क्या चलता है |
| --- | --- |
| `auto` | `/v1/messages` पर Anthropic का मूल फ़ेच। दूसरे एंडपॉइंट पर, Exa सक्षम हो तो Exa, नहीं तो `direct`। |
| `direct` | Phaseo खुद पेज फ़ेच करता है और HTML को सादे टेक्स्ट में बदलता है। |
| `exa` | Exa कंटेंट एक्सट्रैक्शन। |
| `parallel` | Parallel Extract। |
| `firecrawl` | Firecrawl Scrape। |
| `deepseek` | DeepSeek Fetch, जो पेज को Markdown के रूप में लौटाता है। |
| `native` | Anthropic का `web_fetch_20260209` टूल, सिर्फ़ `/v1/messages` पर। दूसरे एंडपॉइंट पर अनुरोध अस्वीकार हो जाता है; `direct` या कोई प्रबंधित इंजन उपयोग करें। |

अगर कोई प्रबंधित इंजन सक्षम नहीं है, तो कॉल मॉडल को `fetch_not_configured` लौटाती है।

सिर्फ़ HTTP(S) URL काम करते हैं। `direct` सिर्फ़ टेक्स्ट जैसे कंटेंट टाइप स्वीकार करता है, जैसे HTML, सादा टेक्स्ट और JSON, और बाकी सब के लिए `unsupported_content_type` लौटाता है। यह अधिकतम 5 रीडायरेक्ट फ़ॉलो करता है और हर एक को आपकी डोमेन सूचियों से जांचता है।

### Anthropic का मूल फ़ेच

```json
{
  "model": "anthropic/claude-sonnet-4.6",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "Read the docs page and summarize the limits." }
  ],
  "tools": [
    {
      "type": "phaseo:web_fetch",
      "parameters": {
        "engine": "native",
        "max_content_tokens": 9000,
        "allowed_domains": ["phaseo.app"]
      }
    }
  ],
  "tool_choice": { "type": "tool", "name": "phaseo:web_fetch" }
}
```

## टूल क्या लौटाता है

```json
{
  "provider": "fetch",
  "engine": "direct",
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "text": "...",
  "truncated": false,
  "returned_chars": 8421
}
```

यह मानने से पहले कि मॉडल ने पूरा पेज देखा, `truncated` जांचें। पूरे उदाहरण के लिए [वेब फ़ेच से टूल ग्राउंडिंग](../../cookbook/tool-grounding-with-web-fetch) देखें।

## उपयोग और मूल्य

हर fetch `usage.server_tool_use.web_fetch_requests` में 1 जोड़ता है। Phaseo, Exa, Parallel, Firecrawl या DeepSeek से हर managed fetch के लिए $0.001 लेता है, जब तक मॉडल का price card `server_tool_web_fetch_requests` के लिए अपनी कीमत तय न करे; direct fetches मुफ़्त हैं। सशुल्क engines से fetches के लिए क्रेडिट चाहिए, भले ही मॉडल मुफ़्त हो। Native fetch का बिल `native_web_fetch_requests` से बनता है, जहाँ मॉडल का price card इसे तय करता है।
