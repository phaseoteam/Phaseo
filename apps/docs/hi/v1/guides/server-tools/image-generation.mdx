`phaseo:image_generation` जोड़ें ताकि मॉडल जवाब देते समय इमेज बना सके। मॉडल इमेज प्रॉम्प्ट लिखता है; Phaseo इमेज मॉडल को कॉल करता है और इमेज मॉडल लूप को लौटाता है।

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Design a wide product concept image for a compact desktop synthesizer.",
    "tools": [
      {
        "type": "phaseo:image_generation",
        "parameters": {
          "model": "openai/gpt-image-2",
          "quality": "high",
          "aspect_ratio": "16:9",
          "output_format": "png"
        }
      }
    ]
  }'
```

## पैरामीटर

सभी पैरामीटर वैकल्पिक हैं।

| पैरामीटर | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `model` | string | `openai/gpt-image-2` | इमेज मॉडल। यहाँ सेट करने पर यह मुख्य मॉडल के माँगे गए किसी भी मॉडल को ओवरराइड करता है। |
| `quality` | string | प्रदाता डिफ़ॉल्ट | गुणवत्ता संकेत, जैसे `low`, `medium` या `high`। |
| `size` | string | प्रदाता डिफ़ॉल्ट | इमेज आकार संकेत। |
| `aspect_ratio` | string | प्रदाता डिफ़ॉल्ट | आस्पेक्ट रेशियो, जैसे `1:1`, `16:9` या `9:16`। |
| `background` | string | प्रदाता डिफ़ॉल्ट | बैकग्राउंड मोड संकेत। |
| `output_format` | string | प्रदाता डिफ़ॉल्ट | `png`, `jpeg` या `webp`। |
| `output_compression` | integer | प्रदाता डिफ़ॉल्ट | कम्प्रेशन संकेत, `0` से `100` के बीच सीमित। |
| `moderation` | string | प्रदाता डिफ़ॉल्ट | प्रदाता मॉडरेशन संकेत। |

## मॉडल क्या भेजता है

एक `prompt` (या `description`, जिसे एक जैसा माना जाता है)। यह `model` भी भेज सकता है, जो सिर्फ़ तब इस्तेमाल होता है जब टूल कोई मॉडल सेट नहीं करता, और ऊपर दिए गए बाकी पैरामीटर में से कोई भी, जो उस कॉल के लिए टूल के मानों की जगह ले लेते हैं।

## टूल क्या लौटाता है

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "imageUrl": "https://...",
  "mime_type": "image/png"
}
```

कुछ प्रदाता `imageUrl` की जगह base64 इमेज डेटा के साथ `b64_json` लौटाते हैं। अगर कॉल में कोई प्रॉम्प्ट नहीं है, तो मॉडल को `image_generation_invalid_request` मिलता है; अगर इमेज मॉडल विफल होता है, तो `image_generation_failed`।

## उपयोग और कीमत

हर इमेज `usage.server_tool_use.image_generation_requests` में 1 जोड़ती है और उसका बिल `server_tool_image_generation_requests` के साथ बन सकता है। जब इमेज मॉडल टोकन उपयोग रिपोर्ट करता है, तो वह अनुरोध के उपयोग में जोड़ा जाता है और उस मॉडल की सामान्य दरों पर बिल किया जाता है।
