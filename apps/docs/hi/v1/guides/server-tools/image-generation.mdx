जब मॉडल को जवाब देते समय इमेज बना पाने की क्षमता चाहिए, तो `phaseo:image_generation` उपयोग करें। Phaseo मॉडल को एक प्रबंधित टूल देता है, इमेज अनुरोध को सर्वर पर चलाता है और इमेज का परिणाम वापस मॉडल लूप में भेजता है।

## अनुरोध

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Design a wide product concept image for a compact desktop synthesizer.",
    "tools": [
      {
        "type": "phaseo:image_generation",
        "parameters": {
          "model": "openai/gpt-image-2",
          "quality": "high",
          "aspect_ratio": "16:9",
          "output_format": "png"
        }
      }
    ]
  }'
```

## पैरामीटर

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| `model` | string | वैकल्पिक इमेज-जनरेशन समर्थित मॉडल ID। टूल या टूल कॉल में मॉडल न दिया हो, तो डिफ़ॉल्ट `openai/gpt-image-2` है। |
| `quality` | string | प्रदाता के लिए वैकल्पिक गुणवत्ता संकेत, जैसे `low`, `medium` या `high`। |
| `size` | string | वैकल्पिक इमेज आकार का संकेत। |
| `aspect_ratio` | string | वैकल्पिक पहलू अनुपात, जैसे `1:1`, `16:9` या `9:16`। |
| `background` | string | वैकल्पिक बैकग्राउंड मोड का संकेत। |
| `output_format` | string | वैकल्पिक आउटपुट फ़ॉर्मैट, जैसे `png`, `jpeg` या `webp`। |
| `output_compression` | integer | प्रदाता के लिए वैकल्पिक कम्प्रेशन संकेत। |
| `moderation` | string | प्रदाता के लिए वैकल्पिक मॉडरेशन संकेत। |

टूल कॉल करते समय अंतिम `prompt` मॉडल देता है। टूल-स्तर के पैरामीटर उस कॉल के डिफ़ॉल्ट और पाबंदियाँ तय करते हैं।

टूल कॉल में `prompt` के बजाय `description` भी भेजा जा सकता है। मॉडल द्वारा जनरेट किए गए इमेज विवरणों के साथ संगतता के लिए Phaseo `description` को प्रॉम्प्ट का उपनाम मानता है।

## टूल का परिणाम

परिणाम मॉडल को JSON के रूप में लौटाया जाता है:

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "imageUrl": "https://...",
  "mime_type": "image/png"
}
```

कुछ प्रदाता इसके बजाय base64 इमेज डेटा लौटाते हैं:

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "b64_json": "...",
  "mime_type": "image/png"
}
```

## उपयोग और मूल्य निर्धारण

जब इमेज मॉडल टोकन उपयोग रिपोर्ट करता है, तो इमेज जनरेशन का उपयोग मूल प्रतिक्रिया के उपयोग में शामिल होता है। Phaseo यह भी दर्ज करता है:

```json
{
  "usage": {
    "server_tool_use": {
      "image_generation_requests": 1
    }
  }
}
```

मूल्य निर्धारण कार्ड इसका बिल `server_tool_image_generation_requests` मीटर से बना सकते हैं। अंतर्निहित इमेज मॉडल के उपयोग पर फिर भी उसके सामान्य मॉडल मूल्य निर्धारण के अनुसार शुल्क लग सकता है।
