`phaseo:search_models` जोड़ें ताकि मॉडल Phaseo के लाइव कैटलॉग का इस्तेमाल करके कोई मॉडल चुन सके या सुझा सके: मौजूदा मोडैलिटी, प्रदाता, समर्थित पैरामीटर और कीमतें।

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "Which models can transcribe audio and return JSON?" }
  ],
  "tools": [{ "type": "phaseo:search_models", "parameters": { "max_results": 5 } }],
  "max_tool_calls": 10
}
```

## पैरामीटर

| पैरामीटर | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `max_results` | integer | `5` | हर खोज में लौटाए जाने वाले मॉडल, अधिकतम `20`। |

## मॉडल क्या भेजता है

इनमें से कोई भी फ़िल्टर। सिर्फ़ सक्रिय मॉडल खोजे जाते हैं, और मॉडल को भेजे गए हर फ़िल्टर से मेल खाना चाहिए।

| आर्ग्युमेंट | किससे मेल खाता है |
| --- | --- |
| `query` | मॉडल ID, नाम या विवरण में टेक्स्ट |
| `series` | मॉडल ID, नाम या विवरण में टेक्स्ट |
| `input_modalities` | वे मॉडल जो ये सभी इनपुट स्वीकार करते हैं |
| `output_modalities` | वे मॉडल जो ये सभी आउटपुट बनाते हैं |
| `provider` | एक प्रदाता ID या नाम |
| `required_params` | वे मॉडल जो ये सभी अनुरोध पैरामीटर सपोर्ट करते हैं |

## टूल क्या लौटाता है

```json
{
  "models": [
    {
      "id": "openai/gpt-4o-mini-transcribe",
      "name": "...",
      "description": "...",
      "input_modalities": ["audio"],
      "output_modalities": ["text"],
      "providers": ["openai"],
      "supported_params": ["..."],
      "pricing": {}
    }
  ],
  "total_results": 4,
  "showing": 4
}
```

## उपयोग और कीमत

हर खोज `usage.server_tool_use.search_models_requests` में 1 जोड़ती है और उसका बिल `server_tool_search_models_requests` के साथ बन सकता है।
