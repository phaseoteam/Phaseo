`phaseo:subagent` जोड़ें ताकि मुख्य मॉडल उसी अनुरोध में एक स्व-निहित टास्क किसी वर्कर मॉडल को सौंप सके, जो अक्सर छोटा या तेज़ होता है। मुख्य मॉडल टास्क का वर्णन करता है; Phaseo वर्कर चलाता है और उसका परिणाम लौटाता है, और मुख्य मॉडल जवाब पूरा करता है।

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5",
    "messages": [
      { "role": "user", "content": "Compare these release notes and summarize the breaking changes." }
    ],
    "tools": [
      {
        "type": "phaseo:subagent",
        "parameters": {
          "model": "openai/gpt-6-astra",
          "instructions": "Return concise findings for the main model. Do not address the end user directly.",
          "max_uses": 3,
          "max_completion_tokens": 1200
        }
      }
    ]
  }'
```

## पैरामीटर

| पैरामीटर | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `model` | string | अनुरोध का मॉडल | वर्कर मॉडल। |
| `instructions` | string | बिल्ट-इन वर्कर निर्देश | वर्कर के लिए अतिरिक्त निर्देश। |
| `max_uses` | integer | `1` | हर अनुरोध में Subagent कॉल। |
| `max_completion_tokens` | integer | `1400` | हर वर्कर जवाब के आउटपुट टोकन। `1024` से कम मान `1024` कर दिए जाते हैं। `max_tokens` पुराने उपनाम के रूप में स्वीकार किया जाता है। |
| `reasoning` | object | प्रदाता डिफ़ॉल्ट | रीज़निंग सेटिंग्स, जहाँ वर्कर मॉडल उन्हें सपोर्ट करता है वहाँ आगे भेजी जाती हैं। |
| `temperature` | number | प्रदाता डिफ़ॉल्ट | वर्कर कॉल के लिए सैंपलिंग तापमान। |

वर्कर को बातचीत कभी नहीं मिलती: उसे जो कुछ चाहिए, सब टास्क में डालें।

## मॉडल क्या भेजता है

पूरे टास्क, संदर्भ और अपेक्षित आउटपुट के साथ एक `task_description`, और साथ में वैकल्पिक छोटा `task_name`:

```json
{
  "task_description": "Extract the three highest-risk migration steps from the supplied plan."
}
```

`task_description` की जगह `task`, `prompt` या `input` भी स्वीकार किए जाते हैं।

## टूल क्या लौटाता है

```json
{
  "status": "ok",
  "model": "openai/gpt-6-astra",
  "outcome": "The highest-risk steps are schema migration, traffic cutover, and rollback verification."
}
```

अगर कॉल नहीं चल पाती, तो मॉडल को `subagent_invalid_request` (कोई टास्क नहीं), `subagent_max_uses_exceeded` या `subagent_request_failed` मिलता है।

## उपयोग और कीमत

हर कॉल `usage.server_tool_use.subagent_requests` में 1 जोड़ती है और उसका बिल `server_tool_subagent_requests` के साथ बन सकता है। वर्कर के टोकन अनुरोध के उपयोग में जोड़े जाते हैं और वर्कर मॉडल की दरों पर गिने जाते हैं। काम सौंपने की जगह समीक्षा पाने के लिए [Advisor](./advisor) इस्तेमाल करें।
