फ़ाइल बदलाव संरचित पैच ऑपरेशन के रूप में वापस पाने के लिए `/v1/responses` पर `phaseo:apply_patch` जोड़ें। Phaseo हर ऑपरेशन का आकार जाँचता है और उसे लौटाता है; यह कभी आपकी फ़ाइलों को नहीं छूता। आपका ऐप तय करता है कि पैच लागू करना है, उपयोगकर्ता को दिखाना है, अस्वीकार करना है या संशोधन माँगना है।

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Create a small README patch for this project.",
    "tools": [
      { "type": "phaseo:apply_patch" }
    ]
  }'
```

`/v1/chat/completions` या `/v1/messages` पर अनुरोध अस्वीकार कर दिया जाता है।

## पैरामीटर

कोई नहीं। `{ "type": "phaseo:apply_patch" }` को जैसा है वैसा जोड़ें।

## मॉडल क्या भेजता है

एक `operation` ऑब्जेक्ट:

```json
{
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  }
}
```

| `type` | ज़रूरी फ़ील्ड | Diff नियम |
| --- | --- | --- |
| `create_file` | `path`, `diff` | हर गैर-ख़ाली लाइन `+` से शुरू होती है |
| `update_file` | `path`, `diff` | हर गैर-ख़ाली लाइन `@@`, एक स्पेस, `+` या `-` से शुरू होती है |
| `delete_file` | `path` | कोई नहीं |

`path` में null बाइट नहीं हो सकते।

## टूल क्या लौटाता है

```json
{
  "status": "completed",
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  },
  "message": "Patch operation validated. The client must apply or reject this patch and report the result."
}
```

ऊपर दिए गए नियम तोड़ने वाला ऑपरेशन कारण के साथ `apply_patch_invalid_operation` लौटाता है, ताकि मॉडल फिर से कोशिश कर सके।

## उपयोग और कीमत

हर कॉल `usage.server_tool_use.apply_patch_requests` में 1 जोड़ती है और उसका बिल `server_tool_apply_patch_requests` के साथ बन सकता है।
