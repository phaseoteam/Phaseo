जब किसी Responses वर्कफ़्लो को फ़ाइलों में किए गए बदलाव संरचित पैच ऑपरेशन के रूप में लौटाने हों, तब `phaseo:apply_patch` इस्तेमाल करें। Phaseo ऑपरेशन को सत्यापित करके आपके क्लाइंट को लौटाता है; यह आपके फ़ाइल सिस्टम या रिपॉज़िटरी में कोई बदलाव नहीं करता।

<Note>
`phaseo:apply_patch` `/v1/responses` पर उपलब्ध है।
</Note>

## अनुरोध

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Create a small README patch for this project.",
    "tools": [
      { "type": "phaseo:apply_patch" }
    ]
  }'
```

## ऑपरेशन की संरचना

जब मॉडल टूल को कॉल करता है, तो वह एक ऑपरेशन ऑब्जेक्ट भेजता है:

```json
{
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  }
}
```

समर्थित ऑपरेशन प्रकार:

| प्रकार | आवश्यक फ़ील्ड |
| --- | --- |
| `create_file` | `path`, `diff` |
| `update_file` | `path`, `diff` |
| `delete_file` | `path` |

## टूल का परिणाम

Phaseo सत्यापित ऑपरेशन को मॉडल लूप में लौटाता है:

```json
{
  "status": "completed",
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  },
  "message": "Patch operation validated. The client must apply or reject this patch and report the result."
}
```

पैच लागू करना, उसे उपयोगकर्ता को दिखाना, अस्वीकार करना या मॉडल से संशोधित ऑपरेशन माँगना आपके ऐप्लिकेशन की ही ज़िम्मेदारी है।

## उपयोग और मूल्य निर्धारण

Phaseo यह दर्ज करता है:

```json
{
  "usage": {
    "server_tool_use": {
      "apply_patch_requests": 1
    }
  }
}
```

मूल्य निर्धारण कार्ड इसका बिल `server_tool_apply_patch_requests` मीटर से बना सकते हैं।
