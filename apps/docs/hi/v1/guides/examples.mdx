लोकल रूप से चलाने और अपने हिसाब से बदलने के लिए एक सैंपल प्रोजेक्ट चुनें। एक API कॉल के लिए [क्विकस्टार्ट](../quickstart.mdx) इस्तेमाल करें; किसी खास फ़ीचर के लिए [कुकबुक](../cookbook/index.mdx) देखें।

## चलाने योग्य प्रोजेक्ट

| क्या बनाना है | वॉकथ्रू | सोर्स |
| --- | --- | --- |
| सर्वर-साइड API कुंजी के साथ ब्राउज़र चैट | [Next.js चैट](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| OAuth ऑथराइज़ेशन और बैकएंड प्रॉक्सी | [OAuth वर्कबेंच](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| एक न्यूनतम REST इंटीग्रेशन | [Node स्मोक ऐप](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| एक Python कमांड-लाइन ऐप्लिकेशन | [Python CLI](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| Vercel AI SDK इस्तेमाल करने वाला ऐप्लिकेशन | [AI SDK इंटीग्रेशन](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

क्रेडेंशियल सर्वर पर रखें, सैंपल के एनवायरनमेंट वेरिएबल की समीक्षा करें, और चलाने से पहले चुने गए मॉडल की कीमत जाँचें। `:free` मॉडल इस्तेमाल करने वाले उदाहरणों के लिए क्रेडिट जमा करना ज़रूरी नहीं है।

## भाषा-विशिष्ट अनुरोध

[क्लाइंट SDK संदर्भ](../sdk-reference/client/overview.mdx) में भाषा के अनुसार इंस्टॉलेशन और अनुरोध के उदाहरण हैं। इमेज पैरामीटर के लिए [इमेज जनरेशन संदर्भ](../api-reference/endpoint/images-generations.mdx) और चैट अनुरोधों के लिए [Chat Completions](../api-reference/endpoint/chat-completions.mdx) इस्तेमाल करें।

किसी कोडिंग एजेंट से प्रोजेक्ट का ढाँचा बनवाने के लिए [मिनी-ऐप स्टार्टर प्रॉम्प्ट](../cookbook/mini-app-starter-prompts.mdx) इस्तेमाल करें, और लाइव क्रेडेंशियल के साथ इस्तेमाल करने से पहले जनरेट किए गए कोड की समीक्षा करें।
