स्थानीय रूप से चलाकर बदलने के लिए नमूना प्रोजेक्ट चुनें। एक API कॉल के लिए [त्वरित शुरुआत](../quickstart.mdx), और विशेष सुविधा के लिए [रेसिपी](../cookbook/index.mdx) देखें।

## चलने योग्य प्रोजेक्ट

| निर्माण | गाइड | स्रोत |
| --- | --- | --- |
| सर्वर पर API कुंजी वाला ब्राउज़र चैट | [Next.js चैट](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| OAuth प्राधिकरण और बैकएंड प्रॉक्सी | [OAuth कार्यक्षेत्र](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| न्यूनतम REST एकीकरण | [Node त्वरित परीक्षण ऐप](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| Python कमांड-लाइन ऐप | [Python CLI](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| Vercel AI SDK इस्तेमाल करने वाला ऐप | [AI SDK एकीकरण](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

क्रेडेंशियल सर्वर पर रखें, नमूने के पर्यावरण चर जाँचें और चलाने से पहले चुने मॉडल की कीमत देखें। `:free` मॉडल के उदाहरणों में जमा क्रेडिट आवश्यक नहीं हैं।

## भाषा-विशिष्ट अनुरोध

[क्लाइंट SDK संदर्भ](../sdk-reference/typescript/overview.mdx) में भाषा के अनुसार इंस्टॉल और अनुरोध उदाहरण हैं। छवि पैरामीटर के लिए [छवि जनरेशन संदर्भ](../api-reference/endpoint/images-generations.mdx), और चैट अनुरोध के लिए [Chat Completions](../api-reference/endpoint/chat-completions.mdx) देखें।

कोडिंग एजेंट से प्रोजेक्ट ढाँचा बनाने के लिए [मिनी ऐप शुरुआती प्रॉम्प्ट](../cookbook/mini-app-starter-prompts.mdx) इस्तेमाल करें और वास्तविक क्रेडेंशियल से चलाने से पहले जनरेट कोड की समीक्षा करें।
