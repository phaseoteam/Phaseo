अकाउंट, बिलिंग, API और फ़ीडबैक से जुड़े सवालों के लिए [Phaseo Help Center](https://phaseo.app/help) से शुरुआत करें; टीम हर अनुरोध को सही जगह भेज देती है।

| आप यह करना चाहते हैं | यहाँ जाएँ |
| --- | --- |
| अपने अकाउंट, बिलिंग या किसी विफल अनुरोध में मदद पाना | [Help Center](https://phaseo.app/help) |
| बग रिपोर्ट करना | [Help Center](https://phaseo.app/help), या GitHub पर [बग रिपोर्ट](https://github.com/phaseoteam/Phaseo/issues/new?template=bug.yml) |
| कैटलॉग डेटा ठीक करना | [योगदान](../contributing/overview) |
| सुरक्षा कमज़ोरी रिपोर्ट करना | [GitHub रिपॉज़िटरी](https://github.com/phaseoteam/Phaseo) पर **Security -> Report a vulnerability** के तहत निजी रिपोर्ट, या `security@phaseo.app`। इसे सार्वजनिक रूप से पोस्ट न करें। |
| समुदाय से पूछना | [Discord](https://discord.gg/aQyywCvgZ5) |

## बग रिपोर्ट में क्या शामिल करें

- अनुरोध ID: प्रतिक्रिया का `id` (`G-...`), त्रुटि का `generation_id`, या `x-request-id` प्रतिक्रिया हेडर।
- आपने क्या भेजा (API कुंजी हटाकर), और आपको क्या उम्मीद थी।
- प्रतिक्रिया बॉडी से त्रुटि कोड और संदेश। [त्रुटि संदर्भ](../api-reference/errors) हर कोड का मतलब बताता है।
- कोई भी संबंधित logs, क्रेडेंशियल और ग्राहक डेटा हटाकर।
