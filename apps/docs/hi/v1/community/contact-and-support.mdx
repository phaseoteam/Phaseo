## बग रिपोर्ट करें

Phaseo Help Center का इस्तेमाल करें और समस्या दोहराने के स्पष्ट चरण, अनुरोध ID और संबंधित logs शामिल करें:

- https://phaseo.app/help

## मदद माँगें

अकाउंट, बिलिंग और API समस्या के लिए Phaseo Help Center से शुरुआत करें:

- https://phaseo.app/help

## फ़ीडबैक दें

फ़ीडबैक कहाँ भेजना है, यह पता न हो तो Phaseo Help Center इस्तेमाल करें। टीम इसे सही जगह भेज देगी।
