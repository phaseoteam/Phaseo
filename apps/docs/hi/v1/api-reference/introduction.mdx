एंडपॉइंट संदर्भ खोलने से पहले सही API पथ खोजने के लिए इस पृष्ठ का उपयोग करें। Phaseo Gateway के सभी एंडपॉइंट एक ही बेस URL साझा करते हैं और Bearer प्रमाणीकरण का उपयोग करते हैं।

## अपना रास्ता चुनें

| अगर आप चाहते हैं | यहाँ से शुरू करें |
| --- | --- |
| अपना पहला अनुरोध भेजना | [क्विकस्टार्ट](../quickstart.mdx) |
| टेक्स्ट जनरेट करना या टूल उपयोग करना | `POST /responses` |
| मौजूदा OpenAI-संगत चैट एकीकरण बनाए रखना | `POST /chat/completions` |
| मॉडल और प्रदाता देखना | `GET /models` और `GET /providers` |
| संगीत बनाना या फ़ाइलें प्रबंधित करना | `POST /music/generations` और `POST /files` |

## बेस URL

प्रोडक्शन बेस URL:

```http
https://api.phaseo.app/v1
```

इस reference के सभी endpoint path उसी `/v1` base URL के सापेक्ष हैं।

## प्रमाणीकरण

अधिकांश एंडपॉइंट के लिए सामान्य Gateway API कुंजी आवश्यक है। प्रबंधन एंडपॉइंट के लिए डैशबोर्ड में बनाई गई प्रबंधन API कुंजी चाहिए।

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

प्रमाणीकरण विफल होने पर API `401` लौटाती है।

## API संसाधन

| संसाधन | काम |
| --- | --- |
| Responses API | टूल, structured output और multimodal input के साथ मॉडल प्रतिक्रियाएँ जनरेट करना। |
| Chat Completions | मौजूदा OpenAI-संगत चैट एकीकरण बनाए रखना। |
| Anthropic Messages | मौजूदा Anthropic-संगत Messages एकीकरण बनाए रखना। |
| Embeddings | खोज, पुनर्प्राप्ति और वर्गीकरण के लिए वेक्टर निरूपण बनाना। |
| Images | इमेज जनरेट या संपादित करना। |
| टेक्स्ट से आवाज़ | टेक्स्ट से बोला गया ऑडियो बनाना। |
| आवाज़ से टेक्स्ट | ऑडियो को ट्रांसक्राइब या अनुवाद करना। |
| संगीत जनरेशन | संगीत के कार्य बनाना और उनकी स्थिति देखना। |
| फ़ाइलें | समर्थित API कार्यप्रवाहों के लिए इनपुट फ़ाइलें अपलोड और प्राप्त करना। |
| मॉडल, प्रदाता और एंडपॉइंट | Gateway के माध्यम से उपलब्ध विकल्प देखना। |
| कीमत, गतिविधि और generation | लागत का अनुमान लगाना और अनुरोधों के नतीजे देखना। |
| API कुंजियाँ और वर्कस्पेस | प्रोग्रामेटिक ऐक्सेस और वर्कस्पेस संसाधन प्रबंधित करना। |

## बिलिंग और रेट लिमिट

- Phaseo अपनी ओर से दर सीमाएँ लागू नहीं करता। ये सीमाएँ अपस्ट्रीम प्रदाता लागू करते हैं।
- भुगतान वाले अनुरोधों के लिए preflight credit check पास करने लायक wallet balance चाहिए।
- `:free` वाले मुफ़्त मॉडल के लिए जमा किए गए credits की ज़रूरत नहीं।
