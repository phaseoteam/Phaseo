हर अनुरोध `https://api.phaseo.app/v1` पर भेजें, और अपनी कुंजी `Authorization: Bearer` हेडर में दें। नीचे अपने काम का एंडपॉइंट खोजें, फिर उसका संदर्भ पेज खोलें।

## सही एंडपॉइंट खोजें

| अगर आप यह करना चाहते हैं | यहां से शुरू करें |
| --- | --- |
| अपना पहला अनुरोध भेजें | [क्विकस्टार्ट](../quickstart) |
| टेक्स्ट बनाएं या टूल इस्तेमाल करें | [`POST /responses`](./endpoint/responses) |
| टाइप किए गए निर्णय लें | [`POST /decisions`](./endpoint/decisions) |
| मौजूदा OpenAI-संगत इंटीग्रेशन बनाए रखें | [`POST /chat/completions`](./endpoint/chat-completions) |
| मॉडल और प्रदाता देखें | [`GET /models`](./endpoint/models) और [`GET /providers`](./endpoint/providers) |
| संगीत बनाएं या फ़ाइलें प्रबंधित करें | [`POST /music/generate`](./endpoint/music-generate) और [`POST /files`](./endpoint/files) |
| वीडियो बनाएं (बीटा) | [`POST /videos`](./endpoint/video-create) |
| बैच सबमिट करें या परिणाम डाउनलोड करें (बीटा) | [`POST /batches`](./endpoint/batches-create) और [`GET /batches/{batch_id}/results`](./endpoint/batches-results) |

## बेस URL

```http
https://api.phaseo.app/v1
```

इस संदर्भ में हर एंडपॉइंट पथ इसी बेस URL के सापेक्ष है।

## OpenAPI

OpenAPI फ़ाइल को Postman, Hoppscotch या किसी SDK जनरेटर में इम्पोर्ट करें।

<Card
	title="Phaseo Gateway OpenAPI"

दस्तावेज़ और SDK यही स्पेसिफ़िकेशन इस्तेमाल करते हैं। Video, Batch और Decisions एंडपॉइंट पर **बीटा** लेबल है; इनके लिए वर्कस्पेस को पूर्वावलोकन पहुंच की ज़रूरत हो सकती है।

## प्रमाणीकरण

| क्रेडेंशियल | फ़ॉर्मैट | किन्हें कॉल करता है |
| --- | --- | --- |
| [Gateway API कुंजी](../developers/authentication.mdx) | `phaseo_v1_sk_<kid>_<secret>` | इन्फ़रेंस एंडपॉइंट |
| [मैनेजमेंट API कुंजी](../developers/management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | प्रशासन एंडपॉइंट, कुंजी की अनुमतियों तक सीमित |

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

प्रमाणीकरण विफल होने पर API `401` लौटाता है।

## API संसाधन

| संसाधन | यह क्या करता है |
| --- | --- |
| इन्फ़रेंस | टेक्स्ट, इमेज, ऑडियो और एम्बेडिंग बनाएं; निर्णय लें, रीरैंक करें, मॉडरेट करें या सामग्री पार्स करें। [Responses](./endpoint/responses.mdx) या [निर्णय](./endpoint/decisions.mdx) से शुरू करें। |
| एसिंक जॉब और फ़ाइलें | [वीडियो](./endpoint/video-create.mdx) या [बैच](./endpoint/batches-create.mdx) जॉब सबमिट करें, फ़ाइलें ट्रांसफ़र करें और वेबहुक कॉन्फ़िगर करें। |
| मॉडल और कीमतें | [मॉडल](./endpoint/models.mdx), प्रदाता ऑफ़र और [अनुमानित लागत](./endpoint/pricing-calculate.mdx) खोजें। |
| रूटिंग और नीतियां | प्रीसेट, प्रदाता क्रेडेंशियल, निजी मॉडल और [गार्डरेल](./endpoint/guardrails.mdx) कॉन्फ़िगर करें। |
| उपयोग और निगरानी | [लॉग](./endpoint/logs-list.mdx), गतिविधि, एनालिटिक्स, मूल्यांकन और सेवा की सेहत देखें। |
| वर्कस्पेस प्रबंधन | [वर्कस्पेस](./endpoint/workspaces-list.mdx), कुंजियां, बजट, पहचान और इंटीग्रेशन प्रबंधित करें। |

## बिलिंग और अनुरोध सीमाएँ

सशुल्क अनुरोधों को चलने से पहले क्रेडिट जांच पास करने के लिए वॉलेट में पर्याप्त बैलेंस चाहिए। जिन मॉडलों का ID `:free` पर खत्म होता है, उन्हें जमा किए गए क्रेडिट की ज़रूरत नहीं होती। अनुरोधों को कोई प्रदाता, या वर्कस्पेस और कुंजी की सीमाएं थ्रॉटल कर सकती हैं; [अनुरोध सीमाएँ](./limits.mdx) देखें।
