<Note>इस एंडपॉइंट के लिए `analytics:read` वाली प्रबंधन API कुंजी आवश्यक है।</Note>

तारीख, अनुरोध लेबल, API कुंजी, अंतिम उपयोगकर्ता, मॉडल, प्रदाता, एंडपॉइंट, क्रेडेंशियल स्रोत या परिणाम के आधार पर फ़िल्टर करें। परिणाम तारीख, मॉडल, प्रदाता और एंडपॉइंट के अनुसार समूहित होते हैं और स्थिर पेजिनेशन का उपयोग करते हैं।

सीमा पिछले 30 पूरे UTC दिनों और अधिकतम 10,000 स्रोत अनुरोधों तक है।
