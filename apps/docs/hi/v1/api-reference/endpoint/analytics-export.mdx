<Note>इस एंडपॉइंट के लिए `analytics:read` वाली प्रबंधन API कुंजी आवश्यक है।</Note>

एक्सपोर्ट एनालिटिक्स एंडपॉइंट वाले ही फ़िल्टर स्वीकार करता है और स्प्रेडशीट-सुरक्षित CSV में सभी मेल खाने वाली aggregated पंक्तियां लौटाता है।
