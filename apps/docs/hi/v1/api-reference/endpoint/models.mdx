डिफ़ॉल्ट रूप से यह endpoint केवल वही मॉडल लौटाता है जिन्हें अभी रूट किया जा सकता है। ज्ञात लेकिन फिलहाल अनुपलब्ध मॉडल भी शामिल करने के लिए `availability=all` सेट करें।

`GET /models/me` भविष्य में मौजूदा caller के guardrail के आधार पर मॉडल फ़िल्टर करने के लिए आरक्षित है। अभी यह `501 not implemented` लौटाता है, इसलिए साझा Gateway catalogue के लिए फिलहाल `GET /models` उपयोग करें।

## उपयोगी फ़िल्टर

- `endpoints` में `chat.completions`, `responses` और `messages` जैसे सार्वजनिक नाम आते हैं
- `status` मॉडल जीवनचक्र के आधार पर फ़िल्टर करता है, जैसे `active`, `deprecated` या `retired`
- `provider` सार्वजनिक provider ID से फ़िल्टर करता है, जैसे `openai`, `anthropic` या `google_vertex`
- `provider_status` provider rollout tier से फ़िल्टर करता है, जैसे `active`, `beta`, `alpha` या `not_ready`
- `provider_routing_status` provider-स्तर की routing स्थिति से फ़िल्टर करता है
- `model_routing_status` model-स्तर की routing स्थिति से फ़िल्टर करता है
- `capability_status` अनुरोधित endpoint mapping के लिए provider capability स्थिति से फ़िल्टर करता है
- `provider_availability_status` provider उपलब्धता से फ़िल्टर करता है, जैसे `active`, `coming_soon` या `inactive`
- `provider_availability_reason` provider उपलब्धता के कारण से फ़िल्टर करता है, जैसे `preview_only`, `provider_not_ready`, `gated`, `access_limited` या `region_limited`
- `organisation` सार्वजनिक model ID के prefix से फ़िल्टर करता है, जैसे `anthropic/claude-3-haiku` में `anthropic`
- `availability=active` डिफ़ॉल्ट है
- `availability=all` में `coming_soon`, `inactive` या अभी सार्वजनिक रूप से रूट न किए जा सकने वाले मॉडल और प्रोवाइडर भी आते हैं
- `input_modalities`, `input_types` का alias है
- `output_modalities`, `output_types` का alias है
- `supported_parameters`, `params` का alias है

किसी मॉडल का एंडपॉइंट अनुबंध देखने के लिए `GET /models/{author}/{slug}/endpoints` कॉल करें। प्रतिक्रिया में हर प्रदाता रूट अलग रहता है और प्रत्येक पंक्ति में सार्वजनिक पथ, समर्थित मोडैलिटी और पैरामीटर का विवरण, उपलब्धता, रूटिंग स्थिति, प्रदाता मॉडल स्लग और मूल्य सारांश दिया जाता है।

Provider entries में ये फ़ील्ड भी हो सकते हैं:

- `availability_status`
- `availability_reason`
- `provider_status`
- `provider_routing_status`
- `model_routing_status`
- `capability_status`
