[`POST /v1/music/generate`](./music-generate.mdx) से लौटाया गया `id` दें, उसका `nativeResponseId` नहीं। जनरेशन पूरा होने पर Phaseo संग्रहीत परिणाम लौटाता है, और जब तक वह चल रहा हो, आपकी ओर से प्रदाता को पोल करता है।

```bash
curl https://api.phaseo.app/v1/music/generate/req_01JY6MUSIC123 \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "suno",
  "model": "V4_5PLUS",
  "nativeResponseId": "task_123",
  "output": [
    {
      "index": 0,
      "id": "clip_1",
      "audio_url": "https://...",
      "stream_audio_url": "https://...",
      "image_url": "https://...",
      "title": "Midnight Blue",
      "tags": "jazz, piano",
      "duration": 8
    }
  ],
  "usage": {
    "output_audio_count": 1,
    "output_audio_seconds": 8
  }
}
```

`status` का मान `queued`, `in_progress`, `completed` या `failed` होता है। जनरेशन पूरा होने के बाद `usage` शामिल किया जाता है।
