`spend_rules:read` आवश्यक है। OAuth कॉलर का वर्कस्पेस का मालिक या एडमिन होना ज़रूरी है। हटाए गए ब्लॉक भी शामिल करने के लिए `include_lifted=true` जोड़ें। ब्लॉक सर्वोत्तम प्रयास पर आधारित हैं; [अनुरोध ब्लॉक करना](../../guides/spend-alerts.mdx#block-requests) देखें।
