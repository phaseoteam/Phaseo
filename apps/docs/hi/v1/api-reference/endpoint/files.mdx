लौटाए गए `file_id` को सहेजें और इसके साथ दोबारा उपयोग करें:

- `POST /v1/batches`
- `GET /v1/files/{file_id}`
- `GET /v1/files/{file_id}/content`

<Note>
साझा गेटवे कुंजी पर अभी `GET /v1/files` समर्थित नहीं है, इसलिए फ़ाइल ID लेने का मानक स्थान अपलोड प्रतिक्रिया है।
</Note>
