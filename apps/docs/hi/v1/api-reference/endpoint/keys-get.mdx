<Note>
इस एंडपॉइंट के लिए प्रबंधन API कुंजी आवश्यक है। मानक Gateway API कुंजियाँ स्वीकार नहीं की जातीं।
</Note>

प्रमाणित वर्कस्पेस में एक API कुंजी का मेटाडेटा लौटाता है। पथ सेगमेंट `{id}` कुंजी का ID है। किसी पुराने रिस्पॉन्स से सहेजा गया कुंजी हैश अब भी स्वीकार किया जाता है, लेकिन रिस्पॉन्स में अब यह शामिल नहीं होता।
