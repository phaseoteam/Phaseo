<Note>
इस एंडपॉइंट के लिए प्रबंधन API कुंजी आवश्यक है। मानक Gateway API कुंजियाँ स्वीकार नहीं की जातीं।
</Note>

प्रमाणित वर्कस्पेस में एक API कुंजी का मेटाडेटा लौटाता है। पथ सेगमेंट `{id}` में कुंजी का आंतरिक ID या API द्वारा लौटाया गया कुंजी हैश हो सकता है।
