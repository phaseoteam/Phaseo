<Note>इस एंडपॉइंट के लिए `presets:write` वाली प्रबंधन API कुंजी और संबद्ध उपयोगकर्ता पहचान आवश्यक है।</Note>

प्रीसेट कॉन्फ़िगरेशन में सीमित प्रॉम्प्ट, पैरामीटर, रूटिंग और प्लगइन डिफ़ॉल्ट शामिल हो सकते हैं। सार्वजनिक प्रीसेट में वर्कस्पेस प्रकाशक हैंडल इस्तेमाल होता है।
