यह एंडपॉइंट [बीटा](../../developers/feature-maturity.mdx) चरण में है और अनुरोध पर हर वर्कस्पेस के लिए अलग से चालू किया जाता है।

साझा Gateway कुंजी का उपयोग करते समय, इस एंडपॉइंट पर निर्भर रहने के बजाय अपलोड के समय दर्ज की गई फ़ाइल ID का उपयोग करें।
