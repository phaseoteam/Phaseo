कनेक्टिविटी की त्वरित जाँच के लिए इस बिना-प्रमाणीकरण वाले एंडपॉइंट का उपयोग करें। मौजूदा घटनाओं और इतिहास के लिए [Phaseo स्थिति पृष्ठ](https://status.phaseo.app) देखें।

<Note>
स्वास्थ्य जाँच सफल होने का अर्थ यह नहीं कि हर प्रदाता या मॉडल रूट उपलब्ध है। अभी उपलब्ध रूट की पुष्टि के लिए डिफ़ॉल्ट `GET /v1/models` प्रतिक्रिया का उपयोग करें।
</Note>
