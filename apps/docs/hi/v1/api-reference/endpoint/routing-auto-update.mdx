यह एंडपॉइंट [अल्फा](../../developers/feature-maturity.mdx) चरण में है और अनुरोध पर हर वर्कस्पेस के लिए अलग से चालू किया जाता है।

<Note>इस एंडपॉइंट के लिए `settings:write` आवश्यक है। वर्कस्पेस के स्वामी और एडमिन ये सेटिंग बदल सकते हैं।</Note>
