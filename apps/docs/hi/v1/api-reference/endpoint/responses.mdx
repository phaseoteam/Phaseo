## सर्वर टूल का उपयोग करें

`tools` में अपने function टूल के साथ एक `phaseo:` टूल जोड़ें, और जब मॉडल उसे कॉल करता है तो Phaseo उसे चलाता है। `/v1/responses` हर सर्वर टूल स्वीकार करता है, जिसमें `phaseo:apply_patch` भी शामिल है, जिसे सिर्फ़ यही एंडपॉइंट सपोर्ट करता है; [सर्वर टूल](../../guides/server-tools) गाइड में उनकी सूची है।

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": [
      { "role": "user", "content": "Give me the current datetime in Asia/Tokyo." }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["Asia/Tokyo"] } }
    ],
    "tool_choice": "auto"
  }'
```

हर सर्वर टूल कॉल `usage.server_tool_use` में गिनी जाती है:

| टूल | काउंटर |
| --- | --- |
| `phaseo:datetime` | `datetime_requests` |
| `phaseo:web_search` | `web_search_requests`, `web_search_results`, `web_search_extra_results` |
| `phaseo:web_fetch` | `web_fetch_requests` |
| `phaseo:advisor` | `advisor_requests` |
| `phaseo:subagent` | `subagent_requests` |
| `phaseo:fusion` | `fusion_requests` |
| `phaseo:search_models` | `search_models_requests` |
| `phaseo:image_generation` | `image_generation_requests` |
| `phaseo:apply_patch` | `apply_patch_requests` |

पुराना `gateway:datetime` टाइप अब भी काम करता है। `stream: true` के साथ, Phaseo टूल टर्न खुद चलाता है, फिर आगे का उत्तर आपको एक ही स्ट्रीम में भेजता है।

## टूल लूप में रीज़निंग

OpenAI, Azure OpenAI और xAI पर, Phaseo Responses अनुरोध अपस्ट्रीम में `store: false` के साथ भेजता है, इसलिए टूल लूप के चरणों के बीच मॉडल की रीज़निंग सिर्फ़ `reasoning` आउटपुट items के ज़रिए जारी रहती है।

हर `reasoning` item में `id`, `summary` और `content` होते हैं। जब प्रदाता रीज़निंग स्थिति लौटाता है, तो item में `encrypted_content` भी होता है, जिसमें इनमें से एक होता है:

- OpenAI, Azure OpenAI और xAI की encrypted reasoning। रीज़निंग मॉडल के लिए Phaseo इसे `include: ["reasoning.encrypted_content"]` के साथ मांगता है।
- Claude thinking signatures और redacted thinking।
- Gemini thought signatures, जिनमें एक अलग `reasoning` item भी शामिल है जो उस function call के ठीक पहले रखा जाता है जिससे signature जुड़ा है।

स्ट्रीमिंग प्रतिक्रियाएं यही items `response.output_item.done` और `response.completed` पर भेजती हैं।

टूल लूप जारी रखने के लिए, हर आउटपुट item, जिनमें `reasoning` items भी शामिल हैं, `input` में बिना बदले वापस भेजें। `encrypted_content` अपारदर्शी है और उसे बनाने वाले प्रदाता और मॉडल को दर्ज करता है। Phaseo इसे सिर्फ़ उसी प्रदाता परिवार और मॉडल को भेजता है, इसलिए किसी दूसरे प्रदाता पर फ़ॉलबैक होने पर यह विफल होने के बजाय हटा दिया जाता है।
