उम्मीदवार दस्तावेज़ों को खोज, पुनर्प्राप्ति या जनरेशन चरण में भेजने से पहले क्रमबद्ध करने के लिए इस एंडपॉइंट का उपयोग करें।

डिप्लॉयमेंट से पहले `GET /v1/models` में मॉडल सत्यापित करें। डिफ़ॉल्ट प्रतिक्रिया में केवल सार्वजनिक Gateway रूट वाले मॉडल होते हैं।
