अनुरोध भेजने से पहले यह एंडपॉइंट कॉल करें, ताकि पुष्टि हो सके कि मॉडल, प्रदाता, एंडपॉइंट और पैरामीटर का संयोजन उपलब्ध है। `openai/gpt-6-astra` के लिए:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

`endpoints` की हर प्रविष्टि एक एंडपॉइंट के लिए एक प्रदाता रूट है:

| फ़ील्ड | इसमें क्या है |
| --- | --- |
| `endpoint`, `capability_id`, `public_path`, `collection` | मानक एंडपॉइंट और क्षमता ID, और सार्वजनिक API पथ |
| `provider`, `model` | प्रदाता का ID और नाम, और प्रदाता का मॉडल स्लग |
| `routable`, `status`, `status_reason` | रूट अभी ट्रैफ़िक लेता है या नहीं, उसकी उपलब्धता, और वह सिर्फ़ पूर्वावलोकन या निष्क्रिय क्यों है |
| `modalities` | इनपुट और आउटपुट मोडैलिटी |
| `capabilities` | समर्थित पैरामीटर नाम और संरचित पैरामीटर विवरण |
| `routing` | प्रदाता, मॉडल और क्षमता की रूटिंग स्थितियां |
| `effective` | जब रूट शेड्यूल्ड या समय-सीमित हो, तब `from` और `to` तारीखें |
| `pricing` | एंडपॉइंट की कीमतों का सारांश |

पहले मॉडलों की तुलना करने के लिए [मॉडल सूचीबद्ध करें](./models.mdx) का उपयोग करें; API द्वारा उपलब्ध हर एंडपॉइंट देखने के लिए [एंडपॉइंट सूचीबद्ध करें](./endpoints.mdx) का उपयोग करें।

## नियोजित और निष्क्रिय रूट शामिल करें

डिफ़ॉल्ट `availability=active` सिर्फ़ सार्वजनिक रूप से रूट होने योग्य पंक्तियां लौटाता है। जल्द आने वाले और निष्क्रिय रूट देखने के लिए `availability=all` का उपयोग करें:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints?availability=all" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

प्रोडक्शन ट्रैफ़िक सिर्फ़ उसी पंक्ति पर रूट करें जिसका `routable` `true` और `status` `active` हो।

## रूट फ़िल्टर करें

ये फ़िल्टर दोहराए गए पैरामीटर या कॉमा से अलग की गई सूची स्वीकार करते हैं: `provider`, `provider_status`, `provider_routing_status`, `model_routing_status`, `capability_status`, `provider_availability_status`, `provider_availability_reason`, `status`, और `supported_parameters` (उपनाम `params`)। इनके मान [मॉडल सूचीबद्ध करें](./models.mdx#filter-the-list) में बताए गए हैं।

यह उन OpenAI रूट को लौटाता है जो `reasoning_effort` का समर्थन करते हैं:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints?provider=openai&supported_parameters=reasoning_effort" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```
