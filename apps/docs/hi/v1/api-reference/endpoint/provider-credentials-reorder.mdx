चुने गए प्रोवाइडर और रूटिंग समूह की हर क्रेडेंशियल ID ठीक एक बार दें। पहली ID को सबसे अधिक प्राथमिकता मिलती है। अधूरे या डुप्लिकेट क्रम अस्वीकार किए जाते हैं।
