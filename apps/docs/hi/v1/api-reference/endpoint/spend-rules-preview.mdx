`spend_rules:read` आवश्यक है। कुछ भी भेजा या दर्ज नहीं होता। पूर्वानुमान, उछाल और बैलेंस नियमों में उनका अपना `forecast`, `spike` या `balance` ऑब्जेक्ट होता है।
