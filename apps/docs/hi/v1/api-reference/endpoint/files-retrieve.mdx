यह एंडपॉइंट [बीटा](../../developers/feature-maturity.mdx) चरण में है और अनुरोध पर हर वर्कस्पेस के लिए अलग से चालू किया जाता है।

यह रूट upstream फ़ाइल मेटाडेटा को रीफ़्रेश करता है और response proxy करने से पहले वर्कस्पेस के स्वामित्व की पुष्टि करता है।
