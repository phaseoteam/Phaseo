`spend_rules:write` आवश्यक है। OAuth कॉलर का वर्कस्पेस का मालिक या एडमिन होना ज़रूरी है। हर राशि USD (`*_usd`) या नैनोडॉलर (`*_nanos`) में से किसी एक में भेजें, दोनों में नहीं। एक वर्कस्पेस में 50 खर्च नियम हो सकते हैं। मीट्रिक, आधार, दायरे और अवधियों के लिए [खर्च अलर्ट गाइड](../../guides/spend-alerts.mdx) देखें।
