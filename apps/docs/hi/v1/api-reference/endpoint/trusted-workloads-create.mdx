<Note>इसके लिए प्रबंधन कुंजी या OAuth टोकन पर `keys:write`, या वर्कस्पेस का मालिक या एडमिन आवश्यक है। भरोसेमंद वर्कलोड बीटा में है; जिन वर्कस्पेस के पास यह सुविधा नहीं है, उन्हें `404` मिलता है।</Note>

पॉलिसी कैसे काम करती हैं और Terraform से उन्हें कैसे प्रबंधित करें, यह जानने के लिए [भरोसेमंद वर्कलोड](../../developers/trusted-workloads.mdx) देखें।
