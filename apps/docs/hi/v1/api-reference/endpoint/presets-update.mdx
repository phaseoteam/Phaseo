<Note>इस एंडपॉइंट के लिए `presets:write` वाली प्रबंधन API कुंजी आवश्यक है।</Note>

पूरी ड्राफ़्ट कॉन्फ़िगरेशन बदलने के लिए `replace_config` उपयोग करें। अन्यथा दिए गए कॉन्फ़िगरेशन फ़ील्ड शीर्ष स्तर पर मर्ज किए जाते हैं।
