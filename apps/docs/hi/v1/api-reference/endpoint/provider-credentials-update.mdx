`key` देने पर एन्क्रिप्टेड सीक्रेट बदल जाता है। इसे छोड़ने पर मौजूदा सीक्रेट बना रहता है। मॉडल और API कुंजी allowlist वैकल्पिक हैं; खाली सूची वर्कस्पेस के सभी मॉडल या API कुंजियों को अनुमति देती है।
