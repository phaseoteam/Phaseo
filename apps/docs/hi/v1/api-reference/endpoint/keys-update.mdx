<Note>इस एंडपॉइंट के लिए प्रबंधन API कुंजी आवश्यक है। मानक Gateway API कुंजियां स्वीकार नहीं की जातीं।</Note>

इस रूट से कुंजी का नाम बदलें, स्कोप समायोजित करें, समाप्ति तय करें, उसे अक्षम करें या `limit` और `limit_reset` से खर्च सीमा सेट करें।
