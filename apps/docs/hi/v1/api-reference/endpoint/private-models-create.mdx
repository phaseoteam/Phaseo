`private_models:write` और मालिक या एडमिन की पहचान आवश्यक है। `model_reference` में कैटलॉग का सटीक मॉडल ID या वर्कस्पेस का छोटा स्थानीय स्लग दें। Phaseo अंतिम मॉडल ID निर्धारित करता है; `credential` एन्क्रिप्ट किया जाता है और केवल लिखा जा सकता है।
