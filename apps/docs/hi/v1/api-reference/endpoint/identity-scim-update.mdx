<Note>Identity प्रशासन के लिए owner या admin identity आवश्यक है। SSO या SCIM चालू करने और provisioning tokens बनाने के लिए identity add-on चाहिए。</Note>

केवल वर्कस्पेस का मालिक SCIM प्रोविज़निंग बदल सकता है या उसके टोकन बना और रद्द कर सकता है। SCIM अनुरोध केवल उसी टोकन से स्वीकार किए जाते हैं जिसे वर्कस्पेस के मौजूदा मालिक ने बनाया हो; अगर आपका टोकन किसी एडमिन या पिछले मालिक ने बनाया था, तो मालिक को नया टोकन बनाना होगा।
