जब ऐप्लिकेशन को ऐसे संरचित उत्तर चाहिए जिन्हें कोड सीधे इस्तेमाल कर सके, तो `POST /v1/decisions` इस्तेमाल करें। समर्थित मॉडल में TypeSafe Jev 1.13 (`typesafe/jev-1.13.0`), Together Tev1 4B Experimental (`together/tev1-4b-experimental`) और Respan Span-01 (`respan/span-01:free` तथा `respan/span-01`) शामिल हैं।

अनुरोध में ये शामिल हैं:

- `state`: मूल्यांकन की जानकारी वाली स्ट्रिंग, ऑब्जेक्ट या ऐरे।
- `questions`: नाम वाले प्रश्नों का मैप। हर प्रश्न में `type` को `noul`, `choice` या `score` रखा जाता है और `instructions` शामिल होता है; समर्थित प्रकार चुने गए मॉडल पर निर्भर हैं।
- `model`: Phaseo मॉडल आईडी। Jev 1.13 के लिए `typesafe/jev-1.13.0` या नवीनतम Jev रिलीज़ के लिए `typesafe/jev-latest` इस्तेमाल करें।

Liquid D1 (`liquid-ai/d1:free`, `liquid-ai/d1` के रूप में भी उपलब्ध) और Perplexity Decider 27B (`perplexity/decider-27b`) तीनों प्रश्न प्रकारों का समर्थन करते हैं। D1 प्रयोगात्मक शुरुआती पहुँच के दौरान मुफ़्त है। Decider की कीमत चित्र टोकन सहित प्रति दस लाख इनपुट टोकन 0.04 अमेरिकी डॉलर है; आउटपुट टोकन मुफ़्त हैं। Decider के लिए Phaseo में Perplexity प्रदाता क्रेडेंशियल जोड़ें। चित्र वाली स्थिति PNG, JPEG या WebP के base64 डेटा URL इस्तेमाल करती है; दूरस्थ चित्र URL समर्थित नहीं हैं। हर चयन प्रश्न में अधिकतम 255 विकल्प और हर स्कोर प्रश्न में अधिकतम 10 स्तर हो सकते हैं। दोनों में से किसी मॉडल को कॉल करने से पहले उसकी उपलब्धता जाँचें।

Respan Span-01 के लिए `state` बातचीत का ऐसा भाग होना चाहिए जिसमें पिछले संदेशों का `input` ऐरे और सहायक का `output` संदेश हो। Span-01 केवल `noul` प्रश्नों का समर्थन करता है। `noul` उत्तर व्यवहार मौजूद होने की संभावना है; `probabilities` में अनुपस्थित और न देखे जा सकने की संभावनाएँ भी हैं।

```json
{
  "model": "respan/span-01:free",
  "state": {
    "input": [{ "role": "user", "content": "Please connect me to a person." }],
    "output": { "role": "assistant", "content": "I will connect you to support." }
  },
  "questions": {
    "escalation": {
      "type": "noul",
      "instructions": "Does the assistant offer a human handoff?"
    }
  }
}
```

`respan/span-01:free` दैनिक सीमा वाला मुफ़्त Lite मॉडल है; Phaseo इसे Respan की API मॉडल आईडी `span-01-free` से मैप करता है। `respan/span-01`, Respan की API मॉडल आईडी `span-01-pro` से मैप होता है और Respan प्रति दस लाख इनपुट टोकन 0.02 अमेरिकी डॉलर लेता है; आउटपुट टोकन मुफ़्त हैं। Span-01 शुरुआती पहुँच में है, इसलिए Respan को आपके संगठन के लिए पहुँच सक्षम करनी होगी। इन मॉडल को कॉल करने से पहले अपनी Respan API कुंजी Phaseo में Respan प्रदाता क्रेडेंशियल के रूप में जोड़ें।

उत्तर `questions` वाली ही कुंजियाँ इस्तेमाल करते हैं। `choice` उत्तर में चुना हुआ विकल्प, संभावनाएँ और विश्वास स्तर होते हैं; `noul` उत्तर में 0–1 की संभावना होती है; और `score` उत्तर में संभावना-भारित स्कोर, संकेत विवरण, संभावनाएँ और विश्वास स्तर होते हैं।

Respan उदाहरण के लिए प्रतिक्रिया इस प्रकार होती है:

```json
{
  "answers": {
    "escalation": {
      "type": "noul",
      "noul": 0.73,
      "probabilities": {
        "true": 0.73,
        "false": 0.25,
        "not_observable": 0.02
      }
    }
  }
}
```

Jev एक अनुरोध में तीनों प्रश्न प्रकारों को मिलाने का समर्थन करता है; Span-01 केवल `noul` प्रश्नों का समर्थन करता है। कॉपी-पेस्ट करने योग्य cURL, JavaScript, TypeScript SDK और Python SDK उदाहरणों के लिए [त्वरित शुरुआत](../../quickstart) देखें। Jev 1.13 की कीमत प्रति दस लाख इनपुट टोकन 0.042 अमेरिकी डॉलर है; आउटपुट टोकन मुफ़्त हैं।

प्रदाता के प्रश्नों के अर्थ के लिए TypeSafe का [API संदर्भ](https://docs.typesafe.ai/api) देखें।

### Clef के साथ चित्र निर्णय

`cloudflare/clef` और `cloudflare/clef-flash`, Cloudflare Workers AI के ज़रिए तीनों प्रश्न प्रकार और एम्बेड किए गए चित्रों का समर्थन करते हैं। दोनों की कॉन्टेक्स्ट विंडो 65,536 टोकन है। इनपुट की कीमत प्रति दस लाख टोकन Clef के लिए 0.24 USD और Clef Flash के लिए 0.09 USD है।

```json
{
  "model": "cloudflare/clef-flash",
  "state": "Inspect the attached product photo.",
  "images": [{ "content_type": "image/png", "base64": "<base64 image bytes>" }],
  "questions": {
    "damaged": { "type": "noul", "instructions": "Is the product visibly damaged?" }
  }
}
```

आप `images` में `data:image/png;base64,...` स्ट्रिंग भी दे सकते हैं। Clef अधिकतम चार PNG, JPEG या WebP चित्र स्वीकार करता है। हर चित्र अधिकतम 4 MiB और 16 मेगापिक्सल का हो सकता है; डिकोड किए गए चित्र डेटा की कुल सीमा 8 MiB और अनुरोध बॉडी की सीमा 13 MiB है। रिमोट URL समर्थित नहीं हैं। Cloudflare चित्रों के प्रारूप और आयाम जाँचता है। जिन मॉडलों में चित्र समर्थन नहीं है, वे चित्र अनुरोध अस्वीकार करते हैं।

Clef अधिकतम 64 प्रश्न स्वीकार करता है। ID में अधिकतम 100 अक्षर, अंक, अंडरस्कोर, डॉट या हाइफ़न हो सकते हैं। विकल्प वाले प्रश्नों में 2–255 विकल्प और स्कोर वाले प्रश्नों में 2–10 स्तर आवश्यक हैं। Cloudflare के [Clef दस्तावेज़](https://developers.cloudflare.com/workers-ai/models/clef/) देखें।

### GPT-6 Luna

Phaseo के मौजूदा Decisions प्रारूप के साथ `openai/gpt-6-luna` इस्तेमाल करें। OpenAI एडेप्टर `state` को इनपुट डेटा, `noul` को प्रेडिकेट, विकल्प मानदंडों को विकल्पों और स्कोर मानदंडों को क्रमबद्ध स्तरों में बदलता है। स्टेट या निर्देशों में मौजूद ऑब्जेक्ट और ऐरे JSON टेक्स्ट के रूप में क्रमबद्ध होते हैं।

```json
{
  "model": "openai/gpt-6-luna",
  "state": "I was charged twice for my order.",
  "questions": {
    "department": {
      "type": "choice",
      "instructions": "Which department should handle this?",
      "criteria": {
        "billing": "Payments and refunds",
        "other": "Everything else"
      }
    }
  }
}
```

Luna, Clef की तरह ही एम्बेड की गई छवियों के लिए `images` फ़ील्ड स्वीकार करता है। Phaseo फ़िलहाल सभी निर्णय अनुरोधों को चार PNG, JPEG या WebP छवियों और 128 नाम वाले प्रश्नों तक सीमित करता है। Phaseo, OpenAI का ऐरे-आधारित अनुरोध प्रारूप स्वीकार नहीं करता।

अगर OpenAI किसी प्रश्न का उत्तर देने से इनकार करता है, तो मूल प्रश्न की कुंजी के अंतर्गत उत्तर `{ "type": "refusal" }` होता है। प्रायिकता, विकल्प या स्कोर इस्तेमाल करने से पहले उत्तर का प्रकार जाँचें।

OpenAI Decisions सार्वजनिक बीटा में है। मानक इनपुट दर प्रति दस लाख टोकन $0.10 है। आउटपुट या कैश के लिए अलग शुल्क नहीं है; लंबे संदर्भ के गुणक लागू होते हैं। ये दरें Decisions की हैं और Luna चैट की कीमतें नहीं बदलतीं। [OpenAI Decisions गाइड](https://developers.openai.com/api/docs/guides/decisions) देखें।
