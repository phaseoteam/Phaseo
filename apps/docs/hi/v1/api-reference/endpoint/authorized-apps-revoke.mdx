<Note>इस एंडपॉइंट के लिए `oauth_clients:delete` वाला OAuth एक्सेस टोकन आवश्यक है। कॉल करने वाले ऐप का अपना प्राधिकरण रद्द करने पर वह साइन आउट हो जाता है।</Note>
