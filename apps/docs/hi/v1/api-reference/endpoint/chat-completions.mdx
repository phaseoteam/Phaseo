## सर्वर टूल

`/v1/chat/completions` सामान्य फ़ंक्शन टूल और Gateway द्वारा प्रबंधित इन सर्वर टूल का समर्थन करता है:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

### दिनांक और समय का उदाहरण

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Europe/London" }
      }
    ],
    "tool_choice": "auto"
  }'
```

सर्वर टूल उपयोग होने पर उपयोग विवरण में ये शामिल होते हैं:

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` से `server_tool_use.web_search_requests`, `server_tool_use.web_search_results` और `server_tool_use.web_search_extra_results` जुड़ते हैं। `phaseo:web_fetch` से `server_tool_use.web_fetch_requests` जुड़ता है।

## स्ट्रीमिंग नोट

`stream: true` भी समर्थित है। Gateway द्वारा प्रबंधित सर्वर टूल के लिए Phaseo अपस्ट्रीम टूल कॉल वाला टर्न तैयार कर सकता है, और लूप जारी रखने के बाद सिंथेटिक स्ट्रीम दोबारा भेज सकता है।

## टूल लूप में रीज़निंग

रीज़निंग मॉडल अपनी रीज़निंग असिस्टेंट संदेश के दो फ़ील्ड में लौटाते हैं:

- `reasoning_content`: रीज़निंग टेक्स्ट, अगर प्रदाता उसे लौटाता है।
- `reasoning_details`: रीज़निंग ब्लॉक की एक array, उसी फ़ॉर्मैट में जिसका उपयोग OpenRouter करता है। हर एंट्री में `type` (`reasoning.text`, `reasoning.summary` या `reasoning.encrypted`), `index` और प्रदाता परिवार बताने वाला `format` होता है, जैसे `anthropic-claude-v1` या `google-gemini-v1`।

एंट्री में वह प्रदाता स्थिति हो सकती है जिसकी मॉडल को टूल लूप के अगले चरण में ज़रूरत होती है:

- Claude के thinking सिग्नेचर, `reasoning.text` एंट्री के `signature` में।
- Claude की छिपाई गई thinking और OpenAI की एन्क्रिप्टेड रीज़निंग, `reasoning.encrypted` एंट्री के `data` में।
- Gemini के थॉट सिग्नेचर, उन `reasoning.encrypted` एंट्री के `data` में जिनका `id` संबंधित टूल कॉल है।

स्ट्रीमिंग में, हर रीज़निंग ब्लॉक पूरा होने पर एक `reasoning_details` डेल्टा आता है।

चरणों के बीच मॉडल की रीज़निंग बनाए रखने के लिए, असिस्टेंट संदेश को उसके `reasoning_details` के साथ बिना बदलाव वापस भेजें। `signature` और `data` के मान अपारदर्शी होते हैं और उन्हें बनाने वाले प्रदाता और मॉडल को दर्ज करते हैं। Phaseo उन्हें केवल उसी प्रदाता परिवार और मॉडल को भेजता है, इसलिए किसी दूसरे प्रदाता पर फ़ॉलबैक होने पर वे विफल होने के बजाय हटा दिए जाते हैं। मैनुअल thinking मोड वाले Claude मॉडल को टूल लूप के दौरान thinking जारी रखने के लिए अपनी thinking वापस चाहिए; अगर वह नहीं है, तो वह चरण बिना thinking के चलता है।
