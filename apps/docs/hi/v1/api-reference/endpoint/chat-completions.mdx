## सर्वर टूल

`/v1/chat/completions` सामान्य फ़ंक्शन टूल और Gateway द्वारा प्रबंधित इन सर्वर टूल का समर्थन करता है:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

### दिनांक और समय का उदाहरण

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Europe/London" }
      }
    ],
    "tool_choice": "auto"
  }'
```

सर्वर टूल उपयोग होने पर उपयोग विवरण में ये शामिल होते हैं:

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` से `server_tool_use.web_search_requests`, `server_tool_use.web_search_results` और `server_tool_use.web_search_extra_results` जुड़ते हैं। `phaseo:web_fetch` से `server_tool_use.web_fetch_requests` जुड़ता है।

## स्ट्रीमिंग नोट

`stream: true` भी समर्थित है। Gateway द्वारा प्रबंधित सर्वर टूल के लिए Phaseo अपस्ट्रीम टूल कॉल वाला टर्न तैयार कर सकता है, और लूप जारी रखने के बाद सिंथेटिक स्ट्रीम दोबारा भेज सकता है।
