## सर्वर टूल का उपयोग करें

`tools` में अपने function टूल के साथ एक `phaseo:` टूल जोड़ें, और जब मॉडल उसे कॉल करता है तो Phaseo उसे चलाता है। `/v1/chat/completions` `phaseo:apply_patch` को छोड़कर हर सर्वर टूल स्वीकार करता है; [सर्वर टूल](../../guides/server-tools) गाइड में उनकी सूची है।

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["Europe/London"] } }
    ],
    "tool_choice": "auto"
  }'
```

हर सर्वर टूल कॉल `usage.server_tool_use` में गिनी जाती है:

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` `web_search_requests`, `web_search_results` और `web_search_extra_results` जोड़ता है; `phaseo:web_fetch` `web_fetch_requests` जोड़ता है। पुराना `gateway:datetime` टाइप अब भी काम करता है।

`stream: true` के साथ, Phaseo टूल टर्न खुद चलाता है, फिर आगे का उत्तर आपको एक ही स्ट्रीम में भेजता है।

## टूल लूप में रीज़निंग

रीज़निंग मॉडल assistant संदेश पर अपनी रीज़निंग दो फ़ील्ड में लौटाते हैं:

- `reasoning_content`: रीज़निंग टेक्स्ट, अगर प्रदाता कोई लौटाता है।
- `reasoning_details`: रीज़निंग blocks की एक array। हर प्रविष्टि में `reasoning.text`, `reasoning.summary` या `reasoning.encrypted` में से एक `type`, एक `index`, और प्रदाता परिवार बताने वाला `format` होता है, जैसे `anthropic-claude-v1` या `google-gemini-v1`।

प्रविष्टियों में ऐसी प्रदाता स्थिति हो सकती है जिसकी मॉडल को टूल लूप के अगले चरण में ज़रूरत होती है:

| प्रदाता स्थिति | यह कहां है |
| --- | --- |
| Claude thinking signatures | `reasoning.text` प्रविष्टियों पर `signature` |
| Claude redacted thinking, OpenAI encrypted reasoning | `reasoning.encrypted` प्रविष्टियों पर `data` |
| Gemini thought signatures | उन `reasoning.encrypted` प्रविष्टियों पर `data` जिनका `id` उस टूल कॉल का है जिससे वे जुड़ी हैं |

स्ट्रीमिंग के दौरान, हर रीज़निंग block पूरा होने पर एक `reasoning_details` delta आता है।

चरणों के बीच मॉडल की रीज़निंग बनाए रखने के लिए, assistant संदेश को उसके `reasoning_details` के साथ बिना बदले वापस भेजें। `signature` और `data` मान अपारदर्शी होते हैं और उन्हें बनाने वाले प्रदाता और मॉडल को दर्ज करते हैं। Phaseo उन्हें सिर्फ़ उसी प्रदाता परिवार और मॉडल को भेजता है, इसलिए किसी दूसरे प्रदाता पर फ़ॉलबैक होने पर वे विफल होने के बजाय हटा दिए जाते हैं। मैनुअल thinking मोड में Claude मॉडल को टूल लूप के दौरान thinking जारी रखने के लिए अपनी thinking वापस चाहिए; अगर वह नहीं है, तो वह चरण बिना thinking के चलता है।
