<Info>
गार्डरेल प्रबंधन के लिए प्रबंधन API कुंजी आवश्यक है। पढ़ने के लिए `guardrails:read` और बदलाव के लिए `guardrails:write` या `guardrails:delete` आवश्यक है।
</Info>

गोपनीयता नियंत्रण, प्रदाता और मॉडल प्रतिबंध, प्रॉम्प्ट-इंजेक्शन से निपटने और संवेदनशील जानकारी की नीतियाँ लागू करने के लिए सुरक्षा नियमों का उपयोग करें। सुरक्षा नियम API कुंजियों, वर्कस्पेस के सदस्यों या दोनों को सौंपा जा सकता है।

सुरक्षा नियम अनुरोध या खर्च की सीमाएँ लागू नहीं करते। `budgets` इनपुट और `*_limit_requests` तथा `*_limit_cost_nanos` फ़ील्ड संगतता के लिए स्वीकार किए और लौटाए जाते हैं, लेकिन उनका कोई असर नहीं होता। इसके बजाय [API कुंजी की सीमाएँ](./keys-update.mdx) या [वर्कस्पेस बजट](./budgets-list.mdx) इस्तेमाल करें।

सफल बदलाव वर्कस्पेस नीति की स्थिति रीफ़्रेश करते हैं और वर्कस्पेस ऑडिट लॉग में दिखाई देते हैं।
