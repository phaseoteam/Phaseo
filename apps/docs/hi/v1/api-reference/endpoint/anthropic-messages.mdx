`/v1/messages` Anthropic Messages API के पेलोड स्वीकार करता है और Anthropic फ़ॉर्मैट में प्रतिक्रियाएँ लौटाता है।

## स्ट्रीमिंग

Anthropic फ़ॉर्मैट में सर्वर से भेजे गए इवेंट (`message_start`, `content_block_*`, `message_delta`, `message_stop`) पाने के लिए `stream: true` सेट करें।

## बातचीत के बीच सिस्टम संदेश

बातचीत में किसी बिंदु से लागू होने वाले निर्देश के लिए `messages` में `role: "system"` वाला संदेश जोड़ें। टॉप-लेवल `system` फ़ील्ड नहीं बदलता, इसलिए कैश किया गया प्रीफ़िक्स पहले की तरह इस्तेमाल होता रहता है।

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5.5",
    "max_tokens": 512,
    "system": "You are a code review assistant.",
    "messages": [
      { "role": "user", "content": "Review process() in utils.py." },
      { "role": "assistant", "content": "The loop is fine; the regex is compiled on every call." },
      { "role": "user", "content": "Now review the code that calls it." },
      { "role": "system", "content": "From now on, include type annotations in every suggestion." }
    ]
  }'
```

- सिस्टम संदेश एक स्ट्रिंग या टेक्स्ट ब्लॉक लेता है। यह उपयोगकर्ता टर्न (या सर्वर टूल परिणाम पर खत्म होने वाले असिस्टेंट टर्न) के ठीक बाद आना चाहिए, और अंतिम संदेश होना चाहिए या उसके बाद असिस्टेंट टर्न आना चाहिए। किसी और जगह पर 400 त्रुटि मिलती है।
- Claude Fable 5 और 5.1, Mythos 5 और 5.1, Opus 4.8, Opus 5 और 5.5, Sonnet 5.5 और Haiku 5.5 इसे उसी जगह पर पाते हैं। Sonnet 5 सहित बाकी Claude मॉडल, और Microsoft Foundry पर हर Claude मॉडल, इसे टॉप-लेवल सिस्टम प्रॉम्प्ट के हिस्से के रूप में पाते हैं। अन्य प्रदाता इसे सिस्टम संदेश के रूप में पाते हैं, ठीक वैसे ही जैसे Chat Completions को भेजा गया संदेश।
- `clear_at`, `output_config` और `tool_addition` या `tool_removal` ब्लॉक समर्थित नहीं हैं।

## ध्यान दें

- Anthropic के टूल उपयोग वाले फ़ील्ड समर्थित हैं।
- `stream: true` टूल लूप के साथ भी काम करता है। गेटवे द्वारा प्रबंधित सर्वर टूल के लिए Phaseo अपस्ट्रीम टूल कॉल वाले टर्न को पूरा प्राप्त करके लूप जारी रख सकता है और एक सिंथेटिक स्ट्रीम फिर से भेज सकता है।
- Anthropic का मूल वेब खोज टूल स्वरूप भी सीधे `tools` में स्वीकार किया जाता है, जैसे `type: "web_search_20250305"`।
- `X-Phaseo-Strictness` हेडर तय करता है कि असमर्थित पैरामीटर कैसे संभाले जाएँ।

## सर्वर टूल

`/v1/messages` गेटवे द्वारा प्रबंधित इन सर्वर टूल का भी समर्थन करता है:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

Phaseo इन टूल को अपस्ट्रीम के लिए Anthropic-संगत फ़ॉर्मैट में बदलता है, उन्हें सर्वर पर चलाता है और टूल लूप जारी रखता है।

## प्रदाता की मूल वेब खोज

जब कोई संगत Anthropic मॉडल/प्रदाता जोड़ी मूल वेब खोज का समर्थन करती है, तो आप मूल टूल परिभाषा सीधे भी भेज सकते हैं:

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-4",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "Find the latest Anthropic web search guidance." }
    ],
    "tools": [
      {
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": 3,
        "allowed_domains": ["docs.anthropic.com"]
      }
    ],
    "tool_choice": { "type": "tool", "name": "web_search" }
  }'
```

प्रदाता रूटिंग निष्पादन से पहले अब भी `web_search_options` समर्थन के आधार पर फ़िल्टर करती है।

### दिनांक और समय का उदाहरण

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-4",
    "max_tokens": 512,
    "stream": false,
    "messages": [
      { "role": "user", "content": "What time is it in America/New_York right now?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "America/New_York" }
      }
    ],
    "tool_choice": { "type": "auto" }
  }'
```

उपयोग होने पर `usage.server_tool_use.*` काउंटर सर्वर टूल कॉल की गिनती बताते हैं।
