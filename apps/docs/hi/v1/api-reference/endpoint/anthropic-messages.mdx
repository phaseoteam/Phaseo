`/v1/messages` पर Anthropic Messages API पेलोड भेजें और Phaseo द्वारा रूट किए जाने वाले किसी भी मॉडल से Anthropic फ़ॉर्मैट में प्रतिक्रिया पाएं। Anthropic के tool-use फ़ील्ड समर्थित हैं, और `X-Phaseo-Strictness` हेडर तय करता है कि असमर्थित पैरामीटर के साथ क्या किया जाए।

Anthropic फ़ॉर्मैट में server-sent events (`message_start`, `content_block_*`, `message_delta`, `message_stop`) पाने के लिए `stream: true` सेट करें। स्ट्रीमिंग टूल लूप में भी काम करती है।

## बातचीत के बीच सिस्टम संदेश

बातचीत में किसी खास बिंदु से लागू होने वाले निर्देश के लिए `messages` में एक `role: "system"` संदेश जोड़ें। शीर्ष-स्तर का `system` फ़ील्ड वैसा ही रहता है, इसलिए कैश किया गया प्रीफ़िक्स अब भी हिट होता है।

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5.5",
    "max_tokens": 512,
    "system": "You are a code review assistant.",
    "messages": [
      { "role": "user", "content": "Review process() in utils.py." },
      { "role": "assistant", "content": "The loop is fine; the regex is compiled on every call." },
      { "role": "user", "content": "Now review the code that calls it." },
      { "role": "system", "content": "From now on, include type annotations in every suggestion." }
    ]
  }'
```

सिस्टम संदेश एक string या text blocks लेता है। यह किसी user टर्न के ठीक बाद आना चाहिए (या ऐसे assistant टर्न के बाद जो server tool result पर खत्म होता हो), और या तो आखिरी संदेश होना चाहिए या उसके बाद assistant टर्न आना चाहिए। दूसरी जगहों पर `400` लौटता है। `clear_at`, `output_config`, और `tool_addition` या `tool_removal` blocks समर्थित नहीं हैं।

| मॉडल | इसे सिस्टम संदेश कैसे मिलता है |
| --- | --- |
| Claude Fable 5 और 5.1, Mythos 5 और 5.1, Opus 4.8, Opus 5 और 5.5, Sonnet 5.5, Haiku 5.5 | अपनी जगह पर |
| अन्य Claude मॉडल, जिनमें Sonnet 5 शामिल है, और Microsoft Foundry पर हर Claude मॉडल | शीर्ष-स्तर के सिस्टम प्रॉम्प्ट में मिला दिया जाता है |
| अन्य प्रदाताओं के मॉडल | सिस्टम संदेश के रूप में, ठीक वैसे ही जैसे Chat Completions को भेजा गया हो |

## सर्वर टूल का उपयोग करें

`tools` में एक `phaseo:` टूल जोड़ें, और जब मॉडल उसे कॉल करता है तो Phaseo उसे चलाता है: अपस्ट्रीम में उसे Anthropic के टूल फ़ॉर्मैट में बदलता है और टूल लूप को सर्वर पर जारी रखता है। `/v1/messages` `phaseo:apply_patch` को छोड़कर हर सर्वर टूल स्वीकार करता है; [सर्वर टूल](../../guides/server-tools) गाइड में उनकी सूची है।

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "What time is it in America/New_York right now?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["America/New_York"] } }
    ],
    "tool_choice": { "type": "auto" }
  }'
```

सर्वर टूल कॉल `usage.server_tool_use` में गिनी जाती हैं। पुराना `gateway:datetime` टाइप अब भी काम करता है। `stream: true` के साथ, Phaseo टूल टर्न खुद चलाता है, फिर आगे का उत्तर आपको एक ही स्ट्रीम में भेजता है।

## Anthropic की नेटिव वेब सर्च का उपयोग करें

जब रूट किया गया Anthropic मॉडल और प्रदाता नेटिव वेब सर्च का समर्थन करते हैं, तो Anthropic की टूल परिभाषा सीधे दें, उदाहरण के लिए `type: "web_search_20250305"`। निष्पादन से पहले प्रदाता रूटिंग अब भी `web_search_options` समर्थन के आधार पर फ़िल्टर करती है।

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "Find the latest Anthropic web search guidance." }
    ],
    "tools": [
      {
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": 3,
        "allowed_domains": ["docs.anthropic.com"]
      }
    ],
    "tool_choice": { "type": "auto" }
  }'
```
