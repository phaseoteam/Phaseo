एक उपयोग पेलोड भेजें ताकि एक प्रदाता, मॉडल और एंडपॉइंट के लिए सक्रिय Gateway मूल्य नियमों के अनुसार उसकी कीमत निकाली जा सके। चारों फ़ील्ड आवश्यक हैं:

- `provider`: प्रदाता ID, जैसे `openai`।
- `model`: रूट किए गए मॉडल का ID।
- `endpoint`: एंडपॉइंट परिवार, जैसे `responses` या `chat.completions`।
- `usage`: जिस उपयोग की कीमत निकालनी है, जैसे टोकन की संख्या या अन्य मीटर इनपुट।

किसी एक पेलोड की कीमत निकालने के बजाय मौजूदा कीमतें सूचीबद्ध करने के लिए [मॉडल मूल्य सूचीबद्ध करें](./pricing-models.mdx) का उपयोग करें।
