दिए गए उपयोग पेलोड के लिए सक्रिय गेटवे मूल्य नियमों के अनुसार कीमत की गणना करता है।

यह दें:

- `provider`: प्रदाता ID, जैसे `openai`
- `model`: रूट किए गए मॉडल का ID
- `endpoint`: एंडपॉइंट परिवार, जैसे `responses` या `chat.completions`
- `usage`: मूल्य निकालने वाला उपयोग ऑब्जेक्ट, जैसे टोकन की संख्या या अन्य मीटर इनपुट

जब लक्ष्य प्रदाता/मॉडल/एंडपॉइंट पता हो और किसी खास उपयोग पेलोड का बिल अनुमानित करना हो, तब यह रूट उपयोग करें। इसके विपरीत, `GET /pricing/models` मौजूदा सार्वजनिक कैटलॉग मूल्य सूचीबद्ध करता है।
