- `models`: हर दिखाई देने वाले प्रदाता/मॉडल/एंडपॉइंट संयोजन के लिए एक प्रविष्टि
- `meters`: उस प्रविष्टि की सक्रिय मीटर पंक्तियाँ, जिनमें इकाई, इकाई आकार, मुद्रा और प्रति इकाई कीमत शामिल हैं
- `display_name`: मूल्य नियम के मानक सार्वजनिक मॉडल से मेल खाने पर दिखने वाला सार्वजनिक मॉडल नाम
