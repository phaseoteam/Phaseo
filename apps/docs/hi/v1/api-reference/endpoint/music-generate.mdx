एक ही अनुरोध रूप से किसी भी संगीत प्रदाता से ट्रैक पाने के लिए `POST /v1/music/generate` पर `model` और `prompt` भेजें। सिंक्रोनस प्रदाताओं और प्रदाता की कतार की पोलिंग को Phaseo आपकी ओर से संभालता है।

```bash
curl https://api.phaseo.app/v1/music/generate \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax/music-3.0:free",
    "prompt": "Warm jazz trio with brushed drums",
    "format": "mp3"
  }'
```

## परिणाम पढ़ें

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "gmicloud",
  "model": "minimax/music-3.0:free",
  "nativeResponseId": "5c30b275-d669-4a25-8151-de6d60214853",
  "audio_url": "https://.../generated-music.mp3",
  "usage": {
    "requests": 1,
    "output_audio_seconds": 25.364
  }
}
```

पूरे हुए जनरेशन में `audio_url` या `audio_base64` होता है। `status` का मान `queued`, `in_progress`, `completed` या `failed` होता है। जब यह अभी अंतिम न हो, तो उसी `id` के साथ [`GET /v1/music/generate/{music_id}`](./music-status.mdx) पोल करें।

`id` स्थिर Phaseo अनुरोध ID है। `nativeResponseId` अपस्ट्रीम प्रदाता का पहचानकर्ता है, जो प्रदाता से मिलान और सपोर्ट के लिए है। जब प्रदाता बनाई गई अवधि बताता है, तो `usage` में `output_audio_seconds` शामिल होता है।

## Suno विकल्प सेट करें

Suno मॉडल एक वैकल्पिक `suno` ऑब्जेक्ट लेते हैं:

| फ़ील्ड | प्रकार | नोट्स |
| --- | --- | --- |
| `customMode` | boolean | डिफ़ॉल्ट `false` |
| `instrumental` | boolean | डिफ़ॉल्ट `false` |
| `prompt` | string | शीर्ष-स्तर के `prompt` की जगह लेता है |
| `style`, `title` | string | `customMode` के `true` होने पर आवश्यक |
| `personaId`, `personaModel` | string | |
| `negativeTags` | string | |
| `vocalGender` | `m` या `f` | |
| `styleWeight`, `weirdnessConstraint`, `audioWeight` | number | 0 से 1 |

`customMode` के `false` होने पर `prompt` आवश्यक है, और तब भी जब `customMode` `true` हो और `instrumental` `false` पर सेट हो।

प्रदाता का कोई नियम तोड़ने वाला अनुरोध `400` लौटाता है:

```json
{
  "error": "validation_error",
  "reason": "..."
}
```
