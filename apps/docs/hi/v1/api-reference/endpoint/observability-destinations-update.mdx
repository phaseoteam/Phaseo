<Note>इस एंडपॉइंट के लिए `settings:write` वाली प्रबंधन API कुंजी आवश्यक है।</Note>

मौजूदा एन्क्रिप्टेड कॉन्फ़िगरेशन बनाए रखने के लिए `config` छोड़ दें। इसे देने पर डेस्टिनेशन रिकॉर्ड का कॉन्फ़िगरेशन एटॉमिक रूप से बदल दिया जाएगा।
