<Note>इस एंडपॉइंट के लिए `presets:write` वाली प्रबंधन API कुंजी और संबद्ध उपयोगकर्ता पहचान आवश्यक है।</Note>

सक्रिय संस्करण फोर्क करने के लिए `source_version_id` छोड़ दें। नया प्रीसेट निजी होता है और upstream lineage बनाए रखता है।
