description: "खर्च नियम के फ़ील्ड, गंतव्य या कार्रवाई बदलता है।"
---

`spend_rules:write` आवश्यक है। आपके भेजे गए फ़ील्ड सहेजे गए नियम में मिला दिए जाते हैं, और पूरे नियम की फिर से जाँच होती है। `destination_ids` नियम के गंतव्यों को बदल देता है; उन्हें बनाए रखने के लिए इसे न भेजें। ब्लॉक करने वाले नियम की कार्रवाई, दायरा, अवधि या आधार बदलने पर उसका सक्रिय ब्लॉक हट जाता है।
