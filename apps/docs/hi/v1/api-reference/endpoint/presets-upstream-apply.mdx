<Note>इस एंडपॉइंट के लिए `presets:write` वाली प्रबंधन API कुंजी और संबंधित उपयोगकर्ता पहचान आवश्यक है।</Note>

अपस्ट्रीम संस्करण लागू करने से पहले स्थानीय ड्राफ़्ट बदलाव प्रकाशित करें या हटाएँ। लागू करने से बना ड्राफ़्ट प्रकाशित नहीं होता।
