<Warning>
`key` मान केवल लिखने योग्य है। Phaseo इसे तुरंत एन्क्रिप्ट करता है और API प्रतिक्रियाओं में कभी वापस नहीं करता।
</Warning>

प्रबंधित क्षमता से पहले क्रेडेंशियल आज़माने के लिए `routing_mode: "priority"` या बाद में आज़माने के लिए `"fallback"` चुनें। प्राथमिक क्रेडेंशियल विफल होने पर प्रबंधित क्षमता पर फ़ॉलबैक की अनुमति `byokFallbackEnabled` को वर्कस्पेस सेटिंग में कॉन्फ़िगर करके नियंत्रित करें।
