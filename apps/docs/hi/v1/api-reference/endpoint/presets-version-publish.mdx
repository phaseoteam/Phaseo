<Note>इस एंडपॉइंट के लिए `presets:write` वाली प्रबंधन API कुंजी और संबंधित उपयोगकर्ता पहचान आवश्यक है।</Note>

Preset की versioning विधि डिफ़ॉल्ट version label तय करती है। SemVer वाले preset `version_label` स्पष्ट रूप से दे सकते हैं।
