`spend_rules:write` आवश्यक है। टेस्ट नियम के गंतव्यों पर जाता है, या नियम का कोई गंतव्य न होने पर **खर्च अलर्ट** रूट पर। कुछ भी दर्ज नहीं होता। एक वर्कस्पेस प्रति मिनट पाँच टेस्ट भेज सकता है; उससे ज़्यादा पर `Retry-After` के साथ `429` मिलता है।
