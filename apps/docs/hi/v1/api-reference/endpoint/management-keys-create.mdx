<Note>इस एंडपॉइंट के लिए मालिक या व्यवस्थापक पहचान और `management_keys:write` आवश्यक है।</Note>

क्षमता टेम्पलेट चुनें या स्कोप की स्पष्ट सूची दें। कच्ची `key` केवल निर्माण प्रतिक्रिया में लौटाई जाती है; इसे तुरंत सर्वर-साइड सीक्रेट स्टोरेज में रखें।
