प्रतिक्रिया में तीन फ़ील्ड होते हैं:

- `endpoints`: API द्वारा अभी उपलब्ध कराए गए मानक एंडपॉइंट ID।
- `data`: हर एंडपॉइंट के लिए एक रिकॉर्ड, जिसमें `id`, `capability_id`, `public_path`, `collection`, `model_count` और `provider_count` होते हैं, `public_path` के क्रम में।
- `sample_models`: सार्वजनिक कैटलॉग के पहले 10 दिखने वाले मॉडल ID।

प्रतिक्रिया 30 मिनट के लिए कैश की जाती है।

जब आपको किसी एक मॉडल के लिए प्रदाता और पैरामीटर स्तर का विवरण चाहिए, तो [मॉडल एंडपॉइंट क्षमताएं सूचीबद्ध करें](./model-endpoints) का उपयोग करें।
