---

- `endpoints`: API द्वारा अभी उपलब्ध कराए गए मानक एंडपॉइंट ID
- `data`: `public_path`, `collection`, `model_count` और `provider_count` वाले एंडपॉइंट रिकॉर्ड
- `sample_models`: सार्वजनिक कैटलॉग से हाल में दिखे अधिकतम 10 मॉडल ID

किसी मॉडल के लिए प्रदाता और पैरामीटर स्तर का विवरण चाहिए तो [मॉडल एंडपॉइंट क्षमताएँ सूचीबद्ध करें](./model-endpoints.mdx) का उपयोग करें।
