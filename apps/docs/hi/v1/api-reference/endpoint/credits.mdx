## CLI या API से क्रेडिट जोड़ें

एजेंट और स्क्रिप्ट `POST /v1/credits/topups` या CLI से टॉप-अप शुरू कर सकते हैं। शुल्क को हमेशा कोई व्यक्ति स्वीकृत करता है।

```bash
phaseo login --scopes billing:write
phaseo credits add --amount 20
```

- टोकन को `billing:write` स्कोप चाहिए। यह कभी डिफ़ॉल्ट रूप से नहीं मिलता: इसे `phaseo login --scopes billing:write` से जोड़ें, या किसी मैनेजमेंट कुंजी पर सूचीबद्ध करें।
- API या CLI से टॉप-अप $5 से $500 तक होते हैं; इससे बड़े टॉप-अप डैशबोर्ड में किए जाते हैं। एक वर्कस्पेस में एक साथ 5 टॉप-अप प्रतीक्षा में रह सकते हैं (छठा `429` `too_many_pending_topups` लौटाता है), और हर एक 30 मिनट बाद समाप्त हो जाता है।
- **अभी कोई सहेजा गया कार्ड नहीं:** प्रतिक्रिया में `checkout_url` होता है। वर्कस्पेस का कोई मालिक या एडमिन इसे खोलकर नए कार्ड से भुगतान करता है, जो बाद के टॉप-अप के लिए सहेज लिया जाता है।
- **सहेजा गया कार्ड:** हर मालिक और एडमिन को एक बार उपयोग होने वाले लिंक के साथ ईमेल मिलता है। उनमें से कोई एक इसे खोलता है, साइन इन करता है और **Confirm** या **Decline** चुनता है। पुष्टि करने पर कार्ड से शुल्क लिया जाता है, और बैंक मांगे तो बैंक सत्यापन भी होता है।
- `final` के `true` होने तक `GET /v1/credits/topups/{id}` (या `phaseo credits topups get <id>`) पोल करें। स्थिति `paid` होने पर क्रेडिट जुड़ते हैं। `declined`, `expired` और `failed` के साथ एक `reason` कोड आता है: इन्हें अपने आप दोबारा न आज़माएं; इसके बजाय किसी व्यक्ति से पूछें।
