## CLI या API से क्रेडिट जोड़ें

एजेंट और स्क्रिप्ट `POST /v1/credits/topups` या CLI से टॉप-अप शुरू कर सकते हैं। शुल्क को हमेशा कोई व्यक्ति मंज़ूरी देता है।

```bash
phaseo login --scopes billing:write
phaseo credits add --amount 20
```

- टोकन को `billing:write` स्कोप चाहिए। यह डिफ़ॉल्ट रूप से कभी नहीं मिलता: इसे `phaseo login --scopes billing:write` से जोड़ें, या किसी management key में शामिल करें।
- टॉप-अप $5 से $500 तक होते हैं। एक वर्कस्पेस में एक साथ 5 लंबित हो सकते हैं, और हर एक 30 मिनट बाद समाप्त हो जाता है।
- **अभी कोई सहेजा गया कार्ड नहीं:** जवाब में `checkout_url` होता है। वर्कस्पेस का कोई owner या admin इसे खोलकर नए कार्ड से भुगतान करता है; वह कार्ड अगले टॉप-अप के लिए सहेज लिया जाता है।
- **सहेजा गया कार्ड:** हर owner और admin को एक बार इस्तेमाल होने वाले लिंक के साथ ईमेल मिलता है। उनमें से कोई एक इसे खोलता है, साइन इन करता है और **पुष्टि करें** या **अस्वीकार करें** चुनता है। पुष्टि करने पर कार्ड से शुल्क लिया जाता है; बैंक माँगे तो सत्यापन भी होता है।
- `final` के `true` होने तक `GET /v1/credits/topups/{id}` (या `phaseo credits topups get <id>`) पोल करें। स्थिति `paid` होने पर क्रेडिट जुड़ते हैं। `declined`, `expired` और `failed` के साथ `reason` कोड आता है: इन्हें अपने आप दोबारा न आज़माएँ; किसी व्यक्ति से पूछें।
