<Note>इस एंडपॉइंट के लिए `settings:write` वाली प्रबंधन API कुंजी आवश्यक है।</Note>

सभी कुंजियां प्रबंधन कुंजी के वर्कस्पेस की होनी चाहिए। एक कुंजी केवल एक डायनामिक रूट से जुड़ सकती है।
