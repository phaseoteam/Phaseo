इसके लिए `budgets:read` आवश्यक है। OAuth कॉलर के पास वर्कस्पेस मालिक या व्यवस्थापक की भूमिका होनी चाहिए।

उपयोग की गणना सफल गेटवे अनुरोधों से होती है। आरक्षित एसिंक्रोनस कार्य को उसकी होल्ड अवधि में शामिल किया जाता है, इसलिए लौटाई गई शेष राशि लागू सीमा से मेल खाती है।
