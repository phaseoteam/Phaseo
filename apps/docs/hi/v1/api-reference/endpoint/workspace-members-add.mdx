<Note>इस एंडपॉइंट के लिए `workspaces:write` वाली प्रबंधन API कुंजी और मालिक या एडमिन भूमिका आवश्यक है।</Note>

लोग आमंत्रण के ज़रिए वर्कस्पेस से जुड़ते हैं: वे उसे स्वीकार करते हैं, जिससे जुड़ने का अनुरोध बनता है, और यह एंडपॉइंट उसे स्वीकृत करता है। `user_ids` के हर उपयोगकर्ता का वर्कस्पेस में एक लंबित जुड़ने का अनुरोध होना चाहिए। दूसरे उपयोगकर्ता अस्वीकार किए जाते हैं, इसलिए पहले उन्हें आमंत्रण भेजें। जो लोग पहले से सदस्य हैं, उनकी भूमिका नहीं बदलती।

भूमिका `admin` या `member` हो सकती है। भूमिका न देने पर हर व्यक्ति को वही भूमिका मिलती है जिसके साथ उसका आमंत्रण बनाया गया था। केवल वर्कस्पेस का मालिक एडमिन जोड़ सकता है, और इस एंडपॉइंट से वर्कस्पेस का स्वामित्व नहीं सौंपा जा सकता।

हर व्यक्ति को अलग से स्वीकृत किया जाता है। अगर कोई स्वीकृति विफल होती है, तो उससे पहले स्वीकृत लोग वर्कस्पेस में बने रहते हैं और बाकी लोगों के लिए प्रयास नहीं किया जाता। तब प्रतिक्रिया `409` होती है, जिसकी `approved`, `failed` और `not_attempted` सूचियाँ दिखाती हैं कि प्रक्रिया कहाँ रुकी, ताकि आप समस्या ठीक करके बाकी उपयोगकर्ताओं को फिर से भेज सकें।
