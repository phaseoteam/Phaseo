<Note>Identity प्रशासन के लिए owner या admin identity आवश्यक है। SSO या SCIM चालू करने और provisioning tokens बनाने के लिए identity add-on चाहिए。</Note>

केवल वर्कस्पेस का मालिक सिंगल साइन-ऑन सेटिंग बदल सकता है, क्योंकि पहचान प्रदाता से होने वाले साइन-इन वर्कस्पेस के डायरेक्टरी उपयोगकर्ताओं से जोड़े जाते हैं।
