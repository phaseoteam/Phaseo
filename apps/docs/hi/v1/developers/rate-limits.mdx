यह गाइड [रेट लिमिट](../api-reference/limits.mdx) संदर्भ में स्थानांतरित हो गई है। वहाँ मौजूदा Gateway कोटा, प्रोवाइडर सीमाएँ, `Retry-After` और सीमित दोबारा प्रयास के नियम दिए हैं।

Gateway या प्रोवाइडर कोटा के कारण रिक्वेस्ट `429` लौटा सकती है। BYOK पर आपके प्रोवाइडर खाते का कोटा भी लागू होता है। रूटिंग और फ़ॉलबैक विफलताएँ कम कर सकते हैं, लेकिन हर रिक्वेस्ट की सफलता की गारंटी नहीं देते।

## उपयोग की निगरानी

रिक्वेस्ट लॉग में `429` त्रुटियाँ और दोबारा प्रयास देखें। API से अब [वर्कस्पेस एनालिटिक्स प्राप्त करना](../api-reference/endpoint/analytics-get.mdx) और [CSV के रूप में निर्यात करना](../api-reference/endpoint/analytics-export.mdx) उपलब्ध है। दोनों के लिए `analytics:read` वाली प्रबंधन API कुंजी आवश्यक है।
