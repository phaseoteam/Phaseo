Phaseo कुंजी अपने सर्वर पर रखें, अपने ऐप के प्रोटोकॉल से मेल खाने वाला एंडपॉइंट चुनें, और अपने HTTP क्लाइंट या SDK को `https://api.phaseo.app/v1` पर इंगित करें। अगर आपने अभी तक कोई अनुरोध नहीं भेजा है, तो [क्विकस्टार्ट](../quickstart.mdx) से शुरू करें।

आपको Gateway एक्सेस वाला Phaseo खाता और एक HTTP क्लाइंट, OpenAI-संगत SDK या Phaseo SDK चाहिए। उदाहरण `google/gemma-3-27b:free` का उपयोग करते हैं, जो जमा क्रेडिट के बिना चलता है।

<Steps>
<Step title="कुंजी बनाएँ और सहेजें">

[डैशबोर्ड](https://phaseo.app/settings/keys) में **सेटिंग → API कुंजियाँ** खोलें, या प्रबंधन कुंजी के साथ `POST /v1/keys` कॉल करें। कुंजी का नाम ऐप और एनवायरनमेंट के नाम पर रखें, फिर उसे सीक्रेट मैनेजर या एनवायरनमेंट फ़ाइल में सहेजें:

```bash
# .env.local
PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
PHASEO_BASE_URL="https://api.phaseo.app/v1"
```

लोकल डेवलपमेंट, प्रीव्यू डिप्लॉयमेंट और प्रोडक्शन के लिए अलग-अलग कुंजियाँ इस्तेमाल करें, ताकि आप हर एक को अलग से रोटेट और रिव्यू कर सकें।

</Step>
<Step title="एंडपॉइंट चुनें">

| एंडपॉइंट | इसका उपयोग करें |
| --- | --- |
| `/v1/responses` | नए टेक्स्ट बिल्ड, संरचित आउटपुट और बहु-चरणीय वर्कफ़्लो के लिए। |
| `/v1/chat/completions` | चैट इंटरफ़ेस और मौजूदा OpenAI-शैली इंटीग्रेशन के लिए। |
| `/v1/messages` | Anthropic-संगत इंटीग्रेशन के लिए। |
| `/v1/decisions` | ऐप्लिकेशन स्थिति पर टाइप किए गए फ़ैसलों के लिए, Jev 1.13 (बीटा) के साथ। |
| `/v1/moderations` | सुरक्षा और कंटेंट नीति जाँच के लिए। |
| `/v1/images/generations` | टेक्स्ट प्रॉम्प्ट से इमेज के लिए। |

[API संदर्भ](../api-reference/introduction) हर एंडपॉइंट, पैरामीटर और प्रतिक्रिया सूचीबद्ध करता है।

</Step>
<Step title="अपने ऐप से अनुरोध भेजें">

यह उदाहरण Chat Completions का उपयोग करता है, जिसे OpenAI-संगत क्लाइंट पहले से समझते हैं। हर अनुरोध कुंजी को `Authorization: Bearer $PHASEO_API_KEY` के रूप में भेजता है।

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemma-3-27b:free",
    "messages": [
      { "role": "system", "content": "You are a helpful assistant." },
      { "role": "user", "content": "Explain the benefits of AI." }
    ]
  }'
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});

const response = await client.chat.completions.create({
  model: "google/gemma-3-27b:free",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: "Explain the benefits of AI." },
  ],
});

console.log(response.choices[0]?.message?.content);
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.phaseo.app/v1",
)

response = client.chat.completions.create(
    model="google/gemma-3-27b:free",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain the benefits of AI."},
    ],
)

print(response.choices[0].message.content)
```

```go Go
package main

import (
  "context"
  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New("YOUR_API_KEY", "https://api.phaseo.app/v1")

  response, err := client.CreateChatCompletion(context.Background(), phaseo.ChatCompletionsRequest{
    Model: "google/gemma-3-27b:free",
    Messages: []map[string]interface{}{
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain the benefits of AI."},
    },
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(response)
}
```

<Note>
जिन मॉडलों की ID `:free` पर खत्म होती है, वे जमा क्रेडिट के बिना चलते हैं। पेड मॉडल के लिए वॉलेट में उपलब्ध बैलेंस चाहिए।
</Note>

## प्रोडक्शन ट्रैफ़िक भेजने से पहले

कौन से प्रदाता आपके अनुरोध सर्व करें, इसे नियंत्रित करने के लिए [रूटिंग और फ़ॉलबैक](../guides/routing-and-fallbacks) पढ़ें, और कुंजी संभालने और प्रमाणीकरण त्रुटियों के लिए [प्रमाणीकरण](./authentication)। [SDK संदर्भ](../sdk-reference/client/overview) हर भाषा का क्लाइंट कवर करता है, और [उदाहरण](../guides/examples) में पूरे ऐप और स्क्रिप्ट के पैटर्न हैं।
