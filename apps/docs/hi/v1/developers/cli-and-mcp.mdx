# CLI और MCP

टर्मिनल से Phaseo इस्तेमाल करने के लिए CLI चलाएँ या MCP के ज़रिए AI क्लाइंट जोड़ें। दोनों Phaseo OAuth इस्तेमाल करते हैं, लेकिन इन्हें अलग-अलग कामों के लिए बनाया गया है।

| इंटरफ़ेस | किसके लिए उपयुक्त | पहुँच |
| --- | --- | --- |
| Phaseo CLI | टर्मिनल वर्कफ़्लो, CI, प्रशासन और ऑटोमेशन | पढ़ने और लिखने की अनुमति, जो आपके स्कोप और वर्कस्पेस भूमिका से सीमित है |
| Phaseo MCP | Codex, Claude, ChatGPT और अन्य MCP क्लाइंट में Phaseo का लाइव डेटा, और वैकल्पिक खाता प्रबंधन | प्रमाणीकृत; खाता प्रबंधन के साथ कनेक्ट न करने पर केवल पढ़ने के लिए |
| Docs MCP | कोडिंग के समय Phaseo के वर्तमान दस्तावेज़ देखना | केवल दस्तावेज़, केवल पढ़ने के लिए |
| Phaseo प्लगइन | Claude Code या Codex में Phaseo MCP, Docs MCP और Phaseo स्किल्स एक साथ इंस्टॉल करना | हर MCP सर्वर के समान |

## Phaseo CLI

जब आपको Phaseo संसाधन बनाने या बदलने हों, किसी वर्कफ़्लो की स्क्रिप्ट लिखनी हो या शेल से खाते का डेटा देखना हो, तब CLI इस्तेमाल करें।

### इंस्टॉल करें और साइन इन करें

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

इंटरैक्टिव टर्मिनल डिफ़ॉल्ट रूप से ब्राउज़र OAuth इस्तेमाल करते हैं। SSH, CI और हेडलेस एनवायरनमेंट के लिए डिवाइस ऑथराइज़ेशन इस्तेमाल करें:

```bash
phaseo login --device-code
```

### आम वर्कफ़्लो

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys create --name "Local development"
phaseo logs list --since 1h --status error --json
```

जब किसी दूसरे टूल या स्क्रिप्ट को संरचित आउटपुट चाहिए, तब `--json` इस्तेमाल करें। गुप्त मान केवल वही कमांड दिखाते हैं जो उन्हें स्पष्ट रूप से बनाते या प्रकट करते हैं।

## Phaseo MCP

जब आप चाहते हैं कि AI क्लाइंट लाइव मॉडल, मूल्य निर्धारण, प्रदाता, उपयोग और वर्कस्पेस डेटा के आधार पर सवालों के जवाब दे, तब Phaseo MCP सर्वर जोड़ें।

### सर्वर URL

`https://mcp.phaseo.app/mcp`

### Codex से कनेक्ट करें

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

लॉगिन कमांड Phaseo OAuth खोलता है। एक वर्कस्पेस चुनें और माँगे गए पढ़ने वाले स्कोप को मंज़ूरी दें, फिर कनेक्शन की पुष्टि करें:

```bash
codex mcp list
```

किसी दूसरे MCP क्लाइंट के लिए यही URL रिमोट Streamable HTTP सर्वर के रूप में जोड़ें। क्लाइंट में OAuth डिस्कवरी, S256 PKCE वाले ऑथराइज़ेशन कोड और MCP `resource` पैरामीटर का समर्थन होना चाहिए।

### MCP क्या पढ़ सकता है

- मॉडल, प्रदाता, बेंचमार्क रैंकिंग, मूल्य निर्धारण और लागत अनुमान
- क्रेडिट, गतिविधि, एनालिटिक्स, अनुरोध लॉग और जनरेशन मेटाडेटा

ये टूल केवल पढ़ने के लिए हैं। ये कभी भी प्रॉम्प्ट, जवाब या गुप्त मान नहीं लौटाते।

### अपना खाता प्रबंधित करें (वैकल्पिक)

किसी एजेंट को अपने Phaseo वर्कस्पेस में बदलाव करने देने के लिए, इसके बजाय प्रबंधन URL से कनेक्ट करें:

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

साइन इन करते समय सहमति स्क्रीन कनेक्शन द्वारा माँगी गई हर अनुमति अलग से दिखाती है, जैसे API कुंजियाँ प्रबंधित करना या बजट हटाना, और उस पर **पढ़ें**, **लिखें** या **हटाएँ** का निशान लगाती है। जो अनुमति आप नहीं देना चाहते, उसका चेकबॉक्स हटा दें। एजेंट को सिर्फ़ उन्हीं अनुमतियों के टूल मिलते हैं जिन्हें आप देते हैं, और Phaseo हर बदलाव पर आपकी वर्कस्पेस भूमिका भी जाँचता है। इसलिए जो सदस्य मालिक या एडमिन नहीं है, वह इस तरीके से केवल एडमिन के लिए बनी सेटिंग्स नहीं बदल सकता।

अगर आप पहले से केवल-पढ़ने वाले URL से कनेक्ट हैं, तो क्लाइंट को प्रबंधन URL पर बदलें और फिर से साइन इन करें। केवल-पढ़ने वाली पहुँच पर लौटने के लिए सामान्य URL से दोबारा कनेक्ट करें या **सेटिंग → कनेक्टेड ऐप्स** में ऐप की पहुँच रद्द करें।

| क्षेत्र | टूल | अनुमतियाँ |
| --- | --- | --- |
| API कुंजियाँ | `api_keys_list`, `api_key_get`, `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete` | `keys:read`, `keys:write`, `keys:delete` |
| बजट | `budgets_list`, `budget_create`, `budget_update`, `budget_delete` | `budgets:read`, `budgets:write`, `budgets:delete` |
| खर्च नियम | `spend_rules_list`, `spend_rule_create`, `spend_rule_update`, `spend_rule_delete` | `spend_rules:read`, `spend_rules:write`, `spend_rules:delete` |
| प्रदाता कुंजियाँ (BYOK) | `provider_keys_list`, `provider_key_create`, `provider_key_update`, `provider_key_delete` | `provider_credentials:read`, `provider_credentials:write`, `provider_credentials:delete` |
| गार्डरेल | `guardrails_list`, `guardrail_get`, `guardrail_create`, `guardrail_update`, `guardrail_delete`, `guardrail_keys_set` | `guardrails:read`, `guardrails:write`, `guardrails:delete` |
| प्रीसेट | `presets_list`, `preset_get`, `preset_create`, `preset_update`, `preset_version_publish` | `presets:read`, `presets:write` |
| सेटिंग | `settings_get`, `settings_update` (रूटिंग मोड, गोपनीयता और ZDR, लॉगिंग, प्रदाता प्रतिबंध) | `settings:read`, `settings:write` |
| वेबहुक | `webhooks_list`, `webhook_create`, `webhook_delete` | `settings:read`, `settings:write` |
| ऑब्ज़र्वेबिलिटी गंतव्य | `observability_destinations_list`, `observability_destination_create`, `observability_destination_delete` | `settings:read`, `settings:write` |

जो टूल कुछ बदलते या हटाते हैं, उन पर ऐसा चिह्न होता है, ताकि इसे सपोर्ट करने वाले MCP क्लाइंट हर कॉल से पहले आपसे पूछें। नई API कुंजी या वेबहुक साइनिंग सीक्रेट टूल के नतीजे में सिर्फ़ एक बार दिखाया जाता है और फिर दोबारा नहीं दिखाया जा सकता। सहेजी गई प्रदाता कुंजियाँ और गंतव्यों के क्रेडेंशियल कभी नहीं लौटाए जाते।

MCP में बिलिंग, भुगतान, वर्कस्पेस, सदस्य, प्रबंधन कुंजियों या OAuth ऐप के लिए कोई टूल नहीं है। इनके लिए डैशबोर्ड, CLI या मैनेजमेंट API इस्तेमाल करें।

## Docs MCP

Docs MCP, Phaseo दस्तावेज़ खोजने और पढ़ने के लिए एक अलग एंडपॉइंट है। यह आपके खाते या वर्कस्पेस तक नहीं पहुँचता।

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

जब किसी कोडिंग असिस्टेंट को मौजूदा API उदाहरण, इंटीग्रेशन मार्गदर्शन या फ़ीचर दस्तावेज़ चाहिए हों, तब इसका इस्तेमाल करें।

## Phaseo प्लगइन

Phaseo प्लगइन में Phaseo MCP, Docs MCP और इंटीग्रेशन, माइग्रेशन, मॉडल चयन, उपयोग की निगरानी, SDK और CLI के लिए Phaseo एजेंट स्किल्स एक साथ मिलती हैं। हर हिस्से को अलग से जोड़ने के बजाय इसे एक बार इंस्टॉल करें।

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

अपना Phaseo खाता जोड़ने के लिए `/mcp` चलाएँ और `plugin:phaseo:phaseo` में साइन इन करें। अनुरोध से मेल खाने पर स्किल्स अपने आप लोड होती हैं, या आप किसी स्किल को सीधे चला सकते हैं, जैसे `/phaseo:phaseo-gateway`।

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

आखिरी कमांड Phaseo MCP के लिए Phaseo OAuth खोलती है। अनुरोध से मेल खाने पर स्किल्स अपने आप लोड होती हैं।

## सही इंटरफ़ेस चुनें

- कुंजियाँ बनाने, सेटिंग्स बदलने, वर्कस्पेस सँभालने या प्रशासनिक वर्कफ़्लो ऑटोमेट करने के लिए **CLI** इस्तेमाल करें।
- AI क्लाइंट को Phaseo के लाइव डेटा तक सुरक्षित पहुँच देने के लिए **Phaseo MCP** इस्तेमाल करें।
- खाते तक पहुँच दिए बिना कोडिंग असिस्टेंट को Phaseo के मौजूदा दस्तावेज़ देने के लिए **Docs MCP** इस्तेमाल करें।
- Claude Code या Codex में दोनों MCP सर्वर और Phaseo स्किल्स एक साथ सेट अप करने के लिए **Phaseo प्लगइन** का उपयोग करें।
