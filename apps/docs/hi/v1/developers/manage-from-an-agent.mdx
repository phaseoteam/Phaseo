आप डैशबोर्ड खोले बिना `phaseo` CLI, `/v1` प्रबंधन API या Phaseo MCP सर्वर से Phaseo खाता चला सकते हैं। हर काम का कमांड, रूट या टूल ढूँढने के लिए इस पेज का उपयोग करें।

केवल तीन चरणों में ब्राउज़र में किसी व्यक्ति की ज़रूरत होती है:

- Phaseo खाते के लिए **साइन अप करना**।
- **पहले साइन-इन को स्वीकृत करना**: `phaseo login` द्वारा खोला गया ब्राउज़र पेज, या `phaseo login --device-code` द्वारा दिखाया गया कोड।
- पहली बार क्रेडिट खरीदते समय **कार्ड दर्ज करना**। बाद के टॉप-अप सेव किए गए कार्ड से होते हैं, और हर एक को वर्कस्पेस का मालिक या एडमिन ईमेल में भेजे गए लिंक से स्वीकृत करता है।

<Visibility for="agents">
Phaseo प्रबंधित करने वाले एजेंट के लिए नियम:

- नीचे की तालिकाओं के किसी काम के लिए उपयोगकर्ता को डैशबोर्ड पर न भेजें। CLI कमांड चलाएँ, रूट कॉल करें या MCP टूल इस्तेमाल करें।
- कभी भी API कुंजी स्वयं न बनाएँ और न उसका अनुमान लगाएँ। `phaseo keys create --name <name> --json` से एक बनाएँ और सीक्रेट को एक बार, सर्वर-साइड, सेव करें।
- हर CLI कमांड पर `--json` इस्तेमाल करें। विनाशकारी कमांड को `--yes` केवल तब दें जब उपयोगकर्ता ने ठीक वही बदलाव माँगा हो।
- केवल वही क्रेडिट टॉप-अप शुरू करें जो उपयोगकर्ता ने माँगा हो। कभी भी चेकआउट लिंक खुद पूरा न करें, और अस्वीकृत, समाप्त या विफल हुए टॉप-अप को दोबारा न आज़माएँ।
</Visibility>

## एक बार सेटअप

```bash
npm install -g @phaseo/cli
phaseo login                 # opens a browser; a person approves it
phaseo login --device-code   # SSH, CI and agent sandboxes: a person enters the code
phaseo whoami --json
```

फिर ऐप्लिकेशन के लिए एक इन्फ़रेंस कुंजी बनाएँ, और अगर वर्कस्पेस में क्रेडिट नहीं है तो क्रेडिट जोड़ें:

```bash
phaseo keys create --name "Production app" --json
phaseo credits get --json
phaseo login --scopes billing:write   # one-time opt-in before the first top-up
phaseo credits add --amount 20 --json
```

`phaseo credits add` अपने आप कभी शुल्क नहीं लेता। सेव किए गए कार्ड पर, Phaseo वर्कस्पेस के हर मालिक और एडमिन को शुल्क की पुष्टि का लिंक ईमेल करता है, और कमांड नतीजे का इंतज़ार करता है। सेव किया कार्ड न होने पर, यह एक लिंक लौटाता है जहाँ मालिक या एडमिन कार्ड दर्ज करता है। रूट के लिए [क्रेडिट](../api-reference/endpoint/credits) देखें।

## इंटरफ़ेस चुनें

| इंटरफ़ेस | कब इस्तेमाल करें | साइन-इन |
| --- | --- | --- |
| [`phaseo` CLI](../guides/integrations/phaseo-cli) | एजेंट shell कमांड चला सकता है | `phaseo login` या `phaseo login --device-code` |
| [प्रबंधन API](../api-reference/introduction) | सर्वर कोड, CI या ऐसी भाषा जिसमें CLI नहीं है | एक [प्रबंधन कुंजी](./management-api-keys) (`phaseo_v1_mk_...`) या OAuth टोकन |
| [Phaseo MCP](./cli-and-mcp#phaseo-mcp) | एजेंट किसी MCP क्लाइंट में चलता है | `https://mcp.phaseo.app/mcp?access=manage` से कनेक्ट करें और ज़रूरी अनुमतियाँ स्वीकृत करें |

इंस्टॉल किया गया CLI कौन-से फ़्लैग स्वीकार करता है, यह देखने के लिए `phaseo <group> --help` चलाएँ। जिस काम का अपना कमांड नहीं है, उसके लिए `phaseo api get|post|patch|put|delete /v1/<path>` आपके सेशन से रूट कॉल करता है।

## कामों की सूची

### कुंजियाँ और पहुँच

| काम | CLI | API रूट | MCP टूल |
| --- | --- | --- | --- |
| API कुंजी बनाएँ | `phaseo keys create --name <name>` | `POST /v1/keys` | `api_key_create` |
| कुंजियाँ सूचीबद्ध करें, अपडेट करें या हटाएँ | `phaseo keys list`, `keys update <id>`, `keys delete <id>` | `GET`, `PATCH`, `DELETE /v1/keys/{id}` | `api_keys_list`, `api_key_update`, `api_key_delete` |
| कुंजी रोटेट करें | `phaseo keys rotate <id>` | `POST /v1/keys/{id}/rotate` | `api_key_rotate` |
| कुंजी को IP पतों तक सीमित करें | `phaseo keys update <id> --ip-allowlist <label=address,...>` | `PATCH /v1/keys/{id}` | — |
| प्रबंधन कुंजी बनाएँ | `phaseo management-keys create --name <name>` | `POST /v1/management-keys` | — |
| आपके द्वारा अधिकृत ऐप देखें या रद्द करें | `phaseo authorized-apps list`, `authorized-apps revoke <id>` | `GET`, `DELETE /v1/me/authorized-apps/{id}` | — |
| अपनी प्रोफ़ाइल अपडेट करें | `phaseo profile update` | `PATCH /v1/me/profile` | — |

## अनुमतियाँ

CLI सेशन, प्रबंधन कुंजी या MCP कनेक्शन वही कर सकता है जिसकी अनुमति उसके स्कोप और वर्कस्पेस में आपकी भूमिका देती है। केवल मालिक और एडमिन वाले बदलावों के लिए अब भी मालिक या एडमिन चाहिए। अगर कोई कमांड `403` लौटाए, तो `phaseo whoami --json` से दिए गए स्कोप देखें, और कोई स्कोप न होने पर `phaseo login --scopes <scope,...>` से फिर साइन इन करें। `billing:write` डिफ़ॉल्ट रूप से कभी नहीं दिया जाता।
