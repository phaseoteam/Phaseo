**設定 → ワークスペース → アクティビティ** を開くと、現在のワークスペースで誰がいつキー、メンバー、そのほかの管理設定を変更したかを確認できます。イベントは新しい順に表示されます。ログを閲覧できるのは、ワークスペースのオーナーと管理者だけです。

リクエストと生成のログには、どのトラフィックが実行されたかが表示されます。監査ログには、その周りの管理設定を誰が変更したかが表示されます。

## 記録される内容

| 領域 | 操作の例 |
| --- | --- |
| API キー | `api_key.created`、`api_key.updated`、`api_key.paused`、`api_key.resumed`、`api_key.rotated`、`api_key.deleted` |
| 管理キー | `management_key.created`、`management_key.updated`、`management_key.deleted` |
| メンバーと招待 | `workspace.member.added`、`workspace.member.role_updated`、`workspace.member.removed`、`workspace.invite.created` |
| プロバイダーキー（BYOK） | `provider_credential.created`、`provider_credential.updated`、`provider_credential.reordered`、`provider_credential.deleted` |
| ルーティングとプリセット | `routing.policy.updated`、`routing.dynamic_route.deployed`、`preset.version.published` |
| 予算と支出 | `workspace_budget.updated`、`spend_block.lifted`、`rate_limit_raise.requested` |
| ガードレール | `guardrail.created`、`guardrail.updated`、`guardrail.keys.added` |
| ID 管理 | `identity.sso.updated`、`identity.scim_token.created`、`identity.group_mapping.updated` |
| 連携 | `observability.destination.created`、`notifications.destination.created`、`webhook_endpoint.secret_rotated`、`oauth_authorization.revoked` |

各イベントには、実行者、操作、対象の種類、対象の ID と名前、タイムスタンプ、リクエスト ID、少量の変更メタデータが含まれます。イベントは追記専用です。

ログには、平文のキー、認証情報のハッシュ、認可ヘッダー、全スコープ一覧、リクエスト本文は保存されません。名前に secret、token、hash、credential、scope、value を含むメタデータのフィールドは、イベントを書き込む前に取り除かれます。

## API でイベントを読む

`activity:read` を持つ[管理キー](../developers/management-api-keys.mdx)で `GET /v1/audit-events` を呼び出します。OAuth トークンにも `activity:read` が必要で、そのユーザーはワークスペースのオーナーまたは管理者である必要があります。

```bash
curl "https://api.phaseo.app/v1/audit-events?limit=50" \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY"
```

| クエリパラメーター | 意味 |
| --- | --- |
| `limit` | 1 ページあたりのイベント数。1〜100。既定は `50`。 |
| `cursor` | 前のページの `next_cursor`。カーソルでページを送ると、同じタイムスタンプのイベントが抜けることはありません。 |
| `action` | `api_key.rotated` など、1 つの操作だけを返します。 |
| `target_type` | `api_key` など、1 つの対象の種類だけを返します。 |

レスポンスには `data`、`has_more`、`next_cursor` が含まれます。各イベントには、メンバーの `display_name` と `email` を含む `actor` オブジェクトがあります。
