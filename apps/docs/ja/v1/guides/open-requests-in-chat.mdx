Gateway I/Oログを有効にすると、Phaseoは各リクエストのプロンプトとレスポンスを保存します。保存されたChat Completions、Responses、Messagesのリクエストはどれでもチャットで開き、どのように表示されたかを確認し、同じモデルまたは別のモデルでそこから会話を続けられます。

## 始める前に

- **設定 → プライバシー**で**リクエストとレスポンスのペイロードを保存**を有効にしてください。有効になっている間に送信されたリクエストだけを開けます。
- **ゼロデータ保持を必須にする**がオンのワークスペースでは、プロンプトもレスポンスも保存されません。ゼロデータ保持を必須とするガードレールが設定されたAPIキーで送信したリクエストも同様です。これらのリクエストは開けません。
- [リージョンエンドポイント](./regional-routing.mdx)（`eu.api.phaseo.app` と `us.api.phaseo.app`）に送信したリクエストは保存されないため、開けません。
- リクエストが属するワークスペースのメンバーである必要があります。**内容を閲覧できるユーザー**が**オーナーと管理者**に設定されている場合、リクエストを開けるのはオーナーと管理者のみです。

## リクエストを開く

| 場所 | 方法 |
| --- | --- |
| リクエストの詳細 | 詳細の上部にある**チャットで開く**を選択します。 |
| リクエストログ | リクエストを右クリックし、**チャットで開く**を選択します。 |
| セッションの詳細 | 最新のターンから続けるには**チャットで開く**を、特定のターンから続けるにはその行のチャットアイコンを選択します。 |

セッションの各ターンには、その時点までの会話がすでに含まれています。そのため、あるターンを開くと、それより前の内容もすべて開かれます。

チャットが開くリンクにはリクエストIDしか含まれないため、ワークスペースの他のメンバーと共有できます。チャットは、リンクを開いた人ごとに、その人自身のアクセス権でリクエストを再読み込みします。

## 引き継ぐ内容を選ぶ

チャットを作成する前に、リクエストに含まれる内容と引き継がれる内容がチャットに表示されます。

| オプション | 内容 |
| --- | --- |
| プロバイダーを固定 | 続きのターンを、リクエストを処理したプロバイダーに送信します。デフォルトではオフで、通常どおりルーティングがプロバイダーを選びます。 |
| パラメーター | temperature、最大トークン数、top-pとtop-k、seed、ペナルティ、推論、サービスティアを引き継ぎます。 |
| システムプロンプト | リクエストのシステム指示または開発者指示を引き継ぎます。 |
| サーバーツール | リクエストで使われたPhaseoのサーバーツール（Web検索など）を引き継ぎます。 |
| 関数ツール | 以前のツール呼び出しが有効なままになるよう、リクエスト独自の関数ツールを宣言します。チャットではこれらを実行できません。除外した場合、以前のツール呼び出しと結果はテキストとして送信されます。 |
| 記録された応答 | リクエストが受け取ったレスポンスを含めます。同じ会話に対して新しいレスポンスを生成するには除外してください。 |

リクエストのモデルがチャットで利用できない場合は、代わりに現在のモデルが使われます。チャットを開いた後でモデルを変更できます。

## チャットの続き方

- リクエストは独自のセッションIDを持つ新しいチャットとして開かれ、他のチャットと同じくブラウザーに保存されます。続きのターンは、ログ内の元のセッションには追加されません。
- 編集していないメッセージは元の形式のまま送信されるため、ツール呼び出し、ツールの結果、画像、音声、ファイルは次のターンでも保持されます。編集したメッセージと新しいメッセージは、通常のチャットと同じくテキストとして送信されます。
- 通常のチャットと同じく、モデルの切り替え、複数モデルの並列比較、分岐、編集ができます。
- 続きのターンはアクティブなワークスペースで実行され、他のチャットリクエストと同じく課金されます。

## 引き継げないもの

続ける前に、引き継げなかったものがチャットに一覧表示されます。

- `previous_response_id`または会話IDによってプロバイダー側で保持されているターン。保存されるのはリクエスト自体に含まれるターンだけです。
- インラインではなく、ファイルIDやリモート参照で送信された添付ファイル。
- 失敗した、途中で切れた、または複数の選択肢を返したレスポンス（最初の選択肢だけが保持されます）。
- 結果を受け取らなかったツール呼び出し。これらはテキストとして送信されます。
- プロバイダー固有のブロックなど、チャットで表示できないコンテンツタイプ。

保存するには大きすぎるリクエストや、保存された内容の有効期限が切れたか削除されたリクエストは開けません。チャットで開けるのはテキストのリクエストのみです。画像、音声、動画、埋め込みのリクエストは開けません。
