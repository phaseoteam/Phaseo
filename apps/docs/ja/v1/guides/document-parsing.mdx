文書画像を `POST /v1/parse` に送ると、そのテキストが読み順に、Markdown として、またはテキスト・画像・表の構造化ブロックとして返されます。プレーンテキストだけが必要な場合は [OCR](../api-reference/endpoint/ocr.mdx) を使ってください。

<Warning>
  Parse はリクエストごとに 1 枚の画像を、`http(s)` の URL または base64 の `data:image/...` URI として受け付けます。PDF は受け付けないため、先に各ページを画像に変換してください。Cohere は画像 1 枚あたり 20 MB、5,000 万ピクセル、デコード後 200 MB に制限しています。
</Warning>

## Markdown に解析する

既定の `output_format` は Markdown です。読み順を保ち、表を HTML としてインラインに含め、検出した画像をページ上のメタデータにリンクします。

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/parse \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cohere/parse-v5.0",
    "document": {
      "type": "image_url",
      "image_url": "https://example.com/invoice.png"
    },
    "output_format": "markdown"
  }'
```

```ts TypeScript
const response = await fetch("https://api.phaseo.app/v1/parse", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "cohere/parse-v5.0",
    document: {
      type: "image_url",
      image_url: "https://example.com/invoice.png",
    },
    output_format: "markdown",
  }),
});

const parsed = await response.json();
console.log(parsed.pages[0].markdown.content);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/parse",
    headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
    json={
        "model": "cohere/parse-v5.0",
        "document": {
            "type": "image_url",
            "image_url": "https://example.com/invoice.png",
        },
        "output_format": "markdown",
    },
)
response.raise_for_status()
print(response.json()["pages"][0]["markdown"]["content"])
```
</CodeGroup>

## 構造化ブロックを返す

`output_format` を `blocks` に設定すると、順序付きのテキスト、画像、表の領域が返されます。画像と表のブロックには、利用できる場合はピクセル単位と正規化済みのバウンディングボックスが含まれます。

## Parse の課金方法

Parse の使用量はページ単位で計測されます。プロバイダーが課金ページ数を報告した場合、レスポンスには Cohere のメタデータと正規化された `usage.input_pages` の値が含まれます。Cohere は現在、レート制限付きの無料評価用 API アクセスを提供しており、本番用の Parse API の料金はまだ公開していません。
