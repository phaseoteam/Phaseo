<Note>
Slack エージェントはワークスペースに順次提供しています。設定に **設定 → Slack** がまだ表示されない場合、そのワークスペースではまだ利用できません。
</Note>

Phaseo エージェントは Slack で質問に回答します。チャンネルでメンションするか、ダイレクトメッセージを送ると、スレッドで回答し、書きながらストリーミングで表示します。Phaseo で選んだモデルを使い、Web 検索や Web ページの読み取りができます。また、連携済みのメンバーには、ワークスペースの Phaseo の支出、クレジット、API キーの利用状況、モデルについて答えられます。作成したグラフや画像を投稿したり、共有された画像や PDF を読んだり、あなたの代わりに Slack ワークスペースを検索したりすることもできます。

オーナーと管理者は **設定 → Slack** からエージェントを追加し、利用できる人を選び、上限を設定します。料金は、その月にエージェントを使った人数に応じた月額料金です。モデルのトークンは、ほかのゲートウェイリクエストと同じように課金されます。

## 始める前に

- Phaseo ワークスペースのオーナーまたは管理者であり、Slack ワークスペースにアプリを追加できる必要があります。
- **Chat** を一度開いて、ワークスペースのプライバシー設定を確認してください。Phaseo は最初のインストールの前にこれを求めます。
- [クレジット](https://phaseo.app/settings/credits)を追加してください。月額の請求とエージェントのモデルのトークンは、クレジットから支払われます。

## エージェントを Slack に追加する

<Steps>
<Step title="動作を選ぶ">

**設定 → Slack** を開きます。**Slack に追加** で、モデル、エージェントを利用できる人、利用状況データを共有できる場所、上限（下の「上限」を参照）を選びます。ワークスペースで自動ルーティングを利用できる場合は、**自動** を選ぶと Phaseo が質問ごとに適したモデルを選びます。利用できない場合は特定のモデルを選んでください。これらはすべて後から変更できます。

</Step>

<Step title="Slack で承認する">

**Slack に追加** を選びます。Slack にエージェントが求める権限が表示されます。承認すると Slack から **設定 → Slack** に戻り、インストールが表示されます。

</Step>

<Step title="質問してみる">

Slack のアプリ一覧からエージェントを開き、メッセージを送ります。チャンネルで使うには、`/invite @Phaseo` で招待してからメンションします。

</Step>
</Steps>

インストールすると、Phaseo ワークスペースに次の 2 つが作成されます。

- **エージェント用の API キー。** Phaseo が管理するため、API キーの一覧には表示されません。エージェントのモデルのトークンはこのキーで課金されます。
- **そのキーに付く Slack agent という名前のガードレール。** Slack のメッセージを学習から除外します（下の「データとプライバシー」を参照）。

1 つの Slack ワークスペースに同時に追加できるのは、1 つの Phaseo ワークスペースのエージェントだけです。

## Slack でエージェントを使う

- **ダイレクトメッセージ：** Slack のアプリ一覧からエージェントを開き、**Messages** タブに書き込みます。すべてのメッセージに回答します。
- **チャンネル：** エージェントをパブリックまたはプライベートチャンネルに招待してから、メンションします。例：`@Phaseo which model should we use to summarise call transcripts?`。スレッドで回答します。そのスレッドで続けて質問するときも、毎回メンションしてください。

回答中は次のように動作します。

- 会話の流れを追えるように、スレッドの最新の部分を、あなたのメッセージまで読みます。Slack が一度に読ませるメッセージは 15 件で、Phaseo のアプリが読めるのは各 Slack ワークスペースでおよそ 1 分に 1 回です。
  - スレッドの最初のメッセージは常に読みます。
  - ダイレクトメッセージでは、あなたとの会話の最新のメッセージを読みます。
  - チャンネルでは、最大で直近 30 分の最新のメッセージを読みます。
  - 読めた数より多くのメッセージが書かれていた場合は、一部が欠けていることがエージェントに伝えられます。
  - そのとき Slack がスレッドを読ませない場合は、スレッド内の自分の以前の回答をもとに答えます。
- 各スレッドでは、メッセージに 1 件ずつ回答します。さらに最大 5 件のメッセージが順番を待ち、それを超えると前の回答を待つよう伝えます。
- Slack の停止ボタンで、作業中の回答を止められます。
- 各回答の最後には、モデルと、その回答にかかったモデルのトークンの費用が表示されます（例：`Auto → GPT-6 Luna · $0.0031`）。**自動** の場合は、選ばれたモデルが矢印の後に、回答で使ったほかのモデルが + の後に表示されます。モデル名は Phaseo のモデルページに、費用は **ログ** のその回答のリクエストにリンクしています。ログは Phaseo ワークスペースのメンバーが開けます。

## メッセージごとにモデルを選ぶ

オーナーと管理者は、1 件のメッセージに使うモデルを選べるようにできます。**設定 → Slack** の **モデルの選択** で **メッセージごとのモデル選択を許可する** をオンにし、Phaseo カタログから最大 10 個のモデルを追加します。ワークスペースで自動ルーティングを利用できる場合は、**「自動」を含める** で **自動** もリストに加えられます。それ以外のメッセージには、引き続き **エージェント** のモデルが回答します。

モデルを選ぶには、メッセージを `with <model>:` で始め、許可されたモデルを名前または ID で指定します。

```text
@Phaseo with Claude Opus 5.5: check this incident summary for gaps
with openai/gpt-6-luna: draft a reply to this customer
```

- 照合するのは許可されたモデルだけで、大文字と小文字は区別しません。許可されたモデルのうち 1 つだけが持つ名前や ID であれば、先頭部分だけでも指定できます。たとえば、リストに Claude のモデルが 1 つしかなければ `with claude:` で選べます。ID はラボ名を省いても使えます（例: `with gpt-6-luna:`）。
- エージェントはそのメッセージに、`with …:` の部分を除いた内容でそのモデルを使って回答し、フッターに回答したモデルを表示します。
- リストにないカタログのモデルを指定した場合や、名前が複数のモデルに当てはまる場合は、選べるモデルの一覧を本人だけに返信し、メッセージには回答しません。そのメッセージは回答として数えません。「With …:」で始まってもモデル名を含まないメッセージ（例: 「With regards to the invoice: …」）には、通常どおり回答します。
- どのモデルが回答しても、各回答の上限（$0.50 と 12 ステップ。下の「回答ごとの上限」を参照）は変わりません。モデルのトークンは、そのモデルの料金で請求されます。
- **Slack agent** ガードレールは引き続き適用されます。選んだモデルのどのプロバイダーもこれを満たさない場合、エージェントは回答せずにその旨を伝えます。

### 別のモデルに聞く

モデルの選択がオンのあいだは、エージェントは回答中に、許可されたモデルの 1 つにセカンドオピニオンを求めることもできます。たとえば、別のモデルの意見を尋ねたときです。

```text
@Phaseo draft a reply to this customer, then ask Claude Opus 5.5 to check it
```

- 相手のモデルに見えるのは、エージェントが送った内容だけです。Slack のスレッドは見えず、Web 検索やツールも使えません。
- エージェントが 1 回の回答でほかのモデルに聞けるのは 3 回までです。その費用は同じ $0.50 の上限（下の「回答ごとの上限」を参照）に含まれ、回答を書き終えるのに足りないほどしか残っていない場合、エージェントはそれ以上聞きません。
- フッターには使ったすべてのモデルが表示され（例：`GPT-6 Luna + Claude Opus 5.5 · $0.0123`）、費用にもそれらが含まれます。
- モデルを使えない場合（たとえば、どのプロバイダーも **Slack agent** ガードレールを満たさない場合）は、エージェントに理由が伝わり、そのモデルなしで回答します。

### モデルを比較する

許可された 2 つまたは 3 つのモデルが同じ質問にどう答えるかを見るには、メッセージを `compare` で始め、モデルをカンマで区切って並べ、コロンを付けます。

```text
@Phaseo compare GPT-6 Luna, Claude Opus 5.5: what are the risks of moving our database to another region?
compare gpt-6-luna, claude, auto: summarise the EU AI Act in five bullet points
```

- モデルは `with <model>:` と同じように、許可されたモデルの中からだけ照合されます。リストにないモデルがある、名前が複数のモデルに当てはまる、モデルが 2 つ未満または 3 つより多い、コロンの後に質問がない、のいずれかの場合、エージェントは本人だけに返信し、メッセージには回答しません。そのメッセージは回答として数えません。 `compare the two plans, then pick one: …` のようにモデルをまったく指定していないメッセージは通常のテキストとして扱われ、エージェントはいつもどおり回答します。
- 各モデルが受け取るのはあなたの質問だけで、スレッドのほかの部分は渡されません。各モデルは Web 検索や Web ページの読み込みができ、同時に回答します。
- 返信にはモデルごとのセクションがあり、モデル名（Phaseo のモデルページへのリンク付き）、費用、回答が表示されます。各モデルには短く答えるよう指示しており、長い回答はすべてが 1 つの Slack メッセージに収まるように切り詰められます。
- 失敗したモデルがあれば、そのセクションに理由が表示され、ほかの回答はそのまま表示されます。
- 比較は 1 回の回答として数えられます。$0.50 の上限（下の「回答ごとの上限」を参照）はモデル間で均等に分けられ、フッターにはすべてのモデルと合計が表示されます。 この分割は、モデルに質問するかどうかを決めるだけです。割り当てが $0.02 未満のモデルには質問しません。回答は割り当てに達しても止まらないため、それ以上かかることがあります。その代わり、各モデルの回答の長さに上限があります。

### ボタン付きの質問

先に進む前に、いくつかの選択肢から選んでもらったり、何かを承認してもらったりする必要があるとき、エージェントはスレッドで質問し、選択肢ごとにボタンを表示します（最大 5 個）。**Other…** を出すこともあり、選ぶと自分の言葉で答えるための小さなフォームが開きます。

- 答えられるのは、エージェントが回答している相手だけです。ほかの人がボタンを選ぶと、その人だけに見えるメモが届きます。
- ボタンの代わりにスレッドで返信することもできます（チャンネルではエージェントをメンションします）。その返信が答えとして扱われます。
- 答えると、ボタンがあなたの答えに置き換わり、エージェントは止まったところから続けます。
- 質問は最大 1 時間待ちます。それを過ぎると、質問に期限切れと表示され、回答はそこで終わります。準備ができたら、もう一度質問してください。
- 待っている間も、Slack の停止ボタンを使えます。
- 待っている間、スレッド内のほかの人のメッセージは順番を待ち、誰の答えを待っているかがその人だけに伝えられます。
- 1 つの回答で質問できるのは 3 回までです。全体で 1 回の回答として数えられ、回答ごとの上限は、各質問の前後を含めた全体に適用されます。

### Home タブ

Slack でエージェントを開いて **Home** を選ぶと、使い方、使っているモデル、Phaseo アカウントが接続されているかどうかを確認できます。接続されておらず、接続すると役に立つ場合（**連携済みのアカウントのみ** のとき、または **利用状況データ** が許可されている場所）は、タブに **Connect your Phaseo account** ボタンが表示されます。アカウントを接続した Phaseo ワークスペースのメンバーには、今月（UTC）エージェントがこの Slack ワークスペースで回答した数も表示されます。タブに表示されるのは設定と数だけで、メッセージは表示されません。 自分が設定した定期タスクと、その次回の実行も表示されます（下の「スケジュールされたタスク」を参照）。

独自の Slack アプリでは、Home タブに最新のマニフェストが必要です。`home_tab_enabled` を `true` にし、ボットイベント `app_home_opened` を追加してください。

## グラフ、画像、ファイル

エージェントはスレッドにグラフや画像を投稿し、共有された画像や PDF を読むことができます。

- **グラフ：** グラフを頼みます。例：`@Phaseo chart our spend by week this month`。エージェントは手元の数値から棒グラフ、折れ線グラフ、円グラフのいずれかを描き、画像としてスレッドに投稿します。グラフの文字にはラテン文字とキリル文字を使います。それ以外の文字は回答の本文に書きます。
- **画像：** 画像の作成を頼みます。例：`@Phaseo make an icon of a paper plane in blue`。エージェントの API キーで [GPT Image 2](https://phaseo.app/models/openai/gpt-image-2) を使い、ほかのリクエストと同じように課金されます。画像 1 枚の費用は数セントで、回答の上限 $0.50 に含まれます（下の「回答ごとの上限」を参照）。回答のフッターにも含まれます。1 回の回答で作成できる画像は最大 2 枚で、上限の残りが $0.15 以上あるときだけ作成します。
- **共有したファイル：** 画像（PNG、JPEG、GIF、WebP、各 5 MB まで）や PDF（10 MB まで）をメッセージに添付するか、エージェントが読むスレッド内の以前のメッセージに添付します。1 回の回答で、新しいものから最大 4 ファイル、合計 12 MB まで読みます。ほかの種類のファイルはまだ読めません。

モデル自体も画像や PDF を読める必要があります。**Auto** の場合、エージェントはファイルを送り、選んだモデルが読めなければファイルなしで回答します。特定のモデルの場合、共有された種類のファイルをそのモデルが読めないときはエージェントがそう伝えます。

共有したファイルは、それを読む回答のためにダウンロードされ、保存されることはありません。エージェントが投稿するグラフや画像は、ほかのファイルと同じく Slack ワークスペースのファイルです。

### Slack 権限を更新する

グラフと画像には Slack の `files:write` 権限が、ファイルの読み取りには `files:read` が、Slack の検索（下の「Slack を検索する」を参照）には `search:read.public` と `search:read.files` が必要です。これらができるようになる前に追加したエージェントには、まだこれらの権限がありません。その場合、エージェントは管理者が権限を更新する必要があると伝え、**設定 → Slack** に **Slack 権限を更新** が表示されます。

1. **Slack 権限を更新** を選びます。エージェントが求める権限が Slack に表示されます。
2. 同じ Slack ワークスペースで承認します。Slack から **設定 → Slack** に戻ります。

更新しても、エージェントの設定、API キー、ガードレール、履歴はそのまま残ります。独自の Slack アプリを使う場合は、先に **設定 → Slack** に表示されるスコープをそのマニフェストに追加してください（下の「独自の Slack アプリを使う」を参照）。

## Slack を検索する

エージェントは質問した人の代わりに Slack ワークスペースを検索し、使ったメッセージやファイルへのリンクを付けて回答できます。例:

```text
What did we decide about the launch date?
@Phaseo find the latest incident review in #ops and summarise it
Who has been working on the billing migration this month?
```

- **あなたとして検索します。** あなたのメッセージに対して Slack が与える権限で Slack のリアルタイム検索を使うため、あなたが Slack で見られるものだけが見つかります。検索するのはパブリックチャンネルだけで、プライベートチャンネル、ダイレクトメッセージ、グループ DM は検索しません。
- **使ったものにはリンクを付けます。** 根拠にしたメッセージやファイルにはそれぞれリンクが付くので、Slack で開けます。検索で何も見つからなかったときは、そう伝えます。
- **検索を絞り込めます。** チャンネル、人、期間で絞り込めます。1 つの回答で最大 4 回、1 回あたり 10 件まで検索します。
- **意味でもキーワードでも。** AI 検索を含む Slack プラン（Business+ と Enterprise+）では、自分の言葉で書いた質問を意味で検索します。ほかのプランではキーワードで検索します。

どこで検索するかは **設定 → Slack** の **Slack 検索** で選びます。変更はすぐに反映されます。

| オプション | 検索する場所 |
| --- | --- |
| **オフ** | どこでも検索しません。 |
| **ダイレクトメッセージ**（デフォルト） | エージェントとのダイレクトメッセージ内だけです。見つけた内容を読むのは質問した人だけです。 |
| **ダイレクトメッセージとチャンネル** | 誰かがメンションしたときは、チャンネルでも検索します。回答はチャンネルの全員が読めます。見つかったチャンネルを開けないゲストも含むため、ワークスペースにとって問題がない場合だけ選んでください。 |

Slack による制限もあります:

- 検索するのはメッセージに回答するときだけです。Slack はエージェントをメンションしたメッセージや、エージェントに直接送られたメッセージごとに検索の権限を与えます。エージェントがその権限を保持するのは回答し終えるまでです。
- Slack はアプリがゲストの代わりに検索することを許可していません。また、エージェントがほかの会社の人の代わりに検索することはありません。
- Slack で 1 人が検索できるのは 1 分あたり約 10 回です。それを超えると、エージェントは手元の情報で回答し、そのことを伝えます。
- Slack がこの検索を許可しているのは、Slack Marketplace のアプリと、会社が独自に作ったアプリだけです。Phaseo の Slack アプリは、Slack Marketplace での掲載が承認されると検索できるようになります。それまでは、検索は利用できないとエージェントが伝えます。今すぐ検索するには、独自の Slack アプリを使ってください（下の「独自の Slack アプリを使う」を参照）。
- 検索機能より前のインストールでは、Slack 権限の更新が必要です（上の「Slack 権限を更新する」を参照）。

見つけた内容はその回答だけに使われ、保存されません（下の「データとプライバシー」を参照）。同じ理由で、Slack を検索した回答では、途中で質問したり、メモ、ピン、To-Do、スキルを保存したり、定期タスクを設定したりできません。

## 利用できる人

**利用できる人** で選びます。

| オプション | 回答を受け取る人 |
| --- | --- |
| **Slack の全員**（デフォルト） | Slack ワークスペースの全員。設定した上限の範囲内です。 |
| **連携済みのアカウントのみ** | Slack アカウントをこの Phaseo ワークスペースのメンバーと連携した人だけです。それ以外の人には、エージェントが連携用のリンクを送ります。 |

**上限** では、**ゲストを許可**（デフォルトでオン）で Slack ワークスペースのゲストがエージェントを使えるようになり、**他社の人を許可**（デフォルトでオフ）で共有の Slack Connect チャンネルにいる他の組織の人が使えるようになります。同じ Enterprise Grid 組織の別のワークスペースの人は、自社の人として扱われます。エージェントがボットやほかのアプリに回答することはありません。

### Slack アカウントを連携する

エージェントは、連携していない人に **Connect your Phaseo account** ボタンを非公開で送ります。

- **連携済みのアカウントのみ** の場合は、その人がメッセージを送ったときです。連携するまで回答しません。
- **Slack の全員** の場合は、**利用状況データ** で許可されている場所で、その人が利用状況について質問したときです（下の「利用状況についての質問」を参照）。それでも答えられることには回答し、ボタンは各スレッドで 1 人につき最大 1 回だけ送ります。新しいボタンが必要な場合は、新しいスレッドで質問してください。

ボタンは 15 分間有効です。

1. ボタンを選びます。ブラウザで Phaseo が開きます。
2. エージェントをインストールした Phaseo ワークスペースのメンバーであるアカウントでサインインします。
3. **アカウントを接続** を選びます。

アカウントを連携すると、利用状況についても質問できるようになります。

## 利用状況についての質問

連携済みのメンバーは、この Phaseo ワークスペースについてエージェントに次のことを質問できます（それ以外の人が質問すると、アカウントを連携するためのボタンが届きます。上の「Slack アカウントを連携する」を参照）。

- 期間内のリクエストと支出（日・週・月ごと、モデルやプロバイダーごと）
- クレジット残高、処理中のリクエストのために確保されたクレジット、今月使ったクレジット
- API キーごとのリクエストと支出
- Phaseo カタログのモデル

日付は UTC で、週は月曜日に始まります。エージェントがこれらの質問に答える場所は、**利用状況データ** で選びます。

| オプション | 連携済みのメンバーが質問できる場所 |
| --- | --- |
| **オフ** | どこでも答えません。エージェントは利用状況データを共有しません。 |
| **ダイレクトメッセージ**（デフォルト） | エージェントとのダイレクトメッセージだけです。 |
| **ダイレクトメッセージと選んだチャンネル** | ダイレクトメッセージと、**チャンネル ID** に入力したチャンネル（最大 100）です。 |

チャンネルのメンバーは全員エージェントの回答を読めるため、ワークスペースの支出を見てもよいメンバーだけのチャンネルを指定してください。チャンネルの ID は、Slack のチャンネル詳細の一番下にあります（例：`C0123ABCD`）。

## メモリとスキル

エージェントは、チームに頼まれたことを覚えておき、スキル（繰り返す作業のために保存した指示）に従うことができます。Slack で次のように頼みます。

- `@Phaseo remember that deploys freeze on Fridays after 3pm`
- `@Phaseo pin this for everyone: our fiscal year starts on 1 April`
- `@Phaseo add a to-do: send the Q4 budget to finance`、あとで `@Phaseo the budget to-do is done`
- `@Phaseo what do you remember about deploys?` または `@Phaseo forget the note about deploys`

エージェントは 3 種類のメモを、それぞれ 500 文字以内で、自分の言葉で保存します。

| 種類 | 用途 |
| --- | --- |
| **メモ** | 覚えておくこと。エージェントは関係があるときにメモを調べます。 |
| **ピン** | 常に念頭に置いておくこと。エージェントはメッセージごとに、その会話のピンを最大 10 件と、ワークスペース全体のピンを最大 10 件確認します。 |
| **To-Do** | 進み具合を追うこと。完了にできます。 |

メモは、保存されたチャンネルまたはダイレクトメッセージに属します。ワークスペース全体向けにするよう頼まれた場合は例外です。会話の中でエージェントが確認するのは、その会話のメモとワークスペース全体のメモだけで、ほかのチャンネルやダイレクトメッセージのメモは確認しません。ワークスペース全体のメモは、エージェントが回答する組織内のすべての人が利用できます。共有された Slack Connect チャンネルにいる他社の人が見たり保存したりできるのは、その会話のメモだけで、ワークスペース全体のメモは対象外です。保存済みのスキルは使えますが、スキルはワークスペース全体に適用されるため、新しいスキルは保存できません。メモは `remember until Friday that the office is closed` のように日付まで保持でき、その日を過ぎると削除されます。

エージェントがメモを保存するのは、覚えておく、ピン留めする、やることとして記録するよう頼まれたときか、決定事項や締め切りのように長く必要な事実があるときだけです。メッセージやスレッドを丸ごとコピーすることはありません。

### スキル

スキルは、名前、1 行の説明、最大 4,000 文字の指示からなり、週次レポートのようにチームが繰り返す作業に使います。エージェントに保存を頼むには、次のようにします。

`@Phaseo save a skill called Weekly report: list what shipped this week, then what slipped, then next week's priorities`

エージェントはメッセージごとに、最近変更された 20 件のスキルの名前と説明を確認します。依頼がスキルに合うとき、または `@Phaseo use the Weekly report skill` のように頼まれたときに、そのスキルの指示を読み込みます。スキルを保存するのははっきり頼まれたときだけで、同じ名前のスキルを置き換えるのも頼まれたときだけです。

### 管理者が管理できること

- **エージェントにメモを残させる**（既定でオン。**設定 → Slack** の **メモリとスキル** にあります）をオフにすると、メモ、ピン、To-Do が使えなくなります。オフの間、エージェントはメモを保存も参照もせず、何かを覚えるよう頼まれると、管理者がメモリをオフにしていると伝えます。スキルは引き続き使えます。保存済みのメモは残り、オーナーと管理者は引き続き確認・削除できます。オンに戻すと、エージェントは再びそれらを使います。
- Slack ワークスペースごとに、メモは最大 500 件、スキルは最大 100 件まで保持します。メモリがいっぱいになるとエージェントがそう伝えるので、いくつか削除して空きを作ってください。
- オーナーと管理者は、エージェントが保存したものをすべて **設定 → Slack** の **メモリとスキル** で確認できます。メモを種類で絞り込み、任意のメモやスキルを削除し、スキルの名前、説明、指示を編集できます。これらの変更は、本文を含めずにワークスペースのアクティビティログに記録されます。
- エージェントをアンインストールすると、メモとスキルはすべて削除されます。もう一度追加すると、空のメモリから始まります。

## スケジュールされたタスク

エージェントに定期的に何かをするよう頼むと、その会話に定期タスクを設定します。例:

- `@Phaseo every weekday at 9:00, summarise yesterday's news about electric vehicles`
- `@Phaseo every Monday at 8:30, list last week's Phaseo spend by model`
- `@Phaseo on the 1st of every month at 10:00, list the API keys nobody used last month`
- `@Phaseo which recurring tasks are set up here?` or `@Phaseo cancel the Monday spend summary`

エージェントは、設定した内容（何をするか、どこに投稿するか、頻度、次回の実行日時）を確認として伝えます。

- **頻度:** 毎時（指定した分）、毎日、平日（月曜から金曜）、毎週指定した曜日、または毎月指定した日（その日がない月は月末）。1 時間に 1 回より多くは実行されません。
- **時刻:** 設定した人の Slack のタイムゾーンでの現地時刻です。夏時間の切り替えがあってもその時刻を保ちます。
- **場所:** 設定したチャンネルまたはダイレクトメッセージです。各実行ではそこに短い **Scheduled: …** メッセージを投稿し、そのスレッドで回答します。そのスレッドへの返信は、エージェントへの通常のメッセージとして扱われます。
- **実行内容:** エージェントは依頼を単独で完結する指示として保存するため、各実行は設定したときの会話がなくても動きます。スケジュールされた実行では、ボタン付きの質問や Slack の検索はせず、定期タスクの設定や変更もできません。

各実行は、設定した人への通常の回答です。エージェントはその人がまだ利用できるかを確認し、実行はその人の回答の 1 回としてプラン、**月の支出上限**、**1 人 1 時間あたりの回答数** に数えられ、回答ごとの上限（下の「回答ごとの上限」を参照）を守り、いつものフッターで終わります。

実行できない場合:

- 設定した人がエージェントを使えなくなった、エージェントが Phaseo で一時停止された、または会話に投稿できなくなった（チャンネルから外された場合など）ときは、その実行はスキップされ、タスクは一時停止されます。理由は **設定 → Slack** に表示されます。
- それ以外で実行できなかった場合（**月の支出上限** に達して断られた場合など）は失敗として数えられます。3 回続けて失敗するとタスクは一時停止され、エージェントが設定した人にダイレクトメッセージで知らせます。

自分が設定したタスクは、エージェントに頼んでキャンセルできます。Slack アカウントを連携した Phaseo ワークスペースのオーナーと管理者（上の「Slack アカウントを連携する」を参照）は、誰のタスクでもキャンセルできます。共有の Slack Connect チャンネルにいるほかの会社の人は、会話のタスクを見られますが、設定はできません。エージェントの **Home** タブには自分のタスクが表示されます。

### 定期タスクの設定

オーナーと管理者は、**設定 → Slack** の **定期タスク** で次を設定します:

| 設定 | 内容 | 既定値 |
| --- | --- | --- |
| **定期タスクの設定を許可する** | オフにすると、誰も設定できず、どれも実行されません。タスクは保持され、オンに戻すと再び実行されます。 | オン |
| **このワークスペースの定期タスクの上限** | 1 から 100 まで。下げても、設定済みのタスクは残ります。 | 20 |
| **設定できる人** | **エージェントを使えるすべての人** または **Phaseo アカウントを連携した人のみ**。 | すべての人 |

同じセクションに、各タスクの内容、投稿先、頻度、次回の実行、設定した人、前回の実行結果が一覧表示されます。どのタスクも一時停止、再開、削除できます。再開したタスクは次の時刻に実行され、失敗の回数は 0 から数え直されます。エージェントをアンインストールすると、定期タスクはすべて削除されます。

## 上限

オーナーと管理者が **設定 → Slack** で設定します。

| 設定 | 内容 | デフォルト |
| --- | --- | --- |
| **プラン** | エージェントが 1 か月に対応する人数です。3、10、25、50、100 人まで、または 100 を超える任意の人数を選べます。 | 3 人まで |
| **新しい人がプランを超える場合** | **断る** は、新しい人にプランが上限に達したことを伝えます。**自動的に上位プランに切り替える** は、エージェントを使う人に合わせて **月の最大人数** までプランを広げます。 | **断る** |
| **月の最大人数** | プランに関係なく、1 か月の人数に固定の上限を設けます。プランより少なくはできません。 | 上限なし |
| **月の支出上限** | エージェントの月額請求の上限額です。次の回答で上限を超える場合、エージェントは翌月まで回答を止めます。プランの料金以上である必要があります。 | インストール時に設定 |
| **1 人 1 時間あたりの回答数** | 1 人で 1 か月分を使い切らないようにします。 | 60 |
| **月のモデル支出上限** | エージェントの API キーが毎月モデルのトークンに使う金額の上限です。 | 上限なし |
| **ゲストを許可** | Slack ワークスペースのゲストがエージェントを使えます。 | オン |
| **他社の人を許可** | 共有の Slack Connect チャンネルにいる他の組織の人がエージェントを使えます。 | オフ |

**エージェント** セクションでは、モデルと **指示** を設定します。指示は、口調や重点など、エージェントがすべての回答で従う追加のガイドで、最大 8,000 文字です。

### 回答ごとの上限

各回答は、12 ステップまたはモデルの支出 $0.50 のどちらか早いほうで止まります。1 ステップは、1 回のモデル呼び出しと、それが実行するツール（Web 検索など）です。エージェントが聞いたほかのモデルや、比較のモデルも同じ $0.50 に含まれます。上限で回答が止まった場合はエージェントがそう伝え、続けるよう頼むことができます。これらの上限はすべてのワークスペースで共通です。エージェントが作成した画像も $0.50 に含まれます。

## 料金

料金は、その月（UTC）に 1 回以上回答を受け取った人数で決まります。1 人は回答の数にかかわらず月に 1 回だけ数えられ、誰もエージェントを使わなかった月は無料です。

| その月にエージェントを使った人数 | 月額料金 |
| --- | --- |
| 1〜3 | $0.99 |
| 4〜10 | $2.99 |
| 11〜25 | $4.99 |
| 26〜50 | $7.99 |
| 51〜100 | $14.99 |
| 101〜1,000 | $15 から $59 まで均等に上がります（1 ドル単位）。たとえば 200 人なら $20、500 人なら $35 です。 |
| 1,000 超 | $59、または 1 人あたり $0.045（1 ドル単位）のうち高いほうです（約 1,300 人から）。たとえば 2,000 人なら $90 です。 |

1 人あたり月 300 件の回答が含まれ、ワークスペース全体で共有されます。それを超える回答は 1,000 件あたり $0.25 です。

たとえば、8 人が 1 か月に 3,000 件の回答を受け取った場合、料金は 10 人までの $2.99 です。2,400 件の回答が含まれるため、残りの 600 件が $0.15 となり、その月の請求は $3.14 です。

モデルのトークンはこの料金に含まれません。エージェントの回答に応じて、エージェントの API キーを通じて通常のゲートウェイリクエストとして、各モデルの料金で課金されます。**月のモデル支出上限** で制限できます。

### 請求のしくみ

- その月の請求は、月が終わってから最初の数時間のうちにクレジットから差し引かれ、**月の支出上限** を超えることはありません。
- **設定 → Slack** の **今月** には、これまでの人数、回答数、請求見込みが表示されます。各請求は **過去の請求** と、請求の取引履歴に **Slack エージェント** として表示されます。
- クレジットが足りない場合、請求はクレジット待ちになり、エージェントのステータスが **支払い待ち** になります。支払いが済むまで回答を止めます。Phaseo は 1 時間ごとに再試行するため、クレジットを追加してからおよそ 1 時間以内に回答が再開します。金額は最初の試行時に確定します。

## オーナーと管理者へのメール

オーナーまたは管理者にしか解決できない理由でエージェントが人を断った場合、Phaseo はワークスペースのすべてのオーナーと管理者にメールを送ります。

| 理由 | メールの件名 | 対処 |
| --- | --- | --- |
| プランが上限に達した | Slack agent: someone new was turned away | より大きなプランを選ぶか、**自動的に上位プランに切り替える** を選びます。 |
| **月の最大人数** に達した | Slack agent: people limit reached | **月の最大人数** を引き上げるか、なくします。 |
| **月の支出上限** に達した | Slack agent: monthly spending cap reached | 上限を引き上げるか、翌月まで待ちます。 |
| 請求が未払い | Slack agent: paused until the charge is paid | クレジットを追加します。 |

各メールは、理由ごとに月 1 回までしか送られません。メールには Slack のユーザー名もメッセージも含まれません。

ゲスト、他社の人、1 時間あたりの上限による拒否はメールで通知されません。ワークスペースのアクティビティログには、プランの上限、**月の最大人数**、**月の支出上限** による拒否は毎月最初の 1 回が、ゲスト、他社の人、1 時間あたりの上限による拒否は人ごとに毎月最初の 1 回が記録されます。Slack でのエージェントの返信が、管理者に通知したと伝えることはありません。

## データとプライバシー

Slack の API 利用規約では、Slack のデータでの学習もデータのアーカイブも認められていないため、エージェントは次のように設定されています。

- **Phaseo のログにメッセージの内容を残しません。** エージェントの API キーは、ワークスペースの設定にかかわらず、リクエストやレスポンスの内容をログ、キャッシュ、テレメトリーのどこにも保存しません。リクエスト自体は内容なしで利用状況とログに表示され、[リクエストラベル](./request-labels.mdx) `app=slack-agent`、`slack_team`、`slack_channel` と[アプリのタイトル](./app-attribution.mdx) `Phaseo Slack agent` が付きます。
- **プロンプトで学習するプロバイダーは使いません。** **Slack agent** [ガードレール](../cookbook/guardrails-for-api-keys.mdx)は、有料・無料モデルでの学習とプロンプトの公開をオフにするため、プロンプトで学習するプロバイダーは使われません。ログを保持しても学習には使わないプロバイダーは回答できます。こうしたプロバイダーは、自社のポリシーに従ってメッセージの内容をログに保持する場合があります。Phaseo 自身のログ、キャッシュ、テレメトリーにはメッセージの内容は保存されません。
- **作業メモリは短期間だけ保持します。** エージェントはスレッドごとに、最近の自分の回答、使ったツールについての短いメモ、順番を待っているメッセージ、どこから読むかを判断するためのスレッドの最近のメッセージの ID（本文は含みません）、接続ボタンを送った相手、自分がした質問とその答えを保持します。これらはスレッドの最後のアクティビティから 7 日後に削除されます。
- **メモリは確認でき、削除できます。** エージェントは、保存を頼まれたメモ、ピン、To-Do、スキルを、メッセージのコピーではなく自分の言葉で、頼んだ人の Slack ID とともに保持します。誰かが削除するか、保持期限の日付を過ぎるか、エージェントをアンインストールするまで残ります。オーナーと管理者は **設定 → Slack** で確認・削除でき、メモをオフにすることもできます（上の「メモリとスキル」を参照）。 他社の人がワークスペース全体のメモを見ることはありません。
- **共有されたファイルは読むだけで、保持しません。** エージェントは回答のために読む画像や PDF をダウンロードし、同じルールのもとで、その回答のリクエストと一緒にモデルへ送ります。保存することはなく、回答が終わるまでメッセージと一緒に Slack のファイル ID とファイル名だけを保持します。
- **Slack の検索結果は保持しません。** エージェントが Slack を検索して見つけた内容は、同じルールのもとで、その回答のリクエストと一緒にモデルへ送られるだけで、ほかのどこにも残りません。作業メモリにも、ログにも、Phaseo のデータベースにも残らず、質問への回答を待っている間も同じです。作業メモリに残るのは、何を検索したかと見つかった件数だけです。あなたの代わりに検索する Slack の権限は、回答が終わるまであなたのメッセージと一緒に保持されます。
- **定期タスク。** エージェントは各タスクについて、タイトルと指示、投稿先、スケジュールとタイムゾーン、設定した人の Slack ID、前回の実行結果を保持します。誰かがタスクをキャンセルまたは削除するか、エージェントをアンインストールするまで残ります。オーナーと管理者は **設定 → Slack** で確認、一時停止、削除できます。
- **何もアーカイブしません。** Phaseo は Slack のものを何もアーカイブしません。エージェント自身のログには、Slack の ID とステータスだけが残ります。
- **シークレットは暗号化します。** ボットトークンと Slack アプリのシークレットは暗号化して保存し、二度と表示しません。

アンインストールすると、エージェントの API キー、メモ、保存済みスキル、定期タスクが削除され、ガードレールも外されます。

<Steps>
<Step title="マニフェストからアプリを作成する">

Slack のアプリ設定（[api.slack.com/apps](https://api.slack.com/apps)）で **Create New App**、**From a manifest** の順に選びます。Slack ワークスペースを選び、下のマニフェストを貼り付けます。`name`、`description`、`long_description`、`display_name` は変更できますが、それ以外はそのままにしてください。Slack にリクエスト URL がまだ検証されていないと表示されることがありますが、手順 3 までは想定どおりです。

</Step>

<Step title="Phaseo にアプリを保存する">

Slack のアプリの **Basic Information** ページで、**App ID**、**Client ID**、**Client Secret**、**Signing Secret** をコピーします。Phaseo で **設定 → Slack** を開き、**詳細: 独自の Slack アプリを使う** に入力して **Slack アプリを保存** を選びます。

</Step>

<Step title="リクエスト URL を自分のアプリに向ける">

Slack でアプリの **App Manifest** ページを開きます。2 つのリクエスト URL の `YOUR_APP_ID` をアプリ ID に置き換えます（例：`https://slack.phaseo.app/events/A0123ABCDEF`）。保存し、Slack から求められたらリクエスト URL を検証します。

</Step>

<Step title="インストールする">

**設定 → Slack** の **Slack アプリ** で **独自の Slack アプリ** を選び、**Slack に追加** を選びます。

</Step>
</Steps>

| 設定 | 値 |
| --- | --- |
| リダイレクト URL | `https://phaseo.app/api/account/settings/slack/oauth/callback` |
| Event Subscriptions のリクエスト URL | `https://slack.phaseo.app/events/YOUR_APP_ID` |
| Interactivity のリクエスト URL | `https://slack.phaseo.app/interactions/YOUR_APP_ID` |
| ボットイベント | `app_mention`、`message.im`、`agent_session_stopped`、`app_uninstalled`、`tokens_revoked`、`app_home_opened` |

Phaseo はインストール時に、Slack にちょうど次のボットトークンのスコープを求めます。そのため、アプリにはこれらすべてが必要です。

| スコープ | 許可される内容 |
| --- | --- |
| `app_mentions:read` | エージェントをメンションしたメッセージを見る。 |
| `assistant:write` | Slack でエージェントとして動作し、回答中にステータスと停止ボタンを表示する。 |
| `chat:write` | 回答を投稿し、ストリーミングする。 |
| `im:history` | エージェントに送られたダイレクトメッセージを読む。 |
| `channels:history`、`groups:history` | パブリックチャンネルとプライベートチャンネルで、メンションされたスレッドを読む。 |
| `users:read` | ゲスト、ボット、他の組織の人かどうかを確認する。 |
| `files:read` | エージェントに共有された画像や PDF を読む。 |
| `files:write` | スレッドにグラフや画像を投稿する。 |
| `search:read.public` | 質問した人の代わりにパブリックチャンネルを検索する。 |
| `search:read.files` | パブリックチャンネルで共有されたファイルも検索に含める。 |

独自のアプリについてのルール：

- マニフェストのとおり、トークンのローテーションはオフのままにしてください。一度オンにすると、Slack ではオフに戻せません。
- マニフェストは Slack のエージェントメッセージ機能（`agent_view`）を使います。Slack が新しいアプリに提供しているのはこの機能だけです。
- 1 つの Slack アプリを接続できる Phaseo ワークスペースは 1 つで、1 つの Phaseo ワークスペースに保存できる Slack アプリも 1 つです。
- エージェントが独自のアプリでインストールされている間は、そのシークレットしか置き換えられません。別のアプリや Phaseo のアプリに切り替えるには、先にアンインストールしてください。

## 一時停止またはアンインストール

- **設定 → Slack** の **回答を一時停止** を選ぶと、**回答を再開** を選ぶまですべての回答が止まります。エージェントにメッセージを送った人には、一時停止中であることが非公開で通知されます。一時停止中に実行時刻を迎えた定期タスクも一時停止されます。**定期タスク** で再開してください。
- **アンインストール** を選ぶと、エージェントがすぐに止まり、API キー、メモ、保存済みスキル、定期タスクが削除され、ガードレールが外され、Slack からアプリが削除されます。Slack が削除を確認できなかった場合は Phaseo がその旨を伝えるので、Slack でもアプリを削除してください。ガードレールをほかのキーやメンバーにも追加している場合、ガードレールは残ります。
- Slack 側でアプリを削除するか、ボットトークンを取り消した場合も、Phaseo で同じようにアンインストールされます。

過去の請求は請求履歴に残ります。アンインストールした月にエージェントを使った人の分は、その月の終わりに請求されます。エージェントはいつでも再び追加できます。

## トラブルシューティング

エージェントが回答できない場合は、Slack で非公開で返信します。

| Slack での返信 | 理由 | 対処 |
| --- | --- | --- |
| "The Phaseo agent is paused until this workspace's Phaseo bill is paid." | 過去の月の請求がクレジット待ちです（**支払い待ち**）。 | クレジットを追加します。およそ 1 時間以内に回答が再開します。 |
| "The Phaseo agent is paused in this Slack workspace." | 管理者が **回答を一時停止** を選びました。 | **回答を再開** を選びます。 |
| "…has answered as many people this month as this workspace's plan covers…" | プランが上限に達し、新しい人が断られています。 | より大きなプランを選ぶか、**自動的に上位プランに切り替える** を選びます。 |
| "This workspace has reached its Slack agent limit for the month." | **月の最大人数** に達しました。 | 上限を引き上げるか、なくします。 |
| "…has reached this workspace's monthly spending cap…" | 次の回答で **月の支出上限** を超えます。 | 上限を引き上げるか、翌月まで待ちます。 |
| "You've reached the limit of … answers an hour." | **1 人 1 時間あたりの回答数** に達しました。 | 待つか、上限を引き上げます。 |
| "The Phaseo agent isn't available to guests in this workspace." | **ゲストを許可** がオフです。 | ゲストにも使ってもらう場合はオンにします。 |
| "The Phaseo agent only answers people in this organization." | **他社の人を許可** がオフです。 | その人たちにも使ってもらう場合はオンにします。 |
| "Connect your Phaseo account to use the Phaseo agent here." | アクセスが **連携済みのアカウントのみ** です。 | Slack アカウントを連携します（上の「Slack アカウントを連携する」を参照）。 |
| "I'm still working through earlier messages in this thread." | このスレッドではすでに 5 件のメッセージが待っています。 | それらの回答を待ちます。 |
| "Sorry, I couldn't check your Slack account just now." | Slack が照会に応答しませんでした。 | 1 分後にもう一度試します。 |
| "The model chosen for this agent isn't available to the Slack agent." | ゲートウェイがエージェントのキーでそのモデルを使えません。自動ルーティングなしで **自動** を選んでいるか、**Slack agent** ガードレールを満たすプロバイダーがそのモデルにありません。 | **設定 → Slack** で別のモデルを選びます。 |
| "…isn't one of the models you can choose here, so I didn't answer." | メッセージが `with …:` で始まり、**モデルの選択** にないモデル、または複数の許可されたモデルに当てはまる名前を指定しています。 | 返信の一覧にあるモデルを使うか、`with …:` を外してください。 |
| "The model you chose for this message isn't available to the Slack agent." | 上と同じ理由で、ゲートウェイがエージェントのキーで選ばれたモデルを使えません。 | `with …:` を付けずに質問するか、**モデルの選択** のモデルを入れ替えてください。 |
| "The model this agent uses can't read the files shared here." | エージェントのモデルのどのプロバイダーも、共有された画像や PDF を読めません。 | ファイルなしで質問するか、**設定 → Slack** で画像を読めるモデルを選んでください。 |
| "…so I didn't compare them." または "Name 2 or 3 different models to compare…" | メッセージが `compare …:` で始まり、**モデルの選択** にないモデルや、複数の許可されたモデルに当てはまる名前を指定しているか、異なるモデルの数が 2 つ未満か 3 つより多くなっています。 | 返信のリストから 2 つか 3 つのモデルを使ってください。 |

エージェントがまったく返信しない場合：

- チャンネルでは、エージェントがそのチャンネルのメンバーであることを確認し、回答してほしいメッセージごとにメンションしてください。
- 編集されたメッセージ、ボット、ほかのアプリには回答しません。
- 独自の Slack アプリの場合は、2 つのリクエスト URL の末尾がアプリ ID になっていること、Slack で検証済みと表示されていること、アプリが **設定 → Slack** に保存されていることを確認してください。

インストールが完了しない場合は、**設定 → Slack** に理由が表示されます。よくある理由は、プライバシー設定の確認がまだ済んでいないこと（**Chat** を一度開きます）と、Slack ワークスペースにすでに別の Phaseo ワークスペースのエージェントが入っていること（先にそちらでアンインストールします）です。
