**設定 → Slack** から Phaseo エージェントを Slack に追加すると、チームはチャンネルでメンションするか直接メッセージを送って、選んだモデルから回答を得られます。エージェントはスレッドで返信し、書きながら回答をストリーミングします。オーナーと管理者は、利用できる人と上限を決めます。料金は利用した人数に応じた月額で、モデルのトークンはほかのゲートウェイリクエストと同じように課金されます（[Slack エージェントの管理と料金](/ja/v1/guides/slack-agent-admin)を参照）。

<Note>
Slack エージェントはワークスペースに順次提供しています。設定に **設定 → Slack** がまだ表示されない場合、そのワークスペースではまだ利用できません。
</Note>

| できること | セクション |
| --- | --- |
| 選んだモデル、またはメッセージごとに指定したモデルで回答し、2 つか 3 つのモデルを比較する | [メッセージごとにモデルを選ぶ](/ja/v1/guides/slack-agent-usage#choosing-a-model-per-message) |
| Web を検索し、Web ページを読む | [Slack でエージェントを使う](/ja/v1/guides/slack-agent-usage#use-the-agent-in-slack) |
| グラフや画像を投稿し、共有された画像や PDF を読む | [グラフ、画像、ファイル](/ja/v1/guides/slack-agent-usage#charts-images-and-files) |
| 質問した人として Slack ワークスペースのパブリックチャンネルを検索する | [Slack を検索する](/ja/v1/guides/slack-agent-usage#searching-slack) |
| 連携済みのメンバーに Phaseo の支出、クレジット、API キーの利用状況、モデルを伝える | [利用状況について質問する](/ja/v1/guides/slack-agent-usage#ask-about-usage) |
| メモを覚えておき、保存したスキルに従う | [メモリとスキル](/ja/v1/guides/slack-agent-usage#memory-and-skills) |
| 依頼をスケジュールどおりに実行する | [スケジュールされたタスク](/ja/v1/guides/slack-agent-usage#scheduled-tasks) |
| 長い回答を Web ページとして公開する | [共有ページ](/ja/v1/guides/slack-agent-usage#shared-pages) |

## 始める前に

- Phaseo ワークスペースのオーナーまたは管理者であり、Slack ワークスペースにアプリを追加できる必要があります。
- **チャット** を一度開いて、ワークスペースのプライバシー設定を確認してください。Phaseo は最初のインストールの前にこれを求めます。
- [クレジット](https://phaseo.app/settings/credits)を追加してください。月額の請求とエージェントのモデルのトークンは、クレジットから支払われます。

## エージェントを Slack に追加する

<Steps>
<Step title="動作を選ぶ">

**設定 → Slack** を開きます。**Slack に追加** で、モデル、エージェントを利用できる人、利用状況データを共有できる場所、[上限](/ja/v1/guides/slack-agent-admin#limits)を選びます。ワークスペースで自動ルーティングを利用できる場合は、**自動** を選ぶと Phaseo が質問ごとに適したモデルを選びます。利用できない場合は特定のモデルを選んでください。これらはすべて後から変更できます。

</Step>

<Step title="Slack で承認する">

**Slack に追加** を選びます。Slack にエージェントが求める権限が表示されます。承認すると Slack から **設定 → Slack** に戻り、インストールが表示されます。

</Step>

<Step title="質問してみる">

Slack のアプリ一覧からエージェントを開き、メッセージを送ります。チャンネルで使うには、`/invite @Phaseo` で招待してからメンションします。何を頼めるかは [Slack エージェントを使う](/ja/v1/guides/slack-agent-usage)で説明しています。

</Step>
</Steps>

インストールすると、Phaseo ワークスペースに次の 2 つが作成されます。

- **エージェント用の API キー。** Phaseo が管理するため、キーのページには表示されません。エージェントのモデルのトークンはこのキーで課金されます。
- **そのキーに付く Slack agent という名前のガードレール。** Slack のメッセージを学習から除外します（[データとプライバシー](/ja/v1/guides/slack-agent-admin#data-and-privacy)を参照）。

1 つの Slack ワークスペースに同時に追加できるのは、1 つの Phaseo ワークスペースのエージェントだけです。

<span id="who-can-use-it"></span>
## 利用できる人

**利用できる人** で選びます。

| オプション | 回答を受け取る人 |
| --- | --- |
| **Slack の全員**（デフォルト） | Slack ワークスペースの全員。[上限](/ja/v1/guides/slack-agent-admin#limits)の範囲内です。 |
| **連携済みのアカウントのみ** | Slack アカウントをこの Phaseo ワークスペースのメンバーと連携した人だけです。それ以外の人には、エージェントが連携用のリンクを送ります。 |

**上限** では、**ゲストを許可**（デフォルトでオン）で Slack ワークスペースのゲストがエージェントを使えるようになり、**他社の人を許可**（デフォルトでオフ）で共有の Slack Connect チャンネルにいる他の組織の人が使えるようになります。同じ Enterprise Grid 組織の別のワークスペースの人は、自社の人として扱われます。エージェントがボットやほかのアプリに回答することはありません。

<span id="link-a-slack-account"></span>
### Slack アカウントを連携する

エージェントは、連携していない人に **Connect your Phaseo account** ボタンを非公開で送ります。

- **連携済みのアカウントのみ** の場合は、その人がメッセージを送ったときです。連携するまで回答しません。
- **Slack の全員** の場合は、[利用状況データ](/ja/v1/guides/slack-agent-usage#ask-about-usage)が許可されている場所で、その人が利用状況について質問したときです。それでも答えられることには回答し、ボタンは各スレッドで 1 人につき最大 1 回だけ送ります。新しいボタンが必要な場合は、新しいスレッドで質問してください。

ボタンは 15 分間有効です。

1. ボタンを選びます。ブラウザで Phaseo が開きます。
2. エージェントをインストールした Phaseo ワークスペースのメンバーであるアカウントでサインインします。
3. **アカウントを接続** を選びます。

アカウントを連携すると、利用状況についても質問できるようになります。

<span id="update-slack-permissions"></span>
## Slack 権限を更新する

グラフと画像には Slack の `files:write` 権限が、ファイルの読み取りには `files:read` が、[Slack の検索](/ja/v1/guides/slack-agent-usage#searching-slack)には `search:read.public` と `search:read.files` が必要です。これらができるようになる前に追加したエージェントには、まだこれらの権限がありません。その場合、エージェントは管理者が権限を更新する必要があると伝え、**設定 → Slack** に **Slack 権限を更新** が表示されます。

1. **Slack 権限を更新** を選びます。エージェントが求める権限が Slack に表示されます。
2. 同じ Slack ワークスペースで承認します。Slack から **設定 → Slack** に戻ります。

更新しても、エージェントの設定、API キー、ガードレール、履歴はそのまま残ります。独自の Slack アプリを使う場合は、先に **設定 → Slack** に表示されるスコープをその[マニフェスト](#use-your-own-slack-app)に追加してください。

<span id="use-your-own-slack-app"></span>
## 独自の Slack アプリを使う

デフォルトでは、エージェントは Phaseo の Slack アプリをインストールします。自社の名前やアイコンを使うなど、自社が所有する Slack アプリを使う場合は、Phaseo のマニフェストからアプリを作成します。

<Steps>
<Step title="マニフェストからアプリを作成する">

Slack のアプリ設定（[api.slack.com/apps](https://api.slack.com/apps)）で **Create New App**、**From a manifest** の順に選びます。Slack ワークスペースを選び、下のマニフェストを貼り付けます。`name`、`description`、`long_description`、`display_name` は変更できますが、それ以外はそのままにしてください。Slack にリクエスト URL がまだ検証されていないと表示されることがありますが、手順 3 までは想定どおりです。

</Step>

<Step title="Phaseo にアプリを保存する">

Slack のアプリの **Basic Information** ページで、**App ID**、**Client ID**、**Client Secret**、**Signing Secret** をコピーします。Phaseo で **設定 → Slack** を開き、**詳細: 独自の Slack アプリを使う** に入力して **Slack アプリを保存** を選びます。

</Step>

<Step title="リクエスト URL を自分のアプリに向ける">

Phaseo の **設定 → Slack** に、保存したアプリ用の 2 つのリクエスト URL が表示されます。Slack でアプリの **App Manifest** ページを開き、2 つの `request_url` の値をこれらに置き換えます（1 つ目はイベント用、2 つ目はインタラクティビティ用）。保存し、Slack から求められたらリクエスト URL を検証します。

</Step>

<Step title="インストールする">

**設定 → Slack** の **Slack アプリ** で **独自の Slack アプリ** を選び、**Slack に追加** を選びます。

</Step>
</Steps>

```json manifest.json
{
  "_metadata": {
    "major_version": 2,
    "minor_version": 1
  },
  "display_information": {
    "name": "Phaseo",
    "description": "Ask the Phaseo agent questions in Slack, answered by the model your team chooses.",
    "background_color": "#0069a8",
    "long_description": "The Phaseo agent answers questions in Slack. Mention it in a channel or send it a direct message, and it replies in the thread with the model your workspace chose in Phaseo. It can search the web and read web pages, and linked members of your Phaseo workspace can ask about spend, credits, API key usage and models. It can also search your Slack workspace's public channels for the person asking, finding only what they can see (searching by meaning needs a Business+ or Enterprise+ Slack plan). Phaseo's request logs never keep message content, requests never go to providers that train on prompts, and a thread's working memory is deleted 7 days after its last activity. Owners and admins choose who can use it, its limits and its monthly spending cap in Phaseo settings."
  },
  "features": {
    "app_home": {
      "home_tab_enabled": true,
      "messages_tab_enabled": true,
      "messages_tab_read_only_enabled": false
    },
    "bot_user": {
      "display_name": "Phaseo",
      "always_online": true
    },
    "agent_view": {
      "agent_description": "Answers your team's questions with the model your Phaseo workspace chooses. It can search the web, and linked members can ask about Phaseo spend, credits, API key usage and models."
    }
  },
  "oauth_config": {
    "redirect_urls": [
      "https://phaseo.app/api/account/settings/slack/oauth/callback",
      "https://slack.phaseo.app/p/signin"
    ],
    "scopes": {
      "bot": [
        "app_mentions:read",
        "assistant:write",
        "chat:write",
        "im:history",
        "channels:history",
        "groups:history",
        "users:read",
        "files:read",
        "files:write",
        "search:read.public",
        "search:read.files"
      ]
    }
  },
  "settings": {
    "event_subscriptions": {
      "request_url": "https://slack.phaseo.app/apps/FROM_PHASEO_SETTINGS/events",
      "bot_events": [
        "app_mention",
        "message.im",
        "agent_session_stopped",
        "app_uninstalled",
        "tokens_revoked",
        "app_home_opened"
      ]
    },
    "interactivity": {
      "is_enabled": true,
      "request_url": "https://slack.phaseo.app/apps/FROM_PHASEO_SETTINGS/interactions"
    },
    "org_deploy_enabled": true,
    "socket_mode_enabled": false,
    "token_rotation_enabled": false
  }
}
```

| 設定 | 値 |
| --- | --- |
| リダイレクト URL | `https://phaseo.app/api/account/settings/slack/oauth/callback` |
| Event Subscriptions のリクエスト URL | `https://slack.phaseo.app/apps/FROM_PHASEO_SETTINGS/events` |
| Interactivity のリクエスト URL | `https://slack.phaseo.app/apps/FROM_PHASEO_SETTINGS/interactions` |
| ボットイベント | `app_mention`、`message.im`、`agent_session_stopped`、`app_uninstalled`、`tokens_revoked`、`app_home_opened` |

Phaseo はインストール時に、Slack にちょうど次のボットトークンのスコープを求めます。そのため、アプリにはこれらすべてが必要です。

| スコープ | 許可される内容 |
| --- | --- |
| `app_mentions:read` | エージェントをメンションしたメッセージを見る。 |
| `assistant:write` | Slack でエージェントとして動作し、回答中にステータスと停止ボタンを表示する。 |
| `chat:write` | 回答を投稿し、ストリーミングする。 |
| `im:history` | エージェントに送られたダイレクトメッセージを読む。 |
| `channels:history`、`groups:history` | パブリックチャンネルとプライベートチャンネルで、メンションされたスレッドを読む。 |
| `users:read` | ゲスト、ボット、他の組織の人かどうかを確認する。 |
| `files:read` | エージェントに共有された画像や PDF を読む。 |
| `files:write` | スレッドにグラフや画像を投稿する。 |
| `search:read.public` | 質問した人の代わりにパブリックチャンネルを検索する。 |
| `search:read.files` | パブリックチャンネルで共有されたファイルも検索に含める。 |

独自のアプリについてのルール：

- マニフェストのとおり、トークンのローテーションはオフのままにしてください。一度オンにすると、Slack ではオフに戻せません。
- マニフェストは Slack のエージェントメッセージ機能（`agent_view`）を使います。Slack が新しいアプリに提供しているのはこの機能だけです。
- マニフェストの `home_tab_enabled: true` とボットイベント `app_home_opened` により、エージェントに [Home タブ](/ja/v1/guides/slack-agent-usage#check-the-home-tab)が付きます。以前のマニフェストからアプリを作成した場合は、アプリの **App Manifest** ページで両方を追加してください。
- 1 つの Slack アプリを接続できる Phaseo ワークスペースは 1 つで、1 つの Phaseo ワークスペースに保存できる Slack アプリも 1 つです。
- エージェントが独自のアプリでインストールされている間は、そのシークレットしか置き換えられません。別のアプリや Phaseo のアプリに切り替えるには、先にアンインストールしてください。
- マニフェストの 2 つ目のリダイレクト URL `https://slack.phaseo.app/p/signin` により、Slack でサインインして [Slack ワークスペースと共有されたページ](/ja/v1/guides/slack-agent-usage#shared-pages)を表示できます。以前のマニフェストからアプリを作成した場合は、アプリの **App Manifest** ページで追加してください。

<span id="fix-setup-problems"></span>
## 設定の問題を解決する

インストールが完了しない場合は、**設定 → Slack** に理由が表示されます。よくある理由は、プライバシー設定の確認がまだ済んでいないこと（**チャット** を一度開きます）と、Slack ワークスペースにすでに別の Phaseo ワークスペースのエージェントが入っていること（先にそちらでアンインストールします）です。

エージェントがまったく返信しない場合：

- チャンネルでは、エージェントがそのチャンネルのメンバーであることを確認し、回答してほしいメッセージごとにメンションしてください。
- 編集されたメッセージ、ボット、ほかのアプリには回答しません。
- 独自の Slack アプリの場合は、リクエスト URL が **設定 → Slack** で保存したアプリに表示されているものであること、Slack で検証済みと表示されていることを確認してください。

回答できないと非公開で返信された場合は、その返信に理由が書かれています。[エージェントが回答できない場合](/ja/v1/guides/slack-agent-admin#when-the-agent-cant-answer)を参照してください。
