---
icon: "waypoints"
title: "ツール呼び出しのパターン"
description: "Chat Completions と Responses のエンドポイントで、信頼できるツール呼び出しのループを組みます。"
---

モデルがツールを呼び出したら、会話、モデルの呼び出し、ツールの結果を繰り返し含めた続きのリクエストを送ります。するとモデルは回答を書くか、別のツールを呼び出すので、その場合は同じことを繰り返します。アプリがすでに使っているメッセージ形式のエンドポイントを使ってください。OpenAI 形式のメッセージループなら `/v1/chat/completions`、Responses API なら `/v1/responses`、Anthropic ネイティブのアプリなら `/v1/messages` です。

<Tabs>
<Tab title="Chat Completions">

`finish_reason` が `tool_calls` のときは各呼び出しを実行し、アシスタントメッセージをそのまま送り、その後に呼び出しごとに 1 つずつ、`tool_call_id` で対応付けた `role: "tool"` メッセージを送ります。`tools` も再度送ってください。

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "What is the weather in Seattle?" },
    {
      "role": "assistant",
      "content": null,
      "tool_calls": [
        {
          "id": "call_123",
          "type": "function",
          "function": {
            "name": "get_weather",
            "arguments": "{\"city\":\"Seattle\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_123",
      "content": "72F and sunny"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    }
  ]
}
```

</Tab>
<Tab title="Responses">

呼び出しは `function_call` タイプの出力アイテムとして届きます。呼び出しのアイテムを入力として送り返し、その後に同じ `call_id` を持つ `function_call_output` アイテムを続けます。

```json
{
  "model": "openai/gpt-6-astra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [{ "type": "input_text", "text": "What's the weather in Seattle?" }]
    },
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Seattle\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "72F and sunny"
    }
  ]
}
```

</Tab>
</Tabs>

呼び出しを実行する前に、その引数を検証してください。[ツール呼び出しの安全性](./tool-calling-safety)を参照してください。
