サンプルプロジェクトを選び、ローカルで実行して自分用に調整してください。1 回の API 呼び出しなら[クイックスタート](../quickstart.mdx)、特定の機能なら[クックブック](../cookbook/index.mdx)を参照してください。

## 実行可能なプロジェクト

| 作るもの | 手順 | ソース |
| --- | --- | --- |
| サーバー側の API キーを使うブラウザーチャット | [Next.js チャット](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| OAuth 認可とバックエンドプロキシ | [OAuth ワークベンチ](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| 最小限の REST 連携 | [Node スモークアプリ](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| Python のコマンドラインアプリケーション | [Python CLI](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| Vercel AI SDK を使うアプリケーション | [AI SDK 連携](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

認証情報はサーバー側に置き、サンプルの環境変数を確認し、実行前に選択したモデルの料金を確認してください。`:free` モデルを使うサンプルでは、クレジットの入金は必要ありません。

## 言語別のリクエスト

[クライアント SDK リファレンス](../sdk-reference/client/overview.mdx)には、言語別のインストール手順とリクエストの例があります。画像のパラメーターは[画像生成リファレンス](../api-reference/endpoint/images-generations.mdx)、チャットのリクエストは [Chat Completions](../api-reference/endpoint/chat-completions.mdx) を参照してください。

コーディングエージェントにプロジェクトの雛形を作らせる場合は、[ミニアプリのスタータープロンプト](../cookbook/mini-app-starter-prompts.mdx)を使い、実際の認証情報で使う前に生成されたコードをレビューしてください。
