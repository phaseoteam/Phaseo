---
title: "パッチの適用"
description: "Responses のモデルが検証済みのパッチ操作を返せるようにします。"
icon: "file-pen-line"
---

`/v1/responses` で `phaseo:apply_patch` を追加すると、ファイルの変更を構造化されたパッチ操作として受け取れます。Phaseo は各操作の形式を確認して返すだけで、ファイルには一切触れません。パッチを適用するか、ユーザーに表示するか、拒否するか、修正を求めるかはアプリが判断します。

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Create a small README patch for this project.",
    "tools": [
      { "type": "phaseo:apply_patch" }
    ]
  }'
```

`/v1/chat/completions` または `/v1/messages` では、リクエストは拒否されます。

## パラメーター

ありません。`{ "type": "phaseo:apply_patch" }` をそのまま追加します。

## モデルが送信する内容

`operation` オブジェクトです。

```json
{
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  }
}
```

| `type` | 必須の項目 | diff のルール |
| --- | --- | --- |
| `create_file` | `path`、`diff` | 空でないすべての行が `+` で始まる |
| `update_file` | `path`、`diff` | 空でないすべての行が `@@`、空白、`+`、`-` のいずれかで始まる |
| `delete_file` | `path` | なし |

`path` に null バイトを含めることはできません。

## ツールが返す内容

```json
{
  "status": "completed",
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  },
  "message": "Patch operation validated. The client must apply or reject this patch and report the result."
}
```

上記のルールに違反する操作は、理由とともに `apply_patch_invalid_operation` を返すため、モデルは再試行できます。

## 利用量と料金

呼び出しごとに `usage.server_tool_use.apply_patch_requests` に 1 が加算され、`server_tool_apply_patch_requests` で課金されることがあります。
