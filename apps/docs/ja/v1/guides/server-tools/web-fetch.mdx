`phaseo:web_fetch` を追加すると、ドキュメントページ、記事、変更履歴など、既知の URL をモデルが読めるようになります。モデルが `url` を指定し、Phaseo がページを取得してサイズ制限内に切り詰めたテキストを返します。モデルは回答する前に、さらに別のページを取得することもできます。

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Summarize https://phaseo.app/docs/v1/guides/tool-calling" }
    ],
    "tools": [
      { "type": "phaseo:web_fetch" }
    ]
  }'
```

<span id="parameters"></span>
## パラメーター

```json
{
  "type": "phaseo:web_fetch",
  "parameters": {
    "engine": "direct",
    "max_chars": 12000,
    "allowed_domains": ["phaseo.app"],
    "blocked_domains": ["internal.example.com"]
  }
}
```

| パラメーター | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `engine` | string | `direct` | `auto`、`native`、`direct`、`exa`、`parallel`、`firecrawl` のいずれか。[エンジンの選択](#choose-an-engine)を参照してください。 |
| `max_chars` | integer | `12000` | モデルに返すページテキストの文字数。上限は `100000` です。 |
| `max_content_tokens` | integer | なし | `max_chars` を省略したときに代わりに使われます。`native` のサイズ上限にもなります。 |
| `max_uses` | integer | `10` | 1 リクエストあたりの取得回数。上限は `100` です。 |
| `allowed_domains` | string[] | なし | これらのドメインからのみ取得します。モデルは呼び出し時にこのリストを絞り込めますが、広げることはできません。 |
| `blocked_domains` | string[] | なし | これらのドメインからは取得しません。別名: `excluded_domains`。 |

## モデルが送信する内容

各呼び出しには `url` が含まれます。モデルは `engine`、`max_chars`、`max_content_tokens`、ドメインリストも送信できます。

<span id="choose-an-engine"></span>
## エンジンの選択

| エンジン | 実行される処理 |
| --- | --- |
| `auto` | `/v1/messages` では Anthropic のネイティブ取得を使います。その他のエンドポイントでは、Exa が有効なら Exa、そうでなければ `direct` を使います。 |
| `direct` | Phaseo 自身がページを取得し、HTML をプレーンテキストに変換します。 |
| `exa` | Exa のコンテンツ抽出。 |
| `parallel` | Parallel Extract。 |
| `firecrawl` | Firecrawl Scrape。 |
| `native` | Anthropic の `web_fetch_20260209` ツール。`/v1/messages` でのみ使えます。その他のエンドポイントではリクエストが拒否されるため、`direct` または管理エンジンを使ってください。 |

管理エンジンが有効になっていない場合、呼び出しはモデルに `fetch_not_configured` を返します。

使えるのは HTTP(S) URL のみです。`direct` は HTML、プレーンテキスト、JSON などのテキスト形式のコンテンツタイプのみを受け付け、それ以外には `unsupported_content_type` を返します。リダイレクトは最大 5 回まで追跡し、それぞれをドメインリストと照合します。

### Anthropic ネイティブ取得

```json
{
  "model": "anthropic/claude-sonnet-4.6",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "Read the docs page and summarize the limits." }
  ],
  "tools": [
    {
      "type": "phaseo:web_fetch",
      "parameters": {
        "engine": "native",
        "max_content_tokens": 9000,
        "allowed_domains": ["phaseo.app"]
      }
    }
  ],
  "tool_choice": { "type": "tool", "name": "phaseo:web_fetch" }
}
```

## ツールが返す内容

```json
{
  "provider": "fetch",
  "engine": "direct",
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "text": "...",
  "truncated": false,
  "returned_chars": 8421
}
```

モデルがページ全体を読んだと判断する前に、`truncated` を確認してください。実践例は [Web Fetch によるツールのグラウンディング](../../cookbook/tool-grounding-with-web-fetch)を参照してください。

## 使用量と料金

取得 1 回ごとに `usage.server_tool_use.web_fetch_requests` が 1 増えます。管理対象の取得は `server_tool_web_fetch_requests` で課金されます。ネイティブ取得は、モデルの料金カードに定義がある場合 `native_web_fetch_requests` で課金されます。
