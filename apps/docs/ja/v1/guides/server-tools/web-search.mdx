`phaseo:web_search` を追加すると、最新の情報や出典のある情報が必要なときにモデルが Web を検索できるようになります。モデルがクエリを書き、1 回のリクエストで複数回検索できます。Phaseo は URL、タイトル、スニペット、ハイライト、必要に応じてページ本文を返し、モデルはそれに基づいた回答を書きます。

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What were the major AI announcements this week?" }
    ],
    "tools": [
      { "type": "phaseo:web_search" }
    ]
  }'
```

同じツール定義は、`/v1/responses` と `/v1/messages` の `tools` でも使えます。

<span id="parameters"></span>
## パラメーター

```json
{
  "type": "phaseo:web_search",
  "parameters": {
    "engine": "exa",
    "max_results": 5,
    "max_total_results": 15,
    "search_context_size": "medium",
    "max_characters": 2048,
    "allowed_domains": ["arxiv.org", "nature.com"],
    "include_highlights": true,
    "include_text": false
  }
}
```

| パラメーター | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `engine` | string | `exa` | `auto`、`native`、`exa`、`parallel`、`firecrawl`、`perplexity`、`tinyfish` のいずれか。[エンジンの選択](#choose-an-engine)を参照してください。 |
| `max_results` | integer | `5` | 検索 1 回あたりの結果数。上限は `25` です。 |
| `max_total_results` | integer | `25` | リクエスト内のすべての検索を合わせた結果数。上限は `100` です。`max_results` を下回ることはありません。 |
| `max_uses` | integer | `10` | 1 リクエストあたりの検索回数。上限は `100` です。 |
| `search_context_size` | string | `medium` | `low`、`medium`、`high` のいずれか。ハイライトのサイズを調整するエンジンで使われます。 |
| `max_characters` | integer | エンジンの既定値 | 本文を含める場合の、結果 1 件あたりの文字数。 |
| `allowed_domains` | string[] | なし | これらのドメインのみを検索します。別名: `include_domains`。 |
| `excluded_domains` | string[] | なし | これらのドメインを除外します。別名: `exclude_domains`。 |
| `include_highlights` | boolean | `true` | エンジンのハイライトまたはスニペットを含めます。 |
| `include_text` | boolean | `false` | エンジンが対応している場合、より詳しいページ本文を含めます。 |
| `user_location` | object | なし | `engine` が `native` のとき、プロバイダー自身の検索に渡す位置情報のヒント。 |

## モデルが送信する内容

各呼び出しには `query` が含まれます。モデルは `max_results`、`engine`、`search_context_size`、ドメインリスト、`include_text`、`include_highlights`、`max_characters`、および次のローカライズ用ヒントも送信できます。

| 引数 | 説明 |
| --- | --- |
| `user_location` | おおよその位置。Perplexity は地域検索に `user_location.country` を使い、TinyFish は国と言語を使います。 |
| `language` | `en` などの結果の言語コード。ローカライズに対応したエンジンで使われます。 |
| `page` | 結果ページ `0` から `10`。TinyFish 用です。 |

モデルが送信した値は、その呼び出しに限りツールの既定値を上書きします。`max_results` は引き続き `max_total_results` の残りで制限され、それを使い切ると以降の呼び出しは `max_total_results_reached` を返します。

<span id="choose-an-engine"></span>
## エンジンの選択

| エンジン | 実行される処理 |
| --- | --- |
| `exa` | 管理対象の Exa 検索。既定値です。 |
| `auto` | 管理対象の既定エンジン。現在は Exa です。 |
| `parallel` | 管理対象の Parallel 検索。 |
| `firecrawl` | 管理対象の Firecrawl 検索。 |
| `perplexity` | Perplexity Search API。ランク付けされた結果、`search_context_size`、`user_location.country` による地域検索に対応します。 |
| `tinyfish` | TinyFish Search。ローカライズされ、ページ分割されたランク付きの結果を返します。返すのはスニペットで、ページ全文は返しません。モデルにさらに情報が必要な場合は [`phaseo:web_fetch`](./web-fetch) を使ってください。 |
| `native` | OpenAI の `web_search_preview` や Anthropic の `web_search_20250305` など、プロバイダー自身の Web 検索ツール。 |

管理エンジンが有効になっていない場合、呼び出しはモデルに `search_not_configured` を返します。

`/v1/chat/completions` または `/v1/responses` で `engine: "native"` を指定すると、リクエストは Web 検索を自前で実行するプロバイダーにのみ送られます。そのモデルを提供するプロバイダーがない場合、Phaseo は代わりに既定エンジンを実行し、管理検索として課金します。`native` はツール定義でのみ指定してください。プロバイダーのツールはリクエスト送信前に選ぶ必要があるため、モデルが呼び出しで `native` を指定すると、その呼び出しは `unsupported_search_engine` を返します。

## ドメインで絞り込む

回答を決まった情報源から得る必要がある場合は `allowed_domains` を、それ以外は制限のない検索から特定のサイトだけを外したい場合は `excluded_domains` を使います。

```json
{
  "type": "phaseo:web_search",
  "parameters": { "allowed_domains": ["phaseo.app", "github.com"] }
}
```

リストの扱いはエンジンによって異なります。

- **Perplexity** はどちらか一方のリストのみを受け付け、両方は指定できません。ドメインは最大 20 件です。除外ドメインは Perplexity の拒否リスト形式で送られます。
- **Firecrawl** はどちらか一方のリストのみを受け付け、両方は指定できません。
- **TinyFish** は両方を受け付け、クエリ内の `site:` と `-site:` 演算子に変換します。

## ツールが返す内容

エンジン、クエリ、`results` 配列を含む JSON の結果です。各結果には `title`、`url`、`snippet` または `highlights` があり、ページ本文を要求してエンジンがそれを提供する場合は `text` も含まれます。

## 使用量と料金

検索ごとに `usage.server_tool_use` に加算されます。

```json
{
  "usage": {
    "server_tool_use": {
      "web_search_requests": 1,
      "web_search_results": 5,
      "web_search_extra_results": 0
    }
  }
}
```

管理検索は `server_tool_web_search_requests` と `server_tool_web_search_extra_results` で課金されます。ネイティブ検索は、モデルの料金カードに定義がある場合 `native_web_search_requests` で課金されます。TinyFish Search は公開プランでは無料のため、Phaseo は `engine: "tinyfish"` に検索料金を加算しません。ただし、リクエストの通常のトークン料金は適用されます。
