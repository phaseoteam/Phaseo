`phaseo:advisor` を追加すると、メインのモデルは回答する前に、2 つ目のモデルにレビュー、計画、妥当性の確認、専門的な意見を求められます。メインのモデルは他のツールと同じように Advisor を呼び出し、Phaseo が Advisor のモデルを実行して、その助言をツールの結果として返します。

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Design a rate limiter for a distributed API gateway." }
    ],
    "tools": [
      {
        "type": "phaseo:advisor",
        "parameters": {
          "model": "anthropic/claude-opus-5",
          "max_uses": 1,
          "max_completion_tokens": 1400
        }
      }
    ]
  }'
```

Advisor は、サポートされている任意のテキストモデルで動作します。Phaseo が自分で実行し、Anthropic のネイティブなツールの形式で送信した場合にのみ、Anthropic のネイティブな Advisor ツールに変換されます。

## パラメーター

```json
{
  "type": "phaseo:advisor",
  "parameters": {
    "name": "reviewer",
    "model": "anthropic/claude-opus-5",
    "instructions": "Review plans for correctness, missing edge cases, and implementation risk.",
    "forward_transcript": true,
    "max_uses": 2,
    "max_completion_tokens": 1400,
    "reasoning": { "effort": "high" },
    "temperature": 0.2
  }
}
```

| パラメーター | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `name` | string | なし | 英字、数字、空白、アンダースコア、ダッシュで 1〜64 文字。複数の Advisor を追加する場合に必要です。 |
| `model` | string | 下記を参照 | Advisor のモデル。 |
| `instructions` | string | 組み込みの Advisor の指示 | Advisor への追加の指示。 |
| `forward_transcript` | boolean | `false` | 現在の会話を Advisor に送信します。 |
| `max_uses` | integer | `1` | リクエストあたりのこの Advisor の呼び出し回数。 |
| `max_completion_tokens` | integer | `1400` | Advisor の各返答の出力トークン数。`1024` 未満の値は `1024` に引き上げられます。古いエイリアスとして `max_tokens` も受け付けます。 |
| `reasoning` | object | プロバイダーのデフォルト | 推論の設定。Advisor のモデルが対応している場合に渡されます。 |
| `temperature` | number | プロバイダーのデフォルト | Advisor の呼び出しのサンプリング温度。 |

Advisor のモデルは、`parameters.model` が設定されていればそれを、設定されていなければメインのモデルが呼び出し時に送る `model` を、それもなければリクエスト自体のモデルを使います。

## モデルが送信する内容

通常は `prompt` です。ツールでモデルが固定されていない場合は、呼び出し時にモデルを選ぶこともできます。

```json
{
  "model": "anthropic/claude-opus-5",
  "prompt": "Check this security design for missing controls."
}
```

`forward_transcript: true` の場合、モデルはプロンプトなしで Advisor を呼び出すことができ、Advisor は転送された会話をレビューします。

## 複数の Advisor を追加する

Advisor ごとに `phaseo:advisor` のエントリを 1 つ追加します。名前を付けた各 Advisor は、`phaseo_advisor_security_reviewer` のように、モデルにとって個別のツールになります。

```json
{
  "tools": [
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "security-reviewer",
        "model": "anthropic/claude-opus-5",
        "instructions": "Review for vulnerabilities, abuse cases, and missing mitigations."
      }
    },
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "architect",
        "model": "openai/gpt-5",
        "instructions": "Review system design tradeoffs and operational risks."
      }
    }
  ]
}
```

名前は、前後の空白を除き大文字と小文字を区別しない状態で一意である必要があり、`name` を省略できるのは 1 つのエントリだけです。そうでない場合、リクエストは拒否されます。複数の Advisor があるときに `tool_choice: "phaseo:advisor"` を指定すると、最初の Advisor が強制的に使われます。

## ツールが返す内容

```json
{
  "status": "ok",
  "name": "reviewer",
  "model": "anthropic/claude-opus-5",
  "advice": "Start with a smaller migration slice and define rollback criteria before changing traffic routing."
}
```

呼び出しを実行できない場合、モデルには代わりにエラー結果が返ります: `advisor_invalid_request`（プロンプトまたはモデルがない）、`advisor_max_uses_exceeded`、`advisor_request_failed`。

Advisor はリクエスト間で状態を保持しません。以前のメッセージとツールの結果を再送すると、メインのモデルは以前の助言を参照できますが、Advisor が会話を参照できるのは `forward_transcript` がオンの場合だけです。助言はストリーミングされず、Advisor 自身はツールを呼び出せません。

## 利用量と料金

呼び出しごとに `usage.server_tool_use.advisor_requests` に 1 が加算され、`server_tool_advisor_requests` で課金されることがあります。Advisor のトークンは Advisor モデル自身の料金で、リクエストの請求の別項目として課金され、呼び出し元モデルのトークン数には加算されません。有料の Advisor モデルを使うには、呼び出し元モデルが無料でもクレジットが必要です。
