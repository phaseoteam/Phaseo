現在の日付、曜日、時刻、タイムゾーンが必要なプロンプトでは、`phaseo:datetime`を使います。

ツールを呼び出すタイミングはモデルが判断します。Phaseoは解決済みのタイムゾーンと現在のタイムスタンプをモデルに返し、その後モデルが最終回答を作成します。

## クイックスタート

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "messages": [
      { "role": "user", "content": "What day of the week is it in Tokyo?" }
    ],
    "tools": [
      {
        "type": "phaseo:datetime",
        "parameters": {
          "timezones": ["Asia/Tokyo", "UTC"]
        }
      }
    ]
  }'
```

## 設定

```json
{
  "type": "phaseo:datetime",
  "parameters": {
    "timezones": ["Europe/London", "UTC"]
  }
}
```

| パラメーター | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `timezones` | string[] | `["UTC"]` | ツール呼び出し1回で返すIANAタイムゾーン名（最大5つ）。例：`["Europe/London", "UTC"]`。 |

## ツールの結果

ツールの結果には、要求したタイムゾーンごとに1つのエントリが含まれます。

```json
{
  "timezones": [
    {
      "timezone": "Europe/London",
      "datetime": "2026-07-03T10:00:00.123+01:00"
    },
    {
      "timezone": "UTC",
      "datetime": "2026-07-03T09:00:00.123+00:00"
    }
  ]
}
```

## 使用量

Datetimeの呼び出しでは次の値が加算されます。

```json
{
  "usage": {
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```
