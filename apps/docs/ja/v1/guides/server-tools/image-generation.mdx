title: "画像生成"
description: "Phaseo のサーバーツールを通じて、モデルが画像を作成できるようにします。"
---

`phaseo:image_generation` を追加すると、モデルは回答しながら画像を作成できます。モデルが画像のプロンプトを書き、Phaseo が画像モデルを呼び出して、画像をモデルのループに返します。

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Design a wide product concept image for a compact desktop synthesizer.",
    "tools": [
      {
        "type": "phaseo:image_generation",
        "parameters": {
          "model": "openai/gpt-image-2",
          "quality": "high",
          "aspect_ratio": "16:9",
          "output_format": "png"
        }
      }
    ]
  }'
```

## パラメーター

すべてのパラメーターは任意です。

| パラメーター | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `model` | string | `openai/gpt-image-2` | 画像モデル。ここで設定すると、メインのモデルが求めるモデルよりも優先されます。 |
| `quality` | string | プロバイダーのデフォルト | `low`、`medium`、`high` などの品質のヒント。 |
| `size` | string | プロバイダーのデフォルト | 画像サイズのヒント。 |
| `aspect_ratio` | string | プロバイダーのデフォルト | `1:1`、`16:9`、`9:16` などのアスペクト比。 |
| `background` | string | プロバイダーのデフォルト | 背景モードのヒント。 |
| `output_format` | string | プロバイダーのデフォルト | `png`、`jpeg`、または `webp`。 |
| `output_compression` | integer | プロバイダーのデフォルト | 圧縮のヒント。`0`〜`100` の範囲に収められます。 |
| `moderation` | string | プロバイダーのデフォルト | プロバイダーのモデレーションのヒント。 |

## モデルが送信する内容

`prompt`（または同じ扱いの `description`）です。ツールでモデルが設定されていない場合にのみ使われる `model` や、上記のその他のパラメーターも送信でき、その呼び出しではツールの値が置き換えられます。

## ツールが返す内容

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "imageUrl": "https://...",
  "mime_type": "image/png"
}
```

プロバイダーによっては、`imageUrl` の代わりに base64 の画像データを含む `b64_json` を返します。呼び出しにプロンプトがない場合、モデルには `image_generation_invalid_request` が返り、画像モデルが失敗した場合は `image_generation_failed` が返ります。

## 利用量と料金

画像ごとに `usage.server_tool_use.image_generation_requests` に 1 が加算され、`server_tool_image_generation_requests` で課金されることがあります。画像モデルは自身の料金で、リクエストの請求の別項目として課金されます。有料の画像モデルを使うには、呼び出し元モデルが無料でもクレジットが必要です。
