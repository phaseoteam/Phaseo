description: "メインのモデルが、特定の作業をワーカーモデルに委任できるようにします。"
---

`phaseo:subagent` を追加すると、メインのモデルは同じリクエスト内で、独立したタスクをワーカーモデル（多くの場合はより小さい、または高速なモデル）に渡せます。メインのモデルがタスクを記述し、Phaseo がワーカーを実行してその結果を返し、メインのモデルが回答を完成させます。

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5",
    "messages": [
      { "role": "user", "content": "Compare these release notes and summarize the breaking changes." }
    ],
    "tools": [
      {
        "type": "phaseo:subagent",
        "parameters": {
          "model": "openai/gpt-6-astra",
          "instructions": "Return concise findings for the main model. Do not address the end user directly.",
          "max_uses": 3,
          "max_completion_tokens": 1200
        }
      }
    ]
  }'
```

## パラメーター

| パラメーター | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `model` | string | リクエストのモデル | ワーカーモデル。 |
| `instructions` | string | 組み込みのワーカーの指示 | ワーカーへの追加の指示。 |
| `max_uses` | integer | `1` | リクエストあたりの Subagent の呼び出し回数。 |
| `max_completion_tokens` | integer | `1400` | ワーカーの各返答の出力トークン数。`1024` 未満の値は `1024` に引き上げられます。古いエイリアスとして `max_tokens` も受け付けます。 |
| `reasoning` | object | プロバイダーのデフォルト | 推論の設定。ワーカーモデルが対応している場合に渡されます。 |
| `temperature` | number | プロバイダーのデフォルト | ワーカーの呼び出しのサンプリング温度。 |

ワーカーが会話を受け取ることはありません。必要な情報はすべてタスクに含めてください。

## モデルが送信する内容

タスク全体、コンテキスト、期待する出力を含む `task_description` と、任意の短い `task_name` です。

```json
{
  "task_description": "Extract the three highest-risk migration steps from the supplied plan."
}
```

`task_description` の代わりに `task`、`prompt`、`input` も受け付けます。

## ツールが返す内容

```json
{
  "status": "ok",
  "model": "openai/gpt-6-astra",
  "outcome": "The highest-risk steps are schema migration, traffic cutover, and rollback verification."
}
```

呼び出しを実行できない場合、モデルには `subagent_invalid_request`（タスクがない）、`subagent_max_uses_exceeded`、`subagent_request_failed` のいずれかが返ります。

## 利用量と料金

呼び出しごとに `usage.server_tool_use.subagent_requests` に 1 が加算され、`server_tool_subagent_requests` で課金されることがあります。ワーカーのトークンはリクエストの利用量に加算され、ワーカーモデルの料金で計算されます。作業を委任するのではなくレビューを受けたい場合は、[Advisor](./advisor) を使います。
