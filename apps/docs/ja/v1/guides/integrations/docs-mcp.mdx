`https://phaseo.app/docs/mcp` を MCP サーバーとしてコーディングエージェントに追加すると、エージェントは学習データではなく最新のドキュメントをもとに Phaseo に関する質問に答えます。サーバーは読み取り専用です。エージェントはドキュメントの検索、ページ全体の読み取り、ホストされている [skill.md](https://phaseo.app/docs/skill.md) の機能概要の読み取りができます。

## Codex

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
codex mcp list
```

## Claude Code

現在のプロジェクトにサーバーを追加するか、`--scope user` を付けてすべてのプロジェクトで使えるようにします。

```bash
claude mcp add --transport http phaseo-docs https://phaseo.app/docs/mcp
claude mcp add --transport http --scope user phaseo-docs https://phaseo.app/docs/mcp
claude mcp list
```

## Cursor

任意のドキュメントページのコンテキストメニューからインストールするか、Cursor の MCP 設定に追加します。

```json
{
  "mcpServers": {
    "phaseoDocs": {
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## VS Code

任意のドキュメントページのコンテキストメニューからインストールするか、VS Code の MCP 設定に追加します。

```json
{
  "servers": {
    "phaseoDocs": {
      "type": "http",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## OpenCode

`opencode.json` に追加します。

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "phaseoDocs": {
      "type": "remote",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## 動作を確認する

ドキュメントでしか答えられない質問をエージェントに尋ね、Phaseo のドキュメントサーバーを呼び出すことを確認します。

- `Look up the Responses request format in the Phaseo docs and give me a minimal example.`
- `Use the Phaseo docs MCP server to check how provider.sort works before you change this request.`
- `Find the guardrails docs in Phaseo and summarize the parts that affect provider routing.`

エージェントはこのサーバーを使って、リクエストの形式、モデルやプロバイダーが対応するエンドポイント、ルーティング、プリセット、ガードレール、非同期ジョブの動作を確認します。ドキュメントサーバーは Phaseo をモデルゲートウェイにするものではありません。その方法については[コーディングエージェント](./coding-assistants.mdx)を参照してください。
