Phaseo のキー、`baseURL: "https://api.phaseo.app/v1"`、使用する Phaseo のモデル ID で TanStack AI の `openaiCompatible` アダプターを作成します。React、Solid、Preact、Vue、Svelte、またはサーバーサイドの TypeScript で、型安全なチャットに使えます。

## インストール

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## アダプターを Phaseo に向ける

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-6-astra", "anthropic/claude-sonnet-5.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-6-astra"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

使う予定のすべての Phaseo モデル ID を `models` で宣言します。ID は[モデル](../../api-reference/endpoint/models.mdx)で確認してください。

## 既知の制限

- アダプターは Chat Completions を使います。Responses 専用の機能を使うには、Phaseo を直接呼び出すか [OpenAI SDK](./openai-sdk.mdx) を使います。
- モデルが[ツール](../tool-calling.mdx)や画像に対応していない場合は、TanStack AI で対応機能を絞って宣言し、未対応の呼び出しを TypeScript で検出できるようにします。
