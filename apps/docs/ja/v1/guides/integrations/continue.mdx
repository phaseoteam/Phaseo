`phaseo continue` を実行して Phaseo を指す Continue の設定を書き込むか、同じモデルエントリとシークレットを既存の設定に追加します。IDE 拡張機能と `cn` CLI は同じ設定を共有します。

## Phaseo CLI で設定する

```bash
phaseo login
phaseo continue --model anthropic/claude-sonnet-5.5
```

`~/.continue/config.yaml` と `~/.continue/.env` が存在しない場合、セットアップは `Phaseo CLI: Continue API Key`（有効期限 90 日、月額 $100 の利用上限）を作成し、両方のファイルを書き込みます。`--model` を指定しない場合は `anthropic/claude-sonnet-4.6` を使います。

```yaml ~/.continue/config.yaml
# Managed by Phaseo CLI
name: Phaseo
version: 1.0.0
schema: v1
models:
  - name: "anthropic/claude-sonnet-5.5 via Phaseo"
    provider: openai
    model: "anthropic/claude-sonnet-5.5"
    apiBase: https://api.phaseo.app/v1
    apiKey: ${{ secrets.PHASEO_API_KEY }}
    useResponsesApi: false
    roles: [chat, edit, apply]
```

キーは `PHASEO_API_KEY` として `~/.continue/.env` に保存されます。`useResponsesApi: false` により、Continue は Phaseo の Chat Completions エンドポイントを使い続けます。

<Warning>
Continue のグローバルな `.env` は平文です。絶対にコミットしないでください。IDE 拡張機能はシェルの環境変数を引き継がないため、CLI は Continue の[ローカルシークレット](https://docs.continue.dev/faqs#managing-local-secrets-and-environment-variables)ファイルを使います。
</Warning>

## Continue を手動で設定する

どちらかのファイルに独自の設定がすでにある場合、セットアップはファイルを変更せずに停止します。上記のモデルエントリを `config.yaml` に追加し、`phaseo integrations credential continue` の出力または任意の Phaseo API キーを使って、`.env` に `PHASEO_API_KEY=<key>` を追加します。その他の項目については、Continue の [OpenAI プロバイダー](https://docs.continue.dev/customize/model-providers/top-level/openai)のドキュメントを参照してください。

## 動作を確認する

VS Code または JetBrains でウィンドウを再読み込みし、Continue を開いて **Phaseo** を選択し、`PHASEO_CONTINUE_OK` と返答するよう依頼します。CLI では `cn` を実行し（別の設定が有効な場合は `/config` を使います）、同じプロンプトを送信します。**設定 → 利用状況 → ログ**にリクエストが表示されることを確認します。

## Phaseo を削除する

```bash
phaseo integrations remove continue
```

これによりキーが失効し、両方のファイルが Phaseo CLI のマーカーで始まっている場合にのみ削除されます。自分でマージしたエントリはそのまま残ります。

## よくある問題を解決する

### Phaseo が表示されない

IDE を再読み込みし、`config.yaml` にトップレベルの `name`、`version`、`schema` の項目があることを確認します。

### Continue がシークレットの不足を報告する

`~/.continue/.env` に `phaseo integrations credential continue` で取得したキーがあることを確認し、IDE を再起動します。

### Continue が Responses API を呼び出す

Phaseo のモデルエントリで `useResponsesApi: false` を維持します。
