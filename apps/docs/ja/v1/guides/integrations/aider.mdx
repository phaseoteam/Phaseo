`phaseo aider` を実行して Phaseo を指す Aider の設定を書き込むか、既存の `.aider.conf.yml` に 3 行を追加します。

## Phaseo CLI で設定する

```bash
phaseo login
phaseo aider --model anthropic/claude-sonnet-5.5
```

`~/.aider.conf.yml` が存在しない場合、セットアップは `Phaseo CLI: Aider API Key`（有効期限 90 日、月の支出上限 $100）を作成し、次のファイルを書き込みます。`--model` を指定しない場合は `anthropic/claude-sonnet-4.6` を使います。

```yaml ~/.aider.conf.yml
# Managed by Phaseo CLI
model: openai/anthropic/claude-sonnet-5.5
openai-api-base: https://api.phaseo.app/v1
openai-api-key: "<dedicated Phaseo key>"
```

Aider で OpenAI 互換アダプター経由でカスタムモデルを送るには、`openai/` プレフィックスが必要です。Phaseo に送られるモデルは `anthropic/claude-sonnet-5.5` のままです。

<Warning>
`.aider.conf.yml` は Aider がドキュメントで示しているキーの保存場所の 1 つなので、キーは平文で保存されます。このファイルは自分のユーザーアカウントだけが読めるようにし、決してコミットしないでください。
</Warning>

## Aider を手動で設定する

すでに Aider の設定がある場合、CLI は何も変更せずに停止します。上の 3 つの設定を、Aider に読み込ませたい設定ファイルにコピーしてください。`openai-api-key` には `phaseo integrations credential aider` の出力か、任意の Phaseo API キーを使います。Aider はホームディレクトリ、リポジトリのルート、カレントディレクトリの順に `.aider.conf.yml` を読み込み、後に読み込んだファイルが優先されます。Aider の [YAML 設定](https://aider.chat/docs/config/aider_conf.html)と [OpenAI 互換 API](https://aider.chat/docs/llms/openai-compat.html) のドキュメントを参照してください。

## 動作を確認する

リポジトリを開いて Aider を起動します。

```bash
aider
```

起動時の出力に `openai/anthropic/claude-sonnet-5.5` が表示されることを確認し、`PHASEO_AIDER_OK` と返答するよう頼んで、リクエストが **設定 → 使用量 → ログ** に表示されることを確認します。

不明なモデルの警告が出ても、リクエストは止まりません。トークン上限や費用の見積もりを正確にしたい場合にだけ、Aider のモデルメタデータを追加してください。

## Phaseo を削除する

```bash
phaseo integrations remove aider
```

これによりキーが取り消され、`~/.aider.conf.yml` がまだ Phaseo CLI のマーカーで始まっている場合にだけ、そのファイルが削除されます。設定を自分のファイルに統合した場合は、3 行を自分で削除してください。

## よくある問題を解決する

### Aider が別のエンドポイントやモデルを使う

リポジトリのルートやカレントディレクトリにある `.aider.conf.yml` は、ホームディレクトリのものより優先されます。環境変数とコマンドラインのオプションは、そのすべてより優先されます。

### 認証に失敗する

`openai-api-key` を `phaseo integrations credential aider` の出力と比べ、`openai-api-base` は正確に `https://api.phaseo.app/v1` にしてください。

### モデルを解決できない

Aider の `openai/` プレフィックスを残してください。Phaseo のモデル `openai/gpt-6-astra` は、Aider では `openai/openai/gpt-6-astra` になります。
