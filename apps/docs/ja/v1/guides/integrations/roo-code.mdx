`phaseo roo-code` を実行してキーを作成し、Roo Code に **OpenAI Compatible** のプロファイルを追加します。Roo Code はキーを VS Code のシークレットストレージに保存するため、最後の手順は Roo Code の画面で行います。

## Phaseo CLI で設定する

```bash
phaseo login
phaseo roo-code --model anthropic/claude-sonnet-5.5
```

CLI は、有効期限が 90 日で月額 $100 の利用上限が付いた `Phaseo CLI: Roo Code API Key` を作成し、次の手順で使う値を表示します。

## Roo Code を設定する

1. VS Code で Roo Code を開き、**Settings → Providers** を開きます。
2. プロバイダーの設定プロファイルを作成し、**OpenAI Compatible** を選びます。
3. 次の値を入力します。

| Roo Code の項目 | 値 |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | `phaseo integrations credential roo-code` の出力、または任意の Phaseo API キー |
| Model | `anthropic/claude-sonnet-5.5`、またはセットアップ時に表示されたモデル |

4. プロファイルを保存し、有効にします。

項目のラベルはリリースによって多少異なります。表示が違う場合は、Roo Code の[モデルプロバイダー](https://docs.roocode.com/providers/)のドキュメントを参照してください。

## 動作を確認する

Roo Code に `PHASEO_ROO_OK` と返答するよう依頼し、**設定 → 利用状況 → ログ**にリクエストが表示されることを確認します。

## Phaseo を削除する

Phaseo のプロファイルを削除するか別のプロファイルに切り替えてから、次を実行します。

```bash
phaseo integrations remove roo-code
```

これによりキーが失効します。CLI は VS Code の拡張機能ストレージを消去できません。

## よくある問題を解決する

### 認証に失敗する

`phaseo integrations credential roo-code` でキーをもう一度コピーし、Base URL が `/v1` で終わっていることを確認します。

### Roo Code がモデルを見つけられない

プロバイダーのプレフィックスを含めて、Phaseo のモデル ID を正確に入力します。

### チャットは動くがツールが失敗する

ツール呼び出しに対応したモデルに切り替えます。
