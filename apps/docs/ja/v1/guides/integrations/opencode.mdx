`phaseo opencode` を実行して、互換性のあるすべての Phaseo モデルを含む Phaseo プロバイダーを OpenCode に追加するか、`opencode.json` に `phaseo` プロバイダーを自分で追加します。

## Phaseo CLI で設定する

```bash
phaseo login
phaseo opencode --model openai/gpt-5.6-terra
```

OpenCode がインストールされていない場合、CLI は公式のインストールコマンドを表示し、実行する前に確認します。その後、セットアップは次の処理を行います。

- Chat Completions で動作する Phaseo の有効なテキストモデルをすべて含む、グローバルな `phaseo` プロバイダーを追加します。グローバルな `opencode.jsonc` があればそれを、なければ `~/.config/opencode/opencode.json` を更新し、その他の設定はそのまま残します。
- 有効期限が 90 日で月額 $100 の利用上限が付いた `Phaseo CLI: OpenCode API Key` を作成し、OpenCode の資格情報ストアに保存します。CLI は独自のコピーを OS の資格情報ストアに保持します。期限切れのキーを置き換えるには、`phaseo opencode` を再実行します。

選択したモデルだけを追加するには `--catalog default` を、変更内容をプレビューするには `--dry-run` を使います。

## OpenCode を手動で設定する

プロジェクトの `opencode.json`、またはグローバルな OpenCode の設定にプロバイダーを追加します。

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-6-astra",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-6-astra": { "name": "GPT-6 Astra" },
        "openai/gpt-5.4-mini": { "name": "GPT-5.4 Mini" },
        "anthropic/claude-sonnet-5.5": { "name": "Claude Sonnet 5.5" }
      }
    }
  }
}
```

`PHASEO_API_KEY` をエクスポートし、`models` のエントリを追加・削除して、OpenCode に表示する Phaseo のモデルを選びます。

## 動作を確認する

OpenCode を再起動し、`/models` から Phaseo のモデルを選んで、ファイルを編集する作業を始める前に短いプロンプトを送信します。**設定 → 利用状況 → ログ**にリクエストが表示されることを確認します。

## Phaseo を削除する

```bash
phaseo integrations remove opencode
```

これにより、Phaseo プロバイダーと保存された資格情報だけが削除され、キーが失効します。

## よくある問題を解決する

| 問題 | 対処 |
| --- | --- |
| モデルが拒否される | [Models エンドポイント](../../api-reference/endpoint/models.mdx)で正確な ID を確認します。 |
| 認証に失敗する | `phaseo opencode` を再実行し、`opencode auth list` を確認します。 |

セッション中に OpenCode が Phaseo のドキュメントを読めるようにするには、[Docs MCP](./docs-mcp.mdx) サーバーを追加します。
