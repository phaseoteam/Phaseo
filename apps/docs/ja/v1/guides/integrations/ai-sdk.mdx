`@phaseo/ai-sdk-provider` をインストールし、AI SDK のどの呼び出しでもモデルとして `phaseo("<model id>")` を渡します。プロバイダーは環境変数から `PHASEO_API_KEY` を読み取ります。

## インストール

```bash
npm install @phaseo/ai-sdk-provider
```

バージョンを指定しないパッケージは npm の `latest` タグ（AI SDK 7 の系列）に従い、`ai@^7` をピア依存関係として宣言します。これは npm が自動でインストールします。古い AI SDK を使う場合は、対応するタグをインストールしてください。

| AI SDK | プロバイダーの契約 | インストール |
| --- | --- | --- |
| 7（現行） | `ProviderV4`（プロバイダー 2.x） | `npm install @phaseo/ai-sdk-provider` |
| 6 | `ProviderV3`（プロバイダー 1.x、メンテナンス中） | `npm install @phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `ProviderV2` | `npm install @phaseo/ai-sdk-provider@ai-sdk-v5` |

パッケージマネージャーがピア依存関係をインストールしない場合は、対応する `ai` のメジャーバージョン（`ai@^7`、`ai@^6`、`ai@^5`）もインストールしてください。

AI SDK 8 が安定版になると、Phaseo は npm でプロバイダー 1.x を非推奨にします。既存のリリースは削除されず、サポート終了は別途お知らせします。

## テキストを生成する

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Summarize this in one sentence.",
});

console.log(result.text);
```

同じコードが 3 つの系列すべてで動きます。モデル ID は [Models エンドポイント](../../api-reference/endpoint/models.mdx)のものを使ってください。各機能は、引き続きモデルと上流のプロバイダーに依存します。

## 系列ごとの対応機能

| 機能 | AI SDK 7（プロバイダー 2.x） | AI SDK 5 |
| --- | --- | --- |
| テキスト生成とストリーミング | 対応 | 対応 |
| 関数ツールとツール結果のやり取り | 対応（ストリーミングされるツール入力を含む） | 対応 |
| JSON と JSON Schema の構造化出力 | 対応 | 対応 |
| 埋め込みと画像生成 | 対応 | 対応 |
| 文字起こしと音声合成 | 対応 | 対応 |
| リランキング | 対応 | 非対応 |
| プロバイダーに依存しない推論の設定と出力 | 対応 | |
| テキストと画像のファイル入力（V7 のタグ付きファイルデータ） | 対応 | |
| URL の引用ソース | 対応 | |
| プロバイダーのメタデータ、使用量、リクエストヘッダー、中止シグナル、生のストリームチャンク | 対応 | |

AI SDK 7 の列は、プロバイダー 2.x が AI SDK 7 ネイティブの v4 契約に対して実装し、テストしている内容です。リランキングは AI SDK 6 の系列でも使えます。

## ドキュメントをリランキングする

AI SDK の `rerank()` ヘルパーを `phaseo.rerankingModel(modelId)` と一緒に使います。

```ts
import { rerank } from "ai";
import { phaseo } from "@phaseo/ai-sdk-provider";

const result = await rerank({
	model: phaseo.rerankingModel("voyage/rerank-2"),
	query: "Which document is about TypeScript?",
	documents: [
		"TypeScript adds static types to JavaScript.",
		"Rust is a systems programming language.",
	],
	topN: 1,
});
```

## 既知の制限

- まだ存在しない Phaseo の API を必要とする `ProviderV4` の機能は、プロバイダーとして対応を示していません。管理されたファイルのアップロードと参照、スキル、プロバイダーが実行するツールの定義、結果、承認レスポンスです。
- アプリが実行する関数ツールは、引き続き AI SDK の通常の実行と承認の流れを使います。
- 対応していないプロバイダー固有またはカスタムのプロンプトパーツは、黙って捨てられるのではなく、明確なエラーで失敗します。
