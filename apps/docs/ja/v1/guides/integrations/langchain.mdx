LangChain の chain、agent、LangGraph ワークフローから Phaseo 経由でモデルを呼び出すには、このガイドを使ってください。

## インストール

```bash
pip install -U langchain langchain-openai
```

## ChatOpenAI を設定する

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-5-nano",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

## LangGraph で使う

同じ `llm` をグラフのノードまたはエージェントビルダーに渡します。

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## 注意点

- LangChain の OpenAI 互換経路では Chat Completions を使います。`/v1/chat/completions` で利用できる Phaseo 機能を使用してください。
- `phaseo:apply_patch` など Responses 専用のサーバーツールが必要な場合は、Phaseo を直接呼び出すか OpenAI SDK ガイドを参照してください。
- トレースを使う場合は、この設定を[可観測性](./observability.mdx)と組み合わせてください。
