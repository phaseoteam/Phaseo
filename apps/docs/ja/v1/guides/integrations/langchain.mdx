Phaseo のキーと `base_url="https://api.phaseo.app/v1"` で `ChatOpenAI` モデルを作成すると、LangChain のチェーン、エージェント、LangGraph のワークフローが Phaseo 経由でモデルを呼び出します。

## インストール

```bash
pip install -U langchain langchain-openai
```

## ChatOpenAI を Phaseo に向ける

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

文が 1 つ出力されれば、設定は正しく動作しています。

## LangGraph で使う

同じ `llm` をグラフのノードやエージェントビルダーに渡します。

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## 既知の制限

- この方法は [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) を使うため、[ツール呼び出し](../tool-calling.mdx)や[ルーティングとフォールバック](../routing-and-fallbacks.mdx)など、`/v1/chat/completions` で使える Phaseo の機能だけが動作します。
- `phaseo:apply_patch` など Responses 専用のサーバーツールを使うには、Phaseo を直接呼び出すか [OpenAI SDK](./openai-sdk.mdx) を使います。
- LangSmith によるトレースについては、[可観測性](./observability.mdx)を参照してください。
