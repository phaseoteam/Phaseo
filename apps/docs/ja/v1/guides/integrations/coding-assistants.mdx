`phaseo login` を実行してから `phaseo <agent>` を実行すると、専用の API キーを使ってコーディングエージェントを Phaseo に向けられます。CLI を使わない場合は、エージェントの設定に[手動のプロバイダー値](#enter-the-provider-values-yourself)を入力します。

```bash
phaseo login
phaseo codex
```

## エージェント用のコマンドを確認する

CLI は各エージェントを次の 3 つのいずれかの方法で設定します。

- **設定済み**: CLI がエージェントの設定ファイルを書き込みます。エージェントを起動して Phaseo のモデルを選びます。
- **キーのみ**: エージェントがキーを独自のアプリストレージに保存するため、CLI はキーを作成し、入力する項目を表示します。
- **セッション**: CLI は終了時に削除される一時的な設定でエージェントを起動します。通常の設定には影響しません。

| エージェント | コマンド | 設定方法 | ガイド |
| --- | --- | --- | --- |
| Claude Code | `phaseo claude-code` | 設定済み | [Claude Code](./claude-code.mdx) |
| Codex | `phaseo codex` | 設定済み | [Codex](./codex.mdx) |
| OpenCode | `phaseo opencode` | 設定済み | [OpenCode](./opencode.mdx) |
| fx | `phaseo fx` | 設定済み | [fx](./fx.mdx) |
| DeepSeek Harness | `phaseo deepseek-harness` | 設定済み | [DeepSeek Harness](./deepseek-harness.mdx) |
| Pi | `phaseo pi` | 設定済み | [Pi](./pi.mdx) |
| Prime Agent | `phaseo prime-agent` | 設定済み | [Prime Agent](./prime-agent.mdx) |
| OpenClaw | `phaseo openclaw` | 設定済み | [OpenClaw](./openclaw.mdx) |
| Hermes Agent | `phaseo hermes` | 設定済み | [Hermes Agent](./hermes.mdx) |
| Aider | `phaseo aider` | 設定済み | [Aider](./aider.mdx) |
| Continue | `phaseo continue` | 設定済み | [Continue](./continue.mdx) |
| Zed | `phaseo zed` | 設定済み、その後 Zed にキーを貼り付け | [Zed](./zed.mdx) |
| Cursor | `phaseo cursor` | キーのみ | [Cursor](./cursor.mdx) |
| Roo Code | `phaseo roo-code` | キーのみ | [Roo Code](./roo-code.mdx) |
| Kilo Code | `phaseo kilo-code`（拡張機能）または `phaseo kilo`（CLI） | キーのみ、またはセッション | [Kilo Code](./kilo-code.mdx) |
| Cline | `phaseo setup cline`（拡張機能）または `phaseo cline`（CLI） | キーのみ、またはセッション | [Cline](./cline.mdx) |
| oh-my-pi | `phaseo omp` | セッション | [oh-my-pi](./oh-my-pi.mdx) |

## CLI が作成するもの

各エージェントには、エージェント名の付いた専用の API キー（例: `Phaseo CLI: Codex API Key`）が作成されます。キーの有効期限は 90 日で、月額 $100 の利用上限があります。期限切れのキーを置き換えるにはセットアップコマンドを再実行し、上限を引き上げるには `phaseo keys update <id> --limit` を使います。

Claude Code、Codex、OpenCode、fx、DeepSeek Harness、Pi、Prime Agent、OpenClaw、Hermes Agent がインストールされていない場合、CLI は公式のインストールコマンドを表示し、実行する前に確認します。対話型ターミナル以外では、インストールコマンドを表示して停止します。OpenCode、fx、DeepSeek Harness、Pi、Prime Agent、OpenClaw には、Chat Completions で動作する Phaseo の有効なテキストモデルもすべて登録されます。

| フラグまたはコマンド | 効果 |
| --- | --- |
| `--model <id>` | デフォルトのモデルを設定します。Claude Code では使えません。 |
| `--catalog default` | カタログ全体ではなく、選択したモデルだけを追加します。 |
| `--skip-install` | 自分で管理しているエージェントのために、インストールの確認をスキップします。 |
| `--dry-run` | ファイルを変更せずに、変更内容を表示します。 |
| `phaseo integrations credential <agent>` | キーを貼り付けて使うエージェントのために、そのエージェントのキーを表示します。 |
| `phaseo integrations remove <agent>` | Phaseo が書き込んだ設定を削除し、キーを失効させます。その他の設定はそのまま残ります。 |

## プロバイダーの値を手動で入力する

OpenAI 互換プロバイダーを持つエージェントであれば、次の値を使えます。項目名はツールによって異なります。

| 設定 | 値 |
| --- | --- |
| プロバイダーの種類 | OpenAI Compatible |
| Base URL | `https://api.phaseo.app/v1` |
| API キー | Phaseo の API キー |
| モデル | Phaseo のモデル ID（例: `openai/gpt-6-astra`） |

Anthropic Messages API を使うエージェントの場合:

| 設定 | 値 |
| --- | --- |
| Base URL | `https://api.phaseo.app`（クライアントが `/v1/messages` を付加します） |
| 認証トークン | Phaseo の API キー |
| モデル | Phaseo のモデル ID（例: `anthropic/claude-sonnet-5.5`） |

`/` を含むモデル ID を受け付けないエージェントもあります。お使いのエージェントがそうで、エイリアスに対応している場合は、Phaseo のモデル ID に対応するローカルのエイリアスを作成します。

## 専用ガイドがないエージェント

### VS Code

お使いのビルドに OpenAI 互換プロバイダーが含まれている場合、VS Code は Language Models エディターでモデルを追加できます。

1. コマンドパレットを開き、`Chat: Manage Language Models` を実行します。
2. `OpenAI Compatible` または `OAI Compatible` を選びます。
3. Phaseo の API キーを入力し、エンドポイントを `https://api.phaseo.app/v1` に設定します。
4. `openai/gpt-6-astra` などの Phaseo のモデル ID を追加し、チャットのモデル選択で選びます。

お使いのビルドに OpenAI 互換プロバイダーがない場合は、カスタムプロバイダーに対応した拡張機能を使います: [Continue](./continue.mdx)、[Cline](./cline.mdx)、[Roo Code](./roo-code.mdx)、[Kilo Code](./kilo-code.mdx)。

### Claude Desktop

Claude Desktop ではカスタムのモデルプロバイダーを使えません。Phaseo のドキュメントを参照させるには [Docs MCP](./docs-mcp.mdx) を追加し、Phaseo をモデルゲートウェイとして使う必要がある場合は [Claude Code](./claude-code.mdx) を使います。

### Deep Agents CLI とその他の LangChain ツール

[LangChain](./langchain.mdx) にある Base URL とキーを使います。ツールが OpenAI の環境変数を読み込む場合は、次の変数を設定し、モデルの項目に Phaseo のモデル ID を渡します。

```bash
export OPENAI_API_KEY="your_phaseo_api_key"
export OPENAI_BASE_URL="https://api.phaseo.app/v1"
```

## 既知の制限

- サーバーツールは、エージェントが送信する場合にのみ動作します。`phaseo:apply_patch` は [Responses](../../api-reference/endpoint/responses.mdx) でのみ使えます。Responses のイベントや[サーバーツール](../server-tools/index.mdx)を処理できない古いエージェントは、[Chat Completions](../../api-reference/endpoint/chat-completions.mdx) を使うほうが安全です。
- エージェントにファイルを編集させる前に短いチャットリクエストを送信し、エージェント作業にはツール呼び出しに対応したモデルを選びます。
- セッション中にエージェントに Phaseo のドキュメントを読ませたい場合は、[Docs MCP](./docs-mcp.mdx) を追加します。
