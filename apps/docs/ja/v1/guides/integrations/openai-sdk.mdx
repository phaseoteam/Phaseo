API キー、Base URL（`https://api.phaseo.app/v1`）、モデル ID の 3 つを変更して、OpenAI 公式 SDK を Phaseo に向けます。

## インストール

<CodeGroup>

```bash TypeScript
npm install openai
```

```bash Python
pip install openai
```

</CodeGroup>

## クライアントを Phaseo に向ける

<CodeGroup>

```ts TypeScript
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Write one sentence about reliable model routing.",
});

console.log(response.output_text);
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Write one sentence about reliable model routing.",
)

print(response.output_text)
```

</CodeGroup>

文が 1 つ出力されれば、キーと Base URL は正しく動作しています。リクエストは**設定 → 利用状況 → ログ**にも表示されます。

## Chat Completions を使う

Chat Completions を呼び出すコードも、同じクライアントで動作します。

```ts
const completion = await client.chat.completions.create({
	model: "openai/gpt-6-astra",
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## 既知の制限

- `openai/`、`anthropic/`、`google/` などのプロバイダーのプレフィックスが付いた Phaseo のモデル ID を使います。リクエストの完全な形式については、[Responses](../../api-reference/endpoint/responses.mdx) と [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) を参照してください。
- [サーバーツール](../server-tools/index.mdx)は、`phaseo:web_search` などの Phaseo のツール名を使います。
- Anthropic 形式の `/v1/messages` クライアントについては、[Anthropic SDK](./anthropic-sdk.mdx) のガイドを参照してください。
