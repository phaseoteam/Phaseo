---

`phaseo prime-agent` を実行すると、互換性のあるすべての Phaseo モデルを含む Phaseo プロバイダーが Prime Agent に追加されます。Prime Agent は macOS と Linux で動作します。Windows では、WSL 内でインストールしてセットアップを実行してください。

## Phaseo CLI で設定する

```bash
phaseo login
phaseo prime-agent
```

Prime Agent がインストールされていない場合、CLI は公式のインストーラーコマンドを表示し、実行する前に確認します。その後、セットアップは `Phaseo CLI: Prime Agent API Key`（有効期限 90 日、月額 $100 の利用上限）を作成し、`~/.prime/agent/models.json` に `phaseo` プロバイダーを書き込みます。プロバイダーには、Chat Completions で動作する Phaseo の有効なテキストモデルがすべて登録されます。

| フラグ | 効果 |
| --- | --- |
| `--model <id>` | 最初のモデルを設定します。デフォルトは `anthropic/claude-sonnet-4.6` です。 |
| `--catalog default` | 選択したモデルだけを追加します。 |
| `--dry-run` | ファイルを変更せずに、変更内容を表示します。 |

プロバイダーは、Prime Agent のコマンドでキーを取得する形式を使ってリクエスト時にキーを取得するため、平文のキーはファイルに書き込まれません。

```text
!phaseo integrations credential prime-agent
```

## 動作を確認する

```bash
prime-agent
```

`/model` を開いて `phaseo` プロバイダーを選び、短いプロンプトを送信します。**設定 → 利用状況 → ログ**にリクエストが表示されることを確認します。

## Phaseo を削除する

```bash
phaseo integrations remove prime-agent
```

これにより、Phaseo プロバイダーだけが削除され、キーが失効します。
