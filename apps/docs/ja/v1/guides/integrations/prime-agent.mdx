## Phaseo CLIで設定する

本番環境向けのこれらのコマンドにはPhaseoアカウントが必要です。CLIはログインとセットアップ時に専用のGateway資格情報を作成します。

```bash
phaseo login
phaseo prime-agent
```

まずPrime Agentの公式リリースをインストールします。セットアップにより、管理対象の`phaseo`プロバイダーが`~/.prime/agent/models.json`に書き込まれます。このプロバイダーはChat Completions対応の有効なPhaseoテキストモデルをすべて公開し、各リクエスト時にPhaseo CLIから専用APIキーを取得します。

Prime Agentは現在macOSとLinuxに対応しています。Windowsでは、実行ファイルをWSLにインストールしてから、WSL内でセットアップを実行します。

初期カタログ項目を選ぶか、必要に応じて1つのモデルだけを設定します。

```bash
phaseo prime-agent --model anthropic/claude-sonnet-4.6
phaseo prime-agent --catalog default
```

## 起動して確認する

```bash
prime-agent
```

「/model」を開いて`phaseo`プロバイダーを選び、簡単なプロンプトを送ります。生成されたプロバイダーはPrime Agentがサポートするコマンド連携型キー形式を使います。

```text
!phaseo integrations credential prime-agent
```

Phaseoが管理するプロバイダーだけを削除し、専用キーを失効させるには、次を実行します。

```bash
phaseo integrations remove prime-agent
```
