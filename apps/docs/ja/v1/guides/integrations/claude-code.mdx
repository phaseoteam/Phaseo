`phaseo claude-code` を実行して Claude Code のリクエストを Phaseo 経由で送るか、3 つの環境変数を自分で設定します。Claude Code は Anthropic 形式の `/v1/messages` を呼び出し、Phaseo はそれを [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx) として処理するため、プロンプトを変える必要はありません。

## Phaseo CLI で設定する

```bash
phaseo login
phaseo claude-code
claude
```

Claude Code がインストールされていない場合、CLI は公式のインストールコマンドを表示し、実行する前に確認します。その後、セットアップは次のことを行います。

- 90 日後に期限が切れ、月の支出上限が $100 の `Phaseo CLI: Claude Code API Key` を作成し、OS の認証情報ストアに保存します。
- `~/.claude/settings.json` に `ANTHROPIC_BASE_URL` と `apiKeyHelper` を設定します。ヘルパーは CLI からキーを取得し、古いキーの期限が切れると新しいキーを作成するため、Claude Code の設定に平文のキーが書き込まれることはありません。

`settings.json` にすでに別の `ANTHROPIC_BASE_URL` や別の `apiKeyHelper` がある場合、または空でない `ANTHROPIC_API_KEY` や `ANTHROPIC_AUTH_TOKEN` がある場合、セットアップは何も変更せずに停止します。Claude Code では `--model` に対応していません。代わりに `ANTHROPIC_MODEL` を設定してください（下記を参照）。

## Claude Code を手動で設定する

Claude Code を起動するシェルで、次を設定します。

<CodeGroup>

```bash bash
export ANTHROPIC_BASE_URL="https://api.phaseo.app"
export ANTHROPIC_AUTH_TOKEN="your_phaseo_api_key"
export ANTHROPIC_API_KEY=""
```

```powershell PowerShell
$env:ANTHROPIC_BASE_URL = "https://api.phaseo.app"
$env:ANTHROPIC_AUTH_TOKEN = "your_phaseo_api_key"
$env:ANTHROPIC_API_KEY = ""
```

</CodeGroup>

Claude Code は `ANTHROPIC_AUTH_TOKEN` を `Authorization` ヘッダーとして送り、Phaseo はこれを受け付けます。既定のモデルを固定するには、`ANTHROPIC_MODEL` に [Models](../../api-reference/endpoint/models.mdx) の Phaseo モデル ID を設定します。

## 動作を確認する

`claude` を実行して短いプロンプトを送り、リクエストが **設定 → 使用量 → ログ** に表示されることを確認します。

## Phaseo を削除する

```bash
phaseo integrations remove claude-code
```

これにより、Phaseo が `settings.json` に追加したベース URL、キーヘルパー、空の認証情報の変数が削除され、キーが取り消されます。手動で設定した場合は、3 つの環境変数の設定を解除してください。

## 既知の制限

- チームを移行する前に、ストリーミングするツールのループを自分のワークフローでテストしてください。
- セッション中に Claude Code に Phaseo のドキュメントを読ませたい場合は、[Docs MCP](./docs-mcp.mdx) サーバーを追加してください。
