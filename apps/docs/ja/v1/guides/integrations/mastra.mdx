Phaseo のキーと `baseURL: "https://api.phaseo.app/v1"` で AI SDK の OpenAI プロバイダーを作成し、そのモデルを Mastra のエージェントとワークフローに渡します。

## インストール

```bash
npm install @mastra/core @ai-sdk/openai ai
```

## Mastra エージェントを Phaseo に向ける

```ts
import { Agent } from "@mastra/core/agent";
import { createOpenAI } from "@ai-sdk/openai";

const phaseo = createOpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
	compatibility: "compatible",
});

export const agent = new Agent({
	name: "support-agent",
	instructions: "Answer in two short paragraphs.",
	model: phaseo("openai/gpt-6-astra"),
});
```

`/chat/completions` や `/responses` を付けずに、Base URL だけを使います。短いプロンプトでエージェントを一度実行し、**設定 → 利用状況 → ログ**にリクエストが表示されることを確認します。

## 既知の制限

- Mastra エージェントの動作は AI SDK プロバイダーに依存します。本番環境の前に[ツール呼び出し](../tool-calling.mdx)とストリーミングをテストしてください。
- 特定のプロバイダーを優先するには、リクエストまたは[プリセット](../presets.mdx)で Phaseo のルーティング設定を指定します。
