`https://api.phaseo.app/v1` に向けた `OpenAIProvider` で `OpenAIChatModel` を作成すると、PydanticAI のエージェントが Phaseo のモデルで動作します。

## インストール

```bash
pip install "pydantic-ai-slim[openai]"
```

## PydanticAI を Phaseo に向ける

```python
import os
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-6-astra",
    provider=OpenAIProvider(
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)

agent = Agent(model, system_prompt="Answer concisely.")
result = agent.run_sync("Reply with only: ok")
print(result.output)
```

`ok` が出力されれば、設定は正しく動作しています。

## 既知の制限

- この方法は OpenAI 形式の Chat Completions を使います。`phaseo:apply_patch` など Responses 専用の機能を使うには、Phaseo の Responses エンドポイントを直接呼び出します。
- [構造化出力](../structured-outputs.mdx)のスキーマは、モデルのコンテキストウィンドウに収まる大きさにしてください。上限は[モデル](../../api-reference/endpoint/models.mdx)で確認します。
