Phaseo のキーと `api_base="https://api.phaseo.app/v1"` で `OpenAILike` の LLM を作成し、LlamaIndex のデフォルトに設定すると、RAG ワークフローの生成が Phaseo を経由します。

## インストール

```bash
pip install llama-index llama-index-llms-openai-like llama-index-embeddings-openai-like
```

## LlamaIndex を Phaseo に向ける

```python
import os
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    is_chat_model=True,
)

response = llm.complete("Write one sentence about retrieval quality.")
print(response)
```

文が 1 つ出力されれば、設定は正しく動作しています。`OpenAILike` は、サードパーティの OpenAI 互換 API 用の LlamaIndex のクラスです。

## インデックスで使う

```python
from llama_index.core import Settings

Settings.llm = llm
```

その後、通常どおりインデックスを構築またはクエリします。

## 既知の制限

- LlamaIndex のデフォルトは Phaseo を向いていません。生成モデルと埋め込みモデルを明示的に設定してください。
- Phaseo の[埋め込み](../../api-reference/endpoint/embeddings.mdx)を使うには、Phaseo のモデル ID と同じ Base URL で埋め込みモデルを設定します。
