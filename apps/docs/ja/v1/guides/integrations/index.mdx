OpenAI 互換または Anthropic 互換のクライアントを Phaseo の Base URL に向け、Phaseo の API キーを渡せば、`openai/gpt-6-astra` などの Phaseo のモデル ID をそのまま使えます。各ガイドでは、まずツールを設定し、次に動作の確認方法と、動作しない機能を説明します。

| クライアントの形式 | Base URL | キーの入力先 |
| --- | --- | --- |
| OpenAI 互換 | `https://api.phaseo.app/v1` | API キーの項目。`Authorization: Bearer` として送信されます |
| Anthropic 互換（`/v1/messages` を自動で付加） | `https://api.phaseo.app` | 認証トークンの項目。`Authorization: Bearer` として送信されます |

モデル ID は [Models エンドポイント](../../api-reference/endpoint/models.mdx)から取得します。OpenAI 形式の新しいアプリには [Responses](../../api-reference/endpoint/responses.mdx) を使います。古いライブラリは [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) を使うのが最も安全です。`PHASEO_API_KEY` を一度設定してツールが求める変数に割り当て、エージェントのトラフィックを移行する前にストリーミングとツール呼び出しをテストしてください。
