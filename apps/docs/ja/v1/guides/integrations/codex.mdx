`phaseo codex` を実行して Codex に Phaseo のプロファイルを追加するか、`config.toml` に `phaseo` プロバイダーを自分で追加します。同じ設定が Codex CLI、Codex App、Codex IDE 拡張機能で使えます。

## Phaseo CLI で設定する

```bash
phaseo login
phaseo codex --model openai/gpt-5.6-terra
codex --profile phaseo
```

Codex がインストールされていない場合、CLI は公式のインストールコマンドを表示し、実行する前に確認します。その後セットアップはダッシュボードのページを開き、有効期限が 90 日で月額 $100 の利用上限が付いた `Phaseo CLI: Codex API Key` を承認するよう求めます。CLI はキーを OS の資格情報ストアに保存し、プロファイルを `~/.codex/phaseo.config.toml`（または `CODEX_HOME` の下）に書き込みます。Codex はキーを CLI から取得するため、設定ファイルに平文のキーは書き込まれません。キーの期限が切れたら、`phaseo codex` を再実行して新しいキーを承認してください。`--model` を指定しない場合、プロファイルは `openai/gpt-5.6-terra` を使います。

## Codex を手動で設定する

次の内容を `~/.codex/config.toml`、または信頼済みプロジェクトの `.codex/config.toml` に追加します。

```toml
model = "openai/gpt-6-astra"
model_provider = "phaseo"

[model_providers.phaseo]
name = "Phaseo"
base_url = "https://api.phaseo.app/v1"
env_key = "PHASEO_API_KEY"
wire_api = "responses"
```

次に `PHASEO_API_KEY` をエクスポートして Codex を起動します。Codex のカスタムプロバイダーはデフォルトで Responses のワイヤープロトコルを使うため、`wire_api` は省略しても構いません。IDE 拡張機能では、**Codex Settings → Open config.toml** からファイルを開きます。

## 動作を確認する

短いプロンプトを送信し、**設定 → 利用状況 → ログ**にリクエストが表示されることを確認します。Codex は [Responses](../../api-reference/endpoint/responses.mdx) を呼び出すため、モデルがこのエンドポイントに対応している必要があります。

## Phaseo を削除する

```bash
phaseo integrations remove codex
```

これにより、Phaseo が作成した場合は `phaseo.config.toml` が削除され、キーが失効します。手動で設定した場合は、`config.toml` から `phaseo` プロバイダーを削除します。

## よくある問題を解決する

| エラー | 対処 |
| --- | --- |
| `401 Unauthorized` | `phaseo whoami` を実行してから、`phaseo codex` を再実行します。 |
| `model_not_found` | [モデル](../../api-reference/endpoint/models.mdx)から現在の ID を取得し、`model` を更新します。 |
| プロバイダーが失敗する | フェイルオーバーについては[ルーティングとフォールバック](../routing-and-fallbacks.mdx)を参照してください。 |

## Phaseo のスキルとドキュメントを追加する

作業中に Codex が最新の Phaseo ドキュメントを読めるようにするには、[Docs MCP](./docs-mcp.mdx) サーバーを追加します。Codex 用に公開の [Phaseo スキル](https://phaseo.app/docs/.well-known/agent-skills/index.json)をインストールするには、次を実行します。

```bash
npx skills add https://phaseo.app/docs --agent codex --skill '*'
```

同じ CLI のワークフローで、[Cline](./cline.mdx)、[Kilo Code](./kilo-code.mdx)、[oh-my-pi](./oh-my-pi.mdx)、[Muse Code](./muse-code.mdx)、[MiniMax Code](./minimax-code.mdx) を一時的な設定で起動できます。
