LiveKit Agents の OpenAI プラグインの LLM を Phaseo のキーとともに `https://api.phaseo.app/v1` に向けると、音声エージェントが Phaseo のモデル ID とルーティングを使います。プラグインは Phaseo の Chat Completions エンドポイントを呼び出します。

## インストール

<CodeGroup>

```bash Python
uv add "livekit-agents[openai]"
```

```bash Node.js
pnpm add @livekit/agents @livekit/agents-plugin-openai
```

</CodeGroup>

## エージェントの LLM を Phaseo に向ける

<CodeGroup>

```python Python
import os
from livekit.agents import AgentSession
from livekit.plugins import openai

session = AgentSession(
    llm=openai.LLM(
        model="openai/gpt-6-astra",
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)
```

```ts Node.js
import { voice } from "@livekit/agents";
import * as openai from "@livekit/agents-plugin-openai";

const session = new voice.AgentSession({
	llm: new openai.LLM({
		model: "openai/gpt-6-astra",
		apiKey: process.env.PHASEO_API_KEY,
		baseURL: "https://api.phaseo.app/v1",
	}),
});
```

</CodeGroup>

セッションを開始して何か話しかけ、**設定 → 利用状況 → ログ**にリクエストが表示されることを確認します。

## 既知の制限

- カスタムエンドポイントには、プラグインの Chat Completions モードを使います。LiveKit の Responses 専用の OpenAI ツールは、Phaseo のサーバーツールにはなりません。
- ルーティングされるのは LLM だけです。使用する LiveKit のインターフェースがそのモダリティでカスタムの OpenAI 互換 URL を受け付ける場合を除き、音声認識と音声合成は別途設定してください。
- 本番の音声トラフィックの前に、割り込みの処理、[ツール呼び出し](../tool-calling.mdx)、[ストリーミング](../streaming.mdx)のレイテンシをテストしてください。
