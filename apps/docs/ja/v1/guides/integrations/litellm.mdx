LiteLLM にモデル `openai/<Phaseo model ID>`、Phaseo のキー、`api_base="https://api.phaseo.app/v1"` を渡します。これは LiteLLM の直接呼び出しにも、LiteLLM プロキシの背後にあるモデルにも使えます。

## インストール

```bash
pip install litellm
```

## LiteLLM から Phaseo を呼び出す

```python
import os
from litellm import completion

response = completion(
    model="openai/openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(response.choices[0].message.content)
```

`ok` が出力されれば、設定は正しく動作しています。LiteLLM は OpenAI 互換エンドポイントに `openai/` プレフィックスを使います。Phaseo のモデル ID はそのまま `openai/gpt-6-astra` なので、LiteLLM のモデル文字列は `openai/openai/gpt-6-astra` になります。

## LiteLLM プロキシに Phaseo のモデルを追加する

アプリケーションのコードで LiteLLM のプレフィックスが不要になるよう、各モデルにエイリアスを付けます。

```yaml
model_list:
  - model_name: phaseo-gpt-6-astra
    litellm_params:
      model: openai/openai/gpt-6-astra
      api_key: os.environ/PHASEO_API_KEY
      api_base: https://api.phaseo.app/v1
```

次に、`model: "phaseo-gpt-6-astra"` でプロキシを呼び出します。エイリアスを使うと、本番環境でモデル名が読みやすくなります。

## 既知の制限

- プロキシ層によっては、認識できないツールの種類を変更したり削除したりします。Phaseo の[サーバーツール](../server-tools/index.mdx)を使う場合は、実際に使う LiteLLM のルートでテストしてください。
- LiteLLM と Phaseo の両方が利用額を記録します。どちらをコストの正式な記録にするかを決めてください。Phaseo の料金は[料金計算ツール](../../api-reference/endpoint/pricing-calculate.mdx)で確認できます。
