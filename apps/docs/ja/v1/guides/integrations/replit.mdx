`PHASEO_API_KEY` を Replit Secrets に追加してから、[OpenAI SDK](./openai-sdk.mdx) または [Phaseo AI SDK プロバイダー](./ai-sdk.mdx)で Phaseo を呼び出します。キーはソースコードに含めないでください。

## シークレットを追加する

Replit のワークスペースで **Tools → Secrets** を開き、次を追加します。

```text
PHASEO_API_KEY=phaseo_v1_sk_...
```

Replit はシークレットを環境変数としてアプリに公開します。キーの種類については[認証](../../developers/authentication.mdx)を参照してください。

## Phaseo を呼び出す

<CodeGroup>

```ts OpenAI SDK
// npm install openai
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Reply with only: ok",
});

console.log(response.output_text);
```

```ts AI SDK
// npm install @phaseo/ai-sdk-provider
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const { text } = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Reply with only: ok",
});

console.log(text);
```

</CodeGroup>

`ok` が出力されれば、シークレットと Base URL は正しく動作しています。

## デプロイする

`PHASEO_API_KEY` は、ワークスペースだけでなくデプロイのシークレットにも追加します。デプロイが環境変数やリクエストヘッダーをログに出力しないことを確認してください。
