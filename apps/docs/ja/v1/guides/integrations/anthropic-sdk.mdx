Anthropic SDK の接続先を `https://api.phaseo.app` にし、Phaseo のキーを認証トークンとして渡します。Claude 形式の `/v1/messages` リクエストを送るアプリ、エージェント、コーディングツールで使ってください。Phaseo はそれらを [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx) として処理します。

## インストール

<CodeGroup>

```bash TypeScript
npm install @anthropic-ai/sdk
```

```bash Python
pip install anthropic
```

</CodeGroup>

## クライアントの接続先を Phaseo にする

<CodeGroup>

```ts TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
	apiKey: null,
	authToken: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app",
});

const message = await client.messages.create({
	model: "anthropic/claude-sonnet-5.5",
	max_tokens: 512,
	messages: [{ role: "user", content: "Reply with only: ok" }],
});

console.log(message.content);
```

```python Python
import os
from anthropic import Anthropic

client = Anthropic(
    auth_token=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app",
)

message = client.messages.create(
    model="anthropic/claude-sonnet-5.5",
    max_tokens=512,
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(message.content)
```

</CodeGroup>

`ok` を含むテキストブロックが返れば、設定は機能しています。

| 設定 | 理由 |
| --- | --- |
| `baseURL: "https://api.phaseo.app"` | ルートのホストを使います。Anthropic のクライアントは `/v1/messages` を自分で付け加えます。 |
| `authToken`（Python では `auth_token`） | どの SDK バージョンでも `Authorization: Bearer` を送ります。Phaseo は `x-api-key` を受け付けません。`@anthropic-ai/sdk` 1.0 と `anthropic` 2.0 より前では、`apiKey` はこれを送ります。 |
| `apiKey: null` | 古い TypeScript SDK が `ANTHROPIC_API_KEY` も送らないようにします。0.98 より前の Python SDK は、設定されていれば常にこれを送るため、アップグレードするか、Phaseo を呼び出す環境では設定を解除してください。 |

## 既知の制限

- Anthropic ネイティブのツール形式は、Phaseo が対応している範囲で使えます。プロバイダーをまたいで使えるサーバーツールは Phaseo のツール名を使います。[ツール呼び出し](../tool-calling.mdx)を参照してください。
- Anthropic 互換クライアントは、ツールイベントの順序に厳格です。本番環境の前に、ストリーミングするツールのループをテストしてください。
- [Claude Code](./claude-code.mdx) には専用のガイドを使ってください。
