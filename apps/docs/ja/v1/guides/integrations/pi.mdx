`phaseo pi` を実行すると、互換性のあるすべての Phaseo モデルを含む Phaseo のプロバイダー拡張機能が Pi に追加されます。

## Phaseo CLI で設定する

```bash
phaseo login
phaseo pi
```

Pi がインストールされていない場合、CLI は公式のインストールコマンドを表示し、実行する前に確認します。その後、セットアップは `Phaseo CLI: Pi API Key`（有効期限 90 日、月額 $100 の利用上限）を作成し、`~/.pi/agent/extensions/phaseo.ts` にプロバイダー拡張機能を書き込みます。拡張機能には、Chat Completions で動作する Phaseo の有効なテキストモデルがすべて登録されます。

| フラグ | 効果 |
| --- | --- |
| `--model <id>` | 最初のモデルを設定します。デフォルトは `anthropic/claude-sonnet-4.6` です。 |
| `--catalog default` | 選択したモデルだけを追加します。 |
| `--dry-run` | ファイルを変更せずに、変更内容を表示します。 |

拡張機能は、Pi のコマンドでキーを取得する構文を使ってリクエスト時にキーを取得するため、平文のキーはファイルに書き込まれません。

```text
!phaseo integrations credential pi
```

## 動作を確認する

```bash
pi
```

`/model` を開いて `phaseo` プロバイダーを選び、短いプロンプトを送信します。**設定 → 利用状況 → ログ**にリクエストが表示されることを確認します。

## Phaseo を削除する

```bash
phaseo integrations remove pi
```

これにより、Phaseo の拡張機能だけが削除され、キーが失効します。
