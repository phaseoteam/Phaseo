オーナーと管理者は **設定 → Slack** で Slack エージェントの上限と支出上限を設定し、エージェントを使った人数に応じた月額料金と、各モデルの料金によるモデルのトークン代を支払います。まずエージェントを追加するには、[Slack エージェントを設定する](/ja/v1/guides/slack-agent)を参照してください。Slack 検索、メモリー、定期タスク、共有ページなど個別の機能の設定は、[Slack エージェントを使う](/ja/v1/guides/slack-agent-usage)のそれぞれの機能の説明にあります。

<span id="limits"></span>
## 上限

オーナーと管理者は **設定 → Slack** で次の項目を設定します。

| 設定 | 動作 | 既定値 |
| --- | --- | --- |
| **プラン** | エージェントが 1 か月に対応する人数。最大 3、10、25、50、100 人、または 100 を超える任意の人数。 | 最大 3 人 |
| **新しい人がプランを超える場合** | **断る** は、新しい人にプランが満員であることを伝えます。**自動的に上位プランに切り替える** は、エージェントを使う人数に合わせて **月の最大人数** までプランを拡大します。 | **断る** |
| **月の最大人数** | プランにかかわらず、1 か月の人数の厳格な上限。プランより低くはできません。 | 上限なし |
| **月の支出上限** | エージェントの月額請求の上限。次の回答でこれを超える場合、エージェントは翌月まで回答を停止します。プランの料金以上である必要があります。 | インストール時に設定 |
| **1 人 1 時間あたりの回答数** | 1 人が 1 か月分を使い切るのを防ぎます。 | 60 |
| **月のモデル支出上限** | エージェントの API キーが毎月モデルのトークンに使う金額の上限。 | 上限なし |

**ゲストを許可** と **他社の人を許可** も **上限** にあります。[利用できる人](/ja/v1/guides/slack-agent#who-can-use-it)を参照してください。

**エージェント** セクションでは、モデルと **指示** を設定します。指示は、口調や重視する点など、エージェントがすべての回答で従う補足のガイダンスで、最大 8,000 文字です。

<span id="limits-on-each-answer"></span>
### 各回答の上限

各回答は、12 ステップまたはモデルの支出 $0.50 のどちらか早い方に達すると停止します。1 ステップは、1 回のモデル呼び出しと、Web 検索など、それが実行するツールです。エージェントが問い合わせる他のモデル、比較で使うモデル、エージェントが作る画像も、すべて同じ $0.50 に数えられます。上限で回答が止まると、エージェントはそのことを伝え、続きを頼むことができます。これらの上限はすべてのワークスペースで同じです。

## コスト

その月（UTC）に少なくとも 1 回回答を受け取った人数に対して支払います。回答をいくつ受け取っても 1 人は月に 1 回だけ数えられ、誰もエージェントを使わなかった月の料金はかかりません。

| その月にエージェントを使った人数 | 月額料金 |
| --- | --- |
| 1〜3 人 | $0.99 |
| 4〜10 人 | $2.99 |
| 11〜25 人 | $4.99 |
| 26〜50 人 | $7.99 |
| 51〜100 人 | $14.99 |
| 101〜1,000 人 | $15 から $59 まで、1 ドル単位で均等に上がります。たとえば 200 人は $20、500 人は $35 です。 |
| 1,000 人超 | $59、またはそれを超える場合は 1 人あたり $0.045（1 ドル単位、約 1,300 人から）。たとえば 2,000 人は $90 です。 |

1 人あたり月 300 回の回答が含まれ、ワークスペース全体で共有されます。それを超える回答は 1,000 回あたり $0.25 です。

たとえば、8 人が 1 か月に 3,000 回の回答を受け取った場合、料金は最大 10 人の $2.99 です。2,400 回の回答が含まれるので、残りの 600 回は $0.15 で、その月の請求額は $3.14 になります。数値を変えて、自分の月の料金を計算してください。

<SlackAgentPricing locale="ja" />

モデルのトークンはこの料金に含まれません。エージェントが回答するときに、通常の Gateway リクエストとしてエージェントの API キーを通じ、各モデルの料金で課金されます。**月のモデル支出上限** で制限してください。

### 請求の仕組み

- その月の請求額は、月が終わってから最初の数時間以内にクレジットから差し引かれ、**月の支出上限** を超えることはありません。
- **設定 → Slack** の **今月** には、それまでの人数、回答数、推定請求額が表示されます。各請求は **過去の請求** と、請求の取引履歴に **Slack エージェント** として表示されます。
- クレジットで請求額を賄えない場合、請求はクレジットを待ち、エージェントのステータスは **支払い待ち** になります。請求が支払われるまで回答を停止します。Phaseo は 1 時間ごとに再試行するため、クレジットを追加してから約 1 時間以内に回答が再開します。金額は最初の試行時に確定します。

## オーナーと管理者へのメール

オーナーまたは管理者にしか解決できない理由でエージェントが人を断った場合、Phaseo はワークスペースのすべてのオーナーと管理者にメールを送ります。

| 理由 | メールの件名 | 対処 |
| --- | --- | --- |
| プランが満員 | Slack agent: someone new was turned away | より大きなプランを選ぶか、**自動的に上位プランに切り替える** を選びます。 |
| **月の最大人数** に到達 | Slack agent: people limit reached | **月の最大人数** を引き上げるか、なくします。 |
| **月の支出上限** に到達 | Slack agent: monthly spending cap reached | 上限を引き上げるか、翌月まで待ちます。 |
| 請求が未払い | Slack agent: paused until the charge is paid | クレジットを追加します。 |

各メールは理由ごとに月 1 回まで送られます。Slack のユーザー名は記載されず、メッセージも引用されません。

ゲスト、他社の人、1 時間あたりの上限による拒否はメールで通知されません。ワークスペースのアクティビティログには、プランの満員、**月の最大人数**、**月の支出上限** による各月の最初の拒否と、ゲスト、他社の人、1 時間あたりの上限による各人の最初の拒否が記録されます。Slack でのエージェントの返信で、管理者に通知されたと伝えることはありません。

<span id="data-and-privacy"></span>
## データとプライバシー

Slack の API 規約では Slack データでの学習やアーカイブが認められていないため、エージェントは次のように設定されています。

- **Phaseo のログにメッセージの内容は残りません。** エージェントの API キーは、ワークスペースの設定にかかわらず、ログ、キャッシュ、テレメトリーにリクエストやレスポンスの内容を保存しません。そのリクエストは引き続き使用量とログに内容なしで表示され、[リクエストラベル](/ja/v1/guides/request-labels) `app=slack-agent`、`slack_team`、`slack_channel` と、[アプリのタイトル](/ja/v1/guides/app-attribution) `Phaseo Slack agent` が付きます。
- **プロンプトで学習するプロバイダーは使いません。** **Slack エージェント** の[ガードレール](/ja/v1/cookbook/guardrails-for-api-keys)は、有料モデルと無料モデルでの学習とプロンプトの公開を無効にするため、プロンプトで学習するプロバイダーが使われることはありません。学習はせずにログを保持するプロバイダーは回答でき、自社のポリシーに基づいてそのログにメッセージの内容を保持することがあります。Phaseo 自身のログ、キャッシュ、テレメトリーには、引き続きメッセージの内容は残りません。
- **短期の作業メモリー。** スレッドごとに、エージェントは最近の返信、使ったツールに関する短いメモ、順番を待っているメッセージ、どこから読めばよいか分かるようにスレッドの最近のメッセージの ID（テキストではなく）、接続ボタンを送った相手、行った質問とその回答を保持します。これらはスレッドの最後のアクティビティから 7 日後に削除されます。
- **確認と削除ができるメモリー。** エージェントは、依頼された人の Slack ID とともに、保存を頼まれたメモ、ピン留め、To-Do、スキルを保持します。内容はエージェント自身の言葉で書かれ、メッセージのコピーではありません。誰かが削除するか、保持期限の日付が過ぎるか、エージェントをアンインストールするまで残ります。オーナーと管理者は **設定 → Slack** でそれらを確認して削除でき、メモをオフにすることもできます（[メモリーとスキル](/ja/v1/guides/slack-agent-usage#memory-and-skills)を参照）。他社の人にワークスペース全体のメモが見えることはありません。
- **共有ファイルは読むだけで保持しません。** エージェントは回答のために読む画像と PDF をダウンロードし、同じルールに従って、その回答のリクエストとともにモデルに送ります。保存することはなく、回答が終わるまでメッセージとともに保持されるのは Slack のファイル ID と名前だけです。
- **Slack の検索結果は保持しません。** エージェントが [Slack を検索](/ja/v1/guides/slack-agent-usage#searching-slack)して見つけたものは、その回答のリクエストとともにモデルに送られるだけで、それ以外の場所には残りません。作業メモリー、ログ、Phaseo のデータベースにも残らず、質問への回答を待っている間も同様です。回答で最初の検索を行ってからは、そのリクエストはデータ保持ゼロのプロバイダーにだけ送られるため、結果がプロバイダーのログに残ることもありません。検索した回答について作業メモリーに残るのは、使ったツールと回答したというメモだけで、何を検索したか、何が見つかったか、何を書いたかは残りません。代わりに検索するための Slack の権限は、回答が終わるまでメッセージとともに保持されます。
- **定期タスク。** タスクごとに、エージェントはタイトルと指示、投稿先、スケジュールとタイムゾーン、設定した人の Slack ID、前回の実行結果を保持します。誰かがタスクをキャンセルまたは削除するか、エージェントをアンインストールするまで残ります。オーナーと管理者は **設定 → Slack** でそれらを確認、一時停止、削除できます。
- **共有ページは期限切れになるまで保持します。** エージェントが公開するページには、Slack での発言や見つけた内容を含められますが、Slack の検索結果は含められません。ページは静的なので、スクリプトを実行したり、どこかに何かを送ったりすることはできません。Phaseo は、期限切れになる（管理者の選択に応じて 7、30、90 日後）、オーナーまたは管理者が削除する、またはエージェントをアンインストールするまで、ページ、そのタイトル、依頼した人の Slack ID、開かれた回数を保持します。ページの設定に応じて、リンクを知っている人なら誰でも開けるか、Slack ワークスペースにログインしているメンバーだけが開けます。ページが Phaseo のログに表示されることはありません。
- **何もアーカイブしません。** Phaseo は Slack の内容を何もアーカイブしません。エージェント自身のログに残るのは Slack の ID とステータスだけです。
- **シークレットは暗号化されます。** ボットトークンと Slack アプリのシークレットは暗号化して保存され、二度と表示されません。

アンインストールすると、エージェントの API キー、メモ、保存したスキル、定期タスク、共有ページが削除され、そのガードレールも取り除かれます（[一時停止またはアンインストール](#pause-or-uninstall)を参照）。

<span id="pause-or-uninstall"></span>
## 一時停止またはアンインストール

- **設定 → Slack** の **回答を一時停止** は、**回答を再開** を選ぶまですべての回答を停止します。エージェントにメッセージを送った人には、一時停止中であることを伝える非公開のメモが届きます。定期タスクは一時停止中に予定された実行をスキップし、回答を再開した後の次の時刻から続行します。
- **アンインストール** はエージェントをすぐに停止し、その API キー、メモ、保存したスキル、定期タスクを削除し、ガードレールを取り除いて、Slack からアプリを削除します。Slack が削除を確認しない場合は Phaseo がそのことを伝えるので、Slack でもアプリを削除してください。ガードレールを他のキーやメンバーに追加している場合、ガードレールは残ります。
- アンインストールするとエージェントの共有ページも削除されるため、そのリンクは機能しなくなります。
- Slack 内でアプリを削除するか、ボットトークンを取り消した場合も、同じように Phaseo でアンインストールされます。

過去の請求は請求履歴に残ります。アンインストールした月にエージェントを使った人の分は、その月の終わりに請求されます。エージェントはいつでも再び追加できます。

<span id="when-the-agent-cant-answer"></span>
## エージェントが回答できない場合

エージェントが誰かに回答できない場合、Slack で非公開で返信します。

| Slack での返信 | 理由 | 対処 |
| --- | --- | --- |
| "The Phaseo agent is paused until this workspace's Phaseo bill is paid." | 過去の月の請求がクレジット待ちです（**支払い待ち**）。 | クレジットを追加します。約 1 時間以内に回答が再開します。 |
| "The Phaseo agent is paused in this Slack workspace." | 管理者が **回答を一時停止** を選びました。 | **回答を再開** を選びます。 |
| "…has answered as many people this month as this workspace's plan covers…" | プランが満員で、新しい人が断られています。 | より大きなプランを選ぶか、**自動的に上位プランに切り替える** を選びます。 |
| "This workspace has reached its Slack agent limit for the month." | **月の最大人数** に達しました。 | 上限を引き上げるか、なくします。 |
| "…has reached this workspace's monthly spending cap…" | 次の回答で **月の支出上限** を超えます。 | 上限を引き上げるか、翌月まで待ちます。 |
| "You've reached the limit of … answers an hour." | **1 人 1 時間あたりの回答数** に達しました。 | 待つか、上限を引き上げます。 |
| "The Phaseo agent isn't available to guests in this workspace." | **ゲストを許可** がオフです。 | ゲストにエージェントを使わせる場合はオンにします。 |
| "The Phaseo agent only answers people in this organization." | **他社の人を許可** がオフです。 | その人たちにエージェントを使わせる場合はオンにします。 |
| "Connect your Phaseo account to use the Phaseo agent here." | アクセスが **連携済みのアカウントのみ** です。 | [Slack アカウントを連携します](/ja/v1/guides/slack-agent#link-a-slack-account)。 |
| "I'm still working through earlier messages in this thread." | このスレッドですでに 5 件のメッセージが待っています。 | それらの回答を待ちます。 |
| "Sorry, I couldn't check your Slack account just now." | Slack が照会に応答しませんでした。 | 1 分後にもう一度試します。 |
| "The model chosen for this agent isn't available to the Slack agent." | Gateway がエージェントのキーでそのモデルを使えません。自動ルーティングなしで **自動** を選んでいるか、モデルのどのプロバイダーも **Slack エージェント** のガードレールを満たしていません。 | **設定 → Slack** で別のモデルを選びます。 |
| "…isn't one of the models you can choose here, so I didn't answer." | メッセージが `with …:` で始まり、**モデルの選択** にないモデル、または複数の許可モデルに当てはまるモデルを指定しました。 | 返信の一覧にあるモデルを使うか、`with …:` を省きます。 |
| "The model you chose for this message isn't available to the Slack agent." | 上と同じく、Gateway がエージェントのキーで選ばれたモデルを使えません。 | `with …:` なしで依頼するか、**モデルの選択** のモデルを置き換えます。 |
| "The model this agent uses can't read the files shared here." | エージェントのモデルのどのプロバイダーも、共有された画像や PDF を読めません。 | ファイルなしで依頼するか、**設定 → Slack** で画像を読めるモデルを選びます。 |
| "I stopped here: after a Slack search, I can only use AI providers that keep no data…" | 回答で Slack を検索しましたが、データ保持ゼロのモデルのプロバイダーがどれも回答できませんでした。 | **設定 → Slack** でデータを保持しないモデルを選びます。メッセージが `with <model>:` で始まっていた場合は、そこでデータを保持しないモデルを選ぶか、それを省いてエージェントのモデルを使います。 |
| "…so I didn't compare them." または "Name 2 or 3 different models to compare…" | メッセージが `compare …:` で始まり、**モデルの選択** にないモデルがあるか、名前が複数の許可モデルに当てはまるか、指定した異なるモデルが 2 未満または 3 を超えています。 | 返信の一覧から 2 つか 3 つのモデルを使います。 |
| "Comparing models isn't turned on here, so I didn't answer." | メッセージが `compare …:` で始まり、カタログのモデルを指定しましたが、モデルの選択がオフです。 | オーナーまたは管理者に **モデルの選択** の **メッセージごとのモデル選択を許可する** をオンにしてもらうか、`compare …:` を省きます。 |

エージェントがまったく返信しない場合や、インストールが完了しない場合は、[設定の問題を解決する](/ja/v1/guides/slack-agent#fix-setup-problems)を参照してください。
