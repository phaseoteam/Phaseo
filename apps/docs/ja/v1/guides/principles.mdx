Gateway とモデルカタログに関するプロダクト上の選択を理解したいときにお読みください。

Phaseo は、統合の移植性を保つこと、モデルとプロバイダーの動作を可視化すること、本番環境を安全に運用するためのルーティング制御をチームに提供することを基本原則としています。

## オープン性と透明性

料金、プロバイダーの利用可否、ルーティングの動作、パフォーマンスデータは、可能な限り確認できるようにします。

Phaseo は、次のような実務的な疑問に答えやすくします。

- このモデルを提供できるプロバイダーはどれか？
- このリクエストの費用はいくらか？
- ルートの応答速度はどのくらいか？
- モデルまたはプロバイダーの更新で何が変わったか？

## すべてのモデルに共通する API

モデルプロバイダーが提供する API はそれぞれ異なります。Phaseo は、複数のプロバイダーのエコシステム、モデルファミリー、モダリティに対応する安定したレイヤーをアプリケーションに提供します。

すべてのプロバイダー間の違いを隠すことが目的ではありません。一般的なワークフローの一貫性を保ち、重要なプロバイダー固有の動作を明確にすることが目的です。

## 移植性と耐障害性

本番環境の AI システムには、モデル変更、プロバイダーの障害、料金の変動、アカウント単位の制限に耐えられることが求められます。

Phaseo は、プロバイダー互換のルートで統合の移植性を保ち、ルーティングとフォールバックの制御でシステムの耐障害性を高めます。

## 標準で備わる可観測性

本番環境のリクエストは、発生後に簡単にデバッグできるべきです。

Phaseo は使用量、レイテンシ、コスト、エラーの詳細、リクエスト ID を記録します。チームは独自の可観測性レイヤーを一から構築しなくても、システムの動作を把握できます。

## 互いを尊重するコミュニティ

Phaseo では、公開ドキュメント、モデルデータ、サンプル、コントリビューションの方法を提供しています。フィードバックは具体的かつ建設的で、プラットフォームやカタログのメンテナーに役立つ内容にしてください。
