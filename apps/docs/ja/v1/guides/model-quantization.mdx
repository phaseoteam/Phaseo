## 量子化とは

量子化では、モデルの重みと活性化をより低精度の数値で表し、メモリ使用量を減らして推論を高速化します。

一般に：

- 高精度：品質と安定性が高く、コストも高い。
- 低精度：スループットが向上してコストが下がる一方、品質低下のリスクが高まる。
