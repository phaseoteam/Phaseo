ユーザーの評価を、リクエスト ID と回答した[プリセット](./presets.mdx)とともに `POST /v1/feedback` に送信します。こうすると、レイテンシやコストだけでなく、回答が高く評価された頻度でプリセットを比較できます。

<Note>
Preset Feedback はアルファ版で、API とダッシュボードは今後変わる可能性があります。さらに役立つものにするためのご意見は、[Preset Feedback ページ](https://phaseo.app/settings/presets/experiments)の **フィードバック** ボタンからお寄せください。
</Note>

## 評価を記録する

`feedback:write` 権限を持つ API キー、Phaseo が返したリクエスト ID、プリセットの UUID が必要です。プリセット ID を含めることで、イベントがプリセット比較とコホート分析の対象になります。

```bash cURL
curl https://api.phaseo.app/v1/feedback \
  -X POST \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "requestId": "gen_01K...",
    "presetId": "8f54b2d9-9ba3-4ced-8a7f-9bb70a44dbea",
    "rating": "thumbs_up",
    "score": 1,
    "comment": "The answer resolved the customer question.",
    "metadataDimensions": {
      "plan": "pro",
      "surface": "support_chat"
    }
  }'
```

フィードバックイベントは、リクエスト、セッション、プリセット、テスト実行のうち少なくとも 1 つを対象にする必要があります。`score` は省略可能で、`0` から `1` の範囲で指定します。

プラン、デプロイ、ロケール、アプリケーションの画面など、取りうる値の種類が少ない値は `metadataDimensions` に入れると、それで絞り込めます。任意の値や種類の多いコンテキストは `metadata` に入れてください。

## 評価を選ぶ

| シグナル | `rating` |
| --- | --- |
| ユーザーの簡単な反応 | `thumbs_up`、`thumbs_down` |
| 評価済みの回答 | `correct`、`partly_correct`、`incorrect` |
| 運用上の問題 | `bad_format`、`too_slow`、`too_expensive` |
| 安全性に関する結果 | `unsafe`、`refused_incorrectly` |
| その他 | `not_helpful`、`other` |

数値のスコアだけでなく、明示的な評価を送ることをおすすめします。プリセット比較は評価をもとに作られ、スコアは補足情報として表示されます。

## プリセットを比較する

[設定 → プリセット → フィードバック](https://phaseo.app/settings/presets/experiments)を開くと、次のことができます。

- 肯定的、部分的、否定的な評価の割合を比較する
- 基準となるプリセットを選ぶ
- 日付、評価、メタデータのディメンションで絞り込む
- イベントの背後にあるリクエスト、セッション、コメント、タグを確認する

ダッシュボードが分析するのは、選択した期間内で条件に一致するフィードバック行のうち、最新の最大 10,000 件です。

## API でフィードバックを読み取る

読み取りには `feedback:read` が必要です。結果は、認証されたワークスペースと、呼び出し元が参照できるプリセットに限られます。

最近のイベントを一覧表示します。

```bash
curl "https://api.phaseo.app/v1/feedback?preset_id=PRESET_UUID&limit=100" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

サーバー側で計算された集計を取得します。

```bash
curl "https://api.phaseo.app/v1/feedback/summary?group_by=preset&since=2026-08-01T00:00:00Z" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

テスト実行とカスタム結果イベント用の API も利用できますが、そのダッシュボード表示はまだ変更中です。プリセットの変更を段階的に展開するには、[プリセットの展開とルーティングのデバッグ](../cookbook/preset-rollout-and-routing-debug)を参照してください。
