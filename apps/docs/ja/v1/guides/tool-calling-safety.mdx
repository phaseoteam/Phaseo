すべてのツール呼び出しを信頼できない入力として扱ってください。何かを実行する前に、ツール名を許可リストと照合し、引数を検証します。

```typescript
import { z } from "zod";

const WeatherArgs = z.object({
  city: z.string().min(1),
});

function executeToolCall(name: string, rawArgs: string) {
  if (name !== "get_weather") {
    throw new Error(`Unsupported tool: ${name}`);
  }

  const parsed = WeatherArgs.parse(JSON.parse(rawArgs));
  return getWeather(parsed.city);
}
```

## チェックリスト

- **スキーマは小さく明確に保つ。** 型付きのフィールドが少ないほど、モデルが予期しないものを送る余地が減ります。
- **解析した引数を検証する。** 上の例のように、実行前に行います。
- **不明なツール名は拒否する。** モデルの意図を推測してはいけません。
- **タイムアウトと再試行を加える。** 外部システムに届く呼び出しが対象です。
- **ログに残す。** 呼び出し ID、ツール名、検証の失敗を記録します。

## 検証に失敗したとき

ツールは実行しないでください。次のターンで、短く管理されたエラーをツールの結果として送り、修正した引数で再試行するようモデルに求めます。

## ストリーミング

`stream: true` では、引数は分割して届きます。呼び出しを解析、検証、実行する前に、その呼び出しの引数の差分をすべて集めてください。ツール呼び出しがストリーミングされるかどうかは、モデルとプロバイダーによって異なります。[ストリーミング](./streaming.mdx)を参照してください。
