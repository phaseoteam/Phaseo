`"model": "phaseo/free"` を送ると、Phaseo はリクエストに対応している利用可能な無料モデルで、クレジットを使わずにリクエストを実行します。完成すると、好きな言語で動くリクエストが 1 つでき、どのモデルが応答したかも分かります。

これはプロトタイプ、デモ、重要度の低いトラフィック向けの、本番環境で使えるリクエストの形です。無料モデルは、レイテンシ、出力のスタイル、固定のプロバイダーを保証しません。

## リクエストを送る

<Steps>
<Step title="キーを設定する">

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```

```go Go
package main

import (
  "context"
  "fmt"
  "os"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4"
)

func main() {
  client := phaseo.New(os.Getenv("PHASEO_API_KEY"), "https://api.phaseo.app/v1")

  temperature := 0.2
  response, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
    Model:       "phaseo/free",
    Input:       "Summarize why provider-aware free routing helps prototypes.",
    Temperature: &temperature,
  })
  if err != nil {
    panic(err)
  }

  fmt.Printf("%+v\n", response)
}
```

## 無料モデルの選ばれ方

1. リクエストは共有の `phaseo/free` エイリアスに送られます。
2. Phaseo は、このリクエスト（エンドポイント、パラメーター、ツール）に対応できる無料モデルに絞り込みます。
3. その中の 1 つにリクエストを送ります。

無料モデルには、既定でユーザーごとに UTC の 1 日あたり 1,500 リクエストの共有枠があります。これを超えると、UTC 00:00 まではリクエストがコード `phaseo_free_model_limit_exceeded` とともに `429` を返します。[Gateway の制限](../api-reference/limits#gateway-limits)を参照してください。

## 無料ルーターから移行する

ツールや JSON Schema など、必要な機能に対応する無料モデルがない場合は、同じリクエストを再試行せずに特定の有料モデルに切り替えてください。予測できるレイテンシ、出力のスタイル、プロバイダーの選択が必要な場合は固定のモデルに移行し、共通の設定を[プリセット](../guides/presets)にまとめて、すべてのサービスが同じリクエストを送るようにします。有料リクエストがプロバイダーを選ぶ仕組みは[ルーティングとフォールバック](../guides/routing-and-fallbacks)で、エラーコードの一覧は [API エラー](../api-reference/errors)で説明しています。
