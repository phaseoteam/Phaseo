ローカルのステータスツールを呼び出して運用に関する質問に答える Go エージェントを、ジョブシステムを使わずに 1 つのサービス内で実行します。完成すると、現在のプロバイダーのレイテンシーについて短い回答を出力する `main.go` が 1 つできます。

ツールは固定のサンプルデータを返すため、このプログラムは例示用です。実際には独自のステータスやメトリクスの呼び出しに置き換えてください。必要なコンテキストをすでにローカル呼び出しや内部呼び出しで取得できる Go サービスに適しています。

## 作成する

<Steps>
<Step title="インストールする">

```bash
go mod init ops-runbook
go get github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go@latest
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

コアの `sdk-go/v4` モジュールも一緒に取得されます。要件については [Go Agent SDK のインストール](../sdk-reference/agent/installation)をご覧ください。

</Step>
<Step title="エージェントを書く">

```go main.go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  statusTool := phaseoagent.DefineTool(phaseoagent.Tool{
    ID:          "read-status",
    Description: "Read the current service status page summary.",
    Parameters: map[string]any{
      "type":                 "object",
      "properties":           map[string]any{},
      "additionalProperties": false,
    },
    Execute: func(input any, ctx phaseoagent.RuntimeContext) (any, error) {
      return map[string]any{
        "status":  "degraded",
        "summary": "Latency is elevated on one provider route.",
      }, nil
    },
  })

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "ops-runbook-agent",
    Model:        "openai/gpt-6-astra",
    Instructions: "Use tools when helpful and answer briefly.",
    Tools:        []phaseoagent.Tool{statusTool},
    MaxSteps:     4,
  })

  // PHASEO_API_KEY（設定されていれば PHASEO_BASE_URL も）を読み取ります。
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "What is happening with provider latency right now?",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Run.Status)
  fmt.Println(result.Output)
}
```

</Step>
<Step title="実行する">

```bash
go run .
```

</Step>
</Steps>

## 動作を確認する

- プログラムは `completed` を出力し、続いて 1 つのプロバイダールートでレイテンシーが悪化していることに触れた回答を出力します。
- **設定 → 利用状況 → ログ** では、最初のモデルターンに `read-status` のツール呼び出しが表示されます。
- `PHASEO_API_KEY` がない場合、`CreateGatewayAgentClient` は `PHASEO_API_KEY is required` を返します。

## 本番環境の前に

Go SDK の `MaxSteps` のデフォルトは `8` です。ジョブを完了できる最小の値に設定してください。ツールが引数を受け取る場合は、引数がモデルから来るため、`Parameters` スキーマと、想定外の入力にエラーを返す `InputSchema` バリデーターを指定してください。人が呼び出しを承認する場合（`RequireApproval: true`）を除き、ツールは読み取り専用にしてください。承認、状態、ストリーミングについては [Go Agent SDK リファレンス](../sdk-reference/agent/usage)で説明しています。ローカルツールの代わりに既知のページを読む方法は [Web フェッチによるグラウンディング](./tool-grounding-with-web-fetch)で紹介しています。
