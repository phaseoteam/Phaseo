あいまいな統合計画ではなく、小さくても動作するアプリを作るための具体的なプロンプトをコーディングエージェントに渡す場合に、このページを使います。

<Tip>
Cursor、Claude Code、Codex などで効果的に使えるよう、これらのプロンプトは成果と実装方法を具体的に指定しています。
</Tip>

## プロンプトの使い方

<Steps>
  <Step title="統合方法を選ぶ">
    アプリから Phaseo を呼び出す方法に合ったプロンプトを選びます。

    - raw HTTP
    - 公式 SDK
    - Vercel AI SDK
    - Agent SDK
  </Step>
  <Step title="角括弧の変数を置き換える">
    コーディングエージェントに貼り付ける前に、`[アプリのアイデア]`、`[フレームワーク]`、`[モデル]`、`[LANGUAGE]` などの値を入力します。
  </Step>
  <Step title="コードだけでなく検証も求める">
    プロンプトには検証項目を残してください。エージェントが実際に実行した内容、置いた前提、手動設定が必要な項目を報告するようになります。
  </Step>
</Steps>

## プロンプトをより効果的にする方法

- `[アプリのアイデア]` には広い製品構想ではなく、具体的で限定されたユーザーの作業を指定してください。
- エージェントに使わせたいモデルの正確な ID を `[モデル]` に指定してください。
- 出力を自由形式テキスト、厳密な JSON、チャット、または単一の生成アセットのどれにするか指定してください。
- 分かる場合は、UI フレームワークとデプロイ先を記載してください。
- `EU-only providers`、`use streaming`、`keep all secrets server-side` のような重要な制約を 1～2 個追加してください。
