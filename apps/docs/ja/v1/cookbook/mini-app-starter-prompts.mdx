description: "コーディングエージェントが素の HTTP、SDK、エージェントランタイムを使って小規模な Phaseo アプリを作るための、コピー可能なプロンプトです。"
---

これらのプロンプトのいずれかを Cursor、Claude Code、Codex などのコーディングエージェントに貼り付けると、小さな動作する Phaseo アプリを作成し、実行した内容と確認できなかった内容を報告します。各プロンプトには、連携方法、安全のためのルール、期待する確認内容が書かれています。

生成されるアプリは出発点です。デプロイする前に、特にシークレットの扱いとツールの検証を中心にコードをレビューしてください。

## プロンプトを使う

<Steps>
  <Step title="連携方法を選ぶ">
    | プロンプト | Phaseo の呼び出し方 |
    | --- | --- |
    | 素の HTTP | `https://api.phaseo.app/v1` に対する `fetch` |
    | TypeScript SDK | `@phaseo/sdk` |
    | Python SDK | `phaseo` |
    | Vercel AI SDK | `@phaseo/ai-sdk-provider` |
    | Agent SDK | `@phaseo/agent-sdk`、`phaseo-agent-sdk`、または使う言語向けの Agent SDK |
  </Step>
  <Step title="角かっこの変数を置き換える">
    プロンプトをコーディングエージェントに貼り付ける前に、`[APP IDEA]`、`[FRAMEWORK]`、`[MODEL]`、`[LANGUAGE]` などの値を埋めます。
  </Step>
  <Step title="コードだけでなく確認も依頼する">
    プロンプトの確認に関する行は残しておきます。これにより、エージェントは実際に実行した内容、前提にした内容、手動での設定がまだ必要な内容を報告するようになります。
  </Step>
</Steps>

## プロンプトの効果を高めるには

- `[APP IDEA]` は、幅広い製品の売り文句ではなく、ユーザーの具体的な作業 1 つに置き換えます。
- `[MODEL]` は、エージェントに使わせたいモデル ID そのものに置き換えます。
- 出力を自由形式のテキスト、厳密な JSON、チャット、生成アセット 1 つのどれにするかを指定します。
- 分かっている場合は、UI フレームワークとデプロイ先を書きます。
- `EU-only providers`、`use streaming`、`keep all secrets server-side` など、重要な制約を 1 つか 2 つ追加します。

[TypeScript と Python の SDK](../sdk-reference/client/overview) と [Agent SDK](../sdk-reference/agent/overview) のリファレンスには各パッケージが提供する機能が載っているため、エージェントのコードをそれと照らし合わせて確認できます。
