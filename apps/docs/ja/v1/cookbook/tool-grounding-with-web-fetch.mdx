モデルに `phaseo:web_fetch` と既知の URL を渡すと、Phaseo がページを取得し、サイズの上限まで切り詰めてテキストを返し、その後でモデルが抽出、要約、分類を行います。完成すると、1 つのページを読んでそこからフィールドを返すリクエストが 1 つでき、実際にどのページを読んだかをログで確認できます。

このリクエストは、示したドメイン制限があれば本番環境で使えます。取得したページは信頼できない入力です。モデルがその中の指示を目にする可能性があるため、返された内容を検証してください。URL が分からない場合は、代わりに[ウェブ検索](../guides/server-tools/web-search)を使います。

## 根拠付きのリクエストを送る

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
    "tools": [
      {
        "type": "phaseo:web_fetch",
        "parameters": {
          "allowed_domains": ["phaseo.app"],
          "max_chars": 8000,
          "max_uses": 1
        }
      }
    ],
    "tool_choice": "phaseo:web_fetch"
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-6-astra",
  input:
    "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
  tools: [
    {
      type: "phaseo:web_fetch",
      parameters: {
        allowed_domains: ["phaseo.app"],
        max_chars: 8000,
        max_uses: 1,
      },
    },
  ],
  tool_choice: "phaseo:web_fetch",
});

console.log(JSON.stringify(response.output, null, 2));
console.log(response.usage?.server_tool_use);
```
</CodeGroup>

プロンプトには、取得後の作業を明示してください。たとえば、これらのフィールドを抽出する、このセクションを要約する、文書を分類する、1 つの主張を確認する、などです。

| パラメーター | 既定値 | 用途 |
| --- | --- | --- |
| `allowed_domains` | なし | これらのドメインからだけ取得します。モデルは一覧を絞り込めますが、広げることはできません。 |
| `max_chars` | `12000` | 返されるページテキストの文字数で、上限は `100000` です。タイトルや要約なら少なめに、フィールドの抽出なら多めにします。 |
| `max_uses` | `10` | リクエストあたりの取得回数で、上限は `100` です。 |

`blocked_domains` やエンジンなど、その他のパラメーターは[ウェブ取得ガイド](../guides/server-tools/web-fetch#parameters)に一覧があります。

## 読んだ内容を確認する

リクエストのログに表示されるツールの結果には、モデルが根拠としたページが正確に示されます。

```json
{
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "truncated": false,
  "returned_chars": 8000
}
```

モデルがページ全体を見たと判断する前に、リダイレクト後の `final_url` と `truncated` を確認してください。取得のたびに `usage.server_tool_use.web_fetch_requests` が 1 増えます。

## 制限を知る

既定の `direct` エンジンでは、Phaseo 自身がページを取得し、HTML をプレーンテキストに変換します。`localhost` やプライベートアドレスは拒否し、リダイレクトは最大 5 回までたどり、各リダイレクトをドメインの一覧と照合します。一覧の外へのリダイレクトは、モデルに `redirect_blocked_by_domain_policy` を返します。

ウェブ取得は、HTML ページ、プレーンテキスト、小さな JSON や XML のレスポンスに適しています。バイナリファイル、多数のページのクロール、JavaScript でのページの描画結果の確認には向いていません。それらにはブラウザーを使うワークフローを使ってください。ページが非常に大きい場合は、`max_chars` を引き上げるのではなく、抽出の作業を絞り込みます。

まず 1 つのプリセットまたはエンドポイントで始め、ログで取得の詳細と切り詰めの有無を確認し、取得したテキストが広すぎる場合はプロンプトを絞り込んでから利用を広げてください。
