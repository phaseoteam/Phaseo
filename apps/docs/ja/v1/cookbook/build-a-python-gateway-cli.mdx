標準ライブラリだけで動く Python CLI を実行し、Phaseo のエンドポイントを 1 コマンドずつ呼び出します。完成すると、health、models、Responses、Chat Completions に対して `python quickstart.py <command>` が動作し、さらにワーカーやバックエンドにコピーできる embeddings、モデレーション、画像、OCR、動画、音楽のコマンドもそろいます。

この CLI は説明用です。パッケージ化されたツールではなく、リクエストの形を確認するための参考実装です。メディア系コマンドの既定のモデル ID のいくつかはすでに提供されていないため、それらには `--model` を渡してください（[メディア系コマンドのモデルを選ぶ](#pick-models-for-the-media-commands)を参照）。

同様の CLI をコーディングエージェントにゼロから作らせるには、次のプロンプトを貼り付けます。

## CLI でできること

サンプルは [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) です。`urllib`、`json`、`argparse` だけを使う `quickstart.py` 1 ファイルで構成されています。

| コマンド | 呼び出し |
| --- | --- |
| `smoke` | `GET /v1/health`、`GET /v1/models`、`GET /v1/providers`、および `POST /v1/responses` を 1 回 |
| `health`、`models`、`providers` | 対応する `GET` ルート |
| `responses --prompt` | `POST /v1/responses` |
| `chat --prompt` | `POST /v1/chat/completions` |
| `embeddings --text` | `POST /v1/embeddings` |
| `moderations --text` | `POST /v1/moderations` |
| `image --prompt` | `POST /v1/images/generations` |
| `ocr --image-url` | `POST /v1/ocr` |
| `video-create`、`video-status`、`video-cancel`、`video-download-url` | `POST /v1/videos`、`GET /v1/videos/{video_id}`、`POST /v1/videos/{video_id}/cancel`、`POST /v1/videos/{video_id}/download_url` |
| `music-create`、`music-status` | `POST /v1/music/generate`、`GET /v1/music/generate/{music_id}` |

どのリクエストも、`429`、`5xx`、ネットワークエラーのときに 1 秒、2 秒と待って 2 回まで再試行し、45 秒でタイムアウトします。各コマンドは呼び出しが `2xx` でない場合に `1` で終了するため、スクリプトの中で使えます。

## 実行する

Python 3 と Phaseo の API キーが必要です。

<Steps>
<Step title=".env.local を作成する">

スクリプトは、実行したフォルダーにある `.env.local` を読み込みます。サンプルには `.env.example` がないため、ファイルを作成します。

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# 任意
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My Python CLI
PHASEO_HTTP_REFERER=https://myapp.example
```

シェルですでに設定されている変数は、ファイルの値より優先されます。`PHASEO_MODEL` がない場合、テキスト系コマンドは `openai/gpt-5.6-sol` を使います。

</Step>
<Step title="スモークチェックを実行する">

```bash
cd examples/gateway-python-quickstart
python quickstart.py smoke
```

`smoke` は短い Responses リクエストも 1 件送るため、クレジットを少し消費します。

</Step>
<Step title="リクエストを 1 件送る">

```bash
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

</Step>
</Steps>

## 動作を確認する

- `smoke` はすべてのブロックで `HTTP 200` を表示し、`0` で終了します。
- `responses` コマンドの出力に `integration_ok` が含まれます。
- `--help` はリクエストを送らずにコマンドの一覧を表示します。
- キーがない場合、スクリプトは `Missing PHASEO_API_KEY` を表示して `1` で終了します。
- リクエストは **設定 → 使用量 → ログ** に表示されます。

## メディア系コマンドのモデルを選ぶ

`quickstart.py` の次の既定値は、提供終了しているか、有効なプロバイダーがありません。`--model` で現在のモデルを渡してください。モデルは[モデルページ](https://phaseo.app/models)または `python quickstart.py models` から選べます。

| コマンド | サンプルの既定値 | 状態 |
| --- | --- | --- |
| `moderations` | `openai/omni-moderation-latest` | カタログの ID ではありません。`openai/omni-moderation` を使ってください |
| `ocr` | `mistral/mistral-ocr` | 提供終了。`mistral/ocr-4.1` を試してください |
| `video-create` | `openai/sora-2` | 提供終了 |
| `music-create` | `suno/suno-v4` | 有効なプロバイダーなし |

`embeddings`（`google/gemini-embedding-2`）と `image`（`openai/gpt-image-2`）の既定値は提供中です。動画と音楽のジョブは非同期です。返された ID を保存して、ステータス確認のコマンドでポーリングしてください。ジョブのライフサイクルは[非同期の動画とバッチ](../guides/async-video-and-batch)で説明しています。

ファイルはサービスに必要なコマンドだけに絞り込み、共通の `gateway_request()` ヘルパーは 1 つ残します。型付きのリクエストを使いたい場合は、[Python SDK](../sdk-reference/client/overview) に切り替えてください。
