---
title: "ローカルのエージェントツールを並行して実行する"
icon: "network"
description: "TypeScript Agent SDK で上限付きのローカルツール並行実行を使い、1 回のモデルターンで独立したコンテキストを、ツール呼び出しを 1 つずつ順に実行せずに集めます。"
---

`toolExecution.toolConcurrency` を設定すると、TypeScript Agent SDK は 1 回のモデルターンから出た複数の独立したツール呼び出しを、1 つずつ順にではなく同時に実行します。完成すると、ドキュメント、ステータス、インシデントのコンテキストを並行して集め、その結果をモデルが要求した順序で記録するエージェントができます。

ツールは固定のサンプルデータを返すため、このスクリプトは例示用です。実際には独自の読み取り専用の検索に置き換えてください。パッケージ化した版は `packages/sdk/agent-sdk-ts/examples/parallel-tool-agent.ts` にあります。

## 作成する

<Steps>
<Step title="インストールする">

```bash
npm install @phaseo/agent-sdk zod
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="エージェントを書く">

```ts parallel-agent.ts
import { z } from "zod";
import { createAgent, createGatewayAgentClient, defineTool } from "@phaseo/agent-sdk";

const fetchDocs = defineTool({
  id: "fetch-docs",
  description: "Return a short summary of one Phaseo docs page by slug.",
  parameters: {
    type: "object",
    properties: { slug: { type: "string" } },
    required: ["slug"],
    additionalProperties: false,
  },
  inputSchema: z.object({ slug: z.string().regex(/^[a-z0-9/-]{1,80}$/) }).strict(),
  parallelSafe: true,
  timeoutMs: 5_000,
  async execute({ slug }) {
    return { slug, summary: `Docs summary for ${slug}` };
  },
});

const fetchStatus = defineTool({
  id: "fetch-status",
  description: "Return the status of one Phaseo component.",
  parameters: {
    type: "object",
    properties: { component: { type: "string", enum: ["gateway", "dashboard", "async-jobs"] } },
    required: ["component"],
    additionalProperties: false,
  },
  inputSchema: z.object({ component: z.enum(["gateway", "dashboard", "async-jobs"]) }).strict(),
  parallelSafe: true,
  timeoutMs: 5_000,
  async execute({ component }) {
    return { component, status: "operational" };
  },
});

const fetchIncidents = defineTool({
  id: "fetch-incidents",
  description: "Return the open incident count for one service.",
  parameters: {
    type: "object",
    properties: { service: { type: "string", enum: ["gateway", "dashboard", "async-jobs"] } },
    required: ["service"],
    additionalProperties: false,
  },
  inputSchema: z.object({ service: z.enum(["gateway", "dashboard", "async-jobs"]) }).strict(),
  parallelSafe: true,
  timeoutMs: 5_000,
  async execute({ service }) {
    return { service, openIncidents: 0 };
  },
});

const agent = createAgent({
  id: "parallel-tool-agent",
  model: "openai/gpt-6-astra",
  instructions:
    "Use the available tools to gather context, then return one concise operational summary.",
  tools: [fetchDocs, fetchStatus, fetchIncidents],
  toolExecution: { toolConcurrency: 3 },
  maxSteps: 4,
});

const result = await agent.run({
  input:
    "Fetch the presets docs, the gateway status, and the async-jobs incident digest, then summarize the current state.",
  client: createGatewayAgentClient({
    clientOptions: { apiKey: process.env.PHASEO_API_KEY! },
    parallelToolCalls: true,
  }),
  onEvent(event) {
    if (event.type === "tool.started" || event.type === "tool.completed") {
      console.log(event.type, event.toolName, event.timestamp);
    }
  },
});

console.log(result.output);
```

</Step>
<Step title="実行する">

```bash
npx tsx parallel-agent.ts
```

</Step>
</Steps>

## 動作を確認する

- モデルが 1 回のターンで 3 つすべてを要求した場合、3 つの `tool.started` の行が、対応する `tool.completed` の行より前に、近いタイムスタンプで出力されます。
- `result.messages` には、完了した順序にかかわらず、モデルのツール呼び出しの順序でツールの結果が並びます。
- 実行は `result.output` の 1 つの要約で終わります。

## 同時に実行されるもの

| 設定 | 効果 |
| --- | --- |
| `toolExecution.toolConcurrency` | 1 回のターンのツール呼び出しを、この数まで同時に実行します。デフォルトは `1` です。 |
| ターン内のすべてのツールに `parallelSafe: true` | 最大 8 個、または `toolConcurrency` のほうが大きければその数まで同時に実行します。読み取り専用のツールにだけ使ってください。 |
| ツールの `timeoutMs` | この時間が経つとその呼び出しは失敗するため、1 つの依存先が止まってもすべての枠がふさがることはありません。 |
| Gateway クライアントの `parallelToolCalls` | モデルが 1 回のターンで複数のツール呼び出しを要求できるようにします。実際に要求するかどうかはモデルによって異なります。 |

`tool.started` と `tool.completed` は引き続き呼び出しごとに発生し、ツールのフェーズが終わると実行がチェックポイントを保存します。

## 安全に使う

並行実行は、互いの出力に依存せず、共有状態を変更しないツールにだけ使ってください。`2` か `3` から始め、ツールは副作用の少ない冪等なものにし、上の例のようにすべての引数を `inputSchema` で検証してください。`state` アクセサーは、[永続化可能なループ](./agent-sdk-durable-loop)のように、実行を再開する必要がある場合にだけ追加してください。本番で頼る前に、複数ツールのターンを扱うテストを実行し、結果の順序を確認してください。
