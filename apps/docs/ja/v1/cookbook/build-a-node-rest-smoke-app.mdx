依存関係のない Node.js スクリプトを実行し、素の `fetch` で Phaseo を呼び出して、すべてのリクエストとレスポンスを確認します。完成すると、デプロイ前に実行できるスモークテストが手元に残ります。このテストは API に到達できることを確認し、モデル一覧を取得し、Responses、Chat Completions、Embeddings にそれぞれ 1 件ずつリクエストを送ります。

このスクリプトは説明用です。各 HTTP ステータスを表示しますが、終了コードは常に `0` です。CI で使う前に、[デプロイチェックとして使う](#use-it-as-a-deploy-check)の終了コードのチェックを追加してください。

同じスクリプトをコーディングエージェントにゼロから作らせるには、次のプロンプトを貼り付けます。

## スクリプトが呼び出すもの

サンプルは [examples/gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) です。依存関係のない `index.mjs` 1 ファイルだけで構成されています。

| モード | 呼び出し | クレジットの消費 |
| --- | --- | --- |
| `npm run smoke` | `GET /v1/health`、`GET /v1/models` | なし |
| `npm run start` | 上の 2 つに続けて `POST /v1/responses`、`POST /v1/chat/completions`、`POST /v1/embeddings` | あり |

テキストの呼び出しは `PHASEO_MODEL`（既定値は `openai/gpt-5.6-sol`）に `Return exactly: integration_ok` を送ります。Embeddings の呼び出しには `google/gemini-embedding-2` を使います。

## 実行する

組み込みの `fetch` を使うため Node.js 18 以降と、Phaseo の API キーが必要です。

<Steps>
<Step title=".env.local を作成する">

スクリプトは、実行したフォルダーにある `.env.local` をパッケージなしで読み込みます。サンプルには `.env.example` がないため、ファイルを作成します。

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# 任意
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My smoke test
PHASEO_HTTP_REFERER=https://myapp.example
```

シェルですでに設定されている変数は、ファイルの値より優先されます。

</Step>
<Step title="スモークモードを実行する">

```bash
cd examples/gateway-node-quickstart
npm run smoke
```

</Step>
<Step title="フルモードを実行する">

```bash
npm run start
```

</Step>
</Steps>

## 動作を確認する

各呼び出しは次のようなブロックを表示します。

```text
=== Health ===
HTTP 200
{ ... }
```

- `Health` と `Models` に `HTTP 200` が表示され、`Models` に少なくとも 1 つのモデルが一覧表示されます。
- フル実行では、Responses と Chat Completions のブロックに `integration_ok` が含まれます。
- キーが間違っている場合、生成のブロックには `HTTP 401` とエラー本文が表示され、エラーが握りつぶされることはありません。
- リクエストは **設定 → 使用量 → ログ** に表示されます。

## デプロイチェックとして使う

`request()` は `{ status, ok, payload }` を返しますが、`ok` を確認する処理はありません。`print()` の先頭に 1 行追加すると、いずれかの呼び出しが失敗したときにスクリプトが `1` で終了します。

```js index.mjs
function print(title, result) {
  if (!result.ok) process.exitCode = 1;
  console.log(`\n=== ${title} ===`);
  // ...以降は変更なし
}
```

スクリプトはサービスで使うルートだけに絞り込みます。ペイロードを手で組み立てたくない場合は、[TypeScript SDK](../sdk-reference/client/overview) に切り替えてください。
