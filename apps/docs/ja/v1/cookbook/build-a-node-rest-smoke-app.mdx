## サンプルプロジェクト

- GitHub: [examples/gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart)
- リポジトリ内のパス: `examples/gateway-node-quickstart`

## このアプリの機能

- を呼び出す `GET /v1/health`
- を呼び出す `GET /v1/models`
- 次のような生成ルートを試す `POST /v1/responses`
- スモークテスト、スクリプト、バックエンド確認に使えるHTTP直接呼び出しの例を示す

## このサンプルが適しているケース

次のような場合はここから始めます。

- API呼び出しを直接デバッグしたい
- まだSDKの抽象化を使いたくない
- Web UIではなく、スクリプト、worker、CLIを作成している

## 前提条件

- 組み込みの`fetch` support
- Phaseo APIキー

## サンプルを実行する

```bash
cd examples/gateway-node-quickstart
cp .env.example .env.local
```

次を設定します。

- `PHASEO_API_KEY`

次のいずれかを実行します。

```bash
npm run smoke
```

または:

```bash
npm run start
```

## 動作を確認する

- スモークモードでAPIに接続できることを確認できます。
- モデル検出で少なくとも1つのモデルが返されます。
- 完全実行で生成成功のレスポンスが1件出力されます。
- 認証エラーや200以外のレスポンスを、分かりやすいターミナルエラーとして表示します。

## コード内で確認すること

- スクリプトによる読み込み方法 `.env.local`
- Authorizationヘッダーの設定方法
- 各リクエストを明示的に組み立てる方法
- 200以外のレスポンスを無視せず表示する方法

## 独自の用途に合わせる方法

- サービスに必要なルートだけにスクリプトを絞る
- 複数のスクリプトで使う共通リクエストコードをヘルパーに移す
- HTTPを直接扱うコードが重複してきたらTypeScript SDKに移行する
