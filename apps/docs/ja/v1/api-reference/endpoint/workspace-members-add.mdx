description: "既存ユーザーをワークスペースに追加します。"

<Note>このエンドポイントには `workspaces:write` 権限を持つ管理APIキーと、オーナーまたは管理者のロールが必要です。</Note>

ワークスペースへの参加は招待を通じて行います。招待を承諾すると参加リクエストが作成され、このエンドポイントがそれを承認します。`user_ids` の各ユーザーには、ワークスペースに保留中の参加リクエストが必要です。それ以外のユーザーは拒否されるため、先に招待を送ってください。既存のメンバーのロールは変わりません。

ロールには `admin` または `member` を指定できます。ロールを指定しない場合、各ユーザーには招待作成時のロールが付与されます。管理者を追加できるのはワークスペースのオーナーだけで、このエンドポイントではワークスペースの所有権を割り当てられません。

各ユーザーは個別に承認されます。途中で承認に失敗した場合、それまでに承認されたユーザーはワークスペースに残り、残りのユーザーは試行されません。その場合のレスポンスは `409` で、`approved`、`failed`、`not_attempted` の各リストで処理が止まった位置がわかります。問題を解決してから、残りのユーザーを再度送信してください。
