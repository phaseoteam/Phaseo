description: "既存ユーザーをワークスペースに追加します。"
---
<Note>このエンドポイントには `workspaces:write` 権限を持つ管理APIキーと、オーナーまたは管理者のロールが必要です。</Note>

ロールは `admin` または `member` です。このエンドポイントからワークスペースの所有権を割り当てることはできません。
