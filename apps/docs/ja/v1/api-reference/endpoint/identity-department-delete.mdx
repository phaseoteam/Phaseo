---
title: "ワークスペースの部署を削除"
badge: "Beta"
openapi: "/ja/openapi/v1/openapi.localized.yaml DELETE /identity/departments/{id}"
---
<Note>エンタープライズディレクトリの管理には、Identity アドオン、オーナーまたは管理者の ID、および対応する設定スコープが必要です。</Note>

ディレクトリグループのマッピングがその部署を使っている場合、削除できるのはワークスペースのオーナーだけです。部署を削除すると、それらのマッピングと、マッピングが付与するロールも削除されるためです。
