検索、取得、生成の処理に渡す前に、候補ドキュメントを並べ替えるためのエンドポイントです。

デプロイ前に`GET /v1/models`でモデルを確認してください。既定のレスポンスには公開Gatewayルートがあるモデルのみが含まれます。
