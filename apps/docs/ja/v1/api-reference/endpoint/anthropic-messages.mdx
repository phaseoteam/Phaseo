`/v1/messages` は Anthropic Messages API のリクエスト形式を受け取り、Anthropic 形式の応答を返します。

## ストリーミング

`stream: true` を設定すると、Anthropic 形式の Server-Sent Events（`message_start`、`content_block_*`、`message_delta`、`message_stop`）を受信できます。

## 会話途中のシステムメッセージ

会話のその時点以降に適用する指示は、`messages` に `role: "system"` のメッセージとして追加します。トップレベルの `system` フィールドは変わらないため、キャッシュ済みのプレフィックスは引き続きヒットします。

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5.5",
    "max_tokens": 512,
    "system": "You are a code review assistant.",
    "messages": [
      { "role": "user", "content": "Review process() in utils.py." },
      { "role": "assistant", "content": "The loop is fine; the regex is compiled on every call." },
      { "role": "user", "content": "Now review the code that calls it." },
      { "role": "system", "content": "From now on, include type annotations in every suggestion." }
    ]
  }'
```

- システムメッセージは文字列またはテキストブロックを受け付けます。ユーザーターン（またはサーバーツールの結果で終わるアシスタントターン）の直後に置き、最後のメッセージにするか、直後にアシスタントターンを続ける必要があります。それ以外の位置では 400 が返ります。
- Claude Fable 5 と 5.1、Mythos 5 と 5.1、Opus 4.8、Opus 5 と 5.5、Sonnet 5.5、Haiku 5.5 はその位置のまま受け取ります。Sonnet 5 を含むその他の Claude モデルでは、トップレベルのシステムプロンプトの一部として渡されます。その他のプロバイダーには、Chat Completions に送ったシステムメッセージと同じ形で渡されます。
- `clear_at`、`output_config`、`tool_addition` / `tool_removal` ブロックには対応していません。

## 補足

- Anthropic のツール使用フィールドに対応しています。
- `stream: true` はツールループでも利用できます。Gateway 管理サーバーツールでは、Phaseo が上流のターンを処理してループを続行し、合成ストリームを再送する場合があります。
- Anthropic ネイティブの Web 検索ツール形式も `tools` で直接指定できます。例: `type: "web_search_20250305"`。
- `X-Phaseo-Strictness` ヘッダーで、未対応パラメーターの扱いを制御します。

## サーバーツール

`/v1/messages` は次の Gateway 管理サーバーツールにも対応しています。

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

Phaseo はこれらのツールを上流プロバイダー向けの Anthropic 互換形式に変換してサーバー側で実行し、ツールループを続行します。

## プロバイダーのネイティブ Web 検索

互換性のある Anthropic モデルとプロバイダーの組み合わせがネイティブ Web 検索に対応している場合は、ネイティブのツール定義を直接渡すこともできます。

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-4",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "Find the latest Anthropic web search guidance." }
    ],
    "tools": [
      {
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": 3,
        "allowed_domains": ["docs.anthropic.com"]
      }
    ],
    "tool_choice": { "type": "tool", "name": "web_search" }
  }'
```

実行前に、プロバイダーのルーティングで `web_search_options` の対応状況が引き続き確認されます。

### 日時の例

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-4",
    "max_tokens": 512,
    "stream": false,
    "messages": [
      { "role": "user", "content": "What time is it in America/New_York right now?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "America/New_York" }
      }
    ],
    "tool_choice": { "type": "auto" }
  }'
```

使用すると、`usage.server_tool_use.*` カウンターにサーバーツールの呼び出し回数が記録されます。
