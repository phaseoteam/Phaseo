<Note>このエンドポイントには `settings:read` 権限を持つ管理APIキーが必要です。</Note>

各ルートには、現在の下書きバージョン、デプロイ済みバージョン、変更不可のバージョン履歴、関連するAPIキーIDが含まれます。
