title: "ワークスペースの予算を一覧表示"
sidebarTitle: "予算を一覧表示"
badge: "Beta"
openapi: "/ja/openapi/v1/openapi.localized.yaml GET /budgets"
description: "ワークスペースに適用された支出上限を、現在の使用量と残額とともに一覧表示します。"
---

`budgets:read`が必要です。OAuthの呼び出し元には、ワークスペースのオーナーまたは管理者ロールが必要です。

使用量は成功したゲートウェイリクエストから計算されます。非同期処理の予約は保留が有効な間は含まれるため、返される残額は適用中の制限と一致します。
