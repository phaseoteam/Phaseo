<Note>
このエンドポイントには管理機能`activity:read`が必要です。OAuthの呼び出し元には、ワークスペースのオーナーまたは管理者ロールも必要です。
</Note>

イベントにはサニタイズ済みのメタデータのみが含まれます。平文の認証情報、認証情報のハッシュ、認証ヘッダー、スコープの全一覧、リクエスト本文は返されません。
