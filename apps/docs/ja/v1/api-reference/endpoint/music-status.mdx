description: "Phaseo のリクエスト ID を使って音楽生成結果を取得します。"
---

`nativeResponseId` ではなく、[`POST /v1/music/generate`](./music-generate.mdx) が返した `id` を渡してください。生成が完了している場合、Phaseo は保存された結果を返し、まだ実行中の場合はプロバイダーをポーリングします。

```bash
curl https://api.phaseo.app/v1/music/generate/req_01JY6MUSIC123 \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "suno",
  "model": "V4_5PLUS",
  "nativeResponseId": "task_123",
  "output": [
    {
      "index": 0,
      "id": "clip_1",
      "audio_url": "https://...",
      "stream_audio_url": "https://...",
      "image_url": "https://...",
      "title": "Midnight Blue",
      "tags": "jazz, piano",
      "duration": 8
    }
  ],
  "usage": {
    "output_audio_count": 1,
    "output_audio_seconds": 8
  }
}
```

`status` は `queued`、`in_progress`、`completed`、`failed` のいずれかです。`usage` は生成が完了すると含まれます。
