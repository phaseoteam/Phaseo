---

- `models`: 表示対象となるプロバイダー、モデル、エンドポイントの組み合わせごとに1件
- `meters`: 単位、単位量、通貨、単価など、その項目の有効な計量行
- `display_name`: 料金ルールが正規の公開モデルに対応する場合に表示されるモデル名
