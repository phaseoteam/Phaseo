---

- `endpoints`: APIが現在公開している正規のエンドポイントID
- `data`: `public_path`、`collection`、`model_count`、`provider_count`を含むエンドポイントレコード
- `sample_models`: 公開カタログで最近表示されたモデルID（最大10件）

モデルごとのプロバイダーやパラメーターの詳細が必要な場合は、[モデルのエンドポイント機能を一覧表示](./model-endpoints.mdx)を使用してください。
