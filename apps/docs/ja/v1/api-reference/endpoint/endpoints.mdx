レスポンスには 3 つのフィールドがあります。

- `endpoints`: API が現在公開している正規のエンドポイント ID。
- `data`: エンドポイントごとに 1 つのレコード。`id`、`capability_id`、`public_path`、`collection`、`model_count`、`provider_count` を含み、`public_path` の順に並びます。
- `sample_models`: 公開カタログで表示されている最初の 10 個のモデル ID。

レスポンスは 30 分間キャッシュされます。

1 つのモデルについて、プロバイダーやパラメーター単位の詳細が必要な場合は、[モデルのエンドポイント機能を一覧表示](./model-endpoints)を使ってください。
