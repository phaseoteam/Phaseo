---
title: "プリセット公開者を更新"
sidebarTitle: "公開者を更新"
badge: "ベータ"
openapi: "/ja/openapi/v1/openapi.localized.yaml PUT /presets/publisher"
description: "ワークスペースの公開プリセット公開者ハンドルの名前を変更します。"
---
<Note>このエンドポイントには `presets:write` 権限を持つ管理APIキーと、関連付けられたユーザーIDが必要です。</Note>

既存の公開プリセット参照を引き続き解決できるよう、以前のハンドルはエイリアスとして保持されます。
