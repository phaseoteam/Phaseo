## CLI または API からクレジットを追加する

エージェントやスクリプトは、`POST /v1/credits/topups` または CLI でチャージを開始できます。請求は必ず人が承認します。

```bash
phaseo login --scopes billing:write
phaseo credits add --amount 20
```

- トークンには `billing:write` スコープが必要です。このスコープはデフォルトでは付与されません。`phaseo login --scopes billing:write` で追加するか、管理キーに指定してください。
- API または CLI からのチャージは $5〜$500 です。それより大きいチャージはダッシュボードで行います。ワークスペースで同時に保留できるのは 5 件までで（6 件目は `429` `too_many_pending_topups` を返します）、各チャージは 30 分で期限切れになります。
- **保存済みのカードがない場合:** レスポンスに `checkout_url` が含まれます。ワークスペースのオーナーまたは管理者がそれを開いて新しいカードで支払うと、そのカードは以降のチャージ用に保存されます。
- **保存済みのカードがある場合:** すべてのオーナーと管理者に 1 回限りのリンクがメールで届きます。そのうち 1 人がリンクを開いてサインインし、**確認** または **拒否** を選びます。確認するとカードに請求され、銀行が求める場合は本人確認が行われます。
- `final` が `true` になるまで `GET /v1/credits/topups/{id}`（または `phaseo credits topups get <id>`）をポーリングしてください。ステータスが `paid` になるとクレジットが追加されます。`declined`、`expired`、`failed` には `reason` コードが付きます。これらは自動で再試行せず、人に確認してください。
