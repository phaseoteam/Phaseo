## サーバーツール

`/v1/chat/completions` は通常の関数ツールに加え、次の Gateway 管理サーバーツールに対応しています。

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

### 日時の例

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Europe/London" }
      }
    ],
    "tool_choice": "auto"
  }'
```

サーバーツールを使用すると、使用量には次の項目が含まれます。

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` は `server_tool_use.web_search_requests`、`server_tool_use.web_search_results`、`server_tool_use.web_search_extra_results` を追加します。`phaseo:web_fetch` は `server_tool_use.web_fetch_requests` を追加します。

## ストリーミングに関する注意

`stream: true` にも対応しています。Gateway 管理サーバーツールでは、Phaseo が上流のツール呼び出しターンを処理し、ループを続行した後に合成ストリームを再送する場合があります。
