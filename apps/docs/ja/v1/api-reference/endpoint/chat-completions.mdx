## サーバーツールを使う

自分の関数ツールと並べて `tools` に `phaseo:` ツールを追加すると、モデルがそれを呼び出したときに Phaseo が実行します。`/v1/chat/completions` は `phaseo:apply_patch` を除くすべてのサーバーツールを受け付けます。一覧は[サーバーツール](../../guides/server-tools)ガイドにあります。

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["Europe/London"] } }
    ],
    "tool_choice": "auto"
  }'
```

サーバーツールの各呼び出しは `usage.server_tool_use` に計数されます。

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` は `web_search_requests`、`web_search_results`、`web_search_extra_results` を追加し、`phaseo:web_fetch` は `web_fetch_requests` を追加します。以前の `gateway:datetime` タイプも引き続き動作します。

`stream: true` の場合、Phaseo がツールのターンを自分で実行し、続きの回答を 1 つのストリームとして送信します。

## ツールループでの推論

推論モデルは、アシスタントメッセージの 2 つのフィールドで推論を返します。

- `reasoning_content`: プロバイダーが返す場合の推論テキスト。
- `reasoning_details`: 推論ブロックの配列。各エントリーには、`reasoning.text`、`reasoning.summary`、`reasoning.encrypted` のいずれかの `type`、`index`、プロバイダーの系統を示す `format`（例: `anthropic-claude-v1` や `google-gemini-v1`）があります。

エントリーには、ツールループの次のステップでモデルが必要とするプロバイダーの状態が含まれることがあります。

| プロバイダーの状態 | 場所 |
| --- | --- |
| Claude の思考の署名 | `reasoning.text` エントリーの `signature` |
| Claude の秘匿化された思考、OpenAI の暗号化された推論 | `reasoning.encrypted` エントリーの `data` |
| Gemini の思考の署名 | `id` が対応するツール呼び出しを示す `reasoning.encrypted` エントリーの `data` |

ストリーミングでは、各推論ブロックが完了するたびに `reasoning_details` のデルタが届きます。

ステップ間でモデルの推論を維持するには、アシスタントメッセージを `reasoning_details` を変更せずに送り返します。`signature` と `data` の値は不透明で、それを生成したプロバイダーとモデルを記録しています。Phaseo はこれらをそのプロバイダーの系統とモデルにのみ送信するため、別のプロバイダーにフォールバックした場合は失敗せずに除外されます。手動思考モードの Claude モデルがツールループ中に思考を続けるには、思考を送り返す必要があります。ない場合、そのステップは思考なしで実行されます。
