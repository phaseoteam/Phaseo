---

使用量ペイロードを送信すると、1 つのプロバイダー、モデル、エンドポイントについて、現在有効な Gateway の料金ルールで料金が計算されます。4 つのフィールドはすべて必須です。

- `provider`: プロバイダー ID（例: `openai`）。
- `model`: ルーティング先のモデル ID。
- `endpoint`: エンドポイントの種類（例: `responses` または `chat.completions`）。
- `usage`: 料金を計算する使用量（トークン数やその他の計量値など）。

1 つのペイロードの料金ではなく現在の料金を一覧表示するには、[モデルの料金を一覧表示](./pricing-models.mdx)を使ってください。
