<Note>ID 管理にはオーナーまたは管理者の ID が必要です。SSO または SCIM の有効化とプロビジョニングトークンの作成には、Identity アドオンが必要です。</Note>

SCIM プロビジョニングの変更と、そのトークンの作成・取り消しができるのはワークスペースのオーナーだけです。SCIM リクエストは、現在のワークスペースのオーナーが作成したトークンでのみ受け付けます。管理者や以前のオーナーが作成したトークンの場合は、オーナーが新しいトークンを作成する必要があります。
