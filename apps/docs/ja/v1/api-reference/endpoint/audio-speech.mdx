## 音声を選ぶ

プロバイダーをまたいで使えるリクエストにするには、トップレベルの `voice` を設定します。Phaseo はこれをルーティング先のプロバイダーの音声に対応付けます。ルーティング先のプロバイダーとモデルが受け付けない `voice` を指定すると、`param: "voice"` 付きで `400 invalid_request_error` が返されます。

| プロバイダー | 受け付ける `voice` の値 | サンプル |
| --- | --- | --- |
| `openai` | 一般的な音声。例: `alloy`、`ash`、`ballad`、`coral`、`echo`、`fable`、`onyx`、`nova`、`sage`、`shimmer`、`verse`、`cedar`、`marin` | [openai.fm](https://www.openai.fm/) |
| `google`（AI Studio / Gemini TTS） | 組み込みの音声: `Zephyr`、`Puck`、`Charon`、`Kore`、`Fenrir`、`Leda`、`Orus`、`Aoede`、`Callirrhoe`、`Autonoe`、`Enceladus`、`Iapetus`、`Umbriel`、`Algieba`、`Despina`、`Erinome`、`Algenib`、`Rasalgethi`、`Laomedeia`、`Achernar`、`Alnilam`、`Schedar`、`Gacrux`、`Pulcherrima`、`Achird`、`Zubenelgenubi`、`Vindemiatrix`、`Sadachbia`、`Sadaltager`、`Sulafat` | [Gemini の音声合成ドキュメント](https://ai.google.dev/gemini-api/docs/speech-generation#voices) |
| `elevenlabs` | 一般的な公開スターター音声。例: `rachel`、`domi`、`bella`、`antoni`、`elli`、`josh`、`arnold`、`adam`、`sam` | [ElevenLabs Voice Library](https://elevenlabs.io/voice-library) |

`eleven-labs/eleven-v4` と `eleven-labs/eleven-v4-turbo` では、カスタムのクローンを含め、20 文字の ElevenLabs ボイスライブラリ ID を指定できます。必要に応じて `config.elevenlabs.voice_settings.stability` と `similarity_boost` を設定してください。Eleven v4 は `speed` と `voice_settings.style` に対応していません。

## プロバイダー固有の音声を渡す

`voice` の代わりにプロバイダー独自の音声設定を使うには、次を指定します。

- ElevenLabs: `config.elevenlabs.voice_id`、`config.elevenlabs.voice`、または `config.elevenlabs.voiceName`。
- Google: `config.google.voice_name` または `config.google.voiceName`。
