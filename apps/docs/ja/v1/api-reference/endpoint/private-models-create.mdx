`private_models:write`権限と、所有者または管理者の認証情報が必要です。`model_reference`には、カタログの正確なモデルIDまたはワークスペース内の短いスラッグを指定します。Phaseoが最終的なモデルIDを割り当てます。`credential`は暗号化され、書き込み専用です。
