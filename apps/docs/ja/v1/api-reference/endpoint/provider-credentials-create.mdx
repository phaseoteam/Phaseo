description: "ワークスペースのルーティング用にプロバイダー認証情報を暗号化して保存します。"
---

<Warning>
`key`の値は書き込み専用です。Phaseoは直ちに暗号化し、APIレスポンスで返すことはありません。
</Warning>

`routing_mode: "priority"`を指定すると管理容量より先に認証情報を試し、`"fallback"`では後から試します。優先認証情報に失敗した際に管理容量へフォールバックできるかは、ワークスペース設定の`byokFallbackEnabled`で指定します。
