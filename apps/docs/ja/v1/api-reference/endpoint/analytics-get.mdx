sidebarTitle: "分析を取得"

openapi: "/ja/openapi/v1/openapi.localized.yaml GET /analytics"
description: "ワークスペースのコスト、リクエスト、トークンの集計を絞り込んで取得します。"
---
<Note>このエンドポイントには、`analytics:read`を持つ管理APIキーが必要です。</Note>

日付、リクエストラベル、APIキー、エンドユーザー、モデル、プロバイダー、エンドポイント、認証情報の取得元、結果で絞り込めます。結果は日付、モデル、プロバイダー、エンドポイント別にグループ化され、安定したページネーションで返されます。

期間は直近30日間の完了済みUTC日まで、元のリクエスト数は最大10,000件です。
