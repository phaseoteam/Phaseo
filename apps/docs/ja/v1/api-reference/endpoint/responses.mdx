## サーバーツール

`/v1/responses` は通常の関数ツールに加え、次の Gateway 管理サーバーツールに対応しています。

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`
- `phaseo:apply_patch`

### 日時の例

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "input": [
      { "role": "user", "content": "Give me the current datetime in Asia/Tokyo." }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Asia/Tokyo" }
      }
    ],
    "tool_choice": "auto"
  }'
```

サーバーツールを使用すると、使用量に対応する `usage.server_tool_use.*` カウンターが含まれます。

- `gateway:datetime` -> `datetime_requests`
- `phaseo:web_search` -> `web_search_requests`, `web_search_results`, `web_search_extra_results`
- `phaseo:web_fetch` -> `web_fetch_requests`
- `phaseo:advisor` -> `advisor_requests`
- `phaseo:image_generation` -> `image_generation_requests`
- `phaseo:apply_patch` -> `apply_patch_requests`

## ストリーミングに関する注意

`stream: true` にも対応しています。Gateway 管理サーバーツールでは、Phaseo が上流のツール呼び出しターンを処理し、ループを続行した後に合成ストリームを再送する場合があります。

## ツールループでの推論

Phaseo は Responses リクエストを `store: false` で上流に送ります。そのため、ツールループのステップ間でモデルの推論が続くのは `reasoning` 出力アイテムを通じた場合だけです。

各 `reasoning` アイテムには `id`、`summary`、`content` があります。プロバイダーが推論の状態を返した場合、アイテムには `encrypted_content` も含まれます。

- OpenAI、Azure OpenAI、xAI の暗号化された推論。Phaseo は推論モデルに対して `include: ["reasoning.encrypted_content"]` で要求します。
- Claude の thinking 署名と秘匿された thinking。
- Gemini の思考署名。署名が属する関数呼び出しの直前に置かれる専用の `reasoning` アイテムも含みます。

ストリーミングのレスポンスでは、同じアイテムが `response.output_item.done` と `response.completed` に含まれます。

ツールループを続けるには、`reasoning` アイテムを含むすべての出力アイテムを変更せずに `input` で送り返してください。`encrypted_content` は不透明で、生成したプロバイダーとモデルを記録しています。Phaseo はそのプロバイダーファミリーとモデルにだけ送るため、別のプロバイダーへのフォールバックでは失敗せずに破棄されます。
