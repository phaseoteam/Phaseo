## サーバーツールを使う

自分の関数ツールと並べて `tools` に `phaseo:` ツールを追加すると、モデルがそれを呼び出したときに Phaseo が実行します。`/v1/responses` は、このエンドポイントだけが対応する `phaseo:apply_patch` を含め、すべてのサーバーツールを受け付けます。一覧は[サーバーツール](../../guides/server-tools)ガイドにあります。

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": [
      { "role": "user", "content": "Give me the current datetime in Asia/Tokyo." }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["Asia/Tokyo"] } }
    ],
    "tool_choice": "auto"
  }'
```

サーバーツールの各呼び出しは `usage.server_tool_use` に計数されます。

| ツール | カウンター |
| --- | --- |
| `phaseo:datetime` | `datetime_requests` |
| `phaseo:web_search` | `web_search_requests`、`web_search_results`、`web_search_extra_results` |
| `phaseo:web_fetch` | `web_fetch_requests` |
| `phaseo:advisor` | `advisor_requests` |
| `phaseo:subagent` | `subagent_requests` |
| `phaseo:fusion` | `fusion_requests` |
| `phaseo:search_models` | `search_models_requests` |
| `phaseo:image_generation` | `image_generation_requests` |
| `phaseo:apply_patch` | `apply_patch_requests` |

以前の `gateway:datetime` タイプも引き続き動作します。`stream: true` の場合、Phaseo がツールのターンを自分で実行し、続きの回答を 1 つのストリームとして送信します。

## ツールループでの推論

OpenAI、Azure OpenAI、xAI では、Phaseo は Responses リクエストを `store: false` で上流に送信するため、ツールループのステップ間でモデルの推論が引き継がれるのは `reasoning` 出力アイテムを通じてのみです。

各 `reasoning` アイテムには `id`、`summary`、`content` があります。プロバイダーが推論の状態を返す場合、アイテムには `encrypted_content` も含まれ、次のいずれかが入ります。

- OpenAI、Azure OpenAI、xAI の暗号化された推論。推論モデルでは、Phaseo が `include: ["reasoning.encrypted_content"]` で要求します。
- Claude の思考の署名と秘匿化された思考。
- Gemini の思考の署名。署名が属する関数呼び出しの直前に置かれる、別の `reasoning` アイテムも含みます。
- Claude の返信が実行された度合い。出力の最後の `reasoning` アイテムに入り、テキストはありません。

ストリーミングのレスポンスでは、同じアイテムが `response.output_item.done` と `response.completed` で届きます。

<Warning>
ツールループに限らず、すべてのリクエストで、すべての出力アイテムを変更せずに `input` で送り返してください。`encrypted_content` の有無にかかわらず、テキストのないアイテムも含め、`reasoning` アイテムを削除、編集、並べ替えしないでください。
</Warning>

`encrypted_content` は不透明で、それを生成したプロバイダーとモデルを記録しています。Phaseo はこれをそのプロバイダーの系統とモデルにのみ送信するため、別のプロバイダーにフォールバックした場合は失敗せずに除外されます。これがないと、Claude はツールループのステップ間で推論を失い、`reasoning.effort` を変更すると Claude のプロンプトキャッシュがやり直しになります。[会話の途中で推論の度合いを変える](../../guides/reasoning-effort)を参照してください。
