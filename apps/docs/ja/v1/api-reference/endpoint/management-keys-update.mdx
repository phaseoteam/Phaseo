---
title: "管理キーを更新"
sidebarTitle: "管理キーを更新"
badge: "ベータ"
openapi: "/ja/openapi/v1/openapi.localized.yaml PATCH /management-keys/{id}"
description: "管理キーのスコープ、上限、有効期限、名前、一時停止状態を更新します。"
---
<Note>このエンドポイントにはオーナーまたは管理者のIDと `management_keys:write` が必要です。</Note>

呼び出し元が保有していないスコープは付与できません。省略したフィールドは現在の値を維持します。
