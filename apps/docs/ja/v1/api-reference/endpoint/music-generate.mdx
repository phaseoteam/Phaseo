`model` と `prompt` を `POST /v1/music/generate` に送信すると、1 つのリクエスト形式でどの音楽プロバイダーからでもトラックを取得できます。同期型のプロバイダーへの対応や、プロバイダーのキューのポーリングは Phaseo が行います。

```bash
curl https://api.phaseo.app/v1/music/generate \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax/music-3.0:free",
    "prompt": "Warm jazz trio with brushed drums",
    "format": "mp3"
  }'
```

## 結果を読む

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "gmicloud",
  "model": "minimax/music-3.0:free",
  "nativeResponseId": "5c30b275-d669-4a25-8151-de6d60214853",
  "audio_url": "https://.../generated-music.mp3",
  "usage": {
    "requests": 1,
    "output_audio_seconds": 25.364
  }
}
```

完了した生成には `audio_url` または `audio_base64` が含まれます。`status` は `queued`、`in_progress`、`completed`、`failed` のいずれかです。まだ最終状態でない場合は、同じ `id` で [`GET /v1/music/generate/{music_id}`](./music-status.mdx) をポーリングしてください。

`id` は Phaseo の固定のリクエスト ID です。`nativeResponseId` は上流プロバイダーの識別子で、プロバイダー側との照合やサポートに使います。プロバイダーが生成された長さを報告する場合、`usage` に `output_audio_seconds` が含まれます。

## Suno のオプションを設定する

Suno のモデルは、任意の `suno` オブジェクトを受け付けます。

| フィールド | 型 | 備考 |
| --- | --- | --- |
| `customMode` | boolean | デフォルト `false` |
| `instrumental` | boolean | デフォルト `false` |
| `prompt` | string | トップレベルの `prompt` を上書きします |
| `style`、`title` | string | `customMode` が `true` の場合は必須 |
| `personaId`、`personaModel` | string | |
| `negativeTags` | string | |
| `vocalGender` | `m` または `f` | |
| `styleWeight`、`weirdnessConstraint`、`audioWeight` | number | 0〜1 |

`prompt` は、`customMode` が `false` の場合と、`customMode` が `true` で `instrumental` が `false` の場合に必須です。

プロバイダーのルールに違反するリクエストは `400` を返します。

```json
{
  "error": "validation_error",
  "reason": "..."
}
```
