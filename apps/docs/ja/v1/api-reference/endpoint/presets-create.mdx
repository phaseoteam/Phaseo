<Note>このエンドポイントには `presets:write` 権限を持つ管理APIキーと、関連付けられたユーザーIDが必要です。</Note>

プリセットには、制限付きのプロンプト、パラメーター、ルーティング、プラグインのデフォルト値を含められます。公開プリセットではワークスペースの公開者ハンドルを使います。
