<Note>管理キーまたは OAuth トークンの `keys:write`、もしくはワークスペースのオーナーまたは管理者が必要です。信頼済みワークロードはベータ版で、利用できないワークスペースには `404` が返ります。</Note>

ポリシーの仕組みと Terraform での管理方法は、[信頼済みワークロード](../../developers/trusted-workloads.mdx)を参照してください。
