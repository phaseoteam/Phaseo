description: "コントロールプレーンの自動化に使う、スコープ付き管理キーを作成します。"
---
<Note>このエンドポイントには、オーナーまたは管理者のIDと`management_keys:write`が必要です。</Note>

機能テンプレートを選ぶか、スコープの一覧を明示してください。生の`key`は作成レスポンスでのみ返されるため、すぐにサーバー側のシークレットストレージへ保存してください。
