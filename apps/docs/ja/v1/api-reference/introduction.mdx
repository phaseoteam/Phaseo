エンドポイントリファレンスを開く前に、このページで適切な API パスを確認してください。Phaseo Gateway のすべてのエンドポイントは共通のベース URL を使用し、Bearer 認証を使います。

## パスを選ぶ

| 目的 | 参照先 |
| --- | --- |
| 最初のリクエストを送信する | [クイックスタート](../quickstart.mdx) |
| テキストを生成する、またはツールを使う | `POST /responses` |
| 型付きの判断を行う | [`POST /decisions`](./endpoint/decisions) |
| 既存の OpenAI 互換連携を維持する | `POST /chat/completions` |
| モデルとプロバイダーを確認する | `GET /models` と `GET /providers` |
| 音楽を作成する、またはファイルを管理する | `POST /music/generations` と `POST /files` |
| 動画を生成（ベータ） | [`POST /videos`](./endpoint/video-create) |
| バッチ送信または結果のダウンロード（ベータ） | [`POST /batches`](./endpoint/batches-create) と [`GET /batches/{batch_id}/results`](./endpoint/batches-results) |

## ベース URL

本番環境のベース URL:

```http
https://api.phaseo.app/v1
```

このリファレンスのエンドポイントパスは、すべてベース URL `/v1` からの相対パスです。

## OpenAPI

OpenAPI ファイルを使うと、Postman、Hoppscotch、SDK ジェネレーターに API をインポートできます。

ドキュメントとSDKは同じ仕様を使います。Video、Batch、Decisionsのエンドポイントは**ベータ**で、ワークスペースのプレビューアクセスが必要な場合があります。
## 認証

推論には標準のGateway APIキー、管理には適切な権限を持つ管理APIキーを使います。[認証](../developers/authentication.mdx)と[管理APIキー](../developers/management-api-keys.mdx)を参照してください。

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

認証に失敗すると、API は `401` を返します。

## API リソース

| リソース | 機能 |
| --- | --- |
| 推論 | テキスト、画像、音声、埋め込みを生成し、判断、再ランキング、モデレーション、解析を行います。[Responses](./endpoint/responses.mdx)または[Decisions](./endpoint/decisions.mdx)から始めてください。 |
| 非同期ジョブとファイル | [動画](./endpoint/video-create.mdx)または[バッチ](./endpoint/batches-create.mdx)ジョブを送信し、ファイル転送とWebhook設定を行います。 |
| モデルと料金 | [モデル](./endpoint/models.mdx)、プロバイダーの提供内容、[推定コスト](./endpoint/pricing-calculate.mdx)を確認します。 |
| ルーティングとポリシー | プリセット、プロバイダー認証情報、プライベートモデル、[ガードレール](./endpoint/guardrails.mdx)を設定します。 |
| 使用量と監視 | [ログ](./endpoint/logs-list.mdx)、アクティビティ、分析、評価、サービスの状態を確認します。 |
| ワークスペース管理 | [ワークスペース](./endpoint/workspaces-list.mdx)、キー、予算、ID、連携を管理します。 |

## 課金とレート制限

- [レート制限ガイド](./limits.mdx)でプロバイダーの制限と適用されるアクセスポリシーを確認してください。
- 有料リクエストでは、事前のクレジット確認に通るだけのウォレット残高が必要です。
- `:free` を含む無料モデルでは、入金済みクレジットは不要です。
