すべてのリクエストを `https://api.phaseo.app/v1` に送信し、キーを `Authorization: Bearer` ヘッダーに入れます。下の表で目的に合うエンドポイントを見つけ、そのリファレンスページを開いてください。

## 適切なエンドポイントを見つける

| 目的 | 参照先 |
| --- | --- |
| 最初のリクエストを送信する | [クイックスタート](../quickstart) |
| テキストを生成する、またはツールを使う | [`POST /responses`](./endpoint/responses) |
| 型付きの判断を行う | [`POST /decisions`](./endpoint/decisions) |
| 既存の OpenAI 互換連携を維持する | [`POST /chat/completions`](./endpoint/chat-completions) |
| モデルとプロバイダーを確認する | [`GET /models`](./endpoint/models) と [`GET /providers`](./endpoint/providers) |
| 音楽を作成する、またはファイルを管理する | [`POST /music/generate`](./endpoint/music-generate) と [`POST /files`](./endpoint/files) |
| 動画を生成する（ベータ） | [`POST /videos`](./endpoint/video-create) |
| バッチを送信する、または結果をダウンロードする（ベータ） | [`POST /batches`](./endpoint/batches-create) と [`GET /batches/{batch_id}/results`](./endpoint/batches-results) |

## ベース URL

```http
https://api.phaseo.app/v1
```

このリファレンスのエンドポイントパスは、すべてこのベース URL からの相対パスです。

## OpenAPI

OpenAPI ファイルを Postman、Hoppscotch、または SDK ジェネレーターにインポートします。

## 認証

| 認証情報 | 形式 | 呼び出せるもの |
| --- | --- | --- |
| [Gateway API キー](../developers/authentication.mdx) | `phaseo_v1_sk_<kid>_<secret>` | 推論エンドポイント |
| [管理 API キー](../developers/management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | 管理エンドポイント（キーの権限の範囲内） |

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

認証に失敗すると、API は `401` を返します。

## API リソース

| リソース | 機能 |
| --- | --- |
| 推論 | テキスト、画像、音声、埋め込みを生成し、判断、再ランキング、モデレーション、解析を行います。[Responses](./endpoint/responses.mdx) または [Decisions](./endpoint/decisions.mdx) から始めてください。 |
| 非同期ジョブとファイル | [動画](./endpoint/video-create.mdx)または[バッチ](./endpoint/batches-create.mdx)ジョブを送信し、ファイルを転送し、Webhook を設定します。 |
| モデルと料金 | [モデル](./endpoint/models.mdx)、プロバイダーの提供内容、[推定コスト](./endpoint/pricing-calculate.mdx)を確認します。 |
| ルーティングとポリシー | プリセット、プロバイダー認証情報、プライベートモデル、[ガードレール](./endpoint/guardrails.mdx)を設定します。 |
| 使用量と監視 | [ログ](./endpoint/logs-list.mdx)、アクティビティ、分析、評価、サービスの状態を確認します。 |
| ワークスペース管理 | [ワークスペース](./endpoint/workspaces-list.mdx)、キー、予算、ID、連携を管理します。 |

## 課金とレート制限

有料リクエストは、実行前のクレジット確認に通るだけのウォレット残高が必要です。ID が `:free` で終わるモデルには、入金済みクレジットは不要です。リクエストはプロバイダー、またはワークスペースとキーの制限によってスロットリングされることがあります。[レート制限](./limits.mdx)を参照してください。
