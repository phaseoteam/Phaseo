<Update label="2026年10月24日" tags={["製品"]} rss={{ title: "2026年10月24日: 製品" }}>

- 提供終了モデルのルーティングをすべてのワークスペースで利用できるようになりました。提供終了したモデルを提供するプロバイダーがなくなったとき、そのリクエストを失敗させずに承認済みの後継モデルへ送れます。初期設定ではオフです。オーナーと管理者が **設定 -> ルーティング -> 提供終了モデルのルーティング** でオンにし、後継モデルの料金が高くなってもよいかを選びます。リダイレクトされたレスポンスには `x-phaseo-model-substitution` ヘッダーが付きます。詳しくは[モデルの非推奨化と提供終了](./guides/model-retirement.mdx)をご覧ください。

</Update>

<Update label="2026年10月9日" tags={["製品"]} rss={{ title: "2026年10月9日: 製品" }}>

- チャットに、任意で有効にできるインタラクティブな回答の実験機能を追加しました。一時チャットの隣から切り替えられ、比較カード、表、棒グラフ、フォローアップフォームに対応しています。フォームの値は回答の各バリエーションに保存され、送信すると会話が続きます。

</Update>
