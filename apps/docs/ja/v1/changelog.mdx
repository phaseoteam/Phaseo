<Update label="2026年10月28日">

<div data-changelog-category="api">

<p className="changelog-category">API と SDK</p>

- `/v1/embeddings` は、構造化入力のフィールドがネストしたオブジェクトや配列の場合に `400 validation_error` を返します。以前は `502` を返していました ([#3296](https://github.com/phaseoteam/Phaseo/pull/3296))。
- すべてのプロバイダーが同じ `400`、`413`、`422` でリクエストを拒否した場合、ゲートウェイは `502` ではなくそのステータスとプロバイダーのメッセージを返します ([#3296](https://github.com/phaseoteam/Phaseo/pull/3296))。
- API キーの支出上限による `429` エラーは `$0.0117 of $0.01` のようにドル金額を表示し、月間上限でも `Retry-After` ヘッダーが残ります ([#3296](https://github.com/phaseoteam/Phaseo/pull/3296))。

</div>

</Update>

<Update label="2026年10月27日">

<div data-changelog-category="product">

<p className="changelog-category">製品</p>

</div>

<div data-changelog-category="api">

<p className="changelog-category">API と SDK</p>

- プリセットを使うリクエストは `prompt.version` または `model: "@slug@label"` でバージョンやラベルを固定でき、存在しない指定には `404 preset_version_not_found` を返します。詳しくは[プロンプトテンプレート](./guides/prompt-templates.mdx)をご覧ください ([#3281](https://github.com/phaseoteam/Phaseo/pull/3281))。
- `GET`、`PUT`、`DELETE /v1/presets/{id}/labels` でプリセットのラベルを一覧、移動、削除できます。詳しくは[Set preset label](./api-reference/endpoint/presets-label-set.mdx)をご覧ください ([#3283](https://github.com/phaseoteam/Phaseo/pull/3283))。
- Chat Completions、Responses、Messages のストリーミングイベントの `model` に Phaseo のモデル ID が入るようになりました。以前は一部にプロバイダー独自の ID が入っていました ([#3273](https://github.com/phaseoteam/Phaseo/pull/3273))。
- `GET /oauth/userinfo` は、`profile` スコープを持つトークンに対して Phaseo のプロフィールから `picture`、`name`、`given_name` を返します ([#3189](https://github.com/phaseoteam/Phaseo/pull/3189))。

</div>

</Update>

<Update label="2026年10月23日">

<div data-changelog-category="product">

<p className="changelog-category">製品</p>

- オーナーと管理者は **設定 -> レート制限** で、1 分あたりのリクエスト数、1 分あたりのトークン数、同時リクエスト数、**厳格モード** を持つレート制限ポリシーを作成できます。詳しくは[レート制限](./api-reference/limits.mdx)をご覧ください ([#3150](https://github.com/phaseoteam/Phaseo/pull/3150), [#3213](https://github.com/phaseoteam/Phaseo/pull/3213))。
- **設定 -> レート制限** では、ポリシーを API キー、メンバー、部門、ガードレール、またはエンドユーザーの既定値に割り当て、過去 24 時間に制限したリクエスト数を確認できます ([#3150](https://github.com/phaseoteam/Phaseo/pull/3150))。
- オーナーと管理者は **設定 -> 予算** で部門ごとの日次、週次、月次予算を追加できます。予算は 80% と 100% でアラートを送り、リクエストをブロックすることはありません ([#3208](https://github.com/phaseoteam/Phaseo/pull/3208))。
- キーのセキュリティは **設定 -> APIキー -> キーのセキュリティ** に移り、キーの表に **Status** 列と並べ替え可能な列が追加されました ([#3184](https://github.com/phaseoteam/Phaseo/pull/3184))。
- Broadcast は、Amazon S3 と S3 互換ストレージ、Cloudflare R2、Google Cloud Storage、ClickHouse、BigQuery、Snowflake にトレースを送れます。詳しくは[Broadcast](./guides/broadcast.mdx)をご覧ください ([#3181](https://github.com/phaseoteam/Phaseo/pull/3181), [#3182](https://github.com/phaseoteam/Phaseo/pull/3182), [#3185](https://github.com/phaseoteam/Phaseo/pull/3185))。
- 新しいガイド: [Broadcast](./guides/broadcast.mdx) に、すべての送信先タイプの設定をまとめました ([#3190](https://github.com/phaseoteam/Phaseo/pull/3190))。
- 比較ページに、各モデルの Phaseo 経由のトークン数とリクエスト数を示す 30 日間の **Activity** グラフが追加されました ([#3147](https://github.com/phaseoteam/Phaseo/pull/3147))。
- 比較ページに、能力指数での各モデルの順位が表示されます ([#3148](https://github.com/phaseoteam/Phaseo/pull/3148))。
- 2 モデルの比較に、`/compare/anthropic_claude-opus-5.5-vs-openai_gpt-6-astra` のような概要と FAQ 付きの専用ページができました ([#3162](https://github.com/phaseoteam/Phaseo/pull/3162))。

</div>

- EU と US のリージョナルゲートウェイを通るリクエストも Broadcast の送信先に届くようになりました ([#3187](https://github.com/phaseoteam/Phaseo/pull/3187))。

<div data-changelog-category="api">

<p className="changelog-category">API と SDK</p>

- `/v1/messages` は、Claude が許可する位置であれば会話途中の `role: "system"` メッセージを受け付けます。詳しくは[メッセージを作成](./api-reference/endpoint/anthropic-messages.mdx)をご覧ください ([#3165](https://github.com/phaseoteam/Phaseo/pull/3165))。
- キーのエンドポイントとすべての SDK が、キーの保管場所を最大 8 件まで示す `storage_locations` (例: `["railway", "github"]`) を受け付けて返します。詳しくは[APIキーを作成](./api-reference/endpoint/keys-create.mdx)をご覧ください ([#3164](https://github.com/phaseoteam/Phaseo/pull/3164))。
- **ベータ:** `/v1/department-budgets` は部門ごとに日次、週次、月次の USD 予算を設定し、約 80% と 100% でオーナーと管理者に通知しますが、リクエストはブロックしません ([#3125](https://github.com/phaseoteam/Phaseo/pull/3125))。
- ゼロデータ保持は、ワークスペース設定、キーのガードレール、リクエストのいずれで指定された場合も、リクエストをレスポンスキャッシュ、データサンプル、Phaseo のテレメトリから除外します ([#3161](https://github.com/phaseoteam/Phaseo/pull/3161), [#3175](https://github.com/phaseoteam/Phaseo/pull/3175))。
- カスタム Webhook への通知配信は `x-phaseo-timestamp` と `x-phaseo-signature` (HMAC-SHA256) で署名されます。詳しくは[ワークスペース通知](./guides/workspace-notifications.mdx)をご覧ください ([#3089](https://github.com/phaseoteam/Phaseo/pull/3089))。
- Broadcast は、リクエストの `metadata` を `phaseo.metadata.<key>` スパン属性としてエクスポートします ([#3127](https://github.com/phaseoteam/Phaseo/pull/3127))。
- リクエストの `metadata` にある `trace_name`、`span_name`、`generation_name`、`trace_id` で、Broadcast がエクスポートするトレースに名前を付けたりグループ化したりできます ([#3127](https://github.com/phaseoteam/Phaseo/pull/3127))。

</div>

- 比較ページは、各行の最良値を強調する 1 つのグループ化された表になり、違いのある行だけを表示する切り替えがあります ([#3116](https://github.com/phaseoteam/Phaseo/pull/3116))。

<div data-changelog-category="api">

<p className="changelog-category">API と SDK</p>

- **破壊的変更:** エラーレスポンスは `error` を `code`、`message`、`type`、`param`、`metadata` を持つオブジェクトとして返します。`error` を文字列として読んでいたコードは、新しいトップレベルの `code` を読んでください。詳しくは[エラーとデバッグ](./api-reference/errors.mdx)をご覧ください ([#3055](https://github.com/phaseoteam/Phaseo/pull/3055))。
- Chat Completions、Responses、Messages、embeddings のレスポンスに、USD 建ての `usage.cost` と内訳の `usage.cost_details` が含まれます ([#3050](https://github.com/phaseoteam/Phaseo/pull/3050))。
- `POST /v1/keys` は新しいシークレットをトップレベルの `key` として返します。詳しくは[APIキーを作成](./api-reference/endpoint/keys-create.mdx)をご覧ください ([#3050](https://github.com/phaseoteam/Phaseo/pull/3050))。
- テキストエンドポイントは、任意パラメーターへの明示的な `null`、`service_tier: "auto"` と `"scale"`、`prediction` など、以前は `400` を返していた入力を受け付けます ([#3049](https://github.com/phaseoteam/Phaseo/pull/3049))。
- `web` と `web-fetch` プラグインは、Phaseo の Web 検索と Web 取得のサーバーツールとして、どのモデルでも動作します。詳しくは[Web検索サーバーツール](./guides/server-tools/web-search.mdx)をご覧ください ([#3051](https://github.com/phaseoteam/Phaseo/pull/3051))。
- レート制限ポリシーは `tokens_per_minute` を適用し、`x-ratelimit-limit-tokens`、`x-ratelimit-remaining-tokens`、`x-ratelimit-reset-tokens` ヘッダーを返します。詳しくは[レート制限](./api-reference/limits.mdx)をご覧ください ([#2961](https://github.com/phaseoteam/Phaseo/pull/2961))。
- 部門に割り当てたレート制限ポリシーが、その部門のリクエストに適用されるようになりました ([#3088](https://github.com/phaseoteam/Phaseo/pull/3088))。
- プロンプトキャッシュの書き込みは、Claude の 1 時間の書き込みで入力の 2 倍、OpenAI の 12 時間の書き込みで入力の 2.5 倍という公開料金で課金されます。詳しくは[プロンプトキャッシュ](./guides/prompt-caching.mdx)をご覧ください ([#3078](https://github.com/phaseoteam/Phaseo/pull/3078), [#3076](https://github.com/phaseoteam/Phaseo/pull/3076))。
- Responses の usage は、30 分と 12 時間のキャッシュ書き込みの内訳を `input_tokens_details.cache_write_tokens_details` で返します ([#3078](https://github.com/phaseoteam/Phaseo/pull/3078))。

- `/v1/batches/models` に Gemini のバッチオファーが表示されます ([#2936](https://github.com/phaseoteam/Phaseo/pull/2936))。
