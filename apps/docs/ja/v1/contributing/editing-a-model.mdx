---

モデルの修正や未掲載の項目の追加を依頼するには、GitHub の Issue を作成してください。JSON の編集やリポジトリのセットアップは不要です。

## 修正を報告

1. モデルの Phaseo ページの URL またはモデル ID をコピーしてください。
2. [誤った情報を報告](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml)し、現在の値と修正案を記載してください。
3. 公式ドキュメント、リリース発表、またはその他の検証可能な情報源を添えてください。

料金については、プロバイダー、通貨、課金単位、該当する料金区分、適用開始日を記載してください。ベンチマークのスコアについては、[スコアの提出](../research/submitting-scores.mdx)に従ってください。

## 未掲載のモデルを依頼

モデル名、組織、公式リンク、リリース日、既知の機能を記載して、[データの追加を依頼](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml)してください。対応する Gateway ルートが利用可能になる前に、モデルがカタログに掲載される場合があります。

## 提出後

メンテナーが根拠を確認し、内部エディターでデータベースを更新します。質問や公開状況は Issue で確認してください。毎日の JSON スナップショットはカタログのエクスポートです。アーカイブ済みの JSON ファイルを変更しても、公開中のサイトは更新されません。

管理者は[内部データ](https://phaseo.app/internal/data)でレコードを編集し、[プロバイダーの更新](https://phaseo.app/internal/data/imports)で提案された料金を確認できます。これらのページには管理者権限が必要です。
