モデルデータは `packages/data/catalog/src/data/models` 以下のJSONファイルにあります。 各モデルには専用のフォルダーと `model.json` ファイルがあります。

## 1. モデルを探す

プロバイダー名とモデル名からモデルのディレクトリを探します。例:

`packages/data/catalog/src/data/models/openai/gpt-5-2025-08-07/model.json`

## 2. 変更する

よくある更新内容:

- 説明とリンク
- 機能と対応エンドポイント
- 料金や提供状況に関する注記
- ベンチマークの参照情報

近くのファイルで使われている既存のスキーマに合わせて値を設定してください。

## 3. データを検証

PRを作成する前に、データ検証スクリプトを実行してください:

```bash
pnpm validate:data
```

## 4. PRを作成

変更内容と使用した情報源を簡潔に記載してください。
