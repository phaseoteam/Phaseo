---

組織情報の不足や古い情報は GitHub の Issue で報告してください。メンテナーが根拠を確認し、承認した変更をデータベースエディターで適用します。

## 修正を報告

1. 組織の Phaseo ページの URL または ID をコピーしてください。
2. [誤った情報を報告](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml)し、該当するフィールドと提案する値を記載してください。
3. 公式サイト、発表、またはその他の検証可能な情報源へのリンクを添えてください。

よくある修正内容には、名称、説明、ウェブサイト、所在地、モデルや API プロバイダーとの関係があります。

## 未掲載の組織を依頼

組織名、公式サイト、関連するモデルやプロバイダーへのリンクを記載して、[データの追加を依頼](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml)してください。

## 提出後

レビューと公開状況は Issue で確認してください。カタログのレコード変更には、JSON の編集やプルリクエストは不要です。毎日の JSON ファイルはエクスポートであり、稼働中のデータベースにはインポートされません。

管理者は[内部カタログエディター](https://phaseo.app/internal/data)で組織を管理します。このエディターには管理者権限が必要です。
