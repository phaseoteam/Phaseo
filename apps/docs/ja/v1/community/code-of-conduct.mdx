Phaseo は、GitHub の Issue とプルリクエスト、Discord、その他すべてのコミュニティスペースで [Contributor Covenant](https://github.com/phaseoteam/Phaseo/blob/main/CODE_OF_CONDUCT.md) に従います。親切に、敬意を持って、ほかの考え方を受け入れてください。

ハラスメントやその他の容認できない行動は、`support@phaseo.app` または [Discord](https://discord.gg/aQyywCvgZ5) のモデレーターに報告してください。報告はコミュニティのリーダーが確認し、報告者の身元は非公開に保たれます。

例や執行手順を含む全文は [`CODE_OF_CONDUCT.md`](https://github.com/phaseoteam/Phaseo/blob/main/CODE_OF_CONDUCT.md) にあります。貢献のルールは [`CONTRIBUTING.md`](https://github.com/phaseoteam/Phaseo/blob/main/CONTRIBUTING.md) にあります。
