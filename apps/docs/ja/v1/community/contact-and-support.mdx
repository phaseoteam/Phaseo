アカウント、請求、API、フィードバックに関する質問は、まず [Phaseo ヘルプセンター](https://phaseo.app/help)から送ってください。チームが各リクエストを適切な窓口に振り分けます。

| 目的 | 窓口 |
| --- | --- |
| アカウント、請求、失敗したリクエストについてサポートを受ける | [ヘルプセンター](https://phaseo.app/help) |
| バグを報告する | [ヘルプセンター](https://phaseo.app/help)、または GitHub の[バグレポート](https://github.com/phaseoteam/Phaseo/issues/new?template=bug.yml) |
| カタログデータを修正する | [貢献](../contributing/overview) |
| セキュリティの脆弱性を報告する | [GitHub リポジトリ](https://github.com/phaseoteam/Phaseo)の **Security -> Report a vulnerability** から非公開で報告するか、`security@phaseo.app` に送ってください。公開の場には投稿しないでください。 |
| コミュニティに質問する | [Discord](https://discord.gg/aQyywCvgZ5) |

## バグレポートに含める情報

- リクエスト ID：レスポンスの `id`（`G-...`）、エラーの `generation_id`、または `x-request-id` レスポンスヘッダー。
- 送信した内容（API キーは削除してください）と、期待した結果。
- レスポンス本文のエラーコードとメッセージ。各コードの意味は[エラーリファレンス](../api-reference/errors)で説明しています。
- 関連するログ（認証情報と顧客データは削除してください）。
