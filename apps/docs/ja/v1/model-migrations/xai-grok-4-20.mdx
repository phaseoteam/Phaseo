モデル ID を変更し、検証セットを再実行します。リクエストとレスポンスの形式は変わりません。新しい制御は、マルチエージェント版がどこまで深く作業するかだけです。

| モデル | Phaseo のモデル ID | 推論の制御 |
| --- | --- | --- |
| Grok 4.20 | `spacex-ai/grok-4.20` | `reasoning.enabled`: オンまたはオフ |
| Grok 4.20 Multi-Agent(ベータ版) | `spacex-ai/grok-4.20-multi-agent-beta` | `reasoning.effort`: `low`、`medium`、`high` |

## Grok 4.20 で推論を切り替える

推論版のモデルを使うには `reasoning.enabled: true` を設定します。設定しない場合や `false` の場合、Phaseo は非推論版を呼び出します。

```json
{
  "model": "spacex-ai/grok-4.20",
  "input": "Explain this architecture",
  "reasoning": { "enabled": true }
}
```

## マルチエージェントモデルで深さを設定する

深さは `reasoning.effort` で制御します。Gateway のリクエストでは xAI の `agent_count` は受け付けません。xAI によると、`low` と `medium` では 4 つのエージェントが動作し、`high` ではより大きな構成が動作します。

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": { "effort": "medium" }
}
```
