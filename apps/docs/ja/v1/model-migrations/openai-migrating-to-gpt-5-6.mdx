ワークロードに合った GPT-5.6 のティアを選び、モデル ID だけを差し替えて、推論の effort、ツール、レイテンシー、コストを再テストします。評価に合格するまでは、以前の GPT-5 モデルをフォールバックとして残しておきます。

## ティアを選ぶ

| モデル | 用途 | 推論の effort |
| --- | --- | --- |
| `openai/gpt-5.6-sol` | 最高性能の推論、エージェントによるコーディング、科学的な分析、複雑な専門業務 | `none`、`low`、`medium`、`high`、`xhigh`、`max` |
| `openai/gpt-5.6-terra` | バランスの取れた日常的な推論、コーディング、アシスタント業務 | `none`、`low`、`medium`、`high`、`xhigh`、`max` |
| `openai/gpt-5.6-luna` | 低レイテンシーでコストを重視する作業 | `none`、`low`、`medium`、`high`、`xhigh`、`max` |

3 つとも、コンテキストウィンドウは 1,050,000 トークン、出力は 128K トークンです。それぞれに Pro の ID(`openai/gpt-5.6-sol-pro`、`-terra-pro`、`-luna-pro`)もあり、自動で `reasoning.mode: "pro"` を送ります。

OpenAI 自身の `gpt-5.6` エイリアスは `gpt-5.6-sol` を指します。Phaseo では、ティアの ID を直接呼び出してください。ティアのエイリアス `openai/gpt-sol-latest`、`openai/gpt-terra-latest`、`openai/gpt-luna-latest` は各ティアの最新モデルを指し、`openai/gpt-sol-latest` はすでに GPT-5.6 より新しいモデルを指しています。今後のリリースに自動で移行したい場合にのみ使ってください。

## リクエストを更新する

GPT-5.6 では、すべてのティアに最も大きな推論の予算である `max` が追加されました。追加のレイテンシーとコストに見合う場合にのみ使ってください。

<CodeGroup>
```json Responses
{
  "model": "openai/gpt-5.6-sol",
  "input": "Review this multi-service incident report and propose a rollback plan.",
  "reasoning": { "effort": "max" }
}
```

```json Chat Completions
{
  "model": "openai/gpt-5.6-terra",
  "messages": [
    { "role": "user", "content": "Design a test plan for this agent workflow." }
  ],
  "reasoning_effort": "medium"
}
```
</CodeGroup>

GPT-5.6 では次の機能も追加されています。

- **`reasoning.mode: "pro"`**: モデルを切り替えずに、より難しいタスクに対応します。
- **`reasoning.context`**(`auto`、`current_turn`、`all_turns`): どの推論を保持するかを制御します。
- ツールを多用するワークフロー向けの、ベータ版のマルチエージェント対応と Programmatic Tool Calling。
- `prompt_cache_options` とキャッシュブレークポイントによる明示的なプロンプトキャッシュ。GPT-5.6 では `prompt_cache_options.ttl` が `prompt_cache_retention` に代わります。Phaseo は `prompt_cache_retention` を GPT-5.6 モデルに送りません。

## 料金を確認する

OpenAI の標準ティアでの 100 万トークンあたりの価格です(入力 272K トークンまでのリクエスト)。

| モデル | 入力 | キャッシュ読み取り | キャッシュ書き込み(30 分) | キャッシュ書き込み(12 時間) | 出力 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Sol | $5.00 | $0.50 | $6.25 | $12.50 | $30.00 |
| Terra | $2.00 | $0.20 | $2.50 | $5.00 | $12.00 |
| Luna | $0.20 | $0.02 | $0.25 | $0.50 | $1.20 |

入力が 272K トークンを超えるリクエストは高くなります。Sol は入力 $10.00・出力 $45.00、Terra は $4.00 と $18.00、Luna は $0.40 と $1.80 で、キャッシュの価格も同じ比率で上がります。2026 年 11 月 30 日までは、OpenAI の Sol のプロモーション価格が適用され、272K トークンまでは入力 $4.00、出力 $20.00 です。その他のティアやプロバイダーの現在の価格は、モデルページを確認してください。

キャッシュ読み取りは入力料金の 10%、30 分の書き込みは 1.25 倍、12 時間の書き込みは 2.5 倍です。各入力トークンは、これらのうちちょうど 1 つの料金で課金されます。使用量では、キャッシュの読み取りと書き込みは `input_tokens`(Chat Completions では `prompt_tokens`)に含めて数えられ、書き込みは `cache_write_tokens` に報告されます。[使用量と料金のフィールド](../guides/prompt-caching.mdx#usage-and-pricing-fields)を参照してください。

## 繰り返すコンテキストをキャッシュする

プロンプトの変わらない部分をキャッシュ可能なブロックに入れ、リクエスト固有のテキストはその後に置きます。

```json
{
  "model": "openai/gpt-5.6-sol",
  "input": [
    {
      "role": "user",
      "content": [
        {
          "type": "input_text",
          "text": "Stable policy document...",
          "prompt_cache_breakpoint": { "mode": "explicit" }
        },
        {
          "type": "input_text",
          "text": "Apply the policy to this new customer request."
        }
      ]
    }
  ],
  "prompt_cache_options": { "mode": "explicit", "ttl": "30m" }
}
```

- `prompt_cache_breakpoint` は、そのブロックまでのすべて(そのブロックを含む)をキャッシュします。`explicit` モードでは、OpenAI は自分で配置したブレークポイントのみをキャッシュします。
- `{"type": "ephemeral"}` のようなブロックの `cache_control` も使えます。Phaseo はこれを GPT-5.6 に `prompt_cache_breakpoint` として送ります。どちらの指定も Claude にはキャッシュブレークポイントとして届くため、Claude へのフォールバックでもキャッシュされます。
- `ttl` は `30m`(既定値)または `12h` です。どのルートで使えるかは [OpenAI の 12 時間キャッシュ](../guides/prompt-caching.mdx#12-hour-cache-on-openai)を、その他のフィールドは [OpenAI の保持期間とオプション](../guides/prompt-caching.mdx#openai-retention-and-options)を参照してください。

## テストする内容

- **推論と出力の品質:** 公開する effort レベルでの各ティア(品質を最優先する場合は `max` も含む)、難しいタスクでの標準と `reasoning.mode: "pro"` の比較、各レベルでのスキーマ合格率とツール呼び出しの品質。
- **コストとレイテンシー:** 各 effort でのレイテンシー、現在の基準と比べた出力トークンの増加、繰り返すプロンプトでのキャッシュの読み取りと書き込みの比率、トークンあたりの価格ではなく成功したタスクあたりのコスト。

## 展開する

1. 以前の GPT-5 モデルを `models` のフォールバックとして残します。
2. 本番相当のプロンプトで実証されるまで、`max` は設定フラグまたは[プリセット](../guides/presets)の背後に置いておきます。
3. キャッシュ書き込みの量は、キャッシュ読み取りとは別に監視します。
4. 評価でタスクの成功、コスト、レイテンシーが確認できてから、GPT-5.6 を既定にします。
