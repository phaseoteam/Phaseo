モデルを `anthropic/claude-opus-4.6` に変更し、assistant のプリフィルを削除し、構造化出力を `output_config.format` に移します。これらはリクエスト形式の変更で、Opus 4.5 の古いパターンを残したままにすると `400` で失敗します。

| | Claude Opus 4.5 | Claude Opus 4.6 |
| --- | --- | --- |
| Phaseo のモデル ID | `anthropic/claude-opus-4.5` | `anthropic/claude-opus-4.6` |
| コンテキストウィンドウ | 200K トークン | 1M トークン |
| 最大出力 | 64K トークン | 128K トークン |
| assistant のプリフィル | サポート | `400` を返す |
| 構造化出力 | `output_format` | `output_config.format` |
| 思考 | `budget_tokens` | 適応型。`output_config.effort` で調整 |
| `interleaved-thinking-2025-05-14` ベータ | 必要 | 不要 |

## リクエストを更新する

**1. assistant のプリフィルを削除します。** JSON や特定の書き出しを強制するために assistant のターンを事前に埋めている場合、Opus 4.6 は `400` を返します。代わりに、より明確なシステム指示、プロンプト内の例、または構造化出力を使ってください。

**2. 構造化出力を移します。** `output_format` から `output_config.format` に移し、スキーマとパーサーのテストを再実行します。

```json
{
  "model": "anthropic/claude-opus-4.6",
  "max_tokens": 1024,
  "messages": [{ "role": "user", "content": "Extract the invoice fields." }],
  "output_config": {
    "format": { "type": "json_schema", "schema": { "type": "object", "properties": { "total": { "type": "number" } } } }
  }
}
```

`/v1/chat/completions` と `/v1/responses` では、引き続き `response_format` を使います。

**3. 思考を適応型に切り替えます。** Opus 4.6 は、リクエストで求めない限り思考しません。Phaseo では、トークン予算なしの `reasoning.effort` または `reasoning.enabled: true` で適応型思考が有効になり、effort は `output_config.effort` になります。Opus 4.6 は `xhigh` 以外のすべての effort レベルを受け付け、`xhigh` は Phaseo が `max` として送ります。思考が有効な間、Phaseo は `temperature` と `top_k`、および 0.95 未満の `top_p` を除外します。

**4. 古いベータヘッダーを削除します。** SDK のラッパー、ミドルウェア、プリセットから取り除いてください。Phaseo は `anthropic-beta` ヘッダーを転送しないため、もう何の効果もありません。

## テストする内容

- **プロンプト:** 長いコーディングとリファクタリングのプロンプト、複数ステップのリサーチとドキュメントのワークフロー、プリフィルに依存していたプロンプト、1M のウィンドウを使う場合は長いコンテキストのタスク。
- **契約とツール:** `output_config.format` に移した後のスキーマ合格率、複数ステップのエージェントタスクでのツール呼び出しの引数、モデルが拒否したり出力の形式を変えたりしたときのリトライ、コードレビューとデバッグのワークフロー。
- **運用:** 思考を有効にしたときのレイテンシーの中央値と p95、長い実行でのトークン使用量、大きなコンテキストのタスクでのタイムアウト率、評価セットでの Opus 4.5 と比べた成功率。

## 展開する

1. トラフィックを移す前に、プリフィルを削除し、構造化出力を移行します。
2. 重要な本番プロンプトで Opus 4.6 をシャドー実行します。
3. `models` に Opus 4.5 をフォールバックとして入れてカナリアリリースします。
4. スキーマ合格率、レイテンシー、タスク完了が維持されたら昇格させます。
