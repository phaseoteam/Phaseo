# モデル移行

同じプラットフォームを使い続けながらモデルをアップグレードする場合は、これらのガイドを使います。

実際の連携で問題になりやすい変更を扱います。

- リクエストパラメーターの変更
- プロンプトや推論動作の変化
- 構造化出力やツール呼び出しの不具合
- 段階的な展開、フォールバック、ロールバックの方法

## このセクションの使い方

1. 移行先モデルと同じモデルファミリーのガイドから始めます。
2. 出力品質を確認する前に、リクエストパラメーターを更新します。
3. 本番に近いプロンプトで、プロンプトとスキーマの評価を再実行します。
4. フォールバックとロールバックのルールを明確にして、段階的にトラフィックを移します。

モデルだけでなく、プロバイダー、SDK、Gateway を変更する場合は、[移行ガイド](../migration-guides/index.mdx)を参照してください。
