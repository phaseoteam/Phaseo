## モデルを移行する

1. 出力の品質をテストする前に、モデルのガイドに従ってリクエスト形式を更新します。
2. 本番相当のプロンプトで、プロンプトとスキーマの評価を再実行します。
3. 以前のモデルを `models` のフォールバックとし、明確な切り戻しのルールを決めたうえで、段階的にトラフィックを移します。
