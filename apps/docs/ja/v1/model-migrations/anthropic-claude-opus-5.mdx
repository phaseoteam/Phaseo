モデルを `anthropic/claude-opus-5` に変更し、評価している間は Claude Opus 4.8 をフォールバックとして残しておきます。価格は Opus 4.8 と同じなので、コストの差はトークン使用量から生じます。

```json
{
  "model": "anthropic/claude-opus-5",
  "models": ["anthropic/claude-opus-4.8"],
  "messages": [
    {
      "role": "user",
      "content": "Review this implementation plan and identify the highest-risk assumptions."
    }
  ]
}
```

| | Claude Opus 4.8 | Claude Opus 5 |
| --- | --- | --- |
| Phaseo のモデル ID | `anthropic/claude-opus-4.8` | `anthropic/claude-opus-5` |
| コンテキストウィンドウ | 1M トークン | 1M トークン |
| 最大出力 | 128K トークン | 128K トークン |
| 100 万トークンあたりの価格(入力 / 出力) | $5.00 / $25.00 | $5.00 / $25.00 |
| リクエストで推論を設定しない場合の思考 | オフ | 適応型 |

価格はカタログにある Anthropic の標準ティアのものです。その他のティアやプロバイダーについては、モデルページを確認してください。

## Phaseo によるリクエストの送信方法

Opus 5 は Opus 4.7 および 4.8 と同じリクエスト形式を受け付けます。

- **サンプリングパラメーターは除外されます。** `temperature`、`top_p`、`top_k` はモデルに送られません。
- **推論の設定があれば適応型思考が有効になります。** Phaseo は `thinking: {"type": "adaptive", "display": "summarized"}` を送り、`reasoning.effort` は `output_config.effort` になります。思考の予算は転送されません。
- **`reasoning.effort: "none"` または `reasoning.enabled: false` で思考がオフになります**(`thinking: {"type": "disabled"}`)。
- **推論の設定がない場合、Phaseo は `thinking` フィールドを送りません。** そのため、Opus 5 の既定である適応型思考が適用されます。Opus 4.8 は求められたときだけ思考するため、同じリクエストでも Opus 5 では出力トークンが多くなることがあります。

## テストする内容

- **プロンプトと出力:** 最も長いシステムプロンプトでの指示への追従、スキーマ合格率、レスポンスの長さと停止、Opus 4.8 向けに調整したプロンプト。
- **ツールとエージェント:** ツールの選択と引数、ツールのエラーや部分的な結果からの回復、長期タスクの完了率、自律性の高いワークフローでの権限の境界。
- **運用:** 公開する各 effort レベルでのレイテンシーとトークン使用量、長いドキュメントやエージェントのトレースでのコンテキスト使用量、成功したタスクあたりのコスト、プライマリのルートがタイムアウトまたは失敗したときのフォールバック。

## 展開する

1. ユーザーに提供する前に、代表的な本番トラフィックでシャドー実行します。
2. すべての Opus ルートを一度に移すのではなく、ワークロードごとにカナリアリリースします。
3. 品質、レイテンシー、コスト、ツールの安全性の確認が目標を満たしてから昇格させます。
