# Anthropic Claude Opus 5

`anthropic/claude-opus-5` を本番環境に安全に導入するには、このガイドを使います。

Claude Opus 5 は、複雑な推論、長時間のエージェント型コーディング、高い自律性が必要なワークフロー向けの最新 Opus モデルです。価格は Opus 4.8 と同じで、100 万トークンのコンテキストウィンドウと最大 128K トークンの出力に対応します。

## 移行クイックスタート

1. リクエストのほかの部分は変更せず、モデル ID を `anthropic/claude-opus-5` に切り替えます。
2. 本番プロンプト、ツール、構造化出力の評価を再実行します。
3. 長いコンテキストや高い推論負荷の処理について、レイテンシ、トークン使用量、タスクのコストを測り直します。
4. デフォルト経路を変更する前に、Claude Opus 4.8 へのフォールバックを用意して段階的に試します。

```json
{
  "model": "anthropic/claude-opus-5",
  "messages": [
    {
      "role": "user",
      "content": "Review this implementation plan and identify the highest-risk assumptions."
    }
  ]
}
```

## 新機能

- Phaseo でのモデル ID は `anthropic/claude-opus-5` です。
- コンテキストウィンドウは 100 万トークンです。
- 最大出力は 128K トークンです。
- 長時間の推論、コーディング、自律型ツールワークフロー向けに設計されています。
- 価格は Claude Opus 4.8 と同じ水準です。

## テスト項目

### プロンプトと出力

- 最も長いシステムプロンプトでの指示追従。
- 構造化出力とスキーマの成功率。
- 応答の長さと終了動作。
- Claude Opus 4.8 用に調整したプロンプトでの回帰。

### ツールとエージェント

- ツール選択と引数の品質。
- ツールエラーや部分的な結果からの復旧。
- 長時間タスクの完了率。
- 高い自律性が必要な処理における権限と承認の境界。

### 運用

- 公開する各推論負荷レベルでのレイテンシとトークン使用量。
- 長い文書やエージェントトレースでのコンテキスト使用量。
- タスク成功あたりのコスト。
- 主経路がタイムアウトまたは失敗した場合のフォールバック動作。

## 安全なロールアウト

1. 評価中は Claude Opus 4.8 をフォールバックとして利用できる状態にします。
2. ユーザーリクエストを処理する前に、本番に近いトラフィックをシャドー実行します。
3. すべての Opus 経路を一度に変更せず、ワークロードごとに段階的に試します。
4. 品質、レイテンシ、コスト、ツール安全性が目標を満たしてから拡大します。
