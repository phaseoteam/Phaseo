# Google Nano Banana 2

本番の画像ワークフローに Nano Banana 2 を安全に導入するには、このガイドを使います。

Nano Banana 2 は品質が向上しただけではありません。Google は、出力形式、解像度、忠実度をより細かく制御できる本番向け画像モデルとして位置づけています。

## 新機能

- アスペクト比を明示的に制御できます。
- 出力解像度は `512px` から `4K` まで指定できます。
- 生成や編集を繰り返した際の被写体の一貫性が向上しました。
- 指示への追従性が向上しました。
- 画像内のテキスト描画と翻訳が改善しました。
- 生成速度を保ちながら、視覚的な忠実度が向上しています。

## 移行クイックスタート

### 1. 出力に関する前提を見直す

後続のコードが固定サイズ、アスペクト比、クロップ動作を前提にしている場合は、ロールアウト前に更新します。Nano Banana 2 は柔軟性が高いため、以前の前提が崩れやすくなります。

### 2. プロダクトのプリセットを更新する

次を確認します。

- SNS 用のアスペクト比プリセット
- デフォルト解像度
- 編集とインペインティングのワークフロー
- 利用可能な画像サイズを説明する UI ラベル

### 3. 画像編集用プロンプトを調整する

指示追従が強化されたため、構図、テキスト、スタイルを細かく指定しすぎたプロンプトは不要に厳密かもしれません。短いプロンプトでも再テストし、結果を比較します。

## テスト項目

### 出力品質

- 縦長、正方形、横長のアスペクト比
- 低解像度と高解像度の出力
- 反復編集における被写体の一貫性
- 画像内のテキスト、看板、キャプション、翻訳文

### ワークフローとの互換性

- 高解像度ファイルの処理
- 高忠実度生成でのタイムアウト動作
- モデレーションや人手レビューの合格率
- 後続のリサイズやアセット処理に関する前提

### プロダクト指標

- 生成全体のレイテンシ
- 利用可能な出力の割合
- 再試行率
- 承認済みアセットあたりのコスト

## ロールアウトの推奨事項

1. 単一の移行として扱わず、アスペクト比と解像度別にテストします。
2. サポート予定の最大出力サイズでアセットパイプラインを検証します。
3. 特に編集や画像内テキストの要求など、本番の実際のプロンプトを試します。
4. UI で画像オプションを提供している場合、モデル変更とデフォルトプリセット変更を分けてロールアウトします。
