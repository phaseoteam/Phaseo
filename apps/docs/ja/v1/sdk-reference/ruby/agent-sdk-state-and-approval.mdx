description: "人による判断のためにRubyエージェントを一時停止し、アプリケーション管理の状態から続行します。"
---

一般的なチェックポイントには`human_review`を使います。承認ゲート付きまたは手動のツールは、正確な呼び出しIDを`run.pause.pending_tool_calls`に設定します。

`Agent#continue_run`を使って次の内容を指定し、続行します。

- 承認または却下を表す`ToolDecision`値
- 手動作業の結果を表す`ToolOutput`値
- 一般的なレビュー一時停止に対する`human_input`
- 前の実行、またはstate accessorと`run_id`

判断には正確な呼び出しIDが使われるため、同じツールへの並行呼び出しも区別されます。互換性のある状態オブジェクトは`load(run_id)`と`save(result)`を実装します。
