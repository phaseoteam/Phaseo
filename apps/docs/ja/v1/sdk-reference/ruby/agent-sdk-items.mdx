title: "ストリーム項目"
description: "Rubyエージェントの実行から、テキスト、推論、ツール、プロバイダー項目のイベントを取得します。"
---

ストリーム結果には、テキストとプロバイダー項目を再走査できるコンシューマーが用意されています。

```ruby
stream = agent.stream(input: prompt, client: client)

stream.item_stream.each do |item|
  render_item(item)
end

result = stream.result
```

推論の差分、ツールの進捗、承認チェックポイント、ライフサイクルイベントもUIで必要な場合は、`full_stream`を使います。

<Note>
Rubyの項目値は汎用ハッシュであり、型付き項目の閉じたユニオンではありません。UIで使用するフィールドを検証し、未知の項目や将来追加されるプロバイダーイベントに備えたフォールバックを用意します。
</Note>

Rubyはプロバイダーのストリームを同期的に読み取り、収集したシーケンスを再走査できるようにします。これだけでバックグラウンドのプッシュサービスが作成されるわけではありません。
