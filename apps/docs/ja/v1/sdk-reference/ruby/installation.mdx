title: "Ruby SDKのインストール"
description: "RubyGemsからPhaseo Ruby SDKをインストールします。"
---

SDKは [`phaseo_sdk`](https://rubygems.org/gems/phaseo_sdk) で公開されています： RubyGems.

## 要件

- Ruby 3.1以降

## インストール

```bash
gem install phaseo_sdk
```

または `Gemfile` に追加します：

```ruby
gem "phaseo_sdk"
```
