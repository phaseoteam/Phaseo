**メソッド**: `client.get_generation(...)`

### 例

```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))

record = client.get_generation('G-01ABC...')
```

### パラメーター

- `id` （string、必須）：以前の呼び出しで返されたリクエスト ID。

### 戻り値

生成レコード（JSON）

Gateway にリクエストの詳細がすべて保存されている場合、返されるレコードには `replay_supported` と `replay_request` も含まれます。これを使うと、記録されたペイロードを元のエンドポイントに再送信して、制御された再実行を行えます。

時間フィールドは Gateway 共通の定義に従います。

- `latency_ms`: 計測されている場合、最初のトークンまたは最初の出力バイト/フレームまでの時間
- `generation_ms`: 計測されている場合、レイテンシー後の生成時間
