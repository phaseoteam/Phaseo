公開済みcrateの[`phaseo`](https://crates.io/crates/phaseo)を使うと、RustアプリケーションからPhaseo Gatewayを呼び出せます。

高レベルクライアントが対応する機能：

- `Phaseo::responses(...)`によるResponses APIリクエスト
- `Phaseo::chat_completions(...)`によるChat Completionsリクエスト
- `Phaseo::post(...)`によるその他のJSONエンドポイント
- `Phaseo::model_endpoint_capabilities(...)` による現在のモデルルートの検出
- `Phaseo::check_model_parameters(...)` によるパラメーターの対応状況レポート
- `Phaseo::from_env()`による環境変数ベースの設定
- カスタムHTTPSエンドポイントとループバック開発サーバー
- 構造化されたステータス、JSON本文、リクエストID、エラー詳細

パラメーターレポートは、要求した各パラメーターを `supported`、`partial`、`unsupported`、`unknown` のいずれかとして示し、公開された値と範囲を検証して、パラメーターの組み合わせ全体を受け入れるルートを返します。

```rust
use phaseo::Phaseo;
use serde_json::json;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Phaseo::from_env()?;
    let response = client.responses(&json!({
        "model": "openai/gpt-6-astra",
        "input": "Reply with exactly: Rust SDK works"
    }))?;

    println!("{}", response.body);
    Ok(())
}
```

<Note>
  バージョン`0.1`はサポート対象として公開されていますが、`1.0`まではRust APIが変更される可能性があります。本番環境では互換性のあるマイナーバージョンに固定してください。
</Note>

## 現在の対応範囲

使いやすいクライアントは同期型で、`serde_json::Value`のリクエスト本文を受け付けます。生成された低レベルモジュールは`phaseo::gen`から利用でき、`phaseo::client`、`phaseo::models`、`phaseo::operations`から便利な再エクスポートも使えます。

Rustクライアントは現在、非同期トランスポートや高レベルのストリーミングヘルパーを提供していません。それらが追加される前にストリーミングが必要な場合は、生のHTTP APIを使います。
