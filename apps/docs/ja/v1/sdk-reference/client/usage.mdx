以下の各セクションは、エンドポイントごとの短い例です。SDK にそのエンドポイントのラッパーがない言語はセクションから省いています。代わりの方法は[メソッドの表](./overview#find-the-method-for-each-endpoint)にあります。すべてのパラメーターは、このセクションの各エンドポイントのページにあります。

## セットアップ

<CodeGroup>

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });
```

```python Python

client = Phaseo(api_key="your-api-key")
```


```typescript TypeScript
  max_tokens: 128,

```

```python Python
message = client.generate_message(
    {
        "model": "anthropic/claude-haiku-4.5",
        "messages": [{"role": "user", "content": "Hello from the Messages API"}],
        "max_tokens": 128,
    }

for chunk in client.stream_message(
    {
        "model": "anthropic/claude-haiku-4.5",
```

## 音声

文字起こしと翻訳はマルチパートのアップロードを受け取ります。TypeScript は `FormData` の本文をマルチパートとして送信します。Python、Go、C#、PHP、Ruby のメソッドは JSON を送信するため、文字起こしは `file_url` を受け付けるモデルに URL を渡す場合にしか使えず、翻訳にはマルチパートのアップロードが必要です。これらの SDK から音声ファイルをアップロードするには、[STT（音声認識）](./audio-transcriptions#upload-an-audio-file)と[音声翻訳](./audio-translations)を参照してください。

<CodeGroup>

```typescript TypeScript
import { readFile } from "node:fs/promises";

const speech = await client.generateSpeech({
  model: "openai/gpt-4o-mini-tts",
  input: "Hello world",
});

// Transcriptions and translations take a multipart upload.
const form = new FormData();
form.append("model", "openai/gpt-4o-transcribe");
form.append("file", new Blob([await readFile("call.mp3")], { type: "audio/mpeg" }), "call.mp3");
const transcript = await client.generateTranscription(form as unknown as Record<string, unknown>);
```

```python Python
speech = client.generate_speech(
    {"model": "openai/gpt-4o-mini-tts", "input": "Hello world"}
)

# generate_transcription sends JSON, so pass a URL to a model that accepts file_url.
transcription = client.generate_transcription(
    {"model": "mistral/voxtral-mini-transcribe-2", "file_url": "https://example.com/call.mp3"}
)
```

```go Go
speech, err := client.CreateSpeech(ctx, map[string]interface{}{
  "model": "openai/gpt-4o-mini-tts",
  "input": "Hello from Go",
})
```

```csharp C#
var speech = await client.CreateSpeech(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-4o-mini-tts",
    ["input"] = "Hello from .NET",
});
```

```php PHP
$speech = $client->createSpeech([
    'model' => 'openai/gpt-4o-mini-tts',
    'input' => 'Hello from PHP',
]);

$transcript = $client->generateTranscription([
    'model' => 'mistral/voxtral-mini-transcribe-2',
    'file_url' => 'https://example.com/meeting.mp3',
]);
```

```ruby Ruby
speech = client.generate_speech(
  model: 'openai/gpt-4o-mini-tts',
  input: 'Hello world'
)

transcription = client.generate_transcription(
  model: 'mistral/voxtral-mini-transcribe-2',
  file_url: 'https://example.com/meeting.mp3'
)
```

</CodeGroup>

`generateTranslation()` については[音声翻訳](./audio-translations)を参照してください。**Java：** `createSpeech` は JSON を想定しておりバイナリの音声をデコードできないため、音声合成には `rawClient().requestBytes` を使ってください。文字起こしと翻訳のアップロードは、[STT](./audio-transcriptions) と[音声翻訳](./audio-translations)のページにあるとおり、Java の標準 HTTP クライアントで送信します。

## エラーを処理する

<CodeGroup>

```typescript TypeScript
import { PhaseoHttpError } from "@phaseo/sdk";

try {
  await client.generateText({ model: "invalid", messages: [{ role: "user", content: "Hi" }] });
} catch (error) {
  if (error instanceof PhaseoHttpError) {
    console.error(error.status, error.code, error.requestId, error.traceUrl);
  } else {
    throw error;
  }
}
```

```python Python
from phaseo import PhaseoHTTPError

try:
    client.generate_text({"model": "invalid", "messages": [{"role": "user", "content": "Hi"}]})
except PhaseoHTTPError as error:
    print(error.status, error.code, error.request_id, error.trace_url)
```

```java Java
import app.phaseo.gen.Client;
import app.phaseo.sdk.Phaseo;
import java.time.Duration;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"))
    .setTimeout(Duration.ofSeconds(30))
    .setMaxRetries(2);

try {
    var result = client.requestWithResponse("GET", "/models",
        Map.of("limit", "5"), null, null, null);
    System.out.println(result.requestId());
    System.out.println(result.data);
} catch (Client.ApiException error) {
    System.err.println(error.getStatusCode());
    System.err.println(error.getRequestId());
    System.err.println(error.getResponseBody());
}
```

```rust Rust
let request = serde_json::json!({
    "model": "openai/gpt-6-astra",
    "input": "Handle this request"
});

match client.responses(&request) {
    Ok(response) => println!("{}", response.body),
    Err(error) => {
        eprintln!("message: {}", error.message);
        eprintln!("status: {:?}", error.status);
        eprintln!("body: {:?}", error.body);
    }
}
```

</CodeGroup>

Gateway がエラーを返した場合、`PhaseoError`（Rust）には HTTP ステータスと解析済みの JSON 本文があります。通信と設定の失敗にはステータスがありません。各 SDK のエラーのフィールドは[概要](./overview#request-controls-and-errors)にあります。

## リクエストヘッダーを追加する

**Rust：** `with_header` は、以降のすべてのリクエストにヘッダーを追加します。

```rust Rust
let client = Phaseo::from_env()?
    .with_header("x-phaseo-workspace-id", "workspace_123");
```
