リクエスト ID（`G-01ABC...` など）を SDK の生成メソッドに渡すと、`GET /v1/generations?id=<id>` からそのリクエストの保存済みレコードを取得できます。

<CodeGroup>

```typescript TypeScript
const record = await client.getGeneration("G-01ABC...");
```

```python Python
record = client.get_generation("G-01ABC...")

print(record["model_id"], record["cost_nanos"])
```

```go Go
client, err := phaseo.NewFromEnv()
if err != nil {
  panic(err)
}

record, err := client.GetGeneration(context.Background(), "G-01ABC...")
if err != nil {
  panic(err)
}
fmt.Println(record["status_code"], record["cost_nanos"])
```

```csharp C#
using PhaseoSdk;

var client = new Phaseo();
var record = await client.GetGeneration("G-01ABC...");
```

```php PHP
<?php
require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo();
$record = $client->getGeneration('G-01ABC...');
```

```ruby Ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new
record = client.get_generation('G-01ABC...')
```

```java Java
import app.phaseo.sdk.Phaseo;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

var record = client.getGeneration("G-01ABC...");
System.out.println(record);
```

</CodeGroup>

| 言語 | メソッド | 戻り値 |
| --- | --- | --- |
| TypeScript | `client.getGeneration(id)` | レコードのオブジェクト |
| Python | `client.get_generation(id)` | `APIResponse` の dict |
| Go | `client.GetGeneration(ctx, id)` | `map[string]interface{}` |
| C# | `client.GetGeneration(id)` | `Dictionary<string, object>?` |
| PHP | `$client->getGeneration($id)` | 配列 |
| Ruby | `client.get_generation(id)` | Hash |
| Java | `client.getGeneration(id)` | Jackson の `JsonNode` |
| Rust | ヘルパーはありません。`client.request("GET", "/generations?id=<id>", None, &RequestOptions::default())` を呼び出します | `PhaseoResponse`。レコードは `body`（`serde_json::Value`）にあります |

照会の範囲はあなたのワークスペースに限られます。`id` がない場合は `400`（`missing_id`）が、ワークスペースにない ID の場合は `404`（`not_found`）が返ります。

## 保存済みのリクエストを再実行する

Gateway がリクエスト全体を保存している場合、レコードの `replay_supported` は true になり、`replay_request` が含まれます。これを元のエンドポイントに送り直すと、管理された形で再実行できます。

## タイミングのフィールドを読む

- `latency_ms`：最初のトークン、または最初の出力バイトやフレームまでの時間（計測している場合）。
- `generation_ms`：その時点以降の生成時間（計測している場合）。
