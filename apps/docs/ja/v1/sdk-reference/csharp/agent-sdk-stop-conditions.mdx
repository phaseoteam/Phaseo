`AgentDefinition.StopWhen` で停止ヘルパーを組み合わせます。

```csharp
StopWhen = new[]
{
    AgentSdk.StepCountIs(12),
    AgentSdk.MaxTokensUsed(40_000),
    AgentSdk.MaxCost(2),
    AgentSdk.MaxDuration(TimeSpan.FromMinutes(1)),
};
```

`HasToolCall(...)` と `FinishReasonIs(...)` provide event-based limits. トークン数やコストの上限を使う場合も、使用量の報告に依存するため、ステップ数または実行時間の上限を設定してください。
