**メソッド**：`client.ListModels(...)`

### 例
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var models = await client.ListModels(new Dictionary<string, string>
{
    ["provider"] = "anthropic",
    ["provider_status"] = "beta,not_ready",
    ["provider_availability_reason"] = "preview_only,provider_not_ready",
    ["capability_status"] = "coming_soon,internal_testing",
    ["availability"] = "all",
    ["limit"] = "10"
});
```

### パラメーター
- 任意のフィルター：`provider`、`provider_status`、`provider_routing_status`、`model_routing_status`、`capability_status`、`provider_availability_status`、`provider_availability_reason`、`status`、`organisation`、`endpoints`、`input_types`、`output_types`、`params`、`availability`、`limit`、`offset`。
- ロールアウト状態の`preview_only`、`provider_not_ready`、`gated`、`access_limited`、`region_limited`、`project_limited`、`paused`、`soft_blocked`などを取得する場合、`availability = "all"`と`provider_availability_reason`が役立ちます。
- ルーティングできないエンドポイントの対応付け（`coming_soon`、`internal_testing`など）を取得する場合、`availability = "all"`と`capability_status`が役立ちます。
