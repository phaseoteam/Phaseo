title: "ストリーミング"

---

`Agent.Stream(...)`は`Run(...)`と同じステートマシンを実行し、`AgentStreamResult`を返します。

```csharp
var stream = agent.Stream(new RunOptions { Input = input, Client = client });

await foreach (var delta in stream.TextStream())
{
    Console.Write(delta);
}

var completed = await stream.GetResult();
```

モデル、ツール、ステップ、実行のイベントを取得するには`FullStream()`を使います。キャプチャされた非同期シーケンスは、複数のコンシューマーから独立して再走査できます。実行中の処理を停止する場合は`Cancel()`を呼び出します。キャンセルはモデルリクエストとローカルツールにも伝播します。
