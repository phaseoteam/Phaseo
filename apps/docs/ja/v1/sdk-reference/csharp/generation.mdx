**メソッド**：`client.GetGeneration(...)`

### 例

```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.GetGeneration("G-01ABC...");
```

### パラメーター

- `id`（string、必須）：以前の呼び出しで返されたリクエストID。

### 戻り値

生成レコード（JSON）

ゲートウェイがリクエストの詳細をすべて保存している場合、返されるレコードには`replay_supported`と`replay_request`が含まれます。`replay_request`を元のエンドポイントに送信すると、制御された形で再実行できます。

時間フィールドはゲートウェイ全体で共通の意味に従います。

- `latency_ms`：記録されている場合、最初のトークンまたは出力バイト／フレームまでの時間
- `generation_ms`：記録されている場合、レイテンシ後の生成時間
