失敗した`RunResult`にも、アクティブなステップ、再試行回数、リクエストID、ネイティブレスポンスID、プロバイダーメタデータ、利用可能なゲートウェイ情報が保持されます。

まず次の点を確認してください。

- プロセスから`PHASEO_API_KEY`を参照できる
- ツールIDが一意で安定している
- 承認判断で正確なツール呼び出しIDを使っている
- リクエストの制御を返す前に一時停止状態を保存している
- バリデーターが副作用を起こさない
- キャンセルトークンがツール内で使われる依存関係まで伝わる

アプリケーションのテレメトリーにはライフサイクルフックを、ローカルでの実行確認にはDevToolsを使います。
