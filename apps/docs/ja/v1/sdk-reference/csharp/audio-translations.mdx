**メソッド**: `client.CreateTranslation(...)`

### 例
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.CreateTranslation(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-4o-transcribe",
    ["audio_b64"] = "base64-audio"
});
```

### 主なパラメーター
- `model`（必須）：翻訳に対応するモデルのID。
- `file`（必須）：翻訳する音声データ。
- `prompt`：翻訳の参考となる任意のコンテキスト。
- `temperature`（0～2）：サンプリングのランダム性。
- `response_format`：`json`、`text`、`srt`、`verbose_json`など。

### 戻り値
`AudioTranscriptionResponse`
