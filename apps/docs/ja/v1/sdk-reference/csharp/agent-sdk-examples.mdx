| パターン | 組み合わせ |
| --- | --- |
| チケットの振り分け | プリセットによるルーティング、検索ツール、構造化された最終出力 |
| コードレビュー | リポジトリ用ツール、進捗、変更前の承認 |
| 調査概要 | 管理された検索、ストリーミングテキスト、コスト上限 |
| 運用手順書 | ステータス確認ツール、エスカレーション、永続的な再開 |

エージェントを1つ、決定的なツールを1つか2つ用意し、副作用のある操作には明示的な承認を求めます。
