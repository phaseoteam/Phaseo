`RunResult`はエージェントの永続的な実行結果です。実行レコード、メッセージ、ステップ、使用量とコスト、警告、終了理由、最終出力を含みます。

回答テキストをリアルタイムで取得するには`TextStream()`を、モデル、ツール、ステップ、実行、プロバイダー項目のイベントを受け取るには`FullStream()`を使います。現在、C#はプロバイダー項目を汎用オブジェクトとして公開しており、TypeScriptの判別可能なユニオン型`AgentItem`には対応していません。

実行中はライフサイクルイベントからプロダクトのタイムラインを作成し、その後、保存されたメッセージとステップから最終状態を再構築します。
