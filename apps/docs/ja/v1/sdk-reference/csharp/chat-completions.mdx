description: "C# SDKで/chat/completionsを呼び出します。"
---

**メソッド**：`client.GenerateText(...)`または`client.CreateChatCompletion(...)`

### 例
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.GenerateText(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-5-nano",
    ["messages"] = new[]
    {
        new Dictionary<string, object>
        {
            ["role"] = "user",
            ["content"] = "Write a limerick about lighthouses."
        }
    }
});
```

### 主なパラメーター
- `model`（必須）：対象モデルのID。
- `messages`（必須）：`system|user|assistant|tool`のロールを持つ順序付きメッセージ。内容にはテキストまたはパーツを指定できます。
- サンプリング：`temperature`（0～2）、`top_p`（0～1）、`top_k`（>=1）、`seed`（整数、任意）。
- 長さとペナルティ：`max_output_tokens`（整数）、`presence_penalty`と`frequency_penalty`（-2～2）、`stop`（string|string[]）。
- ツール：`tools`（定義）、`tool_choice`（auto/none/特定のツール）、`max_tool_calls`（整数）、`parallel_tool_calls`（boolean）。
- 対数確率：`logprobs`（boolean）、`top_logprobs`（0～20）。
- 出力：`response_format`（json/text）、`meta`（そのまま渡すオブジェクト）、`stream`（boolean）、`service_tier`。
- Gatewayの追加項目：`usage`（使用量を要求するboolean）、`meta`（metaブロックを含めるboolean）。
