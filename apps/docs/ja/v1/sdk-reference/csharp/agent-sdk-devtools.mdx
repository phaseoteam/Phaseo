description: "開発やデバッグ用に、.NET Agent SDK の実行をローカルに記録します。"
---

ローカルの JSONL 記録を有効にするには `AgentSdk.CreateAgentDevtools(...)` に渡します `RunOptions`.

記録には実行状態と所要時間、モデルやプロバイダーの詳細、リクエスト ID、メッセージ、ステップ、ツールの動作、使用量、コスト、構造化エラーが含まれます。

<Warning>
エージェントの入力、コンテキスト、ツールの結果には機密データが含まれる場合があります。DevTools の出力をソース管理や本番用イメージに含めないでください。
</Warning>
