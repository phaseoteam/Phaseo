| パターン | 組み合わせるもの |
| --- | --- |
| 構造化データの抽出 | 出力検証、厳密なレスポンススキーマ、回数を制限した再試行 |
| サポートの振り分け | プリセットルーティング、検索ツール、最終分類 |
| 調査ブリーフ | 管理された検索、ストリーミングテキスト、コスト上限 |
| コーディングアシスタント | ローカルファイル用ツール、進捗、変更前の承認 |

まずはエージェント1つと決定論的なツール1～2個から始め、副作用を伴う操作には明示的な承認を必須にします。

[Pythonエージェントで構造化JSONを抽出する](../../cookbook/agent-sdk-python-structured-extraction.mdx)も参照してください。
