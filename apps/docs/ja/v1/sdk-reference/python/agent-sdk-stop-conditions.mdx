---

`stop_when`で停止ヘルパーを組み合わせます:

```python
stop_when = [
    step_count_is(12),
    max_tokens_used(40_000),
    max_cost(2),
    max_duration(60_000),
]
```

追加のヘルパーには `has_tool_call(...)` と `finish_reason_is(...)` があります。コストやトークンで制限する場合も、報告される使用量に依存するため、ステップ数または時間の上限を設定してください。
