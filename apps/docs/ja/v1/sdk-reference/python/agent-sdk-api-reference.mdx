| API | 用途 |
| --- | --- |
| `create_agent(...)` | エージェントを定義 |
| `define_tool(...)` | ローカルまたは手動のツールを定義 |
| `create_gateway_agent_client(...)` | モデルのターンをPhaseoに接続 |
| `agent.run(...)` | 完了または一時停止まで実行 |
| `agent.stream(...)` | 再走査可能なストリームコンシューマーで実行 |
| `agent.continue_run(...)` | 保存済みまたは一時停止中の状態から続行 |
| `stream.result()` | 完了した実行結果を取得 |
| `stream.text_stream()` | テキストの差分を取得 |
| `stream.full_stream()` | すべてのイベントを取得 |
| `stream.cancel()` | 実行中の処理をキャンセル |

主な型には`AgentTool`、`AgentToolDecision`、`AgentToolOutput`、`AgentRunResult`、`AgentStateAccessor`、`AgentModelRetryConfig`、`AgentToolExecutionConfig`があります。
