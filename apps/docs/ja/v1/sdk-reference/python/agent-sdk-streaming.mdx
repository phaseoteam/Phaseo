`Agent.stream(...)`は`run(...)`と同じ状態機械を実行し、再走査可能な`AgentStreamResult`を返します。

```python
stream = agent.stream(input="Research this topic", client=client)

for delta in stream.text_stream():
    print(delta, end="", flush=True)

completed = stream.result()
```

別の形式で取得するには`reasoning_stream()`、`item_stream()`、`tool_stream()`、または`full_stream()`を使います。Pythonの項目は現在辞書形式であり、ネイティブの判別可能なユニオンではありません。

アクティブなモデルストリームを停止し、ローカルランタイムの処理にもキャンセルを伝えるには`cancel()`を呼び出します。
