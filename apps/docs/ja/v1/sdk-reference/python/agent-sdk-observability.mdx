失敗した結果にも、アクティブなステップ、再試行回数、リクエストID、ネイティブレスポンスID、プロバイダーメタデータ、利用可能なゲートウェイ情報が保持されます。

次の点を確認してください。

- プロセスから`PHASEO_API_KEY`を参照できる
- ツールIDが一意である
- 承認判断で正確な呼び出しIDを使っている
- 次のリクエストを続行する前に一時停止状態を保存している
- バリデーターが副作用を起こさない
- キャンセルがツール内のネットワーク処理やストレージ処理にも伝わる

アプリケーションのテレメトリーにはライフサイクルイベントを、ローカルでの実行確認にはDevToolsを使います。
