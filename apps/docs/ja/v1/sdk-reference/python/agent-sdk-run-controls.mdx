title: "出力と再試行"
description: "Pythonエージェントの出力を検証し、回数を制限してモデルの失敗を再試行します。"
---

後続のPythonコードが構造化データを期待する場合は、最終出力の検証を使います。検証コールバックは決定論的にし、最終値がアプリケーションの契約を満たさない場合は例外を発生させてください。

`AgentModelRetryConfig`で再試行回数を制限します。

```python
retry = AgentModelRetryConfig(max_retries=2, backoff_ms=250)
```

完了したステップには最終的なモデル試行回数が保持されます。ツールエラーには独自のポリシーが適用され、モデルリクエストとして再試行されることはありません。

ゲートウェイクライアントは、構造化出力、ルーティング、プロバイダー、推論、管理ツール、プラグイン、プロンプトキャッシュ、その他のリクエストオプションを受け付けます。
