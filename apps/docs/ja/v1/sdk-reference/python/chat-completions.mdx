**メソッド**：`client.generate_text()`（`client.stream_chat()`で解析済みチャンクをストリーミングします）。

### 例
```python
chat = client.generate_text({
    "model": "openai/gpt-4o-mini",
    "messages": [
        {"role": "system", "content": "You are helpful."},
        {"role": "user", "content": "Write a limerick about lighthouses."},
    ],
    "temperature": 0.5,
})
```

### ストリーミング
```python
for chunk in client.stream_chat({
    "model": "openai/gpt-4o-mini",
    "messages": [{"role": "user", "content": "Stream a story"}],
}):
    if chunk.get("text"):
        print(chunk["text"], end="", flush=True)
```

### 主なパラメーター
- `model`（必須）：対象モデルのID。
- `messages`（必須）：`system|user|assistant|tool`のロールを持つ順序付きメッセージ。内容はテキストまたはパーツです。
- サンプリング：`temperature`（0～2）、`top_p`（0～1）、`top_k`（>=1）、`seed`（任意の整数）。
- 長さとペナルティ：`max_output_tokens`（整数）、`presence_penalty`と`frequency_penalty`（-2～2）、`stop`（string|string[]）。
- ツール：`tools`（定義）、`tool_choice`（auto/none/特定のツール）、`max_tool_calls`（整数）、`parallel_tool_calls`（真偽値）。
- Logprobs：`logprobs`（真偽値）、`top_logprobs`（0～20）。
- 出力：`response_format`（json/text）、`metadata`（そのまま渡すオブジェクト）、`stream`（真偽値）、`service_tier`。
- ゲートウェイ拡張：`usage`（使用量を要求する真偽値）、`meta`（metaブロックを含める真偽値）。
