<Note type="warning">
  C++ SDK は開発中で、まだパッケージマネージャーからは入手できません。ソースのヘッダーは評価目的でのみ使ってください。
</Note>

C++ SDK は `packages/sdk/sdk-cpp` にあるヘッダーのみの C++17 ソース一式です。公開されておらず、エンドツーエンドで動作するまでは SDK のリリースから除外されています。

| ファイル | 内容 |
| --- | --- |
| `src/gen/client.hpp`、`src/gen/operations.hpp`、`src/gen/models.hpp`、`src/gen/model_ids.hpp` | 生成されたクライアント |
| `src/phaseo.hpp` | ライブのモデル機能を取得する `GetModelEndpointCapabilities(...)` と、パラメーター対応状況のレポートを返す `CheckParameterSupport(...)` |
| `src/workflows.hpp` | ページングとジョブのポーリング用のヘルパー |

プレビュー版の通信層は生の JSON を返すため、確認する前にレスポンスを `ModelEndpointCapabilities` にデシリアライズしてください。試すには[インストール](./installation)を参照してください。C++ の Agent SDK はありません。
