## ローカルで使う

この SDK はヘッダーのみの C++17 です。`packages/sdk/sdk-cpp` を CMake のビルドに追加してインターフェースターゲットをリンクするか、`packages/sdk/sdk-cpp/src` をインクルードパスに追加してください。

```cmake
add_subdirectory(path/to/Phaseo/packages/sdk/sdk-cpp)
target_link_libraries(your_app PRIVATE phaseo::sdk)
```

その後、`phaseo.hpp` をインクルードします。これにより `src/gen` 内の生成されたクライアントが読み込まれます。
