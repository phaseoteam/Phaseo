エージェントの失敗は通常、モデルリクエスト、ローカルツール、スキーマ検証、タイムアウト、または人間による判断の欠落が原因です。

## ツールエラーからの回復

モデルがツールエラーから回復できる場合は、`onError: "return-to-model"`を設定します。エラーは構造化されたツール結果として返され、実行は別の操作を選べます。危険または回復不能な操作ではfail-runの動作を維持してください。

## PHPの実行方式

PHPのツールコールバックは同期的に実行されます。そのため、ツールの並行実行と中断はPHPランタイムおよび基盤のI/Oクライアントによって制限されます。ネットワークやプロセスを扱うツールには明示的なタイムアウトを設定し、タイムアウトしたコールバックを常に強制停止できるとは限らない点に注意してください。

## 続行処理のエラーを診断する

保留中の各呼び出しには、ツール呼び出しIDで識別される承認、却下、または外部から提供された出力が必要です。承認UIを表示する前に、返された実行状態全体を保存してください。

## 有用なフィールドを記録する

実行ID、ステップ番号、リクエストID、プロバイダー、モデル、終了理由、ツール呼び出しID、停止理由を記録します。未加工のプロンプトや認証情報を記録する代わりに、ライフサイクルフックまたはDevToolsを使ってください。
