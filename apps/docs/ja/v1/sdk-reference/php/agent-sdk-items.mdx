icon: "layers"
title: "ストリーム項目"
description: "PHPエージェントの実行から、テキスト、推論、ツール、プロバイダー項目のイベントを取得します。"
---

ストリーム結果には、テキストと構造化イベントを再走査できるコンシューマーが用意されています。

```php
$stream = $agent->stream(input: $prompt, client: $client);

foreach ($stream->itemStream() as $item) {
    renderItem($item);
}

$result = $stream->getResult();
```

プロバイダー項目に加えて、推論の差分、ツールの進捗、承認チェックポイント、ライフサイクルの変化がUIで必要な場合は、全イベントストリームを使います。

<Note>
PHPの項目値は汎用の配列またはオブジェクトであり、型付き項目の閉じたユニオンではありません。UIで使用するフィールドを検証し、未知の項目や将来追加されるプロバイダーイベントに備えたフォールバックを用意します。
</Note>

PHPはプロバイダーのストリームを同期的に読み取り、収集したシーケンスを再走査できるようにします。リクエストワーカーやCLIプログラムには適していますが、これだけでバックグラウンドのプッシュチャネルが作成されるわけではありません。
