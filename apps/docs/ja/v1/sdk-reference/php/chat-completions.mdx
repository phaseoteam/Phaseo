title: "チャット補完"
description: "PHP SDK で /chat/completions を呼び出します。"
---

**メソッド**: `generateText()`, `createChatCompletion()`

### 例

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo(apiKey: $apiKey);

$response = $client->createChatCompletion([
    'model' => 'openai/gpt-4o-mini',
    'messages' => [[
        'role' => 'user',
        'content' => 'Write a limerick about lighthouses.',
    ]],
    'temperature' => 0.5
]);
echo $response['choices'][0]['message']['content'];
```

### 主なパラメーター

- `model`（必須）：対象モデルの ID。
- `messages`（必須）：`system|user|assistant|tool` のロールを持つ順序付きメッセージ。コンテンツには MessageContent オブジェクトを使用します。
- サンプリング：`temperature`（0～2）、`top_p`（0～1）、`top_k`（>=1）、`seed`（int、任意）。
- 長さとペナルティ：`max_output_tokens`（int）、`presence_penalty` と `frequency_penalty`（-2～2）、`stop`（string|string[]）。
- ツール：`tools`（定義）、`tool_choice`（自動/なし/特定のツール）、`max_tool_calls`（int）、`parallel_tool_calls`（bool）。
- Logprobs：`logprobs`（bool）、`top_logprobs`（0～20）。
- 出力：`response_format`（json/text）、meta ブロックを含める `meta`（bool）、`stream`（bool）、`service_tier`。
- Gateway の追加オプション：使用量をリクエストする `usage`（bool）。
