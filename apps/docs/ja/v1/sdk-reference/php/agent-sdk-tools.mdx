---

`Tool`値を作成し、`AgentSdk::defineTool(...)`に渡します。ツールには次の項目を含められます。

- モデルに提示するJSON `parameters`
- `inputSchema`、`outputSchema`、`eventSchema`の検証コールバック
- `timeoutMs`と`execute`コールバック
- boolean値またはコールバックの`requireApproval`
- 対話型処理向けの`onToolCalled`と`onResponseReceived`
- `nextTurnParams`と`onError: "return-to-model"`

途中経過には`RuntimeContext::$emitProgress`を、アプリケーションのコンテキストには`$setContext`を使います。

<Note>
標準のPHPランタイムではツールのコールバックが同期的に実行されます。そのため、並行処理や中断の可否はSDKをホストするPHPプロセスの機能に依存します。
</Note>
