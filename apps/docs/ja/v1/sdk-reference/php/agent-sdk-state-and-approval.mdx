一般的なチェックポイントには`AgentDefinition::$humanReview`を使います。承認ゲート付きまたは手動のツールは、正確な呼び出しIDを`$result->run->pause->pendingToolCalls`に設定します。

`Agent::continueRun(...)`を使って次の内容を指定し、続行します。

- 承認または却下を表す`ToolDecision`値
- 手動作業の結果を表す`ToolOutput`値
- 一般的なレビュー一時停止に対する人間の入力

ストレージから実行を再読み込みするアプリケーションでは、`StateAccessor`と`continueRunById(...)`を使います。判断はツール名ではなく呼び出しIDに対応付けられます。
