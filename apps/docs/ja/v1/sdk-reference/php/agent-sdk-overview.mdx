PHP Agent SDKはPhaseo Gateway向けの完全なローカルエージェント状態機械です。再試行、タイムアウト確認、人によるレビュー、再開可能な状態、ライフサイクルイベント、DevTools記録を備えています。標準のPHPランタイムではツールコールバックは同期的に実行されます。

次の用途に使えます。

- 軽量で上限のあるツールループ
- ゲートウェイ経由の`responses`リクエスト
- 永続化とオーケストレーションをアプリケーション側で制御すること

## 提供機能

- `AgentSdk::createAgent(...)`
- `AgentSdk::defineTool(...)`
- `AgentSdk::createGatewayAgentClient(...)`
- Phaseoの`responses` API上で動作する上限付きツールループ
