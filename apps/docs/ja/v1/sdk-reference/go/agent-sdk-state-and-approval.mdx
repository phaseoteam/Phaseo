description: "人による判断のためにGoエージェントを一時停止し、アプリケーション管理の状態から続行します。"
---

一般的なチェックポイントには`HumanReview`を使います。承認ゲート付きまたは手動のツールは、正確な呼び出しIDを`Run.Pause.PendingToolCalls`に設定します。

`Agent.Continue(...)`を使って次の内容を指定し、続行します。

- `Approvals`または`Rejections`内の`ToolDecision`エントリー
- 手動作業に対する`ToolOutput`エントリー
- 一般的なレビュー一時停止に対する`HumanInput`
- 前の`RunResult`、または`StateAccessor`と`RunID`

判断には正確な呼び出しIDが使われるため、同じツールへの並行呼び出しも区別されます。リクエストや再起動をまたいで実行状態を保持するには、`StateAccessor.Load(...)`と`Save(...)`を実装します。
