Go Agent SDKはPhaseo Gateway用の完全なローカルエージェントランタイムです。再試行、並行ツール、コンテキストとタイムアウト、人による確認、再開可能な状態、ライフサイクルイベント、DevTools記録を備えています。

次の用途に適しています:

- 軽量で上限のあるツールループ
- Gateway の `responses` エンドポイントへのリクエスト
- 永続化とオーケストレーションをアプリ側で制御

## 提供される機能

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- Gateway の `responses` エンドポイントへのリクエスト
