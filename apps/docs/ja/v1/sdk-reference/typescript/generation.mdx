**メソッド**：`client.getGeneration()`。

### 例
```typescript
const record = await client.getGeneration("G-01ABC...");
```

### パラメーター
- `id`（文字列、必須）：以前の呼び出しで返されたリクエストID。

### 戻り値
生成レコード（JSON）

ゲートウェイがリクエストの詳細をすべて保存している場合、返されるレコードには`replay_supported`と`replay_request`が含まれます。制御された再実行には、`replay_request`を元のエンドポイントに送信します。

時間フィールドはゲートウェイ共通の仕様に従います。

- `latency_ms`：記録されている場合、最初のトークンまたは出力バイト／フレームまでの時間
- `generation_ms`：記録されている場合、レイテンシー後の生成時間
