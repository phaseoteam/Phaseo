構築中のプロダクトに合う最小限の例を選んでください。どのパターンでも、状態の保存とユーザーインターフェイスはアプリケーション側で管理し、モデルのターンにPhaseoを使います。

## パッケージに含まれる例

| 例 | 用途 |
| --- | --- |
| `research-brief-agent.ts` | 管理された検索を使って調査し、型付きの最終ブリーフを作成する |
| `support-triage-agent.ts` | 管理されたプリセットでサポート案件を振り分け、分類する |
| `coding-review-agent.ts` | ローカル実行ツールでコードをレビューする |
| `parallel-tool-agent.ts` | 独立したローカルツールを並列実行する |
