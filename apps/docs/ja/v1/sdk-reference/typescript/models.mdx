---

**メソッド**：`client.getModels()`。

### 例
```typescript
const models = await client.getModels({
  provider: ["anthropic"],
  provider_status: ["beta", "not_ready"],
  provider_availability_reason: ["preview_only", "provider_not_ready"],
  capability_status: ["coming_soon", "internal_testing"],
  availability: "all",
});
```

### パラメーター
- 任意のフィルター：`provider`、`provider_status`、`provider_routing_status`、`model_routing_status`、`capability_status`、`provider_availability_status`、`provider_availability_reason`、`status`、`organisation`、`endpoints[]`、`input_types[]`、`output_types[]`、`params[]`、`availability`、`limit`、`offset`。
- `availability: "all"`と併用する`provider_availability_reason`は、`preview_only`、`provider_not_ready`、`gated`、`access_limited`、`region_limited`、`project_limited`、`paused`、`soft_blocked`などの段階的な公開状態を調べるのに便利です。
- `availability: "all"`と併用する`capability_status`は、`coming_soon`や`internal_testing`など、ルーティングできないエンドポイントの割り当てを調べるのに便利です。
