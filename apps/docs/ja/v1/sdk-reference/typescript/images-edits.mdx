---

**メソッド**: `client.generateImageEdit()`。

### 例
```typescript
const edited = await client.generateImageEdit({
  model: "openai/gpt-image-1",
  prompt: "Make it sunset",
  image: "data:image/png;base64,...",
  mask: "data:image/png;base64,...",
});
```

### 主なパラメーター
- `model`（必須）：画像編集に対応したモデルのID。
- `image`（必須）：base64データURLまたは元画像のURL。
- `prompt`：編集用の新しい任意の指示。
- `mask`：任意のマスク（透明な領域が編集されます）。
- `n`（1～10）：編集後のバリエーション数。
- `size`：例：`1024x1024`、`1024x1792`、`1792x1024`。
- `response_format`：`url`または`b64_json`。
- `user`：エンドユーザー用の任意のタグ。

### 戻り値
`ImageGenerationResponse`

```json
{
  "data": [
    {
      "url": "https://example.com/edited_image.png"
    }
  ]
}
```
