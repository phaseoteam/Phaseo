---

| API | 用途 |
| --- | --- |
| `AgentSdk.createAgent(...)` | エージェントを定義 |
| `AgentSdk.defineTool(...)` | ローカルまたは手動のツールを定義 |
| `AgentSdk.createGatewayAgentClient(...)` | モデルのターンをPhaseoに接続 |
| `Agent.run(...)` | 完了または一時停止まで実行 |
| `Agent.stream(...)` | 再走査可能なストリームコンシューマーで実行 |
| `Agent.continueRun(...)` | 保存済みまたは一時停止中の状態から続行 |
| `StreamResult.getResult()` | 完了した実行結果を取得 |
| `StreamResult.textStream()` | テキストの差分を取得 |
| `StreamResult.fullStream()` | すべてのイベントを取得 |
| `StreamResult.cancel()` | 実行中の処理をキャンセル |

主なレコードとインターフェースには`AgentDefinition`、`RunOptions`、`RunResult`、`RunRecord`、`RunStep`、`Tool`、`ToolDecision`、`ToolOutput`、`RuntimeContext`、`StateAccessor`、`ModelRetryConfig`、`ToolExecutionConfig`があります。
