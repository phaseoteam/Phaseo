description: "Javaエージェントのターン間でモデル設定やツールを変更します。"
---

後続ターンでアプリケーションコンテキスト、前のツール結果、完了したターン数に応じた応答が必要な場合は、動的コールバックを使います。

動的な値で次の項目を選択できます。

- モデルまたはフォールバックモデル
- 指示
- 温度、top-p、最大出力トークン数
- 次のモデルリクエストで使うツールの一覧

ツールは`RuntimeContext`でアプリケーションコンテキストを更新し、直後のリクエストに適用する`NextTurnParams`を返せます。次のターンへの上書き値は一時停止状態とともに保存されるため、承認後もツールのルーティングやサンプリングの判断は失われません。

実行を`StateAccessor`経由で再読み込みする可能性がある場合は、コンテキストと次ターンの値をシリアライズ可能にしてください。
