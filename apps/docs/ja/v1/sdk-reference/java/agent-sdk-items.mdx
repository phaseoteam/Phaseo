`RunResult`をJavaエージェントの永続的な実行結果として使います。実行レコード、保存済みメッセージ、ステップレコード、正規化された使用量とコスト、警告、終了理由、最終出力を含みます。

`StreamResult.fullStream()`には、モデル、ツール、ステップ、実行の各イベントに加えてプロバイダー項目のイベントも含まれます。Javaは現在、プロバイダー項目を汎用オブジェクトとして公開しており、TypeScriptの判別可能なユニオン型`AgentItem`には対応していません。

プロダクトのタイムラインを作成するには、次のようにします。

1. エージェントの実行中に`textStream()`のテキストを表示します。
2. ツールのライフサイクルイベントからツールカードを表示します。
3. 完了した`RunResult`を保存します。
4. 保存されたメッセージとステップから最終タイムラインを再構築します。

プロバイダー固有の項目データはアプリケーションアダプターの背後に置き、プロバイダー形式の変更がUIのほかの部分に影響しないようにします。
