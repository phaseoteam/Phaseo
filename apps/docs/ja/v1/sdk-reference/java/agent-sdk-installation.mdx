<Note type="warning">
  Java Agent SDKはまだMaven Centralで公開されていません。このソースワークフローは評価目的でのみ使用してください。
</Note>

## 必要条件

- Java 17以降
- Maven

## ソースからビルド

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
mvn -f packages/sdk/agent-sdk-java/pom.xml package
```

サンプルを実行する前に、アプリケーション環境で `PHASEO_API_KEY` を設定してください。
