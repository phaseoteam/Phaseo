現在のソースには、Maven Central の古い 3.0.0 アーティファクトにない再試行制御とレスポンスメタデータが含まれます。現在の SDK を使うには、以下の指定リビジョンをビルドしてください。

## 要件

- Java 17+
- Maven 3.8+
- Git

## ソースからビルド

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
git checkout 1ff1119f41ceb3ac2c85ed605f6e1c4beca6e011
mvn -f packages/sdk/sdk-java/pom.xml -DskipTests install
```

Maven は Jackson 依存関係とともに `app.phaseo:phaseo-sdk:3.0.0` をローカルリポジトリにインストールします。

## 依存関係の追加

```xml
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-sdk</artifactId>
  <version>3.0.0</version>
</dependency>
```

<Note>[Maven Central アーティファクト](https://repo.maven.apache.org/maven2/app/phaseo/phaseo-sdk/3.0.0/) は旧 API を提供します。現在の再試行、メタデータ、パラメータ検証 API は含まれません。</Note>
