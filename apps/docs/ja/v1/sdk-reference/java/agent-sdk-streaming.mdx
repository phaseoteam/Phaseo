title: "ストリーミング"
description: "再走査可能なコンシューマーで、Javaエージェントのテキストとイベントをストリーミングします。"
---

`Agent.stream(...)`は`StreamResult`を返します。

```java
var stream = agent.stream(options);

for (var delta : stream.textStream()) {
  System.out.print(delta);
}

var completed = stream.getResult();
```

`textStream()`と`fullStream()`は再走査できるため、プロダクトUIとテレメトリーコードで同じ実行をそれぞれ独立して利用できます。アクティブなストリームワーカーを中断するには`cancel()`を呼び出します。

Javaの項目イベントは引き続き汎用オブジェクトであり、TypeScriptの判別可能なユニオン型`AgentItem`ではありません。
