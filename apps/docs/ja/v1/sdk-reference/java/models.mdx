**メソッド**: `client.listModels(...)`

```java
import app.phaseo.sdk.Phaseo;
import java.util.HashMap;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

Map<String, String> query = new HashMap<>();
query.put("limit", "10");
query.put("provider", "anthropic");
query.put("provider_status", "beta,not_ready");
query.put("provider_availability_reason", "preview_only,provider_not_ready");
query.put("capability_status", "coming_soon,internal_testing");
query.put("availability", "all");

Object models = client.listModels(query);
System.out.println(String.valueOf(models));
```

よく使うクエリキーには、`provider`、`provider_status`、`provider_routing_status`、`model_routing_status`、`capability_status`、`provider_availability_status`、`provider_availability_reason`、`status`、`organisation`、`endpoints`、`input_types`、`output_types`、`params`、`availability`、`limit`、`offset`があります。

`availability=all`と併せて`provider_availability_reason`を使うと、`preview_only`、`provider_not_ready`、`gated`、`access_limited`、`region_limited`、`project_limited`、`paused`、`soft_blocked`などのロールアウト状態を取得できます。`availability=all`と`capability_status`を併用すると、`coming_soon`や`internal_testing`などルーティングできないエンドポイントの対応情報を取得できます。
