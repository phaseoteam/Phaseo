---

エージェントをプロダクトのタイムライン、監査ログ、テレメトリーパイプラインに接続するには、`RunOptions`にイベントコンシューマーを渡します。

```java
event -> logger.info("{} {}", event.type(), event.runId())
```

イベントの種類：

- 実行の開始、再開、人による応答待ち、完了、キャンセル、失敗
- ステップの開始、チェックポイント、完了、キャンセル、失敗
- モデルのリクエスト、完了、失敗
- ツールの開始、事前進捗、完了、失敗

コールバックは短時間で処理します。時間のかかる保存処理やネットワーク処理は実行ループの外でキューに入れます。
