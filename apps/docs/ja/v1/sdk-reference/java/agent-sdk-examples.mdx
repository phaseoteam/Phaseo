次のパターンから始めてください。

| パターン | 組み合わせるもの |
| --- | --- |
| サポートの振り分け | 管理プリセット、検索ツール、構造化された最終出力 |
| コードレビュー | ファイルまたはパッチ用ツール、進捗イベント、編集前の承認 |
| 調査ブリーフ | 管理されたWebツール、コストとステップの上限、ストリーミングテキスト |
| 運用ランブック | ステータス確認ツール、手動エスカレーション、永続化された続行 |

最初の実装は小さく保ちます。エージェント1つ、決定論的なツール1～2個、副作用を伴う操作への明示的な承認から始めてください。
