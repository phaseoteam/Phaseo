Java SDK でテキスト、埋め込み、モデル一覧のリクエストを送信します。

<Note>現在のソースには、Maven Central の古い 3.0.0 アーティファクトにない再試行制御とレスポンスメタデータが含まれます。現在の SDK を使うには、以下の指定リビジョンをビルドしてください。 [インストール](./installation)</Note>

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

## 対応するリクエスト

JSON リクエストには `createResponse`、`createChatCompletion`、`createEmbedding`、`listModels` を使います。`Map` または `JsonNode` を渡してください。JSON 文字列はクライアントのメソッドに渡す前に解析します。

## ストリーミング

`streamResponse` と `rawClient().requestLines` は、到着した SSE 行を逐次返します。try-with-resources でストリームを閉じ、イベント名、データ行、完了マーカーをアプリケーションで処理してください。

<Note>`createSpeech` は JSON を想定しており、バイナリ音声をデコードできません。音声の取得には `rawClient().requestBytes` を使ってください。</Note>
