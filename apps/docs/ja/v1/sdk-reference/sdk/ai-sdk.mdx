`@phaseo/ai-sdk-provider` をインストールし、`generateText`、`streamText`、またはその他の Vercel AI SDK 7 関数の `model` に `phaseo(modelId)` を渡します。テキストリクエストは Gateway の `/v1/chat/completions` エンドポイントに送られます。

## インストール

<CodeGroup>

```bash title="npm"
npm install @phaseo/ai-sdk-provider
```

```bash title="pnpm"
pnpm add @phaseo/ai-sdk-provider
```

```bash title="yarn"
yarn add @phaseo/ai-sdk-provider
```

```bash title="bun"
bun add @phaseo/ai-sdk-provider
```

</CodeGroup>

バージョンを指定しないと npm の `latest` タグがインストールされ、これは AI SDK 7 系です。このパッケージは `ai@^7` をピア依存関係として宣言しているため、ピアを自動インストールするパッケージマネージャーでは自動で追加されます。

サーバー環境に `PHASEO_API_KEY` を設定し、最初のリクエストを送信します。デフォルトの `phaseo` エクスポートは、`PHASEO_API_KEY` が設定されていないとエラーをスローします。

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Reply with: AI SDK works",
});

console.log(result.text);
console.log(result.providerMetadata);
```

現在のモデル ID は [Models エンドポイント](../../api-reference/endpoint/models.mdx)から取得してください。

## テキストをストリーミングする

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Stream a short greeting.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## プロバイダーインスタンスを設定する

`createPhaseo()` を呼び出して、`apiKey`、`baseURL`、`headers`、またはカスタムの `fetch` を設定します。Phaseo のリクエスト詳細でアプリケーションを識別するためにも使えます。

```typescript
import { createPhaseo } from "@phaseo/ai-sdk-provider";

const phaseo = createPhaseo({
  apiKey: process.env.PHASEO_API_KEY,
  headers: {
    "x-title": "My App",
    "http-referer": "https://example.com",
  },
});
```

`PHASEO_BASE_URL` は省略可能で、デフォルトは `https://api.phaseo.app/v1` です。

## モデルの種類を選ぶ

| プロバイダーのメソッド | AI SDK の関数 |
| --- | --- |
| `phaseo(modelId)` または `phaseo.languageModel(modelId)` | `generateText`、`streamText` |
| `phaseo.embeddingModel(modelId)`（別名 `textEmbeddingModel`） | `embed`、`embedMany` |
| `phaseo.imageModel(modelId)` | `generateImage` |
| `phaseo.transcriptionModel(modelId)` | `transcribe` |
| `phaseo.speechModel(modelId)` | `generateSpeech` |
| `phaseo.rerankingModel(modelId)` | `rerank` |

`rerankingModel` 以外のすべてのメソッドは、2番目の引数としてモデルごとの設定を任意で受け付けます。設定できるのは `temperature`、`topP`、`topK`、`maxTokens`、`frequencyPenalty`、`presencePenalty`、`seed`、`user`、`headers`、`fetch` です。

## サポートしている AI SDK 7 の機能

- テキストの生成とストリーミング
- 推論の出力と設定
- 関数ツールと、ストリーミングされるツール入力
- JSON と JSON Schema の出力
- テキストと画像のファイル入力
- URL の引用元
- 埋め込みと画像生成
- リランキング
- 文字起こしと音声生成
- プロバイダーのメタデータ、使用量、中止シグナル、未加工のストリームチャンク

呼び出しで実際にできることは、モデルとプロバイダーによって異なります。このプロバイダーは、管理されたファイル参照、スキル、プロバイダー側で実行されるツール（その定義、結果、承認レスポンス）には対応していません。アプリケーションが実行する関数ツールには、AI SDK の通常の実行と承認のフローを使います。

## 以前の AI SDK バージョンを使う

| AI SDK | インストール |
| --- | --- |
| 7 | `@phaseo/ai-sdk-provider`（`latest`） |
| 6 | `@phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `@phaseo/ai-sdk-provider@ai-sdk-v5` |

ピアの自動インストールが無効な場合は、対応するメジャーバージョンの `ai`（`ai@^7`、`ai@^6`、または `ai@^5`）を自分でインストールしてください。
