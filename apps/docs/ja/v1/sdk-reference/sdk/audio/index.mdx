音声認識には `phaseo.transcriptionModel(modelId)` を `transcribe` に、音声合成には `phaseo.speechModel(modelId)` を `generateSpeech` に渡します。プロバイダーは音声をマルチパートフォームとして `/v1/audio/transcriptions` にアップロードし、音声合成のリクエストを `/v1/audio/speech` に送信します。

```ts
import { readFileSync, writeFileSync } from "node:fs";
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateSpeech, transcribe } from "ai";

const transcription = await transcribe({
  model: phaseo.transcriptionModel("openai/whisper-1"),
  audio: readFileSync("./audio.mp3"),
});

console.log(transcription.text);
console.log(transcription.providerMetadata);

const speech = await generateSpeech({
  model: phaseo.speechModel("openai/gpt-4o-mini-tts"),
  text: "Hello from Phaseo audio.",
  voice: "alloy",
  outputFormat: "mp3",
});

writeFileSync("./speech.mp3", Buffer.from(speech.audio.uint8Array));
console.log(speech.providerMetadata);
```

`audio` には `Buffer`、`Uint8Array`、`ArrayBuffer`、base64 文字列、または `URL` を渡せます。AI SDK 7 は、以前の `experimental_transcribe` と `experimental_generateSpeech` という名前も別名として引き続きエクスポートしています。

## 長い音声や失敗する音声に対処する

- サポートされる入力形式と出力形式はモデルによって異なります。
- 長いファイルではタイムアウトを延ばし、アップロードはモデルのサイズ上限（ほとんどのモデルで 25 MB）以内に収めてください。
- 一時的な `429` と `5xx` レスポンスは、バックオフを入れて再試行してください。
