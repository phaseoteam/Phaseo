`generateText` に `output: Output.object({ schema })` を渡すと、スキーマに一致する型付きオブジェクトを取得できます。AI SDK はスキーマを JSON Schema のレスポンス形式として送信し、結果を検証します。

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, Output } from "ai";
import { z } from "zod";

const { output } = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  output: Output.object({
    schema: z.object({
      title: z.string(),
      priority: z.enum(["low", "medium", "high"]),
      actions: z.array(z.string()),
    }),
  }),
  prompt: "Create a short incident follow-up plan.",
});

console.log(output);
```

AI SDK 7 でも `generateObject` は同じ `schema` で動作し `object` を返しますが、非推奨となっており、`output` を指定した `generateText` が推奨されます。

## 無効な出力に対処する

モデルが使えるオブジェクトを返さなかった場合（たとえば最後のステップがツール呼び出しで終わった場合）、`output` を読み取ると `NoOutputGeneratedError` がスローされます。モデルを呼び出す箇所でキャッチしてください。

- スキーマでは明示的な enum と必須フィールドを使います。
- プロンプトはスキーマの形と一致させます。
- JSON Schema 出力への対応はモデルによって異なります。`/v1/models` でモデルがサポートするパラメーターを確認してください。
