AI SDK の `tool()` ヘルパーでツールを定義して `generateText` に渡し、ツールの実行後にモデルが回答できるように `stopWhen` を設定します。

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, stepCountIs, tool } from "ai";
import { z } from "zod";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "What is 17 + 25? Use the calculator tool.",
  tools: {
    calculator: tool({
      description: "Perform basic arithmetic",
      inputSchema: z.object({
        operation: z.enum(["add", "subtract", "multiply", "divide"]),
        a: z.number(),
        b: z.number(),
      }),
      execute: async ({ operation, a, b }) => {
        if (operation === "add") return a + b;
        if (operation === "subtract") return a - b;
        if (operation === "multiply") return a * b;
        return a / b;
      },
    }),
  },
  stopWhen: stepCountIs(2),
});

console.log(result.text);
```

デフォルトでは、`generateText` は1ステップで停止します。そのステップがツール呼び出しの場合、`result.text` は空になり、ツールの結果は `result.toolResults` に入ります。`stepCountIs(2)` を指定すると、モデルは2番目のステップで結果を使って回答できます。

## 安全なツールを書く

- 説明は正確に、入力スキーマは厳密にしてください。引数はモデルが埋めます。
- 引数は信頼できない入力として扱ってください。副作用を起こす前に `execute` 内で検証します。
- 一時的に失敗する下流の API に対しては、`execute` 内に再試行とバックオフを追加してください。
