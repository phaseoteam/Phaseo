プロバイダー、研究者、上級ユーザーからの投稿を歓迎します。以下の手順に沿って、投稿を迅速に処理できるようにしてください。

---

## 1. データを準備する

- ベンチマークが `/data/benchmarks` にあることを確認します。なければ、追加を提案する issue を作成します。
- プロンプト形式、評価ハーネス、ハードウェアの詳細を含む生の結果を集めます。
- 公開されている場合は、出典（ブログ記事、論文、データセットのリポジトリ）を記載します。

> ✅ **ヒント**
> 再現可能なスクリプトやノートブックを共有すると、検証を大幅に早められます。

---

## 2. リポジトリをフォークする

1. [github.com/phaseoteam/data](https://github.com/phaseoteam/data) をフォークします。
2. 新しいブランチを作成します（例：`add-claude-3.5-sonnet-mmlu`）。
3. 該当するベンチマークの JSON にスコアとメタデータを追加します。

---

## 3. 検証を実行する

リポジトリのツールを使い、構造と値の範囲が正しいことを確認します。

```bash
pnpm install
pnpm run validate:benchmarks
```

報告された問題を修正してから pull request を送信してください。

---

## 4. pull request を開く

PR の説明に次の情報を含めてください。

- ベンチマーク名とデータ分割（例：`GSM8K test`）。
- モデル ID とプロバイダー。
- 出典または評価ログへのリンク。
- スコアの算出方法の概要。

メンテナーが投稿を確認し、必要に応じて詳細を質問したうえで、承認後にマージします。

---

## 5. 公開状況を確認する

マージ後、スコアは次回の予定データ同期で表示されます。Discord の #data-updates チャンネルまたは公開 changelog で進捗を確認できます。
