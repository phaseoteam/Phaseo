元のベンチマークを主要な出典として引用し、モデルを検索、比較、監視した場所として Phaseo へのリンクを記載してください。方法、脚注、謝辞のいずれかにリンクがあれば十分です。

> 本研究では、[Phaseo](https://phaseo.app) のモデルメタデータと集約済みベンチマーク結果を使用しました。

## 正式な引用

データにアクセスした年を使ってください。

<CodeGroup>
```text APA
Phaseo. (2026). Phaseo: Aggregated benchmarks and gateway for AI models. https://phaseo.app
```

```bibtex BibTeX
@misc{phaseo-2026,
    title  = {Phaseo: Aggregated benchmarks and gateway for AI models},
    author = {{Phaseo Team}},
    year   = {2026},
    url    = {https://phaseo.app}
}
```
</CodeGroup>

## ベンチマークスコアを引用する

Phaseo はベンチマークを実行しません。ベンチマークの作成者、モデル開発者、インデックスの発行元が報告したスコアを、それぞれの出典へのリンクとともに掲載しています（[ベンチマークの方法論](./benchmark-methodology.mdx)を参照）。

Phaseo で見つけたスコアを使う場合：

1. 元のベンチマークと論文を主要な出典として引用します。
2. 必要に応じて、スコアを取得または比較した場所として Phaseo に言及します。
3. ベンチマーク名と分割（例：`MMLU test`）、Phaseo のモデル ID とプロバイダー、Phaseo のページまたは API 呼び出しの URL、アクセスした日付を記載します。

> ベンチマークスコアは Phaseo 経由で取得しました（MMLU test 分割）。2026 年 3 月 3 日にアクセス。モデル：`openai/gpt-6-astra`、プロバイダー：OpenAI。

## Gateway に言及する

Phaseo をデータの出典ではなく統合レイヤーとして使った場合は、Gateway として説明し、[API リファレンス](../api-reference/introduction.mdx)にリンクしてください。

> Phaseo Gateway を使い、単一の API から OpenAI、Anthropic、Google のモデルを呼び出しました。
