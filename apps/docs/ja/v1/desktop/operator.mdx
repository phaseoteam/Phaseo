オペレーターは、他のチャットやエージェントを調整するピン留めされたチャットです。作業の監視、変更時に関連する会話を開くこと、アプリ設定の更新を依頼できます。

## オペレーターを開く

まず通常のチャットを始め、Phaseo が使用するエージェント、アカウント、モデルを用意します。`Ctrl+K`（macOS では `Cmd+K`）でコマンドパレットを開き、**Operator** を選びます。再度開くと同じチャットに戻ります。

<Warning>
オペレーターは、プロジェクトフォルダーなしで Code の Full access として起動します。委任先のエージェントには、オペレーター自身より広い権限を与えられません。自分の代わりに操作させることを信頼できるアカウントとエージェントでのみ使ってください。
</Warning>

## 監視する対象を伝える

具体的なタスクと対象のチャット名を伝えます。例：

> 「リリース確認」というチャットを監視してください。完了または失敗したら開いて通知してください。プロジェクトは変更しないでください。

オペレーターは自身でイベントを購読します。チャットの完了、失敗、対応が必要なリクエスト、利用上限に加え、既存のプルリクエストや Issue の監視から届く更新を監視できます。イベントはメッセージとして届き、短時間に集中したイベントはまとめてからオペレーターを起動します。

ページを開いたり設定を変更したりするよう依頼することもできます。

> Appearance を開いて、パネルのアニメーションを 300 ms に設定してください。

## 一時停止と再開

オペレーターの通知で **Pause**、またはコマンドパレットで **Pause the operator** を選ぶと、オペレーターとそのエージェントが停止します。受信イベントは保留されます。**Resume** で再び受信できます。

既定の保護設定ではイベントによる起動は 1 時間に 12 回までで、ツールを呼び出さない起動が 4 回連続すると一時停止します。オペレーターとそのエージェントの記録済み Phaseo 支出が既定の $5 上限に達すると一時停止します。この上限ではサブスクリプション利用の金額は算出されません。上限で停止したら **Raise the cap by $5**、次に **Resume** を選びます。上限を引き上げたり再開したりできるのはユーザーだけです。

プレビュー版は、すべてのアプリイベントの監視やリモート環境の操作にはまだ対応していません。小さなタスクから始め、メッセージと操作を確認してから担当範囲を広げてください。
