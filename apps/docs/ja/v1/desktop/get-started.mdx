Phaseo Desktop は、会話、コーディングエージェント、プロジェクト用ツールを一つのアプリにまとめます。まず個人用チャットを始め、エージェントにファイルを扱わせたいときにプロジェクトを追加します。

<Note>
このガイドはデスクトップのプレビュー版を対象としています。利用できる機能は、ビルドと接続したエージェントによって異なります。
</Note>

## アプリを開く

プレビュー版をお持ちの場合は Phaseo を開きます。ソースから実行するには、Git、Node.js 24、pnpm 10.33 をインストールし、次を実行します。

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
pnpm install
pnpm --filter @phaseo/desktop dev
```

開発コマンドは必要なパッケージをビルドし、デスクトップウィンドウを開きます。使用中はターミナルを起動したままにしてください。

## アカウントを接続する

Phaseo にサインインするには **Settings → Phaseo account** を開きます。API キーやエージェントのサブスクリプションには **Settings → Accounts** を使うか、このコンピューターでサインイン済みのコーディングエージェントを使います。**Settings → Agents** には、端末で利用できるエージェントが表示されます。

使用できるモデルと利用料金の請求方法はアカウントによって決まります。接続したサブスクリプションには提供元の利用上限が適用され、Phaseo 経由のリクエストには Phaseo アカウントが使われます。

## チャットを始める

1. **Chat**、**New chat** の順に選択します。
2. メッセージ欄の横にあるモデル選択を開きます。エージェントとモデルを選び、対応している場合は推論や速度を調整します。
3. メッセージを入力して送信します。プロジェクトは不要です。

モデルが表示されない場合は、**Phaseo account** または **Accounts** でサインイン状態を、**Agents** でエージェントが利用可能かを確認します。

## 自分好みに設定する

**Settings → Appearance** ではテーマ、フォント、パネルのアニメーション時間を設定できます。範囲は 0～600 ms、既定値は 200 ms です。ミニチュアのワークスペースをクリックするとプレビューできます。0 にする、**Animations** をオフにする、またはシステムで視差効果を減らす設定を有効にすると、パネルはすぐに表示されます。

`Ctrl+K`（macOS では `Cmd+K`）でチャットやコマンドを検索できます。**Settings → Keyboard shortcuts** には現在のショートカットが表示されます。
