一般的な会話には **Chat** を使います。エージェントにプロジェクトフォルダー内で作業させ、会話の横で変更を確認する場合は **Code** に切り替えます。

## プロジェクトで作業を始める

フォルダーをプロジェクトとして追加し、**Code** で選択してチャットを始めます。メッセージ欄でエージェントとモデルを選びます。関連する作業には同じチェックアウトを使い、専用のブランチとファイルが必要な場合は新しい Git ワークツリーを選びます。

送信前にモデル選択で権限を確認してください。**Ask first** では承認が必要なリクエストを確認できます。より広い権限ではエージェントが自動で実行できる操作が増えます。選択できる権限はエージェントによって異なります。

## 追加メッセージをキューに入れるか実行中に送る

既定では、エージェントの作業中に送信したメッセージは次のターンのキューに入ります。メッセージ欄の上で編集、並べ替え、削除ができます。

エージェントが対応している場合、キュー内のメッセージで **Send now** を選ぶと実行中のターンに追加できます。`Ctrl+Shift+Enter`（macOS では `Cmd+Shift+Enter`）で下書きを実行中のターンに送り、欄が空の場合はキューの先頭のメッセージを送ります。非対応のエージェントではメッセージはキューに残ります。

既定の動作は **Settings → Chat → Follow-ups while an agent works** で変更できます。**Stop** は現在のターンを中断します。

## 作業を確認する

右側のパネルでファイル、差分、ターミナル、プルリクエスト、ブラウザーを開けます。会話の横に表示され、パネルを閉じても後で戻れます。

コミットや公開の前に、変更されたファイルとコマンド出力を確認してください。チャットのステップにはエージェントの操作が表示され、展開すると詳細を確認できます。権限リクエストや質問は、内容を読んでから回答してください。

## チャットを整理する

よく使うチャットをピン留めし、`Ctrl+K`（macOS では `Cmd+K`）で検索します。別の方法を試すにはチャットを分岐します。**Code** では完了した作業を整理してアクティブな一覧を短くできます。**Settled** から戻ることができ、新しいアクティビティがあるとチャットが再びアクティブになります。

チャットをまたいで作業を調整するエージェントについては[オペレーター](./operator.mdx)を、設定や外観については[スタートガイド](./get-started.mdx)をご覧ください。
