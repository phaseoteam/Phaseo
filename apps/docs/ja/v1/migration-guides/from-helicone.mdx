クライアントの接続先を Phaseo キーとともに `https://api.phaseo.app/v1` に向け、`Helicone-Auth` を削除し、まだ必要な `Helicone-*` ヘッダーをそれぞれ Phaseo の対応するものに移します。リクエストの変更は小さいので、オブザーバビリティの切り替えも同じくらい慎重に計画してください。

| 設定 | Helicone | Phaseo |
| --- | --- | --- |
| ベース URL | `oai.helicone.ai/v1`、`anthropic.helicone.ai`、`ai-gateway.helicone.ai`、または `Helicone-Target-URL` 付きの `gateway.helicone.ai` | `https://api.phaseo.app/v1` |
| 認証 | プロバイダーキーと `Helicone-Auth`、または AI Gateway での `HELICONE_API_KEY` | `PHASEO_API_KEY` のみ |
| カスタムプロパティ | `Helicone-Property-<Name>` | `X-Phaseo-Metadata` のラベル |
| リクエストの可視化 | Helicone のダッシュボード | Phaseo のリクエストログとリクエストの詳細 |

## クライアントを切り替える

<CodeGroup>
```typescript TypeScript
import OpenAI from "openai";

// Before:
// new OpenAI({
//   apiKey: process.env.OPENAI_API_KEY,
//   baseURL: "https://oai.helicone.ai/v1",
//   defaultHeaders: {
//     "Helicone-Auth": `Bearer ${process.env.HELICONE_API_KEY}`,
//     "Helicone-Property-Team": "support",
//   },
// });
const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
  defaultHeaders: {
    "X-Phaseo-Metadata": JSON.stringify({ labels: [{ key: "team", value: "support" }] }),
  },
});

const response = await client.chat.completions.create(
  {
    model: "openai/gpt-6-astra",
    messages: [{ role: "user", content: "Reply with: migration ready" }],
  },
  { headers: { "X-Phaseo-User-Id": "user_123" } },
);
```

```python Python
import json
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
    default_headers={
        "X-Phaseo-Metadata": json.dumps({"labels": [{"key": "team", "value": "support"}]}),
    },
)
```

```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [{"role": "user", "content": "Reply with: migration ready"}]
  }'
```
</CodeGroup>

ユーザー ID のようなリクエストごとの値は、クライアントではなくリクエストに付けます。`anthropic.helicone.ai` のルートは、[Anthropic SDK からの移行](./from-anthropic)の設定に移します。

Helicone AI Gateway では、ルーティングは `model` 文字列に含まれています。これを分割してください。カンマ区切りの最初の項目が `model` になり、残りが `models` 配列になります。`<model>/<provider>` による固定は `provider.only` または `provider:org/model` 形式の ID に、`!provider` による除外は `provider.ignore` になります。

## Helicone のヘッダーを対応付ける

| Helicone | Phaseo での扱い |
| --- | --- |
| `Helicone-Auth` | 削除します。 |
| `Helicone-Property-<Name>` | `X-Phaseo-Metadata` の[ラベル](../guides/request-labels)。最大 32 個で、キーは `[A-Za-z0-9_.:-]`(64 文字)に一致する必要があるため、スペースを含むプロパティは名前を変えてください。不正な JSON や重複したキーは `400` を返します。ラベルに個人データを入れないでください。 |
| `Helicone-User-Id` | ボディの `user` フィールドまたは `X-Phaseo-User-Id`。エンドユーザー向けのレート制限ポリシーのキーにもなります。 |
| `Helicone-Session-Id` | ボディの `session_id` フィールド。トレースツリーではなく、キャッシュとプロバイダーのアフィニティに使われます。 |
| `Helicone-Session-Path`、`Helicone-Session-Name` | ボディの `metadata.trace_id`、`parent_span_id`、`trace_name`、`span_name`、または W3C の `traceparent` ヘッダー。これらはオブザーバビリティの送信先に送られるスパンの構造を決めます。Phaseo 自身のログにはトレースツリーはありません。 |
| `Helicone-Cache-Enabled` | レスポンスキャッシュはありません。必要ならアプリでキャッシュしてください。 |
| `Helicone-Fallbacks`、`Helicone-Retry-Enabled` | `429`、`500`、`502`、`503`、`504` で試される `models` 配列と、組み込みのプロバイダーフォールバック。クライアント側のバックオフは残してください。 |
| `Helicone-RateLimit-Policy` | レート制限ポリシーとキーの制限。[制限](../api-reference/limits)を参照してください。 |
| `Helicone-LLM-Security-Enabled` | ガードレールのプロンプトインジェクション検出。対象はリクエストのみです。 |
| `Helicone-Moderations-Enabled` | Gateway 内の代替はありません。アプリから `/v1/moderations` を呼び出してください。 |
| `Helicone-Omit-Request`、`Helicone-Omit-Response` | ワークスペースのログポリシーまたはゼロデータ保持。 |
| `Helicone-Posthog-*` | PostHog の[オブザーバビリティの送信先](../guides/integrations/observability)。 |
| プロンプト管理 | [プリセットのプロンプトテンプレート](../guides/prompt-templates): `"prompt": {"id": "@slug", "version": "production", "variables": {...}}`。 |

## リクエストの可視化を移す

デバッグには、リクエストログ、リクエスト ID、プロバイダーの試行、料金の詳細を使います。チームがテレメトリをエクスポートしている場合は、空白期間が生じないよう、切り替え前に対応する[オブザーバビリティの送信先](../guides/integrations/observability)を接続してください。トラフィックをプロキシしない Helicone の非同期ロギングは、Gateway の置き換えとは別に判断します。

## テストして展開する

Helicone のヘッダーなしでリクエストが成功すること、そしてインシデント時にチームが確認する事項に引き続き答えられることを検証します。トラフィックを移す前に、次を確認してください。

- Helicone の URL と `Helicone-*` ヘッダーがすべて削除または対応付けされている
- 本番のモデル ID が `GET /v1/models?format=openai` にある
- チームが必要とするアラートとダッシュボードに代わるものがある
- 切り戻しが引き続きベース URL とキーの変更だけで済む
