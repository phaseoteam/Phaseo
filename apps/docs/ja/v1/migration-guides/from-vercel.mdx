AI SDK のコードでは、`@ai-sdk/gateway` を `@phaseo/ai-sdk-provider` に置き換え、各モデル ID を `phaseo(...)` で囲みます。OpenAI 互換のクライアントでは、ベース URL とキーを変更します。生成のロジックは変わりません。

| 設定 | Vercel AI Gateway | Phaseo |
| --- | --- | --- |
| ベース URL | `https://ai-gateway.vercel.sh/v1` | `https://api.phaseo.app/v1` |
| API キー | `AI_GATEWAY_API_KEY` または Vercel OIDC | `PHASEO_API_KEY`。サーバー側のシークレットとして保持 |
| AI SDK プロバイダー | `@ai-sdk/gateway`、または文字列のみのモデル指定 | `@phaseo/ai-sdk-provider` |
| ルーティングのオプション | `providerOptions.gateway` | `providerOptions.phaseo` |

## プロバイダーを切り替える

<CodeGroup>
```typescript AI SDK
import { generateText } from "ai";
// Before: import { gateway } from "@ai-sdk/gateway";
import { phaseo } from "@phaseo/ai-sdk-provider";

const { text } = await generateText({
  // Before: model: gateway("openai/gpt-4.1-mini"),
  model: phaseo("openai/gpt-4.1-mini"),
  prompt: "Generate a migration checklist.",
});
```

```typescript OpenAI SDK
import OpenAI from "openai";

// Before:
// new OpenAI({ apiKey: process.env.AI_GATEWAY_API_KEY, baseURL: "https://ai-gateway.vercel.sh/v1" });
const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});
```

```bash cURL
curl -s "https://api.phaseo.app/v1/chat/completions" \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [{"role":"user","content":"Hello"}]
  }'
```
</CodeGroup>

既定の `phaseo` エクスポートは、モジュールのインポート時に `PHASEO_API_KEY` を一度だけ読み込み、`https://api.phaseo.app/v1` を使います。一部のサーバーレス環境やテスト環境のように、インポート後に変数を設定すると、すべての呼び出しがキー未設定のエラーをスローします。その場合は、ハンドラー内で `createPhaseo({ apiKey, baseURL, headers })` を呼び出してください。

`ai` のメジャーバージョンに合ったプロバイダーをインストールします。AI SDK 7 には `@phaseo/ai-sdk-provider`、AI SDK 6 には `@phaseo/ai-sdk-provider@ai-sdk-v6`、AI SDK 5 には `@phaseo/ai-sdk-provider@ai-sdk-v5` を使います。

AI SDK は、文字列のみのモデル指定(`model: "openai/gpt-4.1-mini"`)を既定で Vercel の Gateway に送るため、文字列のまま残った指定は Vercel を呼び出し続けます。共有のモデルファクトリを一度変更してから、AI SDK の呼び出しで `model: "` を検索してください。`ai-gateway.vercel.sh` に向けた Anthropic SDK のクライアントは、[Anthropic SDK からの移行](./from-anthropic)の設定に移します。

## Gateway のオプションを対応付ける

`providerOptions.phaseo` はリクエストのボディにマージされます。残った `providerOptions.gateway` はエラーにならずに無視されます。

| Vercel AI Gateway | Phaseo での扱い |
| --- | --- |
| `providerOptions.gateway.order`、`.only` | `providerOptions: { phaseo: { provider: { order, only } } }`、または `phaseo("@slug")` として呼び出す[プリセット](../guides/presets)。 |
| `providerOptions.gateway.models` | `providerOptions: { phaseo: { models: [...] } }`、または動的ルートのフォールバック。 |
| `providerOptions.gateway.sort`(`cost`、`ttft`、`tps`) | `provider.sort`(`price`、`latency`、`throughput`)。 |
| `providerOptions.gateway.zeroDataRetention` | `provider.require_zero_data_retention`。ルーティングを ZDR プロバイダーに限定します。 |
| `providerOptions.gateway.user`、`.tags` | `user` と `X-Phaseo-Metadata` の[ラベル](../guides/request-labels)。 |
| リクエスト単位の `byok` 認証情報 | 代替はありません。`phaseo byok create` でワークスペースにプロバイダーキーを追加してください。 |
| テキスト、ストリーミング、ツール、構造化出力、埋め込み、画像、文字起こし、音声合成 | プロバイダーがサポートしています。ただし、対応する機能はモデルによって異なります。 |
| リランキング | AI SDK 6 と 7 の系列で `phaseo.rerankingModel(id)`。 |
| 管理されたファイル参照、プロバイダー実行のツール | サポートされていません。サポートされていない部分は削除されず、エラーになります。 |
| Gateway の使用量ダッシュボード | Phaseo のリクエストログと `GET /v1/generations?id=<request_id>`。結果のプロバイダーメタデータにはリクエスト ID が含まれます。 |

## テストして展開する

同じプロンプトセットを両方の経路で実行し、レイテンシー、出力形式、トークン使用量を比較します。トラフィックを移す前に、次を確認してください。

- Gateway キーがあったすべてのランタイム(エッジ、サーバー、プレビューのデプロイを含む)に `PHASEO_API_KEY` が設定されている
- ステージングで、主要なテキスト生成の経路と 1 つのストリーミングテストが変更なしで通る
- アプリが使う場合は、ツール呼び出しと構造化出力が通る
- アプリケーションレベルのエラーの対応付けが引き続き機能する
- ステージングで失敗したリクエストを見つけられ、`replay_supported` が `true` の場合は `GET /v1/generations?id=<request_id>` からリプレイできる

機能フラグまたは割合指定の展開を使い、社内のトラフィックから出荷します。レイテンシー、エラー率、トークンとコストのずれを監視し、切り戻しにコード変更が要らないよう、少なくとも 1 リリースの間は旧プロバイダーを使える状態にしておきます。

```bash
curl -s "https://api.phaseo.app/v1/health"
curl -s "https://api.phaseo.app/v1/models?format=openai" -H "Authorization: Bearer $PHASEO_API_KEY"
```

プロバイダーの詳細は [AI SDK](../guides/integrations/ai-sdk) を参照してください。
