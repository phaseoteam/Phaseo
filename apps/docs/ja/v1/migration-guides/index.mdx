Phaseo の移行ガイドでは、次の 2 種類の移行を扱います。

- 別のプラットフォームや Gateway から Phaseo への移行
- 同じプラットフォームでのモデルバージョンの更新

## モデルの移行

個別の開始チェックリストには[移行アシスタント](https://phaseo.app/migrate)を使ってください。

連携方法はほぼ変えず、使用するモデルだけを変更する場合に利用します。

次の内容を扱います。

- リクエストパラメーターの変更
- プロンプトや推論の動作の違い
- 構造化出力やツール呼び出しの違い
- 段階的な展開、フォールバック、ロールバックの方法

## ガイドの使い方

1. 変更対象がプラットフォーム、モデル、またはその両方かを確認します。
2. 移行で最もリスクの高い部分に合うガイドから始めます。
3. 出力品質を比べる前に、リクエストパラメーターと endpoint の動作を確認します。
4. 本番トラフィックを切り替える前に、本番に近い評価を実行します。
