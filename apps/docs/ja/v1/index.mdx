作りたいものは決まっているものの、Phaseo のどのドキュメントを最初に読むべきか分からない場合は、このページを使ってください。

Phaseo は、モデルへのアクセス、プロバイダーへのルーティング、料金の確認、利用状況の追跡、非同期 AI ワークフローを 1 つの API で提供します。

Phaseo を初めて使う場合は、まずリクエストを 1 つ成功させましょう。すでに AI を組み込んでいる場合は、アプリに合った移行ガイドまたは SDK ガイドに進んでください。

## 最初のリクエストを成功させる

新しい連携では、次の手順で進めます。

1. ダッシュボードで API キーを作成します。
2. 現行のテキストモデルにリクエストを送信します。
3. レスポンスから生成されたテキストを読み取ります。
4. 次の作業に合った SDK、ルーティング、本番運用のガイドに進みます。

## 最初のリクエスト

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-sol",
    "input": "Reply with: docs ready",
    "temperature": 0
  }'
```

```typescript TypeScript SDK
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-5.6-sol",
  input: "Reply with: docs ready",
  temperature: 0,
});

console.log(response.output_text);
```

```python Python SDK
from phaseo import Phaseo

client = Phaseo(api_key="YOUR_API_KEY")

response = client.generate_response(
    {
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with: docs ready",
        "temperature": 0,
    }
)

print(response.get("output_text"))
```
</CodeGroup>

動作したら、[クイックスタート](./quickstart.mdx)に進み、最初のリクエストの手順を最後まで確認してください。
