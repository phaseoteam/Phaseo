ターミナルやスクリプトから Phaseo を変更するには CLI を使い、AI クライアントに Phaseo の最新データを渡すには Phaseo MCP サーバーに接続します。どちらも Phaseo OAuth でログインします。

| インターフェース | 用途 | アクセス |
| --- | --- | --- |
| [Phaseo CLI](#phaseo-cli) | シェルや CI から、キーの作成、設定の変更、ワークスペースの管理、管理作業の自動化を行う | 読み取りと書き込み。スコープとワークスペースのロールによって制限されます |
| [Phaseo MCP](#phaseo-mcp) | Codex、Claude、ChatGPT などの MCP クライアントに Phaseo の最新データを渡し、必要に応じてアカウントの管理も任せる | アカウント管理付きで接続しない限り読み取り専用 |
| [Docs MCP](#docs-mcp) | コーディングアシスタントに最新の Phaseo ドキュメントを渡す | ドキュメントのみ。アカウントへのアクセスなし |
| [Phaseo プラグイン](#phaseo-plugin) | Claude Code や Codex に両方の MCP サーバーと Phaseo スキルをまとめてインストールする | 各 MCP サーバーと同じ |

<span id="phaseo-cli"></span>
## Phaseo CLI

### インストールしてログインする

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

対話型のターミナルでは、既定でブラウザーによる OAuth を使います。SSH、CI、ヘッドレス環境では、デバイス認可を使います。

```bash
phaseo login --device-code
```

### よく使う操作

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys list
phaseo logs list --since 1h --status error --json
```

別のツールやスクリプトで構造化された出力が必要な場合は `--json` を使います。シークレットの値は、明示的に作成または表示するコマンドでのみ表示されます。

## Phaseo MCP

サーバーの URL は `https://mcp.phaseo.app/mcp` です。これに接続した AI クライアントは、モデル、価格、プロバイダー、使用量、ワークスペースの最新データを使って質問に答えられます。

### クライアントを接続する

ワンクリックでインストール：[Cursor に追加](cursor://anysphere.cursor-deeplink/mcp/install?name=phaseo&config=eyJ1cmwiOiJodHRwczovL21jcC5waGFzZW8uYXBwL21jcCJ9) · [VS Code に追加](vscode:mcp/install?%7B%22name%22%3A%22phaseo%22%2C%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fmcp.phaseo.app%2Fmcp%22%7D)。クライアントからサインインを求められると、ブラウザで Phaseo OAuth が開きます。ワークスペースを選び、要求された読み取りスコープを承認してください。

<Tabs>
<Tab title="Claude Code">
```bash
claude mcp add --transport http phaseo https://mcp.phaseo.app/mcp
```

続けて `/mcp` を実行し、`phaseo` を選んで **Authenticate** を選択します。すべてのプロジェクトで使うには `--scope user` を付けます。
</Tab>
<Tab title="Codex">
```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
codex mcp list
```

ログインコマンドで Phaseo OAuth が開きます。`codex mcp list` で接続を確認できます。
</Tab>
<Tab title="Cursor">
```json ~/.cursor/mcp.json
{
  "mcpServers": {
    "phaseo": {
      "url": "https://mcp.phaseo.app/mcp"
    }
  }
}
```

上の **Cursor に追加** を使うか、`~/.cursor/mcp.json` にサーバーを追加し、Cursor の MCP 設定からサインインします。
</Tab>
<Tab title="VS Code">
```json .vscode/mcp.json
{
  "servers": {
    "phaseo": {
      "type": "http",
      "url": "https://mcp.phaseo.app/mcp"
    }
  }
}
```

上の **VS Code に追加** を使うか、`.vscode/mcp.json` にサーバーを追加します。MCP ビューからサーバーを起動し、VS Code に求められたらサインインします。
</Tab>
<Tab title="Claude">
Claude で **Settings → Connectors** を開き、**Add custom connector** を選んで `Phaseo` とサーバー URL を入力し、**Connect** を選択します。このオプションが表示されない場合は、Claude 組織のオーナーがカスタムコネクタを許可する必要があります。
</Tab>
<Tab title="OpenCode">
```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "phaseo": {
      "type": "remote",
      "url": "https://mcp.phaseo.app/mcp"
    }
  }
}
```

`opencode.json` にサーバーを追加し、`opencode mcp auth phaseo` を実行してサインインします。
</Tab>
</Tabs>

他の MCP クライアントでは、同じ URL をリモートの Streamable HTTP サーバーとして追加します。クライアントは、OAuth ディスカバリー、S256 PKCE を使う認可コード、MCP の `resource` パラメーターに対応している必要があります。

### Phaseo CLI のログインを使う

Phaseo CLI をすでに使っている場合、ローカルのエージェントは CLI を通じて MCP に接続できます。もう一度ログインする必要はありません。

```bash
phaseo login
claude mcp add --scope user phaseo -- phaseo mcp
# or, for Codex
codex mcp add phaseo -- phaseo mcp
```

`phaseo mcp` は CLI のログインを使って MCP を stdio で実行します。このログインを、MCP でのみ使える 15 分間有効なトークンに交換します。このトークンがログインより多くのアクセス権を持つことはなく、有料のモデル呼び出しも許可しません。`--manage` を付けない限り読み取り専用です。`phaseo setup codex` を実行すると、Codex の Phaseo プロファイルに自動で追加されます。この方法で接続したエージェントがログ、アクティビティ、分析を読み取ると、結果には全データを取得するための対応する CLI コマンドも表示されます。

### MCP が読み取れるデータ

読み取り専用のツールは、モデル、プロバイダー、ベンチマークのランキング、価格とコストの見積もりに加えて、クレジット、アクティビティ、分析、リクエストのログ、生成のメタデータを扱います。プロンプト、レスポンス、シークレットの値は決して返しません。

### アカウントを管理する（任意）

エージェントに Phaseo のワークスペースを変更させるには、代わりに管理用の URL で接続します。

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

ログインすると、同意画面に接続が要求する各権限（API キーの管理や予算の削除など）が一覧表示され、それぞれに **読み取り**、**書き込み**、**削除** のいずれかが表示されます。不要な権限はチェックを外してください。エージェントは許可した権限のツールだけを受け取り、Phaseo は変更のたびにワークスペースのロールも確認します。そのため、オーナーや管理者でないメンバーは、この方法で管理者専用の設定を変更することはできません。

すでに読み取り専用の URL で接続している場合は、クライアントを管理用の URL に切り替えて、もう一度ログインします。読み取り専用のアクセスに戻すには、通常の URL で再接続するか、**設定 → 接続アプリ** でアプリを取り消します。

管理用の接続は以下のすべてを読み取れますが、変更できるのは API キーとワークスペースの設定だけです。予算、支出ルール、プロバイダーキー、ガードレール、プリセット、Webhook、可観測性の送信先は、支出やリクエスト内容の送信先を左右するため、ダッシュボードまたは管理キーで変更します。

| 分野 | 読み取り | 変更 |
| --- | --- | --- |
| API キー | `api_keys_list`, `api_key_get` | `phaseo mcp --manage` の場合: `api_key_create`、`api_key_update`、`api_key_rotate`、`api_key_delete`。その他のクライアントは名前の変更（`api_key_update`）と削除（`api_key_delete`）のみ |
| 設定 | `settings_get` | `settings_update`（プライバシー、ログ記録、プロバイダー制限を維持または厳しくする変更） |
| 予算 | `budgets_list` | ダッシュボードで変更 |
| 支出ルール | `spend_rules_list` | ダッシュボードで変更 |
| プロバイダーキー（BYOK） | `provider_keys_list` | ダッシュボードで変更 |
| ガードレール | `guardrails_list`, `guardrail_get` | ダッシュボードで変更 |
| プリセット | `presets_list`, `preset_get` | ダッシュボードで変更 |
| Webhook | `webhooks_list` | ダッシュボードで変更 |
| 可観測性の送信先 | `observability_destinations_list` | ダッシュボードで変更 |

何かを変更または削除するツールにはその旨が示されるため、対応する MCP クライアントは呼び出しのたびに確認を求めます。新しい API キーはツールの結果に一度だけ表示され、再表示はできません。保存済みのプロバイダーキーや送信先の認証情報が返されることはありません。

MCP には、請求、支払い、ワークスペース、メンバー、管理キー、OAuth アプリのツールはありません。これらにはダッシュボード、CLI、または Management API を使ってください。

## Docs MCP

Docs MCP は、Phaseo のドキュメントを検索して読むための別のエンドポイントです。アカウントやワークスペースにはアクセスしません。

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

## Phaseo プラグイン

Phaseo プラグインには、Phaseo MCP、Docs MCP、そして連携、移行、モデル選択、使用量の監視、SDK、CLI のための Phaseo エージェントスキルがまとめられています。各要素を自分で接続する代わりに、一度インストールするだけで済みます。

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

`/mcp` を実行して `plugin:phaseo:phaseo` にログインし、Phaseo アカウントを接続します。スキルはリクエストが一致したときに読み込まれます。`/phaseo:phaseo-gateway` のように直接実行することもできます。

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

最後のコマンドで、Phaseo MCP 用の Phaseo OAuth が開きます。スキルはリクエストが一致したときに読み込まれます。
