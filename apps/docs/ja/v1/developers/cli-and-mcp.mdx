# CLI と MCP

CLI を使ってターミナルから Phaseo を操作するか、MCP 経由で AI クライアントを接続します。どちらも Phaseo OAuth を使いますが、用途は異なります。

| インターフェース | 主な用途 | アクセス |
| --- | --- | --- |
| Phaseo CLI | ターミナルでの作業、CI、管理、自動化 | スコープとワークスペースのロールに応じた読み取り・書き込み |
| Phaseo MCP | Codex、Claude、ChatGPT などの MCP クライアントから参照できる Phaseo の最新データと、任意のアカウント管理 | 認証済み。アカウント管理付きで接続しない限り読み取り専用 |
| Docs MCP | 開発中に Phaseo の最新ドキュメントを検索する | ドキュメントのみ・読み取り専用 |
| Phaseo プラグイン | Claude Code や Codex に Phaseo MCP、Docs MCP、Phaseo スキルをまとめてインストールする | 各 MCP サーバーと同じ |

## Phaseo CLI

Phaseo CLI は、Phaseo リソースの作成・変更、ワークフローのスクリプト化、シェルからのアカウント情報の確認に使用します。

### インストールしてログイン

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

対話型ターミナルでは、デフォルトでブラウザー OAuth を使用します。SSH、CI、ヘッドレス環境ではデバイス認証を使用してください。

```bash
phaseo login --device-code
```

### よく使う操作

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys create --name "Local development"
phaseo logs list --since 1h --status error --json
```

別のツールやスクリプトで構造化出力が必要な場合は `--json` を使用します。シークレット値を表示するのは、明示的に作成または表示するコマンドだけです。

## Phaseo MCP

モデル、料金、プロバイダー、使用量、ワークスペースの最新データを使って AI クライアントに質問へ回答させるには、Phaseo MCP サーバーを接続します。

### サーバー URL

`https://mcp.phaseo.app/mcp`

### Codex から接続する

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

ログインコマンドで Phaseo OAuth が開きます。ワークスペースを選択し、要求された読み取りスコープを承認して接続を確認します。

```bash
codex mcp list
```

別の MCP クライアントには同じ URL をリモート Streamable HTTP サーバーとして追加します。OAuth Discovery、S256 PKCE を使った認可コード、MCP `resource` パラメーターに対応している必要があります。

### MCP が読み取れるデータ

- モデル、プロバイダー、ベンチマークランキング、料金、コスト見積もり
- クレジット、アクティビティ、分析、リクエストログ、生成メタデータ

これらのツールは読み取り専用です。プロンプト、レスポンス、シークレット値を返すことはありません。

### アカウントを管理する（任意）

エージェントに Phaseo ワークスペースを変更させるには、代わりに管理用 URL で接続します。

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

サインイン時の同意画面には、API キーの管理や予算の削除など、接続が求める権限が 1 つずつ表示され、**読み取り**、**書き込み**、**削除** のいずれかが示されます。許可しない権限はチェックを外してください。エージェントが使えるのは許可した権限のツールだけです。また、Phaseo は変更のたびにワークスペースのロールも確認するため、オーナーでも管理者でもないメンバーが、この方法で管理者専用の設定を変更することはできません。

読み取り専用の URL ですでに接続している場合は、クライアントを管理用 URL に切り替えてもう一度サインインしてください。読み取り専用に戻すには、通常の URL で再接続するか、**設定 → 接続アプリ** でアプリのアクセスを取り消します。

| 対象 | ツール | 権限 |
| --- | --- | --- |
| API キー | `api_keys_list`, `api_key_get`, `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete` | `keys:read`, `keys:write`, `keys:delete` |
| 予算 | `budgets_list`, `budget_create`, `budget_update`, `budget_delete` | `budgets:read`, `budgets:write`, `budgets:delete` |
| 支出ルール | `spend_rules_list`, `spend_rule_create`, `spend_rule_update`, `spend_rule_delete` | `spend_rules:read`, `spend_rules:write`, `spend_rules:delete` |
| プロバイダーキー（BYOK） | `provider_keys_list`, `provider_key_create`, `provider_key_update`, `provider_key_delete` | `provider_credentials:read`, `provider_credentials:write`, `provider_credentials:delete` |
| ガードレール | `guardrails_list`, `guardrail_get`, `guardrail_create`, `guardrail_update`, `guardrail_delete`, `guardrail_keys_set` | `guardrails:read`, `guardrails:write`, `guardrails:delete` |
| プリセット | `presets_list`, `preset_get`, `preset_create`, `preset_update`, `preset_version_publish` | `presets:read`, `presets:write` |
| 設定 | `settings_get`, `settings_update` (ルーティングモード、プライバシーと ZDR、ログ記録、プロバイダー制限) | `settings:read`, `settings:write` |
| Webhook | `webhooks_list`, `webhook_create`, `webhook_delete` | `settings:read`, `settings:write` |
| オブザーバビリティの宛先 | `observability_destinations_list`, `observability_destination_create`, `observability_destination_delete` | `settings:read`, `settings:write` |

何かを変更または削除するツールにはその旨が示されるため、対応する MCP クライアントは呼び出しのたびに確認を求めます。新しい API キーや Webhook の署名シークレットはツールの結果に 1 回だけ表示され、あとから再表示することはできません。保存済みのプロバイダーキーや宛先の認証情報が返されることはありません。

MCP には、請求、支払い、ワークスペース、メンバー、管理キー、OAuth アプリのツールはありません。これらにはダッシュボード、CLI、または管理 API を使用してください。

## Docs MCP

Docs MCP は Phaseo ドキュメントの検索・参照用の別エンドポイントです。アカウントやワークスペースにはアクセスしません。

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

コーディングアシスタントに最新の API 例、統合ガイド、機能ドキュメントを参照させる場合に使用します。

## Phaseo プラグイン

Phaseo プラグインには、Phaseo MCP、Docs MCP、そして統合、移行、モデル選択、使用状況の監視、SDK、CLI のための Phaseo エージェントスキルがまとめて含まれています。それぞれを個別に接続する代わりに、一度インストールするだけで使えます。

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

`/mcp` を実行して `plugin:phaseo:phaseo` にサインインし、Phaseo アカウントを接続します。スキルはリクエストに合致したときに読み込まれます。`/phaseo:phaseo-gateway` のように直接実行することもできます。

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

最後のコマンドで Phaseo MCP の Phaseo OAuth が開きます。スキルはリクエストに合致したときに読み込まれます。

## 適切なインターフェースを選ぶ

- キーの作成、設定変更、ワークスペース管理、管理タスクの自動化には **CLI** を使用します。
- AI クライアントに Phaseo の最新データへの安全なアクセスを提供するには **Phaseo MCP** を使用します。
- アカウントにアクセスさせず、コーディングアシスタントに Phaseo の最新ドキュメントを提供するには **Docs MCP** を使用します。
- Claude Code や Codex に 2 つの MCP サーバーと Phaseo スキルをまとめて設定するには **Phaseo プラグイン** を使用します。
