ターミナルやスクリプトから Phaseo を変更するには CLI を使い、AI クライアントに Phaseo の最新データを渡すには Phaseo MCP サーバーに接続します。どちらも Phaseo OAuth でログインします。

| インターフェース | 用途 | アクセス |
| --- | --- | --- |
| [Phaseo CLI](#phaseo-cli) | シェルや CI から、キーの作成、設定の変更、ワークスペースの管理、管理作業の自動化を行う | 読み取りと書き込み。スコープとワークスペースのロールによって制限されます |
| [Phaseo MCP](#phaseo-mcp) | Codex、Claude、ChatGPT などの MCP クライアントに Phaseo の最新データを渡し、必要に応じてアカウントの管理も任せる | アカウント管理付きで接続しない限り読み取り専用 |
| [Docs MCP](#docs-mcp) | コーディングアシスタントに最新の Phaseo ドキュメントを渡す | ドキュメントのみ。アカウントへのアクセスなし |
| [Phaseo プラグイン](#phaseo-plugin) | Claude Code や Codex に両方の MCP サーバーと Phaseo スキルをまとめてインストールする | 各 MCP サーバーと同じ |

<span id="phaseo-cli"></span>
## Phaseo CLI

### インストールしてログインする

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

対話型のターミナルでは、既定でブラウザーによる OAuth を使います。SSH、CI、ヘッドレス環境では、デバイス認可を使います。

```bash
phaseo login --device-code
```

### よく使う操作

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys create --name "Local development"
phaseo logs list --since 1h --status error --json
```

別のツールやスクリプトで構造化された出力が必要な場合は `--json` を使います。シークレットの値は、明示的に作成または表示するコマンドでのみ表示されます。

## Phaseo MCP

サーバーの URL は `https://mcp.phaseo.app/mcp` です。これに接続した AI クライアントは、モデル、価格、プロバイダー、使用量、ワークスペースの最新データを使って質問に答えられます。

### Codex から接続する

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

ログインコマンドを実行すると Phaseo OAuth が開きます。ワークスペースを選び、要求された読み取りスコープを承認してから、接続を確認します。

```bash
codex mcp list
```

他の MCP クライアントでは、同じ URL をリモートの Streamable HTTP サーバーとして追加します。クライアントは、OAuth ディスカバリー、S256 PKCE を使う認可コード、MCP の `resource` パラメーターに対応している必要があります。

### MCP が読み取れるデータ

読み取り専用のツールは、モデル、プロバイダー、ベンチマークのランキング、価格とコストの見積もりに加えて、クレジット、アクティビティ、分析、リクエストのログ、生成のメタデータを扱います。プロンプト、レスポンス、シークレットの値は決して返しません。

### アカウントを管理する（任意）

エージェントに Phaseo のワークスペースを変更させるには、代わりに管理用の URL で接続します。

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

ログインすると、同意画面に接続が要求する各権限（API キーの管理や予算の削除など）が一覧表示され、それぞれに **読み取り**、**書き込み**、**削除** のいずれかが表示されます。不要な権限はチェックを外してください。エージェントは許可した権限のツールだけを受け取り、Phaseo は変更のたびにワークスペースのロールも確認します。そのため、オーナーや管理者でないメンバーは、この方法で管理者専用の設定を変更することはできません。

すでに読み取り専用の URL で接続している場合は、クライアントを管理用の URL に切り替えて、もう一度ログインします。読み取り専用のアクセスに戻すには、通常の URL で再接続するか、**設定 → 接続アプリ** でアプリを取り消します。

| 分野 | ツール | 権限 |
| --- | --- | --- |
| API キー | `api_keys_list`、`api_key_get`、`api_key_create`、`api_key_update`、`api_key_rotate`、`api_key_delete` | `keys:read`、`keys:write`、`keys:delete` |
| 予算 | `budgets_list`、`budget_create`、`budget_update`、`budget_delete` | `budgets:read`、`budgets:write`、`budgets:delete` |
| 支出ルール | `spend_rules_list`、`spend_rule_create`、`spend_rule_update`、`spend_rule_delete` | `spend_rules:read`、`spend_rules:write`、`spend_rules:delete` |
| プロバイダーキー（BYOK） | `provider_keys_list`、`provider_key_create`、`provider_key_update`、`provider_key_delete` | `provider_credentials:read`、`provider_credentials:write`、`provider_credentials:delete` |
| ガードレール | `guardrails_list`、`guardrail_get`、`guardrail_create`、`guardrail_update`、`guardrail_delete`、`guardrail_keys_set` | `guardrails:read`、`guardrails:write`、`guardrails:delete` |
| プリセット | `presets_list`、`preset_get`、`preset_create`、`preset_update`、`preset_version_publish` | `presets:read`、`presets:write` |
| 設定 | `settings_get`、`settings_update`（ルーティングモード、プライバシーと ZDR、ログ記録、プロバイダーの制限） | `settings:read`、`settings:write` |
| Webhook | `webhooks_list`、`webhook_create`、`webhook_delete` | `settings:read`、`settings:write` |
| 可観測性の送信先 | `observability_destinations_list`、`observability_destination_create`、`observability_destination_delete` | `settings:read`、`settings:write` |

何かを変更または削除するツールにはその旨の印が付いているため、対応している MCP クライアントは呼び出しのたびに確認を求めます。新しい API キーや Webhook の署名シークレットはツールの結果に一度だけ表示され、再表示はできません。保存されたプロバイダーキーや送信先の認証情報は決して返されません。

MCP には、請求、支払い、ワークスペース、メンバー、管理キー、OAuth アプリのツールはありません。これらにはダッシュボード、CLI、または Management API を使ってください。

## Docs MCP

Docs MCP は、Phaseo のドキュメントを検索して読むための別のエンドポイントです。アカウントやワークスペースにはアクセスしません。

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

## Phaseo プラグイン

Phaseo プラグインには、Phaseo MCP、Docs MCP、そして連携、移行、モデル選択、使用量の監視、SDK、CLI のための Phaseo エージェントスキルがまとめられています。各要素を自分で接続する代わりに、一度インストールするだけで済みます。

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

`/mcp` を実行して `plugin:phaseo:phaseo` にログインし、Phaseo アカウントを接続します。スキルはリクエストが一致したときに読み込まれます。`/phaseo:phaseo-gateway` のように直接実行することもできます。

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

最後のコマンドで、Phaseo MCP 用の Phaseo OAuth が開きます。スキルはリクエストが一致したときに読み込まれます。
