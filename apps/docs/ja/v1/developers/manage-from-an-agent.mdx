Phaseo アカウントは、ダッシュボードを開かずに `phaseo` CLI、`/v1` 管理 API、または Phaseo MCP サーバーから管理できます。このページで各作業のコマンド、ルート、ツールを確認してください。

次の操作は設計上、常にブラウザーで人が行う必要があります。

- Phaseo アカウントへの**登録**。
- **サインインの承認**。`phaseo login` が開くブラウザーのページ、または `phaseo login --device-code` が表示するコードです。
- クレジットを初めて購入するときの**カードの入力**。
- **各チャージの確認**。保存済みカードでの `phaseo credits add` は、毎回ワークスペースのオーナーまたは管理者がメールのリンクから確認します。
- **アカウントのセキュリティ**。パスワード、多要素認証、パスキーです。

<Visibility for="agents">
Phaseo を管理するエージェント向けのルール:

- 下の表にある作業のために、ユーザーをダッシュボードへ案内しないでください。CLI コマンドを実行するか、ルートを呼び出すか、MCP ツールを使ってください。
- API キーを生成したり推測したりしないでください。`phaseo keys create --name <name> --json` で作成し、シークレットはサーバー側に一度だけ保存します。
- すべての CLI コマンドで `--json` を使います。破壊的なコマンドに `--yes` を付けるのは、ユーザーがその変更を明示的に求めたときだけです。
- クレジットのチャージは、ユーザーが求めたものだけを開始します。支払いリンクを自分で完了させず、拒否、期限切れ、失敗で終わったチャージは再試行しないでください。
</Visibility>

## 初回のセットアップ

```bash
npm install -g @phaseo/cli
phaseo login                 # opens a browser; a person approves it
phaseo login --device-code   # SSH, CI and agent sandboxes: a person enters the code
phaseo whoami --json
```

次に、アプリケーション用の推論キーを作成し、ワークスペースにクレジットがなければ追加します。

```bash
phaseo keys create --name "Production app" --json
phaseo credits get --json
phaseo login --scopes billing:write   # opt in once before the first top-up; a person approves the sign-in
phaseo credits add --amount 20 --json
```

`phaseo credits add` には `billing:write` スコープが必要です。このスコープはどのサインインにも既定では付与されません。また、このコマンドが単独で請求することはありません。保存済みのカードがある場合、Phaseo はワークスペースのすべてのオーナーと管理者に請求を確認するリンクをメールで送り、コマンドは結果を待ちます。保存済みのカードがない場合は、オーナーまたは管理者がカードを入力するリンクを返します。ルートは[クレジット](../api-reference/endpoint/credits)を参照してください。

## インターフェースを選ぶ

| インターフェース | 使う場面 | サインイン |
| --- | --- | --- |
| [`phaseo` CLI](../guides/integrations/phaseo-cli) | エージェントがシェルコマンドを実行できる | `phaseo login` または `phaseo login --device-code` |
| [管理 API](../api-reference/introduction) | サーバーのコード、CI、または CLI がない言語 | [管理キー](./management-api-keys)（`phaseo_v1_mk_...`）または OAuth トークン |
| [Phaseo MCP](./cli-and-mcp#phaseo-mcp) | エージェントが MCP クライアントで動作する | `https://mcp.phaseo.app/mcp?access=manage` に接続し、必要な権限を承認する |

インストール済みの CLI が受け付けるオプションは `phaseo <group> --help` で確認できます。専用のコマンドがない作業は、`phaseo api get|post|patch|put|delete /v1/<path>` でセッションを使ってルートを呼び出せます。

## 作業一覧

### キーとアクセス

| 作業 | CLI | API ルート | MCP ツール |
| --- | --- | --- | --- |
| API キーを作成する | `phaseo keys create --name <name> --json` | `POST /v1/keys` | `api_key_create` |
| キーを一覧表示、更新、削除する | `phaseo keys list`, `phaseo keys update <id>`, `phaseo keys delete <id>` | `GET /v1/keys`, `PATCH /v1/keys/{id}`, `DELETE /v1/keys/{id}` | `api_keys_list`, `api_key_update`, `api_key_delete` |
| キーをローテーションする | `phaseo keys rotate <id> --json` | `POST /v1/keys/{id}/rotate` | `api_key_rotate` |
| キーを IP アドレスに制限する | `phaseo keys update <id> --ip-allowlist <label=address,...>` | `PATCH /v1/keys/{id}` | — |
| 管理キーを作成する | `phaseo management-keys create --name <name> --json` | `POST /v1/management-keys` | — |
| 承認したアプリを確認、制限、または取り消す | `phaseo authorized-apps list`, `phaseo authorized-apps update-scopes <id> --scopes <scope,...>`, `phaseo authorized-apps revoke <id> --yes` | `GET /v1/me/authorized-apps`, `PATCH /v1/me/authorized-apps/{id}`, `DELETE /v1/me/authorized-apps/{id}` | — |
| プロフィールを更新する | `phaseo profile update` | `PATCH /v1/me/profile` | — |

## 権限

CLI セッション、管理キー、MCP 接続ができることは、そのスコープとワークスペースでのあなたのロールが許す範囲に限られます。オーナーと管理者だけが行える変更には、引き続きオーナーまたは管理者が必要です。コマンドが `403` を返した場合は、`phaseo whoami --json` で付与済みのスコープを確認し、不足しているスコープがあれば `phaseo login --scopes <scope,...>` で再度サインインしてください。`billing:write` が既定で付与されることはありません。
