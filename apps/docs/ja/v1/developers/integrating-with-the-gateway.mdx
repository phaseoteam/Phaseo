Phaseo のキーをサーバーに保存し、アプリのプロトコルに合うエンドポイントを選んで、HTTP クライアントまたは SDK の接続先を `https://api.phaseo.app/v1` にします。まだリクエストを送ったことがない場合は、[クイックスタート](../quickstart.mdx)から始めてください。

Gateway へのアクセス権がある Phaseo アカウントと、HTTP クライアント、OpenAI 互換の SDK、または Phaseo SDK が必要です。例では、クレジットを入金しなくても動く `google/gemma-3-27b:free` を使います。

<Steps>
<Step title="キーを作成して保存する">

[Phaseo CLI](../guides/integrations/phaseo-cli) で `phaseo keys create --name <app-and-environment> --json` を実行するか、[ダッシュボード](https://phaseo.app/settings/keys)で **設定 → APIキー** を開きます。キーにはアプリと環境に合わせた名前を付け、シークレットマネージャーまたは環境ファイルに保存します。

```bash
# .env.local
PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
PHASEO_BASE_URL="https://api.phaseo.app/v1"
```

ローカル開発、プレビューデプロイ、本番環境でそれぞれ別のキーを使うと、キーごとに個別にローテーションと確認ができます。

</Step>
<Step title="エンドポイントを選ぶ">

| エンドポイント | 用途 |
| --- | --- |
| `/v1/responses` | 新しく作るテキスト機能、構造化出力、複数ステップのワークフロー。 |
| `/v1/chat/completions` | チャットインターフェースと、既存の OpenAI 形式の連携。 |
| `/v1/messages` | Anthropic 互換の連携。 |
| `/v1/decisions` | Jev 1.13 を使った、アプリケーションの状態に対する型付きの判断（ベータ）。 |
| `/v1/moderations` | 安全性とコンテンツポリシーのチェック。 |
| `/v1/images/generations` | テキストプロンプトからの画像生成。 |

すべてのエンドポイント、パラメーター、レスポンスは [API リファレンス](../api-reference/introduction)に一覧があります。

</Step>
<Step title="アプリからリクエストを送る">

この例では、OpenAI 互換のクライアントがそのまま扱える Chat Completions を使います。どのリクエストも、キーを `Authorization: Bearer $PHASEO_API_KEY` として送ります。

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemma-3-27b:free",
    "messages": [
      { "role": "system", "content": "You are a helpful assistant." },
      { "role": "user", "content": "Explain the benefits of AI." }
    ]
  }'
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});

const response = await client.chat.completions.create({
  model: "google/gemma-3-27b:free",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: "Explain the benefits of AI." },
  ],
});

console.log(response.choices[0]?.message?.content);
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.phaseo.app/v1",
)

response = client.chat.completions.create(
    model="google/gemma-3-27b:free",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain the benefits of AI."},
    ],
)

print(response.choices[0].message.content)
```

```go Go
package main

import (
  "context"
  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New("YOUR_API_KEY", "https://api.phaseo.app/v1")

  response, err := client.CreateChatCompletion(context.Background(), phaseo.ChatCompletionsRequest{
    Model: "google/gemma-3-27b:free",
    Messages: []map[string]interface{}{
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain the benefits of AI."},
    },
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(response)
}
```

<Note>
ID が `:free` で終わるモデルは、クレジットを入金しなくても動作します。有料モデルには、利用可能なウォレット残高が必要です。
</Note>

## 本番トラフィックを送る前に

どのプロバイダーがリクエストを処理するかを制御するには[ルーティングとフォールバック](../guides/routing-and-fallbacks)を、キーの扱いと認証エラーについては[認証](./authentication)を読んでください。各言語のクライアントは [SDK リファレンス](../sdk-reference/client/overview)で、アプリやスクリプトの完全なパターンは[サンプル](../guides/examples)で紹介しています。
