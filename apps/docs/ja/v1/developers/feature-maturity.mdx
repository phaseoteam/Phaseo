Phaseo の一部の機能には、ドキュメント、API リファレンス、ダッシュボードで **アルファ** または **ベータ** のラベルが付いています。ラベルは、その機能がどれだけ安定しているかを示します。ラベルのない機能は一般提供されています。

<span id="stages"></span>

## 段階

| 段階 | 意味 | どうすればよいか |
| --- | --- | --- |
| アルファ | 初期のバージョンです。API、動作、料金が大きく変わる可能性があり、削除されることもあります。 | 試してみて、ご意見をお聞かせください。すぐに変更できないものをこの機能の上に構築しないでください。 |
| ベータ | 主な用途では動作します。フィードバックに応じて細部が変わる可能性があり、変更は[変更履歴](../changelog.mdx)でお知らせします。 | パイロットや、注意深く監視する実際のワークロードに使えます。アップグレード時には変更履歴を確認してください。 |
| 一般提供 | 完全にサポートされ、ドキュメントも整っています。ラベルは表示されません。 | 本番環境で使用してください。 |
| 非推奨 | まだ動作しますが、推奨されなくなっており、今後削除されます。削除日が決まっている場合は表示されます。 | 新たに使い始めず、削除日までに移行してください。 |

モデルとプロバイダーには、これらの段階とは別に独自のライフサイクルラベルがあります。[モデルの非推奨化と提供終了](../guides/model-retirement.mdx)と[プロバイダーと Phaseo のステータス](../guides/provider-statuses.mdx)を参照してください。

<span id="who-can-use-a-feature"></span>

## 機能を使える対象

段階とアクセスは別のものです。ベータ機能が全員に公開されていることもあれば、アルファ機能が一部のワークスペースに限定されていることもあります。

- **全員**: 通常のロールの範囲内で、どのワークスペースでも使えます。たとえば、一部の設定はオーナーと管理者だけが使えます。
- **リクエスト制**: 機能はワークスペースごとに有効化されます。有効になるまでは、設定ページが表示されず、API はエラーを返します。**設定 → 機能プレビュー** で、ワークスペースで Video API と Batch API が有効かどうかを確認できます。これらの機能へのアクセスを希望する場合は、[お問い合わせ](https://phaseo.app/contact)ください。

## 一般提供されていない機能

| [Video API](../guides/async-video-and-batch.mdx) | アルファ | リクエスト制 |

| [Decisions API](../api-reference/endpoint/decisions.mdx) | ベータ | 全員 |
| [リアルタイム音声](../guides/realtime-voice.mdx) | ベータ | リクエスト制 |
| [サーバーツール](../guides/server-tools/index.mdx) | ベータ | 全員 |

<span id="how-features-change-stage"></span>

## 機能の段階が変わるとき

- 主な用途が動作し、API が固まると、機能はアルファからベータへ、またはベータから一般提供へ移行します。この変更は[変更履歴](../changelog.mdx)に記載します。
- アルファ機能とベータ機能への破壊的変更は、変更履歴でお知らせします。
- 機能が非推奨になると、そのドキュメントページにその旨が記載され、削除日が決まっている場合はその日付も示されます。
