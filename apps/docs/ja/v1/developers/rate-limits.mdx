このガイドは[レート制限](../api-reference/limits.mdx)に移動しました。現在の Gateway の上限、プロバイダーの制限、`Retry-After`、回数や時間を制限した再試行については、そちらを参照してください。

Gateway またはプロバイダーの上限により、リクエストが `429` を返す場合があります。BYOK には自分のプロバイダーアカウントの制限も適用されます。ルーティングとフォールバックは失敗を減らせますが、すべてのリクエストの成功を保証しません。

## 使用状況を確認する

リクエストログで `429` エラーと再試行を確認してください。API ではすでに[ワークスペース分析の取得](../api-reference/endpoint/analytics-get.mdx)と[CSV エクスポート](../api-reference/endpoint/analytics-export.mdx)が可能です。どちらも `analytics:read` を持つ管理 API キーが必要です。
