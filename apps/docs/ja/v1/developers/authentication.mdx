title: "認証"
description: "Phaseo Gateway へのすべてのリクエストを API キーで認証します。"

---

[ダッシュボード](https://phaseo.app/settings/keys)で、または管理キーを使った `POST /v1/keys` でキーを作成し、サーバーに保存して、すべての Gateway リクエストで Bearer トークンとして送ります。エージェントは CLI を使ってください。[エージェントから Phaseo を管理する](./manage-from-an-agent)を参照してください。

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

ヘッダーはクライアントで一度設定します。たとえば `fetch` では次のようにします。

```ts
const response = await fetch("https://api.phaseo.app/v1/chat/completions", {
	method: "POST",
	headers: {
		Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
		"Content-Type": "application/json",
	},
	body: JSON.stringify({
		model: "openai/gpt-6-astra",
		messages: [
			{ role: "system", content: "You are a helpful assistant." },
			{ role: "user", content: "Summarize the drawbacks to AI." },
		],
	}),
});
```

<Note>
`:free` モデルは、クレジットを入金しなくても呼び出せます。有料モデルには、利用可能なウォレット残高が必要です。
</Note>

## 認証情報を選ぶ

| 認証情報 | 形式 | 用途 |
| --- | --- | --- |
| Gateway API キー | `phaseo_v1_sk_<kid>_<secret>` | ワークスペースで利用できるモデル、プロバイダー、生成のエンドポイント。 |
| [管理 API キー](./management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | 管理用 API。 |
| [信頼済みワークロード](./trusted-workloads.mdx)（ベータ） | プラットフォームが発行する短期間有効な OIDC トークン | Vercel、GitHub Actions、GitLab、Google Cloud、Buildkite、CircleCI、AWS、または独自の OIDC 発行者上のデプロイと CI ジョブ。キーを保存する必要はありません。 |

キーはパスワードと同じように扱い、クライアント側のコードや公開リポジトリに含めないでください。

## キーを安全に扱う

- **アプリと環境ごとに 1 つのキーを使う。** こうすると、他のサービスに影響を与えずに 1 つのキーをローテーションできます。
- **キーはシークレットマネージャーに保存する。** ログやエラートラッキングにキーが残らなくなります。
- **キーごとの使用量をダッシュボードで監視し**、異常に気付けるようにします。
- **使わなくなったキーは削除する。**

キーをローテーションするには、古いキーを無効にする前に、アプリケーションを新しいキーに切り替えます。[キーのローテーション用エンドポイント](../api-reference/endpoint/keys-rotate.mdx)を参照してください。

## 認証エラーを解決する

| ステータス | 原因 | 対処 |
| --- | --- | --- |
| `401` | キーがない、無効である、または無効化されたワークスペースに属しています。どれに当たるかは本文の `reason` に示されます。 | ヘッダーとキーを確認します。 |
| `403` | キーは有効ですが、要求したプロバイダーやモデルを使えません。 | キーのガードレールとワークスペースのプロバイダー設定を確認します。 |
| `429` | キーまたはワークスペースが上限に達しました。 | [レート制限](../api-reference/limits.mdx)を参照してください。 |
| `5xx` | Phaseo またはプロバイダーで障害が発生しました。 | 指数バックオフで再試行し、解決しない場合は[サポート](https://phaseo.app/help)に連絡してください。 |

すべてのエラーコードは[エラーとデバッグ](../api-reference/errors.mdx)を参照してください。
