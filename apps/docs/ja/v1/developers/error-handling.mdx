優れたモデルでも、時折エラーは発生します。このガイドでは、Gateway がエラーを報告する方法と、その対処方法を説明します。

---

## エラーの種類

エラーは Gateway、プロバイダー、またはリクエストに起因します。エラーレスポンスには、問題の診断に役立つメタデータが含まれます。

| ステータス範囲 | 意味                                  | 一般的な対応                        |
| ----------- | ---------------------------------------- | ------------------------------------- |
| 400-499     | 無効なリクエストまたは認証エラー | リクエスト内容または認証情報を修正します。       |
| 429         | レート制限                             | バックオフして再試行し、制限を守ります。 |
| 500-599     | Gateway またはプロバイダーの障害              | バックオフして再試行し、詳細を記録します。    |

---

## 再試行の動作

- ジッターを加えた指数バックオフを実装します。
- `Retry-After` ヘッダーがある場合は、その値に従います。
- 最大再試行回数を設定し、無限の再試行を避けます。

---

## プロバイダーのエラー

エラーが上流のプロバイダーで発生することがあります。その場合はレスポンスに示すようにします。エラーが続く場合、可能であればルーターがそのプロバイダーを避ける必要があります。
