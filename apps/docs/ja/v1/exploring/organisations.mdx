Phaseo の各モデルは、モデルの開発、学習、保守を担う**組織**に紐づいています。
組織は AI エコシステムの基盤です。誰がモデルを開発したかを知ることで、モデルの目的、機能、信頼性を理解しやすくなります。

---

## 組織ページに掲載される内容

各組織ページでは、企業や研究グループの概要を確認できます。

| セクション | 説明 |
| --- | --- |
| **概要** | 名前、説明、国、設立年、ウェブサイトなどの基本情報。 |
| **公開モデル** | アーカイブ済みや非推奨のモデルを含む、組織が公開したすべてのモデル。 |

---

## Phaseo に掲載されている組織の種類

| 種類 | 例 | 説明 |
| --- | --- | --- |
| **研究所** | OpenAI、Anthropic、DeepMind | 最先端の AI モデル開発とイノベーションに取り組みます。 |
| **テクノロジー企業** | Google、Meta、Microsoft | 大規模な AI インフラと一般向けアプリケーションを展開します。 |
| **スタートアップ** | Mistral、Perplexity、Suno | 専門性や効率性を重視した AI システムを開発する小規模チームです。 |
| **オープンソースコミュニティ** | Hugging Face、Stability AI | 分散型で透明性のあるモデル開発を行います。 |

## プロバイダーと組織の違い

**組織**と**API プロバイダー**は区別が必要です。

| 項目 | 組織 | API プロバイダー |
| --- | --- | --- |
| **定義** | モデルを作成または保守する主体。 | モデルへの API アクセスを提供するプラットフォーム。 |
| **例** | _Anthropic_ は Claude シリーズを開発しました。 | _Anthropic_、_AWS_、_Google Vertex_ は Claude モデルへのアクセスを提供します。 |
| **注力点** | 研究、学習、モデルアーキテクチャ。 | ホスティング、ルーティング、料金、ユーザー体験。 |

OpenAI や Google のように、**開発者**と**プロバイダー**の両方を担う組織もあります。モデルの提供に複数のプラットフォームを利用する組織もあります。
