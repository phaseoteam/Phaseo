[組織](https://phaseo.app/organisations)で組織を開くと、その組織がリリースしたすべてのモデルと、それらのモデルの Gateway でのパフォーマンスを確認できます。Phaseo のすべてのモデルは、1 つの組織（モデルを開発・保守する企業またはラボ）に属しています。

## 組織ページに表示される内容

ページには 2 つのタブがあります。

| タブ | セクション | わかること |
| --- | --- | --- |
| **概要** | 概要 | 名前、説明、国。 |
| | パフォーマンス | 組織のモデル全体における、直近の Gateway のレイテンシーとスループット。 |
| | 最新モデル | 提供状況、コンテキスト、料金、使用量を含む最近のリリース。 |
| | ウェブ上の情報 | 組織のウェブサイト、GitHub、Hugging Face、ソーシャルアカウントへのリンク。 |
| **モデル** | | アーカイブ済みや非推奨のものを含め、組織がリリースしたすべてのモデル。 |

## 組織と API プロバイダー

組織はモデルを開発し、[API プロバイダー](./api-providers.mdx)はそれを提供します。1 つのモデルに複数のプロバイダーがあることはよくあります。

| | 組織 | API プロバイダー |
| --- | --- | --- |
| **役割** | モデルを学習・保守する。 | モデルを API の背後でホストする。 |
| **例** | Anthropic は Claude モデルを開発しました。 | Anthropic、Amazon Bedrock、Google Vertex はいずれも Claude モデルを提供しています。 |

OpenAI や Google のように、自社モデルのプロバイダーを兼ねる組織もあります。

## 修正を報告する

組織ページと公式の出典を添えて GitHub の issue を作成してください。メンテナーが承認した変更をデータベースに反映します。[組織の更新を報告する](../contributing/editing-an-organisation.mdx)を参照してください。
