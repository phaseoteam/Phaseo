[モデル](https://phaseo.app/models)の一覧を開いてテキスト、画像、音声、動画、埋め込みなどのモデルを探し、モデルを開いてそのプロバイダー、料金、パフォーマンス、ベンチマークスコアを確認します。

![Phaseo のモデルページ](/images/gemini-3-page.png)

## カタログのモデルと呼び出し可能なモデル

カタログは Gateway よりも範囲が広くなっています。モデル一覧には、既定で **Gateway で有効** なモデルだけが表示されます。残りを表示するには、**Gateway の状態** フィルターを **近日公開** または **無効** に変更します。

| 用語 | 意味 |
| --- | --- |
| カタログのモデル | Phaseo がモデルのメタデータを追跡しています。呼び出せるルートがない場合もあります。 |
| ルーティング可能なモデル | 少なくとも 1 つのプロバイダールートが現在 Phaseo Gateway で有効です。 |
| 外部マッピング | Phaseo はプロバイダーの提供内容を掲載していますが、Gateway はそれを実行しません。 |

`GET /v1/models` はルーティング可能なモデルのみを返します。残りも含めるには `availability=all` を追加します。

## 一覧を絞り込んで並べ替える

| コントロール | 選択肢 |
| --- | --- |
| Gateway の状態 | Gateway で有効（既定）、近日公開、無効 |
| エンドポイント | テキスト生成や埋め込みなど、モデルがサポートする API エンドポイント |
| 入力と出力のモダリティ | テキスト、画像、音声、動画など |
| 機能 | ツール呼び出しや推論などの機能 |
| 年 | リリース年 |
| 並べ替え | 新しい順、人気順（7 日間のトークン数）、料金、コンテキスト長、スループット、レイテンシー |

1 つのラボのすべてのモデルを見るには、その[組織ページ](./organisations.mdx)を開きます。

## モデルページに表示される内容

| セクション | わかること |
| --- | --- |
| **プロバイダー** | 各プロバイダールートのステータス、コンテキスト長、料金、稼働率、データポリシー。アイコンの意味は[プロバイダーのステータス](../guides/provider-statuses)で説明しています。 |
| **パフォーマンス** | 十分なデータがある場合に、Gateway トラフィックで測定したレイテンシーとスループット。 |
| **料金** | 入力、出力、キャッシュされた入力、メディア単位など、USD でのすべての課金項目。 |
| **ベンチマーク** | 各ベンチマークのスコアと出典。 |
| **アクティビティ** | Gateway でのトークン使用量の推移。 |
| **アプリ** | このモデルを使う公開アプリ。 |
| **稼働状況** | 直近数日間のルートの可用性。 |
| **検証** | 画像と動画のモデル向けの、コンテンツの来歴チェック。 |
| **概要** | リリース日、ライセンス、リンク、ファミリー。 |
| **サブスクリプション** | このモデルを含むプロバイダーのサブスクリプションプラン。 |
| **よくある質問** | このモデルについてよくある質問。 |

各セクションは、対応するデータがある場合にのみ表示されます。有効なルートがあるモデルには、送信するモデル ID を含むクイックスタートも表示されます。

## モデルを比較する

[比較](https://phaseo.app/compare)では、料金、ベンチマークスコア、コンテキスト、機能でモデルを並べて比べられます。コストと速度の数値の読み方は[料金とパフォーマンス](./pricing-performance.mdx)で説明しています。

## 修正を報告する

モデルページと公式の出典を添えて GitHub の issue を作成してください。メンテナーが承認した更新をデータベースに反映します。[モデルの更新を報告する](../contributing/editing-a-model.mdx)を参照してください。
