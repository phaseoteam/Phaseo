Phaseo では、テキスト、画像、音声、動画、埋め込みなど、幅広い AI モデルの公開カタログを管理しています。

各モデルページには技術面と商用面の詳細情報があり、ニーズに合うモデルを評価・比較・選択できます。

<Info>
カタログは Gateway よりも広範です。モデルページにはデフォルトで Gateway の有効なルートがあるモデルが表示されます。近日公開や無効なカタログ項目を意図的に確認する場合のみ、別の Gateway ステータスを選択してください。
</Info>

---

## モデルページで確認できること

Phaseo の各モデルページには、次の主要セクションがあります。

| セクション | 説明 |
| --- | --- |
| **概要** | プロバイダー、リリース日、モデルの種類（チャット、コード、埋め込み、画像など）、短い説明。 |
| **ファミリー** | 関連モデルとその関係。 |
| **タイムライン** | リリース履歴と主な更新。 |
| **ベンチマーク** | 各種ベンチマークの結果と、近いモデルとの比較。 |
| **利用可否** | Gateway の有効なルートと、近日公開、無効、外部プロバイダーの提供内容を区別します。 |
| **料金** | 比較しやすいよう USD で標準化した詳細料金とモデル費用。 |
| **Gateway** | 公開 Gateway ルートがある場合の直接リンクとクイックスタート。 |
| **パフォーマンス** | 十分なデータがある場合に、Gateway 経由のリクエストで観測されたレイテンシ、スループット、成功状況を表示します。 |

## カタログモデルとルーティング可能なモデル

次の用語を一貫して使います。

| 用語 | 意味 |
| --- | --- |
| カタログモデル | Phaseo がモデルのメタデータを管理しています。公開ルートがあるとは限りません。 |
| ルーティング可能なモデル | Phaseo Gateway で少なくとも1つのプロバイダールートが現在有効です。 |
| 外部マッピング | Phaseo がプロバイダーの提供内容を追跡しますが、Gateway では実行されません。 |

プログラムからモデルを検索する場合、`GET /v1/models` はデフォルトでルーティング可能なモデルだけを返します。`availability=all` を指定すると、より広い一覧を確認できます。

## 条件でモデルを探す

Phaseo の画面でフィルターやタグを使って、必要なモデルを見つけます。

- **プロバイダー別:** 「Anthropic のモデルをすべて表示」
- **機能別:** 「JSON の構造化レスポンスに対応するモデルを一覧表示」
- **ベンチマーク別:** 「GPQA の上位10モデル」
- **料金別:** 「1,000トークンあたり0.01米ドル未満のモデル」
- **リリース日別:** 「最近公開されたモデル」

フィルターを組み合わせて、必要なモデルを絞り込めます。
