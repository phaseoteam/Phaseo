Phaseo は無料アクセスとモデルの従量課金を提供しています。ID とディレクトリの管理が必要なチームは、別途月額 Enterprise サブスクリプションを追加できます。以下の価格はすべて USD です。

## Phaseo の利用方法を選ぶ

| 選択肢 | Phaseo の料金 | 対象 |
| --- | --- | --- |
| 無料アクセス | 対応する無料モデルにサブスクリプションやチャージは不要 | 無料モデル、公開カタログデータ、SDK、各種連携 |
| Pay As You Go | カタログ価格でのモデル利用料と、クレジット購入時の 5% の手数料（最低 $1） | ワークスペースの前払いクレジットによる有料モデルへのリクエスト |
| 自分のキーを使用（BYOK） | 月間使用量を取得できる場合、ワークスペースごとに UTC 暦月の最初の 250,000 件の完了リクエストは Phaseo サービス手数料なし。その後はプロバイダー相当コストの 2.5%。月間カウンターと代替の読み取りがどちらも利用できない場合、そのリクエストには 2.5% の手数料が適用されます | 自分の認証情報による Phaseo のルーティングと可観測性。モデル利用料はプロバイダーが直接請求 |
| Self Serve Enterprise | 月額 $29 からのワークスペースサブスクリプションに、モデル利用料とクレジット購入手数料を加算 | SSO、SCIM、ディレクトリ管理、部門、優先メールサポート |

Pay As You Go には月額サブスクリプション、契約、月間最低利用額はありません。手数料はクレジット購入時に適用されます。その後、マネージドリクエストは表示されたモデル価格でクレジットを消費します。

無料モデルにはリクエスト上限があります。Gateway のデフォルト上限は、ユーザーとワークスペースごとに直近 1 分間で 25 件、さらに UTC 日ごとに無料モデルへのリクエスト 1,500 件です。プロバイダーの制限も適用されます。対象範囲と再試行については[レート制限](../api-reference/limits.mdx)を参照してください。

BYOK の設定と課金の詳細は[ルーティングとフォールバック](../guides/routing-and-fallbacks.mdx)を参照してください。Phaseo 手数料がない BYOK リクエストにも、プロバイダーの利用料は適用されます。

## Enterprise のメンバー数別料金

開始プランには、少人数のチームでも最大 100 人のワークスペースメンバーが含まれます。それ以上はメンバー数に応じた料金です。以下は基準価格であり、機能の異なるプランではありません。

| 含まれるワークスペースメンバー数 | 月額サブスクリプション |
| ---: | ---: |
| 100 | $29 |
| 1,000 | $79 |
| 10,000 | $299 |
| 25,000 | $599 |
| 50,000 | $1,099 |
| 100,000 | $1,999 |

[料金](https://phaseo.app/pricing)を開き、人数枠を選択して見積もりを確認してください。セルフサービスの利用可否はワークスペースへの提供状況によって異なります。請求書、調達、個別の取引条件は[ヘルプセンター](https://phaseo.app/help)にお問い合わせください。

メンバーはログインの有無にかかわらず、ワークスペースに所属している間は人数に含まれます。100,000 人未満では、選択した枠を超える新規参加はブロックされます。現在、セルフサービスで人数枠を変更できないため、契約前に今後の増員を考慮してください。

100,000 人の枠では、追加のユニークメンバー 1 人につきサブスクリプションの請求期間ごとに $0.02 がかかります。その期間中に削除されたメンバーも対象です。

Enterprise にモデル用クレジットは含まれず、標準のクレジット購入手数料 5%（最低 $1）も免除されません。請求例と人数枠については[料金と請求](../pricing/tiers.mdx)を参照してください。

## プロバイダーのサブスクリプション

[サブスクリプションカタログ](https://phaseo.app/subscription-plans)には、モデルプロバイダーが販売するプランが掲載されています。それぞれ独自の価格、対象モデル、制限、請求条件があります。プロバイダーの契約によって Phaseo クレジットが追加されたり、Gateway ルートが有効になったりするわけではありません。

プランを選ぶ前に、プロバイダーの条件とモデルの有効な Gateway ルートを確認してください。[料金とパフォーマンス](./pricing-performance.mdx)でモデル利用料と利用可能な性能データを比較できます。
