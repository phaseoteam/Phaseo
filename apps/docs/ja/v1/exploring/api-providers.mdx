[API プロバイダー](https://phaseo.app/api-providers)でプロバイダーを開くと、そのプロバイダーが Phaseo を通じて提供しているモデルとこれまでの速度を確認できます。[プロバイダーを比較](https://phaseo.app/api-providers/compare)して並べて見ることもできます。API プロバイダーはモデルを API の背後でホストする事業者で、モデルを開発した[組織](./organisations.mdx)とは別の会社であることがよくあります。

| | 組織 | API プロバイダー |
| --- | --- | --- |
| **役割** | モデルを開発・学習する | モデル API をホストして提供する |
| **重視する点** | 研究とモデルの品質 | 信頼性、アクセス、リージョン、料金 |
| **モデル** | 通常は自社のファミリー | 多くの組織のモデルを扱うことが多い |

多くの企業は両方を兼ねています。

## プロバイダーページに表示される内容

| セクション | わかること |
| --- | --- |
| **パフォーマンス** | 過去 7 日間の Gateway トラフィックにおける、1 時間ごとのレイテンシーとスループット。 |
| **トークン使用量** | Phaseo がこのプロバイダーに送ったトークン数の推移。 |
| **上位モデル** と **人気アプリ** | このプロバイダーで最もトラフィックの多いモデルと公開アプリ。 |
| **モデル** | プロバイダーが提供するすべてのモデル。テキスト、画像、音声、動画、埋め込み、モデレーションのモデルごとにタブがあります。 |

各モデルのページでは、そのモデルに対するプロバイダーの料金、コンテキスト長、ステータス、データポリシーを確認できます。ステータスアイコンの意味は[プロバイダーのステータス](../guides/provider-statuses)で説明しています。

## Gateway がプロバイダーを使う方法

モデルに複数のプロバイダーがある場合、Gateway はリクエストごとに 1 つを選び、失敗すると別のプロバイダーにフォールバックします。どのプロバイダーが処理しても、送るリクエスト形式は 1 つで、請求も使用量ログも 1 つにまとまります。代わりに自分のプロバイダーアカウントに請求させるには、プロバイダーキーを追加します（[BYOK](../guides/routing-and-fallbacks#byok-considerations)）。

プロバイダーの順位付け、固定、除外の方法は[ルーティングとフォールバック](../guides/routing-and-fallbacks)を参照してください。

## プロバイダーを選ぶ

| 重視する点 | 確認する場所 |
| --- | --- |
| 特定のモデル | モデルページの **プロバイダー** セクション、または `GET /v1/models/{author}/{slug}/endpoints` |
| 自分のリージョンでのレイテンシー | プロバイダーの **パフォーマンス** セクションと、モデルページに表示されるリージョン |
| 自分の利用量でのコスト | モデルの **料金** セクションと[料金計算ツール](https://phaseo.app/tools/pricing-calculator) |
| ツール、ストリーミング、構造化出力 | モデルページまたはエンドポイント API に表示される、ルートがサポートするパラメーター |
| データの取り扱いとコンプライアンス | モデルページに表示される、ルートのデータポリシーと処理場所 |

コストと速度の数値の読み方は[料金とパフォーマンス](./pricing-performance.mdx)で説明しています。
