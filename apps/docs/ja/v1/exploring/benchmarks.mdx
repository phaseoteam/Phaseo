[ベンチマーク](https://phaseo.app/benchmarks)でベンチマークを開くとそのスコア順にモデルを並べられ、モデルページを開くとそのモデルのすべてのスコアを確認できます。Phaseo 自身はベンチマークを実行しません。公開されたスコアを収集し、それぞれを出典にリンクしています。

## 各スコアに記録される内容

| フィールド | わかること |
| --- | --- |
| スコア | 公開されたとおりの値で、ベンチマーク独自のスケールで表されます。 |
| バリアント | few-shot の数や推論の強度など、既定と異なる場合の設定。 |
| 出典 | スコアの出典となった論文、モデルカード、結果ページへのリンク。 |
| 自己申告 | モデルの開発元自身がスコアを公開した場合に設定されます。これは開示であり、却下ではありません。 |

各ベンチマークにはカテゴリーと並べ替えの方向もあります。エラー率のように低いほど良いベンチマークでは、Phaseo は最も低いスコアを先頭に並べます。

## スコアを比較する方法

Phaseo はベンチマークを 1 つの共通スコアに換算しないため、ベンチマークをまたいでではなく、同じベンチマークとバリアントでモデルを比較してください。2 つの数値を同等とみなす前に、バリアントと自己申告のフラグを確認します。同じモデルでも、プロバイダーが報告したスコアと独立に測定したスコアは異なることがあります。

ベンチマークのスコアは判断材料の 1 つです。コスト、レイテンシー、信頼性、そして自分のプロンプトをモデルがどう処理するかも同じくらい重要です。これらは[料金とパフォーマンス](./pricing-performance.mdx)で扱っています。

## ベンチマークページに表示される内容

| セクション | わかること |
| --- | --- |
| **概要** | ベンチマークが測定する内容と、そのベンチマークへのリンク。 |
| **推移** | ベンチマークのスコアがこれまでにどう変化したか。 |
| **モデル結果** | すべてのモデルのスコアを、ベンチマークの並べ替え方向で順位付けしたもの。 |

Artificial Analysis Intelligence Index や Epoch Capabilities Index などの複合指標には専用のページがあり、公開元による順位とバージョンを確認できます。

## ベンチマークのカテゴリー

| カテゴリー | 例 |
| --- | --- |
| 一般 | Artificial Analysis Intelligence Index、Epoch Capabilities Index |
| エージェント | BrowseComp、BFCL-v3、Toolathlon |
| コード | SWE-Bench、Aider-Polyglot |
| 数学 | AIME 2025、MathVision |
| 推論 | HellaSwag、Hallusion Bench |
| 言語 | BIG-Bench Hard、Winogrande |
| マルチモーダル | CharXiv-R、MMBench-V1.1 |
| 長いコンテキスト | AA-LCR、OpenAI-MRCR |

その他のカテゴリーには、音声、埋め込み、ヘルスケア、計画、創造性があります。

## スコアの出典

- モデルの開発元によるモデルカード、技術レポート、論文。
- ベンチマーク運営者自身の結果ページ。
- Artificial Analysis と Epoch AI からの定期的な取り込み。
- GitHub の issue を通じたコミュニティからの報告（公開前にレビューされます）。

詳しいルールは[ベンチマークの方法論](../research/benchmark-methodology.mdx)にあります。スコアを追加または修正するには、[ベンチマークスコアを提出する](../research/submitting-scores.mdx)を参照してください。
