- Settings でのキーのテストが現在の `phaseo_v1_sk_` キーを受け付けるようになりました。以前は新しく作成したキーがテストに失敗していました ([#2251](https://github.com/phaseoteam/Phaseo/pull/2251)).
- 設定のサイドバーに Account と Workspace の全ページを検索できるフィルターが追加され、グローバル検索は現在のページに関連するページを提案します ([#2259](https://github.com/phaseoteam/Phaseo/pull/2259)).
- `openai/gpt-astra-latest` などのエイリアスから開いたモデルページでは、既定の ID の横にそのエイリアスが **Alias** ラベル付きで表示されます ([#2226](https://github.com/phaseoteam/Phaseo/pull/2226)).
