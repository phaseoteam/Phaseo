<Update label="2026年2月27日">

<div data-changelog-category="product">

<p className="changelog-category">製品</p>

- メールでのサインインに失敗した場合、汎用のエラーページではなくサインインページ上に、パスワードの誤りやメール未確認などの理由が表示されます ([#116](https://github.com/phaseoteam/Phaseo/pull/116))。
- メールでのサインアップでは、パスワードの条件（小文字、大文字、数字、記号）が表示され、フォーム送信前に確認されます ([#113](https://github.com/phaseoteam/Phaseo/pull/113))。
- モデル表で100万単位あたりの価格が正しく表示され、ページ幅いっぱいに表示されるようになりました。以前は一部の行で極端に高い価格が表示されていました ([#113](https://github.com/phaseoteam/Phaseo/pull/113), [#116](https://github.com/phaseoteam/Phaseo/pull/116))。

</div>

<div data-changelog-category="api">

<p className="changelog-category">API と SDK</p>

- Gemini 3 へのリクエストでは、`reasoning.effort` が各モデルの対応する思考レベル（`minimal` から `high`）に対応付けられます ([#113](https://github.com/phaseoteam/Phaseo/pull/113))。

</div>

</Update>

<Update label="2026年2月26日">

<div data-changelog-category="api">

<p className="changelog-category">API と SDK</p>

- **破壊的変更:** `/v1/responses/ws` は実験的機能と位置付けられ、プレフィックスのないモデル ID を拒否するようになりました。`openai/<model>` 形式の ID を送信し、本番環境では `POST /v1/responses` を使用してください ([#112](https://github.com/phaseoteam/Phaseo/pull/112))。

</div>
