- **破壊的変更:** モデルを取得するエンドポイントは `GET /v1/models` のみになりました。`/v1/gateway/models` と `/v1/data/models` は削除されたため、`/v1/models` を呼び出してください。詳しくは[モデル一覧](../api-reference/endpoint/models.mdx)をご覧ください ([#681](https://github.com/phaseoteam/Phaseo/pull/681))。
- 管理 API に `/v1/presets`、`/v1/settings`、`/v1/guardrails`、`/v1/management-keys` が追加され、`GET /v1/me` は OAuth トークンに紐づくユーザーとワークスペースを返します ([#562](https://github.com/phaseoteam/Phaseo/pull/562))。
