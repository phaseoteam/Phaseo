<Update label="2026年5月7日">

<div data-changelog-category="product">

<p className="changelog-category">製品</p>

- **Models** の料金ホバーカードに、画像・動画・段階制テキストの料金が品質、解像度、長さ、音声の有無、コンテキストサイズごとにまとめて表示されます ([#474](https://github.com/phaseoteam/Phaseo/pull/474))。
- **Models** では、`whisper-1` など分単位で課金される音声モデルを、丸めたトークン単価ではなく分単価(例: 1 分あたり $0.006)で表示します ([#477](https://github.com/phaseoteam/Phaseo/pull/477))。
- モデルページのヘッダーにモデル ID コントロールが追加され、モデルのエイリアスを切り替えて選んだ ID をコピーできます ([#473](https://github.com/phaseoteam/Phaseo/pull/473))。
- **Models** のサイドバーのフィルター件数が、選択中の他のフィルターに合わせて更新されるようになりました ([#473](https://github.com/phaseoteam/Phaseo/pull/473))。

</div>

<div data-changelog-category="api">

<p className="changelog-category">API と SDK</p>

<Update label="2026年5月6日">

<div data-changelog-category="api">

<p className="changelog-category">API と SDK</p>

- モデル一覧エンドポイントは `availability=all` を受け付け、近日公開や非アクティブのモデルも含めて返します。各プロバイダーには `availability_status` と `availability_reason` が含まれます。詳しくは [モデル一覧](../api-reference/endpoint/models.mdx) を参照 ([#466](https://github.com/phaseoteam/Phaseo/pull/466))。
- エラーレスポンスに `failed_providers`、`routing_diagnostics`、`provider_failure_diagnostics` が含まれ、認証情報の不足やリージョン制限などの原因を示します。詳しくは [エラーとデバッグ](../api-reference/errors.mdx) を参照 ([#467](https://github.com/phaseoteam/Phaseo/pull/467))。
- 生成の取得エンドポイントは `replay_request` と `replay_supported` を返すため、記録されたリクエストを元のエンドポイントに再送信できます。詳しくは [生成の取得](../api-reference/endpoint/generation.mdx) を参照 ([#467](https://github.com/phaseoteam/Phaseo/pull/467))。
