<Update label="2026年4月29日" tags={["機能","モデルのリリース","SDK"]}>

### SDKのリリース

- SDK `2.0.2`を次の言語向けに公開しました: [TypeScript](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fsdk%402.0.2), [Python](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fpy-sdk%402.0.2), [Go](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fgo-sdk%402.0.2), [C#](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fcsharp-sdk%402.0.2), [Java](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fjava-sdk%402.0.2), [PHP](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fphp-sdk%402.0.2)、[Ruby](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fruby-sdk%402.0.2).
- このリリースでは、実行時のリクエストで使うモデルIDと、生成された呼び出し可能ヘルパーの定数を分離しました。これにより、次のSDK公開を待たずに新しいモデルを利用できます。
- 生成ヘルパーが現在のゲートウェイ対応モデル一覧を追跡するようになり、カタログのみの更新による不要なSDK変更が減りました。
