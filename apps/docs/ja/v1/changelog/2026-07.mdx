<Update label="2026年7月31日">

<div data-changelog-category="product">

<p className="changelog-category">製品</p>

- ワークスペースは **Settings -> Routing** で、リクエストのフィールドによる分岐、トラフィックの分割、フォールバックを設定した動的ルートを作成し、API キーに割り当てられます。詳しくは[ルーティングとフォールバック](../guides/routing-and-fallbacks.mdx)をご覧ください ([#1314](https://github.com/phaseoteam/Phaseo/pull/1314))。
- ログが **Requests**、**Upstream Requests**、**Jobs**、**Sessions** に分かれ、各行の詳細はサイドシートで開きます ([#1314](https://github.com/phaseoteam/Phaseo/pull/1314))。
- サポート、ワークスペースの切り替え、キー管理などのドロップダウンメニューの操作が、クリックに再び反応するようになりました。以前は一部が何も実行しませんでした ([#1378](https://github.com/phaseoteam/Phaseo/pull/1378))。

</div>

<div data-changelog-category="api">

<p className="changelog-category">API と SDK</p>

- モデル ID に `baseten:thinking-machines/inkling-small` のようにプロバイダーを指定すると、フォールバックなしでそのプロバイダーだけにリクエストを送れます。詳しくは[プロバイダー指定のモデル ID](../guides/provider-qualified-models.mdx)をご覧ください ([#1369](https://github.com/phaseoteam/Phaseo/pull/1369))。
- Phaseo MCP サーバーは MCP プロトコルバージョン `2026-07-28` に対応し、以前のバージョンのクライアントも引き続き受け付けます ([#1341](https://github.com/phaseoteam/Phaseo/pull/1341))。

</div>

<Update label="2026年7月26日">

<div data-changelog-category="api">

<p className="changelog-category">API と SDK</p>

- Agent SDK のパッケージが TypeScript `0.2.0` に加えて Python、Go、C#、PHP、Ruby 向けに公開され、ツールの承認、停止条件、キャンセル可能なストリーミングに対応します。詳しくは[Agent SDK の概要](../sdk-reference/agent-sdk/overview.mdx)をご覧ください ([#1263](https://github.com/phaseoteam/Phaseo/pull/1263), [#1269](https://github.com/phaseoteam/Phaseo/pull/1269), [#1259](https://github.com/phaseoteam/Phaseo/pull/1259))。
- Rust クライアント `phaseo` と同期型の Rust Agent SDK `phaseo-agent` `0.1.0` が crates.io で公開されました。詳しくは[Rust SDK](../sdk-reference/rust/overview.mdx)をご覧ください ([#1287](https://github.com/phaseoteam/Phaseo/pull/1287), [#1289](https://github.com/phaseoteam/Phaseo/pull/1289))。
- `GET /v1/models` はモデルの標準版と `:free` 版を結び付ける `variants` オブジェクトを返し、Models ページでは各バージョンが別々に表示されます ([#1298](https://github.com/phaseoteam/Phaseo/pull/1298))。
- Phaseo MCP サーバーは、モデル、プロバイダー、コスト、クレジット、使用量、リクエストの状態を扱う 10 個の読み取り専用ツールを提供し、必要な 7 つのスコープだけを要求します。詳しくは[CLI と MCP](../developers/cli-and-mcp.mdx)をご覧ください ([#1290](https://github.com/phaseoteam/Phaseo/pull/1290), [#1292](https://github.com/phaseoteam/Phaseo/pull/1292), [#1297](https://github.com/phaseoteam/Phaseo/pull/1297))。
