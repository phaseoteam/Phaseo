<Update label="2026年8月31日">

<div data-changelog-category="product">

<p className="changelog-category">製品</p>

- BYOK では、ワークスペースごとに UTC の各月 250,000 件のリクエストまで Phaseo の手数料がかからず、それ以降はプロバイダー換算コストの 2.5% が課金されるようになりました。BYOK のリクエスト単位のメタデータは 90 日間保持されます ([#2056](https://github.com/phaseoteam/Phaseo/pull/2056))。

</div>

</Update>

<Update label="2026年8月30日">

<div data-changelog-category="product">

<p className="changelog-category">製品</p>

- Chat のエラーが原因を説明し、再試行、サインイン、別のモデルの選択などの次の操作を提示するようになりました。`402` エラーにはクレジットと `phaseo/free` へのリンクが表示されます ([#2100](https://github.com/phaseoteam/Phaseo/pull/2100))。
- Chat の入力欄は 5 行までしか広がらず、長いプロンプトは会話を覆わずにスクロール表示されるようになりました ([#2096](https://github.com/phaseoteam/Phaseo/pull/2096))。
- モデルページで `?provider=openai` のようなリンクからプロバイダーの詳細を開けるようになり、プロバイダーのダイアログにはコピーできるプロバイダー指定モデル ID が表示されます。詳しくは[プロバイダー修飾モデル ID](../guides/provider-qualified-models.mdx)をご覧ください ([#2095](https://github.com/phaseoteam/Phaseo/pull/2095), [#2052](https://github.com/phaseoteam/Phaseo/pull/2052))。
- モデル検索では、ステータスフィルターを変更するまでゲートウェイ経由でルーティングできるモデルだけが表示されるようになりました。詳しくは[Gatewayの信頼性とステータスを確認する](../developers/reliability-and-status.mdx)をご覧ください ([#2057](https://github.com/phaseoteam/Phaseo/pull/2057))。
- 公開アプリランキングは、ウェブサイトごとに 1 つのエントリーにまとめられ、`/apps/phaseo-chat` のような読みやすい URL を持つようになりました ([#2087](https://github.com/phaseoteam/Phaseo/pull/2087))。
- Trust Centre にセキュリティホワイトペーパー、サブプロセッサー一覧、DPA の草案が追加され、アカウントを削除すると Phaseo のすべての稼働中ストアから 30 日以内にデータが削除されるようになりました ([#2058](https://github.com/phaseoteam/Phaseo/pull/2058))。

</div>

<div data-changelog-category="api">

<p className="changelog-category">API と SDK</p>

- CLI は不足しているコーディングエージェントをインストールする前に確認し、正確なインストールコマンドを表示するようになりました。自分で管理するツールには `--skip-install` を指定します。詳しくは[コーディングエージェント](../guides/integrations/coding-assistants.mdx)をご覧ください ([#2066](https://github.com/phaseoteam/Phaseo/pull/2066))。
- 管理 API で `/v1/byok` のプロバイダー認証情報と `/v1/budgets` のワークスペース予算を管理できるようになり、すべての SDK もこれに合わせて再生成されました。詳しくは[プロバイダー資格情報を一覧表示](../api-reference/endpoint/provider-credentials-list.mdx)をご覧ください ([#2086](https://github.com/phaseoteam/Phaseo/pull/2086))。

</div>

- `/trust` の Trust Centre で、Phaseo のセキュリティ対策、データの取り扱い、サービス提供事業者、コンプライアンスの状況を確認できるようになりました ([#1811](https://github.com/phaseoteam/Phaseo/pull/1811), [#1816](https://github.com/phaseoteam/Phaseo/pull/1816))。

- Compare はプリセットの選択画面を挟まず、直接比較ビューで開くようになりました ([#1803](https://github.com/phaseoteam/Phaseo/pull/1803))。
- BYOK 設定の残り無料リクエスト数が月 1,000,000 件の枠に基づいて計算されるようになりました。以前は廃止済みの 100,000 件の枠が使われていました ([#1595](https://github.com/phaseoteam/Phaseo/pull/1595))。
