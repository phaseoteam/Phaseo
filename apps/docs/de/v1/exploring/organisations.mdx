Öffne eine Organisation unter [Organisationen](https://phaseo.app/organisations), um jedes Modell zu sehen, das sie veröffentlicht hat, und wie diese Modelle im Gateway abschneiden. Jedes Modell auf Phaseo gehört zu einer Organisation: dem Unternehmen oder Labor, das es entwickelt und pflegt.

## Was eine Organisationsseite zeigt

Die Seite hat zwei Tabs.

| Tab | Bereich | Was er dir zeigt |
| --- | --- | --- |
| **Übersicht** | Über | Name, Beschreibung und Land. |
| | Leistung | Aktuelle Gateway-Latenz und -Durchsatz über die Modelle der Organisation. |
| | Neueste Modelle | Neue Veröffentlichungen mit Verfügbarkeit, Kontext, Preisen und Nutzung. |
| | Im Web | Links zur Website der Organisation, zu GitHub, Hugging Face und Social-Media-Konten. |
| **Modelle** | | Jedes Modell, das die Organisation veröffentlicht hat, einschließlich archivierter und veralteter Modelle. |

## Organisationen und API-Anbieter

Die Organisation entwickelt das Modell; ein [API-Anbieter](./api-providers.mdx) stellt es bereit. Ein Modell hat oft mehrere Anbieter.

| | Organisation | API-Anbieter |
| --- | --- | --- |
| **Tut** | Trainiert und pflegt das Modell. | Hostet das Modell hinter einer API. |
| **Beispiel** | Anthropic hat die Claude-Modelle entwickelt. | Anthropic, Amazon Bedrock und Google Vertex stellen alle Claude-Modelle bereit. |

Manche Organisationen, etwa OpenAI und Google, sind auch Anbieter ihrer eigenen Modelle.

## Korrektur melden

Erstelle ein GitHub-Issue mit der Organisationsseite und einer offiziellen Quelle. Die Maintainer übernehmen genehmigte Änderungen in die Datenbank. Siehe [Organisationsaktualisierung melden](../contributing/editing-an-organisation.mdx).
