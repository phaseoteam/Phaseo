Öffne die Liste [Modelle](https://phaseo.app/models), um Text-, Bild-, Audio-, Video-, Embedding- und andere Modelle zu finden, und öffne dann ein Modell, um seine Anbieter, Preise, Leistung und Benchmark-Punktzahlen zu sehen.

![Eine Modellseite auf Phaseo](/images/gemini-3-page.png)

## Katalogmodelle und aufrufbare Modelle

Der Katalog ist umfangreicher als das Gateway. Die Modellliste zeigt standardmäßig nur Modelle, die **Auf Gateway aktiv** sind. Stelle den Filter **Gateway-Status** auf **Demnächst verfügbar** oder **Inaktiv**, um den Rest zu sehen.

| Begriff | Bedeutung |
| --- | --- |
| Katalogmodell | Phaseo erfasst Metadaten zum Modell. Es hat möglicherweise keine Route, die du aufrufen kannst. |
| Routbares Modell | Mindestens eine Anbieterroute ist jetzt auf dem Phaseo-Gateway aktiv. |
| Externe Zuordnung | Phaseo listet ein Anbieterangebot auf, das das Gateway nicht ausführt. |

`GET /v1/models` gibt nur routbare Modelle zurück. Füge `availability=all` hinzu, um den Rest einzuschließen.

## Liste filtern und sortieren

| Steuerelement | Optionen |
| --- | --- |
| Gateway-Status | Auf Gateway aktiv (Standard), Demnächst verfügbar, Inaktiv |
| Endpunkte | Die API-Endpunkte, die ein Modell unterstützt, etwa Textgenerierung oder Embeddings |
| Eingabe- und Ausgabemodalitäten | Text, Bild, Audio, Video und weitere |
| Funktionen | Fähigkeiten wie Tool-Aufrufe oder Reasoning |
| Jahr | Veröffentlichungsjahr |
| Sortierung | Neueste, am beliebtesten (Tokens der letzten 7 Tage), Preis, Kontextlänge, Durchsatz, Latenz |

Um jedes Modell eines Labors zu sehen, öffne seine [Organisationsseite](./organisations.mdx).

## Was eine Modellseite zeigt

| Bereich | Was er dir zeigt |
| --- | --- |
| **Anbieter** | Jede Anbieterroute mit Status, Kontextlänge, Preis, Verfügbarkeit und Datenrichtlinie. [Anbieterstatus](../guides/provider-statuses) erklärt die Symbole. |
| **Leistung** | Latenz und Durchsatz, gemessen im Gateway-Traffic, sofern genügend Daten vorliegen. |
| **Preise** | Jede Abrechnungseinheit in USD: Eingabe, Ausgabe, zwischengespeicherte Eingabe und Medieneinheiten. |
| **Vergleichstests** | Punktzahlen in jedem Benchmark, mit Quellen. |
| **Aktivität** | Gateway-Token-Nutzung im Zeitverlauf. |
| **Apps** | Öffentliche Apps, die das Modell nutzen. |
| **Verfügbarkeit** | Verfügbarkeit der Routen in den letzten Tagen. |
| **Verifizierung** | Prüfungen der Inhaltsherkunft, für Bild- und Videomodelle. |
| **Über dieses Modell** | Veröffentlichungsdaten, Lizenz, Links und Familie. |
| **Abonnements** | Abonnementpläne von Anbietern, die das Modell enthalten. |
| **FAQ** | Häufige Fragen zum Modell. |

Ein Bereich erscheint nur, wenn es Daten dafür gibt. Modelle mit einer aktiven Route zeigen außerdem einen Schnellstart mit der Modell-ID, die du senden musst.

## Modelle vergleichen

[Vergleichen](https://phaseo.app/compare) stellt Modelle nach Preis, Benchmark-Punktzahlen, Kontext und Funktionen nebeneinander. [Preise und Leistung](./pricing-performance.mdx) erklärt, wie du die Kosten- und Geschwindigkeitswerte liest.

## Korrektur melden

Erstelle ein GitHub-Issue mit der Modellseite und einer offiziellen Quelle. Die Maintainer übernehmen genehmigte Aktualisierungen in die Datenbank. Siehe [Modellaktualisierung melden](../contributing/editing-a-model.mdx).
