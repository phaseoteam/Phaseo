Das Python-Agent-SDK ist eine vollständige lokale Agent-Laufzeit für Phaseo Gateway. Dazu gehören Wiederholungen, parallele Werkzeuge, Zeitlimits, menschliche Prüfung, fortsetzbarer Zustand, Lebenszyklusereignisse und DevTools-Aufzeichnung.

Verwende es, wenn du Folgendes möchtest:

- eine schlanke, begrenzte Werkzeugschleife
- Anfragen an den Gateway-Endpunkt `responses`
- anwendungseigene Kontrolle über Persistenz und Orchestrierung

## Enthaltene Funktionen

- `create_agent(...)`
- `define_tool(...)`
- `create_gateway_agent_client(...)`
- Anfragen an den Gateway-Endpunkt `responses`
