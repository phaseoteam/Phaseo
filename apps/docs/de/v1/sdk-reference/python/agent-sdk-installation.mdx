Das Agent SDK wird auf PyPI als [`phaseo-agent-sdk`](https://pypi.org/project/phaseo-agent-sdk/) veröffentlicht.

## Voraussetzungen

- Python 3.10 oder neuer
- Einen Phaseo-API-Schlüssel

## Installation

Installiere das Agent SDK mit deinem bevorzugten Python-Paketmanager:

<CodeGroup>

    ```bash title="pip"
    pip install phaseo-agent-sdk
    ```

    ```bash title="uv"
    uv add phaseo-agent-sdk
    ```

</CodeGroup>

Der zentrale `phaseo`-Client wird automatisch als Abhängigkeit installiert.

## Umgebung

Setze den Gateway-API-Schlüssel, bevor du Beispiele ausführst:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
