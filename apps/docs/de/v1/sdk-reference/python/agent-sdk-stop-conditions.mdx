Kombiniere Stopp-Hilfsfunktionen über `stop_when`:

```python
stop_when = [
    step_count_is(12),
    max_tokens_used(40_000),
    max_cost(2),
    max_duration(60_000),
]
```

Weitere Hilfsfunktionen sind `has_tool_call(...)` und `finish_reason_is(...)`. Lege auch bei Kosten- oder Tokenlimits eine Schritt- oder Zeitgrenze fest, da diese von gemeldeten Nutzungsdaten abhängen.
