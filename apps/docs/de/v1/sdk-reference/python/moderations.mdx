---

**Methode**: `client.generate_moderation()`.

### Beispiel
```python
moderation = client.generate_moderation({
    "model": "openai/omni-moderation-latest",
    "input": "Text to classify",
})
```

### Wichtige Parameter
- `model` (erforderlich): ID des Moderationmodells (z. B. `openai/omni-moderation-latest`).
- `input` (erforderlich): Zeichenfolge oder Array mit Inhaltselementen (Text oder `image_url`).
- Optional: `categories`-/`severity`-Filter (falls unterstützt) und `user`-Kennzeichnung.

### Rückgabe
`ModerationResponse`
