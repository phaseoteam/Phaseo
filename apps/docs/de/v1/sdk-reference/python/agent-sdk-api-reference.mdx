---

| API | Zweck |
| --- | --- |
| `create_agent(...)` | Einen Agenten definieren |
| `define_tool(...)` | Ein lokales oder manuelles Tool definieren |
| `create_gateway_agent_client(...)` | Modellzüge mit Phaseo verbinden |
| `agent.run(...)` | Bis zum Abschluss oder Pausieren ausführen |
| `agent.stream(...)` | Mit erneut durchlaufbaren Stream-Consumern ausführen |
| `agent.continue_run(...)` | Einen gespeicherten oder pausierten Zustand fortsetzen |
| `stream.result()` | Den abgeschlossenen Lauf lesen |
| `stream.text_stream()` | Textänderungen lesen |
| `stream.full_stream()` | Alle Ereignisse lesen |
| `stream.cancel()` | Den aktiven Lauf abbrechen |

Zu den wichtigen Typen gehören `AgentTool`, `AgentToolDecision`, `AgentToolOutput`, `AgentRunResult`, `AgentStateAccessor`, `AgentModelRetryConfig` und `AgentToolExecutionConfig`.
