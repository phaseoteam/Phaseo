Das Agent-SDK wird veröffentlicht als [`phaseo/agent-sdk`](https://packagist.org/packages/phaseo/agent-sdk) auf Packagist.

## Voraussetzungen

- PHP 8.1 oder neuer
- Composer
- einen Phaseo-API-Schlüssel

## Installation

```bash
composer require phaseo/agent-sdk
```

Das Kernpaket `phaseo/sdk` wird automatisch als Abhängigkeit installiert.

## Umgebung

Lege vor dem Ausführen der Beispiele deinen Gateway-API-Schlüssel fest:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
