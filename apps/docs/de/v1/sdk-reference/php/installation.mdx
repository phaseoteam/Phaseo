Das SDK wird als [`phaseo/sdk`](https://packagist.org/packages/phaseo/sdk) auf Packagist.

## Voraussetzungen

- PHP 8.1 oder neuer
- Composer

## Installation

```bash
composer require phaseo/sdk
```
