## Laufzeit vorbereiten

Das Agent-SDK-Paket ist noch nicht auf Packagist verfügbar. Folge den [Installationsanweisungen für den Quellcode](./agent-sdk-installation.mdx).

## Schnellstart

```php
<?php
require "vendor/autoload.php";

use Phaseo\AgentSdk\AgentDefinition;
use Phaseo\AgentSdk\AgentSdk;

$agent = AgentSdk::createAgent(new AgentDefinition(
    id: "quickstart-agent",
    model: "openai/gpt-5.4-nano",
    instructions: "Answer concisely and helpfully."
));

$result = $agent->run(
    input: "Give me one fun fact about cURL.",
    client: AgentSdk::createGatewayAgentClient()
);

echo $result->output . PHP_EOL;
```

## Lieferumfang

- `AgentSdk::createAgent(...)`
- `AgentSdk::defineTool(...)`
- `AgentSdk::createGatewayAgentClient(...)`
- eine begrenzte Tool-Schleife über die Phaseo-`responses`-API

## Erweiterte Laufzeit

PHP unterstützt Validierungs- und Freigabe-Callbacks, HITL- und manuelle Tools, Fortschritt, behebbare Fehler, wiederabspielbare Iteratoren, Abbruchfunktionen, dynamische Turns, persistierte Parameter für den nächsten Turn, normalisierte Nutzung und Kosten sowie `StateAccessor`.

## Streaming und Abbruch

`Agent::stream(...)` und `Agent::continueStream(...)` führen den Responses-SSE-Stream des Gateways über eine Fiber aus, sobald der zurückgegebene Iterator verarbeitet wird. Verwende `textStream()`, `reasoningStream()`, `itemStream()` oder `fullStream()`; rufe `cancel()` auf, um die Fiber anzuhalten und den Generator zu schließen. Abgeschlossene Schritte behalten Request-IDs, Provider-Metadaten, Beendigungsgründe, Warnungen, Nutzung und Kosten.
