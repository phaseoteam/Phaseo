title: "STT (Sprache zu Text)"
description: "Rufe /audio/transcriptions mit dem PHP-SDK auf."
---

**Methode**: `$client->generateTranscription(...)` oder `$client->createTranscription(...)`

### Beispiel

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo(getenv('PHASEO_API_KEY'));
$response = $client->generateTranscription([
    'model' => 'openai/gpt-4o-transcribe',
    'audio_url' => 'https://example.com/audio.mp3', // or 'audio_b64' for base64 data
    'language' => 'en'
]);
echo $response['text'] ?? '';
```

### Wichtige Parameter

- `model` (erforderlich): ID eines transkriptionsfähigen Modells.
- `audio_url` oder `audio_b64` (erforderlich): Audiodaten als URL oder Base64.
- `language`: Sprachhinweis, zum Beispiel `en`.
- `prompt`: optionaler Kontext zur Verbesserung der Genauigkeit.
- `temperature` (0–2): Zufälligkeit der Stichprobenauswahl.
- `response_format`: `json`, `text`, `srt`, `verbose_json` usw.

### Rückgabewert

AudioTranscriptionResponse
