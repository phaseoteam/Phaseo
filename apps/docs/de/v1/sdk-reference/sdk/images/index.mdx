---

Verwende `generateImage` mit `phaseo.imageModel(...)`.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateImage } from "ai";

const result = await generateImage({
  model: phaseo.imageModel("openai/gpt-image-1"),
  prompt: "A minimalist poster of a lighthouse at dawn.",
  size: "1024x1024",
});

console.log(result.images[0].mediaType);
console.log(result.images[0].uint8Array.length);
console.log(result.providerMetadata);
```

## Hinweise

- Die verfügbaren `size`-Werte hängen vom ausgewählten Modell ab.
- Bildantworten des Gateways mit URL werden in das Dateiformat von AI SDK umgewandelt. Lies daher zuerst die stabilen Felder `uint8Array` und `mediaType` aus.
- Speichere für deterministische Abläufe Prompt, Modell und Parameter gemeinsam.
- Speichere die zurückgegebenen Bildmetadaten zusammen mit den Asset-Referenzen.
