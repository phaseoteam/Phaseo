Übergib `phaseo.imageModel(modelId)` an `generateImage`. Die Anfragen gehen an den Endpunkt `/v1/images/generations` des Gateways.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateImage } from "ai";

const result = await generateImage({
  model: phaseo.imageModel("openai/gpt-image-1"),
  prompt: "A minimalist poster of a lighthouse at dawn.",
  size: "1024x1024",
});

console.log(result.images[0].mediaType);
console.log(result.images[0].uint8Array.length);
console.log(result.providerMetadata);
```

## Das Ergebnis lesen

Bilder, die das Gateway als URLs zurückgibt, werden in die Dateiform des AI SDK umgewandelt. Lies daher bei jedem Bild `uint8Array` und `mediaType`, egal was der Anbieter zurückgegeben hat.

- Welche `size`-Werte verfügbar sind, hängt vom Modell ab.
- Um ein Bild später zu reproduzieren, speichere Prompt, Modell und Parameter zusammen mit den Metadaten des Bildes.
