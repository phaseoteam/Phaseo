Übergib `phaseo.transcriptionModel(modelId)` an `transcribe` für Sprache zu Text und `phaseo.speechModel(modelId)` an `generateSpeech` für Text zu Sprache. Der Provider lädt Audio als Multipart-Formular an `/v1/audio/transcriptions` hoch und sendet Sprachanfragen an `/v1/audio/speech`.

```ts
import { readFileSync, writeFileSync } from "node:fs";
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateSpeech, transcribe } from "ai";

const transcription = await transcribe({
  model: phaseo.transcriptionModel("openai/whisper-1"),
  audio: readFileSync("./audio.mp3"),
});

console.log(transcription.text);
console.log(transcription.providerMetadata);

const speech = await generateSpeech({
  model: phaseo.speechModel("openai/gpt-4o-mini-tts"),
  text: "Hello from Phaseo audio.",
  voice: "alloy",
  outputFormat: "mp3",
});

writeFileSync("./speech.mp3", Buffer.from(speech.audio.uint8Array));
console.log(speech.providerMetadata);
```

`audio` akzeptiert einen `Buffer`, ein `Uint8Array`, einen `ArrayBuffer`, einen Base64-String oder eine `URL`. AI SDK 7 exportiert die älteren Namen `experimental_transcribe` und `experimental_generateSpeech` weiterhin als Aliase.

## Lange oder fehlschlagende Audiodateien behandeln

- Welche Ein- und Ausgabeformate unterstützt werden, hängt vom Modell ab.
- Erhöhe die Timeouts für lange Dateien und halte Uploads innerhalb der Größengrenze des Modells (25 MB bei den meisten Modellen).
- Wiederhole vorübergehende `429`- und `5xx`-Antworten mit Backoff.
