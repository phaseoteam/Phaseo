Übergib `phaseo.embeddingModel(modelId)` (oder seinen Alias `textEmbeddingModel`) an `embed` für einen einzelnen Wert oder an `embedMany` für eine Liste. Die Anfragen gehen an den Endpunkt `/v1/embeddings` des Gateways.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { embed, embedMany } from "ai";

const single = await embed({
  model: phaseo.textEmbeddingModel("google/gemini-embedding-001"),
  value: "Embeddings power semantic search.",
});

console.log(single.embedding.length);

const batch = await embedMany({
  model: phaseo.textEmbeddingModel("google/gemini-embedding-001"),
  values: ["pricing", "latency", "quality"],
});

console.log(batch.embeddings.length);
```

## Vektoren vergleichbar halten

- Bette Suchanfragen und Korpus mit derselben Modellversion ein.
- Normalisiere Vektoren einheitlich, bevor du Ähnlichkeiten berechnest.
- Speichere stabile Embeddings für wiederkehrende Inhalte im Cache.
