Definiere Tools mit dem Helfer `tool()` des AI SDK, übergib sie an `generateText` und setze `stopWhen`, damit das Modell nach der Tool-Ausführung antworten kann.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, stepCountIs, tool } from "ai";
import { z } from "zod";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "What is 17 + 25? Use the calculator tool.",
  tools: {
    calculator: tool({
      description: "Perform basic arithmetic",
      inputSchema: z.object({
        operation: z.enum(["add", "subtract", "multiply", "divide"]),
        a: z.number(),
        b: z.number(),
      }),
      execute: async ({ operation, a, b }) => {
        if (operation === "add") return a + b;
        if (operation === "subtract") return a - b;
        if (operation === "multiply") return a * b;
        return a / b;
      },
    }),
  },
  stopWhen: stepCountIs(2),
});

console.log(result.text);
```

Standardmäßig hört `generateText` nach einem Schritt auf. Ist dieser Schritt ein Tool-Aufruf, ist `result.text` leer und das Ergebnis des Tools steht in `result.toolResults`. `stepCountIs(2)` gibt dem Modell einen zweiten Schritt, um mit dem Ergebnis zu antworten.

## Sichere Tools schreiben

- Halte Beschreibungen präzise und Eingabeschemas streng; das Modell füllt die Argumente aus.
- Behandle Argumente als nicht vertrauenswürdige Eingabe. Prüfe sie in `execute`, bevor Nebenwirkungen ausgelöst werden.
- Baue in `execute` Wiederholungen mit Backoff für nachgelagerte APIs ein, die vorübergehend ausfallen.
