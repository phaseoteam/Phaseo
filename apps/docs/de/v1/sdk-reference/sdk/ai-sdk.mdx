Installiere `@phaseo/ai-sdk-provider` und übergib `phaseo(modelId)` als `model` an `generateText`, `streamText` oder eine andere Funktion von Vercel AI SDK 7. Textanfragen gehen an den Endpunkt `/v1/chat/completions` des Gateways.

## Installieren

<CodeGroup>

```bash title="npm"
npm install @phaseo/ai-sdk-provider
```

```bash title="pnpm"
pnpm add @phaseo/ai-sdk-provider
```

```bash title="yarn"
yarn add @phaseo/ai-sdk-provider
```

```bash title="bun"
bun add @phaseo/ai-sdk-provider
```

</CodeGroup>

Das Paket ohne Versionsangabe installiert den npm-Tag `latest`, also die AI-SDK-7-Linie. Es deklariert `ai@^7` als Peer-Abhängigkeit, sodass Paketmanager, die Peers automatisch installieren, sie für dich hinzufügen.

Setze `PHASEO_API_KEY` in deiner Serverumgebung und sende dann deine erste Anfrage. Der Standardexport `phaseo` wirft einen Fehler, wenn `PHASEO_API_KEY` nicht gesetzt ist.

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Reply with: AI SDK works",
});

console.log(result.text);
console.log(result.providerMetadata);
```

Verwende eine aktuelle Modell-ID aus dem [Models-Endpunkt](../../api-reference/endpoint/models.mdx).

## Text streamen

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Stream a short greeting.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Eine Provider-Instanz konfigurieren

Rufe `createPhaseo()` auf, um `apiKey`, `baseURL`, `headers` oder ein eigenes `fetch` festzulegen. Damit kannst du deine Anwendung in den Phaseo-Anfragedetails kennzeichnen:

```typescript
import { createPhaseo } from "@phaseo/ai-sdk-provider";

const phaseo = createPhaseo({
  apiKey: process.env.PHASEO_API_KEY,
  headers: {
    "x-title": "My App",
    "http-referer": "https://example.com",
  },
});
```

`PHASEO_BASE_URL` ist optional und hat den Standardwert `https://api.phaseo.app/v1`.

## Einen Modelltyp wählen

| Provider-Methode | AI-SDK-Funktion |
| --- | --- |
| `phaseo(modelId)` oder `phaseo.languageModel(modelId)` | `generateText`, `streamText` |
| `phaseo.embeddingModel(modelId)` (Alias `textEmbeddingModel`) | `embed`, `embedMany` |
| `phaseo.imageModel(modelId)` | `generateImage` |
| `phaseo.transcriptionModel(modelId)` | `transcribe` |
| `phaseo.speechModel(modelId)` | `generateSpeech` |
| `phaseo.rerankingModel(modelId)` | `rerank` |

Alle Methoden außer `rerankingModel` akzeptieren als zweites Argument optionale Einstellungen pro Modell: `temperature`, `topP`, `topK`, `maxTokens`, `frequencyPenalty`, `presencePenalty`, `seed`, `user`, `headers` und `fetch`.

## Unterstützte Funktionen von AI SDK 7

- Textgenerierung und Streaming
- Reasoning-Ausgabe und -Einstellungen
- Funktions-Tools und gestreamte Tool-Eingaben
- Ausgabe als JSON und nach JSON Schema
- Text- und Bilddateien als Eingabe
- URL-Zitationsquellen
- Embeddings und Bildgenerierung
- Reranking
- Transkription und Sprachgenerierung
- Provider-Metadaten, Nutzung, Abbruchsignale und rohe Stream-Chunks

Was ein Aufruf tatsächlich kann, hängt weiterhin von Modell und Anbieter ab. Der Provider meldet keine verwalteten Dateireferenzen, Skills oder vom Anbieter ausgeführten Tools (weder deren Definitionen noch Ergebnisse oder Freigabeantworten). Funktions-Tools, die deine Anwendung ausführt, nutzen den normalen Ausführungs- und Freigabeablauf des AI SDK.

## Eine ältere AI-SDK-Version verwenden

| AI SDK | Installation |
| --- | --- |
| 7 | `@phaseo/ai-sdk-provider` (`latest`) |
| 6 | `@phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `@phaseo/ai-sdk-provider@ai-sdk-v5` |

Wenn die automatische Installation von Peers ausgeschaltet ist, installiere die passende Hauptversion von `ai` (`ai@^7`, `ai@^6` oder `ai@^5`) selbst.
