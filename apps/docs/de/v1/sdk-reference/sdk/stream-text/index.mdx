Rufe `streamText` mit `phaseo(modelId)` auf und lies `textStream`, um Text zu erhalten, sobald er eintrifft. `streamText` kehrt sofort zurück; lies `providerMetadata`, nachdem der Stream beendet ist.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Aus einem Chatverlauf streamen

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## Einen verlassenen Stream stoppen

Übergib ein `abortSignal` an `streamText` und brich es ab, wenn der Nutzer die Seite verlässt oder ein Timeout abläuft, damit die Anfrage nicht weiterläuft:

```ts
const controller = new AbortController();
setTimeout(() => controller.abort(), 60_000);

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a long report.",
  abortSignal: controller.signal,
});
```

Lies Modell-IDs aus `/v1/models`, statt sie fest einzutragen; siehe [Modellentdeckung](/de/v1/sdk-reference/sdk/get-models).
