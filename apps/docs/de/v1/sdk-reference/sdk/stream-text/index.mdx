---

Verwende `streamText`, wenn du Tokens direkt nach ihrem Eintreffen erhalten möchtest.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Streaming mit Nachrichten

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## Tipps für den Produktionseinsatz

- Bevorzuge Streaming für lange Antworten und interaktive Oberflächen.
- Behandle Abbruch und Timeouts in deiner Laufzeitumgebung für nicht mehr genutzte Streams.
- Halte Modell-IDs über `/v1/models` aktuell, damit keine veralteten Aliase verwendet werden.
