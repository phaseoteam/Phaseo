Rufe `generateText` mit `phaseo(modelId)` auf, um eine vollständige Antwort zu erhalten.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a concise summary of Phaseo Gateway.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

## Chatverlauf senden

Verwende `prompt` für einen einzelnen Zug und `messages`, wenn du mehrere Züge oder eine Systemrolle brauchst.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "system", content: "You are a terse assistant." },
    { role: "user", content: "Give me three bullet points on retrieval augmentation." },
  ],
});

console.log(result.text);
console.log(result.providerMetadata);
```

## Standardwerte am Modell festlegen

Übergib Einstellungen als zweites Argument an `phaseo()`. Diese Einstellungen gelten für jeden Aufruf, der diese Modellinstanz verwendet.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra", {
    maxTokens: 300,
  }),
  prompt: "Draft a release note for an API update.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

Modell-IDs haben die Form `provider/model`. Damit sie aktuell bleiben, lies sie aus `/v1/models`; siehe [Modellentdeckung](/de/v1/sdk-reference/sdk/get-models).
