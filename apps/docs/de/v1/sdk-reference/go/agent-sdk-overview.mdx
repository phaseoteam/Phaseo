Das Go-Agent-SDK ist eine vollständige lokale Agent-Laufzeit für Phaseo Gateway. Dazu gehören Wiederholungen, parallele Werkzeuge, Kontexte und Zeitlimits, menschliche Prüfung, fortsetzbarer Zustand, Lebenszyklusereignisse und DevTools-Aufzeichnung.

Verwende es, wenn du Folgendes möchtest:

- eine schlanke, begrenzte Werkzeugschleife
- Anfragen an den Gateway-Endpunkt `responses`
- anwendungseigene Kontrolle über Persistenz und Orchestrierung

## Enthaltene Funktionen

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- Anfragen an den Gateway-Endpunkt `responses`
