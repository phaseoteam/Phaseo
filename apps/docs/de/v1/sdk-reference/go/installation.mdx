Das SDK wird als [`sdk-go/v2`](https://pkg.go.dev/github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v2) veröffentlicht.

## Voraussetzungen

- Go 1.23 oder höher

## Installation

```bash
go get github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v2@latest
```

Importiere den Modulpfad der Version 2:

```go
import phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v2"
```
