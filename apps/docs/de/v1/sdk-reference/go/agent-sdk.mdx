## Laufzeit vorbereiten

Das Agent SDK hat noch keine öffentliche Go-Modulversion. Folge den [Installationsanweisungen für den Quellcode](./agent-sdk-installation.mdx).

## Schnellstart

```go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "quickstart-agent",
    Model:        "openai/gpt-5.4-nano",
    Instructions: "Answer concisely and helpfully.",
  })

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "Give me one fun fact about cURL.",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Output)
}
```

## Lieferumfang

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- eine begrenzte Tool-Schleife über die Phaseo-`responses`-API

## Erweiterte Laufzeit

Go unterstützt Validatoren und Freigaben, HITL- und manuelle Tools, Fortschritt, behebbare Fehler, wiederabspielbare Channels, Abbruchfunktionen, dynamische Turns, persistierte `NextTurnParams`, normalisierte Nutzung und Kosten sowie `StateAccessor`.

## Streaming und Abbruch

`Agent.Stream(...)` und `Agent.ContinueStream(...)` lesen den Responses-SSE-Stream des Gateways. Lies `Text()` oder `Events()` mehrfach, wenn verschiedene Consumer eine Wiederholung benötigen, und rufe `Cancel()` auf, um den Request-Kontext abzubrechen. Abgeschlossene Schritte behalten Request-IDs, Provider-Metadaten, Beendigungsgründe, Warnungen, Nutzung und Kosten.
