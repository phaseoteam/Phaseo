Validiere die Ausgabe, damit der vom Agent zurückgegebene Wert dem Vertrag deiner Anwendung entspricht. Modellwiederholungen gelten für fehlgeschlagene Anfragen; Tool-Wiederholungen müssen in der Implementierung ausdrücklich festgelegt und nur dann verwendet werden, wenn sie sicher sind.

## Modellwiederholungen konfigurieren

```go
agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
  ID: "research-agent",
  Model: "openai/gpt-5.4-nano",
  ModelRetry: phaseoagent.ModelRetryConfig{
    MaxRetries: 3,
    BaseDelay:  500 * time.Millisecond,
    MaxDelay:   4 * time.Second,
  },
})
```

Der Laufdatensatz speichert die Anzahl der Modellversuche pro Schritt. Bei einer Wiederholung bleiben bereits abgeschlossene Tool-Ergebnisse erhalten.

## Endgültiges Ergebnis validieren

Setze `OutputSchema` in `AgentDefinition`, wenn nachgelagerter Code ein strukturiertes Ergebnis benötigt. Die Validierung läuft, bevor das Ergebnis als abgeschlossen markiert wird. Eine ungültige Ausgabe schlägt daher an der Agent-Grenze fehl und nicht erst später in der Anwendung.

## Ergebnis untersuchen

```go
result, err := agent.Run(ctx, phaseoagent.RunOptions{Input: prompt, Client: client})
if err != nil { return err }

fmt.Println(result.Output)
fmt.Println(result.Run.Status)
fmt.Println(result.Usage.TotalTokens)
fmt.Println(result.Usage.Cost)
```
