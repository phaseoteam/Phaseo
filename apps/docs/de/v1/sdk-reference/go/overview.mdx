Installiere das veröffentlichte Modul [`sdk-go/v2`](https://pkg.go.dev/github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3).

- `GenerateResponse(...)`
- `GenerateEmbedding(...)`
- `GenerateModeration(...)`
- `CreateSpeech(...)`, `CreateTranscription(...)`, `CreateTranslation(...)`
- `CreateAnthropicMessage(...)`
- `GetModels(...)`
- `GetModelEndpointCapabilities(...)`, `CheckModelParameters(...)`
- `ListOrganisations(...)`
- `ListPricingModels(...)`
- `CalculatePricing(...)`
- `ListApiKeys(...)`
- `CreateApiKey(...)`, `UpdateApiKey(...)`, `DeleteApiKey(...)`
- `GetApiKey(...)`
- `ListWorkspaces(...)`, `GetWorkspace(...)`, `CreateWorkspace(...)`, `UpdateWorkspace(...)`, `DeleteWorkspace(...)`
- `GetCurrentApiKey(...)`
- `ListEndpoints(...)`
- `ListProviders(...)`
- `GetAnalytics(...)`, `GetCredits(...)`, `GetActivity(...)`
- `CreateBatch(...)`, `RetrieveBatch(...)`, `CancelBatch(...)`
- `GetAsyncJobWebSocketURL(...)`, `GetBatchWebSocketURL(...)`, `GetVideoWebSocketURL(...)`, `client.AsyncJobs.WebSocketURL(...)`
- `ListFiles(...)`, `RetrieveFile(...)`, `RetrieveFileContent(...)`
- `RetrieveVideoContent(...)`, `GetVideoDownloadURL(...)`

- `ListVideoModels(...)`, `ListVideos(...)`

Für Endpunkte, die noch nicht in den Wrapper aufgenommen wurden, verwende direkt den generierten Client unter `packages/sdk/sdk-go/src/gen`.

```go
import (
  "context"
  "fmt"
  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

client := phaseo.New("YOUR_KEY", "https://api.phaseo.app/v1")
models, err := client.GetModels(context.Background(), map[string]string{"limit": "5"})
if err != nil {
  panic(err)
}
fmt.Println(models)
```

`CheckModelParameters` nutzt aktuelle Metadaten zu Anbieterrouten, um jeden Parameter als `supported`, `partial`, `unsupported` oder `unknown` zu kennzeichnen, die angegebenen Werte und Bereiche zu prüfen und die Routen zu liefern, die den vollständigen Parametersatz akzeptieren.
