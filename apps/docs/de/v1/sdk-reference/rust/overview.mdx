Verwende das veröffentlichte Crate [`phaseo`](https://crates.io/crates/phaseo), um das Phaseo-Gateway aus einer Rust-Anwendung aufzurufen.

Der High-Level-Client unterstützt:

- Responses-API-Anfragen mit `Phaseo::responses(...)`
- Chat-Completions-Anfragen mit `Phaseo::chat_completions(...)`
- weitere JSON-Endpunkte mit `Phaseo::post(...)`
- umgebungsbasierte Konfiguration mit `Phaseo::from_env()`
- benutzerdefinierte HTTPS-Endpunkte und Loopback-Entwicklungsserver
- strukturierter Status, JSON-Body, Request-ID und Fehlerdetails

```rust
use phaseo::Phaseo;
use serde_json::json;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Phaseo::from_env()?;
    let response = client.responses(&json!({
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with exactly: Rust SDK works"
    }))?;

    println!("{}", response.body);
    Ok(())
}
```

<Note>
  Version `0.1` wird unterstützt und ist veröffentlicht, aber die Rust-API kann sich vor `1.0` noch ändern. Fixiere in der Produktion eine kompatible Minor-Version.
</Note>

## Aktueller Umfang

Der komfortable Client ist synchron und akzeptiert Request-Bodies vom Typ `serde_json::Value`. Generierte Low-Level-Module sind weiterhin unter `phaseo::gen` verfügbar, mit praktischen Re-Exports unter `phaseo::client`, `phaseo::models` und `phaseo::operations`.

Der Rust-Client bietet derzeit weder einen asynchronen Transport noch eine High-Level-Streamingfunktion. Verwende die rohe HTTP-API, wenn eine Anwendung Streaming benötigt, bevor diese Hilfsfunktionen verfügbar sind.
