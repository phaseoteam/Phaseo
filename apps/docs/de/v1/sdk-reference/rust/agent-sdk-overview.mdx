Verwende das veröffentlichte [`phaseo-agent`](https://crates.io/crates/phaseo-agent)-Crate, wenn eine Rust-Anwendung eine begrenzte Modellsitzung, lokale Tools, Freigaben oder fortsetzbare menschliche Überprüfung benötigt.

Das Rust Agent SDK baut auf dem `phaseo`-Client auf und führt Modellschritte über die Phaseo Responses API aus.

## Unterstützte Funktionen

| Funktion | Rust-Unterstützung |
| --- | --- |
| Lokale ausführbare Tools | Ja; werden synchron in der Reihenfolge der Modellaufrufe ausgeführt |
| Externe Tool-Ergebnisse | Ja; über `Tool::external(...)` und `ContinueOptions` |
| Tool-Freigabe | Ja; anhand der exakten Tool-Aufruf-ID |
| Menschliche Überprüfung | Ja; mit serialisierbarem pausiertem Ausführungsstatus |
| Modellwiederholungen | Ja; mit festem Warteintervall |
| Lebenszyklusereignisse | Ja; über callbackbasierte Ausführungsmethoden |
| Nutzungsaggregation | Eingabe-, Ausgabe-, Cache- und Gesamttokens; Kosten, wenn ein benutzerdefinierter Modellclient sie bereitstellt |
| Ausführungslimits | Maximale Anzahl der Modellschritte |
| Gateway-Adapter | Responses API über `GatewayAgentClient` |
| Streaming | Noch nicht unterstützt |
| Asynchrone Ausführung und Abbruch | Noch nicht unterstützt |
| Gleichzeitige lokale Tools | Noch nicht unterstützt |
| Laufzeit-Schemavalidierung | Das JSON Schema wird an das Modell gesendet; lokale Ein- und Ausgaben sind `serde_json::Value` |
| Devtools-Aufzeichnung | Noch nicht unterstützt |

<Note>
  Rust ist eine unterstützte synchrone Laufzeitumgebung und keine funktionsgleiche Portierung der TypeScript-Streaming-Laufzeit. Diese Seiten dokumentieren nur APIs aus `phaseo-agent 0.1`.
</Note>

## Laufzeitmodell

1. sendet aktuelle Nachrichten und Tool-Definitionen an einen `ModelClient`
2. führt verfügbare lokale Tools aus
3. pausiert bei Bedarf für Freigaben, externe Ergebnisse oder menschliche Überprüfung
4. fügt Ergebnisse hinzu und fährt bis zum Abschluss oder zum Schrittlimit fort

Das SDK speichert Ausführungen nicht in einem von Phaseo gehosteten Dienst. Speichere `RunResult` in deiner Anwendung, wenn eine Ausführung einen Prozessneustart überstehen muss.

Der Gateway-Adapter `0.1` überträgt `cost_nanos` oder `cost_cents` von Gateway derzeit nicht nach `UsageSummary.cost`. Verwende für Ausgaben die Gateway-Antwort oder den Generierungseintrag statt des Kostenfelds im Agent SDK.
