Das Ruby Agent SDK ist eine vollständige lokale Agent-Runtime für das Phaseo Gateway. Sie umfasst Wiederholungen, parallele Tools, Timeouts, menschliche Prüfung, fortsetzbaren Zustand, Lifecycle-Ereignisse und DevTools-Aufzeichnung.

Verwende es, wenn du Folgendes benötigst:

- eine schlanke, begrenzte Tool-Schleife
- Gateway-gestützte `responses`-Anfragen
- anwendungseigene Kontrolle über Speicherung und Orchestrierung

## Enthaltene Funktionen

- `PhaseoAgentSdk.create_agent(...)`
- `PhaseoAgentSdk.define_tool(...)`
- `PhaseoAgentSdk.create_gateway_agent_client(...)`
- eine begrenzte Tool-Schleife über die Phaseo-`responses`-API
