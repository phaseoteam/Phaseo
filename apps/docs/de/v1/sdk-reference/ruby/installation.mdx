---

Das SDK wird als [`phaseo_sdk`](https://rubygems.org/gems/phaseo_sdk) auf RubyGems.

## Voraussetzungen

- Ruby 3.1 oder neuer

## Installation

```bash
gem install phaseo_sdk
```

Oder füge es zu deinem `Gemfile` hinzu:

```ruby
gem "phaseo_sdk"
```
