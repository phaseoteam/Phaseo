---

**Methode**: `client.generate_image(...)`.

### Beispiel
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
image = client.generate_image(
  model: 'openai/gpt-image-1',
  prompt: 'A lighthouse at golden hour',
  size: '1024x1024',
  n: 1,
  response_format: 'url'
)
```

### Wichtige Parameter
- `model` (erforderlich): ID eines bildfähigen Modells (z. B. `openai/gpt-image-1`).
- `prompt` (erforderlich): Textanweisung.
- `n` (1–10): Anzahl der zu generierenden Bilder.
- `size`: z. B. `1024x1024`, `1024x1792` oder `1792x1024`.
- `quality`: `standard` oder `hd` (modellabhängig).
- `style`: z. B. `vivid` oder `natural` (modellabhängig).
- `response_format`: `url` oder `b64_json`.
- `user`: optionales Endnutzer-Tag zur Verfolgung von Sicherheit und Missbrauch.

### Rückgabewert
`ImageGenerationResponse`
