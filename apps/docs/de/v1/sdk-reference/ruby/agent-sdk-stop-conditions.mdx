Kombiniere Stoppfunktionen, damit autonome Abläufe innerhalb der Anwendungsbudgets bleiben.

```ruby
agent = PhaseoAgentSdk.create_agent(
  id: "bounded-research",
  model: "openai/gpt-5.4-nano",
  stop_when: [
    PhaseoAgentSdk.step_count_is(12),
    PhaseoAgentSdk.max_tokens_used(40_000),
    PhaseoAgentSdk.max_cost(2.50),
    PhaseoAgentSdk.max_duration(120_000)
  ]
)
```

Es gibt auch Bedingungen für Tool-Aufrufe und Beendigungsgründe. Prüfe nach Abschluss `result.run.stop_reason` und den normalisierten Verbrauch, um einen Budget-Stopp von einem normalen Modellende zu unterscheiden.

Ein Stopp ist ein begrenztes Ergebnis und nicht automatisch eine Ausnahme. Entscheide, welche Gründe als erfolgreich gelten, erneut versucht oder dem Nutzer angezeigt werden sollen.
