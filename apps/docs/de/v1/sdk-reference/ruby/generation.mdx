title: "Generierung abrufen"
description: "Rufe /generations auf, um eine frühere Generierung abzurufen."
---

**Methode**: `client.get_generation(...)`

### Beispiel

```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))

record = client.get_generation('G-01ABC...')
```

### Parameter

- `id` (String, erforderlich): Anfrage-ID, die von einem vorherigen Aufruf zurückgegeben wurde.

### Rückgabe

Generierungseintrag (JSON)

Wenn das Gateway vollständige Anfragedetails gespeichert hat, enthält der zurückgegebene Eintrag auch `replay_supported` und `replay_request`. Damit kannst du die erfasste Nutzlast für eine kontrollierte erneute Ausführung an den ursprünglichen Endpunkt senden.

Zeitfelder folgen der gemeinsamen Gateway-Semantik:

- `latency_ms`: Zeit bis zum ersten Token oder zum ersten Ausgabe-Byte/-Frame, sofern erfasst
- `generation_ms`: Generierungszeit nach der Latenz, sofern erfasst
