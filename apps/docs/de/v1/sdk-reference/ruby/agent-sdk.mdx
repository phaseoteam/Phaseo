## Laufzeit vorbereiten

Das Agent-SDK-Gem ist noch nicht auf RubyGems veröffentlicht. Folge den [Installationsanweisungen für den Quellcode](./agent-sdk-installation.mdx).

## Schnellstart

```ruby
require "phaseo_agent_sdk"

agent = PhaseoAgentSdk.create_agent(
  id: "quickstart-agent",
  model: "openai/gpt-5.4-nano",
  instructions: "Answer concisely and helpfully."
)

result = agent.run(
  input: "Give me one fun fact about cURL.",
  client: PhaseoAgentSdk.create_gateway_agent_client
)

puts result.output
```

## Funktionsumfang

- `PhaseoAgentSdk.create_agent(...)`
- `PhaseoAgentSdk.define_tool(...)`
- `PhaseoAgentSdk.create_gateway_agent_client(...)`
- Eine begrenzte Tool-Schleife über die Phaseo-API `responses`

## Erweiterte Laufzeit

Ruby unterstützt Validierungs- und Freigabe-Callables, HITL und manuelle Tools, Fortschritt, behebbare Fehler, wiederholbar abspielbare Enumeratoren, Stopp-Hilfen, dynamische Durchläufe, gespeicherte Parameter für den nächsten Durchlauf, normalisierte Nutzung/Kosten und duck-typisierte State-Accessor.

## Streaming und Abbruch

`Agent#stream(...)` und `Agent#continue_stream(...)` verarbeiten den Responses-SSE-Stream des Gateways in einem Worker-Thread. Verwende `text_stream`, `reasoning_stream`, `item_stream` oder `full_stream`; mit `cancel` stoppst du den Worker und schließt den HTTP-Stream. Abgeschlossene Schritte behalten Request-IDs, Provider-Metadaten, Abschlussgründe, Warnungen, Nutzung und Kosten.
