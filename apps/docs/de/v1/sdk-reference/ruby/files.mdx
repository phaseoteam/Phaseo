---
icon: "files"
title: "Dateien"
description: "Verwende das Ruby-SDK zum Hochladen von Dateien, Abrufen von Metadaten und Auslesen des Dateiinhalts."
---

**Methoden**: `upload_file`, `list_files`, `retrieve_file`, `retrieve_file_content`.

### Beispiel
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch('PHASEO_API_KEY'))

uploaded = client.upload_file(
  'purpose' => 'batch',
  'file' => 'data:application/json;base64,eyJ0ZXN0Ijp0cnVlfQ=='
)

file = client.retrieve_file('file_123')
content = client.retrieve_file_content('file_123')
```

<Note>
`list_files` ist im SDK verfügbar, aber `GET /files` gibt mit dem gemeinsam genutzten Gateway-Schlüssel derzeit `file_list_not_supported_with_shared_gateway_key` zurück
Speichere die IDs hochgeladener Dateien und rufe sie direkt ab.
</Note>
