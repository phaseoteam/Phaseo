Validiere die Ausgabe, wenn nachgelagerter Ruby-Code eine vorhersehbare Ergebnisstruktur benötigt. Modellwiederholungen decken vorübergehende Request-Fehler ab; Wiederholungen von Tools mit Seiteneffekten müssen explizit und idempotent sein.

## Wiederholungen konfigurieren

```ruby
agent = PhaseoAgentSdk.create_agent(
  id: "research-agent",
  model: "openai/gpt-5.4-nano",
  model_retry: PhaseoAgentSdk::ModelRetryConfig.new(
    max_retries: 3,
    base_delay_ms: 500,
    max_delay_ms: 4_000
  )
)
```

Das Ergebnis enthält den Laufdatensatz, die Schritte, Nachrichten, die normalisierte Nutzung, den Stoppgrund und die endgültige Ausgabe.

```ruby
result = agent.run(input: prompt, client: client)

puts result.output
puts result.run.status
puts result.usage[:total_tokens]
puts result.usage[:cost]
```

Nutze [Abbruchbedingungen](./agent-sdk-stop-conditions.mdx), um Budgets durchzusetzen, und [Fehler und Fehlerbehebung](./agent-sdk-observability.mdx), um das Verhalten bei behebbaren Fehlern festzulegen.
