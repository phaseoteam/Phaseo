**Methoden**: `client.generate_image_edit(...)` oder `client.create_image_edit(...)`.

### Beispiel
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
edited = client.generate_image_edit(
  model: 'openai/gpt-image-1',
  prompt: 'Make it sunset',
  image: 'data:image/png;base64,...',
  mask: 'data:image/png;base64,...'
)
```

### Wichtige Parameter
- `model` (erforderlich): ID eines bildbearbeitungsfähigen Modells.
- `image` (erforderlich): Base64-Daten-URL oder URL des Ausgangsbilds.
- `prompt`: optionale neue Bearbeitungsanweisung.
- `mask`: optionale Maske (transparente Bereiche werden bearbeitet).
- `n` (1–10): Anzahl der bearbeiteten Varianten.
- `size`: z. B. `1024x1024`, `1024x1792` oder `1792x1024`.
- `response_format`: `url` oder `b64_json`.
- `user`: optionales Endnutzer-Tag.

### Rückgabewert
`ImageGenerationResponse`
