---

**Methode**: `client.generateModeration()`.

### Beispiel
```typescript
const moderation = await client.generateModeration({
  model: "openai/omni-moderation-latest",
  input: "Text to classify",
});
```

### Wichtige Parameter
- `model` (erforderlich): ID des Moderationsmodells (z. B. `openai/omni-moderation-latest`).
- `input` (erforderlich): Zeichenfolge oder Array mit Inhaltselementen (Text oder `image_url`).
- Optional: `categories`-/`severity`-Filter (sofern unterstützt) und `user`-Tag.
