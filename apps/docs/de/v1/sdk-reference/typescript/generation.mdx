**Methode**: `client.getGeneration()`.

### Beispiel
```typescript
const record = await client.getGeneration("G-01ABC...");
```

### Parameter
- `id` (Zeichenfolge, erforderlich): Request-ID aus einem vorherigen Aufruf.

### Rückgabe
Generierungsdatensatz (JSON)

Wenn das Gateway alle Request-Details gespeichert hat, enthält der zurückgegebene Datensatz `replay_supported` und `replay_request`. Du kannst `replay_request` für eine kontrollierte Wiederholung an den ursprünglichen Endpunkt senden.

Zeitfelder folgen der einheitlichen Gateway-Semantik:

- `latency_ms`: Zeit bis zum ersten Token oder zum ersten Ausgabe-Byte/Frame, sofern erfasst
- `generation_ms`: Generierungszeit nach der Latenz, sofern erfasst
