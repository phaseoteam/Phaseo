Das Agent SDK wird als [`@phaseo/agent-sdk`](https://www.npmjs.com/package/@phaseo/agent-sdk) auf npm veröffentlicht.

## Voraussetzungen

- ein TypeScript- oder JavaScript-Projekt mit npm, pnpm, Yarn oder Bun
- ein Phaseo-API-Schlüssel

## Installation

Installiere das Agent SDK mit deinem bevorzugten Paketmanager:

<CodeGroup>

    ```bash title="npm"
    npm install @phaseo/agent-sdk
    ```

    ```bash title="pnpm"
    pnpm add @phaseo/agent-sdk
    ```

    ```bash title="yarn"
    yarn add @phaseo/agent-sdk
    ```

    ```bash title="bun"
    bun add @phaseo/agent-sdk
    ```

</CodeGroup>

Das Kernpaket `@phaseo/sdk` wird automatisch als Abhängigkeit installiert.

## Umgebung

Lege vor dem Ausführen der Beispiele deinen Gateway-API-Schlüssel fest:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
