Wähle das kleinste Beispiel, das zu deinem Produkt passt. Bei jedem Muster bleiben Persistenz und Benutzeroberfläche in deiner Anwendung; Phaseo übernimmt die Modellrunden.

## Beispiele im Paket

| Beispiel | Zweck |
| --- | --- |
| `research-brief-agent.ts` | Recherche mit verwalteter Suche und einer typisierten Abschlusszusammenfassung |
| `support-triage-agent.ts` | Supportanfragen mit einem verwalteten Preset weiterleiten und klassifizieren |
| `coding-review-agent.ts` | Code mit lokalen Laufzeit-Tools prüfen |
| `parallel-tool-agent.ts` | Unabhängige lokale Tools parallel ausführen |
