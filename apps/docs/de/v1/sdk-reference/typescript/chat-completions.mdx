title: "Chat-Vervollständigungen"
description: "Rufe /chat/completions mit dem TypeScript-SDK auf."
---

**Methode**: `client.generateText()` (übertrage verarbeitete Chunks mit `client.streamChat()`).

### Beispiel
```typescript
const chat = await client.generateText({
  model: "openai/gpt-4o-mini",
  messages: [
    { role: "system", content: "You are helpful." },
    { role: "user", content: "Write a limerick about lighthouses." },
  ],
  temperature: 0.5,
});
```

### Datenstrom
```typescript
for await (const chunk of client.streamChat({
  model: "openai/gpt-4o-mini",
  messages: [{ role: "user", content: "Stream a story" }],
})) {
  if (chunk.text) process.stdout.write(chunk.text);
}
```

### Wichtige Parameter
- `model` (erforderlich): ID des Zielmodells.
- `messages` (erforderlich): Geordnete Nachrichten mit den Rollen `system|user|assistant|tool`; der Inhalt kann aus Zeichenfolgen oder mehreren Teilen bestehen.
- Stichprobenparameter: `temperature` (0–2), `top_p` (0–1), `top_k` (>=1), `seed` (int, optional).
- Länge/Strafen: `max_output_tokens` (int), `presence_penalty` and `frequency_penalty` (-2 to 2), `stop` (string|string[]).
- Werkzeuge: `tools` (Definitionen), `tool_choice` (`auto`/`none`/konkretes Werkzeug), `max_tool_calls` (int), `parallel_tool_calls` (bool).
- Logprobs: `logprobs` (bool), `top_logprobs` (0–20).
- Ausgabe: `response_format` (json/text), `metadata` (object passthrough), `stream` (bool), `service_tier`.
- Zusätzliche Gateway-Optionen: `usage` (bool, um Nutzungsdaten anzufordern), `meta` (bool, um den Meta-Block einzuschließen).
