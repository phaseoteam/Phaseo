Beginne mit einem dieser Muster:

| Muster | Kombination |
| --- | --- |
| Support-Triage | verwaltetes Preset, Suchtools, strukturierte Endausgabe |
| Code-Review | Datei- oder Patch-Tools, Fortschrittsereignisse, Genehmigung vor Änderungen |
| Recherche-Briefing | verwaltete Webtools, Kosten- und Schrittgrenzen, gestreamter Text |
| Betriebs-Runbook | Status-Tools, manuelle Eskalation, dauerhafte Fortsetzung |

Halte die erste Implementierung schlank: ein Agent, ein oder zwei deterministische Tools und ausdrückliche Genehmigung für Seiteneffekte.
