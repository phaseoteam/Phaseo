Der aktuelle Quellcode enthält Wiederholungssteuerung und Antwortmetadaten, die im älteren Maven-Central-Artefakt 3.0.0 fehlen. Baue die angegebene Revision, um das aktuelle SDK zu nutzen.

## Voraussetzungen

- Java 17+
- Maven 3.8+
- Git

## Aus dem Quellcode bauen

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
git checkout 1ff1119f41ceb3ac2c85ed605f6e1c4beca6e011
mvn -f packages/sdk/sdk-java/pom.xml -DskipTests install
```

Maven installiert `app.phaseo:phaseo-sdk:3.0.0` einschließlich Jackson-Abhängigkeit im lokalen Repository.

## Abhängigkeit hinzufügen

```xml
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-sdk</artifactId>
  <version>3.0.0</version>
</dependency>
```

<Note>Das [Maven-Central-Artefakt](https://repo.maven.apache.org/maven2/app/phaseo/phaseo-sdk/3.0.0/) stellt die ältere API bereit. Die aktuellen APIs für Wiederholungen, Metadaten und Parameterprüfung fehlen darin.</Note>
