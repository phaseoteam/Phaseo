Sende Anfragen für Text, Embeddings und Modellabfragen mit dem Java-SDK.

<Note>Der aktuelle Quellcode enthält Wiederholungssteuerung und Antwortmetadaten, die im älteren Maven-Central-Artefakt 3.0.0 fehlen. Baue die angegebene Revision, um das aktuelle SDK zu nutzen. [Installation](./installation)</Note>

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

## Unterstützte Anfragen

Nutze `createResponse`, `createChatCompletion`, `createEmbedding` und `listModels` für JSON-Anfragen. Übergib eine `Map` oder einen `JsonNode`; parse JSON-Zeichenfolgen vor dem Aufruf der Clientmethoden.

## Streaming

`streamResponse` und `rawClient().requestLines` geben SSE-Zeilen sofort nach ihrem Eintreffen zurück. Schließe den Stream mit try-with-resources und verarbeite Ereignisnamen, Datenzeilen und Abschlussmarkierungen in deiner Anwendung.

<Note>Die Methode `createSpeech` erwartet JSON und kann binäre Audiodaten nicht dekodieren. Nutze `rawClient().requestBytes` für die Audioausgabe.</Note>
