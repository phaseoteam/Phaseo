```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

Nutze `createResponse`, `createChatCompletion`, `createEmbedding` und `listModels` für JSON-Anfragen. Übergib eine `Map` oder einen `JsonNode`; parse JSON-Zeichenfolgen vor dem Aufruf der Clientmethoden.

## Wiederholungen und Fehler

Standardmäßig sind Wiederholungen deaktiviert. `setMaxRetries` wiederholt sichere GET/HEAD-Anfragen; Schreibzugriffe und Streaming-Anfragen werden nicht erneut gesendet. HTTP-Fehler liefern Status, Antworttext, Header und Anfrage-ID über `Client.ApiException`.

```java
import app.phaseo.gen.Client;
import app.phaseo.sdk.Phaseo;
import java.time.Duration;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"))
    .setTimeout(Duration.ofSeconds(30))
    .setMaxRetries(2);

try {
    var result = client.requestWithResponse("GET", "/models",
        Map.of("limit", "5"), null, null, null);
    System.out.println(result.requestId());
    System.out.println(result.data);
} catch (Client.ApiException error) {
    System.err.println(error.getStatusCode());
    System.err.println(error.getRequestId());
    System.err.println(error.getResponseBody());
}
```

## Streaming

`streamResponse` und `rawClient().requestLines` geben SSE-Zeilen sofort nach ihrem Eintreffen zurück. Schließe den Stream mit try-with-resources und verarbeite Ereignisnamen, Datenzeilen und Abschlussmarkierungen in deiner Anwendung.

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));
try (var lines = client.streamResponse(Map.of(
    "model", "openai/gpt-6-astra", "input", "Hello"
))) {
    lines.forEach(System.out::println);
}
```
