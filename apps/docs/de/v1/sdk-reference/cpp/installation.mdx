<Note type="warning">Das C++-SDK befindet sich in Arbeit und ist noch nicht in einer Paket-Registry veröffentlicht.</Note>

## Lokale Verwendung

Das SDK besteht nur aus Headern und nutzt C++17. Füge `packages/sdk/sdk-cpp` zu deinem CMake-Build hinzu und linke das Interface-Target, oder nimm `packages/sdk/sdk-cpp/src` in deinen Include-Pfad auf:

```cmake
add_subdirectory(path/to/Phaseo/packages/sdk/sdk-cpp)
target_link_libraries(your_app PRIVATE phaseo::sdk)
```

Binde dann `phaseo.hpp` ein, das den generierten Client in `src/gen` einbezieht.
