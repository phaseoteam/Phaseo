<Note type="warning">Das C++-SDK befindet sich in Arbeit und wurde noch nicht in einer Paketregistrierung veröffentlicht.</Note>

## Lokale Verwendung

- Verwende die generierten Header unter `packages/sdk/sdk-cpp/src/gen`.
- Füge diesen Ordner zum Include-Pfad deines Buildsystems hinzu.
- Der Client besteht derzeit nur aus Headern.
