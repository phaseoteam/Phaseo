<Note type="warning">
  Das C++-SDK befindet sich in Arbeit und ist noch nicht über einen Paketmanager verfügbar. Verwende die Quellcode-Header nur zur Evaluierung.
</Note>

Das C++-SDK ist eine Sammlung reiner C++17-Header-Quellen in `packages/sdk/sdk-cpp`; es ist nicht veröffentlicht und von SDK-Releases ausgeschlossen, bis es durchgängig funktioniert.

| Datei | Inhalt |
| --- | --- |
| `src/gen/client.hpp`, `src/gen/operations.hpp`, `src/gen/models.hpp`, `src/gen/model_ids.hpp` | Der generierte Client |
| `src/phaseo.hpp` | `GetModelEndpointCapabilities(...)` für aktuelle Modellfähigkeiten und `CheckParameterSupport(...)` für Berichte zur Parameterunterstützung |
| `src/workflows.hpp` | Helfer für Paginierung und das Abfragen von Jobs |

Der Vorschau-Transport gibt rohes JSON zurück; deserialisiere die Antwort daher vor der Prüfung in `ModelEndpointCapabilities`. Zum Ausprobieren siehe [Installation](./installation). Ein C++-Agent-SDK gibt es nicht.
