Das Agent-SDK wird auf NuGet als [`Phaseo.AgentSdk`](https://www.nuget.org/packages/Phaseo.AgentSdk) veröffentlicht.

## Voraussetzungen

- .NET 8 oder höher
- ein Phaseo-API-Schlüssel

## Installationation

```bash
dotnet add package Phaseo.AgentSdk
```

Das Kernpaket `Phaseo.Sdk` wird automatisch als Abhängigkeit installiert.

## Umgebung

Setze deinen Gateway-API-Schlüssel, bevor du Beispiele ausführst:

```bash
set PHASEO_API_KEY=phaseo_v1_sk_...
```
