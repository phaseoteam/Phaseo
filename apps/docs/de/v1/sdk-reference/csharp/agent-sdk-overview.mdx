Das C# Agent SDK ist eine vollständige lokale Agent-Runtime für das Phaseo Gateway. Sie umfasst Wiederholungen, parallele Aufgaben, Abbruch und Timeouts, menschliche Prüfung, fortsetzbaren Zustand, Lifecycle-Ereignisse und DevTools-Aufzeichnung.

Verwende es, wenn du Folgendes benötigst:

- eine schlanke, begrenzte Tool-Schleife
- Gateway-gestützte `responses`-Anfragen
- anwendungseigene Kontrolle über Speicherung und Orchestrierung

## Enthaltene Funktionen

- `AgentSdk.CreateAgent(...)`
- `AgentSdk.DefineTool(...)`
- `AgentSdk.CreateGatewayAgentClient(...)`
- eine begrenzte Tool-Schleife über die Phaseo-`responses`-API
