Kombiniere Stopp-Hilfsfunktionen in `AgentDefinition.StopWhen`:

```csharp
StopWhen = new[]
{
    AgentSdk.StepCountIs(12),
    AgentSdk.MaxTokensUsed(40_000),
    AgentSdk.MaxCost(2),
    AgentSdk.MaxDuration(TimeSpan.FromMinutes(1)),
};
```

`HasToolCall(...)` und `FinishReasonIs(...)` provide event-based limits. Lege auch bei Token- oder Kostenlimits eine Schritt- oder Zeitgrenze fest, da diese von gemeldeten Nutzungsdaten abhängen.
