---

`Agent.Stream(...)` verwendet dieselbe Zustandsmaschine wie `Run(...)` und gibt `AgentStreamResult` zurück:

```csharp
var stream = agent.Stream(new RunOptions { Input = input, Client = client });

await foreach (var delta in stream.TextStream())
{
    Console.Write(delta);
}

var completed = await stream.GetResult();
```

Verwende `FullStream()` für Modell-, Tool-, Schritt- und Laufereignisse. Consumer können die aufgezeichnete asynchrone Sequenz unabhängig erneut durchlaufen. Rufe `Cancel()` auf, wenn das Produkt den aktiven Lauf stoppen soll; die Abbruchanforderung wird an Modellanfragen und lokale Tools weitergegeben.
