Das SDK wird als [`Phaseo.Sdk`](https://www.nuget.org/packages/Phaseo.Sdk) auf NuGet.

## Voraussetzungen

- .NET 8 oder neuer

## Installation

```bash
dotnet add package Phaseo.Sdk
```
