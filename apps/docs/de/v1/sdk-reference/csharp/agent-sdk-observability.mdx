Ein fehlgeschlagenes `RunResult` enthält weiterhin den aktiven Schritt, die Anzahl der Wiederholungen, die Anfragen-ID, die native Response-ID, Provider-Metadaten und verfügbare Gateway-Details.

Prüfe zuerst Folgendes:

- der Prozess auf `PHASEO_API_KEY` zugreifen kann
- Tool-IDs eindeutig und stabil sind
- Genehmigungsentscheidungen die exakten Tool-Aufruf-IDs verwenden
- der pausierte Zustand gespeichert wird, bevor die Anfrage verlassen wird
- Validatoren keine Seiteneffekte auslösen
- Abbruchtokens die Abhängigkeiten erreichen, die Tools verwenden

Verwende Lifecycle-Hooks für Anwendungstelemetrie und DevTools zur lokalen Laufinspektion.
