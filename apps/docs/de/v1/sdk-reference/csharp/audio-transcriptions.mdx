title: "STT (Sprache-zu-Text)"
description: "Rufe /audio/transcriptions mit dem C#-SDK auf."
---

**Methode**: `client.CreateTranscription(...)`

### Beispiel
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.CreateTranscription(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-4o-transcribe",
    ["audio_b64"] = "base64-audio",
    ["language"] = "en"
});
```

### Wichtige Parameter
- `model` (erforderlich): ID eines transkriptionsfähigen Modells.
- `file` (erforderlich): Audiodaten (Stream oder Datei).
- `language`: Hinweis auf die Sprache (z. B. `en`).
- `prompt`: optionaler Kontext zur Verbesserung der Genauigkeit.
- `temperature` (0–2): Zufälligkeit der Stichprobenauswahl.
- `response_format`: `json`, `text`, `srt`, `verbose_json` usw.

### Rückgabewert
`AudioTranscriptionResponse`
