title: "Modelle"
description: "Liste Modelle mit dem C#-SDK auf."
---

**Methode**: `client.ListModels(...)`

### Beispiel
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var models = await client.ListModels(new Dictionary<string, string>
{
    ["provider"] = "anthropic",
    ["provider_status"] = "beta,not_ready",
    ["provider_availability_reason"] = "preview_only,provider_not_ready",
    ["capability_status"] = "coming_soon,internal_testing",
    ["availability"] = "all",
    ["limit"] = "10"
});
```

### Parameter
- Optionale Filter: `provider`, `provider_status`, `provider_routing_status`, `model_routing_status`, `capability_status`, `provider_availability_status`, `provider_availability_reason`, `status`, `organisation`, `endpoints`, `input_types`, `output_types`, `params`, `availability`, `limit`, `offset`.
- `provider_availability_reason` ist mit `availability = "all"` nützlich, wenn du Rollout-Status wie `preview_only`, `provider_not_ready`, `gated`, `access_limited`, `region_limited`, `project_limited`, `paused` oder `soft_blocked` sehen möchtest.
- `capability_status` ist mit `availability = "all"` nützlich, wenn du nicht routbare Endpunktzuordnungen wie `coming_soon` oder `internal_testing` sehen möchtest.
