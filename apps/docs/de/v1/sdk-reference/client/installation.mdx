Füge das Phaseo-Paket für deine Sprache hinzu, setze `PHASEO_API_KEY` und sende deine erste Anfrage. Die [Übersicht](./overview) listet für jedes Paket die Registry und die veröffentlichte Version auf.

<Steps>
<Step title="Paket installieren">

<Tabs>
<Tab title="TypeScript">

<CodeGroup>

```bash title="npm"
npm install @phaseo/sdk
```

```bash title="pnpm"
pnpm add @phaseo/sdk
```

```bash title="yarn"
yarn add @phaseo/sdk
```

</CodeGroup>

Du brauchst Node.js 18 oder neuer und für die Typdefinitionen TypeScript 4.5 oder neuer.

</Tab>
<Tab title="Python">

<CodeGroup>

```bash title="pip"
pip install phaseo
```

```bash title="uv"
uv add phaseo
```

</CodeGroup>

Du brauchst Python 3.10 oder neuer. Für [Echtzeit-Sprache](./audio-realtime) installierst du das Extra: `pip install "phaseo[realtime]"`.

</Tab>
<Tab title="Go">

```bash
go get github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3@latest
```

Du brauchst Go 1.23 oder neuer. Importiere den Modulpfad `v3`:

```go
import phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
```

</Tab>
<Tab title="C#">

```bash
dotnet add package Phaseo.Sdk
```

Du brauchst .NET 8 oder neuer. Der Client liegt im Namespace `PhaseoSdk`.

</Tab>
<Tab title="PHP">

```bash
composer require phaseo/sdk
```

Du brauchst PHP 8.1 oder neuer und Composer. Composer installiert außerdem Guzzle 7. Die Client-Klasse ist `Phaseo\Sdk\Phaseo`.

</Tab>
<Tab title="Ruby">

<CodeGroup>

```bash title="gem"
gem install phaseo_sdk
```

```ruby title="Gemfile"
gem "phaseo_sdk"
```

</CodeGroup>

Du brauchst Ruby 3.0 oder neuer. Lade das Gem mit `require 'phaseo_sdk'`; der Client ist `PhaseoSdk::Phaseo`.

</Tab>
<Tab title="Java">

Das Artefakt `3.0.0` auf [Maven Central](https://repo.maven.apache.org/maven2/app/phaseo/phaseo-sdk/3.0.0/) enthält die ältere API, ohne die aktuellen APIs für Wiederholungen, Antwort-Metadaten und Parameterprüfung. Um das aktuelle SDK zu verwenden, baust du den festgelegten Quellstand. Du brauchst Java 17 oder neuer, Maven 3.8 oder neuer und Git.

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
git checkout 1ff1119f41ceb3ac2c85ed605f6e1c4beca6e011
mvn -f packages/sdk/sdk-java/pom.xml -DskipTests install
```

Maven installiert `app.phaseo:phaseo-sdk:3.0.0` einschließlich der Jackson-Abhängigkeit in dein lokales Repository. Füge dann die Abhängigkeit hinzu:

```xml
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-sdk</artifactId>
  <version>3.0.0</version>
</dependency>
```

</Tab>
<Tab title="Rust">

<CodeGroup>

```toml title="Cargo.toml"
[dependencies]
phaseo = "0.2"
serde_json = "1"
```

```bash title="cargo"
cargo add phaseo@0.2 serde_json
```

</CodeGroup>

Du brauchst Rust 1.86 oder neuer. Das Crate ist noch vor `1.0`, und seine API kann sich zwischen Minor-Versionen noch ändern. Lege in der Produktion deshalb eine kompatible Minor-Version fest.

</Tab>
</Tabs>

</Step>
<Step title="API-Schlüssel festlegen">

Erstelle einen Schlüssel unter [API-Schlüssel](https://phaseo.app/settings/keys) und exportiere ihn dann:

<CodeGroup>

```bash title="bash"
export PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
```

```powershell title="PowerShell"
$env:PHASEO_API_KEY = "phaseo_v1_sk_<kid>_<secret>"
```

</CodeGroup>

Behalte den Schlüssel auf deinem Server. Kompiliere ihn nicht in eine Desktop-, Mobil- oder Browser-App oder einen anderen verteilten Client.

</Step>
<Step title="Anfrage senden">

<CodeGroup>

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY!,
});

const response = await client.generateText({
  model: "openai/gpt-6-astra",
  messages: [{ role: "user", content: "Hello!" }],
});

console.log(response.choices[0].message.content);
```

```python Python
from phaseo import Phaseo
import os

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])

response = client.generate_text(
    {
        "model": "openai/gpt-6-astra",
        "messages": [{"role": "user", "content": "Hello!"}],
    }
)

print(response["choices"][0]["message"]["content"])
```

```go Go
client, err := phaseo.NewFromEnv() // liest PHASEO_API_KEY
if err != nil {
  panic(err)
}

chat, err := client.GenerateText(context.Background(), phaseo.ChatCompletionsRequest{
  Model:    "openai/gpt-6-astra",
  Messages: []map[string]interface{}{{"role": "user", "content": "Hello!"}},
})
if err != nil {
  panic(err)
}
fmt.Println(chat["choices"])
```

```csharp C#
using PhaseoSdk;

var client = new Phaseo(); // liest PHASEO_API_KEY

var chat = await client.GenerateText(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-6-astra",
    ["messages"] = new[]
    {
        new Dictionary<string, object> { ["role"] = "user", ["content"] = "Hello!" },
    },
});
```

```php PHP
<?php
require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo(); // liest PHASEO_API_KEY

$chat = $client->generateText([
    'model' => 'openai/gpt-6-astra',
    'messages' => [['role' => 'user', 'content' => 'Hello!']],
]);

echo $chat['choices'][0]['message']['content'];
```

```ruby Ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new # liest PHASEO_API_KEY

chat = client.generate_text(
  model: 'openai/gpt-6-astra',
  messages: [{ role: 'user', content: 'Hello!' }]
)
```

```java Java
import app.phaseo.sdk.Phaseo;
import java.util.List;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

var chat = client.createChatCompletion(Map.of(
    "model", "openai/gpt-6-astra",
    "messages", List.of(Map.of("role", "user", "content", "Hello!"))
));
System.out.println(chat.path("choices").path(0).path("message").path("content").asText());
```

```rust Rust
use phaseo::Phaseo;
use serde_json::json;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Phaseo::from_env()?;
    let response = client.chat_completions(&json!({
        "model": "openai/gpt-6-astra",
        "messages": [{ "role": "user", "content": "Hello!" }]
    }))?;

    println!("{}", response.body);
    Ok(())
}
```

</CodeGroup>

Wenn du keinen Schlüssel übergibst, liest der Client `PHASEO_API_KEY` selbst.

## Client auf eine andere Basis-URL richten

<CodeGroup>

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({
  apiKey: "your-api-key",
  baseUrl: "https://api.phaseo.app/v1",
  timeoutMs: 30_000,
});
```

```python Python
from phaseo import Phaseo

client = Phaseo(
    api_key="your-api-key",
    base_url="https://api.phaseo.app/v1",
    timeout=30.0,
)
```

```go Go
client := phaseo.New(os.Getenv("PHASEO_API_KEY"), "https://api.phaseo.app/v1")
```

```rust Rust
let client = Phaseo::from_env()?.with_base_url("http://localhost:8787/v1")?;
```

</CodeGroup>

Das Timeout wird in TypeScript in Millisekunden (`timeoutMs`) und in Python in Sekunden (`timeout`) angegeben. In Rust kannst du außerdem `PHASEO_BASE_URL` setzen (zum Beispiel `http://localhost:8787/v1`), das `Phaseo::from_env()` übernimmt. Rust akzeptiert einfaches HTTP nur, wenn der Host genau `localhost` oder eine Loopback-IP-Adresse ist; entfernte Endpunkte müssen HTTPS verwenden.

Die [Übersicht](./overview#configure-the-client) listet alle Optionen je Sprache auf. Als Nächstes findest du unter [Verwendung](./usage) ein Beispiel pro Endpunkt oder in der [API-Referenz](../../api-reference/introduction) jedes Feld.
