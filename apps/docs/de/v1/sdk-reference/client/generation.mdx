Übergib eine Anfrage-ID (etwa `G-01ABC...`) an die Generierungsmethode des SDK, um den gespeicherten Datensatz dieser Anfrage von `GET /v1/generations?id=<id>` abzurufen.

<CodeGroup>

```typescript TypeScript
const record = await client.getGeneration("G-01ABC...");
```

```python Python
record = client.get_generation("G-01ABC...")

print(record["model_id"], record["cost_nanos"])
```

```go Go
client, err := phaseo.NewFromEnv()
if err != nil {
  panic(err)
}

record, err := client.GetGeneration(context.Background(), "G-01ABC...")
if err != nil {
  panic(err)
}
fmt.Println(record["status_code"], record["cost_nanos"])
```

```csharp C#
using PhaseoSdk;

var client = new Phaseo();
var record = await client.GetGeneration("G-01ABC...");
```

```php PHP
<?php
require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo();
$record = $client->getGeneration('G-01ABC...');
```

```ruby Ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new
record = client.get_generation('G-01ABC...')
```

```java Java
import app.phaseo.sdk.Phaseo;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

var record = client.getGeneration("G-01ABC...");
System.out.println(record);
```

</CodeGroup>

| Sprache | Methode | Rückgabe |
| --- | --- | --- |
| TypeScript | `client.getGeneration(id)` | Das Datensatzobjekt |
| Python | `client.get_generation(id)` | `APIResponse`-Dict |
| Go | `client.GetGeneration(ctx, id)` | `map[string]interface{}` |
| C# | `client.GetGeneration(id)` | `Dictionary<string, object>?` |
| PHP | `$client->getGeneration($id)` | Array |
| Ruby | `client.get_generation(id)` | Hash |
| Java | `client.getGeneration(id)` | Jackson-`JsonNode` |
| Rust | Kein Helfer; rufe `client.request("GET", "/generations?id=<id>", None, &RequestOptions::default())` auf | `PhaseoResponse`, der Datensatz steht in `body` (ein `serde_json::Value`) |

Der Abruf ist auf deinen Workspace beschränkt. Eine fehlende `id` gibt `400` (`missing_id`) zurück, eine ID, die nicht zu deinem Workspace gehört, gibt `404` (`not_found`) zurück.

## Gespeicherte Anfrage erneut ausführen

Hat das Gateway die vollständige Anfrage gespeichert, enthält der Datensatz `replay_supported` mit dem Wert true und ein `replay_request`, das du für eine kontrollierte Wiederholung an den ursprünglichen Endpunkt zurücksenden kannst.

## Zeitfelder auslesen

- `latency_ms`: Zeit bis zum ersten Token oder zum ersten Ausgabe-Byte bzw. -Frame, sofern erfasst.
- `generation_ms`: Generierungszeit ab diesem Punkt, sofern erfasst.
