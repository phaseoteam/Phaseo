Rufe die Bildmethode des SDK mit einem Modell und einem Prompt auf, um `POST /v1/images/generations` zu senden. Jedes generierte Bild kommt als Eintrag `url` oder `b64_json` in `data` zurück.

<CodeGroup>

```typescript TypeScript
const image = await client.generateImage({
  model: "openai/gpt-image-1",
  prompt: "A lighthouse at golden hour",
  size: "1024x1024",
  n: 1,
});
```

```python Python
image = client.generate_image({
    "model": "openai/gpt-image-1",
    "prompt": "A lighthouse at golden hour",
    "size": "1024x1024",
    "n": 1,
})
```


</CodeGroup>

| Sprache | Methode | Hinweise |
| --- | --- | --- |
| TypeScript | `client.generateImage(request)` | `client.streamImage()` sendet dieselbe Anfrage mit `stream: true` und liefert Events mit Teilbildern. |
| Python | `client.generate_image(request)` | `client.images.generate(request)` macht dasselbe. Kein Helfer für Bild-Streaming. |
| Go | `client.CreateImage(ctx, req)` | Gibt eine `map[string]interface{}` zurück. |
| C# | `client.GenerateImage(request)`, Alias `CreateImage` | Gibt ein `Dictionary<string, object>?` zurück. |
| PHP | `$client->generateImage($request)`, Alias `createImage()` | Gibt ein Array zurück. |
| Ruby | `client.generate_image(...)`, Alias `create_image` | Gibt einen Hash zurück. |
| Java | `client.createImage(request)` | Nimmt eine `Map` oder einen Jackson-`JsonNode` entgegen und gibt einen `JsonNode` zurück. |
| Rust | Kein Bild-Helfer | `client.post("/images/generations", &request)` sendet den JSON-Body und gibt eine `PhaseoResponse` zurück. |

## Parameter

Die Feldnamen sind in jedem SDK die Felder des JSON-Bodys.

| Feld | Hinweise |
| --- | --- |
| `model`, `prompt` | Erforderlich. Prompts für GPT Image können bis zu 32.000 Zeichen lang sein. |
| `n` | Anzahl der Bilder, `1` bis `10`. |
| `size` | Zum Beispiel `1024x1024`, `1024x1792` oder `1792x1024`; die unterstützten Größen hängen vom Modell ab. |
| `aspect_ratio`, `width`, `height` | Modellabhängige Alternativen zu `size`. |
| `quality` | Modellabhängig: `standard` oder `hd` bei `dall-e-3`; `auto`, `low`, `medium` oder `high` bei GPT-Image-Modellen. |
| `output_format`, `output_compression` | `png`, `jpeg` oder `webp`; Kompression (`0` bis `100`) erfordert `jpeg` oder `webp`. |
| `background` | `transparent`, `opaque` oder `auto`. Transparent erfordert `png` oder `webp`. |
| `response_format` | `url` oder `b64_json`. GPT-Image-Modelle lehnen dieses Feld ab. |
| `style` | Modellabhängig, etwa `vivid` oder `natural` bei `dall-e-3`. GPT-Image-Modelle lehnen dieses Feld ab. |
| `stream`, `partial_images` | Streamt bis zu `3` Teilbilder, in TypeScript mit `streamImage()`. |
| `user` | Kennung des Endnutzers zur Missbrauchsverfolgung. |

Das vollständige Schema steht in der [API-Referenz zur Bildgenerierung](../../api-reference/endpoint/images-generations).

## Antwort

`ImagesGenerationResponse`:

```json
{
  "data": [
    {
      "url": "https://example.com/generated_image.png"
    }
  ]
}
```

Modelle, die Bildbytes zurückgeben, legen sie statt in `url` in `b64_json` ab.
