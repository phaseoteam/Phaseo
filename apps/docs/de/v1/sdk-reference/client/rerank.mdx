Rufe `client.rerank.create()` auf, um Kandidatendokumente mit `POST /v1/rerank` nach ihrer Relevanz für eine Suchanfrage zu ordnen. Die Methode heißt in TypeScript und Python gleich; Rust sendet dasselbe JSON mit `client.post()`.

<CodeGroup>

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const result = await client.rerank.create({
  model: "voyage/rerank-2",
  query: "How do I check whether a model is routable?",
  documents: [
    "Call GET /v1/models and use the default availability filter.",
    "Create an image with POST /v1/images/generations.",
  ],
});

console.log(result.results);
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # liest PHASEO_API_KEY

result = client.rerank.create({
    "model": "voyage/rerank-2",
    "query": "How do I check whether a model is routable?",
    "documents": [
        "Call GET /v1/models and use the default availability filter.",
        "Create an image with POST /v1/images/generations.",
    ],
})

print(result["results"])
```

```rust Rust
// Noch keine Rerank-Methode: post() sendet JSON an jeden Phaseo-Pfad.
use phaseo::Phaseo;
use serde_json::json;

let client = Phaseo::from_env()?; // liest PHASEO_API_KEY

let result = client.post("/rerank", &json!({
    "model": "voyage/rerank-2",
    "query": "How do I check whether a model is routable?",
    "documents": [
        "Call GET /v1/models and use the default availability filter.",
        "Create an image with POST /v1/images/generations."
    ]
}))?;

println!("{}", result.body["results"]);
```

</CodeGroup>

**Python:** `client.rerank.create()` sendet das übergebene Dict als JSON-Body und gibt die JSON-Antwort zurück; es gibt keinen typisierten Helfer `generate_rerank`. Auf `AsyncPhaseo` verwendest du `await`.

Die SDKs für Go, C#, PHP, Ruby und Java haben keine Rerank-Methode. Sende `POST /v1/rerank` mit deinem HTTP-Client, wie in der [Rerank-API-Referenz](/de/v1/api-reference/endpoint/rerank) gezeigt.

Prüfe die Modell-ID mit `GET /v1/models`, bevor du sie in der Produktion verwendest.

## Parameter

Die Feldnamen sind in jedem SDK die Felder des JSON-Bodys.

| Feld | Hinweise |
| --- | --- |
| `model`, `query`, `documents` | Erforderlich. `documents` enthält mindestens einen String oder ein Objekt. |
| `top_n` | Gibt nur die besten `n` Ergebnisse zurück. `top_k` wird als Alias akzeptiert. |
| `return_documents` | Nimmt jedes Dokument in sein Ergebnis auf. |
| `rank_fields` | Bei Objektdokumenten die Felder, nach denen gerankt wird. |
| `max_chunks_per_doc`, `max_tokens_per_doc` | Limits für lange Dokumente, bei Anbietern, die sie unterstützen. |

## Antwort

`RerankResponse` enthält `results`, jeweils mit dem `index` des Dokuments in deiner Liste, seinem `relevance_score` und, wenn `return_documents` gesetzt ist, dem `document`, dazu `usage`.
