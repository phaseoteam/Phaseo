# Migrationsassistent

Wenn Sie eine auf Ihre Integration zugeschnittene Migrations-Checkliste benötigen, verwenden Sie den interaktiven Assistenten.

- **Wählen Sie Ihren aktuellen Anbieter oder Ihr SDK**
- **Wählen Sie Ihre Umgebung**
- **Erhalten Sie die genauen Konfigurationsänderungen und den passenden Code**

[Migrationsassistent öffnen](https://phaseo.app/migrate)
