# Migrationsassistent

Wenn du eine auf deine Integration zugeschnittene Migrations-Checkliste benötigst, verwende den interaktiven Assistenten.

- **Wähle deinen aktuellen Anbieter oder dein SDK**
- **Wähle deine Umgebung**
- **Erhalte die genauen Konfigurationsänderungen und den passenden Code**
