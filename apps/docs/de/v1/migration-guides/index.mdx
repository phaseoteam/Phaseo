# Migrationsleitfäden

Die Phaseo-Migrationsleitfäden behandeln zwei Arten von Änderungen:

- den Wechsel von einer anderen Plattform oder einem anderen Gateway zu Phaseo
- die Einführung einer Modellversion auf derselben Plattform

## Modellmigrationen

Nutzen Sie diese Leitfäden, wenn die Integration weitgehend gleich bleibt, sich aber das verwendete Modell ändert.

Sie behandeln:

- Änderungen an Anfrageparametern
- Unterschiede im Verhalten von Prompts und Reasoning
- Unterschiede bei strukturierten Ausgaben und Tool-Aufrufen
- Strategien für schrittweise Einführung, Fallbacks und Rollback

## Diese Leitfäden verwenden

1. Ermitteln Sie, ob Sie die Plattform, das Modell oder beides wechseln.
2. Beginnen Sie mit dem Leitfaden für den riskantesten Teil der Migration.
3. Prüfen Sie Anfrageparameter und Endpoint-Verhalten, bevor Sie die Antwortqualität vergleichen.
4. Führen Sie produktionsnahe Auswertungen durch, bevor Sie Live-Traffic umstellen.
