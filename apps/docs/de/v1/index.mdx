Nutze diese Seite, wenn du weißt, was du bauen möchtest, aber noch nicht, welche Phaseo-Dokumentation du zuerst öffnen sollst.

Phaseo bietet eine API für den Modellzugriff, das Routing über Anbieter, Preise, Nutzungsübersicht und asynchrone KI-Abläufe.

Wenn du neu bei Phaseo bist, beginne mit einer erfolgreichen Anfrage. Wenn du bereits eine KI-Integration hast, wechsle direkt zur passenden Migrations- oder SDK-Anleitung.

## Deine erste erfolgreiche Anfrage

Für eine neue Integration gehst du so vor:

1. Erstelle im Dashboard einen API-Schlüssel.
2. Sende eine Anfrage an ein aktuelles Textmodell.
3. Lies den generierten Text aus der Antwort aus.
4. Fahre mit der passenden Anleitung zu SDK, Routing oder Produktivbetrieb fort.

## Erste Anfrage

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-sol",
    "input": "Reply with: docs ready",
    "temperature": 0
  }'
```

```typescript TypeScript SDK
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-5.6-sol",
  input: "Reply with: docs ready",
  temperature: 0,
});

console.log(response.output_text);
```

```python Python SDK
from phaseo import Phaseo

client = Phaseo(api_key="YOUR_API_KEY")

response = client.generate_response(
    {
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with: docs ready",
        "temperature": 0,
    }
)

print(response.get("output_text"))
```
</CodeGroup>

Wenn das funktioniert, geht es mit dem [Schnellstart](./quickstart.mdx) weiter, der dich durch die vollständige erste Anfrage führt.
