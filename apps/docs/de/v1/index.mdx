Nutze Phaseo, um Modelle mehrerer Anbieter über eine API aufzurufen, Routing zu steuern und Nutzung sowie Kosten zu verfolgen.

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "phaseo/free", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // reads PHASEO_API_KEY

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # reads PHASEO_API_KEY

response = client.responses.create({"model": "phaseo/free", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

Noch kein API-Schlüssel? Führe `phaseo keys create` mit der [Phaseo CLI](./guides/integrations/phaseo-cli) aus oder [erstelle einen im Dashboard](https://phaseo.app/de-DE/settings/keys) und folge dann dem [Schnellstart](./quickstart.mdx).
