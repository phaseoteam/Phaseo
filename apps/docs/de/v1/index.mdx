Rufe Modelle vieler Anbieter über eine API unter `https://api.phaseo.app/v1` auf, lege fest, wie jede Anfrage geroutet wird, und verfolge Nutzung und Kosten pro Anfrage. Diese Anfrage nutzt `phaseo/free` und funktioniert daher schon, bevor du Guthaben aufgeladen hast:

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "phaseo/free", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // reads PHASEO_API_KEY

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # reads PHASEO_API_KEY

response = client.responses.create({"model": "phaseo/free", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

Noch kein API-Schlüssel? [Erstelle einen im Dashboard](https://phaseo.app/settings/keys) und folge dann dem [Schnellstart](./quickstart.mdx).

## Modell wählen

[Durchsuche Modelle](https://phaseo.app/models) oder [vergleiche sie](https://phaseo.app/compare). Der Katalog listet auch Modelle, die du noch nicht aufrufen kannst. Prüfe daher vor der Integration, ob ein Modell **Auf Gateway aktiv** ist, oder liste aufrufbare Modelle mit `GET /v1/models` auf. Unter [So funktioniert Phaseo](./developers/introduction.mdx) findest du mehr zu Modellen, Anbietern und Abrechnung.
