Öffnen Sie ein GitHub-Issue, um ein Modell zu korrigieren oder einen fehlenden Eintrag anzufordern. Sie müssen weder JSON bearbeiten noch das Repository einrichten.

## Korrektur melden

1. Kopieren Sie die URL der Phaseo-Seite des Modells oder die Modell-ID.
2. [Melden Sie falsche Informationen](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) und beschreiben Sie den aktuellen Wert und die vorgeschlagene Korrektur.
3. Fügen Sie offizielle Dokumentation, eine Veröffentlichungsankündigung oder eine andere überprüfbare Quelle hinzu.

Geben Sie bei Preisen Anbieter, Währung, Abrechnungseinheit, betreffende Stufe und Gültigkeitsdatum an. Für Benchmark-Ergebnisse folgen Sie [Ergebnisse einreichen](../research/submitting-scores.mdx).

## Fehlendes Modell anfordern

[Öffnen Sie eine Datenanfrage](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) mit Modellname, Organisation, offiziellem Link, Veröffentlichungsdatum und bekannten Funktionen. Ein Modell kann im Katalog erscheinen, bevor eine unterstützte Gateway-Route verfügbar ist.

## Nach dem Einreichen

Die Verantwortlichen prüfen die Belege und aktualisieren die Datenbank über den internen Editor. Verfolgen Sie Fragen und die Veröffentlichung im Issue. Tägliche JSON-Snapshots exportieren den Katalog; Änderungen an archivierten JSON-Dateien aktualisieren die Live-Website nicht.

Administratoren können Datensätze unter [Interne Daten](https://phaseo.app/internal/data) bearbeiten und vorgeschlagene Preise unter [Anbieteraktualisierungen](https://phaseo.app/internal/data/imports) prüfen. Diese Seiten erfordern Administratorzugriff.
