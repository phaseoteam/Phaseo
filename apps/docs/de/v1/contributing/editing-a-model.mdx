Modelldaten liegen in JSON-Dateien unter `packages/data/catalog/src/data/models`. Jedes Modell hat einen eigenen Ordner mit einer Datei `model.json`.

## 1. Modell finden

Suche das Modellverzeichnis anhand von Anbieter und Modellname. Beispiel:

`packages/data/catalog/src/data/models/openai/gpt-5-2025-08-07/model.json`

## 2. Änderungen vornehmen

Häufige Änderungen sind:

- Beschreibungen und Links
- Fähigkeiten und unterstützte Endpunkte
- Preis- oder Verfügbarkeitshinweise
- Benchmark-Referenzen

Achte darauf, dass die Werte dem Schema in benachbarten Dateien entsprechen.

## 3. Daten prüfen

Führe vor dem Erstellen einer PR das Datenvalidierungsskript aus:

```bash
pnpm validate:data
```

## 4. PR erstellen

Fasse die Änderungen kurz zusammen und nenne die verwendeten Quellen.
