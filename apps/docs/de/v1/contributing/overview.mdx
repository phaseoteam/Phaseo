Phaseo ist ein **offenes, von der Community getragenes Projekt**. Es soll möglichst viele Informationen zu KI-Modellen, Benchmarks und Anbietern für alle frei zugänglich machen.

Deine Beiträge helfen dabei, die Plattform korrekt, transparent und aktuell zu halten.  
Ob du einen Tippfehler korrigierst, neue Benchmarkdaten ergänzt oder die Dokumentation verbesserst – jeder Beitrag zählt.

---

## Warum mitwirken?

KI entwickelt sich immer schneller: Neue Modelle, Aktualisierungen und Preisänderungen gibt es täglich.  
Mit deinem Beitrag hilfst du dabei:

-   Daten zu Modellen, Organisationen und Benchmarks aktuell und verlässlich halten
-   KI-Vergleiche zwischen Anbietern genauer machen
-   Forschungsergebnisse, Erkenntnisse der Community oder fehlende Metadaten teilen
-   Das offene Ökosystem für mehr Transparenz bei KI stärken
-   Sicherstellen, dass die Datenbank frei zugänglich bleibt und der Community gehört

Dein Name erscheint auch auf der [Seite der Mitwirkenden](https://phaseo.app/contribute), als Anerkennung für deine Beiträge.

## Überblick über den Beitragsablauf

1. **Forke** das [Phaseo-GitHub-Repository](https://github.com/phaseoteam/Phaseo).
2. **Erstelle einen Branch** für deine Änderungen (z. B. `fix-model-data` oder `add-new-benchmark`).
3. **Bearbeite die JSON- oder Markdown-Dateien** entsprechend der Struktur in [Repositorystruktur](./repo-structure.mdx).
4. **Teste deine Änderungen lokal**, falls sinnvoll (zum Beispiel im Next.js-Frontend).
5. **Committe und pushe** deine Änderungen.
6. **Eröffne einen Pull Request (PR)** und beschreibe, was du geändert hast und warum.

Nach Prüfung und Freigabe wird dein Beitrag übernommen und in der Phaseo-Datenbank veröffentlicht.

---

## Beitragsarten

| Typ                   | Beispiel                                                 | Schwierigkeit |
| ---------------------- | ------------------------------------------------------- | ---------- |
| **Datenkorrektur**           | Modellnamen, Anbieter oder Benchmarkwerte korrigieren. | Einfach       |
| **Neuer Eintrag**          | Ein neues Modell, einen Benchmark oder eine Organisation hinzufügen.         | Mittel   |
| **Strukturänderung**  | Datenbank- oder Schemastruktur anpassen.                    | Fortgeschritten   |
| **Funktionserweiterung**   | UI-Komponenten oder Next.js-Logik hinzufügen.                  | Fortgeschritten   |
| **Dokumentationsänderung** | Markdown-Dateien oder Anleitungen verbessern.                     | Einfach       |

Wir freuen uns über Beiträge jeder Größe und Komplexität, unabhängig davon, welche Änderung du vorschlägst.

## Richtlinien und Standards

Alle Beiträge müssen diese Standards erfüllen, damit Datenqualität und Konsistenz gewährleistet sind:

-   **Verlässliche Quellen:** Nimm nur verifizierte oder offiziell veröffentlichte Daten auf.
-   **Einheitliche Formatierung:** Achte auf korrekte Groß- und Kleinschreibung, Einrückung und Schema-Schlüssel.
-   **Versionierte Änderungen:** Formuliere Changelogs oder Commit-Nachrichten aussagekräftig.
-   **Quellenangaben:** Füge in der PR-Beschreibung Links zu den Datenquellen hinzu.
-   **Respektvolle Kommunikation:** Befolge unseren [Verhaltenskodex](../community/code-of-conduct.mdx).

## Beispiel für einen Beitragsablauf

```bash
# 1. Fork and clone the repo
git clone https://github.com/yourusername/Phaseo.git

# 2. Create a new branch
git checkout -b add-openai-new-model

# 3. Make your edits
# e.g. edit packages/data/catalog/src/data/models/openai/new-model/model.json

# 4. Stage, commit, and push
git add .
git commit -m "Added new OpenAI model with updated benchmark data"
git push origin add-openai-new-model

# 5. Open a Pull Request on GitHub
# Describe your changes and link any sources
```

## Brauchst du Hilfe?

Wenn du dir beim Beitragen unsicher bist oder vor dem Einreichen Feedback möchtest, kannst du:

-   Stelle deine Frage im [Phaseo-Discord](https://discord.gg/aQyywCvgZ5).
-   Eröffne für Fragen oder Vorschläge eine **GitHub-Diskussion**.
-   Erwähne die Maintainer in deiner PR, wenn du Unterstützung bei der Prüfung möchtest.
