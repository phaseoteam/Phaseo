Öffne für Katalogkorrekturen und Ergänzungen ein Issue mit dem betroffenen Datensatz und belegenden Quellen. Reiche für Code- oder Dokumentationsänderungen einen Pull Request im [Phaseo-Repository](https://github.com/phaseoteam/Phaseo) ein.

## Deinen Beitrag auswählen

| Änderung | Hier beginnen |
| --- | --- |
| Modellmetadaten, Funktionen, Verfügbarkeit oder Preise | [Modellaktualisierung melden](./editing-a-model.mdx) |
| Details zu Unternehmen oder Forschungsorganisationen | [Organisationsaktualisierung melden](./editing-an-organisation.mdx) |
| Benchmark-Ergebnisse | [Ergebnisse einreichen](../research/submitting-scores.mdx) |
| Andere Katalogkorrekturen | [Falsche Informationen melden](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) |
| Fehlende Anbieter oder andere Katalogdaten | [Neue Daten anfordern](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) |
| Dokumentation oder Code | [Beitragsablauf](./how-to-contribute.mdx) und [Repositorystruktur](./repo-structure.mdx) |

## So werden Katalogmeldungen veröffentlicht

Die Verantwortlichen prüfen die Belege im Issue und übernehmen genehmigte Änderungen über den nur Administratoren zugänglichen [internen Editor](https://phaseo.app/internal/data). Preisaktualisierungen von Anbietern erfordern vor der Veröffentlichung eine ausdrückliche Prüfung.

Die Datenbank ist die einzige Quelle für Katalogeinträge. Das Repository enthält keine Katalog-JSON-Dateien, daher kann ein Pull Request keinen Katalogeintrag ändern.

## Vor dem Einreichen

- Gib die betroffene Seite oder Datensatz-ID an und beschreibe die vorgeschlagene Korrektur.
- Zitiere offizielle Quellen und unterscheide gemeldete Benchmark-Ergebnisse von unabhängigen Messungen.
- Halte jede Meldung und jeden Pull Request thematisch fokussiert.
- Füge niemals Zugangsdaten oder private Kundendaten hinzu.
- Befolge den [Verhaltenskodex](../community/code-of-conduct.mdx).

Besprich größere Schema- oder Funktionsänderungen vor der Umsetzung mit den Verantwortlichen. Frage auf [Discord](https://discord.gg/aQyywCvgZ5) nach Hilfe, wenn du unsicher bist, wohin eine Änderung gehört.
