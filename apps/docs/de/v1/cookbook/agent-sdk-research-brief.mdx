Baue einen TypeScript-Agenten, der vor seiner Antwort über Phaseo im Web sucht und ein Recherche-Briefing als streng strukturiertes JSON mit seinen Quellen zurückgibt. Am Ende hast du ein Skript, das für jedes Thema, das du ihm gibst, ein validiertes `{ topic, summary, sources }`-Objekt ausgibt.

Das Skript ist für einmalige Recherchen produktionsreif. Suchergebnisse sind nicht vertrauenswürdige Webinhalte: Die Schemaprüfung unten stoppt fehlerhafte Ausgaben, aber prüfe die Quellen, bevor du auf ihrer Grundlage handelst. Eine fertig verpackte Version liegt in `packages/sdk/agent-sdk-ts/examples/research-brief-agent.ts`.

<Step title="Agenten schreiben">

```ts research-agent.ts
import { z } from "zod";
import { createAgent, createGatewayAgentClient } from "@phaseo/agent-sdk";

// Klein genug, um es in einer Protokollzeile zu lesen.
const ResearchBrief = z
  .object({
    topic: z.string(),
    summary: z.string().min(1),
    sources: z.array(z.object({ title: z.string(), url: z.string().url() }).strict()).min(1),
  })
  .strict();
type ResearchBrief = z.infer<typeof ResearchBrief>;

const researchBriefAgent = createAgent<string, ResearchBrief>({
  id: "research-brief-agent",
  model: "openai/gpt-6-astra",
  instructions:
    "Research the user's topic with web search and return a concise JSON brief with cited sources.",
  maxSteps: 4,
  parseOutput: (text) => JSON.parse(text),
  outputSchema: ResearchBrief,
});

const client = createGatewayAgentClient({
  clientOptions: { apiKey: process.env.PHASEO_API_KEY! },
  // Das JSON-Schema, das das Gateway beim Modell anfordert.
  responseFormat: {
    type: "json_schema",
    name: "research_brief",
    schema: {
      type: "object",
      properties: {
        topic: { type: "string" },
        summary: { type: "string" },
        sources: {
          type: "array",
          items: {
            type: "object",
            properties: { title: { type: "string" }, url: { type: "string" } },
            required: ["title", "url"],
            additionalProperties: false,
          },
          minItems: 1,
        },
      },
      required: ["topic", "summary", "sources"],
      additionalProperties: false,
    },
  },
  // Fast gültiges JSON reparieren.
  plugins: [{ id: "response-healing" }],
  // Phaseo führt die Suche aus; das Modell schreibt die Suchanfragen.
  gatewayTools: [{ type: "phaseo:web_search", parameters: { max_results: 5 } }],
  // Vor der Antwort immer suchen.
  toolChoice: "phaseo:web_search",
  webSearchOptions: { search_context_size: "high" },
});

const result = await researchBriefAgent.run({
  input: "Summarize the latest browser automation support patterns for coding agents.",
  client,
  onEvent(event) {
    console.log(event.type, event.runId);
  },
});

console.log(result.output);
```

| Client-Option | Aufgabe |
| --- | --- |
| `responseFormat` | Hält das Ausgabeschema explizit |
| `plugins` | [Antwortreparatur](./response-healing-for-structured-json) für fast gültiges JSON |
| `gatewayTools` | Fügt `phaseo:web_search` hinzu; der [Leitfaden zur Websuche](../guides/server-tools/web-search) listet seine Parameter |
| `toolChoice` | Erzwingt die Suche für einen Workflow, der sich immer selbst fundieren muss |
| `webSearchOptions` | Sucheinstellungen für Suchmaschinen, die den Umfang ihrer Ergebnisse anpassen |

## Prüfen, ob es funktioniert hat

Das Skript gibt ein Briefing mit mindestens einer Quell-URL aus. Öffne dann die Anfrage unter **Einstellungen → Nutzung → Protokolle** und prüfe:

- **Überwachung der Websuche** zeigt verwaltete Suchen, Ergebnisse und Zitate.
- Der Plugin-Eintrag zeigt `response-healing` nur dann als `applied`, wenn das JSON repariert werden musste.
- Die Antwort hat dem Schema entsprochen; eine Abweichung hätte den Lauf mit einem `AgentSchemaValidationError` fehlschlagen lassen.

[Websuche-Anfragen überprüfen](./web-search-debugging) behandelt die Fälle, in denen keine Suche lief.

## Wann du etwas anderes nutzen solltest

Dieses Muster passt zu einmaligen Recherchen, bei denen sich das Modell selbst fundieren soll und Aufrufer typisiertes JSON möchten. Nutze [`phaseo:web_fetch`](./tool-grounding-with-web-fetch), wenn du die URLs bereits kennst, einen [Agenten mit lokalen Tools](./agent-sdk-durable-loop), wenn die Aufgabe eher deine eigenen Daten als das Web braucht, und reine Textausgabe, wenn der Vertrag so locker ist, dass ein Schema mehr Arbeit macht, als es spart.
