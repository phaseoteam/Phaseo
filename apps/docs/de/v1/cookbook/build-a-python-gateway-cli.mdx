Führe eine Python-CLI aus, die nur die Standardbibliothek nutzt und Phaseo-Endpunkte Befehl für Befehl aufruft. Am Ende funktioniert `python quickstart.py <command>` für Health, Models, Responses und Chat Completions, dazu kommen Befehle für Embeddings, Moderation, Bilder, OCR, Video und Musik, die du in einen Worker oder ein Backend übernehmen kannst.

Die CLI ist ein Beispiel: Sie dient als Referenz für Anfrageformen, nicht als fertiges Werkzeug. Mehrere ihrer Standard-Modell-IDs für die Medienbefehle werden nicht mehr bedient, also übergib für diese `--model` (siehe [Modelle für die Medienbefehle wählen](#pick-models-for-the-media-commands)).

Damit ein Coding-Agent eine ähnliche CLI von Grund auf baut, füge diesen Prompt ein:

## Was die CLI macht

Das Beispiel ist [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart): eine einzige Datei, `quickstart.py`, die nur `urllib`, `json` und `argparse` verwendet.

| Befehl | Aufrufe |
| --- | --- |
| `smoke` | `GET /v1/health`, `GET /v1/models`, `GET /v1/providers` und ein `POST /v1/responses` |
| `health`, `models`, `providers` | Die passende `GET`-Route |
| `responses --prompt` | `POST /v1/responses` |
| `chat --prompt` | `POST /v1/chat/completions` |
| `embeddings --text` | `POST /v1/embeddings` |
| `moderations --text` | `POST /v1/moderations` |
| `image --prompt` | `POST /v1/images/generations` |
| `ocr --image-url` | `POST /v1/ocr` |
| `video-create`, `video-status`, `video-cancel`, `video-download-url` | `POST /v1/videos`, `GET /v1/videos/{video_id}`, `POST /v1/videos/{video_id}/cancel`, `POST /v1/videos/{video_id}/download_url` |
| `music-create`, `music-status` | `POST /v1/music/generate`, `GET /v1/music/generate/{music_id}` |

Jede Anfrage wird bei `429`, `5xx` und Netzwerkfehlern zweimal wiederholt, mit 1 s und dann 2 s Wartezeit, und bricht nach 45 Sekunden ab. Jeder Befehl endet mit `1`, wenn der Aufruf kein `2xx` liefert, sodass du ihn in Skripten verwenden kannst.

## Ausführen

Du brauchst Python 3 und einen Phaseo-API-Schlüssel.

<Steps>
<Step title=".env.local anlegen">

Das Skript liest `.env.local` aus dem Ordner, in dem du es ausführst. Das Beispiel enthält keine `.env.example`, also lege die Datei selbst an:

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# Optional
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My Python CLI
PHASEO_HTTP_REFERER=https://myapp.example
```

Variablen, die in deiner Shell bereits gesetzt sind, haben Vorrang vor der Datei. Ohne `PHASEO_MODEL` verwenden die Textbefehle `openai/gpt-5.6-sol`.

</Step>
<Step title="Smoke-Check ausführen">

```bash
cd examples/gateway-python-quickstart
python quickstart.py smoke
```

`smoke` sendet außerdem eine kurze Responses-Anfrage und verbraucht deshalb ein paar Credits.

</Step>
<Step title="Eine Anfrage senden">

```bash
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

</Step>
</Steps>

## Prüfen, ob es funktioniert hat

- `smoke` gibt für jeden Block `HTTP 200` aus und endet mit `0`.
- Die Ausgabe des Befehls `responses` enthält `integration_ok`.
- `--help` listet die Befehle auf, ohne eine Anfrage zu senden.
- Ohne Schlüssel gibt das Skript `Missing PHASEO_API_KEY` aus und endet mit `1`.
- Die Anfragen erscheinen unter **Einstellungen → Nutzung → Protokolle**.

## Modelle für die Medienbefehle wählen

Diese Standardwerte in `quickstart.py` sind eingestellt oder haben keinen aktiven Anbieter. Übergib mit `--model` ein aktuelles Modell und wähle es auf der [Modellseite](https://phaseo.app/models) oder mit `python quickstart.py models` aus:

| Befehl | Standard im Beispiel | Status |
| --- | --- | --- |
| `moderations` | `openai/omni-moderation-latest` | Keine Katalog-ID; verwende `openai/omni-moderation` |
| `ocr` | `mistral/mistral-ocr` | Eingestellt; versuche `mistral/ocr-4.1` |
| `video-create` | `openai/sora-2` | Eingestellt |
| `music-create` | `suno/suno-v4` | Kein aktiver Anbieter |

Die Standardwerte für `embeddings` (`google/gemini-embedding-2`) und `image` (`openai/gpt-image-2`) werden bedient. Video- und Musikjobs laufen asynchron: Speichere die zurückgegebene ID und frage den Status-Befehl ab; [Asynchrone Videos und Batches](../guides/async-video-and-batch) beschreibt den Lebenszyklus der Jobs.

Kürze die Datei auf die Befehle, die dein Dienst braucht, behalte die gemeinsame Hilfsfunktion `gateway_request()` und wechsle zum [Python-SDK](../sdk-reference/client/overview), wenn du typisierte Anfragen möchtest.
