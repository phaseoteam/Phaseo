Führe einen Ruby-Agenten aus, der eine interne Notiz mit einem lokalen Tool nachschlägt und in einem kurzen Absatz antwortet, ohne die Orchestrierung an ein anderes System abzugeben. Am Ende hast du ein Skript, das deine Notiz zu Presets zusammenfasst.

Das Tool liefert feste Beispieldaten, das Skript dient also der Veranschaulichung; ersetze es durch eine Abfrage in deinem eigenen Notizspeicher. Es passt zu einer Ruby-App, der die Daten bereits gehören und die einfache, deterministische Tool-Eingaben hat.

## Agenten bauen

<Steps>
<Step title="Installieren">

```bash
gem install phaseo_agent_sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

Oder füge `gem "phaseo_agent_sdk"` zu deinem `Gemfile` hinzu. Es installiert `phaseo_sdk` mit und benötigt Ruby 3.2 oder neuer. Siehe [Installation des Ruby Agent SDK](../sdk-reference/agent/installation).

</Step>
<Step title="Agenten schreiben">

```ruby notes.rb
require "phaseo_agent_sdk"

TOPICS = %w[presets routing guardrails].freeze

lookup_note = PhaseoAgentSdk.define_tool(
  PhaseoAgentSdk::Tool.new(
    id: "lookup-note",
    description: "Look up one internal note by topic.",
    parameters: {
      type: "object",
      properties: { topic: { type: "string", enum: TOPICS } },
      required: ["topic"],
      additionalProperties: false
    },
    # Argumente stammen vom Modell: Nur bekannte Themen erreichen execute.
    input_schema: lambda do |input|
      raise ArgumentError, "topic must be one of #{TOPICS.join(', ')}" unless input.is_a?(Hash) && TOPICS.include?(input["topic"])

      input
    end,
    execute: lambda do |input, _context|
      {
        topic: input["topic"],
        summary: "Presets centralize routing defaults so app code stays smaller."
      }
    end
  )
)

agent = PhaseoAgentSdk.create_agent(
  id: "notes-agent",
  model: "openai/gpt-6-astra",
  instructions: "Use tools when helpful and answer in one short paragraph.",
  tools: [lookup_note],
  max_steps: 4
)

# Liest PHASEO_API_KEY aus der Umgebung.
result = agent.run(
  input: "Summarize our note about presets.",
  client: PhaseoAgentSdk.create_gateway_agent_client
)

puts result.run.status
puts result.output
```

</Step>
<Step title="Ausführen">

```bash
ruby notes.rb
```

</Step>
</Steps>

## Prüfen, ob es funktioniert hat

- Das Skript gibt `completed` aus und danach einen Absatz über Presets.
- Unter **Einstellungen → Nutzung → Protokolle** zeigt der erste Modellzug einen `lookup-note`-Aufruf mit `{"topic": "presets"}`.

## Vor dem Produktionseinsatz

Halte das Tool nur lesend und `max_steps` so niedrig, wie es die Aufgabe erlaubt (der Standardwert ist `12`). Wenn dein Notizspeicher groß ist, gib nur die passende Textstelle statt ganzer Dokumente zurück, damit jeder Modellzug klein bleibt. Um Läufe zu speichern und später fortzusetzen, siehe die [robuste Agent-Schleife](./agent-sdk-durable-loop); die Option `state:` des Ruby SDK funktioniert genauso. Die [Ruby Agent SDK-Referenz](../sdk-reference/agent/usage) behandelt Status, Freigabe und Streaming.
