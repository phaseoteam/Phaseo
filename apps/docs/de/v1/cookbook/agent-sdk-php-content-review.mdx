Führe einen PHP-Agenten aus, der einen CMS-Entwurf mit einem lokalen Tool lädt und eine redaktionelle Änderung vorschlägt, innerhalb der App oder des Admin-Backends, dem die Inhalte bereits gehören. Am Ende hast du ein Skript, das einen Vorschlag für die Überschrift des Startseitenentwurfs ausgibt.

Das Tool liefert feste Beispieldaten, das Skript dient also der Veranschaulichung; ersetze es durch deine CMS-Abfrage. Es passt zu einer PHP-App, in der ein oder zwei lokale Tools genügen.

## Agenten bauen

<Steps>
<Step title="Installieren">

```bash
composer require phaseo/agent-sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

`phaseo/agent-sdk` installiert `phaseo/sdk` mit und benötigt PHP 8.1 oder neuer. Siehe [Installation des PHP Agent SDK](../sdk-reference/agent/installation).

</Step>
<Step title="Agenten schreiben">

```php review.php
<?php
require 'vendor/autoload.php';

use Phaseo\AgentSdk\AgentDefinition;
use Phaseo\AgentSdk\AgentSdk;
use Phaseo\AgentSdk\Tool;

const ALLOWED_SLUGS = ['homepage', 'pricing', 'about'];

$loadDraft = AgentSdk::defineTool(new Tool(
    id: 'load-draft',
    description: 'Load one CMS draft by slug.',
    parameters: [
        'type' => 'object',
        'properties' => [
            'slug' => ['type' => 'string', 'enum' => ALLOWED_SLUGS],
        ],
        'required' => ['slug'],
        'additionalProperties' => false,
    ],
    // Argumente stammen vom Modell: Nur bekannte Slugs erreichen execute.
    inputSchema: static function (mixed $input): array {
        if (!is_array($input) || !in_array($input['slug'] ?? null, ALLOWED_SLUGS, true)) {
            throw new InvalidArgumentException('slug must be one of ' . implode(', ', ALLOWED_SLUGS));
        }
        return $input;
    },
    execute: static fn (array $input, $context) => [
        'slug' => $input['slug'],
        'headline' => 'Phaseo makes gateway routing visible.',
    ],
));

$agent = AgentSdk::createAgent(new AgentDefinition(
    id: 'content-review-agent',
    model: 'openai/gpt-6-astra',
    instructions: 'Use tools when helpful and return concise editorial feedback.',
    tools: [$loadDraft],
    maxSteps: 4,
));

// Liest PHASEO_API_KEY aus der Umgebung.
$result = $agent->run(
    input: 'Review the homepage draft and suggest one headline improvement.',
    client: AgentSdk::createGatewayAgentClient(),
);

echo $result->run->status . PHP_EOL;
echo $result->output . PHP_EOL;
```

</Step>
<Step title="Ausführen">

```bash
php review.php
```

</Step>
</Steps>

## Prüfen, ob es funktioniert hat

- Das Skript gibt `completed` aus und danach einen Vorschlag für die Überschrift.
- Unter **Einstellungen → Nutzung → Protokolle** zeigt der erste Modellzug einen `load-draft`-Aufruf mit `{"slug": "homepage"}`.
- Ohne `PHASEO_API_KEY` wirft `createGatewayAgentClient()` den Fehler `PHASEO_API_KEY is required`.

## Vor dem Produktionseinsatz

Halte das Tool nur lesend. Wenn du eines hinzufügst, das Inhalte veröffentlicht oder bearbeitet, setze darauf `requireApproval: true`, damit der Lauf für eine Redakteurin oder einen Redakteur anhält. Um das Feedback als JSON zu erhalten, das dein CMS speichern kann, fordere ein Schema an und repariere fast gültige Ausgaben mit der [Antwortreparatur](./response-healing-for-structured-json). Die [PHP Agent SDK-Referenz](../sdk-reference/agent/usage) behandelt Status, Freigabe und Streaming.
