Führe einen Python-Agenten aus, der mit einem lokalen Tool etwas nachschlägt und seine Antwort als streng strukturiertes JSON zurückgibt. Am Ende hast du ein Skript, dessen `result.output` ein validiertes `PolicySummary`-Objekt mit `summary` und `recommendation` ist, kein freier Text.

Das Tool liefert feste Beispieldaten, das Skript dient also der Veranschaulichung; ersetze es durch deine eigene Abfrage. Es passt zu einem Python-Worker, der seine Orchestrierung selbst verwaltet und eine kleine, deterministische Tool-Auswahl hat.

## Agenten bauen

<Steps>
<Step title="Installieren">

<CodeGroup>
```bash pip
pip install phaseo-agent-sdk
```

```bash uv
uv add phaseo-agent-sdk
```
</CodeGroup>

`phaseo-agent-sdk` installiert den `phaseo`-Client und Pydantic mit.

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="Agenten schreiben">

```python extract.py
import json
import os

from pydantic import BaseModel, ConfigDict

from phaseo_agent import AgentTool, create_agent, create_gateway_agent_client, define_tool

POLICY_SLUGS = {"presets", "routing", "guardrails"}


class PolicySummary(BaseModel):
    model_config = ConfigDict(extra="forbid")
    summary: str
    recommendation: str


def check_lookup_input(value):
    # Vom Modell erzeugte Argumente: alles ablehnen, was kein bekannter Slug ist.
    if not isinstance(value, dict) or set(value) != {"slug"} or value["slug"] not in POLICY_SLUGS:
        raise ValueError(f"slug must be one of {sorted(POLICY_SLUGS)}")
    return value


lookup_policy = define_tool(
    AgentTool(
        id="lookup-policy",
        description="Look up one internal policy by slug.",
        parameters={
            "type": "object",
            "properties": {"slug": {"type": "string", "enum": sorted(POLICY_SLUGS)}},
            "required": ["slug"],
            "additionalProperties": False,
        },
        input_schema=check_lookup_input,
        execute=lambda input, ctx: {
            "slug": input["slug"],
            "summary": "Presets centralize routing, prompts, and caching defaults.",
        },
    )
)

agent = create_agent(
    {
        "id": "policy-extractor",
        "model": "openai/gpt-6-astra",
        "instructions": "Use tools when needed and return JSON with summary and recommendation.",
        "tools": [lookup_policy],
        "max_steps": 4,
        "parse_output": json.loads,
        "output_schema": PolicySummary,
    }
)

# Der Python-Client liest PHASEO_API_KEY nicht selbst: übergib ihn.
client = create_gateway_agent_client(
    client_options={"api_key": os.environ["PHASEO_API_KEY"]},
    response_format={
        "type": "json_schema",
        "name": "policy_summary",
        "schema": {
            "type": "object",
            "properties": {
                "summary": {"type": "string"},
                "recommendation": {"type": "string"},
            },
            "required": ["summary", "recommendation"],
            "additionalProperties": False,
        },
    },
    plugins=[{"id": "response-healing"}],
)

result = agent.run(input="Look up our presets policy and recommend when to use it.", client=client)

print(result.run.status)
print(result.output)
```

| Baustein | Aufgabe |
| --- | --- |
| `parameters` | Das JSON-Schema, das das Modell für die Argumente des Tools sieht |
| `input_schema` | Prüft die Argumente, bevor `execute` läuft; ein fehlerhafter Aufruf lässt den Lauf fehlschlagen |
| `response_format` | Fordert in jedem Zug dieses JSON-Schema beim Gateway an |
| `parse_output` und `output_schema` | Parsen den endgültigen Text und validieren ihn als `PolicySummary` |

</Step>
<Step title="Ausführen">

```bash
python extract.py
```

</Step>
</Steps>

## Prüfen, ob es funktioniert hat

- Das Skript gibt `completed` aus und danach ein `PolicySummary` mit beiden ausgefüllten Feldern.
- Unter **Einstellungen → Nutzung → Protokolle** zeigt der erste Modellzug einen `lookup-policy`-Aufruf mit `{"slug": "presets"}`.
- Eine Ausgabe, die nicht zum Modell passt, schlägt mit `Invalid agent output` fehl, statt ein halb ausgefülltes Objekt zurückzugeben.

Für einmalige strukturierte Ausgaben ohne Tools rufe das [Python SDK direkt](./sdk-python-presets-and-json) auf. Die [Python Agent SDK-Referenz](../sdk-reference/agent/usage) behandelt Status, Freigabe und Streaming.
