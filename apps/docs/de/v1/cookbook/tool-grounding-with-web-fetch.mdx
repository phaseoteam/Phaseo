Gib dem Modell `phaseo:web_fetch` und eine URL, die du bereits kennst, und Phaseo ruft die Seite ab, kürzt sie auf eine Größenbegrenzung und gibt den Text zurück, bevor das Modell ihn extrahiert, zusammenfasst oder klassifiziert. Am Ende hast du eine Anfrage, die eine einzelne Seite liest und Felder daraus zurückgibt, und du kannst im Protokoll bestätigen, welche Seite sie tatsächlich gelesen hat.

Mit der gezeigten Domain-Begrenzung ist die Anfrage produktionsreif. Abgerufene Seiten sind nicht vertrauenswürdige Eingaben: Das Modell kann darin Anweisungen sehen, also validiere, was es zurückgibt. Verwende stattdessen die [Websuche](../guides/server-tools/web-search), wenn du die URL nicht kennst.

## Eine fundierte Anfrage senden

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
    "tools": [
      {
        "type": "phaseo:web_fetch",
        "parameters": {
          "allowed_domains": ["phaseo.app"],
          "max_chars": 8000,
          "max_uses": 1
        }
      }
    ],
    "tool_choice": "phaseo:web_fetch"
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-6-astra",
  input:
    "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
  tools: [
    {
      type: "phaseo:web_fetch",
      parameters: {
        allowed_domains: ["phaseo.app"],
        max_chars: 8000,
        max_uses: 1,
      },
    },
  ],
  tool_choice: "phaseo:web_fetch",
});

console.log(JSON.stringify(response.output, null, 2));
console.log(response.usage?.server_tool_use);
```
</CodeGroup>

Formuliere im Prompt ausdrücklich, was nach dem Abruf geschehen soll: diese Felder extrahieren, diesen Abschnitt zusammenfassen, das Dokument klassifizieren oder eine Aussage prüfen.

| Parameter | Standard | Verwendung |
| --- | --- | --- |
| `allowed_domains` | Keiner | Nur von diesen Domains abrufen. Das Modell kann die Liste einschränken, aber nie erweitern. |
| `max_chars` | `12000` | Zurückgegebene Zeichen Seitentext, bis zu `100000`. Niedriger für einen Titel oder eine Zusammenfassung, höher für die Extraktion von Feldern. |
| `max_uses` | `10` | Abrufe pro Anfrage, bis zu `100`. |

Der [Leitfaden zu Web Fetch](../guides/server-tools/web-fetch#parameters) listet die übrigen auf, darunter `blocked_domains` und die Engines.

## Prüfen, was es gelesen hat

Das Tool-Ergebnis, das im Anfrageprotokoll erscheint, zeigt genau, auf welcher Seite das Modell seine Antwort gestützt hat:

```json
{
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "truncated": false,
  "returned_chars": 8000
}
```

Prüfe `final_url` nach Weiterleitungen und `truncated`, bevor du darauf vertraust, dass das Modell die ganze Seite gesehen hat. Jeder Abruf erhöht `usage.server_tool_use.web_fetch_requests` um 1.

## Die Grenzen kennen

Mit der Standard-Engine `direct` ruft Phaseo die Seite selbst ab und reduziert HTML auf reinen Text. Es lehnt `localhost` und private Adressen ab, folgt höchstens 5 Weiterleitungen und prüft jede Weiterleitung gegen deine Domain-Listen; eine Weiterleitung außerhalb davon gibt dem Modell `redirect_blocked_by_domain_policy` zurück.

Web Fetch eignet sich für HTML-Seiten, reinen Text und kleine JSON- oder XML-Antworten. Es ist nicht gedacht für Binärdateien, das Crawlen vieler Seiten oder die Prüfung, wie eine Seite mit JavaScript gerendert wird; verwende dafür einen Browser-Workflow. Ist die Seite sehr groß, grenze die Extraktionsaufgabe ein, statt `max_chars` zu erhöhen.

Beginne mit einem Preset oder Endpunkt, lies die Abrufdetails und die Kürzung in den Protokollen und verschärfe den Prompt, falls der abgerufene Text zu breit ist, bevor du die Nutzung ausweitest.
