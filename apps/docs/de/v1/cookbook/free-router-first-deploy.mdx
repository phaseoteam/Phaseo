Sende `"model": "phaseo/free"`, und Phaseo führt deine Anfrage ohne Credits auf einem verfügbaren kostenlosen Modell aus, das sie unterstützt. Am Ende hast du eine funktionierende Anfrage in der Sprache deiner Wahl und weißt, welches Modell sie beantwortet hat.

Diese Anfrageform ist produktionsreif für Prototypen, Demos und Traffic mit geringem Risiko. Kostenlose Modelle versprechen weder Latenz noch Ausgabestil noch einen festen Anbieter.

## Die Anfrage senden

<Steps>
<Step title="Deinen Schlüssel setzen">

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="Eine Anfrage senden">

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```



```go Go
package main

import (
  "context"
  "fmt"
  "os"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New(os.Getenv("PHASEO_API_KEY"), "https://api.phaseo.app/v1")

  temperature := 0.2
  response, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
    Model:       "phaseo/free",
    Input:       "Summarize why provider-aware free routing helps prototypes.",
    Temperature: &temperature,
  })
  if err != nil {
    panic(err)
  }

  fmt.Printf("%+v\n", response)
}
```

## Wie ein kostenloses Modell ausgewählt wird

1. Deine Anfrage geht an den gemeinsamen Alias `phaseo/free`.
2. Phaseo behält die kostenlosen Modelle, die diese Anfrage bedienen können (Endpunkt, Parameter, Tools).
3. Es sendet die Anfrage an eines davon.

Kostenlose Modelle teilen sich standardmäßig ein Kontingent von 1.500 Anfragen pro Nutzer und UTC-Tag. Darüber hinaus geben Anfragen bis 00:00 UTC `429` mit dem Code `phaseo_free_model_limit_exceeded` zurück; siehe [Gateway-Limits](../api-reference/limits#gateway-limits).

## Vom kostenlosen Router wechseln

Wenn kein kostenloses Modell eine benötigte Funktion unterstützt, etwa Tools oder ein JSON Schema, wechsle zu einem bestimmten kostenpflichtigen Modell, statt dieselbe Anfrage erneut zu senden. Wechsle zu einem festen Modell, wenn du vorhersagbare Latenz, einen bestimmten Ausgabestil oder die Wahl des Anbieters brauchst, und lege gemeinsame Einstellungen in einem [Preset](../guides/presets) ab, damit jeder Dienst dieselbe Anfrage sendet. [Routing und Fallbacks](../guides/routing-and-fallbacks) erklärt, wie kostenpflichtige Anfragen einen Anbieter wählen, und [API-Fehler](../api-reference/errors) listet die Fehlercodes auf.
