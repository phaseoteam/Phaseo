Nutze diese Seite, wenn du einem Coding-Agenten einen konkreten Prompt für eine kleine, funktionierende App statt eines vagen Integrationsplans geben möchtest.

<Tip>
Diese Prompts sind ergebnisorientiert und implementationsspezifisch, damit sie in Cursor, Claude Code, Codex und ähnlichen Tools besser funktionieren.
</Tip>

## Diese Prompts verwenden

<Steps>
  <Step title="Integrationsschnittstelle auswählen">
    Wähle den Prompt passend dazu aus, wie die App Phaseo aufrufen soll:

    - Raw-HTTP
    - ein offizielles SDK
    - Vercel AI SDK
    - Agent-SDK
  </Step>
  <Step title="Variablen in eckigen Klammern ersetzen">
    Fülle Werte wie `[APP-IDEE]`, `[FRAMEWORK]`, `[MODELL]` und `[LANGUAGE]` aus, bevor du den Prompt in deinen Coding-Agenten einfügst.
  </Step>
  <Step title="Verifizierung statt nur Code verlangen">
    Lass die Verifizierungszeilen im Prompt. So muss der Agent angeben, was er tatsächlich ausgeführt und angenommen hat und was noch manuell eingerichtet werden muss.
  </Step>
</Steps>

## Prompts optimieren

- Ersetze `[APP-IDEE]` durch eine klar abgegrenzte Nutzeraufgabe statt durch eine allgemeine Produktbeschreibung.
- Ersetze `[MODELL]` durch die genaue Modell-ID, die der Agent verwenden soll.
- Gib an, ob die Ausgabe Freitext, striktes JSON, Chat oder ein einzelnes generiertes Asset sein soll.
- Nenne das UI-Framework und das Deployment-Ziel, sofern bekannt.
- Ergänze ein oder zwei wichtige Vorgaben, etwa `nur EU-Anbieter`, `Streaming verwenden` oder `alle Geheimnisse serverseitig speichern`.
