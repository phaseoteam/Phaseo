Führe einen Go-Agenten aus, der eine betriebliche Frage beantwortet, indem er ein lokales Status-Tool aufruft, innerhalb eines einzigen Dienstes und ohne Job-System. Am Ende hast du eine `main.go`, die eine kurze Antwort zur aktuellen Latenz der Anbieter ausgibt.

Das Tool liefert feste Beispieldaten, das Programm dient also der Veranschaulichung; ersetze es durch deinen eigenen Status- oder Metrikaufruf. Es passt zu einem Go-Dienst, dessen Kontext bereits als lokale oder interne Aufrufe vorliegt.

## Agenten bauen

<Steps>
<Step title="Installieren">

```bash
go mod init ops-runbook
go get github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go@latest
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

Das Kernmodul `sdk-go/v4` wird mitinstalliert. Die Voraussetzungen findest du unter [Installation des Go Agent SDK](../sdk-reference/agent/installation).

</Step>
<Step title="Agenten schreiben">

```go main.go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  statusTool := phaseoagent.DefineTool(phaseoagent.Tool{
    ID:          "read-status",
    Description: "Read the current service status page summary.",
    Parameters: map[string]any{
      "type":                 "object",
      "properties":           map[string]any{},
      "additionalProperties": false,
    },
    Execute: func(input any, ctx phaseoagent.RuntimeContext) (any, error) {
      return map[string]any{
        "status":  "degraded",
        "summary": "Latency is elevated on one provider route.",
      }, nil
    },
  })

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "ops-runbook-agent",
    Model:        "openai/gpt-6-astra",
    Instructions: "Use tools when helpful and answer briefly.",
    Tools:        []phaseoagent.Tool{statusTool},
    MaxSteps:     4,
  })

  // Liest PHASEO_API_KEY (und PHASEO_BASE_URL, falls gesetzt).
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "What is happening with provider latency right now?",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Run.Status)
  fmt.Println(result.Output)
}
```

</Step>
<Step title="Ausführen">

```bash
go run .
```

</Step>
</Steps>

## Prüfen, ob es funktioniert hat

- Das Programm gibt `completed` aus und danach eine Antwort, die eine erhöhte Latenz auf einer Anbieterroute erwähnt.
- Unter **Einstellungen → Nutzung → Protokolle** zeigt der erste Modellzug einen `read-status`-Tool-Aufruf.
- Ohne `PHASEO_API_KEY` gibt `CreateGatewayAgentClient` den Fehler `PHASEO_API_KEY is required` zurück.

## Vor dem Produktionseinsatz

`MaxSteps` ist im Go SDK standardmäßig `8`; setze den Wert auf die kleinste Zahl, mit der die Aufgabe abgeschlossen wird. Wenn ein Tool Argumente annimmt, gib ihm ein `Parameters`-Schema und einen `InputSchema`-Validator, der bei allem Unerwarteten einen Fehler zurückgibt, denn die Argumente stammen vom Modell. Halte Tools nur lesend, außer eine Person gibt den Aufruf frei (`RequireApproval: true`). Die [Go Agent SDK-Referenz](../sdk-reference/agent/usage) behandelt Freigaben, Status und Streaming, und [Fundierung mit Web Fetch](./tool-grounding-with-web-fetch) zeigt, wie du statt eines lokalen Tools eine bekannte Seite liest.
