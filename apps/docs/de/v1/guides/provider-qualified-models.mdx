Setze eine Anbieter-ID und einen Doppelpunkt vor die Modell-ID, etwa `baseten:thinking-machines/inkling-small`, damit die Anfrage nur bei diesem Anbieter läuft, ohne Fallback zu einem anderen Anbieter.

| Du möchtest | Sende als `model` |
| --- | --- |
| Phaseo wählt einen Anbieter und wechselt bei Bedarf zwischen Anbietern | `thinking-machines/inkling-small` |
| Nur Baseten, ohne anbieterübergreifenden Fallback | `baseten:thinking-machines/inkling-small` |
| Eine geprüfte kostenlose Route bei einem Anbieter | `google-ai-studio:google/gemma-4-26b-a4b:free` |

Das Format ist `<provider-id>:<canonical-model-id>`. Der erste Doppelpunkt trennt den Anbieter ab; Doppelpunkte nach dem Modell-Namespace bleiben Teil der Modell-ID. In `google-ai-studio:google/gemma-4-26b-a4b:free` ist der Anbieter `google-ai-studio` und das Modell `google/gemma-4-26b-a4b:free`.

Wenn du einen Anbieter nur bevorzugst und einen Fallback möchtest, falls er ausfällt, verwende stattdessen die einfache Modell-ID mit den [Routing- und Fallback-Steuerungen](./routing-and-fallbacks.mdx).

## Eine Anfrage senden

Verwende die qualifizierte ID überall dort, wo der Endpunkt eine Modell-ID akzeptiert.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "baseten:thinking-machines/inkling-small",
    "input": "Explain mixture-of-experts routing in two sentences."
  }'
```

```javascript JavaScript
const response = await fetch("https://api.phaseo.app/v1/responses", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "baseten:thinking-machines/inkling-small",
    input: "Explain mixture-of-experts routing in two sentences.",
  }),
});

const result = await response.json();
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/responses",
    headers={
        "Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "model": "baseten:thinking-machines/inkling-small",
        "input": "Explain mixture-of-experts routing in two sentences.",
    },
)

result = response.json()
```
</CodeGroup>

## Was der Anbieter trotzdem erfüllen muss

Die Qualifizierung beschränkt das Routing auf einen Anbieter; sie überspringt keine andere Prüfung. Der Anbieter muss weiterhin:

- das kanonische Modell am angeforderten Endpunkt bereitstellen, mit aktivierter Fähigkeit
- die Einschränkungen von Arbeitsbereich, API-Schlüssel, Voreinstellung und Datenschutz erfüllen
- die angeforderte Service-Stufe und die Parameter unterstützen
- eine Preiskonfiguration haben

Schlägt eine Prüfung fehl, wird die Anfrage abgelehnt. Phaseo wählt nie stillschweigend einen anderen Anbieter.

## Mit `provider`- oder `routing`-Feldern kombinieren

Die Qualifizierung und alle expliziten Routing-Felder müssen übereinstimmen. Ein passendes `provider.only` oder `routing.only` wird akzeptiert:

```json
{
  "model": "baseten:thinking-machines/inkling-small",
  "provider": { "only": ["baseten"] }
}
```

Eine Zulassungsliste, die andere Anbieter nennt, oder eine Ignorierliste, die den qualifizierten Anbieter enthält, wird mit `provider_qualified_model_conflict` abgelehnt:

```json
{
  "model": "baseten:thinking-machines/inkling-small",
  "provider": { "only": ["deepinfra"] }
}
```

## Eine kostenlose Route bei einem Anbieter anfordern

Ein qualifiziertes `:free`-Modell wird nur akzeptiert, wenn dieser Anbieter eine geeignete kostenlose Route für das Modell und den Endpunkt hat. Ein kanonisches `:free`-Modell bedeutet nicht, dass jeder Anbieter des zugrunde liegenden Modells es kostenlos anbietet.

```json
{
  "model": "google-ai-studio:google/gemma-4-26b-a4b:free",
  "input": "Hello"
}
```

Die Preiskarte der Route darf nicht leer sein, und jede aktuelle Preisregel darauf muss als `free` gekennzeichnet sein und exakt null kosten. Fehlende, kostenpflichtige, gemischte oder negative Preise oder eine Regel mit Nullpreis ohne die Kennzeichnung `free` führen zur Ablehnung der Anfrage, bevor sie den Anbieter erreicht.

## Anbieter-IDs und Aliase

Verwende eine Anbieter-ID aus dem Anbieterkatalog von Phaseo (siehe [API-Anbieter](../exploring/api-providers)). IDs werden in Kleinbuchstaben umgewandelt, und bekannte ältere oder Marken-Aliase werden der kanonischen ID zugeordnet: `NovitaAI` und `novita-ai` werden beide zu `novita`. Fehlerhafte und unbekannte IDs werden vor der Anbieterauswahl abgelehnt; sie werden nie als Teil des Modellnamens an den Upstream-Anbieter gesendet.

## Validierungsfehler

Eine fehlerhafte qualifizierte ID gibt HTTP `400` mit dem Fehlercode `validation_error` zurück. `reason` und `details[].keyword` nennen die Ursache:

| Grund | Bedeutung |
| --- | --- |
| `invalid_provider_slug` | Der Anbieterteil ist leer oder enthält nicht unterstützte Zeichen. |
| `unknown_provider_slug` | Die Anbieter-ID ist korrekt formatiert, gehört aber zu keinem Phaseo-Anbieter. |
| `invalid_provider_qualified_model` | Die ID entspricht nicht dem Format `<provider>:<publisher>/<model>`. |
| `provider_qualified_model_conflict` | `provider.only`, `provider.ignore`, `routing.only` oder `routing.ignore` widerspricht der Qualifizierung. |
| `qualified_provider_unavailable` | Der Anbieter existiert, stellt das Modell aber am angeforderten Endpunkt nicht bereit. |
| `qualified_free_provider_unavailable` | Die Route des Anbieters ist nicht als kostenlos mit durchgehend Nullpreisen bestätigt. |

```json
{
  "error": "validation_error",
  "status_code": 400,
  "reason": "unknown_provider_slug",
  "description": "Unknown provider slug \"not-a-provider\" in provider-qualified model \"not-a-provider:publisher/model\". Use a provider slug returned by Phaseo's provider catalogue.",
  "provider": "not-a-provider",
  "model": "publisher/model",
  "details": [
    {
      "path": ["model"],
      "keyword": "unknown_provider_slug"
    }
  ]
}
```

Andere Fehlerformen findest du unter [Fehler und Debugging](../api-reference/errors.mdx).
