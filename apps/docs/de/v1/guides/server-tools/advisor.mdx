Füge `phaseo:advisor` hinzu, damit das Hauptmodell ein zweites Modell um eine Prüfung, einen Plan, eine Plausibilitätsprüfung oder eine Expertenmeinung bitten kann, bevor es antwortet. Das Hauptmodell ruft den Advisor wie jedes andere Tool auf. Phaseo führt das Advisor-Modell aus und gibt dessen Rat als Tool-Ergebnis zurück.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Design a rate limiter for a distributed API gateway." }
    ],
    "tools": [
      {
        "type": "phaseo:advisor",
        "parameters": {
          "model": "anthropic/claude-opus-5",
          "max_uses": 1,
          "max_completion_tokens": 1400
        }
      }
    ]
  }'
```

Advisor funktioniert mit jedem unterstützten Textmodell. Phaseo führt ihn selbst aus. Nur wenn du das native Tool-Format von Anthropic sendest, wird er in das native Advisor-Tool von Anthropic umgewandelt.

## Parameter

```json
{
  "type": "phaseo:advisor",
  "parameters": {
    "name": "reviewer",
    "model": "anthropic/claude-opus-5",
    "instructions": "Review plans for correctness, missing edge cases, and implementation risk.",
    "forward_transcript": true,
    "max_uses": 2,
    "max_completion_tokens": 1400,
    "reasoning": { "effort": "high" },
    "temperature": 0.2
  }
}
```

| Parameter | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `name` | string | Keiner | 1 bis 64 Buchstaben, Ziffern, Leerzeichen, Unterstriche oder Bindestriche. Nötig, wenn du mehr als einen Advisor hinzufügst. |
| `model` | string | Siehe unten | Das Advisor-Modell. |
| `instructions` | string | Integrierte Advisor-Anweisungen | Zusätzliche Anweisungen für den Advisor. |
| `forward_transcript` | boolean | `false` | Sendet die aktuelle Unterhaltung an den Advisor. |
| `max_uses` | integer | `1` | Aufrufe dieses Advisors pro Anfrage. |
| `max_completion_tokens` | integer | `1400` | Ausgabe-Tokens für jede Antwort des Advisors. Werte unter `1024` werden auf `1024` angehoben. `max_tokens` wird als älterer Alias akzeptiert. |
| `reasoning` | object | Standard des Anbieters | Reasoning-Einstellungen, die weitergegeben werden, wo das Advisor-Modell sie unterstützt. |
| `temperature` | number | Standard des Anbieters | Sampling-Temperatur für den Advisor-Aufruf. |

Das Advisor-Modell ist `parameters.model`, falls gesetzt, andernfalls das `model`, das das Hauptmodell in seinem Aufruf sendet, andernfalls das Modell der Anfrage selbst.

## Was das Modell sendet

In der Regel einen `prompt`. Legt das Tool kein Modell fest, kann der Aufruf auch eines wählen:

```json
{
  "model": "anthropic/claude-opus-5",
  "prompt": "Check this security design for missing controls."
}
```

Mit `forward_transcript: true` kann das Modell den Advisor ohne Prompt aufrufen, und der Advisor prüft die weitergeleitete Unterhaltung.

## Mehrere Advisors hinzufügen

Füge pro Advisor einen `phaseo:advisor`-Eintrag hinzu. Jeder benannte Advisor wird für das Modell zu einem eigenen Tool, etwa `phaseo_advisor_security_reviewer`.

```json
{
  "tools": [
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "security-reviewer",
        "model": "anthropic/claude-opus-5",
        "instructions": "Review for vulnerabilities, abuse cases, and missing mitigations."
      }
    },
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "architect",
        "model": "openai/gpt-5",
        "instructions": "Review system design tradeoffs and operational risks."
      }
    }
  ]
}
```

Namen müssen nach dem Entfernen von Leerzeichen am Rand und ohne Beachtung der Groß- und Kleinschreibung eindeutig sein, und höchstens ein Eintrag darf `name` weglassen. Andernfalls wird die Anfrage abgelehnt. `tool_choice: "phaseo:advisor"` erzwingt bei mehreren Advisors den ersten.

## Was das Tool zurückgibt

```json
{
  "status": "ok",
  "name": "reviewer",
  "model": "anthropic/claude-opus-5",
  "advice": "Start with a smaller migration slice and define rollback criteria before changing traffic routing."
}
```

Kann der Aufruf nicht ausgeführt werden, erhält das Modell stattdessen ein Fehlerergebnis: `advisor_invalid_request` (kein Prompt oder kein Modell), `advisor_max_uses_exceeded` oder `advisor_request_failed`.

Der Advisor behält zwischen Anfragen keinen Zustand. Wenn du frühere Nachrichten und Tool-Ergebnisse erneut sendest, sieht das Hauptmodell den früheren Rat. Der Advisor sieht die Unterhaltung nur, wenn `forward_transcript` aktiviert ist. Der Rat wird nicht gestreamt, und der Advisor kann selbst keine Tools aufrufen.

## Nutzung und Preise

Jeder Aufruf erhöht `usage.server_tool_use.advisor_requests` um 1 und kann über `server_tool_advisor_requests` abgerechnet werden. Die Tokens des Advisors werden zu den Preisen des Advisor-Modells als eigene Position der Anfrage abgerechnet und nicht zu den Tokens des aufrufenden Modells addiert. Ein kostenpflichtiges Advisor-Modell erfordert Guthaben, auch wenn das aufrufende Modell kostenlos ist.
