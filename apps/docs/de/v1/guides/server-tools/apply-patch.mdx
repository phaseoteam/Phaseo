---
title: "Apply Patch"
description: "Lass Responses-Modelle validierte Patch-Operationen zurückgeben."
icon: "file-pen-line"
---

Füge `phaseo:apply_patch` auf `/v1/responses` hinzu, um Dateiänderungen als strukturierte Patch-Operationen zurückzubekommen. Phaseo prüft die Form jeder Operation und gibt sie zurück, deine Dateien fasst es nie an. Deine App entscheidet, ob sie den Patch anwendet, einem Nutzer zeigt, ablehnt oder eine Überarbeitung anfordert.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Create a small README patch for this project.",
    "tools": [
      { "type": "phaseo:apply_patch" }
    ]
  }'
```

Auf `/v1/chat/completions` oder `/v1/messages` wird die Anfrage abgelehnt.

## Parameter

Keine. Füge `{ "type": "phaseo:apply_patch" }` unverändert hinzu.

## Was das Modell sendet

Ein `operation`-Objekt:

```json
{
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  }
}
```

| `type` | Pflichtfelder | Diff-Regeln |
| --- | --- | --- |
| `create_file` | `path`, `diff` | Jede nicht leere Zeile beginnt mit `+` |
| `update_file` | `path`, `diff` | Jede nicht leere Zeile beginnt mit `@@`, einem Leerzeichen, `+` oder `-` |
| `delete_file` | `path` | Keine |

`path` darf keine Null-Bytes enthalten.

## Was das Tool zurückgibt

```json
{
  "status": "completed",
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  },
  "message": "Patch operation validated. The client must apply or reject this patch and report the result."
}
```

Eine Operation, die gegen die obigen Regeln verstößt, gibt `apply_patch_invalid_operation` mit dem Grund zurück, damit das Modell es erneut versuchen kann.

## Nutzung und Preise

Jeder Aufruf erhöht `usage.server_tool_use.apply_patch_requests` um 1 und kann über `server_tool_apply_patch_requests` abgerechnet werden.
