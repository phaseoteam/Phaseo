title: "Server-Tool Web Fetch"
description: "Lass Modelle während einer Anfrage bestimmte URLs abrufen und lesen."
---

Füge `phaseo:web_fetch` hinzu, damit das Modell eine bekannte URL lesen kann, etwa eine Dokumentationsseite, einen Artikel oder ein Änderungsprotokoll. Das Modell gibt die `url` an; Phaseo ruft die Seite ab und gibt ihren Text zurück, gekürzt auf ein Größenlimit. Das Modell kann weitere Seiten abrufen, bevor es antwortet.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Summarize https://phaseo.app/docs/v1/guides/tool-calling" }
    ],
    "tools": [
      { "type": "phaseo:web_fetch" }
    ]
  }'
```

<span id="parameters"></span>
## Parameter

```json
{
  "type": "phaseo:web_fetch",
  "parameters": {
    "engine": "direct",
    "max_chars": 12000,
    "allowed_domains": ["phaseo.app"],
    "blocked_domains": ["internal.example.com"]
  }
}
```

| Parameter | Typ | Standardwert | Beschreibung |
| --- | --- | --- | --- |
| `engine` | string | `direct` | `auto`, `native`, `direct`, `exa`, `parallel`, `firecrawl` oder `deepseek`. Siehe [Engine auswählen](#choose-an-engine). |
| `max_chars` | integer | `12000` | Zeichen Seitentext, die an das Modell zurückgehen, bis `100000`. |
| `max_content_tokens` | integer | Keiner | Wird statt `max_chars` verwendet, wenn `max_chars` fehlt. Gilt auch als Größenlimit für `native`. |
| `max_uses` | integer | `10` | Abrufe pro Anfrage, bis `100`. |
| `allowed_domains` | string[] | Keiner | Ruft nur von diesen Domains ab. Das Modell kann die Liste in einem Aufruf einschränken, aber nicht erweitern. |
| `blocked_domains` | string[] | Keiner | Ruft nie von diesen Domains ab. Alias: `excluded_domains`. |

## Was das Modell sendet

Jeder Aufruf enthält eine `url`. Das Modell kann außerdem `engine`, `max_chars`, `max_content_tokens` und die Domainlisten senden.

<span id="choose-an-engine"></span>
## Engine auswählen

| Engine | Was ausgeführt wird |
| --- | --- |
| `auto` | Anthropics nativer Abruf unter `/v1/messages`. Auf anderen Endpunkten Exa, wenn es aktiviert ist, sonst `direct`. |
| `direct` | Phaseo ruft die Seite selbst ab und reduziert HTML auf Klartext. |
| `exa` | Exa-Inhaltsextraktion. |
| `parallel` | Parallel Extract. |
| `firecrawl` | Firecrawl Scrape. |
| `deepseek` | DeepSeek Fetch, das die Seite als Markdown zurückgibt. |
| `native` | Anthropics Tool `web_fetch_20260209`, nur unter `/v1/messages`. Auf anderen Endpunkten wird die Anfrage abgelehnt; verwende `direct` oder eine verwaltete Engine. |

Ist eine verwaltete Engine nicht aktiviert, gibt der Aufruf `fetch_not_configured` an das Modell zurück.

Nur HTTP(S)-URLs funktionieren. `direct` akzeptiert nur textähnliche Inhaltstypen wie HTML, Klartext und JSON und gibt für alles andere `unsupported_content_type` zurück. Es folgt bis zu 5 Weiterleitungen und prüft jede davon gegen deine Domainlisten.

### Nativer Anthropic-Abruf

```json
{
  "model": "anthropic/claude-sonnet-4.6",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "Read the docs page and summarize the limits." }
  ],
  "tools": [
    {
      "type": "phaseo:web_fetch",
      "parameters": {
        "engine": "native",
        "max_content_tokens": 9000,
        "allowed_domains": ["phaseo.app"]
      }
    }
  ],
  "tool_choice": { "type": "tool", "name": "phaseo:web_fetch" }
}
```

## Was das Tool zurückgibt

```json
{
  "provider": "fetch",
  "engine": "direct",
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "text": "...",
  "truncated": false,
  "returned_chars": 8421
}
```

Prüfe `truncated`, bevor du annimmst, dass das Modell die ganze Seite gesehen hat. Ein durchgearbeitetes Beispiel findest du unter [Antworten mit Web Fetch fundieren](../../cookbook/tool-grounding-with-web-fetch).

## Nutzung und Preise

Jeder Abruf erhöht `usage.server_tool_use.web_fetch_requests` um 1. Phaseo berechnet jeden verwalteten Abruf über Exa, Parallel, Firecrawl oder DeepSeek mit $0.001, sofern die Preiskarte des Modells keinen eigenen Preis für `server_tool_web_fetch_requests` festlegt; direkte Abrufe sind kostenlos. Abrufe über kostenpflichtige Engines erfordern Guthaben, auch wenn das Modell kostenlos ist. Nativer Abruf wird über `native_web_fetch_requests` abgerechnet, wenn die Preiskarte des Modells dies festlegt.
