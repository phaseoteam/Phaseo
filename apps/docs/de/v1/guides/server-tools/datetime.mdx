title: "Server-Tool Datetime"
description: "Gib Modellen das aktuelle Datum und die aktuelle Uhrzeit in einer oder mehreren Zeitzonen."
---

Füge `phaseo:datetime` hinzu, damit das Modell das aktuelle Datum und die Uhrzeit nachschlagen kann, wenn ein Prompt davon abhängt, etwa „Welcher Tag ist in Tokio?“. Das Modell entscheidet, wann es das Tool aufruft. Phaseo gibt die Uhrzeit in jeder Zeitzone zurück, die du angegeben hast.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What day of the week is it in Tokyo?" }
    ],
    "tools": [
      {
        "type": "phaseo:datetime",
        "parameters": { "timezones": ["Asia/Tokyo", "UTC"] }
      }
    ]
  }'
```

## Parameter

| Parameter | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `timezones` | string[] | `["UTC"]` | Bis zu 5 IANA-Zeitzonennamen, etwa `["Europe/London", "UTC"]`. |

Mehr als 5 Zeitzonen oder ein Name, der keine gültige IANA-Zeitzone ist, führen zur Ablehnung der Anfrage, bevor das Modell läuft. Der ältere Typname `gateway:datetime` wird weiterhin akzeptiert.

## Was das Tool zurückgibt

Ein Eintrag pro Zeitzone:

```json
{
  "timezones": [
    { "timezone": "Europe/London", "datetime": "2026-07-03T10:00:00.123+01:00" },
    { "timezone": "UTC", "datetime": "2026-07-03T09:00:00.123+00:00" }
  ]
}
```

## Nutzung und Preise

Jeder Aufruf erhöht `usage.server_tool_use.datetime_requests` um 1. Datetime hat keinen eigenen Preiszähler.
