title: "Server-Tool Subagent"
description: "Lass das Hauptmodell gezielte Arbeit an ein Worker-Modell delegieren."
---

Füge `phaseo:subagent` hinzu, damit das Hauptmodell innerhalb derselben Anfrage eine abgeschlossene Aufgabe an ein Worker-Modell übergeben kann, oft ein kleineres oder schnelleres. Das Hauptmodell beschreibt die Aufgabe, Phaseo führt den Worker aus und gibt dessen Ergebnis zurück, und das Hauptmodell beendet die Antwort.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5",
    "messages": [
      { "role": "user", "content": "Compare these release notes and summarize the breaking changes." }
    ],
    "tools": [
      {
        "type": "phaseo:subagent",
        "parameters": {
          "model": "openai/gpt-6-astra",
          "instructions": "Return concise findings for the main model. Do not address the end user directly.",
          "max_uses": 3,
          "max_completion_tokens": 1200
        }
      }
    ]
  }'
```

## Parameter

| Parameter | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `model` | string | Das Modell der Anfrage | Das Worker-Modell. |
| `instructions` | string | Integrierte Worker-Anweisungen | Zusätzliche Anweisungen für den Worker. |
| `max_uses` | integer | `1` | Subagent-Aufrufe pro Anfrage. |
| `max_completion_tokens` | integer | `1400` | Ausgabe-Tokens für jede Antwort des Workers. Werte unter `1024` werden auf `1024` angehoben. `max_tokens` wird als älterer Alias akzeptiert. |
| `reasoning` | object | Standard des Anbieters | Reasoning-Einstellungen, die weitergegeben werden, wo das Worker-Modell sie unterstützt. |
| `temperature` | number | Standard des Anbieters | Sampling-Temperatur für den Worker-Aufruf. |

Der Worker erhält nie die Unterhaltung: Gib alles, was er braucht, in die Aufgabe.

## Was das Modell sendet

Eine `task_description` mit der vollständigen Aufgabe, dem Kontext und der erwarteten Ausgabe, plus optional einen kurzen `task_name`:

```json
{
  "task_description": "Extract the three highest-risk migration steps from the supplied plan."
}
```

Statt `task_description` werden auch `task`, `prompt` oder `input` akzeptiert.

## Was das Tool zurückgibt

```json
{
  "status": "ok",
  "model": "openai/gpt-6-astra",
  "outcome": "The highest-risk steps are schema migration, traffic cutover, and rollback verification."
}
```

Kann der Aufruf nicht ausgeführt werden, erhält das Modell `subagent_invalid_request` (keine Aufgabe), `subagent_max_uses_exceeded` oder `subagent_request_failed`.

## Nutzung und Preise

Jeder Aufruf erhöht `usage.server_tool_use.subagent_requests` um 1 und kann über `server_tool_subagent_requests` abgerechnet werden. Die Tokens des Hilfsmodells werden zu dessen eigenen Preisen als eigene Position der Anfrage abgerechnet und nicht zu den Tokens des aufrufenden Modells addiert. Ein kostenpflichtiges Hilfsmodell erfordert Guthaben, auch wenn das aufrufende Modell kostenlos ist. Wenn du eine Prüfung statt delegierter Arbeit willst, nutze [Advisor](./advisor).
