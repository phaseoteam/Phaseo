title: "Bildgenerierung"
description: "Lass Modelle über ein Phaseo-Server-Tool Bilder erstellen."
---

Füge `phaseo:image_generation` hinzu, damit das Modell während seiner Antwort ein Bild erstellen kann. Das Modell schreibt den Bild-Prompt, Phaseo ruft das Bildmodell auf und gibt das Bild an die Modellschleife zurück.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Design a wide product concept image for a compact desktop synthesizer.",
    "tools": [
      {
        "type": "phaseo:image_generation",
        "parameters": {
          "model": "openai/gpt-image-2",
          "quality": "high",
          "aspect_ratio": "16:9",
          "output_format": "png"
        }
      }
    ]
  }'
```

## Parameter

Alle Parameter sind optional.

| Parameter | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `model` | string | `openai/gpt-image-2` | Bildmodell. Hier gesetzt, überschreibt es jedes Modell, das das Hauptmodell anfordert. |
| `quality` | string | Standard des Anbieters | Qualitätshinweis, etwa `low`, `medium` oder `high`. |
| `size` | string | Standard des Anbieters | Hinweis zur Bildgröße. |
| `aspect_ratio` | string | Standard des Anbieters | Seitenverhältnis, etwa `1:1`, `16:9` oder `9:16`. |
| `background` | string | Standard des Anbieters | Hinweis zum Hintergrundmodus. |
| `output_format` | string | Standard des Anbieters | `png`, `jpeg` oder `webp`. |
| `output_compression` | integer | Standard des Anbieters | Kompressionshinweis, begrenzt auf `0` bis `100`. |
| `moderation` | string | Standard des Anbieters | Moderationshinweis für den Anbieter. |

## Was das Modell sendet

Einen `prompt` (oder `description`, das gleich behandelt wird). Es kann außerdem `model` senden, das nur verwendet wird, wenn das Tool keines festlegt, sowie jeden der anderen Parameter oben, die für diesen Aufruf die Werte des Tools ersetzen.

## Was das Tool zurückgibt

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "imageUrl": "https://...",
  "mime_type": "image/png"
}
```

Manche Anbieter geben statt `imageUrl` ein `b64_json` mit Base64-Bilddaten zurück. Hat der Aufruf keinen Prompt, erhält das Modell `image_generation_invalid_request`. Schlägt das Bildmodell fehl, erhält es `image_generation_failed`.

## Nutzung und Preise

Jedes Bild erhöht `usage.server_tool_use.image_generation_requests` um 1 und kann über `server_tool_image_generation_requests` abgerechnet werden. Das Bildmodell wird zu seinen eigenen Preisen als eigene Position der Anfrage abgerechnet. Ein kostenpflichtiges Bildmodell erfordert Guthaben, auch wenn das aufrufende Modell kostenlos ist.
