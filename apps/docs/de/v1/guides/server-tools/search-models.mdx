title: "Server-Tool Modellsuche"
description: "Lass ein Modell passende Modelle im Live-Katalog von Phaseo finden."
---

Füge `phaseo:search_models` hinzu, damit das Modell anhand des Live-Katalogs von Phaseo ein Modell auswählen oder empfehlen kann: aktuelle Modalitäten, Anbieter, unterstützte Parameter und Preise.

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "Which models can transcribe audio and return JSON?" }
  ],
  "tools": [{ "type": "phaseo:search_models", "parameters": { "max_results": 5 } }],
  "max_tool_calls": 10
}
```

## Parameter

| Parameter | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `max_results` | integer | `5` | Zurückgegebene Modelle pro Suche, bis zu `20`. |

## Was das Modell sendet

Beliebige dieser Filter. Es werden nur aktive Modelle durchsucht, und ein Modell muss jeden gesendeten Filter erfüllen.

| Argument | Trifft zu auf |
| --- | --- |
| `query` | Text in Modell-ID, Name oder Beschreibung |
| `series` | Text in Modell-ID, Name oder Beschreibung |
| `input_modalities` | Modelle, die alle diese Eingaben akzeptieren |
| `output_modalities` | Modelle, die alle diese Ausgaben erzeugen |
| `provider` | Eine Anbieter-ID oder ein Anbietername |
| `required_params` | Modelle, die alle diese Anfrageparameter unterstützen |

## Was das Tool zurückgibt

```json
{
  "models": [
    {
      "id": "openai/gpt-4o-mini-transcribe",
      "name": "...",
      "description": "...",
      "input_modalities": ["audio"],
      "output_modalities": ["text"],
      "providers": ["openai"],
      "supported_params": ["..."],
      "pricing": {}
    }
  ],
  "total_results": 4,
  "showing": 4
}
```

## Nutzung und Preise

Jede Suche erhöht `usage.server_tool_use.search_models_requests` um 1 und kann über `server_tool_search_models_requests` abgerechnet werden.
