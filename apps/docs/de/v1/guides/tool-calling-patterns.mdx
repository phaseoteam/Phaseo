icon: "waypoints"
title: "Muster für Tool-Aufrufe"
description: "Zuverlässige Tool-Aufruf-Schleifen für die Endpunkte Chat Completions und Responses."
---

Nachdem das Modell ein Tool aufgerufen hat, sende eine Folgeanfrage, die die Unterhaltung, den Aufruf des Modells und das Ergebnis deines Tools wiederholt. Das Modell schreibt dann seine Antwort oder ruft ein weiteres Tool auf, und du wiederholst den Vorgang. Nutze den Endpunkt, dessen Nachrichtenformat deine App bereits verwendet: `/v1/chat/completions` für Nachrichtenschleifen im OpenAI-Stil, `/v1/responses` für die Responses API, `/v1/messages` für Anthropic-native Apps.

<Tabs>
<Tab title="Chat Completions">

Wenn `finish_reason` den Wert `tool_calls` hat, führe jeden Aufruf aus und sende dann die Assistant-Nachricht unverändert, gefolgt von einer Nachricht mit `role: "tool"` pro Aufruf, zugeordnet über `tool_call_id`. Sende `tools` erneut mit.

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "What is the weather in Seattle?" },
    {
      "role": "assistant",
      "content": null,
      "tool_calls": [
        {
          "id": "call_123",
          "type": "function",
          "function": {
            "name": "get_weather",
            "arguments": "{\"city\":\"Seattle\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_123",
      "content": "72F and sunny"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    }
  ]
}
```

</Tab>
<Tab title="Responses">

Aufrufe kommen als Ausgabeelemente vom Typ `function_call` an. Sende das Aufrufelement als Eingabe zurück, gefolgt von einem Element `function_call_output` mit derselben `call_id`.

```json
{
  "model": "openai/gpt-6-astra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [{ "type": "input_text", "text": "What's the weather in Seattle?" }]
    },
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Seattle\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "72F and sunny"
    }
  ]
}
```

</Tab>
</Tabs>

Bevor du einen Aufruf ausführst, validiere seine Argumente; siehe [Sicherheit bei Tool-Aufrufen](./tool-calling-safety).
