Sende ein Dokumentbild an `POST /v1/parse`, um seinen Text in Lesereihenfolge zurückzubekommen, als Markdown oder als strukturierte Text-, Bild- und Tabellenblöcke. Nutze [OCR](../api-reference/endpoint/ocr.mdx), wenn du nur den reinen Text brauchst.

<Warning>
  Parse akzeptiert ein Bild pro Anfrage, als `http(s)`-URL oder als Base64-URI `data:image/...`. PDFs werden nicht akzeptiert: Wandle jede Seite zuerst in ein Bild um. Cohere begrenzt jedes Bild auf 20 MB, 50 Megapixel und 200 MB im dekodierten Zustand.
</Warning>

## In Markdown analysieren

Markdown ist das Standard-`output_format`. Es erhält die Lesereihenfolge, fügt Tabellen als HTML ein und verknüpft erkannte Bilder mit Metadaten auf der Seite.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/parse \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cohere/parse-v5.0",
    "document": {
      "type": "image_url",
      "image_url": "https://example.com/invoice.png"
    },
    "output_format": "markdown"
  }'
```

```ts TypeScript
const response = await fetch("https://api.phaseo.app/v1/parse", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "cohere/parse-v5.0",
    document: {
      type: "image_url",
      image_url: "https://example.com/invoice.png",
    },
    output_format: "markdown",
  }),
});

const parsed = await response.json();
console.log(parsed.pages[0].markdown.content);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/parse",
    headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
    json={
        "model": "cohere/parse-v5.0",
        "document": {
            "type": "image_url",
            "image_url": "https://example.com/invoice.png",
        },
        "output_format": "markdown",
    },
)
response.raise_for_status()
print(response.json()["pages"][0]["markdown"]["content"])
```
</CodeGroup>

## Strukturierte Blöcke zurückgeben

Setze `output_format` auf `blocks`, um geordnete Text-, Bild- und Tabellenbereiche zu erhalten. Bild- und Tabellenblöcke enthalten, sofern verfügbar, Begrenzungsrahmen in Pixeln und in normalisierter Form.

## Wie Parse abgerechnet wird

Die Nutzung von Parse wird pro Seite gemessen. Die Antwort enthält die Metadaten von Cohere und einen normalisierten Wert `usage.input_pages`, wenn der Anbieter abgerechnete Seiten meldet. Cohere bietet derzeit einen kostenlosen, ratenbegrenzten API-Zugang zur Evaluierung an und hat noch keinen Produktionspreis für die Parse-API veröffentlicht.
