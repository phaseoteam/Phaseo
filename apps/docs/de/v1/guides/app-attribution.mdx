---
title: "App-Zuordnung"
description: "Gruppiere die Gateway-Nutzung anhand stabiler IDs, Namen, URLs und Kategorien nach Anwendung."
icon: "badge-check"
---

Sende bei jeder Anfrage einen `X-App-Id`-Header, um ihre Nutzung in App-Analysen und Anfrage-Audits unter einer Anwendung zu gruppieren. Verwende eine eigene ID für jedes Produkt, jede Umgebung oder jedes Kundenerlebnis, über das du getrennt berichten willst. Die Zuordnung verändert nie die Inferenzantwort.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-App-Id: acme-support" \
  -H "X-App-Name: Acme Support" \
  -H "HTTP-Referer: https://acme.example/support" \
  -H "X-App-Categories: chat,productivity" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Summarize this ticket."
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const phaseo = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY,
  app: {
    id: "acme-support",
    name: "Acme Support",
    url: "https://acme.example/support",
    categories: ["chat", "productivity"],
  },
});

const response = await phaseo.generateResponse({
  model: "openai/gpt-6-astra",
  input: "Summarize this ticket.",
});
```
</CodeGroup>

Die Option `app` des TypeScript-SDK sendet dieselben Header bei jeder Anfrage. Phaseo setzt die Zuordnung nie für dich.

## Header

| Header | Zweck |
| --- | --- |
| `X-App-Id` | Stabile, von deiner Anwendung gewählte Kennung. |
| `X-App-Name` | Lesbarer Name, der in den App- und Nutzungsansichten angezeigt wird. |
| `HTTP-Referer` | Öffentliche Seiten- oder Deployment-URL der App. |
| `X-App-Categories` | Kommagetrennte Liste mit bis zu drei Kategorien. |
| `X-Title` | Kompatibilitätsalias für einen lesbaren App-Namen. |

Phaseo erkennt die App an ihrer `HTTP-Referer`-URL, wenn du eine sendest, und sonst an `X-App-Id`. Halte beide stabil: Eine neue URL oder ID startet in den Analysen eine neue App.

`HTTP-Referer` muss nicht mit dem automatischen `Referer`-Header des Browsers übereinstimmen. Setze ihn in serverseitigen Integrationen ausdrücklich, wenn du eine einheitliche App-URL willst.

## Kategorien

Wähle bis zu drei aus `chat`, `developer-tools`, `research`, `productivity`, `education`, `commerce`, `media`, `finance` und `other`.

Groß- und Kleinschreibung spielt bei den Werten keine Rolle. Phaseo ignoriert unbekannte Werte, entfernt Duplikate und behält die ersten drei gültigen Kategorien. Kategorien aus späteren Anfragen werden zu den bereits für die App gespeicherten hinzugefügt; sie entfernen nie Kategorien, die im Dashboard gewählt wurden.

Um Kategorien zentral statt im Anwendungscode zu verwalten, bearbeite sie unter **Einstellungen → Apps**.

## Zuordnung sicher zum Teilen halten

- Füge keine Kunden-IDs, E-Mail-Adressen oder andere personenbezogene Daten in Attributions-Header ein.
- Behandle URL und Name als öffentlich: Sie können in geteilten oder öffentlichen App-Ansichten erscheinen.
