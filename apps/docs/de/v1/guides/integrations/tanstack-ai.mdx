Erstelle den `openaiCompatible`-Adapter von TanStack AI mit deinem Phaseo-Schlüssel, `baseURL: "https://api.phaseo.app/v1"` und den Phaseo-Modell-IDs, die du nutzt. Er funktioniert für typsicheren Chat in React, Solid, Preact, Vue, Svelte oder serverseitigem TypeScript.

## Installieren

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## Den Adapter auf Phaseo richten

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-6-astra", "anthropic/claude-sonnet-5.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-6-astra"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

Gib in `models` jede Phaseo-Modell-ID an, die du nutzen willst. Prüfe die IDs unter [Modelle](../../api-reference/endpoint/models.mdx).

## Bekannte Einschränkungen

- Der Adapter nutzt Chat Completions. Für Funktionen, die es nur bei Responses gibt, rufe Phaseo direkt auf oder nutze das [OpenAI SDK](./openai-sdk.mdx).
- Unterstützt ein Modell keine [Tools](../tool-calling.mdx) oder Bilder, gib in TanStack AI engere Fähigkeiten an, damit TypeScript nicht unterstützte Aufrufe erkennt.
