Führe `phaseo claude-code` aus, um die Anfragen von Claude Code über Phaseo zu senden, oder setze selbst drei Umgebungsvariablen. Claude Code ruft das Anthropic-artige `/v1/messages` auf, das Phaseo als [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx) bedient, sodass sich deine Prompts nicht ändern.

## Mit der Phaseo CLI einrichten

```bash
phaseo login
phaseo claude-code
claude
```

Fehlt Claude Code, zeigt die CLI den offiziellen Installationsbefehl und fragt, bevor sie ihn ausführt. Danach:

- erstellt die Einrichtung einen `Phaseo CLI: Claude Code API Key`, der nach 90 Tagen abläuft und ein monatliches Ausgabenlimit von $100 hat, und legt ihn im Anmeldedatenspeicher des Betriebssystems ab;
- setzt sie `ANTHROPIC_BASE_URL` und einen `apiKeyHelper` in `~/.claude/settings.json`. Der Helfer holt den Schlüssel von der CLI und erstellt einen neuen, wenn der alte abläuft, sodass kein Schlüssel im Klartext in die Einstellungen von Claude Code geschrieben wird.

Die Einrichtung bricht ohne Änderungen ab, wenn `settings.json` bereits eine andere `ANTHROPIC_BASE_URL`, einen anderen `apiKeyHelper` oder ein nicht leeres `ANTHROPIC_API_KEY` oder `ANTHROPIC_AUTH_TOKEN` enthält. `--model` wird für Claude Code nicht unterstützt; setze stattdessen `ANTHROPIC_MODEL` (siehe unten).

## Claude Code manuell konfigurieren

Setze diese Variablen in der Shell, aus der du Claude Code startest:

<CodeGroup>

```bash bash
export ANTHROPIC_BASE_URL="https://api.phaseo.app"
export ANTHROPIC_AUTH_TOKEN="your_phaseo_api_key"
export ANTHROPIC_API_KEY=""
```

```powershell PowerShell
$env:ANTHROPIC_BASE_URL = "https://api.phaseo.app"
$env:ANTHROPIC_AUTH_TOKEN = "your_phaseo_api_key"
$env:ANTHROPIC_API_KEY = ""
```

</CodeGroup>

Claude Code sendet `ANTHROPIC_AUTH_TOKEN` als `Authorization`-Header, den Phaseo akzeptiert. Um ein Standardmodell festzulegen, setze `ANTHROPIC_MODEL` auf eine Phaseo-Modell-ID aus [Modelle](../../api-reference/endpoint/models.mdx).

## Prüfen, ob es funktioniert

Führe `claude` aus, sende einen kurzen Prompt und bestätige, dass die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Phaseo entfernen

```bash
phaseo integrations remove claude-code
```

Das entfernt die Basis-URL, den Schlüsselhelfer und die leeren Anmeldedaten-Variablen, die Phaseo zu `settings.json` hinzugefügt hat, und widerruft dann den Schlüssel. Bei einer manuellen Einrichtung entferne die drei Umgebungsvariablen.

## Bekannte Grenzen

- Füge den Server [Docs MCP](./docs-mcp.mdx) hinzu, wenn Claude Code während einer Sitzung die Phaseo-Dokumentation lesen soll.
