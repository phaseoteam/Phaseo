Führe `phaseo zed` aus, um der `settings.json` von Zed einen Phaseo-Anbieter hinzuzufügen, und füge dann den Schlüssel in Zed ein, das Anbieterschlüssel im Schlüsselbund des Systems speichert. Ohne die CLI fügst du den Anbieter selbst in den Einstellungen von Zed hinzu.

## Mit der Phaseo CLI einrichten

```bash
phaseo login
phaseo zed --model openai/gpt-5.6-terra
```

Die CLI erstellt einen `Phaseo CLI: Zed API Key` (Ablauf nach 90 Tagen, monatliches Ausgabenlimit von $100) und fügt der `settings.json` von Zed einen `openai_compatible`-Anbieter namens `phaseo` hinzu, mit der API-URL `https://api.phaseo.app/v1` und dem ausgewählten Modell. Andere Einstellungen bleiben unangetastet. Ohne `--model` verwendet sie `anthropic/claude-sonnet-4.6`. Die Einrichtung hält an, wenn Zed bereits einen Anbieter namens `phaseo` hat.

## Den Schlüssel in Zed hinzufügen

1. Öffne die Befehlspalette und führe **agent: open settings** aus.
2. Wähle unter **AI** die Option **LLM Providers → Configure**.

![KI-Einstellungen von Zed mit hervorgehobenem Bereich LLM Providers](/images/integrations/zed-agent-settings.png)

3. Wenn Phaseo erscheint, öffne es und füge die Ausgabe von `phaseo integrations credential zed` ein.

Um den Anbieter ohne die CLI hinzuzufügen, wähle stattdessen **Add Provider → OpenAI** und gib die unten stehenden Werte ein.

![Seite LLM Providers in Zed mit Add Provider](/images/integrations/zed-llm-providers.png)

| Feld | Wert |
| --- | --- |
| Provider Name | `Phaseo` |
| API URL | `https://api.phaseo.app/v1` |
| API Key | Ausgabe von `phaseo integrations credential zed` oder ein beliebiger Phaseo-API-Schlüssel |
| Model Name | Eine Phaseo-Modell-ID |

![Formular in Zed zum Hinzufügen eines OpenAI-kompatiblen Anbieters](/images/integrations/zed-add-compatible-provider.png)

Fülle API-URL, Modell und Schlüssel aus, bevor du **Save Provider** wählst.

## Prüfen, ob es funktioniert

Öffne einen neuen Agent-Thread, wähle das Phaseo-Modell und sende eine kurze Anfrage. Prüfe, ob sie unter **Einstellungen → Nutzung → Protokolle** erscheint. Meldet Zed einen ungültigen Schlüssel, führe `phaseo integrations credential zed` erneut aus und ersetze den Schlüssel in Zed.

## Phaseo entfernen

```bash
phaseo integrations remove zed
```

Damit wird der Phaseo-Anbieter aus `settings.json` entfernt und der Schlüssel widerrufen. Zeigt Zed noch den alten Schlüsselbundeintrag an, entferne Phaseo auch unter **LLM Providers**.
