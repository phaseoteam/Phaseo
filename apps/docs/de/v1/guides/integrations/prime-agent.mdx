Führe `phaseo prime-agent` aus, um Prime Agent einen Phaseo-Anbieter mit jedem kompatiblen Phaseo-Modell hinzuzufügen. Prime Agent läuft unter macOS und Linux. Unter Windows installierst du es in WSL und führst die Einrichtung dort aus.

## Mit der Phaseo CLI einrichten

```bash
phaseo login
phaseo prime-agent
```

Fehlt Prime Agent, zeigt die CLI den offiziellen Installer-Befehl an und fragt nach, bevor sie ihn ausführt. Danach erstellt die Einrichtung einen `Phaseo CLI: Prime Agent API Key` (Ablauf nach 90 Tagen, monatliches Ausgabenlimit von $100) und schreibt einen `phaseo`-Anbieter nach `~/.prime/agent/models.json`. Der Anbieter listet jedes aktive Phaseo-Textmodell auf, das mit Chat Completions funktioniert.

| Flag | Wirkung |
| --- | --- |
| `--model <id>` | Legt das Anfangsmodell fest. Standard ist `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | Fügt nur das ausgewählte Modell hinzu. |
| `--dry-run` | Zeigt die Dateiänderungen an, ohne sie vorzunehmen. |

Der Anbieter holt seinen Schlüssel zum Zeitpunkt der Anfrage mit dem befehlsgestützten Schlüsselformat von Prime Agent, sodass kein Klartextschlüssel in die Datei geschrieben wird:

```text
!phaseo integrations credential prime-agent
```

## Prüfen, ob es funktioniert

```bash
prime-agent
```

Öffne `/model`, wähle den Anbieter `phaseo` und sende einen kurzen Prompt. Prüfe, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Phaseo entfernen

```bash
phaseo integrations remove prime-agent
```

Damit wird nur der Phaseo-Anbieter entfernt und der Schlüssel widerrufen.
