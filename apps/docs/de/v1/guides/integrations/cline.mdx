Führe `phaseo cline` aus, um eine Cline-CLI-Sitzung über Phaseo zu starten, oder erstelle mit `phaseo setup cline` einen Schlüssel und füge in der Cline-Erweiterung einen **OpenAI Compatible**-Anbieter hinzu. Die Erweiterung speichert Schlüssel im Secret Storage von VS Code, deshalb findet dieser letzte Schritt in ihrer Oberfläche statt.

## Die Cline CLI über Phaseo ausführen

```bash
phaseo login
phaseo cline --model openai/gpt-5.6-terra -- --tui
```

Der Runner schreibt die Cline-Einstellungen in ein temporäres Verzeichnis, startet `cline` und löscht das Verzeichnis, wenn Cline beendet wird. Deine bestehende Cline- oder VS-Code-Einrichtung bleibt also unverändert. Fehlt Cline, bietet ein interaktiver Lauf die Installation an. Setze die eigenen Flags von Cline hinter `--`.

| Flag | Wirkung |
| --- | --- |
| `--model <id>` | Zu verwendendes Modell. Standard ist `openai/gpt-5.6-terra`. |
| `--catalog all` | Listet jedes aktive Phaseo-Textmodell in Cline auf, nicht nur das ausgewählte. |
| `--dry-run --json` | Zeigt den Installations- und Startplan, ohne einen Schlüssel zu erstellen oder Cline zu starten. |
| `--skip-install` | Überspringt die Installationsprüfung. |

`phaseo run cline ...` ist die Langform desselben Befehls.

## Die Cline-Erweiterung konfigurieren

Erstelle einen Schlüssel für die Erweiterung:

```bash
phaseo login
phaseo setup cline --model anthropic/claude-sonnet-5.5
```

Dann in VS Code:

1. Öffne das Cline-Panel und wähle das Einstellungssymbol oder den Anbieter unter dem Chatfeld.
2. Wähle **OpenAI Compatible** und gib Folgendes ein:

| Cline-Feld | Wert |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | Ausgabe von `phaseo integrations credential cline` |
| Model ID | `anthropic/claude-sonnet-5.5` oder das Modell, das die Einrichtung ausgibt |

3. Speichere den Anbieter. Wenn deine Version **Verify** anzeigt, wähle es aus.
4. Wähle das konfigurierte Modell für die nächste Aufgabe.

Ohne die CLI kannst du jeden beliebigen Phaseo-API-Schlüssel verwenden. Die Cline-Dokumentation zur [OpenAI-kompatiblen Konfiguration](https://docs.cline.bot/enterprise-solutions/configuration/remote-configuration/openai-compatible/member-configuration) behandelt teamverwaltete Einrichtungen.

## Prüfen, ob es funktioniert

Bitte Cline, mit `PHASEO_CLINE_OK` zu antworten, und prüfe dann, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Phaseo entfernen

Lösche den Phaseo-Anbieter in Cline oder wechsle zu einem anderen, und führe dann aus:

```bash
phaseo integrations remove cline
```

Damit wird der Schlüssel widerrufen. Die CLI kann den Erweiterungsspeicher von VS Code nicht leeren, daher kann der gelöschte Schlüssel weiterhin in Cline angezeigt werden, bis du ihn dort entfernst.

## Häufige Probleme beheben

### Die Überprüfung schlägt fehl

Übernimm die Base URL genau wie angegeben, einschließlich `/v1`, und füge einen frisch abgerufenen Schlüssel ohne Anführungszeichen oder Leerzeichen ein.

### Die Modellliste ist leer

Gib die Phaseo-Modell-ID selbst ein. Cline braucht keine Modellerkennung.

### Der Chat funktioniert, aber Tools schlagen fehl

Wähle ein Phaseo-Modell mit Unterstützung für Tool-Aufrufe. Eine funktionierende Verbindung bedeutet nicht, dass das Modell Tools unterstützt.
