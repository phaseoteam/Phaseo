Führe `phaseo minimax` aus, um eine MiniMax-Code-Sitzung (`mcode`) über Phaseo zu starten, oder füge Phaseo mit `mcode provider add` hinzu, damit es in jeder Sitzung verfügbar bleibt.

## MiniMax Code über die Phaseo CLI ausführen

```bash
phaseo login
phaseo minimax --model openai/gpt-5.6-terra
```

Der Runner erstellt einen eigenen Schlüssel, setzt `MINIMAX_DATA_DIR` auf ein temporäres Verzeichnis, fügt dort mit `mcode provider add` einen Phaseo-Anbieter hinzu, startet `mcode` und löscht das Verzeichnis, wenn `mcode` beendet wird. Deine normale `~/.minimax`-Konfiguration wird nicht geändert, und der Schlüssel wird nur an den Prozess zur Anbietereinrichtung übergeben. Setze die eigenen Flags von MiniMax Code hinter `--`.

| Flag | Wirkung |
| --- | --- |
| `--model <id>` | Zu verwendendes Modell. Standard ist `openai/gpt-5.6-terra`. |
| `--catalog all` | Registriert jedes aktive Phaseo-Textmodell, das mit Chat Completions funktioniert. |
| `--dry-run --json` | Zeigt den Installations- und Startplan, ohne einen Schlüssel zu erstellen. |
| `--skip-install` | Überspringt die Installationsprüfung. |

`phaseo run minimax ...` ist die Langform desselben Befehls.

Fehlt `mcode`, bietet der erste interaktive Lauf an, es mit dem offiziellen Installer von MiniMax zu installieren (unter Windows mit dem PowerShell-Installer). Wenn du MiniMax Code selbst verwaltest, installiere es, prüfe `mcode --version` und führe den Befehl erneut mit `--skip-install` aus.

## MiniMax Code manuell konfigurieren

Um einen Phaseo-Anbieter dauerhaft zu behalten, füge ihn mit dem eigenen Befehl von MiniMax Code hinzu:

```bash
export MCODE_PROVIDER_API_KEY="your_phaseo_api_key"
mcode provider add \
  --name "Phaseo" \
  --base-url "https://api.phaseo.app/v1" \
  --api-format openai-completions \
  --model "openai/gpt-5.6-terra" \
  --use
```

MiniMax Code speichert den Anbieter in seinem Datenverzeichnis.

## Prüfen, ob es funktioniert

Sende einen kurzen Prompt und prüfe, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Häufige Probleme beheben

### MiniMax Code ist nicht installiert

Führe den Befehl in einem interaktiven Terminal aus, um den offiziellen Installer zu bestätigen, oder installiere MiniMax Code selbst und führe den Befehl erneut mit `--skip-install` aus.

### Anbieter oder Modell werden nicht aufgeführt

Nutze `phaseo minimax --catalog all` oder gib die Modell-ID mit `--model` an.

### Du brauchst ACP statt der interaktiven CLI

`phaseo minimax` startet die interaktive CLI. MiniMax Code läuft mit `mcode acp` auch als ACP-Prozess. Nutze die ACP-Konfiguration von MiniMax Code, wenn dein Editor oder Host direkt ACP spricht.
