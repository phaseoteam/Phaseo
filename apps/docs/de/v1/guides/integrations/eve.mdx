Übergib deinem [eve](https://eve.dev)-Agent ein Modell aus dem [Phaseo AI SDK Provider](./ai-sdk.mdx), dann läuft jeder Modellaufruf über Phaseo, mit deinem Routing, deinen Schlüsseln, Budgets und Protokollen. eve akzeptiert jedes AI-SDK-Sprachmodell.

## Installieren

eve nutzt AI SDK 7, installiere also `@phaseo/ai-sdk-provider` in Version 2.0.1 oder neuer:

```bash
npm install @phaseo/ai-sdk-provider
```

Setze `PHASEO_API_KEY` in `.env.local` für `eve dev` und in der Serverumgebung jedes Deployments. Die `/login`-Verbindung von eve funktioniert nur auf deinem Rechner.

## Einen eve-Agent auf Phaseo richten

```ts agent/agent.ts
import { defineAgent } from "eve";
import { phaseo } from "@phaseo/ai-sdk-provider";

export default defineAgent({
	model: phaseo("openai/gpt-6-astra"),
	modelContextWindowTokens: 922_000,
	reasoning: "low",
});
```

Übergib ein Modellobjekt wie `phaseo("openai/gpt-6-astra")`. Ein einfacher Modell-ID-String wird nicht an Phaseo gesendet. Setze `modelContextWindowTokens` auf den Wert `limits.input_tokens` des Modells aus dem [Models-Endpunkt](../../api-reference/endpoint/models.mdx). eve kann das Kontextfenster eines Modellobjekts nicht nachschlagen und entscheidet anhand dieser Zahl, wann die Unterhaltung komprimiert wird.

Führe den Agent einmal aus und prüfe, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Pro Turn ein Modell wählen

`defineDynamic` läuft vor jedem Modellaufruf. Gib ein Auswahlobjekt zurück, damit jedes Modell sein eigenes Kontextfenster behält:

```ts agent/agent.ts
import { defineAgent } from "eve";
import { defineDynamic } from "eve/models";
import { phaseo } from "@phaseo/ai-sdk-provider";

export default defineAgent({
	model: defineDynamic((ctx) =>
		ctx.session.auth.initiator?.attributes.plan === "enterprise"
			? { model: phaseo("openai/gpt-6-sol"), modelContextWindowTokens: 1_050_000 }
			: { model: phaseo("openai/gpt-6-luna"), modelContextWindowTokens: 1_050_000 },
	),
});
```

## Bekannte Einschränkungen

- Tools, Streaming, Reasoning, Komprimierung und Prompt-Caching funktionieren über Phaseo. Prompt-Cache-Lesevorgänge erscheinen in den Nutzungs-Events von eve und in den Phaseo-Protokollen.
- eve lässt die Kosten jedes Laufs bei Modellobjekten leer. Die Kosten siehst du auf der Phaseo-Seite **Nutzung** oder unter **Protokolle**.
