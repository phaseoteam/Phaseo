Erstelle ein `OpenAILike`-LLM mit deinem Phaseo-Schlüssel und `api_base="https://api.phaseo.app/v1"` und lege es als Standard von LlamaIndex fest, damit die Generierung in deinen RAG-Workflows über Phaseo läuft.

## Installieren

```bash
pip install llama-index llama-index-llms-openai-like llama-index-embeddings-openai-like
```

## LlamaIndex auf Phaseo richten

```python
import os
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    is_chat_model=True,
)

response = llm.complete("Write one sentence about retrieval quality.")
print(response)
```

Wird ein Satz ausgegeben, funktioniert die Einrichtung. `OpenAILike` ist die Klasse von LlamaIndex für OpenAI-kompatible APIs von Drittanbietern.

## In einem Index verwenden

```python
from llama_index.core import Settings

Settings.llm = llm
```

Baue oder befrage deinen Index dann wie gewohnt.

## Bekannte Einschränkungen

- Die Standardeinstellungen von LlamaIndex zeigen nicht auf Phaseo. Lege Generierungs- und Embedding-Modell ausdrücklich fest.
- Für Phaseo-[Embeddings](../../api-reference/endpoint/embeddings.mdx) konfigurierst du das Embedding-Modell mit einer Phaseo-Modell-ID und derselben Base URL.
