Erstelle mit der Phaseo CLI eine lokale Continue-Konfiguration für IDE-Erweiterungen und die Befehlszeilenschnittstelle `cn` oder füge dieselben Modell- und Geheimniswerte manuell in deine bestehende Continue-Konfiguration ein.

## Mit der Phaseo CLI einrichten

```bash
phaseo login
phaseo continue --model anthropic/claude-sonnet-4.6
```

Wenn `~/.continue/config.yaml` und `~/.continue/.env` noch nicht verwendet werden, erstellt das Setup beide Dateien:

```yaml
name: Phaseo
version: 1.0.0
schema: v1
models:
  - name: Phaseo
    provider: openai
    model: anthropic/claude-sonnet-4.6
    apiBase: https://api.phaseo.app/v1
    apiKey: ${{ secrets.PHASEO_API_KEY }}
    useResponsesApi: false
    roles: [chat, edit, apply]
```

Der Schlüssel wird in `~/.continue/.env` als `PHASEO_API_KEY` gespeichert. `useResponsesApi: false` leitet Anfragen weiterhin über den Chat-Completions-Pfad von Phaseo.

<Warning>
Die globale `.env`-Datei von Continue enthält Klartext. Committe sie niemals. IDE-Erweiterungen übernehmen normale Shell-Umgebungsvariablen nicht, daher verwendet die CLI die von Continue dokumentierte Secret-Datei.
</Warning>

Wenn eine der beiden Dateien bereits eine Konfiguration enthält, stoppt das Setup, ohne sie zu überschreiben. Füge den Modelle-Eintrag und `PHASEO_API_KEY=<dedicated key>` in die vorhandene `.env`-Datei ein. Rufe den Schlüssel mit `phaseo integrations credential continue` ab.

## Überprüfen

Lade in VS Code oder JetBrains das Fenster neu, öffne Continue, wähle **Phaseo** aus und bitte es um die Antwort `PHASEO_CONTINUE_OK`.

Führe für die Continue-CLI `cn` aus. Verwende `/config`, falls eine andere gespeicherte Konfiguration aktiv ist, und sende dann dieselbe Testanfrage. Prüfe, ob sie in den Phaseo-Aktivitäten erscheint.

## Entfernen

```bash
phaseo integrations remove continue
```

Beim Entfernen wird der Schlüssel widerrufen und beide Dateien werden nur gelöscht, wenn sie noch den Eigentumsmarker der Phaseo-CLI enthalten. Manuell eingefügte Einträge bleiben unverändert.

## Fehlerbehebung

### Phaseo wird nicht angezeigt

Lade die IDE neu und prüfe, ob `config.yaml` die erforderlichen Felder der obersten Ebene `name`, `version` und `schema` enthält.

### Continue meldet ein fehlendes Secret

Prüfe, ob `~/.continue/.env` den von `phaseo integrations credential continue` ausgegebenen Schlüssel enthält, und starte die IDE anschließend neu.

### Continue ruft die Responses API auf

Belasse `useResponsesApi: false` im Modelle-Eintrag für Phaseo.
