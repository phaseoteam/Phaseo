Führe `phaseo continue` aus, um eine Continue-Konfiguration zu schreiben, die auf Phaseo zeigt, oder füge denselben Modelleintrag und dasselbe Secret zu deiner bestehenden Konfiguration hinzu. Die IDE-Erweiterungen und die `cn`-CLI teilen sich die Konfiguration.

## Mit der Phaseo CLI einrichten

```bash
phaseo login
phaseo continue --model anthropic/claude-sonnet-5.5
```

Wenn `~/.continue/config.yaml` und `~/.continue/.env` nicht existieren, erstellt die Einrichtung einen `Phaseo CLI: Continue API Key` (Ablauf nach 90 Tagen, monatliches Ausgabenlimit von $100) und schreibt beide Dateien. Ohne `--model` verwendet sie `anthropic/claude-sonnet-4.6`.

```yaml ~/.continue/config.yaml
# Managed by Phaseo CLI
name: Phaseo
version: 1.0.0
schema: v1
models:
  - name: "anthropic/claude-sonnet-5.5 via Phaseo"
    provider: openai
    model: "anthropic/claude-sonnet-5.5"
    apiBase: https://api.phaseo.app/v1
    apiKey: ${{ secrets.PHASEO_API_KEY }}
    useResponsesApi: false
    roles: [chat, edit, apply]
```

Der Schlüssel steht in `~/.continue/.env` als `PHASEO_API_KEY`. `useResponsesApi: false` hält Continue auf dem Chat-Completions-Endpunkt von Phaseo.

<Warning>
Die globale `.env` von Continue ist Klartext. Committe sie niemals. IDE-Erweiterungen übernehmen keine Umgebungsvariablen aus der Shell, deshalb nutzt die CLI die Datei für [lokale Secrets](https://docs.continue.dev/faqs#managing-local-secrets-and-environment-variables) von Continue.
</Warning>

## Continue manuell konfigurieren

Enthält eine der beiden Dateien bereits eigene Einstellungen, hält die Einrichtung an, ohne sie zu ändern. Füge den obigen Modelleintrag zu deiner `config.yaml` hinzu und ergänze `PHASEO_API_KEY=<key>` in deiner `.env`, mit dem Schlüssel aus `phaseo integrations credential continue` oder einem beliebigen Phaseo-API-Schlüssel. Die übrigen Felder beschreibt die Continue-Dokumentation zum [OpenAI-Anbieter](https://docs.continue.dev/customize/model-providers/top-level/openai).

## Prüfen, ob es funktioniert

Lade in VS Code oder JetBrains das Fenster neu, öffne Continue, wähle **Phaseo** und bitte es, mit `PHASEO_CONTINUE_OK` zu antworten. In der CLI führst du `cn` aus (nutze `/config`, wenn eine andere Konfiguration aktiv ist) und sendest denselben Prompt. Prüfe, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Phaseo entfernen

```bash
phaseo integrations remove continue
```

Damit wird der Schlüssel widerrufen, und beide Dateien werden nur gelöscht, wenn sie noch mit der Phaseo-CLI-Markierung beginnen. Einträge, die du selbst zusammengeführt hast, bleiben unangetastet.

## Häufige Probleme beheben

### Phaseo erscheint nicht

Lade die IDE neu und prüfe, ob `config.yaml` die Felder `name`, `version` und `schema` auf oberster Ebene enthält.

### Continue meldet ein fehlendes Secret

Prüfe, ob `~/.continue/.env` den Schlüssel aus `phaseo integrations credential continue` enthält, und starte dann die IDE neu.

### Continue ruft die Responses API auf

Behalte `useResponsesApi: false` im Phaseo-Modelleintrag bei.
