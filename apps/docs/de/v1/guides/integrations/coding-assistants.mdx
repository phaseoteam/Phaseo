Führe `phaseo login` und dann `phaseo <agent>` aus, um einen Coding-Agent mit eigenem API-Schlüssel auf Phaseo zu richten. Ohne die CLI trägst du die [manuellen Anbieterwerte](#enter-the-provider-values-yourself) in den Einstellungen des Agents ein.

```bash
phaseo login
phaseo codex
```

## Den Befehl für deinen Agent finden

Die CLI richtet jeden Agent auf eine von drei Arten ein:

- **Konfiguriert**: Die CLI schreibt die Konfigurationsdatei des Agents. Starte den Agent und wähle ein Phaseo-Modell.
- **Nur Schlüssel**: Der Agent speichert Schlüssel in seinem eigenen App-Speicher, daher erstellt die CLI den Schlüssel und gibt die auszufüllenden Felder aus.
- **Sitzung**: Die CLI startet den Agent mit temporären Einstellungen, die beim Beenden gelöscht werden. Deine normale Konfiguration bleibt unberührt.

| Codex | `phaseo codex` | Konfiguriert | [Codex](./codex.mdx) |
| OpenCode | `phaseo opencode` | Konfiguriert | [OpenCode](./opencode.mdx) |
| fx | `phaseo fx` | Konfiguriert | [fx](./fx.mdx) |

Wie du die CLI installierst, steht in der [Anleitung zur Phaseo CLI](./phaseo-cli.mdx).

## Was die CLI erstellt

Jeder Agent bekommt einen eigenen API-Schlüssel, der nach ihm benannt ist (zum Beispiel `Phaseo CLI: Codex API Key`), mit einem monatlichen Ausgabenlimit von $100 und einem Ablauf nach 90 Tagen. Jeden neuen Schlüssel genehmigst du auf einer Dashboard-Seite, die die CLI öffnet; danach holt die CLI ihn einmal ab, siehe [Den Schlüssel im Browser genehmigen](./phaseo-cli.mdx#approve-the-key-in-your-browser). Führe den Einrichtungsbefehl erneut aus, um einen abgelaufenen Schlüssel zu ersetzen, und ändere das Limit im Dashboard unter **Einstellungen → API-Schlüssel**.

Fehlt Claude Code, Codex, OpenCode, fx, DeepSeek Harness, Pi, Prime Agent, OpenClaw oder Hermes Agent, zeigt die CLI den offiziellen Installationsbefehl an und fragt nach, bevor sie ihn ausführt. Außerhalb eines interaktiven Terminals gibt sie den Installationsbefehl aus und hält an. OpenCode, fx, DeepSeek Harness, Pi, Prime Agent und OpenClaw erhalten außerdem jedes aktive Phaseo-Textmodell, das mit Chat Completions funktioniert.

| Flag oder Befehl | Wirkung |
| --- | --- |
| `--model <id>` | Legt das Standardmodell fest. Für Claude Code nicht unterstützt. |
| `--catalog default` | Fügt nur das ausgewählte Modell statt des ganzen Katalogs hinzu. |
| `--skip-install` | Überspringt die Installationsprüfung, für einen Agent, den du selbst verwaltest. |
| `--dry-run` | Zeigt die Dateiänderungen an, ohne sie vorzunehmen. |
| `--key <key>` | Verwendet einen Schlüssel, den du im Dashboard erstellt hast, statt einen neuen anzufordern. `--key-stdin` liest ihn von der Standardeingabe. |
| `phaseo integrations credential <agent>` | Gibt den Schlüssel dieses Agents aus, für Agents, in die du ihn einfügst. |
| `phaseo integrations remove <agent>` | Löscht die von Phaseo geschriebene Konfiguration und widerruft den Schlüssel. Deine anderen Einstellungen bleiben erhalten. |

## Die Anbieterwerte selbst eintragen

Verwende diese Werte in jedem Agent mit einem OpenAI-kompatiblen Anbieter. Die Feldnamen unterscheiden sich je nach Tool.

| Einstellung | Wert |
| --- | --- |
| Anbietertyp | OpenAI Compatible |
| Base URL | `https://api.phaseo.app/v1` |
| API-Schlüssel | Ein Phaseo-API-Schlüssel |
| Modell | Eine Phaseo-Modell-ID, etwa `openai/gpt-6-astra` |

Für Agents, die die Anthropic Messages API sprechen:

| Einstellung | Wert |
| --- | --- |
| Base URL | `https://api.phaseo.app` (der Client hängt `/v1/messages` an) |
| Auth-Token | Ein Phaseo-API-Schlüssel |
| Modell | Eine Phaseo-Modell-ID, etwa `anthropic/claude-sonnet-5.5` |

Manche Agents lehnen Modell-IDs ab, die `/` enthalten. Wenn deiner das tut und Aliase unterstützt, lege einen lokalen Alias an, der auf die Phaseo-Modell-ID verweist.

## Agents ohne eigene Anleitung

### VS Code

VS Code kann Modelle in seinem Language-Models-Editor hinzufügen, wenn dein Build einen OpenAI-kompatiblen Anbieter enthält.

1. Öffne die Befehlspalette und führe `Chat: Manage Language Models` aus.
2. Wähle `OpenAI Compatible` oder `OAI Compatible`.
3. Gib deinen Phaseo-API-Schlüssel ein und setze den Endpunkt auf `https://api.phaseo.app/v1`.
4. Füge eine Phaseo-Modell-ID hinzu, etwa `openai/gpt-6-astra`, und wähle sie in der Modellauswahl des Chats aus.

Hat dein Build keinen OpenAI-kompatiblen Anbieter, nutze eine Erweiterung, die benutzerdefinierte Anbieter unterstützt: [Continue](./continue.mdx), [Cline](./cline.mdx), [Roo Code](./roo-code.mdx) oder [Kilo Code](./kilo-code.mdx).

### Claude Desktop

Claude Desktop kann keinen benutzerdefinierten Modellanbieter verwenden. Füge [Docs MCP](./docs-mcp.mdx) hinzu, um ihm die Phaseo-Dokumentation zu geben, und nutze [Claude Code](./claude-code.mdx), wenn du Phaseo als Modell-Gateway brauchst.

### Deep Agents CLI und andere LangChain-Tools

Verwende die Base URL und den Schlüssel aus [LangChain](./langchain.mdx). Liest das Tool OpenAI-Umgebungsvariablen, setze diese und gib im Modellfeld eine Phaseo-Modell-ID an:

```bash
export OPENAI_API_KEY="your_phaseo_api_key"
export OPENAI_BASE_URL="https://api.phaseo.app/v1"
```

## Bekannte Einschränkungen

- Server-Tools funktionieren nur dort, wo der Agent sie sendet: `phaseo:apply_patch` ist nur auf [Responses](../../api-reference/endpoint/responses.mdx) verfügbar. Ältere Agents, die Responses-Events oder [Server-Tools](../server-tools/index.mdx) nicht verarbeiten, sind mit [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) sicherer.
- Sende eine kurze Chat-Anfrage, bevor du einen Agent Dateien bearbeiten lässt, und wähle für Agent-Arbeit ein Modell mit Unterstützung für Tool-Aufrufe.
- Füge [Docs MCP](./docs-mcp.mdx) hinzu, wenn der Agent während einer Sitzung die Phaseo-Dokumentation lesen soll.
