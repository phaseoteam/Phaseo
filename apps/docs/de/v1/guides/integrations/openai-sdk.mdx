Richte das offizielle OpenAI SDK auf Phaseo, indem du drei Dinge änderst: den API-Schlüssel, die Base URL (`https://api.phaseo.app/v1`) und die Modell-ID.

## Installieren

<CodeGroup>

```bash TypeScript
npm install openai
```

```bash Python
pip install openai
```

</CodeGroup>

## Den Client auf Phaseo richten

<CodeGroup>

```ts TypeScript
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Write one sentence about reliable model routing.",
});

console.log(response.output_text);
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Write one sentence about reliable model routing.",
)

print(response.output_text)
```

</CodeGroup>

Wird ein Satz ausgegeben, funktionieren Schlüssel und Base URL. Die Anfrage erscheint außerdem unter **Einstellungen → Nutzung → Protokolle**.

## Chat Completions verwenden

Code, der Chat Completions aufruft, funktioniert mit demselben Client:

```ts
const completion = await client.chat.completions.create({
	model: "openai/gpt-6-astra",
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## Bekannte Einschränkungen

- Verwende Phaseo-Modell-IDs mit Anbieterpräfix: `openai/`, `anthropic/`, `google/` und so weiter. Die vollständigen Anfrageformate findest du unter [Responses](../../api-reference/endpoint/responses.mdx) und [Chat Completions](../../api-reference/endpoint/chat-completions.mdx).
- [Server-Tools](../server-tools/index.mdx) verwenden Phaseo-Tool-Namen, etwa `phaseo:web_search`.
- Für `/v1/messages`-Clients im Anthropic-Stil nutze die Anleitung zum [Anthropic SDK](./anthropic-sdk.mdx).
