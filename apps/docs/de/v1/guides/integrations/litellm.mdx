Gib LiteLLM das Modell `openai/<Phaseo-Modell-ID>`, deinen Phaseo-Schlüssel und `api_base="https://api.phaseo.app/v1"`. Das funktioniert für direkte LiteLLM-Aufrufe und für Modelle hinter einem LiteLLM-Proxy.

## Installieren

```bash
pip install litellm
```

## Phaseo aus LiteLLM aufrufen

```python
import os
from litellm import completion

response = completion(
    model="openai/openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(response.choices[0].message.content)
```

Wird `ok` ausgegeben, funktioniert die Einrichtung. LiteLLM verwendet das Präfix `openai/` für OpenAI-kompatible Endpunkte. Die Phaseo-Modell-ID bleibt `openai/gpt-6-astra`, der LiteLLM-Modellstring wird also zu `openai/openai/gpt-6-astra`.

## Phaseo-Modelle zu einem LiteLLM-Proxy hinzufügen

Gib jedem Modell einen Alias, damit der Anwendungscode das LiteLLM-Präfix nicht braucht:

```yaml
model_list:
  - model_name: phaseo-gpt-6-astra
    litellm_params:
      model: openai/openai/gpt-6-astra
      api_key: os.environ/PHASEO_API_KEY
      api_base: https://api.phaseo.app/v1
```

Rufe den Proxy dann mit `model: "phaseo-gpt-6-astra"` auf. Aliase halten Modellnamen in der Produktion lesbar.

## Bekannte Einschränkungen

- Manche Proxy-Schichten ändern oder verwerfen Tool-Typen, die sie nicht kennen. Wenn du Phaseo-[Server-Tools](../server-tools/index.mdx) nutzt, teste genau deine LiteLLM-Route.
- Sowohl LiteLLM als auch Phaseo erfassen Ausgaben. Entscheide, welches System für Kosten maßgeblich ist. Die Preise von Phaseo stehen im [Preisrechner](../../api-reference/endpoint/pricing-calculate.mdx).
