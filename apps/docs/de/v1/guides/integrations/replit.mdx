Füge `PHASEO_API_KEY` zu Replit Secrets hinzu und rufe Phaseo dann mit dem [OpenAI SDK](./openai-sdk.mdx) oder dem [Phaseo AI SDK Provider](./ai-sdk.mdx) auf. Halte den Schlüssel aus deinem Quellcode heraus.

## Das Secret hinzufügen

Öffne in deinem Replit-Workspace **Tools → Secrets** und füge Folgendes hinzu:

```text
PHASEO_API_KEY=phaseo_v1_sk_...
```

Replit stellt das Secret deiner App als Umgebungsvariable bereit. Die Schlüsseltypen beschreibt [Authentifizierung](../../developers/authentication.mdx).

## Phaseo aufrufen

<CodeGroup>

```ts OpenAI SDK
// npm install openai
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Reply with only: ok",
});

console.log(response.output_text);
```

```ts AI SDK
// npm install @phaseo/ai-sdk-provider
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const { text } = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Reply with only: ok",
});

console.log(text);
```

</CodeGroup>

Wird `ok` ausgegeben, funktionieren Secret und Base URL.

## Bereitstellen

Füge `PHASEO_API_KEY` sowohl zu den Secrets des Deployments als auch zum Workspace hinzu. Achte darauf, dass das Deployment keine Umgebungsvariablen oder Anfrage-Header in seine Protokolle schreibt.
