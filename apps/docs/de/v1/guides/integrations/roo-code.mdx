Führe `phaseo roo-code` aus, um einen Schlüssel zu erstellen, und füge dann in Roo Code ein **OpenAI Compatible**-Profil hinzu. Roo Code speichert Schlüssel im Secret Storage von VS Code, deshalb findet dieser letzte Schritt in seiner Oberfläche statt.

## Mit der Phaseo CLI einrichten

```bash
phaseo login
phaseo roo-code --model anthropic/claude-sonnet-5.5
```

Die CLI erstellt einen `Phaseo CLI: Roo Code API Key`, der nach 90 Tagen abläuft und ein monatliches Ausgabenlimit von $100 hat, und gibt dann die Werte für den nächsten Schritt aus.

## Roo Code konfigurieren

1. Öffne Roo Code in VS Code und dann **Settings → Providers**.
2. Erstelle ein Profil für die Anbieterkonfiguration und wähle **OpenAI Compatible**.
3. Gib Folgendes ein:

| Roo-Code-Feld | Wert |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | Ausgabe von `phaseo integrations credential roo-code` oder ein beliebiger Phaseo-API-Schlüssel |
| Model | `anthropic/claude-sonnet-5.5` oder das Modell, das die Einrichtung ausgibt |

4. Speichere das Profil und aktiviere es.

Die Feldbezeichnungen ändern sich von Version zu Version leicht. Weichen deine ab, siehe die Roo-Code-Dokumentation zu [Modellanbietern](https://docs.roocode.com/providers/).

## Prüfen, ob es funktioniert

Bitte Roo Code, mit `PHASEO_ROO_OK` zu antworten, und prüfe dann, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Phaseo entfernen

Lösche das Phaseo-Profil oder wechsle das Profil und führe dann aus:

```bash
phaseo integrations remove roo-code
```

Damit wird der Schlüssel widerrufen. Die CLI kann den Erweiterungsspeicher von VS Code nicht leeren.

## Häufige Probleme beheben

### Die Authentifizierung schlägt fehl

Kopiere den Schlüssel erneut mit `phaseo integrations credential roo-code` und prüfe, ob die Base URL auf `/v1` endet.

### Roo Code findet das Modell nicht

Gib die exakte Phaseo-Modell-ID einschließlich ihres Anbieterpräfixes ein.

### Der Chat funktioniert, aber Tools schlagen fehl

Wechsle zu einem Modell mit Unterstützung für Tool-Aufrufe.
