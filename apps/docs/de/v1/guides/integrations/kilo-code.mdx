Führe `phaseo kilo` aus, um eine Kilo-Code-CLI-Sitzung über Phaseo zu starten, oder erstelle mit `phaseo kilo-code` einen Schlüssel und füge in der Kilo-Code-Erweiterung einen benutzerdefinierten Anbieter hinzu.

## Die Kilo Code CLI über Phaseo ausführen

```bash
phaseo login
phaseo kilo --model openai/gpt-5.6-terra
```

Der Runner schreibt eine temporäre `KILO_CONFIG`-Datei, startet `kilo` und löscht die Datei, wenn Kilo beendet wird. Deine bestehende Kilo-Code- oder VS-Code-Einrichtung bleibt also unverändert. Fehlt Kilo, bietet ein interaktiver Lauf die Installation an. Setze die eigenen Flags von Kilo hinter `--`.

| Flag | Wirkung |
| --- | --- |
| `--model <id>` | Zu verwendendes Modell. Standard ist `openai/gpt-5.6-terra`. |
| `--catalog all` | Listet jedes aktive Phaseo-Textmodell in Kilo auf, nicht nur das ausgewählte. |
| `--dry-run --json` | Zeigt den Installations- und Startplan, ohne einen Schlüssel zu erstellen oder Kilo zu starten. |
| `--skip-install` | Überspringt die Installationsprüfung. |

`phaseo run kilo ...` ist die Langform desselben Befehls.

## Die Kilo-Code-Erweiterung konfigurieren

Erstelle einen Schlüssel für die Erweiterung:

```bash
phaseo login
phaseo kilo-code --model anthropic/claude-sonnet-5.5
```

Dann in VS Code:

1. Öffne Kilo Code, wähle das Einstellungssymbol, öffne **Providers** und wähle dann **Add custom provider**.
2. Gib Folgendes ein:

| Kilo-Code-Feld | Wert |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.phaseo.app/v1` |
| API key | Ausgabe von `phaseo integrations credential kilo-code` |

3. Wird kein Modell erkannt, füge die ID `anthropic/claude-sonnet-5.5` selbst hinzu.
4. Wähle **Submit** und dann das Phaseo-Modell.

Kilo zeigt die Auswahl als `phaseo/anthropic/claude-sonnet-5.5` an. `phaseo` ist die lokale Provider ID, der Rest ist die Modell-ID, die an Phaseo gesendet wird. Die vollständige Form beschreibt Kilos Dokumentation zu [benutzerdefinierten Modellen](https://kilo.ai/docs/code-with-ai/agents/custom-models).

## Prüfen, ob es funktioniert

Bitte Kilo Code, mit `PHASEO_KILO_OK` zu antworten, und prüfe dann, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Phaseo entfernen

Lösche den benutzerdefinierten Anbieter in Kilo Code und führe dann aus:

```bash
phaseo integrations remove kilo-code
```

Damit wird der Schlüssel widerrufen. Die CLI kann den Speicher der Erweiterung nicht leeren.

## Häufige Probleme beheben

### Es werden keine Modelle erkannt

Füge das Modell selbst hinzu. Kilo braucht keine Erkennung über `/models`.

### Die Authentifizierung schlägt fehl

Ersetze den gespeicherten Schlüssel durch die Ausgabe von `phaseo integrations credential kilo-code` und übernimm die Base URL genau wie angegeben.

### Der Modellname sieht anders aus

Wähle in Kilo `phaseo/<Phaseo-Modell-ID>`, füge aber im Feld für die Modell-ID kein `phaseo/` hinzu.
