Die meisten Observability-Tools sitzen oberhalb des Modell-Clients. Behalte deine Trace-Konfiguration bei und richte den zugrunde liegenden OpenAI- oder Anthropic-kompatiblen Client auf Phaseo aus.

## Langfuse mit dem OpenAI-SDK

```bash
pip install langfuse openai
```

```python
import os
from langfuse.openai import openai

client = openai.OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-5-nano",
    input="Reply with only: ok",
)
```

## LangSmith mit LangChain

Nutze die [LangChain](./langchain.mdx)-Einrichtung und aktiviere LangSmith über die üblichen LangChain-Umgebungsvariablen:

```bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your_langsmith_key"
export PHASEO_API_KEY="your_phaseo_key"
```

## OpenTelemetry

Wenn dein Framework OpenTelemetry-Spans erzeugt, ist bei Phaseo kein spezieller Exporter nötig. Ergänze den hilfreichen Request-Kontext selbst:

- Modell-ID
- Endpunkt, zum Beispiel `responses` oder `chat.completions`
- Phaseo-Request-ID aus Antwortmetadaten oder Logs
- Ausgewählter Anbieter, wenn Antwortmetadaten aktiviert sind

## Hinweise

- Sende Phaseo-API-Schlüssel nicht als Attribute an Observability-Tools.
- Wenn die Observability-Bibliothek das OpenAI-SDK umschließt, konfiguriere den umschlossenen Client mit `base_url: "https://api.phaseo.app/v1"`.
- Kombiniere bei LangChain-Traces den Trace-Callback mit der Phaseo-Konfiguration für `ChatOpenAI`.
