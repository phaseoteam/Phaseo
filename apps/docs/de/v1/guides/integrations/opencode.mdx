Führe `phaseo opencode` aus, um OpenCode einen Phaseo-Anbieter mit jedem kompatiblen Phaseo-Modell hinzuzufügen, oder trage selbst einen `phaseo`-Anbieter in `opencode.json` ein.

## Mit der Phaseo CLI einrichten

```bash
phaseo login
phaseo opencode --model openai/gpt-5.6-terra
```

Fehlt OpenCode, zeigt die CLI den offiziellen Installationsbefehl an und fragt nach, bevor sie ihn ausführt. Danach geht die Einrichtung so vor:

- Sie fügt einen globalen `phaseo`-Anbieter mit jedem aktiven Phaseo-Textmodell hinzu, das mit Chat Completions funktioniert. Sie aktualisiert deine globale `opencode.jsonc`, falls vorhanden, andernfalls `~/.config/opencode/opencode.json`, und lässt deine anderen Einstellungen unangetastet.
- Sie erstellt einen `Phaseo CLI: OpenCode API Key`, der nach 90 Tagen abläuft und ein monatliches Ausgabenlimit von $100 hat, und legt ihn im Anmeldeinformationsspeicher von OpenCode ab. Die CLI behält eine eigene Kopie im Anmeldeinformationsspeicher des Betriebssystems. Führe `phaseo opencode` erneut aus, um einen abgelaufenen Schlüssel zu ersetzen.

Mit `--catalog default` wird nur das ausgewählte Modell hinzugefügt, mit `--dry-run` siehst du die Änderungen vorab.

## OpenCode manuell konfigurieren

Füge den Anbieter zu `opencode.json` in deinem Projekt oder zu deiner globalen OpenCode-Konfiguration hinzu:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-6-astra",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-6-astra": { "name": "GPT-6 Astra" },
        "openai/gpt-5.4-mini": { "name": "GPT-5.4 Mini" },
        "anthropic/claude-sonnet-5.5": { "name": "Claude Sonnet 5.5" }
      }
    }
  }
}
```

Exportiere `PHASEO_API_KEY` und füge Einträge in `models` hinzu oder entferne sie, um festzulegen, welche Phaseo-Modelle OpenCode auflistet.

## Prüfen, ob es funktioniert

Starte OpenCode neu, wähle über `/models` ein Phaseo-Modell und sende einen kurzen Prompt, bevor du mit Arbeiten beginnst, die Dateien bearbeiten. Prüfe, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Phaseo entfernen

```bash
phaseo integrations remove opencode
```

Damit werden nur der Phaseo-Anbieter und seine gespeicherten Anmeldeinformationen entfernt und anschließend der Schlüssel widerrufen.

## Häufige Probleme beheben

| Problem | Lösung |
| --- | --- |
| Ein Modell wird abgelehnt | Prüfe die exakte ID mit dem [Models-Endpunkt](../../api-reference/endpoint/models.mdx). |
| Die Authentifizierung schlägt fehl | Führe `phaseo opencode` erneut aus und prüfe `opencode auth list`. |

Damit OpenCode während einer Sitzung die Phaseo-Dokumentation lesen kann, füge den [Docs MCP](./docs-mcp.mdx)-Server hinzu.
