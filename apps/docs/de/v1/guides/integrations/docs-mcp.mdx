---

Füge `https://phaseo.app/docs/mcp` deinem Coding-Agent als MCP-Server hinzu, damit er Fragen zu Phaseo anhand der aktuellen Dokumentation beantwortet statt anhand seiner Trainingsdaten. Der Server ist schreibgeschützt: Agents können die Dokumentation durchsuchen, vollständige Seiten lesen und die gehostete Fähigkeitsübersicht [skill.md](https://phaseo.app/docs/skill.md) lesen.

## Codex

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
codex mcp list
```

## Claude Code

Füge den Server dem aktuellen Projekt hinzu, oder ergänze `--scope user`, um ihn in jedem Projekt verfügbar zu machen:

```bash
claude mcp add --transport http phaseo-docs https://phaseo.app/docs/mcp
claude mcp add --transport http --scope user phaseo-docs https://phaseo.app/docs/mcp
claude mcp list
```

## Cursor

Installiere ihn über das Kontextmenü auf einer beliebigen Dokumentationsseite oder füge ihn der MCP-Konfiguration von Cursor hinzu:

```json
{
  "mcpServers": {
    "phaseoDocs": {
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## VS Code

Installiere ihn über das Kontextmenü auf einer beliebigen Dokumentationsseite oder füge ihn der MCP-Konfiguration von VS Code hinzu:

```json
{
  "servers": {
    "phaseoDocs": {
      "type": "http",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## OpenCode

Füge ihn zu `opencode.json` hinzu:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "phaseoDocs": {
      "type": "remote",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## Prüfen, ob es funktioniert

Stell dem Agent eine Frage, die nur die Dokumentation beantworten kann, und prüfe, ob er den Phaseo-Docs-Server aufruft:

- `Look up the Responses request format in the Phaseo docs and give me a minimal example.`
- `Use the Phaseo docs MCP server to check how provider.sort works before you change this request.`
- `Find the guardrails docs in Phaseo and summarize the parts that affect provider routing.`

Agents nutzen ihn, um Anfrageformate zu prüfen, welche Endpunkte ein Modell oder Anbieter unterstützt und wie sich Routing, Presets, Guardrails und asynchrone Jobs verhalten. Der Docs-Server macht Phaseo nicht zu deinem Modell-Gateway. Dafür siehe [Coding-Agents](./coding-assistants.mdx).
