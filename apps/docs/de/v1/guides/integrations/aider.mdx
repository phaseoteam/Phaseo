Führe `phaseo aider` aus, um eine Aider-Konfiguration zu schreiben, die auf Phaseo zeigt, oder füge drei Zeilen zu deiner bestehenden `.aider.conf.yml` hinzu.

## Mit der Phaseo CLI einrichten

```bash
phaseo login
phaseo aider --model anthropic/claude-sonnet-5.5
```

Wenn `~/.aider.conf.yml` nicht existiert, erstellt die Einrichtung einen `Phaseo CLI: Aider API Key` (Ablauf nach 90 Tagen, monatliches Ausgabenlimit von $100) und schreibt diese Datei. Ohne `--model` wird `anthropic/claude-sonnet-4.6` verwendet.

```yaml ~/.aider.conf.yml
# Managed by Phaseo CLI
model: openai/anthropic/claude-sonnet-5.5
openai-api-base: https://api.phaseo.app/v1
openai-api-key: "<dedicated Phaseo key>"
```

Aider braucht das Präfix `openai/`, um ein benutzerdefiniertes Modell über seinen OpenAI-kompatiblen Adapter zu senden. An Phaseo wird trotzdem das Modell `anthropic/claude-sonnet-5.5` gesendet.

<Warning>
Der Schlüssel wird im Klartext gespeichert, weil `.aider.conf.yml` einer der dokumentierten Speicherorte für Schlüssel in Aider ist. Mach die Datei nur für dein Benutzerkonto lesbar und committe sie nie.
</Warning>

## Aider manuell konfigurieren

Wenn du bereits eine Aider-Konfiguration hast, bricht die CLI ab, ohne sie zu ändern. Kopiere die drei Einstellungen oben in die Konfiguration, die Aider laden soll, und verwende für `openai-api-key` die Ausgabe von `phaseo integrations credential aider` oder einen beliebigen Phaseo-API-Schlüssel. Aider liest `.aider.conf.yml` aus deinem Home-Verzeichnis, dem Stammverzeichnis des Repositorys und dem aktuellen Verzeichnis, und spätere Dateien haben Vorrang. Siehe die Aider-Dokumentation zur [YAML-Konfiguration](https://aider.chat/docs/config/aider_conf.html) und zur [OpenAI-kompatiblen API](https://aider.chat/docs/llms/openai-compat.html).

## Prüfen, ob es funktioniert

Öffne ein Repository und starte Aider:

```bash
aider
```

Prüfe, dass die Startausgabe `openai/anthropic/claude-sonnet-5.5` nennt, bitte Aider, mit `PHASEO_AIDER_OK` zu antworten, und bestätige, dass die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

Eine Warnung zu einem unbekannten Modell hält Anfragen nicht auf. Füge Aider-Modellmetadaten nur hinzu, wenn du genaue Schätzungen zu Token-Limits oder Kosten brauchst.

## Phaseo entfernen

```bash
phaseo integrations remove aider
```

Das widerruft den Schlüssel und löscht `~/.aider.conf.yml` nur, wenn die Datei noch mit der Markierung der Phaseo CLI beginnt. Wenn du die Einstellungen in deine eigene Datei übernommen hast, entferne die drei Zeilen selbst.

## Häufige Probleme beheben

### Aider nutzt einen anderen Endpunkt oder ein anderes Modell

Eine `.aider.conf.yml` im Stammverzeichnis des Repositorys oder im aktuellen Verzeichnis überschreibt die in deinem Home-Verzeichnis. Umgebungsvariablen und Befehlszeilenoptionen überschreiben alle.

### Die Authentifizierung schlägt fehl

Vergleiche `openai-api-key` mit der Ausgabe von `phaseo integrations credential aider` und lass `openai-api-base` exakt bei `https://api.phaseo.app/v1`.

### Das Modell kann nicht aufgelöst werden

Behalte das Präfix `openai/` von Aider bei. Das Phaseo-Modell `openai/gpt-6-astra` wird in Aider zu `openai/openai/gpt-6-astra`.
