LiveKit Agents kann über sein OpenAI-Plugin jeden OpenAI-kompatiblen Chat-Endpunkt aufrufen. Richte das Plugin auf Phaseo aus, um Phaseo-Modell-IDs und -Routing zu verwenden.

## Python

```bash
uv add "livekit-agents[openai]"
```

```python
import os
from livekit.agents import AgentSession
from livekit.plugins import openai

session = AgentSession(
    llm=openai.LLM(
        model="openai/gpt-5-nano",
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)
```

## Node.js

```bash
pnpm add @livekit/agents @livekit/agents-plugin-openai
```

```ts
import { voice } from "@livekit/agents";
import * as openai from "@livekit/agents-plugin-openai";

const session = new voice.AgentSession({
	llm: new openai.LLM({
		model: "openai/gpt-5-nano",
		apiKey: process.env.PHASEO_API_KEY,
		baseURL: "https://api.phaseo.app/v1",
	}),
});
```

## Hinweise

- Verwende für benutzerdefinierte Endpunkte den OpenAI-kompatiblen Chat-Completions-Modus.
- Die Responses-spezifischen OpenAI-Tools von LiveKit werden nicht automatisch zu Phaseo-Server-Tools.
- Richte Sprache-zu-Text und Text-zu-Sprache separat ein, sofern die gewählte LiveKit-Schnittstelle für die jeweilige Modalität keine benutzerdefinierte OpenAI-kompatible URL unterstützt.
- Teste Unterbrechungsbehandlung, Tool-Aufrufe und Streaming-Latenz, bevor du Sprachverkehr produktiv schaltest.
