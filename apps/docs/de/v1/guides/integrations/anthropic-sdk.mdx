Richte das Anthropic SDK auf `https://api.phaseo.app` aus und übergib deinen Phaseo-Schlüssel als Auth-Token. Verwende das für Apps, Agenten und Coding-Tools, die Claude-artige `/v1/messages`-Anfragen senden; Phaseo bedient sie als [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx).

## Installieren

<CodeGroup>

```bash TypeScript
npm install @anthropic-ai/sdk
```

```bash Python
pip install anthropic
```

</CodeGroup>

## Den Client auf Phaseo ausrichten

<CodeGroup>

```ts TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
	apiKey: null,
	authToken: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app",
});

const message = await client.messages.create({
	model: "anthropic/claude-sonnet-5.5",
	max_tokens: 512,
	messages: [{ role: "user", content: "Reply with only: ok" }],
});

console.log(message.content);
```

```python Python
import os
from anthropic import Anthropic

client = Anthropic(
    auth_token=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app",
)

message = client.messages.create(
    model="anthropic/claude-sonnet-5.5",
    max_tokens=512,
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(message.content)
```

</CodeGroup>

Ein Textblock mit `ok` bedeutet, dass die Einrichtung funktioniert.

| Einstellung | Warum |
| --- | --- |
| `baseURL: "https://api.phaseo.app"` | Verwende den Root-Host. Anthropic-Clients hängen `/v1/messages` selbst an. |
| `authToken` (`auth_token` in Python) | Sendet in jeder SDK-Version `Authorization: Bearer`. Phaseo akzeptiert kein `x-api-key`, das `apiKey` vor `@anthropic-ai/sdk` 1.0 und `anthropic` 2.0 sendet. |
| `apiKey: null` | Verhindert, dass ältere TypeScript-SDKs zusätzlich deinen `ANTHROPIC_API_KEY` senden. Python-SDKs vor 0.98 senden ihn immer, wenn er gesetzt ist; aktualisiere also oder entferne ihn dort, wo du Phaseo aufrufst. |

## Bekannte Grenzen

- Native Anthropic-Tool-Formate funktionieren, wo Phaseo sie unterstützt. Server-Tools, die anbieterübergreifend funktionieren, verwenden Phaseo-Tool-Namen; siehe [Tool-Aufrufe](../tool-calling.mdx).
- Anthropic-kompatible Clients sind streng bei der Reihenfolge von Tool-Ereignissen. Teste gestreamte Tool-Schleifen vor dem Produktiveinsatz.
- Für [Claude Code](./claude-code.mdx) nutze die eigene Anleitung.
