Führe `phaseo omp` aus, um eine oh-my-pi-Sitzung über Phaseo zu starten, oder füge `~/.omp/agent/models.yml` einen `phaseo`-Anbieter hinzu, damit Phaseo in jeder Sitzung verfügbar bleibt.

## oh-my-pi über die Phaseo CLI ausführen

```bash
phaseo login
phaseo omp --model openai/gpt-5.6-terra
```

Der Runner erstellt einen eigenen Schlüssel, schreibt `models.yml` unter ein temporäres `PI_CODING_AGENT_DIR`, startet `omp` mit `--model phaseo/<model>` und löscht das Verzeichnis, wenn oh-my-pi beendet wird. Fehlt `omp`, bietet der erste interaktive Lauf die Installation an. Setze die eigenen Flags von oh-my-pi hinter `--`.

| Flag | Wirkung |
| --- | --- |
| `--model <id>` | Zu verwendendes Modell. Standard ist `openai/gpt-5.6-terra`. |
| `--catalog all` | Listet jedes aktive Phaseo-Textmodell auf, nicht nur das ausgewählte. |
| `--dry-run --json` | Zeigt den Installations- und Startplan, ohne einen Schlüssel zu erstellen oder oh-my-pi zu starten. |
| `--skip-install` | Überspringt die Installationsprüfung. |

`phaseo run omp ...` ist die Langform desselben Befehls.

## oh-my-pi manuell konfigurieren

Erstelle im Dashboard unter **Einstellungen → API-Schlüssel** einen Schlüssel, exportiere ihn in der Shell, die oh-my-pi startet, und lege das Konfigurationsverzeichnis an:

```bash
export PHASEO_OMP_API_KEY="<your Phaseo API key>"
mkdir -p ~/.omp/agent
```

Füge den Anbieter hinzu:

```yaml ~/.omp/agent/models.yml
providers:
  phaseo:
    baseUrl: https://api.phaseo.app/v1
    api: openai-completions
    apiKey: PHASEO_OMP_API_KEY
    authHeader: true
    models:
      - id: openai/gpt-5.6-terra
        name: GPT-5.6 Terra via Phaseo
        contextWindow: 32768
        maxTokens: 8192
```

`apiKey` nennt die Umgebungsvariable, der Schlüssel bleibt also aus `models.yml` heraus. Füge bei Bedarf weitere Einträge unter `models` hinzu. Die Limits oben sind Beispiele. Starte oh-my-pi mit der anbieterqualifizierten Modell-ID:

```bash
omp --model phaseo/openai/gpt-5.6-terra
```

Die übrigen Felder beschreibt die oh-my-pi-Dokumentation zur [Anbieterkonfiguration](https://github.com/can1357/oh-my-pi/blob/main/docs/providers.md).

## Prüfen, ob es funktioniert

Sende einen kurzen Prompt und prüfe, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Häufige Probleme beheben

### oh-my-pi ist nicht installiert

Führe den Befehl in einem interaktiven Terminal aus, um die Installation zu bestätigen, oder installiere oh-my-pi selbst und führe den Befehl erneut mit `--skip-install` aus.

### Das Modell wird nicht aufgeführt

Nutze `--catalog all` oder gib die Modell-ID mit `--model` an. Phaseo braucht keine Modellerkennung.
