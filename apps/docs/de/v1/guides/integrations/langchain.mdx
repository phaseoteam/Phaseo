Erstelle ein `ChatOpenAI`-Modell mit deinem Phaseo-Schlüssel und `base_url="https://api.phaseo.app/v1"`, dann rufen LangChain-Chains, -Agents und LangGraph-Workflows Modelle über Phaseo auf.

## Installieren

```bash
pip install -U langchain langchain-openai
```

## ChatOpenAI auf Phaseo richten

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

Wird ein Satz ausgegeben, funktioniert die Einrichtung.

## In LangGraph verwenden

Übergib dasselbe `llm` an deine Graph-Knoten oder deinen Agent-Builder:

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## Bekannte Einschränkungen

- Dieser Weg nutzt [Chat Completions](../../api-reference/endpoint/chat-completions.mdx), daher funktionieren nur Phaseo-Funktionen, die auf `/v1/chat/completions` verfügbar sind, darunter [Tool-Aufrufe](../tool-calling.mdx) sowie [Routing und Fallbacks](../routing-and-fallbacks.mdx).
- Für Server-Tools, die es nur bei Responses gibt, etwa `phaseo:apply_patch`, rufe Phaseo direkt auf oder nutze das [OpenAI SDK](./openai-sdk.mdx).
- Zum Tracing mit LangSmith siehe [Observability](./observability.mdx).
