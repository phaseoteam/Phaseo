Installiere `@phaseo/ai-sdk-provider` und übergib `phaseo("<model id>")` als Modell in jedem Aufruf des AI SDK. Der Provider liest `PHASEO_API_KEY` aus der Umgebung.

## Installieren

```bash
npm install @phaseo/ai-sdk-provider
```

Das Paket ohne Versionsangabe folgt dem npm-Tag `latest`, also der Linie für AI SDK 7, und deklariert `ai@^7` als Peer-Abhängigkeit, die npm für dich installiert. Für ein älteres AI SDK installierst du das passende Tag:

| AI SDK | Provider-Vertrag | Installation |
| --- | --- | --- |
| 7 (aktuell) | `ProviderV4` (Provider 2.x) | `npm install @phaseo/ai-sdk-provider` |
| 6 | `ProviderV3` (Provider 1.x, Wartung) | `npm install @phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `ProviderV2` | `npm install @phaseo/ai-sdk-provider@ai-sdk-v5` |

Wenn dein Paketmanager keine Peer-Abhängigkeiten installiert, installiere zusätzlich die passende Hauptversion von `ai` (`ai@^7`, `ai@^6` oder `ai@^5`).

Sobald AI SDK 8 stabil ist, markiert Phaseo Provider 1.x auf npm als veraltet. Bestehende Releases werden nicht entfernt, und ein Ende des Supports wird gesondert angekündigt.

## Text generieren

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Summarize this in one sentence.",
});

console.log(result.text);
```

Derselbe Code funktioniert auf allen drei Linien. Verwende Modell-IDs vom [Models-Endpunkt](../../api-reference/endpoint/models.mdx); jede Fähigkeit hängt weiterhin vom Modell und vom Upstream-Anbieter ab.

## Was jede Linie unterstützt

| Funktion | AI SDK 7 (Provider 2.x) | AI SDK 5 |
| --- | --- | --- |
| Textgenerierung und Streaming | Ja | Ja |
| Funktions-Tools und Rundläufe mit Tool-Ergebnissen | Ja, einschließlich gestreamter Tool-Eingaben | Ja |
| Strukturierte Ausgabe als JSON und JSON Schema | Ja | Ja |
| Embeddings und Bildgenerierung | Ja | Ja |
| Transkription und Sprachausgabe | Ja | Ja |
| Reranking | Ja | Nein |
| Anbieterunabhängige Reasoning-Einstellungen und -Ausgabe | Ja | |
| Text- und Bilddatei-Eingaben (getaggte Dateidaten in V7) | Ja | |
| URL-Zitatquellen | Ja | |
| Anbieter-Metadaten, Nutzung, Request-Header, Abbruchsignale, rohe Stream-Chunks | Ja | |

Die Spalte AI SDK 7 zeigt, was Provider 2.x implementiert und gegen die nativen v4-Verträge von AI SDK 7 testet. Reranking ist auch auf der Linie für AI SDK 6 verfügbar.

## Dokumente neu ordnen

Verwende den Helfer `rerank()` des AI SDK mit `phaseo.rerankingModel(modelId)`:

```ts
import { rerank } from "ai";
import { phaseo } from "@phaseo/ai-sdk-provider";

const result = await rerank({
	model: phaseo.rerankingModel("voyage/rerank-2"),
	query: "Which document is about TypeScript?",
	documents: [
		"TypeScript adds static types to JavaScript.",
		"Rust is a systems programming language.",
	],
	topN: 1,
});
```

## Bekannte Grenzen

- Der Provider bietet keine `ProviderV4`-Funktionen an, die Phaseo-API-Oberflächen brauchen, die es noch nicht gibt: verwaltete Datei-Uploads und -Referenzen, Skills sowie vom Anbieter ausgeführte Tool-Definitionen, -Ergebnisse oder Freigabeantworten.
- Funktions-Tools, die deine App ausführt, nutzen weiterhin den normalen Ausführungs- und Freigabeablauf des AI SDK.
- Anbieterspezifische oder benutzerdefinierte Prompt-Teile, die nicht unterstützt werden, schlagen mit einem eindeutigen Fehler fehl, statt verworfen zu werden.
