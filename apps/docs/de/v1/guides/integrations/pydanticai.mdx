Erstelle ein `OpenAIChatModel` mit einem `OpenAIProvider`, der auf `https://api.phaseo.app/v1` zeigt, dann laufen PydanticAI-Agents auf Phaseo-Modellen.

## Installieren

```bash
pip install "pydantic-ai-slim[openai]"
```

## PydanticAI auf Phaseo richten

```python
import os
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-6-astra",
    provider=OpenAIProvider(
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)

agent = Agent(model, system_prompt="Answer concisely.")
result = agent.run_sync("Reply with only: ok")
print(result.output)
```

Wird `ok` ausgegeben, funktioniert die Einrichtung.

## Bekannte Einschränkungen

- Dieser Weg nutzt Chat Completions im OpenAI-Stil. Für Funktionen, die es nur bei Responses gibt, etwa `phaseo:apply_patch`, rufe den Responses-Endpunkt von Phaseo direkt auf.
- Halte Schemas für [strukturierte Ausgaben](../structured-outputs.mdx) klein genug für das Kontextfenster des Modells. Die Limits findest du unter [Modelle](../../api-reference/endpoint/models.mdx).
