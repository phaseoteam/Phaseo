Führe `phaseo pi` aus, um Pi eine Phaseo-Anbietererweiterung mit jedem kompatiblen Phaseo-Modell hinzuzufügen.

## Mit der Phaseo CLI einrichten

```bash
phaseo login
phaseo pi
```

Fehlt Pi, zeigt die CLI den offiziellen Installationsbefehl an und fragt nach, bevor sie ihn ausführt. Danach erstellt die Einrichtung einen `Phaseo CLI: Pi API Key` (Ablauf nach 90 Tagen, monatliches Ausgabenlimit von $100) und schreibt eine Anbietererweiterung nach `~/.pi/agent/extensions/phaseo.ts`. Die Erweiterung listet jedes aktive Phaseo-Textmodell auf, das mit Chat Completions funktioniert.

| Flag | Wirkung |
| --- | --- |
| `--model <id>` | Legt das Anfangsmodell fest. Standard ist `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | Fügt nur das ausgewählte Modell hinzu. |
| `--dry-run` | Zeigt die Dateiänderungen an, ohne sie vorzunehmen. |

Die Erweiterung holt ihren Schlüssel zum Zeitpunkt der Anfrage mit der befehlsgestützten Schlüsselsyntax von Pi, sodass kein Klartextschlüssel in die Datei geschrieben wird:

```text
!phaseo integrations credential pi
```

## Prüfen, ob es funktioniert

```bash
pi
```

Öffne `/model`, wähle den Anbieter `phaseo` und sende einen kurzen Prompt. Prüfe, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Phaseo entfernen

```bash
phaseo integrations remove pi
```

Damit wird nur die Phaseo-Erweiterung entfernt und der Schlüssel widerrufen.
