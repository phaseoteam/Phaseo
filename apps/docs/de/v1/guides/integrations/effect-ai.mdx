Rufe die OpenAI-kompatiblen Endpunkte von Phaseo aus Effect mit dessen HTTP-Client auf, oder kapsle das [OpenAI SDK](./openai-sdk.mdx) in einem Effect-Layer. Nutze das eigene OpenAI-Anbieterpaket von Effect nur, wenn deine installierte Version eine benutzerdefinierte Base URL akzeptiert.

## Installieren

```bash
npm install effect @effect/platform
```

## Phaseo mit Effect HTTP aufrufen

```ts
import { FetchHttpClient, HttpClient, HttpClientRequest } from "@effect/platform";
import { Config, Effect, Redacted } from "effect";

const generate = Effect.gen(function* () {
	const apiKey = yield* Config.redacted("PHASEO_API_KEY");
	const client = yield* HttpClient.HttpClient;

	const request = HttpClientRequest.post(
		"https://api.phaseo.app/v1/chat/completions",
	).pipe(
		HttpClientRequest.bearerToken(Redacted.value(apiKey)),
		HttpClientRequest.jsonBody({
			model: "openai/gpt-6-astra",
			messages: [{ role: "user", content: "Reply with only: ok" }],
		}),
	);

	return yield* client.execute(request).pipe(
		Effect.flatMap((response) => response.json),
	);
});

const runnable = generate.pipe(Effect.provide(FetchHttpClient.layer));
```

Die Ausführung gibt eine Chat-Completions-Antwort zurück, deren Nachricht `ok` lautet.

## Das OpenAI SDK in einem Effect-Layer kapseln

Wenn du das OpenAI SDK bereits nutzt, halte die Phaseo-Konfiguration an einer Stelle:

```ts
import OpenAI from "openai";
import { Config, Effect } from "effect";

const makeClient = Effect.gen(function* () {
	const apiKey = yield* Config.string("PHASEO_API_KEY");

	return new OpenAI({
		apiKey,
		baseURL: "https://api.phaseo.app/v1",
	});
});
```

Baue darauf einen eigenen Layer auf, wenn du in deiner App eine anbieterartige Abstraktion möchtest.

## Bekannte Einschränkungen

- Verwende Modell-IDs im Phaseo-Format, etwa `openai/gpt-6-astra`.
- Teste [Streaming](../streaming.mdx) und Tool-Aufrufe vor dem Produktionseinsatz mit genau deinen Effect-Paketversionen.
