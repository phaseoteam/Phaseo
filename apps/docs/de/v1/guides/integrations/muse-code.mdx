Führe `phaseo muse` aus, um eine Muse-Code-Sitzung über Phaseo zu starten. Dieser Runner ist der einzige unterstützte Weg, Phaseo mit Muse Code zu nutzen.

## Muse Code über die Phaseo CLI ausführen

```bash
phaseo login
phaseo muse --model meta/muse-spark-1.3
```

Der Runner erstellt einen eigenen Schlüssel, schreibt die Muse-Einstellungen unter ein temporäres `XDG_CONFIG_HOME`, startet `muse` und löscht die Einstellungen, wenn Muse Code beendet wird. Setze die eigenen Flags von Muse Code hinter `--`.

| Flag | Wirkung |
| --- | --- |
| `--model <id>` | Zu verwendendes Modell. Standard ist `openai/gpt-5.6-terra`. |
| `--catalog all` | Listet jedes aktive Phaseo-Textmodell auf, nicht nur das ausgewählte. |
| `--dry-run --json` | Zeigt den Startplan, ohne einen Schlüssel zu erstellen oder Muse Code zu starten. |
| `--skip-install` | Überspringt die Installationsprüfung. |

`phaseo run muse ...` ist die Langform desselben Befehls.

Unter macOS und Linux bietet der erste interaktive Lauf an, Muse Code mit dem Installer von Meta zu installieren. Unter Windows installierst du Muse Code selbst, prüfst `muse --version` und verwendest `--skip-install`.

## Warum es keine manuelle Einrichtung gibt

Muse Code ist auf Metas eigene [Model API](https://ai.meta.com/llama) und Anmeldung ausgelegt. Meta dokumentiert keine stabile Einstellung, um es auf einen anderen OpenAI-kompatiblen Endpunkt zu richten, nutze also den Runner. Kopiere die temporären Einstellungen des Runners nicht in dein normales Muse-Profil. Sie sind ein internes Detail und werden gelöscht, wenn der Runner beendet wird.

Um ein Phaseo-Modell stattdessen aus deinem eigenen Code aufzurufen, nutze das [OpenAI SDK](./openai-sdk.mdx) mit `https://api.phaseo.app/v1` und einem Phaseo-API-Schlüssel.

## Prüfen, ob es funktioniert

Sende einen kurzen Prompt und prüfe, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Häufige Probleme beheben

### Muse Code ist nicht installiert

Installiere Muse Code selbst, prüfe `muse --version` und führe den Befehl erneut mit `--skip-install` aus.

### Das Modell wird nicht aufgeführt

Nutze `--catalog all` oder gib die Modell-ID mit `--model` an. Phaseo braucht keine Modellerkennung.
