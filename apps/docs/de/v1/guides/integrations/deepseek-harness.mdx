Führe `phaseo deepseek-harness` aus, um Phaseo zur Modellauswahl von DeepSeek Harness hinzuzufügen, oder lege in der Harness-Oberfläche oder in `settings.yaml` einen benutzerdefinierten Anbieter an. Harness sendet OpenAI-kompatible Chat-Completions-Anfragen direkt an Phaseo, ein Adapter ist also nicht nötig.

## Mit der Phaseo CLI einrichten

```bash
phaseo login
phaseo deepseek-harness
```

Fehlt Harness, zeigt die CLI den offiziellen Installationsbefehl an und fragt nach, bevor sie ihn ausführt. Danach geht die Einrichtung so vor:

- Sie schreibt Anbieter, Base URL, Protokoll, Modellkatalog und Standardmodell nach `$DSH_HOME/cordis.patch.yml` (`DSH_HOME` ist standardmäßig `~/.dsh`), in einen markierten Block, damit sie später nur ihre eigenen Einstellungen aktualisieren oder entfernen kann.
- Sie fügt jedes aktive Phaseo-Textmodell hinzu, das mit Chat Completions funktioniert. Mit `--catalog default` wird nur das Standardmodell hinzugefügt.
- Sie erstellt einen `Phaseo CLI: DeepSeek Harness API Key`, der nach 90 Tagen abläuft und ein monatliches Ausgabenlimit von $100 hat, und schreibt ihn in die geschützte Datei `$DSH_HOME/.credentials.yaml` von Harness. Führe `phaseo deepseek-harness` erneut aus, um einen abgelaufenen Schlüssel zu ersetzen.

Das Standardmodell ist `anthropic/claude-sonnet-4.6`. So wählst du ein anderes:

```bash
phaseo deepseek-harness --model YOUR_PHASEO_MODEL_ID
```

## Phaseo in der Harness-Oberfläche hinzufügen

1. Öffne **Settings > Models** und wähle **Add a custom provider**.
2. Gib Folgendes ein:

| Feld | Wert |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Base URL | `https://api.phaseo.app/v1` |
| API protocol | `OpenAI Completions` |
| API key | Ein Phaseo-API-Schlüssel |

3. Wähle unter **Model catalog** die Option **Fetch available models**.
4. Wähle ein Chat-Completions-Modell mit Tool-Unterstützung, etwa `anthropic/claude-sonnet-5.5`, und speichere den Anbieter.
5. Wähle im Eingabebereich das Phaseo-Modell und starte eine neue Sitzung.

Gespeicherte Sitzungen und Verweise auf Anmeldeinformationen behalten die Provider ID, betrachte `phaseo` also als dauerhaft. Anzeigename, URL, Schlüssel und Modellliste kannst du später bearbeiten.

## Phaseo in settings.yaml konfigurieren

Du kannst denselben Anbieter auch in `$DSH_HOME/settings.yaml` einrichten. Halte den Schlüssel aus dieser Datei heraus: `apiKeyEnv` nennt die Variable, aus der Harness ihn liest.

```yaml $DSH_HOME/settings.yaml
llm-pi-ai:
  providers:
    phaseo:
      displayName: Phaseo
      apiKeyEnv: PHASEO_API_KEY
      api: openai-completions
      baseURL: https://api.phaseo.app/v1
      models:
        - id: YOUR_PHASEO_MODEL_ID
```

Setze `PHASEO_API_KEY` in der Umgebung, die Harness startet, oder speichere den Schlüssel auf der Models-Seite. Ersetze `YOUR_PHASEO_MODEL_ID` durch eine exakte ID von Phaseo. Für Coding-Agents fängst du am besten mit `anthropic/claude-sonnet-5.5` an. Die Liste `models` ist ein gespeicherter Katalog, keine Live-Abfrage. Aktualisiere sie also, wenn du weitere Phaseo-Modelle in Harness haben möchtest.

## Prüfen, ob es funktioniert

Prüfe zuerst den Schlüssel und die Modellerkennung:

```bash
curl https://api.phaseo.app/v1/models \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

Wähle dann in einer neuen Harness-Sitzung ein Phaseo-Modell und sende `Reply with exactly: Phaseo is connected.` Eine Antwort bestätigt den gesamten Weg von Harness über Phaseo bis zum Modellanbieter. Die Anfrage erscheint außerdem unter **Einstellungen → Nutzung → Protokolle**. Live-Anfragen werden als normale Nutzung abgerechnet.

## Phaseo entfernen

```bash
phaseo integrations remove deepseek-harness
```

Damit wird nur die Konfiguration entfernt, die Phaseo gehört, und der Schlüssel widerrufen.

## Häufige Probleme beheben

| Problem | Lösung |
| --- | --- |
| Das Abrufen der Modelle gibt `401` zurück | Prüfe, ob der Schlüssel aktuell ist und die Base URL `/v1` enthält. |
| Das Modell fehlt in der Auswahl | Rufe den Katalog erneut ab oder füge die exakte Modell-ID unter `models` in `settings.yaml` hinzu. |
| Harness meldet `MISSING_CREDENTIAL` | Speichere den Schlüssel auf der Models-Seite oder stelle `PHASEO_API_KEY` dem Harness-Prozess zur Verfügung. |
| Anfragen gehen an den falschen Endpunkt | Wähle `OpenAI Completions` (`openai-completions`). Dieser Anbieter nutzt `/v1/chat/completions` von Phaseo. |
| Ein Modell lehnt Funktions-Tools bei aktiviertem Reasoning ab | Wähle ein Modell, das Tools auf Chat Completions unterstützt. Modelle, die für Reasoning mit Tools die Responses API brauchen, funktionieren mit diesem Protokoll nicht. |
| Eine Sitzung behält ihr altes Modell | Starte eine neue Sitzung. Harness speichert Anbieter und Modell in Sitzungen, die bereits eine Anfrage gesendet haben. |
