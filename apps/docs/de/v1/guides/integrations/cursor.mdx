Führe `phaseo cursor` aus, um einen Schlüssel zu erstellen, und aktiviere dann in Cursor die Einstellungen für den OpenAI-API-Schlüssel und **Override OpenAI Base URL**. Damit laufen die Chatmodelle von Cursor über Phaseo. Funktionen, die Cursors eigene Modelle nutzen, etwa die Tab-Vervollständigung, können weiterhin Cursors Infrastruktur verwenden.

## Mit der Phaseo CLI einrichten

```bash
phaseo login
phaseo cursor --model openai/gpt-5.6-terra
```

Die CLI erstellt einen `Phaseo CLI: Cursor API Key`, der nach 90 Tagen abläuft und ein monatliches Ausgabenlimit von $100 hat, und gibt die unten stehenden Einstellungen aus. Führe `phaseo cursor` nach dem Ablauf erneut aus, um einen neuen Schlüssel zu erhalten. Die CLI bearbeitet den Anmeldeinformationsspeicher von Cursor nicht.

## Cursor konfigurieren

1. Öffne **Cursor Settings → Models**.
2. Suche den Abschnitt **OpenAI API Key** und aktiviere ihn.
3. Füge den Schlüssel aus `phaseo integrations credential cursor` oder einen beliebigen Phaseo-API-Schlüssel ein.
4. Aktiviere **Override OpenAI Base URL** und gib `https://api.phaseo.app/v1` ein, ohne abschließenden Schrägstrich.
5. Füge das gewünschte Phaseo-Modell hinzu oder aktiviere es.

| Cursor-Feld | Wert |
| --- | --- |
| OpenAI API Key | Ausgabe von `phaseo integrations credential cursor` |
| Override OpenAI Base URL | `https://api.phaseo.app/v1` |
| Model | Eine Phaseo-Modell-ID, die Cursor akzeptiert |

Die Schlüssel- und Base-URL-Einstellungen von Cursor gelten global, nicht pro Anbieter: Der aktivierte Schlüssel und die Base URL bestimmen, wohin jede Anfrage der OpenAI-Familie geht, und der Modellname wird unverändert weitergegeben. Manche Versionen speichern den Schlüssel ohne **Verify**-Schaltfläche. Teste dann stattdessen mit einem neuen Chat. Siehe Cursors [Dokumentation zu API-Schlüsseln](https://docs.cursor.com/settings/api-keys).

## Prüfen, ob es funktioniert

1. Lass den Schlüssel und die überschriebene Base URL aktiviert.
2. Wähle das Modell in Cursors Modellauswahl und starte einen neuen Chat.
3. Bitte es, mit `PHASEO_CURSOR_OK` zu antworten.
4. Prüfe, ob die Anfrage unter **Einstellungen → Nutzung → Protokolle** erscheint.

## Phaseo entfernen

Deaktiviere den OpenAI-API-Schlüssel und die überschriebene Base URL unter **Cursor Settings → Models** und widerrufe dann den Schlüssel:

```bash
phaseo integrations remove cursor
```

Die CLI kann den Anmeldeinformationsspeicher von Cursor nicht leeren. Wird der Schlüssel noch als konfiguriert angezeigt, lösche ihn in den Models-Einstellungen von Cursor.

## Häufige Probleme beheben

### Von Cursor gehostete Modelle funktionieren nicht mehr

Cursor wendet die überschriebene Base URL auf jedes Modell der OpenAI-Familie an. Schalte **Override OpenAI Base URL** aus, bevor du zu einem von Cursor gehosteten Modell zurückwechselst.

### Das Modell wird abgelehnt

Cursor kann IDs ablehnen, die mit seinem integrierten Katalog kollidieren oder nicht zu seinem Routing für die OpenAI-Familie passen, und manche Versionen lehnen IDs mit Anbieterpräfix ab. Probiere ein anderes Phaseo-Modell, das Cursor als benutzerdefiniertes Modell der OpenAI-Familie akzeptiert.

### Die Authentifizierung schlägt fehl

Führe `phaseo integrations credential cursor` erneut aus, ersetze den Schlüssel in Cursor und prüfe, ob die Base URL genau `https://api.phaseo.app/v1` lautet.
