Rufe Phaseo von jeder Automatisierungsplattform auf, die eine authentifizierte HTTP-Anfrage senden kann: Füge einen HTTP-Schritt hinzu, der an `https://api.phaseo.app/v1/responses` sendet, mit deinem Schlüssel als Bearer-Token. Phaseo hat keine native App für Zapier, n8n oder Pipedream.

## Die Anfrage aufbauen

| Einstellung | Wert |
| --- | --- |
| Methode | `POST` |
| URL | `https://api.phaseo.app/v1/responses` |
| Header | `Authorization: Bearer <PHASEO_API_KEY>` |
| Header | `Content-Type: application/json` |

```json
{
  "model": "openai/gpt-6-astra",
  "input": "Summarise the supplied workflow data in one paragraph."
}
```

Speichere den Schlüssel im Anmeldedaten- oder Secret-Speicher der Plattform, nicht in einer gemeinsam genutzten Workflow-Definition. Alle Felder der Anfrage findest du unter [Responses](../../api-reference/endpoint/responses.mdx).

## Zapier

Verwende **Webhooks by Zapier → Custom Request**:

1. Wähle `POST` und gib `https://api.phaseo.app/v1/responses` ein.
2. Füge die Bearer- und Content-Type-Header hinzu.
3. Weise Felder aus vorherigen Zap-Schritten dem Feld `input` zu.
4. Teste den Zap mit nicht sensiblen Daten.

## n8n

Verwende den Knoten **HTTP Request** mit Bearer-Authentifizierung und einem JSON-Body. Weise das eingehende Element mit einem n8n-Ausdruck dem Feld `input` zu.

## Pipedream

Verwende einen HTTP-Anfrageschritt oder einen Node.js-Code-Schritt. Speichere `PHASEO_API_KEY` als Pipedream-Secret und lies ihn aus der Schrittumgebung aus.

## Prüfen, ob es funktioniert

Führe den Schritt einmal aus. Eine `200`-Antwort mit einem Array `output` bedeutet, dass Schlüssel und URL funktionieren, und die Anfrage erscheint unter **Einstellungen → Nutzung → Protokolle**.

## Automatisierungen sicher betreiben

- Gib jeder Automatisierung einen eigenen Schlüssel mit Ausgabenlimit, damit du sie einzeln verfolgen und widerrufen kannst.
- Verwende [strukturierte Ausgaben](../structured-outputs.mdx), wenn nachfolgende Schritte maschinenlesbare Felder erwarten.
- Wiederhole bei `429` und behebbaren `5xx`-Antworten; siehe [Fehler](../../api-reference/errors.mdx).
- Wiederhole nicht idempotente externe Aktionen nicht allein deshalb, weil ein Modellschritt erneut ausgeführt wurde.
