Wähle ein Beispielprojekt, das du lokal ausführst und anpasst. Für einen einzelnen API-Aufruf nutze den [Schnellstart](../quickstart.mdx), für bestimmte Funktionen das [Rezeptbuch](../cookbook/index.mdx).

## Ausführbare Projekte

| Vorhaben | Anleitung | Quellcode |
| --- | --- | --- |
| Browserchat mit serverseitigem API-Schlüssel | [Next.js-Chat](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| OAuth-Autorisierung und Backend-Proxy | [OAuth-Werkbank](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| Eine minimale REST-Integration | [Node-Testanwendung](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| Eine Python-Befehlszeilenanwendung | [Python CLI](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| Eine Anwendung mit Vercel AI SDK | [AI-SDK-Integration](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

Bewahre Zugangsdaten auf dem Server auf, prüfe die Umgebungsvariablen des Beispiels und kontrolliere den Modellpreis vor dem Ausführen. Beispiele mit `:free`-Modellen benötigen kein eingezahltes Guthaben.

## Sprachspezifische Anfragen

Die [Client-SDK-Referenz](../sdk-reference/typescript/overview.mdx) enthält Installations- und Anfragebeispiele nach Sprache. Nutze die [Bildgenerierungsreferenz](../api-reference/endpoint/images-generations.mdx) für Bildparameter und [Chat Completions](../api-reference/endpoint/chat-completions.mdx) für Chatanfragen.

Nutze [Starter-Prompts für Mini-Apps](../cookbook/mini-app-starter-prompts.mdx), damit ein Programmieragent ein Projektgerüst erstellt, und prüfe den generierten Code vor der Nutzung mit echten Zugangsdaten.
