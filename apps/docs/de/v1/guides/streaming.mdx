Streaming liefert die Antwort in einzelnen SSE-Frames, sodass Nutzer früher erste Ergebnisse sehen.

## Unterstützte Endpunkte

- `/v1/responses`
- `/v1/chat/completions`
- `/v1/messages`

## Anfrage

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Stream a short hello message.",
    "stream": true
  }'
```

## Antwort

```text
data: {"id":"resp_...","object":"response","status":"in_progress",...}
data: {"type":"response.output_text.delta","delta":"Hello"}
data: {"type":"response.completed",...}
data: [DONE]
```

## SDK-Optionen

- TypeScript-SDK: `client.streamResponses()`, `client.streamChat()` und `client.streamMessages()`
- Python SDK: `client.stream_responses()`, `client.stream_chat()` und `client.stream_message()`
- Vercel AI SDK: `streamText(...)` mit `@phaseo/ai-sdk-provider`

## Wichtige Einschränkung

Auf der aktuellen Ebene der Gateway-Request-Validierung wird die Kombination von Tools mit `stream: true` abgelehnt (`400 invalid_request`). Verwende für Tool-Aufruf-Schleifen den Modus ohne Streaming.
