Nutze diese Muster, wenn du vom Prototyp zum Produktionsbetrieb wechselst.

## Checkliste für Zuverlässigkeit

- Richte clientseitige Timeouts und Abbruchsteuerungen ein.
- Behandle `429`- und `5xx`-Statuscodes mit exponentiellem Backoff.
- Behandle getrennte Streams als wiederholbar.
- Speichere Teiltext nur nach Abschluss, wenn Korrektheit wichtig ist.

## Beispiel für Abbruch im Browser oder in Node

```typescript
const controller = new AbortController();
const timeout = setTimeout(() => controller.abort(), 30_000);

try {
  const response = await fetch("https://api.phaseo.app/v1/chat/completions", {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "openai/gpt-5-nano",
      messages: [{ role: "user", content: "Stream a short summary." }],
      stream: true,
    }),
    signal: controller.signal,
  });
  // Parse SSE frames from response.body here.
} finally {
  clearTimeout(timeout);
}
```

## Hinweise zur Benutzeroberfläche

- Gib Token-Deltas schrittweise aus.
- Zeige bei `[DONE]` eindeutig an, dass die Generierung beendet ist.
- Protokolliere Request-ID und Modell-ID, um Anfragen erneut abzuspielen und zu debuggen.

## Wann du Streaming vermeiden solltest

- Tool-Aufruf-Abläufe mit der aktuellen Request-Validierung (`stream + tools` wird abgelehnt).
- Workflows, bei denen die vollständige Validierung vor jeder nutzersichtbaren Ausgabe erforderlich ist.
