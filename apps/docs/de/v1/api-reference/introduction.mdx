Sende jede Anfrage an `https://api.phaseo.app/v1`, mit deinem Schlüssel in einem `Authorization: Bearer`-Header. Suche unten den Endpunkt für deine Aufgabe und öffne dann seine Referenzseite.

## Den richtigen Endpunkt finden

| Wenn du Folgendes möchtest | Beginne mit |
| --- | --- |
| Deine erste Anfrage senden | [Schnellstart](../quickstart) |
| Text generieren oder Tools verwenden | [`POST /responses`](./endpoint/responses) |
| Typisierte Entscheidungen treffen | [`POST /decisions`](./endpoint/decisions) |
| Eine bestehende OpenAI-kompatible Integration beibehalten | [`POST /chat/completions`](./endpoint/chat-completions) |
| Modelle und Anbieter durchsuchen | [`GET /models`](./endpoint/models) und [`GET /providers`](./endpoint/providers) |
| Musik erstellen oder Dateien verwalten | [`POST /music/generate`](./endpoint/music-generate) und [`POST /files`](./endpoint/files) |
| Video generieren (Beta) | [`POST /videos`](./endpoint/video-create) |
| Einen Batch einreichen oder Ergebnisse herunterladen (Beta) | [`POST /batches`](./endpoint/batches-create) und [`GET /batches/{batch_id}/results`](./endpoint/batches-results) |

## Basis-URL

```http
https://api.phaseo.app/v1
```

Jeder Endpunktpfad in dieser Referenz ist relativ zu dieser Basis-URL.

## Authentifizierung

| Zugangsdaten | Format | Aufrufe |
| --- | --- | --- |
| [Gateway-API-Schlüssel](../developers/authentication.mdx) | `phaseo_v1_sk_<kid>_<secret>` | Inferenz-Endpunkte |
| [Verwaltungs-API-Schlüssel](../developers/management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | Verwaltungs-Endpunkte, beschränkt auf die Berechtigungen des Schlüssels |

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

Schlägt die Authentifizierung fehl, gibt die API `401` zurück.

## API-Ressourcen

| Ressource | Funktion |
| --- | --- |
| Inferenz | Generiere Text, Bilder, Audio und Embeddings; triff Entscheidungen, sortiere neu, moderiere oder parse Inhalte. Beginne mit [Responses](./endpoint/responses.mdx) oder [Decisions](./endpoint/decisions.mdx). |
| Asynchrone Jobs und Dateien | Reiche [Video](./endpoint/video-create.mdx)- oder [Batch](./endpoint/batches-create.mdx)-Jobs ein, übertrage Dateien und konfiguriere Webhooks. |
| Modelle und Preise | Entdecke [Modelle](./endpoint/models.mdx), Anbieterangebote und [geschätzte Kosten](./endpoint/pricing-calculate.mdx). |
| Routing und Richtlinien | Konfiguriere Presets, Anbieterzugangsdaten, private Modelle und [Guardrails](./endpoint/guardrails.mdx). |
| Nutzung und Überwachung | Prüfe [Logs](./endpoint/logs-list.mdx), Aktivität, Analysen, Evaluierungen und den Dienststatus. |
| Workspace-Verwaltung | Verwalte [Workspaces](./endpoint/workspaces-list.mdx), Schlüssel, Budgets, Identitäten und Integrationen. |

## Abrechnung und Ratenlimits

Kostenpflichtige Anfragen benötigen genug Wallet-Guthaben, um vor der Ausführung eine Guthabenprüfung zu bestehen. Modelle, deren ID auf `:free` endet, benötigen kein eingezahltes Guthaben. Anfragen können von einem Anbieter oder durch Workspace- und Schlüssellimits gedrosselt werden; siehe [Ratenlimits](./limits.mdx).
