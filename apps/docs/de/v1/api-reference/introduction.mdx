Auf dieser Seite findest du den passenden API-Pfad, bevor du eine Endpunktreferenz öffnest. Alle Phaseo-Gateway-Endpunkte verwenden dieselbe Basis-URL und Bearer-Authentifizierung.

## Pfad auswählen

| Wenn du Folgendes möchtest | Beginne mit |
| --- | --- |
| Deine erste Anfrage senden | [Schnellstart](../quickstart.mdx) |
| Text generieren oder Tools verwenden | [`POST /responses`](./endpoint/responses) |
| Typisierte Entscheidungen treffen | [`POST /decisions`](./endpoint/decisions) |
| Eine bestehende OpenAI-kompatible Integration beibehalten | [`POST /chat/completions`](./endpoint/chat-completions) |
| Modelle und Anbieter durchsuchen | [`GET /models`](./endpoint/models) und [`GET /providers`](./endpoint/providers) |
| Musik erstellen oder Dateien verwalten | [`POST /music/generations`](./endpoint/music-generate) und [`POST /files`](./endpoint/files) |
| Video generieren (Beta) | [`POST /videos`](./endpoint/video-create) |
| Batch einreichen oder Ergebnisse herunterladen (Beta) | [`POST /batches`](./endpoint/batches-create) und [`GET /batches/{batch_id}/results`](./endpoint/batches-results) |

## Basis-URL

Produktions-Basis-URL:

```http
https://api.phaseo.app/v1
```

Alle Endpunktpfade in dieser Referenz beziehen sich auf die Basis-URL `/v1`.

## Authentifizierung

Nutze einen normalen Gateway-API-Schlüssel für Inferenz und einen Verwaltungs-API-Schlüssel mit passenden Berechtigungen für Administration. Siehe [Authentifizierung](../developers/authentication.mdx) und [Verwaltungs-API-Schlüssel](../developers/management-api-keys.mdx).

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

Bei fehlgeschlagener Authentifizierung gibt die API `401` zurück.

## API-Ressourcen

| Ressource | Funktion |
| --- | --- |
| Inferenz | Generiere Text, Bilder, Audio und Embeddings; triff Entscheidungen, sortiere neu, moderiere oder parse Inhalte. Beginne mit [Responses](./endpoint/responses.mdx) oder [Decisions](./endpoint/decisions.mdx). |
| Asynchrone Jobs und Dateien | Reiche [Video](./endpoint/video-create.mdx)- oder [Batch](./endpoint/batches-create.mdx)-Jobs ein, übertrage Dateien und konfiguriere Webhooks. |
| Modelle und Preise | Entdecke [Modelle](./endpoint/models.mdx), Anbieterangebote und [Kostenschätzungen](./endpoint/pricing-calculate.mdx). |
| Routing und Richtlinien | Konfiguriere Voreinstellungen, Anbieterzugangsdaten, private Modelle und [Schutzregeln](./endpoint/guardrails.mdx). |
| Nutzung und Überwachung | Prüfe [Logs](./endpoint/logs-list.mdx), Aktivität, Analysen, Bewertungen und den Dienststatus. |
| Workspace-Verwaltung | Verwalte [Workspaces](./endpoint/workspaces-list.mdx), Schlüssel, Budgets, Identitäten und Integrationen. |

## Abrechnung und Ratenbegrenzungen

- Behandle Anbieter-Drosselung und geltende Zugriffsrichtlinien mit der [Anleitung zu Anfragelimits](./limits.mdx).
- Für kostenpflichtige Anfragen ist ein ausreichendes Wallet-Guthaben erforderlich, damit die Vorabprüfung des Guthabens erfolgreich ist.
- Kostenlose Modelle mit `:free` benötigen kein eingezahltes Guthaben.
