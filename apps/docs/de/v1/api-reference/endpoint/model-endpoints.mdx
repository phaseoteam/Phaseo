Rufe diesen Endpunkt auf, bevor du eine Anfrage sendest, um zu bestätigen, dass eine Kombination aus Modell, Anbieter, Endpunkt und Parameter verfügbar ist. Für `openai/gpt-6-astra`:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

Jeder Eintrag in `endpoints` ist eine Anbieter-Route für einen Endpunkt:

| Feld | Enthält |
| --- | --- |
| `endpoint`, `capability_id`, `public_path`, `collection` | Die kanonischen Endpunkt- und Fähigkeits-IDs und den öffentlichen API-Pfad |
| `provider`, `model` | Die Anbieter-ID und den Anbieternamen sowie den Modell-Slug des Anbieters |
| `routable`, `status`, `status_reason` | Ob die Route gerade Traffic annimmt, ihre Verfügbarkeit und warum sie nur Vorschau oder inaktiv ist |
| `modalities` | Eingabe- und Ausgabemodalitäten |
| `capabilities` | Unterstützte Parameternamen und strukturierte Parameterdetails |
| `routing` | Routing-Status von Anbieter, Modell und Fähigkeit |
| `effective` | `from`- und `to`-Datum, wenn die Route geplant oder zeitlich begrenzt ist |
| `pricing` | Die Preisübersicht des Endpunkts |

Um zuerst Modelle zu vergleichen, verwende [Modelle auflisten](./models.mdx); um jeden Endpunkt zu sehen, den die API bereitstellt, verwende [Endpunkte auflisten](./endpoints.mdx).

## Geplante und inaktive Routen einbeziehen

Der Standard `availability=active` gibt nur öffentlich routbare Zeilen zurück. Verwende `availability=all`, um demnächst verfügbare und inaktive Routen zu prüfen:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints?availability=all" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

Route Produktions-Traffic nur an eine Zeile, deren `routable` gleich `true` und deren `status` gleich `active` ist.

## Routen filtern

Diese Filter akzeptieren wiederholte Parameter oder eine kommagetrennte Liste: `provider`, `provider_status`, `provider_routing_status`, `model_routing_status`, `capability_status`, `provider_availability_status`, `provider_availability_reason`, `status` und `supported_parameters` (Alias `params`). [Modelle auflisten](./models.mdx#filter-the-list) beschreibt ihre Werte.

Diese Anfrage gibt OpenAI-Routen zurück, die `reasoning_effort` unterstützen:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints?provider=openai&supported_parameters=reasoning_effort" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```
