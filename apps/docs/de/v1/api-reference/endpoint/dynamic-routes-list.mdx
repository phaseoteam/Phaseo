openapi: "/de/openapi/v1/openapi.localized.yaml GET /routing/dynamic-routes"
description: "Listet dynamische Routen, Versionen und zugeordnete API-Schlüssel auf."
---
<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel mit `settings:read` erforderlich.</Note>

Jede Route enthält die aktuelle Entwurfsversion, die bereitgestellte Version, den unveränderlichen Versionsverlauf und die IDs verknüpfter API-Schlüssel.
