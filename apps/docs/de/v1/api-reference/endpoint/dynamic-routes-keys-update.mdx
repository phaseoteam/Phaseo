---
title: "Schlüssel dynamischer Route ersetzen"
sidebarTitle: "Schlüssel zuordnen"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml PUT /routing/dynamic-routes/{id}/keys"
description: "Ersetzt atomar die einer dynamischen Route zugeordneten API-Schlüssel."
---
<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel mit `settings:write` erforderlich.</Note>

Alle Schlüssel müssen zum Workspace des Management-Schlüssels gehören. Ein Schlüssel kann nur einer dynamischen Route zugeordnet sein.
