Verwende für neue Aufrufe das OpenAI-kompatible Format: `input` enthält Text oder Benutzernachrichten mit eingebetteten `input_image`-Teilen; `questions` ist eine geordnete Liste von `predicate`-, `choice`- oder `score`-Fragen. Antworten behalten Reihenfolge und optionale Namen bei. Boolesche Auswahlwerte bleiben boolesch. Externe Bild-URLs werden nicht unterstützt; Luna akzeptiert bis zu 128 eingebettete Bilder, andere Anbieter haben eigene Grenzen. Explizite Bilddetails und `safety_identifier` erfordern eine OpenAI-Route. Das bisherige Format mit `state`, benannten Frage-Maps, `noul` und `criteria` bleibt unterstützt und liefert die ursprüngliche Antwort-Map. Together Tev benötigt dieses bisherige Format, da es Bezeichnungen ohne Wahrscheinlichkeiten liefert. Die bisherigen Beispiele unten bleiben gültig.

```json
{
  "model": "openai/gpt-6-luna",
  "input": "I was charged twice for my order.",
  "questions": [{
    "type": "choice",
    "name": "department",
    "instructions": "Which department should handle this?",
    "choices": [
      { "value": "billing", "description": "Payments and refunds" },
      { "value": "other", "description": "Everything else" }
    ]
  }]
}
```



Verwende `POST /v1/decisions`, wenn deine Anwendung strukturierte Antworten benötigt, die der Code direkt verarbeiten kann. Zu den unterstützten Modellen gehören TypeSafe Jev 1.13 (`typesafe/jev-1.13.0`), Together Tev1 4B Experimental (`together/tev1-4b-experimental`) und Respan Span-01 (`respan/span-01:free` und `respan/span-01`).

Die Anfrage enthält:

- `state`: ein String, Objekt oder Array mit den zu bewertenden Informationen.
- `questions`: eine Map benannter Fragen. Jede Frage setzt `type` auf `noul`, `choice` oder `score` und enthält `instructions`; unterstützte Typen hängen vom ausgewählten Modell ab.
- `model`: die Phaseo-Modell-ID. Verwende `typesafe/jev-1.13.0` für Jev 1.13 oder `typesafe/jev-latest`, um jeweils die neueste Jev-Version zu nutzen.

Liquid D1 (`liquid-ai/d1:free`, auch als `liquid-ai/d1` verfügbar) und Perplexity Decider 27B (`perplexity/decider-27b`) unterstützen alle drei Fragetypen. D1 ist während des experimentellen Early Access kostenlos. Decider kostet 0,04 USD pro Million Eingabetokens einschließlich Bildtokens; Ausgabetokens sind kostenlos. Hinterlege in Phaseo Anbieter-Zugangsdaten für Perplexity, um Decider zu nutzen. Sein Bildzustand verwendet Base64-Daten-URLs für PNG, JPEG oder WebP; entfernte Bild-URLs werden nicht unterstützt. Jede Auswahlfrage akzeptiert bis zu 255 Optionen und jede Bewertungsfrage bis zu 10 Stufen. Prüfe vor dem Aufruf die Verfügbarkeit des jeweiligen Modells.

Mercury Decide (`inception/mercury-decide`) unterstützt Prädikat-, Auswahl- und Bewertungsfragen mit Text- oder JSON-Belegen. Auswahlfragen akzeptieren bis zu 255 Optionen; Bewertungsfragen akzeptieren bis zu 10 Stufen. Bilder, Streaming und Tool-Aufrufe werden nicht unterstützt. Eingaben kosten derzeit 0,02 USD pro Million Tokens im Rahmen der 50-%-Aktion von Inception; Ausgabetokens werden erfasst, bleiben aber kostenlos. Inception hat kein Enddatum für die Aktion veröffentlicht. Prüfe vor der Nutzung die Modellverfügbarkeit und die [aktuellen Upstream-Preise](https://docs.inceptionlabs.ai/get-started/models).

```json
{
  "model": "inception/mercury-decide",
  "input": "Please refund the duplicate charge on my account.",
  "questions": [{
    "type": "predicate",
    "name": "billing",
    "instructions": "Is this request about billing?"
  }]
}
```

Microsoft Decision (`microsoft/microsoft-decision-1`) nutzt eine Azure-Foundry-Bereitstellung und unterstützt Prädikat-, Auswahl- und Bewertungsfragen mit Text- oder JSON-Belegen. Das Eingabelimit beträgt 32.768 Tokens. Der veröffentlichte Preis beträgt 0,042 USD pro Million Eingabetokens; Ausgaben sind kostenlos. Medien, Streaming, Tools, `safety_identifier` und `service_tier` werden nicht unterstützt. Prüfe vor dem Aufruf die Modellverfügbarkeit. Siehe die [Anleitung von Microsoft](https://learn.microsoft.com/azure/foundry/foundry-models/how-to/use-foundry-models-microsoft-decision).

```json
{
  "model": "microsoft/microsoft-decision-1",
  "input": "The API returns 500 on every call.",
  "questions": [{
    "type": "choice",
    "name": "team",
    "instructions": "Which team should handle this ticket?",
    "choices": [
      { "value": "engineering", "description": "Bugs, errors, and outages" },
      { "value": "support", "description": "How-to and account questions" }
    ]
  }]
}
```

Für Respan Span-01 muss `state` ein Gesprächsabschnitt mit einem `input`-Array vorheriger Nachrichten und einer `output`-Assistentennachricht sein. Span-01 unterstützt nur `noul`-Fragen. Die `noul`-Antwort ist die Wahrscheinlichkeit, dass das Verhalten vorliegt; `probabilities` enthält außerdem Wahrscheinlichkeiten für fehlendes und nicht beobachtbares Verhalten.

```json
{
  "model": "respan/span-01:free",
  "state": {
    "input": [{ "role": "user", "content": "Please connect me to a person." }],
    "output": { "role": "assistant", "content": "I will connect you to support." }
  },
  "questions": {
    "escalation": {
      "type": "noul",
      "instructions": "Does the assistant offer a human handoff?"
    }
  }
}
```

`respan/span-01:free` ist das kostenlose Lite-Modell mit einem Tageslimit; Phaseo ordnet es der Respan-API-Modell-ID `span-01-free` zu. `respan/span-01` entspricht der Respan-API-Modell-ID `span-01-pro` und wird von Respan mit 0,02 USD pro Million Eingabetokens abgerechnet; Ausgabetokens sind kostenlos. Span-01 befindet sich im Early Access, daher muss Respan den Zugriff für deine Organisation freischalten. Hinterlege vor dem Aufruf dieser Modelle deinen Respan-API-Schlüssel als Respan-Anbieter-Zugangsdaten in Phaseo.

Antworten verwenden dieselben Schlüssel wie `questions`. `choice`-Antworten enthalten die gewählte Option, Wahrscheinlichkeiten und Konfidenz; `noul`-Antworten enthalten eine Wahrscheinlichkeit von 0 bis 1; `score`-Antworten enthalten einen wahrscheinlichkeitsgewichteten Score, eine Legende, Wahrscheinlichkeiten und Konfidenz.

Für das Respan-Beispiel sieht eine Antwort so aus:

```json
{
  "answers": {
    "escalation": {
      "type": "noul",
      "noul": 0.73,
      "probabilities": {
        "true": 0.73,
        "false": 0.25,
        "not_observable": 0.02
      }
    }
  }
}
```

Jev unterstützt alle drei Fragetypen gemeinsam in einer Anfrage; Span-01 unterstützt nur `noul`-Fragen. Im [Schnellstart](../../quickstart) findest du kopierbare Beispiele für cURL, JavaScript, das TypeScript-SDK und das Python-SDK. Jev 1.13 wird mit 0,042 USD pro Million Eingabetokens abgerechnet; Ausgabetokens sind kostenlos.

Die Fragensemantik des Anbieters ist in der [API-Referenz](https://docs.typesafe.ai/api) von TypeSafe beschrieben.

### Bildentscheidungen mit Clef

`cloudflare/clef` und `cloudflare/clef-flash` unterstützen alle drei Fragetypen und eingebettete Bilder über Cloudflare Workers AI. Clef bietet 65.536 Kontext-Tokens, Clef Flash 24.576. Eingaben kosten 0,24 USD pro Million Tokens für Clef und 0,038 USD für Clef Flash.

```json
{
  "model": "cloudflare/clef-flash",
  "state": "Inspect the attached product photo.",
  "images": [{ "content_type": "image/png", "base64": "<base64 image bytes>" }],
  "questions": {
    "damaged": { "type": "noul", "instructions": "Is the product visibly damaged?" }
  }
}
```

Du kannst auch eine Zeichenfolge `data:image/png;base64,...` in `images` übergeben. Clef akzeptiert bis zu vier PNG-, JPEG- oder WebP-Bilder mit jeweils höchstens 4 MiB und 16 Megapixeln, insgesamt höchstens 8 MiB dekodierten Bilddaten und einem Anfragekörper von 13 MiB. Remote-URLs werden nicht unterstützt. Cloudflare prüft Bildformate und Abmessungen. Modelle ohne Bildunterstützung lehnen Bildanfragen ab.

Clef akzeptiert höchstens 64 Fragen mit IDs aus bis zu 100 Buchstaben, Ziffern, Unterstrichen, Punkten oder Bindestrichen. Auswahlfragen benötigen 2–255 Optionen; Bewertungsfragen benötigen 2–10 Stufen. Siehe die [Clef-Dokumentation](https://developers.cloudflare.com/workers-ai/models/clef/) von Cloudflare.

### Audio- und Videoentscheidungen mit Clef Omni

`cloudflare/clef-omni` akzeptiert Text, Bilder, Audio und Video mit denselben geordneten `questions` und Antworten wie andere Decisions-Modelle. Audio und Video sind Phaseo-Erweiterungen des Eingabevertrags im OpenAI-Stil; OpenAI-Entscheidungsrouten unterstützen derzeit nur Text und Bilder. Prüfe vor der Verwendung die Modellverfügbarkeit.

Dieses Beispiel erfordert eine verfügbare Omni-Route und einen Phaseo-API-Schlüssel. Ersetze die Platzhalter-Audiobytes und die Video-URL vor dem Senden durch deine eigenen Medien.

```json
{
  "model": "cloudflare/clef-omni",
  "input": [{
    "role": "user",
    "content": [
      { "type": "input_text", "text": "Review the recording and clip." },
      { "type": "input_audio", "input_audio": { "data": "<base64 WAV bytes>", "format": "wav" } },
      { "type": "input_video", "video_url": { "url": "https://media.example.com/clip.mp4" } }
    ]
  }],
  "questions": [{ "type": "predicate", "name": "safe", "instructions": "Is the equipment operating safely?" }]
}
```

Verwende `input_audio.data` mit `format: "wav"` oder `"mp3"` oder `input_audio.url` mit einer öffentlichen HTTPS-URL oder einer eingebetteten Audio-Daten-URL. `input_video.video_url` akzeptiert einen String oder `{ "url": "..." }` mit einer öffentlichen HTTPS-URL oder einer eingebetteten MP4/WebM-Daten-URL. Entfernte Server müssen den passenden Medien-Content-Type zurückgeben. Phaseo ruft URLs mit Größenlimits sowie Prüfungen auf private Adressen und Weiterleitungen ab und bettet die Medien anschließend für Cloudflare ein; Anbieterzugangsdaten werden niemals an den Medienserver gesendet.

Omni akzeptiert bis zu vier Audioclips (je 8 MiB und 300 Sekunden) und zwei Videos (je 16 MiB und 60 Sekunden). Audio und Video zusammen dürfen dekodiert höchstens 16 MiB umfassen. Omni behält die oben genannten Limits je Bild und für alle Bilder zusammen bei; sein Limit für den Anfragekörper ersetzt das Clef/Flash-Limit von 13 MiB. Phaseo begrenzt den gesamten Omni-Anfragekörper auf 37 MiB. Cloudflare prüft Medienkodierung, Bildabmessungen und Clipdauer und tastet Videos mit zwei Bildern pro Sekunde ab. Die Tonspur eines Videos wird verwendet, wenn jedes Video in der Anfrage eine hat.

Omni hat einen dokumentierten Kontext von 64.000 Tokens und kostet 0,15 USD pro Million aggregierter Eingabetokens. Medien-Tokens zählen zu Kontext und Abrechnung; Ausgaben sind kostenlos. Phaseo rechnet auf Basis des von Cloudflare gemeldeten Eingabeverbrauchs ab, ohne separate Audio- oder Videogebühren hinzuzufügen. Siehe den [Omni-Vertrag von Cloudflare](https://github.com/cloudflare/cloudflare-docs/blob/production/src/content/workers-ai-models/clef-omni.json).
