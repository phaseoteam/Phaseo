Sende `input` und ein geordnetes Array von `questions` an `POST /v1/decisions` und erhalte pro Frage eine typisierte Antwort mit Wahrscheinlichkeiten, in derselben Reihenfolge.

## Eine Entscheidung treffen

Diese Anfrage stellt je eine Frage jedes Typs. Sie benötigt einen Phaseo-API-Schlüssel und eine verfügbare Route für `openai/gpt-6-luna`.

## Fragen formulieren

`input` ist ein String oder ein Array von `user`-Nachrichten, deren `content` ein String oder eine Liste von `input_text`-, `input_image`-, `input_audio`- und `input_video`-Teilen ist. `name` ist optional; Antworten behalten die Reihenfolge der Anfrage bei, auch bei unbenannten und wiederholten Namen.

Eine Anfrage enthält höchstens 128 Fragen, außer bei `google/gemini-decision-1`, das bis zu 1000 akzeptiert, und bei Clef, das bis zu 64 akzeptiert. Eine Anfrage über dem Limit des Modells gibt `400` zurück.

| `type` | Zusätzliche Felder | Antwortfelder |
| --- | --- | --- |
| `predicate` | keine | `probability` (0–1), dass die Antwort Ja lautet |
| `choice` | `choices`: `value` (String oder Boolean, eindeutig) und optional `description` | `choice`, `confidence`, `probabilities` pro Wert |
| `score` | `levels`: `label` und optional `description` | `score` (wahrscheinlichkeitsgewichteter Stufenindex), `confidence`, `probabilities` pro Stufe |
| `box` | keine; erfordert ein Bild in `input` | `box` (`top`, `bottom`, `left`, `right`), `confidence` |

Boolesche Auswahlwerte kommen als Booleans zurück. Ein Modell, das eine Frage ablehnt, gibt für sie `type: "refusal"` zurück. Welche Typen ein Modell unterstützt, steht unter [Ein Modell wählen](#choose-a-model).

Bilder gehören als Data-URLs in `input_image`-Teile. Gehostete HTTPS-Bild-URLs funktionieren nur bei den Base-Labs-Modellen (`baselabs/elephant-1`, `baselabs/mammoth-1` und `baselabs/joey-1`) und müssen auf Amazon S3, Google Cloud Storage oder Azure Blob Storage liegen. Eine Anfrage enthält höchstens 128 Bilder, die Luna akzeptiert; andere Anbieter setzen niedrigere Grenzen. Ein explizites Bild-`detail` und `safety_identifier` erfordern eine OpenAI-Route.

## Das ältere state-Format verwenden

Anfragen mit `state` und einer Map benannter Fragen funktionieren weiterhin und geben Antworten zurück, die nach denselben Namen geschlüsselt sind. Together Tev (`together/tev1-4b-experimental`) erfordert dieses Format, weil es eine Bezeichnung ohne Wahrscheinlichkeiten zurückgibt, und beantwortet nur `choice`-Fragen. Auch Respan Span-01 nutzt dieses Format. Mische die Formate nicht: `input` zusammen mit `state` oder `images` gibt `400` zurück.

- `state`: ein String, Objekt oder Array mit den zu bewertenden Informationen.
- `questions`: bis zu 128 benannte Fragen, bei Modellen mit höherem Limit mehr. Jede setzt `type` auf `noul` (Ja/Nein), `choice` oder `score`, dazu `instructions`. Auswahlfragen nehmen `criteria` als Map von Option zu Beschreibung; Bewertungsfragen nehmen `criteria` als Array mit mindestens zwei Stufenbeschreibungen.
- `images`: bis zu vier PNG-, JPEG- oder WebP-Bilder, als `data:`-URLs oder `{ "content_type", "base64" }`-Objekte.
- `model`: standardmäßig `typesafe/jev-1.13.0`, wenn weggelassen.

Antworten verwenden dieselben Schlüssel wie `questions`. `choice`-Antworten enthalten die gewählte Option, Wahrscheinlichkeiten und Konfidenz; `noul`-Antworten eine Wahrscheinlichkeit von 0–1; `score`-Antworten einen wahrscheinlichkeitsgewichteten Wert, eine Legende, Wahrscheinlichkeiten und Konfidenz.

## Ein Modell wählen

Prüfe die Modellverfügbarkeit, bevor du eines dieser Modelle aufrufst.

| Modell | Fragetypen | Eingabe | Eingabepreis pro 1M Tokens |
| --- | --- | --- | --- |
| `openai/gpt-6-luna` | predicate, choice, score | Text, bis zu 128 Bilder | Siehe Modellseite |
| `typesafe/jev-1.13.0`, `typesafe/jev-1.14.0` | alle drei, gemischt in einer Anfrage; `box` bei 1.14 | Text, PNG-/JPEG-Bilder | $0.042 (Jev 1.13) |
| `cloudflare/clef`, `cloudflare/clef-flash` | alle drei | Text, bis zu 4 Bilder | $0.24 / $0.038 |
| `cloudflare/clef-omni` | alle drei | Text, Bilder, Audio, Video | $0.15 |
| `google/gemini-decision-1` | predicate, choice, score; bis zu 1000 pro Anfrage | Text, Bilder, Audio, Video | $0.10 |
| `liquid-ai/d1:free`, `liquid-ai/d1` | alle drei | Siehe Modellseite | Kostenlos während des Early Access |
| `perplexity/decider-27b` | alle drei | Text, Base64-Bilder | $0.04, einschließlich Bild-Tokens |
| `inception/mercury-decide` | predicate, choice, score | Text oder JSON | $0.02 (Aktion) |
| `microsoft/microsoft-decision-1` | predicate, choice, score | Text oder JSON | $0.042 |
| `respan/span-01:free`, `respan/span-01` | nur `noul` (älteres Format) | Gesprächsausschnitt | Kostenlos (Lite) / $0.02 |
| `together/tev1-4b-experimental` | nur `choice` (älteres Format) | Text | Siehe Modellseite |

Ausgabe-Tokens sind bei jedem Modell mit angegebenem Preis kostenlos.

### TypeSafe Jev

Verwende `typesafe/jev-1.13.0` für Jev 1.13 oder `typesafe/jev-latest`, um der neuesten Jev-Version zu folgen. Die Upstream-Semantik der Fragen findest du in der [API-Referenz](https://docs.typesafe.ai/api) von TypeSafe.

Auf unterstützenden TypeSafe-Routen akzeptieren Jev 1.13 und 1.14 eingebettete PNG- oder JPEG-Bilder über `input_image` oder das ältere Feld `images`. Phaseo erstellt die Bild-Assets für TypeSafe und aktiviert die Bildunterstützung automatisch. Bilder müssen die [Bildgrenzen](https://docs.typesafe.ai/images) von TypeSafe einhalten: höchstens 16 MiB pro Bild, 256 bis 1568 Pixel pro Seite und mindestens 78.400 Pixel insgesamt. TypeSafe prüft Abmessungen und Kodierung und skaliert abgelehnte Bilder nicht. Der zugeordnete Upstream-JSON-Body ist auf 32 MiB begrenzt. Bild-Tokens kosten den normalen Eingabepreis.

`box` (auf unterstützenden Routen wie Jev 1.14) erfordert ein Bild, nimmt keine Kriterien und gibt einen Begrenzungsrahmen samt Konfidenz zurück. Seine Kanten reichen von 0 bis 1, gemessen von der oberen linken Ecke. Box gibt immer ein Rechteck zurück, kombiniere es daher mit einer `predicate`-Frage zur Anwesenheit, wenn das Ziel fehlen kann. Beziehe dich beim älteren Feld `images` auf `images[0]`, bei geordneter Eingabe auf das erste Bild oder `[Image 0]`. Siehe den [Box-Vertrag](https://docs.typesafe.ai/primitives/box).

Setze `provider_options.typesafe.long_context` auf `true`, um die Kontextgrenzen pro Anfrage und pro Frage auf 262k Tokens anzuheben, statt der Standardwerte von 64k pro Anfrage und 32k pro Frage. Langer Kontext kostet pro Token gleich viel. Bilder, Box und langer Kontext sind experimentelle Upstream-Funktionen.

```json
{
  "model": "typesafe/jev-1.14.0",
  "input": [{
    "role": "user",
    "content": [{ "type": "input_image", "image_url": "data:image/png;base64,<base64 image bytes>" }]
  }],
  "questions": [
    { "type": "predicate", "name": "visible", "instructions": "Is there a mug in the first image?" },
    { "type": "box", "name": "mug", "instructions": "The mug in the first image" }
  ],
  "provider_options": { "typesafe": { "long_context": true } }
}
```

### Cloudflare Clef und Clef Flash

`cloudflare/clef` und `cloudflare/clef-flash` laufen auf Cloudflare Workers AI. Clef hat ein Kontextfenster von 65.536 Tokens, Clef Flash von 24.576 Tokens.

```json
{
  "model": "cloudflare/clef-flash",
  "state": "Inspect the attached product photo.",
  "images": [{ "content_type": "image/png", "base64": "<base64 image bytes>" }],
  "questions": {
    "damaged": { "type": "noul", "instructions": "Is the product visibly damaged?" }
  }
}
```

`images` akzeptiert auch einen String `data:image/png;base64,...`. Clef akzeptiert bis zu vier PNG-, JPEG- oder WebP-Bilder mit jeweils höchstens 4 MiB und 16 Megapixeln, insgesamt höchstens 8 MiB dekodierter Bilddaten und einem Anfrage-Body von 13 MiB. Externe URLs werden nicht unterstützt, und Cloudflare prüft Bildformate und Abmessungen. Modelle ohne Bildunterstützung lehnen Bildanfragen ab.

Clef akzeptiert höchstens 64 Fragen mit IDs aus bis zu 100 Buchstaben, Ziffern, Unterstrichen, Punkten oder Bindestrichen. Auswahlfragen benötigen 2–255 Optionen und Bewertungsfragen 2–10 Stufen. Siehe die [Clef-Dokumentation](https://developers.cloudflare.com/workers-ai/models/clef/) von Cloudflare.

### Cloudflare Clef Omni

`cloudflare/clef-omni` akzeptiert Text, Bilder, Audio und Video. Audio- und Videoteile sind Phaseo-Erweiterungen des Eingabeformats; OpenAI-Routen akzeptieren nur Text und Bilder. Ersetze die Platzhalter-Audiobytes und die Video-URL durch deine eigenen Medien, bevor du dieses Beispiel sendest.

```json
{
  "model": "cloudflare/clef-omni",
  "input": [{
    "role": "user",
    "content": [
      { "type": "input_text", "text": "Review the recording and clip." },
      { "type": "input_audio", "input_audio": { "data": "<base64 WAV bytes>", "format": "wav" } },
      { "type": "input_video", "video_url": { "url": "https://media.example.com/clip.mp4" } }
    ]
  }],
  "questions": [{ "type": "predicate", "name": "safe", "instructions": "Is the equipment operating safely?" }]
}
```

Sende Audio als `input_audio.data` mit `format: "wav"` oder `"mp3"` oder als `input_audio.url` mit einer öffentlichen HTTPS-URL oder einer eingebetteten Audio-Data-URL. `input_video.video_url` nimmt einen String oder `{ "url": "..." }` mit einer öffentlichen HTTPS-URL oder einer eingebetteten MP4-/WebM-Data-URL. Externe Server müssen den passenden Content-Type zurückgeben. Phaseo ruft URLs mit Größenbegrenzungen sowie Prüfungen auf private Adressen und Weiterleitungen ab und bettet die Medien dann für Cloudflare ein; Anbieterzugangsdaten werden nie an den Medienserver gesendet.

| Limit | Wert |
| --- | --- |
| Audioclips | 4, jeweils höchstens 8 MiB und 300 Sekunden |
| Videos | 2, jeweils höchstens 16 MiB und 60 Sekunden |
| Audio und Video zusammen | 16 MiB dekodiert |
| Bilder | Dieselben Grenzen pro Bild und insgesamt wie bei Clef |
| Anfrage-Body | 37 MiB (ersetzt die 13 MiB von Clef) |
| Kontext | 64.000 Tokens |

Cloudflare prüft Medienkodierung, Bildabmessungen und Cliplänge und tastet Video mit zwei Bildern pro Sekunde ab. Die Tonspur eines Videos wird verwendet, wenn jedes Video in der Anfrage eine hat. Medien-Tokens zählen zum Kontext und zur Abrechnung; Phaseo rechnet anhand der von Cloudflare gemeldeten Eingabenutzung ab und berechnet Audio oder Video nicht gesondert. Siehe den [Omni-Vertrag von Cloudflare](https://github.com/cloudflare/cloudflare-docs/blob/production/src/content/workers-ai-models/clef-omni.json).

### Liquid D1 und Perplexity Decider

Liquid D1 (`liquid-ai/d1:free`, auch `liquid-ai/d1`) ist während des experimentellen Early Access kostenlos. Perplexity Decider 27B (`perplexity/decider-27b`) benötigt Perplexity-Anbieterzugangsdaten in Phaseo. Sein Bildzustand verwendet Base64-Data-URLs im PNG-, JPEG- oder WebP-Format; externe Bild-URLs werden nicht unterstützt. Bei beiden akzeptiert eine Auswahlfrage bis zu 255 Optionen und eine Bewertungsfrage bis zu 10 Stufen.

### Inception Mercury Decide

`inception/mercury-decide` nimmt Text oder JSON als Beleg. Auswahlfragen akzeptieren bis zu 255 Optionen und Bewertungsfragen bis zu 10 Stufen. Bilder, Streaming und Tool-Aufrufe werden nicht unterstützt. Der Eingabepreis von $0.02 ist eine 50-%-Aktion von Inception ohne veröffentlichtes Enddatum; prüfe vor der Nutzung die [aktuellen Upstream-Preise](https://docs.inceptionlabs.ai/get-started/models).

```json
{
  "model": "inception/mercury-decide",
  "input": "Please refund the duplicate charge on my account.",
  "questions": [{
    "type": "predicate",
    "name": "billing",
    "instructions": "Is this request about billing?"
  }]
}
```

### Microsoft Decision

`microsoft/microsoft-decision-1` läuft auf einem Azure-Foundry-Deployment und nimmt Text oder JSON als Beleg mit bis zu 32.768 Tokens. Medien, Streaming, Tools, `safety_identifier` und `service_tier` werden nicht unterstützt. Siehe den [Leitfaden von Microsoft](https://learn.microsoft.com/azure/foundry/foundry-models/how-to/use-foundry-models-microsoft-decision).

```json
{
  "model": "microsoft/microsoft-decision-1",
  "input": "The API returns 500 on every call.",
  "questions": [{
    "type": "choice",
    "name": "team",
    "instructions": "Which team should handle this ticket?",
    "choices": [
      { "value": "engineering", "description": "Bugs, errors, and outages" },
      { "value": "support", "description": "How-to and account questions" }
    ]
  }]
}
```

### Respan Span-01

Span-01 verwendet das ältere Format. `state` muss ein Gesprächsausschnitt sein: ein `input`-Array vorangehender Nachrichten und eine `output`-Assistentennachricht. Es beantwortet nur `noul`-Fragen: Der `noul`-Wert ist die Wahrscheinlichkeit, dass das Verhalten vorliegt, und `probabilities` gibt außerdem die Wahrscheinlichkeiten für „nicht vorhanden“ und „nicht beobachtbar“ an.

```json
{
  "model": "respan/span-01:free",
  "state": {
    "input": [{ "role": "user", "content": "Please connect me to a person." }],
    "output": { "role": "assistant", "content": "I will connect you to support." }
  },
  "questions": {
    "escalation": {
      "type": "noul",
      "instructions": "Does the assistant offer a human handoff?"
    }
  }
}
```

Eine Antwort sieht so aus:

```json
{
  "answers": {
    "escalation": {
      "type": "noul",
      "noul": 0.73,
      "probabilities": {
        "true": 0.73,
        "false": 0.25,
        "not_observable": 0.02
      }
    }
  }
}
```

`respan/span-01:free` ist das kostenlose Lite-Modell mit Tageslimit und entspricht dem Respan-Modell `span-01-free`. `respan/span-01` entspricht `span-01-pro` und wird von Respan abgerechnet. Span-01 ist im Early Access: Respan muss es für deine Organisation freischalten, und du hinterlegst deinen Respan-API-Schlüssel als Respan-Anbieterzugangsdaten in Phaseo, bevor du eines der beiden Modelle aufrufst.
