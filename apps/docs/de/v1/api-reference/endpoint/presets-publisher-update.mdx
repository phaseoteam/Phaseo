<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel mit `presets:write` und eine zugeordnete Nutzeridentität erforderlich.</Note>

Der bisherige Name bleibt als Alias erhalten, damit bestehende öffentliche Preset-Referenzen weiterhin aufgelöst werden.
