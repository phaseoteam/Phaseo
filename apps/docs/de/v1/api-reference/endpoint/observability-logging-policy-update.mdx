---
<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel mit `settings:write` erforderlich.</Note>

Die Aufbewahrungsdauer beträgt 90 Tage; `retention_days` muss 90 sein. Wenn die Protokollierung deaktiviert wird, wird auch die Datenschutzsperre für Ein-/Ausgabeprotokolle des Arbeitsbereichs deaktiviert.
