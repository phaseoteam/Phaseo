---
<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel mit `settings:write` erforderlich.</Note>

Die Aufbewahrungsdauer muss zwischen 90 und 365 Tagen liegen. Wenn die Protokollierung deaktiviert wird, wird auch die Datenschutzsperre für Ein-/Ausgabeprotokolle des Arbeitsbereichs deaktiviert.
