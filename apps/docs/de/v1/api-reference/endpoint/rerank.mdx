title: "Dokumente neu ordnen"
sidebarTitle: "Dokumente neu ordnen"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml POST /rerank"
description: "Dokumente mit einem unterstützten Reranking-Modell nach ihrer Relevanz für eine Anfrage sortieren."
---

Verwende diesen Endpunkt, um Kandidatendokumente neu zu ordnen, bevor sie an die Suche, den Abruf oder die Generierung übergeben werden.

Prüfe das Modell vor der Bereitstellung mit `GET /v1/models`. Die Standardantwort enthält nur Modelle mit einer öffentlichen Gateway-Route.
