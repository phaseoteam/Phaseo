---
title: "Workspace-Mitglieder entfernen"
sidebarTitle: "Mitglieder entfernen"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml POST /workspaces/{id}/members/remove"
description: "Entfernt Mitglieder außer dem Inhaber aus einem Workspace."
---
Für diesen Endpunkt sind ein Management-API-Schlüssel mit `workspaces:write` und eine Inhaber- oder Admin-Rolle erforderlich.

Der Workspace-Inhaber kann nicht entfernt werden.
