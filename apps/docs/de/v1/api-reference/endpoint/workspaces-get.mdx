description: "Ruft einen Workspace anhand seiner ID oder seines Slugs ab."
---
Für diesen Endpunkt ist ein Management-API-Schlüssel erforderlich. Standard-Gateway-API-Schlüssel werden nicht akzeptiert.

Das Pfadsegment `{id}` kann die UUID oder der Slug des Workspaces sein.
