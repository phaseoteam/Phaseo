## Server-Tools verwenden

Füge `tools` neben deinen eigenen Funktions-Tools ein `phaseo:`-Tool hinzu, und Phaseo führt es aus, wenn das Modell es aufruft. `/v1/chat/completions` akzeptiert jedes Server-Tool außer `phaseo:apply_patch`; der Leitfaden [Server-Tools](../../guides/server-tools) listet sie auf.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["Europe/London"] } }
    ],
    "tool_choice": "auto"
  }'
```

Jeder Server-Tool-Aufruf wird in `usage.server_tool_use` gezählt:

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` fügt `web_search_requests`, `web_search_results` und `web_search_extra_results` hinzu; `phaseo:web_fetch` fügt `web_fetch_requests` hinzu. Der ältere Typ `gateway:datetime` funktioniert weiterhin.

Mit `stream: true` führt Phaseo die Tool-Züge selbst aus und streamt dir dann die fortgesetzte Antwort als einen einzigen Stream.

## Reasoning in Tool-Schleifen

Reasoning-Modelle geben ihr Reasoning in der Assistentennachricht in zwei Feldern zurück:

- `reasoning_content`: der Reasoning-Text, sofern der Anbieter einen zurückgibt.
- `reasoning_details`: ein Array von Reasoning-Blöcken. Jeder Eintrag hat einen `type` (`reasoning.text`, `reasoning.summary` oder `reasoning.encrypted`), einen `index` und ein `format`, das die Anbieterfamilie nennt, zum Beispiel `anthropic-claude-v1` oder `google-gemini-v1`.

Einträge können Anbieterzustand enthalten, den das Modell im nächsten Schritt einer Tool-Schleife braucht:

| Anbieterzustand | Wo er steht |
| --- | --- |
| Claude-Thinking-Signaturen | `signature` in `reasoning.text`-Einträgen |
| Geschwärztes Claude-Thinking, verschlüsseltes OpenAI-Reasoning | `data` in `reasoning.encrypted`-Einträgen |
| Gemini-Thought-Signaturen | `data` in `reasoning.encrypted`-Einträgen, deren `id` der zugehörige Tool-Aufruf ist |
| Die Aufwandsstufe, mit der eine Claude-Antwort lief | `data` im letzten `reasoning.encrypted`-Eintrag, der keinen Text hat |

Beim Streaming kommt ein `reasoning_details`-Delta, sobald ein Reasoning-Block vollständig ist.

<Warning>
Sende jede Assistentennachricht bei jeder Anfrage mit unveränderten `reasoning_details` zurück, nicht nur in Tool-Schleifen. Verwirf, bearbeite oder sortiere Einträge nie um, ob verschlüsselt oder nicht, auch Einträge ohne Text.
</Warning>

`signature`- und `data`-Werte sind undurchsichtig und halten fest, welcher Anbieter und welches Modell sie erzeugt haben. Phaseo sendet sie nur an diese Anbieterfamilie und dieses Modell, sodass ein Fallback auf einen anderen Anbieter sie verwirft, statt fehlzuschlagen. Ohne sie führen Claude-Modelle im manuellen Thinking-Modus den nächsten Schritt der Tool-Schleife ohne Thinking aus, und eine Änderung von `reasoning_effort` startet Claudes Prompt-Cache neu; siehe [Reasoning-Aufwand mitten in der Unterhaltung ändern](../../guides/reasoning-effort).
