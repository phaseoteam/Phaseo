description: "Löscht einen Workspace anhand seiner ID oder seines Slugs."
---
<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel erforderlich. Standard-Gateway-API-Schlüssel werden nicht akzeptiert.</Note>

Der Standard-Workspace kann nicht gelöscht werden. Workspaces mit aktiven API-Schlüsseln müssen zuerst bereinigt werden.
