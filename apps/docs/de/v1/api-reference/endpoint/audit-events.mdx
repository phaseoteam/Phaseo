<Note>
Für diesen Endpunkt ist die Management-Berechtigung `activity:read` erforderlich. OAuth-Aufrufer benötigen außerdem die Rolle „Eigentümer“ oder „Administrator“ des Arbeitsbereichs.
</Note>

Ereignisse enthalten ausschließlich bereinigte Metadaten. Zugangsdaten im Klartext, Zugangsdaten-Hashes, Autorisierungsheader, vollständige Berechtigungslisten und Anfrageinhalte werden nie zurückgegeben.
