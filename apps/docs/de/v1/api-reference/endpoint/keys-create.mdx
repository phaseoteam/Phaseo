<Note>
Für diesen Endpunkt ist ein Management-API-Schlüssel erforderlich. Standard-Gateway-API-Schlüssel werden nicht akzeptiert.
</Note>

Der API-Schlüssel im Klartext wird nur bei der Erstellung einmal zurückgegeben. Die Kompatibilitätsfelder `limit`, `limit_reset` und `include_byok_in_limit` werden akzeptiert; Phaseo behandelt `include_byok_in_limit` derzeit ausschließlich aus Kompatibilitätsgründen und rechnet BYOK nie auf dieses Schlüssellimit an.
