---
title: "Workspace-Einladung löschen"
sidebarTitle: "Einladung löschen"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml DELETE /workspaces/{id}/invites/{invite_id}"
description: "Widerruft eine Workspace-Einladung dauerhaft."
---
Für diesen Endpunkt ist ein Management-API-Schlüssel mit `workspaces:write` erforderlich.

Durch das Löschen einer Einladung werden Mitglieder, die zuvor über diese Einladung beigetreten sind, nicht entfernt.
