---
title: "Berechtigungsbereiche einer autorisierten App entfernen"
sidebarTitle: "App-Bereiche reduzieren"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml PATCH /me/authorized-apps/{id}"
description: "Schränkt den Zugriff einer autorisierten App auf weniger Berechtigungsbereiche ein."
---
<Note>Für diesen Endpunkt ist ein OAuth-Zugriffstoken mit `oauth_clients:write` erforderlich. Bereiche können nur entfernt werden; zum Hinzufügen autorisierst du die App erneut im Browser.</Note>
