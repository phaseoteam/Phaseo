description: "Eine öffentliche vorgelagerte Version auf einen lokalen Fork-Entwurf anwenden."
---
<Note>Für diesen Endpunkt sind ein Management-API-Schlüssel mit `presets:write` und eine zugehörige Benutzeridentität erforderlich.</Note>

Veröffentliche oder verwerfe lokale Entwurfsänderungen, bevor du eine vorgelagerte Version anwendest. Das Anwenden veröffentlicht den resultierenden Entwurf nicht.
