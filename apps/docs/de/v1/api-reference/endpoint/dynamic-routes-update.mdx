<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel mit `settings:write` erforderlich.</Note>

Eine Änderung an `config` erstellt eine neue unveränderliche Version. Änderungen nur an Metadaten erzeugen keine neue Version.
