<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel mit `presets:write` erforderlich.</Note>

Verwende `replace_config`, um die vollständige Entwurfskonfiguration zu ersetzen. Andernfalls werden die angegebenen Konfigurationsfelder auf oberster Ebene zusammengeführt.
