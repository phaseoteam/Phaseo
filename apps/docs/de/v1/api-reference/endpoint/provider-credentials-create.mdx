description: "Anbieterzugangsdaten für das Routing des Arbeitsbereichs verschlüsseln und speichern."
---

<Warning>
Der Wert `key` ist nur schreibbar. Phaseo verschlüsselt ihn sofort und gibt ihn nie in API-Antworten zurück.
</Warning>

Verwende `routing_mode: "priority"`, um die Zugangsdaten vor der verwalteten Kapazität zu testen, oder `"fallback"`, um sie danach zu testen. Lege in den Arbeitsbereichseinstellungen mit `byokFallbackEnabled` fest, ob fehlgeschlagene priorisierte Zugangsdaten auf verwaltete Kapazität zurückgreifen dürfen.
