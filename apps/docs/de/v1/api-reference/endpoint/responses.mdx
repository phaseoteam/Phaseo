## Servertools

`/v1/responses` unterstützt reguläre Funktionstools sowie diese vom Gateway verwalteten Servertools:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`
- `phaseo:apply_patch`

### Beispiel für Datum und Uhrzeit

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "input": [
      { "role": "user", "content": "Give me the current datetime in Asia/Tokyo." }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Asia/Tokyo" }
      }
    ],
    "tool_choice": "auto"
  }'
```

Bei Verwendung eines Servertools enthält die Nutzungsübersicht die passenden `usage.server_tool_use.*`-Zähler.

- `gateway:datetime` -> `datetime_requests`
- `phaseo:web_search` -> `web_search_requests`, `web_search_results`, `web_search_extra_results`
- `phaseo:web_fetch` -> `web_fetch_requests`
- `phaseo:advisor` -> `advisor_requests`
- `phaseo:image_generation` -> `image_generation_requests`
- `phaseo:apply_patch` -> `apply_patch_requests`

## Hinweis zu Streaming

`stream: true` wird ebenfalls unterstützt. Bei vom Gateway verwalteten Servertools kann Phaseo den Upstream-Tool-Aufruf-Zug materialisieren, die Schleife fortsetzen und anschließend einen synthetischen Stream erneut ausgeben.

## Reasoning in Tool-Schleifen

Phaseo sendet Responses-Anfragen mit `store: false` an den Anbieter. Das Reasoning eines Modells setzt sich zwischen den Schritten einer Tool-Schleife daher nur über die `reasoning`-Ausgabeelemente fort.

Jedes `reasoning`-Element hat eine `id`, `summary` und `content`. Liefert der Anbieter Reasoning-Zustand, hat das Element zusätzlich `encrypted_content`:

- Verschlüsseltes Reasoning von OpenAI, Azure OpenAI und xAI. Phaseo fordert es für Reasoning-Modelle mit `include: ["reasoning.encrypted_content"]` an.
- Claude-Thinking-Signaturen und geschwärztes Thinking.
- Gemini-Thought-Signaturen, einschließlich eines eigenen `reasoning`-Elements direkt vor dem Funktionsaufruf, zu dem eine Signatur gehört.

Gestreamte Antworten enthalten dieselben Elemente in `response.output_item.done` und `response.completed`.

Um eine Tool-Schleife fortzusetzen, sende alle Ausgabeelemente unverändert in `input` zurück, auch die `reasoning`-Elemente. `encrypted_content` ist undurchsichtig und vermerkt Anbieter und Modell, die es erzeugt haben. Phaseo sendet es nur an diese Anbieterfamilie und dieses Modell. Ein Fallback auf einen anderen Anbieter verwirft es daher, statt fehlzuschlagen.
