title: "Ausgabenregeln auflisten"
sidebarTitle: "Regeln auflisten"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml GET /spend-rules"
description: "Listet die Ausgabenregeln des Arbeitsbereichs und das Limit von 50 Regeln auf."
---

Erfordert `spend_rules:read`. Alle Mitglieder des Arbeitsbereichs können Ausgabenregeln lesen. Wie Regeln ausgewertet werden, erklärt der [Leitfaden zu Ausgabenwarnungen](../../guides/spend-alerts.mdx).
