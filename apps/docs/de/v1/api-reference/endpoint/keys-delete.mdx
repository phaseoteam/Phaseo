title: "API-Schlüssel löschen"
sidebarTitle: "API-Schlüssel löschen"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml DELETE /keys/{id}"
description: "Löscht einen API-Schlüssel im authentifizierten Workspace."
---
<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel erforderlich. Standard-Gateway-API-Schlüssel werden nicht akzeptiert.</Note>

Aus Sicht der öffentlichen API ist die Löschung dauerhaft. Die Antwort bestätigt, dass der Schlüssel gelöscht wurde.
