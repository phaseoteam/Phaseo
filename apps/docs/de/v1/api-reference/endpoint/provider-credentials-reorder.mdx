---
title: "Anbieterzugangsdaten neu sortieren"
sidebarTitle: "Zugangsdaten neu sortieren"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml POST /byok/reorder"
description: "Ersetzt die Priorität von Zugangsdaten innerhalb einer Anbieter-Routinggruppe."
---
Gib jede Zugangsdaten-ID der ausgewählten Anbieter- und Routinggruppe genau einmal an. Die erste ID erhält die höchste Priorität. Unvollständige oder doppelte Reihenfolgen werden abgelehnt.
