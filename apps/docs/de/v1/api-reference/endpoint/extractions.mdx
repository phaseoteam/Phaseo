<Warning>Die Extraktion ist eine Vorschau. Die Modellverfügbarkeit hängt von den konfigurierten Anbieterrouten ab.</Warning>

Benenne die gewünschten `fields` und sende sie zusammen mit deinem Quelltext an `POST /v1/extractions`, um typisierte Werte zurückzubekommen, etwa eine Rechnungsnummer, ein Datum oder eine Gesamtsumme. Um stattdessen zwischen bekannten Optionen zu wählen, verwende [Decisions](./decisions.mdx).

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/extractions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cloudflare/clairic",
    "input": "Invoice INV-2291: 4 pallets at $250 each, shipping $80.",
    "fields": {
      "invoice_number": { "type": "text" },
      "total": { "type": "number", "decimals": 2, "instructions": "Total including shipping" }
    }
  }'
```

```typescript TypeScript SDK
import { Phaseo } from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY });
const result = await client.extractions.create({
  model: "cloudflare/clairic",
  input: "Invoice INV-2291: 4 pallets at $250 each, shipping $80.",
  fields: {
    invoice_number: { type: "text" },
    total: { type: "number", decimals: 2, instructions: "Total including shipping" },
  },
});
console.log(result.answers.total.value);
```

```python Python SDK
import os
from phaseo import Phaseo

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])
result = client.extractions.create({
    "model": "cloudflare/clairic",
    "input": "Invoice INV-2291: 4 pallets at $250 each, shipping $80.",
    "fields": {"total": {"type": "number", "decimals": 2,
                         "instructions": "Total including shipping"}},
})
print(result["answers"]["total"]["value"])
```
</CodeGroup>

Die Beispiele benötigen eine aktive Route für ein Extraktionsmodell, prüfe also die
Modellverfügbarkeit, bevor du Anfragen sendest. Python `AsyncPhaseo` stellt außerdem
`await client.extractions.create(...)` bereit.

## Feldtypen

Unterstützte Typen sind `text`, `number`, `date`, `time`, `datetime`, `duration` und
`list`. Listen erfordern `items: "text"`, `"number"` oder `"date"`. Gib 1–64 Felder
und höchstens 16.384 Zeichen Quelltext an. Feldnamen beginnen mit einem Buchstaben oder Unterstrich
und enthalten bis zu 64 Buchstaben, Ziffern, Unterstriche, Punkte oder Bindestriche.

Zahlen und Zeitdauern unterstützen `integer` und `decimals` (0–6). Zeitdauern akzeptieren
`seconds`, `minutes`, `hours`, `days`, `weeks`, `months` oder `years`. Setze
`reference_date`, wenn die Deutung unvollständiger Datumsangaben von einem bestimmten Jahr abhängt.

Bildeingaben verwenden `{ content_type, base64 }`-Objekte: höchstens vier PNG-/JPEG-/WebP-Bilder,
jeweils 4 MiB und zusammen 8 MiB nach dem Dekodieren. Das Anfragelimit liegt bei 16 MiB.
Externe URLs, PDFs, Audio, Video, Schätzungen, Prognosen und Streaming werden nicht unterstützt.

## Antworten lesen

Lies `answers[field_name].value`. Ein skalarer Wert kann `null` sein, wenn die Quelle
ihn nicht festlegt. `p_null` ist die Wahrscheinlichkeit des Modells für einen unbestimmten Wert;
`confidence` ist ein separater, vom Modell gemeldeter Wert. Listen liefern Konfidenz ohne
`p_null`. Diese Werte garantieren keine Korrektheit: Wähle Prüfschwellen für
deine Arbeitslast. Eine gültige leere Liste ist etwas anderes als eine fehlgeschlagene Anfrage.

`truncated: true` bedeutet, dass der Anbieter nicht die gesamte Quelleingabe verarbeitet hat. Prüfe die Eingabe
oder sende eine kürzere erneut, bevor du dich auf Vollständigkeit verlässt. Textpositionen und Rohschätzungen
werden nicht bereitgestellt. Komplexe Berechnungen solltest du im Anwendungscode durchführen.

Die Nutzung meldet `input_tokens` aufsummiert über alle Anbieterdurchläufe. Ausgabe-Tokens sind
null. Verwende die vom Gateway zurückgegebenen Preise, statt die Kosten aus der Quelllänge zu schätzen
oder die Nutzung mit der Anzahl der Felder zu multiplizieren.
