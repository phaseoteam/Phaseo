<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel mit `presets:write` und eine zugeordnete Nutzeridentität erforderlich.</Note>

Die Preset-Konfiguration kann begrenzte Standardwerte für Prompts, Parameter, Routing und Plugins enthalten. Öffentliche Presets verwenden den Herausgebernamen des Workspaces.
