Wenn du `key` angibst, wird das verschlüsselte Secret ersetzt. Ohne Angabe bleibt das vorhandene Secret erhalten. Modell- und API-Schlüssel-Allowlisten sind optional; eine leere Liste erlaubt alle Modelle oder API-Schlüssel im Workspace.
