<Info>
Für die Guardrail-Verwaltung ist ein Management-API-Schlüssel erforderlich. Lesevorgänge benötigen `guardrails:read`, Änderungen `guardrails:write` oder `guardrails:delete`.
</Info>

Mit Guardrails kannst du Datenschutzkontrollen, Anbieter- und Modellbeschränkungen, den Umgang mit Prompt-Injection, Richtlinien für vertrauliche Informationen sowie Anfrage- oder Kostenlimits anwenden. Ein Guardrail kann API-Schlüsseln, Arbeitsbereichsmitgliedern oder beiden zugewiesen werden.

Erfolgreiche Änderungen aktualisieren den Richtlinienstatus des Arbeitsbereichs und erscheinen im Auditprotokoll.
