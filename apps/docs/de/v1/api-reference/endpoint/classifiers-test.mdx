<Note>Dieser Endpunkt stellt mit deinen eigenen Anmeldedaten eine kostenpflichtige Modellanfrage, daher ist ein OAuth-Token mit `classifiers:write` und `gateway:access` erforderlich. Management-Schlüssel werden nicht akzeptiert.</Note>
