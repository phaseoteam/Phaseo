title: "Privates Modell erstellen"
sidebarTitle: "Privates Modell erstellen"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml POST /private-models"
description: "Verbinde einen OpenAI-kompatiblen Endpunkt mit dem authentifizierten Arbeitsbereich."
---

Erfordert `private_models:write` und eine Besitzer- oder Administratoridentität. Gib für `model_reference` entweder eine exakte Modell-ID aus dem Katalog oder einen kurzen arbeitsbereichslokalen Slug an. Phaseo weist die endgültige Modell-ID zu; `credential` wird verschlüsselt und ist nur schreibbar.
