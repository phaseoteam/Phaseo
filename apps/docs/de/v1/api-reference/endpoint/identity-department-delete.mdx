---
title: "Workspace-Abteilung löschen"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml DELETE /identity/departments/{id}"
---
<Note>Die Verwaltung von Unternehmensverzeichnissen erfordert das Identity-Add-on, eine Owner- oder Admin-Identität und den passenden Einstellungsbereich.</Note>

Wenn Verzeichnisgruppen-Zuordnungen die Abteilung verwenden, kann nur der Workspace-Inhaber sie löschen, denn dabei werden auch diese Zuordnungen und die Rollen gelöscht, die sie vergeben.
