Übergib die `id`, die [`POST /v1/music/generate`](./music-generate.mdx) zurückgegeben hat, nicht deren `nativeResponseId`. Phaseo gibt das gespeicherte Ergebnis zurück, wenn die Generierung fertig ist, und fragt für dich beim Anbieter nach, solange sie noch läuft.

```bash
curl https://api.phaseo.app/v1/music/generate/req_01JY6MUSIC123 \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "suno",
  "model": "V4_5PLUS",
  "nativeResponseId": "task_123",
  "output": [
    {
      "index": 0,
      "id": "clip_1",
      "audio_url": "https://...",
      "stream_audio_url": "https://...",
      "image_url": "https://...",
      "title": "Midnight Blue",
      "tags": "jazz, piano",
      "duration": 8
    }
  ],
  "usage": {
    "output_audio_count": 1,
    "output_audio_seconds": 8
  }
}
```

`status` ist `queued`, `in_progress`, `completed` oder `failed`. `usage` ist enthalten, sobald die Generierung abgeschlossen ist.
