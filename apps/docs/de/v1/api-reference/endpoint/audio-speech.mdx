## Eine Stimme wählen

Setze `voice` auf oberster Ebene für portable Anfragen. Phaseo ordnet sie der Stimme des gerouteten Anbieters zu; eine `voice`, die der geroutete Anbieter und das Modell nicht akzeptieren, gibt `400 invalid_request_error` mit `param: "voice"` zurück.

| Anbieter | Akzeptierte `voice`-Werte | Hörproben |
| --- | --- | --- |
| `openai` | Gängige Stimmen, zum Beispiel `alloy`, `ash`, `ballad`, `coral`, `echo`, `fable`, `onyx`, `nova`, `sage`, `shimmer`, `verse`, `cedar`, `marin` | [openai.fm](https://www.openai.fm/) |
| `google` (AI Studio / Gemini TTS) | Vorgefertigte Stimmen: `Zephyr`, `Puck`, `Charon`, `Kore`, `Fenrir`, `Leda`, `Orus`, `Aoede`, `Callirrhoe`, `Autonoe`, `Enceladus`, `Iapetus`, `Umbriel`, `Algieba`, `Despina`, `Erinome`, `Algenib`, `Rasalgethi`, `Laomedeia`, `Achernar`, `Alnilam`, `Schedar`, `Gacrux`, `Pulcherrima`, `Achird`, `Zubenelgenubi`, `Vindemiatrix`, `Sadachbia`, `Sadaltager`, `Sulafat` | [Gemini-Dokumentation zur Sprachsynthese](https://ai.google.dev/gemini-api/docs/speech-generation#voices) |
| `elevenlabs` | Gängige öffentliche Einstiegsstimmen, zum Beispiel `rachel`, `domi`, `bella`, `antoni`, `elli`, `josh`, `arnold`, `adam`, `sam` | [ElevenLabs Voice Library](https://elevenlabs.io/voice-library) |

Übergib für `eleven-labs/eleven-v4` und `eleven-labs/eleven-v4-turbo` eine beliebige 20-stellige ID aus der ElevenLabs-Stimmenbibliothek, auch für einen eigenen Stimmenklon. Setze `config.elevenlabs.voice_settings.stability` und `similarity_boost` nach Bedarf. Eleven v4 unterstützt weder `speed` noch `voice_settings.style`.

## Eine anbieternative Stimme übergeben

So verwendest du statt `voice` die eigene Stimmeinstellung eines Anbieters:

- ElevenLabs: `config.elevenlabs.voice_id`, `config.elevenlabs.voice` oder `config.elevenlabs.voiceName`.
- Google: `config.google.voice_name` oder `config.google.voiceName`.
