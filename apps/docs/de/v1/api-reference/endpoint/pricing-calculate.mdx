description: "Schätze die Kosten für eine bestimmte Nutzung eines Anbieters, Modells und Endpunkts."
---

Sende eine Nutzungs-Payload, um sie anhand der aktiven Gateway-Preisregeln für einen Anbieter, ein Modell und einen Endpunkt zu bepreisen. Alle vier Felder sind Pflicht:

- `provider`: die Anbieter-ID, zum Beispiel `openai`.
- `model`: die geroutete Modell-ID.
- `endpoint`: die Endpunktfamilie, zum Beispiel `responses` oder `chat.completions`.
- `usage`: die zu bepreisende Nutzung, etwa Token-Anzahlen oder andere Messwerte.

Um aktuelle Preise aufzulisten, statt eine einzelne Payload zu bepreisen, verwende [Modellpreise auflisten](./pricing-models.mdx).
