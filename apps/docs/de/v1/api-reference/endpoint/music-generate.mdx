Sende `model` und `prompt` an `POST /v1/music/generate`, um mit einer einzigen Anfrageform einen Track von jedem Musikanbieter zu erhalten. Phaseo kümmert sich für dich um synchrone Anbieter und das Abfragen von Anbieterwarteschlangen.

```bash
curl https://api.phaseo.app/v1/music/generate \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax/music-3.0:free",
    "prompt": "Warm jazz trio with brushed drums",
    "format": "mp3"
  }'
```

## Das Ergebnis lesen

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "gmicloud",
  "model": "minimax/music-3.0:free",
  "nativeResponseId": "5c30b275-d669-4a25-8151-de6d60214853",
  "audio_url": "https://.../generated-music.mp3",
  "usage": {
    "requests": 1,
    "output_audio_seconds": 25.364
  }
}
```

Eine abgeschlossene Generierung enthält `audio_url` oder `audio_base64`. `status` ist `queued`, `in_progress`, `completed` oder `failed`. Ist der Status noch nicht endgültig, frage [`GET /v1/music/generate/{music_id}`](./music-status.mdx) mit derselben `id` ab.

`id` ist die stabile Phaseo-Anfrage-ID. `nativeResponseId` ist die Kennung des Upstream-Anbieters, zur Zuordnung beim Anbieter und für den Support. `usage` enthält `output_audio_seconds`, wenn der Anbieter die generierte Dauer meldet.

## Suno-Optionen festlegen

Suno-Modelle nehmen ein optionales `suno`-Objekt:

| Feld | Typ | Hinweise |
| --- | --- | --- |
| `customMode` | boolean | Standard `false` |
| `instrumental` | boolean | Standard `false` |
| `prompt` | string | Überschreibt `prompt` auf oberster Ebene |
| `style`, `title` | string | Pflicht, wenn `customMode` gleich `true` ist |
| `personaId`, `personaModel` | string | |
| `negativeTags` | string | |
| `vocalGender` | `m` oder `f` | |
| `styleWeight`, `weirdnessConstraint`, `audioWeight` | number | 0 bis 1 |

`prompt` ist Pflicht, wenn `customMode` gleich `false` ist, und wenn `customMode` gleich `true` ist und `instrumental` auf `false` steht.

Eine Anfrage, die gegen eine Anbieterregel verstößt, gibt `400` zurück:

```json
{
  "error": "validation_error",
  "reason": "..."
}
```
