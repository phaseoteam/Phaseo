<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel mit `workspaces:write` erforderlich.</Note>

Bei der Genehmigung werden der Ablauf und die verbleibenden Nutzungen der Einladung geprüft, die Einladungsrolle angewendet und die Entscheidung in einer Transaktion gespeichert.
