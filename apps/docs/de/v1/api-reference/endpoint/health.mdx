Verwende diesen nicht authentifizierten Endpunkt für eine einfache Erreichbarkeitsprüfung. Aktuelle Vorfälle und den Verlauf findest du auf der [Phaseo-Statusseite](https://status.phaseo.app).

<Note>
Eine erfolgreiche Statusantwort belegt nicht, dass alle Anbieter- oder Modellrouten verfügbar sind. Prüfe mit der Standardantwort von `GET /v1/models`, welche Routen aktuell erreichbar sind.
</Note>
