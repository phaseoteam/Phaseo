<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel mit `analytics:read` erforderlich.</Note>

Der Export akzeptiert dieselben Filter wie der Analyse-Endpunkt und gibt alle passenden aggregierten Zeilen als tabellenkalkulationssicheres CSV zurück.
