Dieser Endpunkt hat den Status [Beta](../../developers/feature-maturity.mdx) und wird auf Anfrage pro Workspace freigeschaltet.

Diese Route leitet die Dateibytes vom Upstream erst weiter, nachdem bestätigt wurde, dass die Datei zum aktuellen Workspace gehört.
