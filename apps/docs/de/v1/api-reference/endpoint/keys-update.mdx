<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel erforderlich. Standard-Gateway-API-Schlüssel werden nicht akzeptiert.</Note>

Mit dieser Route kannst du einen Schlüssel umbenennen, Berechtigungsbereiche anpassen, einen Ablauf festlegen, den Schlüssel deaktivieren oder mit `limit` und `limit_reset` ein Ausgabenlimit setzen.
