description: "Liste fähigkeitsbasierte Gateway-Endpunkte mit öffentlichen Pfaden sowie Modell- und Anbieterabdeckung auf."
---

Die Antwort hat drei Felder:

- `endpoints`: die kanonischen Endpunkt-IDs, die die API aktuell bereitstellt.
- `data`: ein Datensatz pro Endpunkt mit `id`, `capability_id`, `public_path`, `collection`, `model_count` und `provider_count`, sortiert nach `public_path`.
- `sample_models`: die ersten 10 sichtbaren Modell-IDs aus dem öffentlichen Katalog.

Die Antwort wird 30 Minuten lang zwischengespeichert.

Verwende [Endpunktfähigkeiten eines Modells auflisten](./model-endpoints), wenn du Details auf Anbieter- und Parameterebene für ein einzelnes Modell brauchst.
