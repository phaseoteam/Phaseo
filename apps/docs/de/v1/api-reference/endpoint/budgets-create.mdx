---
title: "Workspace-Budget erstellen"
sidebarTitle: "Budget erstellen"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml POST /budgets"
description: "Erstelle eine tägliche, wöchentliche, monatliche oder unbefristete Ausgabenobergrenze für den Workspace."
---

Erfordert `budgets:write`. Beträge werden in USD angegeben. Ein Workspace kann pro Intervall ein Budget haben; ein zweites zu erstellen gibt `409` `conflict` zurück.
