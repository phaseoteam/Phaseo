---
<Note>
Für diesen Endpunkt ist ein Management-API-Schlüssel erforderlich. Standard-Gateway-API-Schlüssel werden nicht akzeptiert.
</Note>

Gibt Metadaten für einen API-Schlüssel im authentifizierten Arbeitsbereich zurück. Das Pfadsegment `{id}` kann die interne Schlüssel-ID oder der von der API zurückgegebene Schlüssel-Hash sein.
