---
title: "Workspace-Mitglieder hinzufügen"
sidebarTitle: "Mitglieder hinzufügen"
badge: "Beta"
openapi: "/de/openapi/v1/openapi.localized.yaml POST /workspaces/{id}/members/add"
description: "Fügt vorhandene Nutzer zu einem Workspace hinzu."
---
<Note>Für diesen Endpunkt sind ein Management-API-Schlüssel mit `workspaces:write` und eine Inhaber- oder Admin-Rolle erforderlich.</Note>

Die Rolle kann `admin` oder `member` sein. Die Workspace-Inhaberschaft kann über diesen Endpunkt nicht zugewiesen werden.
