<Note>Für diesen Endpunkt ist ein Management-API-Schlüssel mit `settings:write` erforderlich.</Note>

Änderungen an Routing und Anbieterrichtlinien aktualisieren betroffene Gateway-Caches und werden im Workspace-Auditprotokoll erfasst.
