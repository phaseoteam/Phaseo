<Note>Für die Identitätsverwaltung ist eine Owner- oder Admin-Identität erforderlich. Zum Aktivieren von SSO oder SCIM und zum Erstellen von Provisioning-Tokens wird das Identity-Add-on benötigt.</Note>

Nur der Workspace-Inhaber kann die Single-Sign-on-Einstellungen ändern, weil Anmeldungen über den Identitätsanbieter mit den Verzeichnisbenutzern des Workspace verknüpft werden.
