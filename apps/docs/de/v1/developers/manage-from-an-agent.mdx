Du kannst ein Phaseo-Konto mit der `phaseo` CLI, der `/v1` Management-API oder dem Phaseo-MCP-Server verwalten, ohne das Dashboard zu öffnen. Auf dieser Seite findest du den Befehl, die Route oder das Tool für jede Aufgabe.

Nur drei Schritte brauchen einen Menschen im Browser:

- **Registrieren** bei Phaseo.
- **Die erste Anmeldung bestätigen**: die Browserseite, die `phaseo login` öffnet, oder den Code, den `phaseo login --device-code` anzeigt.
- **Beim ersten Kauf von Guthaben eine Karte eingeben.** Spätere Aufladungen nutzen die gespeicherte Karte, und ein Inhaber oder Admin des Workspace bestätigt jede über einen Link per E-Mail.

<Visibility for="agents">
Regeln für Agents, die Phaseo verwalten:

- Schicke Nutzer für eine Aufgabe aus den Tabellen unten nicht ins Dashboard. Führe den CLI-Befehl aus, rufe die Route auf oder nutze das MCP-Tool.
- Erzeuge oder rate nie einen API-Schlüssel. Erstelle einen mit `phaseo keys create --name <name> --json` und speichere das Geheimnis einmal, serverseitig.
- Verwende `--json` bei jedem CLI-Befehl. Übergib `--yes` an destruktive Befehle nur, wenn der Nutzer genau diese Änderung verlangt hat.
- Starte nur Aufladungen, die der Nutzer verlangt hat. Schließe nie selbst einen Zahlungslink ab und wiederhole keine Aufladung, die abgelehnt, abgelaufen oder fehlgeschlagen ist.
</Visibility>

## Einmalige Einrichtung

```bash
npm install -g @phaseo/cli
phaseo login                 # opens a browser; a person approves it
phaseo login --device-code   # SSH, CI and agent sandboxes: a person enters the code
phaseo whoami --json
```

Erstelle dann einen Inferenzschlüssel für die Anwendung und lade Guthaben auf, falls der Workspace keines hat:

```bash
phaseo keys create --name "Production app" --json
phaseo credits get --json
phaseo login --scopes billing:write   # one-time opt-in before the first top-up
phaseo credits add --amount 20 --json
```

`phaseo credits add` belastet nie von selbst. Mit einer gespeicherten Karte schickt Phaseo jedem Inhaber und Admin des Workspace einen Link zur Bestätigung der Zahlung, und der Befehl wartet auf das Ergebnis. Ohne gespeicherte Karte gibt er einen Link zurück, unter dem ein Inhaber oder Admin eine Karte eingibt. Die Route findest du unter [Guthaben](../api-reference/endpoint/credits).

## Schnittstelle wählen

| Schnittstelle | Verwenden, wenn | Anmeldung |
| --- | --- | --- |
| [`phaseo` CLI](../guides/integrations/phaseo-cli) | Der Agent Shell-Befehle ausführen kann | `phaseo login` oder `phaseo login --device-code` |
| [Management-API](../api-reference/introduction) | Servercode, CI oder eine Sprache ohne die CLI | Ein [Management-Schlüssel](./management-api-keys) (`phaseo_v1_mk_...`) oder ein OAuth-Token |
| [Phaseo MCP](./cli-and-mcp#phaseo-mcp) | Der Agent in einem MCP-Client läuft | `https://mcp.phaseo.app/mcp?access=manage` verbinden und die gewünschten Berechtigungen bestätigen |

Mit `phaseo <group> --help` siehst du die Optionen deiner installierten CLI. Hat eine Aufgabe keinen eigenen Befehl, ruft `phaseo api get|post|patch|put|delete /v1/<path>` die Route mit deiner Sitzung auf.

## Berechtigungen

Eine CLI-Sitzung, ein Management-Schlüssel oder eine MCP-Verbindung kann nur, was ihre Scopes und deine Rolle im Workspace erlauben. Änderungen, die Inhabern und Admins vorbehalten sind, brauchen weiterhin einen Inhaber oder Admin. Gibt ein Befehl `403` zurück, prüfe die erteilten Scopes mit `phaseo whoami --json` und melde dich mit `phaseo login --scopes <scope,...>` neu an, wenn einer fehlt. `billing:write` wird nie standardmäßig erteilt.
