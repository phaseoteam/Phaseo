Speichere einen Phaseo-Schlüssel auf deinem Server, wähle den Endpunkt, der zum Protokoll deiner App passt, und richte deinen HTTP-Client oder dein SDK auf `https://api.phaseo.app/v1` aus. Beginne mit dem [Schnellstart](../quickstart.mdx), falls du noch keine Anfrage gesendet hast.

Du brauchst ein Phaseo-Konto mit Gateway-Zugriff und einen HTTP-Client, ein OpenAI-kompatibles SDK oder ein Phaseo-SDK. Die Beispiele verwenden `google/gemma-3-27b:free`, das ohne eingezahlte Credits läuft.

<Steps>
<Step title="Einen Schlüssel erstellen und speichern">

Öffne **Einstellungen → API-Schlüssel** im [Dashboard](https://phaseo.app/settings/keys) oder rufe `POST /v1/keys` mit einem Management-Schlüssel auf. Benenne den Schlüssel nach App und Umgebung und speichere ihn dann in einem Secrets-Manager oder einer Umgebungsdatei:

```bash
# .env.local
PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
PHASEO_BASE_URL="https://api.phaseo.app/v1"
```

Verwende getrennte Schlüssel für lokale Entwicklung, Preview-Deployments und Produktion, damit du jeden einzeln rotieren und prüfen kannst.

</Step>
<Step title="Den Endpunkt wählen">

| Endpunkt | Verwendung |
| --- | --- |
| `/v1/responses` | Neue Text-Integrationen, strukturierte Ausgabe und mehrstufige Workflows. |
| `/v1/chat/completions` | Chat-Oberflächen und bestehende Integrationen im OpenAI-Stil. |
| `/v1/messages` | Anthropic-kompatible Integrationen. |
| `/v1/decisions` | Typisierte Entscheidungen anhand des Anwendungszustands, mit Jev 1.13 (Beta). |
| `/v1/moderations` | Prüfungen auf Sicherheit und Inhaltsrichtlinien. |
| `/v1/images/generations` | Bilder aus Text-Prompts. |

Die [API-Referenz](../api-reference/introduction) listet jeden Endpunkt, Parameter und jede Antwort auf.

</Step>
<Step title="Eine Anfrage aus deiner App senden">

Dieses Beispiel verwendet Chat Completions, das OpenAI-kompatible Clients bereits sprechen. Jede Anfrage sendet den Schlüssel als `Authorization: Bearer $PHASEO_API_KEY`.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemma-3-27b:free",
    "messages": [
      { "role": "system", "content": "You are a helpful assistant." },
      { "role": "user", "content": "Explain the benefits of AI." }
    ]
  }'
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});

const response = await client.chat.completions.create({
  model: "google/gemma-3-27b:free",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: "Explain the benefits of AI." },
  ],
});

console.log(response.choices[0]?.message?.content);
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.phaseo.app/v1",
)

response = client.chat.completions.create(
    model="google/gemma-3-27b:free",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain the benefits of AI."},
    ],
)

print(response.choices[0].message.content)
```

```go Go
package main

import (
  "context"
  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4"
)

func main() {
  client := phaseo.New("YOUR_API_KEY", "https://api.phaseo.app/v1")

  response, err := client.CreateChatCompletion(context.Background(), phaseo.ChatCompletionsRequest{
    Model: "google/gemma-3-27b:free",
    Messages: []map[string]interface{}{
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain the benefits of AI."},
    },
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(response)
}
```

<Note>
Modelle, deren ID auf `:free` endet, laufen ohne eingezahlte Credits. Kostenpflichtige Modelle brauchen ein verfügbares Guthaben in der Wallet.
</Note>
