# CLI und MCP

Nutze Phaseo im Terminal mit der CLI oder verbinde einen KI-Client über MCP. Beide verwenden Phaseo OAuth, sind aber für unterschiedliche Aufgaben gedacht.

| Schnittstelle | Am besten für | Zugriff |
| --- | --- | --- |
| Phaseo CLI | Terminal-Workflows, CI, Verwaltung und Automatisierung | Lesen und Schreiben, beschränkt durch deine Scopes und Workspace-Rolle |
| Phaseo MCP | Live-Phaseo-Daten in Codex, Claude, ChatGPT und anderen MCP-Clients sowie optionale Kontoverwaltung | Authentifiziert; schreibgeschützt, außer du verbindest dich mit Kontoverwaltung |
| Docs MCP | Aktuelle Phaseo-Dokumentation beim Programmieren nachschlagen | Nur Dokumentation und schreibgeschützt |
| Phaseo-Plugin | Phaseo MCP, Docs MCP und die Phaseo-Skills in einem Schritt in Claude Code oder Codex installieren | Wie beim jeweiligen MCP-Server |

## Phaseo CLI

Verwende die CLI, um Phaseo-Ressourcen zu erstellen oder zu ändern, Workflows zu automatisieren oder Kontodaten in einer Shell zu prüfen.

### Installieren und anmelden

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

Interaktive Terminals verwenden standardmäßig Browser-OAuth. Für SSH, CI und Umgebungen ohne Benutzeroberfläche verwendest du die Geräteautorisierung:

```bash
phaseo login --device-code
```

### Häufige Workflows

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys create --name "Local development"
phaseo logs list --since 1h --status error --json
```

Verwende `--json`, wenn ein anderes Tool oder Skript strukturierte Ausgaben benötigt. Geheimnisse werden nur von Befehlen angezeigt, die sie ausdrücklich erstellen oder offenlegen.

## Phaseo MCP

Verbinde den Phaseo-MCP-Server, wenn ein KI-Client Fragen mit aktuellen Daten zu Modellen, Preisen, Anbietern, Nutzung und Workspaces beantworten soll.

### Server-URL

`https://mcp.phaseo.app/mcp`

### Von Codex aus verbinden

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

Der Anmeldebefehl öffnet Phaseo OAuth. Wähle einen Workspace aus, genehmige die angeforderten Leseberechtigungen und bestätige anschließend die Verbindung:

```bash
codex mcp list
```

Füge für einen anderen MCP-Client dieselbe URL als entfernten Streamable-HTTP-Server hinzu. Der Client muss OAuth Discovery, den Authorization-Code-Flow mit S256 PKCE und den MCP-Parameter `resource` unterstützen.

### Über MCP verfügbare Daten

- Modelle, Anbieter, Benchmark-Ranglisten, Preise und Kostenschätzungen
- Guthaben, Aktivität, Analysen, Anfrageprotokolle und Generierungsmetadaten

Diese Tools sind schreibgeschützt. Sie geben niemals Prompts, Antworten oder geheime Werte zurück.

### Konto verwalten (optional)

Damit ein Agent deinen Phaseo-Workspace ändern kann, verbinde dich stattdessen über die Verwaltungs-URL:

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

Bei der Anmeldung listet der Zustimmungsbildschirm jede angeforderte Berechtigung einzeln auf, etwa das Verwalten von API-Schlüsseln oder das Löschen von Budgets, und kennzeichnet sie mit **Lesen**, **Schreiben** oder **Löschen**. Entferne das Häkchen bei allem, was du nicht erlauben möchtest. Der Agent erhält nur Tools für die erlaubten Berechtigungen, und Phaseo prüft bei jeder Änderung weiterhin deine Workspace-Rolle. Ein Mitglied, das weder Owner noch Admin ist, kann auf diesem Weg also keine Einstellungen ändern, die Admins vorbehalten sind.

Wenn du dich bereits über die schreibgeschützte URL verbunden hast, stelle den Client auf die Verwaltungs-URL um und melde dich erneut an. Um zum schreibgeschützten Zugriff zurückzukehren, verbinde dich wieder über die normale URL oder widerrufe die App unter **Einstellungen → Verbundene Apps**.

| Bereich | Tools | Berechtigungen |
| --- | --- | --- |
| API-Schlüssel | `api_keys_list`, `api_key_get`, `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete` | `keys:read`, `keys:write`, `keys:delete` |
| Budgets | `budgets_list`, `budget_create`, `budget_update`, `budget_delete` | `budgets:read`, `budgets:write`, `budgets:delete` |
| Ausgabenregeln | `spend_rules_list`, `spend_rule_create`, `spend_rule_update`, `spend_rule_delete` | `spend_rules:read`, `spend_rules:write`, `spend_rules:delete` |
| Anbieter-Schlüssel (BYOK) | `provider_keys_list`, `provider_key_create`, `provider_key_update`, `provider_key_delete` | `provider_credentials:read`, `provider_credentials:write`, `provider_credentials:delete` |
| Guardrails | `guardrails_list`, `guardrail_get`, `guardrail_create`, `guardrail_update`, `guardrail_delete`, `guardrail_keys_set` | `guardrails:read`, `guardrails:write`, `guardrails:delete` |
| Voreinstellungen | `presets_list`, `preset_get`, `preset_create`, `preset_update`, `preset_version_publish` | `presets:read`, `presets:write` |
| Einstellungen | `settings_get`, `settings_update` (Routing-Modus, Datenschutz und ZDR, Protokollierung, Anbieterbeschränkungen) | `settings:read`, `settings:write` |
| Webhooks | `webhooks_list`, `webhook_create`, `webhook_delete` | `settings:read`, `settings:write` |
| Observability-Ziele | `observability_destinations_list`, `observability_destination_create`, `observability_destination_delete` | `settings:read`, `settings:write` |

Tools, die etwas ändern oder löschen, sind entsprechend gekennzeichnet, sodass MCP-Clients, die das unterstützen, vor jedem Aufruf nachfragen. Ein neuer API-Schlüssel oder ein neues Webhook-Signaturgeheimnis wird einmal im Tool-Ergebnis angezeigt und kann danach nicht erneut angezeigt werden. Gespeicherte Anbieter-Schlüssel und Zugangsdaten von Zielen werden nie zurückgegeben.

MCP bietet keine Tools für Abrechnung, Zahlungen, Workspaces, Mitglieder, Management-Schlüssel oder OAuth-Apps. Nutze dafür das Dashboard, die CLI oder die Management-API.

## Docs MCP

Docs MCP ist ein separater Endpunkt zum Suchen und Lesen der Phaseo-Dokumentation. Er greift nicht auf dein Konto oder deinen Workspace zu.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

Verwende ihn, wenn ein Coding-Assistent aktuelle API-Beispiele, Integrationshinweise oder Feature-Dokumentation benötigt.

## Phaseo-Plugin

Das Phaseo-Plugin bündelt Phaseo MCP, Docs MCP und die Phaseo-Agent-Skills für Integration, Migration, Modellauswahl, Nutzungsüberwachung, die SDKs und die CLI. Installiere es einmal, statt jeden Teil selbst zu verbinden.

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

Führe `/mcp` aus und melde dich bei `plugin:phaseo:phaseo` an, um dein Phaseo-Konto zu verbinden. Skills werden geladen, wenn eine Anfrage zu ihnen passt, oder du rufst einen direkt auf, zum Beispiel `/phaseo:phaseo-gateway`.

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

Der letzte Befehl öffnet Phaseo OAuth für Phaseo MCP. Skills werden geladen, wenn eine Anfrage zu ihnen passt.

## Die passende Schnittstelle auswählen

- Verwende die **CLI**, um Schlüssel zu erstellen, Einstellungen zu ändern, Workspaces zu verwalten oder administrative Abläufe zu automatisieren.
- Verwende **Phaseo MCP**, um einem KI-Client sicheren Zugriff auf aktuelle Phaseo-Daten zu geben.
- Verwende **Docs MCP**, um einem Coding-Assistenten aktuelle Phaseo-Dokumentation bereitzustellen, ohne Kontozugriff zu gewähren.
- Verwende das **Phaseo-Plugin**, um beide MCP-Server und die Phaseo-Skills in einem Schritt in Claude Code oder Codex einzurichten.
