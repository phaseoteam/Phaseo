Ändere die Modell-ID und führe deinen Validierungssatz erneut aus; Anfrage- und Antwortformen bleiben gleich. Neu ist nur die Steuerung, wie tief die Multi-Agenten-Variante arbeitet.

| Modell | Phaseo-Modell-ID | Reasoning-Steuerung |
| --- | --- | --- |
| Grok 4.20 | `spacex-ai/grok-4.20` | `reasoning.enabled`: an oder aus |
| Grok 4.20 Multi-Agent (Beta) | `spacex-ai/grok-4.20-multi-agent-beta` | `reasoning.effort`: `low`, `medium` oder `high` |

## Reasoning bei Grok 4.20 umschalten

Setze `reasoning.enabled: true`, um die Reasoning-Version des Modells zu verwenden. Ohne diese Einstellung oder mit `false` ruft Phaseo die Version ohne Reasoning auf.

```json
{
  "model": "spacex-ai/grok-4.20",
  "input": "Explain this architecture",
  "reasoning": { "enabled": true }
}
```

## Tiefe beim Multi-Agenten-Modell festlegen

Steuere die Tiefe mit `reasoning.effort`. Gateway-Anfragen nehmen `agent_count` von xAI nicht an; laut xAI laufen bei `low` und `medium` 4 Agenten, bei `high` eine größere Konfiguration.

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": { "effort": "medium" }
}
```
