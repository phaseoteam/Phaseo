Ändere das Modell in `anthropic/claude-opus-4.6`, entferne Assistant-Prefills und verschiebe strukturierte Ausgaben nach `output_config.format`. Das sind Änderungen an der Anfrageform: Alte Opus-4.5-Muster schlagen mit `400` fehl, wenn sie bestehen bleiben.

| | Claude Opus 4.5 | Claude Opus 4.6 |
| --- | --- | --- |
| Phaseo-Modell-ID | `anthropic/claude-opus-4.5` | `anthropic/claude-opus-4.6` |
| Kontextfenster | 200K Tokens | 1M Tokens |
| Maximale Ausgabe | 64K Tokens | 128K Tokens |
| Assistant-Prefill | Unterstützt | Gibt `400` zurück |
| Strukturierte Ausgabe | `output_format` | `output_config.format` |
| Thinking | `budget_tokens` | Adaptiv, gesteuert über `output_config.effort` |
| Beta `interleaved-thinking-2025-05-14` | Erforderlich | Nicht erforderlich |

## Anfrage anpassen

**1. Entferne Assistant-Prefills.** Wenn du den Assistant-Zug vorbelegst, um JSON oder ein Präfix zu erzwingen, gibt Opus 4.6 `400` zurück. Verwende stattdessen klarere Systemanweisungen, Beispiele im Prompt oder strukturierte Ausgaben.

**2. Verschiebe strukturierte Ausgaben** von `output_format` nach `output_config.format` und führe deine Schema- und Parser-Tests erneut aus:

```json
{
  "model": "anthropic/claude-opus-4.6",
  "max_tokens": 1024,
  "messages": [{ "role": "user", "content": "Extract the invoice fields." }],
  "output_config": {
    "format": { "type": "json_schema", "schema": { "type": "object", "properties": { "total": { "type": "number" } } } }
  }
}
```

Unter `/v1/chat/completions` und `/v1/responses` verwendest du weiterhin `response_format`.

**3. Stelle Thinking auf adaptiv um.** Opus 4.6 denkt nur, wenn die Anfrage es verlangt. Bei Phaseo schaltet `reasoning.effort` oder `reasoning.enabled: true` ohne Tokenbudget adaptives Thinking ein, und der Effort wird zu `output_config.effort`. Opus 4.6 akzeptiert jede Effort-Stufe außer `xhigh`, die Phaseo als `max` sendet. Solange Thinking aktiv ist, lässt Phaseo `temperature` und `top_k` weg, ebenso `top_p` unter 0.95.

**4. Entferne veraltete Beta-Header** aus SDK-Wrappern, Middleware und Presets. Phaseo leitet `anthropic-beta`-Header nicht weiter, sie haben also keine Wirkung mehr.

## Was du testen solltest

- **Prompts:** lange Programmier- und Refactoring-Prompts, mehrstufige Recherche- und Dokument-Workflows, Prompts, die sich auf Prefills verlassen haben, und Aufgaben mit langem Kontext, falls du das 1M-Fenster nutzen willst.
- **Verträge und Tools:** Schema-Erfolgsquote nach dem Wechsel zu `output_config.format`, Tool-Aufruf-Argumente bei mehrstufigen Agentenaufgaben, Wiederholungen, wenn das Modell ablehnt oder die Ausgabe umformatiert, sowie Code-Review- und Debugging-Workflows.
- **Betrieb:** Median- und p95-Latenz mit aktivem Thinking, Tokenverbrauch bei längeren Durchläufen, Timeout-Rate bei Aufgaben mit großem Kontext und Erfolgsquote gegenüber Opus 4.5 in deinem Evaluierungssatz.

## Umstellen

1. Entferne Prefills und migriere strukturierte Ausgaben, bevor du Traffic verschiebst.
2. Lass Opus 4.6 im Schattenbetrieb mit den Produktions-Prompts laufen, die für dich wichtig sind.
3. Führe einen Canary-Test mit Opus 4.5 als Fallback in `models` durch.
4. Stufe hoch, sobald Schema-Erfolgsquote, Latenz und Aufgabenerfüllung stabil bleiben.
