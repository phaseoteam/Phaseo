# Modellmigrationen

Nutzen Sie diese Leitfäden, wenn Sie das Modell aktualisieren und auf derselben Plattform bleiben.

Sie konzentrieren sich auf Änderungen, die bestehende Integrationen häufig zuerst beeinträchtigen:

- Änderungen an Anfrageparametern
- Unterschiede im Verhalten von Prompts und Reasoning
- Regressionen bei strukturierten Ausgaben und Tool-Aufrufen
- Strategien für schrittweise Einführung, Fallback und Rollback

## Diesen Bereich verwenden

1. Beginnen Sie mit dem Leitfaden für die genaue Modellfamilie, auf die Sie wechseln.
2. Aktualisieren Sie die Anfrageparameter, bevor Sie die Ausgabequalität testen.
3. Wiederholen Sie Prompt- und Schema-Auswertungen mit produktionsnahen Beispielen.
4. Stellen Sie den Traffic schrittweise um und legen Sie Fallback- und Rollback-Regeln fest.

Wenn Sie Anbieter, SDK oder Gateway statt nur des Modells wechseln, nutzen Sie den Bereich [Migrationsleitfäden](../migration-guides/index.mdx).
