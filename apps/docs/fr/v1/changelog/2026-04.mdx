<Update label="29 avril 2026" tags={["Fonctionnalités","Sorties de modèles","SDK"]}>

### Sorties du SDK

- Le SDK `2.0.2` a été publié pour [TypeScript](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fsdk%402.0.2), [Python](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fpy-sdk%402.0.2), [Go](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fgo-sdk%402.0.2), [C#](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fcsharp-sdk%402.0.2), [Java](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fjava-sdk%402.0.2), [PHP](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fphp-sdk%402.0.2) et [Ruby](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fruby-sdk%402.0.2).
- Cette version a séparé les identifiants de modèle des requêtes à l’exécution des constantes générées pour les assistants appelables, afin que les nouveaux modèles soient utilisables avant la prochaine publication du SDK.
- Les assistants générés suivent désormais l’instantané actuel des modèles appelables sur la passerelle, ce qui réduit les changements inutiles du SDK dus aux seules mises à jour du catalogue.

<Update label="25 avril 2026" tags={["Fonctionnalités","Tarifs","Sorties de modèles"]}>

### Fonctionnalités

- Les alertes de solde faible et les protections de facturation ont été renforcées pour avertir plus clairement les équipes avant d’atteindre les limites du compte ([PR #371](https://github.com/phaseoteam/Phaseo/pull/371)).
- Les cas limites de tarification échouent désormais de façon plus prévisible lorsque les règles de facturation d’un fournisseur sont incomplètes ou que les métadonnées d’une route changent de manière inattendue ([PR #374](https://github.com/phaseoteam/Phaseo/pull/374)).
