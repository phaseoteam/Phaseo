Ouvrez un benchmark sur la page [Évaluations comparatives](https://phaseo.app/benchmarks) pour classer les modèles selon leur score, ou ouvrez la page d’un modèle pour voir tous ses scores. Phaseo n’exécute pas de benchmarks : il collecte les scores publiés et relie chacun à sa source.

## Ce que contient chaque score

| Champ | Ce qu’il vous apprend |
| --- | --- |
| Score | La valeur telle que publiée, sur l’échelle propre au benchmark. |
| Variante | La configuration lorsqu’elle diffère de celle par défaut, comme le nombre d’exemples few-shot ou l’effort de raisonnement. |
| Source | Un lien vers l’article, la fiche du modèle ou la page de résultats d’où provient le score. |
| Auto-déclaré | Indiqué lorsque le développeur du modèle a lui-même publié le score. Il s’agit d’une mention, pas d’un rejet. |

Chaque benchmark a aussi une catégorie et un sens de tri. Pour les benchmarks où une valeur plus basse est meilleure, comme les taux d’erreur, Phaseo place le score le plus bas en premier.

## Comparer les scores

Phaseo ne convertit pas les benchmarks en un score commun : comparez donc les modèles sur un même benchmark et une même variante, pas d’un benchmark à l’autre. Vérifiez la variante et la mention auto-déclaré avant de considérer deux chiffres comme équivalents : un score déclaré par un fournisseur et un score mesuré de façon indépendante peuvent différer pour le même modèle.

Un score de benchmark n’est qu’un élément parmi d’autres. Le coût, la latence, la fiabilité et la façon dont un modèle traite vos propres prompts comptent tout autant ; [Prix et performances](./pricing-performance.mdx) couvre ces aspects.

## Ce que montre une page de benchmark

| Section | Ce qu’elle vous apprend |
| --- | --- |
| **Résumé** | Ce que mesure le benchmark, avec un lien vers celui-ci. |
| **Progression** | L’évolution des scores sur le benchmark au fil du temps. |
| **Résultats des modèles** | Le score de chaque modèle, classé selon le sens de tri du benchmark. |

Les indices composites, comme l’Artificial Analysis Intelligence Index et l’Epoch Capabilities Index, ont leurs propres pages avec les classements et les versions de leur éditeur.

## Catégories de benchmarks

| Catégorie | Exemples |
| --- | --- |
| Général | Artificial Analysis Intelligence Index, Epoch Capabilities Index |
| Agents | BrowseComp, BFCL-v3, Toolathlon |
| Code | SWE-Bench, Aider-Polyglot |
| Mathématiques | AIME 2025, MathVision |
| Raisonnement | HellaSwag, Hallusion Bench |
| Langage | BIG-Bench Hard, Winogrande |
| Multimodal | CharXiv-R, MMBench-V1.1 |
| Contexte long | AA-LCR, OpenAI-MRCR |

Les autres catégories incluent l’audio, les embeddings, la santé, la planification et la créativité.

## Origine des scores

- Les fiches de modèle, rapports techniques et articles du développeur du modèle.
- Les pages de résultats des organisateurs des benchmarks.
- Des imports programmés depuis Artificial Analysis et Epoch AI.
- Des signalements de la communauté via des issues GitHub, vérifiés avant publication.

La [méthodologie des benchmarks](../research/benchmark-methodology.mdx) détaille toutes les règles. Pour ajouter ou corriger un score, consultez [Soumettre des scores de benchmark](../research/submitting-scores.mdx).
