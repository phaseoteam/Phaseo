Ouvrez une organisation sur la page [Organisations](https://phaseo.app/organisations) pour voir tous les modèles qu’elle a publiés et leurs performances sur le Gateway. Chaque modèle de Phaseo appartient à une organisation : l’entreprise ou le laboratoire qui le développe et le maintient.

## Ce que montre une page d’organisation

La page comporte deux onglets.

| Onglet | Section | Ce qu’elle vous apprend |
| --- | --- | --- |
| **Vue d’ensemble** | À propos | Nom, description et pays. |
| | Performances | La latence et le débit récents sur le Gateway pour l’ensemble des modèles de l’organisation. |
| | Modèles récents | Les dernières sorties, avec leur disponibilité, leur contexte, leurs tarifs et leur utilisation. |
| | Sur le web | Des liens vers le site web de l’organisation, son GitHub, son Hugging Face et ses comptes sur les réseaux sociaux. |
| **Modèles** | | Tous les modèles publiés par l’organisation, y compris ceux archivés et dépréciés. |

## Organisations et fournisseurs d’API

L’organisation crée le modèle ; un [fournisseur d’API](./api-providers.mdx) le sert. Un même modèle a souvent plusieurs fournisseurs.

| | Organisation | Fournisseur d’API |
| --- | --- | --- |
| **Rôle** | Entraîne et maintient le modèle. | Héberge le modèle derrière une API. |
| **Exemple** | Anthropic a créé les modèles Claude. | Anthropic, Amazon Bedrock et Google Vertex servent tous des modèles Claude. |

Certaines organisations, comme OpenAI et Google, sont aussi fournisseurs de leurs propres modèles.

## Signaler une correction

Ouvrez une issue GitHub avec la page de l’organisation et une source officielle. Les mainteneurs appliquent les modifications approuvées dans la base de données. Consultez [Signaler une mise à jour d’organisation](../contributing/editing-an-organisation.mdx).
