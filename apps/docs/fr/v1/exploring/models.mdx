Ouvrez la liste des [Modèles](https://phaseo.app/models) pour trouver des modèles de texte, d’image, d’audio, de vidéo, d’embedding et autres, puis ouvrez un modèle pour voir ses fournisseurs, ses prix, ses performances et ses scores de benchmark.

![Une page de modèle sur Phaseo](/images/gemini-3-page.png)

## Modèles du catalogue et modèles appelables

Le catalogue est plus large que le Gateway. Par défaut, la liste des modèles n’affiche que les modèles **Actif sur Gateway**. Changez le filtre **État Gateway** en **Bientôt disponible** ou **Inactif** pour voir les autres.

| Terme | Signification |
| --- | --- |
| Modèle du catalogue | Phaseo suit les métadonnées du modèle. Il n’a peut-être aucune route que vous pouvez appeler. |
| Modèle routable | Au moins une route de fournisseur est active sur le Gateway Phaseo maintenant. |
| Correspondance externe | Phaseo répertorie une offre de fournisseur que le Gateway n’exécute pas. |

`GET /v1/models` ne renvoie que les modèles routables. Ajoutez `availability=all` pour inclure les autres.

## Filtrer et trier la liste

| Contrôle | Options |
| --- | --- |
| État Gateway | Actif sur Gateway (par défaut), Bientôt disponible, Inactif |
| Points de terminaison | Les endpoints d’API pris en charge par un modèle, comme la génération de texte ou les embeddings |
| Modalités d’entrée et de sortie | Texte, image, audio, vidéo et autres |
| Fonctionnalités | Des capacités comme l’appel d’outils ou le raisonnement |
| Année | Année de sortie |
| Tri | Plus récents, plus populaires (tokens sur 7 jours), prix, longueur de contexte, débit, latence |

Pour voir tous les modèles d’un laboratoire, ouvrez sa [page d’organisation](./organisations.mdx).

## Ce que montre une page de modèle

| Section | Ce qu’elle vous apprend |
| --- | --- |
| **Fournisseurs** | Chaque route de fournisseur avec son état, sa longueur de contexte, son prix, sa disponibilité et sa politique de données. [États du fournisseur](../guides/provider-statuses) explique les icônes. |
| **Performances** | La latence et le débit mesurés sur le trafic du Gateway, lorsque les données sont suffisantes. |
| **Tarifs** | Chaque compteur en USD : entrée, sortie, entrée en cache et unités média. |
| **Évaluations comparatives** | Les scores sur chaque benchmark, avec leurs sources. |
| **Activité** | L’utilisation des tokens sur le Gateway au fil du temps. |
| **Applications** | Les applications publiques qui utilisent le modèle. |
| **Disponibilité** | La disponibilité des routes au cours des derniers jours. |
| **Vérification** | Les contrôles de provenance du contenu, pour les modèles d’image et de vidéo. |
| **À propos** | Les dates de sortie, la licence, les liens et la famille. |
| **Abonnements** | Les forfaits d’abonnement des fournisseurs qui incluent le modèle. |
| **FAQ** | Les questions fréquentes sur le modèle. |

Une section n’apparaît que si des données existent pour elle. Les modèles qui ont une route active affichent aussi un démarrage rapide avec l’ID de modèle à envoyer.

## Comparer des modèles

[Comparer](https://phaseo.app/compare) place des modèles côte à côte selon le prix, les scores de benchmark, le contexte et les fonctionnalités. [Prix et performances](./pricing-performance.mdx) explique comment lire les chiffres de coût et de vitesse.

## Signaler une correction

Ouvrez une issue GitHub avec la page du modèle et une source officielle. Les mainteneurs appliquent les mises à jour approuvées dans la base de données. Consultez [Signaler une mise à jour de modèle](../contributing/editing-a-model.mdx).
