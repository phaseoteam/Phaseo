Soumettez vos résultats de benchmark dans une issue GitHub. Les responsables vérifient les preuves et publient les scores approuvés via l’éditeur de base de données.

## Préparer vos preuves

Incluez :

- L’identifiant du modèle, le fournisseur et la page Phaseo si elle existe.
- Le nom du benchmark, sa version, sa partition, le score et ses unités.
- La date d’évaluation, le format des prompts, le dispositif d’évaluation et les réglages matériels ou d’échantillonnage pertinents.
- Une publication publique, une page de résultats, un jeu de données ou un journal d’évaluation reproductible.
- Si le résultat est déclaré par le fournisseur ou mesuré de façon indépendante.

## Soumettre l’issue

[Demandez de nouvelles données de benchmark](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) pour un nouveau résultat ou un nouveau benchmark. [Signalez des informations incorrectes](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) pour corriger un score existant, en indiquant sa valeur actuelle et la valeur proposée.

N’incluez ni identifiants de connexion, ni prompts privés, ni données clients dans les rapports publics.

## Suivre la publication

Les responsables peuvent demander des précisions dans l’issue avant de mettre à jour la base de données. Les scores ne sont publiés que via la base de données ; le dépôt ne contient aucun JSON de benchmark à modifier.

Pour obtenir de l’aide pour préparer une soumission, rendez-vous sur le [Discord communautaire](https://discord.gg/aQyywCvgZ5).
