Soumettez les résultats de benchmark dans une issue GitHub. Les responsables vérifient les preuves et publient les scores approuvés dans l’éditeur de base de données.

## Préparer vos preuves

Incluez :

- L’identifiant du modèle, le fournisseur et la page Phaseo si elle existe.
- Le nom du benchmark, sa version, sa partition, son score et ses unités.
- La date d’évaluation, le format des prompts, le dispositif d’évaluation et les réglages matériels ou d’échantillonnage pertinents.
- Une publication publique, une page de résultats, un jeu de données ou un journal d’évaluation reproductible.
- Si le résultat est déclaré par le fournisseur ou mesuré indépendamment.

## Soumettre l’issue

[Demandez de nouvelles données de benchmark](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) pour un nouveau résultat ou benchmark. [Signalez des informations incorrectes](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) pour corriger un score existant, en indiquant sa valeur actuelle et la valeur proposée.

N’incluez ni identifiants, ni prompts privés, ni données clients dans les rapports publics.

## Suivre la publication

Les responsables peuvent demander des précisions dans l’issue avant de mettre à jour la base de données. Les instantanés JSON quotidiens reflètent les données publiées ; modifier le JSON archivé des benchmarks ne publie pas de score.

Pour préparer votre soumission, demandez de l’aide sur le [Discord communautaire](https://discord.gg/aQyywCvgZ5).
