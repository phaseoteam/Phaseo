## Données de benchmark

Phaseo **n’exécute pas les benchmarks**. Nous présentons et normalisons les scores publiés par les auteurs de benchmarks et les fournisseurs de modèles.

Lorsque vous utilisez des résultats de benchmarks consultés via Phaseo :

1. Citez le benchmark et l’article d’origine comme source principale.
2. Vous pouvez mentionner Phaseo comme l’endroit où vous avez récupéré ou comparé les scores.
3. Incluez :

- Nom et partition du benchmark (par exemple, `MMLU test`).
- Identifiant du modèle et fournisseur.
- URL de la page ou de l’API Phaseo concernée.
- Date de consultation.

Exemple de formulation :

> Les scores du benchmark ont été récupérés via Phaseo (partition MMLU test), consulté le 3 mars 2025. Modèle : `openai-gpt-4o` ; fournisseur : OpenAI.
