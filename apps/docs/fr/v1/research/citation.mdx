Citez le benchmark d’origine comme source principale, et ajoutez un lien vers Phaseo si vous l’avez utilisé pour rechercher, comparer ou surveiller des modèles. Un lien dans votre méthodologie, une note de bas de page ou les remerciements suffit :

> Ce travail utilise les métadonnées des modèles et les résultats agrégés de benchmarks de [Phaseo](https://phaseo.app).

## Citation formelle

Indiquez l’année à laquelle vous avez consulté les données.

<CodeGroup>
```text APA
Phaseo. (2026). Phaseo: Aggregated benchmarks and gateway for AI models. https://phaseo.app
```

```bibtex BibTeX
@misc{phaseo-2026,
    title  = {Phaseo: Aggregated benchmarks and gateway for AI models},
    author = {{Phaseo Team}},
    year   = {2026},
    url    = {https://phaseo.app}
}
```
</CodeGroup>

## Citer des scores de benchmark

Phaseo n’exécute pas de benchmarks. Il publie les scores déclarés par les auteurs de benchmarks, les développeurs de modèles et les éditeurs d’indices, avec un lien vers chaque source (voir [Méthodologie des benchmarks](./benchmark-methodology.mdx)).

Lorsque vous utilisez un score trouvé sur Phaseo :

1. Citez le benchmark et l’article d’origine comme source principale.
2. Vous pouvez aussi mentionner Phaseo comme l’endroit où vous avez récupéré ou comparé le score.
3. Indiquez le nom du benchmark et sa partition (par exemple `MMLU test`), l’identifiant Phaseo du modèle et le fournisseur, l’URL de la page Phaseo ou de l’appel d’API, ainsi que la date de consultation.

> Les scores de benchmark ont été récupérés via Phaseo (partition MMLU test), consultés le 3 mars 2026. Modèle : `openai/gpt-6-astra`, fournisseur : OpenAI.

## Mentionner le Gateway

Si Phaseo vous a servi de couche d’intégration plutôt que de source de données, présentez-le comme la passerelle et ajoutez un lien vers la [référence de l’API](../api-reference/introduction.mdx) :

> Nous avons utilisé le Phaseo Gateway pour appeler des modèles OpenAI, Anthropic et Google via une seule API.
