Choisissez une recette selon ce que vous voulez créer. Chacune commence par le résultat final, puis donne les étapes, le code complet, la façon de le lancer et la façon de vérifier qu’il fonctionne. Chaque recette indique si son code est prêt pour la production ou s’il s’agit d’un point de départ à compléter.

Tous les exemples utilisent `https://api.phaseo.app/v1` et lisent votre clé depuis `PHASEO_API_KEY`.
