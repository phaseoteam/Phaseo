Envoyez `"model": "phaseo/free"` et Phaseo exécute votre requête sur un modèle gratuit disponible qui la prend en charge, sans crédits. À la fin, vous avez une requête qui fonctionne dans le langage de votre choix et vous savez quel modèle y a répondu.

Cette forme de requête est prête pour la production pour les prototypes, les démos et le trafic à faible enjeu. Les modèles gratuits ne garantissent ni la latence, ni le style de sortie, ni un fournisseur fixe.

## Envoyer la requête

<Steps>

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

<Step title="Envoyer une requête">

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```

```go Go
package main

import (
  "context"
  "fmt"
  "os"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4"
)

func main() {
  client := phaseo.New(os.Getenv("PHASEO_API_KEY"), "https://api.phaseo.app/v1")

  temperature := 0.2
  response, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
    Model:       "phaseo/free",
    Input:       "Summarize why provider-aware free routing helps prototypes.",
    Temperature: &temperature,
  })
  if err != nil {
    panic(err)
  }

  fmt.Printf("%+v\n", response)
}
```

## Comment un modèle gratuit est choisi

1. Votre requête est envoyée à l’alias partagé `phaseo/free`.
2. Phaseo garde les modèles gratuits capables de servir cette requête (endpoint, paramètres, outils).
3. Il envoie la requête à l’un d’eux.

Les modèles gratuits partagent par défaut une allocation de 1 500 requêtes par utilisateur et par jour UTC. Au-delà, les requêtes renvoient `429` avec le code `phaseo_free_model_limit_exceeded` jusqu’à 00:00 UTC ; voir [Limites du Gateway](../api-reference/limits#gateway-limits).

## Quitter le routeur gratuit

Si aucun modèle gratuit ne prend en charge une fonctionnalité dont vous avez besoin, comme les outils ou un JSON Schema, passez à un modèle payant précis au lieu de réessayer la même requête. Passez à un modèle fixe lorsque vous avez besoin d’une latence, d’un style de sortie ou d’un choix de fournisseur prévisibles, et placez les réglages partagés dans un [préréglage](../guides/presets) pour que chaque service envoie la même requête. [Routage et replis](../guides/routing-and-fallbacks) explique comment les requêtes payantes choisissent un fournisseur, et [Erreurs de l’API](../api-reference/errors) liste les codes d’erreur.
