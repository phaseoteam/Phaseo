Utilisez cette page pour fournir à un agent de programmation un prompt précis qui produit une petite application fonctionnelle, plutôt qu’un plan d’intégration vague.

<Tip>
Ces prompts sont axés sur le résultat et précisent la mise en œuvre afin de mieux fonctionner dans Cursor, Claude Code, Codex et les outils similaires.
</Tip>

## Comment utiliser ces prompts

<Steps>
  <Step title="Choisissez le point d’intégration">
    Choisissez le prompt correspondant à la façon dont vous souhaitez que l’application appelle Phaseo :

    - HTTP brut
    - un SDK officiel
    - Vercel AI SDK
    - SDK Agent
  </Step>
  <Step title="Remplacez les variables entre crochets">
    Renseignez des valeurs comme `[IDÉE D’APPLICATION]`, `[FRAMEWORK]`, `[MODÈLE]` et `[LANGUAGE]` avant de coller le prompt dans votre agent de programmation.
  </Step>
  <Step title="Demandez des vérifications, pas seulement du code">
    Gardez les lignes de vérification dans le prompt. L’agent devra ainsi indiquer ce qu’il a réellement exécuté, ses hypothèses et ce qui reste à configurer manuellement.
  </Step>
</Steps>

## Comment améliorer ces prompts

- Remplacez `[IDÉE D’APPLICATION]` par une tâche utilisateur précise, et non par une présentation générale du produit.
- Remplacez `[MODÈLE]` par l’identifiant exact du modèle que l’agent doit utiliser.
- Précisez si la sortie doit être du texte libre, du JSON strict, un chat ou un seul élément généré.
- Indiquez le framework d’interface et la cible de déploiement si vous les connaissez.
- Ajoutez une ou deux contraintes importantes, comme `fournisseurs de l’UE uniquement`, `utiliser le streaming` ou `garder tous les secrets côté serveur`.
