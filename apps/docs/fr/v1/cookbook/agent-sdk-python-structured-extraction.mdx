Exécutez un agent Python qui recherche une information avec un outil local et renvoie sa réponse en JSON strict. À la fin, vous avez un script dont le `result.output` est un objet `PolicySummary` validé, avec `summary` et `recommendation`, et non du texte libre.

L’outil renvoie des données d’exemple fixes : le script est donc illustratif ; remplacez-le par votre propre recherche. Il convient à un worker Python qui gère sa propre orchestration et dispose d’un petit ensemble d’outils déterministes.

## Le construire

<Steps>
<Step title="Installer">

<CodeGroup>
```bash pip
pip install phaseo-agent-sdk
```

```bash uv
uv add phaseo-agent-sdk
```
</CodeGroup>

`phaseo-agent-sdk` installe le client `phaseo` et Pydantic avec lui.

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="Écrire l’agent">

```python extract.py
import json
import os

from pydantic import BaseModel, ConfigDict

from phaseo_agent import AgentTool, create_agent, create_gateway_agent_client, define_tool

POLICY_SLUGS = {"presets", "routing", "guardrails"}


class PolicySummary(BaseModel):
    model_config = ConfigDict(extra="forbid")
    summary: str
    recommendation: str


def check_lookup_input(value):
    # Arguments générés par le modèle : rejetez tout ce qui n’est pas un slug connu.
    if not isinstance(value, dict) or set(value) != {"slug"} or value["slug"] not in POLICY_SLUGS:
        raise ValueError(f"slug must be one of {sorted(POLICY_SLUGS)}")
    return value


lookup_policy = define_tool(
    AgentTool(
        id="lookup-policy",
        description="Look up one internal policy by slug.",
        parameters={
            "type": "object",
            "properties": {"slug": {"type": "string", "enum": sorted(POLICY_SLUGS)}},
            "required": ["slug"],
            "additionalProperties": False,
        },
        input_schema=check_lookup_input,
        execute=lambda input, ctx: {
            "slug": input["slug"],
            "summary": "Presets centralize routing, prompts, and caching defaults.",
        },
    )
)

agent = create_agent(
    {
        "id": "policy-extractor",
        "model": "openai/gpt-6-astra",
        "instructions": "Use tools when needed and return JSON with summary and recommendation.",
        "tools": [lookup_policy],
        "max_steps": 4,
        "parse_output": json.loads,
        "output_schema": PolicySummary,
    }
)

# Le client Python ne lit pas PHASEO_API_KEY de lui-même : passez-la.
client = create_gateway_agent_client(
    client_options={"api_key": os.environ["PHASEO_API_KEY"]},
    response_format={
        "type": "json_schema",
        "name": "policy_summary",
        "schema": {
            "type": "object",
            "properties": {
                "summary": {"type": "string"},
                "recommendation": {"type": "string"},
            },
            "required": ["summary", "recommendation"],
            "additionalProperties": False,
        },
    },
    plugins=[{"id": "response-healing"}],
)

result = agent.run(input="Look up our presets policy and recommend when to use it.", client=client)

print(result.run.status)
print(result.output)
```

| Élément | Rôle |
| --- | --- |
| `parameters` | Le JSON Schema que le modèle voit pour les arguments de l’outil |
| `input_schema` | Vérifie les arguments avant l’appel d’`execute` ; un appel incorrect fait échouer l’exécution |
| `response_format` | Demande ce JSON Schema au Gateway à chaque tour |
| `parse_output` et `output_schema` | Analysent le texte final et le valident sous forme de `PolicySummary` |

</Step>
<Step title="L’exécuter">

```bash
python extract.py
```

</Step>
</Steps>

## Vérifier que ça fonctionne

- Le script affiche `completed`, puis un `PolicySummary` dont les deux champs sont remplis.
- Dans **Paramètres → Utilisation → Journaux**, le premier tour du modèle affiche un appel `lookup-policy` avec `{"slug": "presets"}`.
- Une sortie qui ne correspond pas au modèle Pydantic échoue avec `Invalid agent output` au lieu de renvoyer un objet à moitié rempli.

Pour une sortie structurée en un seul appel, sans outils, appelez [directement le SDK Python](./sdk-python-presets-and-json). La [référence de l’Agent SDK Python](../sdk-reference/agent/usage) couvre l’état, l’approbation et le streaming.
