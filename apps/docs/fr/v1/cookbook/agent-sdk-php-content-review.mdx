Exécutez un agent PHP qui charge un brouillon CMS avec un outil local et propose une modification éditoriale, au sein de l’application ou du back-office qui gère déjà le contenu. À la fin, vous avez un script qui affiche une suggestion de titre pour le brouillon de la page d’accueil.

L’outil renvoie des données d’exemple fixes : le script est donc illustratif ; remplacez-le par votre recherche dans le CMS. Il convient à une application PHP pour laquelle un ou deux outils locaux suffisent.

## Le construire

<Steps>
<Step title="Installer">

```bash
composer require phaseo/agent-sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

`phaseo/agent-sdk` installe `phaseo/sdk` avec lui et nécessite PHP 8.1 ou une version plus récente. Consultez [Installation de l’Agent SDK PHP](../sdk-reference/agent/installation).

</Step>
<Step title="Écrire l’agent">

```php review.php
<?php
require 'vendor/autoload.php';

use Phaseo\AgentSdk\AgentDefinition;
use Phaseo\AgentSdk\AgentSdk;
use Phaseo\AgentSdk\Tool;

const ALLOWED_SLUGS = ['homepage', 'pricing', 'about'];

$loadDraft = AgentSdk::defineTool(new Tool(
    id: 'load-draft',
    description: 'Load one CMS draft by slug.',
    parameters: [
        'type' => 'object',
        'properties' => [
            'slug' => ['type' => 'string', 'enum' => ALLOWED_SLUGS],
        ],
        'required' => ['slug'],
        'additionalProperties' => false,
    ],
    // Les arguments viennent du modèle : seuls les slugs connus atteignent execute.
    inputSchema: static function (mixed $input): array {
        if (!is_array($input) || !in_array($input['slug'] ?? null, ALLOWED_SLUGS, true)) {
            throw new InvalidArgumentException('slug must be one of ' . implode(', ', ALLOWED_SLUGS));
        }
        return $input;
    },
    execute: static fn (array $input, $context) => [
        'slug' => $input['slug'],
        'headline' => 'Phaseo makes gateway routing visible.',
    ],
));

$agent = AgentSdk::createAgent(new AgentDefinition(
    id: 'content-review-agent',
    model: 'openai/gpt-6-astra',
    instructions: 'Use tools when helpful and return concise editorial feedback.',
    tools: [$loadDraft],
    maxSteps: 4,
));

// Lit PHASEO_API_KEY depuis l’environnement.
$result = $agent->run(
    input: 'Review the homepage draft and suggest one headline improvement.',
    client: AgentSdk::createGatewayAgentClient(),
);

echo $result->run->status . PHP_EOL;
echo $result->output . PHP_EOL;
```

</Step>
<Step title="L’exécuter">

```bash
php review.php
```

</Step>
</Steps>

## Vérifier que ça fonctionne

- Le script affiche `completed`, puis une suggestion de titre.
- Dans **Paramètres → Utilisation → Journaux**, le premier tour du modèle affiche un appel `load-draft` avec `{"slug": "homepage"}`.
- Sans `PHASEO_API_KEY`, `createGatewayAgentClient()` lève `PHASEO_API_KEY is required`.

## Avant la production

Gardez l’outil en lecture seule. Si vous en ajoutez un qui publie ou modifie du contenu, définissez `requireApproval: true` sur cet outil pour que l’exécution se mette en pause en attendant un éditeur. Pour obtenir les retours en JSON que votre CMS peut stocker, demandez un schéma et réparez la sortie presque valide avec la [réparation des réponses](./response-healing-for-structured-json). La [référence de l’Agent SDK PHP](../sdk-reference/agent/usage) couvre l’état, l’approbation et le streaming.
