Donnez au modèle `phaseo:web_fetch` et une URL que vous connaissez déjà : Phaseo récupère la page, la réduit à une taille limite et renvoie le texte avant que le modèle ne l’extraie, ne le résume ou ne le classe. À la fin, vous avez une requête qui lit une seule page et en renvoie des champs, et vous pouvez confirmer dans le journal quelle page elle a réellement lue.

La requête est prête pour la production avec la limite de domaine indiquée. Les pages récupérées sont des entrées non fiables : le modèle peut y voir des instructions ; validez donc ce qu’il renvoie. Utilisez plutôt la [recherche Web](../guides/server-tools/web-search) quand vous ne connaissez pas l’URL.

## Envoyer une requête ancrée

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
    "tools": [
      {
        "type": "phaseo:web_fetch",
        "parameters": {
          "allowed_domains": ["phaseo.app"],
          "max_chars": 8000,
          "max_uses": 1
        }
      }
    ],
    "tool_choice": "phaseo:web_fetch"
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-6-astra",
  input:
    "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
  tools: [
    {
      type: "phaseo:web_fetch",
      parameters: {
        allowed_domains: ["phaseo.app"],
        max_chars: 8000,
        max_uses: 1,
      },
    },
  ],
  tool_choice: "phaseo:web_fetch",
});

console.log(JSON.stringify(response.output, null, 2));
console.log(response.usage?.server_tool_use);
```
</CodeGroup>

Indiquez clairement dans le prompt la tâche à faire après la récupération : extraire ces champs, résumer cette section, classer le document ou vérifier une affirmation.

| Paramètre | Valeur par défaut | Usage |
| --- | --- | --- |
| `allowed_domains` | Aucune | Ne récupérer que depuis ces domaines. Le modèle peut restreindre la liste, jamais l’élargir. |
| `max_chars` | `12000` | Nombre de caractères du texte de la page renvoyé, jusqu’à `100000`. Plus bas pour un titre ou un résumé, plus haut pour extraire des champs. |
| `max_uses` | `10` | Nombre d’appels de récupération par requête, jusqu’à `100`. |

Le [guide de web fetch](../guides/server-tools/web-fetch#parameters) liste les autres paramètres, dont `blocked_domains` et les moteurs.

## Vérifier ce qui a été lu

Le résultat de l’outil, visible dans le journal de la requête, indique exactement sur quelle page le modèle s’est appuyé :

```json
{
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "truncated": false,
  "returned_chars": 8000
}
```

Vérifiez `final_url` après les redirections et `truncated` avant de considérer que le modèle a vu toute la page. Chaque récupération ajoute 1 à `usage.server_tool_use.web_fetch_requests`.

## Connaître les limites

Avec le moteur `direct` par défaut, Phaseo récupère la page lui-même et réduit le HTML à du texte brut. Il refuse `localhost` et les adresses privées, suit au plus 5 redirections et vérifie chaque redirection par rapport à vos listes de domaines ; une redirection hors de ces listes renvoie `redirect_blocked_by_domain_policy` au modèle.

Web fetch convient aux pages HTML, au texte brut et aux petites réponses JSON ou XML. Il n’est pas fait pour les fichiers binaires, pour parcourir de nombreuses pages ou pour vérifier le rendu d’une page avec JavaScript ; utilisez un workflow de navigateur pour cela. Si la page est très volumineuse, réduisez la tâche d’extraction plutôt que d’augmenter `max_chars`.

Commencez par un préréglage ou un endpoint, lisez les détails de récupération et de troncature dans les journaux, et resserrez le prompt si le texte récupéré est trop large avant d’étendre l’usage.
