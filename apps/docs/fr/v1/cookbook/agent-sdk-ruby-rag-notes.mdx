Exécutez un agent Ruby qui recherche une note interne avec un outil local et répond en un court paragraphe, sans confier l’orchestration à un autre système. À la fin, vous avez un script qui résume votre note sur les préréglages.

L’outil renvoie des données d’exemple fixes : le script est donc illustratif ; remplacez-le par une recherche dans votre propre stockage de notes. Il convient à une application Ruby qui possède déjà les données et dont les entrées d’outils sont simples et déterministes.

## Le construire

<Steps>
<Step title="Installer">

```bash
gem install phaseo_agent_sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

Ou ajoutez `gem "phaseo_agent_sdk"` à votre `Gemfile`. Il installe `phaseo_sdk` avec lui et nécessite Ruby 3.2 ou une version plus récente. Consultez [Installation de l’Agent SDK Ruby](../sdk-reference/agent/installation).

</Step>
<Step title="Écrire l’agent">

```ruby notes.rb
require "phaseo_agent_sdk"

TOPICS = %w[presets routing guardrails].freeze

lookup_note = PhaseoAgentSdk.define_tool(
  PhaseoAgentSdk::Tool.new(
    id: "lookup-note",
    description: "Look up one internal note by topic.",
    parameters: {
      type: "object",
      properties: { topic: { type: "string", enum: TOPICS } },
      required: ["topic"],
      additionalProperties: false
    },
    # Les arguments viennent du modèle : seuls les sujets connus atteignent execute.
    input_schema: lambda do |input|
      raise ArgumentError, "topic must be one of #{TOPICS.join(', ')}" unless input.is_a?(Hash) && TOPICS.include?(input["topic"])

      input
    end,
    execute: lambda do |input, _context|
      {
        topic: input["topic"],
        summary: "Presets centralize routing defaults so app code stays smaller."
      }
    end
  )
)

agent = PhaseoAgentSdk.create_agent(
  id: "notes-agent",
  model: "openai/gpt-6-astra",
  instructions: "Use tools when helpful and answer in one short paragraph.",
  tools: [lookup_note],
  max_steps: 4
)

# Lit PHASEO_API_KEY depuis l’environnement.
result = agent.run(
  input: "Summarize our note about presets.",
  client: PhaseoAgentSdk.create_gateway_agent_client
)

puts result.run.status
puts result.output
```

</Step>
<Step title="L’exécuter">

```bash
ruby notes.rb
```

</Step>
</Steps>

## Vérifier que ça fonctionne

- Le script affiche `completed`, puis un paragraphe sur les préréglages.
- Dans **Paramètres → Utilisation → Journaux**, le premier tour du modèle affiche un appel `lookup-note` avec `{"topic": "presets"}`.

## Avant la production

Gardez l’outil en lecture seule et `max_steps` aussi bas que la tâche le permet (la valeur par défaut est `12`). Si votre stockage de notes est volumineux, renvoyez uniquement le passage correspondant plutôt que des documents entiers, pour que chaque tour du modèle reste léger. Pour enregistrer des exécutions et les reprendre plus tard, consultez la [boucle durable](./agent-sdk-durable-loop) ; l’option `state:` du SDK Ruby fonctionne de la même façon. La [référence de l’Agent SDK Ruby](../sdk-reference/agent/usage) couvre l’état, l’approbation et le streaming.
