Créez un agent TypeScript qui effectue une recherche sur le Web via Phaseo avant de répondre, et renvoie une synthèse de recherche en JSON strict avec ses sources. À la fin, vous avez un script qui affiche un objet `{ topic, summary, sources }` validé pour n’importe quel sujet que vous lui donnez.

Le script est prêt pour la production pour une recherche en un seul passage. Les résultats de recherche sont du contenu Web non fiable : la vérification du schéma ci-dessous bloque les sorties mal formées, mais examinez les sources avant d’agir en conséquence. Une version packagée se trouve dans `packages/sdk/agent-sdk-ts/examples/research-brief-agent.ts`.

<Step title="Écrire l’agent">

```ts research-agent.ts
import { z } from "zod";
import { createAgent, createGatewayAgentClient } from "@phaseo/agent-sdk";

// Assez petit pour tenir sur une ligne de journal.
const ResearchBrief = z
  .object({
    topic: z.string(),
    summary: z.string().min(1),
    sources: z.array(z.object({ title: z.string(), url: z.string().url() }).strict()).min(1),
  })
  .strict();
type ResearchBrief = z.infer<typeof ResearchBrief>;

const researchBriefAgent = createAgent<string, ResearchBrief>({
  id: "research-brief-agent",
  model: "openai/gpt-6-astra",
  instructions:
    "Research the user's topic with web search and return a concise JSON brief with cited sources.",
  maxSteps: 4,
  parseOutput: (text) => JSON.parse(text),
  outputSchema: ResearchBrief,
});

const client = createGatewayAgentClient({
  clientOptions: { apiKey: process.env.PHASEO_API_KEY! },
  // Le JSON Schema que le Gateway demande au modèle.
  responseFormat: {
    type: "json_schema",
    name: "research_brief",
    schema: {
      type: "object",
      properties: {
        topic: { type: "string" },
        summary: { type: "string" },
        sources: {
          type: "array",
          items: {
            type: "object",
            properties: { title: { type: "string" }, url: { type: "string" } },
            required: ["title", "url"],
            additionalProperties: false,
          },
          minItems: 1,
        },
      },
      required: ["topic", "summary", "sources"],
      additionalProperties: false,
    },
  },
  // Réparer le JSON presque valide.
  plugins: [{ id: "response-healing" }],
  // Phaseo exécute la recherche ; le modèle rédige les requêtes.
  gatewayTools: [{ type: "phaseo:web_search", parameters: { max_results: 5 } }],
  // Toujours rechercher avant de répondre.
  toolChoice: "phaseo:web_search",
  webSearchOptions: { search_context_size: "high" },
});

const result = await researchBriefAgent.run({
  input: "Summarize the latest browser automation support patterns for coding agents.",
  client,
  onEvent(event) {
    console.log(event.type, event.runId);
  },
});

console.log(result.output);
```

| Option du client | Rôle |
| --- | --- |
| `responseFormat` | Garde le schéma de sortie explicite |
| `plugins` | [Réparation des réponses](./response-healing-for-structured-json) pour le JSON presque valide |
| `gatewayTools` | Ajoute `phaseo:web_search` ; le [guide de la recherche Web](../guides/server-tools/web-search) liste ses paramètres |
| `toolChoice` | Force la recherche pour un flux de travail qui doit toujours s’appuyer sur des sources |
| `webSearchOptions` | Paramètres de recherche pour les moteurs qui dimensionnent leurs résultats |

## Vérifier que ça fonctionne

Le script affiche une synthèse avec au moins une URL de source. Ouvrez ensuite la requête dans **Paramètres → Utilisation → Journaux** et vérifiez que :

- **Observabilité de la recherche sur le Web** affiche les recherches gérées, les résultats et les citations.
- L’enregistrement des plugins indique `response-healing` comme `applied` uniquement quand le JSON a dû être réparé.
- La réponse respectait le schéma ; un écart aurait fait échouer l’exécution avec une `AgentSchemaValidationError`.

[Déboguer la recherche Web](./web-search-debugging) couvre les cas où aucune recherche n’a eu lieu.

## Quand utiliser autre chose

Ce modèle convient à une recherche en un seul passage où le modèle doit s’appuyer sur des sources et où les appelants veulent du JSON typé. Utilisez [`phaseo:web_fetch`](./tool-grounding-with-web-fetch) quand vous connaissez déjà les URL, un [agent avec outils locaux](./agent-sdk-durable-loop) quand le travail dépend davantage de vos propres données que du Web, et une sortie en texte brut quand le contrat est assez souple pour qu’un schéma coûte plus d’efforts qu’il n’en épargne.
