Exécutez un agent Go qui répond à une question opérationnelle en appelant un outil d’état local, au sein d’un même service et sans système de tâches. À la fin, vous avez un seul `main.go` qui affiche une courte réponse sur la latence actuelle des fournisseurs.

L’outil renvoie des données d’exemple fixes : le programme est donc illustratif ; remplacez-le par votre propre appel d’état ou de métriques. Il convient à un service Go dont le contexte existe déjà sous forme d’appels locaux ou internes.

## Le construire

<Steps>
<Step title="Installer">

```bash
go mod init ops-runbook
go get github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go@latest
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

Le module principal `sdk-go/v4` est installé avec lui. Consultez [Installation de l’Agent SDK Go](../sdk-reference/agent/installation) pour les prérequis.

</Step>
<Step title="Écrire l’agent">

```go main.go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  statusTool := phaseoagent.DefineTool(phaseoagent.Tool{
    ID:          "read-status",
    Description: "Read the current service status page summary.",
    Parameters: map[string]any{
      "type":                 "object",
      "properties":           map[string]any{},
      "additionalProperties": false,
    },
    Execute: func(input any, ctx phaseoagent.RuntimeContext) (any, error) {
      return map[string]any{
        "status":  "degraded",
        "summary": "Latency is elevated on one provider route.",
      }, nil
    },
  })

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "ops-runbook-agent",
    Model:        "openai/gpt-6-astra",
    Instructions: "Use tools when helpful and answer briefly.",
    Tools:        []phaseoagent.Tool{statusTool},
    MaxSteps:     4,
  })

  // Lit PHASEO_API_KEY (et PHASEO_BASE_URL s’il est défini).
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "What is happening with provider latency right now?",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Run.Status)
  fmt.Println(result.Output)
}
```

</Step>
<Step title="L’exécuter">

```bash
go run .
```

</Step>
</Steps>

## Vérifier que ça fonctionne

- Le programme affiche `completed`, puis une réponse qui mentionne une latence dégradée sur une route de fournisseur.
- Dans **Paramètres → Utilisation → Journaux**, le premier tour du modèle affiche un appel d’outil `read-status`.
- Sans `PHASEO_API_KEY`, `CreateGatewayAgentClient` renvoie `PHASEO_API_KEY is required`.

## Avant la production

`MaxSteps` vaut `8` par défaut dans le SDK Go ; fixez-le au plus petit nombre qui permet de terminer la tâche. Quand un outil prend des arguments, donnez-lui un schéma `Parameters` et un validateur `InputSchema` qui renvoie une erreur pour toute valeur inattendue, car les arguments viennent du modèle. Gardez les outils en lecture seule, sauf si une personne approuve l’appel (`RequireApproval: true`). La [référence de l’Agent SDK Go](../sdk-reference/agent/usage) couvre les approbations, l’état et le streaming, et l’[ancrage avec web fetch](./tool-grounding-with-web-fetch) montre comment lire une page connue au lieu d’un outil local.
