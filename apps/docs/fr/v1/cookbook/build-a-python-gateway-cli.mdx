Exécutez une CLI Python, limitée à la bibliothèque standard, qui appelle les endpoints Phaseo une commande à la fois. À la fin, `python quickstart.py <command>` fonctionne pour health, models, Responses et Chat Completions, et vous disposez de commandes pour les embeddings, la modération, les images, l’OCR, la vidéo et la musique, à copier dans un worker ou un backend.

La CLI est illustrative : c’est une référence pour la forme des requêtes, pas un outil packagé. Plusieurs de ses ID de modèle par défaut pour les commandes média ne sont plus servis ; passez donc `--model` pour celles-ci (voir [Choisir les modèles des commandes média](#pick-models-for-the-media-commands)).

Pour qu’un agent de codage crée une CLI similaire de zéro, collez ce prompt :

## Ce que fait la CLI

L’exemple est [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) : un seul fichier, `quickstart.py`, qui n’utilise que `urllib`, `json` et `argparse`.

| Commande | Appels |
| --- | --- |
| `smoke` | `GET /v1/health`, `GET /v1/models`, `GET /v1/providers` et un `POST /v1/responses` |
| `health`, `models`, `providers` | La route `GET` correspondante |
| `responses --prompt` | `POST /v1/responses` |
| `chat --prompt` | `POST /v1/chat/completions` |
| `embeddings --text` | `POST /v1/embeddings` |
| `moderations --text` | `POST /v1/moderations` |
| `image --prompt` | `POST /v1/images/generations` |
| `ocr --image-url` | `POST /v1/ocr` |
| `video-create`, `video-status`, `video-cancel`, `video-download-url` | `POST /v1/videos`, `GET /v1/videos/{video_id}`, `POST /v1/videos/{video_id}/cancel`, `POST /v1/videos/{video_id}/download_url` |
| `music-create`, `music-status` | `POST /v1/music/generate`, `GET /v1/music/generate/{music_id}` |

Chaque requête est réessayée deux fois en cas de `429`, de `5xx` ou d’erreur réseau, avec une attente de 1 s puis de 2 s, et expire au bout de 45 secondes. Chaque commande se termine avec `1` quand l’appel ne renvoie pas `2xx`, ce qui permet de l’utiliser dans des scripts.

## Lancer la CLI

Il vous faut Python 3 et une clé API Phaseo.

<Steps>
<Step title="Créer .env.local">

Le script lit `.env.local` depuis le dossier où vous le lancez. L’exemple ne fournit pas de `.env.example` ; créez donc le fichier :

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# Facultatif
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My Python CLI
PHASEO_HTTP_REFERER=https://myapp.example
```

Les variables déjà définies dans votre shell l’emportent sur le fichier. Sans `PHASEO_MODEL`, les commandes texte utilisent `openai/gpt-5.6-sol`.

</Step>
<Step title="Lancer le contrôle rapide">

```bash
cd examples/gateway-python-quickstart
python quickstart.py smoke
```

`smoke` envoie aussi une courte requête Responses ; il consomme donc quelques crédits.

</Step>
<Step title="Envoyer une requête">

```bash
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

</Step>
</Steps>

## Vérifier que tout fonctionne

- `smoke` affiche `HTTP 200` pour chaque bloc et se termine avec `0`.
- La sortie de la commande `responses` contient `integration_ok`.
- `--help` liste les commandes sans envoyer de requête.
- Sans clé, le script affiche `Missing PHASEO_API_KEY` et se termine avec `1`.
- Les requêtes apparaissent dans **Paramètres → Utilisation → Journaux**.

## Choisir les modèles des commandes média

Ces valeurs par défaut de `quickstart.py` sont retirées ou n’ont aucun fournisseur actif. Passez un modèle actuel avec `--model`, choisi sur la [page des modèles](https://phaseo.app/models) ou avec `python quickstart.py models` :

| Commande | Valeur par défaut de l’exemple | État |
| --- | --- | --- |
| `moderations` | `openai/omni-moderation-latest` | Pas un ID du catalogue ; utilisez `openai/omni-moderation` |
| `ocr` | `mistral/mistral-ocr` | Retiré ; essayez `mistral/ocr-4.1` |
| `video-create` | `openai/sora-2` | Retiré |
| `music-create` | `suno/suno-v4` | Aucun fournisseur actif |

Les valeurs par défaut de `embeddings` (`google/gemini-embedding-2`) et de `image` (`openai/gpt-image-2`) sont servies. Les tâches vidéo et musique sont asynchrones : conservez l’ID renvoyé et interrogez la commande d’état ; [Vidéo asynchrone et batch](../guides/async-video-and-batch) décrit le cycle de vie des tâches.

Réduisez le fichier aux commandes dont votre service a besoin, gardez l’unique fonction partagée `gateway_request()`, et passez au [SDK Python](../sdk-reference/client/overview) quand vous voulez des requêtes typées.
