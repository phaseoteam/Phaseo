<Update label="17 novembre 2026">

<div data-changelog-category="api">

<p className="changelog-category">API et SDK</p>

- `@phaseo/cli` `0.4.0` affiche les listes sous forme de tableaux, montre les prix d’entrée, de sortie et de lecture du cache dans `phaseo pricing models` et ajoute `phaseo pricing get <model>` ; voir [CLI Phaseo](./guides/integrations/phaseo-cli.mdx) ([#3774](https://github.com/phaseoteam/Phaseo/pull/3774), [#3780](https://github.com/phaseoteam/Phaseo/pull/3780)).
- `@phaseo/cli` `0.4.0` ajoute des commandes pour toutes les routes de gestion `/v1`, dont `spend-rules`, `budgets`, `byok`, `rate-limits` et `classifiers` ([#3312](https://github.com/phaseoteam/Phaseo/pull/3312), [#3323](https://github.com/phaseoteam/Phaseo/pull/3323)).
- `phaseo mcp` lance le serveur MCP de Phaseo pour les agents locaux avec votre `phaseo login`, en lecture seule sauf si vous passez `--manage` ([#3659](https://github.com/phaseoteam/Phaseo/pull/3659)).
- La configuration des agents de code, comme `phaseo codex`, vous demande d’approuver leur clé d’API dans le tableau de bord au lieu de la créer avec votre connexion à la CLI ([#3584](https://github.com/phaseoteam/Phaseo/pull/3584)).
- `GET /v1/pricing/models` renvoie le `service_tier` de chaque entrée ; voir [Lister les tarifs des modèles](./api-reference/endpoint/pricing-models.mdx) ([#3774](https://github.com/phaseoteam/Phaseo/pull/3774)).
- `GET /v1/analytics` renvoie les noms des fournisseurs tels que Phaseo les affiche, par exemple `Liquid AI` ([#3777](https://github.com/phaseoteam/Phaseo/pull/3777)).

</div>

<Update label="3 novembre 2026">

<div data-changelog-category="product">

<p className="changelog-category">Produit</p>

- Les pages de modèles ne comptent la réussite des appels d’outils et des sorties structurées que sur les réponses vérifiées par Phaseo ; auparavant, les requêtes en échec comptaient comme du JSON valide et les heures sans données affichaient 100 % ([#3475](https://github.com/phaseoteam/Phaseo/pull/3475)).
- La vitesse de sortie sur les pages de modèles exclut le raisonnement masqué effectué avant la réponse et n’affiche aucune valeur quand la réponse arrive d’un seul bloc ; voir [Mesurer les prix et les performances](./exploring/pricing-performance.mdx) ([#3465](https://github.com/phaseoteam/Phaseo/pull/3465), [#3476](https://github.com/phaseoteam/Phaseo/pull/3476)).
