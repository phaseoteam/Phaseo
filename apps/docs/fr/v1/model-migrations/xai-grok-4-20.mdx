Changez l’identifiant de modèle et relancez votre jeu de validation ; les formats de requête et de réponse restent les mêmes. Le seul nouveau contrôle concerne la profondeur de travail de la variante multi-agent.

| Modèle | Identifiant de modèle Phaseo | Contrôle du raisonnement |
| --- | --- | --- |
| Grok 4.20 | `spacex-ai/grok-4.20` | `reasoning.enabled` : activé ou désactivé |
| Grok 4.20 Multi-Agent (bêta) | `spacex-ai/grok-4.20-multi-agent-beta` | `reasoning.effort` : `low`, `medium` ou `high` |

## Activer ou désactiver le raisonnement sur Grok 4.20

Définissez `reasoning.enabled: true` pour utiliser la version avec raisonnement du modèle. Sans ce paramètre, ou avec `false`, Phaseo appelle la version sans raisonnement.

```json
{
  "model": "spacex-ai/grok-4.20",
  "input": "Explain this architecture",
  "reasoning": { "enabled": true }
}
```

## Définir la profondeur du modèle multi-agent

Contrôlez la profondeur avec `reasoning.effort`. Les requêtes à la passerelle n’acceptent pas le paramètre `agent_count` de xAI ; selon xAI, `low` et `medium` exécutent 4 agents et `high` exécute une configuration plus grande.

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": { "effort": "medium" }
}
```
