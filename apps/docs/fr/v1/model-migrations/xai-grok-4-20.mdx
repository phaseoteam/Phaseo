# SpaceXAI Grok 4.20

Suivez ce guide pour adopter Grok 4.20 via Phaseo Gateway en toute sécurité.

Route principale du catalogue :

- `spacex-ai/grok-4-20-2026-02-17`

Route multi-agent facultative, exposée sous l’identifiant de modèle du fournisseur :

- `spacex-ai/grok-4.20-multi-agent-beta-0309`

## Démarrage rapide de la migration

Pour la plupart des intégrations, il suffit de mettre à jour l’identifiant du modèle et de relancer vos vérifications habituelles.

Les formats de requête et de réponse existants peuvent rester inchangés.

## Nouveautés

La route Grok 4.20 de base ne nécessite aucun changement de comportement dans Phaseo Gateway.

Le seul changement pratique concerne le réglage de la variante multi-agent.

Avec Phaseo Gateway :

- Vous pouvez activer le raisonnement du Grok 4.20 de base avec `reasoning.enabled`.
- Réglez la variante multi-agent avec `reasoning.effort`.
- Choisissez `low`, `medium`, `high` ou `extra high`.
- D’après la documentation SpaceXAI, `low` et `medium` utilisent 4 agents ; `high` et `extra high` utilisent des configurations multi-agents plus importantes.

Nous ne transmettons pas directement `agent_count` dans les requêtes Gateway.

### Grok 4.20 de base avec contrôle du raisonnement

Utilisez le modèle de base et définissez directement `reasoning.enabled` :

```json
{
  "model": "spacex-ai/grok-4-20-2026-02-17",
  "input": "Explain this architecture",
  "reasoning": {
    "enabled": true
  }
}
```

### Grok 4.20 multi-agent avec réglage de l’effort

Utilisez le modèle multi-agent et réglez son niveau avec `reasoning.effort` :

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta-0309",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": {
    "effort": "medium"
  }
}
```

Niveaux d’effort de raisonnement :

- `low`
- `medium`
- `high`
- `extra high`
