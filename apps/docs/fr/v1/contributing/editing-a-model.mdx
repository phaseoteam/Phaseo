Les données des modèles se trouvent dans des fichiers JSON sous `packages/data/catalog/src/data/models`. Chaque modèle possède son propre dossier et un fichier `model.json`.

## 1. Trouver le modèle

Repérez le dossier du modèle à partir du fournisseur et du nom du modèle. Par exemple :

`packages/data/catalog/src/data/models/openai/gpt-5-2025-08-07/model.json`

## 2. Effectuer les modifications

Les modifications courantes comprennent :

- Descriptions et liens
- Capacités et points de terminaison pris en charge
- Tarifs ou informations sur la disponibilité
- Références aux benchmarks

Respectez le schéma utilisé dans les fichiers voisins.

## 3. Valider les données

Exécutez le script de validation des données avant d’ouvrir une PR :

```bash
pnpm validate:data
```

## 4. Ouvrir une PR

Ajoutez un court résumé des modifications et des sources utilisées.
