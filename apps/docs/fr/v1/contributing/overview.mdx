Pour corriger ou compléter le catalogue, ouvrez un ticket avec l’enregistrement concerné et les sources justificatives. Pour le code ou la documentation, soumettez une demande de fusion au [dépôt Phaseo](https://github.com/phaseoteam/Phaseo).

## Choisir votre contribution

| Changement | Commencer ici |
| --- | --- |
| Métadonnées, capacités, disponibilité ou prix des modèles | [Signaler une mise à jour de modèle](./editing-a-model.mdx) |
| Détails d’entreprise ou d’organisme de recherche | [Signaler une mise à jour d’organisation](./editing-an-organisation.mdx) |
| Résultats de benchmarks | [Soumettre des scores](../research/submitting-scores.mdx) |
| Autres corrections du catalogue | [Signaler des informations incorrectes](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) |
| Fournisseurs ou autres données du catalogue manquants | [Demander de nouvelles données](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) |
| Documentation ou code | [Processus de contribution](./how-to-contribute.mdx) et [structure du dépôt](./repo-structure.mdx) |

## Publication des signalements du catalogue

Les responsables examinent les preuves du ticket et appliquent les changements approuvés via l’[éditeur interne](https://phaseo.app/internal/data), réservé aux administrateurs. Les changements de prix des fournisseurs nécessitent une revue explicite avant publication.

La base de données fait autorité pour le catalogue. Les instantanés JSON publics quotidiens restent disponibles, mais leurs modifications et les demandes de fusion de JSON archivés ne mettent pas à jour le catalogue en ligne. L’ancien importateur JSON a été retiré.

## Avant de soumettre

- Incluez la page ou l’identifiant d’enregistrement concerné et décrivez la correction proposée.
- Citez des sources officielles et distinguez les benchmarks publiés des mesures indépendantes.
- Gardez chaque signalement ou demande de fusion ciblé.
- N’incluez jamais d’identifiants secrets ni de données privées de clients.
- Suivez le [Code de conduite](../community/code-of-conduct.mdx).

Discutez des grands changements de schéma ou de fonctionnalités avec les responsables avant de les implémenter. Demandez de l’aide sur [Discord](https://discord.gg/aQyywCvgZ5) si vous ne savez pas où placer un changement.
