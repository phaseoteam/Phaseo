Pour corriger ou compléter le catalogue, ouvrez une issue avec l’enregistrement concerné et les sources justificatives. Pour le code ou la documentation, soumettez une pull request au [dépôt Phaseo](https://github.com/phaseoteam/Phaseo).

## Choisir votre contribution

| Changement | Commencer ici |
| --- | --- |
| Métadonnées, capacités, disponibilité ou tarifs des modèles | [Signaler une mise à jour de modèle](./editing-a-model.mdx) |
| Informations sur une entreprise ou un organisme de recherche | [Signaler une mise à jour d’organisation](./editing-an-organisation.mdx) |
| Résultats de benchmarks | [Soumettre des scores](../research/submitting-scores.mdx) |
| Autres corrections du catalogue | [Signaler une information incorrecte](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) |
| Fournisseurs ou autres données du catalogue manquants | [Demander de nouvelles données](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) |
| Documentation ou code | [Processus de contribution](./how-to-contribute.mdx) et [structure du dépôt](./repo-structure.mdx) |

## Comment les signalements du catalogue sont publiés

Les responsables examinent les preuves de l’issue et appliquent les changements approuvés via l’[éditeur interne](https://phaseo.app/internal/data), réservé aux administrateurs. Les mises à jour de prix des fournisseurs nécessitent une revue explicite avant publication.

La base de données est la seule source des enregistrements du catalogue. Le dépôt ne contient aucun JSON de catalogue : une pull request ne peut donc pas modifier un enregistrement du catalogue.

## Avant de soumettre

- Indiquez la page ou l’identifiant de l’enregistrement concerné et décrivez la correction proposée.
- Citez des sources officielles et distinguez les résultats de benchmarks annoncés des mesures indépendantes.
- Limitez chaque signalement ou pull request à un seul sujet.
- N’incluez jamais d’identifiants de connexion ni de données privées de clients.
- Respectez le [Code de conduite](../community/code-of-conduct.mdx).

Discutez des changements importants de schéma ou de fonctionnalité avec les responsables avant de les implémenter. Demandez de l’aide sur [Discord](https://discord.gg/aQyywCvgZ5) si vous ne savez pas où placer un changement.
