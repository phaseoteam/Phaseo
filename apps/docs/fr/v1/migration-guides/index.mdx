# Guides de migration

Les guides de migration Phaseo couvrent deux types d’évolution :

- passer d’une autre plateforme ou passerelle à Phaseo
- adopter une version de modèle sur la même plateforme

## Migrations de modèles

Utilisez ces guides lorsque l’intégration reste globalement la même, mais que le modèle sous-jacent change.

Ils couvrent :

- les changements de paramètres de requête
- les évolutions du comportement des prompts et du raisonnement
- les différences de sortie structurée et d’appel d’outils
- les stratégies de déploiement progressif, de repli et de retour arrière

## Utiliser ces guides

1. Déterminez si vous changez de plateforme, de modèle ou des deux.
2. Commencez par le guide correspondant à la partie la plus risquée de la migration.
3. Vérifiez les paramètres de requête et le comportement de l’endpoint avant de comparer la qualité des réponses.
4. Exécutez des évaluations proches de la production avant de déplacer le trafic réel.
