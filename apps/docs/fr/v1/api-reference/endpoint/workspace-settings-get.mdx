sidebarTitle: "Obtenir les paramètres"

description: "Récupère les paramètres par défaut de routage, de fournisseur, de confidentialité et de Gateway de l’espace de travail."
---
<Note>Ce point de terminaison nécessite une clé API de gestion avec `settings:read`.</Note>

Utilisez ce point de terminaison pour consulter les mêmes paramètres durables de l’espace de travail que ceux utilisés par le tableau de bord et Gateway.
