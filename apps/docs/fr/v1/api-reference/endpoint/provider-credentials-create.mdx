---
title: "Créer un identifiant fournisseur"
sidebarTitle: "Créer un identifiant"
badge: "Beta"
openapi: "/fr/openapi/v1/openapi.localized.yaml POST /byok"
description: "Chiffrer et stocker un identifiant fournisseur pour le routage de l’espace de travail."
---

<Warning>
La valeur `key` est accessible en écriture uniquement. Phaseo la chiffre immédiatement et ne la renvoie jamais dans les réponses de l’API.
</Warning>

Utilisez `routing_mode: "priority"` pour essayer l’identifiant avant la capacité gérée, ou `"fallback"` pour l’essayer ensuite. Configurez `byokFallbackEnabled` dans les paramètres de l’espace de travail pour autoriser ou non le recours à la capacité gérée en cas d’échec de l’identifiant prioritaire.
