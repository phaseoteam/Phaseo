---
<Note>Ce point de terminaison nécessite une clé API de gestion avec `presets:write` et une identité utilisateur associée.</Note>

La configuration du préréglage peut définir des valeurs par défaut limitées pour les prompts, paramètres, routage et plugins. Les préréglages publics utilisent l’identifiant éditeur de l’espace de travail.
