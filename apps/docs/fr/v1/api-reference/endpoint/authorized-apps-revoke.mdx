---
title: "Révoquer une application autorisée"
sidebarTitle: "Révoquer l’application"
badge: "Beta"
openapi: "/fr/openapi/v1/openapi.localized.yaml DELETE /me/authorized-apps/{id}"
description: "Révoquez l’accès d’une application pour que ses jetons cessent de fonctionner."
---
<Note>Ce point de terminaison nécessite un jeton d’accès OAuth avec `oauth_clients:delete`. Révoquer l’autorisation de l’application appelante la déconnecte.</Note>
