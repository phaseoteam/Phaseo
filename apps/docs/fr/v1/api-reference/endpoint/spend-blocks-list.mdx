Nécessite `spend_rules:read`. Les appelants OAuth doivent être propriétaires ou administrateurs de l'espace de travail. Ajoutez `include_lifted=true` pour inclure les blocages levés. Les blocages sont appliqués au mieux ; consultez [bloquer les requêtes](../../guides/spend-alerts.mdx#block-requests).
