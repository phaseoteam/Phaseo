---
<Note>Ce point de terminaison nécessite une clé API de gestion avec `settings:write`.</Note>

La durée de conservation doit être comprise entre 90 et 365 jours. La désactivation de la journalisation désactive également le contrôle de confidentialité des journaux d’entrée et de sortie de l’espace de travail.
