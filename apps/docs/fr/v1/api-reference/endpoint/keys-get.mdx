---
<Note>
Ce point de terminaison nécessite une clé API de gestion. Les clés API Gateway standard ne sont pas acceptées.
</Note>

Renvoie les métadonnées d’une clé API de l’espace de travail authentifié. Le segment de chemin `{id}` peut être l’identifiant interne de la clé ou son empreinte renvoyée par l’API.
