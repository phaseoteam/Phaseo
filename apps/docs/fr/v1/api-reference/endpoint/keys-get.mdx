description: "Récupérer une clé API par son identifiant ou son empreinte."
---
<Note>
Ce point de terminaison nécessite une clé API de gestion. Les clés API Gateway standard ne sont pas acceptées.
</Note>

Renvoie les métadonnées d’une clé API de l’espace de travail authentifié. Le segment de chemin `{id}` est l’identifiant de la clé. Une empreinte de clé conservée d’une réponse précédente reste acceptée, mais les réponses ne l’incluent plus.
