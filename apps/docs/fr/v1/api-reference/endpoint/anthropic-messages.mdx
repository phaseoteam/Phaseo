Envoyez une charge utile de l’API Anthropic Messages à `/v1/messages` et recevez une réponse au format Anthropic, pour n’importe quel modèle routé par Phaseo. Les champs d’utilisation d’outils d’Anthropic sont pris en charge, et l’en-tête `X-Phaseo-Strictness` détermine le traitement des paramètres non pris en charge.

Définissez `stream: true` pour recevoir des server-sent events au format Anthropic (`message_start`, `content_block_*`, `message_delta`, `message_stop`). Le streaming fonctionne aussi dans les boucles d’outils.

## Messages système en cours de conversation

Ajoutez un message `role: "system"` dans `messages` pour une instruction qui s’applique à partir de ce point de la conversation. Le champ `system` de niveau supérieur ne change pas, donc un préfixe mis en cache est toujours réutilisé.

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5.5",
    "max_tokens": 512,
    "system": "You are a code review assistant.",
    "messages": [
      { "role": "user", "content": "Review process() in utils.py." },
      { "role": "assistant", "content": "The loop is fine; the regex is compiled on every call." },
      { "role": "user", "content": "Now review the code that calls it." },
      { "role": "system", "content": "From now on, include type annotations in every suggestion." }
    ]
  }'
```

Un message système accepte une chaîne ou des blocs de texte. Il doit suivre directement un tour utilisateur (ou un tour assistant qui se termine par un résultat d’outil serveur) et être le dernier message ou être suivi d’un tour assistant. Toute autre position renvoie un `400`. `clear_at`, `output_config` et les blocs `tool_addition` ou `tool_removal` ne sont pas pris en charge.

| Modèle | Comment il reçoit le message système |
| --- | --- |
| Claude Fable 5 et 5.1, Mythos 5 et 5.1, Opus 4.8, Opus 5 et 5.5, Sonnet 5.5, Haiku 5.5 | À sa place dans la conversation |
| Les autres modèles Claude, dont Sonnet 5, et tous les modèles Claude sur Microsoft Foundry | Fusionné dans le prompt système de niveau supérieur |
| Les modèles des autres fournisseurs | Comme message système, de la même façon qu’un message envoyé à Chat Completions |

## Utiliser les outils serveur

Ajoutez un outil `phaseo:` dans `tools` : Phaseo l’exécute lorsque le modèle l’appelle, le réécrit au format d’outil d’Anthropic pour le fournisseur et poursuit la boucle d’outils côté serveur. `/v1/messages` accepte tous les outils serveur sauf `phaseo:apply_patch` ; le guide [Outils serveur](../../guides/server-tools) les liste.

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "What time is it in America/New_York right now?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["America/New_York"] } }
    ],
    "tool_choice": { "type": "auto" }
  }'
```

Les appels d’outils serveur sont comptés dans `usage.server_tool_use`. L’ancien type `gateway:datetime` fonctionne toujours. Avec `stream: true`, Phaseo exécute lui-même les tours d’outils, puis vous transmet la suite de la réponse en un seul flux.

## Utiliser la recherche web native d’Anthropic

Lorsque le modèle et le fournisseur Anthropic routés prennent en charge la recherche web native, transmettez directement la définition d’outil d’Anthropic, par exemple `type: "web_search_20250305"`. Le routage des fournisseurs filtre toujours sur la prise en charge de `web_search_options` avant l’exécution.

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "Find the latest Anthropic web search guidance." }
    ],
    "tools": [
      {
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": 3,
        "allowed_domains": ["docs.anthropic.com"]
      }
    ],
    "tool_choice": { "type": "auto" }
  }'
```
