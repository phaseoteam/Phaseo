---
Cet endpoint est en [Bêta](../../developers/feature-maturity.mdx) et s’active par espace de travail, sur demande.

Lorsque vous utilisez la clé Gateway partagée, utilisez les ID de fichiers enregistrés lors de l’envoi au lieu de dépendre de ce point de terminaison.
