description: "Ajoute des utilisateurs existants à un espace de travail."

<Note>Ce point de terminaison nécessite une clé API de gestion avec `workspaces:write` et un rôle de propriétaire ou d’administrateur.</Note>

Les personnes rejoignent un espace de travail via une invitation : elles l’acceptent, ce qui crée une demande d’adhésion, et ce point de terminaison l’approuve. Chaque utilisateur de `user_ids` doit avoir une demande d’adhésion en attente dans l’espace de travail. Les autres utilisateurs sont refusés ; envoyez-leur d’abord une invitation. Les membres existants conservent leur rôle.

Le rôle peut être `admin` ou `member`. Sans rôle, chaque personne reçoit le rôle avec lequel son invitation a été créée. Seul le propriétaire de l’espace de travail peut ajouter des administrateurs, et la propriété de l’espace de travail ne peut pas être attribuée via ce point de terminaison.

Chaque personne est approuvée séparément. Si une approbation échoue, les personnes approuvées avant restent dans l’espace de travail et les suivantes ne sont pas tentées. La réponse est alors un `409` dont les listes `approved`, `failed` et `not_attempted` indiquent où le traitement s’est arrêté ; corrigez le problème et renvoyez les utilisateurs restants.
