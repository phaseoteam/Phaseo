Envoyez `input` et un tableau ordonné de `questions` à `POST /v1/decisions`, et recevez une réponse typée par question, avec des probabilités, dans le même ordre.

## Prendre une décision

Cette requête pose une question de chaque type. Elle nécessite une clé API Phaseo et une route `openai/gpt-6-luna` disponible.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/decisions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-luna",
    "input": "I was charged twice for my order and I cannot log in to download the invoice.",
    "questions": [
      {
        "type": "choice",
        "name": "department",
        "instructions": "Which team should handle this request?",
        "choices": [
          { "value": "billing", "description": "Payments, invoices and refunds" },
          { "value": "support", "description": "Product usage and troubleshooting" }
        ]
      },
      {
        "type": "predicate",
        "name": "is_blocked",
        "instructions": "Is the customer blocked from using the product?"
      },
      {
        "type": "score",
        "name": "urgency",
        "instructions": "How urgent is this request?",
        "levels": [{ "label": "low" }, { "label": "medium" }, { "label": "high" }]
      }
    ]
  }'
```

```typescript TypeScript SDK
    },

console.log(decision.answers);
```

## Rédiger les questions

`input` est une chaîne, ou un tableau de messages `user` dont le `content` est une chaîne ou une liste d’éléments `input_text`, `input_image`, `input_audio` et `input_video`. `name` est facultatif ; les réponses conservent l’ordre de la requête, y compris pour les questions sans nom et les noms répétés.

Une requête contient au plus 128 questions, sauf sur `google/gemini-decision-1`, qui en accepte jusqu’à 1000, sur `parallel/decisions-fast`, qui en accepte jusqu’à 100, et sur Clef, qui en accepte jusqu’à 64. Une requête qui dépasse la limite du modèle renvoie `400`.

| `type` | Champs supplémentaires | Champs de la réponse |
| --- | --- | --- |
| `predicate` | aucun | `probability` (0–1) que la réponse soit oui |
| `choice` | `choices` : `value` (chaîne ou booléen, distincts) et `description` facultative | `choice`, `confidence`, `probabilities` par valeur |
| `score` | `levels` : `label` et `description` facultative | `score` (indice de niveau pondéré par les probabilités), `confidence`, `probabilities` par niveau |
| `box` | aucun ; nécessite une image dans `input` | `box` (`top`, `bottom`, `left`, `right`), `confidence` |
| `locate` | aucun ; nécessite un `input` de type chaîne sans média | `spans` : `start`, `end`, `text`, `score` |

Les valeurs de choix booléennes sont renvoyées sous forme de booléens. Un modèle qui refuse une question renvoie `type: "refusal"` pour celle-ci. Les types pris en charge par chaque modèle sont listés dans [Choisir un modèle](#choose-a-model).

Les images se placent dans des éléments `input_image` sous forme de data URL. Les URL HTTPS d’images hébergées ne fonctionnent qu’avec les modèles Base Labs (`baselabs/elephant-1`, `baselabs/mammoth-1` et `baselabs/joey-1`) et doivent pointer vers Amazon S3, Google Cloud Storage ou Azure Blob Storage. Une requête contient au plus 128 images, ce que Luna accepte ; les autres fournisseurs fixent des limites plus basses. Un `detail` d’image explicite et `safety_identifier` nécessitent une route OpenAI.

## Utiliser l’ancien format `state`

Les requêtes avec `state` et un dictionnaire de questions nommées fonctionnent toujours et renvoient des réponses indexées par les mêmes noms. Together Tev (`together/tev1-4b-experimental`) exige ce format, car il renvoie une étiquette sans probabilités, et ne répond qu’aux questions `choice`. Respan Span-01 utilise aussi ce format. Ne mélangez pas les formats : `input` avec `state` ou `images` renvoie `400`.

- `state` : une chaîne, un objet ou un tableau contenant les informations à évaluer.
- `questions` : jusqu’à 128 questions nommées, ou davantage sur les modèles dont la limite est plus élevée. Chacune définit `type` à `noul` (oui/non), `choice` ou `score`, ainsi que `instructions`. Les questions à choix prennent `criteria` sous forme de dictionnaire option → description ; les questions à score prennent `criteria` sous forme de tableau d’au moins deux descriptions de niveaux.
- Les questions `locate` n’utilisent que `instructions` et nécessitent un `state` de type chaîne sans `images` ; voir [Perplexity Decider](#liquid-d1-and-perplexity-decider).
- `images` : jusqu’à quatre images PNG, JPEG ou WebP, sous forme d’URL `data:` ou d’objets `{ "content_type", "base64" }`.
- `model` : `typesafe/jev-1.13.0` par défaut s’il est omis.

Les réponses utilisent les mêmes clés que `questions`. Les réponses `choice` contiennent l’option choisie, les probabilités et la confiance ; les réponses `noul` contiennent une probabilité de 0 à 1 ; les réponses `score` contiennent un score pondéré par les probabilités, une légende, les probabilités et la confiance.

### TypeSafe Jev

Utilisez `typesafe/jev-1.13.0` pour Jev 1.13, ou `typesafe/jev-latest` pour suivre la dernière version de Jev. Pour la sémantique des questions chez le fournisseur, consultez la [référence de l’API](https://docs.typesafe.ai/api) de TypeSafe.

Sur les routes TypeSafe compatibles, Jev 1.13 et 1.14 acceptent des images PNG ou JPEG intégrées via `input_image` ou l’ancien champ `images`. Phaseo construit les ressources image de TypeSafe et active automatiquement la prise en charge des images. Les images doivent respecter les [limites d’images](https://docs.typesafe.ai/images) de TypeSafe : au plus 16 MiB chacune, de 256 à 1568 pixels de côté, et au moins 78 400 pixels au total. TypeSafe valide les dimensions et l’encodage et ne redimensionne pas les images refusées. Le corps JSON transmis au fournisseur est limité à 32 MiB. Les tokens d’image sont facturés au prix d’entrée normal.

`box` (sur les routes compatibles comme Jev 1.14) nécessite une image, ne prend aucun critère et renvoie un cadre de délimitation avec sa confiance. Ses bords vont de 0 à 1, mesurés depuis le coin supérieur gauche. Box renvoie toujours un rectangle : associez-le donc à une question de présence `predicate` lorsque la cible peut être absente. Avec l’ancien champ `images`, faites référence à `images[0]` ; avec une entrée ordonnée, faites référence à la première image ou à `[Image 0]`. Consultez le [contrat Box](https://docs.typesafe.ai/primitives/box).

Définissez `provider_options.typesafe.long_context` à `true` pour porter les limites de contexte par requête et par question à 262k tokens, au lieu de 64k par requête et 32k par question par défaut. Le contexte long coûte le même prix par token. Les images, Box et le contexte long sont des capacités expérimentales chez le fournisseur.

```json
{
  "model": "typesafe/jev-1.14.0",
  "input": [{
    "role": "user",
    "content": [{ "type": "input_image", "image_url": "data:image/png;base64,<base64 image bytes>" }]
  }],
  "questions": [
    { "type": "predicate", "name": "visible", "instructions": "Is there a mug in the first image?" },
    { "type": "box", "name": "mug", "instructions": "The mug in the first image" }
  ],
  "provider_options": { "typesafe": { "long_context": true } }
}
```

### Cloudflare Clef et Clef Flash

`cloudflare/clef` et `cloudflare/clef-flash` s’exécutent sur Cloudflare Workers AI. Clef dispose d’une fenêtre de contexte de 65 536 tokens et Clef Flash de 24 576 tokens.

```json
{
  "model": "cloudflare/clef-flash",
  "state": "Inspect the attached product photo.",
  "images": [{ "content_type": "image/png", "base64": "<base64 image bytes>" }],
  "questions": {
    "damaged": { "type": "noul", "instructions": "Is the product visibly damaged?" }
  }
}
```

`images` accepte aussi une chaîne `data:image/png;base64,...`. Clef accepte jusqu’à quatre images PNG, JPEG ou WebP, chacune d’au plus 4 MiB et 16 mégapixels, avec au plus 8 MiB de données d’image décodées et un corps de requête de 13 MiB. Les URL distantes ne sont pas prises en charge, et Cloudflare valide les formats et les dimensions des images. Les modèles sans prise en charge des images refusent les requêtes avec images.

Clef accepte au plus 64 questions, avec des ID d’au plus 100 lettres, chiffres, traits de soulignement, points ou traits d’union. Les questions à choix nécessitent de 2 à 255 options et les questions à score de 2 à 10 niveaux. Consultez la [documentation Clef](https://developers.cloudflare.com/workers-ai/models/clef/) de Cloudflare.

### Cloudflare Clef Omni

`cloudflare/clef-omni` accepte le texte, les images, l’audio et la vidéo. Les éléments audio et vidéo sont des extensions Phaseo du format d’entrée ; les routes OpenAI n’acceptent que le texte et les images. Remplacez les octets audio et l’URL vidéo fictifs par vos propres médias avant d’envoyer cet exemple.

```json
{
  "model": "cloudflare/clef-omni",
  "input": [{
    "role": "user",
    "content": [
      { "type": "input_text", "text": "Review the recording and clip." },
      { "type": "input_audio", "input_audio": { "data": "<base64 WAV bytes>", "format": "wav" } },
      { "type": "input_video", "video_url": { "url": "https://media.example.com/clip.mp4" } }
    ]
  }],
  "questions": [{ "type": "predicate", "name": "safe", "instructions": "Is the equipment operating safely?" }]
}
```

Envoyez l’audio dans `input_audio.data` avec `format: "wav"` ou `"mp3"`, ou dans `input_audio.url` avec une URL HTTPS publique ou une data URL audio intégrée. `input_video.video_url` prend une chaîne ou `{ "url": "..." }` contenant une URL HTTPS publique ou une data URL MP4/WebM intégrée. Les serveurs distants doivent renvoyer le Content-Type correspondant. Phaseo récupère les URL avec des limites de taille et des contrôles d’adresses privées et de redirections, puis intègre les médias pour Cloudflare ; les identifiants du fournisseur ne sont jamais envoyés au serveur de médias.

| Limite | Valeur |
| --- | --- |
| Clips audio | 4, chacun d’au plus 8 MiB et 300 secondes |
| Vidéos | 2, chacune d’au plus 16 MiB et 60 secondes |
| Audio et vidéo cumulés | 16 MiB décodés |
| Images | Mêmes limites par image et cumulées que Clef |
| Corps de la requête | 37 MiB (remplace les 13 MiB de Clef) |
| Contexte | 64 000 tokens |

Cloudflare valide l’encodage des médias, les dimensions des images et la durée des clips, et échantillonne la vidéo à deux images par seconde. La bande son d’une vidéo est utilisée lorsque toutes les vidéos de la requête en ont une. Les tokens de médias comptent dans le contexte et la facturation ; Phaseo facture d’après l’utilisation en entrée indiquée par Cloudflare et n’ajoute aucun frais distinct pour l’audio ou la vidéo. Consultez le [contrat Omni de Cloudflare](https://github.com/cloudflare/cloudflare-docs/blob/production/src/content/workers-ai-models/clef-omni.json).

### Liquid D1 et Perplexity Decider

Liquid D1 (`liquid-ai/d1:free`, ainsi que `liquid-ai/d1`) est gratuit pendant l’accès anticipé expérimental. Perplexity Decider V1.3 (`perplexity/pplx-decider-v1.3`, ou `perplexity/pplx-decider-latest`) et Decider Flash V1.3 (`perplexity/pplx-decider-flash-v1.3`, ou `perplexity/pplx-decider-flash-latest`) nécessitent un identifiant de fournisseur Perplexity dans Phaseo. Leur état image utilise des data URL base64 PNG, JPEG ou WebP ; les URL d’images distantes ne sont pas prises en charge. Ils répondent aussi aux questions `locate`, qui renvoient les parties d’un `input` ou d’un `state` de type chaîne correspondant aux `instructions`, par exemple `"email address"`. Chaque extrait comporte un `text` copié tel quel, des positions `start` et `end` comptées en points de code Unicode (`end` est exclusive) et un `score` d’autant plus élevé que le modèle est certain ; `spans` est vide quand rien ne correspond. Locate n’utilise pas de criteria, n’accepte ni images, ni audio, ni vidéo, et ne fonctionne que sur les modèles qui l’indiquent ; les autres renvoient `400`. Perplexity l’a entraîné sur des entrées de 8K tokens au maximum. Sur les deux, une question à choix accepte jusqu’à 255 options et une question à score jusqu’à 10 niveaux.

### Inception Mercury Decide

`inception/mercury-decide` prend des éléments en texte ou en JSON. Les questions à choix acceptent jusqu’à 255 options et les questions à score jusqu’à 10 niveaux. Les images, le streaming et l’appel d’outils ne sont pas pris en charge. Le prix d’entrée de $0.02 correspond à la promotion de 50 % d’Inception, sans date de fin publiée ; vérifiez les [tarifs actuels du fournisseur](https://docs.inceptionlabs.ai/get-started/models) avant utilisation.

```json
{
  "model": "inception/mercury-decide",
  "input": "Please refund the duplicate charge on my account.",
  "questions": [{
    "type": "predicate",
    "name": "billing",
    "instructions": "Is this request about billing?"
  }]
}
```

### Microsoft Decision

`microsoft/microsoft-decision-1` s’exécute sur un déploiement Azure Foundry et prend des éléments en texte ou en JSON jusqu’à 32 768 tokens. Les médias, le streaming, les outils, `safety_identifier` et `service_tier` ne sont pas pris en charge. Consultez le [guide de Microsoft](https://learn.microsoft.com/azure/foundry/foundry-models/how-to/use-foundry-models-microsoft-decision).

```json
{
  "model": "microsoft/microsoft-decision-1",
  "input": "The API returns 500 on every call.",
  "questions": [{
    "type": "choice",
    "name": "team",
    "instructions": "Which team should handle this ticket?",
    "choices": [
      { "value": "engineering", "description": "Bugs, errors, and outages" },
      { "value": "support", "description": "How-to and account questions" }
    ]
  }]

```

### Respan Span-01

Span-01 utilise l’ancien format. `state` doit être un span de conversation : un tableau `input` des messages précédents et un message assistant `output`. Il ne répond qu’aux questions `noul` : la valeur `noul` est la probabilité que le comportement soit présent, et `probabilities` donne aussi les probabilités qu’il soit absent ou non observable.

```json
{
  "model": "respan/span-01:free",
  "state": {
    "input": [{ "role": "user", "content": "Please connect me to a person." }],
    "output": { "role": "assistant", "content": "I will connect you to support." }
  },
  "questions": {
    "escalation": {
      "type": "noul",
      "instructions": "Does the assistant offer a human handoff?"
    }
  }
}
```

Une réponse ressemble à ceci :

```json
{
  "answers": {
    "escalation": {
      "type": "noul",
      "noul": 0.73,
      "probabilities": {
        "true": 0.73,
        "false": 0.25,
        "not_observable": 0.02
      }
    }
  }
}
```

`respan/span-01:free` est le modèle Lite gratuit, avec une limite quotidienne, et correspond au modèle `span-01-free` de Respan. `respan/span-01` correspond à `span-01-pro` et est facturé par Respan. Span-01 est en accès anticipé : Respan doit l’activer pour votre organisation, et vous devez ajouter votre clé API Respan comme identifiant de fournisseur Respan dans Phaseo avant d’appeler l’un ou l’autre modèle.
