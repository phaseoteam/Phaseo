---
title: "Supprimer une route dynamique"
sidebarTitle: "Supprimer la route"
badge: "Bêta"
openapi: "/fr/openapi/v1/openapi.localized.yaml DELETE /routing/dynamic-routes/{id}"
description: "Supprime une route dynamique et son historique de versions."
---
<Note>Ce point de terminaison nécessite une clé API de gestion avec `settings:write`.</Note>

Transmettez `confirm_name` pour confirmer facultativement le nom exact. Les contextes des clés associées sont actualisés après la suppression.
