---
title: "Supprimer une clé API"
sidebarTitle: "Supprimer la clé API"
badge: "Bêta"
openapi: "/fr/openapi/v1/openapi.localized.yaml DELETE /keys/{id}"
description: "Supprime une clé API de l’espace de travail authentifié."
---
<Note>Ce point de terminaison nécessite une clé API de gestion. Les clés API Gateway standard ne sont pas acceptées.</Note>

La suppression est définitive du point de vue de l’API publique. La réponse confirme que la clé a été supprimée.
