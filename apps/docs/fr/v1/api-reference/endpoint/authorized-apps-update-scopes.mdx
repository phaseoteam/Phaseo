title: "Retirer des portées d’une application autorisée"
sidebarTitle: "Réduire les portées"
badge: "Beta"
openapi: "/fr/openapi/v1/openapi.localized.yaml PATCH /me/authorized-apps/{id}"
description: "Limitez l’accès d’une application autorisée à moins de portées."
---
<Note>Ce point de terminaison nécessite un jeton d’accès OAuth avec `oauth_clients:write`. Les portées peuvent seulement être retirées ; pour en ajouter, autorisez de nouveau l’application dans le navigateur.</Note>
