---
title: "Supprimer une destination d’observabilité"
sidebarTitle: "Supprimer la destination"
badge: "Bêta"
openapi: "/fr/openapi/v1/openapi.localized.yaml DELETE /observability/destinations/{id}"
description: "Supprime une destination et ses filtres."
---
<Note>Ce point de terminaison nécessite une clé API de gestion avec `settings:write`.</Note>

La suppression d’une destination supprime également ses liens vers les clés API et ses groupes de règles.
