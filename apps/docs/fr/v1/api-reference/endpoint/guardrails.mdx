<Info>
La gestion des garde-fous nécessite une clé API de gestion. Les opérations de lecture nécessitent `guardrails:read` ; les modifications nécessitent `guardrails:write` ou `guardrails:delete`.
</Info>

Utilisez les garde-fous pour appliquer des contrôles de confidentialité, des restrictions de fournisseurs et de modèles, le traitement des injections de prompt et des politiques sur les informations sensibles. Un garde-fou peut être attribué à des clés API, à des membres de l'espace de travail, ou aux deux.

Les garde-fous ne limitent ni les requêtes ni les dépenses. Utilisez plutôt les [limites de clé API](./keys-update.mdx), les [budgets de l'espace de travail](./budgets-list.mdx) ou les [alertes de dépenses](../../guides/spend-alerts.mdx). L'entrée `budgets` et les champs `*_limit_requests` et `*_limit_cost_nanos` ont été retirés des garde-fous ; un client qui les envoie encore n'est pas refusé, et ils sont ignorés.

Les modifications réussies actualisent l’état des règles de l’espace de travail et apparaissent dans son journal d’audit.
