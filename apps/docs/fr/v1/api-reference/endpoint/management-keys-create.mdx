title: "Créer une clé de gestion"
sidebarTitle: "Créer une clé de gestion"
badge: "Beta"
openapi: "/fr/openapi/v1/openapi.localized.yaml POST /management-keys"
description: "Créer une clé de gestion avec des portées pour automatiser le plan de contrôle."
---
<Note>Ce point de terminaison nécessite une identité de propriétaire ou d’administrateur ainsi que `management_keys:write`.</Note>

Choisissez un modèle de capacités ou fournissez une liste explicite de portées. La `key` brute n’est renvoyée que dans la réponse de création ; stockez-la immédiatement dans un coffre de secrets côté serveur.
