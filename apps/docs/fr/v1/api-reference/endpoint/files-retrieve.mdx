description: "Récupère les métadonnées d’un fichier appartenant à l’espace de travail authentifié."
---
Cette route actualise les métadonnées du fichier auprès du fournisseur en amont et vérifie que l’espace de travail en est propriétaire avant de transmettre la réponse.
