---
title: "Supprimer des membres de l’espace de travail"
sidebarTitle: "Supprimer des membres"
badge: "Bêta"
openapi: "/fr/openapi/v1/openapi.localized.yaml POST /workspaces/{id}/members/remove"
description: "Supprime de l’espace de travail les membres qui n’en sont pas propriétaires."
---
Ce point de terminaison nécessite une clé API de gestion avec `workspaces:write` et le rôle de propriétaire ou d’administrateur.

Le propriétaire de l’espace de travail ne peut pas être supprimé.
