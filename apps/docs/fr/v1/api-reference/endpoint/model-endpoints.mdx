Appelez cet endpoint avant d’envoyer une requête pour confirmer qu’une combinaison de modèle, fournisseur, endpoint et paramètres est disponible. Pour `openai/gpt-6-astra` :

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

Chaque entrée de `endpoints` correspond à une route de fournisseur pour un endpoint :

| Champ | Contenu |
| --- | --- |
| `endpoint`, `capability_id`, `public_path`, `collection` | Les ID canoniques de l’endpoint et de la capacité, et le chemin public de l’API |
| `provider`, `model` | L’ID et le nom du fournisseur, et le slug du modèle chez le fournisseur |
| `routable`, `status`, `status_reason` | Si la route reçoit du trafic actuellement, sa disponibilité, et pourquoi elle est en aperçu uniquement ou inactive |
| `modalities` | Les modalités d’entrée et de sortie |
| `capabilities` | Les noms des paramètres pris en charge et le détail structuré des paramètres |
| `routing` | Les états de routage du fournisseur, du modèle et de la capacité |
| `effective` | Les dates `from` et `to` lorsque la route est planifiée ou limitée dans le temps |
| `pricing` | Le résumé des tarifs de l’endpoint |

Pour comparer d’abord des modèles, utilisez [Lister les modèles](./models.mdx) ; pour voir tous les endpoints exposés par l’API, utilisez [Lister les endpoints](./endpoints.mdx).

## Inclure les routes prévues et inactives

La valeur par défaut `availability=active` ne renvoie que les lignes routables publiquement. Utilisez `availability=all` pour examiner les routes à venir et inactives :

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints?availability=all" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

N’envoyez du trafic de production que vers une ligne dont `routable` vaut `true` et `status` vaut `active`.

## Filtrer les routes

Ces filtres acceptent des paramètres répétés ou une liste séparée par des virgules : `provider`, `provider_status`, `provider_routing_status`, `model_routing_status`, `capability_status`, `provider_availability_status`, `provider_availability_reason`, `status` et `supported_parameters` (alias `params`). [Lister les modèles](./models.mdx#filter-the-list) décrit leurs valeurs.

Cette requête renvoie les routes OpenAI qui prennent en charge `reasoning_effort` :

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints?provider=openai&supported_parameters=reasoning_effort" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```
