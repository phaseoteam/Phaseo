---
title: "Lister les règles de dépenses"
sidebarTitle: "Lister les règles"
badge: "Beta"
openapi: "/fr/openapi/v1/openapi.localized.yaml GET /spend-rules"
description: "Liste les règles de dépenses de l'espace de travail et la limite de 50 règles."
---

Nécessite `spend_rules:read`. Tous les membres de l'espace de travail peuvent lire les règles de dépenses. Consultez le [guide des alertes de dépenses](../../guides/spend-alerts.mdx) pour savoir comment les règles sont évaluées.
