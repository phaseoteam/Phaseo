<Warning>L’extraction est en aperçu. La disponibilité des modèles dépend des routes de fournisseurs configurées.</Warning>

Nommez les `fields` voulus et envoyez-les avec votre texte source à `POST /v1/extractions` pour récupérer des valeurs typées, comme un numéro de facture, une date ou un total. Pour choisir parmi des options connues, utilisez plutôt [Décisions](./decisions.mdx).

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/extractions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cloudflare/clairic",
    "input": "Invoice INV-2291: 4 pallets at $250 each, shipping $80.",
    "fields": {
      "invoice_number": { "type": "text" },
      "total": { "type": "number", "decimals": 2, "instructions": "Total including shipping" }
    }
  }'
```

```typescript TypeScript SDK
import { Phaseo } from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY });
const result = await client.extractions.create({
  model: "cloudflare/clairic",
  input: "Invoice INV-2291: 4 pallets at $250 each, shipping $80.",
  fields: {
    invoice_number: { type: "text" },
    total: { type: "number", decimals: 2, instructions: "Total including shipping" },
  },
});
console.log(result.answers.total.value);
```

```python Python SDK
import os
from phaseo import Phaseo

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])
result = client.extractions.create({
    "model": "cloudflare/clairic",
    "input": "Invoice INV-2291: 4 pallets at $250 each, shipping $80.",
    "fields": {"total": {"type": "number", "decimals": 2,
                         "instructions": "Total including shipping"}},
})
print(result["answers"]["total"]["value"])
```
</CodeGroup>

Les exemples nécessitent une route de modèle d’extraction active : vérifiez donc la disponibilité du modèle
avant d’envoyer des requêtes. `AsyncPhaseo` en Python expose aussi
`await client.extractions.create(...)`.

## Types de champs

Les types pris en charge sont `text`, `number`, `date`, `time`, `datetime`, `duration` et
`list`. Les listes exigent `items: "text"`, `"number"` ou `"date"`. Fournissez de 1 à 64 champs
et au plus 16 384 caractères source. Les noms de champs commencent par une lettre ou un trait de soulignement
et contiennent jusqu’à 64 lettres, chiffres, traits de soulignement, points ou traits d’union.

Les nombres et les durées prennent en charge `integer` et `decimals` (0–6). Les durées acceptent
`seconds`, `minutes`, `hours`, `days`, `weeks`, `months` ou `years`. Définissez
`reference_date` lorsque l’interprétation de dates incomplètes dépend d’une année précise.

Les entrées image utilisent des objets `{ content_type, base64 }` : au plus quatre images PNG/JPEG/WebP,
de 4 MiB chacune et de 8 MiB au total après décodage. La limite de la requête est de 16 MiB.
Les URL distantes, les PDF, l’audio, la vidéo, les estimations, les prévisions et le streaming ne sont pas pris en charge.

## Lire les réponses

Lisez `answers[field_name].value`. Une valeur scalaire peut être `null` lorsque la source
ne permet pas de la déterminer. `p_null` est la probabilité, selon le modèle, d’une valeur indéterminée ;
`confidence` est un score distinct renvoyé par le modèle. Les listes fournissent `confidence` sans
`p_null`. Ces scores ne garantissent pas l’exactitude : choisissez des seuils de relecture adaptés à
votre charge de travail. Une liste vide valide n’est pas la même chose qu’une requête en échec.

`truncated: true` signifie que le fournisseur n’a pas traité toute l’entrée source. Relisez ou
renvoyez une entrée plus courte avant de compter sur l’exhaustivité du résultat. Les positions dans le texte et les suppositions brutes
ne sont pas exposées. Effectuez les calculs complexes dans le code de votre application.

L’utilisation agrège `input_tokens` sur l’ensemble des passes du fournisseur. Les tokens de sortie valent
zéro. Utilisez la tarification renvoyée par la passerelle plutôt que d’estimer le coût à partir de la longueur de la source
ou de multiplier l’utilisation par le nombre de champs.
