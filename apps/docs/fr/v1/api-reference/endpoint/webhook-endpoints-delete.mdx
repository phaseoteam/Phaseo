---
title: "Supprimer un endpoint webhook"
badge: "Bêta"
openapi: "/fr/openapi/v1/openapi.localized.yaml DELETE /webhook-endpoints/{id}"
---
Cet endpoint est en [Bêta](../../developers/feature-maturity.mdx) et s’active par espace de travail, sur demande.

<Note>Nécessite que l’espace de travail ait accès aux API asynchrones. Les secrets de signature ne sont renvoyés qu’à la création ou lors d’une rotation.</Note>
