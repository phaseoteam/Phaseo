<Note>Ce point de terminaison nécessite une clé API de gestion avec `analytics:read`.</Note>

L’export accepte les mêmes filtres que le point de terminaison d’analyses et renvoie toutes les lignes agrégées correspondantes dans un CSV compatible avec les tableurs.
