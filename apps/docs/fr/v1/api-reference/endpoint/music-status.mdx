---

Transmettez l’`id` renvoyé par [`POST /v1/music/generate`](./music-generate.mdx), et non son `nativeResponseId`. Phaseo renvoie le résultat stocké lorsque la génération est terminée, et interroge le fournisseur à votre place tant qu’elle est en cours.

```bash
curl https://api.phaseo.app/v1/music/generate/req_01JY6MUSIC123 \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "suno",
  "model": "V4_5PLUS",
  "nativeResponseId": "task_123",
  "output": [
    {
      "index": 0,
      "id": "clip_1",
      "audio_url": "https://...",
      "stream_audio_url": "https://...",
      "image_url": "https://...",
      "title": "Midnight Blue",
      "tags": "jazz, piano",
      "duration": 8
    }
  ],
  "usage": {
    "output_audio_count": 1,
    "output_audio_seconds": 8
  }
}
```

`status` vaut `queued`, `in_progress`, `completed` ou `failed`. `usage` est inclus une fois la génération terminée.
