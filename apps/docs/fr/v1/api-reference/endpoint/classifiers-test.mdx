Cet endpoint est en [Bêta](../../developers/feature-maturity.mdx) et s’active par espace de travail, sur demande.

<Note>Ce point de terminaison effectue une requête de modèle facturée avec vos propres identifiants ; il nécessite donc un jeton OAuth avec `classifiers:write` et `gateway:access`. Les clés de gestion ne sont pas acceptées.</Note>
