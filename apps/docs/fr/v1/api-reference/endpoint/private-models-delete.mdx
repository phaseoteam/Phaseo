---
title: "Supprimer un modèle privé"
sidebarTitle: "Supprimer un modèle privé"
badge: "Bêta"
openapi: "/fr/openapi/v1/openapi.localized.yaml DELETE /private-models/{id}"
description: "Supprimez un point de terminaison de modèle privé de l’espace de travail."
---

Nécessite `private_models:delete` et une identité de propriétaire ou d’administrateur. Les requêtes existantes utilisant l’identifiant du modèle ne pourront plus être résolues.
