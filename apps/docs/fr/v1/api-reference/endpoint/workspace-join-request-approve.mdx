<Note>Ce point de terminaison nécessite une clé API de gestion avec `workspaces:write`.</Note>

L’approbation vérifie l’expiration de l’invitation et le nombre d’utilisations restantes, applique le rôle de l’invitation et enregistre la décision dans une seule transaction.
