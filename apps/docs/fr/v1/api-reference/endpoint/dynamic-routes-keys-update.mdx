---
title: "Remplacer les clés d’une route dynamique"
sidebarTitle: "Associer des clés"
badge: "Bêta"
openapi: "/fr/openapi/v1/openapi.localized.yaml PUT /routing/dynamic-routes/{id}/keys"
description: "Remplace de manière atomique les clés API associées à une route dynamique."
---
<Note>Ce point de terminaison nécessite une clé API de gestion avec `settings:write`.</Note>

Toutes les clés doivent appartenir à l’espace de travail de la clé de gestion. Une clé ne peut être associée qu’à une seule route dynamique.
