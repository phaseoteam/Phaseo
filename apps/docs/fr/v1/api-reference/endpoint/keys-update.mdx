<Note>Ce point de terminaison nécessite une clé API de gestion. Les clés API Gateway standard ne sont pas acceptées.</Note>

Utilisez cette route pour renommer une clé, ajuster ses périmètres, définir son expiration, la désactiver ou fixer un plafond de dépenses avec `limit` et `limit_reset`.
