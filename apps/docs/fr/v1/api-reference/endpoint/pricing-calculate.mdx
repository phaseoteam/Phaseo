Envoyez une charge utile d’utilisation pour la tarifer selon les règles de tarification actives de la passerelle pour un fournisseur, un modèle et un endpoint. Les quatre champs sont obligatoires :

- `provider` : l’ID du fournisseur, par exemple `openai`.
- `model` : l’ID du modèle routé.
- `endpoint` : la famille d’endpoints, par exemple `responses` ou `chat.completions`.
- `usage` : l’utilisation à tarifer, comme des nombres de tokens ou d’autres valeurs de mesure.

Pour lister les tarifs actuels plutôt que tarifer une charge utile, utilisez [Lister les tarifs des modèles](./pricing-models.mdx).
