---

- `endpoints` : les identifiants canoniques des points de terminaison actuellement exposés par l’API
- `data` : les enregistrements des points de terminaison avec `public_path`, `collection`, `model_count` et `provider_count`
- `sample_models` : jusqu’à 10 identifiants récents de modèles visibles dans le catalogue public

Consultez [Lister les capacités des points de terminaison d’un modèle](./model-endpoints.mdx) pour obtenir des détails par fournisseur et paramètre.
