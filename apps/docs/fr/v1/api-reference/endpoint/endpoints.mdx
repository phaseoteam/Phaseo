---

La réponse contient trois champs :

- `endpoints` : les ID canoniques des endpoints actuellement exposés par l’API.
- `data` : un enregistrement par endpoint avec `id`, `capability_id`, `public_path`, `collection`, `model_count` et `provider_count`, trié par `public_path`.
- `sample_models` : les 10 premiers ID de modèles visibles du catalogue public.

La réponse est mise en cache pendant 30 minutes.

Utilisez [Lister les capacités des endpoints d’un modèle](./model-endpoints) lorsque vous avez besoin du détail par fournisseur et par paramètre pour un modèle.
