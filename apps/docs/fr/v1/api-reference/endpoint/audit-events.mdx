---

<Note>
Ce point de terminaison nécessite la capacité de gestion `activity:read`. Les utilisateurs OAuth doivent également avoir le rôle de propriétaire ou d’administrateur de l’espace de travail.
</Note>

Les événements ne contiennent que des métadonnées nettoyées. Les identifiants en clair, leurs empreintes, les en-têtes d’autorisation, les listes complètes de portées et les corps de requête ne sont jamais renvoyés.
