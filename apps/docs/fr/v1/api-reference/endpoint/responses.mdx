## Outils serveur

`/v1/responses` prend en charge les outils de fonction classiques ainsi que les outils serveur gérés par le Gateway suivants :

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`
- `phaseo:apply_patch`

### Exemple de date et heure

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "input": [
      { "role": "user", "content": "Give me the current datetime in Asia/Tokyo." }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Asia/Tokyo" }
      }
    ],
    "tool_choice": "auto"
  }'
```

Lorsqu’un outil serveur est utilisé, les compteurs `usage.server_tool_use.*` correspondants sont inclus dans les données d’utilisation.

- `gateway:datetime` -> `datetime_requests`
- `phaseo:web_search` -> `web_search_requests`, `web_search_results`, `web_search_extra_results`
- `phaseo:web_fetch` -> `web_fetch_requests`
- `phaseo:advisor` -> `advisor_requests`
- `phaseo:image_generation` -> `image_generation_requests`
- `phaseo:apply_patch` -> `apply_patch_requests`

## À propos du streaming

`stream: true` est également pris en charge. Avec les outils serveur gérés par le Gateway, Phaseo peut matérialiser le tour d’appel d’outil amont, poursuivre la boucle, puis réémettre un flux synthétique.

## Raisonnement dans les boucles d’outils

Phaseo envoie les requêtes Responses au fournisseur avec `store: false` : le raisonnement d’un modèle ne se poursuit donc d’une étape à l’autre d’une boucle d’outils qu’au moyen des éléments de sortie `reasoning`.

Chaque élément `reasoning` possède un `id`, un `summary` et un `content`. Lorsque le fournisseur renvoie un état de raisonnement, l’élément contient aussi `encrypted_content` :

- Le raisonnement chiffré d’OpenAI, d’Azure OpenAI et de xAI. Phaseo le demande avec `include: ["reasoning.encrypted_content"]` pour les modèles de raisonnement.
- Les signatures de thinking de Claude et le thinking masqué.
- Les signatures de pensée de Gemini, y compris un élément `reasoning` distinct placé juste avant l’appel de fonction auquel une signature appartient.

Les réponses en streaming contiennent les mêmes éléments dans `response.output_item.done` et `response.completed`.

Pour poursuivre une boucle d’outils, renvoyez tous les éléments de sortie dans `input` sans les modifier, y compris les éléments `reasoning`. `encrypted_content` est opaque et enregistre le fournisseur et le modèle qui l’ont produit. Phaseo ne l’envoie qu’à cette famille de fournisseurs et à ce modèle : un fallback vers un autre fournisseur l’abandonne au lieu d’échouer.
