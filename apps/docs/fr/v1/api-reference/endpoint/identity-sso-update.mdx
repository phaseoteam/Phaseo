<Note>La gestion des identités nécessite une identité propriétaire ou administrateur. L’activation de SSO ou de SCIM et la création de jetons de provisionnement nécessitent l’extension d’identité.</Note>

Seul le propriétaire de l’espace de travail peut modifier les paramètres de l’authentification unique, car les connexions via le fournisseur d’identité sont associées aux utilisateurs de l’annuaire de l’espace de travail.
