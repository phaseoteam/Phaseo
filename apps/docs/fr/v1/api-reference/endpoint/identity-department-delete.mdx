<Note>L’administration de l’annuaire d’entreprise nécessite l’extension d’identité, une identité propriétaire ou administrateur et le périmètre de paramètres correspondant.</Note>

Si des correspondances de groupes de l’annuaire utilisent le département, seul le propriétaire de l’espace de travail peut le supprimer, car sa suppression supprime aussi ces correspondances et les rôles qu’elles accordent.
