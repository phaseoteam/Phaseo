description: "Met à jour les métadonnées, le routage ou les filtres d’un identifiant, ou remplace son secret."
---
La fourniture de `key` remplace le secret chiffré. En son absence, le secret existant est conservé. Les listes d’autorisation de modèles et de clés API sont facultatives ; une liste vide autorise tous les modèles ou toutes les clés API de l’espace de travail.
