<Note>Ce point de terminaison nécessite une clé API de gestion avec `presets:write` et une identité utilisateur associée.</Note>

Publiez ou abandonnez les modifications du brouillon local avant d’appliquer une version amont. L’application ne publie pas le brouillon obtenu.
