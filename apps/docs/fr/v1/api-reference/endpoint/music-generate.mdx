Envoyez un `model` et un `prompt` à `POST /v1/music/generate` pour obtenir un morceau de n’importe quel fournisseur de musique avec une seule forme de requête. Phaseo gère pour vous les fournisseurs synchrones et l’interrogation des files d’attente des fournisseurs.

```bash
curl https://api.phaseo.app/v1/music/generate \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax/music-3.0:free",
    "prompt": "Warm jazz trio with brushed drums",
    "format": "mp3"
  }'
```

## Lire le résultat

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "gmicloud",
  "model": "minimax/music-3.0:free",
  "nativeResponseId": "5c30b275-d669-4a25-8151-de6d60214853",
  "audio_url": "https://.../generated-music.mp3",
  "usage": {
    "requests": 1,
    "output_audio_seconds": 25.364
  }
}
```

Une génération terminée contient `audio_url` ou `audio_base64`. `status` vaut `queued`, `in_progress`, `completed` ou `failed`. Tant que l’état n’est pas définitif, interrogez [`GET /v1/music/generate/{music_id}`](./music-status.mdx) avec le même `id`.

`id` est l’ID de requête Phaseo stable. `nativeResponseId` est l’identifiant du fournisseur d’origine, utile pour la corrélation avec le fournisseur et le support. `usage` contient `output_audio_seconds` lorsque le fournisseur indique la durée générée.

## Définir les options Suno

Les modèles Suno acceptent un objet `suno` facultatif :

| Champ | Type | Remarques |
| --- | --- | --- |
| `customMode` | boolean | `false` par défaut |
| `instrumental` | boolean | `false` par défaut |
| `prompt` | string | Remplace le `prompt` de niveau supérieur |
| `style`, `title` | string | Obligatoires lorsque `customMode` vaut `true` |
| `personaId`, `personaModel` | string | |
| `negativeTags` | string | |
| `vocalGender` | `m` ou `f` | |
| `styleWeight`, `weirdnessConstraint`, `audioWeight` | number | De 0 à 1 |

`prompt` est obligatoire lorsque `customMode` vaut `false`, ainsi que lorsque `customMode` vaut `true` avec `instrumental` à `false`.

Une requête qui enfreint une règle du fournisseur renvoie `400` :

```json
{
  "error": "validation_error",
  "reason": "..."
}
```
