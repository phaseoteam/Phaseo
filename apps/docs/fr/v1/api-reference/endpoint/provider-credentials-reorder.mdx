title: "Réorganiser les identifiants du fournisseur"
sidebarTitle: "Réorganiser les identifiants"
badge: "Bêta"
openapi: "/fr/openapi/v1/openapi.localized.yaml POST /byok/reorder"
description: "Remplace l’ordre de priorité des identifiants au sein d’un groupe de routage du fournisseur."
---
Indiquez exactement une fois chaque ID d’identifiant du fournisseur et du groupe de routage sélectionnés. Le premier ID reçoit la priorité la plus élevée. Les ordres partiels ou contenant des doublons sont rejetés.
