Envoyez chaque requête à `https://api.phaseo.app/v1` avec votre clé dans un en-tête `Authorization: Bearer`. Trouvez ci-dessous l’endpoint adapté à votre tâche, puis ouvrez sa page de référence.

## Trouver le bon endpoint

| Pour | Commencez par |
| --- | --- |
| Envoyer votre première requête | [Démarrage rapide](../quickstart) |
| Générer du texte ou utiliser des outils | [`POST /responses`](./endpoint/responses) |
| Prendre des décisions typées | [`POST /decisions`](./endpoint/decisions) |
| Conserver une intégration existante compatible OpenAI | [`POST /chat/completions`](./endpoint/chat-completions) |
| Parcourir les modèles et les fournisseurs | [`GET /models`](./endpoint/models) et [`GET /providers`](./endpoint/providers) |
| Créer de la musique ou gérer des fichiers | [`POST /music/generate`](./endpoint/music-generate) et [`POST /files`](./endpoint/files) |
| Générer une vidéo (Bêta) | [`POST /videos`](./endpoint/video-create) |
| Soumettre un lot ou télécharger les résultats (Bêta) | [`POST /batches`](./endpoint/batches-create) et [`GET /batches/{batch_id}/results`](./endpoint/batches-results) |

## URL de base

```http
https://api.phaseo.app/v1
```

Tous les chemins d’endpoints de cette référence sont relatifs à cette URL de base.

## Authentification

| Identifiant | Format | Appels |
| --- | --- | --- |
| [Clé API Gateway](../developers/authentication.mdx) | `phaseo_v1_sk_<kid>_<secret>` | Endpoints d’inférence |
| [Clé API de gestion](../developers/management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | Endpoints d’administration, dans la limite des autorisations de la clé |

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

En cas d’échec de l’authentification, l’API renvoie `401`.

## Facturation et limites de débit

Les requêtes payantes nécessitent un solde de portefeuille suffisant pour passer une vérification des crédits avant leur exécution. Les modèles dont l’ID se termine par `:free` ne nécessitent pas de crédits déposés. Les requêtes peuvent être limitées par un fournisseur ou par les limites de l’espace de travail et des clés ; consultez [Limites de débit](./limits.mdx).
