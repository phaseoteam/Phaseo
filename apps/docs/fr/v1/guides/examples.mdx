Choisissez un exemple de projet à exécuter localement et à adapter. Pour un seul appel API, utilisez le [Démarrage rapide](../quickstart.mdx) ; pour une fonctionnalité précise, consultez le [Recueil de recettes](../cookbook/index.mdx).

## Projets exécutables

| Réalisation | Guide | Source |
| --- | --- | --- |
| Chat web avec une clé API côté serveur | [Chat Next.js](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| Autorisation OAuth et proxy backend | [Atelier OAuth](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| Une intégration REST minimale | [Application de test Node](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| Une application Python en ligne de commande | [Python CLI](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| Une application utilisant Vercel AI SDK | [Intégration AI SDK](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

Gardez les identifiants sur le serveur, examinez les variables d’environnement de l’exemple et vérifiez le tarif du modèle choisi avant de l’exécuter. Les exemples avec des modèles `:free` ne nécessitent pas de crédits déposés.

## Requêtes par langage

La [référence SDK client](../sdk-reference/typescript/overview.mdx) contient des exemples d’installation et de requêtes par langage. Utilisez la [référence de génération d’images](../api-reference/endpoint/images-generations.mdx) pour les paramètres d’image et [Chat Completions](../api-reference/endpoint/chat-completions.mdx) pour le chat.

Pour qu’un agent de programmation crée la structure d’un projet, utilisez les [prompts de démarrage de mini-applications](../cookbook/mini-app-starter-prompts.mdx) et examinez le code généré avant d’utiliser des identifiants réels.
