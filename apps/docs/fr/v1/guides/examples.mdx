Choisissez un exemple de projet à exécuter localement et à adapter. Pour un seul appel API, utilisez le [Démarrage rapide](../quickstart.mdx) ; pour une fonctionnalité précise, consultez le [Recueil de recettes](../cookbook/index.mdx).

## Projets exécutables

| Ce que vous construisez | Tutoriel | Source |
| --- | --- | --- |
| Un chat dans le navigateur avec une clé API côté serveur | [Chat Next.js](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| Une autorisation OAuth et un proxy backend | [Atelier OAuth](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| Une intégration REST minimale | [Application de test Node](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| Une application en ligne de commande Python | [CLI Python](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| Une application utilisant Vercel AI SDK | [Intégration AI SDK](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

Gardez les identifiants côté serveur, vérifiez les variables d’environnement de l’exemple et consultez les tarifs du modèle sélectionné avant de l’exécuter. Les exemples qui utilisent des modèles `:free` ne nécessitent pas de crédits déposés.

## Requêtes par langage

La [référence du SDK client](../sdk-reference/client/overview.mdx) contient des exemples d’installation et de requêtes par langage. Utilisez la [référence de génération d’images](../api-reference/endpoint/images-generations.mdx) pour les paramètres d’image et [Chat Completions](../api-reference/endpoint/chat-completions.mdx) pour les requêtes de chat.

Pour qu’un agent de code génère la structure d’un projet, utilisez les [prompts de démarrage pour mini-applications](../cookbook/mini-app-starter-prompts.mdx) et relisez le code généré avant de l’utiliser avec de vrais identifiants.
