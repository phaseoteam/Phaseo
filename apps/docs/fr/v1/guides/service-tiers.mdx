Définissez `service_tier` sur une requête texte pour payer une livraison plus rapide (`fast`, `ultrafast`) ou accepter un mode moins cher et moins prioritaire (`flex`). Phaseo ne route alors que vers les fournisseurs qui proposent ce niveau pour le modèle. Le champ fonctionne de la même façon sur `/v1/chat/completions`, `/v1/responses` et `/v1/messages`.

```json
{
  "model": "openai/gpt-5.5",
  "input": "Summarise this incident report.",
  "service_tier": "fast"
}
```

| Niveau | Comment le demander | Usage |
| --- | --- | --- |
| Standard | Rien, ou `"standard"` / `"default"` | Trafic de production général |
| Fast | `"fast"`, ou son alias `"priority"` | L’offre premium ou plus prioritaire du fournisseur |
| Ultrafast | `"ultrafast"` | L’offre la plus rapide |
| Flex | `"flex"` | Une offre moins chère, lorsque le fournisseur en a une |
| Batch | L’[API Batch](../api-reference/endpoint/batches-create.mdx), pas `service_tier` | Grandes charges de travail différées |

Les niveaux ne sont disponibles que pour les modèles texte, et seulement là où le modèle et le fournisseur les prennent en charge. Les pages des modèles affichent les prix par niveau lorsque Phaseo les connaît.

## Que se passe-t-il quand un niveau n’est pas proposé

Phaseo ne conserve que les routes de fournisseur qui proposent le niveau demandé ; il ne se rabat jamais sur un autre niveau. Si aucune route ne le propose, la requête échoue avec `400 unsupported_model_or_endpoint`, motif `service_tier_not_supported`.

D’autres valeurs échouent avec `400 validation_error` :

- `service_tier: "batch"` sur une requête synchrone (mot-clé `batch_service_tier_not_supported`). Utilisez plutôt l’API Batch.
- Toute valeur autre que `standard`, `default`, `fast`, `ultrafast`, `priority`, `flex` ou `batch` (mot-clé `unsupported_service_tier`).

Vous envoyez toujours ces valeurs du Gateway. Phaseo les traduit dans les contrôles propres à chaque fournisseur : une route Anthropic, par exemple, reçoit les champs de niveau d’Anthropic.

## Demander un niveau sur chaque endpoint

<CodeGroup>
```json Responses
{
  "model": "openai/gpt-5.5",
  "input": [
    { "role": "user", "content": "Summarise this incident report." }
  ],
  "service_tier": "flex"
}
```

```json Chat Completions
{
  "model": "openai/gpt-5.5",
  "messages": [
    { "role": "user", "content": "Summarise this incident report." }
  ],
  "service_tier": "flex"
}
```

```json Messages
{
  "model": "anthropic/claude-opus-5.5",
  "max_tokens": 512,
  "messages": [
    { "role": "user", "content": "Summarise this incident report." }
  ],
  "service_tier": "fast"
}
```
</CodeGroup>

Pour `ultrafast`, utilisez un modèle dont la page indique un tarif Ultrafast.

## Mistral Priority et routage UE

Mistral Priority Tier nécessite un compte entreprise Mistral éligible. Phaseo associe `priority` au mode de priorité automatique de Mistral et facture le niveau que Mistral indique : si Mistral se rabat sur Standard, vous payez les prix Standard.

Un prix dans le catalogue ne rend pas un niveau routable. Priority reste désactivé tant que la route Mistral concernée n’annonce pas la prise en charge de Priority, et l’éligibilité dépend toujours du compte et du modèle Mistral.

GLM 5.2 peut être épinglé à l’endpoint régional UE de Mistral avec l’offre de fournisseur `mistral-eu` :

```json
{
  "model": "z-ai/glm-5.2",
  "messages": [
    { "role": "user", "content": "Summarise this incident report." }
  ],
  "service_tier": "priority",
  "provider": {
    "only": ["mistral-eu"],
    "required_execution_region": "eu"
  }
}
```

L’inférence régionale Mistral coûte 10 % de plus. Le tarif Batch n’est disponible que sur l’offre Mistral globale, via l’API Batch ; Mistral ne prend pas en charge Batch sur les endpoints régionaux.

La référence complète des champs se trouve dans [Paramètres](../api-reference/parameters.mdx) ; pour la combinaison des niveaux avec l’ordre des fournisseurs et les solutions de repli, consultez [Routage et solutions de repli](./routing-and-fallbacks.mdx).
