icon: "waypoints"
title: "Modèles d’appel d’outils"
description: "Boucles d’appel d’outils fiables pour les points de terminaison chat completions et responses."
---

Après que le modèle a appelé un outil, envoyez une requête de suivi qui reprend la conversation, l’appel du modèle et le résultat de votre outil. Le modèle écrit alors sa réponse, ou appelle un autre outil et vous recommencez. Utilisez le point de terminaison dont votre application utilise déjà le format de messages : `/v1/chat/completions` pour les boucles de messages de type OpenAI, `/v1/responses` pour l’API Responses, `/v1/messages` pour les applications natives Anthropic.

<Tabs>
<Tab title="Chat Completions">

Quand `finish_reason` vaut `tool_calls`, exécutez chaque appel, puis envoyez le message de l’assistant tel quel, suivi d’un message `role: "tool"` par appel, associé par `tool_call_id`. Renvoyez aussi `tools`.

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "What is the weather in Seattle?" },
    {
      "role": "assistant",
      "content": null,
      "tool_calls": [
        {
          "id": "call_123",
          "type": "function",
          "function": {
            "name": "get_weather",
            "arguments": "{\"city\":\"Seattle\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_123",
      "content": "72F and sunny"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    }
  ]
}
```

</Tab>
<Tab title="Responses">

Les appels arrivent sous forme d’éléments de sortie de type `function_call`. Renvoyez l’élément d’appel en entrée, suivi d’un élément `function_call_output` avec le même `call_id`.

```json
{
  "model": "openai/gpt-6-astra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [{ "type": "input_text", "text": "What's the weather in Seattle?" }]
    },
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Seattle\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "72F and sunny"
    }
  ]
}
```

</Tab>
</Tabs>

Avant d’exécuter un appel, validez ses arguments ; consultez [Sécurité et validation des appels d’outils](./tool-calling-safety).
