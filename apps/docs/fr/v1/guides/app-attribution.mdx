Envoyez un en-tête `X-App-Id` avec chaque requête pour regrouper son utilisation sous une même application dans les analyses d’applications et les audits de requêtes. Utilisez un ID différent pour chaque produit, environnement ou expérience destinée aux clients dont vous voulez suivre les données séparément. L’attribution ne modifie jamais la réponse d’inférence.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-App-Id: acme-support" \
  -H "X-App-Name: Acme Support" \
  -H "HTTP-Referer: https://acme.example/support" \
  -H "X-App-Categories: chat,productivity" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Summarize this ticket."
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const phaseo = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY,
  app: {
    id: "acme-support",
    name: "Acme Support",
    url: "https://acme.example/support",
    categories: ["chat", "productivity"],
  },
});

const response = await phaseo.generateResponse({
  model: "openai/gpt-6-astra",
  input: "Summarize this ticket.",
});
```
</CodeGroup>

L’option `app` du SDK TypeScript envoie les mêmes en-têtes avec chaque requête. Phaseo ne définit jamais l’attribution à votre place.

## En-têtes

| En-tête | Rôle |
| --- | --- |
| `X-App-Id` | Identifiant stable choisi par votre application. |
| `X-App-Name` | Nom lisible affiché dans les vues des applications et de l’utilisation. |
| `HTTP-Referer` | URL publique de la page ou du déploiement associée à l’application. |
| `X-App-Categories` | Liste de trois catégories au maximum, séparées par des virgules. |
| `X-Title` | Alias de compatibilité pour un nom d’application lisible. |

Phaseo identifie l’application par son URL `HTTP-Referer` lorsque vous en envoyez une, et par `X-App-Id` sinon. Gardez les deux stables : une nouvelle URL ou un nouvel ID crée une nouvelle application dans les analyses.

`HTTP-Referer` n’a pas besoin de correspondre à l’en-tête `Referer` automatique du navigateur. Définissez-le explicitement dans les intégrations côté serveur lorsque vous voulez une URL d’application canonique unique.

## Catégories

Choisissez jusqu’à trois valeurs parmi `chat`, `developer-tools`, `research`, `productivity`, `education`, `commerce`, `media`, `finance` et `other`.

Les valeurs ne sont pas sensibles à la casse. Phaseo ignore les valeurs inconnues, supprime les doublons et conserve les trois premières catégories valides. Les catégories envoyées dans des requêtes ultérieures s’ajoutent à celles déjà enregistrées pour l’application ; elles ne retirent jamais les catégories choisies dans le tableau de bord.

Pour gérer les catégories de façon centralisée plutôt que dans le code de l’application, modifiez-les dans **Paramètres → Applications**.

## Garder une attribution partageable sans risque

- Ne placez pas d’ID client, d’adresse e-mail ou d’autres données personnelles dans les en-têtes d’attribution.
- Considérez l’URL et le nom comme publics : ils peuvent apparaître dans des vues d’applications partagées ou publiques.
