title: "Outil serveur Datetime"
description: "Donnez aux modèles la date et l’heure actuelles dans un ou plusieurs fuseaux horaires."
---

Ajoutez `phaseo:datetime` pour que le modèle puisse consulter la date et l’heure actuelles lorsqu’un prompt en dépend, par exemple « quel jour sommes-nous à Tokyo ? ». Le modèle décide quand l’appeler ; Phaseo renvoie l’heure dans chacun des fuseaux horaires que vous avez listés.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What day of the week is it in Tokyo?" }
    ],
    "tools": [
      {
        "type": "phaseo:datetime",
        "parameters": { "timezones": ["Asia/Tokyo", "UTC"] }
      }
    ]
  }'
```

## Paramètres

| Paramètre | Type | Défaut | Description |
| --- | --- | --- | --- |
| `timezones` | string[] | `["UTC"]` | Jusqu’à 5 noms de fuseaux horaires IANA, par exemple `["Europe/London", "UTC"]`. |

Plus de 5 fuseaux horaires, ou un nom qui n’est pas un fuseau horaire IANA valide, entraîne le refus de la requête avant l’exécution du modèle. L’ancien nom de type `gateway:datetime` est toujours accepté.

## Ce que renvoie l’outil

Une entrée par fuseau horaire :

```json
{
  "timezones": [
    { "timezone": "Europe/London", "datetime": "2026-07-03T10:00:00.123+01:00" },
    { "timezone": "UTC", "datetime": "2026-07-03T09:00:00.123+00:00" }
  ]
}
```

## Utilisation et tarification

Chaque appel ajoute 1 à `usage.server_tool_use.datetime_requests`. Datetime n’a pas de compteur de prix propre.
