Ajoutez `phaseo:image_generation` pour que le modèle puisse créer une image pendant qu’il répond. Le modèle rédige le prompt de l’image ; Phaseo appelle le modèle d’image et renvoie l’image dans la boucle du modèle.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Design a wide product concept image for a compact desktop synthesizer.",
    "tools": [
      {
        "type": "phaseo:image_generation",
        "parameters": {
          "model": "openai/gpt-image-2",
          "quality": "high",
          "aspect_ratio": "16:9",
          "output_format": "png"
        }
      }
    ]
  }'
```

## Paramètres

Tous les paramètres sont facultatifs.

| Paramètre | Type | Défaut | Description |
| --- | --- | --- | --- |
| `model` | string | `openai/gpt-image-2` | Modèle d’image. Défini ici, il remplace tout modèle demandé par le modèle principal. |
| `quality` | string | Défaut du fournisseur | Indication de qualité, par exemple `low`, `medium` ou `high`. |
| `size` | string | Défaut du fournisseur | Indication de taille d’image. |
| `aspect_ratio` | string | Défaut du fournisseur | Format d’image, par exemple `1:1`, `16:9` ou `9:16`. |
| `background` | string | Défaut du fournisseur | Indication de mode d’arrière-plan. |
| `output_format` | string | Défaut du fournisseur | `png`, `jpeg` ou `webp`. |
| `output_compression` | integer | Défaut du fournisseur | Indication de compression, ramenée entre `0` et `100`. |
| `moderation` | string | Défaut du fournisseur | Indication de modération pour le fournisseur. |

## Ce que le modèle envoie

Un `prompt` (ou `description`, traité de la même façon). Il peut aussi envoyer `model`, utilisé uniquement si l’outil n’en définit pas, ainsi que n’importe lequel des autres paramètres ci-dessus, qui remplacent alors les valeurs de l’outil pour cet appel.

## Ce que renvoie l’outil

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "imageUrl": "https://...",
  "mime_type": "image/png"
}
```

Certains fournisseurs renvoient `b64_json` avec les données de l’image en base64 au lieu de `imageUrl`. Si l’appel n’a pas de prompt, le modèle reçoit `image_generation_invalid_request` ; si le modèle d’image échoue, `image_generation_failed`.

## Utilisation et tarification

Chaque image ajoute 1 à `usage.server_tool_use.image_generation_requests` et peut être facturée via `server_tool_image_generation_requests`. Lorsque le modèle d’image indique une utilisation de tokens, celle-ci s’ajoute à l’utilisation de la requête et est facturée au tarif normal de ce modèle.
