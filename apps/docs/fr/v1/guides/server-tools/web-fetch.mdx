Ajoutez `phaseo:web_fetch` pour que le modèle puisse lire une URL connue, par exemple une page de documentation, un article ou un journal des modifications. Le modèle fournit l’`url` ; Phaseo récupère la page et renvoie son texte, tronqué à une taille limite, et le modèle peut récupérer d’autres pages avant de répondre.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Summarize https://phaseo.app/docs/v1/guides/tool-calling" }
    ],
    "tools": [
      { "type": "phaseo:web_fetch" }
    ]
  }'
```

<span id="parameters"></span>
## Paramètres

```json
{
  "type": "phaseo:web_fetch",
  "parameters": {
    "engine": "direct",
    "max_chars": 12000,
    "allowed_domains": ["phaseo.app"],
    "blocked_domains": ["internal.example.com"]
  }
}
```

| Paramètre | Type | Valeur par défaut | Description |
| --- | --- | --- | --- |
| `engine` | string | `direct` | `auto`, `native`, `direct`, `exa`, `parallel`, `firecrawl` ou `deepseek`. Voir [Choisir un moteur](#choose-an-engine). |
| `max_chars` | integer | `12000` | Nombre de caractères de texte de la page renvoyés au modèle, jusqu’à `100000`. |
| `max_content_tokens` | integer | Aucune | Utilisé à la place de `max_chars` lorsque `max_chars` est omis. C’est aussi la taille limite pour `native`. |
| `max_uses` | integer | `10` | Appels de récupération par requête, jusqu’à `100`. |
| `allowed_domains` | string[] | Aucune | Récupère uniquement depuis ces domaines. Le modèle peut restreindre cette liste dans un appel, mais pas l’élargir. |
| `blocked_domains` | string[] | Aucune | Ne récupère jamais depuis ces domaines. Alias : `excluded_domains`. |

## Ce que le modèle envoie

Chaque appel contient une `url`. Le modèle peut aussi envoyer `engine`, `max_chars`, `max_content_tokens` et les listes de domaines.

<span id="choose-an-engine"></span>
## Choisir un moteur

| Moteur | Ce qui s’exécute |
| --- | --- |
| `auto` | La récupération native d’Anthropic sur `/v1/messages`. Sur les autres endpoints, Exa s’il est activé, sinon `direct`. |
| `direct` | Phaseo récupère la page lui-même et réduit le HTML à du texte brut. |
| `exa` | Extraction de contenu Exa. |
| `parallel` | Parallel Extract. |
| `firecrawl` | Firecrawl Scrape. |
| `deepseek` | DeepSeek Fetch, qui renvoie la page en Markdown. |
| `native` | L’outil `web_fetch_20260209` d’Anthropic, sur `/v1/messages` uniquement. Sur les autres endpoints, la requête est rejetée ; utilisez `direct` ou un moteur géré. |

Si un moteur géré n’est pas activé, l’appel renvoie `fetch_not_configured` au modèle.

Seules les URL HTTP(S) fonctionnent. `direct` n’accepte que les types de contenu textuels, comme le HTML, le texte brut et le JSON, et renvoie `unsupported_content_type` pour tout le reste. Il suit jusqu’à 5 redirections et vérifie chacune d’elles par rapport à vos listes de domaines.

### Récupération native d’Anthropic

```json
{
  "model": "anthropic/claude-sonnet-4.6",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "Read the docs page and summarize the limits." }
  ],
  "tools": [
    {
      "type": "phaseo:web_fetch",
      "parameters": {
        "engine": "native",
        "max_content_tokens": 9000,
        "allowed_domains": ["phaseo.app"]
      }
    }
  ],
  "tool_choice": { "type": "tool", "name": "phaseo:web_fetch" }
}
```

## Ce que l’outil renvoie

```json
{
  "provider": "fetch",
  "engine": "direct",
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "text": "...",
  "truncated": false,
  "returned_chars": 8421
}
```

Vérifiez `truncated` avant de supposer que le modèle a vu la page entière. Pour un exemple complet, consultez [Ancrer les réponses avec Web Fetch](../../cookbook/tool-grounding-with-web-fetch).

## Utilisation et tarification

Chaque récupération ajoute 1 à `usage.server_tool_use.web_fetch_requests`. Phaseo facture chaque récupération gérée via Exa, Parallel, Firecrawl ou DeepSeek $0.001, sauf si la fiche tarifaire du modèle définit son propre prix pour `server_tool_web_fetch_requests` ; les récupérations directes sont gratuites. Les récupérations via des moteurs payants nécessitent du crédit même lorsque le modèle est gratuit. La récupération native est facturée avec `native_web_fetch_requests` lorsque la fiche tarifaire du modèle la définit.
