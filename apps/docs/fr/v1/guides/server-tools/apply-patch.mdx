Ajoutez `phaseo:apply_patch` sur `/v1/responses` pour recevoir les modifications de fichiers sous forme d’opérations de patch structurées. Phaseo vérifie la forme de chaque opération et la renvoie ; il ne touche jamais à vos fichiers. Votre application décide d’appliquer le patch, de le montrer à un utilisateur, de le refuser ou de demander une révision.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Create a small README patch for this project.",
    "tools": [
      { "type": "phaseo:apply_patch" }
    ]
  }'
```

Sur `/v1/chat/completions` ou `/v1/messages`, la requête est refusée.

## Paramètres

Aucun. Ajoutez `{ "type": "phaseo:apply_patch" }` tel quel.

## Ce que le modèle envoie

Un objet `operation` :

```json
{
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  }
}
```

| `type` | Champs requis | Règles du diff |
| --- | --- | --- |
| `create_file` | `path`, `diff` | Chaque ligne non vide commence par `+` |
| `update_file` | `path`, `diff` | Chaque ligne non vide commence par `@@`, une espace, `+` ou `-` |
| `delete_file` | `path` | Aucune |

`path` ne peut pas contenir d’octets nuls.

## Ce que renvoie l’outil

```json
{
  "status": "completed",
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  },
  "message": "Patch operation validated. The client must apply or reject this patch and report the result."
}
```

Une opération qui enfreint les règles ci-dessus renvoie `apply_patch_invalid_operation` avec la raison, pour que le modèle puisse réessayer.

## Utilisation et tarification

Chaque appel ajoute 1 à `usage.server_tool_use.apply_patch_requests` et peut être facturé via `server_tool_apply_patch_requests`.
