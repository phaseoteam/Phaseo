Ajoutez `phaseo:web_search` pour que le modèle puisse rechercher sur le Web lorsqu’il a besoin d’informations récentes ou appuyées par des sources. Le modèle rédige la requête de recherche et peut chercher plusieurs fois au cours d’une même requête ; Phaseo renvoie des URL, des titres, des extraits, des passages mis en évidence et, en option, le texte des pages, et le modèle rédige une réponse étayée.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What were the major AI announcements this week?" }
    ],
    "tools": [
      { "type": "phaseo:web_search" }
    ]
  }'
```

La même entrée d’outil fonctionne dans `tools` sur `/v1/responses` et `/v1/messages`.

<span id="parameters"></span>
## Paramètres

```json
{
  "type": "phaseo:web_search",
  "parameters": {
    "engine": "exa",
    "max_results": 5,
    "max_total_results": 15,
    "search_context_size": "medium",
    "max_characters": 2048,
    "allowed_domains": ["arxiv.org", "nature.com"],
    "include_highlights": true,
    "include_text": false
  }
}
```

| Paramètre | Type | Valeur par défaut | Description |
| --- | --- | --- | --- |
| `engine` | string | `exa` | `auto`, `native`, `exa`, `parallel`, `firecrawl`, `perplexity`, `tinyfish` ou `deepseek`. Voir [Choisir un moteur](#choose-an-engine). |
| `mode` | string | Valeur par défaut du moteur | Façon dont le moteur cherche : plus vite, plus en profondeur ou avec une exécution de recherche approfondie. Voir [Choisir un mode](#choose-a-mode). |
| `max_results` | integer | `5` | Résultats par appel de recherche, jusqu’à `25`. |
| `max_total_results` | integer | `25` | Résultats sur l’ensemble des recherches de la requête, jusqu’à `100`. Jamais inférieur à `max_results`. |
| `max_uses` | integer | `10` | Appels de recherche par requête, jusqu’à `100`. |
| `search_context_size` | string | `medium` | `low`, `medium` ou `high`, pour les moteurs qui dimensionnent les passages mis en évidence. |
| `max_characters` | integer | Valeur du moteur | Caractères de texte par résultat lorsque le texte est inclus. |
| `allowed_domains` | string[] | Aucune | Recherche uniquement dans ces domaines. Alias : `include_domains`. |
| `excluded_domains` | string[] | Aucune | Exclut ces domaines. Alias : `exclude_domains`. |
| `include_highlights` | boolean | `true` | Inclut les passages mis en évidence ou les extraits du moteur. |
| `include_text` | boolean | `false` | Inclut un texte de page plus complet lorsque le moteur le permet. |
| `user_location` | object | Aucune | Indication de localisation. Lorsque `engine` vaut `native`, elle est transmise à la recherche propre du fournisseur ; sinon, la recherche de Phaseo l’utilise lorsque l’appel du modèle n’indique pas de localisation. |

## Ce que le modèle envoie

Chaque appel contient une `query`. Le modèle peut aussi envoyer `max_results`, `engine`, `search_context_size`, les listes de domaines, `include_text`, `include_highlights`, `max_characters` et ces indications de localisation :

| Argument | Description |
| --- | --- |
| `user_location` | Localisation approximative. Exa et Perplexity utilisent `user_location.country` (un code à deux lettres comme `GB`) pour la recherche régionale ; TinyFish utilise le pays et la langue. |
| `language` | Code de langue des résultats, par exemple `en`, pour les moteurs qui localisent. DeepSeek l’ajoute à la requête sous forme de filtre `lang:`. |
| `page` | Page de résultats de `0` à `10`, pour TinyFish. |

Les valeurs envoyées par le modèle remplacent les valeurs par défaut de l’outil pour cet appel. `max_results` reste plafonné par ce qu’il reste de `max_total_results` ; une fois ce total épuisé, les appels suivants renvoient `max_total_results_reached`.

<span id="choose-an-engine"></span>
## Choisir un moteur

| Moteur | Ce qui s’exécute |
| --- | --- |
| `exa` | Recherche Exa gérée. Valeur par défaut. |
| `auto` | Le moteur géré par défaut, actuellement Exa. |
| `parallel` | Recherche Parallel gérée. |
| `firecrawl` | Recherche Firecrawl gérée. |
| `perplexity` | L’API Perplexity Search : résultats classés, `search_context_size` et recherche régionale à partir de `user_location.country`. |
| `tinyfish` | TinyFish Search : résultats classés, localisés et paginés. Il renvoie des extraits, pas le texte complet des pages ; utilisez [`phaseo:web_fetch`](./web-fetch) lorsque le modèle a besoin de plus. |
| `deepseek` | DeepSeek Search : résultats classés avec un résumé de chaque page, rédigé pour être lu par le modèle. |
| `native` | L’outil de recherche Web propre au fournisseur, comme `web_search_preview` d’OpenAI, `web_search_20250305` d’Anthropic ou `deepseek_web_search` de DeepSeek. |

Si un moteur géré n’est pas activé, l’appel renvoie `search_not_configured` au modèle.

Avec `engine: "native"` sur `/v1/chat/completions` ou `/v1/responses`, la requête n’est envoyée qu’aux fournisseurs qui exécutent eux-mêmes la recherche Web. Si aucun ne sert le modèle, Phaseo exécute à la place son moteur par défaut et le facture comme une recherche gérée.

Les fournisseurs qui exécutent eux-mêmes la recherche Web sur ces endpoints sont OpenAI, les déploiements Azure OpenAI sur `/v1/responses`, xAI et DeepSeek sur `deepseek/deepseek-v4.1-flash-1017`. DeepSeek ne recherche par lui-même que lorsque la recherche Web est le seul outil de la requête, sans listes de domaines ni position de l’utilisateur, sans sortie JSON et sans `tool_choice` forcé. Son API rejette les listes de domaines, la position et la sortie JSON, désactive sa recherche Web lorsque la requête contient d’autres outils et ne peut pas forcer une recherche. Les autres requêtes vers ce modèle utilisent à la place la recherche de Phaseo, qui fonctionne avec vos propres outils. Lorsque le raisonnement est activé, DeepSeek lance une recherche plus approfondie qui ouvre et lit des pages en plusieurs étapes.

Les outils de recherche des fournisseurs ne peuvent pas appliquer `max_results` ni `max_total_results`, et seul celui de Claude applique `max_uses`. Une recherche native qui fixe une limite que son fournisseur ne peut pas appliquer passe par le moteur par défaut de Phaseo et est facturée comme recherche gérée.

Envoyer l’outil propre à OpenAI `{ "type": "web_search" }` fonctionne comme `engine: "native"`. Définissez `native` uniquement dans la définition de l’outil : si le modèle demande `native` dans un appel, l’appel renvoie `unsupported_search_engine`, car l’outil du fournisseur doit être choisi avant l’envoi de la requête.

<span id="choose-a-mode"></span>
## Choisir un mode

Définissez `mode` sur l’outil pour choisir comment son moteur cherche. Le modèle ne peut pas le modifier : un appel ne coûte donc jamais plus que le mode choisi. Si le modèle passe à un autre moteur, celui-ci s’exécute dans son mode par défaut. Un mode que le moteur ne propose pas renvoie une 400.

| Moteur | `mode` | Ce qui s’exécute | Prix par appel |
| --- | --- | --- | --- |
| `exa` | `lite` | Recherche à faible latence pour le chat et la voix | $0.004 |
| `exa` | `auto` (par défaut) | Recherche équilibrée | $0.007 |
| `exa` | `deep-lite` | Recherche légère en plusieurs étapes, environ 4 secondes | $0.012 |
| `exa` | `deep` | Recherche en plusieurs étapes avec une `answer` synthétisée, de 4 à 15 secondes | $0.012 |
| `exa` | `agent-minimal` | Une exécution de recherche Exa Agent à effort minimal | $0.012 |
| `exa` | `agent-low` | Une exécution de recherche Exa Agent à effort faible | $0.025 |
| `parallel` | `turbo`, `fast` | La recherche la plus rapide de Parallel | $0.001 |
| `parallel` | `basic`, `advanced` (par défaut) | La recherche de meilleure qualité de Parallel | $0.005 |
| `parallel` | `task-lite` | Une exécution de recherche Parallel Task, de 10 à 60 secondes | $0.005 |
| `parallel` | `task-base` | Une exécution de recherche Parallel Task, de 15 à 100 secondes | $0.010 |
| `perplexity` | `standard` (par défaut) | Perplexity Search | $0.005 |
| `perplexity` | `fast` | Perplexity Fast Search | $0.001 |

Les recherches Exa et Parallel coûtent aussi $0.001 par résultat au-delà des 10 premiers, et Exa facture $0.001 par page pour chaque type de contenu renvoyé : extraits et texte sur 5 résultats ajoutent donc $0.010. `firecrawl`, `tinyfish` et `deepseek` n’ont pas de modes.

Les modes de recherche approfondie renvoient une `answer` et les pages qu’elle cite dans `results`. Une exécution qui n’est pas terminée après 120 secondes renvoie `research_timeout`. Les exécutions qui expirent, échouent ou perdent leur client ne sont pas facturées. Les modes de recherche approfondie ne peuvent pas être limités à des domaines : un outil de recherche avec `allowed_domains` ou `excluded_domains` renvoie une erreur 400. Le moteur `native` n’a pas de mode.

## Filtrer par domaine

Utilisez `allowed_domains` lorsque la réponse doit provenir d’un ensemble fixe de sources, et `excluded_domains` pour écarter certains sites d’une recherche autrement ouverte.

```json
{
  "type": "phaseo:web_search",
  "parameters": { "allowed_domains": ["phaseo.app", "github.com"] }
}
```

Les moteurs traitent ces listes différemment :

- **Perplexity** accepte l’une ou l’autre liste, pas les deux, et jusqu’à 20 domaines. Les domaines exclus sont envoyés dans son format de liste de refus.
- **Firecrawl** accepte l’une ou l’autre liste, pas les deux.
- **TinyFish** accepte les deux et les convertit en opérateurs `site:` et `-site:` dans la requête de recherche.
- **DeepSeek** accepte les deux et les convertit en opérateurs `site:` et `-site:`. Ses requêtes sont limitées à 128 caractères : la requête est donc raccourcie pour laisser de la place aux opérateurs. Si les listes de domaines dépassent à elles seules la limite, l’appel renvoie `search_query_too_long`.

## Ce que l’outil renvoie

Un résultat JSON avec le moteur, la requête de recherche et un tableau `results`. Chaque résultat contient un `title`, une `url`, un `snippet` ou des `highlights`, et `text` lorsque le texte de la page a été demandé et que le moteur le fournit.

## Utilisation et tarification

Chaque recherche s’ajoute à `usage.server_tool_use` :

```json
{
  "usage": {
    "server_tool_use": {
      "web_search_requests": 1,
      "web_search_results": 5,
      "web_search_extra_results": 0
    }
  }
}
```

Phaseo facture les recherches sur Exa, Parallel, Perplexity et DeepSeek au prix que chaque moteur facture à Phaseo : les prix de [Choisir un mode](#choose-a-mode), et $0.00075 pour une recherche DeepSeek, facturée uniquement si elle renvoie des résultats. Pour Exa, le montant est le coût qu’Exa indique pour l’appel, ou son prix catalogue quand Exa n’en indique aucun. Chaque montant est une ligne dans les `pricing_lines` de la requête, avec son `engine`, son `mode` et son `price_source`. Les recherches Firecrawl sont facturées $0.007, plus $0.001 par résultat au-delà des 10 premiers. Les recherches qui échouent ne sont pas facturées, et TinyFish Search est gratuit sur ses offres publiées : `engine: "tinyfish"` n’ajoute donc aucun coût de recherche. Les recherches sur des moteurs payants nécessitent du crédit même lorsque le modèle est gratuit. La recherche native est facturée avec `native_web_search_requests` au prix publié par le fournisseur : par exemple $10 pour 1,000 recherches chez OpenAI et Anthropic, et $0.75 pour 1,000 chez DeepSeek, où seules les recherches qui renvoient des résultats comptent. DeepSeek facture aussi chaque récupération de page, où il lit une URL avec son outil de lecture de liens, à $0.75 pour 1,000, sous la forme de `native_web_fetch_requests`. Lorsque le raisonnement est activé, une seule réponse de DeepSeek peut lancer une douzaine de recherches ou plus, et les résultats qu’il lit s’ajoutent aux tokens d’entrée.
