Ajoutez `phaseo:subagent` pour que le modèle principal puisse confier une tâche autonome à un modèle exécutant, souvent plus petit ou plus rapide, dans la même requête. Le modèle principal décrit la tâche ; Phaseo exécute le modèle exécutant et renvoie son résultat, puis le modèle principal termine la réponse.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5",
    "messages": [
      { "role": "user", "content": "Compare these release notes and summarize the breaking changes." }
    ],
    "tools": [
      {
        "type": "phaseo:subagent",
        "parameters": {
          "model": "openai/gpt-6-astra",
          "instructions": "Return concise findings for the main model. Do not address the end user directly.",
          "max_uses": 3,
          "max_completion_tokens": 1200
        }
      }
    ]
  }'
```

## Paramètres

| Paramètre | Type | Défaut | Description |
| --- | --- | --- | --- |
| `model` | string | Le modèle de la requête | Le modèle exécutant. |
| `instructions` | string | Instructions intégrées de l’exécutant | Instructions supplémentaires pour l’exécutant. |
| `max_uses` | integer | `1` | Nombre d’appels Subagent par requête. |
| `max_completion_tokens` | integer | `1400` | Tokens de sortie pour chaque réponse de l’exécutant. Les valeurs inférieures à `1024` sont relevées à `1024`. `max_tokens` est accepté comme ancien alias. |
| `reasoning` | object | Défaut du fournisseur | Réglages de raisonnement, transmis lorsque le modèle exécutant les prend en charge. |
| `temperature` | number | Défaut du fournisseur | Température d’échantillonnage de l’appel à l’exécutant. |

L’exécutant ne reçoit jamais la conversation : mettez dans la tâche tout ce dont il a besoin.

## Ce que le modèle envoie

Un `task_description` contenant la tâche complète, le contexte et le résultat attendu, ainsi qu’un `task_name` court facultatif :

```json
{
  "task_description": "Extract the three highest-risk migration steps from the supplied plan."
}
```

`task`, `prompt` ou `input` sont acceptés à la place de `task_description`.

## Ce que renvoie l’outil

```json
{
  "status": "ok",
  "model": "openai/gpt-6-astra",
  "outcome": "The highest-risk steps are schema migration, traffic cutover, and rollback verification."
}
```

Si l’appel ne peut pas s’exécuter, le modèle reçoit `subagent_invalid_request` (pas de tâche), `subagent_max_uses_exceeded` ou `subagent_request_failed`.

## Utilisation et tarification

Chaque appel ajoute 1 à `usage.server_tool_use.subagent_requests` et peut être facturé via `server_tool_subagent_requests`. Les tokens de l’exécutant s’ajoutent à l’utilisation de la requête et sont facturés au tarif du modèle exécutant. Pour obtenir une relecture plutôt que déléguer du travail, utilisez [Advisor](./advisor).
