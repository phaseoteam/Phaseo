Ajoutez `phaseo:advisor` pour que le modèle principal puisse demander à un second modèle une relecture, un plan, une vérification de cohérence ou l’avis d’un spécialiste avant de répondre. Le modèle principal appelle l’Advisor comme n’importe quel outil ; Phaseo exécute le modèle Advisor et renvoie son avis comme résultat de l’outil.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Design a rate limiter for a distributed API gateway." }
    ],
    "tools": [
      {
        "type": "phaseo:advisor",
        "parameters": {
          "model": "anthropic/claude-opus-5",
          "max_uses": 1,
          "max_completion_tokens": 1400
        }
      }
    ]
  }'
```

Advisor fonctionne avec tout modèle texte pris en charge. Phaseo l’exécute lui-même ; il n’est converti en outil Advisor natif d’Anthropic que si vous envoyez la forme d’outil native d’Anthropic.

## Paramètres

```json
{
  "type": "phaseo:advisor",
  "parameters": {
    "name": "reviewer",
    "model": "anthropic/claude-opus-5",
    "instructions": "Review plans for correctness, missing edge cases, and implementation risk.",
    "forward_transcript": true,
    "max_uses": 2,
    "max_completion_tokens": 1400,
    "reasoning": { "effort": "high" },
    "temperature": 0.2
  }
}
```

| Paramètre | Type | Défaut | Description |
| --- | --- | --- | --- |
| `name` | string | Aucun | De 1 à 64 lettres, chiffres, espaces, traits de soulignement ou tirets. Requis lorsque vous ajoutez plusieurs Advisors. |
| `model` | string | Voir ci-dessous | Le modèle Advisor. |
| `instructions` | string | Instructions intégrées de l’Advisor | Instructions supplémentaires pour l’Advisor. |
| `forward_transcript` | boolean | `false` | Envoie la conversation en cours à l’Advisor. |
| `max_uses` | integer | `1` | Nombre d’appels à cet Advisor par requête. |
| `max_completion_tokens` | integer | `1400` | Tokens de sortie pour chaque réponse de l’Advisor. Les valeurs inférieures à `1024` sont relevées à `1024`. `max_tokens` est accepté comme ancien alias. |
| `reasoning` | object | Défaut du fournisseur | Réglages de raisonnement, transmis lorsque le modèle Advisor les prend en charge. |
| `temperature` | number | Défaut du fournisseur | Température d’échantillonnage de l’appel à l’Advisor. |

Le modèle Advisor est `parameters.model` s’il est défini ; sinon le `model` que le modèle principal envoie dans son appel ; sinon le modèle de la requête elle-même.

## Ce que le modèle envoie

En général un `prompt`. Si l’outil n’impose pas de modèle, l’appel peut aussi en choisir un :

```json
{
  "model": "anthropic/claude-opus-5",
  "prompt": "Check this security design for missing controls."
}
```

Avec `forward_transcript: true`, le modèle peut appeler l’Advisor sans prompt, et l’Advisor examine la conversation transmise.

## Ajouter plusieurs Advisors

Ajoutez une entrée `phaseo:advisor` par Advisor. Chaque Advisor nommé devient un outil distinct pour le modèle, par exemple `phaseo_advisor_security_reviewer`.

```json
{
  "tools": [
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "security-reviewer",
        "model": "anthropic/claude-opus-5",
        "instructions": "Review for vulnerabilities, abuse cases, and missing mitigations."
      }
    },
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "architect",
        "model": "openai/gpt-5",
        "instructions": "Review system design tradeoffs and operational risks."
      }
    }
  ]
}
```

Les noms doivent être uniques après suppression des espaces aux extrémités, sans tenir compte de la casse, et une seule entrée au plus peut omettre `name` ; sinon la requête est refusée. Avec plusieurs Advisors, `tool_choice: "phaseo:advisor"` force le premier.

## Ce que renvoie l’outil

```json
{
  "status": "ok",
  "name": "reviewer",
  "model": "anthropic/claude-opus-5",
  "advice": "Start with a smaller migration slice and define rollback criteria before changing traffic routing."
}
```

Si l’appel ne peut pas s’exécuter, le modèle reçoit à la place un résultat d’erreur : `advisor_invalid_request` (pas de prompt ou pas de modèle), `advisor_max_uses_exceeded` ou `advisor_request_failed`.

L’Advisor ne conserve aucun état entre les requêtes. Si vous rejouez des messages et des résultats d’outils antérieurs, le modèle principal voit les avis précédents ; l’Advisor ne voit la conversation que lorsque `forward_transcript` est activé. Les avis ne sont pas diffusés en streaming, et l’Advisor ne peut pas appeler d’outils lui-même.

## Utilisation et tarification

Chaque appel ajoute 1 à `usage.server_tool_use.advisor_requests` et peut être facturé avec `server_tool_advisor_requests`. Les jetons de l’Advisor sont facturés aux tarifs du modèle Advisor lui-même, sur une ligne distincte de la facture de la requête, et ne s’ajoutent pas aux jetons du modèle appelant. Un modèle Advisor payant nécessite du crédit même lorsque le modèle appelant est gratuit.
