Appliquez ces pratiques lors du passage du prototype à la production.

## Liste de contrôle de fiabilité

- Configurez des délais d’attente et des contrôles d’annulation côté client.
- Gérez les statuts `429` et `5xx` avec un délai de reprise exponentiel.
- Considérez les flux interrompus comme pouvant faire l’objet d’une nouvelle tentative.
- Si la justesse est importante, ne stockez le texte partiel qu’une fois la réponse terminée.

## Exemple d’annulation dans un navigateur ou avec Node

```typescript
const controller = new AbortController();
const timeout = setTimeout(() => controller.abort(), 30_000);

try {
  const response = await fetch("https://api.phaseo.app/v1/chat/completions", {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "openai/gpt-5-nano",
      messages: [{ role: "user", content: "Stream a short summary." }],
      stream: true,
    }),
    signal: controller.signal,
  });
  // Parse SSE frames from response.body here.
} finally {
  clearTimeout(timeout);
}
```

## Conseils pour l’interface

- Affichez progressivement les fragments de tokens.
- Affichez clairement l’état « génération terminée » à la réception de `[DONE]`.
- Conservez l’ID de requête et l’ID de modèle dans les journaux pour pouvoir rejouer et déboguer la requête.

## Quand éviter le streaming

- Flux d’appels d’outils avec la validation actuelle des requêtes (`stream + tools` est refusé).
- Flux de travail nécessitant une validation complète avant d’afficher le moindre résultat à l’utilisateur.
