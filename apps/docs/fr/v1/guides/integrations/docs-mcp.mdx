Ajoutez `https://phaseo.app/docs/mcp` à votre agent de code comme serveur MCP pour qu’il réponde aux questions sur Phaseo à partir de la documentation en direct plutôt que de ses données d’entraînement. Le serveur est en lecture seule : les agents peuvent rechercher dans la documentation, lire des pages complètes et lire le résumé des capacités hébergé [skill.md](https://phaseo.app/docs/skill.md).

## Codex

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
codex mcp list
```

## Claude Code

Ajoutez le serveur au projet en cours, ou ajoutez `--scope user` pour le rendre disponible dans tous les projets :

```bash
claude mcp add --transport http phaseo-docs https://phaseo.app/docs/mcp
claude mcp add --transport http --scope user phaseo-docs https://phaseo.app/docs/mcp
claude mcp list
```

## Cursor

Installez-le depuis le menu contextuel de n’importe quelle page de la documentation, ou ajoutez-le à la configuration MCP de Cursor :

```json
{
  "mcpServers": {
    "phaseoDocs": {
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## VS Code

Installez-le depuis le menu contextuel de n’importe quelle page de la documentation, ou ajoutez-le à la configuration MCP de VS Code :

```json
{
  "servers": {
    "phaseoDocs": {
      "type": "http",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## OpenCode

Ajoutez-le à `opencode.json` :

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "phaseoDocs": {
      "type": "remote",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## Vérifier que tout fonctionne

Posez à l’agent une question à laquelle seule la documentation peut répondre, et vérifiez qu’il appelle le serveur de documentation Phaseo :

- `Look up the Responses request format in the Phaseo docs and give me a minimal example.`
- `Use the Phaseo docs MCP server to check how provider.sort works before you change this request.`
- `Find the guardrails docs in Phaseo and summarize the parts that affect provider routing.`

Les agents s’en servent pour vérifier la forme des requêtes, les endpoints pris en charge par un modèle ou un fournisseur, et le comportement du routage, des préréglages, des règles de protection et des tâches asynchrones. Le serveur de documentation ne fait pas de Phaseo votre passerelle de modèles ; pour cela, consultez [Agents de code](./coding-assistants.mdx).
