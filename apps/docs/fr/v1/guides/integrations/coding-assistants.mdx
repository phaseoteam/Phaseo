Exécutez `phaseo login`, puis `phaseo <agent>` pour diriger un agent de code vers Phaseo avec sa propre clé API. Pour vous passer de la CLI, saisissez les [valeurs du fournisseur à la main](#enter-the-provider-values-yourself) dans les réglages de l’agent.

```bash
phaseo login
phaseo codex
```

## Trouver la commande de votre agent

La CLI configure chaque agent de l’une des trois façons suivantes :

- **Configuré** : la CLI écrit le fichier de configuration de l’agent. Démarrez l’agent et choisissez un modèle Phaseo.
- **Clé seule** : l’agent conserve les clés dans son propre stockage ; la CLI crée donc la clé et affiche les champs à remplir.
- **Session** : la CLI lance l’agent avec des réglages temporaires, supprimés à sa fermeture. Votre configuration habituelle n’est pas modifiée.

| --- | --- | --- | --- |
| Claude Code | `phaseo claude-code` | Configuré | [Claude Code](./claude-code.mdx) |
| Codex | `phaseo codex` | Configuré | [Codex](./codex.mdx) |
| OpenCode | `phaseo opencode` | Configuré | [OpenCode](./opencode.mdx) |
| fx | `phaseo fx` | Configuré | [fx](./fx.mdx) |
| DeepSeek Harness | `phaseo deepseek-harness` | Configuré | [DeepSeek Harness](./deepseek-harness.mdx) |
| Pi | `phaseo pi` | Configuré | [Pi](./pi.mdx) |

Consultez le [guide de la CLI Phaseo](./phaseo-cli.mdx) pour installer la CLI.

## Ce que crée la CLI

Chaque agent reçoit sa propre clé API, nommée d’après lui (par exemple `Phaseo CLI: Codex API Key`), avec une limite de dépenses mensuelle de $100 et une expiration au bout de 90 jours. Vous approuvez chaque nouvelle clé sur une page du tableau de bord que la CLI ouvre, puis la CLI la récupère une seule fois ; voir [Approuver la clé dans le navigateur](./phaseo-cli.mdx#approve-the-key-in-your-browser). Relancez la commande de configuration pour remplacer une clé expirée, et modifiez la limite dans le tableau de bord, sous **Paramètres → Clés d’API**.

Si Claude Code, Codex, OpenCode, fx, DeepSeek Harness, Pi, Prime Agent, OpenClaw ou Hermes Agent n’est pas installé, la CLI affiche la commande d’installation officielle et demande confirmation avant de l’exécuter. Hors d’un terminal interactif, elle affiche la commande d’installation et s’arrête. OpenCode, fx, DeepSeek Harness, Pi, Prime Agent et OpenClaw reçoivent aussi tous les modèles texte Phaseo actifs compatibles avec Chat Completions.

| Option ou commande | Effet |
| --- | --- |
| `--model <id>` | Définit le modèle par défaut. Non pris en charge pour Claude Code. |
| `--catalog default` | Ajoute uniquement le modèle sélectionné au lieu de tout le catalogue. |
| `--skip-install` | Ignore la vérification de l’installation, pour un agent que vous gérez vous-même. |
| `--dry-run` | Affiche les modifications de fichiers sans les appliquer. |
| `--key <key>` | Utilise une clé créée dans le tableau de bord au lieu d’en demander une nouvelle. `--key-stdin` la lit sur l’entrée standard. |
| `phaseo integrations credential <agent>` | Affiche la clé de cet agent, pour les agents où vous la collez vous-même. |
| `phaseo integrations remove <agent>` | Supprime la configuration écrite par Phaseo et révoque la clé. Vos autres réglages restent en place. |

## Saisir vous-même les valeurs du fournisseur

Utilisez ces valeurs dans tout agent doté d’un fournisseur compatible avec OpenAI. Le nom des champs varie selon l’outil.

| Réglage | Valeur |
| --- | --- |
| Type de fournisseur | OpenAI Compatible |
| Base URL | `https://api.phaseo.app/v1` |
| Clé API | Une clé API Phaseo |
| Modèle | Un ID de modèle Phaseo, par exemple `openai/gpt-6-astra` |

Pour les agents qui utilisent l’API Anthropic Messages :

| Réglage | Valeur |
| --- | --- |
| Base URL | `https://api.phaseo.app` (le client ajoute `/v1/messages`) |
| Jeton d’authentification | Une clé API Phaseo |
| Modèle | Un ID de modèle Phaseo, par exemple `anthropic/claude-sonnet-5.5` |

Certains agents refusent les ID de modèle qui contiennent `/`. Si c’est le cas du vôtre et qu’il prend en charge les alias, créez un alias local qui pointe vers l’ID du modèle Phaseo.

## Agents sans guide dédié

### VS Code

VS Code peut ajouter des modèles dans son éditeur Language Models lorsque votre version inclut un fournisseur compatible avec OpenAI.

1. Ouvrez la palette de commandes et exécutez `Chat: Manage Language Models`.
2. Choisissez `OpenAI Compatible` ou `OAI Compatible`.
3. Saisissez votre clé API Phaseo et définissez l’endpoint sur `https://api.phaseo.app/v1`.
4. Ajoutez un ID de modèle Phaseo, par exemple `openai/gpt-6-astra`, puis sélectionnez-le dans le sélecteur de modèle du chat.

Si votre version n’a pas de fournisseur compatible avec OpenAI, utilisez une extension qui prend en charge les fournisseurs personnalisés : [Continue](./continue.mdx), [Cline](./cline.mdx), [Roo Code](./roo-code.mdx) ou [Kilo Code](./kilo-code.mdx).

### Claude Desktop

Claude Desktop ne peut pas utiliser de fournisseur de modèles personnalisé. Ajoutez [Docs MCP](./docs-mcp.mdx) pour lui donner accès à la documentation Phaseo, et utilisez [Claude Code](./claude-code.mdx) lorsque vous avez besoin de Phaseo comme passerelle de modèles.

### Deep Agents CLI et autres outils LangChain

Utilisez la Base URL et la clé indiquées dans [LangChain](./langchain.mdx). Si l’outil lit les variables d’environnement OpenAI, définissez celles-ci et indiquez un ID de modèle Phaseo dans son champ de modèle :

```bash
export OPENAI_API_KEY="your_phaseo_api_key"
export OPENAI_BASE_URL="https://api.phaseo.app/v1"
```

## Limites connues

- Les outils serveur ne fonctionnent que là où l’agent les envoie : `phaseo:apply_patch` n’est disponible que sur [Responses](../../api-reference/endpoint/responses.mdx). Les agents plus anciens qui ne gèrent pas les événements Responses ni les [outils serveur](../server-tools/index.mdx) sont plus sûrs sur [Chat Completions](../../api-reference/endpoint/chat-completions.mdx).
- Envoyez une courte requête de chat avant de laisser un agent modifier des fichiers, et choisissez un modèle qui prend en charge l’appel d’outils pour le travail d’agent.
- Ajoutez [Docs MCP](./docs-mcp.mdx) si vous voulez que l’agent lise la documentation Phaseo pendant une session.
