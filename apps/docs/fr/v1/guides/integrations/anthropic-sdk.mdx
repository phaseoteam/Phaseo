Faites pointer l’Anthropic SDK vers `https://api.phaseo.app` et passez votre clé Phaseo comme token d’authentification. Utilisez cette méthode pour les applications, agents et outils de programmation qui envoient des requêtes `/v1/messages` au format Claude ; Phaseo les sert comme [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx).

## Installer

<CodeGroup>

```bash TypeScript
npm install @anthropic-ai/sdk
```

```bash Python
pip install anthropic
```

</CodeGroup>

## Faire pointer le client vers Phaseo

<CodeGroup>

```ts TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
	apiKey: null,
	authToken: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app",
});

const message = await client.messages.create({
	model: "anthropic/claude-sonnet-5.5",
	max_tokens: 512,
	messages: [{ role: "user", content: "Reply with only: ok" }],
});

console.log(message.content);
```

```python Python
import os
from anthropic import Anthropic

client = Anthropic(
    auth_token=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app",
)

message = client.messages.create(
    model="anthropic/claude-sonnet-5.5",
    max_tokens=512,
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(message.content)
```

</CodeGroup>

Un bloc de texte contenant `ok` signifie que la configuration fonctionne.

| Réglage | Pourquoi |
| --- | --- |
| `baseURL: "https://api.phaseo.app"` | Utilisez l’hôte racine. Les clients Anthropic ajoutent eux-mêmes `/v1/messages`. |
| `authToken` (`auth_token` en Python) | Envoie `Authorization: Bearer` avec toutes les versions du SDK. Phaseo n’accepte pas `x-api-key`, que `apiKey` envoie avant `@anthropic-ai/sdk` 1.0 et `anthropic` 2.0. |
| `apiKey: null` | Empêche les anciens SDK TypeScript d’envoyer aussi votre `ANTHROPIC_API_KEY`. Les SDK Python antérieurs à 0.98 l’envoient dès qu’elle est définie : mettez à jour, ou retirez-la là où vous appelez Phaseo. |

## Limites connues

- Les formes d’outils natives d’Anthropic fonctionnent là où Phaseo les prend en charge. Les outils serveur qui fonctionnent avec tous les fournisseurs utilisent les noms d’outils Phaseo ; consultez [Appels d’outils](../tool-calling.mdx).
- Les clients compatibles avec Anthropic sont stricts sur l’ordre des événements d’outils. Testez les boucles d’outils diffusées avant la production.
- Pour [Claude Code](./claude-code.mdx), utilisez son guide dédié.
