Utilisez ce guide si votre application appelle déjà OpenAI depuis TypeScript, JavaScript ou Python. Modifiez uniquement la clé API, l’URL de base et l’identifiant du modèle.

## TypeScript

```bash
npm install openai
```

```ts
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-5-nano",
	input: "Write one sentence about reliable model routing.",
});

console.log(response.output_text);
```

## Python

```bash
pip install openai
```

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-5-nano",
    input="Write one sentence about reliable model routing.",
)

print(response.output_text)
```

## Chat Completions

Les bibliothèques plus anciennes peuvent encore utiliser Chat Completions :

```ts
const completion = await client.chat.completions.create({
	model: "openai/gpt-5-nano",
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## Remarques

- Utilisez les identifiants de modèle Phaseo, y compris les préfixes de fournisseur tels que `openai/`, `anthropic/` ou `google/`.
- Les outils serveur utilisent des noms Phaseo, par exemple `phaseo:web_search`.
- Pour les clients natifs Anthropic, consultez le guide du [SDK Anthropic](./anthropic-sdk.mdx).
