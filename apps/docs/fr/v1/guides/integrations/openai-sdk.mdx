Dirigez le SDK OpenAI officiel vers Phaseo en changeant trois choses : la clé API, la Base URL (`https://api.phaseo.app/v1`) et l’ID du modèle.

## Installer

<CodeGroup>

```bash TypeScript
npm install openai
```

```bash Python
pip install openai
```

</CodeGroup>

## Diriger le client vers Phaseo

<CodeGroup>

```ts TypeScript
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Write one sentence about reliable model routing.",
});

console.log(response.output_text);
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Write one sentence about reliable model routing.",
)

print(response.output_text)
```

</CodeGroup>

Si une phrase s’affiche, la clé et la Base URL fonctionnent. La requête apparaît aussi dans **Paramètres → Utilisation → Journaux**.

## Utiliser Chat Completions

Le code qui appelle Chat Completions fonctionne avec le même client :

```ts
const completion = await client.chat.completions.create({
	model: "openai/gpt-6-astra",
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## Limites connues

- Utilisez les ID de modèle Phaseo, avec le préfixe du fournisseur : `openai/`, `anthropic/`, `google/`, etc. Consultez [Responses](../../api-reference/endpoint/responses.mdx) et [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) pour la forme complète des requêtes.
- Les [outils serveur](../server-tools/index.mdx) utilisent les noms d’outils Phaseo, comme `phaseo:web_search`.
- Pour les clients `/v1/messages` de style Anthropic, consultez le guide du [SDK Anthropic](./anthropic-sdk.mdx).
