Donnez à LiteLLM le modèle `openai/<Phaseo model ID>`, votre clé Phaseo et `api_base="https://api.phaseo.app/v1"`. Cela fonctionne pour les appels LiteLLM directs comme pour les modèles placés derrière un proxy LiteLLM.

## Installer

```bash
pip install litellm
```

## Appeler Phaseo depuis LiteLLM

```python
import os
from litellm import completion

response = completion(
    model="openai/openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(response.choices[0].message.content)
```

Si `ok` s’affiche, la configuration fonctionne. LiteLLM utilise le préfixe `openai/` pour les endpoints compatibles avec OpenAI. L’ID du modèle Phaseo reste `openai/gpt-6-astra` ; la chaîne de modèle LiteLLM devient donc `openai/openai/gpt-6-astra`.

## Ajouter des modèles Phaseo à un proxy LiteLLM

Donnez un alias à chaque modèle pour que le code de l’application n’ait pas besoin du préfixe LiteLLM :

```yaml
model_list:
  - model_name: phaseo-gpt-6-astra
    litellm_params:
      model: openai/openai/gpt-6-astra
      api_key: os.environ/PHASEO_API_KEY
      api_base: https://api.phaseo.app/v1
```

Appelez ensuite le proxy avec `model: "phaseo-gpt-6-astra"`. Les alias gardent des noms de modèle lisibles en production.

## Limites connues

- Certaines couches de proxy modifient ou suppriment les types d’outils qu’elles ne connaissent pas. Si vous utilisez les [outils serveur](../server-tools/index.mdx) de Phaseo, testez la route LiteLLM exacte.
- LiteLLM et Phaseo suivent tous deux les dépenses. Choisissez lequel fait référence pour les coûts ; les prix de Phaseo figurent dans le [calculateur de prix](../../api-reference/endpoint/pricing-calculate.mdx).
