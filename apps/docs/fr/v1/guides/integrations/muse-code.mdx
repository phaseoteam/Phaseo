Lancez `phaseo muse` pour démarrer une session Muse Code via Phaseo. Ce lanceur est la seule façon prise en charge d’utiliser Phaseo avec Muse Code.

## Exécuter Muse Code via la CLI Phaseo

```bash
phaseo login
phaseo muse --model meta/muse-spark-1.3
```

Le lanceur crée une clé dédiée, écrit les réglages de Muse dans un `XDG_CONFIG_HOME` temporaire, lance `muse`, puis supprime ces réglages quand Muse Code se ferme. Placez les options propres à Muse Code après `--`.

| Option | Effet |
| --- | --- |
| `--model <id>` | Modèle à utiliser. Par défaut : `openai/gpt-5.6-terra`. |
| `--catalog all` | Affiche tous les modèles texte Phaseo actifs, pas seulement celui sélectionné. |
| `--dry-run --json` | Affiche le plan de lancement sans créer de clé ni démarrer Muse Code. |
| `--skip-install` | Ignore la vérification de l’installation. |

`phaseo run muse ...` est la forme longue de la même commande.

Sous macOS et Linux, la première exécution interactive propose d’installer Muse Code avec l’installateur de Meta. Sous Windows, installez Muse Code vous-même, vérifiez `muse --version` et utilisez `--skip-install`.

## Pourquoi il n’y a pas de configuration manuelle

Muse Code est conçu autour de la [Model API](https://ai.meta.com/llama) de Meta et de sa connexion. Meta ne documente aucun réglage stable pour le diriger vers un autre endpoint compatible avec OpenAI ; utilisez donc le lanceur. Ne copiez pas les réglages temporaires du lanceur dans votre profil Muse habituel : ce sont des détails internes, supprimés à la fermeture du lanceur.

Pour appeler plutôt un modèle Phaseo depuis votre propre code, utilisez le [SDK OpenAI](./openai-sdk.mdx) avec `https://api.phaseo.app/v1` et une clé API Phaseo.

## Vérifier que tout fonctionne

Envoyez un court prompt et vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Résoudre les problèmes courants

### Muse Code n’est pas installé

Installez Muse Code vous-même, vérifiez `muse --version`, puis relancez avec `--skip-install`.

### Le modèle n’apparaît pas

Utilisez `--catalog all`, ou passez l’ID du modèle avec `--model`. Phaseo n’a pas besoin de la découverte des modèles.
