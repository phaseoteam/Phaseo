Créez un modèle `ChatOpenAI` avec votre clé Phaseo et `base_url="https://api.phaseo.app/v1"` : les chaînes LangChain, les agents et les workflows LangGraph appellent alors les modèles via Phaseo.

## Installer

```bash
pip install -U langchain langchain-openai
```

## Diriger ChatOpenAI vers Phaseo

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

Si une phrase s’affiche, la configuration fonctionne.

## L’utiliser dans LangGraph

Passez le même `llm` à vos nœuds de graphe ou à votre constructeur d’agent :

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## Limites connues

- Ce chemin utilise [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) ; seules les fonctionnalités Phaseo disponibles sur `/v1/chat/completions` fonctionnent, dont l’[appel d’outils](../tool-calling.mdx) et le [routage et les solutions de repli](../routing-and-fallbacks.mdx).
- Pour les outils serveur réservés à Responses, comme `phaseo:apply_patch`, appelez Phaseo directement ou utilisez le [SDK OpenAI](./openai-sdk.mdx).
- Pour le traçage avec LangSmith, consultez [Observabilité](./observability.mdx).
