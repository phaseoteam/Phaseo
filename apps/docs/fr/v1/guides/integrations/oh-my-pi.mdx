Lancez `phaseo omp` pour démarrer une session oh-my-pi via Phaseo, ou ajoutez un fournisseur `phaseo` à `~/.omp/agent/models.yml` pour conserver Phaseo dans toutes les sessions.

## Exécuter oh-my-pi via la CLI Phaseo

```bash
phaseo login
phaseo omp --model openai/gpt-5.6-terra
```

Le lanceur crée une clé dédiée, écrit `models.yml` dans un `PI_CODING_AGENT_DIR` temporaire, lance `omp` avec `--model phaseo/<model>`, puis supprime ce répertoire quand oh-my-pi se ferme. Si `omp` n’est pas installé, la première exécution interactive propose de l’installer. Placez les options propres à oh-my-pi après `--`.

| Option | Effet |
| --- | --- |
| `--model <id>` | Modèle à utiliser. Par défaut : `openai/gpt-5.6-terra`. |
| `--catalog all` | Affiche tous les modèles texte Phaseo actifs, pas seulement celui sélectionné. |
| `--dry-run --json` | Affiche le plan d’installation et de lancement sans créer de clé ni démarrer oh-my-pi. |
| `--skip-install` | Ignore la vérification de l’installation. |

`phaseo run omp ...` est la forme longue de la même commande.

## Configurer oh-my-pi manuellement

Créez une clé, exportez-la dans le shell qui démarre oh-my-pi et créez le répertoire de configuration :

```bash
phaseo keys create --name "oh-my-pi Phaseo key" --json
export PHASEO_OMP_API_KEY="<your Phaseo API key>"
mkdir -p ~/.omp/agent
```

Ajoutez le fournisseur :

```yaml ~/.omp/agent/models.yml
providers:
  phaseo:
    baseUrl: https://api.phaseo.app/v1
    api: openai-completions
    apiKey: PHASEO_OMP_API_KEY
    authHeader: true
    models:
      - id: openai/gpt-5.6-terra
        name: GPT-5.6 Terra via Phaseo
        contextWindow: 32768
        maxTokens: 8192
```

`apiKey` indique le nom de la variable d’environnement : la clé reste ainsi hors de `models.yml`. Ajoutez d’autres entrées sous `models` selon vos besoins ; les limites ci-dessus sont des exemples. Démarrez oh-my-pi avec l’ID de modèle préfixé par le fournisseur :

```bash
omp --model phaseo/openai/gpt-5.6-terra
```

Consultez la documentation d’oh-my-pi sur la [configuration des fournisseurs](https://github.com/can1357/oh-my-pi/blob/main/docs/providers.md) pour les autres champs.

## Vérifier que tout fonctionne

Envoyez un court prompt et vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Résoudre les problèmes courants

### oh-my-pi n’est pas installé

Exécutez la commande dans un terminal interactif pour approuver l’installation, ou installez oh-my-pi vous-même et relancez avec `--skip-install`.

### Le modèle n’apparaît pas

Utilisez `--catalog all`, ou passez l’ID du modèle avec `--model`. Phaseo n’a pas besoin de la découverte des modèles.
