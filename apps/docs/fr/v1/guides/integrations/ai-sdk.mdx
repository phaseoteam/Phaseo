Installez `@phaseo/ai-sdk-provider` et passez `phaseo("<model id>")` comme modèle dans n’importe quel appel AI SDK. Le fournisseur lit `PHASEO_API_KEY` dans l’environnement.

## Installer

```bash
npm install @phaseo/ai-sdk-provider
```

Le package sans version suit le tag npm `latest`, qui correspond à la branche AI SDK 7, et déclare `ai@^7` comme dépendance pair (peer dependency) que npm installe pour vous. Pour une version plus ancienne d’AI SDK, installez le tag correspondant :

| AI SDK | Contrat du fournisseur | Installation |
| --- | --- | --- |
| 7 (actuelle) | `ProviderV4` (fournisseur 2.x) | `npm install @phaseo/ai-sdk-provider` |
| 6 | `ProviderV3` (fournisseur 1.x, maintenance) | `npm install @phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `ProviderV2` | `npm install @phaseo/ai-sdk-provider@ai-sdk-v5` |

Si votre gestionnaire de paquets n’installe pas les dépendances pair, installez aussi la version majeure correspondante de `ai` (`ai@^7`, `ai@^6` ou `ai@^5`).

Quand AI SDK 8 sera stable, Phaseo marquera le fournisseur 1.x comme obsolète sur npm. Les versions existantes ne seront pas retirées, et toute fin de prise en charge sera annoncée séparément.

## Générer du texte

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Summarize this in one sentence.",
});

console.log(result.text);
```

Le même code fonctionne sur les trois branches. Utilisez les ID de modèle du [point de terminaison Models](../../api-reference/endpoint/models.mdx) ; chaque fonctionnalité dépend toujours du modèle et du fournisseur d’origine.

## Ce que prend en charge chaque branche

| Fonctionnalité | AI SDK 7 (fournisseur 2.x) | AI SDK 5 |
| --- | --- | --- |
| Génération de texte et streaming | Oui | Oui |
| Outils de fonction et allers-retours de résultats d’outils | Oui, y compris les entrées d’outils diffusées | Oui |
| Sortie structurée JSON et JSON Schema | Oui | Oui |
| Embeddings et génération d’images | Oui | Oui |
| Transcription et synthèse vocale | Oui | Oui |
| Reranking | Oui | Non |
| Paramètres et sortie de raisonnement indépendants du fournisseur | Oui | |
| Entrées de fichiers texte et image (données de fichier balisées V7) | Oui | |
| Sources de citation par URL | Oui | |
| Métadonnées du fournisseur, utilisation, en-têtes de requête, signaux d’annulation, fragments de flux bruts | Oui | |

La colonne AI SDK 7 correspond à ce que le fournisseur 2.x implémente et teste avec les contrats v4 natifs d’AI SDK 7. Le reranking est aussi disponible sur la branche AI SDK 6.

## Reclasser des documents

Utilisez l’outil `rerank()` d’AI SDK avec `phaseo.rerankingModel(modelId)` :

```ts
import { rerank } from "ai";
import { phaseo } from "@phaseo/ai-sdk-provider";

const result = await rerank({
	model: phaseo.rerankingModel("voyage/rerank-2"),
	query: "Which document is about TypeScript?",
	documents: [
		"TypeScript adds static types to JavaScript.",
		"Rust is a systems programming language.",
	],
	topN: 1,
});
```

## Limites connues

- Le fournisseur n’annonce pas les fonctionnalités `ProviderV4` qui nécessitent des surfaces de l’API Phaseo qui n’existent pas encore : téléversements et références de fichiers gérés, compétences, et définitions, résultats ou réponses d’approbation d’outils exécutés par le fournisseur.
- Les outils de fonction que votre application exécute utilisent toujours le flux normal d’exécution et d’approbation d’AI SDK.
- Les parties de prompt propres à un fournisseur ou personnalisées qui ne sont pas prises en charge échouent avec une erreur claire au lieu d’être ignorées.
