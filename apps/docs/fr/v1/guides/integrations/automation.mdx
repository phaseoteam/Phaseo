Appelez Phaseo depuis n’importe quelle plateforme d’automatisation capable d’envoyer une requête HTTP authentifiée : ajoutez une étape HTTP qui envoie un POST à `https://api.phaseo.app/v1/responses` avec votre clé comme token bearer. Phaseo n’a pas d’application native pour Zapier, n8n ou Pipedream.

## Construire la requête

| Réglage | Valeur |
| --- | --- |
| Méthode | `POST` |
| URL | `https://api.phaseo.app/v1/responses` |
| En-tête | `Authorization: Bearer <PHASEO_API_KEY>` |
| En-tête | `Content-Type: application/json` |

```json
{
  "model": "openai/gpt-6-astra",
  "input": "Summarise the supplied workflow data in one paragraph."
}
```

Stockez la clé dans le gestionnaire d’identifiants ou de secrets de la plateforme, pas dans une définition de workflow partagée. Consultez [Responses](../../api-reference/endpoint/responses.mdx) pour tous les champs de la requête.

## Zapier

Utilisez **Webhooks by Zapier → Custom Request** :

1. Sélectionnez `POST` et saisissez `https://api.phaseo.app/v1/responses`.
2. Ajoutez les en-têtes bearer et content-type.
3. Associez les champs des étapes précédentes du Zap à `input`.
4. Testez le Zap avec des données non sensibles.

## n8n

Utilisez le nœud **HTTP Request** avec une authentification bearer et un corps JSON. Associez l’élément entrant à `input` avec une expression n8n.

## Pipedream

Utilisez une étape de requête HTTP ou une étape de code Node.js. Stockez `PHASEO_API_KEY` comme secret Pipedream et lisez-le depuis l’environnement de l’étape.

## Vérifier que tout fonctionne

Exécutez l’étape une fois. Une réponse `200` avec un tableau `output` signifie que la clé et l’URL fonctionnent, et la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Exécuter les automatisations en toute sécurité

- Donnez à chaque automatisation sa propre clé avec une limite de dépenses, pour pouvoir la suivre et la révoquer séparément.
- Utilisez les [sorties structurées](../structured-outputs.mdx) quand les étapes suivantes attendent des champs lisibles par machine.
- Réessayez sur `429` et sur les réponses `5xx` récupérables ; consultez [Erreurs](../../api-reference/errors.mdx).
- Ne répétez pas des actions externes non idempotentes simplement parce qu’une étape de modèle a été relancée.
