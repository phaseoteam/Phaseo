Lancez `phaseo roo-code` pour créer une clé, puis ajoutez un profil **OpenAI Compatible** dans Roo Code. Roo Code conserve les clés dans le stockage des secrets de VS Code ; cette dernière étape se fait donc dans son interface.

## Configurer avec la CLI Phaseo

```bash
phaseo login
phaseo roo-code --model anthropic/claude-sonnet-5.5
```

La CLI crée une clé `Phaseo CLI: Roo Code API Key` qui expire au bout de 90 jours et dispose d’une limite de dépenses mensuelle de $100, puis affiche les valeurs pour l’étape suivante.

## Configurer Roo Code

1. Ouvrez Roo Code dans VS Code, puis **Settings → Providers**.
2. Créez un profil de configuration de fournisseur et choisissez **OpenAI Compatible**.
3. Saisissez :

| Champ Roo Code | Valeur |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | Sortie de `phaseo integrations credential roo-code`, ou n’importe quelle clé API Phaseo |
| Model | `anthropic/claude-sonnet-5.5`, ou le modèle affiché par la configuration |

4. Enregistrez le profil et rendez-le actif.

Les libellés des champs changent légèrement d’une version à l’autre ; consultez la documentation de Roo Code sur les [fournisseurs de modèles](https://docs.roocode.com/providers/) si les vôtres diffèrent.

## Vérifier que tout fonctionne

Demandez à Roo Code de répondre `PHASEO_ROO_OK`, puis vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Retirer Phaseo

Supprimez le profil Phaseo ou changez de profil, puis exécutez :

```bash
phaseo integrations remove roo-code
```

Cette commande révoque la clé. La CLI ne peut pas vider le stockage de l’extension VS Code.

## Résoudre les problèmes courants

### L’authentification échoue

Copiez à nouveau la clé avec `phaseo integrations credential roo-code`, et vérifiez que la Base URL se termine par `/v1`.

### Roo Code ne trouve pas le modèle

Saisissez l’ID exact du modèle Phaseo, y compris son préfixe de fournisseur.

### Le chat fonctionne mais les outils échouent

Passez à un modèle qui prend en charge l’appel d’outils.
