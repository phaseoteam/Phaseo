Utilisez Phaseo depuis Replit avec le SDK officiel OpenAI ou le fournisseur Phaseo officiel pour AI SDK. Conservez la clé API dans Replit Secrets, et non dans le code source.

## Ajouter le secret

Dans votre espace de travail Replit, ouvrez **Tools → Secrets** et ajoutez :

```text
PHASEO_API_KEY=phaseo_v1_sk_...
```

Le secret sera disponible pour votre application sous forme de variable d’environnement.

## TypeScript avec le SDK OpenAI

```bash
npm install openai
```

```ts
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-5-nano",
	input: "Reply with only: ok",
});

console.log(response.output_text);
```

## TypeScript avec AI SDK

```bash
npm install @phaseo/ai-sdk-provider
```

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const { text } = await generateText({
	model: phaseo("openai/gpt-5-nano"),
	prompt: "Reply with only: ok",
});

console.log(text);
```

## Déploiements

Ajoutez également `PHASEO_API_KEY` aux secrets du déploiement, en plus de l’espace de développement. Vérifiez que le déploiement n’écrit pas les variables d’environnement ni les en-têtes de requête dans les journaux.
