Ajoutez `PHASEO_API_KEY` aux Replit Secrets, puis appelez Phaseo avec le [SDK OpenAI](./openai-sdk.mdx) ou le [fournisseur AI SDK de Phaseo](./ai-sdk.mdx). Gardez la clé hors de votre code source.

## Ajouter le secret

Dans votre espace de travail Replit, ouvrez **Tools → Secrets** et ajoutez :

```text
PHASEO_API_KEY=phaseo_v1_sk_...
```

Replit expose le secret à votre application sous forme de variable d’environnement. Consultez [Authentification](../../developers/authentication.mdx) pour les types de clés.

## Appeler Phaseo

<CodeGroup>

```ts OpenAI SDK
// npm install openai
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Reply with only: ok",
});

console.log(response.output_text);
```

```ts AI SDK
// npm install @phaseo/ai-sdk-provider
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const { text } = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Reply with only: ok",
});

console.log(text);
```

</CodeGroup>

Si `ok` s’affiche, le secret et la Base URL fonctionnent.

## Déployer

Ajoutez `PHASEO_API_KEY` aux secrets du déploiement en plus de ceux de l’espace de travail. Assurez-vous que le déploiement n’écrit ni les variables d’environnement ni les en-têtes de requête dans ses journaux.
