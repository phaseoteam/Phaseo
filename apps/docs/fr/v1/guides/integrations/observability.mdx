Vous pouvez tracer les requêtes Phaseo de deux façons : activez la [Diffusion](../broadcast.mdx) pour que Phaseo envoie une trace de chaque requête à Langfuse, LangSmith ou tout outil OpenTelemetry, sans modifier votre code, ou gardez votre bibliothèque de traçage dans votre application et dirigez son client de modèle vers Phaseo.

| | Diffusion | Traçage dans votre application |
| --- | --- | --- |
| Origine des traces | Phaseo, pour chaque requête | Le client de modèle de votre application |
| Modification du code | Aucune ; configuration dans **Paramètres → Diffusion** | Encapsuler le client, puis changer sa Base URL |
| Contenu de la trace | Modèle, fournisseur, chaque tentative auprès d’un fournisseur, tokens, coût, durées et (en option) prompt et sortie | Ce qu’enregistre votre bibliothèque, plus le contexte propre à votre application |

## Langfuse avec le SDK OpenAI

Conservez l’encapsulation OpenAI de Langfuse et donnez au client encapsulé la Base URL de Phaseo :

```bash
pip install langfuse openai
```

```python
import os
from langfuse.openai import openai

client = openai.OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Reply with only: ok",
)
```

## LangSmith avec LangChain

Utilisez la configuration `ChatOpenAI` de [LangChain](./langchain.mdx) et activez LangSmith avec les variables d’environnement habituelles de LangChain :

```bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your_langsmith_key"
export PHASEO_API_KEY="your_phaseo_key"
```

## OpenTelemetry

Si votre framework émet déjà des spans OpenTelemetry, vous n’avez pas besoin d’exportateur spécial. Ajoutez vous-même ce contexte de requête à vos spans :

- l’ID du modèle ;
- l’endpoint, par exemple `responses` ou `chat.completions` ;
- l’ID de requête Phaseo, issu des métadonnées de réponse ou des [journaux](../../api-reference/endpoint/activity.mdx) ;
- le fournisseur qui a servi la requête, lorsque les métadonnées de réponse sont activées.

N’enregistrez jamais les clés API Phaseo comme attributs de span.
