La plupart des intégrations consistent à configurer un client compatible avec OpenAI ou Anthropic pour qu’il utilise Phaseo et une clé API Phaseo. Commencez par le guide de l’outil que vous utilisez déjà.

## URL de base

| Type de client | URL de base |
| --- | --- |
| Clients compatibles avec OpenAI | `https://api.phaseo.app/v1` |
| Clients compatibles avec Anthropic | `https://api.phaseo.app` |

Utilisez les identifiants du [endpoint Models](../../api-reference/endpoint/models.mdx). Pour les nouvelles applications de style OpenAI, privilégiez [Responses](../../api-reference/endpoint/responses.mdx). Pour les anciennes bibliothèques, [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) est généralement l’option la plus sûre.

## Paramètres recommandés

- Configurez `PHASEO_API_KEY` une seule fois et associez-la à la variable d’environnement attendue par le client.
- Conservez l’identifiant du modèle tel quel, par exemple `openai/gpt-5-nano`.
- Utilisez `https://api.phaseo.app/v1` pour les bibliothèques compatibles avec OpenAI, sauf si l’outil demande explicitement l’hôte racine.
- Utilisez `https://api.phaseo.app` pour les SDK et outils compatibles avec Anthropic qui ajoutent `/v1/messages`.
- Testez le streaming et les appels d’outils en préproduction avant de transférer le trafic des agents.
