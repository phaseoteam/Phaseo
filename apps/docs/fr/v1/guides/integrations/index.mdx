Dirigez un client compatible avec OpenAI ou avec Anthropic vers la Base URL de Phaseo, donnez-lui une clé API Phaseo et utilisez tels quels les ID de modèle Phaseo, comme `openai/gpt-6-astra`. Chaque guide configure d’abord l’outil, puis montre comment vérifier qu’il fonctionne et ce qui ne fonctionne pas.

| Type de client | Base URL | Emplacement de la clé |
| --- | --- | --- |
| Compatible avec OpenAI | `https://api.phaseo.app/v1` | Le champ de clé API, envoyé sous la forme `Authorization: Bearer` |
| Compatible avec Anthropic (ajoute lui-même `/v1/messages`) | `https://api.phaseo.app` | Le champ de jeton d’authentification, envoyé sous la forme `Authorization: Bearer` |

Récupérez les ID de modèle depuis l’[endpoint Models](../../api-reference/endpoint/models.mdx). Pour les nouvelles applications de style OpenAI, utilisez [Responses](../../api-reference/endpoint/responses.mdx) ; les bibliothèques plus anciennes sont plus sûres sur [Chat Completions](../../api-reference/endpoint/chat-completions.mdx). Définissez `PHASEO_API_KEY` une fois et associez-la à la variable attendue par l’outil, puis testez le streaming et l’appel d’outils avant d’y basculer le trafic de vos agents.
