Créez l’adaptateur `openaiCompatible` de TanStack AI avec votre clé Phaseo, `baseURL: "https://api.phaseo.app/v1"` et les ID de modèle Phaseo que vous utilisez. Il convient au chat typé en React, Solid, Preact, Vue, Svelte ou en TypeScript côté serveur.

## Installer

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## Diriger l’adaptateur vers Phaseo

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-6-astra", "anthropic/claude-sonnet-5.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-6-astra"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

Déclarez dans `models` chaque ID de modèle Phaseo que vous comptez utiliser. Vérifiez les ID dans [Modèles](../../api-reference/endpoint/models.mdx).

## Limites connues

- L’adaptateur utilise Chat Completions. Pour les fonctionnalités réservées à Responses, appelez Phaseo directement ou utilisez le [SDK OpenAI](./openai-sdk.mdx).
- Si un modèle ne prend pas en charge les [outils](../tool-calling.mdx) ou les images, déclarez des capacités plus restreintes dans TanStack AI pour que TypeScript détecte les appels non pris en charge.
