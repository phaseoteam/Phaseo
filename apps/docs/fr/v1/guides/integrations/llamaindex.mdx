Créez un LLM `OpenAILike` avec votre clé Phaseo et `api_base="https://api.phaseo.app/v1"`, puis définissez-le comme LLM par défaut de LlamaIndex : la génération dans vos workflows RAG passe alors par Phaseo.

## Installer

```bash
pip install llama-index llama-index-llms-openai-like llama-index-embeddings-openai-like
```

## Diriger LlamaIndex vers Phaseo

```python
import os
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    is_chat_model=True,
)

response = llm.complete("Write one sentence about retrieval quality.")
print(response)
```

Si une phrase s’affiche, la configuration fonctionne. `OpenAILike` est la classe de LlamaIndex pour les API tierces compatibles avec OpenAI.

## L’utiliser dans un index

```python
from llama_index.core import Settings

Settings.llm = llm
```

Construisez ou interrogez ensuite votre index comme d’habitude.

## Limites connues

- Les valeurs par défaut de LlamaIndex ne pointent pas vers Phaseo. Définissez explicitement les modèles de génération et d’embedding.
- Pour les [embeddings](../../api-reference/endpoint/embeddings.mdx) Phaseo, configurez le modèle d’embedding avec un ID de modèle Phaseo et la même Base URL.
