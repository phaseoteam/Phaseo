Dirigez le LLM du plugin OpenAI de LiveKit Agents vers `https://api.phaseo.app/v1` avec votre clé Phaseo : vos agents vocaux utilisent alors les ID de modèle et le routage de Phaseo. Le plugin appelle l’endpoint Chat Completions de Phaseo.

## Installer

<CodeGroup>

```bash Python
uv add "livekit-agents[openai]"
```

```bash Node.js
pnpm add @livekit/agents @livekit/agents-plugin-openai
```

</CodeGroup>

## Diriger le LLM de l’agent vers Phaseo

<CodeGroup>

```python Python
import os
from livekit.agents import AgentSession
from livekit.plugins import openai

session = AgentSession(
    llm=openai.LLM(
        model="openai/gpt-6-astra",
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)
```

```ts Node.js
import { voice } from "@livekit/agents";
import * as openai from "@livekit/agents-plugin-openai";

const session = new voice.AgentSession({
	llm: new openai.LLM({
		model: "openai/gpt-6-astra",
		apiKey: process.env.PHASEO_API_KEY,
		baseURL: "https://api.phaseo.app/v1",
	}),
});
```

</CodeGroup>

Démarrez une session, dites quelque chose et vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Limites connues

- Utilisez le mode Chat Completions du plugin pour les endpoints personnalisés. Les outils OpenAI propres à Responses dans LiveKit ne deviennent pas des outils serveur Phaseo.
- Seul le LLM est routé. Configurez séparément la reconnaissance vocale et la synthèse vocale, sauf si l’interface LiveKit que vous utilisez accepte une URL personnalisée compatible avec OpenAI pour cette modalité.
- Testez la gestion des interruptions, les [appels d’outils](../tool-calling.mdx) et la latence du [streaming](../streaming.mdx) avant d’envoyer du trafic vocal de production.
