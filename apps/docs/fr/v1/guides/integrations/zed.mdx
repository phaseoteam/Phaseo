Lancez `phaseo zed` pour ajouter un fournisseur Phaseo au `settings.json` de Zed, puis collez la clé dans Zed, qui conserve les clés des fournisseurs dans le trousseau du système. Pour vous passer de la CLI, ajoutez vous-même le fournisseur dans les réglages de Zed.

## Configurer avec la CLI Phaseo

```bash
phaseo login
phaseo zed --model openai/gpt-5.6-terra
```

La CLI crée une clé `Phaseo CLI: Zed API Key` (expiration au bout de 90 jours, limite de dépenses mensuelle de $100) et ajoute au `settings.json` de Zed un fournisseur `openai_compatible` nommé `phaseo`, avec l’API URL `https://api.phaseo.app/v1` et le modèle sélectionné. Les réglages sans rapport ne sont pas touchés. Sans `--model`, elle utilise `anthropic/claude-sonnet-4.6`. La configuration s’arrête si Zed a déjà un fournisseur nommé `phaseo`.

## Ajouter la clé dans Zed

1. Ouvrez la palette de commandes et exécutez **agent: open settings**.
2. Sous **AI**, sélectionnez **LLM Providers → Configure**.

![Réglages AI de Zed avec LLM Providers mis en évidence](/images/integrations/zed-agent-settings.png)

3. Si Phaseo apparaît, ouvrez-le et collez la sortie de `phaseo integrations credential zed`.

Pour ajouter le fournisseur sans la CLI, sélectionnez plutôt **Add Provider → OpenAI** et saisissez les valeurs ci-dessous.

![Page LLM Providers de Zed avec Add Provider](/images/integrations/zed-llm-providers.png)

| Champ | Valeur |
| --- | --- |
| Provider Name | `Phaseo` |
| API URL | `https://api.phaseo.app/v1` |
| API Key | Sortie de `phaseo integrations credential zed`, ou n’importe quelle clé API Phaseo |
| Model Name | Un ID de modèle Phaseo |

![Formulaire de Zed pour ajouter un fournisseur compatible avec OpenAI](/images/integrations/zed-add-compatible-provider.png)

Renseignez l’API URL, le modèle et la clé avant de sélectionner **Save Provider**.

## Vérifier que tout fonctionne

Ouvrez un nouveau fil Agent, sélectionnez le modèle Phaseo et envoyez une courte requête. Vérifiez qu’elle apparaît dans **Paramètres → Utilisation → Journaux**. Si Zed signale une clé invalide, relancez `phaseo integrations credential zed` et remplacez la clé dans Zed.

## Retirer Phaseo

```bash
phaseo integrations remove zed
```

Cette commande retire le fournisseur Phaseo de `settings.json` et révoque la clé. Si Zed affiche toujours l’ancienne entrée du trousseau, retirez aussi Phaseo de **LLM Providers**.
