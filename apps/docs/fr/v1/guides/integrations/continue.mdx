Lancez `phaseo continue` pour écrire une configuration Continue qui pointe vers Phaseo, ou ajoutez la même entrée de modèle et le même secret à votre configuration existante. Les extensions IDE et la CLI `cn` partagent cette configuration.

## Configurer avec la CLI Phaseo

```bash
phaseo login
phaseo continue --model anthropic/claude-sonnet-5.5
```

Si `~/.continue/config.yaml` et `~/.continue/.env` n’existent pas, la configuration crée une clé `Phaseo CLI: Continue API Key` (expiration au bout de 90 jours, limite de dépenses mensuelle de $100) et écrit les deux fichiers. Sans `--model`, elle utilise `anthropic/claude-sonnet-4.6`.

```yaml ~/.continue/config.yaml
# Managed by Phaseo CLI
name: Phaseo
version: 1.0.0
schema: v1
models:
  - name: "anthropic/claude-sonnet-5.5 via Phaseo"
    provider: openai
    model: "anthropic/claude-sonnet-5.5"
    apiBase: https://api.phaseo.app/v1
    apiKey: ${{ secrets.PHASEO_API_KEY }}
    useResponsesApi: false
    roles: [chat, edit, apply]
```

La clé va dans `~/.continue/.env` sous le nom `PHASEO_API_KEY`. `useResponsesApi: false` maintient Continue sur l’endpoint Chat Completions de Phaseo.

<Warning>
Le fichier `.env` global de Continue est en clair. Ne le commitez jamais. Les extensions IDE n’héritent pas des variables d’environnement du shell ; c’est pourquoi la CLI utilise le fichier de [secrets locaux](https://docs.continue.dev/faqs#managing-local-secrets-and-environment-variables) de Continue.
</Warning>

## Configurer Continue manuellement

Si l’un des deux fichiers contient déjà vos propres réglages, la configuration s’arrête sans le modifier. Ajoutez l’entrée de modèle ci-dessus à votre `config.yaml`, et ajoutez `PHASEO_API_KEY=<key>` à votre `.env`, en utilisant `phaseo integrations credential continue` ou n’importe quelle clé API Phaseo. Consultez la documentation de Continue sur le [fournisseur OpenAI](https://docs.continue.dev/customize/model-providers/top-level/openai) pour les autres champs.

## Vérifier que tout fonctionne

Dans VS Code ou JetBrains, rechargez la fenêtre, ouvrez Continue, sélectionnez **Phaseo** et demandez-lui de répondre `PHASEO_CONTINUE_OK`. Dans la CLI, exécutez `cn` (utilisez `/config` si une autre configuration est active) et envoyez le même prompt. Vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Retirer Phaseo

```bash
phaseo integrations remove continue
```

Cette commande révoque la clé et ne supprime les deux fichiers que s’ils commencent toujours par le marqueur de la CLI Phaseo. Les entrées que vous avez fusionnées vous-même ne sont pas touchées.

## Résoudre les problèmes courants

### Phaseo n’apparaît pas

Rechargez l’IDE et vérifiez que `config.yaml` contient les champs de premier niveau `name`, `version` et `schema`.

### Continue signale un secret manquant

Vérifiez que `~/.continue/.env` contient la clé fournie par `phaseo integrations credential continue`, puis redémarrez l’IDE.

### Continue appelle l’API Responses

Conservez `useResponsesApi: false` sur l’entrée du modèle Phaseo.
