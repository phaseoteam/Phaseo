Lancez `phaseo claude-code` pour faire passer les requêtes de Claude Code par Phaseo, ou définissez vous-même trois variables d’environnement. Claude Code appelle `/v1/messages` au format Anthropic, que Phaseo sert comme [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx) : vos prompts ne changent donc pas.

## Configurer avec la CLI Phaseo

```bash
phaseo login
phaseo claude-code
claude
```

Si Claude Code est absent, la CLI affiche la commande d’installation officielle et demande avant de l’exécuter. La configuration ensuite :

- crée une `Phaseo CLI: Claude Code API Key` qui expire après 90 jours et a une limite de dépenses mensuelle de $100, et la conserve dans le magasin d’identifiants du système d’exploitation ;
- définit `ANTHROPIC_BASE_URL` et un `apiKeyHelper` dans `~/.claude/settings.json`. Le helper récupère la clé depuis la CLI et en crée une nouvelle quand l’ancienne expire : aucune clé en texte brut n’est donc écrite dans les paramètres de Claude Code.

La configuration s’arrête sans rien modifier si `settings.json` contient déjà un autre `ANTHROPIC_BASE_URL`, un autre `apiKeyHelper`, ou un `ANTHROPIC_API_KEY` ou `ANTHROPIC_AUTH_TOKEN` non vide. `--model` n’est pas pris en charge pour Claude Code ; définissez plutôt `ANTHROPIC_MODEL` (voir ci-dessous).

## Configurer Claude Code manuellement

Définissez ces variables dans le shell depuis lequel vous démarrez Claude Code :

<CodeGroup>

```bash bash
export ANTHROPIC_BASE_URL="https://api.phaseo.app"
export ANTHROPIC_AUTH_TOKEN="your_phaseo_api_key"
export ANTHROPIC_API_KEY=""
```

```powershell PowerShell
$env:ANTHROPIC_BASE_URL = "https://api.phaseo.app"
$env:ANTHROPIC_AUTH_TOKEN = "your_phaseo_api_key"
$env:ANTHROPIC_API_KEY = ""
```

</CodeGroup>

Claude Code envoie `ANTHROPIC_AUTH_TOKEN` dans un en-tête `Authorization`, que Phaseo accepte. Pour fixer un modèle par défaut, définissez `ANTHROPIC_MODEL` sur un ID de modèle Phaseo issu de [Models](../../api-reference/endpoint/models.mdx).

## Vérifier que tout fonctionne

Lancez `claude`, envoyez un prompt court et vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Retirer Phaseo

```bash
phaseo integrations remove claude-code
```

Cette commande retire l’URL de base, le helper de clé et les variables d’identifiants vides que Phaseo a ajoutés à `settings.json`, puis révoque la clé. Pour une configuration manuelle, supprimez les trois variables d’environnement.
