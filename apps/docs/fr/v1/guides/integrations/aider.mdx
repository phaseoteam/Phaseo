Lancez `phaseo aider` pour écrire une configuration Aider qui pointe vers Phaseo, ou ajoutez trois lignes à votre `.aider.conf.yml` existant.

## Configurer avec la CLI Phaseo

```bash
phaseo login
phaseo aider --model anthropic/claude-sonnet-5.5
```

Si `~/.aider.conf.yml` n’existe pas, la configuration crée une `Phaseo CLI: Aider API Key` (expiration à 90 jours, limite de dépenses mensuelle de $100) et écrit ce fichier. Sans `--model`, elle utilise `anthropic/claude-sonnet-4.6`.

```yaml ~/.aider.conf.yml
# Managed by Phaseo CLI
model: openai/anthropic/claude-sonnet-5.5
openai-api-base: https://api.phaseo.app/v1
openai-api-key: "<dedicated Phaseo key>"
```

Aider a besoin du préfixe `openai/` pour envoyer un modèle personnalisé via son adaptateur compatible OpenAI. Le modèle envoyé à Phaseo reste `anthropic/claude-sonnet-5.5`.

<Warning>
La clé est stockée en texte brut, car `.aider.conf.yml` fait partie des emplacements de clé documentés par Aider. Limitez la lecture du fichier à votre compte utilisateur, et ne le commitez jamais.
</Warning>

## Configurer Aider manuellement

Si vous avez déjà une configuration Aider, la CLI s’arrête sans la modifier. Copiez les trois réglages ci-dessus dans la configuration qu’Aider doit charger, en utilisant `phaseo integrations credential aider` ou n’importe quelle clé API Phaseo pour `openai-api-key`. Aider lit `.aider.conf.yml` dans votre dossier personnel, à la racine du dépôt et dans le dossier courant, et les fichiers lus en dernier l’emportent. Consultez la documentation d’Aider sur la [configuration YAML](https://aider.chat/docs/config/aider_conf.html) et l’[API compatible OpenAI](https://aider.chat/docs/llms/openai-compat.html).

## Vérifier que tout fonctionne

Ouvrez un dépôt et démarrez Aider :

```bash
aider
```

Vérifiez que la sortie de démarrage nomme `openai/anthropic/claude-sonnet-5.5`, demandez-lui de répondre `PHASEO_AIDER_OK`, et vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

Un avertissement de modèle inconnu n’empêche pas les requêtes. N’ajoutez des métadonnées de modèle Aider que si vous avez besoin d’estimations exactes de limite de tokens ou de coût.

## Retirer Phaseo

```bash
phaseo integrations remove aider
```

Cette commande révoque la clé et supprime `~/.aider.conf.yml` uniquement si le fichier commence toujours par le marqueur de la CLI Phaseo. Si vous avez fusionné les réglages dans votre propre fichier, retirez vous-même les trois lignes.

## Résoudre les problèmes courants

### Aider utilise un autre point de terminaison ou un autre modèle

Un `.aider.conf.yml` à la racine du dépôt ou dans le dossier courant remplace celui de votre dossier personnel. Les variables d’environnement et les options de ligne de commande les remplacent tous.

### L’authentification échoue

Comparez `openai-api-key` avec la sortie de `phaseo integrations credential aider`, et gardez `openai-api-base` exactement égal à `https://api.phaseo.app/v1`.

### Le modèle est introuvable

Gardez le préfixe `openai/` d’Aider. Le modèle Phaseo `openai/gpt-6-astra` devient `openai/openai/gpt-6-astra` dans Aider.
