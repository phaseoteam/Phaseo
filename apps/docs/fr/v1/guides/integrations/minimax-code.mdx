Lancez `phaseo minimax` pour démarrer une session MiniMax Code (`mcode`) via Phaseo, ou ajoutez Phaseo avec `mcode provider add` pour le conserver dans toutes les sessions.

## Exécuter MiniMax Code via la CLI Phaseo

```bash
phaseo login
phaseo minimax --model openai/gpt-5.6-terra
```

Le lanceur crée une clé dédiée, définit `MINIMAX_DATA_DIR` sur un répertoire temporaire, y ajoute un fournisseur Phaseo avec `mcode provider add`, lance `mcode`, puis supprime ce répertoire quand `mcode` se ferme. Votre configuration habituelle `~/.minimax` n’est pas modifiée, et la clé n’est transmise qu’au processus de configuration du fournisseur. Placez les options propres à MiniMax Code après `--`.

| Option | Effet |
| --- | --- |
| `--model <id>` | Modèle à utiliser. Par défaut : `openai/gpt-5.6-terra`. |
| `--catalog all` | Enregistre tous les modèles texte Phaseo actifs compatibles avec Chat Completions. |
| `--dry-run --json` | Affiche le plan d’installation et de lancement sans créer de clé. |
| `--skip-install` | Ignore la vérification de l’installation. |

`phaseo run minimax ...` est la forme longue de la même commande.

Si `mcode` n’est pas installé, la première exécution interactive propose de l’installer avec l’installateur officiel de MiniMax (l’installateur PowerShell sous Windows). Si vous gérez MiniMax Code vous-même, installez-le, vérifiez `mcode --version`, puis relancez avec `--skip-install`.

## Configurer MiniMax Code manuellement

Pour conserver un fournisseur Phaseo, ajoutez-le avec la commande propre à MiniMax Code :

```bash
export MCODE_PROVIDER_API_KEY="your_phaseo_api_key"
mcode provider add \
  --name "Phaseo" \
  --base-url "https://api.phaseo.app/v1" \
  --api-format openai-completions \
  --model "openai/gpt-5.6-terra" \
  --use
```

MiniMax Code enregistre le fournisseur dans son répertoire de données.

## Vérifier que tout fonctionne

Envoyez un court prompt et vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Résoudre les problèmes courants

### MiniMax Code n’est pas installé

Exécutez la commande dans un terminal interactif pour approuver l’installateur officiel, ou installez MiniMax Code vous-même et relancez avec `--skip-install`.

### Le fournisseur ou le modèle n’apparaît pas

Utilisez `phaseo minimax --catalog all`, ou passez l’ID du modèle avec `--model`.

### Vous avez besoin d’ACP plutôt que de la CLI interactive

`phaseo minimax` exécute la CLI interactive. MiniMax Code fonctionne aussi comme processus ACP avec `mcode acp` ; utilisez la configuration ACP de MiniMax Code lorsque votre éditeur ou votre hôte parle directement ACP.
