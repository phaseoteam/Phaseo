Lancez `phaseo prime-agent` pour ajouter à Prime Agent un fournisseur Phaseo avec tous les modèles Phaseo compatibles. Prime Agent fonctionne sous macOS et Linux ; sous Windows, installez-le et lancez la configuration dans WSL.

## Configurer avec la CLI Phaseo

```bash
phaseo login
phaseo prime-agent
```

Si Prime Agent n’est pas installé, la CLI affiche la commande de l’installateur officiel et demande confirmation avant de l’exécuter. La configuration crée ensuite une clé `Phaseo CLI: Prime Agent API Key` (expiration au bout de 90 jours, limite de dépenses mensuelle de $100) et écrit un fournisseur `phaseo` dans `~/.prime/agent/models.json`. Le fournisseur liste tous les modèles texte Phaseo actifs compatibles avec Chat Completions.

| Option | Effet |
| --- | --- |
| `--model <id>` | Définit le modèle initial. Par défaut : `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | Ajoute uniquement le modèle sélectionné. |
| `--dry-run` | Affiche les modifications de fichiers sans les appliquer. |

Le fournisseur obtient sa clé au moment de la requête grâce au format de clé fournie par commande de Prime Agent : aucune clé en clair n’est écrite dans le fichier.

```text
!phaseo integrations credential prime-agent
```

## Vérifier que tout fonctionne

```bash
prime-agent
```

Ouvrez `/model`, sélectionnez le fournisseur `phaseo` et envoyez un court prompt. Vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Retirer Phaseo

```bash
phaseo integrations remove prime-agent
```

Cette commande retire uniquement le fournisseur Phaseo et révoque la clé.
