Faites tourner les clés API Phaseo sans interruption : créez une clé de remplacement avec une [clé de gestion](../../developers/management-api-keys.mdx), basculez votre application dessus, puis supprimez l’ancienne. Cette page donne les valeurs qu’une connexion Infisical utilise pour cette rotation.

<Warning>
Phaseo n’est pas encore une App Connection sélectionnable dans Infisical. Le connecteur, ses tests et son entrée dans l’interface doivent encore être acceptés par Infisical. D’ici là, utilisez les requêtes ci-dessous depuis votre propre tâche de rotation.
</Warning>

## Fonctionnement de la rotation

```mermaid
flowchart LR
  mk["Clé de gestion"] -->|"POST /v1/keys"| newkey["Nouvelle clé API"]
  newkey -->|"Stockage dans le secret"| app["L’application utilise la nouvelle clé"]
  app -->|"DELETE /v1/keys/{id}"| old["Ancienne clé révoquée"]
```

Phaseo n’affiche la valeur d’une clé API qu’une seule fois, à sa création. L’ancienne et la nouvelle clé fonctionnent toutes deux jusqu’à ce que vous supprimiez l’ancienne ; votre application peut donc basculer pendant la mise à jour du secret.

## Créer une clé de gestion à portée limitée

Dans **Paramètres → Clés de gestion**, créez une clé avec ces capacités :

| Capacité | Sert à |
| --- | --- |
| `keys:read` | Vérifier la connexion et lister les clés gérées. |
| `keys:write` | Créer des clés de remplacement. |
| `keys:delete` | Révoquer les anciennes clés. |

Stockez la valeur `phaseo_v1_mk_...` dans Infisical. Les clés de gestion contrôlent votre compte et ne peuvent pas servir à l’inférence.

## Détails de la connexion

| Champ | Valeur |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| Authentification | `Authorization: Bearer <PHASEO_MANAGEMENT_KEY>` |
| Vérifier la connexion | `GET /keys` |
| Lister les clés API | `GET /keys` |
| Créer une clé API | [`POST /keys`](../../api-reference/endpoint/keys-create.mdx) |
| Révoquer une clé API | [`DELETE /keys/{id}`](../../api-reference/endpoint/keys-delete.mdx) |

## Créer la clé de remplacement

```bash
curl https://api.phaseo.app/v1/keys \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "infisical-production",
    "limit": 100,
    "limit_reset": "monthly",
    "include_byok_in_limit": false
  }'
```

La réponse contient la nouvelle clé, une seule fois, dans `data.key`, et son ID dans `data.id`.

| Champ | Valeurs |
| --- | --- |
| `limit` | Limite de dépenses en dollars américains. |
| `limit_reset` | `daily`, `weekly` ou `monthly`. |
| `include_byok_in_limit` | Accepté uniquement pour la compatibilité. L’utilisation BYOK n’est jamais comptée dans cette limite. |

## Révoquer l’ancienne clé

```bash
curl -X DELETE https://api.phaseo.app/v1/keys/$PREVIOUS_KEY_ID \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY"
```

La suppression est idempotente : supprimer une clé déjà supprimée renvoie `200` avec `{"deleted": true}`, ce qui permet de relancer une rotation sans risque.
