Lancez `phaseo cursor` pour créer une clé, puis activez les réglages de clé API OpenAI et **Override OpenAI Base URL** de Cursor. Les modèles de chat de Cursor passent alors par Phaseo ; les fonctionnalités qui utilisent les modèles propres à Cursor, comme la complétion par tabulation, peuvent continuer à utiliser l’infrastructure de Cursor.

## Configurer avec la CLI Phaseo

```bash
phaseo login
phaseo cursor --model openai/gpt-5.6-terra
```

La CLI crée une clé `Phaseo CLI: Cursor API Key` qui expire au bout de 90 jours et dispose d’une limite de dépenses mensuelle de $100, puis affiche les réglages ci-dessous. Relancez `phaseo cursor` pour obtenir une nouvelle clé après son expiration. La CLI ne modifie pas le magasin d’identifiants de Cursor.

## Configurer Cursor

1. Ouvrez **Cursor Settings → Models**.
2. Repérez la section **OpenAI API Key** et activez-la.
3. Collez la clé fournie par `phaseo integrations credential cursor`, ou n’importe quelle clé API Phaseo.
4. Activez **Override OpenAI Base URL** et saisissez `https://api.phaseo.app/v1`, sans barre oblique finale.
5. Ajoutez ou activez le modèle Phaseo de votre choix.

| Champ Cursor | Valeur |
| --- | --- |
| OpenAI API Key | Sortie de `phaseo integrations credential cursor` |
| Override OpenAI Base URL | `https://api.phaseo.app/v1` |
| Model | Un ID de modèle Phaseo accepté par Cursor |

Les réglages de clé et de Base URL de Cursor sont globaux, et non propres à chaque fournisseur : la clé et la Base URL activées déterminent la destination de toutes les requêtes de la famille OpenAI, et le nom du modèle est transmis tel quel. Certaines versions enregistrent la clé sans bouton **Verify** ; testez plutôt avec un nouveau chat. Consultez la [documentation de Cursor sur les clés API](https://docs.cursor.com/settings/api-keys).

## Vérifier que tout fonctionne

1. Laissez la clé et le remplacement de la Base URL activés.
2. Sélectionnez le modèle dans le sélecteur de modèle de Cursor et démarrez un nouveau chat.
3. Demandez-lui de répondre `PHASEO_CURSOR_OK`.
4. Vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Retirer Phaseo

Désactivez la clé API OpenAI et le remplacement de la Base URL dans **Cursor Settings → Models**, puis révoquez la clé :

```bash
phaseo integrations remove cursor
```

La CLI ne peut pas vider le stockage des identifiants de Cursor. Si la clé apparaît toujours comme configurée, supprimez-la dans les réglages Models de Cursor.

## Résoudre les problèmes courants

### Les modèles hébergés par Cursor ne fonctionnent plus

Cursor applique le remplacement de la Base URL à tous les modèles de la famille OpenAI. Désactivez **Override OpenAI Base URL** avant de revenir à un modèle hébergé par Cursor.

### Le modèle est refusé

Cursor peut refuser les ID qui entrent en conflit avec son catalogue intégré ou ne correspondent pas à son routage de la famille OpenAI, et certaines versions refusent les ID avec un préfixe de fournisseur. Essayez un autre modèle Phaseo que Cursor accepte comme modèle personnalisé de la famille OpenAI.

### L’authentification échoue

Relancez `phaseo integrations credential cursor`, remplacez la clé dans Cursor et vérifiez que la Base URL est exactement `https://api.phaseo.app/v1`.
