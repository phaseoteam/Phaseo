Lancez `phaseo opencode` pour ajouter à OpenCode un fournisseur Phaseo avec tous les modèles Phaseo compatibles, ou ajoutez vous-même un fournisseur `phaseo` à `opencode.json`.

## Configurer avec la CLI Phaseo

```bash
phaseo login
phaseo opencode --model openai/gpt-5.6-terra
```

Si OpenCode n’est pas installé, la CLI affiche la commande d’installation officielle et demande confirmation avant de l’exécuter. La configuration ensuite :

- ajoute un fournisseur global `phaseo` avec tous les modèles texte Phaseo actifs compatibles avec Chat Completions. Elle met à jour votre `opencode.jsonc` global s’il existe, sinon `~/.config/opencode/opencode.json`, sans toucher à vos autres réglages ;
- crée une clé `Phaseo CLI: OpenCode API Key` qui expire au bout de 90 jours et dispose d’une limite de dépenses mensuelle de $100, et la stocke dans le magasin d’identifiants d’OpenCode. La CLI en conserve sa propre copie dans le magasin d’identifiants du système d’exploitation. Relancez `phaseo opencode` pour remplacer une clé expirée.

Utilisez `--catalog default` pour n’ajouter que le modèle sélectionné, ou `--dry-run` pour prévisualiser les modifications.

## Configurer OpenCode manuellement

Ajoutez le fournisseur à `opencode.json` dans votre projet, ou à votre configuration OpenCode globale :

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-6-astra",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-6-astra": { "name": "GPT-6 Astra" },
        "openai/gpt-5.4-mini": { "name": "GPT-5.4 Mini" },
        "anthropic/claude-sonnet-5.5": { "name": "Claude Sonnet 5.5" }
      }
    }
  }
}
```

Exportez `PHASEO_API_KEY`, puis ajoutez ou retirez des entrées dans `models` pour choisir les modèles Phaseo listés par OpenCode.

## Vérifier que tout fonctionne

Redémarrez OpenCode, choisissez un modèle Phaseo dans `/models` et envoyez un court prompt avant de commencer à modifier des fichiers. Vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Retirer Phaseo

```bash
phaseo integrations remove opencode
```

Cette commande retire uniquement le fournisseur Phaseo et son identifiant stocké, puis révoque la clé.

## Résoudre les problèmes courants

| Problème | Solution |
| --- | --- |
| Un modèle est refusé | Vérifiez l’ID exact avec l’[endpoint Models](../../api-reference/endpoint/models.mdx). |
| L’authentification échoue | Relancez `phaseo opencode` et vérifiez `opencode auth list`. |

Pour que OpenCode lise la documentation Phaseo pendant une session, ajoutez le serveur [Docs MCP](./docs-mcp.mdx).
