Passez un modèle du [fournisseur AI SDK de Phaseo](./ai-sdk.mdx) à votre agent [eve](https://eve.dev) : chaque appel de modèle passe alors par Phaseo, avec votre routage, vos clés, vos budgets et vos journaux. eve accepte n’importe quel modèle de langage AI SDK.

## Installer

eve utilise AI SDK 7 ; installez donc `@phaseo/ai-sdk-provider` 2.0.1 ou une version ultérieure :

```bash
npm install @phaseo/ai-sdk-provider
```

Définissez `PHASEO_API_KEY` dans `.env.local` pour `eve dev`, et dans l’environnement serveur de chaque déploiement. La connexion `/login` d’eve ne fonctionne que sur votre machine.

## Diriger un agent eve vers Phaseo

```ts agent/agent.ts
import { defineAgent } from "eve";
import { phaseo } from "@phaseo/ai-sdk-provider";

export default defineAgent({
	model: phaseo("openai/gpt-6-astra"),
	modelContextWindowTokens: 922_000,
	reasoning: "low",
});
```

Passez un objet modèle comme `phaseo("openai/gpt-6-astra")` ; une simple chaîne d’ID de modèle n’est pas envoyée à Phaseo. Définissez `modelContextWindowTokens` sur la valeur `limits.input_tokens` du modèle, fournie par l’[endpoint Models](../../api-reference/endpoint/models.mdx). eve ne peut pas connaître la fenêtre de contexte d’un objet modèle, et utilise ce nombre pour décider quand compacter la conversation.

Exécutez l’agent une fois et vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Choisir un modèle à chaque tour

`defineDynamic` s’exécute avant chaque appel de modèle. Renvoyez un objet de sélection pour que chaque modèle conserve sa propre fenêtre de contexte :

```ts agent/agent.ts
import { defineAgent } from "eve";
import { defineDynamic } from "eve/models";
import { phaseo } from "@phaseo/ai-sdk-provider";

export default defineAgent({
	model: defineDynamic((ctx) =>
		ctx.session.auth.initiator?.attributes.plan === "enterprise"
			? { model: phaseo("openai/gpt-6-sol"), modelContextWindowTokens: 1_050_000 }
			: { model: phaseo("openai/gpt-6-luna"), modelContextWindowTokens: 1_050_000 },
	),
});
```

## Limites connues

- Les outils, le streaming, le raisonnement, la compaction et le cache de prompts fonctionnent via Phaseo. Les lectures du cache de prompts apparaissent dans les événements d’utilisation d’eve et dans les journaux Phaseo.
- eve laisse vide le coût de chaque exécution pour les objets modèle. Consultez le coût sur la page **Utilisation** de Phaseo ou dans **Journaux**.
