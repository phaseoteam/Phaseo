Lancez `phaseo pi` pour ajouter à Pi une extension de fournisseur Phaseo avec tous les modèles Phaseo compatibles.

## Configurer avec la CLI Phaseo

```bash
phaseo login
phaseo pi
```

Si Pi n’est pas installé, la CLI affiche la commande d’installation officielle et demande confirmation avant de l’exécuter. La configuration crée ensuite une clé `Phaseo CLI: Pi API Key` (expiration au bout de 90 jours, limite de dépenses mensuelle de $100) et écrit une extension de fournisseur dans `~/.pi/agent/extensions/phaseo.ts`. L’extension liste tous les modèles texte Phaseo actifs compatibles avec Chat Completions.

| Option | Effet |
| --- | --- |
| `--model <id>` | Définit le modèle initial. Par défaut : `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | Ajoute uniquement le modèle sélectionné. |
| `--dry-run` | Affiche les modifications de fichiers sans les appliquer. |

L’extension obtient sa clé au moment de la requête grâce à la syntaxe de clé fournie par commande de Pi : aucune clé en clair n’est écrite dans le fichier.

```text
!phaseo integrations credential pi
```

## Vérifier que tout fonctionne

```bash
pi
```

Ouvrez `/model`, choisissez le fournisseur `phaseo` et envoyez un court prompt. Vérifiez que la requête apparaît dans **Paramètres → Utilisation → Journaux**.

## Retirer Phaseo

```bash
phaseo integrations remove pi
```

Cette commande retire uniquement l’extension Phaseo et révoque la clé.
