Créez un `OpenAIChatModel` avec un `OpenAIProvider` dirigé vers `https://api.phaseo.app/v1` : les agents PydanticAI s’exécutent alors sur les modèles Phaseo.

## Installer

```bash
pip install "pydantic-ai-slim[openai]"
```

## Diriger PydanticAI vers Phaseo

```python
import os
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-6-astra",
    provider=OpenAIProvider(
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)

agent = Agent(model, system_prompt="Answer concisely.")
result = agent.run_sync("Reply with only: ok")
print(result.output)
```

Si `ok` s’affiche, la configuration fonctionne.

## Limites connues

- Ce chemin utilise Chat Completions de style OpenAI. Pour les fonctionnalités réservées à Responses, comme `phaseo:apply_patch`, appelez directement l’endpoint Responses de Phaseo.
- Gardez les schémas de [sorties structurées](../structured-outputs.mdx) assez petits pour la fenêtre de contexte du modèle. Vérifiez les limites dans [Modèles](../../api-reference/endpoint/models.mdx).
