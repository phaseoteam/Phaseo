Le streaming renvoie la réponse sous forme de fragments SSE successifs, afin que les utilisateurs la voient plus tôt.

## Points de terminaison pris en charge

- `/v1/responses`
- `/v1/chat/completions`
- `/v1/messages`

## Requête

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Stream a short hello message.",
    "stream": true
  }'
```

## Réponse

```text
data: {"id":"resp_...","object":"response","status":"in_progress",...}
data: {"type":"response.output_text.delta","delta":"Hello"}
data: {"type":"response.completed",...}
data: [DONE]
```

## Options du SDK

- SDK TypeScript : `client.streamResponses()`, `client.streamChat()` et `client.streamMessages()`
- Python SDK : `client.stream_responses()`, `client.stream_chat()` et `client.stream_message()`
- Vercel AI SDK : `streamText(...)` avec `@phaseo/ai-sdk-provider`

## Limitation importante

Au niveau actuel de validation des requêtes de la passerelle, l’association d’outils avec `stream: true` est refusée (`400 invalid_request`). Utilisez le mode sans streaming pour les boucles d’appels d’outils.
