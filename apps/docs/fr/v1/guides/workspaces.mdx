Les espaces de travail regroupent les clés API, les paramètres de routage, les préréglages, les garde-fous et les accès administratifs d’une équipe, d’un produit ou d’un environnement.

Les espaces de travail sont inclus dans le service standard à l’usage de Phaseo. Aucun forfait distinct n’est nécessaire pour les créer ou les utiliser.

## Quand créer un espace de travail

Utilisez des espaces de travail distincts si vous souhaitez :

- isoler les identifiants de développement, de préproduction et de production
- séparer différents produits ou projets clients
- limiter les intégrations administratives aux ressources dont elles ont besoin
- appliquer différentes règles de routage, de préréglage ou de garde-fous

Pour une petite intégration, l’espace de travail par défaut peut suffire.

## Gérer les espaces de travail

Vous pouvez gérer les espaces de travail depuis le tableau de bord Phaseo ou via l’API de gestion.

L’API des espaces de travail utilise des [clés API de gestion](../developers/management-api-keys.mdx). Les clés Gateway standard servent aux requêtes d’inférence et ne peuvent pas appeler les points de terminaison d’administration des espaces de travail.

| Tâche | Point de terminaison |
| --- | --- |
| Lister les espaces de travail | [`GET /workspaces`](../api-reference/endpoint/workspaces-list.mdx) |
| Créer un espace de travail | [`POST /workspaces`](../api-reference/endpoint/workspaces-create.mdx) |
| Lire un espace de travail | [`GET /workspaces/{id}`](../api-reference/endpoint/workspaces-get.mdx) |
| Mettre à jour un espace de travail | [`PATCH /workspaces/{id}`](../api-reference/endpoint/workspaces-update.mdx) |
| Supprimer un espace de travail | [`DELETE /workspaces/{id}`](../api-reference/endpoint/workspaces-delete.mdx) |

<Note>
Les points de terminaison de gestion des espaces de travail sont actuellement marqués Beta. Facilitez les nouvelles tentatives de l’automatisation administrative et vérifiez les réponses de l’API avant d’appliquer d’autres modifications.
</Note>

## Choisir le bon niveau d’accès

Créez une clé de gestion limitée aux capacités sur les espaces de travail nécessaires à votre intégration :

- `workspaces:read` pour lister et consulter les espaces de travail
- `workspaces:write` pour créer ou modifier les espaces de travail
- `workspaces:delete` pour supprimer les espaces de travail

Phaseo vérifie également l’appartenance à l’espace de travail et les rôles. Une capacité ne donne pas, à elle seule, accès à un autre espace de travail.

Stockez les clés de gestion dans le coffre de secrets côté serveur. Ne les exposez pas dans le code du navigateur, les journaux de bureau, le contrôle de version ou les conversations.

## Supprimer un espace de travail

L’espace de travail par défaut ne peut pas être supprimé. Avant d’en supprimer un autre, retirez ou déplacez ses clés API actives afin que les requêtes ne ciblent pas un espace de travail qui n’existe plus.

## Facturation

Les espaces de travail ne créent pas de niveaux tarifaires distincts. L’utilisation reste facturée selon le modèle standard à l’usage décrit dans [Tarification et facturation](../pricing/tiers.mdx).
