Envoyez une image de document à `POST /v1/parse` pour récupérer son texte dans l’ordre de lecture, en Markdown ou sous forme de blocs structurés de texte, d’images et de tableaux. Utilisez l’[OCR](../api-reference/endpoint/ocr.mdx) si vous n’avez besoin que du texte brut.

<Warning>
  Parse accepte une image par requête, sous forme d’URL `http(s)` ou d’URI base64 `data:image/...`. Les PDF ne sont pas acceptés : convertissez d’abord chaque page en image. Cohere limite chaque image à 20 Mo, 50 mégapixels et 200 Mo une fois décodée.
</Warning>

## Extraire en Markdown

Markdown est la valeur par défaut de `output_format`. Ce format conserve l’ordre de lecture, intègre les tableaux en HTML et relie les images détectées aux métadonnées de la page.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/parse \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cohere/parse-v5.0",
    "document": {
      "type": "image_url",
      "image_url": "https://example.com/invoice.png"
    },
    "output_format": "markdown"
  }'
```

```ts TypeScript
const response = await fetch("https://api.phaseo.app/v1/parse", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "cohere/parse-v5.0",
    document: {
      type: "image_url",
      image_url: "https://example.com/invoice.png",
    },
    output_format: "markdown",
  }),
});

const parsed = await response.json();
console.log(parsed.pages[0].markdown.content);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/parse",
    headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
    json={
        "model": "cohere/parse-v5.0",
        "document": {
            "type": "image_url",
            "image_url": "https://example.com/invoice.png",
        },
        "output_format": "markdown",
    },
)
response.raise_for_status()
print(response.json()["pages"][0]["markdown"]["content"])
```
</CodeGroup>

## Renvoyer des blocs structurés

Définissez `output_format` sur `blocks` pour recevoir des zones de texte, d’image et de tableau ordonnées. Les blocs d’image et de tableau incluent des cadres de délimitation en pixels et normalisés lorsqu’ils sont disponibles.

## Facturation de Parse

L’utilisation de Parse est comptabilisée à la page. La réponse inclut les métadonnées de Cohere et une valeur normalisée `usage.input_pages` lorsque le fournisseur indique les pages facturées. Cohere propose actuellement un accès API d’évaluation gratuit et soumis à des limites de débit, et n’a pas publié de tarif de production pour l’API Parse.
