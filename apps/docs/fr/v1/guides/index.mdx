## Première intégration

S’il s’agit de votre première intégration avec Phaseo, suivez ces étapes dans l’ordre :

1. [Démarrage rapide](../quickstart.mdx) : effectuez une requête réussie.
2. [Authentification](../developers/authentication.mdx) : stockez et envoyez les clés en toute sécurité.
3. [Exemples](./examples.mdx) : copiez des exemples de requêtes dans votre application.

<Note>
Vous pouvez appeler les modèles `:free` sans déposer de crédits. Les modèles payants nécessitent un solde disponible dans le portefeuille.
</Note>
