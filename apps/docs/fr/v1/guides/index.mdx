Choisissez le guide qui correspond au travail en cours. Pour une première intégration de Phaseo, suivez cet ordre :

1. [Démarrage rapide](../quickstart) : réussissez une première requête.
2. [Authentification](../developers/authentication) : stockez et envoyez vos clés en toute sécurité.
3. [Exemples](./examples) : copiez des modèles de requêtes dans votre application.

<Note>
Vous pouvez appeler les modèles `:free` sans déposer de crédits. Les modèles payants nécessitent toujours un solde disponible dans le portefeuille.
</Note>
