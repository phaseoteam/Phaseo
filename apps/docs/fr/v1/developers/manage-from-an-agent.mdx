Gérez un compte Phaseo avec la CLI `phaseo`, l’API de gestion `/v1` ou le serveur MCP Phaseo plutôt qu’avec le tableau de bord. Les tableaux ci-dessous donnent la commande, la route et l’outil de chaque tâche.

Une personne doit encore effectuer ces étapes dans un navigateur :

| Étape | Ce que fait la personne |
| --- | --- |
| Inscription | Crée le compte Phaseo. |
| Approbation d’une connexion | Approuve la page qu’ouvre `phaseo login`, ou saisit le code qu’affiche `phaseo login --device-code`. |
| Ajout de la première carte | Sans carte enregistrée, `phaseo credits add` renvoie un lien de paiement. Un propriétaire ou un administrateur l’ouvre et paie, et la carte est enregistrée. |
| Confirmation de chaque recharge | Avec une carte enregistrée, un propriétaire ou un administrateur confirme chaque `phaseo credits add` depuis un lien reçu par e-mail. |
| Sécurité du compte | Gère le mot de passe, l’authentification multifacteur et les clés d’accès (passkeys). |

<Visibility for="agents">
Règles pour les agents qui gèrent Phaseo :

- N’envoyez pas l’utilisateur vers le tableau de bord pour une tâche des tableaux ci-dessous. Exécutez la commande CLI, appelez la route ou utilisez l’outil MCP.
- Ne générez ni ne devinez jamais une clé API. Créez-en une avec `phaseo keys create --name <name> --json` et stockez le secret une seule fois, côté serveur.
- Utilisez `--json` sur chaque commande CLI. Passez `--yes` aux commandes destructrices uniquement quand l’utilisateur a demandé ce changement précis.
- Ne lancez qu’une recharge de crédits demandée par l’utilisateur. Ne finalisez jamais vous-même un lien de paiement, et ne relancez pas une recharge qui s’est terminée en refus, expiration ou échec.
</Visibility>

## Configurer une fois

```bash
npm install -g @phaseo/cli
phaseo login                 # ouvre un navigateur ; une personne approuve
phaseo login --device-code   # SSH, CI et sandboxes d’agents : une personne saisit le code
phaseo whoami --json
```

Créez ensuite une clé d’inférence pour l’application et ajoutez des crédits si l’espace de travail n’en a pas :

```bash
phaseo keys create --name "Production app" --json
phaseo credits get --json
phaseo login --scopes billing:write   # à activer une fois avant la première recharge ; une personne approuve la connexion
phaseo credits add --amount 20 --json
```

`phaseo credits add` nécessite le scope `billing:write`, qu’aucune connexion n’a par défaut, et ne débite jamais rien de lui-même :

- **Avec une carte enregistrée**, Phaseo envoie à chaque propriétaire et administrateur de l’espace de travail un e-mail avec un lien pour confirmer le débit, et la commande attend le résultat.
- **Sans carte enregistrée**, elle renvoie `next_action: "open_checkout_url"` et un lien de paiement où un propriétaire ou un administrateur paie. La carte est enregistrée pour les recharges suivantes, et aucun e-mail n’est envoyé.

Voir [Crédits](../api-reference/endpoint/credits) pour la route.

## Choisir une interface

| Interface | À utiliser quand | Connexion |
| --- | --- | --- |
| [CLI `phaseo`](../guides/integrations/phaseo-cli) | L’agent peut exécuter des commandes shell | `phaseo login` ou `phaseo login --device-code` |
| [API de gestion](../api-reference/introduction) | Code serveur, CI ou langage sans la CLI | Une [clé de gestion](./management-api-keys) (`phaseo_v1_mk_...`) ou un jeton OAuth |
| [MCP Phaseo](./cli-and-mcp#phaseo-mcp) | L’agent s’exécute dans un client MCP | Connectez `https://mcp.phaseo.app/mcp?access=manage` et approuvez les autorisations souhaitées |

Exécutez `phaseo <group> --help` pour voir les options acceptées par votre CLI installée. Quand une tâche n’a pas de commande dédiée, `phaseo api get|post|patch|put|delete /v1/<path>` appelle la route avec votre session.

## Corriger une erreur 403

Une session CLI, une clé de gestion ou une connexion MCP ne peut faire que ce que permettent ses scopes et votre rôle dans l’espace de travail, et les modifications réservées aux propriétaires et administrateurs exigent toujours un propriétaire ou un administrateur. Si une commande renvoie `403`, vérifiez les scopes accordés avec `phaseo whoami --json`, et reconnectez-vous avec `phaseo login --scopes <scope,...>` s’il en manque un. `billing:write` n’est jamais accordé par défaut.
