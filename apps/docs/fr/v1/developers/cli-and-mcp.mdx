Utilisez la CLI pour modifier Phaseo depuis un terminal ou un script, ou connectez un client IA au serveur MCP Phaseo pour lui donner des données Phaseo en direct. Les deux se connectent avec OAuth Phaseo.

| Interface | Pour | Accès |
| --- | --- | --- |
| [CLI Phaseo](#phaseo-cli) | Créer des clés, modifier des réglages, gérer des espaces de travail et automatiser l’administration depuis un shell ou la CI | Lecture et écriture, selon vos scopes et votre rôle dans l’espace de travail |
| [MCP Phaseo](#phaseo-mcp) | Donner à Codex, Claude, ChatGPT et aux autres clients MCP des données Phaseo en direct, et éventuellement les laisser gérer votre compte | Lecture seule, sauf si vous vous connectez avec la gestion du compte |
| [MCP de la documentation](#docs-mcp) | Donner à un assistant de codage la documentation Phaseo à jour | Documentation uniquement, sans accès au compte |
| [Plugin Phaseo](#phaseo-plugin) | Installer en une fois les deux serveurs MCP et les skills Phaseo dans Claude Code ou Codex | Identique à chaque serveur MCP |

<span id="phaseo-cli"></span>
## CLI Phaseo

### Installer et se connecter

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

Les terminaux interactifs utilisent par défaut OAuth dans le navigateur. Pour SSH, la CI et les environnements sans interface, utilisez l’autorisation par appareil :

```bash
phaseo login --device-code
```

### Workflows courants

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys list
phaseo logs list --since 1h --status error --json
```

Utilisez `--json` quand un autre outil ou script a besoin d’une sortie structurée. Les valeurs secrètes ne s’affichent qu’avec les commandes qui les créent ou les révèlent explicitement.

## MCP Phaseo

L’URL du serveur est `https://mcp.phaseo.app/mcp`. Un client IA qui y est connecté peut répondre aux questions avec des données en direct sur les modèles, les prix, les fournisseurs, l’utilisation et l’espace de travail.

### Connecter votre client

Installez-le en un clic : [Ajouter à Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=phaseo&config=eyJ1cmwiOiJodHRwczovL21jcC5waGFzZW8uYXBwL21jcCJ9) · [Ajouter à VS Code](vscode:mcp/install?%7B%22name%22%3A%22phaseo%22%2C%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fmcp.phaseo.app%2Fmcp%22%7D). Lorsque le client vous demande de vous connecter, Phaseo OAuth s'ouvre dans votre navigateur. Choisissez un workspace et approuvez les scopes de lecture demandés.

<Tabs>
<Tab title="Claude Code">
```bash
claude mcp add --transport http phaseo https://mcp.phaseo.app/mcp
```

Exécutez ensuite `/mcp`, sélectionnez `phaseo` puis **Authenticate**. Ajoutez `--scope user` pour le rendre disponible dans tous vos projets.
</Tab>
<Tab title="Codex">
```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
codex mcp list
```

La commande de connexion ouvre Phaseo OAuth. `codex mcp list` confirme la connexion.
</Tab>
<Tab title="Cursor">

Utilisez **Ajouter à Cursor** ci-dessus, ou ajoutez le serveur à `~/.cursor/mcp.json`, puis connectez-vous depuis les paramètres MCP de Cursor.
</Tab>

Utilisez **Ajouter à VS Code** ci-dessus, ou ajoutez le serveur à `.vscode/mcp.json`. Démarrez-le depuis la vue MCP et connectez-vous lorsque VS Code vous le demande.
</Tab>
<Tab title="Claude">
Dans Claude, ouvrez **Settings → Connectors**, choisissez **Add custom connector**, saisissez `Phaseo` et l'URL du serveur, puis sélectionnez **Connect**. Si l'option n'apparaît pas, un propriétaire de votre organisation Claude doit autoriser les connecteurs personnalisés.

Pour un autre client MCP, ajoutez la même URL comme serveur distant Streamable HTTP. Le client doit prendre en charge la découverte OAuth, le code d’autorisation avec PKCE S256 et le paramètre MCP `resource`.

### Utiliser votre connexion à la CLI Phaseo

Si vous utilisez déjà la CLI Phaseo, un agent local peut accéder au MCP par son intermédiaire sans seconde connexion :

```bash
phaseo login
claude mcp add --scope user phaseo -- phaseo mcp
# or, for Codex
codex mcp add phaseo -- phaseo mcp
```

`phaseo mcp` exécute le MCP sur stdio avec votre connexion à la CLI. Il échange cette connexion contre un jeton de 15 minutes qui ne fonctionne que sur le MCP, n’a jamais plus d’accès que votre connexion et n’autorise jamais d’appels payants aux modèles. Il est en lecture seule sauf si vous ajoutez `--manage`. `phaseo setup codex` l’ajoute pour vous au profil Phaseo de Codex. Quand un agent connecté ainsi lit des journaux, de l’activité ou des analyses, le résultat suggère aussi la commande CLI correspondante pour obtenir toutes les données.

### Ce que le MCP peut lire

Les outils en lecture seule couvrent les modèles, les fournisseurs, les classements de benchmarks, les prix et les estimations de coût, ainsi que les crédits, l’activité, les analyses, les journaux de requêtes et les métadonnées de génération. Ils ne renvoient jamais de prompts, de réponses ni de valeurs secrètes.

### Gérer votre compte (facultatif)

Pour permettre à un agent de modifier votre espace de travail Phaseo, connectez-vous plutôt avec l’URL de gestion :

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

À la connexion, l’écran de consentement liste chaque autorisation demandée par la connexion, par exemple gérer les clés API ou supprimer des budgets, et l’indique comme **Lecture**, **Écriture** ou **Supprimer**. Décochez celles que vous ne voulez pas accorder. L’agent n’obtient des outils que pour les autorisations accordées, et Phaseo vérifie toujours votre rôle dans l’espace de travail à chaque modification : un membre qui n’est ni propriétaire ni administrateur ne peut donc pas modifier ainsi les réglages réservés aux administrateurs.

Si vous êtes déjà connecté avec l’URL en lecture seule, passez le client à l’URL de gestion et reconnectez-vous. Pour revenir à un accès en lecture seule, reconnectez-vous avec l’URL simple ou révoquez l’application dans **Paramètres → Applications connectées**.

Une connexion de gestion lit tout ce qui figure ci-dessous, mais ne modifie que les clés API et les réglages de l’espace de travail. Les budgets, les règles de dépenses, les clés de fournisseur, les garde-fous, les préréglages, les webhooks et les destinations d’observabilité contrôlent les dépenses ou la destination du contenu des requêtes : vous les modifiez donc dans le tableau de bord ou avec une clé de gestion.

| Domaine | Lecture | Modification |
| --- | --- | --- |
| Clés API | `api_keys_list`, `api_key_get` | Avec `phaseo mcp --manage` : `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete`. Les autres clients peuvent renommer (`api_key_update`) et supprimer (`api_key_delete`) |
| Réglages | `settings_get` | `settings_update`, pour les modifications qui conservent ou renforcent la confidentialité, la journalisation et les restrictions de fournisseurs |
| Budgets | `budgets_list` | Dans le tableau de bord |
| Règles de dépenses | `spend_rules_list` | Dans le tableau de bord |
| Clés de fournisseur (BYOK) | `provider_keys_list` | Dans le tableau de bord |
| Garde-fous | `guardrails_list`, `guardrail_get` | Dans le tableau de bord |
| Préréglages | `presets_list`, `preset_get` | Dans le tableau de bord |
| Webhooks | `webhooks_list` | Dans le tableau de bord |
| Destinations d’observabilité | `observability_destinations_list` | Dans le tableau de bord |

Les outils qui modifient ou suppriment quelque chose sont signalés comme tels, afin que les clients MCP qui le prennent en charge vous demandent confirmation avant chaque appel. Une nouvelle clé API s’affiche une seule fois dans le résultat de l’outil et ne peut plus être affichée ensuite. Les clés de fournisseur enregistrées et les identifiants des destinations ne sont jamais renvoyés.

Le MCP n’a pas d’outils pour la facturation, les paiements, les espaces de travail, les membres, les clés de gestion ni les applications OAuth. Utilisez pour cela le tableau de bord, la CLI ou l’API de gestion.

## MCP de la documentation

Le MCP de la documentation est un endpoint distinct pour rechercher et lire la documentation Phaseo. Il n’accède ni à votre compte ni à votre espace de travail.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

<span id="phaseo-plugin"></span>
## Plugin Phaseo

Le plugin Phaseo regroupe le MCP Phaseo, le MCP de la documentation et les skills d’agent Phaseo pour l’intégration, la migration, le choix des modèles, le suivi de l’utilisation, les SDK et la CLI. Installez-le une fois au lieu de connecter chaque élément vous-même.

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

Exécutez `/mcp` et connectez-vous à `plugin:phaseo:phaseo` pour relier votre compte Phaseo. Les skills se chargent quand une demande leur correspond, ou vous pouvez en lancer un directement, par exemple `/phaseo:phaseo-gateway`.

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

La dernière commande ouvre OAuth Phaseo pour le MCP Phaseo. Les skills se chargent quand une demande leur correspond.
