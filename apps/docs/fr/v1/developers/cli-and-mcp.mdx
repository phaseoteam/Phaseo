# CLI et MCP

Utilisez Phaseo dans le terminal avec la CLI ou connectez un client IA via MCP. Les deux utilisent Phaseo OAuth, mais répondent à des besoins différents.

| Interface | Idéal pour | Accès |
| --- | --- | --- |
| Phaseo CLI | Workflows dans le terminal, CI, administration et automatisation | Lecture et écriture, selon vos portées et le rôle de votre espace de travail |
| Phaseo MCP | Données Phaseo en direct dans Codex, Claude, ChatGPT et d’autres clients MCP, et gestion du compte en option | Authentifié ; en lecture seule, sauf si vous vous connectez avec la gestion du compte |
| Docs MCP | Consulter la documentation Phaseo actuelle pendant le développement | Documentation uniquement et en lecture seule |
| Plugin Phaseo | Installer Phaseo MCP, Docs MCP et les skills Phaseo dans Claude Code ou Codex en une seule fois | Identique à chaque serveur MCP |

## Phaseo CLI

Utilisez la CLI pour créer ou modifier des ressources Phaseo, automatiser un workflow ou consulter les données du compte depuis un shell.

### Installer et se connecter

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

Par défaut, les terminaux interactifs utilisent OAuth dans le navigateur. Pour SSH, la CI et les environnements sans interface, utilisez l’autorisation par appareil :

```bash
phaseo login --device-code
```

### Workflows courants

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys create --name "Local development"
phaseo logs list --since 1h --status error --json
```

Utilisez `--json` lorsqu’un autre outil ou script a besoin d’une sortie structurée. Les valeurs secrètes ne sont affichées que par les commandes qui les créent ou les révèlent explicitement.

## Phaseo MCP

Connectez le serveur MCP Phaseo pour qu’un client IA réponde à partir des données en direct sur les modèles, les prix, les fournisseurs, l’utilisation et les espaces de travail.

### URL du serveur

`https://mcp.phaseo.app/mcp`

### Se connecter depuis Codex

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

La commande de connexion ouvre Phaseo OAuth. Choisissez un espace de travail, approuvez les portées de lecture demandées et confirmez la connexion :

```bash
codex mcp list
```

Pour un autre client MCP, ajoutez la même URL comme serveur HTTP distant en streaming. Le client doit prendre en charge la découverte OAuth, le code d’autorisation avec S256 PKCE et le paramètre MCP `resource`.

### Données accessibles via MCP

- modèles, fournisseurs, classements de benchmarks, tarifs et estimations de coût
- crédits, activité, analyses, journaux de requêtes et métadonnées de génération

Ces outils sont en lecture seule. Ils ne renvoient jamais de prompts, de réponses ni de valeurs secrètes.

### Gérer votre compte (facultatif)

Pour permettre à un agent de modifier votre espace de travail Phaseo, connectez-vous plutôt avec l’URL de gestion :

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

À la connexion, l’écran de consentement liste chaque autorisation demandée, par exemple gérer les clés API ou supprimer des budgets, et l’indique comme **Lecture**, **Écriture** ou **Suppression**. Décochez celles que vous ne voulez pas accorder. L’agent n’obtient des outils que pour les autorisations accordées, et Phaseo vérifie toujours votre rôle dans l’espace de travail à chaque modification : un membre qui n’est ni propriétaire ni administrateur ne peut donc pas modifier ainsi les paramètres réservés aux administrateurs.

Si vous êtes déjà connecté avec l’URL en lecture seule, passez le client à l’URL de gestion et reconnectez-vous. Pour revenir à un accès en lecture seule, reconnectez-vous avec l’URL normale ou révoquez l’application dans **Paramètres → Applications connectées**.

| Domaine | Outils | Autorisations |
| --- | --- | --- |
| Clés API | `api_keys_list`, `api_key_get`, `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete` | `keys:read`, `keys:write`, `keys:delete` |
| Budgets | `budgets_list`, `budget_create`, `budget_update`, `budget_delete` | `budgets:read`, `budgets:write`, `budgets:delete` |
| Règles de dépenses | `spend_rules_list`, `spend_rule_create`, `spend_rule_update`, `spend_rule_delete` | `spend_rules:read`, `spend_rules:write`, `spend_rules:delete` |
| Clés de fournisseur (BYOK) | `provider_keys_list`, `provider_key_create`, `provider_key_update`, `provider_key_delete` | `provider_credentials:read`, `provider_credentials:write`, `provider_credentials:delete` |
| Garde-fous | `guardrails_list`, `guardrail_get`, `guardrail_create`, `guardrail_update`, `guardrail_delete`, `guardrail_keys_set` | `guardrails:read`, `guardrails:write`, `guardrails:delete` |
| Préréglages | `presets_list`, `preset_get`, `preset_create`, `preset_update`, `preset_version_publish` | `presets:read`, `presets:write` |
| Paramètres | `settings_get`, `settings_update` (mode de routage, confidentialité et ZDR, journalisation, restrictions de fournisseurs) | `settings:read`, `settings:write` |
| Webhooks | `webhooks_list`, `webhook_create`, `webhook_delete` | `settings:read`, `settings:write` |
| Destinations d’observabilité | `observability_destinations_list`, `observability_destination_create`, `observability_destination_delete` | `settings:read`, `settings:write` |

Les outils qui modifient ou suppriment quelque chose sont signalés comme tels, afin que les clients MCP compatibles vous demandent confirmation avant chaque appel. Une nouvelle clé API ou un nouveau secret de signature de webhook n’est affiché qu’une seule fois dans le résultat de l’outil et ne peut plus être affiché ensuite. Les clés de fournisseur enregistrées et les identifiants des destinations ne sont jamais renvoyés.

MCP ne propose aucun outil pour la facturation, les paiements, les espaces de travail, les membres, les clés de gestion ou les applications OAuth. Utilisez pour cela le tableau de bord, la CLI ou l’API de gestion.

## Docs MCP

Docs MCP est un endpoint distinct pour rechercher et consulter la documentation Phaseo. Il n’accède ni à votre compte ni à votre espace de travail.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

Utilisez-le lorsqu’un assistant de programmation a besoin d’exemples API actuels, de conseils d’intégration ou de documentation sur les fonctionnalités.

## Plugin Phaseo

Le plugin Phaseo regroupe Phaseo MCP, Docs MCP et les skills Phaseo pour agents consacrées à l’intégration, à la migration, au choix des modèles, au suivi de l’utilisation, aux SDK et à la CLI. Installez-le une seule fois au lieu de connecter chaque élément vous-même.

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

Exécutez `/mcp` et connectez-vous à `plugin:phaseo:phaseo` pour relier votre compte Phaseo. Les skills se chargent lorsqu’une requête leur correspond, ou vous pouvez en lancer une directement, comme `/phaseo:phaseo-gateway`.

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

La dernière commande ouvre Phaseo OAuth pour Phaseo MCP. Les skills se chargent lorsqu’une requête leur correspond.

## Choisir la bonne interface

- Utilisez la **CLI** pour créer des clés, modifier des paramètres, gérer des espaces de travail ou automatiser des tâches administratives.
- Utilisez **Phaseo MCP** pour donner à un client IA un accès sécurisé aux données Phaseo en direct.
- Utilisez **Docs MCP** pour donner à un assistant de programmation accès à la documentation Phaseo actuelle sans lui ouvrir votre compte.
- Utilisez le **plugin Phaseo** pour configurer les deux serveurs MCP et les skills Phaseo dans Claude Code ou Codex en une seule fois.
