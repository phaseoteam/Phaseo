Stockez une clé Phaseo sur votre serveur, choisissez l’endpoint qui correspond au protocole de votre application, et faites pointer votre client HTTP ou votre SDK vers `https://api.phaseo.app/v1`. Commencez par le [Démarrage rapide](../quickstart.mdx) si vous n’avez pas encore envoyé de requête.

Il vous faut un compte Phaseo avec accès au Gateway et un client HTTP, un SDK compatible OpenAI ou un SDK Phaseo. Les exemples utilisent `google/gemma-3-27b:free`, qui s’exécute sans crédits déposés.

<Steps>
<Step title="Créer et stocker une clé">

Ouvrez **Paramètres → Clés API** dans le [tableau de bord](https://phaseo.app/settings/keys), ou appelez `POST /v1/keys` avec une clé de gestion. Nommez la clé d’après l’application et l’environnement, puis stockez-la dans un gestionnaire de secrets ou un fichier d’environnement :

```bash
# .env.local
PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
PHASEO_BASE_URL="https://api.phaseo.app/v1"
```

Utilisez des clés distinctes pour le développement local, les déploiements de prévisualisation et la production, afin de pouvoir faire tourner et examiner chacune séparément.

</Step>
<Step title="Choisir l’endpoint">

| Endpoint | À utiliser pour |
| --- | --- |
| `/v1/responses` | Les nouveaux développements texte, la sortie structurée et les workflows en plusieurs étapes. |
| `/v1/chat/completions` | Les interfaces de chat et les intégrations existantes de style OpenAI. |
| `/v1/messages` | Les intégrations compatibles Anthropic. |
| `/v1/decisions` | Les décisions typées sur l’état de l’application, avec Jev 1.13 (bêta). |
| `/v1/moderations` | Les contrôles de sécurité et de politique de contenu. |
| `/v1/images/generations` | Les images à partir de prompts texte. |

La [Référence API](../api-reference/introduction) liste chaque endpoint, paramètre et réponse.

</Step>
<Step title="Envoyer une requête depuis votre application">

Cet exemple utilise Chat Completions, que les clients compatibles OpenAI savent déjà appeler. Chaque requête envoie la clé sous la forme `Authorization: Bearer $PHASEO_API_KEY`.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemma-3-27b:free",
    "messages": [
      { "role": "system", "content": "You are a helpful assistant." },
      { "role": "user", "content": "Explain the benefits of AI." }
    ]
  }'
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});

const response = await client.chat.completions.create({
  model: "google/gemma-3-27b:free",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: "Explain the benefits of AI." },
  ],
});

console.log(response.choices[0]?.message?.content);
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.phaseo.app/v1",
)

response = client.chat.completions.create(
    model="google/gemma-3-27b:free",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain the benefits of AI."},
    ],
)

print(response.choices[0].message.content)
```

```go Go
package main

import (
  "context"
  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4"
)

func main() {
  client := phaseo.New("YOUR_API_KEY", "https://api.phaseo.app/v1")

  response, err := client.CreateChatCompletion(context.Background(), phaseo.ChatCompletionsRequest{
    Model: "google/gemma-3-27b:free",
    Messages: []map[string]interface{}{
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain the benefits of AI."},
    },
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(response)
}
```

<Note>
Les modèles dont l’ID se termine par `:free` s’exécutent sans crédits déposés. Les modèles payants nécessitent un solde de portefeuille disponible.
</Note>
