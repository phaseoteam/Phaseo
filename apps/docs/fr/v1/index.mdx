Utilisez cette page si vous savez ce que vous voulez créer, mais pas quelle page de documentation Phaseo consulter en premier.

Phaseo propose une API unique pour accéder aux modèles, router les requêtes vers les fournisseurs, consulter les tarifs, suivre l’utilisation et exécuter des workflows d’IA asynchrones.

Si vous découvrez Phaseo, commencez par envoyer une requête qui fonctionne. Si vous avez déjà une intégration IA, passez directement au guide de migration ou du SDK adapté à votre application.

## Réussir votre première requête

Pour une nouvelle intégration, suivez ces étapes :

1. Créez une clé API dans le tableau de bord.
2. Envoyez une requête à un modèle de texte disponible.
3. Lisez le texte généré dans la réponse.
4. Poursuivez avec le guide SDK, routage ou production qui correspond à votre besoin.

## Première requête

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-sol",
    "input": "Reply with: docs ready",
    "temperature": 0
  }'
```

```typescript TypeScript SDK
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-5.6-sol",
  input: "Reply with: docs ready",
  temperature: 0,
});

console.log(response.output_text);
```

```python Python SDK
from phaseo import Phaseo

client = Phaseo(api_key="YOUR_API_KEY")

response = client.generate_response(
    {
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with: docs ready",
        "temperature": 0,
    }
)

print(response.get("output_text"))
```
</CodeGroup>

Si cela fonctionne, poursuivez avec le [guide de démarrage rapide](./quickstart.mdx) pour suivre le parcours complet de première requête.
