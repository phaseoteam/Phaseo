Utilisez Phaseo pour appeler les modèles de plusieurs fournisseurs via une API, contrôler le routage et suivre l’utilisation et les coûts.

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "openai/gpt-6-astra", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // reads PHASEO_API_KEY

const response = await client.generateResponse({
  model: "openai/gpt-6-astra",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # reads PHASEO_API_KEY

response = client.responses.create({"model": "openai/gpt-6-astra", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

Pas encore de clé API ? [Créez-en une dans le tableau de bord](https://phaseo.app/fr-FR/settings/keys), puis suivez le [démarrage rapide](./quickstart.mdx).

## Choisir un modèle

[Parcourez les modèles](https://phaseo.app/models) ou [comparez-les](https://phaseo.app/compare). Le catalogue peut inclure des modèles non routables ; vérifiez leur disponibilité Gateway avant l’intégration. Consultez [Le fonctionnement de Phaseo](./developers/introduction.mdx) pour les modèles, fournisseurs et facturation.

Pour accéder à la documentation depuis un assistant, connectez [Docs MCP](./guides/integrations/docs-mcp.mdx) ou lisez le [résumé des capacités pour les agents](https://phaseo.app/docs/skill.md).
