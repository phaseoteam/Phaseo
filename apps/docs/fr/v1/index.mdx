Appelez les modèles de nombreux fournisseurs via une seule API à l’adresse `https://api.phaseo.app/v1`, choisissez comment chaque requête est routée, et suivez l’utilisation et le coût de chaque requête. Cette requête utilise `phaseo/free` : elle fonctionne avant même que vous ajoutiez des crédits.

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "phaseo/free", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // reads PHASEO_API_KEY

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # reads PHASEO_API_KEY

response = client.responses.create({"model": "phaseo/free", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

Pas encore de clé API ? [Créez-en une dans le tableau de bord](https://phaseo.app/settings/keys), puis suivez le [démarrage rapide](./quickstart.mdx).

## Choisir un modèle

[Parcourez les modèles](https://phaseo.app/models) ou [comparez-les](https://phaseo.app/compare). Le catalogue répertorie aussi des modèles que vous ne pouvez pas encore appeler : vérifiez donc qu’un modèle est **Actif sur Gateway** avant de l’intégrer, ou listez les modèles appelables avec `GET /v1/models`. Consultez [Le fonctionnement de Phaseo](./developers/introduction.mdx) pour les modèles, les fournisseurs et la facturation.
