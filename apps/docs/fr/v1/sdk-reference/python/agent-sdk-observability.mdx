description: "Diagnostiquez les échecs des agents Python, les données d’outils non valides et les exécutions interrompues."

Un résultat en échec conserve l’étape active, le nombre de nouvelles tentatives, l’identifiant de requête, l’identifiant de réponse natif, les métadonnées du fournisseur et les détails disponibles de la passerelle.

Vérifiez que :

- le processus a accès à `PHASEO_API_KEY`
- les identifiants des outils sont uniques
- les décisions d’approbation utilisent les identifiants exacts des appels
- l’état en pause est enregistré avant la reprise d’une autre requête
- les validateurs ne produisent pas d’effets de bord
- l’annulation interrompt les opérations réseau ou de stockage exécutées par les outils

Utilisez les événements de cycle de vie pour la télémétrie de l’application et DevTools pour inspecter les exécutions localement.
