| Modèle | À combiner |
| --- | --- |
| Extraction structurée | validation de sortie, schéma de réponse strict, nouvelles tentatives limitées |
| Triage des demandes d’assistance | routage prédéfini, outils de recherche, classification finale |
| Synthèse de recherche | recherche gérée, texte en flux, limites de coût |
| Assistant de programmation | outils de fichiers locaux, progression, approbation avant modification |

Commencez avec un agent, un ou deux outils déterministes et une approbation explicite pour les effets de bord.
