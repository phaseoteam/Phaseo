Le SDK est publié sous le nom [`phaseo`](https://pypi.org/project/phaseo/) sur PyPI.

## Installation

Installez le SDK avec le gestionnaire de paquets Python de votre choix :

<CodeGroup>

    ```bash title="pip"
    pip install phaseo
    ```

    ```bash title="uv"
    uv add phaseo
    ```

</CodeGroup>

## Prérequis

- Python 3.10+

## Configuration

### Clé API

Créez une clé API dans le [tableau de bord Phaseo](https://phaseo.app/gateway/keys).

### Variable d’environnement

```bash
export PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
```

### Utilisation de base

```python
from phaseo import Phaseo
import os

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])

response = client.generate_text(
    {
        "model": "openai/gpt-5-nano",
        "messages": [{"role": "user", "content": "Hello!"}],
    }
)

print(response["choices"][0]["message"]["content"])
```

### Configuration facultative du client

```python
from phaseo import Phaseo

client = Phaseo(
    api_key="your-api-key",
    base_url="https://api.phaseo.app/v1",
    timeout=30.0,
)
```
