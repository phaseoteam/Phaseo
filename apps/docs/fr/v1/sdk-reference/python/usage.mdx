## Configuration

```python
from phaseo import Phaseo

client = Phaseo(api_key="your-api-key")
```

## Complétions de chat

```python
completion = client.generate_text(
    {
        "model": "openai/gpt-4o-mini",
        "messages": [{"role": "user", "content": "Hi!"}],
    }
)

for chunk in client.stream_chat(
    {
        "model": "openai/gpt-4o-mini",
        "messages": [{"role": "user", "content": "Stream a story"}],
    }
):
    if chunk.get("text"):
        print(chunk["text"], end="", flush=True)
```

## Réponses

```python
resp = client.generate_response(
    {
        "model": "openai/gpt-4.1",
        "input": [{"role": "user", "content": [{"type": "input_text", "text": "Summarise"}]}],
    }
)

for chunk in client.stream_responses(
    {
        "model": "openai/gpt-4.1",
        "input": [{"role": "user", "content": [{"type": "input_text", "text": "Stream it"}]}],
    }
):
    if chunk.get("text"):
        print(chunk["text"], end="", flush=True)
```

## Messages (compatible avec Anthropic)

```python
message = client.generate_message(
    {
        "model": "anthropic/claude-3-5-sonnet-latest",
        "messages": [{"role": "user", "content": "Hello from messages API"}],
        "max_tokens": 128,
    }
)

for chunk in client.stream_message(
    {
        "model": "anthropic/claude-3-5-sonnet-latest",
        "messages": [{"role": "user", "content": "Stream a short hello"}],
        "max_tokens": 128,
        "stream": True,
    }
):
    if chunk.get("text"):
        print(chunk["text"], end="", flush=True)
```

## Traitement par lots

```python
batch = client.create_batch(
    {
        "endpoint": "responses",
        "input_file_id": "file_123",
        "completion_window": "24h",
        "session_id": "agent-run-42",
    }
)

status = client.get_batch(batch["id"])
```

## Gestion des erreurs

```python
try:
    client.generate_text({"model": "invalid", "messages": []})
except Exception as exc:
    print(f"API error: {exc}")
```

from phaseo import Phaseo

client = Phaseo(
