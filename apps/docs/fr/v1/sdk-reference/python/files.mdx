title: "Fichiers"
description: "Appelez `/files` avec le SDK Python."
---

**Méthodes** : `client.upload_file()`, `client.list_files()`, `client.get_file()`, `client.get_file_content()`.

```python
uploaded = client.upload_file(
    purpose="batch",
    file="data:application/json;base64,eyJ0ZXN0Ijp0cnVlfQ==",
)
file_obj = client.get_file(uploaded["id"])
file_bytes = client.get_file_content(uploaded["id"])

print(uploaded)
print(file_obj)
print(file_bytes[:20])
```

<Note>
  `list_files()` est disponible dans le SDK, mais `GET /files` renvoie actuellement `file_list_not_supported_with_shared_gateway_key`
  avec la clé partagée de la passerelle. Conservez les identifiants des fichiers importés et récupérez-les directement.
</Note>
