Choisissez l’exemple le plus simple qui correspond au produit que vous créez. Chaque modèle conserve la persistance et l’interface utilisateur dans votre application et utilise Phaseo pour les tours du modèle.

## Exemples inclus dans le package

| Exemple | Utilisation |
| --- | --- |
| `research-brief-agent.ts` | Effectuer des recherches avec la recherche gérée et produire un résumé final typé |
| `support-triage-agent.ts` | Acheminer et classer les demandes d’assistance avec un préréglage géré |
| `coding-review-agent.ts` | Examiner du code avec des outils d’exécution locaux |
| `parallel-tool-agent.ts` | Exécuter simultanément des outils locaux indépendants |
