**Méthode** : `client.getGeneration()`.

### Exemple
```typescript
const record = await client.getGeneration("G-01ABC...");
```

### Paramètres
- `id` (chaîne, obligatoire) : ID de requête renvoyé par un appel précédent.

### Retour
Enregistrement de génération (JSON)

Si la passerelle a stocké tous les détails de la requête, l’enregistrement renvoyé inclut `replay_supported` et `replay_request`. Vous pouvez envoyer `replay_request` au point de terminaison d’origine pour la relancer de manière contrôlée.

Les champs temporels suivent les conventions communes de la passerelle :

- `latency_ms` : délai avant le premier jeton ou le premier octet/fragment de sortie, s’il est suivi
- `generation_ms` : durée de génération après la latence, si elle est suivie
