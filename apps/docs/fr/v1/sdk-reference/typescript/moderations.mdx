**Méthode** : `client.generateModeration()`.

### Exemple
```typescript
const moderation = await client.generateModeration({
  model: "openai/omni-moderation-latest",
  input: "Text to classify",
});
```

### Paramètres clés
- `model` (obligatoire) : ID du modèle de modération (par exemple, `openai/omni-moderation-latest`).
- `input` (obligatoire) : chaîne ou tableau d’éléments de contenu (texte ou `image_url`).
- Facultatif : filtres `categories`/`severity` (si pris en charge) et étiquette `user`.
