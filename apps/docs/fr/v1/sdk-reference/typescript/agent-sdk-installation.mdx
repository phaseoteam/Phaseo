Le SDK Agent est publié sur npm sous le nom [`@phaseo/agent-sdk`](https://www.npmjs.com/package/@phaseo/agent-sdk).

## Prérequis

- un projet TypeScript ou JavaScript utilisant npm, pnpm, Yarn ou Bun
- une clé API Phaseo

## Installation

Installez le SDK Agent avec le gestionnaire de paquets de votre choix :

<CodeGroup>

    ```bash title="npm"
    npm install @phaseo/agent-sdk
    ```

    ```bash title="pnpm"
    pnpm add @phaseo/agent-sdk
    ```

    ```bash title="yarn"
    yarn add @phaseo/agent-sdk
    ```

    ```bash title="bun"
    bun add @phaseo/agent-sdk
    ```

</CodeGroup>

Le package principal `@phaseo/sdk` est installé automatiquement comme dépendance.

## Environnement

Définissez votre clé API de la passerelle avant d’exécuter les exemples :

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
