<Note type="warning">Le SDK C++ est en cours de développement et n’est pas encore publié dans un registre de packages.</Note>

## Utilisation locale

- Utilisez les en-têtes générés dans `packages/sdk/sdk-cpp/src/gen`.
- Ajoutez ce dossier au chemin d’inclusion de votre système de build.
- Le client est actuellement uniquement composé d’en-têtes.
