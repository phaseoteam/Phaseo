Le SDK est publié sous le nom [`phaseo/sdk`](https://packagist.org/packages/phaseo/sdk) sur Packagist.

## Prérequis

- PHP 8.1 ou version ultérieure
- Composer

## Installation

```bash
composer require phaseo/sdk
```
