**Méthode** : `$client->generateImageEdit(...)` ou `$client->createImageEdit(...)`

### Exemple

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo(getenv('PHASEO_API_KEY'));
$response = $client->generateImageEdit([
    'model' => 'openai/gpt-image-1',
    'prompt' => 'Make it sunset',
    'image' => 'data:image/png;base64,...',
    'mask' => 'data:image/png;base64,...'
]);
echo $response['data'][0]['url'] ?? '';
```

### Paramètres principaux

-   `model` (obligatoire) : identifiant d’un modèle capable de retoucher des images.
-   `image` (obligatoire) : URL de données Base64 ou URL de l’image source.
-   `prompt` : nouvelle instruction facultative pour la retouche.
-   `mask` : masque facultatif (les zones transparentes sont modifiées).
-   `n` (1–10) : nombre de variantes retouchées.
-   `size` : par exemple, `1024x1024`, `1024x1792` ou `1792x1024`.
-   `response_format` : `url` ou `b64_json`.
-   `user` : étiquette facultative pour l’utilisateur final.

### Valeur renvoyée

ImageGenerationResponse
