description: "Limitez les exécutions des agents PHP par nombre d’étapes, jetons, coût, durée, outils ou motif de fin."
---

Combinez des fonctions d’arrêt pour appliquer les limites du produit indépendamment de la décision du modèle de continuer.

```php
$agent = AgentSdk::createAgent(new AgentDefinition(
    id: "bounded-research",
    model: "openai/gpt-5.4-nano",
    stopWhen: [
        AgentSdk::stepCountIs(12),
        AgentSdk::maxTokensUsed(40000),
        AgentSdk::maxCost(2.50),
        AgentSdk::maxDuration(120000),
    ]
));
```

Le SDK propose également des conditions pour les appels d’outils et les motifs de fin. Après l’exécution, inspectez `$result->run->stopReason` et l’utilisation normalisée afin que l’application distingue un arrêt budgétaire d’une fin normale du modèle.

L’arrêt est un résultat borné, pas automatiquement une exception. Déterminez quels motifs d’arrêt votre produit considère comme réussis, réessayables ou visibles par l’utilisateur.
