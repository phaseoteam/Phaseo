---

**Méthodes**: `generateText()`, `createChatCompletion()`

### Exemple

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo(apiKey: $apiKey);

$response = $client->createChatCompletion([
    'model' => 'openai/gpt-4o-mini',
    'messages' => [[
        'role' => 'user',
        'content' => 'Write a limerick about lighthouses.',
    ]],
    'temperature' => 0.5
]);
echo $response['choices'][0]['message']['content'];
```

### Paramètres clés

- `model` (obligatoire) : ID du modèle cible.
- `messages` (obligatoire) : messages ordonnés avec les rôles `system|user|assistant|tool` ; le contenu utilise des objets MessageContent.
- Échantillonnage : `temperature` (0–2), `top_p` (0–1), `top_k` (>=1), `seed` (int, facultatif).
- Longueur et pénalités : `max_output_tokens` (int), `presence_penalty` et `frequency_penalty` (-2 à 2), `stop` (string|string[]).
- Outils : `tools` (définitions), `tool_choice` (automatique/aucun/outil spécifique), `max_tool_calls` (int), `parallel_tool_calls` (bool).
- Logprobs : `logprobs` (bool), `top_logprobs` (0–20).
- Sortie : `response_format` (json/text), `meta` (bool pour inclure le bloc meta), `stream` (bool), `service_tier`.
- Options supplémentaires de la passerelle : `usage` (bool pour demander l’utilisation).
