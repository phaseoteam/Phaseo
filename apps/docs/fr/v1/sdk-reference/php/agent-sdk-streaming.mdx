`Agent::stream(...)` renvoie un `AgentStreamResult` :

```php
$stream = $agent->stream($input, $client);

foreach ($stream->textStream() as $delta) {
    echo $delta;
}

$completed = $stream->result;
```

Utilisez `reasoningStream()`, `itemStream()` ou `fullStream()` pour obtenir d’autres projections. Chaque itérable peut être relu après la consommation des événements du flux synchrone du fournisseur.

Les valeurs d’élément PHP restent des tableaux et des objets génériques, et non l’union discriminée d’éléments de TypeScript.
