title: "Fichiers"
description: "Utilisez le SDK PHP pour importer des fichiers, consulter leurs métadonnées et récupérer leur contenu."
---

**Méthodes** : `uploadFile()`, `listFiles()`, `retrieveFile()`, `retrieveFileContent()`

### Exemple

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo(apiKey: $apiKey);

$uploaded = $client->uploadFile([
    'purpose' => 'batch',
    'file' => 'data:application/json;base64,eyJ0ZXN0Ijp0cnVlfQ==',
]);

$file = $client->retrieveFile('file_123');
$content = $client->retrieveFileContent('file_123');
```

<Note>
`listFiles()` est disponible dans le SDK, mais `GET /files` renvoie actuellement `file_list_not_supported_with_shared_gateway_key` avec la clé de passerelle partagée
Conservez les identifiants des fichiers importés et récupérez-les directement.
</Note>
