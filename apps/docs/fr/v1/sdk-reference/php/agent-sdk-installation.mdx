Le SDK Agent est publié sous le nom [`phaseo/agent-sdk`](https://packagist.org/packages/phaseo/agent-sdk) sur Packagist.

## Prérequis

- PHP 8.1 ou version ultérieure
- Composer
- une clé API Phaseo

## Installation

```bash
composer require phaseo/agent-sdk
```

Le package principal `phaseo/sdk` est installé automatiquement comme dépendance.

## Environnement

Définissez votre clé API Gateway avant d’exécuter les exemples :

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
