| API | Fonction |
| --- | --- |
| `AgentSdk::createAgent(...)` | Définir un agent |
| `AgentSdk::defineTool(...)` | Définir un outil local ou manuel |
| `AgentSdk::createGatewayAgentClient(...)` | Relier les tours du modèle à Phaseo |
| `Agent::run(...)` | Exécuter jusqu’à la fin ou la mise en pause |
| `Agent::stream(...)` | Exécuter avec des itérables pouvant être relus |
| `Agent::continueRun(...)` | Reprendre un état enregistré ou en pause |
| `Agent::continueRunById(...)` | Recharger et reprendre via un accesseur d’état |
| `AgentStreamResult::textStream()` | Lire les fragments de texte |
| `AgentStreamResult::fullStream()` | Lire tous les événements |

Les principales classes incluent `AgentDefinition`, `RunResult`, `RunRecord`, `Tool`, `ToolDecision`, `ToolOutput`, `RuntimeContext`, `StateAccessor` et `GatewayAgentClientOptions`.
