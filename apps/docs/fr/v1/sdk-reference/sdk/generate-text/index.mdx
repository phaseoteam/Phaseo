Appelez `generateText` avec `phaseo(modelId)` pour obtenir une réponse complète.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a concise summary of Phaseo Gateway.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

## Envoyer un historique de conversation

Utilisez `prompt` pour un seul tour et `messages` quand vous avez besoin de plusieurs tours ou d’un rôle système.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "system", content: "You are a terse assistant." },
    { role: "user", content: "Give me three bullet points on retrieval augmentation." },
  ],
});

console.log(result.text);
console.log(result.providerMetadata);
```

## Définir des valeurs par défaut sur le modèle

Passez des réglages en second argument de `phaseo()`. Ils s’appliquent à chaque appel qui utilise cette instance de modèle.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra", {
    maxTokens: 300,
  }),
  prompt: "Draft a release note for an API update.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

Les ID de modèles ont la forme `provider/model`. Pour qu’ils restent à jour, lisez-les depuis `/v1/models` ; consultez [Découverte des modèles](/fr/v1/sdk-reference/sdk/get-models).
