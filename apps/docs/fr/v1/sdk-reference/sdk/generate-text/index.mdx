Utilisez `generateText` avec `phaseo(modelId)` pour obtenir une réponse en un seul appel.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-5-nano"),
  prompt: "Write a concise summary of Phaseo Gateway.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

## Avec l’historique de chat

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-5-nano"),
  messages: [
    { role: "system", content: "You are a terse assistant." },
    { role: "user", content: "Give me three bullet points on retrieval augmentation." },
  ],
});

console.log(result.text);
console.log(result.providerMetadata);
```

## Paramètres propres au modèle

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-5-nano", {
    temperature: 0.2,
    topP: 0.9,
    maxTokens: 300,
  }),
  prompt: "Draft a release note for an API update.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

## Prompt ou messages

- Utilisez `prompt` pour les requêtes rapides en un seul tour.
- Utilisez `messages` pour le contexte sur plusieurs tours et le contrôle des rôles.
- Interrogez `/v1/models` pour tenir les ID de modèle à jour (voir [Découverte des modèles](../get-models/index.mdx)).
