Passez `phaseo.embeddingModel(modelId)` (ou son alias `textEmbeddingModel`) à `embed` pour une seule valeur ou à `embedMany` pour une liste. Les requêtes sont envoyées à l’endpoint `/v1/embeddings` du Gateway.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { embed, embedMany } from "ai";

const single = await embed({
  model: phaseo.textEmbeddingModel("google/gemini-embedding-001"),
  value: "Embeddings power semantic search.",
});

console.log(single.embedding.length);

const batch = await embedMany({
  model: phaseo.textEmbeddingModel("google/gemini-embedding-001"),
  values: ["pricing", "latency", "quality"],
});

console.log(batch.embeddings.length);
```

## Garder des vecteurs comparables

- Générez les embeddings des requêtes et du corpus avec la même version de modèle.
- Normalisez les vecteurs de façon cohérente avant de calculer la similarité.
- Mettez en cache les embeddings stables des contenus répétés.
