Installez `@phaseo/ai-sdk-provider` et passez `phaseo(modelId)` comme `model` à `generateText`, `streamText` ou toute autre fonction de Vercel AI SDK 7. Les requêtes texte sont envoyées à l’endpoint `/v1/chat/completions` du Gateway.

## Installer

<CodeGroup>

```bash title="npm"
npm install @phaseo/ai-sdk-provider
```

```bash title="pnpm"
pnpm add @phaseo/ai-sdk-provider
```

```bash title="yarn"
yarn add @phaseo/ai-sdk-provider
```

```bash title="bun"
bun add @phaseo/ai-sdk-provider
```

</CodeGroup>

Le paquet sans version installe le tag npm `latest`, qui correspond à la ligne AI SDK 7. Il déclare `ai@^7` comme dépendance pair : les gestionnaires de paquets qui installent automatiquement les dépendances pairs l’ajoutent pour vous.

Définissez `PHASEO_API_KEY` dans l’environnement de votre serveur, puis envoyez votre première requête. L’export par défaut `phaseo` lève une erreur si `PHASEO_API_KEY` n’est pas défini.

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Reply with: AI SDK works",
});

console.log(result.text);
console.log(result.providerMetadata);
```

Utilisez un ID de modèle actuel issu de l’[endpoint Models](../../api-reference/endpoint/models.mdx).

## Streamer du texte

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Stream a short greeting.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Configurer une instance du fournisseur

Appelez `createPhaseo()` pour définir `apiKey`, `baseURL`, `headers` ou un `fetch` personnalisé. Utilisez-le pour identifier votre application dans les détails des requêtes Phaseo :

```typescript
import { createPhaseo } from "@phaseo/ai-sdk-provider";

const phaseo = createPhaseo({
  apiKey: process.env.PHASEO_API_KEY,
  headers: {
    "x-title": "My App",
    "http-referer": "https://example.com",
  },
});
```

`PHASEO_BASE_URL` est facultatif et vaut par défaut `https://api.phaseo.app/v1`.

## Choisir un type de modèle

| Méthode du fournisseur | Fonction AI SDK |
| --- | --- |
| `phaseo(modelId)` ou `phaseo.languageModel(modelId)` | `generateText`, `streamText` |
| `phaseo.embeddingModel(modelId)` (alias `textEmbeddingModel`) | `embed`, `embedMany` |
| `phaseo.imageModel(modelId)` | `generateImage` |
| `phaseo.transcriptionModel(modelId)` | `transcribe` |
| `phaseo.speechModel(modelId)` | `generateSpeech` |
| `phaseo.rerankingModel(modelId)` | `rerank` |

Toutes les méthodes sauf `rerankingModel` acceptent en second argument des réglages facultatifs par modèle : `temperature`, `topP`, `topK`, `maxTokens`, `frequencyPenalty`, `presencePenalty`, `seed`, `user`, `headers` et `fetch`.

## Fonctionnalités d’AI SDK 7 prises en charge

- Génération de texte et streaming
- Sortie et réglages de raisonnement
- Outils de type fonction et entrées d’outil streamées
- Sortie JSON et JSON Schema
- Entrées de fichiers texte et image
- Sources de citation par URL
- Embeddings et génération d’images
- Reclassement
- Transcription et synthèse vocale
- Métadonnées du fournisseur, utilisation, signaux d’abandon et fragments de flux bruts

Ce qu’un appel peut faire dépend toujours du modèle et du fournisseur. Le fournisseur n’annonce ni références de fichiers gérées, ni skills, ni outils exécutés par le fournisseur (leurs définitions, résultats ou réponses d’approbation). Les outils de type fonction exécutés par votre application suivent le flux d’exécution et d’approbation habituel d’AI SDK.

## Utiliser une version antérieure d’AI SDK

| AI SDK | Installation |
| --- | --- |
| 7 | `@phaseo/ai-sdk-provider` (`latest`) |
| 6 | `@phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `@phaseo/ai-sdk-provider@ai-sdk-v5` |

Si l’installation automatique des dépendances pairs est désactivée, installez vous-même la version majeure correspondante de `ai` (`ai@^7`, `ai@^6` ou `ai@^5`).
