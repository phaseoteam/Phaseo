Passez `phaseo.transcriptionModel(modelId)` à `transcribe` pour la reconnaissance vocale, et `phaseo.speechModel(modelId)` à `generateSpeech` pour la synthèse vocale. Le fournisseur envoie l’audio à `/v1/audio/transcriptions` sous forme de formulaire multipart et envoie les requêtes de synthèse à `/v1/audio/speech`.

```ts
import { readFileSync, writeFileSync } from "node:fs";
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateSpeech, transcribe } from "ai";

const transcription = await transcribe({
  model: phaseo.transcriptionModel("openai/whisper-1"),
  audio: readFileSync("./audio.mp3"),
});

console.log(transcription.text);
console.log(transcription.providerMetadata);

const speech = await generateSpeech({
  model: phaseo.speechModel("openai/gpt-4o-mini-tts"),
  text: "Hello from Phaseo audio.",
  voice: "alloy",
  outputFormat: "mp3",
});

writeFileSync("./speech.mp3", Buffer.from(speech.audio.uint8Array));
console.log(speech.providerMetadata);
```

`audio` accepte un `Buffer`, un `Uint8Array`, un `ArrayBuffer`, une chaîne base64 ou une `URL`. AI SDK 7 exporte encore les anciens noms `experimental_transcribe` et `experimental_generateSpeech` comme alias.

## Gérer l’audio long ou en échec

- Les formats d’entrée et de sortie pris en charge dépendent du modèle.
- Augmentez les délais d’expiration pour les fichiers longs et respectez la taille maximale d’envoi du modèle (25 Mo pour la plupart des modèles).
- Relancez les réponses `429` et `5xx` transitoires avec un délai progressif.
