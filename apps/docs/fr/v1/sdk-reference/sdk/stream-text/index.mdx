Appelez `streamText` avec `phaseo(modelId)` et lisez `textStream` pour recevoir le texte au fur et à mesure. `streamText` rend la main immédiatement ; lisez `providerMetadata` une fois le flux terminé.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Streamer à partir d’un historique de conversation

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## Arrêter un flux abandonné

Passez un `abortSignal` à `streamText` et déclenchez l’abandon quand l’utilisateur part ou qu’un délai expire, pour que la requête ne continue pas de tourner :

```ts
const controller = new AbortController();
setTimeout(() => controller.abort(), 60_000);

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a long report.",
  abortSignal: controller.signal,
});
```

Lisez les ID de modèles depuis `/v1/models` plutôt que de les coder en dur ; consultez [Découverte des modèles](/fr/v1/sdk-reference/sdk/get-models).
