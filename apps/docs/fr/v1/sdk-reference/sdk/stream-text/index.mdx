Utilisez `streamText` pour recevoir les jetons au fur et à mesure de leur arrivée.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Streaming avec des messages

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## Conseils pour la production

- Privilégiez le streaming pour les réponses longues et les interfaces interactives.
- Gérez l’annulation et les délais d’attente dans votre environnement d’exécution pour les flux abandonnés.
- Actualisez les ID de modèle via `/v1/models` pour éviter les alias obsolètes.
