Passez `phaseo.imageModel(modelId)` à `generateImage`. Les requêtes sont envoyées à l’endpoint `/v1/images/generations` du Gateway.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateImage } from "ai";

const result = await generateImage({
  model: phaseo.imageModel("openai/gpt-image-1"),
  prompt: "A minimalist poster of a lighthouse at dawn.",
  size: "1024x1024",
});

console.log(result.images[0].mediaType);
console.log(result.images[0].uint8Array.length);
console.log(result.providerMetadata);
```

## Lire le résultat

Les images que le Gateway renvoie sous forme d’URL sont converties au format de fichier d’AI SDK : lisez donc `uint8Array` et `mediaType` sur chaque image, quel que soit le format renvoyé par le fournisseur.

- Les valeurs de `size` disponibles dépendent du modèle.
- Pour reproduire une image plus tard, stockez le prompt, le modèle et les paramètres avec les métadonnées de l’image.
