Passez `output: Output.object({ schema })` à `generateText` pour obtenir un objet typé conforme à votre schéma. AI SDK envoie le schéma comme format de réponse JSON Schema et valide le résultat.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, Output } from "ai";
import { z } from "zod";

const { output } = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  output: Output.object({
    schema: z.object({
      title: z.string(),
      priority: z.enum(["low", "medium", "high"]),
      actions: z.array(z.string()),
    }),
  }),
  prompt: "Create a short incident follow-up plan.",
});

console.log(output);
```

`generateObject` fonctionne toujours dans AI SDK 7 avec le même `schema` et renvoie `object`, mais il est déprécié au profit de `generateText` avec `output`.

## Gérer une sortie invalide

La lecture de `output` lève `NoOutputGeneratedError` quand le modèle ne renvoie aucun objet exploitable, par exemple quand la dernière étape s’est terminée par un appel d’outil. Interceptez cette erreur là où vous appelez le modèle.

- Utilisez des enums explicites et des champs obligatoires dans le schéma.
- Gardez le prompt cohérent avec la forme du schéma.
- La prise en charge de la sortie JSON Schema varie selon les modèles ; vérifiez les paramètres pris en charge par le modèle dans `/v1/models`.
