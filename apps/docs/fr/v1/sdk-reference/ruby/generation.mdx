title: "Récupération d’une génération"
description: "Appelez /generations pour récupérer une génération précédente."
---

**Méthode**: `client.get_generation(...)`

### Exemple

```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))

record = client.get_generation('G-01ABC...')
```

### Paramètres

- `id` (chaîne, obligatoire) : ID de requête renvoyé par un appel précédent.

### Renvoie

Enregistrement de génération (JSON)

Si la passerelle a enregistré tous les détails de la requête, l’enregistrement renvoyé inclut également `replay_supported` et `replay_request`, ce qui permet de renvoyer la charge utile capturée au point de terminaison d’origine pour une nouvelle exécution contrôlée.

Les champs temporels suivent la sémantique commune de la passerelle :

- `latency_ms`: temps jusqu’au premier jeton ou au premier octet/à la première image de sortie, lorsqu’il est mesuré
- `generation_ms`: temps de génération après la latence, lorsqu’il est mesuré
