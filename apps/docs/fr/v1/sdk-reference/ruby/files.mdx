icon: "files"
title: "Fichiers"
description: "Utilisez le SDK Ruby pour importer des fichiers, consulter leurs métadonnées et récupérer leur contenu."
---

**Méthodes** : `upload_file`, `list_files`, `retrieve_file`, `retrieve_file_content`.

### Exemple
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch('PHASEO_API_KEY'))

uploaded = client.upload_file(
  'purpose' => 'batch',
  'file' => 'data:application/json;base64,eyJ0ZXN0Ijp0cnVlfQ=='
)

file = client.retrieve_file('file_123')
content = client.retrieve_file_content('file_123')
```

<Note>
`list_files` est disponible dans le SDK, mais `GET /files` renvoie actuellement `file_list_not_supported_with_shared_gateway_key` avec la clé de passerelle partagée
Conservez les identifiants des fichiers importés et récupérez-les directement.
</Note>
