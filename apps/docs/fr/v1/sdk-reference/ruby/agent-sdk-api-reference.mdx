| API | Fonction |
| --- | --- |
| `PhaseoAgentSdk.create_agent(...)` | Définir un agent |
| `PhaseoAgentSdk.define_tool(...)` | Définir un outil local ou manuel |
| `PhaseoAgentSdk.create_gateway_agent_client(...)` | Relier les tours du modèle à Phaseo |
| `Agent#run` | Exécuter jusqu’à la fin ou la mise en pause |
| `Agent#stream` | Exécuter avec des séquences pouvant être relues |
| `Agent#continue_run` | Reprendre un état enregistré ou en pause |
| `StreamResult#result` | Lire l’exécution terminée |
| `StreamResult#text_stream` | Lire les fragments de texte |
| `StreamResult#full_stream` | Lire tous les événements |

Les classes et valeurs importantes incluent `Tool`, `ToolDecision`, `ToolOutput`, `RuntimeContext`, `RunResult`, la configuration des nouvelles tentatives, la configuration d’exécution des outils et les accesseurs d’état.
