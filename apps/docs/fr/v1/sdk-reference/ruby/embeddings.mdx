**Méthodes** : `client.generate_embedding(...)` ou `client.create_embedding(...)`.

### Exemple

```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
embedding = client.generate_embedding(
  model: 'openai/text-embedding-3-large',
  input: 'Sample text'
)
```

### Paramètres principaux

-   `model` (obligatoire) : identifiant du modèle d’embeddings (par exemple, `openai/text-embedding-3-large`).
-   `input` (obligatoire) : une chaîne ou un tableau de chaînes.
-   `encoding_format` : `float` (par défaut) ou `base64`.
-   `dimensions` : entier facultatif pour réduire la longueur de l’embedding (selon le modèle).
-   `user` : étiquette facultative pour l’utilisateur final.

### Valeur renvoyée

Charge utile d’embeddings (JSON)
