**Méthode** : `client.list_models(...)`.

### Exemple
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
models = client.list_models(
  limit: "5",
  provider: "anthropic",
  provider_status: "beta,not_ready",
  provider_availability_reason: "preview_only,provider_not_ready",
  capability_status: "coming_soon,internal_testing",
  availability: "all",
)
```

### Paramètres clés
- `provider` (facultatif) : filtrer par fournisseur
- `provider_status` / `provider_routing_status` / `model_routing_status` (facultatif) : filtrer par état de déploiement et de routage
- `capability_status` / `provider_availability_status` / `provider_availability_reason` (facultatif) : filtrer par capacité et disponibilité
- `provider_availability_reason` est utile avec `availability: "all"` pour rechercher des états de déploiement tels que `preview_only`, `provider_not_ready`, `gated`, `access_limited`, `region_limited`, `project_limited`, `paused` ou `soft_blocked`
- `capability_status` est utile avec `availability: "all"` pour rechercher les correspondances de points de terminaison non routables, comme `coming_soon` ou `internal_testing`
- `status` (facultatif) : filtrer par état du cycle de vie du modèle
- `organisation` (facultatif) : filtrer par organisation
- `endpoints` (facultatif) : tableau de points de terminaison
- `input_types` / `output_types` / `params` (facultatif) : filtres de capacité
- `availability` (facultatif) : `active` ou `all`
- `limit` (facultatif) : nombre
- `offset` (facultatif) : nombre d’éléments à ignorer
