**Méthodes** : `client.generate_response(...)`, `client.create_response(...)`.

### Exemple
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))

resp = client.create_response(
  "model" => "openai/gpt-4.1",
  "input" => [{ "role" => "user", "content" => [{ "type" => "input_text", "text" => "Summarise this text" }] }],
  "temperature" => 0.7
)
```

### Paramètres principaux
- `model` (obligatoire) : identifiant du modèle cible.
- `input` (obligatoire) : tableau ordonné d’éléments d’entrée, comme des messages et des appels d’outils.
- `temperature` (0–2) : plus la valeur est élevée, plus le résultat est aléatoire.
- `top_p` (0–1) / `top_k` (>=1) : contrôles d’échantillonnage par noyau et par k meilleures options.
- `max_output_tokens` (entier) : limite strict de jetons générés par réponse ; utilisez `max_output_tokens_per_message` pour limiter chaque message.
- Outils : `tools` (définitions), `tool_choice` (automatique/aucun/spécifique), `max_tool_calls` (entier), `parallel_tool_calls` (booléen).
- Logprobs : `logprobs` (booléen), `top_logprobs` (0–20) pour renvoyer les probabilités logarithmiques de chaque jeton.
- Sortie : `response_format` (json/text), `service_tier`, `store` (booléen), `stream` (booléen).
- Métadonnées : `metadata` (objet transmis tel quel), `reasoning` (objet contenant des indications d’effort).
- Options supplémentaires de la passerelle : `usage` (booléen pour demander l’utilisation), `meta` (booléen pour inclure le bloc meta).

### Valeur renvoyée
`ResponsesResponse`
