Ruby Agent SDK est un environnement d’exécution local complet pour les agents de Phaseo Gateway. Il inclut des nouvelles tentatives, des outils concurrents, des délais d’attente, une validation humaine, un état reprenable, des événements de cycle de vie et la capture DevTools.

Utilisez-le lorsque vous avez besoin :

- une boucle d’outils légère et limitée
- des requêtes `responses` via la passerelle
- la maîtrise de la persistance et de l’orchestration par l’application

## Fonctionnalités fournies

- `PhaseoAgentSdk.create_agent(...)`
- `PhaseoAgentSdk.define_tool(...)`
- `PhaseoAgentSdk.create_gateway_agent_client(...)`
- une boucle d’outils limitée au-dessus de l’API `responses` de Phaseo
