Le SDK est publié sous le nom [`phaseo_sdk`](https://rubygems.org/gems/phaseo_sdk) sur RubyGems.

## Prérequis

- Ruby 3.1 ou version ultérieure

## Installation

```bash
gem install phaseo_sdk
```

Ou ajoutez-le à votre `Gemfile` :

```ruby
gem "phaseo_sdk"
```
