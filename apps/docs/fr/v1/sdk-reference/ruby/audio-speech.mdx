description: "Appelez `/audio/speech` avec le SDK Ruby."
---

**Méthode** : `client.generate_speech(...)` ou `client.create_speech(...)`.

### Exemple
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
audio = client.generate_speech(
  model: 'openai/gpt-4o-mini-tts',
  input: 'Hello world',
  voice: 'alloy',
  format: 'mp3'
)
```

### Paramètres principaux
- `model` (obligatoire) : identifiant d’un modèle compatible avec le TTS.
- `input` (obligatoire) : texte à synthétiser.
- `voice` : préréglage de voix (dépend du modèle, par exemple `alloy`).
- `format` : `mp3`, `wav`, `flac`, etc.
- `speed` : multiplicateur de vitesse de lecture (généralement entre 0,25 et 4).

### Valeur renvoyée
Données audio binaires
