Validez la sortie lorsque le code Ruby en aval exige une structure de résultat prévisible. Les nouvelles tentatives du modèle couvrent les échecs transitoires des requêtes ; celles des outils produisant des effets secondaires doivent rester explicites et idempotentes.

## Configurer les tentatives

```ruby
agent = PhaseoAgentSdk.create_agent(
  id: "research-agent",
  model: "openai/gpt-5.4-nano",
  model_retry: PhaseoAgentSdk::ModelRetryConfig.new(
    max_retries: 3,
    base_delay_ms: 500,
    max_delay_ms: 4_000
  )
)
```

Le résultat contient le journal d’exécution, les étapes, les messages, l’utilisation normalisée, le motif d’arrêt et la sortie finale.

```ruby
result = agent.run(input: prompt, client: client)

puts result.output
puts result.run.status
puts result.usage[:total_tokens]
puts result.usage[:cost]
```

Utilisez les [conditions d’arrêt](./agent-sdk-stop-conditions.mdx) pour imposer des limites et la page [erreurs et dépannage](./agent-sdk-observability.mdx) pour choisir le comportement en cas d’échec récupérable.
