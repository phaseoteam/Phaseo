title: "Conditions d’arrêt"
description: "Limitez les exécutions des agents Ruby par nombre d’étapes, jetons, coût, durée, outils ou motif de fin."
---

Combinez des fonctions d’arrêt pour maintenir le travail autonome dans les limites de l’application.

```ruby
agent = PhaseoAgentSdk.create_agent(
  id: "bounded-research",
  model: "openai/gpt-5.4-nano",
  stop_when: [
    PhaseoAgentSdk.step_count_is(12),
    PhaseoAgentSdk.max_tokens_used(40_000),
    PhaseoAgentSdk.max_cost(2.50),
    PhaseoAgentSdk.max_duration(120_000)
  ]
)
```

Des conditions sont également disponibles pour les appels d’outils et les motifs de fin. Après l’exécution, inspectez `result.run.stop_reason` et l’utilisation normalisée pour distinguer un arrêt budgétaire d’une fin normale du modèle.

L’arrêt est un résultat borné, pas automatiquement une exception. Déterminez quels motifs doivent être considérés comme réussis, réessayés ou présentés à l’utilisateur.
