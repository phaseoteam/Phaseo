---

Le SDK Agent Go est un environnement d’exécution local complet pour les agents de Phaseo Gateway. Il inclut les nouvelles tentatives, les outils concurrents, les contextes et délais d’attente, la validation humaine, l’état reprenable, les événements du cycle de vie et la capture DevTools.

Utilisez-le si vous souhaitez :

- une boucle d’outils légère et limitée
- requêtes vers le point de terminaison Gateway `responses`
- contrôle de la persistance et de l’orchestration par l’application

## Ce que contient le SDK

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- requêtes vers le point de terminaison Gateway `responses`
