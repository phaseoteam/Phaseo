## Préparer l’environnement d’exécution

Le SDK Agent ne dispose pas encore de version publique du module Go. Suivez les [instructions d’installation depuis les sources](./agent-sdk-installation.mdx).

## Démarrage rapide

```go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "quickstart-agent",
    Model:        "openai/gpt-5.4-nano",
    Instructions: "Answer concisely and helpfully.",
  })

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "Give me one fun fact about cURL.",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Output)
}
```

## Fonctionnalités fournies

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- une boucle d’outils limitée utilisant l’API `responses` de Phaseo

## Environnement d’exécution avancé

Go prend en charge la validation et les approbations, les outils HITL et manuels, la progression, les erreurs récupérables, les canaux rejouables, les fonctions d’arrêt, les tours dynamiques, `NextTurnParams` persistants, l’utilisation et le coût normalisés, ainsi que `StateAccessor`.

## Streaming et annulation

`Agent.Stream(...)` et `Agent.ContinueStream(...)` consomment le flux SSE Responses de la passerelle. Lisez plusieurs fois `Text()` ou `Events()` si différents consommateurs doivent rejouer le flux, et appelez `Cancel()` pour annuler le contexte de requête. Les étapes terminées conservent les ID de requête, les métadonnées du fournisseur, les motifs de fin, les avertissements, l’utilisation et le coût.
