`AgentSdk.Tool` prend en charge :

- des `parameters` JSON présentés au modèle
- des fonctions `Validator` pour les entrées, les sorties et les événements de progression
- des délais `Duration` propres à chaque outil
- une approbation inconditionnelle ou conditionnelle
- des outils manuels exécutés par votre application
- une progression préliminaire via `RuntimeContext.emitProgress()`
- une gestion des erreurs `fail-run` ou `return-to-model`
- des remplacements pour le tour suivant après l’exécution réussie d’un outil

Transmettez les enregistrements d’outils via `AgentSdk.defineTool(...)` et soumettez les effets de bord à une approbation explicite ou à une exécution manuelle gérée par l’application.
