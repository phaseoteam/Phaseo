Envoyez des requêtes de texte, d'embeddings et de découverte de modèles avec le SDK Java.

<Note>Les sources actuelles incluent des contrôles de nouvelles tentatives et des métadonnées de réponse absents de l'ancien artefact 3.0.0 de Maven Central. Compilez la révision indiquée pour utiliser le SDK actuel. [Installation](./installation)</Note>

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

## Requêtes prises en charge

Utilisez `createResponse`, `createChatCompletion`, `createEmbedding` et `listModels` pour les requêtes JSON. Passez un `Map` ou un `JsonNode` ; analysez les chaînes JSON avant de les transmettre aux méthodes du client.

## Streaming

`streamResponse` et `rawClient().requestLines` renvoient les lignes SSE dès leur arrivée. Fermez le flux avec try-with-resources et gérez les noms d'événements, les données et les marqueurs de fin dans votre application.

<Note>La méthode `createSpeech` attend du JSON et ne décode pas l'audio binaire. Utilisez `rawClient().requestBytes` pour récupérer l'audio.</Note>
