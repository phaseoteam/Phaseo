## Configuration

```java
import app.phaseo.sdk.Phaseo;

String apiKey = System.getenv("PHASEO_API_KEY");
Phaseo client = new Phaseo(apiKey);
```

## Modèle d’utilisation

Les appels courants au wrapper ressemblent à ceci :

```java
Object response = client.createChatCompletion("""
{
  "model": "openai/gpt-5-nano",
  "messages": [
    { "role": "user", "content": "Say hello from Java" }
  ]
}
""");
```

Les méthodes du wrapper renvoient des nœuds JSON analysés pour la plupart des endpoints JSON et des tableaux d’octets pour les fonctions de récupération du contenu des fichiers et des vidéos.

## Recommandations

- Commencez par `app.phaseo.sdk.Phaseo` pour les fonctions courantes de la passerelle.
- Utilisez `app.phaseo.gen.Client` et `app.phaseo.gen.Operations` uniquement si vous avez besoin d’une opération de niveau inférieur qui n’a pas encore été intégrée au wrapper.
- Consultez d’abord les exemples propres à chaque endpoint de cette section pour connaître les noms actuels des méthodes du wrapper.
