description: "Référencez les principaux enregistrements et méthodes du SDK Java Agent."
---

| API | Rôle |
| --- | --- |
| `AgentSdk.createAgent(...)` | Définir un agent |
| `AgentSdk.defineTool(...)` | Définir un outil local ou manuel |
| `AgentSdk.createGatewayAgentClient(...)` | Relier les tours du modèle à Phaseo |
| `Agent.run(...)` | Exécuter jusqu’à la fin ou la mise en pause |
| `Agent.stream(...)` | Exécuter avec des consommateurs de flux réutilisables |
| `Agent.continueRun(...)` | Reprendre un état enregistré ou en pause |
| `StreamResult.getResult()` | Lire l’exécution terminée |
| `StreamResult.textStream()` | Lire les fragments de texte |
| `StreamResult.fullStream()` | Lire tous les événements |
| `StreamResult.cancel()` | Annuler l’exécution en cours |

Les principaux enregistrements et interfaces incluent `AgentDefinition`, `RunOptions`, `RunResult`, `RunRecord`, `RunStep`, `Tool`, `ToolDecision`, `ToolOutput`, `RuntimeContext`, `StateAccessor`, `ModelRetryConfig` et `ToolExecutionConfig`.
