Commencez par l’un de ces modèles :

| Modèle | À combiner |
| --- | --- |
| Triage des demandes d’assistance | preset géré, outils de recherche, sortie finale structurée |
| Revue de code | outils de fichiers ou de patch, événements de progression, approbation avant modification |
| Synthèse de recherche | outils web gérés, limites de coût et d’étapes, texte en flux |
| Guide d’exploitation | outils de statut, escalade manuelle, reprise durable |

Gardez la première implémentation ciblée : un agent, un ou deux outils déterministes et une approbation explicite pour les effets de bord.
