Les sources actuelles incluent des contrôles de nouvelles tentatives et des métadonnées de réponse absents de l'ancien artefact 3.0.0 de Maven Central. Compilez la révision indiquée pour utiliser le SDK actuel.

## Prérequis

- Java 17+
- Maven 3.8+
- Git

## Compiler depuis les sources

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
git checkout 1ff1119f41ceb3ac2c85ed605f6e1c4beca6e011
mvn -f packages/sdk/sdk-java/pom.xml -DskipTests install
```

Maven installe `app.phaseo:phaseo-sdk:3.0.0` dans votre dépôt local, avec sa dépendance Jackson.

## Ajouter la dépendance

```xml
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-sdk</artifactId>
  <version>3.0.0</version>
</dependency>
```

<Note>L'[artefact Maven Central](https://repo.maven.apache.org/maven2/app/phaseo/phaseo-sdk/3.0.0/) fournit l'ancienne API. Il n'inclut pas les API actuelles de nouvelles tentatives, de métadonnées ou de validation des paramètres.</Note>
