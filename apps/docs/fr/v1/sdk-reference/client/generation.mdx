Passez un identifiant de requête (comme `G-01ABC...`) à la méthode de génération du SDK pour récupérer l’enregistrement stocké de cette requête depuis `GET /v1/generations?id=<id>`.

<CodeGroup>

```typescript TypeScript
const record = await client.getGeneration("G-01ABC...");
```

```python Python
record = client.get_generation("G-01ABC...")

print(record["model_id"], record["cost_nanos"])
```

```go Go
client, err := phaseo.NewFromEnv()
if err != nil {
  panic(err)
}

record, err := client.GetGeneration(context.Background(), "G-01ABC...")
if err != nil {
  panic(err)
}
fmt.Println(record["status_code"], record["cost_nanos"])
```

```csharp C#
using PhaseoSdk;

var client = new Phaseo();
var record = await client.GetGeneration("G-01ABC...");
```

```php PHP
<?php
require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo();
$record = $client->getGeneration('G-01ABC...');
```

```ruby Ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new
record = client.get_generation('G-01ABC...')
```

```java Java
import app.phaseo.sdk.Phaseo;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

var record = client.getGeneration("G-01ABC...");
System.out.println(record);
```

</CodeGroup>

| Langage | Méthode | Renvoie |
| --- | --- | --- |
| TypeScript | `client.getGeneration(id)` | L’objet de l’enregistrement |
| Python | `client.get_generation(id)` | Dict `APIResponse` |
| Go | `client.GetGeneration(ctx, id)` | `map[string]interface{}` |
| C# | `client.GetGeneration(id)` | `Dictionary<string, object>?` |
| PHP | `$client->getGeneration($id)` | Tableau |
| Ruby | `client.get_generation(id)` | Hash |
| Java | `client.getGeneration(id)` | `JsonNode` Jackson |
| Rust | Pas d’assistant ; appelez `client.request("GET", "/generations?id=<id>", None, &RequestOptions::default())` | `PhaseoResponse`, avec l’enregistrement dans `body` (un `serde_json::Value`) |

La consultation est limitée à votre espace de travail. Un `id` manquant renvoie `400` (`missing_id`), et un identifiant qui n’appartient pas à votre espace de travail renvoie `404` (`not_found`).

## Rejouer une requête stockée

Si la passerelle a stocké la requête complète, l’enregistrement a `replay_supported` à true et un `replay_request`, que vous pouvez renvoyer vers l’endpoint d’origine pour une réexécution contrôlée.

## Lire les champs de durée

- `latency_ms` : le temps jusqu’au premier token, ou jusqu’au premier octet ou à la première trame de sortie, quand il est mesuré.
- `generation_ms` : le temps de génération après ce point, quand il est mesuré.
