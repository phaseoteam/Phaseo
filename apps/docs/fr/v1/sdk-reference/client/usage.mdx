## Chat completions

<CodeGroup>

```typescript TypeScript
const completion = await client.generateText({
  model: "openai/gpt-6-astra",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: "What is Phaseo?" },
  ],
});

for await (const chunk of client.streamChat({
  model: "openai/gpt-6-astra",
  messages: [{ role: "user", content: "Tell me a story" }],
})) {
  if (chunk.text) process.stdout.write(chunk.text);
}
```


```typescript TypeScript
const message = await client.generateMessage({

  max_tokens: 128,
});

for await (const chunk of client.streamMessages({
  model: "anthropic/claude-haiku-4.5",
  messages: [{ role: "user", content: "Stream a short hello" }],
  max_tokens: 128,
})) {

```

```python Python
message = client.generate_message(
    {
        "model": "anthropic/claude-haiku-4.5",
        "messages": [{"role": "user", "content": "Hello from the Messages API"}],
        "max_tokens": 128,
    }
)

for chunk in client.stream_message(
    {
        "model": "anthropic/claude-haiku-4.5",
```

**Python :** `stream_message` renvoie des fragments analysés ; `stream_messages` renvoie les lignes SSE brutes. Go, C#, PHP, Ruby et Java proposent `createAnthropicMessage`, selon la convention de nommage de chaque langage.

## Audio

Les transcriptions et les traductions prennent un envoi multipart. TypeScript envoie un corps `FormData` en multipart. Les méthodes Python, Go, C#, PHP et Ruby envoient du JSON : la transcription ne fonctionne donc qu’avec une URL passée à un modèle qui accepte `file_url`, et la traduction exige un envoi multipart. Pour envoyer un fichier audio depuis ces SDK, consultez [STT (reconnaissance vocale)](./audio-transcriptions#upload-an-audio-file) et [Traductions](./audio-translations).

<CodeGroup>

```typescript TypeScript
import { readFile } from "node:fs/promises";

const speech = await client.generateSpeech({
  model: "openai/gpt-4o-mini-tts",
  input: "Hello world",
});

// Les transcriptions et les traductions prennent un envoi multipart.
const form = new FormData();
form.append("model", "openai/gpt-4o-transcribe");
form.append("file", new Blob([await readFile("call.mp3")], { type: "audio/mpeg" }), "call.mp3");
const transcript = await client.generateTranscription(form as unknown as Record<string, unknown>);
```

```python Python
speech = client.generate_speech(
    {"model": "openai/gpt-4o-mini-tts", "input": "Hello world"}
)

# generate_transcription envoie du JSON : passez une URL à un modèle qui accepte file_url.
transcription = client.generate_transcription(
    {"model": "mistral/voxtral-mini-transcribe-2", "file_url": "https://example.com/call.mp3"}
)
```

```go Go
speech, err := client.CreateSpeech(ctx, map[string]interface{}{
  "model": "openai/gpt-4o-mini-tts",
  "input": "Hello from Go",
})
```

```csharp C#
var speech = await client.CreateSpeech(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-4o-mini-tts",
    ["input"] = "Hello from .NET",
});
```

```php PHP
$speech = $client->createSpeech([
    'model' => 'openai/gpt-4o-mini-tts',
    'input' => 'Hello from PHP',
]);

$transcript = $client->generateTranscription([
    'model' => 'mistral/voxtral-mini-transcribe-2',
    'file_url' => 'https://example.com/meeting.mp3',

```

```ruby Ruby

  model: 'openai/gpt-4o-mini-tts',
```

## Gérer les erreurs

<CodeGroup>

```typescript TypeScript
import { PhaseoHttpError } from "@phaseo/sdk";

try {
  await client.generateText({ model: "invalid", messages: [{ role: "user", content: "Hi" }] });
} catch (error) {
  if (error instanceof PhaseoHttpError) {
    console.error(error.status, error.code, error.requestId, error.traceUrl);
  } else {
    throw error;
  }
}
```

```python Python
from phaseo import PhaseoHTTPError

try:
    client.generate_text({"model": "invalid", "messages": [{"role": "user", "content": "Hi"}]})
except PhaseoHTTPError as error:
    print(error.status, error.code, error.request_id, error.trace_url)
```

```java Java
import app.phaseo.gen.Client;
import app.phaseo.sdk.Phaseo;
import java.time.Duration;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"))
    .setTimeout(Duration.ofSeconds(30))
    .setMaxRetries(2);

try {
    var result = client.requestWithResponse("GET", "/models",
        Map.of("limit", "5"), null, null, null);
    System.out.println(result.requestId());
    System.out.println(result.data);
} catch (Client.ApiException error) {
    System.err.println(error.getStatusCode());
    System.err.println(error.getRequestId());
    System.err.println(error.getResponseBody());
}
```

```rust Rust
let request = serde_json::json!({
    "model": "openai/gpt-6-astra",
    "input": "Handle this request"
});

match client.responses(&request) {
    Ok(response) => println!("{}", response.body),
    Err(error) => {
        eprintln!("message: {}", error.message);
        eprintln!("status: {:?}", error.status);
        eprintln!("body: {:?}", error.body);
    }
}
```

</CodeGroup>

`PhaseoError` (Rust) contient un statut HTTP et le corps JSON analysé quand le Gateway a renvoyé une erreur ; les échecs de transport et de configuration n’ont pas de statut. La [présentation](./overview#request-controls-and-errors) liste les champs d’erreur de chaque SDK.

## Ajouter un en-tête de requête

**Rust :** `with_header` ajoute un en-tête à toutes les requêtes suivantes.

```rust Rust
let client = Phaseo::from_env()?
    .with_header("x-phaseo-workspace-id", "workspace_123");
```
