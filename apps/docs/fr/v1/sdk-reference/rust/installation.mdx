Suivez ce guide pour ajouter le client Rust pris en charge et le rendre accessible à votre application.

## Prérequis

- Rust 1.86 ou version ultérieure
- une clé API Phaseo Gateway

## Installation

Ajoutez le client et la dépendance JSON :

```toml
[dependencies]
phaseo = "0.1"
serde_json = "1"
```

Ou exécutez :

```bash
cargo add phaseo@0.1 serde_json
```

## Configurer votre clé API

`Phaseo::from_env()` lit `PHASEO_API_KEY` :

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

PowerShell :

```powershell
$env:PHASEO_API_KEY = "phaseo_v1_sk_..."
```

Conservez la clé sur le serveur. Ne l’intégrez pas à un client de bureau, mobile, navigateur ou autre client distribué.

## Vérifier l’installation

```rust
use phaseo::Phaseo;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let _client = Phaseo::from_env()?;
    println!("Phaseo Rust client configured");
    Ok(())
}
```

```bash
cargo run
```

## Points de terminaison personnalisés

Définissez `PHASEO_BASE_URL` lorsqu’un point de terminaison de développement ou de proxy doit remplacer `https://api.phaseo.app/v1` :

```bash
export PHASEO_BASE_URL="http://localhost:8787/v1"
```

Les points de terminaison distants doivent utiliser HTTPS. Le HTTP non chiffré n’est accepté que si l’hôte analysé est exactement `localhost` ou une adresse IP de boucle locale.
