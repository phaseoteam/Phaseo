Utilisez le crate publié [`phaseo`](https://crates.io/crates/phaseo) pour appeler la passerelle Phaseo depuis une application Rust.

Le client de haut niveau prend en charge :

- requêtes à l’API Responses avec `Phaseo::responses(...)`
- requêtes Chat Completions avec `Phaseo::chat_completions(...)`
- d’autres points de terminaison JSON avec `Phaseo::post(...)`
- configuration basée sur l’environnement avec `Phaseo::from_env()`
- points de terminaison HTTPS personnalisés et serveurs de développement loopback
- statut, corps JSON, ID de requête et détails d’erreur structurés

```rust
use phaseo::Phaseo;
use serde_json::json;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Phaseo::from_env()?;
    let response = client.responses(&json!({
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with exactly: Rust SDK works"
    }))?;

    println!("{}", response.body);
    Ok(())
}
```

<Note>
  La version `0.1` est prise en charge et publiée, mais l’API Rust peut encore évoluer avant la version `1.0`. Verrouillez une version mineure compatible en production.
</Note>

## Périmètre actuel

Le client ergonomique est synchrone et accepte des corps de requête `serde_json::Value`. Les modules bas niveau générés restent disponibles dans `phaseo::gen`, avec des réexportations pratiques dans `phaseo::client`, `phaseo::models` et `phaseo::operations`.

Le client Rust ne fournit actuellement ni transport asynchrone ni fonction de streaming de haut niveau. Utilisez l’API HTTP brute si l’application a besoin de streaming avant l’ajout de ces fonctions.
