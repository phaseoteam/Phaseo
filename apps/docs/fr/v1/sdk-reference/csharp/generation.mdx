**Méthode** : `client.GetGeneration(...)`

### Exemple

```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.GetGeneration("G-01ABC...");
```

### Paramètres

- `id` (string, obligatoire) : ID de requête renvoyé par un appel précédent.

### Retour

Enregistrement de génération (JSON)

Si la passerelle a stocké tous les détails de la requête, l’enregistrement renvoyé inclut `replay_supported` et `replay_request`. Vous pouvez envoyer `replay_request` au point de terminaison d’origine pour relancer la requête de manière contrôlée.

Les champs de durée suivent les mêmes conventions dans toute la passerelle :

- `latency_ms` : délai avant le premier token ou le premier octet/fragment de sortie, s’il est suivi
- `generation_ms` : durée de génération après la latence, si elle est suivie
