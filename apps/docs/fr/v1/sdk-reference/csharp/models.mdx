**Méthode** : `client.ListModels(...)`

### Exemple
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var models = await client.ListModels(new Dictionary<string, string>
{
    ["provider"] = "anthropic",
    ["provider_status"] = "beta,not_ready",
    ["provider_availability_reason"] = "preview_only,provider_not_ready",
    ["capability_status"] = "coming_soon,internal_testing",
    ["availability"] = "all",
    ["limit"] = "10"
});
```

### Paramètres
- Filtres facultatifs : `provider`, `provider_status`, `provider_routing_status`, `model_routing_status`, `capability_status`, `provider_availability_status`, `provider_availability_reason`, `status`, `organisation`, `endpoints`, `input_types`, `output_types`, `params`, `availability`, `limit`, `offset`.
- `provider_availability_reason` est utile avec `availability = "all"` pour inclure les états de déploiement tels que `preview_only`, `provider_not_ready`, `gated`, `access_limited`, `region_limited`, `project_limited`, `paused` ou `soft_blocked`.
- `capability_status` est utile avec `availability = "all"` pour inclure des correspondances de points de terminaison non routables, comme `coming_soon` ou `internal_testing`.
