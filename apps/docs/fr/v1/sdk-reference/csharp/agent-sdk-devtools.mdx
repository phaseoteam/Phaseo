---
icon: "chart-spline"
title: "Outils de développement"
description: "Capturez localement les exécutions du SDK Agent .NET pour le développement et le débogage."
---

Activez la capture JSONL locale avec `AgentSdk.CreateAgentDevtools(...)` et transmettez-le dans `RunOptions`.

Les entrées capturées comprennent l’état et la durée de l’exécution, les détails du modèle et du fournisseur, les identifiants de requête, les messages, les étapes, l’activité des outils, l’utilisation, le coût et les erreurs structurées.

<Warning>
Les entrées, le contexte et les résultats des outils peuvent contenir des données sensibles. Ne stockez pas la sortie DevTools dans le contrôle de version ni dans les images de production.
</Warning>
