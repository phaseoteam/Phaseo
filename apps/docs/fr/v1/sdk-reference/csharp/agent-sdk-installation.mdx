Le SDK Agent est publié sur NuGet sous le nom [`Phaseo.AgentSdk`](https://www.nuget.org/packages/Phaseo.AgentSdk).

## Prérequis

- .NET 8 ou version ultérieure
- une clé API Phaseo

## Installeration

```bash
dotnet add package Phaseo.AgentSdk
```

Le package principal `Phaseo.Sdk` est installé automatiquement en tant que dépendance.

## Environnement

Définissez votre clé API de la passerelle avant d’exécuter les exemples :

```bash
set PHASEO_API_KEY=phaseo_v1_sk_...
```
