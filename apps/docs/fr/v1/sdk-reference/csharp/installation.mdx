Le SDK est publié sous le nom [`Phaseo.Sdk`](https://www.nuget.org/packages/Phaseo.Sdk) sur NuGet.

## Prérequis

- .NET 8 ou version ultérieure

## Installation

```bash
dotnet add package Phaseo.Sdk
```
