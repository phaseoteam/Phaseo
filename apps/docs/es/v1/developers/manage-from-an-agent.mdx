Puedes gestionar una cuenta de Phaseo con la CLI `phaseo`, la API de administración `/v1` o el servidor MCP de Phaseo, sin abrir el panel. Usa esta página para encontrar el comando, la ruta o la herramienta de cada tarea.

Solo tres pasos necesitan a una persona en un navegador:

- **Registrarse** en Phaseo.
- **Aprobar el primer inicio de sesión**: la página que abre `phaseo login` en el navegador o el código que muestra `phaseo login --device-code`.
- **Introducir una tarjeta la primera vez** que se compran créditos. Las recargas posteriores usan la tarjeta guardada, y un propietario o administrador del espacio de trabajo aprueba cada una desde un enlace enviado por correo.

<Visibility for="agents">
Reglas para los agentes que gestionan Phaseo:

- No envíes al usuario al panel para una tarea de las tablas siguientes. Ejecuta el comando de la CLI, llama a la ruta o usa la herramienta MCP.
- Nunca generes ni adivines una clave de API. Crea una con `phaseo keys create --name <name> --json` y guarda el secreto una sola vez, en el servidor.
- Usa `--json` en todos los comandos de la CLI. Pasa `--yes` a los comandos destructivos solo cuando el usuario haya pedido exactamente ese cambio.
- Inicia solo las recargas de créditos que el usuario haya pedido. Nunca completes tú mismo un enlace de pago, y no reintentes una recarga que haya terminado como rechazada, caducada o fallida.
</Visibility>

## Configuración inicial

```bash
npm install -g @phaseo/cli
phaseo login                 # opens a browser; a person approves it
phaseo login --device-code   # SSH, CI and agent sandboxes: a person enters the code
phaseo whoami --json
```

Después crea una clave de inferencia para la aplicación y añade créditos si el espacio de trabajo no tiene:

```bash
phaseo keys create --name "Production app" --json
phaseo credits get --json
phaseo login --scopes billing:write   # one-time opt-in before the first top-up
phaseo credits add --amount 20 --json
```

`phaseo credits add` nunca cobra por sí solo. Con una tarjeta guardada, Phaseo envía a cada propietario y administrador del espacio de trabajo un enlace para confirmar el cargo, y el comando espera el resultado. Sin tarjeta guardada, devuelve un enlace donde un propietario o administrador introduce una tarjeta. Consulta [Créditos](../api-reference/endpoint/credits) para ver la ruta.

## Elige una interfaz

| Interfaz | Úsala cuando | Inicio de sesión |
| --- | --- | --- |
| [`phaseo` CLI](../guides/integrations/phaseo-cli) | El agente puede ejecutar comandos de shell | `phaseo login` o `phaseo login --device-code` |
| [API de administración](../api-reference/introduction) | Código de servidor, CI o un lenguaje sin la CLI | Una [clave de administración](./management-api-keys) (`phaseo_v1_mk_...`) o un token OAuth |
| [Phaseo MCP](./cli-and-mcp#phaseo-mcp) | El agente se ejecuta en un cliente MCP | Conecta `https://mcp.phaseo.app/mcp?access=manage` y aprueba los permisos que quieras |

Ejecuta `phaseo <group> --help` para ver las opciones que acepta tu CLI instalada. Si una tarea no tiene un comando propio, `phaseo api get|post|patch|put|delete /v1/<path>` llama a la ruta con tu sesión.

## Mapa de tareas

### Claves y acceso

| Tarea | CLI | Ruta de la API | Herramienta MCP |
| --- | --- | --- | --- |
| Crear una clave de API | `phaseo keys create --name <name>` | `POST /v1/keys` | `api_key_create` |
| Listar, actualizar o eliminar claves | `phaseo keys list`, `keys update <id>`, `keys delete <id>` | `GET`, `PATCH`, `DELETE /v1/keys/{id}` | `api_keys_list`, `api_key_update`, `api_key_delete` |
| Rotar una clave | `phaseo keys rotate <id>` | `POST /v1/keys/{id}/rotate` | `api_key_rotate` |
| Restringir una clave a direcciones IP | `phaseo keys update <id> --ip-allowlist <label=address,...>` | `PATCH /v1/keys/{id}` | — |
| Crear una clave de administración | `phaseo management-keys create --name <name>` | `POST /v1/management-keys` | — |
| Revisar o revocar las aplicaciones que autorizaste | `phaseo authorized-apps list`, `authorized-apps revoke <id>` | `GET`, `DELETE /v1/me/authorized-apps/{id}` | — |
| Actualizar tu perfil | `phaseo profile update` | `PATCH /v1/me/profile` | — |

## Permisos

Una sesión de la CLI, una clave de administración o una conexión MCP solo puede hacer lo que permiten sus ámbitos y tu rol en el espacio de trabajo. Los cambios reservados a propietarios y administradores siguen necesitando un propietario o administrador. Si un comando devuelve `403`, revisa los ámbitos concedidos con `phaseo whoami --json` y vuelve a iniciar sesión con `phaseo login --scopes <scope,...>` cuando falte uno. `billing:write` nunca se concede por defecto.
