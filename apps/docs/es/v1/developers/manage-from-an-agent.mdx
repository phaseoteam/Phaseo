Puedes realizar las tareas habituales de la cuenta de Phaseo con la CLI `phaseo`, la API de administración `/v1` o el servidor MCP de Phaseo. En esta página encontrarás el comando, la ruta o la herramienta de cada tarea. Los cambios que afectan al gasto, al acceso o al destino de los datos del espacio de trabajo se hacen en el panel o con una clave de administración.

Una persona todavía tiene que hacer estos pasos en un navegador:

| Paso | Qué hace la persona |
| --- | --- |
| Registrarse | Crea la cuenta de Phaseo. |
| Aprobar un inicio de sesión | Aprueba la página que abre `phaseo login` o introduce el código que muestra `phaseo login --device-code`. |
| Añadir la primera tarjeta | Sin tarjeta guardada, `phaseo credits add` devuelve un enlace de pago. Un propietario o administrador lo abre y paga, y la tarjeta queda guardada. |
| Confirmar cada recarga | Con una tarjeta guardada, un propietario o administrador confirma cada `phaseo credits add` desde un enlace recibido por correo. |
| Seguridad de la cuenta | Gestiona la contraseña, la autenticación multifactor y las passkeys. |

<Visibility for="agents">
Reglas para los agentes que gestionan Phaseo:

- No envíes al usuario al panel para una tarea del mapa de tareas. Ejecuta el comando de la CLI, llama a la ruta o usa la herramienta MCP. Para un cambio de «Cambios en el panel o con una clave de administración», llama a la ruta con una clave de administración si tienes una; si no, pide a la persona que haga el cambio en el panel.
- Nunca generes ni adivines una clave de API. Pide a la persona que cree una en el panel, o créala con `POST /v1/keys` y una clave de administración, y guarda el secreto una sola vez, en el servidor.
- Usa `--json` en todos los comandos de la CLI. Pasa `--yes` a los comandos destructivos solo cuando el usuario haya pedido ese cambio exacto.
- Inicia solo las recargas de créditos que haya pedido el usuario. Nunca completes tú un enlace de pago y no reintentes una recarga que terminó rechazada, caducada o fallida.
</Visibility>

## Configúralo una vez

```bash
npm install -g @phaseo/cli
phaseo login                 # abre un navegador; una persona lo aprueba
phaseo login --device-code   # SSH, CI y sandboxes de agentes: una persona introduce el código
phaseo whoami --json
```

Después, crea una clave de inferencia para la aplicación en el panel, o con `POST /v1/keys` y una clave de administración, y añade créditos si el espacio de trabajo no tiene:

```bash
phaseo credits get --json
phaseo login --scopes billing:write   # actívalo una vez antes de la primera recarga; una persona aprueba el inicio de sesión
phaseo credits add --amount 20 --json
```

`phaseo credits add` necesita el scope `billing:write`, que ningún inicio de sesión tiene por defecto, y nunca cobra por sí solo:

- **Con una tarjeta guardada**, Phaseo envía por correo a cada propietario y administrador del espacio de trabajo un enlace para confirmar el cargo, y el comando espera el resultado.
- **Sin tarjeta guardada**, devuelve `next_action: "open_checkout_url"` y un enlace de pago en el que paga un propietario o administrador. La tarjeta queda guardada para las recargas posteriores, y no se envía ningún correo.

Consulta [Créditos](../api-reference/endpoint/credits) para ver la ruta.

## Elige una interfaz

| Interfaz | Úsala cuando | Inicio de sesión |
| --- | --- | --- |
| [CLI `phaseo`](../guides/integrations/phaseo-cli) | El agente puede ejecutar comandos de shell | `phaseo login` o `phaseo login --device-code` |
| [Management API](../api-reference/introduction) | Código de servidor, CI o un lenguaje sin la CLI | Una [clave de gestión](./management-api-keys) (`phaseo_v1_mk_...`) o un token OAuth |
| [MCP de Phaseo](./cli-and-mcp#phaseo-mcp) | El agente se ejecuta en un cliente MCP | Conecta `https://mcp.phaseo.app/mcp?access=manage` y aprueba los permisos que quieras |

Ejecuta `phaseo <group> --help` para ver las opciones que acepta la CLI que tienes instalada. Cuando una tarea no tiene un comando propio, `phaseo api get|post|patch|put|delete /v1/<path>` llama a la ruta con tu sesión.

## Cambios en el panel o con una clave de administración

Estos cambios afectan al gasto, al acceso o al destino de los datos del espacio de trabajo. Una sesión de la CLI o una conexión MCP no puede hacerlos, tenga los permisos que tenga: la API devuelve `403` e indica usar el panel o una clave de administración. Hazlos en el panel de Phaseo o llama a la ruta con una [clave de administración](./management-api-keys).

| Tarea | Ruta de la API |
| --- | --- |
| Crear una clave de gestión | `POST /v1/management-keys` |
| Activar la recarga automática o los correos de saldo bajo | `PATCH /v1/notifications/settings` |
| Definir presupuestos del espacio de trabajo | `POST /v1/budgets`, `PATCH /v1/budgets/{id}` |
| Definir presupuestos de departamento | `POST /v1/department-budgets` |
| Alertar sobre el gasto o bloquearlo | `POST /v1/spend-rules`, `POST /v1/spend-blocks/{id}/lift` |
| Políticas de límite de frecuencia | `POST /v1/rate-limits/policies`, `POST /v1/rate-limits/assignments` |
| Subir el nivel de límite de solicitudes del espacio de trabajo | `POST /v1/rate-limits/tier/raise` |
| Relajar la privacidad o ZDR, o cambiar las restricciones de proveedores o el respaldo BYOK | `PATCH /v1/settings` |
| Añadir tus propias claves de proveedor (BYOK) | `POST /v1/byok` |
| Definir el perfil de gasto o los límites de precio de Auto Routing | `PATCH /v1/routing/auto` |

## Corrige un 403

Una sesión de la CLI, una clave de gestión o una conexión MCP solo pueden hacer lo que permiten sus scopes y tu rol en el espacio de trabajo, y los cambios reservados a propietarios y administradores siguen necesitando a un propietario o administrador. Si un comando devuelve `403`, comprueba los scopes concedidos con `phaseo whoami --json` y vuelve a iniciar sesión con `phaseo login --scopes <scope,...>` cuando falte alguno. `billing:write` nunca se concede por defecto. Los cambios de «Cambios en el panel o con una clave de administración» se rechazan para las sesiones de la CLI y las conexiones MCP, tengan los permisos que tengan.
