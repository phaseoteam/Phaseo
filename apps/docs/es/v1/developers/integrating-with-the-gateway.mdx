Guarda una clave de Phaseo en tu servidor, elige el endpoint que coincide con el protocolo de tu aplicación y apunta tu cliente HTTP o tu SDK a `https://api.phaseo.app/v1`. Empieza por la [Guía de inicio rápido](../quickstart.mdx) si todavía no has enviado ninguna solicitud.

Necesitas una cuenta de Phaseo con acceso a Gateway y un cliente HTTP, un SDK compatible con OpenAI o un SDK de Phaseo. Los ejemplos usan `google/gemma-3-27b:free`, que funciona sin créditos depositados.

<Steps>
<Step title="Crea y guarda una clave">

Abre **Ajustes → Claves de API** en el [panel](https://phaseo.app/settings/keys) o llama a `POST /v1/keys` con una clave de administración. Ponle a la clave el nombre de la aplicación y el entorno, y después guárdala en un gestor de secretos o en un archivo de entorno:

```bash
# .env.local
PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
PHASEO_BASE_URL="https://api.phaseo.app/v1"
```

Usa claves distintas para el desarrollo local, los despliegues de vista previa y producción, para poder rotar y revisar cada una por separado.

</Step>
<Step title="Elige el endpoint">

| Endpoint | Úsalo para |
| --- | --- |
| `/v1/responses` | Nuevos desarrollos de texto, salida estructurada y flujos de varios pasos. |
| `/v1/chat/completions` | Interfaces de chat e integraciones existentes al estilo de OpenAI. |
| `/v1/messages` | Integraciones compatibles con Anthropic. |
| `/v1/decisions` | Decisiones tipadas sobre el estado de la aplicación, con Jev 1.13 (Beta). |
| `/v1/moderations` | Comprobaciones de seguridad y de política de contenido. |
| `/v1/images/generations` | Imágenes a partir de prompts de texto. |

La [Referencia de la API](../api-reference/introduction) lista todos los endpoints, parámetros y respuestas.

</Step>
<Step title="Envía una solicitud desde tu aplicación">

Este ejemplo usa Chat Completions, que los clientes compatibles con OpenAI ya hablan. Cada solicitud envía la clave como `Authorization: Bearer $PHASEO_API_KEY`.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemma-3-27b:free",
    "messages": [
      { "role": "system", "content": "You are a helpful assistant." },
      { "role": "user", "content": "Explain the benefits of AI." }
    ]
  }'
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});

const response = await client.chat.completions.create({
  model: "google/gemma-3-27b:free",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: "Explain the benefits of AI." },
  ],
});

console.log(response.choices[0]?.message?.content);
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",

    model="google/gemma-3-27b:free",
    messages=[

        {"role": "user", "content": "Explain the benefits of AI."},
    ],

print(response.choices[0].message.content)
```

```go Go
package main

import (
  "context"
  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4"
)

func main() {
  client := phaseo.New("YOUR_API_KEY", "https://api.phaseo.app/v1")

  response, err := client.CreateChatCompletion(context.Background(), phaseo.ChatCompletionsRequest{
    Model: "google/gemma-3-27b:free",
    Messages: []map[string]interface{}{
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain the benefits of AI."},
    },
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(response)
}
```

<Note>
Los modelos cuyo ID termina en `:free` funcionan sin créditos depositados. Los modelos de pago necesitan saldo disponible en el monedero.
</Note>
