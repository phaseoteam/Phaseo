Usa la CLI para cambiar Phaseo desde una terminal o un script, o conecta un cliente de IA al servidor MCP de Phaseo para darle datos de Phaseo en vivo. Ambos inician sesión con OAuth de Phaseo.

| Interfaz | Úsala para | Acceso |
| --- | --- | --- |
| [CLI de Phaseo](#phaseo-cli) | Crear claves, cambiar ajustes, gestionar espacios de trabajo y automatizar tareas de administración desde un shell o CI | Lectura y escritura, limitadas por tus scopes y tu rol en el espacio de trabajo |
| [MCP de Phaseo](#phaseo-mcp) | Dar a Codex, Claude, ChatGPT y otros clientes MCP datos de Phaseo en vivo y, opcionalmente, dejar que gestionen tu cuenta | Solo lectura, salvo que te conectes con gestión de la cuenta |
| [MCP de la documentación](#docs-mcp) | Dar a un asistente de programación la documentación actual de Phaseo | Solo documentación, sin acceso a la cuenta |
| [Plugin de Phaseo](#phaseo-plugin) | Instalar a la vez los dos servidores MCP y las skills de Phaseo en Claude Code o Codex | El mismo que cada servidor MCP |

<span id="phaseo-cli"></span>
## CLI de Phaseo

### Instala e inicia sesión

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

Las terminales interactivas usan OAuth en el navegador de forma predeterminada. Para SSH, CI y entornos sin interfaz gráfica, usa la autorización de dispositivo:

```bash
phaseo login --device-code
```

### Flujos de trabajo habituales

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys list
phaseo logs list --since 1h --status error --json
```

Usa `--json` cuando otra herramienta o un script necesite una salida estructurada. Los valores secretos solo se muestran en los comandos que los crean o los revelan de forma explícita.

## MCP de Phaseo

La URL del servidor es `https://mcp.phaseo.app/mcp`. Un cliente de IA conectado a él puede responder preguntas con datos en vivo de modelos, precios, proveedores, uso y espacio de trabajo.

### Conecta tu cliente

Instálalo con un clic: [Añadir a Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=phaseo&config=eyJ1cmwiOiJodHRwczovL21jcC5waGFzZW8uYXBwL21jcCJ9) · [Añadir a VS Code](vscode:mcp/install?%7B%22name%22%3A%22phaseo%22%2C%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fmcp.phaseo.app%2Fmcp%22%7D). Cuando el cliente te pida iniciar sesión, Phaseo OAuth se abre en tu navegador. Elige un workspace y aprueba los scopes de lectura solicitados.

<Tabs>
<Tab title="Claude Code">
```bash
claude mcp add --transport http phaseo https://mcp.phaseo.app/mcp
```

Después ejecuta `/mcp`, selecciona `phaseo` y elige **Authenticate**. Añade `--scope user` para tenerlo disponible en todos los proyectos.
</Tab>
<Tab title="Codex">
```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
codex mcp list
```

El comando de inicio de sesión abre Phaseo OAuth. `codex mcp list` confirma la conexión.
</Tab>
<Tab title="Cursor">
```json ~/.cursor/mcp.json
{
  "mcpServers": {
    "phaseo": {
      "url": "https://mcp.phaseo.app/mcp"
    }
  }
}
```

Usa **Añadir a Cursor** arriba, o añade el servidor a `~/.cursor/mcp.json` e inicia sesión desde la configuración de MCP de Cursor.
</Tab>
<Tab title="VS Code">
```json .vscode/mcp.json
{
  "servers": {
    "phaseo": {
      "type": "http",
      "url": "https://mcp.phaseo.app/mcp"
    }
  }
}
```

Usa **Añadir a VS Code** arriba, o añade el servidor a `.vscode/mcp.json`. Inícialo desde la vista de MCP e inicia sesión cuando VS Code te lo pida.
</Tab>
<Tab title="Claude">
En Claude, abre **Settings → Connectors**, elige **Add custom connector**, introduce `Phaseo` y la URL del servidor y selecciona **Connect**. Si no ves la opción, un propietario de tu organización de Claude tiene que permitir los conectores personalizados.
</Tab>
<Tab title="OpenCode">
```json opencode.json
{

      "type": "remote",
      "url": "https://mcp.phaseo.app/mcp"
    }
  }

```

Añade el servidor a `opencode.json` y ejecuta `opencode mcp auth phaseo` para iniciar sesión.
</Tab>
</Tabs>

Para otro cliente MCP, añade la misma URL como servidor remoto Streamable HTTP. El cliente debe admitir el descubrimiento de OAuth, el código de autorización con PKCE S256 y el parámetro `resource` de MCP.

### Usa tu inicio de sesión de la CLI de Phaseo

Si ya usas la CLI de Phaseo, un agente local puede acceder al MCP a través de ella sin iniciar sesión otra vez:

```bash
phaseo login
claude mcp add --scope user phaseo -- phaseo mcp
# or, for Codex
codex mcp add phaseo -- phaseo mcp
```

`phaseo mcp` ejecuta el MCP por stdio con tu sesión de la CLI. Cambia esa sesión por un token de 15 minutos que solo funciona en el MCP, nunca tiene más acceso que tu sesión y nunca permite llamadas de pago a modelos. Es de solo lectura salvo que añadas `--manage`. `phaseo setup codex` lo añade por ti al perfil de Phaseo en Codex. Cuando un agente conectado así lee registros, actividad o analíticas, el resultado también sugiere el comando de la CLI correspondiente para obtener los datos completos.

### Qué puede leer el MCP

Las herramientas de solo lectura cubren modelos, proveedores, clasificaciones de benchmarks, precios y estimaciones de coste, además de créditos, actividad, analíticas, registros de solicitudes y metadatos de generación. Nunca devuelven prompts, respuestas ni valores secretos.

### Gestiona tu cuenta (opcional)

Para que un agente pueda cambiar tu espacio de trabajo de Phaseo, conéctate con la URL de gestión:

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

Al iniciar sesión, la pantalla de consentimiento lista cada permiso que pide la conexión, como gestionar claves de API o eliminar presupuestos, y lo marca como **Lectura**, **Escritura** o **Eliminar**. Desmarca los que no quieras. El agente solo recibe herramientas para los permisos que permites, y Phaseo sigue comprobando tu rol en el espacio de trabajo en cada cambio, así que un miembro que no sea propietario ni administrador no puede cambiar por esta vía los ajustes reservados a administradores.

Si ya te conectaste con la URL de solo lectura, cambia el cliente a la URL de gestión y vuelve a iniciar sesión. Para volver al acceso de solo lectura, vuelve a conectarte con la URL simple o revoca la aplicación en **Configuración → Aplicaciones conectadas**.

Una conexión de gestión lee todo lo que aparece abajo, pero solo cambia claves de API y ajustes del espacio de trabajo. Los presupuestos, las reglas de gasto, las claves de proveedores, los guardrails, los preajustes, los webhooks y los destinos de observabilidad controlan el gasto o adónde va el contenido de las solicitudes, así que los cambias en el panel o con una clave de gestión.

| Área | Leer | Cambiar |
| --- | --- | --- |
| Claves de API | `api_keys_list`, `api_key_get` | Con `phaseo mcp --manage`: `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete`. Otros clientes pueden renombrar (`api_key_update`) y eliminar (`api_key_delete`) |
| Ajustes | `settings_get` | `settings_update`, para cambios que mantienen o refuerzan la privacidad, el registro y las restricciones de proveedores |
| Presupuestos | `budgets_list` | En el panel |
| Reglas de gasto | `spend_rules_list` | En el panel |
| Claves de proveedores (BYOK) | `provider_keys_list` | En el panel |
| Guardrails | `guardrails_list`, `guardrail_get` | En el panel |
| Preajustes | `presets_list`, `preset_get` | En el panel |
| Webhooks | `webhooks_list` | En el panel |
| Destinos de observabilidad | `observability_destinations_list` | En el panel |

Las herramientas que cambian o eliminan algo están marcadas como tales, así que los clientes MCP compatibles te preguntan antes de cada llamada. Una clave de API nueva se muestra una vez en el resultado de la herramienta y no se puede volver a mostrar. Las claves de proveedores guardadas y las credenciales de los destinos nunca se devuelven.

El MCP no tiene herramientas de facturación, pagos, espacios de trabajo, miembros, claves de gestión ni aplicaciones OAuth. Para eso, usa el panel, la CLI o la Management API.

## MCP de la documentación

El MCP de la documentación es un endpoint aparte para buscar y leer la documentación de Phaseo. No accede a tu cuenta ni a tu espacio de trabajo.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

## Plugin de Phaseo

El plugin de Phaseo incluye el MCP de Phaseo, el MCP de la documentación y las skills de agente de Phaseo para integración, migración, selección de modelos, supervisión del uso, los SDKs y la CLI. Instálalo una vez en lugar de conectar cada pieza por tu cuenta.

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

Ejecuta `/mcp` e inicia sesión en `plugin:phaseo:phaseo` para conectar tu cuenta de Phaseo. Las skills se cargan cuando una solicitud coincide con ellas, o puedes ejecutar una directamente, como `/phaseo:phaseo-gateway`.

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

El último comando abre OAuth de Phaseo para el MCP de Phaseo. Las skills se cargan cuando una solicitud coincide con ellas.
