# CLI y MCP

Usa Phaseo desde el terminal con la CLI o conecta un cliente de IA mediante MCP. Ambos usan Phaseo OAuth, pero sirven para tareas distintas.

| Interfaz | Ideal para | Acceso |
| --- | --- | --- |
| Phaseo CLI | Flujos de trabajo en el terminal, CI, administración y automatización | Lectura y escritura, según tus ámbitos y el rol de tu espacio de trabajo |
| Phaseo MCP | Datos actuales de Phaseo en Codex, Claude, ChatGPT y otros clientes MCP, y gestión opcional de la cuenta | Autenticado; de solo lectura salvo que te conectes con gestión de la cuenta |
| Docs MCP | Consultar la documentación actual de Phaseo mientras programas | Solo documentación y de solo lectura |
| Plugin de Phaseo | Instalar Phaseo MCP, Docs MCP y las skills de Phaseo en Claude Code o Codex de una vez | Igual que cada servidor MCP |

## Phaseo CLI

Usa la CLI para crear o modificar recursos de Phaseo, automatizar un flujo de trabajo o consultar los datos de la cuenta desde un shell.

### Instalar e iniciar sesión

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

Los terminales interactivos usan OAuth en el navegador de forma predeterminada. Para SSH, CI y entornos sin interfaz, usa la autorización mediante dispositivo:

```bash
phaseo login --device-code
```

### Flujos de trabajo habituales

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys create --name "Local development"
phaseo logs list --since 1h --status error --json
```

Usa `--json` cuando otra herramienta o un script necesite datos estructurados. Los valores secretos solo aparecen en comandos que los crean o revelan explícitamente.

## Phaseo MCP

Conecta el servidor MCP de Phaseo cuando quieras que un cliente de IA responda preguntas con datos actuales sobre modelos, precios, proveedores, uso y espacios de trabajo.

### URL del servidor

`https://mcp.phaseo.app/mcp`

### Conectar desde Codex

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

El comando de inicio de sesión abre Phaseo OAuth. Elige un espacio de trabajo, aprueba los ámbitos de lectura solicitados y confirma la conexión:

```bash
codex mcp list
```

Para otro cliente MCP, añade la misma URL como servidor HTTP remoto con streaming. El cliente debe admitir el descubrimiento OAuth, el flujo de código de autorización con S256 PKCE y el parámetro `resource` de MCP.

### Datos disponibles en MCP

- modelos, proveedores, clasificaciones de benchmarks, precios y estimaciones de costo
- créditos, actividad, analíticas, registros de solicitudes y metadatos de generación

Estas herramientas son de solo lectura. Nunca devuelven prompts, respuestas ni valores secretos.

### Gestionar tu cuenta (opcional)

Para que un agente pueda modificar tu espacio de trabajo de Phaseo, conéctate con la URL de gestión:

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

Al iniciar sesión, la pantalla de consentimiento muestra cada permiso que solicita la conexión, como gestionar claves de API o eliminar presupuestos, y lo marca como **Lectura**, **Escritura** o **Eliminación**. Desmarca los que no quieras conceder. El agente solo recibe herramientas para los permisos que autorizas, y Phaseo sigue comprobando tu rol en el espacio de trabajo en cada cambio, así que un miembro que no sea propietario ni administrador no puede cambiar por esta vía los ajustes reservados a administradores.

Si ya te conectaste con la URL de solo lectura, cambia el cliente a la URL de gestión y vuelve a iniciar sesión. Para volver al acceso de solo lectura, conéctate de nuevo con la URL normal o revoca la aplicación en **Ajustes → Aplicaciones conectadas**.

| Área | Herramientas | Permisos |
| --- | --- | --- |
| Claves de API | `api_keys_list`, `api_key_get`, `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete` | `keys:read`, `keys:write`, `keys:delete` |
| Presupuestos | `budgets_list`, `budget_create`, `budget_update`, `budget_delete` | `budgets:read`, `budgets:write`, `budgets:delete` |
| Reglas de gasto | `spend_rules_list`, `spend_rule_create`, `spend_rule_update`, `spend_rule_delete` | `spend_rules:read`, `spend_rules:write`, `spend_rules:delete` |
| Claves de proveedor (BYOK) | `provider_keys_list`, `provider_key_create`, `provider_key_update`, `provider_key_delete` | `provider_credentials:read`, `provider_credentials:write`, `provider_credentials:delete` |
| Barreras de seguridad | `guardrails_list`, `guardrail_get`, `guardrail_create`, `guardrail_update`, `guardrail_delete`, `guardrail_keys_set` | `guardrails:read`, `guardrails:write`, `guardrails:delete` |
| Preajustes | `presets_list`, `preset_get`, `preset_create`, `preset_update`, `preset_version_publish` | `presets:read`, `presets:write` |
| Ajustes | `settings_get`, `settings_update` (modo de enrutamiento, privacidad y ZDR, registro, restricciones de proveedores) | `settings:read`, `settings:write` |
| Webhooks | `webhooks_list`, `webhook_create`, `webhook_delete` | `settings:read`, `settings:write` |
| Destinos de observabilidad | `observability_destinations_list`, `observability_destination_create`, `observability_destination_delete` | `settings:read`, `settings:write` |

Las herramientas que modifican o eliminan algo están marcadas como tales, de modo que los clientes MCP compatibles te piden confirmación antes de cada llamada. Una nueva clave de API o un nuevo secreto de firma de webhook se muestra una sola vez en el resultado de la herramienta y no se puede volver a mostrar. Las claves de proveedor guardadas y las credenciales de los destinos nunca se devuelven.

MCP no incluye herramientas de facturación, pagos, espacios de trabajo, miembros, claves de administración ni aplicaciones OAuth. Para eso, usa el panel, la CLI o la API de administración.

## Docs MCP

Docs MCP es un endpoint independiente para buscar y consultar la documentación de Phaseo. No accede a tu cuenta ni a tu espacio de trabajo.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

Úsalo cuando un asistente de programación necesite ejemplos actuales de la API, guías de integración o documentación de funciones.

## Plugin de Phaseo

El plugin de Phaseo reúne Phaseo MCP, Docs MCP y las skills de Phaseo para agentes sobre integración, migración, selección de modelos, supervisión del uso, los SDK y la CLI. Instálalo una vez en lugar de conectar cada pieza por tu cuenta.

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

Ejecuta `/mcp` e inicia sesión en `plugin:phaseo:phaseo` para conectar tu cuenta de Phaseo. Las skills se cargan cuando una solicitud coincide con ellas, o puedes ejecutar una directamente, como `/phaseo:phaseo-gateway`.

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

El último comando abre Phaseo OAuth para Phaseo MCP. Las skills se cargan cuando una solicitud coincide con ellas.

## Elige la interfaz adecuada

- Usa la **CLI** para crear claves, cambiar ajustes, gestionar espacios de trabajo o automatizar tareas administrativas.
- Usa **Phaseo MCP** para dar a un cliente de IA acceso seguro a datos actuales de Phaseo.
- Usa **Docs MCP** para dar a un asistente de programación acceso a la documentación actual de Phaseo sin acceder a tu cuenta.
- Usa el **plugin de Phaseo** para configurar ambos servidores MCP y las skills de Phaseo en Claude Code o Codex de una vez.
