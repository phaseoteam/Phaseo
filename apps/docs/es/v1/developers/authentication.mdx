title: "Autenticación"
description: "Usa claves de API para autenticar cada solicitud a Phaseo Gateway."

---

Crea una clave con `phaseo keys create --name <name> --json` en la [CLI de Phaseo](../guides/integrations/phaseo-cli) o en el [panel](https://phaseo.app/settings/keys), guárdala en tu servidor y envíala como token bearer en cada solicitud al Gateway. Los agentes deben usar la CLI; consulta [Gestiona Phaseo desde un agente](./manage-from-an-agent).

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

Define la cabecera una sola vez en tu cliente. Por ejemplo, con `fetch`:

```ts
const response = await fetch("https://api.phaseo.app/v1/chat/completions", {
	method: "POST",
	headers: {
		Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
		"Content-Type": "application/json",
	},
	body: JSON.stringify({
		model: "openai/gpt-6-astra",
		messages: [
			{ role: "system", content: "You are a helpful assistant." },
			{ role: "user", content: "Summarize the drawbacks to AI." },
		],
	}),
});
```

<Note>
Puedes llamar a los modelos `:free` sin depositar créditos. Los modelos de pago necesitan saldo disponible en el monedero.
</Note>

## Elige una credencial

| Credencial | Formato | Úsala para |
| --- | --- | --- |
| Clave de API del Gateway | `phaseo_v1_sk_<kid>_<secret>` | Los endpoints de modelos, proveedores y generación disponibles para tu espacio de trabajo. |
| [Clave de API de gestión](./management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | Las APIs de administración. |
| [Carga de trabajo de confianza](./trusted-workloads.mdx) (beta) | Un token OIDC de corta duración de la plataforma | Despliegues y trabajos de CI en Vercel, GitHub Actions, GitLab, Google Cloud, Buildkite, CircleCI, AWS o tu propio emisor OIDC, sin ninguna clave almacenada. |

Trata las claves como contraseñas: mantenlas fuera del código del lado del cliente y de los repositorios públicos.

## Maneja las claves de forma segura

- **Una clave por aplicación y entorno**, para poder rotar una sin afectar a otros servicios.
- **Guarda las claves en un gestor de secretos**, que las mantiene fuera de los registros y del seguimiento de errores.
- **Vigila el uso por clave** en el panel para detectar anomalías.
- **Elimina las claves que ya no uses.**

Para rotar una clave, pasa tu aplicación a la clave de sustitución antes de invalidar la anterior. Consulta el [endpoint de rotación de claves](../api-reference/endpoint/keys-rotate.mdx).

## Corrige errores de autenticación

| Estado | Causa | Qué hacer |
| --- | --- | --- |
| `401` | Falta la clave, no es válida o pertenece a un espacio de trabajo desactivado. El `reason` del cuerpo indica cuál de estos casos es. | Comprueba la cabecera y la clave. |
| `403` | La clave es válida, pero no puede usar el proveedor o el modelo solicitado. | Revisa los guardrails de la clave y los ajustes de proveedores del espacio de trabajo. |
| `429` | La clave o el espacio de trabajo alcanzó un límite. | Consulta [Límites de solicitudes](../api-reference/limits.mdx). |
| `5xx` | Falló Phaseo o el proveedor. | Reintenta con espera exponencial y contacta con [soporte](https://phaseo.app/help) si persiste. |

Consulta [Errores y depuración](../api-reference/errors.mdx) para ver todos los códigos de error.
