Instala `@phaseo/ai-sdk-provider` y pasa `phaseo("<model id>")` como modelo en cualquier llamada de AI SDK. El proveedor lee `PHASEO_API_KEY` del entorno.

## Instalar

```bash
npm install @phaseo/ai-sdk-provider
```

El paquete sin versión sigue la etiqueta `latest` de npm, que es la línea de AI SDK 7, y declara `ai@^7` como dependencia par que npm instala por ti. Para un AI SDK anterior, instala la etiqueta correspondiente:

| AI SDK | Contrato del proveedor | Instalación |
| --- | --- | --- |
| 7 (actual) | `ProviderV4` (proveedor 2.x) | `npm install @phaseo/ai-sdk-provider` |
| 6 | `ProviderV3` (proveedor 1.x, mantenimiento) | `npm install @phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `ProviderV2` | `npm install @phaseo/ai-sdk-provider@ai-sdk-v5` |

Si tu gestor de paquetes no instala las dependencias pares, instala también la versión principal de `ai` correspondiente (`ai@^7`, `ai@^6` o `ai@^5`).

Cuando AI SDK 8 sea estable, Phaseo marcará el proveedor 1.x como obsoleto en npm. Las versiones existentes no se eliminarán, y cualquier fin de soporte se anunciará por separado.

## Generar texto

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Summarize this in one sentence.",
});

console.log(result.text);
```

El mismo código funciona en las tres líneas. Usa los ID de modelo del [endpoint Models](../../api-reference/endpoint/models.mdx); cada capacidad sigue dependiendo del modelo y del proveedor de origen.

## Qué admite cada línea

| Función | AI SDK 7 (proveedor 2.x) | AI SDK 5 |
| --- | --- | --- |
| Generación de texto y streaming | Sí | Sí |
| Herramientas de funciones e idas y vueltas con resultados de herramientas | Sí, incluidas las entradas de herramientas en streaming | Sí |
| Salida estructurada JSON y JSON Schema | Sí | Sí |
| Embeddings y generación de imágenes | Sí | Sí |
| Transcripción y voz | Sí | Sí |
| Reordenación (reranking) | Sí | No |
| Ajustes y salida de razonamiento independientes del proveedor | Sí | |
| Entradas de archivos de texto e imagen (datos de archivo etiquetados de V7) | Sí | |
| Fuentes de citas por URL | Sí | |
| Metadatos del proveedor, uso, cabeceras de solicitud, señales de cancelación, fragmentos sin procesar del stream | Sí | |

La columna de AI SDK 7 es lo que el proveedor 2.x implementa y prueba con los contratos nativos v4 de AI SDK 7. La reordenación también está disponible en la línea de AI SDK 6.

## Reordenar documentos

Usa el asistente `rerank()` de AI SDK con `phaseo.rerankingModel(modelId)`:

```ts
import { rerank } from "ai";
import { phaseo } from "@phaseo/ai-sdk-provider";

const result = await rerank({
	model: phaseo.rerankingModel("voyage/rerank-2"),
	query: "Which document is about TypeScript?",
	documents: [
		"TypeScript adds static types to JavaScript.",
		"Rust is a systems programming language.",
	],
	topN: 1,
});
```

## Límites conocidos

- El proveedor no anuncia funciones de `ProviderV4` que necesitan superficies de la API de Phaseo que todavía no existen: subidas y referencias de archivos gestionados, skills, y definiciones, resultados o respuestas de aprobación de herramientas ejecutadas por el proveedor.
- Las herramientas de funciones que ejecuta tu aplicación siguen usando el flujo normal de ejecución y aprobación de AI SDK.
- Las partes de prompt específicas del proveedor o personalizadas que no se admiten fallan con un error claro en lugar de descartarse.
