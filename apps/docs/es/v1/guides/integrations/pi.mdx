Ejecuta `phaseo pi` para añadir a Pi una extensión de proveedor de Phaseo con todos los modelos compatibles de Phaseo.

## Configura con la CLI de Phaseo

```bash
phaseo login
phaseo pi
```

Si falta Pi, la CLI muestra el comando de instalación oficial y pide confirmación antes de ejecutarlo. Después, la configuración crea una `Phaseo CLI: Pi API Key` (caduca a los 90 días, límite de gasto mensual de $100) y escribe una extensión de proveedor en `~/.pi/agent/extensions/phaseo.ts`. La extensión incluye todos los modelos de texto activos de Phaseo que funcionan con Chat Completions.

| Flag | Efecto |
| --- | --- |
| `--model <id>` | Establece el modelo inicial. Por defecto, `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | Añade solo el modelo seleccionado. |
| `--dry-run` | Muestra los cambios en los archivos sin hacerlos. |

La extensión obtiene su clave en el momento de la solicitud con la sintaxis de Pi para claves obtenidas mediante un comando, así que no se escribe ninguna clave en texto plano en el archivo:

```text
!phaseo integrations credential pi
```

## Comprueba que funciona

```bash
pi
```

Abre `/model`, elige el proveedor `phaseo` y envía un prompt corto. Confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Quita Phaseo

```bash
phaseo integrations remove pi
```

Esto quita solo la extensión de Phaseo y revoca la clave.
