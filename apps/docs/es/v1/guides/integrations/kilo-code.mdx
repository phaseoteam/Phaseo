Ejecuta `phaseo kilo` para iniciar una sesión de la CLI de Kilo Code a través de Phaseo, o crea una clave con `phaseo kilo-code` y añade un proveedor personalizado en la extensión de Kilo Code.

## Ejecuta la CLI de Kilo Code a través de Phaseo

```bash
phaseo login
phaseo kilo --model openai/gpt-5.6-terra
```

El ejecutor escribe un archivo `KILO_CONFIG` temporal, inicia `kilo` y borra el archivo cuando Kilo se cierra, así que tu configuración actual de Kilo Code o VS Code no cambia. Si falta Kilo, una ejecución interactiva ofrece instalarlo. Pon los flags propios de Kilo después de `--`.

| Flag | Efecto |
| --- | --- |
| `--model <id>` | Modelo que se usa. Por defecto, `openai/gpt-5.6-terra`. |
| `--catalog all` | Muestra en Kilo todos los modelos de texto activos de Phaseo, no solo el seleccionado. |
| `--dry-run --json` | Muestra el plan de instalación e inicio sin crear una clave ni iniciar Kilo. |
| `--skip-install` | Omite la comprobación de instalación. |

`phaseo run kilo ...` es la forma larga del mismo comando.

## Configura la extensión de Kilo Code

Crea una clave para la extensión:

```bash
phaseo login
phaseo kilo-code --model anthropic/claude-sonnet-5.5
```

Después, en VS Code:

1. Abre Kilo Code, selecciona el icono de ajustes, abre **Providers** y selecciona **Add custom provider**.
2. Introduce:

| Campo de Kilo Code | Valor |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.phaseo.app/v1` |
| API key | Salida de `phaseo integrations credential kilo-code` |

3. Si no se descubre ningún modelo, añade tú el ID `anthropic/claude-sonnet-5.5`.
4. Selecciona **Submit** y elige el modelo de Phaseo.

Kilo muestra la selección como `phaseo/anthropic/claude-sonnet-5.5`. `phaseo` es el ID del proveedor local; el resto es el ID de modelo que se envía a Phaseo. Consulta la documentación de [modelos personalizados](https://kilo.ai/docs/code-with-ai/agents/custom-models) de Kilo para ver el formulario completo.

## Comprueba que funciona

Pide a Kilo Code que responda con `PHASEO_KILO_OK` y confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Quita Phaseo

Elimina el proveedor personalizado en Kilo Code y después ejecuta:

```bash
phaseo integrations remove kilo-code
```

Esto revoca la clave. La CLI no puede borrar el almacenamiento de la extensión.

## Soluciona problemas habituales

### No se descubre ningún modelo

Añade tú el modelo. Kilo no necesita descubrirlo mediante `/models`.

### La autenticación falla

Sustituye la clave guardada por la salida de `phaseo integrations credential kilo-code` y deja la Base URL exactamente como se muestra.

### El nombre del modelo se ve distinto

Selecciona `phaseo/<Phaseo model ID>` en Kilo, pero no añadas `phaseo/` en el campo del ID del modelo.
