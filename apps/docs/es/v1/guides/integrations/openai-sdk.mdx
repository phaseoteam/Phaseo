Haz que el SDK oficial de OpenAI use Phaseo cambiando tres cosas: la clave de API, la URL base (`https://api.phaseo.app/v1`) y el ID del modelo.

## Instala

<CodeGroup>

```bash TypeScript
npm install openai
```

```bash Python
pip install openai
```

</CodeGroup>

## Haz que el cliente use Phaseo

<CodeGroup>

```ts TypeScript
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Write one sentence about reliable model routing.",
});

console.log(response.output_text);
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Write one sentence about reliable model routing.",
)

print(response.output_text)
```

</CodeGroup>

Si se imprime una frase, la clave y la URL base funcionan. La solicitud también aparece en **Ajustes → Uso → Registros**.

## Usa Chat Completions

El código que llama a Chat Completions funciona con el mismo cliente:

```ts
const completion = await client.chat.completions.create({
	model: "openai/gpt-6-astra",
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## Límites conocidos

- Usa IDs de modelo de Phaseo, con el prefijo del proveedor: `openai/`, `anthropic/`, `google/`, etc. Consulta [Responses](../../api-reference/endpoint/responses.mdx) y [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) para ver la forma completa de las solicitudes.
- Las [herramientas de servidor](../server-tools/index.mdx) usan nombres de herramienta de Phaseo, como `phaseo:web_search`.
- Para clientes de `/v1/messages` de estilo Anthropic, usa la guía del [SDK de Anthropic](./anthropic-sdk.mdx).
