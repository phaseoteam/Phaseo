Dirige el SDK de Anthropic a `https://api.phaseo.app` y pasa tu clave de Phaseo como token de autenticación. Úsalo con aplicaciones, agentes y herramientas de programación que envían solicitudes `/v1/messages` al estilo de Claude; Phaseo las atiende como [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx).

## Instalar

<CodeGroup>

```bash TypeScript
npm install @anthropic-ai/sdk
```

```bash Python
pip install anthropic
```

</CodeGroup>

## Dirigir el cliente a Phaseo

<CodeGroup>

```ts TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
	apiKey: null,
	authToken: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app",
});

const message = await client.messages.create({
	model: "anthropic/claude-sonnet-5.5",
	max_tokens: 512,
	messages: [{ role: "user", content: "Reply with only: ok" }],
});

console.log(message.content);
```

```python Python
import os
from anthropic import Anthropic

client = Anthropic(
    auth_token=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app",
)

message = client.messages.create(
    model="anthropic/claude-sonnet-5.5",
    max_tokens=512,
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(message.content)
```

</CodeGroup>

Un bloque de texto que contiene `ok` significa que la configuración funciona.

| Ajuste | Por qué |
| --- | --- |
| `baseURL: "https://api.phaseo.app"` | Usa el host raíz. Los clientes de Anthropic añaden `/v1/messages` por sí mismos. |
| `authToken` (`auth_token` en Python) | Envía `Authorization: Bearer` en todas las versiones del SDK. Phaseo no acepta `x-api-key`, que es lo que envía `apiKey` antes de `@anthropic-ai/sdk` 1.0 y `anthropic` 2.0. |
| `apiKey: null` | Evita que los SDK de TypeScript antiguos envíen también tu `ANTHROPIC_API_KEY`. Los SDK de Python anteriores a 0.98 la envían siempre que está definida, así que actualiza o elimínala donde llames a Phaseo. |

## Límites conocidos

- Las formas nativas de herramientas de Anthropic funcionan donde Phaseo las admite. Las herramientas del servidor que funcionan con todos los proveedores usan nombres de herramientas de Phaseo; consulta [Llamadas a herramientas](../tool-calling.mdx).
- Los clientes compatibles con Anthropic son estrictos con el orden de los eventos de herramientas. Prueba los ciclos de herramientas en streaming antes de pasar a producción.
- Para [Claude Code](./claude-code.mdx), usa su propia guía.
