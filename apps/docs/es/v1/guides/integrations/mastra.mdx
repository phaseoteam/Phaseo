Crea un proveedor OpenAI de AI SDK con tu clave de Phaseo y `baseURL: "https://api.phaseo.app/v1"`, y pasa sus modelos a los agentes y flujos de trabajo de Mastra.

## Instala

```bash
npm install @mastra/core @ai-sdk/openai ai
```

## Haz que un agente de Mastra use Phaseo

```ts
import { Agent } from "@mastra/core/agent";
import { createOpenAI } from "@ai-sdk/openai";

const phaseo = createOpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
	compatibility: "compatible",
});

export const agent = new Agent({
	name: "support-agent",
	instructions: "Answer in two short paragraphs.",
	model: phaseo("openai/gpt-6-astra"),
});
```

Usa solo la URL base, sin `/chat/completions` ni `/responses`. Ejecuta el agente una vez con un prompt corto y confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Límites conocidos

- El comportamiento de los agentes de Mastra depende del proveedor de AI SDK. Prueba las [llamadas a herramientas](../tool-calling.mdx) y el streaming antes de pasar a producción.
- Para dar preferencia a ciertos proveedores, establece los controles de enrutamiento de Phaseo en la solicitud o en un [preajuste](../presets.mdx).
