Llama a Phaseo desde cualquier plataforma de automatización que pueda enviar una solicitud HTTP autenticada: añade un paso HTTP que haga POST a `https://api.phaseo.app/v1/responses` con tu clave como token bearer. Phaseo no tiene una aplicación nativa para Zapier, n8n ni Pipedream.

## Crear la solicitud

| Ajuste | Valor |
| --- | --- |
| Método | `POST` |
| URL | `https://api.phaseo.app/v1/responses` |
| Encabezado | `Authorization: Bearer <PHASEO_API_KEY>` |
| Encabezado | `Content-Type: application/json` |

```json
{
  "model": "openai/gpt-6-astra",
  "input": "Summarise the supplied workflow data in one paragraph."
}
```

Guarda la clave en el almacén de credenciales o secretos de la plataforma, no en una definición de flujo de trabajo compartida. Consulta [Responses](../../api-reference/endpoint/responses.mdx) para ver todos los campos de la solicitud.

## Zapier

Usa **Webhooks by Zapier → Custom Request**:

1. Selecciona `POST` e introduce `https://api.phaseo.app/v1/responses`.
2. Añade los encabezados de bearer y de tipo de contenido.
3. Asigna a `input` campos de pasos anteriores del Zap.
4. Prueba el Zap con datos no sensibles.

## n8n

Usa el nodo **HTTP Request** con autenticación bearer y un cuerpo JSON. Asigna el elemento de entrada a `input` con una expresión de n8n.

## Pipedream

Usa un paso de solicitud HTTP o un paso de código Node.js. Guarda `PHASEO_API_KEY` como secreto de Pipedream y léelo desde el entorno del paso.

## Comprobar que funciona

Ejecuta el paso una vez. Una respuesta `200` con un array `output` significa que la clave y la URL funcionan, y la solicitud aparece en **Ajustes → Uso → Registros**.

## Ejecutar automatizaciones de forma segura

- Da a cada automatización su propia clave con un límite de gasto, para poder seguirla y revocarla por separado.
- Usa [salidas estructuradas](../structured-outputs.mdx) cuando los pasos posteriores esperen campos legibles por máquina.
- Reintenta ante respuestas `429` y `5xx` recuperables; consulta [Errores](../../api-reference/errors.mdx).
- No repitas acciones externas que no sean idempotentes solo porque se reintentó un paso del modelo.
