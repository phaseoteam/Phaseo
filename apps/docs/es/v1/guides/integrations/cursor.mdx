Ejecuta `phaseo cursor` para crear una clave y después activa los ajustes de clave de API de OpenAI y **Override OpenAI Base URL** de Cursor. Así, los modelos de chat de Cursor pasan por Phaseo; las funciones que usan los modelos propios de Cursor, como el autocompletado con Tab, pueden seguir usando la infraestructura de Cursor.

## Configura con la CLI de Phaseo

```bash
phaseo login
phaseo cursor --model openai/gpt-5.6-terra
```

La CLI crea una `Phaseo CLI: Cursor API Key` que caduca a los 90 días y tiene un límite de gasto mensual de $100, y muestra los ajustes de abajo. Cuando caduque, vuelve a ejecutar `phaseo cursor` para obtener una clave nueva. La CLI no edita el almacén de credenciales de Cursor.

## Configura Cursor

1. Abre **Cursor Settings → Models**.
2. Busca la sección **OpenAI API Key** y actívala.
3. Pega la clave de `phaseo integrations credential cursor`, o cualquier clave de API de Phaseo.
4. Activa **Override OpenAI Base URL** e introduce `https://api.phaseo.app/v1`, sin barra final.
5. Añade o activa el modelo de Phaseo que quieras.

| Campo de Cursor | Valor |
| --- | --- |
| OpenAI API Key | Salida de `phaseo integrations credential cursor` |
| Override OpenAI Base URL | `https://api.phaseo.app/v1` |
| Model | Un ID de modelo de Phaseo que Cursor acepte |

Los ajustes de clave y Base URL de Cursor son globales, no por proveedor: la clave y la Base URL activadas deciden adónde va cada solicitud de la familia OpenAI, y el nombre del modelo se reenvía tal cual. Algunas versiones guardan la clave sin un botón **Verify**; en ese caso, prueba con un chat nuevo. Consulta la [documentación de claves de API](https://docs.cursor.com/settings/api-keys) de Cursor.

## Comprueba que funciona

1. Mantén activadas la clave y la sustitución de la Base URL.
2. Selecciona el modelo en el selector de modelos de Cursor e inicia un chat nuevo.
3. Pídele que responda con `PHASEO_CURSOR_OK`.
4. Confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Quita Phaseo

Desactiva la clave de API de OpenAI y la sustitución de la Base URL en **Cursor Settings → Models**, y después revoca la clave:

```bash
phaseo integrations remove cursor
```

La CLI no puede borrar el almacenamiento de credenciales de Cursor. Si la clave sigue apareciendo como configurada, elimínala en los ajustes de Models de Cursor.

## Soluciona problemas habituales

### Los modelos alojados por Cursor dejan de funcionar

Cursor aplica la sustitución de la Base URL a todos los modelos de la familia OpenAI. Desactiva **Override OpenAI Base URL** antes de volver a un modelo alojado por Cursor.

### Se rechaza el modelo

Cursor puede rechazar IDs que coinciden con su catálogo integrado o que no encajan en su enrutamiento de la familia OpenAI, y algunas versiones rechazan IDs con prefijo de proveedor. Prueba otro modelo de Phaseo que Cursor acepte como modelo personalizado de la familia OpenAI.

### La autenticación falla

Vuelve a ejecutar `phaseo integrations credential cursor`, sustituye la clave en Cursor y comprueba que la Base URL es exactamente `https://api.phaseo.app/v1`.
