Pasa a LiteLLM el modelo `openai/<Phaseo model ID>`, tu clave de Phaseo y `api_base="https://api.phaseo.app/v1"`. Funciona tanto en llamadas directas a LiteLLM como con modelos detrás de un proxy de LiteLLM.

## Instala

```bash
pip install litellm
```

## Llama a Phaseo desde LiteLLM

```python
import os
from litellm import completion

response = completion(
    model="openai/openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(response.choices[0].message.content)
```

Si se imprime `ok`, la configuración funciona. LiteLLM usa el prefijo `openai/` para los endpoints compatibles con OpenAI. El ID del modelo en Phaseo sigue siendo `openai/gpt-6-astra`, así que la cadena del modelo en LiteLLM queda como `openai/openai/gpt-6-astra`.

## Añade modelos de Phaseo a un proxy de LiteLLM

Da a cada modelo un alias para que el código de la aplicación no necesite el prefijo de LiteLLM:

```yaml
model_list:
  - model_name: phaseo-gpt-6-astra
    litellm_params:
      model: openai/openai/gpt-6-astra
      api_key: os.environ/PHASEO_API_KEY
      api_base: https://api.phaseo.app/v1
```

Después llama al proxy con `model: "phaseo-gpt-6-astra"`. Los alias mantienen legibles los nombres de los modelos en producción.

## Límites conocidos

- Algunas capas de proxy cambian o descartan los tipos de herramienta que no conocen. Si usas [herramientas de servidor](../server-tools/index.mdx) de Phaseo, prueba la ruta exacta de LiteLLM.
- Tanto LiteLLM como Phaseo registran el gasto. Decide cuál de los dos es tu registro de costes; los precios de Phaseo están en la [calculadora de precios](../../api-reference/endpoint/pricing-calculate.mdx).
