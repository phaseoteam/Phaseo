---
title: "Roo Code"
description: "Conecta Roo Code a Phaseo mediante un perfil OpenAI compatible."
---

La CLI de Phaseo crea y administra la clave exclusiva de Roo Code. Roo Code guarda las credenciales en el almacenamiento seguro de VS Code, así que debes completar el perfil en la extensión.

## Crear la credencial

```bash
phaseo login
phaseo integrations setup roo-code --model anthropic/claude-sonnet-4.6
```

## Configurar Roo Code

1. Abre Roo Code en VS Code.
2. Abre **Settings** y luego **Providers**.
3. Crea un perfil de configuración del proveedor y elige **OpenAI Compatible**.
4. Introduce estos valores:

| Campo de Roo Code | Valor |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | Salida de `phaseo integrations credential roo-code` |
| Model | `anthropic/claude-sonnet-4.6` o el modelo que indique la configuración |

5. Guarda el perfil y actívalo.

Las etiquetas de los campos pueden variar ligeramente entre versiones, pero el perfil necesita el endpoint, la clave y el ID de modelo exacto.

## Verificar

Pide a Roo Code que responda `PHASEO_ROO_OK` y confirma que la solicitud aparezca en la actividad de Phaseo.

## Eliminar

Elimina el perfil de Phaseo o cambia de perfil y luego ejecuta:

```bash
phaseo integrations remove roo-code
```

La CLI no puede eliminar valores del almacenamiento privado de extensiones de VS Code, pero al quitarla se revoca la clave.

## Solución de problemas

### Falla la autenticación

Vuelve a obtener la clave con `phaseo integrations credential roo-code`. Asegúrate de que la URL base termine en `/v1`.

### Roo Code no encuentra el modelo

Introduce manualmente el ID exacto del modelo Phaseo, incluido el prefijo del proveedor.

### El chat funciona, pero las herramientas fallan

Cambia a un modelo compatible con llamadas a herramientas.
