Ejecuta `phaseo roo-code` para crear una clave y después añade un perfil **OpenAI Compatible** en Roo Code. Roo Code guarda las claves en el almacenamiento de secretos de VS Code, así que ese último paso se hace en su interfaz.

## Configura con la CLI de Phaseo

```bash
phaseo login
phaseo roo-code --model anthropic/claude-sonnet-5.5
```

La CLI crea una `Phaseo CLI: Roo Code API Key` que caduca a los 90 días y tiene un límite de gasto mensual de $100, y después muestra los valores para el siguiente paso.

## Configura Roo Code

1. Abre Roo Code en VS Code y después **Settings → Providers**.
2. Crea un perfil de configuración de proveedor y elige **OpenAI Compatible**.
3. Introduce:

| Campo de Roo Code | Valor |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | Salida de `phaseo integrations credential roo-code`, o cualquier clave de API de Phaseo |
| Model | `anthropic/claude-sonnet-5.5`, o el modelo que muestra la configuración |

4. Guarda el perfil y actívalo.

Los nombres de los campos cambian un poco entre versiones; consulta la documentación de [proveedores de modelos](https://docs.roocode.com/providers/) de Roo Code si los tuyos son distintos.

## Comprueba que funciona

Pide a Roo Code que responda con `PHASEO_ROO_OK` y confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Quita Phaseo

Elimina el perfil de Phaseo o cambia de perfil, y después ejecuta:

```bash
phaseo integrations remove roo-code
```

Esto revoca la clave. La CLI no puede borrar el almacenamiento de la extensión de VS Code.

## Soluciona problemas habituales

### La autenticación falla

Vuelve a copiar la clave con `phaseo integrations credential roo-code` y comprueba que la Base URL termina en `/v1`.

### Roo Code no encuentra el modelo

Escribe el ID exacto del modelo de Phaseo, incluido su prefijo de proveedor.

### El chat funciona, pero las herramientas fallan

Cambia a un modelo compatible con llamadas a herramientas.
