Elige el ejecutor de Phaseo CLI para una sesión aislada, o crea una clave dedicada con la CLI y configura manualmente una instalación existente de Cline. Cline guarda las credenciales en el almacenamiento seguro de secretos de VS Code, por lo que la introducción final se realiza en la interfaz de la extensión.

## Ejecuta Cline con Phaseo CLI

Para la CLI de Cline, deja que Phaseo prepare la configuración del proveedor para una sesión:

```bash
phaseo login
phaseo cline --model openai/gpt-5.6-terra -- --tui
```

Usa `--catalog all` para mostrar todos los modelos activos de texto/chat de Phaseo, o `--dry-run --json` para previsualizar el plan de instalación e inicio. Usa `phaseo run cline ...` para la forma explícita del comando. El ejecutor usa ajustes y directorios de datos temporales de Cline, por lo que no sobrescribe una configuración existente de Cline o VS Code.

## Crea la credencial con Phaseo CLI

```bash
phaseo login
phaseo setup cline --model anthropic/claude-sonnet-4.6
```

## Configura Cline manualmente

1. Abre el panel de Cline en VS Code.
2. Selecciona el icono de configuración o el proveedor que aparece debajo del cuadro de chat.
3. Elige **OpenAI Compatible**.
4. Introduce estos valores:

| Campo de Cline | Valor |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | Salida de `phaseo integrations credential cline` |
| Model ID | `anthropic/claude-sonnet-4.6` o el modelo que indique la configuración |

5. Guarda el proveedor. Si tu versión muestra **Verify**, selecciónalo.
6. Selecciona el modelo configurado para la siguiente tarea.

## Verificar

Pídele a Cline que responda `PHASEO_CLINE_OK` y confirma que la solicitud aparece en la actividad de Phaseo.

## Eliminar

Elimina o cambia el proveedor de Phaseo en Cline y luego ejecuta:

```bash
phaseo integrations remove cline
```

La CLI no puede borrar el almacenamiento privado de extensiones de VS Code, pero la eliminación revoca la clave almacenada.

## Solución de problemas

### Falla la verificación

Mantén la URL base exactamente como se muestra, incluido `/v1`, y pega una clave recién recuperada sin comillas ni espacios en blanco.

### La lista de modelos está vacía

Introduce manualmente el ID del modelo de Phaseo. No es necesario descubrir modelos.

### El chat funciona, pero las herramientas fallan

Elige un modelo de Phaseo compatible con llamadas a herramientas. La conectividad y la compatibilidad del modelo con herramientas son comprobaciones independientes.
