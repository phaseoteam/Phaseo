Crea un LLM `OpenAILike` con tu clave de Phaseo y `api_base="https://api.phaseo.app/v1"`, y establécelo como predeterminado en LlamaIndex para que la generación de tus flujos de RAG pase por Phaseo.

## Instala

```bash
pip install llama-index llama-index-llms-openai-like llama-index-embeddings-openai-like
```

## Haz que LlamaIndex use Phaseo

```python
import os
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    is_chat_model=True,
)

response = llm.complete("Write one sentence about retrieval quality.")
print(response)
```

Si se imprime una frase, la configuración funciona. `OpenAILike` es la clase de LlamaIndex para APIs de terceros compatibles con OpenAI.

## Úsalo en un índice

```python
from llama_index.core import Settings

Settings.llm = llm
```

Después crea o consulta tu índice como siempre.

## Límites conocidos

- Los valores predeterminados de LlamaIndex no apuntan a Phaseo. Establece explícitamente los modelos de generación y de embeddings.
- Para los [embeddings](../../api-reference/endpoint/embeddings.mdx) de Phaseo, configura el modelo de embeddings con un ID de modelo de Phaseo y la misma URL base.
