Usa TanStack AI si quieres flujos de chat con seguridad de tipos en React, Solid, Preact, Vue, Svelte o TypeScript del lado del servidor.

## Instalar

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## Configurar el adaptador

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-5-nano", "anthropic/claude-sonnet-4.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-5-nano"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## Notas

- Declara en el array `models` los IDs de modelo de Phaseo que vayas a usar.
- El adaptador compatible con OpenAI utiliza Chat Completions de forma predeterminada. Para funciones exclusivas de Responses, usa llamadas directas a la API.
- Si un modelo no admite herramientas o imágenes en tu flujo, declara capacidades más limitadas en TanStack AI para que TypeScript detecte antes las llamadas no compatibles.
