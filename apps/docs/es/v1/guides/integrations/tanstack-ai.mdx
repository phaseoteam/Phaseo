Crea el adaptador `openaiCompatible` de TanStack AI con tu clave de Phaseo, `baseURL: "https://api.phaseo.app/v1"` y los IDs de modelo de Phaseo que uses. Sirve para chat con tipos seguros en React, Solid, Preact, Vue, Svelte o TypeScript en el servidor.

## Instala

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## Haz que el adaptador use Phaseo

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-6-astra", "anthropic/claude-sonnet-5.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-6-astra"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

Declara en `models` todos los IDs de modelo de Phaseo que pienses usar. Comprueba los IDs en [Modelos](../../api-reference/endpoint/models.mdx).

## Límites conocidos

- El adaptador usa Chat Completions. Para funciones exclusivas de Responses, llama a Phaseo directamente o usa el [SDK de OpenAI](./openai-sdk.mdx).
- Si un modelo no admite [herramientas](../tool-calling.mdx) o imágenes, declara capacidades más limitadas en TanStack AI para que TypeScript detecte las llamadas no compatibles.
