Ejecuta `phaseo login` y después `phaseo <agent>` para que un agente de programación use Phaseo con su propia clave de API. Para no usar la CLI, introduce los [valores manuales del proveedor](#enter-the-provider-values-yourself) en los ajustes del agente.

```bash
phaseo login
phaseo codex
```

## Busca el comando de tu agente

La CLI configura cada agente de una de estas tres formas:

- **Configurado**: la CLI escribe el archivo de configuración del agente. Inicia el agente y elige un modelo de Phaseo.
- **Solo clave**: el agente guarda las claves en el almacenamiento de su propia aplicación, así que la CLI crea la clave y muestra los campos que debes rellenar.
- **Sesión**: la CLI inicia el agente con ajustes temporales que se borran cuando se cierra. Tu configuración habitual no cambia.

## Qué crea la CLI

Cada agente recibe su propia clave de API, con su nombre (por ejemplo, `Phaseo CLI: Codex API Key`). La clave caduca a los 90 días y tiene un límite de gasto mensual de $100. Vuelve a ejecutar el comando de configuración para sustituir una clave caducada, y sube el límite con `phaseo keys update <id> --limit`.

Si falta Claude Code, Codex, OpenCode, fx, DeepSeek Harness, Pi, Prime Agent, OpenClaw o Hermes Agent, la CLI muestra el comando de instalación oficial y pide confirmación antes de ejecutarlo. Fuera de una terminal interactiva, muestra el comando de instalación y se detiene. OpenCode, fx, DeepSeek Harness, Pi, Prime Agent y OpenClaw también reciben todos los modelos de texto activos de Phaseo que funcionan con Chat Completions.

| Flag o comando | Efecto |
| --- | --- |
| `--model <id>` | Establece el modelo predeterminado. No se admite en Claude Code. |
| `--catalog default` | Añade solo el modelo seleccionado en lugar de todo el catálogo. |
| `--skip-install` | Omite la comprobación de instalación, para un agente que gestionas tú. |
| `--dry-run` | Muestra los cambios en los archivos sin hacerlos. |
| `phaseo integrations credential <agent>` | Muestra la clave de ese agente, para los agentes en los que la pegas tú. |
| `phaseo integrations remove <agent>` | Borra la configuración que escribió Phaseo y revoca la clave. El resto de tus ajustes se mantiene. |

## Introduce tú los valores del proveedor

Usa estos valores en cualquier agente con un proveedor compatible con OpenAI. Los nombres de los campos varían según la herramienta.

| Ajuste | Valor |
| --- | --- |
| Tipo de proveedor | OpenAI Compatible |
| Base URL | `https://api.phaseo.app/v1` |
| Clave de API | Una clave de API de Phaseo |
| Modelo | Un ID de modelo de Phaseo, como `openai/gpt-6-astra` |

Para agentes que usan la API Messages de Anthropic:

| Ajuste | Valor |
| --- | --- |
| Base URL | `https://api.phaseo.app` (el cliente añade `/v1/messages`) |
| Token de autenticación | Una clave de API de Phaseo |
| Modelo | Un ID de modelo de Phaseo, como `anthropic/claude-sonnet-5.5` |

Algunos agentes rechazan los IDs de modelo que contienen `/`. Si el tuyo lo hace y admite alias, crea un alias local que apunte al ID de modelo de Phaseo.

## Agentes sin guía propia

### VS Code

VS Code puede añadir modelos en su editor de Language Models cuando tu versión incluye un proveedor compatible con OpenAI.

1. Abre la paleta de comandos y ejecuta `Chat: Manage Language Models`.
2. Elige `OpenAI Compatible` u `OAI Compatible`.
3. Introduce tu clave de API de Phaseo y establece el endpoint en `https://api.phaseo.app/v1`.
4. Añade un ID de modelo de Phaseo, como `openai/gpt-6-astra`, y selecciónalo en el selector de modelos del chat.

Si tu versión no tiene un proveedor compatible con OpenAI, usa una extensión que admita proveedores personalizados: [Continue](./continue.mdx), [Cline](./cline.mdx), [Roo Code](./roo-code.mdx) o [Kilo Code](./kilo-code.mdx).

### Claude Desktop

Claude Desktop no puede usar un proveedor de modelos personalizado. Añade [Docs MCP](./docs-mcp.mdx) para darle la documentación de Phaseo, y usa [Claude Code](./claude-code.mdx) cuando necesites Phaseo como gateway de modelos.

### Deep Agents CLI y otras herramientas de LangChain

Usa la URL base y la clave de [LangChain](./langchain.mdx). Si la herramienta lee las variables de entorno de OpenAI, establece estas y pasa un ID de modelo de Phaseo en su campo de modelo:

```bash
export OPENAI_API_KEY="your_phaseo_api_key"
export OPENAI_BASE_URL="https://api.phaseo.app/v1"
```

## Límites conocidos

- Las herramientas de servidor solo funcionan donde el agente las envía: `phaseo:apply_patch` solo está disponible en [Responses](../../api-reference/endpoint/responses.mdx). Para los agentes antiguos que no gestionan los eventos de Responses ni las [herramientas de servidor](../server-tools/index.mdx), es más seguro usar [Chat Completions](../../api-reference/endpoint/chat-completions.mdx).
- Envía una solicitud de chat corta antes de dejar que un agente edite archivos, y elige un modelo compatible con llamadas a herramientas para el trabajo de agentes.
- Añade [Docs MCP](./docs-mcp.mdx) si quieres que el agente lea la documentación de Phaseo durante una sesión.
