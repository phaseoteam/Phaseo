Ejecuta `phaseo codex` para añadir un perfil de Phaseo a Codex, o añade tú un proveedor `phaseo` a `config.toml`. La misma configuración funciona en Codex CLI, Codex App y la extensión de Codex para IDE.

## Configura con la CLI de Phaseo

```bash
phaseo login
phaseo codex --model openai/gpt-5.6-terra
codex --profile phaseo
```

Si falta Codex, la CLI muestra el comando de instalación oficial y pide confirmación antes de ejecutarlo. Después, la configuración crea una `Phaseo CLI: Codex API Key` que caduca a los 90 días y tiene un límite de gasto mensual de $100, la guarda en el almacén de credenciales del sistema operativo y escribe el perfil en `~/.codex/phaseo.config.toml` (o dentro de `CODEX_HOME`). Codex obtiene la clave de la CLI, que crea una nueva cuando la anterior caduca, así que no se escribe ninguna clave en texto plano en la configuración. Sin `--model`, el perfil usa `openai/gpt-5.6-terra`.

## Configura Codex manualmente

Añade esto a `~/.codex/config.toml`, o a `.codex/config.toml` en un proyecto de confianza:

```toml
model = "openai/gpt-6-astra"
model_provider = "phaseo"

[model_providers.phaseo]
name = "Phaseo"
base_url = "https://api.phaseo.app/v1"
env_key = "PHASEO_API_KEY"
wire_api = "responses"
```

Después exporta `PHASEO_API_KEY` e inicia Codex. Los proveedores personalizados de Codex usan el protocolo de Responses, que es el predeterminado, así que también puedes omitir `wire_api`. En la extensión para IDE, abre el archivo desde **Codex Settings → Open config.toml**.

## Comprueba que funciona

Envía un prompt corto y confirma que la solicitud aparece en **Ajustes → Uso → Registros**. Codex llama a [Responses](../../api-reference/endpoint/responses.mdx), así que el modelo debe admitir ese endpoint.

## Quita Phaseo

```bash
phaseo integrations remove codex
```

Esto borra `phaseo.config.toml` si lo creó Phaseo y revoca la clave. En una configuración manual, quita el proveedor `phaseo` de `config.toml`.

## Soluciona problemas habituales

| Error | Solución |
| --- | --- |
| `401 Unauthorized` | Ejecuta `phaseo whoami` y vuelve a ejecutar `phaseo codex`. |
| `model_not_found` | Obtén un ID actual en [Modelos](../../api-reference/endpoint/models.mdx) y actualiza `model`. |
| Falla un proveedor | Consulta [Enrutamiento y alternativas](../routing-and-fallbacks.mdx) para la conmutación por error. |

## Añade las skills y la documentación de Phaseo

Para que Codex lea la documentación actual de Phaseo mientras trabaja, añade el servidor [Docs MCP](./docs-mcp.mdx). Para instalar las [skills de Phaseo](https://phaseo.app/docs/.well-known/agent-skills/index.json) públicas para Codex:

```bash
npx skills add https://phaseo.app/docs --agent codex --skill '*'
```

El mismo flujo de la CLI inicia [Cline](./cline.mdx), [Kilo Code](./kilo-code.mdx), [oh-my-pi](./oh-my-pi.mdx), [Muse Code](./muse-code.mdx) y [MiniMax Code](./minimax-code.mdx) con ajustes temporales.
