Codex admite proveedores de modelos personalizados mediante `config.toml`. Así puedes enrutar sus solicitudes a través de Phaseo sin cambiar tu flujo de trabajo en la CLI, la aplicación o el IDE.

Si también quieres que Codex consulte la documentación actual de Phaseo mientras trabaja, añade también el servidor [Docs MCP](./docs-mcp.mdx).

## Configurar mediante Phaseo CLI

```bash
phaseo login
phaseo codex --model openai/gpt-5.6-terra
```

Instala primero Codex desde su versión oficial. La configuración crea una clave `Phaseo CLI: Codex API Key` que no caduca, la guarda en el almacén de credenciales del sistema operativo y crea un perfil de Phaseo independiente. Codex obtiene la clave mediante el ayudante de CLI, por lo que no se guarda en texto sin formato en `config.toml`.

### Inicia Codex con:

```bash
codex --profile phaseo
```

## Configuración manual

Crea o actualiza tu configuración de usuario en `~/.codex/config.toml`. En un proyecto de confianza, también puedes guardar los mismos ajustes en `.codex/config.toml` dentro del repositorio.

```toml
model = "openai/gpt-5.5"
model_provider = "phaseo"

[model_providers.phaseo]
name = "Phaseo"
base_url = "https://api.phaseo.app/v1"
env_key = "PHASEO_API_KEY"
wire_api = "responses"
```

Codex usa actualmente el protocolo Responses para proveedores personalizados. Conserva `wire_api = "responses"` o elimina esa opción para usar el valor predeterminado.

La aplicación Codex y la extensión IDE comparten las mismas capas de configuración. En la extensión IDE, abre la configuración desde `Codex Settings > Open config.toml`.

## Verificación

- Antes de iniciar, comprueba en [Modelos](../../api-reference/endpoint/models.mdx) que exista el ID del modelo.
- Usa [Responses](../../api-reference/endpoint/responses.mdx) para el flujo predeterminado de Codex.

## Solución de problemas

- `401 Unauthorized`: ejecuta `phaseo whoami` y luego vuelve a ejecutar `phaseo codex`.
- `model_not_found`: obtén un ID actual en [Modelos](../../api-reference/endpoint/models.mdx) y actualiza `model`.
- Problemas específicos del proveedor: consulta [Enrutamiento y fallbacks](../routing-and-fallbacks.mdx) para conocer el comportamiento de conmutación por error.
