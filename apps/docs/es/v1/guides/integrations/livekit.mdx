Haz que el LLM del plugin de OpenAI de LiveKit Agents apunte a `https://api.phaseo.app/v1` con tu clave de Phaseo, y tus agentes de voz usarán los IDs de modelo y el enrutamiento de Phaseo. El plugin llama al endpoint de Chat Completions de Phaseo.

## Instala

<CodeGroup>

```bash Python
uv add "livekit-agents[openai]"
```

```bash Node.js
pnpm add @livekit/agents @livekit/agents-plugin-openai
```

</CodeGroup>

## Haz que el LLM del agente use Phaseo

<CodeGroup>

```python Python
import os
from livekit.agents import AgentSession
from livekit.plugins import openai

session = AgentSession(
    llm=openai.LLM(
        model="openai/gpt-6-astra",
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)
```

```ts Node.js
import { voice } from "@livekit/agents";
import * as openai from "@livekit/agents-plugin-openai";

const session = new voice.AgentSession({
	llm: new openai.LLM({
		model: "openai/gpt-6-astra",
		apiKey: process.env.PHASEO_API_KEY,
		baseURL: "https://api.phaseo.app/v1",
	}),
});
```

</CodeGroup>

Inicia una sesión, di algo y confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Límites conocidos

- Usa el modo Chat Completions del plugin con endpoints personalizados. Las herramientas de OpenAI específicas de Responses en LiveKit no se convierten en herramientas de servidor de Phaseo.
- Esto solo enruta el LLM. Configura por separado la conversión de voz a texto y de texto a voz, salvo que la interfaz de LiveKit que uses acepte una URL personalizada compatible con OpenAI para esa modalidad.
- Prueba la gestión de interrupciones, las [llamadas a herramientas](../tool-calling.mdx) y la latencia del [streaming](../streaming.mdx) antes de enviar tráfico de voz en producción.
