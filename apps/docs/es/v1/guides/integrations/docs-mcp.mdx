Añade `https://phaseo.app/docs/mcp` a tu agente de programación como servidor MCP para que responda a las preguntas sobre Phaseo con la documentación actual en lugar de con sus datos de entrenamiento. El servidor es de solo lectura: los agentes pueden buscar en la documentación, leer páginas completas y leer el resumen de capacidades alojado en [skill.md](https://phaseo.app/docs/skill.md).

## Codex

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
codex mcp list
```

## Claude Code

Añade el servidor al proyecto actual, o añade `--scope user` para que esté disponible en todos los proyectos:

```bash
claude mcp add --transport http phaseo-docs https://phaseo.app/docs/mcp
claude mcp add --transport http --scope user phaseo-docs https://phaseo.app/docs/mcp
claude mcp list
```

## Cursor

Instálalo desde el menú contextual de cualquier página de la documentación, o añádelo a la configuración MCP de Cursor:

```json
{
  "mcpServers": {
    "phaseoDocs": {
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## VS Code

Instálalo desde el menú contextual de cualquier página de la documentación, o añádelo a la configuración MCP de VS Code:

```json
{
  "servers": {
    "phaseoDocs": {
      "type": "http",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## OpenCode

Añádelo a `opencode.json`:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "phaseoDocs": {
      "type": "remote",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## Comprueba que funciona

Pregunta al agente algo que solo pueda responder la documentación y comprueba que llama al servidor de documentación de Phaseo:

- `Look up the Responses request format in the Phaseo docs and give me a minimal example.`
- `Use the Phaseo docs MCP server to check how provider.sort works before you change this request.`
- `Find the guardrails docs in Phaseo and summarize the parts that affect provider routing.`

Los agentes lo usan para comprobar la forma de las solicitudes, qué endpoints admite un modelo o un proveedor y cómo se comportan el enrutamiento, los preajustes, los guardrails y los trabajos asíncronos. El servidor de documentación no convierte a Phaseo en tu gateway de modelos; para eso, consulta [Agentes de programación](./coding-assistants.mdx).
