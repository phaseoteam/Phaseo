Ejecuta `phaseo claude-code` para enviar las solicitudes de Claude Code a través de Phaseo, o define tú mismo tres variables de entorno. Claude Code llama a `/v1/messages` al estilo de Anthropic, que Phaseo atiende como [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx), así que tus prompts no cambian.

## Configurar con Phaseo CLI

```bash
phaseo login
phaseo claude-code
claude
```

Si falta Claude Code, la CLI muestra el comando de instalación oficial y pregunta antes de ejecutarlo. Después, la configuración:

- crea una `Phaseo CLI: Claude Code API Key` que caduca a los 90 días y tiene un límite de gasto mensual de $100, y la guarda en el almacén de credenciales del sistema operativo;
- define `ANTHROPIC_BASE_URL` y un `apiKeyHelper` en `~/.claude/settings.json`. El asistente obtiene la clave de la CLI y crea una nueva cuando la anterior caduca, así que no se escribe ninguna clave en texto plano en los ajustes de Claude Code.

La configuración se detiene sin hacer cambios si `settings.json` ya tiene otro `ANTHROPIC_BASE_URL`, otro `apiKeyHelper`, o un `ANTHROPIC_API_KEY` o `ANTHROPIC_AUTH_TOKEN` no vacío. `--model` no es compatible con Claude Code; define `ANTHROPIC_MODEL` en su lugar (ver abajo).

## Configurar Claude Code manualmente

Define estas variables en la shell desde la que inicias Claude Code:

<CodeGroup>

```bash bash
export ANTHROPIC_BASE_URL="https://api.phaseo.app"
export ANTHROPIC_AUTH_TOKEN="your_phaseo_api_key"
export ANTHROPIC_API_KEY=""
```

```powershell PowerShell
$env:ANTHROPIC_BASE_URL = "https://api.phaseo.app"
$env:ANTHROPIC_AUTH_TOKEN = "your_phaseo_api_key"
$env:ANTHROPIC_API_KEY = ""
```

</CodeGroup>

Claude Code envía `ANTHROPIC_AUTH_TOKEN` como encabezado `Authorization`, que Phaseo acepta. Para fijar un modelo predeterminado, define `ANTHROPIC_MODEL` con un ID de modelo de Phaseo de [Models](../../api-reference/endpoint/models.mdx).

## Comprobar que funciona

Ejecuta `claude`, envía un prompt corto y confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Quitar Phaseo

```bash
phaseo integrations remove claude-code
```

Esto quita la URL base, el asistente de claves y las variables de credenciales vacías que Phaseo añadió a `settings.json`, y después revoca la clave. En una configuración manual, elimina las tres variables de entorno.
