Llama a los endpoints compatibles con OpenAI de Phaseo desde Effect con su cliente HTTP, o envuelve el [SDK de OpenAI](./openai-sdk.mdx) en una capa de Effect. Usa el paquete de proveedor OpenAI propio de Effect solo si la versión que tienes instalada acepta una URL base personalizada.

## Instala

```bash
npm install effect @effect/platform
```

## Llama a Phaseo con Effect HTTP

```ts
import { FetchHttpClient, HttpClient, HttpClientRequest } from "@effect/platform";
import { Config, Effect, Redacted } from "effect";

const generate = Effect.gen(function* () {
	const apiKey = yield* Config.redacted("PHASEO_API_KEY");
	const client = yield* HttpClient.HttpClient;

	const request = HttpClientRequest.post(
		"https://api.phaseo.app/v1/chat/completions",
	).pipe(
		HttpClientRequest.bearerToken(Redacted.value(apiKey)),
		HttpClientRequest.jsonBody({
			model: "openai/gpt-6-astra",
			messages: [{ role: "user", content: "Reply with only: ok" }],
		}),
	);

	return yield* client.execute(request).pipe(
		Effect.flatMap((response) => response.json),
	);
});

const runnable = generate.pipe(Effect.provide(FetchHttpClient.layer));
```

Al ejecutarlo, devuelve una respuesta de Chat Completions cuyo mensaje dice `ok`.

## Envuelve el SDK de OpenAI en una capa de Effect

Si ya usas el SDK de OpenAI, mantén la configuración de Phaseo en un solo lugar:

```ts
import OpenAI from "openai";
import { Config, Effect } from "effect";

const makeClient = Effect.gen(function* () {
	const apiKey = yield* Config.string("PHASEO_API_KEY");

	return new OpenAI({
		apiKey,
		baseURL: "https://api.phaseo.app/v1",
	});
});
```

Construye una capa personalizada sobre esto cuando quieras una abstracción de tipo proveedor en toda tu aplicación.

## Límites conocidos

- Mantén los IDs de modelo en formato de Phaseo, como `openai/gpt-6-astra`.
- Prueba el [streaming](../streaming.mdx) y las llamadas a herramientas con las versiones exactas de tus paquetes de Effect antes de pasar a producción.
