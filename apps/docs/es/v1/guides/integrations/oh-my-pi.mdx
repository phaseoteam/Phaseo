Ejecuta `phaseo omp` para iniciar una sesión de oh-my-pi a través de Phaseo, o añade un proveedor `phaseo` a `~/.omp/agent/models.yml` para tener Phaseo en todas las sesiones.

## Ejecuta oh-my-pi a través de la CLI de Phaseo

```bash
phaseo login
phaseo omp --model openai/gpt-5.6-terra
```

El ejecutor crea una clave propia, escribe `models.yml` en un `PI_CODING_AGENT_DIR` temporal, inicia `omp` con `--model phaseo/<model>` y borra el directorio cuando oh-my-pi se cierra. Si falta `omp`, la primera ejecución interactiva ofrece instalarlo. Pon los flags propios de oh-my-pi después de `--`.

| Flag | Efecto |
| --- | --- |
| `--model <id>` | Modelo que se usa. Por defecto, `openai/gpt-5.6-terra`. |
| `--catalog all` | Muestra todos los modelos de texto activos de Phaseo, no solo el seleccionado. |
| `--dry-run --json` | Muestra el plan de instalación e inicio sin crear una clave ni iniciar oh-my-pi. |
| `--skip-install` | Omite la comprobación de instalación. |

`phaseo run omp ...` es la forma larga del mismo comando.

## Configura oh-my-pi manualmente

Crea una clave, expórtala en la shell que inicia oh-my-pi y crea el directorio de configuración:

```bash
phaseo keys create --name "oh-my-pi Phaseo key" --json
export PHASEO_OMP_API_KEY="<your Phaseo API key>"
mkdir -p ~/.omp/agent
```

Añade el proveedor:

```yaml ~/.omp/agent/models.yml
providers:
  phaseo:
    baseUrl: https://api.phaseo.app/v1
    api: openai-completions
    apiKey: PHASEO_OMP_API_KEY
    authHeader: true
    models:
      - id: openai/gpt-5.6-terra
        name: GPT-5.6 Terra via Phaseo
        contextWindow: 32768
        maxTokens: 8192
```

`apiKey` indica el nombre de la variable de entorno, así que la clave no queda en `models.yml`. Añade más entradas en `models` según lo necesites; los límites de arriba son ejemplos. Inicia oh-my-pi con el ID de modelo cualificado con el proveedor:

```bash
omp --model phaseo/openai/gpt-5.6-terra
```

Consulta la documentación de [configuración de proveedores](https://github.com/can1357/oh-my-pi/blob/main/docs/providers.md) de oh-my-pi para el resto de campos.

## Comprueba que funciona

Envía un prompt corto y confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Soluciona problemas habituales

### oh-my-pi no está instalado

Ejecuta el comando en una terminal interactiva para aprobar la instalación, o instala tú oh-my-pi y vuelve a ejecutar con `--skip-install`.

### El modelo no aparece

Usa `--catalog all`, o pasa el ID del modelo con `--model`. Phaseo no necesita descubrir los modelos.
