Ejecuta `phaseo prime-agent` para añadir a Prime Agent un proveedor de Phaseo con todos los modelos compatibles de Phaseo. Prime Agent funciona en macOS y Linux; en Windows, instálalo y ejecuta la configuración dentro de WSL.

## Configura con la CLI de Phaseo

```bash
phaseo login
phaseo prime-agent
```

Si falta Prime Agent, la CLI muestra el comando del instalador oficial y pide confirmación antes de ejecutarlo. Después, la configuración crea una `Phaseo CLI: Prime Agent API Key` (caduca a los 90 días, límite de gasto mensual de $100) y escribe un proveedor `phaseo` en `~/.prime/agent/models.json`. El proveedor incluye todos los modelos de texto activos de Phaseo que funcionan con Chat Completions.

| Flag | Efecto |
| --- | --- |
| `--model <id>` | Establece el modelo inicial. Por defecto, `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | Añade solo el modelo seleccionado. |
| `--dry-run` | Muestra los cambios en los archivos sin hacerlos. |

El proveedor obtiene su clave en el momento de la solicitud con el formato de Prime Agent para claves obtenidas mediante un comando, así que no se escribe ninguna clave en texto plano en el archivo:

```text
!phaseo integrations credential prime-agent
```

## Comprueba que funciona

```bash
prime-agent
```

Abre `/model`, selecciona el proveedor `phaseo` y envía un prompt corto. Confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Quita Phaseo

```bash
phaseo integrations remove prime-agent
```

Esto quita solo el proveedor de Phaseo y revoca la clave.
