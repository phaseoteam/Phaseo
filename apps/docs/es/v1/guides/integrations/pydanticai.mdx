Usa PydanticAI si quieres agentes Python con salidas tipadas, validación y una configuración compacta de modelos compatible con OpenAI.

## Instalar

```bash
pip install "pydantic-ai-slim[openai]"
```

## Configurar el modelo

```python
import os
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-5-nano",
    provider=OpenAIProvider(
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)

agent = Agent(model, system_prompt="Answer concisely.")
result = agent.run_sync("Reply with only: ok")
print(result.output)
```

## Notas

- La ruta compatible con OpenAI de PydanticAI utiliza un comportamiento de chat al estilo de OpenAI.
- Usa llamadas directas de Phaseo Responses para funciones exclusivas de Responses, como `phaseo:apply_patch`.
- Mantén los esquemas de salida estructurada lo bastante pequeños para la ventana de contexto del modelo seleccionado.
