Crea un `OpenAIChatModel` con un `OpenAIProvider` que apunte a `https://api.phaseo.app/v1`, y los agentes de PydanticAI funcionarán con modelos de Phaseo.

## Instala

```bash
pip install "pydantic-ai-slim[openai]"
```

## Haz que PydanticAI use Phaseo

```python
import os
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-6-astra",
    provider=OpenAIProvider(
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)

agent = Agent(model, system_prompt="Answer concisely.")
result = agent.run_sync("Reply with only: ok")
print(result.output)
```

Si se imprime `ok`, la configuración funciona.

## Límites conocidos

- Esta vía usa Chat Completions de estilo OpenAI. Para funciones exclusivas de Responses, como `phaseo:apply_patch`, llama directamente al endpoint de Responses de Phaseo.
- Mantén los esquemas de [salida estructurada](../structured-outputs.mdx) lo bastante pequeños para la ventana de contexto del modelo. Consulta los límites en [Modelos](../../api-reference/endpoint/models.mdx).
