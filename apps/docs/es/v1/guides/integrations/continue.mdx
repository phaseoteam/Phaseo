Ejecuta `phaseo continue` para escribir una configuración de Continue que apunte a Phaseo, o añade la misma entrada de modelo y el mismo secreto a tu configuración actual. Las extensiones para IDE y la CLI `cn` comparten la configuración.

## Configura con la CLI de Phaseo

```bash
phaseo login
phaseo continue --model anthropic/claude-sonnet-5.5
```

Si `~/.continue/config.yaml` y `~/.continue/.env` no existen, la configuración crea una `Phaseo CLI: Continue API Key` (caduca a los 90 días, límite de gasto mensual de $100) y escribe los dos archivos. Sin `--model`, usa `anthropic/claude-sonnet-4.6`.

```yaml ~/.continue/config.yaml
# Managed by Phaseo CLI
name: Phaseo
version: 1.0.0
schema: v1
models:
  - name: "anthropic/claude-sonnet-5.5 via Phaseo"
    provider: openai
    model: "anthropic/claude-sonnet-5.5"
    apiBase: https://api.phaseo.app/v1
    apiKey: ${{ secrets.PHASEO_API_KEY }}
    useResponsesApi: false
    roles: [chat, edit, apply]
```

La clave va en `~/.continue/.env` como `PHASEO_API_KEY`. `useResponsesApi: false` mantiene Continue en el endpoint de Chat Completions de Phaseo.

<Warning>
El `.env` global de Continue está en texto plano. No lo subas nunca al repositorio. Las extensiones para IDE no heredan las variables de entorno de la shell; por eso la CLI usa el archivo de [secretos locales](https://docs.continue.dev/faqs#managing-local-secrets-and-environment-variables) de Continue.
</Warning>

## Configura Continue manualmente

Si alguno de los dos archivos ya tiene ajustes tuyos, la configuración se detiene sin cambiarlo. Añade la entrada de modelo anterior a tu `config.yaml` y añade `PHASEO_API_KEY=<key>` a tu `.env`, con la salida de `phaseo integrations credential continue` o cualquier clave de API de Phaseo. Consulta la documentación del [proveedor OpenAI](https://docs.continue.dev/customize/model-providers/top-level/openai) de Continue para el resto de campos.

## Comprueba que funciona

En VS Code o JetBrains, recarga la ventana, abre Continue, selecciona **Phaseo** y pídele que responda con `PHASEO_CONTINUE_OK`. En la CLI, ejecuta `cn` (usa `/config` si hay otra configuración activa) y envía el mismo prompt. Confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Quita Phaseo

```bash
phaseo integrations remove continue
```

Esto revoca la clave y borra los dos archivos solo si todavía empiezan con la marca de la CLI de Phaseo. Las entradas que combinaste tú no se tocan.

## Soluciona problemas habituales

### Phaseo no aparece

Recarga el IDE y comprueba que `config.yaml` tiene los campos de nivel superior `name`, `version` y `schema`.

### Continue indica que falta un secreto

Comprueba que `~/.continue/.env` tiene la clave de `phaseo integrations credential continue` y reinicia el IDE.

### Continue llama a la API de Responses

Mantén `useResponsesApi: false` en la entrada del modelo de Phaseo.
