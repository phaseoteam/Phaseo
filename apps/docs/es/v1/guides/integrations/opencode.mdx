Ejecuta `phaseo opencode` para añadir a OpenCode un proveedor de Phaseo con todos los modelos compatibles de Phaseo, o añade tú un proveedor `phaseo` a `opencode.json`.

## Configura con la CLI de Phaseo

```bash
phaseo login
phaseo opencode --model openai/gpt-5.6-terra
```

Si falta OpenCode, la CLI muestra el comando de instalación oficial y pide confirmación antes de ejecutarlo. Después, la configuración:

- añade un proveedor global `phaseo` con todos los modelos de texto activos de Phaseo que funcionan con Chat Completions. Actualiza tu `opencode.jsonc` global si existe o, si no, `~/.config/opencode/opencode.json`, y no toca el resto de tus ajustes;
- crea una `Phaseo CLI: OpenCode API Key` que caduca a los 90 días y tiene un límite de gasto mensual de $100, y la guarda en el almacén de credenciales de OpenCode. La CLI guarda su propia copia en el almacén de credenciales del sistema operativo. Vuelve a ejecutar `phaseo opencode` para sustituir una clave caducada.

Usa `--catalog default` para añadir solo el modelo seleccionado, o `--dry-run` para previsualizar los cambios.

## Configura OpenCode manualmente

Añade el proveedor a `opencode.json` en tu proyecto, o a tu configuración global de OpenCode:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-6-astra",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-6-astra": { "name": "GPT-6 Astra" },
        "openai/gpt-5.4-mini": { "name": "GPT-5.4 Mini" },
        "anthropic/claude-sonnet-5.5": { "name": "Claude Sonnet 5.5" }
      }
    }
  }
}
```

Exporta `PHASEO_API_KEY`, y añade o quita entradas en `models` para elegir qué modelos de Phaseo muestra OpenCode.

## Comprueba que funciona

Reinicia OpenCode, elige un modelo de Phaseo en `/models` y envía un prompt corto antes de empezar a editar archivos. Confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Quita Phaseo

```bash
phaseo integrations remove opencode
```

Esto quita solo el proveedor de Phaseo y su credencial guardada, y después revoca la clave.

## Soluciona problemas habituales

| Problema | Solución |
| --- | --- |
| Se rechaza un modelo | Comprueba el ID exacto con el [endpoint de modelos](../../api-reference/endpoint/models.mdx). |
| La autenticación falla | Vuelve a ejecutar `phaseo opencode` y comprueba `opencode auth list`. |

Para que OpenCode lea la documentación de Phaseo durante una sesión, añade el servidor [Docs MCP](./docs-mcp.mdx).
