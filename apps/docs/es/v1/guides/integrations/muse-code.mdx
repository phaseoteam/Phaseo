Ejecuta `phaseo muse` para iniciar una sesión de Muse Code a través de Phaseo. Este ejecutor es la única forma compatible de usar Phaseo con Muse Code.

## Ejecuta Muse Code a través de la CLI de Phaseo

```bash
phaseo login
phaseo muse --model meta/muse-spark-1.3
```

El ejecutor crea una clave propia, escribe los ajustes de Muse en un `XDG_CONFIG_HOME` temporal, inicia `muse` y borra los ajustes cuando Muse Code se cierra. Pon los flags propios de Muse Code después de `--`.

| Flag | Efecto |
| --- | --- |
| `--model <id>` | Modelo que se usa. Por defecto, `openai/gpt-5.6-terra`. |
| `--catalog all` | Muestra todos los modelos de texto activos de Phaseo, no solo el seleccionado. |
| `--dry-run --json` | Muestra el plan de inicio sin crear una clave ni iniciar Muse Code. |
| `--skip-install` | Omite la comprobación de instalación. |

`phaseo run muse ...` es la forma larga del mismo comando.

En macOS y Linux, la primera ejecución interactiva ofrece instalar Muse Code con el instalador de Meta. En Windows, instala tú Muse Code, comprueba `muse --version` y usa `--skip-install`.

## Por qué no hay configuración manual

Muse Code está diseñado en torno a la [Model API](https://ai.meta.com/llama) y el inicio de sesión propios de Meta. Meta no documenta un ajuste estable para apuntarlo a otro endpoint compatible con OpenAI, así que usa el ejecutor. No copies los ajustes temporales del ejecutor en tu perfil habitual de Muse; son un detalle interno y se borran cuando el ejecutor termina.

Para llamar a un modelo de Phaseo desde tu propio código, usa el [SDK de OpenAI](./openai-sdk.mdx) con `https://api.phaseo.app/v1` y una clave de API de Phaseo.

## Comprueba que funciona

Envía un prompt corto y confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Soluciona problemas habituales

### Muse Code no está instalado

Instala tú Muse Code, comprueba `muse --version` y vuelve a ejecutar con `--skip-install`.

### El modelo no aparece

Usa `--catalog all`, o pasa el ID del modelo con `--model`. Phaseo no necesita descubrir los modelos.
