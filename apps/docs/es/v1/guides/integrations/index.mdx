Apunta un cliente compatible con OpenAI o con Anthropic a la URL base de Phaseo, dale una clave de API de Phaseo y usa los IDs de modelo de Phaseo, como `openai/gpt-6-astra`, sin cambios. Cada guía configura primero la herramienta y después muestra cómo comprobar que funciona y qué no funciona.

| Tipo de cliente | URL base | Dónde va la clave |
| --- | --- | --- |
| Compatible con OpenAI | `https://api.phaseo.app/v1` | El campo de clave de API, enviada como `Authorization: Bearer` |
| Compatible con Anthropic (añade `/v1/messages` por su cuenta) | `https://api.phaseo.app` | El campo de token de autenticación, enviado como `Authorization: Bearer` |

Obtén los IDs de modelo del [endpoint de modelos](../../api-reference/endpoint/models.mdx). Para aplicaciones nuevas de estilo OpenAI, usa [Responses](../../api-reference/endpoint/responses.mdx); con las bibliotecas más antiguas, lo más seguro es [Chat Completions](../../api-reference/endpoint/chat-completions.mdx). Establece `PHASEO_API_KEY` una vez y asígnala a la variable que espere cada herramienta, y prueba el streaming y las llamadas a herramientas antes de mover el tráfico de agentes.
