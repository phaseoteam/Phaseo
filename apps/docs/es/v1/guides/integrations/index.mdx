La mayoría de las integraciones funcionan al configurar un cliente compatible con OpenAI o Anthropic para que use Phaseo y una clave de API de Phaseo. Empieza con la guía de la herramienta que ya utilizas.

## URL base

| Estilo de cliente | URL base |
| --- | --- |
| Clientes compatibles con OpenAI | `https://api.phaseo.app/v1` |
| Clientes compatibles con Anthropic | `https://api.phaseo.app` |

Usa los IDs de modelo del [endpoint Models](../../api-reference/endpoint/models.mdx). Para aplicaciones nuevas que usan el estilo de OpenAI, es preferible [Responses](../../api-reference/endpoint/responses.mdx). Para bibliotecas antiguas, [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) suele ser la opción más segura.

## Ajustes recomendados

- Configura `PHASEO_API_KEY` una vez y asígnala a la variable de entorno que espera el cliente.
- Mantén sin cambios el ID del modelo, por ejemplo `openai/gpt-5-nano`.
- Usa `https://api.phaseo.app/v1` para bibliotecas compatibles con OpenAI, salvo que la herramienta solicite explícitamente el host raíz.
- Usa `https://api.phaseo.app` para los SDK y herramientas compatibles con Anthropic que añaden `/v1/messages`.
- Prueba el streaming y las llamadas a herramientas en staging antes de migrar el tráfico de agentes.
