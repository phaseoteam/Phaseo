Ejecuta `phaseo minimax` para iniciar una sesión de MiniMax Code (`mcode`) a través de Phaseo, o añade Phaseo con `mcode provider add` para tenerlo en todas las sesiones.

## Ejecuta MiniMax Code a través de la CLI de Phaseo

```bash
phaseo login
phaseo minimax --model openai/gpt-5.6-terra
```

El ejecutor crea una clave propia, establece `MINIMAX_DATA_DIR` en un directorio temporal, añade allí un proveedor de Phaseo con `mcode provider add`, inicia `mcode` y borra el directorio cuando `mcode` se cierra. Tu configuración habitual de `~/.minimax` no cambia, y la clave solo se pasa al proceso de configuración del proveedor. Pon los flags propios de MiniMax Code después de `--`.

| Flag | Efecto |
| --- | --- |
| `--model <id>` | Modelo que se usa. Por defecto, `openai/gpt-5.6-terra`. |
| `--catalog all` | Registra todos los modelos de texto activos de Phaseo que funcionan con Chat Completions. |
| `--dry-run --json` | Muestra el plan de instalación e inicio sin crear una clave. |
| `--skip-install` | Omite la comprobación de instalación. |

`phaseo run minimax ...` es la forma larga del mismo comando.

Si falta `mcode`, la primera ejecución interactiva ofrece instalarlo con el instalador oficial de MiniMax (el instalador de PowerShell en Windows). Si gestionas tú MiniMax Code, instálalo, comprueba `mcode --version` y vuelve a ejecutar con `--skip-install`.

## Configura MiniMax Code manualmente

Para conservar un proveedor de Phaseo, añádelo con el propio comando de MiniMax Code:

```bash
export MCODE_PROVIDER_API_KEY="your_phaseo_api_key"
mcode provider add \
  --name "Phaseo" \
  --base-url "https://api.phaseo.app/v1" \
  --api-format openai-completions \
  --model "openai/gpt-5.6-terra" \
  --use
```

MiniMax Code guarda el proveedor en su directorio de datos.

## Comprueba que funciona

Envía un prompt corto y confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

## Soluciona problemas habituales

### MiniMax Code no está instalado

Ejecuta el comando en una terminal interactiva para aprobar el instalador oficial, o instala tú MiniMax Code y vuelve a ejecutar con `--skip-install`.

### El proveedor o el modelo no aparece

Usa `phaseo minimax --catalog all`, o pasa el ID del modelo con `--model`.

### Necesitas ACP en lugar de la CLI interactiva

`phaseo minimax` ejecuta la CLI interactiva. MiniMax Code también funciona como proceso ACP con `mcode acp`; usa la configuración ACP de MiniMax Code cuando tu editor o host hable ACP directamente.
