Ejecuta `phaseo aider` para escribir una configuración de Aider que apunte a Phaseo, o añade tres líneas a tu `.aider.conf.yml` existente.

## Configurar con Phaseo CLI

```bash
phaseo login
phaseo aider --model anthropic/claude-sonnet-5.5
```

Si `~/.aider.conf.yml` no existe, la configuración crea una `Phaseo CLI: Aider API Key` (caduca en 90 días, límite de gasto mensual de $100) y escribe este archivo. Sin `--model`, usa `anthropic/claude-sonnet-4.6`.

```yaml ~/.aider.conf.yml
# Managed by Phaseo CLI
model: openai/anthropic/claude-sonnet-5.5
openai-api-base: https://api.phaseo.app/v1
openai-api-key: "<dedicated Phaseo key>"
```

Aider necesita el prefijo `openai/` para enviar un modelo personalizado a través de su adaptador compatible con OpenAI. El modelo que se envía a Phaseo sigue siendo `anthropic/claude-sonnet-5.5`.

<Warning>
La clave se guarda en texto plano, porque `.aider.conf.yml` es una de las ubicaciones de claves documentadas de Aider. Haz que solo tu cuenta de usuario pueda leer el archivo y no lo confirmes nunca en el repositorio.
</Warning>

## Configurar Aider manualmente

Si ya tienes una configuración de Aider, la CLI se detiene sin cambiarla. Copia los tres ajustes anteriores en la configuración que quieres que cargue Aider, usando `phaseo integrations credential aider` o cualquier clave de API de Phaseo para `openai-api-key`. Aider lee `.aider.conf.yml` de tu directorio personal, de la raíz del repositorio y del directorio actual, y los archivos posteriores prevalecen. Consulta la documentación de Aider sobre la [configuración YAML](https://aider.chat/docs/config/aider_conf.html) y la [API compatible con OpenAI](https://aider.chat/docs/llms/openai-compat.html).

## Comprobar que funciona

Abre un repositorio e inicia Aider:

```bash
aider
```

Comprueba que la salida de inicio nombra `openai/anthropic/claude-sonnet-5.5`, pídele que responda con `PHASEO_AIDER_OK` y confirma que la solicitud aparece en **Ajustes → Uso → Registros**.

Una advertencia de modelo desconocido no detiene las solicitudes. Añade metadatos de modelo de Aider solo si necesitas estimaciones precisas del límite de tokens o del coste.

## Quitar Phaseo

```bash
phaseo integrations remove aider
```

Esto revoca la clave y elimina `~/.aider.conf.yml` solo si el archivo sigue empezando con el marcador de Phaseo CLI. Si combinaste los ajustes en tu propio archivo, quita tú mismo las tres líneas.

## Resolver problemas comunes

### Aider usa otro endpoint u otro modelo

Un `.aider.conf.yml` en la raíz del repositorio o en el directorio actual sustituye al de tu directorio personal. Las variables de entorno y las opciones de la línea de comandos sustituyen a todos ellos.

### La autenticación falla

Compara `openai-api-key` con la salida de `phaseo integrations credential aider` y mantén `openai-api-base` exactamente como `https://api.phaseo.app/v1`.

### No se puede resolver el modelo

Mantén el prefijo `openai/` de Aider. El modelo de Phaseo `openai/gpt-6-astra` se convierte en `openai/openai/gpt-6-astra` en Aider.
