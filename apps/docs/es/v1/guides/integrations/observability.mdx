La mayoría de las herramientas de observabilidad se sitúan por encima del cliente del modelo. Conserva la misma configuración de trazas y apunta a Phaseo el cliente compatible con OpenAI o Anthropic que hay debajo.

## Langfuse con el SDK de OpenAI

```bash
pip install langfuse openai
```

```python
import os
from langfuse.openai import openai

client = openai.OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-5-nano",
    input="Reply with only: ok",
)
```

## LangSmith con LangChain

Usa la configuración de [LangChain](./langchain.mdx) y activa LangSmith con las variables de entorno habituales de LangChain:

```bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your_langsmith_key"
export PHASEO_API_KEY="your_phaseo_key"
```

## OpenTelemetry

Si tu framework genera spans de OpenTelemetry, Phaseo no requiere un exportador especial. Añade tú mismo el contexto útil de la solicitud:

- ID del modelo
- Endpoint, como `responses` o `chat.completions`
- ID de solicitud de Phaseo, obtenido de los metadatos de respuesta o los registros
- Proveedor seleccionado, si están habilitados los metadatos de respuesta

## Notas

- No envíes claves de API de Phaseo a las herramientas de observabilidad como atributos.
- Si la biblioteca de observabilidad envuelve el SDK de OpenAI, configura el cliente envuelto con `base_url: "https://api.phaseo.app/v1"`.
- Para las trazas de LangChain, combina el callback de trazas con la configuración de Phaseo `ChatOpenAI`.
