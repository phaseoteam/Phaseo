Crea un modelo `ChatOpenAI` con tu clave de Phaseo y `base_url="https://api.phaseo.app/v1"`, y las cadenas, los agentes y los flujos de LangGraph de LangChain llamarán a los modelos a través de Phaseo.

## Instala

```bash
pip install -U langchain langchain-openai
```

## Haz que ChatOpenAI use Phaseo

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

Si se imprime una frase, la configuración funciona.

## Úsalo en LangGraph

Pasa el mismo `llm` a los nodos de tu grafo o a tu constructor de agentes:

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## Límites conocidos

- Esta vía usa [Chat Completions](../../api-reference/endpoint/chat-completions.mdx), así que solo funcionan las funciones de Phaseo disponibles en `/v1/chat/completions`, incluidas las [llamadas a herramientas](../tool-calling.mdx) y el [enrutamiento y las alternativas](../routing-and-fallbacks.mdx).
- Para herramientas de servidor exclusivas de Responses, como `phaseo:apply_patch`, llama a Phaseo directamente o usa el [SDK de OpenAI](./openai-sdk.mdx).
- Para trazar con LangSmith, consulta [Observabilidad](./observability.mdx).
