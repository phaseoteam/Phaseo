Elige la guía para el trabajo que tienes delante. Para una primera integración con Phaseo, sigue este orden:

1. [Inicio rápido](../quickstart): haz una solicitud correcta.
2. [Autenticación](../developers/authentication): guarda y envía las claves de forma segura.
3. [Ejemplos](./examples): copia patrones de solicitud en tu aplicación.

<Note>
Puedes llamar a los modelos `:free` sin depositar créditos. Los modelos de pago siguen requiriendo saldo disponible en el monedero.
</Note>
