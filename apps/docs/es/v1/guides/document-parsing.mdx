Envía la imagen de un documento a `POST /v1/parse` para recibir su texto en orden de lectura, como Markdown o como bloques estructurados de texto, imagen y tabla. Usa [OCR](../api-reference/endpoint/ocr.mdx) cuando solo necesites el texto sin formato.

<Warning>
  Parse acepta una imagen por solicitud, como URL `http(s)` o como URI `data:image/...` en base64. No acepta PDF: convierte antes cada página en una imagen. Cohere limita cada imagen a 20 MB, 50 megapíxeles y 200 MB descodificada.
</Warning>

## Convierte a Markdown

Markdown es el `output_format` predeterminado. Conserva el orden de lectura, inserta las tablas como HTML y enlaza las imágenes detectadas con los metadatos de la página.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/parse \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cohere/parse-v5.0",
    "document": {
      "type": "image_url",
      "image_url": "https://example.com/invoice.png"
    },
    "output_format": "markdown"
  }'
```

```ts TypeScript
const response = await fetch("https://api.phaseo.app/v1/parse", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "cohere/parse-v5.0",
    document: {
      type: "image_url",
      image_url: "https://example.com/invoice.png",
    },
    output_format: "markdown",
  }),
});

const parsed = await response.json();
console.log(parsed.pages[0].markdown.content);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/parse",
    headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
    json={
        "model": "cohere/parse-v5.0",
        "document": {
            "type": "image_url",
            "image_url": "https://example.com/invoice.png",
        },
        "output_format": "markdown",
    },
)
response.raise_for_status()
print(response.json()["pages"][0]["markdown"]["content"])
```
</CodeGroup>

## Devuelve bloques estructurados

Define `output_format` como `blocks` para recibir regiones ordenadas de texto, imagen y tabla. Los bloques de imagen y de tabla incluyen cuadros delimitadores en píxeles y normalizados cuando están disponibles.

## Cómo se factura Parse

El uso de Parse se mide por página. La respuesta incluye los metadatos de Cohere y un valor normalizado `usage.input_pages` cuando el proveedor informa de las páginas facturadas. Actualmente, Cohere ofrece acceso gratuito a la API de evaluación con límites de frecuencia y no ha publicado una tarifa de producción para la API de Parse.
