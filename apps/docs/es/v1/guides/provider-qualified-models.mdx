title: "ID de modelo calificados por proveedor"
description: "Enruta una solicitud a un proveedor y un modelo exactos con un solo identificador de modelo."
icon: "route"
---

Pon un ID de proveedor y dos puntos delante del ID del modelo, como `baseten:thinking-machines/inkling-small`, para ejecutar la solicitud solo en ese proveedor, sin alternativa a otro proveedor.

| Lo que quieres | Envía como `model` |
| --- | --- |
| Que Phaseo elija un proveedor y recurra a otros proveedores si falla | `thinking-machines/inkling-small` |
| Solo Baseten, sin alternativa entre proveedores | `baseten:thinking-machines/inkling-small` |
| Una ruta gratuita verificada en un proveedor | `google-ai-studio:google/gemma-4-26b-a4b:free` |

El formato es `<provider-id>:<canonical-model-id>`. Los primeros dos puntos separan el proveedor; los dos puntos que aparecen después del espacio de nombres del modelo siguen formando parte del ID del modelo. En `google-ai-studio:google/gemma-4-26b-a4b:free`, el proveedor es `google-ai-studio` y el modelo es `google/gemma-4-26b-a4b:free`.

Si solo prefieres un proveedor y quieres una alternativa cuando falle, usa el ID de modelo simple con los [controles de enrutamiento y alternativas](./routing-and-fallbacks.mdx).

## Envía una solicitud

Usa el ID calificado en cualquier lugar donde el endpoint acepte un ID de modelo.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "baseten:thinking-machines/inkling-small",
    "input": "Explain mixture-of-experts routing in two sentences."
  }'
```

```javascript JavaScript
const response = await fetch("https://api.phaseo.app/v1/responses", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "baseten:thinking-machines/inkling-small",
    input: "Explain mixture-of-experts routing in two sentences.",
  }),
});

const result = await response.json();
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/responses",
    headers={
        "Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "model": "baseten:thinking-machines/inkling-small",
        "input": "Explain mixture-of-experts routing in two sentences.",
    },
)

result = response.json()
```
</CodeGroup>

## Qué debe seguir cumpliendo el proveedor

El calificador limita el enrutamiento a un proveedor; no omite ninguna otra comprobación. El proveedor debe seguir:

- sirviendo el modelo canónico en el endpoint solicitado, con esa capacidad habilitada
- cumpliendo las restricciones del espacio de trabajo, la clave de API, el preajuste y la privacidad
- admitiendo el nivel de servicio y los parámetros solicitados
- teniendo precios configurados

Si falla alguna comprobación, la solicitud se rechaza. Phaseo nunca elige otro proveedor sin avisar.

## Combínalo con los campos `provider` o `routing`

El calificador y los campos de enrutamiento explícitos deben coincidir. Se acepta un `provider.only` o `routing.only` que coincida:

```json
{
  "model": "baseten:thinking-machines/inkling-small",
  "provider": { "only": ["baseten"] }
}
```

Una lista de permitidos que nombra otros proveedores, o una lista de ignorados que contiene el proveedor calificado, se rechaza con `provider_qualified_model_conflict`:

```json
{
  "model": "baseten:thinking-machines/inkling-small",
  "provider": { "only": ["deepinfra"] }
}
```

## Solicita una ruta gratuita en un proveedor

Un modelo `:free` calificado solo se acepta cuando ese proveedor tiene una ruta gratuita apta para el modelo y el endpoint. Un modelo canónico `:free` no significa que todos los proveedores del modelo subyacente lo ofrezcan gratis.

```json
{
  "model": "google-ai-studio:google/gemma-4-26b-a4b:free",
  "input": "Hello"
}
```

La tarjeta de precios de la ruta no puede estar vacía, y cada regla de precio vigente que contenga debe estar etiquetada como `free` y tener un precio exactamente cero. Los precios ausentes, de pago, mixtos o negativos, o una regla con precio cero no etiquetada como `free`, rechazan la solicitud antes de que llegue al proveedor.

## ID y alias de proveedores

Usa un ID de proveedor del catálogo de proveedores de Phaseo (consulta [Proveedores de API](../exploring/api-providers)). Los ID se convierten a minúsculas, y los alias heredados o de marca conocidos se asignan al ID canónico: `NovitaAI` y `novita-ai` se convierten en `novita`. Los ID mal formados y desconocidos se rechazan antes de seleccionar el proveedor; nunca se envían upstream como parte del nombre del modelo.

## Errores de validación

Un ID calificado incorrecto devuelve HTTP `400` con el código de error `validation_error`. `reason` y `details[].keyword` indican la causa:

| Motivo | Significado |
| --- | --- |
| `invalid_provider_slug` | La parte del proveedor está vacía o contiene caracteres no admitidos. |
| `unknown_provider_slug` | El ID del proveedor tiene un formato correcto, pero no es un proveedor de Phaseo. |
| `invalid_provider_qualified_model` | El ID no coincide con `<provider>:<publisher>/<model>`. |
| `provider_qualified_model_conflict` | `provider.only`, `provider.ignore`, `routing.only` o `routing.ignore` contradice el calificador. |
| `qualified_provider_unavailable` | El proveedor existe, pero no sirve ese modelo en el endpoint solicitado. |
| `qualified_free_provider_unavailable` | La ruta del proveedor no está verificada como gratuita con todos los precios a cero. |

```json
{
  "error": "validation_error",
  "status_code": 400,
  "reason": "unknown_provider_slug",
  "description": "Unknown provider slug \"not-a-provider\" in provider-qualified model \"not-a-provider:publisher/model\". Use a provider slug returned by Phaseo's provider catalogue.",
  "provider": "not-a-provider",
  "model": "publisher/model",
  "details": [
    {
      "path": ["model"],
      "keyword": "unknown_provider_slug"
    }
  ]
}
```

Para otros formatos de error, consulta [Errores y depuración](../api-reference/errors.mdx).
