Al pasar del prototipo a producción, aplica estas prácticas.

## Lista de comprobación de fiabilidad

- Configura controles de tiempo de espera y cancelación en el cliente.
- Gestiona los estados `429` y `5xx` con retroceso exponencial.
- Considera que los flujos desconectados se pueden reintentar.
- Si la corrección es importante, guarda el texto parcial solo cuando se haya completado la respuesta.

## Ejemplo de cancelación en navegador o Node

```typescript
const controller = new AbortController();
const timeout = setTimeout(() => controller.abort(), 30_000);

try {
  const response = await fetch("https://api.phaseo.app/v1/chat/completions", {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "openai/gpt-5-nano",
      messages: [{ role: "user", content: "Stream a short summary." }],
      stream: true,
    }),
    signal: controller.signal,
  });
  // Parse SSE frames from response.body here.
} finally {
  clearTimeout(timeout);
}
```

## Recomendaciones para la interfaz

- Muestra progresivamente los fragmentos de tokens.
- Muestra claramente el estado «generación finalizada» cuando llegue `[DONE]`.
- Conserva el ID de solicitud y el ID del modelo en los registros para poder reproducir y depurar la solicitud.

## Cuándo no usar streaming

- Flujos de llamadas a herramientas con la validación actual de solicitudes (se rechaza `stream + tools`).
- Flujos de trabajo que requieren validarlo todo antes de mostrar contenido al usuario.
