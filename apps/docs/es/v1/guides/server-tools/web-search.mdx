Añade `phaseo:web_search` para que el modelo pueda buscar en la web cuando necesite información actual o respaldada por fuentes. El modelo redacta la consulta y puede buscar varias veces en una misma solicitud; Phaseo devuelve URL, títulos, fragmentos, destacados y, opcionalmente, el texto de las páginas, y el modelo redacta una respuesta fundamentada.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What were the major AI announcements this week?" }
    ],
    "tools": [
      { "type": "phaseo:web_search" }
    ]
  }'
```

La misma entrada de herramienta funciona en `tools` en `/v1/responses` y `/v1/messages`.

<span id="parameters"></span>
## Parámetros

```json
{
  "type": "phaseo:web_search",
  "parameters": {
    "engine": "exa",
    "max_results": 5,
    "max_total_results": 15,
    "search_context_size": "medium",
    "max_characters": 2048,
    "allowed_domains": ["arxiv.org", "nature.com"],
    "include_highlights": true,
    "include_text": false
  }
}
```

| Parámetro | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `engine` | string | `exa` | `auto`, `native`, `exa`, `parallel`, `firecrawl`, `perplexity` o `tinyfish`. Consulta [Elegir un motor](#choose-an-engine). |
| `max_results` | integer | `5` | Resultados por llamada de búsqueda, hasta `25`. |
| `max_total_results` | integer | `25` | Resultados de todas las búsquedas de la solicitud, hasta `100`. Nunca es inferior a `max_results`. |
| `max_uses` | integer | `10` | Llamadas de búsqueda por solicitud, hasta `100`. |
| `search_context_size` | string | `medium` | `low`, `medium` o `high`, para los motores que ajustan el tamaño de los destacados. |
| `max_characters` | integer | El del motor | Caracteres de texto por resultado cuando se incluye el texto. |
| `allowed_domains` | string[] | Ninguno | Busca solo en estos dominios. Alias: `include_domains`. |
| `excluded_domains` | string[] | Ninguno | Excluye estos dominios. Alias: `exclude_domains`. |
| `include_highlights` | boolean | `true` | Incluye los destacados o fragmentos del motor. |
| `include_text` | boolean | `false` | Incluye más texto de la página cuando el motor lo admite. |
| `user_location` | object | Ninguno | Indicación de ubicación que se pasa a la búsqueda propia del proveedor cuando `engine` es `native`. |

## Qué envía el modelo

Cada llamada incluye una `query`. El modelo también puede enviar `max_results`, `engine`, `search_context_size`, las listas de dominios, `include_text`, `include_highlights`, `max_characters` y estas indicaciones de localización:

| Argumento | Descripción |
| --- | --- |
| `user_location` | Ubicación aproximada. Perplexity usa `user_location.country` para la búsqueda regional; TinyFish usa el país y el idioma. |
| `language` | Código de idioma de los resultados, como `en`, para los motores que localizan. |
| `page` | Página de resultados de `0` a `10`, para TinyFish. |

Los valores que envía el modelo sustituyen los predeterminados de la herramienta en esa llamada. `max_results` sigue limitado por lo que quede de `max_total_results`; cuando se agota, las llamadas siguientes devuelven `max_total_results_reached`.

<span id="choose-an-engine"></span>
## Elegir un motor

| Motor | Qué se ejecuta |
| --- | --- |
| `exa` | Búsqueda gestionada de Exa. Es el predeterminado. |
| `auto` | El motor gestionado predeterminado, actualmente Exa. |
| `parallel` | Búsqueda gestionada de Parallel. |
| `firecrawl` | Búsqueda gestionada de Firecrawl. |
| `perplexity` | La Perplexity Search API: resultados ordenados, `search_context_size` y búsqueda regional a partir de `user_location.country`. |
| `tinyfish` | TinyFish Search: resultados ordenados, localizados y paginados. Devuelve fragmentos, no el texto completo de la página; usa [`phaseo:web_fetch`](./web-fetch) cuando el modelo necesite más. |
| `native` | La herramienta de búsqueda web propia del proveedor, como `web_search_preview` de OpenAI o `web_search_20250305` de Anthropic. |

Si un motor gestionado no está habilitado, la llamada devuelve `search_not_configured` al modelo.

Con `engine: "native"` en `/v1/chat/completions` o `/v1/responses`, la solicitud solo va a proveedores que ejecutan la búsqueda web por sí mismos. Si ninguno ofrece el modelo, Phaseo ejecuta en su lugar su motor predeterminado y lo factura como búsqueda gestionada. Define `native` solo en la definición de la herramienta: si el modelo pide `native` en una llamada, la llamada devuelve `unsupported_search_engine`, porque la herramienta del proveedor debe elegirse antes de enviar la solicitud.

## Filtrar por dominio

Usa `allowed_domains` cuando la respuesta deba proceder de un conjunto fijo de fuentes, y `excluded_domains` para quitar sitios concretos de una búsqueda por lo demás abierta.

```json
{
  "type": "phaseo:web_search",
  "parameters": { "allowed_domains": ["phaseo.app", "github.com"] }
}
```

Cada motor trata las listas de forma distinta:

- **Perplexity** acepta una de las dos listas, no ambas, con hasta 20 dominios. Los dominios excluidos se envían en su formato de lista de bloqueo.
- **Firecrawl** acepta una de las dos listas, no ambas.
- **TinyFish** acepta ambas y las convierte en operadores `site:` y `-site:` en la consulta.

## Qué devuelve la herramienta

Un resultado JSON con el motor, la consulta y una matriz `results`. Cada resultado tiene `title`, `url`, `snippet` o `highlights`, y `text` cuando se pidió el texto de la página y el motor lo proporciona.

## Uso y precios

Cada búsqueda suma a `usage.server_tool_use`:

```json
{
  "usage": {
    "server_tool_use": {
      "web_search_requests": 1,
      "web_search_results": 5,
      "web_search_extra_results": 0
    }
  }
}
```

La búsqueda gestionada se factura con `server_tool_web_search_requests` y `server_tool_web_search_extra_results`. La búsqueda nativa se factura con `native_web_search_requests` cuando la tarjeta de precios del modelo lo define. TinyFish Search es gratuito en sus planes publicados, por lo que Phaseo no añade ningún cargo de búsqueda con `engine: "tinyfish"`; se sigue aplicando el precio normal por tokens de la solicitud.
