title: "Herramienta de servidor Web Search"
description: "Permite que los modelos busquen en la web durante una solicitud."
---

Añade `phaseo:web_search` para que el modelo pueda buscar en la web cuando necesite información actual o respaldada por fuentes. El modelo redacta la consulta y puede buscar varias veces en una misma solicitud; Phaseo devuelve URL, títulos, fragmentos, destacados y, opcionalmente, el texto de las páginas, y el modelo redacta una respuesta fundamentada.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What were the major AI announcements this week?" }
    ],
    "tools": [
      { "type": "phaseo:web_search" }
    ]
  }'
```

La misma entrada de herramienta funciona en `tools` en `/v1/responses` y `/v1/messages`.

<span id="parameters"></span>
## Parámetros

```json
{
  "type": "phaseo:web_search",
  "parameters": {
    "engine": "exa",
    "max_results": 5,
    "max_total_results": 15,
    "search_context_size": "medium",
    "max_characters": 2048,
    "allowed_domains": ["arxiv.org", "nature.com"],
    "include_highlights": true,
    "include_text": false
  }
}
```

| Parámetro | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `engine` | string | `exa` | `auto`, `native`, `exa`, `parallel`, `firecrawl`, `perplexity`, `tinyfish` o `deepseek`. Consulta [Elegir un motor](#choose-an-engine). |
| `mode` | string | Predeterminado del motor | Cómo busca el motor: más rápido, más a fondo o con una ejecución de investigación. Consulta [Elegir un modo](#choose-a-mode). |
| `max_results` | integer | `5` | Resultados por llamada de búsqueda, hasta `25`. |
| `max_total_results` | integer | `25` | Resultados de todas las búsquedas de la solicitud, hasta `100`. Nunca es inferior a `max_results`. |
| `max_uses` | integer | `10` | Llamadas de búsqueda por solicitud, hasta `100`. |
| `search_context_size` | string | `medium` | `low`, `medium` o `high`, para los motores que ajustan el tamaño de los destacados. |
| `max_characters` | integer | El del motor | Caracteres de texto por resultado cuando se incluye el texto. |
| `allowed_domains` | string[] | Ninguno | Busca solo en estos dominios. Alias: `include_domains`. |
| `excluded_domains` | string[] | Ninguno | Excluye estos dominios. Alias: `exclude_domains`. |
| `include_highlights` | boolean | `true` | Incluye los destacados o fragmentos del motor. |
| `include_text` | boolean | `false` | Incluye más texto de la página cuando el motor lo admite. |
| `user_location` | object | Ninguno | Indicación de ubicación. Con `engine` en `native` se pasa a la búsqueda propia del proveedor; si no, la búsqueda de Phaseo la usa cuando la llamada del modelo no indica ubicación. |

## Qué envía el modelo

Cada llamada incluye una `query`. El modelo también puede enviar `max_results`, `engine`, `search_context_size`, las listas de dominios, `include_text`, `include_highlights`, `max_characters` y estas indicaciones de localización:

| Argumento | Descripción |
| --- | --- |
| `user_location` | Ubicación aproximada. Exa y Perplexity usan `user_location.country` (un código de dos letras como `GB`) para la búsqueda regional; TinyFish usa el país y el idioma. |
| `language` | Código de idioma de los resultados, como `en`, para los motores que localizan. DeepSeek lo añade a la consulta como filtro `lang:`. |
| `page` | Página de resultados de `0` a `10`, para TinyFish. |

Los valores que envía el modelo sustituyen los predeterminados de la herramienta en esa llamada. `max_results` sigue limitado por lo que quede de `max_total_results`; cuando se agota, las llamadas siguientes devuelven `max_total_results_reached`.

<span id="choose-an-engine"></span>
## Elegir un motor

| Motor | Qué se ejecuta |
| --- | --- |
| `exa` | Búsqueda gestionada de Exa. Es el predeterminado. |
| `auto` | El motor gestionado predeterminado, actualmente Exa. |
| `parallel` | Búsqueda gestionada de Parallel. |
| `firecrawl` | Búsqueda gestionada de Firecrawl. |
| `perplexity` | La Perplexity Search API: resultados ordenados, `search_context_size` y búsqueda regional a partir de `user_location.country`. |
| `tinyfish` | TinyFish Search: resultados ordenados, localizados y paginados. Devuelve fragmentos, no el texto completo de la página; usa [`phaseo:web_fetch`](./web-fetch) cuando el modelo necesite más. |
| `deepseek` | DeepSeek Search: resultados ordenados con un resumen de cada página, redactado para que lo lea el modelo. |
| `native` | La herramienta de búsqueda web propia del proveedor, como `web_search_preview` de OpenAI, `web_search_20250305` de Anthropic o `deepseek_web_search` de DeepSeek. |

Si un motor gestionado no está habilitado, la llamada devuelve `search_not_configured` al modelo.

Con `engine: "native"` en `/v1/chat/completions` o `/v1/responses`, la solicitud solo va a proveedores que ejecutan la búsqueda web por sí mismos. Si ninguno ofrece el modelo, Phaseo ejecuta en su lugar su motor predeterminado y lo factura como búsqueda gestionada.

Los proveedores que ejecutan la búsqueda web por sí mismos en estos endpoints son OpenAI, los despliegues de Azure OpenAI en `/v1/responses`, xAI y DeepSeek en `deepseek/deepseek-v4.1-flash-1017`. DeepSeek busca por su cuenta solo cuando la búsqueda web es la única herramienta de la solicitud, sin listas de dominios ni ubicación del usuario, sin salida JSON y sin un `tool_choice` forzado. Su API rechaza las listas de dominios, la ubicación y la salida JSON, desactiva su búsqueda web cuando la solicitud tiene otras herramientas y no puede forzar una búsqueda. Las demás solicitudes a ese modelo usan en su lugar la búsqueda de Phaseo, que funciona junto con tus propias herramientas. Con el razonamiento activado, DeepSeek ejecuta una búsqueda más profunda que abre y lee páginas en varios pasos.

Las herramientas de búsqueda propias de los proveedores no pueden aplicar `max_results` ni `max_total_results`, y solo la de Claude aplica `max_uses`. Una búsqueda nativa que fija un límite que su proveedor no puede aplicar se ejecuta en el motor predeterminado de Phaseo y se factura como búsqueda gestionada.

Enviar la herramienta propia de OpenAI `{ "type": "web_search" }` funciona igual que `engine: "native"`. Define `native` solo en la definición de la herramienta: si el modelo pide `native` en una llamada, la llamada devuelve `unsupported_search_engine`, porque la herramienta del proveedor debe elegirse antes de enviar la solicitud.

<span id="choose-a-mode"></span>
## Elegir un modo

Define `mode` en la herramienta para elegir cómo busca su motor. El modelo no puede cambiarlo, así que una llamada nunca cuesta más que el modo que elegiste. Si el modelo cambia a otro motor, ese motor usa su modo predeterminado. Un modo que el motor no tiene devuelve un 400.

| Motor | `mode` | Qué se ejecuta | Precio por llamada |
| --- | --- | --- | --- |
| `exa` | `lite` | Búsqueda de baja latencia para chat y voz | $0.004 |
| `exa` | `auto` (predeterminado) | Búsqueda equilibrada | $0.007 |
| `exa` | `deep-lite` | Investigación ligera en varios pasos, unos 4 segundos | $0.012 |
| `exa` | `deep` | Investigación en varios pasos con una `answer` sintetizada, de 4 a 15 segundos | $0.012 |
| `exa` | `agent-minimal` | Una ejecución de investigación de Exa Agent con esfuerzo mínimo | $0.012 |
| `exa` | `agent-low` | Una ejecución de investigación de Exa Agent con esfuerzo bajo | $0.025 |
| `parallel` | `turbo`, `fast` | La búsqueda más rápida de Parallel | $0.001 |
| `parallel` | `basic`, `advanced` (predeterminado) | La búsqueda de mayor calidad de Parallel | $0.005 |
| `parallel` | `task-lite` | Una ejecución de investigación de Parallel Task, de 10 a 60 segundos | $0.005 |
| `parallel` | `task-base` | Una ejecución de investigación de Parallel Task, de 15 a 100 segundos | $0.010 |
| `perplexity` | `standard` (predeterminado) | Perplexity Search | $0.005 |
| `perplexity` | `fast` | Perplexity Fast Search | $0.001 |

Las búsquedas de Exa y Parallel también cuestan $0.001 por cada resultado después de los 10 primeros, y Exa cobra $0.001 por página por cada tipo de contenido que devuelve, así que fragmentos destacados y texto en 5 resultados suman $0.010. `firecrawl`, `tinyfish` y `deepseek` no tienen modos.

Los modos de investigación devuelven una `answer` y las páginas que cita como `results`. Una ejecución de investigación que no ha terminado tras 120 segundos devuelve `research_timeout`. Las ejecuciones que agotan el tiempo, fallan o pierden su cliente no se cobran. Los modos de investigación no se pueden limitar a dominios, así que una herramienta de investigación con `allowed_domains` o `excluded_domains` devuelve un 400. El motor `native` no tiene modos.

## Filtrar por dominio

Usa `allowed_domains` cuando la respuesta deba proceder de un conjunto fijo de fuentes, y `excluded_domains` para quitar sitios concretos de una búsqueda por lo demás abierta.

```json
{
  "type": "phaseo:web_search",
  "parameters": { "allowed_domains": ["phaseo.app", "github.com"] }
}
```

Cada motor trata las listas de forma distinta:

- **Perplexity** acepta una de las dos listas, no ambas, con hasta 20 dominios. Los dominios excluidos se envían en su formato de lista de bloqueo.
- **Firecrawl** acepta una de las dos listas, no ambas.
- **TinyFish** acepta ambas y las convierte en operadores `site:` y `-site:` en la consulta.
- **DeepSeek** acepta ambas y las convierte en operadores `site:` y `-site:`. Sus consultas están limitadas a 128 caracteres, así que la consulta se acorta para dejar espacio a los operadores. Si solo las listas de dominios ya superan el límite, la llamada devuelve `search_query_too_long`.

## Qué devuelve la herramienta

Un resultado JSON con el motor, la consulta y una matriz `results`. Cada resultado tiene `title`, `url`, `snippet` o `highlights`, y `text` cuando se pidió el texto de la página y el motor lo proporciona.

## Uso y precios

Cada búsqueda suma a `usage.server_tool_use`:

```json
{
  "usage": {
    "server_tool_use": {
      "web_search_requests": 1,
      "web_search_results": 5,
      "web_search_extra_results": 0
    }
  }
}
```

Phaseo cobra las búsquedas en Exa, Parallel, Perplexity y DeepSeek por lo que cada motor le cobra a Phaseo: los precios de [Elegir un modo](#choose-a-mode), y $0.00075 por una búsqueda de DeepSeek, que solo se cobra si devuelve resultados. En Exa, el cargo es el costo que Exa informa para la llamada, o su precio de lista cuando Exa no informa ninguno. Cada cargo es una línea en las `pricing_lines` de la solicitud con su `engine`, `mode` y `price_source`. Las búsquedas de Firecrawl se cobran a $0.007, más $0.001 por cada resultado después de los 10 primeros. Las búsquedas fallidas no se cobran, y TinyFish Search es gratuito en sus planes publicados, así que `engine: "tinyfish"` no añade cargo de búsqueda. Las búsquedas con motores de pago requieren saldo aunque el modelo sea gratuito. La búsqueda nativa se cobra con `native_web_search_requests` al precio publicado del proveedor: por ejemplo, $10 por 1,000 búsquedas en OpenAI y Anthropic, y $0.75 por 1,000 en DeepSeek, donde solo cuentan las búsquedas que devuelven resultados. DeepSeek también cobra cada lectura de página, en la que lee una URL con su herramienta de lectura de enlaces, a $0.75 por 1,000, como `native_web_fetch_requests`. Con el razonamiento activado, una sola respuesta de DeepSeek puede ejecutar una docena de búsquedas o más, y los resultados que lee se suman a los tokens de entrada.
