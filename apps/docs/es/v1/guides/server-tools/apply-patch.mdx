---
title: "Aplicar parche"
description: "Permite que los modelos de Responses devuelvan operaciones de parche validadas."
icon: "file-pen-line"
---

Añade `phaseo:apply_patch` en `/v1/responses` para recibir los cambios en archivos como operaciones de parche estructuradas. Phaseo comprueba la forma de cada operación y la devuelve; nunca toca tus archivos. Tu aplicación decide si aplicar el parche, mostrárselo a un usuario, rechazarlo o pedir una revisión.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Create a small README patch for this project.",
    "tools": [
      { "type": "phaseo:apply_patch" }
    ]
  }'
```

En `/v1/chat/completions` o `/v1/messages`, la solicitud se rechaza.

## Parámetros

Ninguno. Añade `{ "type": "phaseo:apply_patch" }` tal cual.

## Qué envía el modelo

Un objeto `operation`:

```json
{
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  }
}
```

| `type` | Campos obligatorios | Reglas del diff |
| --- | --- | --- |
| `create_file` | `path`, `diff` | Cada línea no vacía empieza con `+` |
| `update_file` | `path`, `diff` | Cada línea no vacía empieza con `@@`, un espacio, `+` o `-` |
| `delete_file` | `path` | Ninguna |

`path` no puede contener bytes nulos.

## Qué devuelve la herramienta

```json
{
  "status": "completed",
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  },
  "message": "Patch operation validated. The client must apply or reject this patch and report the result."
}
```

Una operación que incumple las reglas anteriores devuelve `apply_patch_invalid_operation` con el motivo, para que el modelo pueda volver a intentarlo.

## Uso y precios

Cada llamada suma 1 a `usage.server_tool_use.apply_patch_requests` y se puede facturar con `server_tool_apply_patch_requests`.
