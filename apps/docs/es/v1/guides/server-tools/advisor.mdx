---
icon: "compass"
title: "Herramienta de servidor Advisor"
description: "Permite que un modelo consulte a otro modelo durante la generación."
---

Añade `phaseo:advisor` para que el modelo principal pueda pedir a un segundo modelo una revisión, un plan, una comprobación o una opinión experta antes de responder. El modelo principal llama al Advisor como a cualquier otra herramienta; Phaseo ejecuta el modelo Advisor y devuelve su consejo como resultado de la herramienta.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Design a rate limiter for a distributed API gateway." }
    ],
    "tools": [
      {
        "type": "phaseo:advisor",
        "parameters": {
          "model": "anthropic/claude-opus-5",
          "max_uses": 1,
          "max_completion_tokens": 1400
        }
      }
    ]
  }'
```

Advisor funciona con cualquier modelo de texto compatible. Lo ejecuta el propio Phaseo; solo se convierte en la herramienta Advisor nativa de Anthropic si envías el formato de herramienta nativo de Anthropic.

## Parámetros

```json
{
  "type": "phaseo:advisor",
  "parameters": {
    "name": "reviewer",
    "model": "anthropic/claude-opus-5",
    "instructions": "Review plans for correctness, missing edge cases, and implementation risk.",
    "forward_transcript": true,
    "max_uses": 2,
    "max_completion_tokens": 1400,
    "reasoning": { "effort": "high" },
    "temperature": 0.2
  }
}
```

| Parámetro | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `name` | string | Ninguno | De 1 a 64 letras, números, espacios, guiones bajos o guiones. Es obligatorio cuando añades más de un Advisor. |
| `model` | string | Ver abajo | El modelo Advisor. |
| `instructions` | string | Instrucciones integradas del Advisor | Instrucciones adicionales para el Advisor. |
| `forward_transcript` | boolean | `false` | Envía la conversación actual al Advisor. |
| `max_uses` | integer | `1` | Llamadas a este Advisor por solicitud. |
| `max_completion_tokens` | integer | `1400` | Tokens de salida de cada respuesta del Advisor. Los valores por debajo de `1024` se suben a `1024`. `max_tokens` se acepta como alias antiguo. |
| `reasoning` | object | Valor predeterminado del proveedor | Ajustes de razonamiento, que se transmiten cuando el modelo Advisor los admite. |
| `temperature` | number | Valor predeterminado del proveedor | Temperatura de muestreo para la llamada al Advisor. |

El modelo Advisor es `parameters.model` si está establecido; si no, el `model` que envía el modelo principal en su llamada; y si no, el propio modelo de la solicitud.

## Qué envía el modelo

Normalmente, un `prompt`. Si la herramienta no fija un modelo, la llamada también puede elegir uno:

```json
{
  "model": "anthropic/claude-opus-5",
  "prompt": "Check this security design for missing controls."
}
```

Con `forward_transcript: true`, el modelo puede llamar al Advisor sin prompt, y el Advisor revisa la conversación reenviada.

## Añade varios advisors

Añade una entrada `phaseo:advisor` por cada advisor. Cada Advisor con nombre se convierte en una herramienta propia para el modelo, como `phaseo_advisor_security_reviewer`.

```json
{
  "tools": [
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "security-reviewer",
        "model": "anthropic/claude-opus-5",
        "instructions": "Review for vulnerabilities, abuse cases, and missing mitigations."
      }
    },
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "architect",
        "model": "openai/gpt-5",
        "instructions": "Review system design tradeoffs and operational risks."
      }
    }
  ]
}
```

Los nombres deben ser únicos tras quitar los espacios de los extremos y sin distinguir mayúsculas y minúsculas, y como máximo una entrada puede omitir `name`; si no, la solicitud se rechaza. `tool_choice: "phaseo:advisor"` con varios Advisors fuerza el primero.

## Qué devuelve la herramienta

```json
{
  "status": "ok",
  "name": "reviewer",
  "model": "anthropic/claude-opus-5",
  "advice": "Start with a smaller migration slice and define rollback criteria before changing traffic routing."
}
```

Si la llamada no se puede ejecutar, el modelo recibe en su lugar un resultado de error: `advisor_invalid_request` (sin prompt o sin modelo), `advisor_max_uses_exceeded` o `advisor_request_failed`.

El Advisor no guarda estado entre solicitudes. Si reenvías mensajes y resultados de herramientas anteriores, el modelo principal ve el consejo anterior; el Advisor solo ve la conversación cuando `forward_transcript` está activado. El consejo no se transmite en streaming, y el Advisor no puede llamar a herramientas por su cuenta.

## Uso y precios

Cada llamada suma 1 a `usage.server_tool_use.advisor_requests` y puede cobrarse con `server_tool_advisor_requests`. Los tokens de Advisor se cobran según las tarifas del propio modelo Advisor, como una línea aparte en la factura de la solicitud, y no se suman a los tokens del modelo que lo llama. Un modelo Advisor de pago requiere saldo aunque el modelo que lo llama sea gratuito.
