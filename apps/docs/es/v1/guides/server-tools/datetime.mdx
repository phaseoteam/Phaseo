title: "Herramienta de fecha y hora"
description: "Proporciona a los modelos la fecha y hora actuales en una o varias zonas horarias."
---

Usa `phaseo:datetime` cuando una solicitud dependa de la fecha actual, el día de la semana, la hora o la zona horaria.

El modelo decide cuándo llamar a la herramienta. Phaseo devuelve al modelo las zonas horarias resueltas y las marcas de tiempo actuales; después, el modelo redacta la respuesta final.

## Inicio rápido

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "messages": [
      { "role": "user", "content": "What day of the week is it in Tokyo?" }
    ],
    "tools": [
      {
        "type": "phaseo:datetime",
        "parameters": {
          "timezones": ["Asia/Tokyo", "UTC"]
        }
      }
    ]
  }'
```

## Configuración

```json
{
  "type": "phaseo:datetime",
  "parameters": {
    "timezones": ["Europe/London", "UTC"]
  }
}
```

| Parámetro | Tipo | Valor predeterminado | Descripción |
| --- | --- | --- | --- |
| `timezones` | string[] | `["UTC"]` | Hasta 5 nombres de zonas horarias IANA que se devolverán en una llamada a la herramienta, por ejemplo, `["Europe/London", "UTC"]`. |

## Resultado de la herramienta

El resultado de la herramienta contiene una entrada por cada zona horaria solicitada.

```json
{
  "timezones": [
    {
      "timezone": "Europe/London",
      "datetime": "2026-07-03T10:00:00.123+01:00"
    },
    {
      "timezone": "UTC",
      "datetime": "2026-07-03T09:00:00.123+00:00"
    }
  ]
}
```

## Uso

Las llamadas a Datetime incrementan:

```json
{
  "usage": {
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```
