title: "Herramienta de servidor Datetime"
description: "Da a los modelos la fecha y la hora actuales en una o varias zonas horarias."
---

Añade `phaseo:datetime` para que el modelo pueda consultar la fecha y la hora actuales cuando un prompt dependa de ellas, como "¿qué día es en Tokio?". El modelo decide cuándo llamarla; Phaseo devuelve la hora en cada zona horaria que indicaste.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What day of the week is it in Tokyo?" }
    ],
    "tools": [
      {
        "type": "phaseo:datetime",
        "parameters": { "timezones": ["Asia/Tokyo", "UTC"] }
      }
    ]
  }'
```

## Parámetros

| Parámetro | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `timezones` | string[] | `["UTC"]` | Hasta 5 nombres de zona horaria IANA, como `["Europe/London", "UTC"]`. |

Más de 5 zonas horarias, o un nombre que no sea una zona horaria IANA válida, hace que la solicitud se rechace antes de que se ejecute el modelo. El nombre de tipo antiguo `gateway:datetime` se sigue aceptando.

## Qué devuelve la herramienta

Una entrada por zona horaria:

```json
{
  "timezones": [
    { "timezone": "Europe/London", "datetime": "2026-07-03T10:00:00.123+01:00" },
    { "timezone": "UTC", "datetime": "2026-07-03T09:00:00.123+00:00" }
  ]
}
```

## Uso y precios

Cada llamada suma 1 a `usage.server_tool_use.datetime_requests`. Datetime no tiene un medidor de precio propio.
