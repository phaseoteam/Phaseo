description: "Permite que el modelo principal delegue trabajo concreto en un modelo trabajador."
---

Añade `phaseo:subagent` para que el modelo principal pueda pasar una tarea autónoma a un modelo trabajador, a menudo uno más pequeño o más rápido, dentro de la misma solicitud. El modelo principal describe la tarea; Phaseo ejecuta el trabajador y devuelve su resultado, y el modelo principal termina la respuesta.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5",
    "messages": [
      { "role": "user", "content": "Compare these release notes and summarize the breaking changes." }
    ],
    "tools": [
      {
        "type": "phaseo:subagent",
        "parameters": {
          "model": "openai/gpt-6-astra",
          "instructions": "Return concise findings for the main model. Do not address the end user directly.",
          "max_uses": 3,
          "max_completion_tokens": 1200
        }
      }
    ]
  }'
```

## Parámetros

| Parámetro | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `model` | string | El modelo de la solicitud | El modelo trabajador. |
| `instructions` | string | Instrucciones integradas del trabajador | Instrucciones adicionales para el trabajador. |
| `max_uses` | integer | `1` | Llamadas a Subagent por solicitud. |
| `max_completion_tokens` | integer | `1400` | Tokens de salida de cada respuesta del trabajador. Los valores por debajo de `1024` se suben a `1024`. `max_tokens` se acepta como alias antiguo. |
| `reasoning` | object | Valor predeterminado del proveedor | Ajustes de razonamiento, que se transmiten cuando el modelo trabajador los admite. |
| `temperature` | number | Valor predeterminado del proveedor | Temperatura de muestreo para la llamada al trabajador. |

El trabajador nunca recibe la conversación: incluye en la tarea todo lo que necesite.

## Qué envía el modelo

Un `task_description` con la tarea completa, el contexto y la salida esperada, más un `task_name` corto opcional:

```json
{
  "task_description": "Extract the three highest-risk migration steps from the supplied plan."
}
```

Se aceptan `task`, `prompt` o `input` en lugar de `task_description`.

## Qué devuelve la herramienta

```json
{
  "status": "ok",
  "model": "openai/gpt-6-astra",
  "outcome": "The highest-risk steps are schema migration, traffic cutover, and rollback verification."
}
```

Si la llamada no se puede ejecutar, el modelo recibe `subagent_invalid_request` (sin tarea), `subagent_max_uses_exceeded` o `subagent_request_failed`.

## Uso y precios

Cada llamada suma 1 a `usage.server_tool_use.subagent_requests` y se puede facturar con `server_tool_subagent_requests`. Los tokens del trabajador se suman al uso de la solicitud y se cobran a las tarifas del modelo trabajador. Para obtener una revisión en lugar de delegar trabajo, usa [Advisor](./advisor).
