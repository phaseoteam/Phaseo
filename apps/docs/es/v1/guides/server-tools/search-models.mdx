title: "Herramienta de servidor Search Models"
description: "Permite que un modelo encuentre modelos adecuados en el catálogo actual de Phaseo."
---

Añade `phaseo:search_models` para que el modelo pueda elegir o recomendar un modelo usando el catálogo actual de Phaseo: modalidades, proveedores, parámetros admitidos y precios actuales.

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "Which models can transcribe audio and return JSON?" }
  ],
  "tools": [{ "type": "phaseo:search_models", "parameters": { "max_results": 5 } }],
  "max_tool_calls": 10
}
```

## Parámetros

| Parámetro | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `max_results` | integer | `5` | Modelos devueltos por búsqueda, hasta `20`. |

## Qué envía el modelo

Cualquiera de estos filtros. Solo se buscan modelos activos, y un modelo debe cumplir todos los filtros enviados.

| Argumento | Coincide con |
| --- | --- |
| `query` | Texto en el ID, el nombre o la descripción del modelo |
| `series` | Texto en el ID, el nombre o la descripción del modelo |
| `input_modalities` | Modelos que aceptan todas estas entradas |
| `output_modalities` | Modelos que producen todas estas salidas |
| `provider` | Un ID o nombre de proveedor |
| `required_params` | Modelos que admiten todos estos parámetros de solicitud |

## Qué devuelve la herramienta

```json
{
  "models": [
    {
      "id": "openai/gpt-4o-mini-transcribe",
      "name": "...",
      "description": "...",
      "input_modalities": ["audio"],
      "output_modalities": ["text"],
      "providers": ["openai"],
      "supported_params": ["..."],
      "pricing": {}
    }
  ],
  "total_results": 4,
  "showing": 4
}
```

## Uso y precios

Cada búsqueda suma 1 a `usage.server_tool_use.search_models_requests` y se puede facturar con `server_tool_search_models_requests`.
