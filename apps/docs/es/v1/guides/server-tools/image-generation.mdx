title: "Generación de imágenes"
description: "Permite que los modelos creen imágenes mediante una herramienta del servidor de Phaseo."
---

Usa `phaseo:image_generation` cuando el modelo deba crear una imagen durante la respuesta. Phaseo proporciona al modelo una herramienta gestionada, ejecuta la solicitud de imagen en el servidor y devuelve el resultado al ciclo del modelo.

## Solicitud

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Design a wide product concept image for a compact desktop synthesizer.",
    "tools": [
      {
        "type": "phaseo:image_generation",
        "parameters": {
          "model": "openai/gpt-image-2",
          "quality": "high",
          "aspect_ratio": "16:9",
          "output_format": "png"
        }
      }
    ]
  }'
```

## Parámetros

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| `model` | string | ID opcional de un modelo compatible con imágenes. El valor predeterminado es `openai/gpt-image-2` si ni la herramienta ni la llamada proporcionan un modelo. |
| `quality` | string | Indicación opcional de calidad del proveedor, como `low`, `medium` o `high`. |
| `size` | string | Indicación opcional del tamaño de la imagen. |
| `aspect_ratio` | string | Relación de aspecto opcional, como `1:1`, `16:9` o `9:16`. |
| `background` | string | Indicación opcional del modo de fondo. |
| `output_format` | string | Formato de salida opcional, como `png`, `jpeg` o `webp`. |
| `output_compression` | integer | Indicación opcional de compresión del proveedor. |
| `moderation` | string | Indicación opcional de moderación del proveedor. |

El modelo proporciona el `prompt` final al llamar a la herramienta. Los parámetros de la herramienta definen los valores predeterminados y las restricciones de esa llamada.

La llamada a la herramienta también puede enviar `description` en lugar de `prompt`. Para mantener la compatibilidad con descripciones de imágenes generadas por modelos, Phaseo trata `description` como un alias de prompt.

## Resultado de la herramienta

El resultado se devuelve al modelo en formato JSON:

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "imageUrl": "https://...",
  "mime_type": "image/png"
}
```

Algunos proveedores devuelven datos de imagen en base64:

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "b64_json": "...",
  "mime_type": "image/png"
}
```

## Uso y precios

El uso de generación de imágenes se incluye en el uso de la respuesta principal cuando el modelo de imagen informa del uso de tokens. Phaseo también registra:

```json
{
  "usage": {
    "server_tool_use": {
      "image_generation_requests": 1
    }
  }
}
```

Las tarjetas de precios pueden cobrarlo con el contador `server_tool_image_generation_requests`. El uso del modelo de imagen subyacente también puede cobrarse según sus precios habituales.
