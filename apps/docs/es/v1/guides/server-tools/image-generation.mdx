title: "Generación de imágenes"
description: "Permite que los modelos creen imágenes mediante una herramienta de servidor de Phaseo."
---

Añade `phaseo:image_generation` para que el modelo pueda crear una imagen mientras responde. El modelo escribe el prompt de la imagen; Phaseo llama al modelo de imágenes y devuelve la imagen al ciclo del modelo.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Design a wide product concept image for a compact desktop synthesizer.",
    "tools": [
      {
        "type": "phaseo:image_generation",
        "parameters": {
          "model": "openai/gpt-image-2",
          "quality": "high",
          "aspect_ratio": "16:9",
          "output_format": "png"
        }
      }
    ]
  }'
```

## Parámetros

Todos los parámetros son opcionales.

| Parámetro | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `model` | string | `openai/gpt-image-2` | Modelo de imágenes. Si lo estableces aquí, sustituye cualquier modelo que pida el modelo principal. |
| `quality` | string | Valor predeterminado del proveedor | Indicación de calidad, como `low`, `medium` o `high`. |
| `size` | string | Valor predeterminado del proveedor | Indicación del tamaño de la imagen. |
| `aspect_ratio` | string | Valor predeterminado del proveedor | Relación de aspecto, como `1:1`, `16:9` o `9:16`. |
| `background` | string | Valor predeterminado del proveedor | Indicación del modo de fondo. |
| `output_format` | string | Valor predeterminado del proveedor | `png`, `jpeg` o `webp`. |
| `output_compression` | integer | Valor predeterminado del proveedor | Indicación de compresión, limitada al intervalo de `0` a `100`. |
| `moderation` | string | Valor predeterminado del proveedor | Indicación de moderación para el proveedor. |

## Qué envía el modelo

Un `prompt` (o `description`, que se trata igual). También puede enviar `model`, que solo se usa cuando la herramienta no establece uno, y cualquiera de los demás parámetros de arriba, que sustituyen los valores de la herramienta en esa llamada.

## Qué devuelve la herramienta

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "imageUrl": "https://...",
  "mime_type": "image/png"
}
```

Algunos proveedores devuelven `b64_json` con los datos de la imagen en base64 en lugar de `imageUrl`. Si la llamada no tiene prompt, el modelo recibe `image_generation_invalid_request`; si falla el modelo de imágenes, `image_generation_failed`.

## Uso y precios

Cada imagen suma 1 a `usage.server_tool_use.image_generation_requests` y se puede facturar con `server_tool_image_generation_requests`. Cuando el modelo de imágenes informa del uso de tokens, se suma al uso de la solicitud y se factura a las tarifas normales de ese modelo.
