description: "Permite que los modelos obtengan y lean URL concretas durante una solicitud."
---

Añade `phaseo:web_fetch` para que el modelo pueda leer una URL conocida, como una página de documentación, un artículo o un registro de cambios. El modelo proporciona la `url`; Phaseo obtiene la página y devuelve su texto, recortado a un límite de tamaño, y el modelo puede obtener más páginas antes de responder.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Summarize https://phaseo.app/docs/v1/guides/tool-calling" }
    ],
    "tools": [
      { "type": "phaseo:web_fetch" }
    ]
  }'
```

<span id="parameters"></span>
## Parámetros

```json
{
  "type": "phaseo:web_fetch",
  "parameters": {
    "engine": "direct",
    "max_chars": 12000,
    "allowed_domains": ["phaseo.app"],
    "blocked_domains": ["internal.example.com"]
  }
}
```

| Parámetro | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `engine` | string | `direct` | `auto`, `native`, `direct`, `exa`, `parallel`, `firecrawl` o `deepseek`. Consulta [Elegir un motor](#choose-an-engine). |
| `max_chars` | integer | `12000` | Caracteres del texto de la página que se devuelven al modelo, hasta `100000`. |
| `max_content_tokens` | integer | Ninguno | Se usa en lugar de `max_chars` cuando se omite `max_chars`. También es el límite de tamaño para `native`. |
| `max_uses` | integer | `10` | Llamadas de obtención por solicitud, hasta `100`. |
| `allowed_domains` | string[] | Ninguno | Solo obtiene páginas de estos dominios. El modelo puede acotar esta lista en una llamada, pero no ampliarla. |
| `blocked_domains` | string[] | Ninguno | Nunca obtiene páginas de estos dominios. Alias: `excluded_domains`. |

## Qué envía el modelo

Cada llamada incluye una `url`. El modelo también puede enviar `engine`, `max_chars`, `max_content_tokens` y las listas de dominios.

<span id="choose-an-engine"></span>
## Elegir un motor

| Motor | Qué se ejecuta |
| --- | --- |
| `auto` | La obtención nativa de Anthropic en `/v1/messages`. En otros endpoints, Exa si está habilitado y, si no, `direct`. |
| `direct` | Phaseo obtiene la página por sí mismo y reduce el HTML a texto sin formato. |
| `exa` | Extracción de contenido de Exa. |
| `parallel` | Parallel Extract. |
| `firecrawl` | Firecrawl Scrape. |
| `deepseek` | DeepSeek Fetch, que devuelve la página como Markdown. |
| `native` | La herramienta `web_fetch_20260209` de Anthropic, solo en `/v1/messages`. En otros endpoints la solicitud se rechaza; usa `direct` o un motor gestionado. |

Si un motor gestionado no está habilitado, la llamada devuelve `fetch_not_configured` al modelo.

Solo funcionan las URL HTTP(S). `direct` solo acepta tipos de contenido de texto, como HTML, texto sin formato y JSON, y devuelve `unsupported_content_type` para cualquier otro. Sigue hasta 5 redirecciones y comprueba cada una con tus listas de dominios.

### Obtención nativa de Anthropic

```json
{
  "model": "anthropic/claude-sonnet-4.6",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "Read the docs page and summarize the limits." }
  ],
  "tools": [
    {
      "type": "phaseo:web_fetch",
      "parameters": {
        "engine": "native",
        "max_content_tokens": 9000,
        "allowed_domains": ["phaseo.app"]
      }
    }
  ],
  "tool_choice": { "type": "tool", "name": "phaseo:web_fetch" }
}
```

## Qué devuelve la herramienta

```json
{
  "provider": "fetch",
  "engine": "direct",
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "text": "...",
  "truncated": false,
  "returned_chars": 8421
}
```

Comprueba `truncated` antes de dar por hecho que el modelo vio la página completa. Para ver un ejemplo completo, consulta [Fundamentar herramientas con Web Fetch](../../cookbook/tool-grounding-with-web-fetch).

## Uso y precios

Cada consulta suma 1 a `usage.server_tool_use.web_fetch_requests`. Phaseo cobra cada consulta gestionada a través de Exa, Parallel, Firecrawl o DeepSeek a $0.001, salvo que la tarjeta de precios del modelo fije su propio precio para `server_tool_web_fetch_requests`; las consultas directas son gratuitas. Las consultas con motores de pago requieren saldo aunque el modelo sea gratuito. La consulta nativa se cobra con `native_web_fetch_requests` donde la tarjeta de precios del modelo lo define.
