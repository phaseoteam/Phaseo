Streaming envía la respuesta en fragmentos SSE progresivos para que los usuarios la vean antes.

## Endpoints compatibles

- `/v1/responses`
- `/v1/chat/completions`
- `/v1/messages`

## Solicitud

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Stream a short hello message.",
    "stream": true
  }'
```

## Respuesta

```text
data: {"id":"resp_...","object":"response","status":"in_progress",...}
data: {"type":"response.output_text.delta","delta":"Hello"}
data: {"type":"response.completed",...}
data: [DONE]
```

## Opciones del SDK

- SDK de TypeScript: `client.streamResponses()`, `client.streamChat()` y `client.streamMessages()`
- Python SDK: `client.stream_responses()`, `client.stream_chat()` y `client.stream_message()`
- Vercel AI SDK: `streamText(...)` con `@phaseo/ai-sdk-provider`

## Limitación importante

Con el nivel actual de validación de solicitudes del gateway, no se permite combinar herramientas con `stream: true` (`400 invalid_request`). Usa el modo sin streaming para los ciclos de llamadas a herramientas.
