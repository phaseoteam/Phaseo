Elige un proyecto de ejemplo para ejecutar localmente y adaptar. Para una sola llamada de API, usa el [Inicio rápido](../quickstart.mdx); para una función específica, consulta el [Recetario](../cookbook/index.mdx).

## Proyectos ejecutables

| Construcción | Guía | Código fuente |
| --- | --- | --- |
| Chat en el navegador con una clave de API en el servidor | [Chat de Next.js](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| Autorización OAuth y proxy backend | [Entorno de pruebas OAuth](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| Una integración REST mínima | [Aplicación de prueba rápida de Node](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| Una aplicación de línea de comandos de Python | [Python CLI](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| Una aplicación que usa Vercel AI SDK | [Integración de AI SDK](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

Mantén las credenciales en el servidor, revisa las variables de entorno del ejemplo y comprueba el precio del modelo seleccionado antes de ejecutarlo. Los ejemplos con modelos `:free` no requieren créditos depositados.

## Solicitudes por lenguaje

La [referencia de los SDK cliente](../sdk-reference/typescript/overview.mdx) contiene ejemplos de instalación y solicitudes por lenguaje. Usa la [referencia de generación de imágenes](../api-reference/endpoint/images-generations.mdx) para los parámetros de imágenes y [Chat Completions](../api-reference/endpoint/chat-completions.mdx) para solicitudes de chat.

Para que un agente de programación cree la estructura de un proyecto, usa los [prompts iniciales de miniaplicaciones](../cookbook/mini-app-starter-prompts.mdx) y revisa el código generado antes de usarlo con credenciales reales.
