Elige un proyecto de ejemplo para ejecutarlo localmente y adaptarlo. Para una sola llamada a la API, usa el [Inicio rápido](../quickstart.mdx); para una función concreta, consulta el [Recetario](../cookbook/index.mdx).

## Proyectos ejecutables

| Qué construir | Guía paso a paso | Código fuente |
| --- | --- | --- |
| Chat en el navegador con una clave de API del lado del servidor | [Chat con Next.js](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| Autorización OAuth y un proxy de backend | [Banco de trabajo OAuth](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| Una integración REST mínima | [Aplicación de prueba con Node](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| Una aplicación de línea de comandos en Python | [CLI en Python](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| Una aplicación con Vercel AI SDK | [Integración con AI SDK](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

Mantén las credenciales en el servidor, revisa las variables de entorno del ejemplo y comprueba el precio del modelo seleccionado antes de ejecutarlo. Los ejemplos que usan modelos `:free` no requieren créditos depositados.

## Solicitudes por lenguaje

La [referencia del SDK de cliente](../sdk-reference/client/overview.mdx) contiene ejemplos de instalación y de solicitudes por lenguaje. Usa la [referencia de generación de imágenes](../api-reference/endpoint/images-generations.mdx) para los parámetros de imagen y [Chat Completions](../api-reference/endpoint/chat-completions.mdx) para las solicitudes de chat.

Para que un agente de programación genere la estructura de un proyecto, usa los [prompts iniciales para miniaplicaciones](../cookbook/mini-app-starter-prompts.mdx) y revisa el código generado antes de usarlo con credenciales reales.
