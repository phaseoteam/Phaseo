icon: "waypoints"
title: "Patrones de llamadas a herramientas"
description: "Ciclos fiables de llamadas a herramientas para los endpoints de chat completions y responses."
---

Después de que el modelo llame a una herramienta, envía una solicitud de seguimiento que repita la conversación, la llamada del modelo y el resultado de tu herramienta. El modelo escribe entonces su respuesta, o llama a otra herramienta y repites el proceso. Usa el endpoint cuyo formato de mensajes ya usa tu aplicación: `/v1/chat/completions` para ciclos de mensajes al estilo de OpenAI, `/v1/responses` para la API Responses y `/v1/messages` para aplicaciones nativas de Anthropic.

<Tabs>
<Tab title="Chat Completions">

Cuando `finish_reason` es `tool_calls`, ejecuta cada llamada y después envía el mensaje del asistente sin cambios, seguido de un mensaje `role: "tool"` por cada llamada, emparejado por `tool_call_id`. Vuelve a enviar `tools`.

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "What is the weather in Seattle?" },
    {
      "role": "assistant",
      "content": null,
      "tool_calls": [
        {
          "id": "call_123",
          "type": "function",
          "function": {
            "name": "get_weather",
            "arguments": "{\"city\":\"Seattle\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_123",
      "content": "72F and sunny"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    }
  ]
}
```

</Tab>
<Tab title="Responses">

Las llamadas llegan como elementos de salida de tipo `function_call`. Devuelve el elemento de la llamada como entrada, seguido de un elemento `function_call_output` con el mismo `call_id`.

```json
{
  "model": "openai/gpt-6-astra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [{ "type": "input_text", "text": "What's the weather in Seattle?" }]
    },
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Seattle\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "72F and sunny"
    }
  ]
}
```

</Tab>
</Tabs>

Antes de ejecutar una llamada, valida sus argumentos; consulta [Seguridad y validación de llamadas a herramientas](./tool-calling-safety).
