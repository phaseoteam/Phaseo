Envía un encabezado `X-Phaseo-Metadata` para marcar una solicitud con etiquetas clave/valor, como `team=support`, y después filtra el gasto y los registros por esas etiquetas. Usa etiquetas cuando necesites una dimensión de coste más específica que una clave de API o una aplicación. No cambian la solicitud al modelo y no se reenvían a los proveedores.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H 'X-Phaseo-Metadata: {"labels":[{"key":"team","value":"support"},{"key":"environment","value":"production"}]}' \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Summarize this ticket."
  }'
```

Los SDK de TypeScript y Python aceptan encabezados personalizados, así que puedes configurar el mismo encabezado una sola vez en el cliente.

Para etiquetar solicitudes automáticamente según su contenido, usa [clasificadores de solicitudes](/es/v1/guides/request-classifiers). Sus respuestas se guardan como etiquetas de solicitud y se filtran de la misma forma.

## Reglas de las etiquetas

| Regla | Límite |
| --- | --- |
| Etiquetas por solicitud | Hasta 32, cada una con una clave única |
| Clave | De 1 a 64 caracteres: letras, números, `_`, `.`, `:`, `-` |
| Valor | Cadena de 1 a 256 caracteres, sin caracteres de control |
| Tamaño del encabezado | Hasta 8 KiB |
| Clave reservada | `phaseo.classifier` solo la establecen las llamadas de clasificadores de Phaseo |

Se eliminan los espacios al principio y al final de claves y valores. Un encabezado mal formado, una clave duplicada o una etiqueta que incumpla estas reglas hace que la solicitud falle con `400 validation_error`, motivo `invalid_request_metadata`, antes de llamar a ningún modelo.

No pongas prompts, secretos, direcciones de correo electrónico ni otros datos personales en las etiquetas.

## Filtra el gasto por etiqueta

Pasa `label_key` y `label_value` al endpoint de analíticas:

```text
GET /v1/analytics?label_key=team&label_value=support
```

La respuesta tiene el mismo formato de gasto agrupado que las analíticas sin filtrar, pero solo cuenta las solicitudes que llevan exactamente ese par de etiqueta. Si envías solo uno de los dos parámetros, se devuelve `400 invalid_request`.
