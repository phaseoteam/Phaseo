Envía cada valoración de usuario a `POST /v1/feedback` con el ID de la solicitud y el [preajuste](./presets.mdx) que respondió. Después compara los preajustes según la frecuencia con la que sus respuestas recibieron buenas valoraciones, no solo por latencia y coste.

<Note>
Preset Feedback está en fase Alfa, y la API y el panel aún pueden cambiar. Usa el botón **Comentarios** de la [página de Preset Feedback](https://phaseo.app/settings/presets/experiments) para contarnos qué lo haría más útil.
</Note>

## Registra una valoración

Necesitas una clave de API con la capacidad `feedback:write`, el ID de solicitud que devolvió Phaseo y el UUID del preajuste. El ID del preajuste es lo que incluye el evento en las comparaciones de preajustes y en el análisis por cohortes.

```bash cURL
curl https://api.phaseo.app/v1/feedback \
  -X POST \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "requestId": "gen_01K...",
    "presetId": "8f54b2d9-9ba3-4ced-8a7f-9bb70a44dbea",
    "rating": "thumbs_up",
    "score": 1,
    "comment": "The answer resolved the customer question.",
    "metadataDimensions": {
      "plan": "pro",
      "surface": "support_chat"
    }
  }'
```

Un evento de comentario debe apuntar al menos a una solicitud, sesión, preajuste o ejecución de prueba. `score` es opcional y debe estar entre `0` y `1`.

Pon en `metadataDimensions` los valores de baja cardinalidad, como el plan, el despliegue, la configuración regional o la superficie de la aplicación, para poder filtrar por ellos. El contexto arbitrario o de alta cardinalidad va en `metadata`.

## Elige una valoración

| Señal | `rating` |
| --- | --- |
| Una reacción simple del usuario | `thumbs_up`, `thumbs_down` |
| Una respuesta evaluada | `correct`, `partly_correct`, `incorrect` |
| Un problema operativo | `bad_format`, `too_slow`, `too_expensive` |
| Un resultado de seguridad | `unsafe`, `refused_incorrectly` |
| Cualquier otra cosa | `not_helpful`, `other` |

Es preferible una valoración explícita a una puntuación numérica sola: las comparaciones de preajustes se basan en las valoraciones, y las puntuaciones se muestran como detalle complementario.

## Compara preajustes

Abre [Ajustes → Presets → Comentarios](https://phaseo.app/settings/presets/experiments) para:

- comparar los porcentajes de valoraciones positivas, parciales y negativas
- seleccionar un preajuste de referencia
- filtrar por fecha, valoración y dimensiones de metadatos
- revisar la solicitud, la sesión, los comentarios y las etiquetas que hay detrás de un evento

El panel analiza como máximo las 10.000 filas de comentarios coincidentes más recientes del periodo seleccionado.

## Lee los comentarios con la API

Para leer se necesita `feedback:read`. Los resultados se limitan al espacio de trabajo autenticado y a los preajustes que puede ver quien hace la llamada.

Lista los eventos recientes:

```bash
curl "https://api.phaseo.app/v1/feedback?preset_id=PRESET_UUID&limit=100" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

Obtén un resumen calculado en el servidor:

```bash
curl "https://api.phaseo.app/v1/feedback/summary?group_by=preset&since=2026-08-01T00:00:00Z" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

Las API de ejecuciones de prueba y de eventos de resultados personalizados están disponibles, pero sus vistas del panel aún están cambiando. Para desplegar un cambio de preajuste de forma gradual, consulta [Desplegar preajustes y depurar el enrutamiento](../cookbook/preset-rollout-and-routing-debug).
