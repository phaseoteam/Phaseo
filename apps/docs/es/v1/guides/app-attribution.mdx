title: "Atribución de aplicaciones"
description: "Agrupa el uso de Gateway por aplicación mediante ID, nombres, URL y categorías estables."
icon: "badge-check"
---

Envía un encabezado `X-App-Id` en cada solicitud para agrupar su uso bajo una aplicación en los análisis de aplicaciones y las auditorías de solicitudes. Usa un ID distinto para cada producto, entorno o experiencia de cara al cliente sobre la que quieras informar por separado. La atribución nunca modifica la respuesta de inferencia.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-App-Id: acme-support" \
  -H "X-App-Name: Acme Support" \
  -H "HTTP-Referer: https://acme.example/support" \
  -H "X-App-Categories: chat,productivity" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Summarize this ticket."
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const phaseo = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY,
  app: {
    id: "acme-support",
    name: "Acme Support",
    url: "https://acme.example/support",
    categories: ["chat", "productivity"],
  },
});

const response = await phaseo.generateResponse({
  model: "openai/gpt-6-astra",
  input: "Summarize this ticket.",
});
```
</CodeGroup>

La opción `app` del SDK de TypeScript envía los mismos encabezados en cada solicitud. Phaseo nunca define la atribución por ti.

## Encabezados

| Encabezado | Finalidad |
| --- | --- |
| `X-App-Id` | Identificador estable que elige tu aplicación. |
| `X-App-Name` | Nombre legible que se muestra en las vistas de aplicaciones y de uso. |
| `HTTP-Referer` | URL de la página pública o del despliegue asociada a la aplicación. |
| `X-App-Categories` | Lista separada por comas de hasta tres categorías. |
| `X-Title` | Alias de compatibilidad para un nombre de aplicación legible. |

Phaseo identifica la aplicación por su URL de `HTTP-Referer` cuando la envías y, si no, por `X-App-Id`. Mantén ambos estables: una URL o un ID nuevos crean una aplicación nueva en los análisis.

`HTTP-Referer` no tiene que coincidir con el encabezado `Referer` que el navegador envía automáticamente. Defínelo de forma explícita en las integraciones del lado del servidor cuando quieras una única URL canónica para la aplicación.

## Categorías

Elige hasta tres entre `chat`, `developer-tools`, `research`, `productivity`, `education`, `commerce`, `media`, `finance` y `other`.

Los valores no distinguen entre mayúsculas y minúsculas. Phaseo ignora los valores desconocidos, elimina los duplicados y conserva las tres primeras categorías válidas. Las categorías enviadas en solicitudes posteriores se añaden a las ya guardadas para la aplicación; nunca eliminan las categorías elegidas en el panel.

Para gestionar las categorías de forma centralizada en lugar de en el código de la aplicación, edítalas en **Ajustes → Aplicaciones**.

## Mantén la atribución segura para compartir

- No pongas ID de clientes, direcciones de correo electrónico ni otros datos personales en los encabezados de atribución.
- Trata la URL y el nombre como públicos: pueden aparecer en vistas de aplicaciones compartidas o públicas.
