<Update label="29 de abril de 2026" tags={["Novedades","Lanzamientos de modelos","SDK"]}>

### Lanzamientos del SDK

- Se publicó el SDK `2.0.2` para [TypeScript](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fsdk%402.0.2), [Python](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fpy-sdk%402.0.2), [Go](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fgo-sdk%402.0.2), [C#](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fcsharp-sdk%402.0.2), [Java](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fjava-sdk%402.0.2), [PHP](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fphp-sdk%402.0.2) y [Ruby](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fruby-sdk%402.0.2).
- Esta versión separó los ID de modelo de las solicitudes en tiempo de ejecución de las constantes auxiliares generadas, para que los modelos nuevos puedan usarse antes de publicar la siguiente versión del SDK.
- Los auxiliares generados ahora siguen la instantánea actual de modelos invocables en la pasarela, lo que reduce los cambios innecesarios del SDK causados solo por actualizaciones del catálogo.

### Novedades

- Se ampliaron las alertas de saldo bajo y las protecciones de facturación para avisar con más claridad antes de que el uso alcance los límites de la cuenta ([PR #371](https://github.com/phaseoteam/Phaseo/pull/371)).
