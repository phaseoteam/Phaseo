<Update label="23 de marzo de 2026">

<div data-changelog-category="product">

<p className="changelog-category">Producto</p>

- Las salas de chat ahora pueden ejecutar modelos de audio, moderación y embeddings, además de modelos de texto ([#201](https://github.com/phaseoteam/Phaseo/pull/201), [#157](https://github.com/phaseoteam/Phaseo/pull/157)).
- Foundry, un nuevo espacio para proyectos experimentales, se estrena con LLM Council, que envía una misma instrucción a varios modelos y combina sus respuestas en una sola ([#201](https://github.com/phaseoteam/Phaseo/pull/201)).

</div>

<div data-changelog-category="api">

<p className="changelog-category">API y SDK</p>

- Los SDK de Go, C#, Java, PHP y Ruby ya están disponibles junto a los de TypeScript y Python, todos en la versión `1.1.0` ([#203](https://github.com/phaseoteam/Phaseo/pull/203), [#201](https://github.com/phaseoteam/Phaseo/pull/201)).
- Los SDK `1.1.0` avisan cuando una solicitud usa un modelo obsoleto o retirado, y sus tipos de modelo y rutas coinciden con la API ([#201](https://github.com/phaseoteam/Phaseo/pull/201), [#203](https://github.com/phaseoteam/Phaseo/pull/203)).

</div>

<Update label="11 de marzo de 2026">

<div data-changelog-category="product">

<p className="changelog-category">Producto</p>

- **Settings -> Provisioning Keys** pasa a ser **Settings -> Management API Keys**, y la dirección anterior redirige a la nueva página ([#153](https://github.com/phaseoteam/Phaseo/pull/153)).
- La búsqueda del encabezado prioriza las coincidencias por nombre de modelo, así que al buscar `Grok 4.20` aparece Grok 4.20 en primer lugar ([#156](https://github.com/phaseoteam/Phaseo/pull/156)).
- Nueva guía: [SpaceXAI Grok 4.20](../model-migrations/xai-grok-4-20.mdx) explica los controles de esfuerzo de razonamiento y multiagente al adoptar Grok 4.20 ([#155](https://github.com/phaseoteam/Phaseo/pull/155)).

</div>

<Update label="2 de marzo de 2026">

<div data-changelog-category="api">

<p className="changelog-category">API y SDK</p>

- La API Responses acepta y devuelve el `phase` de los mensajes del asistente (`commentary` o `final_answer`), para que las solicitudes de varios turnos puedan reenviarlo; consulta [Crear una respuesta](../api-reference/endpoint/responses.mdx) ([#130](https://github.com/phaseoteam/Phaseo/pull/130)).
- Las solicitudes Responses a modelos de OpenAI aceptan `provider_options.openai.context_management` con `type: "compaction"` y un `compact_threshold` opcional; consulta [Parámetros](../api-reference/parameters.mdx) ([#130](https://github.com/phaseoteam/Phaseo/pull/130)).
- Las solicitudes a OpenAI que omiten `safety_identifier` ahora envían uno tomado de `user` o `user_id` o, si faltan, del ID de la solicitud ([#130](https://github.com/phaseoteam/Phaseo/pull/130)).

</div>
