<div data-changelog-category="api">

- La API de gestión añade `/v1/presets`, `/v1/settings`, `/v1/guardrails` y `/v1/management-keys`, y `GET /v1/me` devuelve el usuario y el espacio de trabajo de un token OAuth ([#562](https://github.com/phaseoteam/Phaseo/pull/562)).

<Update label="7 de junio de 2026">
