Abre un proveedor en [Proveedores de API](https://phaseo.app/api-providers) para ver qué modelos sirve a través de Phaseo y lo rápido que ha sido, o [compara proveedores](https://phaseo.app/api-providers/compare) en paralelo. Un proveedor de API aloja modelos detrás de una API; la [organización](./organisations.mdx) que creó un modelo suele ser otra empresa.

| | Organización | Proveedor de API |
| --- | --- | --- |
| **Qué hace** | Crea y entrena modelos | Aloja y sirve API de modelos |
| **Enfoque** | Investigación y calidad de los modelos | Fiabilidad, acceso, regiones y precios |
| **Modelos** | Normalmente, sus propias familias | A menudo, modelos de muchas organizaciones |

Muchas empresas son ambas cosas.

## Qué muestra la página de un proveedor

| Sección | Qué te indica |
| --- | --- |
| **Rendimiento** | Latencia y rendimiento por hora del tráfico de Gateway en los últimos siete días. |
| **Uso de tokens** | Los tokens que Phaseo ha enviado al proveedor a lo largo del tiempo. |
| **Modelos principales** y **Aplicaciones principales** | Los modelos y las aplicaciones públicas con más tráfico en este proveedor. |
| **Modelos** | Todos los modelos que sirve el proveedor, con pestañas para modelos de texto, imagen, audio, vídeo, embeddings y moderación. |

La página de cada modelo muestra después el precio, la longitud de contexto, el estado y la política de datos del proveedor para ese modelo; [Estados del proveedor](../guides/provider-statuses) explica los iconos de estado.

## Cómo usa el Gateway a los proveedores

Cuando un modelo tiene varios proveedores, el Gateway elige uno por solicitud y recurre a otro si falla. Envías un solo formato de solicitud y recibes una sola factura y un solo registro de uso, sea cual sea el proveedor que la atienda. Para que se facture a tu propia cuenta del proveedor, añade una clave de proveedor ([BYOK](../guides/routing-and-fallbacks#byok-considerations)).

[Enrutamiento y alternativas](../guides/routing-and-fallbacks) muestra cómo ordenar, fijar o excluir proveedores.

## Elige un proveedor

| Si te importa | Consulta |
| --- | --- |
| Un modelo concreto | La sección **Proveedores** de la página del modelo, o `GET /v1/models/{author}/{slug}/endpoints` |
| La latencia en tu región | La sección **Rendimiento** del proveedor y sus regiones en la página del modelo |
| El coste según tu volumen | La sección **Precios** del modelo y la [calculadora de precios](https://phaseo.app/tools/pricing-calculator) |
| Herramientas, streaming o salida estructurada | Los parámetros compatibles de la ruta en la página del modelo o en la API de endpoints |
| Tratamiento de datos y cumplimiento normativo | La política de datos y las ubicaciones de procesamiento de la ruta en la página del modelo |

[Precios y rendimiento](./pricing-performance.mdx) explica cómo interpretar las cifras de coste y velocidad.
