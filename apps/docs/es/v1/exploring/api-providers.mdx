Los proveedores de API son las plataformas que alojan y ofrecen API de modelos.

Las organizaciones de modelos entrenan modelos. Los proveedores ofrecen esos modelos mediante endpoints de producción, autenticación, controles de uso y herramientas operativas.

## Qué suele gestionar un proveedor de API

- Autenticación y gestión de claves
- Enrutamiento de solicitudes y gestión de disponibilidad
- Medición del uso y facturación
- API y experiencia de uso del SDK
- Alojamiento regional y controles de cumplimiento

## Proveedor y organización

| Aspecto | Organización | Proveedor de API |
| --- | --- | --- |
| Función principal | Crea y entrena modelos | Aloja y ofrece API de modelos |
| Enfoque | Investigación y calidad de modelos | Fiabilidad, acceso y operaciones |
| Distribución | Normalmente ofrece su propia familia de modelos | Puede ofrecer modelos de varias organizaciones |

Muchas empresas cumplen ambas funciones, según el producto.

## Phaseo Gateway como capa de proveedores

Phaseo Gateway unifica el acceso a numerosos proveedores.

Ventajas:

- Formato unificado de solicitudes y respuestas entre proveedores
- Enrutamiento y comportamiento alternativo según el proveedor
- Uso unificado del SDK para integraciones con varios proveedores
- Observabilidad centralizada del uso y los costes
- Compatibilidad opcional con BYOK para claves propias del proveedor

## Cómo elegir un proveedor

Al evaluar proveedores, ten en cuenta:

- Disponibilidad de los modelos para tu caso de uso
- Fiabilidad y latencia en la región objetivo
- Coste previsto con tu volumen de tráfico
- Compatibilidad de herramientas, streaming y salidas estructuradas
- Requisitos de cumplimiento y gestión de datos

## Preguntas de evaluación

- ¿Qué proveedores ofrecen la familia de modelos que necesito?
- ¿Qué proveedor ofrece menor latencia en mi región?
- ¿Cuál es la opción de menor coste para mi volumen de tokens?
- ¿Qué proveedor admite las funciones de endpoint que necesito?
