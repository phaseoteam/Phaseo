Abre una organización en [Organizaciones](https://phaseo.app/organisations) para ver todos los modelos que ha lanzado y cómo rinden en el Gateway. Cada modelo de Phaseo pertenece a una organización: la empresa o el laboratorio que lo desarrolla y lo mantiene.

## Qué muestra la página de una organización

La página tiene dos pestañas.

| Pestaña | Sección | Qué te indica |
| --- | --- | --- |
| **Resumen** | Acerca de | Nombre, descripción y país. |
| | Rendimiento | Latencia y rendimiento recientes en Gateway de los modelos de la organización. |
| | Modelos recientes | Lanzamientos recientes con disponibilidad, contexto, precios y uso. |
| | En la web | Enlaces al sitio web, GitHub, Hugging Face y redes sociales de la organización. |
| **Modelos** | | Todos los modelos que ha lanzado la organización, incluidos los archivados y obsoletos. |

## Organizaciones y proveedores de API

La organización crea el modelo; un [proveedor de API](./api-providers.mdx) lo sirve. Un mismo modelo suele tener varios proveedores.

| | Organización | Proveedor de API |
| --- | --- | --- |
| **Qué hace** | Entrena y mantiene el modelo. | Aloja el modelo detrás de una API. |
| **Ejemplo** | Anthropic creó los modelos Claude. | Anthropic, Amazon Bedrock y Google Vertex sirven modelos Claude. |

Algunas organizaciones, como OpenAI y Google, también son proveedores de sus propios modelos.

## Informa de una corrección

Abre un issue de GitHub con la página de la organización y una fuente oficial. Los responsables aplican en la base de datos los cambios aprobados. Consulta [Informar de una actualización de organización](../contributing/editing-an-organisation.mdx).
