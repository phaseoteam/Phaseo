Cada modelo de Phaseo está vinculado a una **organización**, la entidad responsable de desarrollarlo, entrenarlo y mantenerlo.
Las organizaciones forman la base del ecosistema de IA. Saber quién crea cada modelo te ayuda a entender su propósito, capacidades y fiabilidad.

---

## Qué incluye una página de organización

Cada página ofrece información general sobre una empresa o grupo de investigación, como:

| Sección | Descripción |
| --- | --- |
| **Resumen** | Datos básicos como el nombre, la descripción, el país, el año de fundación y el sitio web. |
| **Modelos publicados** | Todos los modelos que publicó la organización, incluidos los archivados o en desuso. |

---

## Tipos de organizaciones en Phaseo

| Tipo | Ejemplo | Descripción |
| --- | --- | --- |
| **Laboratorios de investigación** | OpenAI, Anthropic, DeepMind | Se centran en desarrollar e innovar con modelos de IA de vanguardia. |
| **Empresas tecnológicas** | Google, Meta, Microsoft | Despliegan infraestructura de IA a gran escala y aplicaciones para consumidores. |
| **Startups** | Mistral, Perplexity, Suno | Equipos pequeños que crean sistemas de IA especializados o eficientes. |
| **Comunidades de código abierto** | Hugging Face, Stability AI | Colaboraciones distribuidas que desarrollan modelos de forma transparente. |

---

## Proveedor y organización

Es importante distinguir entre **organizaciones** y **proveedores de API**:

| Aspecto | Organización | Proveedor de API |
| --- | --- | --- |
| **Definición** | Crea o mantiene el modelo. | Ofrece acceso por API al modelo. |
| **Ejemplo** | _Anthropic_ creó la serie Claude. | _Anthropic_, _AWS_ y _Google Vertex_ ofrecen acceso a modelos Claude. |
| **Enfoque** | Investigación, entrenamiento y arquitectura del modelo. | Alojamiento, enrutamiento, precios y experiencia de usuario. |

Algunas organizaciones, como OpenAI o Google, son tanto **desarrolladoras** como **proveedoras**. Otras se asocian con varias plataformas para distribuir sus modelos.

## Contribuir con datos de organizaciones

Si encuentras información sobre una organización que falta o está desactualizada, abre una incidencia en GitHub con la página afectada y fuentes oficiales. Los mantenedores aplican las correcciones aprobadas mediante el editor de la base de datos.
Tus contribuciones ayudan a mantener la precisión en toda la plataforma.
