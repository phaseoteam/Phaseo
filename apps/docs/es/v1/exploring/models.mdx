Phaseo mantiene un amplio catálogo abierto de modelos de texto, imagen, audio, vídeo, embeddings y otras modalidades de IA.

Cada página de modelo incluye información técnica y comercial detallada para ayudarte a evaluar, comparar y elegir el modelo adecuado.

<Info>
El catálogo es más amplio que Gateway. De forma predeterminada, la página Modelos muestra los modelos con una ruta activa en Gateway. Cambia el estado de Gateway solo si quieres consultar entradas del catálogo próximas o inactivas.
</Info>

---

## Qué encontrarás en una página de modelo

Todas las páginas de modelos de Phaseo incluyen estas secciones principales:

| Sección | Descripción |
| --- | --- |
| **Resumen** | Proveedor, fecha de lanzamiento, tipo de modelo (chat, código, embeddings, imagen, etc.) y una descripción breve. |
| **Familia** | Modelos relacionados y sus relaciones. |
| **Cronología** | Historial de lanzamientos y principales actualizaciones a lo largo del tiempo. |
| **Benchmarks** | Resultados de rendimiento en distintos benchmarks para comparar modelos similares. |
| **Disponibilidad** | Separa las rutas activas de Gateway de las que están por llegar, inactivas o asignadas externamente a un proveedor. |
| **Precios** | Precios detallados en USD, normalizados para que sea fácil compararlos y calcular el coste del modelo. |
| **Gateway** | Enlaces directos e inicios rápidos cuando existe una ruta pública de Gateway. |
| **Rendimiento** | Latencia, rendimiento y éxito observados en solicitudes enrutadas por Gateway, cuando hay datos suficientes. |

## Modelos del catálogo y modelos enrutables

Usa estos términos de forma coherente:

| Término | Significado |
| --- | --- |
| Modelo del catálogo | Phaseo registra metadatos del modelo. Puede que no exista una ruta pública. |
| Modelo enrutable | Hay al menos una ruta de proveedor activa en Phaseo Gateway. |
| Asignación externa | Phaseo registra una oferta del proveedor que Gateway no ejecuta. |

Para consultar modelos mediante la API, `GET /v1/models` devuelve solo los modelos enrutables de forma predeterminada. Usa `availability=all` para consultar el catálogo completo.

## Buscar modelos por criterios

Usa filtros y etiquetas en la interfaz de Phaseo para encontrar modelos que se ajusten a tus necesidades:

- **Por proveedor:** `Mostrar todos los modelos de Anthropic`.
- **Por capacidad:** `Listar modelos compatibles con respuestas estructuradas en JSON`.
- **Por benchmark:** `Los 10 modelos mejor puntuados en GPQA`.
- **Por precio:** `Modelos que cuestan menos de 0,01 USD por 1.000 tokens`.
- **Por fecha de lanzamiento:** `Modelos publicados recientemente`.

Puedes combinar los filtros para encontrar exactamente lo que necesitas.
