Abre la lista de [Modelos](https://phaseo.app/models) para encontrar modelos de texto, imagen, audio, vídeo, embeddings y otros tipos, y después abre un modelo para ver sus proveedores, precios, rendimiento y puntuaciones en benchmarks.

![Página de un modelo en Phaseo](/images/gemini-3-page.png)

## Modelos del catálogo y modelos que se pueden llamar

El catálogo es más amplio que el Gateway. Por defecto, la lista de Modelos solo muestra los modelos **Activo en Gateway**. Cambia el filtro **Estado de Gateway** a **Próximamente** o **Inactivo** para ver el resto.

| Término | Significado |
| --- | --- |
| Modelo del catálogo | Phaseo registra los metadatos del modelo. Puede que no tenga ninguna ruta a la que puedas llamar. |
| Modelo enrutable | Al menos una ruta de proveedor está activa ahora en el Gateway de Phaseo. |
| Asignación externa | Phaseo muestra una oferta de un proveedor que el Gateway no ejecuta. |

`GET /v1/models` devuelve solo los modelos enrutables. Añade `availability=all` para incluir el resto.

## Filtra y ordena la lista

| Control | Opciones |
| --- | --- |
| Estado de Gateway | Activo en Gateway (predeterminado), Próximamente, Inactivo |
| Endpoints | Los endpoints de la API que admite un modelo, como generación de texto o embeddings |
| Modalidades de entrada y salida | Texto, imagen, audio, vídeo y otras |
| Funciones | Capacidades como la llamada a herramientas o el razonamiento |
| Año | Año de lanzamiento |
| Orden | Más recientes, más populares (tokens en 7 días), precio, longitud de contexto, rendimiento, latencia |

Para ver todos los modelos de un laboratorio, abre su [página de organización](./organisations.mdx).

## Qué muestra la página de un modelo

| Sección | Qué te indica |
| --- | --- |
| **Proveedores** | Cada ruta de proveedor con su estado, longitud de contexto, precio, disponibilidad y política de datos. [Estados del proveedor](../guides/provider-statuses) explica los iconos. |
| **Rendimiento** | Latencia y rendimiento medidos en el tráfico de Gateway, cuando hay datos suficientes. |
| **Precios** | Cada medidor en USD: entrada, salida, entrada en caché y unidades multimedia. |
| **Evaluaciones comparativas** | Puntuaciones en cada benchmark, con sus fuentes. |
| **Actividad** | Uso de tokens en Gateway a lo largo del tiempo. |
| **Aplicaciones** | Aplicaciones públicas que usan el modelo. |
| **Disponibilidad** | Disponibilidad de las rutas en los últimos días. |
| **Verificación** | Comprobaciones de procedencia del contenido, para modelos de imagen y vídeo. |
| **Acerca de** | Fechas de lanzamiento, licencia, enlaces y familia. |
| **Suscripciones** | Planes de suscripción de proveedores que incluyen el modelo. |
| **FAQ** | Preguntas frecuentes sobre el modelo. |

Una sección solo aparece cuando hay datos para ella. Los modelos con una ruta activa también muestran un inicio rápido con el ID del modelo que debes enviar.

## Compara modelos

[Comparar](https://phaseo.app/compare) muestra modelos en paralelo por precio, puntuaciones en benchmarks, contexto y funciones. [Precios y rendimiento](./pricing-performance.mdx) explica cómo interpretar las cifras de coste y velocidad.

## Informa de una corrección

Abre un issue de GitHub con la página del modelo y una fuente oficial. Los responsables aplican en la base de datos las actualizaciones aprobadas. Consulta [Informar de una actualización de modelo](../contributing/editing-a-model.mdx).
