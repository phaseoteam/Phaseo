Crea un agente de TypeScript que busca en la web a través de Phaseo antes de responder y devuelve un informe de investigación como JSON estricto con sus fuentes. Al terminar tendrás un script que imprime un objeto `{ topic, summary, sources }` validado para cualquier tema que le des.

El script está listo para producción en investigaciones de una sola llamada. Los resultados de búsqueda son contenido web no fiable: la comprobación de esquema de abajo detiene la salida mal formada, pero revisa las fuentes antes de actuar en función de ellas. Hay una versión empaquetada en `packages/sdk/agent-sdk-ts/examples/research-brief-agent.ts`.

<Step title="Escribe el agente">

```ts research-agent.ts
import { z } from "zod";
import { createAgent, createGatewayAgentClient } from "@phaseo/agent-sdk";

// Lo bastante pequeño para leerlo en una línea de registro.
const ResearchBrief = z
  .object({
    topic: z.string(),
    summary: z.string().min(1),
    sources: z.array(z.object({ title: z.string(), url: z.string().url() }).strict()).min(1),
  })
  .strict();
type ResearchBrief = z.infer<typeof ResearchBrief>;

const researchBriefAgent = createAgent<string, ResearchBrief>({
  id: "research-brief-agent",
  model: "openai/gpt-6-astra",
  instructions:
    "Research the user's topic with web search and return a concise JSON brief with cited sources.",
  maxSteps: 4,
  parseOutput: (text) => JSON.parse(text),
  outputSchema: ResearchBrief,
});

const client = createGatewayAgentClient({
  clientOptions: { apiKey: process.env.PHASEO_API_KEY! },
  // El JSON Schema que el Gateway pide al modelo.
  responseFormat: {
    type: "json_schema",
    name: "research_brief",
    schema: {
      type: "object",
      properties: {
        topic: { type: "string" },
        summary: { type: "string" },
        sources: {
          type: "array",
          items: {
            type: "object",
            properties: { title: { type: "string" }, url: { type: "string" } },
            required: ["title", "url"],
            additionalProperties: false,
          },
          minItems: 1,
        },
      },
      required: ["topic", "summary", "sources"],
      additionalProperties: false,
    },
  },
  // Repara el JSON casi válido.
  plugins: [{ id: "response-healing" }],
  // Phaseo ejecuta la búsqueda; el modelo escribe las consultas.
  gatewayTools: [{ type: "phaseo:web_search", parameters: { max_results: 5 } }],
  // Busca siempre antes de responder.
  toolChoice: "phaseo:web_search",
  webSearchOptions: { search_context_size: "high" },
});

const result = await researchBriefAgent.run({
  input: "Summarize the latest browser automation support patterns for coding agents.",
  client,
  onEvent(event) {
    console.log(event.type, event.runId);
  },
});

console.log(result.output);
```

| Opción del cliente | Qué hace |
| --- | --- |
| `responseFormat` | Mantiene explícito el esquema de salida |
| `plugins` | [Reparación de respuestas](./response-healing-for-structured-json) para JSON casi válido |
| `gatewayTools` | Añade `phaseo:web_search`; la [guía de búsqueda web](../guides/server-tools/web-search) enumera sus parámetros |
| `toolChoice` | Fuerza la búsqueda en un flujo que siempre debe fundamentarse |
| `webSearchOptions` | Ajustes de búsqueda para los motores que dimensionan sus resultados |

## Comprueba que funciona

El script imprime un informe con al menos una URL de fuente. Después abre la solicitud en **Ajustes → Uso → Registros** y comprueba que:

- **Supervisión de la búsqueda web** muestra las búsquedas gestionadas, los resultados y las citas.
- El registro de plugins muestra `response-healing` como `applied` solo cuando el JSON necesitó reparación.
- La respuesta coincidió con el esquema; si no, la ejecución habría fallado con un `AgentSchemaValidationError`.

[Depurar la búsqueda web](./web-search-debugging) cubre los casos en los que no se ejecutó ninguna búsqueda.

## Cuándo usar otra cosa

Este patrón encaja en investigaciones de una sola llamada en las que el modelo debe fundamentarse por sí mismo y quien llama quiere JSON tipado. Usa [`phaseo:web_fetch`](./tool-grounding-with-web-fetch) cuando ya conozcas las URL, un [agente con herramientas locales](./agent-sdk-durable-loop) cuando el trabajo necesite tus propios datos más que la web, y salida de texto simple cuando el contrato sea tan flexible que un esquema añada más trabajo del que ahorra.
