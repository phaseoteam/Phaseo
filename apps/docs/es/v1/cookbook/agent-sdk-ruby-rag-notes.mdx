Ejecuta un agente de Ruby que consulta una nota interna con una herramienta local y responde en un párrafo breve, sin ceder la orquestación a otro sistema. Al terminar tendrás un script que resume tu nota sobre los presets.

La herramienta devuelve datos de ejemplo fijos, así que el script es ilustrativo; sustitúyela por una consulta a tu propio almacén de notas. Encaja en una aplicación Ruby que ya es dueña de los datos y tiene entradas de herramientas sencillas y deterministas.

## Créalo

<Steps>
<Step title="Instala">

```bash
gem install phaseo_agent_sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

O añade `gem "phaseo_agent_sdk"` a tu `Gemfile`. Instala `phaseo_sdk` junto con él y necesita Ruby 3.2 o posterior. Consulta [Instalación del Agent SDK de Ruby](../sdk-reference/agent/installation).

</Step>
<Step title="Escribe el agente">

```ruby notes.rb
require "phaseo_agent_sdk"

TOPICS = %w[presets routing guardrails].freeze

lookup_note = PhaseoAgentSdk.define_tool(
  PhaseoAgentSdk::Tool.new(
    id: "lookup-note",
    description: "Look up one internal note by topic.",
    parameters: {
      type: "object",
      properties: { topic: { type: "string", enum: TOPICS } },
      required: ["topic"],
      additionalProperties: false
    },
    # Los argumentos vienen del modelo: solo los temas conocidos llegan a execute.
    input_schema: lambda do |input|
      raise ArgumentError, "topic must be one of #{TOPICS.join(', ')}" unless input.is_a?(Hash) && TOPICS.include?(input["topic"])

      input
    end,
    execute: lambda do |input, _context|
      {
        topic: input["topic"],
        summary: "Presets centralize routing defaults so app code stays smaller."
      }
    end
  )
)

agent = PhaseoAgentSdk.create_agent(
  id: "notes-agent",
  model: "openai/gpt-6-astra",
  instructions: "Use tools when helpful and answer in one short paragraph.",
  tools: [lookup_note],
  max_steps: 4
)

# Lee PHASEO_API_KEY del entorno.
result = agent.run(
  input: "Summarize our note about presets.",
  client: PhaseoAgentSdk.create_gateway_agent_client
)

puts result.run.status
puts result.output
```

</Step>
<Step title="Ejecútalo">

```bash
ruby notes.rb
```

</Step>
</Steps>

## Comprueba que funciona

- El script imprime `completed` y después un párrafo sobre los presets.
- En **Ajustes → Uso → Registros**, el primer turno del modelo muestra una llamada a `lookup-note` con `{"topic": "presets"}`.

## Antes de pasar a producción

Mantén la herramienta en solo lectura y `max_steps` tan bajo como permita el trabajo (el valor predeterminado es `12`). Si tu almacén de notas es grande, devuelve solo el fragmento que coincide en lugar de documentos completos, para que cada turno del modelo siga siendo pequeño. Para guardar ejecuciones y reanudarlas más tarde, consulta el [bucle duradero](./agent-sdk-durable-loop); la opción `state:` del SDK de Ruby funciona igual. La [referencia del Agent SDK de Ruby](../sdk-reference/agent/usage) explica el estado, la aprobación y el streaming.
