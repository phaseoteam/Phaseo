Ejecuta un agente de PHP que carga un borrador del CMS con una herramienta local y sugiere un cambio editorial, dentro de la aplicación o el backend de administración que ya gestiona el contenido. Al terminar tendrás un script que imprime una sugerencia de titular para el borrador de la página de inicio.

La herramienta devuelve datos de ejemplo fijos, así que el script es ilustrativo; sustitúyela por tu consulta al CMS. Encaja en una aplicación PHP en la que basten una o dos herramientas locales.

## Créalo

<Steps>
<Step title="Instala">

```bash
composer require phaseo/agent-sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

`phaseo/agent-sdk` instala `phaseo/sdk` junto con él y necesita PHP 8.1 o posterior. Consulta [Instalación del Agent SDK de PHP](../sdk-reference/agent/installation).

</Step>
<Step title="Escribe el agente">

```php review.php
<?php
require 'vendor/autoload.php';

use Phaseo\AgentSdk\AgentDefinition;
use Phaseo\AgentSdk\AgentSdk;
use Phaseo\AgentSdk\Tool;

const ALLOWED_SLUGS = ['homepage', 'pricing', 'about'];

$loadDraft = AgentSdk::defineTool(new Tool(
    id: 'load-draft',
    description: 'Load one CMS draft by slug.',
    parameters: [
        'type' => 'object',
        'properties' => [
            'slug' => ['type' => 'string', 'enum' => ALLOWED_SLUGS],
        ],
        'required' => ['slug'],
        'additionalProperties' => false,
    ],
    // Los argumentos vienen del modelo: solo los slugs conocidos llegan a execute.
    inputSchema: static function (mixed $input): array {
        if (!is_array($input) || !in_array($input['slug'] ?? null, ALLOWED_SLUGS, true)) {
            throw new InvalidArgumentException('slug must be one of ' . implode(', ', ALLOWED_SLUGS));
        }
        return $input;
    },
    execute: static fn (array $input, $context) => [
        'slug' => $input['slug'],
        'headline' => 'Phaseo makes gateway routing visible.',
    ],
));

$agent = AgentSdk::createAgent(new AgentDefinition(
    id: 'content-review-agent',
    model: 'openai/gpt-6-astra',
    instructions: 'Use tools when helpful and return concise editorial feedback.',
    tools: [$loadDraft],
    maxSteps: 4,
));

// Lee PHASEO_API_KEY del entorno.
$result = $agent->run(
    input: 'Review the homepage draft and suggest one headline improvement.',
    client: AgentSdk::createGatewayAgentClient(),
);

echo $result->run->status . PHP_EOL;
echo $result->output . PHP_EOL;
```

</Step>
<Step title="Ejecútalo">

```bash
php review.php
```

</Step>
</Steps>

## Comprueba que funciona

- El script imprime `completed` y después una sugerencia de titular.
- En **Ajustes → Uso → Registros**, el primer turno del modelo muestra una llamada a `load-draft` con `{"slug": "homepage"}`.
- Sin `PHASEO_API_KEY`, `createGatewayAgentClient()` lanza `PHASEO_API_KEY is required`.

## Antes de pasar a producción

Mantén la herramienta en solo lectura. Si añades una que publica o edita contenido, pon `requireApproval: true` en ella para que la ejecución se detenga a esperar a un editor. Para obtener los comentarios como JSON que tu CMS pueda guardar, pide un esquema y repara la salida casi válida con la [reparación de respuestas](./response-healing-for-structured-json). La [referencia del Agent SDK de PHP](../sdk-reference/agent/usage) explica el estado, la aprobación y el streaming.
