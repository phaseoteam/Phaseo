Dale al modelo `phaseo:web_fetch` y una URL que ya conoces, y Phaseo obtendrá la página, la recortará a un tamaño máximo y devolverá el texto antes de que el modelo lo extraiga, resuma o clasifique. Al terminar tendrás una solicitud que lee una sola página y devuelve campos de ella, y podrás confirmar en el registro qué página leyó realmente.

La solicitud está lista para producción con el límite de dominio que se muestra. Las páginas obtenidas son entrada no fiable: el modelo puede ver instrucciones en ellas, así que valida lo que devuelve. Usa la [búsqueda web](../guides/server-tools/web-search) cuando no conozcas la URL.

## Envía una solicitud fundamentada

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
    "tools": [
      {
        "type": "phaseo:web_fetch",
        "parameters": {
          "allowed_domains": ["phaseo.app"],
          "max_chars": 8000,
          "max_uses": 1
        }
      }
    ],
    "tool_choice": "phaseo:web_fetch"
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-6-astra",
  input:
    "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
  tools: [
    {
      type: "phaseo:web_fetch",
      parameters: {
        allowed_domains: ["phaseo.app"],
        max_chars: 8000,
        max_uses: 1,
      },
    },
  ],
  tool_choice: "phaseo:web_fetch",
});

console.log(JSON.stringify(response.output, null, 2));
console.log(response.usage?.server_tool_use);
```
</CodeGroup>

Deja claro en el prompt qué hay que hacer después de obtener la página: extraer estos campos, resumir esta sección, clasificar el documento o comprobar una afirmación.

| Parámetro | Valor predeterminado | Uso |
| --- | --- | --- |
| `allowed_domains` | Ninguno | Obtiene páginas solo de estos dominios. El modelo puede reducir la lista, nunca ampliarla. |
| `max_chars` | `12000` | Caracteres de texto de la página que se devuelven, hasta `100000`. Más bajo para un título o un resumen, más alto para extraer campos. |
| `max_uses` | `10` | Llamadas de obtención por solicitud, hasta `100`. |

La [guía de web fetch](../guides/server-tools/web-fetch#parameters) lista el resto, incluidos `blocked_domains` y los motores.

## Comprueba qué leyó

El resultado de la herramienta, que aparece en el registro de la solicitud, indica exactamente en qué página se basó el modelo:

```json
{
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "truncated": false,
  "returned_chars": 8000
}
```

Comprueba `final_url` después de las redirecciones y `truncated` antes de dar por hecho que el modelo vio la página completa. Cada obtención suma 1 a `usage.server_tool_use.web_fetch_requests`.

## Conoce los límites

Con el motor `direct` predeterminado, Phaseo obtiene la página por sí mismo y reduce el HTML a texto sin formato. Rechaza `localhost` y las direcciones privadas, sigue como máximo 5 redirecciones y comprueba cada redirección con tus listas de dominios; una redirección fuera de ellas devuelve `redirect_blocked_by_domain_policy` al modelo.

Web fetch sirve para páginas HTML, texto sin formato y respuestas JSON o XML pequeñas. No sirve para archivos binarios, para rastrear muchas páginas ni para comprobar cómo se renderiza una página con JavaScript; para eso, usa un flujo con navegador. Si la página es muy grande, acota la tarea de extracción en lugar de subir `max_chars`.

Empieza con un preajuste o un endpoint, lee en los registros los detalles de la obtención y el recorte, y ajusta el prompt si el texto obtenido es demasiado amplio antes de extender su uso.
