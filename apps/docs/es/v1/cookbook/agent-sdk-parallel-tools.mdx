---
title: "Ejecutar herramientas locales del agente en paralelo"
icon: "network"
description: "Usa concurrencia acotada de herramientas locales en el Agent SDK de TypeScript para que un turno del modelo reúna contexto independiente sin ejecutar cada llamada a herramienta en serie."
---

Configura `toolExecution.toolConcurrency` para que el Agent SDK de TypeScript ejecute a la vez varias llamadas a herramientas independientes de un mismo turno del modelo, en lugar de una tras otra. Al terminar tendrás un agente que reúne en paralelo contexto de documentación, estado e incidentes, y aun así registra los resultados en el orden en que el modelo los pidió.

Las herramientas devuelven datos de ejemplo fijos, así que el script es ilustrativo; sustitúyelas por tus propias consultas de solo lectura. Hay una versión empaquetada en `packages/sdk/agent-sdk-ts/examples/parallel-tool-agent.ts`.

## Créalo

<Steps>
<Step title="Instala">

```bash
npm install @phaseo/agent-sdk zod
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="Escribe el agente">

```ts parallel-agent.ts
import { z } from "zod";
import { createAgent, createGatewayAgentClient, defineTool } from "@phaseo/agent-sdk";

const fetchDocs = defineTool({
  id: "fetch-docs",
  description: "Return a short summary of one Phaseo docs page by slug.",
  parameters: {
    type: "object",
    properties: { slug: { type: "string" } },
    required: ["slug"],
    additionalProperties: false,
  },
  inputSchema: z.object({ slug: z.string().regex(/^[a-z0-9/-]{1,80}$/) }).strict(),
  parallelSafe: true,
  timeoutMs: 5_000,
  async execute({ slug }) {
    return { slug, summary: `Docs summary for ${slug}` };
  },
});

const fetchStatus = defineTool({
  id: "fetch-status",
  description: "Return the status of one Phaseo component.",
  parameters: {
    type: "object",
    properties: { component: { type: "string", enum: ["gateway", "dashboard", "async-jobs"] } },
    required: ["component"],
    additionalProperties: false,
  },
  inputSchema: z.object({ component: z.enum(["gateway", "dashboard", "async-jobs"]) }).strict(),
  parallelSafe: true,
  timeoutMs: 5_000,
  async execute({ component }) {
    return { component, status: "operational" };
  },
});

const fetchIncidents = defineTool({
  id: "fetch-incidents",
  description: "Return the open incident count for one service.",
  parameters: {
    type: "object",
    properties: { service: { type: "string", enum: ["gateway", "dashboard", "async-jobs"] } },
    required: ["service"],
    additionalProperties: false,
  },
  inputSchema: z.object({ service: z.enum(["gateway", "dashboard", "async-jobs"]) }).strict(),
  parallelSafe: true,
  timeoutMs: 5_000,
  async execute({ service }) {
    return { service, openIncidents: 0 };
  },
});

const agent = createAgent({
  id: "parallel-tool-agent",
  model: "openai/gpt-6-astra",
  instructions:
    "Use the available tools to gather context, then return one concise operational summary.",
  tools: [fetchDocs, fetchStatus, fetchIncidents],
  toolExecution: { toolConcurrency: 3 },
  maxSteps: 4,
});

const result = await agent.run({
  input:
    "Fetch the presets docs, the gateway status, and the async-jobs incident digest, then summarize the current state.",
  client: createGatewayAgentClient({
    clientOptions: { apiKey: process.env.PHASEO_API_KEY! },
    parallelToolCalls: true,
  }),
  onEvent(event) {
    if (event.type === "tool.started" || event.type === "tool.completed") {
      console.log(event.type, event.toolName, event.timestamp);
    }
  },
});

console.log(result.output);
```

</Step>

## Comprueba que funciona

- Cuando el modelo pide las tres herramientas en un mismo turno, las tres líneas `tool.started` se imprimen antes que las líneas `tool.completed` correspondientes, con marcas de tiempo cercanas.
- `result.messages` enumera los resultados de las herramientas en el orden de las llamadas del modelo, sea cual sea el orden en que terminaron.
- La ejecución termina con un único resumen en `result.output`.

## Qué se ejecuta a la vez

| Ajuste | Efecto |
| --- | --- |
| `toolExecution.toolConcurrency` | Se ejecutan a la vez hasta este número de llamadas a herramientas de un mismo turno. Valor predeterminado: `1`. |
| `parallelSafe: true` en todas las herramientas del turno | Se ejecutan a la vez hasta 8, o `toolConcurrency` si es mayor. Úsalo solo con herramientas de solo lectura. |
| `timeoutMs` en una herramienta | Esa llamada falla pasado este tiempo, así que una dependencia bloqueada no puede ocupar todos los huecos. |
| `parallelToolCalls` en el cliente del gateway | Permite que el modelo pida varias llamadas a herramientas en un turno; que lo haga depende del modelo. |

`tool.started` y `tool.completed` se siguen emitiendo para cada llamada, y la ejecución guarda un punto de control cuando termina la fase de herramientas.

## Mantenlo seguro

Usa la concurrencia solo con herramientas que no dependan de la salida de las demás ni modifiquen estado compartido. Empieza con `2` o `3`, mantén las herramientas idempotentes y con pocos efectos secundarios, y valida cada argumento con `inputSchema` como arriba. Añade un accesor `state`, como en el [bucle duradero](./agent-sdk-durable-loop), solo cuando necesites reanudar ejecuciones. Antes de confiar en ello, ejecuta tus pruebas que cubren turnos con varias herramientas y comprueba el orden de los resultados.
