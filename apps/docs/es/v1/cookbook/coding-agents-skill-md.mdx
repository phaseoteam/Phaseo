Añade un `SKILL.md` a tu repositorio para que los agentes de programación llamen a Phaseo como espera tu proyecto: la misma URL base, la misma variable de la clave, el mismo endpoint, los modelos aprobados y el mismo registro. Al terminar tendrás instaladas las skills públicas de Phaseo, una skill del proyecto encima de ellas y un módulo de cliente compartido al que apunta la skill.

La skill y el módulo de abajo están listos para producción en cuanto sustituyas los IDs de modelo y los nombres de preajuste por los tuyos.

<Steps>
<Step title="Instala las skills públicas de Phaseo">

<Visibility for="humans">
Las skills públicas cubren el Gateway, los SDKs, los preajustes, el enrutamiento y las migraciones. Instálalas desde [`phaseo.app/docs`](https://phaseo.app/docs/.well-known/agent-skills/index.json):
</Visibility>

<Visibility for="agents">
Instala las skills públicas de Phaseo desde [`phaseo.app/docs`](https://phaseo.app/docs/.well-known/agent-skills/index.json) antes de escribir instrucciones locales del proyecto:
</Visibility>

```bash
npx skills add https://phaseo.app/docs --agent codex --skill '*'
```

Cambia `--agent` por el agente que usa tu equipo. Deja en tu propio `SKILL.md` solo las reglas específicas del proyecto.

</Step>
<Step title="Instala el SDK">

<CodeGroup>
```bash npm
npm install @phaseo/sdk
```

```bash pnpm
pnpm add @phaseo/sdk
```

```bash yarn
yarn add @phaseo/sdk
```

```bash bun
bun add @phaseo/sdk
```

```bash Python
pip install phaseo
```
</CodeGroup>

</Step>
<Step title="Añade un cliente compartido">

Los agentes reutilizan un helper pequeño y evidente con más fiabilidad que un wrapper grande. Pon el cliente en un módulo e impórtalo en todas partes:

```ts src/lib/phaseo.ts
import Phaseo from "@phaseo/sdk";

export const gateway = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY!,
});
```

Mantén una sola ruta de llamada por cada superficie que uses, como generación de texto, embeddings, generación de imágenes o vídeo asíncrono.

</Step>
<Step title="Escribe la skill del proyecto">

Crea `SKILL.md` en la raíz del repositorio o en la carpeta de skills que lee tu agente (por ejemplo, `.agents/skills/phaseo-project/SKILL.md`). El agente lee el `name` y la `description` del frontmatter para decidir cuándo cargar la skill:

```md SKILL.md
---
name: phaseo-project
description: "How this repository calls Phaseo Gateway: client module, endpoint, approved models and presets, logging and async jobs. Use when adding or changing any Phaseo call in this repo."
---

# Phaseo in this repository

- Import the client from `src/lib/phaseo.ts`. Never create another one.
- The base URL is `https://api.phaseo.app/v1`. The key is in `PHASEO_API_KEY`; never hard-code it or send it to the browser.
- Use the Responses API (`POST /v1/responses`) for new text features.
- Approved models: `openai/gpt-6-astra` for drafts, `anthropic/claude-sonnet-5.5` for reviews. Ask before adding another.
- Prefer the `@support-triage` preset for support features; pass it as `model`.
- Log the response `id` and `model` on every call, and `generation_id` from error bodies.
- For async video jobs, store the returned ID and poll status until it is terminal.
- Validate any model-generated tool arguments before acting on them.
```

</Step>
</Steps>

## Comprueba que ha funcionado

Pide a tu agente que añada una pequeña función de Phaseo, como "resume un ticket con Phaseo". El cambio debería importar `src/lib/phaseo.ts`, leer `PHASEO_API_KEY`, usar un modelo o preajuste aprobado y registrar el ID de la respuesta. Si no lo hace, lo más probable es que la `description` de la skill no coincida con la petición: nombra las palabras que usa tu equipo para esa tarea.

## Qué poner en la skill

Responde a las preguntas que más tiempo le cuestan a un agente, y a nada más:

| Pregunta | Respuesta de ejemplo |
| --- | --- |
| ¿Qué familia de endpoints? | Responses para texto, Embeddings para búsqueda |
| ¿Dónde están las credenciales? | `PHASEO_API_KEY`, solo en el servidor |
| ¿Qué IDs de modelo o preajustes están aprobados? | Una lista corta, con el formato `org/model` |
| ¿Qué se registra? | El `id` de la respuesta, `model` y `generation_id` en los errores |
| ¿Cómo se siguen los trabajos asíncronos? | Guarda el ID y consulta el estado hasta que sea final |

[Codex](../guides/integrations/codex), el [Vercel AI SDK](../guides/integrations/ai-sdk) y [Ejemplos](../guides/examples) muestran las mismas convenciones en cada herramienta.
