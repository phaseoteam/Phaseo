Usa esta página cuando quieras dar a un agente de programación un prompt concreto para crear una aplicación pequeña y funcional, en lugar de un plan de integración impreciso.

<Tip>
Estos prompts se centran en los resultados y especifican la implementación para funcionar mejor en Cursor, Claude Code, Codex y herramientas similares.
</Tip>

## Cómo usar estos prompts

<Steps>
  <Step title="Elige la superficie de integración">
    Elige el prompt que corresponda a cómo quieres que la aplicación invoque Phaseo:

    - HTTP directo
    - un SDK oficial
    - Vercel AI SDK
    - SDK de agentes
  </Step>
  <Step title="Sustituye las variables entre corchetes">
    Antes de pegar el prompt en el agente de programación, completa valores como `[IDEA DE LA APLICACIÓN]`, `[MARCO DE TRABAJO]`, `[MODELO]` y `[LANGUAGE]`.
  </Step>
  <Step title="Pide verificaciones, no solo código">
    Mantén las líneas de verificación en el prompt. Así, el agente tendrá que indicar qué ejecutó realmente, qué supuso y qué queda por configurar manualmente.
  </Step>
</Steps>

## Cómo mejorar estos prompts

- Sustituye `[IDEA DE LA APLICACIÓN]` por una tarea concreta y acotada del usuario, no por una descripción general del producto.
- Sustituye `[MODELO]` por el ID exacto del modelo que quieres que use el agente.
- Indica si la salida debe ser texto libre, JSON estricto, chat o un único recurso generado.
- Si los conoces, menciona el framework de interfaz y el destino del despliegue.
- Añade una o dos restricciones importantes, como `solo proveedores de la UE`, `usar streaming` o `mantener todos los secretos en el servidor`.
