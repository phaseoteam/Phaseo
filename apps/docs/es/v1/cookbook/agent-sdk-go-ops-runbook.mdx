Ejecuta un agente de Go que responde a una pregunta operativa llamando a una herramienta local de estado, dentro de un único servicio y sin un sistema de trabajos. Al terminar tendrás un `main.go` que imprime una respuesta breve sobre la latencia actual de los proveedores.

La herramienta devuelve datos de ejemplo fijos, así que el programa es ilustrativo; sustitúyela por tu propia llamada de estado o métricas. Encaja en un servicio de Go cuyo contexto ya existe como llamadas locales o internas.

## Créalo

<Steps>
<Step title="Instala">

```bash
go mod init ops-runbook
go get github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go@latest
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

El módulo principal `sdk-go/v4` se instala con él. Consulta los requisitos en [Instalación del Agent SDK de Go](../sdk-reference/agent/installation).

</Step>
<Step title="Escribe el agente">

```go main.go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  statusTool := phaseoagent.DefineTool(phaseoagent.Tool{
    ID:          "read-status",
    Description: "Read the current service status page summary.",
    Parameters: map[string]any{
      "type":                 "object",
      "properties":           map[string]any{},
      "additionalProperties": false,
    },
    Execute: func(input any, ctx phaseoagent.RuntimeContext) (any, error) {
      return map[string]any{
        "status":  "degraded",
        "summary": "Latency is elevated on one provider route.",
      }, nil
    },
  })

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "ops-runbook-agent",
    Model:        "openai/gpt-6-astra",
    Instructions: "Use tools when helpful and answer briefly.",
    Tools:        []phaseoagent.Tool{statusTool},
    MaxSteps:     4,
  })

  // Lee PHASEO_API_KEY (y PHASEO_BASE_URL si está definida).
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "What is happening with provider latency right now?",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Run.Status)
  fmt.Println(result.Output)
}
```

</Step>
<Step title="Ejecútalo">

```bash
go run .
```

</Step>
</Steps>

## Comprueba que funciona

- El programa imprime `completed` y después una respuesta que menciona la latencia degradada en una ruta de proveedor.
- En **Ajustes → Uso → Registros**, el primer turno del modelo muestra una llamada a la herramienta `read-status`.
- Sin `PHASEO_API_KEY`, `CreateGatewayAgentClient` devuelve `PHASEO_API_KEY is required`.

## Antes de pasar a producción

En el SDK de Go, `MaxSteps` vale `8` de forma predeterminada; ajústalo al número más pequeño que complete el trabajo. Cuando una herramienta reciba argumentos, dale un esquema `Parameters` y un validador `InputSchema` que devuelva un error ante cualquier cosa inesperada, porque los argumentos vienen del modelo. Mantén las herramientas en solo lectura salvo que una persona apruebe la llamada (`RequireApproval: true`). La [referencia del Agent SDK de Go](../sdk-reference/agent/usage) explica las aprobaciones, el estado y el streaming, y [grounding con web fetch](./tool-grounding-with-web-fetch) muestra cómo leer una página conocida en lugar de usar una herramienta local.
