Envía `"model": "phaseo/free"` y Phaseo ejecuta tu solicitud en un modelo gratuito disponible que la admita, sin gastar créditos. Al terminar tendrás una solicitud que funciona en el lenguaje que elijas y sabrás qué modelo la respondió.

Esta forma de solicitud está lista para producción en prototipos, demos y tráfico de bajo riesgo. Los modelos gratuitos no garantizan latencia, estilo de salida ni un proveedor fijo.

## Envía la solicitud

<Steps>

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

<Step title="Envía una solicitud">

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```

```go Go
package main

import (
  "context"
  "fmt"
  "os"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4"
)

func main() {
  client := phaseo.New(os.Getenv("PHASEO_API_KEY"), "https://api.phaseo.app/v1")

  temperature := 0.2
  response, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
    Model:       "phaseo/free",
    Input:       "Summarize why provider-aware free routing helps prototypes.",
    Temperature: &temperature,
  })
  if err != nil {
    panic(err)
  }

  fmt.Printf("%+v\n", response)
}
```

## Cómo se elige un modelo gratuito

1. Tu solicitud va al alias compartido `phaseo/free`.
2. Phaseo se queda con los modelos gratuitos que pueden atender esta solicitud (endpoint, parámetros, herramientas).
3. Envía la solicitud a uno de ellos.

Por defecto, los modelos gratuitos comparten una cuota de 1.500 solicitudes por usuario y día UTC. Cuando la superas, las solicitudes devuelven `429` con el código `phaseo_free_model_limit_exceeded` hasta las 00:00 UTC; consulta [Límites del Gateway](../api-reference/limits#gateway-limits).

## Deja el enrutador gratuito

Si ningún modelo gratuito admite una función que necesitas, como herramientas o un JSON Schema, cambia a un modelo de pago concreto en lugar de reintentar la misma solicitud. Pasa a un modelo fijo cuando necesites una latencia, un estilo de salida o una elección de proveedor predecibles, y pon los ajustes compartidos en un [preajuste](../guides/presets) para que todos los servicios envíen la misma solicitud. [Enrutamiento y alternativas](../guides/routing-and-fallbacks) explica cómo eligen proveedor las solicitudes de pago, y [Errores de la API](../api-reference/errors) lista los códigos de error.
