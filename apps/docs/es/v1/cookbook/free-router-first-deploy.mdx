Usa esta guía para poner en marcha tu primera integración con Phaseo sin elegir todavía un modelo de pago.

En lugar de elegir tú un modelo gratuito, envía las solicitudes a `phaseo/free`. Phaseo seleccionará un modelo gratuito disponible que admita la solicitud.
## Ejemplo de solicitud
<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```

## Qué ocurre en segundo plano

1. La solicitud se envía al alias compartido `phaseo/free`.
2. Phaseo comprueba qué modelos gratuitos pueden atenderla.
3. Selecciona un modelo gratuito disponible y lo usa para generar la respuesta.
4. Los detalles de la solicitud muestran el modelo exacto que se ejecutó para que puedas inspeccionarlo o depurarlo más tarde.

## Después de la primera solicitud

- En **Gateway -> Uso**, abre los detalles de la solicitud y confirma qué modelo se utilizó.
- Si una política del espacio de trabajo bloquea la solicitud, revisa los detalles para ver qué ajuste la detuvo.
- Si ningún modelo gratuito admite la función que necesitas, cambia de `phaseo/free` a un modelo de pago específico en lugar de repetir la solicitud.

## Notas para producción

- Reserva `phaseo/free` para prototipos, demostraciones y tráfico de bajo riesgo.
- Si necesitas latencia, estilo de salida o proveedor predecibles, cambia a un modelo específico cuando sepas cuál funciona mejor.
- Si necesitas un comportamiento estable de los prompts entre servicios, combina esta guía con [Presets](../guides/presets.mdx).
