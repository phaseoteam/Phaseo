Usa esta receta cuando el modelo no cambie, pero quieras que el gateway ordene de otra manera las ofertas de proveedores para una solicitud.

## Objetivo

- Prioriza el proveedor más barato para una solicitud.
- Prioriza el proveedor con menor latencia para flujos interactivos.
- Prioriza el proveedor con mayor rendimiento para la generación por lotes.

## 1. Añade `provider.sort` a la solicitud

En las solicitudes de texto, define el orden deseado directamente en el objeto `provider`.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemini-3.1-flash-lite",
    "input": "Give me one release-note bullet for the last deploy.",
    "provider": {
      "sort": "price"
    }
  }'
```

Los criterios de ordenamiento disponibles para este flujo son:

- `price`
- `latency`
- `throughput`

## 2. Elige el criterio de ordenamiento adecuado para la carga de trabajo

Usa:

- `price` cuando el coste importa más que la latencia de cola
- `latency` para chat, copilotos y herramientas con intervención humana
- `throughput` para generación de alto volumen o procesos de recuperación

## 3. Entiende qué compara el gateway

Cuando envías un criterio explícito de ordenamiento por solicitud, el gateway clasifica los candidatos de forma determinista en vez de usar la aleatoriedad ponderada equilibrada habitual.

Para modelos de texto:

- `price` compara una base de precios común entre los proveedores aptos
- si existen medidores de texto compartidos, el gateway prefiere los que coinciden en `input_text_tokens` y `output_text_tokens`
- `latency` usa los datos de latencia más recientes de los proveedores
- `throughput` usa las mediciones de rendimiento más recientes

## 4. Mantén realista el conjunto de proveedores

El ordenamiento funciona mejor cuando primero limitas el conjunto de candidatos si es necesario.

Por ejemplo, ordena únicamente un conjunto aprobado de proveedores:

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
```

## 5. Verifica el resultado ordenado

Al depurar, inspecciona la solicitud en **Gateway -> Uso** y busca:

- proveedores considerados
- proveedores ordenados
- los factores de puntuación del enrutamiento relacionados con precio, latencia o rendimiento

Así puedes confirmar fácilmente si el gateway ordenó los resultados como esperabas.
