---
title: "Fija o ignora proveedores por solicitud"
icon: "pin"
description: "Usa los controles de proveedor a nivel de solicitud para preferir un orden de proveedores, restringir el grupo o descartar un proveedor."
---

Añade un objeto `provider` a una solicitud para cambiar qué proveedores la atienden, sin tocar los valores predeterminados del espacio de trabajo ni los preajustes. Al terminar podrás preferir un orden, mantener una solicitud dentro de una lista permitida u omitir un proveedor, y ver en la respuesta qué proveedor contestó.

Estas formas de solicitud están listas para producción. Los slugs de proveedor son ejemplos reales; consulta la página del modelo para ver qué proveedores lo sirven.

| Campo | Qué hace | Ejemplo |
| --- | --- | --- |
| `order` | Prueba primero estos proveedores y después el resto del grupo elegible | `["anthropic-us", "anthropic"]` |
| `only` | Mantiene la solicitud dentro de esta lista | `["openai", "openai-eu"]` |
| `ignore` | Quita estos proveedores para esta solicitud | `["novita"]` |
| `sort` | Clasifica lo que queda por `price`, `latency` o `throughput` | `"price"` |

Para usar exactamente un proveedor y desactivar la alternativa entre proveedores, ponlo delante del ID del modelo: consulta [Fija un proveedor](../guides/routing-and-fallbacks#pin-one-provider).

## Prueba los proveedores en un orden fijo

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "input": "Write a concise launch summary.",
    "provider": {
      "order": ["anthropic-us", "anthropic"]
    },
    "meta": true
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "anthropic/claude-sonnet-5.5",
  input: "Write a concise launch summary.",
  provider: {
    order: ["anthropic-us", "anthropic"],
  },
  meta: true,
});

console.log(response.meta?.routing); // { selected_provider: "anthropic-us", ... }
```

```python Python
import os

from phaseo import Phaseo

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])

response = client.generate_response(
    {
        "model": "anthropic/claude-sonnet-5.5",
        "input": "Write a concise launch summary.",
        "provider": {
            "order": ["anthropic-us", "anthropic"],
        },
        "meta": True,
    }
)

print(response["meta"]["routing"]["selected_provider"])
```
</CodeGroup>

`meta: true` añade `meta.routing.selected_provider` a la respuesta, así que puedes comprobar el resultado sin abrir los registros.

## Mantén una solicitud dentro de una lista permitida

Envía `only` y, si quieres, `sort` para clasificar dentro de esa lista:

```json
{
  "model": "openai/gpt-5.6-luna",
  "input": "Extract the action items.",
  "provider": {
    "only": ["openai", "openai-eu"],
    "sort": "price"
  }
}
```

Si ninguno de los proveedores de la lista sirve el modelo, la solicitud falla en lugar de salir de la lista.

## Omite un proveedor

Envía `ignore` cuando un proveedor esté degradado o mientras pruebas otra ruta:

```json
{
  "model": "meta/llama-4-maverick",
  "input": "Summarize the transcript.",
  "provider": {
    "ignore": ["novita"]
  }
}
```

## Combínalos

Usa `only` para el grupo, `order` para la preferencia dentro de él y `sort` para el resto. Esto mantiene una solicitud en Google Vertex, prueba primero la región de la UE y después clasifica por latencia:

```json
{
  "model": "anthropic/claude-sonnet-5.5",
  "input": "Summarize the incident in one sentence.",
  "provider": {
    "only": ["google-vertex", "google-vertex-eu"],
    "order": ["google-vertex-eu"],
    "sort": "latency"
  }
}
```

## Comprueba adónde fue

Abre la solicitud en **Configuración → Uso → Registros** y despliega **Observabilidad de enrutamiento**. Muestra los proveedores que se excluyeron antes de la clasificación y por qué, y los candidatos clasificados con sus puntuaciones; [Explica una decisión de enrutamiento](../guides/routing-and-fallbacks#explain-a-routing-decision) describe cada campo.

Usa reglas a nivel de solicitud para cambios temporales, propios de un llamante o ligados a un flujo de usuario. Cuando las mismas reglas aparezcan en varios servicios, pásalas a un [preajuste](../guides/presets), donde además limitan qué proveedores puede usar una alternativa. Para comparar clasificaciones, consulta [Ordena proveedores](./sort-providers-by-price-latency-or-throughput).
