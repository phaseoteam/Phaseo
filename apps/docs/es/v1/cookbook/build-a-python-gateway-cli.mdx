Ejecuta una CLI de Python hecha solo con la biblioteca estándar que llama a los endpoints de Phaseo, un comando cada vez. Al terminar tendrás `python quickstart.py <command>` funcionando para estado, modelos, Responses y Chat Completions, además de comandos para embeddings, moderación, imágenes, OCR, vídeo y música que puedes copiar en un worker o un backend.

La CLI es ilustrativa: es una referencia de la forma de las solicitudes, no una herramienta empaquetada. Varios de los IDs de modelo predeterminados de los comandos multimedia ya no se sirven, así que pasa `--model` en esos casos (consulta [Elige modelos para los comandos multimedia](#pick-models-for-the-media-commands)).

Para que un agente de programación cree una CLI parecida desde cero, pega este prompt:

## Qué hace la CLI

El ejemplo es [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart): un solo archivo, `quickstart.py`, que usa solo `urllib`, `json` y `argparse`.

| Comando | Llamadas |
| --- | --- |
| `smoke` | `GET /v1/health`, `GET /v1/models`, `GET /v1/providers` y un `POST /v1/responses` |
| `health`, `models`, `providers` | La ruta `GET` correspondiente |
| `responses --prompt` | `POST /v1/responses` |
| `chat --prompt` | `POST /v1/chat/completions` |
| `embeddings --text` | `POST /v1/embeddings` |
| `moderations --text` | `POST /v1/moderations` |
| `image --prompt` | `POST /v1/images/generations` |
| `ocr --image-url` | `POST /v1/ocr` |
| `video-create`, `video-status`, `video-cancel`, `video-download-url` | `POST /v1/videos`, `GET /v1/videos/{video_id}`, `POST /v1/videos/{video_id}/cancel`, `POST /v1/videos/{video_id}/download_url` |
| `music-create`, `music-status` | `POST /v1/music/generate`, `GET /v1/music/generate/{music_id}` |

Cada solicitud se reintenta dos veces ante `429`, `5xx` y errores de red, con esperas de 1 s y después 2 s, y agota el tiempo de espera a los 45 segundos. Cada comando termina con `1` cuando la llamada no devuelve `2xx`, así que puedes usarlo en scripts.

## Ejecútalo

Necesitas Python 3 y una clave de API de Phaseo.

<Steps>
<Step title="Crea .env.local">

El script lee `.env.local` desde la carpeta en la que lo ejecutas. El ejemplo no incluye `.env.example`, así que crea el archivo:

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# Optional
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My Python CLI
PHASEO_HTTP_REFERER=https://myapp.example
```

Las variables que ya están definidas en tu shell tienen prioridad sobre el archivo. Sin `PHASEO_MODEL`, los comandos de texto usan `openai/gpt-5.6-sol`.

</Step>
<Step title="Ejecuta la comprobación rápida">

```bash
cd examples/gateway-python-quickstart
python quickstart.py smoke
```

`smoke` también envía una solicitud corta a Responses, así que consume algunos créditos.

</Step>
<Step title="Envía una solicitud">

```bash
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

</Step>
</Steps>

## Comprueba que ha funcionado

- `smoke` imprime `HTTP 200` en todos los bloques y termina con `0`.
- La salida del comando `responses` contiene `integration_ok`.
- `--help` lista los comandos sin hacer ninguna solicitud.
- Sin clave, el script imprime `Missing PHASEO_API_KEY` y termina con `1`.
- Las solicitudes aparecen en **Configuración → Uso → Registros**.

## Elige modelos para los comandos multimedia

Estos valores predeterminados de `quickstart.py` están retirados o no tienen ningún proveedor activo. Pasa un modelo actual con `--model` y elígelo en la [página de modelos](https://phaseo.app/models) o con `python quickstart.py models`:

| Comando | Valor predeterminado del ejemplo | Estado |
| --- | --- | --- |
| `moderations` | `openai/omni-moderation-latest` | No es un ID del catálogo; usa `openai/omni-moderation` |
| `ocr` | `mistral/mistral-ocr` | Retirado; prueba `mistral/ocr-4.1` |
| `video-create` | `openai/sora-2` | Retirado |
| `music-create` | `suno/suno-v4` | Sin proveedor activo |

Los valores predeterminados de `embeddings` (`google/gemini-embedding-2`) e `image` (`openai/gpt-image-2`) sí se sirven. Los trabajos de vídeo y música son asíncronos: guarda el ID devuelto y consulta el comando de estado; [Vídeo asíncrono y lotes](../guides/async-video-and-batch) explica el ciclo de vida de los trabajos.

Reduce el archivo a los comandos que necesita tu servicio, conserva el único helper compartido `gateway_request()` y pasa al [SDK de Python](../sdk-reference/client/overview) cuando quieras solicitudes tipadas.
