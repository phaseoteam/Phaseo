Llama a modelos de muchos proveedores mediante una sola API en `https://api.phaseo.app/v1`, elige cómo se enruta cada solicitud y sigue el uso y el coste de cada una. Esta solicitud usa `phaseo/free`, así que funciona antes de que añadas créditos:

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "phaseo/free", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // reads PHASEO_API_KEY

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # reads PHASEO_API_KEY

response = client.responses.create({"model": "phaseo/free", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

¿Aún no tienes una clave de API? [Crea una en el panel](https://phaseo.app/settings/keys) y luego sigue la [guía de inicio rápido](./quickstart.mdx).

## Elige un modelo

[Explora modelos](https://phaseo.app/models) o [compáralos](https://phaseo.app/compare). El catálogo también incluye modelos a los que aún no puedes llamar, así que comprueba que un modelo esté **Activo en Gateway** antes de integrarlo, o lista los modelos disponibles con `GET /v1/models`. Consulta [Cómo funciona Phaseo](./developers/introduction.mdx) para conocer los modelos, los proveedores y la facturación.

## Crea con un agente de IA

<Prompt description="Dale a tu agente de programación (Cursor, Claude Code, Codex y otros) todo lo que necesita para añadir Phaseo a tu proyecto." icon="bot" actions={["copy", "cursor"]}>
{`Add Phaseo Gateway to this project.

1. Install the Phaseo skills: npx skills add https://phaseo.app/docs
2. If your tools support MCP, connect the Phaseo docs server at https://phaseo.app/docs/mcp and look up endpoints and SDK usage there instead of guessing.
3. Inspect the current AI provider setup and propose the smallest change that sends requests to https://api.phaseo.app/v1 with a server-side PHASEO_API_KEY.
4. Use the official SDK for this language if there is one (@phaseo/sdk for TypeScript, phaseo for Python). Otherwise call the REST API.
5. Check model IDs with GET /v1/models instead of inventing them. Use phaseo/free for a first test if no paid model has been chosen.
6. Explain which files you will change and how you will verify the change before you edit. Never print or commit API keys.`}
</Prompt>

Los agentes también pueden buscar en esta documentación con [Docs MCP](./guides/integrations/docs-mcp.mdx), leer el [resumen de capacidades](https://phaseo.app/docs/skill.md) o empezar por [llms.txt](https://phaseo.app/docs/llms.txt).
