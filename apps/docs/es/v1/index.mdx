## Elige un modelo

[Explora modelos](https://phaseo.app/models) o [compáralos](https://phaseo.app/compare). El catálogo puede incluir modelos sin rutas disponibles; comprueba la disponibilidad en el Gateway antes de integrarlos. Consulta [Cómo funciona Phaseo](./developers/introduction.mdx) para conocer modelos, proveedores y facturación.

Para acceder a la documentación desde un asistente, conecta [Docs MCP](./guides/integrations/docs-mcp.mdx) o lee el [resumen de capacidades para agentes](https://phaseo.app/docs/skill.md).
