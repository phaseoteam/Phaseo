Usa esta página si sabes qué quieres crear, pero no qué página de la documentación de Phaseo deberías abrir primero.

Phaseo ofrece una sola API para acceder a modelos, enrutar solicitudes a proveedores, consultar precios, hacer seguimiento del uso y ejecutar flujos de IA asíncronos.

Si acabas de llegar a Phaseo, empieza con una solicitud que funcione. Si ya tienes una integración de IA, ve directamente a la guía de migración o del SDK que corresponda a tu aplicación.

## Tu primera solicitud correcta

Para una integración nueva, sigue estos pasos:

1. Crea una clave de API en el panel de control.
2. Envía una solicitud a un modelo de texto actual.
3. Lee el texto generado en la respuesta.
4. Continúa con la guía de SDK, enrutamiento o producción que necesites.

## Primera solicitud

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-sol",
    "input": "Reply with: docs ready",
    "temperature": 0
  }'
```

```typescript TypeScript SDK
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-5.6-sol",
  input: "Reply with: docs ready",
  temperature: 0,
});

console.log(response.output_text);
```

```python Python SDK
from phaseo import Phaseo

client = Phaseo(api_key="YOUR_API_KEY")

response = client.generate_response(
    {
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with: docs ready",
        "temperature": 0,
    }
)

print(response.get("output_text"))
```
</CodeGroup>

Si funciona, continúa con la [Guía de inicio rápido](./quickstart.mdx) para completar el recorrido de tu primera solicitud.
