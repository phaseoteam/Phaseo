---

Aceptamos contribuciones de proveedores, investigadores y usuarios avanzados. Sigue este proceso para que podamos revisar tu envío rápidamente.

---

## 1. Preparar los datos

- Confirma que el benchmark exista en `/data/benchmarks`. Si no existe, abre un issue para proponerlo.
- Recopila los resultados sin procesar, incluidos el formato de los prompts, el sistema de evaluación y los detalles del hardware.
- Cuando exista, incluye una cita pública (entrada de blog, artículo o repositorio del conjunto de datos).

> ✅ **Consejo**
> Compartir un script o notebook reproducible agiliza mucho la verificación.

---

## 2. Forkear el repositorio

1. Haz un fork de [github.com/phaseoteam/data](https://github.com/phaseoteam/data).
2. Crea una rama nueva (por ejemplo, `add-claude-3.5-sonnet-mmlu`).
3. Actualiza el JSON del benchmark correspondiente con tus puntuaciones y metadatos.

---

## 3. Ejecutar la validación

Usa las herramientas del repositorio para verificar la estructura y los rangos:

```bash
pnpm install
pnpm run validate:benchmarks
```

Corrige cualquier problema que se informe antes de enviar tu pull request.

---

## 4. Abrir un pull request

Incluye lo siguiente en la descripción del PR:

- Nombre del benchmark y partición (por ejemplo, `GSM8K test`).
- ID del modelo y proveedor.
- Enlaces a las citas o los registros de evaluación.
- Resumen de cómo se obtuvo la puntuación.

El equipo de mantenimiento revisará el envío, pedirá aclaraciones si hace falta y lo combinará cuando esté aprobado.

---

## 5. Seguir la publicación

Después de combinar el PR, la puntuación aparecerá en la próxima sincronización de datos programada. Puedes seguir el progreso en el canal #data-updates de Discord o en el registro de cambios público.

---
