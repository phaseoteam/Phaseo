## Datos de benchmarks

Phaseo **no ejecuta benchmarks**. Mostramos y normalizamos puntuaciones publicadas por autores de benchmarks y proveedores de modelos.

Cuando uses resultados de benchmarks consultados mediante Phaseo:

1. Cita el benchmark original y el artículo como fuente principal.
2. Puedes mencionar Phaseo como el sitio donde consultaste o comparaste las puntuaciones.
3. Incluye:

- Nombre del benchmark y partición (por ejemplo, `MMLU test`).
- Identificador del modelo y proveedor.
- URL de la página o API correspondiente de Phaseo.
- Fecha de consulta.

Ejemplo de texto:

> Las puntuaciones del benchmark se consultaron en Phaseo (partición MMLU test) el 3 de marzo de 2025. Modelo: `openai-gpt-4o`; proveedor: OpenAI.
