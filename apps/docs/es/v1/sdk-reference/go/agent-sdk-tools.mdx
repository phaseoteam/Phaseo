Crea valores `Tool` y pásalos mediante `DefineTool(...)`. Las herramientas pueden incluir:

- JSON `Parameters` que se muestran al modelo
- validadores `InputSchema`, `OutputSchema` y `EventSchema`
- un `Timeout` y una función `Execute(input, RuntimeContext)`
- `RequireApproval` incondicional o un predicado condicional `Approval`
- `OnToolCalled` y `OnResponseReceived` para trabajo interactivo
- anulaciones `NextTurn` y `OnError: "return-to-model"`

Usa `RuntimeContext.EmitProgress`, `SetContext` y el contexto `context.Context` proporcionado. `ToolExecutionConfig{Concurrency: ...}` ejecuta herramientas independientes en paralelo y conserva el orden de los resultados.
