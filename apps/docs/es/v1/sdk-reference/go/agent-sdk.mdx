## Preparar el runtime

El Agent SDK aún no tiene una versión pública del módulo Go. Sigue las [instrucciones de instalación desde el código fuente](./agent-sdk-installation.mdx).

## Inicio rápido

```go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "quickstart-agent",
    Model:        "openai/gpt-5.4-nano",
    Instructions: "Answer concisely and helpfully.",
  })

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "Give me one fun fact about cURL.",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Output)
}
```

## Qué incluye

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- un bucle de herramientas con límites mediante la API `responses` de Phaseo

## Runtime avanzado

Go admite validadores y aprobaciones, herramientas HITL y manuales, progreso, errores recuperables, canales reproducibles, ayudantes de detención, turnos dinámicos, `NextTurnParams` persistentes, uso y costo normalizados, y `StateAccessor`.

## Streaming y cancelación

`Agent.Stream(...)` y `Agent.ContinueStream(...)` consumen el flujo SSE de Responses del gateway. Lee `Text()` o `Events()` varias veces si distintos consumidores necesitan reproducirlo y llama a `Cancel()` para cancelar el contexto de solicitud. Los pasos completados conservan los ID de solicitud, los metadatos del proveedor, los motivos de finalización, las advertencias, el uso y el costo.
