Define herramientas con el helper `tool()` de AI SDK, pásalas a `generateText` y define `stopWhen` para que el modelo pueda responder después de que se ejecute la herramienta.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, stepCountIs, tool } from "ai";
import { z } from "zod";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "What is 17 + 25? Use the calculator tool.",
  tools: {
    calculator: tool({
      description: "Perform basic arithmetic",
      inputSchema: z.object({
        operation: z.enum(["add", "subtract", "multiply", "divide"]),
        a: z.number(),
        b: z.number(),
      }),
      execute: async ({ operation, a, b }) => {
        if (operation === "add") return a + b;
        if (operation === "subtract") return a - b;
        if (operation === "multiply") return a * b;
        return a / b;
      },
    }),
  },
  stopWhen: stepCountIs(2),
});

console.log(result.text);
```

De forma predeterminada, `generateText` se detiene después de un paso. Si ese paso es una llamada a herramienta, `result.text` está vacío y el resultado de la herramienta está en `result.toolResults`. `stepCountIs(2)` da al modelo un segundo paso para responder con el resultado.

## Escribir herramientas seguras

- Mantén las descripciones precisas y los esquemas de entrada estrictos; el modelo rellena los argumentos.
- Trata los argumentos como entrada no fiable. Valídalos dentro de `execute` antes de cualquier efecto secundario.
- Añade reintentos y espera progresiva dentro de `execute` para las API externas que fallan de forma transitoria.
