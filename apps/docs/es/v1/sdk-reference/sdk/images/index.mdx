Pasa `phaseo.imageModel(modelId)` a `generateImage`. Las solicitudes van al endpoint `/v1/images/generations` del Gateway.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateImage } from "ai";

const result = await generateImage({
  model: phaseo.imageModel("openai/gpt-image-1"),
  prompt: "A minimalist poster of a lighthouse at dawn.",
  size: "1024x1024",
});

console.log(result.images[0].mediaType);
console.log(result.images[0].uint8Array.length);
console.log(result.providerMetadata);
```

## Leer el resultado

Las imágenes que el Gateway devuelve como URL se convierten al formato de archivo de AI SDK, así que lee `uint8Array` y `mediaType` en cada imagen, sea cual sea lo que devolvió el proveedor.

- Los valores de `size` disponibles dependen del modelo.
- Para reproducir una imagen más adelante, guarda el prompt, el modelo y los parámetros junto con los metadatos de la imagen.
