Pasa `phaseo.transcriptionModel(modelId)` a `transcribe` para convertir voz en texto, y `phaseo.speechModel(modelId)` a `generateSpeech` para convertir texto en voz. El proveedor sube el audio a `/v1/audio/transcriptions` como formulario multipart y envía las solicitudes de voz a `/v1/audio/speech`.

```ts
import { readFileSync, writeFileSync } from "node:fs";
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateSpeech, transcribe } from "ai";

const transcription = await transcribe({
  model: phaseo.transcriptionModel("openai/whisper-1"),
  audio: readFileSync("./audio.mp3"),
});

console.log(transcription.text);
console.log(transcription.providerMetadata);

const speech = await generateSpeech({
  model: phaseo.speechModel("openai/gpt-4o-mini-tts"),
  text: "Hello from Phaseo audio.",
  voice: "alloy",
  outputFormat: "mp3",
});

writeFileSync("./speech.mp3", Buffer.from(speech.audio.uint8Array));
console.log(speech.providerMetadata);
```

`audio` acepta un `Buffer`, `Uint8Array`, `ArrayBuffer`, una cadena base64 o una `URL`. AI SDK 7 sigue exportando los nombres anteriores `experimental_transcribe` y `experimental_generateSpeech` como alias.

## Gestionar audio largo o que falla

- Los formatos de entrada y salida compatibles dependen del modelo.
- Aumenta los tiempos de espera para archivos largos y mantén las subidas dentro del límite de tamaño del modelo (25 MB en la mayoría de los modelos).
- Reintenta con espera progresiva las respuestas transitorias `429` y `5xx`.
