Llama a `generateText` con `phaseo(modelId)` para obtener una respuesta completa.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a concise summary of Phaseo Gateway.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

## Enviar el historial del chat

Usa `prompt` para un solo turno y `messages` cuando necesites varios turnos o un rol de sistema.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "system", content: "You are a terse assistant." },
    { role: "user", content: "Give me three bullet points on retrieval augmentation." },
  ],
});

console.log(result.text);
console.log(result.providerMetadata);
```

## Definir valores predeterminados en el modelo

Pasa los ajustes como segundo argumento de `phaseo()`. Se aplican a todas las llamadas que usan esa instancia del modelo.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra", {
    maxTokens: 300,
  }),
  prompt: "Draft a release note for an API update.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

Los IDs de modelo tienen la forma `provider/model`. Para mantenerlos al día, léelos de `/v1/models`; consulta [Descubrimiento de modelos](/es/v1/sdk-reference/sdk/get-models).
