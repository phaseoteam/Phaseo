El proveedor de AI SDK no tiene un helper `listModels()`. Lee los IDs de modelo actuales de `GET /v1/models`, directamente o con el SDK de TypeScript, y pásalos a `phaseo(modelId)`.

## Obtenerlos desde la API del Gateway

```ts
const response = await fetch("https://api.phaseo.app/v1/models", {
  method: "GET",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
  },
});

const filteredResponse = await fetch(
  "https://api.phaseo.app/v1/models?provider=anthropic&status=active,deprecated&availability=all",
  {
    headers: {
      Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    },
  },
);

if (!response.ok || !filteredResponse.ok) {
  throw new Error("Failed to load models");
}

const models = await response.json();
const filteredModels = await filteredResponse.json();
console.log(models, filteredModels);
```

`/v1/models` acepta filtros como `provider`, `status`, `organisation`, `endpoints` y `availability`. El [endpoint Models](/es/v1/api-reference/endpoint/models) los enumera todos.

## Obtenerlos con el SDK de TypeScript

```ts
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });
const models = await client.getModels({
  provider: ["anthropic"],
  status: ["active", "deprecated"],
  availability: "all",
});

console.log(models);
```

## Usar un ID descubierto

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Hello from a discovered model ID.",
});

console.log(result.text);
```

Los IDs de modelo tienen la forma `provider/model`. Vuelve a consultar la lista periódicamente para recoger los cambios de enrutamiento y las retiradas, en lugar de fijar los IDs en el código a largo plazo.
