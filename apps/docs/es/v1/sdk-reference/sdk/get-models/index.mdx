description: "Cómo obtener IDs de modelos actuales para usarlos con el proveedor de AI SDK."
---

El proveedor de Vercel AI SDK no incluye un método `listModels()` integrado. Usa uno de estos patrones para mantener actualizados los IDs de modelos.

## Opción 1: obtenerlos de la API Gateway

```ts
const response = await fetch("https://api.phaseo.app/v1/models", {
  method: "GET",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
  },
});

const filteredResponse = await fetch(
  "https://api.phaseo.app/v1/models?provider=anthropic&status=active,deprecated&availability=all",
  {
    headers: {
      Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    },
  },
);

if (!response.ok || !filteredResponse.ok) {
  throw new Error("Failed to load models");
}

const models = await response.json();
const filteredModels = await filteredResponse.json();
console.log(models, filteredModels);
```

## Opción 2: usar el SDK oficial de TypeScript

```ts
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });
const models = await client.getModels({
  provider: ["anthropic"],
  status: ["active", "deprecated"],
  availability: "all",
});

console.log(models);
```

## Usar los IDs descubiertos con AI SDK

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-5-nano"),
  prompt: "Hello from a discovered model ID.",
});

console.log(result.text);
```

## Notas

- Los IDs de modelos usan el formato `provider/model`.
- `/v1/models` admite filtros como `provider`, `status`, `organisation`, `endpoints` y `availability`.
- Vuelve a comprobar periódicamente la disponibilidad de los modelos para detectar cambios de enrutamiento y obsolescencia.
- Es preferible seleccionar los IDs de `/v1/models` en lugar de fijarlos a largo plazo.
