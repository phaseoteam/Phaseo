Llama a `streamText` con `phaseo(modelId)` y lee `textStream` para recibir el texto a medida que llega. `streamText` devuelve el control de inmediato; lee `providerMetadata` cuando termine el stream.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Transmitir a partir del historial del chat

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## Detener un stream abandonado

Pasa un `abortSignal` a `streamText` y cancélalo cuando el usuario se vaya o se agote un tiempo de espera, para que la solicitud no siga en marcha:

```ts
const controller = new AbortController();
setTimeout(() => controller.abort(), 60_000);

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a long report.",
  abortSignal: controller.signal,
});
```

Lee los IDs de modelo de `/v1/models` en lugar de fijarlos en el código; consulta [Descubrimiento de modelos](/es/v1/sdk-reference/sdk/get-models).
