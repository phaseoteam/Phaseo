title: "Transmisión de texto (AI SDK)"
description: "Genera texto en streaming con Vercel AI SDK y Phaseo."
---

Usa `streamText` cuando quieras recibir tokens parciales a medida que llegan.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Transmisión con mensajes

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## Consejos para producción

- Prefiere el streaming para respuestas largas y interfaces interactivas.
- Gestiona la cancelación y los tiempos de espera en tu runtime para las transmisiones abandonadas.
- Mantén actualizados los ID de modelo mediante `/v1/models` para evitar alias obsoletos.
