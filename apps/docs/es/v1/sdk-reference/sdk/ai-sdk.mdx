Instala `@phaseo/ai-sdk-provider` y pasa `phaseo(modelId)` como `model` a `generateText`, `streamText` o cualquier otra función de Vercel AI SDK 7. Las solicitudes de texto van al endpoint `/v1/chat/completions` del Gateway.

## Instalar

<CodeGroup>

```bash title="npm"
npm install @phaseo/ai-sdk-provider
```

```bash title="pnpm"
pnpm add @phaseo/ai-sdk-provider
```

```bash title="yarn"
yarn add @phaseo/ai-sdk-provider
```

```bash title="bun"
bun add @phaseo/ai-sdk-provider
```

</CodeGroup>

El paquete sin versión instala la etiqueta `latest` de npm, que corresponde a la línea de AI SDK 7. Declara `ai@^7` como dependencia peer, así que los gestores de paquetes que instalan peers automáticamente la añaden por ti.

Define `PHASEO_API_KEY` en el entorno de tu servidor y haz tu primera solicitud. La exportación predeterminada `phaseo` lanza un error si `PHASEO_API_KEY` no está definida.

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Reply with: AI SDK works",
});

console.log(result.text);
console.log(result.providerMetadata);
```

Usa un ID de modelo actual del [endpoint Models](../../api-reference/endpoint/models.mdx).

## Transmitir texto en streaming

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Stream a short greeting.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Configurar una instancia del proveedor

Llama a `createPhaseo()` para definir `apiKey`, `baseURL`, `headers` o un `fetch` personalizado. Úsalo para identificar tu aplicación en los detalles de las solicitudes de Phaseo:

```typescript
import { createPhaseo } from "@phaseo/ai-sdk-provider";

const phaseo = createPhaseo({
  apiKey: process.env.PHASEO_API_KEY,
  headers: {
    "x-title": "My App",
    "http-referer": "https://example.com",
  },
});
```

`PHASEO_BASE_URL` es opcional y su valor predeterminado es `https://api.phaseo.app/v1`.

## Elegir un tipo de modelo

| Método del proveedor | Función de AI SDK |
| --- | --- |
| `phaseo(modelId)` o `phaseo.languageModel(modelId)` | `generateText`, `streamText` |
| `phaseo.embeddingModel(modelId)` (alias `textEmbeddingModel`) | `embed`, `embedMany` |
| `phaseo.imageModel(modelId)` | `generateImage` |
| `phaseo.transcriptionModel(modelId)` | `transcribe` |
| `phaseo.speechModel(modelId)` | `generateSpeech` |
| `phaseo.rerankingModel(modelId)` | `rerank` |

Todos los métodos excepto `rerankingModel` aceptan como segundo argumento ajustes opcionales por modelo: `temperature`, `topP`, `topK`, `maxTokens`, `frequencyPenalty`, `presencePenalty`, `seed`, `user`, `headers` y `fetch`.

## Funciones de AI SDK 7 compatibles

- Generación de texto y streaming
- Salida y ajustes de razonamiento
- Herramientas de función y entradas de herramientas en streaming
- Salida JSON y JSON Schema
- Entradas de texto y de archivos de imagen
- Fuentes de citas por URL
- Embeddings y generación de imágenes
- Reranking
- Transcripción y generación de voz
- Metadatos del proveedor, uso, señales de cancelación y fragmentos de stream sin procesar

Lo que puede hacer una llamada sigue dependiendo del modelo y del proveedor. El proveedor no anuncia referencias a archivos gestionados, skills ni herramientas ejecutadas por el proveedor (sus definiciones, resultados o respuestas de aprobación). Las herramientas de función que ejecuta tu aplicación usan el flujo normal de ejecución y aprobación de AI SDK.

## Usar una versión anterior de AI SDK

| AI SDK | Instalación |
| --- | --- |
| 7 | `@phaseo/ai-sdk-provider` (`latest`) |
| 6 | `@phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `@phaseo/ai-sdk-provider@ai-sdk-v5` |

Si la instalación automática de peers está desactivada, instala tú mismo la versión mayor de `ai` correspondiente (`ai@^7`, `ai@^6` o `ai@^5`).
