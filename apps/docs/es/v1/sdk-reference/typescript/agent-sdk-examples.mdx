Elige el ejemplo más sencillo que se ajuste al producto que estás creando. Cada patrón deja la persistencia y la interfaz de usuario en tu aplicación y usa Phaseo para los turnos del modelo.

## Ejemplos incluidos en el paquete

| Ejemplo | Uso |
| --- | --- |
| `research-brief-agent.ts` | Investigar con búsqueda administrada y un resumen final tipado |
| `support-triage-agent.ts` | Enrutar y clasificar solicitudes de soporte con un preset administrado |
| `coding-review-agent.ts` | Revisar código con herramientas locales de ejecución |
| `parallel-tool-agent.ts` | Ejecutar herramientas locales independientes en paralelo |
