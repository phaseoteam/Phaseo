description: "Llama a /moderations con el SDK de TypeScript."
---

**Método**: `client.generateModeration()`.

### Ejemplo
```typescript
const moderation = await client.generateModeration({
  model: "openai/omni-moderation-latest",
  input: "Text to classify",
});
```

### Parámetros clave
- `model` (obligatorio): ID del modelo de moderación (p. ej., `openai/omni-moderation-latest`).
- `input` (obligatorio): cadena o matriz de elementos de contenido (texto o `image_url`).
- Opcional: filtros de `categories`/`severity` (si son compatibles) y etiqueta `user`.
