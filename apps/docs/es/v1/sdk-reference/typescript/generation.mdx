**Método**: `client.getGeneration()`.

### Ejemplo
```typescript
const record = await client.getGeneration("G-01ABC...");
```

### Parámetros
- `id` (cadena, obligatorio): ID de solicitud devuelto por una llamada anterior.

### Devuelve
Registro de generación (JSON)

Si el gateway guardó todos los detalles de la solicitud, el registro devuelto incluye `replay_supported` y `replay_request`. Puedes enviar `replay_request` al endpoint original para volver a ejecutarla de forma controlada.

Los campos de tiempo siguen la semántica común del gateway:

- `latency_ms`: tiempo hasta el primer token o el primer byte/frame de salida, cuando se registra
- `generation_ms`: tiempo de generación después de la latencia, cuando se registra
