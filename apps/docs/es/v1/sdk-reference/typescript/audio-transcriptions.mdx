title: "STT (voz a texto)"
description: "Llama a /audio/transcriptions con el SDK de TypeScript."
---

**Método**: `client.generateTranscription()`.

### Ejemplo
```typescript
const transcript = await client.generateTranscription({
  model: "openai/gpt-4o-transcribe",
  file: "data:audio/mp3;base64,...",
  language: "en",
});
```

### Parámetros principales
- `model` (obligatorio): ID de un modelo compatible con transcripción.
- `file` (obligatorio): datos de audio (URL, base64 o binarios).
- `language`: código de idioma sugerido (por ejemplo, `en`).
- `prompt`: contexto opcional para mejorar la precisión.
- `temperature` (0–2): aleatoriedad del muestreo.
- `response_format`: `json`, `text`, `srt`, `verbose_json`, entre otros.

### Valor devuelto
`AudioTranscriptionResponse`

```json
{
  "text": "Hello world"
}
```
