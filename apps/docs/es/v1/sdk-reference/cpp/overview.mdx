<Note type="warning">
  El SDK de C++ está en desarrollo y todavía no está disponible mediante un gestor de paquetes. Usa las cabeceras del código fuente solo para evaluarlo.
</Note>

El SDK de C++ es un conjunto de fuentes C++17 solo de cabeceras en `packages/sdk/sdk-cpp`; no está publicado y queda excluido de las versiones de los SDK hasta que funcione de principio a fin.

| Archivo | Contenido |
| --- | --- |
| `src/gen/client.hpp`, `src/gen/operations.hpp`, `src/gen/models.hpp`, `src/gen/model_ids.hpp` | El cliente generado |
| `src/phaseo.hpp` | `GetModelEndpointCapabilities(...)` para las capacidades de modelos en directo y `CheckParameterSupport(...)` para los informes de compatibilidad de parámetros |
| `src/workflows.hpp` | Helpers de paginación y de sondeo de trabajos |

El transporte de la versión preliminar devuelve JSON sin procesar, así que deserializa la respuesta en `ModelEndpointCapabilities` antes de comprobarla. Para probarlo, consulta [Instalación](./installation). No hay Agent SDK para C++.
