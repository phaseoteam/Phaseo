<Note type="warning">El SDK de C++ está en desarrollo y todavía no se ha publicado en ningún registro de paquetes.</Note>

## Uso local

El SDK es C++17 solo de cabeceras. Añade `packages/sdk/sdk-cpp` a tu compilación de CMake y enlaza el target de interfaz, o pon `packages/sdk/sdk-cpp/src` en tu ruta de inclusión:

```cmake
add_subdirectory(path/to/Phaseo/packages/sdk/sdk-cpp)
target_link_libraries(your_app PRIVATE phaseo::sdk)
```

Después incluye `phaseo.hpp`, que incorpora el cliente generado en `src/gen`.
