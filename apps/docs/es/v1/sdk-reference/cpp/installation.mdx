<Note type="warning">El SDK de C++ está en desarrollo y aún no se ha publicado en un registro de paquetes.</Note>

## Uso local

- Usa los encabezados generados en `packages/sdk/sdk-cpp/src/gen`.
- Añade esa carpeta a la ruta de inclusión de tu sistema de compilación.
- Actualmente, el cliente solo incluye encabezados.
