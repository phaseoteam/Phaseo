El SDK se publica como [`phaseo`](https://pypi.org/project/phaseo/) en PyPI.

## Instalación

Instala el SDK con el gestor de paquetes de Python que prefieras:

<CodeGroup>

    ```bash title="pip"
    pip install phaseo
    ```

    ```bash title="uv"
    uv add phaseo
    ```

</CodeGroup>

## Requisitos

- Python 3.10+

## Configuración

### Clave de API

Crea una clave de API en el [panel de Phaseo](https://phaseo.app/gateway/keys).

### Variable de entorno

```bash
export PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
```

### Uso básico

```python
from phaseo import Phaseo
import os

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])

response = client.generate_text(
    {
        "model": "openai/gpt-5-nano",
        "messages": [{"role": "user", "content": "Hello!"}],
    }
)

print(response["choices"][0]["message"]["content"])
```

### Configuración opcional del cliente

```python
from phaseo import Phaseo

client = Phaseo(
    api_key="your-api-key",
    base_url="https://api.phaseo.app/v1",
    timeout=30.0,
)
```
