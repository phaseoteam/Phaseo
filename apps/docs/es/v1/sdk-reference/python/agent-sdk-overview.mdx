El Agent SDK de Python es un entorno de ejecución local completo para agentes de Phaseo Gateway. Incluye reintentos, herramientas concurrentes, tiempos de espera, revisión humana, estado reanudable, eventos del ciclo de vida y captura con DevTools.

Úsalo cuando quieras:

- un ciclo ligero y acotado de herramientas
- solicitudes al endpoint `responses` de Gateway
- control de la persistencia y la orquestación en la aplicación

## Qué incluye

- `create_agent(...)`
- `define_tool(...)`
- `create_gateway_agent_client(...)`
- solicitudes al endpoint `responses` de Gateway
