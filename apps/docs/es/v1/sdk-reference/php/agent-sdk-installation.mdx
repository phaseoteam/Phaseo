El SDK de agentes se publica como [`phaseo/agent-sdk`](https://packagist.org/packages/phaseo/agent-sdk) en Packagist.

## Requisitos

- PHP 8.1 o posterior
- Composer
- una clave de API de Phaseo

## Instalación

```bash
composer require phaseo/agent-sdk
```

El paquete principal `phaseo/sdk` se instala automáticamente como dependencia.

## Entorno

Configura la clave de API de tu Gateway antes de ejecutar los ejemplos:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
