---
icon: "files"
title: "Archivos"
description: "Usa el SDK de PHP para subir archivos, consultar sus metadatos y recuperar su contenido."
---

**Métodos**: `uploadFile()`, `listFiles()`, `retrieveFile()`, `retrieveFileContent()`

### Ejemplo

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo(apiKey: $apiKey);

$uploaded = $client->uploadFile([
    'purpose' => 'batch',
    'file' => 'data:application/json;base64,eyJ0ZXN0Ijp0cnVlfQ==',
]);

$file = $client->retrieveFile('file_123');
$content = $client->retrieveFileContent('file_123');
```

<Note>
`listFiles()` está disponible en el SDK, pero actualmente `GET /files` devuelve `file_list_not_supported_with_shared_gateway_key` cuando se usa la clave compartida del gateway
Guarda los IDs de los archivos subidos y recupéralos directamente.
</Note>
