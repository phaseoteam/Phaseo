title: "Finalizaciones de chat"
description: "Llama a /chat/completions con el SDK de PHP."
---

**Métodos**: `generateText()`, `createChatCompletion()`

### Ejemplo

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo(apiKey: $apiKey);

$response = $client->createChatCompletion([
    'model' => 'openai/gpt-4o-mini',
    'messages' => [[
        'role' => 'user',
        'content' => 'Write a limerick about lighthouses.',
    ]],
    'temperature' => 0.5
]);
echo $response['choices'][0]['message']['content'];
```

### Parámetros clave

- `model` (obligatorio): ID del modelo de destino.
- `messages` (obligatorio): mensajes ordenados con los roles `system|user|assistant|tool`; el contenido usa objetos MessageContent.
- Muestreo: `temperature` (0–2), `top_p` (0–1), `top_k` (>=1), `seed` (int, opcional).
- Longitud y penalizaciones: `max_output_tokens` (int), `presence_penalty` y `frequency_penalty` (-2 a 2), `stop` (string|string[]).
- Herramientas: `tools` (definiciones), `tool_choice` (automático/ninguno/herramienta específica), `max_tool_calls` (int), `parallel_tool_calls` (bool).
- Logprobs: `logprobs` (bool), `top_logprobs` (0–20).
- Salida: `response_format` (json/text), `meta` (bool para incluir el bloque meta), `stream` (bool), `service_tier`.
- Opciones adicionales del gateway: `usage` (bool para solicitar el uso).
