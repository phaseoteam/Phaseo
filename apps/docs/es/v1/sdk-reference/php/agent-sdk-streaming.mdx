`Agent::stream(...)` devuelve `AgentStreamResult`:

```php
$stream = $agent->stream($input, $client);

foreach ($stream->textStream() as $delta) {
    echo $delta;
}

$completed = $stream->result;
```

Usa `reasoningStream()`, `itemStream()` o `fullStream()` para obtener otras proyecciones. Cada iterable se puede volver a recorrer después de consumir los eventos del flujo síncrono del proveedor.

Los valores de elementos de PHP siguen siendo arrays y objetos genéricos, no la unión de elementos discriminada de TypeScript.
