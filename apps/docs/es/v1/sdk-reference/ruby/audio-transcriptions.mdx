description: "Llama a /audio/transcriptions con el SDK de Ruby."
---

**Métodos**: `client.generate_transcription(...)` o `client.create_transcription(...)`.

### Ejemplo
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
transcript = client.generate_transcription(
  model: 'openai/gpt-4o-transcribe',
  audio_b64: 'base64_audio_data',
  language: 'en'
)
```

### Parámetros principales
- `model` (obligatorio): ID de un modelo compatible con transcripción.
- `audio_url` o `audio_b64` (obligatorio): datos de audio (URL o base64).
- `language`: código de idioma sugerido (por ejemplo, `en`).
- `prompt`: contexto opcional para mejorar la precisión.
- `temperature` (0–2): aleatoriedad del muestreo.
- `response_format`: `json`, `text`, `srt`, `verbose_json`, entre otros.

### Valor devuelto
`AudioTranscriptionResponse`
