Ruby Agent SDK es un entorno de ejecución local completo para agentes de Phaseo Gateway. Incluye reintentos, herramientas simultáneas, tiempos de espera, revisión humana, estado reanudable, eventos del ciclo de vida y captura de DevTools.

Úsalo cuando necesites:

- un ciclo ligero y acotado de herramientas
- solicitudes `responses` respaldadas por la pasarela
- control de la persistencia y la orquestación a cargo de la aplicación

## Funciones incluidas

- `PhaseoAgentSdk.create_agent(...)`
- `PhaseoAgentSdk.define_tool(...)`
- `PhaseoAgentSdk.create_gateway_agent_client(...)`
- un ciclo acotado de herramientas sobre la API `responses` de Phaseo
