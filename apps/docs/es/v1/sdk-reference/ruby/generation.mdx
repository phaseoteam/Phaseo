title: "Consulta de generaciones"
description: "Llama a /generations para recuperar una generación anterior."
---

**Método**: `client.get_generation(...)`

### Ejemplo

```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))

record = client.get_generation('G-01ABC...')
```

### Parámetros

- `id` (cadena, obligatorio): ID de solicitud devuelto por una llamada anterior.

### Devuelve

Registro de generación (JSON)

Si el gateway almacenó los detalles completos de la solicitud, el registro devuelto también incluye `replay_supported` y `replay_request`, que permiten volver a enviar la carga capturada al endpoint original para repetir la solicitud de forma controlada.

Los campos de tiempo siguen la semántica compartida del gateway:

- `latency_ms`: tiempo hasta el primer token o el primer byte/trama de salida, cuando se registra
- `generation_ms`: tiempo de generación posterior a la latencia, cuando se registra
