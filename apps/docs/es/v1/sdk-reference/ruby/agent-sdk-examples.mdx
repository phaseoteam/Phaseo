## Despliegue con aprobación

```ruby
deploy = PhaseoAgentSdk.define_tool(
  id: "deploy",
  description: "Deploy the selected release",
  require_approval: true,
  execute: ->(input, runtime) { deployments.deploy(input) }
)
```

Guarda la ejecución devuelta cuando pase a `waiting_for_human` y, después, continúa con una decisión asociada al ID de la llamada pendiente.

## Transmitir texto

```ruby
stream = agent.stream(input: prompt, client: client)
stream.text_stream.each { |delta| print delta }
result = stream.result
```

## Limitar el trabajo autónomo

Combina límites de pasos, tokens, coste y duración para que el agente no supere el presupuesto de la aplicación, aunque siga encontrando tareas útiles.
