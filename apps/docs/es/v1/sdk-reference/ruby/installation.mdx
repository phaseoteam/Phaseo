description: "Instala el SDK de Ruby de Phaseo desde RubyGems."
---

El SDK se publica como [`phaseo_sdk`](https://rubygems.org/gems/phaseo_sdk) en RubyGems.

## Requisitos

- Ruby 3.1 o posterior

## Instalación

```bash
gem install phaseo_sdk
```

O agrégalo a tu `Gemfile`:

```ruby
gem "phaseo_sdk"
```
