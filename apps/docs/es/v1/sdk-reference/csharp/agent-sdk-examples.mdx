| Patrón | Combinación |
| --- | --- |
| Clasificación de tickets | enrutamiento con ajustes preestablecidos, herramientas de búsqueda y respuesta final estructurada |
| Revisión de código | herramientas para repositorios, progreso y aprobación antes de realizar cambios |
| Resumen de investigación | búsqueda gestionada, texto en streaming y límites de coste |
| Guía de operaciones | herramientas de estado, escalado y continuación persistente |

Empieza con un agente, una o dos herramientas deterministas y aprobación explícita para las acciones con efectos secundarios.
