Un `RunResult` fallido conserva el paso activo, el recuento de reintentos, el ID de solicitud, el ID de respuesta nativo, los metadatos del proveedor y los detalles disponibles de la pasarela.

Comprueba primero lo siguiente:

- el proceso tiene acceso a `PHASEO_API_KEY`
- los ID de las herramientas son únicos y estables
- las decisiones de aprobación usan los ID exactos de llamadas a herramientas
- el estado pausado se guarda antes de que el control salga de la solicitud
- los validadores no producen efectos secundarios
- los tokens de cancelación llegan a las dependencias que usan las herramientas

Usa hooks del ciclo de vida para la telemetría de la aplicación y DevTools para inspeccionar ejecuciones localmente.
