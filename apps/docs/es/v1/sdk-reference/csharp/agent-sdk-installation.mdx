El SDK de agentes se publica en NuGet como [`Phaseo.AgentSdk`](https://www.nuget.org/packages/Phaseo.AgentSdk).

## Requisitos

- .NET 8 o posterior
- una clave de API de Phaseo

## Instalación

```bash
dotnet add package Phaseo.AgentSdk
```

El paquete principal `Phaseo.Sdk` se instala automáticamente como dependencia.

## Entorno

Configura tu clave de API del gateway antes de ejecutar los ejemplos:

```bash
set PHASEO_API_KEY=phaseo_v1_sk_...
```
