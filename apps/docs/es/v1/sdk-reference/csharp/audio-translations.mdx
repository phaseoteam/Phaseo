**Método**: `client.CreateTranslation(...)`

### Ejemplo
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.CreateTranslation(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-4o-transcribe",
    ["audio_b64"] = "base64-audio"
});
```

### Parámetros principales
- `model` (obligatorio): ID de un modelo compatible con traducción.
- `file` (obligatorio): datos de audio que se van a traducir.
- `prompt`: contexto opcional para orientar la traducción.
- `temperature` (0–2): aleatoriedad del muestreo.
- `response_format`: `json`, `text`, `srt`, `verbose_json`, entre otros.

### Valor devuelto
`AudioTranscriptionResponse`
