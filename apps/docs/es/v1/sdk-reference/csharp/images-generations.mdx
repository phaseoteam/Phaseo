---

**Métodos**: `client.GenerateImage(...)` o `client.CreateImage(...)`

### Ejemplo
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.GenerateImage(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-image-1",
    ["prompt"] = "A lighthouse at golden hour",
    ["size"] = "1024x1024",
    ["n"] = 1,
    ["response_format"] = "url"
});
```

### Parámetros principales
- `model` (obligatorio): ID de un modelo compatible con imágenes (por ejemplo, `openai/gpt-image-1`).
- `prompt` (obligatorio): texto de la instrucción.
- `n` (1–10): número de imágenes que se van a generar.
- `size`: por ejemplo, `1024x1024`, `1024x1792` o `1792x1024`.
- `quality`: `standard` o `hd` (depende del modelo).
- `style`: por ejemplo, `vivid` o `natural` (depende del modelo).
- `response_format`: `url` o `b64_json`.
- `user`: etiqueta opcional del usuario final para el seguimiento de seguridad o uso indebido.

### Valor devuelto
`ImageGenerationResponse`
