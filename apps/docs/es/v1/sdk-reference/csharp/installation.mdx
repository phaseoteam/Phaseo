El SDK se publica como [`Phaseo.Sdk`](https://www.nuget.org/packages/Phaseo.Sdk) en NuGet.

## Requisitos

- .NET 8 o posterior

## Instalación

```bash
dotnet add package Phaseo.Sdk
```
