Pasa un ID de solicitud (como `G-01ABC...`) al método de generaciones del SDK para obtener el registro guardado de esa solicitud desde `GET /v1/generations?id=<id>`.

<CodeGroup>

```typescript TypeScript
const record = await client.getGeneration("G-01ABC...");
```

```python Python
record = client.get_generation("G-01ABC...")

print(record["model_id"], record["cost_nanos"])
```

```go Go
client, err := phaseo.NewFromEnv()
if err != nil {
  panic(err)
}

record, err := client.GetGeneration(context.Background(), "G-01ABC...")
if err != nil {
  panic(err)
}
fmt.Println(record["status_code"], record["cost_nanos"])
```

```csharp C#
using PhaseoSdk;

var client = new Phaseo();
var record = await client.GetGeneration("G-01ABC...");
```

```php PHP
<?php
require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo();
$record = $client->getGeneration('G-01ABC...');
```

```ruby Ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new
record = client.get_generation('G-01ABC...')
```

```java Java
import app.phaseo.sdk.Phaseo;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

var record = client.getGeneration("G-01ABC...");
System.out.println(record);
```

</CodeGroup>

| Lenguaje | Método | Devuelve |
| --- | --- | --- |
| TypeScript | `client.getGeneration(id)` | El objeto del registro |
| Python | `client.get_generation(id)` | Dict `APIResponse` |
| Go | `client.GetGeneration(ctx, id)` | `map[string]interface{}` |
| C# | `client.GetGeneration(id)` | `Dictionary<string, object>?` |
| PHP | `$client->getGeneration($id)` | Array |
| Ruby | `client.get_generation(id)` | Hash |
| Java | `client.getGeneration(id)` | `JsonNode` de Jackson |
| Rust | No hay helper; llama a `client.request("GET", "/generations?id=<id>", None, &RequestOptions::default())` | `PhaseoResponse`, con el registro en `body` (un `serde_json::Value`) |

La consulta se limita a tu espacio de trabajo. Si falta el `id`, devuelve `400` (`missing_id`), y un ID que no está en tu espacio de trabajo devuelve `404` (`not_found`).

## Repite una solicitud guardada

Si el gateway guardó la solicitud completa, el registro tiene `replay_supported` a true y un `replay_request`, que puedes volver a enviar al endpoint original para repetirla de forma controlada.

## Lee los campos de tiempo

- `latency_ms`: tiempo hasta el primer token, o el primer byte o fotograma de salida, cuando se mide.
- `generation_ms`: tiempo de generación a partir de ese punto, cuando se mide.
