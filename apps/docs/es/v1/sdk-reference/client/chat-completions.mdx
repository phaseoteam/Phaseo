Llama al método de chat del SDK para enviar `POST /v1/chat/completions` y recibir una respuesta completa. Para integraciones nuevas, la [API de Responses](./responses) ofrece una sola forma de solicitud para texto, entrada multimodal, herramientas y elementos de salida más completos.

```typescript TypeScript
  ],

console.log(chat.choices[0].message.content);
```

```rust Rust
use serde_json::json;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Phaseo::from_env()?;
    let response = client.chat_completions(&json!({
        "model": "openai/gpt-6-astra",
        "messages": [
            {
                "role": "system",
                "content": "Answer concisely."
            },
            {
                "role": "user",
                "content": "What is provider fallback?"
            }
        ]
    }))?;

    let text = response
        .body
        .pointer("/choices/0/message/content")
        .and_then(|value| value.as_str())

    Ok(())
```

</CodeGroup>

| Lenguaje | Método | Devuelve |
| --- | --- | --- |
| TypeScript | `client.generateText(request)`; `client.chat.completions.create(request)` hace lo mismo y pasa a streaming cuando `stream` es true | `ChatCompletionsResponse` |
| Python | `client.generate_text(request)`; también `client.chat.completions.create(request)` | Dict `APIResponse` |
| Go | `client.GenerateText(ctx, req)`, alias `CreateChatCompletion`; recibe un `phaseo.ChatCompletionsRequest` | `map[string]interface{}` |
| C# | `client.GenerateText(request)`, alias `CreateChatCompletion` | `Dictionary<string, object>?` |
| PHP | `$client->generateText($request)`, alias `createChatCompletion()` | Array |
| Ruby | `client.generate_text(...)`, alias `create_chat_completion` | Hash |
| Java | `client.createChatCompletion(request)`; recibe un `Map` o un `JsonNode` de Jackson | `JsonNode` de Jackson |
| Rust | `client.chat_completions(&request)` | `PhaseoResponse`; el JSON está en `body` |

Todos los valores devueltos tienen la forma de Chat Completions: la respuesta está en `choices[0].message.content`, junto con `finish_reason` y `usage`.

## Transmite la respuesta

<CodeGroup>

```typescript TypeScript
for await (const chunk of client.streamChat({
  model: "openai/gpt-6-astra",
  messages: [{ role: "user", content: "Stream a story" }],
})) {
  if (chunk.text) process.stdout.write(chunk.text);
}
```

```python Python
for chunk in client.stream_chat({
    "model": "openai/gpt-6-astra",
    "messages": [{"role": "user", "content": "Stream a story"}],
}):
    if chunk.get("text"):
        print(chunk["text"], end="", flush=True)
```

```java Java
import app.phaseo.sdk.Phaseo;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.List;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));
var payload = Map.of(
    "model", "openai/gpt-6-astra",
    "messages", List.of(Map.of("role", "user", "content", "Hello")),
    "stream", true
);
try (var lines = client.rawClient().requestLines(
    "POST", "/chat/completions", null, null,
    new ObjectMapper().writeValueAsString(payload)
)) {
    lines.forEach(System.out::println);
}
```

</CodeGroup>

| Lenguaje | Cómo transmitir |
| --- | --- |
| TypeScript | `client.streamChat(request)` produce fragmentos ya analizados; `client.streamText()` produce las líneas SSE sin procesar. |
| Python | `client.stream_chat(request)` produce fragmentos ya analizados; `client.stream_text()` produce las líneas SSE sin procesar. |
| Java | `createChatCompletion` devuelve un solo cuerpo JSON. Define `stream: true` y envía la solicitud con `rawClient().requestLines`, que devuelve las líneas SSE a medida que llegan; ciérralo con try-with-resources. |
| Go, C#, PHP, Ruby, Rust | No hay helper de streaming para Chat Completions; no definas `stream`. En C#, PHP y Ruby, [Responses](./responses#stream-the-response) tiene un método de streaming. |

Cada fragmento analizado (TypeScript y Python) conserva los campos originales (`choices`, `id`, …) y añade `text` (el contenido que aporta ese fragmento), `usage` y los tokens de razonamiento (`reasoningTokens` / `reasoning_tokens`).

## Parámetros

Los nombres de los campos son los del cuerpo JSON en todos los SDK. El tipo `phaseo.ChatCompletionsRequest` de Go usa campos de struct en PascalCase (`Model`, `Messages`).

| Grupo | Campos |
| --- | --- |
| Obligatorios | `model`; `messages` con los roles `system`, `developer`, `user`, `assistant` o `tool`, y contenido como cadena o como partes |
| Muestreo | `temperature` (0–2), `top_p` (0–1), `top_k` (-1 o más), `min_p` (0–1), `seed`, si el modelo los admite |
| Longitud y penalizaciones | `max_tokens` o `max_completion_tokens`, `presence_penalty` y `frequency_penalty` (de -2 a 2), `repetition_penalty` (mayor que 0), `stop` (cadena o array) |
| Herramientas | `tools`, `tool_choice`, `max_tool_calls`, `parallel_tool_calls` |
| Razonamiento | Objeto `reasoning` o `reasoning_effort` |
| Probabilidades logarítmicas | `logprobs`, `top_logprobs` (0–20) |
| Salida | `response_format`, `n` (1–16), `stream`, `service_tier`, `metadata` (valores de cadena) |
| Gateway | Enrutamiento `provider`, `usage` (incluir el uso), `meta` (incluir el bloque meta del gateway) |

[Parámetros](/es/v1/api-reference/parameters) explica cada campo, y la [referencia de la API de Chat Completions](../../api-reference/endpoint/chat-completions) tiene el esquema completo.

## Respuesta

`ChatCompletionsResponse`:

```json
{
  "id": "chatcmpl-123",
  "object": "chat.completion",
  "created": 1677652288,
  "model": "openai/gpt-6-astra",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello there, how may I assist you today?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 9,
    "completion_tokens": 12,
    "total_tokens": 21
  }
}
```

Con `stream: true`, el endpoint envía tramas SSE que terminan con `data: [DONE]`:

```

data: {"id":"chatcmpl-123","object":"chat.completion.chunk","created":1677652288,"model":"openai/gpt-6-astra","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}]}
```
