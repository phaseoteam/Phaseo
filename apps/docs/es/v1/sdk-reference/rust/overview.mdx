Usa el crate publicado [`phaseo`](https://crates.io/crates/phaseo) para llamar al gateway de Phaseo desde una aplicación Rust.

El cliente de alto nivel admite:

- solicitudes a la API Responses con `Phaseo::responses(...)`
- solicitudes a Chat Completions con `Phaseo::chat_completions(...)`
- otros endpoints JSON con `Phaseo::post(...)`
- configuración basada en el entorno con `Phaseo::from_env()`
- endpoints HTTPS personalizados y servidores de desarrollo loopback
- estado, cuerpo JSON, ID de solicitud y detalles de error estructurados

```rust
use phaseo::Phaseo;
use serde_json::json;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Phaseo::from_env()?;
    let response = client.responses(&json!({
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with exactly: Rust SDK works"
    }))?;

    println!("{}", response.body);
    Ok(())
}
```

<Note>
  La versión `0.1` tiene soporte y está publicada, pero la API de Rust puede seguir evolucionando antes de `1.0`. Fija una versión menor compatible en producción.
</Note>

## Alcance actual

El cliente de alto nivel es síncrono y acepta cuerpos de solicitud `serde_json::Value`. Los módulos de bajo nivel generados siguen disponibles en `phaseo::gen`, con exportaciones prácticas en `phaseo::client`, `phaseo::models` y `phaseo::operations`.

El cliente de Rust actualmente no ofrece un transporte asíncrono ni un ayudante de streaming de alto nivel. Usa la API HTTP sin procesar si la aplicación necesita streaming antes de que se incorporen esas funciones.
