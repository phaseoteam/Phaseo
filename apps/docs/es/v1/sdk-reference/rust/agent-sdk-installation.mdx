## Requisitos

- Rust 1.86 o posterior
- una clave de API del gateway de Phaseo

## Instalación

```toml
[dependencies]
phaseo = "0.1"
phaseo-agent = "0.1"
serde_json = "1"
```

O ejecuta:

```bash
cargo add phaseo@0.1 phaseo-agent@0.1 serde_json
```

## Configurar la autenticación

`create_gateway_agent_client(...)` y `GatewayAgentClient::from_env(...)` leen `PHASEO_API_KEY`:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

El cliente `phaseo` subyacente también acepta `PHASEO_BASE_URL` de forma opcional.

## Verificar la instalación

```rust
use phaseo_agent::{create_agent, AgentDefinition};

fn main() {
    let _agent = create_agent(AgentDefinition::new(
        "verification-agent",
        "openai/gpt-6-astra",
    ));
    println!("Phaseo Rust Agent SDK installed");
}
```
