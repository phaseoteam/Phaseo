Empieza con uno de estos patrones:

| Patrón | Combina |
| --- | --- |
| Clasificación de solicitudes de soporte | preset administrado, herramientas de búsqueda, resultado final estructurado |
| Revisión de código | herramientas de archivos o parches, eventos de progreso, aprobación antes de editar |
| Resumen de investigación | herramientas web administradas, límites de coste y pasos, texto en streaming |
| Manual de operaciones | herramientas de estado, escalamiento manual, continuación persistente |

Mantén acotada la primera implementación: un agente, una o dos herramientas deterministas y aprobación explícita para los efectos secundarios.
