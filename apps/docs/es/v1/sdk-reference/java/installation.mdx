El código fuente actual incluye controles de reintentos y metadatos de respuesta que no están en el antiguo artefacto 3.0.0 de Maven Central. Compila la revisión indicada para usar el SDK actual.

## Requisitos

- Java 17+
- Maven 3.8+
- Git

## Compilar desde el código fuente

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
git checkout 1ff1119f41ceb3ac2c85ed605f6e1c4beca6e011
mvn -f packages/sdk/sdk-java/pom.xml -DskipTests install
```

Maven instala `app.phaseo:phaseo-sdk:3.0.0` en tu repositorio local, incluida su dependencia de Jackson.

## Añadir la dependencia

```xml
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-sdk</artifactId>
  <version>3.0.0</version>
</dependency>
```

<Note>El [artefacto de Maven Central](https://repo.maven.apache.org/maven2/app/phaseo/phaseo-sdk/3.0.0/) ofrece la API anterior. No incluye las API actuales de reintentos, metadatos ni validación de parámetros.</Note>
