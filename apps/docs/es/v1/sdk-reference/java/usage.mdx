```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

Usa `createResponse`, `createChatCompletion`, `createEmbedding` y `listModels` para solicitudes JSON. Pasa un `Map` o `JsonNode`; convierte las cadenas JSON antes de pasarlas a los métodos del cliente.

## Reintentos y errores

Los reintentos están desactivados por defecto. `setMaxRetries` reintenta solicitudes GET/HEAD seguras; no repite escrituras ni solicitudes de streaming. Los errores HTTP exponen estado, cuerpo, cabeceras e ID de solicitud mediante `Client.ApiException`.

```java
import app.phaseo.gen.Client;
import app.phaseo.sdk.Phaseo;
import java.time.Duration;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"))
    .setTimeout(Duration.ofSeconds(30))
    .setMaxRetries(2);

try {
    var result = client.requestWithResponse("GET", "/models",
        Map.of("limit", "5"), null, null, null);
    System.out.println(result.requestId());
    System.out.println(result.data);
} catch (Client.ApiException error) {
    System.err.println(error.getStatusCode());
    System.err.println(error.getRequestId());
    System.err.println(error.getResponseBody());
}
```

## Streaming

`streamResponse` y `rawClient().requestLines` devuelven líneas SSE a medida que llegan. Cierra el flujo con try-with-resources y procesa los nombres de eventos, los datos y los marcadores de finalización en tu aplicación.

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));
try (var lines = client.streamResponse(Map.of(
    "model", "openai/gpt-6-astra", "input", "Hello"
))) {
    lines.forEach(System.out::println);
}
```
