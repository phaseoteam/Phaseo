Envía solicitudes de texto, embeddings y consulta de modelos con el SDK de Java.

<Note>El código fuente actual incluye controles de reintentos y metadatos de respuesta que no están en el antiguo artefacto 3.0.0 de Maven Central. Compila la revisión indicada para usar el SDK actual. [Instalación](./installation)</Note>

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

## Solicitudes compatibles

Usa `createResponse`, `createChatCompletion`, `createEmbedding` y `listModels` para solicitudes JSON. Pasa un `Map` o `JsonNode`; convierte las cadenas JSON antes de pasarlas a los métodos del cliente.

## Streaming

`streamResponse` y `rawClient().requestLines` devuelven líneas SSE a medida que llegan. Cierra el flujo con try-with-resources y procesa los nombres de eventos, los datos y los marcadores de finalización en tu aplicación.

<Note>El método `createSpeech` espera JSON y no puede decodificar audio binario. Usa `rawClient().requestBytes` para obtener audio.</Note>
