Contribuir a **Phaseo** es sencillo, transparente y abierto a todo el mundo.
Esta guía explica todo el proceso, tanto si editas un registro de modelo, actualizas datos de benchmarks, mejoras la documentación o aportas ideas.

---

## Antes de empezar

Necesitarás tener instaladas algunas herramientas básicas:

| Herramienta | Uso | Instalación |
| ------------------ | ---------------------------------------------- | -------------------------------------------------- |
| **Git**            | Control de versiones para clonar y subir cambios.     | [Instalar Git](https://git-scm.com/downloads)       |
| **Node.js (v20+)** | Ejecuta el sitio de Phaseo localmente (Next.js).      | [Descargar Node.js](https://nodejs.org/en/download) |
| **pnpm**           | Gestor de paquetes utilizado en este proyecto.          | `npm install -g pnpm`                              |
| **cuenta de GitHub** | Necesaria para crear forks, incidencias y solicitudes de incorporación de cambios. | [Regístrate aquí](https://github.com/signup)          |

Si solo quieres editar **datos** o **documentación Markdown**, puedes hacer los cambios directamente en GitHub sin configurar un entorno local.

---

## 1. Haz un fork del repositorio

Ve al [repositorio de Phaseo en GitHub](https://github.com/phaseoteam/Phaseo) y haz clic en **Fork**, en la esquina superior derecha.
Esto crea una copia propia del proyecto que puedes modificar libremente.

---

## 2. Clona tu fork

```bash
git clone https://github.com/yourusername/Phaseo.git
cd Phaseo
```

Esto descarga tu fork en tu equipo local.

---

## 3. Crea una rama nueva

Se recomienda crear una rama nueva para cada cambio:

```bash
git checkout -b update-benchmark-data
```

Usa un nombre de rama descriptivo que indique el cambio para facilitar la revisión.

Ejemplos:

-   `fix-{model-name}`
-   `add-new-organisation`
-   `improve-docs`
-   `update-pricing-for-{model-name}`

---

## 4. Realiza los cambios

Según lo que quieras editar:

| Área | Archivos | Descripción |
| --------------------- | --------------------------------------------- | ----------------------------------------------------- |
| **Datos de modelos**        | `/packages/data/catalog/src/data/models/**/model.json`     | Añade o actualiza metadatos, precios o benchmarks de modelos. |
| **Datos de organizaciones** | `/packages/data/catalog/src/data/organisations/*.json`     | Actualiza información sobre empresas o grupos de investigación.    |
| **Datos de benchmarks**    | `/packages/data/catalog/src/data/benchmarks/**/*.json`     | Envía nuevos resultados de evaluación o correcciones.         |
| **Documentación**     | `/apps/docs/v1/**/*.mdx`                      | Mejora o amplía las guías, referencias y páginas de documentación. |
| **Pasarela**           | `/apps/api/*`                                 | Realiza cambios en la pasarela de API.                      |

Si editas datos, sigue los esquemas y formatos de campo descritos en [Estructura del repositorio](./repo-structure.mdx).

---

## 5. Previsualiza tus cambios (opcional)

Si quieres previsualizar tus cambios localmente:

```bash
pnpm install
pnpm dev
```

Usa [http://localhost:3100](http://localhost:3100) para los cambios web y [http://localhost:3101](http://localhost:3101) para la documentación. Los cambios en los datos solo se pueden previsualizar después de crear una PR, ya que la aplicación web obtiene los datos de la base de datos.

---

## 6. Confirma tus cambios

Cuando estés conforme, confirma tu trabajo:

```bash
git add .
git commit -m "Updated benchmark data for Claude 3.5 Sonnet"
```

Asegúrate de que el mensaje del commit describa los cambios para que quienes revisen puedan entender tu contribución.

---

## 7. Sube tu rama

```bash
git push origin update-benchmark-data
```

---

## 8. Crea una solicitud de incorporación de cambios (PR)

1. Ve a tu fork en GitHub.
2. Aparecerá un mensaje para crear una PR: haz clic en **Compare & Pull Request**.
3. Completa la plantilla de la PR con la información pertinente sobre tus cambios.
4. Envía la PR.

Cuando revisen y aprueben la PR, se integrará en el repositorio principal de Phaseo.

---

## 9. Celebra

Tu contribución estará disponible cuando se integre. Si llegaste hasta aquí, agradecemos tu esfuerzo y apoyo.

## Consejos para contribuir

-   Mantén las PR **pequeñas y enfocadas**: incluye un solo cambio lógico en cada una.
-   Cuando sea posible, sigue [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/). Usa **prefijos claros** como `fix:`, `add:` o `chore:`.
-   Si tu cambio afecta la precisión de los datos, incluye **fuentes o referencias**.
-   Si la idea es grande o aún no está clara, abre un **debate en GitHub** o escribe en Discord antes de empezar a programar.
-   Mantén siempre un trato respetuoso y sigue nuestro [Código de conducta](../community/code-of-conduct.mdx).

---

## Resumen del flujo de ejemplo

```bash
# 1. Fork and clone

git clone https://github.com/yourusername/Phaseo.git
cd Phaseo

# 2. Create branch
git checkout -b add-openai-new-model

# 3. Make changes
# e.g., update packages/data/catalog/src/data/models/openai/new-model/model.json

# 4. Commit and push
git add .
git commit -m "Add new OpenAI model entry"
git push origin add-new-openai-model

# 5. Create a Pull Request on GitHub
```
