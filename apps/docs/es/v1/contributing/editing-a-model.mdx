description: "Actualiza los metadatos, los precios y las capacidades del modelo en el conjunto de datos de Phaseo."
---

Los datos de los modelos están en archivos JSON dentro de `packages/data/catalog/src/data/models`. Cada modelo tiene su propia carpeta y un archivo `model.json`.

## 1. Busca el modelo

Busca el directorio del modelo por proveedor y nombre. Por ejemplo:

`packages/data/catalog/src/data/models/openai/gpt-5-2025-08-07/model.json`

## 2. Realiza los cambios

Entre los cambios habituales se incluyen:

- Descripciones y enlaces
- Capacidades y endpoints compatibles
- Precios o notas sobre disponibilidad
- Referencias a benchmarks

Mantén los valores coherentes con el esquema existente en los archivos cercanos.

## 3. Valida los datos

Ejecuta el script de validación de datos antes de abrir una PR:

```bash
pnpm validate:data
```

## 4. Abre una PR

Incluye un breve resumen de los cambios y las fuentes utilizadas.
