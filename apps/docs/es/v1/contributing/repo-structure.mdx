Phaseo es un monorepositorio de pnpm y Turborepo. Usa esta referencia para encontrar los archivos de un cambio de código o documentación. Para cambios de registros del catálogo, [abre una incidencia](./overview.mdx).

## Aplicaciones y paquetes

| Ruta | Finalidad |
| --- | --- |
| `apps/web` | Sitio web Next.js 16, panel y editor interno del catálogo. |
| `apps/web-api` | Lecturas públicas del catálogo y API autenticadas de cuentas y administración. |
| `apps/api` | Enrutamiento de la pasarela y ejecución de proveedores en Cloudflare Workers. |
| `apps/docs` | Documentación Mintlify; páginas MDX en `v1` y navegación en `docs.json`. |
| `packages/sdk` | SDK de TypeScript, Python, Go, C#, PHP, Ruby, Java, Rust y C++. |
| `supabase/migrations` | Migraciones de esquemas y permisos de la base de datos. |
| `scripts` | Utilidades de validación, generación de SDK y automatización. |
| `.github/workflows` | CI, despliegue y sincronización del catálogo. |
| `.changeset` | Metadatos de publicación de paquetes versionados. |

## Datos del catálogo

La base de datos es la fuente de verdad de modelos, proveedores, organizaciones, precios, benchmarks y ajustes relacionados del catálogo. Los administradores gestionan registros mediante [Datos internos](https://phaseo.app/internal/data). Las contribuciones públicas se revisan mediante incidencias de GitHub.

- El repositorio no contiene JSON del catálogo. El importador antiguo de JSON a base de datos está retirado.

Los cambios de esquemas y aplicaciones siguen usando migraciones y solicitudes de cambios. Los artefactos SDK generados deben actualizarse con sus comandos de generación.

## Automatización del catálogo

La sincronización de proveedores pone los precios propuestos en cola para su revisión en [Actualizaciones de proveedores](https://phaseo.app/internal/data/imports). Los trabajos de benchmarks y ciclo de vida de modelos usan la base de datos.

Los registros exclusivos del catálogo no habilitan automáticamente el enrutamiento de la pasarela. Los cambios de rutas y precios requieren la revisión administrativa correspondiente.
