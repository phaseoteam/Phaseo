Phaseo es un monorepositorio de pnpm y Turborepo. Busca abajo la carpeta de tu cambio de código o documentación. Los registros del catálogo no están en el repositorio; para cambiar uno, [abre una incidencia](./overview.mdx).

## Aplicaciones

| Ruta | Finalidad |
| --- | --- |
| `apps/web` | Sitio web Next.js 16, panel y editor interno del catálogo. |
| `apps/web-api` | Lecturas públicas del catálogo y API autenticadas de cuentas y administración. |
| `apps/api` | Enrutamiento del Gateway y ejecución de proveedores en Cloudflare Workers. |
| `apps/docs` | Documentación de Mintlify; las páginas MDX están en `v1` y la navegación en `docs.json`. |
| `apps/mcp` | Servidor MCP de Phaseo para descubrir modelos, precios y uso. |
| `apps/desktop` | Aplicación Phaseo Desktop. |
| `apps/mobile` | Aplicación móvil de Phaseo (Expo, primero Android). |
| `apps/slack` | Worker que da servicio al agente de Slack de Phaseo. |

## Paquetes y herramientas

| Ruta | Finalidad |
| --- | --- |
| `packages/sdk` | SDK de TypeScript, Python, Go, C#, PHP, Ruby, Java, Rust y C++, además de los Agent SDK (`agent-sdk-*`). |
| `packages/cli/phaseo` | La herramienta de línea de comandos `@phaseo/cli`. |
| `packages/integrations` | El proveedor para Vercel AI SDK y el proveedor de Terraform. |
| `packages/shared` | Código compartido entre aplicaciones, como la interfaz, las reglas de gasto y los ajustes de enrutamiento. |
| `supabase/schemas` | Definiciones declarativas de la base de datos. |
| `supabase/migrations` | Migraciones SQL hacia delante que despliegan los cambios de esquema y permisos. |
| `scripts` | Utilidades de validación, generación de SDK y automatización. |
| `.github/workflows` | CI, despliegue y sincronización del catálogo. |
| `.changeset` | Metadatos de publicación de los paquetes versionados. |

## Datos del catálogo

La base de datos es la única fuente de modelos, proveedores, organizaciones, precios, benchmarks y ajustes del catálogo. El repositorio no contiene JSON del catálogo. Los administradores gestionan los registros en [Datos internos](https://phaseo.app/internal/data); las contribuciones públicas llegan como incidencias de GitHub.

Los cambios de esquema y de aplicaciones siguen pasando por migraciones y solicitudes de incorporación. Actualiza los archivos de SDK generados con sus comandos de generación, no a mano.

## Automatización del catálogo

La sincronización de proveedores pone en cola los precios propuestos para su revisión en [Actualizaciones de proveedores](https://phaseo.app/internal/data/imports). Los trabajos de benchmarks y del ciclo de vida de los modelos leen y escriben en la base de datos.

Un registro del catálogo no habilita por sí solo el enrutamiento en el Gateway. Los cambios de rutas y precios requieren la revisión de un administrador.

Para empezar un cambio, consulta [Contribuir código o documentación](./how-to-contribute.mdx).
