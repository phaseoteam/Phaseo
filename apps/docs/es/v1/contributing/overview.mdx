Phaseo es un **proyecto abierto e impulsado por la comunidad** que busca ofrecer a todo el mundo acceso gratuito a tanta información como sea posible sobre modelos de IA, benchmarks y proveedores.

Tus aportaciones ayudan a mantener la plataforma precisa, transparente y actualizada.  
Ya sea que corrijas un error tipográfico, añadas datos de benchmarks o mejores la documentación, cada aportación cuenta.

---

## ¿Por qué contribuir?

La IA evoluciona cada vez más rápido: a diario aparecen modelos nuevos y cambian las actualizaciones y los precios.  
Al contribuir, ayudas a:

-   Mantener actualizados y fiables los datos de modelos, organizaciones y benchmarks
-   Mejorar la precisión de las comparaciones de IA entre proveedores
-   Compartir hallazgos de investigación, descubrimientos de la comunidad o metadatos que faltan
-   Fortalecer el ecosistema abierto para la transparencia de la IA
-   Garantizar que la base de datos siga siendo de acceso gratuito y propiedad de la comunidad

Tu nombre también aparecerá en la [página de colaboradores](https://phaseo.app/contribute), como reconocimiento por tus contribuciones.

## Resumen del flujo de contribución

1. **Haz un fork** del [repositorio de Phaseo en GitHub](https://github.com/phaseoteam/Phaseo).
2. **Crea una rama** para tus cambios (por ejemplo, `fix-model-data` o `add-new-benchmark`).
3. **Edita los archivos JSON o Markdown** según la estructura descrita en [Estructura del repositorio](./repo-structure.mdx).
4. **Prueba tus cambios localmente** si corresponde (por ejemplo, revisándolos en el frontend de Next.js).
5. **Confirma y sube** tus cambios.
6. **Abre una solicitud de incorporación de cambios (PR)** y describe qué cambiaste y por qué.

Cuando se revise y apruebe, tu contribución se integrará y aparecerá en la base de datos activa de Phaseo.

## Tipos de contribuciones

| Tipo                   | Ejemplo                                                 | Dificultad |
| ---------------------- | ------------------------------------------------------- | ---------- |
| **Corrección de datos**           | Corregir nombres de modelos, proveedores o valores de benchmarks. | Fácil       |
| **Nueva entrada**          | Añadir un modelo, benchmark u organización.         | Moderada   |
| **Cambio estructural**  | Ajustar la estructura de la base de datos o del esquema.                    | Avanzada   |
| **Nueva funcionalidad**   | Añadir componentes de interfaz o lógica de Next.js.                  | Avanzada   |
| **Edición de documentación** | Mejorar archivos Markdown o guías.                     | Fácil       |

Sea cual sea el cambio que quieras proponer, agradecemos contribuciones de cualquier tamaño y complejidad.

## Pautas y estándares

Todas las contribuciones deben seguir estos estándares para garantizar la calidad y coherencia de los datos:

-   **Fuentes verificadas:** Incluye únicamente datos verificados o publicados oficialmente.
-   **Formato coherente:** Usa las mayúsculas, la indentación y las claves del esquema correctamente.
-   **Cambios con versión:** Redacta descripciones claras en los registros de cambios o mensajes de commit.
-   **Referencias:** Incluye enlaces a las fuentes de datos en las descripciones de las PR.
-   **Comunicación respetuosa:** Sigue nuestro [Código de conducta](../community/code-of-conduct.mdx).

## Ejemplo de flujo de contribución

```bash
# 1. Fork and clone the repo
git clone https://github.com/yourusername/Phaseo.git

# 2. Create a new branch
git checkout -b add-openai-new-model

# 3. Make your edits
# e.g. edit packages/data/catalog/src/data/models/openai/new-model/model.json

# 4. Stage, commit, and push
git add .
git commit -m "Added new OpenAI model with updated benchmark data"
git push origin add-openai-new-model

# 5. Open a Pull Request on GitHub
# Describe your changes and link any sources
```

## ¿Necesitas ayuda?

Si no sabes cómo contribuir o quieres recibir comentarios antes de enviar los cambios, puedes:

-   Pregunta en el [Discord de Phaseo](https://discord.gg/aQyywCvgZ5).
-   Abre un **debate en GitHub** si tienes preguntas o sugerencias.
-   Menciona a los responsables en tu PR para recibir orientación durante la revisión.
