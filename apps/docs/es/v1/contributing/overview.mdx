Para correcciones y adiciones al catálogo, abre una incidencia con el registro afectado y fuentes de apoyo. Para cambios de código o documentación, envía una solicitud de cambios al [repositorio de Phaseo](https://github.com/phaseoteam/Phaseo).

## Elegir tu contribución

| Cambio | Empieza aquí |
| --- | --- |
| Metadatos, capacidades, disponibilidad o precios de modelos | [Informar de una actualización de modelo](./editing-a-model.mdx) |
| Detalles de empresas u organizaciones de investigación | [Informar de una actualización de organización](./editing-an-organisation.mdx) |
| Resultados de benchmarks | [Enviar puntuaciones](../research/submitting-scores.mdx) |
| Otras correcciones del catálogo | [Informar de información incorrecta](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) |
| Proveedores u otros datos del catálogo que faltan | [Solicitar datos nuevos](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) |
| Documentación o código | [Flujo de contribución](./how-to-contribute.mdx) y [estructura del repositorio](./repo-structure.mdx) |

## Cómo se publican los informes del catálogo

Los responsables revisan las pruebas de la incidencia y aplican los cambios aprobados mediante el [editor interno](https://phaseo.app/internal/data), exclusivo de administradores. Las actualizaciones de precios de proveedores requieren revisión explícita antes de publicarse.

La base de datos es la fuente de verdad del catálogo. Siguen disponibles las instantáneas JSON públicas diarias, pero ni sus ediciones ni las solicitudes de cambios de JSON archivado actualizan el catálogo en vivo. El importador JSON antiguo está retirado.

## Antes de enviar

- Incluye la página o ID del registro afectado y describe la corrección propuesta.
- Cita fuentes oficiales y distingue los resultados de benchmarks publicados de las mediciones independientes.
- Mantén cada informe o solicitud de cambios centrado en un tema.
- Nunca incluyas credenciales ni datos privados de clientes.
- Sigue el [Código de conducta](../community/code-of-conduct.mdx).

Comenta los cambios importantes de esquemas o funciones con los responsables antes de implementarlos. Pide ayuda en [Discord](https://discord.gg/aQyywCvgZ5) si no sabes dónde encaja un cambio.
