Cambia el modelo a `anthropic/claude-opus-5` y mantén Claude Opus 4.8 como respaldo mientras lo evalúas. El precio es el mismo que el de Opus 4.8, así que la diferencia de coste viene del uso de tokens.

```json
{
  "model": "anthropic/claude-opus-5",
  "models": ["anthropic/claude-opus-4.8"],
  "messages": [
    {
      "role": "user",
      "content": "Review this implementation plan and identify the highest-risk assumptions."
    }
  ]
}
```

| | Claude Opus 4.8 | Claude Opus 5 |
| --- | --- | --- |
| ID de modelo de Phaseo | `anthropic/claude-opus-4.8` | `anthropic/claude-opus-5` |
| Ventana de contexto | 1M tokens | 1M tokens |
| Salida máxima | 128K tokens | 128K tokens |
| Precio por 1M de tokens (entrada / salida) | $5.00 / $25.00 | $5.00 / $25.00 |
| Pensamiento cuando la solicitud no define razonamiento | Desactivado | Adaptativo |

Los precios son los del nivel estándar de Anthropic según el catálogo; consulta la página del modelo para ver otros niveles y proveedores.

## Cómo envía Phaseo la solicitud

Opus 5 usa la misma estructura de solicitud que Opus 4.7 y 4.8:

- **Los parámetros de muestreo se omiten.** `temperature`, `top_p` y `top_k` no se envían al modelo.
- **Cualquier ajuste de razonamiento activa el pensamiento adaptativo.** Phaseo envía `thinking: {"type": "adaptive", "display": "summarized"}`, y `reasoning.effort` pasa a ser `output_config.effort`. Los presupuestos de pensamiento no se reenvían.
- **`reasoning.effort: "none"` o `reasoning.enabled: false` desactiva el pensamiento** (`thinking: {"type": "disabled"}`).
- **Sin ajuste de razonamiento, Phaseo no envía ningún campo `thinking`,** así que se aplica el valor predeterminado de Opus 5, el pensamiento adaptativo. Opus 4.8 solo piensa cuando se le pide, así que la misma solicitud puede usar más tokens de salida en Opus 5.

## Qué probar

- **Prompts y salidas:** seguimiento de instrucciones en tus prompts de sistema más largos, tasas de validación del esquema, longitud de las respuestas y momento en que se detienen, y prompts ajustados para Opus 4.8.
- **Herramientas y agentes:** selección de herramientas y argumentos, recuperación tras errores de herramientas o resultados parciales, tasa de finalización en tareas de largo recorrido y límites de permisos en flujos con mucha autonomía.
- **Operaciones:** latencia y uso de tokens en cada nivel de esfuerzo que expongas, uso de contexto en documentos largos y trazas de agentes, coste por tarea completada con éxito y respaldo cuando la ruta principal agota el tiempo de espera o falla.

## Despliega

1. Ejecuta en modo sombra tráfico de producción representativo antes de atender a usuarios.
2. Haz un canary por carga de trabajo en lugar de mover todas las rutas de Opus a la vez.
3. Promuévelo solo cuando las comprobaciones de calidad, latencia, coste y seguridad de las herramientas cumplan tus objetivos.
