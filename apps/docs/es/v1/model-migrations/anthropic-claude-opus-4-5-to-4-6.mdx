Cambia el modelo a `anthropic/claude-opus-4.6`, elimina los prefills del asistente y pasa la salida estructurada a `output_config.format`. Son cambios en la estructura de la solicitud: los patrones antiguos de Opus 4.5 fallan con `400` si se dejan como están.

| | Claude Opus 4.5 | Claude Opus 4.6 |
| --- | --- | --- |
| ID de modelo de Phaseo | `anthropic/claude-opus-4.5` | `anthropic/claude-opus-4.6` |
| Ventana de contexto | 200K tokens | 1M tokens |
| Salida máxima | 64K tokens | 128K tokens |
| Prefill del asistente | Compatible | Devuelve `400` |
| Salida estructurada | `output_format` | `output_config.format` |
| Pensamiento | `budget_tokens` | Adaptativo, guiado por `output_config.effort` |
| Beta `interleaved-thinking-2025-05-14` | Necesaria | No necesaria |

## Actualiza la solicitud

**1. Elimina los prefills del asistente.** Si rellenas de antemano el turno del asistente para forzar JSON o un prefijo, Opus 4.6 devuelve `400`. Usa en su lugar instrucciones de sistema más claras, ejemplos en el prompt o salida estructurada.

**2. Pasa la salida estructurada** de `output_format` a `output_config.format` y vuelve a ejecutar las pruebas de esquema y del analizador:

```json
{
  "model": "anthropic/claude-opus-4.6",
  "max_tokens": 1024,
  "messages": [{ "role": "user", "content": "Extract the invoice fields." }],
  "output_config": {
    "format": { "type": "json_schema", "schema": { "type": "object", "properties": { "total": { "type": "number" } } } }
  }
}
```

En `/v1/chat/completions` y `/v1/responses`, sigue usando `response_format`.

**3. Cambia el pensamiento a adaptativo.** Opus 4.6 no piensa a menos que la solicitud lo pida. En Phaseo, `reasoning.effort` o `reasoning.enabled: true` sin presupuesto de tokens activa el pensamiento adaptativo, y el esfuerzo pasa a ser `output_config.effort`. Opus 4.6 admite todos los niveles de esfuerzo excepto `xhigh`, que Phaseo envía como `max`. Mientras el pensamiento está activado, Phaseo omite `temperature` y `top_k`, y `top_p` por debajo de 0.95.

**4. Elimina los encabezados beta obsoletos** de los wrappers del SDK, el middleware y los presets. Phaseo no reenvía los encabezados `anthropic-beta`, así que ya no tienen ningún efecto.

## Qué probar

- **Prompts:** prompts largos de programación y refactorización, flujos de investigación y documentos de varios pasos, prompts que dependían de prefills y tareas de contexto largo si vas a usar la ventana de 1M.
- **Contratos y herramientas:** tasa de validación del esquema tras pasar a `output_config.format`, argumentos de las llamadas a herramientas en tareas de agente de varios pasos, reintentos cuando el modelo se niega o cambia el formato de la salida, y flujos de revisión de código y depuración.
- **Operaciones:** latencia mediana y p95 con el pensamiento activado, uso de tokens en ejecuciones más largas, tasa de tiempos de espera agotados en tareas con mucho contexto y tasa de éxito frente a Opus 4.5 en tu conjunto de evaluación.

## Despliega

1. Elimina los prefills y migra la salida estructurada antes de mover tráfico.
2. Ejecuta Opus 4.6 en modo sombra con los prompts de producción que te importan.
3. Haz un canary con Opus 4.5 como respaldo en `models`.
4. Promuévelo cuando se mantengan la tasa de validación del esquema, la latencia y la finalización de tareas.
