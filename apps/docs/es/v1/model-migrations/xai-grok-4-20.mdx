# SpaceXAI Grok 4.20

Usa esta guía para incorporar Grok 4.20 de forma segura a través de Phaseo Gateway.

Ruta principal del catálogo:

- `spacex-ai/grok-4-20-2026-02-17`

Ruta multiagente opcional, disponible con el ID de modelo del proveedor:

- `spacex-ai/grok-4.20-multi-agent-beta-0309`

## Inicio rápido de la migración

En la mayoría de las integraciones, basta con actualizar el ID del modelo y volver a ejecutar las comprobaciones habituales.

Puedes conservar los patrones actuales de solicitud y respuesta.

## Novedades

La ruta básica de Grok 4.20 no requiere cambios de comportamiento en Phaseo Gateway.

El cambio práctico está en cómo ajustar la variante multiagente.

Para usar Phaseo Gateway:

- Puedes activar o desactivar el razonamiento del Grok 4.20 básico con `reasoning.enabled`.
- Ajusta Grok 4.20 multiagente con `reasoning.effort`.
- Usa `low`, `medium`, `high` o `extra high`.
- Según la documentación de SpaceXAI, `low` y `medium` usan 4 agentes; `high` y `extra high` usan configuraciones multiagente mayores.

No enviamos `agent_count` directamente en las solicitudes de Gateway.

### Grok 4.20 básico con control de razonamiento

Usa el modelo básico y configura `reasoning.enabled` directamente:

```json
{
  "model": "spacex-ai/grok-4-20-2026-02-17",
  "input": "Explain this architecture",
  "reasoning": {
    "enabled": true
  }
}
```

### Grok 4.20 multiagente con control de esfuerzo

Usa el modelo multiagente y ajusta el nivel con `reasoning.effort`:

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta-0309",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": {
    "effort": "medium"
  }
}
```

Niveles de esfuerzo de razonamiento:

- `low`
- `medium`
- `high`
- `extra high`
