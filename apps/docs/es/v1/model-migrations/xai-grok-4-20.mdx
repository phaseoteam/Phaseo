Cambia el ID de modelo y vuelve a ejecutar tu conjunto de validación; las estructuras de solicitud y respuesta no cambian. El único control nuevo es la profundidad con la que trabaja la variante multiagente.

| Modelo | ID de modelo de Phaseo | Control del razonamiento |
| --- | --- | --- |
| Grok 4.20 | `spacex-ai/grok-4.20` | `reasoning.enabled`: activado o desactivado |
| Grok 4.20 Multi-Agent (beta) | `spacex-ai/grok-4.20-multi-agent-beta` | `reasoning.effort`: `low`, `medium` o `high` |

## Activa o desactiva el razonamiento en Grok 4.20

Define `reasoning.enabled: true` para usar la versión con razonamiento del modelo. Sin ese ajuste, o con `false`, Phaseo llama a la versión sin razonamiento.

```json
{
  "model": "spacex-ai/grok-4.20",
  "input": "Explain this architecture",
  "reasoning": { "enabled": true }
}
```

## Fija la profundidad en el modelo multiagente

Controla la profundidad con `reasoning.effort`. Las solicitudes al gateway no admiten el `agent_count` de xAI; según xAI, `low` y `medium` ejecutan 4 agentes y `high` ejecuta una configuración mayor.

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": { "effort": "medium" }
}
```
