Busca una palabra que hayas visto en el panel, en la API o en esta documentación. Cada fila da un significado en una frase, enlaza a la página que explica el término en detalle e indica dónde se aplica: API, Panel, CLI, SDK, MCP, Chat o Slack.

## Cuentas y acceso

| Término | Significado | Se aplica a |
| --- | --- | --- |
| [Administrador](./developers/management-api-keys.mdx) | Un rol del espacio de trabajo que gestiona los ajustes exclusivos de administradores, como presupuestos, reglas de gasto, guardrails y políticas de confianza, y lee el registro de auditoría. | API, Panel, CLI, MCP |
| [Espacio de trabajo](./guides/workspaces.mdx) | Un contenedor que mantiene sus propias claves de API, ajustes de enrutamiento, preajustes, guardrails y acceso de administración separados de otros espacios de trabajo. | API, Panel, CLI |
| [Miembro](./developers/management-api-keys.mdx) | Un rol del espacio de trabajo que usa el espacio de trabajo y puede ver sus reglas de gasto, pero no puede cambiar los ajustes exclusivos de propietarios y administradores. | API, Panel, CLI, MCP |
| [Propietario](./developers/management-api-keys.mdx) | Un rol del espacio de trabajo que gestiona los mismos ajustes que un administrador y recibe los correos para propietarios, como los avisos de obsolescencia de modelos. | API, Panel, CLI, MCP |

| Término | Significado | Se aplica a |
| --- | --- | --- |
| [Alternativa de BYOK](./guides/routing-and-fallbacks.mdx#byok-considerations) | Un ajuste del espacio de trabajo que decide si una solicitud BYOK fallida puede reintentarse con créditos de Phaseo. | API, Panel |
| [Aplicación OAuth](./guides/integrations/phaseo-cli.mdx#oauth-apps) | Una aplicación que inicia la sesión de las personas con Phaseo OAuth y actúa en su nombre dentro de los scopes y el espacio de trabajo que aprueban. | API, Panel, CLI, MCP |
| [BYOK](./guides/routing-and-fallbacks.mdx#byok-considerations) | Bring your own key: Phaseo enruta las solicitudes con la clave de API de tu proveedor, y el proveedor factura el uso del modelo. | API, Panel |
| [Capacidad](./developers/management-api-keys.mdx#choose-an-access-level) | Un permiso de una clave de administración o de un inicio de sesión OAuth, como `keys:write`, que decide a qué API de administración puede llamar. | API, Panel, CLI, MCP |
| [Carga de trabajo de confianza](./developers/trusted-workloads.mdx) | Un despliegue o trabajo de CI que envía el token OIDC de corta duración de su plataforma en lugar de una clave de API, y que coincide con una política de confianza. | API, Panel |
| [Clave de administración](./developers/management-api-keys.mdx) | Un secreto que empieza por `phaseo_v1_mk_` para API de administración como claves, preajustes y guardrails; no puede enviar solicitudes de inferencia. | API, Panel |
| [Clave de API](./developers/authentication.mdx#choose-a-credential) | Un secreto que empieza por `phaseo_v1_sk_` y se envía como token bearer para autenticar solicitudes de modelos y de generación. | API, Panel, CLI, SDK, MCP |

## Modelos y proveedores

| Término | Significado | Se aplica a |
| --- | --- | --- |
| [Cuantización](./guides/quantization.mdx) | Guardar los pesos de un modelo en un tipo numérico más pequeño, como `FP8` o `INT4`, que responde más rápido a cambio de algo de calidad. | API, Panel, SDK |
| [Icono de estado del proveedor](./guides/provider-statuses.mdx#status-icon) | El estado que Phaseo fija a mano para una ruta de proveedor: `Active`, `Lower priority` (solo como respaldo) o `Disabled`. | Panel |
| [ID de modelo](./api-reference/parameters.mdx#parameter-model) | El ID que envías como `model`, como `openai/gpt-6-astra`, que aparece en el inicio rápido de cada página de modelo. | API, Panel, CLI, SDK, MCP |
| [ID de modelo calificado por proveedor](./guides/provider-qualified-models.mdx) | Un ID de modelo con prefijo de proveedor, como `baseten:thinking-machines/inkling-small`, que se ejecuta en ese proveedor sin alternativa. | API, SDK |
| [Longitud de contexto](./exploring/models.mdx#what-a-model-page-shows) | El tamaño de contexto que admite una ruta de proveedor para un modelo, que se muestra para cada proveedor en la página del modelo. | API, Panel |
| [Modelo enrutable](./exploring/models.mdx#catalog-models-and-callable-models) | Un modelo con al menos una ruta de proveedor activa ahora en el Gateway; `GET /v1/models` solo lista estos de forma predeterminada. | API, Panel, MCP |
| [Modelo privado](./guides/private-models.mdx) | Un despliegue dedicado o autoalojado compatible con OpenAI que se añade a tu espacio de trabajo y que solo tu espacio de trabajo puede ver o llamar. | API, Panel |
| [Obsoleto (modelo)](./guides/model-retirement.mdx#how-a-model-is-retired) | El laboratorio o el proveedor ha anunciado la retirada del modelo, y sus solicitudes se siguen atendiendo con normalidad. | API, Panel |
| [Proveedor](./developers/introduction.mdx#models-and-providers) | Una empresa que aloja un modelo y fija su disponibilidad, los parámetros admitidos, los precios y el rendimiento. | API, Panel, SDK, MCP |
| [Retirado (modelo)](./guides/model-retirement.mdx#how-a-model-is-retired) | La fecha de retirada ya pasó; las solicitudes funcionan mientras un proveedor sirva el modelo y después fallan con `410 model_retired`. | API, Panel |

## Solicitudes y respuestas

| Término | Significado | Se aplica a |
| --- | --- | --- |
| [Caché de prompts](./guides/prompt-caching.mdx) | Mantener igual el inicio de un prompt para que el proveedor lo lea de la caché y lo facture a la tarifa de lectura de caché. | API, SDK |
| [Esfuerzo de razonamiento](./api-reference/parameters.mdx#parameter-reasoning) | Cuánto piensa un modelo de razonamiento antes de responder, fijado con `reasoning.effort` o `reasoning_effort`, de `none` a `max`. | API, SDK |
| [Gateway](./developers/introduction.mdx) | La API de Phaseo en `https://api.phaseo.app/v1`, que enruta cada solicitud a un proveedor que aloja el modelo. | API, SDK |
| [ID de generación](./api-reference/endpoint/generation.mdx) | El ID de solicitud que empieza por `G-`, devuelto en `x-request-id` y en los cuerpos de error; úsalo para registros, búsquedas y soporte. | API, Panel, SDK |
| [ID de sesión](./guides/routing-and-fallbacks.mdx#keep-a-conversation-on-one-provider) | Un `session_id` que envías para mantener las solicitudes de una conversación en un proveedor, durante hasta 24 horas de actividad. | API, Panel, SDK |
| [Nivel de servicio](./guides/service-tiers.mdx) | Un nivel de velocidad y precio para una solicitud de texto (`standard`, `fast`, `ultrafast` o `flex`), que solo atienden los proveedores que lo ofrecen. | API, SDK |
| [Objeto usage](./guides/prompt-caching.mdx#usage-and-pricing-fields) | El campo `usage` de una respuesta, que indica los recuentos de tokens de entrada, salida y caché de la solicitud. | API, SDK |
| [Streaming](./guides/streaming.mdx) | Fijar `stream: true` para que el Gateway envíe la salida como server-sent events mientras el modelo la escribe. | API, SDK |
| [Tokens](./guides/context-and-token-budgeting.mdx) | Las unidades que un modelo lee como entrada y escribe como salida; cada token añade latencia y coste. | API, Panel, SDK |
| [Tokens de razonamiento](./guides/context-and-token-budgeting.mdx#what-counts-towards-a-request) | Tokens que un modelo de razonamiento gasta antes de responder; cuentan como salida y usan parte del límite de salida. | API, SDK |
| [Tokens en caché](./guides/prompt-caching.mdx#usage-and-pricing-fields) | Tokens de entrada que el proveedor leyó de su caché de prompts, facturados a la tarifa de lectura de caché e indicados como `cached_tokens`. | API, SDK |

## Enrutamiento

| Término | Significado | Se aplica a |
| --- | --- | --- |
| [Alternativa de proveedor](./guides/routing-and-fallbacks.mdx) | Cuando el proveedor elegido falla, el Gateway prueba el siguiente proveedor válido para el mismo modelo. | API, SDK |
| [Alternativas de modelo](./guides/routing-and-fallbacks.mdx#request-level-model-fallbacks) | Modelos indicados en `models`, que se prueban en orden cuando el modelo anterior termina con `429`, `500`, `502`, `503` o `504`. | API, SDK |
| [Canales de proveedores Alpha y Beta](./guides/routing-and-fallbacks.mdx#choose-how-providers-are-ranked) | Interruptores de los ajustes de enrutamiento para que los proveedores en vista previa solo reciban tráfico si lo activas; `provider.include_alpha` permite proveedores Alpha por solicitud. | API, Panel |
| [Enrutador gratuito](./cookbook/free-router-first-deploy.mdx) | Envía `phaseo/free` y Phaseo ejecuta la solicitud en un modelo gratuito disponible, sin necesidad de créditos. | API, SDK |
| [Enrutamiento automático](./guides/auto-routing.mdx) | Envía `phaseo/auto` y Phaseo elige un modelo para cada solicitud a partir de la carga de trabajo, tu objetivo y tus límites de precio. | API, Panel, CLI, SDK, Slack |
| [Enrutamiento de modelos retirados](./guides/model-retirement.mdx#route-requests-to-a-replacement-automatically) | Un ajuste opcional del espacio de trabajo que envía las solicitudes de un modelo que ningún proveedor sirve a un sustituto aprobado o elegido. | API, Panel |
| [Enrutamiento regional](./guides/regional-routing.mdx) | Enviar solicitudes de texto a `eu.api.phaseo.app` o `us.api.phaseo.app` para usar solo rutas que se ejecutan allí. | API, SDK |
| [Etiqueta de versión de preajuste](./guides/prompt-templates.mdx#labels) | Un nombre como `production` que apunta a una versión publicada de un preajuste; al moverla, las solicitudes avanzan o vuelven a otra versión. | API, Panel, SDK |
| [Orden de proveedores](./guides/routing-and-fallbacks.mdx#choose-how-providers-are-ranked) | Cómo se clasifican los proveedores: `balanced` (predeterminado, coste por respuesta correcta), `price`, `latency` o `throughput`. | API, Panel, CLI, SDK |
| [Plantilla de prompt](./guides/prompt-templates.mdx) | Mensajes de un preajuste con `{{variables}}`, para que cada solicitud envíe solo la referencia al preajuste y los valores de las variables. | API, Panel, SDK |
| [Preajuste](./guides/presets.mdx) | Un modelo guardado con prompt de sistema, parámetros y reglas de proveedor, que quien llama usa enviando su nombre, como `@support-triage`. | API, Panel, SDK |
| [Ruta dinámica](./guides/routing-and-fallbacks.mdx#attach-routing-rules-to-api-keys) | Un flujo versionado de reglas asociado a claves de API que puede ramificarse, repartir el tráfico, limitar el uso y cambiar de modelo. | API, Panel |

| Término | Significado | Se aplica a |

| [Alerta de gasto](./guides/spend-alerts.mdx#alert-types-and-bases) | La notificación que envía una regla de gasto cuando el gasto, una previsión, un pico o el saldo cruza su umbral. | API, Panel |

## Fases de las funciones

| Término | Significado | Se aplica a |
| --- | --- | --- |
| [Alpha](./developers/feature-maturity.mdx) | Una función temprana que puede cambiar mucho o eliminarse. | API, Panel, CLI, SDK, MCP, Chat, Slack |
| [Bajo solicitud](./developers/feature-maturity.mdx#who-can-use-a-feature) | Una función que se activa por espacio de trabajo; hasta entonces, su página de ajustes está oculta y su API devuelve un error. | API, Panel |
| [Beta](./developers/feature-maturity.mdx) | Una función que sirve para su uso principal, aunque algunos detalles pueden cambiar; los cambios se anuncian en el registro de cambios. | API, Panel, CLI, SDK, MCP, Chat, Slack |
| [Disponibilidad general](./developers/feature-maturity.mdx) | Una función estable, que se muestra sin insignia de fase. | API, Panel, CLI, SDK, MCP, Chat, Slack |
| [Obsoleta (función)](./developers/feature-maturity.mdx) | Una función que sigue funcionando pero se eliminará; su página da la fecha de eliminación cuando se fija una. | API, Panel, CLI, SDK, MCP, Chat, Slack |
| [Vista previa de funciones](./developers/feature-maturity.mdx#who-can-use-a-feature) | La página de ajustes que muestra si la API de vídeo y la API de lotes están activadas en tu espacio de trabajo. | Panel |
