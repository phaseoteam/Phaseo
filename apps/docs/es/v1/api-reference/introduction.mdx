Envía todas las solicitudes a `https://api.phaseo.app/v1` con tu clave en un encabezado `Authorization: Bearer`. Busca abajo el endpoint para tu tarea y abre su página de referencia.

## Encuentra el endpoint adecuado

| Si quieres | Empieza por |
| --- | --- |
| Enviar tu primera solicitud | [Guía de inicio rápido](../quickstart) |
| Generar texto o usar herramientas | [`POST /responses`](./endpoint/responses) |
| Tomar decisiones tipadas | [`POST /decisions`](./endpoint/decisions) |
| Mantener una integración existente compatible con OpenAI | [`POST /chat/completions`](./endpoint/chat-completions) |
| Explorar modelos y proveedores | [`GET /models`](./endpoint/models) y [`GET /providers`](./endpoint/providers) |
| Crear música o gestionar archivos | [`POST /music/generate`](./endpoint/music-generate) y [`POST /files`](./endpoint/files) |
| Generar vídeo (Beta) | [`POST /videos`](./endpoint/video-create) |
| Enviar un lote o descargar resultados (Beta) | [`POST /batches`](./endpoint/batches-create) y [`GET /batches/{batch_id}/results`](./endpoint/batches-results) |

## URL base

```http
https://api.phaseo.app/v1
```

Todas las rutas de endpoints de esta referencia son relativas a esta URL base.

## Autenticación

| Credencial | Formato | Llama a |
| --- | --- | --- |
| [Clave de API del Gateway](../developers/authentication.mdx) | `phaseo_v1_sk_<kid>_<secret>` | Endpoints de inferencia |
| [Clave de API de administración](../developers/management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | Endpoints de administración, limitados a los permisos de la clave |

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

Si falla la autenticación, la API devuelve `401`.

## Recursos de la API

| Recurso | Función |
| --- | --- |
| Inferencia | Genera texto, imágenes, audio y embeddings; toma decisiones, reordena, modera o analiza contenido. Empieza con [Responses](./endpoint/responses.mdx) o [Decisions](./endpoint/decisions.mdx). |
| Trabajos asíncronos y archivos | Envía trabajos de [vídeo](./endpoint/video-create.mdx) o de [lotes](./endpoint/batches-create.mdx), transfiere archivos y configura webhooks. |
| Modelos y precios | Descubre [modelos](./endpoint/models.mdx), ofertas de proveedores y [costes estimados](./endpoint/pricing-calculate.mdx). |
| Enrutamiento y políticas | Configura presets, credenciales de proveedores, modelos privados y [guardrails](./endpoint/guardrails.mdx). |
| Uso y supervisión | Revisa [registros](./endpoint/logs-list.mdx), actividad, analítica, evaluaciones y estado del servicio. |
| Administración de espacios de trabajo | Gestiona [espacios de trabajo](./endpoint/workspaces-list.mdx), claves, presupuestos, identidades e integraciones. |

## Facturación y límites de solicitudes

Las solicitudes de pago necesitan saldo suficiente en la cartera para superar una comprobación de crédito antes de ejecutarse. Los modelos cuyo ID termina en `:free` no necesitan créditos depositados. Un proveedor, o los límites del espacio de trabajo y de la clave, pueden limitar las solicitudes; consulta [Límites de solicitudes](./limits.mdx).
