openapi: "/es/openapi/v1/openapi.localized.yaml POST /presets/{id}/upstream"
description: "Aplicar una versión pública previa al borrador de una bifurcación local."
---
<Note>Este endpoint requiere una clave de API de gestión con `presets:write` y una identidad de usuario asociada.</Note>

Publica o descarta los cambios del borrador local antes de aplicar una versión previa. La aplicación no publica el borrador resultante.
