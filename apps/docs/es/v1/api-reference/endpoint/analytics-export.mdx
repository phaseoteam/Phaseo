---
title: "Exportar analíticas del espacio de trabajo"
sidebarTitle: "Exportar analíticas"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml GET /analytics/export"
description: "Exporta analíticas filtradas del espacio de trabajo como CSV."
---
<Note>Este endpoint requiere una clave de API de gestión con `analytics:read`.</Note>

La exportación admite los mismos filtros que el endpoint de analíticas y devuelve todas las filas agregadas coincidentes en formato CSV seguro para hojas de cálculo.
