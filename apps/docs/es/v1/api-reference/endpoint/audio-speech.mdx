## Elige una voz

Configura `voice` en el nivel superior para que las solicitudes sean portables. Phaseo lo asigna a la voz del proveedor enrutado; un `voice` que el proveedor y el modelo enrutados no aceptan devuelve `400 invalid_request_error` con `param: "voice"`.

| Proveedor | Valores de `voice` aceptados | Muestras |
| --- | --- | --- |
| `openai` | Voces comunes, por ejemplo `alloy`, `ash`, `ballad`, `coral`, `echo`, `fable`, `onyx`, `nova`, `sage`, `shimmer`, `verse`, `cedar`, `marin` | [openai.fm](https://www.openai.fm/) |
| `google` (AI Studio / Gemini TTS) | Voces predefinidas: `Zephyr`, `Puck`, `Charon`, `Kore`, `Fenrir`, `Leda`, `Orus`, `Aoede`, `Callirrhoe`, `Autonoe`, `Enceladus`, `Iapetus`, `Umbriel`, `Algieba`, `Despina`, `Erinome`, `Algenib`, `Rasalgethi`, `Laomedeia`, `Achernar`, `Alnilam`, `Schedar`, `Gacrux`, `Pulcherrima`, `Achird`, `Zubenelgenubi`, `Vindemiatrix`, `Sadachbia`, `Sadaltager`, `Sulafat` | [Documentación de texto a voz de Gemini](https://ai.google.dev/gemini-api/docs/speech-generation#voices) |
| `elevenlabs` | Voces públicas iniciales comunes, por ejemplo `rachel`, `domi`, `bella`, `antoni`, `elli`, `josh`, `arnold`, `adam`, `sam` | [ElevenLabs Voice Library](https://elevenlabs.io/voice-library) |

Para `eleven-labs/eleven-v4` y `eleven-labs/eleven-v4-turbo`, pasa cualquier ID de 20 caracteres de la biblioteca de voces de ElevenLabs, incluido un clon personalizado. Configura `config.elevenlabs.voice_settings.stability` y `similarity_boost` según lo necesites. Eleven v4 no admite `speed` ni `voice_settings.style`.

## Pasa una voz nativa del proveedor

Para usar el ajuste de voz propio de un proveedor en lugar de `voice`:

- ElevenLabs: `config.elevenlabs.voice_id`, `config.elevenlabs.voice` o `config.elevenlabs.voiceName`.
- Google: `config.google.voice_name` o `config.google.voiceName`.
