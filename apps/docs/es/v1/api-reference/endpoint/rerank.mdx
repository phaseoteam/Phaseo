---

Usa este endpoint para reordenar los documentos candidatos antes de pasarlos a una búsqueda, recuperación o paso de generación.

Verifica el modelo en `GET /v1/models` antes del despliegue. La respuesta predeterminada solo contiene modelos con una ruta pública de Gateway.
