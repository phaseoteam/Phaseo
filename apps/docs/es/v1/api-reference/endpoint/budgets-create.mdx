openapi: "/es/openapi/v1/openapi.localized.yaml POST /budgets"
description: "Crea un límite de gasto diario, semanal, mensual o vitalicio para el espacio de trabajo."
---

Requiere `budgets:write`. Los importes se expresan en USD. Un espacio de trabajo puede tener un presupuesto por intervalo; crear un segundo devuelve `409` `conflict`.
