openapi: "/es/openapi/v1/openapi.localized.yaml DELETE /workspaces/{id}"
description: "Elimina un espacio de trabajo por su ID o slug."
---
<Note>Este endpoint requiere una clave de API de gestión. No se aceptan las claves de API estándar de la pasarela.</Note>

No se puede eliminar el espacio de trabajo predeterminado. Primero hay que limpiar los espacios de trabajo que tengan claves de API activas.
