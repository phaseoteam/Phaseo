---
title: "Eliminar un modelo privado"
sidebarTitle: "Eliminar un modelo privado"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml DELETE /private-models/{id}"
description: "Elimina un endpoint de modelo privado del espacio de trabajo."
---

Requiere `private_models:delete` y una identidad de propietario o administrador. Las solicitudes existentes que utilicen el ID del modelo dejarán de resolverse.
