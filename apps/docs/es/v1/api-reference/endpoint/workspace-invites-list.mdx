title: "Listar invitaciones del espacio de trabajo"
sidebarTitle: "Listar invitaciones"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml GET /workspaces/{id}/invites"
description: "Muestra los metadatos de las invitaciones del espacio de trabajo."
---
Este endpoint requiere una clave de API de gestión con `workspaces:read`.

Solo se devuelve una vista previa enmascarada del token. Los tokens de invitación en texto sin formato no se pueden recuperar más adelante.
