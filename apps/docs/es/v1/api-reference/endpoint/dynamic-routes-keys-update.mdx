---
title: "Reemplazar claves de ruta dinámica"
sidebarTitle: "Asociar claves"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml PUT /routing/dynamic-routes/{id}/keys"
description: "Reemplaza de forma atómica las claves de API asociadas a una ruta dinámica."
---
<Note>Este endpoint requiere una clave de API de gestión con `settings:write`.</Note>

Todas las claves deben pertenecer al espacio de trabajo de la clave de gestión. Una clave solo puede asociarse a una ruta dinámica.
