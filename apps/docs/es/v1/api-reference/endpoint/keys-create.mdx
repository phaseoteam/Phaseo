<Note>
Este endpoint requiere una clave de API de gestión. No se aceptan las claves de API estándar de Gateway.
</Note>

La clave de API en texto sin formato se devuelve una sola vez, al crearla. Se aceptan los campos de compatibilidad `limit`, `limit_reset` e `include_byok_in_limit`; actualmente, Phaseo trata `include_byok_in_limit` solo por compatibilidad y siempre excluye BYOK del límite de esta clave.
