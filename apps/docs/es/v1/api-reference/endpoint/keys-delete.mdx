---
title: "Eliminar clave de API"
sidebarTitle: "Eliminar clave de API"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml DELETE /keys/{id}"
description: "Elimina una clave de API del espacio de trabajo autenticado."
---
<Note>Este endpoint requiere una clave de API de gestión. No se aceptan las claves de API estándar de la pasarela.</Note>

La eliminación es permanente desde la perspectiva de la API pública. La respuesta confirma que se eliminó la clave.
