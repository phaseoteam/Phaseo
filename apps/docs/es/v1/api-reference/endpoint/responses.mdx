## Usa herramientas del servidor

Añade una herramienta `phaseo:` a `tools` junto a tus propias herramientas de función, y Phaseo la ejecuta cuando el modelo la llama. `/v1/responses` acepta todas las herramientas del servidor, incluida `phaseo:apply_patch`, que solo admite este endpoint; la guía de [Herramientas del servidor](../../guides/server-tools) las enumera.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": [
      { "role": "user", "content": "Give me the current datetime in Asia/Tokyo." }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["Asia/Tokyo"] } }
    ],
    "tool_choice": "auto"
  }'
```

Cada llamada a una herramienta del servidor se cuenta en `usage.server_tool_use`:

| Herramienta | Contadores |
| --- | --- |
| `phaseo:datetime` | `datetime_requests` |
| `phaseo:web_search` | `web_search_requests`, `web_search_results`, `web_search_extra_results` |
| `phaseo:web_fetch` | `web_fetch_requests` |
| `phaseo:advisor` | `advisor_requests` |
| `phaseo:subagent` | `subagent_requests` |
| `phaseo:fusion` | `fusion_requests` |
| `phaseo:search_models` | `search_models_requests` |
| `phaseo:image_generation` | `image_generation_requests` |
| `phaseo:apply_patch` | `apply_patch_requests` |

El tipo antiguo `gateway:datetime` sigue funcionando. Con `stream: true`, Phaseo ejecuta los turnos de herramientas por su cuenta y después te transmite la respuesta continuada como un único stream.

## Razonamiento en bucles de herramientas

En OpenAI, Azure OpenAI y xAI, Phaseo envía las solicitudes de Responses al proveedor con `store: false`, así que el razonamiento de un modelo continúa entre los pasos de un bucle de herramientas solo a través de los elementos de salida `reasoning`.

Cada elemento `reasoning` tiene `id`, `summary` y `content`. Cuando el proveedor devuelve estado de razonamiento, el elemento también tiene `encrypted_content`, que contiene uno de estos:

- El razonamiento cifrado de OpenAI, Azure OpenAI y xAI. Phaseo lo solicita con `include: ["reasoning.encrypted_content"]` para los modelos de razonamiento.
- Las firmas de pensamiento y el pensamiento censurado de Claude.
- Las firmas de pensamiento de Gemini, incluido un elemento `reasoning` aparte colocado justo antes de la llamada a función a la que pertenece una firma.

Las respuestas con streaming incluyen los mismos elementos en `response.output_item.done` y `response.completed`.

Para continuar un bucle de herramientas, devuelve todos los elementos de salida en `input`, incluidos los elementos `reasoning`, sin cambios. `encrypted_content` es opaco y registra el proveedor y el modelo que lo generaron. Phaseo solo lo envía a esa familia de proveedor y a ese modelo, así que un fallback a otro proveedor lo descarta en lugar de fallar.
