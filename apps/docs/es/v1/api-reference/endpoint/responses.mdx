## Herramientas del servidor

`/v1/responses` admite herramientas de funciones habituales y estas herramientas de servidor administradas por Gateway:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`
- `phaseo:apply_patch`

### Ejemplo de fecha y hora

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "input": [
      { "role": "user", "content": "Give me the current datetime in Asia/Tokyo." }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Asia/Tokyo" }
      }
    ],
    "tool_choice": "auto"
  }'
```

Cuando se usa una herramienta del servidor, los datos de uso incluyen los contadores correspondientes de `usage.server_tool_use.*`.

- `gateway:datetime` -> `datetime_requests`
- `phaseo:web_search` -> `web_search_requests`, `web_search_results`, `web_search_extra_results`
- `phaseo:web_fetch` -> `web_fetch_requests`
- `phaseo:advisor` -> `advisor_requests`
- `phaseo:image_generation` -> `image_generation_requests`
- `phaseo:apply_patch` -> `apply_patch_requests`

## Nota sobre el streaming

También se admite `stream: true`. Para las herramientas de servidor administradas por Gateway, Phaseo puede materializar el turno de llamada a la herramienta upstream, continuar el ciclo y volver a emitir un flujo sintético.

## Razonamiento en ciclos de herramientas

Phaseo envía las solicitudes de Responses al proveedor con `store: false`, así que el razonamiento de un modelo continúa entre los pasos de un ciclo de herramientas solo a través de los elementos de salida `reasoning`.

Cada elemento `reasoning` tiene `id`, `summary` y `content`. Cuando el proveedor devuelve estado de razonamiento, el elemento también tiene `encrypted_content`:

- Razonamiento cifrado de OpenAI, Azure OpenAI y xAI. Phaseo lo solicita con `include: ["reasoning.encrypted_content"]` para los modelos de razonamiento.
- Firmas de thinking de Claude y thinking censurado.
- Firmas de pensamiento de Gemini, incluido un elemento `reasoning` propio justo antes de la llamada a función a la que pertenece una firma.

Las respuestas con streaming llevan los mismos elementos en `response.output_item.done` y `response.completed`.

Para continuar un ciclo de herramientas, devuelva todos los elementos de salida en `input` sin cambios, incluidos los elementos `reasoning`. `encrypted_content` es opaco y registra el proveedor y el modelo que lo generaron. Phaseo lo envía solo a esa familia de proveedores y a ese modelo, así que un fallback a otro proveedor lo descarta en lugar de fallar.
