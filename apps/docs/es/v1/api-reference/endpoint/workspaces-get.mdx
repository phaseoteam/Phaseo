badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml GET /workspaces/{id}"
description: "Obtiene un espacio de trabajo por su ID o slug."
---
Este endpoint requiere una clave de API de gestión. No se aceptan las claves de API estándar de la pasarela.

El segmento de ruta `{id}` puede ser el UUID o el slug del espacio de trabajo.
