title: "Crear una clave de gestión"
sidebarTitle: "Crear una clave de gestión"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml POST /management-keys"
description: "Crear una clave de gestión con ámbitos para automatizar el plano de control."
---
<Note>Este endpoint requiere una identidad de propietario o administrador y `management_keys:write`.</Note>

Elige una plantilla de capacidades o proporciona una lista explícita de ámbitos. La `key` sin procesar solo se devuelve en la respuesta de creación; guárdala de inmediato en un almacén de secretos del servidor.
