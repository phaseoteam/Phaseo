sidebarTitle: "Obtener configuración"

openapi: "/es/openapi/v1/openapi.localized.yaml GET /settings"
description: "Obtiene los valores predeterminados de enrutamiento, proveedor, privacidad y pasarela del espacio de trabajo."
---
<Note>Este endpoint requiere una clave de API de gestión con `settings:read`.</Note>

Usa este endpoint para consultar los mismos valores predeterminados persistentes del espacio de trabajo que utilizan el panel y la pasarela.
