description: "Recuperar una clave de API por su ID o hash."
---
<Note>
Este endpoint requiere una clave de API de gestión. No se aceptan las claves de API estándar de Gateway.
</Note>

Devuelve los metadatos de una clave de API del espacio de trabajo autenticado. El segmento de ruta `{id}` puede ser el ID interno de la clave o el hash que devuelve la API.
