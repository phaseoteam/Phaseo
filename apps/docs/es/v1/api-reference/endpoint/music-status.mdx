Pasa el `id` que devolvió [`POST /v1/music/generate`](./music-generate.mdx), no su `nativeResponseId`. Phaseo devuelve el resultado guardado cuando la generación ha terminado, y consulta al proveedor por ti mientras sigue en curso.

```bash
curl https://api.phaseo.app/v1/music/generate/req_01JY6MUSIC123 \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "suno",
  "model": "V4_5PLUS",
  "nativeResponseId": "task_123",
  "output": [
    {
      "index": 0,
      "id": "clip_1",
      "audio_url": "https://...",
      "stream_audio_url": "https://...",
      "image_url": "https://...",
      "title": "Midnight Blue",
      "tags": "jazz, piano",
      "duration": 8
    }
  ],
  "usage": {
    "output_audio_count": 1,
    "output_audio_seconds": 8
  }
}
```

`status` es `queued`, `in_progress`, `completed` o `failed`. `usage` se incluye cuando la generación se ha completado.
