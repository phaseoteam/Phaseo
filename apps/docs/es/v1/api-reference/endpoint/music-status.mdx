Recupera un resultado musical creado con `POST /music/generate`. Este endpoint devuelve el resultado normalizado guardado cuando el proveedor terminó y consulta al proveedor de origen si el trabajo sigue siendo asíncrono.

## Estructura de la respuesta

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "suno",
  "model": "V4_5PLUS",
  "nativeResponseId": "task_123",
  "output": [
    {
      "index": 0,
      "id": "clip_1",
      "audio_url": "https://...",
      "stream_audio_url": "https://...",
      "image_url": "https://...",
      "title": "Midnight Blue",
      "tags": "jazz, piano",
      "duration": 8
    }
  ],
  "usage": {
    "output_audio_count": 1,
    "output_audio_seconds": 8
  }
}
```

## Notas

- `status` puede ser: `queued`, `in_progress`, `completed` o `failed`.
- `usage` se incluye cuando termina la generación.
- Envía el `id` de Phaseo que devuelve `POST /music/generate`, no `nativeResponseId`.
- Este endpoint gestiona internamente las API de estado y recuperación específicas de cada proveedor.
