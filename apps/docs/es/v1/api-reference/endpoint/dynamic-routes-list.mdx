title: "Listar rutas dinámicas"
sidebarTitle: "Listar rutas"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml GET /routing/dynamic-routes"
description: "Muestra rutas dinámicas, versiones y claves de API adjuntas."
---
<Note>Este endpoint requiere una clave de API de gestión con `settings:read`.</Note>

Cada ruta incluye su versión de borrador actual, la versión implementada, el historial de versiones inmutable y los ID de las claves de API adjuntas.
