---
title: "API de barreras de protección"
sidebarTitle: "Descripción general"
description: "Gestión programática de barreras de protección para espacios de trabajo y claves."
---
<Info>
La gestión de barreras de protección requiere una clave de API de gestión. Las operaciones de lectura requieren `guardrails:read`; las modificaciones requieren `guardrails:write` o `guardrails:delete`.
</Info>

Usa las barreras de protección para aplicar controles de privacidad, restricciones de proveedores y modelos, tratamiento de inyecciones de instrucciones, políticas de información confidencial y límites de solicitudes o costes. Puedes asignar una barrera a claves de API, miembros del espacio de trabajo o ambos.

Las modificaciones correctas actualizan el estado de las políticas del espacio de trabajo y aparecen en su registro de auditoría.
