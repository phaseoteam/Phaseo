description: "Lista los endpoints del gateway respaldados por capacidades, con sus rutas públicas y su cobertura de modelos y proveedores."
---

La respuesta tiene tres campos:

- `endpoints`: los IDs canónicos de los endpoints que expone la API actualmente.
- `data`: un registro por endpoint con `id`, `capability_id`, `public_path`, `collection`, `model_count` y `provider_count`, ordenados por `public_path`.
- `sample_models`: los 10 primeros IDs de modelos visibles del catálogo público.

La respuesta se guarda en caché durante 30 minutos.

Usa [Listar las capacidades de endpoints del modelo](./model-endpoints) cuando necesites detalles a nivel de proveedor y de parámetro para un modelo.
