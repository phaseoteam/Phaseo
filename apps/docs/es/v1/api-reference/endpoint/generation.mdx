Recupera el registro de auditoría almacenado para un `request_id` de tu equipo.

Las nuevas solicitudes reciben un ID de generación `G-` creado por el servidor, devuelto en la cabecera de respuesta `x-request-id` y en la respuesta de generación. Úsalo para los registros, las consultas y el soporte. Un `x-request-id` enviado por el cliente no sustituye este ID. Los ID UUID de registros anteriores siguen siendo válidos para consultas.

Usa:
- `GET /v1/generations?id=<request_id>`

Si la pasarela capturó todos los detalles de la solicitud de esa generación, la respuesta también incluye:

- `replay_supported`: indica si hay disponible una carga útil lista para reproducir
- `replay_request`: el cuerpo de la solicitud guardado que puedes volver a enviar al endpoint original para repetirla de forma controlada

Flujo habitual para repetir una solicitud:

1. Lee el registro de generación con `GET /v1/generations?id=<request_id>`.
2. Comprueba que `replay_supported === true`.
3. Vuelve a enviar `replay_request` al endpoint original indicado por `endpoint`, como `/v1/chat/completions` o `/v1/responses`.
