Envía un payload de uso para calcular su precio con las reglas de precios activas del gateway para un proveedor, un modelo y un endpoint. Los cuatro campos son obligatorios:

- `provider`: el ID del proveedor, por ejemplo `openai`.
- `model`: el ID del modelo enrutado.
- `endpoint`: la familia del endpoint, por ejemplo `responses` o `chat.completions`.
- `usage`: el uso que se valora, como recuentos de tokens u otras entradas de medición.

Para listar los precios actuales en lugar de calcular el de un payload, usa [Listar precios de modelos](./pricing-models.mdx).
