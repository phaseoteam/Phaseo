title: "Actualizar borrador de ajuste preestablecido"
sidebarTitle: "Actualizar ajuste preestablecido"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml PATCH /presets/{id}"
description: "Actualiza los metadatos y la configuración del borrador del ajuste preestablecido."
---
<Note>Este endpoint requiere una clave de API de gestión con `presets:write`.</Note>

Usa `replace_config` para reemplazar toda la configuración del borrador. De lo contrario, los campos de configuración proporcionados se combinan en el nivel superior.
