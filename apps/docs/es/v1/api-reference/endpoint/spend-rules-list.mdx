description: "Lista las reglas de gasto del espacio de trabajo y el límite de 50 reglas."

Requiere `spend_rules:read`. Todos los miembros del espacio de trabajo pueden leer las reglas de gasto. Consulta la [guía de alertas de gasto](../../guides/spend-alerts.mdx) para saber cómo se evalúan las reglas.
