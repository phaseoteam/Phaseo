Envía un `model` y un `prompt` a `POST /v1/music/generate` para obtener una pista de cualquier proveedor de música con una única forma de solicitud. Phaseo se encarga de los proveedores síncronos y de consultar las colas de los proveedores por ti.

```bash
curl https://api.phaseo.app/v1/music/generate \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax/music-3.0:free",
    "prompt": "Warm jazz trio with brushed drums",
    "format": "mp3"
  }'
```

## Lee el resultado

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "gmicloud",
  "model": "minimax/music-3.0:free",
  "nativeResponseId": "5c30b275-d669-4a25-8151-de6d60214853",
  "audio_url": "https://.../generated-music.mp3",
  "usage": {
    "requests": 1,
    "output_audio_seconds": 25.364
  }
}
```

Una generación completada incluye `audio_url` o `audio_base64`. `status` es `queued`, `in_progress`, `completed` o `failed`. Si aún no es definitivo, consulta [`GET /v1/music/generate/{music_id}`](./music-status.mdx) con el mismo `id`.

`id` es el ID de solicitud estable de Phaseo. `nativeResponseId` es el identificador del proveedor, para correlacionar con el proveedor y para soporte. `usage` incluye `output_audio_seconds` cuando el proveedor informa de la duración generada.

## Configura las opciones de Suno

Los modelos de Suno aceptan un objeto `suno` opcional:

| Campo | Tipo | Notas |
| --- | --- | --- |
| `customMode` | boolean | Predeterminado `false` |
| `instrumental` | boolean | Predeterminado `false` |
| `prompt` | string | Sustituye el `prompt` de nivel superior |
| `style`, `title` | string | Obligatorios cuando `customMode` es `true` |
| `personaId`, `personaModel` | string | |
| `negativeTags` | string | |
| `vocalGender` | `m` o `f` | |
| `styleWeight`, `weirdnessConstraint`, `audioWeight` | number | De 0 a 1 |

`prompt` es obligatorio cuando `customMode` es `false`, y cuando `customMode` es `true` con `instrumental` en `false`.

Una solicitud que incumple una regla del proveedor devuelve `400`:

```json
{
  "error": "validation_error",
  "reason": "..."
}
```
