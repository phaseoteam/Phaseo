Envía un payload de la API Anthropic Messages a `/v1/messages` y recibe una respuesta con formato de Anthropic, para cualquier modelo que enrute Phaseo. Se admiten los campos de uso de herramientas de Anthropic, y el encabezado `X-Phaseo-Strictness` controla cómo se tratan los parámetros no admitidos.

Configura `stream: true` para recibir server-sent events en formato de Anthropic (`message_start`, `content_block_*`, `message_delta`, `message_stop`). El streaming también funciona en bucles de herramientas.

## Mensajes de sistema a mitad de la conversación

Añade un mensaje `role: "system"` a `messages` para una instrucción que se aplica desde ese punto de la conversación. El campo `system` de nivel superior no cambia, así que un prefijo en caché sigue acertando.

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5.5",
    "max_tokens": 512,
    "system": "You are a code review assistant.",
    "messages": [
      { "role": "user", "content": "Review process() in utils.py." },
      { "role": "assistant", "content": "The loop is fine; the regex is compiled on every call." },
      { "role": "user", "content": "Now review the code that calls it." },
      { "role": "system", "content": "From now on, include type annotations in every suggestion." }
    ]
  }'
```

Un mensaje de sistema acepta una cadena o bloques de texto. Debe ir justo después de un turno del usuario (o de un turno del asistente que termine en un resultado de herramienta del servidor) y ser el último mensaje o ir seguido de un turno del asistente. Las demás posiciones devuelven `400`. No se admiten `clear_at`, `output_config` ni los bloques `tool_addition` o `tool_removal`.

| Modelo | Cómo recibe el mensaje de sistema |
| --- | --- |
| Claude Fable 5 y 5.1, Mythos 5 y 5.1, Opus 4.8, Opus 5 y 5.5, Sonnet 5.5, Haiku 5.5 | En su posición |
| Otros modelos de Claude, incluido Sonnet 5, y todos los modelos de Claude en Microsoft Foundry | Fusionado con el prompt de sistema de nivel superior |
| Modelos de otros proveedores | Como mensaje de sistema, igual que uno enviado a Chat Completions |

## Usa herramientas del servidor

Añade una herramienta `phaseo:` a `tools` y Phaseo la ejecuta cuando el modelo la llama: la reescribe al formato de herramientas de Anthropic para el proveedor y continúa el bucle de herramientas en el servidor. `/v1/messages` acepta todas las herramientas del servidor excepto `phaseo:apply_patch`; la guía de [Herramientas del servidor](../../guides/server-tools) las enumera.

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "What time is it in America/New_York right now?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["America/New_York"] } }
    ],
    "tool_choice": { "type": "auto" }
  }'
```

Las llamadas a herramientas del servidor se cuentan en `usage.server_tool_use`. El tipo antiguo `gateway:datetime` sigue funcionando. Con `stream: true`, Phaseo ejecuta los turnos de herramientas por su cuenta y después te transmite la respuesta continuada como un único stream.

## Usa la búsqueda web nativa de Anthropic

Cuando el modelo y el proveedor de Anthropic enrutados admiten la búsqueda web nativa, pasa directamente la definición de herramienta de Anthropic, por ejemplo `type: "web_search_20250305"`. El enrutamiento de proveedores sigue filtrando por compatibilidad con `web_search_options` antes de la ejecución.

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "Find the latest Anthropic web search guidance." }
    ],
    "tools": [
      {
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": 3,
        "allowed_domains": ["docs.anthropic.com"]
      }
    ],
    "tool_choice": { "type": "auto" }
  }'
```
