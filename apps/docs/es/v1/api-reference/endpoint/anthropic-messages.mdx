`/v1/messages` acepta cargas de solicitud de la API Anthropic Messages y devuelve respuestas con formato Anthropic.

## Transmisión

Establece `stream: true` para recibir eventos enviados por el servidor en formato Anthropic (`message_start`, `content_block_*`, `message_delta`, `message_stop`).

## Notas

- Se admiten los campos de uso de herramientas de Anthropic.
- `stream: true` también funciona con ciclos de herramientas. Para las herramientas de servidor administradas por Gateway, Phaseo puede materializar el turno upstream, continuar el ciclo y volver a emitir un flujo sintético.
- El formato nativo de la herramienta de búsqueda web de Anthropic también se acepta directamente en `tools`, por ejemplo `type: "web_search_20250305"`.
- El encabezado `X-Phaseo-Strictness` controla cómo se gestionan los parámetros no compatibles.

## Herramientas del servidor

`/v1/messages` también admite estas herramientas de servidor administradas por Gateway:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

Phaseo convierte estas herramientas al formato compatible con Anthropic para el proveedor upstream, las ejecuta en el servidor y continúa el ciclo de herramientas.

## Búsqueda web nativa del proveedor

Cuando un par compatible de modelo y proveedor Anthropic admite búsqueda web nativa, también puedes pasar directamente esta definición de herramienta:

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-4",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "Find the latest Anthropic web search guidance." }
    ],
    "tools": [
      {
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": 3,
        "allowed_domains": ["docs.anthropic.com"]
      }
    ],
    "tool_choice": { "type": "tool", "name": "web_search" }
  }'
```

El enrutamiento del proveedor sigue filtrando por compatibilidad con `web_search_options` antes de ejecutar la solicitud.

### Ejemplo de fecha y hora

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-4",
    "max_tokens": 512,
    "stream": false,
    "messages": [
      { "role": "user", "content": "What time is it in America/New_York right now?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "America/New_York" }
      }
    ],
    "tool_choice": { "type": "auto" }
  }'
```

Cuando se usa, los contadores `usage.server_tool_use.*` registran las invocaciones de herramientas del servidor.
