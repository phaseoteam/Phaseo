Este endpoint está en fase [Beta](../../developers/feature-maturity.mdx) y se activa por espacio de trabajo bajo solicitud.

Esta ruta reenvía los bytes del archivo del proveedor de origen solo después de confirmar que pertenece al espacio de trabajo actual.
