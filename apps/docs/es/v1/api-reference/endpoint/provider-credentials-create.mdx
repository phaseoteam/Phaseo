---
title: "Crear credencial de proveedor"
sidebarTitle: "Crear credencial"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml POST /byok"
description: "Cifrar y guardar una credencial de proveedor para el enrutamiento del espacio de trabajo."
---

<Warning>
El valor `key` solo se puede escribir. Phaseo lo cifra de inmediato y nunca lo devuelve en respuestas de la API.
</Warning>

Usa `routing_mode: "priority"` para probar la credencial antes que la capacidad administrada o `"fallback"` para probarla después. Configura `byokFallbackEnabled` en los ajustes del espacio de trabajo para decidir si las credenciales prioritarias fallidas pueden recurrir a la capacidad administrada.
