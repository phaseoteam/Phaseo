---
title: "Crear una bifurcación de un ajuste público"
sidebarTitle: "Bifurcar ajuste preestablecido"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml POST /presets/{id}/fork"
description: "Crea una bifurcación de un ajuste preestablecido público en el espacio de trabajo de gestión."
---
<Note>Este endpoint requiere una clave de API de gestión con `presets:write` y una identidad de usuario asociada.</Note>

Omite `source_version_id` para bifurcar la versión activa. El nuevo ajuste es privado y conserva el linaje de origen.
