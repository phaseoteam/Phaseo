Envía `input` y un array ordenado de `questions` a `POST /v1/decisions` y recibe una respuesta tipada por pregunta, con probabilidades, en el mismo orden.

## Toma una decisión

Esta solicitud hace una pregunta de cada tipo. Necesita una clave de API de Phaseo y una ruta disponible de `openai/gpt-6-luna`.

<CodeGroup>

    "model": "openai/gpt-6-luna",
    "input": "I was charged twice for my order and I cannot log in to download the invoice.",

## Escribe las preguntas

`input` es una cadena, o un array de mensajes `user` cuyo `content` es una cadena o una lista de partes `input_text`, `input_image`, `input_audio` e `input_video`. `name` es opcional; las respuestas mantienen el orden de la solicitud, incluidas las preguntas sin nombre y los nombres repetidos.

Una solicitud lleva como máximo 128 preguntas, salvo en `google/gemini-decision-1`, que acepta hasta 1000, en `parallel/decisions-fast`, que acepta hasta 100, y en Clef, que acepta hasta 64. Una solicitud que supera el límite del modelo devuelve `400`.

| `type` | Campos adicionales | Campos de la respuesta |
| --- | --- | --- |
| `predicate` | ninguno | `probability` (0–1) de que la respuesta sea sí |
| `choice` | `choices`: `value` (cadena o booleano, distintos entre sí) y `description` opcional | `choice`, `confidence`, `probabilities` por valor |
| `score` | `levels`: `label` y `description` opcional | `score` (índice de nivel ponderado por probabilidad), `confidence`, `probabilities` por nivel |
| `box` | ninguno; necesita una imagen en `input` | `box` (`top`, `bottom`, `left`, `right`), `confidence` |
| `locate` | ninguno; necesita un `input` de tipo cadena sin contenido multimedia | `spans`: `start`, `end`, `text`, `score` |

Los valores de opción booleanos se devuelven como booleanos. Un modelo que se niega a responder una pregunta devuelve `type: "refusal"` para ella. Los tipos que admite cada modelo aparecen en [Elige un modelo](#choose-a-model).

Las imágenes van en partes `input_image` como data URLs. Las URLs HTTPS de imágenes alojadas solo funcionan en los modelos de Base Labs (`baselabs/elephant-1`, `baselabs/mammoth-1` y `baselabs/joey-1`) y deben estar en Amazon S3, Google Cloud Storage o Azure Blob Storage. Una solicitud admite como máximo 128 imágenes, que Luna acepta; otros proveedores fijan límites más bajos. Un `detail` de imagen explícito y `safety_identifier` requieren una ruta de OpenAI.

## Usa el formato de estado antiguo

Las solicitudes con `state` y un mapa de preguntas con nombre siguen funcionando y devuelven respuestas indexadas por esos mismos nombres. Together Tev (`together/tev1-4b-experimental`) requiere este formato, porque devuelve una etiqueta sin probabilidades, y solo responde preguntas `choice`. Respan Span-01 también usa este formato. No mezcles los formatos: `input` con `state` o `images` devuelve `400`.

- `state`: una cadena, un objeto o un array con la información que se evalúa.
- `questions`: hasta 128 preguntas con nombre, o más en los modelos con un límite superior. Cada una configura `type` como `noul` (sí/no), `choice` o `score`, además de `instructions`. Las preguntas de opción aceptan `criteria` como un mapa de opción a descripción; las de puntuación aceptan `criteria` como un array de al menos dos descripciones de nivel.
- Las preguntas `locate` solo usan `instructions` y necesitan un `state` de tipo cadena sin `images`; consulta [Perplexity Decider](#liquid-d1-and-perplexity-decider).
- `images`: hasta cuatro imágenes PNG, JPEG o WebP, como URLs `data:` u objetos `{ "content_type", "base64" }`.
- `model`: si se omite, es `typesafe/jev-1.13.0` de forma predeterminada.

Las respuestas usan las mismas claves que `questions`. Las respuestas `choice` incluyen la opción seleccionada, las probabilidades y la confianza; las respuestas `noul` incluyen una probabilidad de 0 a 1; las respuestas `score` incluyen una puntuación ponderada por probabilidad, una leyenda, las probabilidades y la confianza.

### TypeSafe Jev

Usa `typesafe/jev-1.13.0` para Jev 1.13, o `typesafe/jev-latest` para seguir la última versión de Jev. Para la semántica de las preguntas en el proveedor, consulta la [referencia de la API](https://docs.typesafe.ai/api) de TypeSafe.

En las rutas de TypeSafe compatibles, Jev 1.13 y 1.14 aceptan imágenes PNG o JPEG en línea mediante `input_image` o el campo antiguo `images`. Phaseo crea los recursos de imagen de TypeSafe y activa la compatibilidad con imágenes automáticamente. Las imágenes deben cumplir los [límites de imagen](https://docs.typesafe.ai/images) de TypeSafe: como máximo 16 MiB cada una, de 256 a 1568 píxeles por lado y al menos 78.400 píxeles en total. TypeSafe valida las dimensiones y la codificación y no redimensiona las imágenes rechazadas. El cuerpo JSON asignado que se envía al proveedor está limitado a 32 MiB. Los tokens de imagen usan el precio de entrada normal.

`box` (en rutas compatibles como Jev 1.14) requiere una imagen, no acepta criterios y devuelve un cuadro delimitador más la confianza. Sus bordes van de 0 a 1, medidos desde la esquina superior izquierda. Box siempre devuelve un rectángulo, así que combínalo con una pregunta `predicate` de presencia cuando el objetivo pueda no estar. Con el campo antiguo `images`, haz referencia a `images[0]`; con la entrada ordenada, haz referencia a la primera imagen o a `[Image 0]`. Consulta el [contrato de Box](https://docs.typesafe.ai/primitives/box).

Configura `provider_options.typesafe.long_context` como `true` para elevar los límites de contexto por solicitud y por pregunta a 262k tokens, desde los valores predeterminados de 64k por solicitud y 32k por pregunta. El contexto largo cuesta lo mismo por token. Las imágenes, Box y el contexto largo son capacidades experimentales del proveedor.

```json
{
  "model": "typesafe/jev-1.14.0",
  "input": [{
    "role": "user",
    "content": [{ "type": "input_image", "image_url": "data:image/png;base64,<base64 image bytes>" }]
  }],
  "questions": [
    { "type": "predicate", "name": "visible", "instructions": "Is there a mug in the first image?" },
    { "type": "box", "name": "mug", "instructions": "The mug in the first image" }
  ],
  "provider_options": { "typesafe": { "long_context": true } }
}
```

### Cloudflare Clef y Clef Flash

`cloudflare/clef` y `cloudflare/clef-flash` se ejecutan en Cloudflare Workers AI. Clef tiene una ventana de contexto de 65.536 tokens y Clef Flash, de 24.576 tokens.

```json
{
  "model": "cloudflare/clef-flash",
  "state": "Inspect the attached product photo.",
  "images": [{ "content_type": "image/png", "base64": "<base64 image bytes>" }],
  "questions": {
    "damaged": { "type": "noul", "instructions": "Is the product visibly damaged?" }
  }
}
```

`images` también acepta una cadena `data:image/png;base64,...`. Clef acepta hasta cuatro imágenes PNG, JPEG o WebP, de 4 MiB y 16 megapíxeles como máximo cada una, con un máximo de 8 MiB de datos de imagen decodificados y un cuerpo de solicitud de 13 MiB. No se admiten URLs remotas, y Cloudflare valida los formatos y las dimensiones de las imágenes. Los modelos sin compatibilidad con imágenes rechazan las solicitudes con imágenes.

Clef acepta como máximo 64 preguntas, con IDs de hasta 100 letras, dígitos, guiones bajos, puntos o guiones. Las preguntas de opción necesitan de 2 a 255 opciones y las de puntuación, de 2 a 10 niveles. Consulta la [documentación de Clef](https://developers.cloudflare.com/workers-ai/models/clef/) de Cloudflare.

### Cloudflare Clef Omni

`cloudflare/clef-omni` acepta texto, imágenes, audio y vídeo. Las partes de audio y vídeo son extensiones de Phaseo al formato de entrada; las rutas de OpenAI solo aceptan texto e imágenes. Sustituye los bytes de audio y la URL de vídeo de ejemplo por tus propios archivos multimedia antes de enviar este ejemplo.

```json
{
  "model": "cloudflare/clef-omni",
  "input": [{
    "role": "user",
    "content": [
      { "type": "input_text", "text": "Review the recording and clip." },
      { "type": "input_audio", "input_audio": { "data": "<base64 WAV bytes>", "format": "wav" } },
      { "type": "input_video", "video_url": { "url": "https://media.example.com/clip.mp4" } }
    ]
  }],
  "questions": [{ "type": "predicate", "name": "safe", "instructions": "Is the equipment operating safely?" }]
}
```

Envía el audio como `input_audio.data` con `format: "wav"` o `"mp3"`, o como `input_audio.url` con una URL HTTPS pública o una data URL de audio en línea. `input_video.video_url` acepta una cadena o `{ "url": "..." }` con una URL HTTPS pública o una data URL MP4/WebM en línea. Los servidores remotos deben devolver el Content-Type correspondiente. Phaseo descarga las URLs con límites de tamaño y comprobaciones de direcciones privadas y redirecciones, y después incrusta el contenido multimedia para Cloudflare; las credenciales del proveedor nunca se envían al servidor multimedia.

| Límite | Valor |
| --- | --- |
| Clips de audio | 4, de 8 MiB y 300 segundos como máximo cada uno |
| Vídeos | 2, de 16 MiB y 60 segundos como máximo cada uno |
| Audio y vídeo combinados | 16 MiB decodificados |
| Imágenes | Los mismos límites por imagen y combinados que Clef |
| Cuerpo de la solicitud | 37 MiB (sustituye los 13 MiB de Clef) |
| Contexto | 64.000 tokens |

Cloudflare valida la codificación multimedia, las dimensiones de las imágenes y la duración de los clips, y muestrea el vídeo a dos fotogramas por segundo. La pista de audio de un vídeo se usa cuando todos los vídeos de la solicitud tienen una. Los tokens multimedia cuentan para el contexto y la facturación; Phaseo liquida según el uso de entrada que informa Cloudflare y no añade ningún cargo aparte por audio o vídeo. Consulta el [contrato de Omni de Cloudflare](https://github.com/cloudflare/cloudflare-docs/blob/production/src/content/workers-ai-models/clef-omni.json).

### Liquid D1 y Perplexity Decider

Liquid D1 (`liquid-ai/d1:free`, también `liquid-ai/d1`) es gratuito durante el acceso anticipado experimental. Perplexity Decider V1.3 (`perplexity/pplx-decider-v1.3`, o `perplexity/pplx-decider-latest`) y Decider Flash V1.3 (`perplexity/pplx-decider-flash-v1.3`, o `perplexity/pplx-decider-flash-latest`) necesitan una credencial del proveedor Perplexity en Phaseo. Su estado de imagen usa data URLs en base64 PNG, JPEG o WebP; no se admiten URLs de imagen remotas. También responden preguntas `locate`, que devuelven las partes de un `input` o `state` de tipo cadena que coinciden con las `instructions`, como `"email address"`. Cada fragmento tiene `text` copiado literalmente, posiciones `start` y `end` contadas en puntos de código Unicode (`end` es exclusiva) y un `score` en el que un valor más alto indica más certeza; `spans` está vacío cuando nada coincide. Locate no usa criteria ni admite imágenes, audio o vídeo, y solo funciona en los modelos que lo indican; los demás devuelven `400`. Perplexity lo entrenó con entradas de hasta 8K tokens. En ambos, una pregunta de opción acepta hasta 255 opciones y una pregunta de puntuación hasta 10 niveles.

### Inception Mercury Decide

`inception/mercury-decide` acepta evidencia en texto o JSON. Las preguntas de opción aceptan hasta 255 opciones y las de puntuación hasta 10 niveles. No se admiten imágenes, streaming ni llamadas a herramientas. El precio de entrada de $0.02 es la promoción del 50% de Inception, que no tiene fecha de fin publicada; consulta los [precios actuales del proveedor](https://docs.inceptionlabs.ai/get-started/models) antes de usarlo.

```json
{
  "model": "inception/mercury-decide",
  "input": "Please refund the duplicate charge on my account.",
  "questions": [{
    "type": "predicate",
    "name": "billing",
    "instructions": "Is this request about billing?"
  }]
}
```

### Microsoft Decision

`microsoft/microsoft-decision-1` se ejecuta en un despliegue de Azure Foundry y acepta evidencia en texto o JSON de hasta 32.768 tokens. No se admiten contenido multimedia, streaming, herramientas, `safety_identifier` ni `service_tier`. Consulta la [guía de Microsoft](https://learn.microsoft.com/azure/foundry/foundry-models/how-to/use-foundry-models-microsoft-decision).

```json
{
  "model": "microsoft/microsoft-decision-1",
  "input": "The API returns 500 on every call.",
  "questions": [{
    "type": "choice",
    "name": "team",
    "instructions": "Which team should handle this ticket?",
    "choices": [
      { "value": "engineering", "description": "Bugs, errors, and outages" },
      { "value": "support", "description": "How-to and account questions" }
    ]
  }]
}
```

### Respan Span-01

Span-01 usa el formato antiguo. `state` debe ser un tramo de conversación: un array `input` con los mensajes anteriores y un mensaje del asistente en `output`. Solo responde preguntas `noul`: el valor `noul` es la probabilidad de que el comportamiento esté presente, y `probabilities` también da las probabilidades de ausente y no observable.

```json
{
  "model": "respan/span-01:free",
  "state": {
    "input": [{ "role": "user", "content": "Please connect me to a person." }],
    "output": { "role": "assistant", "content": "I will connect you to support." }
  },
  "questions": {
    "escalation": {
      "type": "noul",
      "instructions": "Does the assistant offer a human handoff?"
    }
  }
}
```

Una respuesta tiene este aspecto:

```json
{
  "answers": {
    "escalation": {
      "type": "noul",
      "noul": 0.73,
      "probabilities": {
        "true": 0.73,
        "false": 0.25,
        "not_observable": 0.02
      }
    }
  }
}
```

`respan/span-01:free` es el modelo Lite gratuito con un límite diario y corresponde al modelo `span-01-free` de Respan. `respan/span-01` corresponde a `span-01-pro` y lo factura Respan. Span-01 está en acceso anticipado: Respan debe habilitarlo para tu organización, y debes añadir tu clave de API de Respan como credencial del proveedor Respan en Phaseo antes de llamar a cualquiera de los dos modelos.
