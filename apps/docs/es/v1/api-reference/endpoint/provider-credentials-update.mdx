title: "Actualizar credencial del proveedor"
sidebarTitle: "Actualizar credencial"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml PATCH /byok/{id}"
description: "Actualiza los metadatos, el enrutamiento o los filtros de una credencial, o reemplaza su secreto."
---
Si proporcionas `key`, se reemplaza el secreto cifrado. Si lo omites, se conserva el secreto existente. Las listas permitidas de modelos y claves de API son opcionales; una lista vacía permite todos los modelos o claves del espacio de trabajo.
