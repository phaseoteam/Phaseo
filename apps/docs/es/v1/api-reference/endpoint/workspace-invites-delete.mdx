---
title: "Eliminar invitación del espacio de trabajo"
sidebarTitle: "Eliminar invitación"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml DELETE /workspaces/{id}/invites/{invite_id}"
description: "Revoca permanentemente una invitación del espacio de trabajo."
---
Este endpoint requiere una clave de API de gestión con `workspaces:write`.

Eliminar una invitación no quita a los miembros que se unieron con ella.
