<Note>
Este endpoint requiere una clave de API de administración. No se aceptan las claves de API estándar del Gateway.
</Note>

## Añade créditos desde la CLI o la API

Los agentes y los scripts pueden iniciar una recarga con `POST /v1/credits/topups` o con la CLI. Una persona siempre aprueba el cargo.

```bash
phaseo login --scopes billing:write
phaseo credits add --amount 20
```

- El token necesita el scope `billing:write`. Nunca se concede de forma predeterminada: añádelo con `phaseo login --scopes billing:write` o inclúyelo en una clave de administración.
- Las recargas desde la API o la CLI van de $5 a $500; las recargas mayores se hacen en el panel. Un espacio de trabajo puede tener 5 en espera a la vez (una sexta devuelve `429` `too_many_pending_topups`), y cada una caduca a los 30 minutos.
- **Sin tarjeta guardada todavía:** la respuesta incluye un `checkout_url`. Un propietario o administrador del espacio de trabajo lo abre y paga con una tarjeta nueva, que se guarda para recargas posteriores.
- **Con tarjeta guardada:** todos los propietarios y administradores reciben un correo con un enlace de un solo uso. Uno de ellos lo abre, inicia sesión y elige **Confirm** o **Decline**. Al confirmar se cobra la tarjeta, con verificación bancaria si el banco la pide.
- Consulta `GET /v1/credits/topups/{id}` (o `phaseo credits topups get <id>`) hasta que `final` sea `true`. Los créditos se añaden cuando el estado es `paid`. `declined`, `expired` y `failed` incluyen un código `reason`: no los reintentes automáticamente; pregunta a una persona.
