title: "Actualizar el rol de un miembro del espacio de trabajo"
sidebarTitle: "Actualizar el rol del miembro"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml PATCH /workspaces/{id}/members/{user_id}"
description: "Cambia el rol de un miembro entre administrador y miembro."
---
Este endpoint requiere un propietario del espacio de trabajo y una clave de API de gestión con `workspaces:write`.

El rol del propietario no se puede cambiar.
