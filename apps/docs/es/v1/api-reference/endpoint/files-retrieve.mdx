Este endpoint está en fase [Beta](../../developers/feature-maturity.mdx) y se activa por espacio de trabajo bajo solicitud.

Esta ruta actualiza los metadatos del archivo en el proveedor de origen y comprueba que el espacio de trabajo sea su propietario antes de reenviar la respuesta.
