description: "Crea un ajuste preestablecido reutilizable de pasarela para el espacio de trabajo."
---
<Note>Este endpoint requiere una clave de API de gestión con `presets:write` y una identidad de usuario asociada.</Note>

La configuración del ajuste puede incluir valores predeterminados acotados de indicaciones, parámetros, enrutamiento y complementos. Los ajustes públicos usan el identificador del editor del espacio de trabajo.
