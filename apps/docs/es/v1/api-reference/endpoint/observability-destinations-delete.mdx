---
title: "Eliminar destino de observabilidad"
sidebarTitle: "Eliminar destino"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml DELETE /observability/destinations/{id}"
description: "Elimina un destino y sus filtros."
---
<Note>Este endpoint requiere una clave de API de gestión con `settings:write`.</Note>

Al eliminar un destino también se quitan sus vínculos a claves de API y sus grupos de reglas.
