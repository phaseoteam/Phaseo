title: "Eliminar un presupuesto del espacio de trabajo"
sidebarTitle: "Eliminar presupuesto"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml DELETE /budgets/{id}"

---

Requiere `budgets:delete`. La eliminación queda registrada en el registro de auditoría del espacio de trabajo.
