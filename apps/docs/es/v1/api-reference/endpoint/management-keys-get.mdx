sidebarTitle: "Obtener clave de gestión"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml GET /management-keys/{id}"
description: "Obtiene los metadatos, ámbitos, límites y estado de una clave de gestión."
---
Este endpoint requiere una identidad de propietario o administrador y `management_keys:read`.

La respuesta nunca incluye el valor sin procesar de la clave.
