## Usa herramientas del servidor

Añade una herramienta `phaseo:` a `tools` junto a tus propias herramientas de función, y Phaseo la ejecuta cuando el modelo la llama. `/v1/chat/completions` acepta todas las herramientas del servidor excepto `phaseo:apply_patch`; la guía de [Herramientas del servidor](../../guides/server-tools) las enumera.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["Europe/London"] } }
    ],
    "tool_choice": "auto"
  }'
```

Cada llamada a una herramienta del servidor se cuenta en `usage.server_tool_use`:

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` añade `web_search_requests`, `web_search_results` y `web_search_extra_results`; `phaseo:web_fetch` añade `web_fetch_requests`. El tipo antiguo `gateway:datetime` sigue funcionando.

Con `stream: true`, Phaseo ejecuta los turnos de herramientas por su cuenta y después te transmite la respuesta continuada como un único stream.

## Razonamiento en bucles de herramientas

Los modelos de razonamiento devuelven su razonamiento en el mensaje del asistente, en dos campos:

- `reasoning_content`: el texto del razonamiento, cuando el proveedor lo devuelve.
- `reasoning_details`: un array de bloques de razonamiento. Cada entrada tiene un `type` (`reasoning.text`, `reasoning.summary` o `reasoning.encrypted`), un `index` y un `format` que nombra la familia del proveedor, por ejemplo `anthropic-claude-v1` o `google-gemini-v1`.

Las entradas pueden llevar estado del proveedor que el modelo necesita en el siguiente paso de un bucle de herramientas:

| Estado del proveedor | Dónde está |
| --- | --- |
| Firmas de pensamiento de Claude | `signature` en las entradas `reasoning.text` |
| Pensamiento censurado de Claude, razonamiento cifrado de OpenAI | `data` en las entradas `reasoning.encrypted` |
| Firmas de pensamiento de Gemini | `data` en las entradas `reasoning.encrypted` cuyo `id` es la llamada a herramienta a la que pertenecen |
| El nivel de esfuerzo con el que se ejecutó una respuesta de Claude | `data` en la última entrada `reasoning.encrypted`, que no tiene texto |

Con streaming, llega un delta `reasoning_details` cuando se completa cada bloque de razonamiento.

<Warning>
Devuelve cada mensaje del asistente con su `reasoning_details` sin cambios, en cada solicitud, no solo en los bucles de herramientas. Nunca descartes, edites ni reordenes entradas, cifradas o no, incluidas las entradas sin texto.
</Warning>

Los valores de `signature` y `data` son opacos y registran el proveedor y el modelo que los generaron. Phaseo solo los envía a esa familia de proveedor y a ese modelo, así que un fallback a otro proveedor los descarta en lugar de fallar. Sin ellos, los modelos de Claude en modo de pensamiento manual ejecutan el siguiente paso del bucle de herramientas sin pensamiento, y un cambio de `reasoning_effort` reinicia la caché de prompts de Claude; consulta [Cambia el esfuerzo de razonamiento a mitad de la conversación](../../guides/prompt-caching#change-reasoning-effort-mid-conversation).
