---
title: "Revocar un token SCIM"
badge: "Beta"
openapi: "/es/openapi/v1/openapi.localized.yaml DELETE /identity/scim/tokens/{id}"
---
<Note>La administración de identidades requiere una identidad de propietario o administrador. Para habilitar SSO o SCIM y crear tokens de aprovisionamiento se necesita el complemento de identidad.</Note>

Solo el propietario del espacio de trabajo puede cambiar el aprovisionamiento SCIM o crear y revocar sus tokens. Las solicitudes SCIM solo se aceptan con un token que haya creado el propietario actual del espacio de trabajo; si lo creó un administrador o un propietario anterior, el propietario debe crear uno nuevo.
