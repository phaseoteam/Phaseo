يجمع Phaseo Desktop المحادثات ووكلاء البرمجة وأدوات المشاريع في تطبيق واحد. ابدأ بمحادثة شخصية، ثم أضف مشروعًا عندما تريد أن يعمل وكيل على الملفات.

<Note>
تصف هذه الأدلة النسخة التجريبية لتطبيق سطح المكتب. تعتمد الميزات المتاحة على إصدارك والوكيل المتصل.
</Note>

## افتح التطبيق

إذا كانت لديك نسخة تجريبية بالفعل، فافتح Phaseo. للتشغيل من الشيفرة المصدرية، ثبّت Git وNode.js 24 وpnpm 10.33، ثم نفّذ:

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
pnpm install
pnpm --filter @phaseo/desktop dev
```

يبني أمر التطوير الحزم المطلوبة ويفتح نافذة تطبيق سطح المكتب. أبقِ الطرفية قيد التشغيل أثناء استخدامه.

## اربط حسابًا

افتح **Settings → Phaseo account** لتسجيل الدخول إلى Phaseo. استخدم **Settings → Accounts** لمفاتيح API واشتراكات الوكلاء، أو استخدم وكيل برمجة سبق تسجيل الدخول إليه على هذا الكمبيوتر. يعرض **Settings → Agents** الوكلاء المتاحين على جهازك.

يحدد حسابك النماذج التي يمكنك استخدامها وكيفية فوترة الاستخدام. يحتفظ الاشتراك المتصل بحدود الاستخدام الخاصة بمزوّده؛ أما الطلبات عبر Phaseo فتستخدم حسابك في Phaseo.

## ابدأ محادثة

1. اختر **Chat** ثم **New chat**.
2. افتح منتقي النماذج بجانب مربع الرسالة. اختر وكيلًا ونموذجًا، ثم عدّل الاستدلال أو السرعة حيثما كان ذلك مدعومًا.
3. اكتب رسالة وأرسلها. لا يلزم وجود مشروع.

إذا لم تظهر النماذج، فتحقق من تسجيل الدخول في **Phaseo account** أو **Accounts** ومن توفر الوكيل في **Agents**.

## خصّص التطبيق

يتحكم **Settings → Appearance** في السمات والخطوط ومدة حركة اللوحات: من 0 إلى 600 ms، والقيمة الافتراضية 200 ms. انقر على مساحة العمل المصغّرة للمعاينة. تظهر اللوحات فورًا عند اختيار صفر، أو تعطيل **Animations**، أو تفعيل تفضيل النظام لتقليل الحركة.

استخدم `Ctrl+K` ‏(`Cmd+K` على macOS) للعثور على المحادثات والأوامر. يعرض **Settings → Keyboard shortcuts** اختصاراتك الحالية.
