تتطلب جميع الطلبات إلى Gateway مفتاح API من نوع Bearer.

أنشئ المفاتيح وأدِرها من لوحة تحكم Phaseo.

<Note>
يمكن تشغيل الطلبات إلى نماذج `:free` من دون إيداع رصيد. أما النماذج المدفوعة فتتطلب رصيدًا متاحًا في المحفظة.
</Note>

## استخدام مفتاح API

أضف مفتاح API إلى ترويسة `Authorization` باستخدام مخطط `Bearer`:

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Hello!"
  }'
```

## تنسيق المفتاح والتعامل معه

- تنسيق المفتاح: `phaseo_v1_sk_<kid>_<secret>`
- خزّن المفاتيح في مدير أسرار، ولا تضعها في الشيفرة التي تعمل في المتصفح.
- استخدم مفاتيح منفصلة لكل تطبيق وبيئة لتدويرها بأمان أكبر.

## مفاتيح الإدارة

تُنشأ مفاتيح Management API وتُدار من لوحة تحكم Phaseo، وليس عبر واجهة API العامة.

استخدمها لنقاط النهاية الإدارية ذات الصلاحيات المرتفعة، مثل [الأرصدة](./endpoint/credits.mdx) و[النشاط](./endpoint/activity.mdx)، ولواجهات التحكم المستقبلية الخاصة بالضوابط وإدارة المفاتيح ومساحات العمل.

## إخفاقات المصادقة

- `401`: مفتاح API مفقود أو مشوّه أو غير صالح.
- `403`: المفتاح صالح، لكنه لا يتيح الوصول إلى الإمكانية المطلوبة.

<Visibility for="agents">
إذا كنت تنفّذ تدفقات مصادقة بصفتك وكيلاً:

- استخدم مهارات المستودع للتعامل مع الأسرار وإعداد البيئة.
- لا تضع مفاتيح Gateway API مطلقًا في شيفرة تُرسل إلى العميل.
- فضّل الرموز الداخلية قصيرة العمر بين الواجهة الأمامية والخلفية، وأبقِ مفاتيح Gateway على الخادم فقط.
</Visibility>
