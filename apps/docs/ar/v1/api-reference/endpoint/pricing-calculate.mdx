أرسل حمولة استخدام لتسعيرها وفق قواعد تسعير الـ Gateway النشطة لمزوّد ونموذج ونقطة نهاية واحدة. الحقول الأربعة كلها مطلوبة:

- `provider`: معرّف المزوّد، مثل `openai`.
- `model`: معرّف النموذج الموجَّه إليه.
- `endpoint`: عائلة نقطة النهاية، مثل `responses` أو `chat.completions`.
- `usage`: الاستخدام المراد تسعيره، مثل أعداد الـ tokens أو مدخلات العدّادات الأخرى.

لعرض الأسعار الحالية بدلًا من تسعير حمولة واحدة، استخدم [عرض أسعار النماذج](./pricing-models.mdx).
