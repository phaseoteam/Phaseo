تعيد نقطة النهاية هذه افتراضيًا النماذج القابلة للتوجيه حاليًا فقط. اضبط `availability=all` لتضمين النماذج المعروفة غير المتاحة حاليًا.

`GET /models/me` مخصص لتصفية مستقبلية للنماذج وفق ضوابط المتصل الحالي. وهو يعيد حاليًا `501 not implemented`، لذا استخدم `GET /models` للوصول إلى كتالوج Gateway المشترك في الوقت الحالي.

## عوامل تصفية مفيدة

- يستخدم `endpoints` أسماء عامة مثل `chat.completions` و`responses` و`messages`
- يرشح `status` النماذج حسب دورة حياتها، مثل `active` أو `deprecated` أو `retired`
- يرشح `provider` حسب معرّف المزوّد العام، مثل `openai` أو `anthropic` أو `google_vertex`
- يرشح `provider_status` حسب مستوى طرح المزوّد، مثل `active` أو `beta` أو `alpha` أو `not_ready`
- يرشح `provider_routing_status` حسب حالة توجيه المزوّد
- يرشح `model_routing_status` حسب حالة توجيه النموذج
- يرشح `capability_status` حسب حالة إمكانات المزوّد لمطابقة نقطة النهاية المطلوبة
- يرشح `provider_availability_status` حسب توفر المزوّد، مثل `active` أو `coming_soon` أو `inactive`
- يرشح `provider_availability_reason` حسب سبب توفر المزوّد، مثل `preview_only` أو `provider_not_ready` أو `gated` أو `access_limited` أو `region_limited`
- يرشح `organisation` حسب بادئة معرّف النموذج العام، مثل `anthropic` في `anthropic/claude-3-haiku`
- القيمة الافتراضية هي `availability=active`
- يتضمن `availability=all` النماذج أو المزوّدين ذوي الحالة `coming_soon` أو `inactive` أو غير القابلين للتوجيه للعامة بعد
- `input_modalities` اسم بديل لـ `input_types`
- `output_modalities` اسم بديل لـ `output_types`
- `supported_parameters` اسم بديل لـ `params`

للاطلاع على عقد نقطة النهاية لنموذج واحد، استدعِ `GET /models/{author}/{slug}/endpoints`. تفصل الاستجابة مسارات المزوّدين وتعرض في كل صف المسار العام والوسائط وتفاصيل المعلمات المدعومة والتوفر وحالة التوجيه واسم النموذج لدى المزوّد وملخص الأسعار.

قد تتضمن إدخالات المزوّد أيضًا:

- `availability_status`
- `availability_reason`
- `provider_status`
- `provider_routing_status`
- `model_routing_status`
- `capability_status`
