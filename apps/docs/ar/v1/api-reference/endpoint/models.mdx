استدعِ `GET /v1/models` لعرض النماذج التي يمكنك التوجيه إليها الآن. اضبط `availability=all` لتضمين النماذج المعروفة لكنها غير متاحة حاليًا.

```bash
curl "https://api.phaseo.app/v1/models?limit=50" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

يسرد كل نموذج إدخالًا واحدًا في `offers` لكل مسار مزوّد (مختصر، والقيم توضيحية):

```json
{
  "ok": true,
  "availability_mode": "active",
  "limit": 50,
  "offset": 0,
  "total": 412,
  "models": [
    {
      "id": "anthropic/claude-sonnet-5.5",
      "name": "Claude Sonnet 5.5",
      "organization": { "id": "anthropic", "name": "Anthropic", "color": "#d97757" },
      "lifecycle": { "status": "active", "released_at": "2026-09-28", "replacement_id": null },
      "modalities": { "input": ["text", "image"], "output": ["text"] },
      "capabilities": { "endpoints": ["chat.completions", "messages", "responses"] },
      "availability": { "status": "active", "provider_count": 3, "active_provider_count": 3 },
      "offers": [
        {
          "provider": { "id": "anthropic", "name": "Anthropic" },
          "model": "claude-sonnet-5-5",
          "status": "active",
          "status_reason": null,
          "routable": true,
          "service_tiers": ["standard"],
          "routing": { "provider": "active", "model": "active", "capability": "active" }
        }
      ]
    }
  ]
}
```

لا توجّه حركة الإنتاج إلا إلى عرض تكون فيه قيمة `routable` هي `true`. يوضح `status_reason` سبب كون العرض للمعاينة فقط أو غير نشط. المخطط الكامل أدناه.

`GET /models/me` محجوز لتصفية مستقبلية للنماذج تراعي ضوابط الحماية للمتصل الحالي. يُرجع اليوم `501 not implemented`، لذا استخدم `GET /models`.

## صفِّ القائمة

تقبل المرشحات التي تأخذ عدة قيم معاملات مكررة أو قائمة مفصولة بفواصل.

| المعامل | يصفّي حسب |
| --- | --- |
| `availability` | `active` (الافتراضي) للنماذج القابلة للتوجيه علنًا، أو `all` لإضافة النماذج والمزوّدين `coming_soon` و`inactive` وغير القابلين للتوجيه بعد |
| `endpoints` | أسماء نقاط النهاية العامة، مثل `chat.completions` و`responses` و`messages` |
| `status` | دورة حياة النموذج، مثل `active` أو `deprecated` أو `retired` |
| `organisation` | بادئة معرّف النموذج، مثل `anthropic` في `anthropic/claude-3-haiku` |
| `provider` | معرّف المزوّد العام، مثل `openai` أو `anthropic` أو `google_vertex` |
| `provider_status` | مستوى إطلاق المزوّد، مثل `active` أو `beta` أو `alpha` أو `not_ready` |
| `provider_routing_status` | حالة التوجيه على مستوى المزوّد |
| `model_routing_status` | حالة التوجيه على مستوى النموذج |
| `capability_status` | حالة قدرة المزوّد لربط نقطة النهاية المطلوبة |
| `provider_availability_status` | التوفر لدى المزوّد، مثل `active` أو `coming_soon` أو `inactive` |
| `provider_availability_reason` | سبب عدم توفر مزوّد، مثل `preview_only` أو `provider_not_ready` أو `gated` أو `access_limited` أو `region_limited` |
| `input_types` (الاسم المستعار `input_modalities`) | وسائط الإدخال |
| `output_types` (الاسم المستعار `output_modalities`) | وسائط الإخراج |
| `params` (الاسم المستعار `supported_parameters`) | معاملات الطلب المدعومة |

لفحص مسارات المزوّدين لنموذج واحد وتفاصيل معاملاته وتسعيره، استدعِ [`GET /models/{author}/{slug}/endpoints`](./model-endpoints.mdx).

## تحقق من فئات الخدمة لكل عرض

يتضمن كل إدخال في `offers` الحقل `service_tiers`، وهو [فئات الخدمة](../../guides/service-tiers.mdx) التي يقبلها عرض ذلك المزوّد. وهو مجموعة فرعية مرتّبة أبجديًا من `flex` و`priority` و`standard` و`ultrafast`، حيث `priority` هي الفئة Fast. تُدرج الفئة عندما يكون لمسار المزوّد تسعير نشط وساري المفعول حاليًا لها، والمسار الذي يخدم فئة واحدة يُدرج تلك الفئة فقط. تتوفر بعض الفئات أيضًا عبر مسارات مزوّدين منفصلة خاصة بالفئة وغير مدرجة. تظل الأسعار تحت `pricing` أسعار الفئة القياسية.

## احصل على القائمة بتنسيق OpenAI

استخدم `GET /v1/models?format=openai` للعملاء التي تتوقع استجابة قائمة النماذج الخاصة بـ OpenAI. تُرجع القيمة الافتراضية `format=json` البيانات الوصفية الأغنى للنماذج في Phaseo.

```bash
curl "https://api.phaseo.app/v1/models?format=openai" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

```json
{
  "object": "list",
  "data": [
    { "id": "openai/gpt-6-astra", "object": "model", "created": 1788393600, "owned_by": "openai" }
  ]
}
```

يستخدم تنسيق OpenAI المصادقة نفسها والتوفر الإقليمي نفسه والنماذج الخاصة بمساحة العمل والمرشحات نفسها كما في JSON الأصلي. يُرجع كل النماذج المطابقة ما لم تقدّم `limit`؛ ويظل `offset` ساريًا. تبقى المعرّفات بصيغة Phaseo القياسية للاستدلال. يستخدم `created` تاريخ الإصدار في الفهرس، أو `0` عندما يكون غير معروف؛ ويستخدم `owned_by` المؤسسة في الفهرس، أو `private` لنماذج مساحة العمل، أو `phaseo` عندما تكون غير معروفة.

## خزّن قائمة النماذج مؤقتًا

تُخزَّن استجابات الفهرس مؤقتًا لمدة خمس دقائق، وقد تُقدَّم لخمس دقائق أخرى أثناء إعادة التحقق من الذاكرة المؤقتة. ينطبق هذا على تمثيلات JSON وRSS وAtom للفهرس الحالي؛ أما موجز الإصدارات فله ذاكرة استطلاع مؤقتة خاصة أقصر.

تتضمن استجابات JSON وتنسيق OpenAI ترويسة `ETag` ضعيفة (`W/"…"`). تتغير عندما تتغير النماذج في الصفحة أو `limit` أو `offset` أو `total` أو التنسيق. وتتجاهل `gateway_region`، لذا يحمل الفهرس نفسه المقدَّم من منطقة أخرى قيمة `ETag` نفسها. لهذا هي ضعيفة: الاستجابات التي تتشاركها متكافئة، لكن بايتاتها قد تختلف. لا تتضمنها استجابات RSS وAtom والأخطاء.

أعد إرسال القيمة المحفوظة دون تغيير في `If-None-Match`. إذا لم يتغير الفهرس، تكون الاستجابة `304 Not Modified` بلا جسم، وتكرر ترويسات `ETag` و`Cache-Control` و`Vary`. وإلا فستحصل على `200` عادية مع القائمة الجديدة و`ETag` جديدة. يقبل `If-None-Match` أيضًا قائمة مفصولة بفواصل و`*`، والمقارنة ضعيفة، لذا تتطابق القيمة مع البادئة `W/` أو بدونها.

```ts
let etag: string | null = null;
let models: unknown[] = [];

async function refreshModels() {
  const response = await fetch("https://api.phaseo.app/v1/models?limit=250", {
    headers: {
      Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
      ...(etag ? { "If-None-Match": etag } : {}),
    },
  });
  if (response.status === 304) return models; // Unchanged; a 304 has no body.
  if (!response.ok) throw new Error(`Model list request failed: ${response.status}`);
  etag = response.headers.get("ETag");
  models = (await response.json()).models;
  return models;
}
```

توفّر الاستجابة `304` النقل والتحليل. ومع ذلك يقيّم الخادم الطلب: فهو يحمّل الفهرس ويعيد حساب `ETag`. الاستطلاع كل 15 دقيقة تقريبًا كافٍ، مع تنزيل القائمة مجددًا فقط عندما يتغير الفهرس. احتفظ بقيمة `ETag` واحدة لكل عنوان URL للطلب، لأن لكل صفحة ومجموعة مرشحات وتنسيق قيمته الخاصة.
