استدعِ نقطة النهاية هذه قبل إرسال طلب للتأكد من توفر تركيبة النموذج والمزوّد ونقطة النهاية والمعاملات. بالنسبة إلى `openai/gpt-6-astra`:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

كل إدخال في `endpoints` هو مسار مزوّد واحد لنقطة نهاية واحدة:

| الحقل | يحتوي على |
| --- | --- |
| `endpoint` و`capability_id` و`public_path` و`collection` | معرّفات نقطة النهاية والقدرة القياسية ومسار الواجهة البرمجية العام |
| `provider` و`model` | معرّف المزوّد واسمه، ومعرّف النموذج المختصر لدى المزوّد |
| `routable` و`status` و`status_reason` | ما إذا كان المسار يستقبل حركة الآن، وتوفره، وسبب كونه للمعاينة فقط أو غير نشط |
| `modalities` | وسائط الإدخال والإخراج |
| `capabilities` | أسماء المعاملات المدعومة وتفاصيل المعاملات المنظّمة |
| `routing` | حالات التوجيه للمزوّد والنموذج والقدرة |
| `effective` | تاريخا `from` و`to` عندما يكون المسار مجدولًا أو محدودًا زمنيًا |
| `pricing` | ملخص تسعير نقطة النهاية |

لمقارنة النماذج أولًا، استخدم [عرض النماذج](./models.mdx)؛ ولرؤية كل نقاط النهاية التي تتيحها الواجهة البرمجية، استخدم [عرض نقاط النهاية](./endpoints.mdx).

## ضمّن المسارات المخطط لها وغير النشطة

لا تُرجع القيمة الافتراضية `availability=active` إلا الصفوف القابلة للتوجيه علنًا. استخدم `availability=all` لفحص المسارات القادمة قريبًا وغير النشطة:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints?availability=all" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

لا توجّه حركة الإنتاج إلا إلى صف تكون فيه قيمة `routable` هي `true` وقيمة `status` هي `active`.

## صفِّ المسارات

تقبل هذه المرشحات معاملات مكررة أو قائمة مفصولة بفواصل: `provider` و`provider_status` و`provider_routing_status` و`model_routing_status` و`capability_status` و`provider_availability_status` و`provider_availability_reason` و`status` و`supported_parameters` (الاسم المستعار `params`). يصف [عرض النماذج](./models.mdx#filter-the-list) قيمها.

يُرجع هذا مسارات OpenAI التي تدعم `reasoning_effort`:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints?provider=openai&supported_parameters=reasoning_effort" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```
