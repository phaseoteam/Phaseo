<Note>يتطلب هذا المسار مفتاح API للإدارة يتضمن `analytics:read`.</Note>

يمكنك التصفية حسب التاريخ أو تسمية الطلب أو مفتاح API أو المستخدم النهائي أو النموذج أو المزوّد أو المسار أو مصدر بيانات الاعتماد أو النتيجة. وتُجمّع النتائج حسب التاريخ والنموذج والمزوّد والمسار مع ترقيم صفحات ثابت.

تقتصر الفترات على آخر 30 يومًا مكتملًا بتوقيت UTC وبحد أقصى 10,000 طلب مصدر.
