<Note>
يتطلب هذا المسار مفتاح API للإدارة. ولا تُقبل مفاتيح Gateway API القياسية.
</Note>

يعيد بيانات وصفية لمفتاح API واحد في مساحة العمل التي تمت المصادقة عليها. يمكن أن يكون مقطع المسار `{id}` المعرّف الداخلي للمفتاح أو تجزئة المفتاح التي أعادتها API.
