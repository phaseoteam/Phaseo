<Note>
يتطلب هذا المسار مفتاح API للإدارة. ولا تُقبل مفاتيح Gateway API القياسية.
</Note>

يعيد بيانات وصفية لمفتاح API واحد في مساحة العمل التي تمت المصادقة عليها. مقطع المسار `{id}` هو معرّف المفتاح. لا تزال تجزئة المفتاح المحفوظة من استجابة سابقة مقبولة، لكن الاستجابات لم تعد تتضمنها.
