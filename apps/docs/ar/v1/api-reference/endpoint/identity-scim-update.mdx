<Note>تتطلب إدارة الهوية هوية مالك أو مسؤول. كما يتطلب تفعيل SSO أو SCIM وإنشاء رموز التهيئة إضافة الهوية.</Note>

وحده مالك مساحة العمل يمكنه تغيير توفير SCIM أو إنشاء رموزه وإلغاؤها. لا تُقبل طلبات SCIM إلا برمز أنشأه المالك الحالي لمساحة العمل؛ وإذا أنشأ رمزك مسؤول أو مالك سابق، فيجب على المالك إنشاء رمز جديد.
