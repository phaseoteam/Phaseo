يتطلب `private_models:write` وهوية مالك أو مسؤول. قدّم `model_reference` على هيئة معرّف نموذج مطابق تمامًا للكتالوج أو اسم مختصر محلي لمساحة العمل. تعيّن Phaseo معرّف النموذج النهائي؛ تُشفّر `credential` وتكون للكتابة فقط.
