للاستجابة ثلاثة حقول:

- `endpoints`: معرّفات نقاط النهاية القياسية التي تتيحها الواجهة البرمجية حاليًا.
- `data`: سجل واحد لكل نقطة نهاية يحتوي `id` و`capability_id` و`public_path` و`collection` و`model_count` و`provider_count`، مرتّبًا حسب `public_path`.
- `sample_models`: أول 10 معرّفات نماذج ظاهرة من الفهرس العام.

تُخزَّن الاستجابة مؤقتًا لمدة 30 دقيقة.

استخدم [عرض قدرات نقاط نهاية النموذج](./model-endpoints) عندما تحتاج إلى تفاصيل على مستوى المزوّد والمعاملات لنموذج واحد.
