- `endpoints`: معرّفات المسارات الأساسية التي تعرضها API حاليًا
- `data`: سجلات المسارات التي تتضمن `public_path` و`collection` و`model_count` و`provider_count`
- `sample_models`: ما يصل إلى 10 معرّفات حديثة للنماذج الظاهرة في الفهرس العام

استخدم [عرض قدرات مسارات النموذج](./model-endpoints.mdx) عند الحاجة إلى تفاصيل مزوّد أو معلمات لنموذج واحد.
