description: "عرض حدود الإنفاق المطبّقة على مساحة العمل مع الاستخدام الحالي والمبلغ المتبقي."
---

يتطلب `budgets:read`. يجب أن يكون لدى مستدعي OAuth دور مالك مساحة العمل أو مسؤولها.

يُحسب الاستخدام من طلبات البوابة الناجحة. ويُحتسب العمل غير المتزامن المحجوز ما دام الحجز نشطًا، بحيث يتوافق المبلغ المتبقي المعاد مع الحد المطبّق.
