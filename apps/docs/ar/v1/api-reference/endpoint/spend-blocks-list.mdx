يتطلب `spend_rules:read`. يجب أن يكون مستدعو OAuth مالكين أو مشرفين في مساحة العمل. أضف `include_lifted=true` لتضمين حالات الحظر المرفوعة. الحظر يتم بأفضل جهد؛ راجع [حظر الطلبات](../../guides/spend-alerts.mdx#block-requests).
