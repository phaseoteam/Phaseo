- `models`: إدخال واحد لكل مجموعة ظاهرة من المزوّد والنموذج والمسار
- `meters`: بنود القياس النشطة لهذا الإدخال، بما في ذلك الوحدة وحجمها والعملة والسعر لكل وحدة
- `display_name`: اسم النموذج العام الظاهر عندما ترتبط قاعدة التسعير بنموذج عام أساسي
