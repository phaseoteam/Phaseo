description: "عرض بطاقات الأسعار النشطة حاليًا في الفهرس والمتاحة عبر البوابة."
---

- `models`: إدخال واحد لكل مجموعة ظاهرة من المزوّد والنموذج والمسار ومستوى الخدمة
- `service_tier`: مستوى خدمة المزوّد الذي تنطبق عليه أسعار الإدخال، مثل `standard` أو `flex` أو `priority`
- `meters`: بنود القياس النشطة لهذا الإدخال، بما في ذلك الوحدة وحجمها والعملة والسعر لكل وحدة
- `display_name`: اسم النموذج العام الظاهر عندما ترتبط قاعدة التسعير بنموذج عام أساسي
