<Note>تتطلب نقطة النهاية هذه `keys:write` على مفتاح إدارة أو رمز OAuth، أو مالك مساحة العمل أو أحد مسؤوليها. ميزة أحمال العمل الموثوقة في المرحلة التجريبية، وتتلقى مساحات العمل التي لا تملكها `404`.</Note>

لا يمكن تغيير المنصة أو المُصدِر أو المالك. أنشئ سياسة جديدة بدلًا من ذلك. تصل التغييرات إلى البوابة خلال دقيقة.

راجع [أحمال العمل الموثوقة](../../developers/trusted-workloads.mdx) لمعرفة كيف تعمل السياسات وكيف تديرها باستخدام Terraform.
