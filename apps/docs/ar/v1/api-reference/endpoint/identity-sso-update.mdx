<Note>تتطلب إدارة الهوية هوية مالك أو مسؤول. كما يتطلب تفعيل SSO أو SCIM وإنشاء رموز التهيئة إضافة الهوية.</Note>

وحده مالك مساحة العمل يمكنه تغيير إعدادات تسجيل الدخول الموحّد، لأن عمليات تسجيل الدخول عبر موفّر الهوية تُربط بمستخدمي دليل مساحة العمل.
