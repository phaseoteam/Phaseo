<Warning>
قيمة `key` مخصصة للكتابة فقط. ويشفّرها Phaseo فورًا ولا يعيدها مطلقًا في استجابات API.
</Warning>

استخدم `routing_mode: "priority"` لتجربة بيانات الاعتماد قبل السعة المُدارة، أو `"fallback"` لتجربتها بعدها. اضبط `byokFallbackEnabled` من إعدادات مساحة العمل للتحكم في السماح بالرجوع إلى السعة المُدارة عند فشل بيانات الاعتماد ذات الأولوية.
