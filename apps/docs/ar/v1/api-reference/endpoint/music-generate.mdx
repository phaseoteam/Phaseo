أرسل `model` و`prompt` إلى `POST /v1/music/generate` لتحصل على مقطوعة من أي مزوّد موسيقى عبر شكل طلب واحد. يتولى Phaseo عنك التعامل مع المزوّدين المتزامنين واستطلاع قوائم انتظار المزوّدين.

```bash
curl https://api.phaseo.app/v1/music/generate \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax/music-3.0:free",
    "prompt": "Warm jazz trio with brushed drums",
    "format": "mp3"
  }'
```

## اقرأ النتيجة

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "gmicloud",
  "model": "minimax/music-3.0:free",
  "nativeResponseId": "5c30b275-d669-4a25-8151-de6d60214853",
  "audio_url": "https://.../generated-music.mp3",
  "usage": {
    "requests": 1,
    "output_audio_seconds": 25.364
  }
}
```

تتضمن عملية التوليد المكتملة `audio_url` أو `audio_base64`. قيمة `status` هي `queued` أو `in_progress` أو `completed` أو `failed`. وعندما لا تكون نهائية بعد، استطلع [`GET /v1/music/generate/{music_id}`](./music-status.mdx) بالمعرّف `id` نفسه.

`id` هو معرّف طلب Phaseo الثابت. و`nativeResponseId` هو معرّف المزوّد، لأغراض الربط مع المزوّد والدعم. يتضمن `usage` الحقل `output_audio_seconds` عندما يبلغ المزوّد عن المدة المولّدة.

## اضبط خيارات Suno

تأخذ نماذج Suno كائن `suno` اختياريًا:

| الحقل | النوع | ملاحظات |
| --- | --- | --- |
| `customMode` | boolean | الافتراضي `false` |
| `instrumental` | boolean | الافتراضي `false` |
| `prompt` | string | يتجاوز `prompt` في المستوى الأعلى |
| `style` و`title` | string | مطلوبان عندما تكون قيمة `customMode` هي `true` |
| `personaId` و`personaModel` | string | |
| `negativeTags` | string | |
| `vocalGender` | `m` أو `f` | |
| `styleWeight` و`weirdnessConstraint` و`audioWeight` | number | من 0 إلى 1 |

يكون `prompt` مطلوبًا عندما تكون قيمة `customMode` هي `false`، وعندما تكون `true` مع ضبط `instrumental` على `false`.

يُرجع الطلب الذي يخالف قاعدة لدى المزوّد `400`:

```json
{
  "error": "validation_error",
  "reason": "..."
}
```
