## أدوات الخادم

تدعم `/v1/responses` أدوات الدوال العادية وأدوات الخادم التالية التي يديرها Gateway:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`
- `phaseo:apply_patch`

### مثال التاريخ والوقت

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "input": [
      { "role": "user", "content": "Give me the current datetime in Asia/Tokyo." }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Asia/Tokyo" }
      }
    ],
    "tool_choice": "auto"
  }'
```

عند استخدام أداة خادم، تتضمن بيانات الاستخدام العدادات المطابقة `usage.server_tool_use.*`.

- `gateway:datetime` -> `datetime_requests`
- `phaseo:web_search` -> `web_search_requests`, `web_search_results`, `web_search_extra_results`
- `phaseo:web_fetch` -> `web_fetch_requests`
- `phaseo:advisor` -> `advisor_requests`
- `phaseo:image_generation` -> `image_generation_requests`
- `phaseo:apply_patch` -> `apply_patch_requests`

## ملاحظة حول البث

يدعم `stream: true` أيضًا. وبالنسبة إلى أدوات الخادم التي يديرها Gateway، قد يعالج Phaseo دور استدعاء الأداة لدى المزوّد، ثم يواصل الحلقة ويعيد إصدار تدفق اصطناعي.

## الاستدلال في حلقات الأدوات

يرسل Phaseo طلبات Responses إلى المزوّد مع `store: false`، لذلك لا يستمر استدلال النموذج بين خطوات حلقة الأدوات إلا عبر عناصر الإخراج `reasoning`.

لكل عنصر `reasoning` قيم `id` و`summary` و`content`. وعندما يعيد المزوّد حالة استدلال، يحتوي العنصر أيضًا على `encrypted_content`:

- الاستدلال المشفّر من OpenAI وAzure OpenAI وxAI. يطلبه Phaseo باستخدام `include: ["reasoning.encrypted_content"]` لنماذج الاستدلال.
- توقيعات التفكير في Claude والتفكير المحجوب.
- توقيعات التفكير في Gemini، بما في ذلك عنصر `reasoning` مستقل يوضع مباشرة قبل استدعاء الدالة الذي ينتمي إليه التوقيع.

تحمل الاستجابات المبثوثة العناصر نفسها في `response.output_item.done` و`response.completed`.

لمتابعة حلقة الأدوات، أعد إرسال جميع عناصر الإخراج في `input` دون تغيير، بما فيها عناصر `reasoning`. قيمة `encrypted_content` معتمة وتسجّل المزوّد والنموذج اللذين أنشآها. لا يرسلها Phaseo إلا إلى عائلة المزوّد هذه وهذا النموذج، لذلك يتجاهلها الرجوع إلى مزوّد آخر بدلًا من أن يفشل الطلب.
