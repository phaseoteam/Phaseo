يتطلب هذا المسار صلاحية الإدارة `activity:read`. ويجب أن يكون لدى مستدعي OAuth أيضًا دور مالك مساحة العمل أو مسؤولها.
</Note>

تتضمن الأحداث بيانات وصفية منقّحة فقط. ولا تُعاد مطلقًا بيانات الاعتماد النصية أو تجزئاتها أو ترويسات التفويض أو قوائم النطاقات الكاملة أو أجسام الطلبات.
