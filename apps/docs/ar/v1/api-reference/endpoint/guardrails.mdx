<Info>
تتطلب إدارة الضوابط الوقائية مفتاح API للإدارة. تتطلب عمليات القراءة `guardrails:read`، وتتطلب التعديلات `guardrails:write` أو `guardrails:delete`.
</Info>

استخدم ضوابط الحماية لتطبيق ضوابط الخصوصية، وقيود المزوّدين والنماذج، والتعامل مع حقن الأوامر، وسياسات المعلومات الحساسة. يمكن تعيين ضابط الحماية لمفاتيح API أو لأعضاء مساحة العمل أو لكليهما.

لا تحدّ ضوابط الحماية من الطلبات أو الإنفاق. استخدم بدلًا من ذلك [حدود مفتاح API](./keys-update.mdx) أو [ميزانيات مساحة العمل](./budgets-list.mdx) أو [تنبيهات الإنفاق](../../guides/spend-alerts.mdx). أُزيل الإدخال `budgets` والحقلان `*_limit_requests` و`*_limit_cost_nanos` من ضوابط الحماية؛ لا يُرفض العميل الذي لا يزال يرسلها، ويتم تجاهلها.

تؤدي التعديلات الناجحة إلى تحديث حالة سياسات مساحة العمل وتظهر في سجل تدقيقها.
