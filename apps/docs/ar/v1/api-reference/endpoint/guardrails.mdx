<Info>
تتطلب إدارة الضوابط الوقائية مفتاح API للإدارة. تتطلب عمليات القراءة `guardrails:read`، وتتطلب التعديلات `guardrails:write` أو `guardrails:delete`.
</Info>

استخدم الضوابط الوقائية لتطبيق ضوابط الخصوصية وقيود المزوّدين والنماذج ومعالجة حقن المطالبات وسياسات المعلومات الحساسة وميزانيات الطلبات أو التكاليف. ويمكن تعيين الضابط لمفاتيح API أو أعضاء مساحة العمل أو كليهما.

تؤدي التعديلات الناجحة إلى تحديث حالة سياسات مساحة العمل وتظهر في سجل تدقيقها.
