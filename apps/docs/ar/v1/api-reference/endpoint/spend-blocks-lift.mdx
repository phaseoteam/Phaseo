يتطلب `spend_rules:write`. يجب أن يكون مستدعو OAuth مالكين أو مشرفين في مساحة العمل. لا يبدأ الحظر مجددًا في الفترة نفسها (وفي القواعد المتجددة لمدة نافذة واحدة)، ويُرسل إشعار **حظر الإنفاق**. تلاحظ الطلبات التغيير خلال دقيقة تقريبًا.
