يتطلب `spend_rules:write`. يجب أن يكون مستدعو OAuth مالكين أو مشرفين في مساحة العمل. أرسل كل مبلغ بالدولار الأمريكي (`*_usd`) أو بالنانودولار (`*_nanos`)، وليس بالاثنين. يمكن أن تحتوي مساحة العمل على 50 قاعدة إنفاق. راجع [دليل تنبيهات الإنفاق](../../guides/spend-alerts.mdx) لمعرفة المقاييس والأسس والنطاقات والفترات.
