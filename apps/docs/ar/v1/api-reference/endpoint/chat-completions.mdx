## استخدم أدوات الخادم

أضف أداة `phaseo:` إلى `tools` بجانب أدوات الدوال الخاصة بك، وسيشغّلها Phaseo عندما يستدعيها النموذج. تقبل `/v1/chat/completions` كل أدوات الخادم باستثناء `phaseo:apply_patch`؛ ويسردها دليل [أدوات الخادم](../../guides/server-tools).

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["Europe/London"] } }
    ],
    "tool_choice": "auto"
  }'
```

يُحتسب كل استدعاء لأداة خادم في `usage.server_tool_use`:

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

تضيف `phaseo:web_search` الحقول `web_search_requests` و`web_search_results` و`web_search_extra_results`؛ وتضيف `phaseo:web_fetch` الحقل `web_fetch_requests`. ولا يزال النوع الأقدم `gateway:datetime` يعمل.

مع `stream: true`، يشغّل Phaseo أدوار الأدوات بنفسه، ثم يبث إليك الإجابة المستكملة في بث واحد.

## الاستدلال في حلقات الأدوات

تُرجع نماذج الاستدلال استدلالها في رسالة المساعد ضمن حقلين:

- `reasoning_content`: نص الاستدلال، إن أعاد المزوّد أيًا منه.
- `reasoning_details`: مصفوفة من كتل الاستدلال. لكل إدخال `type` قيمته `reasoning.text` أو `reasoning.summary` أو `reasoning.encrypted`، و`index`، و`format` يسمّي عائلة المزوّد، مثل `anthropic-claude-v1` أو `google-gemini-v1`.

قد تحمل الإدخالات حالة خاصة بالمزوّد يحتاجها النموذج في الخطوة التالية من حلقة الأدوات:

| حالة المزوّد | أين توجد |
| --- | --- |
| تواقيع التفكير في Claude | `signature` في إدخالات `reasoning.text` |
| التفكير المحجوب في Claude، والاستدلال المشفّر في OpenAI | `data` في إدخالات `reasoning.encrypted` |
| تواقيع الأفكار في Gemini | `data` في إدخالات `reasoning.encrypted` التي يكون `id` فيها هو استدعاء الأداة الذي تنتمي إليه |

عند البث، يصل فرق `reasoning_details` بمجرد اكتمال كل كتلة استدلال.

للحفاظ على استدلال النموذج بين الخطوات، أعد إرسال رسالة المساعد مع `reasoning_details` دون تغيير. قيم `signature` و`data` معتمة، وتسجّل المزوّد والنموذج اللذين أنتجاها. لا يرسلها Phaseo إلا إلى عائلة المزوّد تلك والنموذج نفسه، لذا فإن الرجوع إلى مزوّد آخر يُسقطها بدلًا من أن يفشل. تحتاج نماذج Claude في وضع التفكير اليدوي إلى استعادة تفكيرها لتواصل التفكير أثناء حلقة الأدوات؛ وإذا كان مفقودًا، تعمل تلك الخطوة بلا تفكير.
