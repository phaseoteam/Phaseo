## أدوات الخادم

تدعم `/v1/chat/completions` أدوات الدوال العادية وأدوات الخادم التالية التي يديرها Gateway:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

### مثال التاريخ والوقت

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Europe/London" }
      }
    ],
    "tool_choice": "auto"
  }'
```

عند استخدام أداة خادم، تتضمن بيانات الاستخدام ما يلي:

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

تضيف `phaseo:web_search` الحقول `server_tool_use.web_search_requests` و`server_tool_use.web_search_results` و`server_tool_use.web_search_extra_results`. وتضيف `phaseo:web_fetch` الحقل `server_tool_use.web_fetch_requests`.

## ملاحظة حول البث

يدعم `stream: true` أيضًا. وبالنسبة إلى أدوات الخادم التي يديرها Gateway، قد يعالج Phaseo دور استدعاء الأداة لدى المزوّد، ثم يواصل الحلقة ويعيد إصدار تدفق اصطناعي.

## الاستدلال في حلقات الأدوات

تعيد نماذج الاستدلال استدلالها في حقلين من رسالة المساعد:

- `reasoning_content`: نص الاستدلال، إذا أعاده المزوّد.
- `reasoning_details`: مصفوفة من كتل الاستدلال بالتنسيق الذي يستخدمه OpenRouter. يحتوي كل إدخال على `type` (`reasoning.text` أو `reasoning.summary` أو `reasoning.encrypted`) و`index` و`format` يحدد عائلة المزوّد، مثل `anthropic-claude-v1` أو `google-gemini-v1`.

قد تحمل الإدخالات حالة المزوّد التي يحتاج إليها النموذج في الخطوة التالية من حلقة الأدوات:

- توقيعات التفكير في Claude، في `signature` ضمن إدخالات `reasoning.text`.
- التفكير المحجوب في Claude والاستدلال المشفّر في OpenAI، في `data` ضمن إدخالات `reasoning.encrypted`.
- توقيعات التفكير في Gemini، في `data` ضمن إدخالات `reasoning.encrypted` التي يكون `id` فيها هو استدعاء الأداة الذي تنتمي إليه.

عند البث، يصل تغيير `reasoning_details` عند اكتمال كل كتلة استدلال.

للحفاظ على استدلال النموذج بين الخطوات، أعد إرسال رسالة المساعد مع `reasoning_details` دون تغيير. قيم `signature` و`data` معتمة وتسجّل المزوّد والنموذج اللذين أنشآها. لا يرسلها Phaseo إلا إلى عائلة المزوّد هذه وهذا النموذج، لذلك يتجاهلها الرجوع إلى مزوّد آخر بدلًا من أن يفشل الطلب. تحتاج نماذج Claude في وضع التفكير اليدوي إلى استعادة تفكيرها لمواصلة التفكير أثناء حلقة الأدوات؛ وإذا كان مفقودًا، تعمل تلك الخطوة دون تفكير.
