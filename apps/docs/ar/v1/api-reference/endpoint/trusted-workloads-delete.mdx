<Note>تتطلب نقطة النهاية هذه `keys:delete` على مفتاح إدارة أو رمز OAuth، أو مالك مساحة العمل أو أحد مسؤوليها. ميزة أحمال العمل الموثوقة في المرحلة التجريبية، وتتلقى مساحات العمل التي لا تملكها `404`.</Note>

تُرفض الرموز المطابقة خلال دقيقة. تحتفظ الطلبات السابقة بمفتاحها في السجلات والاستخدام.

راجع [أحمال العمل الموثوقة](../../developers/trusted-workloads.mdx) لمعرفة كيف تعمل السياسات وكيف تديرها باستخدام Terraform.
