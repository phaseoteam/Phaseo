نقطة النهاية هذه في [المرحلة التجريبية](../../developers/feature-maturity.mdx)، وتُفعَّل لكل مساحة عمل عند الطلب.

<Note>تتطلب إدارة دليل المؤسسة إضافة الهوية، وهوية مالك أو مسؤول، ونطاق الإعدادات المطابق.</Note>

إذا كانت تعيينات مجموعات الدليل تستخدم القسم، فوحده مالك مساحة العمل يمكنه حذفه، لأن حذفه يحذف أيضًا تلك التعيينات والأدوار التي تمنحها.
