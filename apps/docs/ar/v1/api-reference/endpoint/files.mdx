احفظ `file_id` المُعاد واستخدمه مجددًا مع:

- `POST /v1/batches`
- `GET /v1/files/{file_id}`
- `GET /v1/files/{file_id}/content`

<Note>
لا يتوفر `GET /v1/files` حاليًا باستخدام مفتاح البوابة المشترك، لذا تُعد استجابة التحميل المرجع الأساسي للحصول على معرّف الملف.
</Note>
