يتطلب `spend_rules:write`. يُرسل الاختبار إلى وجهات القاعدة، أو إلى مسار **تنبيهات الإنفاق** إذا لم تكن لها وجهات. لا يُسجَّل أي شيء. يمكن لمساحة العمل إرسال خمسة اختبارات في الدقيقة؛ وما يزيد يعيد `429` مع `Retry-After`.
