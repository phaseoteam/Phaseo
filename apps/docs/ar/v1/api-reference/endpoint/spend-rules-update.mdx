يتطلب `spend_rules:write`. تُدمج الحقول التي ترسلها مع القاعدة المحفوظة، ثم يُعاد فحص القاعدة كاملة. يستبدل `destination_ids` وجهات القاعدة؛ احذفه للإبقاء عليها. يؤدي تغيير إجراء قاعدة حاظرة أو نطاقها أو فترتها أو أساسها إلى رفع حظرها النشط.
