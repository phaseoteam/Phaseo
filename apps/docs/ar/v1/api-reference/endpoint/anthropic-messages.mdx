أرسل حمولة Anthropic Messages API إلى `/v1/messages` واحصل على استجابة بتنسيق Anthropic، لأي نموذج يوجّه إليه Phaseo. حقول استخدام الأدوات في Anthropic مدعومة، وتتحكم الترويسة `X-Phaseo-Strictness` في كيفية التعامل مع المعاملات غير المدعومة.

اضبط `stream: true` لتلقي أحداث مرسلة من الخادم بتنسيق Anthropic (`message_start` و`content_block_*` و`message_delta` و`message_stop`). ويعمل البث أيضًا في حلقات الأدوات.

## رسائل النظام في منتصف المحادثة

أضف رسالة `role: "system"` إلى `messages` لتعليمة تسري من تلك النقطة في المحادثة. يبقى الحقل `system` في المستوى الأعلى كما هو، لذا تظل البادئة المخزّنة مؤقتًا تُصاب.

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5.5",
    "max_tokens": 512,
    "system": "You are a code review assistant.",
    "messages": [
      { "role": "user", "content": "Review process() in utils.py." },
      { "role": "assistant", "content": "The loop is fine; the regex is compiled on every call." },
      { "role": "user", "content": "Now review the code that calls it." },
      { "role": "system", "content": "From now on, include type annotations in every suggestion." }
    ]
  }'
```

تقبل رسالة النظام سلسلة نصية أو كتلًا نصية. يجب أن تأتي مباشرة بعد دور للمستخدم (أو دور للمساعد ينتهي بنتيجة أداة خادم)، وأن تكون الرسالة الأخيرة أو يتبعها دور للمساعد. تُرجع المواضع الأخرى `400`. لا تُدعم `clear_at` و`output_config` وكتل `tool_addition` أو `tool_removal`.

| النموذج | كيف يتلقى رسالة النظام |
| --- | --- |
| Claude Fable 5 و5.1، وMythos 5 و5.1، وOpus 4.8، وOpus 5 و5.5، وSonnet 5.5، وHaiku 5.5 | في موضعها |
| نماذج Claude الأخرى، بما فيها Sonnet 5، وكل نماذج Claude على Microsoft Foundry | مدمجة في مطالبة النظام في المستوى الأعلى |
| نماذج المزوّدين الآخرين | بوصفها رسالة نظام، كما لو أُرسلت إلى Chat Completions |

## استخدم أدوات الخادم

أضف أداة `phaseo:` إلى `tools` وسيشغّلها Phaseo عندما يستدعيها النموذج، محوّلًا إياها إلى تنسيق أدوات Anthropic عند إرسالها إلى المزوّد ومواصلًا حلقة الأدوات من جانب الخادم. تقبل `/v1/messages` كل أدوات الخادم باستثناء `phaseo:apply_patch`؛ ويسردها دليل [أدوات الخادم](../../guides/server-tools).

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "What time is it in America/New_York right now?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["America/New_York"] } }
    ],
    "tool_choice": { "type": "auto" }
  }'
```

تُحتسب استدعاءات أدوات الخادم في `usage.server_tool_use`. ولا يزال النوع الأقدم `gateway:datetime` يعمل. مع `stream: true`، يشغّل Phaseo أدوار الأدوات بنفسه، ثم يبث إليك الإجابة المستكملة في بث واحد.

## استخدم بحث الويب الأصلي في Anthropic

عندما يدعم نموذج Anthropic والمزوّد الموجَّه إليهما بحث الويب الأصلي، مرّر تعريف أداة Anthropic مباشرة، مثل `type: "web_search_20250305"`. ويظل توجيه المزوّدين يصفّي حسب دعم `web_search_options` قبل التنفيذ.

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "Find the latest Anthropic web search guidance." }
    ],
    "tools": [
      {
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": 3,
        "allowed_domains": ["docs.anthropic.com"]
      }
    ],
    "tool_choice": { "type": "auto" }
  }'
```
