تقبل `/v1/messages` أجسام طلبات Anthropic Messages API وتعيد استجابات بتنسيق Anthropic.

## البث

اضبط `stream: true` لتلقي أحداث مرسلة من الخادم بتنسيق Anthropic (`message_start` و`content_block_*` و`message_delta` و`message_stop`).

## رسائل النظام في منتصف المحادثة

أضف رسالة `role: "system"` إلى `messages` لتعليمة تنطبق من تلك النقطة في المحادثة. يبقى الحقل `system` على المستوى الأعلى كما هو، لذا يظل التخزين المؤقت للبادئة يعمل.

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5.5",
    "max_tokens": 512,
    "system": "You are a code review assistant.",
    "messages": [
      { "role": "user", "content": "Review process() in utils.py." },
      { "role": "assistant", "content": "The loop is fine; the regex is compiled on every call." },
      { "role": "user", "content": "Now review the code that calls it." },
      { "role": "system", "content": "From now on, include type annotations in every suggestion." }
    ]
  }'
```

- تقبل رسالة النظام سلسلة نصية أو كتلًا نصية. يجب أن تأتي مباشرةً بعد دور المستخدم (أو بعد دور المساعد الذي ينتهي بنتيجة أداة خادم)، وأن تكون الرسالة الأخيرة أو يليها دور المساعد. تُرجع المواضع الأخرى الخطأ 400.
- تتلقاها نماذج Claude Fable 5 و5.1 وMythos 5 و5.1 وOpus 4.8 وOpus 5 و5.5 وSonnet 5.5 وHaiku 5.5 في موضعها. أما نماذج Claude الأخرى، ومنها Sonnet 5، وكل نماذج Claude على Microsoft Foundry، فتتلقاها جزءًا من موجّه النظام على المستوى الأعلى. ويتلقاها المزوّدون الآخرون رسالةَ نظام، كما لو أُرسلت إلى Chat Completions.
- لا يُدعم `clear_at` ولا `output_config` ولا كتل `tool_addition` أو `tool_removal`.

## ملاحظات

- حقول استخدام الأدوات الخاصة بـ Anthropic مدعومة.
- يعمل `stream: true` أيضًا مع حلقات الأدوات. وبالنسبة إلى أدوات الخادم التي يديرها Gateway، قد يعالج Phaseo الدور لدى المزوّد، ثم يواصل الحلقة ويعيد إصدار تدفق اصطناعي.
- يُقبل شكل أداة البحث على الويب الأصلي من Anthropic مباشرة ضمن `tools` أيضًا، مثل `type: "web_search_20250305"`.
- تتحكم ترويسة `X-Phaseo-Strictness` في كيفية التعامل مع المعلمات غير المدعومة.

## أدوات الخادم

تدعم `/v1/messages` أيضًا أدوات الخادم التالية التي يديرها Gateway:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

يحوّل Phaseo هذه الأدوات إلى تنسيق متوافق مع Anthropic لدى المزوّد، وينفّذها على الخادم، ثم يواصل حلقة الأدوات.

## بحث الويب الأصلي للمزوّد

عندما يدعم زوج متوافق من نموذج Anthropic ومزوّده بحث الويب الأصلي، يمكنك تمرير تعريف الأداة الأصلي مباشرة أيضًا:

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-4",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "Find the latest Anthropic web search guidance." }
    ],
    "tools": [
      {
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": 3,
        "allowed_domains": ["docs.anthropic.com"]
      }
    ],
    "tool_choice": { "type": "tool", "name": "web_search" }
  }'
```

يظل توجيه المزوّد يتحقق من دعم `web_search_options` قبل التنفيذ.

### مثال التاريخ والوقت

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-4",
    "max_tokens": 512,
    "stream": false,
    "messages": [
      { "role": "user", "content": "What time is it in America/New_York right now?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "America/New_York" }
      }
    ],
    "tool_choice": { "type": "auto" }
  }'
```

عند الاستخدام، تسجّل العدادات `usage.server_tool_use.*` استدعاءات أدوات الخادم.
