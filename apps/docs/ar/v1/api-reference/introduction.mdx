استخدم هذه الصفحة للعثور على مسار API الصحيح قبل فتح مرجع نقطة النهاية. تشترك جميع نقاط نهاية Phaseo Gateway في عنوان URL أساسي واحد وتستخدم مصادقة Bearer.

## اختيار المسار

| إذا أردت | ابدأ من |
| --- | --- |
| إرسال طلبك الأول | [البدء السريع](../quickstart.mdx) |
| توليد النص أو استخدام الأدوات | `POST /responses` |
| الإبقاء على تكامل OpenAI متوافق موجود | `POST /chat/completions` |
| تصفح النماذج والمزوّدين | `GET /models` و`GET /providers` |
| إنشاء الموسيقى أو إدارة الملفات | `POST /music/generations` و`POST /files` |

## عنوان URL الأساسي

عنوان URL الأساسي للإنتاج:

```http
https://api.phaseo.app/v1
```

جميع مسارات نقاط النهاية في هذا المرجع نسبية إلى عنوان `/v1` الأساسي.

## المصادقة

تتطلب معظم نقاط النهاية مفتاح Gateway API عاديًا. وتتطلب نقاط الإدارة مفتاح إدارة API تم إنشاؤه في لوحة التحكم.

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

عند فشل المصادقة، تعيد API الرمز `401`.

## موارد API

| المورد | وظيفته |
| --- | --- |
| Responses API | إنشاء استجابات للنماذج مع الأدوات والإخراج المنظم والإدخال متعدد الوسائط. |
| Chat Completions | الإبقاء على تكامل دردشة متوافق مع OpenAI موجود. |
| Anthropic Messages | الإبقاء على تكامل Messages متوافق مع Anthropic موجود. |
| Embeddings | إنشاء تمثيلات متجهة للبحث والاسترجاع والتصنيف. |
| الصور | إنشاء الصور أو تعديلها. |
| تحويل النص إلى كلام | إنشاء صوت منطوق من النص. |
| تحويل الكلام إلى نص | تفريغ الصوت نصيًا أو ترجمته. |
| توليد الموسيقى | إنشاء مهام الموسيقى والاطلاع على حالتها. |
| الملفات | تحميل المدخلات واستعادتها لتدفقات عمل API المدعومة. |
| النماذج والمزوّدون ونقاط النهاية | استكشاف ما هو متاح عبر Gateway. |
| الأسعار والنشاط وعمليات التوليد | تقدير التكلفة وفحص نتائج الطلبات. |
| مفاتيح API ومساحات العمل | إدارة الوصول البرمجي وموارد مساحة العمل. |

## الفوترة وحدود المعدل

- لا تفرض Phaseo حدود معدل خاصة بها؛ بل يفرضها المزوّدون الأساسيون.
- تتطلب الطلبات المدفوعة رصيدًا كافيًا في المحفظة لاجتياز فحص الرصيد المسبق.
- لا تتطلب النماذج المجانية التي تحمل `:free` رصيدًا مودعًا.
