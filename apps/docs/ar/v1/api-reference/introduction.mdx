أرسل كل طلب إلى `https://api.phaseo.app/v1` مع مفتاحك في ترويسة `Authorization: Bearer`. ابحث أدناه عن نقطة النهاية المناسبة لمهمتك، ثم افتح صفحتها المرجعية.

## اعثر على نقطة النهاية المناسبة

| إذا أردت | ابدأ من |
| --- | --- |
| إرسال طلبك الأول | [البدء السريع](../quickstart) |
| توليد النص أو استخدام الأدوات | [`POST /responses`](./endpoint/responses) |
| اتخاذ قرارات ذات أنواع محددة | [`POST /decisions`](./endpoint/decisions) |
| الإبقاء على تكامل موجود متوافق مع OpenAI | [`POST /chat/completions`](./endpoint/chat-completions) |
| تصفح النماذج والمزوّدين | [`GET /models`](./endpoint/models) و[`GET /providers`](./endpoint/providers) |
| إنشاء الموسيقى أو إدارة الملفات | [`POST /music/generate`](./endpoint/music-generate) و[`POST /files`](./endpoint/files) |
| توليد فيديو (تجريبي) | [`POST /videos`](./endpoint/video-create) |
| إرسال دفعة أو تنزيل النتائج (تجريبي) | [`POST /batches`](./endpoint/batches-create) و[`GET /batches/{batch_id}/results`](./endpoint/batches-results) |

## عنوان URL الأساسي

```http
https://api.phaseo.app/v1
```

كل مسار نقطة نهاية في هذا المرجع نسبي إلى عنوان URL الأساسي هذا.

## المصادقة

| بيانات الاعتماد | التنسيق | ما تستدعيه |
| --- | --- | --- |
| [مفتاح Gateway API](../developers/authentication.mdx) | `phaseo_v1_sk_<kid>_<secret>` | نقاط نهاية الاستدلال |
| [مفتاح API للإدارة](../developers/management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | نقاط نهاية الإدارة، في حدود أذونات المفتاح |

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

إذا فشلت المصادقة، تُرجع API الرمز `401`.

## موارد API

| المورد | وظيفته |
| --- | --- |
| الاستدلال | ولّد نصوصًا وصورًا وصوتًا وتضمينات؛ واتخذ قرارات وأعد الترتيب وراجع المحتوى أو حلّله. ابدأ بـ[Responses](./endpoint/responses.mdx) أو [Decisions](./endpoint/decisions.mdx). |
| المهام غير المتزامنة والملفات | أرسل مهام [فيديو](./endpoint/video-create.mdx) أو [دفعات](./endpoint/batches-create.mdx)، وانقل الملفات واضبط الويب هوك. |
| النماذج والتسعير | اكتشف [النماذج](./endpoint/models.mdx) وعروض المزوّدين و[التكاليف التقديرية](./endpoint/pricing-calculate.mdx). |
| التوجيه والسياسات | اضبط الإعدادات المسبقة وبيانات اعتماد المزوّدين والنماذج الخاصة و[ضوابط الحماية](./endpoint/guardrails.mdx). |
| الاستخدام والمراقبة | افحص [السجلات](./endpoint/logs-list.mdx) والنشاط والتحليلات والتقييمات وحالة الخدمة. |
| إدارة مساحة العمل | أدِر [مساحات العمل](./endpoint/workspaces-list.mdx) والمفاتيح والميزانيات والهويات والتكاملات. |

## الفوترة وحدود المعدل

تحتاج الطلبات المدفوعة إلى رصيد كافٍ في المحفظة لاجتياز فحص الرصيد قبل تنفيذها. لا تحتاج النماذج التي ينتهي معرّفها بـ `:free` إلى رصيد مودع. قد يُقيَّد معدل الطلبات من جانب مزوّد أو بحدود مساحة العمل والمفتاح؛ راجع [حدود المعدل](./limits.mdx).
