# Anthropic Claude Opus 4.7

استخدم هذا الدليل لاعتماد `anthropic/claude-opus-4.7` بأمان في الإنتاج.

يُدخل Claude Opus 4.7 تغييرات على تنسيق الطلب؛ وقد تفشل أنماط 4.6 القديمة بالكامل إذا لم تُحدّث.

## الجديد

- مستوى جهد جديد: `xhigh` (واجهة Messages).
- أُزيلت ميزانيات التفكير الموسّع في Opus 4.7؛ وأصبح `thinking: { type: "enabled", budget_tokens: ... }` يفشل.
- لم تعد معلمات أخذ العينات غير الافتراضية مدعومة لهذا النموذج: `temperature` و`top_p` و`top_k`.
- يُحذف محتوى التفكير افتراضيًا ما لم تفعّله صراحةً.
- قد يزيد مرمّز الرموز المحدّث استهلاك الرموز مقارنةً بـ Opus 4.6.

## سلوك التوافق في Phaseo Gateway

لتقليل مشكلات الترحيل، يقبل Phaseo حقول Opus 4.6 القديمة مع Opus 4.7 ويوحّدها قبل إرسالها إلى المزوّد:

- تُقبل `temperature` و`top_p` و`top_k` ثم تُحذف.
- لا تُمرر ميزانيات التفكير القديمة.
- يُرسل تفكير Opus 4.7 دائمًا بهذه الصيغة: `thinking: { "type": "adaptive", "display": "summarized" }`.
- يظل `reasoning.effort` مدعومًا ويُحوّل إلى `output_config.effort`، مع دعم `xhigh`.

## البدء السريع للترحيل

### 1. حدّث معرّف النموذج

عيّن المعرّف إلى `anthropic/claude-opus-4.7`.

### 2. استخدم التفكير التكيفي مع عرض الملخص

في Opus 4.7، استخدم:

- `thinking: { "type": "adaptive", "display": "summarized" }`

تجنّب ميزانيات التفكير الموسّع القديمة.

### 3. أزل ضوابط أخذ العينات

لا ترسل:

- `temperature`
- `top_p`
- `top_k`

اضبط المطالبات والتعليمات بدلًا منها.

### 4. أعد ضبط مستويات الجهد

إذا كنت تستخدم ضوابط الاستدلال، فأعد الاختبار بالقيم التالية:

- `output_config.effort = "high"` كخط أساس.
- `output_config.effort = "xhigh"` لأصعب مسارات البرمجة والوكلاء.

عند استدعاء Phaseo بحمولة بأسلوب OpenAI، يُحوّل `reasoning.effort` إلى قيمة `output_config.effort` نفسها في Opus 4.7.

### 5. أعد التحقق من حدود الرموز

بسبب تغيير الترميز، راجع:

- `max_tokens` / `max_output_tokens`
- ميزانيات المهلة
- ضوابط التكلفة والتنبيهات

## ما ينبغي اختباره

- معدل اجتياز إخراج المخططات الصارمة بمطالبات الإنتاج.
- تدفقات الأدوات طويلة الأمد: عدد الاستدعاءات ومعدل الإكمال وزمن الاستجابة.
- فروق جودة المخرجات بين `high` و`xhigh`.
- فروق تكلفة الرموز في فئات المطالبات الأعلى استخدامًا.

## طرح آمن

1. انشر تغييرات تنسيق الطلب قبل تحويل حركة المرور.
2. شغّل Opus 4.7 على مجموعة تقييم الإنتاج بالتوازي.
3. اختبر تدريجيًا مع إبقاء التراجع إلى Opus 4.6 ممكنًا.
4. وسّع الطرح عندما تقع فروق الجودة وزمن الاستجابة والتكلفة ضمن الأهداف.
