غيّر النموذج إلى `anthropic/claude-opus-4.7`، وأسقط معاملات أخذ العينات وميزانيات التفكير، وحدد العمق بمستوى جهد. الطلبات التي لا تزال تحمل حقول Opus 4.6 لا تفشل على Phaseo؛ إذ تعيد البوابة كتابتها كما هو موضح أدناه.

| طلب Opus 4.6 | ما يرسله Phaseo إلى Opus 4.7 |
| --- | --- |
| `temperature` و`top_p` و`top_k` | تُحذف. كانت Anthropic ستعيد `400` للقيم غير الافتراضية. |
| `thinking: {"type": "enabled", "budget_tokens": …}` | `thinking: {"type": "adaptive", "display": "summarized"}`؛ ولا تُمرَّر الميزانية. |
| `reasoning.effort` | `output_config.effort`، بما في ذلك `xhigh`. |
| `reasoning.effort: "none"` أو `reasoning.enabled: false` | `thinking: {"type": "disabled"}`. |
| لا يوجد إعداد استدلال | لا يوجد حقل `thinking`، لذا لا يفكر Opus 4.7. |

يخفي Opus 4.7 أيضًا محتوى التفكير ما لم تختر إظهاره؛ ويطلب Phaseo العرض الملخّص كلما فعّل التفكير. وقد ينتج مقسّم الرموز فيه رموزًا أكثر من Opus 4.6 للنص نفسه.

## تحديث الطلب

1. اضبط معرّف النموذج على `anthropic/claude-opus-4.7`.
2. أزل `temperature` و`top_p` و`top_k`، واضبط السلوك بالتعليمات بدلًا منها.
3. استبدل ميزانيات التفكير بالتفكير التكيفي ومستوى جهد:

```json
{
  "model": "anthropic/claude-opus-4.7",
  "messages": [{ "role": "user", "content": "Refactor this module and explain the risks." }],
  "reasoning": { "effort": "xhigh" }
}
```

ابدأ بـ `high` واستخدم `xhigh` لأصعب مسارات البرمجة والوكلاء. على `/v1/messages`، أرسل `thinking: {"type": "adaptive"}` مع `output_config.effort` بدلًا من ذلك.

4. لأن مقسّم الرموز تغيّر، راجع `max_tokens` و`max_output_tokens` وميزانيات المهلة وتنبيهات التكلفة.

## ما الذي يجب اختباره

- معدل نجاح المخطط على مطالبات الإنتاج لديك؛
- مسارات عمل الأدوات طويلة التشغيل: عدد استدعاءات الأدوات ومعدل الإنجاز وزمن الاستجابة؛
- الجودة عند `high` مقارنة بـ `xhigh`؛
- تكلفة الرموز لفئات المطالبات الأعلى حجمًا لديك.

## النشر

1. انشر تغييرات شكل الطلب قبل نقل الحركة.
2. شغّل Opus 4.7 في وضع الظل على مجموعة تقييم الإنتاج لديك.
3. انشر تجريبيًا (canary) مع Opus 4.6 كنموذج احتياطي في `models`.
4. رقِّ النموذج بعد أن تصبح تغييرات الجودة وزمن الاستجابة والتكلفة ضمن الهدف.
