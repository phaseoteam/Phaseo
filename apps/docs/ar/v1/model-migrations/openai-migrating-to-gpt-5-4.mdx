غيّر النموذج إلى `openai/gpt-5.4`، واحتفظ ببقية الطلب، واختر مستوى جهد الاستدلال لكل مسار. شكل الطلب مماثل لنماذج GPT-5 السابقة؛ والذي يتغير هو نطاق الجهد وتفاصيل الصور وأداة الحاسوب. لا يصف توثيق OpenAI معامل `phase` خاصًا بـ GPT-5.4.

| التغيير | ما الذي يجب فعله |
| --- | --- |
| يقبل `reasoning.effort` القيم `none` و`low` و`medium` و`high` و`xhigh` | أعد اختبار كل مسار عند مستوى الجهد الذي يناسب ميزانية زمن الاستجابة الخاصة به. |
| إدخال الصور `detail: "original"` للإدراك بأعلى دقة | اختبره بشكل منفصل: فهو يغيّر الجودة والتكلفة. |
| أداة `computer` المحدّثة هي مسار استخدام الحاسوب | انقل أتمتة المتصفح وسطح المكتب إليها وأعد الاختبار من البداية إلى النهاية. |
| استخدام أفضل للأدوات في المهام طويلة الأمد، وللعمل بالسياق الكبير، ولمسارات عمل المستندات | أعد تشغيل تقييمات الوكلاء والمستندات لديك. |

```json
{
  "model": "openai/gpt-5.4",
  "input": "Summarize the open risks in this design review.",
  "reasoning": { "effort": "medium" }
}
```

## اختيار مستوى جهد الاستدلال

إذا كنت قادمًا من GPT-4.1 أو نموذج GPT-5 أقدم، فلا تفترض أن إعداداتك الافتراضية السابقة لا تزال مناسبة:

| المسار | ابدأ بـ |
| --- | --- |
| زمن استجابة منخفض | `none` أو `low` |
| معظم المهام المنظّمة | `medium` أو `high` |
| الاستدلال العميق ومسارات عمل الوكلاء | `xhigh` |

## إرسال الصور بكامل التفاصيل

للقطات الشاشة الكثيفة أو المستندات أو توطين واجهات المستخدم، اضبط `detail: "original"` على إدخال الصورة. يمرّره Phaseo إلى المزوّدين الذين يدعمونه، بما في ذلك OpenAI وAzure، ويرسل `high`، وهو أقرب مستوى، إلى المزوّدين الذين لا يدعمونه.

## نقل استخدام الحاسوب إلى أداة `computer`

حدّث أتمتة المتصفح وسطح المكتب لتستخدم أداة `computer`، وأعد اختبار إنجاز الخطوات عبر المهام الكاملة. لا تُوجَّه الأدوات المستضافة إلا إلى المزوّدين الذين يشغّلونها.

## ما الذي يجب اختباره

- **المطالبات:** مطالبات النظام الطويلة، والاستخراج والتصنيف، والمخرجات الحساسة للتنسيق، والمطالبات التي احتاجت إلى إعادة محاولات للبقاء ضمن المهمة.
- **الأدوات والمخرجات المنظّمة:** الالتزام بالمخطط عند كل مستوى جهد، واختيار الأدوات، واكتمال الوسائط، واستقرار استخدام الحاسوب متعدد الخطوات.
- **الرؤية والعمليات:** لقطات الشاشة والمستندات بتفاصيل `high` مقابل `original`، وزمن الاستجابة واستخدام الرموز تحت الحمل، ومعدل إعادة المحاولة وانتهاء المهلة، والتكلفة لكل مهمة ناجحة مقارنة بالنموذج الذي تستبدله.

## النشر

1. قِس أداء GPT-5.4 عند مستويات الجهد نفسها التي ستستخدمها.
2. شغّل مطالبات الإنتاج في وضع الظل قبل تبديل مسار افتراضي.
3. رقِّ النموذج تدريجيًا، مع نموذج OpenAI أقدم أو مزوّد آخر كنموذج احتياطي في `models`.
