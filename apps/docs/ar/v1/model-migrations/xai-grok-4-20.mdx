غيّر معرّف النموذج وأعد تشغيل مجموعة التحقق لديك؛ إذ تبقى أشكال الطلب والاستجابة كما هي. عنصر التحكم الجديد الوحيد هو مدى عمق عمل نسخة الوكلاء المتعددين.

| النموذج | معرّف النموذج في Phaseo | التحكم في الاستدلال |
| --- | --- | --- |
| Grok 4.20 | `spacex-ai/grok-4.20` | `reasoning.enabled`: مفعّل أو متوقف |
| Grok 4.20 Multi-Agent (تجريبي) | `spacex-ai/grok-4.20-multi-agent-beta` | `reasoning.effort`: `low` أو `medium` أو `high` |

## تبديل الاستدلال في Grok 4.20

اضبط `reasoning.enabled: true` لاستخدام نسخة الاستدلال من النموذج. دونه، أو مع `false`، يستدعي Phaseo النسخة غير المستدلّة.

```json
{
  "model": "spacex-ai/grok-4.20",
  "input": "Explain this architecture",
  "reasoning": { "enabled": true }
}
```

## تحديد العمق في نموذج الوكلاء المتعددين

تحكّم في العمق باستخدام `reasoning.effort`. لا تقبل طلبات البوابة `agent_count` الخاص بـ xAI؛ ووفقًا لـ xAI، يشغّل `low` و`medium` أربعة وكلاء، ويشغّل `high` إعدادًا أكبر.

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": { "effort": "medium" }
}
```
