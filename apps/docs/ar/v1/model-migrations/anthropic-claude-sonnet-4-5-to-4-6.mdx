# Anthropic Claude Sonnet 4.6

استخدم هذا الدليل لاعتماد `anthropic/claude-sonnet-4.6` بأمان في الإنتاج.

يتبع Sonnet 4.6 آليات الترحيل نفسها المستخدمة في بقية سلسلة Claude 4.6، لكن ملف الأداء تغيّر بما يكفي لإعادة التحقق من افتراضات المطالبات والتوجيه.

## الجديد

- لم تعد نماذج Claude 4.6 تدعم البادئات المسبقة للمساعد وتعيد `400`.
- انتقلت المخرجات المنظّمة من `output_format` إلى `output_config.format`.
- يُضبط التفكير التكيفي عبر `output_config.effort`.
- أزل عناوين beta القديمة.
- يشكّل Sonnet 4.6 ترقية شاملة للبرمجة واستخدام الحاسوب والاستدلال طويل السياق وتخطيط الوكلاء واتباع التعليمات.
- يضيف Sonnet 4.6 نافذة سياق بمليون رمز في beta.

## البدء السريع للترحيل

### 1. أوقف استخدام بادئات المساعد المسبقة

إذا كانت مطالبات Sonnet 4.5 تبدأ دور المساعد ببادئة JSON أو علامة XML أو قالب تنسيق، فأزل هذا النمط قبل الطرح.

### 2. انقل إعداد المخرجات المنظّمة

استبدل `output_format` بـ `output_config.format` وأعد اختبارات المخططات والمحلّل.

### 3. أعد ضبط مستوى الجهد وتوقعات زمن الاستجابة

إذا كنت تستخدم Sonnet للمسارات التفاعلية، فقارن مستويات `effort` المختلفة قبل جعل 4.6 افتراضيًا. النموذج أقوى، لكن الإعداد الأنسب يعتمد على ميزانية زمن الاستجابة لديك.

## ما ينبغي اختباره

### سلوك المخرجات

- اتباع التعليمات في المطالبات الحساسة للتنسيق.
- جودة تخطيط الوكلاء للمهام متعددة الخطوات.
- مطالبات البرمجة وإعادة الهيكلة والمراجعة.
- استرجاع المعلومات وتلخيصها من السياق الطويل.

### استقرار العقود

- معدل اجتياز التحقق من JSON والمخططات.
- اكتمال وسائط الأدوات.
- أسباب الإنهاء والتعامل مع المخرجات الفارغة.
- المسارات التي اعتمدت سابقًا على البادئات المسبقة لتثبيت التنسيق.

### مقاييس الإنتاج

- زمن الاستجابة بحسب مستوى الجهد.
- نجاح المهام مقارنةً بـ Sonnet 4.5.
- معدلات انتهاء المهلة وإعادة المحاولة.
- التكلفة لكل مهمة ناجحة.

## طرح آمن

1. أزل البادئات المسبقة وحدّث إعداد المخرجات المنظّمة أولًا.
2. قيّم Sonnet 4.6 على مجموعة مطالبات الإنتاج الحالية.
3. اختبر حركة المرور تدريجيًا مع إبقاء Sonnet 4.5 أو مسار مستقر آخر بديلًا.
4. زد حركة المرور فقط بعد استقرار الجودة والعقود.
