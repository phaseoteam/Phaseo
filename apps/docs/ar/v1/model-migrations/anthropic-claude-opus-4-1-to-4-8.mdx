# Anthropic Claude Opus 4.8

استخدم هذا الدليل لاعتماد `anthropic/claude-opus-4.8` بأمان في الإنتاج.

أوقفت Anthropic اعتماد Claude Opus 4.1 في 5 يونيو 2026 وحددت 5 أغسطس 2026 موعدًا لإيقافه. إرشادات الترحيل تراكمية: طبّق أولًا تغييرات تنسيق الطلب الخاصة بـ Opus 4.7، ثم راجع تغييرات السلوك في Opus 4.8.

## الجديد

- معرّف نموذج Phaseo هو `anthropic/claude-opus-4.8`.
- ترفض إصدارات Opus 4.7 وما بعدها معلمات أخذ العينات غير الافتراضية مثل `temperature` و`top_p` و`top_k`.
- ترفض إصدارات Opus 4.7 وما بعدها ميزانيات التفكير الموسّع اليدوية؛ استخدم التفكير التكيفي.
- يضبط Opus 4.8 `output_config.effort` على `high` افتراضيًا.
- يدعم Opus 4.8 رسائل النظام في منتصف المحادثة.
- يرفع Opus 4.8 الحدود الأساسية إلى مليون رمز للسياق و128 ألف رمز كحد أقصى للإخراج في Claude API وClaude Platform على AWS وAmazon Bedrock وVertex AI.

## البدء السريع للترحيل

### 1. حدّث معرّف النموذج

عيّن معرّف النموذج إلى `anthropic/claude-opus-4.8`.

### 2. أزل معلمات أخذ العينات غير الافتراضية

إذا كانت طلبات Opus 4.1 تضبط أيًا من هذه القيم، فأزلها قبل الطرح:

- `temperature`
- `top_p`
- `top_k`

تعيد القيم غير الافتراضية لهذه الحقول `400` في Opus 4.7 وما بعده.

### 3. استبدل ميزانيات التفكير اليدوية بالتفكير التكيفي

إذا كنت ترسل حمولة تفكير قديمة مثل:

- `thinking: { "type": "enabled", "budget_tokens": 32000 }`

فاستخدم بدلًا منها:

- `thinking: { "type": "adaptive" }`
- `output_config.effort = "high"` كقيمة أساسية

### 4. أعد ضبط توقعات الجهد والسياق الطويل

يستخدم Opus 4.8 `high` افتراضيًا ويدعم سياقًا أكبر بكثير من Opus 4.1 على واجهات API التي تشغلها Anthropic. أعد اختبار:

- ميزانيات زمن الاستجابة
- استهلاك الرموز
- سلوك تخزين المطالبات مؤقتًا
- المستندات الطويلة وآثار الوكلاء

إذا كنت تستخدم Microsoft Foundry، فلا تفترض توافر نافذة المليون رمز عند الإطلاق؛ توثّق Anthropic نافذة سياق تبلغ 200 ألف رمز لـ Opus 4.8 على Foundry.

### 5. أعد التحقق من تحديث التعليمات في المحادثات الطويلة

يدعم Opus 4.8 رسائل النظام في منتصف المحادثة. إذا كانت حلقة الوكيل تعيد كتابة مطالبة النظام بالكامل في كل دور، فقد تتمكن من تبسيط التدفق والحفاظ على مزيد من إصابات الذاكرة المؤقتة.

## ما ينبغي اختباره

- الطلبات التي لا تزال ترسل `temperature` أو `top_p` أو `top_k`.
- مسارات التفكير التي اعتمدت سابقًا على `budget_tokens`.
- سير عمل الوكلاء والأدوات طويل الأمد.
- المخرجات الحساسة للمخططات مع مستويات `effort` صريحة.
- فروق تكلفة الرموز وزمن الاستجابة في فئات مطالبات Opus 4.1 الأعلى استخدامًا.

## طرح آمن

1. أزل معلمات أخذ العينات وميزانيات التفكير القديمة قبل تحويل حركة المرور.
2. شغّل Opus 4.8 بالتوازي على مطالبات ومسارات أدوات تحاكي الإنتاج.
3. اختبر تدريجيًا مع إبقاء مسار بديل خلال فترة التداخل السابقة لـ 5 أغسطس 2026.
4. وسّع الطرح بعد وقوع فروق زمن الاستجابة والتكلفة وإكمال المهام ضمن الأهداف.
