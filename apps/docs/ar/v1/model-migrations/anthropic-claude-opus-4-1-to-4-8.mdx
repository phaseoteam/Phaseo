انقل حركة Claude Opus 4.1 إلى `anthropic/claude-opus-4.8`: غيّر معرّف النموذج، وأزل معاملات أخذ العينات، واستبدل ميزانيات التفكير بمستوى جهد.

أعلنت Anthropic إهمال Opus 4.1 في 5 يونيو 2026 وأوقفته في 5 أغسطس 2026. يواصل Phaseo تقديم `anthropic/claude-opus-4.1` ما دام أي مزوّد يقدّمه، وعندما لا يبقى أي مزوّد يوجّه هذه الطلبات إلى Opus 4.8 (راجع [إهمال النماذج وإيقافها](../guides/model-retirement)). رحّل قبل حدوث ذلك حتى يكون التغيير مختبرًا لا تلقائيًا.

إرشادات Anthropic تراكمية: طبّق تغييرات شكل الطلب الخاصة بـ Opus 4.7، ثم راجع تغييرات السلوك في Opus 4.8.

| | Claude Opus 4.1 | Claude Opus 4.8 |
| --- | --- | --- |
| معرّف النموذج في Phaseo | `anthropic/claude-opus-4.1` | `anthropic/claude-opus-4.8` |
| نافذة السياق | 200K رمز | 1M رمز |
| الحد الأقصى للمخرجات | 32K رمز | 128K رمز |
| `temperature` و`top_p` و`top_k` | تُرسل | يحذفها Phaseo |
| التفكير | `budget_tokens` | تكيفي، يُوجَّه بمستوى الجهد (الافتراضي `high`) |
| رسائل النظام في منتصف المحادثة | لا | نعم |

## تحديث الطلب

**1. غيّر معرّف النموذج** إلى `anthropic/claude-opus-4.8`.

**2. أزل معاملات أخذ العينات.** ترفض Anthropic القيم غير الافتراضية لـ `temperature` و`top_p` و`top_k` في Opus 4.7 وما بعده بالخطأ `400`. يحذفها Phaseo بدلًا من الفشل، لذا لم يعد لها أي تأثير؛ اضبط السلوك بالتعليمات بدلًا منها.

**3. استبدل ميزانيات التفكير بمستوى جهد.** لا يمرّر Phaseo `budget_tokens` إلى Opus 4.8. يُرسل أي إعداد استدلال بصيغة `thinking: {"type": "adaptive", "display": "summarized"}`، ويحدد `reasoning.effort` (أو `output_config.effort` على `/v1/messages`) العمق:

```json
{
  "model": "anthropic/claude-opus-4.8",
  "max_tokens": 4096,
  "thinking": { "type": "adaptive" },
  "output_config": { "effort": "high" },
  "messages": [{ "role": "user", "content": "Plan the schema migration." }]
}
```

دون أي إعداد استدلال، لا يفكر Opus 4.8. يرسل `reasoning.effort: "none"` القيمة `thinking: {"type": "disabled"}`.

**4. أعد ضبط خط الأساس للجهد والسياق الطويل.** يضبط Opus 4.8 الجهد افتراضيًا على `high`، ونافذة سياقه أكبر بكثير من Opus 4.1. أعد اختبار ميزانيات زمن الاستجابة واستخدام الرموز والتخزين المؤقت للمطالبات وتتبّعات المستندات الطويلة والوكلاء طويلي الأمد. على Microsoft Foundry، توثّق Anthropic نافذة سياق بحجم 200K لـ Opus 4.8 عند الإطلاق.

**5. بسّط تحديثات التعليمات في المحادثات الطويلة.** يقبل Opus 4.8 رسائل `role: "system"` في منتصف المحادثة. إذا كانت حلقة الوكيل لديك تعيد كتابة مطالبة النظام كاملة في كل دور، فأضف رسالة نظام بدلًا من ذلك واحتفظ بمزيد من إصابات ذاكرة التخزين المؤقت.

## ما الذي يجب اختباره

- الطلبات التي لا تزال ترسل `temperature` أو `top_p` أو `top_k`، لأن تأثيرها زال الآن؛
- مسارات التفكير التي اعتمدت على `budget_tokens`؛
- مسارات عمل الوكلاء والأدوات طويلة الأمد؛
- المخرجات الحساسة للمخطط عند كل مستوى من `effort`؛
- تكلفة الرموز وزمن الاستجابة لفئات مطالبات Opus 4.1 الأعلى حجمًا لديك.

## النشر

1. أزل معاملات أخذ العينات وميزانيات التفكير قبل تبديل الحركة.
2. شغّل Opus 4.8 في وضع الظل على مطالبات ومسارات أدوات شبيهة بالإنتاج.
3. انشر تجريبيًا (canary) مع Opus 4.1 كنموذج احتياطي في `models` ما دام المزوّدون يقدّمونه.
4. رقِّ النموذج بعد أن تصبح تغييرات زمن الاستجابة والتكلفة وإنجاز المهام ضمن الهدف.
