# ترحيل النماذج

استخدم هذه الأدلة لترقية النموذج مع الاستمرار على المنصة نفسها.

تركّز الصفحات على التغييرات التي غالبًا ما تؤثر أولًا في عمليات التكامل الحالية:

- تغييرات معلمات الطلب
- اختلافات سلوك المطالبات والاستدلال
- تراجعات المخرجات المنظّمة واستدعاء الأدوات
- استراتيجيات الطرح التدريجي والبدائل والتراجع

## كيفية استخدام هذا القسم

1. ابدأ بالدليل الخاص بعائلة النموذج المستهدف.
2. حدّث معلمات الطلب قبل اختبار جودة المخرجات.
3. أعد تشغيل تقييمات المطالبات والمخططات باستخدام أمثلة تحاكي الإنتاج.
4. حوّل حركة المرور تدريجيًا مع قواعد واضحة للبدائل والتراجع.

إذا كنت تغيّر المزوّد أو SDK أو البوابة، وليس النموذج فقط، فاستخدم قسم [أدلة الترحيل](../migration-guides/index.mdx).
