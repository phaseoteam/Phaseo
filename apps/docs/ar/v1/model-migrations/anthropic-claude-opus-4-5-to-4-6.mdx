غيّر النموذج إلى `anthropic/claude-opus-4.6`، وأزل التعبئة المسبقة لرسائل المساعد، وانقل المخرجات المنظّمة إلى `output_config.format`. هذه تغييرات في شكل الطلب: أنماط Opus 4.5 القديمة تفشل بالخطأ `400` إذا تُركت كما هي.

| | Claude Opus 4.5 | Claude Opus 4.6 |
| --- | --- | --- |
| معرّف النموذج في Phaseo | `anthropic/claude-opus-4.5` | `anthropic/claude-opus-4.6` |
| نافذة السياق | 200K رمز | 1M رمز |
| الحد الأقصى للمخرجات | 64K رمز | 128K رمز |
| التعبئة المسبقة لرسالة المساعد | مدعومة | تعيد `400` |
| المخرجات المنظّمة | `output_format` | `output_config.format` |
| التفكير | `budget_tokens` | تكيفي، يُوجَّه بـ `output_config.effort` |
| الميزة التجريبية `interleaved-thinking-2025-05-14` | مطلوبة | غير مطلوبة |

## تحديث الطلب

**1. أزل التعبئة المسبقة لرسائل المساعد.** إذا كنت تملأ دور المساعد مسبقًا لفرض JSON أو بادئة معينة، فسيعيد Opus 4.6 الخطأ `400`. استخدم تعليمات نظام أوضح، أو أمثلة في المطالبة، أو المخرجات المنظّمة بدلًا من ذلك.

**2. انقل المخرجات المنظّمة** من `output_format` إلى `output_config.format`، وأعد تشغيل اختبارات المخطط والمحلّل:

```json
{
  "model": "anthropic/claude-opus-4.6",
  "max_tokens": 1024,
  "messages": [{ "role": "user", "content": "Extract the invoice fields." }],
  "output_config": {
    "format": { "type": "json_schema", "schema": { "type": "object", "properties": { "total": { "type": "number" } } } }
  }
}
```

على `/v1/chat/completions` و`/v1/responses`، واصل استخدام `response_format`.

**3. حوّل التفكير إلى الوضع التكيفي.** لا يفكر Opus 4.6 ما لم يطلب الطلب ذلك. على Phaseo، يفعّل `reasoning.effort` أو `reasoning.enabled: true` دون ميزانية رموز التفكيرَ التكيفي، ويصبح مستوى الجهد `output_config.effort`. يقبل Opus 4.6 كل مستويات الجهد باستثناء `xhigh`، الذي يرسله Phaseo بوصفه `max`. أثناء تفعيل التفكير، يحذف Phaseo `temperature` و`top_k`، و`top_p` الأقل من 0.95.

**4. أزل ترويسات الميزات التجريبية القديمة** من مغلّفات SDK والبرمجيات الوسيطة والإعدادات المسبقة. لا يمرّر Phaseo ترويسات `anthropic-beta`، لذا لم يعد لها أي تأثير.

## ما الذي يجب اختباره

- **المطالبات:** مطالبات البرمجة وإعادة الهيكلة الطويلة، ومسارات البحث والمستندات متعددة الخطوات، والمطالبات التي اعتمدت على التعبئة المسبقة، ومهام السياق الطويل إذا كنت ستستخدم نافذة 1M.
- **العقود والأدوات:** معدل نجاح المخطط بعد الانتقال إلى `output_config.format`، ووسائط استدعاءات الأدوات في مهام الوكلاء متعددة الخطوات، وإعادات المحاولة عندما يرفض النموذج أو يعيد تنسيق المخرجات، ومسارات مراجعة الشيفرة وتصحيح الأخطاء.
- **العمليات:** الوسيط وp95 لزمن الاستجابة مع تفعيل التفكير، واستخدام الرموز في التشغيلات الأطول، ومعدل انتهاء المهلة في مهام السياق الكبير، ومعدل النجاح مقارنة بـ Opus 4.5 على مجموعة التقييم لديك.

## النشر

1. أزل التعبئة المسبقة ورحّل المخرجات المنظّمة قبل نقل أي حركة.
2. شغّل Opus 4.6 في وضع الظل على مطالبات الإنتاج المهمة لك.
3. انشر تجريبيًا (canary) مع Opus 4.5 كنموذج احتياطي في `models`.
4. رقِّ النموذج بعد ثبات معدل نجاح المخطط وزمن الاستجابة وإنجاز المهام.
