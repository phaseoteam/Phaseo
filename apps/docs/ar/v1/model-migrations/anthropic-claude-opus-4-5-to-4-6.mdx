# Anthropic Claude Opus 4.6

استخدم هذا الدليل لاعتماد `anthropic/claude-opus-4.6` بأمان في الإنتاج.

لا يقتصر الترحيل إلى Claude Opus 4.6 على تبديل معرّف النموذج. تشمل إرشادات Anthropic تغييرات في الطلبات وإزالة أعلام تجريبية وسلوكًا أكثر صرامة مع البادئات المسبقة.

## الجديد

- لم تعد نماذج Claude 4.6 تدعم البادئات المسبقة للمساعد، وتعيد الآن `400`.
- انتقلت المخرجات المنظّمة من `output_format` إلى `output_config.format`.
- يُضبط التفكير التكيفي الآن عبر `output_config.effort`.
- أزل عناوين beta القديمة.
- لم يعد Opus 4.6 يحتاج إلى عنوان beta `interleaved-thinking-2025-05-14`.
- يضيف Opus 4.6 نافذة سياق بمليون رمز في beta، ويحسّن مهام البرمجة والوكلاء طويلة الأمد.

## البدء السريع للترحيل

### 1. أزل البادئات المسبقة للمساعد

إذا كنت تفرض JSON أو بادئة استجابة عبر ملء جزء من دور المساعد مسبقًا، فسيفشل هذا النمط مع 4.6. انقل التحكم إلى:

- تعليمات نظام أوضح
- أمثلة ضمن مطالبة المستخدم أو النظام
- المخرجات المنظّمة عبر `output_config.format`

### 2. رحّل المخرجات المنظّمة

إذا كنت لا تزال ترسل `output_format`، فحدّث جسم الطلب لاستخدام `output_config.format`.

### 3. راجع إعداد التفكير

إذا كنت تعتمد على إصدارات thinking beta قديمة، فانتقل إلى إعداد `effort` الحالي داخل `output_config` وأعد اختبار المسارات الحساسة لزمن الاستجابة.

### 4. أزل أعلام beta القديمة

راجع عناوين beta الثابتة في أغلفة SDK والبرمجيات الوسيطة وإعدادات Gateway المسبقة. يؤدي إبقاء الأعلام القديمة إلى إخفاقات غير ضرورية أثناء الطرح.

## ما ينبغي اختباره

### سلوك المطالبات

- مطالبات البرمجة وإعادة الهيكلة الطويلة.
- سير عمل البحث أو المستندات متعدد الخطوات.
- المطالبات التي اعتمدت سابقًا على بادئات المساعد.
- المهام ذات السياق الطويل إذا كنت تنوي استخدام نافذة beta ذات المليون رمز.

### العقود والأدوات

- معدل اجتياز المخططات بعد الانتقال إلى `output_config.format`.
- جودة وسائط استدعاء الأدوات في مهام الوكلاء متعددة الخطوات.
- سلوك إعادة المحاولة عندما يرفض النموذج المخرجات أو يعيد تنسيقها.
- معالجة التراجعات في مراجعة الشفرة وتصحيح الأخطاء.

### التشغيل

- وسيط وp95 زمن الاستجابة مع إعدادات التفكير الجديدة.
- استهلاك الرموز في التشغيلات الطويلة.
- معدل انتهاء المهلة للمهام ذات السياق الكبير.
- معدل النجاح مقارنةً بـ Opus 4.5 في مجموعة تقييم الإنتاج.

## طرح آمن

1. أزل البادئات المسبقة ورحّل إعداد المخرجات المنظّمة قبل تحويل حركة المرور.
2. شغّل Opus 4.6 بالتوازي مع مطالبات الإنتاج المهمة.
3. اختبر حركة المرور تدريجيًا مع إبقاء Opus 4.5 بديلًا.
4. وسّع الطرح بعد استقرار معدل اجتياز المخططات وزمن الاستجابة وإكمال المهام.
