افتح أي معيار في [المعايير](https://phaseo.app/benchmarks) لترتيب النماذج حسب نتيجتها فيه، أو افتح صفحة نموذج لترى كل نتائجه. لا يشغّل Phaseo المعايير بنفسه؛ بل يجمع النتائج المنشورة ويربط كل نتيجة بمصدرها.

## ما تسجّله كل نتيجة

| الحقل | ما يخبرك به |
| --- | --- |
| النتيجة | القيمة كما نُشرت، على مقياس المعيار نفسه. |
| النسخة | الإعداد عندما يختلف عن الافتراضي، مثل عدد الأمثلة (few-shot) أو مستوى جهد الاستدلال. |
| المصدر | رابط إلى الورقة البحثية أو بطاقة النموذج أو صفحة النتائج التي جاءت منها النتيجة. |
| مُبلغ عنه ذاتيًا | يُضبط عندما ينشر مطوّر النموذج نفسه النتيجة. هو إفصاح، لا رفض. |

لكل معيار أيضًا فئة واتجاه ترتيب. يرتّب Phaseo المعايير التي تكون فيها القيمة الأقل أفضل، مثل معدلات الخطأ، بحيث تأتي أقل نتيجة أولًا.

## كيف تقارن النتائج

لا يحوّل Phaseo المعايير إلى نتيجة مشتركة واحدة، لذا قارن النماذج على المعيار والنسخة نفسيهما، لا عبر معايير مختلفة. تحقق من النسخة ومن علامة الإبلاغ الذاتي قبل أن تعامل رقمين على أنهما متساويان: قد تختلف النتيجة التي أبلغ عنها المزوّد عن نتيجة مقيسة بشكل مستقل للنموذج نفسه.

نتيجة المعيار مُدخل واحد فقط. التكلفة وزمن الاستجابة والموثوقية وطريقة تعامل النموذج مع موجّهاتك الخاصة مهمة بالقدر نفسه؛ ويغطي [الأسعار والأداء](./pricing-performance.mdx) هذه الجوانب.

## ما تعرضه صفحة المعيار

| القسم | ما يخبرك به |
| --- | --- |
| **ملخص** | ما يقيسه المعيار، مع رابط إليه. |
| **التقدم** | كيف تغيّرت النتائج على المعيار بمرور الوقت. |
| **نتائج النماذج** | نتيجة كل نموذج، مرتبة وفق اتجاه ترتيب المعيار. |

للمؤشرات المركّبة، مثل Artificial Analysis Intelligence Index وEpoch Capabilities Index، صفحات خاصة بها تتضمن ترتيبات الجهة الناشرة وإصداراتها.

## فئات المعايير

| الفئة | أمثلة |
| --- | --- |
| عام | Artificial Analysis Intelligence Index، Epoch Capabilities Index |
| الوكلاء | BrowseComp، BFCL-v3، Toolathlon |
| البرمجة | SWE-Bench، Aider-Polyglot |
| الرياضيات | AIME 2025، MathVision |
| الاستدلال | HellaSwag، Hallusion Bench |
| اللغة | BIG-Bench Hard، Winogrande |
| متعدد الوسائط | CharXiv-R، MMBench-V1.1 |
| السياق الطويل | AA-LCR، OpenAI-MRCR |

من الفئات الأخرى: الصوت والتضمينات والرعاية الصحية والتخطيط والإبداع.

## من أين تأتي النتائج

- بطاقات النماذج والتقارير التقنية والأوراق البحثية الصادرة عن مطوّر النموذج.
- صفحات النتائج الخاصة بالجهات المنظمة للمعايير.
- عمليات استيراد مجدولة من Artificial Analysis وEpoch AI.
- بلاغات المجتمع عبر مشكلات GitHub، وتُراجَع قبل النشر.
