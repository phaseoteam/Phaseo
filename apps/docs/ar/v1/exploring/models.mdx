تتتبّع Phaseo كتالوجًا مفتوحًا واسعًا لنماذج الذكاء الاصطناعي النصية والصورية والصوتية والمرئية ونماذج التضمين وغيرها.

تتضمن صفحة كل نموذج معلومات تقنية وتجارية مفصلة تساعدك على تقييم النموذج المناسب لاحتياجاتك ومقارنته واختياره.

<Info>
الكتالوج أوسع من Gateway. تعرض صفحة النماذج افتراضيًا النماذج ذات المسارات النشطة في Gateway. اختر حالة Gateway أخرى فقط إذا كنت تريد عمدًا الاطلاع على عناصر الكتالوج القادمة أو غير النشطة.
</Info>

---

## ما ستجده في صفحة النموذج

تحتوي كل صفحة نموذج في Phaseo على الأقسام الرئيسية التالية:

| القسم | الوصف |
| --- | --- |
| **نظرة عامة** | المزوّد وتاريخ الإصدار ونوع النموذج (دردشة أو شيفرة أو تضمين أو صورة وغيرها) ووصف موجز. |
| **العائلة** | النماذج المرتبطة والعلاقات بينها. |
| **الخط الزمني** | سجل الإصدارات والتحديثات الرئيسية بمرور الوقت. |
| **المعايير** | نتائج الأداء عبر معايير مختلفة لمقارنة النماذج الأقرب. |
| **التوافر** | يميّز مسارات Gateway النشطة عن المسارات القادمة وغير النشطة وعروض المزوّدين الخارجية. |
| **الأسعار** | أسعار مفصلة بالدولار الأمريكي، موحّدة لتسهيل المقارنة وتقدير تكلفة النموذج. |
| **Gateway** | روابط مباشرة وأدلة بدء سريع عند توفر مسار Gateway عام. |
| **الأداء** | زمن الاستجابة ومعدل النقل وبيانات النجاح المرصودة لطلبات Gateway الموجّهة عند توفر بيانات كافية. |

## نماذج الكتالوج والنماذج القابلة للتوجيه

استخدم هذه المصطلحات باستمرار:

| المصطلح | المعنى |
| --- | --- |
| نموذج في الكتالوج | تتتبّع Phaseo بيانات النموذج الوصفية، وقد لا يتوفر له مسار عام. |
| نموذج قابل للتوجيه | يوجد مسار مزوّد نشط واحد على الأقل في Phaseo Gateway حاليًا. |
| ربط خارجي | تتتبّع Phaseo عرضًا لدى مزوّد لا تنفّذه Gateway. |

للاستكشاف البرمجي، يعيد `GET /v1/models` النماذج القابلة للتوجيه فقط افتراضيًا. عيّن `availability=all` للاطلاع على المجموعة الأوسع.

## العثور على نماذج وفق معايير

استخدم المرشحات والوسوم في واجهة Phaseo للعثور على النماذج المناسبة لاحتياجاتك:

- **حسب المزوّد:** `اعرض جميع نماذج Anthropic`.
- **حسب القدرة:** `اعرض النماذج التي تدعم استجابات JSON المنظّمة`.
- **حسب المعيار:** `أفضل 10 نماذج في GPQA`.
- **حسب السعر:** `نماذج تكلف أقل من 0.01 دولار لكل 1,000 رمز`.
- **حسب تاريخ الإصدار:** `النماذج الصادرة حديثًا`.

اجمع المرشحات للعثور بدقة على ما تحتاج إليه.

## المساهمة في تحديث بيانات النماذج

يتطور الذكاء الاصطناعي بسرعة، لذلك تعتمد Phaseo على المساهمين للحفاظ على دقة بيانات النماذج.
افتح مشكلة على GitHub للإبلاغ عن تصحيح أو إرسال معايير مفقودة أو طلب بيانات وصفية جديدة. أرفق صفحة النموذج والمصادر الرسمية؛ يطبّق المسؤولون التحديثات المعتمدة عبر محرر قاعدة البيانات.
