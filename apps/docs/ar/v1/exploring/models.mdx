افتح قائمة [النماذج](https://phaseo.app/models) للعثور على نماذج النص والصور والصوت والفيديو والتضمين وغيرها، ثم افتح أي نموذج لترى مزوّديه وأسعاره وأداءه ونتائجه في المعايير.

![صفحة نموذج على Phaseo](/images/gemini-3-page.png)

## نماذج الكتالوج والنماذج القابلة للاستدعاء

الكتالوج أوسع من الـ Gateway. لا تعرض قائمة النماذج افتراضيًا إلا النماذج التي حالتها **نشط على Gateway**. غيّر عامل التصفية **حالة Gateway** إلى **قريبًا** أو **غير نشط** لترى البقية.

| المصطلح | المعنى |
| --- | --- |
| نموذج الكتالوج | يتتبع Phaseo البيانات الوصفية للنموذج. وقد لا يكون له مسار يمكنك استدعاؤه. |
| نموذج قابل للتوجيه | مسار مزوّد واحد على الأقل نشط الآن على Phaseo Gateway. |
| ربط خارجي | يدرج Phaseo عرضًا من مزوّد لا ينفّذه الـ Gateway. |

يعيد `GET /v1/models` النماذج القابلة للتوجيه فقط. أضف `availability=all` لتضمين البقية.

## صفِّ القائمة ورتّبها

| عنصر التحكم | الخيارات |
| --- | --- |
| حالة Gateway | نشط على Gateway (الافتراضي)، قريبًا، غير نشط |
| نقاط النهاية | نقاط نهاية الواجهة البرمجية التي يدعمها النموذج، مثل توليد النص أو التضمينات |
| وسائط الإدخال والإخراج | النص والصور والصوت والفيديو وغيرها |
| الميزات | قدرات مثل استدعاء الأدوات أو الاستدلال |
| السنة | سنة الإصدار |
| الترتيب | الأحدث، الأكثر شيوعًا (رموز 7 أيام)، السعر، طول السياق، الإنتاجية، زمن الاستجابة |

لترى كل نماذج مختبر واحد، افتح [صفحة المؤسسة](./organisations.mdx) الخاصة به.

## ما تعرضه صفحة النموذج

| القسم | ما يخبرك به |
| --- | --- |
| **المزوّدون** | كل مسار مزوّد مع حالته وطول السياق والسعر ووقت التشغيل وسياسة البيانات. تشرح [حالات المزوّد](../guides/provider-statuses) الأيقونات. |
| **الأداء** | زمن الاستجابة والإنتاجية المقيسان على حركة الـ Gateway، عند توفر بيانات كافية. |
| **الأسعار** | كل عدّاد بالدولار الأمريكي: الإدخال والإخراج والإدخال المخزّن مؤقتًا ووحدات الوسائط. |
| **المعايير** | النتائج على كل معيار، مع المصادر. |
| **النشاط** | استخدام الرموز عبر الـ Gateway بمرور الوقت. |
| **التطبيقات** | التطبيقات العامة التي تستخدم النموذج. |
| **مدة التشغيل** | توفر المسار خلال الأيام الأخيرة. |
| **التحقّق** | فحوصات مصدر المحتوى، لنماذج الصور والفيديو. |
| **حول النموذج** | تواريخ الإصدار والترخيص والروابط والعائلة. |
| **الاشتراكات** | خطط اشتراك المزوّدين التي تتضمن النموذج. |
| **أسئلة شائعة** | أسئلة متكررة حول النموذج. |

لا يظهر القسم إلا عند توفر بيانات له. وتعرض النماذج التي لها مسار نشط أيضًا دليل بدء سريع يتضمن معرّف النموذج الذي ترسله.

## قارن النماذج

تضع صفحة [المقارنة](https://phaseo.app/compare) النماذج جنبًا إلى جنب من حيث السعر ونتائج المعايير والسياق والميزات. ويشرح [الأسعار والأداء](./pricing-performance.mdx) كيفية قراءة أرقام التكلفة والسرعة.

## أبلغ عن تصحيح

افتح مشكلة على GitHub تتضمن صفحة النموذج ومصدرًا رسميًا. يطبّق المشرفون التحديثات المعتمدة في قاعدة البيانات. راجع [الإبلاغ عن تحديث نموذج](../contributing/editing-a-model.mdx).
