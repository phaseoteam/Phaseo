افتح أي مؤسسة في [المؤسسات](https://phaseo.app/organisations) لترى كل نموذج أصدرته وأداء تلك النماذج على الـ Gateway. ينتمي كل نموذج في Phaseo إلى مؤسسة واحدة: الشركة أو المختبر الذي يطوّره ويصونه.

## ما تعرضه صفحة المؤسسة

للصفحة تبويبان.

| التبويب | القسم | ما يخبرك به |
| --- | --- | --- |
| **نظرة عامة** | حول | الاسم والوصف والبلد. |
| | الأداء | زمن الاستجابة والإنتاجية الأخيران على الـ Gateway عبر نماذج المؤسسة. |
| | أحدث النماذج | الإصدارات الأخيرة مع التوفر والسياق والأسعار والاستخدام. |
| | على الويب | روابط إلى موقع المؤسسة وحساباتها على GitHub وHugging Face ووسائل التواصل الاجتماعي. |
| **النماذج** | | كل نموذج أصدرته المؤسسة، بما في ذلك النماذج المؤرشفة والمتقادمة. |

## المؤسسات ومزوّدو API

تبني المؤسسة النموذج؛ ويقدّمه [مزوّد API](./api-providers.mdx). وغالبًا ما يكون للنموذج الواحد عدة مزوّدين.

| | المؤسسة | مزوّد API |
| --- | --- | --- |
| **ماذا تفعل** | تدرّب النموذج وتصونه. | تستضيف النموذج خلف واجهة برمجية. |
| **مثال** | بنت Anthropic نماذج Claude. | تقدّم Anthropic وAmazon Bedrock وGoogle Vertex جميعها نماذج Claude. |

بعض المؤسسات، مثل OpenAI وGoogle، هي أيضًا مزوّدات لنماذجها الخاصة.

## أبلغ عن تصحيح

افتح مشكلة على GitHub تتضمن صفحة المؤسسة ومصدرًا رسميًا. يطبّق المشرفون التغييرات المعتمدة في قاعدة البيانات. راجع [الإبلاغ عن تحديث مؤسسة](../contributing/editing-an-organisation.mdx).
