افتح صفحة أي مزوّد في [مزوّدو API](https://phaseo.app/api-providers) لترى النماذج التي يقدّمها عبر Phaseo ومدى سرعته، أو [قارن المزوّدين](https://phaseo.app/api-providers/compare) جنبًا إلى جنب. يستضيف مزوّد API النماذج خلف واجهة برمجية؛ أما [المؤسسة](./organisations.mdx) التي بنت النموذج فهي غالبًا شركة مختلفة.

| | المؤسسة | مزوّد API |
| --- | --- | --- |
| **ماذا تفعل** | تبني النماذج وتدرّبها | تستضيف واجهات النماذج البرمجية وتقدّمها |
| **التركيز** | البحث وجودة النماذج | الموثوقية والوصول والمناطق والأسعار |
| **النماذج** | عادةً عائلاتها الخاصة | غالبًا نماذج من مؤسسات كثيرة |

كثير من الشركات تؤدي الدورين معًا.

## ما تعرضه صفحة المزوّد

| القسم | ما يخبرك به |
| --- | --- |
| **الأداء** | زمن الاستجابة والإنتاجية كل ساعة على حركة الـ Gateway خلال الأيام السبعة الماضية. |
| **استخدام الرموز** | الرموز التي أرسلها Phaseo إلى المزوّد بمرور الوقت. |
| **أفضل النماذج** و**أفضل التطبيقات** | النماذج والتطبيقات العامة الأكثر حركة على هذا المزوّد. |
| **النماذج** | كل نموذج يقدّمه المزوّد، مع تبويبات لنماذج النص والصور والصوت والفيديو والتضمين والإشراف. |

ثم تعرض صفحة كل نموذج سعر المزوّد وطول السياق والحالة وسياسة البيانات لذلك النموذج؛ وتشرح [حالات المزوّد](../guides/provider-statuses) أيقونات الحالة.

## كيف يستخدم الـ Gateway المزوّدين

عندما يكون للنموذج عدة مزوّدين، يختار الـ Gateway واحدًا لكل طلب وينتقل إلى آخر إذا فشل. ترسل صيغة طلب واحدة وتحصل على فاتورة واحدة وسجل استخدام واحد، أيًّا كان المزوّد الذي يخدم الطلب. ولتُحمَّل التكلفة على حسابك لدى المزوّد بدلًا من ذلك، أضف مفتاح مزوّد ([BYOK](../guides/routing-and-fallbacks#byok-considerations)).

يوضح [التوجيه والبدائل](../guides/routing-and-fallbacks) كيفية ترتيب المزوّدين أو تثبيتهم أو استبعادهم.

## اختر مزوّدًا

| إذا كان يهمك | راجع |
| --- | --- |
| نموذج محدد | قسم **المزوّدون** في صفحة النموذج، أو `GET /v1/models/{author}/{slug}/endpoints` |
| زمن الاستجابة في منطقتك | قسم **الأداء** للمزوّد ومناطقه في صفحة النموذج |
| التكلفة عند حجم استخدامك | قسم **الأسعار** للنموذج و[حاسبة الأسعار](https://phaseo.app/tools/pricing-calculator) |
| الأدوات أو التدفق أو المخرجات المنظَّمة | المعاملات المدعومة للمسار في صفحة النموذج أو في واجهة نقاط النهاية البرمجية |
| معالجة البيانات والامتثال | سياسة البيانات للمسار ومواقع المعالجة في صفحة النموذج |

يشرح [الأسعار والأداء](./pricing-performance.mdx) كيفية قراءة أرقام التكلفة والسرعة.
