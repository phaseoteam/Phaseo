موفّرو API هم المنصات التي تستضيف واجهات النماذج وتقدّمها.

تدرّب مؤسسات النماذج النماذج، بينما تتيحها المزوّدات عبر نقاط نهاية الإنتاج والمصادقة وضوابط الاستخدام وأدوات التشغيل.

## ما الذي يتولاه موفّر API عادةً

- المصادقة وإدارة المفاتيح
- توجيه الطلبات وإدارة التوافر
- قياس الاستخدام والفوترة
- سهولة استخدام API وSDK
- الاستضافة الإقليمية وضوابط الامتثال

## المزوّد مقابل المؤسسة

| الجانب | المؤسسة | موفّر API |
| --- | --- | --- |
| الدور الأساسي | إنشاء النماذج وتدريبها | استضافة واجهات النماذج وتقديمها |
| التركيز | البحث وجودة النماذج | الموثوقية والوصول والتشغيل |
| التوزيع | عادةً عائلة النماذج الخاصة بها | قد يقدّم نماذج من مؤسسات متعددة |

تؤدي شركات كثيرة الدورين معًا بحسب المنتج.

## ما يمكنك الاطلاع عليه في صفحات موفّري Phaseo

| القسم | ما يوضحه |
| --- | --- |
| نظرة عامة | هوية المزوّد وروابط الوثائق والقدرات المدعومة |
| النماذج | النماذج والمتغيرات المتاحة |
| الأسعار | توحيد أسعار المزوّد ووحدات القياس |
| الحدود | حدود الطلبات ومعدل النقل عند توفرها |
| الميزات | البث والأدوات والمخرجات المنظّمة ودعم الوسائط |

## Phaseo Gateway كطبقة للمزوّدين

توحّد Phaseo Gateway الوصول إلى العديد من الأنظمة الخلفية.

المزايا:

- شكل موحّد للطلبات والاستجابات عبر المزوّدين
- توجيه وبدائل تراعي المزوّد
- استخدام SDK موحّد للتكاملات متعددة المزوّدين
- مراقبة مركزية للاستخدام والتكلفة
- دعم اختياري لـ BYOK لاستخدام مفاتيح المزوّد الأصلية

## اختيار مزوّد

عند تقييم المزوّدين، ركّز على:

- توافر النماذج لحالة الاستخدام لديك
- الموثوقية وزمن الاستجابة في المنطقة المستهدفة
- التكلفة المتوقعة عند حجم حركة المرور لديك
- دعم الأدوات والبث والمخرجات المنظّمة
- متطلبات الامتثال ومعالجة البيانات

## أسئلة للتقييم

- ما المزوّدون الذين يقدّمون عائلة النماذج التي أحتاج إليها؟
- أي مزوّد يوفّر زمن استجابة أفضل في منطقتي؟
- ما الخيار الأقل تكلفة عند حجم الرموز المتوقع؟
- أي مزوّد يدعم ميزات نقطة النهاية المطلوبة؟
