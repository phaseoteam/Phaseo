ابحث عن كلمة صادفتها في لوحة التحكم أو في API أو في هذا التوثيق. يقدّم كل صف معنى المصطلح في جملة واحدة، ويربط بالصفحة التي تشرحه بالكامل، ويسرد المواضع التي ينطبق فيها: API أو لوحة التحكم أو CLI أو SDK أو MCP أو الدردشة أو Slack.

## الحسابات والوصول

| المصطلح | المعنى | ينطبق على |
| --- | --- | --- |
| [المسؤول](./developers/management-api-keys.mdx) | دور في مساحة العمل يدير الإعدادات المخصصة للمسؤولين، مثل الميزانيات وقواعد الإنفاق وضوابط الحماية وسياسات الثقة، ويقرأ سجل التدقيق. | API، لوحة التحكم، CLI، MCP |
| [العضو](./developers/management-api-keys.mdx) | دور في مساحة العمل يستخدم مساحة العمل ويمكنه رؤية قواعد الإنفاق فيها، لكنه لا يستطيع تغيير الإعدادات المخصصة للمالكين والمسؤولين. | API، لوحة التحكم، CLI، MCP |
| [المالك](./developers/management-api-keys.mdx) | دور في مساحة العمل يدير الإعدادات نفسها المخصصة للمسؤولين ويتلقى رسائل البريد الموجّهة إلى المالكين، مثل تنبيهات إهمال النماذج. | API، لوحة التحكم، CLI، MCP |
| [مساحة العمل](./guides/workspaces.mdx) | حاوية تفصل مفاتيح API وإعدادات التوجيه والإعدادات المسبقة وضوابط الحماية ووصول المسؤولين الخاصة بها عن مساحات العمل الأخرى. | API، لوحة التحكم، CLI |

| [حمل عمل موثوق](./developers/trusted-workloads.mdx) | عملية نشر أو مهمة CI ترسل رمز OIDC قصير العمر من منصتها بدلًا من مفتاح API، وتطابقه سياسة ثقة. | API، لوحة التحكم |
