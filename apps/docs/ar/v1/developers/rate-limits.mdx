انتقل هذا الدليل إلى مرجع [حدود المعدل](../api-reference/limits.mdx). يشرح المرجع حصص Gateway الحالية وحدود المزوّد و`Retry-After` وإعادة المحاولة ضمن حدود محددة.

قد يعيد الطلب `429` بسبب حصة Gateway أو المزوّد. يخضع BYOK أيضًا لحصص حسابك لدى المزوّد. يمكن للتوجيه والمسارات البديلة تقليل الإخفاقات، لكنها لا تضمن نجاح كل طلب.

## مراقبة الاستخدام

راجع أخطاء `429` وإعادة المحاولة في سجلات الطلبات. تتيح API بالفعل [جلب تحليلات مساحة العمل](../api-reference/endpoint/analytics-get.mdx) و[تصديرها بصيغة CSV](../api-reference/endpoint/analytics-export.mdx). تتطلب العمليتان مفتاح API للإدارة بصلاحية `analytics:read`.
