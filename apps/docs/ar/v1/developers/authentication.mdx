راجع هذا المرجع لإرسال الطلبات المصادق عليها أو لتحديد طريقة تخزين المفاتيح وتدويرها.

تستخدم Phaseo Gateway رموز Bearer. يجب أن يتضمن كل طلب API مفتاحاً صالحاً من مساحة العمل.

---

## أنواع المفاتيح

- **مفاتيح API الخاصة بـ Gateway** تستدعي نقاط نهاية النماذج والمزوّدين والتوليد المتاحة لمساحة العمل.
- **مفاتيح API للإدارة** تستدعي واجهات الإدارة. راجع [مفاتيح API للإدارة](./management-api-keys.mdx).
- **المفاتيح التي تم تدويرها** يمكن إنشاؤها في أي وقت، ثم استبدالها في التطبيق قبل حذف المفتاح القديم.

تتبع المفاتيح التنسيق `phaseo_v1_sk_<kid>_<secret>`. تعامل معها ككلمات مرور، وتجنب حفظها في شيفرة جهة العميل أو المستودعات العامة.

<Note>
يمكنك استدعاء نماذج `:free` دون إيداع رصيد. تتطلب النماذج المدفوعة رصيداً متاحاً في المحفظة.
</Note>

---

## تنسيق الترويسة

أدرج المفتاح في ترويسة `Authorization` مع كل طلب:

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

تتيح معظم برامج HTTP ضبط ذلك مرة واحدة. إليك مثالاً باستخدام `fetch`:

```ts
const response = await fetch("https://api.phaseo.app/v1/chat/completions", {
	method: "POST",
	headers: {
		Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
		"Content-Type": "application/json",
	},
	body: JSON.stringify({
		model: "gpt-5-nano-2025-08-07",
		messages: [
			{ role: "system", content: "You are a helpful assistant." },
			{
				role: "user",
				content: "Summarize the drawbacks to AI.",
			},
		],
	}),
});
```

## قائمة التحقق لإدارة المفاتيح

| الممارسة            | سبب أهميتها                                                           |
| ------------------- | ------------------------------------------------------------------------ |
| استخدم مفتاحاً مستقلاً لكل تطبيق | يسهّل ذلك تدوير المفتاح دون التأثير في الخدمات الأخرى.                |
| خزّن المفاتيح بأمان | تمنع برامج إدارة الأسرار ظهور المفاتيح دون قصد في السجلات أو أدوات تتبع الأخطاء.  |
| راقب الاستخدام       | تعرض لوحة التحكم مقاييس لكل مفتاح، ما يساعدك على اكتشاف الأنشطة غير المعتادة بسرعة. |
| احذف المفاتيح غير المستخدمة  | يقلل حذف المفاتيح القديمة مساحة التعرّض لإساءة الاستخدام المحتملة.        |

## أخطاء المصادقة الشائعة

- **401 غير مصرح به**: المفتاح مفقود أو غير صالح أو مرتبط بمساحة عمل معطّلة.
- **403 محظور**: المفتاح موجود، لكنه لا يتيح الوصول إلى المزوّد أو النموذج المطلوب.
- **429 طلبات كثيرة جداً**: تجاوز المفتاح أو مساحة العمل أحد الحدود. راجع [حدود الطلبات](./rate-limits.mdx).
- **أخطاء 5xx**: أعد المحاولة مع تأخير أُسّي، وتواصل مع [الدعم](https://phaseo.app/help) إذا استمرت المشكلة.
