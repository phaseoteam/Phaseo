أنشئ مفتاحًا من [لوحة التحكم](https://phaseo.app/settings/keys)، أو باستخدام `POST /v1/keys` ومفتاح إدارة، واحفظه على خادمك، وأرسله كرمز bearer مع كل طلب إلى الـ Gateway. ينبغي أن يستخدم الوكلاء CLI؛ راجع [أدِر Phaseo من وكيل](./manage-from-an-agent).

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

عيّن الترويسة مرة واحدة في عميلك. على سبيل المثال، مع `fetch`:

```ts
const response = await fetch("https://api.phaseo.app/v1/chat/completions", {
	method: "POST",
	headers: {
		Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
		"Content-Type": "application/json",
	},
	body: JSON.stringify({
		model: "openai/gpt-6-astra",
		messages: [
			{ role: "system", content: "You are a helpful assistant." },
			{ role: "user", content: "Summarize the drawbacks to AI." },
		],
	}),
});
```

<Note>
يمكنك استدعاء نماذج `:free` دون إيداع أرصدة. أما النماذج المدفوعة فتحتاج إلى رصيد متاح في المحفظة.
</Note>

## اختر بيانات الاعتماد

| بيانات الاعتماد | التنسيق | استخدمها من أجل |
| --- | --- | --- |
| مفتاح Gateway API | `phaseo_v1_sk_<kid>_<secret>` | نقاط نهاية النماذج والمزوّدين والإنشاء المتاحة لمساحة عملك. |
| [مفتاح Management API](./management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | واجهات API الإدارية. |
| [حمل عمل موثوق](./trusted-workloads.mdx) (تجريبي) | رمز OIDC قصير الأجل من المنصة | عمليات النشر ومهام CI على Vercel أو GitHub Actions أو GitLab أو Google Cloud أو Buildkite أو CircleCI أو AWS أو مُصدِر OIDC الخاص بك، دون مفتاح مخزّن. |

تعامل مع المفاتيح ككلمات المرور: أبقِها خارج الشيفرة على جهة العميل وخارج المستودعات العامة.

## تعامل مع المفاتيح بأمان

- **مفتاح واحد لكل تطبيق وبيئة**، لكي تتمكن من تدوير أحدها دون التأثير على الخدمات الأخرى.
- **احفظ المفاتيح في مدير أسرار**، فهو يُبقيها خارج السجلات وأدوات تتبع الأخطاء.
- **راقب الاستخدام لكل مفتاح** في لوحة التحكم لاكتشاف الحالات الشاذة.
- **احذف المفاتيح التي لم تعد تستخدمها.**

لتدوير مفتاح، انقل تطبيقك إلى المفتاح البديل قبل أن تُبطل القديم. راجع [نقطة نهاية تدوير المفاتيح](../api-reference/endpoint/keys-rotate.mdx).

## أصلح أخطاء المصادقة

| الحالة | السبب | ما الذي تفعله |
| --- | --- | --- |
| `401` | المفتاح مفقود أو غير صالح أو ينتمي إلى مساحة عمل معطّلة. يذكر الحقل `reason` في المحتوى أيها. | تحقّق من الترويسة والمفتاح. |
| `403` | المفتاح صالح لكنه لا يستطيع استخدام المزوّد أو النموذج المطلوب. | تحقّق من ضوابط الحماية للمفتاح ومن إعدادات المزوّدين في مساحة العمل. |
| `429` | بلغ المفتاح أو مساحة العمل حدًا ما. | راجع [حدود المعدل](../api-reference/limits.mdx). |
| `5xx` | فشل Phaseo أو المزوّد. | أعِد المحاولة مع تراجع أسّي، وتواصل مع [الدعم](https://phaseo.app/help) إذا استمرت المشكلة. |

راجع [الأخطاء وتصحيحها](../api-reference/errors.mdx) لكل رموز الأخطاء.
