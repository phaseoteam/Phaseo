# CLI وMCP

استخدم Phaseo من الطرفية عبر CLI، أو اربط عميلاً للذكاء الاصطناعي عبر MCP. يستخدم كلاهما Phaseo OAuth، لكن لكل منهما غرض مختلف.

| الواجهة | مناسبة لـ | الصلاحيات |
| --- | --- | --- |
| Phaseo CLI | سير العمل عبر الطرفية وCI والإدارة والأتمتة | قراءة وكتابة وفق النطاقات ودورك في مساحة العمل |
| Phaseo MCP | بيانات Phaseo المباشرة داخل Codex وClaude وChatGPT وعملاء MCP الآخرين، مع إدارة اختيارية للحساب | مصادق عليه؛ للقراءة فقط ما لم تتصل مع إدارة الحساب |
| Docs MCP | البحث في وثائق Phaseo الحالية أثناء البرمجة | الوثائق فقط وللقراءة فقط |
| إضافة Phaseo | تثبيت Phaseo MCP وDocs MCP ومهارات Phaseo في Claude Code أو Codex دفعة واحدة | مثل كل خادم MCP |

## Phaseo CLI

استخدم CLI لإنشاء موارد Phaseo أو تغييرها، أو لكتابة البرامج النصية لسير العمل، أو لفحص بيانات الحساب من shell.

### التثبيت وتسجيل الدخول

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

تستخدم الطرفيات التفاعلية OAuth عبر المتصفح افتراضياً. استخدم تفويض الجهاز مع SSH وCI والبيئات بلا واجهة:

```bash
phaseo login --device-code
```

### سير العمل الشائع

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys create --name "Local development"
phaseo logs list --since 1h --status error --json
```

استخدم `--json` عندما تحتاج أداة أو برنامج نصي آخر إلى مخرجات منظّمة. لا تُعرض القيم السرية إلا عبر أوامر تنشئها أو تكشفها صراحةً.

## Phaseo MCP

اربط خادم Phaseo MCP عندما تريد من عميل ذكاء اصطناعي الإجابة استناداً إلى بيانات حية عن النماذج والأسعار والمزوّدين والاستخدام ومساحات العمل.

### عنوان الخادم

`https://mcp.phaseo.app/mcp`

### الاتصال من Codex

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

يفتح أمر تسجيل الدخول Phaseo OAuth. اختر مساحة عمل ووافق على نطاقات القراءة المطلوبة، ثم أكّد الاتصال:

```bash
codex mcp list
```

لعميل MCP آخر، أضف عنوان URL نفسه كخادم HTTP متدفق عن بُعد. يجب أن يدعم العميل اكتشاف OAuth ورمز التفويض مع S256 PKCE ومعامل MCP `resource`.

### البيانات التي يمكن لـ MCP قراءتها

- النماذج ومزوّدو الخدمة وتصنيفات المقاييس المعيارية والأسعار وتقديرات التكلفة
- الأرصدة والنشاط والتحليلات وسجلات الطلبات وبيانات التوليد الوصفية

هذه الأدوات للقراءة فقط، ولا تُرجع أبدًا المطالبات أو الردود أو القيم السرية.

### إدارة حسابك (اختياري)

للسماح لوكيل بتغيير مساحة عمل Phaseo الخاصة بك، اتصل باستخدام عنوان الإدارة بدلًا من ذلك:

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

عند تسجيل الدخول، تعرض شاشة الموافقة كل صلاحية يطلبها الاتصال على حدة، مثل إدارة مفاتيح API أو حذف الميزانيات، وتضع عليها علامة **قراءة** أو **كتابة** أو **حذف**. ألغِ تحديد أي صلاحية لا تريد منحها. لا يحصل الوكيل إلا على أدوات الصلاحيات التي تسمح بها، وتواصل Phaseo التحقق من دورك في مساحة العمل عند كل تغيير، لذا لا يستطيع العضو الذي ليس مالكًا أو مشرفًا تغيير الإعدادات المقصورة على المشرفين بهذه الطريقة.

إذا كنت متصلًا بالفعل عبر عنوان القراءة فقط، فبدّل العميل إلى عنوان الإدارة وسجّل الدخول مرة أخرى. وللعودة إلى الوصول للقراءة فقط، أعد الاتصال بالعنوان العادي أو ألغِ وصول التطبيق من **الإعدادات ← التطبيقات المتصلة**.

| المجال | الأدوات | الصلاحيات |
| --- | --- | --- |
| مفاتيح API | `api_keys_list`, `api_key_get`, `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete` | `keys:read`, `keys:write`, `keys:delete` |
| الميزانيات | `budgets_list`, `budget_create`, `budget_update`, `budget_delete` | `budgets:read`, `budgets:write`, `budgets:delete` |
| قواعد الإنفاق | `spend_rules_list`, `spend_rule_create`, `spend_rule_update`, `spend_rule_delete` | `spend_rules:read`, `spend_rules:write`, `spend_rules:delete` |
| مفاتيح المزوّد (BYOK) | `provider_keys_list`, `provider_key_create`, `provider_key_update`, `provider_key_delete` | `provider_credentials:read`, `provider_credentials:write`, `provider_credentials:delete` |
| الضوابط | `guardrails_list`, `guardrail_get`, `guardrail_create`, `guardrail_update`, `guardrail_delete`, `guardrail_keys_set` | `guardrails:read`, `guardrails:write`, `guardrails:delete` |
| الإعدادات المسبقة | `presets_list`, `preset_get`, `preset_create`, `preset_update`, `preset_version_publish` | `presets:read`, `presets:write` |
| الإعدادات | `settings_get`, `settings_update` (وضع التوجيه، والخصوصية وZDR، والتسجيل، وقيود المزوّدين) | `settings:read`, `settings:write` |
| خطافات الويب | `webhooks_list`, `webhook_create`, `webhook_delete` | `settings:read`, `settings:write` |
| وجهات قابلية الرصد | `observability_destinations_list`, `observability_destination_create`, `observability_destination_delete` | `settings:read`, `settings:write` |

تحمل الأدوات التي تغيّر شيئًا أو تحذفه علامة تدل على ذلك، حتى تطلب منك عملاء MCP الداعمة لهذه الميزة التأكيد قبل كل استدعاء. يظهر مفتاح API الجديد أو سر توقيع خطاف الويب الجديد مرة واحدة فقط في نتيجة الأداة، ولا يمكن عرضه مرة أخرى. ولا تُرجع أبدًا مفاتيح المزوّد المحفوظة أو بيانات اعتماد الوجهات.

لا يتضمن MCP أدوات للفوترة أو المدفوعات أو مساحات العمل أو الأعضاء أو مفاتيح الإدارة أو تطبيقات OAuth. استخدم لوحة التحكم أو CLI أو واجهة Management API لهذه العمليات.

## Docs MCP

Docs MCP نقطة نهاية منفصلة للبحث في وثائق Phaseo وقراءتها، ولا تصل إلى حسابك أو مساحة عملك.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

استخدمها عندما يحتاج مساعد البرمجة إلى أمثلة API حديثة أو إرشادات تكامل أو وثائق الميزات.

## إضافة Phaseo

تجمع إضافة Phaseo بين Phaseo MCP وDocs MCP ومهارات Phaseo للوكلاء الخاصة بالتكامل والترحيل واختيار النماذج ومراقبة الاستخدام وحزم SDK وCLI. ثبّتها مرة واحدة بدلًا من توصيل كل جزء بنفسك.

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

شغّل `/mcp` وسجّل الدخول إلى `plugin:phaseo:phaseo` لربط حسابك في Phaseo. تُحمَّل المهارات عندما يطابقها الطلب، أو يمكنك تشغيل إحداها مباشرة، مثل `/phaseo:phaseo-gateway`.

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

يفتح الأمر الأخير مصادقة Phaseo OAuth لخادم Phaseo MCP. تُحمَّل المهارات عندما يطابقها الطلب.

## اختيار الواجهة المناسبة

- استخدم **CLI** لإنشاء المفاتيح أو تغيير الإعدادات أو إدارة مساحات العمل أو أتمتة المهام الإدارية.
- استخدم **Phaseo MCP** لمنح عميل الذكاء الاصطناعي وصولاً آمناً إلى بيانات Phaseo الحية.
- استخدم **Docs MCP** لإتاحة وثائق Phaseo الحالية لمساعد برمجي دون الوصول إلى الحساب.
- استخدم **إضافة Phaseo** لإعداد خادمَي MCP ومهارات Phaseo في Claude Code أو Codex دفعة واحدة.
