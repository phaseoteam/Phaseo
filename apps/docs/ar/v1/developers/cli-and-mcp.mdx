استخدم CLI لتغيير Phaseo من الطرفية أو من سكربت، أو اربط عميل ذكاء اصطناعي بخادم Phaseo MCP لتمنحه بيانات Phaseo الحية. يسجّل كلاهما الدخول باستخدام Phaseo OAuth.

| الواجهة | استخدمها من أجل | الوصول |
| --- | --- | --- |
| [Phaseo CLI](#phaseo-cli) | إنشاء المفاتيح، وتغيير الإعدادات، وإدارة مساحات العمل، وأتمتة العمل الإداري من الطرفية أو CI | قراءة وكتابة، في حدود نطاقاتك ودورك في مساحة العمل |
| [Phaseo MCP](#phaseo-mcp) | منح Codex وClaude وChatGPT وعملاء MCP الآخرين بيانات Phaseo الحية، والسماح لهم اختياريًا بإدارة حسابك | قراءة فقط ما لم تتصل مع إدارة الحساب |
| [Docs MCP](#docs-mcp) | منح مساعد البرمجة توثيق Phaseo الحالي | التوثيق فقط، دون وصول إلى الحساب |
| [إضافة Phaseo](#phaseo-plugin) | تثبيت خادمَي MCP ومهارات Phaseo في Claude Code أو Codex دفعة واحدة | مثل كل خادم MCP |

## Phaseo CLI

### ثبّته وسجّل الدخول

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

تستخدم الطرفيات التفاعلية OAuth عبر المتصفح افتراضيًا. أما في SSH وCI والبيئات بلا واجهة، فاستخدم تفويض الجهاز:

```bash
phaseo login --device-code
```

### سير العمل الشائع

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys list
phaseo logs list --since 1h --status error --json
```

استخدم `--json` عندما تحتاج أداة أخرى أو سكربت إلى مخرجات منظَّمة. لا تُعرض القيم السرية إلا في الأوامر التي تنشئها أو تكشفها صراحةً.

## Phaseo MCP

عنوان الخادم هو `https://mcp.phaseo.app/mcp`. يستطيع عميل الذكاء الاصطناعي المتصل به الإجابة عن الأسئلة باستخدام بيانات حية عن النماذج والأسعار والمزوّدين والاستخدام ومساحة العمل.

### اربط عميلك

ثبّته بنقرة واحدة: [إضافة إلى Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=phaseo&config=eyJ1cmwiOiJodHRwczovL21jcC5waGFzZW8uYXBwL21jcCJ9) · [إضافة إلى VS Code](vscode:mcp/install?%7B%22name%22%3A%22phaseo%22%2C%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fmcp.phaseo.app%2Fmcp%22%7D). عندما يطلب منك العميل تسجيل الدخول، يُفتح Phaseo OAuth في متصفحك. اختر مساحة عمل ووافق على نطاقات القراءة المطلوبة.

<Tabs>
<Tab title="Claude Code">
```bash
claude mcp add --transport http phaseo https://mcp.phaseo.app/mcp
```

ثم شغّل `/mcp`، واختر `phaseo`، ثم اختر **Authenticate**. أضف `--scope user` لإتاحته في كل المشاريع.
</Tab>
<Tab title="Codex">
```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
codex mcp list
```

يفتح أمر تسجيل الدخول Phaseo OAuth، ويؤكد `codex mcp list` الاتصال.
</Tab>
<Tab title="Cursor">

```json ~/.cursor/mcp.json
      "url": "https://mcp.phaseo.app/mcp"
    }
  }
}
```

استخدم **إضافة إلى Cursor** أعلاه، أو أضف الخادم إلى `~/.cursor/mcp.json`، ثم سجّل الدخول من إعدادات MCP في Cursor.
</Tab>
<Tab title="VS Code">
```json .vscode/mcp.json
{

    "phaseo": {
      "type": "http",

```

استخدم **إضافة إلى VS Code** أعلاه، أو أضف الخادم إلى `.vscode/mcp.json`. شغّله من عرض MCP وسجّل الدخول عندما يطلب VS Code ذلك.
</Tab>
<Tab title="Claude">
في Claude، افتح **Settings → Connectors**، واختر **Add custom connector**، وأدخل `Phaseo` وعنوان URL للخادم، ثم اختر **Connect**. إذا لم يظهر هذا الخيار، فيجب أن يسمح مالك مؤسستك في Claude بالموصلات المخصصة.
</Tab>
<Tab title="OpenCode">

أضف الخادم إلى `opencode.json`، ثم شغّل `opencode mcp auth phaseo` لتسجيل الدخول.

لعميل MCP آخر، أضف العنوان نفسه كخادم Streamable HTTP بعيد. يجب أن يدعم العميل اكتشاف OAuth، ورمز التفويض مع S256 PKCE، ومعامل MCP `resource`.

### استخدم تسجيل الدخول إلى Phaseo CLI

إذا كنت تستخدم Phaseo CLI بالفعل، فيمكن لوكيل محلي الوصول إلى MCP من خلالها دون تسجيل دخول ثانٍ:

```bash
phaseo login
claude mcp add --scope user phaseo -- phaseo mcp
# or, for Codex
codex mcp add phaseo -- phaseo mcp
```

يشغّل `phaseo mcp` خادم MCP عبر stdio باستخدام تسجيل دخولك إلى CLI. ويستبدل تسجيل الدخول هذا برمز صالح لمدة 15 دقيقة يعمل على MCP فقط، ولا يملك أبدًا صلاحيات أكثر من تسجيل دخولك، ولا يسمح أبدًا باستدعاءات مدفوعة للنماذج. وهو للقراءة فقط ما لم تضف `--manage`. ويضيفه `phaseo setup codex` إلى ملف Phaseo الشخصي في Codex نيابةً عنك. وعندما يقرأ وكيل متصل بهذه الطريقة السجلات أو النشاط أو التحليلات، تقترح النتيجة أيضًا أمر CLI المطابق للحصول على البيانات كاملة.

### ما الذي يستطيع MCP قراءته

تغطي أدوات القراءة فقط النماذج، والمزوّدين، وتصنيفات المقاييس المرجعية، والأسعار وتقديرات التكلفة، إضافةً إلى الأرصدة والنشاط والتحليلات وسجلات الطلبات والبيانات الوصفية للإنشاء. ولا تعيد أبدًا المطالبات أو الردود أو القيم السرية.

### إدارة حسابك (اختياري)

لتسمح لوكيل بتغيير مساحة عمل Phaseo الخاصة بك، اتصل باستخدام عنوان الإدارة بدلًا من ذلك:

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

عند تسجيل الدخول، تسرد شاشة الموافقة كل إذن يطلبه الاتصال، مثل إدارة مفاتيح API أو حذف الميزانيات، وتصنّفه على أنه **قراءة** أو **كتابة** أو **حذف**. ألغِ تحديد أي إذن لا تريده. لا يحصل الوكيل إلا على أدوات الأذونات التي تسمح بها، ولا يزال Phaseo يتحقق من دورك في مساحة العمل عند كل تغيير، لذا لا يستطيع العضو الذي ليس مالكًا أو مسؤولًا تغيير الإعدادات المقصورة على المسؤولين بهذه الطريقة.

إذا كنت قد اتصلت بالفعل باستخدام عنوان القراءة فقط، فبدّل العميل إلى عنوان الإدارة وسجّل الدخول مجددًا. للعودة إلى الوصول للقراءة فقط، أعِد الاتصال بالعنوان العادي أو ألغِ التطبيق من **الإعدادات → التطبيقات المتصلة**.

يقرأ اتصال الإدارة كل ما يرد أدناه، لكنه لا يغيّر إلا مفاتيح API وإعدادات مساحة العمل. أما الميزانيات وقواعد الإنفاق ومفاتيح المزوّدين وضوابط الحماية والإعدادات المسبقة وخطافات الويب ووجهات قابلية الرصد فهي تتحكم في الإنفاق أو في وجهة محتوى الطلبات، لذا تغيّرها من لوحة التحكم أو باستخدام مفتاح إدارة.

| المجال | القراءة | التغيير |
| --- | --- | --- |
| مفاتيح API | `api_keys_list`, `api_key_get` | مع `phaseo mcp --manage`: `api_key_create` و`api_key_update` و`api_key_rotate` و`api_key_delete`. ويمكن للعملاء الآخرين إعادة التسمية (`api_key_update`) والحذف (`api_key_delete`) |
| الإعدادات | `settings_get` | `settings_update`، للتغييرات التي تُبقي على الخصوصية والتسجيل وقيود المزوّدين أو تشدّدها |
| الميزانيات | `budgets_list` | من لوحة التحكم |
| قواعد الإنفاق | `spend_rules_list` | من لوحة التحكم |
| مفاتيح المزوّدين (BYOK) | `provider_keys_list` | من لوحة التحكم |
| ضوابط الحماية | `guardrails_list`, `guardrail_get` | من لوحة التحكم |
| الإعدادات المسبقة | `presets_list`, `preset_get` | من لوحة التحكم |
| خطافات الويب | `webhooks_list` | من لوحة التحكم |
| وجهات قابلية الرصد | `observability_destinations_list` | من لوحة التحكم |

تُوسَم الأدوات التي تغيّر شيئًا أو تحذفه بذلك، لذا تطلب منك عملاء MCP التي تدعم ذلك التأكيد قبل كل استدعاء. يظهر مفتاح API الجديد مرة واحدة في نتيجة الأداة ولا يمكن عرضه مرة أخرى. ولا تُعاد أبدًا مفاتيح المزوّدين المخزّنة ولا بيانات اعتماد الوجهات.

لا يتضمن MCP أدوات للفوترة أو الدفع أو مساحات العمل أو الأعضاء أو مفاتيح الإدارة أو تطبيقات OAuth. استخدم لوحة التحكم أو CLI أو Management API لذلك.

## Docs MCP

Docs MCP نقطة نهاية منفصلة للبحث في توثيق Phaseo وقراءته. ولا يصل إلى حسابك أو مساحة عملك.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

## إضافة Phaseo

تجمع إضافة Phaseo بين Phaseo MCP وDocs MCP ومهارات وكلاء Phaseo للتكامل والترحيل واختيار النماذج ومراقبة الاستخدام وحزم SDK وCLI. ثبّتها مرة واحدة بدلًا من ربط كل جزء بنفسك.

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

شغّل `/mcp` وسجّل الدخول إلى `plugin:phaseo:phaseo` لربط حساب Phaseo الخاص بك. تُحمَّل المهارات عندما يطابقها طلب، أو يمكنك تشغيل إحداها مباشرةً، مثل `/phaseo:phaseo-gateway`.

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

يفتح الأمر الأخير Phaseo OAuth لـ Phaseo MCP. تُحمَّل المهارات عندما يطابقها طلب.
