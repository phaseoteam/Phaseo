# CLI وMCP

استخدم Phaseo من الطرفية عبر CLI، أو اربط عميلاً للذكاء الاصطناعي عبر MCP. يستخدم كلاهما Phaseo OAuth، لكن لكل منهما غرض مختلف.

| الواجهة | مناسبة لـ | الصلاحيات |
| --- | --- | --- |
| Phaseo CLI | سير العمل عبر الطرفية وCI والإدارة والأتمتة | قراءة وكتابة وفق النطاقات ودورك في مساحة العمل |
| Phaseo MCP | بيانات Phaseo المباشرة داخل Codex وClaude وChatGPT وعملاء MCP الآخرين | مصادق عليه وللقراءة فقط |
| Docs MCP | البحث في وثائق Phaseo الحالية أثناء البرمجة | الوثائق فقط وللقراءة فقط |

## Phaseo CLI

استخدم CLI لإنشاء موارد Phaseo أو تغييرها، أو لكتابة البرامج النصية لسير العمل، أو لفحص بيانات الحساب من shell.

### التثبيت وتسجيل الدخول

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

تستخدم الطرفيات التفاعلية OAuth عبر المتصفح افتراضياً. استخدم تفويض الجهاز مع SSH وCI والبيئات بلا واجهة:

```bash
phaseo login --device-code
```

### سير العمل الشائع

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys create --name "Local development"
phaseo logs list --since 1h --status error --json
```

استخدم `--json` عندما تحتاج أداة أو برنامج نصي آخر إلى مخرجات منظّمة. لا تُعرض القيم السرية إلا عبر أوامر تنشئها أو تكشفها صراحةً.

## Phaseo MCP

اربط خادم Phaseo MCP عندما تريد من عميل ذكاء اصطناعي الإجابة استناداً إلى بيانات حية عن النماذج والأسعار والمزوّدين والاستخدام ومساحات العمل.

### عنوان الخادم

`https://mcp.phaseo.app/mcp`

### الاتصال من Codex

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

يفتح أمر تسجيل الدخول Phaseo OAuth. اختر مساحة عمل ووافق على نطاقات القراءة المطلوبة، ثم أكّد الاتصال:

```bash
codex mcp list
```

لعميل MCP آخر، أضف عنوان URL نفسه كخادم HTTP متدفق عن بُعد. يجب أن يدعم العميل اكتشاف OAuth ورمز التفويض مع S256 PKCE ومعامل MCP `resource`.

### البيانات التي يمكن لـ MCP قراءتها

- النماذج ومزوّدو الخدمة والمؤسسات وعائلات نقاط النهاية والأسعار
- الأرصدة والنشاط والتحليلات وسجلات الطلبات وبيانات التوليد الوصفية
- مساحات العمل والأعضاء والإعدادات المسبقة والضوابط والإعدادات
- بيانات مفاتيح API ومفاتيح الإدارة وتطبيقات OAuth وخطافات الويب دون قيم سرية

لا ينفّذ MCP استدلالاً مدفوعاً ولا يعيد قيماً سرية ولا يغيّر موارد Phaseo. استخدم لوحة التحكم أو CLI أو Management API لتنفيذ هذه العمليات.

## Docs MCP

Docs MCP نقطة نهاية منفصلة للبحث في وثائق Phaseo وقراءتها، ولا تصل إلى حسابك أو مساحة عملك.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

استخدمها عندما يحتاج مساعد البرمجة إلى أمثلة API حديثة أو إرشادات تكامل أو وثائق الميزات.

## اختيار الواجهة المناسبة

- استخدم **CLI** لإنشاء المفاتيح أو تغيير الإعدادات أو إدارة مساحات العمل أو أتمتة المهام الإدارية.
- استخدم **Phaseo MCP** لمنح عميل الذكاء الاصطناعي وصولاً آمناً إلى بيانات Phaseo الحية.
- استخدم **Docs MCP** لإتاحة وثائق Phaseo الحالية لمساعد برمجي دون الوصول إلى الحساب.
