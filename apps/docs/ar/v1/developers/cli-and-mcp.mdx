استخدم CLI لتغيير Phaseo من الطرفية أو من سكربت، أو اربط عميل ذكاء اصطناعي بخادم Phaseo MCP لتمنحه بيانات Phaseo الحية. يسجّل كلاهما الدخول باستخدام Phaseo OAuth.

| الواجهة | استخدمها من أجل | الوصول |
| --- | --- | --- |
| [Phaseo CLI](#phaseo-cli) | إنشاء المفاتيح، وتغيير الإعدادات، وإدارة مساحات العمل، وأتمتة العمل الإداري من الطرفية أو CI | قراءة وكتابة، في حدود نطاقاتك ودورك في مساحة العمل |
| [Phaseo MCP](#phaseo-mcp) | منح Codex وClaude وChatGPT وعملاء MCP الآخرين بيانات Phaseo الحية، والسماح لهم اختياريًا بإدارة حسابك | قراءة فقط ما لم تتصل مع إدارة الحساب |
| [Docs MCP](#docs-mcp) | منح مساعد البرمجة توثيق Phaseo الحالي | التوثيق فقط، دون وصول إلى الحساب |
| [إضافة Phaseo](#phaseo-plugin) | تثبيت خادمَي MCP ومهارات Phaseo في Claude Code أو Codex دفعة واحدة | مثل كل خادم MCP |

## Phaseo CLI

### ثبّته وسجّل الدخول

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

تستخدم الطرفيات التفاعلية OAuth عبر المتصفح افتراضيًا. أما في SSH وCI والبيئات بلا واجهة، فاستخدم تفويض الجهاز:

```bash
phaseo login --device-code
```

### سير العمل الشائع

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys list
phaseo logs list --since 1h --status error --json
```

استخدم `--json` عندما تحتاج أداة أخرى أو سكربت إلى مخرجات منظَّمة. لا تُعرض القيم السرية إلا في الأوامر التي تنشئها أو تكشفها صراحةً.

## Phaseo MCP

عنوان الخادم هو `https://mcp.phaseo.app/mcp`. يستطيع عميل الذكاء الاصطناعي المتصل به الإجابة عن الأسئلة باستخدام بيانات حية عن النماذج والأسعار والمزوّدين والاستخدام ومساحة العمل.

### الاتصال من Codex

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

يفتح أمر تسجيل الدخول Phaseo OAuth. اختر مساحة عمل ووافق على نطاقات القراءة المطلوبة، ثم أكّد الاتصال:

```bash
codex mcp list
```

لعميل MCP آخر، أضف العنوان نفسه كخادم Streamable HTTP بعيد. يجب أن يدعم العميل اكتشاف OAuth، ورمز التفويض مع S256 PKCE، ومعامل MCP `resource`.

### ما الذي يستطيع MCP قراءته

تغطي أدوات القراءة فقط النماذج، والمزوّدين، وتصنيفات المقاييس المرجعية، والأسعار وتقديرات التكلفة، إضافةً إلى الأرصدة والنشاط والتحليلات وسجلات الطلبات والبيانات الوصفية للإنشاء. ولا تعيد أبدًا المطالبات أو الردود أو القيم السرية.

### إدارة حسابك (اختياري)

لتسمح لوكيل بتغيير مساحة عمل Phaseo الخاصة بك، اتصل باستخدام عنوان الإدارة بدلًا من ذلك:

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

عند تسجيل الدخول، تسرد شاشة الموافقة كل إذن يطلبه الاتصال، مثل إدارة مفاتيح API أو حذف الميزانيات، وتصنّفه على أنه **قراءة** أو **كتابة** أو **حذف**. ألغِ تحديد أي إذن لا تريده. لا يحصل الوكيل إلا على أدوات الأذونات التي تسمح بها، ولا يزال Phaseo يتحقق من دورك في مساحة العمل عند كل تغيير، لذا لا يستطيع العضو الذي ليس مالكًا أو مسؤولًا تغيير الإعدادات المقصورة على المسؤولين بهذه الطريقة.

إذا كنت قد اتصلت بالفعل باستخدام عنوان القراءة فقط، فبدّل العميل إلى عنوان الإدارة وسجّل الدخول مجددًا. للعودة إلى الوصول للقراءة فقط، أعِد الاتصال بالعنوان العادي أو ألغِ التطبيق من **الإعدادات → التطبيقات المتصلة**.

| المجال | الأدوات | الأذونات |
| --- | --- | --- |
| مفاتيح API | `api_keys_list`، `api_key_get`، `api_key_create`، `api_key_update`، `api_key_rotate`، `api_key_delete` | `keys:read`، `keys:write`، `keys:delete` |
| الميزانيات | `budgets_list`، `budget_create`، `budget_update`، `budget_delete` | `budgets:read`، `budgets:write`، `budgets:delete` |
| قواعد الإنفاق | `spend_rules_list`، `spend_rule_create`، `spend_rule_update`، `spend_rule_delete` | `spend_rules:read`، `spend_rules:write`، `spend_rules:delete` |
| مفاتيح المزوّدين (BYOK) | `provider_keys_list`، `provider_key_create`، `provider_key_update`، `provider_key_delete` | `provider_credentials:read`، `provider_credentials:write`، `provider_credentials:delete` |
| ضوابط الحماية | `guardrails_list`، `guardrail_get`، `guardrail_create`، `guardrail_update`، `guardrail_delete`، `guardrail_keys_set` | `guardrails:read`، `guardrails:write`، `guardrails:delete` |
| الإعدادات المسبقة | `presets_list`، `preset_get`، `preset_create`، `preset_update`، `preset_version_publish` | `presets:read`، `presets:write` |
| الإعدادات | `settings_get`، `settings_update` (وضع التوجيه، والخصوصية وZDR، والتسجيل، وقيود المزوّدين) | `settings:read`، `settings:write` |
| خطافات الويب | `webhooks_list`، `webhook_create`، `webhook_delete` | `settings:read`، `settings:write` |
| وجهات قابلية الرصد | `observability_destinations_list`، `observability_destination_create`، `observability_destination_delete` | `settings:read`، `settings:write` |

الأدوات التي تغيّر شيئًا أو تحذفه موسومة بذلك، لذا تطلب منك عملاء MCP التي تدعم ذلك الموافقة قبل كل استدعاء. يُعرض مفتاح API الجديد أو سر توقيع خطاف الويب مرة واحدة في نتيجة الأداة ولا يمكن عرضه مجددًا. ولا تُعاد أبدًا مفاتيح المزوّدين المخزّنة أو بيانات اعتماد الوجهات.

لا يتضمن MCP أدوات للفوترة أو الدفع أو مساحات العمل أو الأعضاء أو مفاتيح الإدارة أو تطبيقات OAuth. استخدم لوحة التحكم أو CLI أو Management API لذلك.

## Docs MCP

Docs MCP نقطة نهاية منفصلة للبحث في توثيق Phaseo وقراءته. ولا يصل إلى حسابك أو مساحة عملك.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

## إضافة Phaseo

تجمع إضافة Phaseo بين Phaseo MCP وDocs MCP ومهارات وكلاء Phaseo للتكامل والترحيل واختيار النماذج ومراقبة الاستخدام وحزم SDK وCLI. ثبّتها مرة واحدة بدلًا من ربط كل جزء بنفسك.

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

شغّل `/mcp` وسجّل الدخول إلى `plugin:phaseo:phaseo` لربط حساب Phaseo الخاص بك. تُحمَّل المهارات عندما يطابقها طلب، أو يمكنك تشغيل إحداها مباشرةً، مثل `/phaseo:phaseo-gateway`.

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

يفتح الأمر الأخير Phaseo OAuth لـ Phaseo MCP. تُحمَّل المهارات عندما يطابقها طلب.
