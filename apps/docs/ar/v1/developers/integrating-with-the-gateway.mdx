احفظ مفتاح Phaseo على خادمك، واختر نقطة النهاية التي تطابق بروتوكول تطبيقك، ووجّه عميل HTTP أو SDK الخاص بك إلى `https://api.phaseo.app/v1`. ابدأ من [البدء السريع](../quickstart.mdx) إذا لم تكن قد أرسلت طلبًا بعد.

تحتاج إلى حساب Phaseo مع صلاحية الوصول إلى الـ Gateway، وإلى عميل HTTP أو SDK متوافق مع OpenAI أو SDK من Phaseo. تستخدم الأمثلة `google/gemma-3-27b:free`، الذي يعمل دون إيداع أرصدة.

<Steps>
<Step title="أنشئ مفتاحًا واحفظه">

افتح **الإعدادات → مفاتيح API** في [لوحة التحكم](https://phaseo.app/settings/keys)، أو استدعِ `POST /v1/keys` باستخدام مفتاح إدارة. سمِّ المفتاح باسم التطبيق والبيئة، ثم احفظه في مدير أسرار أو في ملف بيئة:

```bash
# .env.local
PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
PHASEO_BASE_URL="https://api.phaseo.app/v1"
```

استخدم مفاتيح منفصلة للتطوير المحلي وعمليات النشر التجريبية والإنتاج، لتتمكن من تدوير كل مفتاح ومراجعته على حدة.

</Step>
<Step title="اختر نقطة النهاية">

| نقطة النهاية | استخدمها من أجل |
| --- | --- |
| `/v1/responses` | المشاريع النصية الجديدة، والمخرجات المنظَّمة، وسير العمل متعدد الخطوات. |
| `/v1/chat/completions` | واجهات المحادثة والتكاملات الحالية بنمط OpenAI. |
| `/v1/messages` | التكاملات المتوافقة مع Anthropic. |
| `/v1/decisions` | القرارات ذات الأنواع المحددة بناءً على حالة التطبيق، مع Jev 1.13 (تجريبي). |
| `/v1/moderations` | فحوصات الأمان وسياسة المحتوى. |
| `/v1/images/generations` | الصور من مطالبات نصية. |

يسرد [مرجع API](../api-reference/introduction) كل نقطة نهاية ومعامل ورد.

</Step>
<Step title="أرسل طلبًا من تطبيقك">

يستخدم هذا المثال Chat Completions، الذي تتعامل معه العملاء المتوافقة مع OpenAI أصلًا. يرسل كل طلب المفتاح على شكل `Authorization: Bearer $PHASEO_API_KEY`.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemma-3-27b:free",
    "messages": [
      { "role": "system", "content": "You are a helpful assistant." },
      { "role": "user", "content": "Explain the benefits of AI." }
    ]
  }'
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});

const response = await client.chat.completions.create({
  model: "google/gemma-3-27b:free",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: "Explain the benefits of AI." },
  ],
});

console.log(response.choices[0]?.message?.content);
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.phaseo.app/v1",
)

response = client.chat.completions.create(
    model="google/gemma-3-27b:free",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain the benefits of AI."},
    ],
)

print(response.choices[0].message.content)
```

```go Go
package main

import (
  "context"
  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New("YOUR_API_KEY", "https://api.phaseo.app/v1")

  response, err := client.CreateChatCompletion(context.Background(), phaseo.ChatCompletionsRequest{
    Model: "google/gemma-3-27b:free",
    Messages: []map[string]interface{}{
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain the benefits of AI."},
    },
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(response)
}
```

<Note>
النماذج التي ينتهي معرّفها بـ `:free` تعمل دون إيداع أرصدة. أما النماذج المدفوعة فتحتاج إلى رصيد متاح في المحفظة.
</Note>
