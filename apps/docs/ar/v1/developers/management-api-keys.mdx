أنشئ مفتاح إدارة لاستدعاء واجهات API الإدارية في Phaseo من خوادمك: الأرصدة والنشاط ومساحات العمل والمفاتيح والإعدادات المسبقة والإعدادات وضوابط الحماية. لا يمكن لمفاتيح الإدارة إرسال طلبات الاستدلال.

أنشئ مفتاحًا من لوحة التحكم ضمن **الإعدادات → مفاتيح الإدارة**. لا يظهر السر إلا مرة واحدة، فاحفظه في مدير الأسرار. أرسله من الشيفرة التي تعمل على الخادم فقط، إلى عنوان URL الأساسي نفسه الذي يستخدمه الـ Gateway (`https://api.phaseo.app/v1`):

```http
Authorization: Bearer phaseo_v1_mk_<kid>_<secret>
```

## مفاتيح الإدارة ومفاتيح API ورموز OAuth

| بيانات الاعتماد | الصيغة | استخدمها في | تحدّها |
| --- | --- | --- | --- |
| مفتاح API للـ Gateway | `phaseo_v1_sk_<kid>_<secret>` | طلبات النماذج والتوليد | سياسة التوجيه والميزانيات والحدود وضوابط الحماية المرفقة |
| مفتاح واجهة إدارة API | `phaseo_v1_mk_<kid>_<secret>` | الطلبات الإدارية | صلاحياته ودورك في مساحة العمل |
| رمز وصول OAuth | | الإدارة نيابةً عن مستخدم | نطاقات OAuth المعتمدة ودور المستخدم في مساحة العمل |

لا تقبل مسارات الإدارة إلا مفاتيح الإدارة (أو رموز OAuth)؛ ولا يمكن لمفتاح API الخاص بالـ Gateway استدعاؤها.

[ضوابط الحماية](../cookbook/guardrails-for-api-keys.mdx) أداة تحكم منفصلة: تنطبق على مفاتيح API الخاصة بالـ Gateway وتحكم حركة الاستدلال، مثل قيود التوجيه والميزانيات ومعالجة حقن التعليمات وقواعد المعلومات الحساسة. أما صلاحيات مفتاح الإدارة فتحدد واجهات API الإدارية التي يمكنه استدعاؤها.

## اختر مستوى الوصول

يتحوّل كل قالب إلى قائمة صريحة من الصلاحيات عند إنشاء المفتاح. لا يخزّن Phaseo أبدًا حرف بدل مثل `all`، لذا لا يكتسب المفتاح أي صلاحية تُضاف لاحقًا.

| القالب | `--template` | يمنح |
| --- | --- | --- |
| **قراءة** | `read-only` | كل صلاحيات `*:read` الحالية |
| **كتابة** | `read-write` | كل صلاحيات `*:read` و`*:write` الحالية، دون الحذف |
| **الكل** | `full-control` | كل صلاحيات القراءة والكتابة والحذف الحالية |

لا يتضمن أي قالب الصلاحية `billing:write` التي تبدأ عمليات شحن الرصيد؛ اطلبها صراحةً باستخدام `--scopes`. لا تستخدم **الكل** إلا لأتمتة إدارية موثوقة.

لمنح صلاحيات أضيق، مرّر الصلاحيات التي تحتاجها باستخدام `--scopes scope_a,scope_b`:

| المجال | قراءة | كتابة | حذف |
| --- | --- | --- | --- |
| الهوية والكتالوج | `me:read`، `models:read`، `providers:read`، `pricing:read` | | |
| الاستخدام وقابلية الرصد | `credits:read`، `activity:read`، `analytics:read`، `generations:read`، `feedback:read` | `feedback:write` | |
| الفوترة | | `billing:write` (بالاشتراك الصريح) | |
| مساحات العمل | `workspaces:read` | `workspaces:write` | `workspaces:delete` |
| مفاتيح API للـ Gateway | `keys:read` | `keys:write` | `keys:delete` |
| مفاتيح واجهة إدارة API | `management_keys:read` | `management_keys:write` | `management_keys:delete` |
| الإعدادات المسبقة | `presets:read` | `presets:write` | `presets:delete` |
| الإعدادات | `settings:read` | `settings:write` | |
| بيانات اعتماد المزوّدين | `provider_credentials:read` | `provider_credentials:write` | `provider_credentials:delete` |
| النماذج الخاصة | `private_models:read` | `private_models:write` | `private_models:delete` |
| ضوابط الحماية | `guardrails:read` | `guardrails:write` | `guardrails:delete` |
| الميزانيات | `budgets:read` | `budgets:write` | `budgets:delete` |
| حدود المعدل | `rate_limits:read` | `rate_limits:write` | `rate_limits:delete` |
| المصنّفات | `classifiers:read` | `classifiers:write` | `classifiers:delete` |
| قواعد الإنفاق | `spend_rules:read` | `spend_rules:write` | `spend_rules:delete` |
| عملاء OAuth | `oauth_clients:read` | `oauth_clients:write` | `oauth_clients:delete` |

## الصلاحيات لا تتجاوز أدوار مساحة العمل

يتحقق Phaseo من أمرين في كل استدعاء: أن المفتاح يملك الصلاحية، وأن المفتاح أو مستخدم OAuth ينتمي إلى مساحة العمل بالدور الذي يتطلبه الإجراء. على سبيل المثال، تسمح `keys:write` بإدارة المفاتيح، لكن التحقق من الدور هو ما يقرر ما إذا كان المستدعي يستطيع إدارة المفاتيح في تلك المساحة. لا يمكن للمفتاح استخدام صلاحية للوصول إلى مساحة عمل أخرى أو لتخطي تحققات المالك والمسؤول.

## حافظ على أمان المفاتيح

- أبقِ مفاتيح الإدارة بعيدًا عن المتصفحات وسجلات سطح المكتب وأنظمة التحكم في المصدر والمحادثات.
- استخدم مفتاحًا واحدًا لكل تكامل، مع أضيق قالب يفي بالغرض.
- حدّد تاريخ انتهاء صلاحية عندما لا يحتاج التكامل إلى وصول دائم.
- أوقف المفاتيح غير المستخدمة مؤقتًا أو احذفها فورًا.
- غيّر المفتاح المسرّب قبل أن تتابع التحقيق.
