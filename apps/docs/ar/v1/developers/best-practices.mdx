ضع استدعاءات الـ Gateway خلف خدمة واحدة في الواجهة الخلفية، وأبقِ المفاتيح خارج العملاء والسجلات، ولا تُعِد إلا ما يمكن إعادته بأمان، وراقب زمن الاستجابة والتكلفة والأخطاء لكل نموذج. يرتبط كل قسم أدناه بالصفحة التي تتضمن التفاصيل.

## نظّم التكامل

- **غلّف استدعاءات الـ Gateway في خدمة واحدة أو عميل SDK واحد**، لكي يبقى تغيير النموذج أو المزوّد في مكان واحد. راجع [التكامل مع الـ Gateway](./integrating-with-the-gateway.mdx).
- **ابثّ الردود إلى واجهات المحادثة**، ليرى المستخدمون الـ tokens فور وصولها. راجع [البث](../guides/streaming.mdx).
- **ضع العمل غير العاجل في طابور**، مثل عمليات الإنشاء الخلفية والتقييمات، لتخفيف ذروات الحركة. يشغّل [Batch API](../guides/async-video-and-batch.mdx) المهام الكبيرة بشكل غير متزامن.

## أبقِ المفاتيح سرية

- احفظ مفاتيح API في مدير أسرار (AWS Secrets Manager أو Doppler أو 1Password) بدلًا من ملفات `.env` في بيئة الإنتاج.
- استدعِ الـ Gateway من واجهتك الخلفية، وصادِق تطبيقات العملاء الخاصة بك معها، لكي لا يحمل العملاء مفتاح Gateway أبدًا.
- سجّل بادئة المفتاح فقط، مثل `phaseo_v1_sk_<kid>`، ولا تسجّل السر أبدًا.

راجع [المصادقة](./authentication.mdx).

## أعِد المحاولة بأمان

- أعِد محاولة ردود `429` و`5xx` مع تراجع أسّي وتذبذب عشوائي.
- انتظر [`Retry-After`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Retry-After) قبل إعادة محاولة طلب خضع لتحديد المعدل.
- تحقّق في سجلات الطلبات من المزوّد الذي خدم كل طلب، لتلاحظ متى تنتقل الحركة إلى مزوّد آخر.

راجع [الأخطاء وتصحيحها](../api-reference/errors.mdx) و[حدود المعدل](../api-reference/limits.mdx).

## راقب الإشارات الصحيحة

| الإشارة | ما الذي تفعله |
| --- | --- |
| زمن الاستجابة | تتبّع p95 وp99 لاكتشاف التراجعات. |
| استخدام الـ tokens | قارن التكلفة بمقياس الأعمال الذي تدعمه. |
| معدل الأخطاء | أطلق تنبيهًا عندما تبقى حالات الفشل فوق 1%. |
| توزيع المزوّدين | تحقّق من أن الحركة موزّعة بين المزوّدين كما تتوقع. |

راجع [سجلات الطلبات وقابلية الرصد](../guides/integrations/observability.mdx). احتفظ بقوالب المطالبات والمعاملات وطريقة معالجة المخرجات موثّقة حيث يمكن لفريقك مراجعتها؛ تُبقي [الإعدادات المسبقة](../guides/presets.mdx) المطالبات المشتركة والقيم الافتراضية في مكان واحد.
