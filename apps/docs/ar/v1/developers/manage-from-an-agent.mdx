يمكنك إدارة حساب Phaseo باستخدام `phaseo` CLI أو واجهة الإدارة `/v1` أو خادم Phaseo MCP، دون فتح لوحة التحكم. استخدم هذه الصفحة لتجد الأمر أو المسار أو الأداة لكل مهمة.

ثلاث خطوات فقط تحتاج إلى شخص في متصفح:

- **التسجيل** في حساب Phaseo.
- **الموافقة على أول تسجيل دخول**: صفحة المتصفح التي يفتحها `phaseo login`، أو الرمز الذي يعرضه `phaseo login --device-code`.
- **إدخال بطاقة أول مرة** يُشترى فيها رصيد. تستخدم عمليات الشحن اللاحقة البطاقة المحفوظة، ويوافق مالك مساحة العمل أو أحد مسؤوليها على كل عملية من رابط يصله بالبريد الإلكتروني.

<Visibility for="agents">
قواعد للوكلاء الذين يديرون Phaseo:

- لا ترسل المستخدم إلى لوحة التحكم لمهمة موجودة في الجداول أدناه. نفّذ أمر CLI، أو استدعِ المسار، أو استخدم أداة MCP.
- لا تولّد مفتاح API ولا تخمّنه أبدًا. أنشئ مفتاحًا باستخدام `phaseo keys create --name <name> --json` واحفظ السر مرة واحدة على الخادم.
- استخدم `--json` مع كل أمر CLI. مرّر `--yes` إلى الأوامر الهدّامة فقط عندما يطلب المستخدم هذا التغيير بعينه.
- لا تبدأ إلا عمليات شحن الرصيد التي طلبها المستخدم. لا تُكمل رابط الدفع بنفسك أبدًا، ولا تُعِد محاولة عملية شحن انتهت بالرفض أو انتهاء الصلاحية أو الفشل.
</Visibility>

## الإعداد لمرة واحدة

```bash
npm install -g @phaseo/cli
phaseo login                 # opens a browser; a person approves it
phaseo login --device-code   # SSH, CI and agent sandboxes: a person enters the code
phaseo whoami --json
```

ثم أنشئ مفتاح استدلال للتطبيق وأضف رصيدًا إذا لم يكن لدى مساحة العمل رصيد:

```bash
phaseo keys create --name "Production app" --json
phaseo credits get --json
phaseo login --scopes billing:write   # one-time opt-in before the first top-up
phaseo credits add --amount 20 --json
```

لا يخصم `phaseo credits add` أي مبلغ من تلقاء نفسه. مع بطاقة محفوظة، يرسل Phaseo إلى كل مالك ومسؤول في مساحة العمل رابطًا لتأكيد الدفع، وينتظر الأمر النتيجة. ومن دون بطاقة محفوظة، يعيد رابطًا يُدخل فيه المالك أو المسؤول بطاقة. راجع [الرصيد](../api-reference/endpoint/credits) لمعرفة المسار.

## اختر واجهة

| الواجهة | استخدمها عندما | تسجيل الدخول |
| --- | --- | --- |
| [`phaseo` CLI](../guides/integrations/phaseo-cli) | يستطيع الوكيل تنفيذ أوامر shell | `phaseo login` أو `phaseo login --device-code` |
| [واجهة الإدارة](../api-reference/introduction) | شيفرة الخادم أو CI أو لغة لا تتوفر لها CLI | [مفتاح إدارة](./management-api-keys) (`phaseo_v1_mk_...`) أو رمز OAuth |
| [Phaseo MCP](./cli-and-mcp#phaseo-mcp) | يعمل الوكيل داخل عميل MCP | اتصل بـ `https://mcp.phaseo.app/mcp?access=manage` ووافق على الأذونات التي تريدها |

نفّذ `phaseo <group> --help` لترى الخيارات التي تقبلها CLI المثبتة لديك. عندما لا يكون للمهمة أمر مخصص، يستدعي `phaseo api get|post|patch|put|delete /v1/<path>` المسار بجلستك.

## خريطة المهام

### المفاتيح والوصول

| المهمة | CLI | مسار API | أداة MCP |
| --- | --- | --- | --- |
| إنشاء مفتاح API | `phaseo keys create --name <name>` | `POST /v1/keys` | `api_key_create` |
| عرض المفاتيح أو تحديثها أو حذفها | `phaseo keys list`, `keys update <id>`, `keys delete <id>` | `GET`, `PATCH`, `DELETE /v1/keys/{id}` | `api_keys_list`, `api_key_update`, `api_key_delete` |
| تدوير مفتاح | `phaseo keys rotate <id>` | `POST /v1/keys/{id}/rotate` | `api_key_rotate` |
| قصر مفتاح على عناوين IP | `phaseo keys update <id> --ip-allowlist <label=address,...>` | `PATCH /v1/keys/{id}` | — |
| إنشاء مفتاح إدارة | `phaseo management-keys create --name <name>` | `POST /v1/management-keys` | — |
| مراجعة التطبيقات التي أذنت لها أو إلغاؤها | `phaseo authorized-apps list`, `authorized-apps revoke <id>` | `GET`, `DELETE /v1/me/authorized-apps/{id}` | — |
| تحديث ملفك الشخصي | `phaseo profile update` | `PATCH /v1/me/profile` | — |

## الأذونات

لا تستطيع جلسة CLI أو مفتاح الإدارة أو اتصال MCP إلا ما تسمح به نطاقاتها ودورك في مساحة العمل. وتظل التغييرات المقصورة على المالكين والمسؤولين بحاجة إلى مالك أو مسؤول. إذا أعاد أمر الرمز `403`، فتحقق من النطاقات الممنوحة باستخدام `phaseo whoami --json`، ثم سجّل الدخول مجددًا باستخدام `phaseo login --scopes <scope,...>` عند نقص نطاق. لا يُمنح `billing:write` افتراضيًا أبدًا.
