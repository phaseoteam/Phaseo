امنح طلب TypeScript واحدًا الأداة `phaseo:web_search` وJSON Schema، لكي يبحث النموذج قبل أن يجيب ويعيد موجزًا مع مصادره. في النهاية يصبح لديك سكربت يطبع كائن `{ summary, sources }` تم التحقق منه، إضافةً إلى المعرّفات وعدّادات البحث التي تحتاجها لتصحيحه.

السكربت جاهز للإنتاج بمجرد أن تستبدل الإعداد المسبق والنطاق بما يخصك. نتائج البحث محتوى ويب غير موثوق: تحقّق من المخرجات ولا تتبع أي تعليمات موجودة فيها.

## ابنِه

<Steps>
<Step title="أنشئ إعدادًا مسبقًا">

أنشئ `research-brief` في **الإعدادات → الإعدادات المسبقة** مع النموذج، وتفضيلات المزوّدين، وإعدادات الاستدلال، ومطالبة النظام التي يجب أن يتشاركها كل المستدعين. يجب أن يدعم النموذج الأدوات ومخرجات JSON Schema.

</Step>
<Step title="ثبّت SDK">

```bash
npm install @phaseo/sdk zod
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="اكتب السكربت">

```ts research-brief.ts
import Phaseo from "@phaseo/sdk";
import { z } from "zod";

const gateway = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const Brief = z
  .object({
    summary: z.string().min(1),
    sources: z
      .array(z.object({ title: z.string(), url: z.string().url() }).strict())
      .min(1),
  })
  .strict();

const response = await gateway.generateResponse({
  model: "@research-brief",
  input: "Find the latest public changes to Phaseo webhook delivery behavior and summarize them.",
  tools: [
    {
      type: "phaseo:web_search",
      parameters: {
        allowed_domains: ["phaseo.app"],
        max_results: 5,
        include_highlights: true,
      },
    },
  ],
  tool_choice: "phaseo:web_search",
  text: {
    format: {
      type: "json_schema",
      name: "research_brief",
      strict: true,
      schema: {
        type: "object",
        required: ["summary", "sources"],
        properties: {
          summary: { type: "string" },
          sources: {
            type: "array",
            minItems: 1,
            items: {
              type: "object",
              required: ["title", "url"],
              properties: {
                title: { type: "string" },
                url: { type: "string", format: "uri" },
              },
              additionalProperties: false,
            },
          },
        },
        additionalProperties: false,
      },
    },
  },
  plugins: [{ id: "response-healing" }],
  meta: true,
});

const text = (response.output ?? [])
  .filter((item) => item.type === "message")
  .flatMap((item) => item.content ?? [])
  .filter((part) => part.type === "output_text")
  .map((part) => part.text ?? "")
  .join("");

const brief = Brief.parse(JSON.parse(text));

console.log({
  responseId: response.id,
  model: response.model,
  routing: response.meta?.routing,
  pluginExecutions: response.meta?.plugin_executions,
  serverToolUse: response.usage?.server_tool_use,
});
console.log(brief);
```

| الحقل | ما يفعله |
| --- | --- |
| `tools` مع `phaseo:web_search` | يشغّل Phaseo البحث، سواء كان لدى المزوّد بحثه الخاص أم لا. والنموذج هو من يكتب الاستعلام. |
| `allowed_domains` | يقصر النتائج على مصادرك الخاصة. كل المعاملات موجودة في [دليل البحث على الويب](../guides/server-tools/web-search#parameters). |
| `tool_choice: "phaseo:web_search"` | يُلزم النموذج بالبحث بدلًا من الإجابة من ذاكرته. |
| `text.format` | JSON Schema الخاص بالإجابة. |
| `plugins` | يصلح الـ JSON شبه الصالح؛ راجع [إصلاح الردود](./response-healing-for-structured-json). |
| `meta: true` | يضيف `meta.routing` و`meta.plugin_executions`. |

</Step>
<Step title="شغّله">

```bash
npx tsx research-brief.ts
```

</Step>
</Steps>

## تحقّق من نجاحه

- قيمة `serverToolUse.web_search_requests` تساوي `1` على الأقل، أي أن البحث جرى.
- يسرد `brief.sources` عناوين URL من `phaseo.app`.
- يذكر `routing.selected_provider` المزوّد، ويُظهر `pluginExecutions` ما إذا كان الإصلاح قد غيّر شيئًا.
- في **الإعدادات → الاستخدام → السجلات**، يعرض قسم **قابلية رصد البحث على الويب** في الطلب عمليات البحث المُدارة والنتائج والاستشهادات.

إذا بدت النتائج خاطئة، فأصلح الإعداد المسبق أو معاملات الأداة بناءً على ما تُظهره السجلات بدلًا من إضافة تجاوزات. تسرد صفحة [صحّح البحث على الويب](./web-search-debugging) الحالات الشائعة. أبقِ البحث الاستكشافي ذا `temperature` الأعلى في إعداد مسبق منفصل عن هذا الإعداد الحتمي، لتبقى مقارنة توجيههما سهلة.
