شغّل وكيلًا بلغة C# يحمّل تذكرة دعم باستخدام أداة محلية ويكتب ملخص فرز قصيرًا، داخل خدمة ASP.NET أو خدمة عامل واحدة. في النهاية يكون لديك تطبيق وحدة تحكم يطبع الإجراء التالي للتذكرة `T-1042`.

تُرجع الأداة بيانات عيّنة ثابتة، لذا فالبرنامج توضيحي؛ استبدلها بمخزن التذاكر لديك. يناسب ذلك خدمة تعرف مسبقًا كيف تجلب حالة التذاكر الداخلية وتريد حلقة محدودة قبل إضافة قوائم الانتظار أو الموافقات.

## أنشئه

<Steps>
<Step title="التثبيت">

```bash
dotnet new console -n TicketTriage
cd TicketTriage
dotnet add package Phaseo.AgentSdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

تثبّت `Phaseo.AgentSdk` الحزمة `Phaseo.Sdk` معها، وتتطلب .NET 8 أو أحدث. راجع [تثبيت C# Agent SDK](../sdk-reference/agent/installation).

</Step>
<Step title="اكتب الوكيل">

```csharp Program.cs
using System.Text.Json;
using System.Text.RegularExpressions;
using PhaseoAgentSdk;

var loadTicket = AgentSdk.DefineTool(new Tool(
    Id: "load-ticket",
    Description: "Load one support ticket by id.",
    Parameters: new Dictionary<string, object?>
    {
        ["type"] = "object",
        ["properties"] = new Dictionary<string, object?>
        {
            ["ticketId"] = new Dictionary<string, object?> { ["type"] = "string", ["pattern"] = "^T-\\d+$" },
        },
        ["required"] = new[] { "ticketId" },
        ["additionalProperties"] = false,
    },
    Execute: (input, ctx) => Task.FromResult<object?>(new Dictionary<string, object?>
    {
        ["ticketId"] = ((JsonElement)input!).GetProperty("ticketId").GetString(),
        ["severity"] = "medium",
        ["summary"] = "Customer cannot find preset routing settings.",
    })
))
{
    // تأتي الوسائط من النموذج: ارفض أي شيء غير معرّف تذكرة سليم الصيغة.
    InputSchema = input =>
    {
        if (input is JsonElement json
            && json.TryGetProperty("ticketId", out var id)
            && id.ValueKind == JsonValueKind.String
            && Regex.IsMatch(id.GetString()!, @"^T-\d+$"))
        {
            return input;
        }
        throw new ArgumentException("ticketId must look like T-1042");
    },
};

var agent = AgentSdk.CreateAgent(new AgentDefinition
{
    Id = "ticket-triage-agent",
    Model = "openai/gpt-6-astra",
    Instructions = "Use tools when helpful and answer with a short triage summary.",
    Tools = new[] { loadTicket },
    MaxSteps = 4,
});

// يقرأ PHASEO_API_KEY من متغيرات البيئة.
var result = await agent.Run(new RunOptions
{
    Input = "Review ticket T-1042 and summarize the next action.",
    Client = AgentSdk.CreateGatewayAgentClient(),
});

Console.WriteLine(result.Run.Status);
Console.WriteLine(result.Output);
```

</Step>


## تحقّق من نجاحه

- يطبع التطبيق `completed`، ثم ملخصًا يذكر إعدادات توجيه الإعدادات المسبقة.
- في **الإعدادات → الاستخدام → السجلات**، يعرض أول دور للنموذج استدعاء `load-ticket` مع `{"ticketId": "T-1042"}`.
- من دون `PHASEO_API_KEY`، يرمي `CreateGatewayAgentClient` الخطأ `PHASEO_API_KEY is required.`

## قبل الإنتاج

أبقِ `MaxSteps` منخفضًا (القيمة الافتراضية `12`)، واجعل الأداة للقراءة فقط، واضبط `RequireApproval = true` على أي أداة تغيّر تذكرة كي يتوقف التشغيل بانتظار شخص. لمسار فرز أكبر يستخدم إعدادًا مسبقًا وJSON صارمًا وتوقفات للمراجعة، راجع [فرز طلبات الدعم](./agent-sdk-support-triage). يشرح [مرجع C# Agent SDK](../sdk-reference/agent/usage) الحالة والموافقة والبث.
