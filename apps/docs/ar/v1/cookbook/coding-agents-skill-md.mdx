أضف ملف `SKILL.md` إلى مستودعك لكي يستدعي وكلاء البرمجة Phaseo بالطريقة التي يتوقعها مشروعك: عنوان الأساس نفسه، ومتغير المفتاح نفسه، ونقطة النهاية نفسها، والنماذج المعتمدة، والتسجيل. في النهاية تكون قد ثبّتّ مهارات Phaseo العامة، وأضفت فوقها مهارة واحدة خاصة بالمشروع، ووحدة عميل مشتركة واحدة تشير إليها المهارة.

المهارة والوحدة أدناه جاهزتان للإنتاج بمجرد أن تستبدل معرّفات النماذج وأسماء الإعدادات المسبقة بما يخصك.

<Steps>
<Step title="ثبّت مهارات Phaseo العامة">

<Visibility for="humans">
تغطي المهارات العامة الـ Gateway وحزم SDK والإعدادات المسبقة والتوجيه والترحيل. ثبّتها من [`phaseo.app/docs`](https://phaseo.app/docs/.well-known/agent-skills/index.json):
</Visibility>

<Visibility for="agents">
ثبّت مهارات Phaseo العامة من [`phaseo.app/docs`](https://phaseo.app/docs/.well-known/agent-skills/index.json) قبل كتابة تعليمات محلية خاصة بالمشروع:
</Visibility>

```bash
npx skills add https://phaseo.app/docs --agent codex --skill '*'
```

غيّر `--agent` إلى الوكيل الذي يستخدمه فريقك. احتفظ في ملف `SKILL.md` الخاص بك بالقواعد الخاصة بالمشروع فقط.

</Step>
<Step title="ثبّت SDK">

<CodeGroup>
```bash npm
npm install @phaseo/sdk
```

```bash pnpm
pnpm add @phaseo/sdk
```

```bash yarn
yarn add @phaseo/sdk
```

```bash bun
bun add @phaseo/sdk
```

```bash Python
pip install phaseo
```
</CodeGroup>

</Step>
<Step title="أضف عميلًا مشتركًا واحدًا">

يعيد الوكلاء استخدام دالة مساعدة صغيرة وواضحة بموثوقية أكبر من غلاف كبير. ضع العميل في وحدة واحدة واستورده في كل مكان:

```ts src/lib/phaseo.ts
import Phaseo from "@phaseo/sdk";

export const gateway = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY!,
});
```

احتفظ بمسار استدعاء واحد لكل واجهة تستخدمها، مثل إنشاء النص أو التضمينات أو إنشاء الصور أو الفيديو غير المتزامن.

</Step>
<Step title="اكتب مهارة المشروع">

أنشئ `SKILL.md` في جذر المستودع أو في مجلد المهارات الذي يقرؤه وكيلك (مثل `.agents/skills/phaseo-project/SKILL.md`). الحقلان `name` و`description` في الترويسة هما ما يقرؤه الوكيل ليقرر متى يحمّل المهارة:

```md SKILL.md
---
name: phaseo-project
description: "How this repository calls Phaseo Gateway: client module, endpoint, approved models and presets, logging and async jobs. Use when adding or changing any Phaseo call in this repo."
---

# Phaseo in this repository

- Import the client from `src/lib/phaseo.ts`. Never create another one.
- The base URL is `https://api.phaseo.app/v1`. The key is in `PHASEO_API_KEY`; never hard-code it or send it to the browser.
- Use the Responses API (`POST /v1/responses`) for new text features.
- Approved models: `openai/gpt-6-astra` for drafts, `anthropic/claude-sonnet-5.5` for reviews. Ask before adding another.
- Prefer the `@support-triage` preset for support features; pass it as `model`.
- Log the response `id` and `model` on every call, and `generation_id` from error bodies.
- For async video jobs, store the returned ID and poll status until it is terminal.
- Validate any model-generated tool arguments before acting on them.
```

</Step>
</Steps>

## تحقّق من نجاحه

اطلب من وكيلك إضافة ميزة صغيرة تستخدم Phaseo، مثل "summarise a ticket with Phaseo". يجب أن يستورد التغيير `src/lib/phaseo.ts`، ويقرأ `PHASEO_API_KEY`، ويستخدم نموذجًا أو إعدادًا مسبقًا معتمدًا، ويسجّل معرّف الرد. إن لم يحدث ذلك، فعلى الأرجح أن `description` في المهارة لا يطابق الطلب: اذكر فيه الكلمات التي يستخدمها فريقك لوصف المهمة.

## ما الذي تضعه في المهارة

أجب عن الأسئلة التي تكلّف الوكيل أكبر قدر من الوقت، ولا شيء غيرها:

| السؤال | مثال على الإجابة |
| --- | --- |
| أي عائلة من نقاط النهاية؟ | Responses للنص، وEmbeddings للبحث |
| أين بيانات الاعتماد؟ | `PHASEO_API_KEY`، من جهة الخادم فقط |
| ما معرّفات النماذج أو الإعدادات المسبقة المعتمدة؟ | قائمة قصيرة، بصيغة `org/model` |
| ما الذي يُسجَّل؟ | `id` و`model` للرد، و`generation_id` عند الأخطاء |
| كيف تُتابَع المهام غير المتزامنة؟ | احفظ المعرّف، واستعلم حتى تصل إلى حالة نهائية |
