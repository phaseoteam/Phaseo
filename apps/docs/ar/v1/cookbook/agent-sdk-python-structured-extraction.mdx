شغّل وكيلًا بلغة Python يبحث عن شيء باستخدام أداة محلية واحدة ويُرجع إجابته بصيغة JSON صارمة. في النهاية يكون لديك سكربت واحد تكون فيه `result.output` كائن `PolicySummary` تم التحقق منه يحتوي على `summary` و`recommendation`، لا نصًا حرًا.

تُرجع الأداة بيانات عيّنة ثابتة، لذا فالسكربت توضيحي؛ استبدلها بعملية البحث الخاصة بك. يناسب ذلك عاملًا بلغة Python يملك تنسيقه الخاص ولديه مجموعة أدوات صغيرة وحتمية.

## أنشئه

<Steps>
<Step title="التثبيت">

<CodeGroup>
```bash pip
pip install phaseo-agent-sdk
```

```bash uv
uv add phaseo-agent-sdk
```
</CodeGroup>

تثبّت `phaseo-agent-sdk` عميل `phaseo` وPydantic معها.

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="اكتب الوكيل">

```python extract.py
import json
import os

from pydantic import BaseModel, ConfigDict

from phaseo_agent import AgentTool, create_agent, create_gateway_agent_client, define_tool

POLICY_SLUGS = {"presets", "routing", "guardrails"}


class PolicySummary(BaseModel):
    model_config = ConfigDict(extra="forbid")
    summary: str
    recommendation: str


def check_lookup_input(value):
    # وسائط يولّدها النموذج: ارفض أي شيء ليس معرّفًا نصيًا معروفًا.
    if not isinstance(value, dict) or set(value) != {"slug"} or value["slug"] not in POLICY_SLUGS:
        raise ValueError(f"slug must be one of {sorted(POLICY_SLUGS)}")
    return value


lookup_policy = define_tool(
    AgentTool(
        id="lookup-policy",
        description="Look up one internal policy by slug.",
        parameters={
            "type": "object",
            "properties": {"slug": {"type": "string", "enum": sorted(POLICY_SLUGS)}},
            "required": ["slug"],
            "additionalProperties": False,
        },
        input_schema=check_lookup_input,
        execute=lambda input, ctx: {
            "slug": input["slug"],
            "summary": "Presets centralize routing, prompts, and caching defaults.",
        },
    )
)

agent = create_agent(
    {
        "id": "policy-extractor",
        "model": "openai/gpt-6-astra",
        "instructions": "Use tools when needed and return JSON with summary and recommendation.",
        "tools": [lookup_policy],
        "max_steps": 4,
        "parse_output": json.loads,
        "output_schema": PolicySummary,
    }
)

# لا يقرأ عميل Python المتغير PHASEO_API_KEY تلقائيًا: مرّره بنفسك.
client = create_gateway_agent_client(
    client_options={"api_key": os.environ["PHASEO_API_KEY"]},
    response_format={
        "type": "json_schema",
        "name": "policy_summary",
        "schema": {
            "type": "object",
            "properties": {
                "summary": {"type": "string"},
                "recommendation": {"type": "string"},
            },
            "required": ["summary", "recommendation"],
            "additionalProperties": False,
        },
    },
    plugins=[{"id": "response-healing"}],
)

result = agent.run(input="Look up our presets policy and recommend when to use it.", client=client)

print(result.run.status)
print(result.output)
```

| الجزء | وظيفته |
| --- | --- |
| `parameters` | مخطط JSON Schema الذي يراه النموذج لوسائط الأداة |
| `input_schema` | يتحقق من الوسائط قبل تشغيل `execute`؛ ويؤدي الاستدعاء السيئ إلى فشل التشغيل |
| `response_format` | يطلب من الـ Gateway مخطط JSON Schema هذا في كل دور |
| `parse_output` و`output_schema` | يحلّلان النص النهائي ويتحققان منه ويحوّلانه إلى `PolicySummary` |

## تحقّق من نجاحه

- يطبع السكربت `completed`، ثم `PolicySummary` مع تعبئة الحقلين كليهما.
- في **الإعدادات → الاستخدام → السجلات**، يعرض أول دور للنموذج استدعاء `lookup-policy` مع `{"slug": "presets"}`.
- تفشل المخرجات التي لا تطابق نموذج `PolicySummary` بالخطأ `Invalid agent output` بدلًا من إرجاع كائن نصف معبّأ.

للحصول على مخرجات منظّمة في طلب واحد دون أدوات، استدعِ [Python SDK مباشرةً](./sdk-python-presets-and-json). يشرح [مرجع Python Agent SDK](../sdk-reference/agent/usage) الحالة والموافقة والبث.
