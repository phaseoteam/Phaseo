أرسل `"model": "phaseo/free"` وسيشغّل Phaseo طلبك على نموذج مجاني متاح يدعمه، دون أرصدة. في النهاية يصبح لديك طلب واحد يعمل باللغة التي تختارها، وتعرف أي نموذج أجاب عنه.

هذا شكل طلب جاهز للإنتاج للنماذج الأولية والعروض التوضيحية والحركة منخفضة المخاطر. لا تَعِد النماذج المجانية بزمن استجابة أو أسلوب مخرجات أو مزوّد ثابت.

## أرسل الطلب

<Steps>
<Step title="عيّن مفتاحك">

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="أرسل طلبًا واحدًا">

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Summarize why provider-aware free routing helps prototypes.",
  temperature: 0.2,
});

console.log(JSON.stringify(response.output, null, 2));
```

```python Python
import json
import os

from phaseo import Phaseo

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])

response = client.generate_response(
    {
        "model": "phaseo/free",
        "input": "Summarize why provider-aware free routing helps prototypes.",
        "temperature": 0.2,
    }
)

print(json.dumps(response.get("output"), indent=2))
```

```go Go
package main

import (
  "context"
  "fmt"
  "os"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New(os.Getenv("PHASEO_API_KEY"), "https://api.phaseo.app/v1")

  temperature := 0.2
  response, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
    Model:       "phaseo/free",
    Input:       "Summarize why provider-aware free routing helps prototypes.",
    Temperature: &temperature,
  })
  if err != nil {
    panic(err)
  }

  fmt.Printf("%+v\n", response)
}
```

## كيف يُختار النموذج المجاني

1. يذهب طلبك إلى الاسم المستعار المشترك `phaseo/free`.
2. يُبقي Phaseo على النماذج المجانية القادرة على خدمة هذا الطلب (نقطة النهاية، والمعاملات، والأدوات).
3. يرسل الطلب إلى أحدها.

تتشارك النماذج المجانية حصة افتراضية قدرها 1,500 طلب لكل مستخدم في كل يوم UTC. بعد تجاوزها، تعيد الطلبات `429` مع الرمز `phaseo_free_model_limit_exceeded` حتى الساعة 00:00 UTC؛ راجع [حدود الـ Gateway](../api-reference/limits#gateway-limits).

## الانتقال من الموجّه المجاني

إذا لم يدعم أي نموذج مجاني ميزة تحتاجها، مثل الأدوات أو JSON Schema، فانتقل إلى نموذج مدفوع محدد بدلًا من إعادة محاولة الطلب نفسه. انتقل إلى نموذج ثابت عندما تحتاج إلى زمن استجابة متوقع أو أسلوب مخرجات ثابت أو اختيار المزوّد، وضع الإعدادات المشتركة في [إعداد مسبق](../guides/presets) لكي ترسل كل خدمة الطلب نفسه. يشرح [التوجيه والاحتياط](../guides/routing-and-fallbacks) كيف تختار الطلبات المدفوعة مزوّدها، وتسرد [أخطاء API](../api-reference/errors) رموز الأخطاء.
