استخدم هذا الدليل لتشغيل أول عملية تكامل مع Phaseo دون اختيار نموذج مدفوع الآن.

بدلًا من اختيار نموذج مجاني بنفسك، أرسل الطلبات إلى `phaseo/free`. ستختار Phaseo نموذجًا مجانيًا متاحًا يدعم الطلب الذي ترسله.
## مثال على طلب
<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```

```typescript TypeScript SDK
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Summarize why provider-aware free routing helps prototypes.",
  temperature: 0.2,
});

console.log(response.output_text);
```

```python Python SDK
from phaseo import Phaseo

client = Phaseo(api_key="YOUR_API_KEY")

response = client.generate_response(
    {
        "model": "phaseo/free",
        "input": "Summarize why provider-aware free routing helps prototypes.",
        "temperature": 0.2,
    }
)

print(response.get("output_text"))
```

```go Go SDK
package main

import (
  "context"
  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New("YOUR_API_KEY", "https://api.phaseo.app/v1")

  response, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
    Model: "phaseo/free",
    Input: map[string]interface{}{
      "role": "user",
      "content": []map[string]string{
        {
          "type": "input_text",
          "text": "Summarize why provider-aware free routing helps prototypes.",
        },
      },
    },
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(response)
}
```

## ما يحدث في الخلفية

1. يُرسل طلبك إلى الاسم المستعار المشترك `phaseo/free`.
2. تتحقق Phaseo من النماذج المجانية القادرة على معالجة الطلب.
3. يُختار نموذج مجاني متاح لاستخدامه في إنشاء الرد.
4. تظل تفاصيل الطلب تعرض النموذج المحدد الذي نُفّذ، لتتمكن من فحصه أو تصحيح أخطائه لاحقًا.

## بعد أول طلب

- في **Gateway -> الاستخدام**، افتح تفاصيل الطلب وتحقق من النموذج الذي استُخدم.
- إذا منعت سياسة مساحة العمل الطلب، فراجع التفاصيل لمعرفة الإعداد الذي أوقفه.
- إذا لم يدعم أي نموذج مجاني الميزة التي تحتاجها، فانتقل من `phaseo/free` إلى نموذج مدفوع محدد بدلًا من تكرار الطلب نفسه.

## ملاحظات للإنتاج

- استخدم `phaseo/free` للنماذج الأولية والعروض التوضيحية وحركة المرور منخفضة المخاطر.
- إذا كنت تحتاج إلى زمن استجابة أو أسلوب إخراج أو اختيار مزوّد يمكن توقعه، فانتقل إلى نموذج محدد بعد معرفة الأنسب.
- إذا كنت تحتاج إلى سلوك ثابت للمطالبات بين الخدمات، فأرفق هذا الدليل مع [الإعدادات المسبقة](../guides/presets.mdx).
