استخدم هذه الصفحة عندما تريد تزويد وكيل برمجة بموجّه واضح ينشئ تطبيقًا صغيرًا يعمل بدلًا من خطة تكامل مبهمة.

<Tip>
صيغت هذه الموجّهات للتركيز على النتائج وتحديد تفاصيل التنفيذ كي تعمل بشكل أفضل في Cursor وClaude Code وCodex والأدوات المشابهة.
</Tip>

## كيفية استخدام هذه الموجّهات

<Steps>
  <Step title="اختر واجهة التكامل">
    اختر الموجّه الذي يناسب طريقة استدعاء التطبيق لـPhaseo:

    - HTTP الخام
    - SDK رسمي واحد
    - Vercel AI SDK
    - SDK الوكلاء
  </Step>
  <Step title="استبدل المتغيرات بين الأقواس المعقوفة">
    املأ قيمًا مثل `[فكرة التطبيق]` و`[إطار العمل]` و`[النموذج]` و`[LANGUAGE]` قبل لصق الموجّه في وكيل البرمجة.
  </Step>
  <Step title="اطلب التحقق، لا الرمز فقط">
    أبقِ أسطر التحقق في الموجّه، فهي تلزم الوكيل بذكر ما نفذه فعليًا وما افترضه وما يتطلب إعدادًا يدويًا.
  </Step>
</Steps>

## كيفية تحسين هذه الموجّهات

- استبدل `[فكرة التطبيق]` بمهمة واحدة محددة للمستخدم، لا بوصف عام للمنتج.
- استبدل `[النموذج]` بمعرّف النموذج الدقيق الذي تريد من الوكيل استخدامه.
- حدد ما إذا كانت المخرجات نصًا حرًا أو JSON صارمًا أو محادثة أو عنصرًا مولدًا واحدًا.
- اذكر إطار واجهة المستخدم ووجهة النشر إن كنت تعرفهما.
- أضف قيدًا أو اثنين مهمين، مثل `مزودو الاتحاد الأوروبي فقط` أو `استخدم البث` أو `أبقِ جميع الأسرار على الخادم`.
