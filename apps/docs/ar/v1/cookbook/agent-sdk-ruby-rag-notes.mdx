شغّل وكيلًا بلغة Ruby يبحث عن ملاحظة داخلية باستخدام أداة محلية ويجيب في فقرة قصيرة واحدة، دون تسليم التنسيق إلى نظام آخر. في النهاية يكون لديك سكربت واحد يلخّص ملاحظتك عن الإعدادات المسبقة.

تُرجع الأداة بيانات عيّنة ثابتة، لذا فالسكربت توضيحي؛ استبدلها ببحث في مخزن الملاحظات الخاص بك. يناسب ذلك تطبيق Ruby يملك البيانات أصلًا ومدخلات أدواته بسيطة وحتمية.

## أنشئه

<Steps>
<Step title="التثبيت">

```bash
gem install phaseo_agent_sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

أو أضف `gem "phaseo_agent_sdk"` إلى ملف `Gemfile`. تثبّت الحزمة `phaseo_sdk` معها، وتتطلب Ruby 3.2 أو أحدث. راجع [تثبيت Ruby Agent SDK](../sdk-reference/agent/installation).

</Step>
<Step title="اكتب الوكيل">

```ruby notes.rb
require "phaseo_agent_sdk"

TOPICS = %w[presets routing guardrails].freeze

lookup_note = PhaseoAgentSdk.define_tool(
  PhaseoAgentSdk::Tool.new(
    id: "lookup-note",
    description: "Look up one internal note by topic.",
    parameters: {
      type: "object",
      properties: { topic: { type: "string", enum: TOPICS } },
      required: ["topic"],
      additionalProperties: false
    },
    # تأتي الوسائط من النموذج: لا يصل إلى execute إلا الموضوعات المعروفة.
    input_schema: lambda do |input|
      raise ArgumentError, "topic must be one of #{TOPICS.join(', ')}" unless input.is_a?(Hash) && TOPICS.include?(input["topic"])

      input
    end,
    execute: lambda do |input, _context|
      {
        topic: input["topic"],
        summary: "Presets centralize routing defaults so app code stays smaller."
      }
    end
  )
)

agent = PhaseoAgentSdk.create_agent(
  id: "notes-agent",
  model: "openai/gpt-6-astra",
  instructions: "Use tools when helpful and answer in one short paragraph.",
  tools: [lookup_note],
  max_steps: 4
)

# يقرأ PHASEO_API_KEY من متغيرات البيئة.
result = agent.run(
  input: "Summarize our note about presets.",
  client: PhaseoAgentSdk.create_gateway_agent_client
)

puts result.run.status
puts result.output
```

</Step>
<Step title="شغّله">

```bash
ruby notes.rb
```

</Step>
</Steps>

## تحقّق من نجاحه

- يطبع السكربت `completed`، ثم فقرة واحدة عن الإعدادات المسبقة.
- في **الإعدادات → الاستخدام → السجلات**، يعرض أول دور للنموذج استدعاء `lookup-note` مع `{"topic": "presets"}`.

## قبل الإنتاج

اجعل الأداة للقراءة فقط، وأبقِ `max_steps` منخفضًا بقدر ما تسمح المهمة (القيمة الافتراضية `12`). إذا كان مخزن ملاحظاتك كبيرًا، فأرجِع المقطع المطابق فقط بدلًا من المستندات كاملة، كي يبقى كل دور للنموذج صغيرًا. لحفظ التشغيلات واستئنافها لاحقًا، راجع [حلقة الوكيل المستدامة](./agent-sdk-durable-loop)؛ يعمل خيار `state:` في Ruby SDK بالطريقة نفسها. يشرح [مرجع Ruby Agent SDK](../sdk-reference/agent/usage) الحالة والموافقة والبث.
