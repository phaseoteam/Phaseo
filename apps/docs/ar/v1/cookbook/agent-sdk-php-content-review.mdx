شغّل وكيلًا بلغة PHP يحمّل مسودة من CMS باستخدام أداة محلية ويقترح تعديلًا تحريريًا، داخل التطبيق أو الواجهة الخلفية للإدارة التي تملك المحتوى أصلًا. في النهاية يكون لديك سكربت واحد يطبع اقتراحًا لعنوان مسودة الصفحة الرئيسية.

تُرجع الأداة بيانات عيّنة ثابتة، لذا فالسكربت توضيحي؛ استبدلها بعملية البحث في CMS لديك. يناسب ذلك تطبيق PHP تكفيه أداة محلية أو اثنتان.

## أنشئه

<Steps>
<Step title="التثبيت">

```bash
composer require phaseo/agent-sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

تثبّت `phaseo/agent-sdk` الحزمة `phaseo/sdk` معها، وتتطلب PHP 8.1 أو أحدث. راجع [تثبيت PHP Agent SDK](../sdk-reference/agent/installation).

</Step>
<Step title="اكتب الوكيل">

```php review.php
<?php
require 'vendor/autoload.php';

use Phaseo\AgentSdk\AgentDefinition;
use Phaseo\AgentSdk\AgentSdk;
use Phaseo\AgentSdk\Tool;

const ALLOWED_SLUGS = ['homepage', 'pricing', 'about'];

$loadDraft = AgentSdk::defineTool(new Tool(
    id: 'load-draft',
    description: 'Load one CMS draft by slug.',
    parameters: [
        'type' => 'object',
        'properties' => [
            'slug' => ['type' => 'string', 'enum' => ALLOWED_SLUGS],
        ],
        'required' => ['slug'],
        'additionalProperties' => false,
    ],
    // تأتي الوسائط من النموذج: لا يصل إلى execute إلا المعرّفات النصية المعروفة.
    inputSchema: static function (mixed $input): array {
        if (!is_array($input) || !in_array($input['slug'] ?? null, ALLOWED_SLUGS, true)) {
            throw new InvalidArgumentException('slug must be one of ' . implode(', ', ALLOWED_SLUGS));
        }
        return $input;
    },
    execute: static fn (array $input, $context) => [
        'slug' => $input['slug'],
        'headline' => 'Phaseo makes gateway routing visible.',
    ],
));

$agent = AgentSdk::createAgent(new AgentDefinition(
    id: 'content-review-agent',
    model: 'openai/gpt-6-astra',
    instructions: 'Use tools when helpful and return concise editorial feedback.',
    tools: [$loadDraft],
    maxSteps: 4,
));

// يقرأ PHASEO_API_KEY من متغيرات البيئة.
$result = $agent->run(
    input: 'Review the homepage draft and suggest one headline improvement.',
    client: AgentSdk::createGatewayAgentClient(),
);

echo $result->run->status . PHP_EOL;
echo $result->output . PHP_EOL;
```

</Step>
<Step title="شغّله">

```bash
php review.php
```

</Step>
</Steps>

## تحقّق من نجاحه

- يطبع السكربت `completed`، ثم اقتراحًا واحدًا للعنوان.
- في **الإعدادات → الاستخدام → السجلات**، يعرض أول دور للنموذج استدعاء `load-draft` مع `{"slug": "homepage"}`.
- من دون `PHASEO_API_KEY`، يرمي `createGatewayAgentClient()` الخطأ `PHASEO_API_KEY is required`.

## قبل الإنتاج

اجعل الأداة للقراءة فقط. إذا أضفت أداة تنشر المحتوى أو تعدّله، فاضبط `requireApproval: true` عليها كي يتوقف التشغيل بانتظار محرّر. للحصول على الملاحظات بصيغة JSON يستطيع CMS تخزينها، اطلب مخططًا وأصلح المخرجات شبه الصالحة باستخدام [إصلاح الاستجابة](./response-healing-for-structured-json). يشرح [مرجع PHP Agent SDK](../sdk-reference/agent/usage) الحالة والموافقة والبث.
