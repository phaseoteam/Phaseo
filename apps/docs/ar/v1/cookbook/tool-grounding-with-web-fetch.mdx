امنح النموذج `phaseo:web_fetch` وعنوان URL تعرفه مسبقًا، وسيجلب Phaseo الصفحة، ويقصّها إلى حد معيّن في الحجم، ويعيد النص قبل أن يستخرج النموذج منه أو يلخصه أو يصنّفه. في النهاية يصبح لديك طلب واحد يقرأ صفحة واحدة ويعيد حقولًا منها، ويمكنك التأكد في السجل من الصفحة التي قرأها فعلًا.

الطلب جاهز للإنتاج مع حد النطاق الموضّح. الصفحات المجلوبة مدخلات غير موثوقة: قد يرى النموذج تعليمات داخلها، لذا تحقّق مما يعيده. استخدم [البحث على الويب](../guides/server-tools/web-search) بدلًا من ذلك عندما لا تعرف عنوان URL.

## أرسل طلبًا مؤسَّسًا على مصدر

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
    "tools": [
      {
        "type": "phaseo:web_fetch",
        "parameters": {
          "allowed_domains": ["phaseo.app"],
          "max_chars": 8000,
          "max_uses": 1
        }
      }
    ],
    "tool_choice": "phaseo:web_fetch"
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-6-astra",
  input:
    "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
  tools: [
    {
      type: "phaseo:web_fetch",
      parameters: {
        allowed_domains: ["phaseo.app"],
        max_chars: 8000,
        max_uses: 1,
      },
    },
  ],
  tool_choice: "phaseo:web_fetch",
});

console.log(JSON.stringify(response.output, null, 2));
console.log(response.usage?.server_tool_use);
```
</CodeGroup>

اجعل المطالبة صريحة بشأن المهمة بعد الجلب: استخرج هذه الحقول، أو لخّص هذا القسم، أو صنّف المستند، أو تحقّق من ادعاء واحد.

| المعامل | الافتراضي | الاستخدام |
| --- | --- | --- |
| `allowed_domains` | لا شيء | الجلب من هذه النطاقات فقط. يمكن للنموذج تضييق القائمة، لكن لا يمكنه توسيعها أبدًا. |
| `max_chars` | `12000` | عدد أحرف نص الصفحة المُعادة، حتى `100000`. أقل للعنوان أو الملخص، وأعلى لاستخراج الحقول. |
| `max_uses` | `10` | عدد استدعاءات الجلب لكل طلب، حتى `100`. |

يسرد [دليل جلب الويب](../guides/server-tools/web-fetch#parameters) بقية المعاملات، بما فيها `blocked_domains` والمحرّكات.

## تحقّق مما قرأه

تذكر نتيجة الأداة، التي يعرضها سجل الطلب، الصفحة التي أسّس النموذج إجابته عليها بالضبط:

```json
{
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "truncated": false,
  "returned_chars": 8000
}
```

تحقّق من `final_url` بعد عمليات إعادة التوجيه، ومن `truncated` قبل أن تثق بأن النموذج رأى الصفحة كاملة. يضيف كل جلب 1 إلى `usage.server_tool_use.web_fetch_requests`.

## اعرف الحدود

مع المحرّك الافتراضي `direct`، يجلب Phaseo الصفحة بنفسه ويختزل HTML إلى نص عادي. يرفض `localhost` والعناوين الخاصة، ويتبع 5 عمليات إعادة توجيه على الأكثر، ويتحقق من كل إعادة توجيه مقابل قوائم النطاقات لديك؛ وأي إعادة توجيه خارجها تعيد `redirect_blocked_by_domain_policy` إلى النموذج.

يناسب جلب الويب صفحات HTML والنص العادي وردود JSON أو XML الصغيرة. وهو ليس مخصصًا للملفات الثنائية، أو الزحف إلى صفحات كثيرة، أو التحقق من طريقة عرض صفحة باستخدام JavaScript؛ استخدم سير عمل عبر متصفح لذلك. إذا كانت الصفحة كبيرة جدًا، فضيّق مهمة الاستخراج بدلًا من رفع `max_chars`.

ابدأ بإعداد مسبق واحد أو نقطة نهاية واحدة، واقرأ تفاصيل الجلب والقص في السجلات، وشدّد المطالبة إذا كان النص المجلوب واسعًا جدًا قبل أن توسّع الاستخدام.
