أنشئ وكيلًا بلغة TypeScript يبحث على الويب عبر Phaseo قبل أن يجيب، ويُرجع ملخصًا بحثيًا بصيغة JSON صارمة مع مصادره. في النهاية يكون لديك سكربت واحد يطبع كائن `{ topic, summary, sources }` تم التحقق منه لأي موضوع تعطيه إياه.

السكربت جاهز للإنتاج للبحث في طلب واحد. نتائج البحث محتوى ويب غير موثوق: يمنع فحص المخطط أدناه المخرجات المشوّهة، لكن راجع المصادر قبل أن تتصرف بناءً عليها. توجد نسخة جاهزة في `packages/sdk/agent-sdk-ts/examples/research-brief-agent.ts`.

<Step title="اكتب الوكيل">

```ts research-agent.ts
import { z } from "zod";
import { createAgent, createGatewayAgentClient } from "@phaseo/agent-sdk";

// صغير بما يكفي لقراءته في سطر سجل واحد.
const ResearchBrief = z
  .object({
    topic: z.string(),
    summary: z.string().min(1),
    sources: z.array(z.object({ title: z.string(), url: z.string().url() }).strict()).min(1),
  })
  .strict();
type ResearchBrief = z.infer<typeof ResearchBrief>;

const researchBriefAgent = createAgent<string, ResearchBrief>({
  id: "research-brief-agent",
  model: "openai/gpt-6-astra",
  instructions:
    "Research the user's topic with web search and return a concise JSON brief with cited sources.",
  maxSteps: 4,
  parseOutput: (text) => JSON.parse(text),
  outputSchema: ResearchBrief,
});

const client = createGatewayAgentClient({
  clientOptions: { apiKey: process.env.PHASEO_API_KEY! },
  // مخطط JSON Schema الذي يطلبه الـ Gateway من النموذج.
  responseFormat: {
    type: "json_schema",
    name: "research_brief",
    schema: {
      type: "object",
      properties: {
        topic: { type: "string" },
        summary: { type: "string" },
        sources: {
          type: "array",
          items: {
            type: "object",
            properties: { title: { type: "string" }, url: { type: "string" } },
            required: ["title", "url"],
            additionalProperties: false,
          },
          minItems: 1,
        },
      },
      required: ["topic", "summary", "sources"],
      additionalProperties: false,
    },
  },
  // أصلح JSON شبه الصالح.
  plugins: [{ id: "response-healing" }],
  // ينفّذ Phaseo البحث؛ ويكتب النموذج الاستعلامات.
  gatewayTools: [{ type: "phaseo:web_search", parameters: { max_results: 5 } }],
  // ابحث دائمًا قبل الإجابة.
  toolChoice: "phaseo:web_search",
  webSearchOptions: { search_context_size: "high" },
});

const result = await researchBriefAgent.run({
  input: "Summarize the latest browser automation support patterns for coding agents.",
  client,
  onEvent(event) {
    console.log(event.type, event.runId);
  },
});

console.log(result.output);
```

| خيار العميل | وظيفته |
| --- | --- |
| `responseFormat` | يُبقي مخطط المخرجات صريحًا |
| `plugins` | [إصلاح الاستجابة](./response-healing-for-structured-json) لـ JSON شبه الصالح |
| `gatewayTools` | يضيف `phaseo:web_search`؛ ويسرد [دليل البحث على الويب](../guides/server-tools/web-search) معاملاته |
| `toolChoice` | يفرض البحث في سير عمل يجب أن يستند دائمًا إلى مصادر |
| `webSearchOptions` | إعدادات البحث للمحركات التي تحدد حجم نتائجها |

## تحقّق من نجاحه

يطبع السكربت ملخصًا يتضمن رابط مصدر واحدًا على الأقل. ثم افتح الطلب في **الإعدادات → الاستخدام → السجلات** وتحقّق مما يلي:

- يعرض **قابلية رصد البحث على الويب** عمليات البحث المُدارة والنتائج والاستشهادات.
- يعرض سجل الإضافات `response-healing` بالحالة `applied` فقط عندما احتاج JSON إلى إصلاح.
- طابقت الاستجابة المخطط؛ ولو لم تطابقه لفشل التشغيل بخطأ `AgentSchemaValidationError`.

تشرح صفحة [تصحيح أخطاء البحث على الويب](./web-search-debugging) الحالات التي لم يُنفَّذ فيها أي بحث.

## متى تستخدم شيئًا آخر

يناسب هذا النمط البحث في طلب واحد حيث ينبغي أن يستند النموذج إلى مصادر بنفسه ويريد المستدعون JSON مكتوب الأنواع. استخدم [`phaseo:web_fetch`](./tool-grounding-with-web-fetch) عندما تعرف الروابط مسبقًا، و[وكيلًا بأدوات محلية](./agent-sdk-durable-loop) عندما يحتاج العمل إلى بياناتك أكثر من الويب، ومخرجات نصية عادية عندما يكون العقد مرنًا بما يكفي لأن يضيف المخطط عملًا أكثر مما يوفّر.
