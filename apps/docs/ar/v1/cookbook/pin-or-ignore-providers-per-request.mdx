أضف كائن `provider` إلى طلب واحد لتغيير المزوّدين الذين يخدمونه، دون المساس بالإعدادات الافتراضية لمساحة العمل أو الإعدادات المسبقة. في النهاية يمكنك تفضيل ترتيب معيّن، أو إبقاء الطلب ضمن قائمة سماح، أو تخطي مزوّد واحد، ورؤية المزوّد الذي أجاب في الرد.

أشكال الطلبات هذه جاهزة للإنتاج. معرّفات المزوّدين أمثلة حقيقية؛ راجع صفحة النموذج لمعرفة المزوّدين الذين يخدمون نموذجك.

| الحقل | ما يفعله | مثال |
| --- | --- | --- |
| `order` | يجرّب هؤلاء المزوّدين أولًا، ثم بقية المجموعة المؤهلة | `["anthropic-us", "anthropic"]` |
| `only` | يُبقي الطلب ضمن هذه القائمة | `["openai", "openai-eu"]` |
| `ignore` | يستبعد هؤلاء المزوّدين لهذا الطلب | `["novita"]` |
| `sort` | يرتّب المتبقي بحسب `price` أو `latency` أو `throughput` | `"price"` |

لاستخدام مزوّد واحد بالضبط وإيقاف الرجوع إلى مزوّدين آخرين، ضعه قبل معرّف النموذج بدلًا من ذلك: راجع [ثبّت مزوّدًا واحدًا](../guides/routing-and-fallbacks#pin-one-provider).

## جرّب المزوّدين بترتيب محدد

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "input": "Write a concise launch summary.",
    "provider": {
      "order": ["anthropic-us", "anthropic"]
    },
    "meta": true
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "anthropic/claude-sonnet-5.5",
  input: "Write a concise launch summary.",
  provider: {
    order: ["anthropic-us", "anthropic"],
  },
  meta: true,
});

console.log(response.meta?.routing); // { selected_provider: "anthropic-us", ... }
```

```python Python
import os

from phaseo import Phaseo

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])

response = client.generate_response(
    {
        "model": "anthropic/claude-sonnet-5.5",
        "input": "Write a concise launch summary.",
        "provider": {
            "order": ["anthropic-us", "anthropic"],
        },
        "meta": True,
    }
)

print(response["meta"]["routing"]["selected_provider"])
```
</CodeGroup>

يضيف `meta: true` الحقل `meta.routing.selected_provider` إلى الرد، لتتمكن من التحقق من النتيجة دون فتح السجلات.

## أبقِ الطلب ضمن قائمة سماح

أرسل `only`، واختياريًا `sort` للترتيب داخل تلك القائمة:

```json
{
  "model": "openai/gpt-5.6-luna",
  "input": "Extract the action items.",
  "provider": {
    "only": ["openai", "openai-eu"],
    "sort": "price"
  }
}
```

إذا لم يخدم أي من المزوّدين المدرجين النموذج، يفشل الطلب بدلًا من الخروج عن القائمة.

## تخطَّ مزوّدًا واحدًا

أرسل `ignore` عندما يكون أداء مزوّد متراجعًا، أو أثناء اختبارك لمسار آخر:

```json
{
  "model": "meta/llama-4-maverick",
  "input": "Summarize the transcript.",
  "provider": {
    "ignore": ["novita"]
  }
}
```

## اجمع بينها

استخدم `only` لتحديد المجموعة، و`order` للتفضيل داخلها، و`sort` لترتيب البقية. هذا المثال يُبقي الطلب على Google Vertex، ويجرّب منطقة الاتحاد الأوروبي أولًا، ثم يرتّب بحسب زمن الاستجابة:

```json
{
  "model": "anthropic/claude-sonnet-5.5",
  "input": "Summarize the incident in one sentence.",
  "provider": {
    "only": ["google-vertex", "google-vertex-eu"],
    "order": ["google-vertex-eu"],
    "sort": "latency"
  }
}
```

## تحقّق من وجهة الطلب

افتح الطلب في **الإعدادات → الاستخدام → السجلات** ووسّع **قابلية رصد التوجيه**. يسرد هذا القسم المزوّدين الذين استُبعدوا قبل الترتيب وسبب ذلك، والمرشحين المرتّبين مع درجاتهم؛ ويشرح [فسّر قرار توجيه](../guides/routing-and-fallbacks#explain-a-routing-decision) كل حقل.

استخدم القواعد على مستوى الطلب للتجاوزات المؤقتة، أو الخاصة بمستدعٍ واحد، أو المرتبطة بتدفق مستخدم واحد. وبمجرد أن تظهر القواعد نفسها في عدة خدمات، انقلها إلى [إعداد مسبق](../guides/presets)، حيث تحدّ أيضًا من المزوّدين الذين يمكن للاحتياط استخدامهم. لمقارنة الترتيبات، راجع [رتّب المزوّدين](./sort-providers-by-price-latency-or-throughput).
