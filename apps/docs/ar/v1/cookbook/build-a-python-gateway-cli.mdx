## مشروع نموذجي

- GitHub: [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart)
- المسار المحلي في المستودع: `examples/gateway-python-quickstart`

## وظائف هذا التطبيق

- يدعم مسارات التحكم مثل:
  - `GET /v1/health`
  - `GET /v1/models`
  - `GET /v1/providers`
- يدعم مسارات التوليد مثل:
  - `POST /v1/responses`
  - `POST /v1/chat/completions`
  - `POST /v1/embeddings`
  - وعدة نقاط نهاية إضافية

## فائدة هذا المثال

يوفر لك:

- مرجعًا يعتمد على Python دون اعتماديات خارجية
- حمولات طلبات ومعالجة استجابات واضحة
- نمطًا عمليًا للعوامل والنصوص البرمجية والأدوات الداخلية

## المتطلبات الأساسية

- Python 3
- مفتاح API من Phaseo

## تشغيل المثال

```bash
cd examples/gateway-python-quickstart
cp .env.example .env.local
```

عيّن:

- `PHASEO_API_KEY`

ثم جرّب:

```bash
python quickstart.py smoke
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

## التحقق من عملك

- يؤكد وضع الاختبار السريع إمكانية الوصول إلى API.
- يطبع أمر Responses القيمة `integration_ok`.
- يعرض `--help` الأوامر المتاحة دون إرسال طلب.
- تظهر أخطاء المصادقة وAPI بوضوح في الطرفية.

## ما ينبغي مراجعته في الشيفرة

- طريقة تحميل متغيرات البيئة
- كيفية توزيع الأوامر في واجهة سطر الأوامر
- طريقة إنشاء حمولات الطلبات المختلفة
- كيفية معالجة مسارات الفيديو والموسيقى غير المتزامنة بصورة منفصلة عن مسارات النص ذات الاستجابة الواحدة

## تكييف المثال لاحتياجاتك

- احذف نقاط النهاية التي لا تحتاج إليها خدمتك
- استخدم دالة مساعدة مشتركة للطلبات بدل تكرار الترويسات في كل موضع
- انتقل لاحقًا إلى Python SDK إذا احتجت إلى عميل بمستوى تجريد أعلى
