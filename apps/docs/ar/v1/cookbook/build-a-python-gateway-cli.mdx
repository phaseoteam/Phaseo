شغّل واجهة سطر أوامر بلغة Python تعتمد على المكتبة القياسية فقط وتستدعي نقاط نهاية Phaseo أمرًا تلو الآخر. في النهاية يعمل لديك `python quickstart.py <command>` لكلٍّ من الصحة والنماذج وResponses وChat Completions، إضافةً إلى أوامر للتضمينات والإشراف والصور وOCR والفيديو والموسيقى يمكنك نسخها إلى عامل أو خدمة خلفية.

واجهة سطر الأوامر توضيحية: هي مرجع لأشكال الطلبات، وليست أداة مُحزَّمة. عدد من معرّفات النماذج الافتراضية لأوامر الوسائط لم يعد متاحًا، لذا مرّر `--model` لهذه الأوامر (راجع [اختر نماذج لأوامر الوسائط](#pick-models-for-the-media-commands)).

لتجعل وكيل برمجة ينشئ واجهة سطر أوامر مشابهة من الصفر، الصق هذه المطالبة:

## ما الذي تفعله واجهة سطر الأوامر

العينة هي [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart): ملف واحد هو `quickstart.py`، يستخدم فقط `urllib` و`json` و`argparse`.

| الأمر | الاستدعاءات |
| --- | --- |
| `smoke` | `GET /v1/health` و`GET /v1/models` و`GET /v1/providers` وطلب `POST /v1/responses` واحد |
| `health`، `models`، `providers` | مسار `GET` المطابق |
| `responses --prompt` | `POST /v1/responses` |
| `chat --prompt` | `POST /v1/chat/completions` |
| `embeddings --text` | `POST /v1/embeddings` |
| `moderations --text` | `POST /v1/moderations` |
| `image --prompt` | `POST /v1/images/generations` |
| `ocr --image-url` | `POST /v1/ocr` |
| `video-create`، `video-status`، `video-cancel`، `video-download-url` | `POST /v1/videos`، `GET /v1/videos/{video_id}`، `POST /v1/videos/{video_id}/cancel`، `POST /v1/videos/{video_id}/download_url` |
| `music-create`، `music-status` | `POST /v1/music/generate`، `GET /v1/music/generate/{music_id}` |

يُعاد كل طلب مرتين عند `429` و`5xx` وأخطاء الشبكة، بانتظار ثانية واحدة ثم ثانيتين، وتنتهي مهلته بعد 45 ثانية. يخرج كل أمر بالرمز `1` عندما لا يكون الاستدعاء `2xx`، لذا يمكنك استخدامه في السكربتات.

## شغّلها

تحتاج إلى Python 3 ومفتاح Phaseo API.

<Steps>
<Step title="أنشئ .env.local">

يقرأ السكربت `.env.local` من المجلد الذي تشغّله منه. لا تحتوي العينة على `.env.example`، لذا أنشئ الملف:

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# Optional
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My Python CLI
PHASEO_HTTP_REFERER=https://myapp.example
```

المتغيرات المعيّنة مسبقًا في الطرفية لها الأولوية على الملف. بدون `PHASEO_MODEL` تستخدم الأوامر النصية `openai/gpt-5.6-sol`.

</Step>
<Step title="شغّل الفحص الأولي">

```bash
cd examples/gateway-python-quickstart
python quickstart.py smoke
```

يرسل `smoke` أيضًا طلب Responses قصيرًا واحدًا، لذا يستهلك بعض الأرصدة.

</Step>
<Step title="أرسل طلبًا واحدًا">

```bash
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

</Step>
</Steps>

## تحقّق من نجاحها

- يطبع `smoke` القيمة `HTTP 200` لكل كتلة ويخرج بالرمز `0`.
- يحتوي ناتج الأمر `responses` على `integration_ok`.
- يعرض `--help` الأوامر دون إرسال أي طلب.
- بدون مفتاح، يطبع السكربت `Missing PHASEO_API_KEY` ويخرج بالرمز `1`.
- تظهر الطلبات في **الإعدادات → الاستخدام → السجلات**.

## اختر نماذج لأوامر الوسائط

هذه القيم الافتراضية في `quickstart.py` متقاعدة أو ليس لها مزوّد نشط. مرّر نموذجًا حاليًا باستخدام `--model`، واختره من [صفحة النماذج](https://phaseo.app/models) أو من `python quickstart.py models`:

| الأمر | القيمة الافتراضية في العينة | الحالة |
| --- | --- | --- |
| `moderations` | `openai/omni-moderation-latest` | ليس معرّفًا في الكتالوج؛ استخدم `openai/omni-moderation` |
| `ocr` | `mistral/mistral-ocr` | متقاعد؛ جرّب `mistral/ocr-4.1` |
| `video-create` | `openai/sora-2` | متقاعد |
| `music-create` | `suno/suno-v4` | لا يوجد مزوّد نشط |

القيمتان الافتراضيتان لـ `embeddings` (`google/gemini-embedding-2`) و`image` (`openai/gpt-image-2`) متاحتان. مهام الفيديو والموسيقى غير متزامنة: احفظ المعرّف المُعاد واستعلم بأمر الحالة؛ يشرح [الفيديو غير المتزامن والدفعات](../guides/async-video-and-batch) دورة حياة المهمة.

اختصر الملف ليقتصر على الأوامر التي تحتاجها خدمتك، واحتفظ بالدالة المساعدة المشتركة الوحيدة `gateway_request()`، وانتقل إلى [Python SDK](../sdk-reference/client/overview) عندما تريد طلبات ذات أنواع محددة.
