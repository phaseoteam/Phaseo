## المشروع النموذجي

- GitHub: [examples/gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart)
- مسار المشروع داخل المستودع: `examples/gateway-node-quickstart`

## ما يفعله التطبيق

- يستدعي `GET /v1/health`
- يستدعي `GET /v1/models`
- يختبر مسارات الإنشاء مثل `POST /v1/responses`
- يوفر مرجعًا لاستخدام HTTP مباشر في الاختبارات الأولية والسكربتات وفحوصات الواجهة الخلفية

## متى يكون هذا المثال مناسبًا

ابدأ من هنا عندما:

- تريد تصحيح استدعاءات API مباشرةً
- لا تريد طبقات تجريد SDK بعد
- تبني سكربتًا أو عاملًا أو CLI بدلًا من واجهة ويب

## المتطلبات المسبقة

- Node.js مع دعم `fetch` support
- مفتاح Phaseo API

## تشغيل المثال

```bash
cd examples/gateway-node-quickstart
cp .env.example .env.local
```

عيّن:

- `PHASEO_API_KEY`

ثم شغّل أحد الأمرين:

```bash
npm run smoke
```

أو:

```bash
npm run start
```

## تحقق من النتيجة

- يؤكد وضع الاختبار الأولي إمكانية الوصول إلى API.
- يعيد اكتشاف النماذج نموذجًا واحدًا على الأقل.
- تطبع العملية الكاملة رد إنشاء ناجحًا واحدًا.
- تعرض أخطاء المصادقة والردود غير 200 أخطاء واضحة في الطرفية.

## ما الذي يجب مراجعته في الشيفرة

- كيف يحمّل السكربت `.env.local`
- كيفية إضافة ترويسة التفويض
- كيفية إنشاء كل طلب بوضوح
- كيفية إظهار الردود غير 200 بدلًا من تجاهلها

## كيفية تخصيص المثال

- اختصر السكربت ليقتصر على المسارات التي تحتاجها خدمتك
- انقل شيفرة الطلبات المشتركة إلى helper إذا كانت عدة سكربتات ستستخدمها
- انتقل لاحقًا إلى TypeScript SDK إذا تكرر مسار HTTP المباشر
