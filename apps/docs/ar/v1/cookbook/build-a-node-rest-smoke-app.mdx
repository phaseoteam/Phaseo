شغّل سكربت Node.js بلا اعتماديات يستدعي Phaseo باستخدام `fetch` العادي، لترى كل طلب وكل رد. في النهاية يصبح لديك اختبار أولي تشغّله قبل النشر: يتحقق من إمكانية الوصول إلى API، ويعرض النماذج، ويرسل طلبًا واحدًا إلى كلٍّ من Responses وChat Completions وEmbeddings.

السكربت توضيحي: يطبع حالة HTTP لكل استدعاء لكنه يخرج دائمًا بالرمز `0`، لذا أضف فحص رمز الخروج الموضّح في [استخدمه كفحص قبل النشر](#use-it-as-a-deploy-check) قبل أن تعتمد عليه في CI.

لتجعل وكيل برمجة ينشئ السكربت نفسه من الصفر، الصق هذه المطالبة:

## ما الذي يستدعيه السكربت

العينة هي [examples/gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart): ملف واحد هو `index.mjs`، بلا اعتماديات.

| الوضع | الاستدعاءات | يستهلك الأرصدة |
| --- | --- | --- |
| `npm run smoke` | `GET /v1/health`، `GET /v1/models` | لا |
| `npm run start` | الاستدعاءان السابقان، ثم `POST /v1/responses` و`POST /v1/chat/completions` و`POST /v1/embeddings` | نعم |

ترسل الاستدعاءات النصية `Return exactly: integration_ok` إلى `PHASEO_MODEL` (الافتراضي `openai/gpt-5.6-sol`). ويستخدم استدعاء التضمينات `google/gemini-embedding-2`.

## شغّله

تحتاج إلى Node.js 18 أو أحدث، من أجل `fetch` المدمج، وإلى مفتاح Phaseo API.

<Steps>
<Step title="أنشئ .env.local">

يحمّل السكربت `.env.local` من المجلد الذي تشغّله منه، دون أي حزمة. لا تحتوي العينة على `.env.example`، لذا أنشئ الملف:

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# Optional
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My smoke test
PHASEO_HTTP_REFERER=https://myapp.example
```

المتغيرات المعيّنة مسبقًا في الطرفية لها الأولوية على الملف.

</Step>
<Step title="شغّل وضع الاختبار الأولي">

```bash
cd examples/gateway-node-quickstart
npm run smoke
```

</Step>
<Step title="شغّل الوضع الكامل">

```bash
npm run start
```

</Step>
</Steps>

## تحقّق من نجاحه

يطبع كل استدعاء كتلة مثل هذه:

```text
=== Health ===
HTTP 200
{ ... }
```

- تعرض `Health` و`Models` القيمة `HTTP 200`، وتعرض `Models` نموذجًا واحدًا على الأقل.
- في التشغيل الكامل، تحتوي كتلتا Responses وChat Completions على `integration_ok`.
- عند استخدام مفتاح خاطئ، تعرض كتل الإنشاء `HTTP 401` ونص الخطأ بدلًا من إخفائه.
- تظهر الطلبات في **الإعدادات → الاستخدام → السجلات**.

## استخدمه كفحص قبل النشر

تعيد الدالة `request()` القيمة `{ status, ok, payload }`، لكن لا شيء يتحقق من `ok`. أضف سطرًا واحدًا في بداية `print()` ليخرج السكربت بالرمز `1` عند فشل أي استدعاء:

```js index.mjs
function print(title, result) {
  if (!result.ok) process.exitCode = 1;
  console.log(`\n=== ${title} ===`);
  // ...rest unchanged
}
```

اختصر السكربت ليقتصر على المسارات التي تستخدمها خدمتك، وانتقل إلى [TypeScript SDK](../sdk-reference/client/overview) عندما تفضّل ألا تبني محتوى الطلبات يدويًا.
