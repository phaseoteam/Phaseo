شغّل وكيلًا بلغة Go يجيب عن سؤال تشغيلي باستدعاء أداة حالة محلية، داخل خدمة واحدة ومن دون نظام مهام. في النهاية يكون لديك ملف `main.go` واحد يطبع إجابة قصيرة عن زمن استجابة المزوّدين الحالي.

تُرجع الأداة بيانات عيّنة ثابتة، لذا فالبرنامج توضيحي؛ استبدلها باستدعاء الحالة أو المقاييس الخاص بك. يناسب ذلك خدمة Go يتوفر سياقها مسبقًا على شكل استدعاءات محلية أو داخلية.

## أنشئه

<Steps>
<Step title="التثبيت">

```bash
go mod init ops-runbook
go get github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go@latest
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

تأتي الوحدة الأساسية `sdk-go/v4` معها. راجع [تثبيت Go Agent SDK](../sdk-reference/agent/installation) لمعرفة المتطلبات.

</Step>
<Step title="اكتب الوكيل">

```go main.go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  statusTool := phaseoagent.DefineTool(phaseoagent.Tool{
    ID:          "read-status",
    Description: "Read the current service status page summary.",
    Parameters: map[string]any{
      "type":                 "object",
      "properties":           map[string]any{},
      "additionalProperties": false,
    },
    Execute: func(input any, ctx phaseoagent.RuntimeContext) (any, error) {
      return map[string]any{
        "status":  "degraded",
        "summary": "Latency is elevated on one provider route.",
      }, nil
    },
  })

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "ops-runbook-agent",
    Model:        "openai/gpt-6-astra",
    Instructions: "Use tools when helpful and answer briefly.",
    Tools:        []phaseoagent.Tool{statusTool},
    MaxSteps:     4,
  })

  // يقرأ PHASEO_API_KEY (وPHASEO_BASE_URL إن كان مضبوطًا).
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "What is happening with provider latency right now?",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Run.Status)
  fmt.Println(result.Output)
}
```

</Step>
<Step title="شغّله">

```bash
go run .
```

</Step>
</Steps>

## تحقّق من نجاحه

- يطبع البرنامج `completed`، ثم إجابة تذكر تدهور زمن الاستجابة على مسار أحد المزوّدين.
- في **الإعدادات → الاستخدام → السجلات**، يعرض أول دور للنموذج استدعاءً للأداة `read-status`.
- من دون `PHASEO_API_KEY`، تُرجع `CreateGatewayAgentClient` الخطأ `PHASEO_API_KEY is required`.

## قبل الإنتاج

القيمة الافتراضية لـ `MaxSteps` في Go SDK هي `8`؛ اضبطها على أصغر عدد يُنهي المهمة. عندما تأخذ أداة وسائط، أعطها مخطط `Parameters` ومُتحقِّق `InputSchema` يُرجع خطأً لأي شيء غير متوقع، لأن الوسائط تأتي من النموذج. اجعل الأدوات للقراءة فقط ما لم يوافق شخص على الاستدعاء (`RequireApproval: true`). يشرح [مرجع Go Agent SDK](../sdk-reference/agent/usage) الموافقات والحالة والبث، وتوضح [التأريض بجلب الويب](./tool-grounding-with-web-fetch) كيفية قراءة صفحة معروفة بدلًا من أداة محلية.
