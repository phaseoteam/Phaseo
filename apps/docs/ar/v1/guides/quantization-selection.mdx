اتبع سير العمل هذا لاختيار متغيرات التكميم بأمان.

لفرض الاختيار في Phaseo Gateway، أرسل عامل تصفية توجيه متوافقًا مع OpenRouter:

```json
{
  "model": "meta/llama-3.3-70b-instruct",
  "messages": [{ "role": "user", "content": "Hello" }],
  "provider": {
    "quantizations": ["FP8"]
  }
}
```

ينطبق عامل التصفية على عروض النماذج لدى كل مزوّد، وليس على أسماء المزوّدين وحدها. ولا تتأثر المطابقة بحالة الأحرف، كما تدعم الأسماء البديلة الواضحة مثل `float8` لـ `FP8` و`bfloat16` لـ `BF16`. لا يُقبل أي عرض يفتقر إلى بيانات التكميم الوصفية. إذا لم يطابق أي عرض مؤهل، يفشل الطلب مع تشخيصات التوجيه؛ ولا ينتقل Phaseo إلى تكميم غير متحقق منه. ويُقبل أيضًا الشكل المكافئ `routing.quantizations`.

## الخطوة 1: حدّد معايير النجاح

قبل اختيار صيغة التكميم:

- حدّد عتبات الجودة (دقة المهمة ومعدلات النجاح وصلاحية المخرجات المنظّمة).
- حدّد أهداف زمن الاستجابة والتكلفة.
- حدّد أنماط الإخفاق غير المقبولة.

## الخطوة 2: اختر خط أساس عالي الجودة

ابدأ بخط أساس أعلى دقة (غالبًا `BF16` أو `FP16`) وقِس:

- جودة المخرجات
- زمن الاستجابة الوسيط وذي الذيل
- نمط استهلاك الرموز والتكلفة

سيكون هذا مرجع المقارنة.

## الخطوة 3: اخفض الدقة تدريجيًا

قيّم تدريجيًا الصيغ الأقل دقة:

1. `FP8` or `INT8`
2. استخدم `FP4` أو `INT4` فقط عند الحاجة إلى خفض التكلفة أو زيادة معدل النقل.

لا تنتقل مباشرةً إلى أصغر متغير ما لم تتوفر لديك أدلة قوية على ملاءمته لحجم عملك.

## الخطوة 4: قيّم أحمال العمل الفعلية

استخدم مطالبات مشابهة لبيئة الإنتاج:

- مطالبات طويلة
- استدلال متعدد الخطوات
- استدعاء الأدوات
- الحالات الطرفية في تذاكر الدعم

## الخطوة 5: حدّد الاختيار لكل نقطة نهاية أو حالة استخدام

ليس من الضروري أن تناسب صيغة تكميم واحدة جميع الاستخدامات.

أمثلة:

- دعم العملاء واتخاذ القرارات الحساسة: دقة أعلى.
- التصنيف أو التلخيص بكميات كبيرة: قد تكون الدقة الأقل مقبولة.

## نقاط بداية مقترحة

| نوع عبء العمل | صيغة التكميم الموصى بها للبدء |
| --- | --- |
| استدلال يتطلب جودة عالية | `BF16` / `FP16` |
| توازن التكلفة والجودة | `FP8` / `INT8` |
| معدل نقل مرتفع مع حساسية للتكلفة | `INT4` / `FP4` (بعد التحقق) |

## سياسة النشر

- هيّئ نموذجًا أو صيغة تكميم احتياطية.
- راقب تراجع الجودة بعد الإطلاق.
- أعد الاختبار عند تغيّر بيئة تشغيل المزوّد أو إصدار النموذج.
