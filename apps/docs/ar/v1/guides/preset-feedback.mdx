أرسل كل تقييم من المستخدم إلى `POST /v1/feedback` مع معرّف الطلب و[الإعداد المسبق](./presets.mdx) الذي أجاب، ثم قارن الإعدادات المسبقة بمدى تكرار تقييم إجاباتها تقييمًا جيدًا، لا بزمن الاستجابة والتكلفة فقط.

<Note>
ميزة ملاحظات الإعدادات المسبقة في مرحلة ألفا، وقد تتغير واجهة API ولوحة التحكم. استخدم زر **الملاحظات** في [صفحة ملاحظات الإعداد المسبق](https://phaseo.app/settings/presets/experiments) لإخبارنا بما يجعلها أكثر فائدة.
</Note>

## سجّل تقييمًا

تحتاج إلى مفتاح API بصلاحية `feedback:write`، ومعرّف الطلب الذي أعاده Phaseo، ومعرّف UUID للإعداد المسبق. معرّف الإعداد المسبق هو ما يُدخل الحدث في مقارنات الإعدادات المسبقة وتحليل المجموعات.

```bash cURL
curl https://api.phaseo.app/v1/feedback \
  -X POST \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "requestId": "gen_01K...",
    "presetId": "8f54b2d9-9ba3-4ced-8a7f-9bb70a44dbea",
    "rating": "thumbs_up",
    "score": 1,
    "comment": "The answer resolved the customer question.",
    "metadataDimensions": {
      "plan": "pro",
      "surface": "support_chat"
    }
  }'
```

يجب أن يستهدف حدث الملاحظات طلبًا أو جلسة أو إعدادًا مسبقًا أو تشغيل اختبار واحدًا على الأقل. الحقل `score` اختياري ويجب أن يكون بين `0` و`1`.

ضع القيم منخفضة التنوع مثل الخطة أو النشر أو اللغة أو واجهة التطبيق في `metadataDimensions` حتى تتمكن من التصفية بها. وضع السياق الاعتباطي أو عالي التنوع في `metadata` بدلًا من ذلك.

## اختر تقييمًا

| الإشارة | `rating` |
| --- | --- |
| تفاعل بسيط من المستخدم | `thumbs_up`، `thumbs_down` |
| إجابة خضعت للتقييم | `correct`، `partly_correct`، `incorrect` |
| مشكلة تشغيلية | `bad_format`، `too_slow`، `too_expensive` |
| نتيجة متعلقة بالسلامة | `unsafe`، `refused_incorrectly` |
| أي شيء آخر | `not_helpful`، `other` |

فضّل تقييمًا صريحًا على درجة رقمية وحدها: تُبنى مقارنات الإعدادات المسبقة على التقييمات، وتُعرض الدرجات كتفاصيل داعمة.

## قارن الإعدادات المسبقة

افتح [الإعدادات ← الإعدادات المسبقة ← الملاحظات](https://phaseo.app/settings/presets/experiments) من أجل:

- مقارنة نسب التقييمات الإيجابية والجزئية والسلبية
- اختيار إعداد مسبق أساسي للمقارنة
- التصفية حسب التاريخ والتقييم وأبعاد البيانات الوصفية
- فحص الطلب والجلسة والتعليقات والوسوم وراء كل حدث

تحلّل لوحة التحكم 10,000 صف ملاحظات مطابق على الأكثر، وهي الأحدث ضمن النافذة الزمنية المحددة.

## اقرأ الملاحظات عبر API

تتطلب القراءة صلاحية `feedback:read`. تقتصر النتائج على مساحة العمل الموثَّقة والإعدادات المسبقة التي يستطيع المستدعي رؤيتها.

اسرد الأحداث الأخيرة:

```bash
curl "https://api.phaseo.app/v1/feedback?preset_id=PRESET_UUID&limit=100" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

احصل على ملخص محسوب على الخادم:

```bash
curl "https://api.phaseo.app/v1/feedback/summary?group_by=preset&since=2026-08-01T00:00:00Z" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

تتوفر واجهات API لتشغيلات الاختبار وأحداث النتائج المخصصة، لكن طرق عرضها في لوحة التحكم ما زالت تتغير. لطرح تغيير على إعداد مسبق تدريجيًا، راجع [طرح الإعدادات المسبقة وتصحيح التوجيه](../cookbook/preset-rollout-and-routing-debug).
