يتيح Preset Feedback ربط تقييمات تطبيقك بالإعداد المسبق الذي أنشأ الرد. استخدمه لمقارنة تغييرات الطلبات والتوجيه بإشارات المستخدمين الفعلية بدل الاعتماد على زمن الاستجابة والتكلفة فقط.

<Note>
ما زالت Preset Feedback في مرحلة ألفا. نعمل على تحسين واجهة API ولوحة التحكم استنادًا إلى كيفية تقييم الفرق لردود الذكاء الاصطناعي في الإنتاج. استخدم زر **Feedback** في [صفحة Preset Feedback](https://phaseo.app/settings/presets/experiments) لإخبارنا بما يجعلها أكثر فائدة.
</Note>

## قبل أن تبدأ

تحتاج إلى:

- مفتاح API لـ Phaseo بصلاحية `feedback:write`
- معرّف الطلب الذي يعيده Phaseo
- معرّف UUID للإعداد المسبق الذي تريد تحليله

أدرج معرّف الإعداد المسبق عند تسجيل الملاحظات، فهذا ما يُظهر الحدث في مقارنات الإعدادات المسبقة وتحليل المجموعات.

## تسجيل تقييم

أرسل الملاحظات بعد تقييم المستخدم لرد أو بعد تحديد تطبيقك للنتيجة.

```bash cURL
curl https://api.phaseo.app/v1/feedback \
  -X POST \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "requestId": "gen_01K...",
    "presetId": "8f54b2d9-9ba3-4ced-8a7f-9bb70a44dbea",
    "rating": "thumbs_up",
    "score": 1,
    "comment": "The answer resolved the customer question.",
    "metadataDimensions": {
      "plan": "pro",
      "surface": "support_chat"
    }
  }'
```

يجب أن يستهدف حدث الملاحظات طلبًا أو جلسة أو إعدادًا مسبقًا أو تشغيل اختبار واحدًا على الأقل. الدرجات اختيارية ويجب أن تتراوح بين `0` و`1`.

## اختيار التقييم

استخدم تقييمًا يصف الإشارة التي جمعتها فعليًا:

- استخدم `thumbs_up` أو `thumbs_down` لتفاعلات المستخدم البسيطة
- استخدم `correct` أو `partly_correct` أو `incorrect` للإجابات المُقيّمة
- استخدم `bad_format` أو `too_slow` أو `too_expensive` للمشكلات التشغيلية
- استخدم `unsafe` أو `refused_incorrectly` لنتائج السلامة
- استخدم `not_helpful` أو `other` عندما لا تناسب القيم الأخرى

لا تحوّل كل إشارة إلى درجة رقمية. تسهّل التقييمات الصريحة شرح المقارنات في لوحة التحكم.

## مقارنة الإعدادات المسبقة

افتح [الإعدادات ← الإعدادات المسبقة ← Feedback](https://phaseo.app/settings/presets/experiments) من أجل:

- مقارنة معدلات التقييمات الإيجابية والجزئية والسلبية
- اختيار إعداد مسبق أساسي
- التصفية حسب التاريخ والتقييم وأبعاد البيانات الوصفية
- فحص الطلب والجلسة والتعليقات والوسوم المرتبطة بالحدث

أضف القيم منخفضة التعدد مثل الخطة والنشر واللغة وواجهة التطبيق إلى `metadataDimensions`. واحفظ السياق العشوائي أو عالي التعدد في `metadata`.

## قراءة الملاحظات عبر API

سرد الأحداث الأخيرة:

```bash
curl "https://api.phaseo.app/v1/feedback?preset_id=PRESET_UUID&limit=100" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

طلب ملخص من جهة الخادم:

```bash
curl "https://api.phaseo.app/v1/feedback/summary?group_by=preset&since=2026-08-01T00:00:00Z" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

تتطلب عمليات القراءة `feedback:read`. وتقتصر النتائج على مساحة العمل المُصادَق عليها والإعدادات المسبقة الظاهرة لمُصدر الطلب.

## حدود إصدار ألفا الحالية

تحلّل لوحة التحكم ما يصل إلى 10,000 صف من الملاحظات المطابقة الأحدث ضمن الفترة المحددة.
تستخدم مقارنات الإعدادات المسبقة تقييمات صريحة، وتُعرض الدرجات الرقمية كتفاصيل داعمة.
تتوفر واجهات API لتشغيل الاختبارات وأحداث النتائج المخصصة، لكن مسارات العمل في لوحة التحكم ما زالت قيد التطوير.
