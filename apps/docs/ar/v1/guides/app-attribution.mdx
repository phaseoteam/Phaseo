أرسل الترويسة `X-App-Id` مع كل طلب لتجميع استخدامه تحت تطبيق واحد في تحليلات التطبيقات وتدقيق الطلبات. استخدم معرّفًا مختلفًا لكل منتج أو بيئة أو تجربة موجّهة للعملاء تريد إعداد تقارير عنها بشكل منفصل. لا يغيّر الإسناد استجابة الاستدلال أبدًا.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-App-Id: acme-support" \
  -H "X-App-Name: Acme Support" \
  -H "HTTP-Referer: https://acme.example/support" \
  -H "X-App-Categories: chat,productivity" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Summarize this ticket."
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const phaseo = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY,
  app: {
    id: "acme-support",
    name: "Acme Support",
    url: "https://acme.example/support",
    categories: ["chat", "productivity"],
  },
});

const response = await phaseo.generateResponse({
  model: "openai/gpt-6-astra",
  input: "Summarize this ticket.",
});
```
</CodeGroup>

يرسل الخيار `app` في TypeScript SDK الترويسات نفسها مع كل طلب. لا يضبط Phaseo الإسناد نيابةً عنك أبدًا.

## الترويسات

| الترويسة | الغرض |
| --- | --- |
| `X-App-Id` | معرّف ثابت يختاره تطبيقك. |
| `X-App-Name` | اسم مقروء يظهر في عروض التطبيقات والاستخدام. |
| `HTTP-Referer` | عنوان URL لصفحة عامة أو لعملية نشر مرتبطة بالتطبيق. |
| `X-App-Categories` | قائمة مفصولة بفواصل تضم ما يصل إلى ثلاث فئات. |
| `X-Title` | اسم بديل للتوافق يحمل اسمًا مقروءًا للتطبيق. |

يحدد Phaseo التطبيق بعنوان `HTTP-Referer` عندما ترسله، وبـ `X-App-Id` في غير ذلك. أبقِ كليهما ثابتين: أي عنوان URL أو معرّف جديد يبدأ تطبيقًا جديدًا في التحليلات.

لا يلزم أن يطابق `HTTP-Referer` الترويسة `Referer` التي يرسلها المتصفح تلقائيًا. اضبطه صراحةً في التكاملات من جهة الخادم عندما تريد عنوان URL معتمدًا واحدًا للتطبيق.

## الفئات

اختر ما يصل إلى ثلاث من `chat` و`developer-tools` و`research` و`productivity` و`education` و`commerce` و`media` و`finance` و`other`.

القيم غير حساسة لحالة الأحرف. يتجاهل Phaseo القيم غير المعروفة، ويزيل التكرارات، ويحتفظ بأول ثلاث فئات صالحة. تُضاف الفئات المرسلة في الطلبات اللاحقة إلى الفئات المحفوظة مسبقًا للتطبيق؛ ولا تزيل أبدًا الفئات المختارة في لوحة التحكم.

لإدارة الفئات مركزيًا بدلًا من شيفرة التطبيق، عدّلها في **الإعدادات → التطبيقات**.

## اجعل الإسناد آمنًا للمشاركة

- لا تضع معرّفات العملاء أو عناوين البريد الإلكتروني أو أي بيانات شخصية أخرى في ترويسات الإسناد.
- تعامل مع عنوان URL والاسم كبيانات عامة: فقد يظهران في عروض التطبيقات المشتركة أو العامة.
