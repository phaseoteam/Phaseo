استخدم إسناد التطبيق لفصل الاستخدام بين المنتجات أو البيئات أو التجارب المقدمة للعملاء. يظهر الإسناد في تحليلات التطبيق وتدقيق الطلبات من دون تغيير استجابة الاستدلال.

## إضافة ترويسات الإسناد

أرسل معرّف تطبيق ثابتًا مع كل طلب. أضف اسمًا وعنوان URL وما يصل إلى ثلاث فئات للحصول على تجميع أدق في لوحة التحكم.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-App-Id: acme-support" \
  -H "X-App-Name: Acme Support" \
  -H "HTTP-Referer: https://acme.example/support" \
  -H "X-App-Categories: chat,productivity" \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Summarize this ticket."
  }'
```

استخدم `X-App-Id` نفسه لكل طلب صادر من التطبيق نفسه. ويستخدمه Phaseo كهوية ثابتة عند عدم توفر عنوان URL.

## استخدام TypeScript SDK

```typescript
import Phaseo from "@phaseo/sdk";

const phaseo = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY,
  app: {
    id: "acme-support",
    name: "Acme Support",
    url: "https://acme.example/support",
    categories: ["chat", "productivity"],
  },
});

const response = await phaseo.generateResponse({
  model: "openai/gpt-5-nano",
  input: "Summarize this ticket.",
});
```

## الترويسات المدعومة

| الترويسة | الغرض |
| --- | --- |
| `X-App-Id` | معرّف ثابت يحدده تطبيقك. |
| `X-App-Name` | اسم مقروء يظهر في طرق عرض التطبيقات والاستخدام. |
| `HTTP-Referer` | عنوان URL عام للصفحة أو النشر المرتبط بالتطبيق. |
| `X-App-Categories` | قائمة مفصولة بفواصل تضم ما يصل إلى ثلاث فئات مدعومة. |
| `X-Title` | اسم مستعار للتوافق مع اسم تطبيق مقروء. |

`HTTP-Referer` بيانات وصفية للإسناد، ولا يلزم أن يطابق ترويسة `Referer` التلقائية للمتصفح. اضبطه صراحةً في عمليات التكامل على الخادم عندما تريد عنوان URL أساسيًا واحدًا للتطبيق.

## الفئات

اختر ما يصل إلى ثلاث قيم:

- `chat`
- `developer-tools`
- `research`
- `productivity`
- `education`
- `commerce`
- `media`
- `finance`
- `other`

لا تتأثر القيم بحالة الأحرف. يتجاهل Phaseo القيم غير المعروفة، ويحذف التكرارات، ويحتفظ بأول ثلاث فئات صالحة. وتُدمج الفئات الواردة في الطلبات اللاحقة مع الفئات المحفوظة للتطبيق؛ ولا تزيل اختيارات لوحة التحكم.

يمكنك أيضًا تعديل الفئات ضمن **Gateway → الإعدادات → التطبيقات**. استخدم لوحة التحكم عندما تُدار الفئات مركزيًا بدلًا من إدارتها في كود التطبيق.

## إرشادات الإسناد

- حافظ على ثبات المعرّفات عبر عمليات النشر ليظل الاستخدام مجمّعًا.
- استخدم معرّفات منفصلة للتطبيقات التي تحتاج إلى تقارير مستقلة للتكلفة أو الاستخدام.
- لا تضع معرّفات العملاء أو عناوين البريد الإلكتروني أو أي بيانات شخصية أخرى في ترويسات الإسناد.
- تعامل مع عنوان URL كبيانات وصفية عامة إذا كان التطبيق قد يظهر في عروض مشتركة أو عامة.
