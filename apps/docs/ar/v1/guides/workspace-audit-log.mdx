افتح **الإعدادات ← مساحة العمل ← النشاط** لترى من غيّر مفتاحًا أو عضوًا أو أي عنصر تحكم إداري آخر في مساحة العمل النشطة، ومتى. تُعرض الأحداث بدءًا بالأحدث. لا يستطيع قراءة السجل إلا مالكو مساحة العمل ومسؤولوها.

تعرض سجلات الطلبات والتوليد الحركة التي جرت. أما سجل التدقيق فيعرض من غيّر عناصر التحكم المحيطة بها.

## ما يُسجَّل

| المجال | أمثلة على الإجراءات |
| --- | --- |
| مفاتيح API | `api_key.created`، `api_key.updated`، `api_key.paused`، `api_key.resumed`، `api_key.rotated`، `api_key.deleted` |
| مفاتيح الإدارة | `management_key.created`، `management_key.updated`، `management_key.deleted` |
| الأعضاء والدعوات | `workspace.member.added`، `workspace.member.role_updated`، `workspace.member.removed`، `workspace.invite.created` |
| مفاتيح المزوّدين (BYOK) | `provider_credential.created`، `provider_credential.updated`، `provider_credential.reordered`، `provider_credential.deleted` |
| التوجيه والإعدادات المسبقة | `routing.policy.updated`، `routing.dynamic_route.deployed`، `preset.version.published` |
| الميزانيات والإنفاق | `workspace_budget.updated`، `spend_block.lifted`، `rate_limit_raise.requested` |
| ضوابط الحماية | `guardrail.created`، `guardrail.updated`، `guardrail.keys.added` |
| الهوية | `identity.sso.updated`، `identity.scim_token.created`، `identity.group_mapping.updated` |
| التكاملات | `observability.destination.created`، `notifications.destination.created`، `webhook_endpoint.secret_rotated`، `oauth_authorization.revoked` |

يتضمن كل حدث المنفِّذ، والإجراء، ونوع الهدف، ومعرّف الهدف واسمه، والطابع الزمني، ومعرّف الطلب، ومجموعة صغيرة من بيانات التغيير الوصفية. الأحداث للإضافة فقط.

لا يخزّن السجل أبدًا المفاتيح بنص صريح، أو تجزئات بيانات الاعتماد، أو ترويسات التفويض، أو قوائم النطاقات الكاملة، أو نصوص الطلبات. تُحذف حقول البيانات الوصفية التي تشير أسماؤها إلى سر أو token أو تجزئة أو بيانات اعتماد أو نطاق أو قيمة قبل كتابة الحدث.

## قراءة الأحداث من API

استدعِ `GET /v1/audit-events` باستخدام [مفتاح إدارة](../developers/management-api-keys.mdx) يملك `activity:read`. ويحتاج OAuth token أيضًا إلى `activity:read`، ويجب أن يكون مستخدمه مالكًا لمساحة العمل أو مسؤولًا فيها.

```bash
curl "https://api.phaseo.app/v1/audit-events?limit=50" \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY"
```

| معامل الاستعلام | المعنى |
| --- | --- |
| `limit` | عدد الأحداث في الصفحة، من 1 إلى 100. الافتراضي `50`. |
| `cursor` | قيمة `next_cursor` من الصفحة السابقة. التنقل بالمؤشر لا يتخطى أبدًا الأحداث التي تشترك في طابع زمني. |
| `action` | يعيد إجراءً واحدًا فقط، مثل `api_key.rotated`. |
| `target_type` | يعيد نوع هدف واحدًا فقط، مثل `api_key`. |

تحتوي الاستجابة على `data` و`has_more` و`next_cursor`. يتضمن كل حدث كائن `actor` يحمل `display_name` و`email` الخاصين بالعضو.
