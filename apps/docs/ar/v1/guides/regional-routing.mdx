أرسل الطلبات النصية إلى `eu.api.phaseo.app` أو `us.api.phaseo.app` لاستخدام مسارات المزوّدين التي تشغّل النموذج وتعالج بيانات الموجّه والإكمال داخل تلك المنطقة فقط. تبقى معرّفات النماذج ومفاتيح API كما هي. تُدعم Chat Completions وResponses وMessages.

| المنطقة | عنوان URL الأساسي | مسارات المزوّدين المستخدمة |
| --- | --- | --- |
| الاتحاد الأوروبي | `https://eu.api.phaseo.app/v1` | فقط المسارات التي تصرّح بالتنفيذ ومعالجة البيانات داخل الاتحاد الأوروبي |
| الولايات المتحدة | `https://us.api.phaseo.app/v1` | فقط المسارات التي تصرّح بالتنفيذ ومعالجة البيانات داخل الولايات المتحدة |
| عالمي | `https://api.phaseo.app/v1` | سياسة التوجيه العالمية القياسية |

<Warning>
التوجيه الإقليمي ليس بعد ضمانًا شاملًا لإقامة البيانات من البداية إلى النهاية. يقيّد Phaseo اختيار المزوّد ويضع الـ Gateway قرب المنطقة، لكن أنظمة الحساب والفوترة والذاكرة المؤقتة والتشغيل المشتركة قد تعالج البيانات خارجها. راجع [ما يبقى خارج المنطقة](#what-stays-outside-the-region).
</Warning>

## أرسل طلبًا إقليميًا

<CodeGroup>
```ts TypeScript
import { Phaseo } from "@phaseo/sdk";

const phaseo = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY!,
  region: "eu",
});

const response = await phaseo.responses.create({
  model: "openai/gpt-5.6-luna",
  input: "Summarize this note in one sentence.",
});

console.log(response.output_text);
```

```python Python
import os
from phaseo import Phaseo

phaseo = Phaseo(
    api_key=os.environ["PHASEO_API_KEY"],
    region="eu",
)

response = phaseo.responses.create({
    "model": "openai/gpt-5.6-luna",
    "input": "Summarize this note in one sentence.",
})

print(response.get("output_text"))
```

```bash Chat Completions
curl https://eu.api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-luna",
    "messages": [
      {"role": "user", "content": "Write a two-line status update."}
    ]
  }'
```

```bash Responses
curl https://eu.api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-luna",
    "input": "Extract the three most important actions from this note."
  }'
```

```bash Messages
curl https://us.api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 256,
    "messages": [
      {"role": "user", "content": "Summarize this incident report."}
    ]
  }'
```
</CodeGroup>

في حزم SDK، اضبط `region` على `"eu"` أو `"us"`؛ واتركه، أو استخدم `"global"`، للتوجيه العالمي. ترمي حزمة SDK خطأً إذا ضبطت كلًا من `region` و`baseUrl` مخصصًا (`base_url` في Python)، لأنهما يختاران مضيفين مختلفين.

اسم المضيف هو السياسة. يفشل وجود `required_execution_region` أو `required_data_region` في الطلب أو في إعداد مسبق يسمّي منطقة أخرى بالخطأ `400 validation_error` والسبب `deployment_region_conflict`. تُطبَّق الإعدادات المسبقة وقواعد التوجيه الديناميكي أولًا والقاعدة الإقليمية أخيرًا، لذا لا يمكنها إضعافها. لا يعيد Phaseo المحاولة أبدًا عبر مزوّد خارج المنطقة.

## ما الذي يمكن أن يحتويه الطلب الإقليمي

| مدعوم | مرفوض |
| --- | --- |
| إدخال نصي ومخرجات نصية | الصور والصوت والفيديو والمستندات والملفات والمرفقات |
| التدفق وعدم التدفق | وسائط المخرجات غير النصية |
| تعليمات النظام والمطوّر | الأدوات المستضافة لدى المزوّد مثل البحث على الويب والبحث في الملفات وتنفيذ الشيفرة واستخدام الحاسوب وتوليد الصور، و`web_search_options` |
| أدوات `function` و`custom` الخاصة بك، ونتائج الأدوات النصية | [أدوات الخادم](./server-tools) في Phaseo (أنواع `phaseo:`) |
| المخرجات النصية المنظَّمة وJSON، حيث يدعمها النموذج | نقاط نهاية الصور والصوت والفيديو والتضمين والإشراف والدفعات والملفات وwebhooks والوقت الفعلي |
| الإعدادات المسبقة، وترتيب المزوّدين، والبدائل، وحدود الأسعار التي لا تتعارض مع المنطقة | |

أدواتك الخاصة مسموح بها لأنها تعمل في تطبيقك. أما الأدوات المستضافة وأدوات الخادم فتعمل في مكان لا تستطيع القاعدة الإقليمية التحكم فيه.

## اعثر على النماذج المتاحة في منطقة

استدعِ `/v1/models` على اسم المضيف نفسه الذي ترسل إليه الطلبات. يختلف التوفر بين نقاط النهاية الأوروبية والأمريكية والعالمية.

```bash
curl https://eu.api.phaseo.app/v1/models \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

لا تحتوي القائمة إلا على النماذج التي لها مسار مزوّد نشط تشمل منطقتا التنفيذ والبيانات المصرّح بهما فيه المنطقة المعنية، ولا تعلن إلا عن Chat Completions وResponses وMessages بإدخال ومخرجات نصية. يعرض كل عرض مناطقه:

```json
{
  "provider": { "id": "example-eu", "name": "Example EU" },
  "residency": {
    "execution_regions": ["eu"],
    "data_regions": ["eu"]
  }
}
```

## تحقّق من الـ Gateway الذي عالج الطلب

تحمل الاستجابات الإقليمية `X-Phaseo-Gateway-Region: eu` (أو `us`). تسمّي الترويسة السياسة الإقليمية التي عالجت الطلب؛ وليست دليلًا على المكان الذي شغّله فيه Cloudflare. تسجّل تفاصيل الطلب أيضًا منطقتي التنفيذ والبيانات المطلوبتين، والمزوّد المختار، والمناطق المصرّح بها لذلك المزوّد.

## الأخطاء

تعيد مخالفات القاعدة الإقليمية `400 not_supported` مع إحدى قيم `reason` التالية:

| `reason` | السبب | الإصلاح |
| --- | --- | --- |
| `regional_endpoint_not_supported` | المسار غير متاح إقليميًا | استخدم Chat Completions أو Responses أو Messages، أو الواجهة العالمية |
| `regional_non_text_content` | وسائط أو ملف أو مرفق في الطلب | أزله، أو استخدم الواجهة العالمية |
| `regional_non_text_output` | طُلب وسيط مخرجات غير نصي | اطلب نصًا، أو استخدم الواجهة العالمية |
| `regional_hosted_tool_not_supported` | أداة غير `function` أو `custom` | استخدم أداة دالة خاصة بك، أو الواجهة العالمية |

يعني `400 validation_error` مع السبب `deployment_region_conflict` أن الطلب أو إعدادًا مسبقًا يسمّي منطقة أخرى؛ أزل ذلك الإعداد. إذا لم يستوفِ أي مسار مزوّد سليم النموذج والمنطقة معًا، يتوقف الطلب قبل استدعاء أي مزوّد؛ اختر نموذجًا مدرجًا في `/v1/models` الإقليمية.

## ما يبقى خارج المنطقة

تغطي القاعدة الإقليمية المزوّد الذي يشغّل النموذج ويعالج بيانات الموجّه والإكمال. ولا تغطي بعد دورة حياة الطلب كاملة:

- يضع تموضع Cloudflare الـ Gateway قرب المنطقة، لكنه ليس حدًا للامتثال.
- تعيش بيانات الحساب والمصادقة والفوترة والبيانات الوصفية للطلبات على بنية Supabase التحتية المشتركة.
- لا ترتبط Cloudflare KV وسجلات استدعاء Worker بمنطقة.
- تذهب الاستدعاءات إلى المزوّد إلى نقطة النهاية الإقليمية لذلك المزوّد، بغض النظر عن المكان الذي وضع فيه Cloudflare الـ Gateway.
- لا يقتصر موظفو الدعم والتشغيل على المنطقة.

لن يسمّي Phaseo هذا إقامة بيانات شاملة من البداية إلى النهاية إلا عندما تملك مسارات الـ Gateway والتخزين والتسجيل والمزوّد والتشغيل كلها ضوابط إقليمية قابلة للإنفاذ.
