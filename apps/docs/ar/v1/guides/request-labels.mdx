استخدم تسميات الطلب عندما يحتاج كود التطبيق إلى بُعد تكلفة ثابت وأكثر تحديدًا من مفتاح API أو التطبيق. تُسجّل التسميات مع تدقيق الطلب ويمكن تصفيتها في التحليلات دون تغيير طلب النموذج.

## إرسال التسميات

اضبط `X-Phaseo-Metadata` على كائن JSON يتضمن حتى 32 زوجًا فريدًا من المفاتيح والقيم:

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H 'X-Phaseo-Metadata: {"labels":[{"key":"team","value":"support"},{"key":"environment","value":"production"}]}' \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Summarize this ticket."
  }'
```

تقبل حزم TypeScript وPython ترويسات مخصصة، لذا يمكن ضبط الترويسة نفسها على العميل. ولا تُمرر التسميات إلى المزوّدين.

## تقسيم الإنفاق

استخدم نقطة نهاية التحليلات مع `label_key` و`label_value`:

```text
GET /v1/analytics?label_key=team&label_value=support
```

تستخدم الاستجابة تنسيق الإنفاق المجمّع نفسه المستخدم في التحليلات غير المصفّاة، لكنها لا تشمل إلا الطلبات التي تحمل زوج التسميات المحدد حرفيًا.

## القواعد

- تقتصر المفاتيح على الأحرف والأرقام والرموز `_` و`.` و`:` و`-`، وبحد أقصى 64 حرفًا.
- القيم نصوص لا يتجاوز طولها 256 حرفًا.
- يمكن أن يتضمن الطلب حتى 32 تسمية، ويقتصر حجم الترويسة على 8 KiB.
- تُرفض المفاتيح المكررة أو البيانات الوصفية المشوهة مع `400 invalid_request`.
- لا تضع الموجّهات أو الأسرار أو عناوين البريد الإلكتروني أو غيرها من البيانات الشخصية في التسميات.
