title: "أنماط استدعاء الأدوات"
description: "حلقات موثوقة لاستدعاء الأدوات لنقطتي النهاية chat completions وresponses."
---

بعد أن يستدعي النموذج أداة، أرسل طلب متابعة يكرر المحادثة واستدعاء النموذج ونتيجة أداتك. يكتب النموذج حينها إجابته، أو يستدعي أداة أخرى فتكرر العملية. استخدم نقطة النهاية التي يستخدم تطبيقك تنسيق رسائلها بالفعل: `/v1/chat/completions` لحلقات الرسائل بنمط OpenAI، و`/v1/responses` لـ Responses API، و`/v1/messages` للتطبيقات الأصلية لـ Anthropic.

<Tabs>
<Tab title="Chat Completions">

عندما تكون `finish_reason` بقيمة `tool_calls`، شغّل كل استدعاء، ثم أرسل رسالة المساعد دون تغيير متبوعة برسالة `role: "tool"` واحدة لكل استدعاء، تُطابَق عبر `tool_call_id`. وأرسل `tools` مجددًا.

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "What is the weather in Seattle?" },
    {
      "role": "assistant",
      "content": null,
      "tool_calls": [
        {
          "id": "call_123",
          "type": "function",
          "function": {
            "name": "get_weather",
            "arguments": "{\"city\":\"Seattle\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_123",
      "content": "72F and sunny"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    }
  ]
}
```

</Tab>
<Tab title="Responses">

تصل الاستدعاءات عناصرَ إخراج من النوع `function_call`. أعِد عنصر الاستدعاء إدخالًا، متبوعًا بعنصر `function_call_output` يحمل `call_id` نفسه.

```json
{
  "model": "openai/gpt-6-astra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [{ "type": "input_text", "text": "What's the weather in Seattle?" }]
    },
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Seattle\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "72F and sunny"
    }
  ]
}
```

</Tab>
</Tabs>

قبل تشغيل استدعاء، تحقّق من معاملاته؛ راجع [سلامة استدعاء الأدوات](./tool-calling-safety).
