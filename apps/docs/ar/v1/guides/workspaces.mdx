أنشئ مساحة عمل لكل فريق أو منتج أو بيئة لتبقى مفاتيح API وإعدادات التوجيه والإعدادات المسبقة وحواجز الحماية والوصول الإداري الخاصة بها منفصلة. يبدأ كل حساب بمساحة عمل شخصية، وهي كافية لتكامل صغير.

تفيد مساحات العمل المنفصلة عندما تريد:

- عزل بيانات اعتماد التطوير والتجهيز والإنتاج
- إبقاء المنتجات أو مشاريع العملاء منفصلة
- منح تكامل إداري الوصول إلى الموارد التي يحتاجها فقط
- تطبيق سياسات توجيه أو إعدادات مسبقة أو حواجز حماية مختلفة

لا تغيّر مساحات العمل أسعارك: يبقى كل الاستخدام على الفوترة القياسية بالدفع حسب الاستخدام، الموضحة في [الأسعار والفوترة](../pricing/tiers). تُتاح مساحات العمل الإضافية بعد أول إيداع للأرصدة؛ وحتى ذلك الحين، يفشل إنشاء مساحة عمل مع `403 workspace_upgrade_required`.

## إدارة مساحات العمل من API

أدِر مساحات العمل من لوحة التحكم أو باستخدام API الإدارة. يحتاج API إلى [مفتاح إدارة](../developers/management-api-keys)؛ أما مفاتيح Gateway API العادية فهي للاستدلال ولا يمكنها استدعاء نقاط النهاية هذه.

| المهمة | نقطة النهاية | الصلاحية |
| --- | --- | --- |
| سرد مساحات العمل | [`GET /workspaces`](../api-reference/endpoint/workspaces-list) | `workspaces:read` |
| قراءة مساحة عمل | [`GET /workspaces/{id}`](../api-reference/endpoint/workspaces-get) | `workspaces:read` |
| إنشاء مساحة عمل | [`POST /workspaces`](../api-reference/endpoint/workspaces-create) | `workspaces:write` |
| تحديث مساحة عمل | [`PATCH /workspaces/{id}`](../api-reference/endpoint/workspaces-update) | `workspaces:write` |
| حذف مساحة عمل | [`DELETE /workspaces/{id}`](../api-reference/endpoint/workspaces-delete) | `workspaces:delete` |

امنح المفتاح الصلاحيات التي يحتاجها فقط. يتحقق Phaseo أيضًا من عضوية مساحة العمل والدور، لذا لا تمنح الصلاحية وحدها أبدًا الوصول إلى مساحة عمل أخرى. يجب أن يتكون `slug` لمساحة العمل الجديدة من 1 إلى 50 حرفًا لاتينيًا صغيرًا أو رقمًا أو شرطة.

احفظ مفاتيح الإدارة في مخزن أسرار على الخادم، ولا تضعها أبدًا في شيفرة المتصفح أو سجلات سطح المكتب أو نظام التحكم في المصدر أو الدردشة.

<Note>
نقاط نهاية مساحات العمل في مرحلة تجريبية. اجعل الأتمتة آمنة لإعادة المحاولة، وتحقّق من كل استجابة قبل إجراء تغيير لاحق.
</Note>

## إعادة تسمية مساحة عمل أو حذفها

لا يمكن إعادة تسمية مساحة العمل الشخصية (الافتراضية) أو حذفها؛ ويعيد كلا الإجراءين `400 bad_request`. قبل حذف مساحة عمل أخرى، أزِل مفاتيح API النشطة فيها أو انقلها حتى لا تشير أي طلبات إلى مساحة عمل لم تعد موجودة.
