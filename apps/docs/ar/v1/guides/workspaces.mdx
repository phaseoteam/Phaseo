تنظّم مساحات العمل مفاتيح API وإعدادات التوجيه والإعدادات المسبقة والضوابط والوصول الإداري لفريق أو منتج أو بيئة.

تتضمن خدمة Phaseo القياسية للدفع حسب الاستخدام مساحات العمل. لا تحتاج إلى خطة منفصلة لإنشائها أو استخدامها.

## متى تنشئ مساحة عمل

استخدم مساحات عمل منفصلة إذا أردت:

- عزل بيانات اعتماد التطوير والاختبار والإنتاج
- إبقاء المنتجات أو مشاريع العملاء المختلفة منفصلة
- منح عمليات التكامل الإدارية حق الوصول إلى الموارد التي تحتاج إليها فقط
- تطبيق سياسات مختلفة للتوجيه أو الإعدادات المسبقة أو الضوابط

قد تكون مساحة العمل الافتراضية كافية لتكامل صغير.

## إدارة مساحات العمل

يمكنك إدارة مساحات العمل من لوحة تحكم Phaseo أو عبر واجهة إدارة API.

تستخدم واجهة مساحات العمل [مفاتيح API للإدارة](../developers/management-api-keys.mdx). مفاتيح Gateway القياسية مخصصة لطلبات الاستدلال ولا يمكنها استدعاء نقاط إدارة مساحات العمل.

| المهمة | نقطة النهاية |
| --- | --- |
| سرد مساحات العمل | [`GET /workspaces`](../api-reference/endpoint/workspaces-list.mdx) |
| إنشاء مساحة عمل | [`POST /workspaces`](../api-reference/endpoint/workspaces-create.mdx) |
| قراءة مساحة عمل | [`GET /workspaces/{id}`](../api-reference/endpoint/workspaces-get.mdx) |
| تحديث مساحة عمل | [`PATCH /workspaces/{id}`](../api-reference/endpoint/workspaces-update.mdx) |
| حذف مساحة عمل | [`DELETE /workspaces/{id}`](../api-reference/endpoint/workspaces-delete.mdx) |

<Note>
نقاط إدارة مساحات العمل موسومة حاليًا بمرحلة Beta. اجعل أتمتة الإدارة سهلة لإعادة المحاولة، وراجع ردود API قبل تطبيق تغييرات لاحقة.
</Note>

## اختيار مستوى الوصول المناسب

أنشئ مفتاح إدارة يتضمن قدرات مساحات العمل التي يحتاج إليها تكاملك فقط:

- `workspaces:read` لسرد مساحات العمل وفحصها
- `workspaces:write` لإنشاء مساحات العمل أو تحديثها
- `workspaces:delete` لحذف مساحات العمل

يتحقق Phaseo أيضًا من عضوية مساحة العمل والأدوار. ولا تمنح القدرة وحدها حق الوصول إلى مساحة عمل أخرى.

خزّن مفاتيح الإدارة في مخزن أسرار على الخادم. لا تكشفها في شيفرة المتصفح أو سجلات سطح المكتب أو نظام التحكم بالمصدر أو المحادثات.

## حذف مساحة عمل

لا يمكن حذف مساحة العمل الافتراضية. قبل حذف مساحة أخرى، أزل مفاتيح API النشطة الخاصة بها أو انقلها حتى لا تُوجّه الطلبات إلى مساحة عمل لم تعد موجودة.

## الفوترة

لا تنشئ مساحات العمل مستويات أسعار منفصلة. يستمر احتساب الاستخدام وفق نموذج الدفع القياسي حسب الاستخدام الموضح في [الأسعار والفوترة](../pricing/tiers.mdx).
