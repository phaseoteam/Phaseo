توفّر البوابة وسائط متعددة عبر واجهة API موحدة. وترتبط كل نقطة نهاية بقدرة مختلفة، كما يختلف دعم النماذج حسب المزوّد.

## الوسائط ونقاط النهاية

| الوسيط | نقاط النهاية الرئيسية | ملاحظات |
| --- | --- | --- |
| النص | `/v1/responses` و`/v1/chat/completions` و`/v1/messages` | مخرجات منظّمة وحوارية. |
| الصور | `/v1/images/generations` و`/v1/images/edits` | إنشاء الصور من النص وتحريرها. |
| الصوت (TTS/STT/الترجمة) | `/v1/audio/speech` و`/v1/audio/transcriptions` و`/v1/audio/translations` | تحويل النص إلى كلام والكلام إلى نص وترجمة الصوت المنطوق. |
| الفيديو | `/v1/videos` و`/v1/videos/{video_id}` و`/v1/videos/{video_id}/content` و`/v1/videos/{video_id}` (DELETE) | أنشئ مهام فيديو غير متزامنة، واستطلع حالتها، واسترجع المحتوى، واحذف المهام. |
| الموسيقى | `/v1/music/generate` | إنشاء الموسيقى عبر المزوّدين المدعومين. |
| OCR | `/v1/ocr` | استخرج النص من الصور عند توفر الدعم. |

## التحقق من دعم النماذج

استخدم [نقطة نهاية النماذج](../api-reference/endpoint/models.mdx) لمعرفة النماذج المتاحة ونقاط النهاية التي تدعمها. ويتوفر دعم المزوّدين عبر [نقطة نهاية المزوّدين](../api-reference/endpoint/providers.mdx).

## أفضل الممارسات

- اختر نقطة النهاية المناسبة للوسيط الذي تحتاجه، حتى إن كان اسم النموذج مشتركًا بين وسائط متعددة.
- تحقّق من الحمولات باستخدام [مرجع API](../api-reference/introduction.mdx) قبل الإطلاق.
