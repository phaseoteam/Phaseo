استخدم وجهات الإشعارات لإرسال التنبيهات المفعّلة في مساحة العمل إلى الأدوات التي يراقبها فريقك بالفعل. تشترك مساحة العمل في الوجهات ويمكن اختبارها قبل الاعتماد عليها للتنبيهات التشغيلية.

## إضافة وجهة

1. افتح **Gateway → الإعدادات → الإشعارات**.
2. اختر **إضافة وجهة**.
3. أدخل اسمًا واختر قناة واحدة أو أكثر.
4. أضف تفاصيل الوجهة واذكر المستلمين اختياريًا.
5. اختر **إرسال اختبار** لكل قناة تم إعدادها.
6. أنشئ الوجهات بعد نجاح جميع الاختبارات.

تحصل الـ webhooks المخصصة على سر توقيع عند إنشائها. انسخه من مربع الحوار الذي يظهر؛ فهو يُعرض مرة واحدة فقط.

يدعم Phaseo:

- عناوين البريد الإلكتروني وقوائم التوزيع
- قنوات Discord عبر رمز bot
- webhooks من Discord
- webhooks واردة من Slack
- عناوين URL لسير عمل Microsoft Teams
- webhooks مخصصة عبر HTTPS

تُشفّر بيانات الاعتماد وعناوين webhook قبل تخزينها. خصّص بيانات اعتماد القنوات لإرسال الإشعارات فقط وبدّلها إذا انكشفت.

## تفعيل تنبيهات المنتج

تعرض صفحة الإشعارات أنواع التنبيهات المتاحة لمساحة العمل. فعّل **تنبيهات إيقاف النماذج** لتتلقى إشعارًا قبل إيقاف نموذج تستخدمه مساحة العمل.

تُرسل **إشعارات النموذج البديل** عندما يكون [توجيه النماذج المتوقفة](./model-retirement.mdx#route-requests-to-a-replacement-automatically) مفعّلًا ويجيب نموذج بديل عن طلبات مساحة العمل لنموذج لم يعد أي مزوّد يقدّمه. يُرسل إشعار واحد لكل نموذج وبديله، في المرة الأولى التي يجيب فيها بديل بنجاح. يتلقى مالك مساحة العمل رسالة بريد إلكتروني دائمًا؛ اختر وجهات لإرسال الإشعار إلى فريقك أيضًا.

تُرسل التنبيهات إلى الوجهات التي تم إعدادها، إضافةً إلى أي مستلمين مدمجين يظهرون في لوحة التحكم.

## الإشارات

تتيح حقول الإشارة الاختيارية للتنبيه إخطار مستلمين محددين:

- يقبل Discord معرّفات المستخدمين والأدوار.
- يقبل Slack معرّفات المستخدمين ومجموعات المستخدمين.
- يقبل Microsoft Teams عناوين بريد Microsoft 365 أو معرّفات كائنات Entra.

استخدم الإشارات باعتدال. من الأفضل عادةً إرسال تنبيهات مساحة العمل المتكررة إلى قناة خاضعة للمراقبة بدلًا من تنبيه مجموعة واسعة.

## اختبار الوجهات وإزالتها

استخدم **إرسال اختبار** بجانب وجهة موجودة بعد تبديل بيانات الاعتماد أو تغيير إعداد القناة. أزل الوجهات التي لم تعد خاضعة للمراقبة حتى لا تبدو التنبيهات وكأنها تُرسل إلى قناة مهجورة.

يجب أن تستخدم webhooks المخصصة HTTPS وأن تتحقق من الطلب قبل معالجته. أعد استجابة نجاح بسرعة وانقل المهام الأبطأ إلى مهمة تعمل في الخلفية.

## التحقق من تواقيع webhook

توقّع Phaseo كل عملية تسليم إلى webhook مخصص، بما في ذلك الاختبارات المرسلة من وجهة محفوظة، بالطريقة نفسها المستخدمة في [webhooks الفيديو والدُفعات](./async-video-and-batch.mdx). يحمل كل طلب هذه الترويسات:

```http
POST /your/endpoint HTTP/1.1
content-type: application/json
user-agent: Phaseo-Notifications/1.0
x-phaseo-event-id: 6f1c0f5e-3f0b-4a39-9a51-2f4f2c1d9e10
x-phaseo-event-type: rate_limit_throttled
x-phaseo-timestamp: 1792569600
x-phaseo-signature: 5d2a…e41f
```

`x-phaseo-signature` هو HMAC-SHA256 بالنظام الست عشري لقيمة `x-phaseo-timestamp` ثم نقطة حرفية (`.`) ثم **نص الطلب دون تعديل**، باستخدام سر توقيع الوجهة (`whsec_…`) مفتاحًا. تكون قيمة `x-phaseo-timestamp` بثواني Unix.

للتحقق من عملية تسليم:

1. اقرأ نص الطلب الخام قبل تحليله بصيغة JSON.
2. أعد حساب التوقيع وقارنه في زمن ثابت.
3. ارفض الطوابع الزمنية التي تختلف عن ساعتك بأكثر من خمس دقائق.
4. أزل التكرار باستخدام `x-phaseo-event-id`. تُعاد محاولة عمليات التسليم الفاشلة، وتُوقَّع كل محاولة من جديد بطابع زمني جديد.

<CodeGroup>
```js Node.js
import crypto from "node:crypto";

// rawBody هو نص الطلب كما استُلم تمامًا، كسلسلة نصية.
export function verifyPhaseoSignature(rawBody, headers, secret, toleranceSeconds = 300) {
  const timestamp = headers["x-phaseo-timestamp"];
  const signature = headers["x-phaseo-signature"];
  if (!timestamp || !signature) return false;
  if (Math.abs(Date.now() / 1000 - Number(timestamp)) > toleranceSeconds) return false;
  const expected = crypto
    .createHmac("sha256", secret)
    .update(`${timestamp}.${rawBody}`)
    .digest("hex");
  const a = Buffer.from(expected, "hex");
  const b = Buffer.from(signature, "hex");
  return a.length === b.length && crypto.timingSafeEqual(a, b);
}
```

```python Python
import hashlib
import hmac
import time

# raw_body هو نص الطلب كما استُلم تمامًا، كبايتات.
def verify_phaseo_signature(raw_body: bytes, headers, secret: str, tolerance_seconds: int = 300) -> bool:
    timestamp = headers.get("x-phaseo-timestamp", "")
    signature = headers.get("x-phaseo-signature", "")
    if not timestamp.isdigit() or not signature:
        return False
    if abs(time.time() - int(timestamp)) > tolerance_seconds:
        return False
    expected = hmac.new(secret.encode(), timestamp.encode() + b"." + raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature)
```
</CodeGroup>

### إنشاء سر أو تدويره

يُعرض السر مرة واحدة فقط عند إنشاء الوجهة. لاستبداله، اختر **تدوير السر** بجانب الوجهة في **الإعدادات ← الإشعارات**، أو استدعِ [`POST /v1/notifications/destinations/{id}/rotate-secret`](/ar/v1/api-reference/endpoint/notifications-destination-rotate-secret). تُوقَّع عملية التسليم التالية بالسر الجديد ويتوقف السر القديم عن العمل، لذا حدّث جهة الاستقبال فورًا.

الـ webhooks المخصصة التي أُنشئت قبل توفر التوقيع ليس لها سر وما زالت تُسلَّم دون توقيع. تظهر في الإعدادات بعلامة **غير موقّع**. اختر **إنشاء سر**، وأضف السر إلى جهة الاستقبال، ثم أرسل اختبارًا للتحقق. الاختبارات المرسلة من لوحة **إضافة وجهة** قبل حفظ الوجهة غير موقّعة لأنه لا يوجد سر بعد.

لا تُوقَّع وجهات البريد الإلكتروني وSlack وDiscord وMicrosoft Teams: فهذه الخدمات تصادق على عنوان webhook أو رمز البوت بنفسها.
