أضف `phaseo:datetime` ليتمكن النموذج من معرفة التاريخ والوقت الحاليين عندما يعتمد الموجّه عليهما، مثل "ما اليوم في طوكيو؟". يقرر النموذج متى يستدعيها؛ ويعيد Phaseo الوقت في كل منطقة زمنية أدرجتها.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What day of the week is it in Tokyo?" }
    ],
    "tools": [
      {
        "type": "phaseo:datetime",
        "parameters": { "timezones": ["Asia/Tokyo", "UTC"] }
      }
    ]
  }'
```

## المعاملات

| المعامل | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `timezones` | string[] | `["UTC"]` | حتى 5 أسماء مناطق زمنية من IANA، مثل `["Europe/London", "UTC"]`. |

أكثر من 5 مناطق زمنية، أو اسم ليس منطقة زمنية صالحة في IANA، يؤدي إلى رفض الطلب قبل تشغيل النموذج. لا يزال اسم النوع الأقدم `gateway:datetime` مقبولًا.

## ما تعيده الأداة

إدخال واحد لكل منطقة زمنية:

```json
{
  "timezones": [
    { "timezone": "Europe/London", "datetime": "2026-07-03T10:00:00.123+01:00" },
    { "timezone": "UTC", "datetime": "2026-07-03T09:00:00.123+00:00" }
  ]
}
```

## الاستخدام والتسعير

يضيف كل استدعاء 1 إلى `usage.server_tool_use.datetime_requests`. ليس لأداة التاريخ والوقت عدّاد تسعير خاص بها.
