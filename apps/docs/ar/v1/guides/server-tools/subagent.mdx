أضف `phaseo:subagent` ليتمكن النموذج الرئيسي من تسليم مهمة مستقلة إلى نموذج عامل، يكون غالبًا أصغر أو أسرع، في الطلب نفسه. يصف النموذج الرئيسي المهمة؛ ويشغّل Phaseo النموذج العامل ويعيد نتيجته، ثم يُكمل النموذج الرئيسي الإجابة.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5",
    "messages": [
      { "role": "user", "content": "Compare these release notes and summarize the breaking changes." }
    ],
    "tools": [
      {
        "type": "phaseo:subagent",
        "parameters": {
          "model": "openai/gpt-6-astra",
          "instructions": "Return concise findings for the main model. Do not address the end user directly.",
          "max_uses": 3,
          "max_completion_tokens": 1200
        }
      }
    ]
  }'
```

## المعاملات

| المعامل | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `model` | string | نموذج الطلب | النموذج العامل. |
| `instructions` | string | تعليمات النموذج العامل المدمجة | تعليمات إضافية للنموذج العامل. |
| `max_uses` | integer | `1` | عدد استدعاءات Subagent في كل طلب. |
| `max_completion_tokens` | integer | `1400` | توكنات الإخراج لكل رد من النموذج العامل. تُرفع القيم الأقل من `1024` إلى `1024`. يُقبل `max_tokens` كاسم مستعار أقدم. |
| `reasoning` | object | افتراضي المزوّد | إعدادات الاستدلال، تُمرَّر حيث يدعمها النموذج العامل. |
| `temperature` | number | افتراضي المزوّد | درجة حرارة أخذ العينات لاستدعاء النموذج العامل. |

لا يتلقى النموذج العامل المحادثة أبدًا: ضع في المهمة كل ما يحتاجه.

## ما يرسله النموذج

`task_description` يتضمن المهمة كاملة والسياق والمخرجات المتوقعة، إضافةً إلى `task_name` قصير اختياري:

```json
{
  "task_description": "Extract the three highest-risk migration steps from the supplied plan."
}
```

يُقبل `task` أو `prompt` أو `input` بدلًا من `task_description`.

## ما تعيده الأداة

```json
{
  "status": "ok",
  "model": "openai/gpt-6-astra",
  "outcome": "The highest-risk steps are schema migration, traffic cutover, and rollback verification."
}
```

إذا تعذّر تشغيل الاستدعاء، يحصل النموذج على `subagent_invalid_request` (لا توجد مهمة)، أو `subagent_max_uses_exceeded`، أو `subagent_request_failed`.

## الاستخدام والتسعير

يضيف كل استدعاء 1 إلى `usage.server_tool_use.subagent_requests` ويمكن احتسابه عبر `server_tool_subagent_requests`. تُحتسب رموز النموذج المساعد بأسعار ذلك النموذج، كبند مستقل في فاتورة الطلب، ولا تُضاف إلى عدد رموز النموذج المستدعي. ويتطلب النموذج المساعد المدفوع رصيدًا حتى عندما يكون النموذج المستدعي مجانيًا. للحصول على مراجعة بدلًا من تفويض العمل، استخدم [Advisor](./advisor).
