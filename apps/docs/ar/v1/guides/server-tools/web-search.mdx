أضف `phaseo:web_search` ليتمكن النموذج من البحث على الويب عندما يحتاج إلى معلومات حديثة أو موثّقة بالمصادر. يكتب النموذج الاستعلام ويمكنه البحث عدة مرات في الطلب الواحد؛ ويعيد Phaseo عناوين URL والعناوين والمقتطفات والنقاط البارزة، ونص الصفحة اختياريًا، ثم يكتب النموذج إجابة مستندة إلى المصادر.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What were the major AI announcements this week?" }
    ],
    "tools": [
      { "type": "phaseo:web_search" }
    ]
  }'
```

يعمل إدخال الأداة نفسه في `tools` على `/v1/responses` و`/v1/messages`.

<span id="parameters"></span>
## المعاملات

```json
{
  "type": "phaseo:web_search",
  "parameters": {
    "engine": "exa",
    "max_results": 5,
    "max_total_results": 15,
    "search_context_size": "medium",
    "max_characters": 2048,
    "allowed_domains": ["arxiv.org", "nature.com"],
    "include_highlights": true,
    "include_text": false
  }
}
```

| المعامل | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `engine` | string | `exa` | `auto` أو `native` أو `exa` أو `parallel` أو `firecrawl` أو `perplexity` أو `tinyfish` أو `deepseek`. راجع [اختيار المحرك](#choose-an-engine). |
| `mode` | string | الافتراضي للمحرك | طريقة بحث المحرك: أسرع، أو أعمق، أو جولة بحث معمّق. راجع [اختيار وضع](#choose-a-mode). |
| `max_results` | integer | `5` | عدد النتائج لكل استدعاء بحث، حتى `25`. |
| `max_total_results` | integer | `25` | عدد النتائج عبر جميع عمليات البحث في الطلب، حتى `100`. لا تقل أبدًا عن `max_results`. |
| `max_uses` | integer | `10` | عدد استدعاءات البحث لكل طلب، حتى `100`. |
| `search_context_size` | string | `medium` | `low` أو `medium` أو `high`، للمحركات التي تحدد حجم النقاط البارزة. |
| `max_characters` | integer | القيمة الافتراضية للمحرك | عدد أحرف النص لكل نتيجة عند تضمين النص. |
| `allowed_domains` | string[] | لا شيء | البحث في هذه النطاقات فقط. الاسم البديل: `include_domains`. |
| `excluded_domains` | string[] | لا شيء | استبعاد هذه النطاقات. الاسم البديل: `exclude_domains`. |
| `include_highlights` | boolean | `true` | تضمين النقاط البارزة أو المقتطفات من المحرك. |
| `include_text` | boolean | `false` | تضمين نص أكمل للصفحة حيث يدعمه المحرك. |
| `user_location` | object | لا شيء | تلميح للموقع. عندما تكون قيمة `engine` هي `native` يُمرَّر إلى بحث المزوّد نفسه، وإلا يستخدمه بحث Phaseo كلما لم يحدد استدعاء النموذج موقعًا. |

## ما يرسله النموذج

يحتوي كل استدعاء على `query`. ويمكن للنموذج أيضًا إرسال `max_results` و`engine` و`search_context_size` وقوائم النطاقات و`include_text` و`include_highlights` و`max_characters`، إضافة إلى تلميحات الترجمة المحلية التالية:

| الوسيط | الوصف |
| --- | --- |
| `user_location` | الموقع التقريبي. يستخدم Exa وPerplexity القيمة `user_location.country` (رمز من حرفين مثل `GB`) للبحث الإقليمي؛ ويستخدم TinyFish الدولة واللغة. |
| `language` | رمز لغة النتائج، مثل `en`، للمحركات التي تدعم الترجمة المحلية. ويضيفه DeepSeek إلى الاستعلام كمرشّح `lang:`. |
| `page` | صفحة النتائج من `0` إلى `10`، لـ TinyFish. |

تحل القيم التي يرسلها النموذج محل القيم الافتراضية للأداة في ذلك الاستدعاء. يبقى `max_results` محدودًا بما تبقى من `max_total_results`؛ وعندما ينفد، تعيد الاستدعاءات اللاحقة `max_total_results_reached`.

<span id="choose-an-engine"></span>
## اختيار المحرك

| المحرك | ما الذي يعمل |
| --- | --- |
| `exa` | بحث Exa المُدار. القيمة الافتراضية. |
| `auto` | المحرك المُدار الافتراضي، وهو Exa حاليًا. |
| `parallel` | بحث Parallel المُدار. |
| `firecrawl` | بحث Firecrawl المُدار. |
| `perplexity` | واجهة Perplexity Search API: نتائج مرتبة، و`search_context_size`، وبحث إقليمي من `user_location.country`. |
| `tinyfish` | TinyFish Search: نتائج مرتبة ومقسمة إلى صفحات ومخصصة محليًا. يعيد مقتطفات، لا نص الصفحة الكامل؛ استخدم [`phaseo:web_fetch`](./web-fetch) عندما يحتاج النموذج إلى المزيد. |
| `deepseek` | DeepSeek Search: نتائج مرتبة مع ملخص لكل صفحة، مكتوب ليقرأه النموذج. |
| `native` | أداة البحث على الويب الخاصة بالمزوّد، مثل `web_search_preview` من OpenAI أو `web_search_20250305` من Anthropic أو `deepseek_web_search` من DeepSeek. |

إذا لم يكن المحرك المُدار مفعّلًا، يعيد الاستدعاء `search_not_configured` إلى النموذج.

مع `engine: "native"` على `/v1/chat/completions` أو `/v1/responses`، لا يُرسل الطلب إلا إلى المزوّدين الذين ينفذون البحث على الويب بأنفسهم. إذا لم يقدّم أي منهم النموذج، يشغّل Phaseo محركه الافتراضي بدلًا من ذلك ويحتسبه بحثًا مُدارًا.

المزوّدون الذين ينفذون البحث على الويب بأنفسهم على نقاط النهاية هذه هم OpenAI وعمليات نشر Azure OpenAI على `/v1/responses` وxAI وDeepSeek على `deepseek/deepseek-v4.1-flash-1017`. لا يبحث DeepSeek بنفسه إلا عندما يكون البحث على الويب هو الأداة الوحيدة في الطلب، من دون قوائم نطاقات أو موقع للمستخدم، ومن دون مخرجات JSON أو `tool_choice` يفرض أداة. فواجهته البرمجية ترفض قوائم النطاقات والموقع ومخرجات JSON، وتوقف البحث على الويب عندما يحتوي الطلب على أدوات أخرى، ولا يمكنها فرض البحث. أما الطلبات الأخرى إلى ذلك النموذج فتستخدم بحث Phaseo بدلًا من ذلك، وهو يعمل جنبًا إلى جنب مع أدواتك الخاصة. وعند تفعيل الاستدلال، يجري DeepSeek بحثًا أعمق يفتح الصفحات ويقرؤها عبر عدة خطوات.

لا تستطيع أدوات البحث الخاصة بالمزوّدين فرض `max_results` أو `max_total_results`، ووحدها أداة Claude تفرض `max_uses`. إذا حدّد بحث أصلي حدًا لا يستطيع مزوّده فرضه، يعمل البحث على محرك Phaseo الافتراضي بدلًا من ذلك ويُحتسب كبحث مُدار.

إرسال أداة OpenAI الخاصة `{ "type": "web_search" }` يعمل بالطريقة نفسها كما في `engine: "native"`. اضبط `native` في تعريف الأداة فقط: إذا طلب النموذج `native` في استدعاء ما، يعيد الاستدعاء `unsupported_search_engine`، لأن أداة المزوّد يجب اختيارها قبل إرسال الطلب.

<span id="choose-a-mode"></span>
## اختيار وضع

عيّن `mode` في الأداة لاختيار طريقة بحث محركها. لا يستطيع النموذج تغييره، لذا لا يكلّف أي استدعاء أكثر من الوضع الذي اخترته. إذا انتقل النموذج إلى محرك آخر، يعمل ذلك المحرك بوضعه الافتراضي. أما الوضع غير المتاح للمحرك فيُرجع 400.

| المحرك | `mode` | ما الذي يعمل | السعر لكل استدعاء |
| --- | --- | --- | --- |
| `exa` | `lite` | بحث منخفض الكمون للدردشة والصوت | $0.004 |
| `exa` | `auto` (الافتراضي) | بحث متوازن | $0.007 |
| `exa` | `deep-lite` | بحث متعدد الخطوات خفيف، نحو 4 ثوانٍ | $0.012 |
| `exa` | `deep` | بحث متعدد الخطوات مع `answer` مُركّب، من 4 إلى 15 ثانية | $0.012 |
| `exa` | `agent-minimal` | جولة بحث من Exa Agent بأدنى جهد | $0.012 |
| `exa` | `agent-low` | جولة بحث من Exa Agent بجهد منخفض | $0.025 |
| `parallel` | `turbo`, `fast` | أسرع بحث لدى Parallel | $0.001 |
| `parallel` | `basic`, `advanced` (الافتراضي) | بحث Parallel الأعلى جودة | $0.005 |
| `parallel` | `task-lite` | جولة بحث من Parallel Task، من 10 إلى 60 ثانية | $0.005 |
| `parallel` | `task-base` | جولة بحث من Parallel Task، من 15 إلى 100 ثانية | $0.010 |
| `perplexity` | `standard` (الافتراضي) | Perplexity Search | $0.005 |
| `perplexity` | `fast` | Perplexity Fast Search | $0.001 |

تكلّف عمليات بحث Exa وParallel أيضًا $0.001 لكل نتيجة بعد أول 10 نتائج، ويحتسب Exa ‏$0.001 لكل صفحة عن كل نوع محتوى يُرجعه، فإضافة المقتطفات والنص إلى 5 نتائج تضيف $0.010. لا تملك `firecrawl` و`tinyfish` و`deepseek` أوضاعًا.

تُرجع أوضاع البحث المعمّق `answer` والصفحات التي يستشهد بها في `results`. وإذا لم تنتهِ جولة البحث بعد 120 ثانية تُرجع `research_timeout`. لا تُحتسب الجولات التي تنتهي مهلتها أو تفشل أو ينقطع عميلها.

## التصفية حسب النطاق

استخدم `allowed_domains` عندما يجب أن تأتي الإجابة من مجموعة ثابتة من المصادر، و`excluded_domains` لاستبعاد مواقع محددة من بحث مفتوح فيما عدا ذلك.

```json
{
  "type": "phaseo:web_search",
  "parameters": { "allowed_domains": ["phaseo.app", "github.com"] }
}
```

تتعامل المحركات مع القوائم بطرق مختلفة:

- **Perplexity** يقبل إحدى القائمتين، لا كلتيهما، وحتى 20 نطاقًا. تُرسل النطاقات المستبعدة بصيغة قائمة الحظر الخاصة به.
- **Firecrawl** يقبل إحدى القائمتين، لا كلتيهما.
- **TinyFish** يقبل القائمتين ويحوّلهما إلى عاملَي `site:` و`-site:` في الاستعلام.
- **DeepSeek** يقبل القائمتين ويحوّلهما إلى عاملَي `site:` و`-site:`. استعلاماته محدودة بـ 128 حرفًا، لذا يُقصَّر الاستعلام ليتسع للعوامل. وإذا تجاوزت قوائم النطاقات وحدها الحد، يعيد الاستدعاء `search_query_too_long`.

## ما تعيده الأداة

نتيجة JSON تتضمن المحرك والاستعلام ومصفوفة `results`. تحتوي كل نتيجة على `title` و`url` و`snippet` أو `highlights`، و`text` عندما يُطلب نص الصفحة ويوفّره المحرك.

## الاستخدام والتسعير

تضيف كل عملية بحث إلى `usage.server_tool_use`:

```json
{
  "usage": {
    "server_tool_use": {
      "web_search_requests": 1,
      "web_search_results": 5,
      "web_search_extra_results": 0
    }
  }
}
```

يحتسب Phaseo عمليات البحث على Exa وParallel وPerplexity وDeepSeek بما يدفعه Phaseo لكل محرك: الأسعار في [اختيار وضع](#choose-a-mode)، و$0.00075 لبحث DeepSeek، ولا يُحتسب إلا إذا أرجع نتائج. في Exa تكون الرسوم هي التكلفة التي يُبلغ عنها Exa للاستدعاء، أو سعره المُعلن عندما لا يُبلغ عن تكلفة. تظهر كل رسوم سطرًا في `pricing_lines` للطلب مع `engine` و`mode` و`price_source`. تُحتسب عمليات بحث Firecrawl بسعر $0.007، مع $0.001 لكل نتيجة بعد أول 10. لا تُحتسب عمليات البحث الفاشلة، وبحث TinyFish مجاني ضمن خططه المنشورة، لذا لا يضيف `engine: "tinyfish"` أي رسوم بحث. وتتطلب عمليات البحث على المحركات المدفوعة رصيدًا حتى عندما يكون النموذج مجانيًا. ويُحتسب البحث الأصلي عبر `native_web_search_requests` بالسعر المنشور لدى المزوّد: على سبيل المثال $10 لكل 1,000 عملية بحث لدى OpenAI وAnthropic، و$0.75 لكل 1,000 لدى DeepSeek، حيث تُحتسب فقط عمليات البحث التي تعيد نتائج. كما يحاسب DeepSeek على كل عملية جلب صفحة، أي قراءة عنوان URL بأداة قراءة الروابط، بمبلغ $0.75 لكل 1,000، ضمن `native_web_fetch_requests`. وعند تفعيل الاستدلال، قد تُجري إجابة واحدة من DeepSeek اثني عشر بحثًا أو أكثر، وتُضاف النتائج التي يقرؤها إلى رموز الإدخال.
