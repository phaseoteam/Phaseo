أضف `phaseo:web_search` ليتمكن النموذج من البحث على الويب عندما يحتاج إلى معلومات حديثة أو موثّقة بالمصادر. يكتب النموذج الاستعلام ويمكنه البحث عدة مرات في الطلب الواحد؛ ويعيد Phaseo عناوين URL والعناوين والمقتطفات والنقاط البارزة، ونص الصفحة اختياريًا، ثم يكتب النموذج إجابة مستندة إلى المصادر.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What were the major AI announcements this week?" }
    ],
    "tools": [
      { "type": "phaseo:web_search" }
    ]
  }'
```

يعمل إدخال الأداة نفسه في `tools` على `/v1/responses` و`/v1/messages`.

<span id="parameters"></span>
## المعاملات

```json
{
  "type": "phaseo:web_search",
  "parameters": {
    "engine": "exa",
    "max_results": 5,
    "max_total_results": 15,
    "search_context_size": "medium",
    "max_characters": 2048,
    "allowed_domains": ["arxiv.org", "nature.com"],
    "include_highlights": true,
    "include_text": false
  }
}
```

| المعامل | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `engine` | string | `exa` | `auto` أو `native` أو `exa` أو `parallel` أو `firecrawl` أو `perplexity` أو `tinyfish`. راجع [اختيار المحرك](#choose-an-engine). |
| `max_results` | integer | `5` | عدد النتائج لكل استدعاء بحث، حتى `25`. |
| `max_total_results` | integer | `25` | عدد النتائج عبر جميع عمليات البحث في الطلب، حتى `100`. لا تقل أبدًا عن `max_results`. |
| `max_uses` | integer | `10` | عدد استدعاءات البحث لكل طلب، حتى `100`. |
| `search_context_size` | string | `medium` | `low` أو `medium` أو `high`، للمحركات التي تحدد حجم النقاط البارزة. |
| `max_characters` | integer | القيمة الافتراضية للمحرك | عدد أحرف النص لكل نتيجة عند تضمين النص. |
| `allowed_domains` | string[] | لا شيء | البحث في هذه النطاقات فقط. الاسم البديل: `include_domains`. |
| `excluded_domains` | string[] | لا شيء | استبعاد هذه النطاقات. الاسم البديل: `exclude_domains`. |
| `include_highlights` | boolean | `true` | تضمين النقاط البارزة أو المقتطفات من المحرك. |
| `include_text` | boolean | `false` | تضمين نص أكمل للصفحة حيث يدعمه المحرك. |
| `user_location` | object | لا شيء | تلميح للموقع يُمرَّر إلى بحث المزوّد نفسه عندما تكون قيمة `engine` هي `native`. |

## ما يرسله النموذج

يحتوي كل استدعاء على `query`. ويمكن للنموذج أيضًا إرسال `max_results` و`engine` و`search_context_size` وقوائم النطاقات و`include_text` و`include_highlights` و`max_characters`، إضافة إلى تلميحات الترجمة المحلية التالية:

| الوسيط | الوصف |
| --- | --- |
| `user_location` | الموقع التقريبي. يستخدم Perplexity القيمة `user_location.country` للبحث الإقليمي؛ ويستخدم TinyFish الدولة واللغة. |
| `language` | رمز لغة النتائج، مثل `en`، للمحركات التي تدعم الترجمة المحلية. |
| `page` | صفحة النتائج من `0` إلى `10`، لـ TinyFish. |

تحل القيم التي يرسلها النموذج محل القيم الافتراضية للأداة في ذلك الاستدعاء. يبقى `max_results` محدودًا بما تبقى من `max_total_results`؛ وعندما ينفد، تعيد الاستدعاءات اللاحقة `max_total_results_reached`.

<span id="choose-an-engine"></span>
## اختيار المحرك

| المحرك | ما الذي يعمل |
| --- | --- |
| `exa` | بحث Exa المُدار. القيمة الافتراضية. |
| `auto` | المحرك المُدار الافتراضي، وهو Exa حاليًا. |
| `parallel` | بحث Parallel المُدار. |
| `firecrawl` | بحث Firecrawl المُدار. |
| `perplexity` | واجهة Perplexity Search API: نتائج مرتبة، و`search_context_size`، وبحث إقليمي من `user_location.country`. |
| `tinyfish` | TinyFish Search: نتائج مرتبة ومقسمة إلى صفحات ومخصصة محليًا. يعيد مقتطفات، لا نص الصفحة الكامل؛ استخدم [`phaseo:web_fetch`](./web-fetch) عندما يحتاج النموذج إلى المزيد. |
| `native` | أداة البحث على الويب الخاصة بالمزوّد، مثل `web_search_preview` من OpenAI أو `web_search_20250305` من Anthropic. |

إذا لم يكن المحرك المُدار مفعّلًا، يعيد الاستدعاء `search_not_configured` إلى النموذج.

مع `engine: "native"` على `/v1/chat/completions` أو `/v1/responses`، لا يُرسل الطلب إلا إلى المزوّدين الذين ينفذون البحث على الويب بأنفسهم. إذا لم يقدّم أي منهم النموذج، يشغّل Phaseo محركه الافتراضي بدلًا من ذلك ويحتسبه بحثًا مُدارًا. اضبط `native` في تعريف الأداة فقط: إذا طلب النموذج `native` في استدعاء ما، يعيد الاستدعاء `unsupported_search_engine`، لأن أداة المزوّد يجب اختيارها قبل إرسال الطلب.

## التصفية حسب النطاق

استخدم `allowed_domains` عندما يجب أن تأتي الإجابة من مجموعة ثابتة من المصادر، و`excluded_domains` لاستبعاد مواقع محددة من بحث مفتوح فيما عدا ذلك.

```json
{
  "type": "phaseo:web_search",
  "parameters": { "allowed_domains": ["phaseo.app", "github.com"] }
}
```

تتعامل المحركات مع القوائم بطرق مختلفة:

- **Perplexity** يقبل إحدى القائمتين، لا كلتيهما، وحتى 20 نطاقًا. تُرسل النطاقات المستبعدة بصيغة قائمة الحظر الخاصة به.
- **Firecrawl** يقبل إحدى القائمتين، لا كلتيهما.
- **TinyFish** يقبل القائمتين ويحوّلهما إلى عاملَي `site:` و`-site:` في الاستعلام.

## ما تعيده الأداة

نتيجة JSON تتضمن المحرك والاستعلام ومصفوفة `results`. تحتوي كل نتيجة على `title` و`url` و`snippet` أو `highlights`، و`text` عندما يُطلب نص الصفحة ويوفّره المحرك.

## الاستخدام والتسعير

تضيف كل عملية بحث إلى `usage.server_tool_use`:

```json
{
  "usage": {
    "server_tool_use": {
      "web_search_requests": 1,
      "web_search_results": 5,
      "web_search_extra_results": 0
    }
  }
}
```

يُحتسب البحث المُدار عبر `server_tool_web_search_requests` و`server_tool_web_search_extra_results`. ويُحتسب البحث الأصلي عبر `native_web_search_requests` حيث تحدده بطاقة سعر النموذج. TinyFish Search مجاني ضمن خططه المنشورة، لذا لا يضيف Phaseo رسوم بحث على `engine: "tinyfish"`؛ ويبقى تسعير الرموز المعتاد للطلب ساريًا.
