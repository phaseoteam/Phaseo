أضف `phaseo:image_generation` ليتمكن النموذج من إنشاء صورة أثناء إجابته. يكتب النموذج موجّه الصورة؛ ويستدعي Phaseo نموذج الصور ويعيد الصورة إلى حلقة النموذج.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Design a wide product concept image for a compact desktop synthesizer.",
    "tools": [
      {
        "type": "phaseo:image_generation",
        "parameters": {
          "model": "openai/gpt-image-2",
          "quality": "high",
          "aspect_ratio": "16:9",
          "output_format": "png"
        }
      }
    ]
  }'
```

## المعاملات

كل المعاملات اختيارية.

| المعامل | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `model` | string | `openai/gpt-image-2` | نموذج الصور. عند ضبطه هنا، يتجاوز أي نموذج يطلبه النموذج الرئيسي. |
| `quality` | string | افتراضي المزوّد | تلميح للجودة، مثل `low` أو `medium` أو `high`. |
| `size` | string | افتراضي المزوّد | تلميح لحجم الصورة. |
| `aspect_ratio` | string | افتراضي المزوّد | نسبة العرض إلى الارتفاع، مثل `1:1` أو `16:9` أو `9:16`. |
| `background` | string | افتراضي المزوّد | تلميح لوضع الخلفية. |
| `output_format` | string | افتراضي المزوّد | `png` أو `jpeg` أو `webp`. |
| `output_compression` | integer | افتراضي المزوّد | تلميح للضغط، مقيّد بين `0` و`100`. |
| `moderation` | string | افتراضي المزوّد | تلميح للإشراف لدى المزوّد. |

## ما يرسله النموذج

`prompt` (أو `description`، ويُعامل بالطريقة نفسها). يمكنه أيضًا إرسال `model`، الذي لا يُستخدم إلا عندما لا تحدد الأداة نموذجًا، وأيًا من المعاملات الأخرى أعلاه، التي تحل محل قيم الأداة لذلك الاستدعاء.

## ما تعيده الأداة

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "imageUrl": "https://...",
  "mime_type": "image/png"
}
```

تعيد بعض المزوّدات `b64_json` مع بيانات صورة بترميز base64 بدلًا من `imageUrl`. إذا لم يتضمن الاستدعاء موجّهًا، يحصل النموذج على `image_generation_invalid_request`؛ وإذا فشل نموذج الصور، على `image_generation_failed`.

## الاستخدام والتسعير

تضيف كل صورة 1 إلى `usage.server_tool_use.image_generation_requests` ويمكن احتسابها عبر `server_tool_image_generation_requests`. يُحتسب نموذج الصور بأسعاره، كبند مستقل في فاتورة الطلب. ويتطلب نموذج الصور المدفوع رصيدًا حتى عندما يكون النموذج المستدعي مجانيًا.
