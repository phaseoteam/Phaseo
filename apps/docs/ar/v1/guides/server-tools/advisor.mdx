أضف `phaseo:advisor` ليتمكن النموذج الرئيسي من طلب مراجعة أو خطة أو فحص منطقي أو رأي متخصص من نموذج ثانٍ قبل أن يجيب. يستدعي النموذج الرئيسي Advisor كأي أداة؛ ويشغّل Phaseo نموذج Advisor ويعيد نصيحته كنتيجة للأداة.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Design a rate limiter for a distributed API gateway." }
    ],
    "tools": [
      {
        "type": "phaseo:advisor",
        "parameters": {
          "model": "anthropic/claude-opus-5",
          "max_uses": 1,
          "max_completion_tokens": 1400
        }
      }
    ]
  }'
```

يعمل Advisor مع أي نموذج نصي مدعوم. يشغّله Phaseo بنفسه؛ ولا يُحوَّل إلى أداة Advisor الأصلية في Anthropic إلا إذا أرسلت شكل الأداة الأصلي الخاص بـ Anthropic.

## المعاملات

```json
{
  "type": "phaseo:advisor",
  "parameters": {
    "name": "reviewer",
    "model": "anthropic/claude-opus-5",
    "instructions": "Review plans for correctness, missing edge cases, and implementation risk.",
    "forward_transcript": true,
    "max_uses": 2,
    "max_completion_tokens": 1400,
    "reasoning": { "effort": "high" },
    "temperature": 0.2
  }
}
```

| المعامل | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `name` | string | لا يوجد | من 1 إلى 64 حرفًا أو رقمًا أو مسافة أو شرطة سفلية أو شرطة. مطلوب عند إضافة أكثر من Advisor واحد. |
| `model` | string | انظر أدناه | نموذج Advisor. |
| `instructions` | string | تعليمات Advisor المدمجة | تعليمات إضافية لـ Advisor. |
| `forward_transcript` | boolean | `false` | يرسل المحادثة الحالية إلى Advisor. |
| `max_uses` | integer | `1` | عدد استدعاءات هذا Advisor في كل طلب. |
| `max_completion_tokens` | integer | `1400` | توكنات الإخراج لكل رد من Advisor. تُرفع القيم الأقل من `1024` إلى `1024`. يُقبل `max_tokens` كاسم مستعار أقدم. |
| `reasoning` | object | افتراضي المزوّد | إعدادات الاستدلال، تُمرَّر حيث يدعمها نموذج Advisor. |
| `temperature` | number | افتراضي المزوّد | درجة حرارة أخذ العينات لاستدعاء Advisor. |

نموذج Advisor هو `parameters.model` إن كان معيّنًا؛ وإلا فـ `model` الذي يرسله النموذج الرئيسي في استدعائه؛ وإلا فنموذج الطلب نفسه.

## ما يرسله النموذج

عادةً `prompt`. إذا لم تثبّت الأداة نموذجًا، يمكن للاستدعاء أيضًا اختيار نموذج:

```json
{
  "model": "anthropic/claude-opus-5",
  "prompt": "Check this security design for missing controls."
}
```

مع `forward_transcript: true`، يمكن للنموذج استدعاء Advisor دون موجّه، ويراجع Advisor المحادثة المُمرَّرة.

## إضافة عدة مستشارين

أضف إدخال `phaseo:advisor` واحدًا لكل مستشار. يصبح كل Advisor مسمّى أداة مستقلة للنموذج، مثل `phaseo_advisor_security_reviewer`.

```json
{
  "tools": [
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "security-reviewer",
        "model": "anthropic/claude-opus-5",
        "instructions": "Review for vulnerabilities, abuse cases, and missing mitigations."
      }
    },
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "architect",
        "model": "openai/gpt-5",
        "instructions": "Review system design tradeoffs and operational risks."
      }
    }
  ]
}
```

يجب أن تكون الأسماء فريدة بعد إزالة المسافات المحيطة ودون تمييز حالة الأحرف، ويمكن لإدخال واحد على الأكثر أن يحذف `name`؛ وإلا يُرفض الطلب. مع عدة مستشارين، يفرض `tool_choice: "phaseo:advisor"` استخدام الأول.

## ما تعيده الأداة

```json
{
  "status": "ok",
  "name": "reviewer",
  "model": "anthropic/claude-opus-5",
  "advice": "Start with a smaller migration slice and define rollback criteria before changing traffic routing."
}
```

إذا تعذّر تشغيل الاستدعاء، يحصل النموذج على نتيجة خطأ بدلًا من ذلك: `advisor_invalid_request` (لا يوجد موجّه أو نموذج)، أو `advisor_max_uses_exceeded`، أو `advisor_request_failed`.

لا يحتفظ Advisor بأي حالة بين الطلبات. إذا أعدت تشغيل الرسائل ونتائج الأدوات السابقة، يرى النموذج الرئيسي النصيحة السابقة؛ ولا يرى Advisor المحادثة إلا عند تفعيل `forward_transcript`. لا تُبث النصيحة، ولا يستطيع Advisor استدعاء الأدوات بنفسه.

## الاستخدام والتسعير

يضيف كل استدعاء 1 إلى `usage.server_tool_use.advisor_requests` ويمكن احتسابه عبر `server_tool_advisor_requests`. تُحتسب رموز Advisor بأسعار نموذج Advisor نفسه، كبند مستقل في فاتورة الطلب، ولا تُضاف إلى عدد رموز النموذج المستدعي. ويتطلب نموذج Advisor المدفوع رصيدًا حتى عندما يكون النموذج المستدعي مجانيًا.
