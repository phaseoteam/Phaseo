title: "تطبيق التصحيح"

---

أضف `phaseo:apply_patch` على `/v1/responses` لتحصل على تغييرات الملفات كعمليات تصحيح منظمة. يتحقق Phaseo من شكل كل عملية ويعيدها؛ ولا يمس ملفاتك أبدًا. يقرر تطبيقك ما إذا كان سيطبّق التصحيح، أو يعرضه على مستخدم، أو يرفضه، أو يطلب مراجعة.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Create a small README patch for this project.",
    "tools": [
      { "type": "phaseo:apply_patch" }
    ]
  }'
```

على `/v1/chat/completions` أو `/v1/messages`، يُرفض الطلب.

## المعاملات

لا يوجد. أضف `{ "type": "phaseo:apply_patch" }` كما هو.

## ما يرسله النموذج

كائن `operation`:

```json
{
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  }
}
```

| `type` | الحقول المطلوبة | قواعد الفرق |
| --- | --- | --- |
| `create_file` | `path`، `diff` | يبدأ كل سطر غير فارغ بـ `+` |
| `update_file` | `path`، `diff` | يبدأ كل سطر غير فارغ بـ `@@` أو مسافة أو `+` أو `-` |
| `delete_file` | `path` | لا يوجد |

لا يمكن أن يحتوي `path` على بايتات فارغة.

## ما تعيده الأداة

```json
{
  "status": "completed",
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  },
  "message": "Patch operation validated. The client must apply or reject this patch and report the result."
}
```

العملية التي تخالف القواعد أعلاه تعيد `apply_patch_invalid_operation` مع السبب، حتى يتمكن النموذج من المحاولة مرة أخرى.

## الاستخدام والتسعير

يضيف كل استدعاء 1 إلى `usage.server_tool_use.apply_patch_requests` ويمكن احتسابه باستخدام `server_tool_apply_patch_requests`.
