أضف `phaseo:web_fetch` ليتمكن النموذج من قراءة عنوان URL معروف، مثل صفحة توثيق أو مقالة أو سجل تغييرات. يقدّم النموذج `url`، فيجلب Phaseo الصفحة ويعيد نصها مقتطعًا ضمن حد للحجم، ويمكن للنموذج جلب صفحات أخرى قبل أن يجيب.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Summarize https://phaseo.app/docs/v1/guides/tool-calling" }
    ],
    "tools": [
      { "type": "phaseo:web_fetch" }
    ]
  }'
```

<span id="parameters"></span>
## المعاملات

```json
{
  "type": "phaseo:web_fetch",
  "parameters": {
    "engine": "direct",
    "max_chars": 12000,
    "allowed_domains": ["phaseo.app"],
    "blocked_domains": ["internal.example.com"]
  }
}
```

| المعامل | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `engine` | string | `direct` | `auto` أو `native` أو `direct` أو `exa` أو `parallel` أو `firecrawl`. راجع [اختيار المحرك](#choose-an-engine). |
| `max_chars` | integer | `12000` | عدد أحرف نص الصفحة المُعادة إلى النموذج، حتى `100000`. |
| `max_content_tokens` | integer | لا شيء | يُستخدم بدلًا من `max_chars` عند حذف `max_chars`. وهو أيضًا حد الحجم لمحرك `native`. |
| `max_uses` | integer | `10` | عدد استدعاءات الجلب لكل طلب، حتى `100`. |
| `allowed_domains` | string[] | لا شيء | الجلب من هذه النطاقات فقط. يمكن للنموذج تضييق هذه القائمة في استدعاء ما، لكن لا يمكنه توسيعها. |
| `blocked_domains` | string[] | لا شيء | عدم الجلب من هذه النطاقات أبدًا. الاسم البديل: `excluded_domains`. |

## ما يرسله النموذج

يحتوي كل استدعاء على `url`. ويمكن للنموذج أيضًا إرسال `engine` و`max_chars` و`max_content_tokens` وقوائم النطاقات.

<span id="choose-an-engine"></span>
## اختيار المحرك

| المحرك | ما الذي يعمل |
| --- | --- |
| `auto` | الجلب الأصلي من Anthropic على `/v1/messages`. على نقاط النهاية الأخرى، Exa عندما يكون مفعّلًا، وإلا `direct`. |
| `direct` | يجلب Phaseo الصفحة بنفسه ويحوّل HTML إلى نص عادي. |
| `exa` | استخراج المحتوى من Exa. |
| `parallel` | Parallel Extract. |
| `firecrawl` | Firecrawl Scrape. |
| `native` | أداة `web_fetch_20260209` من Anthropic، على `/v1/messages` فقط. على نقاط النهاية الأخرى يُرفض الطلب؛ استخدم `direct` أو محركًا مُدارًا. |

إذا لم يكن المحرك المُدار مفعّلًا، يعيد الاستدعاء `fetch_not_configured` إلى النموذج.

لا تعمل إلا عناوين URL من نوع HTTP(S). يقبل `direct` أنواع المحتوى النصية فقط، مثل HTML والنص العادي وJSON، ويعيد `unsupported_content_type` لأي نوع آخر. ويتبع حتى 5 عمليات إعادة توجيه ويتحقق من كل واحدة منها مقابل قوائم النطاقات لديك.

### جلب Anthropic الأصلي

```json
{
  "model": "anthropic/claude-sonnet-4.6",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "Read the docs page and summarize the limits." }
  ],
  "tools": [
    {
      "type": "phaseo:web_fetch",
      "parameters": {
        "engine": "native",
        "max_content_tokens": 9000,
        "allowed_domains": ["phaseo.app"]
      }
    }
  ],
  "tool_choice": { "type": "tool", "name": "phaseo:web_fetch" }
}
```

## ما تعيده الأداة

```json
{
  "provider": "fetch",
  "engine": "direct",
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "text": "...",
  "truncated": false,
  "returned_chars": 8421
}
```

تحقق من `truncated` قبل افتراض أن النموذج رأى الصفحة كاملة. للاطلاع على مثال عملي، راجع [إسناد الأدوات باستخدام Web Fetch](../../cookbook/tool-grounding-with-web-fetch).

## الاستخدام والتسعير

يضيف كل جلب 1 إلى `usage.server_tool_use.web_fetch_requests`. يحاسب Phaseo كل جلب مُدار عبر Exa أو Parallel أو Firecrawl بمبلغ $0.001، ما لم تحدد بطاقة سعر النموذج سعرها الخاص لـ `server_tool_web_fetch_requests`؛ والجلب المباشر مجاني. وتتطلب عمليات الجلب عبر المحركات المدفوعة رصيدًا حتى عندما يكون النموذج مجانيًا. ويُحتسب الجلب الأصلي عبر `native_web_fetch_requests` حيث تحدده بطاقة سعر النموذج.
