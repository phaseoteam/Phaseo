اختر مشروعًا نموذجيًا لتشغيله محليًا وتعديله. لاستدعاء API واحد استخدم [البدء السريع](../quickstart.mdx)، ولميزة محددة تصفّح [دليل الوصفات](../cookbook/index.mdx).

## مشاريع قابلة للتشغيل

| ما تبنيه | الشرح التفصيلي | المصدر |
| --- | --- | --- |
| محادثة في المتصفح مع مفتاح API على الخادم | [محادثة Next.js](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| تفويض OAuth ووكيل على الخادم الخلفي | [منصة عمل OAuth](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| تكامل REST بسيط | [تطبيق Node للاختبار السريع](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| تطبيق سطر أوامر بلغة Python | [Python CLI](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| تطبيق يستخدم Vercel AI SDK | [تكامل AI SDK](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

أبقِ بيانات الاعتماد على الخادم، وراجع متغيرات البيئة في المثال، وتحقّق من أسعار النموذج المختار قبل تشغيله. لا تتطلب الأمثلة التي تستخدم نماذج `:free` إيداع أرصدة.

## طلبات حسب اللغة

يحتوي [مرجع Client SDK](../sdk-reference/client/overview.mdx) على أمثلة التثبيت والطلبات حسب اللغة. استخدم [مرجع توليد الصور](../api-reference/endpoint/images-generations.mdx) لمعاملات الصور و[Chat Completions](../api-reference/endpoint/chat-completions.mdx) لطلبات المحادثة.

ليتمكن وكيل برمجة من إنشاء هيكل مشروع، استخدم [موجّهات بدء التطبيقات المصغّرة](../cookbook/mini-app-starter-prompts.mdx) وراجع الشيفرة المولَّدة قبل استخدامها مع بيانات اعتماد حقيقية.
