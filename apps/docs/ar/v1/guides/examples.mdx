اختر مشروعًا نموذجيًا لتشغيله محليًا وتعديله. لاستدعاء API واحد استخدم [البدء السريع](../quickstart.mdx)، ولميزة محددة راجع [دليل الوصفات](../cookbook/index.mdx).

## مشاريع قابلة للتشغيل

| المشروع | الشرح | المصدر |
| --- | --- | --- |
| دردشة متصفح بمفتاح API على الخادم | [دردشة Next.js](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| تفويض OAuth ووكيل خادم خلفي | [بيئة عمل OAuth](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| تكامل REST بسيط | [تطبيق اختبار Node](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| تطبيق Python لسطر الأوامر | [Python CLI](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| تطبيق يستخدم Vercel AI SDK | [تكامل AI SDK](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

احتفظ ببيانات الاعتماد على الخادم، وراجع متغيرات بيئة المثال وتحقق من تسعير النموذج قبل تشغيله. لا تتطلب أمثلة نماذج `:free` رصيدًا مودعًا.

## طلبات بحسب اللغة

يتضمن [مرجع SDK العميل](../sdk-reference/typescript/overview.mdx) أمثلة التثبيت والطلبات بحسب اللغة. استخدم [مرجع توليد الصور](../api-reference/endpoint/images-generations.mdx) لمعلمات الصور و[Chat Completions](../api-reference/endpoint/chat-completions.mdx) لطلبات الدردشة.

ليُنشئ وكيل برمجة هيكل مشروع، استخدم [موجّهات بدء التطبيقات المصغرة](../cookbook/mini-app-starter-prompts.mdx) وراجع الكود المولّد قبل استخدام بيانات اعتماد حقيقية.
