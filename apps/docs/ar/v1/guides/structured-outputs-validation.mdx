حتى عند تقييد التوليد بمخطط، تحقّق دائمًا من المخرجات على خادمك.

## المسار الموصى به

1. اطلب مخرجات مقيّدة بمخطط.
2. حلّل JSON.
3. تحقّق منه باستخدام مخطط الخادم.
4. أعد المحاولة مرة واحدة بتوجيه تصحيحي إذا كانت غير صالحة.
5. إذا بقيت غير صالحة، فانتقل إلى معالجة آمنة للإخفاق.

## مثال على التحقق (TypeScript)

```typescript
import { z } from "zod";

const Summary = z.object({
  order_id: z.string(),
  total_usd: z.number(),
  status: z.enum(["pending", "paid", "failed"]),
});

function parseStructuredContent(content: string) {
  const data = JSON.parse(content);
  return Summary.parse(data);
}
```

## توجيه تصحيحي لإعادة المحاولة

عند فشل التحقق، أرسل تعليمات تصحيحية موجزة:

`لم تطابق مخرجاتك السابقة المخطط. أعد JSON صالحًا فقط، مع الحقول المطلوبة ومن دون مفاتيح إضافية.`

## إرشادات الإنتاج

- احتفظ بمخطط لكل حالة استخدام وأدر إصداراته.
- تتبّع معدلات فشل التحقق حسب معرّف النموذج.
- أطلق تنبيهًا عند الارتفاع المفاجئ في إخفاقات المخطط بعد تغييرات النموذج.
