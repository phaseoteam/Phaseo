ضع معرّف مزوّد ونقطتين أمام معرّف النموذج، مثل `baseten:thinking-machines/inkling-small`، لتشغيل الطلب على ذلك المزوّد فقط، دون الرجوع إلى مزوّد آخر.

| ما تريده | ما ترسله في `model` |
| --- | --- |
| أن يختار Phaseo مزوّدًا وينتقل بين المزوّدين عند الفشل | `thinking-machines/inkling-small` |
| Baseten فقط، دون رجوع إلى مزوّد آخر | `baseten:thinking-machines/inkling-small` |
| مسار مجاني واحد مُتحقَّق منه لدى مزوّد واحد | `google-ai-studio:google/gemma-4-26b-a4b:free` |

الصيغة هي `<provider-id>:<canonical-model-id>`. تفصل النقطتان الأوليان المزوّد؛ أما النقطتان بعد نطاق أسماء النموذج فتبقيان جزءًا من معرّف النموذج. في `google-ai-studio:google/gemma-4-26b-a4b:free`، المزوّد هو `google-ai-studio` والنموذج هو `google/gemma-4-26b-a4b:free`.

إذا كنت تفضّل مزوّدًا فقط وتريد الرجوع إلى بديل عند فشله، فاستخدم معرّف النموذج العادي مع [عناصر التحكم في التوجيه والبدائل](./routing-and-fallbacks.mdx) بدلًا من ذلك.

## أرسل طلبًا

استخدم المعرّف المقيّد في أي مكان تقبل فيه نقطة النهاية معرّف نموذج.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "baseten:thinking-machines/inkling-small",
    "input": "Explain mixture-of-experts routing in two sentences."
  }'
```

```javascript JavaScript
const response = await fetch("https://api.phaseo.app/v1/responses", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "baseten:thinking-machines/inkling-small",
    input: "Explain mixture-of-experts routing in two sentences.",
  }),
});

const result = await response.json();
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/responses",
    headers={
        "Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "model": "baseten:thinking-machines/inkling-small",
        "input": "Explain mixture-of-experts routing in two sentences.",
    },
)

result = response.json()
```
</CodeGroup>

## ما يجب أن يجتازه المزوّد مع ذلك

يضيّق المقيِّد التوجيه إلى مزوّد واحد؛ ولا يتخطى أي فحص آخر. يجب أن يظل المزوّد:

- يخدم النموذج المرجعي على نقطة النهاية المطلوبة، مع تفعيل تلك القدرة
- مستوفيًا لقيود مساحة العمل ومفتاح API والإعداد المسبق والخصوصية
- داعمًا لفئة الخدمة والمعاملات المطلوبة
- مضبوط التسعير

إذا فشل أي فحص، يُرفض الطلب. لا يختار Phaseo مزوّدًا آخر بصمت أبدًا.

## ادمجه مع حقول `provider` أو `routing`

يجب أن يتوافق المقيِّد مع أي حقول توجيه صريحة. يُقبل `provider.only` أو `routing.only` المطابق:

```json
{
  "model": "baseten:thinking-machines/inkling-small",
  "provider": { "only": ["baseten"] }
}
```

تُرفض قائمة السماح التي تسمّي مزوّدين آخرين، أو قائمة التجاهل التي تحتوي على المزوّد المقيِّد، بالخطأ `provider_qualified_model_conflict`:

```json
{
  "model": "baseten:thinking-machines/inkling-small",
  "provider": { "only": ["deepinfra"] }
}
```

## اطلب مسارًا مجانيًا لدى مزوّد واحد

لا يُقبل نموذج `:free` مقيّد إلا عندما يكون لدى ذلك المزوّد مسار مجاني مؤهل للنموذج ونقطة النهاية. لا يعني نموذج `:free` المرجعي أن كل مزوّد للنموذج الأساسي يقدّمه مجانًا.

```json
{
  "model": "google-ai-studio:google/gemma-4-26b-a4b:free",
  "input": "Hello"
}
```

يجب ألا تكون بطاقة أسعار المسار فارغة، ويجب أن تكون كل قاعدة تسعير حالية عليها موسومة بـ `free` ومسعّرة بالصفر تمامًا. يؤدي التسعير المفقود أو المدفوع أو المختلط أو السالب، أو قاعدة مسعّرة بالصفر غير موسومة بـ `free`، إلى رفض الطلب قبل وصوله إلى المزوّد.

## معرّفات المزوّدين وأسماؤهم البديلة

استخدم معرّف مزوّد من كتالوج مزوّدي Phaseo (راجع [مزوّدو API](../exploring/api-providers)). تُحوَّل المعرّفات إلى أحرف صغيرة، وتُربط الأسماء البديلة القديمة أو التجارية المعروفة بالمعرّف المرجعي: يصبح كل من `NovitaAI` و`novita-ai` القيمة `novita`. تُرفض المعرّفات المشوّهة وغير المعروفة قبل اختيار المزوّد؛ ولا تُرسل أبدًا إلى المزوّد كجزء من اسم النموذج.

## أخطاء التحقق

يعيد المعرّف المقيّد غير الصالح رمز HTTP `400` مع رمز الخطأ `validation_error`. يبيّن `reason` و`details[].keyword` السبب:

| السبب | المعنى |
| --- | --- |
| `invalid_provider_slug` | جزء المزوّد فارغ أو يحتوي على أحرف غير مدعومة. |
| `unknown_provider_slug` | معرّف المزوّد سليم الصيغة لكنه ليس مزوّدًا في Phaseo. |
| `invalid_provider_qualified_model` | لا يطابق المعرّف `<provider>:<publisher>/<model>`. |
| `provider_qualified_model_conflict` | يتعارض `provider.only` أو `provider.ignore` أو `routing.only` أو `routing.ignore` مع المقيِّد. |
| `qualified_provider_unavailable` | المزوّد موجود لكنه لا يخدم ذلك النموذج على نقطة النهاية المطلوبة. |
| `qualified_free_provider_unavailable` | لم يُتحقَّق من أن مسار المزوّد مجاني بتسعير صفري بالكامل. |

```json
{
  "error": "validation_error",
  "status_code": 400,
  "reason": "unknown_provider_slug",
  "description": "Unknown provider slug \"not-a-provider\" in provider-qualified model \"not-a-provider:publisher/model\". Use a provider slug returned by Phaseo's provider catalogue.",
  "provider": "not-a-provider",
  "model": "publisher/model",
  "details": [
    {
      "path": ["model"],
      "keyword": "unknown_provider_slug"
    }
  ]
}
```

لأشكال الأخطاء الأخرى، راجع [الأخطاء وتصحيحها](../api-reference/errors.mdx).
