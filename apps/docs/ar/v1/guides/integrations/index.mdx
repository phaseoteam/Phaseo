تعمل معظم عمليات التكامل بتوجيه عميل متوافق مع OpenAI أو Anthropic إلى Phaseo واستخدام مفتاح API الخاص به. ابدأ بدليل الأداة التي تستخدمها بالفعل.

## عناوين URL الأساسية

| نمط العميل | عنوان URL الأساسي |
| --- | --- |
| عملاء متوافقون مع OpenAI | `https://api.phaseo.app/v1` |
| عملاء متوافقون مع Anthropic | `https://api.phaseo.app` |

استخدم معرّفات النماذج من [نقطة النهاية Models](../../api-reference/endpoint/models.mdx). للتطبيقات الجديدة بأسلوب OpenAI، يُفضّل [Responses](../../api-reference/endpoint/responses.mdx). أما المكتبات الأقدم، فعادةً ما تكون [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) الخيار الأكثر أمانًا.

## الإعدادات الموصى بها

- اضبط `PHASEO_API_KEY` مرة واحدة واربطها بمتغير البيئة الذي يتوقعه العميل.
- أبقِ معرّف النموذج كما هو، مثل `openai/gpt-5-nano`.
- استخدم `https://api.phaseo.app/v1` للمكتبات المتوافقة مع OpenAI، ما لم تطلب الأداة صراحةً المضيف الجذر.
- استخدم `https://api.phaseo.app` لحزم SDK والأدوات المتوافقة مع Anthropic التي تضيف `/v1/messages`.
- اختبر البث واستدعاء الأدوات في بيئة ما قبل الإنتاج قبل نقل حركة الوكلاء.
