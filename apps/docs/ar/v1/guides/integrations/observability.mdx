تتبّع طلبات Phaseo بطريقتين: فعّل [البث](../broadcast.mdx) ليرسل Phaseo تتبّعًا لكل طلب إلى Langfuse أو LangSmith أو أي أداة OpenTelemetry دون تغيير في الكود، أو أبقِ مكتبة التتبّع في تطبيقك ووجّه عميل النموذج فيها إلى Phaseo.

| | البث | التتبّع في تطبيقك |
| --- | --- | --- |
| مصدر التتبّعات | Phaseo، لكل طلب | عميل النموذج في تطبيقك |
| تغيير الكود | لا شيء؛ يُعدّ في **الإعدادات → البث** | غلّف العميل، ثم غيّر Base URL الخاص به |
| محتوى التتبّع | النموذج والمزوّد وكل محاولة لدى المزوّد والتوكنات والتكلفة والتوقيت، و(اختياريًا) الموجّه والمخرجات | كل ما تسجّله مكتبتك، إضافةً إلى سياق تطبيقك |

## Langfuse مع OpenAI SDK

أبقِ غلاف OpenAI الخاص بـ Langfuse وزوّد العميل المغلّف بـ Base URL الخاص بـ Phaseo:

```bash
pip install langfuse openai
```

```python
import os
from langfuse.openai import openai

client = openai.OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Reply with only: ok",
)
```

## LangSmith مع LangChain

استخدم إعداد `ChatOpenAI` من [LangChain](./langchain.mdx) وفعّل LangSmith بمتغيرات البيئة المعتادة في LangChain:

```bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your_langsmith_key"
export PHASEO_API_KEY="your_phaseo_key"
```

## OpenTelemetry

إذا كان إطار العمل لديك يُصدر مقاطع OpenTelemetry بالفعل، فلا تحتاج إلى مُصدِّر خاص. أضف سياق الطلب هذا إلى مقاطعك بنفسك:

- معرّف النموذج؛
- نقطة النهاية، مثل `responses` أو `chat.completions`؛
- معرّف طلب Phaseo، من بيانات الاستجابة الوصفية أو من [السجلات](../../api-reference/endpoint/activity.mdx)؛
- المزوّد الذي خدم الطلب، عندما تكون بيانات الاستجابة الوصفية مفعّلة.

لا تسجّل أبدًا مفاتيح API من Phaseo كسمات للمقاطع.
