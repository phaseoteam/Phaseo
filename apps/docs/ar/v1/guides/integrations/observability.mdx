تعمل معظم أدوات قابلية الرصد فوق عميل النموذج. احتفظ بإعداد التتبّع كما هو، ووجّه عميل OpenAI أو Anthropic الأساسي إلى Phaseo.

## Langfuse مع OpenAI SDK

```bash
pip install langfuse openai
```

```python
import os
from langfuse.openai import openai

client = openai.OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-5-nano",
    input="Reply with only: ok",
)
```

## LangSmith مع LangChain

استخدم إعداد [LangChain](./langchain.mdx) وفعّل LangSmith عبر متغيرات بيئة LangChain المعتادة:

```bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your_langsmith_key"
export PHASEO_API_KEY="your_phaseo_key"
```

## OpenTelemetry

إذا كان إطار العمل لديك يصدر مقاطع OpenTelemetry، فلا تتطلب Phaseo مُصدّرًا خاصًا. أضف سياق الطلب المفيد بنفسك:

- معرّف النموذج
- نقطة النهاية، مثل `responses` أو `chat.completions`
- معرّف طلب Phaseo من بيانات الاستجابة الوصفية أو السجلات
- المزوّد المحدد عند تفعيل بيانات الاستجابة الوصفية

## ملاحظات

- لا ترسل مفاتيح API الخاصة بـ Phaseo إلى أدوات قابلية الرصد كسمات.
- إذا كانت مكتبة قابلية الرصد تغلّف OpenAI SDK، فأعد إعداد العميل المغلّف باستخدام `base_url: "https://api.phaseo.app/v1"`.
- لتتبعات LangChain، اربط callback التتبّع بإعداد Phaseo لـ `ChatOpenAI`.
