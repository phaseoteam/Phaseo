شغّل `phaseo login`، ثم `phaseo <agent>` لتوجيه وكيل برمجة إلى Phaseo بمفتاح API خاص به. لتخطي CLI، أدخل [قيم المزوّد اليدوية](#enter-the-provider-values-yourself) في إعدادات الوكيل.

```bash
phaseo login
phaseo codex
```

## اعثر على أمر وكيلك

تُعدّ CLI كل وكيل بإحدى ثلاث طرق:

- **مُعدّ**: تكتب CLI ملف إعداد الوكيل. ابدأ الوكيل واختر نموذجًا من Phaseo.
- **مفتاح فقط**: يحتفظ الوكيل بالمفاتيح في مخزن تطبيقه الخاص، لذا تنشئ CLI المفتاح وتطبع الحقول التي عليك تعبئتها.
- **جلسة**: تشغّل CLI الوكيل بإعدادات مؤقتة تُحذف عند خروجه. لا يتغير إعدادك المعتاد.

| الوكيل | الأمر | الإعداد | الدليل |
| --- | --- | --- | --- |
| Claude Code | `phaseo claude-code` | مُعدّ | [Claude Code](./claude-code.mdx) |
| Codex | `phaseo codex` | مُعدّ | [Codex](./codex.mdx) |
| OpenCode | `phaseo opencode` | مُعدّ | [OpenCode](./opencode.mdx) |
| fx | `phaseo fx` | مُعدّ | [fx](./fx.mdx) |
| DeepSeek Harness | `phaseo deepseek-harness` | مُعدّ | [DeepSeek Harness](./deepseek-harness.mdx) |
| Pi | `phaseo pi` | مُعدّ | [Pi](./pi.mdx) |
| Prime Agent | `phaseo prime-agent` | مُعدّ | [Prime Agent](./prime-agent.mdx) |
| OpenClaw | `phaseo openclaw` | مُعدّ | [OpenClaw](./openclaw.mdx) |
| Hermes Agent | `phaseo hermes` | مُعدّ | [Hermes Agent](./hermes.mdx) |

## ما تنشئه CLI

يحصل كل وكيل على مفتاح API خاص به يحمل اسمه (مثل `Phaseo CLI: Codex API Key`). تنتهي صلاحية المفتاح بعد 90 يومًا وله حد إنفاق شهري قدره $100. شغّل أمر الإعداد مرة أخرى لاستبدال مفتاح منتهي الصلاحية، وارفع الحد باستخدام `phaseo keys update <id> --limit`.

إذا لم يكن Claude Code أو Codex أو OpenCode أو fx أو DeepSeek Harness أو Pi أو Prime Agent أو OpenClaw أو Hermes Agent مثبتًا، تعرض CLI أمر التثبيت الرسمي وتطلب موافقتك قبل تشغيله. خارج الطرفية التفاعلية، تطبع أمر التثبيت وتتوقف. يحصل OpenCode وfx وDeepSeek Harness وPi وPrime Agent وOpenClaw أيضًا على كل نماذج النص النشطة في Phaseo التي تعمل مع Chat Completions.

| الخيار أو الأمر | الأثر |
| --- | --- |
| `--model <id>` | يحدد النموذج الافتراضي. غير مدعوم في Claude Code. |
| `--catalog default` | يضيف النموذج المحدد فقط بدلًا من الكتالوج كاملًا. |
| `--skip-install` | يتخطى فحص التثبيت، لوكيل تديره بنفسك. |
| `--dry-run` | يعرض تغييرات الملفات دون تنفيذها. |
| `phaseo integrations credential <agent>` | يطبع مفتاح ذلك الوكيل، للوكلاء التي تلصق فيها المفتاح بنفسك. |
| `phaseo integrations remove <agent>` | يحذف الإعداد الذي كتبه Phaseo ويلغي المفتاح. تبقى إعداداتك الأخرى. |

## أدخل قيم المزوّد بنفسك

استخدم هذه القيم في أي وكيل يدعم مزوّدًا متوافقًا مع OpenAI. تختلف أسماء الحقول من أداة إلى أخرى.

| الإعداد | القيمة |
| --- | --- |
| نوع المزوّد | OpenAI Compatible |
| Base URL | `https://api.phaseo.app/v1` |
| مفتاح API | مفتاح API من Phaseo |
| النموذج | معرّف نموذج Phaseo، مثل `openai/gpt-6-astra` |

للوكلاء التي تستخدم Anthropic Messages API:

| الإعداد | القيمة |
| --- | --- |
| Base URL | `https://api.phaseo.app` (يضيف العميل `/v1/messages`) |
| رمز المصادقة | مفتاح API من Phaseo |
| النموذج | معرّف نموذج Phaseo، مثل `anthropic/claude-sonnet-5.5` |

ترفض بعض الوكلاء معرّفات النماذج التي تحتوي على `/`. إذا كان وكيلك كذلك ويدعم الأسماء المستعارة، فأنشئ اسمًا مستعارًا محليًا يشير إلى معرّف نموذج Phaseo.

## وكلاء ليس لها دليل خاص

### VS Code

يمكن لـ VS Code إضافة نماذج في محرر Language Models عندما يتضمن إصدارك مزوّدًا متوافقًا مع OpenAI.

1. افتح Command Palette وشغّل `Chat: Manage Language Models`.
2. اختر `OpenAI Compatible` أو `OAI Compatible`.
3. أدخل مفتاح API من Phaseo واضبط نقطة النهاية على `https://api.phaseo.app/v1`.
4. أضف معرّف نموذج Phaseo، مثل `openai/gpt-6-astra`، واختره في منتقي نماذج الدردشة.

إذا لم يتضمن إصدارك مزوّدًا متوافقًا مع OpenAI، فاستخدم إضافة تدعم المزوّدات المخصّصة: [Continue](./continue.mdx) أو [Cline](./cline.mdx) أو [Roo Code](./roo-code.mdx) أو [Kilo Code](./kilo-code.mdx).

### Claude Desktop

لا يستطيع Claude Desktop استخدام مزوّد نماذج مخصّص. أضف [Docs MCP](./docs-mcp.mdx) لتزويده بوثائق Phaseo، واستخدم [Claude Code](./claude-code.mdx) عندما تحتاج إلى Phaseo كبوابة للنماذج.

### Deep Agents CLI وأدوات LangChain الأخرى

استخدم Base URL والمفتاح من [LangChain](./langchain.mdx). إذا كانت الأداة تقرأ متغيرات بيئة OpenAI، فاضبط ما يلي ومرّر معرّف نموذج Phaseo في حقل النموذج:

```bash
export OPENAI_API_KEY="your_phaseo_api_key"
export OPENAI_BASE_URL="https://api.phaseo.app/v1"
```

## القيود المعروفة

- لا تعمل أدوات الخادم إلا حيث يرسلها الوكيل: `phaseo:apply_patch` متاحة على [Responses](../../api-reference/endpoint/responses.mdx) فقط. الوكلاء الأقدم التي لا تعالج أحداث Responses أو [أدوات الخادم](../server-tools/index.mdx) أكثر أمانًا على [Chat Completions](../../api-reference/endpoint/chat-completions.mdx).
- أرسل طلب دردشة قصيرًا قبل أن تسمح لوكيل بتعديل الملفات، واختر نموذجًا يدعم استدعاء الأدوات لعمل الوكلاء.
- أضف [Docs MCP](./docs-mcp.mdx) إذا أردت أن يقرأ الوكيل وثائق Phaseo أثناء الجلسة.
