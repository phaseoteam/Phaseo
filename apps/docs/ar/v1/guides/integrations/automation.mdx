استدعِ Phaseo من أي منصة أتمتة تستطيع إرسال طلب HTTP مصادَق عليه: أضف خطوة HTTP ترسل POST إلى `https://api.phaseo.app/v1/responses` مع مفتاحك بوصفه bearer token. ليس لدى Phaseo تطبيق أصلي في Zapier أو n8n أو Pipedream.

## بناء الطلب

| الإعداد | القيمة |
| --- | --- |
| الطريقة | `POST` |
| عنوان URL | `https://api.phaseo.app/v1/responses` |
| الترويسة | `Authorization: Bearer <PHASEO_API_KEY>` |
| الترويسة | `Content-Type: application/json` |

```json
{
  "model": "openai/gpt-6-astra",
  "input": "Summarise the supplied workflow data in one paragraph."
}
```

خزّن المفتاح في مخزن بيانات الاعتماد أو الأسرار في المنصة، لا في تعريف سير عمل مشترك. راجع [Responses](../../api-reference/endpoint/responses.mdx) للاطلاع على كل حقول الطلب.

## Zapier

استخدم **Webhooks by Zapier → Custom Request**:

1. اختر `POST` وأدخل `https://api.phaseo.app/v1/responses`.
2. أضف ترويستي bearer ونوع المحتوى.
3. اربط الحقول من خطوات Zap السابقة بـ `input`.
4. اختبر الـ Zap ببيانات غير حساسة.

## n8n

استخدم العقدة **HTTP Request** مع مصادقة bearer ونص JSON. اربط العنصر الوارد بـ `input` باستخدام تعبير n8n.

## Pipedream

استخدم خطوة طلب HTTP أو خطوة شيفرة Node.js. خزّن `PHASEO_API_KEY` سرًّا في Pipedream واقرأه من بيئة الخطوة.

## التحقق من أنه يعمل

شغّل الخطوة مرة واحدة. تعني الاستجابة `200` التي تحتوي على مصفوفة `output` أن المفتاح وعنوان URL يعملان، ويظهر الطلب في **الإعدادات ← الاستخدام ← السجلات**.

## تشغيل الأتمتة بأمان

- امنح كل أتمتة مفتاحها الخاص مع حد إنفاق، لتتمكن من تتبعه وإلغائه وحده.
- استخدم [المخرجات المنظّمة](../structured-outputs.mdx) عندما تتوقع الخطوات اللاحقة حقولًا قابلة للقراءة آليًا.
- أعد المحاولة عند `429` واستجابات `5xx` القابلة للاستعادة؛ راجع [الأخطاء](../../api-reference/errors.mdx).
- لا تكرر الإجراءات الخارجية غير المتساوية القوة (non-idempotent) لمجرد أن خطوة نموذج أُعيدت محاولتها.
