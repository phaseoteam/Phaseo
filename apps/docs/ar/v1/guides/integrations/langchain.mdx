أنشئ نموذج `ChatOpenAI` بمفتاح Phaseo و`base_url="https://api.phaseo.app/v1"`، فتستدعي سلاسل LangChain ووكلاؤه وسير عمل LangGraph النماذج عبر Phaseo.

## التثبيت

```bash
pip install -U langchain langchain-openai
```

## توجيه ChatOpenAI إلى Phaseo

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

طباعة جملة تعني أن الإعداد يعمل.

## الاستخدام في LangGraph

مرّر `llm` نفسه إلى عُقد الرسم البياني أو أداة بناء الوكيل:

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## القيود المعروفة

- يستخدم هذا المسار [Chat Completions](../../api-reference/endpoint/chat-completions.mdx)، لذا لا تعمل إلا ميزات Phaseo المتاحة على `/v1/chat/completions`، ومنها [استدعاء الأدوات](../tool-calling.mdx) و[التوجيه والبدائل](../routing-and-fallbacks.mdx).
- لأدوات الخادم المتاحة على Responses فقط مثل `phaseo:apply_patch`، استدعِ Phaseo مباشرةً أو استخدم [OpenAI SDK](./openai-sdk.mdx).
- للتتبّع باستخدام LangSmith، راجع [المراقبة](./observability.mdx).
