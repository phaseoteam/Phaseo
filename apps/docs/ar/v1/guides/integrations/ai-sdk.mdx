ثبّت `@phaseo/ai-sdk-provider` ومرّر `phaseo("<model id>")` نموذجًا في أي استدعاء لـ AI SDK. يقرأ المزوّد `PHASEO_API_KEY` من البيئة.

## التثبيت

```bash
npm install @phaseo/ai-sdk-provider
```

تتبع الحزمة غير المحددة الإصدار وسم `latest` في npm، وهو خط AI SDK 7، وتعلن `ai@^7` تبعيةً نظيرة يثبّتها npm نيابةً عنك. لإصدار أقدم من AI SDK، ثبّت الوسم المطابق:

| AI SDK | عقد المزوّد | التثبيت |
| --- | --- | --- |
| 7 (الحالي) | `ProviderV4` (المزوّد 2.x) | `npm install @phaseo/ai-sdk-provider` |
| 6 | `ProviderV3` (المزوّد 1.x، صيانة) | `npm install @phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `ProviderV2` | `npm install @phaseo/ai-sdk-provider@ai-sdk-v5` |

إذا كان مدير الحزم لديك لا يثبّت التبعيات النظيرة، فثبّت أيضًا الإصدار الرئيسي المطابق من `ai` (`ai@^7` أو `ai@^6` أو `ai@^5`).

عندما يصبح AI SDK 8 مستقرًا، سيضع Phaseo علامة الإيقاف على المزوّد 1.x في npm. لن تُزال الإصدارات الحالية، وسيُعلن عن أي انتهاء للدعم بشكل منفصل.

## توليد النص

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Summarize this in one sentence.",
});

console.log(result.text);
```

تعمل الشيفرة نفسها على الخطوط الثلاثة كلها. استخدم معرّفات النماذج من [نقطة نهاية Models](../../api-reference/endpoint/models.mdx)؛ وتظل كل قدرة معتمدة على النموذج والمزوّد الأصلي.

## ما يدعمه كل خط

| الميزة | AI SDK 7 (المزوّد 2.x) | AI SDK 5 |
| --- | --- | --- |
| توليد النص والبث | نعم | نعم |
| أدوات الدوال وجولات نتائج الأدوات | نعم، بما في ذلك مدخلات الأدوات المبثوثة | نعم |
| المخرجات المنظّمة بـ JSON وJSON Schema | نعم | نعم |
| التضمينات وتوليد الصور | نعم | نعم |
| التفريغ الصوتي والكلام | نعم | نعم |
| إعادة الترتيب | نعم | لا |
| إعدادات الاستدلال ومخرجاته المستقلة عن المزوّد | نعم | |
| مدخلات الملفات النصية والصور (بيانات ملفات V7 الموسومة) | نعم | |
| مصادر الاستشهاد بعناوين URL | نعم | |
| البيانات الوصفية للمزوّد، والاستخدام، وترويسات الطلب، وإشارات الإلغاء، وأجزاء التدفق الخام | نعم | |

يمثّل عمود AI SDK 7 ما ينفّذه المزوّد 2.x ويختبره مقابل عقود v4 الأصلية في AI SDK 7. وتتوفر إعادة الترتيب أيضًا في خط AI SDK 6.

## إعادة ترتيب المستندات

استخدم المساعد `rerank()` في AI SDK مع `phaseo.rerankingModel(modelId)`:

```ts
import { rerank } from "ai";
import { phaseo } from "@phaseo/ai-sdk-provider";

const result = await rerank({
	model: phaseo.rerankingModel("voyage/rerank-2"),
	query: "Which document is about TypeScript?",
	documents: [
		"TypeScript adds static types to JavaScript.",
		"Rust is a systems programming language.",
	],
	topN: 1,
});
```

## الحدود المعروفة

- لا يعلن المزوّد عن ميزات `ProviderV4` التي تحتاج إلى واجهات Phaseo API غير موجودة بعد: رفع الملفات المُدارة ومراجعها، والمهارات، وتعريفات الأدوات التي ينفّذها المزوّد ونتائجها واستجابات الموافقة عليها.
- تظل أدوات الدوال التي يشغّلها تطبيقك تستخدم مسار التنفيذ والموافقة المعتاد في AI SDK.
- أجزاء الموجّه الخاصة بالمزوّد أو المخصصة غير المدعومة تفشل بخطأ واضح بدلًا من إسقاطها.
