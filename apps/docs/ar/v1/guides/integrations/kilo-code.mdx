شغّل `phaseo kilo` لبدء جلسة Kilo Code CLI عبر Phaseo، أو أنشئ مفتاحًا باستخدام `phaseo kilo-code` وأضف مزوّدًا مخصّصًا في إضافة Kilo Code.

## تشغيل Kilo Code CLI عبر Phaseo

```bash
phaseo login
phaseo kilo --model openai/gpt-5.6-terra
```

يكتب المشغّل ملف `KILO_CONFIG` مؤقتًا، ويشغّل `kilo`، ثم يحذف الملف عند خروج Kilo، فيبقى إعداد Kilo Code أو VS Code الحالي لديك دون تغيير. إذا لم يكن Kilo مثبتًا، يعرض التشغيل التفاعلي تثبيته. ضع خيارات Kilo الخاصة بعد `--`.

| الخيار | الأثر |
| --- | --- |
| `--model <id>` | النموذج المستخدم. القيمة الافتراضية `openai/gpt-5.6-terra`. |
| `--catalog all` | يعرض في Kilo كل نماذج النص النشطة في Phaseo، لا النموذج المحدد فقط. |
| `--dry-run --json` | يعرض خطة التثبيت والتشغيل دون إنشاء مفتاح أو بدء Kilo. |
| `--skip-install` | يتخطى فحص التثبيت. |

`phaseo run kilo ...` هو الصيغة الطويلة للأمر نفسه.

## إعداد إضافة Kilo Code

أنشئ مفتاحًا للإضافة:

```bash
phaseo login
phaseo kilo-code --model anthropic/claude-sonnet-5.5
```

ثم في VS Code:

1. افتح Kilo Code، واختر رمز الإعدادات، وافتح **Providers**، ثم اختر **Add custom provider**.
2. أدخل:

| حقل Kilo Code | القيمة |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.phaseo.app/v1` |
| API key | ناتج الأمر `phaseo integrations credential kilo-code` |

3. إذا لم يُكتشف أي نموذج، فأضف المعرّف `anthropic/claude-sonnet-5.5` بنفسك.
4. اختر **Submit**، ثم اختر نموذج Phaseo.

يعرض Kilo الاختيار بالشكل `phaseo/anthropic/claude-sonnet-5.5`. ‏`phaseo` هو معرّف المزوّد المحلي؛ والباقي هو معرّف النموذج المُرسل إلى Phaseo. راجع وثائق [النماذج المخصّصة](https://kilo.ai/docs/code-with-ai/agents/custom-models) في Kilo للنموذج الكامل.

## التحقق من أنه يعمل

اطلب من Kilo Code الرد بـ `PHASEO_KILO_OK`، ثم تأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## إزالة Phaseo

احذف المزوّد المخصّص في Kilo Code، ثم شغّل:

```bash
phaseo integrations remove kilo-code
```

يلغي هذا الأمر المفتاح. لا تستطيع CLI مسح مخزن الإضافة.

## إصلاح المشكلات الشائعة

### لم يُكتشف أي نموذج

أضف النموذج بنفسك. لا يحتاج Kilo إلى الاكتشاف عبر `/models`.

### تفشل المصادقة

استبدل المفتاح المحفوظ بناتج الأمر `phaseo integrations credential kilo-code`، وأبقِ Base URL كما هو تمامًا.

### يبدو اسم النموذج مختلفًا

اختر `phaseo/<Phaseo model ID>` في Kilo، لكن لا تضف `phaseo/` في حقل معرّف النموذج.
