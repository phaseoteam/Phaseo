يمكن لـ LiveKit Agents استدعاء أي نقطة نهاية دردشة متوافقة مع OpenAI عبر إضافة OpenAI. وجّه الإضافة إلى Phaseo لاستخدام معرّفات نماذج Phaseo وتوجيهها.

## Python

```bash
uv add "livekit-agents[openai]"
```

```python
import os
from livekit.agents import AgentSession
from livekit.plugins import openai

session = AgentSession(
    llm=openai.LLM(
        model="openai/gpt-5-nano",
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)
```

## Node.js

```bash
pnpm add @livekit/agents @livekit/agents-plugin-openai
```

```ts
import { voice } from "@livekit/agents";
import * as openai from "@livekit/agents-plugin-openai";

const session = new voice.AgentSession({
	llm: new openai.LLM({
		model: "openai/gpt-5-nano",
		apiKey: process.env.PHASEO_API_KEY,
		baseURL: "https://api.phaseo.app/v1",
	}),
});
```

## ملاحظات

- استخدم وضع Chat Completions المتوافق مع OpenAI لنقاط النهاية المخصصة.
- لا تتحول أدوات OpenAI الخاصة بـ Responses في LiveKit تلقائيًا إلى أدوات خادم Phaseo.
- هيّئ تحويل الكلام إلى نص وتحويل النص إلى كلام كلٌ على حدة، ما لم تدعم واجهة LiveKit المحددة عنوان URL مخصصًا متوافقًا مع OpenAI لهذه الوسيطة.
- اختبر معالجة المقاطعات واستدعاءات الأدوات وزمن تأخر التدفق قبل تمرير حركة صوتية للإنتاج.
