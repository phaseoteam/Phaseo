وجّه نموذج LLM في إضافة OpenAI الخاصة بـ LiveKit Agents إلى `https://api.phaseo.app/v1` بمفتاح Phaseo، فتستخدم وكلاء الصوت لديك معرّفات نماذج Phaseo وتوجيهه. تستدعي الإضافة نقطة النهاية Chat Completions في Phaseo.

## التثبيت

<CodeGroup>

```bash Python
uv add "livekit-agents[openai]"
```

```bash Node.js
pnpm add @livekit/agents @livekit/agents-plugin-openai
```

</CodeGroup>

## توجيه LLM الخاص بالوكيل إلى Phaseo

<CodeGroup>

```python Python
import os
from livekit.agents import AgentSession
from livekit.plugins import openai

session = AgentSession(
    llm=openai.LLM(
        model="openai/gpt-6-astra",
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)
```

```ts Node.js
import { voice } from "@livekit/agents";
import * as openai from "@livekit/agents-plugin-openai";

const session = new voice.AgentSession({
	llm: new openai.LLM({
		model: "openai/gpt-6-astra",
		apiKey: process.env.PHASEO_API_KEY,
		baseURL: "https://api.phaseo.app/v1",
	}),
});
```

</CodeGroup>

ابدأ جلسة، وقل شيئًا، وتأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## القيود المعروفة

- استخدم وضع Chat Completions في الإضافة لنقاط النهاية المخصّصة. أدوات OpenAI الخاصة بـ Responses في LiveKit لا تتحول إلى أدوات خادم في Phaseo.
- يوجّه هذا نموذج LLM فقط. اضبط تحويل الكلام إلى نص والنص إلى كلام بشكل منفصل، إلا إذا كانت واجهة LiveKit التي تستخدمها تقبل URL مخصّصًا متوافقًا مع OpenAI لتلك الوسيلة.
- اختبر معالجة المقاطعة و[استدعاءات الأدوات](../tool-calling.mdx) وزمن استجابة [البث](../streaming.mdx) قبل تمرير حركة الصوت في الإنتاج.
