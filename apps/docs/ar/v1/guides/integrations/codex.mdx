شغّل `phaseo codex` لإضافة ملف تعريف Phaseo إلى Codex، أو أضف مزوّد `phaseo` إلى `config.toml` بنفسك. يعمل الإعداد نفسه في Codex CLI وCodex App وإضافة Codex لبيئات التطوير.

## الإعداد باستخدام Phaseo CLI

```bash
phaseo login
phaseo codex --model openai/gpt-5.6-terra
codex --profile phaseo
```

إذا لم يكن Codex مثبتًا، تعرض CLI أمر التثبيت الرسمي وتطلب موافقتك قبل تشغيله. ثم يفتح الإعداد صفحة في لوحة التحكم توافق فيها على مفتاح باسم `Phaseo CLI: Codex API Key` تنتهي صلاحيته بعد 90 يومًا وله حد إنفاق شهري قدره $100. تحفظ CLI المفتاح في مخزن بيانات الاعتماد في نظام التشغيل، وتكتب ملف التعريف في `~/.codex/phaseo.config.toml` (أو داخل `CODEX_HOME`). يجلب Codex المفتاح من CLI، لذلك لا يُكتب أي مفتاح كنص صريح في الإعداد. عند انتهاء صلاحية المفتاح، شغّل `phaseo codex` مرة أخرى للموافقة على مفتاح جديد. بدون `--model`، يستخدم ملف التعريف `openai/gpt-5.6-terra`.

## إعداد Codex يدويًا

أضف ما يلي إلى `~/.codex/config.toml`، أو إلى `.codex/config.toml` في مشروع موثوق:

```toml
model = "openai/gpt-6-astra"
model_provider = "phaseo"

[model_providers.phaseo]
name = "Phaseo"
base_url = "https://api.phaseo.app/v1"
env_key = "PHASEO_API_KEY"
wire_api = "responses"
```

ثم صدّر `PHASEO_API_KEY` وابدأ Codex. تستخدم المزوّدات المخصّصة في Codex بروتوكول النقل الخاص بـ Responses، وهو الافتراضي، لذا يمكنك أيضًا حذف `wire_api`. في إضافة بيئة التطوير، افتح الملف من **Codex Settings → Open config.toml**.

## التحقق من أنه يعمل

أرسل موجّهًا قصيرًا وتأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**. يستدعي Codex نقطة النهاية [Responses](../../api-reference/endpoint/responses.mdx)، لذا يجب أن يدعم النموذج نقطة النهاية هذه.

## إزالة Phaseo

```bash
phaseo integrations remove codex
```

يحذف هذا الأمر `phaseo.config.toml` إذا كان Phaseo قد أنشأه، ويلغي المفتاح. في الإعداد اليدوي، احذف مزوّد `phaseo` من `config.toml`.

## إصلاح المشكلات الشائعة

| الخطأ | الحل |
| --- | --- |
| `401 Unauthorized` | شغّل `phaseo whoami`، ثم أعد تشغيل `phaseo codex`. |
| `model_not_found` | احصل على معرّف حالي من [النماذج](../../api-reference/endpoint/models.mdx) وحدّث `model`. |
| فشل أحد المزوّدين | راجع [التوجيه والبدائل](../routing-and-fallbacks.mdx) لمعرفة التحويل عند الإخفاق. |

## إضافة مهارات Phaseo ووثائقه

ليتمكن Codex من قراءة وثائق Phaseo المحدّثة أثناء العمل، أضف خادم [Docs MCP](./docs-mcp.mdx). لتثبيت [مهارات Phaseo](https://phaseo.app/docs/.well-known/agent-skills/index.json) العامة لـ Codex:

```bash
npx skills add https://phaseo.app/docs --agent codex --skill '*'
```

يشغّل سير عمل CLI نفسه [Cline](./cline.mdx) و[Kilo Code](./kilo-code.mdx) و[oh-my-pi](./oh-my-pi.mdx) و[Muse Code](./muse-code.mdx) و[MiniMax Code](./minimax-code.mdx) بإعدادات مؤقتة.
