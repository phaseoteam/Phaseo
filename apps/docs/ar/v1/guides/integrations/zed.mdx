شغّل `phaseo zed` لإضافة مزوّد Phaseo إلى `settings.json` في Zed، ثم الصق المفتاح في Zed، الذي يحتفظ بمفاتيح المزوّدين في سلسلة مفاتيح النظام. لتخطي CLI، أضف المزوّد في إعدادات Zed بنفسك.

## الإعداد باستخدام Phaseo CLI

```bash
phaseo login
phaseo zed --model openai/gpt-5.6-terra
```

تنشئ CLI مفتاحًا باسم `Phaseo CLI: Zed API Key` (تنتهي صلاحيته بعد 90 يومًا، وحد إنفاقه الشهري $100) وتضيف إلى `settings.json` في Zed مزوّدًا من نوع `openai_compatible` باسم `phaseo`، مع API URL ‏`https://api.phaseo.app/v1` والنموذج المحدد. تبقى الإعدادات غير المرتبطة كما هي. بدون `--model`، تستخدم `anthropic/claude-sonnet-4.6`. يتوقف الإعداد إذا كان لدى Zed بالفعل مزوّد باسم `phaseo`.

## إضافة المفتاح في Zed

1. افتح لوحة الأوامر وشغّل **agent: open settings**.
2. تحت **AI**، اختر **LLM Providers → Configure**.

![إعدادات AI في Zed مع إبراز LLM Providers](/images/integrations/zed-agent-settings.png)

3. إذا ظهر Phaseo، فافتحه والصق ناتج الأمر `phaseo integrations credential zed`.

لإضافة المزوّد دون CLI، اختر **Add Provider → OpenAI** بدلًا من ذلك وأدخل القيم أدناه.

![صفحة LLM Providers في Zed مع Add Provider](/images/integrations/zed-llm-providers.png)

| الحقل | القيمة |
| --- | --- |
| Provider Name | `Phaseo` |
| API URL | `https://api.phaseo.app/v1` |
| API Key | ناتج الأمر `phaseo integrations credential zed`، أو أي مفتاح API من Phaseo |
| Model Name | معرّف نموذج Phaseo |

![نموذج Zed لإضافة مزوّد متوافق مع OpenAI](/images/integrations/zed-add-compatible-provider.png)

املأ API URL والنموذج والمفتاح قبل اختيار **Save Provider**.

## التحقق من أنه يعمل

افتح سلسلة Agent جديدة، واختر نموذج Phaseo، وأرسل طلبًا قصيرًا. تأكد من ظهوره في **الإعدادات → الاستخدام → السجلات**. إذا أبلغ Zed عن مفتاح غير صالح، فشغّل `phaseo integrations credential zed` مرة أخرى واستبدل المفتاح في Zed.

## إزالة Phaseo

```bash
phaseo integrations remove zed
```

يزيل هذا الأمر مزوّد Phaseo من `settings.json` ويلغي المفتاح. إذا ظل Zed يعرض إدخال سلسلة المفاتيح القديم، فأزل Phaseo من **LLM Providers** أيضًا.
