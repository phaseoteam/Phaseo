أضف `PHASEO_API_KEY` إلى Replit Secrets، ثم استدعِ Phaseo باستخدام [OpenAI SDK](./openai-sdk.mdx) أو [مزوّد Phaseo لـ AI SDK](./ai-sdk.mdx). أبقِ المفتاح خارج الكود المصدري.

## إضافة السر

في مساحة عمل Replit، افتح **Tools → Secrets** وأضف:

```text
PHASEO_API_KEY=phaseo_v1_sk_...
```

يتيح Replit السر لتطبيقك كمتغير بيئة. راجع [المصادقة](../../developers/authentication.mdx) لمعرفة أنواع المفاتيح.

## استدعاء Phaseo

<CodeGroup>

```ts OpenAI SDK
// npm install openai
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Reply with only: ok",
});

console.log(response.output_text);
```

```ts AI SDK
// npm install @phaseo/ai-sdk-provider
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const { text } = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Reply with only: ok",
});

console.log(text);
```

</CodeGroup>

طباعة `ok` تعني أن السر وBase URL يعملان.

## النشر

أضف `PHASEO_API_KEY` إلى أسرار النشر وكذلك إلى مساحة العمل. تأكد من أن النشر لا يطبع متغيرات البيئة أو ترويسات الطلبات في سجلاته.
