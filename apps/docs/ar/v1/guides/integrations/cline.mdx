شغّل `phaseo cline` لبدء جلسة Cline CLI عبر Phaseo، أو أنشئ مفتاحًا باستخدام `phaseo setup cline` وأضف مزوّدًا من نوع **OpenAI Compatible** في إضافة Cline. تحتفظ الإضافة بالمفاتيح في مخزن الأسرار الخاص بـ VS Code، لذا تتم هذه الخطوة الأخيرة في واجهتها.

## تشغيل Cline CLI عبر Phaseo

```bash
phaseo login
phaseo cline --model openai/gpt-5.6-terra -- --tui
```

يكتب المشغّل إعدادات Cline في مجلد مؤقت، ويشغّل `cline`، ثم يحذف المجلد عند خروج Cline، فيبقى إعداد Cline أو VS Code الحالي لديك دون تغيير. إذا لم يكن Cline مثبتًا، يعرض التشغيل التفاعلي تثبيته. ضع خيارات Cline الخاصة بعد `--`.

| الخيار | الأثر |
| --- | --- |
| `--model <id>` | النموذج المستخدم. القيمة الافتراضية `openai/gpt-5.6-terra`. |
| `--catalog all` | يعرض في Cline كل نماذج النص النشطة في Phaseo، لا النموذج المحدد فقط. |
| `--dry-run --json` | يعرض خطة التثبيت والتشغيل دون إنشاء مفتاح أو بدء Cline. |
| `--skip-install` | يتخطى فحص التثبيت. |

`phaseo run cline ...` هو الصيغة الطويلة للأمر نفسه.

## إعداد إضافة Cline

أنشئ مفتاحًا للإضافة:

```bash
phaseo login
phaseo setup cline --model anthropic/claude-sonnet-5.5
```

ثم في VS Code:

1. افتح لوحة Cline واختر رمز الإعدادات، أو المزوّد أسفل مربع الدردشة.
2. اختر **OpenAI Compatible** وأدخل:

| حقل Cline | القيمة |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | ناتج الأمر `phaseo integrations credential cline` |
| Model ID | `anthropic/claude-sonnet-5.5`، أو النموذج الذي يطبعه الإعداد |

3. احفظ المزوّد. إذا ظهر خيار **Verify** في إصدارك، فاختره.
4. اختر النموذج المُعدّ للمهمة التالية.

لتخطي CLI، استخدم أي مفتاح API من Phaseo. تغطي وثائق [تهيئة Cline المتوافقة مع OpenAI](https://docs.cline.bot/enterprise-solutions/configuration/remote-configuration/openai-compatible/member-configuration) الإعدادات التي تديرها الفرق.

## التحقق من أنه يعمل

اطلب من Cline الرد بـ `PHASEO_CLINE_OK`، ثم تأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## إزالة Phaseo

احذف مزوّد Phaseo في Cline أو انتقل إلى مزوّد آخر، ثم شغّل:

```bash
phaseo integrations remove cline
```

يلغي هذا الأمر المفتاح. لا تستطيع CLI مسح مخزن إضافات VS Code، لذا قد يظل المفتاح المحذوف ظاهرًا في Cline حتى تزيله من هناك.

## إصلاح المشكلات الشائعة

### فشل التحقق

أبقِ Base URL كما هو تمامًا، بما في ذلك `/v1`، والصق مفتاحًا استرجعته للتو دون علامات اقتباس أو مسافات.

### قائمة النماذج فارغة

اكتب معرّف نموذج Phaseo بنفسك. لا يحتاج Cline إلى اكتشاف النماذج.

### تعمل الدردشة لكن الأدوات تفشل

اختر نموذج Phaseo يدعم استدعاء الأدوات. نجاح الاتصال لا يعني أن النموذج يدعم الأدوات.
