أنشئ مزوّد OpenAI من AI SDK بمفتاح Phaseo و`baseURL: "https://api.phaseo.app/v1"`، ومرّر نماذجه إلى وكلاء Mastra وسير عمله.

## التثبيت

```bash
npm install @mastra/core @ai-sdk/openai ai
```

## توجيه وكيل Mastra إلى Phaseo

```ts
import { Agent } from "@mastra/core/agent";
import { createOpenAI } from "@ai-sdk/openai";

const phaseo = createOpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
	compatibility: "compatible",
});

export const agent = new Agent({
	name: "support-agent",
	instructions: "Answer in two short paragraphs.",
	model: phaseo("openai/gpt-6-astra"),
});
```

استخدم Base URL وحده، دون `/chat/completions` أو `/responses`. شغّل الوكيل مرة واحدة بموجّه قصير وتأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## القيود المعروفة

- يعتمد سلوك وكلاء Mastra على مزوّد AI SDK. اختبر [استدعاء الأدوات](../tool-calling.mdx) والبث قبل الإنتاج.
- لتفضيل مزوّدين معيّنين، اضبط عناصر التحكم في توجيه Phaseo في الطلب أو في [إعداد مسبق](../presets.mdx).
