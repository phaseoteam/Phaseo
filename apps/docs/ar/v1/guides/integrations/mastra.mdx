يعمل Mastra مع مزوّدي AI SDK، لذا فإن أسهل طريقة هي إنشاء مزوّد متوافق مع OpenAI يشير إلى Phaseo.

## التثبيت

```bash
npm install @mastra/core @ai-sdk/openai ai
```

## تهيئة وكيل

```ts
import { Agent } from "@mastra/core/agent";
import { createOpenAI } from "@ai-sdk/openai";

const phaseo = createOpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
	compatibility: "compatible",
});

export const agent = new Agent({
	name: "support-agent",
	instructions: "Answer in two short paragraphs.",
	model: phaseo("openai/gpt-5-nano"),
});
```

## ملاحظات

- استخدم عنوان URL الأساسي فقط، دون `/chat/completions` أو `/responses`.
- يعتمد سلوك وكلاء Mastra على مسار مزوّد AI SDK. اختبر الأدوات والتدفق قبل النشر للإنتاج.
- استخدم عناصر التحكم في توجيه Phaseo على مستوى الطلب أو عبر presets عند الحاجة إلى تفضيلات للمزوّد.
