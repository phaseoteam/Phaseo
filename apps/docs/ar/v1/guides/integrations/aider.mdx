شغّل `phaseo aider` لكتابة إعداد Aider يشير إلى Phaseo، أو أضف ثلاثة أسطر إلى ملف `.aider.conf.yml` الموجود لديك.

## الإعداد باستخدام Phaseo CLI

```bash
phaseo login
phaseo aider --model anthropic/claude-sonnet-5.5
```

إذا لم يكن `~/.aider.conf.yml` موجودًا، ينشئ الإعداد مفتاح `Phaseo CLI: Aider API Key` (صلاحية 90 يومًا، وحد إنفاق شهري $100) ويكتب هذا الملف. ومن دون `--model`، يستخدم `anthropic/claude-sonnet-4.6`.

```yaml ~/.aider.conf.yml
# Managed by Phaseo CLI
model: openai/anthropic/claude-sonnet-5.5
openai-api-base: https://api.phaseo.app/v1
openai-api-key: "<dedicated Phaseo key>"
```

يحتاج Aider إلى البادئة `openai/` لإرسال نموذج مخصص عبر محوّله المتوافق مع OpenAI. ويظل النموذج المرسل إلى Phaseo هو `anthropic/claude-sonnet-5.5`.

<Warning>
يُخزَّن المفتاح بنص صريح، لأن `.aider.conf.yml` أحد مواقع المفاتيح الموثّقة في Aider. اجعل الملف قابلًا للقراءة من حساب المستخدم الخاص بك فقط، ولا تُدرجه في أي commit أبدًا.
</Warning>

## إعداد Aider يدويًا

إذا كان لديك إعداد Aider بالفعل، يتوقف CLI دون تغييره. انسخ الإعدادات الثلاثة أعلاه إلى الإعداد الذي تريد أن يحمّله Aider، مستخدمًا `phaseo integrations credential aider` أو أي مفتاح Phaseo API لـ `openai-api-key`. يقرأ Aider `.aider.conf.yml` من مجلدك الرئيسي وجذر المستودع والمجلد الحالي، وتكون الأولوية للملفات اللاحقة. راجع وثائق Aider حول [إعداد YAML](https://aider.chat/docs/config/aider_conf.html) و[API المتوافقة مع OpenAI](https://aider.chat/docs/llms/openai-compat.html).

## التحقق من أنه يعمل

افتح مستودعًا وشغّل Aider:

```bash
aider
```

تحقّق من أن مخرجات بدء التشغيل تذكر `openai/anthropic/claude-sonnet-5.5`، واطلب منه الرد بـ `PHASEO_AIDER_OK`، وتأكد من ظهور الطلب في **الإعدادات ← الاستخدام ← السجلات**.

لا يوقف تحذير النموذج غير المعروف الطلبات. أضف البيانات الوصفية للنموذج في Aider فقط إذا احتجت إلى تقديرات دقيقة لحد الـ tokens أو التكلفة.

## إزالة Phaseo

```bash
phaseo integrations remove aider
```

يُلغي هذا المفتاح ويحذف `~/.aider.conf.yml` فقط إذا كان الملف لا يزال يبدأ بعلامة Phaseo CLI. إذا دمجت الإعدادات في ملفك الخاص، فأزل الأسطر الثلاثة بنفسك.

## إصلاح المشكلات الشائعة

### يستخدم Aider نقطة نهاية أو نموذجًا آخر

ملف `.aider.conf.yml` في جذر المستودع أو المجلد الحالي يتجاوز الملف الموجود في مجلدك الرئيسي. وتتجاوز متغيرات البيئة وخيارات سطر الأوامر جميعها.

### فشل المصادقة

قارن `openai-api-key` بمخرجات `phaseo integrations credential aider`، وأبقِ `openai-api-base` بالقيمة `https://api.phaseo.app/v1` تمامًا.

### تعذّر تحديد النموذج

أبقِ البادئة `openai/` الخاصة بـ Aider. يصبح نموذج Phaseo `openai/gpt-6-astra` في Aider `openai/openai/gpt-6-astra`.
