شغّل `phaseo claude-code` لإرسال طلبات Claude Code عبر Phaseo، أو عيّن ثلاثة متغيرات بيئة بنفسك. يستدعي Claude Code نقطة النهاية `/v1/messages` بنمط Anthropic، الذي يخدمه Phaseo بوصفه [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx)، لذا لا تتغير موجّهاتك.

## الإعداد باستخدام Phaseo CLI

```bash
phaseo login
phaseo claude-code
claude
```

إذا لم يكن Claude Code مثبّتًا، يعرض CLI أمر التثبيت الرسمي ويسألك قبل تشغيله. ثم يقوم الإعداد بما يلي:

- ينشئ مفتاح `Phaseo CLI: Claude Code API Key` تنتهي صلاحيته بعد 90 يومًا وله حد إنفاق شهري $100، ويحفظه في مخزن بيانات الاعتماد في نظام التشغيل؛
- يعيّن `ANTHROPIC_BASE_URL` و`apiKeyHelper` في `~/.claude/settings.json`. يجلب المساعد المفتاح من CLI وينشئ مفتاحًا جديدًا عند انتهاء صلاحية القديم، فلا يُكتب أي مفتاح بنص صريح في إعدادات Claude Code.

يتوقف الإعداد دون إجراء تغييرات إذا كان `settings.json` يحتوي بالفعل على `ANTHROPIC_BASE_URL` مختلف، أو `apiKeyHelper` مختلف، أو `ANTHROPIC_API_KEY` أو `ANTHROPIC_AUTH_TOKEN` غير فارغ. الخيار `--model` غير مدعوم لـ Claude Code؛ عيّن `ANTHROPIC_MODEL` بدلًا منه (انظر أدناه).

## إعداد Claude Code يدويًا

عيّن هذه المتغيرات في الصدفة التي تشغّل منها Claude Code:

<CodeGroup>

```bash bash
export ANTHROPIC_BASE_URL="https://api.phaseo.app"
export ANTHROPIC_AUTH_TOKEN="your_phaseo_api_key"
export ANTHROPIC_API_KEY=""
```

```powershell PowerShell
$env:ANTHROPIC_BASE_URL = "https://api.phaseo.app"
$env:ANTHROPIC_AUTH_TOKEN = "your_phaseo_api_key"
$env:ANTHROPIC_API_KEY = ""
```

</CodeGroup>

يرسل Claude Code قيمة `ANTHROPIC_AUTH_TOKEN` في ترويسة `Authorization`، التي يقبلها Phaseo. لتثبيت نموذج افتراضي، عيّن `ANTHROPIC_MODEL` إلى معرّف نموذج Phaseo من [Models](../../api-reference/endpoint/models.mdx).

## التحقق من أنه يعمل

شغّل `claude`، وأرسل موجّهًا قصيرًا، وتأكد من ظهور الطلب في **الإعدادات ← الاستخدام ← السجلات**.

## إزالة Phaseo

```bash
phaseo integrations remove claude-code
```

يزيل هذا عنوان URL الأساسي ومساعد المفتاح ومتغيرات بيانات الاعتماد الفارغة التي أضافها Phaseo إلى `settings.json`، ثم يُلغي المفتاح. في الإعداد اليدوي، ألغِ تعيين متغيرات البيئة الثلاثة.

## الحدود المعروفة

- اختبر حلقات الأدوات المبثوثة مع سير عملك قبل نقل فريق إليه.
- أضف خادم [Docs MCP](./docs-mcp.mdx) إذا أردت أن يقرأ Claude Code وثائق Phaseo أثناء الجلسة.
