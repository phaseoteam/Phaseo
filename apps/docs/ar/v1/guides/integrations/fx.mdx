[fx](https://fx.sh) وكيل برمجة مفتوح المصدر من Vercel Labs. يمكنه استدعاء أي نقطة نهاية Chat Completions متوافقة مع OpenAI عبر اتصال مخصص مسمّى، لذا يعمل Phaseo بوابةً لنماذجه. يعمل fx على macOS وLinux.

## 1) إعداد fx

استخدم CLI الخاص بـ Phaseo لإضافة الاتصال ومزامنة نماذج Phaseo المتوافقة وجعل Phaseo المزوّد النشط في fx:

```bash
phaseo login
phaseo fx --model openai/gpt-5.6-terra
```

إذا لم يكن fx مثبتًا في طرفية تفاعلية، يعرض Phaseo أمر التثبيت الرسمي ويطلب التأكيد قبل تشغيله. ثم يقوم الأمر بما يلي:

- يضيف اتصال `phaseo` إلى `~/.fx/settings.json` مع الحفاظ على إعداداتك واتصالاتك الأخرى؛
- يزامن ما يصل إلى 256 نموذجًا متوافقًا من Phaseo، وهو الحد الأقصى الذي يقبله fx، مع حدود السياق والمخرجات الخاصة بها؛
- يعيّن `phaseo` مزوّدًا نشطًا في fx ويسجّل المزوّد السابق حتى تتمكن الإزالة من استعادته؛
- ينشئ مفتاح `Phaseo CLI: fx API Key` تنتهي صلاحيته بعد 90 يومًا وله حد إنفاق شهري قدره 100 دولار، ويخزّنه في الملف `~/.config/phaseo/integrations/fx.env` الذي لا يقرؤه إلا مالكه. شغّل `phaseo fx` مرة أخرى لاستبدال مفتاح منتهي الصلاحية.

استخدم `--catalog default` لتهيئة النموذج المحدد فقط، أو `--dry-run` لمعاينة التغييرات على الملفات.

## 2) تحميل المفتاح في الصدفة

يقرأ fx مفاتيح الاتصالات المخصصة من متغيرات البيئة فقط، ولا يقرؤها أبدًا من ملف إعداداته. أضف هذا السطر إلى `~/.zshrc` أو `~/.bashrc` مرة واحدة، ثم افتح طرفية جديدة:

```bash
[ -f "$HOME/.config/phaseo/integrations/fx.env" ] && . "$HOME/.config/phaseo/integrations/fx.env"
```

يعيّن هذا السطر `PHASEO_FX_API_KEY` عند وجود الملف، ولا يفعل شيئًا بعد إزالة التكامل.

## 3) تشغيل fx

```bash
fx
```

بدّل النماذج باستخدام `/model`، أو اختر أي معرّف نموذج من Phaseo لتشغيل واحد باستخدام `FX_MODEL=<id> fx`. للعودة إلى مزوّد آخر، استخدم `fx provider <name>`.

## الإعداد اليدوي

أضف الاتصال إلى `~/.fx/settings.json`. لا يقبل fx الاتصالات المخصصة في ملف `.fx.json` الخاص بالمشروع.

```json
{
  "provider": "phaseo",
  "providers": {
    "phaseo": {
      "protocol": "openai-chat-completions",
      "base_url": "https://api.phaseo.app/v1",
      "auth": { "type": "bearer", "env": "PHASEO_API_KEY" },
      "model_metadata": {
        "openai/gpt-5.6-terra": { "context_window": 400000, "max_output_tokens": 128000 }
      }
    }
  },
  "models": { "phaseo": "openai/gpt-5.6-terra" }
}
```

ثم صدّر `PHASEO_API_KEY` وشغّل `fx`. بدون `context_window` لا يستطيع fx تحديد متى يضغط المحادثة، لذا صرّح بحدود النماذج التي تستخدمها. الحدود أعلاه أمثلة فقط؛ خذ القيم الفعلية من [نقطة النهاية Models](../../api-reference/endpoint/models.mdx).

## الإزالة

```bash
phaseo integrations remove fx
```

يزيل هذا الأمر اتصال `phaseo` ونموذجه، ويستعيد مزوّد fx السابق إذا كان Phaseo لا يزال نشطًا، ويحذف ملف المفتاح، ويلغي المفتاح.

## التحقق

- شغّل `fx status --json` للتأكد من المزوّد النشط ونقطة النهاية والنموذج.
- شغّل طلبًا بسيطًا مثل `fx ask "Summarize README.md"` قبل العمل على تعديل الملفات.
- إذا أبلغ fx عن بيانات اعتماد مفقودة، فافتح طرفية جديدة أو تحقق من وجود السطر في ملف تعريف الصدفة.
- ميزات fx الخاصة بـ AI Gateway وحده، مثل البحث على الويب عبر البوابة والتحقق من الرصيد، غير متاحة عبر الاتصالات المخصصة.
