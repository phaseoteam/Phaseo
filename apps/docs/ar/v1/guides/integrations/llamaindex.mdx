أنشئ نموذج LLM من نوع `OpenAILike` بمفتاح Phaseo و`api_base="https://api.phaseo.app/v1"`، ثم اجعله الافتراضي في LlamaIndex حتى يمر التوليد في سير عمل RAG عبر Phaseo.

## التثبيت

```bash
pip install llama-index llama-index-llms-openai-like llama-index-embeddings-openai-like
```

## توجيه LlamaIndex إلى Phaseo

```python
import os
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    is_chat_model=True,
)

response = llm.complete("Write one sentence about retrieval quality.")
print(response)
```

طباعة جملة تعني أن الإعداد يعمل. ‏`OpenAILike` هي فئة LlamaIndex لواجهات API الخارجية المتوافقة مع OpenAI.

## الاستخدام في فهرس

```python
from llama_index.core import Settings

Settings.llm = llm
```

ثم ابنِ فهرسك أو استعلم عنه كالمعتاد.

## القيود المعروفة

- لا تشير الإعدادات الافتراضية في LlamaIndex إلى Phaseo. اضبط نموذجي التوليد والتضمين صراحةً.
- لـ [التضمينات](../../api-reference/endpoint/embeddings.mdx) في Phaseo، اضبط نموذج التضمين بمعرّف نموذج Phaseo وBase URL نفسه.
