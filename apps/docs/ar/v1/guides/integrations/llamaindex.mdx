استخدم هذا الدليل عندما تريد توجيه التوليد أو التضمينات في تطبيق LlamaIndex عبر Phaseo.

## التثبيت

```bash
pip install llama-index llama-index-llms-openai-like llama-index-embeddings-openai-like
```

## تهيئة نموذج LLM متوافق مع OpenAI

```python
import os
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="openai/gpt-5-nano",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    is_chat_model=True,
)

response = llm.complete("Write one sentence about retrieval quality.")
print(response)
```

## الاستخدام في فهرس

```python
from llama_index.core import Settings

Settings.llm = llm
```

بعد ذلك، أنشئ الفهرس أو استعلم عنه كالمعتاد.

## ملاحظات

- استخدم `OpenAILike` لواجهات API التابعة لجهات خارجية والمتوافقة مع OpenAI.
- حدّد معرّفات نماذج التوليد والتضمين صراحةً. لا تفترض أن الإعدادات الافتراضية في LlamaIndex تشير إلى Phaseo.
- إذا استخدمت تضمينات Phaseo، فعيّن نموذج التضمين باستخدام معرّف نموذج Phaseo وعنوان URL الأساسي نفسه.
