شغّل `phaseo prime-agent` لإضافة مزوّد Phaseo مع كل نماذج Phaseo المتوافقة إلى Prime Agent. يعمل Prime Agent على macOS وLinux؛ على Windows، ثبّته وشغّل الإعداد داخل WSL.

## الإعداد باستخدام Phaseo CLI

```bash
phaseo login
phaseo prime-agent
```

إذا لم يكن Prime Agent مثبتًا، تعرض CLI أمر المثبّت الرسمي وتطلب موافقتك قبل تشغيله. ثم ينشئ الإعداد مفتاحًا باسم `Phaseo CLI: Prime Agent API Key` (تنتهي صلاحيته بعد 90 يومًا، وحد إنفاقه الشهري $100) ويكتب مزوّد `phaseo` في `~/.prime/agent/models.json`. يسرد المزوّد كل نماذج النص النشطة في Phaseo التي تعمل مع Chat Completions.

| الخيار | الأثر |
| --- | --- |
| `--model <id>` | يحدد النموذج الأولي. القيمة الافتراضية `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | يضيف النموذج المحدد فقط. |
| `--dry-run` | يعرض تغييرات الملفات دون تنفيذها. |

يحصل المزوّد على مفتاحه وقت الطلب باستخدام صيغة المفاتيح المعتمدة على الأوامر في Prime Agent، لذا لا يُكتب أي مفتاح كنص صريح في الملف:

```text
!phaseo integrations credential prime-agent
```

## التحقق من أنه يعمل

```bash
prime-agent
```

افتح `/model`، واختر المزوّد `phaseo`، وأرسل موجّهًا قصيرًا. تأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## إزالة Phaseo

```bash
phaseo integrations remove prime-agent
```

يزيل هذا الأمر مزوّد Phaseo فقط ويلغي المفتاح.
