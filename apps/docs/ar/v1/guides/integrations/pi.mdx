## الإعداد باستخدام CLI الخاصة بـ Phaseo

تتطلب هذه الأوامر الجاهزة للإنتاج حساب Phaseo؛ وتنشئ CLI بيانات اعتماد مخصصة للبوابة أثناء تسجيل الدخول والإعداد.

```bash
phaseo login
phaseo pi
```

ثبّت Pi أولًا من إصداره الرسمي. يكتب الإعداد إضافة مزوّد مُدارة في `~/.pi/agent/extensions/phaseo.ts`. وتعرض الإضافة جميع نماذج Phaseo النصية النشطة المتوافقة مع Chat Completions، وتحصل على مفتاح API المخصص من CLI الخاصة بـ Phaseo عند كل طلب.

اختر نموذجًا أوليًا أو هيّئ نموذجًا واحدًا فقط عند الحاجة:

```bash
phaseo pi --model anthropic/claude-sonnet-4.6
phaseo pi --catalog default
```

استخدم `--dry-run` لمعاينة تغييرات الملفات.

## التشغيل والتحقق

```bash
pi
```

افتح `/model`، واختر المزوّد `phaseo`، وأرسل طلبًا بسيطًا. لإزالة الإضافة المُدارة وحدها وإلغاء مفتاحها المخصص، شغّل:

```bash
phaseo integrations remove pi
```

## الوصول اليدوي إلى بيانات الاعتماد

تستخدم الإضافة المُنشأة صيغة مفتاح Pi المعتمدة على الأوامر:

```text
!phaseo integrations credential pi
```

لا يُكتب أي مفتاح بنص صريح في الإضافة.
