شغّل `phaseo pi` لإضافة امتداد مزوّد Phaseo إلى Pi مع كل نماذج Phaseo المتوافقة.

## الإعداد باستخدام Phaseo CLI

```bash
phaseo login
phaseo pi
```

إذا لم يكن Pi مثبتًا، تعرض CLI أمر التثبيت الرسمي وتطلب موافقتك قبل تشغيله. ثم ينشئ الإعداد مفتاحًا باسم `Phaseo CLI: Pi API Key` (تنتهي صلاحيته بعد 90 يومًا، وحد إنفاقه الشهري $100) ويكتب امتداد مزوّد في `~/.pi/agent/extensions/phaseo.ts`. يسرد الامتداد كل نماذج النص النشطة في Phaseo التي تعمل مع Chat Completions.

| الخيار | الأثر |
| --- | --- |
| `--model <id>` | يحدد النموذج الأولي. القيمة الافتراضية `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | يضيف النموذج المحدد فقط. |
| `--dry-run` | يعرض تغييرات الملفات دون تنفيذها. |

يحصل الامتداد على مفتاحه وقت الطلب باستخدام صيغة المفاتيح المعتمدة على الأوامر في Pi، لذا لا يُكتب أي مفتاح كنص صريح في الملف:

```text
!phaseo integrations credential pi
```

## التحقق من أنه يعمل

```bash
pi
```

افتح `/model`، واختر المزوّد `phaseo`، وأرسل موجّهًا قصيرًا. تأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## إزالة Phaseo

```bash
phaseo integrations remove pi
```

يزيل هذا الأمر امتداد Phaseo فقط ويلغي المفتاح.
