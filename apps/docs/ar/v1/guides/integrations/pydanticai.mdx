أنشئ `OpenAIChatModel` مع `OpenAIProvider` موجّه إلى `https://api.phaseo.app/v1`، فتعمل وكلاء PydanticAI على نماذج Phaseo.

## التثبيت

```bash
pip install "pydantic-ai-slim[openai]"
```

## توجيه PydanticAI إلى Phaseo

```python
import os
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-6-astra",
    provider=OpenAIProvider(
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)

agent = Agent(model, system_prompt="Answer concisely.")
result = agent.run_sync("Reply with only: ok")
print(result.output)
```

طباعة `ok` تعني أن الإعداد يعمل.

## القيود المعروفة

- يستخدم هذا المسار Chat Completions على نمط OpenAI. للميزات المتاحة على Responses فقط مثل `phaseo:apply_patch`، استدعِ نقطة النهاية Responses في Phaseo مباشرةً.
- أبقِ مخططات [المخرجات المنظمة](../structured-outputs.mdx) صغيرة بما يكفي لنافذة سياق النموذج. تحقق من الحدود في [النماذج](../../api-reference/endpoint/models.mdx).
