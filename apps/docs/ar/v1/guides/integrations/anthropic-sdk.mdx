وجّه Anthropic SDK إلى `https://api.phaseo.app` ومرّر مفتاح Phaseo بوصفه auth token. استخدم ذلك للتطبيقات والوكلاء وأدوات البرمجة التي ترسل طلبات `/v1/messages` بنمط Claude؛ إذ يخدمها Phaseo بوصفها [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx).

## التثبيت

<CodeGroup>

```bash TypeScript
npm install @anthropic-ai/sdk
```

```bash Python
pip install anthropic
```

</CodeGroup>

## توجيه العميل إلى Phaseo

<CodeGroup>

```ts TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
	apiKey: null,
	authToken: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app",
});

const message = await client.messages.create({
	model: "anthropic/claude-sonnet-5.5",
	max_tokens: 512,
	messages: [{ role: "user", content: "Reply with only: ok" }],
});

console.log(message.content);
```

```python Python
import os
from anthropic import Anthropic

client = Anthropic(
    auth_token=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app",
)

message = client.messages.create(
    model="anthropic/claude-sonnet-5.5",
    max_tokens=512,
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(message.content)
```

</CodeGroup>

تعني كتلة نصية تحتوي على `ok` أن الإعداد يعمل.

| الإعداد | السبب |
| --- | --- |
| `baseURL: "https://api.phaseo.app"` | استخدم المضيف الجذري. يضيف عملاء Anthropic `/v1/messages` بأنفسهم. |
| `authToken` (`auth_token` في Python) | يرسل `Authorization: Bearer` في كل إصدارات SDK. لا يقبل Phaseo `x-api-key`، الذي يرسله `apiKey` في الإصدارات السابقة لـ `@anthropic-ai/sdk` 1.0 و`anthropic` 2.0. |
| `apiKey: null` | يمنع إصدارات TypeScript SDK الأقدم من إرسال `ANTHROPIC_API_KEY` لديك أيضًا. ترسله إصدارات Python SDK السابقة لـ 0.98 كلما كان معيّنًا، لذا حدّث الإصدار، أو ألغِ تعيينه حيث تستدعي Phaseo. |

## الحدود المعروفة

- تعمل أشكال الأدوات الأصلية في Anthropic حيث يدعمها Phaseo. تستخدم أدوات الخادم التي تعمل عبر المزوّدين أسماء أدوات Phaseo؛ راجع [استدعاء الأدوات](../tool-calling.mdx).
- العملاء المتوافقون مع Anthropic صارمون في ترتيب أحداث الأدوات. اختبر حلقات الأدوات المبثوثة قبل الإنتاج.
- لـ [Claude Code](./claude-code.mdx)، استخدم الدليل الخاص به.
