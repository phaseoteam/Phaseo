وجّه OpenAI SDK الرسمية إلى Phaseo بتغيير ثلاثة أشياء: مفتاح API، وBase URL ‏(`https://api.phaseo.app/v1`)، ومعرّف النموذج.

## التثبيت

<CodeGroup>

```bash TypeScript
npm install openai
```

```bash Python
pip install openai
```

</CodeGroup>

## توجيه العميل إلى Phaseo

<CodeGroup>

```ts TypeScript
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Write one sentence about reliable model routing.",
});

console.log(response.output_text);
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Write one sentence about reliable model routing.",
)

print(response.output_text)
```

</CodeGroup>

طباعة جملة تعني أن المفتاح وBase URL يعملان. يظهر الطلب أيضًا في **الإعدادات → الاستخدام → السجلات**.

## استخدام Chat Completions

يعمل الكود الذي يستدعي Chat Completions مع العميل نفسه:

```ts
const completion = await client.chat.completions.create({
	model: "openai/gpt-6-astra",
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## القيود المعروفة

- استخدم معرّفات نماذج Phaseo مع بادئة المزوّد: `openai/` و`anthropic/` و`google/` وهكذا. راجع [Responses](../../api-reference/endpoint/responses.mdx) و[Chat Completions](../../api-reference/endpoint/chat-completions.mdx) للاطلاع على أشكال الطلبات كاملة.
- تستخدم [أدوات الخادم](../server-tools/index.mdx) أسماء أدوات Phaseo، مثل `phaseo:web_search`.
- لعملاء `/v1/messages` على نمط Anthropic، استخدم دليل [Anthropic SDK](./anthropic-sdk.mdx).
