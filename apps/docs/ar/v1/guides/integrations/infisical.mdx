دوّر مفاتيح API في Phaseo دون توقف بإنشاء مفتاح بديل باستخدام [مفتاح إدارة](../../developers/management-api-keys.mdx)، ثم نقل تطبيقك إليه، ثم حذف المفتاح القديم. تقدم هذه الصفحة القيم التي يستخدمها اتصال Infisical لهذا التدوير.

<Warning>
Phaseo ليس بعد App Connection قابلًا للاختيار في Infisical. لا يزال على Infisical قبول الموصّل والاختبارات وإدخال الواجهة. حتى ذلك الحين، استخدم الطلبات أدناه من مهمة التدوير الخاصة بك.
</Warning>

## كيف يعمل التدوير

```mermaid
flowchart LR
  mk["مفتاح الإدارة"] -->|"POST /v1/keys"| newkey["مفتاح API جديد"]
  newkey -->|"الحفظ في السر"| app["يستخدم التطبيق المفتاح الجديد"]
  app -->|"DELETE /v1/keys/{id}"| old["إلغاء المفتاح القديم"]
```

يعرض Phaseo قيمة مفتاح API مرة واحدة فقط، عند إنشائه. يعمل المفتاحان القديم والجديد معًا حتى تحذف القديم، لذا يمكن لتطبيقك الانتقال بينما يُحدَّث السر.

## إنشاء مفتاح إدارة محدود الصلاحيات

في **الإعدادات → مفاتيح الإدارة**، أنشئ مفتاحًا بهذه الصلاحيات:

| الصلاحية | تُستخدم من أجل |
| --- | --- |
| `keys:read` | التحقق من الاتصال وسرد المفاتيح المُدارة. |
| `keys:write` | إنشاء مفاتيح بديلة. |
| `keys:delete` | إلغاء المفاتيح القديمة. |

احفظ قيمة `phaseo_v1_mk_...` في Infisical. تتحكم مفاتيح الإدارة في حسابك ولا يمكن استخدامها للاستدلال.

## تفاصيل الاتصال

| الحقل | القيمة |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| المصادقة | `Authorization: Bearer <PHASEO_MANAGEMENT_KEY>` |
| التحقق من الاتصال | `GET /keys` |
| سرد مفاتيح API | `GET /keys` |
| إنشاء مفتاح API | [`POST /keys`](../../api-reference/endpoint/keys-create.mdx) |
| إلغاء مفتاح API | [`DELETE /keys/{id}`](../../api-reference/endpoint/keys-delete.mdx) |

## إنشاء المفتاح البديل

```bash
curl https://api.phaseo.app/v1/keys \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "infisical-production",
    "limit": 100,
    "limit_reset": "monthly",
    "include_byok_in_limit": false
  }'
```

تحتوي الاستجابة على المفتاح الجديد مرة واحدة في `data.key`، وعلى معرّفه في `data.id`.

| الحقل | القيم |
| --- | --- |
| `limit` | حد الإنفاق بالدولار الأمريكي. |
| `limit_reset` | `daily` أو `weekly` أو `monthly`. |
| `include_byok_in_limit` | مقبول للتوافق فقط. لا يُحتسب استخدام BYOK أبدًا ضمن هذا الحد. |

## إلغاء المفتاح القديم

```bash
curl -X DELETE https://api.phaseo.app/v1/keys/$PREVIOUS_KEY_ID \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY"
```

الحذف متساوي الأثر: حذف مفتاح محذوف بالفعل يعيد `200` مع `{"deleted": true}`، لذا فإن إعادة محاولة التدوير آمنة.
