شغّل `phaseo roo-code` لإنشاء مفتاح، ثم أضف ملف تعريف من نوع **OpenAI Compatible** في Roo Code. يحتفظ Roo Code بالمفاتيح في مخزن الأسرار الخاص بـ VS Code، لذا تتم هذه الخطوة الأخيرة في واجهته.

## الإعداد باستخدام Phaseo CLI

```bash
phaseo login
phaseo roo-code --model anthropic/claude-sonnet-5.5
```

تنشئ CLI مفتاحًا باسم `Phaseo CLI: Roo Code API Key` تنتهي صلاحيته بعد 90 يومًا وله حد إنفاق شهري قدره $100، ثم تطبع القيم اللازمة للخطوة التالية.

## إعداد Roo Code

1. افتح Roo Code في VS Code، ثم **Settings → Providers**.
2. أنشئ ملف تعريف لإعداد المزوّد واختر **OpenAI Compatible**.
3. أدخل:

| حقل Roo Code | القيمة |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | ناتج الأمر `phaseo integrations credential roo-code`، أو أي مفتاح API من Phaseo |
| Model | `anthropic/claude-sonnet-5.5`، أو النموذج الذي يطبعه الإعداد |

4. احفظ ملف التعريف واجعله نشطًا.

تتغير تسميات الحقول قليلًا بين الإصدارات؛ راجع وثائق [مزوّدي النماذج](https://docs.roocode.com/providers/) في Roo Code إذا كانت تسمياتك مختلفة.

## التحقق من أنه يعمل

اطلب من Roo Code الرد بـ `PHASEO_ROO_OK`، ثم تأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## إزالة Phaseo

احذف ملف تعريف Phaseo أو انتقل إلى ملف تعريف آخر، ثم شغّل:

```bash
phaseo integrations remove roo-code
```

يلغي هذا الأمر المفتاح. لا تستطيع CLI مسح مخزن إضافات VS Code.

## إصلاح المشكلات الشائعة

### تفشل المصادقة

انسخ المفتاح مرة أخرى باستخدام `phaseo integrations credential roo-code`، وتأكد من أن Base URL ينتهي بـ `/v1`.

### لا يعثر Roo Code على النموذج

اكتب معرّف نموذج Phaseo الدقيق، بما في ذلك بادئة المزوّد.

### تعمل الدردشة لكن الأدوات تفشل

انتقل إلى نموذج يدعم استدعاء الأدوات.
