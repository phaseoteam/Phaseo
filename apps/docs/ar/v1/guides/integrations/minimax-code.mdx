شغّل `phaseo minimax` لبدء جلسة MiniMax Code ‏(`mcode`) عبر Phaseo، أو أضف Phaseo باستخدام `mcode provider add` للإبقاء عليه في كل جلسة.

## تشغيل MiniMax Code عبر Phaseo CLI

```bash
phaseo login
phaseo minimax --model openai/gpt-5.6-terra
```

ينشئ المشغّل مفتاحًا مخصصًا، ويضبط `MINIMAX_DATA_DIR` على مجلد مؤقت، ويضيف مزوّد Phaseo هناك باستخدام `mcode provider add`، ويشغّل `mcode`، ثم يحذف المجلد عند خروج `mcode`. لا يتغير إعداد `~/.minimax` المعتاد لديك، ولا يُمرَّر المفتاح إلا إلى عملية إعداد المزوّد. ضع خيارات MiniMax Code الخاصة بعد `--`.

| الخيار | الأثر |
| --- | --- |
| `--model <id>` | النموذج المستخدم. القيمة الافتراضية `openai/gpt-5.6-terra`. |
| `--catalog all` | يسجّل كل نماذج النص النشطة في Phaseo التي تعمل مع Chat Completions. |
| `--dry-run --json` | يعرض خطة التثبيت والتشغيل دون إنشاء مفتاح. |
| `--skip-install` | يتخطى فحص التثبيت. |

`phaseo run minimax ...` هو الصيغة الطويلة للأمر نفسه.

إذا لم يكن `mcode` مثبتًا، يعرض أول تشغيل تفاعلي تثبيته بمثبّت MiniMax الرسمي (مثبّت PowerShell على Windows). إذا كنت تدير MiniMax Code بنفسك، فثبّته، وتحقق من `mcode --version`، وأعد التشغيل باستخدام `--skip-install`.

## إعداد MiniMax Code يدويًا

للإبقاء على مزوّد Phaseo، أضفه باستخدام أمر MiniMax Code الخاص:

```bash
export MCODE_PROVIDER_API_KEY="your_phaseo_api_key"
mcode provider add \
  --name "Phaseo" \
  --base-url "https://api.phaseo.app/v1" \
  --api-format openai-completions \
  --model "openai/gpt-5.6-terra" \
  --use
```

يحفظ MiniMax Code المزوّد في مجلد بياناته.

## التحقق من أنه يعمل

أرسل موجّهًا قصيرًا وتأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## إصلاح المشكلات الشائعة

### MiniMax Code غير مثبت

شغّل الأمر في طرفية تفاعلية للموافقة على المثبّت الرسمي، أو ثبّت MiniMax Code بنفسك وأعد التشغيل باستخدام `--skip-install`.

### المزوّد أو النموذج غير مدرج

استخدم `phaseo minimax --catalog all`، أو مرّر معرّف النموذج باستخدام `--model`.

### تحتاج إلى ACP بدلًا من CLI التفاعلية

يشغّل `phaseo minimax` واجهة CLI التفاعلية. يعمل MiniMax Code أيضًا كعملية ACP باستخدام `mcode acp`؛ استخدم إعداد ACP في MiniMax Code عندما يتعامل محررك أو مضيفك مع ACP مباشرةً.
