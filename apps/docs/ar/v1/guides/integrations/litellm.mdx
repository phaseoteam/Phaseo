زوّد LiteLLM بالنموذج `openai/<Phaseo model ID>` ومفتاح Phaseo و`api_base="https://api.phaseo.app/v1"`. يعمل هذا مع استدعاءات LiteLLM المباشرة ومع النماذج خلف وكيل LiteLLM.

## التثبيت

```bash
pip install litellm
```

## استدعاء Phaseo من LiteLLM

```python
import os
from litellm import completion

response = completion(
    model="openai/openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(response.choices[0].message.content)
```

طباعة `ok` تعني أن الإعداد يعمل. يستخدم LiteLLM البادئة `openai/` لنقاط النهاية المتوافقة مع OpenAI. يبقى معرّف نموذج Phaseo هو `openai/gpt-6-astra`، لذا تصبح سلسلة النموذج في LiteLLM هي `openai/openai/gpt-6-astra`.

## إضافة نماذج Phaseo إلى وكيل LiteLLM

امنح كل نموذج اسمًا مستعارًا حتى لا يحتاج كود التطبيق إلى بادئة LiteLLM:

```yaml
model_list:
  - model_name: phaseo-gpt-6-astra
    litellm_params:
      model: openai/openai/gpt-6-astra
      api_key: os.environ/PHASEO_API_KEY
      api_base: https://api.phaseo.app/v1
```

ثم استدعِ الوكيل باستخدام `model: "phaseo-gpt-6-astra"`. تُبقي الأسماء المستعارة أسماء النماذج مقروءة في الإنتاج.

## القيود المعروفة

- تغيّر بعض طبقات الوكيل أنواع الأدوات التي لا تعرفها أو تحذفها. إذا كنت تستخدم [أدوات الخادم](../server-tools/index.mdx) في Phaseo، فاختبر مسار LiteLLM المحدد.
- يتتبّع كل من LiteLLM وPhaseo الإنفاق. قرّر أيهما مرجعك للتكلفة؛ أسعار Phaseo موجودة في [حاسبة الأسعار](../../api-reference/endpoint/pricing-calculate.mdx).
