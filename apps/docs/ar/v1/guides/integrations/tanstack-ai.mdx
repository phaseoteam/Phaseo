استخدم TanStack AI عندما تريد تدفقات دردشة آمنة الأنواع في React أو Solid أو Preact أو Vue أو Svelte أو TypeScript على الخادم.

## التثبيت

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## تهيئة المحوّل

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-5-nano", "anthropic/claude-sonnet-4.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-5-nano"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## ملاحظات

- صرّح بمعرّفات نماذج Phaseo التي تنوي استخدامها في مصفوفة `models`.
- يستخدم المحوّل المتوافق مع OpenAI واجهة Chat Completions افتراضيًا. استخدم استدعاءات API مباشرة لميزات Responses فقط.
- إذا لم يدعم النموذج الأدوات أو الصور في سير عملك، فصرّح بإمكانات أضيق في TanStack AI كي يكتشف TypeScript الاستدعاءات غير المدعومة مبكرًا.
