أنشئ محوّل `openaiCompatible` في TanStack AI بمفتاح Phaseo و`baseURL: "https://api.phaseo.app/v1"` ومعرّفات نماذج Phaseo التي تستخدمها. يعمل للدردشة الآمنة الأنواع في React أو Solid أو Preact أو Vue أو Svelte أو TypeScript على الخادم.

## التثبيت

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## توجيه المحوّل إلى Phaseo

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-6-astra", "anthropic/claude-sonnet-5.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-6-astra"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

صرّح في `models` بكل معرّف نموذج Phaseo تنوي استخدامه. تحقق من المعرّفات في [النماذج](../../api-reference/endpoint/models.mdx).

## القيود المعروفة

- يستخدم المحوّل Chat Completions. للميزات المتاحة على Responses فقط، استدعِ Phaseo مباشرةً أو استخدم [OpenAI SDK](./openai-sdk.mdx).
- إذا كان النموذج لا يدعم [الأدوات](../tool-calling.mdx) أو الصور، فصرّح بقدرات أضيق في TanStack AI حتى يكتشف TypeScript الاستدعاءات غير المدعومة.
