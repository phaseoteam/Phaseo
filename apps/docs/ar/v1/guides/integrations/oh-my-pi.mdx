شغّل `phaseo omp` لبدء جلسة oh-my-pi عبر Phaseo، أو أضف مزوّد `phaseo` إلى `~/.omp/agent/models.yml` للإبقاء على Phaseo في كل جلسة.

## تشغيل oh-my-pi عبر Phaseo CLI

```bash
phaseo login
phaseo omp --model openai/gpt-5.6-terra
```

ينشئ المشغّل مفتاحًا مخصصًا، ويكتب `models.yml` داخل `PI_CODING_AGENT_DIR` مؤقت، ويشغّل `omp` باستخدام `--model phaseo/<model>`، ثم يحذف المجلد عند خروج oh-my-pi. إذا لم يكن `omp` مثبتًا، يعرض أول تشغيل تفاعلي تثبيته. ضع خيارات oh-my-pi الخاصة بعد `--`.

| الخيار | الأثر |
| --- | --- |
| `--model <id>` | النموذج المستخدم. القيمة الافتراضية `openai/gpt-5.6-terra`. |
| `--catalog all` | يعرض كل نماذج النص النشطة في Phaseo، لا النموذج المحدد فقط. |
| `--dry-run --json` | يعرض خطة التثبيت والتشغيل دون إنشاء مفتاح أو بدء oh-my-pi. |
| `--skip-install` | يتخطى فحص التثبيت. |

`phaseo run omp ...` هو الصيغة الطويلة للأمر نفسه.

## إعداد oh-my-pi يدويًا

أنشئ مفتاحًا من **الإعدادات → مفاتيح API** في لوحة التحكم، وصدّره في الصدفة التي تشغّل oh-my-pi، وأنشئ مجلد الإعداد:

```bash
export PHASEO_OMP_API_KEY="<your Phaseo API key>"
mkdir -p ~/.omp/agent
```

أضف المزوّد:

```yaml ~/.omp/agent/models.yml
providers:
  phaseo:
    baseUrl: https://api.phaseo.app/v1
    api: openai-completions
    apiKey: PHASEO_OMP_API_KEY
    authHeader: true
    models:
      - id: openai/gpt-5.6-terra
        name: GPT-5.6 Terra via Phaseo
        contextWindow: 32768
        maxTokens: 8192
```

يحدد `apiKey` اسم متغير البيئة، فيبقى المفتاح خارج `models.yml`. أضف مزيدًا من الإدخالات تحت `models` حسب الحاجة؛ الحدود أعلاه أمثلة. ابدأ oh-my-pi بمعرّف النموذج المقترن بالمزوّد:

```bash
omp --model phaseo/openai/gpt-5.6-terra
```

راجع وثائق [إعداد المزوّدين](https://github.com/can1357/oh-my-pi/blob/main/docs/providers.md) في oh-my-pi لمعرفة الحقول الأخرى.

## التحقق من أنه يعمل

أرسل موجّهًا قصيرًا وتأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## إصلاح المشكلات الشائعة

### oh-my-pi غير مثبت

شغّل الأمر في طرفية تفاعلية للموافقة على التثبيت، أو ثبّت oh-my-pi بنفسك وأعد التشغيل باستخدام `--skip-install`.

### النموذج غير مدرج

استخدم `--catalog all`، أو مرّر معرّف النموذج باستخدام `--model`. لا يحتاج Phaseo إلى اكتشاف النماذج.
