شغّل `phaseo opencode` لإضافة مزوّد Phaseo مع كل نماذج Phaseo المتوافقة إلى OpenCode، أو أضف مزوّد `phaseo` إلى `opencode.json` بنفسك.

## الإعداد باستخدام Phaseo CLI

```bash
phaseo login
phaseo opencode --model openai/gpt-5.6-terra
```

إذا لم يكن OpenCode مثبتًا، تعرض CLI أمر التثبيت الرسمي وتطلب موافقتك قبل تشغيله. ثم يقوم الإعداد بما يلي:

- يضيف مزوّد `phaseo` عامًا مع كل نماذج النص النشطة في Phaseo التي تعمل مع Chat Completions. يحدّث ملف `opencode.jsonc` العام إن وُجد، وإلا فـ `~/.config/opencode/opencode.json`، ويترك إعداداتك الأخرى كما هي؛
- ينشئ مفتاحًا باسم `Phaseo CLI: OpenCode API Key` تنتهي صلاحيته بعد 90 يومًا وله حد إنفاق شهري قدره $100، ويحفظه في مخزن بيانات الاعتماد في OpenCode. تحتفظ CLI بنسخة خاصة بها في مخزن بيانات الاعتماد في نظام التشغيل. شغّل `phaseo opencode` مرة أخرى لاستبدال مفتاح منتهي الصلاحية.

استخدم `--catalog default` لإضافة النموذج المحدد فقط، أو `--dry-run` لمعاينة التغييرات.

## إعداد OpenCode يدويًا

أضف المزوّد إلى `opencode.json` في مشروعك، أو إلى إعداد OpenCode العام:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-6-astra",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-6-astra": { "name": "GPT-6 Astra" },
        "openai/gpt-5.4-mini": { "name": "GPT-5.4 Mini" },
        "anthropic/claude-sonnet-5.5": { "name": "Claude Sonnet 5.5" }
      }
    }
  }
}
```

صدّر `PHASEO_API_KEY`، وأضف إدخالات إلى `models` أو احذفها لاختيار نماذج Phaseo التي يسردها OpenCode.

## التحقق من أنه يعمل

أعد تشغيل OpenCode، واختر نموذج Phaseo من `/models`، وأرسل موجّهًا قصيرًا قبل بدء العمل على تعديل الملفات. تأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## إزالة Phaseo

```bash
phaseo integrations remove opencode
```

يزيل هذا الأمر مزوّد Phaseo وبيانات اعتماده المحفوظة فقط، ثم يلغي المفتاح.

## إصلاح المشكلات الشائعة

| المشكلة | الحل |
| --- | --- |
| يُرفض نموذج | تحقق من المعرّف الدقيق باستخدام [نقطة نهاية النماذج](../../api-reference/endpoint/models.mdx). |
| تفشل المصادقة | أعد تشغيل `phaseo opencode` وتحقق من `opencode auth list`. |

ليتمكن OpenCode من قراءة وثائق Phaseo أثناء الجلسة، أضف خادم [Docs MCP](./docs-mcp.mdx).
