---

أضف `https://phaseo.app/docs/mcp` إلى وكيل البرمجة كخادم MCP ليجيب عن أسئلة Phaseo من الوثائق الحية بدلًا من بيانات تدريبه. الخادم للقراءة فقط: يمكن للوكلاء البحث في الوثائق، وقراءة الصفحات كاملة، وقراءة ملخص القدرات المستضاف [skill.md](https://phaseo.app/docs/skill.md).

## Codex

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
codex mcp list
```

## Claude Code

أضف الخادم إلى المشروع الحالي، أو أضف `--scope user` لإتاحته في كل المشاريع:

```bash
claude mcp add --transport http phaseo-docs https://phaseo.app/docs/mcp
claude mcp add --transport http --scope user phaseo-docs https://phaseo.app/docs/mcp
claude mcp list
```

## Cursor

ثبّته من القائمة السياقية في أي صفحة من الوثائق، أو أضفه إلى إعداد MCP في Cursor:

```json
{
  "mcpServers": {
    "phaseoDocs": {
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## VS Code

ثبّته من القائمة السياقية في أي صفحة من الوثائق، أو أضفه إلى إعداد MCP في VS Code:

```json
{
  "servers": {
    "phaseoDocs": {
      "type": "http",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## OpenCode

أضفه إلى `opencode.json`:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "phaseoDocs": {
      "type": "remote",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## التحقق من أنه يعمل

اسأل الوكيل سؤالًا لا تجيب عنه إلا الوثائق، وتأكد من أنه يستدعي خادم وثائق Phaseo:

- `Look up the Responses request format in the Phaseo docs and give me a minimal example.`
- `Use the Phaseo docs MCP server to check how provider.sort works before you change this request.`
- `Find the guardrails docs in Phaseo and summarize the parts that affect provider routing.`

يستخدمه الوكلاء للتحقق من أشكال الطلبات، ونقاط النهاية التي يدعمها نموذج أو مزوّد، وسلوك التوجيه والإعدادات المسبقة وحواجز الحماية والمهام غير المتزامنة. لا يجعل خادم الوثائق Phaseo بوابة النماذج لديك؛ لذلك، راجع [وكلاء البرمجة](./coding-assistants.mdx).
