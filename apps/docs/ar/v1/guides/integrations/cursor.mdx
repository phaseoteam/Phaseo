شغّل `phaseo cursor` لإنشاء مفتاح، ثم فعّل إعدادَي مفتاح OpenAI API و**Override OpenAI Base URL** في Cursor. يوجّه هذا نماذج الدردشة في Cursor عبر Phaseo؛ أما الميزات التي تستخدم نماذج Cursor الخاصة، مثل الإكمال بزر Tab، فقد تستمر في استخدام بنية Cursor التحتية.

## الإعداد باستخدام Phaseo CLI

```bash
phaseo login
phaseo cursor --model openai/gpt-5.6-terra
```

تنشئ CLI مفتاحًا باسم `Phaseo CLI: Cursor API Key` تنتهي صلاحيته بعد 90 يومًا وله حد إنفاق شهري قدره $100، وتطبع الإعدادات أدناه. شغّل `phaseo cursor` مرة أخرى للحصول على مفتاح جديد بعد انتهاء الصلاحية. لا تعدّل CLI مخزن بيانات الاعتماد في Cursor.

## إعداد Cursor

1. افتح **Cursor Settings → Models**.
2. ابحث عن قسم **OpenAI API Key** وفعّله.
3. الصق المفتاح الناتج عن `phaseo integrations credential cursor`، أو أي مفتاح API من Phaseo.
4. فعّل **Override OpenAI Base URL** وأدخل `https://api.phaseo.app/v1`، دون شرطة مائلة في النهاية.
5. أضف نموذج Phaseo الذي تريده أو فعّله.

| حقل Cursor | القيمة |
| --- | --- |
| OpenAI API Key | ناتج الأمر `phaseo integrations credential cursor` |
| Override OpenAI Base URL | `https://api.phaseo.app/v1` |
| Model | معرّف نموذج Phaseo يقبله Cursor |

إعدادا المفتاح وBase URL في Cursor عامّان، وليسا لكل مزوّد: المفتاح وBase URL المفعّلان يحددان وجهة كل طلب من عائلة OpenAI، ويُمرَّر اسم النموذج كما هو. تحفظ بعض الإصدارات المفتاح دون زر **Verify**؛ اختبر بدردشة جديدة بدلًا من ذلك. راجع [وثائق مفاتيح API](https://docs.cursor.com/settings/api-keys) في Cursor.

## التحقق من أنه يعمل

1. أبقِ المفتاح وتجاوز Base URL مفعّلين.
2. اختر النموذج في منتقي النماذج في Cursor وابدأ دردشة جديدة.
3. اطلب منه الرد بـ `PHASEO_CURSOR_OK`.
4. تأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## إزالة Phaseo

عطّل مفتاح OpenAI API وتجاوز Base URL في **Cursor Settings → Models**، ثم ألغِ المفتاح:

```bash
phaseo integrations remove cursor
```

لا تستطيع CLI مسح مخزن بيانات الاعتماد في Cursor. إذا ظل المفتاح ظاهرًا كمُعدّ، فاحذفه من إعدادات Models في Cursor.

## إصلاح المشكلات الشائعة

### تتوقف النماذج التي يستضيفها Cursor عن العمل

يطبّق Cursor تجاوز Base URL على كل نماذج عائلة OpenAI. أوقف **Override OpenAI Base URL** قبل العودة إلى نموذج يستضيفه Cursor.

### يُرفض النموذج

قد يرفض Cursor المعرّفات التي تتعارض مع كتالوجه المدمج أو لا تناسب توجيه عائلة OpenAI لديه، وترفض بعض الإصدارات المعرّفات التي تحتوي على بادئة مزوّد. جرّب نموذج Phaseo آخر يقبله Cursor كنموذج مخصّص من عائلة OpenAI.

### تفشل المصادقة

شغّل `phaseo integrations credential cursor` مرة أخرى، واستبدل المفتاح في Cursor، وتأكد من أن Base URL هو `https://api.phaseo.app/v1` تمامًا.
