ثبّت `@phaseo/cli` وشغّل `phaseo login` لربط وكلاء البرمجة بـ Phaseo وإدارة المفاتيح ومساحات العمل والإعدادات المسبقة والإعدادات وحواجز الحماية من الطرفية. تقرأ CLI أيضًا النماذج والمزوّدين والأسعار والرصيد والنشاط والتحليلات وعمليات التوليد.

## التثبيت

<CodeGroup>

```bash npm
npm install -g @phaseo/cli
```

```bash pnpm
pnpm add -g @phaseo/cli
```

```bash yarn
yarn global add @phaseo/cli
```

```bash bun
bun add -g @phaseo/cli
```

</CodeGroup>

تحقق من الإصدار:

| الأمر | يطبع |
| --- | --- |
| `phaseo --version` | الإصدار المثبت. |
| `phaseo version` | الإصدار وأمر التحديث لمدير الحزم لديك. أضف `--json` للحصول على مخرجات منظمة. |

تعرض عمليات التشغيل التفاعلية أيضًا تلميحًا عند نشر إصدار أحدث.

## تسجيل الدخول

```bash
phaseo login
```

| المسار | الخيار | استخدمه لـ |
| --- | --- | --- |
| Sign in with Phaseo | `--browser` | OAuth عبر المتصفح باستخدام رمز التفويض وPKCE. |
| Sign in with Device Code | `--device-code` | SSH وCI والصدفات دون واجهة وبيئات الوكلاء. |

تستخدم البيئات البعيدة وغير التفاعلية رمز الجهاز تلقائيًا. تحقق من الحساب الذي سجّلت الدخول به، مع نطاقاتك ومساحة العمل النشطة ومساحات العمل الأخرى:

```bash
phaseo whoami
phaseo whoami --json
```

## إنشاء المفاتيح وإدارة مساحة العمل

```bash
phaseo keys create --name "Local CLI Key"
phaseo keys create --name "Agent Sandbox Key" --json
phaseo keys current

phaseo workspaces list
phaseo workspaces members <workspace-id-or-slug>

phaseo guardrails list
phaseo guardrails create --name "Production Safety" --body-json '{"enabled":true}'
```

استخدم `--json` عندما يحتاج وكيل أو برنامج نصي إلى المفتاح الجديد؛ فهو يُعرض مرة واحدة فقط. تغطي CLI مهام الإدارة في لوحة التحكم، بما فيها الفوترة والميزانيات وBYOK والتوجيه والهوية. راجع [إدارة Phaseo من وكيل](../../developers/manage-from-an-agent) لمعرفة الأمر الخاص بكل مهمة.

## ربط وكيل برمجة

استخدم اسم الوكيل كأمر. تطلب CLI مفتاحًا مخصصًا توافق عليه في المتصفح، ثم تكتب إعداد الوكيل:

```bash
phaseo codex
phaseo claude-code
phaseo opencode
phaseo fx
phaseo deepseek-harness
phaseo pi
phaseo prime-agent
phaseo openclaw
phaseo hermes
phaseo aider
phaseo continue
phaseo zed
phaseo roo-code
phaseo kilo-code
phaseo cursor
```

استخدم `--model` أو `--catalog all|default` أو `--dry-run` حسب الحاجة. يعمل أيضًا `phaseo setup <agent>` و`phaseo integrations setup <agent>`.

### الموافقة على المفتاح في المتصفح

عند إعداد وكيل لأول مرة، تفتح CLI صفحة في لوحة تحكم Phaseo وتعرض رابطها. تعرض الصفحة مساحة العمل واسم المفتاح وحد الإنفاق الشهري البالغ $100 وانتهاء الصلاحية بعد 90 يومًا، وأن Phaseo CLI هي التي طلبته. اختر **الموافقة وإنشاء المفتاح** لتستلم CLI المفتاح مرة واحدة وتُكمل الإعداد. إذا اخترت **رفض**، أو تركت الطلب حتى تنتهي صلاحيته بعد 10 دقائق، فلن يُنشأ أي شيء.

وافق وأنت مسجّل الدخول إلى لوحة التحكم بالحساب الذي استخدمته في CLI، بصفتك مالكًا لمساحة العمل أو مسؤولًا عنها، ومع عامل التحقق الثاني إذا كنت قد أعددته. لا يمكن لتسجيل الدخول عبر CLI وحده إنشاء مفاتيح. عبر SSH أو في CI، افتح الرابط المعروض على أي جهاز سجّلت الدخول عليه.

لاستخدام مفتاح أنشأته في لوحة التحكم بدلًا من ذلك، مرّره باستخدام `--key <key>`، أو باستخدام `--key-stdin` لإبقائه خارج سجل الصدفة. تتحقق CLI من المفتاح وتحفظه، ولا تلغيه عند إزالة الوكيل.

لتشغيل Cline أو Kilo Code أو oh-my-pi أو Muse Code أو MiniMax Code بإعدادات مؤقتة تُحذف عند خروجه، استخدم مشغّل الجلسات. توضع خيارات Phaseo قبل `--`، وخيارات الوكيل الخاصة بعده:

```bash
phaseo cline --model openai/gpt-5.6-terra -- --tui
phaseo kilo --model openai/gpt-5.6-terra
phaseo omp --model openai/gpt-5.6-terra
phaseo muse --model meta/muse-spark-1.3
phaseo minimax --model openai/gpt-5.6-terra
```

`phaseo run <cline|kilo|omp|muse|minimax>` هو الصيغة الطويلة. أضف `--catalog all` لسرد كل نماذج النص النشطة في Phaseo، أو `--dry-run --json` للمعاينة دون إنشاء مفتاح. تعرض المشغّلات تثبيت الوكيل المفقود في الطرفية التفاعلية (يستخدم MiniMax Code مثبّت PowerShell الرسمي على Windows؛ ويجب تثبيت Muse Code يدويًا على Windows). استخدم `--skip-install` عندما تدير الوكيل بنفسك.

تسرد صفحة [وكلاء البرمجة](./coding-assistants.mdx) كل وكيل، وما يفعله أمره، ودليله.

## كتابة البرامج النصية باستخدام CLI

تطبع الأوامر مع `--json` مخرجات منظمة عادية دون ألوان أو مؤشرات دوّارة. في غير ذلك، تذهب المؤشرات الدوّارة إلى `stderr` وتمسح سطرها عند الانتهاء.

| المتغير | الأثر |
| --- | --- |
| `NO_COLOR` | يوقف الألوان. |
| `TERM=dumb` | يوقف الحركة. ويؤدي `stderr` غير المتصل بـ TTY الأثر نفسه. |
| `FORCE_COLOR=1` | يفرض الألوان عندما يدعمها غلاف الطرفية لكنه لا يبلّغ عن TTY. |

## كيف تحافظ CLI على أمان بيانات الاعتماد

- تُحفظ الجلسات في مخزن بيانات الاعتماد في نظام التشغيل. اضبط `PHASEO_SESSION_BACKEND=file` فقط إذا لم يتوفر مخزن لبيانات الاعتماد؛ فهو يحفظ رموز التحديث في ملف نصي صريح مقيّد الأذونات.
- يلغي `phaseo logout` رمز التحديث المحفوظ قبل مسح الحالة المحلية.
- تحتاج مفاتيح الإدارة إلى صلاحيات صريحة. تُقيَّد مفاتيح الاستدلال بحواجز الحماية وسياسات التوجيه وإعدادات مساحة العمل بدلًا من النطاقات.

## تطبيقات OAuth

يستخدم Phaseo خادم تفويض OAuth واحدًا لـ CLI والتطبيقات التي ينشئها المستخدمون وعملاء MCP المسجّلين ديناميكيًا. تستخدم CLI تسجيل الدخول عبر المتصفح أو الجهاز مع رموز تحديث متناوبة. تستخدم العملاء الخارجية رمز التفويض مع PKCE، ونطاقات صريحة وموافقة على مساحة العمل، وربطًا اختياريًا بالمورد المحمي. تحصل على رمز وصول قابل للإلغاء يدوم 7 أيام ورمز تحديث متناوب يدوم 90 يومًا من آخر استخدام له؛ راجع [إنشاء Workbench لـ OAuth باستخدام Next.js](../../cookbook/build-an-oauth-nextjs-workbench) لمعرفة كيفية عمل التحديث. الموافقة على التطبيق نفسه مرة أخرى تجدد مفتاحه بدلًا من إضافة مفتاح ثانٍ.

تفعّل واجهة Phaseo API المستضافة OAuth للجهات الخارجية. تُبقيه عمليات نشر API المستضافة ذاتيًا ونشر المعاينة معطّلًا ما لم تكن قيمة `PHASEO_THIRD_PARTY_OAUTH_ENABLED` صحيحة: `1` أو `true` أو `yes` أو `on`، دون تمييز حالة الأحرف، مع تجاهل المسافات المحيطة.

```bash .env
PHASEO_THIRD_PARTY_OAUTH_ENABLED=true
```

يكشف تفعيله إدارة تطبيقات OAuth التي ينشئها المستخدمون والتسجيل الديناميكي للعملاء، لذا راجع أولًا إعدادات URI إعادة التوجيه والموافقة وسر العميل وحدود المعدل وتفويض مساحة العمل.

```bash
phaseo update
```

npm install -g @phaseo/cli@latest

pnpm add -g @phaseo/cli@latest
