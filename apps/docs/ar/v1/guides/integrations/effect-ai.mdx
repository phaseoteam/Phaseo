استخدم هذا الدليل إذا كان تطبيقك يستخدم Effect بالفعل وتريد الوصول إلى Phaseo من خدمة أو سير عمل Effect.

## الحالة

يوفر Phaseo نقاط نهاية HTTP متوافقة مع OpenAI. وتفيد حزم المزوّد الرسمية في Effect عندما تدعم المزوّد المطلوب مباشرةً؛ وإذا لم توفر حزمة OpenAI المثبتة في Effect خيار عنوان URL أساسي، فاتصل بـ Phaseo عبر عميل HTTP في Effect أو غلّف [OpenAI SDK](./openai-sdk.mdx) في طبقة Effect خاصة بك.

## التثبيت

```bash
npm install effect @effect/platform
```

## استدعاء Phaseo عبر Effect HTTP

```ts
import { FetchHttpClient, HttpClient, HttpClientRequest } from "@effect/platform";
import { Config, Effect, Redacted } from "effect";

const generate = Effect.gen(function* () {
	const apiKey = yield* Config.redacted("PHASEO_API_KEY");
	const client = yield* HttpClient.HttpClient;

	const request = HttpClientRequest.post(
		"https://api.phaseo.app/v1/chat/completions",
	).pipe(
		HttpClientRequest.bearerToken(Redacted.value(apiKey)),
		HttpClientRequest.jsonBody({
			model: "openai/gpt-5-nano",
			messages: [{ role: "user", content: "Reply with only: ok" }],
		}),
	);

	return yield* client.execute(request).pipe(
		Effect.flatMap((response) => response.json),
	);
});

const runnable = generate.pipe(Effect.provide(FetchHttpClient.layer));
```

## تضمين OpenAI SDK في خدمة Effect

إذا كنت تستخدم OpenAI SDK الرسمي في موضع آخر، فاجعل إعداد Phaseo في طبقة واحدة:

```ts
import OpenAI from "openai";
import { Config, Effect } from "effect";

const makeClient = Effect.gen(function* () {
	const apiKey = yield* Config.string("PHASEO_API_KEY");

	return new OpenAI({
		apiKey,
		baseURL: "https://api.phaseo.app/v1",
	});
});
```

## ملاحظات

- استخدم `https://api.phaseo.app/v1` لطلبات OpenAI المتوافقة.
- أبقِ معرّفات النماذج بتنسيق Phaseo، مثل `openai/gpt-5-nano`.
- استخدم طبقة Effect مخصصة إذا أردت تجريدًا موحدًا للمزوّد عبر بقية التطبيق.
- اختبر التدفق واستدعاءات الأدوات باستخدام إصدارات حزم Effect نفسها قبل النشر للإنتاج.
