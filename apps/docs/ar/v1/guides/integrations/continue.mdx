شغّل `phaseo continue` لكتابة إعداد Continue يشير إلى Phaseo، أو أضف إدخال النموذج نفسه والسر إلى إعدادك الحالي. تشترك إضافات بيئات التطوير وواجهة `cn` CLI في الإعداد نفسه.

## الإعداد باستخدام Phaseo CLI

```bash
phaseo login
phaseo continue --model anthropic/claude-sonnet-5.5
```

إذا لم يكن `~/.continue/config.yaml` و`~/.continue/.env` موجودين، ينشئ الإعداد مفتاحًا باسم `Phaseo CLI: Continue API Key` (تنتهي صلاحيته بعد 90 يومًا، وحد إنفاقه الشهري $100) ويكتب الملفين. بدون `--model`، يستخدم `anthropic/claude-sonnet-4.6`.

```yaml ~/.continue/config.yaml
# Managed by Phaseo CLI
name: Phaseo
version: 1.0.0
schema: v1
models:
  - name: "anthropic/claude-sonnet-5.5 via Phaseo"
    provider: openai
    model: "anthropic/claude-sonnet-5.5"
    apiBase: https://api.phaseo.app/v1
    apiKey: ${{ secrets.PHASEO_API_KEY }}
    useResponsesApi: false
    roles: [chat, edit, apply]
```

يُحفظ المفتاح في `~/.continue/.env` باسم `PHASEO_API_KEY`. يُبقي `useResponsesApi: false` على Continue يستخدم نقطة النهاية Chat Completions في Phaseo.

<Warning>
ملف `.env` العام في Continue نص صريح. لا تُدرجه في المستودع أبدًا. لا ترث إضافات بيئات التطوير متغيرات بيئة الصدفة، ولهذا تستخدم CLI ملف [الأسرار المحلية](https://docs.continue.dev/faqs#managing-local-secrets-and-environment-variables) في Continue.
</Warning>

## إعداد Continue يدويًا

إذا كان أي من الملفين يحتوي على إعداداتك الخاصة، يتوقف الإعداد دون تغييره. أضف إدخال النموذج أعلاه إلى `config.yaml`، وأضف `PHASEO_API_KEY=<key>` إلى `.env`، مستخدمًا `phaseo integrations credential continue` أو أي مفتاح API من Phaseo. راجع وثائق [مزوّد OpenAI](https://docs.continue.dev/customize/model-providers/top-level/openai) في Continue لمعرفة الحقول الأخرى.

## التحقق من أنه يعمل

في VS Code أو JetBrains، أعد تحميل النافذة، وافتح Continue، واختر **Phaseo**، واطلب منه الرد بـ `PHASEO_CONTINUE_OK`. في CLI، شغّل `cn` (استخدم `/config` إذا كان إعداد آخر نشطًا) وأرسل الموجّه نفسه. تأكد من ظهور الطلب في **الإعدادات → الاستخدام → السجلات**.

## إزالة Phaseo

```bash
phaseo integrations remove continue
```

يلغي هذا الأمر المفتاح ويحذف الملفين فقط إذا كانا لا يزالان يبدآن بعلامة Phaseo CLI. تبقى الإدخالات التي دمجتها بنفسك كما هي.

## إصلاح المشكلات الشائعة

### لا يظهر Phaseo

أعد تحميل بيئة التطوير وتأكد من أن `config.yaml` يحتوي على الحقول العليا `name` و`version` و`schema`.

### يبلّغ Continue عن سر مفقود

تأكد من أن `~/.continue/.env` يحتوي على المفتاح الناتج عن `phaseo integrations credential continue`، ثم أعد تشغيل بيئة التطوير.

### يستدعي Continue واجهة Responses API

أبقِ `useResponsesApi: false` في إدخال نموذج Phaseo.
