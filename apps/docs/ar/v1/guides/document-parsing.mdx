أرسل صورة مستند إلى `POST /v1/parse` لتحصل على نصها بترتيب القراءة، بصيغة Markdown أو ككتل منظّمة من النصوص والصور والجداول. استخدم [OCR](../api-reference/endpoint/ocr.mdx) عندما تحتاج إلى النص العادي فقط.

<Warning>
  يقبل Parse صورة واحدة لكل طلب، كعنوان URL من نوع `http(s)` أو URI بصيغة base64 `data:image/...`. لا تُقبل ملفات PDF: حوّل كل صفحة إلى صورة أولًا. تحدّ Cohere كل صورة بـ 20 MB و50 ميغابكسل و200 MB بعد فك الترميز.
</Warning>

## حلّل إلى Markdown

Markdown هو القيمة الافتراضية لـ `output_format`. يحافظ على ترتيب القراءة، ويضمّن الجداول بصيغة HTML، ويربط الصور المكتشفة ببيانات وصفية في الصفحة.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/parse \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cohere/parse-v5.0",
    "document": {
      "type": "image_url",
      "image_url": "https://example.com/invoice.png"
    },
    "output_format": "markdown"
  }'
```

```ts TypeScript
const response = await fetch("https://api.phaseo.app/v1/parse", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "cohere/parse-v5.0",
    document: {
      type: "image_url",
      image_url: "https://example.com/invoice.png",
    },
    output_format: "markdown",
  }),
});

const parsed = await response.json();
console.log(parsed.pages[0].markdown.content);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/parse",
    headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
    json={
        "model": "cohere/parse-v5.0",
        "document": {
            "type": "image_url",
            "image_url": "https://example.com/invoice.png",
        },
        "output_format": "markdown",
    },
)
response.raise_for_status()
print(response.json()["pages"][0]["markdown"]["content"])
```
</CodeGroup>

## أعد كتلًا منظّمة

اضبط `output_format` على `blocks` لتتلقى مناطق النصوص والصور والجداول مرتبة. تتضمن كتل الصور والجداول مربعات إحاطة بالبكسل ومُطبَّعة حيثما توفرت.

## كيف يُحتسب Parse

يُقاس استخدام Parse بالصفحة. تتضمن الاستجابة البيانات الوصفية من Cohere وقيمة مُطبَّعة `usage.input_pages` عندما يبلغ المزوّد عن الصفحات المحتسبة. تقدّم Cohere حاليًا وصولًا مجانيًا محدود المعدل إلى الواجهة البرمجية لأغراض التقييم، ولم تنشر سعرًا لواجهة Parse البرمجية في الإنتاج.
