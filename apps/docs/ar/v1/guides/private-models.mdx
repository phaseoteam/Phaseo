أضف عملية نشر مخصصة أو مستضافة ذاتيًا إلى مساحة عملك، ليستدعيها فريقك عبر واجهة Phaseo API المعتادة بمعرّف نموذج مثل `acme/legal-assistant`. لا يستطيع رؤيتها أو استدعاءها سوى مساحة عملك، وتعمل في أي مكان يعمل فيه معرّف نموذج عام.

المصادر المعتادة هي عمليات النشر المخصصة على Baseten أو Modal أو RunPod أو Fireworks أو Together، والخوادم التي تشغّل vLLM أو خادمًا آخر متوافقًا مع OpenAI.

## قبل أن تبدأ

يجب أن توفّر عملية النشر:

- عنوان URL أساسيًا عامًا عبر HTTPS؛
- نقطة نهاية `/chat/completions` متوافقة مع OpenAI؛
- مصادقة برمز Bearer؛
- معرّف نموذج أو عملية نشر لدى المزوّد تقبله نقطة النهاية تلك.

دعم `/responses` اختياري. أبقِه معطّلًا ما لم تنفّذ عملية النشر نقطة النهاية هذه صراحةً.

<Warning>
لا تكيّف النماذج الخاصة بروتوكولات المزوّدين الأصلية فقط أو أنظمة المصادقة المخصصة. ضع طبقة متوافقة مع OpenAI أمام عمليات النشر هذه أو استخدم تكامل مزوّد مدعومًا في Phaseo.
</Warning>

## اربط عملية نشر

<Steps>
<Step title="افتح النماذج الخاصة">

افتح **لوحة التحكم ← الإعدادات ← مساحة العمل ← النماذج الخاصة**، ثم اختر **إضافة نموذج**. يجب أن تكون مالكًا لمساحة العمل أو مسؤولًا فيها. للأتمتة، استدعِ `POST /v1/private-models` بالحقول نفسها ومفتاح إدارة.

</Step>

<Step title="سمِّ النموذج">

اختر نموذجًا موجودًا في الكتالوج لإضافة عملية النشر هذه إلى قائمة مزوّديه، أو أدخل معرّفًا نصيًا قصيرًا للنموذج مثل `legal-assistant`. إذا لم يكن لأي نموذج في الكتالوج هذا المعرّف النصي الفريد، يدمجه Phaseo مع نطاق الأسماء الموثوق لمساحة العمل:

```text
acme/legal-assistant
```

لا يمكنك اختيار نطاق أسماء مساحة العمل أو استبداله. تُرفق معرّفات الكتالوج المطابقة تمامًا بذلك النموذج دون تغيير هويته العامة.

</Step>

<Step title="اضبط نقطة النهاية">

أدخل عنوان URL الأساسي الذي يسبق مسار الاستدلال. على سبيل المثال، استخدم:

```text
https://model.example.com/v1
```

لا تُدرج `/chat/completions` أو `/responses`. أدخل معرّف النموذج أو عملية النشر لدى المزوّد بدقة في حقل منفصل، ويستبدله Phaseo عند تمرير الطلبات.

</Step>

<Step title="خزّن بيانات الاعتماد">

أدخل مفتاح API لعملية النشر. يشفّر Phaseo بيانات الاعتماد ولا يعيدها أبدًا بعد الحفظ. يمكنك استبدالها لاحقًا من صفحة إعدادات النموذج.

</Step>

<Step title="استدعِ النموذج">

استخدم معرّف النموذج المولَّد مع نقطة نهاية Chat Completions المعتادة:

```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "acme/legal-assistant",
    "messages": [{"role": "user", "content": "Summarize this contract."}]
  }'
```

يجب أن ينتمي مفتاح API المستدعي إلى مساحة العمل نفسها التي ينتمي إليها النموذج الخاص.

</Step>
</Steps>

## كيف يعمل التوجيه

يُوجَّه نموذج مساحة العمل المستقل إلى نقطة النهاية المضبوطة له فقط. أما نقطة النهاية المرفقة بنموذج في الكتالوج فتنضم إلى قائمة مزوّدي ذلك النموذج وفق سياسة التوجيه الخاصة بها:

| لوحة التحكم | `routing_policy` في API | الأثر |
| --- | --- | --- |
| **مفضّل** (افتراضي) | `preferred` | تُجرَّب عملية نشرك قبل المزوّدين العامين للنموذج. |
| **مجموعة عادية** | `balanced` | تُرتَّب عملية نشرك إلى جانب المزوّدين العامين. |
| **احتياطي فقط** | `fallback` | لا تُجرَّب عملية نشرك إلا بعد المزوّدين العامين. |

يرسل Phaseo بيانات الاعتماد المخزّنة كرمز Bearer ويستبدل معرّف النموذج لدى المزوّد المضبوط.

لا يصبح النموذج الخاص أبدًا مسار مزوّد عامًا، ولا يظهر لمساحات العمل الأخرى. تُضمَّن النماذج الخاصة المفعّلة في كتالوج النماذج للمستخدم الموثَّق وتظهر تحت عامل التصفية **خاص**.

<Note>
بعد إضافة عملية نشر خاصة أو تغييرها أو تفعيلها، انتظر حتى دقيقة واحدة قبل اختبار توجيهها. حتى ذلك الحين، قد تظل بعض الطلبات تستخدم الإعدادات السابقة، مثل المزوّدين العامين للنموذج. لا يُعاد توجيه الطلبات الجارية بالفعل.
</Note>

## أمثلة على المزوّدين

| عملية النشر | ما الذي تُدخله |
| --- | --- |
| نقطة نهاية مخصصة على Baseten | عنوان URL الأساسي المتوافق مع OpenAI، ومعرّف نموذج عملية النشر، ومفتاح API |
| نقطة نهاية ويب على Modal | نقطة نهاية HTTPS عامة تنفّذ عقد OpenAI Chat Completions |
| نقطة نهاية serverless على RunPod | عنوان URL لوكيل متوافق مع OpenAI وبيانات اعتماد Bearer |
| عملية نشر مخصصة على Fireworks أو Together | عنوان URL المخصص المتوافق مع OpenAI ومعرّف النموذج لدى المزوّد |
| vLLM | عنوان URL العام المنتهي بـ `/v1` واسم النموذج الذي يخدمه vLLM |

قد تتغير منتجات المزوّدين وصيغ عناوين URL. تحقّق من عنوان URL الأساسي ومعرّف النموذج وطريقة المصادقة ونقاط النهاية المدعومة في وثائق النشر الحالية لدى المزوّد.

## أدِر النماذج الخاصة عبر API

يمكن للإدارة من جهة الخادم استخدام [Private Models API](../api-reference/endpoint/private-models-list) بمفتاح إدارة يحمل `private_models:read` أو `private_models:write` أو `private_models:delete` حسب الحاجة.

تقبل طلبات الإنشاء والتحديث `model_reference`، وهو إما معرّف نموذج مطابق تمامًا في الكتالوج أو معرّف نصي قصير. يشتق Phaseo قيمة `model_id`، ولا يمكن للعملاء إرسالها مباشرة. استخدم `host_provider_id` لمزوّد موجود في Phaseo، أو `custom_provider_name` و`custom_provider_url` الاختياري لمشغّل آخر.

## استكشاف الأخطاء وإصلاحها

- **خطأ 404 من المزوّد:** تحقّق من أن عنوان URL الأساسي يتوقف قبل مسار الاستدلال.
- **نموذج غير معروف:** انسخ معرّف عملية النشر لدى المزوّد إلى **معرّف النموذج لدى المزوّد**. لا تستخدم هناك معرّف نموذج مساحة العمل في Phaseo.
- **طلب غير مصرّح به لدى المزوّد:** استبدل بيانات الاعتماد المخزّنة وتأكد من أن المزوّد يقبل مصادقة Bearer.
- **Chat يعمل لكن Responses يفشل:** عطّل **Responses API** ما لم يكن المزوّد ينفّذ `/responses` أصليًا.
- **النموذج غير موجود في الكتالوج:** تأكد من أن النموذج مفعّل وأن المستدعي موثَّق في مساحة العمل نفسها.
