Phaseo **مشروع مفتوح تقوده مجتمعاته**، ويهدف إلى إتاحة أكبر قدر ممكن من المعلومات عن نماذج الذكاء الاصطناعي والمعايير والمزوّدين للجميع مجانًا.

تساعد مساهماتك في الحفاظ على دقة المنصة وشفافيتها وتحديثها.  
سواء أصلحت خطأً مطبعيًا أو أضفت بيانات معيارية أو حسّنت الوثائق، فكل مساهمة تُحدث فرقًا.

---

## لماذا تساهم؟

يتطور الذكاء الاصطناعي بوتيرة متسارعة، مع ظهور نماذج وتحديثات وتغييرات في الأسعار يوميًا.  
من خلال المساهمة، تساعد على:

-   الحفاظ على حداثة وموثوقية بيانات النماذج والمؤسسات والمعايير
-   تحسين دقة مقارنات الذكاء الاصطناعي بين المزوّدين
-   مشاركة نتائج الأبحاث أو اكتشافات المجتمع أو البيانات الوصفية الناقصة
-   تعزيز المنظومة المفتوحة لشفافية الذكاء الاصطناعي
-   ضمان استمرار إتاحة قاعدة البيانات مجانًا وامتلاك المجتمع لها

سيظهر اسمك أيضًا في [صفحة المساهمين](https://phaseo.app/contribute) تقديرًا لمساهماتك.

## نظرة عامة على خطوات المساهمة

1. **أنشئ تفرعًا** من [مستودع Phaseo على GitHub](https://github.com/phaseoteam/Phaseo).
2. **أنشئ فرعًا** لتعديلاتك (مثل `fix-model-data` أو `add-new-benchmark`).
3. **عدّل ملفات JSON أو Markdown** وفق البنية الموضحة في [بنية المستودع](./repo-structure.mdx).
4. **اختبر تغييراتك محليًا** عند الحاجة، مثل معاينتها في واجهة Next.js.
5. **ثبّت تغييراتك وادفعها**.
6. **افتح طلب سحب (PR)** واشرح ما غيّرته والسبب.

بعد المراجعة والموافقة، ستُدمج مساهمتك وتظهر في قاعدة بيانات Phaseo المباشرة.

## أنواع المساهمات

| النوع                   | مثال                                                 | الصعوبة |
| ---------------------- | ------------------------------------------------------- | ---------- |
| **تصحيح البيانات**           | تصحيح أسماء النماذج أو المزوّدين أو قيم المعايير. | سهل       |
| **إضافة سجل**          | إضافة نموذج أو معيار أو مؤسسة جديدة.         | متوسطة   |
| **تغيير هيكلي**  | تعديل بنية قاعدة البيانات أو المخطط.                    | متقدمة   |
| **إضافة ميزة**   | إضافة مكونات واجهة أو منطق Next.js.                  | متقدمة   |
| **تعديل الوثائق** | تحسين ملفات Markdown أو الأدلة.                     | سهل       |

نرحب بالمساهمات بمختلف أحجامها ودرجات تعقيدها، مهما كان التغيير الذي ترغب فيه.

## الإرشادات والمعايير

يجب أن تلتزم جميع المساهمات بهذه المعايير لضمان جودة البيانات واتساقها:

-   **مصادر دقيقة:** أدرج البيانات التي تم التحقق منها أو نشرها رسميًا فقط.
-   **تنسيق متسق:** استخدم حالة الأحرف والمسافات البادئة ومفاتيح المخطط الصحيحة.
-   **تغييرات موثّقة بالإصدار:** اجعل سجلات التغيير أو رسائل التثبيت وصفية وواضحة.
-   **الاستشهادات:** أدرج روابط مصادر البيانات في وصف طلب السحب.
-   **تواصل يتسم بالاحترام:** اتبع [مدونة السلوك](../community/code-of-conduct.mdx).

## مثال على خطوات المساهمة

```bash
# 1. Fork and clone the repo
git clone https://github.com/yourusername/Phaseo.git

# 2. Create a new branch
git checkout -b add-openai-new-model

# 3. Make your edits
# e.g. edit packages/data/catalog/src/data/models/openai/new-model/model.json

# 4. Stage, commit, and push
git add .
git commit -m "Added new OpenAI model with updated benchmark data"
git push origin add-openai-new-model

# 5. Open a Pull Request on GitHub
# Describe your changes and link any sources
```

## هل تحتاج إلى مساعدة؟

إذا لم تكن متأكدًا من طريقة المساهمة أو أردت ملاحظات قبل الإرسال، يمكنك:

-   اطرح سؤالك في [Discord الخاص بـ Phaseo](https://discord.gg/aQyywCvgZ5).
-   افتح **نقاشًا على GitHub** لطرح الأسئلة أو الاقتراحات.
-   أشر إلى المشرفين في طلب السحب للحصول على إرشادات المراجعة.
