لتصحيحات الكتالوج وإضافاته، افتح بلاغًا يتضمن السجل المتأثر والمصادر الداعمة. لتغييرات الكود أو الوثائق، أرسل طلب سحب إلى [مستودع Phaseo](https://github.com/phaseoteam/Phaseo).

## اختيار مساهمتك

| التغيير | ابدأ هنا |
| --- | --- |
| بيانات النموذج الوصفية أو إمكاناته أو توفره أو أسعاره | [الإبلاغ عن تحديث نموذج](./editing-a-model.mdx) |
| تفاصيل شركة أو مؤسسة بحثية | [الإبلاغ عن تحديث مؤسسة](./editing-an-organisation.mdx) |
| نتائج الاختبارات المعيارية | [إرسال النتائج](../research/submitting-scores.mdx) |
| تصحيحات أخرى للكتالوج | [الإبلاغ عن معلومات غير صحيحة](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) |
| مزوّدون أو بيانات كتالوج أخرى مفقودة | [طلب بيانات جديدة](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) |
| وثائق أو كود | [مسار المساهمة](./how-to-contribute.mdx) و[بنية المستودع](./repo-structure.mdx) |

## كيفية نشر بلاغات الكتالوج

يراجع القائمون على الصيانة الأدلة في البلاغ ويطبقون التغييرات المعتمدة عبر [المحرر الداخلي](https://phaseo.app/internal/data) المخصص للمسؤولين فقط. تتطلب تحديثات أسعار المزوّدين مراجعة صريحة قبل النشر.

قاعدة البيانات هي المصدر المرجعي للكتالوج. تظل لقطات JSON العامة اليومية متاحة، لكن لا تعديلات اللقطات ولا طلبات سحب JSON المؤرشف تحدّث الكتالوج الحي. أُوقف مستورد JSON القديم.

## قبل الإرسال

- أدرج الصفحة أو معرّف السجل المتأثر وصف التصحيح المقترح.
- استشهد بالمصادر الرسمية وميّز نتائج الاختبارات المعيارية المُعلنة من القياسات المستقلة.
- اجعل كل بلاغ أو طلب سحب محدد النطاق.
- لا تُدرج بيانات اعتماد أو بيانات عملاء خاصة مطلقًا.
- اتبع [مدونة السلوك](../community/code-of-conduct.mdx).

ناقش تغييرات المخططات أو الميزات الكبيرة مع القائمين على الصيانة قبل تنفيذها. اطلب المساعدة في [Discord](https://discord.gg/aQyywCvgZ5) إن لم تعرف أين ينتمي التغيير.
