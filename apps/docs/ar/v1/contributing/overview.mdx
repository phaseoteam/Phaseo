لتصحيحات الكتالوج وإضافاته، افتح مسألة تتضمن السجل المتأثر والمصادر الداعمة. لتغييرات الكود أو الوثائق، أرسل طلب سحب إلى [مستودع Phaseo](https://github.com/phaseoteam/Phaseo).

## اختر مساهمتك

| التغيير | ابدأ هنا |
| --- | --- |
| بيانات النموذج الوصفية أو إمكاناته أو توفره أو أسعاره | [الإبلاغ عن تحديث نموذج](./editing-a-model.mdx) |
| تفاصيل شركة أو مؤسسة بحثية | [الإبلاغ عن تحديث مؤسسة](./editing-an-organisation.mdx) |
| نتائج الاختبارات المعيارية | [إرسال النتائج](../research/submitting-scores.mdx) |
| تصحيحات أخرى للكتالوج | [الإبلاغ عن معلومات غير صحيحة](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) |
| مزوّدون مفقودون أو بيانات كتالوج أخرى | [طلب بيانات جديدة](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) |
| وثائق أو كود | [مسار المساهمة](./how-to-contribute.mdx) و[بنية المستودع](./repo-structure.mdx) |

## كيف تُنشر بلاغات الكتالوج

يراجع القائمون على الصيانة الأدلة في المسألة ويطبّقون التغييرات المعتمدة عبر [المحرّر الداخلي](https://phaseo.app/internal/data) المخصص للمشرفين فقط. تتطلب تحديثات أسعار المزوّدين مراجعة صريحة قبل النشر.

قاعدة البيانات هي المصدر الوحيد لسجلات الكتالوج. لا يحتوي المستودع على أي JSON للكتالوج، لذلك لا يمكن لطلب سحب أن يغيّر سجلًا في الكتالوج.

## قبل الإرسال

- أدرج الصفحة المتأثرة أو معرّف السجل، وصِف التصحيح المقترح.
- استشهد بمصادر رسمية، وميّز نتائج الاختبارات المعيارية المُعلنة من القياسات المستقلة.
- اجعل كل بلاغ أو طلب سحب مركّزًا على أمر واحد.
- لا تُدرج بيانات اعتماد أو بيانات عملاء خاصة أبدًا.
- اتبع [مدونة السلوك](../community/code-of-conduct.mdx).

ناقش تغييرات المخطط أو الميزات الكبيرة مع القائمين على الصيانة قبل تنفيذها. اطلب المساعدة في [Discord](https://discord.gg/aQyywCvgZ5) إن لم تكن متأكدًا من المكان المناسب للتغيير.
