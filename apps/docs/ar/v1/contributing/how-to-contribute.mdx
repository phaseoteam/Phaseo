المساهمة في **Phaseo** سهلة وشفافة ومتاحة للجميع.
يرشدك هذا الدليل خلال العملية كاملة، سواء أكنت تعدّل سجل نموذج أو تحدّث بيانات المعايير أو تحسّن الوثائق أو تطرح أفكارًا جديدة.

---

## قبل البدء

ستحتاج إلى تثبيت بعض الأدوات الأساسية:

| الأداة | الغرض | التثبيت |
| ------------------ | ---------------------------------------------- | -------------------------------------------------- |
| **Git**            | إدارة الإصدارات لاستنساخ التغييرات وإرسالها.     | [تثبيت Git](https://git-scm.com/downloads)       |
| **Node.js (v20+)** | يشغّل موقع Phaseo محليًا (Next.js).      | [تنزيل Node.js](https://nodejs.org/en/download) |
| **pnpm**           | مدير الحزم المستخدم في هذا المشروع.          | `npm install -g pnpm`                              |
| **حساب GitHub** | مطلوب لإنشاء التفرعات والمشكلات وطلبات السحب. | [سجّل هنا](https://github.com/signup)          |

إذا كنت تريد تعديل **البيانات** أو **وثائق Markdown** فقط، فيمكنك إجراء التغييرات مباشرةً على GitHub دون إعداد بيئة محلية.

---

## 1. أنشئ تفرعًا من المستودع

انتقل إلى [مستودع Phaseo على GitHub](https://github.com/phaseoteam/Phaseo)، ثم انقر على **Fork** في الزاوية العلوية اليمنى.
ينشئ ذلك نسخة خاصة بك من المشروع يمكنك تعديلها بحرية.

---

## 2. استنسخ التفرع الخاص بك

```bash
git clone https://github.com/yourusername/Phaseo.git
cd Phaseo
```

ينزّل ذلك التفرع إلى جهازك المحلي.

---

## 3. أنشئ فرعًا جديدًا

من الأفضل إنشاء فرع جديد لكل تغيير تجريه:

```bash
git checkout -b update-benchmark-data
```

استخدم اسمًا وصفيًا للفرع يعكس التغيير لتسهيل مراجعته.

أمثلة:

-   `fix-{model-name}`
-   `add-new-organisation`
-   `improve-docs`
-   `update-pricing-for-{model-name}`

---

## 4. أجرِ التغييرات

بحسب ما تريد تعديله:

| المجال | الملفات | الوصف |
| --------------------- | --------------------------------------------- | ----------------------------------------------------- |
| **بيانات النماذج**        | `/packages/data/catalog/src/data/models/**/model.json`     | أضف البيانات الوصفية للنماذج أو أسعارها أو معاييرها أو حدّثها. |
| **بيانات المؤسسات** | `/packages/data/catalog/src/data/organisations/*.json`     | حدّث تفاصيل الشركات أو فرق الأبحاث.    |
| **بيانات المعايير**    | `/packages/data/catalog/src/data/benchmarks/**/*.json`     | قدّم نتائج تقييم جديدة أو تصحيحات.         |
| **الوثائق**     | `/apps/docs/v1/**/*.mdx`                      | حسّن الأدلة والمراجع وصفحات الوثائق أو وسّعها. |
| **البوابة**           | `/apps/api/*`                                 | أجرِ تغييرات على بوابة API.                      |

إذا كنت تعدّل البيانات، فاتبع المخططات وتنسيقات الحقول الموضحة في [بنية المستودع](./repo-structure.mdx).

---

## 5. عاين تغييراتك (اختياري)

إذا أردت معاينة تعديلاتك محليًا:

```bash
pnpm install
pnpm dev
```

استخدم [http://localhost:3100](http://localhost:3100) لتغييرات الموقع و[http://localhost:3101](http://localhost:3101) لتغييرات الوثائق. لا يمكن معاينة تغييرات البيانات إلا بعد إنشاء طلب سحب، لأن تطبيق الويب يجلب البيانات من قاعدة البيانات.

---

## 6. ثبّت تغييراتك

بعد التأكد من التعديلات، ثبّت عملك:

```bash
git add .
git commit -m "Updated benchmark data for Claude 3.5 Sonnet"
```

احرص على أن يصف عنوان التثبيت التغييرات ليسهل على المراجعين فهم مساهمتك.

---

## 7. ادفع الفرع إلى المستودع

```bash
git push origin update-benchmark-data
```

---

## 8. أنشئ طلب سحب (PR)

1. انتقل إلى التفرع الخاص بك على GitHub.
2. ستظهر رسالة تقترح إنشاء طلب سحب؛ انقر على **Compare & Pull Request**.
3. املأ قالب طلب السحب بالمعلومات المناسبة لتغييراتك.
4. أرسل طلب السحب.

بعد مراجعة طلب السحب والموافقة عليه، سيُدمج في مستودع Phaseo الرئيسي.

---

ستظهر مساهمتك بعد دمجها. نقدّر جهودك ودعمك.

## نصائح للمساهمة

-   اجعل طلبات السحب **صغيرة ومحددة**، بحيث يتضمن كل طلب تغييرًا منطقيًا واحدًا.
-   اتبع [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) متى أمكن، واستخدم **بادئات واضحة للتثبيت** مثل `fix:` و`add:` و`chore:`.
-   إذا أثّر التغيير في دقة البيانات، فأرفق **المصادر أو المراجع**.
-   إذا كانت الفكرة كبيرة أو غير واضحة، فافتح **نقاشًا على GitHub** أو تواصل عبر Discord قبل كتابة الشيفرة.
-   احرص دائمًا على الاحترام واتبع [مدونة قواعد السلوك](../community/code-of-conduct.mdx).

---

## ملخص سير العمل كمثال

```bash
# 1. Fork and clone

git clone https://github.com/yourusername/Phaseo.git
cd Phaseo

# 2. Create branch
git checkout -b add-openai-new-model

# 3. Make changes
# e.g., update packages/data/catalog/src/data/models/openai/new-model/model.json

# 4. Commit and push
git add .
git commit -m "Add new OpenAI model entry"
git push origin add-new-openai-model

# 5. Create a Pull Request on GitHub
```
