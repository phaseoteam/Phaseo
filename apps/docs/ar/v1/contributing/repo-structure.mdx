Phaseo مستودع موحّد يستخدم pnpm وTurborepo. استخدم هذا المرجع للعثور على ملفات تغيير الكود أو الوثائق. لتغييرات سجلات الكتالوج، [افتح بلاغًا](./overview.mdx).

## التطبيقات والحزم

| المسار | الغرض |
| --- | --- |
| `apps/web` | موقع Next.js 16 ولوحة المعلومات ومحرر الكتالوج الداخلي. |
| `apps/web-api` | قراءة الكتالوج العامة وواجهات الحساب والإدارة التي تتطلب المصادقة. |
| `apps/api` | توجيه البوابة وتنفيذ المزوّد على Cloudflare Workers. |
| `apps/docs` | وثائق Mintlify؛ صفحات MDX في `v1` والتنقل في `docs.json`. |
| `packages/data/catalog` | مخططات الكتالوج وبيانات اختبار التوافق واللقطات العامة المنشأة. |
| `packages/sdk` | حزم SDK للغات TypeScript وPython وGo وC# وPHP وRuby وJava وRust وC++. |
| `supabase/migrations` | ترحيلات مخطط قاعدة البيانات والأذونات. |
| `scripts` | أدوات التحقق وتوليد SDK والأتمتة. |
| `.github/workflows` | CI والنشر ومزامنة الكتالوج وجداول اللقطات. |
| `.changeset` | بيانات الإصدار الوصفية للحزم ذات الإصدارات. |

## بيانات الكتالوج

قاعدة البيانات هي المصدر المرجعي للنماذج والمزوّدين والمؤسسات والأسعار والاختبارات المعيارية وإعدادات الكتالوج الداعمة. يدير المسؤولون السجلات عبر [البيانات الداخلية](https://phaseo.app/internal/data). تُراجع المساهمات العامة عبر بلاغات GitHub.

- يحتوي `packages/data/catalog/generated/database-v2` على اللقطات العامة اليومية وفهرس تعداد النماذج المنشأ الذي تستخدمه أدوات OpenAPI وSDK.
- يحتوي `packages/data/catalog/src/data` على بيانات اختبار توافق مؤرشفة.
- تعديل أي من المجلدين لا يحدّث سجلات الكتالوج الحي. أُوقف المستورد القديم من JSON إلى قاعدة البيانات.

تظل تغييرات المخططات والتطبيقات تستخدم الترحيلات وطلبات السحب. يجب تحديث اللقطات ومنتجات SDK المنشأة عبر أوامر توليدها.

## أتمتة الكتالوج

تضع مزامنة المزوّد الأسعار المقترحة في قائمة المراجعة ضمن [تحديثات المزوّدين](https://phaseo.app/internal/data/imports). تستخدم مهام الاختبارات المعيارية ودورة حياة النماذج قاعدة البيانات. تنتج التصديرات العامة اليومية طلبات سحب لقطات قابلة للمراجعة.

السجلات الموجودة في الكتالوج فقط لا تفعّل توجيه البوابة تلقائيًا. تتطلب تغييرات المسارات والأسعار مراجعة المسؤول المناسبة.
