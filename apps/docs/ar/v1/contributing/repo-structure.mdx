Phaseo مستودع موحّد (monorepo) يستخدم pnpm وTurborepo. اعثر أدناه على المجلد المناسب لتغيير الكود أو الوثائق. سجلات الكتالوج ليست في المستودع؛ لتغيير أحدها، [افتح مسألة](./overview.mdx).

## التطبيقات

| المسار | الغرض |
| --- | --- |
| `apps/web` | موقع Next.js 16 ولوحة التحكم ومحرّر الكتالوج الداخلي. |
| `apps/web-api` | قراءات الكتالوج العامة وواجهات API للحساب والمشرفين التي تتطلب مصادقة. |
| `apps/api` | توجيه Gateway وتنفيذ طلبات المزوّدين على Cloudflare Workers. |
| `apps/docs` | وثائق Mintlify؛ صفحات MDX في `v1`، والتنقل في `docs.json`. |
| `apps/mcp` | خادم Phaseo MCP لاكتشاف النماذج والأسعار والاستخدام. |
| `apps/desktop` | تطبيق Phaseo Desktop. |
| `apps/mobile` | تطبيق Phaseo للهاتف المحمول (Expo، وAndroid أولًا). |
| `apps/slack` | الـ Worker الذي يشغّل وكيل Phaseo في Slack. |

## الحزم والأدوات

| المسار | الغرض |
| --- | --- |
| `packages/sdk` | حزم SDK للغات TypeScript وPython وGo وC# وPHP وRuby وJava وRust وC++، إضافة إلى Agent SDK (`agent-sdk-*`). |
| `packages/cli/phaseo` | أداة سطر الأوامر `@phaseo/cli`. |
| `packages/integrations` | مزوّد Vercel AI SDK ومزوّد Terraform. |
| `packages/shared` | كود مشترك بين التطبيقات، مثل واجهة المستخدم وقواعد الإنفاق وإعدادات التوجيه. |
| `supabase/schemas` | تعريفات قاعدة البيانات التصريحية. |
| `supabase/migrations` | ترحيلات SQL أمامية تنشر تغييرات المخطط والصلاحيات. |
| `scripts` | أدوات التحقق وتوليد SDK والأتمتة. |
| `.github/workflows` | CI والنشر ومزامنة الكتالوج. |
| `.changeset` | بيانات الإصدار للحزم ذات الإصدارات. |

## بيانات الكتالوج

قاعدة البيانات هي المصدر الوحيد للنماذج والمزوّدين والمؤسسات والأسعار والاختبارات المعيارية وإعدادات الكتالوج. لا يحتوي المستودع على أي JSON للكتالوج. يدير المشرفون السجلات في [البيانات الداخلية](https://phaseo.app/internal/data)؛ وتصل المساهمات العامة على شكل مسائل في GitHub.

لا تزال تغييرات المخطط والتطبيقات تمر عبر الترحيلات وطلبات السحب. حدّث ملفات SDK المولّدة بأوامر التوليد الخاصة بها، لا يدويًا.

## أتمتة الكتالوج

تضع مزامنة المزوّدين الأسعار المقترحة في قائمة انتظار للمراجعة في [تحديثات المزوّدين](https://phaseo.app/internal/data/imports). تقرأ مهام الاختبارات المعيارية ودورة حياة النماذج من قاعدة البيانات وتكتب فيها.

لا يفعّل سجل الكتالوج وحده توجيه Gateway. تحتاج تغييرات المسارات والأسعار إلى مراجعة المشرفين.

لبدء تغيير، راجع [المساهمة بالكود أو الوثائق](./how-to-contribute.mdx).
