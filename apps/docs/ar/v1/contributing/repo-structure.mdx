من المهم فهم **بنية المستودع** قبل المساهمة في Phaseo.
يفصل المشروع بين البيانات والوثائق ومنطق التطبيقات لتسهيل العثور على ما تحتاج إليه ودعم التوسع بوضوح.

---

## نظرة عامة

إليك شكل المجلد الجذر للمستودع:

```bash
Phaseo/
+-- apps/
¦   +-- web/ # The main Phaseo Next.js website (contains data)
¦   +-- api/ # The Phaseo Gateway API (Hono/Cloudflare Workers)
¦   +-- docs/ # The Mintlify-powered documentation site
¦
+-- packages/ # SDKs and shared tooling
¦   +-- sdk-ts/
¦   +-- sdk-py/
¦   +-- sdk-go/
¦   +-- sdk-csharp/
¦   +-- sdk-php/
¦   +-- sdk-ruby/
¦   +-- sdk-java/
¦   +-- sdk-rust/
¦   +-- sdk-cpp/
¦   +-- ai-sdk-phaseo/
¦
+-- scripts/ # Automation scripts and utilities
+-- .changeset/ # Release metadata
+-- turbo.json # Turborepo configuration
+-- package.json # Global scripts and dependencies
+-- README.md # Root readme file
```

## مجلدات البيانات

يخزّن Phaseo البيانات المنظمة في **ملفات JSON** ضمن المجلد `/packages/data/catalog/src/data`.
تُعد هذه الملفات المصدر المعتمد لبيانات النماذج والمعايير والأسعار.

### `/packages/data/catalog/src/data/models`

يحتوي على ملف JSON واحد لكل نموذج.
يصف كل ملف البيانات الوصفية للنموذج وأسعاره ومعاييره وقدراته.

مثال:
`/packages/data/catalog/src/data/models/openai/gpt-5-2025-08-07/model.json`

---

### `/packages/data/catalog/src/data/organisations`

يصف الشركات أو فرق الأبحاث المسؤولة عن النماذج.
يتضمن كل ملف JSON الاسم والوصف وتاريخ التأسيس والموقع الإلكتروني والبلد.

مثال:
`/packages/data/catalog/src/data/organisations/openai.json`

---

### `/packages/data/catalog/src/data/benchmarks`

يحتوي على البيانات الوصفية للمعايير والنتائج المجمّعة عبر النماذج.
لكل معيار معرّف واسم ووصف وفئة ومقاييس.

مثال:
`/packages/data/catalog/src/data/benchmarks/mmlu.json`

---

### `/packages/data/catalog/src/data/api_providers`

يسرد جميع مزوّدي API المدعومين ونماذجهم.
يربط هذا بين النماذج والمؤسسات.

مثال:
`/packages/data/catalog/src/data/api_providers/openai.json`

---

### `/packages/data/catalog/src/data/pricing`

يتتبّع بيانات الأسعار التاريخية بمرور الوقت لتحليل الاتجاهات.
تتضمن الملفات طوابع زمنية وغالبًا ما تُجمع حسب المزوّد.

---

## مجلدات الوثائق

تُكتب الوثائق بتنسيق **MDX** وتوجد ضمن `/apps/docs/v1/`.
يقابل كل مجلد مجموعة في إعداد Mintlify.

| المجلد | الغرض |
| ----------------------------- | ------------------------------------------------------- |
| `/apps/docs/v1/exploring`     | يشرح مفاهيم البيانات (النماذج والمعايير والمزوّدين). |
| `/apps/docs/v1/contributing`  | أدلة خطوة بخطوة للمساهمين.                   |
| `/apps/docs/v1/developers`    | أدلة التكامل واستخدام API.                       |
| `/apps/docs/v1/api-reference` | مرجع مفصل لكل مسار.                  |
| `/apps/docs/v1/community`     | صفحات الدعم والأسئلة الشائعة والمجتمع.                      |

---

## مجلدات التطبيقات

| المسار | الوصف |
| ------------ | ------------------------------------------------------------------------------------------------- |
| `/apps/web`  | موقع Phaseo الرئيسي المبني باستخدام Next.js 15 وTailwindCSS. يقرأ البيانات المعتمدة من `packages/data/catalog/src/data`. |
| `/apps/api`  | بوابة API: التوجيه والتخزين المؤقت ومنطق الوكيل للنماذج.                                         |
| `/apps/docs` | مشروع وثائق Mintlify الذي تقرأه الآن.                                           |

يعمل كل تطبيق بشكل مستقل، لكنه يشارك الأنواع والإعدادات عبر `/packages`.

---

## حِزم SDK

يحتوي المجلد `/packages` على حِزم SDK لاستخدام API الخاصة بـ Phaseo بلغات برمجة متعددة.

| SDK | الوصف |
| ------------ | ------------------------------------------------ |
| `sdk-ts`     | حزمة SDK بلغة TypeScript لتطبيقات Node.js والويب. |
| `sdk-py`     | حزمة SDK بلغة Python.                                      |
| `sdk-go`     | حزمة SDK بلغة Go.                                          |
| `sdk-csharp` | حزمة SDK بلغة C#.                                          |
| `sdk-php`    | حزمة SDK بلغة PHP.                                         |
| `sdk-ruby`   | حزمة SDK بلغة Ruby.                                        |
| `sdk-java`   | حزمة SDK بلغة Java.                                        |
| `sdk-rust`   | حزمة SDK بلغة Rust.                                        |
| `sdk-cpp`    | حزمة SDK بلغة C++.                                         |
| `ai-sdk-phaseo` | موفّر Vercel AI SDK.                      |

## الأتمتة والنصوص البرمجية

يستخدم Phaseo الأتمتة للحفاظ على حداثة البيانات:

-   **أدوات الاستيراد**: تجلب بيانات جديدة من مصادر مثل Hugging Face أو واجهات API للمزوّدين.
-   **المراقبات**: تعمل وفق جدول (عبر GitHub Actions) لاكتشاف التحديثات وتثبيتها.
-   **الأدوات المساعدة**: تتولى التحقق وفحص المخططات وتنسيق JSON.

يمكنك استكشاف هذه الملفات ضمن `/scripts/`.

---

## من أين تبدأ

إذا كنت تريد المساهمة:

-   **البيانات:** ابحث عن ملفات JSON ضمن `/packages/data/catalog/src/data/`.
-   **الوثائق:** ابحث عن ملفات MDX ضمن `/apps/docs/v1/`.
-   **الشفرة:** استكشف `/apps/web` أو `/apps/api`.
-   **الأتمتة:** عدّل الملفات ضمن `/scripts/` أو افحصها.
-   **حِزم SDK:** ابحث عن الحزم الخاصة بكل لغة ضمن `/packages/`.
