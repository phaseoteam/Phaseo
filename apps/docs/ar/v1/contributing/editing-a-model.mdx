توجد بيانات النماذج في ملفات JSON ضمن `packages/data/catalog/src/data/models`. لكل نموذج مجلد خاص وملف `model.json`.

## 1. ابحث عن النموذج

حدّد مجلد النموذج باستخدام اسم المزوّد واسم النموذج. مثال:

`packages/data/catalog/src/data/models/openai/gpt-5-2025-08-07/model.json`

## 2. أجرِ التعديلات

تشمل التحديثات الشائعة ما يلي:

- الأوصاف والروابط
- القدرات والمسارات المدعومة
- ملاحظات الأسعار أو التوفّر
- مراجع المعايير

احرص على توافق القيم مع المخطط المستخدم في الملفات المجاورة.

## 3. تحقّق من البيانات

شغّل برنامج التحقق من البيانات قبل فتح طلب السحب:

```bash
pnpm validate:data
```

## 4. افتح طلب سحب

أدرج ملخصًا موجزًا للتغييرات والمصادر المستخدمة.
