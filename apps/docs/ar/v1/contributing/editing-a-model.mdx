افتح مسألة على GitHub لتصحيح نموذج أو طلب إضافة إدخال مفقود. لا تحتاج إلى تعديل JSON أو إعداد المستودع.

## الإبلاغ عن تصحيح

1. انسخ رابط صفحة النموذج على Phaseo أو معرّف النموذج.
2. [أبلغ عن معلومات غير صحيحة](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml)، مع وصف القيمة الحالية والتصحيح المقترح.
3. أرفق وثائق رسمية أو إعلان إصدار أو مصدرًا آخر يمكن التحقق منه.

للأسعار، أدرج المزوّد والعملة ووحدة الفوترة والفئة المعنية وتاريخ السريان. لنتائج الاختبارات المعيارية، اتبع [إرسال النتائج](../research/submitting-scores.mdx).

## طلب نموذج مفقود

[افتح طلب بيانات](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) يتضمن اسم النموذج والمؤسسة والرابط الرسمي وتاريخ الإصدار والإمكانات المعروفة. قد يظهر النموذج في الكتالوج قبل أن يكون له مسار مدعوم في Gateway.

## بعد الإرسال

يراجع القائمون على الصيانة الأدلة ويحدّثون قاعدة البيانات عبر المحرّر الداخلي. تابع الأسئلة والنشر في المسألة. قاعدة البيانات هي المصدر الوحيد لسجلات الكتالوج؛ ولا يحتوي المستودع على أي JSON للكتالوج يمكن تعديله.

يعدّل المشرفون السجلات في [البيانات الداخلية](https://phaseo.app/internal/data) ويراجعون الأسعار المقترحة في [تحديثات المزوّدين](https://phaseo.app/internal/data/imports). تتطلب الصفحتان صلاحية المشرف.
