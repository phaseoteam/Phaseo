افتح مسألة على GitHub لتصحيح نموذج أو طلب إضافة إدخال مفقود. لا تحتاج إلى تعديل JSON أو إعداد المستودع.

## الإبلاغ عن تصحيح

1. انسخ رابط صفحة النموذج على Phaseo أو معرّف النموذج.
2. [أبلغ عن معلومات غير صحيحة](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml)، مع وصف القيمة الحالية والتصحيح المقترح.
3. أرفق وثائق رسمية أو إعلان إصدار أو مصدرًا آخر يمكن التحقق منه.

للأسعار، أدرج المزوّد والعملة ووحدة الفوترة والمستوى المعني وتاريخ السريان. لنتائج التقييمات، اتبع [إرسال النتائج](../research/submitting-scores.mdx).

## طلب إضافة نموذج مفقود

[افتح طلب بيانات](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) يتضمن اسم النموذج والمؤسسة والرابط الرسمي وتاريخ الإصدار والإمكانات المعروفة. قد يظهر النموذج في الكتالوج قبل توفّر مسار مدعوم له في Gateway.

## بعد الإرسال

يراجع القائمون على الصيانة الأدلة ويحدّثون قاعدة البيانات عبر المحرّر الداخلي. تابع الأسئلة والنشر في المسألة. تُصدّر لقطات JSON اليومية الكتالوج؛ ولا تؤدي التغييرات في ملفات JSON المؤرشفة إلى تحديث الموقع المباشر.

يمكن للمشرفين تعديل السجلات في [البيانات الداخلية](https://phaseo.app/internal/data) ومراجعة الأسعار المقترحة في [تحديثات المزوّدين](https://phaseo.app/internal/data/imports). تتطلب هذه الصفحات صلاحية المشرف.
