توجد بيانات المؤسسات في ملفات JSON ضمن `packages/data/catalog/src/data/organisations`.

## 1. ابحث عن المؤسسة

تُحفظ بيانات كل مؤسسة في ملف JSON واحد، مثل:

`packages/data/catalog/src/data/organisations/openai.json`

## 2. أجرِ التعديلات

تشمل التحديثات الشائعة ما يلي:

- الاسم والوصف والموقع الإلكتروني
- رمز البلد أو حقول البيانات الوصفية
- روابط الارتباط بالنماذج أو المزوّدين

احرص على اتساق التنسيق وترتيب الحقول مع الملفات المجاورة.

## 3. تحقّق من البيانات

شغّل برنامج التحقق من البيانات قبل فتح طلب السحب:

```bash
pnpm validate:data
```

## 4. افتح طلب سحب

أرفق مصادر أو مراجع لأي تغييرات تتعلق بالحقائق.
