أبلغ عن تفاصيل المؤسسة المفقودة أو القديمة عبر مسألة على GitHub. يراجع القائمون على الصيانة الأدلة ويطبّقون التغييرات المعتمدة في محرّر قاعدة البيانات.

## الإبلاغ عن تصحيح

1. انسخ رابط صفحة المؤسسة على Phaseo أو معرّفها.
2. [أبلغ عن معلومات غير صحيحة](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) مع تحديد الحقل المعني والقيمة المقترحة.
3. أضف رابطًا إلى موقع رسمي أو إعلان أو مصدر آخر يمكن التحقق منه.

تشمل التصحيحات الشائعة الاسم والوصف والموقع الإلكتروني والموقع الجغرافي والعلاقات بالنماذج أو مزوّدي API.

## طلب إضافة مؤسسة مفقودة

[افتح طلب بيانات](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) يتضمن اسم المؤسسة وموقعها الرسمي وروابط النماذج أو المزوّدين ذات الصلة.

## بعد الإرسال

تابع المراجعة والنشر في المسألة. لا يتطلب تغيير سجل في الكتالوج تعديل JSON أو فتح طلب سحب. ملفات JSON اليومية هي صادرات؛ ولا تُستورد إلى قاعدة البيانات المباشرة.

يدير المشرفون المؤسسات عبر [محرّر الكتالوج الداخلي](https://phaseo.app/internal/data)، الذي يتطلب صلاحية المشرف.
