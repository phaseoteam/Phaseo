**الطرق**: `client.generate_response(...)` و`client.create_response(...)`.

### مثال
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))

resp = client.create_response(
  "model" => "openai/gpt-4.1",
  "input" => [{ "role" => "user", "content" => [{ "type" => "input_text", "text" => "Summarise this text" }] }],
  "temperature" => 0.7
)
```

### المعلمات الأساسية
- `model` (مطلوب): معرّف النموذج المستهدف.
- `input` (مطلوب): مصفوفة مرتبة من عناصر الإدخال، مثل الرسائل واستدعاءات الأدوات.
- `temperature` (0–2): كلما زادت القيمة زادت العشوائية.
- `top_p` (0–1) / `top_k` (>=1): إعدادات أخذ العينات بالنواة وأفضل k خيارات.
- `max_output_tokens` (عدد صحيح): حد صارم للرموز المولّدة في كل استجابة؛ استخدم `max_output_tokens_per_message` لتحديد كل رسالة.
- الأدوات: `tools` (تعريفات) و`tool_choice` (تلقائي/بلا/محدد) و`max_tool_calls` (عدد صحيح) و`parallel_tool_calls` (قيمة منطقية).
- الاحتمالات اللوغاريتمية: `logprobs` (قيمة منطقية) و`top_logprobs` (0–20) لإرجاع الاحتمال اللوغاريتمي لكل رمز.
- المخرجات: `response_format` (json/text) و`service_tier` و`store` (قيمة منطقية) و`stream` (قيمة منطقية).
- البيانات الوصفية: `metadata` (كائن يُمرّر كما هو) و`reasoning` (كائن لتلميحات مستوى الاستدلال).
- إضافات البوابة: `usage` (قيمة منطقية لطلب بيانات الاستخدام) و`meta` (قيمة منطقية لتضمين كتلة meta).
