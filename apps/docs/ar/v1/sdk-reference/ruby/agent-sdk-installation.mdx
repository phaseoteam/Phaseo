تُنشر Agent SDK على RubyGems باسم [`phaseo_agent_sdk`](https://rubygems.org/gems/phaseo_agent_sdk).

## المتطلبات

- Ruby 3.2 أو أحدث
- RubyGems أو Bundler
- مفتاح API من Phaseo

## التثبيت

```bash
gem install phaseo_agent_sdk
```

أو أضِفه إلى `Gemfile` الخاص بك:

```ruby
gem "phaseo_agent_sdk"
```

تُثبّت gem الأساسية `phaseo_sdk` تلقائيًا باعتبارها اعتمادية.

## البيئة

عيّن مفتاح API للبوابة قبل تشغيل الأمثلة:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
