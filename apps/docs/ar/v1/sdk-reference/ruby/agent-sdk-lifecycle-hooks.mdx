مرّر `on_event` لتلقي أحداث دورة حياة منظّمة أثناء التشغيل.

```ruby
result = agent.run(
  input: prompt,
  client: client,
  on_event: ->(event) {
    logger.info(
      "agent event",
      type: event[:type],
      run_id: event[:run_id],
      details: event[:details]
    )
  }
)
```

تشمل الأحداث المفيدة بدء التشغيل وإكماله وفشله، ومحاولات النموذج، وتغييرات النص والاستدلال، وبدء الأدوات وتقدمها وإكمالها وفشلها، ونقاط التحقق البشرية.

اجعل معالجات الأحداث سريعة. ضع مهام التخزين البطيئة في قائمة انتظار، واحجب مدخلات الأدوات الحساسة قبل إرسال الأحداث إلى خدمات خارجية.
