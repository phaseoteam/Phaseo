استخدم `human_review` لنقطة تحقق عامة. وتملأ الأدوات التي تتطلب موافقة أو تُنفذ يدويًا `run.pause.pending_tool_calls` بمعرّفات الاستدعاء الدقيقة.

تابع عبر `Agent#continue_run` مع:

- قيم `ToolDecision` للموافقة أو الرفض
- قيم `ToolOutput` للعمل اليدوي
- `human_input` لإيقاف المراجعة العامة مؤقتًا
- التشغيل السابق، أو `run_id` مع أداة وصول إلى الحالة

تستخدم القرارات معرّفات الاستدعاء الدقيقة، لذلك تظل الاستدعاءات المتزامنة للأداة نفسها متميزة. وينفّذ كائن الحالة المتوافق `load(run_id)` و`save(result)`.
