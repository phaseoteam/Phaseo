description: "استدعِ /audio/transcriptions باستخدام SDK Ruby."
---

**الطرق**: `client.generate_transcription(...)` أو `client.create_transcription(...)`.

### مثال
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
transcript = client.generate_transcription(
  model: 'openai/gpt-4o-transcribe',
  audio_b64: 'base64_audio_data',
  language: 'en'
)
```

### المعلمات الأساسية
- `model` (مطلوب): معرّف نموذج يدعم النسخ الصوتي.
- `audio_url` أو `audio_b64` (مطلوب): بيانات الصوت (URL أو base64).
- `language`: رمز اللغة كإشارة (مثل `en`).
- `prompt`: سياق اختياري لتحسين الدقة.
- `temperature` (0–2): عشوائية أخذ العينات.
- `response_format`: ‏`json` و`text` و`srt` و`verbose_json` وغيرها.

### القيمة المعادة
`AudioTranscriptionResponse`
