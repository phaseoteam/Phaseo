تعيد حقول الوكيل القابلة للاستدعاء حساب معلمات الطلب من حالة التشغيل الحالية قبل كل خطوة للنموذج.

```ruby
agent = PhaseoAgentSdk.create_agent(
  id: "support-agent",
  model: ->(turn) {
    turn.run.step_count > 3 ? "openai/gpt-5.4" : "openai/gpt-5.4-nano"
  },
  instructions: ->(turn) {
    "Resolve the request using the current context."
  }
)
```

يمكن للأدوات الديناميكية وقيم أخذ العينات اتباع النمط نفسه. ويمكن للأداة تعيين `next_turn_params` لتعديل الطلب التالي مباشرةً فقط. وتظل هذه التجاوزات بعد نقطة الموافقة وتنتهي بعد الخطوة التالية.

استخدم الدوال القابلة للاستدعاء للسياسات التي ينبغي إعادة حسابها في كل خطوة. واستخدم `next_turn_params` لتمرير إعداد خاص بأداة.
