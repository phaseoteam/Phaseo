description: "استدعِ `/audio/speech` باستخدام SDK Ruby."
---

**الطريقة**: `client.generate_speech(...)` أو `client.create_speech(...)`.

### مثال
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
audio = client.generate_speech(
  model: 'openai/gpt-4o-mini-tts',
  input: 'Hello world',
  voice: 'alloy',
  format: 'mp3'
)
```

### المعلمات الرئيسية
- `model` (مطلوب): معرّف نموذج يدعم TTS.
- `input` (مطلوب): النص المراد تحويله إلى كلام.
- `voice`: إعداد صوت مسبق (يعتمد على النموذج، مثل `alloy`).
- `format`: `mp3` و`wav` و`flac` وغيرها.
- `speed`: معامل سرعة التشغيل (عادةً من 0.25 إلى 4).

### القيمة المُعادة
بيانات صوتية ثنائية
