فعّل تسجيل DevTools عند إنشاء الجداول الزمنية للأدوات وواجهات الموافقة وفاحصات التشغيل.

```ruby
result = agent.run(
  input: prompt,
  client: client,
  devtools: PhaseoAgentSdk.create_agent_devtools(
    directory: ".phaseo-devtools"
  )
)
```

تكتب كل عملية تشغيل واستكمال سجل JSONL منظّمًا يتضمن الحالة والاستخدام ومحاولات النماذج واستدعاءات الأدوات والتوقفات المؤقتة وبيانات الطلب والأخطاء.

التسجيل المحلي أداة للتطوير وليس مخزن تدقيق للإنتاج. طبّق إخفاء البيانات والتحكم في الوصول والتشفير والاحتفاظ بما يناسب التطبيق.
