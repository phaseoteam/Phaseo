تُنشر حزمة SDK باسم [`phaseo_sdk`](https://rubygems.org/gems/phaseo_sdk) على RubyGems.

## المتطلبات

- Ruby 3.1 أو أحدث

## التثبيت

```bash
gem install phaseo_sdk
```

أو أضفها إلى `Gemfile`:

```ruby
gem "phaseo_sdk"
```
