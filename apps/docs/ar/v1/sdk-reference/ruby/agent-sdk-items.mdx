توفّر نتيجة التدفق مستهلكين قابلين لإعادة الاستخدام للنص وعناصر المزوّد.

```ruby
stream = agent.stream(input: prompt, client: client)

stream.item_stream.each do |item|
  render_item(item)
end

result = stream.result
```

استخدم `full_stream` إذا كانت الواجهة تحتاج أيضًا إلى أجزاء الاستدلال أو تقدم الأدوات أو نقاط التحقق للموافقة أو أحداث دورة الحياة.

<Note>
قيم عناصر Ruby هي خرائط عامة وليست اتحادًا مغلقًا لعناصر ذات أنواع محددة. تحقّق من الحقول التي تستخدمها الواجهة واحتفظ بمعالجة احتياطية للعناصر غير المعروفة وأحداث المزوّد المستقبلية.
</Note>

يستهلك Ruby تدفق المزوّد بشكل متزامن ويتيح إعادة قراءة التسلسل المُجمّع. ولا ينشئ ذلك بحد ذاته خدمة دفع تعمل في الخلفية.
