تنتج إخفاقات الوكيل عادةً عن طلب النموذج أو أداة محلية أو التحقق من المخطط أو انتهاء المهلة أو غياب قرار بشري.

## التعافي من أخطاء الأدوات

اضبط `on_error: "return-to-model"` عندما يستطيع النموذج التعافي من خطأ الأداة. يتحول الخطأ إلى نتيجة أداة ويمكن للوكيل اختيار إجراء آخر. وأبقِ سلوك fail-run للعمليات غير الآمنة أو التي يتعذر التعافي منها.

## فهم تنفيذ Ruby

يستهلك Ruby تدفقات النموذج عبر تكرار متزامن عادي. عيّن مهلات صريحة لأدوات الشبكة والعمليات، وتجنب حظر عمليات رد نداء دورة الحياة بعمليات حفظ بطيئة.

## تشخيص أخطاء الاستكمال

يحتاج كل استدعاء معلّق إلى موافقة أو رفض أو مخرجات مقدّمة خارجيًا، مرتبطة بمعرّف استدعاء الأداة. احفظ حالة التشغيل المُعادة كاملة قبل عرض واجهة الموافقة.

## تسجيل الحقول المفيدة

سجّل معرّف التشغيل وفهرس الخطوة ومعرّف الطلب والمزوّد والنموذج وسبب الإنهاء ومعرّف استدعاء الأداة وسبب التوقف. فضّل خطافات دورة الحياة أو DevTools على تسجيل المطالبات الخام.
