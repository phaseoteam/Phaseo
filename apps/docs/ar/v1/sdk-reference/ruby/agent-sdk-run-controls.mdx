تحقّق من المخرجات عندما يحتاج كود Ruby اللاحق إلى بنية نتيجة متوقعة. تعالج محاولات النموذج إخفاقات الطلب المؤقتة؛ أما إعادة محاولة الأدوات ذات الآثار الجانبية فيجب أن تكون صريحة ومتكررة بأمان.

## إعداد إعادة المحاولة

```ruby
agent = PhaseoAgentSdk.create_agent(
  id: "research-agent",
  model: "openai/gpt-5.4-nano",
  model_retry: PhaseoAgentSdk::ModelRetryConfig.new(
    max_retries: 3,
    base_delay_ms: 500,
    max_delay_ms: 4_000
  )
)
```

تتضمن النتيجة سجل التشغيل والخطوات والرسائل والاستخدام الموحّد وسبب الإيقاف والمخرجات النهائية.

```ruby
result = agent.run(input: prompt, client: client)

puts result.output
puts result.run.status
puts result.usage[:total_tokens]
puts result.usage[:cost]
```

استخدم [شروط الإيقاف](./agent-sdk-stop-conditions.mdx) لفرض الميزانيات، و[الأخطاء واستكشاف المشكلات](./agent-sdk-observability.mdx) لاختيار السلوك عند الإخفاقات القابلة للتعافي.
