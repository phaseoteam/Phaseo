استدعِ `client.rerank.create()` لترتيب المستندات المرشّحة بحسب صلتها باستعلام باستخدام `POST /v1/rerank`. للدالة الاسم نفسه في TypeScript وPython؛ أما Rust فترسل بيانات JSON نفسها باستخدام `client.post()`.

<CodeGroup>

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const result = await client.rerank.create({
  model: "voyage/rerank-2",
  query: "How do I check whether a model is routable?",
  documents: [
    "Call GET /v1/models and use the default availability filter.",
    "Create an image with POST /v1/images/generations.",
  ],
});

console.log(result.results);
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # يقرأ PHASEO_API_KEY

result = client.rerank.create({
    "model": "voyage/rerank-2",
    "query": "How do I check whether a model is routable?",
    "documents": [
        "Call GET /v1/models and use the default availability filter.",
        "Create an image with POST /v1/images/generations.",
    ],
})

print(result["results"])
```

```rust Rust
// لا توجد دالة لإعادة الترتيب بعد: ترسل post() بيانات JSON إلى أي مسار في Phaseo.
use phaseo::Phaseo;
use serde_json::json;

let client = Phaseo::from_env()?; // يقرأ PHASEO_API_KEY

let result = client.post("/rerank", &json!({
    "model": "voyage/rerank-2",
    "query": "How do I check whether a model is routable?",
    "documents": [
        "Call GET /v1/models and use the default availability filter.",
        "Create an image with POST /v1/images/generations."
    ]
}))?;

println!("{}", result.body["results"]);
```

</CodeGroup>

**Python:** ترسل `client.rerank.create()` القاموس الذي تمرّره بوصفه جسم JSON وتعيد استجابة JSON؛ لا توجد دالة مساعدة `generate_rerank` ذات أنواع محددة. على `AsyncPhaseo`، استخدم await معها.

لا تتضمن حزم Go وC# وPHP وRuby وJava دالة لإعادة الترتيب. أرسل `POST /v1/rerank` باستخدام عميل HTTP الخاص بك، كما في [مرجع Rerank API](/ar/v1/api-reference/endpoint/rerank).

تحقّق من معرّف النموذج باستخدام `GET /v1/models` قبل استخدامه في الإنتاج.

## المعاملات

أسماء الحقول في كل حزمة SDK هي حقول جسم JSON.

| الحقل | ملاحظات |
| --- | --- |
| `model`، `query`، `documents` | مطلوبة. يحتوي `documents` على سلسلة نصية أو كائن واحد على الأقل. |
| `top_n` | أعد أفضل `n` نتائج فقط. يُقبل `top_k` بوصفه اسمًا بديلًا. |
| `return_documents` | ضمّن كل مستند في نتيجته. |
| `rank_fields` | للمستندات من نوع الكائن، الحقول التي يُرتَّب على أساسها. |
| `max_chunks_per_doc`، `max_tokens_per_doc` | حدود للمستندات الطويلة، لدى المزوّدين الذين يدعمونها. |

## الاستجابة

تتضمن `RerankResponse` الحقل `results`، ولكل نتيجة `index` المستند في قائمتك، و`relevance_score` الخاص به، و`document` عند تعيين `return_documents`، إضافة إلى `usage`.
