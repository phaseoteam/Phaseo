مرّر معرّف طلب (مثل `G-01ABC...`) إلى دالة التوليد في حزمة SDK لجلب السجل المخزّن لذلك الطلب من `GET /v1/generations?id=<id>`.

<CodeGroup>

```typescript TypeScript
const record = await client.getGeneration("G-01ABC...");
```

```python Python
record = client.get_generation("G-01ABC...")

print(record["model_id"], record["cost_nanos"])
```

```go Go
client, err := phaseo.NewFromEnv()
if err != nil {
  panic(err)
}

record, err := client.GetGeneration(context.Background(), "G-01ABC...")
if err != nil {
  panic(err)
}
fmt.Println(record["status_code"], record["cost_nanos"])
```

```csharp C#
using PhaseoSdk;

var client = new Phaseo();
var record = await client.GetGeneration("G-01ABC...");
```

```php PHP
<?php
require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo();
$record = $client->getGeneration('G-01ABC...');
```

```ruby Ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new
record = client.get_generation('G-01ABC...')
```

```java Java
import app.phaseo.sdk.Phaseo;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

var record = client.getGeneration("G-01ABC...");
System.out.println(record);
```

</CodeGroup>

| اللغة | الدالة | القيمة المُعادة |
| --- | --- | --- |
| TypeScript | `client.getGeneration(id)` | كائن السجل |
| Python | `client.get_generation(id)` | قاموس `APIResponse` |
| Go | `client.GetGeneration(ctx, id)` | `map[string]interface{}` |
| C# | `client.GetGeneration(id)` | `Dictionary<string, object>?` |
| PHP | `$client->getGeneration($id)` | مصفوفة |
| Ruby | `client.get_generation(id)` | Hash |
| Java | `client.getGeneration(id)` | `JsonNode` من Jackson |
| Rust | لا توجد دالة مساعدة؛ استدعِ `client.request("GET", "/generations?id=<id>", None, &RequestOptions::default())` | `PhaseoResponse`، والسجل في `body` (من النوع `serde_json::Value`) |

يقتصر البحث على مساحة العمل الخاصة بك. يؤدي غياب `id` إلى `400` (`missing_id`)، ويؤدي معرّف غير موجود في مساحة العمل إلى `404` (`not_found`).

## إعادة تشغيل طلب مخزّن

إذا خزّنت البوابة الطلب كاملًا، فسيحتوي السجل على `replay_supported` بقيمة true وعلى `replay_request`، ويمكنك إرساله مجددًا إلى نقطة النهاية الأصلية لإعادة تشغيل مضبوطة.

## قراءة حقول التوقيت

- `latency_ms`: الوقت حتى أول token، أو أول بايت أو إطار من المخرجات، عند تتبّعه.
- `generation_ms`: وقت التوليد بعد تلك النقطة، عند تتبّعه.
