استدعِ دالة المحادثة في حزمة SDK لإرسال `POST /v1/chat/completions` والحصول على استجابة واحدة مكتملة. للتكاملات الجديدة، توفّر [Responses API](./responses) شكل طلب واحدًا للنصوص، والمدخلات متعددة الوسائط، والأدوات، وعناصر المخرجات الأغنى.

```rust Rust
use phaseo::Phaseo;
use serde_json::json;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Phaseo::from_env()?;
    let response = client.chat_completions(&json!({
        "model": "openai/gpt-6-astra",
        "messages": [
            {
                "role": "system",
                "content": "Answer concisely."
            },
            {
                "role": "user",
                "content": "What is provider fallback?"
            }
        ]
    }))?;

    let text = response
        .body
        .pointer("/choices/0/message/content")
        .and_then(|value| value.as_str())
        .unwrap_or("");

    println!("{text}");
    Ok(())
}
```

| اللغة | الدالة | القيمة المُعادة |
| --- | --- | --- |
| TypeScript | `client.generateText(request)`؛ وتؤدي `client.chat.completions.create(request)` الوظيفة نفسها وتنتقل إلى البث عندما تكون قيمة `stream` هي true | `ChatCompletionsResponse` |
| Python | `client.generate_text(request)`؛ وكذلك `client.chat.completions.create(request)` | قاموس `APIResponse` |
| Go | `client.GenerateText(ctx, req)`، والاسم البديل `CreateChatCompletion`؛ وتقبل `phaseo.ChatCompletionsRequest` | `map[string]interface{}` |
| C# | `client.GenerateText(request)`، والاسم البديل `CreateChatCompletion` | `Dictionary<string, object>?` |
| PHP | `$client->generateText($request)`، والاسم البديل `createChatCompletion()` | مصفوفة |
| Ruby | `client.generate_text(...)`، والاسم البديل `create_chat_completion` | Hash |
| Java | `client.createChatCompletion(request)`؛ وتقبل `Map` أو `JsonNode` من Jackson | `JsonNode` من Jackson |
| Rust | `client.chat_completions(&request)` | `PhaseoResponse`؛ وبيانات JSON في `body` |

لكل قيمة مُعادة شكل Chat Completions: الرد موجود في `choices[0].message.content`، ومعه `finish_reason` و`usage`.

## بثّ الاستجابة

<CodeGroup>

```typescript TypeScript
for await (const chunk of client.streamChat({
  model: "openai/gpt-6-astra",
  messages: [{ role: "user", content: "Stream a story" }],
})) {
  if (chunk.text) process.stdout.write(chunk.text);
}
```

```python Python
for chunk in client.stream_chat({
    "model": "openai/gpt-6-astra",
    "messages": [{"role": "user", "content": "Stream a story"}],
}):
    if chunk.get("text"):
        print(chunk["text"], end="", flush=True)
```

```java Java
import app.phaseo.sdk.Phaseo;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.List;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));
var payload = Map.of(
    "model", "openai/gpt-6-astra",
    "messages", List.of(Map.of("role", "user", "content", "Hello")),
    "stream", true
);
try (var lines = client.rawClient().requestLines(
    "POST", "/chat/completions", null, null,
    new ObjectMapper().writeValueAsString(payload)
)) {
    lines.forEach(System.out::println);
}
```

</CodeGroup>

| اللغة | طريقة البث |
| --- | --- |
| TypeScript | تُنتج `client.streamChat(request)` أجزاءً محلَّلة؛ وتُنتج `client.streamText()` أسطر SSE الخام. |
| Python | تُنتج `client.stream_chat(request)` أجزاءً محلَّلة؛ وتُنتج `client.stream_text()` أسطر SSE الخام. |
| Java | تعيد `createChatCompletion` جسم JSON واحدًا. عيّن `stream: true` وأرسل الطلب باستخدام `rawClient().requestLines`، التي تعيد أسطر SSE فور وصولها؛ وأغلقها باستخدام try-with-resources. |
| Go وC# وPHP وRuby وRust | لا توجد دالة مساعدة لبث Chat Completions؛ اترك `stream` دون تعيين. في C# وPHP وRuby، تتضمن [Responses](./responses#stream-the-response) دالة للبث. |

يحتفظ كل جزء محلَّل (في TypeScript وPython) بالحقول الأصلية (`choices` و`id` و…) ويضيف `text` (المحتوى الذي أضافه هذا الجزء)، و`usage`، ورموز الاستدلال (`reasoningTokens` / `reasoning_tokens`).

## المعاملات

أسماء الحقول في كل حزمة SDK هي حقول جسم JSON. يستخدم النوع `phaseo.ChatCompletionsRequest` في Go حقول بنية بأسلوب PascalCase (`Model` و`Messages`).

| المجموعة | الحقول |
| --- | --- |
| مطلوبة | `model`؛ و`messages` بالأدوار `system` أو `developer` أو `user` أو `assistant` أو `tool`، والمحتوى سلسلة نصية أو أجزاء |
| أخذ العيّنات | `temperature` (0–2)، و`top_p` (0–1)، و`top_k` (-1 أو أكثر)، و`min_p` (0–1)، و`seed`، حيث يدعمها النموذج |
| الطول والعقوبات | `max_tokens` أو `max_completion_tokens`، و`presence_penalty` و`frequency_penalty` (من -2 إلى 2)، و`repetition_penalty` (أكبر من 0)، و`stop` (سلسلة نصية أو مصفوفة) |
| الأدوات | `tools`، `tool_choice`، `max_tool_calls`، `parallel_tool_calls` |
| الاستدلال | كائن `reasoning` أو `reasoning_effort` |
| الاحتمالات اللوغاريتمية | `logprobs`، و`top_logprobs` (0–20) |
| المخرجات | `response_format`، و`n` (1–16)، و`stream`، و`service_tier`، و`metadata` (قيم نصية) |
| البوابة | توجيه `provider`، و`usage` (تضمين الاستخدام)، و`meta` (تضمين كتلة meta الخاصة بالبوابة) |

تشرح صفحة [المعاملات](/ar/v1/api-reference/parameters) كل حقل، ويحتوي [مرجع Chat Completions API](../../api-reference/endpoint/chat-completions) على المخطط الكامل.
