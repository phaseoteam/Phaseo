استخدم Agent SDK من Phaseo عندما يحتاج تطبيقك إلى أكثر من عملية إنشاء واحدة:

- حلقات أدوات متعددة الخطوات
- أدوات وقت تشغيل محلية
- أدوار نماذج عبر Gateway
- حالة تشغيل قابلة للاستئناف يديرها التطبيق
- الموافقة على استدعاءات محددة، وأدوات بمشاركة بشرية، وأدوات يدوية، ومتابعة قابلة للاستئناف
- التحقق وقت التشغيل، وأدوات تعرض التقدم، وأخطاء أدوات قابلة للاستعادة
- بث مخرجات النماذج مع مستهلكي أحداث يمكن إعادة تشغيلها
- إعداد ديناميكي للأدوار، وشروط إيقاف قابلة للتركيب، واستخدام/تكلفة موحدان
- إعادة محاولات النماذج، ومهل الأدوات، وتزامن أدوات محدود، وأحداث دورة الحياة
- التقاط محلي باستخدام Phaseo Devtools
- توجيه متسق للطلبات باللغات نفسها التي تدعمها SDKs العميل الأساسية

## النموذج المشترك

تحافظ كل Agent SDK على نموذج وقت التشغيل نفسه:

- تعريف وكيل واحد
- تعريف صفر أو أكثر من الأدوات المحلية
- إنشاء عميل نموذج متصل بـ Gateway
- تشغيل حلقة محدودة فوق واجهة API `responses`
- فحص أحداث دورة الحياة أو أثر Devtools
- حفظ التشغيل الناتج واستئنافه بعد اتخاذ شخص قرارًا

TypeScript هو التصميم المرجعي لواجهة API. وتوفّر Python وGo وC# وPHP وRuby العقد الأوسع بين اللغات باستخدام callbacks وبدائيات أصلية للغة للتزامن والمهل والإلغاء. أما Rust فهو وقت تشغيل متزامن مدعوم، ويتضمن أدوات محلية وخارجية، وموافقات بمعرّف دقيق، ومراجعة بشرية، وإعادة محاولات النماذج، وحالة تشغيل قابلة للتسلسل، وcallbacks لدورة الحياة، وتجميع الاستخدام. ولا يزال Java وC++ قيد التطوير.

<Note>
  يُنشر Rust Agent SDK باسم `phaseo-agent`. ولا يتضمن بعد البث أو التنفيذ غير المتزامن أو الأدوات المحلية المتزامنة أو التحقق من المخططات وقت التشغيل أو التقاط Devtools.
</Note>

## Client SDK وAgent SDK وواجهة API

| الاستخدام | اختر | ما الذي يديره |
| --- | --- | --- |
| طلب API واحد أو تغطية كاملة لنقاط النهاية | Client SDK | أنواع API المولدة والنقل |
| منطق تطبيق متعدد الخطوات يستخدم الأدوات | Agent SDK | الحلقة المحلية والأدوات ونقاط الحفظ والمراجعة والأحداث وDevtools |
| نقل مخصص أو لغة غير مدعومة | واجهة API مباشرة | معالجة طلب واستجابة HTTP |

تفوض محولات Gateway في Agent SDK أدوار النماذج إلى Client SDK المطابقة. ويمكن للغات التي تدعم hook باسم `requestOptions` أو ما يعادله تمرير حقول إضافية من Responses API، بينما تستمر Agent SDK في إدارة `model` و`input` و`instructions` وأدوات الدوال المحلية. ويرسل محول Rust `0.1` حاليًا حقول الوكيل الموحدة دون hook إضافي لخيارات الطلب.
