<Note type="warning">
  لا تزال SDK للغة C++ قيد التطوير وغير متاحة عبر مدير للحزم. استخدم ترويسات المصدر للتقييم فقط.
</Note>

- الحالة: قيد التطوير (لم تُنشر بعد).
- يوجد المصدر في `packages/sdk/sdk-cpp`.
- توجد الترويسات المولّدة في `packages/sdk/sdk-cpp/src/gen`.
