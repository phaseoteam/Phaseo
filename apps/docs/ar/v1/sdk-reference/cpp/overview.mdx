title: "SDK للغة C++ (قيد التطوير)"
description: "راجع ترويسات C++ قيد التطوير."
---

<Note type="warning">
  لا تزال SDK للغة C++ قيد التطوير وغير متاحة عبر مدير حزم. استخدم ترويسات المصدر للتقييم فقط.
</Note>

حزمة SDK للغة C++ مجموعة من المصادر المكوّنة من ترويسات فقط بمعيار C++17 في `packages/sdk/sdk-cpp`؛ وهي غير منشورة ومستبعدة من إصدارات SDK إلى أن تعمل من البداية إلى النهاية.

| الملف | المحتوى |
| --- | --- |
| `src/gen/client.hpp`، `src/gen/operations.hpp`، `src/gen/models.hpp`، `src/gen/model_ids.hpp` | العميل المولَّد |
| `src/phaseo.hpp` | `GetModelEndpointCapabilities(...)` لقدرات النماذج الحية و`CheckParameterSupport(...)` لتقارير دعم المعاملات |
| `src/workflows.hpp` | دوال مساعدة للتقسيم إلى صفحات والاستعلام الدوري عن المهام |

يعيد النقل التجريبي JSON خامًا، لذا حوّل الاستجابة إلى `ModelEndpointCapabilities` قبل التحقق منها. للتجربة، راجع [التثبيت](./installation). لا تتوفر Agent SDK للغة C++.
