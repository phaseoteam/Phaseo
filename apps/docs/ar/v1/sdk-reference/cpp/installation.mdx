---
title: "تثبيت SDK للغة C++ (قيد التطوير)"
description: "استخدم ترويسات C++ قيد التطوير من المصدر."
---

<Note type="warning">لا تزال SDK للغة C++ قيد التطوير ولم تُنشر بعد في سجل للحزم.</Note>

## الاستخدام المحلي

- استخدم الترويسات المولّدة في `packages/sdk/sdk-cpp/src/gen`.
- أضف هذا المجلد إلى مسار التضمين في نظام البناء لديك.
- العميل يعتمد على الترويسات فقط حاليًا.
