**الطرق**: `$client->generateEmbedding(...)` أو `$client->createEmbedding(...)`

### مثال

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo(getenv('PHASEO_API_KEY'));
$response = $client->generateEmbedding([
    'model' => 'openai/text-embedding-3-large',
    'input' => 'Sample text',
]);

echo $response['data'][0]['embedding'][0] ?? '';
```

### المعلمات الأساسية

-   `model` (مطلوب): معرّف نموذج التضمينات (مثل `openai/text-embedding-3-large`).
-   `input` (مطلوب): سلسلة نصية أو مصفوفة من السلاسل.
-   `encoding_format`: `float` (الافتراضي) أو `base64`.
-   `dimensions`: عدد صحيح اختياري لاقتطاع طول التضمين (يعتمد على النموذج).
-   `user`: وسم اختياري للمستخدم النهائي.

### القيمة المعادة

محتوى التضمينات (JSON)
