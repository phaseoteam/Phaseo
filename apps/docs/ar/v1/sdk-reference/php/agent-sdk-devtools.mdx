---

فعّل تسجيل DevTools أثناء إنشاء جداول الأدوات الزمنية وواجهات الموافقة وفاحصات التشغيل.

```php
$result = $agent->run(
    input: $prompt,
    client: $client,
    devtools: AgentSdk::createAgentDevtools(".phaseo-devtools")
);
```

تكتب كل عملية تشغيل واستكمال سجل JSONL منظّمًا يتضمن الحالة والاستخدام ومحاولات النموذج واستدعاءات الأدوات والإيقافات المؤقتة وبيانات الطلب الوصفية والأخطاء.

التسجيل المحلي أداة مساعدة للتطوير وليس مخزن تدقيق للإنتاج. طبّق قواعد التنقيح والتحكم في الوصول والتشفير والاحتفاظ الخاصة بتطبيقك قبل حفظ محتوى حساس.
