**الطرق**: `generateResponse()` و`createResponse()`

### مثال

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo(apiKey: $apiKey);

$response = $client->createResponse([
    'model' => 'openai/gpt-4.1',
    'input' => [
        [
            'role' => 'user',
            'content' => [
                [
                    'type' => 'output_text',
                    'text' => 'Summarise this text'
                ]
            ]
        ]
    ],
    'temperature' => 0.7,
    'stream' => false
]);
echo $response['output'][0]['content'][0]['text'];
```

### المعلمات الأساسية

- `model` (مطلوب): معرّف النموذج المستهدف.
- `input` (مطلوب): مصفوفة مرتبة من عناصر الإدخال (رسائل واستدعاءات أدوات وغيرها).
- `temperature` (0–2): كلما ارتفعت القيمة زادت عشوائية النتيجة.
- `top_p` (0–1): عنصر التحكم في أخذ العينات بالنواة.
- `max_output_tokens` (عدد صحيح): الحد الأقصى للرموز المُنشأة في كل استجابة.
- الأدوات: `tools` (تعريفات)، و`tool_choice` (auto/none/محدد)، و`max_tool_calls` (عدد صحيح)، و`parallel_tool_calls` (قيمة منطقية).
- Logprobs: `top_logprobs` (0–20) لإرجاع logprobs لكل رمز.
- الإخراج: `service_tier` و`store` (قيمة منطقية) و`stream` (قيمة منطقية).
- البيانات الوصفية: `metadata` (كائن يُمرر كما هو)، و`reasoning` (كائن لتلميحات مستوى الجهد).
- إضافات البوابة: `usage` (قيمة منطقية لطلب الاستخدام)، و`meta` (قيمة منطقية لتضمين كتلة meta).

### القيمة المعادة

كائن JSON من النوع `ResponsesResponse`.
