---

توفّر نتيجة التدفق مستهلكين قابلين لإعادة الاستخدام للنص والأحداث المنظّمة.

```php
$stream = $agent->stream(input: $prompt, client: $client);

foreach ($stream->itemStream() as $item) {
    renderItem($item);
}

$result = $stream->getResult();
```

استخدم تدفق الأحداث الكامل إذا كانت الواجهة تحتاج، إلى جانب عناصر المزوّد، إلى أجزاء الاستدلال أو تقدم الأدوات أو نقاط التحقق للموافقة أو تغييرات دورة الحياة.

<Note>
قيم عناصر PHP هي مصفوفات أو كائنات عامة وليست اتحادًا مغلقًا لعناصر ذات أنواع محددة. تحقّق من الحقول التي تستخدمها الواجهة واحتفظ بمعالجة احتياطية للعناصر غير المعروفة وأحداث المزوّد المستقبلية.
</Note>

يستهلك PHP تدفق المزوّد بشكل متزامن ويتيح إعادة قراءة التسلسل المُجمّع. وهذا مناسب لعمّال الطلبات وبرامج CLI، لكنه لا ينشئ وحده قناة دفع تعمل في الخلفية.
