---

**الطريقة**: `$client->listModels(...)`

### مثال
```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo($apiKey);

$models = $client->listModels([
    'provider' => 'anthropic',
    'provider_status' => 'beta,not_ready',
    'provider_availability_reason' => 'preview_only,provider_not_ready',
    'capability_status' => 'coming_soon,internal_testing',
    'availability' => 'all',
    'limit' => 5,
]);
echo "Found " . count($models['models'] ?? []) . " models\n";
```

### المعلمات
- عوامل تصفية اختيارية: `provider` و`provider_status` و`provider_routing_status` و`model_routing_status` و`capability_status` و`provider_availability_status` و`provider_availability_reason` و`status` و`organisation` و`endpoints[]` و`input_types[]` و`output_types[]` و`params[]` و`availability` و`limit` و`offset`.
- يفيد `provider_availability_reason` مع `availability=all` عند البحث عن حالات الإطلاق مثل `preview_only` و`provider_not_ready` و`gated` و`access_limited` و`region_limited` و`project_limited` و`paused` أو `soft_blocked`.
- يفيد `capability_status` مع `availability=all` عند البحث عن تعيينات نقاط النهاية غير القابلة للتوجيه مثل `coming_soon` أو `internal_testing`.
