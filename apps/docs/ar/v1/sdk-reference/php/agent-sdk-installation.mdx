يُنشر Agent SDK باسم [`phaseo/agent-sdk`](https://packagist.org/packages/phaseo/agent-sdk) على Packagist.

## المتطلبات

- PHP 8.1 أو أحدث
- Composer
- مفتاح API من Phaseo

## التثبيت

```bash
composer require phaseo/agent-sdk
```

حزمة `phaseo/sdk` تُثبَّت تلقائيًا باعتبارها اعتمادًا.

## البيئة

اضبط مفتاح API للبوابة قبل تشغيل الأمثلة:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
