مرّر دالة رد نداء `onEvent` لتلقي أحداث دورة حياة منظّمة أثناء التشغيل.

```php
$result = $agent->run(
    input: $prompt,
    client: $client,
    onEvent: function (array $event): void {
        $logger->info("agent event", [
            "type" => $event["type"],
            "run_id" => $event["run_id"],
            "details" => $event["details"] ?? [],
        ]);
    }
);
```

تشمل الأحداث المفيدة بدء التشغيل وإكماله وفشله، ومحاولات النموذج، وأجزاء النص والاستدلال، وبدء الأدوات وتقدمها وإكمالها وفشلها، ونقاط المراجعة البشرية.

أبقِ دوال رد النداء سريعة. ضع مهام التخزين البطيئة في قائمة انتظار، واحذف المدخلات الحساسة للأدوات قبل إرسال الأحداث إلى أنظمة القياس عن بُعد الخارجية.
