يمثل PHP Agent SDK آلة حالات محلية كاملة لوكلاء Phaseo Gateway، تشمل إعادة المحاولات وفحوص المهلة والمراجعة البشرية والحالة القابلة للاستئناف وأحداث دورة الحياة وتسجيل DevTools. وتُنفّذ عمليات رد نداء الأدوات بصورة متزامنة في بيئة PHP القياسية.

استخدمه عندما تحتاج إلى:

- حلقة أدوات خفيفة ومحدودة
- طلبات `responses` المدعومة بالبوابة
- تحكم التطبيق في الحفظ والتنسيق

## ما يوفّره

- `AgentSdk::createAgent(...)`
- `AgentSdk::defineTool(...)`
- `AgentSdk::createGatewayAgentClient(...)`
- حلقة أدوات محدودة فوق واجهة `responses` في Phaseo
