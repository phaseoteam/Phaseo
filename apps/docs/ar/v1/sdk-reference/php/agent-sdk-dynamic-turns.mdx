تعيد عمليات رد النداء الديناميكية حساب معلمات النموذج من حالة التشغيل الحالية قبل كل طلب للنموذج.

```php
$agent = AgentSdk::createAgent(new AgentDefinition(
    id: "support-agent",
    model: fn ($turn) => $turn->run->stepCount > 3
        ? "openai/gpt-5.4"
        : "openai/gpt-5.4-nano",
    instructions: fn ($turn) => "Resolve the request using the current context."
));
```

يمكن للأدوات الديناميكية وقيم أخذ العينات استخدام سياق الخطوة نفسه. ويمكن للأداة أيضًا تعيين `nextTurnParams` لتعديل الطلب التالي مباشرةً فقط. وتظل هذه التجاوزات محفوظة عند إيقاف التشغيل مؤقتًا للموافقة، ثم تنتهي بعد الخطوة التالية.

استخدم عمليات رد النداء الديناميكية للسياسات التي ينبغي إعادة حسابها في كل خطوة. واستخدم `nextTurnParams` لتمرير إعداد خاص بأداة.
