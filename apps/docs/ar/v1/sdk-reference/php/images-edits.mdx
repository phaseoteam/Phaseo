description: "استدعِ /images/edits باستخدام SDK PHP."
---

**الطريقة**: `$client->generateImageEdit(...)` أو `$client->createImageEdit(...)`

### مثال

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo(getenv('PHASEO_API_KEY'));
$response = $client->generateImageEdit([
    'model' => 'openai/gpt-image-1',
    'prompt' => 'Make it sunset',
    'image' => 'data:image/png;base64,...',
    'mask' => 'data:image/png;base64,...'
]);
echo $response['data'][0]['url'] ?? '';
```

### المعلمات الأساسية

-   `model` (مطلوب): معرّف نموذج يدعم تحرير الصور.
-   `image` (مطلوب): عنوان URL لبيانات Base64 أو عنوان URL للصورة المصدر.
-   `prompt`: تعليمات جديدة اختيارية للتحرير.
-   `mask`: قناع اختياري (تُحرّر المناطق الشفافة).
-   `n` (1–10): عدد النسخ المعدّلة.
-   `size`: مثل `1024x1024` أو `1024x1792` أو `1792x1024`.
-   `response_format`: `url` أو `b64_json`.
-   `user`: وسم اختياري للمستخدم النهائي.
