اجمع دوال الإيقاف لفرض حدود المنتج بغض النظر عن قرار النموذج بالمتابعة.

```php
$agent = AgentSdk::createAgent(new AgentDefinition(
    id: "bounded-research",
    model: "openai/gpt-5.4-nano",
    stopWhen: [
        AgentSdk::stepCountIs(12),
        AgentSdk::maxTokensUsed(40000),
        AgentSdk::maxCost(2.50),
        AgentSdk::maxDuration(120000),
    ]
));
```

يوفّر SDK أيضًا شروطًا لاستدعاءات الأدوات وأسباب الإنهاء. افحص `$result->run->stopReason` والاستخدام الموحد بعد الاكتمال كي يميّز التطبيق بين التوقف بسبب الميزانية والانتهاء الطبيعي للنموذج.

يُعد التوقف نتيجة ضمن حد، وليس استثناءً تلقائيًا. حدّد أسباب التوقف التي يعاملها منتجك كنجاح أو قابلة لإعادة المحاولة أو مرئية للمستخدم.
