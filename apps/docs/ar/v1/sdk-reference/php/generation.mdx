**الطريقة**: `getGeneration()`

### مثال

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo(apiKey: $apiKey);

$record = $client->getGeneration('G-01ABC...');
```

### المعاملات

- `id` (سلسلة نصية، مطلوب): معرّف الطلب الذي أعادته استدعاءة سابقة.

### القيمة المعادة

سجل التوليد (JSON)

إذا خزّنت البوابة تفاصيل الطلب كاملة، فسيتضمن السجل المُعاد أيضًا `replay_supported` و`replay_request`، ما يتيح إعادة إرسال الحمولة المسجّلة إلى نقطة النهاية الأصلية لإعادة تشغيل مضبوطة.

تتبع حقول التوقيت دلالات البوابة المشتركة:

- `latency_ms`: الوقت حتى أول رمز أو أول بايت/إطار إخراج، عند تسجيله
- `generation_ms`: وقت التوليد بعد زمن الاستجابة، عند تسجيله
