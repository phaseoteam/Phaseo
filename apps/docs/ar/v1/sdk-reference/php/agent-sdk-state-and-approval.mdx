استخدم `AgentDefinition::$humanReview` لنقطة تحقق عامة. وتملأ الأدوات التي تتطلب موافقة أو تُنفذ يدويًا `$result->run->pause->pendingToolCalls` بمعرّفات الاستدعاء الدقيقة.

تابع عبر `Agent::continueRun(...)` مع:

- قيم `ToolDecision` للموافقة أو الرفض
- قيم `ToolOutput` للعمل اليدوي
- إدخال بشري لإيقاف المراجعة العامة مؤقتًا

استخدم `continueRunById(...)` مع `StateAccessor` عندما ينبغي للتطبيق إعادة تحميل التشغيل من التخزين. وتُطابق القرارات بمعرّف الاستدعاء لا باسم الأداة.
