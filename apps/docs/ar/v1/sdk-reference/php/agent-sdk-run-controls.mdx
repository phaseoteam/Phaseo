استخدم التحقق من المخرجات عندما يحتاج كود PHP اللاحق إلى بنية متوقعة. تعالج محاولات النموذج إخفاقات الطلب المؤقتة؛ أما الأدوات ذات الآثار الجانبية فيجب أن تعيد المحاولة داخل تنفيذ الأداة نفسه وأن تكون متكررة بأمان.

## إعداد إعادة المحاولة

```php
$agent = AgentSdk::createAgent(new AgentDefinition(
    id: "research-agent",
    model: "openai/gpt-5.4-nano",
    modelRetry: new ModelRetryConfig(
        maxRetries: 3,
        baseDelayMs: 500,
        maxDelayMs: 4000
    )
));
```

يتضمن ناتج التشغيل الحالة والخطوات والرسائل والاستخدام الموحّد وسبب الإيقاف والمخرجات النهائية. افحص هذه الحقول بدلًا من اعتبار النص النهائي سجل التشغيل الكامل.

$result = $agent->run(input: $prompt, client: $client);
