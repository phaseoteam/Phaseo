استخدم الحزمة المنشورة [`phaseo-agent`](https://crates.io/crates/phaseo-agent) عندما يحتاج تطبيق Rust إلى حلقة نموذج محدودة أو أدوات محلية أو موافقات أو مراجعة بشرية قابلة للاستئناف.

تعتمد حزمة وكلاء Rust على عميل `phaseo` وتشغّل جولات النموذج عبر واجهة Phaseo Responses API.

## الإمكانات المدعومة

| الإمكانات | دعم Rust |
| --- | --- |
| الأدوات المحلية القابلة للتنفيذ | نعم؛ تُنفّذ بالتزامن وفق ترتيب استدعاءات النموذج |
| مخرجات الأدوات الخارجية | نعم؛ باستخدام `Tool::external(...)` و`ContinueOptions` |
| الموافقة على الأدوات | نعم؛ باستخدام المعرّف الدقيق لاستدعاء الأداة |
| المراجعة البشرية | نعم؛ مع حالة تشغيل متوقفة قابلة للتسلسل |
| إعادات محاولة النموذج | نعم؛ مع فترة انتظار ثابتة بين المحاولات |
| أحداث دورة الحياة | نعم؛ عبر أساليب تشغيل تعتمد على callbacks |
| تجميع الاستخدام | رموز الإدخال والإخراج والمخزنة مؤقتًا والإجمالية؛ والتكلفة إذا ملأها عميل نموذج مخصص |
| حدود التشغيل | الحد الأقصى لخطوات النموذج |
| محوّل Gateway | Responses API عبر `GatewayAgentClient` |
| البث | غير مدعوم بعد |
| التنفيذ غير المتزامن والإلغاء | غير مدعومين بعد |
| الأدوات المحلية المتزامنة | غير مدعومة بعد |
| التحقق من المخطط وقت التشغيل | يُرسل JSON Schema إلى النموذج؛ وتكون المدخلات والمخرجات المحلية من نوع `serde_json::Value` |
| التقاط Devtools | غير مدعوم بعد |

<Note>
Rust بيئة تشغيل متزامنة مدعومة، وليست منفذًا مكافئًا في جميع الميزات لبيئة البث في TypeScript. توثّق هذه الصفحات واجهات API المتاحة في `phaseo-agent 0.1` فقط.
</Note>

## نموذج التشغيل

1. يرسل الرسائل الحالية وتعريفات الأدوات إلى `ModelClient`
2. ينفّذ الأدوات المحلية المتاحة
3. يتوقف مؤقتًا للموافقات أو المخرجات الخارجية أو المراجعة البشرية عند الحاجة
4. يضيف النتائج ويتابع حتى الاكتمال أو بلوغ حد الخطوات

لا تخزّن SDK عمليات التشغيل في خدمة تستضيفها Phaseo. احفظ `RunResult` في تطبيقك إذا كان يجب أن يستمر التشغيل بعد إعادة تشغيل العملية.

لا يربط محوّل Gateway `0.1` حاليًا `cost_nanos` أو `cost_cents` من Gateway بالحقل `UsageSummary.cost`. لتتبّع الإنفاق، استخدم استجابة Gateway أو سجل التوليد بدلًا من حقل التكلفة في Agent SDK.
