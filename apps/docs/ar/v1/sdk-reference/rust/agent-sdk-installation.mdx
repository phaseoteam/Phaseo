## المتطلبات

- Rust 1.86 أو أحدث
- مفتاح API لبوابة Phaseo

## التثبيت

```toml
[dependencies]
phaseo = "0.1"
phaseo-agent = "0.1"
serde_json = "1"
```

أو شغّل:

```bash
cargo add phaseo@0.1 phaseo-agent@0.1 serde_json
```

## إعداد المصادقة

تقرأ `create_gateway_agent_client(...)` و`GatewayAgentClient::from_env(...)` المتغير `PHASEO_API_KEY`:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

يقبل عميل `phaseo` الأساسي أيضًا المتغير الاختياري `PHASEO_BASE_URL`.

## التحقق من التثبيت

```rust
use phaseo_agent::{create_agent, AgentDefinition};

fn main() {
    let _agent = create_agent(AgentDefinition::new(
        "verification-agent",
        "openai/gpt-5.6-sol",
    ));
    println!("Phaseo Rust Agent SDK installed");
}
```
