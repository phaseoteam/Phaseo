اضبط `OnEvent` في `RunOptions` أو `ContinueOptions` لتلقي أحداث دورة حياة منظّمة دون ربط التطبيق بوسيلة نقل النموذج.

```go
result, err := agent.Run(ctx, phaseoagent.RunOptions{
  Input: prompt,
  Client: client,
  OnEvent: func(event phaseoagent.AgentEvent) {
    logger.Info("agent event",
      "type", event.Type,
      "run_id", event.RunID,
      "details", event.Details,
    )
  },
})
```

تشمل فئات الأحداث المفيدة بدء التشغيل وإكماله وفشله، ومحاولات النموذج، وأجزاء نص المخرجات والاستدلال، وبدء الأدوات وتقدمها وإكمالها وفشلها، ونقاط المراجعة البشرية.

أبقِ المعالجات سريعة وغير حاجبة. أرسل الأحداث إلى قائمة انتظار أو طبقة قياس عن بُعد خاصة بك إذا كان التخزين قد يستغرق وقتًا، واحذف المدخلات الحساسة للأدوات قبل إرسالها إلى جهة خارجية.
