## تجهيز بيئة التشغيل

لا يتوفر لـ Agent SDK إصدار وحدة Go عام بعد. اتبع [تعليمات التثبيت من المصدر](./agent-sdk-installation.mdx).

## البدء السريع

```go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "quickstart-agent",
    Model:        "openai/gpt-5.4-nano",
    Instructions: "Answer concisely and helpfully.",
  })

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "Give me one fun fact about cURL.",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Output)
}
```

## ما الذي يتضمنه

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- حلقة أدوات محدودة عبر واجهة `responses` من Phaseo

## بيئة تشغيل متقدمة

يدعم Go أدوات التحقق والموافقات، وأدوات التدخل البشري واليدوية، والتقدم، والأخطاء القابلة للاسترداد، والقنوات القابلة لإعادة التشغيل، ومساعدات الإيقاف، والجولات الديناميكية، و`NextTurnParams` المحفوظة، والاستخدام والتكلفة الموحدين، و`StateAccessor`.

## البث والإلغاء

تستهلك `Agent.Stream(...)` و`Agent.ContinueStream(...)` تدفق Responses SSE للبوابة. اقرأ `Text()` أو `Events()` أكثر من مرة عندما تحتاج مستهلكات منفصلة إلى إعادة التشغيل، واستدعِ `Cancel()` لإلغاء سياق الطلب. تحتفظ الخطوات المكتملة بمعرّفات الطلب وبيانات مزود الخدمة الوصفية وأسباب الإنهاء والتحذيرات والاستخدام والتكلفة.
