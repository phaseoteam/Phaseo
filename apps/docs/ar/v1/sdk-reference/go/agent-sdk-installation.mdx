يُنشر Agent SDK باسم [`agent-sdk-go`](https://pkg.go.dev/github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go) عبر وحدات Go.

## المتطلبات

- Go 1.24 أو أحدث
- مفتاح API من Phaseo

## التثبيت

```bash
go get github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go@latest
```

الوحدة الأساسية `sdk-go/v2` تُثبَّت تلقائيًا باعتبارها اعتمادًا.

## البيئة

اضبط مفتاح API للبوابة قبل تشغيل الأمثلة:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
