description: "سجّل عمليات Go Agent SDK بتنسيق أحداث Phaseo DevTools المحلي."
---

يسجّل DevTools لكل عملية تشغيل واستكمال سجل JSONL منظّمًا. ويفيد ذلك أثناء إنشاء الجداول الزمنية وواجهات الموافقة وعروض استدعاءات الأدوات.

```go
result, err := agent.Run(ctx, phaseoagent.RunOptions{
  Input: prompt,
  Client: client,
  Devtools: phaseoagent.CreateAgentDevtools(".phaseo-devtools"),
})
```

يتضمن السجل حالة التشغيل والاستخدام ومحاولات النموذج واستدعاءات الأدوات والإيقافات المؤقتة وبيانات الطلب الوصفية والأخطاء. وترتبط عمليات الاستكمال بهوية التشغيل نفسها.

لا تتعامل مع التسجيل المحلي بوصفه مخزن تدقيق للإنتاج. طبّق سياساتك الخاصة للاحتفاظ والتحكم في الوصول والتنقيح والتشفير قبل حفظ المطالبات أو نتائج الأدوات الحساسة.
