Go Agent SDK بيئة تشغيل محلية متكاملة لوكلاء Phaseo Gateway، وتشمل إعادة المحاولة والأدوات المتزامنة والسياقات والمهل ومراجعة البشر والحالة القابلة للاستئناف وأحداث دورة الحياة وتسجيل DevTools.

استخدمه عندما تريد:

- حلقة أدوات خفيفة ومحدودة
- طلبات إلى نقطة نهاية `responses` عبر Gateway
- تحكم التطبيق في الاستمرارية والتنسيق

## ما الذي يقدمه

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- طلبات إلى نقطة نهاية `responses` عبر Gateway
