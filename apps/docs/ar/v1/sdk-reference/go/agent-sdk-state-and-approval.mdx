استخدم `HumanReview` لنقطة تحقق عامة. وتملأ الأدوات التي تتطلب موافقة أو تُنفذ يدويًا `Run.Pause.PendingToolCalls` بمعرّفات الاستدعاء الدقيقة.

تابع عبر `Agent.Continue(...)` مع:

- إدخالات `ToolDecision` ضمن `Approvals` أو `Rejections`
- إدخالات `ToolOutput` للعمل اليدوي
- `HumanInput` لإيقاف المراجعة العامة مؤقتًا
- قيمة `RunResult` السابقة، أو `RunID` مع `StateAccessor`

تستخدم القرارات معرّفات الاستدعاء الدقيقة، لذلك تظل الاستدعاءات المتزامنة للأداة نفسها متميزة. نفّذ `StateAccessor.Load(...)` و`Save(...)` إذا كان ينبغي أن تستمر عمليات التشغيل عبر الطلبات أو عمليات إعادة التشغيل.
