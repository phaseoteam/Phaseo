استخدم TypeScript Agent SDK عندما يحتاج تطبيقك إلى أكثر من عملية توليد واحدة:

- حلقات أدوات محلية متعددة الخطوات
- حالة تشغيل قابلة للاستئناف
- جولات نموذج مدعومة بالبوابة
- مخرجات منظّمة تم التحقق منها، وتقدم متدفق، وتوجيه متوافق مع الإضافات

يعتمد على `@phaseo/sdk` ويحدد عقد بيئة التشغيل المرجعي المشترك بين إصدارات Agent SDK للغات الأخرى.

## مصفوفة إمكانات بيئة التشغيل

| الإمكانية | دعم SDK |
| --- | --- |
| أدوات قابلة للتنفيذ ومتزامنة | مدمجة، مع ترتيب حتمي للنتائج ومهلة زمنية لكل أداة |
| التحقق وقت التشغيل | مخططات الإدخال والإخراج والأحداث والنتيجة النهائية للوكيل عبر `parse` أو `safeParse` أو دوال التحقق |
| الموافقة البشرية | لكل أداة أو استدعاء، مع الموافقة باستخدام معرّف الاستدعاء الدقيق والرفض عند الاستئناف |
| أدوات تتضمن تدخلًا بشريًا | الإيقاف المؤقت عبر `onToolCalled` والتحويل عبر `onResponseReceived` |
| الأدوات اليدوية | `execute: false` مع توفير `toolOutputs` خارجيًا |
| أدوات تعرض التقدم | أدوات مولّدات غير متزامنة وأحداث `tool.preliminary_result` |
| التعافي من أخطاء الأدوات | إفشال التشغيل أو إعادة خطأ أداة منظّم إلى النموذج |
| البث | فروق النموذج ومستهلكات قابلة لإعادة التشغيل للنص والاستدلال والعناصر والأدوات وجميع الأحداث |
| عناصر التحكم في الإيقاف | الخطوات والمدة والرموز والتكلفة واستدعاءات الأدوات وسبب الإنهاء والشروط المخصصة |
| الجولات الديناميكية | نموذج وتعليمات وقيم أخذ عينات ومجموعات أدوات وتعديل للسياق و`nextTurnParams` ديناميكية |
| متابعة دائمة | نتائج تشغيل قابلة للتسلسل أو أداة وصول إلى `state` تتولى التطبيق تحميلها وحفظها |
| قابلية المراقبة | استخدام وتكلفة موحدان، وتحذيرات، وأسباب الإنهاء، ونتائج الخطوات، وأحداث دورة الحياة، وأدوات التطوير المحلية |

## ما الذي ستحصل عليه

- `createAgent()`
- `defineTool()`
- `createGatewayAgentClient()`
- `run()`، `stream()`، `continueRun()`، و`continueStream()`
- أدوات قابلة للتنفيذ ويدوية وخاضعة للموافقة وتتضمن تدخلًا بشريًا
- مخططات الإدخال والإخراج وقت التشغيل، وتقدم المولدات، وشروط إيقاف قابلة للتركيب، وملخصات الاستخدام والتكلفة
- أدوات وصول اختيارية إلى الحالة تملكها التطبيقات وأحداث دورة الحياة لأدوات التطوير
