**الطريقة**: `client.generateText()` (لبث الأجزاء التي جرى تحليلها استخدم `client.streamChat()`).

### مثال
```typescript
const chat = await client.generateText({
  model: "openai/gpt-4o-mini",
  messages: [
    { role: "system", content: "You are helpful." },
    { role: "user", content: "Write a limerick about lighthouses." },
  ],
  temperature: 0.5,
});
```

### البث
```typescript
for await (const chunk of client.streamChat({
  model: "openai/gpt-4o-mini",
  messages: [{ role: "user", content: "Stream a story" }],
})) {
  if (chunk.text) process.stdout.write(chunk.text);
}
```

### المعلمات الأساسية
- `model` (required): معرّف النموذج المستهدف.
- `messages` (required): رسائل مرتبة بأدوار `system|user|assistant|tool`؛ ويمكن أن يكون المحتوى سلاسل نصية أو أجزاء.
- أخذ العينات: `temperature` (0–2), `top_p` (0–1), `top_k` (>=1), `seed` (int, optional).
- الطول/العقوبات: `max_output_tokens` (int), `presence_penalty` and `frequency_penalty` (-2 to 2), `stop` (string|string[]).
- الأدوات: `tools` (التعريفات), `tool_choice` (`auto`/`none`/أداة محددة), `max_tool_calls` (int), `parallel_tool_calls` (bool).
- Logprobs: `logprobs` (bool), `top_logprobs` (0–20).
- الإخراج: `response_format` (json/text), `metadata` (object passthrough), `stream` (bool), `service_tier`.
- خيارات Gateway الإضافية: `usage` (قيمة منطقية لطلب الاستخدام)، و`meta` (قيمة منطقية لتضمين كتلة البيانات الوصفية).
