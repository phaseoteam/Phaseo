**الطريقة**: `client.getGeneration()`.

### مثال
```typescript
const record = await client.getGeneration("G-01ABC...");
```

### المعلمات
- `id` (سلسلة نصية، مطلوب): معرّف الطلب الذي أعاده استدعاء سابق.

### القيمة المعادة
سجل التوليد (JSON)

إذا خزّنت البوابة تفاصيل الطلب كاملة، فسيتضمن السجل المُعاد `replay_supported` و`replay_request`. أرسل `replay_request` إلى نقطة النهاية الأصلية لإعادة تشغيل مضبوطة.

تتبع حقول التوقيت دلالات البوابة المشتركة:

- `latency_ms`: الوقت حتى أول رمز أو أول بايت/إطار إخراج عند تتبعه
- `generation_ms`: وقت التوليد بعد زمن الاستجابة الأولية عند تتبعه
