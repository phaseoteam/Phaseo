---

**الطريقة**: `client.generateModeration()`.

### مثال
```typescript
const moderation = await client.generateModeration({
  model: "openai/omni-moderation-latest",
  input: "Text to classify",
});
```

### المعلمات الأساسية
- `model` (مطلوب): معرّف نموذج الإشراف على المحتوى (مثل `openai/omni-moderation-latest`).
- `input` (مطلوب): سلسلة أو مصفوفة من عناصر المحتوى (نص أو `image_url`).
- اختياري: عوامل تصفية `categories`/`severity` عند دعمها، ووسم `user`.
