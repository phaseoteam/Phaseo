يُنشر Agent SDK على npm باسم [`@phaseo/agent-sdk`](https://www.npmjs.com/package/@phaseo/agent-sdk).

## المتطلبات

- مشروع TypeScript أو JavaScript يستخدم npm أو pnpm أو Yarn أو Bun
- مفتاح API من Phaseo

## التثبيت

ثبّت Agent SDK باستخدام مدير الحزم المفضل لديك:

<CodeGroup>

    ```bash title="npm"
    npm install @phaseo/agent-sdk
    ```

    ```bash title="pnpm"
    pnpm add @phaseo/agent-sdk
    ```

    ```bash title="yarn"
    yarn add @phaseo/agent-sdk
    ```

    ```bash title="bun"
    bun add @phaseo/agent-sdk
    ```

</CodeGroup>

يُثبّت الحزمة الأساسية `@phaseo/sdk` تلقائيًا كاعتمادية.

## البيئة

اضبط مفتاح API للبوابة قبل تشغيل الأمثلة:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
