اختر أبسط مثال يناسب المنتج الذي تبنيه. تحتفظ كل الأنماط بإدارة الاستمرارية وواجهة المستخدم في تطبيقك، مع استخدام Phaseo لجولات النموذج.

## أمثلة ضمن الحزمة

| المثال | الاستخدام |
| --- | --- |
| `research-brief-agent.ts` | البحث باستخدام البحث المُدار وإنتاج موجز نهائي محدد النوع |
| `support-triage-agent.ts` | توجيه طلبات الدعم وتصنيفها باستخدام إعداد مُدار مسبقًا |
| `coding-review-agent.ts` | مراجعة الكود باستخدام أدوات تشغيل محلية |
| `parallel-tool-agent.ts` | تشغيل أدوات محلية مستقلة بالتوازي |
