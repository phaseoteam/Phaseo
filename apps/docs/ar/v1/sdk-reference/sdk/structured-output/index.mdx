مرّر `output: Output.object({ schema })` إلى `generateText` لتحصل على كائن محدد النوع يطابق مخططك. يرسل AI SDK المخطط بوصفه صيغة استجابة JSON Schema ويتحقق من النتيجة.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, Output } from "ai";
import { z } from "zod";

const { output } = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  output: Output.object({
    schema: z.object({
      title: z.string(),
      priority: z.enum(["low", "medium", "high"]),
      actions: z.array(z.string()),
    }),
  }),
  prompt: "Create a short incident follow-up plan.",
});

console.log(output);
```

لا تزال `generateObject` تعمل في AI SDK 7 مع `schema` نفسه وتعيد `object`، لكنها مُهمَلة لصالح `generateText` مع `output`.

## التعامل مع المخرجات غير الصالحة

ترمي قراءة `output` الخطأ `NoOutputGeneratedError` عندما لا يعيد النموذج كائنًا صالحًا للاستخدام، مثلًا عندما تنتهي الخطوة الأخيرة باستدعاء أداة. التقطه في الموضع الذي تستدعي فيه النموذج.

- استخدم قيم enum صريحة وحقولًا مطلوبة في المخطط.
- أبقِ الموجّه متسقًا مع بنية المخطط.
- يختلف دعم النماذج لمخرجات JSON Schema؛ تحقّق من المعاملات المدعومة للنموذج في `/v1/models`.
