استخدم `streamText` عندما تريد استلام الرموز الجزئية فور وصولها.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## البث باستخدام الرسائل

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## نصائح للإنتاج

- فضّل البث للاستجابات الطويلة والواجهات التفاعلية.
- عالج الإلغاء والمهلة في بيئة التشغيل للتدفقات المهجورة.
- حدّث معرّفات النماذج عبر `/v1/models` لتجنّب الأسماء المستعارة القديمة.
