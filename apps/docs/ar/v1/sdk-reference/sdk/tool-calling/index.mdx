عرّف الأدوات بالمساعد `tool()` في AI SDK، ومرّرها إلى `generateText`، واضبط `stopWhen` كي يتمكن النموذج من الإجابة بعد تشغيل الأداة.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, stepCountIs, tool } from "ai";
import { z } from "zod";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "What is 17 + 25? Use the calculator tool.",
  tools: {
    calculator: tool({
      description: "Perform basic arithmetic",
      inputSchema: z.object({
        operation: z.enum(["add", "subtract", "multiply", "divide"]),
        a: z.number(),
        b: z.number(),
      }),
      execute: async ({ operation, a, b }) => {
        if (operation === "add") return a + b;
        if (operation === "subtract") return a - b;
        if (operation === "multiply") return a * b;
        return a / b;
      },
    }),
  },
  stopWhen: stepCountIs(2),
});

console.log(result.text);
```

تتوقف `generateText` افتراضيًا بعد خطوة واحدة. إذا كانت تلك الخطوة استدعاء أداة، يكون `result.text` فارغًا وتكون نتيجة الأداة في `result.toolResults`. يمنح `stepCountIs(2)` النموذج خطوة ثانية ليجيب باستخدام النتيجة.

## كتابة أدوات آمنة

- اجعل الأوصاف دقيقة ومخططات الإدخال صارمة؛ فالنموذج هو من يملأ الوسائط.
- عامِل الوسائط على أنها مدخلات غير موثوقة. تحقّق منها داخل `execute` قبل أي أثر جانبي.
- أضف إعادات المحاولة والتراجع التدريجي داخل `execute` لواجهات API اللاحقة التي تفشل مؤقتًا.
