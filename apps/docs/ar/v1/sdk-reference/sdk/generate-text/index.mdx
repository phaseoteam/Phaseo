استدعِ `generateText` مع `phaseo(modelId)` للحصول على استجابة واحدة مكتملة.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a concise summary of Phaseo Gateway.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

## إرسال سجل المحادثة

استخدم `prompt` لجولة واحدة، و`messages` عندما تحتاج إلى عدة جولات أو إلى دور النظام.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "system", content: "You are a terse assistant." },
    { role: "user", content: "Give me three bullet points on retrieval augmentation." },
  ],
});

console.log(result.text);
console.log(result.providerMetadata);
```

## ضبط القيم الافتراضية على النموذج

مرّر الإعدادات وسيطًا ثانيًا إلى `phaseo()`. تنطبق على كل استدعاء يستخدم نسخة النموذج هذه.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra", {
    maxTokens: 300,
  }),
  prompt: "Draft a release note for an API update.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

تأخذ معرّفات النماذج الصيغة `provider/model`. لإبقائها محدّثة، اقرأها من `/v1/models`؛ راجع [اكتشاف النماذج](/ar/v1/sdk-reference/sdk/get-models).
