مرّر `phaseo.transcriptionModel(modelId)` إلى `transcribe` لتحويل الكلام إلى نص، و`phaseo.speechModel(modelId)` إلى `generateSpeech` لتحويل النص إلى كلام. يرفع المزوّد الصوت إلى `/v1/audio/transcriptions` بصيغة نموذج multipart، ويرسل طلبات الكلام إلى `/v1/audio/speech`.

```ts
import { readFileSync, writeFileSync } from "node:fs";
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateSpeech, transcribe } from "ai";

const transcription = await transcribe({
  model: phaseo.transcriptionModel("openai/whisper-1"),
  audio: readFileSync("./audio.mp3"),
});

console.log(transcription.text);
console.log(transcription.providerMetadata);

const speech = await generateSpeech({
  model: phaseo.speechModel("openai/gpt-4o-mini-tts"),
  text: "Hello from Phaseo audio.",
  voice: "alloy",
  outputFormat: "mp3",
});

writeFileSync("./speech.mp3", Buffer.from(speech.audio.uint8Array));
console.log(speech.providerMetadata);
```

يقبل `audio` قيمة من نوع `Buffer` أو `Uint8Array` أو `ArrayBuffer` أو سلسلة base64 أو `URL`. لا يزال AI SDK 7 يصدّر الاسمين الأقدم `experimental_transcribe` و`experimental_generateSpeech` بوصفهما اسمين بديلين.

## التعامل مع الصوت الطويل أو الطلبات الفاشلة

- تعتمد صيغ الإدخال والإخراج المدعومة على النموذج.
- ارفع مهلات الانتظار للملفات الطويلة، وأبقِ عمليات الرفع ضمن حد الحجم الخاص بالنموذج (25 MB لمعظم النماذج).
- أعِد محاولة استجابات `429` و`5xx` المؤقتة مع تراجع تدريجي.
