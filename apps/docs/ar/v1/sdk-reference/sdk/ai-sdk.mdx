ثبّت `@phaseo/ai-sdk-provider` ومرّر `phaseo(modelId)` بوصفه `model` إلى `generateText` أو `streamText` أو أي دالة أخرى في Vercel AI SDK 7. تذهب الطلبات النصية إلى نقطة النهاية `/v1/chat/completions` في Gateway.

## التثبيت

<CodeGroup>

```bash title="npm"
npm install @phaseo/ai-sdk-provider
```

```bash title="pnpm"
pnpm add @phaseo/ai-sdk-provider
```

```bash title="yarn"
yarn add @phaseo/ai-sdk-provider
```

```bash title="bun"
bun add @phaseo/ai-sdk-provider
```

</CodeGroup>

تثبيت الحزمة دون تحديد إصدار يجلب الوسم `latest` في npm، وهو خط AI SDK 7. تعلن الحزمة `ai@^7` اعتماديةً نظيرة (peer dependency)، لذا تضيفها مديرات الحزم التي تثبّت الاعتماديات النظيرة تلقائيًا نيابةً عنك.

اضبط `PHASEO_API_KEY` في بيئة الخادم، ثم أرسل طلبك الأول. يرمي التصدير الافتراضي `phaseo` خطأً إذا لم يكن `PHASEO_API_KEY` مضبوطًا.

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Reply with: AI SDK works",
});

console.log(result.text);
console.log(result.providerMetadata);
```

استخدم معرّف نموذج حاليًا من [نقطة النهاية Models](../../api-reference/endpoint/models.mdx).

## بث النص

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Stream a short greeting.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## ضبط نسخة من المزوّد

استدعِ `createPhaseo()` لضبط `apiKey` أو `baseURL` أو `headers` أو `fetch` مخصّص. استخدمها لتعريف تطبيقك في تفاصيل الطلبات في Phaseo:

```typescript
import { createPhaseo } from "@phaseo/ai-sdk-provider";

const phaseo = createPhaseo({
  apiKey: process.env.PHASEO_API_KEY,
  headers: {
    "x-title": "My App",
    "http-referer": "https://example.com",
  },
});
```

`PHASEO_BASE_URL` اختياري، وقيمته الافتراضية `https://api.phaseo.app/v1`.

## اختيار نوع النموذج

| طريقة المزوّد | دالة AI SDK |
| --- | --- |
| `phaseo(modelId)` أو `phaseo.languageModel(modelId)` | `generateText`، `streamText` |
| `phaseo.embeddingModel(modelId)` (الاسم البديل `textEmbeddingModel`) | `embed`، `embedMany` |
| `phaseo.imageModel(modelId)` | `generateImage` |
| `phaseo.transcriptionModel(modelId)` | `transcribe` |
| `phaseo.speechModel(modelId)` | `generateSpeech` |
| `phaseo.rerankingModel(modelId)` | `rerank` |

تقبل كل الطرق باستثناء `rerankingModel` إعدادات اختيارية لكل نموذج وسيطًا ثانيًا: `temperature` و`topP` و`topK` و`maxTokens` و`frequencyPenalty` و`presencePenalty` و`seed` و`user` و`headers` و`fetch`.

## ميزات AI SDK 7 المدعومة

- توليد النص وبثه
- مخرجات الاستدلال وإعداداته
- أدوات الدوال ومدخلات الأدوات المبثوثة
- مخرجات JSON وJSON Schema
- مدخلات الملفات النصية وملفات الصور
- مصادر الاستشهاد بعناوين URL
- التضمينات وتوليد الصور
- إعادة الترتيب
- النسخ الصوتي وتوليد الكلام
- البيانات الوصفية للمزوّد، والاستخدام، وإشارات الإلغاء، وأجزاء البث الخام

لا تزال قدرات الاستدعاء تعتمد على النموذج والمزوّد. لا يعلن المزوّد عن مراجع الملفات المُدارة أو المهارات أو الأدوات التي ينفّذها المزوّد (تعريفاتها أو نتائجها أو ردود الموافقة عليها). أما أدوات الدوال التي ينفّذها تطبيقك فتستخدم مسار التنفيذ والموافقة المعتاد في AI SDK.

## استخدام إصدار أقدم من AI SDK

| AI SDK | التثبيت |
| --- | --- |
| 7 | `@phaseo/ai-sdk-provider` (`latest`) |
| 6 | `@phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `@phaseo/ai-sdk-provider@ai-sdk-v5` |

إذا كان التثبيت التلقائي للاعتماديات النظيرة متوقفًا، فثبّت الإصدار الرئيسي المطابق من `ai` (`ai@^7` أو `ai@^6` أو `ai@^5`) بنفسك.
