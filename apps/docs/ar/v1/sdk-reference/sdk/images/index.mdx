مرّر `phaseo.imageModel(modelId)` إلى `generateImage`. تذهب الطلبات إلى نقطة النهاية `/v1/images/generations` في Gateway.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateImage } from "ai";

const result = await generateImage({
  model: phaseo.imageModel("openai/gpt-image-1"),
  prompt: "A minimalist poster of a lighthouse at dawn.",
  size: "1024x1024",
});

console.log(result.images[0].mediaType);
console.log(result.images[0].uint8Array.length);
console.log(result.providerMetadata);
```

## قراءة النتيجة

تُحوَّل الصور التي يعيدها Gateway في صورة عناوين URL إلى بنية الملفات في AI SDK، لذا اقرأ `uint8Array` و`mediaType` في كل صورة، أيًّا كان ما أعاده المزوّد.

- تعتمد قيم `size` المتاحة على النموذج.
- لإعادة إنتاج صورة لاحقًا، خزّن الموجّه والنموذج والمعاملات مع البيانات الوصفية للصورة.
