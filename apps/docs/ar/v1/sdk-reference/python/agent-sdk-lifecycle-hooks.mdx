مرّر `on_event` لتحديث الجداول الزمنية للمنتج أو سجلات التدقيق أو نظام القياس عن بُعد الحالي:

```python
def on_event(event):
    logger.info("%s %s", event.type, event.run_id)
```

تشمل الأحداث حالة التشغيل واستدعاءات النماذج والخطوات ونقاط الحفظ وتنفيذ الأدوات وتقدمها وانتظار التدخل البشري والإلغاء والإخفاقات. اجعل دالة الاستدعاء سريعة وضع المهام البطيئة في قائمة انتظار خارجية.
