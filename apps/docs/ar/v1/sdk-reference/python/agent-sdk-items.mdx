تتضمن `AgentRunResult` حالة التشغيل الدائمة والرسائل والخطوات والاستخدام والتكلفة والتحذيرات وأسباب الإنهاء والمخرجات النهائية.

استخدم `text_stream()` لنص الإجابة و`item_stream()` لعناصر المزوّد وبيئة التشغيل. تكون عناصر Python حاليًا على شكل قواميس، وليست الاتحاد المميّز `AgentItem` في TypeScript.

```python
for item in stream.item_stream():
    item_type = item.get("type")
    render_timeline_item(item_type, item)
```

اجعل الوصول إلى القواميس الخاصة بالمزوّد عبر محوّل تطبيق واحد، ثم احفظ النتيجة المكتملة لإعادة بنائها لاحقًا.
