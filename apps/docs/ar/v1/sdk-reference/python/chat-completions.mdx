**الطريقة**: `client.generate_text()` (يمكنك بث الأجزاء المُحللة باستخدام `client.stream_chat()`).

### مثال
```python
chat = client.generate_text({
    "model": "openai/gpt-4o-mini",
    "messages": [
        {"role": "system", "content": "You are helpful."},
        {"role": "user", "content": "Write a limerick about lighthouses."},
    ],
    "temperature": 0.5,
})
```

### البث
```python
for chunk in client.stream_chat({
    "model": "openai/gpt-4o-mini",
    "messages": [{"role": "user", "content": "Stream a story"}],
}):
    if chunk.get("text"):
        print(chunk["text"], end="", flush=True)
```

### المعلمات الأساسية
- `model` (مطلوب): معرّف النموذج المستهدف.
- `messages` (مطلوب): رسائل مرتبة بأدوار `system|user|assistant|tool`؛ ويمكن أن يكون المحتوى نصًا أو أجزاءً.
- أخذ العينات: `temperature` (0–2) و`top_p` (0–1) و`top_k` (>=1) و`seed` (عدد صحيح اختياري).
- الطول والعقوبات: `max_output_tokens` (عدد صحيح)، و`presence_penalty` و`frequency_penalty` (من -2 إلى 2)، و`stop` (string|string[]).
- الأدوات: `tools` (تعريفات)، و`tool_choice` (auto/none/أداة محددة)، و`max_tool_calls` (عدد صحيح)، و`parallel_tool_calls` (قيمة منطقية).
- Logprobs: `logprobs` (قيمة منطقية)، و`top_logprobs` (0–20).
- الإخراج: `response_format` (json/text)، و`metadata` (كائن يُمرر كما هو)، و`stream` (قيمة منطقية)، و`service_tier`.
- إضافات البوابة: `usage` (قيمة منطقية لطلب الاستخدام)، و`meta` (قيمة منطقية لتضمين كتلة meta).
