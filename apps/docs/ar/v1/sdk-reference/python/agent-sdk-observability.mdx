تحتفظ النتيجة الفاشلة بالخطوة النشطة وعدد المحاولات ومعرّف الطلب ومعرّف الاستجابة الأصلي وبيانات المزوّد الوصفية وتفاصيل البوابة المتاحة.

تحقق من أن:

- يمكن للعملية الوصول إلى `PHASEO_API_KEY`
- معرّفات الأدوات فريدة
- تستخدم قرارات الموافقة معرّفات الاستدعاء الدقيقة
- تُحفظ الحالة المتوقفة مؤقتًا قبل متابعة طلب آخر
- لا تُحدث أدوات التحقق آثارًا جانبية
- يصل الإلغاء إلى أعمال الشبكة أو التخزين داخل الأدوات

استخدم أحداث دورة الحياة لقياس التطبيق، وDevTools لفحص عمليات التشغيل محليًا.
