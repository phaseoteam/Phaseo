يمكن أن تكون قيم النموذج والنماذج الاحتياطية والتعليمات ودرجة الحرارة والحد الأقصى لرموز الإخراج وtop-p والأدوات ثابتة أو عمليات رد نداء تُقيّم في كل خطوة.

استخدم `runtime.set_context(value)` عندما تكتشف أداة معلومات ستحتاج إليها لاحقًا. واستخدم `next_turn_params` لتجاوز يُطبّق على طلب النموذج التالي مباشرةً فقط.

تُحفظ تجاوزات الخطوة التالية مع الحالة المتوقفة مؤقتًا، لذا لا تؤدي نقطة الموافقة إلى إسقاط قرار التوجيه أو أخذ العينات.

اجعل السياق قابلًا للتسلسل عند استخدام `AgentStateAccessor`.
