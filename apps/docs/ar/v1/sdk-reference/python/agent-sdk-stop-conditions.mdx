اجمع أدوات الإيقاف المساعدة عبر `stop_when`:

```python
stop_when = [
    step_count_is(12),
    max_tokens_used(40_000),
    max_cost(2),
    max_duration(60_000),
]
```

تشمل الأدوات الإضافية `has_tool_call(...)` و`finish_reason_is(...)`. احتفظ بحد للخطوات أو المدة حتى عند تحديد التكلفة أو عدد الرموز، لأن هذه الحدود تعتمد على الاستخدام المُبلّغ عنه.
