استخدم التحقق من المخرجات النهائية إذا كان رمز Python اللاحق يتوقع بيانات منظّمة. وينبغي أن تكون عمليات رد نداء التحقق حتمية وأن ترفع خطأ عندما لا تستوفي القيمة النهائية عقد التطبيق.

اضبط عددًا محدودًا من المحاولات باستخدام `AgentModelRetryConfig`:

```python
retry = AgentModelRetryConfig(max_retries=2, backoff_ms=250)
```

تحتفظ الخطوة المكتملة بالعدد النهائي لمحاولات النموذج. وتتبع أخطاء الأدوات سياسة خاصة بها ولا يُعاد تنفيذها كطلبات للنموذج.

يقبل عميل البوابة المخرجات المنظّمة وخيارات التوجيه والمزوّد والاستدلال والأدوات المُدارة والإضافات وذاكرة المطالبات المؤقتة وخيارات الطلب الإضافية.
