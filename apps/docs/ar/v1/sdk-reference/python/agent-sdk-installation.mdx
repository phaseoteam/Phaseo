تُنشر Agent SDK على PyPI باسم [`phaseo-agent-sdk`](https://pypi.org/project/phaseo-agent-sdk/).

## المتطلبات

- Python 3.10 أو أحدث
- مفتاح API من Phaseo

## التثبيت

ثبّت Agent SDK باستخدام مدير حزم Python الذي تفضّله:

<CodeGroup>

    ```bash title="pip"
    pip install phaseo-agent-sdk
    ```

    ```bash title="uv"
    uv add phaseo-agent-sdk
    ```

</CodeGroup>

يُثبّت عميل `phaseo` الأساسي تلقائيًا كاعتمادية.

## البيئة

اضبط مفتاح API للبوابة قبل تشغيل الأمثلة:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
