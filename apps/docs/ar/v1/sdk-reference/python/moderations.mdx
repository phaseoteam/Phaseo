description: "استدعِ `/moderations` باستخدام SDK Python."
---

**الطريقة**: `client.generate_moderation()`.

### مثال
```python
moderation = client.generate_moderation({
    "model": "openai/omni-moderation-latest",
    "input": "Text to classify",
})
```

### المعلمات الأساسية
- `model` (مطلوب): معرّف نموذج الإشراف (مثل `openai/omni-moderation-latest`).
- `input` (مطلوب): سلسلة أو مصفوفة من عناصر المحتوى (نص أو `image_url`).
- اختياري: مرشحات `categories`/`severity` (عند دعمها) ووسم `user`.

### القيمة المعادة
`ModerationResponse`
