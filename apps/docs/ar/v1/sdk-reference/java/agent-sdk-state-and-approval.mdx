أعِد `HumanReviewRequest` من `AgentDefinition.humanReview` لنقطة تحقق عامة. وتُدرج موافقات الأدوات والعمل اليدوي معرّفات الاستدعاء الدقيقة في النتيجة المتوقفة مؤقتًا.

تابع عبر `Agent.continueRun(...)` مع توفير:

- إدخالات `ToolDecision` للموافقة أو الرفض
- إدخالات `ToolOutput` للأدوات اليدوية
- إدخال بشري لإيقاف المراجعة العامة مؤقتًا
- قيمة `RunResult` متسلسلة أو معرّف تشغيل مدعوم بـ`StateAccessor`

لا يعتمد SDK على حالة Agent SDK المستضافة. نفّذ `StateAccessor` إذا كان ينبغي أن تستمر عملية التشغيل عبر الطلبات أو إعادة تشغيل الخدمة.
