يتضمن المصدر الحالي عناصر للتحكم في إعادة المحاولة وبيانات وصفية للاستجابة غير موجودة في حزمة 3.0.0 القديمة على Maven Central. ابنِ المراجعة المحددة أدناه لاستخدام SDK الحالي.

## المتطلبات

- Java 17+
- Maven 3.8+
- Git

## البناء من المصدر

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
git checkout 1ff1119f41ceb3ac2c85ed605f6e1c4beca6e011
mvn -f packages/sdk/sdk-java/pom.xml -DskipTests install
```

يثبّت Maven الحزمة `app.phaseo:phaseo-sdk:3.0.0` في المستودع المحلي مع اعتماد Jackson.

## إضافة الاعتماد

```xml
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-sdk</artifactId>
  <version>3.0.0</version>
</dependency>
```

<Note>توفّر [حزمة Maven Central](https://repo.maven.apache.org/maven2/app/phaseo/phaseo-sdk/3.0.0/) واجهة API القديمة، ولا تشمل واجهات إعادة المحاولة أو البيانات الوصفية أو فحص المعلمات الحالية.</Note>
