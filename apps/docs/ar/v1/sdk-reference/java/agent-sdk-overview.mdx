<Note type="warning">
  لا يزال Java Client SDK وAgent SDK قيد التطوير، وهما غير متاحين بعد عبر Maven Central.
</Note>

Java Agent SDK بيئة تشغيل متاحة بصيغة المصدر فقط ومبنية فوق Java Client SDK. وهي توفّر العقد الأساسي نفسه الذي يوفّره TypeScript Agent SDK:

- حلقات أدوات متعددة الخطوات ضمن حدود
- أدوات متزامنة مع مهلة لكل أداة
- إعادة محاولات النموذج مع تأخير تصاعدي
- إيقافات للمراجعة البشرية وسجلات تشغيل قابلة للاستئناف
- أحداث دورة الحياة وتسجيل JSONL عبر Phaseo DevTools
- محوّل بوابة يستند إلى Java Client SDK

تبقى عمليات التشغيل داخل تطبيقك. تتولى Phaseo طلبات النموذج، بينما تدير خدمتك الحفظ وقوائم الانتظار والتفويض وواجهة المراجعة.
