ميّز بين إخفاقات النقل والبوابة وبين بيانات الأدوات أو المخرجات غير الصالحة. تحتفظ العملية الفاشلة بحالتها وخطوتها النشطة وعدد المحاولات ومعرّف الطلب ومعرّف الاستجابة الأصلي وتفاصيل البوابة المتاحة.

## فحوص شائعة

- تحقق من أن عملية Java يمكنها الوصول إلى `PHASEO_API_KEY`.
- امنح كل أداة معرّفًا فريدًا وثابتًا.
- قدّم الموافقات والرفض والمخرجات اليدوية باستخدام معرّفات استدعاء الأدوات الدقيقة.
- احفظ `RunResult` المتوقفة مؤقتًا قبل إعادة التحكم إلى طلب آخر أو عامل.
- اجعل أدوات التحقق حتمية وخالية من الآثار الجانبية.
- تعامل مع استثناءات الإلغاء وانتهاء المهلة على أنها نهائية ما لم يبدأ التطبيق تشغيلًا جديدًا صراحةً.

استخدم خطافات دورة الحياة لقياس التطبيق وDevTools لتسجيل العمليات محليًا، بدلًا من الاعتماد على مخرجات وحدة التحكم وحدها.
