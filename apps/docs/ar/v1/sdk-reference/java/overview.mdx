أرسل طلبات النص والتضمينات واستكشاف النماذج باستخدام حزمة Java SDK.

<Note>يتضمن المصدر الحالي عناصر للتحكم في إعادة المحاولة وبيانات وصفية للاستجابة غير موجودة في حزمة 3.0.0 القديمة على Maven Central. ابنِ المراجعة المحددة أدناه لاستخدام SDK الحالي. [التثبيت](./installation)</Note>

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

## الطلبات المدعومة

استخدم `createResponse` و`createChatCompletion` و`createEmbedding` و`listModels` لطلبات JSON. مرّر `Map` أو `JsonNode`؛ حلّل سلاسل JSON قبل تمريرها إلى طرق العميل.

## البث

تعيد `streamResponse` و`rawClient().requestLines` أسطر SSE فور وصولها. أغلق البث باستخدام try-with-resources، وعالج أسماء الأحداث وأسطر البيانات وعلامات الاكتمال في تطبيقك.

<Note>تتوقع طريقة `createSpeech` بيانات JSON ولا تفك ترميز الصوت الثنائي. استخدم `rawClient().requestBytes` للحصول على الصوت.</Note>
