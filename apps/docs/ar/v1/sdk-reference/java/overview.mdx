<Note type="warning">
  ما تزال حزمة Java قيد التطوير ولم تُنشر بعد على Maven Central. استخدم البناء من المصدر للتقييم فقط.
</Note>

تتضمن حزمة Java الآن غلافًا خفيفًا مكتوبًا يدويًا فوق العميل المُولّد:

- يوفّر `app.phaseo.sdk.Phaseo` مساعدات للدردشة والاستجابات ورسائل Anthropic والصور والتضمينات والإشراف على المحتوى والصوت/التفريغ/الترجمة والدفعات والملفات والفيديو والنماذج/المزوّدين/نقاط النهاية/المؤسسات/الأسعار، واكتشاف مفاتيح API وإدارة دورة حياتها، وإدارة مساحة العمل والمفتاح الحالي، وحساب الأسعار والنشاط/الأرصدة/التحليلات والبحث عن عمليات التوليد والتحقق من دورة الحياة، وروابط WebSocket للمهام غير المتزامنة عبر المساعدات المباشرة أو `client.asyncJobs.websocketUrl(...)`، وقياسًا يدعم أدوات التطوير.
- يظل `app.phaseo.gen.Client` و`app.phaseo.gen.Operations` متاحين في الطبقة الأدنى لتغطية جميع العمليات عند الحاجة.

## الحالة الحالية

- قيد التطوير؛ لم يُنشر بعد على Maven Central.
- يوجد المصدر في `packages/sdk/sdk-java`.
- يوجد الكود المُولّد منخفض المستوى في `packages/sdk/sdk-java/src/gen`.
- يوجد الغلاف المكتوب يدويًا في `packages/sdk/sdk-java/src/app/phaseo/sdk`.
