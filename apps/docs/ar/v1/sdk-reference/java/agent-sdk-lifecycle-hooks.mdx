مرّر مستهلك أحداث في `RunOptions` لربط الوكيل بخط زمني للمنتج أو سجل تدقيق أو مسار قياس عن بُعد:

```java
event -> logger.info("{} {}", event.type(), event.runId())
```

تشمل فئات الأحداث:

- بدء التشغيل واستئنافه وانتظار تدخل بشري وإكماله وإلغاؤه وفشله
- بدء الخطوة ونقطة التحقق وإكمالها وإلغاؤها وفشلها
- طلب النموذج وإكماله وفشله
- بدء الأداة وتقدمها الأولي وإكمالها وفشلها

أبقِ دالة رد النداء سريعة. ضع عمليات التخزين أو الشبكة البطيئة في قائمة انتظار خارج حلقة التشغيل.
