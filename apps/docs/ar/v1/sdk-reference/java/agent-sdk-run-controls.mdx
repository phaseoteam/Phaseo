---

استخدم التحقق من المخرجات النهائية عندما يتوقع كود Java اللاحق قيمة منظّمة بدلًا من نص نموذج غير متحقق منه. أضف مدقّقًا نهائيًا إلى تعريف الوكيل وتعامل مع إخفاقات التحقق كأخطاء في العقد.

استخدم `ModelRetryConfig` عند حدوث إخفاقات مؤقتة في النموذج أو المزوّد:

```java
var retry = new AgentSdk.ModelRetryConfig(
    2,
    Duration.ofMillis(250)
);
```

يسجّل عدد المحاولات الإضافية بعد الطلب الأول. وتحتفظ الخطوات المكتملة بالعدد النهائي لمحاولات النموذج لأغراض تصحيح الأخطاء وقياس الأداء.

استخدم `ToolExecutionConfig` بشكل منفصل للتحكم في تزامن الأدوات المحلية. ولا تعيد محاولات النموذج الآثار الجانبية الفاشلة داخل الأدوات.

يمكن تمرير خيارات إضافية لـ Responses API عبر `GatewayOptions.requestOptions`؛ ويظل المحوّل مسؤولًا عن النموذج والإدخال والتعليمات وأدوات الدوال المحلية.
