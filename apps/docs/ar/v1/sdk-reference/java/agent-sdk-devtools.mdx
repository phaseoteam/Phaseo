---

فعّل التسجيل المحلي للتشغيل باستخدام `AgentSdk.createAgentDevtools(...)`:

```java
var devtools = AgentSdk.createAgentDevtools(".phaseo-devtools");
```

مرّر هذه القيمة عبر `RunOptions`. وتتضمن سجلات JSONL الملتقطة حالة التشغيل ومدته وتفاصيل النموذج والمزوّد ومعرّفات الطلبات والرسائل والخطوات ونشاط الأدوات والاستخدام والتكلفة والأخطاء المنظّمة.

<Warning>
قد تحتوي مدخلات الوكيل ورسائله وسياقه ونتائج أدواته على بيانات حساسة. استثنِ مجلد DevTools من التحكم بالمصادر وصور الإنتاج.
</Warning>
