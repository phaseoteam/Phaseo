يدعم `AgentSdk.Tool`:

- `parameters` بصيغة JSON تُعرض على النموذج
- دوال `Validator` للتحقق من المدخلات والمخرجات وأحداث التقدم
- مهلات `Duration` لكل أداة
- موافقة مشروطة أو غير مشروطة
- أدوات يكتمل تنفيذها يدويًا بواسطة تطبيقك
- تحديثات تقدم أولية عبر `RuntimeContext.emitProgress()`
- معالجة أخطاء باستخدام `fail-run` أو `return-to-model`
- تجاوزات للخطوة التالية بعد نجاح تنفيذ الأداة

مرّر سجلات الأدوات عبر `AgentSdk.defineTool(...)`، واشترط موافقة صريحة على الآثار الجانبية أو تنفيذًا يدويًا يديره التطبيق.
