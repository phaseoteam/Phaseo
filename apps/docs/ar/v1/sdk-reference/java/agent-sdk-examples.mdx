ابدأ بأحد هذه الأنماط:

| النمط | المكوّنات |
| --- | --- |
| فرز طلبات الدعم | إعداد مُدار وأدوات بحث ومخرجات نهائية منظّمة |
| مراجعة التعليمات البرمجية | أدوات الملفات أو التصحيحات وأحداث التقدم والموافقة قبل التعديل |
| موجز بحث | أدوات ويب مُدارة وحدود للتكلفة والخطوات ونص متدفق |
| دليل التشغيل | أدوات الحالة والتصعيد اليدوي والاستكمال الدائم |

اجعل التنفيذ الأول محدود النطاق: وكيل واحد وأداة أو أداتان محددتا السلوك وموافقة صريحة على الآثار الجانبية.
