استخدم `RunResult` بوصفها النتيجة الدائمة لوكيل Java. وهي تتضمن سجل التشغيل والرسائل المحفوظة وسجلات الخطوات والاستخدام والتكلفة الموحدين والتحذيرات وأسباب الإنهاء والمخرجات النهائية.

يتضمن `StreamResult.fullStream()` أحداث عناصر المزوّد إلى جانب أحداث النموذج والأداة والخطوة والتشغيل. ويعرض Java حاليًا عناصر المزوّد ككائنات عامة، وليست الاتحاد المميّز `AgentItem` في TypeScript.

لإنشاء جدول زمني للمنتج:

1. اعرض نص `textStream()` أثناء تشغيل الوكيل.
2. اعرض بطاقات الأدوات من أحداث دورة حياة الأدوات.
3. احفظ `RunResult` المكتملة.
4. أعد بناء الجدول الزمني النهائي من الرسائل والخطوات المحفوظة.

ضع بيانات العناصر الخاصة بالمزوّد خلف محوّل تطبيق كي لا يؤثر تغيير تنسيق المزوّد على بقية الواجهة.
