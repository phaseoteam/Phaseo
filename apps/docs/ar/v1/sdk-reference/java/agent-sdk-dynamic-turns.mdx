استخدم عمليات رد النداء الديناميكية عندما ينبغي للخطوات اللاحقة الاستجابة لسياق التطبيق أو نتائج الأدوات السابقة أو عدد الخطوات المكتملة.

يمكن للقيم الديناميكية اختيار:

- النموذج أو النماذج الاحتياطية
- التعليمات
- درجة الحرارة وtop-p والحد الأقصى لرموز الإخراج
- قائمة الأدوات لطلب النموذج التالي

يمكن للأدوات تحديث سياق التطبيق عبر `RuntimeContext` وإرجاع `NextTurnParams` للطلب التالي مباشرةً. وتُحفظ تجاوزات الخطوة التالية مع الحالة المتوقفة مؤقتًا، لذا لا تؤدي الموافقة إلى إسقاط قرار التوجيه أو أخذ العينات الخاص بالأداة.

اجعل السياق وقيم الخطوة التالية قابلة للتسلسل إذا كان من الممكن إعادة تحميل التشغيل عبر `StateAccessor`.
