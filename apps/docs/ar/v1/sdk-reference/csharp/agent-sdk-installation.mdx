تُنشر حزمة Agent SDK على NuGet باسم [`Phaseo.AgentSdk`](https://www.nuget.org/packages/Phaseo.AgentSdk).

## المتطلبات

- .NET 8 أو أحدث
- مفتاح API من Phaseo

## التثبيت

```bash
dotnet add package Phaseo.AgentSdk
```

يُثبّت الحزمة الأساسية `Phaseo.Sdk` تلقائيًا كاعتماد.

## البيئة

اضبط مفتاح API للبوابة قبل تشغيل الأمثلة:

```bash
set PHASEO_API_KEY=phaseo_v1_sk_...
```
