تحتفظ `RunResult` الفاشلة بالخطوة النشطة وعدد المحاولات ومعرّف الطلب ومعرّف الاستجابة الأصلي وبيانات المزوّد الوصفية وتفاصيل البوابة المتاحة.

تحقق أولًا مما يلي:

- يمكن للعملية الوصول إلى `PHASEO_API_KEY`
- معرّفات الأدوات فريدة وثابتة
- تستخدم قرارات الموافقة معرّفات استدعاء الأدوات الدقيقة
- تُحفظ الحالة المتوقفة مؤقتًا قبل انتهاء الطلب
- لا تُحدث أدوات التحقق آثارًا جانبية
- تصل رموز الإلغاء إلى التبعيات المستخدمة داخل الأدوات

استخدم خطافات دورة الحياة لقياس التطبيق، وDevTools لفحص عمليات التشغيل محليًا.
