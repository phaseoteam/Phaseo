تحقّق من المخرجات النهائية عندما تتوقع شيفرة .NET اللاحقة قيمة منظّمة. تعامل مع فشل التحقق بوصفه خطأ عقد، لا إخفاق نقل مؤقتًا.

هيّئ محاولات إعادة محدودة باستخدام `ModelRetryConfig`:

```csharp
ModelRetry = new ModelRetryConfig
{
    MaxRetries = 2,
    Backoff = TimeSpan.FromMilliseconds(250),
}
```

تحتفظ الخطوة المكتملة بعدد محاولات النموذج النهائي. وتُعالج إخفاقات الأدوات المحلية على نحو منفصل ولا يعاد تشغيلها كطلبات نموذج.

تتضمن `GatewayAgentClientOptions` خيارات الاستجابة المنظّمة والتوجيه والمزوّد والاستدلال واختيار الأدوات وتخزين المطالبات مؤقتًا وخيارات الطلب الإضافية.
