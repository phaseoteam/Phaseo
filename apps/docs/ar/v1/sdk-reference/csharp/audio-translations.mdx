**الطريقة**: `client.CreateTranslation(...)`

### مثال
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.CreateTranslation(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-4o-transcribe",
    ["audio_b64"] = "base64-audio"
});
```

### المعلمات الأساسية
- `model` (مطلوب): معرّف نموذج يدعم الترجمة.
- `file` (مطلوب): بيانات الصوت المطلوب ترجمتها.
- `prompt`: سياق اختياري لتوجيه الترجمة.
- `temperature` (0–2): عشوائية أخذ العينات.
- `response_format`: ‏`json` و`text` و`srt` و`verbose_json` وغيرها.

### القيمة المعادة
`AudioTranscriptionResponse`
