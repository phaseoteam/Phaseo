يوفّر C# Agent SDK بيئة تشغيل محلية كاملة لوكلاء Phaseo Gateway، بما يشمل إعادة المحاولات والمهام المتزامنة والإلغاء والمهل والمراجعة البشرية والحالة القابلة للاستئناف وأحداث دورة الحياة وتسجيل DevTools.

استخدمه عندما تحتاج إلى:

- حلقة أدوات خفيفة ومحدودة
- طلبات `responses` المدعومة بالبوابة
- تحكم التطبيق في الحفظ والتنسيق

## ما يوفّره

- `AgentSdk.CreateAgent(...)`
- `AgentSdk.DefineTool(...)`
- `AgentSdk.CreateGatewayAgentClient(...)`
- حلقة أدوات محدودة فوق واجهة `responses` في Phaseo
