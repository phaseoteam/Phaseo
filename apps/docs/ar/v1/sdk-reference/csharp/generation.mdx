**الطريقة**: `client.GetGeneration(...)`

### مثال

```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.GetGeneration("G-01ABC...");
```

### المعلمات

- `id` (string، مطلوب): معرّف الطلب الذي أعاده استدعاء سابق.

### القيمة المعادة

سجل التوليد (JSON)

إذا خزّنت البوابة تفاصيل الطلب كاملة، فسيتضمن السجل المُعاد `replay_supported` و`replay_request`. أرسل `replay_request` إلى نقطة النهاية الأصلية لإعادة تشغيل مضبوطة.

تتبع حقول التوقيت دلالات موحدة في جميع أنحاء البوابة:

- `latency_ms`: الوقت حتى أول رمز أو أول بايت/إطار إخراج عند تتبعه
- `generation_ms`: وقت التوليد بعد زمن الاستجابة عند تتبعه
