**الطريقة**: `client.CreateTranscription(...)`

### مثال
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.CreateTranscription(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-4o-transcribe",
    ["audio_b64"] = "base64-audio",
    ["language"] = "en"
});
```

### المعلمات الأساسية
- `model` (مطلوب): معرّف نموذج يدعم النسخ الصوتي.
- `file` (مطلوب): بيانات الصوت (تدفق أو ملف).
- `language`: رمز اللغة كإشارة (مثل `en`).
- `prompt`: سياق اختياري لتحسين الدقة.
- `temperature` (0–2): عشوائية أخذ العينات.
- `response_format`: ‏`json` و`text` و`srt` و`verbose_json` وغيرها.

### القيمة المعادة
`AudioTranscriptionResponse`
