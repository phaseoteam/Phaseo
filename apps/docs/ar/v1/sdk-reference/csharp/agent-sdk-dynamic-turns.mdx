استخدم `DynamicModel` و`DynamicInstructions` و`Temperature` و`MaxOutputTokens` و`TopP` و`DynamicTools` عندما ينبغي للخطوات اللاحقة الاستجابة للسياق أو لنتائج الأدوات السابقة.

يمكن للأدوات تحديث سياق التطبيق عبر `RuntimeContext.SetContext` وتوفير `NextTurnParams` للطلب التالي مباشرةً. وتظل هذه التجاوزات محفوظة مع حالة التشغيل المتوقفة مؤقتًا عند الاستكمال بعد الموافقة.

اجعل سياق التطبيق قابلًا للتسلسل إذا كان من الممكن حفظ حالة التشغيل عبر `IStateAccessor`.
