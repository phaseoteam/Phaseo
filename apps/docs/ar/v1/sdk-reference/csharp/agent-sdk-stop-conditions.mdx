ركّب دوال الإيقاف المساعدة داخل `AgentDefinition.StopWhen`:

```csharp
StopWhen = new[]
{
    AgentSdk.StepCountIs(12),
    AgentSdk.MaxTokensUsed(40_000),
    AgentSdk.MaxCost(2),
    AgentSdk.MaxDuration(TimeSpan.FromMinutes(1)),
};
```

`HasToolCall(...)` و`FinishReasonIs(...)` provide event-based limits. احتفظ بحد للخطوات أو المدة حتى عند تحديد عدد الرموز أو التكلفة، لأنهما يعتمدان على الاستخدام المُبلّغ عنه.
