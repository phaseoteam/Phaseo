Pass `RunOptions.OnEvent` لتحديث المخطط الزمني للمنتج أو سجل التدقيق أو مسار القياس عن بُعد.

تشمل أنواع الأحداث بدء التشغيل واستئنافه وحالاته النهائية وطلبات النماذج ونقاط حفظ الخطوات وتنفيذ الأدوات وتقدمها وانتظار التدخل البشري والإلغاء والإخفاقات.

اجعل دالة الاستدعاء سريعة. ضع أعمال التخزين أو الشبكة البطيئة في قائمة انتظار خارج حلقة الوكيل.

```csharp
OnEvent = value => logger.LogInformation(
    "{EventType} {RunId}", value.Type, value.RunId
);
```
