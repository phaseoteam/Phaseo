---

فعّل تسجيل JSONL محليًا باستخدام `AgentSdk.CreateAgentDevtools(...)` وتمريره إلى `RunOptions`.

تتضمن السجلات الحالة والمدة وتفاصيل النموذج والمزوّد ومعرّفات الطلبات والرسائل والخطوات ونشاط الأدوات والاستخدام والتكلفة والأخطاء المنظّمة.

<Warning>
قد تحتوي مدخلات الوكيل والسياق ونتائج الأدوات على بيانات حساسة. لا تضع مخرجات DevTools في التحكم بالمصدر أو صور الإنتاج.
</Warning>
