تمثل `RunResult` النتيجة الدائمة للوكيل. وهي تتضمن سجل التشغيل والرسائل والخطوات والاستخدام والتكلفة والتحذيرات وأسباب الإنهاء والمخرجات النهائية.

استخدم `TextStream()` لنص الإجابة المباشر و`FullStream()` لأحداث النموذج والأدوات والخطوات والتشغيل وعناصر المزوّد. يعرض C# حاليًا عناصر المزوّد ككائنات عامة بدلًا من الاتحاد المميّز `AgentItem` في TypeScript.

أنشئ جداول زمنية للمنتج من أحداث دورة الحياة أثناء تشغيل الوكيل، ثم أعد بناء الحالة النهائية من الرسائل والخطوات المحفوظة.
