استدعِ نماذج من مزوّدين كثيرين عبر API واحدة على `https://api.phaseo.app/v1`، واختر كيفية توجيه كل طلب، وتتبّع الاستخدام والتكلفة لكل طلب. يستخدم هذا الطلب `phaseo/free`، لذا يعمل قبل أن تضيف رصيدًا:

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "phaseo/free", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // reads PHASEO_API_KEY

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # reads PHASEO_API_KEY

response = client.responses.create({"model": "phaseo/free", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

ليس لديك مفتاح API بعد؟ نفّذ `phaseo keys create` باستخدام [Phaseo CLI](./guides/integrations/phaseo-cli) أو [أنشئ مفتاحًا من لوحة التحكم](https://phaseo.app/settings/keys)، ثم اتبع [دليل البدء السريع](./quickstart.mdx).

## اختر نموذجًا

[تصفّح النماذج](https://phaseo.app/models) أو [قارنها](https://phaseo.app/compare). يعرض الكتالوج أيضًا نماذج لا يمكنك استدعاؤها بعد، لذا تحقّق من أن النموذج **نشط على Gateway** قبل دمجه، أو اعرض النماذج القابلة للاستدعاء باستخدام `GET /v1/models`. راجع [كيف يعمل Phaseo](./developers/introduction.mdx) لمعرفة المزيد عن النماذج والمزوّدين والفوترة.
