استخدم هذه الصفحة إذا كنت تعرف ما تريد بناءه، لكنك لا تعرف أي صفحة من وثائق Phaseo ينبغي أن تفتح أولاً.

توفّر Phaseo واجهة API واحدة للوصول إلى النماذج، وتوجيه الطلبات إلى المزوّدين، ومعرفة الأسعار، وتتبع الاستخدام، وتشغيل سير عمل الذكاء الاصطناعي غير المتزامن.

إذا كنت جديداً على Phaseo، فابدأ بإرسال طلب يعمل بنجاح. وإذا كان لديك تكامل ذكاء اصطناعي بالفعل، فانتقل مباشرةً إلى دليل الترحيل أو SDK المناسب لتطبيقك.

## إرسال طلبك الأول بنجاح

لإنشاء تكامل جديد، اتبع الخطوات التالية:

1. أنشئ مفتاح API في لوحة التحكم.
2. أرسل طلباً إلى نموذج نصي متاح حالياً.
3. اقرأ النص المُنشأ من الاستجابة.
4. تابع إلى دليل SDK أو التوجيه أو الإنتاج المناسب لخطوتك التالية.

## الطلب الأول

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-sol",
    "input": "Reply with: docs ready",
    "temperature": 0
  }'
```

```typescript TypeScript SDK
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-5.6-sol",
  input: "Reply with: docs ready",
  temperature: 0,
});

console.log(response.output_text);
```

```python Python SDK
from phaseo import Phaseo

client = Phaseo(api_key="YOUR_API_KEY")

response = client.generate_response(
    {
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with: docs ready",
        "temperature": 0,
    }
)

print(response.get("output_text"))
```
</CodeGroup>

إذا نجح الطلب، فتابع إلى [دليل البدء السريع](./quickstart.mdx) لإكمال خطوات الطلب الأول.
