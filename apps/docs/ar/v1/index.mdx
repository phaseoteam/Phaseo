استخدم Phaseo لاستدعاء نماذج من مزوّدين متعددين عبر API واحدة والتحكم في التوجيه وتتبع الاستخدام والتكاليف.

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "phaseo/free", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // reads PHASEO_API_KEY

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # reads PHASEO_API_KEY

response = client.responses.create({"model": "phaseo/free", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

ليس لديك مفتاح API بعد؟ [أنشئ مفتاحًا من لوحة التحكم](https://phaseo.app/ar-SA/settings/keys)، ثم اتبع [دليل البدء السريع](./quickstart.mdx).
