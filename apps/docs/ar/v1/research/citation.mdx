تجمع Phaseo معلومات عامة ونتائج معايير أداء من مزوّدي النماذج ومشروعات التقييم.
إذا استخدمت Phaseo للبحث عن النماذج أو مقارنتها أو مراقبتها، فإن إشارة بسيطة تساعد الآخرين على اكتشاف المنصة.

---

## صيغة مختصرة

إذا أفادتك Phaseo، فأضف رابطًا إليها في موضع مناسب (المنهجية أو حاشية أو الشكر):

> يستخدم هذا العمل بيانات وصفية للنماذج ونتائج معايير أداء مجمّعة من [Phaseo](https://phaseo.app).

## بيانات معايير الأداء

**لا تُجري Phaseo معايير الأداء بنفسها**. بل نعرض النتائج التي ينشرها مؤلفو المعايير ومزوّدو النماذج ونوحّد تنسيقها.

عند استخدام نتائج معايير الأداء التي حصلت عليها عبر Phaseo:

1. استشهد بالمعيار والورقة البحثية الأصلية كمصدر أساسي.
2. يمكنك الإشارة اختياريًا إلى Phaseo بوصفها المكان الذي استرجعت النتائج أو قارنتها فيه.
3. أدرج ما يلي:

- اسم المعيار والتقسيم (مثل `MMLU test`).
- معرّف النموذج والمزوّد.
- عنوان URL لصفحة Phaseo أو واجهة API ذات الصلة.
- تاريخ الاطلاع.

مثال للنص:

> استُرجعت نتائج المعيار عبر Phaseo (تقسيم MMLU test)، واطّلعنا عليها في 3 مارس 2025. النموذج: `openai-gpt-4o`؛ المزوّد: OpenAI.

## Gateway والأدوات

عند وصف عمليات التكامل، يمكنك ذكر Phaseo بوصفها طبقة Gateway لا مصدرًا لمعايير الأبحاث:

> استخدمنا Phaseo Gateway لتوحيد الوصول إلى نماذج OpenAI وAnthropic وGoogle عبر واجهة API واحدة.

أدرج رابطًا مباشرًا إلى [مرجع API](../api-reference/introduction.mdx) ليتمكن القراء من استكشاف المزيد.
