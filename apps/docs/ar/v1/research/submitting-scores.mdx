أرسل نتائج معايير الأداء عبر مشكلة (issue) على GitHub. يتحقق المشرفون من الأدلة وينشرون النتائج المعتمدة عبر محرر قاعدة البيانات.

## جهّز أدلتك

أرفق:

- معرّف النموذج والمزوّد، وصفحة Phaseo إن وُجدت.
- اسم المعيار وإصداره وتقسيمه والنتيجة ووحداتها.
- تاريخ التقييم وتنسيق الموجّه وأداة التقييم وإعدادات العتاد أو أخذ العينات ذات الصلة.
- ورقة بحثية منشورة أو صفحة نتائج أو مجموعة بيانات أو سجل تقييم قابل لإعادة الإنتاج.
- ما إذا كانت النتيجة معلنة من المزوّد أو مقيسة بشكل مستقل.

## أرسل المشكلة

[اطلب بيانات معيار جديدة](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) لنتيجة أو معيار جديد. [أبلغ عن معلومات غير صحيحة](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) لتصحيح نتيجة موجودة، مع ذكر قيمتها الحالية والقيمة المقترحة.

لا تضمّن بيانات اعتماد أو موجّهات خاصة أو بيانات عملاء في التقارير العامة.

## تابع النشر

قد يطلب المشرفون توضيحًا في المشكلة قبل تحديث قاعدة البيانات. لا تُنشر النتائج إلا عبر قاعدة البيانات؛ ولا يحتوي المستودع على ملفات JSON لمعايير الأداء يمكن تعديلها.

للمساعدة في إعداد مشاركتك، استخدم [Discord المجتمع](https://discord.gg/aQyywCvgZ5).
