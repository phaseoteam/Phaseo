نرحب بمساهمات المزوّدين والباحثين والمستخدمين المتقدمين. اتبع الخطوات التالية لتسريع معالجة مشاركتك.

---

## 1. إعداد البيانات

- تحقق من وجود المعيار في `/data/benchmarks`. إذا لم يكن موجودًا، فأنشئ issue لاقتراح إضافته.
- اجمع النتائج الخام، بما في ذلك تنسيق المطالبات وإطار التقييم وتفاصيل الأجهزة.
- أرفق مصدرًا عامًا عند توفره (منشور مدونة أو ورقة بحثية أو مستودع مجموعة البيانات).

> ✅ **نصيحة**
> تساعد مشاركة نص برمجي أو دفتر ملاحظات قابل لإعادة الإنتاج على تسريع التحقق كثيرًا.

---

## 2. إنشاء fork للمستودع

1. أنشئ fork من [github.com/phaseoteam/data](https://github.com/phaseoteam/data).
2. أنشئ فرعًا جديدًا (مثل `add-claude-3.5-sonnet-mmlu`).
3. حدّث JSON الخاص بالمعيار المعني بنتائجك والبيانات الوصفية.

---

## 3. تشغيل التحقق

استخدم أدوات المستودع للتأكد من صحة البنية والنطاقات:

```bash
pnpm install
pnpm run validate:benchmarks
```

أصلح أي مشكلات تظهر قبل إرسال pull request.

---

## 4. فتح pull request

أدرج المعلومات التالية في وصف PR:

- اسم المعيار والتقسيم (مثل `GSM8K test`).
- معرّف النموذج والمزوّد.
- روابط المصادر أو سجلات التقييم.
- ملخص لكيفية احتساب النتيجة.

سيراجع المشرفون المشاركة، ويطلبون توضيحات عند الحاجة، ثم يدمجونها بعد الموافقة.

---

## 5. متابعة النشر

بعد الدمج، ستظهر النتيجة في مزامنة البيانات المجدولة التالية. يمكنك متابعة التقدم في قناة #data-updates على Discord أو في سجل التغييرات العام.
