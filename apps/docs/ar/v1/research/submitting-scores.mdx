أرسل نتائج المعايير عبر مشكلة على GitHub. يتحقق المسؤولون من الأدلة وينشرون النتائج المعتمدة عبر محرر قاعدة البيانات.

## إعداد الأدلة

أرفق:

- معرّف النموذج والمزوّد وصفحة Phaseo إن وجدت.
- اسم المعيار وإصداره وتقسيمه ونتيجته ووحداته.
- تاريخ التقييم وتنسيق الموجّه وأداة التقييم وإعدادات العتاد أو أخذ العينات ذات الصلة.
- بحث منشور أو صفحة نتائج أو مجموعة بيانات أو سجل تقييم قابل لإعادة الإنتاج.
- ما إذا كانت النتيجة معلنة من المزوّد أو مقاسة بشكل مستقل.

## إرسال المشكلة

[اطلب بيانات معيار جديدة](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) لنتيجة أو معيار جديد. [أبلغ عن معلومات غير صحيحة](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) لتصحيح نتيجة موجودة، مع قيمتها الحالية والمقترحة.

لا تضمّن بيانات اعتماد أو موجّهات خاصة أو بيانات عملاء في التقارير العامة.

## متابعة النشر

قد يطلب المسؤولون توضيحًا في المشكلة قبل تحديث قاعدة البيانات. تعكس لقطات JSON اليومية البيانات المنشورة؛ لا يؤدي تعديل JSON المعايير المؤرشف إلى نشر نتيجة.

للمساعدة في إعداد المشاركة، استخدم [Discord المجتمع](https://discord.gg/aQyywCvgZ5).
