تتناول هذه الأدلة:

- تغييرات معلمات الطلب
- اختلافات سلوك المطالبات والاستدلال
- اختلافات المخرجات المنظّمة واستدعاء الأدوات
- استراتيجيات الطرح التدريجي والبدائل والتراجع

## كيفية استخدام هذه الأدلة

1. حدّد ما إذا كنت تغيّر المنصة أو النموذج أو كليهما.
2. ابدأ بالدليل الذي يغطي الجزء الأعلى مخاطرة في الترحيل.
3. تحقّق من معلمات الطلب وسلوك نقطة النهاية قبل مقارنة جودة المخرجات.
4. شغّل تقييمات تحاكي الإنتاج قبل تحويل حركة المرور الفعلية.
