اختر الدليل المناسب لما تغيّره: المنصة التي يستدعيها تطبيقك (أدناه)، أو النموذج الذي يستخدمه ([ترحيل النماذج](../model-migrations)). إذا كنت تغيّر الاثنين، فانقل المنصة أولًا وأبقِ النموذج كما هو حتى يتم التحقق من المسار الجديد.

للحصول على قائمة تحقق مخصصة، استخدم [مساعد الترحيل](https://phaseo.app/migrate).

<span id="platform-migrations"></span>
## ترحيل المنصات

يتبع كل دليل منصة الترتيب نفسه: بدّل عنوان URL الأساسي والمفتاح، وطابق معرّفات النماذج، وطابق ميزات المنصة، ثم اختبر وانشر مع إبقاء التراجع مجرد تغيير لعنوان URL الأساسي والمفتاح.

| ما تستدعيه | مؤشرات في الشيفرة | الدليل |
| --- | --- | --- |
| OpenAI مباشرة | `api.openai.com` و`OPENAI_API_KEY` و`AzureOpenAI` | [OpenAI SDK](./from-openai) |
| Anthropic مباشرة | `api.anthropic.com` و`ANTHROPIC_API_KEY` و`@anthropic-ai/sdk` | [Anthropic SDK](./from-anthropic) |
| OpenRouter | `openrouter.ai` و`OPENROUTER_API_KEY` ومفاتيح `sk-or-v1` | [OpenRouter](./from-openrouter) |
| Vercel AI Gateway | `ai-gateway.vercel.sh` و`@ai-sdk/gateway` ونماذج بسلاسل نصية مجردة في استدعاءات AI SDK | [Vercel AI Gateway](./from-vercel) |
| LLM Gateway | `api.llmgateway.io` و`LLM_GATEWAY_API_KEY` | [LLM Gateway](./from-llmgateway) |
| وكيل LiteLLM | `config.yaml` يحتوي على `model_list`، ومتغيرات `LITELLM_*`، والمنفذ 4000 | [LiteLLM](./from-litellm) |
| Cloudflare AI Gateway | `gateway.ai.cloudflare.com` وترويسات `cf-aig-*` | [Cloudflare AI Gateway](./from-cloudflare) |
| Helicone | `*.helicone.ai` و`Helicone-Auth` | [Helicone](./from-helicone) |

لتخطيط النشر والتحقق منه، استخدم [قائمة التحقق من ميزات الترحيل](./feature-parity-matrix).

## ترحيل النماذج

استخدم [دليل ترحيل النموذج](../model-migrations) عندما يبقى التكامل كما هو ويتغير النموذج. يغطي كل دليل تغييرات معاملات الطلب، والتحولات في سلوك المطالبات والاستدلال، واختلافات المخرجات المنظّمة واستدعاء الأدوات، وكيفية النشر مع نموذج احتياطي.

في أي من نوعي الترحيل، تحقّق من معاملات الطلب وسلوك نقطة النهاية قبل مقارنة جودة المخرجات، وشغّل تقييمات شبيهة بالإنتاج قبل نقل الحركة الفعلية.
