بدّل عنوان URL الأساسي والمفتاح، واحتفظ بحمولات الطلبات، وطابق كل معرّف نموذج: البادئة في LLM Gateway تسمّي المزوّد الذي يقدّم النموذج، بينما تسمّي البادئة في Phaseo الجهة المطوّرة للنموذج.

| الإعداد | LLM Gateway | Phaseo |
| --- | --- | --- |
| عنوان URL الأساسي | `https://api.llmgateway.io/v1` | `https://api.phaseo.app/v1` |
| العملاء بنمط Anthropic | `ANTHROPIC_BASE_URL=https://api.llmgateway.io` | `https://api.phaseo.app`، راجع [الترحيل من Anthropic SDK](./from-anthropic) |
| مفتاح API | `LLM_GATEWAY_API_KEY` (`llmgtwy_…`) | `PHASEO_API_KEY` |
| معرّفات النماذج | `gpt-4o` و`<provider>/<model>` و`auto` | `<org>/<model>` من `GET /v1/models?format=openai` |
| حمولة الطلب | متوافقة مع OpenAI | دون تغيير |

## تبديل العميل

<CodeGroup>
```typescript TypeScript
import OpenAI from "openai";

// قبل:
// new OpenAI({ apiKey: process.env.LLM_GATEWAY_API_KEY, baseURL: "https://api.llmgateway.io/v1" });
const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)
```

```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```
</CodeGroup>

طابق كل متغير `LLM_GATEWAY_*` أو أزله، بما في ذلك في إعدادات CI والاستضافة. إذا كان التطبيق يستخدم `@llmgateway/ai-sdk-provider`، فانتقل إلى `@phaseo/ai-sdk-provider` كما في [الترحيل من Vercel AI Gateway](./from-vercel).

## مطابقة معرّفات النماذج

اعرض معرّفات Phaseo وتحقّق من كل نموذج إنتاجي مقابلها:

```bash
curl -s "https://api.phaseo.app/v1/models?format=openai" \
  -H "Authorization: Bearer $PHASEO_API_KEY" | jq -r '.data[].id'
```

المعرّف `alibaba/<model>` في LLM Gateway ليس معرّفًا في Phaseo. طابق كل معرّف مع `<org>/<model>` في Phaseo، واحتفظ بتثبيت المزوّد باستخدام `provider.only` أو معرّف بصيغة `provider:org/model`. ترجم الأسماء المستعارة بلا بادئة مثل `gpt-4o` في دالة واحدة عند حدود العميل بدلًا من كل موضع استدعاء.

## مطابقة ميزات البوابة

| LLM Gateway | على Phaseo |
| --- | --- |
| موجّه `auto` | `phaseo/auto` ([التوجيه التلقائي](../guides/auto-routing)، ألفا)؛ لا يمكن دمجه مع `models`. |
| سلاسل الاحتياط | مصفوفة `models` أو المسارات الديناميكية، تُجرَّب عند `429` و`500` و`502` و`503` و`504`، ولا تُجرَّب أبدًا عند أخطاء الطلب. |
| `X-No-Fallback` | `provider.allow_fallbacks: false`، أو معرّف بصيغة `provider:org/model`. |
| منطق السماح بالمزوّدين ورفضهم | `provider.only` أو `provider.ignore` أو [الإعدادات المسبقة](../guides/presets). أبقِ مزوّدًا مؤهلًا واحدًا على الأقل. |
| ترويسات `X-LLMGateway-<Key>` | [تسميات](../guides/request-labels) `X-Phaseo-Metadata`، حتى 32. |
| ترويسات الجلسة (`x-session-id`) | حقل الجسم `session_id`؛ يتجاهل Phaseo ترويسات الجلسة. |
| `X-Source` | `HTTP-Referer` أو `X-App-Name`. راجع [إسناد التطبيق](../guides/app-attribution). |
| تخزين الاستجابات مؤقتًا | لا توجد ذاكرة تخزين مؤقت للاستجابات. |
| مفاتيح المزوّدين | BYOK (**الإعدادات → BYOK** أو `POST /v1/byok`)، أو أرصدة Phaseo. الرجوع إلى الأرصدة هو إعداد مساحة العمل `byok_fallback_enabled`. |
| سجلات الطلبات | سجلات الطلبات ووجهات المراقبة و`GET /v1/generations?id=<request_id>`. عندما تكون قيمة `replay_supported` هي `true`، أعد تشغيل طلب فاشل من حمولته `replay_request`. |

## الاختبار والنشر

شغّل مطالباتك المرجعية على البوابتين وقارن الجودة وزمن الاستجابة والتكلفة. تحقّق من نقاط النهاية أولًا:

```bash
curl -s "https://api.phaseo.app/v1/health"
curl -s "https://api.phaseo.app/v1/models?format=openai" -H "Authorization: Bearer $PHASEO_API_KEY"
```

قبل نقل الحركة، تأكد من أن:

- `PHASEO_API_KEY` مضبوط في كل بيئة؛
- كل معرّف نموذج إنتاجي مُطابَق ومُدرج؛
- طلبًا غير متدفق وطلبًا متدفقًا ينجحان في بيئة الاختبار المرحلية؛
- أخطاء المفتاح غير الصالح والنموذج غير الصالح تُعالَج؛ فقد تختلف أجسامها عن تلك الموجودة في LLM Gateway؛
- يمكن استعادة طلب فاشل في بيئة الاختبار المرحلية من `GET /v1/generations`؛
- الإعدادات الافتراضية المشتركة للمطالبات والتوجيه موجودة في الإعدادات المسبقة حيث ينبغي.

أطلق التغيير خلف علامة canary، وانتقل من حصة صغيرة من الحركة إلى الحركة كلها بعد الاستقرار، وراقب مقاييس الإنتاج لدورة إصدار واحدة على الأقل قبل إزالة الإعداد القديم.
