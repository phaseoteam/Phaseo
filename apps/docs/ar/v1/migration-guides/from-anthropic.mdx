احتفظ بـ Anthropic SDK واستدعاء Messages. وجّه العميل إلى `https://api.phaseo.app`، ومرّر مفتاح Phaseo بوصفه `authToken`، وامنح كل نموذج معرّفه في Phaseo.

| الإعداد | Anthropic | Phaseo |
| --- | --- | --- |
| عنوان URL الأساسي | القيمة الافتراضية في SDK (`https://api.anthropic.com`) | `https://api.phaseo.app` (يضيف SDK المسار `/v1/messages`) |
| مفتاح API | `ANTHROPIC_API_KEY`، يُرسل بوصفه `x-api-key` | `PHASEO_API_KEY` بوصفه `authToken` / `auth_token`، يُرسل بوصفه `Authorization: Bearer` |
| النموذج | `claude-sonnet-5-5` | `anthropic/claude-sonnet-5.5`، أو أي معرّف من `GET /v1/models` |
| استدعاء Messages | `messages.create` | دون تغيير |

## تبديل العميل

أنشئ مفتاحًا باستخدام `phaseo keys create` في [Phaseo CLI](../guides/integrations/phaseo-cli) أو في [مفاتيح API](https://phaseo.app/settings/keys)، واجعله متاحًا للتطبيق بوصفه `PHASEO_API_KEY`.

<CodeGroup>
```typescript TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  apiKey: null,
  authToken: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app",
});

const response = await client.messages.create({
  model: "anthropic/claude-sonnet-5.5",
  max_tokens: 256,
  messages: [{ role: "user", content: "Reply with: migration ready" }],
});
```

```python Python
import os
import anthropic

client = anthropic.Anthropic(
    auth_token=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app",
)

response = client.messages.create(
    model="anthropic/claude-sonnet-5.5",
    max_tokens=256,
    messages=[{"role": "user", "content": "Reply with: migration ready"}],
)
```

```bash cURL
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 256,
    "messages": [{"role": "user", "content": "Reply with: migration ready"}]
  }'
```
</CodeGroup>

ثلاث تفاصيل تُفشل هذه الخطوة في أغلب الأحيان:

- **استخدم المضيف الجذر.** يؤدي `baseURL: "https://api.phaseo.app/v1"` إلى `/v1/v1/messages`. أما عملاء OpenAI المتوافقون في المستودع نفسه فيظلون يستخدمون `/v1`.
- **أرسل المفتاح كرمز bearer.** لا تقرأ البوابة إلا `Authorization: Bearer`؛ وتحصل ترويسة `x-api-key` على `401` `missing_or_invalid_authorization_header`. يرسل `authToken` ترويسة Bearer في كل إصدارات SDK. أما `apiKey` فلا يفعل ذلك إلا بدءًا من `@anthropic-ai/sdk` 1.0 و`anthropic` 2.0.
- **أزل `ANTHROPIC_API_KEY`** من البيئات التي تستدعي Phaseo الآن. يمنع `apiKey: null` إصدارات TypeScript SDK الأقدم من قراءته، وتقرؤه إصدارات Python SDK السابقة لـ 0.98 حتى عند ضبط `auth_token`.

تستخدم الأدوات التي تُضبط عبر متغيرات البيئة، مثل Claude Code، القيمة `ANTHROPIC_BASE_URL=https://api.phaseo.app`، و`ANTHROPIC_AUTH_TOKEN` مضبوطًا على مفتاح Phaseo، و`ANTHROPIC_API_KEY` فارغًا.

## مطابقة معرّفات النماذج

تحقّق من كل نموذج إنتاجي مقابل `data[].id` من `GET /v1/models?format=openai`. تستخدم معرّفات Phaseo النقاط في الإصدار: يصبح `claude-sonnet-5-5` هو `anthropic/claude-sonnet-5.5`. إذا كان النموذج يتغير أيضًا، فاقرأ [دليل ترحيل النموذج](../model-migrations) الخاص به.

## ما الذي يعمل بشكل مختلف

| ميزة Anthropic | على Phaseo |
| --- | --- |
| ترويسة `anthropic-version` | تُقبل أي قيمة؛ يستدعي Phaseo نماذج Claude بإصداره الخاص. |
| ترويسات `anthropic-beta` | لا تُمرَّر. يضيف Phaseo الميزات التجريبية التي تحتاجها ميزاته المدعومة؛ وتعيد حقول الجسم التجريبية فقط مثل `mcp_servers` الخطأ `400`. |
| `temperature` و`top_p` و`top_k` | تُحذف حيث لا يقبلها النموذج أو المسار، وتُدرج في `X-Phaseo-Dropped-Params`. |
| `speed: "fast"` | يعيد `400`. استخدم `service_tier: "fast"`. |
| أدوات البحث على الويب والجلب الأصلية | مقبولة حيث يشغّلها المزوّد، أو استخدم أداة الخادم `phaseo:web_search` من Phaseo. |
| `cache_control` | مدعوم في المستوى الأعلى أو لكل كتلة. راجع [التخزين المؤقت للمطالبات](../guides/prompt-caching). |
| `metadata.user_id` | لا يُستخدم كمعرّف للمستخدم النهائي. أرسل `user` أو ترويسة `X-Phaseo-User-Id` لسياسات حدود المعدّل الخاصة بالمستخدم النهائي. |
| Message Batches (`/v1/messages/batches`) | لا يوجد هذا المسار. يقبل `/v1/batches` صفوف `/v1/messages` بشكل مختلف. |
| عدّ الرموز (`/v1/messages/count_tokens`) | لا يوجد مقابل. أبقِه على Anthropic أو قدّره في جهة العميل. |
| Files API (`client.beta.files`) | لا يوجد مقابل. أرسل المستندات مضمّنة. |
| عميلا `AnthropicBedrock` و`AnthropicVertex` | استبدلهما بعميل `Anthropic` العادي؛ لا تنطبق إعدادات المصادقة السحابية والمنطقة. |

## الاختبار والنشر

اختبر مطالبات النظام والبث واستخدام الأدوات والتفكير والمخرجات المنظّمة باستخدام معرّفات النماذج نفسها التي يستخدمها التطبيق. ثم قارن مجموعة مطالبات تمثيلية عبر الإعدادين من حيث شكل المخرجات وزمن الاستجابة واستخدام الرموز والأخطاء والتكلفة. قبل نقل الحركة، تأكد من أن:

- مفتاح Phaseo مضبوط في كل بيئة نشر؛
- كل معرّف نموذج إنتاجي موجود في `GET /v1/models?format=openai`؛
- مسارات البث واستخدام الأدوات تنجح في بيئة الاختبار المرحلية؛
- كل ترويسة `anthropic-beta` وكل حقل تجريبي فقط قد أُزيل أو استُبدل؛
- التراجع لا يزال مجرد تغيير لعنوان URL الأساسي والمفتاح.
