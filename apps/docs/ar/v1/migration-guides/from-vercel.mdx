في شيفرة AI SDK، استبدل `@ai-sdk/gateway` بـ `@phaseo/ai-sdk-provider` وغلّف كل معرّف نموذج بـ `phaseo(...)`. وفي العملاء المتوافقين مع OpenAI، غيّر عنوان URL الأساسي والمفتاح. يبقى منطق التوليد لديك كما هو.

| الإعداد | Vercel AI Gateway | Phaseo |
| --- | --- | --- |
| عنوان URL الأساسي | `https://ai-gateway.vercel.sh/v1` | `https://api.phaseo.app/v1` |
| مفتاح API | `AI_GATEWAY_API_KEY` أو Vercel OIDC | `PHASEO_API_KEY`، كسرّ على جهة الخادم |
| مزوّد AI SDK | `@ai-sdk/gateway`، أو نماذج بسلاسل نصية مجردة | `@phaseo/ai-sdk-provider` |
| خيارات التوجيه | `providerOptions.gateway` | `providerOptions.phaseo` |

## تبديل المزوّد

<CodeGroup>
```typescript AI SDK
import { generateText } from "ai";
// قبل: import { gateway } from "@ai-sdk/gateway";
import { phaseo } from "@phaseo/ai-sdk-provider";

const { text } = await generateText({
  // قبل: model: gateway("openai/gpt-4.1-mini"),
  model: phaseo("openai/gpt-4.1-mini"),
  prompt: "Generate a migration checklist.",
});
```

```typescript OpenAI SDK
import OpenAI from "openai";

// قبل:
// new OpenAI({ apiKey: process.env.AI_GATEWAY_API_KEY, baseURL: "https://ai-gateway.vercel.sh/v1" });
const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});
```

```bash cURL
curl -s "https://api.phaseo.app/v1/chat/completions" \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [{"role":"user","content":"Hello"}]
  }'
```
</CodeGroup>

يقرأ التصدير الافتراضي `phaseo` المتغير `PHASEO_API_KEY` مرة واحدة عند استيراد الوحدة، ويستخدم `https://api.phaseo.app/v1`. إذا ضُبط المتغير بعد الاستيراد، كما في بعض إعدادات الحوسبة بلا خادم والاختبار، فسيرمي كل استدعاء خطأ مفتاح مفقود؛ استدعِ `createPhaseo({ apiKey, baseURL, headers })` داخل المعالج بدلًا من ذلك.

ثبّت إصدار المزوّد المطابق للإصدار الرئيسي من `ai` لديك: `@phaseo/ai-sdk-provider` لـ AI SDK 7، و`@phaseo/ai-sdk-provider@ai-sdk-v6` لـ AI SDK 6، و`@phaseo/ai-sdk-provider@ai-sdk-v5` لـ AI SDK 5.

يرسل AI SDK النماذج المكتوبة كسلاسل نصية مجردة (`model: "openai/gpt-4.1-mini"`) عبر بوابة Vercel افتراضيًا، لذا فإن أي سلسلة مجردة متبقية تواصل استدعاءها. غيّر مصنع النماذج المشترك مرة واحدة، ثم ابحث عن `model: "` في استدعاءات AI SDK. تنتقل عملاء Anthropic SDK الموجّهة إلى `ai-gateway.vercel.sh` إلى الإعداد الموضح في [الترحيل من Anthropic SDK](./from-anthropic).

## مطابقة خيارات البوابة

يُدمج `providerOptions.phaseo` في جسم الطلب. أما `providerOptions.gateway` المتبقي فيُتجاهل دون خطأ.

| Vercel AI Gateway | على Phaseo |
| --- | --- |
| `providerOptions.gateway.order` و`.only` | `providerOptions: { phaseo: { provider: { order, only } } }`، أو [إعداد مسبق](../guides/presets) يُستدعى بصيغة `phaseo("@slug")`. |
| `providerOptions.gateway.models` | `providerOptions: { phaseo: { models: [...] } }`، أو الاحتياطات في مسار ديناميكي. |
| `providerOptions.gateway.sort` (`cost` و`ttft` و`tps`) | `provider.sort` (`price` و`latency` و`throughput`). |
| `providerOptions.gateway.zeroDataRetention` | `provider.require_zero_data_retention`، الذي يقصر التوجيه على مزوّدي ZDR. |
| `providerOptions.gateway.user` و`.tags` | `user` و[تسميات](../guides/request-labels) `X-Phaseo-Metadata`. |
| بيانات اعتماد `byok` على مستوى الطلب | لا يوجد مقابل. أضف مفاتيح المزوّدين إلى مساحة العمل باستخدام `phaseo byok create`. |
| النص والبث والأدوات والمخرجات المنظّمة والتضمينات والصور والنسخ الصوتي والكلام | يدعمها المزوّد؛ وتظل الإمكانات معتمدة على النموذج. |
| إعادة الترتيب | `phaseo.rerankingModel(id)` في إصداري AI SDK 6 و7. |
| مراجع الملفات المُدارة والأدوات التي ينفذها المزوّد | غير مدعومة. تفشل الأجزاء غير المدعومة بخطأ بدلًا من إسقاطها. |
| لوحة استخدام البوابة | سجلات الطلبات في Phaseo و`GET /v1/generations?id=<request_id>`. تتضمن بيانات المزوّد الوصفية في النتائج معرّف الطلب. |

## الاختبار والنشر

شغّل مجموعة المطالبات نفسها عبر المسارين وقارن زمن الاستجابة وتنسيق المخرجات واستخدام الرموز. قبل ترقية الحركة، تأكد من أن:

- `PHASEO_API_KEY` مضبوط في كل بيئة تشغيل كان فيها مفتاح البوابة، بما في ذلك عمليات النشر على الحافة والخادم والمعاينة؛
- مسار توليد النص الرئيسي واختبار بث واحد ينجحان دون تغيير في بيئة الاختبار المرحلية؛
- استدعاءات الأدوات والمخرجات المنظّمة تنجح إذا كان التطبيق يستخدمها؛
- مطابقة الأخطاء على مستوى التطبيق لا تزال تعمل؛
- يمكن العثور على طلب فاشل في بيئة الاختبار المرحلية، وعندما تكون قيمة `replay_supported` هي `true`، إعادة تشغيله من `GET /v1/generations?id=<request_id>`.

أطلق التغيير خلف علامة ميزة أو نشر بنسبة مئوية، بدءًا بالحركة الداخلية. راقب زمن الاستجابة ومعدل الأخطاء وانحراف الرموز والتكلفة، وأبقِ المزوّد القديم متاحًا لإصدار واحد على الأقل حتى لا يحتاج التراجع إلى تغيير في الشيفرة.

```bash
curl -s "https://api.phaseo.app/v1/health"
curl -s "https://api.phaseo.app/v1/models?format=openai" -H "Authorization: Bearer $PHASEO_API_KEY"
```

لمزيد من المعلومات عن المزوّد، راجع [AI SDK](../guides/integrations/ai-sdk).
