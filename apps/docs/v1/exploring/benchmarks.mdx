Open a benchmark on [Benchmarks](https://phaseo.app/benchmarks) to rank models by their score on it, or open a model page to see every score that model has. Phaseo doesn't run benchmarks; it collects published scores and links each one to its source.

## What each score records

| Field | What it tells you |
| --- | --- |
| Score | The value as published, on the benchmark's own scale. |
| Variant | The setup when it differs from the default, such as few-shot count or reasoning effort. |
| Source | A link to the paper, model card or results page the score came from. |
| Self-reported | Set when the model's own developer published the score. It's a disclosure, not a rejection. |

Each benchmark also has a category and a sort direction. Phaseo ranks lower-is-better benchmarks, such as error rates, with the lowest score first.

## How to compare scores

Phaseo doesn't convert benchmarks to one common score, so compare models on the same benchmark and variant, not across benchmarks. Check the variant and the self-reported flag before treating two numbers as equal: a provider-reported score and an independently measured one can differ for the same model.

A benchmark score is one input. Cost, latency, reliability and how a model handles your own prompts matter as much; [Pricing and performance](./pricing-performance.mdx) covers those.

## What a benchmark page shows

| Section | What it tells you |
| --- | --- |
| **Summary** | What the benchmark measures, with a link to it. |
| **Progress** | How scores on the benchmark have changed over time. |
| **Model results** | Every model's score, ranked in the benchmark's sort direction. |

Composite indexes, such as the Artificial Analysis Intelligence Index and the Epoch Capabilities Index, have their own pages with the publisher's rankings and versions.

## Benchmark categories

| Category | Examples |
| --- | --- |
| General | Artificial Analysis Intelligence Index, Epoch Capabilities Index |
| Agents | BrowseComp, BFCL-v3, Toolathlon |
| Code | SWE-Bench, Aider-Polyglot |
| Math | AIME 2025, MathVision |
| Reasoning | HellaSwag, Hallusion Bench |
| Language | BIG-Bench Hard, Winogrande |
| Multimodal | CharXiv-R, MMBench-V1.1 |
| Long context | AA-LCR, OpenAI-MRCR |

Other categories include audio, embeddings, healthcare, planning and creativity.

## Where scores come from

- Model cards, technical reports and papers from the model's developer.
- Benchmark organisers' own results pages.
- Scheduled imports from Artificial Analysis and Epoch AI.
- Community reports through GitHub issues, reviewed before publication.
