Open a provider on [API providers](https://phaseo.app/api-providers) to see which models it serves through Phaseo and how fast it has been, or [compare providers](https://phaseo.app/api-providers/compare) side by side. An API provider hosts models behind an API; the [organisation](./organisations.mdx) that built a model is often a different company.

| | Organisation | API provider |
| --- | --- | --- |
| **Does** | Builds and trains models | Hosts and serves model APIs |
| **Focus** | Research and model quality | Reliability, access, regions and pricing |
| **Models** | Usually its own families | Often models from many organisations |

Many companies are both.

## What a provider page shows

| Section | What it tells you |
| --- | --- |
| **Performance** | Hourly latency and throughput on Gateway traffic over the past seven days. |
| **Token usage** | Tokens Phaseo has sent to the provider over time. |
| **Top models** and **Top apps** | The models and public apps with the most traffic on this provider. |
| **Models** | Every model the provider serves, with tabs for text, image, audio, video, embedding and moderation models. |

Each model's page then shows the provider's price, context length, status and data policy for that model; [Provider statuses](../guides/provider-statuses) explains the status icons.

## How the Gateway uses providers

When a model has several providers, the Gateway picks one per request and falls back to another if it fails. You send one request format and get one bill and one usage log, whichever provider serves it. To bill your own provider account instead, add a provider key ([BYOK](../guides/routing-and-fallbacks#byok-considerations)).

[Routing and fallbacks](../guides/routing-and-fallbacks) shows how to rank, pin or exclude providers.

## Choose a provider

| If you care about | Check |
| --- | --- |
| A specific model | The model page's **Providers** section, or `GET /v1/models/{author}/{slug}/endpoints` |
| Latency in your region | The provider's **Performance** section and its regions on the model page |
| Cost at your volume | The model's **Pricing** section and the [pricing calculator](https://phaseo.app/tools/pricing-calculator) |
| Tools, streaming or structured output | The route's supported parameters on the model page or the endpoints API |
| Data handling and compliance | The route's data policy and processing locations on the model page |

[Pricing and performance](./pricing-performance.mdx) explains how to read the cost and speed numbers.
