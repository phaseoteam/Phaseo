Open the [Models](https://phaseo.app/models) list to find text, image, audio, video, embedding and other models, then open a model to see its providers, prices, performance and benchmark scores.

![A model page on Phaseo](/images/gemini-3-page.png)

## Catalog models and callable models

The catalog is broader than the Gateway. The Models list shows only models that are **Active on Gateway** by default. Change the **Gateway status** filter to **Coming soon** or **Not active** to see the rest.

| Term | Meaning |
| --- | --- |
| Catalog model | Phaseo tracks metadata for the model. It may have no route you can call. |
| Routable model | At least one provider route is active on the Phaseo Gateway now. |
| External mapping | Phaseo lists a provider offer that the Gateway doesn't execute. |

`GET /v1/models` returns only routable models. Add `availability=all` to include the rest.

## Filter and sort the list

| Control | Options |
| --- | --- |
| Gateway status | Active on Gateway (default), Coming soon, Not active |
| Endpoints | The API endpoints a model supports, such as text generation or embeddings |
| Input and output modalities | Text, image, audio, video and others |
| Features | Capabilities such as tool calling or reasoning |
| Year | Release year |
| Sort | Newest, most popular (7-day tokens), price, context length, throughput, latency |

To see every model from one lab, open its [organisation page](./organisations.mdx).

## What a model page shows

| Section | What it tells you |
| --- | --- |
| **Providers** | Each provider route with its status, context length, price, uptime and data policy. [Provider statuses](../guides/provider-statuses) explains the icons. |
| **Performance** | Latency and throughput measured on Gateway traffic, when there is enough data. |
| **Pricing** | Every meter in USD: input, output, cached input, and media units. |
| **Benchmarks** | Scores on each benchmark, with sources. |
| **Activity** | Gateway token usage over time. |
| **Apps** | Public apps that use the model. |
| **Uptime** | Route availability over recent days. |
| **Verification** | Content-provenance checks, for image and video models. |
| **About** | Release dates, licence, links and family. |
| **Subscriptions** | Provider subscription plans that include the model. |
| **FAQs** | Common questions about the model. |

A section appears only when there is data for it. Models with an active route also show a quickstart with the model ID to send.

## Compare models

[Compare](https://phaseo.app/compare) puts models side by side on price, benchmark scores, context and features. [Pricing and performance](./pricing-performance.mdx) explains how to read the cost and speed numbers.

## Report a correction

Open a GitHub issue with the model page and an official source. Maintainers apply approved updates in the database. See [Report a model update](../contributing/editing-a-model.mdx).
