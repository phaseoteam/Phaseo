Phaseo tracks a broad open catalog of text, image, audio, video, embedding, and other AI models.

Each model page on Phaseo includes detailed technical and commercial information to help you evaluate, compare, and select the right model for your needs.

<Info>
The catalog is broader than the Gateway. The Models page shows models with an active Gateway route by default. Select a different Gateway Status only when you intentionally want to inspect coming-soon or inactive catalog entries.
</Info>

---

## What you'll find on a model page

Every model on Phaseo contains the following key sections:

| Section          | Description                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Overview**     | Includes provider, release date, model type (chat, code, embedding, image, etc.), and short description.                       |
| **Family**       | Easily see related models and their relationships.                                                                             |
| **Timeline**     | Visualizes release history and major updates over time.                                                                        |
| **Benchmarks**   | Shows performance results across benchmarks, easily compare to nearest models.                                                 |
| **Availability** | Separates active Gateway routes from coming-soon, inactive, and external provider mappings. |
| **Pricing**      | Displays detailed pricing in USD, normalized for easy comparison to make it easy to see what the model costs.                  |
| **Gateway**      | Direct links and quickstarts when a public Gateway route is available.                                                        |
| **Performance**  | Observational latency, throughput, and success data from routed Gateway requests when enough data is available.              |

## Catalog models vs routable models

Use these terms consistently:

| Term | Meaning |
| --- | --- |
| Catalog model | Phaseo tracks metadata for the model. A public route may not exist. |
| Routable model | At least one provider route is active on the Phaseo Gateway now. |
| External mapping | Phaseo tracks a provider offer that is not executed by the Gateway. |

For programmatic discovery, `GET /v1/models` returns only routable models by default. Set `availability=all` to inspect the broader set.

## Finding models by criteria

Use filters and tags across the Phaseo interface to locate models that fit your needs:

-   **By provider:** "Show all Anthropic models."
-   **By capability:** "List models supporting JSON structured responses."
-   **By benchmark:** "Top-10 models on GPQA."
-   **By pricing:** "Models costing under $0.01 per 1K tokens."
-   **By release date:** "Recently released models."

Each filter combines seamlessly, letting you discover exactly what you need.

## Contributing model updates

Because AI evolves rapidly, Phaseo relies on contributors to keep model data accurate.
Open a GitHub issue to report a correction, submit missing benchmarks, or request new metadata. Include the model page and official sources; maintainers apply approved updates through the database editor.
