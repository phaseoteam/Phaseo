Open an organisation on [Organisations](https://phaseo.app/organisations) to see every model it has released and how those models perform on the Gateway. Every model on Phaseo belongs to one organisation: the company or lab that develops and maintains it.

## What an organisation page shows

The page has two tabs.

| Tab | Section | What it tells you |
| --- | --- | --- |
| **Overview** | About | Name, description and country. |
| | Performance | Recent Gateway latency and throughput across the organisation's models. |
| | Latest models | Recent releases with availability, context, pricing and usage. |
| | Around the web | Links to the organisation's website, GitHub, Hugging Face and social accounts. |
| **Models** | | Every model the organisation has released, including archived and deprecated ones. |

## Organisations and API providers

The organisation builds the model; an [API provider](./api-providers.mdx) serves it. One model often has several providers.

| | Organisation | API provider |
| --- | --- | --- |
| **Does** | Trains and maintains the model. | Hosts the model behind an API. |
| **Example** | Anthropic built the Claude models. | Anthropic, Amazon Bedrock and Google Vertex all serve Claude models. |

Some organisations, such as OpenAI and Google, are also providers for their own models.

## Report a correction

Open a GitHub issue with the organisation page and an official source. Maintainers apply approved changes in the database. See [Report an organisation update](../contributing/editing-an-organisation.mdx).
