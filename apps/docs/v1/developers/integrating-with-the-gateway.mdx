Store a Phaseo key on your server, pick the endpoint that matches your app's protocol, and point your HTTP client or SDK at `https://api.phaseo.app/v1`. Start from the [Quickstart](../quickstart.mdx) if you haven't sent a request yet.

You need a Phaseo account with Gateway access and an HTTP client, an OpenAI-compatible SDK or a Phaseo SDK. The examples use `google/gemma-3-27b:free`, which runs without deposited credits.

<Steps>
<Step title="Create and store a key">

Open **Settings → API Keys** in the [dashboard](https://phaseo.app/settings/keys), or call `POST /v1/keys` with a management key. Name the key after the app and environment, then store it in a secrets manager or an environment file:

```bash
# .env.local
PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
PHASEO_BASE_URL="https://api.phaseo.app/v1"
```

Use separate keys for local development, preview deployments and production, so you can rotate and review each one on its own.

</Step>
<Step title="Choose the endpoint">

| Endpoint | Use it for |
| --- | --- |
| `/v1/responses` | New text builds, structured output and multi-step workflows. |
| `/v1/chat/completions` | Chat interfaces and existing OpenAI-style integrations. |
| `/v1/messages` | Anthropic-compatible integrations. |
| `/v1/decisions` | Typed decisions against application state, with Jev 1.13 (Beta). |
| `/v1/moderations` | Safety and content policy checks. |
| `/v1/images/generations` | Images from text prompts. |

The [API Reference](../api-reference/introduction) lists every endpoint, parameter and response.

</Step>
<Step title="Send a request from your app">

This example uses Chat Completions, which OpenAI-compatible clients already speak. Every request sends the key as `Authorization: Bearer $PHASEO_API_KEY`.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemma-3-27b:free",
    "messages": [
      { "role": "system", "content": "You are a helpful assistant." },
      { "role": "user", "content": "Explain the benefits of AI." }
    ]
  }'
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});

const response = await client.chat.completions.create({
  model: "google/gemma-3-27b:free",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: "Explain the benefits of AI." },
  ],
});

console.log(response.choices[0]?.message?.content);
```

```python Python

```

```go Go
package main

import (
  "context"
  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4"
)

func main() {
  client := phaseo.New("YOUR_API_KEY", "https://api.phaseo.app/v1")

  response, err := client.CreateChatCompletion(context.Background(), phaseo.ChatCompletionsRequest{
    Model: "google/gemma-3-27b:free",
    Messages: []map[string]interface{}{
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain the benefits of AI."},
    },
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(response)
}
```
