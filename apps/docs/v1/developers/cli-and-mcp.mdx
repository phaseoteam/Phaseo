Use the CLI to change Phaseo from a terminal or script, or connect an AI client to the Phaseo MCP server to give it live Phaseo data. Both sign in with Phaseo OAuth.

| Interface | Use it to | Access |
| --- | --- | --- |
| [Phaseo CLI](#phaseo-cli) | Create keys, change settings, manage workspaces, and automate admin work from a shell or CI | Read and write, limited by your scopes and workspace role |
| [Phaseo MCP](#phaseo-mcp) | Give Codex, Claude, ChatGPT and other MCP clients live Phaseo data, and optionally let them manage your account | Read-only unless you connect with account management |
| [Docs MCP](#docs-mcp) | Give a coding assistant current Phaseo documentation | Documentation only, no account access |
| [Phaseo plugin](#phaseo-plugin) | Install both MCP servers and the Phaseo skills in Claude Code or Codex at once | Same as each MCP server |

## Phaseo CLI

### Install and sign in

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

Interactive terminals use browser OAuth by default. For SSH, CI, and headless environments, use device authorization:

```bash
phaseo login --device-code
```

### Common workflows

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys list
phaseo logs list --since 1h --status error --json
```

Use `--json` when another tool or script needs structured output. Secret values are displayed only by commands that explicitly create or reveal them.

## Phaseo MCP

The server URL is `https://mcp.phaseo.app/mcp`. An AI client connected to it can answer questions with live model, pricing, provider, usage and workspace data.

### Connect from Codex

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

The login command opens Phaseo OAuth. Choose a workspace and approve the requested read scopes, then confirm the connection:

```bash
codex mcp list
```

For another MCP client, add the same URL as a remote Streamable HTTP server. The client must support OAuth discovery, authorization code with S256 PKCE, and the MCP `resource` parameter.

### What the MCP can read

The read-only tools cover models, providers, benchmark rankings, pricing and cost estimates, plus credits, activity, analytics, request logs and generation metadata. They never return prompts, responses or secret values.

### Manage your account (optional)

To let an agent change your Phaseo workspace, connect with the manage URL instead:

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

When you sign in, the consent screen lists each permission the connection asks for, such as managing API keys or deleting budgets, and marks it **Read**, **Write**, or **Delete**. Untick any you do not want. The agent only gets tools for the permissions you allow, and Phaseo still checks your workspace role on every change, so a member who is not an owner or admin cannot change admin-only settings this way.

If you already connected with the read-only URL, switch the client to the manage URL and sign in again. To go back to read-only access, reconnect with the plain URL or revoke the app under **Settings → Connected Apps**.

| Area | Tools | Permissions |
| --- | --- | --- |
| API keys | `api_keys_list`, `api_key_get`, `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete` | `keys:read`, `keys:write`, `keys:delete` |
| Budgets | `budgets_list`, `budget_create`, `budget_update`, `budget_delete` | `budgets:read`, `budgets:write`, `budgets:delete` |
| Spend rules | `spend_rules_list`, `spend_rule_create`, `spend_rule_update`, `spend_rule_delete` | `spend_rules:read`, `spend_rules:write`, `spend_rules:delete` |
| Provider keys (BYOK) | `provider_keys_list`, `provider_key_create`, `provider_key_update`, `provider_key_delete` | `provider_credentials:read`, `provider_credentials:write`, `provider_credentials:delete` |
| Guardrails | `guardrails_list`, `guardrail_get`, `guardrail_create`, `guardrail_update`, `guardrail_delete`, `guardrail_keys_set` | `guardrails:read`, `guardrails:write`, `guardrails:delete` |
| Presets | `presets_list`, `preset_get`, `preset_create`, `preset_update`, `preset_version_publish` | `presets:read`, `presets:write` |
| Settings | `settings_get`, `settings_update` (routing mode, privacy and ZDR, logging, provider restrictions) | `settings:read`, `settings:write` |
| Webhooks | `webhooks_list`, `webhook_create`, `webhook_delete` | `settings:read`, `settings:write` |
| Observability destinations | `observability_destinations_list`, `observability_destination_create`, `observability_destination_delete` | `settings:read`, `settings:write` |

Tools that change or delete something are marked as such, so MCP clients that support it ask you before each call. A new API key or webhook signing secret is shown once in the tool result and cannot be shown again. Stored provider keys and destination credentials are never returned.

The MCP has no billing, payment, workspace, member, management-key, or OAuth-app tools. Use the dashboard, CLI, or Management API for those.

## Docs MCP

The Docs MCP is a separate endpoint for searching and reading Phaseo documentation. It does not access your account or workspace.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

## Phaseo plugin

The Phaseo plugin bundles the Phaseo MCP, the Docs MCP, and the Phaseo agent skills for integration, migration, model selection, usage monitoring, the SDKs, and the CLI. Install it once instead of connecting each piece yourself.

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

Run `/mcp` and sign in to `plugin:phaseo:phaseo` to connect your Phaseo account. Skills load when a request matches them, or you can run one directly, such as `/phaseo:phaseo-gateway`.

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

The last command opens Phaseo OAuth for the Phaseo MCP. Skills load when a request matches them.
