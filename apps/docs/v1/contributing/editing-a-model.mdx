Open a GitHub issue to correct a model or request a missing entry. You do not need to edit JSON or set up the repository.

## Report a correction

1. Copy the model's Phaseo page URL or model ID.
2. [Report incorrect information](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml), describing the current value and the proposed correction.
3. Include official documentation, a release announcement, or another verifiable source.

For pricing, include the provider, currency, billing unit, relevant tier, and effective date. For benchmark scores, follow [Submit scores](../research/submitting-scores.mdx).

## Request a missing model

[Open a data request](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) with the model name, organisation, official link, release date, and known capabilities. A model can appear in the catalog before it has a supported Gateway route.

## After submitting

Maintainers review the evidence and update the database through the internal editor. Track questions and publication in the issue. Daily JSON snapshots export the catalog; changes to archived JSON files do not update the live site.

Admins can edit records at [Internal data](https://phaseo.app/internal/data) and review proposed prices at [Provider updates](https://phaseo.app/internal/data/imports). These pages require admin access.
