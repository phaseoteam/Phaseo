Submit a pull request to the [Phaseo repository](https://github.com/phaseoteam/Phaseo) with the change, its source or rationale, and the checks you ran.

## Choose your contribution

| Change | Start here |
| --- | --- |
| Model metadata, capabilities, or pricing | [Edit a model](./editing-a-model.mdx) |
| Company or research organisation details | [Edit an organisation](./editing-an-organisation.mdx) |
| Benchmark results | [Submit scores](../research/submitting-scores.mdx) |
| Documentation or code | [Contribution workflow](./how-to-contribute.mdx) and [repository structure](./repo-structure.mdx) |

For a larger schema or feature change, discuss the proposal with maintainers before implementing it.

## Before submitting

- Cite official sources for data changes and distinguish reported results from independently measured results.
- Follow the existing schema and formatting. Include the relevant validation results in the pull request.
- Keep the change focused and explain the problem it fixes.
- Never include credentials or private customer data.
- Follow the [Code of Conduct](../community/code-of-conduct.mdx).

Use the [step-by-step contribution workflow](./how-to-contribute.mdx) for branch setup, local checks, and opening a pull request. Ask for help in [Discord](https://discord.gg/aQyywCvgZ5) if you are unsure where a change belongs.
