For catalog corrections and additions, open an issue with the affected record and supporting sources. For code or documentation changes, submit a pull request to the [Phaseo repository](https://github.com/phaseoteam/Phaseo).

## Choose your contribution

| Change | Start here |
| --- | --- |
| Model metadata, capabilities, availability, or pricing | [Report a model update](./editing-a-model.mdx) |
| Company or research organisation details | [Report an organisation update](./editing-an-organisation.mdx) |
| Benchmark results | [Submit scores](../research/submitting-scores.mdx) |
| Other catalog corrections | [Report incorrect information](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) |
| Missing providers or other catalog data | [Request new data](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) |
| Documentation or code | [Contribution workflow](./how-to-contribute.mdx) and [repository structure](./repo-structure.mdx) |

## How catalog reports are published

Maintainers review the evidence in the issue and apply approved changes through the admin-only [internal editor](https://phaseo.app/internal/data). Provider price updates require explicit review before publication.

The database is the catalog source of truth. Daily public JSON snapshots remain available, but neither snapshot edits nor archived JSON pull requests update the live catalog. The legacy JSON importer is retired.

## Before submitting

- Include the affected page or record ID and describe the proposed correction.
- Cite official sources and distinguish reported benchmark results from independent measurements.
- Keep each report or pull request focused.
- Never include credentials or private customer data.
- Follow the [Code of Conduct](../community/code-of-conduct.mdx).

Discuss larger schema or feature changes with maintainers before implementing them. Ask for help in [Discord](https://discord.gg/aQyywCvgZ5) if you are unsure where a change belongs.
