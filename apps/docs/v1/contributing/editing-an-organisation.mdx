Report missing or outdated organisation details through a GitHub issue. Maintainers review the evidence and apply approved changes in the database editor.

## Report a correction

1. Copy the organisation's Phaseo page URL or ID.
2. [Report incorrect information](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) with the affected field and proposed value.
3. Link to an official website, announcement, or another verifiable source.

Common corrections include the name, description, website, location, and relationships to models or API providers.

## Request a missing organisation

[Open a data request](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) with the organisation's name, official website, and relevant model or provider links.

## After submitting

Track review and publication in the issue. No JSON edit or pull request is needed for a catalog record change. Daily JSON files are exports; they are not imported into the live database.

Admins manage organisations through the [internal catalog editor](https://phaseo.app/internal/data), which requires admin access.
