Phaseo is a pnpm and Turborepo monorepo. Find the folder for your code or documentation change below. Catalog records aren't in the repository; to change one, [open an issue](./overview.mdx).

## Applications

| Path | Purpose |
| --- | --- |
| `apps/web` | Next.js 16 website, dashboard, and internal catalog editor. |
| `apps/web-api` | Public catalog reads and authenticated account and admin APIs. |
| `apps/api` | Gateway routing and provider execution on Cloudflare Workers. |
| `apps/docs` | Mintlify documentation; MDX pages are in `v1`, navigation in `docs.json`. |
| `apps/mcp` | Phaseo MCP server for model discovery, pricing and usage. |
| `apps/desktop` | Phaseo Desktop app. |
| `apps/mobile` | Phaseo mobile app (Expo, Android first). |
| `apps/slack` | Worker behind the Phaseo Slack agent. |

## Packages and tooling

| Path | Purpose |
| --- | --- |
| `packages/sdk` | TypeScript, Python, Go, C#, PHP, Ruby, Java, Rust and C++ SDKs, plus the Agent SDKs (`agent-sdk-*`). |
| `packages/cli/phaseo` | The `@phaseo/cli` command-line tool. |
| `packages/integrations` | The Vercel AI SDK provider and the Terraform provider. |
| `packages/shared` | Code shared between apps, such as UI, spend rules and routing settings. |
| `supabase/schemas` | Declarative database definitions. |
| `supabase/migrations` | Forward SQL migrations that deploy schema and permission changes. |
| `scripts` | Validation, SDK generation, and automation utilities. |
| `.github/workflows` | CI, deployment, and catalog synchronization. |
| `.changeset` | Release metadata for versioned packages. |

## Catalog data

The database is the only source for models, providers, organisations, pricing, benchmarks, and catalog settings. The repository holds no catalog JSON. Admins manage records in [Internal data](https://phaseo.app/internal/data); public contributions arrive as GitHub issues.

Schema and application changes still go through migrations and pull requests. Update generated SDK files with their generation commands, not by hand.

## Catalog automation

Provider sync queues proposed prices for review in [Provider updates](https://phaseo.app/internal/data/imports). Benchmark and model lifecycle jobs read and write the database.

A catalog record doesn't enable Gateway routing on its own. Route and price changes need admin review.

To start a change, see [Contribute code or documentation](./how-to-contribute.mdx).
