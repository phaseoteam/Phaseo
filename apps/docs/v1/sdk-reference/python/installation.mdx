The SDK is published as [`phaseo`](https://pypi.org/project/phaseo/) on PyPI.

## Installation

Install the SDK using your preferred Python package manager:

<CodeGroup>

    ```bash title="pip"
    pip install phaseo
    ```

    ```bash title="uv"
    uv add phaseo
    ```

</CodeGroup>

## Requirements

- Python 3.10+

## Setup

### API key

Create an API key in the [Phaseo Dashboard](https://phaseo.app/settings/keys).

### Environment variable

```bash
export PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
```

### Basic usage

```python
from phaseo import Phaseo
import os

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])

response = client.generate_text(
    {
        "model": "openai/gpt-5-nano",
        "messages": [{"role": "user", "content": "Hello!"}],
    }
)

print(response["choices"][0]["message"]["content"])
```

### Optional client configuration

```python
from phaseo import Phaseo

client = Phaseo(
    api_key="your-api-key",
    base_url="https://api.phaseo.app/v1",
    timeout=30.0,
)
```
