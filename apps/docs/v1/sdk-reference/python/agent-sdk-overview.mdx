The Python Agent SDK is a full local agent runtime for Phaseo Gateway, including retries, concurrent tools, timeouts, human review, resumable state, lifecycle events, and Devtools capture.

Use it when you want:

- a lightweight bounded tool loop
- gateway-backed `responses` requests
- app-owned control over persistence and orchestration

## What it ships

- `create_agent(...)`
- `define_tool(...)`
- `create_gateway_agent_client(...)`
- a bounded tool loop over the Phaseo `responses` API
