Enable local JSONL capture with `create_agent_devtools(...)` and pass it to `run(...)`, `stream(...)`, or continuation.

Captured entries include status, timing, model/provider details, request IDs, messages, steps, tool activity, usage, cost, and structured errors.

<Warning>
Agent inputs, context, and tool results may contain sensitive data. Keep DevTools output out of source control and production images.
</Warning>
