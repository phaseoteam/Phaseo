Use the wrapper method:

- `client.GenerateModeration(ctx, req)`

```go
import (
  "context"
  "fmt"
  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4"
)

client := phaseo.New(apiKey, "https://api.phaseo.app/v1")
resp, err := client.GenerateModeration(context.Background(), map[string]interface{}{
  "model": "openai/omni-moderation-latest",
  "input": "some text to classify",
})
if err != nil {
  panic(err)
}

fmt.Println(resp)
```
