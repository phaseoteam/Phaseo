The SDK is published as [`sdk-go/v3`](https://pkg.go.dev/github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4).

## Requirements

- Go 1.23 or newer

## Install

```bash
go get github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4@latest
```

Import the v2 module path:

```go
import phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4"
```
