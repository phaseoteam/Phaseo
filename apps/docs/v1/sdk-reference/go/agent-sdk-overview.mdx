The Go Agent SDK is a full local agent runtime for Phaseo Gateway, including retries, concurrent tools, contexts and timeouts, human review, resumable state, lifecycle events, and Devtools capture.

Use it when you want:

- a lightweight bounded tool loop
- gateway-backed `responses` requests
- app-owned control over persistence and orchestration

## What it ships

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- a bounded tool loop over the Phaseo `responses` API
