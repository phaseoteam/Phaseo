The Agent SDK is published as [`agent-sdk-go`](https://pkg.go.dev/github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go) through Go modules.

## Requirements

- Go 1.24 or newer
- a Phaseo API key

## Installation

```bash
go get github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go@latest
```

The core `sdk-go/v3` module is installed automatically as a dependency.

## Environment

Set your gateway API key before running examples:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
