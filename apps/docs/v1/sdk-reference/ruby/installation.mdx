The SDK is published as [`phaseo_sdk`](https://rubygems.org/gems/phaseo_sdk) on RubyGems.

## Requirements

- Ruby 3.1 or newer

## Install

```bash
gem install phaseo_sdk
```

Or add it to your `Gemfile`:

```ruby
gem "phaseo_sdk"
```
