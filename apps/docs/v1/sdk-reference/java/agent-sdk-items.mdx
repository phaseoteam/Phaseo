Use `RunResult` as the durable result of a Java agent. It contains the run record, saved messages, step records, normalized usage and cost, warnings, finish reasons, and final output.

`StreamResult.fullStream()` includes provider item events alongside model, tool, step, and run events. Java currently exposes provider items as generic objects rather than the TypeScript `AgentItem` discriminated union.

For a product timeline:

1. render text from `textStream()` while the run is active
2. render tool cards from tool lifecycle events
3. persist the completed `RunResult`
4. rebuild the final timeline from saved messages and steps

Keep provider-specific item data behind an adapter in your application so a provider format change does not affect the rest of the UI.
