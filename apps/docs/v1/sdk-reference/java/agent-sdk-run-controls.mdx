Use final-output validation when downstream Java code expects a structured value rather than unchecked model text. Attach a final validator to the agent definition and treat validation failures as contract errors.

Use `ModelRetryConfig` for transient model or provider failures:

```java
var retry = new AgentSdk.ModelRetryConfig(
    2,
    Duration.ofMillis(250)
);
```

The retry count records additional attempts after the first request. Completed steps retain the final model-attempt count for debugging and telemetry.

Use `ToolExecutionConfig` separately for local tool concurrency. Model retries do not retry failed side effects inside tools.

Additional Responses API options can be supplied through `GatewayOptions.requestOptions`; the adapter continues to own model, input, instructions, and local function tools.
