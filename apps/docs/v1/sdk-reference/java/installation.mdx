The current source includes retry controls and response metadata that are absent from the older 3.0.0 artifact on Maven Central. Build the pinned source below to use the current SDK.

## Requirements

- Java 17+
- Maven 3.8+
- Git

## Build from source

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
git checkout 1ff1119f41ceb3ac2c85ed605f6e1c4beca6e011
mvn -f packages/sdk/sdk-java/pom.xml -DskipTests install
```

Maven installs `app.phaseo:phaseo-sdk:3.0.0` in your local repository, including its Jackson dependency.

## Add the dependency

```xml
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-sdk</artifactId>
  <version>3.0.0</version>
</dependency>
```

<Note>The [Maven Central artifact](https://repo.maven.apache.org/maven2/app/phaseo/phaseo-sdk/3.0.0/) is available for the older API. It does not include the current retry, metadata, or parameter-checking APIs.</Note>
