Start with one of these patterns:

| Pattern | Combine |
| --- | --- |
| Support triage | managed preset, lookup tools, structured final output |
| Coding review | file or patch tools, progress events, approval before edits |
| Research brief | managed web tools, cost and step limits, streamed text |
| Operations runbook | status tools, manual escalation, durable continuation |

Keep the first implementation narrow: one agent, one or two deterministic tools, and explicit approval around side effects.
