`AgentSdk.Tool` supports:

- JSON `parameters` shown to the model
- input, output, and progress-event `Validator` functions
- per-tool `Duration` timeouts
- unconditional or conditional approval
- manual tools completed by your application
- preliminary progress through `RuntimeContext.emitProgress()`
- `fail-run` or `return-to-model` error handling
- next-turn overrides after successful tool execution

Pass tool records through `AgentSdk.defineTool(...)` and keep side effects behind explicit approval or application-owned manual execution.
