`Agent.stream(...)` returns `StreamResult`:

```java
var stream = agent.stream(options);

for (var delta : stream.textStream()) {
  System.out.print(delta);
}

var completed = stream.getResult();
```

`textStream()` and `fullStream()` are replayable, so product UI and telemetry code can consume the same run independently. Call `cancel()` to interrupt the active stream worker.

Java item events remain generic objects rather than the TypeScript discriminated `AgentItem` union.
