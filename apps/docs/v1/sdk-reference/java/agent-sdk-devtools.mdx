Enable local run capture with `AgentSdk.createAgentDevtools(...)`:

```java
var devtools = AgentSdk.createAgentDevtools(".phaseo-devtools");
```

Pass that value through `RunOptions`. Captured JSONL entries include run status and duration, model and provider details, request IDs, messages, steps, tool activity, usage, cost, and structured errors.

<Warning>
Agent inputs, messages, context, and tool results may contain sensitive data. Keep the DevTools directory out of source control and production images.
</Warning>
