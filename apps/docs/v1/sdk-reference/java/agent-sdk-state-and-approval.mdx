Return `HumanReviewRequest` from `AgentDefinition.humanReview` for a general checkpoint. Tool approvals and manual work place exact call IDs in the paused result.

Continue with `Agent.continueRun(...)` and provide:

- `ToolDecision` entries in approvals or rejections
- `ToolOutput` entries for manual tools
- human input for a general review pause
- a serialized `RunResult`, or a run ID backed by `StateAccessor`

The SDK does not rely on hosted Agent SDK state. Implement `StateAccessor` when a run must survive requests or service restarts.
