Send text, embeddings, and model-discovery requests with the Java SDK.

<Note>The current source includes retry controls and response metadata that are absent from the older 3.0.0 artifact on Maven Central. Build the pinned source below to use the current SDK. [Installation](./installation)</Note>

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

## Supported requests

Use `createResponse`, `createChatCompletion`, `createEmbedding`, and `listModels` for JSON requests. Pass a `Map` or `JsonNode`; parse JSON strings before passing them to wrapper methods.

## Streaming

`streamResponse` and `rawClient().requestLines` return SSE lines as they arrive. Close the stream with try-with-resources and handle event names, data lines, and completion markers in your application.

<Note>The `createSpeech` wrapper expects JSON and cannot decode binary audio. Use `rawClient().requestBytes` for speech output.</Note>
