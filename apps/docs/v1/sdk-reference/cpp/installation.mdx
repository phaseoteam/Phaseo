<Note type="warning">The C++ SDK is a work in progress and is not yet published to a package registry.</Note>

## Local usage

The SDK is header-only C++17. Add `packages/sdk/sdk-cpp` to your CMake build and link the interface target, or put `packages/sdk/sdk-cpp/src` on your include path:

```cmake
add_subdirectory(path/to/Phaseo/packages/sdk/sdk-cpp)
target_link_libraries(your_app PRIVATE phaseo::sdk)
```

Then include `phaseo.hpp`, which pulls in the generated client in `src/gen`.
