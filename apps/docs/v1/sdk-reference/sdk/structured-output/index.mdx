Pass `output: Output.object({ schema })` to `generateText` to get a typed object that matches your schema. The AI SDK sends the schema as a JSON Schema response format and validates the result.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, Output } from "ai";
import { z } from "zod";

const { output } = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  output: Output.object({
    schema: z.object({
      title: z.string(),
      priority: z.enum(["low", "medium", "high"]),
      actions: z.array(z.string()),
    }),
  }),
  prompt: "Create a short incident follow-up plan.",
});

console.log(output);
```

`generateObject` still works in AI SDK 7 with the same `schema` and returns `object`, but it is deprecated in favour of `generateText` with `output`.

## Handle invalid output

Reading `output` throws `NoOutputGeneratedError` when the model returns no usable object, for example when the last step ended in a tool call. Catch it where you call the model.

- Use explicit enums and required fields in the schema.
- Keep the prompt consistent with the schema's shape.
- Model support for JSON Schema output varies; check the model's supported parameters in `/v1/models`.
