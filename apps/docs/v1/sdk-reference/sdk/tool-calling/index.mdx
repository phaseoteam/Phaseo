Define tools with the AI SDK's `tool()` helper, pass them to `generateText`, and set `stopWhen` so the model can answer after the tool runs.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, stepCountIs, tool } from "ai";
import { z } from "zod";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "What is 17 + 25? Use the calculator tool.",
  tools: {
    calculator: tool({
      description: "Perform basic arithmetic",
      inputSchema: z.object({
        operation: z.enum(["add", "subtract", "multiply", "divide"]),
        a: z.number(),
        b: z.number(),
      }),
      execute: async ({ operation, a, b }) => {
        if (operation === "add") return a + b;
        if (operation === "subtract") return a - b;
        if (operation === "multiply") return a * b;
        return a / b;
      },
    }),
  },
  stopWhen: stepCountIs(2),
});

console.log(result.text);
```

By default `generateText` stops after one step. If that step is a tool call, `result.text` is empty and the tool's result is in `result.toolResults`. `stepCountIs(2)` gives the model a second step to answer with the result.

## Write safe tools

- Keep descriptions precise and input schemas strict; the model fills in the arguments.
- Treat arguments as untrusted input. Validate them inside `execute` before any side effect.
- Add retries and backoff inside `execute` for downstream APIs that fail transiently.
