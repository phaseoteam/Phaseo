Call `streamText` with `phaseo(modelId)` and read `textStream` to get text as it arrives. `streamText` returns at once; read `providerMetadata` after the stream finishes.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Stream from chat history

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## Stop an abandoned stream

Pass an `abortSignal` to `streamText` and abort it when the user leaves or a timeout passes, so the request doesn't keep running:

```ts
const controller = new AbortController();
setTimeout(() => controller.abort(), 60_000);

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a long report.",
  abortSignal: controller.signal,
});
```

Read model IDs from `/v1/models` rather than hard-coding them; see [Model Discovery](/v1/sdk-reference/sdk/get-models).
