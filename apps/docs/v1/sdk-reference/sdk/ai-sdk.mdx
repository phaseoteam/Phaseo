Install `@phaseo/ai-sdk-provider` and pass `phaseo(modelId)` as the `model` to `generateText`, `streamText`, or any other Vercel AI SDK 7 function. Text requests go to the Gateway's `/v1/chat/completions` endpoint.

## Install

<CodeGroup>

```bash title="npm"
npm install @phaseo/ai-sdk-provider
```

```bash title="pnpm"
pnpm add @phaseo/ai-sdk-provider
```

```bash title="yarn"
yarn add @phaseo/ai-sdk-provider
```

```bash title="bun"
bun add @phaseo/ai-sdk-provider
```

</CodeGroup>

The unversioned package installs npm's `latest` tag, which is the AI SDK 7 line. It declares `ai@^7` as a peer dependency, so package managers that auto-install peers add it for you.

Set `PHASEO_API_KEY` in your server environment, then make your first request. The default `phaseo` export throws if `PHASEO_API_KEY` isn't set.

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Reply with: AI SDK works",
});

console.log(result.text);
console.log(result.providerMetadata);
```

Use a current model id from the [Models endpoint](../../api-reference/endpoint/models.mdx).

## Stream text

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Stream a short greeting.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Configure a provider instance

Call `createPhaseo()` to set `apiKey`, `baseURL`, `headers` or a custom `fetch`. Use it to identify your application in Phaseo request details:

```typescript
import { createPhaseo } from "@phaseo/ai-sdk-provider";

const phaseo = createPhaseo({
  apiKey: process.env.PHASEO_API_KEY,
  headers: {
    "x-title": "My App",
    "http-referer": "https://example.com",
  },
});
```

`PHASEO_BASE_URL` is optional and defaults to `https://api.phaseo.app/v1`.

## Pick a model type

| Provider method | AI SDK function |
| --- | --- |
| `phaseo(modelId)` or `phaseo.languageModel(modelId)` | `generateText`, `streamText` |
| `phaseo.embeddingModel(modelId)` (alias `textEmbeddingModel`) | `embed`, `embedMany` |
| `phaseo.imageModel(modelId)` | `generateImage` |
| `phaseo.transcriptionModel(modelId)` | `transcribe` |
| `phaseo.speechModel(modelId)` | `generateSpeech` |
| `phaseo.rerankingModel(modelId)` | `rerank` |

Every method except `rerankingModel` accepts optional per-model settings as a second argument: `temperature`, `topP`, `topK`, `maxTokens`, `frequencyPenalty`, `presencePenalty`, `seed`, `user`, `headers` and `fetch`.

## Supported AI SDK 7 features

- Text generation and streaming
- Reasoning output and settings
- Function tools and streamed tool inputs
- JSON and JSON Schema output
- Text and image file inputs
- URL citation sources
- Embeddings and image generation
- Reranking
- Transcription and speech generation
- Provider metadata, usage, abort signals, and raw stream chunks

What a call can do still depends on the model and provider. The provider doesn't advertise managed file references, skills, or provider-executed tools (their definitions, results, or approval responses). Function tools that your application executes use the AI SDK's normal execution and approval flow.

## Use an earlier AI SDK version

| AI SDK | Install |
| --- | --- |
| 7 | `@phaseo/ai-sdk-provider` (`latest`) |
| 6 | `@phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `@phaseo/ai-sdk-provider@ai-sdk-v5` |

If peer auto-installation is off, install the matching `ai` major (`ai@^7`, `ai@^6`, or `ai@^5`) yourself.
