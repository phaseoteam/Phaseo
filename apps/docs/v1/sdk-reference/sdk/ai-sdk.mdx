Use the official Phaseo provider to call Phaseo models through Vercel AI SDK 7. Start here when your application already uses `generateText`, `streamText`, or another AI SDK function.

## Install

<CodeGroup>

```bash title="npm"
npm install @phaseo/ai-sdk-provider
```

```bash title="pnpm"
pnpm add @phaseo/ai-sdk-provider
```

```bash title="yarn"
yarn add @phaseo/ai-sdk-provider
```

```bash title="bun"
bun add @phaseo/ai-sdk-provider
```

</CodeGroup>

The unversioned Phaseo package follows npm's `latest` tag and selects the active AI SDK 7-compatible provider line. It declares AI SDK 7 as a peer dependency, so package managers with peer auto-installation enabled install the compatible runtime automatically.

Set `PHASEO_API_KEY` in your server environment, then make your first request:

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Reply with: AI SDK works",
});

console.log(result.text);
console.log(result.providerMetadata);
```

Use a current model id from the [Models endpoint](../../api-reference/endpoint/models.mdx).

## Stream text

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Stream a short greeting.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Add application attribution

Create a provider instance when you want Phaseo request details to identify your application:

```typescript
import { createPhaseo } from "@phaseo/ai-sdk-provider";

const phaseo = createPhaseo({
  apiKey: process.env.PHASEO_API_KEY,
  headers: {
    "x-title": "My App",
    "http-referer": "https://example.com",
  },
});
```

`PHASEO_BASE_URL` is optional and defaults to `https://api.phaseo.app/v1`.

## Supported AI SDK 7 features

- Text generation and streaming
- Reasoning output and settings
- Function tools and streamed tool inputs
- JSON and JSON Schema output
- Text and image file inputs
- URL citation sources
- Embeddings and image generation
- Reranking
- Transcription and speech generation
- Provider metadata, usage, abort signals, and raw stream chunks

Reranking is supported through `rerank()` with `phaseo.rerankingModel(modelId)`. Model and provider capabilities still vary. Managed file references, skills, and provider-executed tool definitions, results, or approval responses are not currently advertised by the provider. Application-executed function tools can use the AI SDK's normal execution and approval flow.

## Earlier AI SDK versions

- AI SDK 6: install `@phaseo/ai-sdk-provider@ai-sdk-v6`.
- AI SDK 5: install `@phaseo/ai-sdk-provider@ai-sdk-v5`.

If peer auto-installation is disabled, install the matching `ai` major (`ai@^7`, `ai@^6`, or `ai@^5`) separately.
