Pass `phaseo.imageModel(modelId)` to `generateImage`. Requests go to the Gateway's `/v1/images/generations` endpoint.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateImage } from "ai";

const result = await generateImage({
  model: phaseo.imageModel("openai/gpt-image-1"),
  prompt: "A minimalist poster of a lighthouse at dawn.",
  size: "1024x1024",
});

console.log(result.images[0].mediaType);
console.log(result.images[0].uint8Array.length);
console.log(result.providerMetadata);
```

## Read the result

Images the Gateway returns as URLs are converted to the AI SDK's file shape, so read `uint8Array` and `mediaType` on every image, whatever the provider returned.

- Available `size` values depend on the model.
- To reproduce an image later, store the prompt, model and parameters together with the image's metadata.
