Pass `phaseo.transcriptionModel(modelId)` to `transcribe` for speech to text, and `phaseo.speechModel(modelId)` to `generateSpeech` for text to speech. The provider uploads audio to `/v1/audio/transcriptions` as a multipart form and sends speech requests to `/v1/audio/speech`.

```ts
import { readFileSync, writeFileSync } from "node:fs";
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateSpeech, transcribe } from "ai";

const transcription = await transcribe({
  model: phaseo.transcriptionModel("openai/whisper-1"),
  audio: readFileSync("./audio.mp3"),
});

console.log(transcription.text);
console.log(transcription.providerMetadata);

const speech = await generateSpeech({
  model: phaseo.speechModel("openai/gpt-4o-mini-tts"),
  text: "Hello from Phaseo audio.",
  voice: "alloy",
  outputFormat: "mp3",
});

writeFileSync("./speech.mp3", Buffer.from(speech.audio.uint8Array));
console.log(speech.providerMetadata);
```

`audio` takes a `Buffer`, `Uint8Array`, `ArrayBuffer`, base64 string or `URL`. AI SDK 7 still exports the older `experimental_transcribe` and `experimental_generateSpeech` names as aliases.

## Handle long or failing audio

- Supported input and output formats depend on the model.
- Raise timeouts for long files, and keep uploads within the model's size limit (25 MB for most models).
- Retry transient `429` and `5xx` responses with backoff.
