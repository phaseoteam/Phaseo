Call the SDK's image method with a model and prompt to send `POST /v1/images/generations`. Each generated image comes back as a `url` or `b64_json` entry in `data`.

<CodeGroup>

```typescript TypeScript
const image = await client.generateImage({
  model: "openai/gpt-image-1",
  prompt: "A lighthouse at golden hour",
  size: "1024x1024",
  n: 1,
});
```

```python Python
image = client.generate_image({
    "model": "openai/gpt-image-1",
    "prompt": "A lighthouse at golden hour",
    "size": "1024x1024",
    "n": 1,
})
```

```go Go

})
if err != nil {

```

</CodeGroup>

| Language | Method | Notes |
| --- | --- | --- |
| TypeScript | `client.generateImage(request)` | `client.streamImage()` sends the same request with `stream: true` and yields partial-image events. |
| Python | `client.generate_image(request)` | `client.images.generate(request)` does the same. No image streaming helper. |
| Go | `client.CreateImage(ctx, req)` | Returns a `map[string]interface{}`. |
| C# | `client.GenerateImage(request)`, alias `CreateImage` | Returns a `Dictionary<string, object>?`. |
| PHP | `$client->generateImage($request)`, alias `createImage()` | Returns an array. |
| Ruby | `client.generate_image(...)`, alias `create_image` | Returns a Hash. |
| Java | `client.createImage(request)` | Takes a `Map` or Jackson `JsonNode`; returns a `JsonNode`. |
| Rust | No image helper | `client.post("/images/generations", &request)` sends the JSON body and returns a `PhaseoResponse`. |

## Parameters

Field names are the JSON body fields in every SDK.

| Field | Notes |
| --- | --- |
| `model`, `prompt` | Required. GPT Image prompts can be up to 32,000 characters. |
| `n` | Number of images, `1` to `10`. |
| `size` | For example `1024x1024`, `1024x1792` or `1792x1024`; supported sizes depend on the model. |
| `aspect_ratio`, `width`, `height` | Model-dependent alternatives to `size`. |
| `quality` | Model-dependent: `standard` or `hd` on `dall-e-3`; `auto`, `low`, `medium` or `high` on GPT Image models. |
| `output_format`, `output_compression` | `png`, `jpeg` or `webp`; compression (`0` to `100`) needs `jpeg` or `webp`. |
| `background` | `transparent`, `opaque` or `auto`. Transparent needs `png` or `webp`. |
| `response_format` | `url` or `b64_json`. GPT Image models reject this field. |
| `style` | Model-dependent, such as `vivid` or `natural` on `dall-e-3`. GPT Image models reject this field. |
| `stream`, `partial_images` | Stream up to `3` partial images, with `streamImage()` in TypeScript. |
| `user` | End-user tag for abuse tracking. |

The full schema is in the [Image generations API reference](../../api-reference/endpoint/images-generations).

## Response

`ImagesGenerationResponse`:

```json
{
  "data": [
    {
      "url": "https://example.com/generated_image.png"
    }
  ]
}
```

Models that return image bytes put them in `b64_json` instead of `url`.
