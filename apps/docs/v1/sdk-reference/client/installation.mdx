Add the Phaseo package for your language, set `PHASEO_API_KEY`, and send your first request. The [overview](./overview) lists each package's registry and published version.

<Steps>
<Step title="Install the package">

<Tabs>
<Tab title="TypeScript">

<CodeGroup>

```bash title="npm"
npm install @phaseo/sdk
```

```bash title="pnpm"
pnpm add @phaseo/sdk
```

```bash title="yarn"
yarn add @phaseo/sdk
```

</CodeGroup>

You need Node.js 18 or later, and TypeScript 4.5 or later for the type definitions.

</Tab>
<Tab title="Python">

<CodeGroup>

```bash title="pip"
pip install phaseo
```

```bash title="uv"
uv add phaseo
```

</CodeGroup>

You need Python 3.10 or later. For [realtime voice](./audio-realtime), install the extra: `pip install "phaseo[realtime]"`.

</Tab>
<Tab title="Go">

```bash
go get github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3@latest
```

You need Go 1.23 or later. Import the `v3` module path:

```go
import phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
```

</Tab>
<Tab title="C#">

```bash
dotnet add package Phaseo.Sdk
```

You need .NET 8 or later. The client is in the `PhaseoSdk` namespace.

</Tab>
<Tab title="PHP">

```bash
composer require phaseo/sdk
```

You need PHP 8.1 or later and Composer. Composer also installs Guzzle 7. The client class is `Phaseo\Sdk\Phaseo`.

</Tab>
<Tab title="Ruby">

<CodeGroup>

```bash title="gem"
gem install phaseo_sdk
```

```ruby title="Gemfile"
gem "phaseo_sdk"
```

</CodeGroup>

You need Ruby 3.0 or later. Load it with `require 'phaseo_sdk'`; the client is `PhaseoSdk::Phaseo`.

</Tab>
<Tab title="Java">

The `3.0.0` artifact on [Maven Central](https://repo.maven.apache.org/maven2/app/phaseo/phaseo-sdk/3.0.0/) has the older API, without the current retry, response metadata and parameter-checking APIs. To use the current SDK, build the pinned source. You need Java 17 or later, Maven 3.8 or later, and Git.

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
git checkout 1ff1119f41ceb3ac2c85ed605f6e1c4beca6e011
mvn -f packages/sdk/sdk-java/pom.xml -DskipTests install
```

Maven installs `app.phaseo:phaseo-sdk:3.0.0` in your local repository, including its Jackson dependency. Then add the dependency:

```xml
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-sdk</artifactId>
  <version>3.0.0</version>
</dependency>
```

</Tab>
<Tab title="Rust">

<CodeGroup>

```toml title="Cargo.toml"
[dependencies]
phaseo = "0.2"
serde_json = "1"
```

```bash title="cargo"
cargo add phaseo@0.2 serde_json
```

</CodeGroup>

You need Rust 1.86 or later. The crate is pre-`1.0`, and its API can still change between minor versions, so pin a compatible minor version in production.

</Tab>
</Tabs>

</Step>
<Step title="Set your API key">

Create a key with `phaseo keys create` in the [Phaseo CLI](../../guides/integrations/phaseo-cli) or in [API Keys](https://phaseo.app/settings/keys), then export it:

<CodeGroup>

```bash title="bash"
export PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
```

```powershell title="PowerShell"
$env:PHASEO_API_KEY = "phaseo_v1_sk_<kid>_<secret>"
```

</CodeGroup>

Keep the key on your server. Don't compile it into a desktop, mobile, browser, or other distributed client.

</Step>
<Step title="Send a request">

<CodeGroup>

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY!,
});

const response = await client.generateText({
  model: "openai/gpt-6-astra",
  messages: [{ role: "user", content: "Hello!" }],
});

console.log(response.choices[0].message.content);
```

```python Python
from phaseo import Phaseo
import os

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])

response = client.generate_text(
    {
        "model": "openai/gpt-6-astra",
        "messages": [{"role": "user", "content": "Hello!"}],
    }
)

print(response["choices"][0]["message"]["content"])
```

```go Go
client, err := phaseo.NewFromEnv() // reads PHASEO_API_KEY
if err != nil {
  panic(err)
}

chat, err := client.GenerateText(context.Background(), phaseo.ChatCompletionsRequest{
  Model:    "openai/gpt-6-astra",
  Messages: []map[string]interface{}{{"role": "user", "content": "Hello!"}},
})
if err != nil {
  panic(err)
}
fmt.Println(chat["choices"])
```

```csharp C#
using PhaseoSdk;

var client = new Phaseo(); // reads PHASEO_API_KEY

var chat = await client.GenerateText(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-6-astra",
    ["messages"] = new[]
    {
        new Dictionary<string, object> { ["role"] = "user", ["content"] = "Hello!" },
    },
});
```

```php PHP
<?php
require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo(); // reads PHASEO_API_KEY

$chat = $client->generateText([
    'model' => 'openai/gpt-6-astra',
    'messages' => [['role' => 'user', 'content' => 'Hello!']],
]);

echo $chat['choices'][0]['message']['content'];
```

```ruby Ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new # reads PHASEO_API_KEY

chat = client.generate_text(
  model: 'openai/gpt-6-astra',
  messages: [{ role: 'user', content: 'Hello!' }]
)
```

```java Java
import app.phaseo.sdk.Phaseo;
import java.util.List;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

var chat = client.createChatCompletion(Map.of(
    "model", "openai/gpt-6-astra",
    "messages", List.of(Map.of("role", "user", "content", "Hello!"))
));
System.out.println(chat.path("choices").path(0).path("message").path("content").asText());
```

```rust Rust
use phaseo::Phaseo;
use serde_json::json;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Phaseo::from_env()?;
    let response = client.chat_completions(&json!({
        "model": "openai/gpt-6-astra",
        "messages": [{ "role": "user", "content": "Hello!" }]
    }))?;

    println!("{}", response.body);
    Ok(())
}
```

</CodeGroup>

If you don't pass a key, the client reads `PHASEO_API_KEY` itself.

## Point the client at another base URL

<CodeGroup>

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({
  apiKey: "your-api-key",
  baseUrl: "https://api.phaseo.app/v1",
  timeoutMs: 30_000,
});
```

```python Python
from phaseo import Phaseo

client = Phaseo(
    api_key="your-api-key",
    base_url="https://api.phaseo.app/v1",
    timeout=30.0,
)
```

```go Go
client := phaseo.New(os.Getenv("PHASEO_API_KEY"), "https://api.phaseo.app/v1")
```

```rust Rust
let client = Phaseo::from_env()?.with_base_url("http://localhost:8787/v1")?;
```

</CodeGroup>

The timeout is in milliseconds in TypeScript (`timeoutMs`) and in seconds in Python (`timeout`). In Rust, you can also set `PHASEO_BASE_URL` (for example `http://localhost:8787/v1`) for `Phaseo::from_env()` to pick up. Rust accepts plain HTTP only when the host is exactly `localhost` or a loopback IP address; remote endpoints must use HTTPS.

The [overview](./overview#configure-the-client) lists every option per language. Next, see [Usage](./usage) for one example per endpoint, or the [API Reference](../../api-reference/introduction) for every field.
