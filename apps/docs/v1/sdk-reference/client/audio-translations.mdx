Upload speech to `POST /v1/audio/translations` to get English text back. The endpoint reads the audio only from a multipart `file` field and has no URL option, so only the TypeScript SDK can call it directly; every other language posts the form with its standard HTTP client.

<CodeGroup>

```typescript TypeScript
import { readFile } from "node:fs/promises";

const form = new FormData();
form.append("model", "openai/whisper-1");
form.append("file", new Blob([await readFile("interview.mp3")], { type: "audio/mpeg" }), "interview.mp3");

const translated = await client.generateTranslation(form as unknown as Record<string, unknown>);
console.log(translated.text);
```

```python Python
# generate_translation() can't upload audio yet, so post the form with HTTPX.
import os
import httpx

with open("interview.mp3", "rb") as audio:
    response = httpx.post(
        "https://api.phaseo.app/v1/audio/translations",
        headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
        data={"model": "openai/whisper-1"},
        files={"file": ("interview.mp3", audio, "audio/mpeg")},
        timeout=120,
    )
response.raise_for_status()
print(response.json()["text"])
```

```go Go
// CreateTranslation() sends JSON, so post the form with net/http and mime/multipart.
var body bytes.Buffer
form := multipart.NewWriter(&body)
_ = form.WriteField("model", "openai/whisper-1")
part, _ := form.CreateFormFile("file", "interview.mp3")
audio, _ := os.ReadFile("interview.mp3")
_, _ = part.Write(audio)
_ = form.Close()

req, _ := http.NewRequest("POST", "https://api.phaseo.app/v1/audio/translations", &body)
req.Header.Set("Authorization", "Bearer "+os.Getenv("PHASEO_API_KEY"))
req.Header.Set("Content-Type", form.FormDataContentType())

resp, err := http.DefaultClient.Do(req)
```


```java Java
// The SDK's JSON helpers don't encode multipart, so post the form with java.net.http.
import java.io.IOException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpRequest.BodyPublishers;
import java.net.http.HttpResponse.BodyHandlers;
import java.nio.file.Path;
import java.time.Duration;
import java.util.UUID;

String baseUrl = System.getenv().getOrDefault("PHASEO_BASE_URL", "https://api.phaseo.app/v1")
    .replaceAll("/+$", "");
String apiKey = System.getenv("PHASEO_API_KEY");
String boundary = "phaseo-" + UUID.randomUUID();
var body = BodyPublishers.concat(
    BodyPublishers.ofString("--" + boundary + "\r\nContent-Disposition: form-data; name=\"model\"\r\n\r\nopenai/whisper-1\r\n"),
    BodyPublishers.ofString("--" + boundary + "\r\nContent-Disposition: form-data; name=\"file\"; filename=\"interview.mp3\"\r\nContent-Type: audio/mpeg\r\n\r\n"),
    BodyPublishers.ofFile(Path.of("interview.mp3")),
    BodyPublishers.ofString("\r\n--" + boundary + "--\r\n")
);
var request = HttpRequest.newBuilder(URI.create(baseUrl + "/audio/translations"))
    .header("Authorization", "Bearer " + apiKey)
    .header("Content-Type", "multipart/form-data; boundary=" + boundary)
    .timeout(Duration.ofSeconds(60))
    .POST(body)
    .build();
var response = HttpClient.newHttpClient().send(request, BodyHandlers.ofString());
if (response.statusCode() < 200 || response.statusCode() >= 300) {
    throw new IOException("HTTP " + response.statusCode() + ": " + response.body());
}
System.out.println(response.body());
```

</CodeGroup>

| Language | SDK method | Can it upload a file? |
| --- | --- | --- |
| TypeScript | `client.generateTranslation(form)` | Yes. Pass a `FormData` body and the SDK sends it as multipart unchanged; the cast is needed because the method's type describes a JSON body. |
| Python | `client.generate_translation(request)` | No. It sends JSON, so post the form with HTTPX, as above. |
| Go | `client.CreateTranslation(ctx, req)` | No. It sends JSON, and the gateway rejects it with `file is required`. |
| C# | `client.CreateTranslation(request)` | No. It sends JSON, and the gateway rejects it with `file is required`. |
| PHP | `$client->generateTranslation($request)` | No. It sends JSON, and the gateway rejects it with `file is required`. |
| Ruby | `client.generate_translation(...)` | No. It sends JSON, and the gateway rejects it with `file is required`. |
| Java | None | No. Use `java.net.http.HttpClient` with a multipart body. |

Rust has no translation method, and its `post()` helper sends JSON only.

## Parameters

Field names are the form fields in every language.

| Field | Notes |
| --- | --- |
| `model` | Required. A translation model ID. |
| `file` | Required. Up to 25 MB, as `flac`, `mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `ogg`, `wav` or `webm`. |
| `prompt` | Context to guide the translation. |
| `temperature` | `0` to `1`. |
| `response_format` | `json`, `text`, `srt`, `verbose_json` or `vtt`. |

The full schema is in the [Translations API reference](/v1/api-reference/endpoint/audio-translations).

## Response

`AudioTranslationResponse`:

```json
{
  "text": "Hello world"
}
```
