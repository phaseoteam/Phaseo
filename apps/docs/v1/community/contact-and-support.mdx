Start at the [Phaseo Help Center](https://phaseo.app/help) for account, billing, API and feedback questions; the team routes each request to the right place.

| You want to | Go to |
| --- | --- |
| Get help with your account, billing or a failing request | [Help Center](https://phaseo.app/help) |
| Report a bug | [Help Center](https://phaseo.app/help), or a [bug report](https://github.com/phaseoteam/Phaseo/issues/new?template=bug.yml) on GitHub |
| Correct catalog data | [Contributing](../contributing/overview) |
| Report a security vulnerability | A private report under **Security -> Report a vulnerability** on the [GitHub repository](https://github.com/phaseoteam/Phaseo), or `security@phaseo.app`. Don't post it publicly. |
| Ask the community | [Discord](https://discord.gg/aQyywCvgZ5) |

## Include in a bug report

- The request ID: the response's `id` (`G-...`), the error's `generation_id`, or the `x-request-id` response header.
- What you sent, with the API key removed, and what you expected.
- The error code and message from the response body. The [error reference](../api-reference/errors) explains each code.
- Any relevant logs, with credentials and customer data removed.
