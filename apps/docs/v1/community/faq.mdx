## Where do I get an API key?

Create keys in the Phaseo dashboard. See [Authentication](../developers/authentication).

## What base URL should I use?

Use `https://api.phaseo.app/v1` as the base URL for the Gateway.

## Which endpoint should I start with?

Use `/responses` for most text workflows. `/chat/completions` and `/messages` are available for compatibility.

## How do I see supported models?

Use the [Models endpoint](../api-reference/endpoint/models.mdx) for the latest list.

## How does BYOK work?

Bring-your-own-key lets you use Phaseo routing and observability while your provider bills model usage directly. The first 250,000 completed requests each UTC month have no Phaseo service fee; after that, Phaseo charges 2.5% of provider-equivalent cost. See [Routing and fallbacks](../guides/routing-and-fallbacks#byok-considerations).
