Use this guide to keep your Anthropic SDK workflow while moving requests through Phaseo. Change the client configuration first, then verify model IDs and the Anthropic-specific behavior your application depends on.

## What changes

| Setting | Before | After |
| --- | --- | --- |
| Base URL | Anthropic default | `https://api.phaseo.app/v1` |
| API key | Anthropic key | `PHASEO_API_KEY` |
| Model | Anthropic model name | A Phaseo model ID returned by `GET /v1/models` |
| Messages call | Existing SDK call | Usually unchanged |

<Steps>
<Step title="Create a Phaseo API key">

Create a key in [Gateway Keys](https://phaseo.app/settings/keys) and make it available to your application as `PHASEO_API_KEY`.

</Step>

<Step title="Update the Anthropic client">

Point the SDK at the Phaseo base URL and use your Phaseo key.

<CodeGroup>
```typescript TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});

const response = await client.messages.create({
  model: "anthropic/claude-sonnet-4.6",
  max_tokens: 256,
  messages: [{ role: "user", content: "Reply with: migration ready" }],
});
```

```python Python
import os
import anthropic

client = anthropic.Anthropic(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.messages.create(
    model="anthropic/claude-sonnet-4.6",
    max_tokens=256,
    messages=[{"role": "user", "content": "Reply with: migration ready"}],
)
```

```bash cURL
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-4.6",
    "max_tokens": 256,
    "messages": [{"role": "user", "content": "Reply with: migration ready"}]
  }'
```
</CodeGroup>

</Step>

<Step title="Verify Anthropic-specific behavior">

Test system prompts, streaming, tool use, thinking or reasoning options, and structured output behavior with the exact models your application uses. Remove obsolete beta headers or request fields rather than carrying them into the new path blindly.

</Step>

<Step title="Roll out gradually">

Compare a representative prompt set across both configurations. Check output shape, latency, token usage, errors, and cost before shifting production traffic.

</Step>
</Steps>

## Migration checklist

- The Phaseo key is configured in every deployment environment.
- The Anthropic client points to `https://api.phaseo.app/v1`.
- Every production model ID is verified against `GET /v1/models`.
- Streaming and tool-use flows pass in staging.
- Anthropic-specific beta headers and parameters have been reviewed.
- Rollback remains a configuration-only key and endpoint change.
