Pick the guide for what you're changing: the platform your app calls (below), or the model it uses ([model migrations](../model-migrations)). If you're changing both, move the platform first and keep the model the same until the new path is verified.

For a tailored checklist, use the [Migration Assistant](https://phaseo.app/migrate).

## Platform migrations

Every platform guide follows the same order: swap the base URL and key, map model IDs, map the platform's features, then test and roll out with rollback kept to a base URL and key change.

| You call | Code signals | Guide |
| --- | --- | --- |
| OpenAI directly | `api.openai.com`, `OPENAI_API_KEY`, `AzureOpenAI` | [OpenAI SDK](./from-openai) |
| Anthropic directly | `api.anthropic.com`, `ANTHROPIC_API_KEY`, `@anthropic-ai/sdk` | [Anthropic SDK](./from-anthropic) |
| OpenRouter | `openrouter.ai`, `OPENROUTER_API_KEY`, `sk-or-v1` keys | [OpenRouter](./from-openrouter) |
| Vercel AI Gateway | `ai-gateway.vercel.sh`, `@ai-sdk/gateway`, bare string models in AI SDK calls | [Vercel AI Gateway](./from-vercel) |
| LLM Gateway | `api.llmgateway.io`, `LLM_GATEWAY_API_KEY` | [LLM Gateway](./from-llmgateway) |
| A LiteLLM proxy | `config.yaml` with `model_list`, `LITELLM_*` variables, port 4000 | [LiteLLM](./from-litellm) |
| Cloudflare AI Gateway | `gateway.ai.cloudflare.com`, `cf-aig-*` headers | [Cloudflare AI Gateway](./from-cloudflare) |
| Helicone | `*.helicone.ai`, `Helicone-Auth` | [Helicone](./from-helicone) |

To plan and check the rollout, use the [Migration Feature Checklist](./feature-parity-matrix).

## Migrate with a coding agent

<Prompt description="Ask a coding agent to plan and carry out the migration with you." icon="arrow-right-left" actions={["copy", "cursor"]}>
{`Migrate this project's AI requests to Phaseo Gateway.

1. Install the Phaseo skills: npx skills add https://phaseo.app/docs
   Use phaseo-migration, which has a guide for each source platform (and openrouter-to-phaseo-migration for a detailed OpenRouter move).
2. Find every place the project calls its current provider or gateway (OpenAI, Anthropic, OpenRouter, Vercel AI Gateway, LiteLLM or another), including environment variables, SDK clients, base URLs and model IDs.
3. Read the matching guide at https://phaseo.app/docs/v1/migration-guides and map each call to its Phaseo equivalent at https://api.phaseo.app/v1 with a server-side PHASEO_API_KEY.
4. Check every model ID against data[].id from GET /v1/models?format=openai. Do not assume IDs carry over unchanged.
5. List the changes and a rollback plan before editing. After editing, verify one normal request and one streaming request if the project streams.
6. Never print or commit API keys, and do not switch production traffic without my approval.`}
</Prompt>

## Model migrations

Use a [model migration guide](../model-migrations) when the integration stays the same but the model changes. Each one covers request parameter changes, shifts in prompt and reasoning behavior, structured-output and tool-calling differences, and how to roll out with a fallback.

For either kind of migration, check request parameters and endpoint behavior before comparing output quality, and run production-like evaluations before shifting live traffic.
