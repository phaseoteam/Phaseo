After the model calls a tool, send a follow-up request that repeats the conversation, the model's call, and your tool's result. The model then writes its answer, or calls another tool and you repeat. Use the endpoint whose message format your app already uses: `/v1/chat/completions` for OpenAI-style message loops, `/v1/responses` for the Responses API, `/v1/messages` for Anthropic-native apps.

<Tabs>
<Tab title="Chat Completions">

When `finish_reason` is `tool_calls`, run each call, then send the assistant message unchanged followed by one `role: "tool"` message per call, matched by `tool_call_id`. Send `tools` again.

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "What is the weather in Seattle?" },
    {
      "role": "assistant",
      "content": null,
      "tool_calls": [
        {
          "id": "call_123",
          "type": "function",
          "function": {
            "name": "get_weather",
            "arguments": "{\"city\":\"Seattle\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_123",
      "content": "72F and sunny"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    }
  ]
}
```

</Tab>
<Tab title="Responses">

Calls arrive as output items of type `function_call`. Send the call item back as input, followed by a `function_call_output` item with the same `call_id`.

```json
{
  "model": "openai/gpt-6-astra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [{ "type": "input_text", "text": "What's the weather in Seattle?" }]
    },
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Seattle\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "72F and sunny"
    }
  ]
}
```

</Tab>
</Tabs>

Before you run a call, validate its arguments; see [Tool Calling Safety](./tool-calling-safety).
