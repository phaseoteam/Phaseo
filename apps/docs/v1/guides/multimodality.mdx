Pick the endpoint for the output you want, then a model that supports that endpoint. The same model name can appear on several endpoints, and provider support differs on each.

| Modality | Endpoints | What they do |
| --- | --- | --- |
| Text | `/v1/responses`, `/v1/chat/completions`, `/v1/messages` | Conversational and structured text output. |
| Images | [`/v1/images/generations`](../api-reference/endpoint/images-generations.mdx), [`/v1/images/edits`](../api-reference/endpoint/images-edits.mdx) | Text-to-image generation and image editing. |
| Audio | [`/v1/audio/speech`](../api-reference/endpoint/audio-speech.mdx), [`/v1/audio/transcriptions`](../api-reference/endpoint/audio-transcriptions.mdx), [`/v1/audio/translations`](../api-reference/endpoint/audio-translations.mdx) | Text-to-speech, speech-to-text, and spoken-audio translation. |
| Realtime voice | `/v1/audio/realtime/sessions` | Live voice calls. See [Realtime voice](./realtime-voice.mdx). |
| Video | [`POST /v1/videos`](../api-reference/endpoint/video-create.mdx), `GET /v1/videos/{video_id}`, `GET /v1/videos/{video_id}/content`, `DELETE /v1/videos/{video_id}` | Create an asynchronous video job, poll its status, fetch the content, and delete the job. See [Video and batch jobs](./async-video-and-batch.mdx). |
| Music | [`/v1/music/generate`](../api-reference/endpoint/music-generate.mdx) | Music generation on supported providers. |
| OCR | [`/v1/ocr`](../api-reference/endpoint/ocr.mdx) | Text extraction from images. |
| Document parsing | [`/v1/parse`](../api-reference/endpoint/parse.mdx) | Ordered text, tables and layout from document images. See [Parse document images](./document-parsing.mdx). |

## Check which models support an endpoint

Call the [Models endpoint](../api-reference/endpoint/models.mdx): each model lists the `endpoints` it supports, and `GET /v1/models/{author}/{slug}/endpoints` shows each provider route for one model, with its modalities and supported parameters. The [Providers endpoint](../api-reference/endpoint/providers.mdx) lists provider coverage.

Check request bodies against the [API reference](../api-reference/introduction) for the endpoint before you ship.
