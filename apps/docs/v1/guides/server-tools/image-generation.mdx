Add `phaseo:image_generation` so the model can create an image while it answers. The model writes the image prompt; Phaseo calls the image model and returns the image to the model loop.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Design a wide product concept image for a compact desktop synthesizer.",
    "tools": [
      {
        "type": "phaseo:image_generation",
        "parameters": {
          "model": "openai/gpt-image-2",
          "quality": "high",
          "aspect_ratio": "16:9",
          "output_format": "png"
        }
      }
    ]
  }'
```

## Parameters

All parameters are optional.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `model` | string | `openai/gpt-image-2` | Image model. Set here, it overrides any model the main model asks for. |
| `quality` | string | Provider default | Quality hint, such as `low`, `medium`, or `high`. |
| `size` | string | Provider default | Image size hint. |
| `aspect_ratio` | string | Provider default | Aspect ratio, such as `1:1`, `16:9`, or `9:16`. |
| `background` | string | Provider default | Background mode hint. |
| `output_format` | string | Provider default | `png`, `jpeg`, or `webp`. |
| `output_compression` | integer | Provider default | Compression hint, clamped to `0` to `100`. |
| `moderation` | string | Provider default | Provider moderation hint. |

## What the model sends

A `prompt` (or `description`, treated the same). It can also send `model`, used only when the tool doesn't set one, and any of the other parameters above, which replace the tool's values for that call.

## What the tool returns

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "imageUrl": "https://...",
  "mime_type": "image/png"
}
```

Some providers return `b64_json` with base64 image data instead of `imageUrl`. If the call has no prompt, the model gets `image_generation_invalid_request`; if the image model fails, `image_generation_failed`.

## Usage and pricing

Each image adds 1 to `usage.server_tool_use.image_generation_requests` and can be billed with `server_tool_image_generation_requests`. The image model is billed at its own rates, as a separate line on the request's bill. A paid image model needs credits even when the calling model is free.
