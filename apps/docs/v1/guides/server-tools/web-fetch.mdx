Add `phaseo:web_fetch` so the model can read a known URL, such as a documentation page, article, or changelog. The model supplies the `url`; Phaseo fetches the page and returns its text, trimmed to a size limit, and the model can fetch more pages before it answers.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Summarize https://phaseo.app/docs/v1/guides/tool-calling" }
    ],
    "tools": [
      { "type": "phaseo:web_fetch" }
    ]
  }'
```

## Parameters

```json
{
  "type": "phaseo:web_fetch",
  "parameters": {
    "engine": "direct",
    "max_chars": 12000,
    "allowed_domains": ["phaseo.app"],
    "blocked_domains": ["internal.example.com"]
  }
}
```

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `engine` | string | `direct` | `auto`, `native`, `direct`, `exa`, `parallel`, or `firecrawl`. See [Choose an engine](#choose-an-engine). |
| `max_chars` | integer | `12000` | Characters of page text returned to the model, up to `100000`. |
| `max_content_tokens` | integer | None | Used instead of `max_chars` when `max_chars` is omitted. Also the size limit for `native`. |
| `max_uses` | integer | `10` | Fetch calls per request, up to `100`. |
| `allowed_domains` | string[] | None | Fetch only from these domains. The model can narrow this list in a call but not widen it. |
| `blocked_domains` | string[] | None | Never fetch from these domains. Alias: `excluded_domains`. |

## What the model sends

Each call has a `url`. The model can also send `engine`, `max_chars`, `max_content_tokens`, and the domain lists.

## Choose an engine

| Engine | What runs |
| --- | --- |
| `auto` | Anthropic's native fetch on `/v1/messages`. On other endpoints, Exa when it's enabled, otherwise `direct`. |
| `direct` | Phaseo fetches the page itself and reduces HTML to plain text. |
| `exa` | Exa content extraction. |
| `parallel` | Parallel Extract. |
| `firecrawl` | Firecrawl Scrape. |
| `native` | Anthropic's `web_fetch_20260209` tool, on `/v1/messages` only. On other endpoints the request is rejected; use `direct` or a managed engine. |

If a managed engine isn't enabled, the call returns `fetch_not_configured` to the model.

Only HTTP(S) URLs work. `direct` accepts only text-like content types, such as HTML, plain text, and JSON, and returns `unsupported_content_type` for anything else. It follows up to 5 redirects and checks each one against your domain lists.

### Native Anthropic fetch

```json
{
  "model": "anthropic/claude-sonnet-4.6",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "Read the docs page and summarize the limits." }
  ],
  "tools": [
    {
      "type": "phaseo:web_fetch",
      "parameters": {
        "engine": "native",
        "max_content_tokens": 9000,
        "allowed_domains": ["phaseo.app"]
      }
    }
  ],
  "tool_choice": { "type": "tool", "name": "phaseo:web_fetch" }
}
```

## What the tool returns

```json
{
  "provider": "fetch",
  "engine": "direct",
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "text": "...",
  "truncated": false,
  "returned_chars": 8421
}
```

Check `truncated` before assuming the model saw the whole page. For a worked example, see [Tool grounding with web fetch](../../cookbook/tool-grounding-with-web-fetch).

## Usage and pricing

Each fetch adds 1 to `usage.server_tool_use.web_fetch_requests`. Phaseo bills each managed fetch through Exa, Parallel or Firecrawl at $0.001, unless the model's price card sets its own `server_tool_web_fetch_requests` price; direct fetches are free. Fetches through paid engines need credits even when the model is free. Native fetch is billed with `native_web_fetch_requests` where the model's price card defines it.
