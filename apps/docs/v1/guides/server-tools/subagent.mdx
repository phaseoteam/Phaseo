Add `phaseo:subagent` so the main model can hand a self-contained task to a worker model, often a smaller or faster one, in the same request. The main model describes the task; Phaseo runs the worker and returns its result, and the main model finishes the answer.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5",
    "messages": [
      { "role": "user", "content": "Compare these release notes and summarize the breaking changes." }
    ],
    "tools": [
      {
        "type": "phaseo:subagent",
        "parameters": {
          "model": "openai/gpt-6-astra",
          "instructions": "Return concise findings for the main model. Do not address the end user directly.",
          "max_uses": 3,
          "max_completion_tokens": 1200
        }
      }
    ]
  }'
```

## Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `model` | string | The request's model | The worker model. |
| `instructions` | string | Built-in worker instructions | Extra instructions for the worker. |
| `max_uses` | integer | `1` | Subagent calls per request. |
| `max_completion_tokens` | integer | `1400` | Output tokens for each worker reply. Values below `1024` are raised to `1024`. `max_tokens` is accepted as an older alias. |
| `reasoning` | object | Provider default | Reasoning settings, passed on where the worker model supports them. |
| `temperature` | number | Provider default | Sampling temperature for the worker call. |

The worker never receives the conversation: put everything it needs in the task.

## What the model sends

A `task_description` with the complete task, context, and expected output, plus an optional short `task_name`:

```json
{
  "task_description": "Extract the three highest-risk migration steps from the supplied plan."
}
```

`task`, `prompt`, or `input` are accepted in place of `task_description`.

## What the tool returns

```json
{
  "status": "ok",
  "model": "openai/gpt-6-astra",
  "outcome": "The highest-risk steps are schema migration, traffic cutover, and rollback verification."
}
```

If the call can't run, the model gets `subagent_invalid_request` (no task), `subagent_max_uses_exceeded`, or `subagent_request_failed`.

## Usage and pricing

Each call adds 1 to `usage.server_tool_use.subagent_requests` and can be billed with `server_tool_subagent_requests`. The worker's tokens are added to the request's usage and priced at the worker model's rates. To get a review rather than delegate work, use [Advisor](./advisor).
