[eve](https://eve.dev) agents accept any AI SDK language model. Pass a model from the [Phaseo AI SDK provider](./ai-sdk.mdx) and every model call goes through Phaseo, with your routing, keys, budgets and logs.

## Install

Install the provider in your eve project. eve uses AI SDK 7, so use version 2.0.1 or later:

```bash
npm install @phaseo/ai-sdk-provider
```

Set `PHASEO_API_KEY` in `.env.local` for `eve dev`, and in the server environment of every deployment.

## Configure the agent

```ts title="agent/agent.ts"
import { defineAgent } from "eve";
import { phaseo } from "@phaseo/ai-sdk-provider";

export default defineAgent({
	model: phaseo("openai/gpt-6-luna"),
	modelContextWindowTokens: 1_050_000,
	reasoning: "low",
});
```

Use model ids from the [Models endpoint](../../api-reference/endpoint/models.mdx), and set `modelContextWindowTokens` to the model's `limits.input_tokens` from the same endpoint. eve can't look up the context window of a model object, and it uses this number to decide when to compact the conversation.

## Pick a model per turn

`defineDynamic` runs before each model call. Return a selection object so each model keeps its own context window:

```ts title="agent/agent.ts"
import { defineAgent } from "eve";
import { defineDynamic } from "eve/models";
import { phaseo } from "@phaseo/ai-sdk-provider";

export default defineAgent({
	model: defineDynamic((ctx) =>
		ctx.session.auth.initiator?.attributes.plan === "enterprise"
			? { model: phaseo("openai/gpt-6-sol"), modelContextWindowTokens: 1_050_000 }
			: { model: phaseo("openai/gpt-6-luna"), modelContextWindowTokens: 1_050_000 },
	),
});
```

## Notes

- Pass a model object such as `phaseo("openai/gpt-6-luna")`. A plain model id string is not sent to Phaseo.
- Tools, streaming, reasoning, compaction and prompt caching work through Phaseo. Prompt cache reads appear in eve's usage events and in Phaseo logs.
- eve leaves the cost of each run empty for model objects. See the cost on the Phaseo Usage page or in Logs.
- eve's `/login` connection only works on your machine. Deployments need `PHASEO_API_KEY`.
