Create a `ChatOpenAI` model with your Phaseo key and `base_url="https://api.phaseo.app/v1"`, and LangChain chains, agents, and LangGraph workflows call models through Phaseo.

## Install

```bash
pip install -U langchain langchain-openai
```

## Point ChatOpenAI at Phaseo

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

A printed sentence means the setup works.

## Use it in LangGraph

Pass the same `llm` to your graph nodes or agent builder:

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## Known limits

- This path uses [Chat Completions](../../api-reference/endpoint/chat-completions.mdx), so only Phaseo features available on `/v1/chat/completions` work, including [tool calling](../tool-calling.mdx) and [routing and fallbacks](../routing-and-fallbacks.mdx).
- For Responses-only server tools such as `phaseo:apply_patch`, call Phaseo directly or use the [OpenAI SDK](./openai-sdk.mdx).
- For tracing with LangSmith, see [Observability](./observability.mdx).
