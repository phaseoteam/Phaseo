Call Phaseo's OpenAI-compatible endpoints from Effect with its HTTP client, or wrap the [OpenAI SDK](./openai-sdk.mdx) in an Effect layer. Use Effect's own OpenAI provider package only if your installed version accepts a custom base URL.

## Install

```bash
npm install effect @effect/platform
```

## Call Phaseo with Effect HTTP

```ts
import { FetchHttpClient, HttpClient, HttpClientRequest } from "@effect/platform";
import { Config, Effect, Redacted } from "effect";

const generate = Effect.gen(function* () {
	const apiKey = yield* Config.redacted("PHASEO_API_KEY");
	const client = yield* HttpClient.HttpClient;

	const request = HttpClientRequest.post(
		"https://api.phaseo.app/v1/chat/completions",
	).pipe(
		HttpClientRequest.bearerToken(Redacted.value(apiKey)),
		HttpClientRequest.jsonBody({
			model: "openai/gpt-6-astra",
			messages: [{ role: "user", content: "Reply with only: ok" }],
		}),
	);

	return yield* client.execute(request).pipe(
		Effect.flatMap((response) => response.json),
	);
});

const runnable = generate.pipe(Effect.provide(FetchHttpClient.layer));
```

Running it returns a Chat Completions response whose message says `ok`.

## Wrap the OpenAI SDK in an Effect layer

If you already use the OpenAI SDK, keep the Phaseo configuration in one place:

```ts
import OpenAI from "openai";
import { Config, Effect } from "effect";

const makeClient = Effect.gen(function* () {
	const apiKey = yield* Config.string("PHASEO_API_KEY");

	return new OpenAI({
		apiKey,
		baseURL: "https://api.phaseo.app/v1",
	});
});
```

Build a custom layer on top of this when you want a provider-style abstraction across your app.

## Known limits

- Keep model IDs in Phaseo format, such as `openai/gpt-6-astra`.
- Test [streaming](../streaming.mdx) and tool calls with your exact Effect package versions before production.
