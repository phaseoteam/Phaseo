Point the official OpenAI SDK at Phaseo by changing three things: the API key, the base URL (`https://api.phaseo.app/v1`), and the model ID.

## Install

<CodeGroup>

```bash TypeScript
npm install openai
```

```bash Python
pip install openai
```

</CodeGroup>

## Point the client at Phaseo

<CodeGroup>

```ts TypeScript
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Write one sentence about reliable model routing.",
});

console.log(response.output_text);
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Write one sentence about reliable model routing.",
)

print(response.output_text)
```

</CodeGroup>

A printed sentence means the key and base URL work. The request also appears in **Settings → Usage → Logs**.

## Use Chat Completions

Code that calls Chat Completions works with the same client:

```ts
const completion = await client.chat.completions.create({
	model: "openai/gpt-6-astra",
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## Known limits

- Use Phaseo model IDs, with the provider prefix: `openai/`, `anthropic/`, `google/`, and so on. See [Responses](../../api-reference/endpoint/responses.mdx) and [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) for the full request shapes.
- [Server tools](../server-tools/index.mdx) use Phaseo tool names, such as `phaseo:web_search`.
- For Anthropic-style `/v1/messages` clients, use the [Anthropic SDK](./anthropic-sdk.mdx) guide.
