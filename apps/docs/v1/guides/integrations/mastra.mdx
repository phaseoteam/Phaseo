Create an AI SDK OpenAI provider with your Phaseo key and `baseURL: "https://api.phaseo.app/v1"`, and pass its models to Mastra agents and workflows.

## Install

```bash
npm install @mastra/core @ai-sdk/openai ai
```

## Point a Mastra agent at Phaseo

```ts
import { Agent } from "@mastra/core/agent";
import { createOpenAI } from "@ai-sdk/openai";

const phaseo = createOpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
	compatibility: "compatible",
});

export const agent = new Agent({
	name: "support-agent",
	instructions: "Answer in two short paragraphs.",
	model: phaseo("openai/gpt-6-astra"),
});
```

Use the base URL only, without `/chat/completions` or `/responses`. Run the agent once with a short prompt and confirm the request appears in **Settings → Usage → Logs**.

## Known limits

- How Mastra agents behave depends on the AI SDK provider. Test [tool calling](../tool-calling.mdx) and streaming before production.
- To prefer certain providers, set Phaseo routing controls on the request or in a [preset](../presets.mdx).
