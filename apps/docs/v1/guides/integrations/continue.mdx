Run `phaseo continue` to write a Continue config that points at Phaseo, or add the same model entry and secret to your existing config. The IDE extensions and the `cn` CLI share the config.

## Set up with the Phaseo CLI

```bash
phaseo login
phaseo continue --model anthropic/claude-sonnet-5.5
```

If `~/.continue/config.yaml` and `~/.continue/.env` don't exist, setup creates a `Phaseo CLI: Continue API Key` (90-day expiry, $100 monthly spend limit) and writes both files. Without `--model`, it uses `anthropic/claude-sonnet-4.6`.

```yaml ~/.continue/config.yaml
# Managed by Phaseo CLI
name: Phaseo
version: 1.0.0
schema: v1
models:
  - name: "anthropic/claude-sonnet-5.5 via Phaseo"
    provider: openai
    model: "anthropic/claude-sonnet-5.5"
    apiBase: https://api.phaseo.app/v1
    apiKey: ${{ secrets.PHASEO_API_KEY }}
    useResponsesApi: false
    roles: [chat, edit, apply]
```

The key goes in `~/.continue/.env` as `PHASEO_API_KEY`. `useResponsesApi: false` keeps Continue on Phaseo's Chat Completions endpoint.

<Warning>
Continue's global `.env` is plaintext. Never commit it. IDE extensions don't inherit shell environment variables, which is why the CLI uses Continue's [local secrets](https://docs.continue.dev/faqs#managing-local-secrets-and-environment-variables) file.
</Warning>

## Configure Continue manually

If either file already has your own settings, setup stops without changing it. Add the model entry above to your `config.yaml`, and add `PHASEO_API_KEY=<key>` to your `.env`, using `phaseo integrations credential continue` or any Phaseo API key. See Continue's [OpenAI provider](https://docs.continue.dev/customize/model-providers/top-level/openai) docs for the other fields.

## Check it works

In VS Code or JetBrains, reload the window, open Continue, select **Phaseo**, and ask it to reply with `PHASEO_CONTINUE_OK`. In the CLI, run `cn` (use `/config` if another config is active) and send the same prompt. Confirm the request appears in **Settings → Usage → Logs**.

## Remove Phaseo

```bash
phaseo integrations remove continue
```

This revokes the key and deletes both files only if they still start with the Phaseo CLI marker. Entries you merged yourself are left alone.

## Fix common problems

### Phaseo doesn't appear

Reload the IDE and check that `config.yaml` has the top-level `name`, `version`, and `schema` fields.

### Continue reports a missing secret

Check that `~/.continue/.env` has the key from `phaseo integrations credential continue`, then restart the IDE.

### Continue calls the Responses API

Keep `useResponsesApi: false` on the Phaseo model entry.
