Run `phaseo opencode` to add a Phaseo provider with every compatible Phaseo model to OpenCode, or add a `phaseo` provider to `opencode.json` yourself.

## Set up with the Phaseo CLI

```bash
phaseo login
phaseo opencode --model openai/gpt-5.6-terra
```

If OpenCode is missing, the CLI shows the official install command and asks before running it. Setup then:

- adds a global `phaseo` provider with every active Phaseo text model that works with Chat Completions. It updates your global `opencode.jsonc` if there is one, otherwise `~/.config/opencode/opencode.json`, and leaves your other settings alone;
- creates a `Phaseo CLI: OpenCode API Key` that expires after 90 days and has a $100 monthly spend limit, and stores it in OpenCode's credential store. The CLI keeps its own copy in the OS credential store. Run `phaseo opencode` again to replace an expired key.

Use `--catalog default` to add only the selected model, or `--dry-run` to preview the changes.

## Configure OpenCode manually

Add the provider to `opencode.json` in your project, or to your global OpenCode config:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-6-astra",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-6-astra": { "name": "GPT-6 Astra" },
        "openai/gpt-5.4-mini": { "name": "GPT-5.4 Mini" },
        "anthropic/claude-sonnet-5.5": { "name": "Claude Sonnet 5.5" }
      }
    }
  }
}
```

Export `PHASEO_API_KEY`, and add or remove entries in `models` to choose which Phaseo models OpenCode lists.

## Check it works

Restart OpenCode, choose a Phaseo model from `/models`, and send a short prompt before you start file-editing work. Confirm the request appears in **Settings → Usage → Logs**.

## Remove Phaseo

```bash
phaseo integrations remove opencode
```

This removes only the Phaseo provider and its stored credential, then revokes the key.

## Fix common problems

| Problem | Fix |
| --- | --- |
| A model is rejected | Check the exact ID with the [Models endpoint](../../api-reference/endpoint/models.mdx). |
| Authentication fails | Rerun `phaseo opencode` and check `opencode auth list`. |

To let OpenCode read the Phaseo docs during a session, add the [Docs MCP](./docs-mcp.mdx) server.
