Run `phaseo muse` to start a Muse Code session through Phaseo. This runner is the only supported way to use Phaseo with Muse Code.

## Run Muse Code through the Phaseo CLI

```bash
phaseo login
phaseo muse --model meta/muse-spark-1.3
```

The runner creates a dedicated key, writes Muse settings under a temporary `XDG_CONFIG_HOME`, launches `muse`, and deletes the settings when Muse Code exits. Put Muse Code's own flags after `--`.

| Flag | Effect |
| --- | --- |
| `--model <id>` | Model to use. Defaults to `openai/gpt-5.6-terra`. |
| `--catalog all` | Lists every active Phaseo text model, not just the selected one. |
| `--dry-run --json` | Shows the launch plan without creating a key or starting Muse Code. |
| `--skip-install` | Skips the install check. |

`phaseo run muse ...` is the long form of the same command.

On macOS and Linux, the first interactive run offers to install Muse Code with Meta's installer. On Windows, install Muse Code yourself, check `muse --version`, and use `--skip-install`.

## Why there's no manual setup

Muse Code is built around Meta's own [Model API](https://ai.meta.com/llama) and sign-in. Meta doesn't document a stable setting for pointing it at another OpenAI-compatible endpoint, so use the runner. Don't copy the runner's temporary settings into your normal Muse profile; they're an internal detail and are deleted when the runner exits.

To call a Phaseo model from your own code instead, use the [OpenAI SDK](./openai-sdk.mdx) with `https://api.phaseo.app/v1` and a Phaseo API key.

## Check it works

Send a short prompt and confirm the request appears in **Settings → Usage → Logs**.

## Fix common problems

### Muse Code isn't installed

Install Muse Code yourself, check `muse --version`, and rerun with `--skip-install`.

### The model isn't listed

Use `--catalog all`, or pass the model ID with `--model`. Phaseo doesn't need model discovery.
