Run `phaseo minimax` to start a MiniMax Code (`mcode`) session through Phaseo, or add Phaseo with `mcode provider add` to keep it in every session.

## Run MiniMax Code through the Phaseo CLI

```bash
phaseo login
phaseo minimax --model openai/gpt-5.6-terra
```

The runner creates a dedicated key, sets `MINIMAX_DATA_DIR` to a temporary directory, adds a Phaseo provider there with `mcode provider add`, launches `mcode`, and deletes the directory when `mcode` exits. Your normal `~/.minimax` configuration isn't changed, and the key is passed only to the provider setup process. Put MiniMax Code's own flags after `--`.

| Flag | Effect |
| --- | --- |
| `--model <id>` | Model to use. Defaults to `openai/gpt-5.6-terra`. |
| `--catalog all` | Registers every active Phaseo text model that works with Chat Completions. |
| `--dry-run --json` | Shows the install and launch plan without creating a key. |
| `--skip-install` | Skips the install check. |

`phaseo run minimax ...` is the long form of the same command.

If `mcode` is missing, the first interactive run offers to install it with MiniMax's official installer (the PowerShell installer on Windows). If you manage MiniMax Code yourself, install it, check `mcode --version`, and rerun with `--skip-install`.

## Configure MiniMax Code manually

To keep a Phaseo provider, add it with MiniMax Code's own command:

```bash
export MCODE_PROVIDER_API_KEY="your_phaseo_api_key"
mcode provider add \
  --name "Phaseo" \
  --base-url "https://api.phaseo.app/v1" \
  --api-format openai-completions \
  --model "openai/gpt-5.6-terra" \
  --use
```

MiniMax Code saves the provider in its data directory.

## Check it works

Send a short prompt and confirm the request appears in **Settings → Usage → Logs**.

## Fix common problems

### MiniMax Code isn't installed

Run the command in an interactive terminal to approve the official installer, or install MiniMax Code yourself and rerun with `--skip-install`.

### The provider or model isn't listed

Use `phaseo minimax --catalog all`, or pass the model ID with `--model`.

### You need ACP instead of the interactive CLI

`phaseo minimax` runs the interactive CLI. MiniMax Code also runs as an ACP process with `mcode acp`; use MiniMax Code's ACP configuration when your editor or host speaks ACP directly.
