Create an `OpenAILike` LLM with your Phaseo key and `api_base="https://api.phaseo.app/v1"`, then set it as LlamaIndex's default so generation in your RAG workflows goes through Phaseo.

## Install

```bash
pip install llama-index llama-index-llms-openai-like llama-index-embeddings-openai-like
```

## Point LlamaIndex at Phaseo

```python
import os
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    is_chat_model=True,
)

response = llm.complete("Write one sentence about retrieval quality.")
print(response)
```

A printed sentence means the setup works. `OpenAILike` is LlamaIndex's class for third-party OpenAI-compatible APIs.

## Use it in an index

```python
from llama_index.core import Settings

Settings.llm = llm
```

Then build or query your index as usual.

## Known limits

- LlamaIndex defaults don't point at Phaseo. Set the generation and embedding models explicitly.
- For Phaseo [embeddings](../../api-reference/endpoint/embeddings.mdx), configure the embedding model with a Phaseo model ID and the same base URL.
