Install `@phaseo/ai-sdk-provider` and pass `phaseo("<model id>")` as the model in any AI SDK call. The provider reads `PHASEO_API_KEY` from the environment.

## Install

```bash
npm install @phaseo/ai-sdk-provider
```

The unversioned package follows npm's `latest` tag, which is the AI SDK 7 line, and declares `ai@^7` as a peer dependency that npm installs for you. For an older AI SDK, install the matching tag:

| AI SDK | Provider contract | Install |
| --- | --- | --- |
| 7 (current) | `ProviderV4` (provider 2.x) | `npm install @phaseo/ai-sdk-provider` |
| 6 | `ProviderV3` (provider 1.x, maintenance) | `npm install @phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `ProviderV2` | `npm install @phaseo/ai-sdk-provider@ai-sdk-v5` |

If your package manager doesn't install peer dependencies, also install the matching `ai` major (`ai@^7`, `ai@^6`, or `ai@^5`).

When AI SDK 8 is stable, Phaseo will mark provider 1.x as deprecated on npm. Existing releases won't be removed, and any end of support will be announced separately.

## Generate text

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Summarize this in one sentence.",
});

console.log(result.text);
```

The same code works on all three lines. Use model IDs from the [Models endpoint](../../api-reference/endpoint/models.mdx); each capability still depends on the model and upstream provider.

## What each line supports

| Feature | AI SDK 7 (provider 2.x) | AI SDK 5 |
| --- | --- | --- |
| Text generation and streaming | Yes | Yes |
| Function tools and tool-result round trips | Yes, including streamed tool inputs | Yes |
| JSON and JSON Schema structured output | Yes | Yes |
| Embeddings and image generation | Yes | Yes |
| Transcription and speech | Yes | Yes |
| Reranking | Yes | No |
| Provider-agnostic reasoning settings and output | Yes | |
| Text and image file inputs (V7 tagged file data) | Yes | |
| URL citation sources | Yes | |
| Provider metadata, usage, request headers, abort signals, raw stream chunks | Yes | |

The AI SDK 7 column is what provider 2.x implements and tests against AI SDK 7's native v4 contracts. Reranking is also available on the AI SDK 6 line.

## Rerank documents

Use the AI SDK `rerank()` helper with `phaseo.rerankingModel(modelId)`:

```ts
import { rerank } from "ai";
import { phaseo } from "@phaseo/ai-sdk-provider";

const result = await rerank({
	model: phaseo.rerankingModel("voyage/rerank-2"),
	query: "Which document is about TypeScript?",
	documents: [
		"TypeScript adds static types to JavaScript.",
		"Rust is a systems programming language.",
	],
	topN: 1,
});
```

## Known limits

- The provider doesn't advertise `ProviderV4` features that need Phaseo API surfaces that don't exist yet: managed file uploads and references, skills, and provider-executed tool definitions, results, or approval responses.
- Function tools your app runs still use the AI SDK's normal execution and approval flow.
- Provider-specific or custom prompt parts that aren't supported fail with a clear error instead of being dropped.
