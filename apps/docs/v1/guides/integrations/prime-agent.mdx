Run `phaseo prime-agent` to add a Phaseo provider with every compatible Phaseo model to Prime Agent. Prime Agent runs on macOS and Linux; on Windows, install it and run setup inside WSL.

## Set up with the Phaseo CLI

```bash
phaseo login
phaseo prime-agent
```

If Prime Agent is missing, the CLI shows the official installer command and asks before running it. Setup then creates a `Phaseo CLI: Prime Agent API Key` (90-day expiry, $100 monthly spend limit) and writes a `phaseo` provider to `~/.prime/agent/models.json`. The provider lists every active Phaseo text model that works with Chat Completions.

| Flag | Effect |
| --- | --- |
| `--model <id>` | Sets the initial model. Defaults to `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | Adds only the selected model. |
| `--dry-run` | Shows the file changes without making them. |

The provider gets its key at request time with Prime Agent's command-backed key format, so no plaintext key is written to the file:

```text
!phaseo integrations credential prime-agent
```

## Check it works

```bash
prime-agent
```

Open `/model`, select the `phaseo` provider, and send a short prompt. Confirm the request appears in **Settings → Usage → Logs**.

## Remove Phaseo

```bash
phaseo integrations remove prime-agent
```

This removes only the Phaseo provider and revokes the key.
