Run `phaseo claude-code` to send Claude Code's requests through Phaseo, or set three environment variables yourself. Claude Code calls Anthropic-style `/v1/messages`, which Phaseo serves as [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx), so your prompts don't change.

## Set up with the Phaseo CLI

```bash
phaseo login
phaseo claude-code
claude
```

If Claude Code is missing, the CLI shows the official install command and asks before running it. Setup then:

- creates a `Phaseo CLI: Claude Code API Key` that expires after 90 days and has a $100 monthly spend limit, and keeps it in the OS credential store;
- sets `ANTHROPIC_BASE_URL` and an `apiKeyHelper` in `~/.claude/settings.json`. The helper fetches the key from the CLI and creates a new one when the old one expires, so no plaintext key is written to Claude Code settings.

Setup stops without changes if `settings.json` already has a different `ANTHROPIC_BASE_URL`, a different `apiKeyHelper`, or a non-empty `ANTHROPIC_API_KEY` or `ANTHROPIC_AUTH_TOKEN`. `--model` isn't supported for Claude Code; set `ANTHROPIC_MODEL` instead (see below).

## Configure Claude Code manually

Set these in the shell you start Claude Code from:

<CodeGroup>

```bash bash
export ANTHROPIC_BASE_URL="https://api.phaseo.app"
export ANTHROPIC_AUTH_TOKEN="your_phaseo_api_key"
export ANTHROPIC_API_KEY=""
```

```powershell PowerShell
$env:ANTHROPIC_BASE_URL = "https://api.phaseo.app"
$env:ANTHROPIC_AUTH_TOKEN = "your_phaseo_api_key"
$env:ANTHROPIC_API_KEY = ""
```

</CodeGroup>

Claude Code sends `ANTHROPIC_AUTH_TOKEN` as an `Authorization` header, which Phaseo accepts. To fix a default model, set `ANTHROPIC_MODEL` to a Phaseo model ID from [Models](../../api-reference/endpoint/models.mdx).

## Check it works

Run `claude`, send a short prompt, and confirm the request appears in **Settings → Usage → Logs**.

## Remove Phaseo

```bash
phaseo integrations remove claude-code
```

This removes the base URL, key helper, and the empty credential variables Phaseo added to `settings.json`, then revokes the key. For a manual setup, unset the three environment variables.
