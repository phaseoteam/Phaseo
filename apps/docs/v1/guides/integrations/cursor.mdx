Run `phaseo cursor` to create a key, then turn on Cursor's OpenAI API key and **Override OpenAI Base URL** settings. This routes Cursor's chat models through Phaseo; features that use Cursor's own models, such as tab completion, may keep using Cursor's infrastructure.

## Set up with the Phaseo CLI

```bash
phaseo login
phaseo cursor --model openai/gpt-5.6-terra
```

The CLI creates a `Phaseo CLI: Cursor API Key` that expires after 90 days and has a $100 monthly spend limit, and prints the settings below. Run `phaseo cursor` again for a new key after it expires. The CLI doesn't edit Cursor's credential store.

## Configure Cursor

1. Open **Cursor Settings → Models**.
2. Find the **OpenAI API Key** section and enable it.
3. Paste the key from `phaseo integrations credential cursor`, or any Phaseo API key.
4. Enable **Override OpenAI Base URL** and enter `https://api.phaseo.app/v1`, with no trailing slash.
5. Add or enable the Phaseo model you want.

| Cursor field | Value |
| --- | --- |
| OpenAI API Key | Output of `phaseo integrations credential cursor` |
| Override OpenAI Base URL | `https://api.phaseo.app/v1` |
| Model | A Phaseo model ID that Cursor accepts |

Cursor's key and Base URL settings are global, not per provider: the enabled key and Base URL decide where every OpenAI-family request goes, and the model name is forwarded as is. Some releases save the key without a **Verify** button; test with a new chat instead. See Cursor's [API key docs](https://docs.cursor.com/settings/api-keys).

## Check it works

1. Keep the key and Base URL override enabled.
2. Select the model in Cursor's model picker and start a new chat.
3. Ask it to reply with `PHASEO_CURSOR_OK`.
4. Confirm the request appears in **Settings → Usage → Logs**.

## Remove Phaseo

Disable the OpenAI API key and Base URL override in **Cursor Settings → Models**, then revoke the key:

```bash
phaseo integrations remove cursor
```

The CLI can't clear Cursor's credential storage. If the key still shows as configured, delete it in Cursor's Models settings.

## Fix common problems

### Cursor-hosted models stop working

Cursor applies the Base URL override to every OpenAI-family model. Turn **Override OpenAI Base URL** off before you switch back to a Cursor-hosted model.

### The model is rejected

Cursor can reject IDs that collide with its built-in catalog or don't fit its OpenAI-family routing, and some releases reject IDs with a provider prefix. Try another Phaseo model that Cursor accepts as an OpenAI-family custom model.

### Authentication fails

Run `phaseo integrations credential cursor` again, replace the key in Cursor, and check that the Base URL is exactly `https://api.phaseo.app/v1`.
