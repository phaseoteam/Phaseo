Add `https://phaseo.app/docs/mcp` to your coding agent as an MCP server so it answers Phaseo questions from the live docs instead of its training data. The server is read-only: agents can search the docs, read full pages, and read the hosted [skill.md](https://phaseo.app/docs/skill.md) capability summary.

## Codex

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
codex mcp list
```

## Claude Code

Add the server to the current project, or add `--scope user` to make it available in every project:

```bash
claude mcp add --transport http phaseo-docs https://phaseo.app/docs/mcp
claude mcp add --transport http --scope user phaseo-docs https://phaseo.app/docs/mcp
claude mcp list
```

## Cursor

Install it from the contextual menu on any docs page, or add it to Cursor's MCP config:

```json
{
  "mcpServers": {
    "phaseoDocs": {
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## VS Code

Install it from the contextual menu on any docs page, or add it to VS Code's MCP config:

```json
{
  "servers": {
    "phaseoDocs": {
      "type": "http",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## OpenCode

Add it to `opencode.json`:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "phaseoDocs": {
      "type": "remote",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## Check it works

Ask the agent something only the docs can answer, and check that it calls the Phaseo docs server:

- `Look up the Responses request format in the Phaseo docs and give me a minimal example.`
- `Use the Phaseo docs MCP server to check how provider.sort works before you change this request.`
- `Find the guardrails docs in Phaseo and summarize the parts that affect provider routing.`

Agents use it to check request shapes, which endpoints a model or provider supports, and how routing, presets, guardrails, and async jobs behave. The docs server doesn't make Phaseo your model gateway; for that, see [Coding Agents](./coding-assistants.mdx).
