Run `phaseo roo-code` to create a key, then add an **OpenAI Compatible** profile in Roo Code. Roo Code keeps keys in VS Code's secret storage, so that last step happens in its UI.

## Set up with the Phaseo CLI

```bash
phaseo login
phaseo roo-code --model anthropic/claude-sonnet-5.5
```

The CLI creates a `Phaseo CLI: Roo Code API Key` that expires after 90 days and has a $100 monthly spend limit, then prints the values for the next step.

## Configure Roo Code

1. Open Roo Code in VS Code, then **Settings → Providers**.
2. Create a provider configuration profile and choose **OpenAI Compatible**.
3. Enter:

| Roo Code field | Value |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | Output of `phaseo integrations credential roo-code`, or any Phaseo API key |
| Model | `anthropic/claude-sonnet-5.5`, or the model printed by setup |

4. Save the profile and make it active.

Field labels change slightly between releases; see Roo Code's [model providers](https://docs.roocode.com/providers/) docs if yours differ.

## Check it works

Ask Roo Code to reply with `PHASEO_ROO_OK`, then confirm the request appears in **Settings → Usage → Logs**.

## Remove Phaseo

Delete the Phaseo profile or switch profiles, then run:

```bash
phaseo integrations remove roo-code
```

This revokes the key. The CLI can't clear VS Code's extension storage.

## Fix common problems

### Authentication fails

Copy the key again with `phaseo integrations credential roo-code`, and check that the Base URL ends in `/v1`.

### Roo Code can't find the model

Type the exact Phaseo model ID, including its provider prefix.

### Chat works but tools fail

Switch to a model with tool-calling support.
