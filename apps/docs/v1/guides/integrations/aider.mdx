Run `phaseo aider` to write an Aider config that points at Phaseo, or add three lines to your existing `.aider.conf.yml`.

## Set up with the Phaseo CLI

```bash
phaseo login
phaseo aider --model anthropic/claude-sonnet-5.5
```

If `~/.aider.conf.yml` doesn't exist, setup creates a `Phaseo CLI: Aider API Key` (90-day expiry, $100 monthly spend limit) and writes this file. Without `--model`, it uses `anthropic/claude-sonnet-4.6`.

```yaml ~/.aider.conf.yml
# Managed by Phaseo CLI
model: openai/anthropic/claude-sonnet-5.5
openai-api-base: https://api.phaseo.app/v1
openai-api-key: "<dedicated Phaseo key>"
```

Aider needs the `openai/` prefix to send a custom model through its OpenAI-compatible adapter. The model sent to Phaseo is still `anthropic/claude-sonnet-5.5`.

<Warning>
The key is stored in plaintext, because `.aider.conf.yml` is one of Aider's documented key locations. Keep the file readable only by your user account, and never commit it.
</Warning>

## Configure Aider manually

If you already have an Aider config, the CLI stops without changing it. Copy the three settings above into the config you want Aider to load, using `phaseo integrations credential aider` or any Phaseo API key for `openai-api-key`. Aider reads `.aider.conf.yml` from your home directory, the repository root, and the current directory, and later files win. See Aider's [YAML configuration](https://aider.chat/docs/config/aider_conf.html) and [OpenAI-compatible API](https://aider.chat/docs/llms/openai-compat.html) docs.

## Check it works

Open a repository and start Aider:

```bash
aider
```

Check that the startup output names `openai/anthropic/claude-sonnet-5.5`, ask it to reply with `PHASEO_AIDER_OK`, and confirm the request appears in **Settings → Usage → Logs**.

An unknown-model warning doesn't stop requests. Add Aider model metadata only if you need accurate token-limit or cost estimates.

## Remove Phaseo

```bash
phaseo integrations remove aider
```

This revokes the key and deletes `~/.aider.conf.yml` only if the file still starts with the Phaseo CLI marker. If you merged the settings into your own file, remove the three lines yourself.

## Fix common problems

### Aider uses another endpoint or model

A `.aider.conf.yml` in the repository root or current directory overrides the one in your home directory. Environment variables and command-line options override all of them.

### Authentication fails

Compare `openai-api-key` with the output of `phaseo integrations credential aider`, and keep `openai-api-base` exactly `https://api.phaseo.app/v1`.

### The model can't be resolved

Keep Aider's `openai/` prefix. Phaseo model `openai/gpt-6-astra` becomes `openai/openai/gpt-6-astra` in Aider.
