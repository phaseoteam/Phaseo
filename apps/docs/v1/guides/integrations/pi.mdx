Run `phaseo pi` to add a Phaseo provider extension to Pi with every compatible Phaseo model.

## Set up with the Phaseo CLI

```bash
phaseo login
phaseo pi
```

If Pi is missing, the CLI shows the official install command and asks before running it. Setup then creates a `Phaseo CLI: Pi API Key` (90-day expiry, $100 monthly spend limit) and writes a provider extension to `~/.pi/agent/extensions/phaseo.ts`. The extension lists every active Phaseo text model that works with Chat Completions.

| Flag | Effect |
| --- | --- |
| `--model <id>` | Sets the initial model. Defaults to `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | Adds only the selected model. |
| `--dry-run` | Shows the file changes without making them. |

The extension gets its key at request time with Pi's command-backed key syntax, so no plaintext key is written to the file:

```text
!phaseo integrations credential pi
```

## Check it works

```bash
pi
```

Open `/model`, choose the `phaseo` provider, and send a short prompt. Confirm the request appears in **Settings → Usage → Logs**.

## Remove Phaseo

```bash
phaseo integrations remove pi
```

This removes only the Phaseo extension and revokes the key.
