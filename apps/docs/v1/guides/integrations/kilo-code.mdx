Run `phaseo kilo` to start a Kilo Code CLI session through Phaseo, or create a key with `phaseo kilo-code` and add a custom provider in the Kilo Code extension.

## Run the Kilo Code CLI through Phaseo

```bash
phaseo login
phaseo kilo --model openai/gpt-5.6-terra
```

The runner writes a temporary `KILO_CONFIG` file, launches `kilo`, and deletes the file when Kilo exits, so your existing Kilo Code or VS Code setup is untouched. If Kilo is missing, an interactive run offers to install it. Put Kilo's own flags after `--`.

| Flag | Effect |
| --- | --- |
| `--model <id>` | Model to use. Defaults to `openai/gpt-5.6-terra`. |
| `--catalog all` | Lists every active Phaseo text model in Kilo, not just the selected one. |
| `--dry-run --json` | Shows the install and launch plan without creating a key or starting Kilo. |
| `--skip-install` | Skips the install check. |

`phaseo run kilo ...` is the long form of the same command.

## Configure the Kilo Code extension

Create a key for the extension:

```bash
phaseo login
phaseo kilo-code --model anthropic/claude-sonnet-5.5
```

Then, in VS Code:

1. Open Kilo Code, select the settings icon, open **Providers**, then select **Add custom provider**.
2. Enter:

| Kilo Code field | Value |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.phaseo.app/v1` |
| API key | Output of `phaseo integrations credential kilo-code` |

3. If no model is discovered, add the ID `anthropic/claude-sonnet-5.5` yourself.
4. Select **Submit**, then choose the Phaseo model.

Kilo shows the selection as `phaseo/anthropic/claude-sonnet-5.5`. `phaseo` is the local provider ID; the rest is the model ID sent to Phaseo. See Kilo's [custom models](https://kilo.ai/docs/code-with-ai/agents/custom-models) docs for the full form.

## Check it works

Ask Kilo Code to reply with `PHASEO_KILO_OK`, then confirm the request appears in **Settings → Usage → Logs**.

## Remove Phaseo

Delete the custom provider in Kilo Code, then run:

```bash
phaseo integrations remove kilo-code
```

This revokes the key. The CLI can't clear the extension's storage.

## Fix common problems

### No models are discovered

Add the model yourself. Kilo doesn't need discovery through `/models`.

### Authentication fails

Replace the saved key with the output of `phaseo integrations credential kilo-code`, and keep the Base URL exactly as shown.

### The model name looks different

Select `phaseo/<Phaseo model ID>` in Kilo, but don't add `phaseo/` in the model ID field.
