Point the Anthropic SDK at `https://api.phaseo.app` and pass your Phaseo key as an auth token. Use this for apps, agents, and coding tools that send Claude-style `/v1/messages` requests; Phaseo serves them as [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx).

## Install

<CodeGroup>

```bash TypeScript
npm install @anthropic-ai/sdk
```

```bash Python
pip install anthropic
```

</CodeGroup>

## Point the client at Phaseo

<CodeGroup>

```ts TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
	apiKey: null,
	authToken: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app",
});

const message = await client.messages.create({
	model: "anthropic/claude-sonnet-5.5",
	max_tokens: 512,
	messages: [{ role: "user", content: "Reply with only: ok" }],
});

console.log(message.content);
```

```python Python
import os
from anthropic import Anthropic

client = Anthropic(
    auth_token=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app",
)

message = client.messages.create(
    model="anthropic/claude-sonnet-5.5",
    max_tokens=512,
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(message.content)
```

</CodeGroup>

A text block containing `ok` means the setup works.

| Setting | Why |
| --- | --- |
| `baseURL: "https://api.phaseo.app"` | Use the root host. Anthropic clients add `/v1/messages` themselves. |
| `authToken` (`auth_token` in Python) | Sends `Authorization: Bearer` on every SDK version. Phaseo doesn't accept `x-api-key`, which `apiKey` sends before `@anthropic-ai/sdk` 1.0 and `anthropic` 2.0. |
| `apiKey: null` | Stops older TypeScript SDKs from also sending your `ANTHROPIC_API_KEY`. Python SDKs before 0.98 send it whenever it's set, so upgrade, or unset it where you call Phaseo. |

## Known limits

- Native Anthropic tool shapes work where Phaseo supports them. Server tools that work across providers use Phaseo tool names; see [Tool Calling](../tool-calling.mdx).
- Anthropic-compatible clients are strict about the order of tool events. Test streamed tool loops before production.
- For [Claude Code](./claude-code.mdx), use its own guide.
