Point an OpenAI-compatible or Anthropic-compatible client at Phaseo's base URL, give it a Phaseo API key, and use Phaseo model IDs such as `openai/gpt-6-astra` unchanged. Each guide sets the tool up first, then shows how to check it works and what doesn't.

| Client style | Base URL | Key goes in |
| --- | --- | --- |
| OpenAI-compatible | `https://api.phaseo.app/v1` | The API key field, sent as `Authorization: Bearer` |
| Anthropic-compatible (adds `/v1/messages` itself) | `https://api.phaseo.app` | The auth token field, sent as `Authorization: Bearer` |

Get model IDs from the [Models endpoint](../../api-reference/endpoint/models.mdx). For new OpenAI-style apps, use [Responses](../../api-reference/endpoint/responses.mdx); older libraries are safest on [Chat Completions](../../api-reference/endpoint/chat-completions.mdx). Set `PHASEO_API_KEY` once and map it to whatever variable the tool expects, and test streaming and tool calling before you move agent traffic over.
