Run `phaseo login`, then `phaseo <agent>` to point a coding agent at Phaseo with its own API key. To skip the CLI, enter the [manual provider values](#enter-the-provider-values-yourself) in the agent's settings.

```bash
phaseo login
phaseo codex
```

## Find the command for your agent

The CLI sets up each agent in one of three ways:

- **Configured**: the CLI writes the agent's config file. Start the agent and pick a Phaseo model.
- **Key only**: the agent keeps keys in its own app storage, so the CLI creates the key and prints the fields to fill in.
- **Session**: the CLI launches the agent with temporary settings that are deleted when it exits. Your normal config is not touched.

## What the CLI creates

Every agent gets its own API key, named after it (for example `Phaseo CLI: Codex API Key`). The key expires after 90 days and has a $100 monthly spend limit. Run the setup command again to replace an expired key, and raise the limit with `phaseo keys update <id> --limit`.

If Claude Code, Codex, OpenCode, fx, DeepSeek Harness, Pi, Prime Agent, OpenClaw, or Hermes Agent is missing, the CLI shows the official install command and asks before running it. Outside an interactive terminal it prints the install command and stops. OpenCode, fx, DeepSeek Harness, Pi, Prime Agent, and OpenClaw also receive every active Phaseo text model that works with Chat Completions.

| Flag or command | Effect |
| --- | --- |
| `--model <id>` | Sets the default model. Not supported for Claude Code. |
| `--catalog default` | Adds only the selected model instead of the whole catalog. |
| `--skip-install` | Skips the install check, for an agent you manage yourself. |
| `--dry-run` | Shows the file changes without making them. |
| `phaseo integrations credential <agent>` | Prints that agent's key, for agents where you paste it in. |
| `phaseo integrations remove <agent>` | Deletes the configuration Phaseo wrote and revokes the key. Your other settings stay. |

## Enter the provider values yourself

Use these values in any agent with an OpenAI-compatible provider. Field names vary by tool.

| Setting | Value |
| --- | --- |
| Provider type | OpenAI Compatible |
| Base URL | `https://api.phaseo.app/v1` |
| API key | A Phaseo API key |
| Model | A Phaseo model ID, such as `openai/gpt-6-astra` |

For agents that speak the Anthropic Messages API:

| Setting | Value |
| --- | --- |
| Base URL | `https://api.phaseo.app` (the client adds `/v1/messages`) |
| Auth token | A Phaseo API key |
| Model | A Phaseo model ID, such as `anthropic/claude-sonnet-5.5` |

Some agents reject model IDs that contain `/`. If yours does and it supports aliases, create a local alias that maps to the Phaseo model ID.

## Agents without their own guide

### VS Code

VS Code can add models in its Language Models editor when your build includes an OpenAI-compatible provider.

1. Open the Command Palette and run `Chat: Manage Language Models`.
2. Choose `OpenAI Compatible` or `OAI Compatible`.
3. Enter your Phaseo API key and set the endpoint to `https://api.phaseo.app/v1`.
4. Add a Phaseo model ID, such as `openai/gpt-6-astra`, and select it in the chat model picker.

If your build has no OpenAI-compatible provider, use an extension that supports custom providers: [Continue](./continue.mdx), [Cline](./cline.mdx), [Roo Code](./roo-code.mdx), or [Kilo Code](./kilo-code.mdx).

### Claude Desktop

Claude Desktop can't use a custom model provider. Add [Docs MCP](./docs-mcp.mdx) to give it Phaseo documentation, and use [Claude Code](./claude-code.mdx) when you need Phaseo as the model gateway.

### Deep Agents CLI and other LangChain tools

Use the base URL and key from [LangChain](./langchain.mdx). If the tool reads OpenAI environment variables, set these and pass a Phaseo model ID in its model field:

```bash
export OPENAI_API_KEY="your_phaseo_api_key"
export OPENAI_BASE_URL="https://api.phaseo.app/v1"
```

## Known limits

- Server tools work only where the agent sends them: `phaseo:apply_patch` is available on [Responses](../../api-reference/endpoint/responses.mdx) only. Older agents that don't handle Responses events or [server tools](../server-tools/index.mdx) are safer on [Chat Completions](../../api-reference/endpoint/chat-completions.mdx).
- Send a short chat request before you let an agent edit files, and pick a model with tool-calling support for agent work.
- Add [Docs MCP](./docs-mcp.mdx) if you want the agent to read Phaseo docs during a session.
