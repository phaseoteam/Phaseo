Run `phaseo omp` to start an oh-my-pi session through Phaseo, or add a `phaseo` provider to `~/.omp/agent/models.yml` to keep Phaseo in every session.

## Run oh-my-pi through the Phaseo CLI

```bash
phaseo login
phaseo omp --model openai/gpt-5.6-terra
```

The runner creates a dedicated key, writes `models.yml` under a temporary `PI_CODING_AGENT_DIR`, launches `omp` with `--model phaseo/<model>`, and deletes the directory when oh-my-pi exits. If `omp` is missing, the first interactive run offers to install it. Put oh-my-pi's own flags after `--`.

| Flag | Effect |
| --- | --- |
| `--model <id>` | Model to use. Defaults to `openai/gpt-5.6-terra`. |
| `--catalog all` | Lists every active Phaseo text model, not just the selected one. |
| `--dry-run --json` | Shows the install and launch plan without creating a key or starting oh-my-pi. |
| `--skip-install` | Skips the install check. |

`phaseo run omp ...` is the long form of the same command.

## Configure oh-my-pi manually

Create a key under **Settings → API Keys** in the dashboard, export it in the shell that starts oh-my-pi, and create the config directory:

```bash
export PHASEO_OMP_API_KEY="<your Phaseo API key>"
mkdir -p ~/.omp/agent
```

Add the provider:

```yaml ~/.omp/agent/models.yml
providers:
  phaseo:
    baseUrl: https://api.phaseo.app/v1
    api: openai-completions
    apiKey: PHASEO_OMP_API_KEY
    authHeader: true
    models:
      - id: openai/gpt-5.6-terra
        name: GPT-5.6 Terra via Phaseo
        contextWindow: 32768
        maxTokens: 8192
```

`apiKey` names the environment variable, so the key stays out of `models.yml`. Add more entries under `models` as needed; the limits above are examples. Start oh-my-pi with the provider-qualified model ID:

```bash
omp --model phaseo/openai/gpt-5.6-terra
```

See oh-my-pi's [provider configuration](https://github.com/can1357/oh-my-pi/blob/main/docs/providers.md) docs for the other fields.

## Check it works

Send a short prompt and confirm the request appears in **Settings → Usage → Logs**.

## Fix common problems

### oh-my-pi isn't installed

Run the command in an interactive terminal to approve the install, or install oh-my-pi yourself and rerun with `--skip-install`.

### The model isn't listed

Use `--catalog all`, or pass the model ID with `--model`. Phaseo doesn't need model discovery.
