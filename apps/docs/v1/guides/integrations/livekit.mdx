Point the LiveKit Agents OpenAI plugin's LLM at `https://api.phaseo.app/v1` with your Phaseo key, and your voice agents use Phaseo model IDs and routing. The plugin calls Phaseo's Chat Completions endpoint.

## Install

<CodeGroup>

```bash Python
uv add "livekit-agents[openai]"
```

```bash Node.js
pnpm add @livekit/agents @livekit/agents-plugin-openai
```

</CodeGroup>

## Point the agent's LLM at Phaseo

<CodeGroup>

```python Python
import os
from livekit.agents import AgentSession
from livekit.plugins import openai

session = AgentSession(
    llm=openai.LLM(
        model="openai/gpt-6-astra",
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)
```

```ts Node.js
import { voice } from "@livekit/agents";
import * as openai from "@livekit/agents-plugin-openai";

const session = new voice.AgentSession({
	llm: new openai.LLM({
		model: "openai/gpt-6-astra",
		apiKey: process.env.PHASEO_API_KEY,
		baseURL: "https://api.phaseo.app/v1",
	}),
});
```

</CodeGroup>

Start a session, say something, and confirm the request appears in **Settings → Usage → Logs**.

## Known limits

- Use the plugin's Chat Completions mode for custom endpoints. LiveKit's Responses-specific OpenAI tools don't become Phaseo server tools.
- This only routes the LLM. Configure speech-to-text and text-to-speech separately, unless the LiveKit interface you use accepts a custom OpenAI-compatible URL for that modality.
- Test interruption handling, [tool calls](../tool-calling.mdx), and [streaming](../streaming.mdx) latency before production voice traffic.
