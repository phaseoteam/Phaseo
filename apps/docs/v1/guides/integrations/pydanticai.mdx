Create an `OpenAIChatModel` with an `OpenAIProvider` pointed at `https://api.phaseo.app/v1`, and PydanticAI agents run on Phaseo models.

## Install

```bash
pip install "pydantic-ai-slim[openai]"
```

## Point PydanticAI at Phaseo

```python
import os
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-6-astra",
    provider=OpenAIProvider(
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)

agent = Agent(model, system_prompt="Answer concisely.")
result = agent.run_sync("Reply with only: ok")
print(result.output)
```

A printed `ok` means the setup works.

## Known limits

- This path uses OpenAI-style Chat Completions. For Responses-only features such as `phaseo:apply_patch`, call Phaseo's Responses endpoint directly.
- Keep [structured output](../structured-outputs.mdx) schemas small enough for the model's context window. Check limits in [Models](../../api-reference/endpoint/models.mdx).
