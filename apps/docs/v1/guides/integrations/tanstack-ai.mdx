Create TanStack AI's `openaiCompatible` adapter with your Phaseo key, `baseURL: "https://api.phaseo.app/v1"`, and the Phaseo model IDs you use. It works for type-safe chat in React, Solid, Preact, Vue, Svelte, or server-side TypeScript.

## Install

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## Point the adapter at Phaseo

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-6-astra", "anthropic/claude-sonnet-5.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-6-astra"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

Declare every Phaseo model ID you plan to use in `models`. Check the IDs in [Models](../../api-reference/endpoint/models.mdx).

## Known limits

- The adapter uses Chat Completions. For Responses-only features, call Phaseo directly or use the [OpenAI SDK](./openai-sdk.mdx).
- If a model doesn't support [tools](../tool-calling.mdx) or images, declare narrower capabilities in TanStack AI so TypeScript catches unsupported calls.
