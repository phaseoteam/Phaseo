Run `phaseo cline` to start a Cline CLI session through Phaseo, or create a key with `phaseo setup cline` and add an **OpenAI Compatible** provider in the Cline extension. The extension keeps keys in VS Code's secret storage, so that last step happens in its UI.

## Run the Cline CLI through Phaseo

```bash
phaseo login
phaseo cline --model openai/gpt-5.6-terra -- --tui
```

The runner writes Cline settings to a temporary directory, launches `cline`, and deletes the directory when Cline exits, so your existing Cline or VS Code setup is untouched. If Cline is missing, an interactive run offers to install it. Put Cline's own flags after `--`.

| Flag | Effect |
| --- | --- |
| `--model <id>` | Model to use. Defaults to `openai/gpt-5.6-terra`. |
| `--catalog all` | Lists every active Phaseo text model in Cline, not just the selected one. |
| `--dry-run --json` | Shows the install and launch plan without creating a key or starting Cline. |
| `--skip-install` | Skips the install check. |

`phaseo run cline ...` is the long form of the same command.

## Configure the Cline extension

Create a key for the extension:

```bash
phaseo login
phaseo setup cline --model anthropic/claude-sonnet-5.5
```

Then, in VS Code:

1. Open the Cline panel and select the settings icon, or the provider below the chat box.
2. Choose **OpenAI Compatible** and enter:

| Cline field | Value |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | Output of `phaseo integrations credential cline` |
| Model ID | `anthropic/claude-sonnet-5.5`, or the model printed by setup |

3. Save the provider. If your version shows **Verify**, select it.
4. Select the configured model for the next task.

To skip the CLI, use any Phaseo API key. Cline's [OpenAI-compatible configuration](https://docs.cline.bot/enterprise-solutions/configuration/remote-configuration/openai-compatible/member-configuration) docs cover team-managed setups.

## Check it works

Ask Cline to reply with `PHASEO_CLINE_OK`, then confirm the request appears in **Settings → Usage → Logs**.

## Remove Phaseo

Delete or switch away from the Phaseo provider in Cline, then run:

```bash
phaseo integrations remove cline
```

This revokes the key. The CLI can't clear VS Code's extension storage, so the deleted key may still show in Cline until you remove it there.

## Fix common problems

### Verification fails

Keep the Base URL exactly as shown, including `/v1`, and paste a freshly retrieved key with no quotes or spaces.

### The model list is empty

Type the Phaseo model ID yourself. Cline doesn't need model discovery.

### Chat works but tools fail

Pick a Phaseo model with tool-calling support. A working connection doesn't mean the model supports tools.
