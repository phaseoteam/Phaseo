Run `phaseo codex` to add a Phaseo profile to Codex, or add a `phaseo` provider to `config.toml` yourself. The same config works in Codex CLI, the Codex App, and the Codex IDE extension.

## Set up with the Phaseo CLI

```bash
phaseo login
phaseo codex --model openai/gpt-5.6-terra
codex --profile phaseo
```

If Codex is missing, the CLI shows the official install command and asks before running it. Setup then opens a dashboard page where you approve a `Phaseo CLI: Codex API Key` that expires after 90 days and has a $100 monthly spend limit. The CLI keeps the key in the OS credential store and writes the profile to `~/.codex/phaseo.config.toml` (or under `CODEX_HOME`). Codex fetches the key from the CLI, so no plaintext key is written to the config. When the key expires, run `phaseo codex` again to approve a new one. Without `--model`, the profile uses `openai/gpt-5.6-terra`.

## Configure Codex manually

Add this to `~/.codex/config.toml`, or to `.codex/config.toml` in a trusted project:

```toml
model = "openai/gpt-6-astra"
model_provider = "phaseo"

[model_providers.phaseo]
name = "Phaseo"
base_url = "https://api.phaseo.app/v1"
env_key = "PHASEO_API_KEY"
wire_api = "responses"
```

Then export `PHASEO_API_KEY` and start Codex. Codex custom providers use the Responses wire protocol, which is the default, so you can also leave out `wire_api`. In the IDE extension, open the file from **Codex Settings → Open config.toml**.

## Check it works

Send a short prompt and confirm the request appears in **Settings → Usage → Logs**. Codex calls [Responses](../../api-reference/endpoint/responses.mdx), so the model must support that endpoint.

## Remove Phaseo

```bash
phaseo integrations remove codex
```

This deletes `phaseo.config.toml` if Phaseo created it, and revokes the key. For a manual setup, remove the `phaseo` provider from `config.toml`.

## Fix common problems

| Error | Fix |
| --- | --- |
| `401 Unauthorized` | Run `phaseo whoami`, then rerun `phaseo codex`. |
| `model_not_found` | Get a current ID from [Models](../../api-reference/endpoint/models.mdx) and update `model`. |
| A provider fails | See [Routing and fallbacks](../routing-and-fallbacks.mdx) for failover. |

## Add Phaseo skills and docs

To let Codex read the live Phaseo docs while it works, add the [Docs MCP](./docs-mcp.mdx) server. To install the public [Phaseo skills](https://phaseo.app/docs/.well-known/agent-skills/index.json) for Codex:

```bash
npx skills add https://phaseo.app/docs --agent codex --skill '*'
```

The same CLI workflow launches [Cline](./cline.mdx), [Kilo Code](./kilo-code.mdx), [oh-my-pi](./oh-my-pi.mdx), [Muse Code](./muse-code.mdx), and [MiniMax Code](./minimax-code.mdx) with temporary settings.
