Send an `X-App-Id` header on every request to group its usage under one application in app analytics and request audits. Use a different ID for each product, environment, or customer-facing experience you want to report on separately. Attribution never changes the inference response.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-App-Id: acme-support" \
  -H "X-App-Name: Acme Support" \
  -H "HTTP-Referer: https://acme.example/support" \
  -H "X-App-Categories: chat,productivity" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Summarize this ticket."
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const phaseo = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY,
  app: {
    id: "acme-support",
    name: "Acme Support",
    url: "https://acme.example/support",
    categories: ["chat", "productivity"],
  },
});

const response = await phaseo.generateResponse({
  model: "openai/gpt-6-astra",
  input: "Summarize this ticket.",
});
```
</CodeGroup>

The TypeScript SDK's `app` option sends the same headers on every request. Phaseo never sets attribution for you.

## Headers

| Header | Purpose |
| --- | --- |
| `X-App-Id` | Stable identifier chosen by your application. |
| `X-App-Name` | Human-readable name shown in app and usage views. |
| `HTTP-Referer` | Public page or deployment URL associated with the app. |
| `X-App-Categories` | Comma-separated list of up to three categories. |
| `X-Title` | Compatibility alias for a human-readable app name. |

Phaseo identifies the app by its `HTTP-Referer` URL when you send one, and by `X-App-Id` otherwise. Keep both stable: a new URL or ID starts a new app in analytics.

`HTTP-Referer` doesn't need to match the browser's automatic `Referer` header. Set it explicitly in server-side integrations when you want one canonical app URL.

## Categories

Choose up to three of `chat`, `developer-tools`, `research`, `productivity`, `education`, `commerce`, `media`, `finance`, and `other`.

Values are case-insensitive. Phaseo ignores unknown values, removes duplicates, and keeps the first three valid categories. Categories sent on later requests are added to the ones already saved for the app; they never remove categories chosen in the dashboard.

To manage categories centrally instead of in application code, edit them in **Settings → Apps**.

## Keep attribution safe to share

- Don't put customer IDs, email addresses, or other personal data in attribution headers.
- Treat the URL and name as public: they can appear in shared or public app views.
