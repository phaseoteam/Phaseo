Choose a sample project to run locally and adapt. For a single API call, use the [Quickstart](../quickstart.mdx); for a specific feature, browse the [Cookbook](../cookbook/index.mdx).

## Runnable projects

| Build | Walkthrough | Source |
| --- | --- | --- |
| Browser chat with a server-side API key | [Next.js chat](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| OAuth authorisation and a backend proxy | [OAuth workbench](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| A minimal REST integration | [Node smoke app](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| A Python command-line application | [Python CLI](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| An application using Vercel AI SDK | [AI SDK integration](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

Keep credentials on the server, review the sample's environment variables, and check the selected model's pricing before running it. Examples using `:free` models do not require deposited credits.

## Language-specific requests

The [Client SDK reference](../sdk-reference/typescript/overview.mdx) contains installation and request examples by language. Use the [image generation reference](../api-reference/endpoint/images-generations.mdx) for image parameters and [Chat Completions](../api-reference/endpoint/chat-completions.mdx) for chat requests.

For a coding agent to scaffold a project, use [mini-app starter prompts](../cookbook/mini-app-starter-prompts.mdx) and review the generated code before using it with live credentials.
