<Update label="March 23, 2026">

<div data-changelog-category="product">

<p className="changelog-category">Product</p>

- Chat rooms can now run audio, moderation and embeddings models as well as text models ([#201](https://github.com/phaseoteam/Phaseo/pull/201), [#157](https://github.com/phaseoteam/Phaseo/pull/157)).
- Foundry, a new home for experimental projects, opens with LLM Council, which sends one prompt to several models and merges their answers into one ([#201](https://github.com/phaseoteam/Phaseo/pull/201)).

</div>

<div data-changelog-category="api">

<p className="changelog-category">API & SDKs</p>

- Go, C#, Java, PHP and Ruby SDKs are now available alongside the TypeScript and Python SDKs, all at version `1.1.0` ([#203](https://github.com/phaseoteam/Phaseo/pull/203), [#201](https://github.com/phaseoteam/Phaseo/pull/201)).
- The SDKs `1.1.0` warn when a request names a deprecated or retired model, and their model types and route paths match the API ([#201](https://github.com/phaseoteam/Phaseo/pull/201), [#203](https://github.com/phaseoteam/Phaseo/pull/203)).

<Update label="March 2, 2026">

<div data-changelog-category="api">

<p className="changelog-category">API & SDKs</p>

- The Responses API accepts and returns the assistant message `phase` (`commentary` or `final_answer`), so multi-turn requests can send it back; see [Create a response](../api-reference/endpoint/responses.mdx) ([#130](https://github.com/phaseoteam/Phaseo/pull/130)).
- Responses requests to OpenAI models accept `provider_options.openai.context_management` with `type: "compaction"` and an optional `compact_threshold`; see [Parameters](../api-reference/parameters.mdx) ([#130](https://github.com/phaseoteam/Phaseo/pull/130)).
- Requests to OpenAI that omit `safety_identifier` now send one taken from `user` or `user_id`, or else the request ID ([#130](https://github.com/phaseoteam/Phaseo/pull/130)).
