<Update label="May 6, 2026">

<div data-changelog-category="api">

<p className="changelog-category">API & SDKs</p>

- The List models endpoint accepts `availability=all` to include coming-soon and inactive models, and each provider entry returns `availability_status` and `availability_reason`; see [List models](../api-reference/endpoint/models.mdx) ([#466](https://github.com/phaseoteam/Phaseo/pull/466)).

- The Get a generation endpoint returns `replay_request` and `replay_supported`, so a logged request can be sent again to its original endpoint; see [Get a generation](../api-reference/endpoint/generation.mdx) ([#467](https://github.com/phaseoteam/Phaseo/pull/467)).
