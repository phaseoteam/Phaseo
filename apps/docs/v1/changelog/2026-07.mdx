<Update label="July 31, 2026">

<div data-changelog-category="product">

<p className="changelog-category">Product</p>

- Workspaces can build dynamic routes in **Settings -> Routing** that branch on request fields, split traffic and set fallbacks, then attach them to API keys; see [Routing and Fallbacks](../guides/routing-and-fallbacks.mdx) ([#1314](https://github.com/phaseoteam/Phaseo/pull/1314)).
- Logs are split into **Requests**, **Upstream Requests**, **Jobs** and **Sessions**, and each row opens its details in a side sheet ([#1314](https://github.com/phaseoteam/Phaseo/pull/1314)).
- Dropdown menu actions such as Support, workspace switching and key management respond to clicks again; before, some of them did nothing ([#1378](https://github.com/phaseoteam/Phaseo/pull/1378)).

</div>

<div data-changelog-category="api">

<p className="changelog-category">API & SDKs</p>

- Model IDs can name a provider, as in `baseten:thinking-machines/inkling-small`, to send the request only to that provider with no fallback; see [Provider-qualified model IDs](../guides/provider-qualified-models.mdx) ([#1369](https://github.com/phaseoteam/Phaseo/pull/1369)).
- The Phaseo MCP server supports MCP protocol version `2026-07-28` and still accepts clients on earlier versions ([#1341](https://github.com/phaseoteam/Phaseo/pull/1341)).

</div>

<Update label="July 26, 2026">

<div data-changelog-category="product">

<p className="changelog-category">Product</p>

- The pricing calculator compares several models side by side, including long-context rates, and keeps the selection in the page URL ([#1299](https://github.com/phaseoteam/Phaseo/pull/1299)).
- BYOK requests are free for the first 1 million each month, then carry a 2.5% service fee, as shown on the Pricing page ([#1299](https://github.com/phaseoteam/Phaseo/pull/1299)).
- Model pages link to the previous and next model in the family and to the model's licence, and family pages list releases newest first ([#1266](https://github.com/phaseoteam/Phaseo/pull/1266)).
- Model migration guides are named for the model you move to and listed newest first, with a new Claude Opus 5 guide; see [Model Migrations](../model-migrations/index.mdx) ([#1273](https://github.com/phaseoteam/Phaseo/pull/1273)).

</div>

<div data-changelog-category="api">

<p className="changelog-category">API & SDKs</p>

- Agent SDK packages are published for Python, Go, C#, PHP and Ruby alongside TypeScript `0.2.0`, with tool approvals, stop conditions and cancellable streaming; see [Agent SDK Overview](../sdk-reference/agent-sdk/overview.mdx) ([#1263](https://github.com/phaseoteam/Phaseo/pull/1263), [#1269](https://github.com/phaseoteam/Phaseo/pull/1269), [#1259](https://github.com/phaseoteam/Phaseo/pull/1259)).
- The `phaseo` Rust client and the synchronous `phaseo-agent` Rust Agent SDK `0.1.0` are published on crates.io; see [Rust SDK](../sdk-reference/rust/overview.mdx) ([#1287](https://github.com/phaseoteam/Phaseo/pull/1287), [#1289](https://github.com/phaseoteam/Phaseo/pull/1289)).
- `GET /v1/models` returns a `variants` object that links a model's standard and `:free` versions, and the Models page lists each version separately ([#1298](https://github.com/phaseoteam/Phaseo/pull/1298)).
- The Phaseo MCP server offers ten read-only tools for models, providers, costs, credits, usage and request health, and asks only for the seven scopes they need; see [CLI and MCP](../developers/cli-and-mcp.mdx) ([#1290](https://github.com/phaseoteam/Phaseo/pull/1290), [#1292](https://github.com/phaseoteam/Phaseo/pull/1292), [#1297](https://github.com/phaseoteam/Phaseo/pull/1297)).
