Send every request to `https://api.phaseo.app/v1` with your key in an `Authorization: Bearer` header. Find the endpoint for your task below, then open its reference page.

## Find the right endpoint

| If you want to | Start with |
| --- | --- |
| Send your first request | [Quickstart](../quickstart) |
| Generate text or use tools | [`POST /responses`](./endpoint/responses) |
| Make typed decisions | [`POST /decisions`](./endpoint/decisions) |
| Keep an existing OpenAI-compatible integration | [`POST /chat/completions`](./endpoint/chat-completions) |
| Browse models and providers | [`GET /models`](./endpoint/models) and [`GET /providers`](./endpoint/providers) |
| Create music or manage files | [`POST /music/generate`](./endpoint/music-generate) and [`POST /files`](./endpoint/files) |
| Generate video (Beta) | [`POST /videos`](./endpoint/video-create) |
| Submit a batch or download results (Beta) | [`POST /batches`](./endpoint/batches-create) and [`GET /batches/{batch_id}/results`](./endpoint/batches-results) |

## Base URL

```http
https://api.phaseo.app/v1
```

Every endpoint path in this reference is relative to this base URL.

## Authentication

| Credential | Format | Calls |
| --- | --- | --- |
| [Gateway API key](../developers/authentication.mdx) | `phaseo_v1_sk_<kid>_<secret>` | Inference endpoints |
| [Management API key](../developers/management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | Administration endpoints, limited to the key's permissions |

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

If authentication fails, the API returns `401`.

## API resources

| Resource | What it does |
| --- | --- |
| Inference | Generate text, images, audio, and embeddings; make decisions, rerank, moderate, or parse content. Start with [Responses](./endpoint/responses.mdx) or [Decisions](./endpoint/decisions.mdx). |
| Async Jobs & Files | Submit [video](./endpoint/video-create.mdx) or [batch](./endpoint/batches-create.mdx) jobs, transfer files, and configure webhooks. |
| Models & Pricing | Discover [models](./endpoint/models.mdx), provider offers, and [estimated costs](./endpoint/pricing-calculate.mdx). |
| Routing & Policies | Configure presets, provider credentials, private models, and [guardrails](./endpoint/guardrails.mdx). |
| Usage & Monitoring | Inspect [logs](./endpoint/logs-list.mdx), activity, analytics, evaluations, and service health. |
| Workspace Management | Manage [workspaces](./endpoint/workspaces-list.mdx), keys, budgets, identities, and integrations. |

## Billing and rate limits

Paid requests need enough wallet balance to pass a credit check before they run. Models whose ID ends in `:free` don't need deposited credits. Requests can be throttled by a provider or by workspace and key limits; see [Rate Limits](./limits.mdx).
