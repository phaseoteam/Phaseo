Retrieve a music result created by `POST /music/generate`. This endpoint returns the stored normalized result for completed providers and polls the upstream provider when a job is still asynchronous.

## Response Shape

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "suno",
  "model": "V4_5PLUS",
  "nativeResponseId": "task_123",
  "output": [
    {
      "index": 0,
      "id": "clip_1",
      "audio_url": "https://...",
      "stream_audio_url": "https://...",
      "image_url": "https://...",
      "title": "Midnight Blue",
      "tags": "jazz, piano",
      "duration": 8
    }
  ],
  "usage": {
    "output_audio_count": 1,
    "output_audio_seconds": 8
  }
}
```

## Notes

- `status` can be: `queued`, `in_progress`, `completed`, `failed`.
- `usage` is included when generation is complete.
- Pass the Phaseo `id` returned by `POST /music/generate`, not `nativeResponseId`.
- Provider-specific status and retrieval APIs are handled behind this endpoint.
