openapi: "/openapi/v1/openapi.yaml POST /presets/{id}/upstream"
description: "Apply a public upstream version to a local fork draft."
---
<Note>This endpoint requires a management API key with `presets:write` and an associated user identity.</Note>

Publish or discard local draft changes before applying an upstream version. Applying does not publish the resulting draft.
