<Note>Identity administration requires an owner or admin identity. Enabling SSO or SCIM and creating provisioning tokens require the identity add-on.</Note>

Only the workspace owner can change SCIM provisioning or create and revoke its tokens. SCIM requests are accepted only with a token the current workspace owner created; if an admin or a previous owner created yours, the owner must create a new one.
