Use the OpenAI-compatible format for new calls: `input` contains text or user messages with inline `input_image` parts, and `questions` is an ordered array of `predicate`, `choice`, or `score` questions. Answers use the same order, with optional names. Boolean choice values remain booleans. Hosted image URLs are unsupported; Luna accepts up to 128 inline images, while other providers impose their own limits. Explicit image detail and `safety_identifier` require an OpenAI route. Existing `state`, named question maps, `noul`, and `criteria` remain supported and return the original answer map. Together Tev requires that legacy format because it returns labels without probabilities. The legacy examples below remain valid.

```json
{
  "model": "openai/gpt-6-luna",
  "input": "I was charged twice for my order.",
  "questions": [{
    "type": "choice",
    "name": "department",
    "instructions": "Which department should handle this?",
    "choices": [
      { "value": "billing", "description": "Payments and refunds" },
      { "value": "other", "description": "Everything else" }
    ]
  }]
}
```



Use `POST /v1/decisions` when your application needs structured answers that code can consume directly. Supported models include TypeSafe Jev 1.13 (`typesafe/jev-1.13.0`), Together Tev1 4B Experimental (`together/tev1-4b-experimental`), and Respan Span-01 (`respan/span-01:free` and `respan/span-01`).

The request contains:

- `state`: a string, object, or array containing the information to evaluate.
- `questions`: a map of named questions. Each question sets `type` to `noul`, `choice`, or `score` and includes `instructions`; supported types depend on the selected model.
- `model`: the Phaseo model ID. Use `typesafe/jev-1.13.0` for Jev 1.13, or `typesafe/jev-latest` to follow the latest Jev release.

Liquid D1 (`liquid-ai/d1:free`, also available as `liquid-ai/d1`) and Perplexity Decider 27B (`perplexity/decider-27b`) support all three question types. D1 is free during experimental early access. Decider costs $0.04 per million input tokens, including image tokens; output tokens are free. Add a Perplexity provider credential in Phaseo to use Decider. Its image state uses PNG, JPEG, or WebP base64 data URLs; remote image URLs are unsupported. Each choice question accepts up to 255 options, and each score question accepts up to 10 levels. Check model availability before calling either model.

Mercury Decide (`inception/mercury-decide`) supports predicate, choice, and score questions with text or JSON evidence. Choice questions accept up to 255 options; score questions accept up to 10 levels. Images, streaming, and tool calling are unsupported. Input is currently $0.02 per million tokens under Inception's 50% promotion; output tokens are reported but free. Inception has not published a promotion end date. Check model availability and [current upstream pricing](https://docs.inceptionlabs.ai/get-started/models) before use.

```json
{
  "model": "inception/mercury-decide",
  "input": "Please refund the duplicate charge on my account.",
  "questions": [{
    "type": "predicate",
    "name": "billing",
    "instructions": "Is this request about billing?"
  }]
}
```

Microsoft Decision (`microsoft/microsoft-decision-1`) uses an Azure Foundry deployment and supports predicate, choice, and score questions with text or JSON evidence. Its input limit is 32,768 tokens. Published pricing is $0.042 per million input tokens, with free output. Media, streaming, tools, `safety_identifier`, and `service_tier` are unsupported. Check model availability before calling it. See [Microsoft's guide](https://learn.microsoft.com/azure/foundry/foundry-models/how-to/use-foundry-models-microsoft-decision).

```json
{
  "model": "microsoft/microsoft-decision-1",
  "input": "The API returns 500 on every call.",
  "questions": [{
    "type": "choice",
    "name": "team",
    "instructions": "Which team should handle this ticket?",
    "choices": [
      { "value": "engineering", "description": "Bugs, errors, and outages" },
      { "value": "support", "description": "How-to and account questions" }
    ]
  }]
}
```

For Respan Span-01, `state` must be a conversation span with an `input` array of preceding messages and an `output` assistant message. Span-01 supports `noul` questions only. The `noul` answer is the probability that the behavior is present; `probabilities` also includes absent and not-observable probabilities.

```json
{
  "model": "respan/span-01:free",
  "state": {
    "input": [{ "role": "user", "content": "Please connect me to a person." }],
    "output": { "role": "assistant", "content": "I will connect you to support." }
  },
  "questions": {
    "escalation": {
      "type": "noul",
      "instructions": "Does the assistant offer a human handoff?"
    }
  }
}
```

`respan/span-01:free` is the free Lite model with a daily limit; Phaseo maps it to Respan's `span-01-free` API model ID. `respan/span-01` maps to Respan's `span-01-pro` API model ID and is billed by Respan at $0.02 per million input tokens; output tokens are free. Span-01 is in early access, so Respan must enable access for your organization. Add your Respan API key as a Respan provider credential in Phaseo before calling these models.

Answers use the same keys as `questions`. `choice` answers include the selected option, probabilities, and confidence; `noul` answers include a 0–1 probability; and `score` answers include a probability-weighted score, legend, probabilities, and confidence.

For the Respan example, a response looks like this:

```json
{
  "answers": {
    "escalation": {
      "type": "noul",
      "noul": 0.73,
      "probabilities": {
        "true": 0.73,
        "false": 0.25,
        "not_observable": 0.02
      }
    }
  }
}
```

Jev supports mixing all three question types in one request; Span-01 supports `noul` questions only. See the [Quickstart](../../quickstart) for copy-pasteable cURL, JavaScript, TypeScript SDK, and Python SDK examples. Jev 1.13 is billed at $0.042 per 1M input tokens; output tokens are free.

For the upstream question semantics, see TypeSafe's [API reference](https://docs.typesafe.ai/api).


### Image decisions with Clef

`cloudflare/clef` and `cloudflare/clef-flash` support all three question types and embedded images through Cloudflare Workers AI. Clef has a 65,536-token context window; Clef Flash has 24,576 tokens. Input costs $0.24 per million tokens for Clef and $0.038 for Clef Flash.

```json
{
  "model": "cloudflare/clef-flash",
  "state": "Inspect the attached product photo.",
  "images": [{ "content_type": "image/png", "base64": "<base64 image bytes>" }],
  "questions": {
    "damaged": { "type": "noul", "instructions": "Is the product visibly damaged?" }
  }
}
```

You can also supply a `data:image/png;base64,...` string in `images`. Clef accepts up to four PNG, JPEG, or WebP images, each at most 4 MiB and 16 megapixels, with at most 8 MiB of decoded image data and a 13 MiB request body. Remote URLs are unsupported. Cloudflare validates image formats and dimensions. Models without image support reject image requests.

Clef accepts at most 64 questions, with IDs of up to 100 letters, digits, underscores, dots, or hyphens. Choice questions require 2–255 options; score questions require 2–10 levels. See Cloudflare's [Clef documentation](https://developers.cloudflare.com/workers-ai/models/clef/).

### Audio and video decisions with Clef Omni

`cloudflare/clef-omni` accepts text, images, audio, and video with the same ordered `questions` and answers as other Decisions models. Audio and video are Phaseo extensions to the OpenAI-style input contract; OpenAI Decisions routes currently support text and images only. Check model availability before use.

This example requires an available Omni route and a Phaseo API key. Replace the placeholder audio bytes and video URL with your own media before sending it.

```json
{
  "model": "cloudflare/clef-omni",
  "input": [{
    "role": "user",
    "content": [
      { "type": "input_text", "text": "Review the recording and clip." },
      { "type": "input_audio", "input_audio": { "data": "<base64 WAV bytes>", "format": "wav" } },
      { "type": "input_video", "video_url": { "url": "https://media.example.com/clip.mp4" } }
    ]
  }],
  "questions": [{ "type": "predicate", "name": "safe", "instructions": "Is the equipment operating safely?" }]
}
```

Use `input_audio.data` with `format: "wav"` or `"mp3"`, or `input_audio.url` with a public HTTPS URL or an inline audio data URL. `input_video.video_url` accepts a string or `{ "url": "..." }` containing a public HTTPS URL or an inline MP4/WebM data URL. Remote servers must return the matching media Content-Type. Phaseo fetches URLs with size limits and private-address/redirect checks, then embeds the media for Cloudflare; provider credentials are never sent to the media server.

Omni accepts up to four audio clips (8 MiB and 300 seconds each) and two videos (16 MiB and 60 seconds each). Audio and video together cannot exceed 16 MiB decoded. Omni retains the per-image and combined-image limits above; its request-body limit replaces the 13 MiB Clef/Flash limit. Phaseo caps the complete Omni request body at 37 MiB. Cloudflare validates media encoding, image dimensions, and clip duration, and samples video at two frames per second. A video's soundtrack is used when every video in the request has one.

Omni has a documented 64,000-token context and costs $0.15 per million aggregate input tokens. Media tokens count toward context and billing; output is free. Phaseo settles against Cloudflare's reported input usage without adding separate audio or video charges. See [Cloudflare's Omni contract](https://github.com/cloudflare/cloudflare-docs/blob/production/src/content/workers-ai-models/clef-omni.json).
