Requires `spend_rules:write`. OAuth callers must be workspace owners or admins. Send each amount in USD (`*_usd`) or nanodollars (`*_nanos`), not both. A workspace can have 50 spend rules. See the [spend alerts guide](../../guides/spend-alerts.mdx) for the metrics, bases, scopes and periods.
