Generates music through one provider-independent API. Phaseo handles synchronous responses and provider queue polling behind the scenes.

For completed generations, the response includes `audio_url` or `audio_base64`. If a provider returns a non-terminal job, use the same response `id` with `GET /music/generate/{music_id}`.

## Request Shape

```json
{
  "model": "minimax/music-3.0:free",
  "prompt": "Warm jazz trio with brushed drums",
  "format": "mp3"
}
```

## Suno Options

- `suno.customMode` (boolean, default `false`)
- `suno.instrumental` (boolean, default `false`)
- `suno.prompt` (optional override for top-level `prompt`)
- `suno.style`, `suno.title` (required when `customMode = true`)
- `suno.personaId`, `suno.personaModel`
- `suno.negativeTags`, `suno.vocalGender`
- `suno.styleWeight`, `suno.weirdnessConstraint`, `suno.audioWeight`

## Validation Rules

- When `customMode = false`, `prompt` is required.
- When `customMode = true`, both `style` and `title` are required.
- When `customMode = true` and `instrumental = false`, `prompt` is required.

Validation errors return `400` with:

```json
{
  "error": "validation_error",
  "reason": "..."
}
```

## Response

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "gmicloud",
  "model": "minimax/music-3.0:free",
  "nativeResponseId": "5c30b275-d669-4a25-8151-de6d60214853",
  "audio_url": "https://.../generated-music.mp3",
  "usage": {
    "requests": 1,
    "output_audio_seconds": 25.364
  }
}
```

- `id` is the stable Phaseo request ID. Use it for retrieval through `GET /music/generate/{music_id}`.
- `nativeResponseId` is the upstream provider's identifier and is intended for provider correlation and support.
- `status` can be `queued`, `in_progress`, `completed`, or `failed`.
- `usage` can include `output_audio_seconds` when the provider reports generated duration.
