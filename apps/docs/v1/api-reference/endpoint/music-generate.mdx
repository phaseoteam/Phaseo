Send a `model` and `prompt` to `POST /v1/music/generate` to get a track from any music provider through one request shape. Phaseo handles synchronous providers and provider queue polling for you.

```bash
curl https://api.phaseo.app/v1/music/generate \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax/music-3.0:free",
    "prompt": "Warm jazz trio with brushed drums",
    "format": "mp3"
  }'
```

## Read the result

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "gmicloud",
  "model": "minimax/music-3.0:free",
  "nativeResponseId": "5c30b275-d669-4a25-8151-de6d60214853",
  "audio_url": "https://.../generated-music.mp3",
  "usage": {
    "requests": 1,
    "output_audio_seconds": 25.364
  }
}
```

A completed generation includes `audio_url` or `audio_base64`. `status` is `queued`, `in_progress`, `completed` or `failed`. When it isn't final yet, poll [`GET /v1/music/generate/{music_id}`](./music-status.mdx) with the same `id`.

`id` is the stable Phaseo request ID. `nativeResponseId` is the upstream provider's identifier, for provider correlation and support. `usage` includes `output_audio_seconds` when the provider reports the generated duration.

## Set Suno options

Suno models take an optional `suno` object:

| Field | Type | Notes |
| --- | --- | --- |
| `customMode` | boolean | Default `false` |
| `instrumental` | boolean | Default `false` |
| `prompt` | string | Overrides the top-level `prompt` |
| `style`, `title` | string | Required when `customMode` is `true` |
| `personaId`, `personaModel` | string | |
| `negativeTags` | string | |
| `vocalGender` | `m` or `f` | |
| `styleWeight`, `weirdnessConstraint`, `audioWeight` | number | 0 to 1 |

`prompt` is required when `customMode` is `false`, and when `customMode` is `true` with `instrumental` set to `false`.

A request that breaks a provider rule returns `400`:

```json
{
  "error": "validation_error",
  "reason": "..."
}
```
