---
title: "Remove workspace members"
sidebarTitle: "Remove members"
badge: "Beta"
openapi: "/openapi/v1/openapi.yaml POST /workspaces/{id}/members/remove"
description: "Remove non-owner members from a workspace."
---
<Note>This endpoint requires a management API key with `workspaces:write` and an owner or admin role.</Note>

The workspace owner cannot be removed.
