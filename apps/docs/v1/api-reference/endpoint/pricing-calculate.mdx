Send a usage payload to price it against the active gateway pricing rules for one provider, model and endpoint. All four fields are required:

- `provider`: the provider ID, for example `openai`.
- `model`: the routed model ID.
- `endpoint`: the endpoint family, for example `responses` or `chat.completions`.
- `usage`: the usage to price, such as token counts or other meter inputs.

To list current prices instead of pricing one payload, use [List model pricing](./pricing-models.mdx).
