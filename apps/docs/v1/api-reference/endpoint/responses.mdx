## Server tools

`/v1/responses` supports regular function tools and these gateway-managed server tools:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`
- `phaseo:apply_patch`

### Datetime example

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "input": [
      { "role": "user", "content": "Give me the current datetime in Asia/Tokyo." }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Asia/Tokyo" }
      }
    ],
    "tool_choice": "auto"
  }'
```

When a server tool is used, usage includes the matching `usage.server_tool_use.*` counters.

- `gateway:datetime` -> `datetime_requests`
- `phaseo:web_search` -> `web_search_requests`, `web_search_results`, `web_search_extra_results`
- `phaseo:web_fetch` -> `web_fetch_requests`
- `phaseo:advisor` -> `advisor_requests`
- `phaseo:image_generation` -> `image_generation_requests`
- `phaseo:apply_patch` -> `apply_patch_requests`

## Streaming note

`stream: true` is also supported. For gateway-managed server tools, Phaseo may materialize the upstream tool-call turn and re-emit a synthetic stream after continuing the loop.

## Reasoning in tool loops

Phaseo sends Responses requests upstream with `store: false`, so a model's reasoning continues between tool-loop steps only through the `reasoning` output items.

Each `reasoning` item has an `id`, `summary` and `content`. When the provider returns reasoning state, the item also has `encrypted_content`:

- OpenAI, Azure OpenAI and xAI encrypted reasoning. Phaseo requests it with `include: ["reasoning.encrypted_content"]` for reasoning models.
- Claude thinking signatures and redacted thinking.
- Gemini thought signatures, including a separate `reasoning` item placed just before the function call a signature belongs to.

Streaming responses carry the same items on `response.output_item.done` and `response.completed`.

To continue a tool loop, send every output item back in `input`, including `reasoning` items, unchanged. `encrypted_content` is opaque and records the provider and model that produced it. Phaseo sends it only to that provider family and model, so a fallback to another provider drops it rather than failing.
