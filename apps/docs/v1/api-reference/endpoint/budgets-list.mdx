openapi: "/openapi/v1/openapi.yaml GET /budgets"
description: "List enforced workspace spend ceilings with live usage and remaining spend."
---

Requires `budgets:read`. OAuth callers must have the workspace owner or admin role.

Usage is calculated from successful gateway requests. Reserved async work is included while its hold is active, so the returned remaining amount matches enforcement.
