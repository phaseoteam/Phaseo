<Note>Requires `keys:write` on a management key or OAuth token, or a workspace owner or admin. Trusted workloads is in beta; workspaces without it get `404`.</Note>

The platform, issuer and owner can't change. Create a new policy instead. Changes reach the gateway within a minute.

See [Trusted Workloads](../../developers/trusted-workloads.mdx) for how policies work and how to manage them with Terraform.
