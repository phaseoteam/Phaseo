## Choose a voice

Set the top-level `voice` for portable requests. Phaseo maps it to the routed provider's voice; a `voice` that the routed provider and model don't accept returns `400 invalid_request_error` with `param: "voice"`.

| Provider | Accepted `voice` values | Samples |
| --- | --- | --- |
| `openai` | Common voices, for example `alloy`, `ash`, `ballad`, `coral`, `echo`, `fable`, `onyx`, `nova`, `sage`, `shimmer`, `verse`, `cedar`, `marin` | [openai.fm](https://www.openai.fm/) |
| `google` (AI Studio / Gemini TTS) | Prebuilt voices: `Zephyr`, `Puck`, `Charon`, `Kore`, `Fenrir`, `Leda`, `Orus`, `Aoede`, `Callirrhoe`, `Autonoe`, `Enceladus`, `Iapetus`, `Umbriel`, `Algieba`, `Despina`, `Erinome`, `Algenib`, `Rasalgethi`, `Laomedeia`, `Achernar`, `Alnilam`, `Schedar`, `Gacrux`, `Pulcherrima`, `Achird`, `Zubenelgenubi`, `Vindemiatrix`, `Sadachbia`, `Sadaltager`, `Sulafat` | [Gemini text-to-speech docs](https://ai.google.dev/gemini-api/docs/speech-generation#voices) |
| `elevenlabs` | Common public starter voices, for example `rachel`, `domi`, `bella`, `antoni`, `elli`, `josh`, `arnold`, `adam`, `sam` | [ElevenLabs Voice Library](https://elevenlabs.io/voice-library) |

For `eleven-labs/eleven-v4` and `eleven-labs/eleven-v4-turbo`, pass any 20-character ElevenLabs voice library ID, including a custom clone. Set `config.elevenlabs.voice_settings.stability` and `similarity_boost` as needed. Eleven v4 does not support `speed` or `voice_settings.style`.

## Pass a provider-native voice

To use a provider's own voice setting instead of `voice`:

- ElevenLabs: `config.elevenlabs.voice_id`, `config.elevenlabs.voice` or `config.elevenlabs.voiceName`.
- Google: `config.google.voice_name` or `config.google.voiceName`.
