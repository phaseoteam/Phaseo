The response has three fields:

- `endpoints`: the canonical endpoint IDs currently exposed by the API.
- `data`: one record per endpoint with `id`, `capability_id`, `public_path`, `collection`, `model_count` and `provider_count`, sorted by `public_path`.
- `sample_models`: the first 10 visible model IDs from the public catalogue.

The response is cached for 30 minutes.

Use [List model endpoint capabilities](./model-endpoints) when you need provider- and parameter-level detail for one model.
