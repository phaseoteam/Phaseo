<Info>
Guardrail management requires a management API key. Read operations require `guardrails:read`; mutations require `guardrails:write` or `guardrails:delete`.
</Info>

Use guardrails to apply privacy controls, provider and model restrictions, prompt-injection handling, sensitive-information policies, and request or cost budgets. A guardrail can be assigned to API keys, workspace members, or both.

Successful mutations refresh workspace policy state and appear in the workspace audit log.
