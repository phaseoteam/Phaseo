## Server tools

`/v1/chat/completions` supports regular function tools and these gateway-managed server tools:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

### Datetime example

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Europe/London" }
      }
    ],
    "tool_choice": "auto"
  }'
```

When a server tool is used, usage includes:

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` adds `server_tool_use.web_search_requests`, `server_tool_use.web_search_results`, and `server_tool_use.web_search_extra_results`. `phaseo:web_fetch` adds `server_tool_use.web_fetch_requests`.

## Streaming note

`stream: true` is also supported. For gateway-managed server tools, Phaseo may materialize the upstream tool-call turn and re-emit a synthetic stream after continuing the loop.


## Reasoning in tool loops

Reasoning models return their reasoning on the assistant message in two fields:

- `reasoning_content`: the reasoning text, where the provider returns any.
- `reasoning_details`: an array of reasoning blocks in the format OpenRouter uses. Each entry has a `type` of `reasoning.text`, `reasoning.summary` or `reasoning.encrypted`, an `index`, and a `format` naming the provider family, for example `anthropic-claude-v1` or `google-gemini-v1`.

Entries can carry provider state that the model needs on the next step of a tool loop:

- Claude thinking signatures, in `signature` on `reasoning.text` entries.
- Claude redacted thinking and OpenAI encrypted reasoning, in `data` on `reasoning.encrypted` entries.
- Gemini thought signatures, in `data` on `reasoning.encrypted` entries whose `id` is the tool call they belong to.

When streaming, a `reasoning_details` delta arrives once each reasoning block is complete.

To keep the model's reasoning between steps, send the assistant message back with its `reasoning_details` unchanged. `signature` and `data` values are opaque and record the provider and model that produced them. Phaseo sends them only to that provider family and model, so a fallback to another provider drops them rather than failing. Claude models in manual thinking mode need their thinking back to keep thinking during a tool loop; if it is missing, that step runs without thinking.
