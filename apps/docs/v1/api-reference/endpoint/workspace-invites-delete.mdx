---
title: "Delete workspace invite"
sidebarTitle: "Delete invite"
badge: "Beta"
openapi: "/openapi/v1/openapi.yaml DELETE /workspaces/{id}/invites/{invite_id}"
description: "Permanently revoke a workspace invite."
---
<Note>This endpoint requires a management API key with `workspaces:write`.</Note>

Deleting an invite does not remove members who previously joined with it.
