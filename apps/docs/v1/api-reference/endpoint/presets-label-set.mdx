<Note>This endpoint requires a management API key with `presets:write` and an associated user identity. The preset's creator can change its labels, and so can workspace owners and admins when the preset is shared.</Note>

Requests that pin the label, such as `@support-triage@production` or `prompt.version: "production"`, use the new version within about two minutes. See [Versions and labels](/v1/guides/prompt-templates#versions-and-labels).
