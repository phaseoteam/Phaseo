<Note>Requires `keys:delete` on a management key or OAuth token, or a workspace owner or admin. Trusted workloads is in beta; workspaces without it get `404`.</Note>

Matching tokens are refused within a minute. Past requests keep their key in logs and usage.

See [Trusted Workloads](../../developers/trusted-workloads.mdx) for how policies work and how to manage them with Terraform.
