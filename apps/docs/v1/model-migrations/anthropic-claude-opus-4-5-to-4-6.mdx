Change the model to `anthropic/claude-opus-4.6`, remove assistant prefills, and move structured output to `output_config.format`. These are request-shape changes: old Opus 4.5 patterns fail with `400` if left in place.

| | Claude Opus 4.5 | Claude Opus 4.6 |
| --- | --- | --- |
| Phaseo model ID | `anthropic/claude-opus-4.5` | `anthropic/claude-opus-4.6` |
| Context window | 200K tokens | 1M tokens |
| Max output | 64K tokens | 128K tokens |
| Assistant prefill | Supported | Returns `400` |
| Structured output | `output_format` | `output_config.format` |
| Thinking | `budget_tokens` | Adaptive, steered by `output_config.effort` |
| `interleaved-thinking-2025-05-14` beta | Needed | Not needed |

## Update the request

**1. Remove assistant prefills.** If you pre-seed the assistant turn to force JSON or a prefix, Opus 4.6 returns `400`. Use clearer system instructions, examples in the prompt, or structured output instead.

**2. Move structured output** from `output_format` to `output_config.format`, and rerun your schema and parser tests:

```json
{
  "model": "anthropic/claude-opus-4.6",
  "max_tokens": 1024,
  "messages": [{ "role": "user", "content": "Extract the invoice fields." }],
  "output_config": {
    "format": { "type": "json_schema", "schema": { "type": "object", "properties": { "total": { "type": "number" } } } }
  }
}
```

On `/v1/chat/completions` and `/v1/responses`, keep using `response_format`.

**3. Switch thinking to adaptive.** Opus 4.6 doesn't think unless the request asks. On Phaseo, `reasoning.effort` or `reasoning.enabled: true` without a token budget turns on adaptive thinking, and the effort becomes `output_config.effort`. Opus 4.6 takes every effort level except `xhigh`, which Phaseo sends as `max`. While thinking is on, Phaseo leaves out `temperature` and `top_k`, and `top_p` below 0.95.

**4. Remove stale beta headers** from SDK wrappers, middleware, and presets. Phaseo doesn't forward `anthropic-beta` headers, so they no longer have any effect.

## What to test

- **Prompts:** long coding and refactor prompts, multi-step research and document workflows, prompts that relied on prefills, and long-context tasks if you'll use the 1M window.
- **Contracts and tools:** schema pass rate after moving to `output_config.format`, tool-call arguments on multi-step agent tasks, retries when the model refuses or reformats output, and code-review and debugging workflows.
- **Operations:** median and p95 latency with thinking on, token use on longer runs, timeout rate on large-context tasks, and success rate against Opus 4.5 on your evaluation set.

## Roll out

1. Remove prefills and migrate structured output before shifting any traffic.
2. Shadow Opus 4.6 on the production prompts that matter to you.
3. Canary with Opus 4.5 as a fallback in `models`.
4. Promote once schema pass rate, latency, and task completion hold.
