Change the model to `anthropic/claude-sonnet-4.6`, remove assistant prefills, and move structured output to `output_config.format`. Sonnet 4.6 shares these request changes with [Claude Opus 4.6](./anthropic-claude-opus-4-5-to-4-6); it also performs differently enough on coding, computer use, and agent planning that prompt and routing assumptions need re-testing.

| | Claude Sonnet 4.5 | Claude Sonnet 4.6 |
| --- | --- | --- |
| Phaseo model ID | `anthropic/claude-sonnet-4.5` | `anthropic/claude-sonnet-4.6` |
| Status | Deprecated; retires November 30, 2026 | Available |
| Context window | 200K tokens | 1M tokens |
| Max output | 64K tokens | 64K tokens |
| Assistant prefill | Supported | Returns `400` |
| Structured output | `output_format` | `output_config.format` |
| Thinking | `budget_tokens` | Adaptive, steered by `output_config.effort` |

## Update the request

**1. Stop using assistant prefills.** If your Sonnet 4.5 prompts start the assistant turn with a JSON prefix, XML tag, or formatting stub, remove it before rollout; Sonnet 4.6 returns `400`.

**2. Move structured output** from `output_format` to `output_config.format` on `/v1/messages`, and rerun your schema and parser tests. On `/v1/chat/completions` and `/v1/responses`, keep using `response_format`.

**3. Re-tune effort for latency.** Sonnet 4.6 thinks only when asked. On Phaseo, `reasoning.effort` or `reasoning.enabled: true` turns on adaptive thinking and sets `output_config.effort`; every level except `xhigh` is accepted, and `xhigh` is sent as `max`. Benchmark the levels against your latency budget before making 4.6 the default for interactive routes.

**4. Remove outdated beta headers.** Phaseo doesn't forward `anthropic-beta` headers.

## What to test

- **Output behavior:** formatting-sensitive prompts, multi-step agent planning, coding, refactor, and review prompts, and long-context retrieval and summarization.
- **Contract stability:** JSON and schema pass rate, tool argument completeness, finish reasons and empty outputs, and routes that relied on prefills.
- **Production metrics:** latency by effort level, task success against Sonnet 4.5, timeout and retry rates, and cost per successful task.

## Roll out

1. Remove prefills and update structured output first.
2. Evaluate Sonnet 4.6 on your current production prompts.
3. Canary with Sonnet 4.5 or another stable model as a fallback in `models`, and finish before Sonnet 4.5 retires.
4. Increase traffic once quality and contract stability hold.
