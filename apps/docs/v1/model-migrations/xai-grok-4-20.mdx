Change the model ID and re-run your validation set; request and response shapes stay the same. The only new control is how deep the multi-agent variant works.

| Model | Phaseo model ID | Reasoning control |
| --- | --- | --- |
| Grok 4.20 | `spacex-ai/grok-4.20` | `reasoning.enabled`: on or off |
| Grok 4.20 Multi-Agent (beta) | `spacex-ai/grok-4.20-multi-agent-beta` | `reasoning.effort`: `low`, `medium`, or `high` |

## Toggle reasoning on Grok 4.20

Set `reasoning.enabled: true` to use the reasoning version of the model. Without it, or with `false`, Phaseo calls the non-reasoning version.

```json
{
  "model": "spacex-ai/grok-4.20",
  "input": "Explain this architecture",
  "reasoning": { "enabled": true }
}
```

## Set depth on the multi-agent model

Control depth with `reasoning.effort`. Gateway requests don't take xAI's `agent_count`; according to xAI, `low` and `medium` run 4 agents and `high` runs a larger configuration.

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": { "effort": "medium" }
}
```
