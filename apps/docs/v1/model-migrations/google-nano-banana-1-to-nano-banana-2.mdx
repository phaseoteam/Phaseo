Switch image requests to `google/gemini-3.1-flash-image` (Nano Banana 2) and choose the aspect ratio and output size with `image_config`. Downstream code that assumes one image size is what breaks first.

| | Nano Banana | Nano Banana 2 |
| --- | --- | --- |
| Phaseo model ID | `google/gemini-2.5-flash-image` | `google/gemini-3.1-flash-image` |
| Status | Deprecated; retires March 15, 2027 | Available |

Nano Banana 2 adds explicit control over aspect ratio (`image_config.aspect_ratio`, such as `16:9` or `9:16`) and output size from 512px to 4K (`image_config.image_size`: `0.5K`, `1K`, `2K`, or `4K`). Google also reports better subject consistency across generations and edits, stronger instruction following, better text rendering and translation inside images, and higher fidelity at similar speed. Its successor, `google/gemini-nano-banana-2.1`, is also available.

```json
{
  "model": "google/gemini-3.1-flash-image",
  "messages": [{ "role": "user", "content": "A product photo of a ceramic mug on a walnut desk." }],
  "modalities": ["image", "text"],
  "image_config": { "aspect_ratio": "16:9", "image_size": "2K" }
}
```

Providers that can't take `image_config` drop it and list it in the `X-Phaseo-Dropped-Params` response header; see [Parameters](../api-reference/parameters).

## Update your product

1. **Check output assumptions.** If downstream code expects a fixed size, aspect ratio, or crop, update it first.
2. **Revisit presets:** social aspect ratios, default sizes, edit and inpaint workflows, and UI labels that describe image sizes.
3. **Shorten editing prompts.** Prompts that over-specify composition, text, or style to compensate for the older model may now be too rigid. Re-test shorter versions.

## What to test

- **Output quality:** vertical, square, and widescreen ratios; small versus large sizes; subject consistency across edits; text, signage, captions, and translated text in images.
- **Workflow:** file handling at larger sizes, timeouts on high-fidelity generations, moderation or human-review pass rate, and downstream resizing.
- **Product metrics:** end-to-end latency, usable-output rate, retry rate, and cost per approved asset.

## Roll out

1. Test by aspect ratio and size rather than as one migration.
2. Validate your asset pipeline at the largest size you'll support.
3. Sample real production prompts, especially edits and text-in-image requests.
4. If your UI exposes image options, ship default preset changes separately from the model swap.
