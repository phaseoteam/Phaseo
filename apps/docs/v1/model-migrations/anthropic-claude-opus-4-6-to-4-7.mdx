Change the model to `anthropic/claude-opus-4.7`, drop sampling parameters and thinking budgets, and set depth with an effort level. Requests that still carry Opus 4.6 fields don't fail on Phaseo; the gateway rewrites them as shown below.

| Opus 4.6 request | What Phaseo sends to Opus 4.7 |
| --- | --- |
| `temperature`, `top_p`, `top_k` | Left out. Anthropic would return `400` for non-default values. |
| `thinking: {"type": "enabled", "budget_tokens": …}` | `thinking: {"type": "adaptive", "display": "summarized"}`; the budget isn't forwarded. |
| `reasoning.effort` | `output_config.effort`, including `xhigh`. |
| `reasoning.effort: "none"` or `reasoning.enabled: false` | `thinking: {"type": "disabled"}`. |
| No reasoning setting | No `thinking` field, so Opus 4.7 doesn't think. |

Opus 4.7 also hides thinking content unless you opt in; Phaseo asks for the summarized display whenever it turns thinking on. Its tokenizer can produce more tokens than Opus 4.6 for the same text.

## Update the request

1. Set the model ID to `anthropic/claude-opus-4.7`.
2. Remove `temperature`, `top_p`, and `top_k`, and tune with instructions instead.
3. Replace thinking budgets with adaptive thinking and an effort level:

```json
{
  "model": "anthropic/claude-opus-4.7",
  "messages": [{ "role": "user", "content": "Refactor this module and explain the risks." }],
  "reasoning": { "effort": "xhigh" }
}
```

Start at `high` and use `xhigh` for the hardest coding and agentic routes. On `/v1/messages`, send `thinking: {"type": "adaptive"}` with `output_config.effort` instead.

4. Because the tokenizer changed, audit `max_tokens` and `max_output_tokens`, timeout budgets, and cost alerts.

## What to test

- schema pass rate on your production prompts;
- long-running tool workflows: tool call count, completion rate, and latency;
- quality at `high` versus `xhigh`;
- token cost on your highest-volume prompt classes.

## Roll out

1. Deploy the request-shape changes before shifting traffic.
2. Shadow Opus 4.7 on your production evaluation suite.
3. Canary with Opus 4.6 as a fallback in `models`.
4. Promote once quality, latency, and cost changes are within target.
