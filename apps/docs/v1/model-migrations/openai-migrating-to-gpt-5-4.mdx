Change the model to `openai/gpt-5.4`, keep the rest of the request, and choose a reasoning effort per route. The request shape is the same as earlier GPT-5 models; what changes is the effort range, image detail, and the computer tool. OpenAI's docs don't describe a GPT-5.4-specific `phase` parameter.

| Change | What to do |
| --- | --- |
| `reasoning.effort` takes `none`, `low`, `medium`, `high`, and `xhigh` | Re-test each route at the effort that fits its latency budget. |
| Image input `detail: "original"` for full-fidelity perception | Test it separately: it changes quality and cost. |
| The updated `computer` tool is the path for computer use | Move browser and desktop automation to it and retest end to end. |
| Better long-horizon tool use, large-context work, and document workflows | Re-run your agent and document evaluations. |

```json
{
  "model": "openai/gpt-5.4",
  "input": "Summarize the open risks in this design review.",
  "reasoning": { "effort": "medium" }
}
```

## Choose a reasoning effort

If you're coming from GPT-4.1 or an earlier GPT-5 model, don't assume your previous defaults still fit:

| Route | Start with |
| --- | --- |
| Low latency | `none` or `low` |
| Most structured tasks | `medium` or `high` |
| Deep reasoning and agentic workflows | `xhigh` |

## Send images at full detail

For dense screenshots, documents, or UI localization, set `detail: "original"` on the image input. Phaseo passes it to providers that support it, including OpenAI and Azure, and sends `high`, the closest level, to providers that don't.

## Move computer use to the `computer` tool

Update browser and desktop automation to the `computer` tool and retest step completion across whole tasks. Hosted tools are routed only to providers that run them.

## What to test

- **Prompts:** long system prompts, extraction and classification, format-sensitive outputs, and prompts that needed retries to stay on task.
- **Tools and structured outputs:** schema adherence at each effort level, tool selection, argument completeness, and multi-step computer-use stability.
- **Vision and operations:** screenshots and documents at `high` versus `original` detail, latency and token use under load, retry and timeout rate, and cost per successful task against the model you're replacing.

## Roll out

1. Benchmark GPT-5.4 at the exact effort levels you'll use.
2. Shadow production prompts before switching a default route.
3. Promote gradually, with an older OpenAI model or another provider as a fallback in `models`.
