Run a Ruby agent that looks up an internal note with a local tool and answers in one short paragraph, without handing orchestration to another system. When you're done you have one script that summarises your note about presets.

The tool returns fixed sample data, so the script is illustrative; replace it with a lookup in your own notes store. It suits a Ruby app that already owns the data and has simple, deterministic tool inputs.

## Build it

<Steps>
<Step title="Install">

```bash
gem install phaseo_agent_sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

Or add `gem "phaseo_agent_sdk"` to your `Gemfile`. It installs `phaseo_sdk` with it and needs Ruby 3.2 or newer. See [Ruby Agent SDK installation](../sdk-reference/agent/installation).

</Step>
<Step title="Write the agent">

```ruby notes.rb
require "phaseo_agent_sdk"

TOPICS = %w[presets routing guardrails].freeze

lookup_note = PhaseoAgentSdk.define_tool(
  PhaseoAgentSdk::Tool.new(
    id: "lookup-note",
    description: "Look up one internal note by topic.",
    parameters: {
      type: "object",
      properties: { topic: { type: "string", enum: TOPICS } },
      required: ["topic"],
      additionalProperties: false
    },
    # Arguments come from the model: only known topics reach execute.
    input_schema: lambda do |input|
      raise ArgumentError, "topic must be one of #{TOPICS.join(', ')}" unless input.is_a?(Hash) && TOPICS.include?(input["topic"])

      input
    end,
    execute: lambda do |input, _context|
      {
        topic: input["topic"],
        summary: "Presets centralize routing defaults so app code stays smaller."
      }
    end
  )
)

agent = PhaseoAgentSdk.create_agent(
  id: "notes-agent",
  model: "openai/gpt-6-astra",
  instructions: "Use tools when helpful and answer in one short paragraph.",
  tools: [lookup_note],
  max_steps: 4
)

# Reads PHASEO_API_KEY from the environment.
result = agent.run(
  input: "Summarize our note about presets.",
  client: PhaseoAgentSdk.create_gateway_agent_client
)

puts result.run.status
puts result.output
```

</Step>
<Step title="Run it">

```bash
ruby notes.rb
```

</Step>
</Steps>

## Check it worked

- The script prints `completed`, then one paragraph about presets.
- In **Settings → Usage → Logs**, the first model turn shows a `lookup-note` call with `{"topic": "presets"}`.

## Before production

Keep the tool read-only, and keep `max_steps` as low as the job allows (the default is `12`). If your notes store is large, return only the matching passage rather than whole documents, so each model turn stays small. To save runs and resume them later, see the [durable loop](./agent-sdk-durable-loop); the Ruby SDK's `state:` option works the same way. The [Ruby Agent SDK reference](../sdk-reference/agent/usage) covers state, approval and streaming.
