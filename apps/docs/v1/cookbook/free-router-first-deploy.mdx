Send `"model": "phaseo/free"` and Phaseo runs your request on an available free model that supports it, without credits. When you're done you have one working request in your language of choice and know which model answered it.

This is a production-ready request shape for prototypes, demos and low-stakes traffic. Free models don't promise latency, output style or a fixed provider.

## Send the request

<Steps>
<Step title="Set your key">

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="Send one request">

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```

```go Go
package main

import (
  "context"
  "fmt"
  "os"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New(os.Getenv("PHASEO_API_KEY"), "https://api.phaseo.app/v1")

  temperature := 0.2
  response, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
    Model:       "phaseo/free",
    Input:       "Summarize why provider-aware free routing helps prototypes.",
    Temperature: &temperature,
  })
  if err != nil {
    panic(err)
  }

  fmt.Printf("%+v\n", response)
}
```

## How a free model is picked

1. Your request goes to the shared `phaseo/free` alias.
2. Phaseo keeps the free models that can serve this request (endpoint, parameters, tools).
3. It sends the request to one of them.

Free models share an allowance of 1,500 requests per user per UTC day by default. Past it, requests return `429` with code `phaseo_free_model_limit_exceeded` until 00:00 UTC; see [Gateway limits](../api-reference/limits#gateway-limits).

## Move off the free router

If no free model supports a feature you need, such as tools or a JSON Schema, switch to a specific paid model instead of retrying the same request. Move to a fixed model when you need predictable latency, output style or provider choice, and put shared settings in a [preset](../guides/presets) so every service sends the same request. [Routing and fallbacks](../guides/routing-and-fallbacks) explains how paid requests pick a provider, and [API errors](../api-reference/errors) lists the error codes.
