Pick a recipe by what you want to build. Each one starts with the finished result, then gives the steps, the full code, how to run it, and how to check it worked. Each recipe says whether its code is ready for production or a starting point you need to finish.

Every example uses `https://api.phaseo.app/v1` and reads your key from `PHASEO_API_KEY`.

## Build agents

| [Research brief](./agent-sdk-research-brief) | TypeScript | Web search plus a strict JSON brief |
