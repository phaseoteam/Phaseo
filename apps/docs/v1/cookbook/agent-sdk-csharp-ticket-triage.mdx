Run a C# agent that loads a support ticket with a local tool and writes a short triage summary, inside one ASP.NET or worker service. When you're done you have a console app that prints the next action for ticket `T-1042`.

The tool returns fixed sample data, so the program is illustrative; replace it with your ticket store. It suits a service that already knows how to fetch internal ticket state and wants a narrow loop before adding queues or approvals.

## Build it

<Steps>
<Step title="Install">

```bash
dotnet new console -n TicketTriage
cd TicketTriage
dotnet add package Phaseo.AgentSdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

`Phaseo.AgentSdk` installs `Phaseo.Sdk` with it and needs .NET 8 or newer. See [C# Agent SDK installation](../sdk-reference/agent/installation).

</Step>
<Step title="Write the agent">

```csharp Program.cs
using System.Text.Json;
using System.Text.RegularExpressions;
using PhaseoAgentSdk;

var loadTicket = AgentSdk.DefineTool(new Tool(
    Id: "load-ticket",
    Description: "Load one support ticket by id.",
    Parameters: new Dictionary<string, object?>
    {
        ["type"] = "object",
        ["properties"] = new Dictionary<string, object?>
        {
            ["ticketId"] = new Dictionary<string, object?> { ["type"] = "string", ["pattern"] = "^T-\\d+$" },
        },
        ["required"] = new[] { "ticketId" },
        ["additionalProperties"] = false,
    },
    Execute: (input, ctx) => Task.FromResult<object?>(new Dictionary<string, object?>
    {
        ["ticketId"] = ((JsonElement)input!).GetProperty("ticketId").GetString(),
        ["severity"] = "medium",
        ["summary"] = "Customer cannot find preset routing settings.",
    })
))
{
    // Arguments come from the model: reject anything but a well-formed ticket id.
    InputSchema = input =>
    {
        if (input is JsonElement json
            && json.TryGetProperty("ticketId", out var id)
            && id.ValueKind == JsonValueKind.String
            && Regex.IsMatch(id.GetString()!, @"^T-\d+$"))
        {
            return input;
        }
        throw new ArgumentException("ticketId must look like T-1042");
    },
};

var agent = AgentSdk.CreateAgent(new AgentDefinition
{
    Id = "ticket-triage-agent",
    Model = "openai/gpt-6-astra",
    Instructions = "Use tools when helpful and answer with a short triage summary.",
    Tools = new[] { loadTicket },
    MaxSteps = 4,
});

// Reads PHASEO_API_KEY from the environment.
var result = await agent.Run(new RunOptions
{
    Input = "Review ticket T-1042 and summarize the next action.",
    Client = AgentSdk.CreateGatewayAgentClient(),
});

Console.WriteLine(result.Run.Status);
Console.WriteLine(result.Output);
```

</Step>
<Step title="Run it">

```bash
dotnet run
```

</Step>
</Steps>

## Check it worked

- The app prints `completed`, then a summary that mentions preset routing settings.
- In **Settings → Usage → Logs**, the first model turn shows a `load-ticket` call with `{"ticketId": "T-1042"}`.
- Without `PHASEO_API_KEY`, `CreateGatewayAgentClient` throws `PHASEO_API_KEY is required.`

## Before production

Keep `MaxSteps` low (the default is `12`), keep the tool read-only, and set `RequireApproval = true` on any tool that changes a ticket so the run pauses for a person. For a larger triage flow with a preset, strict JSON and review pauses, see [support triage](./agent-sdk-support-triage). The [C# Agent SDK reference](../sdk-reference/agent/usage) covers state, approval and streaming.
