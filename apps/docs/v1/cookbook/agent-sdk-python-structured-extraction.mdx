Run a Python agent that looks something up with one local tool and returns its answer as strict JSON. When you're done you have one script whose `result.output` is a validated `PolicySummary` object with `summary` and `recommendation`, not free text.

The tool returns fixed sample data, so the script is illustrative; replace it with your own lookup. It suits a Python worker that owns its orchestration and has a small, deterministic tool set.

## Build it

<Steps>
<Step title="Install">

<CodeGroup>
```bash pip
pip install phaseo-agent-sdk
```

```bash uv
uv add phaseo-agent-sdk
```
</CodeGroup>

`phaseo-agent-sdk` installs the `phaseo` client and Pydantic with it.

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="Write the agent">

```python extract.py
import json
import os

from pydantic import BaseModel, ConfigDict

from phaseo_agent import AgentTool, create_agent, create_gateway_agent_client, define_tool

POLICY_SLUGS = {"presets", "routing", "guardrails"}


class PolicySummary(BaseModel):
    model_config = ConfigDict(extra="forbid")
    summary: str
    recommendation: str


def check_lookup_input(value):
    # Model-generated arguments: reject anything that isn't a known slug.
    if not isinstance(value, dict) or set(value) != {"slug"} or value["slug"] not in POLICY_SLUGS:
        raise ValueError(f"slug must be one of {sorted(POLICY_SLUGS)}")
    return value


lookup_policy = define_tool(
    AgentTool(
        id="lookup-policy",
        description="Look up one internal policy by slug.",
        parameters={
            "type": "object",
            "properties": {"slug": {"type": "string", "enum": sorted(POLICY_SLUGS)}},
            "required": ["slug"],
            "additionalProperties": False,
        },
        input_schema=check_lookup_input,
        execute=lambda input, ctx: {
            "slug": input["slug"],
            "summary": "Presets centralize routing, prompts, and caching defaults.",
        },
    )
)

agent = create_agent(
    {
        "id": "policy-extractor",
        "model": "openai/gpt-6-astra",
        "instructions": "Use tools when needed and return JSON with summary and recommendation.",
        "tools": [lookup_policy],
        "max_steps": 4,
        "parse_output": json.loads,
        "output_schema": PolicySummary,
    }
)

# The Python client doesn't read PHASEO_API_KEY by itself: pass it.
client = create_gateway_agent_client(
    client_options={"api_key": os.environ["PHASEO_API_KEY"]},
    response_format={
        "type": "json_schema",
        "name": "policy_summary",
        "schema": {
            "type": "object",
            "properties": {
                "summary": {"type": "string"},
                "recommendation": {"type": "string"},
            },
            "required": ["summary", "recommendation"],
            "additionalProperties": False,
        },
    },
    plugins=[{"id": "response-healing"}],
)

result = agent.run(input="Look up our presets policy and recommend when to use it.", client=client)

print(result.run.status)
print(result.output)
```

| Piece | Does |
| --- | --- |
| `parameters` | The JSON Schema the model sees for the tool's arguments |
| `input_schema` | Checks the arguments before `execute` runs; a bad call fails the run |
| `response_format` | Asks the Gateway for this JSON Schema on every turn |
| `parse_output` and `output_schema` | Parse the final text and validate it into `PolicySummary` |

</Step>
<Step title="Run it">

```bash
python extract.py
```

</Step>
</Steps>

## Check it worked

- The script prints `completed`, then a `PolicySummary` with both fields filled.
- In **Settings → Usage → Logs**, the first model turn shows a `lookup-policy` call with `{"slug": "presets"}`.
- Output that doesn't match the model fails with `Invalid agent output` instead of returning a half-filled object.

For one-shot structured output without tools, call the [Python SDK directly](./sdk-python-presets-and-json). The [Python Agent SDK reference](../sdk-reference/agent/usage) covers state, approval and streaming.
