Run a standard-library Python CLI that calls Phaseo endpoints one command at a time. When you're done you have `python quickstart.py <command>` working for health, models, Responses and Chat Completions, plus commands for embeddings, moderation, images, OCR, video and music you can copy into a worker or backend.

The CLI is illustrative: it's a reference for request shapes, not a packaged tool. Several of its default model IDs for the media commands are no longer served, so pass `--model` for those (see [Pick models for the media commands](#pick-models-for-the-media-commands)).

## What the CLI does

The sample is [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart): one file, `quickstart.py`, using only `urllib`, `json` and `argparse`.

| Command | Calls |
| --- | --- |
| `smoke` | `GET /v1/health`, `GET /v1/models`, `GET /v1/providers`, and one `POST /v1/responses` |
| `health`, `models`, `providers` | The matching `GET` route |
| `responses --prompt` | `POST /v1/responses` |
| `chat --prompt` | `POST /v1/chat/completions` |
| `embeddings --text` | `POST /v1/embeddings` |
| `moderations --text` | `POST /v1/moderations` |
| `image --prompt` | `POST /v1/images/generations` |
| `ocr --image-url` | `POST /v1/ocr` |
| `video-create`, `video-status`, `video-cancel`, `video-download-url` | `POST /v1/videos`, `GET /v1/videos/{video_id}`, `POST /v1/videos/{video_id}/cancel`, `POST /v1/videos/{video_id}/download_url` |
| `music-create`, `music-status` | `POST /v1/music/generate`, `GET /v1/music/generate/{music_id}` |

Every request retries twice on `429`, `5xx` and network errors, with 1 s then 2 s waits, and times out after 45 seconds. Each command exits `1` when the call isn't `2xx`, so you can use it in scripts.

## Run it

You need Python 3 and a Phaseo API key.

<Steps>
<Step title="Create .env.local">

The script reads `.env.local` from the folder you run it in. The sample has no `.env.example`, so create the file:

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# Optional
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My Python CLI
PHASEO_HTTP_REFERER=https://myapp.example
```

Variables already set in your shell win over the file. Without `PHASEO_MODEL`, text commands use `openai/gpt-5.6-sol`.

</Step>
<Step title="Run the smoke check">

```bash
cd examples/gateway-python-quickstart
python quickstart.py smoke
```

`smoke` also sends one short Responses request, so it uses a few credits.

</Step>
<Step title="Send one request">

```bash
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

</Step>
</Steps>

## Check it worked

- `smoke` prints `HTTP 200` for every block and exits `0`.
- The `responses` command's output contains `integration_ok`.
- `--help` lists the commands without making a request.
- Without a key, the script prints `Missing PHASEO_API_KEY` and exits `1`.
- The requests appear in **Settings → Usage → Logs**.

## Pick models for the media commands

These defaults in `quickstart.py` are retired or have no active provider. Pass a current model with `--model`, and pick one from the [models page](https://phaseo.app/models) or `python quickstart.py models`:

| Command | Default in the sample | Status |
| --- | --- | --- |
| `moderations` | `openai/omni-moderation-latest` | Not a catalogue ID; use `openai/omni-moderation` |
| `ocr` | `mistral/mistral-ocr` | Retired; try `mistral/ocr-4.1` |
| `video-create` | `openai/sora-2` | Retired |
| `music-create` | `suno/suno-v4` | No active provider |

`embeddings` (`google/gemini-embedding-2`) and `image` (`openai/gpt-image-2`) defaults are served. Video and music jobs are asynchronous: store the returned ID and poll the status command; [Async video and batch](../guides/async-video-and-batch) covers the job lifecycle.

Strip the file down to the commands your service needs, keep the one shared `gateway_request()` helper, and switch to the [Python SDK](../sdk-reference/client/overview) when you want typed requests.
