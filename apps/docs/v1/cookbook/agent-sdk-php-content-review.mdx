Run a PHP agent that loads a CMS draft with a local tool and suggests an editorial change, inside the app or admin backend that already owns the content. When you're done you have one script that prints a headline suggestion for the homepage draft.

The tool returns fixed sample data, so the script is illustrative; replace it with your CMS lookup. It suits a PHP app where one or two local tools are enough.

## Build it

<Steps>
<Step title="Install">

```bash
composer require phaseo/agent-sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

`phaseo/agent-sdk` installs `phaseo/sdk` with it and needs PHP 8.1 or newer. See [PHP Agent SDK installation](../sdk-reference/agent/installation).

</Step>
<Step title="Write the agent">

```php review.php
<?php
require 'vendor/autoload.php';

use Phaseo\AgentSdk\AgentDefinition;
use Phaseo\AgentSdk\AgentSdk;
use Phaseo\AgentSdk\Tool;

const ALLOWED_SLUGS = ['homepage', 'pricing', 'about'];

$loadDraft = AgentSdk::defineTool(new Tool(
    id: 'load-draft',
    description: 'Load one CMS draft by slug.',
    parameters: [
        'type' => 'object',
        'properties' => [
            'slug' => ['type' => 'string', 'enum' => ALLOWED_SLUGS],
        ],
        'required' => ['slug'],
        'additionalProperties' => false,
    ],
    // Arguments come from the model: only known slugs reach execute.
    inputSchema: static function (mixed $input): array {
        if (!is_array($input) || !in_array($input['slug'] ?? null, ALLOWED_SLUGS, true)) {
            throw new InvalidArgumentException('slug must be one of ' . implode(', ', ALLOWED_SLUGS));
        }
        return $input;
    },
    execute: static fn (array $input, $context) => [
        'slug' => $input['slug'],
        'headline' => 'Phaseo makes gateway routing visible.',
    ],
));

$agent = AgentSdk::createAgent(new AgentDefinition(
    id: 'content-review-agent',
    model: 'openai/gpt-6-astra',
    instructions: 'Use tools when helpful and return concise editorial feedback.',
    tools: [$loadDraft],
    maxSteps: 4,
));

// Reads PHASEO_API_KEY from the environment.
$result = $agent->run(
    input: 'Review the homepage draft and suggest one headline improvement.',
    client: AgentSdk::createGatewayAgentClient(),
);

echo $result->run->status . PHP_EOL;
echo $result->output . PHP_EOL;
```

</Step>
<Step title="Run it">

```bash
php review.php
```

</Step>
</Steps>

## Check it worked

- The script prints `completed`, then one headline suggestion.
- In **Settings → Usage → Logs**, the first model turn shows a `load-draft` call with `{"slug": "homepage"}`.
- Without `PHASEO_API_KEY`, `createGatewayAgentClient()` throws `PHASEO_API_KEY is required`.

## Before production

Keep the tool read-only. If you add one that publishes or edits content, set `requireApproval: true` on it so the run pauses for an editor. To get the feedback as JSON your CMS can store, ask for a schema and repair near-valid output with [response healing](./response-healing-for-structured-json). The [PHP Agent SDK reference](../sdk-reference/agent/usage) covers state, approval and streaming.
