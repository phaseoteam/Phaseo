Use Phaseo to call models from multiple providers through one API, control routing, and track usage and costs.

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "openai/gpt-6-astra", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // reads PHASEO_API_KEY

const response = await client.generateResponse({
  model: "openai/gpt-6-astra",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # reads PHASEO_API_KEY

response = client.responses.create({"model": "openai/gpt-6-astra", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

No API key yet? [Create one in the dashboard](https://phaseo.app/settings/keys), then follow the [quickstart](./quickstart.mdx).
