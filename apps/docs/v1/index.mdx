## Choose a model

[Browse models](https://phaseo.app/models) or [compare them](https://phaseo.app/compare). Catalog entries can include models that are not routable; check Gateway availability before integrating. See [How Phaseo Works](./developers/introduction.mdx) for models, providers, and billing.

For documentation access inside an assistant, connect [Docs MCP](./guides/integrations/docs-mcp.mdx) or read the [agent capability summary](https://phaseo.app/docs/skill.md).
