## September 28, 2026

<p style={{ fontSize: "1rem", fontWeight: 600, marginTop: "1rem", marginBottom: "0.5rem" }}>Product</p>

- Speech prices now appear as character-based text input rates in provider details, with introductory discounts shown on the applicable SKU ([#2649](https://github.com/phaseoteam/Phaseo/pull/2649), [#2652](https://github.com/phaseoteam/Phaseo/pull/2652)).

<p style={{ fontSize: "1rem", fontWeight: 600, marginTop: "1rem", marginBottom: "0.5rem" }}>New Models</p>

- [Eleven v4](https://phaseo.app/models/eleven-labs/eleven-v4) and [Eleven v4 Turbo](https://phaseo.app/models/eleven-labs/eleven-v4-turbo) were added for speech generation with inline expressive tags and voice-library IDs. Introductory rates of $0.022 and $0.011 per 1,000 characters run through October 12; v4 request options are available in the API and SDKs ([#2646](https://github.com/phaseoteam/Phaseo/pull/2646), [#2649](https://github.com/phaseoteam/Phaseo/pull/2649)).

![Claude Sonnet 5.5 model release artwork](../images/model-releases/2026-09-28--anthropic--claude-sonnet-5.5.png)

- [Claude Sonnet 5.5](https://phaseo.app/models/anthropic/claude-sonnet-5.5) added with Anthropic, Claude Platform on AWS, Amazon Bedrock, and Google Vertex routes. Anthropic lists standard pricing at $2 per million input tokens and $10 per million output tokens.
