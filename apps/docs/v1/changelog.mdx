<Update label="October 28, 2026">

<div data-changelog-category="api">

<p className="changelog-category">API & SDKs</p>

- `/v1/embeddings` returns `400 validation_error` when a structured input field is a nested object or array; before, it returned `502` ([#3296](https://github.com/phaseoteam/Phaseo/pull/3296)).
- When every provider rejects a request with the same `400`, `413` or `422`, the gateway returns that status and the provider's message instead of `502` ([#3296](https://github.com/phaseoteam/Phaseo/pull/3296)).
- API key spend limit `429` errors show dollar amounts, such as `$0.0117 of $0.01`, and monthly limits keep their `Retry-After` header ([#3296](https://github.com/phaseoteam/Phaseo/pull/3296)).

</div>

</Update>

<Update label="October 27, 2026">

<div data-changelog-category="product">

<p className="changelog-category">Product</p>

- The preset editor's **Versions and labels** section points named labels at published versions, so moving a label rolls requests back in one click; see [Prompt Templates](./guides/prompt-templates.mdx) ([#3283](https://github.com/phaseoteam/Phaseo/pull/3283)).

</div>

<div data-changelog-category="api">

<p className="changelog-category">API & SDKs</p>

- Preset requests can pin a version or label with `prompt.version` or `model: "@slug@label"`, and an unknown one returns `404 preset_version_not_found`; see [Prompt Templates](./guides/prompt-templates.mdx) ([#3281](https://github.com/phaseoteam/Phaseo/pull/3281)).
- `GET /v1/presets/{id}/labels` lists preset labels, and `PUT` and `DELETE /v1/presets/{id}/labels/{label}` move and remove one; see [Set preset label](./api-reference/endpoint/presets-label-set.mdx) ([#3283](https://github.com/phaseoteam/Phaseo/pull/3283)).
- Streamed Chat Completions, Responses and Messages events now carry the Phaseo model ID in `model`; before, some carried the provider's own ID ([#3273](https://github.com/phaseoteam/Phaseo/pull/3273)).
- `GET /oauth/userinfo` returns `picture`, `name` and `given_name` for tokens with the `profile` scope, taken from the Phaseo profile ([#3189](https://github.com/phaseoteam/Phaseo/pull/3189)).

</div>

<Update label="October 24, 2026">

<div data-changelog-category="product">

<p className="changelog-category">Product</p>

- Every workspace can use retired model routing: owners and admins turn it on in **Settings -> Routing -> Retired model routing**, and requests go to the approved replacement; see [Model Deprecation and Retirement](./guides/model-retirement.mdx) ([#2899](https://github.com/phaseoteam/Phaseo/pull/2899), [#2896](https://github.com/phaseoteam/Phaseo/pull/2896)).
- Retired model routing uses an approved replacement only when it costs no more than the retired model, unless owners and admins allow a higher price; a replacement they choose themselves is used whatever it costs ([#2899](https://github.com/phaseoteam/Phaseo/pull/2899), [#3211](https://github.com/phaseoteam/Phaseo/pull/3211)).

</div>

- `POST /v1/keys` returns the new secret at the top level as `key`; see [Create API key](./api-reference/endpoint/keys-create.mdx) ([#3050](https://github.com/phaseoteam/Phaseo/pull/3050)).
- Text endpoints accept explicit `null` for optional parameters, `service_tier: "auto"` and `"scale"`, and `prediction`, which used to return `400` ([#3049](https://github.com/phaseoteam/Phaseo/pull/3049)).
- The `web` and `web-fetch` plugins work on any model, running as Phaseo's web search and web fetch server tools; see [Web Search Server Tool](./guides/server-tools/web-search.mdx) ([#3051](https://github.com/phaseoteam/Phaseo/pull/3051)).
- Rate limit policies enforce `tokens_per_minute` and return `x-ratelimit-limit-tokens`, `x-ratelimit-remaining-tokens` and `x-ratelimit-reset-tokens` headers; see [Rate Limits](./api-reference/limits.mdx) ([#2961](https://github.com/phaseoteam/Phaseo/pull/2961)).
- Rate limit policies assigned to a department now apply to that department's requests ([#3088](https://github.com/phaseoteam/Phaseo/pull/3088)).
- Prompt cache writes bill at the documented rates: 2x input for 1-hour Claude writes and 2.5x input for 12-hour OpenAI writes; see [Prompt Caching](./guides/prompt-caching.mdx) ([#3078](https://github.com/phaseoteam/Phaseo/pull/3078), [#3076](https://github.com/phaseoteam/Phaseo/pull/3076)).
- Responses usage returns `input_tokens_details.cache_write_tokens_details` with the 30-minute and 12-hour cache write split ([#3078](https://github.com/phaseoteam/Phaseo/pull/3078)).
