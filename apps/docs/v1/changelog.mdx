<Update label="October 24, 2026" tags={["Product"]} rss={{ title: "October 24, 2026: Product" }}>

- Retired model routing is available to every workspace. When no provider serves a retired model any more, its requests can go to the approved replacement instead of failing. It is off by default: owners and admins turn it on in **Settings -> Routing -> Retired model routing** and choose whether a replacement may cost more. Redirected responses carry the `x-phaseo-model-substitution` header. See [Model Deprecation and Retirement](./guides/model-retirement.mdx).

</Update>

<Update label="October 9, 2026" tags={["Product"]} rss={{ title: "October 9, 2026: Product" }}>

- Chat adds an opt-in Interactive answers experiment beside temporary chat, with comparison cards, tables, bar charts, and follow-up forms. Form values stay with each response variant, and submissions continue the conversation.

</Update>
