Cite the original benchmark as the primary source, and link to Phaseo where you looked up, compared or monitored models. A link in your methods, a footnote or the acknowledgements is enough:

> This work uses model metadata and aggregated benchmark results from [Phaseo](https://phaseo.app).

## Formal citation

Use the year you accessed the data.

<CodeGroup>
```text APA
Phaseo. (2026). Phaseo: Aggregated benchmarks and gateway for AI models. https://phaseo.app
```

```bibtex BibTeX
@misc{phaseo-2026,
    title  = {Phaseo: Aggregated benchmarks and gateway for AI models},
    author = {{Phaseo Team}},
    year   = {2026},
    url    = {https://phaseo.app}
}
```
</CodeGroup>

## Cite benchmark scores

Phaseo doesn't run benchmarks. It publishes scores reported by benchmark authors, model developers and index publishers, with a link to each source (see [Benchmark methodology](./benchmark-methodology.mdx)).

When you use a score you found on Phaseo:

1. Cite the original benchmark and paper as the primary source.
2. Optionally acknowledge Phaseo as where you retrieved or compared the score.
3. Include the benchmark name and split (for example `MMLU test`), the Phaseo model ID and provider, the URL of the Phaseo page or API call, and the date you accessed it.

> Benchmark scores were retrieved via Phaseo (MMLU test split), accessed 3 March 2026. Model: `openai/gpt-6-astra`, provider: OpenAI.

## Mention the Gateway

When Phaseo was your integration layer rather than a data source, describe it as the gateway and link to the [API reference](../api-reference/introduction.mdx):

> We used the Phaseo Gateway to call OpenAI, Anthropic, and Google models through a single API.
