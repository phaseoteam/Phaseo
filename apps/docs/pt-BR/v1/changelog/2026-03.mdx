<Update label="23 de março de 2026">

<div data-changelog-category="product">

<p className="changelog-category">Produto</p>

- As salas de chat agora podem executar modelos de áudio, moderação e embeddings, além de modelos de texto ([#201](https://github.com/phaseoteam/Phaseo/pull/201), [#157](https://github.com/phaseoteam/Phaseo/pull/157)).
- O Foundry, um novo espaço para projetos experimentais, estreia com o LLM Council, que envia um mesmo prompt a vários modelos e combina as respostas em uma só ([#201](https://github.com/phaseoteam/Phaseo/pull/201)).

</div>

<div data-changelog-category="api">

<p className="changelog-category">API e SDKs</p>

- SDKs para Go, C#, Java, PHP e Ruby agora estão disponíveis junto com os SDKs de TypeScript e Python, todos na versão `1.1.0` ([#203](https://github.com/phaseoteam/Phaseo/pull/203), [#201](https://github.com/phaseoteam/Phaseo/pull/201)).
- Os SDKs `1.1.0` avisam quando uma requisição usa um modelo obsoleto ou aposentado, e seus tipos de modelo e caminhos de rota correspondem à API ([#201](https://github.com/phaseoteam/Phaseo/pull/201), [#203](https://github.com/phaseoteam/Phaseo/pull/203)).

</div>

<Update label="2 de março de 2026">

<div data-changelog-category="api">

<p className="changelog-category">API e SDKs</p>

- A API Responses aceita e retorna o `phase` das mensagens do assistente (`commentary` ou `final_answer`), para que requisições de vários turnos possam reenviá-lo; veja [Criar uma resposta](../api-reference/endpoint/responses.mdx) ([#130](https://github.com/phaseoteam/Phaseo/pull/130)).
- Requisições Responses para modelos da OpenAI aceitam `provider_options.openai.context_management` com `type: "compaction"` e um `compact_threshold` opcional; veja [Parâmetros](../api-reference/parameters.mdx) ([#130](https://github.com/phaseoteam/Phaseo/pull/130)).
- Requisições para a OpenAI sem `safety_identifier` agora enviam um valor obtido de `user` ou `user_id` ou, na falta deles, do ID da requisição ([#130](https://github.com/phaseoteam/Phaseo/pull/130)).

</div>
