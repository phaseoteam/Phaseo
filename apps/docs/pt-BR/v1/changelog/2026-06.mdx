- **Alteração incompatível:** `GET /v1/models` agora é o único endpoint de descoberta de modelos; `/v1/gateway/models` e `/v1/data/models` foram removidos, então chame `/v1/models`; veja [Listar modelos](../api-reference/endpoint/models.mdx) ([#681](https://github.com/phaseoteam/Phaseo/pull/681)).
- A API de gerenciamento adiciona `/v1/presets`, `/v1/settings`, `/v1/guardrails` e `/v1/management-keys`, e `GET /v1/me` retorna o usuário e o workspace de um token OAuth ([#562](https://github.com/phaseoteam/Phaseo/pull/562)).
