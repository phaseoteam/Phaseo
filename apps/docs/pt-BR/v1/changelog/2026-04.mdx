<Update label="29 de abril de 2026" tags={["Novidades","Lançamentos de modelos","SDK"]}>

### Lançamentos do SDK

- O SDK `2.0.2` foi lançado para [TypeScript](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fsdk%402.0.2), [Python](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fpy-sdk%402.0.2), [Go](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fgo-sdk%402.0.2), [C#](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fcsharp-sdk%402.0.2), [Java](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fjava-sdk%402.0.2), [PHP](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fphp-sdk%402.0.2) e [Ruby](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fruby-sdk%402.0.2).
- Esta versão separou os IDs de modelo das solicitações em tempo de execução das constantes geradas para auxiliares chamáveis, permitindo usar novos modelos antes da próxima publicação do SDK.
- Os auxiliares gerados agora acompanham a versão atual dos modelos chamáveis no gateway, reduzindo mudanças desnecessárias no SDK causadas apenas por atualizações do catálogo.

<Update label="25 de abril de 2026" tags={["Novidades","Preços","Lançamentos de modelos"]}>

### Novidades

- Os alertas de saldo baixo e as proteções de cobrança foram ampliados para avisar as equipes com mais clareza antes de atingir os limites da conta ([PR #371](https://github.com/phaseoteam/Phaseo/pull/371)).
- Os casos extremos de preços agora falham de forma mais previsível quando as regras de cobrança do provedor estão incompletas ou os metadados da rota mudam inesperadamente ([PR #374](https://github.com/phaseoteam/Phaseo/pull/374)).
