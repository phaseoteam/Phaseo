## Escolha um modelo

[Explore modelos](https://phaseo.app/models) ou [compare-os](https://phaseo.app/compare). O catálogo pode incluir modelos sem rotas disponíveis; confira a disponibilidade no Gateway antes de integrar. Veja [Como o Phaseo funciona](./developers/introduction.mdx) para modelos, provedores e cobrança.

Para acessar documentação dentro de um assistente, conecte [Docs MCP](./guides/integrations/docs-mcp.mdx) ou leia o [resumo de recursos para agentes](https://phaseo.app/docs/skill.md).
