Chame modelos de vários provedores por uma única API em `https://api.phaseo.app/v1`, escolha como cada solicitação é roteada e acompanhe o uso e o custo por solicitação. Esta solicitação usa `phaseo/free`, então funciona antes de você adicionar créditos:

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "phaseo/free", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // lê PHASEO_API_KEY

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # lê PHASEO_API_KEY

response = client.responses.create({"model": "phaseo/free", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

Ainda não tem uma chave de API? Execute `phaseo keys create` com a [CLI do Phaseo](./guides/integrations/phaseo-cli) ou [crie uma no painel](https://phaseo.app/settings/keys) e depois siga o [início rápido](./quickstart.mdx).

## Escolha um modelo

[Explore os modelos](https://phaseo.app/models) ou [compare-os](https://phaseo.app/compare). O catálogo também lista modelos que você ainda não pode chamar, então confira se o modelo está **Ativo no Gateway** antes de integrá-lo ou liste os modelos que podem ser chamados com `GET /v1/models`. Veja [Como o Phaseo funciona](./developers/introduction.mdx) para saber sobre modelos, provedores e cobrança.
