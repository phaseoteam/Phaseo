Use o Phaseo para chamar modelos de vários provedores por uma API, controlar o roteamento e acompanhar uso e custos.

<CodeGroup>

```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "phaseo/free", "input": "Hello"}'
```

```typescript TypeScript
import Phaseo, { outputText } from "@phaseo/sdk";

const client = new Phaseo(); // reads PHASEO_API_KEY

const response = await client.generateResponse({
  model: "phaseo/free",
  input: "Hello",
});

console.log(outputText(response));
```

```python Python
from phaseo import Phaseo

client = Phaseo()  # reads PHASEO_API_KEY

response = client.responses.create({"model": "phaseo/free", "input": "Hello"})

print(response.output_text)
```

</CodeGroup>

Ainda não tem uma chave de API? Execute `phaseo keys create` com a [CLI da Phaseo](./guides/integrations/phaseo-cli) ou [crie uma no painel](https://phaseo.app/pt-BR/settings/keys) e depois siga o [início rápido](./quickstart.mdx).
