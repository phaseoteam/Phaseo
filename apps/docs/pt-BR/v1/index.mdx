Use esta página quando você souber o que quer criar, mas ainda não souber qual página da documentação da Phaseo consultar primeiro.

A Phaseo oferece uma única API para acessar modelos, rotear solicitações entre provedores, consultar preços, acompanhar o uso e executar fluxos assíncronos de IA.

Se você está começando com a Phaseo, faça primeiro uma solicitação funcionar. Se já tem uma integração de IA, vá direto ao guia de migração ou SDK mais adequado ao seu aplicativo.

## Sua primeira solicitação bem-sucedida

Para uma nova integração, siga este caminho:

1. Crie uma chave de API no painel.
2. Envie uma solicitação a um modelo de texto atual.
3. Leia o texto gerado na resposta.
4. Continue pelo guia de SDK, roteamento ou produção que corresponde ao seu próximo passo.

## Primeira solicitação

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-sol",
    "input": "Reply with: docs ready",
    "temperature": 0
  }'
```

```typescript TypeScript SDK
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-5.6-sol",
  input: "Reply with: docs ready",
  temperature: 0,
});

console.log(response.output_text);
```

```python Python SDK
from phaseo import Phaseo

client = Phaseo(api_key="YOUR_API_KEY")

response = client.generate_response(
    {
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with: docs ready",
        "temperature": 0,
    }
)

print(response.get("output_text"))
```
</CodeGroup>

Se funcionar, continue pelo [guia de início rápido](./quickstart.mdx) para concluir o passo a passo da primeira solicitação.
