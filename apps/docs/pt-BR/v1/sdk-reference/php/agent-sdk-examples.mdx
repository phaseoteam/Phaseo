## Implantação com aprovação

```php
$deploy = new Tool(
    id: "deploy",
    description: "Deploy the selected release",
    requireApproval: true,
    execute: fn (array $input, $runtime) => $deployments->deploy($input)
);
```

Armazene a execução retornada quando ela entrar em `waiting_for_human` e depois continue com uma decisão associada ao ID da chamada pendente.

## Transmitir texto

```php
$stream = $agent->stream(input: $prompt, client: $client);
foreach ($stream->textStream() as $delta) { echo $delta; }
$result = $stream->getResult();
```

## Limitar o trabalho autônomo

Combine limites de etapas, tokens, custo e duração para que o agente não exceda o orçamento da aplicação, mesmo que continue encontrando trabalho útil.
