---

**Métodos**: `generateText()`, `createChatCompletion()`

### Exemplo

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo(apiKey: $apiKey);

$response = $client->createChatCompletion([
    'model' => 'openai/gpt-4o-mini',
    'messages' => [[
        'role' => 'user',
        'content' => 'Write a limerick about lighthouses.',
    ]],
    'temperature' => 0.5
]);
echo $response['choices'][0]['message']['content'];
```

### Parâmetros principais

- `model` (obrigatório): ID do modelo de destino.
- `messages` (obrigatório): mensagens ordenadas com os papéis `system|user|assistant|tool`; o conteúdo usa objetos MessageContent.
- Amostragem: `temperature` (0–2), `top_p` (0–1), `top_k` (>=1), `seed` (int, opcional).
- Tamanho e penalidades: `max_output_tokens` (int), `presence_penalty` e `frequency_penalty` (-2 a 2), `stop` (string|string[]).
- Ferramentas: `tools` (definições), `tool_choice` (automática/nenhuma/ferramenta específica), `max_tool_calls` (int), `parallel_tool_calls` (bool).
- Logprobs: `logprobs` (bool), `top_logprobs` (0–20).
- Saída: `response_format` (json/text), `meta` (bool para incluir o bloco meta), `stream` (bool), `service_tier`.
- Opções adicionais do gateway: `usage` (bool para solicitar o uso).
