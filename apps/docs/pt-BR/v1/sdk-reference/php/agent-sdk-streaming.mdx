`Agent::stream(...)` retorna um `AgentStreamResult`:

```php
$stream = $agent->stream($input, $client);

foreach ($stream->textStream() as $delta) {
    echo $delta;
}

$completed = $stream->result;
```

Use `reasoningStream()`, `itemStream()` ou `fullStream()` para obter outras projeções. Cada iterável pode ser percorrido novamente depois que os eventos forem consumidos do fluxo síncrono do provedor.

Os valores de itens em PHP continuam sendo arrays e objetos genéricos, não a união discriminada de itens do TypeScript.
