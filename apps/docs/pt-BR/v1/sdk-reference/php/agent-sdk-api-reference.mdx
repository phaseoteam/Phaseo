| API | Finalidade |
| --- | --- |
| `AgentSdk::createAgent(...)` | Definir um agente |
| `AgentSdk::defineTool(...)` | Definir uma ferramenta local ou manual |
| `AgentSdk::createGatewayAgentClient(...)` | Conectar turnos do modelo ao Phaseo |
| `Agent::run(...)` | Executar até concluir ou pausar |
| `Agent::stream(...)` | Executar com iteráveis que podem ser percorridos novamente |
| `Agent::continueRun(...)` | Continuar um estado salvo ou pausado |
| `Agent::continueRunById(...)` | Recarregar e continuar por meio de um acessor de estado |
| `AgentStreamResult::textStream()` | Ler os fragmentos de texto |
| `AgentStreamResult::fullStream()` | Ler todos os eventos |

As principais classes incluem `AgentDefinition`, `RunResult`, `RunRecord`, `Tool`, `ToolDecision`, `ToolOutput`, `RuntimeContext`, `StateAccessor` e `GatewayAgentClientOptions`.
