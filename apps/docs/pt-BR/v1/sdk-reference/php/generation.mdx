**Método**: `getGeneration()`

### Exemplo

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo(apiKey: $apiKey);

$record = $client->getGeneration('G-01ABC...');
```

### Parâmetros

- `id` (string, obrigatório): ID da solicitação retornado por uma chamada anterior.

### Retorna

Registro de geração (JSON)

Se o gateway armazenou os detalhes completos da solicitação, o registro retornado também inclui `replay_supported` e `replay_request`, permitindo reenviar a carga capturada ao endpoint original para uma nova execução controlada.

Os campos de tempo seguem a semântica compartilhada do gateway:

- `latency_ms`: tempo até o primeiro token ou o primeiro byte/quadro de saída, quando registrado
- `generation_ms`: tempo de geração após a latência, quando registrado
