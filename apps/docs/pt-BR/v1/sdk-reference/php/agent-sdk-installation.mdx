O SDK de agentes é publicado como [`phaseo/agent-sdk`](https://packagist.org/packages/phaseo/agent-sdk) no Packagist.

## Requisitos

- PHP 8.1 ou superior
- Composer
- uma chave de API da Phaseo

## Instalação

```bash
composer require phaseo/agent-sdk
```

O pacote principal `phaseo/sdk` é instalado automaticamente como dependência.

## Ambiente

Defina sua chave de API do Gateway antes de executar os exemplos:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
