title: "Condições de parada"
description: "Limite execuções de agentes PHP por etapas, tokens, custo, duração, ferramentas ou motivo de conclusão."
---

Combine funções de parada para impor limites do produto independentemente da decisão do modelo de continuar.

```php
$agent = AgentSdk::createAgent(new AgentDefinition(
    id: "bounded-research",
    model: "openai/gpt-5.4-nano",
    stopWhen: [
        AgentSdk::stepCountIs(12),
        AgentSdk::maxTokensUsed(40000),
        AgentSdk::maxCost(2.50),
        AgentSdk::maxDuration(120000),
    ]
));
```

O SDK também oferece condições para chamadas de ferramentas e motivos de conclusão. Após a execução, inspecione `$result->run->stopReason` e o uso normalizado para que a aplicação diferencie uma parada por orçamento de uma conclusão normal do modelo.

Parar é um resultado limitado, não uma exceção automática. Decida quais motivos de parada o produto tratará como bem-sucedidos, repetíveis ou visíveis ao usuário.
