Use o crate publicado [`phaseo`](https://crates.io/crates/phaseo) para chamar o gateway da Phaseo em um aplicativo Rust.

O cliente de alto nível oferece suporte a:

- solicitações à API Responses com `Phaseo::responses(...)`
- solicitações de Chat Completions com `Phaseo::chat_completions(...)`
- outros endpoints JSON com `Phaseo::post(...)`
- configuração baseada no ambiente com `Phaseo::from_env()`
- endpoints HTTPS personalizados e servidores de desenvolvimento loopback
- status, corpo JSON, ID da solicitação e detalhes estruturados do erro

```rust
use phaseo::Phaseo;
use serde_json::json;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Phaseo::from_env()?;
    let response = client.responses(&json!({
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with exactly: Rust SDK works"
    }))?;

    println!("{}", response.body);
    Ok(())
}
```

<Note>
  A versão `0.1` tem suporte e está publicada, mas a API Rust ainda pode evoluir antes da `1.0`. Fixe uma versão minor compatível em produção.
</Note>

## Escopo atual

O cliente de alto nível é síncrono e aceita corpos de solicitação `serde_json::Value`. Os módulos de baixo nível gerados continuam disponíveis em `phaseo::gen`, com reexportações convenientes em `phaseo::client`, `phaseo::models` e `phaseo::operations`.

O cliente Rust ainda não oferece transporte assíncrono nem auxiliar de streaming de alto nível. Use a API HTTP bruta se o aplicativo precisar de streaming antes da inclusão desses recursos.
