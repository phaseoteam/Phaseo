## Requisitos

- Rust 1.86 ou mais recente
- uma chave de API do gateway da Phaseo

## Instalação

```toml
[dependencies]
phaseo = "0.1"
phaseo-agent = "0.1"
serde_json = "1"
```

Ou execute:

```bash
cargo add phaseo@0.1 phaseo-agent@0.1 serde_json
```

## Configurar a autenticação

`create_gateway_agent_client(...)` e `GatewayAgentClient::from_env(...)` leem `PHASEO_API_KEY`:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

O cliente `phaseo` subjacente também aceita `PHASEO_BASE_URL` opcionalmente.

## Verificar a instalação

```rust
use phaseo_agent::{create_agent, AgentDefinition};

fn main() {
    let _agent = create_agent(AgentDefinition::new(
        "verification-agent",
        "openai/gpt-6-astra",
    ));
    println!("Phaseo Rust Agent SDK installed");
}
```
