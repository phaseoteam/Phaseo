Escolha o exemplo mais simples que corresponda ao produto que você está criando. Cada padrão mantém a persistência e a interface do usuário na aplicação e usa o Phaseo para os turnos do modelo.

## Exemplos incluídos no pacote

| Exemplo | Uso |
| --- | --- |
| `research-brief-agent.ts` | Pesquisar com busca gerenciada e um resumo final tipado |
| `support-triage-agent.ts` | Encaminhar e classificar solicitações de suporte com um preset gerenciado |
| `coding-review-agent.ts` | Revisar código com ferramentas locais de execução |
| `parallel-tool-agent.ts` | Executar ferramentas locais independentes em paralelo |
