O Agent SDK é publicado no npm como [`@phaseo/agent-sdk`](https://www.npmjs.com/package/@phaseo/agent-sdk).

## Requisitos

- um projeto TypeScript ou JavaScript que use npm, pnpm, Yarn ou Bun
- uma chave de API da Phaseo

## Instalação

Instale o Agent SDK usando seu gerenciador de pacotes preferido:

<CodeGroup>

    ```bash title="npm"
    npm install @phaseo/agent-sdk
    ```

    ```bash title="pnpm"
    pnpm add @phaseo/agent-sdk
    ```

    ```bash title="yarn"
    yarn add @phaseo/agent-sdk
    ```

    ```bash title="bun"
    bun add @phaseo/agent-sdk
    ```

</CodeGroup>

O pacote principal `@phaseo/sdk` é instalado automaticamente como dependência.

## Ambiente

Defina a chave de API do gateway antes de executar os exemplos:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
