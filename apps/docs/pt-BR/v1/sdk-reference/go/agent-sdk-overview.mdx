O SDK de agentes Go é um runtime local completo para agentes do Phaseo Gateway, com novas tentativas, ferramentas concorrentes, contextos e timeouts, revisão humana, estado retomável, eventos do ciclo de vida e captura do DevTools.

Use quando você quiser:

- um loop de ferramentas leve e limitado
- solicitações ao endpoint `responses` do Gateway
- controle do aplicativo sobre persistência e orquestração

## O que o SDK oferece

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- solicitações ao endpoint `responses` do Gateway
