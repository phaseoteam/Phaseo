## Preparar o runtime

O Agent SDK ainda não tem uma versão pública do módulo Go. Siga as [instruções de instalação a partir do código-fonte](./agent-sdk-installation.mdx).

## Início rápido

```go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "quickstart-agent",
    Model:        "openai/gpt-5.4-nano",
    Instructions: "Answer concisely and helpfully.",
  })

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "Give me one fun fact about cURL.",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Output)
}
```

## O que inclui

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- um loop de ferramentas com limites usando a API `responses` da Phaseo

## Runtime avançado

O Go oferece validadores e aprovações, ferramentas HITL e manuais, progresso, erros recuperáveis, canais reproduzíveis, auxiliares de parada, turnos dinâmicos, `NextTurnParams` persistidos, uso e custo normalizados e `StateAccessor`.

## Streaming e cancelamento

`Agent.Stream(...)` e `Agent.ContinueStream(...)` consomem o stream SSE de Responses do gateway. Leia `Text()` ou `Events()` mais de uma vez quando consumidores diferentes precisarem reproduzir o stream e chame `Cancel()` para cancelar o contexto da solicitação. As etapas concluídas mantêm IDs de solicitação, metadados do provedor, motivos de conclusão, avisos, uso e custo.
