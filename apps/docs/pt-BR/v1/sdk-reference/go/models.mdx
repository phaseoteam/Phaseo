description: "Liste modelos com o wrapper de Go."
---

Use o método do wrapper:

- `client.GetModels(ctx, query)`

```go
import (
  "context"
  "fmt"
  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v2"
)

client := phaseo.New(apiKey, "https://api.phaseo.app/v1")
models, err := client.GetModels(context.Background(), map[string]string{
  "provider": "anthropic",
  "provider_status": "beta,not_ready",
  "provider_availability_reason": "preview_only,provider_not_ready",
  "capability_status": "coming_soon,internal_testing",
  "availability": "all",
  "limit": "10",
})
if err != nil {
  panic(err)
}

fmt.Println(models)
```

As chaves de consulta aceitas incluem `provider`, `provider_status`, `provider_routing_status`, `model_routing_status`, `capability_status`, `provider_availability_status`, `provider_availability_reason`, `status`, `organisation`, `endpoints`, `input_types`, `output_types`, `params`, `availability`, `limit` e `offset`.

Use `provider_availability_reason` com `availability=all` para obter estados de lançamento como `preview_only`, `provider_not_ready`, `gated`, `access_limited`, `region_limited`, `project_limited`, `paused` ou `soft_blocked`. Use `capability_status` com `availability=all` para obter mapeamentos de endpoints não roteáveis, como `coming_soon` ou `internal_testing`.
