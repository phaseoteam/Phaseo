O SDK de agentes é publicado como [`agent-sdk-go`](https://pkg.go.dev/github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go) por meio de módulos Go.

## Requisitos

- Go 1.24 ou superior
- uma chave de API da Phaseo

## Instalação

```bash
go get github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go@latest
```

O módulo principal `sdk-go/v2` é instalado automaticamente como dependência.

## Ambiente

Defina sua chave de API do Gateway antes de executar os exemplos:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
