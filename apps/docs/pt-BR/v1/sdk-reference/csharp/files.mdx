icon: "files"
title: "Arquivos"
description: "Use o SDK C# para enviar arquivos, consultar metadados e recuperar o conteúdo dos arquivos."
---

**Métodos**: `client.UploadFile()`, `client.ListFiles()`, `client.RetrieveFile()`, `client.RetrieveFileContent()`.

### Exemplo
```csharp
var client = new Phaseo(apiKey: apiKey);

var uploaded = await client.UploadFile(new Dictionary<string, object>
{
    ["purpose"] = "batch",
    ["file"] = "data:application/json;base64,eyJ0ZXN0Ijp0cnVlfQ=="
});

var file = await client.RetrieveFile("file_123");
var content = await client.RetrieveFileContent("file_123");
```

<Note>
`ListFiles()` está disponível no SDK, mas atualmente `GET /files` retorna `file_list_not_supported_with_shared_gateway_key` quando se usa a chave compartilhada do gateway
Armazene os IDs dos arquivos enviados e recupere-os diretamente.
</Note>
