O SDK de agentes é publicado no NuGet como [`Phaseo.AgentSdk`](https://www.nuget.org/packages/Phaseo.AgentSdk).

## Requisitos

- .NET 8 ou superior
- uma chave de API do Phaseo

## Instalação

```bash
dotnet add package Phaseo.AgentSdk
```

O pacote principal `Phaseo.Sdk` é instalado automaticamente como dependência.

## Ambiente

Defina sua chave de API do gateway antes de executar os exemplos:

```bash
set PHASEO_API_KEY=phaseo_v1_sk_...
```
