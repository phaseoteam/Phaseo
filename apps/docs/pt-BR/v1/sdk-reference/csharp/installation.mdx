O SDK é publicado como [`Phaseo.Sdk`](https://www.nuget.org/packages/Phaseo.Sdk) no NuGet.

## Requisitos

- .NET 8 ou superior

## Instalação

```bash
dotnet add package Phaseo.Sdk
```
