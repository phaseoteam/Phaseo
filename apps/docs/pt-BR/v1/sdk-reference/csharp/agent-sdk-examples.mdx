| Padrão | Combinação |
| --- | --- |
| Triagem de tickets | roteamento predefinido, ferramentas de consulta e resposta final estruturada |
| Revisão de código | ferramentas de repositório, progresso e aprovação antes das alterações |
| Resumo de pesquisa | busca gerenciada, texto em streaming e limites de custo |
| Runbook de operações | ferramentas de status, escalonamento e continuação persistente |

Comece com um agente, uma ou duas ferramentas determinísticas e aprovação explícita para ações com efeitos colaterais.
