Envie o áudio para `POST /v1/audio/transcriptions` como um formulário multipart com um campo `file`. Um corpo JSON com uma string base64 falha na validação. Só o SDK de TypeScript consegue enviar esse formulário; em todas as outras linguagens, envie-o com o cliente HTTP padrão, como abaixo, ou envie uma URL em vez disso (veja [Transcreva áudio a partir de uma URL](#transcribe-audio-from-a-url)).

<span id="upload-an-audio-file"></span>
## Envie um arquivo de áudio

<CodeGroup>

```typescript TypeScript
import { readFile } from "node:fs/promises";

const form = new FormData();
form.append("model", "openai/gpt-4o-transcribe");
form.append("language", "en");
form.append("file", new Blob([await readFile("call.mp3")], { type: "audio/mpeg" }), "call.mp3");

const transcript = await client.generateTranscription(form as unknown as Record<string, unknown>);
console.log(transcript.text);
```

```python Python
# generate_transcription() ainda não envia multipart, então envie o formulário com HTTPX.
import os
import httpx

with open("call.mp3", "rb") as audio:
    response = httpx.post(
        "https://api.phaseo.app/v1/audio/transcriptions",
        headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
        data={"model": "openai/gpt-4o-transcribe", "language": "en"},
        files={"file": ("call.mp3", audio, "audio/mpeg")},
        timeout=120,
    )
response.raise_for_status()
print(response.json()["text"])
```

```go Go
// CreateTranscription() envia JSON, então envie o formulário com net/http e mime/multipart.
var body bytes.Buffer
form := multipart.NewWriter(&body)
_ = form.WriteField("model", "openai/gpt-4o-transcribe")
_ = form.WriteField("language", "en")
part, _ := form.CreateFormFile("file", "call.mp3")
audio, _ := os.ReadFile("call.mp3")
_, _ = part.Write(audio)
_ = form.Close()

req, _ := http.NewRequest("POST", "https://api.phaseo.app/v1/audio/transcriptions", &body)
req.Header.Set("Authorization", "Bearer "+os.Getenv("PHASEO_API_KEY"))
req.Header.Set("Content-Type", form.FormDataContentType())

resp, err := http.DefaultClient.Do(req)
```

```csharp C#
// CreateTranscription() envia JSON, então envie o formulário com HttpClient.
using var http = new HttpClient();
http.DefaultRequestHeaders.Authorization =
    new("Bearer", Environment.GetEnvironmentVariable("PHASEO_API_KEY"));

using var form = new MultipartFormDataContent
{
    { new StringContent("openai/gpt-4o-transcribe"), "model" },
    { new StringContent("en"), "language" },
    { new ByteArrayContent(await File.ReadAllBytesAsync("call.mp3")), "file", "call.mp3" },
};

var response = await http.PostAsync("https://api.phaseo.app/v1/audio/transcriptions", form);
Console.WriteLine(await response.Content.ReadAsStringAsync());
```

```php PHP
<?php
// generateTranscription() envia JSON, então envie o formulário com o Guzzle, que o Composer instalou junto com o SDK.
require 'vendor/autoload.php';

$http = new GuzzleHttp\Client();

$response = $http->post('https://api.phaseo.app/v1/audio/transcriptions', [
    'headers' => ['Authorization' => 'Bearer ' . getenv('PHASEO_API_KEY')],
    'multipart' => [
        ['name' => 'model', 'contents' => 'openai/gpt-4o-transcribe'],
        ['name' => 'language', 'contents' => 'en'],
        ['name' => 'file', 'contents' => fopen('call.mp3', 'r'), 'filename' => 'call.mp3'],
    ],
]);

echo $response->getBody();
```

```ruby Ruby
# generate_transcription envia JSON, então envie o formulário com Net::HTTP.
require 'net/http'

uri = URI('https://api.phaseo.app/v1/audio/transcriptions')
request = Net::HTTP::Post.new(uri)
request['Authorization'] = "Bearer #{ENV.fetch('PHASEO_API_KEY')}"
request.set_form(
  [['model', 'openai/gpt-4o-transcribe'], ['language', 'en'], ['file', File.open('call.mp3')]],
  'multipart/form-data'
)

response = Net::HTTP.start(uri.host, uri.port, use_ssl: true) { |http| http.request(request) }
puts response.body
```

```java Java
// Os helpers JSON do SDK não codificam multipart, então envie o formulário com java.net.http.
import java.io.IOException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpRequest.BodyPublishers;
import java.net.http.HttpResponse.BodyHandlers;
import java.nio.file.Path;
import java.time.Duration;
import java.util.UUID;

String baseUrl = System.getenv().getOrDefault("PHASEO_BASE_URL", "https://api.phaseo.app/v1")
    .replaceAll("/+$", "");
String apiKey = System.getenv("PHASEO_API_KEY");
String boundary = "phaseo-" + UUID.randomUUID();
var body = BodyPublishers.concat(
    BodyPublishers.ofString("--" + boundary + "\r\nContent-Disposition: form-data; name=\"model\"\r\n\r\nopenai/gpt-4o-transcribe\r\n"),
    BodyPublishers.ofString("--" + boundary + "\r\nContent-Disposition: form-data; name=\"language\"\r\n\r\nen\r\n"),
    BodyPublishers.ofString("--" + boundary + "\r\nContent-Disposition: form-data; name=\"file\"; filename=\"call.mp3\"\r\nContent-Type: audio/mpeg\r\n\r\n"),
    BodyPublishers.ofFile(Path.of("call.mp3")),
    BodyPublishers.ofString("\r\n--" + boundary + "--\r\n")
);
var request = HttpRequest.newBuilder(URI.create(baseUrl + "/audio/transcriptions"))
    .header("Authorization", "Bearer " + apiKey)
    .header("Content-Type", "multipart/form-data; boundary=" + boundary)
    .timeout(Duration.ofSeconds(60))
    .POST(body)
    .build();
var response = HttpClient.newHttpClient().send(request, BodyHandlers.ofString());
if (response.statusCode() < 200 || response.statusCode() >= 300) {
    throw new IOException("HTTP " + response.statusCode() + ": " + response.body());
}
System.out.println(response.body());
```

</CodeGroup>

| Linguagem | Método do SDK | Consegue enviar um arquivo? |
| --- | --- | --- |
| TypeScript | `client.generateTranscription(form)` | Sim. Passe um corpo `FormData` e o SDK o envia como multipart sem alterações. O cast é necessário porque o tipo do método descreve um corpo JSON. |
| Python | `client.generate_transcription(request)` | Não. Ele sempre envia JSON, então envie o formulário com HTTPX, como acima. |
| Go | `client.CreateTranscription(ctx, req)` | Não. Ele envia JSON; use `net/http` e `mime/multipart`. |
| C# | `client.CreateTranscription(request)` | Não. Ele envia JSON; use `HttpClient` e `MultipartFormDataContent`. |
| PHP | `$client->generateTranscription($request)`, alias `createTranscription()` | Não. Ele envia JSON; use a opção `multipart` do Guzzle. |
| Ruby | `client.generate_transcription(...)`, alias `create_transcription` | Não. Ele envia JSON; use `Net::HTTP` e `set_form`. |
| Java | Nenhum | Não. Use `java.net.http.HttpClient` com um corpo multipart. |
| Rust | Nenhum | Não. `client.post()` envia apenas JSON, então só funciona para [origens por URL](#transcribe-audio-from-a-url). |

## Transcreva áudio a partir de uma URL

Os modelos da Mistral, da ElevenLabs e da Morpheus conseguem ler o áudio de uma URL em vez de um upload. Como essa solicitação é JSON, os métodos dos SDKs que não conseguem enviar arquivos dão conta dela:

<CodeGroup>

```python Python
result = client.generate_transcription({
    "model": "mistral/voxtral-mini-transcribe-2",
    "file_url": "https://example.com/call.mp3",
    "language": "en",
})

print(result["text"])
```

```go Go
resp, err := client.CreateTranscription(context.Background(), map[string]interface{}{
  "model":    "mistral/voxtral-mini-transcribe-2",
  "file_url": "https://example.com/call.mp3",
  "language": "en",
})
if err != nil {
  panic(err)
}
fmt.Println(resp["text"])
```

```csharp C#
var response = await client.CreateTranscription(new Dictionary<string, object>
{
    ["model"] = "mistral/voxtral-mini-transcribe-2",
    ["file_url"] = "https://example.com/call.mp3",
    ["language"] = "en",
});
```

```php PHP
$response = $client->generateTranscription([
    'model' => 'mistral/voxtral-mini-transcribe-2',
    'file_url' => 'https://example.com/call.mp3',
    'language' => 'en',
]);

echo $response['text'];
```

```ruby Ruby
response = client.generate_transcription(
  model: 'mistral/voxtral-mini-transcribe-2',
  file_url: 'https://example.com/call.mp3',
  language: 'en'
)
```

```rust Rust
let response = client.post("/audio/transcriptions", &json!({
    "model": "mistral/voxtral-mini-transcribe-2",
    "file_url": "https://example.com/call.mp3",
    "language": "en"
}))?;

println!("{}", response.body["text"]);
```

</CodeGroup>

## Parâmetros

Os nomes dos campos são os campos do formulário (ou campos JSON, para uma origem por URL) em todas as linguagens.

| Campo | Observações |
| --- | --- |
| `model` | Obrigatório. Um ID de modelo de transcrição. |
| `file` | O áudio enviado: `aac`, `flac`, `mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `ogg`, `opus`, `wav` ou `webm`. Obrigatório, exceto nas opções de URL abaixo. Até 25 MB na maioria dos modelos. |
| `file_url`, `file_id`, `s3_presigned_url` | Os modelos da Mistral, da ElevenLabs e da Morpheus aceitam exatamente uma origem de áudio, então podem usar uma URL em vez de `file`. |
| `language` | Dica de idioma, como `en`. |
| `prompt` | Contexto para melhorar a precisão. |
| `temperature` | De `0` a `1` (de `0` a `2` na ElevenLabs). |
| `response_format` | `json`, `text`, `srt`, `verbose_json`, `vtt` ou `diarized_json`. |
| `timestamp_granularities` | `word` e/ou `segment`. |
| `stream` | Transmite a transcrição à medida que ela é produzida, quando o modelo dá suporte. |

O schema completo está na [referência da API de transcrições](/pt-BR/v1/api-reference/endpoint/audio-transcriptions).

## Resposta

`AudioTranscriptionResponse`, retornada no tipo de mapa de cada SDK (`map[string]interface{}` em Go, `Dictionary<string, object>?` em C#, um array em PHP, um Hash em Ruby):

```json
{
  "text": "Hello world"
}
```
