Envie texto para `POST /v1/audio/speech` e receba o áudio falado no formato que você pedir. Os exemplos usam um `client` criado como em [Instalação](./installation).

<CodeGroup>

```typescript TypeScript
import { writeFile } from "node:fs/promises";

const audio = await client.generateSpeech({
  model: "openai/gpt-4o-mini-tts",
  input: "Hello world",
  voice: "alloy",
  format: "mp3",
});

await writeFile("hello.mp3", Buffer.from(await audio.arrayBuffer()));
```

```python Python
audio = client.generate_speech({
    "model": "openai/gpt-4o-mini-tts",
    "input": "Hello world",
    "voice": "alloy",
    "format": "mp3",
})

with open("hello.mp3", "wb") as file:
    file.write(audio)
```

```go Go
audio, err := client.CreateSpeech(context.Background(), map[string]interface{}{
  "model":  "openai/gpt-4o-mini-tts",
  "input":  "Hello world",
  "voice":  "alloy",
  "format": "mp3",
})
if err != nil {
  panic(err)
}
fmt.Printf("%T\n", audio) // verifique o tipo concreto antes de gravá-lo em um arquivo
```

```csharp C#
var audio = await client.CreateSpeech(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-4o-mini-tts",
    ["input"] = "Hello world",
    ["voice"] = "alloy",
    ["format"] = "mp3",
});
```

```php PHP
$audio = $client->createSpeech([
    'model' => 'openai/gpt-4o-mini-tts',
    'input' => 'Hello world',
    'voice' => 'alloy',
    'format' => 'mp3',

```

```ruby Ruby

  model: 'openai/gpt-4o-mini-tts',

  format: 'mp3'

```

```java Java

{
  "model": "openai/gpt-4o-mini-tts",
```

## Método por linguagem

| Linguagem | Método | Retorna |
| --- | --- | --- |
| TypeScript | `client.generateSpeech(request)` | Um `Blob` |
| Python | `client.generate_speech(request)` ou `client.audio.speech.create(request)` | `bytes` |
| Go | `client.CreateSpeech(ctx, req)` | `interface{}`; verifique o tipo concreto antes de gravá-lo em um arquivo |
| C# | `client.CreateSpeech(request)` | `object?`; verifique o tipo concreto antes de gravá-lo em um arquivo |
| PHP | `$client->createSpeech($request)` | O áudio; verifique o tipo do valor antes de gravá-lo em um arquivo |
| Ruby | `client.generate_speech(...)`, alias `create_speech` | O áudio; verifique a classe do valor antes de gravá-lo em um arquivo |
| Java | Não há método de fala. `client.rawClient().requestBytes("POST", "/audio/speech", ...)` envia o corpo JSON | `byte[]` |

O Rust não tem método de fala, e o helper `post()` dele interpreta as respostas como JSON, então não consegue retornar áudio.

## Parâmetros

Os nomes dos campos são os campos do corpo JSON em todos os SDKs. Use `format`: a API também aceita `response_format`, mas o tipo de solicitação do TypeScript o rejeita.

| Campo | Observações |
| --- | --- |
| `model` | Obrigatório. Um ID de modelo de fala. |
| `input` | Obrigatório. Texto a ser falado. A maioria dos provedores aceita até 4.096 caracteres; os modelos da ElevenLabs permitem de 5.000 a 40.000, dependendo do modelo. |
| `voice` | Um alias de voz normalizado entre provedores (recomendado), o valor de voz do próprio provedor ou um objeto com `id` ou `name`. Se a voz não for válida para o provedor roteado, a API retorna `400` com `param: "voice"`. |
| `format` | `mp3`, `wav`, `ogg`, `aac`, `flac`, `opus` ou `pcm`. |
| `speed` | Velocidade de reprodução, de `0.25` a `4`. |
| `instructions` | Orientações de estilo, quando o modelo dá suporte. |
| `config` | Configurações específicas do provedor; veja abaixo. |
| `provider` | Preferências de roteamento de provedores. |

O schema completo está na [referência da API de fala](/pt-BR/v1/api-reference/endpoint/audio-speech).

## Defina a voz própria de um provedor

Passe a voz exata do provedor em `config`. O mesmo objeto aninhado funciona no mapa de solicitação de todos os SDKs.

<CodeGroup>

```typescript TypeScript
// ElevenLabs: escolha um ID de voz exato
await client.generateSpeech({
  model: "eleven-labs/eleven-v3",
  input: "Hello from ElevenLabs",
  voice: "rachel",
  config: {
    elevenlabs: {
      voice_id: "21m00Tcm4TlvDq8ikWAM",
    },
  },
});

// Google: escolha um nome de voz exato
await client.generateSpeech({
  model: "google/gemini-3.1-flash-tts-preview",
  input: "Hello from Gemini",
  voice: "kore",
  config: {
    google: {
      voice_name: "Kore",
    },
  },
});
```

```python Python
# ElevenLabs: escolha um ID de voz exato
client.generate_speech({
    "model": "eleven-labs/eleven-v3",
    "input": "Hello from ElevenLabs",
    "voice": "rachel",
    "config": {"elevenlabs": {"voice_id": "21m00Tcm4TlvDq8ikWAM"}},
})

# Google: escolha um nome de voz exato
client.generate_speech({
    "model": "google/gemini-3.1-flash-tts-preview",
    "input": "Hello from Gemini",
    "voice": "kore",
    "config": {"google": {"voice_name": "Kore"}},
})
```
