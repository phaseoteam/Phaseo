Passe um ID de solicitação (como `G-01ABC...`) ao método de geração do SDK para buscar o registro armazenado dessa solicitação em `GET /v1/generations?id=<id>`.

<CodeGroup>

```typescript TypeScript
const record = await client.getGeneration("G-01ABC...");
```

```python Python
record = client.get_generation("G-01ABC...")

print(record["model_id"], record["cost_nanos"])
```

```go Go
client, err := phaseo.NewFromEnv()
if err != nil {
  panic(err)
}

record, err := client.GetGeneration(context.Background(), "G-01ABC...")
if err != nil {
  panic(err)
}
fmt.Println(record["status_code"], record["cost_nanos"])
```

```csharp C#
using PhaseoSdk;

var client = new Phaseo();
var record = await client.GetGeneration("G-01ABC...");
```

```php PHP
<?php
require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$client = new Phaseo();
$record = $client->getGeneration('G-01ABC...');
```

```ruby Ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new
record = client.get_generation('G-01ABC...')
```

```java Java
import app.phaseo.sdk.Phaseo;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

var record = client.getGeneration("G-01ABC...");
System.out.println(record);
```

</CodeGroup>

| Linguagem | Método | Retorna |
| --- | --- | --- |
| TypeScript | `client.getGeneration(id)` | O objeto do registro |
| Python | `client.get_generation(id)` | Dict `APIResponse` |
| Go | `client.GetGeneration(ctx, id)` | `map[string]interface{}` |
| C# | `client.GetGeneration(id)` | `Dictionary<string, object>?` |
| PHP | `$client->getGeneration($id)` | Array |
| Ruby | `client.get_generation(id)` | Hash |
| Java | `client.getGeneration(id)` | `JsonNode` do Jackson |
| Rust | Não há helper; chame `client.request("GET", "/generations?id=<id>", None, &RequestOptions::default())` | `PhaseoResponse`, com o registro em `body` (um `serde_json::Value`) |

A consulta é limitada ao seu espaço de trabalho. Um `id` ausente retorna `400` (`missing_id`), e um ID que não está no seu espaço de trabalho retorna `404` (`not_found`).

## Reexecute uma solicitação armazenada

Se o gateway armazenou a solicitação completa, o registro tem `replay_supported` definido como true e um `replay_request`, que você pode enviar de volta ao endpoint original para uma reexecução controlada.

## Leia os campos de tempo

- `latency_ms`: tempo até o primeiro token, ou o primeiro byte ou frame de saída, quando medido.
- `generation_ms`: tempo de geração depois desse ponto, quando medido.
