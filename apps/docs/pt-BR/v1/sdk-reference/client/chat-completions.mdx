Chame o método de chat do SDK para enviar `POST /v1/chat/completions` e receber uma resposta completa. Para novas integrações, a [API Responses](./responses) oferece um único formato de solicitação para texto, entrada multimodal, ferramentas e itens de saída mais ricos.

```typescript TypeScript
console.log(chat.choices[0].message.content);
```

```rust Rust
fn main() -> Result<(), Box<dyn std::error::Error>> {

        "model": "openai/gpt-6-astra",
        "messages": [
            {
                "role": "system",
                "content": "Answer concisely."
            },
            {
```

</CodeGroup>

| Linguagem | Método | Retorna |
| --- | --- | --- |
| TypeScript | `client.generateText(request)`; `client.chat.completions.create(request)` faz o mesmo e passa para streaming quando `stream` é true | `ChatCompletionsResponse` |
| Python | `client.generate_text(request)`; também `client.chat.completions.create(request)` | Dict `APIResponse` |
| Go | `client.GenerateText(ctx, req)`, alias `CreateChatCompletion`; recebe um `phaseo.ChatCompletionsRequest` | `map[string]interface{}` |
| C# | `client.GenerateText(request)`, alias `CreateChatCompletion` | `Dictionary<string, object>?` |
| PHP | `$client->generateText($request)`, alias `createChatCompletion()` | Array |
| Ruby | `client.generate_text(...)`, alias `create_chat_completion` | Hash |
| Java | `client.createChatCompletion(request)`; recebe um `Map` ou um `JsonNode` do Jackson | `JsonNode` do Jackson |
| Rust | `client.chat_completions(&request)` | `PhaseoResponse`; o JSON fica em `body` |

Todos os valores de retorno têm o formato de Chat Completions: a resposta fica em `choices[0].message.content`, com `finish_reason` e `usage` ao lado.

## Transmita a resposta

<CodeGroup>

```typescript TypeScript
for await (const chunk of client.streamChat({
  model: "openai/gpt-6-astra",
  messages: [{ role: "user", content: "Stream a story" }],
})) {
  if (chunk.text) process.stdout.write(chunk.text);
}
```

```python Python
for chunk in client.stream_chat({
    "model": "openai/gpt-6-astra",
    "messages": [{"role": "user", "content": "Stream a story"}],
}):
    if chunk.get("text"):
        print(chunk["text"], end="", flush=True)
```

```java Java
import app.phaseo.sdk.Phaseo;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.List;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));
var payload = Map.of(
    "model", "openai/gpt-6-astra",
    "messages", List.of(Map.of("role", "user", "content", "Hello")),
    "stream", true
);
try (var lines = client.rawClient().requestLines(
    "POST", "/chat/completions", null, null,
    new ObjectMapper().writeValueAsString(payload)
)) {
    lines.forEach(System.out::println);
}
```

</CodeGroup>

| Linguagem | Como transmitir |
| --- | --- |
| TypeScript | `client.streamChat(request)` produz chunks já interpretados; `client.streamText()` produz as linhas SSE brutas. |
| Python | `client.stream_chat(request)` produz chunks já interpretados; `client.stream_text()` produz as linhas SSE brutas. |
| Java | `createChatCompletion` retorna um único corpo JSON. Defina `stream: true` e envie a solicitação com `rawClient().requestLines`, que retorna as linhas SSE à medida que chegam; feche-o com try-with-resources. |
| Go, C#, PHP, Ruby, Rust | Não há helper de streaming para Chat Completions; deixe `stream` sem definir. Em C#, PHP e Ruby, [Responses](./responses#stream-the-response) tem um método de streaming. |

Cada chunk interpretado (TypeScript e Python) mantém os campos originais (`choices`, `id`, …) e adiciona `text` (o conteúdo acrescentado por esse chunk), `usage` e os tokens de raciocínio (`reasoningTokens` / `reasoning_tokens`).

## Parâmetros

Os nomes dos campos são os campos do corpo JSON em todos os SDKs. O tipo `phaseo.ChatCompletionsRequest` do Go usa campos de struct em PascalCase (`Model`, `Messages`).

| Grupo | Campos |
| --- | --- |
| Obrigatórios | `model`; `messages` com os papéis `system`, `developer`, `user`, `assistant` ou `tool`, e conteúdo como string ou partes |
| Amostragem | `temperature` (0–2), `top_p` (0–1), `top_k` (-1 ou mais), `min_p` (0–1), `seed`, quando o modelo dá suporte |
| Tamanho e penalidades | `max_tokens` ou `max_completion_tokens`, `presence_penalty` e `frequency_penalty` (de -2 a 2), `repetition_penalty` (acima de 0), `stop` (string ou array) |
| Ferramentas | `tools`, `tool_choice`, `max_tool_calls`, `parallel_tool_calls` |
| Raciocínio | Objeto `reasoning` ou `reasoning_effort` |
| Log probabilities | `logprobs`, `top_logprobs` (0–20) |
| Saída | `response_format`, `n` (1–16), `stream`, `service_tier`, `metadata` (valores string) |
| Gateway | Roteamento `provider`, `usage` (incluir o uso), `meta` (incluir o bloco meta do gateway) |

[Parâmetros](/pt-BR/v1/api-reference/parameters) explica cada campo, e a [referência da API de Chat Completions](../../api-reference/endpoint/chat-completions) tem o schema completo.

## Resposta

`ChatCompletionsResponse`:

```json
{
  "id": "chatcmpl-123",
  "object": "chat.completion",
  "created": 1677652288,
  "model": "openai/gpt-6-astra",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello there, how may I assist you today?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 9,
    "completion_tokens": 12,
    "total_tokens": 21
  }
}
```

Com `stream: true`, o endpoint envia frames SSE que terminam com `data: [DONE]`:

