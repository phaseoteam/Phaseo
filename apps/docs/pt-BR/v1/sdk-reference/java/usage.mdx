```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

Use `createResponse`, `createChatCompletion`, `createEmbedding` e `listModels` para solicitações JSON. Passe um `Map` ou `JsonNode`; converta strings JSON antes de passá-las aos métodos do cliente.

## Novas tentativas e erros

As novas tentativas estão desativadas por padrão. `setMaxRetries` repete solicitações GET/HEAD seguras; escritas e solicitações de streaming não são repetidas. `Client.ApiException` expõe status, corpo, cabeçalhos e ID da solicitação em erros HTTP.

```java
import app.phaseo.gen.Client;
import app.phaseo.sdk.Phaseo;
import java.time.Duration;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"))
    .setTimeout(Duration.ofSeconds(30))
    .setMaxRetries(2);

try {
    var result = client.requestWithResponse("GET", "/models",
        Map.of("limit", "5"), null, null, null);
    System.out.println(result.requestId());
    System.out.println(result.data);
} catch (Client.ApiException error) {
    System.err.println(error.getStatusCode());
    System.err.println(error.getRequestId());
    System.err.println(error.getResponseBody());
}
```

## Streaming

`streamResponse` e `rawClient().requestLines` retornam linhas SSE à medida que chegam. Feche o fluxo com try-with-resources e processe nomes de eventos, dados e marcadores de conclusão na aplicação.

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));
try (var lines = client.streamResponse(Map.of(
    "model", "openai/gpt-6-astra", "input", "Hello"
))) {
    lines.forEach(System.out::println);
}
```
