---
icon: "search-check"
title: "Consulta de gerações"
description: "Chame `/generations` para recuperar um registro de geração anterior."
---

**Método**: `client.getGeneration(...)`

```java
import app.phaseo.sdk.Phaseo;

Phaseo client = new Phaseo(System.getenv("PHASEO_API_KEY"));

Object generation = client.getGeneration("G-01ABC123");
System.out.println(String.valueOf(generation));
```

Quando os detalhes da solicitação são armazenados, o registro de geração retornado também inclui `replay_supported` e `replay_request` para reenviar o payload capturado ao endpoint original.
