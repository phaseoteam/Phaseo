Envie solicitações de texto, embeddings e consulta de modelos com o SDK Java.

<Note>O código-fonte atual inclui controles de novas tentativas e metadados de resposta ausentes no antigo artefato 3.0.0 do Maven Central. Compile a revisão indicada para usar o SDK atual. [Instalação](./installation)</Note>

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

## Solicitações suportadas

Use `createResponse`, `createChatCompletion`, `createEmbedding` e `listModels` para solicitações JSON. Passe um `Map` ou `JsonNode`; converta strings JSON antes de passá-las aos métodos do cliente.

## Streaming

`streamResponse` e `rawClient().requestLines` retornam linhas SSE à medida que chegam. Feche o fluxo com try-with-resources e processe nomes de eventos, dados e marcadores de conclusão na aplicação.

<Note>O método `createSpeech` espera JSON e não decodifica áudio binário. Use `rawClient().requestBytes` para obter áudio.</Note>
