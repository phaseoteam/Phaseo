Comece com um destes padrões:

| Padrão | Combine |
| --- | --- |
| Triagem de suporte | preset gerenciado, ferramentas de consulta, saída final estruturada |
| Revisão de código | ferramentas de arquivos ou patches, eventos de progresso, aprovação antes das edições |
| Resumo de pesquisa | ferramentas web gerenciadas, limites de custo e etapas, texto em streaming |
| Runbook operacional | ferramentas de status, escalonamento manual, continuação persistente |

Mantenha a primeira implementação enxuta: um agente, uma ou duas ferramentas determinísticas e aprovação explícita para efeitos colaterais.
