O código-fonte atual inclui controles de novas tentativas e metadados de resposta ausentes no antigo artefato 3.0.0 do Maven Central. Compile a revisão indicada para usar o SDK atual.

## Requisitos

- Java 17+
- Maven 3.8+
- Git

## Compilar a partir do código-fonte

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
git checkout 1ff1119f41ceb3ac2c85ed605f6e1c4beca6e011
mvn -f packages/sdk/sdk-java/pom.xml -DskipTests install
```

O Maven instala `app.phaseo:phaseo-sdk:3.0.0` no repositório local, incluindo a dependência do Jackson.

## Adicionar a dependência

```xml
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-sdk</artifactId>
  <version>3.0.0</version>
</dependency>
```

<Note>O [artefato do Maven Central](https://repo.maven.apache.org/maven2/app/phaseo/phaseo-sdk/3.0.0/) fornece a API anterior. Ele não inclui as APIs atuais de novas tentativas, metadados ou validação de parâmetros.</Note>
