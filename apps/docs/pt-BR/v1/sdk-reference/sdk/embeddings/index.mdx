Passe `phaseo.embeddingModel(modelId)` (ou o alias `textEmbeddingModel`) para `embed`, com um valor, ou para `embedMany`, com uma lista. As solicitações vão para o endpoint `/v1/embeddings` do Gateway.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { embed, embedMany } from "ai";

const single = await embed({
  model: phaseo.textEmbeddingModel("google/gemini-embedding-001"),
  value: "Embeddings power semantic search.",
});

console.log(single.embedding.length);

const batch = await embedMany({
  model: phaseo.textEmbeddingModel("google/gemini-embedding-001"),
  values: ["pricing", "latency", "quality"],
});

console.log(batch.embeddings.length);
```

## Manter os vetores comparáveis

- Gere os embeddings das consultas e do corpus com a mesma versão do modelo.
- Normalize os vetores de forma consistente antes de calcular a similaridade.
- Armazene em cache os embeddings estáveis de conteúdo repetido.
