Passe `output: Output.object({ schema })` para `generateText` para receber um objeto tipado que corresponde ao seu schema. O AI SDK envia o schema como um formato de resposta JSON Schema e valida o resultado.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, Output } from "ai";
import { z } from "zod";

const { output } = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  output: Output.object({
    schema: z.object({
      title: z.string(),
      priority: z.enum(["low", "medium", "high"]),
      actions: z.array(z.string()),
    }),
  }),
  prompt: "Create a short incident follow-up plan.",
});

console.log(output);
```

`generateObject` ainda funciona no AI SDK 7 com o mesmo `schema` e retorna `object`, mas foi descontinuado em favor de `generateText` com `output`.

## Lidar com saída inválida

Ler `output` lança `NoOutputGeneratedError` quando o modelo não retorna um objeto utilizável, por exemplo quando a última etapa terminou em uma chamada de ferramenta. Capture esse erro onde você chama o modelo.

- Use enums explícitos e campos obrigatórios no schema.
- Mantenha o prompt consistente com a forma do schema.
- O suporte a saída JSON Schema varia entre modelos; confira os parâmetros compatíveis do modelo em `/v1/models`.
