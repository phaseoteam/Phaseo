Chame `streamText` com `phaseo(modelId)` e leia `textStream` para receber o texto à medida que ele chega. `streamText` retorna imediatamente; leia `providerMetadata` depois que o stream terminar.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Transmitir a partir do histórico do chat

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## Interromper um stream abandonado

Passe um `abortSignal` para `streamText` e cancele-o quando o usuário sair ou um timeout expirar, para que a solicitação não continue em execução:

```ts
const controller = new AbortController();
setTimeout(() => controller.abort(), 60_000);

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a long report.",
  abortSignal: controller.signal,
});
```

Leia os IDs de modelo em `/v1/models` em vez de fixá-los no código; consulte [Descoberta de modelos](/pt-BR/v1/sdk-reference/sdk/get-models).
