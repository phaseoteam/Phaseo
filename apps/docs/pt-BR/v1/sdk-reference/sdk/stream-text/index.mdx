description: "Gere texto em streaming com o Vercel AI SDK e a Phaseo."
---

Use `streamText` quando quiser receber tokens parciais à medida que chegam.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  prompt: "Explain SSE streaming in plain language.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Streaming com mensagens

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-5-nano"),
  messages: [
    { role: "user", content: "Write a five-step rollout plan for a gateway migration." },
  ],
});

let text = "";
for await (const chunk of result.textStream) {
  text += chunk;
}

console.log(text);
console.log(await result.providerMetadata);
```

## Dicas para produção

- Prefira streaming para respostas longas e interfaces interativas.
- Trate cancelamentos e timeouts no runtime para transmissões abandonadas.
- Mantenha os IDs de modelo atualizados por `/v1/models` para evitar aliases desatualizados.
