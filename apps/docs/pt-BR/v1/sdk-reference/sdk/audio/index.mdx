Passe `phaseo.transcriptionModel(modelId)` para `transcribe` para converter fala em texto e `phaseo.speechModel(modelId)` para `generateSpeech` para converter texto em fala. O provedor envia o áudio para `/v1/audio/transcriptions` como um formulário multipart e envia as solicitações de fala para `/v1/audio/speech`.

```ts
import { readFileSync, writeFileSync } from "node:fs";
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateSpeech, transcribe } from "ai";

const transcription = await transcribe({
  model: phaseo.transcriptionModel("openai/whisper-1"),
  audio: readFileSync("./audio.mp3"),
});

console.log(transcription.text);
console.log(transcription.providerMetadata);

const speech = await generateSpeech({
  model: phaseo.speechModel("openai/gpt-4o-mini-tts"),
  text: "Hello from Phaseo audio.",
  voice: "alloy",
  outputFormat: "mp3",
});

writeFileSync("./speech.mp3", Buffer.from(speech.audio.uint8Array));
console.log(speech.providerMetadata);
```

`audio` aceita um `Buffer`, `Uint8Array`, `ArrayBuffer`, string base64 ou `URL`. O AI SDK 7 ainda exporta os nomes antigos `experimental_transcribe` e `experimental_generateSpeech` como aliases.

## Lidar com áudios longos ou com falhas

- Os formatos de entrada e saída compatíveis dependem do modelo.
- Aumente os timeouts para arquivos longos e mantenha os uploads dentro do limite de tamanho do modelo (25 MB na maioria dos modelos).
- Repita respostas `429` e `5xx` transitórias com backoff.
