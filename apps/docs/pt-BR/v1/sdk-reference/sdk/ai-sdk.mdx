Instale `@phaseo/ai-sdk-provider` e passe `phaseo(modelId)` como `model` para `generateText`, `streamText` ou qualquer outra função do Vercel AI SDK 7. As solicitações de texto vão para o endpoint `/v1/chat/completions` do Gateway.

## Instalar

<CodeGroup>

```bash title="npm"
npm install @phaseo/ai-sdk-provider
```

```bash title="pnpm"
pnpm add @phaseo/ai-sdk-provider
```

```bash title="yarn"
yarn add @phaseo/ai-sdk-provider
```

```bash title="bun"
bun add @phaseo/ai-sdk-provider
```

</CodeGroup>

O pacote sem versão instala a tag `latest` do npm, que é a linha do AI SDK 7. Ele declara `ai@^7` como dependência peer, então gerenciadores de pacotes que instalam peers automaticamente a adicionam para você.

Defina `PHASEO_API_KEY` no ambiente do servidor e faça sua primeira solicitação. O export padrão `phaseo` lança um erro se `PHASEO_API_KEY` não estiver definida.

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Reply with: AI SDK works",
});

console.log(result.text);
console.log(result.providerMetadata);
```

Use um ID de modelo atual do [endpoint Models](../../api-reference/endpoint/models.mdx).

## Transmitir texto

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Stream a short greeting.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## Configurar uma instância do provedor

Chame `createPhaseo()` para definir `apiKey`, `baseURL`, `headers` ou um `fetch` personalizado. Use-o para identificar seu aplicativo nos detalhes das solicitações do Phaseo:

```typescript
import { createPhaseo } from "@phaseo/ai-sdk-provider";

const phaseo = createPhaseo({
  apiKey: process.env.PHASEO_API_KEY,
  headers: {
    "x-title": "My App",
    "http-referer": "https://example.com",
  },
});
```

`PHASEO_BASE_URL` é opcional e tem como padrão `https://api.phaseo.app/v1`.

## Escolher um tipo de modelo

| Método do provedor | Função do AI SDK |
| --- | --- |
| `phaseo(modelId)` ou `phaseo.languageModel(modelId)` | `generateText`, `streamText` |
| `phaseo.embeddingModel(modelId)` (alias `textEmbeddingModel`) | `embed`, `embedMany` |
| `phaseo.imageModel(modelId)` | `generateImage` |
| `phaseo.transcriptionModel(modelId)` | `transcribe` |
| `phaseo.speechModel(modelId)` | `generateSpeech` |
| `phaseo.rerankingModel(modelId)` | `rerank` |

Todos os métodos, exceto `rerankingModel`, aceitam configurações opcionais por modelo como segundo argumento: `temperature`, `topP`, `topK`, `maxTokens`, `frequencyPenalty`, `presencePenalty`, `seed`, `user`, `headers` e `fetch`.

## Recursos compatíveis do AI SDK 7

- Geração de texto e streaming
- Saída e configurações de raciocínio
- Ferramentas de função e entradas de ferramentas transmitidas
- Saída em JSON e JSON Schema
- Entradas de arquivos de texto e imagem
- Fontes de citação por URL
- Embeddings e geração de imagens
- Reranking
- Transcrição e geração de fala
- Metadados do provedor, uso, sinais de cancelamento e chunks brutos do stream

O que uma chamada consegue fazer ainda depende do modelo e do provedor. O provedor não anuncia referências a arquivos gerenciados, skills nem ferramentas executadas pelo provedor (suas definições, resultados ou respostas de aprovação). As ferramentas de função que o seu aplicativo executa usam o fluxo normal de execução e aprovação do AI SDK.

## Usar uma versão anterior do AI SDK

| AI SDK | Instalação |
| --- | --- |
| 7 | `@phaseo/ai-sdk-provider` (`latest`) |
| 6 | `@phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `@phaseo/ai-sdk-provider@ai-sdk-v5` |

Se a instalação automática de peers estiver desativada, instale você mesmo a versão principal correspondente de `ai` (`ai@^7`, `ai@^6` ou `ai@^5`).
