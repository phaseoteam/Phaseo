Chame `generateText` com `phaseo(modelId)` para receber uma resposta completa.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Write a concise summary of Phaseo Gateway.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

## Enviar o histórico do chat

Use `prompt` para um único turno e `messages` quando precisar de vários turnos ou de um papel de sistema.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  messages: [
    { role: "system", content: "You are a terse assistant." },
    { role: "user", content: "Give me three bullet points on retrieval augmentation." },
  ],
});

console.log(result.text);
console.log(result.providerMetadata);
```

## Definir padrões no modelo

Passe as configurações como segundo argumento de `phaseo()`. Elas valem para todas as chamadas que usam essa instância do modelo.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra", {
    maxTokens: 300,
  }),
  prompt: "Draft a release note for an API update.",
});

console.log(result.text);
console.log(result.providerMetadata);
```

Os IDs de modelo usam o formato `provider/model`. Para mantê-los atualizados, leia-os de `/v1/models`; consulte [Descoberta de modelos](/pt-BR/v1/sdk-reference/sdk/get-models).
