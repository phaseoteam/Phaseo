Passe `phaseo.imageModel(modelId)` para `generateImage`. As solicitações vão para o endpoint `/v1/images/generations` do Gateway.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateImage } from "ai";

const result = await generateImage({
  model: phaseo.imageModel("openai/gpt-image-1"),
  prompt: "A minimalist poster of a lighthouse at dawn.",
  size: "1024x1024",
});

console.log(result.images[0].mediaType);
console.log(result.images[0].uint8Array.length);
console.log(result.providerMetadata);
```

## Ler o resultado

As imagens que o Gateway retorna como URLs são convertidas para o formato de arquivo do AI SDK, então leia `uint8Array` e `mediaType` em todas as imagens, seja qual for o retorno do provedor.

- Os valores de `size` disponíveis dependem do modelo.
- Para reproduzir uma imagem depois, armazene o prompt, o modelo e os parâmetros junto com os metadados da imagem.
