Defina ferramentas com o helper `tool()` do AI SDK, passe-as para `generateText` e defina `stopWhen` para que o modelo possa responder depois que a ferramenta for executada.

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, stepCountIs, tool } from "ai";
import { z } from "zod";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "What is 17 + 25? Use the calculator tool.",
  tools: {
    calculator: tool({
      description: "Perform basic arithmetic",
      inputSchema: z.object({
        operation: z.enum(["add", "subtract", "multiply", "divide"]),
        a: z.number(),
        b: z.number(),
      }),
      execute: async ({ operation, a, b }) => {
        if (operation === "add") return a + b;
        if (operation === "subtract") return a - b;
        if (operation === "multiply") return a * b;
        return a / b;
      },
    }),
  },
  stopWhen: stepCountIs(2),
});

console.log(result.text);
```

Por padrão, `generateText` para depois de uma etapa. Se essa etapa for uma chamada de ferramenta, `result.text` fica vazio e o resultado da ferramenta está em `result.toolResults`. `stepCountIs(2)` dá ao modelo uma segunda etapa para responder com o resultado.

## Escrever ferramentas seguras

- Mantenha as descrições precisas e os schemas de entrada rígidos; é o modelo que preenche os argumentos.
- Trate os argumentos como entrada não confiável. Valide-os dentro de `execute` antes de qualquer efeito colateral.
- Adicione novas tentativas e backoff dentro de `execute` para APIs downstream com falhas transitórias.
