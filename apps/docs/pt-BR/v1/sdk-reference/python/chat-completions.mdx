**Método**: `client.generate_text()` (transmita partes processadas com `client.stream_chat()`).

### Exemplo
```python
chat = client.generate_text({
    "model": "openai/gpt-4o-mini",
    "messages": [
        {"role": "system", "content": "You are helpful."},
        {"role": "user", "content": "Write a limerick about lighthouses."},
    ],
    "temperature": 0.5,
})
```

### Transmissão contínua
```python
for chunk in client.stream_chat({
    "model": "openai/gpt-4o-mini",
    "messages": [{"role": "user", "content": "Stream a story"}],
}):
    if chunk.get("text"):
        print(chunk["text"], end="", flush=True)
```

### Parâmetros principais
- `model` (obrigatório): ID do modelo de destino.
- `messages` (obrigatório): mensagens ordenadas com as funções `system|user|assistant|tool`; o conteúdo pode ser texto ou partes.
- Amostragem: `temperature` (0–2), `top_p` (0–1), `top_k` (>=1), `seed` (inteiro, opcional).
- Tamanho e penalidades: `max_output_tokens` (inteiro), `presence_penalty` e `frequency_penalty` (-2 a 2), `stop` (string|string[]).
- Ferramentas: `tools` (definições), `tool_choice` (auto/none/ferramenta específica), `max_tool_calls` (inteiro), `parallel_tool_calls` (booleano).
- Logprobs: `logprobs` (booleano), `top_logprobs` (0–20).
- Saída: `response_format` (json/text), `metadata` (objeto repassado), `stream` (booleano), `service_tier`.
- Extras do gateway: `usage` (booleano para solicitar o uso), `meta` (booleano para incluir o bloco meta).
