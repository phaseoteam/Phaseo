description: "Chame `/files` usando o SDK Python."
---

**Métodos**: `client.upload_file()`, `client.list_files()`, `client.get_file()`, `client.get_file_content()`.

```python
uploaded = client.upload_file(
    purpose="batch",
    file="data:application/json;base64,eyJ0ZXN0Ijp0cnVlfQ==",
)
file_obj = client.get_file(uploaded["id"])
file_bytes = client.get_file_content(uploaded["id"])

print(uploaded)
print(file_obj)
print(file_bytes[:20])
```

<Note>
  `list_files()` está integrado ao SDK, mas `GET /files` retorna atualmente `file_list_not_supported_with_shared_gateway_key`
  com a chave compartilhada do gateway. Guarde os IDs dos arquivos enviados e recupere-os diretamente.
</Note>
