O SDK de agentes Python é um runtime local completo para agentes do Phaseo Gateway, com novas tentativas, ferramentas concorrentes, timeouts, revisão humana, estado retomável, eventos do ciclo de vida e captura do DevTools.

Use quando você quiser:

- um loop de ferramentas leve e limitado
- solicitações ao endpoint `responses` do Gateway
- controle do aplicativo sobre persistência e orquestração

## O que o SDK oferece

- `create_agent(...)`
- `define_tool(...)`
- `create_gateway_agent_client(...)`
- solicitações ao endpoint `responses` do Gateway
