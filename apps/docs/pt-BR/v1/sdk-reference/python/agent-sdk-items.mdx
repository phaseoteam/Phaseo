`AgentRunResult` contém o estado persistente da execução, mensagens, etapas, uso e custo, avisos, motivos de conclusão e saída final.

Use `text_stream()` para obter o texto da resposta e `item_stream()` para itens do provedor e do runtime. Atualmente, os itens em Python são dicionários, não a união discriminada `AgentItem` do TypeScript.

```python
for item in stream.item_stream():
    item_type = item.get("type")
    render_timeline_item(item_type, item)
```

Mantenha o acesso a dicionários específicos do provedor em um único adaptador da aplicação e depois persista o resultado concluído para reconstruí-lo mais tarde.
