Um resultado com falha mantém a etapa ativa, a contagem de tentativas, o ID da solicitação, o ID de resposta nativo, os metadados do provedor e os detalhes disponíveis do gateway.

Verifique se:

- o processo tem acesso a `PHASEO_API_KEY`
- os IDs das ferramentas são exclusivos
- as decisões de aprovação usam os IDs exatos das chamadas
- o estado pausado é salvo antes de continuar outra solicitação
- os validadores não produzem efeitos colaterais
- o cancelamento alcança operações de rede ou armazenamento dentro das ferramentas

Use eventos do ciclo de vida para a telemetria da aplicação e o DevTools para inspecionar execuções localmente.
