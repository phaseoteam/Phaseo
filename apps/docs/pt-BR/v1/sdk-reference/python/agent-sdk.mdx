## Preparar o ambiente de execução

O pacote independente ainda não está disponível no PyPI. Siga as [instruções de instalação a partir do código-fonte](./agent-sdk-installation.mdx).

## Início rápido

```python
from phaseo_agent import create_agent, create_gateway_agent_client

agent = create_agent({
    "id": "quickstart-agent",
    "model": "openai/gpt-5.4-nano",
    "instructions": "Answer concisely and helpfully.",
})

result = agent.run(
    input="Give me one fun fact about cURL.",
    client=create_gateway_agent_client(),
)

print(result.output)
```

## Recursos incluídos

- `create_agent(...)`
- `define_tool(...)`
- `create_gateway_agent_client(...)`
- novas tentativas, ferramentas simultâneas, timeouts e eventos do ciclo de vida
- pausas para revisão humana com `continue_run(...)`
- estado serializável e captura no Phaseo Devtools

## Ambiente de execução avançado

O Python oferece suporte a schemas e aprovações por funções, ferramentas HITL e manuais, progresso, erros recuperáveis, streams reproduzíveis, auxiliares para interrupção, turnos dinâmicos, substituições persistidas do próximo turno, uso e custo normalizados e acesso ao estado controlado pela aplicação.

## Streaming e cancelamento

`agent.stream(...)` e `agent.continue_stream(...)` usam o fluxo SSE de Responses do gateway. Consuma `text_stream()`, `reasoning_stream()`, `item_stream()`, `tool_stream()` ou `full_stream()`; chame `cancel()` para encerrar a solicitação ativa. As etapas concluídas mantêm IDs de solicitação, metadados do provedor, motivos de término, avisos, uso e custo.
