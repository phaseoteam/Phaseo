| Padrão | Combine |
| --- | --- |
| Extração estruturada | validação de saída, esquema de resposta estrito, novas tentativas limitadas |
| Triagem de suporte | roteamento predefinido, ferramentas de consulta, classificação final |
| Resumo de pesquisa | busca gerenciada, texto em streaming, limites de custo |
| Assistente de programação | ferramentas de arquivos locais, progresso, aprovação antes de alterações |

Comece com um agente, uma ou duas ferramentas determinísticas e aprovação explícita para efeitos colaterais.
