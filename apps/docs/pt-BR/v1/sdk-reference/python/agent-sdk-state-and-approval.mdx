title: "Estado e aprovação"
description: "Pause agentes Python para decisões humanas e continue o estado gerenciado pela aplicação."
---

Use `human_review` como ponto de controle geral. Ferramentas que exigem aprovação e ferramentas manuais colocam os IDs exatos das chamadas em `paused.run.pause.pending_tool_calls`.

```python
from phaseo_agent import AgentToolDecision, AgentToolOutput

pending = paused.run.pause.pending_tool_calls

continued = agent.continue_run(
    run=paused,
    client=client,
    approvals=[AgentToolDecision(pending[0].call.id)],
    tool_outputs=[AgentToolOutput(pending[1].call.id, {"status": "complete"})],
)
```

Forneça `rejections` para chamadas rejeitadas ou `human_input` para uma pausa geral de revisão. As decisões são associadas ao ID da chamada, não ao nome da ferramenta.

Implemente `AgentStateAccessor.load(run_id)` e `save(result)` quando as execuções precisarem sobreviver a solicitações ou reinicializações do processo. Assim, a continuação pode carregar o estado usando `run_id`.
