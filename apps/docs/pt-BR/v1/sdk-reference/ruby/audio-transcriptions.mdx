description: "Chame /audio/transcriptions com o SDK Ruby."
---

**Métodos**: `client.generate_transcription(...)` ou `client.create_transcription(...)`.

### Exemplo
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
transcript = client.generate_transcription(
  model: 'openai/gpt-4o-transcribe',
  audio_b64: 'base64_audio_data',
  language: 'en'
)
```

### Parâmetros principais
- `model` (obrigatório): ID de um modelo compatível com transcrição.
- `audio_url` ou `audio_b64` (obrigatório): dados de áudio (URL ou base64).
- `language`: código de idioma como sugestão (por exemplo, `en`).
- `prompt`: contexto opcional para aumentar a precisão.
- `temperature` (0–2): aleatoriedade da amostragem.
- `response_format`: `json`, `text`, `srt`, `verbose_json` etc.

### Retorno
`AudioTranscriptionResponse`
