O Ruby Agent SDK é um runtime local completo de agentes para o Phaseo Gateway. Ele inclui novas tentativas, ferramentas concorrentes, timeouts, revisão humana, estado retomável, eventos do ciclo de vida e captura do DevTools.

Use quando precisar de:

- um loop leve e limitado de ferramentas
- solicitações `responses` respaldadas pelo gateway
- controle da persistência e da orquestração pela aplicação

## O que inclui

- `PhaseoAgentSdk.create_agent(...)`
- `PhaseoAgentSdk.define_tool(...)`
- `PhaseoAgentSdk.create_gateway_agent_client(...)`
- um loop limitado de ferramentas sobre a API `responses` do Phaseo
