Valide a saída quando o código Ruby seguinte precisar de um formato de resultado previsível. As novas tentativas do modelo cobrem falhas transitórias de solicitações; tentativas para ferramentas com efeitos colaterais devem ser explícitas e idempotentes.

## Configurar novas tentativas

```ruby
agent = PhaseoAgentSdk.create_agent(
  id: "research-agent",
  model: "openai/gpt-5.4-nano",
  model_retry: PhaseoAgentSdk::ModelRetryConfig.new(
    max_retries: 3,
    base_delay_ms: 500,
    max_delay_ms: 4_000
  )
)
```

O resultado contém o registro da execução, as etapas, as mensagens, o uso normalizado, o motivo da parada e a saída final.

```ruby
result = agent.run(input: prompt, client: client)

puts result.output
puts result.run.status
puts result.usage[:total_tokens]
puts result.usage[:cost]
```

Use [condições de parada](./agent-sdk-stop-conditions.mdx) para impor limites e [erros e solução de problemas](./agent-sdk-observability.mdx) para escolher o comportamento em falhas recuperáveis.
