O Agent SDK é publicado no RubyGems como [`phaseo_agent_sdk`](https://rubygems.org/gems/phaseo_agent_sdk).

## Requisitos

- Ruby 3.2 ou posterior
- RubyGems ou Bundler
- uma chave de API do Phaseo

## Instalação

```bash
gem install phaseo_agent_sdk
```

Ou adicione-o ao `Gemfile`:

```ruby
gem "phaseo_agent_sdk"
```

A gem principal `phaseo_sdk` é instalada automaticamente como dependência.

## Ambiente

Defina a chave de API do gateway antes de executar os exemplos:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
