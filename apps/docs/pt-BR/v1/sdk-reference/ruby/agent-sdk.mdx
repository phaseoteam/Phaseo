## Preparar o ambiente de execução

A gem do Agent SDK ainda não foi publicada no RubyGems. Siga as [instruções de instalação a partir do código-fonte](./agent-sdk-installation.mdx).

## Início rápido

```ruby
require "phaseo_agent_sdk"

agent = PhaseoAgentSdk.create_agent(
  id: "quickstart-agent",
  model: "openai/gpt-5.4-nano",
  instructions: "Answer concisely and helpfully."
)

result = agent.run(
  input: "Give me one fun fact about cURL.",
  client: PhaseoAgentSdk.create_gateway_agent_client
)

puts result.output
```

## O que o pacote inclui

- `PhaseoAgentSdk.create_agent(...)`
- `PhaseoAgentSdk.define_tool(...)`
- `PhaseoAgentSdk.create_gateway_agent_client(...)`
- Um loop limitado de ferramentas sobre a API `responses` do Phaseo

## Ambiente de execução avançado

Ruby oferece funções de validação e aprovação, HITL e ferramentas manuais, progresso, erros recuperáveis, enumeradores reproduzíveis, helpers de parada, turnos dinâmicos, parâmetros persistidos para o próximo turno, uso/custo normalizados e acessores de estado com tipagem duck.

## Streaming e cancelamento

`Agent#stream(...)` e `Agent#continue_stream(...)` consomem o fluxo SSE de Responses do gateway em uma thread de trabalho. Use `text_stream`, `reasoning_stream`, `item_stream` ou `full_stream`; chame `cancel` para interromper a thread e fechar o fluxo HTTP. Etapas concluídas mantêm IDs de solicitação, metadados do provedor, motivos de conclusão, avisos, uso e custo.
