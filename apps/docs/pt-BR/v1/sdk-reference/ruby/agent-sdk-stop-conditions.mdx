title: "Condições de parada"
description: "Limite execuções de agentes Ruby por etapas, tokens, custo, duração, ferramentas ou motivo de conclusão."
---

Combine funções de parada para manter o trabalho autônomo dentro dos limites da aplicação.

```ruby
agent = PhaseoAgentSdk.create_agent(
  id: "bounded-research",
  model: "openai/gpt-5.4-nano",
  stop_when: [
    PhaseoAgentSdk.step_count_is(12),
    PhaseoAgentSdk.max_tokens_used(40_000),
    PhaseoAgentSdk.max_cost(2.50),
    PhaseoAgentSdk.max_duration(120_000)
  ]
)
```

Também há condições para chamadas de ferramentas e motivos de conclusão. Após a execução, inspecione `result.run.stop_reason` e o uso normalizado para distinguir uma parada por orçamento de uma conclusão normal do modelo.

Parar é um resultado limitado, não uma exceção automática. Decida quais motivos devem ser considerados bem-sucedidos, repetidos ou exibidos ao usuário.
