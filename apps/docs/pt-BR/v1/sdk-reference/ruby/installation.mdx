description: "Instale o SDK de Ruby da Phaseo pelo RubyGems."
---

O SDK é publicado como [`phaseo_sdk`](https://rubygems.org/gems/phaseo_sdk) no RubyGems.

## Requisitos

- Ruby 3.1 ou superior

## Instalação

```bash
gem install phaseo_sdk
```

Ou adicione-o ao seu `Gemfile`:

```ruby
gem "phaseo_sdk"
```
