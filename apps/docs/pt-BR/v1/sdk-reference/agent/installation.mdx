Instale o pacote do Agent SDK da sua linguagem, defina `PHASEO_API_KEY` e crie um primeiro agente em [Uso](./usage). Cada pacote traz como dependência o cliente principal da Phaseo da sua linguagem.

<Steps>
<Step title="Instale o pacote">

<Tabs>
<Tab title="TypeScript">

Instale [`@phaseo/agent-sdk`](https://www.npmjs.com/package/@phaseo/agent-sdk) 0.3.0 em um projeto TypeScript ou JavaScript. O `@phaseo/sdk` vem junto.

<CodeGroup>

```bash npm
npm install @phaseo/agent-sdk
```

```bash pnpm
pnpm add @phaseo/agent-sdk
```

```bash yarn
yarn add @phaseo/agent-sdk
```

```bash bun
bun add @phaseo/agent-sdk
```

</CodeGroup>

</Tab>
<Tab title="Python">

Instale [`phaseo-agent-sdk`](https://pypi.org/project/phaseo-agent-sdk/) 0.3.0 em um ambiente com Python 3.10 ou mais recente. O cliente principal `phaseo` (3.x) vem junto, e o pacote é instalado como o módulo `phaseo_agent`.

<CodeGroup>

```bash pip
pip install phaseo-agent-sdk
```

```bash uv
uv add phaseo-agent-sdk
```

</CodeGroup>

</Tab>
<Tab title="Go">

Adicione [`agent-sdk-go`](https://pkg.go.dev/github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go) `v0.3.0` com Go 1.24 ou mais recente. O Go adiciona o cliente principal, `github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4`, como dependência.

```bash
go get github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go@latest
```

Importe o pacote do agente como `phaseoagent`:

```go
import phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
```

</Tab>
<Tab title="C#">

Adicione [`Phaseo.AgentSdk`](https://www.nuget.org/packages/Phaseo.AgentSdk) 0.3.0 pelo NuGet. Você precisa do .NET 8 ou mais recente. O NuGet adiciona `Phaseo.Sdk` como dependência.

```bash
dotnet add package Phaseo.AgentSdk
```

Os tipos do agente ficam no namespace `PhaseoAgentSdk`:

```csharp
using PhaseoAgentSdk;
```

</Tab>
<Tab title="PHP">

Adicione [`phaseo/agent-sdk`](https://packagist.org/packages/phaseo/agent-sdk) `v0.3.0` com o Composer. Você precisa do PHP 8.1 ou mais recente. O Composer adiciona `phaseo/sdk` (`^3.0.0`) como dependência.

```bash
composer require phaseo/agent-sdk
```

As classes do agente ficam no namespace `Phaseo\AgentSdk`:

```php
use Phaseo\AgentSdk\AgentDefinition;
use Phaseo\AgentSdk\AgentSdk;
use Phaseo\AgentSdk\Tool;
```

</Tab>
<Tab title="Ruby">

Adicione [`phaseo_agent_sdk`](https://rubygems.org/gems/phaseo_agent_sdk) 0.3.0 com o RubyGems ou o Bundler. Você precisa do Ruby 3.2 ou mais recente. O RubyGems adiciona `phaseo_sdk` (`>= 3.0.0, < 4.0.0`) como dependência.

<CodeGroup>

```bash gem
gem install phaseo_agent_sdk
```

```ruby Gemfile
gem "phaseo_agent_sdk"
```

</CodeGroup>

Carregue o módulo do agente com:

```ruby
require "phaseo_agent_sdk"
```

</Tab>
<Tab title="Java">

Adicione `app.phaseo:phaseo-agent-sdk` 0.3.0 pelo Maven Central. Você precisa do Java 17 ou mais recente. O build adiciona `app.phaseo:phaseo-sdk` 3.0.0 e o Jackson como dependências. Todos os tipos são records aninhados em `app.phaseo.agent.AgentSdk`.

<CodeGroup>

```xml Maven
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-agent-sdk</artifactId>
  <version>0.3.0</version>
</dependency>
```

```kotlin Gradle
implementation("app.phaseo:phaseo-agent-sdk:0.3.0")
```

</CodeGroup>

Para compilar a partir do código-fonte:

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
mvn -f packages/sdk/agent-sdk-java/pom.xml package
```

</Tab>
<Tab title="Rust">

Adicione [`phaseo-agent`](https://crates.io/crates/phaseo-agent) e o cliente `phaseo`, ambos na versão 0.2.0 no crates.io, com Rust 1.86 ou mais recente. Diferente das outras linguagens, você mesmo adiciona o cliente principal.

<CodeGroup>

```toml Cargo.toml
[dependencies]
phaseo = "0.2"
phaseo-agent = "0.2"
serde_json = "1"
```

```bash cargo
cargo add phaseo@0.2 phaseo-agent@0.2 serde_json
```

</CodeGroup>

</Tab>
</Tabs>

</Step>
<Step title="Defina sua chave de API">

Crie uma chave em [Chaves de API](https://phaseo.app/settings/keys) e depois exporte-a:

<CodeGroup>

```bash macOS and Linux
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

```powershell Windows
$env:PHASEO_API_KEY = "phaseo_v1_sk_..."
```

</CodeGroup>

A maioria dos clientes de gateway lê a chave do ambiente; o do Python não. TypeScript, Python e Java ignoram `PHASEO_BASE_URL`:

| Linguagem | Cliente de gateway | Lê `PHASEO_API_KEY` | Lê `PHASEO_BASE_URL` | Passe no código com |
| --- | --- | --- | --- | --- |
| TypeScript | `createGatewayAgentClient()` | Sim | Não | `clientOptions.apiKey`, `clientOptions.baseUrl` |
| Python | `create_gateway_agent_client()` | Não; lança `ValueError` sem uma chave | Não | `client_options={"api_key": ...}` ou `client=Phaseo()` |
| Go | `CreateGatewayAgentClient(...)` | Sim, quando `APIKey` está vazio | Sim, quando `BaseURL` está vazio | `GatewayAgentClientOptions.APIKey`, `.BaseURL` |
| C# | `AgentSdk.CreateGatewayAgentClient()` | Sim | Sim | `apiKey`, `baseUrl` em `GatewayAgentClientOptions.ClientOptions` |
| PHP | `AgentSdk::createGatewayAgentClient()` | Sim | Sim | `api_key`, `base_url` em `GatewayAgentClientOptions::$clientOptions` |
| Ruby | `PhaseoAgentSdk.create_gateway_agent_client` | Sim | Sim | `api_key:`, `base_url:` |
| Java | `AgentSdk.createGatewayAgentClient()` | Sim | Não | `new AgentSdk.GatewayOptions(null, apiKey, baseUrl, null, null, null)` |
| Rust | `create_gateway_agent_client(model)`, `GatewayAgentClient::from_env(model)` | Sim | Sim, pelo cliente `phaseo` | `GatewayAgentClient::new(client, model)` |

A URL base padrão é `https://api.phaseo.app/v1`.

</Step>
<Step title="Verifique a instalação">

Crie um agente sem chamar o modelo. Se isto compilar e rodar, o pacote está instalado:

<CodeGroup>

```typescript TypeScript
import { createAgent } from "@phaseo/agent-sdk";

createAgent({ id: "verification-agent", model: "openai/gpt-6-astra" });
console.log("Phaseo Agent SDK installed");
```

```python Python
from phaseo_agent import create_agent

create_agent({"id": "verification-agent", "model": "openai/gpt-6-astra"})
print("Phaseo Agent SDK installed")
```

```go Go
package main

import (
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  phaseoagent.CreateAgent(phaseoagent.AgentDefinition{ID: "verification-agent", Model: "openai/gpt-6-astra"})
  fmt.Println("Phaseo Agent SDK installed")
}
```

```csharp C#
using PhaseoAgentSdk;

AgentSdk.CreateAgent(new AgentDefinition { Id = "verification-agent", Model = "openai/gpt-6-astra" });
Console.WriteLine("Phaseo Agent SDK installed");
```

```php PHP
<?php
require "vendor/autoload.php";

use Phaseo\AgentSdk\AgentDefinition;
use Phaseo\AgentSdk\AgentSdk;

AgentSdk::createAgent(new AgentDefinition(id: "verification-agent", model: "openai/gpt-6-astra"));
echo "Phaseo Agent SDK installed" . PHP_EOL;
```

```ruby Ruby
require "phaseo_agent_sdk"

PhaseoAgentSdk.create_agent(id: "verification-agent", model: "openai/gpt-6-astra")
puts "Phaseo Agent SDK installed"
```

```rust Rust
use phaseo_agent::{create_agent, AgentDefinition};

fn main() {
    let _agent = create_agent(AgentDefinition::new(
        "verification-agent",
        "openai/gpt-6-astra",
    ));
    println!("Phaseo Rust Agent SDK installed");
}
```

</CodeGroup>

O Java não tem forma curta: `AgentDefinition` é um record posicional, mostrado por completo em [Uso](./usage).

</Step>
</Steps>
