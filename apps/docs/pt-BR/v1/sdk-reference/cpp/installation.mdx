<Note type="warning">O SDK de C++ está em desenvolvimento e ainda não foi publicado em um registro de pacotes.</Note>

## Uso local

O SDK é composto apenas de headers C++17. Adicione `packages/sdk/sdk-cpp` ao seu build do CMake e vincule o target de interface, ou coloque `packages/sdk/sdk-cpp/src` no seu include path:

```cmake
add_subdirectory(path/to/Phaseo/packages/sdk/sdk-cpp)
target_link_libraries(your_app PRIVATE phaseo::sdk)
```

Depois, inclua `phaseo.hpp`, que importa o cliente gerado em `src/gen`.
