Comece pela [Central de Ajuda da Phaseo](https://phaseo.app/help) para dúvidas sobre conta, cobrança, API e feedback; a equipe encaminha cada solicitação ao lugar certo.

| Você quer | Vá para |
| --- | --- |
| Obter ajuda com sua conta, a cobrança ou uma solicitação que falha | [Central de Ajuda](https://phaseo.app/help) |
| Relatar um bug | [Central de Ajuda](https://phaseo.app/help) ou um [relatório de bug](https://github.com/phaseoteam/Phaseo/issues/new?template=bug.yml) no GitHub |
| Corrigir dados do catálogo | [Contribuir](../contributing/overview) |
| Relatar uma vulnerabilidade de segurança | Um relatório privado em **Security -> Report a vulnerability** no [repositório do GitHub](https://github.com/phaseoteam/Phaseo), ou `security@phaseo.app`. Não publique o problema abertamente. |
| Perguntar à comunidade | [Discord](https://discord.gg/aQyywCvgZ5) |

## O que incluir em um relatório de bug

- O ID da solicitação: o `id` da resposta (`G-...`), o `generation_id` do erro ou o cabeçalho de resposta `x-request-id`.
- O que você enviou, sem a chave de API, e o que você esperava.
- O código e a mensagem de erro do corpo da resposta. A [referência de erros](../api-reference/errors) explica cada código.
- Registros relevantes, sem credenciais e sem dados de clientes.
