Abra a lista de [Modelos](https://phaseo.app/models) para encontrar modelos de texto, imagem, áudio, vídeo, embedding e outros, e depois abra um modelo para ver os provedores, os preços, o desempenho e as pontuações em benchmarks dele.

![A página de um modelo no Phaseo](/images/gemini-3-page.png)

## Modelos do catálogo e modelos que podem ser chamados

O catálogo é mais amplo do que o Gateway. Por padrão, a lista de modelos mostra apenas os modelos **Ativo no Gateway**. Mude o filtro **Status do Gateway** para **Em breve** ou **Inativo** para ver os demais.

| Termo | Significado |
| --- | --- |
| Modelo do catálogo | O Phaseo acompanha os metadados do modelo. Ele pode não ter nenhuma rota que você consiga chamar. |
| Modelo roteável | Pelo menos uma rota de provedor está ativa no Gateway do Phaseo agora. |
| Mapeamento externo | O Phaseo lista uma oferta de provedor que o Gateway não executa. |

`GET /v1/models` retorna apenas modelos roteáveis. Adicione `availability=all` para incluir os demais.

## Filtre e ordene a lista

| Controle | Opções |
| --- | --- |
| Status do Gateway | Ativo no Gateway (padrão), Em breve, Inativo |
| Endpoints | Os endpoints de API compatíveis com o modelo, como geração de texto ou embeddings |
| Modalidades de entrada e saída | Texto, imagem, áudio, vídeo e outras |
| Recursos | Capacidades como chamada de ferramentas ou raciocínio |
| Ano | Ano de lançamento |
| Ordenar | Mais recentes, mais populares (tokens em 7 dias), preço, tamanho do contexto, vazão, latência |

Para ver todos os modelos de um laboratório, abra a [página da organização](./organisations.mdx).

## O que a página de um modelo mostra

| Seção | O que ela informa |
| --- | --- |
| **Provedores** | Cada rota de provedor com status, tamanho do contexto, preço, disponibilidade e política de dados. [Status do provedor e do Phaseo](../guides/provider-statuses) explica os ícones. |
| **Desempenho** | Latência e vazão medidas no tráfego do Gateway, quando há dados suficientes. |
| **Preços** | Cada medidor em USD: entrada, saída, entrada em cache e unidades de mídia. |
| **Avaliações comparativas** | As pontuações em cada benchmark, com as fontes. |
| **Atividade** | O uso de tokens no Gateway ao longo do tempo. |
| **Aplicativos** | Apps públicos que usam o modelo. |
| **Disponibilidade** | A disponibilidade das rotas nos últimos dias. |
| **Verificação** | Verificações de procedência do conteúdo, para modelos de imagem e vídeo. |
| **Sobre** | Datas de lançamento, licença, links e família. |
| **Assinaturas** | Planos de assinatura de provedores que incluem o modelo. |
| **FAQ** | Perguntas frequentes sobre o modelo. |

Uma seção só aparece quando há dados para ela. Modelos com uma rota ativa também mostram um guia rápido com o ID do modelo a ser enviado.

## Compare modelos

[Comparar](https://phaseo.app/compare) coloca modelos lado a lado em preço, pontuações em benchmarks, contexto e recursos. [Preços e desempenho](./pricing-performance.mdx) explica como ler os números de custo e velocidade.

## Informe uma correção

Abra uma issue no GitHub com a página do modelo e uma fonte oficial. Os mantenedores aplicam as atualizações aprovadas no banco de dados. Consulte [Informe uma atualização de modelo](../contributing/editing-a-model.mdx).
