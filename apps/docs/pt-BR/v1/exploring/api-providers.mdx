Provedores de API são as plataformas que hospedam e disponibilizam APIs de modelos.

As organizações de modelos treinam os modelos. Os provedores disponibilizam esses modelos por endpoints de produção, autenticação, controles de uso e ferramentas operacionais.

## O que um provedor de API costuma fazer

- Autenticação e gerenciamento de chaves
- Roteamento de solicitações e gerenciamento de disponibilidade
- Medição de uso e faturamento
- Usabilidade da API e do SDK
- Hospedagem regional e controles de conformidade

## Provedor e organização

| Aspecto | Organização | Provedor de API |
| --- | --- | --- |
| Função principal | Cria e treina modelos | Hospeda e disponibiliza APIs de modelos |
| Foco | Pesquisa e qualidade dos modelos | Confiabilidade, acesso e operação |
| Distribuição | Geralmente oferece sua própria família de modelos | Pode oferecer modelos de várias organizações |

Muitas empresas exercem as duas funções, dependendo do produto.

## Phaseo Gateway como camada de provedores

O Phaseo Gateway unifica o acesso a vários backends.

Vantagens:

- Formato unificado de solicitação e resposta entre provedores
- Roteamento e fallback que consideram o provedor
- Uso unificado do SDK para integrações com vários provedores
- Observabilidade centralizada de uso e custos
- Suporte opcional a BYOK para chaves nativas do provedor

## Como escolher um provedor

Ao avaliar provedores, considere:

- Disponibilidade dos modelos para seu caso de uso
- Confiabilidade e latência na região desejada
- Perfil de custo para o volume de tráfego esperado
- Compatibilidade com ferramentas, streaming e saídas estruturadas
- Requisitos de conformidade e tratamento de dados

## Perguntas para avaliar

- Quais provedores disponibilizam a família de modelos de que preciso?
- Qual provedor oferece menor latência na minha região?
- Qual é a opção de menor custo para meu volume de tokens?
- Qual provedor oferece os recursos de endpoint necessários?
