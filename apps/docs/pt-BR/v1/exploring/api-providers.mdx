Abra um provedor em [Provedores de API](https://phaseo.app/api-providers) para ver quais modelos ele disponibiliza pelo Phaseo e qual tem sido a velocidade dele, ou [compare provedores](https://phaseo.app/api-providers/compare) lado a lado. Um provedor de API hospeda modelos por trás de uma API; a [organização](./organisations.mdx) que criou um modelo costuma ser outra empresa.

| | Organização | Provedor de API |
| --- | --- | --- |
| **Faz** | Cria e treina modelos | Hospeda e disponibiliza APIs de modelos |
| **Foco** | Pesquisa e qualidade dos modelos | Confiabilidade, acesso, regiões e preços |
| **Modelos** | Geralmente suas próprias famílias | Muitas vezes modelos de várias organizações |

Muitas empresas são as duas coisas.

## O que a página de um provedor mostra

| Seção | O que ela informa |
| --- | --- |
| **Desempenho** | Latência e vazão por hora no tráfego do Gateway nos últimos sete dias. |
| **Uso de tokens** | Os tokens que o Phaseo enviou ao provedor ao longo do tempo. |
| **Principais modelos** e **Principais apps** | Os modelos e apps públicos com mais tráfego neste provedor. |
| **Modelos** | Todos os modelos que o provedor disponibiliza, com abas para modelos de texto, imagem, áudio, vídeo, embedding e moderação. |

A página de cada modelo mostra, então, o preço, o tamanho do contexto, o status e a política de dados do provedor para aquele modelo; [Status do provedor e do Phaseo](../guides/provider-statuses) explica os ícones de status.

## Como o Gateway usa os provedores

Quando um modelo tem vários provedores, o Gateway escolhe um por solicitação e recorre a outro se ele falhar. Você envia um único formato de solicitação e recebe uma única fatura e um único log de uso, seja qual for o provedor que atende. Para cobrar na sua própria conta do provedor, adicione uma chave do provedor ([BYOK](../guides/routing-and-fallbacks#byok-considerations)).

[Roteamento e fallbacks](../guides/routing-and-fallbacks) mostra como ordenar, fixar ou excluir provedores.

## Escolha um provedor

| Se o que importa para você é | Verifique |
| --- | --- |
| Um modelo específico | A seção **Provedores** da página do modelo, ou `GET /v1/models/{author}/{slug}/endpoints` |
| A latência na sua região | A seção **Desempenho** do provedor e as regiões dele na página do modelo |
| O custo no seu volume | A seção **Preços** do modelo e a [calculadora de preços](https://phaseo.app/tools/pricing-calculator) |
| Ferramentas, streaming ou saída estruturada | Os parâmetros compatíveis da rota na página do modelo ou na API de endpoints |
| Tratamento de dados e conformidade | A política de dados e os locais de processamento da rota na página do modelo |

[Preços e desempenho](./pricing-performance.mdx) explica como ler os números de custo e velocidade.
