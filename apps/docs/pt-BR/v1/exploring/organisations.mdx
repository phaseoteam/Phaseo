Abra uma organização em [Organizações](https://phaseo.app/organisations) para ver todos os modelos que ela lançou e o desempenho deles no Gateway. Todo modelo no Phaseo pertence a uma organização: a empresa ou o laboratório que o desenvolve e o mantém.

## O que a página de uma organização mostra

A página tem duas abas.

| Aba | Seção | O que ela informa |
| --- | --- | --- |
| **Visão geral** | Sobre | Nome, descrição e país. |
| | Desempenho | A latência e a vazão recentes no Gateway em todos os modelos da organização. |
| | Modelos recentes | Lançamentos recentes com disponibilidade, contexto, preços e uso. |
| | Na web | Links para o site, o GitHub, o Hugging Face e as redes sociais da organização. |
| **Modelos** | | Todos os modelos que a organização lançou, incluindo os arquivados e os descontinuados. |

## Organizações e provedores de API

A organização cria o modelo; um [provedor de API](./api-providers.mdx) o disponibiliza. Um mesmo modelo costuma ter vários provedores.

| | Organização | Provedor de API |
| --- | --- | --- |
| **Faz** | Treina e mantém o modelo. | Hospeda o modelo por trás de uma API. |
| **Exemplo** | A Anthropic criou os modelos Claude. | Anthropic, Amazon Bedrock e Google Vertex disponibilizam os modelos Claude. |

Algumas organizações, como a OpenAI e o Google, também são provedores dos próprios modelos.

## Informe uma correção

Abra uma issue no GitHub com a página da organização e uma fonte oficial. Os mantenedores aplicam as alterações aprovadas no banco de dados. Consulte [Informe uma atualização de organização](../contributing/editing-an-organisation.mdx).
