Para correções e acréscimos ao catálogo, abra uma issue com o registro afetado e as fontes que o comprovam. Para alterações de código ou de documentação, envie um pull request ao [repositório da Phaseo](https://github.com/phaseoteam/Phaseo).

## Escolha sua contribuição

| Alteração | Comece aqui |
| --- | --- |
| Metadados, recursos, disponibilidade ou preços de modelos | [Informar uma atualização de modelo](./editing-a-model.mdx) |
| Detalhes de empresas ou organizações de pesquisa | [Informar uma atualização de organização](./editing-an-organisation.mdx) |
| Resultados de benchmarks | [Enviar pontuações](../research/submitting-scores.mdx) |
| Outras correções do catálogo | [Informar dados incorretos](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) |
| Provedores ausentes ou outros dados do catálogo | [Solicitar novos dados](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) |
| Documentação ou código | [Fluxo de contribuição](./how-to-contribute.mdx) e [estrutura do repositório](./repo-structure.mdx) |

## Como os relatos do catálogo são publicados

Os mantenedores analisam as evidências na issue e aplicam as alterações aprovadas pelo [editor interno](https://phaseo.app/internal/data), exclusivo para administradores. As atualizações de preços de provedores exigem revisão explícita antes da publicação.

O banco de dados é a única fonte dos registros do catálogo. O repositório não contém JSON do catálogo, então um pull request não consegue alterar um registro do catálogo.

## Antes de enviar

- Inclua a página ou o ID do registro afetado e descreva a correção proposta.
- Cite fontes oficiais e diferencie resultados de benchmarks divulgados de medições independentes.
- Mantenha cada relato ou pull request focado em um assunto.
- Nunca inclua credenciais ou dados privados de clientes.
- Siga o [Código de Conduta](../community/code-of-conduct.mdx).

Discuta alterações maiores de esquema ou de recursos com os mantenedores antes de implementá-las. Peça ajuda no [Discord](https://discord.gg/aQyywCvgZ5) se não souber onde uma alteração se encaixa.
