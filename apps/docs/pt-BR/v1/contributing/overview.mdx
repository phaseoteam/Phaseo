O Phaseo é um **projeto aberto e conduzido pela comunidade**, criado para tornar o máximo possível de informações sobre modelos de IA, benchmarks e provedores acessível gratuitamente a todos.

Suas contribuições ajudam a manter a plataforma precisa, transparente e atualizada.  
Seja corrigindo um erro de digitação, adicionando dados de benchmark ou melhorando a documentação, toda contribuição faz diferença.

---

## Por que contribuir?

A IA evolui cada vez mais rápido: novos modelos, atualizações e mudanças de preços surgem todos os dias.  
Ao contribuir, você ajuda a:

-   Manter atualizados e confiáveis os dados de modelos, organizações e benchmarks
-   Melhorar a precisão das comparações de IA entre provedores
-   Compartilhar descobertas de pesquisas, contribuições da comunidade ou metadados ausentes
-   Fortalecer o ecossistema aberto de transparência em IA
-   Garantir que o banco de dados continue acessível gratuitamente e pertencente à comunidade

Seu nome também aparecerá na [página de colaboradores](https://phaseo.app/contribute), em reconhecimento pelas suas contribuições.

## Visão geral do fluxo de contribuição

1. **Faça um fork** do [repositório do Phaseo no GitHub](https://github.com/phaseoteam/Phaseo).
2. **Crie uma branch** para suas alterações (por exemplo, `fix-model-data` ou `add-new-benchmark`).
3. **Edite os arquivos JSON ou Markdown** conforme a estrutura descrita em [Estrutura do repositório](./repo-structure.mdx).
4. **Teste suas alterações localmente** se for pertinente (por exemplo, conferindo-as no frontend do Next.js).
5. **Faça commit e envie** suas alterações.
6. **Abra um pull request (PR)** e descreva o que foi alterado e por quê.

Após a revisão e aprovação, sua contribuição será integrada e ficará visível no banco de dados ativo do Phaseo.

## Tipos de contribuição

| Tipo                   | Exemplo                                                 | Dificuldade |
| ---------------------- | ------------------------------------------------------- | ---------- |
| **Correção de dados**           | Corrigir nomes de modelos, provedores ou valores de benchmark. | Fácil       |
| **Nova entrada**          | Adicionar um modelo, benchmark ou organização.         | Moderada   |
| **Alteração estrutural**  | Ajustar a estrutura do banco de dados ou do esquema.                    | Avançada   |
| **Adição de funcionalidade**   | Adicionar componentes de interface ou lógica do Next.js.                  | Avançada   |
| **Edição da documentação** | Melhorar arquivos Markdown ou guias.                     | Fácil       |

Seja qual for a alteração que você deseja fazer, aceitamos contribuições de todos os tamanhos e níveis de complexidade.

## Diretrizes e padrões

Todas as contribuições devem seguir estes padrões para garantir a qualidade e a consistência dos dados:

-   **Fontes confiáveis:** Inclua apenas dados verificados ou publicados oficialmente.
-   **Formatação consistente:** Use corretamente maiúsculas, indentação e chaves do esquema.
-   **Alterações versionadas:** Escreva descrições claras nos changelogs ou nas mensagens de commit.
-   **Referências:** Inclua links para as fontes dos dados nas descrições dos pull requests.
-   **Comunicação respeitosa:** Siga nosso [Código de Conduta](../community/code-of-conduct.mdx).

## Exemplo de fluxo de contribuição

```bash
# 1. Fork and clone the repo
git clone https://github.com/yourusername/Phaseo.git

# 2. Create a new branch
git checkout -b add-openai-new-model

# 3. Make your edits
# e.g. edit packages/data/catalog/src/data/models/openai/new-model/model.json

# 4. Stage, commit, and push
git add .
git commit -m "Added new OpenAI model with updated benchmark data"
git push origin add-openai-new-model

# 5. Open a Pull Request on GitHub
# Describe your changes and link any sources
```

## Precisa de ajuda?

Se não souber como contribuir ou quiser receber comentários antes de enviar, você pode:

-   Pergunte no [Discord do Phaseo](https://discord.gg/aQyywCvgZ5).
-   Abra uma **discussão no GitHub** para perguntas ou sugestões.
-   Mencione os mantenedores no pull request para receber orientação durante a revisão.
