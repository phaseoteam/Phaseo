Para correções e adições ao catálogo, abra uma issue com o registro afetado e fontes de apoio. Para alterações de código ou documentação, envie uma solicitação de alteração ao [repositório do Phaseo](https://github.com/phaseoteam/Phaseo).

## Escolher sua contribuição

| Alteração | Comece aqui |
| --- | --- |
| Metadados, capacidades, disponibilidade ou preços de modelos | [Relatar atualização de modelo](./editing-a-model.mdx) |
| Detalhes de empresas ou organizações de pesquisa | [Relatar atualização de organização](./editing-an-organisation.mdx) |
| Resultados de benchmarks | [Enviar pontuações](../research/submitting-scores.mdx) |
| Outras correções do catálogo | [Relatar informações incorretas](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) |
| Provedores ou outros dados do catálogo ausentes | [Solicitar novos dados](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) |
| Documentação ou código | [Fluxo de contribuição](./how-to-contribute.mdx) e [estrutura do repositório](./repo-structure.mdx) |

## Como relatos do catálogo são publicados

Os mantenedores revisam as evidências da issue e aplicam alterações aprovadas pelo [editor interno](https://phaseo.app/internal/data), exclusivo de administradores. Atualizações de preços dos provedores exigem revisão explícita antes da publicação.

O banco de dados é a fonte de verdade do catálogo. Snapshots JSON públicos diários continuam disponíveis, mas nem sua edição nem solicitações de alteração de JSON arquivado atualizam o catálogo ativo. O importador JSON antigo foi aposentado.

## Antes de enviar

- Inclua a página ou ID do registro afetado e descreva a correção proposta.
- Cite fontes oficiais e diferencie resultados de benchmarks publicados de medições independentes.
- Mantenha cada relato ou solicitação de alteração focado.
- Nunca inclua credenciais ou dados privados de clientes.
- Siga o [Código de conduta](../community/code-of-conduct.mdx).

Discuta alterações maiores de esquema ou recursos com os mantenedores antes de implementar. Peça ajuda no [Discord](https://discord.gg/aQyywCvgZ5) se não souber onde uma alteração se encaixa.
