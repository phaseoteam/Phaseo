Informe detalhes ausentes ou desatualizados de organizações por uma issue no GitHub. Os mantenedores analisam as evidências e aplicam as alterações aprovadas no editor do banco de dados.

## Informar uma correção

1. Copie a URL da página da organização no Phaseo ou seu ID.
2. [Informe dados incorretos](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) com o campo afetado e o valor proposto.
3. Inclua um link para um site oficial, um anúncio ou outra fonte verificável.

Correções comuns incluem nome, descrição, site, localização e relações com modelos ou provedores de API.

## Solicitar uma organização ausente

[Abra uma solicitação de dados](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) com o nome da organização, o site oficial e links relevantes de modelos ou provedores.

## Após o envio

Acompanhe a revisão e a publicação na issue. Uma alteração de registro do catálogo não exige edição de JSON nem pull request. Os arquivos JSON diários são exportações; eles não são importados para o banco de dados em produção.

Administradores gerenciam organizações pelo [editor interno do catálogo](https://phaseo.app/internal/data), que exige acesso de administrador.
