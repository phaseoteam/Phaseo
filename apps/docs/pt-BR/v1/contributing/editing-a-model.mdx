Abra uma issue no GitHub para corrigir um modelo ou solicitar uma entrada ausente. Você não precisa editar JSON nem configurar o repositório.

## Informar uma correção

1. Copie a URL da página do modelo na Phaseo ou o ID do modelo.
2. [Informe dados incorretos](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml), descrevendo o valor atual e a correção proposta.
3. Inclua documentação oficial, um anúncio de lançamento ou outra fonte verificável.

Para preços, inclua o provedor, a moeda, a unidade de cobrança, o nível aplicável e a data de vigência. Para pontuações de benchmarks, siga [Enviar pontuações](../research/submitting-scores.mdx).

## Solicitar um modelo ausente

[Abra uma solicitação de dados](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) com o nome do modelo, a organização, o link oficial, a data de lançamento e os recursos conhecidos. Um modelo pode aparecer no catálogo antes de ter uma rota compatível no Gateway.

## Depois do envio

Os mantenedores analisam as evidências e atualizam o banco de dados pelo editor interno. Acompanhe as perguntas e a publicação na issue. O banco de dados é a única fonte dos registros do catálogo; o repositório não contém JSON do catálogo para editar.

Administradores editam registros em [Dados internos](https://phaseo.app/internal/data) e analisam os preços propostos em [Atualizações de provedores](https://phaseo.app/internal/data/imports). As duas páginas exigem acesso de administrador.
