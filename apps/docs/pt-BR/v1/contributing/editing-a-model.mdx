Os dados dos modelos ficam em arquivos JSON em `packages/data/catalog/src/data/models`. Cada modelo tem uma pasta própria e um arquivo `model.json`.

## 1. Localize o modelo

Localize a pasta do modelo pelo provedor e pelo nome do modelo. Por exemplo:

`packages/data/catalog/src/data/models/openai/gpt-5-2025-08-07/model.json`

## 2. Faça as alterações

As alterações mais comuns incluem:

- Descrições e links
- Recursos e endpoints compatíveis
- Preços ou informações de disponibilidade
- Referências a benchmarks

Mantenha os valores de acordo com o esquema usado nos arquivos próximos.

## 3. Valide os dados

Execute o script de validação de dados antes de abrir um PR:

```bash
pnpm validate:data
```

## 4. Abra um PR

Inclua um breve resumo das alterações e das fontes usadas.
