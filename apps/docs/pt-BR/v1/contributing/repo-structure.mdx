A Phaseo é um monorepo pnpm e Turborepo. Encontre abaixo a pasta da sua alteração de código ou de documentação. Os registros do catálogo não ficam no repositório; para alterar um, [abra uma issue](./overview.mdx).

## Aplicações

| Caminho | Finalidade |
| --- | --- |
| `apps/web` | Site Next.js 16, painel e editor interno do catálogo. |
| `apps/web-api` | Leituras públicas do catálogo e APIs autenticadas de conta e de administração. |
| `apps/api` | Roteamento do Gateway e execução nos provedores em Cloudflare Workers. |
| `apps/docs` | Documentação Mintlify; as páginas MDX ficam em `v1`, e a navegação em `docs.json`. |
| `apps/mcp` | Servidor MCP da Phaseo para descoberta de modelos, preços e uso. |
| `apps/desktop` | Aplicativo Phaseo Desktop. |
| `apps/mobile` | Aplicativo móvel da Phaseo (Expo, Android primeiro). |
| `apps/slack` | Worker por trás do agente da Phaseo para Slack. |

## Pacotes e ferramentas

| Caminho | Finalidade |
| --- | --- |
| `packages/sdk` | SDKs de TypeScript, Python, Go, C#, PHP, Ruby, Java, Rust e C++, além dos Agent SDKs (`agent-sdk-*`). |
| `packages/cli/phaseo` | A ferramenta de linha de comando `@phaseo/cli`. |
| `packages/integrations` | O provedor do Vercel AI SDK e o provedor Terraform. |
| `packages/shared` | Código compartilhado entre aplicações, como UI, regras de gasto e configurações de roteamento. |
| `supabase/schemas` | Definições declarativas do banco de dados. |
| `supabase/migrations` | Migrações SQL progressivas que implantam alterações de esquema e de permissões. |
| `scripts` | Utilitários de validação, geração de SDKs e automação. |
| `.github/workflows` | CI, implantação e sincronização do catálogo. |
| `.changeset` | Metadados de lançamento dos pacotes versionados. |

## Dados do catálogo

O banco de dados é a única fonte de modelos, provedores, organizações, preços, benchmarks e configurações do catálogo. O repositório não contém JSON do catálogo. Administradores gerenciam os registros em [Dados internos](https://phaseo.app/internal/data); as contribuições públicas chegam como issues do GitHub.

Alterações de esquema e de aplicações continuam passando por migrações e pull requests. Atualize os arquivos de SDK gerados com os comandos de geração deles, não manualmente.

## Automação do catálogo

A sincronização de provedores coloca os preços propostos na fila para revisão em [Atualizações de provedores](https://phaseo.app/internal/data/imports). Os jobs de benchmarks e de ciclo de vida de modelos leem e gravam no banco de dados.

Um registro do catálogo não habilita sozinho o roteamento no Gateway. Alterações de rotas e preços precisam de revisão de um administrador.

Para começar uma alteração, veja [Contribuir com código ou documentação](./how-to-contribute.mdx).
