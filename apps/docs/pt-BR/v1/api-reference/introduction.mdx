Envie todas as solicitações para `https://api.phaseo.app/v1` com sua chave em um cabeçalho `Authorization: Bearer`. Encontre abaixo o endpoint para a sua tarefa e abra a página de referência dele.

## Encontrar o endpoint certo

| Se você quer | Comece por |
| --- | --- |
| Enviar sua primeira solicitação | [Início rápido](../quickstart) |
| Gerar texto ou usar ferramentas | [`POST /responses`](./endpoint/responses) |
| Tomar decisões tipadas | [`POST /decisions`](./endpoint/decisions) |
| Manter uma integração existente compatível com a OpenAI | [`POST /chat/completions`](./endpoint/chat-completions) |
| Consultar modelos e provedores | [`GET /models`](./endpoint/models) e [`GET /providers`](./endpoint/providers) |
| Criar música ou gerenciar arquivos | [`POST /music/generate`](./endpoint/music-generate) e [`POST /files`](./endpoint/files) |
| Gerar vídeo (Beta) | [`POST /videos`](./endpoint/video-create) |
| Enviar um lote ou baixar resultados (Beta) | [`POST /batches`](./endpoint/batches-create) e [`GET /batches/{batch_id}/results`](./endpoint/batches-results) |

## URL base

```http
https://api.phaseo.app/v1
```

Todos os caminhos de endpoints desta referência são relativos a esta URL base.

## Autenticação

| Credencial | Formato | Chamadas |
| --- | --- | --- |
| [Chave de API do Gateway](../developers/authentication.mdx) | `phaseo_v1_sk_<kid>_<secret>` | Endpoints de inferência |
| [Chave de API de gerenciamento](../developers/management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | Endpoints de administração, limitados às permissões da chave |

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

Se a autenticação falhar, a API retorna `401`.

## Recursos da API

| Recurso | O que faz |
| --- | --- |
| Inferência | Gere texto, imagens, áudio e embeddings; tome decisões, reordene, modere ou analise conteúdo. Comece com [Responses](./endpoint/responses.mdx) ou [Decisões](./endpoint/decisions.mdx). |
| Tarefas assíncronas e arquivos | Envie tarefas de [vídeo](./endpoint/video-create.mdx) ou de [lote](./endpoint/batches-create.mdx), transfira arquivos e configure webhooks. |
| Modelos e preços | Descubra [modelos](./endpoint/models.mdx), ofertas de provedores e [custos estimados](./endpoint/pricing-calculate.mdx). |
| Roteamento e políticas | Configure predefinições, credenciais de provedores, modelos privados e [proteções](./endpoint/guardrails.mdx). |
| Uso e monitoramento | Examine [logs](./endpoint/logs-list.mdx), atividade, análises, avaliações e saúde do serviço. |
| Gerenciamento do espaço de trabalho | Gerencie [espaços de trabalho](./endpoint/workspaces-list.mdx), chaves, orçamentos, identidades e integrações. |

## Cobrança e limites de taxa

Solicitações pagas precisam de saldo suficiente na carteira para passar por uma verificação de créditos antes de serem executadas. Modelos cujo ID termina em `:free` não precisam de créditos depositados. As solicitações podem ser limitadas por um provedor ou pelos limites do espaço de trabalho e da chave; consulte [Limites de taxa](./limits.mdx).
