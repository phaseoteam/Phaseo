Use esta página para encontrar o caminho de API correto antes de abrir a referência de um endpoint. Todos os endpoints do Phaseo Gateway compartilham uma URL base e usam autenticação Bearer.

## Escolha o caminho

| Se você quer | Comece por |
| --- | --- |
| Enviar sua primeira solicitação | [Início rápido](../quickstart.mdx) |
| Gerar texto ou usar ferramentas | `POST /responses` |
| Manter uma integração OpenAI compatível existente | `POST /chat/completions` |
| Consultar modelos e provedores | `GET /models` e `GET /providers` |
| Criar música ou gerenciar arquivos | `POST /music/generations` e `POST /files` |

## URL base

URL base de produção:

```http
https://api.phaseo.app/v1
```

Todos os caminhos de endpoints desta referência são relativos à URL base `/v1`.

## Autenticação

A maioria dos endpoints exige uma chave de API padrão do Gateway. Endpoints de gerenciamento exigem uma chave de API de gerenciamento criada no painel.

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

Se a autenticação falhar, a API retornará `401`.

## Recursos da API

| Recurso | Função |
| --- | --- |
| API de Responses | Gerar respostas de modelos com ferramentas, saída estruturada e entrada multimodal. |
| Chat Completions | Manter uma integração de chat OpenAI compatível existente. |
| Anthropic Messages | Manter uma integração Messages compatível com Anthropic. |
| Embeddings | Criar representações vetoriais para pesquisa, recuperação e classificação. |
| Imagens | Gerar ou editar imagens. |
| Texto para fala | Gerar áudio falado a partir de texto. |
| Fala para texto | Transcrever ou traduzir áudio. |
| Geração de música | Criar tarefas de geração de música e consultar o status delas. |
| Arquivos | Enviar e recuperar entradas para fluxos de trabalho de API compatíveis. |
| Modelos, provedores e endpoints | Descobrir o que está disponível no Gateway. |
| Preços, atividade e gerações | Estimar custos e consultar os resultados das solicitações. |
| Chaves de API e espaços de trabalho | Gerenciar o acesso programático e os recursos do espaço de trabalho. |

## Cobrança e limites de taxa

- A Phaseo não aplica limites de taxa próprios. Os limites são definidos pelos provedores upstream.
- Solicitações pagas exigem saldo suficiente na carteira para passar pela verificação prévia de créditos.
- Modelos gratuitos com `:free` não exigem créditos depositados.
