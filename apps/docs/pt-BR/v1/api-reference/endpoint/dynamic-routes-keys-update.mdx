---
title: "Substituir chaves da rota dinâmica"
sidebarTitle: "Associar chaves"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml PUT /routing/dynamic-routes/{id}/keys"
description: "Substitui atomicamente as chaves de API associadas a uma rota dinâmica."
---
<Note>Este endpoint requer uma chave de API de gerenciamento com `settings:write`.</Note>

Todas as chaves precisam pertencer ao espaço de trabalho da chave de gerenciamento. Uma chave só pode ser associada a uma rota dinâmica.
