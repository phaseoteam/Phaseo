---

Envie um payload de uso para calcular o preço com base nas regras de preços ativas do gateway para um provedor, um modelo e um endpoint. Os quatro campos são obrigatórios:

- `provider`: o ID do provedor, por exemplo `openai`.
- `model`: o ID do modelo roteado.
- `endpoint`: a família de endpoints, por exemplo `responses` ou `chat.completions`.
- `usage`: o uso a ser precificado, como contagens de tokens ou outras entradas de medição.

Para listar os preços atuais em vez de precificar um payload, use [Listar preços dos modelos](./pricing-models.mdx).
