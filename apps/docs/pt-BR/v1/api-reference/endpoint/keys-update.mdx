<Note>Este endpoint requer uma chave de API de gerenciamento. Chaves de API padrão do gateway não são aceitas.</Note>

Use esta rota para renomear uma chave, ajustar escopos, definir expiração, desativá-la ou definir um limite de gastos com `limit` e `limit_reset`.
