description: "Cria uma predefinição reutilizável de gateway para o espaço de trabalho."
---
<Note>Este endpoint requer uma chave de API de gerenciamento com `presets:write` e uma identidade de usuário associada.</Note>

A configuração pode incluir padrões limitados de prompts, parâmetros, roteamento e plugins. Predefinições públicas usam o identificador do publicador do espaço de trabalho.
