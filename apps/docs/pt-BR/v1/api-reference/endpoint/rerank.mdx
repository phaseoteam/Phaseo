Use este endpoint para reordenar documentos candidatos antes de enviá-los para uma etapa de pesquisa, recuperação ou geração.

Verifique o modelo em `GET /v1/models` antes da implantação. A resposta padrão contém apenas modelos com uma rota pública do Gateway.
