Este endpoint está em [Beta](../../developers/feature-maturity.mdx) e é ativado por espaço de trabalho, sob solicitação.

Esta rota encaminha os bytes do arquivo upstream somente depois de confirmar que ele pertence ao espaço de trabalho atual.
