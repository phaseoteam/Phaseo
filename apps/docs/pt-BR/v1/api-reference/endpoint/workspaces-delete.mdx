openapi: "/pt-BR/openapi/v1/openapi.localized.yaml DELETE /workspaces/{id}"
description: "Exclui um espaço de trabalho por ID ou slug."
---
<Note>Este endpoint requer uma chave de API de gerenciamento. Chaves de API padrão do gateway não são aceitas.</Note>

O espaço de trabalho padrão não pode ser excluído. Espaços de trabalho com chaves de API ativas precisam ser limpos primeiro.
