---

- `models`: uma entrada para cada combinação visível de provedor, modelo e endpoint
- `meters`: as linhas de medição ativas dessa entrada, incluindo unidade, tamanho da unidade, moeda e preço por unidade
- `display_name`: o nome público visível do modelo quando a regra de preço corresponde a um modelo público canônico
