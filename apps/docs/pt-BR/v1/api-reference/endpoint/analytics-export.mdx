---
title: "Exportar análises do espaço de trabalho"
sidebarTitle: "Exportar análises"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml GET /analytics/export"
description: "Exporta análises filtradas do espaço de trabalho como CSV."
---
<Note>Este endpoint requer uma chave de API de gerenciamento com `analytics:read`.</Note>

A exportação aceita os mesmos filtros do endpoint de análises e retorna todas as linhas agregadas correspondentes em CSV seguro para planilhas.
