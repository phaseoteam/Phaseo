Envie um `model` e um `prompt` para `POST /v1/music/generate` e receba uma faixa de qualquer provedor de música com um único formato de solicitação. O Phaseo cuida dos provedores síncronos e da consulta às filas dos provedores para você.

```bash
curl https://api.phaseo.app/v1/music/generate \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax/music-3.0:free",
    "prompt": "Warm jazz trio with brushed drums",
    "format": "mp3"
  }'
```

## Ler o resultado

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "gmicloud",
  "model": "minimax/music-3.0:free",
  "nativeResponseId": "5c30b275-d669-4a25-8151-de6d60214853",
  "audio_url": "https://.../generated-music.mp3",
  "usage": {
    "requests": 1,
    "output_audio_seconds": 25.364
  }
}
```

Uma geração concluída inclui `audio_url` ou `audio_base64`. `status` é `queued`, `in_progress`, `completed` ou `failed`. Enquanto ele ainda não for final, consulte [`GET /v1/music/generate/{music_id}`](./music-status.mdx) com o mesmo `id`.

`id` é o ID estável da solicitação no Phaseo. `nativeResponseId` é o identificador do provedor upstream, para correlação com o provedor e suporte. `usage` inclui `output_audio_seconds` quando o provedor informa a duração gerada.

## Definir opções do Suno

Os modelos Suno aceitam um objeto `suno` opcional:

| Campo | Tipo | Observações |
| --- | --- | --- |
| `customMode` | boolean | Padrão `false` |
| `instrumental` | boolean | Padrão `false` |
| `prompt` | string | Substitui o `prompt` de nível superior |
| `style`, `title` | string | Obrigatórios quando `customMode` é `true` |
| `personaId`, `personaModel` | string | |
| `negativeTags` | string | |
| `vocalGender` | `m` ou `f` | |
| `styleWeight`, `weirdnessConstraint`, `audioWeight` | number | De 0 a 1 |

`prompt` é obrigatório quando `customMode` é `false`, e quando `customMode` é `true` com `instrumental` definido como `false`.

Uma solicitação que viola uma regra do provedor retorna `400`:

```json
{
  "error": "validation_error",
  "reason": "..."
}
```
