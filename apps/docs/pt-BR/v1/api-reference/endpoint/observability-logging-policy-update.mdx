description: "Configurar o armazenamento e a retenção dos registros de entrada e saída do espaço de trabalho."
---
<Note>Este endpoint requer uma chave de API de gerenciamento com `settings:write`.</Note>

A retenção deve ficar entre 90 e 365 dias. Desativar o registro também desativa o controle de privacidade dos registros de entrada e saída do espaço de trabalho.
