`/v1/messages` aceita payloads da API Anthropic Messages e retorna respostas no formato Anthropic.

## Transmissão contínua

Defina `stream: true` para receber eventos enviados pelo servidor no formato Anthropic (`message_start`, `content_block_*`, `message_delta`, `message_stop`).

## Mensagens de sistema no meio da conversa

Adicione uma mensagem com `role: "system"` a `messages` para uma instrução que vale a partir desse ponto da conversa. O campo `system` de nível superior não muda, então um prefixo em cache continua sendo aproveitado.

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5.5",
    "max_tokens": 512,
    "system": "You are a code review assistant.",
    "messages": [
      { "role": "user", "content": "Review process() in utils.py." },
      { "role": "assistant", "content": "The loop is fine; the regex is compiled on every call." },
      { "role": "user", "content": "Now review the code that calls it." },
      { "role": "system", "content": "From now on, include type annotations in every suggestion." }
    ]
  }'
```

- Uma mensagem de sistema aceita uma string ou blocos de texto. Ela deve vir logo após um turno do usuário (ou um turno do assistente que termine em um resultado de ferramenta do servidor) e ser a última mensagem ou ser seguida por um turno do assistente. Outras posições retornam 400.
- Claude Fable 5 e 5.1, Mythos 5 e 5.1, Opus 4.8, Opus 5 e 5.5, Sonnet 5.5 e Haiku 5.5 a recebem na posição em que foi enviada. Os outros modelos Claude, incluindo o Sonnet 5, e todos os modelos Claude no Microsoft Foundry a recebem como parte do prompt de sistema de nível superior. Os outros provedores a recebem como uma mensagem de sistema, igual a uma enviada para Chat Completions.
- `clear_at`, `output_config` e os blocos `tool_addition` ou `tool_removal` não são compatíveis.

## Observações

- Os campos de uso de ferramentas do Anthropic são compatíveis.
- `stream: true` também funciona em loops de ferramentas. Para ferramentas de servidor gerenciadas pelo Gateway, a Phaseo pode materializar o turno upstream, continuar o loop e emitir novamente um stream sintético.
- O formato nativo da ferramenta de busca na web do Anthropic também é aceito diretamente em `tools`, por exemplo `type: "web_search_20250305"`.
- O cabeçalho `X-Phaseo-Strictness` controla o tratamento de parâmetros não compatíveis.

## Ferramentas do servidor

`/v1/messages` também aceita estas ferramentas de servidor gerenciadas pelo Gateway:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

A Phaseo converte essas ferramentas para o formato compatível com Anthropic no provedor upstream, executa-as no servidor e continua o loop de ferramentas.

## Busca na web nativa do provedor

Quando um par compatível de modelo/provedor Anthropic oferece busca na web nativa, você também pode enviar diretamente a definição nativa da ferramenta:

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-4",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "Find the latest Anthropic web search guidance." }
    ],
    "tools": [
      {
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": 3,
        "allowed_domains": ["docs.anthropic.com"]
      }
    ],
    "tool_choice": { "type": "tool", "name": "web_search" }
  }'
```

O roteamento do provedor ainda verifica o suporte a `web_search_options` antes da execução.

### Exemplo de data e hora

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-4",
    "max_tokens": 512,
    "stream": false,
    "messages": [
      { "role": "user", "content": "What time is it in America/New_York right now?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "America/New_York" }
      }
    ],
    "tool_choice": { "type": "auto" }
  }'
```

Quando usadas, as chamadas às ferramentas do servidor aparecem nos contadores `usage.server_tool_use.*`.
