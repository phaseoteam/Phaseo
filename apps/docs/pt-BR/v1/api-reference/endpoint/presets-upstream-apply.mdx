openapi: "/pt-BR/openapi/v1/openapi.localized.yaml POST /presets/{id}/upstream"
description: "Aplicar uma versão pública upstream a um rascunho de fork local."
---
<Note>Este endpoint requer uma chave de API de gerenciamento com `presets:write` e uma identidade de usuário associada.</Note>

Publique ou descarte as alterações do rascunho local antes de aplicar uma versão upstream. A aplicação não publica o rascunho resultante.
