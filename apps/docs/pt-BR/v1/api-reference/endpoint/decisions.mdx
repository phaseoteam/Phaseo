Envie `input` e uma matriz ordenada de `questions` para `POST /v1/decisions` e receba uma resposta tipada por pergunta, com probabilidades, na mesma ordem.

## Tomar uma decisão

Esta solicitação faz uma pergunta de cada tipo. Ela precisa de uma chave de API do Phaseo e de uma rota `openai/gpt-6-luna` disponível.

<CodeGroup>
```bash cURL

  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-luna",
    "input": "I was charged twice for my order and I cannot log in to download the invoice.",
    "questions": [
      {
        "type": "choice",
        "name": "department",
        "instructions": "Which team should handle this request?",
        "choices": [
          { "value": "billing", "description": "Payments, invoices and refunds" },
          { "value": "support", "description": "Product usage and troubleshooting" }
        ]
      },
      {
        "type": "predicate",
        "name": "is_blocked",
        "instructions": "Is the customer blocked from using the product?"
      },
      {
        "type": "score",

        "levels": [{ "label": "low" }, { "label": "medium" }, { "label": "high" }]

```

## Escrever perguntas

`input` é uma string ou uma matriz de mensagens `user` cujo `content` é uma string ou uma lista de partes `input_text`, `input_image`, `input_audio` e `input_video`. `name` é opcional; as respostas mantêm a ordem da solicitação, inclusive para perguntas sem nome e nomes repetidos.

Uma solicitação carrega no máximo 128 perguntas, exceto em `google/gemini-decision-1`, que aceita até 1000, em `parallel/decisions-fast`, que aceita até 100, e em Clef, que aceita até 64. Uma solicitação acima do limite do modelo retorna `400`.

| `type` | Campos extras | Campos da resposta |
| --- | --- | --- |
| `predicate` | nenhum | `probability` (0–1) de a resposta ser sim |
| `choice` | `choices`: `value` (string ou booleano, distintos) e `description` opcional | `choice`, `confidence`, `probabilities` por valor |
| `score` | `levels`: `label` e `description` opcional | `score` (índice de nível ponderado pela probabilidade), `confidence`, `probabilities` por nível |
| `box` | nenhum; precisa de uma imagem em `input` | `box` (`top`, `bottom`, `left`, `right`), `confidence` |
| `locate` | nenhum; precisa de um `input` em string sem mídia | `spans`: `start`, `end`, `text`, `score` |

Valores de escolha booleanos voltam como booleanos. Um modelo que se recusa a responder uma pergunta retorna `type: "refusal"` para ela. Os tipos que cada modelo suporta estão listados em [Escolher um modelo](#choose-a-model).

As imagens vão em partes `input_image` como URLs de dados. URLs de imagem HTTPS hospedadas funcionam apenas nos modelos da Base Labs (`baselabs/elephant-1`, `baselabs/mammoth-1` e `baselabs/joey-1`) e precisam estar no Amazon S3, no Google Cloud Storage ou no Azure Blob Storage. Uma solicitação leva no máximo 128 imagens, que o Luna aceita; outros provedores definem limites menores. Um `detail` de imagem explícito e `safety_identifier` exigem uma rota da OpenAI.

## Usar o formato de estado antigo

Solicitações com `state` e um mapa de perguntas nomeadas continuam funcionando e retornam respostas indexadas pelos mesmos nomes. O Together Tev (`together/tev1-4b-experimental`) exige esse formato, porque retorna um rótulo sem probabilidades, e responde apenas perguntas `choice`. O Respan Span-01 também usa esse formato. Não misture os formatos: `input` com `state` ou `images` retorna `400`.

- `state`: uma string, um objeto ou uma matriz com as informações a avaliar.
- `questions`: até 128 perguntas nomeadas, ou mais em modelos com limite maior. Cada uma define `type` como `noul` (sim/não), `choice` ou `score`, além de `instructions`. Perguntas de escolha recebem `criteria` como um mapa de opção para descrição; perguntas de pontuação recebem `criteria` como uma matriz de pelo menos duas descrições de nível.
- Perguntas `locate` usam apenas `instructions` e precisam de um `state` em string sem `images`; veja [Perplexity Decider](#liquid-d1-and-perplexity-decider).
- `images`: até quatro imagens PNG, JPEG ou WebP, como URLs `data:` ou objetos `{ "content_type", "base64" }`.
- `model`: o padrão é `typesafe/jev-1.13.0` quando omitido.

As respostas usam as mesmas chaves de `questions`. Respostas `choice` incluem a opção selecionada, as probabilidades e a confiança; respostas `noul` incluem uma probabilidade de 0 a 1; respostas `score` incluem uma pontuação ponderada pela probabilidade, uma legenda, as probabilidades e a confiança.

### TypeSafe Jev

Use `typesafe/jev-1.13.0` para o Jev 1.13, ou `typesafe/jev-latest` para acompanhar a versão mais recente do Jev. Para a semântica das perguntas no upstream, consulte a [referência da API](https://docs.typesafe.ai/api) da TypeSafe.

Nas rotas da TypeSafe que oferecem suporte, o Jev 1.13 e o 1.14 aceitam imagens PNG ou JPEG embutidas por `input_image` ou pelo campo antigo `images`. O Phaseo monta os recursos de imagem da TypeSafe e ativa o suporte a imagens automaticamente. As imagens precisam respeitar os [limites de imagem](https://docs.typesafe.ai/images) da TypeSafe: no máximo 16 MiB cada, de 256 a 1568 pixels em cada lado e pelo menos 78.400 pixels no total. A TypeSafe valida as dimensões e a codificação e não redimensiona imagens rejeitadas. O corpo JSON mapeado para o upstream é limitado a 32 MiB. Os tokens de imagem usam o preço de entrada normal.

`box` (em rotas que oferecem suporte, como o Jev 1.14) exige uma imagem, não aceita critérios e retorna uma caixa delimitadora mais a confiança. Suas bordas vão de 0 a 1, medidas a partir do canto superior esquerdo. Box sempre retorna um retângulo, então combine-o com uma pergunta `predicate` de presença quando o alvo puder estar ausente. Com o campo antigo `images`, refira-se a `images[0]`; com entrada ordenada, refira-se à primeira imagem ou a `[Image 0]`. Consulte o [contrato do Box](https://docs.typesafe.ai/primitives/box).

Defina `provider_options.typesafe.long_context` como `true` para aumentar os limites de contexto por solicitação e por pergunta para 262 mil tokens, em vez dos padrões de 64 mil por solicitação e 32 mil por pergunta. O contexto longo custa o mesmo por token. Imagens, Box e contexto longo são recursos experimentais no upstream.

```json
{
  "model": "typesafe/jev-1.14.0",
  "input": [{
    "role": "user",
    "content": [{ "type": "input_image", "image_url": "data:image/png;base64,<base64 image bytes>" }]
  }],
  "questions": [
    { "type": "predicate", "name": "visible", "instructions": "Is there a mug in the first image?" },
    { "type": "box", "name": "mug", "instructions": "The mug in the first image" }
  ],
  "provider_options": { "typesafe": { "long_context": true } }
}
```

### Cloudflare Clef e Clef Flash

`cloudflare/clef` e `cloudflare/clef-flash` rodam no Cloudflare Workers AI. O Clef tem uma janela de contexto de 65.536 tokens e o Clef Flash, de 24.576 tokens.

```json
{
  "model": "cloudflare/clef-flash",
  "state": "Inspect the attached product photo.",
  "images": [{ "content_type": "image/png", "base64": "<base64 image bytes>" }],
  "questions": {
    "damaged": { "type": "noul", "instructions": "Is the product visibly damaged?" }
  }
}
```

`images` também aceita uma string `data:image/png;base64,...`. O Clef aceita até quatro imagens PNG, JPEG ou WebP, cada uma com no máximo 4 MiB e 16 megapixels, com no máximo 8 MiB de dados de imagem decodificados e um corpo de solicitação de 13 MiB. URLs remotas não são suportadas, e a Cloudflare valida os formatos e as dimensões das imagens. Modelos sem suporte a imagens rejeitam solicitações com imagens.

O Clef aceita no máximo 64 perguntas, com IDs de até 100 letras, dígitos, sublinhados, pontos ou hifens. Perguntas de escolha precisam de 2 a 255 opções e perguntas de pontuação, de 2 a 10 níveis. Consulte a [documentação do Clef](https://developers.cloudflare.com/workers-ai/models/clef/) da Cloudflare.

### Cloudflare Clef Omni

`cloudflare/clef-omni` aceita texto, imagens, áudio e vídeo. As partes de áudio e vídeo são extensões do Phaseo ao formato de entrada; as rotas da OpenAI aceitam apenas texto e imagens. Substitua os bytes de áudio e a URL de vídeo de exemplo pelas suas próprias mídias antes de enviar este exemplo.

```json
{
  "model": "cloudflare/clef-omni",
  "input": [{
    "role": "user",
    "content": [
      { "type": "input_text", "text": "Review the recording and clip." },
      { "type": "input_audio", "input_audio": { "data": "<base64 WAV bytes>", "format": "wav" } },
      { "type": "input_video", "video_url": { "url": "https://media.example.com/clip.mp4" } }
    ]
  }],
  "questions": [{ "type": "predicate", "name": "safe", "instructions": "Is the equipment operating safely?" }]
}
```

Envie o áudio como `input_audio.data` com `format: "wav"` ou `"mp3"`, ou como `input_audio.url` com uma URL HTTPS pública ou uma URL de dados de áudio embutida. `input_video.video_url` aceita uma string ou `{ "url": "..." }` com uma URL HTTPS pública ou uma URL de dados MP4/WebM embutida. Os servidores remotos precisam retornar o Content-Type correspondente. O Phaseo busca as URLs com limites de tamanho e verificações de endereços privados e de redirecionamentos, e depois incorpora a mídia para a Cloudflare; as credenciais do provedor nunca são enviadas ao servidor de mídia.

| Limite | Valor |
| --- | --- |
| Clipes de áudio | 4, cada um com no máximo 8 MiB e 300 segundos |
| Vídeos | 2, cada um com no máximo 16 MiB e 60 segundos |
| Áudio e vídeo combinados | 16 MiB decodificados |
| Imagens | Os mesmos limites por imagem e combinados do Clef |
| Corpo da solicitação | 37 MiB (substitui os 13 MiB do Clef) |
| Contexto | 64.000 tokens |

A Cloudflare valida a codificação da mídia, as dimensões das imagens e a duração dos clipes, e amostra o vídeo a dois quadros por segundo. A trilha sonora de um vídeo é usada quando todos os vídeos da solicitação têm uma. Os tokens de mídia contam para o contexto e para a cobrança; o Phaseo faz a liquidação com base no uso de entrada informado pela Cloudflare e não adiciona cobrança separada por áudio ou vídeo. Consulte o [contrato do Omni da Cloudflare](https://github.com/cloudflare/cloudflare-docs/blob/production/src/content/workers-ai-models/clef-omni.json).

### Liquid D1 e Perplexity Decider

O Liquid D1 (`liquid-ai/d1:free`, também `liquid-ai/d1`) é gratuito durante o acesso antecipado experimental. O Perplexity Decider V1.3 (`perplexity/pplx-decider-v1.3`, ou `perplexity/pplx-decider-latest`) e o Decider Flash V1.3 (`perplexity/pplx-decider-flash-v1.3`, ou `perplexity/pplx-decider-flash-latest`) precisam de uma credencial de provedor da Perplexity no Phaseo. O estado de imagem deles usa URLs de dados base64 PNG, JPEG ou WebP; URLs de imagem remotas não são suportadas. Eles também respondem a perguntas `locate`, que retornam as partes de um `input` ou `state` em string que correspondem às `instructions`, como `"email address"`. Cada trecho tem `text` copiado literalmente, posições `start` e `end` contadas em pontos de código Unicode (`end` é exclusiva) e um `score` em que um valor maior indica mais certeza; `spans` fica vazio quando nada corresponde. Locate não usa criteria nem aceita imagens, áudio ou vídeo, e só funciona nos modelos que o indicam; os outros retornam `400`. A Perplexity o treinou com entradas de até 8K tokens. Nos dois, uma pergunta de escolha aceita até 255 opções e uma pergunta de pontuação, até 10 níveis.

### Inception Mercury Decide

`inception/mercury-decide` recebe evidências em texto ou JSON. Perguntas de escolha aceitam até 255 opções e perguntas de pontuação, até 10 níveis. Imagens, streaming e chamadas de ferramentas não são suportados. O preço de entrada de $0.02 é a promoção de 50% da Inception, que não tem data de término publicada; consulte os [preços atuais no upstream](https://docs.inceptionlabs.ai/get-started/models) antes de usar.

```json
{
  "model": "inception/mercury-decide",
  "input": "Please refund the duplicate charge on my account.",
  "questions": [{
    "type": "predicate",
    "name": "billing",
    "instructions": "Is this request about billing?"
  }]
}
```

### Microsoft Decision

`microsoft/microsoft-decision-1` roda em uma implantação do Azure Foundry e recebe evidências em texto ou JSON de até 32.768 tokens. Mídia, streaming, ferramentas, `safety_identifier` e `service_tier` não são suportados. Consulte o [guia da Microsoft](https://learn.microsoft.com/azure/foundry/foundry-models/how-to/use-foundry-models-microsoft-decision).

```json
{
  "model": "microsoft/microsoft-decision-1",
  "input": "The API returns 500 on every call.",
  "questions": [{
    "type": "choice",
    "name": "team",
    "instructions": "Which team should handle this ticket?",
    "choices": [
      { "value": "engineering", "description": "Bugs, errors, and outages" },
      { "value": "support", "description": "How-to and account questions" }
    ]
  }]
}
```

### Respan Span-01

O Span-01 usa o formato antigo. `state` precisa ser um trecho de conversa: uma matriz `input` com as mensagens anteriores e uma mensagem do assistente em `output`. Ele responde apenas perguntas `noul`: o valor `noul` é a probabilidade de o comportamento estar presente, e `probabilities` também traz as probabilidades de ausência e de não observável.

```json
{
  "model": "respan/span-01:free",
  "state": {
    "input": [{ "role": "user", "content": "Please connect me to a person." }],
    "output": { "role": "assistant", "content": "I will connect you to support." }
  },
  "questions": {
    "escalation": {
      "type": "noul",
      "instructions": "Does the assistant offer a human handoff?"
    }
  }
}
```

Uma resposta tem esta forma:

```json
{
  "answers": {
    "escalation": {
      "type": "noul",
      "noul": 0.73,
      "probabilities": {
        "true": 0.73,
        "false": 0.25,
        "not_observable": 0.02
      }
    }
  }
}
```

`respan/span-01:free` é o modelo Lite gratuito, com limite diário, e corresponde ao modelo `span-01-free` da Respan. `respan/span-01` corresponde a `span-01-pro` e é cobrado pela Respan. O Span-01 está em acesso antecipado: a Respan precisa ativá-lo para a sua organização, e você precisa adicionar sua chave de API da Respan como credencial de provedor da Respan no Phaseo antes de chamar qualquer um dos dois modelos.
