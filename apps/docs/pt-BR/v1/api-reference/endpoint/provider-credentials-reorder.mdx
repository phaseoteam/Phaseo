title: "Reordenar credenciais do provedor"
sidebarTitle: "Reordenar credenciais"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml POST /byok/reorder"
description: "Substitui a prioridade das credenciais em um grupo de roteamento do provedor."
---
Informe cada ID de credencial do provedor e grupo de roteamento selecionados exatamente uma vez. O primeiro ID recebe a maior prioridade. Ordens parciais ou duplicadas são rejeitadas.
