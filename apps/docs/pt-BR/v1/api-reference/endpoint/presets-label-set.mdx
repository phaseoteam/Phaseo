---
<Note>Este endpoint requer uma chave de API de gerenciamento com `presets:write` e uma identidade de usuário associada. Quem criou a predefinição pode alterar os rótulos, assim como proprietários e administradores do espaço de trabalho quando a predefinição é compartilhada.</Note>

Solicitações que fixam o rótulo, como `@support-triage@production` ou `prompt.version: "production"`, usam a nova versão em cerca de dois minutos. Veja [Templates de prompt](../../guides/prompt-templates.mdx).
