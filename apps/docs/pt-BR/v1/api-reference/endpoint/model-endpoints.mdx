Chame este endpoint antes de enviar uma solicitação para confirmar que uma combinação de modelo, provedor, endpoint e parâmetro está disponível. Para `openai/gpt-6-astra`:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

Cada entrada em `endpoints` é uma rota de provedor para um endpoint:

| Campo | Contém |
| --- | --- |
| `endpoint`, `capability_id`, `public_path`, `collection` | Os IDs canônicos do endpoint e do recurso e o caminho público da API |
| `provider`, `model` | O ID e o nome do provedor, e o slug do modelo no provedor |
| `routable`, `status`, `status_reason` | Se a rota recebe tráfego agora, sua disponibilidade e por que ela está apenas em prévia ou inativa |
| `modalities` | Modalidades de entrada e saída |
| `capabilities` | Nomes dos parâmetros suportados e detalhes estruturados dos parâmetros |
| `routing` | Estados de roteamento do provedor, do modelo e do recurso |
| `effective` | Datas `from` e `to` quando a rota está agendada ou tem prazo definido |
| `pricing` | O resumo de preços do endpoint |

Para comparar modelos antes, use [Listar modelos](./models.mdx); para ver todos os endpoints que a API expõe, use [Listar endpoints](./endpoints.mdx).

## Incluir rotas planejadas e inativas

O padrão `availability=active` retorna apenas linhas roteáveis publicamente. Use `availability=all` para inspecionar rotas em breve e inativas:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints?availability=all" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

Só envie tráfego de produção para uma linha em que `routable` seja `true` e `status` seja `active`.

## Filtrar rotas

Estes filtros aceitam parâmetros repetidos ou uma lista separada por vírgulas: `provider`, `provider_status`, `provider_routing_status`, `model_routing_status`, `capability_status`, `provider_availability_status`, `provider_availability_reason`, `status` e `supported_parameters` (alias `params`). [Listar modelos](./models.mdx#filter-the-list) descreve os valores deles.

Esta chamada retorna as rotas da OpenAI que suportam `reasoning_effort`:

```bash
curl "https://api.phaseo.app/v1/models/openai/gpt-6-astra/endpoints?provider=openai&supported_parameters=reasoning_effort" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```
