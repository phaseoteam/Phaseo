description: "Recupere uma geração de música pelo ID de solicitação do Phaseo."
---

Passe o `id` retornado por [`POST /v1/music/generate`](./music-generate.mdx), não o `nativeResponseId`. O Phaseo retorna o resultado armazenado quando a geração termina e consulta o provedor para você enquanto ela ainda está em andamento.

```bash
curl https://api.phaseo.app/v1/music/generate/req_01JY6MUSIC123 \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "suno",
  "model": "V4_5PLUS",
  "nativeResponseId": "task_123",
  "output": [
    {
      "index": 0,
      "id": "clip_1",
      "audio_url": "https://...",
      "stream_audio_url": "https://...",
      "image_url": "https://...",
      "title": "Midnight Blue",
      "tags": "jazz, piano",
      "duration": 8
    }
  ],
  "usage": {
    "output_audio_count": 1,
    "output_audio_seconds": 8
  }
}
```

`status` é `queued`, `in_progress`, `completed` ou `failed`. `usage` é incluído quando a geração termina.
