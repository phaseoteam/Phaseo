## Usar ferramentas de servidor

Adicione uma ferramenta `phaseo:` a `tools`, ao lado das suas próprias ferramentas de função, e o Phaseo a executa quando o modelo a chama. `/v1/chat/completions` aceita todas as ferramentas de servidor, exceto `phaseo:apply_patch`; o guia [Ferramentas de servidor](../../guides/server-tools) lista todas elas.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["Europe/London"] } }
    ],
    "tool_choice": "auto"
  }'
```

Cada chamada de ferramenta de servidor é contabilizada em `usage.server_tool_use`:

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` adiciona `web_search_requests`, `web_search_results` e `web_search_extra_results`; `phaseo:web_fetch` adiciona `web_fetch_requests`. O tipo antigo `gateway:datetime` continua funcionando.

Com `stream: true`, o Phaseo executa os turnos de ferramenta por conta própria e depois transmite a continuação da resposta para você como um único stream.

## Raciocínio em loops de ferramentas

Modelos de raciocínio retornam o raciocínio na mensagem do assistente em dois campos:

- `reasoning_content`: o texto do raciocínio, quando o provedor retorna algum.
- `reasoning_details`: uma matriz de blocos de raciocínio. Cada entrada tem um `type` igual a `reasoning.text`, `reasoning.summary` ou `reasoning.encrypted`, um `index` e um `format` que indica a família do provedor, por exemplo `anthropic-claude-v1` ou `google-gemini-v1`.

As entradas podem carregar o estado do provedor de que o modelo precisa no passo seguinte de um loop de ferramentas:

| Estado do provedor | Onde fica |
| --- | --- |
| Assinaturas de pensamento do Claude | `signature` nas entradas `reasoning.text` |
| Pensamento redigido do Claude, raciocínio criptografado da OpenAI | `data` nas entradas `reasoning.encrypted` |
| Assinaturas de pensamento do Gemini | `data` nas entradas `reasoning.encrypted` cujo `id` é a chamada de ferramenta a que pertencem |
| O nível de esforço em que uma resposta do Claude foi executada | `data` na última entrada `reasoning.encrypted`, que não tem texto |

Durante o streaming, um delta de `reasoning_details` chega assim que cada bloco de raciocínio termina.

<Warning>
Envie de volta cada mensagem do assistente com o `reasoning_details` inalterado, em todas as solicitações, não só em loops de ferramentas. Nunca descarte, edite nem reordene entradas, criptografadas ou não, incluindo entradas sem texto.
</Warning>

Os valores de `signature` e `data` são opacos e registram o provedor e o modelo que os produziram. O Phaseo os envia somente para essa família de provedor e esse modelo, de modo que um fallback para outro provedor os descarta em vez de falhar. Sem eles, modelos Claude no modo de pensamento manual executam o passo seguinte do loop de ferramentas sem pensamento, e uma mudança de `reasoning_effort` reinicia o cache de prompts do Claude; veja [Mudar o esforço de raciocínio no meio da conversa](../../guides/prompt-caching#change-reasoning-effort-mid-conversation).
