## Ferramentas do servidor

`/v1/chat/completions` aceita ferramentas de função comuns e estas ferramentas de servidor gerenciadas pelo Gateway:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

### Exemplo de data e hora

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Europe/London" }
      }
    ],
    "tool_choice": "auto"
  }'
```

Quando uma ferramenta de servidor é usada, os dados de uso incluem:

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` adiciona `server_tool_use.web_search_requests`, `server_tool_use.web_search_results` e `server_tool_use.web_search_extra_results`. `phaseo:web_fetch` adiciona `server_tool_use.web_fetch_requests`.

## Nota sobre streaming

`stream: true` também é compatível. Para ferramentas de servidor gerenciadas pelo Gateway, a Phaseo pode materializar o turno de chamada à ferramenta a montante, continuar o ciclo e emitir novamente um fluxo sintético.

## Raciocínio em ciclos de ferramentas

Modelos de raciocínio retornam o raciocínio em dois campos da mensagem do assistente:

- `reasoning_content`: o texto do raciocínio, quando o provedor retorna algum.
- `reasoning_details`: um array de blocos de raciocínio no formato usado pelo OpenRouter. Cada entrada tem um `type` (`reasoning.text`, `reasoning.summary` ou `reasoning.encrypted`), um `index` e um `format` que indica a família do provedor, por exemplo `anthropic-claude-v1` ou `google-gemini-v1`.

As entradas podem trazer estado do provedor de que o modelo precisa na próxima etapa de um ciclo de ferramentas:

- Assinaturas de thinking do Claude, em `signature` nas entradas `reasoning.text`.
- Thinking ocultado do Claude e raciocínio criptografado da OpenAI, em `data` nas entradas `reasoning.encrypted`.
- Assinaturas de pensamento do Gemini, em `data` nas entradas `reasoning.encrypted` cujo `id` é a chamada de ferramenta a que pertencem.

Com streaming, um delta de `reasoning_details` chega quando cada bloco de raciocínio termina.

Para que o modelo mantenha o raciocínio entre as etapas, envie de volta a mensagem do assistente com o `reasoning_details` inalterado. Os valores de `signature` e `data` são opacos e registram o provedor e o modelo que os geraram. A Phaseo os envia apenas para essa família de provedores e esse modelo, então uma alternativa com outro provedor os descarta em vez de falhar. Modelos Claude no modo de thinking manual precisam receber o thinking de volta para continuar pensando durante um ciclo de ferramentas; se ele faltar, essa etapa é executada sem thinking.
