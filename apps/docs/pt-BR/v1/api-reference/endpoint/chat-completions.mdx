## Ferramentas do servidor

`/v1/chat/completions` aceita ferramentas de função comuns e estas ferramentas de servidor gerenciadas pelo Gateway:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`

### Exemplo de data e hora

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Europe/London" }
      }
    ],
    "tool_choice": "auto"
  }'
```

Quando uma ferramenta de servidor é usada, os dados de uso incluem:

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` adiciona `server_tool_use.web_search_requests`, `server_tool_use.web_search_results` e `server_tool_use.web_search_extra_results`. `phaseo:web_fetch` adiciona `server_tool_use.web_fetch_requests`.

## Nota sobre streaming

`stream: true` também é compatível. Para ferramentas de servidor gerenciadas pelo Gateway, a Phaseo pode materializar o turno de chamada à ferramenta upstream, continuar o ciclo e emitir novamente um stream sintético.
