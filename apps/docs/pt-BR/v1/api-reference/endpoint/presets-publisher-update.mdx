description: "Renomeia o identificador público do publicador de predefinições do espaço de trabalho."
---
<Note>Este endpoint requer uma chave de API de gerenciamento com `presets:write` e uma identidade de usuário associada.</Note>

O identificador anterior é mantido como alias para que referências públicas existentes continuem funcionando.
