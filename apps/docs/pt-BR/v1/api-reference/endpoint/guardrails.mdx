---
title: "API de proteções"
sidebarTitle: "Visão geral"
description: "Gerenciamento programático de proteções para espaços de trabalho e chaves."
---
<Info>
O gerenciamento de proteções requer uma chave de API de gerenciamento. Operações de leitura exigem `guardrails:read`; alterações exigem `guardrails:write` ou `guardrails:delete`.
</Info>

Use proteções para aplicar controles de privacidade, restrições de provedores e modelos, tratamento de injeção de prompt, políticas de informações confidenciais e limites de solicitações ou custos. Uma proteção pode ser atribuída a chaves de API, membros do espaço de trabalho ou ambos.

Alterações bem-sucedidas atualizam o estado das políticas do espaço de trabalho e aparecem no registro de auditoria.
