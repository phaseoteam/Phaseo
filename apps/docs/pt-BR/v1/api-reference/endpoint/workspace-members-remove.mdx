---
title: "Remover membros do espaço de trabalho"
sidebarTitle: "Remover membros"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml POST /workspaces/{id}/members/remove"
description: "Remove do espaço de trabalho os membros que não são proprietários."
---
Este endpoint requer uma chave de API de gerenciamento com `workspaces:write` e uma função de proprietário ou administrador.

O proprietário do espaço de trabalho não pode ser removido.
