---

<Note>
Este endpoint requer a permissão de gerenciamento `activity:read`. Chamadas OAuth também devem ter a função de proprietário ou administrador do espaço de trabalho.
</Note>

Os eventos contêm apenas metadados sanitizados. Credenciais em texto simples, hashes de credenciais, cabeçalhos de autorização, listas completas de escopos e corpos de solicitações nunca são retornados.
