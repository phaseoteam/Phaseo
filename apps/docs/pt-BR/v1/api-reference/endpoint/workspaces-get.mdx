title: "Obter um espaço de trabalho"
sidebarTitle: "Obter espaço de trabalho"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml GET /workspaces/{id}"
description: "Recupera um espaço de trabalho por ID ou slug."
---
Este endpoint requer uma chave de API de gerenciamento. Chaves de API padrão do gateway não são aceitas.

O segmento de caminho `{id}` pode ser o UUID ou o slug do espaço de trabalho.
