title: "Publicar versão da predefinição"
sidebarTitle: "Publicar versão"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml POST /presets/{id}/versions"
description: "Publicar o rascunho atual da predefinição como uma versão imutável."
---
<Note>Este endpoint requer uma chave de API de gerenciamento com `presets:write` e uma identidade de usuário associada.</Note>

O método de versionamento da predefinição determina o rótulo padrão da versão. Predefinições com SemVer podem informar `version_label` explicitamente.
