---
title: "Atualizar configurações do espaço de trabalho"
sidebarTitle: "Atualizar configurações"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml PATCH /settings"
description: "Atualiza os padrões de roteamento, provedor, privacidade e gateway do espaço de trabalho."
---
<Note>Este endpoint requer uma chave de API de gerenciamento com `settings:write`.</Note>

Alterações de roteamento e de políticas de provedores atualizam os caches afetados do gateway e são registradas no log de auditoria do espaço de trabalho.
