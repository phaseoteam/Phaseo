---
title: "Excluir um modelo privado"
sidebarTitle: "Excluir um modelo privado"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml DELETE /private-models/{id}"
description: "Remova um endpoint de modelo privado do espaço de trabalho."
---

Requer `private_models:delete` e uma identidade de proprietário ou administrador. Solicitações existentes que usem o ID do modelo deixarão de ser resolvidas.
