---

- `endpoints`: os IDs canônicos dos endpoints expostos atualmente pela API
- `data`: registros de endpoints com `public_path`, `collection`, `model_count` e `provider_count`
- `sample_models`: até 10 IDs recentes de modelos visíveis no catálogo público

Use [Listar recursos dos endpoints do modelo](./model-endpoints.mdx) quando precisar de detalhes de um modelo por provedor e parâmetro.
