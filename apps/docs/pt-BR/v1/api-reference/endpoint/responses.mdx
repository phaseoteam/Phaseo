## Ferramentas do servidor

`/v1/responses` aceita ferramentas de função comuns e estas ferramentas de servidor gerenciadas pelo Gateway:

- `gateway:datetime`
- `phaseo:web_search`
- `phaseo:web_fetch`
- `phaseo:advisor`
- `phaseo:image_generation`
- `phaseo:apply_patch`

### Exemplo de data e hora

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "stream": false,
    "input": [
      { "role": "user", "content": "Give me the current datetime in Asia/Tokyo." }
    ],
    "tools": [
      {
        "type": "gateway:datetime",
        "parameters": { "timezone": "Asia/Tokyo" }
      }
    ],
    "tool_choice": "auto"
  }'
```

Quando uma ferramenta de servidor é usada, o uso inclui os contadores correspondentes de `usage.server_tool_use.*`.

- `gateway:datetime` -> `datetime_requests`
- `phaseo:web_search` -> `web_search_requests`, `web_search_results`, `web_search_extra_results`
- `phaseo:web_fetch` -> `web_fetch_requests`
- `phaseo:advisor` -> `advisor_requests`
- `phaseo:image_generation` -> `image_generation_requests`
- `phaseo:apply_patch` -> `apply_patch_requests`

## Nota sobre streaming

`stream: true` também é compatível. Para ferramentas de servidor gerenciadas pelo Gateway, a Phaseo pode materializar o turno de chamada à ferramenta upstream, continuar o ciclo e emitir novamente um stream sintético.

## Raciocínio em ciclos de ferramentas

A Phaseo envia as solicitações de Responses ao provedor com `store: false`, então o raciocínio de um modelo continua entre as etapas de um ciclo de ferramentas apenas pelos itens de saída `reasoning`.

Cada item `reasoning` tem `id`, `summary` e `content`. Quando o provedor retorna estado de raciocínio, o item também tem `encrypted_content`:

- Raciocínio criptografado da OpenAI, do Azure OpenAI e da xAI. A Phaseo o solicita com `include: ["reasoning.encrypted_content"]` para modelos de raciocínio.
- Assinaturas de thinking do Claude e thinking ocultado.
- Assinaturas de pensamento do Gemini, incluindo um item `reasoning` próprio logo antes da chamada de função a que uma assinatura pertence.

Respostas com streaming trazem os mesmos itens em `response.output_item.done` e `response.completed`.

Para continuar um ciclo de ferramentas, envie todos os itens de saída de volta em `input` sem alterações, incluindo os itens `reasoning`. `encrypted_content` é opaco e registra o provedor e o modelo que o geraram. A Phaseo o envia apenas para essa família de provedores e esse modelo, então um fallback para outro provedor o descarta em vez de falhar.
