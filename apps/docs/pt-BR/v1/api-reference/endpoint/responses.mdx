## Usar ferramentas de servidor

Adicione uma ferramenta `phaseo:` a `tools`, ao lado das suas próprias ferramentas de função, e o Phaseo a executa quando o modelo a chama. `/v1/responses` aceita todas as ferramentas de servidor, incluindo `phaseo:apply_patch`, que só este endpoint suporta; o guia [Ferramentas de servidor](../../guides/server-tools) lista todas elas.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": [
      { "role": "user", "content": "Give me the current datetime in Asia/Tokyo." }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["Asia/Tokyo"] } }
    ],
    "tool_choice": "auto"
  }'
```

Cada chamada de ferramenta de servidor é contabilizada em `usage.server_tool_use`:

| Ferramenta | Contadores |
| --- | --- |
| `phaseo:datetime` | `datetime_requests` |
| `phaseo:web_search` | `web_search_requests`, `web_search_results`, `web_search_extra_results` |
| `phaseo:web_fetch` | `web_fetch_requests` |
| `phaseo:advisor` | `advisor_requests` |
| `phaseo:subagent` | `subagent_requests` |
| `phaseo:fusion` | `fusion_requests` |
| `phaseo:search_models` | `search_models_requests` |
| `phaseo:image_generation` | `image_generation_requests` |
| `phaseo:apply_patch` | `apply_patch_requests` |

O tipo antigo `gateway:datetime` continua funcionando. Com `stream: true`, o Phaseo executa os turnos de ferramenta por conta própria e depois transmite a continuação da resposta para você como um único stream.

## Raciocínio em loops de ferramentas

Na OpenAI, no Azure OpenAI e na xAI, o Phaseo envia as solicitações do Responses ao upstream com `store: false`, então o raciocínio de um modelo continua entre os passos do loop de ferramentas somente por meio dos itens de saída `reasoning`.

Cada item `reasoning` tem `id`, `summary` e `content`. Quando o provedor retorna estado de raciocínio, o item também tem `encrypted_content`, que contém um destes:

- Raciocínio criptografado da OpenAI, do Azure OpenAI e da xAI. O Phaseo o solicita com `include: ["reasoning.encrypted_content"]` para modelos de raciocínio.
- Assinaturas de pensamento e pensamento redigido do Claude.
- Assinaturas de pensamento do Gemini, incluindo um item `reasoning` separado colocado logo antes da chamada de função a que a assinatura pertence.
- O nível de esforço em que uma resposta do Claude foi executada, no último item `reasoning` da saída, que não tem texto.

As respostas em streaming trazem os mesmos itens em `response.output_item.done` e `response.completed`.

<Warning>
Envie de volta em `input` todos os itens de saída sem alterações em todas as solicitações, não só em loops de ferramentas. Nunca descarte, edite nem reordene itens `reasoning`, com ou sem `encrypted_content`, incluindo itens sem texto.
</Warning>

`encrypted_content` é opaco e registra o provedor e o modelo que o produziram. O Phaseo o envia somente para essa família de provedor e esse modelo, de modo que um fallback para outro provedor o descarta em vez de falhar. Sem ele, o Claude perde o raciocínio entre os passos do loop de ferramentas, e uma mudança de `reasoning.effort` reinicia o cache de prompts do Claude; veja [Mudar o esforço de raciocínio no meio da conversa](../../guides/prompt-caching#change-reasoning-effort-mid-conversation).
