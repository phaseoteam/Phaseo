<Note>A administração de identidade exige uma identidade de proprietário ou administrador. A ativação de SSO ou SCIM e a criação de tokens de provisionamento exigem o complemento de identidade.</Note>

Só o proprietário do espaço de trabalho pode alterar o provisionamento SCIM ou criar e revogar os tokens dele. As solicitações SCIM só são aceitas com um token criado pelo proprietário atual do espaço de trabalho; se um administrador ou um proprietário anterior criou o seu, o proprietário precisa criar um novo.
