---
title: "Criar credencial do provedor"
sidebarTitle: "Criar credencial"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml POST /byok"
description: "Criptografar e armazenar uma credencial de provedor para o roteamento do espaço de trabalho."
---

<Warning>
O valor `key` é somente para gravação. O Phaseo o criptografa imediatamente e nunca o retorna nas respostas da API.
</Warning>

Use `routing_mode: "priority"` para testar a credencial antes da capacidade gerenciada ou `"fallback"` para testá-la depois. Configure `byokFallbackEnabled` nas configurações do espaço de trabalho para controlar se credenciais prioritárias com falha podem recorrer à capacidade gerenciada.
