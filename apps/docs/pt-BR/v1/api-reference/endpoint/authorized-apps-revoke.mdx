---
title: "Revogar um aplicativo autorizado"
sidebarTitle: "Revogar aplicativo"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml DELETE /me/authorized-apps/{id}"
description: "Revogue o acesso de um aplicativo para que seus tokens parem de funcionar."
---
<Note>Este endpoint exige um token de acesso OAuth com `oauth_clients:delete`. Revogar a autorização do próprio aplicativo que faz a chamada encerra a sessão dele.</Note>
