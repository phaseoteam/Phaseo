---
title: "Atualizar um modelo privado"
sidebarTitle: "Atualizar um modelo privado"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml PATCH /private-models/{id}"
description: "Atualize as configurações do endpoint ou rotacione a credencial que permite apenas escrita."
---

Requer `private_models:write` e uma identidade de proprietário ou administrador. Envie `slug` para renomear o modelo local ao espaço de trabalho; `model_id` não pode ser informado diretamente.
