<Note>Requer `keys:delete` em uma chave de gerenciamento ou token OAuth, ou um proprietário ou administrador do espaço de trabalho. Os workloads confiáveis estão em beta; espaços de trabalho sem o recurso recebem `404`.</Note>

Tokens correspondentes passam a ser recusados em até um minuto. Solicitações anteriores mantêm sua chave nos logs e no uso.

Veja [Workloads confiáveis](../../developers/trusted-workloads.mdx) para saber como as políticas funcionam e como gerenciá-las com Terraform.
