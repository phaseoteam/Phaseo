description: "Aprovar atomicamente uma solicitação de entrada pendente."
---
<Note>Este endpoint requer uma chave de API de gerenciamento com `workspaces:write`.</Note>

A aprovação valida o vencimento do convite e os usos restantes, aplica a função do convite e registra a decisão em uma única transação.
