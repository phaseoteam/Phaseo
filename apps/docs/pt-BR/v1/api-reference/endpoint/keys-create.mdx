<Note>
Este endpoint requer uma chave de API de gerenciamento. Chaves de API padrão do Gateway não são aceitas.
</Note>

A chave de API em texto simples é retornada uma única vez, durante a criação. Os campos de compatibilidade `limit`, `limit_reset` e `include_byok_in_limit` são aceitos; atualmente, o Phaseo trata `include_byok_in_limit` apenas para compatibilidade e sempre exclui BYOK do limite dessa chave.
