<Note>
Este endpoint requer uma chave de API de gerenciamento. Chaves de API padrão do Gateway não são aceitas.
</Note>

Retorna os metadados de uma chave de API no espaço de trabalho autenticado. O segmento de caminho `{id}` é o ID da chave. Um hash de chave salvo de uma resposta anterior ainda é aceito, mas as respostas não o incluem mais.
