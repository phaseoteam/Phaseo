---
title: "Remover rótulo da predefinição"
sidebarTitle: "Remover rótulo"
badge: "Beta"
openapi: "/pt-BR/openapi/v1/openapi.localized.yaml DELETE /presets/{id}/labels/{label}"
description: "Remove um rótulo de uma predefinição."
---
<Note>Este endpoint requer uma chave de API de gerenciamento com `presets:write` e uma identidade de usuário associada. Quem criou a predefinição pode alterar os rótulos, assim como proprietários e administradores do espaço de trabalho quando a predefinição é compartilhada.</Note>

Solicitações que ainda fixam o rótulo falham com `preset_version_not_found` até você adicioná-lo de novo.
