Encontre o modelo para o qual você está migrando, faça as mudanças no formato da solicitação que o guia descreve e execute de novo as suas avaliações antes de mover o tráfego. Estes guias tratam de uma troca de modelo na mesma plataforma; para trocar de gateway ou SDK, use os [guias de migração de plataforma](../migration-guides/index).

## Migre um modelo

1. Atualize o formato da solicitação conforme o guia do modelo antes de testar a qualidade da saída.
2. Execute de novo as avaliações de prompt e de esquema com prompts parecidos com os de produção.
3. Mova o tráfego aos poucos, com o modelo anterior como fallback em `models` e uma regra clara de rollback.
