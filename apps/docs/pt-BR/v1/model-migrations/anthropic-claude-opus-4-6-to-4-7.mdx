Troque o modelo para `anthropic/claude-opus-4.7`, remova os parâmetros de amostragem e os orçamentos de pensamento e defina a profundidade com um nível de esforço. Solicitações que ainda trazem campos do Opus 4.6 não falham no Phaseo; o gateway as reescreve como mostrado abaixo.

| Solicitação do Opus 4.6 | O que o Phaseo envia ao Opus 4.7 |
| --- | --- |
| `temperature`, `top_p`, `top_k` | Omitidos. A Anthropic retornaria `400` para valores não padrão. |
| `thinking: {"type": "enabled", "budget_tokens": …}` | `thinking: {"type": "adaptive", "display": "summarized"}`; o orçamento não é repassado. |
| `reasoning.effort` | `output_config.effort`, incluindo `xhigh`. |
| `reasoning.effort: "none"` ou `reasoning.enabled: false` | `thinking: {"type": "disabled"}`. |
| Nenhuma configuração de raciocínio | Nenhum campo `thinking`, então o Opus 4.7 não pensa. |

O Opus 4.7 também oculta o conteúdo do pensamento, a menos que você o solicite; o Phaseo pede a exibição resumida sempre que ativa o pensamento. O tokenizador dele pode gerar mais tokens que o do Opus 4.6 para o mesmo texto.

## Atualize a solicitação

1. Defina o ID do modelo como `anthropic/claude-opus-4.7`.
2. Remova `temperature`, `top_p` e `top_k` e ajuste o comportamento com instruções.
3. Substitua os orçamentos de pensamento por pensamento adaptativo e um nível de esforço:

```json
{
  "model": "anthropic/claude-opus-4.7",
  "messages": [{ "role": "user", "content": "Refactor this module and explain the risks." }],
  "reasoning": { "effort": "xhigh" }
}
```

Comece em `high` e use `xhigh` nas rotas de código e de agentes mais difíceis. Em `/v1/messages`, envie `thinking: {"type": "adaptive"}` com `output_config.effort` no lugar.

4. Como o tokenizador mudou, revise `max_tokens` e `max_output_tokens`, os orçamentos de timeout e os alertas de custo.

## O que testar

- taxa de aprovação do esquema nos seus prompts de produção;
- fluxos de ferramentas de longa duração: número de chamadas de ferramentas, taxa de conclusão e latência;
- qualidade em `high` em comparação com `xhigh`;
- custo de tokens nas classes de prompt com maior volume.

## Faça o rollout

1. Implante as mudanças no formato da solicitação antes de mover o tráfego.
2. Rode o Opus 4.7 em modo sombra no seu conjunto de avaliação de produção.
3. Faça um canário com o Opus 4.6 como fallback em `models`.
4. Promova quando as mudanças de qualidade, latência e custo estiverem dentro da meta.
