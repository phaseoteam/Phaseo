Troque o ID do modelo e execute de novo o seu conjunto de validação; os formatos de solicitação e de resposta continuam os mesmos. O único controle novo é a profundidade com que a variante multiagente trabalha.

| Modelo | ID do modelo no Phaseo | Controle de raciocínio |
| --- | --- | --- |
| Grok 4.20 | `spacex-ai/grok-4.20` | `reasoning.enabled`: ativado ou desativado |
| Grok 4.20 Multi-Agent (beta) | `spacex-ai/grok-4.20-multi-agent-beta` | `reasoning.effort`: `low`, `medium` ou `high` |

## Ative ou desative o raciocínio no Grok 4.20

Defina `reasoning.enabled: true` para usar a versão com raciocínio do modelo. Sem ele, ou com `false`, o Phaseo chama a versão sem raciocínio.

```json
{
  "model": "spacex-ai/grok-4.20",
  "input": "Explain this architecture",
  "reasoning": { "enabled": true }
}
```

## Defina a profundidade no modelo multiagente

Controle a profundidade com `reasoning.effort`. As solicitações pelo gateway não aceitam o `agent_count` da xAI; segundo a xAI, `low` e `medium` executam 4 agentes e `high` executa uma configuração maior.

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": { "effort": "medium" }
}
```
