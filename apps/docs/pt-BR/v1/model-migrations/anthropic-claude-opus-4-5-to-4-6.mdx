Troque o modelo para `anthropic/claude-opus-4.6`, remova os prefills do assistente e passe a saída estruturada para `output_config.format`. São mudanças no formato da solicitação: padrões antigos do Opus 4.5 falham com `400` se forem mantidos.

| | Claude Opus 4.5 | Claude Opus 4.6 |
| --- | --- | --- |
| ID do modelo no Phaseo | `anthropic/claude-opus-4.5` | `anthropic/claude-opus-4.6` |
| Janela de contexto | 200K tokens | 1M tokens |
| Saída máxima | 64K tokens | 128K tokens |
| Prefill do assistente | Com suporte | Retorna `400` |
| Saída estruturada | `output_format` | `output_config.format` |
| Pensamento | `budget_tokens` | Adaptativo, orientado por `output_config.effort` |
| Beta `interleaved-thinking-2025-05-14` | Necessário | Não é necessário |

## Atualize a solicitação

**1. Remova os prefills do assistente.** Se você preenche previamente o turno do assistente para forçar JSON ou um prefixo, o Opus 4.6 retorna `400`. Use instruções de sistema mais claras, exemplos no prompt ou saída estruturada no lugar.

**2. Mova a saída estruturada** de `output_format` para `output_config.format` e execute de novo os testes de esquema e de parser:

```json
{
  "model": "anthropic/claude-opus-4.6",
  "max_tokens": 1024,
  "messages": [{ "role": "user", "content": "Extract the invoice fields." }],
  "output_config": {
    "format": { "type": "json_schema", "schema": { "type": "object", "properties": { "total": { "type": "number" } } } }
  }
}
```

Em `/v1/chat/completions` e `/v1/responses`, continue usando `response_format`.

**3. Mude o pensamento para adaptativo.** O Opus 4.6 só pensa se a solicitação pedir. No Phaseo, `reasoning.effort` ou `reasoning.enabled: true` sem orçamento de tokens ativa o pensamento adaptativo, e o esforço vira `output_config.effort`. O Opus 4.6 aceita todos os níveis de esforço, exceto `xhigh`, que o Phaseo envia como `max`. Enquanto o pensamento está ativo, o Phaseo omite `temperature` e `top_k`, e `top_p` abaixo de 0.95.

**4. Remova cabeçalhos beta antigos** de wrappers do SDK, middleware e predefinições. O Phaseo não repassa cabeçalhos `anthropic-beta`, então eles não têm mais efeito.

## O que testar

- **Prompts:** prompts longos de código e refatoração, fluxos de pesquisa e de documentos em várias etapas, prompts que dependiam de prefills e tarefas de contexto longo, se você for usar a janela de 1M.
- **Contratos e ferramentas:** taxa de aprovação do esquema depois de migrar para `output_config.format`, argumentos de chamadas de ferramentas em tarefas de agentes com várias etapas, novas tentativas quando o modelo recusa ou reformata a saída, e fluxos de revisão de código e depuração.
- **Operações:** latência mediana e p95 com o pensamento ativo, uso de tokens em execuções mais longas, taxa de timeout em tarefas com contexto grande e taxa de sucesso em relação ao Opus 4.5 no seu conjunto de avaliação.

## Faça o rollout

1. Remova os prefills e migre a saída estruturada antes de mover qualquer tráfego.
2. Rode o Opus 4.6 em modo sombra nos prompts de produção que importam para você.
3. Faça um canário com o Opus 4.5 como fallback em `models`.
4. Promova quando a taxa de aprovação do esquema, a latência e a conclusão de tarefas se mantiverem.
