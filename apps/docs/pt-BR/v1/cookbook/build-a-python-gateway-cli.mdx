Use esta página quando sua primeira integração real com a Phaseo estiver em Python e você quiser um ponto de partida prático para uma CLI, um worker ou um serviço de back-end.

**Objetivo:** Executar as rotas de controle e geração da Phaseo em um pequeno aplicativo de linha de comando em Python.

**Resultado:** Uma CLI com poucas dependências que você pode adaptar para um worker, script ou integração de back-end.

## Projeto de exemplo

- GitHub: [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart)
- Caminho local no repositório: `examples/gateway-python-quickstart`

## O que este aplicativo faz

- oferece rotas de controle como:
  - `GET /v1/health`
  - `GET /v1/models`
  - `GET /v1/providers`
- oferece rotas de geração como:
  - `POST /v1/responses`
  - `POST /v1/chat/completions`
  - `POST /v1/embeddings`
  - e vários endpoints adicionais

## Por que este exemplo é útil

Ele oferece:

- uma referência em Python sem dependências de terceiros
- payloads de requisição e tratamento de resposta explícitos
- um padrão prático para workers, scripts e ferramentas internas

## Pré-requisitos

- Python 3
- uma chave de API da Phaseo

## Execute o exemplo

```bash
cd examples/gateway-python-quickstart
cp .env.example .env.local
```

Defina:

- `PHASEO_API_KEY`

Depois, teste:

```bash
python quickstart.py smoke
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

## Confira o resultado

- O modo de teste rápido confirma que a API está acessível.
- O comando Responses imprime `integration_ok`.
- `--help` lista os comandos disponíveis sem enviar uma requisição.
- Erros de autenticação e da API são exibidos claramente no terminal.

## O que observar no código

- como as variáveis de ambiente são carregadas
- como a CLI encaminha os comandos
- como cada payload de requisição é montado
- como as rotas assíncronas de vídeo e música são tratadas separadamente das rotas de texto com resposta única

## Adapte o exemplo

- remova os endpoints que seu serviço não precisa
- mantenha um helper de requisição compartilhado em vez de duplicar os cabeçalhos
- migre para o SDK de Python depois, se quiser um cliente de nível mais alto
