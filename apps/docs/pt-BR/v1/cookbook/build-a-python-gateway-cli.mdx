Execute uma CLI em Python, só com a biblioteca padrão, que chama os endpoints do Phaseo um comando por vez. No fim, você tem `python quickstart.py <command>` funcionando para health, models, Responses e Chat Completions, além de comandos para embeddings, moderação, imagens, OCR, vídeo e música que você pode copiar para um worker ou backend.

A CLI é ilustrativa: ela serve de referência para o formato das solicitações, não é uma ferramenta empacotada. Vários IDs de modelo padrão dos comandos de mídia não são mais atendidos, então passe `--model` nesses casos (veja [Escolha modelos para os comandos de mídia](#pick-models-for-the-media-commands)).

Para que um agente de programação crie uma CLI parecida do zero, cole este prompt:

## O que a CLI faz

O exemplo é [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart): um único arquivo, `quickstart.py`, que usa apenas `urllib`, `json` e `argparse`.

| Comando | Chamadas |
| --- | --- |
| `smoke` | `GET /v1/health`, `GET /v1/models`, `GET /v1/providers` e um `POST /v1/responses` |
| `health`, `models`, `providers` | A rota `GET` correspondente |
| `responses --prompt` | `POST /v1/responses` |
| `chat --prompt` | `POST /v1/chat/completions` |
| `embeddings --text` | `POST /v1/embeddings` |
| `moderations --text` | `POST /v1/moderations` |
| `image --prompt` | `POST /v1/images/generations` |
| `ocr --image-url` | `POST /v1/ocr` |
| `video-create`, `video-status`, `video-cancel`, `video-download-url` | `POST /v1/videos`, `GET /v1/videos/{video_id}`, `POST /v1/videos/{video_id}/cancel`, `POST /v1/videos/{video_id}/download_url` |
| `music-create`, `music-status` | `POST /v1/music/generate`, `GET /v1/music/generate/{music_id}` |

Cada solicitação tenta de novo duas vezes em caso de `429`, `5xx` e erros de rede, com esperas de 1 s e depois 2 s, e expira após 45 segundos. Cada comando termina com `1` quando a chamada não retorna `2xx`, então você pode usá-lo em scripts.

## Execute

Você precisa do Python 3 e de uma chave de API do Phaseo.

<Steps>
<Step title="Crie o .env.local">

O script lê o `.env.local` da pasta em que você o executa. O exemplo não tem `.env.example`, então crie o arquivo:

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# Optional
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My Python CLI
PHASEO_HTTP_REFERER=https://myapp.example
```

As variáveis já definidas no seu shell têm prioridade sobre o arquivo. Sem `PHASEO_MODEL`, os comandos de texto usam `openai/gpt-5.6-sol`.

</Step>
<Step title="Execute a verificação smoke">

```bash
cd examples/gateway-python-quickstart
python quickstart.py smoke
```

`smoke` também envia uma solicitação curta para Responses, então consome alguns créditos.

</Step>
<Step title="Envie uma solicitação">

```bash
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

</Step>
</Steps>

## Confira se funcionou

- `smoke` imprime `HTTP 200` em todos os blocos e termina com `0`.
- A saída do comando `responses` contém `integration_ok`.
- `--help` lista os comandos sem fazer nenhuma solicitação.
- Sem uma chave, o script imprime `Missing PHASEO_API_KEY` e termina com `1`.
- As solicitações aparecem em **Configurações → Uso → Registros**.

## Escolha modelos para os comandos de mídia

Estes padrões em `quickstart.py` foram aposentados ou não têm provedor ativo. Passe um modelo atual com `--model` e escolha um na [página de modelos](https://phaseo.app/models) ou com `python quickstart.py models`:

| Comando | Padrão no exemplo | Status |
| --- | --- | --- |
| `moderations` | `openai/omni-moderation-latest` | Não é um ID do catálogo; use `openai/omni-moderation` |
| `ocr` | `mistral/mistral-ocr` | Aposentado; tente `mistral/ocr-4.1` |
| `video-create` | `openai/sora-2` | Aposentado |
| `music-create` | `suno/suno-v4` | Sem provedor ativo |

Os padrões de `embeddings` (`google/gemini-embedding-2`) e `image` (`openai/gpt-image-2`) são atendidos. Os trabalhos de vídeo e música são assíncronos: guarde o ID retornado e consulte o comando de status; [Vídeo assíncrono e batch](../guides/async-video-and-batch) explica o ciclo de vida dos trabalhos.

Reduza o arquivo aos comandos de que o seu serviço precisa, mantenha o único helper compartilhado `gateway_request()` e passe para o [SDK de Python](../sdk-reference/client/overview) quando quiser solicitações tipadas.
