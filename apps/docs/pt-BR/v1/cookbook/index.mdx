Escolha uma receita pelo que você quer criar. Cada uma começa pelo resultado final e depois traz os passos, o código completo, como executá-lo e como conferir se funcionou. Cada receita diz se o código está pronto para produção ou se é um ponto de partida que você precisa terminar.

Todos os exemplos usam `https://api.phaseo.app/v1` e leem a sua chave de `PHASEO_API_KEY`.

| [Resumo de pesquisa](./agent-sdk-research-brief) | TypeScript | Busca na web e um resumo em JSON estrito |
