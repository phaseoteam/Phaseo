Execute um agente em Go que responde a uma pergunta operacional chamando uma ferramenta local de status, dentro de um único serviço e sem um sistema de jobs. Ao final, você terá um único `main.go` que imprime uma resposta curta sobre a latência atual dos provedores.

A ferramenta retorna dados de exemplo fixos, então o programa é ilustrativo; substitua-a pela sua própria chamada de status ou de métricas. Ele serve para um serviço em Go cujo contexto já existe como chamadas locais ou internas.

## Crie o agente

<Steps>
<Step title="Instale">

```bash
go mod init ops-runbook
go get github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go@latest
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

O módulo principal `sdk-go/v4` vem junto. Veja [Instalação do Agent SDK de Go](../sdk-reference/agent/installation) para os requisitos.

</Step>
<Step title="Escreva o agente">

```go main.go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  statusTool := phaseoagent.DefineTool(phaseoagent.Tool{
    ID:          "read-status",
    Description: "Read the current service status page summary.",
    Parameters: map[string]any{
      "type":                 "object",
      "properties":           map[string]any{},
      "additionalProperties": false,
    },
    Execute: func(input any, ctx phaseoagent.RuntimeContext) (any, error) {
      return map[string]any{
        "status":  "degraded",
        "summary": "Latency is elevated on one provider route.",
      }, nil
    },
  })

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "ops-runbook-agent",
    Model:        "openai/gpt-6-astra",
    Instructions: "Use tools when helpful and answer briefly.",
    Tools:        []phaseoagent.Tool{statusTool},
    MaxSteps:     4,
  })

  // Lê PHASEO_API_KEY (e PHASEO_BASE_URL, se definido).
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "What is happening with provider latency right now?",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Run.Status)
  fmt.Println(result.Output)
}
```

</Step>
<Step title="Execute">

```bash
go run .
```

</Step>
</Steps>

## Verifique se funcionou

- O programa imprime `completed` e depois uma resposta que menciona latência degradada em uma rota de provedor.
- Em **Configurações → Uso → Registros**, o primeiro turno do modelo mostra uma chamada à ferramenta `read-status`.
- Sem `PHASEO_API_KEY`, `CreateGatewayAgentClient` retorna `PHASEO_API_KEY is required`.

## Antes da produção

`MaxSteps` tem padrão `8` no SDK de Go; defina o menor número que conclua o trabalho. Quando uma ferramenta recebe argumentos, dê a ela um esquema `Parameters` e um validador `InputSchema` que retorne erro para qualquer coisa inesperada, porque os argumentos vêm do modelo. Mantenha as ferramentas somente leitura, a menos que uma pessoa aprove a chamada (`RequireApproval: true`). A [referência do Agent SDK de Go](../sdk-reference/agent/usage) cobre aprovações, estado e streaming, e [fundamentação com web fetch](./tool-grounding-with-web-fetch) mostra como ler uma página conhecida em vez de usar uma ferramenta local.
