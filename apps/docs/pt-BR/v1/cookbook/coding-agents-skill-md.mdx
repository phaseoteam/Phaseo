Adicione um `SKILL.md` ao seu repositório para que os agentes de programação chamem o Phaseo do jeito que o seu projeto espera: a mesma URL base, a mesma variável de chave, o mesmo endpoint, os modelos aprovados e o mesmo registro em log. No fim, você tem as skills públicas do Phaseo instaladas, uma skill do projeto por cima delas e um módulo de cliente compartilhado para o qual a skill aponta.

A skill e o módulo abaixo estão prontos para produção depois que você substituir os IDs de modelo e os nomes das predefinições pelos seus.

<Steps>
<Step title="Instale as skills públicas do Phaseo">

<Visibility for="humans">
As skills públicas cobrem o Gateway, os SDKs, as predefinições, o roteamento e as migrações. Instale-as a partir de [`phaseo.app/docs`](https://phaseo.app/docs/.well-known/agent-skills/index.json):
</Visibility>

<Visibility for="agents">
Instale as skills públicas do Phaseo a partir de [`phaseo.app/docs`](https://phaseo.app/docs/.well-known/agent-skills/index.json) antes de escrever instruções locais do projeto:
</Visibility>

```bash
npx skills add https://phaseo.app/docs --agent codex --skill '*'
```

Troque `--agent` pelo agente que a sua equipe usa. Deixe no seu próprio `SKILL.md` apenas as regras específicas do projeto.

</Step>
<Step title="Instale o SDK">

<CodeGroup>
```bash npm
npm install @phaseo/sdk
```

```bash pnpm
pnpm add @phaseo/sdk
```

```bash yarn
yarn add @phaseo/sdk
```

```bash bun
bun add @phaseo/sdk
```

```bash Python
pip install phaseo
```
</CodeGroup>

</Step>
<Step title="Adicione um cliente compartilhado">

Os agentes reutilizam um helper pequeno e óbvio com mais confiabilidade do que um wrapper grande. Coloque o cliente em um único módulo e importe-o em todos os lugares:

```ts src/lib/phaseo.ts
import Phaseo from "@phaseo/sdk";

export const gateway = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY!,
});
```

Mantenha um único caminho de chamada para cada área que você usa, como geração de texto, embeddings, geração de imagens ou vídeo assíncrono.

</Step>
<Step title="Escreva a skill do projeto">

Crie o `SKILL.md` na raiz do repositório ou na pasta de skills que o seu agente lê (por exemplo, `.agents/skills/phaseo-project/SKILL.md`). O agente lê o `name` e a `description` do frontmatter para decidir quando carregar a skill:

```md SKILL.md
---
name: phaseo-project
description: "How this repository calls Phaseo Gateway: client module, endpoint, approved models and presets, logging and async jobs. Use when adding or changing any Phaseo call in this repo."
---

# Phaseo in this repository

- Import the client from `src/lib/phaseo.ts`. Never create another one.
- The base URL is `https://api.phaseo.app/v1`. The key is in `PHASEO_API_KEY`; never hard-code it or send it to the browser.
- Use the Responses API (`POST /v1/responses`) for new text features.
- Approved models: `openai/gpt-6-astra` for drafts, `anthropic/claude-sonnet-5.5` for reviews. Ask before adding another.
- Prefer the `@support-triage` preset for support features; pass it as `model`.
- Log the response `id` and `model` on every call, and `generation_id` from error bodies.
- For async video jobs, store the returned ID and poll status until it is terminal.
- Validate any model-generated tool arguments before acting on them.
```

</Step>
</Steps>

## Confira se funcionou

Peça ao seu agente para adicionar um pequeno recurso com o Phaseo, como "resumir um ticket com o Phaseo". A alteração deve importar `src/lib/phaseo.ts`, ler `PHASEO_API_KEY`, usar um modelo ou uma predefinição aprovados e registrar o ID da resposta. Se isso não acontecer, provavelmente a `description` da skill não corresponde ao pedido: use as palavras que a sua equipe usa para a tarefa.

## O que colocar na skill

Responda às perguntas que mais custam tempo a um agente, e a nada mais:

| Pergunta | Exemplo de resposta |
| --- | --- |
| Qual família de endpoints? | Responses para texto, Embeddings para busca |
| Onde ficam as credenciais? | `PHASEO_API_KEY`, só no servidor |
| Quais IDs de modelo ou predefinições estão aprovados? | Uma lista curta, no formato `org/model` |
| O que é registrado em log? | O `id` da resposta, o `model` e o `generation_id` nos erros |
| Como os trabalhos assíncronos são acompanhados? | Guarde o ID e consulte até chegar a um estado final |

[Codex](../guides/integrations/codex), o [Vercel AI SDK](../guides/integrations/ai-sdk) e [Exemplos](../guides/examples) mostram as mesmas convenções em cada ferramenta.
