Execute um agente em C# que carrega um ticket de suporte com uma ferramenta local e escreve um resumo curto da triagem, dentro de um único serviço ASP.NET ou worker. Ao final, você terá um app de console que imprime a próxima ação para o ticket `T-1042`.

A ferramenta retorna dados de exemplo fixos, então o programa é ilustrativo; substitua-a pelo seu armazenamento de tickets. Ele serve para um serviço que já sabe buscar o estado interno dos tickets e quer um loop restrito antes de adicionar filas ou aprovações.

## Crie o agente

<Steps>
<Step title="Instale">

```bash
dotnet new console -n TicketTriage
cd TicketTriage
dotnet add package Phaseo.AgentSdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

`Phaseo.AgentSdk` instala o `Phaseo.Sdk` junto e precisa do .NET 8 ou mais recente. Veja [Instalação do Agent SDK de C#](../sdk-reference/agent/installation).

</Step>
<Step title="Escreva o agente">

```csharp Program.cs
using System.Text.Json;
using System.Text.RegularExpressions;
using PhaseoAgentSdk;

var loadTicket = AgentSdk.DefineTool(new Tool(
    Id: "load-ticket",
    Description: "Load one support ticket by id.",
    Parameters: new Dictionary<string, object?>
    {
        ["type"] = "object",
        ["properties"] = new Dictionary<string, object?>
        {
            ["ticketId"] = new Dictionary<string, object?> { ["type"] = "string", ["pattern"] = "^T-\\d+$" },
        },
        ["required"] = new[] { "ticketId" },
        ["additionalProperties"] = false,
    },
    Execute: (input, ctx) => Task.FromResult<object?>(new Dictionary<string, object?>
    {
        ["ticketId"] = ((JsonElement)input!).GetProperty("ticketId").GetString(),
        ["severity"] = "medium",
        ["summary"] = "Customer cannot find preset routing settings.",
    })
))
{
    // Os argumentos vêm do modelo: rejeite qualquer coisa que não seja um ID de ticket bem formado.
    InputSchema = input =>
    {
        if (input is JsonElement json
            && json.TryGetProperty("ticketId", out var id)
            && id.ValueKind == JsonValueKind.String
            && Regex.IsMatch(id.GetString()!, @"^T-\d+$"))
        {
            return input;
        }
        throw new ArgumentException("ticketId must look like T-1042");
    },
};

var agent = AgentSdk.CreateAgent(new AgentDefinition
{
    Id = "ticket-triage-agent",
    Model = "openai/gpt-6-astra",
    Instructions = "Use tools when helpful and answer with a short triage summary.",
    Tools = new[] { loadTicket },
    MaxSteps = 4,
});

// Lê PHASEO_API_KEY do ambiente.
var result = await agent.Run(new RunOptions
{
    Input = "Review ticket T-1042 and summarize the next action.",
    Client = AgentSdk.CreateGatewayAgentClient(),
});

Console.WriteLine(result.Run.Status);
Console.WriteLine(result.Output);
```

</Step>
<Step title="Execute">

```bash
dotnet run
```

</Step>
</Steps>

## Verifique se funcionou

- O app imprime `completed` e depois um resumo que menciona as configurações de roteamento de predefinições.
- Em **Configurações → Uso → Registros**, o primeiro turno do modelo mostra uma chamada `load-ticket` com `{"ticketId": "T-1042"}`.
- Sem `PHASEO_API_KEY`, `CreateGatewayAgentClient` lança `PHASEO_API_KEY is required.`

## Antes da produção

Mantenha `MaxSteps` baixo (o padrão é `12`), mantenha a ferramenta somente leitura e defina `RequireApproval = true` em qualquer ferramenta que altere um ticket, para que a execução pause para uma pessoa. Para um fluxo de triagem maior com uma predefinição, JSON estrito e pausas para revisão, veja [triagem de suporte](./agent-sdk-support-triage). A [referência do Agent SDK de C#](../sdk-reference/agent/usage) cobre estado, aprovação e streaming.
