Crie um agente em TypeScript que pesquisa na web pela Phaseo antes de responder e retorna um resumo de pesquisa como JSON estrito, com as fontes. Ao final, você terá um único script que imprime um objeto `{ topic, summary, sources }` validado para qualquer tema que você informar.

O script está pronto para produção em pesquisas de uma única chamada. Os resultados de busca são conteúdo da web não confiável: a verificação de esquema abaixo barra saídas malformadas, mas revise as fontes antes de agir com base nelas. Uma versão empacotada está em `packages/sdk/agent-sdk-ts/examples/research-brief-agent.ts`.

<Step title="Escreva o agente">

```ts research-agent.ts
import { z } from "zod";
import { createAgent, createGatewayAgentClient } from "@phaseo/agent-sdk";

// Pequeno o bastante para ler em uma linha de log.
const ResearchBrief = z
  .object({
    topic: z.string(),
    summary: z.string().min(1),
    sources: z.array(z.object({ title: z.string(), url: z.string().url() }).strict()).min(1),
  })
  .strict();
type ResearchBrief = z.infer<typeof ResearchBrief>;

const researchBriefAgent = createAgent<string, ResearchBrief>({
  id: "research-brief-agent",
  model: "openai/gpt-6-astra",
  instructions:
    "Research the user's topic with web search and return a concise JSON brief with cited sources.",
  maxSteps: 4,
  parseOutput: (text) => JSON.parse(text),
  outputSchema: ResearchBrief,
});

const client = createGatewayAgentClient({
  clientOptions: { apiKey: process.env.PHASEO_API_KEY! },
  // O JSON Schema que o Gateway pede ao modelo.
  responseFormat: {
    type: "json_schema",
    name: "research_brief",
    schema: {
      type: "object",
      properties: {
        topic: { type: "string" },
        summary: { type: "string" },
        sources: {
          type: "array",
          items: {
            type: "object",
            properties: { title: { type: "string" }, url: { type: "string" } },
            required: ["title", "url"],
            additionalProperties: false,
          },
          minItems: 1,
        },
      },
      required: ["topic", "summary", "sources"],
      additionalProperties: false,
    },
  },
  // Repara JSON quase válido.
  plugins: [{ id: "response-healing" }],
  // A Phaseo executa a busca; o modelo escreve as consultas.
  gatewayTools: [{ type: "phaseo:web_search", parameters: { max_results: 5 } }],
  // Sempre pesquisa antes de responder.
  toolChoice: "phaseo:web_search",
  webSearchOptions: { search_context_size: "high" },
});

const result = await researchBriefAgent.run({
  input: "Summarize the latest browser automation support patterns for coding agents.",
  client,
  onEvent(event) {
    console.log(event.type, event.runId);
  },
});

console.log(result.output);
```

| Opção do cliente | O que faz |
| --- | --- |
| `responseFormat` | Mantém o esquema de saída explícito |
| `plugins` | [Reparo de respostas](./response-healing-for-structured-json) para JSON quase válido |
| `gatewayTools` | Adiciona `phaseo:web_search`; o [guia de busca na web](../guides/server-tools/web-search) lista os parâmetros |
| `toolChoice` | Força a busca em um fluxo que sempre precisa se fundamentar |
| `webSearchOptions` | Configurações de busca para mecanismos que dimensionam seus resultados |

## Verifique se funcionou

O script imprime um resumo com pelo menos uma URL de fonte. Depois, abra a solicitação em **Configurações → Uso → Registros** e confira:

- **Web search observability** mostra as buscas gerenciadas, os resultados e as citações.
- O registro de plugins mostra `response-healing` como `applied` apenas quando o JSON precisou de reparo.
- A resposta correspondeu ao esquema; uma divergência teria feito a execução falhar com um `AgentSchemaValidationError`.

[Depurar solicitações de busca na web](./web-search-debugging) cobre os casos em que nenhuma busca foi executada.

## Quando usar outra abordagem

Este padrão serve para pesquisas de uma única chamada em que o modelo deve se fundamentar e quem chama quer JSON tipado. Use [`phaseo:web_fetch`](./tool-grounding-with-web-fetch) quando você já conhece as URLs, um [agente com ferramentas locais](./agent-sdk-durable-loop) quando o trabalho depende mais dos seus próprios dados do que da web, e saída em texto simples quando o contrato é solto o bastante para que um esquema dê mais trabalho do que economiza.
