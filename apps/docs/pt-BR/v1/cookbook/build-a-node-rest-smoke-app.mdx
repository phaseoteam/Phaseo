Use esta página se quiser a menor integração possível com Node e quiser ver cada solicitação HTTP com clareza.

**Objetivo:** Verifique a disponibilidade da Phaseo, a descoberta de modelos e uma solicitação de geração usando HTTP direto.

**Resultado:** Um script com poucas dependências que você pode manter como smoke test de implantação ou integração.

## Projeto de exemplo

- GitHub: [examples/gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart)
- Caminho local no repositório: `examples/gateway-node-quickstart`

## O que este aplicativo faz

- chama `GET /v1/health`
- chama `GET /v1/models`
- testa rotas de geração como `POST /v1/responses`
- oferece uma referência de HTTP direto para smoke tests, scripts e verificações de backend

## Quando este exemplo é indicado

Comece por aqui quando:

- quiser depurar chamadas diretas à API
- ainda não quiser abstrações de SDK
- estiver criando um script, worker ou CLI, e não uma interface web

## Pré-requisitos

- Node.js com suporte integrado a `fetch` support
- uma chave de API da Phaseo

## Execute o exemplo

```bash
cd examples/gateway-node-quickstart
cp .env.example .env.local
```

Defina:

- `PHASEO_API_KEY`

Depois execute um destes comandos:

```bash
npm run smoke
```

ou:

```bash
npm run start
```

## Verifique o resultado

- O modo de smoke test confirma que a API está acessível.
- A descoberta de modelos retorna pelo menos um modelo.
- A execução completa exibe uma resposta de geração bem-sucedida.
- Falhas de autenticação e respostas diferentes de 200 geram erros claros no terminal.

## O que observar no código

- como o script carrega `.env.local`
- como o cabeçalho de autorização é anexado
- como cada solicitação é construída explicitamente
- como respostas diferentes de 200 são exibidas em vez de ignoradas

## Como adaptar o exemplo

- reduza o script às rotas que seu serviço realmente precisa
- mova o código compartilhado das solicitações para um helper se vários scripts forem usá-lo
- migre para o SDK de TypeScript depois se o caminho HTTP direto ficar repetitivo
