Use este guia para colocar sua primeira integração com a Phaseo em funcionamento sem escolher um modelo pago ainda.

Em vez de escolher um modelo gratuito por conta própria, envie as solicitações para `phaseo/free`. A Phaseo selecionará um modelo gratuito disponível que aceite a solicitação.
## Exemplo de solicitação
<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```

```typescript TypeScript SDK
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

  model: "phaseo/free",
  input: "Summarize why provider-aware free routing helps prototypes.",
  temperature: 0.2,

console.log(response.output_text);
```

```go Go SDK

  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"

      "role": "user",

          "text": "Summarize why provider-aware free routing helps prototypes.",

    panic(err)
  }

}
```

## O que acontece nos bastidores

1. Sua solicitação vai para o alias compartilhado `phaseo/free`.
2. A Phaseo verifica quais modelos gratuitos podem atendê-la.
3. Um modelo gratuito disponível é selecionado e usado para gerar a resposta.
4. Os detalhes da solicitação ainda mostram o modelo exato executado para que você possa inspecioná-lo ou depurá-lo depois.

## Depois da primeira solicitação

- Em **Gateway -> Uso**, abra os detalhes da solicitação e confirme qual modelo foi usado.
- Se uma política do workspace bloquear a solicitação, consulte os detalhes para identificar a configuração que a interrompeu.
- Se nenhum modelo gratuito oferecer o recurso necessário, troque `phaseo/free` por um modelo pago específico em vez de repetir a mesma solicitação.

## Observações para produção

- Use `phaseo/free` em protótipos, demonstrações e tráfego de baixo risco.
- Se precisar de latência, estilo de saída ou escolha de provedor previsíveis, migre para um modelo específico quando souber qual funciona melhor.
- Se precisar de um comportamento de prompt estável entre serviços, combine este guia com [Presets](../guides/presets.mdx).
