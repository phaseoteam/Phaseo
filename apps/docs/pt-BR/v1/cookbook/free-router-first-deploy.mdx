Envie `"model": "phaseo/free"` e o Phaseo executa a sua solicitação em um modelo gratuito disponível que a suporte, sem gastar créditos. No fim, você tem uma solicitação funcionando na linguagem que preferir e sabe qual modelo respondeu.

Este é um formato de solicitação pronto para produção em protótipos, demonstrações e tráfego de baixo risco. Os modelos gratuitos não garantem latência, estilo de saída nem um provedor fixo.

## Envie a solicitação

<Steps>
<Step title="Defina a sua chave">

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="Envie uma solicitação">

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```

```go Go
package main

import (
  "context"
  "fmt"
  "os"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v4"
)

func main() {
  client := phaseo.New(os.Getenv("PHASEO_API_KEY"), "https://api.phaseo.app/v1")

  temperature := 0.2
  response, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
    Model:       "phaseo/free",
    Input:       "Summarize why provider-aware free routing helps prototypes.",
    Temperature: &temperature,
  })
  if err != nil {
    panic(err)
  }

  fmt.Printf("%+v\n", response)
}
```

## Como um modelo gratuito é escolhido

1. A sua solicitação vai para o alias compartilhado `phaseo/free`.
2. O Phaseo mantém os modelos gratuitos que conseguem atender a essa solicitação (endpoint, parâmetros, ferramentas).
3. Ele envia a solicitação para um deles.

Os modelos gratuitos compartilham uma cota de 1.500 solicitações por usuário por dia UTC, por padrão. Acima disso, as solicitações retornam `429` com o código `phaseo_free_model_limit_exceeded` até 00:00 UTC; veja [Limites do Gateway](../api-reference/limits#gateway-limits).

## Saia do roteador gratuito

Se nenhum modelo gratuito suporta um recurso de que você precisa, como ferramentas ou um JSON Schema, mude para um modelo pago específico em vez de repetir a mesma solicitação. Passe para um modelo fixo quando precisar de latência, estilo de saída ou escolha de provedor previsíveis, e coloque as configurações compartilhadas em uma [predefinição](../guides/presets) para que todos os serviços enviem a mesma solicitação. [Roteamento e fallbacks](../guides/routing-and-fallbacks) explica como as solicitações pagas escolhem um provedor, e [Erros da API](../api-reference/errors) lista os códigos de erro.
