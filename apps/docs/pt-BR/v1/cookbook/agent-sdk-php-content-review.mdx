Execute um agente em PHP que carrega um rascunho do CMS com uma ferramenta local e sugere uma alteração editorial, dentro do app ou do backend administrativo que já é dono do conteúdo. Ao final, você terá um único script que imprime uma sugestão de título para o rascunho da página inicial.

A ferramenta retorna dados de exemplo fixos, então o script é ilustrativo; substitua-a pela consulta ao seu CMS. Ele serve para um app PHP em que uma ou duas ferramentas locais bastam.

## Crie o agente

<Steps>
<Step title="Instale">

```bash
composer require phaseo/agent-sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

`phaseo/agent-sdk` instala o `phaseo/sdk` junto e precisa do PHP 8.1 ou mais recente. Veja [Instalação do Agent SDK de PHP](../sdk-reference/agent/installation).

</Step>
<Step title="Escreva o agente">

```php review.php
<?php
require 'vendor/autoload.php';

use Phaseo\AgentSdk\AgentDefinition;
use Phaseo\AgentSdk\AgentSdk;
use Phaseo\AgentSdk\Tool;

const ALLOWED_SLUGS = ['homepage', 'pricing', 'about'];

$loadDraft = AgentSdk::defineTool(new Tool(
    id: 'load-draft',
    description: 'Load one CMS draft by slug.',
    parameters: [
        'type' => 'object',
        'properties' => [
            'slug' => ['type' => 'string', 'enum' => ALLOWED_SLUGS],
        ],
        'required' => ['slug'],
        'additionalProperties' => false,
    ],
    // Os argumentos vêm do modelo: só slugs conhecidos chegam a execute.
    inputSchema: static function (mixed $input): array {
        if (!is_array($input) || !in_array($input['slug'] ?? null, ALLOWED_SLUGS, true)) {
            throw new InvalidArgumentException('slug must be one of ' . implode(', ', ALLOWED_SLUGS));
        }
        return $input;
    },
    execute: static fn (array $input, $context) => [
        'slug' => $input['slug'],
        'headline' => 'Phaseo makes gateway routing visible.',
    ],
));

$agent = AgentSdk::createAgent(new AgentDefinition(
    id: 'content-review-agent',
    model: 'openai/gpt-6-astra',
    instructions: 'Use tools when helpful and return concise editorial feedback.',
    tools: [$loadDraft],
    maxSteps: 4,
));

// Lê PHASEO_API_KEY do ambiente.
$result = $agent->run(
    input: 'Review the homepage draft and suggest one headline improvement.',
    client: AgentSdk::createGatewayAgentClient(),
);

echo $result->run->status . PHP_EOL;
echo $result->output . PHP_EOL;
```

</Step>
<Step title="Execute">

```bash
php review.php
```

</Step>
</Steps>

## Verifique se funcionou

- O script imprime `completed` e depois uma sugestão de título.
- Em **Configurações → Uso → Registros**, o primeiro turno do modelo mostra uma chamada `load-draft` com `{"slug": "homepage"}`.
- Sem `PHASEO_API_KEY`, `createGatewayAgentClient()` lança `PHASEO_API_KEY is required`.

## Antes da produção

Mantenha a ferramenta somente leitura. Se você adicionar uma que publica ou edita conteúdo, defina `requireApproval: true` nela para que a execução pause para um editor. Para receber o feedback como JSON que seu CMS possa armazenar, peça um esquema e repare saídas quase válidas com a [recuperação de respostas](./response-healing-for-structured-json). A [referência do Agent SDK de PHP](../sdk-reference/agent/usage) cobre estado, aprovação e streaming.
