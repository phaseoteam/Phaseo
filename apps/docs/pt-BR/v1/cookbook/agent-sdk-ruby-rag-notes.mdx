Execute um agente em Ruby que consulta uma nota interna com uma ferramenta local e responde em um parágrafo curto, sem entregar a orquestração a outro sistema. Ao final, você terá um único script que resume sua nota sobre predefinições.

A ferramenta retorna dados de exemplo fixos, então o script é ilustrativo; substitua-a por uma consulta ao seu próprio armazenamento de notas. Ele serve para um app Ruby que já é dono dos dados e tem entradas de ferramenta simples e determinísticas.

## Crie o agente

<Steps>
<Step title="Instale">

```bash
gem install phaseo_agent_sdk
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

Ou adicione `gem "phaseo_agent_sdk"` ao seu `Gemfile`. Ele instala o `phaseo_sdk` junto e precisa do Ruby 3.2 ou mais recente. Veja [Instalação do Agent SDK de Ruby](../sdk-reference/agent/installation).

</Step>
<Step title="Escreva o agente">

```ruby notes.rb
require "phaseo_agent_sdk"

TOPICS = %w[presets routing guardrails].freeze

lookup_note = PhaseoAgentSdk.define_tool(
  PhaseoAgentSdk::Tool.new(
    id: "lookup-note",
    description: "Look up one internal note by topic.",
    parameters: {
      type: "object",
      properties: { topic: { type: "string", enum: TOPICS } },
      required: ["topic"],
      additionalProperties: false
    },
    # Os argumentos vêm do modelo: só tópicos conhecidos chegam a execute.
    input_schema: lambda do |input|
      raise ArgumentError, "topic must be one of #{TOPICS.join(', ')}" unless input.is_a?(Hash) && TOPICS.include?(input["topic"])

      input
    end,
    execute: lambda do |input, _context|
      {
        topic: input["topic"],
        summary: "Presets centralize routing defaults so app code stays smaller."
      }
    end
  )
)

agent = PhaseoAgentSdk.create_agent(
  id: "notes-agent",
  model: "openai/gpt-6-astra",
  instructions: "Use tools when helpful and answer in one short paragraph.",
  tools: [lookup_note],
  max_steps: 4
)

# Lê PHASEO_API_KEY do ambiente.
result = agent.run(
  input: "Summarize our note about presets.",
  client: PhaseoAgentSdk.create_gateway_agent_client
)

puts result.run.status
puts result.output
```

</Step>
<Step title="Execute">

```bash
ruby notes.rb
```

</Step>
</Steps>

## Verifique se funcionou

- O script imprime `completed` e depois um parágrafo sobre predefinições.
- Em **Configurações → Uso → Registros**, o primeiro turno do modelo mostra uma chamada `lookup-note` com `{"topic": "presets"}`.

## Antes da produção

Mantenha a ferramenta somente leitura e mantenha `max_steps` tão baixo quanto o trabalho permitir (o padrão é `12`). Se o seu armazenamento de notas for grande, retorne apenas o trecho correspondente em vez de documentos inteiros, para que cada turno do modelo continue pequeno. Para salvar execuções e retomá-las depois, veja o [loop persistente](./agent-sdk-durable-loop); a opção `state:` do SDK de Ruby funciona da mesma forma. A [referência do Agent SDK de Ruby](../sdk-reference/agent/usage) cobre estado, aprovação e streaming.
