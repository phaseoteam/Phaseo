Execute um agente em Python que consulta algo com uma ferramenta local e retorna a resposta como JSON estrito. Ao final, você terá um único script cujo `result.output` é um objeto `PolicySummary` validado, com `summary` e `recommendation`, e não texto livre.

A ferramenta retorna dados de exemplo fixos, então o script é ilustrativo; substitua-a pela sua própria consulta. Ele serve para um worker em Python que cuida da própria orquestração e tem um conjunto pequeno e determinístico de ferramentas.

## Crie o agente

<Steps>
<Step title="Instale">

<CodeGroup>
```bash pip
pip install phaseo-agent-sdk
```

```bash uv
uv add phaseo-agent-sdk
```
</CodeGroup>

`phaseo-agent-sdk` instala o cliente `phaseo` e o Pydantic junto.

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="Escreva o agente">

```python extract.py
import json
import os

from pydantic import BaseModel, ConfigDict

from phaseo_agent import AgentTool, create_agent, create_gateway_agent_client, define_tool

POLICY_SLUGS = {"presets", "routing", "guardrails"}


class PolicySummary(BaseModel):
    model_config = ConfigDict(extra="forbid")
    summary: str
    recommendation: str


def check_lookup_input(value):
    # Argumentos gerados pelo modelo: rejeite qualquer coisa que não seja um slug conhecido.
    if not isinstance(value, dict) or set(value) != {"slug"} or value["slug"] not in POLICY_SLUGS:
        raise ValueError(f"slug must be one of {sorted(POLICY_SLUGS)}")
    return value


lookup_policy = define_tool(
    AgentTool(
        id="lookup-policy",
        description="Look up one internal policy by slug.",
        parameters={
            "type": "object",
            "properties": {"slug": {"type": "string", "enum": sorted(POLICY_SLUGS)}},
            "required": ["slug"],
            "additionalProperties": False,
        },
        input_schema=check_lookup_input,
        execute=lambda input, ctx: {
            "slug": input["slug"],
            "summary": "Presets centralize routing, prompts, and caching defaults.",
        },
    )
)

agent = create_agent(
    {
        "id": "policy-extractor",
        "model": "openai/gpt-6-astra",
        "instructions": "Use tools when needed and return JSON with summary and recommendation.",
        "tools": [lookup_policy],
        "max_steps": 4,
        "parse_output": json.loads,
        "output_schema": PolicySummary,
    }
)

# O cliente Python não lê PHASEO_API_KEY sozinho: passe a chave.
client = create_gateway_agent_client(
    client_options={"api_key": os.environ["PHASEO_API_KEY"]},
    response_format={
        "type": "json_schema",
        "name": "policy_summary",
        "schema": {
            "type": "object",
            "properties": {
                "summary": {"type": "string"},
                "recommendation": {"type": "string"},
            },
            "required": ["summary", "recommendation"],
            "additionalProperties": False,
        },
    },
    plugins=[{"id": "response-healing"}],
)

result = agent.run(input="Look up our presets policy and recommend when to use it.", client=client)

print(result.run.status)
print(result.output)
```

| Parte | O que faz |
| --- | --- |
| `parameters` | O JSON Schema que o modelo vê para os argumentos da ferramenta |
| `input_schema` | Verifica os argumentos antes de `execute` rodar; uma chamada inválida faz a execução falhar |
| `response_format` | Pede ao Gateway este JSON Schema em todos os turnos |
| `parse_output` e `output_schema` | Analisam o texto final e o validam como `PolicySummary` |

</Step>
<Step title="Execute">

```bash
python extract.py
```

</Step>
</Steps>

## Verifique se funcionou

- O script imprime `completed` e depois um `PolicySummary` com os dois campos preenchidos.
- Em **Configurações → Uso → Registros**, o primeiro turno do modelo mostra uma chamada `lookup-policy` com `{"slug": "presets"}`.
- Uma saída que não corresponde ao modelo falha com `Invalid agent output` em vez de retornar um objeto preenchido pela metade.

Para saída estruturada em uma única chamada, sem ferramentas, chame o [SDK de Python diretamente](./sdk-python-presets-and-json). A [referência do Agent SDK de Python](../sdk-reference/agent/usage) cobre estado, aprovação e streaming.
