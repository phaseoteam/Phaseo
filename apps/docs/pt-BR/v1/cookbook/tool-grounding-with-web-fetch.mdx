Dê ao modelo `phaseo:web_fetch` e uma URL que você já conhece, e o Phaseo busca a página, corta o texto até um limite de tamanho e o devolve antes que o modelo extraia, resuma ou classifique o conteúdo. No fim, você tem uma solicitação que lê uma única página e retorna campos dela, e consegue confirmar no registro qual página ela realmente leu.

A solicitação está pronta para produção com o limite de domínio mostrado. As páginas buscadas são entrada não confiável: o modelo pode encontrar instruções nelas, então valide o que ele retorna. Use a [busca na web](../guides/server-tools/web-search) quando não souber a URL.

## Envie uma solicitação fundamentada

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
    "tools": [
      {
        "type": "phaseo:web_fetch",
        "parameters": {
          "allowed_domains": ["phaseo.app"],
          "max_chars": 8000,
          "max_uses": 1
        }
      }
    ],
    "tool_choice": "phaseo:web_fetch"
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-6-astra",
  input:
    "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
  tools: [
    {
      type: "phaseo:web_fetch",
      parameters: {
        allowed_domains: ["phaseo.app"],
        max_chars: 8000,
        max_uses: 1,
      },
    },
  ],
  tool_choice: "phaseo:web_fetch",
});

console.log(JSON.stringify(response.output, null, 2));
console.log(response.usage?.server_tool_use);
```
</CodeGroup>

Deixe o prompt explícito sobre a tarefa depois da busca: extrair estes campos, resumir esta seção, classificar o documento ou verificar uma afirmação.

| Parâmetro | Padrão | Uso |
| --- | --- | --- |
| `allowed_domains` | Nenhum | Busca só nestes domínios. O modelo pode restringir a lista, nunca ampliá-la. |
| `max_chars` | `12000` | Caracteres de texto da página retornados, até `100000`. Menos para um título ou resumo, mais para extração de campos. |
| `max_uses` | `10` | Chamadas de busca por solicitação, até `100`. |

O [guia de web fetch](../guides/server-tools/web-fetch#parameters) lista os demais, incluindo `blocked_domains` e os mecanismos.

## Confira o que ele leu

O resultado da ferramenta, que aparece no registro da solicitação, diz exatamente em qual página o modelo se baseou:

```json
{
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "truncated": false,
  "returned_chars": 8000
}
```

Confira `final_url` depois dos redirecionamentos e `truncated` antes de confiar que o modelo viu a página inteira. Cada busca soma 1 a `usage.server_tool_use.web_fetch_requests`.

## Conheça os limites

Com o mecanismo padrão `direct`, o próprio Phaseo busca a página e reduz o HTML a texto simples. Ele recusa `localhost` e endereços privados, segue no máximo 5 redirecionamentos e verifica cada redirecionamento com as suas listas de domínios; um redirecionamento fora delas retorna `redirect_blocked_by_domain_policy` ao modelo.

O web fetch serve para páginas HTML, texto simples e respostas JSON ou XML pequenas. Ele não serve para arquivos binários, para rastrear muitas páginas nem para conferir como uma página é renderizada com JavaScript; use um fluxo com navegador para isso. Se a página for muito grande, restrinja a tarefa de extração em vez de aumentar `max_chars`.

Comece com uma predefinição ou um endpoint, leia nos registros os detalhes da busca e o truncamento, e ajuste o prompt se o texto buscado for amplo demais antes de ampliar o uso.
