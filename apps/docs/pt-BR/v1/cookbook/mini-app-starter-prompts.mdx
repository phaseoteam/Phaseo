---
title: "Prompts iniciais para miniaplicativos"
icon: "code"
description: "Prompts prontos para copiar para que agentes de programação criem pequenos aplicativos com o Phaseo usando HTTP direto, SDKs ou runtimes de agentes."
---

Cole um destes prompts no Cursor, no Claude Code, no Codex ou em um agente de programação parecido, e ele cria um pequeno aplicativo funcionando com o Phaseo e depois informa o que executou e o que não conseguiu verificar. Cada prompt indica a superfície de integração, as regras de segurança e a verificação que você espera.

Os aplicativos gerados são pontos de partida: revise o código, principalmente o tratamento de segredos e a validação de ferramentas, antes de implantá-lo.

## Use um prompt

<Steps>
  <Step title="Escolha a superfície de integração">
    | Prompt | Chama o Phaseo com |
    | --- | --- |
    | HTTP direto | `fetch` em `https://api.phaseo.app/v1` |
    | SDK de TypeScript | `@phaseo/sdk` |
    | SDK de Python | `phaseo` |
    | Vercel AI SDK | `@phaseo/ai-sdk-provider` |
    | Agent SDK | `@phaseo/agent-sdk`, `phaseo-agent-sdk` ou o Agent SDK da sua linguagem |
  </Step>
  <Step title="Substitua as variáveis entre colchetes">
    Preencha valores como `[APP IDEA]`, `[FRAMEWORK]`, `[MODEL]` e `[LANGUAGE]` antes de colar o prompt no seu agente de programação.
  </Step>
  <Step title="Peça verificação, não só código">
    Mantenha as linhas de verificação no prompt. Elas obrigam o agente a informar o que realmente executou, o que presumiu e o que ainda precisa de configuração manual.
  </Step>
</Steps>

Implementation details:
- Use fetch.

- The app code.

## Como fazer os prompts funcionarem melhor

- Substitua `[APP IDEA]` por uma tarefa específica do usuário, não por uma descrição ampla de produto.
- Substitua `[MODEL]` pelo ID exato do modelo que você quer que o agente use.
- Diga se a saída deve ser texto livre, JSON estrito, chat ou um único recurso gerado.
- Mencione o framework de interface e o destino de implantação quando você os souber.
- Adicione uma ou duas restrições que importam, como `EU-only providers`, `use streaming` ou `keep all secrets server-side`.

As referências do [SDK de TypeScript e Python](../sdk-reference/client/overview) e do [Agent SDK](../sdk-reference/agent/overview) listam o que cada pacote oferece, para você conferir o código do agente com base nelas.
