Use esta página quando quiser passar a um agente de programação um prompt concreto que produza um app pequeno e funcional, em vez de um plano de integração vago.

<Tip>
Estes prompts são focados no resultado e específicos quanto à implementação para funcionar melhor no Cursor, Claude Code, Codex e ferramentas semelhantes.
</Tip>

## Como usar estes prompts

<Steps>
  <Step title="Escolha a superfície de integração">
    Escolha o prompt que corresponda à forma como o app deve chamar o Phaseo:

    - HTTP bruto
    - um SDK oficial
    - Vercel AI SDK
    - SDK de agente
  </Step>
  <Step title="Substitua as variáveis entre colchetes">
    Preencha valores como `[IDEIA DO APP]`, `[FRAMEWORK]`, `[MODELO]` e `[LANGUAGE]` antes de colar o prompt no agente de programação.
  </Step>
  <Step title="Peça verificação, não apenas código">
    Mantenha as linhas de verificação no prompt. Elas obrigam o agente a informar o que realmente executou, o que presumiu e o que ainda precisa de configuração manual.
  </Step>
</Steps>

- Execute o app localmente, se possível.

## Como melhorar os prompts

- Substitua `[IDEIA DO APP]` por uma tarefa específica do usuário, não por uma apresentação ampla do produto.
- Substitua `[MODELO]` pelo ID exato do modelo que o agente deve usar.
- Informe se a saída deve ser texto livre, JSON estrito, chat ou um único recurso gerado.
- Mencione o framework de UI e o destino da implantação, se souber.
- Adicione uma ou duas restrições importantes, como `somente provedores da UE`, `usar streaming` ou `manter todos os segredos no servidor`.
