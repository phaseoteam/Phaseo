Este guia foi movido para [Limites de requisições](../api-reference/limits.mdx). Essa referência descreve as cotas atuais do Gateway, os limites do provedor, `Retry-After` e novas tentativas com limites definidos.

Uma solicitação pode receber `429` devido a uma cota do Gateway ou do provedor. BYOK também está sujeito às cotas da sua conta no provedor. Roteamento e alternativas podem reduzir falhas, mas não garantem o sucesso de cada solicitação.

## Monitorar o uso

Revise erros `429` e novas tentativas nos registros de solicitações. A API já permite [consultar análises do workspace](../api-reference/endpoint/analytics-get.mdx) e [exportá-las como CSV](../api-reference/endpoint/analytics-export.mdx). Ambas as operações exigem uma chave de gerenciamento com `analytics:read`.
