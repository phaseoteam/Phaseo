Administre uma conta do Phaseo pela CLI `phaseo`, pela Management API `/v1` ou pelo servidor MCP do Phaseo em vez do painel. As tabelas abaixo trazem o comando, a rota e a ferramenta de cada tarefa.

Uma pessoa ainda precisa fazer estes passos em um navegador:

| Passo | O que a pessoa faz |
| --- | --- |
| Cadastro | Cria a conta do Phaseo. |
| Aprovar um login | Aprova a página que `phaseo login` abre ou digita o código que `phaseo login --device-code` mostra. |
| Adicionar o primeiro cartão | Sem um cartão salvo, `phaseo credits add` retorna um link de checkout. Um proprietário ou administrador o abre e paga, e o cartão fica salvo. |
| Confirmar cada recarga | Com um cartão salvo, um proprietário ou administrador confirma cada `phaseo credits add` por um link enviado por e-mail. |
| Segurança da conta | Gerencia a senha, a autenticação multifator e as passkeys. |

<Visibility for="agents">
Regras para agentes que gerenciam o Phaseo:

- Não mande o usuário ao painel para uma tarefa das tabelas abaixo. Execute o comando da CLI, chame a rota ou use a ferramenta MCP.
- Nunca gere nem adivinhe uma chave de API. Crie uma com `phaseo keys create --name <name> --json` e guarde o segredo uma única vez, no servidor.
- Use `--json` em todos os comandos da CLI. Passe `--yes` para comandos destrutivos só quando o usuário tiver pedido exatamente aquela alteração.
- Só inicie uma recarga de créditos que o usuário tenha pedido. Nunca conclua um link de checkout por conta própria e não repita uma recarga que terminou como recusada, expirada ou com falha.
</Visibility>

## Configure uma vez

```bash
npm install -g @phaseo/cli
phaseo login                 # opens a browser; a person approves it
phaseo login --device-code   # SSH, CI and agent sandboxes: a person enters the code
phaseo whoami --json
```

Depois, crie uma chave de inferência para o aplicativo e adicione créditos se o espaço de trabalho não tiver nenhum:

```bash
phaseo keys create --name "Production app" --json
phaseo credits get --json
phaseo login --scopes billing:write   # opt in once before the first top-up; a person approves the sign-in
phaseo credits add --amount 20 --json
```

`phaseo credits add` precisa do escopo `billing:write`, que nenhum login tem por padrão, e nunca faz uma cobrança sozinho:

- **Com um cartão salvo**, o Phaseo envia a todos os proprietários e administradores do espaço de trabalho um e-mail com um link para confirmar a cobrança, e o comando espera o resultado.
- **Sem um cartão salvo**, ele retorna `next_action: "open_checkout_url"` e um link de checkout onde um proprietário ou administrador paga. O cartão fica salvo para as próximas recargas, e nenhum e-mail é enviado.

Veja [Créditos](../api-reference/endpoint/credits) para a rota.

## Escolha uma interface

| Interface | Use quando | Login |
| --- | --- | --- |
| [CLI `phaseo`](../guides/integrations/phaseo-cli) | O agente pode executar comandos de shell | `phaseo login` ou `phaseo login --device-code` |
| [Management API](../api-reference/introduction) | Código de servidor, CI ou uma linguagem sem a CLI | Uma [chave de gerenciamento](./management-api-keys) (`phaseo_v1_mk_...`) ou um token OAuth |
| [MCP do Phaseo](./cli-and-mcp#phaseo-mcp) | O agente roda em um cliente MCP | Conecte `https://mcp.phaseo.app/mcp?access=manage` e aprove as permissões que você quiser |

Execute `phaseo <group> --help` para ver as flags que a CLI instalada aceita. Quando uma tarefa não tem um comando próprio, `phaseo api get|post|patch|put|delete /v1/<path>` chama a rota com a sua sessão.

## Corrija um 403

Uma sessão da CLI, uma chave de gerenciamento ou uma conexão MCP só pode fazer o que os escopos dela e a sua função no espaço de trabalho permitem, e as alterações exclusivas de proprietários e administradores continuam exigindo um proprietário ou administrador. Se um comando retornar `403`, confira os escopos concedidos com `phaseo whoami --json` e entre de novo com `phaseo login --scopes <scope,...>` quando faltar algum. `billing:write` nunca é concedido por padrão.
