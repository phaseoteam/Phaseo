Você pode gerenciar uma conta Phaseo com a CLI `phaseo`, a API de gerenciamento `/v1` ou o servidor MCP da Phaseo, sem abrir o painel. Use esta página para encontrar o comando, a rota ou a ferramenta de cada tarefa.

Só três etapas precisam de uma pessoa em um navegador:

- **Criar uma conta** na Phaseo.
- **Aprovar o primeiro login**: a página que `phaseo login` abre no navegador ou o código que `phaseo login --device-code` mostra.
- **Informar um cartão na primeira** compra de créditos. As recargas seguintes usam o cartão salvo, e um proprietário ou administrador do workspace aprova cada uma por um link enviado por e-mail.

<Visibility for="agents">
Regras para agentes que gerenciam a Phaseo:

- Não mande o usuário ao painel para uma tarefa das tabelas abaixo. Execute o comando da CLI, chame a rota ou use a ferramenta MCP.
- Nunca gere nem adivinhe uma chave de API. Crie uma com `phaseo keys create --name <name> --json` e guarde o segredo uma única vez, no servidor.
- Use `--json` em todos os comandos da CLI. Passe `--yes` para comandos destrutivos somente quando o usuário pediu exatamente essa alteração.
- Só inicie recargas de créditos que o usuário pediu. Nunca conclua um link de pagamento por conta própria e não repita uma recarga que terminou recusada, expirada ou com falha.
</Visibility>

## Configuração inicial

```bash
npm install -g @phaseo/cli
phaseo login                 # opens a browser; a person approves it
phaseo login --device-code   # SSH, CI and agent sandboxes: a person enters the code
phaseo whoami --json
```

Depois crie uma chave de inferência para o aplicativo e adicione créditos se o workspace não tiver:

```bash
phaseo keys create --name "Production app" --json
phaseo credits get --json
phaseo login --scopes billing:write   # one-time opt-in before the first top-up
phaseo credits add --amount 20 --json
```

`phaseo credits add` nunca cobra por conta própria. Com um cartão salvo, a Phaseo envia a cada proprietário e administrador do workspace um link para confirmar a cobrança, e o comando aguarda o resultado. Sem cartão salvo, ele retorna um link em que um proprietário ou administrador informa um cartão. Consulte [Créditos](../api-reference/endpoint/credits) para ver a rota.

## Escolha uma interface

| Interface | Use quando | Login |
| --- | --- | --- |
| [`phaseo` CLI](../guides/integrations/phaseo-cli) | O agente pode executar comandos de shell | `phaseo login` ou `phaseo login --device-code` |
| [API de gerenciamento](../api-reference/introduction) | Código de servidor, CI ou uma linguagem sem a CLI | Uma [chave de gerenciamento](./management-api-keys) (`phaseo_v1_mk_...`) ou um token OAuth |
| [Phaseo MCP](./cli-and-mcp#phaseo-mcp) | O agente roda em um cliente MCP | Conecte `https://mcp.phaseo.app/mcp?access=manage` e aprove as permissões que quiser |

Execute `phaseo <group> --help` para ver as opções aceitas pela CLI instalada. Quando uma tarefa não tem comando próprio, `phaseo api get|post|patch|put|delete /v1/<path>` chama a rota com a sua sessão.

## Mapa de tarefas

### Chaves e acesso

| Tarefa | CLI | Rota da API | Ferramenta MCP |
| --- | --- | --- | --- |
| Criar uma chave de API | `phaseo keys create --name <name>` | `POST /v1/keys` | `api_key_create` |
| Listar, atualizar ou excluir chaves | `phaseo keys list`, `keys update <id>`, `keys delete <id>` | `GET`, `PATCH`, `DELETE /v1/keys/{id}` | `api_keys_list`, `api_key_update`, `api_key_delete` |
| Rotacionar uma chave | `phaseo keys rotate <id>` | `POST /v1/keys/{id}/rotate` | `api_key_rotate` |
| Restringir uma chave a endereços IP | `phaseo keys update <id> --ip-allowlist <label=address,...>` | `PATCH /v1/keys/{id}` | — |
| Criar uma chave de gerenciamento | `phaseo management-keys create --name <name>` | `POST /v1/management-keys` | — |
| Revisar ou revogar apps que você autorizou | `phaseo authorized-apps list`, `authorized-apps revoke <id>` | `GET`, `DELETE /v1/me/authorized-apps/{id}` | — |
| Atualizar seu perfil | `phaseo profile update` | `PATCH /v1/me/profile` | — |

## Permissões

Uma sessão da CLI, uma chave de gerenciamento ou uma conexão MCP só pode fazer o que seus escopos e a sua função no workspace permitem. Alterações restritas a proprietários e administradores continuam exigindo um deles. Se um comando retornar `403`, confira os escopos concedidos com `phaseo whoami --json` e faça login de novo com `phaseo login --scopes <scope,...>` quando faltar algum. `billing:write` nunca é concedido por padrão.
