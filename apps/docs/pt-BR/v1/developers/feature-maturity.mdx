Alguns recursos do Phaseo têm um rótulo **Alfa** ou **Beta** na documentação, na referência da API e no painel. O rótulo mostra o quanto um recurso já está consolidado. Um recurso sem rótulo tem disponibilidade geral.

## Fases

| Fase | O que significa | O que fazer |
| --- | --- | --- |
| Alfa | Uma versão inicial. A API, o comportamento ou o preço podem mudar bastante, e o recurso pode ser removido. | Experimente e diga o que você acha. Não construa sobre ele nada que você não consiga mudar rapidamente. |
| Beta | Funciona para o uso principal. Alguns detalhes ainda podem mudar com base no feedback, e as mudanças são anunciadas no [changelog](../changelog.mdx). | Adequado para pilotos e cargas de trabalho reais que você acompanha de perto. Confira o changelog ao atualizar. |
| Disponibilidade geral | Com suporte completo e documentado. Nenhum rótulo é exibido. | Use em produção. |
| Descontinuado | Ainda funciona, mas não é mais recomendado e será removido. Uma data de remoção é exibida quando definida. | Não comece a usar e migre antes da data de remoção. |

Modelos e provedores têm seus próprios rótulos de ciclo de vida, separados dessas fases. Veja [Descontinuação e aposentadoria de modelos](../guides/model-retirement.mdx) e [Status do provedor e do Phaseo](../guides/provider-statuses.mdx).

## Quem pode usar um recurso

Fase e acesso são independentes. Um recurso Beta pode estar aberto a todos, e um recurso Alfa pode estar limitado a alguns espaços de trabalho.

- **Todos**: qualquer espaço de trabalho pode usar, de acordo com as funções habituais. Por exemplo, algumas configurações são só para proprietários e administradores.
- **Sob solicitação**: o recurso é ativado por espaço de trabalho. Até ser ativado, a página de configurações dele não aparece e a API dele retorna um erro. **Configurações → Prévia de recursos** mostra se a Video API e a Batch API estão ativadas no seu espaço de trabalho. Para pedir acesso a qualquer um desses recursos, [fale com a gente](https://phaseo.app/contact).

## Como os recursos mudam de fase

- Um recurso passa de Alfa para Beta, ou de Beta para disponibilidade geral, quando o uso principal dele funciona e a API dele está estável. Registramos a mudança no [changelog](../changelog.mdx).
- Mudanças incompatíveis em recursos Alfa e Beta são anunciadas no changelog.
- Quando um recurso é descontinuado, a página de documentação dele informa isso e mostra a data de remoção quando ela estiver definida.
