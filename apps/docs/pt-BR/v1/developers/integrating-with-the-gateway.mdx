Guarde uma chave do Phaseo no seu servidor, escolha o endpoint que corresponde ao protocolo do seu aplicativo e aponte o seu cliente HTTP ou SDK para `https://api.phaseo.app/v1`. Comece pelo [Início rápido](../quickstart.mdx) se ainda não enviou nenhuma solicitação.

Você precisa de uma conta do Phaseo com acesso ao Gateway e de um cliente HTTP, um SDK compatível com OpenAI ou um SDK do Phaseo. Os exemplos usam `google/gemma-3-27b:free`, que funciona sem créditos depositados.

<Steps>
<Step title="Crie e guarde uma chave">

Execute `phaseo keys create --name <app-and-environment> --json` na [CLI do Phaseo](../guides/integrations/phaseo-cli) ou abra **Configurações → Chaves de API** no [painel](https://phaseo.app/settings/keys). Dê à chave o nome do aplicativo e do ambiente e guarde-a em um gerenciador de segredos ou em um arquivo de ambiente:

```bash
# .env.local
PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
PHASEO_BASE_URL="https://api.phaseo.app/v1"
```

Use chaves separadas para desenvolvimento local, implantações de prévia e produção, para poder rotacionar e revisar cada uma separadamente.

</Step>
<Step title="Escolha o endpoint">

| Endpoint | Use para |
| --- | --- |
| `/v1/responses` | Novos projetos de texto, saída estruturada e fluxos com várias etapas. |
| `/v1/chat/completions` | Interfaces de chat e integrações existentes no estilo da OpenAI. |
| `/v1/messages` | Integrações compatíveis com a Anthropic. |
| `/v1/decisions` | Decisões tipadas sobre o estado do aplicativo, com o Jev 1.13 (Beta). |
| `/v1/moderations` | Verificações de segurança e de política de conteúdo. |
| `/v1/images/generations` | Imagens a partir de prompts de texto. |

A [Referência da API](../api-reference/introduction) lista todos os endpoints, parâmetros e respostas.

</Step>
<Step title="Envie uma solicitação a partir do seu aplicativo">

Este exemplo usa Chat Completions, que os clientes compatíveis com OpenAI já falam. Toda solicitação envia a chave como `Authorization: Bearer $PHASEO_API_KEY`.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemma-3-27b:free",
    "messages": [
      { "role": "system", "content": "You are a helpful assistant." },
      { "role": "user", "content": "Explain the benefits of AI." }
    ]
  }'
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});

const response = await client.chat.completions.create({
  model: "google/gemma-3-27b:free",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: "Explain the benefits of AI." },
  ],
});

console.log(response.choices[0]?.message?.content);
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.phaseo.app/v1",
)

response = client.chat.completions.create(
    model="google/gemma-3-27b:free",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain the benefits of AI."},
    ],
)

print(response.choices[0].message.content)
```

```go Go
package main

import (
  "context"
  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New("YOUR_API_KEY", "https://api.phaseo.app/v1")

  response, err := client.CreateChatCompletion(context.Background(), phaseo.ChatCompletionsRequest{
    Model: "google/gemma-3-27b:free",
    Messages: []map[string]interface{}{
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain the benefits of AI."},
    },
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(response)
}
```

<Note>
Os modelos cujo ID termina em `:free` funcionam sem créditos depositados. Os modelos pagos precisam de saldo disponível na carteira.
</Note>
