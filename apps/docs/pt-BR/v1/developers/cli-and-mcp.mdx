Use a CLI para alterar o Phaseo a partir de um terminal ou script, ou conecte um cliente de IA ao servidor MCP do Phaseo para dar a ele dados do Phaseo em tempo real. Os dois fazem login com o OAuth do Phaseo.

| Interface | Use para | Acesso |
| --- | --- | --- |
| [CLI do Phaseo](#phaseo-cli) | Criar chaves, alterar configurações, gerenciar espaços de trabalho e automatizar tarefas de administração a partir de um shell ou da CI | Leitura e gravação, limitadas pelos seus escopos e pela sua função no espaço de trabalho |
| [MCP do Phaseo](#phaseo-mcp) | Dar ao Codex, ao Claude, ao ChatGPT e a outros clientes MCP dados do Phaseo em tempo real e, opcionalmente, deixá-los gerenciar a sua conta | Somente leitura, a menos que você se conecte com gerenciamento de conta |
| [MCP da documentação](#docs-mcp) | Dar a um assistente de programação a documentação atual do Phaseo | Só documentação, sem acesso à conta |
| [Plugin do Phaseo](#phaseo-plugin) | Instalar de uma vez os dois servidores MCP e as skills do Phaseo no Claude Code ou no Codex | O mesmo de cada servidor MCP |

<span id="phaseo-cli"></span>
## CLI do Phaseo

### Instale e faça login

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

Terminais interativos usam o OAuth pelo navegador por padrão. Para SSH, CI e ambientes sem interface, use a autorização por dispositivo:

```bash
phaseo login --device-code
```

### Fluxos comuns

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys list
phaseo logs list --since 1h --status error --json
```

Use `--json` quando outra ferramenta ou script precisar de saída estruturada. Os valores secretos só são exibidos por comandos que os criam ou revelam explicitamente.

## MCP do Phaseo

A URL do servidor é `https://mcp.phaseo.app/mcp`. Um cliente de IA conectado a ela pode responder a perguntas com dados em tempo real sobre modelos, preços, provedores, uso e o espaço de trabalho.

### Conecte o seu cliente

Instale com um clique: [Adicionar ao Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=phaseo&config=eyJ1cmwiOiJodHRwczovL21jcC5waGFzZW8uYXBwL21jcCJ9) · [Adicionar ao VS Code](vscode:mcp/install?%7B%22name%22%3A%22phaseo%22%2C%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fmcp.phaseo.app%2Fmcp%22%7D). Quando o cliente pedir que você faça login, o Phaseo OAuth abre no seu navegador. Escolha um workspace e aprove os scopes de leitura solicitados.

<Tabs>

```bash
claude mcp add --transport http phaseo https://mcp.phaseo.app/mcp
```

Depois execute `/mcp`, selecione `phaseo` e escolha **Authenticate**. Adicione `--scope user` para disponibilizá-lo em todos os projetos.
</Tab>
<Tab title="Codex">
```bash

codex mcp login phaseo
```

O comando de login abre o Phaseo OAuth. `codex mcp list` confirma a conexão.
</Tab>

Para outro cliente MCP, adicione a mesma URL como um servidor remoto Streamable HTTP. O cliente precisa suportar a descoberta OAuth, o authorization code com PKCE S256 e o parâmetro `resource` do MCP.

### Use o login da CLI do Phaseo

Se você já usa a CLI do Phaseo, um agente local pode acessar o MCP por meio dela sem um segundo login:

```bash
phaseo login
claude mcp add --scope user phaseo -- phaseo mcp
# or, for Codex
codex mcp add phaseo -- phaseo mcp
```

`phaseo mcp` executa o MCP via stdio com o login da sua CLI. Ele troca esse login por um token de 15 minutos que só funciona no MCP, nunca tem mais acesso do que o seu login e nunca permite chamadas pagas a modelos. Ele é somente leitura, a menos que você adicione `--manage`. `phaseo setup codex` o adiciona ao perfil do Phaseo no Codex para você. Quando um agente conectado assim lê logs, atividade ou análises, o resultado também sugere o comando da CLI correspondente para os dados completos.

### O que o MCP pode ler

As ferramentas somente leitura cobrem modelos, provedores, rankings de benchmarks, preços e estimativas de custo, além de créditos, atividade, análises, registros de solicitações e metadados de geração. Elas nunca retornam prompts, respostas nem valores secretos.

### Gerencie a sua conta (opcional)

Para deixar um agente alterar o seu espaço de trabalho no Phaseo, conecte-se com a URL de gerenciamento:

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

Ao entrar, a tela de consentimento lista cada permissão que a conexão pede, como gerenciar chaves de API ou excluir orçamentos, e a marca como **Leitura**, **Gravação** ou **Exclusão**. Desmarque as que você não quiser. O agente só recebe ferramentas para as permissões que você permitir, e o Phaseo continua verificando a sua função no espaço de trabalho a cada alteração, então um membro que não é proprietário nem administrador não consegue mudar por aqui configurações exclusivas de administradores.

Se você já se conectou com a URL somente leitura, mude o cliente para a URL de gerenciamento e entre de novo. Para voltar ao acesso somente leitura, conecte-se de novo com a URL simples ou revogue o aplicativo em **Configurações → Apps conectados**.

Uma conexão de gerenciamento lê tudo o que está abaixo, mas só altera chaves de API e configurações do espaço de trabalho. Orçamentos, regras de gastos, chaves de provedor, guardrails, predefinições, webhooks e destinos de observabilidade controlam gastos ou para onde vai o conteúdo das solicitações, então você os altera no painel ou com uma chave de gerenciamento.

| Área | Ler | Alterar |
| --- | --- | --- |
| Chaves de API | `api_keys_list`, `api_key_get` | Com `phaseo mcp --manage`: `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete`. Outros clientes podem renomear (`api_key_update`) e excluir (`api_key_delete`) |
| Configurações | `settings_get` | `settings_update`, para alterações que mantêm ou reforçam a privacidade, o registro de logs e as restrições de provedores |
| Orçamentos | `budgets_list` | No painel |
| Regras de gastos | `spend_rules_list` | No painel |
| Chaves de provedor (BYOK) | `provider_keys_list` | No painel |
| Guardrails | `guardrails_list`, `guardrail_get` | No painel |
| Predefinições | `presets_list`, `preset_get` | No painel |
| Webhooks | `webhooks_list` | No painel |
| Destinos de observabilidade | `observability_destinations_list` | No painel |

Ferramentas que alteram ou excluem algo são marcadas como tal, para que clientes MCP compatíveis peçam sua confirmação antes de cada chamada. Uma nova chave de API aparece uma vez no resultado da ferramenta e não pode ser mostrada de novo. Chaves de provedor armazenadas e credenciais de destinos nunca são retornadas.

O MCP não tem ferramentas de cobrança, pagamento, espaço de trabalho, membros, chaves de gerenciamento nem aplicativos OAuth. Use o painel, a CLI ou a Management API para isso.

## MCP da documentação

O MCP da documentação é um endpoint separado para pesquisar e ler a documentação do Phaseo. Ele não acessa a sua conta nem o seu espaço de trabalho.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

## Plugin do Phaseo

O plugin do Phaseo reúne o MCP do Phaseo, o MCP da documentação e as skills de agente do Phaseo para integração, migração, escolha de modelos, monitoramento de uso, os SDKs e a CLI. Instale-o uma vez em vez de conectar cada parte por conta própria.

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

Execute `/mcp` e entre em `plugin:phaseo:phaseo` para conectar a sua conta do Phaseo. As skills são carregadas quando uma solicitação corresponde a elas, ou você pode executar uma diretamente, como `/phaseo:phaseo-gateway`.

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

O último comando abre o OAuth do Phaseo para o MCP do Phaseo. As skills são carregadas quando uma solicitação corresponde a elas.
