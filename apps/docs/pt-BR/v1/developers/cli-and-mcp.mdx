# CLI e MCP

Use o Phaseo no terminal com a CLI ou conecte um cliente de IA por MCP. Ambos usam o Phaseo OAuth, mas foram criados para tarefas diferentes.

| Interface | Ideal para | Acesso |
| --- | --- | --- |
| Phaseo CLI | Fluxos no terminal, CI, administração e automação | Leitura e gravação, limitadas pelos escopos e pelo papel no espaço de trabalho |
| Phaseo MCP | Dados atuais da Phaseo no Codex, Claude, ChatGPT e outros clientes MCP, e gerenciamento opcional da conta | Autenticado; somente leitura, a menos que você se conecte com gerenciamento da conta |
| Docs MCP | Consultar a documentação atual da Phaseo durante o desenvolvimento | Somente documentação e somente leitura |
| Plugin da Phaseo | Instalar o Phaseo MCP, o Docs MCP e as skills da Phaseo no Claude Code ou no Codex de uma vez | Igual a cada servidor MCP |

## Phaseo CLI

Use a CLI para criar ou alterar recursos da Phaseo, automatizar fluxos ou inspecionar dados da conta pelo shell.

### Instalar e entrar

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

Por padrão, terminais interativos usam OAuth no navegador. Para SSH, CI e ambientes sem interface, use a autorização por dispositivo:

```bash
phaseo login --device-code
```

### Fluxos comuns

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys create --name "Local development"
phaseo logs list --since 1h --status error --json
```

Use `--json` quando outra ferramenta ou script precisar de uma saída estruturada. Valores secretos só são exibidos por comandos que os criam ou revelam explicitamente.

## Phaseo MCP

Conecte o servidor MCP da Phaseo quando quiser que um cliente de IA responda usando dados atuais sobre modelos, preços, provedores, uso e espaços de trabalho.

### URL do servidor

`https://mcp.phaseo.app/mcp`

### Conectar pelo Codex

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

O comando de login abre o Phaseo OAuth. Escolha um espaço de trabalho, aprove os escopos de leitura solicitados e confirme a conexão:

```bash
codex mcp list
```

Para outro cliente MCP, adicione a mesma URL como um servidor HTTP remoto com streaming. O cliente precisa oferecer descoberta OAuth, código de autorização com S256 PKCE e o parâmetro MCP `resource`.

### Dados que o MCP pode ler

- modelos, provedores, rankings de benchmarks, preços e estimativas de custo
- créditos, atividade, análises, registros de solicitações e metadados de geração

Essas ferramentas são somente leitura. Elas nunca retornam prompts, respostas nem valores secretos.

### Gerenciar sua conta (opcional)

Para permitir que um agente altere seu espaço de trabalho da Phaseo, conecte-se com a URL de gerenciamento:

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

Ao entrar, a tela de consentimento lista cada permissão solicitada pela conexão, como gerenciar chaves de API ou excluir orçamentos, e a marca como **Leitura**, **Gravação** ou **Exclusão**. Desmarque as que você não quiser conceder. O agente só recebe ferramentas para as permissões autorizadas, e a Phaseo continua verificando sua função no espaço de trabalho a cada alteração, então um membro que não seja proprietário nem administrador não consegue alterar por aqui as configurações restritas a administradores.

Se você já se conectou com a URL somente leitura, mude o cliente para a URL de gerenciamento e entre novamente. Para voltar ao acesso somente leitura, conecte-se de novo com a URL normal ou revogue o app em **Configurações → Apps conectados**.

| Área | Ferramentas | Permissões |
| --- | --- | --- |
| Chaves de API | `api_keys_list`, `api_key_get`, `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete` | `keys:read`, `keys:write`, `keys:delete` |
| Orçamentos | `budgets_list`, `budget_create`, `budget_update`, `budget_delete` | `budgets:read`, `budgets:write`, `budgets:delete` |
| Regras de gastos | `spend_rules_list`, `spend_rule_create`, `spend_rule_update`, `spend_rule_delete` | `spend_rules:read`, `spend_rules:write`, `spend_rules:delete` |
| Chaves de provedores (BYOK) | `provider_keys_list`, `provider_key_create`, `provider_key_update`, `provider_key_delete` | `provider_credentials:read`, `provider_credentials:write`, `provider_credentials:delete` |
| Guardrails | `guardrails_list`, `guardrail_get`, `guardrail_create`, `guardrail_update`, `guardrail_delete`, `guardrail_keys_set` | `guardrails:read`, `guardrails:write`, `guardrails:delete` |
| Predefinições | `presets_list`, `preset_get`, `preset_create`, `preset_update`, `preset_version_publish` | `presets:read`, `presets:write` |
| Configurações | `settings_get`, `settings_update` (modo de roteamento, privacidade e ZDR, registros, restrições de provedores) | `settings:read`, `settings:write` |
| Webhooks | `webhooks_list`, `webhook_create`, `webhook_delete` | `settings:read`, `settings:write` |
| Destinos de observabilidade | `observability_destinations_list`, `observability_destination_create`, `observability_destination_delete` | `settings:read`, `settings:write` |

As ferramentas que alteram ou excluem algo são marcadas como tal, para que os clientes MCP compatíveis peçam sua confirmação antes de cada chamada. Uma nova chave de API ou um novo segredo de assinatura de webhook aparece uma única vez no resultado da ferramenta e não pode ser exibido de novo. Chaves de provedores salvas e credenciais de destinos nunca são retornadas.

O MCP não tem ferramentas de faturamento, pagamentos, espaços de trabalho, membros, chaves de gerenciamento ou apps OAuth. Para isso, use o painel, a CLI ou a API de gerenciamento.

## Docs MCP

O Docs MCP é um endpoint separado para pesquisar e ler a documentação da Phaseo. Ele não acessa sua conta nem seu espaço de trabalho.

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

Use-o quando um assistente de programação precisar de exemplos atuais de API, orientações de integração ou documentação de recursos.

## Plugin da Phaseo

O plugin da Phaseo reúne o Phaseo MCP, o Docs MCP e as skills da Phaseo para agentes sobre integração, migração, escolha de modelos, monitoramento de uso, os SDKs e a CLI. Instale uma vez em vez de conectar cada parte por conta própria.

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

Execute `/mcp` e entre em `plugin:phaseo:phaseo` para conectar sua conta da Phaseo. As skills são carregadas quando uma solicitação corresponde a elas, ou você pode executar uma diretamente, como `/phaseo:phaseo-gateway`.

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

O último comando abre o Phaseo OAuth para o Phaseo MCP. As skills são carregadas quando uma solicitação corresponde a elas.

## Escolha a interface certa

- Use a **CLI** para criar chaves, alterar configurações, gerenciar espaços de trabalho ou automatizar tarefas administrativas.
- Use o **Phaseo MCP** para dar a um cliente de IA acesso seguro aos dados atuais da Phaseo.
- Use o **Docs MCP** para dar a um assistente de programação acesso à documentação atual da Phaseo sem acesso à conta.
- Use o **plugin da Phaseo** para configurar os dois servidores MCP e as skills da Phaseo no Claude Code ou no Codex de uma vez.
