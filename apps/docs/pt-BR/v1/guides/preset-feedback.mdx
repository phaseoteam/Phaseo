Envie cada avaliação de usuário para `POST /v1/feedback` com o ID da solicitação e a [predefinição](./presets.mdx) que respondeu. Depois, compare as predefinições pela frequência com que suas respostas foram bem avaliadas, e não só por latência e custo.

<Note>
O Feedback de predefinições está em Alpha, e a API e o painel ainda podem mudar. Use o botão **Feedback** na [página de Feedback de predefinições](https://phaseo.app/settings/presets/experiments) para nos contar o que o tornaria mais útil.
</Note>

## Registrar uma avaliação

Você precisa de uma chave de API com a capacidade `feedback:write`, do ID da solicitação retornado pelo Phaseo e do UUID da predefinição. É o ID da predefinição que coloca o evento nas comparações de predefinições e na análise de coortes.

```bash cURL
curl https://api.phaseo.app/v1/feedback \
  -X POST \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "requestId": "gen_01K...",
    "presetId": "8f54b2d9-9ba3-4ced-8a7f-9bb70a44dbea",
    "rating": "thumbs_up",
    "score": 1,
    "comment": "The answer resolved the customer question.",
    "metadataDimensions": {
      "plan": "pro",
      "surface": "support_chat"
    }
  }'
```

Um evento de feedback precisa apontar para pelo menos uma solicitação, sessão, predefinição ou execução de teste. `score` é opcional e deve ficar entre `0` e `1`.

Coloque valores de baixa cardinalidade, como plano, implantação, localidade ou superfície do aplicativo, em `metadataDimensions`, para poder filtrar por eles. Coloque contexto arbitrário ou de alta cardinalidade em `metadata`.

## Escolher uma avaliação

| Sinal | `rating` |
| --- | --- |
| Uma reação simples do usuário | `thumbs_up`, `thumbs_down` |
| Uma resposta avaliada | `correct`, `partly_correct`, `incorrect` |
| Um problema operacional | `bad_format`, `too_slow`, `too_expensive` |
| Um resultado de segurança | `unsafe`, `refused_incorrectly` |
| Qualquer outra coisa | `not_helpful`, `other` |

Prefira uma avaliação explícita a apenas uma pontuação numérica: as comparações de predefinições se baseiam em avaliações, e as pontuações aparecem como detalhe complementar.

## Comparar predefinições

Abra [Configurações → Predefinições → Feedback](https://phaseo.app/settings/presets/experiments) para:

- comparar as taxas positivas, parciais e negativas
- selecionar uma predefinição de referência
- filtrar por data, avaliação e dimensões de metadados
- inspecionar a solicitação, a sessão, os comentários e as tags por trás de um evento

O painel analisa no máximo as 10.000 linhas de feedback correspondentes mais recentes no período selecionado.

## Ler feedback pela API

A leitura exige `feedback:read`. Os resultados ficam limitados ao espaço de trabalho autenticado e às predefinições que quem faz a chamada pode ver.

Liste os eventos recentes:

```bash
curl "https://api.phaseo.app/v1/feedback?preset_id=PRESET_UUID&limit=100" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

Obtenha um resumo calculado no servidor:

```bash
curl "https://api.phaseo.app/v1/feedback/summary?group_by=preset&since=2026-08-01T00:00:00Z" \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

As APIs para execuções de teste e eventos de resultado personalizados estão disponíveis, mas as visualizações delas no painel ainda estão mudando. Para lançar uma alteração de predefinição aos poucos, veja [Implantar predefinições e depurar o roteamento](../cookbook/preset-rollout-and-routing-debug).
