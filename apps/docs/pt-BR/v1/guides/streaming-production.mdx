Use estes padrões ao passar do protótipo para a produção.

## Checklist de confiabilidade

- Configure timeouts e controles de cancelamento no cliente.
- Trate os status `429` e `5xx` com backoff exponencial.
- Considere que fluxos desconectados podem ser repetidos.
- Se a correção for importante, persista o texto parcial somente após a conclusão.

## Exemplo de cancelamento no navegador ou no Node

```typescript
const controller = new AbortController();
const timeout = setTimeout(() => controller.abort(), 30_000);

try {
  const response = await fetch("https://api.phaseo.app/v1/chat/completions", {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "openai/gpt-5-nano",
      messages: [{ role: "user", content: "Stream a short summary." }],
      stream: true,
    }),
    signal: controller.signal,
  });
  // Parse SSE frames from response.body here.
} finally {
  clearTimeout(timeout);
}
```

## Orientações para a interface

- Exiba os deltas de tokens progressivamente.
- Exiba o estado explícito de “geração concluída” quando `[DONE]` chegar.
- Mantenha o ID da solicitação e o ID do modelo nos logs para reprodução e depuração.

## Quando não usar streaming

- Fluxos de chamadas de ferramentas com a validação atual de solicitações (`stream + tools` é rejeitado).
- Fluxos de trabalho que exigem validação completa antes de qualquer saída visível para o usuário.
