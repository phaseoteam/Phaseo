O streaming retorna a resposta em partes SSE incrementais para que as pessoas a vejam mais cedo.

## Endpoints compatíveis

- `/v1/responses`
- `/v1/chat/completions`
- `/v1/messages`

## Solicitação

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Stream a short hello message.",
    "stream": true
  }'
```

## Resposta

```text
data: {"id":"resp_...","object":"response","status":"in_progress",...}
data: {"type":"response.output_text.delta","delta":"Hello"}
data: {"type":"response.completed",...}
data: [DONE]
```

## Opções do SDK

- SDK TypeScript: `client.streamResponses()`, `client.streamChat()` e `client.streamMessages()`
- Python SDK: `client.stream_responses()`, `client.stream_chat()` e `client.stream_message()`
- Vercel AI SDK: `streamText(...)` com `@phaseo/ai-sdk-provider`

## Limitação importante

No nível atual de validação de solicitações do gateway, a combinação de ferramentas com `stream: true` é rejeitada (`400 invalid_request`). Use o modo sem streaming em ciclos de chamadas de ferramentas.
