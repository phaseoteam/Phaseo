---
icon: "waypoints"
title: "Padrões de chamadas de ferramentas"
description: "Ciclos confiáveis de chamadas de ferramentas para os endpoints de chat completions e responses."
---

Depois que o modelo chama uma ferramenta, envie uma solicitação de acompanhamento que repete a conversa, a chamada do modelo e o resultado da sua ferramenta. O modelo então escreve a resposta, ou chama outra ferramenta e você repete o processo. Use o endpoint cujo formato de mensagem o seu app já usa: `/v1/chat/completions` para ciclos de mensagens no estilo da OpenAI, `/v1/responses` para a Responses API, `/v1/messages` para apps nativos da Anthropic.

<Tabs>
<Tab title="Chat Completions">

Quando `finish_reason` for `tool_calls`, execute cada chamada e depois envie a mensagem do assistente sem alterações, seguida de uma mensagem `role: "tool"` por chamada, associada pelo `tool_call_id`. Envie `tools` de novo.

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "What is the weather in Seattle?" },
    {
      "role": "assistant",
      "content": null,
      "tool_calls": [
        {
          "id": "call_123",
          "type": "function",
          "function": {
            "name": "get_weather",
            "arguments": "{\"city\":\"Seattle\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_123",
      "content": "72F and sunny"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    }
  ]
}
```

</Tab>
<Tab title="Responses">

As chamadas chegam como itens de saída do tipo `function_call`. Envie o item da chamada de volta como entrada, seguido de um item `function_call_output` com o mesmo `call_id`.

```json
{
  "model": "openai/gpt-6-astra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [{ "type": "input_text", "text": "What's the weather in Seattle?" }]
    },
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Seattle\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "72F and sunny"
    }
  ]
}
```

</Tab>
</Tabs>

Antes de executar uma chamada, valide os argumentos dela; veja [Segurança e validação de chamadas de ferramentas](./tool-calling-safety).
