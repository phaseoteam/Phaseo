Escolha o guia para o trabalho que você tem pela frente. Para uma primeira integração com o Phaseo, siga esta ordem:

1. [Início rápido](../quickstart): faça uma solicitação bem-sucedida.
2. [Autenticação](../developers/authentication): guarde e envie as chaves com segurança.
3. [Exemplos](./examples): copie padrões de solicitação para o seu aplicativo.

<Note>
Você pode chamar modelos `:free` sem depositar créditos. Os modelos pagos continuam exigindo saldo disponível na carteira.
</Note>
