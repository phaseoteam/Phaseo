Escolha um projeto de exemplo para executar localmente e adaptar. Para uma única chamada à API, use o [Início rápido](../quickstart.mdx); para um recurso específico, consulte o [Cookbook](../cookbook/index.mdx).

## Projetos executáveis

| O que criar | Passo a passo | Código-fonte |
| --- | --- | --- |
| Chat no navegador com uma chave de API no servidor | [Chat em Next.js](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| Autorização OAuth e um proxy no backend | [Workbench OAuth](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| Uma integração REST mínima | [App de teste rápido em Node](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| Um aplicativo de linha de comando em Python | [CLI em Python](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| Um aplicativo que usa o Vercel AI SDK | [Integração com o AI SDK](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

Mantenha as credenciais no servidor, revise as variáveis de ambiente do exemplo e verifique o preço do modelo selecionado antes de executá-lo. Exemplos que usam modelos `:free` não exigem créditos depositados.

## Solicitações por linguagem

A [referência do SDK de cliente](../sdk-reference/client/overview.mdx) contém exemplos de instalação e de solicitações por linguagem. Use a [referência de geração de imagens](../api-reference/endpoint/images-generations.mdx) para os parâmetros de imagem e [Chat Completions](../api-reference/endpoint/chat-completions.mdx) para solicitações de chat.

Para que um agente de programação crie a estrutura de um projeto, use os [prompts iniciais de mini-apps](../cookbook/mini-app-starter-prompts.mdx) e revise o código gerado antes de usá-lo com credenciais reais.
