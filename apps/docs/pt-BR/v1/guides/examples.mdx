Escolha um projeto de exemplo para executar localmente e adaptar. Para uma chamada de API, use o [Início rápido](../quickstart.mdx); para um recurso específico, consulte as [Receitas](../cookbook/index.mdx).

## Projetos executáveis

| Construção | Guia | Código-fonte |
| --- | --- | --- |
| Chat no navegador com chave de API no servidor | [Chat Next.js](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| Autorização OAuth e proxy backend | [Ambiente de trabalho OAuth](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| Uma integração REST mínima | [Aplicativo Node de teste rápido](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| Um aplicativo de linha de comando em Python | [Python CLI](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| Um aplicativo usando Vercel AI SDK | [Integração do AI SDK](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

Mantenha credenciais no servidor, revise as variáveis de ambiente do exemplo e confira o preço do modelo antes de executar. Exemplos com modelos `:free` não exigem créditos depositados.

## Solicitações por linguagem

A [referência dos SDKs cliente](../sdk-reference/typescript/overview.mdx) traz instalação e exemplos por linguagem. Use a [referência de geração de imagens](../api-reference/endpoint/images-generations.mdx) para parâmetros de imagens e [Chat Completions](../api-reference/endpoint/chat-completions.mdx) para chat.

Para um agente de programação criar a estrutura de um projeto, use os [prompts iniciais de miniaplicativos](../cookbook/mini-app-starter-prompts.mdx) e revise o código gerado antes de usar credenciais reais.
