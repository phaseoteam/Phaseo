Execute `phaseo cline` para iniciar uma sessão da CLI do Cline pelo Phaseo, ou crie uma chave com `phaseo setup cline` e adicione um provedor **OpenAI Compatible** na extensão do Cline. A extensão guarda as chaves no armazenamento de segredos do VS Code, então esse último passo é feito na interface dela.

## Execute a CLI do Cline pelo Phaseo

```bash
phaseo login
phaseo cline --model openai/gpt-5.6-terra -- --tui
```

O executor grava as configurações do Cline em um diretório temporário, inicia o `cline` e apaga o diretório quando o Cline é encerrado, então sua configuração atual do Cline ou do VS Code não é alterada. Se o Cline não estiver instalado, uma execução interativa oferece instalá-lo. Coloque as flags do próprio Cline depois de `--`.

| Flag | Efeito |
| --- | --- |
| `--model <id>` | Modelo a usar. O padrão é `openai/gpt-5.6-terra`. |
| `--catalog all` | Lista no Cline todos os modelos de texto ativos do Phaseo, não só o selecionado. |
| `--dry-run --json` | Mostra o plano de instalação e inicialização sem criar uma chave nem iniciar o Cline. |
| `--skip-install` | Pula a verificação de instalação. |

`phaseo run cline ...` é a forma longa do mesmo comando.

## Configure a extensão do Cline

Crie uma chave para a extensão:

```bash
phaseo login
phaseo setup cline --model anthropic/claude-sonnet-5.5
```

Depois, no VS Code:

1. Abra o painel do Cline e selecione o ícone de configurações, ou o provedor abaixo da caixa de chat.
2. Escolha **OpenAI Compatible** e preencha:

| Campo do Cline | Valor |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | Saída de `phaseo integrations credential cline` |
| Model ID | `anthropic/claude-sonnet-5.5`, ou o modelo mostrado pela configuração |

3. Salve o provedor. Se a sua versão mostrar **Verify**, selecione-o.
4. Selecione o modelo configurado para a próxima tarefa.

Para dispensar a CLI, use qualquer chave de API do Phaseo. A documentação de [configuração compatível com OpenAI](https://docs.cline.bot/enterprise-solutions/configuration/remote-configuration/openai-compatible/member-configuration) do Cline cobre configurações gerenciadas pela equipe.

## Confira se funciona

Peça ao Cline para responder com `PHASEO_CLINE_OK` e confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Remova o Phaseo

Exclua o provedor Phaseo no Cline ou troque para outro, depois execute:

```bash
phaseo integrations remove cline
```

Isso revoga a chave. A CLI não consegue limpar o armazenamento da extensão no VS Code, então a chave excluída pode continuar aparecendo no Cline até você removê-la ali.

## Corrija problemas comuns

### A verificação falha

Mantenha a Base URL exatamente como mostrada, incluindo `/v1`, e cole uma chave recém-obtida, sem aspas nem espaços.

### A lista de modelos está vazia

Digite o ID do modelo do Phaseo manualmente. O Cline não precisa descobrir os modelos.

### O chat funciona, mas as ferramentas falham

Escolha um modelo do Phaseo com suporte a chamada de ferramentas. Uma conexão funcionando não significa que o modelo aceita ferramentas.
