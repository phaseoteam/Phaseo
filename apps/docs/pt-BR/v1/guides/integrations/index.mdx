Aponte um cliente compatível com OpenAI ou com Anthropic para a URL base do Phaseo, informe uma chave de API do Phaseo e use os IDs de modelo do Phaseo, como `openai/gpt-6-astra`, sem alterações. Cada guia primeiro configura a ferramenta e depois mostra como conferir se ela funciona e o que não funciona.

| Tipo de cliente | URL base | Onde vai a chave |
| --- | --- | --- |
| Compatível com OpenAI | `https://api.phaseo.app/v1` | No campo de chave de API, enviada como `Authorization: Bearer` |
| Compatível com Anthropic (adiciona `/v1/messages` sozinho) | `https://api.phaseo.app` | No campo de token de autenticação, enviada como `Authorization: Bearer` |

Obtenha os IDs de modelo no [endpoint Models](../../api-reference/endpoint/models.mdx). Para apps novos no estilo OpenAI, use [Responses](../../api-reference/endpoint/responses.mdx); bibliotecas mais antigas funcionam com mais segurança em [Chat Completions](../../api-reference/endpoint/chat-completions.mdx). Defina `PHASEO_API_KEY` uma vez e associe-a à variável que a ferramenta espera, e teste o streaming e a chamada de ferramentas antes de migrar o tráfego de agentes.
