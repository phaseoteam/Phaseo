A maioria das integrações funciona apontando um cliente compatível com OpenAI ou Anthropic para o Phaseo e usando uma chave de API do Phaseo. Comece pelo guia da ferramenta que você já usa.

## URLs base

| Tipo de cliente | URL base |
| --- | --- |
| Clientes compatíveis com OpenAI | `https://api.phaseo.app/v1` |
| Clientes compatíveis com Anthropic | `https://api.phaseo.app` |

Use os IDs de modelo do [endpoint Models](../../api-reference/endpoint/models.mdx). Para novos apps no estilo OpenAI, prefira [Responses](../../api-reference/endpoint/responses.mdx). Para bibliotecas mais antigas, [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) costuma ser o caminho mais seguro.

## Padrões recomendados

- Configure `PHASEO_API_KEY` uma vez e mapeie-a para a variável de ambiente esperada pelo cliente.
- Mantenha o ID do modelo inalterado, por exemplo `openai/gpt-5-nano`.
- Use `https://api.phaseo.app/v1` em bibliotecas compatíveis com OpenAI, a menos que a ferramenta solicite explicitamente o host raiz.
- Use `https://api.phaseo.app` para SDKs e ferramentas compatíveis com Anthropic que acrescentam `/v1/messages`.
- Teste streaming e chamadas de ferramentas em staging antes de migrar o tráfego dos agentes.
