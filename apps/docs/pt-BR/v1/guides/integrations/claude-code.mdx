Execute `phaseo claude-code` para enviar as solicitações do Claude Code pelo Phaseo, ou defina você mesmo três variáveis de ambiente. O Claude Code chama `/v1/messages` no estilo da Anthropic, que o Phaseo atende como [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx), então os seus prompts não mudam.

## Configurar com a CLI do Phaseo

```bash
phaseo login
phaseo claude-code
claude
```

Se o Claude Code não estiver instalado, a CLI mostra o comando de instalação oficial e pergunta antes de executá-lo. Depois, a configuração:

- cria uma `Phaseo CLI: Claude Code API Key` que expira depois de 90 dias e tem um limite de gastos mensal de $100, e a guarda no armazenamento de credenciais do sistema operacional;
- define `ANTHROPIC_BASE_URL` e um `apiKeyHelper` em `~/.claude/settings.json`. O helper busca a chave na CLI e cria uma nova quando a antiga expira, então nenhuma chave em texto simples é gravada nas configurações do Claude Code.

A configuração para sem fazer alterações se `settings.json` já tiver um `ANTHROPIC_BASE_URL` diferente, um `apiKeyHelper` diferente, ou uma `ANTHROPIC_API_KEY` ou `ANTHROPIC_AUTH_TOKEN` não vazia. `--model` não é compatível com o Claude Code; defina `ANTHROPIC_MODEL` em vez disso (veja abaixo).

## Configurar o Claude Code manualmente

Defina estas variáveis no shell em que você inicia o Claude Code:

<CodeGroup>

```bash bash
export ANTHROPIC_BASE_URL="https://api.phaseo.app"
export ANTHROPIC_AUTH_TOKEN="your_phaseo_api_key"
export ANTHROPIC_API_KEY=""
```

```powershell PowerShell
$env:ANTHROPIC_BASE_URL = "https://api.phaseo.app"
$env:ANTHROPIC_AUTH_TOKEN = "your_phaseo_api_key"
$env:ANTHROPIC_API_KEY = ""
```

</CodeGroup>

O Claude Code envia `ANTHROPIC_AUTH_TOKEN` como cabeçalho `Authorization`, que o Phaseo aceita. Para fixar um modelo padrão, defina `ANTHROPIC_MODEL` com um ID de modelo do Phaseo de [Models](../../api-reference/endpoint/models.mdx).

## Conferir se funciona

Execute `claude`, envie um prompt curto e confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Remover o Phaseo

```bash
phaseo integrations remove claude-code
```

Isso remove a URL base, o helper da chave e as variáveis de credencial vazias que o Phaseo adicionou a `settings.json` e depois revoga a chave. Em uma configuração manual, remova as três variáveis de ambiente.

## Limitações conhecidas

- Teste os ciclos de ferramentas com streaming no seu fluxo de trabalho antes de migrar uma equipe.
- Adicione o servidor [Docs MCP](./docs-mcp.mdx) se quiser que o Claude Code leia a documentação do Phaseo durante uma sessão.
