Aponte o Anthropic SDK para `https://api.phaseo.app` e passe a sua chave do Phaseo como token de autenticação. Use isso em apps, agentes e ferramentas de programação que enviam solicitações `/v1/messages` no estilo do Claude; o Phaseo as atende como [Anthropic Messages](../../api-reference/endpoint/anthropic-messages.mdx).

## Instalar

<CodeGroup>

```bash TypeScript
npm install @anthropic-ai/sdk
```

```bash Python
pip install anthropic
```

</CodeGroup>

## Apontar o cliente para o Phaseo

<CodeGroup>

```ts TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
	apiKey: null,
	authToken: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app",
});

const message = await client.messages.create({
	model: "anthropic/claude-sonnet-5.5",
	max_tokens: 512,
	messages: [{ role: "user", content: "Reply with only: ok" }],
});

console.log(message.content);
```

```python Python
import os
from anthropic import Anthropic

client = Anthropic(
    auth_token=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app",
)

message = client.messages.create(
    model="anthropic/claude-sonnet-5.5",
    max_tokens=512,
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(message.content)
```

</CodeGroup>

Um bloco de texto com `ok` significa que a configuração funciona.

| Configuração | Por quê |
| --- | --- |
| `baseURL: "https://api.phaseo.app"` | Use o host raiz. Os clientes da Anthropic acrescentam `/v1/messages` por conta própria. |
| `authToken` (`auth_token` em Python) | Envia `Authorization: Bearer` em todas as versões do SDK. O Phaseo não aceita `x-api-key`, que o `apiKey` envia antes do `@anthropic-ai/sdk` 1.0 e do `anthropic` 2.0. |
| `apiKey: null` | Impede que SDKs TypeScript mais antigos também enviem a sua `ANTHROPIC_API_KEY`. Os SDKs Python anteriores à 0.98 a enviam sempre que ela está definida, então atualize ou remova a variável onde você chama o Phaseo. |

## Limitações conhecidas

- Os formatos nativos de ferramentas da Anthropic funcionam onde o Phaseo os suporta. As ferramentas do servidor que funcionam com vários provedores usam nomes de ferramenta do Phaseo; veja [Chamadas de ferramentas](../tool-calling.mdx).
- Os clientes compatíveis com a Anthropic são rígidos quanto à ordem dos eventos de ferramenta. Teste os ciclos de ferramentas com streaming antes de ir para produção.
- Para o [Claude Code](./claude-code.mdx), use o guia próprio dele.
