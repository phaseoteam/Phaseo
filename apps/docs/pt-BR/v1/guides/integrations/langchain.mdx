Crie um modelo `ChatOpenAI` com sua chave do Phaseo e `base_url="https://api.phaseo.app/v1"`, e as chains, os agentes e os workflows do LangGraph do LangChain chamam os modelos pelo Phaseo.

## Instale

```bash
pip install -U langchain langchain-openai
```

## Aponte o ChatOpenAI para o Phaseo

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

Se uma frase for impressa, a configuração funciona.

## Use no LangGraph

Passe o mesmo `llm` aos nós do grafo ou ao construtor de agentes:

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## Limitações conhecidas

- Este caminho usa [Chat Completions](../../api-reference/endpoint/chat-completions.mdx), então só funcionam os recursos do Phaseo disponíveis em `/v1/chat/completions`, incluindo [chamada de ferramentas](../tool-calling.mdx) e [roteamento e fallbacks](../routing-and-fallbacks.mdx).
- Para ferramentas de servidor exclusivas do Responses, como `phaseo:apply_patch`, chame o Phaseo diretamente ou use o [SDK da OpenAI](./openai-sdk.mdx).
- Para rastreamento com o LangSmith, veja [Observabilidade](./observability.mdx).
