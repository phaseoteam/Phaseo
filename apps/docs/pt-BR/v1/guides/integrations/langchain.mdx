Use este guia para que chains, agentes ou fluxos de trabalho do LangGraph chamem modelos pelo Phaseo.

## Instalação

```bash
pip install -U langchain langchain-openai
```

## Configure o ChatOpenAI

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-5-nano",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

## Use com o LangGraph

Passe o mesmo `llm` para os nós do grafo ou para o construtor do agente:

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## Observações

- O caminho compatível com OpenAI do LangChain usa Chat Completions. Use os recursos do Phaseo disponíveis em `/v1/chat/completions`.
- Para ferramentas de servidor exclusivas da Responses, como `phaseo:apply_patch`, chame o Phaseo diretamente ou consulte o guia do SDK da OpenAI.
- Para rastreamento, combine esta configuração com [Observabilidade](./observability.mdx).
