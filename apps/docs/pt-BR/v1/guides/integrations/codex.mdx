Execute `phaseo codex` para adicionar um perfil do Phaseo ao Codex, ou adicione você mesmo um provedor `phaseo` ao `config.toml`. A mesma configuração funciona no Codex CLI, no Codex App e na extensão do Codex para IDEs.

## Configure com a CLI do Phaseo

```bash
phaseo login
phaseo codex --model openai/gpt-5.6-terra
codex --profile phaseo
```

Se o Codex não estiver instalado, a CLI mostra o comando de instalação oficial e pede confirmação antes de executá-lo. Em seguida, a configuração abre uma página do painel em que você aprova uma `Phaseo CLI: Codex API Key` que expira após 90 dias e tem um limite de gastos mensal de $100. A CLI guarda a chave no armazenamento de credenciais do sistema operacional e grava o perfil em `~/.codex/phaseo.config.toml` (ou em `CODEX_HOME`). O Codex obtém a chave pela CLI, então nenhuma chave em texto puro é gravada na configuração. Quando a chave expirar, execute `phaseo codex` de novo para aprovar uma nova. Sem `--model`, o perfil usa `openai/gpt-5.6-terra`.

## Configure o Codex manualmente

Adicione isto a `~/.codex/config.toml`, ou a `.codex/config.toml` em um projeto confiável:

```toml
model = "openai/gpt-6-astra"
model_provider = "phaseo"

[model_providers.phaseo]
name = "Phaseo"
base_url = "https://api.phaseo.app/v1"
env_key = "PHASEO_API_KEY"
wire_api = "responses"
```

Depois, exporte `PHASEO_API_KEY` e inicie o Codex. Os provedores personalizados do Codex usam o protocolo Responses, que é o padrão, então você também pode omitir `wire_api`. Na extensão para IDEs, abra o arquivo em **Codex Settings → Open config.toml**.

## Confira se funciona

Envie um prompt curto e confirme que a solicitação aparece em **Configurações → Uso → Registros**. O Codex chama [Responses](../../api-reference/endpoint/responses.mdx), então o modelo precisa aceitar esse endpoint.

## Remova o Phaseo

```bash
phaseo integrations remove codex
```

Isso apaga `phaseo.config.toml` se o Phaseo o criou e revoga a chave. Em uma configuração manual, remova o provedor `phaseo` do `config.toml`.

## Corrija problemas comuns

| Erro | Correção |
| --- | --- |
| `401 Unauthorized` | Execute `phaseo whoami` e depois execute `phaseo codex` de novo. |
| `model_not_found` | Obtenha um ID atual em [Modelos](../../api-reference/endpoint/models.mdx) e atualize `model`. |
| Um provedor falha | Veja [Roteamento e fallbacks](../routing-and-fallbacks.mdx) para o failover. |

## Adicione as skills e a documentação do Phaseo

Para deixar o Codex ler a documentação atual do Phaseo enquanto trabalha, adicione o servidor [Docs MCP](./docs-mcp.mdx). Para instalar as [skills do Phaseo](https://phaseo.app/docs/.well-known/agent-skills/index.json) públicas no Codex:

```bash
npx skills add https://phaseo.app/docs --agent codex --skill '*'
```

O mesmo fluxo da CLI inicia o [Cline](./cline.mdx), o [Kilo Code](./kilo-code.mdx), o [oh-my-pi](./oh-my-pi.mdx), o [Muse Code](./muse-code.mdx) e o [MiniMax Code](./minimax-code.mdx) com configurações temporárias.
