O Codex oferece suporte a provedores de modelos personalizados por meio de `config.toml`. Assim, você pode encaminhar solicitações pelo Phaseo e manter seu fluxo de trabalho atual na CLI, no app ou no IDE.

Se também quiser que o Codex consulte a documentação atual da Phaseo durante o trabalho, adicione o servidor [Docs MCP](./docs-mcp.mdx).

## Configurar com a Phaseo CLI

```bash
phaseo login
phaseo codex --model openai/gpt-5.6-terra
```

Instale primeiro o Codex pela versão oficial. A configuração cria uma chave `Phaseo CLI: Codex API Key` sem expiração, armazena-a no gerenciador de credenciais do sistema operacional e grava um perfil Phaseo dedicado. O Codex obtém a chave pelo auxiliar da CLI, sem gravá-la em texto simples no `config.toml`.

### Inicie o Codex com:

```bash
codex --profile phaseo
```

## Configuração manual

Crie ou atualize a configuração do usuário em `~/.codex/config.toml`. Em um projeto confiável, você também pode colocar as mesmas opções em `.codex/config.toml` dentro do repositório.

```toml
model = "openai/gpt-5.5"
model_provider = "phaseo"

[model_providers.phaseo]
name = "Phaseo"
base_url = "https://api.phaseo.app/v1"
env_key = "PHASEO_API_KEY"
wire_api = "responses"
```

Atualmente, o Codex usa o protocolo Responses para provedores personalizados. Mantenha `wire_api = "responses"` ou omita a opção para usar o padrão.

O Codex App e a extensão IDE compartilham as mesmas camadas de configuração. Na extensão IDE, abra o arquivo em `Codex Settings > Open config.toml`.

## Verificação

- Antes de iniciar, confirme em [Modelos](../../api-reference/endpoint/models.mdx) se o ID do modelo existe.
- Use [Responses](../../api-reference/endpoint/responses.mdx) para o fluxo padrão do Codex.

## Solução de problemas

- `401 Unauthorized`: execute `phaseo whoami` e depois execute `phaseo codex` novamente.
- `model_not_found`: obtenha um ID atual em [Modelos](../../api-reference/endpoint/models.mdx) e atualize `model`.
- Problemas específicos do provedor: consulte [Roteamento e fallbacks](../routing-and-fallbacks.mdx) para entender a alternância.
