Crie o adaptador `openaiCompatible` do TanStack AI com sua chave do Phaseo, `baseURL: "https://api.phaseo.app/v1"` e os IDs de modelo do Phaseo que você usa. Ele serve para chat com tipagem segura em React, Solid, Preact, Vue, Svelte ou TypeScript no servidor.

## Instale

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## Aponte o adaptador para o Phaseo

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-6-astra", "anthropic/claude-sonnet-5.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-6-astra"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

Declare em `models` todos os IDs de modelo do Phaseo que você pretende usar. Confira os IDs em [Modelos](../../api-reference/endpoint/models.mdx).

## Limitações conhecidas

- O adaptador usa Chat Completions. Para recursos exclusivos do Responses, chame o Phaseo diretamente ou use o [SDK da OpenAI](./openai-sdk.mdx).
- Se um modelo não aceitar [ferramentas](../tool-calling.mdx) ou imagens, declare recursos mais restritos no TanStack AI para que o TypeScript detecte chamadas não suportadas.
