Faça a rotação das chaves de API do Phaseo sem indisponibilidade: crie uma chave substituta com uma [chave de gerenciamento](../../developers/management-api-keys.mdx), troque seu app para ela e depois exclua a antiga. Esta página traz os valores que uma conexão do Infisical usa nessa rotação.

<Warning>
O Phaseo ainda não é uma App Connection selecionável no Infisical. O conector, os testes e a entrada na interface ainda precisam ser aceitos no Infisical. Até lá, use as solicitações abaixo no seu próprio job de rotação.
</Warning>

## Como a rotação funciona

```mermaid
flowchart LR
  mk["Chave de gerenciamento"] -->|"POST /v1/keys"| newkey["Nova chave de API"]
  newkey -->|"Guardar no segredo"| app["O app usa a nova chave"]
  app -->|"DELETE /v1/keys/{id}"| old["Chave antiga revogada"]
```

O Phaseo mostra o valor de uma chave de API só uma vez, quando ela é criada. A chave antiga e a nova funcionam até você excluir a antiga, então seu app pode fazer a troca enquanto o segredo é atualizado.

## Crie uma chave de gerenciamento com escopo restrito

Em **Configurações → Chaves de gerenciamento**, crie uma chave com estas permissões:

| Permissão | Usada para |
| --- | --- |
| `keys:read` | Verificar a conexão e listar as chaves gerenciadas. |
| `keys:write` | Criar chaves substitutas. |
| `keys:delete` | Revogar chaves antigas. |

Guarde o valor `phaseo_v1_mk_...` no Infisical. As chaves de gerenciamento controlam sua conta e não podem ser usadas para inferência.

## Detalhes da conexão

| Campo | Valor |
| --- | --- |
| URL base | `https://api.phaseo.app/v1` |
| Autenticação | `Authorization: Bearer <PHASEO_MANAGEMENT_KEY>` |
| Verificar a conexão | `GET /keys` |
| Listar chaves de API | `GET /keys` |
| Criar uma chave de API | [`POST /keys`](../../api-reference/endpoint/keys-create.mdx) |
| Revogar uma chave de API | [`DELETE /keys/{id}`](../../api-reference/endpoint/keys-delete.mdx) |

## Crie a chave substituta

```bash
curl https://api.phaseo.app/v1/keys \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "infisical-production",
    "limit": 100,
    "limit_reset": "monthly",
    "include_byok_in_limit": false
  }'
```

A resposta traz a nova chave uma única vez em `data.key`, e o ID dela em `data.id`.

| Campo | Valores |
| --- | --- |
| `limit` | Limite de gastos em dólares americanos. |
| `limit_reset` | `daily`, `weekly` ou `monthly`. |
| `include_byok_in_limit` | Aceito só por compatibilidade. O uso BYOK nunca conta para este limite. |

## Revogue a chave antiga

```bash
curl -X DELETE https://api.phaseo.app/v1/keys/$PREVIOUS_KEY_ID \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY"
```

A exclusão é idempotente: excluir uma chave que já foi excluída retorna `200` com `{"deleted": true}`, então repetir uma rotação é seguro.
