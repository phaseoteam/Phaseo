Execute `phaseo login` e depois `phaseo <agent>` para apontar um agente de programação para o Phaseo com uma chave de API própria. Para dispensar a CLI, informe os [valores manuais do provedor](#enter-the-provider-values-yourself) nas configurações do agente.

```bash
phaseo login
phaseo codex
```

## Encontre o comando do seu agente

A CLI configura cada agente de uma de três formas:

- **Configurado**: a CLI grava o arquivo de configuração do agente. Inicie o agente e escolha um modelo do Phaseo.
- **Só a chave**: o agente guarda as chaves no armazenamento do próprio app, então a CLI cria a chave e mostra os campos a preencher.
- **Sessão**: a CLI inicia o agente com configurações temporárias, que são apagadas quando ele é encerrado. Sua configuração normal não é alterada.

| --- | --- | --- | --- |

| Pi | `phaseo pi` | Configurado | [Pi](./pi.mdx) |
| Prime Agent | `phaseo prime-agent` | Configurado | [Prime Agent](./prime-agent.mdx) |

## O que a CLI cria

Cada agente recebe sua própria chave de API, com o nome dele (por exemplo, `Phaseo CLI: Codex API Key`). A chave expira após 90 dias e tem um limite de gastos mensal de $100. Execute o comando de configuração de novo para substituir uma chave expirada e aumente o limite com `phaseo keys update <id> --limit`.

Se o Claude Code, o Codex, o OpenCode, o fx, o DeepSeek Harness, o Pi, o Prime Agent, o OpenClaw ou o Hermes Agent não estiver instalado, a CLI mostra o comando de instalação oficial e pede confirmação antes de executá-lo. Fora de um terminal interativo, ela mostra o comando de instalação e para. O OpenCode, o fx, o DeepSeek Harness, o Pi, o Prime Agent e o OpenClaw também recebem todos os modelos de texto ativos do Phaseo que funcionam com Chat Completions.

| Flag ou comando | Efeito |
| --- | --- |
| `--model <id>` | Define o modelo padrão. Não é aceito no Claude Code. |
| `--catalog default` | Adiciona só o modelo selecionado, em vez do catálogo inteiro. |
| `--skip-install` | Pula a verificação de instalação, para um agente que você mesmo gerencia. |
| `--dry-run` | Mostra as alterações nos arquivos sem aplicá-las. |
| `phaseo integrations credential <agent>` | Mostra a chave daquele agente, para agentes em que você a cola manualmente. |
| `phaseo integrations remove <agent>` | Apaga a configuração que o Phaseo gravou e revoga a chave. Suas outras configurações continuam. |

## Informe você mesmo os valores do provedor

Use estes valores em qualquer agente que tenha um provedor compatível com OpenAI. Os nomes dos campos variam de ferramenta para ferramenta.

| Configuração | Valor |
| --- | --- |
| Tipo de provedor | OpenAI Compatible |
| Base URL | `https://api.phaseo.app/v1` |
| Chave de API | Uma chave de API do Phaseo |
| Modelo | Um ID de modelo do Phaseo, como `openai/gpt-6-astra` |

Para agentes que usam a API Messages da Anthropic:

| Configuração | Valor |
| --- | --- |
| Base URL | `https://api.phaseo.app` (o cliente adiciona `/v1/messages`) |
| Token de autenticação | Uma chave de API do Phaseo |
| Modelo | Um ID de modelo do Phaseo, como `anthropic/claude-sonnet-5.5` |

Alguns agentes rejeitam IDs de modelo que contêm `/`. Se o seu fizer isso e aceitar aliases, crie um alias local que aponte para o ID do modelo do Phaseo.

## Agentes sem guia próprio

### VS Code

O VS Code pode adicionar modelos no editor Language Models quando a sua build inclui um provedor compatível com OpenAI.

1. Abra a Command Palette e execute `Chat: Manage Language Models`.
2. Escolha `OpenAI Compatible` ou `OAI Compatible`.
3. Informe sua chave de API do Phaseo e defina o endpoint como `https://api.phaseo.app/v1`.
4. Adicione um ID de modelo do Phaseo, como `openai/gpt-6-astra`, e selecione-o no seletor de modelos do chat.

Se a sua build não tiver um provedor compatível com OpenAI, use uma extensão que aceite provedores personalizados: [Continue](./continue.mdx), [Cline](./cline.mdx), [Roo Code](./roo-code.mdx) ou [Kilo Code](./kilo-code.mdx).

### Claude Desktop

O Claude Desktop não consegue usar um provedor de modelos personalizado. Adicione o [Docs MCP](./docs-mcp.mdx) para dar a ele a documentação do Phaseo e use o [Claude Code](./claude-code.mdx) quando precisar do Phaseo como gateway de modelos.

### Deep Agents CLI e outras ferramentas do LangChain

Use a URL base e a chave de [LangChain](./langchain.mdx). Se a ferramenta ler variáveis de ambiente da OpenAI, defina estas e informe um ID de modelo do Phaseo no campo de modelo:

```bash
export OPENAI_API_KEY="your_phaseo_api_key"
export OPENAI_BASE_URL="https://api.phaseo.app/v1"
```

## Limitações conhecidas

- As ferramentas de servidor só funcionam onde o agente as envia: `phaseo:apply_patch` está disponível apenas em [Responses](../../api-reference/endpoint/responses.mdx). Agentes mais antigos que não lidam com eventos do Responses nem com [ferramentas de servidor](../server-tools/index.mdx) funcionam com mais segurança em [Chat Completions](../../api-reference/endpoint/chat-completions.mdx).
- Envie uma solicitação curta de chat antes de deixar um agente editar arquivos e escolha um modelo com suporte a chamada de ferramentas para trabalho de agente.
- Adicione o [Docs MCP](./docs-mcp.mdx) se quiser que o agente leia a documentação do Phaseo durante uma sessão.
