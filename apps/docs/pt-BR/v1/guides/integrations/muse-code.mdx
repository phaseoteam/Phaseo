Execute `phaseo muse` para iniciar uma sessão do Muse Code pelo Phaseo. Esse executor é a única forma suportada de usar o Phaseo com o Muse Code.

## Execute o Muse Code pela CLI do Phaseo

```bash
phaseo login
phaseo muse --model meta/muse-spark-1.3
```

O executor cria uma chave dedicada, grava as configurações do Muse em um `XDG_CONFIG_HOME` temporário, inicia o `muse` e apaga as configurações quando o Muse Code é encerrado. Coloque as flags do próprio Muse Code depois de `--`.

| Flag | Efeito |
| --- | --- |
| `--model <id>` | Modelo a usar. O padrão é `openai/gpt-5.6-terra`. |
| `--catalog all` | Lista todos os modelos de texto ativos do Phaseo, não só o selecionado. |
| `--dry-run --json` | Mostra o plano de inicialização sem criar uma chave nem iniciar o Muse Code. |
| `--skip-install` | Pula a verificação de instalação. |

`phaseo run muse ...` é a forma longa do mesmo comando.

No macOS e no Linux, a primeira execução interativa oferece instalar o Muse Code com o instalador da Meta. No Windows, instale o Muse Code você mesmo, confira `muse --version` e use `--skip-install`.

## Por que não há configuração manual

O Muse Code foi feito em torno da própria [Model API](https://ai.meta.com/llama) e do login da Meta. A Meta não documenta uma configuração estável para apontá-lo para outro endpoint compatível com OpenAI, então use o executor. Não copie as configurações temporárias do executor para o seu perfil normal do Muse; elas são um detalhe interno e são apagadas quando o executor é encerrado.

Para chamar um modelo do Phaseo no seu próprio código, use o [SDK da OpenAI](./openai-sdk.mdx) com `https://api.phaseo.app/v1` e uma chave de API do Phaseo.

## Confira se funciona

Envie um prompt curto e confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Corrija problemas comuns

### O Muse Code não está instalado

Instale o Muse Code você mesmo, confira `muse --version` e execute de novo com `--skip-install`.

### O modelo não aparece na lista

Use `--catalog all`, ou informe o ID do modelo com `--model`. O Phaseo não precisa da descoberta de modelos.
