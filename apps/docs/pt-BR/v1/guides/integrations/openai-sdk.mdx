Aponte o SDK oficial da OpenAI para o Phaseo mudando três coisas: a chave de API, a URL base (`https://api.phaseo.app/v1`) e o ID do modelo.

## Instale

<CodeGroup>

```bash TypeScript
npm install openai
```

```bash Python
pip install openai
```

</CodeGroup>

## Aponte o cliente para o Phaseo

<CodeGroup>

```ts TypeScript
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Write one sentence about reliable model routing.",
});

console.log(response.output_text);
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Write one sentence about reliable model routing.",
)

print(response.output_text)
```

</CodeGroup>

Se uma frase for impressa, a chave e a URL base funcionam. A solicitação também aparece em **Configurações → Uso → Registros**.

## Use Chat Completions

Código que chama Chat Completions funciona com o mesmo cliente:

```ts
const completion = await client.chat.completions.create({
	model: "openai/gpt-6-astra",
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## Limitações conhecidas

- Use os IDs de modelo do Phaseo, com o prefixo do provedor: `openai/`, `anthropic/`, `google/` e assim por diante. Veja [Responses](../../api-reference/endpoint/responses.mdx) e [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) para o formato completo das solicitações.
- As [ferramentas de servidor](../server-tools/index.mdx) usam nomes de ferramenta do Phaseo, como `phaseo:web_search`.
- Para clientes `/v1/messages` no estilo da Anthropic, use o guia do [Anthropic SDK](./anthropic-sdk.mdx).
