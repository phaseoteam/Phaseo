A Phaseo oferece um provedor oficial para o Vercel AI SDK no pacote `@phaseo/ai-sdk-provider`.

## Instalação

O AI SDK 7 e a implementação nativa `ProviderV4` da Phaseo são os padrões para novos projetos:

```bash
npm install @phaseo/ai-sdk-provider
```

O pacote da Phaseo sem versão segue a tag `latest` do npm e, por isso, seleciona a linha ativa do provedor compatível com o AI SDK 7. O pacote declara o AI SDK 7 como dependência peer, que o npm instala automaticamente.

### Linha de manutenção do AI SDK 6

O AI SDK 6 usa o contrato anterior `ProviderV3`. Instale a versão de compatibilidade identificada pela tag correspondente:

```bash
npm install @phaseo/ai-sdk-provider@ai-sdk-v6
```

O provedor 1.x da Phaseo permanece em manutenção enquanto o AI SDK 7 for a versão atual. Quando o AI SDK 8 alcançar uma versão estável, a Phaseo marcará a linha 1.x como obsoleta no npm. Isso não remove as versões existentes; qualquer decisão futura sobre o fim do suporte será anunciada separadamente.

### Compatibilidade com o AI SDK 5

O AI SDK 5 aceita o contrato anterior `ProviderV2`. Instale a versão de compatibilidade específica da Phaseo:

```bash
npm install @phaseo/ai-sdk-provider@ai-sdk-v5
```

Se seu gerenciador de pacotes não instalar dependências peer automaticamente, instale separadamente a versão principal correspondente de `ai` (`ai@^7`, `ai@^6` ou `ai@^5`).

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
	model: phaseo("openai/gpt-4o"),
	prompt: "Summarize this in one sentence.",
});
```

A linha v5 oferece suporte à geração e transmissão de texto, ferramentas, saída estruturada, embeddings, imagens, transcrição e fala. A reclassificação padronizada está disponível nos contratos de provedor do AI SDK 6 e 7.

## Uso básico

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
	model: phaseo("openai/gpt-4o"),
	prompt: "Summarize this in one sentence.",
});
```

## Recursos compatíveis com o AI SDK 7

O Provider 2.x implementa e testa os contratos nativos v4 do AI SDK 7 para:

- geração e transmissão de texto
- configurações de raciocínio independentes do provedor e saída de raciocínio
- ferramentas de função padrão, entradas de ferramenta transmitidas e ciclos de retorno dos resultados
- saída estruturada em JSON e JSON Schema
- entradas de arquivos de texto e imagem no formato marcado de dados de arquivo do V7
- fontes de citação de URL
- embeddings e geração de imagens
- reclassificação
- transcrição e geração de fala
- metadados do provedor, uso, cabeçalhos de requisição, sinais de cancelamento e blocos brutos do fluxo

Use IDs de modelo do [endpoint de modelos](../../api-reference/endpoint/models.mdx). Os recursos disponíveis também dependem do modelo selecionado e do provedor upstream.

## Reclassificação e limites de recursos

A reclassificação está disponível pelo helper `rerank()` do AI SDK e por `phaseo.rerankingModel(modelId)`. O provedor não anuncia recursos do ProviderV4 que dependem de superfícies da API da Phaseo ainda não expostas, como uploads e referências de arquivos gerenciados, skills e definições, resultados ou respostas de aprovação de ferramentas executadas pelo provedor. As ferramentas de função executadas pelo aplicativo continuam usando o fluxo normal de execução e aprovação do AI SDK. Partes de prompt personalizadas ou específicas de um provedor que não são compatíveis retornam um erro claro em vez de serem descartadas sem aviso.

```typescript
import { rerank } from "ai";
import { phaseo } from "@phaseo/ai-sdk-provider";

const result = await rerank({
  model: phaseo.rerankingModel("voyage/rerank-2"),
  query: "Which document is about TypeScript?",
  documents: [
    "TypeScript adds static types to JavaScript.",
    "Rust is a systems programming language.",
  ],
  topN: 1,
});
```
