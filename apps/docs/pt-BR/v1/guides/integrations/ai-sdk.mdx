Instale `@phaseo/ai-sdk-provider` e passe `phaseo("<model id>")` como modelo em qualquer chamada do AI SDK. O provedor lê `PHASEO_API_KEY` do ambiente.

## Instalar

```bash
npm install @phaseo/ai-sdk-provider
```

O pacote sem versão segue a tag `latest` do npm, que é a linha do AI SDK 7, e declara `ai@^7` como dependência peer, que o npm instala para você. Para um AI SDK mais antigo, instale a tag correspondente:

| AI SDK | Contrato do provedor | Instalação |
| --- | --- | --- |
| 7 (atual) | `ProviderV4` (provedor 2.x) | `npm install @phaseo/ai-sdk-provider` |
| 6 | `ProviderV3` (provedor 1.x, em manutenção) | `npm install @phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `ProviderV2` | `npm install @phaseo/ai-sdk-provider@ai-sdk-v5` |

Se o seu gerenciador de pacotes não instala dependências peer, instale também a versão principal correspondente de `ai` (`ai@^7`, `ai@^6` ou `ai@^5`).

Quando o AI SDK 8 estiver estável, o Phaseo vai marcar o provedor 1.x como obsoleto no npm. As versões existentes não serão removidas, e qualquer fim de suporte será anunciado separadamente.

## Gerar texto

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Summarize this in one sentence.",
});

console.log(result.text);
```

O mesmo código funciona nas três linhas. Use IDs de modelo do [endpoint Models](../../api-reference/endpoint/models.mdx); cada recurso ainda depende do modelo e do provedor upstream.

## O que cada linha suporta

| Recurso | AI SDK 7 (provedor 2.x) | AI SDK 5 |
| --- | --- | --- |
| Geração de texto e streaming | Sim | Sim |
| Ferramentas de função e idas e voltas com resultados de ferramentas | Sim, incluindo entradas de ferramenta transmitidas | Sim |
| Saída estruturada em JSON e JSON Schema | Sim | Sim |
| Embeddings e geração de imagens | Sim | Sim |
| Transcrição e fala | Sim | Sim |
| Reranqueamento | Sim | Não |
| Configurações e saída de raciocínio independentes do provedor | Sim | |
| Entradas de arquivo de texto e de imagem (dados de arquivo com tag do V7) | Sim | |
| Fontes de citação por URL | Sim | |
| Metadados do provedor, uso, cabeçalhos da solicitação, sinais de cancelamento, blocos brutos do stream | Sim | |

A coluna do AI SDK 7 é o que o provedor 2.x implementa e testa com os contratos v4 nativos do AI SDK 7. O reranqueamento também está disponível na linha do AI SDK 6.

## Reranquear documentos

Use o helper `rerank()` do AI SDK com `phaseo.rerankingModel(modelId)`:

```ts
import { rerank } from "ai";
import { phaseo } from "@phaseo/ai-sdk-provider";

const result = await rerank({
	model: phaseo.rerankingModel("voyage/rerank-2"),
	query: "Which document is about TypeScript?",
	documents: [
		"TypeScript adds static types to JavaScript.",
		"Rust is a systems programming language.",
	],
	topN: 1,
});
```

## Limitações conhecidas

- O provedor não anuncia recursos do `ProviderV4` que dependem de superfícies da API do Phaseo que ainda não existem: uploads e referências de arquivos gerenciados, skills e definições, resultados ou respostas de aprovação de ferramentas executadas pelo provedor.
- As ferramentas de função que o seu app executa continuam usando o fluxo normal de execução e aprovação do AI SDK.
- Partes de prompt específicas de provedor ou personalizadas que não são compatíveis falham com um erro claro em vez de serem descartadas.
