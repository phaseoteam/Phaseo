Execute `phaseo minimax` para iniciar uma sessão do MiniMax Code (`mcode`) pelo Phaseo, ou adicione o Phaseo com `mcode provider add` para mantê-lo em todas as sessões.

## Execute o MiniMax Code pela CLI do Phaseo

```bash
phaseo login
phaseo minimax --model openai/gpt-5.6-terra
```

O executor cria uma chave dedicada, define `MINIMAX_DATA_DIR` como um diretório temporário, adiciona ali um provedor Phaseo com `mcode provider add`, inicia o `mcode` e apaga o diretório quando o `mcode` é encerrado. Sua configuração normal em `~/.minimax` não é alterada, e a chave só é passada ao processo de configuração do provedor. Coloque as flags do próprio MiniMax Code depois de `--`.

| Flag | Efeito |
| --- | --- |
| `--model <id>` | Modelo a usar. O padrão é `openai/gpt-5.6-terra`. |
| `--catalog all` | Registra todos os modelos de texto ativos do Phaseo que funcionam com Chat Completions. |
| `--dry-run --json` | Mostra o plano de instalação e inicialização sem criar uma chave. |
| `--skip-install` | Pula a verificação de instalação. |

`phaseo run minimax ...` é a forma longa do mesmo comando.

Se o `mcode` não estiver instalado, a primeira execução interativa oferece instalá-lo com o instalador oficial da MiniMax (o instalador do PowerShell no Windows). Se você mesmo gerencia o MiniMax Code, instale-o, confira `mcode --version` e execute de novo com `--skip-install`.

## Configure o MiniMax Code manualmente

Para manter um provedor Phaseo, adicione-o com o comando do próprio MiniMax Code:

```bash
export MCODE_PROVIDER_API_KEY="your_phaseo_api_key"
mcode provider add \
  --name "Phaseo" \
  --base-url "https://api.phaseo.app/v1" \
  --api-format openai-completions \
  --model "openai/gpt-5.6-terra" \
  --use
```

O MiniMax Code salva o provedor no diretório de dados dele.

## Confira se funciona

Envie um prompt curto e confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Corrija problemas comuns

### O MiniMax Code não está instalado

Execute o comando em um terminal interativo para aprovar o instalador oficial, ou instale você mesmo o MiniMax Code e execute de novo com `--skip-install`.

### O provedor ou o modelo não aparece na lista

Use `phaseo minimax --catalog all`, ou informe o ID do modelo com `--model`.

### Você precisa do ACP em vez da CLI interativa

`phaseo minimax` executa a CLI interativa. O MiniMax Code também roda como processo ACP com `mcode acp`; use a configuração ACP do MiniMax Code quando o seu editor ou host usar ACP diretamente.
