Execute `phaseo prime-agent` para adicionar ao Prime Agent um provedor Phaseo com todos os modelos compatíveis do Phaseo. O Prime Agent roda no macOS e no Linux; no Windows, instale-o e execute a configuração dentro do WSL.

## Configure com a CLI do Phaseo

```bash
phaseo login
phaseo prime-agent
```

Se o Prime Agent não estiver instalado, a CLI mostra o comando do instalador oficial e pede confirmação antes de executá-lo. Em seguida, a configuração cria uma `Phaseo CLI: Prime Agent API Key` (expira em 90 dias, limite de gastos mensal de $100) e grava um provedor `phaseo` em `~/.prime/agent/models.json`. O provedor lista todos os modelos de texto ativos do Phaseo que funcionam com Chat Completions.

| Flag | Efeito |
| --- | --- |
| `--model <id>` | Define o modelo inicial. O padrão é `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | Adiciona só o modelo selecionado. |
| `--dry-run` | Mostra as alterações nos arquivos sem aplicá-las. |

O provedor obtém a chave no momento da solicitação com o formato de chave baseado em comando do Prime Agent, então nenhuma chave em texto puro é gravada no arquivo:

```text
!phaseo integrations credential prime-agent
```

## Confira se funciona

```bash
prime-agent
```

Abra `/model`, selecione o provedor `phaseo` e envie um prompt curto. Confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Remova o Phaseo

```bash
phaseo integrations remove prime-agent
```

Isso remove só o provedor do Phaseo e revoga a chave.
