Adicione `https://phaseo.app/docs/mcp` ao seu agente de programação como servidor MCP para que ele responda perguntas sobre o Phaseo com base na documentação atual, e não nos dados de treinamento. O servidor é somente leitura: os agentes podem pesquisar a documentação, ler páginas inteiras e ler o resumo de recursos [skill.md](https://phaseo.app/docs/skill.md) hospedado.

## Codex

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
codex mcp list
```

## Claude Code

Adicione o servidor ao projeto atual, ou acrescente `--scope user` para deixá-lo disponível em todos os projetos:

```bash
claude mcp add --transport http phaseo-docs https://phaseo.app/docs/mcp
claude mcp add --transport http --scope user phaseo-docs https://phaseo.app/docs/mcp
claude mcp list
```

## Cursor

Instale-o pelo menu contextual de qualquer página da documentação, ou adicione-o à configuração MCP do Cursor:

```json
{
  "mcpServers": {
    "phaseoDocs": {
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## VS Code

Instale-o pelo menu contextual de qualquer página da documentação, ou adicione-o à configuração MCP do VS Code:

```json
{
  "servers": {
    "phaseoDocs": {
      "type": "http",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## OpenCode

Adicione-o ao `opencode.json`:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "phaseoDocs": {
      "type": "remote",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## Confira se funciona

Pergunte ao agente algo que só a documentação responde e confira se ele chama o servidor de documentação do Phaseo:

- `Look up the Responses request format in the Phaseo docs and give me a minimal example.`
- `Use the Phaseo docs MCP server to check how provider.sort works before you change this request.`
- `Find the guardrails docs in Phaseo and summarize the parts that affect provider routing.`

Os agentes o usam para conferir o formato das solicitações, quais endpoints um modelo ou provedor aceita e como se comportam o roteamento, as predefinições, os guardrails e os jobs assíncronos. O servidor de documentação não transforma o Phaseo no seu gateway de modelos; para isso, veja [Agentes de programação](./coding-assistants.mdx).
