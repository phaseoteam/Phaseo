Passe um modelo do [provedor Phaseo para AI SDK](./ai-sdk.mdx) ao seu agente do [eve](https://eve.dev), e toda chamada de modelo passa pelo Phaseo com seu roteamento, suas chaves, seus orçamentos e seus registros. O eve aceita qualquer modelo de linguagem do AI SDK.

## Instale

O eve usa o AI SDK 7, então instale o `@phaseo/ai-sdk-provider` 2.0.1 ou posterior:

```bash
npm install @phaseo/ai-sdk-provider
```

Defina `PHASEO_API_KEY` no `.env.local` para o `eve dev` e no ambiente do servidor de cada implantação. A conexão `/login` do eve só funciona na sua máquina.

## Aponte um agente do eve para o Phaseo

```ts agent/agent.ts
import { defineAgent } from "eve";
import { phaseo } from "@phaseo/ai-sdk-provider";

export default defineAgent({
	model: phaseo("openai/gpt-6-astra"),
	modelContextWindowTokens: 922_000,
	reasoning: "low",
});
```

Passe um objeto de modelo como `phaseo("openai/gpt-6-astra")`; uma string simples com o ID do modelo não é enviada ao Phaseo. Defina `modelContextWindowTokens` com o `limits.input_tokens` do modelo, obtido no [endpoint Models](../../api-reference/endpoint/models.mdx). O eve não consegue consultar a janela de contexto de um objeto de modelo e usa esse número para decidir quando compactar a conversa.

Execute o agente uma vez e confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Escolha um modelo a cada turno

`defineDynamic` é executado antes de cada chamada de modelo. Retorne um objeto de seleção para que cada modelo mantenha a própria janela de contexto:

```ts agent/agent.ts
import { defineAgent } from "eve";
import { defineDynamic } from "eve/models";
import { phaseo } from "@phaseo/ai-sdk-provider";

export default defineAgent({
	model: defineDynamic((ctx) =>
		ctx.session.auth.initiator?.attributes.plan === "enterprise"
			? { model: phaseo("openai/gpt-6-sol"), modelContextWindowTokens: 1_050_000 }
			: { model: phaseo("openai/gpt-6-luna"), modelContextWindowTokens: 1_050_000 },
	),
});
```

## Limitações conhecidas

- Ferramentas, streaming, raciocínio, compactação e cache de prompts funcionam pelo Phaseo. As leituras do cache de prompts aparecem nos eventos de uso do eve e nos registros do Phaseo.
- O eve deixa vazio o custo de cada execução quando se usam objetos de modelo. Veja o custo na página **Uso** do Phaseo ou em **Registros**.
