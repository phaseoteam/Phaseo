Use a CLI Phaseo para adicionar o provedor e o modelo ao Zed e salve a chave no chaveiro do Zed. Para dispensar a CLI, insira os mesmos valores do provedor manualmente.

## Configure com a CLI Phaseo

```bash
phaseo login
phaseo zed --model openai/gpt-5.6-terra
```

A CLI adiciona o ID do provedor `phaseo`, a URL da API `https://api.phaseo.app/v1` e o modelo selecionado ao `settings.json` do Zed sem alterar outras configurações.

## Conclua a configuração no Zed

O Zed armazena as chaves dos provedores no chaveiro do sistema, então esta é a única etapa restante na interface.

1. Abra a paleta de comandos e execute **agent: open settings**.
2. Em **AI**, selecione **LLM Providers → Configure**.

![Configurações de IA do Zed com LLM Providers destacado](/images/integrations/zed-agent-settings.png)

3. Se o Phaseo já aparecer, abra-o e cole a chave dedicada. Caso contrário, selecione **Add Provider → OpenAI**.

![Página LLM Providers do Zed com Add Provider](/images/integrations/zed-llm-providers.png)

4. Como alternativa manual, informe:

| Campo | Valor |
| --- | --- |
| Provider Name | `Phaseo` |
| API URL | `https://api.phaseo.app/v1` |
| API Key | Saída de `phaseo integrations credential zed` |
| Model Name | ID do modelo Phaseo selecionado |

![Formulário do Zed para adicionar um provedor compatível com OpenAI](/images/integrations/zed-add-compatible-provider.png)

Não selecione **Save Provider** antes de preencher a URL base, o ID do modelo e a chave.

## Verificar

Abra uma nova conversa do Agent, selecione o modelo Phaseo e envie uma solicitação curta. Se o Zed informar que a chave é inválida, execute `phaseo integrations credential zed` novamente e substitua a chave salva no Zed.

## Remover

```bash
phaseo integrations remove zed
```

A CLI remove o provedor Phaseo do `settings.json` e revoga a chave dedicada. Se o Zed ainda mostrar a entrada antiga do chaveiro, remova também o Phaseo de **LLM Providers**.
