Execute `phaseo continue` para gravar uma configuração do Continue que aponta para o Phaseo, ou adicione a mesma entrada de modelo e o mesmo segredo à sua configuração atual. As extensões para IDEs e a CLI `cn` compartilham a configuração.

## Configure com a CLI do Phaseo

```bash
phaseo login
phaseo continue --model anthropic/claude-sonnet-5.5
```

Se `~/.continue/config.yaml` e `~/.continue/.env` não existirem, a configuração cria uma `Phaseo CLI: Continue API Key` (expira em 90 dias, limite de gastos mensal de $100) e grava os dois arquivos. Sem `--model`, ela usa `anthropic/claude-sonnet-4.6`.

```yaml ~/.continue/config.yaml
# Managed by Phaseo CLI
name: Phaseo
version: 1.0.0
schema: v1
models:
  - name: "anthropic/claude-sonnet-5.5 via Phaseo"
    provider: openai
    model: "anthropic/claude-sonnet-5.5"
    apiBase: https://api.phaseo.app/v1
    apiKey: ${{ secrets.PHASEO_API_KEY }}
    useResponsesApi: false
    roles: [chat, edit, apply]
```

A chave fica em `~/.continue/.env` como `PHASEO_API_KEY`. `useResponsesApi: false` mantém o Continue no endpoint Chat Completions do Phaseo.

<Warning>
O `.env` global do Continue fica em texto puro. Nunca faça commit dele. As extensões para IDEs não herdam as variáveis de ambiente do shell, por isso a CLI usa o arquivo de [segredos locais](https://docs.continue.dev/faqs#managing-local-secrets-and-environment-variables) do Continue.
</Warning>

## Configure o Continue manualmente

Se algum dos arquivos já tiver configurações suas, a configuração para sem alterá-lo. Adicione a entrada de modelo acima ao seu `config.yaml` e adicione `PHASEO_API_KEY=<key>` ao seu `.env`, usando `phaseo integrations credential continue` ou qualquer chave de API do Phaseo. Veja a documentação do [provedor OpenAI](https://docs.continue.dev/customize/model-providers/top-level/openai) do Continue para os outros campos.

## Confira se funciona

No VS Code ou no JetBrains, recarregue a janela, abra o Continue, selecione **Phaseo** e peça para ele responder com `PHASEO_CONTINUE_OK`. Na CLI, execute `cn` (use `/config` se outra configuração estiver ativa) e envie o mesmo prompt. Confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Remova o Phaseo

```bash
phaseo integrations remove continue
```

Isso revoga a chave e apaga os dois arquivos, mas só se eles ainda começarem com o marcador da CLI do Phaseo. Entradas que você mesmo mesclou ficam intactas.

## Corrija problemas comuns

### O Phaseo não aparece

Recarregue a IDE e confira se o `config.yaml` tem os campos de nível superior `name`, `version` e `schema`.

### O Continue informa que falta um segredo

Confira se `~/.continue/.env` tem a chave de `phaseo integrations credential continue` e reinicie a IDE.

### O Continue chama a API Responses

Mantenha `useResponsesApi: false` na entrada de modelo do Phaseo.
