Execute `phaseo deepseek-harness` para adicionar o Phaseo ao seletor de modelos do DeepSeek Harness, ou adicione um provedor personalizado na interface do Harness ou no `settings.yaml`. O Harness envia solicitações Chat Completions compatíveis com OpenAI direto para o Phaseo, então nenhum adaptador é necessário.

## Configure com a CLI do Phaseo

```bash
phaseo login
phaseo deepseek-harness
```

Se o Harness não estiver instalado, a CLI mostra o comando de instalação oficial e pede confirmação antes de executá-lo. Em seguida, a configuração:

- grava o provedor, a URL base, o protocolo, o catálogo de modelos e o modelo padrão em `$DSH_HOME/cordis.patch.yml` (`DSH_HOME` usa `~/.dsh` por padrão), dentro de um bloco marcado, para depois atualizar ou remover só as próprias configurações;
- adiciona todos os modelos de texto ativos do Phaseo que funcionam com Chat Completions. Use `--catalog default` para adicionar só o modelo padrão;
- cria uma `Phaseo CLI: DeepSeek Harness API Key` que expira após 90 dias e tem um limite de gastos mensal de $100, e a grava no arquivo protegido `$DSH_HOME/.credentials.yaml` do Harness. Execute `phaseo deepseek-harness` de novo para substituir uma chave expirada.

O modelo padrão é `anthropic/claude-sonnet-4.6`. Para escolher outro:

```bash
phaseo deepseek-harness --model YOUR_PHASEO_MODEL_ID
```

## Adicione o Phaseo na interface do Harness

1. Abra **Settings > Models** e escolha **Add a custom provider**.
2. Preencha:

| Campo | Valor |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Base URL | `https://api.phaseo.app/v1` |
| API protocol | `OpenAI Completions` |
| API key | Uma chave de API do Phaseo |

3. Em **Model catalog**, escolha **Fetch available models**.
4. Selecione um modelo de Chat Completions com suporte a ferramentas, como `anthropic/claude-sonnet-5.5`, e salve o provedor.
5. No editor de mensagens, escolha o modelo do Phaseo e inicie uma sessão nova.

Sessões salvas e referências de credenciais guardam o ID do provedor, então trate `phaseo` como permanente. Você pode editar depois o nome de exibição, a URL, a chave e a lista de modelos.

## Configure o Phaseo no settings.yaml

Você pode configurar o mesmo provedor em `$DSH_HOME/settings.yaml`. Mantenha a chave fora desse arquivo: `apiKeyEnv` indica a variável de onde o Harness lê a chave.

```yaml $DSH_HOME/settings.yaml
llm-pi-ai:
  providers:
    phaseo:
      displayName: Phaseo
      apiKeyEnv: PHASEO_API_KEY
      api: openai-completions
      baseURL: https://api.phaseo.app/v1
      models:
        - id: YOUR_PHASEO_MODEL_ID
```

Defina `PHASEO_API_KEY` no ambiente que inicia o Harness, ou guarde a chave na página Models. Substitua `YOUR_PHASEO_MODEL_ID` por um ID exato do Phaseo; para agentes de programação, comece com `anthropic/claude-sonnet-5.5`. A lista `models` é um catálogo salvo, não uma consulta em tempo real, então atualize-a quando quiser mais modelos do Phaseo no Harness.

## Confira se funciona

Confira primeiro a chave e a descoberta de modelos:

```bash
curl https://api.phaseo.app/v1/models \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

Depois, selecione um modelo do Phaseo em uma sessão nova do Harness e envie `Reply with exactly: Phaseo is connected.` Uma resposta confirma todo o caminho, do Harness pelo Phaseo até o provedor do modelo. A solicitação também aparece em **Configurações → Uso → Registros**. Solicitações reais são cobradas como uso normal.

## Remova o Phaseo

```bash
phaseo integrations remove deepseek-harness
```

Isso remove só a configuração que pertence ao Phaseo e revoga a chave.

## Corrija problemas comuns

| Problema | Correção |
| --- | --- |
| Buscar os modelos retorna `401` | Confira se a chave é atual e se a URL base inclui `/v1`. |
| O modelo não aparece no seletor | Busque o catálogo de novo, ou adicione o ID exato do modelo em `models` no `settings.yaml`. |
| O Harness informa `MISSING_CREDENTIAL` | Guarde a chave na página Models, ou deixe `PHASEO_API_KEY` disponível para o processo do Harness. |
| As solicitações vão para o endpoint errado | Selecione `OpenAI Completions` (`openai-completions`). Este provedor usa o `/v1/chat/completions` do Phaseo. |
| Um modelo rejeita ferramentas de função com o raciocínio ativado | Escolha um modelo que aceite ferramentas no Chat Completions. Modelos que precisam da API Responses para raciocinar com ferramentas não funcionam com este protocolo. |
| Uma sessão mantém o modelo antigo | Inicie uma sessão nova. O Harness salva o provedor e o modelo nas sessões que já enviaram uma solicitação. |
