Instale `@phaseo/cli` e execute `phaseo login` para conectar agentes de programação ao Phaseo e gerenciar chaves, espaços de trabalho, predefinições, configurações e guardrails pelo terminal. A CLI também consulta modelos, provedores, preços, créditos, atividade, análises e gerações.

## Instale

<CodeGroup>

```bash npm
npm install -g @phaseo/cli
```

```bash pnpm
pnpm add -g @phaseo/cli
```

```bash yarn
yarn global add @phaseo/cli
```

```bash bun
bun add -g @phaseo/cli
```

</CodeGroup>

Confira a versão:

| Comando | Mostra |
| --- | --- |
| `phaseo --version` | A versão instalada. |
| `phaseo version` | A versão e o comando de atualização para o seu gerenciador de pacotes. Adicione `--json` para obter uma saída estruturada. |

As execuções interativas também mostram um aviso quando uma versão mais nova é publicada.

## Entre na sua conta

```bash
phaseo login
```

| Fluxo | Flag | Use para |
| --- | --- | --- |
| Entrar com o Phaseo | `--browser` | OAuth pelo navegador com código de autorização e PKCE. |
| Entrar com código de dispositivo | `--device-code` | SSH, CI, shells sem interface gráfica e ambientes de agentes. |

Ambientes remotos e não interativos usam o código de dispositivo automaticamente. Confira com qual conta você entrou, com seus escopos, o espaço de trabalho ativo e os outros espaços de trabalho:

```bash
phaseo whoami
phaseo whoami --json
```

## Crie chaves e gerencie seu espaço de trabalho

```bash
phaseo keys create --name "Local CLI Key"
phaseo keys create --name "Agent Sandbox Key" --json
phaseo keys current

phaseo workspaces list
phaseo workspaces members <workspace-id-or-slug>

phaseo guardrails list
phaseo guardrails create --name "Production Safety" --body-json '{"enabled":true}'
```

Use `--json` quando um agente ou script precisar da nova chave; ela só é mostrada uma vez. A CLI cobre as tarefas de gerenciamento do painel, incluindo faturamento, orçamentos, BYOK, roteamento e identidade. Veja [Gerencie o Phaseo a partir de um agente](../../developers/manage-from-an-agent) para o comando de cada tarefa.

## Conecte um agente de programação

Use o nome do agente como comando. A CLI pede uma chave dedicada, que você aprova no navegador, e grava a configuração do agente:

```bash
phaseo codex
phaseo claude-code
phaseo opencode
phaseo fx
phaseo deepseek-harness
phaseo pi
phaseo prime-agent
phaseo openclaw
phaseo hermes
phaseo aider
phaseo continue
phaseo zed
phaseo roo-code
phaseo kilo-code
phaseo cursor
```

Use `--model`, `--catalog all|default` ou `--dry-run` conforme precisar. `phaseo setup <agent>` e `phaseo integrations setup <agent>` também funcionam.

### Aprove a chave no navegador

Na primeira vez que você configura um agente, a CLI abre uma página do painel da Phaseo e mostra o link dela. A página mostra o workspace, o nome da chave, o limite de gastos mensal de $100 e a expiração após 90 dias, e que a CLI da Phaseo pediu a chave. Escolha **Aprovar e criar chave** e a CLI recebe a chave uma única vez e conclui a configuração. Se você escolher **Recusar**, ou deixar a solicitação expirar após 10 minutos, nada é criado.

Aprove conectado ao painel com a conta que você usou na CLI, como proprietário ou administrador do workspace e com seu segundo fator, se tiver configurado um. Um login da CLI não consegue criar chaves sozinho. Por SSH ou em CI, abra o link mostrado em qualquer dispositivo em que você esteja conectado.

Para usar uma chave que você criou no painel, passe-a com `--key <key>`, ou com `--key-stdin` para que ela não fique no histórico do shell. A CLI verifica a chave e a guarda, e não a revoga quando você remove o agente.

Para executar o Cline, o Kilo Code, o oh-my-pi, o Muse Code ou o MiniMax Code com configurações temporárias que são apagadas quando ele é encerrado, use o executor de sessão. As flags do Phaseo vêm antes de `--`, e as do próprio agente, depois:

```bash
phaseo cline --model openai/gpt-5.6-terra -- --tui
phaseo kilo --model openai/gpt-5.6-terra
phaseo omp --model openai/gpt-5.6-terra
phaseo muse --model meta/muse-spark-1.3
phaseo minimax --model openai/gpt-5.6-terra
```

`phaseo run <cline|kilo|omp|muse|minimax>` é a forma longa. Adicione `--catalog all` para listar todos os modelos de texto ativos do Phaseo, ou `--dry-run --json` para pré-visualizar sem criar uma chave. Os executores oferecem instalar um agente que falte em um terminal interativo (o MiniMax Code usa o instalador oficial do PowerShell no Windows; o Muse Code precisa ser instalado manualmente no Windows). Use `--skip-install` quando você mesmo gerencia o agente.

[Agentes de programação](./coding-assistants.mdx) lista todos os agentes, o que o comando de cada um faz e o guia correspondente.

## Use a CLI em scripts

Comandos com `--json` mostram uma saída estruturada simples, sem cores nem spinners. Nos demais casos, os spinners vão para `stderr` e limpam a linha quando terminam.

| Variável | Efeito |
| --- | --- |
| `NO_COLOR` | Desativa as cores. |
| `TERM=dumb` | Desativa as animações. Um `stderr` que não é TTY tem o mesmo efeito. |
| `FORCE_COLOR=1` | Força as cores quando um wrapper de terminal as aceita, mas não se identifica como TTY. |

## Como a CLI protege as credenciais

- As sessões ficam no armazenamento de credenciais do sistema operacional. Defina `PHASEO_SESSION_BACKEND=file` só se não houver armazenamento de credenciais disponível; isso guarda os refresh tokens em um arquivo em texto puro com permissões restritas.
- `phaseo logout` revoga o refresh token guardado antes de limpar o estado local.
- As chaves de gerenciamento precisam de permissões explícitas. As chaves de inferência são limitadas por guardrails, políticas de roteamento e configurações do espaço de trabalho, e não por escopos.

## Apps OAuth

O Phaseo usa um único servidor de autorização OAuth para a CLI, para os apps criados por usuários e para os clientes MCP registrados dinamicamente. A CLI usa login pelo navegador ou por dispositivo, com refresh tokens rotativos. Clientes de terceiros usam código de autorização com PKCE, escopos explícitos e consentimento do espaço de trabalho, além de vinculação opcional a um recurso protegido. Eles recebem um access token revogável que dura 7 dias e um refresh token rotativo que dura 90 dias a partir do último uso; veja [Crie um workbench OAuth com Next.js](../../cookbook/build-an-oauth-nextjs-workbench) para entender como a renovação funciona. Aprovar o mesmo app de novo renova a chave dele em vez de adicionar uma segunda.

A API hospedada do Phaseo tem o OAuth de terceiros ativado. Implantações da API auto-hospedadas e de prévia o mantêm desativado, a menos que `PHASEO_THIRD_PARTY_OAUTH_ENABLED` tenha um valor verdadeiro: `1`, `true`, `yes` ou `on`, sem diferenciar maiúsculas e minúsculas e ignorando espaços ao redor.

```bash .env
PHASEO_THIRD_PARTY_OAUTH_ENABLED=true
```

Ativá-lo expõe o gerenciamento de apps OAuth criados por usuários e o registro dinâmico de clientes, então revise antes as configurações de URI de redirecionamento, consentimento, segredo do cliente, limite de taxa e autorização do espaço de trabalho.

## Atualize

```bash
phaseo update
```

Isso executa a atualização com o gerenciador de pacotes que você usou para instalar a CLI. Para atualizar manualmente:

<CodeGroup>

```bash npm
npm install -g @phaseo/cli@latest
```

```bash pnpm
pnpm add -g @phaseo/cli@latest
```

```bash yarn
yarn global add @phaseo/cli@latest
```

```bash bun
bun add -g @phaseo/cli@latest
```

</CodeGroup>
