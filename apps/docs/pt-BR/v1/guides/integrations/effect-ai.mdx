Chame os endpoints compatíveis com OpenAI do Phaseo a partir do Effect com o cliente HTTP dele, ou envolva o [OpenAI SDK](./openai-sdk.mdx) em uma layer do Effect. Use o pacote de provedor OpenAI do próprio Effect só se a versão instalada aceitar uma URL base personalizada.

## Instale

```bash
npm install effect @effect/platform
```

## Chame o Phaseo com o HTTP do Effect

```ts
import { FetchHttpClient, HttpClient, HttpClientRequest } from "@effect/platform";
import { Config, Effect, Redacted } from "effect";

const generate = Effect.gen(function* () {
	const apiKey = yield* Config.redacted("PHASEO_API_KEY");
	const client = yield* HttpClient.HttpClient;

	const request = HttpClientRequest.post(
		"https://api.phaseo.app/v1/chat/completions",
	).pipe(
		HttpClientRequest.bearerToken(Redacted.value(apiKey)),
		HttpClientRequest.jsonBody({
			model: "openai/gpt-6-astra",
			messages: [{ role: "user", content: "Reply with only: ok" }],
		}),
	);

	return yield* client.execute(request).pipe(
		Effect.flatMap((response) => response.json),
	);
});

const runnable = generate.pipe(Effect.provide(FetchHttpClient.layer));
```

Ao executar, ele retorna uma resposta de Chat Completions cuja mensagem diz `ok`.

## Envolva o OpenAI SDK em uma layer do Effect

Se você já usa o OpenAI SDK, mantenha a configuração do Phaseo em um só lugar:

```ts
import OpenAI from "openai";
import { Config, Effect } from "effect";

const makeClient = Effect.gen(function* () {
	const apiKey = yield* Config.string("PHASEO_API_KEY");

	return new OpenAI({
		apiKey,
		baseURL: "https://api.phaseo.app/v1",
	});
});
```

Construa uma layer personalizada sobre isso quando quiser uma abstração no estilo de provedor em toda a aplicação.

## Limitações conhecidas

- Mantenha os IDs de modelo no formato do Phaseo, como `openai/gpt-6-astra`.
- Teste o [streaming](../streaming.mdx) e as chamadas de ferramentas com as versões exatas dos seus pacotes do Effect antes de ir para produção.
