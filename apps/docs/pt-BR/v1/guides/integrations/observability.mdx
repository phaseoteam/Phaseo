A maioria das ferramentas de observabilidade fica acima do cliente do modelo. Mantenha sua configuração de rastreamento e aponte para o Phaseo o cliente subjacente compatível com OpenAI ou Anthropic.

## Langfuse com o SDK da OpenAI

```bash
pip install langfuse openai
```

```python
import os
from langfuse.openai import openai

client = openai.OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-5-nano",
    input="Reply with only: ok",
)
```

## LangSmith com LangChain

Use a configuração do [LangChain](./langchain.mdx) e habilite o LangSmith pelas variáveis de ambiente usuais do LangChain:

```bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your_langsmith_key"
export PHASEO_API_KEY="your_phaseo_key"
```

## OpenTelemetry

Se seu framework emitir spans do OpenTelemetry, o Phaseo não exige um exportador especial. Adicione por conta própria o contexto útil da solicitação:

- ID do modelo
- Endpoint, como `responses` ou `chat.completions`
- ID da solicitação do Phaseo obtido nos metadados da resposta ou nos logs
- Provedor selecionado, quando os metadados da resposta estiverem habilitados

## Observações

- Não envie chaves de API do Phaseo para ferramentas de observabilidade como atributos.
- Se a biblioteca de observabilidade envolver o SDK da OpenAI, configure o cliente encapsulado com `base_url: "https://api.phaseo.app/v1"`.
- Para rastros do LangChain, combine o callback de rastreamento com a configuração `ChatOpenAI` do Phaseo.
