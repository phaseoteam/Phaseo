Rastreie as solicitações do Phaseo de duas formas: ative o [Broadcast](../broadcast.mdx) para que o Phaseo envie um trace de cada solicitação ao Langfuse, ao LangSmith ou a qualquer ferramenta OpenTelemetry sem mudar o código, ou mantenha a biblioteca de rastreamento no seu app e aponte o cliente de modelo dela para o Phaseo.

| | Broadcast | Rastreamento no seu app |
| --- | --- | --- |
| De onde vêm os traces | Do Phaseo, para cada solicitação | Do cliente de modelo do seu app |
| Mudança de código | Nenhuma; configure em **Configurações → Transmissão** | Envolva o cliente e depois mude a URL base dele |
| O que há no trace | Modelo, provedor, cada tentativa de provedor, tokens, custo, tempos e (opcionalmente) o prompt e a saída | O que a sua biblioteca registrar, além do contexto do seu app |

## Langfuse com o SDK da OpenAI

Mantenha o wrapper OpenAI do Langfuse e passe ao cliente envolvido a URL base do Phaseo:

```bash
pip install langfuse openai
```

```python
import os
from langfuse.openai import openai

client = openai.OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Reply with only: ok",
)
```

## LangSmith com o LangChain

Use a configuração de `ChatOpenAI` do [LangChain](./langchain.mdx) e ative o LangSmith com as variáveis de ambiente usuais do LangChain:

```bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your_langsmith_key"
export PHASEO_API_KEY="your_phaseo_key"
```

## OpenTelemetry

Se o seu framework já emite spans do OpenTelemetry, você não precisa de um exportador especial. Adicione você mesmo este contexto da solicitação aos spans:

- ID do modelo;
- endpoint, como `responses` ou `chat.completions`;
- o ID da solicitação no Phaseo, obtido nos metadados da resposta ou nos [registros](../../api-reference/endpoint/activity.mdx);
- o provedor que atendeu a solicitação, quando os metadados da resposta estão ativados.

Nunca registre chaves de API do Phaseo como atributos de span.
