O Mastra funciona com provedores do AI SDK, então o caminho mais simples é criar um provedor compatível com OpenAI apontado para o Phaseo.

## Instalar

```bash
npm install @mastra/core @ai-sdk/openai ai
```

## Configure um agente

```ts
import { Agent } from "@mastra/core/agent";
import { createOpenAI } from "@ai-sdk/openai";

const phaseo = createOpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
	compatibility: "compatible",
});

export const agent = new Agent({
	name: "support-agent",
	instructions: "Answer in two short paragraphs.",
	model: phaseo("openai/gpt-5-nano"),
});
```

## Observações

- Use somente a URL base, não `/chat/completions` nem `/responses`.
- O comportamento dos agentes Mastra depende do caminho do provedor do AI SDK. Teste ferramentas e streaming antes de colocar em produção.
- Use os controles de roteamento do Phaseo por solicitação ou por presets quando precisar de preferências de provedor.
