Crie um provedor OpenAI do AI SDK com sua chave do Phaseo e `baseURL: "https://api.phaseo.app/v1"`, e passe os modelos dele aos agentes e workflows do Mastra.

## Instale

```bash
npm install @mastra/core @ai-sdk/openai ai
```

## Aponte um agente do Mastra para o Phaseo

```ts
import { Agent } from "@mastra/core/agent";
import { createOpenAI } from "@ai-sdk/openai";

const phaseo = createOpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
	compatibility: "compatible",
});

export const agent = new Agent({
	name: "support-agent",
	instructions: "Answer in two short paragraphs.",
	model: phaseo("openai/gpt-6-astra"),
});
```

Use só a URL base, sem `/chat/completions` nem `/responses`. Execute o agente uma vez com um prompt curto e confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Limitações conhecidas

- O comportamento dos agentes do Mastra depende do provedor do AI SDK. Teste a [chamada de ferramentas](../tool-calling.mdx) e o streaming antes de ir para produção.
- Para dar preferência a certos provedores, defina os controles de roteamento do Phaseo na solicitação ou em uma [predefinição](../presets.mdx).
