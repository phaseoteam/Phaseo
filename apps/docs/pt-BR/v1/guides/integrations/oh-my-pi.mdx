Execute `phaseo omp` para iniciar uma sessão do oh-my-pi pelo Phaseo, ou adicione um provedor `phaseo` a `~/.omp/agent/models.yml` para manter o Phaseo em todas as sessões.

## Execute o oh-my-pi pela CLI do Phaseo

```bash
phaseo login
phaseo omp --model openai/gpt-5.6-terra
```

O executor cria uma chave dedicada, grava `models.yml` em um `PI_CODING_AGENT_DIR` temporário, inicia o `omp` com `--model phaseo/<model>` e apaga o diretório quando o oh-my-pi é encerrado. Se o `omp` não estiver instalado, a primeira execução interativa oferece instalá-lo. Coloque as flags do próprio oh-my-pi depois de `--`.

| Flag | Efeito |
| --- | --- |
| `--model <id>` | Modelo a usar. O padrão é `openai/gpt-5.6-terra`. |
| `--catalog all` | Lista todos os modelos de texto ativos do Phaseo, não só o selecionado. |
| `--dry-run --json` | Mostra o plano de instalação e inicialização sem criar uma chave nem iniciar o oh-my-pi. |
| `--skip-install` | Pula a verificação de instalação. |

`phaseo run omp ...` é a forma longa do mesmo comando.

## Configure o oh-my-pi manualmente

Crie uma chave no painel, em **Configurações → Chaves de API**, exporte-a no shell que inicia o oh-my-pi e crie o diretório de configuração:

```bash
export PHASEO_OMP_API_KEY="<your Phaseo API key>"
mkdir -p ~/.omp/agent
```

Adicione o provedor:

```yaml ~/.omp/agent/models.yml
providers:
  phaseo:
    baseUrl: https://api.phaseo.app/v1
    api: openai-completions
    apiKey: PHASEO_OMP_API_KEY
    authHeader: true
    models:
      - id: openai/gpt-5.6-terra
        name: GPT-5.6 Terra via Phaseo
        contextWindow: 32768
        maxTokens: 8192
```

`apiKey` indica a variável de ambiente, então a chave fica fora do `models.yml`. Adicione mais entradas em `models` conforme precisar; os limites acima são exemplos. Inicie o oh-my-pi com o ID do modelo qualificado pelo provedor:

```bash
omp --model phaseo/openai/gpt-5.6-terra
```

Veja a documentação de [configuração de provedores](https://github.com/can1357/oh-my-pi/blob/main/docs/providers.md) do oh-my-pi para os outros campos.

## Confira se funciona

Envie um prompt curto e confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Corrija problemas comuns

### O oh-my-pi não está instalado

Execute o comando em um terminal interativo para aprovar a instalação, ou instale você mesmo o oh-my-pi e execute de novo com `--skip-install`.

### O modelo não aparece na lista

Use `--catalog all`, ou informe o ID do modelo com `--model`. O Phaseo não precisa da descoberta de modelos.
