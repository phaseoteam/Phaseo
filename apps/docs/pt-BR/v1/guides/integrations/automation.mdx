Chame o Phaseo de qualquer plataforma de automação que consiga enviar uma solicitação HTTP autenticada: adicione uma etapa HTTP que faz POST para `https://api.phaseo.app/v1/responses` com a sua chave como token bearer. O Phaseo não tem app nativo para Zapier, n8n ou Pipedream.

## Montar a solicitação

| Configuração | Valor |
| --- | --- |
| Método | `POST` |
| URL | `https://api.phaseo.app/v1/responses` |
| Cabeçalho | `Authorization: Bearer <PHASEO_API_KEY>` |
| Cabeçalho | `Content-Type: application/json` |

```json
{
  "model": "openai/gpt-6-astra",
  "input": "Summarise the supplied workflow data in one paragraph."
}
```

Guarde a chave no armazenamento de credenciais ou de segredos da plataforma, não em uma definição de fluxo de trabalho compartilhada. Veja [Responses](../../api-reference/endpoint/responses.mdx) para todos os campos da solicitação.

## Zapier

Use **Webhooks by Zapier → Custom Request**:

1. Selecione `POST` e informe `https://api.phaseo.app/v1/responses`.
2. Adicione os cabeçalhos de bearer e de content-type.
3. Mapeie campos de etapas anteriores do Zap para `input`.
4. Teste o Zap com dados não sensíveis.

## n8n

Use o nó **HTTP Request** com autenticação bearer e um corpo JSON. Mapeie o item recebido para `input` com uma expressão do n8n.

## Pipedream

Use uma etapa de solicitação HTTP ou uma etapa de código Node.js. Guarde `PHASEO_API_KEY` como segredo do Pipedream e leia-a do ambiente da etapa.

## Conferir se funciona

Execute a etapa uma vez. Uma resposta `200` com um array `output` significa que a chave e a URL funcionam, e a solicitação aparece em **Configurações → Uso → Registros**.

## Executar automações com segurança

- Dê a cada automação a própria chave, com um limite de gastos, para poder acompanhá-la e revogá-la separadamente.
- Use [saídas estruturadas](../structured-outputs.mdx) quando as etapas seguintes esperarem campos legíveis por máquina.
- Tente de novo em respostas `429` e `5xx` recuperáveis; veja [Erros](../../api-reference/errors.mdx).
- Não repita ações externas que não são idempotentes só porque uma etapa do modelo foi tentada de novo.
