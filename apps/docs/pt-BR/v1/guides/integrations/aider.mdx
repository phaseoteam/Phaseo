Execute `phaseo aider` para gravar uma configuração do Aider que aponta para o Phaseo, ou adicione três linhas ao seu `.aider.conf.yml` existente.

## Configurar com a CLI do Phaseo

```bash
phaseo login
phaseo aider --model anthropic/claude-sonnet-5.5
```

Se `~/.aider.conf.yml` não existir, a configuração cria uma `Phaseo CLI: Aider API Key` (validade de 90 dias, limite de gastos mensal de $100) e grava este arquivo. Sem `--model`, ela usa `anthropic/claude-sonnet-4.6`.

```yaml ~/.aider.conf.yml
# Managed by Phaseo CLI
model: openai/anthropic/claude-sonnet-5.5
openai-api-base: https://api.phaseo.app/v1
openai-api-key: "<dedicated Phaseo key>"
```

O Aider precisa do prefixo `openai/` para enviar um modelo personalizado pelo adaptador compatível com a OpenAI. O modelo enviado ao Phaseo continua sendo `anthropic/claude-sonnet-5.5`.

<Warning>
A chave é guardada em texto simples, porque `.aider.conf.yml` é um dos locais de chave documentados pelo Aider. Deixe o arquivo legível só pela sua conta de usuário e nunca faça commit dele.
</Warning>

## Configurar o Aider manualmente

Se você já tem uma configuração do Aider, a CLI para sem alterá-la. Copie as três configurações acima para a configuração que você quer que o Aider carregue, usando `phaseo integrations credential aider` ou qualquer chave de API do Phaseo em `openai-api-key`. O Aider lê `.aider.conf.yml` do seu diretório pessoal, da raiz do repositório e do diretório atual, e os arquivos lidos por último prevalecem. Veja a documentação do Aider sobre [configuração YAML](https://aider.chat/docs/config/aider_conf.html) e [API compatível com a OpenAI](https://aider.chat/docs/llms/openai-compat.html).

## Conferir se funciona

Abra um repositório e inicie o Aider:

```bash
aider
```

Confira se a saída de inicialização mostra `openai/anthropic/claude-sonnet-5.5`, peça que ele responda com `PHASEO_AIDER_OK` e confirme que a solicitação aparece em **Configurações → Uso → Registros**.

Um aviso de modelo desconhecido não impede as solicitações. Adicione metadados de modelo do Aider só se você precisar de estimativas precisas de limite de tokens ou de custo.

## Remover o Phaseo

```bash
phaseo integrations remove aider
```

Isso revoga a chave e exclui `~/.aider.conf.yml` somente se o arquivo ainda começar com o marcador da CLI do Phaseo. Se você mesclou as configurações no seu próprio arquivo, remova as três linhas você mesmo.

## Resolver problemas comuns

### O Aider usa outro endpoint ou modelo

Um `.aider.conf.yml` na raiz do repositório ou no diretório atual substitui o do seu diretório pessoal. Variáveis de ambiente e opções de linha de comando substituem todos eles.

### A autenticação falha

Compare `openai-api-key` com a saída de `phaseo integrations credential aider` e mantenha `openai-api-base` exatamente como `https://api.phaseo.app/v1`.

### O modelo não é encontrado

Mantenha o prefixo `openai/` do Aider. O modelo do Phaseo `openai/gpt-6-astra` vira `openai/openai/gpt-6-astra` no Aider.
