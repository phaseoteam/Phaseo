O LiveKit Agents pode chamar qualquer endpoint de chat compatível com OpenAI pelo plugin OpenAI. Aponte esse plugin para o Phaseo para usar os IDs de modelo e o roteamento do Phaseo.

## Python

```bash
uv add "livekit-agents[openai]"
```

```python
import os
from livekit.agents import AgentSession
from livekit.plugins import openai

session = AgentSession(
    llm=openai.LLM(
        model="openai/gpt-5-nano",
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)
```

## Node.js

```bash
pnpm add @livekit/agents @livekit/agents-plugin-openai
```

```ts
import { voice } from "@livekit/agents";
import * as openai from "@livekit/agents-plugin-openai";

const session = new voice.AgentSession({
	llm: new openai.LLM({
		model: "openai/gpt-5-nano",
		apiKey: process.env.PHASEO_API_KEY,
		baseURL: "https://api.phaseo.app/v1",
	}),
});
```

## Observações

- Use o modo Chat Completions compatível com OpenAI para endpoints personalizados.
- As ferramentas OpenAI específicas de Responses do LiveKit não se tornam automaticamente ferramentas de servidor do Phaseo.
- Configure a conversão de fala em texto e de texto em fala separadamente, a menos que a interface LiveKit escolhida ofereça suporte a uma URL personalizada compatível com OpenAI para essa modalidade.
- Teste o tratamento de interrupções, as chamadas de ferramentas e a latência do streaming antes de colocar tráfego de voz em produção.
