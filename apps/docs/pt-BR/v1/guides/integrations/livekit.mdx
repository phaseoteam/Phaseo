Aponte o LLM do plugin OpenAI do LiveKit Agents para `https://api.phaseo.app/v1` com sua chave do Phaseo, e seus agentes de voz usam os IDs de modelo e o roteamento do Phaseo. O plugin chama o endpoint Chat Completions do Phaseo.

## Instale

<CodeGroup>

```bash Python
uv add "livekit-agents[openai]"
```

```bash Node.js
pnpm add @livekit/agents @livekit/agents-plugin-openai
```

</CodeGroup>

## Aponte o LLM do agente para o Phaseo

<CodeGroup>

```python Python
import os
from livekit.agents import AgentSession
from livekit.plugins import openai

session = AgentSession(
    llm=openai.LLM(
        model="openai/gpt-6-astra",
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)
```

```ts Node.js
import { voice } from "@livekit/agents";
import * as openai from "@livekit/agents-plugin-openai";

const session = new voice.AgentSession({
	llm: new openai.LLM({
		model: "openai/gpt-6-astra",
		apiKey: process.env.PHASEO_API_KEY,
		baseURL: "https://api.phaseo.app/v1",
	}),
});
```

</CodeGroup>

Inicie uma sessão, diga alguma coisa e confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Limitações conhecidas

- Use o modo Chat Completions do plugin para endpoints personalizados. As ferramentas OpenAI específicas do Responses no LiveKit não viram ferramentas de servidor do Phaseo.
- Isso só roteia o LLM. Configure a conversão de fala em texto e de texto em fala separadamente, a menos que a interface do LiveKit que você usa aceite uma URL personalizada compatível com OpenAI para essa modalidade.
- Teste o tratamento de interrupções, as [chamadas de ferramentas](../tool-calling.mdx) e a latência do [streaming](../streaming.mdx) antes de colocar tráfego de voz em produção.
