Crie um `OpenAIChatModel` com um `OpenAIProvider` apontado para `https://api.phaseo.app/v1`, e os agentes do PydanticAI rodam com modelos do Phaseo.

## Instale

```bash
pip install "pydantic-ai-slim[openai]"
```

## Aponte o PydanticAI para o Phaseo

```python
import os
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-6-astra",
    provider=OpenAIProvider(
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)

agent = Agent(model, system_prompt="Answer concisely.")
result = agent.run_sync("Reply with only: ok")
print(result.output)
```

Se `ok` for impresso, a configuração funciona.

## Limitações conhecidas

- Este caminho usa Chat Completions no estilo OpenAI. Para recursos exclusivos do Responses, como `phaseo:apply_patch`, chame diretamente o endpoint Responses do Phaseo.
- Mantenha os schemas de [saída estruturada](../structured-outputs.mdx) pequenos o suficiente para a janela de contexto do modelo. Confira os limites em [Modelos](../../api-reference/endpoint/models.mdx).
