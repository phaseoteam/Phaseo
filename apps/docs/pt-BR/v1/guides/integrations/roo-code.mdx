---
title: "Roo Code"
description: "Conecte o Roo Code ao Phaseo por meio de um perfil compatível com OpenAI."
---

A CLI do Phaseo cria e gerencia a chave exclusiva do Roo Code. O Roo Code mantém as credenciais no armazenamento seguro do VS Code, então você configura o perfil na extensão.

## Criar a credencial

```bash
phaseo login
phaseo integrations setup roo-code --model anthropic/claude-sonnet-4.6
```

## Configurar o Roo Code

1. Abra o Roo Code no VS Code.
2. Abra **Settings** e depois **Providers**.
3. Crie um perfil de configuração do provedor e escolha **OpenAI Compatible**.
4. Insira estes valores:

| Campo do Roo Code | Valor |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | Saída de `phaseo integrations credential roo-code` |
| Model | `anthropic/claude-sonnet-4.6` ou o modelo informado pela configuração |

5. Salve o perfil e deixe-o ativo.

Os rótulos dos campos podem variar um pouco entre versões, mas o perfil precisa do endpoint, da chave e do ID exato do modelo.

## Verificar

Peça ao Roo Code que responda `PHASEO_ROO_OK` e confirme se a solicitação aparece na atividade do Phaseo.

## Remover

Exclua o perfil do Phaseo ou troque de perfil e execute:

```bash
phaseo integrations remove roo-code
```

A CLI não pode excluir valores do armazenamento privado da extensão no VS Code, mas a remoção revoga a chave.

## Solução de problemas

### Falha na autenticação

Obtenha a chave novamente com `phaseo integrations credential roo-code`. Confirme se a URL base termina em `/v1`.

### O Roo Code não encontra o modelo

Insira manualmente o ID exato do modelo do Phaseo, incluindo o prefixo do provedor.

### O chat funciona, mas as ferramentas falham

Troque para um modelo compatível com chamadas de ferramentas.
