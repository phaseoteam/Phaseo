Execute `phaseo roo-code` para criar uma chave e depois adicione um perfil **OpenAI Compatible** no Roo Code. O Roo Code guarda as chaves no armazenamento de segredos do VS Code, então esse último passo é feito na interface dele.

## Configure com a CLI do Phaseo

```bash
phaseo login
phaseo roo-code --model anthropic/claude-sonnet-5.5
```

A CLI cria uma `Phaseo CLI: Roo Code API Key` que expira após 90 dias e tem um limite de gastos mensal de $100 e depois mostra os valores para o próximo passo.

## Configure o Roo Code

1. Abra o Roo Code no VS Code e depois **Settings → Providers**.
2. Crie um perfil de configuração de provedor e escolha **OpenAI Compatible**.
3. Preencha:

| Campo do Roo Code | Valor |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | Saída de `phaseo integrations credential roo-code`, ou qualquer chave de API do Phaseo |
| Model | `anthropic/claude-sonnet-5.5`, ou o modelo mostrado pela configuração |

4. Salve o perfil e ative-o.

Os rótulos dos campos mudam um pouco entre as versões; veja a documentação de [provedores de modelos](https://docs.roocode.com/providers/) do Roo Code se os seus forem diferentes.

## Confira se funciona

Peça ao Roo Code para responder com `PHASEO_ROO_OK` e confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Remova o Phaseo

Exclua o perfil do Phaseo ou troque de perfil e depois execute:

```bash
phaseo integrations remove roo-code
```

Isso revoga a chave. A CLI não consegue limpar o armazenamento da extensão no VS Code.

## Corrija problemas comuns

### A autenticação falha

Copie a chave de novo com `phaseo integrations credential roo-code` e confira se a Base URL termina em `/v1`.

### O Roo Code não encontra o modelo

Digite o ID exato do modelo do Phaseo, incluindo o prefixo do provedor.

### O chat funciona, mas as ferramentas falham

Troque para um modelo com suporte a chamada de ferramentas.
