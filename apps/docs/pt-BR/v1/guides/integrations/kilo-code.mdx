Execute `phaseo kilo` para iniciar uma sessão da CLI do Kilo Code pelo Phaseo, ou crie uma chave com `phaseo kilo-code` e adicione um provedor personalizado na extensão do Kilo Code.

## Execute a CLI do Kilo Code pelo Phaseo

```bash
phaseo login
phaseo kilo --model openai/gpt-5.6-terra
```

O executor grava um arquivo `KILO_CONFIG` temporário, inicia o `kilo` e apaga o arquivo quando o Kilo é encerrado, então sua configuração atual do Kilo Code ou do VS Code não é alterada. Se o Kilo não estiver instalado, uma execução interativa oferece instalá-lo. Coloque as flags do próprio Kilo depois de `--`.

| Flag | Efeito |
| --- | --- |
| `--model <id>` | Modelo a usar. O padrão é `openai/gpt-5.6-terra`. |
| `--catalog all` | Lista no Kilo todos os modelos de texto ativos do Phaseo, não só o selecionado. |
| `--dry-run --json` | Mostra o plano de instalação e inicialização sem criar uma chave nem iniciar o Kilo. |
| `--skip-install` | Pula a verificação de instalação. |

`phaseo run kilo ...` é a forma longa do mesmo comando.

## Configure a extensão do Kilo Code

Crie uma chave para a extensão:

```bash
phaseo login
phaseo kilo-code --model anthropic/claude-sonnet-5.5
```

Depois, no VS Code:

1. Abra o Kilo Code, selecione o ícone de configurações, abra **Providers** e selecione **Add custom provider**.
2. Preencha:

| Campo do Kilo Code | Valor |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.phaseo.app/v1` |
| API key | Saída de `phaseo integrations credential kilo-code` |

3. Se nenhum modelo for descoberto, adicione você mesmo o ID `anthropic/claude-sonnet-5.5`.
4. Selecione **Submit** e escolha o modelo do Phaseo.

O Kilo mostra a seleção como `phaseo/anthropic/claude-sonnet-5.5`. `phaseo` é o ID local do provedor; o resto é o ID do modelo enviado ao Phaseo. Veja a documentação de [modelos personalizados](https://kilo.ai/docs/code-with-ai/agents/custom-models) do Kilo para o formulário completo.

## Confira se funciona

Peça ao Kilo Code para responder com `PHASEO_KILO_OK` e confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Remova o Phaseo

Exclua o provedor personalizado no Kilo Code e depois execute:

```bash
phaseo integrations remove kilo-code
```

Isso revoga a chave. A CLI não consegue limpar o armazenamento da extensão.

## Corrija problemas comuns

### Nenhum modelo é descoberto

Adicione o modelo manualmente. O Kilo não precisa da descoberta por `/models`.

### A autenticação falha

Substitua a chave salva pela saída de `phaseo integrations credential kilo-code` e mantenha a Base URL exatamente como mostrada.

### O nome do modelo parece diferente

Selecione `phaseo/<Phaseo model ID>` no Kilo, mas não adicione `phaseo/` no campo de ID do modelo.
