Execute `phaseo opencode` para adicionar ao OpenCode um provedor Phaseo com todos os modelos compatíveis do Phaseo, ou adicione você mesmo um provedor `phaseo` ao `opencode.json`.

## Configure com a CLI do Phaseo

```bash
phaseo login
phaseo opencode --model openai/gpt-5.6-terra
```

Se o OpenCode não estiver instalado, a CLI mostra o comando de instalação oficial e pede confirmação antes de executá-lo. Em seguida, a configuração:

- adiciona um provedor global `phaseo` com todos os modelos de texto ativos do Phaseo que funcionam com Chat Completions. Ela atualiza o seu `opencode.jsonc` global, se existir, ou então `~/.config/opencode/opencode.json`, e não mexe nas suas outras configurações;
- cria uma `Phaseo CLI: OpenCode API Key` que expira após 90 dias e tem um limite de gastos mensal de $100, e a guarda no armazenamento de credenciais do OpenCode. A CLI mantém uma cópia própria no armazenamento de credenciais do sistema operacional. Execute `phaseo opencode` de novo para substituir uma chave expirada.

Use `--catalog default` para adicionar só o modelo selecionado, ou `--dry-run` para pré-visualizar as alterações.

## Configure o OpenCode manualmente

Adicione o provedor ao `opencode.json` do seu projeto, ou à sua configuração global do OpenCode:

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-6-astra",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-6-astra": { "name": "GPT-6 Astra" },
        "openai/gpt-5.4-mini": { "name": "GPT-5.4 Mini" },
        "anthropic/claude-sonnet-5.5": { "name": "Claude Sonnet 5.5" }
      }
    }
  }
}
```

Exporte `PHASEO_API_KEY` e adicione ou remova entradas em `models` para escolher quais modelos do Phaseo o OpenCode lista.

## Confira se funciona

Reinicie o OpenCode, escolha um modelo do Phaseo em `/models` e envie um prompt curto antes de começar trabalhos que editam arquivos. Confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Remova o Phaseo

```bash
phaseo integrations remove opencode
```

Isso remove só o provedor Phaseo e a credencial guardada dele e depois revoga a chave.

## Corrija problemas comuns

| Problema | Correção |
| --- | --- |
| Um modelo é rejeitado | Confira o ID exato no [endpoint Models](../../api-reference/endpoint/models.mdx). |
| A autenticação falha | Execute `phaseo opencode` de novo e confira `opencode auth list`. |

Para deixar o OpenCode ler a documentação do Phaseo durante uma sessão, adicione o servidor [Docs MCP](./docs-mcp.mdx).
