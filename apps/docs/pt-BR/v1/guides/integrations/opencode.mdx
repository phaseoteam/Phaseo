O OpenCode pode chamar o Phaseo por meio de um provedor personalizado compatível com OpenAI. Use esta configuração se quiser que a seleção de modelos, o uso e o roteamento do OpenCode passem por uma única chave de API do Phaseo.

## 1) Configurar o OpenCode

Instale o OpenCode pela versão oficial e use a CLI do Phaseo para adicionar um provedor global, sincronizar todos os modelos compatíveis do Phaseo e armazenar uma chave exclusiva no gerenciador de credenciais do OpenCode:

```bash
phaseo opencode --model openai/gpt-5.6-terra
```

O comando cria uma `Phaseo CLI: OpenCode API Key` sem expiração, preserva configurações e credenciais não relacionadas do OpenCode e aceita `--dry-run`. Ele atualiza um `opencode.jsonc` global existente ou, se não houver, usa `~/.config/opencode/opencode.json`.

Use `--catalog default` para configurar somente o modelo selecionado.

A CLI também mantém uma cópia própria no gerenciador de credenciais do sistema operacional e revoga a chave quando você executa `phaseo integrations remove opencode`.

## Configuração manual

Crie ou atualize `opencode.json` no projeto ou na configuração global do OpenCode:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-5.5",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-5.5": {
          "name": "GPT-5.5"
        },
        "openai/gpt-5.4-mini": {
          "name": "GPT-5.4 Mini"
        },
        "anthropic/claude-sonnet-4.5": {
          "name": "Claude Sonnet 4.5"
        }
      }
    }
  }
}
```

Adicione ou remova modelos do objeto `models` para corresponder aos IDs de modelo do Phaseo que você quer usar no OpenCode.

## 2) Iniciar o OpenCode

Reinicie o OpenCode depois de editar a configuração e escolha o modelo do Phaseo em `/models`.

Mais tarde, remova somente o provedor Phaseo com:

```bash
phaseo integrations remove opencode
```

## Verificação

- Faça uma solicitação simples antes de usar fluxos de trabalho que editam arquivos.
- Se um modelo for rejeitado, confirme o ID exato no [endpoint Models](../../api-reference/endpoint/models.mdx).
- Se a autenticação falhar, execute `phaseo opencode` novamente e confira `opencode auth list`.
