Crie um LLM `OpenAILike` com sua chave do Phaseo e `api_base="https://api.phaseo.app/v1"` e defina-o como padrão do LlamaIndex, para que a geração nos seus fluxos de RAG passe pelo Phaseo.

## Instale

```bash
pip install llama-index llama-index-llms-openai-like llama-index-embeddings-openai-like
```

## Aponte o LlamaIndex para o Phaseo

```python
import os
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    is_chat_model=True,
)

response = llm.complete("Write one sentence about retrieval quality.")
print(response)
```

Se uma frase for impressa, a configuração funciona. `OpenAILike` é a classe do LlamaIndex para APIs de terceiros compatíveis com OpenAI.

## Use em um índice

```python
from llama_index.core import Settings

Settings.llm = llm
```

Depois, crie ou consulte seu índice normalmente.

## Limitações conhecidas

- Os padrões do LlamaIndex não apontam para o Phaseo. Defina explicitamente os modelos de geração e de embeddings.
- Para [embeddings](../../api-reference/endpoint/embeddings.mdx) do Phaseo, configure o modelo de embeddings com um ID de modelo do Phaseo e a mesma URL base.
