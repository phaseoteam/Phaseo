Use este guia quando quiser rotear a geração ou os embeddings de um app LlamaIndex pelo Phaseo.

## Instalar

```bash
pip install llama-index llama-index-llms-openai-like llama-index-embeddings-openai-like
```

## Configure um LLM compatível com OpenAI

```python
import os
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="openai/gpt-5-nano",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    is_chat_model=True,
)

response = llm.complete("Write one sentence about retrieval quality.")
print(response)
```

## Use em um índice

```python
from llama_index.core import Settings

Settings.llm = llm
```

Em seguida, crie ou consulte o índice como de costume.

## Observações

- Use `OpenAILike` para APIs de terceiros compatíveis com OpenAI.
- Mantenha explícitos os IDs dos modelos de geração e embeddings. Não presuma que os padrões do LlamaIndex apontem para o Phaseo.
- Se usar embeddings do Phaseo, configure o modelo de embeddings com um ID de modelo do Phaseo e a mesma URL base.
