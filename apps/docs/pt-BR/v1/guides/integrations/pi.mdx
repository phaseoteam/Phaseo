Execute `phaseo pi` para adicionar ao Pi uma extensão de provedor Phaseo com todos os modelos compatíveis do Phaseo.

## Configure com a CLI do Phaseo

```bash
phaseo login
phaseo pi
```

Se o Pi não estiver instalado, a CLI mostra o comando de instalação oficial e pede confirmação antes de executá-lo. Em seguida, a configuração cria uma `Phaseo CLI: Pi API Key` (expira em 90 dias, limite de gastos mensal de $100) e grava uma extensão de provedor em `~/.pi/agent/extensions/phaseo.ts`. A extensão lista todos os modelos de texto ativos do Phaseo que funcionam com Chat Completions.

| Flag | Efeito |
| --- | --- |
| `--model <id>` | Define o modelo inicial. O padrão é `anthropic/claude-sonnet-4.6`. |
| `--catalog default` | Adiciona só o modelo selecionado. |
| `--dry-run` | Mostra as alterações nos arquivos sem aplicá-las. |

A extensão obtém a chave no momento da solicitação com a sintaxe de chave baseada em comando do Pi, então nenhuma chave em texto puro é gravada no arquivo:

```text
!phaseo integrations credential pi
```

## Confira se funciona

```bash
pi
```

Abra `/model`, escolha o provedor `phaseo` e envie um prompt curto. Confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Remova o Phaseo

```bash
phaseo integrations remove pi
```

Isso remove só a extensão do Phaseo e revoga a chave.
