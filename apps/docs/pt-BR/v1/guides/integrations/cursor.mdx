Execute `phaseo cursor` para criar uma chave e depois ative as configurações de chave de API da OpenAI e **Override OpenAI Base URL** do Cursor. Isso roteia os modelos de chat do Cursor pelo Phaseo; recursos que usam os modelos do próprio Cursor, como o autocompletar com Tab, podem continuar usando a infraestrutura do Cursor.

## Configure com a CLI do Phaseo

```bash
phaseo login
phaseo cursor --model openai/gpt-5.6-terra
```

A CLI cria uma `Phaseo CLI: Cursor API Key` que expira após 90 dias e tem um limite de gastos mensal de $100, e mostra as configurações abaixo. Execute `phaseo cursor` de novo para obter uma chave nova depois que ela expirar. A CLI não edita o armazenamento de credenciais do Cursor.

## Configure o Cursor

1. Abra **Cursor Settings → Models**.
2. Encontre a seção **OpenAI API Key** e ative-a.
3. Cole a chave de `phaseo integrations credential cursor`, ou qualquer chave de API do Phaseo.
4. Ative **Override OpenAI Base URL** e informe `https://api.phaseo.app/v1`, sem barra no final.
5. Adicione ou ative o modelo do Phaseo que você quer.

| Campo do Cursor | Valor |
| --- | --- |
| OpenAI API Key | Saída de `phaseo integrations credential cursor` |
| Override OpenAI Base URL | `https://api.phaseo.app/v1` |
| Model | Um ID de modelo do Phaseo que o Cursor aceite |

As configurações de chave e Base URL do Cursor são globais, não por provedor: a chave e a Base URL ativadas decidem para onde vai toda solicitação da família OpenAI, e o nome do modelo é repassado como está. Algumas versões salvam a chave sem um botão **Verify**; nesse caso, teste com um chat novo. Veja a [documentação de chaves de API](https://docs.cursor.com/settings/api-keys) do Cursor.

## Confira se funciona

1. Mantenha a chave e a substituição da Base URL ativadas.
2. Selecione o modelo no seletor de modelos do Cursor e inicie um chat novo.
3. Peça para ele responder com `PHASEO_CURSOR_OK`.
4. Confirme que a solicitação aparece em **Configurações → Uso → Registros**.

## Remova o Phaseo

Desative a chave de API da OpenAI e a substituição da Base URL em **Cursor Settings → Models** e depois revogue a chave:

```bash
phaseo integrations remove cursor
```

A CLI não consegue limpar o armazenamento de credenciais do Cursor. Se a chave continuar aparecendo como configurada, exclua-a nas configurações Models do Cursor.

## Corrija problemas comuns

### Os modelos hospedados pelo Cursor param de funcionar

O Cursor aplica a substituição da Base URL a todos os modelos da família OpenAI. Desative **Override OpenAI Base URL** antes de voltar para um modelo hospedado pelo Cursor.

### O modelo é rejeitado

O Cursor pode rejeitar IDs que coincidem com o catálogo integrado dele ou que não se encaixam no roteamento da família OpenAI, e algumas versões rejeitam IDs com prefixo de provedor. Tente outro modelo do Phaseo que o Cursor aceite como modelo personalizado da família OpenAI.

### A autenticação falha

Execute `phaseo integrations credential cursor` de novo, substitua a chave no Cursor e confira se a Base URL é exatamente `https://api.phaseo.app/v1`.
