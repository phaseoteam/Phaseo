description: "Agrupe o uso do Gateway por aplicativo com IDs, nomes, URLs e categorias estáveis."

Envie um cabeçalho `X-App-Id` em cada solicitação para agrupar o uso dela em um aplicativo nas análises de aplicativos e nas auditorias de solicitações. Use um ID diferente para cada produto, ambiente ou experiência voltada ao cliente que você queira acompanhar separadamente. A atribuição nunca altera a resposta de inferência.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-App-Id: acme-support" \
  -H "X-App-Name: Acme Support" \
  -H "HTTP-Referer: https://acme.example/support" \
  -H "X-App-Categories: chat,productivity" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Summarize this ticket."
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const phaseo = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY,
  app: {
    id: "acme-support",
    name: "Acme Support",
    url: "https://acme.example/support",
    categories: ["chat", "productivity"],
  },
});

const response = await phaseo.generateResponse({
  model: "openai/gpt-6-astra",
  input: "Summarize this ticket.",
});
```
</CodeGroup>

A opção `app` do SDK de TypeScript envia os mesmos cabeçalhos em todas as solicitações. O Phaseo nunca define a atribuição por você.

## Cabeçalhos

| Cabeçalho | Finalidade |
| --- | --- |
| `X-App-Id` | Identificador estável escolhido pelo seu aplicativo. |
| `X-App-Name` | Nome legível exibido nas visualizações de aplicativos e de uso. |
| `HTTP-Referer` | URL da página pública ou do deployment associado ao aplicativo. |
| `X-App-Categories` | Lista separada por vírgulas com até três categorias. |
| `X-Title` | Alias de compatibilidade para um nome legível do aplicativo. |

O Phaseo identifica o aplicativo pela URL em `HTTP-Referer` quando você a envia e, caso contrário, por `X-App-Id`. Mantenha os dois estáveis: uma nova URL ou um novo ID cria um novo aplicativo nas análises.

`HTTP-Referer` não precisa corresponder ao cabeçalho `Referer` automático do navegador. Defina-o explicitamente em integrações do lado do servidor quando quiser uma URL canônica para o aplicativo.

## Categorias

Escolha até três entre `chat`, `developer-tools`, `research`, `productivity`, `education`, `commerce`, `media`, `finance` e `other`.

Os valores não diferenciam maiúsculas de minúsculas. O Phaseo ignora valores desconhecidos, remove duplicados e mantém as três primeiras categorias válidas. As categorias enviadas em solicitações posteriores são adicionadas às que já estão salvas para o aplicativo; elas nunca removem categorias escolhidas no painel.

Para gerenciar as categorias de forma centralizada em vez de no código do aplicativo, edite-as em **Configurações → Apps**.

## Mantenha a atribuição segura para compartilhar

- Não coloque IDs de clientes, endereços de e-mail nem outros dados pessoais nos cabeçalhos de atribuição.
- Trate a URL e o nome como públicos: eles podem aparecer em visualizações de aplicativos compartilhadas ou públicas.
