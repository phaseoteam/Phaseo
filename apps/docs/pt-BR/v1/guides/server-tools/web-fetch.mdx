title: "Ferramenta de servidor Web Fetch"
description: "Permita que os modelos busquem e leiam URLs específicas durante uma solicitação."
---

Adicione `phaseo:web_fetch` para que o modelo possa ler uma URL conhecida, como uma página de documentação, um artigo ou um changelog. O modelo fornece a `url`; o Phaseo busca a página e retorna o texto dela, cortado em um limite de tamanho, e o modelo pode buscar mais páginas antes de responder.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Summarize https://phaseo.app/docs/v1/guides/tool-calling" }
    ],
    "tools": [
      { "type": "phaseo:web_fetch" }
    ]
  }'
```

<span id="parameters"></span>
## Parâmetros

```json
{
  "type": "phaseo:web_fetch",
  "parameters": {
    "engine": "direct",
    "max_chars": 12000,
    "allowed_domains": ["phaseo.app"],
    "blocked_domains": ["internal.example.com"]
  }
}
```

| Parâmetro | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `engine` | string | `direct` | `auto`, `native`, `direct`, `exa`, `parallel` ou `firecrawl`. Veja [Escolha um mecanismo](#choose-an-engine). |
| `max_chars` | inteiro | `12000` | Caracteres do texto da página retornados ao modelo, até `100000`. |
| `max_content_tokens` | inteiro | Nenhum | Usado no lugar de `max_chars` quando `max_chars` é omitido. Também é o limite de tamanho para `native`. |
| `max_uses` | inteiro | `10` | Chamadas de busca por solicitação, até `100`. |
| `allowed_domains` | string[] | Nenhum | Busca somente nestes domínios. O modelo pode restringir esta lista em uma chamada, mas não ampliá-la. |
| `blocked_domains` | string[] | Nenhum | Nunca busca nestes domínios. Alias: `excluded_domains`. |

## O que o modelo envia

Cada chamada tem uma `url`. O modelo também pode enviar `engine`, `max_chars`, `max_content_tokens` e as listas de domínios.

<span id="choose-an-engine"></span>
## Escolha um mecanismo

| Mecanismo | O que é executado |
| --- | --- |
| `auto` | A busca nativa da Anthropic em `/v1/messages`. Em outros endpoints, Exa quando estiver habilitado; caso contrário, `direct`. |
| `direct` | O próprio Phaseo busca a página e reduz o HTML a texto simples. |
| `exa` | Extração de conteúdo do Exa. |
| `parallel` | Parallel Extract. |
| `firecrawl` | Firecrawl Scrape. |
| `native` | A ferramenta `web_fetch_20260209` da Anthropic, somente em `/v1/messages`. Em outros endpoints, a solicitação é rejeitada; use `direct` ou um mecanismo gerenciado. |

Se um mecanismo gerenciado não estiver habilitado, a chamada retorna `fetch_not_configured` ao modelo.

Só URLs HTTP(S) funcionam. `direct` aceita apenas tipos de conteúdo de texto, como HTML, texto simples e JSON, e retorna `unsupported_content_type` para qualquer outro. Ele segue até 5 redirecionamentos e verifica cada um em relação às suas listas de domínios.

### Busca nativa da Anthropic

```json
{
  "model": "anthropic/claude-sonnet-4.6",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "Read the docs page and summarize the limits." }
  ],
  "tools": [
    {
      "type": "phaseo:web_fetch",
      "parameters": {
        "engine": "native",
        "max_content_tokens": 9000,
        "allowed_domains": ["phaseo.app"]
      }
    }
  ],
  "tool_choice": { "type": "tool", "name": "phaseo:web_fetch" }
}
```

## O que a ferramenta retorna

```json
{
  "provider": "fetch",
  "engine": "direct",
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "text": "...",
  "truncated": false,
  "returned_chars": 8421
}
```

Verifique `truncated` antes de presumir que o modelo viu a página inteira. Para um exemplo completo, veja [Fundamentação de ferramentas com web fetch](../../cookbook/tool-grounding-with-web-fetch).

## Uso e preços

Cada busca de página soma 1 a `usage.server_tool_use.web_fetch_requests`. A Phaseo cobra $0.001 por busca gerenciada feita pelo Exa, Parallel ou Firecrawl, a menos que o cartão de preços do modelo defina o próprio preço de `server_tool_web_fetch_requests`; buscas diretas são gratuitas. Buscas por mecanismos pagos exigem créditos mesmo quando o modelo é gratuito. A busca nativa é cobrada com `native_web_fetch_requests` quando o cartão de preços do modelo a define.
