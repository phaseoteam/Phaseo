---
title: "Aplicar patch"
description: "Permita que modelos Responses retornem operações de patch validadas."
icon: "file-pen-line"
---

Use `phaseo:apply_patch` quando um fluxo de Responses precisar retornar alterações de arquivos como operações de patch estruturadas. O Phaseo valida a operação e a retorna ao seu cliente; ele não altera seu sistema de arquivos nem seu repositório.

<Note>
`phaseo:apply_patch` is available on `/v1/responses`.
</Note>

## Solicitação

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Create a small README patch for this project.",
    "tools": [
      { "type": "phaseo:apply_patch" }
    ]
  }'
```

## Estrutura da operação

Quando o modelo chama a ferramenta, ele envia um objeto de operação:

```json
{
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  }
}
```

Tipos de operação compatíveis:

| Tipo | Campos obrigatórios |
| --- | --- |
| `create_file` | `path`, `diff` |
| `update_file` | `path`, `diff` |
| `delete_file` | `path` |

## Resultado da ferramenta

O Phaseo retorna a operação validada ao ciclo do modelo:

```json
{
  "status": "completed",
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  },
  "message": "Patch operation validated. The client must apply or reject this patch and report the result."
}
```

Sua aplicação continua responsável por aplicar o patch, mostrá-lo a uma pessoa, rejeitá-lo ou pedir ao modelo uma operação revisada.

## Uso e preços

O Phaseo registra:

```json
{
  "usage": {
    "server_tool_use": {
      "apply_patch_requests": 1
    }
  }
}
```

As tabelas de preços podem cobrar isso pelo medidor `server_tool_apply_patch_requests`.
