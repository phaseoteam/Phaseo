Adicione `phaseo:apply_patch` em `/v1/responses` para receber alterações de arquivos como operações de patch estruturadas. O Phaseo confere o formato de cada operação e a devolve; ele nunca mexe nos seus arquivos. Seu app decide se aplica o patch, se o mostra a um usuário, se o rejeita ou se pede uma revisão.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Create a small README patch for this project.",
    "tools": [
      { "type": "phaseo:apply_patch" }
    ]
  }'
```

Em `/v1/chat/completions` ou `/v1/messages`, a solicitação é rejeitada.

## Parâmetros

Nenhum. Adicione `{ "type": "phaseo:apply_patch" }` como está.

## O que o modelo envia

Um objeto `operation`:

```json
{
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  }
}
```

| `type` | Campos obrigatórios | Regras do diff |
| --- | --- | --- |
| `create_file` | `path`, `diff` | Toda linha não vazia começa com `+` |
| `update_file` | `path`, `diff` | Toda linha não vazia começa com `@@`, um espaço, `+` ou `-` |
| `delete_file` | `path` | Nenhuma |

`path` não pode conter bytes nulos.

## O que a ferramenta retorna

```json
{
  "status": "completed",
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  },
  "message": "Patch operation validated. The client must apply or reject this patch and report the result."
}
```

Uma operação que viola as regras acima retorna `apply_patch_invalid_operation` com o motivo, para que o modelo possa tentar de novo.

## Uso e preços

Cada chamada soma 1 a `usage.server_tool_use.apply_patch_requests` e pode ser cobrada com `server_tool_apply_patch_requests`.
