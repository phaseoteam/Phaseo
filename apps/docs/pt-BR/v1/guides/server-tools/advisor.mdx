description: "Deixe um modelo consultar outro modelo no meio da geração."
---

Adicione `phaseo:advisor` para que o modelo principal possa pedir a um segundo modelo uma revisão, um plano, uma checagem de sanidade ou a opinião de um especialista antes de responder. O modelo principal chama o Advisor como qualquer ferramenta; o Phaseo executa o modelo Advisor e devolve o conselho como resultado da ferramenta.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Design a rate limiter for a distributed API gateway." }
    ],
    "tools": [
      {
        "type": "phaseo:advisor",
        "parameters": {
          "model": "anthropic/claude-opus-5",
          "max_uses": 1,
          "max_completion_tokens": 1400
        }
      }
    ]
  }'
```

O Advisor funciona com qualquer modelo de texto compatível. O próprio Phaseo o executa; ele só é convertido na ferramenta Advisor nativa da Anthropic se você enviar o formato de ferramenta nativo da Anthropic.

## Parâmetros

```json
{
  "type": "phaseo:advisor",
  "parameters": {
    "name": "reviewer",
    "model": "anthropic/claude-opus-5",
    "instructions": "Review plans for correctness, missing edge cases, and implementation risk.",
    "forward_transcript": true,
    "max_uses": 2,
    "max_completion_tokens": 1400,
    "reasoning": { "effort": "high" },
    "temperature": 0.2
  }
}
```

| Parâmetro | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `name` | string | Nenhum | De 1 a 64 letras, números, espaços, sublinhados ou hifens. Obrigatório quando você adiciona mais de um Advisor. |
| `model` | string | Veja abaixo | O modelo Advisor. |
| `instructions` | string | Instruções de advisor integradas | Instruções extras para o Advisor. |
| `forward_transcript` | boolean | `false` | Envia a conversa atual ao Advisor. |
| `max_uses` | integer | `1` | Chamadas a este Advisor por solicitação. |
| `max_completion_tokens` | integer | `1400` | Tokens de saída de cada resposta do Advisor. Valores abaixo de `1024` são elevados para `1024`. `max_tokens` é aceito como alias antigo. |
| `reasoning` | object | Padrão do provedor | Configurações de raciocínio, repassadas quando o modelo Advisor as aceita. |
| `temperature` | number | Padrão do provedor | Temperatura de amostragem da chamada ao Advisor. |

O modelo Advisor é `parameters.model`, se definido; caso contrário, o `model` que o modelo principal envia na chamada; caso contrário, o próprio modelo da solicitação.

## O que o modelo envia

Normalmente, um `prompt`. Se a ferramenta não fixar um modelo, a chamada também pode escolher um:

```json
{
  "model": "anthropic/claude-opus-5",
  "prompt": "Check this security design for missing controls."
}
```

Com `forward_transcript: true`, o modelo pode chamar o Advisor sem prompt, e o Advisor revisa a conversa encaminhada.

## Adicione vários advisors

Adicione uma entrada `phaseo:advisor` por advisor. Cada Advisor com nome vira uma ferramenta própria para o modelo, como `phaseo_advisor_security_reviewer`.

```json
{
  "tools": [
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "security-reviewer",
        "model": "anthropic/claude-opus-5",
        "instructions": "Review for vulnerabilities, abuse cases, and missing mitigations."
      }
    },
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "architect",
        "model": "openai/gpt-5",
        "instructions": "Review system design tradeoffs and operational risks."
      }
    }
  ]
}
```

Os nomes precisam ser únicos depois de remover os espaços das pontas, sem diferenciar maiúsculas e minúsculas, e no máximo uma entrada pode omitir `name`; caso contrário, a solicitação é rejeitada. `tool_choice: "phaseo:advisor"` com vários Advisors força o primeiro.

## O que a ferramenta retorna

```json
{
  "status": "ok",
  "name": "reviewer",
  "model": "anthropic/claude-opus-5",
  "advice": "Start with a smaller migration slice and define rollback criteria before changing traffic routing."
}
```

Se a chamada não puder ser executada, o modelo recebe um resultado de erro: `advisor_invalid_request` (sem prompt ou sem modelo), `advisor_max_uses_exceeded` ou `advisor_request_failed`.

O Advisor não guarda estado entre solicitações. Se você reenviar mensagens e resultados de ferramentas anteriores, o modelo principal vê o conselho anterior; o Advisor só vê a conversa quando `forward_transcript` está ativado. O conselho não é transmitido por streaming, e o Advisor não pode chamar ferramentas.

## Uso e preços

Cada chamada soma 1 a `usage.server_tool_use.advisor_requests` e pode ser cobrada com `server_tool_advisor_requests`. Os tokens do Advisor são somados ao uso da solicitação e cobrados com os preços do modelo Advisor.
