Adicione `phaseo:subagent` para que o modelo principal possa repassar uma tarefa autocontida a um modelo trabalhador, muitas vezes menor ou mais rápido, na mesma solicitação. O modelo principal descreve a tarefa; o Phaseo executa o trabalhador e devolve o resultado, e o modelo principal termina a resposta.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5",
    "messages": [
      { "role": "user", "content": "Compare these release notes and summarize the breaking changes." }
    ],
    "tools": [
      {
        "type": "phaseo:subagent",
        "parameters": {
          "model": "openai/gpt-6-astra",
          "instructions": "Return concise findings for the main model. Do not address the end user directly.",
          "max_uses": 3,
          "max_completion_tokens": 1200
        }
      }
    ]
  }'
```

## Parâmetros

| Parâmetro | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `model` | string | O modelo da solicitação | O modelo trabalhador. |
| `instructions` | string | Instruções de trabalhador integradas | Instruções extras para o trabalhador. |
| `max_uses` | integer | `1` | Chamadas ao Subagent por solicitação. |
| `max_completion_tokens` | integer | `1400` | Tokens de saída de cada resposta do trabalhador. Valores abaixo de `1024` são elevados para `1024`. `max_tokens` é aceito como alias antigo. |
| `reasoning` | object | Padrão do provedor | Configurações de raciocínio, repassadas quando o modelo trabalhador as aceita. |
| `temperature` | number | Padrão do provedor | Temperatura de amostragem da chamada ao trabalhador. |

O trabalhador nunca recebe a conversa: coloque na tarefa tudo de que ele precisa.

## O que o modelo envia

Um `task_description` com a tarefa completa, o contexto e a saída esperada, além de um `task_name` curto opcional:

```json
{
  "task_description": "Extract the three highest-risk migration steps from the supplied plan."
}
```

`task`, `prompt` ou `input` são aceitos no lugar de `task_description`.

## O que a ferramenta retorna

```json
{
  "status": "ok",
  "model": "openai/gpt-6-astra",
  "outcome": "The highest-risk steps are schema migration, traffic cutover, and rollback verification."
}
```

Se a chamada não puder ser executada, o modelo recebe `subagent_invalid_request` (sem tarefa), `subagent_max_uses_exceeded` ou `subagent_request_failed`.

## Uso e preços

Cada chamada soma 1 a `usage.server_tool_use.subagent_requests` e pode ser cobrada com `server_tool_subagent_requests`. Os tokens do modelo auxiliar são cobrados pelos preços desse modelo, como uma linha separada na cobrança da solicitação, e não são somados aos tokens do modelo que o chama. Um modelo auxiliar pago exige créditos mesmo quando o modelo que o chama é gratuito. Para obter uma revisão em vez de delegar o trabalho, use o [Advisor](./advisor).
