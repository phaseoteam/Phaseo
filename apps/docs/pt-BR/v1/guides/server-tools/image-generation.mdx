Adicione `phaseo:image_generation` para que o modelo possa criar uma imagem enquanto responde. O modelo escreve o prompt da imagem; o Phaseo chama o modelo de imagem e devolve a imagem ao loop do modelo.

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Design a wide product concept image for a compact desktop synthesizer.",
    "tools": [
      {
        "type": "phaseo:image_generation",
        "parameters": {
          "model": "openai/gpt-image-2",
          "quality": "high",
          "aspect_ratio": "16:9",
          "output_format": "png"
        }
      }
    ]
  }'
```

## Parâmetros

Todos os parâmetros são opcionais.

| Parâmetro | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `model` | string | `openai/gpt-image-2` | Modelo de imagem. Quando definido aqui, substitui qualquer modelo que o modelo principal pedir. |
| `quality` | string | Padrão do provedor | Indicação de qualidade, como `low`, `medium` ou `high`. |
| `size` | string | Padrão do provedor | Indicação de tamanho da imagem. |
| `aspect_ratio` | string | Padrão do provedor | Proporção, como `1:1`, `16:9` ou `9:16`. |
| `background` | string | Padrão do provedor | Indicação do modo de fundo. |
| `output_format` | string | Padrão do provedor | `png`, `jpeg` ou `webp`. |
| `output_compression` | integer | Padrão do provedor | Indicação de compressão, limitada de `0` a `100`. |
| `moderation` | string | Padrão do provedor | Indicação de moderação do provedor. |

## O que o modelo envia

Um `prompt` (ou `description`, tratado da mesma forma). Ele também pode enviar `model`, usado só quando a ferramenta não define um, e qualquer um dos outros parâmetros acima, que substituem os valores da ferramenta nessa chamada.

## O que a ferramenta retorna

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "imageUrl": "https://...",
  "mime_type": "image/png"
}
```

Alguns provedores retornam `b64_json` com os dados da imagem em base64 em vez de `imageUrl`. Se a chamada não tiver prompt, o modelo recebe `image_generation_invalid_request`; se o modelo de imagem falhar, `image_generation_failed`.

## Uso e preços

Cada imagem soma 1 a `usage.server_tool_use.image_generation_requests` e pode ser cobrada com `server_tool_image_generation_requests`. Quando o modelo de imagem informa o uso de tokens, ele é somado ao uso da solicitação e cobrado com os preços normais desse modelo.
