title: "Ferramenta de servidor Datetime"
description: "Informe aos modelos a data e a hora atuais em um ou mais fusos horários."
---

Adicione `phaseo:datetime` para que o modelo possa consultar a data e a hora atuais quando um prompt depender delas, como em "que dia é hoje em Tóquio?". O modelo decide quando chamá-la; o Phaseo retorna a hora em cada fuso horário que você listou.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What day of the week is it in Tokyo?" }
    ],
    "tools": [
      {
        "type": "phaseo:datetime",
        "parameters": { "timezones": ["Asia/Tokyo", "UTC"] }
      }
    ]
  }'
```

## Parâmetros

| Parâmetro | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `timezones` | string[] | `["UTC"]` | Até 5 nomes de fuso horário IANA, como `["Europe/London", "UTC"]`. |

Mais de 5 fusos horários, ou um nome que não seja um fuso horário IANA válido, fazem a solicitação ser rejeitada antes de o modelo rodar. O nome de tipo antigo `gateway:datetime` continua sendo aceito.

## O que a ferramenta retorna

Uma entrada por fuso horário:

```json
{
  "timezones": [
    { "timezone": "Europe/London", "datetime": "2026-07-03T10:00:00.123+01:00" },
    { "timezone": "UTC", "datetime": "2026-07-03T09:00:00.123+00:00" }
  ]
}
```

## Uso e preços

Cada chamada soma 1 a `usage.server_tool_use.datetime_requests`. A Datetime não tem medidor de preço próprio.
