---

Use `phaseo:datetime` quando uma solicitação depender da data atual, do dia da semana, da hora ou do fuso horário.

O modelo decide quando chamar a ferramenta. O Phaseo retorna ao modelo os fusos horários resolvidos e os registros de data e hora atuais; em seguida, o modelo escreve a resposta final.

## Início rápido

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "messages": [
      { "role": "user", "content": "What day of the week is it in Tokyo?" }
    ],
    "tools": [
      {
        "type": "phaseo:datetime",
        "parameters": {
          "timezones": ["Asia/Tokyo", "UTC"]
        }
      }
    ]
  }'
```

## Configuração

```json
{
  "type": "phaseo:datetime",
  "parameters": {
    "timezones": ["Europe/London", "UTC"]
  }
}
```

| Parâmetro | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `timezones` | string[] | `["UTC"]` | Até 5 nomes de fusos horários IANA para retornar em uma chamada da ferramenta, como `["Europe/London", "UTC"]`. |

## Resultado da ferramenta

O resultado da ferramenta contém uma entrada para cada fuso horário solicitado.

```json
{
  "timezones": [
    {
      "timezone": "Europe/London",
      "datetime": "2026-07-03T10:00:00.123+01:00"
    },
    {
      "timezone": "UTC",
      "datetime": "2026-07-03T09:00:00.123+00:00"
    }
  ]
}
```

## Uso

As chamadas do Datetime incrementam:

```json
{
  "usage": {
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```
