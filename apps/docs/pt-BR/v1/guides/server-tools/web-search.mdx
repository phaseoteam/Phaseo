Adicione `phaseo:web_search` para que o modelo possa pesquisar na web quando precisar de informações atuais ou com fontes. O modelo escreve a consulta e pode pesquisar várias vezes em uma solicitação; o Phaseo retorna URLs, títulos, trechos, destaques e, opcionalmente, o texto das páginas, e o modelo escreve uma resposta fundamentada.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What were the major AI announcements this week?" }
    ],
    "tools": [
      { "type": "phaseo:web_search" }
    ]
  }'
```

A mesma entrada de ferramenta funciona em `tools` em `/v1/responses` e `/v1/messages`.

<span id="parameters"></span>
## Parâmetros

```json
{
  "type": "phaseo:web_search",
  "parameters": {
    "engine": "exa",
    "max_results": 5,
    "max_total_results": 15,
    "search_context_size": "medium",
    "max_characters": 2048,
    "allowed_domains": ["arxiv.org", "nature.com"],
    "include_highlights": true,
    "include_text": false
  }
}
```

| Parâmetro | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `engine` | string | `exa` | `auto`, `native`, `exa`, `parallel`, `firecrawl`, `perplexity`, `tinyfish` ou `deepseek`. Veja [Escolha um mecanismo](#choose-an-engine). |
| `max_results` | inteiro | `5` | Resultados por chamada de pesquisa, até `25`. |
| `max_total_results` | inteiro | `25` | Resultados somando todas as pesquisas da solicitação, até `100`. Nunca é menor que `max_results`. |
| `max_uses` | inteiro | `10` | Chamadas de pesquisa por solicitação, até `100`. |
| `search_context_size` | string | `medium` | `low`, `medium` ou `high`, para mecanismos que dimensionam os destaques. |
| `max_characters` | inteiro | Padrão do mecanismo | Caracteres de texto por resultado quando o texto é incluído. |
| `allowed_domains` | string[] | Nenhum | Pesquisa somente nestes domínios. Alias: `include_domains`. |
| `excluded_domains` | string[] | Nenhum | Deixa estes domínios de fora. Alias: `exclude_domains`. |
| `include_highlights` | booleano | `true` | Inclui os destaques ou trechos do mecanismo. |
| `include_text` | booleano | `false` | Inclui um texto mais completo da página quando o mecanismo oferece suporte. |
| `user_location` | objeto | Nenhum | Indicação de localização repassada à pesquisa do próprio provedor quando `engine` é `native`. |

## O que o modelo envia

Cada chamada tem uma `query`. O modelo também pode enviar `max_results`, `engine`, `search_context_size`, as listas de domínios, `include_text`, `include_highlights`, `max_characters` e estas indicações de localização:

| Argumento | Descrição |
| --- | --- |
| `user_location` | Localização aproximada. O Perplexity usa `user_location.country` para pesquisa regional; o TinyFish usa o país e o idioma. |
| `language` | Código do idioma dos resultados, como `en`, para mecanismos que localizam. A DeepSeek o adiciona à consulta como um filtro `lang:`. |
| `page` | Página de resultados de `0` a `10`, para o TinyFish. |

Os valores que o modelo envia substituem os padrões da ferramenta naquela chamada. `max_results` continua limitado ao que resta de `max_total_results`; quando esse total se esgota, as chamadas seguintes retornam `max_total_results_reached`.

<span id="choose-an-engine"></span>
## Escolha um mecanismo

| Mecanismo | O que é executado |
| --- | --- |
| `exa` | Pesquisa gerenciada do Exa. O padrão. |
| `auto` | O padrão gerenciado, atualmente o Exa. |
| `parallel` | Pesquisa gerenciada do Parallel. |
| `firecrawl` | Pesquisa gerenciada do Firecrawl. |
| `perplexity` | A Perplexity Search API: resultados ranqueados, `search_context_size` e pesquisa regional a partir de `user_location.country`. |
| `tinyfish` | TinyFish Search: resultados ranqueados, localizados e paginados. Retorna trechos, não o texto completo da página; use [`phaseo:web_fetch`](./web-fetch) quando o modelo precisar de mais. |
| `deepseek` | DeepSeek Search: resultados ranqueados com um resumo de cada página, escrito para o modelo ler. |
| `native` | A ferramenta de pesquisa na web do próprio provedor, como `web_search_preview` da OpenAI, `web_search_20250305` da Anthropic ou `deepseek_web_search` da DeepSeek. |

Se um mecanismo gerenciado não estiver habilitado, a chamada retorna `search_not_configured` ao modelo.

Com `engine: "native"` em `/v1/chat/completions` ou `/v1/responses`, a solicitação vai apenas para provedores que executam a pesquisa na web por conta própria. Se nenhum deles atender o modelo, o Phaseo executa o mecanismo padrão no lugar e cobra como pesquisa gerenciada.

Os provedores que executam a pesquisa na web por conta própria nesses endpoints são a OpenAI, as implantações do Azure OpenAI em `/v1/responses`, a xAI e a DeepSeek em `deepseek/deepseek-v4.1-flash-1017`. A DeepSeek pesquisa por conta própria apenas quando a pesquisa na web é a única ferramenta da solicitação e a pesquisa não tem listas de domínios, porque a API dela rejeita ambos. As demais solicitações a esse modelo usam a pesquisa da Phaseo, que funciona junto com as suas próprias ferramentas. Com o raciocínio ativado, a DeepSeek executa uma pesquisa mais profunda, que abre e lê páginas em várias etapas.

Enviar a ferramenta própria da OpenAI `{ "type": "web_search" }` funciona da mesma forma que `engine: "native"`. Defina `native` somente na definição da ferramenta: se o modelo pedir `native` em uma chamada, a chamada retorna `unsupported_search_engine`, porque a ferramenta do provedor precisa ser escolhida antes de a solicitação ser enviada.

## Filtre por domínio

Use `allowed_domains` quando a resposta precisar vir de um conjunto fixo de fontes, e `excluded_domains` para tirar sites específicos de uma pesquisa aberta.

```json
{
  "type": "phaseo:web_search",
  "parameters": { "allowed_domains": ["phaseo.app", "github.com"] }
}
```

Os mecanismos tratam as listas de formas diferentes:

- **Perplexity** aceita uma das listas, não as duas, com até 20 domínios. Os domínios excluídos são enviados no formato de lista de bloqueio dele.
- **Firecrawl** aceita uma das listas, não as duas.
- **TinyFish** aceita as duas e as transforma nos operadores `site:` e `-site:` na consulta.
- **DeepSeek** aceita as duas e as transforma nos operadores `site:` e `-site:`. As consultas dela são limitadas a 128 caracteres, então a consulta é encurtada para abrir espaço para os operadores. Se apenas as listas de domínios já passarem do limite, a chamada retorna `search_query_too_long`.

## O que a ferramenta retorna

Um resultado JSON com o mecanismo, a consulta e um array `results`. Cada resultado tem `title`, `url`, `snippet` ou `highlights`, e `text` quando o texto da página foi solicitado e o mecanismo o fornece.

## Uso e preços

Cada pesquisa soma valores em `usage.server_tool_use`:

```json
{
  "usage": {
    "server_tool_use": {
      "web_search_requests": 1,
      "web_search_results": 5,
      "web_search_extra_results": 0
    }
  }
}
```

A Phaseo cobra $0.007 por busca gerenciada, mais $0.001 por resultado além dos 10 primeiros, a menos que o cartão de preços do modelo defina os próprios preços de `server_tool_web_search_requests` e `server_tool_web_search_extra_results`. Buscas com falha não são cobradas, e o TinyFish Search é gratuito nos planos publicados, então `engine: "tinyfish"` não adiciona cobrança de busca. Buscas em mecanismos pagos exigem créditos mesmo quando o modelo é gratuito. A busca nativa é cobrada com `native_web_search_requests` pelo preço publicado do provedor: por exemplo, $10 por 1,000 buscas na OpenAI e na Anthropic e $0.75 por 1,000 na DeepSeek, onde só contam as buscas que retornam resultados. A DeepSeek também cobra cada página que abre durante uma busca a $0.75 por 1,000, como `native_web_fetch_requests`.
