title: "Ferramenta de servidor Web Search"
description: "Permita que os modelos pesquisem na web durante uma solicitação."
---

Adicione `phaseo:web_search` para que o modelo possa pesquisar na web quando precisar de informações atuais ou com fontes. O modelo escreve a consulta e pode pesquisar várias vezes em uma solicitação; o Phaseo retorna URLs, títulos, trechos, destaques e, opcionalmente, o texto das páginas, e o modelo escreve uma resposta fundamentada.

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What were the major AI announcements this week?" }
    ],
    "tools": [
      { "type": "phaseo:web_search" }
    ]
  }'
```

A mesma entrada de ferramenta funciona em `tools` em `/v1/responses` e `/v1/messages`.

<span id="parameters"></span>
## Parâmetros

```json
{
  "type": "phaseo:web_search",
  "parameters": {
    "engine": "exa",
    "max_results": 5,
    "max_total_results": 15,
    "search_context_size": "medium",
    "max_characters": 2048,
    "allowed_domains": ["arxiv.org", "nature.com"],
    "include_highlights": true,
    "include_text": false
  }
}
```

| Parâmetro | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `engine` | string | `exa` | `auto`, `native`, `exa`, `parallel`, `firecrawl`, `perplexity`, `tinyfish` ou `deepseek`. Veja [Escolha um mecanismo](#choose-an-engine). |
| `mode` | string | Padrão do mecanismo | Como o mecanismo pesquisa: mais rápido, mais a fundo ou com uma execução de pesquisa aprofundada. Veja [Escolha um modo](#choose-a-mode). |
| `max_results` | inteiro | `5` | Resultados por chamada de pesquisa, até `25`. |
| `max_total_results` | inteiro | `25` | Resultados somando todas as pesquisas da solicitação, até `100`. Nunca é menor que `max_results`. |
| `max_uses` | inteiro | `10` | Chamadas de pesquisa por solicitação, até `100`. |
| `search_context_size` | string | `medium` | `low`, `medium` ou `high`, para mecanismos que dimensionam os destaques. |
| `max_characters` | inteiro | Padrão do mecanismo | Caracteres de texto por resultado quando o texto é incluído. |
| `allowed_domains` | string[] | Nenhum | Pesquisa somente nestes domínios. Alias: `include_domains`. |
| `excluded_domains` | string[] | Nenhum | Deixa estes domínios de fora. Alias: `exclude_domains`. |
| `include_highlights` | booleano | `true` | Inclui os destaques ou trechos do mecanismo. |
| `include_text` | booleano | `false` | Inclui um texto mais completo da página quando o mecanismo oferece suporte. |
| `user_location` | objeto | Nenhum | Indicação de localização. Com `engine` igual a `native`, é repassada à pesquisa do próprio provedor; caso contrário, a pesquisa da Phaseo a usa quando a chamada do modelo não informa localização. |

## O que o modelo envia

Cada chamada tem uma `query`. O modelo também pode enviar `max_results`, `engine`, `search_context_size`, as listas de domínios, `include_text`, `include_highlights`, `max_characters` e estas indicações de localização:

| Argumento | Descrição |
| --- | --- |
| `user_location` | Localização aproximada. O Exa e o Perplexity usam `user_location.country` (um código de duas letras, como `GB`) para pesquisa regional; o TinyFish usa o país e o idioma. |
| `language` | Código do idioma dos resultados, como `en`, para mecanismos que localizam. A DeepSeek o adiciona à consulta como um filtro `lang:`. |
| `page` | Página de resultados de `0` a `10`, para o TinyFish. |

Os valores que o modelo envia substituem os padrões da ferramenta naquela chamada. `max_results` continua limitado ao que resta de `max_total_results`; quando esse total se esgota, as chamadas seguintes retornam `max_total_results_reached`.

<span id="choose-an-engine"></span>
## Escolha um mecanismo

| Mecanismo | O que é executado |
| --- | --- |
| `exa` | Pesquisa gerenciada do Exa. O padrão. |
| `auto` | O padrão gerenciado, atualmente o Exa. |
| `parallel` | Pesquisa gerenciada do Parallel. |
| `firecrawl` | Pesquisa gerenciada do Firecrawl. |
| `perplexity` | A Perplexity Search API: resultados ranqueados, `search_context_size` e pesquisa regional a partir de `user_location.country`. |
| `tinyfish` | TinyFish Search: resultados ranqueados, localizados e paginados. Retorna trechos, não o texto completo da página; use [`phaseo:web_fetch`](./web-fetch) quando o modelo precisar de mais. |
| `deepseek` | DeepSeek Search: resultados ranqueados com um resumo de cada página, escrito para o modelo ler. |
| `native` | A ferramenta de pesquisa na web do próprio provedor, como `web_search_preview` da OpenAI, `web_search_20250305` da Anthropic ou `deepseek_web_search` da DeepSeek. |

Se um mecanismo gerenciado não estiver habilitado, a chamada retorna `search_not_configured` ao modelo.

Com `engine: "native"` em `/v1/chat/completions` ou `/v1/responses`, a solicitação vai apenas para provedores que executam a pesquisa na web por conta própria. Se nenhum deles atender o modelo, o Phaseo executa o mecanismo padrão no lugar e cobra como pesquisa gerenciada.

Os provedores que executam a pesquisa na web por conta própria nesses endpoints são a OpenAI, as implantações do Azure OpenAI em `/v1/responses`, a xAI e a DeepSeek em `deepseek/deepseek-v4.1-flash-1017`. A DeepSeek pesquisa por conta própria apenas quando a pesquisa na web é a única ferramenta da solicitação, sem listas de domínios nem localização do usuário, sem saída JSON e sem um `tool_choice` forçado. A API dela rejeita listas de domínios, localização e saída JSON, desativa a pesquisa na web quando a solicitação tem outras ferramentas e não consegue forçar uma pesquisa. As demais solicitações a esse modelo usam a pesquisa da Phaseo, que funciona junto com as suas próprias ferramentas. Com o raciocínio ativado, a DeepSeek executa uma pesquisa mais profunda, que abre e lê páginas em várias etapas.

As ferramentas de pesquisa dos próprios provedores não aplicam `max_results` nem `max_total_results`, e só a do Claude aplica `max_uses`. Uma pesquisa nativa que define um limite que o provedor não consegue aplicar roda no mecanismo padrão do Phaseo e é cobrada como pesquisa gerenciada.

Enviar a ferramenta própria da OpenAI `{ "type": "web_search" }` funciona da mesma forma que `engine: "native"`. Defina `native` somente na definição da ferramenta: se o modelo pedir `native` em uma chamada, a chamada retorna `unsupported_search_engine`, porque a ferramenta do provedor precisa ser escolhida antes de a solicitação ser enviada.

<span id="choose-a-mode"></span>
## Escolha um modo

Defina `mode` na ferramenta para escolher como o mecanismo dela pesquisa. O modelo não pode mudá-lo, então uma chamada nunca custa mais do que o modo escolhido. Se o modelo trocar de mecanismo, esse mecanismo roda no modo padrão. Um modo que o mecanismo não tem retorna 400.

| Mecanismo | `mode` | O que roda | Preço por chamada |
| --- | --- | --- | --- |
| `exa` | `lite` | Pesquisa de baixa latência para chat e voz | $0.004 |
| `exa` | `auto` (padrão) | Pesquisa equilibrada | $0.007 |
| `exa` | `deep-lite` | Pesquisa leve em várias etapas, cerca de 4 segundos | $0.012 |
| `exa` | `deep` | Pesquisa em várias etapas com uma `answer` sintetizada, de 4 a 15 segundos | $0.012 |
| `exa` | `agent-minimal` | Uma execução de pesquisa do Exa Agent com esforço mínimo | $0.012 |
| `exa` | `agent-low` | Uma execução de pesquisa do Exa Agent com esforço baixo | $0.025 |
| `parallel` | `turbo`, `fast` | A pesquisa mais rápida do Parallel | $0.001 |
| `parallel` | `basic`, `advanced` (padrão) | A pesquisa de maior qualidade do Parallel | $0.005 |
| `parallel` | `task-lite` | Uma execução de pesquisa do Parallel Task, de 10 a 60 segundos | $0.005 |
| `parallel` | `task-base` | Uma execução de pesquisa do Parallel Task, de 15 a 100 segundos | $0.010 |
| `perplexity` | `standard` (padrão) | Perplexity Search | $0.005 |
| `perplexity` | `fast` | Perplexity Fast Search | $0.001 |

Pesquisas no Exa e no Parallel também custam $0.001 por resultado depois dos 10 primeiros, e o Exa cobra $0.001 por página para cada tipo de conteúdo que retorna, então destaques e texto em 5 resultados somam $0.010. `firecrawl`, `tinyfish` e `deepseek` não têm modos.

Modos de pesquisa aprofundada retornam uma `answer` e as páginas citadas em `results`. Uma execução que não termina em 120 segundos retorna `research_timeout`. Execuções que expiram, falham ou perdem o cliente não são cobradas. Modos de pesquisa aprofundada não podem ser limitados a domínios, então uma ferramenta de pesquisa com `allowed_domains` ou `excluded_domains` retorna 400. O mecanismo `native` não tem modos.

## Filtre por domínio

Use `allowed_domains` quando a resposta precisar vir de um conjunto fixo de fontes, e `excluded_domains` para tirar sites específicos de uma pesquisa aberta.

```json
{
  "type": "phaseo:web_search",
  "parameters": { "allowed_domains": ["phaseo.app", "github.com"] }
}
```

Os mecanismos tratam as listas de formas diferentes:

- **Perplexity** aceita uma das listas, não as duas, com até 20 domínios. Os domínios excluídos são enviados no formato de lista de bloqueio dele.
- **Firecrawl** aceita uma das listas, não as duas.
- **TinyFish** aceita as duas e as transforma nos operadores `site:` e `-site:` na consulta.
- **DeepSeek** aceita as duas e as transforma nos operadores `site:` e `-site:`. As consultas dela são limitadas a 128 caracteres, então a consulta é encurtada para abrir espaço para os operadores. Se apenas as listas de domínios já passarem do limite, a chamada retorna `search_query_too_long`.

## O que a ferramenta retorna

Um resultado JSON com o mecanismo, a consulta e um array `results`. Cada resultado tem `title`, `url`, `snippet` ou `highlights`, e `text` quando o texto da página foi solicitado e o mecanismo o fornece.

## Uso e preços

Cada pesquisa soma valores em `usage.server_tool_use`:

```json
{
  "usage": {
    "server_tool_use": {
      "web_search_requests": 1,
      "web_search_results": 5,
      "web_search_extra_results": 0
    }
  }
}
```

O Phaseo cobra pesquisas no Exa, Parallel, Perplexity e DeepSeek pelo que cada mecanismo cobra do Phaseo: os preços em [Escolha um modo](#choose-a-mode), e $0.00075 por pesquisa do DeepSeek, cobrada só quando retorna resultados. No Exa, a cobrança é o custo que o Exa informa para a chamada, ou o preço de tabela quando o Exa não informa nenhum. Cada cobrança é uma linha nas `pricing_lines` da requisição, com `engine`, `mode` e `price_source`. Pesquisas no Firecrawl custam $0.007, mais $0.001 por resultado depois dos 10 primeiros. Buscas com falha não são cobradas, e o TinyFish Search é gratuito nos planos publicados, então `engine: "tinyfish"` não adiciona cobrança de busca. Buscas em mecanismos pagos exigem créditos mesmo quando o modelo é gratuito. A busca nativa é cobrada com `native_web_search_requests` pelo preço publicado do provedor: por exemplo, $10 por 1,000 buscas na OpenAI e na Anthropic e $0.75 por 1,000 na DeepSeek, onde só contam as buscas que retornam resultados. A DeepSeek também cobra cada leitura de página, em que lê uma URL com a ferramenta de leitura de links, a $0.75 por 1,000, como `native_web_fetch_requests`. Com o raciocínio ativado, uma única resposta da DeepSeek pode executar uma dúzia de buscas ou mais, e os resultados lidos somam-se aos tokens de entrada.
