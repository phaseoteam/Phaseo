Envie a imagem de um documento para `POST /v1/parse` para receber o texto dela em ordem de leitura, como Markdown ou como blocos estruturados de texto, imagem e tabela. Use [OCR](../api-reference/endpoint/ocr.mdx) quando precisar apenas do texto simples.

<Warning>
  O Parse aceita uma imagem por solicitação, como uma URL `http(s)` ou um URI base64 `data:image/...`. PDFs não são aceitos: converta cada página em imagem primeiro. A Cohere limita cada imagem a 20 MB, 50 megapixels e 200 MB decodificados.
</Warning>

## Converta em Markdown

Markdown é o `output_format` padrão. Ele mantém a ordem de leitura, insere as tabelas como HTML e vincula as imagens detectadas aos metadados da página.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/parse \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cohere/parse-v5.0",
    "document": {
      "type": "image_url",
      "image_url": "https://example.com/invoice.png"
    },
    "output_format": "markdown"
  }'
```

```ts TypeScript
const response = await fetch("https://api.phaseo.app/v1/parse", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "cohere/parse-v5.0",
    document: {
      type: "image_url",
      image_url: "https://example.com/invoice.png",
    },
    output_format: "markdown",
  }),
});

const parsed = await response.json();
console.log(parsed.pages[0].markdown.content);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/parse",
    headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
    json={
        "model": "cohere/parse-v5.0",
        "document": {
            "type": "image_url",
            "image_url": "https://example.com/invoice.png",
        },
        "output_format": "markdown",
    },
)
response.raise_for_status()
print(response.json()["pages"][0]["markdown"]["content"])
```
</CodeGroup>

## Retorne blocos estruturados

Defina `output_format` como `blocks` para receber regiões ordenadas de texto, imagem e tabela. Os blocos de imagem e de tabela incluem caixas delimitadoras em pixels e normalizadas, quando disponíveis.

## Como o Parse é cobrado

O uso do Parse é medido por página. A resposta inclui os metadados da Cohere e um valor normalizado `usage.input_pages` quando o provedor informa as páginas cobradas. No momento, a Cohere oferece acesso gratuito à API para avaliação, com limite de taxa, e não publicou um preço de produção para a Parse API.
