Use o endpoint Parse quando precisar de mais do que OCR simples. Ele preserva a ordem das páginas e pode retornar Markdown ou blocos estruturados de texto, imagem e tabela.

<Warning>
  A API pública Parse da Cohere aceita atualmente apenas URLs de imagem e URIs de dados de imagem em base64. Converta as páginas de PDF em imagens antes de enviá-las. Cada imagem deve ter no máximo 20 MB, 50 megapixels ou 200 MB após a decodificação.
</Warning>

## Analisar e retornar Markdown

O Markdown mantém a ordem de leitura, inclui tabelas como HTML e associa imagens detectadas aos metadados da página.

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/parse \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cohere/parse-v5.0",
    "document": {
      "type": "image_url",
      "image_url": "https://example.com/invoice.png"
    },
    "output_format": "markdown"
  }'
```

```ts TypeScript
const response = await fetch("https://api.phaseo.app/v1/parse", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "cohere/parse-v5.0",
    document: {
      type: "image_url",
      image_url: "https://example.com/invoice.png",
    },
    output_format: "markdown",
  }),
});

const parsed = await response.json();
console.log(parsed.pages[0].markdown.content);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/parse",
    headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
    json={
        "model": "cohere/parse-v5.0",
        "document": {
            "type": "image_url",
            "image_url": "https://example.com/invoice.png",
        },
        "output_format": "markdown",
    },
)
response.raise_for_status()
print(response.json()["pages"][0]["markdown"]["content"])
```
</CodeGroup>

## Retornar blocos estruturados

Defina `output_format` como `blocks` para receber regiões ordenadas de texto, imagem e tabela. Quando disponíveis, os blocos de imagem e tabela incluem caixas delimitadoras em pixels e normalizadas.

O uso do Parse é contabilizado por página. A resposta inclui metadados da Cohere e um valor normalizado de `usage.input_pages` quando o provedor informa as páginas cobradas. Atualmente, a Cohere oferece acesso gratuito e limitado por taxa à API para avaliação e ainda não publicou uma tarifa de produção para o Parse.
