更改模型 ID 并重新运行验证集；请求和响应的结构保持不变。唯一新增的控制项是多智能体版本的工作深度。

| 模型 | Phaseo 模型 ID | 推理控制 |
| --- | --- | --- |
| Grok 4.20 | `spacex-ai/grok-4.20` | `reasoning.enabled`：开启或关闭 |
| Grok 4.20 Multi-Agent（beta） | `spacex-ai/grok-4.20-multi-agent-beta` | `reasoning.effort`：`low`、`medium` 或 `high` |

## 在 Grok 4.20 上切换推理

设置 `reasoning.enabled: true` 即可使用该模型的推理版本。不设置或设为 `false` 时，Phaseo 会调用非推理版本。

```json
{
  "model": "spacex-ai/grok-4.20",
  "input": "Explain this architecture",
  "reasoning": { "enabled": true }
}
```

## 设置多智能体模型的深度

用 `reasoning.effort` 控制深度。网关请求不接受 xAI 的 `agent_count`；据 xAI 介绍，`low` 和 `medium` 运行 4 个智能体，`high` 运行更大的配置。

```json
{
  "model": "spacex-ai/grok-4.20-multi-agent-beta",
  "input": "Evaluate three rollout options with tradeoffs",
  "reasoning": { "effort": "medium" }
}
```
