把模型改为 `anthropic/claude-opus-5`，并在评估期间保留 Claude Opus 4.8 作为回退。它的价格与 Opus 4.8 相同，因此成本差异来自 token 用量。

```json
{
  "model": "anthropic/claude-opus-5",
  "models": ["anthropic/claude-opus-4.8"],
  "messages": [
    {
      "role": "user",
      "content": "Review this implementation plan and identify the highest-risk assumptions."
    }
  ]
}
```

| | Claude Opus 4.8 | Claude Opus 5 |
| --- | --- | --- |
| Phaseo 模型 ID | `anthropic/claude-opus-4.8` | `anthropic/claude-opus-5` |
| 上下文窗口 | 1M token | 1M token |
| 最大输出 | 128K token | 128K token |
| 每 1M token 价格（输入 / 输出） | $5.00 / $25.00 | $5.00 / $25.00 |
| 请求未设置推理时的思考 | 关闭 | 自适应 |

价格为目录中 Anthropic 的标准层级；其他层级和提供商请查看模型页面。

## Phaseo 如何发送请求

Opus 5 使用与 Opus 4.7 和 4.8 相同的请求结构：

- **省略采样参数。** `temperature`、`top_p` 和 `top_k` 不会发送给模型。
- **任何推理设置都会开启自适应思考。** Phaseo 发送 `thinking: {"type": "adaptive", "display": "summarized"}`，`reasoning.effort` 会转为 `output_config.effort`。思考预算不会被转发。
- **`reasoning.effort: "none"` 或 `reasoning.enabled: false` 会关闭思考**（`thinking: {"type": "disabled"}`）。
- **没有推理设置时，Phaseo 不发送 `thinking` 字段，** 因此适用 Opus 5 的默认行为，即自适应思考。Opus 4.8 只在被要求时才思考，所以同一个请求在 Opus 5 上可能会使用更多输出 token。

## 要测试的内容

- **提示词和输出：** 最长系统提示词上的指令遵循、schema 通过率、回复长度和停止行为，以及针对 Opus 4.8 调优过的提示词。
- **工具和智能体：** 工具选择和参数、工具出错或返回部分结果后的恢复、长周期任务完成率，以及高自主性工作流中的权限边界。
- **运营：** 你开放的每个 effort 级别下的延迟和 token 用量、长文档和智能体轨迹的上下文用量、每个成功任务的成本，以及主路由超时或失败时的回退。

## 上线

1. 在为用户提供服务之前，先影子运行有代表性的生产流量。
2. 按工作负载进行金丝雀发布，而不是一次性迁移所有 Opus 路由。
3. 只有在质量、延迟、成本和工具安全检查都达到目标后再全面推广。
