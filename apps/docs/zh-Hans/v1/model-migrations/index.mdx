## 迁移模型

1. 在测试输出质量之前，先按模型指南更新请求结构。
2. 在类似生产的提示词上重新运行提示词和 schema 评估。
3. 逐步迁移流量，把之前的模型作为 `models` 中的回退，并设定明确的回退规则。
