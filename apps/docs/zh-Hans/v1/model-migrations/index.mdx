# 模型迁移

如果你继续使用同一平台，只升级模型，请使用这些指南。

这些指南重点介绍最容易导致现有集成出问题的变更：

- 请求参数变更
- 提示词和推理行为变化
- 结构化输出和工具调用回归
- 灰度发布、回退和回滚策略

## 如何使用本节

1. 从与你要升级的模型系列完全匹配的指南开始。
2. 测试输出质量之前，先更新请求参数。
3. 使用接近生产环境的提示词重新运行提示词和 Schema 评估。
4. 制定明确的回退和回滚规则，再逐步切换流量。

如果你要更换的是提供商、SDK 或 Gateway，而不只是模型，请参阅[迁移指南](../migration-guides/index.mdx)。
