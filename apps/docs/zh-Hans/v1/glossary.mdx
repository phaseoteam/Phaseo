查找你在控制台、API 或本文档中遇到的词语。每一行给出一句话的含义，链接到完整介绍该术语的页面，并列出它适用的范围：API、控制台、CLI、SDK、MCP、聊天或 Slack。

## 账户和访问权限

| 术语 | 含义 | 适用范围 |
| --- | --- | --- |
| [管理员](./developers/management-api-keys.mdx) | 一种工作区角色，可管理仅限管理员的设置（例如预算、支出规则、护栏和信任策略），并可查看审计日志。 | API、控制台、CLI、MCP |
| [成员](./developers/management-api-keys.mdx) | 一种工作区角色，可使用工作区并查看其支出规则，但不能更改仅限所有者和管理员的设置。 | API、控制台、CLI、MCP |
| [所有者](./developers/management-api-keys.mdx) | 一种工作区角色，可管理与管理员相同的仅限管理员设置，并接收发给所有者的电子邮件，例如模型弃用警报。 | API、控制台、CLI、MCP |
| [工作区](./guides/workspaces.mdx) | 一个容器，它的 API 密钥、路由设置、预设、护栏和管理员访问权限与其他工作区相互独立。 | API、控制台、CLI |

## 密钥和身份验证

| 术语 | 含义 | 适用范围 |
| --- | --- | --- |
| [API 密钥](./developers/authentication.mdx#choose-a-credential) | 以 `phaseo_v1_sk_` 开头的密钥，作为 Bearer 令牌发送，用于验证模型请求和生成请求。 | API、控制台、CLI、SDK、MCP |
| [BYOK](./guides/routing-and-fallbacks.mdx#byok-considerations) | 自带密钥：Phaseo 使用你的提供商 API 密钥路由请求，模型用量由提供商计费。 | API、控制台 |
| [BYOK 回退](./guides/routing-and-fallbacks.mdx#byok-considerations) | 一项工作区设置，决定失败的 BYOK 请求是否可以使用 Phaseo 额度重试。 | API、控制台 |
| [权限](./developers/management-api-keys.mdx#choose-an-access-level) | 管理密钥或 OAuth 登录上的一项权限，例如 `keys:write`，决定它可以调用哪些管理 API。 | API、控制台、CLI、MCP |
| [管理密钥](./developers/management-api-keys.mdx) | 以 `phaseo_v1_mk_` 开头的密钥，用于密钥、预设和护栏等管理 API；它不能发送推理请求。 | API、控制台 |
| [OAuth 应用](./guides/integrations/phaseo-cli.mdx#oauth-apps) | 通过 Phaseo OAuth 让用户登录的应用，并在用户批准的范围和工作区内代表用户操作。 | API、控制台、CLI、MCP |
| [受信任的工作负载](./developers/trusted-workloads.mdx) | 发送其平台短期 OIDC 令牌而不是 API 密钥的部署或 CI 作业，由信任策略匹配。 | API、控制台 |

## 模型和提供商

| 术语 | 含义 | 适用范围 |
| --- | --- | --- |
| [上下文长度](./exploring/models.mdx#what-a-model-page-shows) | 某个提供商路由为模型支持的上下文大小，在模型页面上按提供商分别显示。 | API、控制台 |
| [已弃用（模型）](./guides/model-retirement.mdx#how-a-model-is-retired) | 实验室或提供商已宣布该模型将停用，它的请求仍照常处理。 | API、控制台 |
| [模型 ID](./api-reference/parameters.mdx#parameter-model) | 你作为 `model` 发送的 ID，例如 `openai/gpt-6-astra`，显示在每个模型页面的快速入门中。 | API、控制台、CLI、SDK、MCP |
| [私有模型](./guides/private-models.mdx) | 添加到你工作区的专用或自托管 OpenAI 兼容部署，只有你的工作区可以看到或调用。 | API、控制台 |
| [提供商](./developers/introduction.mdx#models-and-providers) | 托管模型并决定其可用性、支持的参数、定价和性能的公司。 | API、控制台、SDK、MCP |
| [提供商状态图标](./guides/provider-statuses.mdx#status-icon) | Phaseo 为提供商路由手动设置的状态：`Active`、`Lower priority`（仅作备用）或 `Disabled`。 | 控制台 |
| [带提供商限定的模型 ID](./guides/provider-qualified-models.mdx) | 带有提供商前缀的模型 ID，例如 `baseten:thinking-machines/inkling-small`，只在该提供商上运行，没有回退。 | API、SDK |
| [量化](./guides/quantization.mdx) | 用更小的数值类型存储模型权重，例如 `FP8` 或 `INT4`，以一定的质量代价换取更快的服务速度。 | API、控制台、SDK |
| [已停用（模型）](./guides/model-retirement.mdx#how-a-model-is-retired) | 停用日期已过；只要仍有提供商提供该模型，请求就能正常工作，之后会失败并返回 `410 model_retired`。 | API、控制台 |
| [可路由模型](./exploring/models.mdx#catalog-models-and-callable-models) | 当前在 Gateway 上至少有一个活跃提供商路由的模型；`GET /v1/models` 默认只列出这些模型。 | API、控制台、MCP |

## 请求和响应

| 术语 | 含义 | 适用范围 |
| --- | --- | --- |
| [缓存 token](./guides/prompt-caching.mdx#usage-and-pricing-fields) | 提供商从提示词缓存中读取的输入 token，按缓存读取价格计费，并以 `cached_tokens` 报告。 | API、SDK |
| [Gateway](./developers/introduction.mdx) | 位于 `https://api.phaseo.app/v1` 的 Phaseo API，它把每个请求路由到托管该模型的提供商。 | API、SDK |
| [生成 ID](./api-reference/endpoint/generation.mdx) | 在 `x-request-id` 和错误响应体中返回的 `G-` 请求 ID；可用于日志、查询和支持。 | API、控制台、SDK |
| [提示词缓存](./guides/prompt-caching.mdx) | 保持提示词开头部分不变，让提供商从缓存中读取它，并按缓存读取价格计费。 | API、SDK |
| [推理强度](./api-reference/parameters.mdx#parameter-reasoning) | 推理模型在回答之前思考的程度，通过 `reasoning.effort` 或 `reasoning_effort` 设置，范围从 `none` 到 `max`。 | API、SDK |
| [推理 token](./guides/context-and-token-budgeting.mdx#what-counts-towards-a-request) | 推理模型在回答之前消耗的 token；它们计为输出，并占用一部分输出上限。 | API、SDK |
| [服务层级](./guides/service-tiers.mdx) | 文本请求的速度和价格层级（`standard`、`fast`、`ultrafast` 或 `flex`），只由提供该层级的提供商处理。 | API、SDK |
| [会话 ID](./guides/routing-and-fallbacks.mdx#keep-a-conversation-on-one-provider) | 你发送的 `session_id`，用于让一段对话的请求保持在同一个提供商上，最长可持续 24 小时的活动时间。 | API、控制台、SDK |
| [流式传输](./guides/streaming.mdx) | 设置 `stream: true`，让 Gateway 在模型生成输出的同时以服务器发送事件的形式发送输出。 | API、SDK |
| [Token](./guides/context-and-token-budgeting.mdx) | 模型作为输入读取、作为输出写入的单位；每个 token 都会增加延迟和成本。 | API、控制台、SDK |
| [用量对象](./guides/prompt-caching.mdx#usage-and-pricing-fields) | 响应中的 `usage` 字段，报告该请求的输入、输出和缓存 token 数量。 | API、SDK |

## 路由

| 术语 | 含义 | 适用范围 |
| --- | --- | --- |
| [Alpha 和 Beta 提供商渠道](./guides/routing-and-fallbacks.mdx#choose-how-providers-are-ranked) | 路由设置中的开关，让预览提供商只在你选择加入时才获得流量；`provider.include_alpha` 可在单个请求中允许 Alpha 提供商。 | API、控制台 |
| [自动路由](./guides/auto-routing.mdx) | 发送 `phaseo/auto`，Phaseo 会根据工作负载、你的目标和价格上限为每个请求选择模型。 | API、控制台、CLI、SDK、Slack |
| [动态路由](./guides/routing-and-fallbacks.mdx#attach-routing-rules-to-api-keys) | 附加到 API 密钥上的带版本规则流程，可以分支、拆分流量、限制用量和切换模型。 | API、控制台 |
| [免费路由](./cookbook/free-router-first-deploy.mdx) | 发送 `phaseo/free`，Phaseo 会在一个可用的免费模型上运行该请求，无需额度。 | API、SDK |
| [模型回退](./guides/routing-and-fallbacks.mdx#request-level-model-fallbacks) | 在 `models` 中列出的模型，当前一个模型以 `429`、`500`、`502`、`503` 或 `504` 结束时按顺序尝试。 | API、SDK |
| [预设](./guides/presets.mdx) | 保存的模型、系统提示词、参数和提供商规则，调用方发送其名称（例如 `@support-triage`）即可使用。 | API、控制台、SDK |
| [预设版本标签](./guides/prompt-templates.mdx#labels) | 一个名称，例如 `production`，指向一个已发布的预设版本；移动它即可让请求前进或回滚。 | API、控制台、SDK |
| [提示词模板](./guides/prompt-templates.mdx) | 带有 `{{variables}}` 的预设消息，因此每个请求只需发送预设引用和变量值。 | API、控制台、SDK |
| [提供商回退](./guides/routing-and-fallbacks.mdx) | 当所选提供商失败时，Gateway 会尝试同一模型的下一个符合条件的提供商。 | API、SDK |
| [提供商排序](./guides/routing-and-fallbacks.mdx#choose-how-providers-are-ranked) | 提供商的排名方式：`balanced`（默认，按每个成功回答的成本）、`price`、`latency` 或 `throughput`。 | API、控制台、CLI、SDK |
| [区域路由](./guides/regional-routing.mdx) | 把文本请求发送到 `eu.api.phaseo.app` 或 `us.api.phaseo.app`，只使用在该区域运行的路由。 | API、SDK |
| [已停用模型路由](./guides/model-retirement.mdx#route-requests-to-a-replacement-automatically) | 一项需主动开启的工作区设置，把对已无提供商提供的模型的请求发送到经批准或你选择的替代模型。 | API、控制台 |

## 护栏和隐私

| 术语 | 含义 | 适用范围 |
| --- | --- | --- |
| [护栏](./cookbook/guardrails-for-api-keys.mdx) | 作用于 API 密钥或成员的策略，用于限制提供商、模型和数据处理方式，并扫描提示词；它不限制支出。 | API、控制台 |
| [护栏操作](./cookbook/guardrails-for-api-keys.mdx) | 护栏内容检查命中时执行的操作：标记、脱敏或拦截。 | API、控制台 |
| [I/O 日志](./guides/open-requests-in-chat.mdx#before-you-start) | 一项隐私设置，会保存每个请求的提示词和响应，以便你查看、重放或在聊天中打开它。 | API、控制台、聊天 |
| [提示词注入检查](./cookbook/guardrails-for-api-keys.mdx) | 一项护栏检查，扫描用户提供的内容中常见的提示词注入模式。 | API、控制台 |
| [敏感信息检查](./cookbook/guardrails-for-api-keys.mdx) | 一项护栏检查，在请求离开 Phaseo 之前找出电子邮件地址、电话号码和银行卡号等数据。 | API、控制台 |
| [ZDR](./cookbook/route-only-to-eu-or-zdr-providers.mdx) | 零数据保留：提供商不保留提示词或输出；可以按请求、按护栏或按工作区要求启用。 | API、控制台、CLI、SDK、MCP |

## 成本、限制和计费

| 术语 | 含义 | 适用范围 |
| --- | --- | --- |
| [预算](./api-reference/limits.mdx#key-limits-and-budgets) | 工作区的支出上限（每日、每周、每月或终身）；超出后的请求会收到 `429 key_limit_exceeded`。 | API、控制台 |
| [额度](./pricing/tiers.mdx) | 预付的工作区余额，付费请求按目录价格消耗；购买时收取 5% 手续费（最低 $1），`:free` 模型无需额度。 | API、控制台、CLI、MCP |
| [部门预算](./api-reference/limits.mdx#department-budgets) | 针对计入某个部门的密钥和 OAuth 请求设置的每日、每周或每月支出上限。 | API、控制台 |
| [密钥限制](./api-reference/limits.mdx#key-limits-and-budgets) | 针对单个 API 密钥的每日、每周或每月请求数或支出上限，每个请求都会检查。 | API、控制台、CLI |
| [速率限制](./api-reference/limits.mdx#gateway-limits) | 每个工作区中每个用户每分钟允许的请求数，随着工作区逐渐成熟而提高。 | API、CLI |
| [支出警报](./guides/spend-alerts.mdx#alert-types-and-bases) | 当支出、预测、激增或余额越过阈值时，支出规则发送的通知。 | API、控制台 |
| [支出规则](./guides/spend-alerts.mdx) | 当某个范围的支出越过阈值时发出警报的规则，还可以用 `429 spend_rule_blocked` 拦截后续请求。 | API、控制台 |
