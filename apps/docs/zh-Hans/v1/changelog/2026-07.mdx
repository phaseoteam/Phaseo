<Update label="2026年7月31日">

<div data-changelog-category="product">

<p className="changelog-category">产品</p>

- 工作区可在 **Settings -> Routing** 中创建动态路由，按请求字段分支、拆分流量并设置回退，再将其绑定到 API 密钥；请参阅[路由与回退](../guides/routing-and-fallbacks.mdx) ([#1314](https://github.com/phaseoteam/Phaseo/pull/1314))。
- 日志分为 **Requests**、**Upstream Requests**、**Jobs** 和 **Sessions**，每一行都会在侧边面板中打开详情 ([#1314](https://github.com/phaseoteam/Phaseo/pull/1314))。
- 支持、切换工作区和密钥管理等下拉菜单操作重新响应点击；此前其中一些点击后没有反应 ([#1378](https://github.com/phaseoteam/Phaseo/pull/1378))。

</div>

<div data-changelog-category="api">

<p className="changelog-category">API 与 SDK</p>

- 模型 ID 可以指定提供商，例如 `baseten:thinking-machines/inkling-small`，使请求只发送到该提供商且不回退；请参阅[指定提供商的模型 ID](../guides/provider-qualified-models.mdx) ([#1369](https://github.com/phaseoteam/Phaseo/pull/1369))。
- Phaseo MCP 服务器支持 MCP 协议版本 `2026-07-28`，并继续接受旧版本的客户端 ([#1341](https://github.com/phaseoteam/Phaseo/pull/1341))。

</div>

<p className="changelog-category">产品</p>

<div data-changelog-category="api">

<p className="changelog-category">API 与 SDK</p>

- Agent SDK 软件包现已发布 Python、Go、C#、PHP 和 Ruby 版本，与 TypeScript `0.2.0` 一起提供工具审批、停止条件和可取消的流式传输；请参阅[Agent SDK 概览](../sdk-reference/agent-sdk/overview.mdx) ([#1263](https://github.com/phaseoteam/Phaseo/pull/1263), [#1269](https://github.com/phaseoteam/Phaseo/pull/1269), [#1259](https://github.com/phaseoteam/Phaseo/pull/1259))。
- Rust 客户端 `phaseo` 和同步 Rust Agent SDK `phaseo-agent` `0.1.0` 已在 crates.io 发布；请参阅[Rust SDK](../sdk-reference/rust/overview.mdx) ([#1287](https://github.com/phaseoteam/Phaseo/pull/1287), [#1289](https://github.com/phaseoteam/Phaseo/pull/1289))。
- `GET /v1/models` 返回一个 `variants` 对象，关联模型的标准版和 `:free` 版，Models 页面分别列出每个版本 ([#1298](https://github.com/phaseoteam/Phaseo/pull/1298))。
- Phaseo MCP 服务器提供十个只读工具，涵盖模型、提供商、费用、额度、用量和请求健康状况，并且只申请这些工具需要的七个范围；请参阅[CLI 和 MCP](../developers/cli-and-mcp.mdx) ([#1290](https://github.com/phaseoteam/Phaseo/pull/1290), [#1292](https://github.com/phaseoteam/Phaseo/pull/1292), [#1297](https://github.com/phaseoteam/Phaseo/pull/1297))。
