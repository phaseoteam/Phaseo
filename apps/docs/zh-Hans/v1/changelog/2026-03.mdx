<p className="changelog-category">产品</p>

- 聊天室现在除了文本模型，还可以运行音频、审核和嵌入模型 ([#201](https://github.com/phaseoteam/Phaseo/pull/201), [#157](https://github.com/phaseoteam/Phaseo/pull/157))。

<div data-changelog-category="api">

<p className="changelog-category">API 与 SDK</p>

- 除 TypeScript 和 Python SDK 外，现已提供 Go、C#、Java、PHP 和 Ruby SDK，版本均为 `1.1.0` ([#203](https://github.com/phaseoteam/Phaseo/pull/203), [#201](https://github.com/phaseoteam/Phaseo/pull/201))。
- SDK `1.1.0` 会在请求指定已弃用或已退役的模型时发出警告，其模型类型和路由路径也与 API 保持一致 ([#201](https://github.com/phaseoteam/Phaseo/pull/201), [#203](https://github.com/phaseoteam/Phaseo/pull/203))。

<Update label="2026年3月2日">

<div data-changelog-category="api">

<p className="changelog-category">API 与 SDK</p>

- Responses API 接受并返回助手消息的 `phase`（`commentary` 或 `final_answer`），多轮请求可以将其原样发回；请参阅[创建响应](../api-reference/endpoint/responses.mdx) ([#130](https://github.com/phaseoteam/Phaseo/pull/130))。
- 发往 OpenAI 模型的 Responses 请求接受 `provider_options.openai.context_management`，其中 `type: "compaction"`，`compact_threshold` 可选；请参阅[参数](../api-reference/parameters.mdx) ([#130](https://github.com/phaseoteam/Phaseo/pull/130))。
- 发往 OpenAI 且未提供 `safety_identifier` 的请求，现在会使用 `user` 或 `user_id` 的值，若都没有则使用请求 ID ([#130](https://github.com/phaseoteam/Phaseo/pull/130))。

</div>
