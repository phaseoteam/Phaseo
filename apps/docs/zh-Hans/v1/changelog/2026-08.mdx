<Update label="2026年8月31日">

<div data-changelog-category="product">

<p className="changelog-category">产品</p>

- BYOK 现在每个工作区每个 UTC 月包含 250,000 次请求且不收取 Phaseo 费用，超出后按提供商等价成本的 2.5% 收费；BYOK 请求级元数据保留 90 天 ([#2056](https://github.com/phaseoteam/Phaseo/pull/2056))。

</div>

</Update>

<Update label="2026年8月30日">

<div data-changelog-category="product">

<p className="changelog-category">产品</p>

- Chat 错误现在会说明出了什么问题并给出下一步操作，例如重试、登录或选择其他模型；`402` 错误会链接到额度页面和 `phaseo/free` ([#2100](https://github.com/phaseoteam/Phaseo/pull/2100))。
- Chat 输入框最多扩展到五行，长提示词会在框内滚动，不再遮住对话 ([#2096](https://github.com/phaseoteam/Phaseo/pull/2096))。
- 模型页面可通过 `?provider=openai` 这样的链接直接打开某个提供商的详情，提供商对话框还会显示可复制的提供商限定模型 ID；请参阅[提供商限定的模型 ID](../guides/provider-qualified-models.mdx) ([#2095](https://github.com/phaseoteam/Phaseo/pull/2095), [#2052](https://github.com/phaseoteam/Phaseo/pull/2052))。
- 在你更改状态筛选之前，模型搜索只显示可以通过网关路由的模型；请参阅[检查 Gateway 的可靠性和状态](../developers/reliability-and-status.mdx) ([#2057](https://github.com/phaseoteam/Phaseo/pull/2057))。
- 公开应用排行榜将每个网站合并为一个条目，并使用易读的 URL，例如 `/apps/phaseo-chat` ([#2087](https://github.com/phaseoteam/Phaseo/pull/2087))。
- Trust Centre 新增安全白皮书、子处理方清单和 DPA 草案；删除账户后，Phaseo 现会在 30 天内从所有在用存储中删除其数据 ([#2058](https://github.com/phaseoteam/Phaseo/pull/2058))。

</div>

<div data-changelog-category="api">

<p className="changelog-category">API 与 SDK</p>

- CLI 在安装缺失的编码代理前会先询问并显示确切的安装命令；对自行管理的工具可传入 `--skip-install`；请参阅[编程智能体](../guides/integrations/coding-assistants.mdx) ([#2066](https://github.com/phaseoteam/Phaseo/pull/2066))。
- 管理 API 现可通过 `/v1/byok` 管理提供商凭据，通过 `/v1/budgets` 管理工作区预算，所有 SDK 也已相应重新生成；请参阅[列出提供商凭据](../api-reference/endpoint/provider-credentials-list.mdx) ([#2086](https://github.com/phaseoteam/Phaseo/pull/2086))。

</div>

</Update>

- `POST /v1/feedback` 和 `POST /v1/events` 可记录与请求、会话和预设关联的评分和事件，并使用新的密钥权限范围 `feedback:read` 和 `feedback:write`；请参阅[收集预设反馈](../guides/preset-feedback.mdx) ([#1033](https://github.com/phaseoteam/Phaseo/pull/1033))。
