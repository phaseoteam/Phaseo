<Update label="2026年5月7日">

<div data-changelog-category="product">

<p className="changelog-category">产品</p>

- **Models** 上的定价悬浮卡片会显示图像、视频和分档文本价格，并按质量、分辨率、时长、音频和上下文长度分组 ([#474](https://github.com/phaseoteam/Phaseo/pull/474))。

- 模型页面标题栏新增模型 ID 控件，可在模型的别名之间切换并复制所选 ID ([#473](https://github.com/phaseoteam/Phaseo/pull/473))。

</div>

<Update label="2026年5月6日">

<div data-changelog-category="api">

<p className="changelog-category">API 与 SDK</p>

- 模型列表端点接受 `availability=all`，以包含即将推出和未激活的模型，每个提供商条目都会返回 `availability_status` 和 `availability_reason`；参见 [列出模型](../api-reference/endpoint/models.mdx) ([#466](https://github.com/phaseoteam/Phaseo/pull/466))。
- 错误响应包含 `failed_providers`、`routing_diagnostics` 和 `provider_failure_diagnostics`，可指出缺少凭据或区域限制等原因；参见 [错误与调试](../api-reference/errors.mdx) ([#467](https://github.com/phaseoteam/Phaseo/pull/467))。
- 获取生成记录端点返回 `replay_request` 和 `replay_supported`，可将已记录的请求重新发送到原始端点；参见 [获取生成记录](../api-reference/endpoint/generation.mdx) ([#467](https://github.com/phaseoteam/Phaseo/pull/467))。

</div>
