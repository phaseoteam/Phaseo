<Update label="2026年4月29日" tags={["功能","模型发布","SDK"]}>

### SDK 发布

- SDK `2.0.2` 已面向以下语言发布：[TypeScript](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fsdk%402.0.2), [Python](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fpy-sdk%402.0.2), [Go](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fgo-sdk%402.0.2), [C#](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fcsharp-sdk%402.0.2), [Java](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fjava-sdk%402.0.2), [PHP](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fphp-sdk%402.0.2)、[Ruby](https://github.com/phaseoteam/Phaseo/releases/tag/%40ai-stats%2Fruby-sdk%402.0.2).
- 此版本将运行时请求使用的模型 ID 与生成的可调用辅助常量分开，因此新发布的模型无需等待下一次 SDK 发布即可使用。
- 生成的辅助函数现在会跟踪当前可由网关调用的模型快照，减少仅因目录更新而造成的 SDK 频繁变更。

### 功能

- 我们扩展了低余额提醒和账单保护，让团队能在使用量触及账户限制前收到更清晰的警告 ([PR #371](https://github.com/phaseoteam/Phaseo/pull/371)).
