## 模型迁移

如需定制的初始检查清单，请使用[迁移助手](https://phaseo.app/migrate)。

如果集成方式基本不变，只是底层模型发生变化，请使用这些指南。

指南涵盖：

- 请求参数变更
- 提示词和推理行为变化
- 结构化输出与工具调用差异
- 灰度发布、回退和回滚策略

## 如何使用这些指南

1. 确认你要更换的是平台、模型，还是两者。
2. 从迁移中风险最高的部分对应的指南开始。
3. 比较输出质量之前，先验证请求参数和端点行为。
4. 切换线上流量前，先运行接近生产环境的评估。
