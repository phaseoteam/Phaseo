根据你要更换的内容选择指南：应用调用的平台（见下文），或应用使用的模型（[模型迁移](../model-migrations)）。如果两者都要更换，先迁移平台，并在新路径验证完成之前保持模型不变。

如需定制的检查清单，请使用[迁移助手](https://phaseo.app/migrate)。

<span id="platform-migrations"></span>
## 平台迁移

每篇平台指南都遵循相同的顺序：更换 base URL 和密钥，映射模型 ID，映射平台的功能，然后测试并上线，并让回退只需更改 base URL 和密钥。

| 你调用的是 | 代码特征 | 指南 |
| --- | --- | --- |
| 直接调用 OpenAI | `api.openai.com`、`OPENAI_API_KEY`、`AzureOpenAI` | [OpenAI SDK](./from-openai) |
| 直接调用 Anthropic | `api.anthropic.com`、`ANTHROPIC_API_KEY`、`@anthropic-ai/sdk` | [Anthropic SDK](./from-anthropic) |
| OpenRouter | `openrouter.ai`、`OPENROUTER_API_KEY`、`sk-or-v1` 密钥 | [OpenRouter](./from-openrouter) |
| Vercel AI Gateway | `ai-gateway.vercel.sh`、`@ai-sdk/gateway`、AI SDK 调用中的裸字符串模型 | [Vercel AI Gateway](./from-vercel) |
| LLM Gateway | `api.llmgateway.io`、`LLM_GATEWAY_API_KEY` | [LLM Gateway](./from-llmgateway) |
| LiteLLM 代理 | 带 `model_list` 的 `config.yaml`、`LITELLM_*` 变量、端口 4000 | [LiteLLM](./from-litellm) |
| Cloudflare AI Gateway | `gateway.ai.cloudflare.com`、`cf-aig-*` 请求头 | [Cloudflare AI Gateway](./from-cloudflare) |
| Helicone | `*.helicone.ai`、`Helicone-Auth` | [Helicone](./from-helicone) |

要规划和检查上线过程，请使用[迁移功能检查清单](./feature-parity-matrix)。

## 模型迁移

当集成方式不变、只更换模型时，请使用[模型迁移指南](../model-migrations)。每篇指南都涵盖请求参数的变化、提示词和推理行为的变化、结构化输出和工具调用的差异，以及如何带着回退方案上线。

无论哪种迁移，都要先检查请求参数和接口行为，再比较输出质量，并在迁移线上流量之前运行类似生产环境的评估。
