把 OpenAI 兼容或 Anthropic 兼容的客户端指向 Phaseo 的 Base URL，提供一个 Phaseo API 密钥，并直接使用 `openai/gpt-6-astra` 这样的 Phaseo 模型 ID。每篇指南都会先完成工具的设置，再说明如何确认可以正常使用，以及哪些功能不可用。

| 客户端类型 | Base URL | 密钥填写位置 |
| --- | --- | --- |
| OpenAI 兼容 | `https://api.phaseo.app/v1` | API 密钥字段，以 `Authorization: Bearer` 发送 |
| Anthropic 兼容（会自动加上 `/v1/messages`） | `https://api.phaseo.app` | 认证令牌字段，以 `Authorization: Bearer` 发送 |

从 [Models 端点](../../api-reference/endpoint/models.mdx)获取模型 ID。新的 OpenAI 风格应用请使用 [Responses](../../api-reference/endpoint/responses.mdx)；较旧的库使用 [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) 最稳妥。设置一次 `PHASEO_API_KEY`，再把它映射到工具所需的变量；在把智能体流量迁移过来之前，先测试流式传输和工具调用。
