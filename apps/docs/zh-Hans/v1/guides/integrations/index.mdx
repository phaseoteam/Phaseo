大多数集成只需将 OpenAI 或 Anthropic 兼容客户端指向 Phaseo，并使用 Phaseo API 密钥。请从你正在使用的工具指南开始。

## 基础 URL

| 客户端类型 | 基础 URL |
| --- | --- |
| OpenAI 兼容客户端 | `https://api.phaseo.app/v1` |
| Anthropic 兼容客户端 | `https://api.phaseo.app` |

请使用 [Models 端点](../../api-reference/endpoint/models.mdx)中的模型 ID。新的 OpenAI 风格应用优先使用 [Responses](../../api-reference/endpoint/responses.mdx)。对于较旧的库，[Chat Completions](../../api-reference/endpoint/chat-completions.mdx) 通常是最稳妥的选择。

## 推荐默认值

- 一次性设置 `PHASEO_API_KEY`，并将其映射到客户端所需的环境变量。
- 保持模型 ID 不变，例如 `openai/gpt-5-nano`。
- 对于 OpenAI 兼容库，请使用 `https://api.phaseo.app/v1`，除非工具明确要求根主机。
- 对于会追加 `/v1/messages` 的 Anthropic 兼容 SDK 和工具，请使用 `https://api.phaseo.app`。
- 在迁移 Agent 流量前，先在预发布环境测试流式传输和工具调用。
