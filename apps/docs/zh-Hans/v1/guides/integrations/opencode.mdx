运行 `phaseo opencode`，为 OpenCode 添加一个包含所有兼容 Phaseo 模型的 Phaseo 提供商；或者自己在 `opencode.json` 中添加 `phaseo` 提供商。

## 使用 Phaseo CLI 设置

```bash
phaseo login
phaseo opencode --model openai/gpt-5.6-terra
```

如果没有安装 OpenCode，CLI 会显示官方安装命令，并在运行前征求你的确认。随后 setup 会：

- 添加一个全局 `phaseo` 提供商，包含所有支持 Chat Completions 的活跃 Phaseo 文本模型。如果存在全局 `opencode.jsonc`，就更新它，否则更新 `~/.config/opencode/opencode.json`，并保留你的其他设置；
- 创建一个 `Phaseo CLI: OpenCode API Key`，它 90 天后过期，每月支出上限为 $100，并保存在 OpenCode 的凭据存储中。CLI 会在操作系统凭据存储中保留自己的副本。再次运行 `phaseo opencode` 即可替换已过期的密钥。

使用 `--catalog default` 可以只添加所选模型，使用 `--dry-run` 可以预览更改。

## 手动配置 OpenCode

把提供商添加到项目中的 `opencode.json`，或你的全局 OpenCode 配置中：

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "phaseo/openai/gpt-6-astra",
  "provider": {
    "phaseo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phaseo",
      "options": {
        "baseURL": "https://api.phaseo.app/v1",
        "apiKey": "{env:PHASEO_API_KEY}"
      },
      "models": {
        "openai/gpt-6-astra": { "name": "GPT-6 Astra" },
        "openai/gpt-5.4-mini": { "name": "GPT-5.4 Mini" },
        "anthropic/claude-sonnet-5.5": { "name": "Claude Sonnet 5.5" }
      }
    }
  }
}
```

导出 `PHASEO_API_KEY`，并在 `models` 中添加或删除条目，以选择 OpenCode 列出哪些 Phaseo 模型。

## 确认可以正常使用

重启 OpenCode，从 `/models` 中选择一个 Phaseo 模型，在开始文件编辑工作之前先发送一条简短的提示词。确认该请求出现在 **设置 → 用量 → 日志** 中。

## 移除 Phaseo

```bash
phaseo integrations remove opencode
```

此命令只删除 Phaseo 提供商及其存储的凭据，然后吊销密钥。

## 解决常见问题

| 问题 | 解决方法 |
| --- | --- |
| 模型被拒绝 | 用 [Models 端点](../../api-reference/endpoint/models.mdx)核对准确的 ID。 |
| 认证失败 | 重新运行 `phaseo opencode`，并检查 `opencode auth list`。 |

要让 OpenCode 在会话中读取 Phaseo 文档，请添加 [Docs MCP](./docs-mcp.mdx) 服务器。
