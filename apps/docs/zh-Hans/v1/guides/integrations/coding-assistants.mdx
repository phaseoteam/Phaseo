先运行 `phaseo login`，再运行 `phaseo <agent>`，即可让编程智能体使用自己的 API 密钥连接 Phaseo。如果不想使用 CLI，请在智能体设置中填写[手动提供商值](#enter-the-provider-values-yourself)。

```bash
phaseo login
phaseo codex
```

## 找到适合你的智能体的命令

CLI 用以下三种方式之一设置每个智能体：

- **已配置**：CLI 写入智能体的配置文件。启动智能体并选择一个 Phaseo 模型即可。
- **仅密钥**：智能体把密钥保存在自己的应用存储中，所以 CLI 只创建密钥，并输出需要填写的字段。
- **会话**：CLI 使用临时设置启动智能体，智能体退出时这些设置会被删除。你平时的配置不会被改动。

| 智能体 | 命令 | 设置方式 | 指南 |
| --- | --- | --- | --- |
| Claude Code | `phaseo claude-code` | 已配置 | [Claude Code](./claude-code.mdx) |
| Codex | `phaseo codex` | 已配置 | [Codex](./codex.mdx) |
| OpenCode | `phaseo opencode` | 已配置 | [OpenCode](./opencode.mdx) |
| fx | `phaseo fx` | 已配置 | [fx](./fx.mdx) |
| DeepSeek Harness | `phaseo deepseek-harness` | 已配置 | [DeepSeek Harness](./deepseek-harness.mdx) |
| Pi | `phaseo pi` | 已配置 | [Pi](./pi.mdx) |
| Prime Agent | `phaseo prime-agent` | 已配置 | [Prime Agent](./prime-agent.mdx) |
| OpenClaw | `phaseo openclaw` | 已配置 | [OpenClaw](./openclaw.mdx) |
| Hermes Agent | `phaseo hermes` | 已配置 | [Hermes Agent](./hermes.mdx) |
| Aider | `phaseo aider` | 已配置 | [Aider](./aider.mdx) |
| Continue | `phaseo continue` | 已配置 | [Continue](./continue.mdx) |
| Zed | `phaseo zed` | 已配置，然后在 Zed 中粘贴密钥 | [Zed](./zed.mdx) |
| Cursor | `phaseo cursor` | 仅密钥 | [Cursor](./cursor.mdx) |
| Roo Code | `phaseo roo-code` | 仅密钥 | [Roo Code](./roo-code.mdx) |

## CLI 会创建什么

每个智能体都有自己的 API 密钥，以智能体命名（例如 `Phaseo CLI: Codex API Key`）。密钥 90 天后过期，每月支出上限为 $100。再次运行 setup 命令即可替换已过期的密钥，用 `phaseo keys update <id> --limit` 可以提高上限。

如果没有安装 Claude Code、Codex、OpenCode、fx、DeepSeek Harness、Pi、Prime Agent、OpenClaw 或 Hermes Agent，CLI 会显示官方安装命令，并在运行前征求你的确认。在非交互式终端中，它会输出安装命令后停止。OpenCode、fx、DeepSeek Harness、Pi、Prime Agent 和 OpenClaw 还会获得所有支持 Chat Completions 的活跃 Phaseo 文本模型。

| 参数或命令 | 作用 |
| --- | --- |
| `--model <id>` | 设置默认模型。Claude Code 不支持。 |
| `--catalog default` | 只添加所选模型，而不是整个模型目录。 |
| `--skip-install` | 跳过安装检查，适用于你自己管理的智能体。 |
| `--dry-run` | 显示将要进行的文件更改，但不实际执行。 |
| `phaseo integrations credential <agent>` | 输出该智能体的密钥，适用于需要你手动粘贴密钥的智能体。 |
| `phaseo integrations remove <agent>` | 删除 Phaseo 写入的配置并吊销密钥。你的其他设置保持不变。 |

## 自己填写提供商值

在任何带有 OpenAI 兼容提供商的智能体中使用这些值。字段名称因工具而异。

| 设置 | 值 |
| --- | --- |
| 提供商类型 | OpenAI Compatible |
| Base URL | `https://api.phaseo.app/v1` |
| API 密钥 | 一个 Phaseo API 密钥 |
| 模型 | 一个 Phaseo 模型 ID，例如 `openai/gpt-6-astra` |

对于使用 Anthropic Messages API 的智能体：

| 设置 | 值 |
| --- | --- |
| Base URL | `https://api.phaseo.app`（客户端会自动加上 `/v1/messages`） |
| 认证令牌 | 一个 Phaseo API 密钥 |
| 模型 | 一个 Phaseo 模型 ID，例如 `anthropic/claude-sonnet-5.5` |

有些智能体不接受包含 `/` 的模型 ID。如果你的智能体是这样，并且支持别名，请创建一个映射到 Phaseo 模型 ID 的本地别名。

## 没有单独指南的智能体

### VS Code

当你的 VS Code 版本包含 OpenAI 兼容提供商时，可以在其 Language Models 编辑器中添加模型。

1. 打开命令面板，运行 `Chat: Manage Language Models`。
2. 选择 `OpenAI Compatible` 或 `OAI Compatible`。
3. 输入你的 Phaseo API 密钥，并将端点设置为 `https://api.phaseo.app/v1`。
4. 添加一个 Phaseo 模型 ID，例如 `openai/gpt-6-astra`，并在聊天模型选择器中选中它。

如果你的版本没有 OpenAI 兼容提供商，请使用支持自定义提供商的扩展：[Continue](./continue.mdx)、[Cline](./cline.mdx)、[Roo Code](./roo-code.mdx) 或 [Kilo Code](./kilo-code.mdx)。

### Claude Desktop

Claude Desktop 无法使用自定义模型提供商。添加 [Docs MCP](./docs-mcp.mdx) 可以让它读取 Phaseo 文档；需要把 Phaseo 用作模型网关时，请使用 [Claude Code](./claude-code.mdx)。

### Deep Agents CLI 和其他 LangChain 工具

使用 [LangChain](./langchain.mdx) 中的 Base URL 和密钥。如果工具读取 OpenAI 环境变量，请设置以下变量，并在其模型字段中填写 Phaseo 模型 ID：

```bash
export OPENAI_API_KEY="your_phaseo_api_key"
export OPENAI_BASE_URL="https://api.phaseo.app/v1"
```

## 已知限制

- 服务器工具只有在智能体发送它们时才会生效：`phaseo:apply_patch` 仅在 [Responses](../../api-reference/endpoint/responses.mdx) 上可用。对于无法处理 Responses 事件或[服务器工具](../server-tools/index.mdx)的旧版智能体，使用 [Chat Completions](../../api-reference/endpoint/chat-completions.mdx) 更稳妥。
- 在让智能体编辑文件之前，先发送一个简短的聊天请求；做智能体工作时，请选择支持工具调用的模型。
- 如果希望智能体在会话中读取 Phaseo 文档，请添加 [Docs MCP](./docs-mcp.mdx)。
