只需更改三处，就能把官方 OpenAI SDK 指向 Phaseo：API 密钥、Base URL（`https://api.phaseo.app/v1`）和模型 ID。

## 安装

<CodeGroup>

```bash TypeScript
npm install openai
```

```bash Python
pip install openai
```

</CodeGroup>

## 将客户端指向 Phaseo

<CodeGroup>

```ts TypeScript
import OpenAI from "openai";

const client = new OpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
});

const response = await client.responses.create({
	model: "openai/gpt-6-astra",
	input: "Write one sentence about reliable model routing.",
});

console.log(response.output_text);
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Write one sentence about reliable model routing.",
)

print(response.output_text)
```

</CodeGroup>

输出一句话即说明密钥和 Base URL 都有效。该请求也会出现在 **设置 → 用量 → 日志** 中。

## 使用 Chat Completions

调用 Chat Completions 的代码可以使用同一个客户端：

```ts
const completion = await client.chat.completions.create({
	model: "openai/gpt-6-astra",
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

## 已知限制

- 使用带提供商前缀的 Phaseo 模型 ID：`openai/`、`anthropic/`、`google/` 等。完整的请求结构请参阅 [Responses](../../api-reference/endpoint/responses.mdx) 和 [Chat Completions](../../api-reference/endpoint/chat-completions.mdx)。
- [服务器工具](../server-tools/index.mdx)使用 Phaseo 工具名称，例如 `phaseo:web_search`。
- 对于 Anthropic 风格的 `/v1/messages` 客户端，请参阅 [Anthropic SDK](./anthropic-sdk.mdx) 指南。
