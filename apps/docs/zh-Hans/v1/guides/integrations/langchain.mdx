用你的 Phaseo 密钥和 `base_url="https://api.phaseo.app/v1"` 创建一个 `ChatOpenAI` 模型，LangChain 的链、智能体和 LangGraph 工作流就会通过 Phaseo 调用模型。

## 安装

```bash
pip install -U langchain langchain-openai
```

## 将 ChatOpenAI 指向 Phaseo

```python
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

result = llm.invoke("Write one sentence about routing reliability.")
print(result.content)
```

输出一句话即说明设置成功。

## 在 LangGraph 中使用

把同一个 `llm` 传给你的图节点或智能体构建器：

```python
def call_model(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

## 已知限制

- 这种方式使用 [Chat Completions](../../api-reference/endpoint/chat-completions.mdx)，因此只有 `/v1/chat/completions` 上提供的 Phaseo 功能可用，包括[工具调用](../tool-calling.mdx)以及[路由和回退](../routing-and-fallbacks.mdx)。
- 对于 `phaseo:apply_patch` 这类仅在 Responses 上可用的服务器工具，请直接调用 Phaseo 或使用 [OpenAI SDK](./openai-sdk.mdx)。
- 使用 LangSmith 追踪请参阅[可观测性](./observability.mdx)。
