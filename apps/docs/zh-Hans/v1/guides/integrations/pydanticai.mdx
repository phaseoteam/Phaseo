创建一个 `OpenAIChatModel`，并让其 `OpenAIProvider` 指向 `https://api.phaseo.app/v1`，PydanticAI 智能体就会在 Phaseo 模型上运行。

## 安装

```bash
pip install "pydantic-ai-slim[openai]"
```

## 将 PydanticAI 指向 Phaseo

```python
import os
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-6-astra",
    provider=OpenAIProvider(
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)

agent = Agent(model, system_prompt="Answer concisely.")
result = agent.run_sync("Reply with only: ok")
print(result.output)
```

输出 `ok` 即说明设置成功。

## 已知限制

- 这种方式使用 OpenAI 风格的 Chat Completions。对于 `phaseo:apply_patch` 这类仅在 Responses 上可用的功能，请直接调用 Phaseo 的 Responses 端点。
- 让[结构化输出](../structured-outputs.mdx)的 schema 足够小，以适应模型的上下文窗口。限制请在 [Models](../../api-reference/endpoint/models.mdx) 中查看。
