追踪 Phaseo 请求有两种方式：开启 [Broadcast](../broadcast.mdx)，无需改动代码，Phaseo 就会把每个请求的追踪数据发送到 Langfuse、LangSmith 或任何 OpenTelemetry 工具；或者在应用中保留你的追踪库，并把它的模型客户端指向 Phaseo。

| | Broadcast | 在应用中追踪 |
| --- | --- | --- |
| 追踪数据来源 | Phaseo，覆盖每个请求 | 你的应用的模型客户端 |
| 代码改动 | 无；在 **设置 → 广播** 中设置 | 包装客户端，然后更改其 Base URL |
| 追踪包含的内容 | 模型、提供商、每次提供商尝试、token、费用、耗时，以及（可选的）提示词和输出 | 你的库记录的任何内容，以及你自己的应用上下文 |

## 在 OpenAI SDK 中使用 Langfuse

保留 Langfuse 的 OpenAI 包装器，并为被包装的客户端设置 Phaseo 的 Base URL：

```bash
pip install langfuse openai
```

```python
import os
from langfuse.openai import openai

client = openai.OpenAI(
    api_key=os.environ["PHASEO_API_KEY"],
    base_url="https://api.phaseo.app/v1",
)

response = client.responses.create(
    model="openai/gpt-6-astra",
    input="Reply with only: ok",
)
```

## 在 LangChain 中使用 LangSmith

使用 [LangChain](./langchain.mdx) 的 `ChatOpenAI` 设置，并用 LangChain 常用的环境变量开启 LangSmith：

```bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your_langsmith_key"
export PHASEO_API_KEY="your_phaseo_key"
```

## OpenTelemetry

如果你的框架已经会产生 OpenTelemetry span，就不需要专门的导出器。请自己把以下请求上下文添加到 span 中：

- 模型 ID；
- 端点，例如 `responses` 或 `chat.completions`；
- Phaseo 请求 ID，可从响应元数据或[日志](../../api-reference/endpoint/activity.mdx)中获取；
- 处理该请求的提供商（开启响应元数据时）。

切勿把 Phaseo API 密钥记录为 span 属性。
