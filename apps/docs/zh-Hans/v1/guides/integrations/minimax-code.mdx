运行 `phaseo minimax` 通过 Phaseo 启动 MiniMax Code（`mcode`）会话，或者用 `mcode provider add` 添加 Phaseo，让它在每个会话中都可用。

## 通过 Phaseo CLI 运行 MiniMax Code

```bash
phaseo login
phaseo minimax --model openai/gpt-5.6-terra
```

运行器会创建一个专用密钥，把 `MINIMAX_DATA_DIR` 设为一个临时目录，用 `mcode provider add` 在其中添加 Phaseo 提供商，启动 `mcode`，并在 `mcode` 退出时删除该目录。你平时的 `~/.minimax` 配置不会被更改，密钥也只会传给提供商设置进程。MiniMax Code 自己的参数放在 `--` 之后。

| 参数 | 作用 |
| --- | --- |
| `--model <id>` | 要使用的模型。默认为 `openai/gpt-5.6-terra`。 |
| `--catalog all` | 注册所有支持 Chat Completions 的活跃 Phaseo 文本模型。 |
| `--dry-run --json` | 显示安装和启动计划，但不创建密钥。 |
| `--skip-install` | 跳过安装检查。 |

`phaseo run minimax ...` 是同一命令的完整形式。

如果没有安装 `mcode`，首次交互式运行会提示你用 MiniMax 官方安装程序安装（在 Windows 上是 PowerShell 安装程序）。如果你自己管理 MiniMax Code，请先安装，检查 `mcode --version`，再加上 `--skip-install` 重新运行。

## 手动配置 MiniMax Code

要长期保留 Phaseo 提供商，请用 MiniMax Code 自己的命令添加：

```bash
export MCODE_PROVIDER_API_KEY="your_phaseo_api_key"
mcode provider add \
  --name "Phaseo" \
  --base-url "https://api.phaseo.app/v1" \
  --api-format openai-completions \
  --model "openai/gpt-5.6-terra" \
  --use
```

MiniMax Code 会把该提供商保存在它的数据目录中。

## 确认可以正常使用

发送一条简短的提示词，并确认该请求出现在 **设置 → 用量 → 日志** 中。

## 解决常见问题

### 未安装 MiniMax Code

在交互式终端中运行该命令以批准官方安装程序，或者自己安装 MiniMax Code，再加上 `--skip-install` 重新运行。

### 提供商或模型没有列出

使用 `phaseo minimax --catalog all`，或用 `--model` 传入模型 ID。

### 你需要 ACP 而不是交互式 CLI

`phaseo minimax` 运行的是交互式 CLI。MiniMax Code 也可以用 `mcode acp` 作为 ACP 进程运行；当你的编辑器或宿主程序直接使用 ACP 时，请使用 MiniMax Code 的 ACP 配置。
