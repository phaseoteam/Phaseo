用[管理密钥](../../developers/management-api-keys.mdx)创建一个替换密钥，把你的应用切换过去，再删除旧密钥，即可零停机轮换 Phaseo API 密钥。本页给出 Infisical 连接在这次轮换中使用的值。

<Warning>
Phaseo 目前还不是 Infisical 中可选择的 App Connection。连接器、测试和界面入口仍需被 Infisical 接受。在此之前，请在你自己的轮换任务中使用下面的请求。
</Warning>

## 轮换的工作方式

```mermaid
flowchart LR
  mk["管理密钥"] -->|"POST /v1/keys"| newkey["新 API 密钥"]
  newkey -->|"存入机密"| app["应用使用新密钥"]
  app -->|"DELETE /v1/keys/{id}"| old["旧密钥已吊销"]
```

Phaseo 只在创建 API 密钥时显示一次它的值。在你删除旧密钥之前，新旧两个密钥都能使用，所以你的应用可以在机密更新期间完成切换。

## 创建限定范围的管理密钥

在 **设置 → 管理密钥** 中，创建一个具有以下能力的密钥：

| 能力 | 用途 |
| --- | --- |
| `keys:read` | 检查连接并列出受管理的密钥。 |
| `keys:write` | 创建替换密钥。 |
| `keys:delete` | 吊销旧密钥。 |

把 `phaseo_v1_mk_...` 值保存在 Infisical 中。管理密钥控制你的账户，不能用于推理。

## 连接详情

| 字段 | 值 |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| 认证 | `Authorization: Bearer <PHASEO_MANAGEMENT_KEY>` |
| 检查连接 | `GET /keys` |
| 列出 API 密钥 | `GET /keys` |
| 创建 API 密钥 | [`POST /keys`](../../api-reference/endpoint/keys-create.mdx) |
| 吊销 API 密钥 | [`DELETE /keys/{id}`](../../api-reference/endpoint/keys-delete.mdx) |

## 创建替换密钥

```bash
curl https://api.phaseo.app/v1/keys \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "infisical-production",
    "limit": 100,
    "limit_reset": "monthly",
    "include_byok_in_limit": false
  }'
```

响应中的 `data.key` 包含新密钥（只返回这一次），`data.id` 是它的 ID。

| 字段 | 取值 |
| --- | --- |
| `limit` | 以美元计的支出上限。 |
| `limit_reset` | `daily`、`weekly` 或 `monthly`。 |
| `include_byok_in_limit` | 仅为兼容而接受。BYOK 用量从不计入此上限。 |

## 吊销旧密钥

```bash
curl -X DELETE https://api.phaseo.app/v1/keys/$PREVIOUS_KEY_ID \
  -H "Authorization: Bearer $PHASEO_MANAGEMENT_KEY"
```

删除操作是幂等的：删除一个已经删除的密钥会返回 `200` 和 `{"deleted": true}`，因此重试轮换是安全的。
