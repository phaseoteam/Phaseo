运行 `phaseo cursor` 创建密钥，然后在 Cursor 中开启 OpenAI API 密钥和 **Override OpenAI Base URL** 设置。这样 Cursor 的聊天模型就会经由 Phaseo；使用 Cursor 自有模型的功能（例如 Tab 补全）可能仍然走 Cursor 的基础设施。

## 使用 Phaseo CLI 设置

```bash
phaseo login
phaseo cursor --model openai/gpt-5.6-terra
```

CLI 会创建一个 `Phaseo CLI: Cursor API Key`，它 90 天后过期，每月支出上限为 $100，并输出下面的设置。密钥过期后，再次运行 `phaseo cursor` 即可获得新密钥。CLI 不会编辑 Cursor 的凭据存储。

## 配置 Cursor

1. 打开 **Cursor Settings → Models**。
2. 找到 **OpenAI API Key** 部分并启用它。
3. 粘贴 `phaseo integrations credential cursor` 输出的密钥，或任意 Phaseo API 密钥。
4. 启用 **Override OpenAI Base URL**，输入 `https://api.phaseo.app/v1`，末尾不要加斜杠。
5. 添加或启用你想使用的 Phaseo 模型。

| Cursor 字段 | 值 |
| --- | --- |
| OpenAI API Key | `phaseo integrations credential cursor` 的输出 |
| Override OpenAI Base URL | `https://api.phaseo.app/v1` |
| Model | Cursor 接受的 Phaseo 模型 ID |

Cursor 的密钥和 Base URL 设置是全局的，而不是按提供商区分：启用的密钥和 Base URL 决定所有 OpenAI 系列请求的去向，模型名称会原样转发。有些版本保存密钥时没有 **Verify** 按钮；这时请新建一个聊天来测试。参阅 Cursor 的 [API 密钥文档](https://docs.cursor.com/settings/api-keys)。

## 确认可以正常使用

1. 保持密钥和 Base URL 覆盖处于启用状态。
2. 在 Cursor 的模型选择器中选择该模型，并新建一个聊天。
3. 让它回复 `PHASEO_CURSOR_OK`。
4. 确认该请求出现在 **设置 → 用量 → 日志** 中。

## 移除 Phaseo

在 **Cursor Settings → Models** 中停用 OpenAI API 密钥和 Base URL 覆盖，然后吊销密钥：

```bash
phaseo integrations remove cursor
```

CLI 无法清除 Cursor 的凭据存储。如果密钥仍显示为已配置，请在 Cursor 的 Models 设置中删除它。

## 解决常见问题

### Cursor 托管的模型无法使用

Cursor 会把 Base URL 覆盖应用到所有 OpenAI 系列模型。切换回 Cursor 托管的模型之前，请关闭 **Override OpenAI Base URL**。

### 模型被拒绝

如果模型 ID 与 Cursor 内置目录冲突，或不符合其 OpenAI 系列路由规则，Cursor 可能会拒绝它；有些版本还会拒绝带提供商前缀的 ID。请换一个 Cursor 接受为 OpenAI 系列自定义模型的 Phaseo 模型。

### 认证失败

再次运行 `phaseo integrations credential cursor`，在 Cursor 中替换密钥，并检查 Base URL 是否正好是 `https://api.phaseo.app/v1`。
