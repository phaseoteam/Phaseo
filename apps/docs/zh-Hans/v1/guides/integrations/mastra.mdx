用你的 Phaseo 密钥和 `baseURL: "https://api.phaseo.app/v1"` 创建一个 AI SDK OpenAI 提供商，再把它的模型传给 Mastra 智能体和工作流。

## 安装

```bash
npm install @mastra/core @ai-sdk/openai ai
```

## 将 Mastra 智能体指向 Phaseo

```ts
import { Agent } from "@mastra/core/agent";
import { createOpenAI } from "@ai-sdk/openai";

const phaseo = createOpenAI({
	apiKey: process.env.PHASEO_API_KEY,
	baseURL: "https://api.phaseo.app/v1",
	compatibility: "compatible",
});

export const agent = new Agent({
	name: "support-agent",
	instructions: "Answer in two short paragraphs.",
	model: phaseo("openai/gpt-6-astra"),
});
```

只填写 Base URL，不要加 `/chat/completions` 或 `/responses`。用一条简短的提示词运行一次智能体，并确认该请求出现在 **设置 → 用量 → 日志** 中。

## 已知限制

- Mastra 智能体的行为取决于 AI SDK 提供商。上线生产环境之前，请测试[工具调用](../tool-calling.mdx)和流式传输。
- 如果想优先使用某些提供商，请在请求中或[预设](../presets.mdx)中设置 Phaseo 路由控制。
