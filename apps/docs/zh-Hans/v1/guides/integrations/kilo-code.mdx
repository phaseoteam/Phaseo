运行 `phaseo kilo` 通过 Phaseo 启动 Kilo Code CLI 会话；或者用 `phaseo kilo-code` 创建密钥，再在 Kilo Code 扩展中添加自定义提供商。

## 通过 Phaseo 运行 Kilo Code CLI

```bash
phaseo login
phaseo kilo --model openai/gpt-5.6-terra
```

运行器会写入一个临时的 `KILO_CONFIG` 文件，启动 `kilo`，并在 Kilo 退出时删除该文件，因此你现有的 Kilo Code 或 VS Code 设置不会被改动。如果没有安装 Kilo，交互式运行会提示你安装。Kilo 自己的参数放在 `--` 之后。

| 参数 | 作用 |
| --- | --- |
| `--model <id>` | 要使用的模型。默认为 `openai/gpt-5.6-terra`。 |
| `--catalog all` | 在 Kilo 中列出所有活跃的 Phaseo 文本模型，而不只是所选模型。 |
| `--dry-run --json` | 显示安装和启动计划，但不创建密钥，也不启动 Kilo。 |
| `--skip-install` | 跳过安装检查。 |

`phaseo run kilo ...` 是同一命令的完整形式。

## 配置 Kilo Code 扩展

为扩展创建一个密钥：

```bash
phaseo login
phaseo kilo-code --model anthropic/claude-sonnet-5.5
```

然后在 VS Code 中：

1. 打开 Kilo Code，选择设置图标，打开 **Providers**，然后选择 **Add custom provider**。
2. 填写：

| Kilo Code 字段 | 值 |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.phaseo.app/v1` |
| API key | `phaseo integrations credential kilo-code` 的输出 |

3. 如果没有发现任何模型，请自己添加 ID `anthropic/claude-sonnet-5.5`。
4. 选择 **Submit**，然后选择 Phaseo 模型。

Kilo 会把所选模型显示为 `phaseo/anthropic/claude-sonnet-5.5`。`phaseo` 是本地提供商 ID，其余部分是发送给 Phaseo 的模型 ID。完整格式请参阅 Kilo 的[自定义模型](https://kilo.ai/docs/code-with-ai/agents/custom-models)文档。

## 确认可以正常使用

让 Kilo Code 回复 `PHASEO_KILO_OK`，然后确认该请求出现在 **设置 → 用量 → 日志** 中。

## 移除 Phaseo

在 Kilo Code 中删除该自定义提供商，然后运行：

```bash
phaseo integrations remove kilo-code
```

这会吊销该密钥。CLI 无法清除扩展的存储。

## 解决常见问题

### 没有发现任何模型

自己添加模型。Kilo 不需要通过 `/models` 发现模型。

### 认证失败

用 `phaseo integrations credential kilo-code` 的输出替换已保存的密钥，并保持 Base URL 与上面完全一致。

### 模型名称看起来不一样

在 Kilo 中选择 `phaseo/<Phaseo model ID>`，但不要在模型 ID 字段中加上 `phaseo/`。
