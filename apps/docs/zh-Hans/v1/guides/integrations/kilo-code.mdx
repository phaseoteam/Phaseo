选择 Phaseo CLI 启动器来运行隔离会话，或使用 CLI 创建专用密钥并手动配置现有的 Kilo Code 安装。

## 通过 Phaseo CLI 运行 Kilo Code

对于 Kilo Code CLI，让 Phaseo 为单个会话准备提供商配置：

```bash
phaseo login
phaseo kilo --model openai/gpt-5.6-terra --
```

使用 `--catalog all` 提供所有活跃的 Phaseo 文本/聊天模型，或使用 `--dry-run --json` 预览安装和启动计划。显式命令形式为 `phaseo run kilo ...`。启动器使用临时 `KILO_CONFIG` 文件，因此不会覆盖现有 Kilo Code 或 VS Code 设置。

## 使用 Phaseo CLI 创建凭据

```bash
phaseo login
phaseo setup kilo-code --model anthropic/claude-sonnet-4.6
```

## 手动配置 Kilo Code

1. 在 VS Code 中打开 Kilo Code。
2. 选择设置图标，打开 **Providers**，然后选择 **Add custom provider**。
3. 输入以下值：

| Kilo Code 字段 | 值 |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.phaseo.app/v1` |
| API key | 以下命令的输出 `phaseo integrations credential kilo-code` |

4. 如果未发现模型，请手动添加 ID `anthropic/claude-sonnet-4.6`。
5. 选择 **Submit**，然后选择 Phaseo 模型。

Kilo 会将选择显示为 `phaseo/anthropic/claude-sonnet-4.6`：`phaseo` 是本地供应商 ID，其余部分会作为模型 ID 发送给 Phaseo。

## 验证

让 Kilo Code 回复 `PHASEO_KILO_OK`，并确认请求出现在 Phaseo 活动记录中。

## 移除

在 Kilo Code 中删除自定义供应商，然后运行：

```bash
phaseo integrations remove kilo-code
```

CLI 无法清除扩展的私有存储，但移除操作会撤销密钥。

## 故障排查

### 未发现模型

手动添加模型。无需通过 `/models` 发现。

### 身份验证失败

使用 `phaseo integrations credential kilo-code` 返回的值替换已保存的值，并确保 Base URL 与显示内容完全一致。

### 模型名称看起来不同

在 Kilo 中选择 `phaseo/<Phaseo model ID>`，但不要在模型 ID 字段中添加 `phaseo/`。
