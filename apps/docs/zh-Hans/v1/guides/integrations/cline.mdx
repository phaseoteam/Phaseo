运行 `phaseo cline` 通过 Phaseo 启动 Cline CLI 会话；或者用 `phaseo setup cline` 创建密钥，再在 Cline 扩展中添加一个 **OpenAI Compatible** 提供商。该扩展把密钥保存在 VS Code 的密钥存储中，所以最后一步要在它的界面里完成。

## 通过 Phaseo 运行 Cline CLI

```bash
phaseo login
phaseo cline --model openai/gpt-5.6-terra -- --tui
```

运行器会把 Cline 设置写入一个临时目录，启动 `cline`，并在 Cline 退出时删除该目录，因此你现有的 Cline 或 VS Code 设置不会被改动。如果没有安装 Cline，交互式运行会提示你安装。Cline 自己的参数放在 `--` 之后。

| 参数 | 作用 |
| --- | --- |
| `--model <id>` | 要使用的模型。默认为 `openai/gpt-5.6-terra`。 |
| `--catalog all` | 在 Cline 中列出所有活跃的 Phaseo 文本模型，而不只是所选模型。 |
| `--dry-run --json` | 显示安装和启动计划，但不创建密钥，也不启动 Cline。 |
| `--skip-install` | 跳过安装检查。 |

`phaseo run cline ...` 是同一命令的完整形式。

## 配置 Cline 扩展

为扩展创建一个密钥：

```bash
phaseo login
phaseo setup cline --model anthropic/claude-sonnet-5.5
```

然后在 VS Code 中：

1. 打开 Cline 面板，选择设置图标，或选择聊天框下方的提供商。
2. 选择 **OpenAI Compatible** 并填写：

| Cline 字段 | 值 |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | `phaseo integrations credential cline` 的输出 |
| Model ID | `anthropic/claude-sonnet-5.5`，或 setup 输出的模型 |

3. 保存提供商。如果你的版本显示 **Verify**，请选择它。
4. 为下一个任务选择已配置的模型。

如果不想使用 CLI，可以使用任意 Phaseo API 密钥。Cline 的 [OpenAI 兼容配置](https://docs.cline.bot/enterprise-solutions/configuration/remote-configuration/openai-compatible/member-configuration)文档介绍了团队托管的设置方式。

## 确认可以正常使用

让 Cline 回复 `PHASEO_CLINE_OK`，然后确认该请求出现在 **设置 → 用量 → 日志** 中。

## 移除 Phaseo

在 Cline 中删除 Phaseo 提供商或切换到其他提供商，然后运行：

```bash
phaseo integrations remove cline
```

这会吊销该密钥。CLI 无法清除 VS Code 的扩展存储，因此在你从 Cline 中删除之前，已删除的密钥可能仍会显示在其中。

## 解决常见问题

### 验证失败

Base URL 必须与上面完全一致，包括 `/v1`。粘贴一个新获取的密钥，不要带引号或空格。

### 模型列表为空

自己输入 Phaseo 模型 ID。Cline 不需要模型发现功能。

### 聊天正常但工具调用失败

选择支持工具调用的 Phaseo 模型。连接正常并不代表该模型支持工具。
