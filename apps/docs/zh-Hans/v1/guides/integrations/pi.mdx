运行 `phaseo pi`，为 Pi 添加一个包含所有兼容 Phaseo 模型的 Phaseo 提供商扩展。

## 使用 Phaseo CLI 设置

```bash
phaseo login
phaseo pi
```

如果没有安装 Pi，CLI 会显示官方安装命令，并在运行前征求你的确认。随后 setup 会创建一个 `Phaseo CLI: Pi API Key`（90 天后过期，每月支出上限为 $100），并把提供商扩展写入 `~/.pi/agent/extensions/phaseo.ts`。该扩展列出所有支持 Chat Completions 的活跃 Phaseo 文本模型。

| 参数 | 作用 |
| --- | --- |
| `--model <id>` | 设置初始模型。默认为 `anthropic/claude-sonnet-4.6`。 |
| `--catalog default` | 只添加所选模型。 |
| `--dry-run` | 显示将要进行的文件更改，但不实际执行。 |

该扩展在请求时通过 Pi 的命令式密钥语法获取密钥，因此文件中不会写入明文密钥：

```text
!phaseo integrations credential pi
```

## 确认可以正常使用

```bash
pi
```

打开 `/model`，选择 `phaseo` 提供商，并发送一条简短的提示词。确认该请求出现在 **设置 → 用量 → 日志** 中。

## 移除 Phaseo

```bash
phaseo integrations remove pi
```

此命令只删除 Phaseo 扩展，并吊销密钥。
