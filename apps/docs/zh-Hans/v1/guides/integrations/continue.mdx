运行 `phaseo continue` 写入一份指向 Phaseo 的 Continue 配置，或者把同样的模型条目和密钥添加到你现有的配置中。IDE 扩展和 `cn` CLI 共用这份配置。

## 使用 Phaseo CLI 设置

```bash
phaseo login
phaseo continue --model anthropic/claude-sonnet-5.5
```

如果 `~/.continue/config.yaml` 和 `~/.continue/.env` 不存在，setup 会创建一个 `Phaseo CLI: Continue API Key`（90 天后过期，每月支出上限为 $100），并写入这两个文件。不指定 `--model` 时，它使用 `anthropic/claude-sonnet-4.6`。

```yaml ~/.continue/config.yaml
# Managed by Phaseo CLI
name: Phaseo
version: 1.0.0
schema: v1
models:
  - name: "anthropic/claude-sonnet-5.5 via Phaseo"
    provider: openai
    model: "anthropic/claude-sonnet-5.5"
    apiBase: https://api.phaseo.app/v1
    apiKey: ${{ secrets.PHASEO_API_KEY }}
    useResponsesApi: false
    roles: [chat, edit, apply]
```

密钥以 `PHASEO_API_KEY` 的形式写入 `~/.continue/.env`。`useResponsesApi: false` 让 Continue 继续使用 Phaseo 的 Chat Completions 端点。

<Warning>
Continue 的全局 `.env` 是明文文件，切勿提交它。IDE 扩展不会继承 shell 环境变量，因此 CLI 使用 Continue 的[本地密钥](https://docs.continue.dev/faqs#managing-local-secrets-and-environment-variables)文件。
</Warning>

## 手动配置 Continue

如果任一文件中已有你自己的设置，setup 会停止，不做任何更改。请把上面的模型条目添加到你的 `config.yaml`，并把 `PHASEO_API_KEY=<key>` 添加到你的 `.env`，密钥可以用 `phaseo integrations credential continue` 获取，也可以使用任意 Phaseo API 密钥。其他字段请参阅 Continue 的 [OpenAI 提供商](https://docs.continue.dev/customize/model-providers/top-level/openai)文档。

## 确认可以正常使用

在 VS Code 或 JetBrains 中重新加载窗口，打开 Continue，选择 **Phaseo**，让它回复 `PHASEO_CONTINUE_OK`。在 CLI 中运行 `cn`（如果当前启用的是其他配置，请使用 `/config`）并发送同样的提示词。确认该请求出现在 **设置 → 用量 → 日志** 中。

## 移除 Phaseo

```bash
phaseo integrations remove continue
```

此命令会吊销密钥；只有当这两个文件仍以 Phaseo CLI 标记开头时，才会删除它们。你自己合并进去的条目不会被改动。

## 解决常见问题

### Phaseo 没有出现

重新加载 IDE，并检查 `config.yaml` 是否包含顶层的 `name`、`version` 和 `schema` 字段。

### Continue 报告缺少密钥

检查 `~/.continue/.env` 中是否有 `phaseo integrations credential continue` 输出的密钥，然后重启 IDE。

### Continue 调用了 Responses API

在 Phaseo 模型条目中保留 `useResponsesApi: false`。
