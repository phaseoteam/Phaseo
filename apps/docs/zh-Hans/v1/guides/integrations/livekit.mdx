用你的 Phaseo 密钥把 LiveKit Agents OpenAI 插件的 LLM 指向 `https://api.phaseo.app/v1`，你的语音智能体就会使用 Phaseo 模型 ID 和路由。该插件调用 Phaseo 的 Chat Completions 端点。

## 安装

<CodeGroup>

```bash Python
uv add "livekit-agents[openai]"
```

```bash Node.js
pnpm add @livekit/agents @livekit/agents-plugin-openai
```

</CodeGroup>

## 将智能体的 LLM 指向 Phaseo

<CodeGroup>

```python Python
import os
from livekit.agents import AgentSession
from livekit.plugins import openai

session = AgentSession(
    llm=openai.LLM(
        model="openai/gpt-6-astra",
        api_key=os.environ["PHASEO_API_KEY"],
        base_url="https://api.phaseo.app/v1",
    ),
)
```

```ts Node.js
import { voice } from "@livekit/agents";
import * as openai from "@livekit/agents-plugin-openai";

const session = new voice.AgentSession({
	llm: new openai.LLM({
		model: "openai/gpt-6-astra",
		apiKey: process.env.PHASEO_API_KEY,
		baseURL: "https://api.phaseo.app/v1",
	}),
});
```

</CodeGroup>

启动一个会话，说一句话，并确认该请求出现在 **设置 → 用量 → 日志** 中。

## 已知限制

- 对于自定义端点，请使用插件的 Chat Completions 模式。LiveKit 中专用于 Responses 的 OpenAI 工具不会变成 Phaseo 服务器工具。
- 这只会路由 LLM。语音转文字和文字转语音需要单独配置，除非你使用的 LiveKit 接口在该模态上接受自定义的 OpenAI 兼容 URL。
- 在承载生产语音流量之前，请测试打断处理、[工具调用](../tool-calling.mdx)和[流式传输](../streaming.mdx)延迟。
