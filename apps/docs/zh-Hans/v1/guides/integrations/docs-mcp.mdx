---
title: "Docs MCP"
icon: "plug-zap"
description: "将 Phaseo 文档 MCP 服务器连接到 Codex、Claude Code、Cursor 或 VS Code。"
---

把 `https://phaseo.app/docs/mcp` 作为 MCP 服务器添加到你的编程智能体，它就会根据最新文档而不是训练数据来回答 Phaseo 相关问题。该服务器是只读的：智能体可以搜索文档、阅读完整页面，并读取托管的 [skill.md](https://phaseo.app/docs/skill.md) 能力摘要。

## Codex

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
codex mcp list
```

## Claude Code

把服务器添加到当前项目，或者加上 `--scope user` 让它在所有项目中可用：

```bash
claude mcp add --transport http phaseo-docs https://phaseo.app/docs/mcp
claude mcp add --transport http --scope user phaseo-docs https://phaseo.app/docs/mcp
claude mcp list
```

## Cursor

从任意文档页面的上下文菜单安装，或将其添加到 Cursor 的 MCP 配置中：

```json
{
  "mcpServers": {
    "phaseoDocs": {
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## VS Code

从任意文档页面的上下文菜单安装，或将其添加到 VS Code 的 MCP 配置中：

```json
{
  "servers": {
    "phaseoDocs": {
      "type": "http",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## OpenCode

将其添加到 `opencode.json`：

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "phaseoDocs": {
      "type": "remote",
      "url": "https://phaseo.app/docs/mcp"
    }
  }
}
```

## 确认可以正常使用

问智能体一个只有文档才能回答的问题，并检查它是否调用了 Phaseo 文档服务器：

- `Look up the Responses request format in the Phaseo docs and give me a minimal example.`
- `Use the Phaseo docs MCP server to check how provider.sort works before you change this request.`
- `Find the guardrails docs in Phaseo and summarize the parts that affect provider routing.`

智能体用它来核对请求结构、某个模型或提供商支持哪些端点，以及路由、预设、护栏和异步任务的行为。文档服务器不会让 Phaseo 成为你的模型网关；如需这样做，请参阅[编程智能体](./coding-assistants.mdx)。
