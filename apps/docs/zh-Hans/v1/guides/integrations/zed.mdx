使用 Phaseo CLI 将提供商和模型添加到 Zed，然后把密钥保存到 Zed 的钥匙串中。如不使用 CLI，请手动输入相同的提供商值。

## 使用 Phaseo CLI 设置

```bash
phaseo login
phaseo zed --model openai/gpt-5.6-terra
```

CLI 将提供商 ID `phaseo`、API URL `https://api.phaseo.app/v1` 和所选模型添加到 Zed 的 `settings.json`，不会更改无关设置。

## 在 Zed 中完成设置

Zed 会将供应商密钥存储在系统密钥链中，因此只剩这一步界面操作。

1. 打开命令面板并运行 **agent: open settings**。
2. 在 **AI** 下选择 **LLM Providers → Configure**。

![突出显示 LLM Providers 的 Zed AI 设置](/images/integrations/zed-agent-settings.png)

3. 如果已显示 Phaseo，请打开并粘贴专用密钥。否则选择 **Add Provider → OpenAI**。

![包含 Add Provider 的 Zed LLM Providers 页面](/images/integrations/zed-llm-providers.png)

4. 如需手动配置，请填写：

| 字段 | 值 |
| --- | --- |
| Provider Name | `Phaseo` |
| API URL | `https://api.phaseo.app/v1` |
| API Key | 以下命令的输出 `phaseo integrations credential zed` |
| Model Name | 所选 Phaseo 模型 ID |

![用于添加 OpenAI 兼容供应商的 Zed 表单](/images/integrations/zed-add-compatible-provider.png)

请先填写 Base URL、模型 ID 和密钥，然后再选择 **Save Provider**。

## 验证

打开新的 Agent 线程，选择 Phaseo 模型并发送简短请求。如果 Zed 提示密钥无效，请重新运行 `phaseo integrations credential zed` 并替换 Zed 中保存的密钥。

## 移除

```bash
phaseo integrations remove zed
```

CLI 会从 `settings.json` 中移除 Phaseo 供应商并撤销其专用密钥。如果 Zed 仍显示旧的密钥链条目，也请从 **LLM Providers** 中移除 Phaseo。
