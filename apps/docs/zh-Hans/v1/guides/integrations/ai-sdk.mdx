安装 `@phaseo/ai-sdk-provider`，然后在任意 AI SDK 调用中把 `phaseo("<model id>")` 作为模型传入。该提供方会从环境中读取 `PHASEO_API_KEY`。

## 安装

```bash
npm install @phaseo/ai-sdk-provider
```

不带版本的包跟随 npm 的 `latest` 标签，即 AI SDK 7 系列，并把 `ai@^7` 声明为对等依赖，npm 会为你安装它。对于较旧的 AI SDK，请安装对应的标签：

| AI SDK | 提供方契约 | 安装 |
| --- | --- | --- |
| 7（当前） | `ProviderV4`（provider 2.x） | `npm install @phaseo/ai-sdk-provider` |
| 6 | `ProviderV3`（provider 1.x，维护中） | `npm install @phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `ProviderV2` | `npm install @phaseo/ai-sdk-provider@ai-sdk-v5` |

如果你的包管理器不会安装对等依赖，请同时安装对应的 `ai` 主版本（`ai@^7`、`ai@^6` 或 `ai@^5`）。

AI SDK 8 稳定后，Phaseo 会在 npm 上把 provider 1.x 标记为已弃用。现有版本不会被移除，任何支持终止都会另行公布。

## 生成文本

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
	model: phaseo("openai/gpt-6-astra"),
	prompt: "Summarize this in one sentence.",
});

console.log(result.text);
```

同样的代码在三个系列上都能运行。使用 [Models 端点](../../api-reference/endpoint/models.mdx)中的模型 ID；每项能力仍取决于模型和上游提供商。

## 各系列支持的功能

| 功能 | AI SDK 7（provider 2.x） | AI SDK 5 |
| --- | --- | --- |
| 文本生成和流式传输 | 是 | 是 |
| 函数工具和工具结果往返 | 是，包括流式工具输入 | 是 |
| JSON 和 JSON Schema 结构化输出 | 是 | 是 |
| 嵌入和图像生成 | 是 | 是 |
| 转录和语音 | 是 | 是 |
| 重排序 | 是 | 否 |
| 与提供商无关的推理设置和输出 | 是 | |
| 文本和图像文件输入（V7 标记文件数据） | 是 | |
| URL 引用来源 | 是 | |
| 提供商元数据、用量、请求头、中止信号、原始流块 | 是 | |

AI SDK 7 一列是 provider 2.x 实现并针对 AI SDK 7 原生 v4 契约测试的内容。AI SDK 6 系列也支持重排序。

## 对文档重排序

将 AI SDK 的 `rerank()` 助手与 `phaseo.rerankingModel(modelId)` 配合使用：

```ts
import { rerank } from "ai";
import { phaseo } from "@phaseo/ai-sdk-provider";

const result = await rerank({
	model: phaseo.rerankingModel("voyage/rerank-2"),
	query: "Which document is about TypeScript?",
	documents: [
		"TypeScript adds static types to JavaScript.",
		"Rust is a systems programming language.",
	],
	topN: 1,
});
```

## 已知限制

- 对于需要 Phaseo 尚不存在的 API 能力的 `ProviderV4` 功能，该提供方不会声明支持：托管文件上传和引用、技能，以及由提供商执行的工具定义、结果或审批响应。
- 由你的应用运行的函数工具仍使用 AI SDK 的常规执行和审批流程。
- 不受支持的提供商特定或自定义提示词部分会以明确的错误失败，而不会被丢弃。
