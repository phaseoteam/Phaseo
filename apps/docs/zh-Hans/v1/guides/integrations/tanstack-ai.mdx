用你的 Phaseo 密钥、`baseURL: "https://api.phaseo.app/v1"` 和你要使用的 Phaseo 模型 ID 创建 TanStack AI 的 `openaiCompatible` 适配器。它可用于 React、Solid、Preact、Vue、Svelte 或服务端 TypeScript 中的类型安全聊天。

## 安装

```bash
npm install @tanstack/ai @tanstack/ai-openai
```

## 将适配器指向 Phaseo

```ts
import { chat } from "@tanstack/ai";
import { openaiCompatible } from "@tanstack/ai-openai/compatible";

const phaseo = openaiCompatible({
	name: "phaseo",
	baseURL: "https://api.phaseo.app/v1",
	apiKey: process.env.PHASEO_API_KEY!,
	models: ["openai/gpt-6-astra", "anthropic/claude-sonnet-5.5"],
});

const stream = chat({
	adapter: phaseo("openai/gpt-6-astra"),
	messages: [{ role: "user", content: "Reply with only: ok" }],
});
```

在 `models` 中声明你打算使用的每个 Phaseo 模型 ID。ID 请在 [Models](../../api-reference/endpoint/models.mdx) 中核对。

## 已知限制

- 该适配器使用 Chat Completions。对于仅在 Responses 上可用的功能，请直接调用 Phaseo 或使用 [OpenAI SDK](./openai-sdk.mdx)。
- 如果某个模型不支持[工具](../tool-calling.mdx)或图像，请在 TanStack AI 中声明更窄的能力，让 TypeScript 捕获不受支持的调用。
