给 LiteLLM 提供模型 `openai/<Phaseo model ID>`、你的 Phaseo 密钥和 `api_base="https://api.phaseo.app/v1"`。这既适用于直接调用 LiteLLM，也适用于 LiteLLM 代理后面的模型。

## 安装

```bash
pip install litellm
```

## 从 LiteLLM 调用 Phaseo

```python
import os
from litellm import completion

response = completion(
    model="openai/openai/gpt-6-astra",
    api_key=os.environ["PHASEO_API_KEY"],
    api_base="https://api.phaseo.app/v1",
    messages=[{"role": "user", "content": "Reply with only: ok"}],
)

print(response.choices[0].message.content)
```

输出 `ok` 即说明设置成功。LiteLLM 用 `openai/` 前缀表示 OpenAI 兼容端点。Phaseo 模型 ID 仍然是 `openai/gpt-6-astra`，所以 LiteLLM 的模型字符串变成 `openai/openai/gpt-6-astra`。

## 将 Phaseo 模型添加到 LiteLLM 代理

为每个模型设置一个别名，这样应用代码就不需要 LiteLLM 前缀：

```yaml
model_list:
  - model_name: phaseo-gpt-6-astra
    litellm_params:
      model: openai/openai/gpt-6-astra
      api_key: os.environ/PHASEO_API_KEY
      api_base: https://api.phaseo.app/v1
```

然后用 `model: "phaseo-gpt-6-astra"` 调用代理。别名能让生产环境中的模型名称保持易读。

## 已知限制

- 有些代理层会更改或丢弃它们不认识的工具类型。如果你使用 Phaseo [服务器工具](../server-tools/index.mdx)，请测试你实际使用的 LiteLLM 路由。
- LiteLLM 和 Phaseo 都会记录支出。请决定以哪一个作为费用的准确记录；Phaseo 的价格见[价格计算器](../../api-reference/endpoint/pricing-calculate.mdx)。
