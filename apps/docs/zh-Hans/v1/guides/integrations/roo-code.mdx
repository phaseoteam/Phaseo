title: "Roo Code"
description: "通过 OpenAI 兼容配置将 Roo Code 连接到 Phaseo。"
---

Phaseo CLI 会创建并管理 Roo Code 的专用密钥。Roo Code 将凭据保存在 VS Code 的安全存储中，因此需要在扩展中完成配置。

## 创建凭据

```bash
phaseo login
phaseo integrations setup roo-code --model anthropic/claude-sonnet-4.6
```

## 配置 Roo Code

1. 在 VS Code 中打开 Roo Code。
2. 打开 **Settings**，然后打开 **Providers**。
3. 创建供应商配置并选择 **OpenAI Compatible**。
4. 输入以下值：

| Roo Code 字段 | 值 |
| --- | --- |
| Base URL | `https://api.phaseo.app/v1` |
| API Key | 以下命令的输出 `phaseo integrations credential roo-code` |
| Model | `anthropic/claude-sonnet-4.6` 或设置过程中显示的模型 |

5. 保存配置并将其设为活动配置。

不同版本中的字段标签可能略有差异，但配置必须包含端点、密钥和准确的模型 ID。

## 验证

让 Roo Code 回复 `PHASEO_ROO_OK`，然后确认请求出现在 Phaseo 活动记录中。

## 移除

删除 Phaseo 配置或切换到其他配置，然后运行：

```bash
phaseo integrations remove roo-code
```

CLI 无法删除 VS Code 扩展私有存储中的值，但移除操作会撤销密钥。

## 故障排除

### 身份验证失败

使用 `phaseo integrations credential roo-code` 重新获取密钥，并确保 Base URL 以 `/v1` 结尾。

### Roo Code 找不到模型

手动输入准确的 Phaseo 模型 ID，包括供应商前缀。

### 聊天正常，但工具调用失败

切换到支持工具调用的模型。
