运行 `phaseo deepseek-harness` 把 Phaseo 添加到 DeepSeek Harness 的模型选择器中，或者在 Harness 界面或 `settings.yaml` 中添加自定义提供商。Harness 会直接向 Phaseo 发送 OpenAI 兼容的 Chat Completions 请求，因此不需要适配器。

## 使用 Phaseo CLI 设置

```bash
phaseo login
phaseo deepseek-harness
```

如果没有安装 Harness，CLI 会显示官方安装命令，并在运行前征求你的确认。随后 setup 会：

- 把提供商、Base URL、协议、模型目录和默认模型写入 `$DSH_HOME/cordis.patch.yml`（`DSH_HOME` 默认为 `~/.dsh`）中的一个带标记的块内，以便之后只更新或删除它自己的设置；
- 添加所有支持 Chat Completions 的活跃 Phaseo 文本模型。使用 `--catalog default` 可以只添加默认模型；
- 创建一个 `Phaseo CLI: DeepSeek Harness API Key`，它 90 天后过期，每月支出上限为 $100，并写入 Harness 受保护的 `$DSH_HOME/.credentials.yaml`。再次运行 `phaseo deepseek-harness` 即可替换已过期的密钥。

默认模型是 `anthropic/claude-sonnet-4.6`。要选择其他模型：

```bash
phaseo deepseek-harness --model YOUR_PHASEO_MODEL_ID
```

## 在 Harness 界面中添加 Phaseo

1. 打开 **Settings > Models**，选择 **Add a custom provider**。
2. 填写：

| 字段 | 值 |
| --- | --- |
| Provider ID | `phaseo` |
| Display name | `Phaseo` |
| Base URL | `https://api.phaseo.app/v1` |
| API protocol | `OpenAI Completions` |
| API key | 一个 Phaseo API 密钥 |

3. 在 **Model catalog** 下，选择 **Fetch available models**。
4. 选择一个支持工具的 Chat Completions 模型，例如 `anthropic/claude-sonnet-5.5`，然后保存提供商。
5. 在输入框中选择 Phaseo 模型，并开始一个新会话。

已保存的会话和凭据引用会记住提供商 ID，因此请把 `phaseo` 视为固定不变的值。显示名称、URL、密钥和模型列表之后都可以修改。

## 在 settings.yaml 中配置 Phaseo

你也可以在 `$DSH_HOME/settings.yaml` 中设置同样的提供商。不要把密钥写进这个文件：`apiKeyEnv` 指定 Harness 从哪个环境变量读取密钥。

```yaml $DSH_HOME/settings.yaml
llm-pi-ai:
  providers:
    phaseo:
      displayName: Phaseo
      apiKeyEnv: PHASEO_API_KEY
      api: openai-completions
      baseURL: https://api.phaseo.app/v1
      models:
        - id: YOUR_PHASEO_MODEL_ID
```

在启动 Harness 的环境中设置 `PHASEO_API_KEY`，或者在 Models 页面中保存密钥。把 `YOUR_PHASEO_MODEL_ID` 替换为 Phaseo 中的准确 ID；用于编程智能体时，可以先从 `anthropic/claude-sonnet-5.5` 开始。`models` 列表是一份保存下来的目录，而不是实时查询，所以想在 Harness 中使用更多 Phaseo 模型时，请更新它。

## 确认可以正常使用

先检查密钥和模型发现：

```bash
curl https://api.phaseo.app/v1/models \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

然后在新的 Harness 会话中选择一个 Phaseo 模型，发送 `Reply with exactly: Phaseo is connected.`。收到回复即说明从 Harness 经过 Phaseo 到模型提供商的整条路径都已打通。该请求也会出现在 **设置 → 用量 → 日志** 中。实时请求按正常用量计费。

## 移除 Phaseo

```bash
phaseo integrations remove deepseek-harness
```

此命令只删除 Phaseo 所拥有的配置，并吊销密钥。

## 解决常见问题

| 问题 | 解决方法 |
| --- | --- |
| 获取模型时返回 `401` | 检查密钥是否有效，以及 Base URL 是否包含 `/v1`。 |
| 选择器中没有该模型 | 重新获取目录，或在 `settings.yaml` 的 `models` 下添加准确的模型 ID。 |
| Harness 报告 `MISSING_CREDENTIAL` | 在 Models 页面中保存密钥，或让 Harness 进程能够读取 `PHASEO_API_KEY`。 |
| 请求发往了错误的端点 | 选择 `OpenAI Completions`（`openai-completions`）。此提供商使用 Phaseo 的 `/v1/chat/completions`。 |
| 开启推理时模型拒绝函数工具 | 选择在 Chat Completions 上支持工具的模型。需要通过 Responses API 才能同时使用推理和工具的模型无法使用此协议。 |
| 会话一直使用旧模型 | 开始一个新会话。Harness 会把提供商和模型保存在已经发送过请求的会话中。 |
