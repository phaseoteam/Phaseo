<Note>
Slack 智能体正在逐步向各个工作区开放。如果你的设置中还没有出现 **设置 → Slack**，说明你的工作区暂时还不能使用它。
</Note>

Phaseo 智能体在 Slack 中回答问题。在频道中提及它，或者给它发私信，它就会在线程中回复，并在撰写时以流式方式显示回答。它使用你在 Phaseo 中选择的模型，可以搜索网页和读取网页内容，还能告诉已关联的成员你的工作区在 Phaseo 上的支出、积分、API 密钥用量和模型。它还可以发布自己生成的图表和图片，读取你分享给它的图片和 PDF，并替你搜索 Slack 工作区。

所有者和管理员在 **设置 → Slack** 中添加它，选择谁可以使用它，并设置它的限制。你按当月使用过它的人数支付月费，模型 token 则像其他网关请求一样计费。

## 开始之前

- 你需要是 Phaseo 工作区的所有者或管理员，并且有权在你的 Slack 工作区中添加应用。
- 打开一次 **Chat**，检查工作区的隐私设置。Phaseo 会在首次安装前要求完成这一步。
- 充值[积分](https://phaseo.app/settings/credits)。每月扣费和智能体的模型 token 都从积分中支付。

## 把智能体添加到 Slack

<Steps>
<Step title="选择它的工作方式">

打开 **设置 → Slack**。在 **添加到 Slack** 下，选择模型、谁可以使用智能体、它可以在哪里分享用量数据，以及它的限制（见下文“限制”）。如果你的工作区可以使用自动路由，选择 **自动** 时，Phaseo 会为每个问题挑选合适的模型；否则请选择指定模型。这些都可以之后再改。

</Step>

<Step title="在 Slack 中批准">

选择 **添加到 Slack**。Slack 会显示智能体请求的权限。批准后，Slack 会带你回到 **设置 → Slack**，页面上会显示这次安装。

</Step>

<Step title="向它提问">

在 Slack 中，从你的应用里打开智能体并给它发消息。要在频道中使用它，先用 `/invite @Phaseo` 邀请它，然后提及它。

</Step>
</Steps>

安装会在你的 Phaseo 工作区中创建两样东西：

- **一个供智能体使用的 API 密钥。** 它由 Phaseo 管理，所以不会出现在你的 API 密钥列表中。智能体的模型 token 通过它计费。
- **该密钥上一个名为 Slack agent 的护栏**，它让 Slack 消息不进入训练（见下文“数据与隐私”）。

一个 Slack 工作区同一时间只能拥有来自一个 Phaseo 工作区的智能体。

## 在 Slack 中使用智能体

- **私信：** 在 Slack 中从你的应用里打开智能体，在它的 **Messages** 标签页中输入。它会回答每一条消息。
- **频道：** 把智能体邀请到公开或私有频道，然后提及它，例如 `@Phaseo which model should we use to summarise call transcripts?`。它会在线程中回复。在该线程中每次追问都要再次提及它。

回答时：

- 它会读取线程中最新的部分，直到你的消息为止，以便跟上对话。Slack 允许它一次读取 15 条消息，并允许 Phaseo 的应用在每个 Slack 工作区中大约每分钟读取一次。
  - 它总能看到线程中的第一条消息。
  - 在私信中，它会读取你和它对话中最新的消息。
  - 在频道中，它最多读取最近 30 分钟内的最新消息。
  - 如果写下的消息比它能读取的多，它会被告知缺少了一些消息。
  - 如果 Slack 当时不让它读取线程，它会根据自己之前在该线程中的回复来回答。
- 在每个线程中，它一次只回答一条消息。最多还有 5 条消息排队等待；超过后，它会请你等待前面的回答。
- 用 Slack 的停止按钮可以停止它正在生成的回答。
- 每个回答的末尾会显示模型以及这次回答的模型 token 费用，例如 `Auto → GPT-6 Luna · $0.0031`。使用 **自动** 时，它选择的模型显示在箭头后面；回答用到的其他模型显示在 + 后面。模型名称链接到它在 Phaseo 上的页面，费用链接到 **日志** 中这次回答的请求，Phaseo 工作区的成员可以打开。

## 按消息选择模型

所有者和管理员可以让成员为单条消息选择模型。在 **设置 → Slack** 的 **模型选择** 下，打开 **允许按消息选择模型**，并从 Phaseo 目录中添加最多 10 个模型。如果你的工作区可以使用自动路由，**包含“自动”** 会把 **自动** 也加入列表。其他消息仍由 **智能体** 中设置的模型回答。

要选择模型，请以 `with <model>:` 开头发送消息，并用名称或 ID 指定一个允许的模型：

```text
@Phaseo with Claude Opus 5.5: check this incident summary for gaps
with openai/gpt-6-luna: draft a reply to this customer
```

- 只会与允许的模型匹配，不区分大小写。如果只有一个允许的模型以某段文字开头，输入名称或 ID 的开头就够了，所以列表中只有一个 Claude 模型时，`with claude:` 也能用。ID 也可以省略实验室部分，例如 `with gpt-6-luna:`。
- 智能体会用该模型回答这条消息，不包括 `with …:` 部分，页脚会显示作答的模型。
- 如果你指定了不在列表中的目录模型，或者名称能对应多个模型，智能体会私下回复可选的模型，不回答这条消息。这条消息不计为一次回答。以“With …:”开头但没有指定任何模型的消息（例如“With regards to the invoice: …”）会照常回答。
- 无论哪个模型回答，每个回答的限制（$0.50 和 12 步，见下文“每个回答的限制”）都不变。模型 token 按该模型自己的价格计费。
- **Slack agent** 护栏仍然适用。如果所选模型没有任何提供商满足它，智能体会说明原因，而不回答。

### 询问另一个模型

开启模型选择后，智能体在回答时还可以向某个允许的模型征求第二意见，例如你问另一个模型怎么看时：

```text
@Phaseo draft a reply to this customer, then ask Claude Opus 5.5 to check it
```

- 另一个模型只能看到智能体发给它的内容。它看不到 Slack 线程，也不能搜索网页或使用工具。
- 智能体在一个回答中最多可以询问其他模型 3 次。它们的费用计入同一个 $0.50 限制（见下文“每个回答的限制”），当剩余额度不足以完成回答时，智能体就不再询问。
- 页脚会列出用到的每个模型，例如 `GPT-6 Luna + Claude Opus 5.5 · $0.0123`，费用也包含它们。
- 如果某个模型无法使用，例如它的提供商都不满足 **Slack agent** 护栏，智能体会得知原因，并在不用它的情况下回答。

### 比较模型

想看 2 到 3 个允许的模型如何回答同一个问题，请以 `compare` 开头，接着写用逗号分隔的模型，再加一个冒号：

```text
@Phaseo compare GPT-6 Luna, Claude Opus 5.5: what are the risks of moving our database to another region?
compare gpt-6-luna, claude, auto: summarise the EU AI Act in five bullet points
```

- 模型的匹配方式与 `with <model>:` 相同，只在允许的模型中匹配。如果某个模型不在列表中、某个名称能对应多个模型、你写的模型少于 2 个或多于 3 个，或者冒号后面没有问题，智能体会私下回复，不回答这条消息。这条消息不计为一次回答。 完全没有指定模型的消息（例如 `compare the two plans, then pick one: …`）是普通文本，智能体会照常回答。
- 每个模型只收到你的问题，不会收到线程的其余内容，并且可以搜索网页和阅读网页。它们同时回答。
- 回复中每个模型有一个部分：模型名称（链接到它在 Phaseo 上的页面）、费用和它的回答。每个模型都会被要求简短回答，过长的回答会被截断，以便全部放进一条 Slack 消息。
- 如果某个模型失败，它的部分会说明原因，其他回答照常显示。
- 一次比较计为一次回答。$0.50 的限制（见下文“每个回答的限制”）在各模型之间平均分配，页脚会列出所有模型并显示总费用。 这种分配只决定是否询问某个模型：份额低于 $0.02 的模型不会被询问。回答不会在达到份额时停止，因此可能花费更多；取而代之的是，每个模型的回答长度有上限。

### 带按钮的问题

当智能体需要你在几个选项中做出选择，或在继续之前批准某件事时，它会在线程中提问，每个选项一个按钮，最多 5 个。它也可以提供 **Other…**，点击后会打开一个小表单，让你用自己的话回答。

- 只有它正在回答的那个人可以回答。其他人点击按钮时，会收到一条只有自己能看到的提示。
- 你也可以直接在线程中回复（在频道中需要提及智能体）。你的回复会被当作你的回答。
- 你回答后，按钮会被替换为你的回答，智能体会从停下的地方继续。
- 一个问题最多等待一小时。超过一小时后，问题会显示已过期，这次回答到此结束。准备好后再问一次即可。
- 等待期间，Slack 的停止按钮同样可用。
- 等待期间，线程中其他人的消息会排队等待，并会私下告知他们智能体正在等谁回答。
- 一次回答最多可以问 3 个问题。整个过程算作一次回答，每个回答的限制覆盖全部内容，包括每个问题之前和之后。

### Home 标签页

在 Slack 中打开智能体并选择 **Home**，可以查看使用方法、它使用的模型，以及你的 Phaseo 账户是否已连接。如果尚未连接，而连接会有帮助（在 **仅限已关联的账户** 时，或在允许 **用量数据** 的地方），标签页会显示 **Connect your Phaseo account** 按钮。已连接账户的 Phaseo 工作区成员还能看到智能体本月（UTC）在这个 Slack 工作区中给出了多少次回答。标签页只显示设置和数字，从不显示消息。 它还会列出你设置的定期任务及其下次运行时间（见下文“计划任务”）。

使用你自己的 Slack 应用时，Home 标签页需要最新的清单：把 `home_tab_enabled` 设为 `true`，并添加机器人事件 `app_home_opened`。

## 图表、图片和文件

智能体可以在线程中发布图表和图片，并读取你分享给它的图片和 PDF。

- **图表：** 让它画一张图表，例如 `@Phaseo chart our spend by week this month`。智能体会根据手头的数字画出柱状图、折线图或饼图，并以图片形式发布到线程中。图表文字使用拉丁字母和西里尔字母；其他文字会写在它的回答里。
- **图片：** 让它生成一张，例如 `@Phaseo make an icon of a paper plane in blue`。它通过智能体的 API 密钥使用 [GPT Image 2](https://phaseo.app/models/openai/gpt-image-2)，像其他请求一样计费。一张图片花费几美分，计入该回答的 $0.50 限制（见下文"每个回答的限制"），回答的页脚也会包含它。一个回答最多生成 2 张图片，并且只在限制还剩至少 $0.15 时生成。
- **你分享的文件：** 把图片（PNG、JPEG、GIF 或 WebP，每张最多 5 MB）或 PDF（最多 10 MB）附加到你的消息上，或附加到智能体会读取的线程中更早的消息上。每个回答最多读取 4 个文件，合计 12 MB，从最新的开始。暂时还无法读取其他类型的文件。

模型本身也必须能读取图片或 PDF。使用 **Auto** 时，智能体会发送这些文件；如果它选中的模型无法读取，就不带文件回答。使用指定模型时，如果该模型无法读取你分享的文件类型，智能体会告诉你。

你分享的文件只会为读取它们的回答下载，从不保存。智能体发布的图表和图片与其他文件一样，是你的 Slack 工作区中的文件。

### 更新 Slack 权限

图表和图片需要 Slack 的 `files:write` 权限，读取文件需要 `files:read`，搜索 Slack（见下文"搜索 Slack"）需要 `search:read.public` 和 `search:read.files`。如果智能体是在能做这些之前添加的，它还没有这些权限：它会告诉大家需要管理员更新它的权限，并且 **设置 → Slack** 会显示 **更新 Slack 权限**。

1. 选择 **更新 Slack 权限**。Slack 会显示智能体请求的权限。
2. 为同一个 Slack 工作区批准这些权限。Slack 会把你带回 **设置 → Slack**。

更新会保留智能体的设置、API 密钥、护栏和历史记录。使用你自己的 Slack 应用时，请先把 **设置 → Slack** 列出的 scope 添加到它的清单中（见下文"使用你自己的 Slack 应用"）。

## 搜索 Slack

智能体可以替提问者搜索你的 Slack 工作区，并在回答中附上它用到的消息和文件的链接。例如：

```text
What did we decide about the launch date?
@Phaseo find the latest incident review in #ops and summarise it
Who has been working on the billing migration this month?
```

- **它以你的身份搜索。** 它使用 Slack 的实时搜索，凭 Slack 为你的消息给它的权限进行搜索，因此只会找到你在 Slack 中能看到的内容。它只搜索公开频道，从不搜索私有频道、私信或群组私信。
- **它为用到的内容附上链接。** 它依据的每条消息或每个文件都有链接，你可以在 Slack 中打开。搜索没有结果时，它会说明。
- **它可以缩小搜索范围**，限定到某个频道、某个人或某个日期范围；每个回答最多搜索 4 次，每次 10 条结果。
- **按含义或按关键词。** 在包含 AI 搜索的 Slack 套餐（Business+ 和 Enterprise+）中，用你自己的话提出的问题会按含义搜索；其他套餐按关键词搜索。
- **只用不保留数据的提供商。** 一次回答搜索过 Slack 后，这次回答的其余部分，包括它询问的其他模型或它生成的图片，都只会发送给零数据保留（ZDR）的 AI 提供商，因此它找到的内容永远不会留在提供商的日志中。在这次回答的其余部分，网页搜索和读取网页也会关闭，因此它找到的内容不会通过搜索或链接外泄：如果两者都需要，请先让它搜索网页。

在 **设置 → Slack** 的 **Slack 搜索** 中选择它在哪里搜索。更改立即生效。

| 选项 | 在哪里搜索 |
| --- | --- |
| **关闭** | 不搜索。 |
| **私信**（默认） | 仅在与智能体的私信中，因此只有提问者能看到搜索结果。 |
| **私信和频道** | 有人提及它时，也在频道中搜索。频道里的每个人都能看到回答，包括无法打开所找到频道的访客，因此只有在这对你的工作区没有问题时才选择此项。 |

有些限制来自 Slack：

- 它只在回答消息时搜索：Slack 会随每条提及它或直接发给它的消息给它搜索权限，智能体只保留这项权限到回答完成为止。
- Slack 不允许应用替访客搜索，智能体也从不替其他公司的人搜索。
- Slack 允许每个人每分钟搜索约 10 次。超过这个频率时，智能体会用已有的信息回答，并说明情况。
- Slack 只允许 Slack Marketplace 中的应用和公司自己的应用使用这种搜索。Phaseo 的 Slack 应用会在其 Slack Marketplace 上架获批后才能搜索；在此之前，智能体会说明搜索不可用。如果现在就要搜索，请使用你自己的 Slack 应用（见下文"使用你自己的 Slack 应用"）。
- 在有搜索功能之前完成的安装需要更新 Slack 权限（见上文"更新 Slack 权限"）。

搜索还需要一个能由零数据保留提供商提供服务的模型。**Auto** 会为每个请求选择模型，无法保证这一点，因此智能体不会在使用 Auto 时搜索，也不会在模型的所有提供商都保留数据时搜索，被要求时会说明这一点。管理员可以在 **设置 → Slack** 中选择一个不保留数据的模型；如果可以按消息选择模型（见上文"按消息选择模型"），也可以用 `with <model>:` 开头发送消息来使用这样的模型。如果搜索之后网关报告没有不保留数据的提供商能够回答，智能体会在那里停下并说明原因（其他错误，例如缺少提供商密钥，会显示通常的提示）；这次回答到那时为止的费用仍会计入。

它找到的内容只用于这次回答，从不保存（见下文"数据与隐私"）。出于同样的原因，搜索过 Slack 的回答不能中途停下来向你提问，也不能保存笔记、置顶、待办或技能、设置定期任务或发布共享页面。

## 谁可以使用

在 **谁可以使用** 中选择：

| 选项 | 谁能得到回答 |
| --- | --- |
| **Slack 中的所有人**（默认） | 你的 Slack 工作区中的任何人，在你设置的限制范围内。 |
| **仅限已关联的账户** | 只有把 Slack 账户关联到这个 Phaseo 工作区成员的人。智能体会给其他人发送一个用于关联的链接。 |

在 **限制** 中，**允许访客**（默认开启）让你的 Slack 工作区中的访客使用智能体，**允许其他公司的人**（默认关闭）让共享 Slack Connect 频道中来自其他组织的人使用它。同一个 Enterprise Grid 组织中其他工作区的人算作你自己的人。智能体从不回答机器人或其他应用。

### 关联 Slack 账户

智能体会私下向尚未关联的人发送 **Connect your Phaseo account** 按钮：

- 使用 **仅限已关联的账户** 时，在对方给它发消息时发送。对方连接之前，它不会回答。
- 使用 **Slack 中的所有人** 时，在 **用量数据** 允许的地方，当对方询问用量时发送（见下文“询问用量”）。它仍会回答能回答的部分，并且在每个线程中对每个人最多发送一次按钮。如需新的按钮，请在新的线程中提问。

该按钮在 15 分钟内有效。

1. 选择按钮。浏览器中会打开 Phaseo。
2. 用一个属于安装了智能体的 Phaseo 工作区成员的账户登录。
3. 选择 **连接账户**。

关联账户后也可以询问用量。

## 询问用量

已关联的成员可以向智能体询问这个 Phaseo 工作区的以下信息（其他人提问时会收到用于关联账户的按钮，见上文“关联 Slack 账户”）：

- 某段时间内的请求和支出，可按天、周或月，以及按模型或提供商查看；
- 积分余额、为进行中的请求预留的积分，以及本月已花费的积分；
- 每个 API 密钥的请求和支出；
- Phaseo 目录中的模型。

日期使用 UTC，每周从星期一开始。在 **用量数据** 中选择智能体可以在哪里回答这些问题：

| 选项 | 已关联的成员可以在哪里提问 |
| --- | --- |
| **关闭** | 任何地方都不行。智能体从不分享用量数据。 |
| **私信**（默认） | 只能在与智能体的私信中。 |
| **私信和指定频道** | 在私信中，以及在 **频道 ID** 中列出的频道里（最多 100 个）。 |

频道中的每个人都能看到智能体的回答，所以只列出成员可以查看你工作区支出的频道。频道 ID 在 Slack 中该频道详情的底部，例如 `C0123ABCD`。

## 记忆和技能

智能体可以记住你的团队让它记住的内容，并遵循技能：为重复的任务保存的指令。在 Slack 中这样让它做，例如：

- `@Phaseo remember that deploys freeze on Fridays after 3pm`
- `@Phaseo pin this for everyone: our fiscal year starts on 1 April`
- `@Phaseo add a to-do: send the Q4 budget to finance`，之后 `@Phaseo the budget to-do is done`
- `@Phaseo what do you remember about deploys?` 或 `@Phaseo forget the note about deploys`

它会保存三类笔记，每条最多 500 个字符，用它自己的话写：

| 类型 | 用途 |
| --- | --- |
| **笔记** | 需要记住的事。智能体会在相关时查找笔记。 |
| **置顶** | 需要一直记在心上的事。每条消息中，智能体都会看到最多 10 条本对话的置顶和 10 条整个工作区的置顶。 |
| **待办** | 需要跟进的事，可以标记为完成。 |

笔记属于保存它的频道或私信，除非有人要求它适用于整个工作区。在一个对话中，智能体只会看到该对话的笔记和整个工作区的笔记，绝不会看到其他频道或私信的笔记。整个工作区的笔记对智能体回答的、你所在组织的所有人可用。共享 Slack Connect 频道中其他公司的人只能查看和保存所在对话的笔记，绝不会看到整个工作区的笔记；他们可以使用已保存的技能，但不能保存新技能，因为技能适用于整个工作区。笔记可以保留到某个日期，例如 `remember until Friday that the office is closed`，过了该日期就会被删除。

只有当有人让智能体记住、置顶某件事或把它记为待办，或者遇到决定、截止日期这类长期有用的事实时，它才会保存笔记。它绝不会复制整条消息或整个线程。

### 技能

技能由名称、一行描述和最多 4,000 个字符的指令组成，用于团队重复的任务，例如周报。让智能体保存一个技能：

`@Phaseo save a skill called Weekly report: list what shipped this week, then what slipped, then next week's priorities`

每条消息中，智能体都会看到最近更改的 20 个技能的名称和描述。当请求与某个技能相符，或有人提出要求时（例如 `@Phaseo use the Weekly report skill`），它会加载该技能的指令。只有在有人明确要求时它才会保存技能，也只有在被要求时才会替换同名技能。

### 管理员可以控制什么

- **允许智能体保留笔记**（默认开启，位于 **设置 → Slack** 的 **记忆和技能** 下）可以关闭笔记、置顶和待办。关闭期间，智能体既不保存也不查看任何笔记，有人让它记住某件事时，它会说明管理员已关闭记忆。技能照常可用。已保存的笔记会保留，所有者和管理员仍可以查看和删除；重新开启后，智能体会再次使用它们。
- 每个 Slack 工作区最多保留 500 条笔记和 100 个技能。记忆已满时智能体会告知；删除一些即可腾出空间。
- 所有者和管理员可以在 **设置 → Slack** 的 **记忆和技能** 下看到智能体保存的全部内容。他们可以按类型筛选笔记、删除任意笔记或技能，以及编辑技能的名称、描述和指令。工作区活动日志会记录这些更改，但不包含文本。
- 卸载智能体会删除它的全部笔记和技能。再次添加后，它会从空的记忆开始。

## 计划任务

请智能体定期做某件事，它就会在该会话中设置一个定期任务。例如：

- `@Phaseo every weekday at 9:00, summarise yesterday's news about electric vehicles`
- `@Phaseo every Monday at 8:30, list last week's Phaseo spend by model`
- `@Phaseo on the 1st of every month at 10:00, list the API keys nobody used last month`
- `@Phaseo which recurring tasks are set up here?` or `@Phaseo cancel the Monday spend summary`

智能体会确认它设置的内容：任务做什么、在哪里发布、多久运行一次，以及下次运行的时间。

- **频率：** 每小时（在你选择的分钟）、每天、工作日（周一到周五）、每周你选择的一天，或每月你选择的一天（较短的月份在最后一天运行）。最多每小时一次。
- **时间：** 设置人在 Slack 中的时区的本地时间，夏令时切换时也保持不变。
- **位置：** 设置它的频道或私信。每次运行都会在那里发一条简短的 **Scheduled: …** 消息，并在其线程中回答。该线程中的回复是发给智能体的普通消息。
- **运行内容：** 智能体会把请求保存为一条完整独立的指令，所以每次运行都不依赖设置时的会话。计划运行不会提出带按钮的问题或搜索 Slack，也不能设置或更改定期任务。

每次运行都是对设置人的一次普通回答。智能体会检查此人是否仍可使用它，这次运行计为此人的一次回答，计入你的套餐、**每月支出上限** 和 **每人每小时回答数**，遵守每个回答的限制（见下文“每个回答的限制”），并以平常的页脚结束。

运行无法进行时：

- 如果设置人已无法使用智能体、智能体在 Phaseo 中被暂停，或它无法再在该会话中发消息（例如被移出了频道），这次运行会被跳过，任务会被暂停，原因显示在 **设置 → Slack** 中。
- 其他未能完成的运行（例如因达到 **每月支出上限** 而被拒绝）都计为失败。连续 3 次失败后，任务会被暂停，智能体会通过私信告诉设置人。

每个人都可以请智能体取消自己设置的任务。已关联 Slack 账户的 Phaseo 工作区所有者和管理员（见上文“关联 Slack 账户”）可以取消任何人的任务。共享 Slack Connect 频道中来自其他公司的人可以看到会话的任务，但不能设置。智能体的 **Home** 标签页会列出你自己的任务。

### 定期任务设置

所有者和管理员在 **设置 → Slack** 的 **定期任务** 中设置：

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| **允许设置定期任务** | 关闭后，任何人都无法设置，所有定期任务也都不会运行。它们会被保留，重新开启后继续运行。 | 开启 |
| **此工作区的定期任务上限** | 1 到 100。调低上限会保留已设置的任务。 | 20 |
| **谁可以设置** | **所有可以使用智能体的人**，或 **仅限已连接 Phaseo 账户的人**。 | 所有人 |

同一部分会列出每个任务：做什么、在哪里发布、频率、下次运行、设置人，以及上次运行的结果。你可以暂停、恢复或删除其中任何一个。恢复的任务会在下一个时间运行，失败次数重新从零开始计算。卸载智能体会删除它的全部定期任务。

## 共享页面

当回答对于一条 Slack 消息来说太长或太复杂，比如报告、表格或图表时，智能体可以把它发布为网页，并在回复中附上链接。可以这样请它做，例如：

- `@Phaseo make a page comparing our spend by model this month`
- `@Phaseo turn the decisions in this thread into a one-page summary`

页面是智能体编写的单个 HTML 文件，可以包含文字、表格和图表。页面是静态的：保存页面之前，Phaseo 会去掉其中的脚本、链接、表单，以及任何会从别处加载的内容（例如其他网站的字体或图片）。因此页面无法运行脚本，也无法把任何内容发送到任何地方，页面上的网址只显示为纯文本。页面在 `slack.phaseo.app` 上的受限沙盒中打开，因此页面无法接触你在 Phaseo 或 Slack 的登录信息。

| 谁可以查看页面 | 方式 |
| --- | --- |
| **拥有链接的任何人**（默认） | 拥有链接的任何人，无需登录。链接很长且随机，无法被猜到。 |
| **此 Slack 工作区的成员** | 你的 Slack 工作区成员，用 Slack 登录之后。只有在 **允许访客** 开启时访客才能查看，其他公司的人不能查看。一次登录有效 8 小时。 |

除非有人要求另一种方式，智能体都会使用管理员选择的默认方式，例如 `@Phaseo make it a page only our Slack workspace can see`。

### 页面限制

- 页面默认保留 30 天，然后删除。管理员可以为新页面选择 7 天、30 天或 90 天。
- 每个回答最多发布 3 个页面，每个 Slack 工作区同时最多保留 200 个页面。单个页面最大 512 KB。
- 发布是回答的一部分：不额外收费，编写页面所用的模型 token 计入回答 $0.50 的限额。
- 共享 Slack Connect 频道中其他公司的人不能发布页面。
- 搜索过 Slack 的回答不能发布页面，因为页面会保存智能体写下的内容（见上文"搜索 Slack"）。

### 管理员可以控制的页面设置

在 **设置 → Slack** 的 **共享页面** 下：

- **允许智能体发布页面**（默认开启）可关闭发布。已发布的页面会保留到过期，或直到你删除。
- **新页面保留时长**：7 天、30 天或 90 天。
- **拥有链接的任何人都可以查看页面**（默认开启）。关闭后，每个页面都需要用 Slack 登录才能查看，已发布的页面也一样。
- **新页面向谁开放** 在两种方式都可用时设置默认方式。
- 列表显示每个页面的标题、请求者、发布时间和过期时间，以及打开次数。所有者和管理员可以删除任何页面，删除后链接会立即失效。他们能否打开页面取决于页面的访问设置：面向 Slack 工作区的页面需要他们以成员身份用 Slack 登录。工作区活动日志会记录删除操作，但不包含标题。

**此 Slack 工作区的成员** 需要智能体所用的 Slack 应用设置好用 Slack 登录。设置好之前，**设置 → Slack** 会提示这一点，页面对拥有链接的任何人开放。使用你自己的 Slack 应用时，它的清单必须包含重定向 URL `https://slack.phaseo.app/p/signin`，就像 Phaseo 的清单一样（见下文“使用你自己的 Slack 应用”）。
## 限制

所有者和管理员在 **设置 → Slack** 中设置以下项目：

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| **套餐** | 智能体每月服务的人数：最多 3、10、25、50 或 100 人，或者你选择的 100 以上的人数。 | 最多 3 人 |
| **当新加入的人会超出套餐时** | **拒绝** 会告诉新来的人套餐已满。**自动升级套餐** 让套餐随着使用智能体的人数增长，最多到 **每月人数上限**。 | **拒绝** |
| **每月人数上限** | 每月人数的硬性上限，与套餐无关。不能低于套餐人数。 | 无上限 |
| **每月支出上限** | 智能体每月扣费的最高金额。如果下一个回答会超过它，智能体会停止回答，直到下个月。它至少要覆盖套餐的价格。 | 安装时设置 |
| **每人每小时回答数** | 防止一个人用完整个月的额度。 | 60 |
| **每月模型支出上限** | 限制智能体的 API 密钥每月在模型 token 上的花费。 | 无上限 |
| **允许访客** | 你的 Slack 工作区中的访客可以使用智能体。 | 开启 |
| **允许其他公司的人** | 共享 Slack Connect 频道中来自其他组织的人可以使用智能体。 | 关闭 |

**智能体** 部分用于设置模型和 **指令**：智能体在每个回答中都会遵循的额外说明，例如语气或重点，最多 8,000 个字符。

### 每个回答的限制

每个回答在 12 步或 $0.50 的模型支出时停止，以先到者为准。一步是一次模型调用及其运行的工具，例如一次网页搜索。智能体询问的其他模型以及比较中的模型，也计入同样的 $0.50。如果某个限制让回答停止，智能体会说明，你可以让它继续。这些限制对所有工作区都一样。智能体生成的图片也计入这 $0.50。

## 价格

你按当月（UTC）至少得到一次回答的人数付费。无论得到多少回答，每人每月只算一次；没有人使用智能体的月份不收费。

| 当月使用过智能体的人数 | 每月价格 |
| --- | --- |
| 1 到 3 | $0.99 |
| 4 到 10 | $2.99 |
| 11 到 25 | $4.99 |
| 26 到 50 | $7.99 |
| 51 到 100 | $14.99 |
| 101 到 1,000 | 从 $15 均匀上升到 $59，按整美元计。例如 200 人为 $20，500 人为 $35。 |
| 超过 1,000 | $59，或每人 $0.045（按整美元计），取较高者（约从 1,300 人起按人计）。例如 2,000 人为 $90。 |

每人每月包含 300 个回答，在整个工作区内共享。超出部分每 1,000 个回答收费 $0.25。

例如，如果 8 个人在一个月内得到 3,000 个回答，价格是最多 10 人的 $2.99。他们包含 2,400 个回答，所以另外 600 个回答收费 $0.15，当月扣费为 $3.14。

模型 token 不包含在这个价格中。它们会在智能体回答时，通过智能体的 API 密钥按普通网关请求、以各模型的价格计费。用 **每月模型支出上限** 来限制它们。

### 如何扣费

- 当月费用会在月末后的最初几个小时内从你的积分中扣除，并且绝不会超过 **每月支出上限**。
- **设置 → Slack** 中的 **本月** 显示到目前为止的人数、回答数和预计费用。每笔扣费都会出现在 **历史扣费** 中，并以 **Slack 智能体** 显示在你的账单交易记录中。
- 如果你的积分不足以支付，扣费会等待积分，智能体的状态会变为 **待付款**。在扣费完成前，它会停止回答。Phaseo 每小时重试一次，所以充值积分后大约一小时内就会恢复回答。金额在第一次尝试时确定。

## 发给所有者和管理员的邮件

当智能体因为只有所有者或管理员才能解决的原因拒绝某人时，Phaseo 会给工作区的每位所有者和管理员发送邮件：

| 原因 | 邮件主题 | 怎么做 |
| --- | --- | --- |
| 套餐已满 | Slack agent: someone new was turned away | 选择更大的套餐，或选择 **自动升级套餐**。 |
| 达到 **每月人数上限** | Slack agent: people limit reached | 提高或取消 **每月人数上限**。 |
| 达到 **每月支出上限** | Slack agent: monthly spending cap reached | 提高上限，或等到下个月。 |
| 有一笔扣费未支付 | Slack agent: paused until the charge is paid | 充值积分。 |

每封邮件对每个原因每月最多发送一次。邮件不会提到任何 Slack 用户，也不会引用任何消息。

对访客、其他公司的人以及因每小时上限而产生的拒绝不会发送邮件。工作区活动日志每月会记录因套餐已满、**每月人数上限** 和 **每月支出上限** 产生的第一次拒绝；对于访客、其他公司的人和每小时上限，则记录每个人的第一次。智能体在 Slack 中的回复从不会说已经通知了管理员。

## 数据与隐私

Slack 的 API 条款不允许用 Slack 数据训练模型，也不允许归档这些数据，所以智能体是这样设置的：

- **Phaseo 的日志中没有消息内容。** 无论你的工作区如何设置，智能体的 API 密钥都从不存储请求或响应的内容，无论是在日志、缓存还是遥测中。它的请求仍会以不含内容的形式出现在你的用量和日志中，并带有[请求标签](./request-labels.mdx) `app=slack-agent`、`slack_team` 和 `slack_channel`，以及[应用标题](./app-attribution.mdx) `Phaseo Slack agent`。
- **不使用会用提示词训练的提供商。** **Slack agent** [护栏](../cookbook/guardrails-for-api-keys.mdx)会关闭在付费和免费模型上的训练以及提示词发布，因此绝不会使用会用提示词训练的提供商。保留日志但不用于训练的提供商可以回答，并可能按其自身政策在这些日志中保留消息内容；Phaseo 自身的日志、缓存和遥测仍不保存任何消息内容。
- **短暂的工作记忆。** 对于每个线程，智能体会保留它最近的回复、关于所用工具的简短记录、正在排队的消息、线程中最近消息的 ID（不含文本，用于判断从哪里开始读取），它向谁发送过连接按钮，以及它提出的问题和对应的回答。它们会在线程最后一次活动的 7 天后删除。
- **可以查看和删除的记忆。** 智能体会保留有人让它保存的笔记、置顶、待办和技能，用它自己的话写，绝不是消息的副本，并附上提出要求的人的 Slack ID。它们会一直保留，直到有人删除、超过保留日期，或你卸载智能体。所有者和管理员可以在 **设置 → Slack** 中查看和删除它们，也可以在那里关闭笔记（见上文“记忆和技能”）。 其他公司的人永远看不到整个工作区的笔记。
- **分享的文件只读取，不保留。** 智能体会下载它为某个回答读取的图片和 PDF，并按同样的规则随该回答的请求发送给模型。它从不保存这些文件；在回答结束前，只有 Slack 文件 ID 和文件名会和消息一起保留。
- **不保留 Slack 搜索结果。** 智能体搜索 Slack 时找到的内容会随该回答的请求发送给模型，不会去任何其他地方：不进入它的工作记忆、它的日志或 Phaseo 的数据库，即使在等待你回答问题时也是如此。从一次回答第一次搜索起，它的请求只会发送给零数据保留的提供商，因此搜索结果也不会留在提供商的日志中。对于进行过搜索的回答，它的工作记忆只保留用过哪些工具以及它已回答的记录，不保留搜索了什么、找到了什么或写了什么。Slack 替你搜索的权限会和你的消息一起保留，直到回答结束。
- **定期任务。** 对每个任务，智能体会保留其标题和指令、发布位置、计划和时区、设置人的 Slack ID，以及上次运行的结果。它们会一直保留，直到有人取消或删除该任务，或你卸载智能体。所有者和管理员可以在 **设置 → Slack** 中查看、暂停和删除它们。
- **共享页面保留到过期。** 智能体发布的页面可能包含 Slack 中的对话内容或它找到的信息，但从不包含 Slack 搜索结果。页面是静态的，因此无法运行脚本，也无法把任何内容发送到任何地方。Phaseo 会保留页面、标题、请求者的 Slack ID 和打开次数，直到页面过期（按管理员的选择，7 天、30 天或 90 天后）、所有者或管理员删除它，或你卸载智能体为止。根据页面的设置，拥有链接的任何人都可以打开它，或者只有已登录的 Slack 工作区成员可以打开。页面从不出现在 Phaseo 的日志中。
- **不归档任何内容。** Phaseo 不会归档来自 Slack 的任何内容。智能体自己的日志只保留 Slack ID 和状态。
- **加密的密钥。** 机器人 token 和你的 Slack 应用的密钥都会加密存储，并且不会再次显示。

卸载会删除智能体的 API 密钥、笔记、已保存的技能和定期任务，并移除它的护栏。 它的共享页面也会被删除，链接随之失效。

## 使用你自己的 Slack 应用

默认情况下，智能体会安装 Phaseo 的 Slack 应用。要使用你公司自己的 Slack 应用，例如使用你自己的名称和图标，请用 Phaseo 的清单创建一个。

<Steps>
<Step title="用清单创建应用">

在 Slack 的应用设置（[api.slack.com/apps](https://api.slack.com/apps)）中，选择 **Create New App**，然后选择 **From a manifest**。选择你的 Slack 工作区，并粘贴下面的清单。你可以修改 `name`、`description`、`long_description` 和 `display_name`；其他内容保持不变。Slack 可能会提示请求 URL 尚未验证，这在第 3 步之前是正常的。

</Step>

<Step title="在 Phaseo 中保存应用">

在 Slack 中该应用的 **Basic Information** 页面上，复制它的 **App ID**、**Client ID**、**Client Secret** 和 **Signing Secret**。在 Phaseo 中打开 **设置 → Slack**，在 **高级：使用你自己的 Slack 应用** 下填入这些信息，然后选择 **保存 Slack 应用**。

</Step>

<Step title="把请求 URL 指向你的应用">

在 Slack 中打开该应用的 **App Manifest** 页面。在两个请求 URL 中，把 `YOUR_APP_ID` 替换为应用 ID，例如 `https://slack.phaseo.app/events/A0123ABCDEF`。保存，并在 Slack 要求时验证请求 URL。

</Step>

<Step title="安装应用">

在 **设置 → Slack** 中，在 **Slack 应用** 下选择 **你的 Slack 应用**，然后选择 **添加到 Slack**。

</Step>
</Steps>

关于你自己的应用，有几条规则：

- 像清单中那样保持 token 轮换关闭。一旦开启，Slack 就无法再关闭它。
- 清单使用 Slack 的智能体消息体验（`agent_view`），这是 Slack 为新应用提供的唯一体验。
- 一个 Slack 应用只能连接到一个 Phaseo 工作区，一个 Phaseo 工作区也只能保存一个 Slack 应用。
- 当智能体通过你的应用安装时，你只能替换应用的密钥。要换成另一个应用，或换回 Phaseo 的应用，请先卸载。
- 清单中的第二个重定向 URL `https://slack.phaseo.app/p/signin` 让人们可以用 Slack 登录，查看与你的 Slack 工作区共享的页面。如果你的应用是用较早的清单创建的，请在应用的 **App Manifest** 页面中添加它。

## 暂停或卸载

- 在 **设置 → Slack** 中选择 **暂停回答** 会停止所有回答，直到你选择 **恢复回答**。给智能体发消息的人会收到一条私密提示，说明它已暂停。暂停期间到期的定期任务也会被暂停；请在 **定期任务** 中恢复它们。
- **卸载** 会立即停止智能体，删除它的 API 密钥、笔记、已保存的技能和定期任务，移除它的护栏，并从 Slack 中移除应用。如果 Slack 没有确认移除，Phaseo 会告诉你，这时你也应该在 Slack 中移除该应用。如果你把这个护栏也添加给了其他密钥或成员，它会保留。
- 卸载也会删除智能体的共享页面，因此它们的链接会失效。
- 在 Slack 中移除应用，或撤销它的机器人 token，也会以同样的方式在 Phaseo 中卸载它。

历史扣费会保留在你的账单记录中。在你卸载的那个月使用过智能体的人，仍会在当月结束时计费。你随时可以再次添加智能体。

## 故障排除

当智能体无法回答某人时，它会在 Slack 中私下回复：

| Slack 中的回复 | 原因 | 解决方法 |
| --- | --- | --- |
| "The Phaseo agent is paused until this workspace's Phaseo bill is paid." | 之前某个月的扣费正在等待积分（**待付款**）。 | 充值积分。大约一小时内会恢复回答。 |
| "The Phaseo agent is paused in this Slack workspace." | 管理员选择了 **暂停回答**。 | 选择 **恢复回答**。 |
| "…has answered as many people this month as this workspace's plan covers…" | 套餐已满，新来的人被拒绝。 | 选择更大的套餐，或选择 **自动升级套餐**。 |
| "This workspace has reached its Slack agent limit for the month." | 已达到 **每月人数上限**。 | 提高或取消该上限。 |
| "…has reached this workspace's monthly spending cap…" | 下一个回答会超过 **每月支出上限**。 | 提高上限，或等到下个月。 |
| "You've reached the limit of … answers an hour." | 已达到 **每人每小时回答数**。 | 稍等，或提高该上限。 |
| "The Phaseo agent isn't available to guests in this workspace." | **允许访客** 已关闭。 | 如果访客应该能使用智能体，就开启它。 |
| "The Phaseo agent only answers people in this organization." | **允许其他公司的人** 已关闭。 | 如果这些人应该能使用智能体，就开启它。 |
| "Connect your Phaseo account to use the Phaseo agent here." | 访问方式为 **仅限已关联的账户**。 | 关联 Slack 账户（见上文“关联 Slack 账户”）。 |
| "I'm still working through earlier messages in this thread." | 这个线程中已有 5 条消息在排队。 | 等待这些回答。 |
| "Sorry, I couldn't check your Slack account just now." | Slack 没有响应一次查询。 | 一分钟后再试。 |
| "The model chosen for this agent isn't available to the Slack agent." | 网关无法用智能体的密钥使用它的模型：在没有自动路由时选择了 **自动**，或者该模型没有符合 **Slack agent** 护栏的提供商。 | 在 **设置 → Slack** 中选择其他模型。 |
| "…isn't one of the models you can choose here, so I didn't answer." | 消息以 `with …:` 开头，但指定的模型不在 **模型选择** 中，或者名称能对应多个允许的模型。 | 使用回复列表中的模型，或去掉 `with …:`。 |
| "The model you chose for this message isn't available to the Slack agent." | 原因同上：网关无法用智能体的密钥使用所选模型。 | 去掉 `with …:` 再问，或在 **模型选择** 中换一个模型。 |
| "The model this agent uses can't read the files shared here." | 智能体所用模型的提供商都无法读取所分享的图片或 PDF。 | 不带文件再问，或在 **设置 → Slack** 中选择一个能读取图片的模型。 |
| "I stopped here: after a Slack search, I can only use AI providers that keep no data…" | 这次回答搜索过 Slack，而该模型没有零数据保留的提供商能够回答。 | 在 **设置 → Slack** 中选择一个不保留数据的模型。 |
| "…so I didn't compare them." 或 "Name 2 or 3 different models to compare…" | 消息以 `compare …:` 开头，并且有模型不在 **模型选择** 中、某个名称能对应多个允许的模型，或者写了少于 2 个或多于 3 个不同的模型。 | 使用回复列表中的 2 到 3 个模型。 |

如果智能体完全没有回复：

- 在频道中，确认它是该频道的成员，并在每条你希望它回答的消息中提及它。
- 它不会回答已编辑的消息、机器人或其他应用。
- 如果使用你自己的 Slack 应用，请检查两个请求 URL 是否都以你的应用 ID 结尾、Slack 是否显示它们已验证，以及应用是否已保存在 **设置 → Slack** 中。

如果安装没有完成，**设置 → Slack** 会显示原因。最常见的原因是还没有完成隐私设置检查（打开一次 **Chat**），以及该 Slack 工作区已经安装了来自另一个 Phaseo 工作区的智能体（请先在那里卸载）。

如果共享页面打不开，它可能已过期或被删除：请让智能体重新生成一个。与你的 Slack 工作区共享的页面会要求用 Slack 登录；请用该工作区登录。只有在 **允许访客** 开启时，访客才能打开。
