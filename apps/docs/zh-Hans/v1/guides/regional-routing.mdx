title: "按区域路由文本请求"
description: "把 Phaseo 文本生成限制在欧盟或美国的提供商路由上。"
---

把文本请求发送到 `eu.api.phaseo.app` 或 `us.api.phaseo.app`，就只会使用在该区域内运行模型并处理提示词和补全数据的提供商路由。模型 ID 和 API 密钥保持不变。支持 Chat Completions、Responses 和 Messages。

| 区域 | 基础 URL | 使用的提供商路由 |
| --- | --- | --- |
| 欧盟 | `https://eu.api.phaseo.app/v1` | 仅限声明在欧盟执行并在欧盟处理数据的路由 |
| 美国 | `https://us.api.phaseo.app/v1` | 仅限声明在美国执行并在美国处理数据的路由 |
| 全球 | `https://api.phaseo.app/v1` | 标准的全球路由策略 |

<Warning>
区域路由目前还不是端到端的数据驻留保证。Phaseo 会限制提供商的选择，并把 Gateway 部署在靠近该区域的位置，但共享的账户、计费、缓存和运维系统可能会在区域之外处理数据。参见[哪些部分仍在区域之外](#what-stays-outside-the-region)。
</Warning>

## 发送区域请求

<CodeGroup>
```ts TypeScript
import { Phaseo } from "@phaseo/sdk";

const phaseo = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY!,
  region: "eu",
});

const response = await phaseo.responses.create({
  model: "openai/gpt-5.6-luna",
  input: "Summarize this note in one sentence.",
});

console.log(response.output_text);
```

```python Python
import os
from phaseo import Phaseo

phaseo = Phaseo(
    api_key=os.environ["PHASEO_API_KEY"],
    region="eu",
)

response = phaseo.responses.create({
    "model": "openai/gpt-5.6-luna",
    "input": "Summarize this note in one sentence.",
})

print(response.get("output_text"))
```

```bash Chat Completions
curl https://eu.api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-luna",
    "messages": [
      {"role": "user", "content": "Write a two-line status update."}
    ]
  }'
```

```bash Responses
curl https://eu.api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-luna",
    "input": "Extract the three most important actions from this note."
  }'
```

```bash Messages
curl https://us.api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 256,
    "messages": [
      {"role": "user", "content": "Summarize this incident report."}
    ]
  }'
```
</CodeGroup>

在 SDK 中，把 `region` 设为 `"eu"` 或 `"us"`；省略它或使用 `"global"` 则为全球路由。如果你同时设置了 `region` 和自定义的 `baseUrl`（Python 中为 `base_url`），SDK 会抛出错误，因为它们会选择不同的主机。

主机名本身就是策略。如果请求或预设中的 `required_execution_region` 或 `required_data_region` 指定了其他区域，请求会失败并返回 `400 validation_error`，原因为 `deployment_region_conflict`。预设和动态路由规则先应用，区域规则最后应用，因此它们无法削弱区域规则。Phaseo 永远不会通过区域之外的提供商重试。

## 区域请求可以包含什么

| 支持 | 拒绝 |
| --- | --- |
| 文本输入和文本输出 | 图像、音频、视频、文档、文件和附件 |
| 流式和非流式 | 非文本的输出模态 |
| 系统和开发者指令 | 由提供商托管的工具，例如网页搜索、文件搜索、代码执行、计算机使用和图像生成，以及 `web_search_options` |
| 你自己的 `function` 和 `custom` 工具，以及文本工具结果 | Phaseo [服务器工具](./server-tools)（`phaseo:` 类型） |
| 结构化文本和 JSON 输出（在模型支持时） | 图像、音频、视频、嵌入、审核、批处理、文件、webhook 和实时端点 |
| 与区域不冲突的预设、提供商排序、回退和价格限制 | |

允许使用你自己的工具，是因为它们在你的应用中运行。托管工具和服务器工具运行的位置不受区域规则控制。

## 查找某个区域可用的模型

在你发送请求的同一主机名上调用 `/v1/models`。欧盟、美国和全球端点的可用模型各不相同。

```bash
curl https://eu.api.phaseo.app/v1/models \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

该列表只包含那些拥有有效提供商路由、且该路由声明的执行区域和数据区域都包含该区域的模型，并且只提供带文本输入和输出的 Chat Completions、Responses 和 Messages。每个报价都会显示其区域：

```json
{
  "provider": { "id": "example-eu", "name": "Example EU" },
  "residency": {
    "execution_regions": ["eu"],
    "data_regions": ["eu"]
  }
}
```

## 查看哪个 Gateway 处理了请求

区域响应会带有 `X-Phaseo-Gateway-Region: eu`（或 `us`）。该响应头表明处理该请求的区域策略；它并不能证明 Cloudflare 在哪里运行了该请求。请求详情还会记录所需的执行区域和数据区域、所选的提供商，以及该提供商声明的区域。

## 错误

违反区域规则会返回 `400 not_supported`，并带有以下 `reason` 值之一：

| `reason` | 起因 | 解决方法 |
| --- | --- | --- |
| `regional_endpoint_not_supported` | 该路径不支持区域访问 | 使用 Chat Completions、Responses 或 Messages，或使用全球 API |
| `regional_non_text_content` | 请求中包含媒体、文件或附件 | 删除它，或使用全球 API |
| `regional_non_text_output` | 请求了非文本的输出模态 | 改为请求文本，或使用全球 API |
| `regional_hosted_tool_not_supported` | 使用了 `function` 或 `custom` 以外的工具 | 使用你自己的函数工具，或使用全球 API |

`400 validation_error` 且原因为 `deployment_region_conflict` 表示请求或某个预设指定了其他区域；请删除该设置。如果没有健康的提供商路由同时满足模型和区域要求，请求会在调用任何提供商之前终止；请选择区域 `/v1/models` 中列出的模型。

## 哪些部分仍在区域之外

区域规则涵盖由哪个提供商运行模型并处理提示词和补全数据。它目前还没有涵盖整个请求生命周期：

- Cloudflare 的部署位置让 Gateway 靠近该区域，但这并不是合规边界。
- 账户、认证、计费和请求元数据存放在共享的 Supabase 基础设施上。
- Cloudflare KV 和 Worker 调用日志不受区域限制。
- 对提供商的调用会发往该提供商的区域端点，与 Cloudflare 把 Gateway 部署在哪里无关。
- 支持和运维人员不受区域限制。

只有当 Gateway、存储、日志、提供商和运维路径都具备可强制执行的区域控制时，Phaseo 才会称之为端到端的数据驻留。
