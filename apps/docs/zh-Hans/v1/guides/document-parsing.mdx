将文档图像发送到 `POST /v1/parse`，即可按阅读顺序取回其中的文本，格式为 Markdown，或结构化的文本、图像和表格区块。如果只需要纯文本，请使用 [OCR](../api-reference/endpoint/ocr.mdx)。

<Warning>
  Parse 每个请求只接受一张图像，形式为 `http(s)` URL 或 base64 `data:image/...` URI。不接受 PDF：请先将每一页转换为图像。Cohere 限制每张图像不超过 20 MB、5000 万像素，解码后不超过 200 MB。
</Warning>

## 解析为 Markdown

Markdown 是默认的 `output_format`。它会保留阅读顺序，以 HTML 内联表格，并将检测到的图像链接到页面上的元数据。

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/parse \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cohere/parse-v5.0",
    "document": {
      "type": "image_url",
      "image_url": "https://example.com/invoice.png"
    },
    "output_format": "markdown"
  }'
```

```ts TypeScript
const response = await fetch("https://api.phaseo.app/v1/parse", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHASEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "cohere/parse-v5.0",
    document: {
      type: "image_url",
      image_url: "https://example.com/invoice.png",
    },
    output_format: "markdown",
  }),
});

const parsed = await response.json();
console.log(parsed.pages[0].markdown.content);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.phaseo.app/v1/parse",
    headers={"Authorization": f"Bearer {os.environ['PHASEO_API_KEY']}"},
    json={
        "model": "cohere/parse-v5.0",
        "document": {
            "type": "image_url",
            "image_url": "https://example.com/invoice.png",
        },
        "output_format": "markdown",
    },
)
response.raise_for_status()
print(response.json()["pages"][0]["markdown"]["content"])
```
</CodeGroup>

## 返回结构化区块

将 `output_format` 设为 `blocks`，即可获得按顺序排列的文本、图像和表格区域。图像和表格区块在可用时会包含像素边界框和归一化边界框。

## Parse 如何计费

Parse 用量按页计量。当提供商报告计费页数时，响应会包含 Cohere 的元数据和归一化的 `usage.input_pages` 值。Cohere 目前提供免费且有速率限制的评估 API 访问，尚未公布生产环境的 Parse API 费率。
