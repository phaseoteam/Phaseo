所有者和管理员在 **设置 → Slack** 中设置 Slack 智能体的限制和支出上限，并按使用过它的人数支付月费，另加按各模型价格计算的模型 token 费用。要先添加智能体，请参见[设置 Slack 智能体](/zh-Hans/v1/guides/slack-agent)。Slack 搜索、记忆、定期任务和共享页面等单项功能的设置，与这些功能一起放在[使用 Slack 智能体](/zh-Hans/v1/guides/slack-agent-usage)中。

<span id="limits"></span>
## 限制

所有者和管理员在 **设置 → Slack** 中设置以下项目：

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| **套餐** | 智能体每月服务的人数：最多 3、10、25、50 或 100 人，或者你选择的 100 以上的人数。 | 最多 3 人 |
| **当新加入的人会超出套餐时** | **拒绝** 会告诉新来的人套餐已满。**自动升级套餐** 让套餐随着使用智能体的人数增长，最多到 **每月人数上限**。 | **拒绝** |
| **每月人数上限** | 每月人数的硬性上限，与套餐无关。不能低于套餐人数。 | 无上限 |
| **每月支出上限** | 智能体每月扣费可以达到的最高金额。如果下一个回答会超过它，智能体会停止回答，直到下个月。它至少要覆盖套餐的价格。 | 安装时设置 |
| **每人每小时回答数** | 防止一个人用完整个月的额度。 | 60 |
| **每月模型支出上限** | 限制智能体的 API 密钥每月在模型 token 上的花费。 | 无上限 |

**允许访客** 和 **允许其他公司的人** 也在 **限制** 下；参见[谁可以使用](/zh-Hans/v1/guides/slack-agent#who-can-use-it)。

**智能体** 部分用于设置模型和 **指令**：智能体在每个回答中都会遵循的额外指引，例如语气或重点，最多 8,000 个字符。

<span id="limits-on-each-answer"></span>
### 每个回答的限制

每个回答在 12 步或 $0.50 的模型支出时停止，以先到者为准。一步是一次模型调用及其运行的工具，例如一次网页搜索。智能体询问的其他模型、比较中的模型以及智能体生成的图片，都计入同样的 $0.50。如果某个限制让回答停止，智能体会说明，你可以让它继续。这些限制对所有工作区都一样。

## 费用

你按当月（UTC）至少得到一次回答的人数付费。无论得到多少回答，每人每月只算一次；没有人使用智能体的月份不收费。

| 当月使用过智能体的人数 | 每月价格 |
| --- | --- |
| 1 到 3 | $0.99 |
| 4 到 10 | $2.99 |
| 11 到 25 | $4.99 |
| 26 到 50 | $7.99 |
| 51 到 100 | $14.99 |
| 101 到 1,000 | 从 $15 均匀上升到 $59，按整美元计。例如 200 人为 $20，500 人为 $35。 |
| 超过 1,000 | $59，或者当每人 $0.045（按整美元计）更高时按此计算（约从 1,300 人起）。例如 2,000 人为 $90。 |

每人每月包含 300 个回答，在整个工作区内共享。超出部分每 1,000 个回答收费 $0.25。

模型 token 不包含在这个价格中。它们会在智能体回答时，通过智能体的 API 密钥作为普通 Gateway 请求、按各模型的价格计费。用 **每月模型支出上限** 来限制它们。

### 如何扣费

- 当月费用会在月末后的最初几个小时内从你的额度中扣除，并且绝不会超过 **每月支出上限**。
- **设置 → Slack** 中的 **本月** 显示到目前为止的人数、回答数和预计费用。每笔扣费都会出现在 **历史扣费** 中，并以 **Slack 智能体** 显示在你的账单交易记录中。
- 如果你的额度不足以支付，扣费会等待额度，智能体的状态会变为 **待付款**。在扣费完成前，它会停止回答。Phaseo 每小时重试一次，所以充值额度后大约一小时内就会恢复回答。金额在第一次尝试时确定。

## 发给所有者和管理员的邮件

当智能体因为只有所有者或管理员才能解决的原因拒绝某人时，Phaseo 会给工作区的每位所有者和管理员发送邮件：

| 原因 | 邮件主题 | 怎么做 |
| --- | --- | --- |
| 套餐已满 | Slack agent: someone new was turned away | 选择更大的套餐，或选择 **自动升级套餐**。 |
| 达到 **每月人数上限** | Slack agent: people limit reached | 提高或取消 **每月人数上限**。 |
| 达到 **每月支出上限** | Slack agent: monthly spending cap reached | 提高上限，或等到下个月。 |
| 有一笔扣费未支付 | Slack agent: paused until the charge is paid | 充值额度。 |

每封邮件对每个原因每月最多发送一次。邮件不会提到任何 Slack 用户，也不会引用任何消息。

对访客、其他公司的人以及因每小时上限而产生的拒绝不会发送邮件。工作区活动日志每月会记录因套餐已满、**每月人数上限** 和 **每月支出上限** 产生的第一次拒绝；对于访客、其他公司的人和每小时上限，则记录每个人的第一次。智能体在 Slack 中的回复从不会说已经通知了管理员。

<span id="data-and-privacy"></span>
## 数据与隐私

Slack 的 API 条款不允许用 Slack 数据训练模型，也不允许归档这些数据，所以智能体是这样设置的：

- **Phaseo 的日志中没有消息内容。** 无论你的工作区如何设置，智能体的 API 密钥都从不存储请求或响应的内容，无论是在日志、缓存还是遥测中。它的请求仍会以不含内容的形式出现在你的用量和日志中，并带有[请求标签](/zh-Hans/v1/guides/request-labels) `app=slack-agent`、`slack_team` 和 `slack_channel`，以及[应用标题](/zh-Hans/v1/guides/app-attribution) `Phaseo Slack agent`。
- **不使用会用提示词训练的提供商。** **Slack agent** [护栏](/zh-Hans/v1/cookbook/guardrails-for-api-keys)会关闭付费和免费模型上的训练以及提示词发布，因此绝不会使用会用提示词训练的提供商。保留日志但不用于训练的提供商可以回答，并可能按其自身政策在这些日志中保留消息内容；Phaseo 自身的日志、缓存和遥测仍不保存任何消息内容。
- **短暂的工作记忆。** 对于每个线程，智能体会保留它最近的回复、关于所用工具的简短记录、正在排队的消息、线程中最近消息的 ID（不含文本，用于判断从哪里开始读取）、它向谁发送过连接按钮，以及它提出的问题和对应的回答。它们会在线程最后一次活动的 7 天后删除。
- **可以查看和删除的记忆。** 智能体会保留有人让它保存的笔记、置顶、待办和技能，用它自己的话写，绝不是消息的副本，并附上提出要求的人的 Slack ID。它们会一直保留，直到有人删除、超过保留日期，或你卸载智能体。所有者和管理员可以在 **设置 → Slack** 中查看和删除它们，也可以在那里关闭笔记（参见[记忆和技能](/zh-Hans/v1/guides/slack-agent-usage#memory-and-skills)）。其他公司的人永远看不到整个工作区的笔记。
- **分享的文件只读取，不保留。** 智能体会下载它为某个回答读取的图片和 PDF，并按同样的规则随该回答的请求发送给模型。它从不保存这些文件；在回答结束前，只有 Slack 文件 ID 和文件名会和消息一起保留。
- **不保留 Slack 搜索结果。** 智能体[搜索 Slack](/zh-Hans/v1/guides/slack-agent-usage#searching-slack) 时找到的内容会随该回答的请求发送给模型，不会去任何其他地方：不进入它的工作记忆、它的日志或 Phaseo 的数据库，即使在等待你回答问题时也是如此。从一次回答的第一次搜索起，它的请求只会发送给零数据保留的提供商，因此搜索结果也不会留在提供商的日志中。对于进行过搜索的回答，它的工作记忆只保留用过哪些工具以及它已回答的记录，不保留搜索了什么、找到了什么或写了什么。Slack 替你搜索的权限会和你的消息一起保留，直到回答结束。
- **定期任务。** 对每个任务，智能体会保留其标题和指令、发布位置、计划和时区、设置人的 Slack ID，以及上次运行的结果。它们会一直保留，直到有人取消或删除该任务，或你卸载智能体。所有者和管理员可以在 **设置 → Slack** 中查看、暂停和删除它们。
- **共享页面保留到过期。** 智能体发布的页面可能包含 Slack 中的对话内容或它找到的信息，但从不包含 Slack 搜索结果。页面是静态的，因此无法运行脚本，也无法把任何内容发送到任何地方。Phaseo 会保留页面、标题、请求者的 Slack ID 和打开次数，直到页面过期（按管理员的选择，7 天、30 天或 90 天后）、所有者或管理员删除它，或你卸载智能体为止。根据页面的设置，拥有链接的任何人都可以打开它，或者只有已登录的 Slack 工作区成员可以打开。页面从不出现在 Phaseo 的日志中。
- **不归档任何内容。** Phaseo 不会归档来自 Slack 的任何内容。智能体自己的日志只保留 Slack ID 和状态。
- **加密的机密信息。** 机器人令牌和你的 Slack 应用的密钥都会加密存储，并且不会再次显示。

卸载会删除智能体的 API 密钥、笔记、已保存的技能、定期任务和共享页面，并移除它的护栏（参见[暂停或卸载](#pause-or-uninstall)）。

<span id="pause-or-uninstall"></span>
## 暂停或卸载

- **设置 → Slack** 中的 **暂停回答** 会停止所有回答，直到你选择 **恢复回答**。给智能体发消息的人会收到一条它已暂停的私密提示。定期任务会跳过暂停期间到期的运行，在你恢复回答后，于下一个时间继续运行。
- **卸载** 会立即停止智能体，删除它的 API 密钥、笔记、已保存的技能和定期任务，移除它的护栏，并从 Slack 中移除该应用。如果 Slack 没有确认移除，Phaseo 会告诉你，你也应该在 Slack 中移除该应用。如果你已把该护栏添加到其他密钥或成员上，它会保留。
- 卸载还会删除智能体的共享页面，因此它们的链接会失效。
- 在 Slack 中移除该应用，或撤销它的机器人令牌，也会以同样方式在 Phaseo 中卸载它。

历史扣费会保留在你的账单历史中。在你卸载的那个月使用过智能体的人，仍会在当月结束时计费。你可以随时再次添加智能体。

<span id="when-the-agent-cant-answer"></span>
## 智能体无法回答时

当智能体无法回答某人时，它会在 Slack 中私下回复：

| Slack 中的回复 | 原因 | 解决方法 |
| --- | --- | --- |
| "The Phaseo agent is paused until this workspace's Phaseo bill is paid." | 之前某个月的扣费正在等待额度（**待付款**）。 | 充值额度。大约一小时内恢复回答。 |
| "The Phaseo agent is paused in this Slack workspace." | 有管理员选择了 **暂停回答**。 | 选择 **恢复回答**。 |
| "…has answered as many people this month as this workspace's plan covers…" | 套餐已满，新的人会被拒绝。 | 选择更大的套餐，或选择 **自动升级套餐**。 |
| "This workspace has reached its Slack agent limit for the month." | 达到了 **每月人数上限**。 | 提高或取消该上限。 |
| "…has reached this workspace's monthly spending cap…" | 下一个回答会超过 **每月支出上限**。 | 提高上限，或等到下个月。 |
| "You've reached the limit of … answers an hour." | 达到了 **每人每小时回答数**。 | 等待，或提高该上限。 |
| "The Phaseo agent isn't available to guests in this workspace." | **允许访客** 已关闭。 | 如果访客应该使用智能体，就打开它。 |
| "The Phaseo agent only answers people in this organization." | **允许其他公司的人** 已关闭。 | 如果他们应该使用智能体，就打开它。 |
| "Connect your Phaseo account to use the Phaseo agent here." | 访问方式为 **仅限已关联的账户**。 | [关联 Slack 账户](/zh-Hans/v1/guides/slack-agent#link-a-slack-account)。 |
| "I'm still working through earlier messages in this thread." | 这个线程中已有 5 条消息在等待。 | 等待这些回答。 |
| "Sorry, I couldn't check your Slack account just now." | Slack 没有响应一次查询。 | 一分钟后重试。 |
| "The model chosen for this agent isn't available to the Slack agent." | Gateway 无法用智能体的密钥使用其模型：选择了 **自动** 但未开启自动路由，或该模型没有任何提供商满足 **Slack agent** 护栏。 | 在 **设置 → Slack** 中选择其他模型。 |
| "…isn't one of the models you can choose here, so I didn't answer." | 消息以 `with …:` 开头，指定的模型不在 **模型选择** 中，或同时匹配多个允许的模型。 | 使用回复列表中的模型，或去掉 `with …:`。 |
| "The model you chose for this message isn't available to the Slack agent." | Gateway 无法用智能体的密钥使用所选模型，原因同上。 | 不带 `with …:` 提问，或在 **模型选择** 中替换该模型。 |
| "The model this agent uses can't read the files shared here." | 智能体所用模型的提供商都无法读取分享的图片或 PDF。 | 不带文件提问，或在 **设置 → Slack** 中选择能读取图像的模型。 |
| "I stopped here: after a Slack search, I can only use AI providers that keep no data…" | 该回答搜索了 Slack，而该模型没有任何零数据保留的提供商能够回答。 | 在 **设置 → Slack** 中选择不保留数据的模型。如果消息以 `with <model>:` 开头，就在那里选择不保留数据的模型，或去掉它以使用智能体的模型。 |
| "…so I didn't compare them." 或 "Name 2 or 3 different models to compare…" | 消息以 `compare …:` 开头，并且某个模型不在 **模型选择** 中、某个名称同时匹配多个允许的模型，或指定的不同模型少于 2 个或多于 3 个。 | 使用回复列表中的 2 或 3 个模型。 |
| "Comparing models isn't turned on here, so I didn't answer." | 消息以 `compare …:` 开头并指定了目录中的模型，但模型选择已关闭。 | 请所有者或管理员在 **模型选择** 下打开 **允许按消息选择模型**，或去掉 `compare …:`。 |

如果智能体完全没有回复，或安装没有完成，请参见[解决设置问题](/zh-Hans/v1/guides/slack-agent#fix-setup-problems)。
