选择与你手头工作对应的指南。如果是首次集成 Phaseo，请按以下顺序进行：

1. [快速入门](../quickstart)：成功发送一次请求。
2. [身份验证](../developers/authentication)：安全地存储和发送密钥。
3. [示例](./examples)：将请求模式复制到你的应用中。

<Note>
调用 `:free` 模型无需充值额度。付费模型仍要求钱包中有可用余额。
</Note>
