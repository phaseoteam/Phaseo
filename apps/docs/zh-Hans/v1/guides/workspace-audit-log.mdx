title: "工作区审计日志"
description: "查看与安全相关的工作区管理变更。"
---

工作区所有者和管理员可在**设置 → 工作区 → 活动**中查看密钥生命周期变更。事件仅属于当前工作区，并按从新到旧排序。

首个版本会记录以下操作：

- API 密钥的创建、重命名、暂停、恢复、限额变更、轮换和删除
- 管理密钥的创建和删除，以及重命名、暂停、恢复、访问模板、限额和有效期的变更

每个事件都包含操作者、操作、目标、时间戳和少量安全的变更元数据。审计事件只能追加，不能修改。Phaseo 不会在此日志中存储明文密钥、凭据哈希、授权标头、完整权限范围列表或请求正文。

审计日志仅对工作区所有者和管理员开放。普通成员无法读取事件，底层数据表也不会向已认证的数据库客户端公开。

如需自动化，请使用具有 `activity:read` 权限的管理密钥调用 `GET /v1/audit-events`。使用返回的 `next_cursor` 获取更早事件，避免时间戳间出现遗漏。

<Note>
  请求和生成日志记录实际运行的流量。工作区审计日志记录谁在何时更改了管理控制项。
</Note>
