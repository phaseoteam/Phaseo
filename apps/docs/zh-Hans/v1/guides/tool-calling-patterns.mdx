---
icon: "waypoints"
title: "工具调用模式"
description: "适用于 chat completions 和 responses 端点的可靠工具调用循环。"
---

模型调用工具后，发送一个后续请求，其中重复对话内容、模型的调用和你的工具结果。然后模型会写出回答，或者调用另一个工具，你再重复这一过程。使用你的应用已在使用的消息格式所对应的端点：OpenAI 风格的消息循环用 `/v1/chat/completions`，Responses API 用 `/v1/responses`，Anthropic 原生应用用 `/v1/messages`。

<Tabs>
<Tab title="Chat Completions">

当 `finish_reason` 为 `tool_calls` 时，运行每个调用，然后原样发送助手消息，后面每个调用跟一条 `role: "tool"` 消息，通过 `tool_call_id` 对应。再次发送 `tools`。

```json
{
  "model": "openai/gpt-6-astra",
  "messages": [
    { "role": "user", "content": "What is the weather in Seattle?" },
    {
      "role": "assistant",
      "content": null,
      "tool_calls": [
        {
          "id": "call_123",
          "type": "function",
          "function": {
            "name": "get_weather",
            "arguments": "{\"city\":\"Seattle\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_123",
      "content": "72F and sunny"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    }
  ]
}
```

</Tab>
<Tab title="Responses">

调用以 `function_call` 类型的输出项到达。把该调用项作为输入发回，后面跟一个具有相同 `call_id` 的 `function_call_output` 项。

```json
{
  "model": "openai/gpt-6-astra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [{ "type": "input_text", "text": "What's the weather in Seattle?" }]
    },
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Seattle\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "72F and sunny"
    }
  ]
}
```

</Tab>
</Tabs>

运行调用之前，先验证它的参数；请参阅[工具调用安全](./tool-calling-safety)。
