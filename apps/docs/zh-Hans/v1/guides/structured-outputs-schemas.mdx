要获得可靠的结构化输出，Schema 设计比模型选择更重要。

## 从简单结构开始

- 尽量使用扁平对象，避免多层嵌套。
- 将所有必需字段加入 `required`。
- 需要严格控制结构时，设置 `additionalProperties: false`。

## 请求

```json
{
  "model": "openai/gpt-5-nano",
  "messages": [
    { "role": "user", "content": "Return a purchase summary for order 42." }
  ],
  "response_format": {
    "type": "json_schema",
    "json_schema": {
      "name": "purchase_summary",
      "strict": true,
      "schema": {
        "type": "object",
        "properties": {
          "order_id": { "type": "string" },
          "total_usd": { "type": "number" },
          "status": { "type": "string", "enum": ["pending", "paid", "failed"] }
        },
        "required": ["order_id", "total_usd", "status"],
        "additionalProperties": false
      }
    }
  }
}
```

## 响应

```json
{
  "choices": [
    {
      "message": {
        "content": "{\"order_id\":\"42\",\"total_usd\":19.99,\"status\":\"paid\"}"
      }
    }
  ]
}
```

## 常见错误

- 本应必填的字段却设为可选。
- 使用范围过宽的字符串字段，而不是 `enum` 约束。
- 让文档中的 Schema 与服务器端校验器不一致。
