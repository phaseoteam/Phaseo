## 什么是量化？

量化是使用较低精度的数值表示模型权重和激活值，以减少内存占用并加快推理。

一般来说：

- 精度更高：质量和稳定性更好，但成本更高。
- 精度更低：吞吐量更高、成本更低，但质量风险更大。
