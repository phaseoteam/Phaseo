title: "图像生成"
description: "让模型通过 Phaseo 服务器工具生成图像。"
---

添加 `phaseo:image_generation`，模型就能在回答时生成图像。模型编写图像提示词；Phaseo 调用图像模型，并把图像返回给模型循环。

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Design a wide product concept image for a compact desktop synthesizer.",
    "tools": [
      {
        "type": "phaseo:image_generation",
        "parameters": {
          "model": "openai/gpt-image-2",
          "quality": "high",
          "aspect_ratio": "16:9",
          "output_format": "png"
        }
      }
    ]
  }'
```

## 参数

所有参数都是可选的。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `model` | string | `openai/gpt-image-2` | 图像模型。在此设置后，会覆盖主模型请求的任何模型。 |
| `quality` | string | 提供商默认值 | 质量提示，例如 `low`、`medium` 或 `high`。 |
| `size` | string | 提供商默认值 | 图像尺寸提示。 |
| `aspect_ratio` | string | 提供商默认值 | 宽高比，例如 `1:1`、`16:9` 或 `9:16`。 |
| `background` | string | 提供商默认值 | 背景模式提示。 |
| `output_format` | string | 提供商默认值 | `png`、`jpeg` 或 `webp`。 |
| `output_compression` | integer | 提供商默认值 | 压缩提示，限制在 `0` 到 `100` 之间。 |
| `moderation` | string | 提供商默认值 | 提供商审核提示。 |

## 模型发送的内容

一个 `prompt`（或 `description`，两者处理方式相同）。它也可以发送 `model`（仅在工具没有设置模型时使用），以及上面的任何其他参数，这些参数会在该次调用中替换工具的值。

## 工具返回的内容

```json
{
  "status": "ok",
  "model": "openai/gpt-image-2",
  "imageUrl": "https://...",
  "mime_type": "image/png"
}
```

有些提供商会返回包含 base64 图像数据的 `b64_json`，而不是 `imageUrl`。如果调用没有 prompt，模型会收到 `image_generation_invalid_request`；如果图像模型失败，则收到 `image_generation_failed`。

## 用量和价格

每张图像会使 `usage.server_tool_use.image_generation_requests` 加 1，并可通过 `server_tool_image_generation_requests` 计费。图像模型按其自身费率计费，作为请求账单中的单独一项。即使调用模型免费，使用付费图像模型也需要账户有余额。
