title: "Web Fetch 服务器工具"
description: "让模型在请求期间获取并读取指定的 URL。"
---

添加 `phaseo:web_fetch`，模型就能读取已知的 URL，例如文档页面、文章或更新日志。模型提供 `url`；Phaseo 抓取页面并返回其文本（按长度上限截断），模型在回答前还可以继续抓取更多页面。

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Summarize https://phaseo.app/docs/v1/guides/tool-calling" }
    ],
    "tools": [
      { "type": "phaseo:web_fetch" }
    ]
  }'
```

<span id="parameters"></span>
## 参数

```json
{
  "type": "phaseo:web_fetch",
  "parameters": {
    "engine": "direct",
    "max_chars": 12000,
    "allowed_domains": ["phaseo.app"],
    "blocked_domains": ["internal.example.com"]
  }
}
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `engine` | string | `direct` | `auto`、`native`、`direct`、`exa`、`parallel`、`firecrawl` 或 `deepseek`。参见[选择引擎](#choose-an-engine)。 |
| `max_chars` | integer | `12000` | 返回给模型的页面文本字符数，最多 `100000`。 |
| `max_content_tokens` | integer | 无 | 省略 `max_chars` 时用它代替。也是 `native` 的长度上限。 |
| `max_uses` | integer | `10` | 每个请求的抓取调用次数，最多 `100`。 |
| `allowed_domains` | string[] | 无 | 只从这些域名抓取。模型可以在调用中缩小此列表，但不能扩大。 |
| `blocked_domains` | string[] | 无 | 永不从这些域名抓取。别名：`excluded_domains`。 |

## 模型发送的内容

每次调用都包含一个 `url`。模型还可以发送 `engine`、`max_chars`、`max_content_tokens` 和域名列表。

<span id="choose-an-engine"></span>
## 选择引擎

| 引擎 | 运行方式 |
| --- | --- |
| `auto` | 在 `/v1/messages` 上使用 Anthropic 原生抓取。在其他接口上，已启用 Exa 时使用 Exa，否则使用 `direct`。 |
| `direct` | Phaseo 自己抓取页面，并将 HTML 简化为纯文本。 |
| `exa` | Exa 内容提取。 |
| `parallel` | Parallel Extract。 |
| `firecrawl` | Firecrawl Scrape。 |
| `deepseek` | DeepSeek Fetch，以 Markdown 形式返回页面。 |
| `native` | Anthropic 的 `web_fetch_20260209` 工具，仅限 `/v1/messages`。在其他接口上请求会被拒绝；请使用 `direct` 或托管引擎。 |

如果托管引擎未启用，调用会向模型返回 `fetch_not_configured`。

只支持 HTTP(S) URL。`direct` 只接受文本类内容类型，例如 HTML、纯文本和 JSON，其他类型会返回 `unsupported_content_type`。它最多跟随 5 次重定向，并用你的域名列表检查每一次重定向。

### Anthropic 原生抓取

```json
{
  "model": "anthropic/claude-sonnet-4.6",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "Read the docs page and summarize the limits." }
  ],
  "tools": [
    {
      "type": "phaseo:web_fetch",
      "parameters": {
        "engine": "native",
        "max_content_tokens": 9000,
        "allowed_domains": ["phaseo.app"]
      }
    }
  ],
  "tool_choice": { "type": "tool", "name": "phaseo:web_fetch" }
}
```

## 工具返回的内容

```json
{
  "provider": "fetch",
  "engine": "direct",
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "text": "...",
  "truncated": false,
  "returned_chars": 8421
}
```

在假定模型看到了完整页面之前，先检查 `truncated`。完整示例请参见[使用 Web Fetch 为工具提供依据](../../cookbook/tool-grounding-with-web-fetch)。

## 用量与价格

每次抓取会使 `usage.server_tool_use.web_fetch_requests` 加 1。除非模型价格卡为 `server_tool_web_fetch_requests` 设置了自己的价格，Phaseo 对每次通过 Exa、Parallel、Firecrawl 或 DeepSeek 的托管抓取收取 $0.001；直接抓取免费。即使模型免费，通过付费引擎抓取也需要账户有余额。如果模型价格卡定义了 `native_web_fetch_requests`，原生抓取按该计量项计费。
