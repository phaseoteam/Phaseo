title: "Advisor 服务器工具"
description: "让一个模型在生成过程中咨询另一个模型。"
---

添加 `phaseo:advisor`，主模型就能在回答之前请第二个模型提供评审、计划、合理性检查或专业意见。主模型像调用其他工具一样调用 Advisor；Phaseo 运行 Advisor 模型，并把建议作为工具结果返回。

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "Design a rate limiter for a distributed API gateway." }
    ],
    "tools": [
      {
        "type": "phaseo:advisor",
        "parameters": {
          "model": "anthropic/claude-opus-5",
          "max_uses": 1,
          "max_completion_tokens": 1400
        }
      }
    ]
  }'
```

Advisor 适用于任何受支持的文本模型。Phaseo 自己运行它；只有当你发送 Anthropic 原生工具格式时，才会转换为 Anthropic 的原生 Advisor 工具。

## 参数

```json
{
  "type": "phaseo:advisor",
  "parameters": {
    "name": "reviewer",
    "model": "anthropic/claude-opus-5",
    "instructions": "Review plans for correctness, missing edge cases, and implementation risk.",
    "forward_transcript": true,
    "max_uses": 2,
    "max_completion_tokens": 1400,
    "reasoning": { "effort": "high" },
    "temperature": 0.2
  }
}
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 无 | 1 到 64 个字母、数字、空格、下划线或短横线。添加多个 Advisor 时必填。 |
| `model` | string | 见下文 | Advisor 模型。 |
| `instructions` | string | 内置的 Advisor 指令 | 给 Advisor 的额外指令。 |
| `forward_transcript` | boolean | `false` | 把当前对话发送给 Advisor。 |
| `max_uses` | integer | `1` | 每个请求中调用此 Advisor 的次数。 |
| `max_completion_tokens` | integer | `1400` | 每次 Advisor 回复的输出 token 数。低于 `1024` 的值会被提高到 `1024`。`max_tokens` 作为旧别名仍被接受。 |
| `reasoning` | object | 提供商默认值 | 推理设置，在 Advisor 模型支持时传递。 |
| `temperature` | number | 提供商默认值 | Advisor 调用的采样温度。 |

如果设置了 `parameters.model`，Advisor 模型就是它；否则是主模型在调用中发送的 `model`；再否则是请求本身的模型。

## 模型发送的内容

通常是一个 `prompt`。如果工具没有固定模型，调用中也可以选择一个模型：

```json
{
  "model": "anthropic/claude-opus-5",
  "prompt": "Check this security design for missing controls."
}
```

设置 `forward_transcript: true` 时，模型可以不带 prompt 调用 Advisor，Advisor 会评审转发过来的对话。

## 添加多个 Advisor

每个 Advisor 添加一个 `phaseo:advisor` 条目。每个具名 Advisor 都会成为模型的一个独立工具，例如 `phaseo_advisor_security_reviewer`。

```json
{
  "tools": [
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "security-reviewer",
        "model": "anthropic/claude-opus-5",
        "instructions": "Review for vulnerabilities, abuse cases, and missing mitigations."
      }
    },
    {
      "type": "phaseo:advisor",
      "parameters": {
        "name": "architect",
        "model": "openai/gpt-5",
        "instructions": "Review system design tradeoffs and operational risks."
      }
    }
  ]
}
```

名称在去除首尾空格并忽略大小写后必须唯一，并且最多只能有一个条目省略 `name`；否则请求会被拒绝。有多个 Advisor 时，`tool_choice: "phaseo:advisor"` 会强制使用第一个。

## 工具返回的内容

```json
{
  "status": "ok",
  "name": "reviewer",
  "model": "anthropic/claude-opus-5",
  "advice": "Start with a smaller migration slice and define rollback criteria before changing traffic routing."
}
```

如果调用无法执行，模型会收到一个错误结果：`advisor_invalid_request`（没有 prompt 或没有模型）、`advisor_max_uses_exceeded` 或 `advisor_request_failed`。

Advisor 在请求之间不保留任何状态。如果你重放之前的消息和工具结果，主模型会看到之前的建议；只有开启 `forward_transcript` 时，Advisor 才能看到对话。建议不会以流式返回，Advisor 自己也不能调用工具。

## 用量和价格

每次调用会使 `usage.server_tool_use.advisor_requests` 加 1，并可通过 `server_tool_advisor_requests` 计费。Advisor 的 token 按 Advisor 模型自身的费率计费，作为请求账单中的单独一项，不会计入调用模型的 token 数。即使调用模型免费，使用付费 Advisor 模型也需要账户有余额。
