---
title: "应用补丁"
description: "让 Responses 模型返回经过验证的补丁操作。"
icon: "file-pen-line"
---

在 `/v1/responses` 上添加 `phaseo:apply_patch`，即可以结构化补丁操作的形式取回文件更改。Phaseo 会检查每个操作的结构并返回它；它从不触碰你的文件。是否应用补丁、展示给用户、拒绝它还是要求修改，都由你的应用决定。

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Create a small README patch for this project.",
    "tools": [
      { "type": "phaseo:apply_patch" }
    ]
  }'
```

在 `/v1/chat/completions` 或 `/v1/messages` 上，该请求会被拒绝。

## 参数

无。按原样添加 `{ "type": "phaseo:apply_patch" }` 即可。

## 模型发送的内容

一个 `operation` 对象：

```json
{
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  }
}
```

| `type` | 必填字段 | Diff 规则 |
| --- | --- | --- |
| `create_file` | `path`、`diff` | 每个非空行都以 `+` 开头 |
| `update_file` | `path`、`diff` | 每个非空行都以 `@@`、空格、`+` 或 `-` 开头 |
| `delete_file` | `path` | 无 |

`path` 不能包含空字节。

## 工具返回的内容

```json
{
  "status": "completed",
  "operation": {
    "type": "update_file",
    "path": "/README.md",
    "diff": "@@ ...\n-Old text\n+New text\n"
  },
  "message": "Patch operation validated. The client must apply or reject this patch and report the result."
}
```

违反上述规则的操作会返回 `apply_patch_invalid_operation` 及原因，以便模型重试。

## 用量和价格

每次调用会使 `usage.server_tool_use.apply_patch_requests` 加 1，并可按 `server_tool_apply_patch_requests` 计费。
