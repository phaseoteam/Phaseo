title: "日期时间服务器工具"
description: "为模型提供一个或多个时区的当前日期和时间。"
---

添加 `phaseo:datetime`，当提示词依赖当前日期和时间时（例如“东京现在是星期几？”），模型就能查询它们。何时调用由模型决定；Phaseo 返回你列出的每个时区的时间。

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What day of the week is it in Tokyo?" }
    ],
    "tools": [
      {
        "type": "phaseo:datetime",
        "parameters": { "timezones": ["Asia/Tokyo", "UTC"] }
      }
    ]
  }'
```

## 参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `timezones` | string[] | `["UTC"]` | 最多 5 个 IANA 时区名称，例如 `["Europe/London", "UTC"]`。 |

如果超过 5 个时区，或某个名称不是有效的 IANA 时区，请求会在模型运行之前被拒绝。旧的类型名称 `gateway:datetime` 仍被接受。

## 工具返回的内容

每个时区一个条目：

```json
{
  "timezones": [
    { "timezone": "Europe/London", "datetime": "2026-07-03T10:00:00.123+01:00" },
    { "timezone": "UTC", "datetime": "2026-07-03T09:00:00.123+00:00" }
  ]
}
```

## 用量和价格

每次调用会使 `usage.server_tool_use.datetime_requests` 加 1。日期时间工具没有单独的计价项。
