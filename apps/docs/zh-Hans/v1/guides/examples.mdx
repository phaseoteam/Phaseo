选择示例项目在本地运行并调整。单次 API 调用请使用[快速入门](../quickstart.mdx)；特定功能请查看[实用指南](../cookbook/index.mdx)。

## 可运行的项目

| 构建目标 | 教程 | 源码 |
| --- | --- | --- |
| 使用服务器端 API 密钥的浏览器聊天 | [Next.js 聊天](../cookbook/build-a-nextjs-web-chat-app.mdx) | [web-chat-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/web-chat-nextjs) |
| OAuth 授权与后端代理 | [OAuth 工作台](../cookbook/build-an-oauth-nextjs-workbench.mdx) | [oauth-client-nextjs](https://github.com/phaseoteam/Phaseo/tree/main/examples/oauth-client-nextjs) |
| 最小 REST 集成 | [Node 冒烟测试应用](../cookbook/build-a-node-rest-smoke-app.mdx) | [gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart) |
| Python 命令行应用 | [Python CLI](../cookbook/build-a-python-gateway-cli.mdx) | [gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart) |
| 使用 Vercel AI SDK 的应用 | [AI SDK 集成](./integrations/ai-sdk.mdx) | [ai-sdk-v7-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/ai-sdk-v7-quickstart) |

凭据应保存在服务器上；运行前请查看示例的环境变量并确认所选模型定价。使用 `:free` 模型的示例不需要充值额度。

## 各语言请求

[客户端 SDK 参考](../sdk-reference/typescript/overview.mdx)包含各语言的安装和请求示例。图像参数请使用[图像生成参考](../api-reference/endpoint/images-generations.mdx)，聊天请求请使用 [Chat Completions](../api-reference/endpoint/chat-completions.mdx)。

如需编程智能体搭建项目框架，请使用[小型应用入门提示](../cookbook/mini-app-starter-prompts.mdx)，并在使用真实凭据之前审核生成代码。
