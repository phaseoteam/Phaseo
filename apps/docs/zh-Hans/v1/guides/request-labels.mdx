---
title: "请求标签"
description: "将网关请求归属到代码定义的团队、功能或环境，并按标签拆分支出。"

---

当应用代码需要比 API 密钥或应用更细致且稳定的成本维度时，请使用请求标签。标签会随请求审计记录，并可在分析中筛选，而不会改变模型请求。

## 发送标签

将 `X-Phaseo-Metadata` 设置为包含最多 32 个唯一键值标签的 JSON 对象：

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H 'X-Phaseo-Metadata: {"labels":[{"key":"team","value":"support"},{"key":"environment","value":"production"}]}' \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Summarize this ticket."
  }'
```

TypeScript 和 Python SDK 支持自定义标头，因此可以在客户端配置相同的标头。标签不会转发给供应商。

## 拆分支出

使用分析端点时同时提供 `label_key` 和 `label_value`：

```text
GET /v1/analytics?label_key=team&label_value=support
```

响应使用与未筛选分析相同的分组支出格式，但仅包含带有这组确切标签的请求。

## 约定

- 键只能包含字母、数字、`_`、`.`、`:` 或 `-`，长度最多为 64 个字符。
- 值为字符串，最多 256 个字符。
- 每个请求最多可包含 32 个标签，标头大小上限为 8 KiB。
- 重复键或格式错误的元数据会被拒绝，并返回 `400 invalid_request`。
- 不要在标签中放入提示词、机密信息、电子邮件地址或其他个人数据。
