所有流式传输端点都使用 SSE 格式的帧：

`data: <json-or-sentinel>`

## 典型帧序列

1. 一个或多个进度帧或增量帧。
2. 包含最终状态和用量的完成帧。
3. `data: [DONE]` 结束标记。

## JavaScript 解析示例

```typescript
for await (const line of client.streamText({
  model: "openai/gpt-5-nano",
  messages: [{ role: "user", content: "Say hello." }],
  stream: true,
})) {
  if (!line.startsWith("data:")) continue;
  const payload = line.slice(5).trim();
  if (payload === "[DONE]") break;
  console.log(payload);
}
```

## Python 解析示例

```python
for line in client.stream_response({
    "model": "openai/gpt-5-nano",
    "input": "Say hello.",
    "stream": True,
}):
    if not line.startswith("data:"):
        continue
    payload = line[5:].strip()
    if payload == "[DONE]":
        break
    print(payload)
```

## 端点格式说明

- `/v1/chat/completions`：分块的 `choices[].delta` 风格事件。
- `/v1/responses`：Responses 风格的输出项/增量事件。
- `/v1/messages`：Anthropic 风格事件（`message_start`、`content_block_delta`、`message_stop`）。
