如果你想了解 Gateway 和模型目录背后的产品设计，请阅读本说明。

Phaseo 遵循几项简单原则：保持集成的可移植性，让模型和提供商的行为清晰可见，并为团队提供足够的路由控制，以便安全地运行生产服务。

## 开放与透明

在条件允许的情况下，价格、提供商可用性、路由行为和性能数据都应清晰可见。

这意味着 Phaseo 应帮助你更轻松地回答实际问题：

- 哪些提供商可以提供此模型？
- 此请求的费用是多少？
- 这条路由的速度如何？
- 模型或提供商更新后发生了哪些变化？

## 一个 API 适配所有模型

不同模型提供商公开的 API 并不相同。Phaseo 为你的应用提供一个稳定的接入层，覆盖不同提供商生态、模型系列和模态。

我们的目标不是隐藏所有提供商之间的差异，而是让常见工作流保持一致，并在必要时明确说明提供商特有的行为。

## 可移植性与韧性

生产环境中的 AI 系统需要能够应对模型变更、提供商故障、价格波动和账户级限制。

Phaseo 通过支持兼容提供商的路由来保持集成的可移植性，并通过提供路由和回退控制来增强系统韧性。

## 默认提供可观测性

每个生产请求都应该便于事后排查问题。

Phaseo 会记录用量、延迟、成本、错误详情和请求标识符。团队无需先自行搭建可观测性层，也能了解系统行为。

## 彼此尊重的社区

Phaseo 提供公开文档、模型数据、示例和贡献渠道。反馈应具体、具有建设性，并能帮助平台和目录的维护者。
