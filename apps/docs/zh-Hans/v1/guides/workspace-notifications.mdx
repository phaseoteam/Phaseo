使用通知目标将工作区已启用的提醒发送到团队日常监控的工具。通知目标由整个工作区共享，可先进行测试，再用于接收重要运维提醒。

## 添加通知目标

1. 打开 **Gateway → 设置 → 通知**。
2. 选择**添加通知目标**。
3. 输入名称并选择一个或多个频道。
4. 填写目标详情，并按需添加提及对象。
5. 为每个已配置的频道选择**发送测试**。
6. 所有测试均成功后，再创建通知目标。

Phaseo 支持：

- 电子邮件地址和通讯组列表
- 通过机器人令牌连接的 Discord 频道
- Discord webhook
- Slack 传入 webhook
- Microsoft Teams 工作流 URL
- 自定义 HTTPS webhook

凭据和 webhook URL 在存储前会加密。请将频道凭据限制为仅用于发送通知；如果凭据泄露，请及时轮换。

## 启用产品提醒

通知页面会列出工作区可用的提醒类型。启用**模型弃用提醒**，即可在工作区使用的模型退役前收到通知。

提醒会发送到已配置的通知目标，也会发送到控制台中显示的内置收件方。

## 提及

可选的提及字段可以让提醒通知特定收件人：

- Discord 支持用户 ID 和角色 ID。
- Slack 支持用户 ID 和用户组 ID。
- Microsoft Teams 支持 Microsoft 365 电子邮件地址或 Entra 对象 ID。

请谨慎使用提及。工作区的高频提醒通常应发送到有人监控的频道，而不是通知范围过大的群组。

## 测试和移除通知目标

轮换凭据或更改频道配置后，可在现有通知目标旁选择**发送测试**。请移除不再监控的目标，避免提醒看似发送到了已弃用的频道。

自定义 webhook 必须使用 HTTPS，并在处理前验证请求。请及时返回成功响应，并将耗时任务移至后台作业。
