在每个请求中发送 `X-App-Id` 请求头，即可在应用分析和请求审计中把它的用量归到同一个应用下。对于想要分别统计的每个产品、环境或面向客户的体验，请使用不同的 ID。归因永远不会改变推理响应。

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-App-Id: acme-support" \
  -H "X-App-Name: Acme Support" \
  -H "HTTP-Referer: https://acme.example/support" \
  -H "X-App-Categories: chat,productivity" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Summarize this ticket."
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const phaseo = new Phaseo({
  apiKey: process.env.PHASEO_API_KEY,
  app: {
    id: "acme-support",
    name: "Acme Support",
    url: "https://acme.example/support",
    categories: ["chat", "productivity"],
  },
});

const response = await phaseo.generateResponse({
  model: "openai/gpt-6-astra",
  input: "Summarize this ticket.",
});
```
</CodeGroup>

TypeScript SDK 的 `app` 选项会在每个请求中发送相同的请求头。Phaseo 从不替你设置归因。

## 请求头

| 请求头 | 用途 |
| --- | --- |
| `X-App-Id` | 由你的应用选择的稳定标识符。 |
| `X-App-Name` | 在应用和用量视图中显示的易读名称。 |
| `HTTP-Referer` | 与该应用关联的公开页面或部署 URL。 |
| `X-App-Categories` | 以逗号分隔的类别列表，最多三个。 |
| `X-Title` | 易读应用名称的兼容别名。 |

如果你发送了 `HTTP-Referer` URL，Phaseo 会据此识别应用；否则使用 `X-App-Id`。请保持两者稳定：新的 URL 或 ID 会在分析中创建一个新应用。

`HTTP-Referer` 不需要与浏览器自动发送的 `Referer` 请求头一致。如果你希望使用一个规范的应用 URL，请在服务器端集成中显式设置它。

## 类别

从 `chat`、`developer-tools`、`research`、`productivity`、`education`、`commerce`、`media`、`finance` 和 `other` 中最多选择三个。

取值不区分大小写。Phaseo 会忽略未知值、移除重复项，并保留前三个有效类别。之后请求中发送的类别会添加到该应用已保存的类别中；它们永远不会移除在控制台中选择的类别。

如需集中管理类别，而不是在应用代码中设置，请在**设置 → 应用**中编辑。

## 确保归因信息可以安全共享

- 不要在归因请求头中放入客户 ID、电子邮件地址或其他个人数据。
- 请把 URL 和名称视为公开信息：它们可能出现在共享或公开的应用视图中。
