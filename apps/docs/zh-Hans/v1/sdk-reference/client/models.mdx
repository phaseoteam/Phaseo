调用 SDK 的列表方法，从 `GET /v1/models` 读取模型目录，并可选择添加筛选条件。

<CodeGroup>

  availability: "all",
});

## 筛选列表

所有筛选条件都是可选的，在每个 SDK 中名称相同：它们就是查询参数。

| 筛选条件 | 筛选依据 |
| --- | --- |
| `provider`、`organisation` | 提供商或模型所属组织 |
| `endpoints`、`input_types`、`output_types`、`params` | 支持的端点、模态和请求参数 |
| `status`、`provider_status`、`provider_routing_status`、`model_routing_status`、`capability_status`、`provider_availability_status`、`provider_availability_reason` | 生命周期和路由状态 |
| `availability` | 设为 `all` 可包含无法路由的模型 |
| `limit`、`offset` | 分页 |

默认情况下，列表只包含可路由的模型。把 `availability` 设为 `all` 可包含其余模型，然后再缩小范围：

- `provider_availability_reason` 选择发布状态，例如 `preview_only`、`provider_not_ready`、`gated`、`access_limited`、`region_limited`、`project_limited`、`paused` 或 `soft_blocked`。
- `capability_status` 选择尚不可路由的端点映射，例如 `coming_soon` 或 `internal_testing`。

## 检查单个模型

`checkParameters` 及其在其他语言中的对应方法会读取实时的提供商路由元数据，把每个参数标记为 `supported`、`partial`、`unsupported` 或 `unknown`，检查公布的取值和范围，并返回接受整组参数的提供商路由。`preflight` 对整个请求正文做同样的检查，并加上模型生命周期检查，给出总体结果 `ok`。

| 语言 | 能力 | 检查参数 | 预检 | 生命周期 |
| --- | --- | --- | --- | --- |
| TypeScript | `models.capabilities(modelId)` | `models.checkParameters(modelId, values, { endpoint, provider })` | `models.preflight(request, { endpoint, provider })` | `models.validate(modelId)` 返回 `{ ok, info, reason }`；`models.getDeprecationInfo(modelId)` |
| Python | `models.capabilities(model_id)` | `models.check_parameters(model_id, values, endpoint=..., provider=...)` | `models.preflight(request, endpoint=..., provider=...)` | `models.validate(model_id)`、`models.get_deprecation_info(model_id)` |
| Go（下个版本） | `GetModelEndpointCapabilities` | `CheckModelParameters` | `PreflightRequest` | `ValidateModel`、`GetModelDeprecationInfo`（已发布） |
| C#（下个版本） | `GetModelEndpointCapabilities(modelId)` | `CheckModelParameters(modelId, values)` | `PreflightRequest` | `ValidateModel`、`GetModelDeprecationInfo`（已发布） |
| PHP（下个版本） | `getModelEndpointCapabilities` | `checkModelParameters(...)` | `preflightRequest` | `validateModel`、`getModelDeprecationInfo`（已发布） |
| Ruby（下个版本） | `model_endpoint_capabilities` | `check_model_parameters(model_id, values)` | `preflight_request` | `validate_model`、`get_model_deprecation_info`（已发布） |
| Java（源码构建） | `getModelEndpointCapabilities(modelId, query)` | `checkModelParameters(modelId, values, options)` | `preflightRequest(request, options)` | `validateModel`、`getModelDeprecationInfo` |
| Rust（`0.2.0` 中没有） | `Phaseo::model_endpoint_capabilities(...)` | `Phaseo::check_model_parameters(...)` | 无 | 无 |

“下个版本”表示该方法已在 SDK 源码中，但尚未进入已发布的包；参见[查看每个包包含的内容](./overview#check-what-each-package-ships)。弃用信息方法返回模型的状态（`active`、`deprecated` 或 `retired`）、弃用和退役日期，以及替代模型 ID。
