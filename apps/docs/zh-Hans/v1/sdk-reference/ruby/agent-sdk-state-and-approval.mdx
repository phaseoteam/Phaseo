如需通用检查点，请使用 `human_review`。需要审批或手动执行的工具会将确切的调用 ID 填入 `run.pause.pending_tool_calls`。

使用 `Agent#continue_run` 继续，并传入：

- 用于批准或拒绝的 `ToolDecision` 值
- 用于手动工作的 `ToolOutput` 值
- 用于通用审核暂停的 `human_input`
- 上一次运行，或 `run_id` 与状态访问器

决策使用确切的调用 ID，因此对同一工具的并发调用仍能区分。兼容的状态对象需实现 `load(run_id)` 和 `save(result)`。
