**方法**：`client.generate_embedding(...)` 或 `client.create_embedding(...)`。

### 示例

```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
embedding = client.generate_embedding(
  model: 'openai/text-embedding-3-large',
  input: 'Sample text'
)
```

### 关键参数

-   `model`（必填）：嵌入模型 ID（例如 `openai/text-embedding-3-large`）。
-   `input`（必填）：字符串或字符串数组。
-   `encoding_format`：`float`（默认）或 `base64`。
-   `dimensions`：用于截短嵌入长度的可选整数（取决于模型）。
-   `user`：可选的终端用户标记。

### 返回值

嵌入数据（JSON）
