**方法**: `client.generate_moderation(...)`, `client.create_moderation(...)`.

### 示例
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))

moderation = client.create_moderation(
  "model" => "openai/omni-moderation-latest",
  "input" => "Text to classify"
)
```

### 关键参数
- `model` 必填: 内容审核模型 ID（例如 `openai/omni-moderation-latest`).
- `input` 必填: 字符串或内容项数组（文本或 image_url）。
- 可选：`categories`/`severity` 筛选项（受支持时），`user` 标签。

### 返回
`ModerationResponse`
