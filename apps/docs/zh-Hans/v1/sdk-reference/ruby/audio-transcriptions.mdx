**方法**：`client.generate_transcription(...)` 或 `client.create_transcription(...)`。

### 示例
```ruby
require 'phaseo_sdk'

client = PhaseoSdk::Phaseo.new(api_key: ENV.fetch("PHASEO_API_KEY"))
transcript = client.generate_transcription(
  model: 'openai/gpt-4o-transcribe',
  audio_b64: 'base64_audio_data',
  language: 'en'
)
```

### 关键参数
- `model`（必填）：支持转录的模型 ID。
- `audio_url` 或 `audio_b64`（必填）：音频数据（URL 或 base64）。
- `language`：语言代码提示（例如 `en`）。
- `prompt`：用于提高准确度的可选上下文。
- `temperature`（0–2）：采样随机度。
- `response_format`：`json`、`text`、`srt`、`verbose_json` 等。

### 返回值
`AudioTranscriptionResponse`
