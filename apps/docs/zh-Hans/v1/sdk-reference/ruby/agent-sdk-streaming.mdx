`Agent#stream` 会返回可重放的 `StreamResult`：

```ruby
stream = agent.stream(input: "Research this topic", client: client)

stream.text_stream.each { |delta| print delta }
completed = stream.result
```

如需其他视图，请使用 `reasoning_stream`、`item_stream` 或 `full_stream`。Ruby 会同步读取供应商流，然后提供可供其他消费者重放的序列。

项目值目前是哈希，而不是 TypeScript 的判别联合类型。
