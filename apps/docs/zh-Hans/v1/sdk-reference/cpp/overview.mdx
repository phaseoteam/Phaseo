<Note type="warning">
  C++ SDK 仍在开发中，尚不能通过包管理器获取。源代码头文件仅供评估使用。
</Note>

C++ SDK 是位于 `packages/sdk/sdk-cpp` 的一组仅头文件的 C++17 源文件；它尚未发布，在端到端可用之前不会包含在 SDK 发布中。

| 文件 | 内容 |
| --- | --- |
| `src/gen/client.hpp`、`src/gen/operations.hpp`、`src/gen/models.hpp`、`src/gen/model_ids.hpp` | 生成的客户端 |
| `src/phaseo.hpp` | 用于获取实时模型能力的 `GetModelEndpointCapabilities(...)`，以及用于生成参数支持报告的 `CheckParameterSupport(...)` |
| `src/workflows.hpp` | 分页和任务轮询辅助函数 |

预览版传输层返回原始 JSON，因此检查之前请先把响应反序列化为 `ModelEndpointCapabilities`。如需试用，请参阅[安装](./installation)。C++ 没有 Agent SDK。
