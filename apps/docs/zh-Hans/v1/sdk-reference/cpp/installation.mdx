## 本地使用

该 SDK 是仅头文件的 C++17 库。把 `packages/sdk/sdk-cpp` 加入你的 CMake 构建并链接接口目标，或者把 `packages/sdk/sdk-cpp/src` 加入你的包含路径：

```cmake
add_subdirectory(path/to/Phaseo/packages/sdk/sdk-cpp)
target_link_libraries(your_app PRIVATE phaseo::sdk)
```

然后包含 `phaseo.hpp`，它会引入 `src/gen` 中生成的客户端。
