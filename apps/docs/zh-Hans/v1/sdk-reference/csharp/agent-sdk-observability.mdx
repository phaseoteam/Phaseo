失败的 `RunResult` 会保留当前步骤、重试次数、请求 ID、原生响应 ID、供应商元数据和可用的网关详情。

请先检查以下各项：

- 进程可访问 `PHASEO_API_KEY`
- 工具 ID 唯一且稳定
- 审批决策使用确切的工具调用 ID
- 控制权离开请求前已持久化暂停状态
- 验证器不会产生副作用
- 取消令牌会传递到工具内部使用的依赖项

使用生命周期钩子记录应用遥测，并使用 DevTools 在本地检查运行。
