**方法**：`client.CreateTranscription(...)`

### 示例
```csharp
using PhaseoSdk;

var client = new Phaseo(apiKey);
var response = await client.CreateTranscription(new Dictionary<string, object>
{
    ["model"] = "openai/gpt-4o-transcribe",
    ["audio_b64"] = "base64-audio",
    ["language"] = "en"
});
```

### 关键参数
- `model`（必填）：支持转录的模型 ID。
- `file`（必填）：音频数据（流或文件）。
- `language`：语言代码提示（例如 `en`）。
- `prompt`：用于提高准确度的可选上下文。
- `temperature`（0–2）：采样随机度。
- `response_format`：`json`、`text`、`srt`、`verbose_json` 等。

### 返回值
`AudioTranscriptionResponse`
