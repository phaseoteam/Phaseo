Agent SDK 以 [`Phaseo.AgentSdk`](https://www.nuget.org/packages/Phaseo.AgentSdk) 的名称发布在 NuGet 上。

## 要求

- .NET 8 或更高版本
- Phaseo API 密钥

## 安装

```bash
dotnet add package Phaseo.AgentSdk
```

核心包 `Phaseo.Sdk` 会作为依赖项自动安装。

## 环境

运行示例前，请设置网关 API 密钥：

```bash
set PHASEO_API_KEY=phaseo_v1_sk_...
```
