Agent 失败通常源于模型请求、本地工具、架构验证、超时或缺少人工决策。

## 从工具错误中恢复

如果模型可以从工具错误中恢复，请设置 `onError: "return-to-model"`。错误会变成结构化工具结果，运行可选择其他操作。对于不安全或无法恢复的操作，请保留 fail-run 行为。

## 了解 PHP 执行方式

PHP 工具回调以同步方式执行。因此，工具并发和中断能力受 PHP 运行时及底层 I/O 客户端限制。请为网络和进程工具设置明确的超时，不要假设超时回调总能被强制停止。

## 排查续接错误

每个待处理调用都需要审批、拒绝或由外部提供的输出，并按工具调用 ID 标识。显示审批界面前，请持久化返回的完整运行状态。

## 记录有用字段

记录运行 ID、步骤索引、请求 ID、供应商、模型、结束原因、工具调用 ID 和停止原因。请使用生命周期钩子或 DevTools，而非直接记录原始提示和凭据。
