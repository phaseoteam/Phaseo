---

**方法**: `getGeneration()`

### 示例

```php
<?php

require 'vendor/autoload.php';

use Phaseo\Sdk\Phaseo;

$apiKey = getenv('PHASEO_API_KEY');
$client = new Phaseo(apiKey: $apiKey);

$record = $client->getGeneration('G-01ABC...');
```

### 参数

- `id` （string，必填）：之前的调用返回的请求 ID。

### 返回值

生成记录（JSON）

如果网关保存了完整的请求详情，返回的记录还会包含 `replay_supported` 和 `replay_request`，可将捕获的请求负载重新发送到原始端点，以便受控地重新运行。

时间字段遵循网关的通用定义：

- `latency_ms`: 如果有记录，则为首个 token 或首个输出字节/帧所需的时间
- `generation_ms`: 如果有记录，则为延迟之后的生成时间
