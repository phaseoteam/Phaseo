Go Agent SDK 是 Phaseo Gateway 的完整本地代理运行时，包含重试、并发工具、上下文和超时、人工审核、可恢复状态、生命周期事件和 DevTools 捕获。

适用于以下需求：

- 轻量且有边界的工具循环
- 发送到 Gateway `responses` 端点的请求
- 由应用控制持久化和编排

## 包含的内容

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- 发送到 Gateway `responses` 端点的请求
