使用封装方法：

- `client.GenerateResponse(ctx, req)`

```go
import (
  "context"
  "fmt"
  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v2"
)

client := phaseo.New(apiKey, "https://api.phaseo.app/v1")
input := map[string]interface{}{
  "role": "user",
  "content": []map[string]interface{}{
    {
      "type": "input_text",
      "text": "Reply with: responses endpoint works",
    },
  },
}
resp, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
  Model: "openai/gpt-5-nano",
  Input: &input,
})
if err != nil {
  panic(err)
}

fmt.Println(resp)
```

封装目前尚未提供专用的流式传输辅助方法。
