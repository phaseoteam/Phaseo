---

创建 `Tool` 值并通过 `DefineTool(...)` 传入。工具可包含：

- 提供给模型的 JSON `Parameters`
- `InputSchema`、`OutputSchema` 和 `EventSchema` 验证器
- `Timeout` 和 `Execute(input, RuntimeContext)` 函数
- 无条件的 `RequireApproval` 或有条件的 `Approval` 谓词
- 用于交互式工作的 `OnToolCalled` 和 `OnResponseReceived`
- `NextTurn` 覆盖项和 `OnError: "return-to-model"`

使用 `RuntimeContext.EmitProgress`、`SetContext` 和提供的 `context.Context`。`ToolExecutionConfig{Concurrency: ...}` 会并发运行互不依赖的工具，同时保留工具结果的顺序。
