## 准备运行时

Agent SDK 尚无公开的 Go 模块版本。请按照[从源码安装的说明](./agent-sdk-installation.mdx)操作。

## 快速入门

```go
package main

import (
  "context"
  "fmt"

  phaseoagent "github.com/phaseoteam/Phaseo/packages/sdk/agent-sdk-go"
)

func main() {
  client, err := phaseoagent.CreateGatewayAgentClient(phaseoagent.GatewayAgentClientOptions{})
  if err != nil {
    panic(err)
  }

  agent := phaseoagent.CreateAgent(phaseoagent.AgentDefinition{
    ID:           "quickstart-agent",
    Model:        "openai/gpt-5.4-nano",
    Instructions: "Answer concisely and helpfully.",
  })

  result, err := agent.Run(context.Background(), phaseoagent.RunOptions{
    Input:  "Give me one fun fact about cURL.",
    Client: client,
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(result.Output)
}
```

## 功能概览

- `CreateAgent(...)`
- `DefineTool(...)`
- `CreateGatewayAgentClient(...)`
- 通过 Phaseo `responses` API 实现的有界工具循环

## 高级运行时

Go 支持验证器与审批、HITL 和手动工具、进度、可恢复错误、可重放 channel、停止辅助方法、动态轮次、持久化 `NextTurnParams`、规范化用量/成本以及 `StateAccessor`。

## 流式传输与取消

`Agent.Stream(...)` 和 `Agent.ContinueStream(...)` 会消费网关的 Responses SSE 流。不同消费者需要重放时，可多次读取 `Text()` 或 `Events()`；调用 `Cancel()` 可取消请求上下文。已完成步骤会保留请求 ID、提供方元数据、结束原因、警告、用量和成本。
