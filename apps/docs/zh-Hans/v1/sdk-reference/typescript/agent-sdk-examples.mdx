选择与你构建的产品相匹配的最小示例。每种模式都由你的应用负责持久化和用户界面，并使用 Phaseo 处理模型轮次。

## 包中示例

| 示例 | 用途 |
| --- | --- |
| `research-brief-agent.ts` | 使用托管搜索进行研究，并生成类型化的最终简报 |
| `support-triage-agent.ts` | 使用托管预设路由和分类支持请求 |
| `coding-review-agent.ts` | 使用本地运行时工具审查代码 |
| `parallel-tool-agent.ts` | 并行运行相互独立的本地工具 |
