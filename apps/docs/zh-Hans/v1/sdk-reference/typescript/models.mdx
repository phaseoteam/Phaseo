**方法**：`client.getModels()`。

### 示例
```typescript
const models = await client.getModels({
  provider: ["anthropic"],
  provider_status: ["beta", "not_ready"],
  provider_availability_reason: ["preview_only", "provider_not_ready"],
  capability_status: ["coming_soon", "internal_testing"],
  availability: "all",
});
```

### 参数
- 可选筛选条件：`provider`、`provider_status`、`provider_routing_status`、`model_routing_status`、`capability_status`、`provider_availability_status`、`provider_availability_reason`、`status`、`organisation`、`endpoints[]`、`input_types[]`、`output_types[]`、`params[]`、`availability`、`limit`、`offset`。
- `provider_availability_reason` 与 `availability: "all"` 搭配使用时，可筛选 `preview_only`、`provider_not_ready`、`gated`、`access_limited`、`region_limited`、`project_limited`、`paused` 或 `soft_blocked` 等发布状态。
- `capability_status` 与 `availability: "all"` 搭配使用时，可筛选 `coming_soon` 或 `internal_testing` 等不可路由的端点映射。
