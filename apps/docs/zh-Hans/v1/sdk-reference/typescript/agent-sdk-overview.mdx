当应用需要一次性生成之外的能力时，可使用 TypeScript Agent SDK：

- 多步本地工具循环
- 可恢复的运行状态
- 由网关支持的模型轮次
- 已验证的结构化输出、流式进度以及支持插件的路由

它构建于 `@phaseo/sdk` 之上，并定义了其他 Agent SDK 语言共用的参考运行时契约。

## 运行时能力矩阵

| 能力 | SDK 支持情况 |
| --- | --- |
| 可执行并发工具 | 内置支持，结果顺序确定，并可为每个工具设置超时 |
| 运行时验证 | 通过 `parse`、`safeParse` 或验证器函数验证输入、输出、事件和 Agent 最终结果的 schema |
| 人工审批 | 可按工具或调用审批；恢复运行时通过精确的调用 ID 批准或拒绝 |
| 人工参与工具 | 使用 `onToolCalled` 暂停，并通过 `onResponseReceived` 转换响应 |
| 手动工具 | 设置 `execute: false`，并从外部传入 `toolOutputs` |
| 产生进度的工具 | 异步生成器工具和 `tool.preliminary_result` 事件 |
| 工具错误恢复 | 使运行失败，或向模型返回结构化工具错误 |
| 流式传输 | 模型增量，以及可重放的文本、推理、条目、工具和完整事件流 |
| 停止控制 | 步骤数、时长、token 数、成本、工具调用、结束原因和自定义谓词 |
| 动态轮次 | 动态设置模型、指令、采样值、工具集、上下文变更和 `nextTurnParams` |
| 持久化续跑 | 可序列化的运行结果，或由应用负责加载和保存的 `state` 访问器 |
| 可观测性 | 规范化的用量与成本、警告、结束原因、步骤结果、生命周期事件和本地开发工具 |

## 提供的功能

- `createAgent()`
- `defineTool()`
- `createGatewayAgentClient()`
- `run()`、`stream()`、`continueRun()` 和 `continueStream()`
- 可执行工具、手动工具、需审批工具和人工参与工具
- 运行时输入/输出 schema、生成器进度、可组合停止条件以及用量和成本摘要
- 可选的应用自有状态访问器，以及供开发工具使用的生命周期事件
