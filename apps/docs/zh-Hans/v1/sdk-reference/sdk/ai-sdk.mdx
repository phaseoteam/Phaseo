安装 `@phaseo/ai-sdk-provider`，然后把 `phaseo(modelId)` 作为 `model` 传给 `generateText`、`streamText` 或任何其他 Vercel AI SDK 7 函数。文本请求会发送到 Gateway 的 `/v1/chat/completions` 端点。

## 安装

<CodeGroup>

```bash title="npm"
npm install @phaseo/ai-sdk-provider
```

```bash title="pnpm"
pnpm add @phaseo/ai-sdk-provider
```

```bash title="yarn"
yarn add @phaseo/ai-sdk-provider
```

```bash title="bun"
bun add @phaseo/ai-sdk-provider
```

</CodeGroup>

不带版本号的包会安装 npm 的 `latest` 标签，也就是 AI SDK 7 系列。它把 `ai@^7` 声明为对等依赖，因此会自动安装对等依赖的包管理器会帮你添加它。

在服务器环境中设置 `PHASEO_API_KEY`，然后发出第一个请求。如果没有设置 `PHASEO_API_KEY`，默认导出的 `phaseo` 会抛出错误。

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText } from "ai";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Reply with: AI SDK works",
});

console.log(result.text);
console.log(result.providerMetadata);
```

请使用 [Models 端点](../../api-reference/endpoint/models.mdx)返回的当前模型 ID。

## 流式输出文本

```typescript
import { phaseo } from "@phaseo/ai-sdk-provider";
import { streamText } from "ai";

const result = streamText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "Stream a short greeting.",
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}

console.log(await result.providerMetadata);
```

## 配置提供商实例

调用 `createPhaseo()` 设置 `apiKey`、`baseURL`、`headers` 或自定义 `fetch`。可以用它在 Phaseo 请求详情中标识你的应用：

```typescript
import { createPhaseo } from "@phaseo/ai-sdk-provider";

const phaseo = createPhaseo({
  apiKey: process.env.PHASEO_API_KEY,
  headers: {
    "x-title": "My App",
    "http-referer": "https://example.com",
  },
});
```

`PHASEO_BASE_URL` 是可选的，默认值为 `https://api.phaseo.app/v1`。

## 选择模型类型

| 提供商方法 | AI SDK 函数 |
| --- | --- |
| `phaseo(modelId)` 或 `phaseo.languageModel(modelId)` | `generateText`、`streamText` |
| `phaseo.embeddingModel(modelId)`（别名 `textEmbeddingModel`） | `embed`、`embedMany` |
| `phaseo.imageModel(modelId)` | `generateImage` |
| `phaseo.transcriptionModel(modelId)` | `transcribe` |
| `phaseo.speechModel(modelId)` | `generateSpeech` |
| `phaseo.rerankingModel(modelId)` | `rerank` |

除 `rerankingModel` 外，每个方法都接受可选的单模型设置作为第二个参数：`temperature`、`topP`、`topK`、`maxTokens`、`frequencyPenalty`、`presencePenalty`、`seed`、`user`、`headers` 和 `fetch`。

## 支持的 AI SDK 7 功能

- 文本生成和流式输出
- 推理输出和推理设置
- 函数工具和流式工具输入
- JSON 和 JSON Schema 输出
- 文本和图像文件输入
- URL 引用来源
- 嵌入和图像生成
- 重排序
- 转录和语音生成
- 提供商元数据、用量、中止信号和原始流数据块

一次调用能做什么仍取决于模型和提供商。该提供商不声明支持托管文件引用、技能或由提供商执行的工具（包括它们的定义、结果或审批响应）。由你的应用执行的函数工具使用 AI SDK 的常规执行和审批流程。

## 使用更早的 AI SDK 版本

| AI SDK | 安装 |
| --- | --- |
| 7 | `@phaseo/ai-sdk-provider`（`latest`） |
| 6 | `@phaseo/ai-sdk-provider@ai-sdk-v6` |
| 5 | `@phaseo/ai-sdk-provider@ai-sdk-v5` |

如果关闭了对等依赖自动安装，请自行安装对应的 `ai` 主版本（`ai@^7`、`ai@^6` 或 `ai@^5`）。
