把 `output: Output.object({ schema })` 传给 `generateText`，即可获得一个与你的 schema 匹配的类型化对象。AI SDK 会把 schema 作为 JSON Schema 响应格式发送，并校验结果。

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, Output } from "ai";
import { z } from "zod";

const { output } = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  output: Output.object({
    schema: z.object({
      title: z.string(),
      priority: z.enum(["low", "medium", "high"]),
      actions: z.array(z.string()),
    }),
  }),
  prompt: "Create a short incident follow-up plan.",
});

console.log(output);
```

在 AI SDK 7 中，`generateObject` 仍然可以使用相同的 `schema` 并返回 `object`，但它已被弃用，推荐改用带 `output` 的 `generateText`。

## 处理无效输出

当模型没有返回可用对象时（例如最后一步以工具调用结束），读取 `output` 会抛出 `NoOutputGeneratedError`。请在调用模型的地方捕获它。

- 在 schema 中使用明确的枚举和必填字段。
- 让提示词与 schema 的结构保持一致。
- 不同模型对 JSON Schema 输出的支持不同；请在 `/v1/models` 中查看模型支持的参数。
