使用 AI SDK 的 `tool()` 辅助函数定义工具，把它们传给 `generateText`，并设置 `stopWhen`，让模型在工具运行后可以作答。

```ts
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateText, stepCountIs, tool } from "ai";
import { z } from "zod";

const result = await generateText({
  model: phaseo("openai/gpt-6-astra"),
  prompt: "What is 17 + 25? Use the calculator tool.",
  tools: {
    calculator: tool({
      description: "Perform basic arithmetic",
      inputSchema: z.object({
        operation: z.enum(["add", "subtract", "multiply", "divide"]),
        a: z.number(),
        b: z.number(),
      }),
      execute: async ({ operation, a, b }) => {
        if (operation === "add") return a + b;
        if (operation === "subtract") return a - b;
        if (operation === "multiply") return a * b;
        return a / b;
      },
    }),
  },
  stopWhen: stepCountIs(2),
});

console.log(result.text);
```

默认情况下，`generateText` 在一步之后就会停止。如果这一步是工具调用，`result.text` 为空，工具的结果位于 `result.toolResults` 中。`stepCountIs(2)` 给模型第二步，让它用这个结果作答。

## 编写安全的工具

- 让描述准确、输入 schema 严格；参数由模型填写。
- 把参数视为不可信输入。在产生任何副作用之前，先在 `execute` 中校验它们。
- 对会暂时失败的下游 API，在 `execute` 中加入重试和退避。
