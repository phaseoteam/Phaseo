把 `phaseo.transcriptionModel(modelId)` 传给 `transcribe` 实现语音转文本，把 `phaseo.speechModel(modelId)` 传给 `generateSpeech` 实现文本转语音。该提供商会以 multipart 表单把音频上传到 `/v1/audio/transcriptions`，并把语音请求发送到 `/v1/audio/speech`。

```ts
import { readFileSync, writeFileSync } from "node:fs";
import { phaseo } from "@phaseo/ai-sdk-provider";
import { generateSpeech, transcribe } from "ai";

const transcription = await transcribe({
  model: phaseo.transcriptionModel("openai/whisper-1"),
  audio: readFileSync("./audio.mp3"),
});

console.log(transcription.text);
console.log(transcription.providerMetadata);

const speech = await generateSpeech({
  model: phaseo.speechModel("openai/gpt-4o-mini-tts"),
  text: "Hello from Phaseo audio.",
  voice: "alloy",
  outputFormat: "mp3",
});

writeFileSync("./speech.mp3", Buffer.from(speech.audio.uint8Array));
console.log(speech.providerMetadata);
```

`audio` 接受 `Buffer`、`Uint8Array`、`ArrayBuffer`、base64 字符串或 `URL`。AI SDK 7 仍然导出旧的 `experimental_transcribe` 和 `experimental_generateSpeech` 名称作为别名。

## 处理较长或失败的音频

- 支持的输入和输出格式取决于模型。
- 处理长文件时请调高超时时间，并让上传大小不超过模型的限制（大多数模型为 25 MB）。
- 对暂时性的 `429` 和 `5xx` 响应使用退避重试。
