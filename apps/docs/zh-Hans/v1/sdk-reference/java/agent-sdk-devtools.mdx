---

使用 `AgentSdk.createAgentDevtools(...)` 启用本地运行捕获：

```java
var devtools = AgentSdk.createAgentDevtools(".phaseo-devtools");
```

通过 `RunOptions` 传入此值。捕获的 JSONL 条目包含运行状态和耗时、模型与供应商详情、请求 ID、消息、步骤、工具活动、用量、成本和结构化错误。

<Warning>
Agent 输入、消息、上下文和工具结果可能包含敏感数据。请勿将 DevTools 目录纳入源代码管理或生产镜像。
</Warning>
