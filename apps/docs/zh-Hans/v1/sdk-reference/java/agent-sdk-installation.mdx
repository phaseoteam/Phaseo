<Note type="warning">
  Java Agent SDK 尚未发布到 Maven Central。此源代码工作流仅供评估使用。
</Note>

## 要求

- Java 17 或更高版本
- Maven

## 从源代码构建

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
mvn -f packages/sdk/agent-sdk-java/pom.xml package
```

运行示例前，请在应用环境中设置 `PHASEO_API_KEY`。
