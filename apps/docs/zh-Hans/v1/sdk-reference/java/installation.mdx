当前源码包含重试控制和响应元数据，而 Maven Central 中较旧的 3.0.0 构件不包含这些功能。请构建下方指定的版本以使用当前 SDK。

## 要求

- Java 17+
- Maven 3.8+
- Git

## 从源码构建

```bash
git clone https://github.com/phaseoteam/Phaseo.git
cd Phaseo
git checkout 1ff1119f41ceb3ac2c85ed605f6e1c4beca6e011
mvn -f packages/sdk/sdk-java/pom.xml -DskipTests install
```

Maven 会将 `app.phaseo:phaseo-sdk:3.0.0` 及其 Jackson 依赖安装到本地仓库。

## 添加依赖

```xml
<dependency>
  <groupId>app.phaseo</groupId>
  <artifactId>phaseo-sdk</artifactId>
  <version>3.0.0</version>
</dependency>
```

<Note>[Maven Central 构件](https://repo.maven.apache.org/maven2/app/phaseo/phaseo-sdk/3.0.0/) 提供旧版 API，不包含当前的重试、元数据或参数检查 API。</Note>
