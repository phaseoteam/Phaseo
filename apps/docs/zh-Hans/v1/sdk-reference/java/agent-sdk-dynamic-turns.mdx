如果后续轮次需要根据应用上下文、先前工具结果或已完成的轮次数作出响应，请使用动态回调。

动态值可用于选择：

- 模型或备用模型
- 指令
- 温度、top-p 和最大输出令牌数
- 下一次模型请求的工具列表

工具可通过 `RuntimeContext` 更新应用上下文，并为紧接着的下一次请求返回 `NextTurnParams`。下一轮覆盖项会随暂停状态保存，因此审批不会丢弃工具的路由或采样决策。

如果运行可能通过 `StateAccessor` 重新加载，请确保上下文和下一轮的值可序列化。
