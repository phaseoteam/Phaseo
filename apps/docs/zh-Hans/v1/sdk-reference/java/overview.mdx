使用 Java SDK 发送文本、嵌入和模型查询请求。

<Note>当前源码包含重试控制和响应元数据，而 Maven Central 中较旧的 3.0.0 构件不包含这些功能。请构建下方指定的版本以使用当前 SDK。 [安装](./installation)</Note>

```java
import app.phaseo.sdk.Phaseo;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        var client = new Phaseo(System.getenv("PHASEO_API_KEY"));
        var response = client.createResponse(Map.of(
            "model", "openai/gpt-6-astra",
            "input", "Reply with: Java SDK works"
        ));
        System.out.println(response);
    }
}
```

## 支持的请求

使用 `createResponse`、`createChatCompletion`、`createEmbedding` 和 `listModels` 发送 JSON 请求。传入 `Map` 或 `JsonNode`；将 JSON 字符串解析后再传给客户端方法。

## 流式响应

`streamResponse` 和 `rawClient().requestLines` 会逐行返回收到的 SSE 数据。使用 try-with-resources 关闭流，并在应用中处理事件名称、数据行和完成标记。

<Note>`createSpeech` 方法期望 JSON，无法解码二进制音频。请使用 `rawClient().requestBytes` 获取音频输出。</Note>
