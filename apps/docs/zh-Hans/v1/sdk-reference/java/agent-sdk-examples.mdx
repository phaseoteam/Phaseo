可从以下模式开始：

| 模式 | 组合内容 |
| --- | --- |
| 支持请求分流 | 托管预设、查询工具、结构化最终输出 |
| 代码审查 | 文件或补丁工具、进度事件、编辑前审批 |
| 研究简报 | 托管网络工具、成本和步骤限制、流式文本 |
| 运维手册 | 状态工具、手动升级、持久化续接 |

首个实现应保持精简：一个 Agent、一两个确定性工具，并对副作用操作设置明确审批。
