## 要求

- Rust 1.86 或更高版本
- Phaseo Gateway API 密钥

## 安装

```toml
[dependencies]
phaseo = "0.1"
phaseo-agent = "0.1"
serde_json = "1"
```

或运行：

```bash
cargo add phaseo@0.1 phaseo-agent@0.1 serde_json
```

## 配置身份验证

`create_gateway_agent_client(...)` 和 `GatewayAgentClient::from_env(...)` 会读取 `PHASEO_API_KEY`：

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

底层 `phaseo` 客户端也支持可选的 `PHASEO_BASE_URL`。

## 验证安装

```rust
use phaseo_agent::{create_agent, AgentDefinition};

fn main() {
    let _agent = create_agent(AgentDefinition::new(
        "verification-agent",
        "openai/gpt-6-astra",
    ));
    println!("Phaseo Rust Agent SDK installed");
}
```
