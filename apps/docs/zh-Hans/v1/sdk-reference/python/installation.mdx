该 SDK 以 [`phaseo`](https://pypi.org/project/phaseo/) 的名称发布在 PyPI。

## 安装

使用你偏好的 Python 包管理器安装 SDK：

<CodeGroup>

    ```bash title="pip"
    pip install phaseo
    ```

    ```bash title="uv"
    uv add phaseo
    ```

</CodeGroup>

## 要求

- Python 3.10+

## 设置

### API 密钥

在 [Phaseo 控制台](https://phaseo.app/gateway/keys)中创建 API 密钥。

### 环境变量

```bash
export PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
```

### 基本用法

```python
from phaseo import Phaseo
import os

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])

response = client.generate_text(
    {
        "model": "openai/gpt-5-nano",
        "messages": [{"role": "user", "content": "Hello!"}],
    }
)

print(response["choices"][0]["message"]["content"])
```

### 可选客户端配置

```python
from phaseo import Phaseo

client = Phaseo(
    api_key="your-api-key",
    base_url="https://api.phaseo.app/v1",
    timeout=30.0,
)
```
