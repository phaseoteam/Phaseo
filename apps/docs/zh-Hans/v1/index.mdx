如果你知道要构建什么，但不确定该先查看哪篇 Phaseo 文档，请从这里开始。

Phaseo 通过一个 API 提供模型访问、提供商路由、价格查询、用量跟踪和异步 AI 工作流。

如果你刚开始使用 Phaseo，先成功发送一个请求。如果你已经接入了 AI，请直接阅读适合你应用的迁移指南或 SDK 指南。

## 成功发送第一个请求

对于新的集成，请按以下步骤操作：

1. 在控制台中创建 API 密钥。
2. 向当前可用的文本模型发送请求。
3. 从响应中读取生成的文本。
4. 根据下一步需求继续阅读 SDK、路由或生产部署指南。

## 第一个请求

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-sol",
    "input": "Reply with: docs ready",
    "temperature": 0
  }'
```

```typescript TypeScript SDK
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-5.6-sol",
  input: "Reply with: docs ready",
  temperature: 0,
});

console.log(response.output_text);
```

```python Python SDK
from phaseo import Phaseo

client = Phaseo(api_key="YOUR_API_KEY")

response = client.generate_response(
    {
        "model": "openai/gpt-5.6-sol",
        "input": "Reply with: docs ready",
        "temperature": 0,
    }
)

print(response.get("output_text"))
```
</CodeGroup>

如果请求成功，请继续阅读[快速入门](./quickstart.mdx)，完成首次请求的完整流程。
