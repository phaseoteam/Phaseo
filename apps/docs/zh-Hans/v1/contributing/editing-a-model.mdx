创建 GitHub 议题来更正模型或请求添加缺失条目。您无需编辑 JSON 或配置代码仓库。

## 报告更正

1. 复制模型的 Phaseo 页面 URL 或模型 ID。
2. [报告错误信息](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml)，说明当前值和建议的更正内容。
3. 附上官方文档、发布公告或其他可验证的来源。

涉及定价时，请提供提供商、币种、计费单位、相关档位和生效日期。涉及基准测试分数时，请参阅[提交分数](../research/submitting-scores.mdx)。

## 请求添加缺失模型

[创建数据请求](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml)，提供模型名称、所属组织、官方链接、发布日期和已知功能。模型可能在拥有受支持的 Gateway 路由之前就已出现在目录中。

## 提交后

维护者会审核依据，并通过内部编辑器更新数据库。请在议题中跟进问题和发布情况。每日 JSON 快照用于导出目录；更改归档 JSON 文件不会更新线上网站。

管理员可以在[内部数据](https://phaseo.app/internal/data)中编辑记录，并在[提供商更新](https://phaseo.app/internal/data/imports)中审核建议价格。这些页面需要管理员访问权限。
