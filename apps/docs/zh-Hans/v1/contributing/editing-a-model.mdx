模型数据存放在 `packages/data/catalog/src/data/models` 下的 JSON 文件中。 每个模型都有自己的文件夹和一个 `model.json` 文件。

## 1. 查找模型

根据供应商和模型名称查找模型目录，例如：

`packages/data/catalog/src/data/models/openai/gpt-5-2025-08-07/model.json`

## 2. 进行修改

常见的更新内容包括：

- 描述和链接
- 能力和支持的端点
- 价格或可用性说明
- 基准测试引用

请确保值与相邻文件中的现有架构一致。

## 3. 验证数据

创建 PR 前，请运行数据验证脚本：

```bash
pnpm validate:data
```

## 4. 创建 PR

简要说明更改内容，并列出所用来源。
