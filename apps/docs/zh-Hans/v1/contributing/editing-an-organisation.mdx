通过 GitHub 议题报告缺失或过时的组织信息。维护者会审核依据，并在数据库编辑器中应用获批的更改。

## 报告更正

1. 复制组织的 Phaseo 页面 URL 或 ID。
2. [报告错误信息](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml)，提供受影响的字段和建议值。
3. 附上官方网站、公告或其他可验证来源的链接。

常见更正包括名称、描述、网站、所在地以及与模型或 API 提供商的关系。

## 请求添加缺失组织

[创建数据请求](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml)，提供组织名称、官方网站以及相关模型或提供商链接。

## 提交后

请在议题中跟进审核和发布情况。更改目录记录无需编辑 JSON 或提交拉取请求。每日 JSON 文件只是导出文件，不会导入线上数据库。

管理员通过[内部目录编辑器](https://phaseo.app/internal/data)管理组织，该编辑器需要管理员访问权限。
