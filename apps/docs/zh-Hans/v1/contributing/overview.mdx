如需纠正或补充目录，请创建问题并附上受影响记录和依据来源。如需更改代码或文档，请向 [Phaseo 仓库](https://github.com/phaseoteam/Phaseo)提交拉取请求。

## 选择贡献类型

| 更改 | 从这里开始 |
| --- | --- |
| 模型元数据、能力、可用性或价格 | [报告模型更新](./editing-a-model.mdx) |
| 公司或研究组织详情 | [报告组织更新](./editing-an-organisation.mdx) |
| 基准测试结果 | [提交分数](../research/submitting-scores.mdx) |
| 其他目录更正 | [报告错误信息](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) |
| 缺失的提供商或其他目录数据 | [请求新数据](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) |
| 文档或代码 | [贡献流程](./how-to-contribute.mdx)和[仓库结构](./repo-structure.mdx) |

## 目录报告如何发布

维护者会审核问题中的证据，并通过仅限管理员使用的[内部编辑器](https://phaseo.app/internal/data)应用已批准更改。提供商价格更新必须在发布前进行明确审核。

数据库是目录的权威来源。每日公开 JSON 快照仍然可用，但编辑快照或提交归档 JSON 的拉取请求都不会更新实时目录。旧版 JSON 导入器已停用。

## 提交之前

- 提供受影响页面或记录 ID，并描述建议更正。
- 引用官方来源，并区分已公布的基准结果与独立测量结果。
- 让每份报告或拉取请求保持范围集中。
- 切勿包含凭据或客户私有数据。
- 遵循[行为准则](../community/code-of-conduct.mdx)。

在实现较大的架构或功能更改前，先与维护者讨论。不确定更改应归于何处时，可在 [Discord](https://discord.gg/aQyywCvgZ5) 求助。
