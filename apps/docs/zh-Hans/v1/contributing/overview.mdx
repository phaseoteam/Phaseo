如需更正或补充目录，请创建议题并附上受影响的记录和依据来源。如需更改代码或文档，请向 [Phaseo 仓库](https://github.com/phaseoteam/Phaseo)提交拉取请求。

## 选择贡献类型

| 更改 | 从这里开始 |
| --- | --- |
| 模型元数据、功能、可用性或定价 | [报告模型更新](./editing-a-model.mdx) |
| 公司或研究组织详情 | [报告组织更新](./editing-an-organisation.mdx) |
| 基准测试结果 | [提交分数](../research/submitting-scores.mdx) |
| 其他目录更正 | [报告错误信息](https://github.com/phaseoteam/Phaseo/issues/new?template=incorrect-info.yml) |
| 缺失的提供商或其他目录数据 | [请求新数据](https://github.com/phaseoteam/Phaseo/issues/new?template=data-request.yml) |
| 文档或代码 | [贡献流程](./how-to-contribute.mdx)和[仓库结构](./repo-structure.mdx) |

## 目录报告如何发布

维护者会审核议题中的依据，并通过仅限管理员使用的[内部编辑器](https://phaseo.app/internal/data)应用获批的更改。提供商价格更新在发布前必须经过明确审核。

数据库是目录记录的唯一来源。仓库中没有目录 JSON，因此拉取请求无法更改目录记录。

## 提交之前

- 提供受影响的页面或记录 ID，并说明建议的更正。
- 引用官方来源，并区分已公布的基准测试结果与独立测量结果。
- 每份报告或拉取请求只关注一件事。
- 切勿包含凭据或客户私有数据。
- 遵守[行为准则](../community/code-of-conduct.mdx)。

较大的架构或功能更改请在实现前先与维护者讨论。如果不确定更改应归于何处，可在 [Discord](https://discord.gg/aQyywCvgZ5) 中求助。
