Phaseo 在 GitHub 议题和拉取请求、Discord 以及其他所有社区空间中遵循 [Contributor Covenant](https://github.com/phaseoteam/Phaseo/blob/main/CODE_OF_CONDUCT.md)。请保持友善、尊重，并对不同观点保持开放。

如遇骚扰或其他不可接受的行为，请发送邮件至 `support@phaseo.app`，或在 [Discord](https://discord.gg/aQyywCvgZ5) 中联系版主。报告由社区负责人审核，他们会对报告人的身份保密。

包含示例和执行步骤的完整文本见 [`CODE_OF_CONDUCT.md`](https://github.com/phaseoteam/Phaseo/blob/main/CODE_OF_CONDUCT.md)。贡献规则见 [`CONTRIBUTING.md`](https://github.com/phaseoteam/Phaseo/blob/main/CONTRIBUTING.md)。
