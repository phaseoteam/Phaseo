## 在哪里获取 API 密钥？

在[控制台](https://phaseo.app/settings/keys)中打开 **设置 -> API 密钥**，或使用管理密钥调用 `POST /v1/keys`。请参阅[身份验证](../developers/authentication)。

## 应该使用哪个基础 URL？

`https://api.phaseo.app/v1`，并以 `Authorization: Bearer $PHASEO_API_KEY` 发送密钥。

## 应该从哪个端点开始？

大多数文本工作使用 `POST /v1/responses`。`/v1/chat/completions` 和 `/v1/messages` 接受现有集成的格式。[快速入门](../quickstart)会带你发出第一个请求。

## 可以不付费试用 Phaseo 吗？

可以。发送 `"model": "phaseo/free"` 即可使用一个可用的免费模型，无需额度。免费模型允许每个用户每个 UTC 日发出 1,500 次请求；请参阅[套餐](../exploring/subscription-plans)。

## 如何查看受支持的模型？

调用 [`GET /v1/models`](../api-reference/endpoint/models.mdx)。它返回你现在可以调用的模型；添加 `availability=all` 可包含仅在目录中的模型。

## BYOK 如何运作？

使用自带密钥（BYOK）时，Phaseo 负责路由和记录请求，模型用量由你的提供商计费。每个工作区每个 UTC 月的前 250,000 次已完成 BYOK 请求不收取 Phaseo 服务费；之后，Phaseo 按提供商等价成本的 2.5% 收费。请参阅 [BYOK 注意事项](../guides/routing-and-fallbacks#byok-considerations)。
