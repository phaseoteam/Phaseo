账户、账单、API 和反馈问题，请先访问 [Phaseo 帮助中心](https://phaseo.app/help)；团队会将每个请求转交给合适的人员。

| 你想要 | 前往 |
| --- | --- |
| 获取账户、账单或失败请求方面的帮助 | [帮助中心](https://phaseo.app/help) |
| 报告错误 | [帮助中心](https://phaseo.app/help)，或在 GitHub 上提交[错误报告](https://github.com/phaseoteam/Phaseo/issues/new?template=bug.yml) |
| 更正目录数据 | [贡献](../contributing/overview) |
| 报告安全漏洞 | 在 [GitHub 仓库](https://github.com/phaseoteam/Phaseo)的 **Security -> Report a vulnerability** 下提交私密报告，或发送邮件至 `security@phaseo.app`。不要公开发布。 |
| 向社区提问 | [Discord](https://discord.gg/aQyywCvgZ5) |

## 错误报告中应包含的内容

- 请求 ID：响应的 `id`（`G-...`）、错误中的 `generation_id`，或 `x-request-id` 响应头。
- 你发送的内容（去掉 API 密钥）以及你预期的结果。
- 响应体中的错误代码和消息。[错误参考](../api-reference/errors)解释了每个代码。
- 任何相关日志，去掉凭据和客户数据。
