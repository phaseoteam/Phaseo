一般对话使用 **Chat**。需要智能体在项目文件夹中工作，并在对话旁审查更改时，切换到 **Code**。

## 开始项目工作

将文件夹添加为项目，在 **Code** 中选择它，然后开始聊天。在消息框中选择智能体和模型。相关工作可以使用同一份检出目录；需要独立分支和文件时，选择新的 Git 工作树。

发送前请在模型选择器中检查权限。**Ask first** 让你审查需要批准的请求。更宽泛的权限级别让智能体能够自动执行更多操作；可用级别取决于智能体。

## 将后续消息排队或发送到当前轮次

默认情况下，智能体工作期间发送的消息会排队等待下一轮。你可以在消息框上方编辑、排序或删除它们。

如果智能体支持即时引导，选择排队消息上的 **Send now** 可将其加入正在运行的轮次。`Ctrl+Shift+Enter`（macOS 上为 `Cmd+Shift+Enter`）会将草稿发送到当前轮次；消息框为空时则发送队列中的第一条消息。不支持该功能的智能体会继续将消息保留在队列中。

可在 **Settings → Chat → Follow-ups while an agent works** 中更改默认行为。**Stop** 会中断当前轮次。

## 审查工作

在右侧面板打开文件、差异、终端、拉取请求和浏览器。它们显示在对话旁；关闭面板后，你仍可稍后返回。

提交或发布前，请审查更改的文件和命令输出。聊天中的步骤展示智能体的操作，展开步骤可查看详情。回答前请先阅读权限请求和问题。

## 整理聊天

置顶常用聊天，并使用 `Ctrl+K`（macOS 上为 `Cmd+K`）搜索。分叉聊天可以探索其他方案。在 **Code** 中，将完成的工作标记为已结束，以缩短活跃列表。你可以从 **Settled** 返回；新的活动会让聊天重新变为活跃状态。

如需智能体协调多个聊天中的工作，请阅读[操作员](./operator.mdx)。设置和外观说明请见[入门指南](./get-started.mdx)。
