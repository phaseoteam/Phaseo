Phaseo 上的每个模型都关联到一个**组织**，也就是负责开发、训练和维护该模型的实体。
组织构成了 AI 生态的基础。了解模型由谁构建，有助于你理解模型的用途、能力和可靠性。

---

## 组织页面包含的内容

每个组织页面都会介绍公司或研究团队，包括：

| 部分 | 说明 |
| --- | --- |
| **概览** | 名称、描述、国家或地区、成立年份和网站等基本信息。 |
| **已发布模型** | 组织发布的所有模型，包括已归档或已弃用的模型。 |

---

## Phaseo 上的组织类型

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| **研究实验室** | OpenAI、Anthropic、DeepMind | 专注于前沿 AI 模型的开发与创新。 |
| **科技公司** | Google、Meta、Microsoft | 部署大规模 AI 基础设施和面向消费者的应用。 |
| **初创公司** | Mistral、Perplexity、Suno | 由规模较小的团队构建专业化或高效的 AI 系统。 |
| **开源社区** | Hugging Face、Stability AI | 通过去中心化协作透明地开发模型。 |

## 提供商与组织

区分**组织**和**API 提供商**很重要：

| 方面 | 组织 | API 提供商 |
| --- | --- | --- |
| **定义** | 创建或维护模型的实体。 | 提供模型 API 访问的平台。 |
| **示例** | _Anthropic_ 构建了 Claude 系列。 | _Anthropic_、_AWS_ 和 _Google Vertex_ 都提供 Claude 模型访问。 |
| **关注重点** | 研究、训练和模型架构。 | 托管、路由、定价和用户体验。 |

一些组织（如 OpenAI 或 Google）既是**开发者**也是**提供商**；另一些组织则与多个平台合作分发模型。
