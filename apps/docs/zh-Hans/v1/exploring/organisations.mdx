在[组织](https://phaseo.app/organisations)中打开某个组织，即可查看它发布的所有模型，以及这些模型在 Gateway 上的表现。Phaseo 上的每个模型都属于一个组织：开发和维护该模型的公司或实验室。

## 组织页面显示的内容

页面有两个标签页。

| 标签页 | 部分 | 告诉你什么 |
| --- | --- | --- |
| **概览** | 关于 | 名称、简介和国家/地区。 |
| | 性能 | 该组织各模型最近的 Gateway 延迟和吞吐量。 |
| | 最新模型 | 近期发布的模型，以及它们的可用性、上下文、价格和使用情况。 |
| | 网络信息 | 指向该组织网站、GitHub、Hugging Face 和社交账号的链接。 |
| **模型** | | 该组织发布的所有模型，包括已归档和已弃用的模型。 |

## 组织与 API 提供商

组织构建模型；[API 提供商](./api-providers.mdx)提供模型服务。一个模型往往有多个提供商。

| | 组织 | API 提供商 |
| --- | --- | --- |
| **职责** | 训练并维护模型。 | 通过 API 托管模型。 |
| **示例** | Anthropic 构建了 Claude 模型。 | Anthropic、Amazon Bedrock 和 Google Vertex 都提供 Claude 模型。 |

部分组织（例如 OpenAI 和 Google）同时也是自家模型的提供商。
