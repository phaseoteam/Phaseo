在[基准测试](https://phaseo.app/benchmarks)中打开某项基准测试，即可按该测试的分数为模型排名；打开模型页面，则可以看到该模型的所有分数。Phaseo 不运行基准测试；它收集已发布的分数，并为每个分数附上来源链接。

## 每个分数记录的内容

| 字段 | 告诉你什么 |
| --- | --- |
| 分数 | 按发布原样记录的值，使用该基准测试自己的量表。 |
| 变体 | 与默认设置不同时的配置，例如 few-shot 数量或推理强度。 |
| 来源 | 指向该分数出处的论文、模型卡或结果页面的链接。 |
| 自报 | 当分数由模型自身的开发者发布时设置。这是一种披露，而非否定。 |

每项基准测试还有一个类别和一个排序方向。对于越低越好的基准测试（例如错误率），Phaseo 会把分数最低的排在最前面。

## 如何比较分数

Phaseo 不会把各项基准测试换算成一个统一分数，因此请在同一基准测试和同一变体上比较模型，而不要跨基准测试比较。在把两个数字视为等同之前，先检查变体和自报标记：对于同一个模型，提供商报告的分数和独立测得的分数可能不同。

基准测试分数只是参考因素之一。成本、延迟、可靠性以及模型处理你自己的提示词的表现同样重要；这些内容见[价格与性能](./pricing-performance.mdx)。

## 基准测试页面显示的内容

| 部分 | 告诉你什么 |
| --- | --- |
| **摘要** | 该基准测试衡量什么，并附有链接。 |
| **进展** | 该基准测试上的分数随时间的变化。 |
| **模型结果** | 所有模型的分数，按该基准测试的排序方向排名。 |

综合指数（例如 Artificial Analysis Intelligence Index 和 Epoch Capabilities Index）有各自的页面，展示发布方的排名和版本。

## 基准测试类别

| 类别 | 示例 |
| --- | --- |
| 通用 | Artificial Analysis Intelligence Index、Epoch Capabilities Index |
| 智能体 | BrowseComp、BFCL-v3、Toolathlon |
| 代码 | SWE-Bench、Aider-Polyglot |
| 数学 | AIME 2025、MathVision |
| 推理 | HellaSwag、Hallusion Bench |
| 语言 | BIG-Bench Hard、Winogrande |
| 多模态 | CharXiv-R、MMBench-V1.1 |
| 长上下文 | AA-LCR、OpenAI-MRCR |

其他类别还包括音频、嵌入、医疗健康、规划和创造力。

## 分数的来源

- 模型开发者发布的模型卡、技术报告和论文。
- 基准测试组织方自己的结果页面。
- 定期从 Artificial Analysis 和 Epoch AI 导入的数据。
- 通过 GitHub issue 提交的社区报告，发布前会经过审核。

完整规则见[基准测试方法](../research/benchmark-methodology.mdx)。如需添加或更正分数，请参阅[提交基准测试分数](../research/submitting-scores.mdx)。
