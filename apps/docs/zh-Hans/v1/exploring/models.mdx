打开[模型](https://phaseo.app/models)列表，查找文本、图像、音频、视频、嵌入和其他模型，然后打开某个模型，查看它的提供商、价格、性能和基准测试分数。

![Phaseo 上的模型页面](/images/gemini-3-page.png)

## 目录模型与可调用模型

目录的范围比 Gateway 更广。模型列表默认只显示 **Gateway 已启用**的模型。将 **Gateway 状态**筛选器改为**即将推出**或**未活跃**，即可查看其余模型。

| 术语 | 含义 |
| --- | --- |
| 目录模型 | Phaseo 跟踪该模型的元数据。它可能没有你可以调用的路由。 |
| 可路由模型 | 目前在 Phaseo Gateway 上至少有一条提供商路由处于活跃状态。 |
| 外部映射 | Phaseo 列出了某个提供商的服务，但 Gateway 不会执行它。 |

`GET /v1/models` 只返回可路由的模型。添加 `availability=all` 可包含其余模型。

## 筛选和排序列表

| 控件 | 选项 |
| --- | --- |
| Gateway 状态 | Gateway 上活跃（默认）、即将推出、未活跃 |
| 端点 | 模型支持的 API 端点，例如文本生成或嵌入 |
| 输入和输出模态 | 文本、图像、音频、视频等 |
| 功能 | 工具调用或推理等能力 |
| 年份 | 发布年份 |
| 排序 | 最新、最热门（7 天 token 数）、价格、上下文长度、吞吐量、延迟 |

要查看某个实验室的所有模型，请打开它的[组织页面](./organisations.mdx)。

## 模型页面显示的内容

| 部分 | 告诉你什么 |
| --- | --- |
| **提供商** | 每条提供商路由的状态、上下文长度、价格、正常运行时间和数据政策。图标含义见[提供商状态](../guides/provider-statuses)。 |
| **性能** | 在数据充足时，基于 Gateway 流量测得的延迟和吞吐量。 |
| **价格** | 以 USD 计的每一项计量：输入、输出、缓存输入和媒体单位。 |
| **基准测试** | 各项基准测试的分数及来源。 |
| **活动** | Gateway token 使用量随时间的变化。 |
| **应用** | 使用该模型的公开应用。 |
| **运行时间** | 最近几天的路由可用性。 |
| **验证** | 图像和视频模型的内容来源核验。 |
| **关于** | 发布日期、许可证、链接和模型系列。 |
| **订阅** | 包含该模型的提供商订阅计划。 |
| **常见问题** | 关于该模型的常见问题。 |

只有在有相应数据时才会显示该部分。拥有活跃路由的模型还会显示一个快速入门，其中包含要发送的模型 ID。

## 比较模型

[比较](https://phaseo.app/compare)可以在价格、基准测试分数、上下文和功能方面并排比较模型。[价格与性能](./pricing-performance.mdx)介绍如何解读成本和速度数据。

## 报告更正

附上模型页面和官方来源，提交一个 GitHub issue。维护者会在数据库中应用已批准的更新。请参阅[报告模型更新](../contributing/editing-a-model.mdx)。
