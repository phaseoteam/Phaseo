Phaseo 跟踪一个开放的大型 AI 模型目录，涵盖文本、图像、音频、视频、嵌入和其他模态。

每个模型页面都提供详细的技术和商业信息，帮助你评估、比较并选择适合需求的模型。

<Info>
模型目录的范围比 Gateway 更广。默认情况下，“模型”页面只显示具有有效 Gateway 路由的模型。只有在你需要查看即将推出或非活动的目录条目时，才选择其他 Gateway 状态。
</Info>

---

## 模型页面包含的内容

Phaseo 的每个模型页面都包含以下主要部分：

| 部分 | 说明 |
| --- | --- |
| **概览** | 提供商、发布日期、模型类型（聊天、代码、嵌入、图像等）和简短描述。 |
| **系列** | 相关模型及其关系。 |
| **时间线** | 随时间变化的发布历史和重大更新。 |
| **基准测试** | 展示不同基准测试的性能结果，便于比较相近模型。 |
| **可用性** | 区分有效 Gateway 路由、即将推出、非活动和外部提供商映射。 |
| **定价** | 以美元显示详细价格，并进行标准化以便比较和估算成本。 |
| **Gateway** | 有公共 Gateway 路由时显示直达链接和快速入门。 |
| **性能** | 数据充足时，展示 Gateway 路由请求的观测延迟、吞吐量和成功情况。 |

## 目录模型与可路由模型

请一致使用以下术语：

| 术语 | 含义 |
| --- | --- |
| 目录模型 | Phaseo 跟踪该模型的元数据，但它可能没有公共路由。 |
| 可路由模型 | Phaseo Gateway 当前至少有一条有效的提供商路由。 |
| 外部映射 | Phaseo 跟踪某个提供商的服务，但 Gateway 不负责执行。 |

通过 API 查找模型时，`GET /v1/models` 默认只返回可路由模型。设置 `availability=all` 可查看范围更广的目录内容。

## 按条件查找模型

使用 Phaseo 界面中的筛选器和标签，查找符合需求的模型：

- **按提供商：**“显示所有 Anthropic 模型。”
- **按能力：**“列出支持 JSON 结构化响应的模型。”
- **按基准测试：**“GPQA 排名前 10 的模型。”
- **按价格：**“每 1,000 个令牌低于 0.01 美元的模型。”
- **按发布日期：**“最近发布的模型。”

组合使用筛选器，精准找到所需模型。
