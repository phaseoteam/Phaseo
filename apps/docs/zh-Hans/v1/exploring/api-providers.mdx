API 提供商是托管并提供模型 API 的平台。

模型组织负责训练模型。提供商通过生产端点、身份验证、用量控制和运维工具提供这些模型。

## API 提供商通常负责的事项

- 身份验证和密钥管理
- 请求路由和可用性管理
- 用量计量和计费
- API 与 SDK 的易用性
- 区域托管和合规控制

## 提供商与组织

| 方面 | 组织 | API 提供商 |
| --- | --- | --- |
| 主要职责 | 构建和训练模型 | 托管并提供模型 API |
| 关注重点 | 研究和模型质量 | 可靠性、访问和运维 |
| 提供范围 | 通常是自有模型系列 | 可能提供多个组织的模型 |

根据产品不同，许多公司同时承担这两种角色。

## 作为提供商层的 Phaseo Gateway

Phaseo Gateway 统一接入多个后端。

优势：

- 各提供商使用统一的请求和响应格式
- 支持感知提供商的路由和回退行为
- 多提供商集成可使用统一 SDK
- 集中查看用量和费用
- 可选 BYOK 支持，以使用提供商原生密钥

## 选择提供商

评估提供商时，请关注：

- 是否提供适合你用例的模型
- 目标区域的可靠性和延迟
- 预期流量下的成本
- 对工具、流式传输和结构化输出的支持程度
- 合规性和数据处理要求

## 评估问题示例

- 哪些提供商提供我需要的模型系列？
- 哪家提供商在我的区域延迟更低？
- 按我的令牌用量，哪种方案成本最低？
- 哪家提供商支持我需要的端点功能？
