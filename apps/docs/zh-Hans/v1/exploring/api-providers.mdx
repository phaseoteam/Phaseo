在 [API 提供商](https://phaseo.app/api-providers)中打开某个提供商，即可查看它通过 Phaseo 提供哪些模型、速度表现如何；也可以[并排比较提供商](https://phaseo.app/api-providers/compare)。API 提供商通过 API 托管模型；开发该模型的[组织](./organisations.mdx)往往是另一家公司。

| | 组织 | API 提供商 |
| --- | --- | --- |
| **职责** | 构建并训练模型 | 托管并提供模型 API |
| **关注点** | 研究和模型质量 | 可靠性、访问、地区和价格 |
| **模型** | 通常是自家的模型系列 | 往往来自多个组织 |

许多公司同时扮演这两种角色。

## 提供商页面显示的内容

| 部分 | 告诉你什么 |
| --- | --- |
| **性能** | 过去七天 Gateway 流量的每小时延迟和吞吐量。 |
| **Token 使用量** | Phaseo 随时间发送给该提供商的 token 数。 |
| **热门模型**和**热门应用** | 在该提供商上流量最多的模型和公开应用。 |
| **模型** | 该提供商提供的所有模型，按文本、图像、音频、视频、嵌入和审核模型分标签页显示。 |

在各模型的页面上，还能看到该提供商对该模型的价格、上下文长度、状态和数据政策；状态图标的含义见[提供商状态](../guides/provider-statuses)。

## Gateway 如何使用提供商

当一个模型有多个提供商时，Gateway 会为每个请求选择一个提供商，失败时回退到另一个。无论由哪个提供商处理，你都只需发送一种请求格式，并获得一份账单和一份使用日志。如果想改为向你自己的提供商账户计费，请添加提供商密钥（[BYOK](../guides/routing-and-fallbacks#byok-considerations)）。

[路由与回退](../guides/routing-and-fallbacks)介绍如何对提供商排序、固定或排除提供商。

## 选择提供商

| 如果你关心 | 请查看 |
| --- | --- |
| 某个特定模型 | 模型页面的**提供商**部分，或 `GET /v1/models/{author}/{slug}/endpoints` |
| 你所在地区的延迟 | 提供商的**性能**部分，以及模型页面上它的地区 |
| 按你的用量计算的成本 | 模型的**价格**部分和[价格计算器](https://phaseo.app/tools/pricing-calculator) |
| 工具、流式传输或结构化输出 | 模型页面或端点 API 上该路由支持的参数 |
| 数据处理与合规 | 模型页面上该路由的数据政策和处理地点 |

[价格与性能](./pricing-performance.mdx)介绍如何解读成本和速度数据。
