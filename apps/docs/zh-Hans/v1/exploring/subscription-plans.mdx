## 订阅计划

本页介绍使用 Phaseo 所列 API 供应商时常见的订阅计划和级别，涵盖典型限额、计费周期，以及计划功能对模型访问权限和价格的影响。

---

### 订阅计划涵盖的内容

-   速率限制（每分钟或每天的请求数）
-   包含的计算资源或 Token 额度
-   访问高级模型或功能（例如 JSON 模式、专用端点）
-   支持服务级别协议（SLA）和商务条款

### 常见级别

以下是常见计划级别的示例；具体名称和功能因供应商而异：

-   免费/试用：用量有限、速率限制较低且不含 SLA
-   开发者/业余版：月费较低，限额适中，适合原型开发
-   商务/团队版：限额更高，支持团队席位和优先服务
-   企业版：自定义限额、专属支持和合同 SLA
