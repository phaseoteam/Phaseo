Phaseo 提供免费访问和按量付费的模型使用。需要身份与目录管理的团队可以另外添加月付 Enterprise 订阅。以下价格均以 USD 计。

## 选择 Phaseo 的使用方式

| 选项 | Phaseo 收费 | 涵盖内容 |
| --- | --- | --- |
| 免费访问 | 使用支持的免费模型无需订阅或充值 | 免费模型、公开目录数据、SDK 和集成 |
| Pay As You Go | 按目录价格计费，购买积分时另收 5% 手续费（最低 $1） | 使用工作区预付积分向付费模型发送请求 |
| 自带密钥（BYOK） | 能获取月度用量时，每个工作区每个 UTC 自然月前 250,000 次已完成请求免 Phaseo 服务费；之后收取提供商等价成本的 2.5%。如果月度计数器和备用读取都不可用，该请求会收取 2.5% 的服务费 | 使用自己的提供商凭据进行 Phaseo 路由与可观测性管理；模型用量由提供商直接计费 |
| Self Serve Enterprise | 工作区月付订阅从 $29 起，模型用量与积分购买手续费另计 | SSO、SCIM、目录管理、部门和优先电子邮件支持 |

Pay As You Go 无需月付订阅、合同或每月最低消费。手续费在购买积分时收取，之后托管请求按列出的模型价格消耗积分。

免费模型受请求额度限制。Gateway 默认允许每个用户在每个工作区的滚动一分钟内发送 25 次请求，另有每个 UTC 日 1,500 次免费模型请求的额度。提供商配额也适用。额度范围与重试规则见[速率限制](../api-reference/limits.mdx)。

BYOK 配置与计费详情见[路由与回退](../guides/routing-and-fallbacks.mdx)。免 Phaseo 服务费的 BYOK 请求仍可能产生提供商的用量费用。

## Enterprise 成员定价

入门订阅包含最多 100 名工作区成员，也适用于较小的团队。更大的额度按成员数量定价；以下是参考价格，而不是功能不同的档位：

| 包含的工作区成员数 | 月付订阅 |
| ---: | ---: |
| 100 | $29 |
| 1,000 | $79 |
| 10,000 | $299 |
| 25,000 | $599 |
| 50,000 | $1,099 |
| 100,000 | $1,999 |

打开[定价](https://phaseo.app/pricing)，选择成员额度并查看对应报价。自助服务是否可用取决于工作区的开放权限。如需发票、采购或定制商业条款，请联系[帮助中心](https://phaseo.app/help)。

成员只要属于工作区就计入人数，无论是否登录。低于 100,000 人时，超出所选额度的新成员加入会被阻止。目前无法自助更改额度，请在订阅前预留增长空间。

选择 100,000 人额度后，额外的独立成员按每个订阅计费周期每人 $0.02 收费，包括在该周期内被移除的成员。

Enterprise 不包含模型积分，也不免除标准的 5% 积分购买手续费（最低 $1）。计费示例与成员额度说明见[定价与账单](../pricing/tiers.mdx)。

## 提供商订阅计划

[订阅计划目录](https://phaseo.app/subscription-plans)列出模型提供商销售的订阅。这些订阅有各自的价格、包含的模型、限制和计费条款。提供商订阅不会自动增加 Phaseo 积分或启用 Gateway 路由。

选择计划前，请核对提供商条款与模型的有效 Gateway 路由。使用[定价与性能](./pricing-performance.mdx)比较模型使用成本和可用的性能数据。
