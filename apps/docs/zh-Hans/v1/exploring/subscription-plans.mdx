你可以免费开始使用，为付费模型按量付费，或者自带提供商密钥。只有在需要身份和目录管理控制时，才需要添加 Enterprise 订阅。所有价格均以 USD 计。

## 选择 Phaseo 的使用方式

| 选项 | Phaseo 收费 | 涵盖内容 |
| --- | --- | --- |
| 免费访问 | 不收费 | 免费模型请求、公开目录数据、SDK 和集成 |
| Pay As You Go | 按目录价格计算模型用量，另收 5% 的额度购买手续费（最低 $1） | 使用工作区预付额度发送的付费模型请求 |
| 自带密钥（BYOK） | 每个工作区每个 UTC 自然月的前 250,000 次已完成请求免费，之后收取提供商等价成本的 2.5% | 使用你的提供商凭据进行 Phaseo 路由和可观测性；模型用量由提供商直接计费 |
| Self Serve Enterprise | 工作区月度订阅 $29 起，另加模型用量和额度购买手续费 | SSO、SCIM、目录管理、部门和优先电子邮件支持 |

Pay As You Go 没有月度订阅、合同或每月最低消费。手续费在你购买额度时收取；之后请求会按列出的模型价格消耗这些额度。[定价与账单](../pricing/tiers.mdx)中有充值计算示例。

## 默认请求限制

在 Gateway 默认的每分钟限制之外，免费模型还有每日配额：

| 限制 | 默认值 | 范围 |
| --- | --- | --- |
| 每分钟请求数（所有模型） | 25 | 每个工作区中的每个用户，滚动一分钟 |
| 每日免费模型请求数 | 1,500 | 每个用户，在你的所有工作区和所有免费模型之间共享；在 00:00 UTC 重置 |

超出每日配额的请求会失败，并返回 `phaseo_free_model_limit_exceeded`。提供商配额同样适用。范围和重试行为见[速率限制](../api-reference/limits.mdx)。

## BYOK 费用

即使 Phaseo 不收取费用，BYOK 请求仍会产生提供商的用量费用。如果 Phaseo 无法读取工作区的月度请求数（计数器及其备用读取都失败），该请求需支付 2.5% 的费用。在[路由与回退](../guides/routing-and-fallbacks.mdx#byok-considerations)中设置密钥和回退规则。

## Enterprise 成员定价

入门订阅包含最多 100 名工作区成员，也适用于较小的团队。更大的成员名额按成员数量定价；以下是参考价格，而不是功能不同的档位：

| 包含的工作区成员数 | 月度订阅 |
| ---: | ---: |
| 100 | $29 |
| 1,000 | $79 |
| 10,000 | $299 |
| 25,000 | $599 |
| 50,000 | $1,099 |
| 100,000 | $1,999 |

介于这些档位之间的成员名额，按相邻两行之间的线性插值定价。打开[定价](https://phaseo.app/pricing)选择成员名额，即可看到按你的成员数计算的报价。能否自助订阅取决于你的工作区是否已开通。

**成员如何计数。** 成员只要属于工作区就计入人数，无论是否登录。在 100,000 人以下时，超出所选名额的新成员加入会被阻止。订阅后你无法自行更改名额，因此请为预期增长预留容量。选择 100,000 人名额时，每增加一名独立成员，按每个订阅计费周期收取 $0.02，包括在该周期内被移除的成员。

Enterprise 不包含模型额度，也不免除 5% 的额度购买手续费（最低 $1）。如需发票、采购或定制商业条款，请联系[帮助中心](https://phaseo.app/help)。

## 提供商订阅计划

[订阅计划目录](https://phaseo.app/subscription-plans)列出了模型提供商销售的订阅。这些订阅有各自的价格、包含的模型、限制和计费条款。提供商订阅不会增加 Phaseo 额度，也不会启用 Gateway 路由。

选择计划前，请核对提供商的条款和模型的活跃 Gateway 路由。使用[价格与性能](./pricing-performance.mdx)比较模型使用成本和性能数据。
