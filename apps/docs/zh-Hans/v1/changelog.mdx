<Update label="2026年10月28日">

<div data-changelog-category="api">

<p className="changelog-category">API 与 SDK</p>

- 当结构化输入的某个字段是嵌套对象或数组时，`/v1/embeddings` 返回 `400 validation_error`；此前返回 `502` ([#3296](https://github.com/phaseoteam/Phaseo/pull/3296))。
- 当所有提供商都以相同的 `400`、`413` 或 `422` 拒绝请求时，网关返回该状态码和提供商的消息，而不是 `502` ([#3296](https://github.com/phaseoteam/Phaseo/pull/3296))。
- API 密钥支出上限触发的 `429` 错误显示美元金额，例如 `$0.0117 of $0.01`，月度上限也会保留 `Retry-After` 标头 ([#3296](https://github.com/phaseoteam/Phaseo/pull/3296))。

</div>

</Update>

<div data-changelog-category="api">

<p className="changelog-category">API 与 SDK</p>

- 使用预设的请求可以用 `prompt.version` 或 `model: "@slug@label"` 固定版本或标签，未知的值返回 `404 preset_version_not_found`；请参阅[提示词模板](./guides/prompt-templates.mdx) ([#3281](https://github.com/phaseoteam/Phaseo/pull/3281))。
- `GET /v1/presets/{id}/labels` 可列出预设标签，`PUT` 和 `DELETE /v1/presets/{id}/labels/{label}` 可移动和删除单个标签；请参阅[Set preset label](./api-reference/endpoint/presets-label-set.mdx) ([#3283](https://github.com/phaseoteam/Phaseo/pull/3283))。
- Chat Completions、Responses 和 Messages 的流式事件现在在 `model` 中返回 Phaseo 模型 ID；此前部分事件返回的是提供商自己的 ID ([#3273](https://github.com/phaseoteam/Phaseo/pull/3273))。
- 对于具有 `profile` 范围的令牌，`GET /oauth/userinfo` 会根据 Phaseo 个人资料返回 `picture`、`name` 和 `given_name` ([#3189](https://github.com/phaseoteam/Phaseo/pull/3189))。

</div>

<div data-changelog-category="product">

<p className="changelog-category">产品</p>

- 密钥安全移至 **设置 -> API 密钥 -> 密钥安全**，密钥表格新增 **Status** 列和可排序的列 ([#3184](https://github.com/phaseoteam/Phaseo/pull/3184))。
- Broadcast 可以将追踪发送到 Amazon S3 及兼容 S3 的存储、Cloudflare R2、Google Cloud Storage、ClickHouse、BigQuery 和 Snowflake；请参阅[Broadcast](./guides/broadcast.mdx) ([#3181](https://github.com/phaseoteam/Phaseo/pull/3181), [#3182](https://github.com/phaseoteam/Phaseo/pull/3182), [#3185](https://github.com/phaseoteam/Phaseo/pull/3185))。
- 新指南：[Broadcast](./guides/broadcast.mdx) 列出了每种目标类型的设置 ([#3190](https://github.com/phaseoteam/Phaseo/pull/3190))。
- 对比页面新增 30 天 **Activity** 图表，显示每个模型通过 Phaseo 的令牌数和请求数 ([#3147](https://github.com/phaseoteam/Phaseo/pull/3147))。
- 对比页面显示每个模型在能力指数上的排名 ([#3148](https://github.com/phaseoteam/Phaseo/pull/3148))。
- 两个模型的对比有了自己的页面，包含摘要和常见问题，例如 `/compare/anthropic_claude-opus-5.5-vs-openai_gpt-6-astra` ([#3162](https://github.com/phaseoteam/Phaseo/pull/3162))。

- 通过欧盟和美国区域网关发送的请求现在也会到达 Broadcast 目标 ([#3187](https://github.com/phaseoteam/Phaseo/pull/3187))。

- 请求详情会说明零数据保留何时跳过了内容存储 ([#3178](https://github.com/phaseoteam/Phaseo/pull/3178))。
- 对比页面可以在每个模型下选择路由和服务层级，价格、成本计算器和结论都会随之更新 ([#3133](https://github.com/phaseoteam/Phaseo/pull/3133))。

<div data-changelog-category="api">

<p className="changelog-category">API 与 SDK</p>

- `/v1/messages` 接受对话中途的 `role: "system"` 消息，前提是位置符合 Claude 的规则；请参阅[创建消息](./api-reference/endpoint/anthropic-messages.mdx) ([#3165](https://github.com/phaseoteam/Phaseo/pull/3165))。
- 密钥端点和所有 SDK 都接受并返回 `storage_locations`，最多记录八个密钥存放位置，例如 `["railway", "github"]`；请参阅[创建 API 密钥](./api-reference/endpoint/keys-create.mdx) ([#3164](https://github.com/phaseoteam/Phaseo/pull/3164))。
- **测试版：** `/v1/department-budgets` 为每个部门设置按日、按周或按月的美元预算，在约 80% 和 100% 时提醒所有者和管理员，但不会阻止请求 ([#3125](https://github.com/phaseoteam/Phaseo/pull/3125))。
- 无论由工作区设置、密钥护栏还是请求本身开启，零数据保留都会让请求的提示词和响应内容不进入响应缓存、数据样本和 Phaseo 遥测 ([#3161](https://github.com/phaseoteam/Phaseo/pull/3161), [#3175](https://github.com/phaseoteam/Phaseo/pull/3175))。
- 发往自定义 Webhook 的通知使用 `x-phaseo-timestamp` 和 `x-phaseo-signature`（HMAC-SHA256）签名；请参阅[工作区通知](./guides/workspace-notifications.mdx) ([#3089](https://github.com/phaseoteam/Phaseo/pull/3089))。
- Broadcast 将请求的 `metadata` 导出为 `phaseo.metadata.<key>` span 属性 ([#3127](https://github.com/phaseoteam/Phaseo/pull/3127))。
- 请求 `metadata` 中的 `trace_name`、`span_name`、`generation_name` 和 `trace_id` 用于命名和分组 Broadcast 导出的追踪 ([#3127](https://github.com/phaseoteam/Phaseo/pull/3127))。

</div>

</Update>

<div data-changelog-category="api">

<p className="changelog-category">API 与 SDK</p>

- **破坏性变更：** 错误响应中的 `error` 改为包含 `code`、`message`、`type`、`param` 和 `metadata` 的对象；原先把 `error` 当字符串读取的代码应改读新的顶层 `code`；请参阅[错误与调试](./api-reference/errors.mdx) ([#3055](https://github.com/phaseoteam/Phaseo/pull/3055))。
- Chat Completions、Responses、Messages 和 embeddings 响应包含以美元计的 `usage.cost` 和明细 `usage.cost_details` ([#3050](https://github.com/phaseoteam/Phaseo/pull/3050))。
- `POST /v1/keys` 在顶层以 `key` 返回新密钥；请参阅[创建 API 密钥](./api-reference/endpoint/keys-create.mdx) ([#3050](https://github.com/phaseoteam/Phaseo/pull/3050))。
- 文本端点接受可选参数的显式 `null`、`service_tier: "auto"` 和 `"scale"`，以及 `prediction`，这些输入以前会返回 `400` ([#3049](https://github.com/phaseoteam/Phaseo/pull/3049))。
- `web` 和 `web-fetch` 插件可用于任何模型，以 Phaseo 网页搜索和网页抓取服务器工具的形式运行；请参阅[网页搜索服务器工具](./guides/server-tools/web-search.mdx) ([#3051](https://github.com/phaseoteam/Phaseo/pull/3051))。
- 速率限制策略会执行 `tokens_per_minute`，并返回 `x-ratelimit-limit-tokens`、`x-ratelimit-remaining-tokens` 和 `x-ratelimit-reset-tokens` 标头；请参阅[速率限制](./api-reference/limits.mdx) ([#2961](https://github.com/phaseoteam/Phaseo/pull/2961))。
- 分配给部门的速率限制策略现在会作用于该部门的请求 ([#3088](https://github.com/phaseoteam/Phaseo/pull/3088))。
- 提示缓存写入按公开费率计费：Claude 1 小时写入为输入价格的 2 倍，OpenAI 12 小时写入为 2.5 倍；请参阅[提示缓存](./guides/prompt-caching.mdx) ([#3078](https://github.com/phaseoteam/Phaseo/pull/3078), [#3076](https://github.com/phaseoteam/Phaseo/pull/3076))。
- Responses 的 usage 在 `input_tokens_details.cache_write_tokens_details` 中返回 30 分钟和 12 小时缓存写入的拆分 ([#3078](https://github.com/phaseoteam/Phaseo/pull/3078))。
