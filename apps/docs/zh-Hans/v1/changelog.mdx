<Update label="2026年10月24日" tags={["产品"]} rss={{ title: "2026年10月24日: 产品" }}>

- 已停用模型的路由现已向所有工作区开放。当不再有任何提供商提供某个已停用模型时，它的请求可以转到已批准的替代模型，而不会失败。此功能默认关闭：所有者和管理员可在 **设置 -> 路由 -> 已停用模型的路由** 中开启，并选择是否允许替代模型价格更高。被重定向的响应会带有 `x-phaseo-model-substitution` 标头。请参阅[模型弃用与停用](./guides/model-retirement.mdx)。

</Update>

<Update label="2026年10月9日" tags={["产品"]} rss={{ title: "2026年10月9日: 产品" }}>

- 聊天新增可选的交互式回答实验功能，开关位于临时聊天旁边，支持对比卡片、表格、条形图和后续表单。表单值会保存在各个回答版本中，提交后将继续对话。

</Update>
