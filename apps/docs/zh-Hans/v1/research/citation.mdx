## 引用基准测试分数

Phaseo 不运行基准测试。它发布由基准测试作者、模型开发者和指数发布方报告的分数，并为每个分数附上来源链接（参见[基准测试方法](./benchmark-methodology.mdx)）。

使用你在 Phaseo 上找到的分数时：

1. 将原始基准测试和论文作为主要来源引用。
2. 也可以注明 Phaseo 是你获取或比较该分数的地方。
3. 写明基准测试名称和数据划分（例如 `MMLU test`）、Phaseo 模型 ID 和提供商、Phaseo 页面或 API 调用的 URL，以及你的访问日期。

> 基准测试分数通过 Phaseo 获取（MMLU test 数据划分），访问日期为 2026 年 3 月 3 日。模型：`openai/gpt-6-astra`，提供商：OpenAI。
