## 基准测试数据

Phaseo **本身不运行基准测试**。我们展示并规范化由基准测试作者和模型提供商报告的分数。

使用通过 Phaseo 获取的基准测试结果时：

1. 将原始基准测试和论文作为主要来源引用。
2. 也可以注明 Phaseo 是你获取或比较分数的平台。
3. 请包含：

- 基准测试名称和数据拆分（例如 `MMLU test`）。
- 模型标识符和提供商。
- 相关 Phaseo 页面或 API 的 URL。
- 访问日期。

示例文本：

> 这些基准测试分数通过 Phaseo 获取（MMLU test 数据拆分），访问日期为 2025 年 3 月 3 日。模型：`openai-gpt-4o`；提供商：OpenAI。
