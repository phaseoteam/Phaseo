流式传输可让界面随着模型生成逐个显示 token，无需等待完整响应。

## 支持的端点

- `POST /v1/responses`
- `POST /v1/chat/completions`
- `POST /v1/messages`

## 启用流式传输

在请求正文中设置 `stream: true`。

```bash
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5-nano",
    "input": "Write a short greeting.",
    "stream": true
  }'
```

## SSE 帧格式

流会以 SSE 帧的形式返回：

```text
data: {"id":"resp_...","status":"in_progress",...}
data: {"type":"response.output_text.delta","delta":"Hello"}
data: {"type":"response.completed",...}
data: [DONE]
```

## 处理流式传输期间的错误

- 如果请求在流开始前失败，你会收到常规 JSON 错误响应。
- 如果在部分输出后失败，请将流视为未完成，并在界面中提供重试方式。
- 如果响应中包含 `generation_id`，请务必记录，以便支持和问题追踪。

## 取消

使用取消控制（JavaScript 中的 `AbortController`，或后端 worker 中的请求超时），避免已放弃的流继续消耗资源。

## 已知限制

Gateway 当前的请求验证层会拒绝 `stream: true` 与工具调用同时使用。工具调用循环请使用非流式模式。
