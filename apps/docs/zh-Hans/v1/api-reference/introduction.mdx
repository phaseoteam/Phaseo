打开端点参考页面之前，请先在此查找合适的 API 路径。所有 Phaseo Gateway 端点共用一个基础 URL，并使用 Bearer 身份验证。

## 选择路径

| 目标 | 从这里开始 |
| --- | --- |
| 发送第一个请求 | [快速入门](../quickstart.mdx) |
| 生成文本或使用工具 | `POST /responses` |
| 保留现有的 OpenAI 兼容集成 | `POST /chat/completions` |
| 浏览模型和提供商 | `GET /models` 和 `GET /providers` |
| 创建音乐或管理文件 | `POST /music/generations` 和 `POST /files` |

## 基础 URL

生产环境基础 URL：

```http
https://api.phaseo.app/v1
```

本参考中的所有端点路径都相对于基础 URL `/v1`。

## 身份验证

大多数端点需要标准 Gateway API 密钥。管理端点需要在控制台中创建的管理 API 密钥。

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

如果身份验证失败，API 会返回 `401`。

## API 资源

| 资源 | 功能 |
| --- | --- |
| Responses API | 使用工具、结构化输出和多模态输入生成模型响应。 |
| Chat Completions | 保留现有的 OpenAI 兼容聊天集成。 |
| Anthropic Messages | 保留现有的 Anthropic 兼容 Messages 集成。 |
| Embeddings | 创建用于搜索、检索和分类的向量表示。 |
| Images | 生成或编辑图像。 |
| 文本转语音 | 根据文本生成语音音频。 |
| 语音转文本 | 转录或翻译音频。 |
| 音乐生成 | 创建音乐任务并查看其状态。 |
| 文件 | 为受支持的 API 工作流上传和获取输入文件。 |
| 模型、提供商和端点 | 查看 Gateway 提供的内容。 |
| 定价、活动和生成记录 | 估算费用并检查请求结果。 |
| API 密钥和工作区 | 管理程序化访问和工作区资源。 |

## 计费和速率限制

- Phaseo 不会设置自己的速率限制。速率限制由上游提供商执行。
- 付费请求需要钱包中有足够余额，才能通过预先的积分检查。
- 带有 `:free` 的免费模型无需预存积分。
