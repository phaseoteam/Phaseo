将每个请求发送到 `https://api.phaseo.app/v1`，并在 `Authorization: Bearer` 标头中带上你的密钥。在下方找到适合你任务的端点，然后打开它的参考页面。

## 找到合适的端点

| 如果你想 | 从这里开始 |
| --- | --- |
| 发送第一个请求 | [快速入门](../quickstart) |
| 生成文本或使用工具 | [`POST /responses`](./endpoint/responses) |
| 作出带类型的决策 | [`POST /decisions`](./endpoint/decisions) |
| 保留现有的 OpenAI 兼容集成 | [`POST /chat/completions`](./endpoint/chat-completions) |
| 浏览模型和提供商 | [`GET /models`](./endpoint/models) 和 [`GET /providers`](./endpoint/providers) |
| 创建音乐或管理文件 | [`POST /music/generate`](./endpoint/music-generate) 和 [`POST /files`](./endpoint/files) |
| 生成视频（测试版） | [`POST /videos`](./endpoint/video-create) |
| 提交批处理或下载结果（测试版） | [`POST /batches`](./endpoint/batches-create) 和 [`GET /batches/{batch_id}/results`](./endpoint/batches-results) |

## 基础 URL

```http
https://api.phaseo.app/v1
```

本参考中的每个端点路径都相对于这个基础 URL。

## 身份验证

| 凭据 | 格式 | 可调用 |
| --- | --- | --- |
| [Gateway API 密钥](../developers/authentication.mdx) | `phaseo_v1_sk_<kid>_<secret>` | 推理端点 |
| [管理 API 密钥](../developers/management-api-keys.mdx) | `phaseo_v1_mk_<kid>_<secret>` | 管理端点，受该密钥的权限限制 |

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

如果身份验证失败，API 会返回 `401`。

## API 资源

| 资源 | 功能 |
| --- | --- |
| 推理 | 生成文本、图像、音频和嵌入；作出决策、重排、审核或解析内容。从 [Responses](./endpoint/responses.mdx) 或 [Decisions](./endpoint/decisions.mdx) 开始。 |
| 异步任务与文件 | 提交[视频](./endpoint/video-create.mdx)或[批处理](./endpoint/batches-create.mdx)任务、传输文件并配置 webhook。 |
| 模型与定价 | 了解[模型](./endpoint/models.mdx)、提供商 offer 和[估算费用](./endpoint/pricing-calculate.mdx)。 |
| 路由与策略 | 配置预设、提供商凭据、私有模型和[护栏](./endpoint/guardrails.mdx)。 |
| 用量与监控 | 查看[日志](./endpoint/logs-list.mdx)、活动、分析、评估和服务健康状态。 |
| 工作区管理 | 管理[工作区](./endpoint/workspaces-list.mdx)、密钥、预算、身份和集成。 |

## 计费和速率限制

付费请求在运行前，钱包余额必须足以通过额度检查。ID 以 `:free` 结尾的模型不需要预存额度。请求可能会被提供商限流，也可能受工作区和密钥限制而被限流；请参阅[速率限制](./limits.mdx)。
