将 `model` 和 `prompt` 发送到 `POST /v1/music/generate`，即可用同一种请求格式从任意音乐提供商获得一首曲目。Phaseo 会替你处理同步提供商以及提供商队列的轮询。

```bash
curl https://api.phaseo.app/v1/music/generate \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax/music-3.0:free",
    "prompt": "Warm jazz trio with brushed drums",
    "format": "mp3"
  }'
```

## 读取结果

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "gmicloud",
  "model": "minimax/music-3.0:free",
  "nativeResponseId": "5c30b275-d669-4a25-8151-de6d60214853",
  "audio_url": "https://.../generated-music.mp3",
  "usage": {
    "requests": 1,
    "output_audio_seconds": 25.364
  }
}
```

已完成的生成结果包含 `audio_url` 或 `audio_base64`。`status` 为 `queued`、`in_progress`、`completed` 或 `failed`。如果尚未到达最终状态，请使用同一个 `id` 轮询 [`GET /v1/music/generate/{music_id}`](./music-status.mdx)。

`id` 是稳定的 Phaseo 请求 ID。`nativeResponseId` 是上游提供商的标识符，用于与提供商关联和联系支持。当提供商报告生成时长时，`usage` 会包含 `output_audio_seconds`。

## 设置 Suno 选项

Suno 模型接受一个可选的 `suno` 对象：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `customMode` | boolean | 默认为 `false` |
| `instrumental` | boolean | 默认为 `false` |
| `prompt` | string | 覆盖顶层 `prompt` |
| `style`、`title` | string | 当 `customMode` 为 `true` 时必填 |
| `personaId`、`personaModel` | string | |
| `negativeTags` | string | |
| `vocalGender` | `m` 或 `f` | |
| `styleWeight`、`weirdnessConstraint`、`audioWeight` | number | 0 到 1 |

当 `customMode` 为 `false` 时，以及当 `customMode` 为 `true` 且 `instrumental` 设为 `false` 时，`prompt` 为必填项。

违反提供商规则的请求会返回 `400`：

```json
{
  "error": "validation_error",
  "reason": "..."
}
```
