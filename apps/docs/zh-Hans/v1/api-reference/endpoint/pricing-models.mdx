description: "列出网关当前公开的有效目录定价卡片。"
---

- `models`：每个可见的供应商/模型/端点/服务层级组合对应一项
- `service_tier`：该条目价格适用的供应商服务层级，例如 `standard`、`flex` 或 `priority`
- `meters`：该条目的有效计量项，包括单位、单位大小、币种和单价
- `display_name`：定价规则映射到规范公共模型时显示的模型名称
