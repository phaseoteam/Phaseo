<Info>
管理防护规则需要管理 API 密钥。读取操作需要 `guardrails:read`；修改操作需要 `guardrails:write` 或 `guardrails:delete`。
</Info>

使用防护规则来应用隐私控制、提供商和模型限制、提示注入处理以及敏感信息策略。防护规则可以分配给 API 密钥、工作区成员或两者。

防护规则不会强制执行请求或支出上限。`budgets` 输入以及 `*_limit_requests` 和 `*_limit_cost_nanos` 字段仅为兼容而接受和返回，不会产生任何效果。请改用 [API 密钥上限](./keys-update.mdx) 或 [工作区预算](./budgets-list.mdx)。

成功修改后会刷新工作区策略状态，并显示在工作区审计日志中。
