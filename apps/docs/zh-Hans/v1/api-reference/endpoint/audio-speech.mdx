## 选择音色

为了让请求可在不同提供商之间移植，请设置顶层 `voice`。Phaseo 会将它映射为路由到的提供商的音色；如果路由到的提供商和模型不接受该 `voice`，会返回 `400 invalid_request_error`，并附带 `param: "voice"`。

| 提供商 | 接受的 `voice` 值 | 试听 |
| --- | --- | --- |
| `openai` | 常用音色，例如 `alloy`、`ash`、`ballad`、`coral`、`echo`、`fable`、`onyx`、`nova`、`sage`、`shimmer`、`verse`、`cedar`、`marin` | [openai.fm](https://www.openai.fm/) |
| `google`（AI Studio / Gemini TTS） | 预置音色：`Zephyr`、`Puck`、`Charon`、`Kore`、`Fenrir`、`Leda`、`Orus`、`Aoede`、`Callirrhoe`、`Autonoe`、`Enceladus`、`Iapetus`、`Umbriel`、`Algieba`、`Despina`、`Erinome`、`Algenib`、`Rasalgethi`、`Laomedeia`、`Achernar`、`Alnilam`、`Schedar`、`Gacrux`、`Pulcherrima`、`Achird`、`Zubenelgenubi`、`Vindemiatrix`、`Sadachbia`、`Sadaltager`、`Sulafat` | [Gemini 文字转语音文档](https://ai.google.dev/gemini-api/docs/speech-generation#voices) |
| `elevenlabs` | 常见的公开入门音色，例如 `rachel`、`domi`、`bella`、`antoni`、`elli`、`josh`、`arnold`、`adam`、`sam` | [ElevenLabs Voice Library](https://elevenlabs.io/voice-library) |

对于 `eleven-labs/eleven-v4` 和 `eleven-labs/eleven-v4-turbo`，可以传入任意 20 个字符的 ElevenLabs 音色库 ID，包括自定义克隆音色。按需设置 `config.elevenlabs.voice_settings.stability` 和 `similarity_boost`。Eleven v4 不支持 `speed` 或 `voice_settings.style`。

## 传入提供商原生音色

要使用提供商自己的音色设置而不是 `voice`：

- ElevenLabs：`config.elevenlabs.voice_id`、`config.elevenlabs.voice` 或 `config.elevenlabs.voiceName`。
- Google：`config.google.voice_name` 或 `config.google.voiceName`。
