description: "加密并存储用于工作区路由的供应商凭据。"
---

<Warning>
`key` 值只能写入。Phaseo 会立即将其加密，且不会在 API 响应中返回。
</Warning>

使用 `routing_mode: "priority"` 可在托管容量之前尝试此凭据，使用 `"fallback"` 则会在之后尝试。在工作区设置中配置 `byokFallbackEnabled`，以控制优先凭据失败时是否回退到托管容量。
