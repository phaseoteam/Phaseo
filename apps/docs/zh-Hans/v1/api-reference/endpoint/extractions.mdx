<Warning>提取功能处于预览阶段。模型可用性取决于已配置的提供商路由。</Warning>

列出你想要的 `fields`，并将它们与源文本一起发送到 `POST /v1/extractions`，即可获得类型化的值，例如发票号、日期或总额。如果要在已知选项中做选择，请改用[决策](./decisions.mdx)。

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/extractions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cloudflare/clairic",
    "input": "Invoice INV-2291: 4 pallets at $250 each, shipping $80.",
    "fields": {
      "invoice_number": { "type": "text" },
      "total": { "type": "number", "decimals": 2, "instructions": "Total including shipping" }
    }
  }'
```

```typescript TypeScript SDK
import { Phaseo } from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY });
const result = await client.extractions.create({
  model: "cloudflare/clairic",
  input: "Invoice INV-2291: 4 pallets at $250 each, shipping $80.",
  fields: {
    invoice_number: { type: "text" },
    total: { type: "number", decimals: 2, instructions: "Total including shipping" },
  },
});
console.log(result.answers.total.value);
```

```python Python SDK
import os
from phaseo import Phaseo

client = Phaseo(api_key=os.environ["PHASEO_API_KEY"])
result = client.extractions.create({
    "model": "cloudflare/clairic",
    "input": "Invoice INV-2291: 4 pallets at $250 each, shipping $80.",
    "fields": {"total": {"type": "number", "decimals": 2,
                         "instructions": "Total including shipping"}},
})
print(result["answers"]["total"]["value"])
```
</CodeGroup>

这些示例需要一个可用的提取模型路由，因此请在发送请求前检查模型可用性。Python `AsyncPhaseo` 也提供 `await client.extractions.create(...)`。

## 字段类型

支持的类型有 `text`、`number`、`date`、`time`、`datetime`、`duration` 和 `list`。列表需要 `items: "text"`、`"number"` 或 `"date"`。需提供 1–64 个字段，源文本最多 16,384 个字符。字段名以字母或下划线开头，最多包含 64 个字母、数字、下划线、点或连字符。

数字和时长支持 `integer` 和 `decimals`（0–6）。时长接受 `seconds`、`minutes`、`hours`、`days`、`weeks`、`months` 或 `years`。如果解释不完整的日期取决于某个特定年份，请设置 `reference_date`。

图像输入使用 `{ content_type, base64 }` 对象：最多四张 PNG/JPEG/WebP 图像，解码后每张不超过 4 MiB，合计不超过 8 MiB。请求大小上限为 16 MiB。不支持远程 URL、PDF、音频、视频、估算、预测和流式传输。

## 读取答案

读取 `answers[field_name].value`。当源内容无法确定某个标量值时，该值可以为 `null`。`p_null` 是模型认为该值无法确定的概率；`confidence` 是模型报告的另一个独立评分。列表提供 confidence，但不提供 `p_null`。这些评分并不保证正确：请根据你的工作负载选择人工审核的阈值。有效的空列表与失败的请求不同。

`truncated: true` 表示提供商没有处理全部源输入。在依赖结果的完整性之前，请先审核，或重新提交更短的输入。不会公开文本偏移量和原始猜测。复杂的算术运算应在应用代码中完成。

用量报告会汇总各轮提供商处理的 `input_tokens`。输出 token 为零。请使用 Gateway 返回的价格，而不要根据源文本长度估算费用，或将用量乘以字段数量。
