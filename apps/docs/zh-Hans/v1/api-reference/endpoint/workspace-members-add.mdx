<Note>此端点需要具有 `workspaces:write` 权限的管理 API 密钥以及所有者或管理员角色。</Note>

用户通过邀请加入工作区：接受邀请后会创建加入请求，此端点负责批准该请求。`user_ids` 中的每个用户都必须在该工作区有待处理的加入请求。其他用户会被拒绝，请先向他们发送邀请。已是成员的用户保留原有角色。

角色可以是 `admin` 或 `member`。未指定角色时，每个人获得其邀请创建时设定的角色。只有工作区所有者可以添加管理员，且无法通过此端点分配工作区所有权。

每个人单独批准。如果某次批准失败，之前已批准的人仍留在工作区，其余的人不会被尝试。此时响应为 `409`，其中的 `approved`、`failed` 和 `not_attempted` 列表显示处理在何处停止，你可以先解决问题，再重新提交其余用户。
