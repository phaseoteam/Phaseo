---

传入 [`POST /v1/music/generate`](./music-generate.mdx) 返回的 `id`，而不是它的 `nativeResponseId`。生成完成后，Phaseo 会返回已存储的结果；仍在运行时，Phaseo 会替你轮询提供商。

```bash
curl https://api.phaseo.app/v1/music/generate/req_01JY6MUSIC123 \
  -H "Authorization: Bearer $PHASEO_API_KEY"
```

```json
{
  "id": "req_01JY6MUSIC123",
  "object": "music",
  "status": "completed",
  "provider": "suno",
  "model": "V4_5PLUS",
  "nativeResponseId": "task_123",
  "output": [
    {
      "index": 0,
      "id": "clip_1",
      "audio_url": "https://...",
      "stream_audio_url": "https://...",
      "image_url": "https://...",
      "title": "Midnight Blue",
      "tags": "jazz, piano",
      "duration": 8
    }
  ],
  "usage": {
    "output_audio_count": 1,
    "output_audio_seconds": 8
  }
}
```

`status` 为 `queued`、`in_progress`、`completed` 或 `failed`。生成完成后才会包含 `usage`。
