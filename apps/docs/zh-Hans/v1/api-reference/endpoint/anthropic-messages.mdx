将 Anthropic Messages API 请求体发送到 `/v1/messages`，即可为 Phaseo 路由的任何模型获得 Anthropic 格式的响应。支持 Anthropic 的工具调用字段，`X-Phaseo-Strictness` 标头控制如何处理不支持的参数。

设置 `stream: true` 可接收 Anthropic 格式的服务器发送事件（`message_start`、`content_block_*`、`message_delta`、`message_stop`）。流式传输在工具循环中同样可用。

## 对话中途的系统消息

在 `messages` 中添加一条 `role: "system"` 消息，作为从对话中该位置开始生效的指令。顶层 `system` 字段保持不变，因此缓存的前缀仍能命中。

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-opus-5.5",
    "max_tokens": 512,
    "system": "You are a code review assistant.",
    "messages": [
      { "role": "user", "content": "Review process() in utils.py." },
      { "role": "assistant", "content": "The loop is fine; the regex is compiled on every call." },
      { "role": "user", "content": "Now review the code that calls it." },
      { "role": "system", "content": "From now on, include type annotations in every suggestion." }
    ]
  }'
```

系统消息可以是字符串或文本块。它必须紧跟在用户轮次之后（或紧跟在以服务器工具结果结尾的助手轮次之后），并且必须是最后一条消息，或者后面紧跟一个助手轮次。放在其他位置会返回 `400`。不支持 `clear_at`、`output_config` 以及 `tool_addition` 或 `tool_removal` 块。

| 模型 | 如何接收系统消息 |
| --- | --- |
| Claude Fable 5 和 5.1、Mythos 5 和 5.1、Opus 4.8、Opus 5 和 5.5、Sonnet 5.5、Haiku 5.5 | 保留在原位置 |
| 其他 Claude 模型（包括 Sonnet 5），以及 Microsoft Foundry 上的所有 Claude 模型 | 合并到顶层系统提示中 |
| 其他提供商的模型 | 作为系统消息，与发送到 Chat Completions 的系统消息相同 |

## 使用服务器工具

在 `tools` 中添加一个 `phaseo:` 工具，模型调用它时由 Phaseo 运行：Phaseo 会在上游将其改写为 Anthropic 的工具格式，并在服务器端继续工具循环。`/v1/messages` 接受除 `phaseo:apply_patch` 以外的所有服务器工具；[服务器工具](../../guides/server-tools)指南列出了这些工具。

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "What time is it in America/New_York right now?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["America/New_York"] } }
    ],
    "tool_choice": { "type": "auto" }
  }'
```

服务器工具调用会计入 `usage.server_tool_use`。旧的 `gateway:datetime` 类型仍然可用。设置 `stream: true` 时，Phaseo 会自行运行工具轮次，然后将后续回答作为单个流发送给你。

## 使用 Anthropic 原生网页搜索

当路由到的 Anthropic 模型和提供商支持原生网页搜索时，可直接传入 Anthropic 的工具定义，例如 `type: "web_search_20250305"`。执行前，提供商路由仍会筛选支持 `web_search_options` 的提供商。

```bash
curl https://api.phaseo.app/v1/messages \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5.5",
    "max_tokens": 512,
    "messages": [
      { "role": "user", "content": "Find the latest Anthropic web search guidance." }
    ],
    "tools": [
      {
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": 3,
        "allowed_domains": ["docs.anthropic.com"]
      }
    ],
    "tool_choice": { "type": "auto" }
  }'
```
