description: "估算特定提供商/模型/端点用量载荷的费用。"
---

发送一份用量载荷，按某个提供商、模型和端点当前有效的 Gateway 定价规则为其计价。四个字段都是必填项：

- `provider`：提供商 ID，例如 `openai`。
- `model`：路由的模型 ID。
- `endpoint`：端点类型，例如 `responses` 或 `chat.completions`。
- `usage`：要计价的用量，例如 token 数量或其他计量输入。

如果你想列出当前价格，而不是为单个载荷计价，请使用[列出模型定价](./pricing-models.mdx)。
