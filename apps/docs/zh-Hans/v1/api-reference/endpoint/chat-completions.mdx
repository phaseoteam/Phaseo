## 使用服务器工具

在 `tools` 中、你自己的函数工具旁添加一个 `phaseo:` 工具，模型调用它时由 Phaseo 运行。`/v1/chat/completions` 接受除 `phaseo:apply_patch` 以外的所有服务器工具；[服务器工具](../../guides/server-tools)指南列出了这些工具。

```bash
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "messages": [
      { "role": "user", "content": "What is the current datetime in Europe/London?" }
    ],
    "tools": [
      { "type": "phaseo:datetime", "parameters": { "timezones": ["Europe/London"] } }
    ],
    "tool_choice": "auto"
  }'
```

每次服务器工具调用都会计入 `usage.server_tool_use`：

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 34,
    "total_tokens": 46,
    "server_tool_use": {
      "datetime_requests": 1
    }
  }
}
```

`phaseo:web_search` 会添加 `web_search_requests`、`web_search_results` 和 `web_search_extra_results`；`phaseo:web_fetch` 会添加 `web_fetch_requests`。旧的 `gateway:datetime` 类型仍然可用。

设置 `stream: true` 时，Phaseo 会自行运行工具轮次，然后将后续回答作为单个流发送给你。

## 工具循环中的推理

推理模型会在助手消息的两个字段中返回推理内容：

- `reasoning_content`：推理文本（如果提供商返回了推理文本）。
- `reasoning_details`：推理块数组。每个条目都有一个 `type`（`reasoning.text`、`reasoning.summary` 或 `reasoning.encrypted`）、一个 `index`，以及一个指明提供商系列的 `format`，例如 `anthropic-claude-v1` 或 `google-gemini-v1`。

条目中可能带有模型在工具循环下一步需要的提供商状态：

| 提供商状态 | 所在位置 |
| --- | --- |
| Claude 思考签名 | `reasoning.text` 条目上的 `signature` |
| Claude 已编辑的思考、OpenAI 加密推理 | `reasoning.encrypted` 条目上的 `data` |
| Gemini 思维签名 | `reasoning.encrypted` 条目上的 `data`，其 `id` 是它所属的工具调用 |

流式传输时，每个推理块完成后会收到一个 `reasoning_details` 增量。

要在步骤之间保留模型的推理，请将助手消息连同未修改的 `reasoning_details` 一起发回。`signature` 和 `data` 的值是不透明的，并记录了生成它们的提供商和模型。Phaseo 只会把它们发送给该提供商系列和模型，因此回退到其他提供商时会丢弃它们，而不会导致请求失败。处于手动思考模式的 Claude 模型需要收到自己之前的思考内容，才能在工具循环中继续思考；如果缺失，该步骤将在不思考的情况下运行。
