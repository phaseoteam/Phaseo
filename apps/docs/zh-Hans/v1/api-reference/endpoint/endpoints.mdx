description: "列出由能力数据支持的 Gateway 端点，以及它们的公共路径和模型/提供商覆盖情况。"
---

响应包含三个字段：

- `endpoints`：API 当前公开的规范端点 ID。
- `data`：每个端点一条记录，包含 `id`、`capability_id`、`public_path`、`collection`、`model_count` 和 `provider_count`，按 `public_path` 排序。
- `sample_models`：公共目录中前 10 个可见的模型 ID。

响应会缓存 30 分钟。

如需某个模型在提供商和参数层面的详细信息，请使用[列出模型端点能力](./model-endpoints)。
