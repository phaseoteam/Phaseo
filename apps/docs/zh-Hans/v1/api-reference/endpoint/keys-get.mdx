<Note>
此端点需要管理 API 密钥。不接受标准 Gateway API 密钥。
</Note>

返回已验证工作区中一个 API 密钥的元数据。路径段 `{id}` 是密钥的 ID。仍可使用从旧响应中保存的密钥哈希值，但响应中已不再包含它。
