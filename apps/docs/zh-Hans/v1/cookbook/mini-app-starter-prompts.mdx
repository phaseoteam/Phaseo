当你想给编程代理一个具体提示，让它构建小型可运行应用，而不是给出模糊的集成计划时，请使用此页面。

<Tip>
这些提示以结果为导向，并明确实现细节，因此在 Cursor、Claude Code、Codex 等工具中效果更好。
</Tip>

## 如何使用这些提示

<Steps>
  <Step title="选择集成方式">
    选择与你希望应用调用 Phaseo 的方式相匹配的提示：

    - 原始 HTTP
    - 一个官方 SDK
    - Vercel AI SDK
    - Agent SDK
  </Step>
  <Step title="替换方括号中的变量">
    将提示粘贴到编程代理之前，请先填写 `[应用创意]`、`[框架]`、`[模型]` 和 `[LANGUAGE]` 等值。
  </Step>
  <Step title="要求验证，而不只是代码">
    保留提示中的验证要求，以便代理报告实际运行了什么、做了哪些假设，以及还需要哪些手动设置。
  </Step>
</Steps>

## 如何让提示效果更好

- 将 `[应用创意]` 替换为一项具体的用户任务，而不是宽泛的产品构想。
- 将 `[模型]` 替换为你希望代理使用的确切模型 ID。
- 说明输出应为自由文本、严格 JSON、聊天内容还是单个生成资产。
- 如果已知，请注明 UI 框架和部署目标。
- 添加一两项重要约束，例如 `仅限欧盟提供商`、`使用流式输出` 或 `所有密钥仅保留在服务器端`。
