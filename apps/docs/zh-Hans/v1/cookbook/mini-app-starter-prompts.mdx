icon: "code"
description: "可复制给编程智能体的提示，用原始 HTTP、SDK 或智能体运行时构建小型 Phaseo 应用。"
---

把下面任一提示粘贴到 Cursor、Claude Code、Codex 或类似的编程智能体中，它就会构建一个可运行的小型 Phaseo 应用，然后报告它运行了什么、哪些内容无法检查。每个提示都写明了集成方式、安全规则和你期望的验证内容。

它们生成的应用只是起点：部署之前请审查代码，尤其是密钥处理和工具验证。

## 使用提示

<Steps>
  <Step title="选择集成方式">
    | 提示 | 调用 Phaseo 的方式 |
    | --- | --- |
    | 原始 HTTP | 针对 `https://api.phaseo.app/v1` 的 `fetch` |
    | TypeScript SDK | `@phaseo/sdk` |
    | Python SDK | `phaseo` |
    | Vercel AI SDK | `@phaseo/ai-sdk-provider` |
    | Agent SDK | `@phaseo/agent-sdk`、`phaseo-agent-sdk`，或对应你所用语言的 Agent SDK |
  </Step>
  <Step title="替换方括号中的变量">
    在把提示粘贴到编程智能体之前，填好 `[APP IDEA]`、`[FRAMEWORK]`、`[MODEL]` 和 `[LANGUAGE]` 等值。
  </Step>
  <Step title="要求验证，而不只是代码">
    保留提示中的验证内容。它们会迫使智能体报告实际运行了什么、做了哪些假设，以及还需要哪些手动设置。
  </Step>
</Steps>

## 让提示效果更好

- 把 `[APP IDEA]` 换成一个具体的用户任务，而不是宽泛的产品构想。
- 把 `[MODEL]` 换成你希望智能体使用的确切模型 ID。
- 说明输出应当是自由文本、严格 JSON、聊天，还是一个生成的资源。
- 如果已经确定，写明 UI 框架和部署目标。
- 添加一两条关键约束，例如 `EU-only providers`、`use streaming` 或 `keep all secrets server-side`。

[TypeScript 和 Python SDK](../sdk-reference/client/overview) 以及 [Agent SDK](../sdk-reference/agent/overview) 参考文档列出了每个包提供的功能，你可以据此检查智能体写出的代码。
