运行一个只用标准库的 Python CLI，一次一个命令地调用 Phaseo 端点。完成后，你会得到可用的 `python quickstart.py <command>`，涵盖健康检查、模型、Responses 和 Chat Completions，另外还有 embeddings、内容审核、图像、OCR、视频和音乐命令，可以复制到 worker 或后端中使用。

该 CLI 仅作示例：它是请求结构的参考，而不是打包好的工具。媒体命令的几个默认模型 ID 已不再提供服务，因此请为这些命令传入 `--model`（见[为媒体命令选择模型](#pick-models-for-the-media-commands)）。

## CLI 能做什么

示例位于 [examples/gateway-python-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-python-quickstart)：只有一个文件 `quickstart.py`，只使用 `urllib`、`json` 和 `argparse`。

| 命令 | 调用 |
| --- | --- |
| `smoke` | `GET /v1/health`、`GET /v1/models`、`GET /v1/providers`，以及一次 `POST /v1/responses` |
| `health`、`models`、`providers` | 对应的 `GET` 路由 |
| `responses --prompt` | `POST /v1/responses` |
| `chat --prompt` | `POST /v1/chat/completions` |
| `embeddings --text` | `POST /v1/embeddings` |
| `moderations --text` | `POST /v1/moderations` |
| `image --prompt` | `POST /v1/images/generations` |
| `ocr --image-url` | `POST /v1/ocr` |
| `video-create`、`video-status`、`video-cancel`、`video-download-url` | `POST /v1/videos`、`GET /v1/videos/{video_id}`、`POST /v1/videos/{video_id}/cancel`、`POST /v1/videos/{video_id}/download_url` |
| `music-create`、`music-status` | `POST /v1/music/generate`、`GET /v1/music/generate/{music_id}` |

遇到 `429`、`5xx` 和网络错误时，每个请求会重试两次，分别等待 1 秒和 2 秒，并在 45 秒后超时。调用结果不是 `2xx` 时，每个命令都会以 `1` 退出，因此可以在脚本中使用。

## 运行

你需要 Python 3 和一个 Phaseo API 密钥。

<Steps>
<Step title="创建 .env.local">

脚本会从你运行它的文件夹读取 `.env.local`。示例中没有 `.env.example`，所以请自己创建该文件：

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# Optional
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My Python CLI
PHASEO_HTTP_REFERER=https://myapp.example
```

shell 中已经设置的变量优先于该文件。没有设置 `PHASEO_MODEL` 时，文本命令使用 `openai/gpt-5.6-sol`。

</Step>
<Step title="运行冒烟检查">

```bash
cd examples/gateway-python-quickstart
python quickstart.py smoke
```

`smoke` 还会发送一个简短的 Responses 请求，因此会消耗少量额度。

</Step>
<Step title="发送一个请求">

```bash
python quickstart.py responses --prompt "Return exactly: integration_ok"
python quickstart.py --help
```

</Step>
</Steps>

## 检查是否成功

- `smoke` 为每个块打印 `HTTP 200`，并以 `0` 退出。
- `responses` 命令的输出包含 `integration_ok`。
- `--help` 列出所有命令，不会发出请求。
- 没有密钥时，脚本打印 `Missing PHASEO_API_KEY` 并以 `1` 退出。
- 这些请求会出现在**设置 → 用量 → 日志**中。

## 为媒体命令选择模型

`quickstart.py` 中的以下默认值已停用或没有可用的提供商。请用 `--model` 传入当前模型，可以从[模型页面](https://phaseo.app/models)或 `python quickstart.py models` 中挑选：

| 命令 | 示例中的默认值 | 状态 |
| --- | --- | --- |
| `moderations` | `openai/omni-moderation-latest` | 不是目录中的 ID；请使用 `openai/omni-moderation` |
| `ocr` | `mistral/mistral-ocr` | 已停用；可尝试 `mistral/ocr-4.1` |
| `video-create` | `openai/sora-2` | 已停用 |
| `music-create` | `suno/suno-v4` | 没有可用的提供商 |

`embeddings`（`google/gemini-embedding-2`）和 `image`（`openai/gpt-image-2`）的默认值仍在提供服务。视频和音乐任务是异步的：保存返回的 ID 并轮询状态命令；[异步视频和批处理](../guides/async-video-and-batch)介绍了任务的生命周期。

把文件精简为你的服务需要的命令，保留共用的 `gateway_request()` 辅助函数；需要类型化请求时，改用 [Python SDK](../sdk-reference/client/overview)。
