发送 `"model": "phaseo/free"`，Phaseo 会在一个支持该请求的可用免费模型上运行它，不消耗额度。完成后，你会用自己选择的语言跑通一个请求，并知道是哪个模型回答的。

这种请求结构可以直接用于原型、演示和低风险流量的生产环境。免费模型不保证延迟、输出风格或固定的提供商。

## 发送请求

<Steps>
<Step title="设置密钥">

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="发送一个请求">

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phaseo/free",
    "input": "Summarize why provider-aware free routing helps prototypes.",
    "temperature": 0.2
  }'
```

```go Go
package main

import (
  "context"
  "fmt"
  "os"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New(os.Getenv("PHASEO_API_KEY"), "https://api.phaseo.app/v1")

  temperature := 0.2
  response, err := client.GenerateResponse(context.Background(), phaseo.ResponsesRequest{
    Model:       "phaseo/free",
    Input:       "Summarize why provider-aware free routing helps prototypes.",
    Temperature: &temperature,
  })
  if err != nil {
    panic(err)
  }

  fmt.Printf("%+v\n", response)
}
```

## 如何挑选免费模型

1. 你的请求发送到共享的 `phaseo/free` 别名。
2. Phaseo 保留能处理该请求的免费模型（端点、参数、工具）。
3. 它把请求发送给其中一个。

默认情况下，免费模型共享每位用户每个 UTC 日 1,500 次请求的额度。超过之后，请求会返回 `429` 和错误码 `phaseo_free_model_limit_exceeded`，直到 UTC 00:00；参见 [Gateway 限制](../api-reference/limits#gateway-limits)。

## 离开免费路由

如果没有免费模型支持你需要的功能（例如工具或 JSON Schema），请换成某个具体的付费模型，而不是重试同一个请求。当你需要可预测的延迟、输出风格或提供商选择时，改用固定模型，并把共享设置放进[预设](../guides/presets)，让每个服务都发送相同的请求。[路由与回退](../guides/routing-and-fallbacks)说明了付费请求如何选择提供商，[API 错误](../api-reference/errors)列出了错误码。
