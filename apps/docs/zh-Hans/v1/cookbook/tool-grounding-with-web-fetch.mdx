为模型提供 `phaseo:web_fetch` 和一个你已知道的 URL，Phaseo 会抓取该页面、按大小上限截断，并在模型提取、总结或分类之前把文本交还给它。完成后，你会得到一个读取单个页面并从中返回字段的请求，并能在日志中确认它实际读取了哪个页面。

配合示例中的域名限制，该请求可直接用于生产环境。抓取到的页面是不可信的输入：模型可能会在其中看到指令，因此请验证它返回的内容。如果你不知道 URL，请改用[网页搜索](../guides/server-tools/web-search)。

## 发送有依据的请求

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/responses \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-6-astra",
    "input": "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
    "tools": [
      {
        "type": "phaseo:web_fetch",
        "parameters": {
          "allowed_domains": ["phaseo.app"],
          "max_chars": 8000,
          "max_uses": 1
        }
      }
    ],
    "tool_choice": "phaseo:web_fetch"
  }'
```

```typescript TypeScript
import Phaseo from "@phaseo/sdk";

const client = new Phaseo({ apiKey: process.env.PHASEO_API_KEY! });

const response = await client.generateResponse({
  model: "openai/gpt-6-astra",
  input:
    "Fetch https://phaseo.app/docs/v1/guides/tool-calling and list the section headings. Use only the fetched text.",
  tools: [
    {
      type: "phaseo:web_fetch",
      parameters: {
        allowed_domains: ["phaseo.app"],
        max_chars: 8000,
        max_uses: 1,
      },
    },
  ],
  tool_choice: "phaseo:web_fetch",
});

console.log(JSON.stringify(response.output, null, 2));
console.log(response.usage?.server_tool_use);
```
</CodeGroup>

在提示中明确说明抓取之后要做什么：提取这些字段、总结这一节、对文档分类，或核实一个说法。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `allowed_domains` | 无 | 只从这些域名抓取。模型可以缩小这个列表，但永远不能扩大。 |
| `max_chars` | `12000` | 返回的页面文本字符数，最多 `100000`。只需标题或摘要时调低，提取字段时调高。 |
| `max_uses` | `10` | 每个请求的抓取调用次数，最多 `100`。 |

[网页抓取指南](../guides/server-tools/web-fetch#parameters)列出了其余参数，包括 `blocked_domains` 和各种引擎。

## 检查它读取了什么

工具结果（请求日志中会显示）准确说明了模型依据的是哪个页面：

```json
{
  "url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "final_url": "https://phaseo.app/docs/v1/guides/tool-calling",
  "status": 200,
  "content_type": "text/html",
  "title": "Tool Calling",
  "truncated": false,
  "returned_chars": 8000
}
```

在确信模型看到了完整页面之前，先检查重定向之后的 `final_url` 和 `truncated`。每次抓取会让 `usage.server_tool_use.web_fetch_requests` 加 1。

## 了解限制

使用默认的 `direct` 引擎时，Phaseo 会自行抓取页面，并把 HTML 简化为纯文本。它会拒绝 `localhost` 和私有地址，最多跟随 5 次重定向，并对照你的域名列表检查每次重定向；重定向到列表之外时，会向模型返回 `redirect_blocked_by_domain_policy`。

网页抓取适用于 HTML 页面、纯文本，以及较小的 JSON 或 XML 响应。它不适合二进制文件、抓取大量页面，或检查页面在 JavaScript 下如何渲染；这些情况请使用浏览器工作流。如果页面非常大，请缩小提取任务的范围，而不是提高 `max_chars`。

先从一个预设或端点开始，在日志中查看抓取详情和截断情况；如果抓取到的文本范围太宽，先收紧提示，再扩大使用范围。
