运行一个 Python 智能体：它用一个本地工具查询信息，并以严格 JSON 返回答案。完成后，你会得到一个脚本，其 `result.output` 是一个经过验证、包含 `summary` 和 `recommendation` 的 `PolicySummary` 对象，而不是自由文本。

该工具返回固定的示例数据，因此该脚本仅作演示；请将它替换为你自己的查询。它适合自行负责编排、工具集小而确定的 Python worker。

## 构建

<Steps>
<Step title="安装">

<CodeGroup>
```bash pip
pip install phaseo-agent-sdk
```

```bash uv
uv add phaseo-agent-sdk
```
</CodeGroup>

`phaseo-agent-sdk` 会一并安装 `phaseo` 客户端和 Pydantic。

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```

</Step>
<Step title="编写智能体">

```python extract.py
import json
import os

from pydantic import BaseModel, ConfigDict

from phaseo_agent import AgentTool, create_agent, create_gateway_agent_client, define_tool

POLICY_SLUGS = {"presets", "routing", "guardrails"}


class PolicySummary(BaseModel):
    model_config = ConfigDict(extra="forbid")
    summary: str
    recommendation: str


def check_lookup_input(value):
    # 参数由模型生成：拒绝任何不是已知 slug 的内容。
    if not isinstance(value, dict) or set(value) != {"slug"} or value["slug"] not in POLICY_SLUGS:
        raise ValueError(f"slug must be one of {sorted(POLICY_SLUGS)}")
    return value


lookup_policy = define_tool(
    AgentTool(
        id="lookup-policy",
        description="Look up one internal policy by slug.",
        parameters={
            "type": "object",
            "properties": {"slug": {"type": "string", "enum": sorted(POLICY_SLUGS)}},
            "required": ["slug"],
            "additionalProperties": False,
        },
        input_schema=check_lookup_input,
        execute=lambda input, ctx: {
            "slug": input["slug"],
            "summary": "Presets centralize routing, prompts, and caching defaults.",
        },
    )
)

agent = create_agent(
    {
        "id": "policy-extractor",
        "model": "openai/gpt-6-astra",
        "instructions": "Use tools when needed and return JSON with summary and recommendation.",
        "tools": [lookup_policy],
        "max_steps": 4,
        "parse_output": json.loads,
        "output_schema": PolicySummary,
    }
)

# Python 客户端不会自行读取 PHASEO_API_KEY：需要显式传入。
client = create_gateway_agent_client(
    client_options={"api_key": os.environ["PHASEO_API_KEY"]},
    response_format={
        "type": "json_schema",
        "name": "policy_summary",
        "schema": {
            "type": "object",
            "properties": {
                "summary": {"type": "string"},
                "recommendation": {"type": "string"},
            },
            "required": ["summary", "recommendation"],
            "additionalProperties": False,
        },
    },
    plugins=[{"id": "response-healing"}],
)

result = agent.run(input="Look up our presets policy and recommend when to use it.", client=client)

print(result.run.status)
print(result.output)
```

| 部分 | 作用 |
| --- | --- |
| `parameters` | 模型看到的工具参数 JSON Schema |
| `input_schema` | 在 `execute` 运行之前检查参数；错误的调用会使运行失败 |
| `response_format` | 要求 Gateway 在每个轮次都使用此 JSON Schema |
| `parse_output` 和 `output_schema` | 解析最终文本，并将其验证为 `PolicySummary` |

</Step>
<Step title="运行">

```bash
python extract.py
```

</Step>
</Steps>

## 检查是否成功

- 脚本先打印 `completed`，然后打印两个字段都已填写的 `PolicySummary`。
- 在 **设置 → 使用情况 → 日志** 中，第一个模型轮次会显示带有 `{"slug": "presets"}` 的 `lookup-policy` 调用。
- 与该 Pydantic 模型不匹配的输出会以 `Invalid agent output` 失败，而不是返回只填了一半的对象。

如需不使用工具的一次性结构化输出，请[直接调用 Python SDK](./sdk-python-presets-and-json)。[Python Agent SDK 参考](../sdk-reference/agent/usage)介绍了状态、审批和流式传输。
