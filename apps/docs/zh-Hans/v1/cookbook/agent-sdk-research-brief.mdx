构建一个 TypeScript 智能体：它在回答之前通过 Phaseo 搜索网络，并以带有来源的严格 JSON 返回研究简报。完成后，你会得到一个脚本，它会为你给出的任何主题打印一个经过验证的 `{ topic, summary, sources }` 对象。

对于一次性研究，该脚本可直接用于生产环境。搜索结果是不可信的网页内容：下面的 schema 检查会拦截格式错误的输出，但在据此采取行动之前，请先审查来源。打包好的版本位于 `packages/sdk/agent-sdk-ts/examples/research-brief-agent.ts`。

<Step title="编写智能体">

```ts research-agent.ts
import { z } from "zod";
import { createAgent, createGatewayAgentClient } from "@phaseo/agent-sdk";

// 足够小，可以在一行日志中读完。
const ResearchBrief = z
  .object({
    topic: z.string(),
    summary: z.string().min(1),
    sources: z.array(z.object({ title: z.string(), url: z.string().url() }).strict()).min(1),
  })
  .strict();
type ResearchBrief = z.infer<typeof ResearchBrief>;

const researchBriefAgent = createAgent<string, ResearchBrief>({
  id: "research-brief-agent",
  model: "openai/gpt-6-astra",
  instructions:
    "Research the user's topic with web search and return a concise JSON brief with cited sources.",
  maxSteps: 4,
  parseOutput: (text) => JSON.parse(text),
  outputSchema: ResearchBrief,
});

const client = createGatewayAgentClient({
  clientOptions: { apiKey: process.env.PHASEO_API_KEY! },
  // Gateway 要求模型遵循的 JSON Schema。
  responseFormat: {
    type: "json_schema",
    name: "research_brief",
    schema: {
      type: "object",
      properties: {
        topic: { type: "string" },
        summary: { type: "string" },
        sources: {
          type: "array",
          items: {
            type: "object",
            properties: { title: { type: "string" }, url: { type: "string" } },
            required: ["title", "url"],
            additionalProperties: false,
          },
          minItems: 1,
        },
      },
      required: ["topic", "summary", "sources"],
      additionalProperties: false,
    },
  },
  // 修复接近有效的 JSON。
  plugins: [{ id: "response-healing" }],
  // 搜索由 Phaseo 执行；查询由模型编写。
  gatewayTools: [{ type: "phaseo:web_search", parameters: { max_results: 5 } }],
  // 回答之前始终先搜索。
  toolChoice: "phaseo:web_search",
  webSearchOptions: { search_context_size: "high" },
});

const result = await researchBriefAgent.run({
  input: "Summarize the latest browser automation support patterns for coding agents.",
  client,
  onEvent(event) {
    console.log(event.type, event.runId);
  },
});

console.log(result.output);
```

| 客户端选项 | 作用 |
| --- | --- |
| `responseFormat` | 明确指定输出 schema |
| `plugins` | 针对接近有效的 JSON 的[响应修复](./response-healing-for-structured-json) |
| `gatewayTools` | 添加 `phaseo:web_search`；[网络搜索指南](../guides/server-tools/web-search)列出了它的参数 |
| `toolChoice` | 为必须始终有据可依的工作流强制执行搜索 |
| `webSearchOptions` | 适用于会调整结果规模的搜索引擎的搜索设置 |

</Step>

## 检查是否成功

脚本会打印一份至少包含一个来源 URL 的简报。然后在 **设置 → 使用情况 → 日志** 中打开该请求并检查：

- **网络搜索可观测性** 显示托管搜索、结果和引用。
- 只有当 JSON 需要修复时，插件记录才会显示 `response-healing` 为 `applied`。
- 响应符合 schema；如果不符合，运行会以 `AgentSchemaValidationError` 失败。

[调试网络搜索](./web-search-debugging)介绍了没有执行搜索的情况。

## 何时改用其他方案

这种模式适合模型需要自行查找依据、调用方需要类型化 JSON 的一次性研究。如果你已经知道 URL，请使用 [`phaseo:web_fetch`](./tool-grounding-with-web-fetch)；如果任务更依赖你自己的数据而不是网络，请使用[本地工具智能体](./agent-sdk-durable-loop)；如果约定足够宽松，使用 schema 带来的工作量超过它节省的工作量，请使用纯文本输出。
