## 示例项目

- GitHub: [examples/gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart)
- 仓库本地路径： `examples/gateway-node-quickstart`

## 此应用的功能

- 调用 `GET /v1/health`
- 调用 `GET /v1/models`
- 测试生成路由，例如 `POST /v1/responses`
- 为冒烟测试、脚本和后端检查提供原始 HTTP 参考

## 适合使用此示例的场景

以下情况可以从此示例开始：

- 你想直接调试原始 API 调用
- 你暂时不需要 SDK 抽象层
- 你正在构建脚本、worker 或 CLI，而不是 Web UI

## 前置条件

- 内置支持`fetch` support
- Phaseo API 密钥

## 运行示例

```bash
cd examples/gateway-node-quickstart
cp .env.example .env.local
```

设置：

- `PHASEO_API_KEY`

然后运行以下任一命令：

```bash
npm run smoke
```

或：

```bash
npm run start
```

## 检查结果

- 冒烟模式会确认 API 可以访问。
- 模型发现至少返回一个模型。
- 完整运行会打印一次成功的生成响应。
- 身份验证失败和非 200 响应会在终端中显示清晰错误。

## 代码检查要点

- 脚本如何加载 `.env.local`
- 如何添加授权标头
- 如何明确构建每个请求
- 如何显示非 200 响应，而不是将其忽略

## 根据需要修改示例

- 精简脚本，只保留服务实际需要的路由
- 多个脚本要复用请求代码时，将其移入一个辅助函数
- 如果原始 HTTP 代码变得重复，可在之后改用 TypeScript SDK
