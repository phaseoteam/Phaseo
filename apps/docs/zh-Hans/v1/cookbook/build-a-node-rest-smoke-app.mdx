运行一个零依赖的 Node.js 脚本，用普通的 `fetch` 调用 Phaseo，让你看到每个请求和响应。完成后，你会得到一个可以在部署前运行的冒烟测试：它检查 API 是否可达、列出模型，并向 Responses、Chat Completions 和 Embeddings 各发送一个请求。

该脚本仅作示例：它会打印每个 HTTP 状态，但始终以 `0` 退出。在 CI 中依赖它之前，请先加上[用作部署检查](#use-it-as-a-deploy-check)中的退出码检查。

## 脚本会调用什么

示例位于 [examples/gateway-node-quickstart](https://github.com/phaseoteam/Phaseo/tree/main/examples/gateway-node-quickstart)：只有一个文件 `index.mjs`，没有任何依赖。

| 模式 | 调用 | 是否消耗额度 |
| --- | --- | --- |
| `npm run smoke` | `GET /v1/health`、`GET /v1/models` | 否 |
| `npm run start` | 先调用以上两个，再调用 `POST /v1/responses`、`POST /v1/chat/completions`、`POST /v1/embeddings` | 是 |

文本调用会把 `Return exactly: integration_ok` 发送给 `PHASEO_MODEL`（默认 `openai/gpt-5.6-sol`）。Embeddings 调用使用 `google/gemini-embedding-2`。

## 运行

你需要 Node.js 18 或更高版本（用于内置的 `fetch`），以及一个 Phaseo API 密钥。

<Steps>
<Step title="创建 .env.local">

脚本会从你运行它的文件夹加载 `.env.local`，不需要任何包。示例中没有 `.env.example`，所以请自己创建该文件：

```bash .env.local
PHASEO_API_KEY=phaseo_v1_sk_...
# Optional
PHASEO_MODEL=openai/gpt-6-astra
PHASEO_BASE_URL=https://api.phaseo.app/v1
PHASEO_APP_TITLE=My smoke test
PHASEO_HTTP_REFERER=https://myapp.example
```

shell 中已经设置的变量优先于该文件。

</Step>
<Step title="运行冒烟模式">

```bash
cd examples/gateway-node-quickstart
npm run smoke
```

</Step>
<Step title="运行完整模式">

```bash
npm run start
```

</Step>
</Steps>

## 检查是否成功

每次调用都会打印类似这样的块：

```text
=== Health ===
HTTP 200
{ ... }
```

- `Health` 和 `Models` 显示 `HTTP 200`，并且 `Models` 至少列出一个模型。
- 在完整运行中，Responses 和 Chat Completions 块包含 `integration_ok`。
- 使用错误的密钥时，生成相关的块会显示 `HTTP 401` 和错误正文，而不是把错误吞掉。
- 这些请求会出现在**设置 → 用量 → 日志**中。

## 用作部署检查

`request()` 返回 `{ status, ok, payload }`，但没有任何地方检查 `ok`。在 `print()` 顶部加一行，让脚本在任一调用失败时以 `1` 退出：

```js index.mjs
function print(title, result) {
  if (!result.ok) process.exitCode = 1;
  console.log(`\n=== ${title} ===`);
  // ...rest unchanged
}
```

把脚本精简为你的服务实际使用的路由；如果你不想手动构建请求体，可以改用 [TypeScript SDK](../sdk-reference/client/overview)。
