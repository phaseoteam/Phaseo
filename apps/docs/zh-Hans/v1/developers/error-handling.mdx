即使是最好的模型也偶尔会失败。本指南介绍 Gateway 如何报告错误，以及你应如何处理。

---

## 错误类别

错误可能来自 Gateway、提供商或你的请求。错误响应会包含帮助你诊断问题的元数据。

| 状态范围 | 含义                                  | 常见处理方式                        |
| ----------- | ---------------------------------------- | ------------------------------------- |
| 400-499     | 请求无效或身份验证问题 | 修正请求内容或凭据。       |
| 429         | 已触发速率限制                             | 等待后重试，并遵守限制。 |
| 500-599     | Gateway 或提供商故障              | 等待后重试，并记录详细信息。    |

---

## 重试行为

- 使用带随机抖动的指数退避。
- 如果存在 `Retry-After` 请求头，请遵循其指示。
- 设置最大重试次数，避免无限重试。

---

## 提供商错误

错误有时来自上游提供商。我们会尝试在错误响应中说明。如果问题持续出现，路由器应尽可能避开该提供商。
