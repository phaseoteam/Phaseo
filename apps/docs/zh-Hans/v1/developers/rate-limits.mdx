本指南已移至[速率限制](../api-reference/limits.mdx)。请在该参考页查看当前 Gateway 配额、提供商限制、`Retry-After` 和有界重试规则。

Gateway 或提供商配额都可能导致请求返回 `429`。BYOK 还受你的提供商账户配额限制。路由与回退可以减少失败，但无法保证每个请求成功。

## 监控用量

在请求日志中检查 `429` 错误和重试。API 已支持[查询工作区分析数据](../api-reference/endpoint/analytics-get.mdx)和[导出为 CSV](../api-reference/endpoint/analytics-export.mdx)。两项操作均需要具有 `analytics:read` 权限的管理 API 密钥。
