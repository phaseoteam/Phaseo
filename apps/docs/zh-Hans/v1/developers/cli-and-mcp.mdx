# CLI 与 MCP

你可以在终端中使用 Phaseo CLI，也可以通过 MCP 连接 AI 客户端。两者都使用 Phaseo OAuth，但用途不同。

| 接口 | 适用场景 | 访问权限 |
| --- | --- | --- |
| Phaseo CLI | 终端工作流、CI、管理和自动化 | 根据授权范围和工作区角色限制读取与写入权限 |
| Phaseo MCP | 在 Codex、Claude、ChatGPT 等 MCP 客户端中访问 Phaseo 实时数据，并可选择管理账户 | 已验证身份；除非以账户管理方式连接，否则仅可读取 |
| Docs MCP | 在编写代码时查阅最新 Phaseo 文档 | 仅文档，只读 |
| Phaseo 插件 | 在 Claude Code 或 Codex 中一次性安装 Phaseo MCP、Docs MCP 和 Phaseo 技能 | 与各 MCP 服务器相同 |

## Phaseo CLI

需要创建或修改 Phaseo 资源、编写工作流脚本或从 shell 检查账户数据时，请使用 CLI。

### 安装并登录

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

交互式终端默认使用浏览器 OAuth。对于 SSH、CI 和无头环境，请使用设备授权：

```bash
phaseo login --device-code
```

### 常见工作流

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys create --name "Local development"
phaseo logs list --since 1h --status error --json
```

其他工具或脚本需要结构化输出时，请使用 `--json`。只有明确创建或显示密钥的命令才会返回密钥值。

## Phaseo MCP

如果你希望 AI 客户端根据模型、价格、提供商、用量和工作区的实时数据回答问题，请连接 Phaseo MCP 服务器。

### 服务器 URL

`https://mcp.phaseo.app/mcp`

### 从 Codex 连接

```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
```

登录命令会打开 Phaseo OAuth。选择工作区、批准请求的只读权限，然后确认连接：

```bash
codex mcp list
```

对于其他 MCP 客户端，请将相同 URL 添加为远程 Streamable HTTP 服务器。客户端必须支持 OAuth 发现、S256 PKCE 授权码流程和 MCP `resource` 参数。

### MCP 可读取的数据

- 模型、提供商、基准排名、价格和成本估算
- 积分、活动、分析、请求日志和生成元数据

这些工具仅可读取，绝不会返回提示词、响应或密钥值。

### 管理账户（可选）

如需让智能体更改你的 Phaseo 工作区，请改用管理 URL 连接：

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

登录时，授权同意页面会逐项列出此连接请求的每项权限，例如管理 API 密钥或删除预算，并标记为**读取**、**写入**或**删除**。取消勾选你不想授予的权限。智能体只会获得你所允许权限对应的工具；每次更改时，Phaseo 仍会检查你在工作区中的角色，因此既不是所有者也不是管理员的成员无法通过这种方式更改仅限管理员的设置。

如果你已通过只读 URL 连接，请将客户端切换到管理 URL 并重新登录。如需恢复只读访问，请使用普通 URL 重新连接，或在**设置 → 已连接应用**中撤销该应用。

| 范围 | 工具 | 权限 |
| --- | --- | --- |
| API 密钥 | `api_keys_list`, `api_key_get`, `api_key_create`, `api_key_update`, `api_key_rotate`, `api_key_delete` | `keys:read`, `keys:write`, `keys:delete` |
| 预算 | `budgets_list`, `budget_create`, `budget_update`, `budget_delete` | `budgets:read`, `budgets:write`, `budgets:delete` |
| 支出规则 | `spend_rules_list`, `spend_rule_create`, `spend_rule_update`, `spend_rule_delete` | `spend_rules:read`, `spend_rules:write`, `spend_rules:delete` |
| 提供商密钥（BYOK） | `provider_keys_list`, `provider_key_create`, `provider_key_update`, `provider_key_delete` | `provider_credentials:read`, `provider_credentials:write`, `provider_credentials:delete` |
| 护栏 | `guardrails_list`, `guardrail_get`, `guardrail_create`, `guardrail_update`, `guardrail_delete`, `guardrail_keys_set` | `guardrails:read`, `guardrails:write`, `guardrails:delete` |
| 预设 | `presets_list`, `preset_get`, `preset_create`, `preset_update`, `preset_version_publish` | `presets:read`, `presets:write` |
| 设置 | `settings_get`, `settings_update` (路由模式、隐私和 ZDR、日志记录、提供商限制) | `settings:read`, `settings:write` |
| Webhook | `webhooks_list`, `webhook_create`, `webhook_delete` | `settings:read`, `settings:write` |
| 可观测性目标 | `observability_destinations_list`, `observability_destination_create`, `observability_destination_delete` | `settings:read`, `settings:write` |

会更改或删除内容的工具都带有相应标记，因此支持此功能的 MCP 客户端会在每次调用前请你确认。新的 API 密钥或 webhook 签名密钥只会在工具结果中显示一次，之后无法再次显示。已保存的提供商密钥和目标凭证绝不会返回。

MCP 不提供账单、付款、工作区、成员、管理密钥或 OAuth 应用相关的工具。如需执行这些操作，请使用控制台、CLI 或管理 API。

## Docs MCP

Docs MCP 是用于搜索和阅读 Phaseo 文档的独立端点，不会访问你的账户或工作区。

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

当编程助手需要最新 API 示例、集成指南或功能文档时，请使用它。

## Phaseo 插件

Phaseo 插件打包了 Phaseo MCP、Docs MCP，以及用于集成、迁移、模型选择、用量监控、SDK 和 CLI 的 Phaseo 智能体技能。只需安装一次，无需逐一连接。

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

运行 `/mcp` 并登录 `plugin:phaseo:phaseo`，即可连接你的 Phaseo 账户。当请求与技能匹配时会自动加载，你也可以直接运行某个技能，例如 `/phaseo:phaseo-gateway`。

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

最后一条命令会为 Phaseo MCP 打开 Phaseo OAuth。当请求与技能匹配时会自动加载。

## 选择合适的接口

- 使用 **CLI** 创建密钥、修改设置、管理工作区或自动执行管理工作流。
- 使用 **Phaseo MCP** 为 AI 客户端安全地开放 Phaseo 实时数据。
- 使用 **Docs MCP** 为编程助手提供最新 Phaseo 文档，同时不授予账户访问权限。
- 使用 **Phaseo 插件**，在 Claude Code 或 Codex 中一次性设置两个 MCP 服务器和 Phaseo 技能。
