使用 CLI 从终端或脚本更改 Phaseo，或把 AI 客户端连接到 Phaseo MCP 服务器，为它提供 Phaseo 实时数据。两者都通过 Phaseo OAuth 登录。

| 接口 | 用途 | 访问权限 |
| --- | --- | --- |
| [Phaseo CLI](#phaseo-cli) | 从 shell 或 CI 创建密钥、更改设置、管理工作区，以及自动化管理工作 | 读取和写入，受你的作用域和工作区角色限制 |
| [Phaseo MCP](#phaseo-mcp) | 为 Codex、Claude、ChatGPT 等 MCP 客户端提供 Phaseo 实时数据，并可选择让它们管理你的账户 | 只读，除非你以账户管理方式连接 |
| [Docs MCP](#docs-mcp) | 为编程助手提供最新的 Phaseo 文档 | 仅文档，无账户访问权限 |
| [Phaseo 插件](#phaseo-plugin) | 在 Claude Code 或 Codex 中一次性安装两个 MCP 服务器和 Phaseo 技能 | 与各 MCP 服务器相同 |

## Phaseo CLI

### 安装并登录

```bash
npm install -g @phaseo/cli
phaseo login
phaseo whoami
```

交互式终端默认使用浏览器 OAuth。对于 SSH、CI 和无头环境，请使用设备授权：

```bash
phaseo login --device-code
```

### 常用工作流

```bash
phaseo models list --limit 20
phaseo pricing models
phaseo credits get
phaseo workspaces list
phaseo keys list
phaseo logs list --since 1h --status error --json
```

当其他工具或脚本需要结构化输出时，使用 `--json`。只有明确用于创建或显示密钥值的命令才会显示这些值。

## Phaseo MCP

服务器 URL 是 `https://mcp.phaseo.app/mcp`。连接到它的 AI 客户端可以用实时的模型、价格、提供商、用量和工作区数据回答问题。

### 连接你的客户端

一键安装：[添加到 Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=phaseo&config=eyJ1cmwiOiJodHRwczovL21jcC5waGFzZW8uYXBwL21jcCJ9) · [添加到 VS Code](vscode:mcp/install?%7B%22name%22%3A%22phaseo%22%2C%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fmcp.phaseo.app%2Fmcp%22%7D)。当客户端要求你登录时，浏览器会打开 Phaseo OAuth。选择一个工作区，并批准所请求的读取权限范围。

<Tabs>

```bash
claude mcp add --transport http phaseo https://mcp.phaseo.app/mcp
```

然后运行 `/mcp`，选择 `phaseo`，再选择 **Authenticate**。加上 `--scope user` 可在所有项目中使用。
</Tab>
<Tab title="Codex">
```bash
codex mcp add phaseo --url https://mcp.phaseo.app/mcp
codex mcp login phaseo
codex mcp list
```

登录命令会打开 Phaseo OAuth。`codex mcp list` 可确认连接。
</Tab>

使用上方的 **添加到 Cursor**，或将服务器添加到 `~/.cursor/mcp.json`，然后在 Cursor 的 MCP 设置中登录。

对于其他 MCP 客户端，把同一个 URL 添加为远程 Streamable HTTP 服务器。客户端必须支持 OAuth 发现、使用 S256 PKCE 的授权码流程，以及 MCP `resource` 参数。

### 使用 Phaseo CLI 的登录

如果你已经在使用 Phaseo CLI，本地智能体可以通过它访问 MCP，无需再次登录：

```bash
phaseo login
claude mcp add --scope user phaseo -- phaseo mcp
# or, for Codex
codex mcp add phaseo -- phaseo mcp
```

`phaseo mcp` 使用你的 CLI 登录，通过 stdio 运行 MCP。它会把该登录换成一个仅对 MCP 有效、有效期 15 分钟的令牌；该令牌的权限绝不会超过你的登录，也绝不允许付费的模型调用。除非加上 `--manage`，否则它是只读的。`phaseo setup codex` 会自动把它添加到 Codex 的 Phaseo 配置文件中。以这种方式连接的智能体读取日志、活动或分析数据时，结果还会给出获取完整数据的对应 CLI 命令。

### MCP 可以读取什么

只读工具涵盖模型、提供商、基准排名、价格和成本估算，以及额度、活动、分析、请求日志和生成元数据。它们从不返回提示、响应或密钥值。

### 管理你的账户（可选）

要让智能体更改你的 Phaseo 工作区，请改用管理 URL 连接：

`https://mcp.phaseo.app/mcp?access=manage`

```bash
codex mcp add phaseo --url "https://mcp.phaseo.app/mcp?access=manage"
codex mcp login phaseo
```

登录时，授权同意页面会列出该连接请求的每项权限（例如管理 API 密钥或删除预算），并标记为**读取**、**写入**或**删除**。取消勾选你不想授予的权限。智能体只会获得你允许的权限所对应的工具，并且 Phaseo 在每次更改时仍会检查你的工作区角色，因此非所有者或管理员的成员无法通过这种方式更改仅限管理员的设置。

如果你已经用只读 URL 连接过，请把客户端切换到管理 URL 并重新登录。要恢复为只读访问，请用普通 URL 重新连接，或在**设置 → 已连接应用**中撤销该应用。

管理连接可以读取下方所有内容，但只能更改 API 密钥和工作区设置。预算、支出规则、提供商密钥、护栏、预设、Webhook 和可观测性目标会影响支出或请求内容的去向，因此请在控制台中或使用管理密钥更改它们。

| 范围 | 读取 | 更改 |
| --- | --- | --- |
| API 密钥 | `api_keys_list`, `api_key_get` | 使用 `phaseo mcp --manage` 时：`api_key_create`、`api_key_update`、`api_key_rotate`、`api_key_delete`。其他客户端只能重命名（`api_key_update`）和删除（`api_key_delete`） |
| 设置 | `settings_get` | `settings_update`，用于保持或收紧隐私、日志记录和提供商限制的更改 |
| 预算 | `budgets_list` | 在控制台中更改 |
| 支出规则 | `spend_rules_list` | 在控制台中更改 |
| 提供商密钥（BYOK） | `provider_keys_list` | 在控制台中更改 |
| 护栏 | `guardrails_list`, `guardrail_get` | 在控制台中更改 |
| 预设 | `presets_list`, `preset_get` | 在控制台中更改 |
| Webhook | `webhooks_list` | 在控制台中更改 |
| 可观测性目标 | `observability_destinations_list` | 在控制台中更改 |

会更改或删除内容的工具都有相应标记，因此支持此功能的 MCP 客户端会在每次调用前征求你的同意。新的 API 密钥只会在工具结果中显示一次，之后无法再次显示。已存储的提供商密钥和目标凭据永远不会被返回。

MCP 没有账单、支付、工作区、成员、管理密钥或 OAuth 应用相关的工具。这些操作请使用仪表板、CLI 或管理 API。

## Docs MCP

Docs MCP 是一个单独的端点，用于搜索和阅读 Phaseo 文档。它不会访问你的账户或工作区。

```bash
codex mcp add phaseoDocs --url https://phaseo.app/docs/mcp
```

## Phaseo 插件

Phaseo 插件打包了 Phaseo MCP、Docs MCP，以及用于集成、迁移、模型选择、用量监控、SDK 和 CLI 的 Phaseo 智能体技能。安装一次即可，无需逐个自行连接。

### Claude Code

```bash
claude plugin marketplace add phaseoteam/skills
claude plugin install phaseo@phaseo
```

运行 `/mcp` 并登录 `plugin:phaseo:phaseo`，以连接你的 Phaseo 账户。技能会在请求与其匹配时加载，你也可以直接运行某个技能，例如 `/phaseo:phaseo-gateway`。

### Codex

```bash
codex plugin marketplace add phaseoteam/skills
codex plugin add phaseo@phaseo
codex mcp login phaseo
```

最后一条命令会为 Phaseo MCP 打开 Phaseo OAuth。技能会在请求与其匹配时加载。
