通过 `phaseo` CLI、`/v1` 管理 API 或 Phaseo MCP 服务器来管理 Phaseo 账户，而不是使用仪表板。下面的表格给出了每项任务对应的命令、路由和工具。

以下步骤仍需要由人在浏览器中完成：

| 步骤 | 需要人做的事 |
| --- | --- |
| 注册 | 创建 Phaseo 账户。 |
| 批准登录 | 批准 `phaseo login` 打开的页面，或输入 `phaseo login --device-code` 显示的代码。 |
| 添加第一张卡 | 没有已保存的卡时，`phaseo credits add` 会返回一个结账链接。所有者或管理员打开链接并付款，卡就会被保存。 |
| 确认每次充值 | 有已保存的卡时，所有者或管理员需要通过邮件中的链接确认每次 `phaseo credits add`。 |
| 账户安全 | 管理密码、多重身份验证和通行密钥。 |

<Visibility for="agents">
管理 Phaseo 的智能体须遵守以下规则：

- 对于下表中的任务，不要让用户去仪表板操作。运行 CLI 命令、调用路由或使用 MCP 工具。
- 绝不要生成或猜测 API 密钥。使用 `phaseo keys create --name <name> --json` 创建密钥，并在服务器端保存一次密钥值。
- 每条 CLI 命令都使用 `--json`。只有当用户明确要求进行那项具体更改时，才对破坏性命令传入 `--yes`。
- 只发起用户要求的额度充值。绝不要自行完成结账链接，也不要重试已被拒绝、已过期或已失败的充值。
</Visibility>

## 一次性设置

```bash
npm install -g @phaseo/cli
phaseo login                 # opens a browser; a person approves it
phaseo login --device-code   # SSH, CI and agent sandboxes: a person enters the code
phaseo whoami --json
```

然后为应用创建一个推理密钥；如果工作区没有额度，就添加额度：

```bash
phaseo keys create --name "Production app" --json
phaseo credits get --json
phaseo login --scopes billing:write   # opt in once before the first top-up; a person approves the sign-in
phaseo credits add --amount 20 --json
```

`phaseo credits add` 需要 `billing:write` 作用域，默认情况下任何登录都不具备该作用域，而且它从不会自行扣款：

- **有已保存的卡时**，Phaseo 会给工作区的每位所有者和管理员发送邮件，附上确认扣款的链接，命令会等待结果。
- **没有已保存的卡时**，它会返回 `next_action: "open_checkout_url"` 和一个结账链接，由所有者或管理员在其中付款。这张卡会被保存以供以后充值使用，不会发送邮件。

该路由参见[额度](../api-reference/endpoint/credits)。

## 选择接口

| 接口 | 适用情况 | 登录方式 |
| --- | --- | --- |
| [`phaseo` CLI](../guides/integrations/phaseo-cli) | 智能体可以运行 shell 命令 | `phaseo login` 或 `phaseo login --device-code` |
| [管理 API](../api-reference/introduction) | 服务器代码、CI，或没有 CLI 的语言 | [管理密钥](./management-api-keys)（`phaseo_v1_mk_...`）或 OAuth 令牌 |
| [Phaseo MCP](./cli-and-mcp#phaseo-mcp) | 智能体运行在 MCP 客户端中 | 连接 `https://mcp.phaseo.app/mcp?access=manage` 并批准你想授予的权限 |

运行 `phaseo <group> --help` 查看你安装的 CLI 接受哪些参数。当某项任务没有专门的命令时，`phaseo api get|post|patch|put|delete /v1/<path>` 会使用你的会话调用该路由。

## 修复 403

CLI 会话、管理密钥或 MCP 连接只能执行其作用域和你的工作区角色所允许的操作，仅限所有者和管理员的更改仍然需要所有者或管理员来完成。如果命令返回 `403`，请用 `phaseo whoami --json` 检查已授予的作用域；缺少某个作用域时，用 `phaseo login --scopes <scope,...>` 重新登录。`billing:write` 默认永远不会授予。
