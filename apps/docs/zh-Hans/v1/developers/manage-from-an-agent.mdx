无需打开控制台，你就可以通过 `phaseo` CLI、`/v1` 管理 API 或 Phaseo MCP 服务器管理 Phaseo 账户。可在本页查找每项任务对应的命令、路由或工具。

只有三个步骤需要由人在浏览器中完成：

- **注册** Phaseo 账户。
- **批准首次登录**：即 `phaseo login` 打开的浏览器页面，或 `phaseo login --device-code` 显示的代码。
- 首次购买额度时**输入银行卡**。之后的充值使用已保存的银行卡，每次都由工作区所有者或管理员通过邮件中的链接批准。

<Visibility for="agents">
管理 Phaseo 的代理应遵守以下规则：

- 不要为了下表中的任务把用户引导到控制台。请运行 CLI 命令、调用路由或使用 MCP 工具。
- 不要生成或猜测 API 密钥。使用 `phaseo keys create --name <name> --json` 创建，并在服务端仅保存一次密钥。
- 每个 CLI 命令都使用 `--json`。只有当用户明确要求该项更改时，才为破坏性命令传入 `--yes`。
- 只发起用户要求的充值。绝不要自行完成支付链接，也不要重试已被拒绝、已过期或已失败的充值。
</Visibility>

## 一次性设置

```bash
npm install -g @phaseo/cli
phaseo login                 # opens a browser; a person approves it
phaseo login --device-code   # SSH, CI and agent sandboxes: a person enters the code
phaseo whoami --json
```

然后为应用创建推理密钥；如果工作区没有额度，再进行充值：

```bash
phaseo keys create --name "Production app" --json
phaseo credits get --json
phaseo login --scopes billing:write   # one-time opt-in before the first top-up
phaseo credits add --amount 20 --json
```

`phaseo credits add` 不会自行扣款。如果有已保存的银行卡，Phaseo 会向工作区的每位所有者和管理员发送确认扣款的邮件链接，命令会等待结果。如果没有已保存的银行卡，则返回一个链接，由所有者或管理员在其中输入银行卡。路由请参阅[额度](../api-reference/endpoint/credits)。

## 选择接口

| 接口 | 适用场景 | 登录方式 |
| --- | --- | --- |
| [`phaseo` CLI](../guides/integrations/phaseo-cli) | 代理可以运行 shell 命令 | `phaseo login` 或 `phaseo login --device-code` |
| [管理 API](../api-reference/introduction) | 服务端代码、CI 或没有 CLI 的语言 | [管理密钥](./management-api-keys)（`phaseo_v1_mk_...`）或 OAuth 令牌 |
| [Phaseo MCP](./cli-and-mcp#phaseo-mcp) | 代理运行在 MCP 客户端中 | 连接 `https://mcp.phaseo.app/mcp?access=manage` 并批准所需权限 |

运行 `phaseo <group> --help` 可查看已安装 CLI 支持的选项。没有专用命令的任务，可用 `phaseo api get|post|patch|put|delete /v1/<path>` 通过你的会话调用路由。

### 密钥与访问

| 任务 | CLI | API 路由 | MCP 工具 |

| 创建 API 密钥 | `phaseo keys create --name <name>` | `POST /v1/keys` | `api_key_create` |
| 列出、更新或删除密钥 | `phaseo keys list`, `keys update <id>`, `keys delete <id>` | `GET`, `PATCH`, `DELETE /v1/keys/{id}` | `api_keys_list`, `api_key_update`, `api_key_delete` |
| 轮换密钥 | `phaseo keys rotate <id>` | `POST /v1/keys/{id}/rotate` | `api_key_rotate` |
| 将密钥限制为特定 IP 地址 | `phaseo keys update <id> --ip-allowlist <label=address,...>` | `PATCH /v1/keys/{id}` | — |
| 创建管理密钥 | `phaseo management-keys create --name <name>` | `POST /v1/management-keys` | — |
| 查看或撤销你授权的应用 | `phaseo authorized-apps list`, `authorized-apps revoke <id>` | `GET`, `DELETE /v1/me/authorized-apps/{id}` | — |
| 更新个人资料 | `phaseo profile update` | `PATCH /v1/me/profile` | — |

## 权限

CLI 会话、管理密钥或 MCP 连接只能执行其作用域和你在工作区中的角色所允许的操作。仅限所有者和管理员的更改仍需由所有者或管理员执行。如果命令返回 `403`，请用 `phaseo whoami --json` 查看已授予的作用域；缺少作用域时，用 `phaseo login --scopes <scope,...>` 重新登录。`billing:write` 永远不会默认授予。
