把 Phaseo 密钥保存在你的服务器上，选择与应用协议相匹配的端点，然后把你的 HTTP 客户端或 SDK 指向 `https://api.phaseo.app/v1`。如果你还没有发送过请求，请从[快速入门](../quickstart.mdx)开始。

你需要一个具有 Gateway 访问权限的 Phaseo 账户，以及一个 HTTP 客户端、兼容 OpenAI 的 SDK 或 Phaseo SDK。示例使用 `google/gemma-3-27b:free`，它无需充值额度即可运行。

<Steps>
<Step title="创建并保存密钥">

在 [Phaseo CLI](../guides/integrations/phaseo-cli) 中运行 `phaseo keys create --name <app-and-environment> --json`，或在[仪表板](https://phaseo.app/settings/keys)中打开**设置 → API 密钥**。按应用和环境为密钥命名，然后把它存放在密钥管理器或环境变量文件中：

```bash
# .env.local
PHASEO_API_KEY="phaseo_v1_sk_<kid>_<secret>"
PHASEO_BASE_URL="https://api.phaseo.app/v1"
```

为本地开发、预览部署和生产环境分别使用不同的密钥，这样你就能单独轮换和审查每一个。

</Step>
<Step title="选择端点">

| 端点 | 用途 |
| --- | --- |
| `/v1/responses` | 新的文本应用、结构化输出和多步骤工作流。 |
| `/v1/chat/completions` | 聊天界面和现有的 OpenAI 风格集成。 |
| `/v1/messages` | 兼容 Anthropic 的集成。 |
| `/v1/decisions` | 使用 Jev 1.13 针对应用状态做出类型化决策（测试版）。 |
| `/v1/moderations` | 安全和内容政策检查。 |
| `/v1/images/generations` | 根据文本提示生成图像。 |

[API 参考](../api-reference/introduction)列出了所有端点、参数和响应。

</Step>
<Step title="从你的应用发送请求">

此示例使用 Chat Completions，兼容 OpenAI 的客户端本身就支持它。每个请求都以 `Authorization: Bearer $PHASEO_API_KEY` 的形式发送密钥。

<CodeGroup>
```bash cURL
curl https://api.phaseo.app/v1/chat/completions \
  -H "Authorization: Bearer $PHASEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemma-3-27b:free",
    "messages": [
      { "role": "system", "content": "You are a helpful assistant." },
      { "role": "user", "content": "Explain the benefits of AI." }
    ]
  }'
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PHASEO_API_KEY,
  baseURL: "https://api.phaseo.app/v1",
});

const response = await client.chat.completions.create({
  model: "google/gemma-3-27b:free",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: "Explain the benefits of AI." },
  ],
});

console.log(response.choices[0]?.message?.content);
```


```go Go
package main

import (
  "context"
  "fmt"

  phaseo "github.com/phaseoteam/Phaseo/packages/sdk/sdk-go/v3"
)

func main() {
  client := phaseo.New("YOUR_API_KEY", "https://api.phaseo.app/v1")

  response, err := client.CreateChatCompletion(context.Background(), phaseo.ChatCompletionsRequest{
    Model: "google/gemma-3-27b:free",
    Messages: []map[string]interface{}{
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain the benefits of AI."},
    },
  })
  if err != nil {
    panic(err)
  }

  fmt.Println(response)
}
```

</Note>
