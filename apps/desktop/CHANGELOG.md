# @phaseo/desktop

## 0.2.0

### Minor Changes

- [#3413](https://github.com/phaseoteam/Phaseo/pull/3413) [`1112661`](https://github.com/phaseoteam/Phaseo/commit/1112661eff4ad5008c5aad179482c47192e74c4b) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Desktop: richer attachments, live work timers, one model-and-effort control, back and forward, browser and HTML tools for agents, delegates in their own worktrees, offers to continue elsewhere when a plan runs out, project defaults, written pull request descriptions, GitLab, Forgejo, Bitbucket and Azure DevOps requests, a local MCP server for outside agents, project folders in the sidebar, and importing past Claude Code and Codex conversations.

- [#3455](https://github.com/phaseoteam/Phaseo/pull/3455) [`6d73f12`](https://github.com/phaseoteam/Phaseo/commit/6d73f1277f976189df2159ec2edee992ec1cae4c) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Desktop settings: new Chat, Diffs, Threads, Browser, Source control, Worktrees and Maintenance pages. Follow-ups can steer by default, and quitting asks first while chats are working. Markdown is styled as you type in every message box and in the other places you write Markdown (pull request and diff comments, review summaries, issue drafts, Factory, scheduled tasks and instructions), and Settings → Chat turns it off everywhere. Diffs get a shared layout and whitespace default and blue-and-orange colours. Chats can resume or snooze until usage limits reset, continue after restarts (now on by default) and compact when idle, with editable snooze times and response streaming modes. Agent health and update checks can be tuned. Links, including pull request and issue links, open where Settings → Browser says; the search engine can be chosen, agent browser tools can be turned off per project, and browsers get separate profiles. Worktrees get a location, branch naming and submodule checkout, and a failed submodule checkout is shown in the chat's Git section. Commit, pull request, title and review guide instructions, a model for git text, and pull request templates are supported. Old recordings and logs can be cleaned up, and About links to the Android app, the licences and the privacy policy.

- [#3413](https://github.com/phaseoteam/Phaseo/pull/3413) [`1112661`](https://github.com/phaseoteam/Phaseo/commit/1112661eff4ad5008c5aad179482c47192e74c4b) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Desktop: side chats. `/side` or `/btw` asks a question beside a chat, in the right pane, without interrupting it, and Bring back hands what you learned to the chat.

- [#3405](https://github.com/phaseoteam/Phaseo/pull/3405) [`c5d5eaa`](https://github.com/phaseoteam/Phaseo/commit/c5d5eaad33cbd330da63cead4b9c01af0e121046) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Add Triage a Phaseo bug to the command palette: an agent debugs the app from the exact source of the running build, fixes and proves the bug, and drafts an issue that you review and file yourself.

- [#3415](https://github.com/phaseoteam/Phaseo/pull/3415) [`c19dddf`](https://github.com/phaseoteam/Phaseo/commit/c19dddf0f2964d1a75c616bf3e8eb40eb37cc2d7) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Code ▸ Factory now sends new GitHub comments, reviews and failed checks to a running stage, from people who can push and review bots you choose. It also nudges runs that go quiet and stops them for you if they stay stuck. Both can be changed in Settings → Checking for new work.

### Patch Changes

- [#3482](https://github.com/phaseoteam/Phaseo/pull/3482) [`1e0ddb8`](https://github.com/phaseoteam/Phaseo/commit/1e0ddb804bbe23105f7cfa29a509fbe009e0ed1c) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Factory's threads no longer load a repository's own agent settings, hooks, plugins or MCP configs (Claude, Cursor, Pi and OpenCode), failed-check logs reach agents fenced as data, and a fork's failed checks are held back. The Slack agent drops web search and web fetch when it can read the workspace's usage, posts replies without link previews, and shows saved pins and skills as people's words, not its own instructions. The Phaseo MCP marks creating keys, provider keys, webhooks and observability destinations as destructive, and the last two as reaching outside Phaseo.

- [#3461](https://github.com/phaseoteam/Phaseo/pull/3461) [`32a90cd`](https://github.com/phaseoteam/Phaseo/commit/32a90cd24f95783050da2929016a384d1db960d4) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Security hardening from the November review. Signed-in users can no longer write OAuth app records directly, move presets into workspaces they don't belong to, or change extended-log billing state. Internal cache actions check for an admin before doing anything. Forged OAuth tokens can no longer force repeated key refreshes, and workload-identity policies from workspaces outside the rollout no longer make a token ambiguous. Transcription and web-fetch downloads are size- and time-limited, more IPv6 private ranges are blocked, and web-api webhook URLs get the same checks as the gateway. Secret comparisons are constant-time. The web app sends HSTS and a report-only content security policy. Factory marks issue text as untrusted in agent prompts, the desktop update feed is fixed at build time, and mobile chat only opens web and email links.
