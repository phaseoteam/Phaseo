# @phaseo/desktop

## 0.2.0

### Minor Changes

- [#3413](https://github.com/phaseoteam/Phaseo/pull/3413) [`1112661`](https://github.com/phaseoteam/Phaseo/commit/1112661eff4ad5008c5aad179482c47192e74c4b) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Desktop: richer attachments, live work timers, one model-and-effort control, back and forward, browser and HTML tools for agents, delegates in their own worktrees, offers to continue elsewhere when a plan runs out, project defaults, written pull request descriptions, GitLab, Forgejo, Bitbucket and Azure DevOps requests, a local MCP server for outside agents, project folders in the sidebar, and importing past Claude Code and Codex conversations.

- [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Phone access: pair the phone app with the desktop by QR code and use your chats from the phone, directly over Tailscale or the same Wi-Fi, or from anywhere with Phaseo Connect. Every connection is end-to-end encrypted.

- [#3455](https://github.com/phaseoteam/Phaseo/pull/3455) [`6d73f12`](https://github.com/phaseoteam/Phaseo/commit/6d73f1277f976189df2159ec2edee992ec1cae4c) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Desktop settings: new Chat, Diffs, Threads, Browser, Source control, Worktrees and Maintenance pages. Follow-ups can steer by default, and quitting asks first while chats are working. Markdown is styled as you type in every message box and in the other places you write Markdown (pull request and diff comments, review summaries, issue drafts, Factory, scheduled tasks and instructions), and Settings → Chat turns it off everywhere. Diffs get a shared layout and whitespace default and blue-and-orange colours. Chats can resume or snooze until usage limits reset, continue after restarts (now on by default) and compact when idle, with editable snooze times and response streaming modes. Agent health and update checks can be tuned. Links, including pull request and issue links, open where Settings → Browser says; the search engine can be chosen, agent browser tools can be turned off per project, and browsers get separate profiles. Worktrees get a location, branch naming and submodule checkout, and a failed submodule checkout is shown in the chat's Git section. Commit, pull request, title and review guide instructions, a model for git text, and pull request templates are supported. Old recordings and logs can be cleaned up, and About links to the Android app, the licences and the privacy policy.

- [#3415](https://github.com/phaseoteam/Phaseo/pull/3415) [`c19dddf`](https://github.com/phaseoteam/Phaseo/commit/c19dddf0f2964d1a75c616bf3e8eb40eb37cc2d7) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Code ▸ Factory now sends new GitHub comments, reviews and failed checks to a running stage, from people who can push and review bots you choose. - [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - The app opens on a new chat, and the bottom tab bar is gone. A sidebar (a drawer on phones that a drag anywhere on the chat opens, always open on tablets) holds search and New chat, Code (with a count of threads that need you), the chats on the phone, then Models, Providers and Usage, and a profile row that opens Account. Those screens open over the chat with a back button, and nothing opens twice. Code lists a paired computer's threads like the desktop's sidebar: needs you first, project folders with New thread, settled threads folded away; each thread opens as its own screen. The composer has one control for the model and its effort, with a sheet to pick both (favourites and recent models first); new threads on a computer can pick from the computer's models too. Home's releases and most used models are now the top of Models, and Compare opens from a model's "Compare with…" (and from the sidebar on tablets). Signed out, the app opens on Models with a "Sign in to chat" button; signing in opens a new chat. Old links, including `/`, and notification taps still open the right screen.

- [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - A paired phone with Make changes on can commit (with Write message), push, pull, and switch or create branches on its computer, start a thread in a new worktree from a base branch, and list, read, review, comment on, merge, close and reopen pull requests through the computer's GitHub sign-in. - [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - A paired phone can review a thread's changes on its computer: uncommitted work, the branch, or one turn, file by file with numbered lines, and a comment on a range of lines goes into the thread's message. The computer's Settings → Phone has switches per phone for reading code (on), making changes and terminals (off), and a change applies at once.

- [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - A paired phone with Use terminals on can open a thread's terminals on its computer, run the project's scripts, type in them (with Esc, Tab, Ctrl, Alt, arrows and Paste), add chosen lines of output to the thread's message, and stop the local servers the thread started. The phone wraps at its own width and never resizes the window's terminal, and the window's title names the phone on every terminal it's in. Use terminals needs Read code, and stays off until it's turned on for that phone in Settings → Phone.
