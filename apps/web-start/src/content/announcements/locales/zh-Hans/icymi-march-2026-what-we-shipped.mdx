3 月是 Phaseo 打基础的一个月。许多工作旨在让用户更信任产品，为春季晚些时候推出更重要的 Gateway 和目录更新做好准备。

本回顾涵盖 **2026 年 3 月 1 日至 3 月 31 日** 发布的内容，依据当月的发布记录、提交记录和目录数据整理而成。

## 本月发布

### 嵌入向量更易使用

3 月，嵌入向量支持从“可以使用”变得更加醒目。我们改进了产品、API、SDK 示例和文档，让团队能找到嵌入模型、了解它们在目录中的用途，并直接基于它们进行开发，无需在产品的不同位置来回查找。

这很重要，因为嵌入向量往往是搜索、检索、排序、记忆和推荐流程的第一个基础组件。它们未必是最受关注的模型发布，但许多实用 AI 功能都依赖它们。

本月目录还加入了 Gemini Embedding 2 Preview，并更新了更多模型元数据。这些改进让 Phaseo 不仅适用于构建聊天界面，也更适合构建检索流程。

浏览目录：

- [查看模型](/models)

### 模型页面更精简，也更容易浏览

3 月，模型页面获得了多项实用改进。时间线开始直接查询前一项和后一项，清理了提供商和模型路由，并同步更新了 Web 应用、API、文档和 SDK 中的模型数据。

这是一次低调但重要的改进：模型页面减少了不必要的处理，产品也更擅长在合适的位置展示正确的模型信息。

搜索功能也有改进。页眉搜索开始优先匹配完整模型名称，并调整了聊天链接，让消息能指向正确的模型页面。目录快速增长时，用户想直接跳转到某个具体发布，这些改进就很有帮助。

### 多模态覆盖范围继续扩大

3 月进行了一批较广泛的更新，使 SDK、多模态示例、文档和产品页面保持一致。音频、视频和聊天界面也在本月陆续得到相关改进。

这些工作并非以一个大型功能的形式一次性上线，而是为产品支持文本模型以外的能力打基础。关键在于一致性：模型类型、文档、示例和产品页面开始更好地对应起来。

这对开发者很重要。如果模型支持音频或视频，产品就应明确说明，文档要解释用法，SDK 示例也不能落后于产品。

### 计费和额度信息更加清晰

3 月新增了促销码兑换流程，改进了交易流程，并为未结清的促销额度总额添加了内部视图。Gateway 也统一了计费用量和快速开始标识符。

这些变化不一定会出现在用户的截图里，但能减少困惑。第一次试用 Phaseo 的用户需要清楚了解基本信息：拥有多少额度、已经用了多少，以及额度属于哪个账户或工作区。

这些工作也为 4 月发布的账户和工作区重大调整做好了准备。

### SDK 和发布工具保持同步

本月发布了多个软件包，开展了 SDK 验证和版本检查，并更新了生成式客户端。随着模型陆续发布，公开软件包也能继续与 API 和模型目录保持一致。

对于目录型产品，这一点尤其重要。只有新的模型数据进入开发者真正使用的环节，才有价值：模型 ID、生成式 SDK、文档、示例和 API 响应。

## 其他更新

- 完善了移动导航，包括下拉菜单宽度、分隔线和主题控件，并统一了移动菜单。
- 通过更安全的副作用处理和更完善的分阶段日志，更容易定位注册失败。
- 调试结束后，移除了临时的上游聊天错误日志。
- 更新了整个仓库的依赖，其中包括安全公告相关更新。
- 改进了模型发现提醒、Hugging Face 通知和内部通知，让目录更新更容易跟进。

## 模型亮点

3 月新增了多款重要模型。OpenAI GPT 5.4、GPT 5.4 Pro、GPT 5.4 Mini 和 GPT 5.4 Nano 扩大了目录中的 OpenAI 覆盖范围。Gemini 3.1 Flash Lite Preview 和 Gemini Embedding 2 Preview 增加了实用的 Google 模型。Mistral Small 4、Mistral Moderation 2、Leanstral 和 Voxtral TTS 扩大了 Mistral 在文本、审核和语音方面的覆盖范围。

本月还发布了 GLM 5 Turbo、Nemotron 3 Super、MiniMax M2.7、多个 Xiaomi MiMo V2 模型，以及月底首次收录的 Veo 3.1 Lite Preview。

## 本月概览

本地 Git 历史记录显示，3 月共有 **74 次提交**。本月包括模型数据和 SDK 软件包发布、计费修复、移动导航优化，以及 OpenAI、Anthropic、Google、Mistral、Xiaomi、MiniMax、Qwen 等目录更新。
