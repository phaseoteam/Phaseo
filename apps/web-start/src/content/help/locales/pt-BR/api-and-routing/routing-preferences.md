---
title: Preferências de roteamento
description: Configure o comportamento de roteamento padrão e a participação no canal beta.
order: 1
updated: 2026-02-09
---

As preferências de roteamento são gerenciadas em `Configurações -> Roteamento`.

Opções atuais:

- Equilibrado
- Preço
- Taxa de transferência
- Latência

Você também pode participar do canal beta para receber lançamentos antecipados de provedores. O roteamento beta não é recomendado para SLAs de produção rigorosos.
