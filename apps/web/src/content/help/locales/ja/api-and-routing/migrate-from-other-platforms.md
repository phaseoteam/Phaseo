ガイド付きの移行手順とコードの変更を並べて確認するには、`/migrate` を使用します。

推奨される移行フロー：

1. 現在利用しているプロバイダーまたは SDK を選択します。
2. 統合方式（SDK または REST）を選択します。
3. 生成された差分を適用し、エンドポイントを一つずつテストします。

まずリスクの低いリクエストから始め、レイテンシーとコストの目標が安定したら、段階的にトラフィックを増やしてください。
