---
title: 多重身份验证设置与恢复
description: 如何注册和管理多重身份验证访问权限。
order: 2
updated: 2026-07-11
---

从 `Settings -> Account` 启用 MFA，以保护你的 API 密钥和账单操作。

推荐的设置方式：

- 首先注册一个身份验证器应用。
- 更换设备前，安全备份身份验证器配置。
- 设置完成后确认能够重新登录。

Supabase MFA 只有在身份验证器挑战验证通过后才会升级会话。由于自定义恢复代码无法创建所需的 AAL2 会话，本应用不会发放自定义恢复代码。如果你无法访问身份验证器，请联系支持团队以安全地恢复账户。

当当前环境已启用通行密钥时，也可以从 MFA 设置页面添加通行密钥。通行密钥支持免密码登录，但不能替代 MFA 所需的身份验证器因素。
