Usa `/migrate` para consultar pasos de migración guiados y cambios de código comparados.

Flujo de migración recomendado:

1. Elige tu proveedor o SDK actual.
2. Selecciona el estilo de integración (SDK o REST).
3. Aplica el diff generado y prueba un endpoint cada vez.

Empieza con solicitudes de bajo riesgo y amplía el tráfico gradualmente cuando los objetivos de latencia y coste sean estables.
