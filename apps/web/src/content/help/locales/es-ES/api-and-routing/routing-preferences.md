---
title: Preferencias de enrutamiento
description: Configura el comportamiento predeterminado del enrutamiento y la participación en el canal beta.
order: 1
updated: 2026-02-09
---

Las preferencias de enrutamiento se gestionan en `Settings -> Routing`.

Opciones actuales:

- Equilibrado
- Precio
- Rendimiento
- Latencia

También puedes activar el canal beta para recibir antes los lanzamientos de proveedores. El enrutamiento beta no se recomienda para SLA de producción estrictos.
