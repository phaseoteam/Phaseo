title: Routing-Einstellungen
description: Konfigurieren Sie das Standard-Routing und die Teilnahme am Beta-Kanal.

updated: 2026-02-09
---

Routing-Einstellungen werden unter `Einstellungen -> Routing` verwaltet.

Aktuelle Optionen:

- Ausgewogen
- Preis
- Durchsatz
- Latenz

Sie können außerdem dem Beta-Kanal für frühe Anbieter-Rollouts beitreten. Beta-Routing wird für strenge Produktions-SLAs nicht empfohlen.
