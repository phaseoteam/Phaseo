---
title: Préférences de routage
description: Configurez le comportement de routage par défaut et la participation au canal bêta.
order: 1
updated: 2026-02-09
---

Les préférences de routage se gèrent depuis `Settings -> Routing`.

Options actuelles :

- Équilibré
- Prix
- Débit
- Latence

Vous pouvez également rejoindre le canal bêta pour tester plus tôt les déploiements de fournisseurs. Le routage bêta n’est pas recommandé pour les accords de niveau de service stricts en production.
