Utilisez `/migrate` pour consulter les étapes de migration guidées et les modifications de code côte à côte.

Parcours de migration recommandé :

1. Choisissez votre fournisseur ou SDK actuel.
2. Sélectionnez le type d’intégration (SDK ou REST).
3. Appliquez le diff généré et testez un point de terminaison à la fois.

Commencez par des requêtes à faible risque, puis augmentez progressivement le trafic une fois les objectifs de latence et de coût stabilisés.
