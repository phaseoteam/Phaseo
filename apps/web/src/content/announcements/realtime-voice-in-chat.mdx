Text benchmarks tell you little about how a voice model sounds and feels in conversation. The only real test is to talk to it: how quickly it answers, whether you can interrupt it, how natural the voice is, and what a few minutes of talking actually costs.

**Realtime voice is now open to every Phaseo account in Chat.** Open [Chat → Realtime](https://phaseo.app/chat/realtime), pick a model and a voice, and start talking. There's nothing to install and no API key to create, and you pay for each call from your workspace credits.

## Talk to voice models from four providers in one place

  <Feature title="Google" meta="Gemini Live">Gemini 3.8 Live, with or without extended thinking, and Gemini 3.1 Flash Live.</Feature>

Switch models between calls to hear the difference for yourself, with the same instructions and the same question.

## See what each call costs as you talk

Chat shows how long the call has run and what it has cost so far, and the exact bill when it ends: audio and text tokens, cached input, and any web searches, priced at the model's published rates. There's no subscription, and Chat calls cost the same as API calls.

To keep a forgotten tab from costing money, Chat ends a call after five minutes with no activity, and when a spend limit on your key is reached. Every provider also has a maximum call length, from 25 minutes for GPT Live to two hours for Grok Voice.

## Settings you can change

- **Voice:** each model's built-in voices, with the regional style described where the provider documents it.
- **Instructions:** tell the model who it is and how to answer, and keep the same instructions while you compare models.
- **GPT Live delegation:** pick the background model, its reasoning effort and output limit, and whether it may search the web.

## Coming next: realtime voice on the API

The same realtime voice models will be available through the Phaseo API, with SDKs for TypeScript, Python, Go, Java, C#, PHP, Ruby and Rust that return each call's final bill. We're opening API access gradually. Until then, the [realtime voice guide](https://phaseo.app/docs/v1/guides/realtime-voice) shows how sessions, events and billing work.

## Get started

Open [Chat → Realtime](https://phaseo.app/chat/realtime) and allow microphone access when your browser asks. If your workspace has no credits yet, add some under [Settings → Credits](https://phaseo.app/settings/credits) first.
