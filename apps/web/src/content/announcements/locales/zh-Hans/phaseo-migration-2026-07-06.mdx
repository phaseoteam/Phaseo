AI Stats 正在更名为 **Phaseo**，因为团队需要的不只是一个模型目录。

他们需要决定使用哪个模型、调用哪家提供商、某条路由的成本是多少，以及市场变化时如何调整方向。

**Phaseo 将这些工作整合到一个地方：**模型发现、提供商覆盖范围、网关路由、成本可见性、SDK，以及面向生产 AI 系统的可观测性。

更名是因为产品已经发生变化。Phaseo 帮助团队了解、比较、切换和使用 AI 模型，无需每当市场变化就重建整个技术栈。

## 为什么现在更名

AI 正从实验和单点集成转变为核心产品基础设施。

静态的模型信息很有用，但当模型进入产品后，这些信息就不够了。生产团队需要了解哪些提供商支持某个模型、每条路由如何定价、某个端点是否可调用、近期有哪些变化，以及下个月出现更好的模型时迁移有多困难。

市场也在变得更大、更分散。[Gartner 预测，2026 年全球 AI 支出将达到 2.52 万亿美元](https://www.gartner.com/en/newsroom/press-releases/2026-1-15-gartner-says-worldwide-ai-spending-will-total-2-point-5-trillion-dollars-in-2026)，同比增长 44%。

斯坦福的 [2026 AI Index](https://hai.stanford.edu/ai-index/2026-ai-index-report) 报告称，2025 年组织采用率达到 88%，美国私人 AI 投资达到 2859 亿美元。

这些数字很重要，因为 AI 支出已不再只是研究预算或原型中的几次 API 调用。它正在成为经常性运营成本。团队需要更好地控制路由、定价、可观测性和模型选择，才能避免这些成本变得难以判断。

**Phaseo 帮助团队持续看清这些决策。**它将模型元数据、提供商可用性、路由定价和网关行为连接起来，让团队能在模型层变成昂贵的黑箱之前进行检查。

## AI 订阅正在改变人们的预期

AI 也正在成为面向消费者和职场的订阅类别。

[OpenAI 表示，ChatGPT 在 2026 年 2 月达到每周 9 亿活跃用户和 5000 万付费订阅用户](https://techcrunch.com/2026/02/27/chatgpt-reaches-900m-weekly-active-users/)。Sensor Tower 的 [2026 State of AI 报告](https://sensortower.com/blog/state-of-ai-2026)随后指出，ChatGPT 在 2026 年 5 月达到每月 10 亿活跃用户。

这种覆盖面改变了人们体验 AI 的方式。越来越多用户通过订阅、用量限制、产品等级和快速变化的默认设置接触模型。SemiAnalysis 也从成本角度持续跟踪这一趋势，从[$20 和 $200 的 AI 订阅服务](https://newsletter.semianalysis.com/p/claude-code-is-the-inflection-point)的经济效益，到[企业讨论](https://newsletter.semianalysis.com/p/tokenbudgeting-our-conversations)中逐渐成为实际运营问题的 token 预算、高级模型访问权限和人均 AI 支出。

模型质量提升的速度同样很快。Phaseo 跟踪的版本，包括 [Claude Fable 5](https://phaseo.app/models/anthropic/claude-fable-5) 和 [Claude Mythos 5](https://phaseo.app/models/anthropic/claude-mythos-5)，展示了团队需要多频繁地重新评估质量、可用性、定价和提供商支持。

对开发者而言，结论很直接：AI 不再是一次性选择的单一供应商，而是一个持续变化的订阅、用量、成本和能力问题。

**Phaseo 就是为这个循环而构建的。**团队可以比较模型、了解提供商覆盖情况、有计划地路由流量，并在经济性或质量曲线变化时进行切换。

## 模型选择正成为基础设施的一部分

模型层的变化速度超过了大多数应用层。

团队可能最初选择一个封闭模型，因为它最适合推理。一个月后，成本更低的模型可能已足以完成分类或信息提取。另一个工作负载可能需要开放权重模型，以满足数据主权、微调、延迟要求，或在受控环境中部署的需求。

实时语音功能可能更关注延迟和分钟计费，而不是基准测试分数。编程助手所需的模型，也可能不同于客户支持分流流程。

永远只选一个模型通常不是合理的抽象方式。

**Phaseo 支持更持久的模式：**让应用保持足够的可移植性，使团队能够有计划地迁移。

**借助 Phaseo，团队可以：**

- 为不同任务使用最合适的模型
- 在切换流量之前比较提供商
- 在用量扩大之前看清价格
- 在服务中断或提供商限制时切换路由
- 测试开放、封闭、托管和自托管方案
- 切换模型时保留可观测性

Phaseo 将模型发现与周边的生产工作流连接起来。目录帮助团队比较方案；网关和 SDK 帮助他们在生产环境中使用这些模型；定价和提供商覆盖范围说明其中的取舍；网关可观测性则展示请求路由后发生了什么。

## AI 支出增长时，开放技术愈发重要

即使封闭的前沿模型在某些领域仍处于领先地位，开源和开放权重 AI 的战略重要性也在不断上升。

斯坦福的 2026 AI Index 指出，开源开发正在扩大 AI 的参与面：世界其他地区在 GitHub 上的贡献现已超过欧洲，并接近美国。

与此同时，开放权重模型持续快速进步；[Artificial Analysis](https://artificialanalysis.ai/models/open-source) 等服务会从质量、速度、上下文窗口、参数数量和许可等方面跟踪开放模型。

这对生产环境很重要。

开放技术让团队有更多方式控制工作运行的位置、数据处理方式和长期成本结构，也降低了产品与单一供应商的模型、定价、政策或可用性紧密绑定的风险。

在某些场景中，封闭的托管模型仍是正确选择；在另一些场景中，开放权重模型、自托管或混合路由策略会更合适。

**Phaseo 面向这种混合环境而设计。**它将开放、封闭、托管和自托管模型视为团队可能需要组合使用的选项，而不是彼此割裂、各用一套工具的世界。

团队不应被迫在“使用最新的托管前沿模型”和“自己掌控每一层”之间二选一。多数生产系统会处于这两个极端之间，并随时间使用多家提供商、多个模型系列和多种部署方式。

**Phaseo 帮助团队管理这个中间地带，**将比较、路由、定价和可观测性整合到同一个工作流中。

## Phaseo 如何支持模型选择

**Phaseo 将模型信息和运行工具整合到一个产品中。**

**借助 Phaseo，团队可以：**

- 搜索模型、提供商、版本、状态和元数据
- 查看模型与提供商页面，了解可用性、定价、生命周期状态和路由选项
- 通过兼容 OpenAI 的工作流和提供商专属工作流路由请求
- 使用 SDK 和示例构建网关集成
- 在流量扩大之前比较提供商和路由定价
- 跟踪模型发布、提供商变更、SDK 发布和产品改进
- 了解网关在生产环境中的行为

切换模型应该是一项运维决策，而不是重写应用。

如果提供商调整定价、模型退役、更好的开放权重模型出现，或工作负载需要迁移到延迟更低的路由，团队应能检查选项、做出选择，并保持周边应用稳定。

## Phaseo 迁移有哪些变化

公开产品、文档、SDK 示例和产品文案正在迁移到 Phaseo 品牌。

具体变化包括：

- 主站迁移到 `phaseo.app`
- 文档、SDK 指引、更新日志条目和产品文案使用 Phaseo 名称
- 新的开发者示例使用 `PHASEO_*`
- 新生成的 API 密钥使用 `phaseo_v1_sk_` 前缀
- 本地、预览和生产构建使用不同的 favicon，让开发者可以快速识别正在测试的环境

这次调整会直接采用新命名。新项目应使用 Phaseo 名称。现有部署不需要进行会造成干扰的环境变量重命名；团队可以按自己的安排保留原变量名，并在准备好时更新其值。

## 开发者需要了解的 API 密钥变化

迁移期间，现有 API 密钥会继续有效。品牌更改后，你无需立即轮换仍在使用的密钥。

迁移后生成的新 API 密钥将使用 Phaseo 前缀：

```bash
PHASEO_API_KEY=phaseo_v1_sk_...
PHASEO_BASE_URL=https://api.phaseo.app/v1
```

旧式 `aistats` API 密钥将在六个月的过渡期内继续有效，计划于 **2027 年 1 月 1 日**停止工作。在此之前，请创建一个新的 Phaseo 前缀密钥，并按自己的时间安排将其替换到部署环境中。

SDK 示例、webhook 验证片段、CLI 配置和管理密钥示例都已更新为 Phaseo 名称。如果这能减少改动，你仍可在自己的应用中继续使用现有环境变量名；新示例使用 `PHASEO_*`，让新项目从当前命名开始。

如果你运行本地或预览构建，favicon 现在会根据环境变化：

- 本地开发使用开发环境 favicon
- Vercel 预览部署使用预览环境 favicon
- 生产环境使用生产环境 favicon

这有助于避免在测试时混淆本地构建、预览部署和线上站点。

## 主站将迁移到 phaseo.app

这将成为产品、文档、博客和模型发现功能的规范入口。旧 AI Stats 链接会在迁移过程中得到处理，但新的链接应指向 Phaseo。

## 产品目标保持不变

Phaseo 仍专注于清晰的模型信息、实用的网关工具、提供商可见性、清楚的定价、SDK，以及让 AI 产品决策更明确的工作流。

品牌名称在变化，因为产品已经成长。

支撑产品的需求也变得更加清晰：AI 团队需要可移植性、成本可见性、开放技术选项，以及一种随着市场变化在模型之间顺畅切换的方式。

这次更名标志着品牌终于与产品相匹配。
