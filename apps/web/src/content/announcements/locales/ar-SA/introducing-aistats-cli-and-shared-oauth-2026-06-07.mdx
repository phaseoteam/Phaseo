نقدّم اليوم **Phaseo CLI**، وهي طريقة جديدة للعمل مع Phaseo من خلال الطرفية.

تضع CLI الأدوات الأكثر استخدامًا لدى المطوّرين—المصادقة ومفاتيح API والأرصدة والنماذج وإدارة مساحات العمل وسجلات الطلبات—في المكان الذي يجري فيه العمل بالفعل. وهي مناسبة للطرفية المحلية، والصدفة البعيدة، وسير عمل الوكلاء على حد سواء.

هدفنا بسيط: تقصير المسافة كثيرًا بين الفكرة وتطبيق ذكاء اصطناعي يعمل ويمكن مراقبته.

## من تسجيل الدخول إلى الطلب الأول

غالبًا ما يتطلب البدء باستخدام بوابة ذكاء اصطناعي جديدة التنقّل بين الوثائق ولوحة التحكم ومتغيرات البيئة والطرفية قبل إرسال الطلب الأول. تجمع Phaseo هذا الإعداد الآن في مسار متصل واحد.

ثبّت CLI، وسجّل الدخول بحساب Phaseo، وأنشئ مفتاحًا:

<CliInstallTabs packageName="@phaseo/cli" />

```bash
phaseo login
phaseo keys create --name "My first Phaseo key"
```

على حاسوبك المحمول، يفتح `phaseo login` متصفحًا. وفي جلسات SSH والبيئات البعيدة وسائر مسارات العمل بلا واجهة رسومية، يوفّر تسجيل الدخول برمز الجهاز التجربة نفسها من دون الحاجة إلى استدعاء محلي.

```bash
phaseo login --device-code
```

بعد ذلك، تعرض CLI مساحة العمل الحالية ورصيد الأرصدة والنماذج المتاحة والموفّرين والأسعار والإعدادات المسبقة والضوابط الوقائية. ويمكنك إدارة مفاتيح API وإعدادات مساحة العمل من دون قطع سير عملك لفتح لوحة التحكم.

يوضح هذا المسار الأول كيف نريد أن تكون تجربة CLI: مباشرة وسهلة الاستكشاف ومفيدة من دون مطالبة المطوّرين بتعلّم بنية كل نقطة نهاية في API أولًا. تتضمن الأوامر مساعدة مدمجة، ومخرجات سهلة القراءة عند الاستخدام التفاعلي، ومخرجات JSON عندما تحتاج إلى تمرير النتيجة إلى أداة أخرى.

## واجهة واحدة لمنصة Phaseo

يتجاوز الإصدار الأول المصادقة بكثير؛ فهو يجمع مجموعة واسعة من مسارات عمل Phaseo في واجهة سطر أوامر واحدة:

- إنشاء مفاتيح API وفحصها وتحديثها وتعطيلها وحذفها
- إنشاء مفاتيح إدارة بصلاحيات واضحة لأتمتة موثوقة
- عرض مساحات العمل وفحص أعضائها وإدارة العضوية فيها
- عرض الإعدادات المسبقة والإعدادات والضوابط الوقائية وتهيئتها
- استكشاف النماذج والموفّرين والأسعار
- مراجعة الأرصدة والنشاط والتحليلات وعمليات التوليد
- فحص طلبات البوابة واسترجاع طلب محدد باستخدام معرّفه
- استدعاء نقطة نهاية مصادق عليها في Phaseo API مباشرةً عندما لا يتوفر لها أمر مخصص بعد

تستطيع CLI الآن مرافقة المشروع من الإعداد الأولي إلى التشغيل اليومي. ففي جلسة طرفية واحدة، يمكن للمطوّر تسجيل الدخول وإنشاء مفتاح محدود الصلاحيات والتأكد من وجود رصيد في الحساب واختيار نموذج وفحص حركة الطلبات الناتجة.

كما توفّر للفرق واجهة تشغيل موحّدة. ويمكن نقل الأوامر المستخدمة أثناء التطوير المحلي إلى البرامج النصية وأدلة التشغيل والبيئات البعيدة والأتمتة محددة الصلاحيات بعناية، من دون الاعتماد على التفاعل مع لوحة التحكم.

## مصممة للأشخاص والوكلاء

تزداد استعانة المطوّرين ووكلاء البرمجة بالطرفية لفهم المشاريع. وبفضل واجهة Phaseo الرسمية، يمكنهم فعل أكثر من إنشاء شيفرة التكامل: إذ يستطيعون التحقق من مساحة العمل النشطة وإنشاء المفتاح المناسب وفحص الرصيد المتاح والتحقيق فيما حدث بعد تشغيل الطلب.

تدعم معظم الأوامر مخرجات JSON منظّمة، ما يجعل الواجهة نفسها مناسبة لشخص يعمل عند موجّه الأوامر ولوكيل ينفّذ مهمة:

```bash
phaseo whoami --json
phaseo credits get --json
phaseo models list --limit 20 --json
```

يمهّد ذلك أيضًا لإنشاء مهارة Phaseo CLI تساعد الوكلاء المتوافقة على استخدام مسارات العمل هذه بأمان واتساق داخل المشروع.

وهذا الفرق مهم. فلا ينبغي أن يضطر الوكيل إلى تخمين صفحة الإعداد في لوحة التحكم أو استخراج المعلومات من واجهة المستخدم أو مطالبة المطوّر بنسخها بين الأدوات. فمن خلال CLI مصادق عليها ومنظّمة، يمكنه فحص الحالة المسموح له برؤيتها وتنفيذ إجراء صريح عبر الواجهة المدعومة نفسها التي يستخدمها المطوّر.

نطوّر مهارة CLI إلى جانب المنتج لكي تفهم الوكلاء الأوامر المتاحة وتفضّل المخرجات المقروءة آليًا وتتجنب كشف الأسرار المنشأة حديثًا وتسترجع تفاصيل طلب بعينه عند الحاجة إلى أدلة لتشخيص مشكلة في التكامل.

## افهم كل طلب

لا ينتهي تطوير الذكاء الاصطناعي بنجاح الطلب. يحتاج المطوّرون إلى معرفة النموذج والموفّر اللذين عالجاه، والوقت الذي استغرقه، وتكلفته، وسبب فشل أي جزء منه.

توفّر Phaseo CLI هذا السياق مباشرةً في الطرفية. يمكنك تضييق نطاق الطلبات الحديثة إلى ما يهمك، ثم فحص تفاصيل طلب بعينه:

```bash
phaseo logs list --since 1h --status error --json
phaseo logs get <request-id> --json
```

تتضمن تفاصيل الطلب السياق التشغيلي اللازم للتحقيق في التوجيه والحالة وزمن الاستجابة والنموذج والموفّر والتكلفة. وهذا يمنح المطوّرين والوكلاء حلقة ملاحظات أقصر: أنشئ وشغّل وافحص وحسّن من المكان نفسه.

نبدأ بقوائم الطلبات المصفّاة واسترجاع الطلبات الفردية. وستأتي المتابعة المباشرة لاحقًا.

على المدى الطويل، نريد أن تصبح CLI رفيقًا متكاملًا لمراقبة Phaseo. ويشمل ذلك خيارات تصفية أوسع، وتنقّلًا أسهل بين الطلبات وعمليات التوليد المرتبطة، وملخصات أوضح للتكلفة وزمن الاستجابة، ومسارات عمل مباشرة لمتابعة حركة الطلبات أثناء تطوير تطبيق أو تصحيح أخطائه.

وسيظل المبدأ كما هو: إتاحة سياق تشغيلي كافٍ لحل المشكلة مع إبقاء بيانات التطبيق الحساسة خارج مخرجات CLI العامة.

## توجهنا: التكافؤ مع API ولوحة التحكم

يمثّل هذا الإطلاق بداية CLI، لا نهاية ما يمكنها فعله.

هدفنا على المدى الطويل أن يكون لكل مسار عمل مهم في Phaseo متاح عبر API أو لوحة التحكم مسار مصمم بعناية في CLI أيضًا. فإذا أمكن تنفيذ إجراء في Phaseo، ينبغي أن يتمكن المطوّرون من اكتشافه وتشغيله وأتمتته من دون مغادرة الطرفية.

نخطط لتوسيع CLI لتغطي المنصة، بما في ذلك:

- إدارة أوسع لمساحات العمل والأعضاء والصلاحيات
- تحكم كامل في دورة حياة مفاتيح API ومفاتيح الإدارة
- تهيئة شاملة للإعدادات المسبقة والتوجيه والموفّرين والضوابط الوقائية
- تقارير أوسع عن الاستخدام والإنفاق والأرصدة والأداء
- مراقبة أشمل لعمليات التوليد والطلبات
- معلومات تشخيصية قابلة للتصدير لتسريع الدعم والتحقيق في الحوادث
- تحسين مسارات العمل غير التفاعلية لأنظمة CI والنشر والوكلاء
- أوامر مخصصة للميزات الجديدة في Phaseo عند إطلاقها

لا يعني تكافؤ الميزات عرض قائمة طويلة من مسارات API آليًا. ينبغي أن تجعل CLI المهام الشائعة أسهل من تركيب الطلبات الخام يدويًا. وسنواصل إضافة أوامر مركّزة بإعدادات افتراضية مفيدة ومساعدة واضحة وأخطاء متوقعة ومخرجات JSON مستقرة.

إلى أن يتوفر أمر مخصص، يتيح الأمر المصادق عليه `phaseo api` استدعاء نقاط نهاية API المدعومة. وهكذا يستطيع المستخدمون المتقدمون مواصلة العمل عبر CLI بينما تتوسع مجموعة الأوامر ذات المستوى الأعلى.

ستظل لوحة التحكم أفضل واجهة مرئية لاستكشاف البيانات وتهيئة Phaseo تفاعليًا. أما CLI فستكون شريكتها التشغيلية: سريعة الاستدعاء، سهلة الأتمتة، ومتاحة أينما أمكن تشغيل صدفة.

## آمنة افتراضيًا

تستخدم CLI أساس OAuth نفسه الذي نبنيه عبر Phaseo، بما في ذلك تسجيل الدخول الآمن عبر المتصفح، وتفويض الجهاز، والوصول قصير الأجل، ورموز التحديث الدوّارة. وعندما يكون ذلك متاحًا، تُخزَّن الجلسات في مخزن بيانات الاعتماد الآمن لنظام التشغيل؛ ويؤدي تسجيل الخروج إلى إبطال الجلسة المخزنة.

تتبع الصلاحيات عضوية مساحة العمل في الوقت الفعلي. فإذا أُزيل مستخدم من مساحة عمل، فلن تعود جلسة CLI الخاصة به قادرة على قراءة معلوماتها أو تغييرها.

يقتصر فحص الطلبات عمدًا على البيانات الوصفية. ولا تعرض أوامر السجلات في CLI المطالبات أو أجسام الطلبات أو الترويسات أو آثار التتبع أو معرّفات المستخدمين النهائيين.

تستخدم مفاتيح الإدارة صلاحيات صريحة لمنح الأتمتة القدر الذي تحتاج إليه فقط. وتظل مفاتيح البوابة العادية خاضعة لسياسة مساحة العمل وإعدادات التوجيه والحدود والضوابط الوقائية. لا تظهر الأسرار المنشأة حديثًا إلا مرة واحدة، وينبغي حفظها في مدير أسرار بدلًا من إيداعها في مستودع أو كتابتها في السجلات.

ستظل هذه الحدود مهمة مع اقتراب CLI من تكافؤ أوسع في الميزات. وستتبع الأوامر الجديدة نموذج التفويض لمساحات العمل نفسه الذي تستخدمه API ولوحة التحكم، بدلًا من إنشاء مسار تحكم منفصل ذي صلاحيات أعلى.

## متاحة اليوم

أصبحت Phaseo CLI متاحة اليوم. وتتصل افتراضيًا بـ `https://api.phaseo.app`، كما يمكن توجيهها إلى نشر محلي أو تجريبي باستخدام `PHASEO_API_URL`.

لا تزال تطبيقات OAuth التي ينشئها المستخدمون قيد الاختبار الخاص. ويركز هذا الإصدار على جعل تجربة CLI الرسمية موثوقة للمطوّرين والفرق والوكلاء.

ستدعم أعمال OAuth المشتركة التي تقف وراء CLI استخدامات تتجاوز تجربتنا الطرفية نفسها. ونعتزم أن تشكّل أساسًا لتطبيقات خارجية معتمدة تطلب نطاقات واضحة وتحصل على موافقة المستخدم وتعمل وفق نموذج التفويض نفسه الذي يراعي مساحات العمل. ونبقي إنشاء تطبيقات OAuth خاصًا إلى أن نتحقق من هذه الضوابط عبر CLI الرسمية.

بعد تثبيتها، ستخبرك CLI عند توفر تحديث. كما يمكنك تحديثها يدويًا في أي وقت:

ينبغي أن تكون الطرفية وسيلة أساسية لاستخدام Phaseo. يضع هذا الإصدار الأساس لذلك: تسجيل دخول آمن، ومجموعة واسعة من الأوامر المفيدة، ومخرجات منظّمة للوكلاء والأتمتة، وسياق الطلبات بالقرب من الشيفرة التي أنشأتها.

ومن هنا، سنواصل تقريب CLI وAPI ولوحة التحكم حتى يمكن إتمام سير عمل Phaseo كاملًا من أي مكان يختاره المطوّرون.
