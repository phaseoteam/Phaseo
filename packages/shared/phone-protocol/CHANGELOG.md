# @phaseo/phone-protocol

## 0.2.0

### Minor Changes

- [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - A new thread on a paired computer starts from the composer: pick Chat, Code or Plan and any model from any agent on the computer (Phaseo and the coding agents signed in there), starting where the computer's window would. The phone shows the permissions the thread will run with. The computer now lists every connected agent's models to the phone instead of one agent's.

- [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - The phone's sidebar switches between Phaseo and a paired computer. With a computer chosen, it lists that computer's projects (empty ones too) and threads in place of the separate Code screen. Phone protocol 2 adds `list_projects` and `projects_changed`, and phones from before it keep working.

- [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - A paired phone can browse and search a project's files on its computer, read-only: text with line numbers, Markdown rendered, and images. "Add to message" puts the file into the thread's message as `@path`. Files shows from a thread and from each project folder, and only while Read code is on for that phone.

- [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - A paired phone with Make changes on can commit (with Write message), push, pull, and switch or create branches on its computer, start a thread in a new worktree from a base branch, and list, read, review, comment on, merge, close and reopen pull requests through the computer's GitHub sign-in. Each runs the window's own command, and the window says what the phone did. Make changes needs Read code, and stays off until it's turned on for that phone in Settings → Phone.

- [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - A paired phone can review a thread's changes on its computer: uncommitted work, the branch, or one turn, file by file with numbered lines, and a comment on a range of lines goes into the thread's message. The computer's Settings → Phone has switches per phone for reading code (on), making changes and terminals (off), and a change applies at once.

- [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - A paired phone with Use terminals on can open a thread's terminals on its computer, run the project's scripts, type in them (with Esc, Tab, Ctrl, Alt, arrows and Paste), add chosen lines of output to the thread's message, and stop the local servers the thread started. The phone wraps at its own width and never resizes the window's terminal, and the window's title names the phone on every terminal it's in. Use terminals needs Read code, and stays off until it's turned on for that phone in Settings → Phone.

- [#3477](https://github.com/phaseoteam/Phaseo/pull/3477) [`85f6240`](https://github.com/phaseoteam/Phaseo/commit/85f6240a61eca896f3f340a6912d0c88f1b92953) Thanks [@DanielButler1](https://github.com/DanielButler1)! - Threads on a paired computer can be organised from the phone: swipe to settle, snooze or archive, a long-press menu with pin, rename and mark unread, undo, and an archive screen. A thread's mode, model and effort change from its floating composer, its queue can be sent now, edited, moved or removed, and each turn shows the files it changed.
